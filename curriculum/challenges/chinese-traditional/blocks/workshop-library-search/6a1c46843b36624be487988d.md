# --description--

現在你需要處理潛在的問題。如果使用者在輸入欄位中沒有輸入任何內容就點擊「搜尋」按鈕會怎麼樣？

目前，函式會接受那個空字串並傳回 `" is available to borrow!"`。這並沒有什麼幫助。

在這種情況下，你可以使用 `throw` 關鍵字來丟出一個 `new Error()`，並停止函式執行。舉例來說：

```js
throw new Error("Your error message goes here");
```

在成功的 `return` 述語之前，新增一個 `if` 述語，檢查 `title` 參數是否嚴格相等於空字串（`""`）。

在 `if` 述語內，使用 `throw` 關鍵字丟出一個 `new Error()`。
將字串 `"Search field cannot be empty"` 精確地傳入 `Error` 建構式中。

**注意：** 寫完這段程式碼後，如果你點擊搜尋按鈕，螢幕上不會顯示任何東西！錯誤會停止點擊處理常式，因為目前還沒有人捕捉這個錯誤。你會在接下來的幾個步驟中修正這個問題。不過你現在可以查看主控台來確認你的程式碼是否正常運作。

# --hints--
