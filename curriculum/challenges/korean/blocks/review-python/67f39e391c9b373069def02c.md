## 파이썬이란?

- **소개**: 파이썬은 단순하고 사용하기 쉬운 범용 프로그래밍 언어로 알려져 있습니다.
- **주요 사용 사례**: 파이썬은 데이터 과학, 머신러닝, 웹 개발, 사이버보안, 임베디드 시스템 및 IoT, 스크립팅, 자동화, 그리고 Raspberry Pi나 MicroPython 호환 보드 같은 마이크로컴퓨터에 사용됩니다.

## 변수

- **변수 선언**: 변수를 선언하려면 변수 이름 다음에 대입 연산자(`=`)를 쓰고 값을 할당하세요. 값은 숫자, 문자열, 불리언 등일 수 있습니다.

- **변수 이름 규칙**: 변수 이름에 적용할 규칙은 다음과 같습니다:

  - 변수 이름은 숫자가 아닌 문자나 밑줄(`_`)로만 시작할 수 있습니다.
  - 변수 이름은 영숫자(`a-z`, `A-Z`, `0-9`)와 밑줄(`_`)만 포함할 수 있습니다.
  - 변수 이름은 대소문자를 구분합니다: `age`, `Age`, `AGE`는 모두 서로 다른 이름으로 간주됩니다.
  - 변수 이름은 `if`, `class`, `def` 같은 파이썬 예약 키워드일 수 없습니다.
  - 여러 단어로 된 변수 이름은 `snake_case`처럼 밑줄을 사용합니다.
  - 변수 이름은 `user_age`처럼 목적을 설명해야 합니다.
  - 의미를 전달하지 못하는 한 글자 변수 이름은 피하세요.

## 주석

- **한 줄 주석**: 이 주석은 코드 내 짧은 메모를 위해 사용하세요.

- **여러 줄 주석**: 여러 줄에 걸쳐 주석을 만들려면 각 줄의 시작에 `#`를 사용할 수 있습니다.

- **`print()` 함수**: 터미널에 데이터를 출력하려면 `print()` 함수를 사용하세요.

## 파이썬의 일반적인 데이터 타입

- **소개**: Python은 동적 타이핑 언어로, 변수의 데이터 타입을 선언할 필요가 없습니다. Python은 변수에 할당된 값으로 타입을 결정합니다.
- **정수**: 소수점이 없는 전체 숫자입니다.

- **부동소수점**: 소수점이 있는 숫자입니다.

- **문자열**: 따옴표로 감싼 문자들의 수열입니다.

- **불리언**: `True` 또는 `False`를 나타내는 값입니다.

Python에는 다른 데이터 타입도 있습니다. 필요할 때마다 하나씩 배우게 됩니다.

- **`type()` 함수**: 변수의 타입을 확인하려면 `type()` 함수를 사용하세요.

- **`isinstance()` 함수**: 변수가 특정 데이터 타입과 일치하는지 확인할 때 사용합니다.

## 문자열 다루기

- **정의**: 문자열은 불변(immutable)이라 생성 후 변경할 수 없습니다. Python에서는 작은따옴표나 큰따옴표를 사용할 수 있으며, 한 가지 스타일을 선택해 일관되게 사용하세요.

- **문자열에서 문자 접근하기**: 대괄호 표기법을 사용해 문자열의 문자를 접근할 수 있습니다:

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **문자열 이스케이프**: 문자열에 따옴표가 포함될 경우 역슬래시(`\`)를 사용해 이스케이프할 수 있습니다:

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **문자열 연결**: 문자열을 연결하려면 `+` 연산자를 사용하세요.

문자열을 연결하고 대입을 동시에 하려면 `+=` 연산자를 사용할 수도 있습니다.

- **`f-strings`**: 포맷된 문자열 리터럴의 줄임말로, 보간과 연결을 간결하고 읽기 쉽게 처리할 수 있습니다:

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

- **문자열 슬라이싱**: 문자열의 일부를 추출하는 방법입니다. 구문은 `str[start:stop:step]`입니다.

start는 추출을 시작할 인덱스이고, stop은 추출을 끝낼 인덱스(포함하지 않음)입니다. step은 인덱스 증가 간격을 나타냅니다.

- **문자열 길이 구하기**: 문자열의 문자 수를 반환하려면 `len()` 함수를 사용하세요.

## `in` 연산자 사용하기

## 자주 쓰이는 문자열 메서드

- **`str.upper()`**: 모든 문자를 대문자로 변환한 새 문자열을 반환합니다.

- **`str.lower()`**: 모든 문자를 소문자로 변환한 새 문자열을 반환합니다.

- **`str.strip()`**: 지정한 앞뒤 문자를 제거한 문자열 복사본을 반환합니다(인수가 없으면 앞뒤 공백을 제거).

- **`replace()`**: 문자열 내 모든 특정 문자열을 새 문자열로 교체한 결과를 반환합니다:

- **`split()`**: 지정한 구분자를 사용해 문자열을 리스트로 분할합니다. 구분자는 분할 위치를 지정하는 문자열입니다:

- **`join()`**: 여러 문자열을 구분자를 사용해 하나의 문자열로 합칠 때 사용합니다.

- **`str.startswith(prefix)`**: 문자열이 지정한 접두사로 시작하는지 여부를 불리언으로 반환합니다.

- **`str.endswith(suffix)`**: 문자열이 지정한 접미사로 끝나는지 여부를 불리언으로 반환합니다.

- **`str.find()`**: 부분 문자열이 처음 나타나는 인덱스를 반환합니다. 없으면 `-1`을 반환합니다.

- **`str.count(substring)`**: 문자열 내에 부분 문자열이 나타나는 횟수를 셉니다.

- **`str.capitalize()`**: 첫 문자는 대문자, 나머지는 소문자로 변환한 새 문자열을 반환합니다.

- **`str.isupper()`**: 문자열의 모든 문자가 대문자면 `True`, 아니면 `False`를 반환합니다.

- **`str.islower()`**: 문자열의 모든 문자가 소문자면 `True`, 아니면 `False`를 반환합니다.

- **`str.title()`**: 각 단어의 첫 글자를 대문자로 변환한 새 문자열을 반환합니다.

- **`str.maketrans()`**: 1:1 문자 매핑 테이블을 생성하는 메서드입니다. 보통 `translate()` 메서드와 함께 사용해 문자열에 적용하고 번역 결과를 반환합니다.

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc'.translate(trans_table)
print(result)  # 123123
```

## 함수 다루기

- **정의**: 함수는 입력(인수)을 받아 출력을 반환하는 재사용 가능한 코드 조각입니다. 함수를 호출하려면 함수 이름 뒤에 소괄호를 붙여 참조하세요:

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

함수가 명시적으로 값을 반환하지 않으면 기본 반환값은 `None`입니다.

매개변수에 기본값을 지정할 수도 있습니다:

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```

함수를 인수 개수에 맞게 호출하지 않으면 `TypeError`가 발생합니다.

## 파이썬의 범위

Python에는 추가적인 범위 규칙이 있습니다. 지금은 지역 범위와 전역 범위에 집중하세요.

- **지역 범위**: 함수 내부에서 생성된 변수는 그 함수 내에서만 사용할 수 있습니다. 함수 매개변수도 지역 변수입니다.

- **전역 범위**: 함수 외부에서 생성된 변수는 함수 안팎 모두에서 사용할 수 있습니다.

## 비교 연산자

- **같음 (`==`)**: 두 값이 같은지 확인합니다.

- **같지 않음 (`!=`)**: 두 값이 같지 않은지 확인합니다.

- **엄격히 큼 (`>`)**: 한 값이 다른 값보다 큰지 확인합니다.

- **엄격히 작음 (`<`)**: 한 값이 다른 값보다 작은지 확인합니다.

- **크거나 같음 (`>=`)**: 한 값이 다른 값보다 크거나 같은지 확인합니다.

- **작거나 같음 (`<=`)**: 한 값이 다른 값보다 작거나 같은지 확인합니다.

## `if`, `elif`, `else` 문장 다루기

- **`if` 문장**: 참인지 아닌지 판단하는 조건문입니다. 조건이 `True`이면 해당 코드 블록이 실행됩니다.

- **`elif` 절**: `if` 문 뒤에 오는 조건입니다. `elif` 절은 이전 조건이 모두 `False`이고 자신의 조건이 `True`일 때만 실행됩니다.

- **`else` 절**: 다른 조건이 `True`이 아닐 때 실행됩니다.

```py
age = 12

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')
else:
    print('You are a child')  # You are a child
```

조건문 안에 또 다른 `if` 문을 중첩할 수도 있습니다.

## 참 같은 값과 거짓 같은 값

- **정의**: Python에서 모든 값은 내재된 불리언 값을 가지며, 논리적 맥락에서 `True` 또는 `False`로 취급됩니다. 많은 값이 참 같은 값으로 간주되어 논리적으로 `True`로 평가되고, 거짓 같은 값은 `False`로 평가됩니다.

예로는 `None`, `False`, `0`, `0.0`, 빈 문자열 `''` 등이 있습니다.

0이 아닌 숫자나 빈 문자열이 아닌 값은 참 같은 값입니다.

## `bool()` 함수 다루기

- **정의**: 값이 참인지 거짓인지 확인하려면 내장 `bool()` 함수를 사용하세요. 이 함수는 값을 불리언으로 명시적 변환하여 참 같은 값은 `True`, 거짓 같은 값은 `False`를 반환합니다.

## 불리언 연산자와 단축 평가

- **정의**: 여러 표현식을 결합해 복잡한 조건 논리를 만드는 특수 연산자입니다. 파이썬에는 `and`, `or`, `not` 세 가지 불리언 연산자가 있습니다.
- **`and` 연산자**: 두 피연산자를 받아 첫 번째가 거짓 같으면 첫 번째를, 그렇지 않으면 두 번째를 반환합니다. 두 피연산자가 모두 참 같아야 전체 표현식이 참 같습니다.

조건문에서 `and` 연산자를 사용할 수도 있습니다.

- **`or` 연산자**: 첫 번째 피연산자가 참 같으면 그 값을 반환하고, 그렇지 않으면 두 번째 피연산자를 반환합니다. `or` 표현식은 적어도 하나가 참 같으면 참 같은 값을 반환합니다.

`and` 연산자와 마찬가지로 조건문에서 `or` 연산자를 사용할 수 있습니다.

- **단락 평가**: `and`와 `or` 연산자는 단락 평가 연산자입니다. 단락 평가는 Python이 왼쪽에서 오른쪽으로 값을 검사하며 최종 결과가 결정되면 즉시 평가를 멈춘다는 뜻입니다.
- **`not` 연산자**: 하나의 피연산자를 받아 불리언 값을 반전시킵니다. 참 같은 값은 `False`로, 거짓 같은 값은 `True`로 변환합니다. 이전 연산자들과 달리 `not`은 항상 `True` 또는 `False`를 반환합니다.

`not` 연산자도 조건문에서 사용할 수 있습니다.

## 파이썬 대화형 셸 사용하기

- **정의**: 대화형 셸은 명령어를 한 번에 하나씩 입력하고 결과를 볼 수 있는 프로그램입니다. 터미널 앱을 열고 `python`을 입력한 뒤 <kbd>Enter</kbd>를 누르세요. 그러면 Python 대화형 셸이 시작됩니다. `>>>` 기호는 Python이 명령어 입력을 기다린다는 뜻입니다. `print("Hello, world!")`를 입력해 보세요:

```bash
>>> print("Hello, world!")
Hello, world!
```

텍스트가 출력된 후 Python은 다시 `>>>` 프롬프트를 표시합니다.

이는 또 다른 명령어를 입력할 수 있음을 의미합니다.

- **읽기, 평가, 출력, 반복 주기(REPL)**: 명령어를 입력할 때마다 인터프리터가 입력을 읽고, 평가하며, 결과를 출력한 후 `>>>`를 보여주며 다시 명령어 입력을 기다립니다.

## 파이썬 리스트

- **소개**: 파이썬에서 리스트는 문자열, 숫자, 다른 리스트 등 다양한 요소로 구성된 순서 있는 수열입니다. 리스트는 변경 가능하며 0부터 시작하는 인덱스를 가집니다.

예를 들어, `cities = ['Los Angeles', 'London', 'Tokyo']`는 문자열 리스트를 만듭니다.

- **리스트 요소 접근**: `cities` 리스트에서 요소를 접근하려면 인덱스를 참조하세요. 예를 들어 `cities[0]`은 `'Los Angeles'`입니다.

- **음수 인덱스 사용**: 리스트의 마지막 요소에 접근하려면 인덱스 번호로 `-1`을 사용할 수 있습니다.

음수 인덱스는 리스트 끝에서부터 요소에 접근할 때 사용하며, 시작 인덱스는 `0`입니다.

- **`list()` 생성자 사용**: 리스트는 `list()` 생성자를 사용해 만들 수도 있습니다. `list()` 생성자는 반복 가능한 객체를 리스트로 변환합니다.

- **리스트 길이 구하기**: 리스트의 길이를 구하려면 `len()` 함수를 사용하세요.

- **리스트 변경 가능성**: 리스트는 변경 가능하므로 유효한 인덱스 번호를 사용해 요소를 업데이트할 수 있습니다. 특정 인덱스에 새 값을 할당하세요.

- **인덱스 범위 초과 오류**: 리스트 범위를 벗어난 인덱스(양수 또는 음수)를 사용하면 `IndexError`가 발생합니다.

- **리스트 요소 삭제**: `del` 키워드를 사용해 리스트에서 요소를 삭제할 수 있습니다.

- **요소 존재 여부 확인**: `in` 키워드를 사용해 리스트에 특정 요소가 있는지 확인할 수 있습니다.

- **리스트 중첩**: 리스트 안에 다른 리스트를 중첩할 수 있습니다.

- 다음 예시에서 중첩된 리스트는 인덱스 `2`에 있습니다. 리스트는 0부터 시작하는 인덱스를 가집니다.

- 중첩 리스트에서 두 번째 언어에 접근하려면 인덱스 `1`를 사용하세요:

```python
developer = ['Alice', 25, ['Python', 'Rust', 'C++']]
developer[2][1] # Rust
```

- **리스트 값 언패킹**: 리스트의 값을 새 변수에 할당하는 기법입니다. `developer` 리스트를 `name`, `age`, `job`라는 새 변수로 언패킹하는 예시는 다음과 같습니다:

```py
developer = ['Alice', 34, 'Rust Developer']
name, age, job = developer
```

- 할당 연산자 왼쪽 변수 개수가 리스트 항목 수와 맞지 않으면 `ValueError` 오류가 발생합니다.

- **나머지 항목 수집**: 리스트에서 남은 요소를 수집하려면 별표(`*`) 연산자를 사용하세요:

```py
developer = ['Alice', 34, 'Rust Developer']
name, *rest = developer
```

- **리스트 슬라이싱**: 슬라이싱은 슬라이스 연산자 `:`를 사용해 리스트의 일부를 접근하는 개념입니다. 예를 들어, `desserts = ['cake', 'pie', 'cookies', 'ice cream']`에서 `desserts[1:3]`는 `['pie', 'cookies']`를 반환합니다.

- **단계 간격**: 인덱스 사이의 증가 간격을 지정할 수도 있습니다. 예를 들어 `[1, 2, 3, 4, 5, 6][1::2]`는 `[2, 4, 6]`을 만듭니다.

## 리스트 메서드

- **append()**: 리스트 끝에 항목을 추가할 때 사용합니다. 예를 들어 `numbers.append(6)`은 `numbers` 리스트 끝에 `6`을 추가합니다.

- **리스트 연결**: `append()` 메서드를 사용해 한 리스트를 다른 리스트 끝에 추가할 수 있습니다:

```py
numbers = [1, 2, 3, 4, 5]
even_numbers = [6, 8, 10]

numbers.append(even_numbers)
print(numbers) # [1, 2, 3, 4, 5, [6, 8, 10]]
```

- **extend()**: 여러 항목을 리스트 끝에 추가합니다. `numbers` 리스트 끝에 `6`, `8`, `10` 숫자를 추가하는 예시는 다음과 같습니다:

```py
numbers = [1, 2, 3, 4, 5]
even_numbers = [6, 8, 10]

numbers.extend(even_numbers)
print(numbers) # [1, 2, 3, 4, 5, 6, 8, 10]
```

- **insert()**: 리스트의 특정 인덱스에 항목을 삽입할 때 사용합니다.

- **remove()**: 리스트에서 항목을 제거할 때 사용합니다. `remove()`는 리스트에서 첫 번째로 나타나는 해당 항목만 제거합니다.

- **pop()**: 리스트에서 특정 항목을 제거하고 반환할 때 사용합니다.

- `pop` 메서드에 인수를 지정하지 않으면 마지막 항목이 제거됩니다.

- **clear()**: 리스트의 모든 항목을 제거할 때 사용합니다.

- **sort()**: `sort()` 메서드는 리스트의 요소를 제자리에서 정렬할 때 사용합니다. 예를 들어, `numbers.sort()`는 `numbers`를 제자리에서 정렬합니다.

- **sorted()**: 원본 리스트를 변경하지 않고 새 정렬된 리스트를 반환하는 내장 함수입니다.

- **reverse()**: 리스트 요소의 순서를 뒤집을 때 사용합니다.

- **index()**: 리스트에서 특정 요소가 처음 나타나는 인덱스를 찾을 때 사용합니다.

- `index()` 메서드로 요소를 찾지 못하면 `ValueError`가 반환됩니다.

## 파이썬 튜플

- **정의**: 튜플은 순서 있는 값의 수열을 만드는 파이썬 데이터 타입입니다. 튜플은 다양한 데이터 타입을 혼합할 수 있습니다:

예를 들어, `developer = ('Alice', 34, 'Rust Developer')`는 튜플을 만듭니다.

- 튜플은 불변이므로 생성 후 요소를 변경할 수 없습니다. 요소를 변경하려 하면 `TypeError`가 발생합니다.

- **튜플 요소 접근**: 튜플에서 요소를 접근하려면 대괄호 표기법과 인덱스 번호를 사용하세요.

- 음수 인덱스를 사용해 튜플 끝에서부터 요소에 접근할 수 있습니다.

- 튜플 길이 이상 또는 같은 인덱스를 사용하면 `IndexError`가 발생합니다.

- 튜플은 `tuple()` 생성자를 사용해 만들 수도 있습니다. 생성자 안에 문자열, 리스트, 다른 튜플 같은 반복 가능한 객체를 전달할 수 있습니다:

- **튜플 내 항목 확인**: 튜플에 항목이 있는지 확인하려면 `in` 키워드를 사용하세요.

- **튜플 언패킹**: 튜플의 항목을 여러 변수에 할당할 수 있습니다. 예: `name, age, job = developer`.

- 남은 항목을 수집하려면 별표(`*`) 연산자를 사용할 수 있습니다.

- **튜플 슬라이싱**: 튜플의 일부를 추출할 수 있습니다. 예: `desserts = ('cake', 'pie', 'cookies', 'ice cream')`에서 `desserts[1:3]`은 `('pie', 'cookies')`를 반환합니다.

- **튜플에서 항목 제거**: 튜플은 불변이므로 항목을 제거하려 하면 `TypeError`가 발생합니다.

- **튜플과 리스트 중 언제 사용할까?**: 요소를 추가, 삭제, 수정하는 동적 컬렉션이 필요하면 리스트를 사용하세요. 고정되고 변경 불가능한 데이터 모음이면 튜플을 사용하세요.

## 튜플의 일반적인 메서드

- **`count()`**: 튜플에서 특정 항목이 몇 번 나타나는지 셉니다. 예: `programming_languages = ('Rust', 'Java', 'Python', 'Rust')`에서 `programming_languages.count('Rust')`는 `2`를 반환합니다.

- `count()` 메서드의 지정 항목이 튜플에 없으면 반환값은 `0`입니다.

- `count()` 메서드에 인수를 전달하지 않으면 Python은 `TypeError`를 반환합니다.

- **index()**: 튜플에서 특정 항목이 있는 인덱스를 찾습니다. 예: `programming_languages.index('Java')`는 `'Java'`의 첫 인덱스를 찾습니다.

- 지정한 항목을 찾을 수 없으면 Python은 `ValueError`를 반환합니다.

- `index()` 메서드에 선택적 시작 인덱스를 전달해 검색 시작 위치를 지정할 수 있습니다.

- `index()` 메서드에 선택적 종료 인덱스를 전달해 검색 종료 위치를 지정할 수 있습니다.

- **`sorted()`**: 반복 가능한 객체의 요소를 정렬해 새 리스트로 반환합니다. 예: `sorted(numbers)`는 새 정렬 리스트를 반환합니다.

- **정렬 동작 수정**: 선택적 `reverse`와 `key` 인수를 사용해 정렬 방식을 맞춤 설정할 수 있습니다. 예: `sorted(programming_languages, key=len)`는 문자열 길이로 정렬합니다.

- `sorted()`에 `reverse=True`를 전달하면 역순으로 정렬된 새 리스트를 만듭니다.

## Python의 반복문

- **정의**: 반복문은 코드 블록을 정해진 횟수만큼 반복 실행할 때 사용합니다.

- **`for` 루프**: 리스트, 튜플, 문자열 같은 수열을 순회하며 각 항목에 대해 코드 블록을 실행할 때 사용합니다. 다음은 `for` 루프를 사용해 리스트를 순회하며 각 언어를 콘솔에 출력하는 예입니다:

```py
programming_languages = ['Rust', 'Java', 'Python', 'C++']

for language in programming_languages:
    print(language)

"""
Result

Rust
Java
Python
C++
"""
```

- `for` 루프는 문자열 `'code'`를 순차적으로 반복하며 각 문자를 출력할 수 있습니다: `c`, `o`, `d`, `e`.

- `for` 루프는 중첩할 수 있으며, 내부 루프는 외부 루프의 각 반복마다 실행됩니다.

- **`while` 루프**: 조건이 `False`일 때까지 코드 블록을 반복 실행합니다. 다음은 추측 게임에 `while` 루프를 사용하는 예입니다:

```py
secret_number = 3
guess = 0

while guess != secret_number:
    guess = int(input('Guess the number (1-5): '))
    if guess != secret_number:
        print('Wrong! Try again.')

print('You got it!')

"""
Result

Guess the number (1-5): 2
Wrong! Try again.
Guess the number (1-5): 1
Wrong! Try again.
Guess the number (1-5): 3
You got it!
"""

```

- **`break` 와 `continue` 문**: 반복문 실행을 제어할 때 사용합니다.

- `break` 문은 특정 조건이 충족되면 즉시 루프를 종료할 때 사용합니다.

- `continue` 문은 현재 반복을 건너뛰고 다음 반복으로 넘어갈 때 사용합니다.

- `for`와 `while` 반복문 모두 `else` 절과 함께 사용할 수 있으며, 이 절은 반복문이 `break`로 종료되지 않았을 때만 실행됩니다.

## 반복문에서의 범위와 사용법

- **`range()` 함수**: `range(start, stop, step)` 구문으로 정수 수열을 생성하는 데 사용됩니다.

- 필수 `stop` 인수는 생성되는 숫자 수열의 끝 지점을 나타내는 정수이며, 포함되지 않습니다.

- `start` 인수가 지정되지 않으면 기본값은 `0`입니다. 기본적으로 정수 수열은 `1`씩 증가합니다. 선택적 `step` 인수를 사용하여 기본 증가 값을 변경할 수 있습니다. 예를 들어, `range(2, 11, 2)`는 2부터 11 미만까지(즉, 10 포함) 짝수 정수를 생성합니다.

- `range()` 함수에 인수를 전혀 전달하지 않으면 `TypeError`가 반환됩니다.

- `range()` 함수는 인수로 정수만 허용하며, 실수를 사용하면 `TypeError`가 발생합니다.

- `step` 인수에 음수를 사용하면 감소하는 정수 수열을 생성할 수 있습니다.

- `range()` 함수는 `list` 생성자와 함께 사용해 정수 리스트를 만들 수도 있습니다. `list` 생성자는 반복 가능한 객체를 리스트로 변환합니다. 예를 들어, `list(range(2, 11, 2))`는 `[2, 4, 6, 8, 10]`을 생성합니다.

## Python의 `enumerate()`와 `zip()` 함수

- **`enumerate()`**: 수열을 순회하며 각 항목의 인덱스를 추적하는 데 사용합니다. `enumerate()` 함수는 반복 가능한 객체를 인수로 받아, 각 항목의 인덱스와 값을 포함하는 `enumerate` 객체를 반환합니다.

```python
languages = ['Spanish', 'English', 'Russian', 'Chinese']

for index, language in enumerate(languages):
    print(f'Index {index} and language {language}')

# Result
# Index 0 and language Spanish
# Index 1 and language English
# Index 2 and language Russian
# Index 3 and language Chinese

```

- `enumerate()` 함수는 `for` 루프 외부에서도 사용할 수 있습니다.

- `enumerate()` 함수는 선택적 `start` 인수를 받아 카운트 시작값을 지정할 수 있습니다. 이 인수를 생략하면 카운트는 `0`부터 시작합니다.

- **`zip()`**: 여러 반복 가능한 객체를 병렬로 순회하는 데 사용합니다. 다음은 `zip()` 함수를 사용해 `developers`와 `ids`를 순회하는 예입니다:

```python
developers = ['Naomi', 'Dario', 'Jessica', 'Tom']
ids = [1, 2, 3, 4]

for name, dev_id in zip(developers, ids):
    print(f'Name: {name}')
    print(f'ID: {dev_id}')

"""
Result

Name: Naomi
ID: 1
Name: Dario
ID: 2
Name: Jessica
ID: 3
Name: Tom
ID: 4
"""

```

## Python의 리스트 내포

- **정의**: 리스트 내포는 대괄호 안에 반복문과 조건을 직접 결합해 한 줄로 새 리스트를 만드는 방법입니다. 코드를 더 짧고 읽기 쉽게 만듭니다.

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

## 반복 가능한 객체 함수

- **`filter()`**: 조건에 따라 반복 가능한 객체에서 요소를 필터링하는 데 사용됩니다. 조건을 만족하는 요소만 포함하는 이터레이터를 반환합니다. 예를 들어, 네 글자 이상인 단어를 선택하는 필터 조건이 있습니다.

- **`map()`**: 반복 가능한 객체의 각 항목에 함수를 적용하고 결과를 포함하는 새 반복 가능한 객체를 반환합니다. 예를 들어, 리스트의 섭씨 온도를 화씨로 변환하는 함수가 있습니다.

- **`sum()`**: 리스트나 튜플 같은 반복 가능한 객체의 합을 구하는 데 사용됩니다.

- 선택적 `start` 인수를 전달해 합산의 초기값을 설정할 수 있습니다. 예를 들어, `sum([5, 10, 15, 20], 10)`은 `60`을 반환합니다.

- `start`를 키워드 인수로도 사용할 수 있습니다. 예: `sum([5, 10, 15, 20], start=10)`.

## 람다 함수

- **정의**: 파이썬의 람다 함수는 이름 없는 함수(익명 함수)를 간결하게 만드는 방법입니다.
- 람다 함수는 종종 다른 함수의 인수로 사용됩니다. 다음은 람다 함수의 예입니다:

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

- 람다 함수 사용 모범 사례는 변수에 할당하지 않고, 간단하고 읽기 쉽게 유지하며, 짧고 일회성 함수에 사용하는 것입니다.

## 딕셔너리

- **사전(Dictionaries)**: 사전은 키-값 쌍을 저장하는 내장 자료 구조입니다. 키는 불변 데이터 타입이어야 합니다. 일반 구문은 `dictionary = {key1: value1, key2: value2}`입니다.

- **`dict()` 생성자**: `dict()` 생성자는 딕셔너리를 만드는 또 다른 방법입니다. `dict()` 생성자에 튜플 리스트를 인수로 전달하세요. 각 튜플은 첫 번째 요소가 키, 두 번째 요소가 값입니다.

- **대괄호 표기법**: 키-값 쌍의 값을 접근할 때 대괄호 표기법을 사용할 수 있습니다.

## 딕셔너리의 일반적인 메서드

- **`get()` 메서드**: `get()` 메서드는 키에 연결된 값을 가져옵니다. 대괄호 표기법과 비슷하지만, 키가 없을 때 오류를 방지하기 위해 기본값을 설정할 수 있습니다. 구문은 `dictionary.get(key, default)`입니다.

- **`keys()` 와 `values()` 메서드**: `keys()` 와 `values()` 메서드는 각각 딕셔너리의 모든 키와 값을 포함하는 뷰 객체를 반환합니다. 뷰 객체는 딕셔너리 내용을 별도의 복사본 없이 볼 수 있는 방법입니다.

- **`items()` 메서드**: `items()` 메서드는 딕셔너리의 모든 키-값 쌍을 포함하는 뷰 객체를 반환합니다.

- **`clear()` 메서드**: `clear()` 메서드는 딕셔너리의 모든 키-값 쌍을 제거합니다.

- **`pop()` 메서드**: `pop()` 메서드는 첫 번째 인수로 지정한 키-값 쌍을 제거하고 그 값을 반환합니다. 키가 없으면 두 번째 인수로 지정한 기본값을 반환합니다. 기본값이 없으면 `KeyError`가 발생합니다.

- **`popitem()` 메서드**: Python 3.7 이상에서 `popitem()` 메서드는 마지막에 삽입된 항목을 제거합니다.

- **`update()` 메서드**: `update()` 메서드는 다른 딕셔너리의 키-값 쌍으로 현재 딕셔너리를 업데이트합니다. 공통 키가 있으면 값이 덮어쓰이고, 새 키는 새 키-값 쌍으로 추가됩니다.

## 딕셔너리 순회

- **값 순회**: 딕셔너리의 값을 순회하려면 `for` 루프와 `values()`를 사용해 딕셔너리의 모든 값을 얻을 수 있습니다.

```python
products = {
    'Laptop': 990,
    'Smartphone': 600,
    'Tablet': 250,
    'Headphones': 70,
}

for price in products.values():
    print(price)
```

- **키 순회**: 위 `products` 딕셔너리의 키를 순회하려면 `products.keys()` 또는 `products`를 직접 작성할 수 있습니다.

- **키-값 쌍 순회**: 키와 해당 값을 동시에 순회하려면 `products.items()`를 순회할 수 있습니다. 각 키와 값이 포함된 튜플을 개별적으로 얻습니다.

키와 값을 별도의 반복 변수에 저장하려면 쉼표로 구분해야 합니다. 첫 번째 변수는 키를, 두 번째 변수는 값을 저장합니다.

```python
for product, price in products.items():
    print(product, price)
```

- **`enumerate()` 함수**: 카운터를 추적하며 딕셔너리를 순회하려면 `enumerate()` 함수를 호출할 수 있습니다. 이 함수는 각 항목에 정수를 할당하는 `enumerate` 객체를 반환합니다. 카운터는 기본적으로 0부터 시작하지만 원하는 숫자부터 시작할 수 있습니다.

`enumerate()`를 사용할 때 인덱스와 항목을 별도의 루프 변수에 할당하는 것이 일반적입니다. 예를 들어, `for index, (product, price) in enumerate(products.items()):`는 카운터와 각 키-값 쌍을 분해합니다.

카운트의 초기값을 맞춤 설정하려면 `enumerate()`에 두 번째 인수를 전달할 수 있습니다. 예를 들어, `enumerate(products.items(), 1)`은 카운트를 1부터 시작합니다.

## 집합

- **집합**: 집합은 중복 값을 허용하지 않는 Python 내장 자료 구조입니다. 집합은 변경 가능하고 순서가 없으므로 인덱스나 키로 접근할 수 없습니다. 또한 집합은 숫자, 문자열, 튜플 같은 변경 불가능한 데이터 타입만 포함할 수 있습니다.

- **집합 정의**: 집합을 정의하려면 중괄호 안에 요소를 작성하고 쉼표로 구분합니다.

예를 들어, `numbers = {1, 2, 3, 4}`.

- **빈 집합 정의**: 빈 집합을 정의하려면 `set()` 함수를 사용해야 합니다. 빈 중괄호만 쓰면 자동으로 딕셔너리가 생성됩니다.

## 집합의 일반적인 메서드

- **`add()` 메서드**: `add()` 메서드를 사용해 집합에 요소를 추가할 수 있으며, 새 요소를 인수로 전달합니다.

- **`remove()` 와 `discard()` 메서드**: 집합에서 요소를 제거하려면 `remove()` 또는 `discard()` 메서드를 사용할 수 있으며, 제거할 요소를 인수로 전달합니다. `remove()` 메서드는 요소가 없으면 `KeyError`를 발생시키지만 `discard()` 메서드는 발생시키지 않습니다.

- **`clear()` 메서드**: `clear()` 메서드는 집합의 모든 요소를 제거합니다.

## 집합의 수학적 연산

- **`issubset()` 와 `issuperset()` 메서드**: `issubset()` 과 `issuperset()` 메서드는 각각 집합이 다른 집합의 부분집합인지 또는 상위집합인지 확인합니다.

- **`isdisjoint()` 메서드**: `isdisjoint()` 메서드는 두 집합이 공통 요소가 없으면 참을 반환합니다.

- **합집합 연산자 (`|`)**: 합집합 연산자 `|`는 두 집합의 모든 요소를 포함하는 새 집합을 반환합니다.

- **교집합 연산자 (`&`)**: 교집합 연산자 `&`는 두 집합에 공통으로 있는 요소만 포함하는 새 집합을 반환합니다.

- **차집합 연산자 (`-`)**: 차집합 연산자 `-`는 첫 번째 집합에만 있고 두 번째 집합에는 없는 요소를 포함하는 새 집합을 반환합니다.

- **대칭 차집합 연산자 (`^`)**: 대칭 차집합 연산자 `^`는 첫 번째 또는 두 번째 집합 중 하나에만 있는 요소를 포함하는 새 집합을 반환합니다.

- **`in` 연산자**: 요소가 집합에 포함되어 있는지 여부는 `in` 연산자를 사용하여 확인할 수 있습니다.

## Python 표준 라이브러리

- **Python 표준 라이브러리**: 함수, 클래스, 자료 구조 같은 미리 작성된 재사용 가능한 코드를 제공하는 라이브러리입니다. Python은 많은 문제와 작업에 표준화된 솔루션을 구현한 내장 모듈이 포함된 광범위한 표준 라이브러리를 제공합니다. 인기 있는 내장 모듈 예로 `math`, `random`, `re` (정규 표현식의 약자), `datetime` 등이 있습니다.

## import 문

- **import 문**: 내장 모듈에 정의된 요소에 접근하려면 import 문을 사용합니다. import 문은 일반적으로 파일 상단에 작성합니다. 함수, 클래스, 상수, 변수 등 모듈에 정의된 모든 요소에 대해 import 문은 동일하게 작동합니다.

- **기본 가져오기 구문**: `import` 키워드 다음에 모듈 이름을 사용합니다.

그런 다음 해당 모듈의 함수를 호출하려면 점 표기법을 사용해 모듈 이름 뒤에 함수 이름을 붙입니다.

예를 들어, `import math` 후에 `math.sqrt(36)`은 36의 제곱근을 반환합니다.

- **별칭으로 모듈 import**: 모듈 이름이 길거나 이름 충돌을 피하려면 import 문 끝에 `as` 뒤에 별칭을 지정할 수 있습니다.

예를 들어, `import math as m`는 `math` 모듈에 별칭 `m`을 할당합니다.

그런 다음 `m.sqrt(36)`처럼 별칭을 사용해 모듈의 요소에 접근할 수 있습니다.

- **특정 요소 import**: 모듈 전체가 필요 없으면 `from`를 사용해 특정 요소만 import할 수 있습니다. 이 경우 import 문은 `from`로 시작하고 모듈 이름, `import` 키워드, import할 요소 이름 순입니다.

예를 들어, `from math import sqrt, sin, cos`.

그다음 파이썬 스크립트에서 모듈 접두사 없이 이 이름들을 바로 사용할 수 있습니다.

이 방법은 편리하지만, 이미 같은 이름의 함수나 변수가 있으면 이름 충돌이 발생할 수 있으니 주의하세요.

별칭을 지정하려면 `as` 키워드 뒤에 별칭을 작성하면 됩니다.

예를 들어, `from math import sqrt as square_root`.

- **별표(*)를 사용한 import (`*`)**: 별표는 해당 모듈의 모든 것을 import하지만 모듈 이름을 접두사로 사용하지 않아도 된다는 뜻입니다.

예를 들어, `from math import *` 후에는 `math` 접두사 없이 `sqrt(36)`을 호출할 수 있습니다.

하지만 일반적으로 권장하지 않습니다. 네임스페이스 충돌이 발생하고 이름 출처를 알기 어려워질 수 있기 때문입니다.

## `if __name__ == '__main__'`

- **`__name__` 변수**: `__name__`는 Python의 특별한 내장 변수입니다. Python 파일을 직접 실행하면 이 변수의 값은 문자열 `"__main__"`로 설정됩니다. 하지만 Python 파일이 다른 스크립트에 모듈로 import되면 `__name__` 변수의 값은 그 모듈 이름으로 설정됩니다.

이 때문에 Python 스크립트에서 이 조건문을 자주 볼 수 있습니다. 이 조건문 안에는 Python 스크립트가 메인 프로그램으로 실행될 때만 실행하고 싶은 코드가 들어 있습니다.

```python
if __name__ == '__main__':
    # Code
```

## Python의 일반적인 오류

- **SyntaxError**: 코드가 구문 규칙을 따르지 않을 때 Python이 발생시키는 오류입니다. 예를 들어, `print("Hello there"` 코드는 닫는 괄호가 없어서 `SyntaxError: '(' was never closed` 메시지와 함께 구문 오류가 발생합니다.
- **NameError**: Python이 정의되지 않은 변수나 함수에 접근하려고 할 때 `NameError`를 발생시킵니다. 예를 들어, `print(username)` 코드에서 `username` 변수가 정의되지 않았다면 `NameError: name 'username' is not defined` 메시지와 함께 이름 오류가 발생합니다.
- **TypeError**: 호환되지 않는 데이터 타입끼리 연산을 수행할 때 Python이 발생시키는 오류입니다. 예를 들어, 문자열과 숫자를 더하려 하면 `TypeError: can only concatenate str (not "int") to str` 오류가 발생합니다.
- **IndexError**: 리스트나 튜플, 문자열 같은 시퀀스에서 존재하지 않는 인덱스를 접근하면 `IndexError`가 발생합니다. 예를 들어, `Hello world` 문자열에서 마지막 문자의 인덱스는 `10`입니다. 이 인덱스를 벗어나 `greet = "hello world"; print(greet[11])`처럼 접근하면 `IndexError: string index out of range` 메시지와 함께 오류가 발생합니다.
- **AttributeError**: 객체에 없는 메서드나 속성을 사용하려 할 때 Python이 발생시키는 오류입니다. 예를 들어, `"hello".append("!")` 같은 문자열에 `.append()`를 호출하면 `AttributeError: 'str' object has no attribute 'append'` 메시지와 함께 오류가 발생합니다.

## 예외 처리

- **`try...except`**: 예외가 발생할 수 있는 코드 블록을 실행하는 데 사용됩니다. `try` 블록은 오류가 발생할 것으로 예상되는 부분이고, `except` 블록은 지정된 예외가 발생하면 실행됩니다.

  여러 `except` 블록을 연결해 다양한 예외를 처리할 수도 있습니다:

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

- **`else` 와 `finally`**: 이 블록들은 `try...except`를 확장합니다. 예외가 없으면 `else` 블록이 실행되고, `finally` 블록은 오류 여부와 상관없이 항상 실행됩니다.

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **예외 객체**: 예외 자체에 접근해 디버깅과 직접적인 오류 메시지 출력을 할 수 있습니다. 예외 객체에 접근하려면 `as` 키워드를 사용합니다. 예:

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **`raise` 문**: 특정 조건이 충족될 때 수동으로 예외를 발생시키는 데 사용됩니다. 예: `raise ValueError("Invalid value")`.

## 예외 신호 보내기

  `raise` 문은 사용자 정의 메시지와 함께 사용자 정의 예외도 발생시킬 수 있습니다. `Exception`을 상속하는 클래스를 만들어 사용자 정의 예외를 정의합니다.

  사용자 정의 예외는 해당 예외 클래스를 명시한 `except` 블록으로 처리합니다.

  `raise` 문은 `from` 키워드와 함께 사용해 예외를 연결할 수 있으며, 서로 다른 오류 간의 관계를 보여줍니다:

  ```py
  def parse_config(filename):
    try:
        with open(filename, 'r') as file:
            data = file.read()
            return int(data)
    except FileNotFoundError:
        raise ValueError('Configuration file is missing') from None
    except ValueError as e:
        raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```

## Python 클래스와 객체

- **클래스 정의**: 클래스는 객체를 생성하기 위한 청사진입니다. 객체가 가질 속성과 메서드를 통해 객체의 동작을 정의합니다. 다음은 Python에서 클래스 정의의 기본 예시입니다:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **객체 생성**: 객체는 클래스의 인스턴스입니다. 필요한 인수를 사용해 클래스를 호출하여 생성합니다.

- **객체에서 메서드 호출**: 객체에서 메서드를 호출해 동작을 수행하거나 정보를 가져올 수 있습니다.

- **클래스와 객체의 차이**: 클래스는 재사용 가능한 템플릿이고, 객체는 실제 데이터를 가진 클래스의 특정 인스턴스입니다.

## 속성

- **인스턴스 속성**: `__init__()`에서 `self`를 사용해 정의하며, 각 객체마다 고유합니다.
- **클래스 속성**: 클래스 내부에 직접 정의되며 모든 인스턴스가 공유합니다.

## 메서드

- **메서드**: 클래스 내부에 정의된 함수로, 객체의 속성에 작용합니다.

- **메서드 접근**: 객체의 메서드는 점 표기법으로 호출합니다. 예를 들어, `dog = Dog('Jack', 3)`에서 `dog.bark()`는 `dog` 객체의 `bark` 메서드를 호출합니다.

## 더블 언더스코어(매직) 메서드

- **정의**: 앞뒤에 이중 밑줄이 붙은 특별한 메서드(e.g., `__init__`, `__len__`, `__str__`, `__eq__`)입니다. Python은 내장 연산을 위해 내부적으로 사용합니다.

- **더블 언더스코어 메서드 간접 호출**: 직접 호출할 필요 없이, 특정 동작이 발생할 때 Python이 자동으로 호출합니다. 이 동작에는 다음이 포함됩니다:

  - **덧셈, 뺄셈, 곱셈, 나눗셈 등 산술 연산**. 덧셈에는 `__add__()`, 뺄셈에는 `__sub__()`, 곱셈에는 `__mul__()`, 나눗셈에는 `__truediv__()`이 호출됩니다.

  - **문자열 연결, 반복, 포맷팅, 텍스트 변환 등 문자열 연산**. 연결에는 `__add__()`, 반복에는 `__mul__()`, 포맷팅에는 `__format__()`, 텍스트 변환에는 `__str__()`와 `__repr__()` 등이 호출됩니다.

  - **동등성, 작음, 큼 등 비교 연산**. 동등성 검사에는 `__eq__()`, 작음에는 `__lt__()`, 큼에는 `__gt__()` 등이 호출됩니다.

  - **객체를 반복 가능하게 만들고 항목을 순차적으로 처리하는 반복 작업**. `__iter__()`는 반복자를 반환하기 위해 호출되고 `__next__()`는 다음 항목을 가져오기 위해 호출됩니다.

## 실제 예시: 쇼핑 카트

- **더블 언더스코어 메서드를 가진 카트 클래스**: 내장 동작으로 항목 추가, 삭제, 반복, 내용 확인을 할 수 있습니다.

## 객체지향 프로그래밍이란?

- **객체지향 프로그래밍**: 개발자가 코드 내 모든 것을 실제 세계의 객체처럼 다루는 프로그래밍 스타일입니다. 흔히 OOP라고 부릅니다. 코드를 효과적으로 조직하고 관리하는 데 도움이 되는 네 가지 핵심 원칙은 **캡슐화**, **상속**, **다형성**, **추상화**입니다.
- **클래스**: 객체를 생성하는 청사진입니다. 클래스에서 생성된 모든 객체는 데이터를 정의하는 속성과 객체의 동작을 결정하는 메서드를 가집니다.

## 캡슐화란?

- **캡슐화**: 객체의 속성과 메서드를 하나의 단위로 묶는 것입니다. 객체의 내부 상태를 공개 메서드와 속성이라는 문처럼 숨길 수 있습니다. 그 문 뒤에는 데이터 변경과 접근을 제어하는 비공개 속성과 메서드가 있습니다.
- **캡슐화 예시**: 지갑 잔액을 추적하려면 입금과 출금은 허용하지만, 잔액 자체를 임의로 변경하지 못하게 합니다.

- **단일 밑줄과 이중 밑줄 접두사의 차이**: 단일 밑줄 접두사는 내부 용도임을 나타내는 관례이며 외부 접근을 막지 않습니다. 이중 밑줄 접두사는 클래스 외부에서 접근하지 못하도록 효과적으로 막습니다.

## 게터와 세터란?

- **게터와 세터**: 클래스 속성에 접근하고 수정하는 방식을 제어하는 메서드입니다. 게터로 값을 가져오고 세터로 값을 설정합니다.
- **프로퍼티**: 게터와 세터를 연결해 데이터를 접근할 수 있게 하며, 값을 가져오거나 설정하거나 삭제할 때 추가 로직을 실행합니다.
- **메서드 대신 프로퍼티를 사용하는 이유**: 프로퍼티는 가독성과 코드 정리를 위해 사용합니다. 일반 속성처럼 점 표기법으로 괄호 없이 접근할 수 있습니다.
- **게터 생성**: `@property` 데코레이터를 사용해 게터를 만듭니다. 아래 예제의 `radius` 게터는 내부 `_radius` 값을 반환합니다.

- **세터 생성**: 반지름을 설정하는 세터를 만들려면 같은 이름의 메서드를 정의하고 위에 `@<property_name>.setter`를 붙입니다:

```py
class Circle:
    def __init__(self, radius):
        self.radius = radius # Calling the setter

    @property
    def radius(self):  # A getter to get the radius
        return self._radius

    @radius.setter
    def radius(self, value):  # A setter to set the radius
        if value <= 0:
            raise ValueError('Radius must be positive')
        self._radius = value

my_circle = Circle(3)
print('Initial radius:', my_circle.radius) # Initial radius: 3

my_circle.radius = 8
print('After modifying the radius:', my_circle.radius) # After modifying the radius: 8
```

- **파이썬의 게터와 세터 처리 방식**: 게터와 세터를 정의하면, 일반 속성 문법을 사용할 때 자동으로 호출됩니다. `my_circle.radius`를 읽으면 게터가 호출되고, `my_circle.radius = 4`로 할당하면 세터가 호출됩니다.

세터 내부에서 프로퍼티 이름에 직접 할당하면 `RecursionError`가 발생하므로 피해야 합니다.

- **딜리터**: 세터와 게터로 값을 설정하고 가져온 후, `deleter`를 사용해 삭제 방식을 제어할 수 있습니다. 딜리터는 프로퍼티에 `del` 문을 사용할 때 사용자 정의 로직을 실행합니다. 딜리터를 만들려면 `@<property_name>.deleter` 데코레이터를 사용합니다.

## 상속이란 무엇이며 코드 재사용에 어떻게 도움이 되나요?

- **상속**: 자식 클래스가 부모 클래스의 속성과 메서드를 사용하는 과정입니다. 상속은 코드 재사용을 촉진하고 명확한 계층 구조를 제공하며, 모든 것을 다시 작성하지 않고 동작을 맞춤화할 수 있게 합니다. 상속을 구현하려면 자식 클래스가 부모 클래스 이름을 받습니다:

예를 들어, `class Child(Parent):`는 자식 클래스 정의를 시작합니다.

- **단일 상속과 다중 상속**: 자식 클래스가 단일 부모로부터 속성과 메서드를 상속받으면 **단일 상속**이라 하고, 둘 이상의 부모로부터 상속받으면 **다중 상속**이라 합니다.

예를 들어, `class Child(Parent1, Parent2):`는 두 부모 클래스로부터 상속받습니다.

- **`super()` 함수**: 클래스가 메서드를 다르게 구현하거나 확장할 때, 부모 클래스의 메서드를 중복 없이 **호출**할 수 있게 해주는 함수입니다.

## 다형성이란 무엇이며 코드 재사용에 어떻게 도움이 되나요?

- **다형성**: OOP 원칙으로, 서로 다른 클래스가 같은 메서드 이름을 사용하지만 호출 시 각 클래스가 다르게 구현하는 것을 말합니다.

- **상속 기반 다형성**: 부모가 메서드를 정의하고, 각 자식 클래스가 이를 자신에게 맞게 변형합니다.

## 이름 맹글링이란 무엇이며 어떻게 작동하나요?

- **이름 맹글링(Name Mangling)**: 파이썬이 내부적으로 이중 밑줄로 시작하는 속성 이름에 클래스 이름과 밑줄을 접두사로 붙여 `__attribute`를 `_ClassName__attribute`로 바꾸는 과정입니다.
- **이름 맹글링 목적**: 상속 시 속성과 메서드가 우연히 덮어쓰이는 것을 방지하기 위함입니다.

## 추상이란 무엇이며 복잡한 시스템을 어떻게 정리하나요?

- **추상화**: 객체나 시스템의 복잡한 구현 세부사항을 숨기고 필수 기능만 보여주는 프로그래밍 개념입니다. Python과 다른 언어에서 추상화는 재사용성을 높여 복잡한 시스템을 단순화합니다.
- **추상화 예시**: 자동차를 운전할 때 엔진이나 브레이크 작동 방식을 몰라도 핸들, 페달, 변속기만 사용하면 되는 것이 좋은 예입니다.
- **Python의 추상화 구현**: Python은 `abc` 모듈을 통해 추상화를 구현합니다. 이 모듈은 `ABC` 클래스(추상 기본 클래스)와 `@abstractmethod` 데코레이터를 제공합니다. 추상 기본 클래스(ABC)는 서브클래스가 반드시 구현해야 하는 공통 메서드와 속성을 정의하며, 인스턴스화할 수 없습니다.
- **추상 메서드 정의 방법**: `@abstractmethod`로 정의하며, 기본 구현이 있어도 서브클래스에서 반드시 재정의해야 합니다. 추상의 기본 문법은 다음과 같습니다:

```py
from abc import ABC, abstractmethod

# Define an abstract base class
class AbstractClass(ABC):
    @abstractmethod
    def abstract_method(self):
        pass

# Concrete subclass that implements the abstract method
class ConcreteClassOne(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassOne')

# Another concrete subclass
class ConcreteClassTwo(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassTwo')
```

## 알고리즘과 빅오 표기법

- **알고리즘**: 문제 해결이나 작업 수행을 위한 명확한 지침 집합입니다. 알고리즘은 유한한 단계 내에 끝나야 하며 각 단계는 정확하고 명확해야 합니다.

- **빅오 표기법**: 입력 크기가 커질 때 알고리즘의 최악 성능 또는 성장률을 나타냅니다. 상수 요소와 낮은 차수 항은 무시하고 입력 크기에 따른 자원 사용 증가에 집중합니다.

### 일반적인 시간 복잡도

- **O(1) - 상수 시간**: 입력 크기와 상관없이 일정한 시간이 걸립니다.

- **O(log n) - 로그 시간**: 입력이 커져도 시간이 천천히 증가합니다. 문제 크기를 반복해서 일정 비율로 줄이는 알고리즘(예: 이진 탐색)에 흔합니다.

- **O(n) - 선형 시간**: 실행 시간이 입력 크기에 비례해 증가합니다.

- **O(n log n) - 로그 선형 시간**: 병합 정렬, 퀵 정렬 같은 효율적인 정렬 알고리즘의 일반적인 시간 복잡도입니다.

- **O(n²) - 이차 시간**: 실행 시간이 제곱에 비례해 증가합니다. 중첩 반복문에서 자주 나타납니다.

### 공간 복잡도

- **O(1) - 상수 공간**: 입력 크기와 상관없이 일정한 메모리를 사용합니다.
- **O(n) - 선형 공간**: 메모리 사용량이 입력 크기에 비례해 증가합니다.
- **O(n²) - 이차 공간**: 메모리 사용량이 제곱에 비례해 증가합니다.

## 문제 해결 기법

- **문제 이해하기**: 문제 설명을 여러 번 읽고, 입력, 예상 출력, 입력을 출력으로 변환하는 방법을 파악하세요.

- **의사 코드**: 언어에 독립적인 알고리즘 논리의 고수준 설명입니다. `IF`, `ELSE`, `FOR`, `WHILE` 같은 프로그래밍 구성 요소와 일반 문자를 혼합해 사용합니다.

- **경계 사례**: 알고리즘이 처리해야 하는 경계에 위치한 특정 유효 입력입니다. 항상 경계 사례를 고려하고 테스트하세요.

## 배열

- **정적 배열**: 초기화 시 크기가 고정됩니다. 요소는 인접한 메모리 위치에 저장되며, 실행 중 크기를 변경할 수 없습니다.

- **동적 배열**: 실행 중 자동으로 크기가 커지거나 작아질 수 있습니다. 필요 시 더 큰 배열로 자동 복사해 크기를 조절합니다.

### Python 리스트(동적 배열)

파이썬 리스트는 동적 배열입니다. 인덱스로 요소에 접근하고 업데이트할 수 있으며, `append()`나 `insert()`로 요소를 추가하고, `pop()`이나 `remove()`로 요소를 제거할 수 있습니다.

### 동적 배열의 시간 복잡도

- **접근**: O(1)
- **끝에 삽입**: 평균 O(1), 크기 조정 시 O(n)
- **중간에 삽입**: O(n)
- **삭제**: 중간 O(n), 끝 O(1)

## 스택

- **스택**: 후입선출(LIFO) 자료 구조입니다. 요소는 오직 맨 위에서 추가되고 제거됩니다.

- **푸시 연산**: 스택 맨 위에 요소를 추가합니다. 시간 복잡도: O(1).

- **팝 연산**: 스택 맨 위에서 요소를 제거합니다. 시간 복잡도: O(1).

파이썬 리스트는 `append()`로 요소를 추가하고 `pop()`으로 마지막 요소를 제거해 스택으로 사용할 수 있습니다.

## 큐

- **큐**: 선입선출(FIFO) 자료 구조입니다. 요소는 뒤에서 추가되고 앞에서 제거됩니다.

- **인큐 연산**: 큐 뒤에 요소를 추가합니다. 시간 복잡도: O(1).

- **디큐 연산**: 큐 앞에서 요소를 제거합니다. 시간 복잡도: O(1).

`collections` 모듈의 `deque`는 `append()`로 요소를 추가하고 `popleft()`로 요소를 제거해 큐로 사용할 수 있습니다.

## 연결 리스트

- **연결 리스트**: 각 노드가 데이터와 다음 노드에 대한 참조를 가지는 선형 자료 구조입니다. 노드들이 체인처럼 연결되어 있습니다.

### 단일 연결 리스트

- **구조**: 각 노드는 데이터와 다음 노드에 대한 하나의 참조를 가집니다.
- **순회**: 헤드에서 꼬리 방향으로만 이동할 수 있습니다.
- **헤드 노드**: 리스트의 첫 번째 노드로, 보통 유일하게 직접 접근 가능한 노드입니다.
- **꼬리 노드**: 리스트의 마지막 노드로, `None`를 가리킵니다.

### 연산과 시간 복잡도

- **처음에 삽입**: O(1)
- **끝에 삽입**: O(n) - 끝까지 순회해야 함
- **중간에 삽입**: O(n) - 위치까지 순회해야 함
- **처음에서 삭제**: O(1)
- **끝에서 삭제**: O(n) - 이전 노드를 찾기 위해 순회해야 함
- **중간에서 삭제**: O(n) - 노드를 찾기 위해 순회해야 함

### 이중 연결 리스트

- **구조**: 각 노드는 데이터와 두 개의 참조(다음 노드, 이전 노드)를 가집니다.
- **순회**: 양방향으로 이동할 수 있습니다.
- **메모리**: 추가 참조 때문에 단일 연결 리스트보다 더 많은 메모리를 사용합니다.

## 해시 맵과 세트

### 맵과 해시 맵

- **맵(추상 자료형)**: 키-값 쌍을 관리합니다. 모든 키는 고유해야 하지만 값은 중복될 수 있습니다.

- **해시 맵**: 해싱 기법을 사용해 맵 ADT를 구체적으로 구현한 것입니다. 해시 함수로 키의 해시 값을 생성해 기본 배열 내 저장 위치를 결정합니다.

### Python 딕셔너리(해시 맵)

파이썬 사전은 해시 맵을 구현합니다. 키로 값을 접근, 업데이트, 삭제하고, `in`으로 키 존재 여부를 확인합니다.

### 해시 맵의 시간 복잡도

- **평균 경우**: 삽입, 조회, 삭제 모두 O(1)
- **최악 경우**: 해시 충돌이 많으면 O(n)

### 세트

- **세트**: 중복 없는 고유 요소의 무순서 집합입니다. 중복 허용하지 않고 특정 순서도 유지하지 않습니다.

- **불변 요소만 허용**: 해시 값이 변하지 않아야 하므로 숫자, 문자열, 튜플 같은 불변 데이터 타입만 포함할 수 있습니다.

### 세트의 시간 복잡도

- **평균 경우**: 추가, 제거, 멤버십 테스트 모두 O(1)
- **최악 경우**: 해시 충돌로 인해 O(n)

## 해시 충돌

- **해시 충돌**: 서로 다른 두 키가 같은 해시 값을 생성할 때 발생합니다.

- **충돌 해결 전략**:
  - **체이닝**: 각 배열 인덱스가 같은 해시 값을 가진 모든 요소를 저장하는 연결 리스트를 가리킵니다.
  - **오픈 어드레싱**: 미리 정의된 순서에 따라 다음 사용 가능한 인덱스를 찾습니다.

## 각 자료 구조 사용 시기

- **리스트**: 순서가 있고 인덱스로 접근해야 하며 크기를 미리 모를 때
- **스택**: LIFO 연산(실행 취소, 표현식 평가, 백트래킹)에 사용
- **큐**: FIFO 연산(작업 스케줄링, 너비 우선 탐색)에 사용
- **연결 리스트**: 빈번한 처음 삽입/삭제, 크기 미정, 임의 접근 불필요할 때
- **해시 맵**: 빠른 키-값 조회, 발생 횟수 세기, 캐싱에 사용
- **세트**: 중복 검사, 수학적 집합 연산, 중복 제거에 사용

## 재귀

- 재귀는 기본 사례에 도달할 때까지 함수를 반복해서 호출할 수 있게 하는 프로그래밍 개념입니다.

다음은 숫자의 팩토리얼을 계산하는 재귀 함수 예시입니다:

```py
def find_factorial(n):
    if n == 0:
        return 1
    return n * find_factorial(n - 1)
```

위 예제에서 `find_factorial` 함수는 `n`이 `0`에 도달할 때까지 재귀적으로 호출됩니다. `n`이 `0`이면 기본 사례에 도달하여 함수가 `1`을 반환합니다. 그런 다음 함수는 `n`과 `find_factorial(n - 1)`의 재귀 호출 결과의 곱을 반환합니다.

- 재귀는 깊이가 알 수 없는, 예를 들어 깊게 중첩된 딕셔너리와 리스트 또는 파일 트리 같은 것을 처리할 수 있게 합니다.
- 재귀 함수의 함수 호출을 추적하기 위해 호출 스택이 사용됩니다. 함수가 호출될 때마다 호출 스택에 추가됩니다. 기본 사례에 도달하면 함수 호출이 스택에서 제거됩니다.
- 기본 사례를 신중하게 정의해야 합니다. 그렇지 않으면 함수가 계속 자신을 호출하여 Python이 `RecursionError`를 발생시킬 수 있습니다.
- 재귀는 팩토리얼과 피보나치 같은 수학 문제 해결, 트리와 그래프 탐색, 순열과 조합 생성에 유용합니다.

## 검색 알고리즘

검색 알고리즘은 특정 항목 목록 내에서 목표를 검색할 수 있게 합니다.

컴퓨터 과학에서 알아야 할 검색 알고리즘은 두 가지가 있습니다. 바로 **선형 검색**과 **이진 검색** 알고리즘입니다. 두 알고리즘의 차이점과 각각 언제 사용하는지 이해하는 것이 중요합니다.

### 선형 검색

- 선형 검색은 목록의 처음부터 끝까지 각 항목을 반복하며 목표 항목을 찾습니다.
- 목표 항목을 찾으면 목록에서 위치한 인덱스를 반환합니다.
- 목표를 찾지 못하면 `-1`를 반환하는데, 이는 대부분 프로그래밍 언어에서 **유효하지 않은 인덱스**를 의미합니다.
- 선형 검색은 목표를 찾을 때까지 각 항목을 확인하기 때문에, 항목이 많은 목록에서는 효율적이지 않습니다.
- 선형 검색의 시간 복잡도는 `O(n)`인데, 목록 크기에 따라 검색 시간이 선형적으로 증가하기 때문입니다.
- 선형 검색의 공간 복잡도는 `O(1)`인데, 목록을 검색하는 데 추가 공간이 필요하지 않기 때문입니다.

### 이진 검색

- 이진 검색은 목록을 반으로 나누고, 목표 값이 목록 중간에 있는지 확인하는 방식으로 작동합니다.
- 이진 검색이 작동하려면 목록의 항목들이 오름차순 또는 내림차순으로 정렬되어 있어야 합니다.
- 이진 검색은 목록을 반으로 나누고 목표가 없는 절반은 무시하기 때문에, 많은 항목이 있는 목록을 검색할 때 더 효율적인 알고리즘입니다.
- 목표 항목이 목록 중간에 있으면 해당 항목의 인덱스를 반환합니다.
- 항목을 찾지 못하면 알고리즘은 목표 항목이 목록의 왼쪽 절반에 있는지 오른쪽 절반에 있는지 확인합니다.
- 목표 항목을 찾을 때까지 남은 목록 부분을 계속 반으로 나눕니다.
- 최종적으로 목표 항목을 찾지 못하면 `-1`를 반환합니다.
- 이진 검색의 시간 복잡도는 `O(log n)`인데, 목록 크기에 따라 검색 시간이 로그 함수적으로 증가하기 때문입니다.
- 이진 검색의 공간 복잡도는 `O(1)`인데, 목록을 검색하는 데 추가 공간이 필요하지 않기 때문입니다.

### 선형 검색과 이진 검색의 차이점

- 이진 검색은 선형 검색에 비해 많은 항목이 있는 목록에 더 적합합니다.
- 선형 검색의 시간 복잡도는 `O(n)`인데, 목록 크기에 따라 검색 시간이 선형적으로 증가하기 때문입니다.
- 이진 검색의 시간 복잡도는 `O(log n)`인데, 목록 크기에 따라 검색 시간이 로그 함수적으로 증가하기 때문입니다.

## 정렬 알고리즘과 분할 정복

컴퓨터 과학에서 분할 정복은 문제를 더 작은 하위 문제로 나누어 해결하기 쉽게 만드는 기법입니다. 재귀는 분할 정복에서 자주 사용되는 기법이며, 분할 정복은 병합 정렬과 같은 효율적인 정렬 알고리즘을 구현하는 강력한 전략입니다.

### 병합 정렬

- 병합 정렬은 분할 정복 방식을 따르는 정렬 알고리즘입니다.
- 목록을 재귀적으로 더 작은 하위 목록으로 나누어 각 하위 목록이 하나의 요소만 포함할 때까지 나눕니다.
- 그런 다음 하위 목록들을 정렬된 순서로 반복해서 병합합니다.
- 병합 정렬의 시간 복잡도는 `O(n log n)`인데, 목록을 계속 반으로 나누고 `(log n)` 다시 병합하기 때문입니다 `(O(n))`.
- 병합 정렬의 공간 복잡도는 `O(n)`인데, 제자리 정렬 알고리즘이 아니기 때문입니다.

## 그래프 개요

그래프는 노드(정점) 집합과 간선(연결)으로 구성됩니다. 각 노드는 여러 다른 노드와 연결될 수 있어 네트워크를 형성합니다. 그래프 유형은 다음과 같습니다:

- 방향 그래프: 간선에 방향이 있으며(한 노드에서 다른 노드로), 직선과 화살표로 표시됩니다.
- 무방향 그래프: 간선에 방향이 없으며, 단순 선으로 표시됩니다.
- 정점: 각 노드는 레이블이나 식별자와 연결됩니다.
- 순환 그래프: 사이클(시작과 끝이 같은 경로)을 포함합니다.
- 비순환 그래프(DAG): 사이클이 없습니다.
- 간선 레이블: 각 간선에 레이블이 붙어 보통 간선 옆에 표시됩니다.
- 가중치 그래프: 간선에 산술 연산에 사용할 수 있는 가중치(값)가 있습니다.
- 비연결 그래프: 두 개 이상의 노드가 간선으로 연결되어 있지 않습니다.

그래프는 지도, 네트워크, 추천 시스템, 의존성 해결 등 다양한 애플리케이션에 사용됩니다.

## 그래프 순회

그래프의 모든 노드를 방문하는 작업입니다. 주요 알고리즘 두 가지는:

- **너비 우선 탐색(BFS)**
  - 큐를 사용합니다.
  - 레벨별로 탐색합니다.
  - 가중치 없는 그래프에서 최단 경로를 찾습니다.

- **깊이 우선 탐색(DFS)**
  - 스택(또는 재귀)을 사용합니다.
  - 한 갈래를 완전히 탐색한 후 되돌아갑니다.
  - 사이클 탐지와 경로 찾기에 유용합니다.

## 그래프 표현

그래프는 두 가지 주요 방식으로 표현할 수 있습니다:

- **인접 리스트**
  - 각 노드가 이웃 노드 목록을 가집니다.
  - 희소 그래프에 공간 효율적입니다.
  - 이웃 노드를 순회하기 쉽습니다.

- **인접 행렬**
  - 행과 열이 노드를 나타내는 2차원 배열입니다.
  - 큰 그래프에 공간을 많이 차지합니다.
  - 두 노드 간 간선 존재 여부를 빠르게 확인할 수 있습니다.

## 트리

트리는 사이클이 없고 연결된 특수한 그래프입니다. 주요 속성은:

- 루프나 사이클(시작과 끝 노드가 같은 경로)이 없습니다.
- 모든 노드가 서로 도달 가능해야 합니다.

### 일반적인 트리 유형

가장 일반적인 트리 유형은:

- 이진 트리
  - 각 노드가 최대 두 개의 자식(왼쪽, 오른쪽)을 가집니다.

- 이진 탐색 트리(BST)
  - 왼쪽 자식은 부모보다 작고, 오른쪽 자식은 부모보다 큰 이진 트리입니다.

## 트라이

접두사 트리라고도 하며, 문자열 집합을 저장하는 데 사용됩니다. 각 노드는 문자를 나타냅니다.

공통 접두사는 한 번만 저장되어 자동 완성, 맞춤법 검사 등에 효율적입니다.

검색과 삽입 연산의 시간 복잡도는 문자열 길이 L에 대해 O(L)입니다.

## 우선순위 큐

우선순위 큐는 각 요소가 우선순위를 가진 추상 자료형입니다.

큐와 스택은 삽입 순서만 고려하지만, 우선순위 큐는 우선순위가 높은 요소가 먼저 처리됩니다.

표준 큐는 FIFO, 스택은 LIFO를 따르지만, 우선순위 큐는 삽입 순서와 관계없이 우선순위가 높은 요소가 먼저 나갑니다.

## 힙

힙은 힙 속성이라는 특정 속성을 가진 특수한 트리 기반 자료 구조입니다.

힙 속성은 부모 노드와 자식 노드 간의 관계를 결정합니다. 힙에는 두 가지 유형이 있습니다:

- 최대 힙
  - 각 부모 노드 값이 자식 노드 값보다 크거나 같습니다.
  - 가장 큰 요소가 루트에 있습니다.

- 최소 힙
  - 각 부모 노드 값이 자식 노드 값보다 작거나 같습니다.
  - 가장 작은 요소가 루트에 있습니다.

### 파이썬 `heapq` 모듈

`heapq` 모듈은 리스트를 사용해 최소 힙을 구현합니다. `heapq.heappush(heap, item)`으로 항목을 삽입하고, `heapq.heappop(heap)`으로 가장 작은 항목을 제거하며, `heapq.heappushpop(heap, item)`으로 항목을 삽입한 후 가장 작은 항목을 제거합니다. `heapq.heapify(items)`는 리스트를 제자리에서 힙으로 변환합니다.

### 우선순위 사용법

힙에 `(priority, item)` 튜플을 저장하여 우선순위별로 항목을 정렬하세요. 숫자가 낮을수록 먼저 제거되므로 `(1, "C")`가 `(2, "B")`보다 먼저 처리됩니다.

## 동적 프로그래밍 소개

- **정의**: 동적 프로그래밍은 복잡한 문제를 더 단순한 하위 문제로 나누고 결과를 저장해 중복 계산을 피하는 알고리즘 기법입니다.
- **중복 하위 문제**: 큰 문제를 풀 때 동일한 작은 문제가 여러 번 나타납니다. 이 하위 문제를 반복 계산하는 대신 결과를 저장합니다.
- **최적 부분 구조**: 문제의 최적 해는 하위 문제들의 최적 해를 포함합니다. 즉, 작은 부분 문제들의 최적 해를 결합해 최적 해를 만들 수 있습니다.

## 동적 프로그래밍 해법

- **메모이제이션(탑다운 방식)**: 비용이 큰 함수 호출 결과를 저장해 같은 입력이 다시 오면 저장된 결과를 반환합니다.

- **테이블화(바텀업 방식)**: 하위 문제부터 차례로 해결해 표에 결과를 채워가며 해를 만듭니다.
