# --description--

當節點有兩個子節點時，你需要用另一個值來替換它的值，同時保持樹的有序性。正確的選擇是它的中序後繼：在中序遍歷中緊接著它的值。

中序後繼是該節點右子樹中最小的值，你可以透過從右子節點一路往左走到最遠來找到它。

在 `BinarySearchTree` 類別中，創建一個名為 `_min_value` 的方法，帶有兩個參數 `self` 和 `node`。在方法內，使用 `while` 迴圈，只要 `node.left` 不是 `None`，就將 `node.left` 指定給 `node`。迴圈結束後，傳回 `node.key`。
