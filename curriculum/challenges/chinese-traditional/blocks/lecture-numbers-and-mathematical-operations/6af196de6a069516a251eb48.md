# --description--

有時候數字用來計算沒問題，但列印出來看起來有點不完整。舉例來說，顯示價格時，`12.50` 會比 `12.5` 感覺更自然。

f-string 讓你能控制數字顯示的樣子，而不改變原始數值，這樣你就能繼續用它做計算。

## 格式規格如何運作

表達式 `f"{value:.2f}"` 會將 `value` 顯示成小數點後剛好兩位數。

在大括號裡，每個字元都有特定的作用：

- 冒號 `:` 引入格式規格
- `.2` 選擇兩位小數
- `f` 選擇定點表示法，以十進位顯示數字。

這表示 `print(f"{12.5:.2f}")` 會輸出 `12.50`，但原始值仍保持不變：

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

輸出顯示 `12.50` 是因為 `.2f` 格式規格總是顯示兩位小數，所以 Python 用尾隨零補足結果。`value` 中儲存的值仍是 `12.5`。


另一方面，像 `12.3456` 這樣的值用 `.2f` 格式化會產生 `12.35`，因為數字必須四捨五入後才顯示：

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## 用 F-String 格式化會產生字串

f-string 會產生一個字串：

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

這表示你可以把結果字串另存，並且仍然用原始數字做計算。

## `round()` 與 F-String 格式化的差異

像 `round(value, 2)` 這樣的表達式會給你一個數值結果，可以用來做後續計算。

列印該結果時會用 Python 一般的數字顯示方式，所以不保證會有尾隨零：

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## 格式化不會改變底層數值

如你之前所見，有些小數像 `0.1` 和 `0.2` 只能用浮點數近似表示。因此，它們相加的結果直接列印時可能會有點令人驚訝：

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

如你所見，f-string 會將總和四捨五入後顯示。任何使用 `total` 的計算仍然用相同的浮點數值。
