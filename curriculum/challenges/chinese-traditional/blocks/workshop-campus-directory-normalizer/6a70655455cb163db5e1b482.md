# --description--

要將部門名稱和數值當作陣列項目來處理，請使用 `Object.entries(rawData)`。它會傳回一個包含物件自身可列舉字串鍵屬性的 `[key, value]` 對組陣列。

```js
const person = {
  name: "Alice",
  age: 30
};

console.log(Object.entries(person));
/*
Output: 
[ ["name", "Alice"], ["age", 30] ]
*/
```

宣告一個名為 `departmentEntries` 的變數，並將它設為 `Object.entries(rawData)`。
接著將 `departmentEntries` 輸出到主控台，以查看它產生的 `[key, value]` 對組。
