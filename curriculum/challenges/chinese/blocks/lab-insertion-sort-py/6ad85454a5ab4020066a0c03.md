# --description--

插入排序通过一次添加一个元素，在列表开头构建一个已排序部分。它从将第一个元素视为已排序开始。然后取下一个元素，将其向后移动到已排序部分，通过将每个较大的元素向右移动或交换一个位置，直到遇到一个小于或相等的元素。这个过程对剩余的每个元素重复，直到整个列表排序完成。

插入排序在平均和最坏情况下具有二次时间复杂度，但当列表已经排序时，它以线性时间运行。

**目标：**实现以下用户需求并通过所有测试以完成实验。

**用户故事：**

1. 你应该定义一个名为 `insertion_sort` 的函数，带有一个表示项列表的参数。
1. 你的 `insertion_sort` 函数应该就地将列表从小到大排序并返回它。
1. 你的 `insertion_sort` 函数应该遵循插入排序算法，从左到右将每个元素插入到列表开头已排序部分的正确位置。
1. 你的 `insertion_sort` 函数在遇到小于或相等的元素时应停止向后移动该元素。
1. 你的 `insertion_sort` 函数不应使用内置的 `sort()` 方法或 `sorted()` 函数。

**注意：** 你不应导入任何模块或使用添加或删除列表项的方法。

```py
def insertion_sort(items):
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j -= 1
        items[j + 1] = current
    return items
```
