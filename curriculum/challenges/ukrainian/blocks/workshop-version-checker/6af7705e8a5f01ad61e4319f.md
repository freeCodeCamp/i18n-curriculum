# --description--

На цьому практичному занятті ви попрактикуєтеся у роботі з кортежами, створюючи програму, яка перевіряє, чи потрібне оновлення застосунку.

Кожен випуск програмного забезпечення має номер версії, щоб люди могли відрізняти релізи та знати, який із них новіший. Загальною конвенцією є використання трьох чисел, розділених крапками, у форматі `MAJOR.MINOR.PATCH`:

- Число `MAJOR` збільшується при великих змінах, які можуть призвести до того, що старий код або файли перестануть працювати з новою версією.
- Число `MINOR` збільшується, коли додають нові функції, які сумісні з попередніми версіями.
- Число `PATCH` збільшується для невеликих виправлень, таких як виправлення помилок, які не додають нових функцій.

Версію, наприклад `2.1.0`, можна зберігати як кортеж із трьох цілих чисел: номер major, minor і patch.

Створіть змінну з ім’ям `releases` і призначте їй кортеж, що містить наведені нижче кортежі версій у цьому порядку:

```py
(1, 9, 0), (2, 0, 0), (1, 9, 1), (2, 1, 0),
(2, 1, 1), (2, 2, 0), (1, 9, 2), (2, 2, 1)
```

Релізи наведені в порядку їх публікації, а не від найнижчої до найвищої версії. Стара лінія `1.9` продовжувала отримувати виправлення навіть після виходу версії `2.0.0`.
