## Installare Python nel tuo ambiente locale

- **Installazione**: Il modo più semplice per installare Python su Windows e macOS è scaricare l'installer dal sito ufficiale di Python (`https://www.python.org/`). Su Linux, la maggior parte delle distribuzioni principali come Ubuntu, Debian e Fedora include già Python, quindi verifica prima la versione installata e installa un pacchetto specifico per la distribuzione solo se manca Python 3.
- **Configurazione su macOS**: Scarica e apri l'installer `.pkg` e segui le istruzioni. Quando termina, fai doppio clic sul file `Install Certificates.command` e lascia che il processo nel terminale si completi per finire la configurazione.
- **Configurazione su Windows**: Scarica e avvia il Python Install Manager `.msix`. Successivamente, i comandi `python`, `py` e `pymanager` saranno disponibili, eseguendo `python` senza runtime installato verrà installato automaticamente uno, e puoi accettare il prompt opzionale per aggiungere una directory di alias (per comandi come `python3.14.exe`) al tuo `PATH`.
- **Configurazione su Linux**: Apri un terminale ed esegui `python --version` o `python3 --version`. Se nessuno dei due riporta una versione di Python 3, cerca un pacchetto di installazione su `https://www.python.org/` o cerca online il modo consigliato per installare Python per la tua distribuzione.

## Verificare l'installazione

- **Verifica della versione**: Conferma l'installazione eseguendo `python --version` o `python3 --version` in un terminale.
- **`python` vs. `python3`**: Su alcuni sistemi macOS e Linux più vecchi, `python` può riferirsi a Python 2. Se `python --version` riporta una versione di Python 2, usa `python3` per il tuo codice da quel momento in poi. Python 2 è fuori supporto e non dovrebbe essere usato per nuovi sviluppi.

## Terminale

- **Definizione**: Un terminale è un'interfaccia testuale che ti permette di interagire con il computer digitando comandi. Ogni sistema operativo ha un'app terminale predefinita. Su macOS puoi usare l'app Terminal. Su Windows puoi usare Prompt dei comandi o PowerShell. Su Linux ogni ambiente desktop ha la sua app terminale predefinita, come GNOME Terminal o Konsole.

## Editor di codice e IDE

- **IDE**: IDE sta per ambiente di sviluppo integrato, e include funzionalità come un editor di codice, strumenti di test, un terminale e altro.
- **Editor di codice e IDE popolari per Python**: VS Code, PyCharm e Spyder.

## Eseguire script Python

- **Configurare il tuo editor**: Apri la cartella del progetto in VS Code e crea un file `.py`. Installa l'estensione Python di Microsoft dalla vista Estensioni o eseguendo `code --install-extension ms-python.python` (su macOS, il comando `code` deve essere aggiunto prima al tuo `PATH`). L'estensione aggiunge il supporto Python all'editor ma non installa Python stesso.
- **Scegliere un interprete**: Esegui `Python: Select Interpreter` dalla Command Palette per indicare all'editor un interprete Python 3 che hai installato in precedenza.
- **Eseguire il codice**: Clicca il pulsante di esecuzione (l'icona play in alto a destra di VS Code) per eseguire il file corrente in un terminale. Puoi anche eseguire uno script manualmente da un terminale. Per esempio, se la cartella del progetto è `python-projects` e lo script è `main.py`, apri un terminale nella cartella che contiene `python-projects`, poi entra nella cartella del progetto ed esegui lo script:

```bash
cd python-projects
python main.py
```

Usa `python3 main.py` invece se `python3` è il comando che riporta Python 3 sul tuo sistema.

## Usare la shell interattiva di Python

- **Avviare la shell**: Apri un terminale ed esegui `python` o `python3` (usa quello che ha riportato una versione di Python 3). Il prompt `>>>` indica che Python aspetta un comando. Prova a stampare `"Hello, world!"`:

```python
print("Hello, world!")
```

- **Ciclo Read, Evaluate, Print, Loop (REPL)**: L'interprete legge il tuo input, lo valuta, stampa il risultato e torna al prompt `>>>` così puoi digitare un altro comando.
- **Input non valido**: Inserire qualcosa che non è Python valido, come `something random`, produce un messaggio `SyntaxError: invalid syntax` e la shell torna al prompt.
- **Uscire dalla shell**: Digita `exit()`, premi <kbd>Ctrl</kbd> + <kbd>D</kbd> su macOS o Linux, oppure premi <kbd>Ctrl</kbd> + <kbd>Z</kbd> seguito da <kbd>Invio</kbd> su Windows.
- **Quando usarla**: La shell interattiva è ideale per piccoli esperimenti e esplorazioni rapide. Per programmi più lunghi o lavoro su più file, usa un editor di codice o un IDE.
