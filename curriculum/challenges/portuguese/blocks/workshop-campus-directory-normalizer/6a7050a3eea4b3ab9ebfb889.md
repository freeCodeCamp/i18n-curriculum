# --description--

Neste ponto, `rawData` está profundamente aninhado: `departments → programs → instructors`. Para buscar um instrutor pelo e-mail, você teria que fazer um loop por cada departamento, depois por cada programa e finalmente por cada instrutor até encontrar uma correspondência.

Embora essa abordagem funcione, ela fica lenta e repetitiva conforme os dados crescem.

Mais adiante na oficina, você vai aprender como normalizar os dados, que é uma abordagem mais eficiente.

Mas nos próximos passos, você vai criar uma função que recebe um e-mail como argumento, usa loops para buscar na estrutura aninhada `rawData` e retorna o nome do instrutor quando encontrar um endereço de e-mail correspondente.

Comece deletando o `console.log()` do passo anterior.

Depois, declare uma função chamada `getInstructorByEmail` e use `email` como nome do parâmetro. Em seguida, retorne `null` da função.
