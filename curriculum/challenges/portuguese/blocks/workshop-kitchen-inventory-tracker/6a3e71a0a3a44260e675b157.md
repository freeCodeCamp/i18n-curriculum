# --description--

Uma função pode chamar outra função e usar o valor retornado por ela. Por exemplo:

```py
def calculate_sum(a, b):
    return a + b

def show_total(a, b):
    total = calculate_sum(a, b)
    print(total)

show_total(3, 4) # 7
```

Aqui, `show_total` chama `calculate_sum`, atribui o valor retornado à variável local `total` e o imprime.

A seguir, você vai criar uma função que verifica se um ovo está disponível e chama `use_eggs` para usá-lo. Abaixo da sua declaração `print(available_eggs)`, defina uma função vazia chamada `make_fried_egg` que recebe `available_eggs` como seu único parâmetro.

Use a palavra-chave `pass` dentro do corpo por enquanto.

def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        print('The kitchen does not have enough eggs.')
        return available_eggs

    print(f'{eggs_to_use} egg(s) used out of {available_eggs} available.')
    return available_eggs - eggs_to_use

use_eggs(available_eggs, 1)
