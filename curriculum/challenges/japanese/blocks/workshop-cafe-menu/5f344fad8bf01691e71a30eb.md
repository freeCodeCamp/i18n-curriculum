# --description--

これまで、コンテンツの見た目や表示方法をあまり自由にコントロールできませんでした。それを変えるために、CSSを使います。

ページにCSSを追加する方法の一つは、通常`head`タグ内に置く`style`要素を使うことです。`style`タグ内のCSSルールはページ全体に適用されます。例を示します：

```html
<style>
  p {
    color: green;
  }
</style>
```

`head`要素の中に`style`要素を追加してください。

# --hints--

コードには `style` 要素を含めてください。

```js
assert.exists(document.querySelector('style:not(.fcc-hide-header)'));
```

コードには閉じる `</style>` タグが必要です。

```js
assert.match(code, /<\/style\s*>/i);
```

`style` 要素は `head` 要素の中にネストされている必要があります。

```js
assert.exists(document.querySelector('head > style:not(.fcc-hide-header)'));
```
