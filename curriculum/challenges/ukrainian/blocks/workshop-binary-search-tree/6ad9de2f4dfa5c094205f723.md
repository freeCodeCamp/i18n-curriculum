# --description--

Кожен вузол може мати до двох дочірніх елементів.

Всередині методу `__init__` створіть атрибут `left` і атрибут `right` та встановіть обидва в `None`, щоб представити новий вузол, який починається без дочірніх елементів.

Вузол без дочірніх елементів називається листовим вузлом.
