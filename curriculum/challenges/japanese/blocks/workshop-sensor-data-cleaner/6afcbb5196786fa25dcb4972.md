# --description--

ターミナルには、読み取り値の代わりに `<filter object at 0x...>` のようなものが表示されます。これは `filter()` がイテレーターを返すためで、リストにすべてを格納するのではなく、1つずつアイテムを渡す仕組みだからです。

イテレーターのアイテムをリストにまとめるには、`list()` 関数に渡してください。

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

`valid_readings` に代入された `filter()` の呼び出しを `list()` で囲んでください。そうすればターミナルに `-999` のエラーコードなしで読み取り値が表示されます。
