# --description--

辞書の作成方法と、その値へのアクセスおよび更新方法を学びました。次は辞書のメソッドを使い、辞書をコピーし、関数がどのように辞書を変更できるかを探ります。

以下の各辞書メソッドの例は、この辞書から始まります：

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## 辞書のメソッド

辞書には一般的な操作を行うための便利なメソッドもあります。

`.get()` メソッドはキーに関連付けられた値を取得します。これは前のレッスンで学んだブラケット記法に似ていますが、キーが存在しない場合にエラーにならず、デフォルト値を設定できる点が利点です：

```python
dictionary.get(key, default)
```

この例では、`toppings`キーが存在しない場合、ここで2番目の引数として渡している空のリストというデフォルト値を返します。しかし`toppings`が存在する場合は、その値を返します：

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

`.keys()`と`.values()`メソッドは、それぞれ辞書内のすべてのキーと値を含むビューオブジェクトを返します：

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

ビューオブジェクトは、データの別コピーを作成せずに辞書の内容を見るための方法です。

`.items()`メソッドは、キーと値の両方を含む辞書内のすべてのキーと値のペアを含むビューオブジェクトを返します：

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

`.clear()`メソッドは辞書からすべてのキーと値のペアを削除します：

```python
pizza.clear()
```

`.pop()`メソッドは、最初の引数で指定したキーのキーと値のペアを削除し、その値を返します。キーが存在しない場合は、2番目の引数で指定したデフォルト値を返します。キーが存在せず、デフォルト値を渡さなかった場合は`KeyError`がスローされます：

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

Python 3.7以降のバージョンでは、`.popitem()`メソッドは最後に挿入されたアイテムを削除します：

```python
pizza.popitem()
```

`.update()` メソッドは、別の辞書のキーと値のペアでキーと値のペアを更新します。共通のキーがある場合、その値は上書きされます。

この例では、`pizza`辞書を更新しています。`price`キーは両方に存在するので、その値は`15`に置き換えられます。

しかし`total_time`は新しいので、`pizza`辞書に新しいキーと値のペアとして追加されます：

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

これは更新された`price`と新しい`total_time`を含む新しい辞書です。価格が`15`になり、`total_time`が新しいキーと値のペアになっていることに注目してください：

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### 代入とシャローコピー

リストで学んだように、辞書を別の変数に代入するとエイリアスが作成されます。両方の名前は同じオブジェクトを参照します：

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

別の外側の辞書を作成するには、`.copy()` メソッドを使います：

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

`copied_settings` のエントリーを置き換えても `settings` の対応するエントリーは置き換わりません。ただし、`.copy()` は**シャローコピー**を作成します：元の辞書と同じオブジェクトを参照するキーと値を持つ新しい外側の辞書を作成します。ネストされたミュータブルなオブジェクトは共有されたままです：

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

2つの辞書は異なるオブジェクトですが、それぞれの `languages` エントリーは同じリストを参照しています。そのリストに追加すると両方の辞書で見えます。`copied_settings['languages']` を新しいリストに置き換えると、コピーのそのエントリーだけが変わります。

辞書を `dict()` に渡してシャローコピーを作成することもできます：

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

`.copy()` と同様に、`dict(settings)` は新しい外側の辞書を作成しますが、ネストされたリストは共有されたままです。どちらかの辞書のエントリーを置き換えてもその辞書だけに影響し、共有されたリストの変更は両方で見えます。

## 関数のパラメータを通じて辞書をミューテートする

リストで学んだ引数渡しのルールは辞書にも当てはまります。パラメータは最初に引数として渡されたオブジェクトを参照します。そのパラメータを通じてエントリーを更新すると共有された辞書がミューテートされます：

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

関数はステータス文字列を返しますが、`preferences` は共有された参照を通じて変わります。値を返すこととオブジェクトをミューテートすることは別の効果です。関数が辞書を返す必要はなく、変更は関数外でも見えます。ローカルパラメータを別の辞書に再代入しても、`preferences` が参照する辞書は置き換わりません。

## 辞書をデフォルト引数として使う

デフォルトのリストは関数定義時に作成され、引数を省略した呼び出し間で再利用されることを思い出してください。デフォルトの辞書も同様に動作します：

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

2回目の呼び出しは1回目の呼び出しで変更された辞書を再利用します。つまり、各呼び出しが独立したローカルパラメータ名を持っていても、設定は呼び出し間で蓄積されます。

各呼び出しが新しい辞書で始まるべき場合は、`None` デフォルトパターンを使ってください：

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

`settings` を省略するか `None` を渡す各呼び出しは新しい辞書を作成します。既存の辞書を渡すと関数はそのオブジェクトをミューテートできます。ここでは `settings is None` を使います：`if not settings` は空の辞書を引数に渡した場合もマッチして新しいローカル辞書に置き換えてしまいます。
