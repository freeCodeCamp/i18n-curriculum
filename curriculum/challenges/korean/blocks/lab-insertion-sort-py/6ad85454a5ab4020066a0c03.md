# --description--

삽입 정렬은 리스트의 앞부분에 정렬된 구간을 하나씩 쌓아 올립니다. 먼저 첫 번째 요소를 정렬된 상태로 간주합니다. 그다음 다음 요소를 가져와 정렬된 구간 안에서 뒤로 이동시키며, 자신보다 큰 요소들을 오른쪽으로 한 칸씩 밀거나 교환하다가 자신보다 작거나 같은 요소를 만나면 멈춥니다. 이 과정을 남은 모든 요소에 대해 반복하여 리스트 전체가 정렬될 때까지 진행합니다.

삽입 정렬은 평균 및 최악의 경우에 이차 시간 복잡도를 가지지만, 리스트가 이미 정렬되어 있을 때는 선형 시간에 실행됩니다.

**목표:** 아래 사용자 스토리를 충족하고 모든 테스트를 통과하여 실습을 완료하세요.

**사용자 스토리:**

1. 항목 리스트를 나타내는 하나의 매개변수를 가진 `insertion_sort`라는 이름의 함수를 정의하세요.
1. `insertion_sort` 함수는 리스트를 제자리에서 가장 작은 값부터 가장 큰 값 순으로 정렬하고 반환해야 합니다.
1. `insertion_sort` 함수는 삽입 정렬 알고리즘을 따라 리스트 앞부분의 정렬된 구간에 각 요소를 왼쪽에서 오른쪽으로 올바른 위치에 삽입해야 합니다.
1. `insertion_sort` 함수는 요소가 자신보다 작거나 같은 요소를 만나면 뒤로 이동을 멈춰야 합니다.
1. `insertion_sort` 함수는 내장된 `sort()` 메서드나 `sorted()` 함수를 사용하지 않아야 합니다.

**참고:** 어떤 모듈도 가져오지 말고, 리스트에 항목을 추가하거나 제거하는 메서드도 사용하지 마세요.

```py
def insertion_sort(items):
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j -= 1
        items[j + 1] = current
    return items
```
