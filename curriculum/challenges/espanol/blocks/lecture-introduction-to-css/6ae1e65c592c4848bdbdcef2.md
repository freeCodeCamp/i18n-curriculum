# --interactive--

La propiedad `text-decoration` te permite agregar líneas decorativas al texto.

Con su valor inicial `none`, se usa comúnmente para eliminar el subrayado predeterminado que los navegadores agregan a los enlaces cuando se necesita personalizar dichos enlaces.

```css
a {
  text-decoration: none;
}
```

Aunque se usa comúnmente para enlaces, `text-decoration` también puede decorar otro texto.

## Otros valores de la propiedad `text-decoration`

Además de `none`, otros valores de la propiedad `text-decoration` son:

- `underline`
- `overline`
- `line-through`

Como indican los nombres de los valores, `underline` agrega una línea debajo del texto, `overline` agrega una línea sobre el texto, y `line-through` agrega esa línea justo en el medio del texto, como tachándolo.

## Hay más en la propiedad `text-decoration`

La propiedad `text-decoration` es en realidad una propiedad abreviada que combina las siguientes propiedades:

- `text-decoration-line`: `none`, `underline`, `overline` y `line-through`
- `text-decoration-color`: El color de la línea.
- `text-decoration-style`: `solid`, `double`, `dotted`, `dashed` o `wavy`.
- `text-decoration-thickness`: El grosor de la línea.

Por ejemplo, esto agrega una línea roja ondulada a un párrafo:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

Y esto agrega una sobrelínea doble verde a un párrafo:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

También puedes combinar tipos de línea si quieres:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
