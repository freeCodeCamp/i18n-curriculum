# --description--

In questo laboratorio costruirai una classe coda. Una coda segue il principio FIFO (first-in, first-out): gli elementi vengono aggiunti alla fine della coda e rimossi dalla parte anteriore.

**Obiettivo:** Completa le storie utente qui sotto e fai passare tutti i test per completare il laboratorio.

**Storie utente:**

1. Dovresti definire una classe chiamata `Queue`. Una nuova istanza di `Queue` dovrebbe iniziare vuota.

1. La classe `Queue` dovrebbe avere i seguenti metodi:

   - `enqueue`: prende un elemento e lo aggiunge alla fine della coda.
   - `dequeue`: rimuove l'elemento dalla parte anteriore della coda e lo restituisce. Se la coda è vuota, dovrebbe restituire `None`.
   - `front`: restituisce l'elemento in testa alla coda senza rimuoverlo. Se la coda è vuota, dovrebbe restituire `None`.
   - `size`: restituisce il numero di elementi nella coda.
   - `is_empty`: restituisce `True` se la coda non ha elementi, e `False` altrimenti.

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
