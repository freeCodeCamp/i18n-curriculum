# --interactive--

El elemento `form` en HTML se utiliza para recopilar información del usuario, como nombres y correos electrónicos. Aquí hay un ejemplo de un elemento `form`:

```html
<form action="url-goes-here">
  <!-- input elements go here -->
</form>
```

El atributo `action` especifica a dónde se enviarán los datos del formulario al enviarlo. Para recopilar información específica, como nombres y correos electrónicos, usarías el elemento `input`. Aquí tienes un ejemplo de cómo usar un elemento `input`.

Activa el editor interactivo e interactúa con el elemento `input` en la ventana de vista previa escribiendo tu nombre en el campo.

:::interactive_editor

```html
<form action="">
  <input type="text" />
</form>
```

:::

Los elementos `input` son elementos vacíos y no tienen etiqueta de cierre. El atributo `type` define el tipo de datos que se espera del usuario. En este caso, los datos serían texto plano. Para agregar una etiqueta al input, usarías un elemento `label`. Aquí tienes un ejemplo de cómo usar un elemento `label` con el texto `Full Name:`.

Haz clic en el texto `Full Name:` en la ventana de vista previa y verás que el campo de entrada recibe el foco. Para interactuar con el ejemplo, necesitarás habilitar el editor interactivo.

:::interactive_editor

```html
<form action="">
  <label>
    Full Name:
    <input type="text" />
  </label>
</form>
```

:::

Al anidar un `input` dentro de un elemento `label`, creas una asociación implícita entre la `label` y el campo `input`. El término "implícito" se refiere a algo que se entiende o se infiere sin necesidad de ser declarado explícitamente o definido con atributos o elementos adicionales. Para asociar explícitamente una `label` con un `input`, puedes usar el atributo `for`. Aquí tienes un ejemplo de cómo usar el atributo `for` para una etiqueta de dirección de correo electrónico.

Interactúa con el elemento `input` en la ventana de vista previa escribiendo una dirección de correo electrónico falsa como `jane@example.com`. Para interactuar con el ejemplo, necesitarás habilitar el editor interactivo.

:::interactive_editor

```html
<form action="">
  <label for="email"> Email Address: </label>
  <input type="email" id="email" />
</form>
```

:::

Cuando usas una asociación explícita, los valores del atributo `for` y del `id` deben ser iguales. En este caso, ambos valores están establecidos como `email`. El tipo `email` en el input proporciona una validación básica para direcciones de correo electrónico con formato correcto. Si quieres mostrar pistas adicionales a los usuarios sobre la entrada esperada, puedes usar el atributo `placeholder`. Aquí tienes un ejemplo usando el atributo `placeholder` dentro del input de correo electrónico.

Activa el editor interactivo, haz clic en el campo de correo electrónico y comienza a escribir un email y verás cómo el texto del placeholder desaparece.

:::interactive_editor

```html
<form action="">
  <label for="email"> Email Address: </label>
  <input type="email" id="email" placeholder="example@email.com" />
</form>
```

:::

Para el texto del marcador de posición, quieres proporcionar un texto corto útil que muestre el formato y tipo de datos que esperas de tus usuarios. En este caso, el texto del marcador de posición, `example@email.com`, muestra al usuario que debe ingresar una dirección de correo electrónico con el formato correcto.
