# --description--

現在包含小費後，你有整個群組的最終金額。你必須將帳單總額除以朋友人數，以決定每個人應付多少。

在 Python 中，你使用斜線 `/` 來執行除法。例如：

```py
half = 10 / 2
```

最後，使用 f-string 列印 `Bill per person:`，後面接一個空格和格式化為兩位小數的 `final_bill`。
