# --description--

Beim Schreiben von Python-Code kommt es häufig zu Fehlern. Diese Fehler zu verstehen, ist der Schlüssel, um Ihren Code schnell und effizient zu debuggen. Diese Meldungen sagen Ihnen genau, was schiefgelaufen ist, wenn Sie wissen, wie Sie sie lesen.

Häufige Python-Fehler sind `SyntaxError`, `NameError`, `TypeError`, `IndexError` und `AttributeError`. Diese treten auf, wenn Python Ihren Code nicht versteht oder wenn Ihre Logik nicht zu den Daten passt, mit denen Sie arbeiten.

Hier ist ein Beispiel für einen `SyntaxError`:

```py
print("Hello, world!"
# SyntaxError: '(' was never closed
```

Diese Zeile fehlt eine schließende Klammer. Python wirft einen `SyntaxError`, weil der Code nicht den korrekten Syntaxregeln folgt.

Hier ist ein Beispiel für einen `NameError`:

```py
print(name)
# NameError: name 'name' is not defined
```

Sie versuchen, eine Variable auszugeben, die noch nicht definiert wurde. Python wirft einen `NameError`, wenn es eine Variable mit diesem Namen nicht finden kann.

Hier ist ein Beispiel für einen `TypeError`:

```py
5 + "5"
# TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

Sie können keine Ganzzahl und einen String zusammenaddieren. Python wirft einen `TypeError`, wenn Sie versuchen, eine Operation mit inkompatiblen Datentypen durchzuführen.

Hier ist ein Beispiel für einen `IndexError`:

```py
my_list = [1, 2, 3]
print(my_list[5])
# IndexError: list index out of range
```

Sie versuchen, auf einen Index zuzugreifen, der in der Liste nicht existiert. Python wirft einen `IndexError`, wenn Sie außerhalb der Grenzen zugreifen.

Hier ist ein Beispiel für einen `AttributeError`:

```py
num = 42
num.append(5)
# AttributeError: 'int' object has no attribute 'append'
```

Das `int`-Objekt hat keine `append()`-Methode. Python wirft einen `AttributeError`, wenn Sie versuchen, eine Methode oder Eigenschaft zu verwenden, die für diesen Datentyp nicht existiert.

Das Erkennen häufiger Python-Fehlermeldungen hilft Ihnen, Probleme schneller zu beheben. Statt zu raten, lesen Sie die Fehlermeldung sorgfältig. Sie sagt Ihnen oft genau, was schiefgelaufen ist und wo Sie nachsehen müssen.
