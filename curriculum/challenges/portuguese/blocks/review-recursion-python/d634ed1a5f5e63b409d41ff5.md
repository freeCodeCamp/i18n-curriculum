# --description--

- **Recursão**: Uma técnica em que uma função chama a si mesma. Cada chamada trabalha em uma versão menor do problema original até atingir um caso base que para as chamadas recursivas.
- **Caso base**: A condição que para a recursão. Você deve definir cuidadosamente o caso base. Caso contrário, a função pode continuar se chamando até o Python lançar um `RecursionError`.
- **Caso recursivo**: A parte da função que chama a função novamente com um argumento que a aproxima do caso base, como `number - 1` ao contar para baixo.

```py
def recursive_countdown(number):
    if number < 1:  # Base case
        return
    print(number)
    recursive_countdown(number - 1)  # Recursive case

recursive_countdown(5)  # Prints 5, 4, 3, 2, 1
```

- **Ordem de execução**: A posição da chamada recursiva muda quando o outro código da função é executado. Código colocado antes da chamada recursiva é executado conforme as chamadas vão se aprofundando, enquanto código colocado depois é executado conforme as chamadas retornam. Mover o `print()` para depois da chamada recursiva faz a função imprimir os números em ordem crescente:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)  # Prints 1, 2, 3, 4, 5
```

- **Pilha de chamadas**: Uma estrutura de dados last-in, first-out que o Python usa para controlar as chamadas de função ativas. Cada vez que uma função é chamada, o Python adiciona um quadro para essa chamada no topo da pilha. O quadro contém informações como os argumentos da função e variáveis locais.
- **Retomando chamadas**: Uma chamada pausa quando faz sua chamada recursiva. Quando o caso base retorna, o Python remove essa chamada do topo da pilha, e as chamadas anteriores retomam após sua chamada recursiva e retornam na ordem last-in, first-out:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

A saída é:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

- **Construindo uma lista recursivamente**: Cada chamada retoma quando sua chamada recursiva retorna, então usa o valor retornado. A função `countup` abaixo retorna uma lista vazia no caso base. Cada outra chamada recebe a lista da sua chamada recursiva, adiciona seu próprio número e retorna a lista:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(5))  # [1, 2, 3, 4, 5]
```

A chamada com `1` recebe `[]` e retorna `[1]`, a chamada com `2` recebe `[1]` e retorna `[1, 2]`, e assim por diante até a chamada com `5` retornar `[1, 2, 3, 4, 5]`.

- **Aplicações da recursão**: A recursão pode lidar com tarefas simples como contar para baixo, contar para cima e construir uma lista. Também é útil para problemas com profundidade desconhecida, como percorrer uma árvore de arquivos.
