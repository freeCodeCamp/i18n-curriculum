# --description--

- **Recursión**: Una técnica en la que una función se llama a sí misma. Cada llamada trabaja sobre una versión más pequeña del problema original hasta que alcanza un caso base que detiene las llamadas recursivas adicionales.
- **Caso base**: La condición que detiene la recursión. Debes definir cuidadosamente el caso base. De lo contrario, la función puede seguir llamándose a sí misma hasta que Python lance un `RecursionError`.
- **Caso recursivo**: La parte de la función que llama a la función nuevamente con un argumento que la acerca al caso base, como `number - 1` al contar hacia abajo.

```py
def recursive_countdown(number):
    if number < 1:  # Base case
        return
    print(number)
    recursive_countdown(number - 1)  # Recursive case

recursive_countdown(5)  # Prints 5, 4, 3, 2, 1
```

- **Orden de ejecución**: La posición de la llamada recursiva cambia cuándo se ejecuta el otro código de la función. El código colocado antes de la llamada recursiva se ejecuta a medida que las llamadas se profundizan, mientras que el código colocado después se ejecuta a medida que las llamadas regresan. Mover `print()` después de la llamada recursiva hace que la función imprima los números en orden ascendente:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)  # Prints 1, 2, 3, 4, 5
```

- **Pila de llamadas**: Una estructura de datos LIFO (último en entrar, primero en salir) que Python usa para llevar el control de las llamadas activas a funciones. Cada vez que se llama a una función, Python agrega un marco para esa llamada en la parte superior de la pila. El marco contiene información como los argumentos y variables locales de la función.
- **Reanudación de llamadas**: Una llamada se pausa cuando hace su llamada recursiva. Cuando el caso base regresa, Python elimina esa llamada de la parte superior de la pila, y las llamadas anteriores se reanudan después de su llamada recursiva y regresan en orden LIFO:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

La salida es:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

- **Construir una lista recursivamente**: Cada llamada se reanuda cuando su llamada recursiva regresa, luego usa el valor retornado. La función `countup` a continuación retorna una lista vacía en el caso base. Cada otra llamada recibe la lista de su llamada recursiva, agrega su propio número y retorna la lista:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(5))  # [1, 2, 3, 4, 5]
```

La llamada con `1` recibe `[]` y retorna `[1]`, la llamada con `2` recibe `[1]` y retorna `[1, 2]`, y así sucesivamente hasta que la llamada con `5` retorna `[1, 2, 3, 4, 5]`.

- **Aplicaciones de la recursión**: La recursión puede manejar tareas simples como contar hacia abajo, contar hacia arriba y construir una lista. También es útil para problemas con una profundidad desconocida, como recorrer un árbol de archivos.
