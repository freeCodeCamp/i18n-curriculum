## ¿Qué es Python?

- **Introducción**: Python es un lenguaje de programación de propósito general conocido por su simplicidad y facilidad de uso.
- **Usos comunes**: Python se usa en ciencia de datos, aprendizaje automático, desarrollo web, ciberseguridad, sistemas embebidos e IoT, scripting, automatización y microcomputadoras como Raspberry Pi y placas compatibles con MicroPython.

## Variables

- **Declarar variables**: Para declarar una variable, comienzas con el nombre de la variable seguido del operador de asignación (`=`) y luego el valor. Esto puede ser un número, cadena, booleano, etc.

- **Convenciones para nombrar variables**: Estas son las convenciones que debes usar para nombrar variables:

  - Los nombres de variables solo pueden comenzar con una letra o un guion bajo (`_`), no con un número.
  - Los nombres de variables solo pueden contener caracteres alfanuméricos (`a-z`, `A-Z`, `0-9`) y guiones bajos (`_`).
  - Los nombres de variables distinguen entre mayúsculas y minúsculas: `age`, `Age` y `AGE` se consideran únicos.
  - Los nombres de variables no pueden ser palabras clave reservadas de Python como `if`, `class` o `def`.
  - Los nombres de variables con varias palabras usan guiones bajos, como en `snake_case`.
  - Los nombres de variables deben describir su propósito, como en `user_age`.
  - Se deben evitar los nombres de variables de una sola letra cuando no comunican significado.

## Comentarios

- **Comentarios de una línea**: Este tipo de comentario se debe usar para notas cortas en tu código.

- **Comentarios multilínea**: Puedes usar un `#` al principio de cada línea para crear comentarios que abarquen varias líneas.

- **Función `print()`**: Para imprimir datos en el terminal, puedes usar la función `print()`.

## Tipos de datos comunes en Python

- **Introducción**: Python es un lenguaje de tipado dinámico, lo que significa que no necesitas declarar el tipo de dato de una variable. Python determina el tipo a partir del valor asignado a la variable.
- **Entero**: Un número entero sin decimales.

- **Float**: Un número con decimales.

- **Cadena**: Una secuencia de caracteres encerrada entre comillas.

- **Booleano**: Un valor que representa `True` o `False`.

Python tiene otros tipos de datos. Aprenderás cada uno cuando los necesites por primera vez.

- **Función `type()`**: Para ver el tipo de una variable, puedes usar la función `type()`.

- **Función `isinstance()`**: Se usa para verificar si una variable coincide con un tipo de dato específico.

## Trabajar con cadenas

- **Definición**: Las cadenas son inmutables, lo que significa que no puedes cambiarlas después de haberlas creado. En Python, puedes usar comillas simples o comillas dobles. Elige un estilo y úsalo de forma consistente.

- **Acceder a caracteres en cadenas**: Puedes acceder a caracteres de cadenas usando notación de corchetes así:

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **Escapar cadenas**: Puedes usar una barra invertida (`\`) si tu cadena contiene comillas así:

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **Concatenación de cadenas**: Para concatenar cadenas, puedes usar el operador `+`.

Otra forma de concatenar cadenas es usando el operador `+=`. Esto se usa para realizar concatenación y asignación en un solo paso.

- **`f-strings`**: Esto es la abreviatura de literales de cadena formateada. Permite manejar interpolación y también hacer concatenación con una sintaxis compacta y legible:

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

- **Segmentación de cadenas**: Esto es cuando puedes extraer porciones de una cadena. La sintaxis es `str[start:stop:step]`.

La posición de inicio representa el índice donde debe comenzar la extracción. La posición de parada es donde debe terminar el segmento. Esta posición no es inclusiva. La posición de paso representa el intervalo para incrementar durante la segmentación.

- **Obtener la longitud de una cadena**: La función `len()` se usa para devolver el número de caracteres en la cadena.

## Trabajando con el operador `in`

- **Operador `in`**: Devuelve un booleano que especifica si el carácter o caracteres existen en la cadena o no.

## Métodos comunes de cadenas

- **`str.upper()`**: Devuelve una nueva cadena con todos los caracteres convertidos a mayúsculas.

- **`str.lower()`**: Devuelve una nueva cadena con todos los caracteres convertidos a minúsculas.

- **`str.strip()`**: Esto devuelve una copia de la cadena con los caracteres especificados al inicio y al final eliminados (si no se pasa un argumento al método, elimina los espacios en blanco al inicio y al final).

- **`replace()`**: Devuelve una nueva cadena con todas las ocurrencias de la cadena antigua reemplazadas por una nueva.

- **`split()`**: Se usa para dividir una cadena en una lista usando un separador especificado. Un separador es una cadena que indica dónde debe ocurrir la división.

- **`join()`**: Se usa para unir una colección de cadenas en una sola cadena con un separador.

- **`str.startswith(prefix)`**: Devuelve un booleano que indica si una cadena comienza con el prefijo especificado.

- **`str.endswith(suffix)`**: Devuelve un booleano que indica si una cadena termina con el sufijo especificado.

- **`str.find()`**: Devuelve el índice de la primera aparición de una subcadena. Si no se encuentra, devuelve `-1`.

- **`str.count(substring)`**: Cuenta cuántas veces aparece una subcadena en una cadena.

- **`str.capitalize()`**: Devuelve una nueva cadena con el primer carácter en mayúscula y los demás en minúsculas.

- **`str.isupper()`**: Devuelve `True` si todas las letras en la cadena están en mayúsculas y `False` en caso contrario.

- **`str.islower()`**: Devuelve `True` si todas las letras en la cadena están en minúsculas y `False` en caso contrario.

- **`str.title()`**: Devuelve una nueva cadena con la primera letra de cada palabra en mayúscula.

- **`str.maketrans()`**: Este método se usa para crear una tabla de mapeo de caracteres de uno a uno para la traducción. A menudo se usa con el método `translate()` que aplica esa tabla a una cadena y devuelve el resultado traducido.

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc'.translate(trans_table)
print(result)  # 123123
```

## Trabajar con funciones

- **Definición**: Las funciones son fragmentos reutilizables de código que reciben entradas (argumentos) y devuelven una salida. Para llamar a una función, debes referenciar el nombre de la función seguido de un par de paréntesis:

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

Si una función no devuelve explícitamente un valor, entonces el valor de retorno predeterminado es `None`.

También puedes proporcionar valores predeterminados a los parámetros así:

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```

Si llamas a la función sin el número correcto de argumentos, obtendrás un `TypeError`.

## Ámbito en Python

Python tiene reglas adicionales de ámbito. Por ahora, enfócate en el ámbito local y global.

- **Ámbito local**: Una variable creada dentro de una función solo puede usarse dentro de esa función. Los parámetros de función también son variables locales.

- **Ámbito global**: Una variable creada fuera de una función puede usarse tanto dentro como fuera de las funciones.

- **No igual (`!=`)**: Verifica si dos valores no son iguales.

- **Mayor estrictamente que (`>`)**: Verifica si un valor es mayor que otro.

- **Menor estrictamente que (`<`)**: Verifica si un valor es menor que otro.

## Trabajar con sentencias `if`, `elif` y `else`

- **Sentencias `if`**: Son condiciones usadas para determinar si algo es verdadero o no. Si la condición evalúa a `True`, ese bloque de código se ejecutará.

- **Cláusula `elif`**: Estas son condiciones que vienen después de una sentencia `if`. Un bloque `elif` se ejecuta solo si todas las condiciones anteriores evalúan a `False` y su propia condición evalúa a `True`.

- **Cláusula `else`**: Se ejecuta si ninguna otra condición evalúa a `True`.

```py
age = 12

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')
else:
    print('You are a child')  # You are a child
```

También puedes anidar una sentencia `if` dentro de otro bloque condicional.

## Valores truthy y falsy

- **Definición**: En Python, cada valor tiene un valor booleano inherente, o un sentido integrado de si debe tratarse como `True` o `False` en un contexto lógico. Muchos valores se consideran truthy, es decir, evalúan a `True` en un contexto lógico. Otros son falsy, lo que significa que evalúan a `False`.

Los ejemplos incluyen `None`, `False`, `0`, `0.0` y la cadena vacía `''`.

Otros valores como números distintos de cero y cadenas no vacías son truthy.

## Trabajar con la función `bool()`

- **Definición**: Si quieres verificar si un valor es truthy o falsy, puedes usar la función integrada `bool()`. Convierte explícitamente un valor a su equivalente booleano y devuelve `True` para valores truthy y `False` para valores falsy.

## Operadores booleanos y evaluación corta

- **Definición**: Son operadores especiales que te permiten combinar múltiples expresiones para crear lógica de decisión más compleja en tu código. Hay tres operadores booleanos en Python: `and`, `or` y `not`.
- **Operador `and`**: Este operador toma dos operandos y devuelve el primer operando si es falsy, de lo contrario, devuelve el segundo operando. Ambos operandos deben ser truthy para que la expresión resulte en un valor truthy.

También puedes usar el operador `and` en condicionales.

- **Operador `or`**: Este operador devuelve el primer operando si es truthy, de lo contrario, devuelve el segundo operando. Una expresión `or` resulta en un valor truthy si al menos un operando es truthy.

Al igual que con el operador `and`, puedes usar el operador `or` en condicionales.

- **Cortocircuito**: Los operadores `and` y `or` son conocidos como operadores de cortocircuito. Cortocircuito significa que Python verifica los valores de izquierda a derecha y se detiene tan pronto como determina el resultado final.
- **Operador `not`**: Este operador toma un solo operando e invierte su valor booleano. Convierte valores truthy en `False` y valores falsy en `True`. A diferencia de los operadores anteriores, `not` siempre devuelve `True` o `False`.

El operador `not` también puede usarse en un condicional.

## Listas en Python

- **Introducción**: En Python, el tipo de dato lista es una secuencia ordenada de elementos que pueden ser cadenas, números o incluso otras listas. Las listas son mutables y tienen índice basado en cero.

Por ejemplo, `cities = ['Los Angeles', 'London', 'Tokyo']` crea una lista de cadenas.

- **Acceder a elementos en una lista**: Para acceder a un elemento de la lista `cities`, referencia su índice, como `cities[0]` para `'Los Angeles'`.

- **Acceder a elementos usando índices negativos**: Para acceder al último elemento de cualquier lista, puedes usar `-1` como número de índice.

- El índice negativo se usa para acceder a elementos comenzando desde el final de la lista en lugar del principio en el índice `0`.

- **Crear listas usando el constructor `list()`**: Las listas también pueden crearse usando el constructor `list()`. El constructor `list()` se usa para convertir un iterable en una lista.

- **Encontrar la longitud de una lista**: Puedes usar la función `len()` para obtener la longitud de una lista.

- **Mutabilidad de listas**: Las listas son mutables, lo que significa que puedes actualizar cualquier elemento en la lista siempre que pases un número de índice válido. Para actualizar listas en un índice particular, puedes asignar un nuevo valor a ese índice.

- **Error de índice fuera de rango**: Si pasas un índice (positivo o negativo) que está fuera de los límites de la lista, recibirás un `IndexError`.

- **Eliminar elementos de una lista**: Los elementos pueden eliminarse de una lista usando la palabra clave `del`.

- **Verificar si un elemento existe en una lista**: La palabra clave `in` puede usarse para verificar si un elemento existe en una lista.

- **Anidar listas**: Las listas pueden anidarse dentro de otras listas.

- En el siguiente ejemplo, la lista anidada está en el índice `2` ya que las listas están basadas en cero.

- Para acceder más a fondo al segundo idioma de esa lista anidada, necesitarás usar el índice `1`:

```python
developer = ['Alice', 25, ['Python', 'Rust', 'C++']]
developer[2][1] # Rust
```

- **Desempaquetar valores de una lista**: Desempaquetar valores de una lista es una técnica usada para asignar valores de una lista a nuevas variables. Aquí un ejemplo para desempaquetar la lista `developer` en nuevas variables llamadas `name`, `age` y `job` así:

```py
developer = ['Alice', 34, 'Rust Developer']
name, age, job = developer
```

- Si el número de variables a la izquierda del operador de asignación no coincide con el total de elementos en la lista, recibirás un `ValueError`.

- **Recolectar elementos restantes de una lista**: Para recolectar cualquier elemento restante de una lista, puedes usar el operador asterisco (`*`) así:

```py
developer = ['Alice', 34, 'Rust Developer']
name, *rest = developer
```

- **Segmentar listas**: La segmentación es el concepto de acceder a una porción de una lista usando el operador de segmento `:`. Por ejemplo, para `desserts = ['cake', 'pie', 'cookies', 'ice cream']`, `desserts[1:3]` devuelve `['pie', 'cookies']`.

- **Intervalos de paso**: También es posible especificar un intervalo de paso que determina cuánto incrementar entre los índices. Por ejemplo, `[1, 2, 3, 4, 5, 6][1::2]` produce `[2, 4, 6]`.

## Métodos de listas

- **append()**: Se usa para agregar un elemento al final de la lista. Por ejemplo, `numbers.append(6)` agrega `6` al final de `numbers`.

- **Agregar listas**: El método `append()` también puede usarse para agregar una lista al final de otra:

```py
numbers = [1, 2, 3, 4, 5]
even_numbers = [6, 8, 10]

numbers.append(even_numbers)
print(numbers) # [1, 2, 3, 4, 5, [6, 8, 10]]
```

- **extend()**: Se usa para agregar múltiples elementos al final de una lista. Aquí un ejemplo de agregar los números `6`, `8` y `10` al final de la lista `numbers`:

```py
numbers = [1, 2, 3, 4, 5]
even_numbers = [6, 8, 10]

numbers.extend(even_numbers)
print(numbers) # [1, 2, 3, 4, 5, 6, 8, 10]
```

- **insert()**: Se usa para insertar un elemento en un índice específico de la lista.

- **remove()**: Se usa para eliminar un elemento de la lista. El método `remove()` solo eliminará la primera aparición de un elemento en la lista.

- **pop()**: Se usa para eliminar un elemento específico de la lista y devolverlo.

- Si no especificas un elemento para el método `pop`, se elimina el último elemento.

- **clear()**: Se usa para eliminar todos los elementos de la lista.

- **sort()**: El método `sort()` se usa para ordenar los elementos en su lugar. Por ejemplo, `numbers.sort()` ordena `numbers` en su lugar.

- **sorted()**: Una función integrada que devuelve una nueva lista ordenada en lugar de modificar la lista original.

- **reverse()**: Se usa para invertir el orden de los elementos en una lista.

- **index()**: Se usa para encontrar el primer índice donde se puede encontrar un elemento en una lista.

- Si el elemento no se puede encontrar usando el método `index()`, el resultado será un `ValueError`.

## Tuplas en Python

- **Definición**: Una tupla es un tipo de dato en Python usado para crear una secuencia ordenada de valores. Las tuplas pueden contener un conjunto mixto de tipos de datos:

Por ejemplo, `developer = ('Alice', 34, 'Rust Developer')`.

- Las tuplas son inmutables, lo que significa que los elementos en la tupla no pueden cambiarse una vez creados. Si intentas actualizar uno de los elementos en la tupla, obtendrás un `TypeError`.

- **Acceder a elementos de una tupla**: Para acceder a un elemento de una tupla, usa la notación de corchetes y el número de índice.

- Se puede usar indexación negativa para acceder a elementos comenzando desde el final de la tupla.

- Si intentas pasar un número de índice que excede o es igual a la longitud de la tupla, recibirás un `IndexError`.

- Una tupla también puede crearse usando el constructor `tuple()`. Dentro del constructor, puedes pasar diferentes iterables como cadenas, listas e incluso otras tuplas.

- **Verificar elementos en una tupla**: Para verificar si un elemento está en una tupla, puedes usar la palabra clave `in`.

- **Desempaquetar tuplas**: Los elementos pueden asignarse a variables separadas, como en `name, age, job = developer`.

- Si necesitas recolectar los elementos restantes de una tupla, puedes usar el operador asterisco (`*`).

- **Segmentar tuplas**: La segmentación puede extraer una porción de una tupla. Por ejemplo, para `desserts = ('cake', 'pie', 'cookies', 'ice cream')`, `desserts[1:3]` devuelve `('pie', 'cookies')`.

- **Eliminar elementos de tuplas**: Eliminar un elemento de una tupla generará un `TypeError` ya que las tuplas son inmutables.

- **¿Cuándo usar una tupla vs una lista?**: Si necesitas una colección dinámica de elementos donde puedas agregar, eliminar y actualizar elementos, debes usar una lista. Si sabes que trabajas con una colección fija e inmutable de datos, debes usar una tupla.

## Métodos comunes de tuplas

- **`count()`**: Se usa para determinar cuántas veces aparece un elemento en una tupla. Por ejemplo, para `programming_languages = ('Rust', 'Java', 'Python', 'Rust')`, `programming_languages.count('Rust')` devuelve `2`.

- Si el elemento especificado en el método `count()` no está presente en la tupla, el valor de retorno será `0`.

- Si no se pasan argumentos al método `count()`, entonces Python devolverá un `TypeError`.

- **index()**: Se usa para encontrar el índice donde un elemento particular está presente en la tupla. Por ejemplo, `programming_languages.index('Java')` encuentra el primer índice de `'Java'`.

- Si no se encuentra el elemento especificado, Python devolverá un `ValueError`.

- Puedes pasar un índice de inicio opcional al método `index()` para especificar dónde comenzar a buscar el elemento en la tupla.

- También puedes pasar un índice de fin opcional al método `index()` para especificar dónde detener la búsqueda del elemento en la tupla.

- **`sorted()`**: Se usa para ordenar los elementos en cualquier iterable y devolver una nueva lista ordenada. Por ejemplo, `sorted(numbers)` devuelve una nueva lista ordenada.

- **Modificar el comportamiento de ordenación**: Puedes personalizar el comportamiento de ordenación para un iterable usando los argumentos opcionales `reverse` y `key`. Por ejemplo, `sorted(programming_languages, key=len)` ordena las cadenas por longitud.

- Puedes crear una nueva lista de valores en orden inverso pasando `reverse=True` a `sorted()`.

## Ciclos en Python

- **Definición**: Los ciclos se usan para repetir un bloque de código un número determinado de veces.

- **Ciclo `for`**: Se usa para iterar sobre una secuencia (como una lista, tupla o cadena) y ejecutar un bloque de código para cada elemento en esa secuencia. Aquí tienes un ejemplo de uso de un ciclo `for` para iterar a través de una lista e imprimir cada lenguaje en la consola:

```py
programming_languages = ['Rust', 'Java', 'Python', 'C++']

for language in programming_languages:
    print(language)

"""
Result

Rust
Java
Python
C++
"""
```

- Un ciclo `for` puede iterar a través de la cadena `'code'` e imprimir cada carácter: `c`, `o`, `d` y `e`.

- Los ciclos `for` pueden anidarse, con un ciclo interno que se ejecuta para cada iteración del ciclo externo.

- **Ciclo `while`**: Repite un bloque de código hasta que la condición sea `False`. Aquí tienes un ejemplo de uso de un ciclo `while` para un juego de adivinanzas:

```py
secret_number = 3
guess = 0

while guess != secret_number:
    guess = int(input('Guess the number (1-5): '))
    if guess != secret_number:
        print('Wrong! Try again.')

print('You got it!')

"""
Result

Guess the number (1-5): 2
Wrong! Try again.
Guess the number (1-5): 1
Wrong! Try again.
Guess the number (1-5): 3
You got it!
"""

```

- **Sentencias `break` y `continue`**: Se usan en ciclos para modificar la ejecución del ciclo.

- La sentencia `break` se usa para salir del ciclo inmediatamente cuando se cumple cierta condición.

- La sentencia `continue` se usa para saltar la iteración actual y pasar a la siguiente iteración del ciclo.

- Tanto los ciclos `for` como `while` pueden combinarse con una cláusula `else`, que se ejecuta solo cuando el ciclo no fue terminado por un `break`.

## Rangos y su uso en ciclos

- **La función `range()`**: Se usa para generar una secuencia de enteros con la sintaxis `range(start, stop, step)`.

- El argumento obligatorio `stop` es un entero (no inclusivo) que representa el punto final para la secuencia de números que se genera.

- Si no se especifica un argumento `start`, el valor predeterminado será `0`. Por defecto, la secuencia de enteros incrementa en `1`. Puedes usar el argumento opcional `step` para cambiar el valor de incremento predeterminado. Por ejemplo, `range(2, 11, 2)` genera enteros pares desde 2 hasta, pero sin incluir, 11 (es decir, incluye 10).

- Si no proporcionas ningún argumento a la función `range()`, obtendrás un `TypeError`.

- La función `range()` solo acepta enteros como argumentos, no flotantes. Usar flotantes también resultará en un `TypeError`.

- Puedes usar un entero negativo para el argumento `step` para generar una secuencia de enteros en orden decreciente.

- La función `range()` también puede usarse para crear una lista de enteros usándola con el constructor `list`. El constructor `list` se usa para convertir un iterable en una lista. Por ejemplo, `list(range(2, 11, 2))` produce `[2, 4, 6, 8, 10]`.

## Funciones `enumerate()` y `zip()` en Python

- **`enumerate()`**: se usa para iterar sobre una secuencia y llevar un registro del índice para cada elemento en esa secuencia. La función `enumerate()` toma un iterable como argumento y devuelve un objeto `enumerate` que consiste en el índice y valor de cada elemento en el iterable.

```python
languages = ['Spanish', 'English', 'Russian', 'Chinese']

for index, language in enumerate(languages):
    print(f'Index {index} and language {language}')

# Result
# Index 0 and language Spanish
# Index 1 and language English
# Index 2 and language Russian
# Index 3 and language Chinese

```

- La función `enumerate()` también puede usarse fuera de un ciclo `for`.

- La función `enumerate()` también acepta un argumento opcional `start` que especifica el valor inicial para el conteo. Si se omite este argumento, el conteo comenzará en `0`.

- **`zip()`**: se usa para iterar sobre múltiples iterables en paralelo. Aquí tienes un ejemplo usando la función `zip()` para iterar sobre `developers` y `ids`:

```python
developers = ['Naomi', 'Dario', 'Jessica', 'Tom']
ids = [1, 2, 3, 4]

for name, dev_id in zip(developers, ids):
    print(f'Name: {name}')

"""
Result

ID: 1
Name: Dario
ID: 2
Name: Jessica

Name: Tom
ID: 4
"""

```

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

## Funciones para iterables

- **`filter()`**: Se usa para filtrar elementos de un iterable según una condición. Devuelve un iterador que contiene solo los elementos que cumplen la condición. Por ejemplo, una condición de filtrado puede seleccionar palabras con más de cuatro caracteres.

- **`map()`**: Se usa para aplicar una función a cada elemento de un iterable y devolver un nuevo iterable con los resultados. Por ejemplo, la función puede convertir cada temperatura en Celsius de una lista a Fahrenheit.

- **`sum()`**: Se usa para obtener la suma de un iterable como una lista o tupla.

- También puedes pasar un argumento opcional `start` que establece el valor inicial para la suma. Por ejemplo, `sum([5, 10, 15, 20], 10)` devuelve `60`.

- También puedes usar `start` como argumento con palabra clave, como en `sum([5, 10, 15, 20], start=10)`.

## Funciones lambda

- **Definición**: Una función lambda en Python es una forma concisa de crear una función sin nombre (una función anónima).
- Las funciones lambda se usan a menudo como argumento para otra función. Aquí hay un ejemplo de una función lambda:

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

- Las buenas prácticas para usar funciones lambda incluyen no asignarlas a una variable, mantenerlas simples y legibles, y usarlas para funciones cortas y puntuales.

## Diccionarios

- **Diccionarios**: Los diccionarios son estructuras de datos integradas que almacenan colecciones de pares clave-valor. Las claves deben ser tipos de datos inmutables. La sintaxis general es `dictionary = {key1: value1, key2: value2}`.

- **Constructor `dict()`**: El constructor `dict()` es una forma alternativa de construir el diccionario. Pasas una lista de tuplas como argumento al constructor `dict()`. Estas tuplas contienen la clave como primer elemento y el valor como segundo elemento.

- **Notación de corchetes**: Para acceder al valor de un par clave-valor, puedes usar la sintaxis conocida como notación de corchetes.

## Métodos comunes de diccionarios

- **Método `get()`**: El método `get()` recupera el valor asociado con una clave. Es similar a la notación de corchetes, pero permite establecer un valor predeterminado, evitando errores si la clave no existe. La sintaxis es `dictionary.get(key, default)`.

- **Métodos `keys()` y `values()`**: Los métodos `keys()` y `values()` devuelven un objeto vista con todas las claves y valores en el diccionario, respectivamente. Un objeto vista es una forma de ver el contenido de un diccionario sin crear una copia separada de los datos.

- **Método `items()`**: El método `items()` devuelve un objeto vista con todos los pares clave-valor en el diccionario, incluyendo tanto las claves como los valores.

- **Método `clear()`**: El método `clear()` elimina todos los pares clave-valor del diccionario.

- **Método `pop()`**: El método `pop()` elimina el par clave-valor con la clave especificada como primer argumento y devuelve su valor. Si la clave no existe, devuelve el valor predeterminado especificado como segundo argumento. Si la clave no existe y no se especifica valor predeterminado, se genera un `KeyError`.

- **Método `popitem()`**: En Python 3.7 y superiores, el método `popitem()` elimina el último elemento insertado.

- **Método `update()`**: El método `update()` actualiza los pares clave-valor con los pares clave-valor de otro diccionario. Si tienen claves en común, sus valores se sobrescriben. Las claves nuevas se agregan al diccionario como nuevos pares clave-valor.

## Iterar sobre un diccionario

- **Iterar sobre valores**: Si necesitas iterar sobre los valores en un diccionario, puedes escribir un ciclo `for` con `values()` para obtener todos los valores de un diccionario.

```python
products = {
    'Laptop': 990,
    'Smartphone': 600,
    'Tablet': 250,
    'Headphones': 70,
}

for price in products.values():
    print(price)
```

- **Iterar sobre claves**: Si necesitas iterar sobre las claves en el diccionario `products` anterior, puedes escribir `products.keys()` o `products` directamente.

- **Iterar sobre pares clave-valor**: Si necesitas iterar sobre las claves y sus valores correspondientes simultáneamente, puedes iterar sobre `products.items()`. Obtienes tuplas individuales con las claves y sus valores correspondientes.

Para almacenar la clave y el valor en variables separadas del ciclo, debes separarlas con una coma. La primera variable almacena la clave y la segunda almacena el valor.

```python
for product, price in products.items():
    print(product, price)
```

- **Función `enumerate()`**: Si necesitas iterar sobre un diccionario mientras llevas un contador, puedes llamar a la función `enumerate()`. La función devuelve un objeto `enumerate`, que asigna un entero a cada elemento, como un contador. Puedes iniciar el contador desde cualquier número, pero por defecto comienza en 0.

Asignar el índice y el elemento a variables separadas en el ciclo es la forma común de usar `enumerate()`. Por ejemplo, `for index, (product, price) in enumerate(products.items()):` desempaqueta el contador y cada par clave-valor.

Para personalizar el valor inicial del conteo, puedes pasar un segundo argumento a `enumerate()`. Por ejemplo, `enumerate(products.items(), 1)` inicia el conteo en 1.

## Conjuntos

- **Conjuntos**: Los conjuntos son estructuras de datos integradas en Python que no permiten valores duplicados. Los conjuntos son mutables y no ordenados, lo que significa que sus elementos no se almacenan en un orden específico, por lo que no puedes usar índices o claves para acceder a ellos. Además, los conjuntos solo pueden contener valores de tipos de datos inmutables, como números, cadenas y tuplas.

- **Definir un conjunto**: Para definir un conjunto, debes escribir sus elementos dentro de llaves y separarlos con comas.

Por ejemplo, `numbers = {1, 2, 3, 4}`.

- **Definir un conjunto vacío**: Si necesitas definir un conjunto vacío, debes usar la función `set()`. Solo escribir llaves vacías creará automáticamente un diccionario.

## Métodos comunes de conjuntos

- **Método `add()`**: Puedes agregar un elemento a un conjunto con el método `add()`, pasando el nuevo elemento como argumento.

- **Métodos `remove()` y `discard()`**: Para eliminar un elemento de un conjunto, puedes usar el método `remove()` o el método `discard()`, pasando el elemento que quieres eliminar como argumento. El método `remove()` generará un `KeyError` si el elemento no se encuentra, mientras que el método `discard()` no lo hará.

- **Método `clear()`**: El método `clear()` elimina todos los elementos del conjunto.

## Operaciones matemáticas con conjuntos

- **Métodos `issubset()` e `issuperset()`**: Los métodos `issubset()` y `issuperset()` verifican si un conjunto es un subconjunto o un superconjunto de otro conjunto, respectivamente.

- **Método `isdisjoint()`**: El método `isdisjoint()` verifica si dos conjuntos son disjuntos, es decir, si no tienen elementos en común.

- **Operador unión (`|`)**: El operador unión `|` devuelve un nuevo conjunto con todos los elementos de ambos conjuntos.

- **Operador intersección (`&`)**: El operador intersección `&` devuelve un nuevo conjunto con solo los elementos que los conjuntos tienen en común.

- **Operador diferencia (`-`)**: El operador diferencia `-` devuelve un nuevo conjunto con los elementos del primer conjunto que no están en el otro conjunto.

- **Operador diferencia simétrica (`^`)**: El operador diferencia simétrica `^` devuelve un nuevo conjunto con los elementos que están en el primer o segundo conjunto, pero no en ambos.

- **Operador `in`**: Puedes verificar si un elemento está en un conjunto o no con el operador `in`.

## Biblioteca estándar de Python

- **Biblioteca estándar de Python**: Una biblioteca te ofrece código preescrito y reutilizable, como funciones, clases y estructuras de datos, que puedes usar en tus proyectos. Python tiene una extensa biblioteca estándar con módulos integrados que implementan soluciones estandarizadas para muchos problemas y tareas. Algunos ejemplos de módulos integrados populares son `math`, `random`, `re` (abreviatura de "expresiones regulares") y `datetime`.

## Sentencia import

- **Sentencia import**: Para acceder a los elementos definidos en módulos integrados, usas una sentencia import. Las sentencias import generalmente se escriben al inicio del archivo. Las sentencias import funcionan igual para funciones, clases, constantes, variables y cualquier otro elemento definido en el módulo.

- **Sentencia básica de importación**: Puedes usar la palabra clave `import` seguida del nombre del módulo.

Luego, si necesitas llamar a una función de ese módulo, usarías la notación de punto, con el nombre del módulo seguido del nombre de la función.

Por ejemplo, después de `import math`, `math.sqrt(36)` devuelve la raíz cuadrada de 36.

- **Importar un módulo con un nombre diferente**: Si necesitas importar el módulo con un nombre diferente (también conocido como "alias"), puedes usar `as` seguido del alias al final de la sentencia import. Esto se usa a menudo para nombres largos de módulos o para evitar conflictos de nombres.

Por ejemplo, `import math as m` asigna el alias `m` al módulo `math`.

Luego, puedes acceder a los elementos del módulo usando el alias, como en `m.sqrt(36)`.

- **Importar elementos específicos**: Si no necesitas todo de un módulo, puedes importar elementos específicos usando `from`. En este caso, la sentencia import comienza con `from`, seguido del nombre del módulo, luego la palabra clave `import` y finalmente los nombres de los elementos que quieres importar.

Por ejemplo, `from math import sqrt, sin, cos`.

Luego, puedes usar estos nombres sin el prefijo del módulo en tu script de Python.

Esto es útil, pero puede resultar en conflictos de nombres si ya tienes funciones o variables con el mismo nombre. Tenlo en cuenta al elegir qué tipo de sentencia import quieres usar.

Si necesitas asignar alias a estos nombres, también puedes hacerlo usando la palabra clave `as` seguida del alias.

Por ejemplo, `from math import sqrt as square_root`.

- **Sentencia import con asterisco (`*`)**: El asterisco le dice a Python que quieres importar todo en ese módulo, pero quieres importarlo para no tener que usar el nombre del módulo como prefijo.

Por ejemplo, después de `from math import *`, puedes llamar a `sqrt(36)` sin el prefijo `math`.

Sin embargo, esto generalmente se desaconseja porque puede causar colisiones en el espacio de nombres y dificultar saber de dónde vienen los nombres.

## Errores comunes en Python

- **SyntaxError**: El error que Python lanza cuando tu código no sigue sus reglas de sintaxis. Por ejemplo, el código `print("Hello there"` causará un error de sintaxis con el mensaje `SyntaxError: '(' was never closed`, porque falta un paréntesis de cierre.
- **NameError**: Python lanza un `NameError` cuando intentas acceder a una variable o función que no has definido. Por ejemplo, si tienes la línea `print(username)` en tu código sin haber definido primero una variable `username`, obtendrás un error de nombre con el mensaje `NameError: name 'username' is not defined`.
- **TypeError**: Este es el error que Python lanza cuando realizas una operación con dos o más tipos de datos incompatibles. Por ejemplo, si intentas sumar una cadena con un número, obtendrás el error `TypeError: can only concatenate str (not "int") to str`.
- **IndexError**: Obtendrás un `IndexError` si accedes a un índice que no existe en una lista u otras secuencias como tupla y cadena. Por ejemplo, en una cadena `Hello world`, el índice del último carácter es `10`. Si accedes a un carácter así, `greet = "hello world"; print(greet[11])`, obtendrás un error con el mensaje `IndexError: string index out of range`.
- **AttributeError**: Python lanza este error cuando intentas usar un método o propiedad que no existe en un objeto de ese tipo. Por ejemplo, llamar `.append()` en una cadena como `"hello".append("!")` causará un error con el mensaje `AttributeError: 'str' object has no attribute 'append'`.

## Manejo de excepciones

- **`try...except`**: Se usa para ejecutar un bloque de código que podría generar una excepción. El bloque `try` es donde anticipas que podría ocurrir un error, mientras que el bloque `except` captura una excepción específica y se ejecuta si ese error ocurre.

  También puedes encadenar múltiples bloques `except` para manejar más tipos de excepciones:

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

- **`else` y `finally`**: Estos bloques extienden `try...except`. Si no ocurre ninguna excepción, se ejecuta el bloque `else`. El bloque `finally` siempre se ejecuta sin importar si hubo errores.

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **Objeto excepción**: Esto te permite acceder a la excepción misma para una mejor depuración e imprimir el mensaje de error directo. Para acceder al objeto excepción, debes usar la palabra clave `as`. Aquí tienes un ejemplo:

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **La sentencia `raise`**: Esto te permite lanzar manualmente una excepción cuando se cumple una determinada condición, como `raise ValueError("Invalid value")`.

## Señalización de excepciones

  La sentencia `raise` también puede lanzar excepciones personalizadas con un mensaje personalizado. Define una excepción personalizada creando una clase que herede de `Exception`.

  Maneja una excepción personalizada con un bloque `except` nombrando esa clase de excepción.

  La sentencia `raise` también puede usarse con la palabra clave `from` para encadenar excepciones, mostrando la relación entre diferentes errores:

  ```py
  def parse_config(filename):
    try:
        with open(filename, 'r') as file:
            data = file.read()
            return int(data)
    except FileNotFoundError:
        raise ValueError('Configuration file is missing') from None
    except ValueError as e:
        raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```

- **Creación de objetos**: Los objetos son instancias de una clase. Se crean llamando a la clase con los argumentos necesarios.

- **Llamar métodos en objetos**: Puedes llamar métodos en objetos para realizar acciones o recuperar información.

- **Diferencia entre clase y objeto**: Una clase es una plantilla reutilizable, mientras que un objeto es una instancia específica de esa clase con datos reales.

## Atributos

- **Atributos de instancia**: Definidos en `__init__()` usando `self`, y únicos para cada objeto.
- **Atributos de clase**: Definidos directamente dentro de la clase y compartidos por todas las instancias.

## Métodos

- **Métodos**: Funciones definidas dentro de una clase que operan sobre los atributos del objeto.

- **Acceder a métodos**: Llama a métodos en objetos usando la notación de punto. Por ejemplo, para `dog = Dog('Jack', 3)`, `dog.bark()` llama al método `bark` en `dog`.

## Métodos dunder (mágicos)

- **Definición**: Métodos especiales que comienzan y terminan con doble guion bajo (por ejemplo, `__init__`, `__len__`, `__str__`, `__eq__`). Python los usa internamente para operaciones integradas.

- **Llamar métodos dunder indirectamente**: No necesitas llamar a métodos dunder directamente. En cambio, Python los llama automáticamente cuando ocurren ciertas acciones. Estas operaciones incluyen:

  - **operaciones aritméticas como suma, resta, multiplicación, división y otras**. `__add__()` se llama para suma, `__sub__()` para resta, `__mul__()` para multiplicación y `__truediv__()` para división.

  - **operaciones con cadenas como concatenación, repetición, formato y conversión a texto**. `__add__()` se llama para concatenación, `__mul__()` para repetición, `__format__()` para formato, `__str__()` y `__repr__()` para conversión a texto, y así sucesivamente.

  - **operaciones de iteración como hacer que un objeto sea iterable y avanzar a través de los elementos**. `__iter__()` se llama para devolver un iterador y `__next__()` para obtener el siguiente elemento.

## ¿Qué es la programación orientada a objetos?

- **Programación orientada a objetos**: Un estilo de programación en el que los desarrolladores tratan todo en su código como un objeto del mundo real. Popularmente se llama OOP. Los cuatro principios clave que te ayudan a organizar y manejar el código eficazmente son **encapsulación**, **herencia**, **polimorfismo** y **abstracción**.
- **Clases**: La plantilla para crear objetos. Cada objeto creado a partir de una clase tiene atributos que definen datos y métodos que determinan el comportamiento del objeto.

## ¿Qué es la encapsulación?

- **Encapsulación**: La agrupación de los atributos y métodos de un objeto en una sola unidad. Permite ocultar el estado interno del objeto detrás de un conjunto simple de métodos y atributos públicos que actúan como puertas. Detrás de esas puertas hay atributos y métodos privados que controlan cómo cambian los datos y quién puede verlos.
- **Ejemplo de encapsulación**: Si quieres rastrear el saldo de una billetera, permitirás depósitos y retiros, pero no querrás que nadie manipule directamente el saldo de la billetera.

- **Diferencia entre prefijar atributos con un guion bajo simple y doble**: Prefijar atributos y métodos con un guion bajo simple significa que están destinados para uso interno. Esto es una convención y no impide acceder a los atributos desde afuera. Prefijar atributos y métodos con doble guion bajo evita efectivamente que se acceda a ellos desde fuera de su clase.

## ¿Qué son getters y setters?

- **Getters y setters**: Métodos que te permiten controlar cómo se accede y modifica a los atributos de una clase. Recuperas valores con getters y asignas valores con setters.
- **Propiedades**: Conectan getters y setters, y permiten el acceso a datos. Ejecutan lógica adicional detrás de escena cuando obtienes, asignas o eliminas valores.
- **Por qué usar propiedades en lugar de métodos**: Las propiedades se usan en lugar de métodos para mejorar la legibilidad y mantener el código limpio. Permiten acceder a valores con notación de punto, como atributos regulares, sin paréntesis.
- **Crear un getter**: Para crear un getter, usas el decorador `@property`. El getter `radius` en el ejemplo a continuación devuelve el valor interno `_radius`.

- **Crear un setter**: Para crear el setter que asignará el radio, debes definir otro método con el mismo nombre y usar `@<property_name>.setter` encima:

```py
class Circle:
    def __init__(self, radius):
        self.radius = radius # Calling the setter

    @property
    def radius(self):  # A getter to get the radius
        return self._radius

    @radius.setter
    def radius(self, value):  # A setter to set the radius
        if value <= 0:
            raise ValueError('Radius must be positive')
        self._radius = value

my_circle = Circle(3)
print('Initial radius:', my_circle.radius) # Initial radius: 3

my_circle.radius = 8
print('After modifying the radius:', my_circle.radius) # After modifying the radius: 8
```

- **Cómo Python maneja getters y setters**: Una vez que defines getters y setters, Python los llama automáticamente cuando usas la sintaxis normal de atributos. Leer `my_circle.radius` llama al getter; asignar `my_circle.radius = 4` llama al setter.

Dentro del setter, no debes asignar al nombre de la propiedad directamente porque eso causará un `RecursionError`.

- **Deleter**: Después de asignar y obtener un valor con setter y getter, puedes controlar cómo se elimina con un `deleter`. Un deleter ejecuta lógica personalizada cuando usas la sentencia `del` en una propiedad. Para crear un deleter, usas el decorador `@<property_name>.deleter`.

## ¿Qué es la herencia y cómo promueve la reutilización de código?

- **Herencia**: El proceso por el cual una clase hija usa los atributos y métodos de una clase padre. La herencia promueve la reutilización de código, proporciona jerarquías claras y personaliza el comportamiento sin reescribir todo. Para implementar herencia, una clase hija recibe el nombre de una clase padre:

Por ejemplo, `class Child(Parent):` inicia la definición de una clase hija.

- **Herencia simple y múltiple**: Cuando una clase hija hereda propiedades y métodos de un solo padre, el proceso se llama **herencia simple**. Cuando una clase hija hereda propiedades y métodos de más de un padre, eso es **herencia múltiple**.

Por ejemplo, `class Child(Parent1, Parent2):` hereda de dos clases padre.

- **Función `super()`**: Una función que te permite **llamar** un método de una clase padre, cuando una clase tiene una implementación diferente de ese método o extiende el método, sin duplicar código.

## ¿Qué es el polimorfismo y cómo promueve la reutilización de código?

- **Polimorfismo**: El principio de POO que permite que diferentes clases usen el mismo nombre de método, pero cada clase lo implementa de forma diferente cuando se llama.

- **Polimorfismo basado en herencia**: Un padre define un método, y cada clase hija lo adapta a su uso.

## ¿Qué es el name mangling y cómo funciona?

- **Name mangling**: Un proceso en el que Python renombra internamente un atributo con prefijo de doble guion bajo agregando un guion bajo y el nombre de la clase como prefijo, convirtiendo `__attribute` en `_ClassName__attribute`.
- **El propósito del name mangling**: El propósito principal es evitar la sobrescritura accidental de atributos y métodos cuando usas herencia.

## ¿Qué es la abstracción y cómo ayuda a mantener organizados sistemas complejos?

- **Abstracción**: Un concepto de programación en el que se ocultan los detalles complejos de implementación de un objeto o sistema y solo se muestran las funcionalidades esenciales. En Python y otros lenguajes, la abstracción simplifica sistemas complejos aumentando la reutilización.
- **Ejemplo de abstracción**: Un buen ejemplo en la vida diaria es un coche que te permite usar solo el volante, los pedales y la palanca sin saber cómo funcionan el motor o los frenos.
- **Cómo Python implementa la abstracción**: Python implementa la abstracción a través del módulo `abc`. El módulo proporciona la clase `ABC` (clase base abstracta) y el decorador `@abstractmethod`. Una clase base abstracta (ABC) define los métodos y propiedades comunes que las subclases deben implementar. No puede ser instanciada.
- **Cómo se define un método abstracto**: Un método abstracto se define con `@abstractmethod` y debe ser sobrescrito en las subclases, incluso si tiene una implementación predeterminada. La sintaxis básica de la abstracción es así:

```py
from abc import ABC, abstractmethod

# Define an abstract base class
class AbstractClass(ABC):
    @abstractmethod
    def abstract_method(self):
        pass

# Concrete subclass that implements the abstract method
class ConcreteClassOne(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassOne')

# Another concrete subclass
class ConcreteClassTwo(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassTwo')
```

## Algoritmos y notación Big O

- **Algoritmos**: Un conjunto de instrucciones claras para resolver un problema o realizar una tarea. Los algoritmos deben terminar en un número finito de pasos y cada paso debe ser preciso y sin ambigüedades.

- **Notación Big O**: Describe el rendimiento en el peor caso, o la tasa de crecimiento, de un algoritmo a medida que aumenta el tamaño de la entrada. Se enfoca en cómo crece el uso de recursos con el tamaño de la entrada, ignorando factores constantes y términos de orden inferior.

### Complejidades de tiempo comunes

- **O(1) - Tiempo constante**: El algoritmo toma el mismo tiempo sin importar el tamaño de la entrada.

- **O(log n) - Tiempo logarítmico**: El tiempo crece lentamente a medida que la entrada crece. Común en algoritmos que reducen repetidamente el tamaño del problema por una fracción (como la búsqueda binaria).

- **O(n) - Tiempo lineal**: El tiempo de ejecución crece proporcionalmente al tamaño de la entrada.

- **O(n log n) - Tiempo log-lineal**: Complejidad común de algoritmos eficientes de ordenamiento como merge sort y quick sort.

- **O(n²) - Tiempo cuadrático**: El tiempo de ejecución crece cuadráticamente. Frecuente en ciclos anidados.

### Complejidad espacial

- **O(1) - Espacio constante**: El algoritmo usa la misma cantidad de memoria sin importar el tamaño de la entrada.
- **O(n) - Espacio lineal**: El uso de memoria crece proporcionalmente con el tamaño de la entrada.
- **O(n²) - Espacio cuadrático**: El uso de memoria crece cuadráticamente con el tamaño de la entrada.

## Técnicas para resolver problemas

- **Entender el problema**: Lee la declaración del problema varias veces. Identifica la entrada, la salida esperada y cómo transformar la entrada en salida.

- **Pseudocódigo**: Descripción de alto nivel de la lógica del algoritmo que es independiente del lenguaje. Usa lenguaje común mezclado con estructuras de programación como `IF`, `ELSE`, `FOR`, `WHILE`.

- **Casos límite**: Entradas específicas y válidas que ocurren en los límites de lo que un algoritmo debe manejar. Siempre considera y prueba casos límite.

## Arreglos

- **Arreglos estáticos**: Tienen un tamaño fijo determinado en la inicialización. Los elementos se almacenan en ubicaciones de memoria adyacentes. El tamaño no puede cambiar durante la ejecución del programa.

- **Arreglos dinámicos**: Pueden crecer o reducirse automáticamente durante la ejecución del programa. Manejan el cambio de tamaño mediante copias automáticas a arreglos más grandes cuando es necesario.

### Listas en Python (arreglos dinámicos)

Las listas de Python son arreglos dinámicos. Puedes acceder y actualizar elementos por índice, agregar elementos con `append()` o `insert()`, y eliminar elementos con `pop()` o `remove()`.

### Complejidades de tiempo para arreglos dinámicos

- **Acceso**: O(1)
- **Insertar al final**: O(1) promedio, O(n) cuando se necesita redimensionar
- **Insertar en medio**: O(n)
- **Eliminar**: O(n) para medio, O(1) para final

## Pilas

- **Pilas**: Estructura de datos LIFO (último en entrar, primero en salir). Los elementos se agregan y eliminan solo desde la cima.

- **Operación push**: Agregar un elemento a la cima de la pila. Complejidad de tiempo: O(1).

- **Operación pop**: Eliminar un elemento de la cima de la pila. Complejidad de tiempo: O(1).

Una lista de Python puede funcionar como una pila usando `append()` para apilar un elemento y `pop()` para eliminar el elemento superior.

## Colas

- **Colas**: Estructura de datos FIFO (primero en entrar, primero en salir). Los elementos se agregan al final y se eliminan del frente.

- **Operación enqueue**: Agregar un elemento al final de la cola. Complejidad de tiempo: O(1).

- **Operación dequeue**: Eliminar un elemento del frente de la cola. Complejidad de tiempo: O(1).

Un `deque` del módulo `collections` puede funcionar como una cola usando `append()` para encolar y `popleft()` para desencolar.

## Listas enlazadas

- **Listas enlazadas**: Estructura de datos lineal donde cada nodo contiene datos y una referencia al siguiente nodo. Los nodos están conectados como una cadena.

### Listas enlazadas simples

- **Estructura**: Cada nodo tiene datos y una referencia al siguiente nodo.
- **Recorrido**: Solo se puede avanzar desde la cabeza hasta la cola.
- **Nodo cabeza**: Primer nodo en la lista, usualmente el único nodo accesible directamente.
- **Nodo cola**: Último nodo en la lista, apunta a `None`.

### Operaciones y complejidades de tiempo

- **Insertar al inicio**: O(1)
- **Insertar al final**: O(n) - se debe recorrer hasta el final
- **Insertar en medio**: O(n) - se debe recorrer hasta la posición
- **Eliminar al inicio**: O(1)
- **Eliminar al final**: O(n) - se debe recorrer para encontrar el nodo anterior
- **Eliminar en medio**: O(n) - se debe recorrer para encontrar el nodo

### Listas doblemente enlazadas

- **Estructura**: Cada nodo tiene datos y dos referencias: al siguiente nodo y al nodo anterior.
- **Recorrido**: Se puede mover en ambas direcciones.
- **Memoria**: Requiere más memoria que las listas enlazadas simples debido a la referencia extra.

## Mapas hash y conjuntos

### Mapas y mapas hash

- **Mapa (tipo abstracto de datos)**: Maneja colecciones de pares clave-valor. Cada clave debe ser única, pero los valores pueden repetirse.

- **Mapa hash**: Implementación concreta del mapa usando la técnica de hashing. Usa una función hash para generar valores hash para las claves, que determinan la ubicación de almacenamiento en un arreglo subyacente.

### Diccionarios en Python (mapas hash)

Los diccionarios de Python implementan mapas hash. Usa claves para acceder, actualizar o eliminar valores, y `in` para verificar si una clave existe.

### Complejidades de tiempo para mapas hash

- **Caso promedio**: O(1) para insertar, obtener, eliminar
- **Peor caso**: O(n) cuando ocurren muchas colisiones de hash

### Conjuntos

- **Conjuntos**: Colecciones no ordenadas de elementos únicos. No permiten duplicados ni mantienen un orden específico.

- **Solo elementos inmutables**: Los conjuntos solo pueden contener tipos de datos inmutables (números, cadenas, tuplas) porque los valores hash deben permanecer constantes.

### Complejidades de tiempo para conjuntos

- **Caso promedio**: O(1) para agregar, eliminar, probar membresía
- **Peor caso**: O(n) debido a colisiones de hash

## Colisiones de hash

- **Colisión de hash**: Ocurre cuando dos claves diferentes producen el mismo valor hash.

- **Estrategias para resolver colisiones**:
  - **Encadenamiento**: Cada índice del arreglo apunta a una lista enlazada que almacena todos los elementos con el mismo valor hash.
  - **Dirección abierta**: Busca el siguiente índice disponible usando una secuencia predefinida.

## Cuándo usar cada estructura de datos

- **Listas**: Cuando necesitas acceso ordenado e indexado y no conoces el tamaño de antemano.
- **Pilas**: Para operaciones LIFO (funcionalidad de deshacer, evaluación de expresiones, retroceso).
- **Colas**: Para operaciones FIFO (planificación de tareas, búsqueda en anchura).
- **Listas enlazadas**: Cuando hay inserciones/eliminaciones frecuentes al inicio, tamaño desconocido, no se necesita acceso aleatorio.
- **Mapas hash**: Para búsquedas rápidas clave-valor, conteo de ocurrencias, caché.
- **Conjuntos**: Para verificar unicidad, operaciones matemáticas de conjuntos, eliminar duplicados.

## Recursión

- La recursión es un concepto de programación que te permite llamar a una función repetidamente hasta que se alcanza un caso base.

Aquí tienes un ejemplo de una función recursiva que calcula el factorial de un número:

```py
def find_factorial(n):
    if n == 0:
        return 1
    return n * find_factorial(n - 1)
```

En el ejemplo anterior, la función `find_factorial` se llama recursivamente hasta que `n` llega a `0`. Cuando `n` es `0`, se alcanza el caso base y la función devuelve `1`. Luego la función devuelve el producto de `n` y el resultado de la llamada recursiva a `find_factorial(n - 1)`.

- La recursión te permite manejar algo con una profundidad desconocida, como diccionarios y listas profundamente anidados, o un árbol de archivos.
- Se usa una pila de llamadas para llevar el control de las llamadas a funciones en una función recursiva. Cada vez que se llama a una función, se agrega a la pila de llamadas. Cuando se alcanza el caso base, las llamadas a funciones se eliminan de la pila.
- Debes definir cuidadosamente el caso base. De lo contrario, la función puede seguir llamándose a sí misma hasta que Python lance un `RecursionError`.
- La recursión es útil para resolver problemas matemáticos como factorial y Fibonacci, recorrer árboles y grafos, y generar permutaciones y combinaciones.

## Algoritmos de búsqueda

Los algoritmos de búsqueda te permiten buscar un objetivo dentro de una lista determinada de elementos.

En ciencias de la computación, hay dos algoritmos de búsqueda que debes conocer. Son los algoritmos de **búsqueda lineal** y **búsqueda binaria**. Es importante entender las diferencias entre los dos algoritmos y cuándo usar cada uno.

### Búsqueda Lineal

- La búsqueda lineal itera a través de una lista de elementos, revisando cada elemento desde el principio hasta que se encuentra el elemento objetivo.
- Si se encuentra el elemento objetivo, se devuelve el índice donde está ubicado en la lista.
- Si no se encuentra el objetivo, devuelve `-1`, lo que significa **índice inválido** en la mayoría de los lenguajes de programación.
- Debido a que la búsqueda lineal revisa cada elemento hasta encontrar el objetivo, no es eficiente para una lista grande de elementos.
- La complejidad temporal de la búsqueda lineal es `O(n)` porque el tiempo que tarda en buscar en la lista crece linealmente con el tamaño de la lista.
- La complejidad espacial de la búsqueda lineal es `O(1)` porque no requiere espacio adicional para buscar en la lista.

### Búsqueda Binaria

- La búsqueda binaria funciona dividiendo una lista de elementos a la mitad y verificando si el valor objetivo está en el medio de la lista.
- La condición para que la búsqueda binaria funcione es que los elementos en la lista estén ordenados, ya sea en orden ascendente o descendente.
- La búsqueda binaria es un algoritmo más eficiente para buscar en una lista grande de elementos porque divide la lista de elementos a la mitad e ignora cualquier mitad donde no se encuentre el objetivo.
- Si el elemento objetivo se encuentra en medio de la lista, se devuelve el índice del elemento objetivo.
- Si el elemento no se encuentra, el algoritmo verifica si el elemento objetivo está en la mitad izquierda o derecha de la lista.
- Continúa dividiendo las partes restantes de la lista en mitades hasta que se encuentre el elemento objetivo.
- Si el elemento objetivo finalmente no se encuentra en la lista, devuelve `-1`
- La complejidad temporal de la búsqueda binaria es `O(log n)` porque el tiempo que tarda en buscar en la lista crece logarítmicamente con el tamaño de la lista.
- La complejidad espacial de la búsqueda binaria es `O(1)` porque no requiere espacio adicional para buscar en la lista.

### Cómo la búsqueda lineal difiere de la búsqueda binaria

- La búsqueda binaria es más adecuada para una lista grande de elementos en comparación con la búsqueda lineal.
- La complejidad temporal de la búsqueda lineal es `O(n)` porque el tiempo que tarda en buscar en la lista crece linealmente con el tamaño de la lista.
- La complejidad temporal de la búsqueda binaria es `O(log n)` porque el tiempo que tarda en buscar en la lista crece logarítmicamente con el tamaño de la lista.

## Algoritmos de ordenamiento y divide y vencerás

En ciencias de la computación, divide-and-conquer es una técnica usada para descomponer un problema en subproblemas más pequeños para que sean más fáciles de resolver. La recursión es la técnica que se emplea frecuentemente en divide-and-conquer, y divide-and-conquer es una estrategia poderosa usada para implementar muchos algoritmos de ordenamiento eficientes como merge sort.

### Ordenamiento por mezcla

- Merge sort es un algoritmo de ordenamiento que sigue el enfoque de divide y vencerás.
- Funciona dividiendo recursivamente una lista en sublistas más pequeñas hasta que cada sublista contiene solo un elemento.
- Luego fusiona repetidamente las sublistas de nuevo en un orden ordenado.
- La complejidad temporal de merge sort es `O(n log n)` porque la lista se divide continuamente a la mitad `(log n)` y luego se combina `(O(n))`.
- La complejidad espacial de merge sort es `O(n)` porque no es un algoritmo de ordenamiento in-place.

## Resumen de grafos

Un grafo es un conjunto de nodos (vértices) conectados por aristas (conexiones). Cada nodo puede conectarse a múltiples otros nodos, formando una red. Los diferentes tipos de grafos incluyen:

- Dirigido: las aristas tienen dirección (de un nodo a otro), a menudo representadas con líneas rectas y flechas.
- No dirigido: las aristas no tienen dirección, representadas con líneas simples.
- Vértice: cada nodo está asociado con una etiqueta o identificador.
- Cíclico: contiene ciclos (un camino que comienza y termina en el mismo nodo).
- Acíclico (DAG): no contiene ciclos.
- Etiquetado en aristas: cada arista tiene una etiqueta usualmente dibujada junto a la arista correspondiente.
- Ponderado: las aristas tienen pesos (valores) asociados que pueden usarse para realizar operaciones aritméticas.
- Desconectado: contiene dos o más nodos que no están conectados por ninguna arista.

Los grafos se usan en varias aplicaciones como mapas, redes, sistemas de recomendación, resolución de dependencias.

## Recorridos en grafos

Esto implica visitar todos los nodos en un grafo. Los dos algoritmos principales son:

- **Búsqueda en anchura (BFS)**
  - Usa una cola.
  - Explora nivel por nivel.
  - Encuentra el camino más corto en grafos no ponderados.

- **Búsqueda en profundidad (DFS)**
  - Usa una pila (o recursión).
  - Explora una rama completamente antes de retroceder.
  - Útil para detección de ciclos y búsqueda de caminos.

## Representaciones de grafos

Los grafos pueden representarse de dos formas principales:

- **Lista de adyacencia**
  - Cada nodo tiene una lista de sus vecinos.
  - Eficiente en espacio para grafos dispersos.
  - Fácil para iterar sobre vecinos.

- **Matriz de adyacencia**
  - Un arreglo 2D donde filas y columnas representan nodos.
  - Consume mucho espacio para grafos grandes.
  - Rápido para verificar si existe una arista entre dos nodos.

## Árboles

Un árbol es un tipo especial de grafo que es acíclico y conectado. Propiedades clave incluyen:

- No tienen ciclos ni bucles (caminos donde el nodo inicial y final son el mismo).
- Deben estar conectados (cada nodo puede alcanzarse desde cualquier otro nodo).

### Tipos comunes de árboles

Los tipos más comunes de árboles son:

- Árboles binarios
  - Cada nodo tiene como máximo dos hijos, uno izquierdo y uno derecho.

- Árboles de búsqueda binaria (BST)
  - Un árbol binario en el que cada hijo izquierdo es menor que su padre, y cada hijo derecho es mayor que su padre.

## Tries

También conocidos como árboles prefijos, se usan para almacenar conjuntos de cadenas, donde cada nodo representa un carácter.

Los prefijos compartidos se almacenan solo una vez, haciéndolos eficientes para tareas como autocompletar y corrección ortográfica.

Las operaciones de búsqueda e inserción tienen complejidad de tiempo O(L), donde L es la longitud de la cadena.

## Colas de prioridad

Una cola de prioridad es un tipo abstracto de datos donde cada elemento tiene una prioridad.

Las colas y pilas consideran solo el orden de inserción, mientras que las colas de prioridad consideran la prioridad de los elementos.

Las colas estándar siguen FIFO (primero en entrar, primero en salir) y las pilas siguen LIFO (último en entrar, primero en salir). Sin embargo, en una cola de prioridad, los elementos con mayor prioridad se atienden antes que los de menor prioridad, sin importar el orden de inserción.

## Montículos

Es una estructura de datos basada en árboles con una propiedad muy específica llamada propiedad de montículo.

La propiedad de montículo determina la relación entre nodos padre e hijo. Hay dos tipos de montículos:

- Montículo máximo
  - El valor de cada nodo padre es mayor o igual que los valores de sus hijos.
  - El elemento más grande está en la raíz.

- Montículo mínimo
  - El valor de cada nodo padre es menor o igual que los valores de sus hijos.
  - El elemento más pequeño está en la raíz.

### Módulo `heapq` de Python

El módulo `heapq` implementa montículos mínimos usando listas. Usa `heapq.heappush(heap, item)` para insertar un elemento, `heapq.heappop(heap)` para eliminar el elemento más pequeño, y `heapq.heappushpop(heap, item)` para insertar un elemento y luego eliminar el más pequeño. `heapq.heapify(items)` transforma una lista en un montículo en el lugar.

### Uso de prioridades

Almacena tuplas `(priority, item)` en un montículo para ordenar los elementos por prioridad. Los números más bajos se eliminan primero, por lo que `(1, "C")` se atiende antes que `(2, "B")`.

## Introducción a la programación dinámica

- **Definición**: La programación dinámica es una técnica algorítmica que resuelve problemas complejos dividiéndolos en subproblemas más simples y almacenando los resultados para evitar cálculos redundantes.
- **Subproblemas superpuestos**: Los mismos problemas más pequeños aparecen varias veces al resolver el problema mayor. En lugar de recalcular estos subproblemas repetidamente, almacenamos sus soluciones.
- **Subestructura óptima**: La solución óptima al problema contiene soluciones óptimas a sus subproblemas. Esto significa que podemos construir la mejor solución combinando las mejores soluciones a partes más pequeñas.

## Soluciones de programación dinámica

- **Memoización (enfoque de arriba hacia abajo)**: La memoización almacena los resultados de llamadas costosas a funciones y devuelve el resultado en caché cuando ocurren las mismas entradas.

- **Tabulación (enfoque de abajo hacia arriba)**: La tabulación construye la solución desde abajo hacia arriba, llenando una tabla con soluciones a subproblemas.

## Aplicaciones reales usando programación dinámica

- **Optimización de rutas**: Los sistemas GPS usan algoritmos de programación dinámica para encontrar las rutas más cortas entre ubicaciones.
- **Procesamiento de texto**: Los correctores ortográficos y las funciones de autocompletar suelen apoyarse en la programación dinámica para calcular las distancias de edición entre palabras.
- **Modelado financiero**: Las estrategias de inversión y la optimización de portafolios emplean con frecuencia técnicas de programación dinámica.
- **Asignación de recursos**: El problema de la mochila y sus variantes aparecen en la programación de tareas, presupuestos y gestión de recursos.

## Cuándo usar programación dinámica

Deberías considerar usar programación dinámica en los siguientes casos:

- El problema puede dividirse en subproblemas que se superponen.
- El problema presenta una subestructura óptima.
- Una solución recursiva ingenua implicaría cálculos repetidos.
- Necesitas optimizar la complejidad temporal a costa de la complejidad espacial.
