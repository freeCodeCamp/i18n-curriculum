# --description--

트리를 만들어볼 시간입니다. 클래스들을 만든 후, `bst`라는 변수를 만들고 `BinarySearchTree`의 새 인스턴스를 할당하세요. 그런 다음, `nodes`라는 리스트를 만들고 값 `50`, `30`, `20`, `40`, `70`, `60`, `80`을 이 순서대로 넣으세요.

마지막으로, `for` 루프를 사용해 루프 변수로 `node`를 지정하고 `nodes`의 각 값을 `bst`에 삽입하세요.

첫 번째 값인 `50`이 루트가 됩니다. 나머지 값들은 각 노드에서 왼쪽이나 오른쪽으로 가면서 빈 자리를 찾을 때까지 이동하며, 결과적으로 다음과 같은 트리가 만들어집니다:

```md
        50
      /    \
    30      70
   /  \    /  \
  20  40  60  80
```

class TreeNode:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None


class BinarySearchTree:
    def __init__(self):
        self.root = None

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node

    def insert(self, key):
        self.root = self._insert(self.root, key)
