# --description--

성공 상태와 오류 상태를 모두 잘 처리했어요. 그런데 무슨 일이 있든 실행하고 싶은 코드가 있다면 어떻게 할까요? 바로 그럴 때 `finally` 블록을 사용해요.

```js
try {
  // Code that might throw an error
} catch (err) {
  // Code to handle the error
} finally {
  // Code to run regardless of success or failure
}
```

`catch` 블록 바로 아래에 `finally` 블록을 추가하세요. 그 안에서 `bookInput`의 `value` 속성을 빈 문자열(`""`)로 설정해 입력 필드를 지워 사용자가 바로 새 검색어를 입력할 수 있게 하세요.
