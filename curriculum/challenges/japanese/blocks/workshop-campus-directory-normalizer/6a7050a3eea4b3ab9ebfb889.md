# --description--

この時点で、`rawData` は深くネストされています：`departments → programs → instructors`。メールアドレスで講師を見つけるには、各部署をループし、次に各プログラムをループし、最後に各講師をループして一致するものを探す必要があります。

その方法は機能しますが、データが増えると遅くなり、繰り返しが多くなります。

ワークショップの後半で、より効率的な方法であるデータの正規化について学びます。

しかし次の数ステップでは、メールアドレスを引数に取り、ループを使ってネストされた`rawData`構造を検索し、一致するメールアドレスが見つかったら講師の名前を返す関数を作成します。

まずは前のステップの`console.log()`を削除してください。

次に、`getInstructorByEmail`という関数を宣言し、パラメータ名に`email`を使ってください。そして関数からは`null`を返してください。
