# --description--

到目前為止，你對內容的呈現和外觀只有有限的控制。為了改變這一點，你將使用 CSS。

將 CSS 添加到頁面的一種方法是使用 `style` 元素，通常放在 `head` 頁籤內。`style` 標記內的任何 CSS 規則都會套用到整個頁面。以下是一個範例：

```html
<style>
  p {
    color: green;
  }
</style>
```

在 `head` 元素內添加一個 `style` 元素。

# --hints--

你的程式碼應該包含一個 `style` 元素。

```js
assert.exists(document.querySelector('style:not(.fcc-hide-header)'));
```

你的程式碼應該有一個結尾的 `</style>` 頁籤。

```js
assert.match(code, /<\/style\s*>/i);
```

你的 `style` 元素應該巢狀在你的 `head` 元素中。

```js
assert.exists(document.querySelector('head > style:not(.fcc-hide-header)'));
```
