# --description--

`departmentId`를 얻었으니, 이를 사용해 `departmentsById` 안에 학과 데이터를 저장하세요.

`departmentsById[departmentId]`에 다음을 포함하는 객체를 할당하세요:

`id`: `departmentId`로 설정,  
`code`: `departmentData.Dept_code`로 설정,  
`name`: `departmentName`으로 설정  
`programIds`: 빈 배열 (나중 단계에서 채울 예정)

마지막으로 `departmentsById[departmentId]`를 콘솔에 출력하세요.
