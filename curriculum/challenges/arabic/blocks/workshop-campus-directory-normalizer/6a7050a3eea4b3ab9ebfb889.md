# --description--

في هذه المرحلة، `rawData` مسكنة بعمق: `departments → programs → instructors`. للعثور على مدرس عبر البريد الإلكتروني، يجب أن تمر عبر كل قسم، ثم كل برنامج، وأخيرًا كل مدرس حتى تجد تطابقًا.

رغم أن هذه الطريقة تعمل، إلا أنها تصبح بطيئة ومتكررة مع زيادة حجم البيانات.

في وقت لاحق من ورشة العمل، ستتعلم كيفية تطبيع البيانات، وهي طريقة أكثر كفاءة.

لكن في الخطوات القليلة القادمة، ستنشئ دالة تأخذ البريد الإلكتروني كمعلمة، وتستخدم الحلقات للبحث في هيكل `rawData` المسكن، وتُرجع اسم المدرس عند العثور على عنوان بريد إلكتروني مطابق.

ابدأ بحذف `console.log()` من الخطوة السابقة.

ثم أعلن دالة باسم `getInstructorByEmail` واستخدم `email` كاسم للمعلمة. بعد ذلك أرجع `null` من الدالة.

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, "log");
const getLogs = () => globalThis.spy.calls.map(call => call?.[0]);
```

# --after-each--

```js
globalThis.spy.restore();
delete globalThis.spy;
```
