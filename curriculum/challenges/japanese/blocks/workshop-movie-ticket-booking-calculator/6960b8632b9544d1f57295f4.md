# --description--

`18`歳以上で`21`歳未満のユーザーはチケットを予約できますが、`show_time`が`Evening`でない場合に限ります。

不等値演算子（`!=`）は、2つの値が等しくないかどうかをチェックします。値が異なる場合は`True`を返し、同じ場合は`False`を返します。

```py
day = 'Monday'
print(day != 'Sunday') # True
print(day != 'Monday') # False
```

`and`と`or`が同じ式で使われる場合、`and`の方が`or`より優先順位が高いです。つまり、`and`で結合された条件がまとめて評価され、その結果が`or`の条件と組み合わされます。

```py
has_key = True
knows_code = False
is_daytime = False

print(has_key or knows_code and is_daytime) # True
```

上の例では、まず`knows_code and is_daytime`が評価され、その結果は`False`になります。式全体は`has_key or False`となり、結果は`True`です。

`if age >= 21:`行の条件を更新してください。`and`演算子を使って、`age`が`18`以上であり、かつ`show_time`が`Evening`でないかをチェックする式を作成します。その後、`or`演算子を使って、その式と既存の条件を組み合わせてください。新しい変数は作成しないでください。
