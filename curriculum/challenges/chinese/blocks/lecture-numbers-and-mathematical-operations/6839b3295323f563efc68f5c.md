# --description--

你已经用过字串的扩充赋值了。现在，让我们看看它是如何作用于数字的。扩充赋值会执行一个操作，并将结果保存回同一个变量，所有这些都在一步完成。

扩充赋值的基本语法如下所示：

```python
variable <operator>= value
```

对于数值变量，这是编写以下赋值的更简短方式：

```python
variable = variable <operator> value
```

例如，你可以使用扩充赋值为现有变量添加 `5`：

```python
my_var = 10
my_var += 5

print(my_var) # 15
```

这里是相同的内容，但没有使用扩充赋值：

```python
my_var = 10
my_var = my_var + 5

print(my_var) # 15
```

扩充赋值的优点是它提供了一种简洁且易读的方式来更新变量值，而无需重复变量名。反过来，这减少了冗余和可能因拼写错误或类似原因引起的潜在误差。

算术和按位操作符都有扩充赋值形式。我们已经看过加法赋值操作符（`+=`），现在来看其他的。

- 减法赋值操作符（`-=`）将右操作对象从左变量中减去，并将差值保存到左变量中：

```python
count = 14
count -= 3

print(count) # 11
```

- 乘法赋值操作符（`*=`）将左侧变量乘以右侧操作对象，并将乘积保存回左侧变量：
    

```python
product = 65
product *= 7

print(product) # 455
```

- 除法赋值操作符（`/=`）将左侧变量除以右侧变量，并将结果保存回左侧变量：
    

```python
price = 100
price /= 4

print(price) # 25.0
```

- 地板除赋值操作符（`//=`）对左侧变量执行地板除以右侧操作数，并将结果保存回左侧变量：
    

```python
total_pages = 23
total_pages //= 5

print(total_pages) # 4
```

- 取模赋值操作符（`%=`）计算左侧变量除以右侧的余数，并将其保存回左侧变量：
    

```python
bits = 35
bits %= 2

print(bits) # 1
```

- 指数赋值操作符（`**=`）将左侧变量提升到右侧的幂，并将结果保存回左侧变量：
    

```python
power = 2
power **= 3

print(power) # 8
```
