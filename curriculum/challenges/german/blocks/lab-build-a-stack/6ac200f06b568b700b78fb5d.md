# --description--

In diesem Labor implementieren Sie eine Stack-Datenstruktur mithilfe von Funktionen. Ein Stack ist eine Last-In-First-Out-(LIFO-)Datenstruktur, bei der Elemente oben hinzugefügt und entfernt werden.

Ihr Stack wird ein Wörterbuch sein, dessen `collection`-Schlüssel eine Liste von Elementen enthält. Die Spitze des Stacks ist das Ende der Liste, sodass das letzte Element in der Liste das zuletzt hinzugefügte ist.

**Ziel:** Erfüllen Sie die untenstehenden User Stories und bestehen Sie alle Tests, um das Labor abzuschließen.

**User Stories:**

1. Sie sollten eine `init_stack`-Funktion haben, die ein Wörterbuch mit einem `collection`-Schlüssel zurückgibt, der auf eine leere Liste gesetzt ist.
1. Sie sollten eine `push`-Funktion haben, die einen Stack und ein Element entgegennimmt und das Element oben auf den Stack legt.
1. Sie sollten eine `pop`-Funktion haben, die einen Stack entgegennimmt, das oberste Element entfernt und zurückgibt oder `None` zurückgibt, wenn der Stack leer ist.
1. Sie sollten eine `peek`-Funktion haben, die einen Stack entgegennimmt und das oberste Element zurückgibt, ohne es zu entfernen, oder `None`, wenn der Stack leer ist.
1. Sie sollten eine `is_empty`-Funktion haben, die einen Stack entgegennimmt und `True` zurückgibt, wenn er keine Elemente enthält, und sonst `False`.
1. Sie sollten eine `clear`-Funktion haben, die einen Stack entgegennimmt und alle seine Elemente löscht.

**Hinweis:** Die meisten Tests hängen von den Funktionen `init_stack` und `push` ab. Implementieren Sie diese zuerst, da die Tests für `pop`, `peek`, `is_empty` und `clear` das Hinzufügen von Elementen zum Stack voraussetzen.

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
