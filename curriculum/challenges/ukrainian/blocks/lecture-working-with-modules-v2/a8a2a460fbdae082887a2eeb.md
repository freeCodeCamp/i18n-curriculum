# --description--

У розробці програмного забезпечення бібліотека — це як набір інструментів для розробників.

Замість того, щоб реалізовувати кожну частину коду з нуля, бібліотека надає вам заздалегідь написаний і багаторазово використовуваний код, такий як функції, класи та структури даних, які ви можете використовувати у своїх проєктах.

Стандартна бібліотека Python — це колекція модулів і пакетів, які входять до складу Python. Пакети сторонніх розробників створюються окремо і зазвичай їх потрібно встановити перед використанням. Стандартна бібліотека надає рішення для загальних програмних завдань, таких як:

* Взаємодія з операційною системою.

* Робота з файлами.

* Мережеві операції.

* Робота з датою і часом.

* Виконання математичних операцій.

* Використання регулярних виразів.

* Тестування та налагодження вашого коду.

* І багато іншого!

Деякі приклади модулів стандартної бібліотеки — це `math`, `random`, `re` (скорочення від «регулярні вирази») та `datetime`.

Модуль `math` має корисні функції для виконання більш складних математичних операцій.

Модуль `random` допомагає генерувати випадкові числа.

Модуль `re` використовується для роботи з регулярними виразами.

Модуль `datetime` допомагає працювати з датами та часом у Python.

Модулі можуть надавати класи, а також функції та константи. Ось приклад класу з модуля `datetime`. Ми створюємо об’єкт дати, який представляє 15 липня 1959 року. Потім призначаємо цей об’єкт `date` змінній і отримуємо доступ до дня, місяця та року окремо, використовуючи точкову нотацію:

```python
import datetime
birthday = datetime.date(1959, 7, 15)
print(birthday.day)    # 15
print(birthday.month)  # 7
print(birthday.year)   # 1959
```

Щоб знайти модуль для певного завдання, перегляньте [довідник стандартної бібліотеки Python](https://docs.python.org/3/library/index.html), де модулі згруповані за темами. Документація кожного модуля пояснює, що він надає і як його використовувати. Наприклад, [`datetime` документація](https://docs.python.org/3/library/datetime.html) описує класи та методи, доступні для роботи з датами та часом.

Ви також можете використовувати функцію `help()`, щоб відобразити документацію модуля або функції. Зверніть увагу, що `help()` наразі недоступна в редакторі freeCodeCamp.

Наприклад, цей код відображає інформацію про модуль `math`:

```py
import math
help(math)
```

Ви також можете отримати документацію конкретної функції:

```py
import math
help(math.comb)
```

Ось вихідні дані:


Щоб дізнатися, які імена надає модуль, ви можете використати функцію `dir()`. Вона перераховує функції, наприклад `math.floor` для округлення числа вниз, і константи, як-от `math.e` (число Ейлера) та `math.pi`. Вона також перераховує деякі інші імена, про які ви дізнаєтеся пізніше в навчальній програмі:

```py
import math
```

## --answers--

### --feedback--

Функція `help()` відображає документацію, а не повертає список імен.

---

### --feedback--

## --text--

Після імпорту модуля `math`, який вираз відображає документацію саме для функції `math.comb`?

## --answers--

`help(math)`

### --feedback--

Це відображає документацію для всього модуля `math`, а не лише для функції `comb`.

---

`dir(math.comb)`

### --feedback--

Функція `dir()` повертає імена, доступні в об’єкті, а не його документацію.

---

`help(math.comb)`

---

`math.comb.help()`

### --feedback--

Функція `help()` — це вбудована функція Python, а не метод `math.comb`.
