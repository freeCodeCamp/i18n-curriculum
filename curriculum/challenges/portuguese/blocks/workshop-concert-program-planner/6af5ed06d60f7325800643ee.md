# --description--

Para adicionar um item em uma posição específica, você pode usar o método `insert()`. Ele recebe o índice onde o novo item deve ser colocado, seguido pelo próprio item. Os itens a partir desse índice são deslocados uma posição para a direita:

```py
fruits = ['apple', 'banana', 'cherry']
fruits.insert(1, 'blueberry')
print(fruits) # ['apple', 'blueberry', 'banana', 'cherry']
```

O maestro quer que as duas danças eslavas sejam tocadas uma após a outra. Use `insert()` para adicionar a string `Slavonic Dance No. 1` em `pieces`, logo antes de `Slavonic Dance No. 8`.
