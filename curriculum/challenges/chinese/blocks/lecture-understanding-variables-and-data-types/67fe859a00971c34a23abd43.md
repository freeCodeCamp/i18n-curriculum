# --description--

在使用 Python 变量之前，了解数据类型非常重要。数据类型描述了变量所保存的值的种类，例如数字或一段文本。编程语言使用数据类型来知道如何保存和处理不同种类的信息。

Python 是一种动态类型语言。这意味着你在创建变量时不需要指定变量的数据类型。Python 会根据赋值给变量的值来确定类型。

这是一些例子：

```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```

变量以后可以被赋值为不同类型的值：

```python
age = 25
age = 'Twenty-five'
```

第二次赋值后，`age` 包含的是字串而不是整数。

现在，重点关注你将在本模块中使用的四种数据类型：

- 整数：没有小数的整数，例如 `10` 或 `-5`。

```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- 浮点数：带有小数点的数字，例如 `4.41` 或 `-0.4`。

```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- 字串：由单引号或双引号括起来的字符序列，如 `'Hello world!'`。

```python
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- 布尔：一种真或假的类型，写作 `True` 或 `False`。

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python 还有其他数据类型。你将在首次需要时学习每一种。
