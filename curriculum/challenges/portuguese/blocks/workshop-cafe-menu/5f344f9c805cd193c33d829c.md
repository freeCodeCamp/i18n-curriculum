# --description--

Uma regra CSS é composta por duas partes principais: um seletor e um bloco de declarações.

Aqui está a sintaxe básica:

```css
selector {
  property: value;
}
```

Um seletor é um padrão usado em CSS para identificar e direcionar elementos HTML específicos para estilização.

Aqui está um exemplo de como mudar todos os elementos de parágrafo para a cor azul.

```css
p {
  color: blue;
}
```

Centralize o conteúdo do elemento `h1` definindo sua propriedade `text-align` para o valor `center`.

```js
const h1TextAlign = new __helpers.CSSHelp(document).getStyle('h1')?.getPropertyValue('text-align');
assert.equal(h1TextAlign, 'center');
```
