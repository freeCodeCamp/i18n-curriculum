# --description--

사전을 생성하고 그 값을 접근하고 업데이트하는 방법을 배웠습니다. 이제 사전 메서드를 사용하고, 사전을 복사하며, 함수가 사전을 어떻게 변경할 수 있는지 살펴보겠습니다.

아래 각 사전 메서드 예제는 이 사전으로 시작합니다:

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## 딕셔너리 메서드

사전에는 일반적인 작업을 수행하는 데 도움이 되는 메서드도 있습니다.

`.get()` 메서드는 키와 연결된 값을 가져옵니다. 이전 수업에서 배운 대괄호 표기법과 비슷하지만, 키가 존재하지 않을 때 오류가 발생하지 않도록 기본값을 설정할 수 있다는 장점이 있습니다:

```python
dictionary.get(key, default)
```

이 예제에서 `toppings` 키가 없으면 두 번째 인수로 전달한 기본값인 빈 리스트를 반환합니다. 하지만 `toppings`가 있으면 그 값을 반환합니다:

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

`.keys()`와 `.values()` 메서드는 각각 사전의 모든 키와 값을 포함하는 뷰 객체를 반환합니다:

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

뷰 객체는 데이터를 별도로 복사하지 않고 사전 내용을 볼 수 있는 방법일 뿐입니다.

`.items()` 메서드는 키와 값 모두를 포함하는 모든 키-값 쌍의 뷰 객체를 반환합니다:

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

`.clear()` 메서드는 사전에서 모든 키-값 쌍을 제거합니다:

```python
pizza.clear()
```

`.pop()` 메서드는 첫 번째 인수로 지정한 키를 가진 키-값 쌍을 제거하고 그 값을 반환합니다. 키가 없으면 두 번째 인수로 지정한 기본값을 반환합니다. 기본값을 지정하지 않고 키가 없으면 `KeyError`가 발생합니다:

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

Python 3.7 이상 버전에서는 `.popitem()` 메서드가 마지막에 삽입된 항목을 제거합니다:

```python
pizza.popitem()
```

`.update()` 메서드는 다른 사전의 키-값 쌍으로 키-값 쌍을 업데이트합니다. 공통된 키가 있으면 그 값이 덮어써집니다.

이 예제에서는 `pizza` 사전을 업데이트합니다. `price` 키가 두 사전에 모두 있으므로 그 값이 `15`로 교체됩니다.

하지만 `total_time`는 새 키이므로 `pizza` 사전에 새 키-값 쌍으로 추가됩니다:

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

업데이트된 `price`와 새 `total_time`가 포함된 새 사전입니다. 가격이 이제 `15`이고 `total_time`가 새 키-값 쌍임을 확인하세요:

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### 할당과 얕은 복사

리스트에서 배운 것처럼, 사전을 다른 변수에 할당하면 별칭이 만들어집니다. 두 이름 모두 같은 객체를 참조합니다:

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

별도의 외부 사전을 만들려면 `.copy()` 메서드를 사용하세요:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

`copied_settings`에서 항목을 교체해도 `settings`의 해당 항목은 교체되지 않습니다. 하지만 `.copy()`는 **얕은 복사**를 만듭니다: 원본 사전과 같은 객체를 참조하는 키와 값을 가진 새로운 외부 사전을 생성합니다. 중첩된 변경 가능한 객체는 여전히 공유됩니다:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

두 사전은 다른 객체이지만, `languages` 항목은 같은 리스트를 참조합니다. 그 리스트에 추가하면 두 사전 모두에서 보입니다. `copied_settings['languages']`를 새 리스트로 교체하면 복사본에서만 그 항목이 변경됩니다.

`dict()`에 사전을 전달해도 얕은 복사를 만들 수 있습니다:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

`.copy()`와 마찬가지로 `dict(settings)`는 새로운 외부 사전을 만들지만, 중첩된 리스트는 여전히 공유됩니다. 어느 한쪽 사전에서 항목을 교체하면 그 사전만 영향을 받고, 공유된 리스트를 변경하면 두 사전 모두에서 보입니다.

## 함수 매개변수를 통한 사전 변이

리스트에서 배운 것과 같은 인수 전달 규칙이 사전에도 적용됩니다. 매개변수는 처음에 인수로 전달된 객체를 참조합니다. 그 매개변수를 통해 항목을 업데이트하면 공유된 사전이 변이됩니다:

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

함수는 상태 문자열을 반환하는 반면, `preferences`는 공유 참조를 통해 변경됩니다. 값을 반환하는 것과 객체를 변이하는 것은 별개의 효과입니다. 함수가 사전을 반환하지 않아도 함수 외부에서 변경 사항이 보입니다. 지역 매개변수를 다른 사전으로 재할당해도 `preferences`가 참조하는 사전은 교체되지 않습니다.

## 기본 인수로 사전 사용하기

기본 리스트는 함수가 정의될 때 생성되고 인수를 생략한 호출에서 재사용된다는 점을 기억하세요. 기본 사전도 같은 방식으로 동작합니다:

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

두 번째 호출은 첫 번째 호출에서 변경된 사전을 재사용합니다. 즉, 각 호출마다 고유한 지역 매개변수 이름이 있어도 설정이 독립 호출 간에 누적됩니다.

각 호출이 새 사전으로 시작해야 할 때는 `None` 기본 패턴을 사용하세요:

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

`settings`를 생략하거나 `None`을 전달하는 각 호출은 새 사전을 만듭니다. 기존 사전을 전달하면 함수가 그 객체를 변이할 수 있습니다. 여기서는 `settings is None`을 사용하세요: `if not settings`는 빈 사전도 인수로 전달된 것으로 간주해 새 지역 사전으로 교체할 수 있습니다.
