# --description--

El operador `or` se usa para verificar si al menos una de dos condiciones es verdadera. Aquí tienes cómo usarlo con una comparación en una sentencia `if`:

```py
day = 'Sunday'
is_raining = False

if day == 'Sunday' or is_raining:
    print('Stay at home')
```

En el ejemplo anterior, se imprime `Stay at home` porque la primera condición es verdadera, aunque `is_raining` sea `False`.

También deberían aplicarse cargos extra los fines de semana. Actualiza la condición de la línea `if show_time == 'Evening':` usando el operador `or` para combinar la condición existente con una segunda condición que verifique si `is_weekend` es verdadera.
