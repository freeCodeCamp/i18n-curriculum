# --description--

ターミナルとは何か、そしてコマンドラインとどう違うのかを学びましょう。

コマンドラインは基本的なテキスト入力インターフェースで、ユーザーが「コマンド」を通常は一連の文字列の形で入力し、<kbd>Enter</kbd>キーを押して送信または実行できます。コマンドラインインターフェースは、最も一般的にターミナル内で見られます。

ターミナルは、基本的な読み書き操作を超えたシステムレベルのコマンドを実行するためのコマンドラインインターフェースを提供する特別なアプリケーションです。「ターミナルエミュレーター」という言葉も聞くかもしれませんが、これは基本的なターミナルインターフェースをラップして追加の機能や機能性を提供するアプリケーションのことです。しかし、一般的な用途では、これらも「ターミナル」と呼んで問題ありません。

最後に、「シェル」についても説明が必要です。シェルはコマンドラインをラップし、入力をコマンドとして解釈して出力を返すソフトウェアです。

では、システム上でターミナルにどうやってアクセスできるでしょうか？

もし最新のWindowsを使っているなら、おそらく2つの異なる選択肢があります。Windowsは標準で2つの異なるシェルアプリケーションを提供しています：PowerShellとCommand Promptです。

これらのシェルはそれぞれ専用のターミナルアプリケーション（シェル名と同じ名前）を備えているので、アプリケーションメニューからPowerShellターミナルかCommand Promptターミナルのどちらかを起動できます。

Windowsはまた、Windows Terminalという比較的新しくモダンなターミナルエミュレーターも提供しています。

このアプリケーションはWindowsストアからインストールでき、PowerShellやCommand Promptのターミナルと同じように起動できます。Windows Terminalの利点は、同じアプリケーションからPowerShellとCommand Promptの両方のシェルにアクセスできることに加え、Windows Subsystem for Linuxを設定していれば対応するLinuxシェルにもアクセスできることです。

macOSには「Terminal」と名付けられたターミナルがあります。スポットライト検索やアプリケーションランチャーからアクセスできます。また、iTermやGhosttyのようなサードパーティ製のターミナルエミュレーターもサポートされています。これらのアプリケーションはそれぞれのホームページからインストールできます。

Linuxでは、デフォルトのターミナルや起動方法はディストリビューションやデスクトップ環境によって大きく異なります。サードパーティ製のターミナルエミュレーターも多くサポートされています。例えば、Arch Linuxでkittyを設定し、wofiのようなアプリケーションマネージャーで起動することもできます。

Linuxはおそらく最も多様なターミナルアプリケーションの選択肢があります。ほとんどはディストリビューションのパッケージマネージャーからインストール可能です。

「ターミナル」、「シェル」、「コマンドライン」の区別は時に細かすぎるように感じるかもしれません。ほとんどの場合、これらの用語はほぼ同じ意味で使われます。しかし、それぞれに特定の意味があり、その意味を理解することが重要です。
