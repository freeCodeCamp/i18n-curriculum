# --description--

У цій лабораторній роботі ви побудуєте клас черги. Черга працює за принципом FIFO (перший прийшов — перший вийшов): елементи додаються в кінець черги і видаляються з початку.

**Мета:** Виконайте наведені нижче історії користувача та пройдіть усі тести, щоб завершити лабораторну роботу.

**Історія користувача:**

1. Ви повинні визначити клас із назвою `Queue`. Новий екземпляр `Queue` має починатися порожнім.

1. Клас `Queue` має мати такі методи:

   - `enqueue`: приймає елемент і додає його в кінець черги.
   - `dequeue`: видаляє елемент із початку черги і повертає його. Якщо черга порожня, має повертати `None`.
   - `front`: повертає елемент із початку черги без видалення. Якщо черга порожня, має повертати `None`.
   - `size`: повертає кількість елементів у черзі.
   - `is_empty`: повертає `True`, якщо в черзі немає елементів, і `False` в іншому випадку.

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
