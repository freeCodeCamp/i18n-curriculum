# --description--

Nesta oficina, você vai trabalhar com um diretório inteligente do campus e criar tabelas de consulta a partir de dados aninhados.
Você vai usar essas tabelas para realizar buscas rápidas e eficientes. O `rawData` já foi fornecido para você.

Reserve um momento para observar sua forma: cada chave é o nome de um departamento e seu valor contém um `Dept_code` junto com
um array de `programs`. Cada programa então contém seu próprio array de `instructors`.

Para começar, registre o `rawData` no console para que você possa inspecionar essa estrutura aninhada antes de trabalhar com ela.

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, "log");
const getLogs = () => globalThis.spy.calls.map(call => call?.[0]);
```

# --after-each--

```js
globalThis.spy.restore();
delete globalThis.spy;
```

# --hints--

Você deve registrar o `rawData` no console.

```js
assert.include(getLogs(), rawData);
```
