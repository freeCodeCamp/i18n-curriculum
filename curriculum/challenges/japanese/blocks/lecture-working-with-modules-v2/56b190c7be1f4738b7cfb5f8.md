# --description--

前のレッスンで学んだように、モジュールとは関連するコードをまとめたPythonファイルで、他のPythonファイルで再利用できます。

自分でモジュールを書いてスクリプトにインポートすることもできます。自分のモジュールを作成することはコードを整理するのに最適な方法です。非常に長いファイルを1つにまとめる代わりに、関連するコードごとに小さなファイルに分割し、必要な場所でそれらをインポートできます。

例えば、温度変換用の2つの関数と、そのうちの1つが動作するか確認する関数呼び出しを含む`temperature.py`ファイルを作成したとします：

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

このファイルを直接実行すると、次のような出力になります：

```md
212.0
```

次に、`temperature.py`と同じフォルダーに`main.py`という別のファイルを作成したとします。ローカルモジュールの関数を使うには、`.py`拡張子を除いたモジュール名でインポートします：

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

`main.py`ファイルを実行すると、次のような出力になります：

```md
212.0
100.0
```

`temperature`がインポートされると、Pythonは`temperature.py`のコードを上から下まで実行します。だから`212.0`が出力されるのです。`main.py`は`fahrenheit_to_celsius()`だけを呼び出しているのにです。このようなチェックコードは、ファイルを直接実行したときだけ動かし、インポートされるたびに実行したくない場合が多いです。

これを制御するには、よく使われるPythonの慣用表現を使えます：

```python
if __name__ == '__main__':
    # Code
```

`__name__`はPythonの特別な組み込み変数です。

Pythonファイルが直接実行されると、この変数の値は文字列`__main__`に設定されます。

しかし、そのPythonファイルが別のPythonスクリプトにモジュールとしてインポートされると、`__name__`変数の値はそのモジュールの名前（通常は`.py`拡張子を除いたファイル名）に設定されます。

だからPythonスクリプトでこの条件文をよく見かけます。これはPythonスクリプトがメインプログラムとして実行されている場合にのみ実行したいコードを含みます。スクリプトがモジュールとしてインポートされた場合、そのブロック内のコードは実行されません。

これはPythonスクリプトに2つの目的を持たせるのに役立ちます。直接実行してメインのロジックを実行することも、別のモジュールにインポートしてメインのロジックを実行せずに使うこともできます。

この慣用表現を使うように更新した`temperature.py`ファイルです。`__name__`の値も出力して、どのように変わるか確認できます：

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

このファイルを直接実行すると、Pythonは`__name__`を`'__main__'`に設定するので条件が`True`になり、`if`ブロック内のコードが実行されます。出力は次の通りです：

```md
The value of __name__ is: __main__
212.0
```

代わりに`main.py`ファイルを実行すると、次のような出力になります：

```md
The value of __name__ is: temperature
100.0
```

`if`ブロックの外の`print()`呼び出しは`temperature`がインポートされたときにも実行され、`__name__`の値がモジュール名の`temperature`になっていることを示します。

しかし`__name__`は`'__main__'`と等しくないため、`if`ブロック内のコードは実行されず、`212.0`は出力されません。唯一の出力は`main.py`の関数呼び出しからの`100.0`です。
