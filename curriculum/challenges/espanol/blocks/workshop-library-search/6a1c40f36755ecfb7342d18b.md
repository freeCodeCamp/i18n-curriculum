# --description--

¡Bienvenido al taller de búsqueda de libros en la biblioteca! En este proyecto, construirás una búsqueda de títulos de libros manejando errores de forma elegante usando `try`, `catch`, `throw` y `finally`.

Se te ha proporcionado un arreglo de libros disponibles llamado `library`, así como algunas variables básicas del DOM para manejar la entrada del usuario.

Si miras al final del archivo `script.js`, hay un listener de evento adjuntado a `searchBtn`. Cuando se hace clic, espera llamar a una función llamada `findBook`, pasando la entrada del usuario.

Para comenzar, declara una función vacía llamada `findBook`. Esta función debe tomar un solo parámetro llamado `title`.
