# --description--

Você provavelmente já conhece alguns dos atalhos básicos, que são herdados do seu sistema operacional. Atalhos como <kbd>Ctrl</kbd> + <kbd>S</kbd> (Windows/Linux) ou <kbd>Cmd</kbd> + <kbd>S</kbd> (macOS) para salvar, <kbd>Ctrl</kbd> + <kbd>C</kbd> ou <kbd>Cmd</kbd> + <kbd>C</kbd> para copiar, e <kbd>Ctrl</kbd> + <kbd>V</kbd> ou <kbd>Cmd</kbd> + <kbd>V</kbd> para colar funcionam no VS Code.

Mas existem alguns que são específicos da aplicação e ainda podem aumentar sua produtividade. Vale lembrar que alguns desses atalhos podem variar conforme o sistema operacional.

Por exemplo, <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> executa o formatador configurado (como o Prettier, para um projeto Javascript) no arquivo aberto atualmente.

Use <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (Windows/Linux) ou <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (macOS) para buscar o conteúdo de texto de todos os arquivos no seu workspace. Depois use <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (Windows/Linux) ou <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (macOS) se quiser executar um buscar e substituir.

Se precisar excluir uma linha, <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (Windows/Linux) ou <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (macOS) vai deletá-la.

Quer mais espaço para todo seu código? <kbd>Ctrl</kbd> + <kbd>B</kbd> (Windows/Linux) ou <kbd>Cmd</kbd> + <kbd>B</kbd> (macOS) vai esconder a barra lateral, que tem a lista de arquivos e o menu de extensões.

Ou talvez você não esteja conseguindo ver seu código? <kbd>Ctrl</kbd> + <kbd>Plus</kbd> (Windows/Linux) ou <kbd>Cmd</kbd> + <kbd>Plus</kbd> (macOS) vai aumentar a escala do editor, e <kbd>Ctrl</kbd> + <kbd>Minus</kbd> (Windows/Linux) ou <kbd>Cmd</kbd> + <kbd>Minus</kbd> (macOS) vai diminuir.

Outro recurso útil no VS Code é a edição em múltiplas linhas, que permite fazer alterações em várias linhas ao mesmo tempo. Por exemplo, você pode colocar múltiplos cursores usando <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> e <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Windows), <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> e <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Linux), ou <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Down</kbd> e <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Up</kbd> (macOS), para estender o cursor para linhas consecutivas. Você também pode pressionar e segurar <kbd>Alt</kbd> (Windows/Linux) ou <kbd>Option</kbd> (macOS) e clicar para adicionar cursores em linhas separadas onde precisar. Depois que os cursores estiverem posicionados, tudo que você digitar ou excluir será aplicado simultaneamente em todos esses locais, o que pode economizar muito tempo ao trabalhar com código repetitivo.

Finalmente, se esquecer algum desses atalhos, você sempre pode usar <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows/Linux) ou <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS), que abre a paleta de comandos para você selecionar o que precisar.
