# --description--

정규 표현식, 또는 정규식은 텍스트에서 문자 수열과 일치시키는 데 사용하는 패턴입니다.

이미 `in` 연산자를 사용해 문자열에 정확한 부분 문자열이 포함되어 있는지 확인해 보셨을 겁니다. 하지만 찾고자 하는 정확한 텍스트는 모르고 그 형태만 아는 경우가 있습니다. 예를 들어, 문자열이 몇 글자의 문자로 시작하고 그 뒤에 숫자가 오는지, 또는 사용자 이름이 허용된 문자로만 이루어졌는지 확인하고 싶을 수 있습니다.

정규 표현식을 사용하면 이런 패턴을 설명하고 문자열이 그 패턴과 일치하는지 확인할 수 있습니다. 주로 입력 검증, 텍스트 검색, 문자열에서 정보 추출에 사용됩니다.

Python에서 정규 표현식을 사용하려면 표준 라이브러리의 일부인 `re` 모듈을 가져와야 합니다:

```python
import re
```

가장 간단한 정규식 패턴은 리터럴 패턴입니다. 이는 정확히 작성된 대로 나타나야 하는 문자 수열입니다. 예를 들어, 패턴 `'cat'`은 문자 `c`, `a`, `t`가 차례로 나오는 것과 일치합니다.

문자열 안에서 패턴을 찾으려면 `re` 모듈의 `search` 함수를 사용할 수 있습니다. 이 함수는 첫 번째 인수로 패턴을, 두 번째 인수로 검색할 문자열을 받습니다:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

`re.search`가 문자열 어디에서든 패턴을 찾으면 매치 객체를 반환합니다. 출력된 매치 객체는 두 가지 정보를 알려줍니다:

- `match='cat'`는 패턴과 일치한 텍스트입니다.

- `span=(4, 7)`는 문자열에서 일치한 위치입니다. 일치는 인덱스 `4`에서 시작해 인덱스 `7` 바로 앞에서 끝납니다.

매치 객체의 `group`과 `span` 메서드로도 이 정보를 얻을 수 있습니다:

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

패턴을 찾지 못하면 `re.search`는 `None`을 반환합니다:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

기본적으로 정규식 일치는 대소문자를 구분합니다. 즉, 패턴 `'Cat'`은 텍스트 `cat`과 일치하지 않습니다:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

패턴 일치 방식을 바꾸려면 `re.search`의 세 번째 인수로 플래그를 전달할 수 있습니다. `re.IGNORECASE` 플래그는 검색을 대소문자 구분 없이 만들어 대문자와 소문자를 동일하게 처리합니다:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
