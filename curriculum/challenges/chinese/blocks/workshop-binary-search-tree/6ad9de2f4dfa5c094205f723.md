# --description--

每个节点最多可以有两个子节点。

在 `__init__` 方法中，创建一个 `left` 属性和一个 `right` 属性，并将它们都设置为 `None`，以表现一个新节点开始时没有子节点。

没有子节点的节点称为叶节点。
