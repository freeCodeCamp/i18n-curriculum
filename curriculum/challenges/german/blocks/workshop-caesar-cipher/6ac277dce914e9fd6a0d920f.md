# --description--

In Python ist `bool` eine Unterklasse von `int`, wobei sich `True` wie `1` und `False` wie `0` verhält. Das bedeutet, dass `isinstance()` Boolean-Werte als ganze Zahlen behandelt:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True
```

Deshalb akzeptiert Ihre Funktion derzeit `True` und `False` als Verschiebungswerte.

Verwenden Sie den `or`-Operator, um Ihrer `if`-Anweisung eine zweite Bedingung hinzuzufügen, die mit `isinstance(shift, bool)` überprüft, ob `shift` ein Boolean ist. So gibt Ihre Funktion auch `Shift must be an integer value.` zurück, wenn `shift` `True` oder `False` ist.
