# --description--

Nem todo departamento tem garantia de ter um `Dept_code`. Você precisa de um fallback para quando ele estiver ausente, assim o departamento ainda recebe um id utilizável.

O operador `||` retorna o valor à esquerda se esse valor for `truthy`, caso contrário retorna o valor à direita.

Por exemplo: `a || b` avalia para `a` quando `a` é `truthy`, e usa o fallback `b` quando `a` é `falsy` (como `undefined`, `null` ou `""`).

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

Atualize a atribuição de `departmentId` para usar o operador `||`. Use `departmentData.Dept_code` como operando à esquerda e o template literal `` `dept-${i + 1}` `` como operando à direita. Isso usa o fallback sempre que `departmentData.Dept_code` for falsy, inclusive quando for `undefined`.
