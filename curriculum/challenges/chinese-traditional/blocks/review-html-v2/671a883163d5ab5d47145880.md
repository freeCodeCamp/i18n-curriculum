## HTML 基礎知識

- **HTML 的角色**：HTML（超文字標記語言）是網頁結構的基礎，定義了網頁的元素。
- **HTML 元素**：用來表述頁面上的內容。大多數由一個開啟標記和一個關閉標記組成（例如，`<h1></h1>`、`<p></p>`）。
- **HTML 結構**：HTML 由 `head` 和 `body` 組成，其中詮釋資料、樣式和內容被結構化。
- **常見的 HTML 元素**：標題（`<h1>` - `<h6>`）、段落（`<p>`）和 div 容器（`<div>`）。
- **`div` 元素**：`div` 元素是一個泛型的 HTML 元素，沒有任何語意意義。它用作泛型容器來容納其他 HTML 元素。
- **Void Elements**：沒有結束標籤（例如 `<img>`）。
- **屬性**：為元素添加詮釋資料和行為。

## 識別字與群組

- **IDs**：唯一元素識別符。
- **類別**：用於樣式和行為的元素群組。

## 樣板程式碼和編碼

- **HTML boilerplate**：網頁的基本結構，包括 `DOCTYPE`、`html`、`head` 和 `body` 元素。它應該作為 HTML 文件的起點使用。
- **UTF-8 字元編碼**：確保通用字元顯示。

## 語意化 HTML 的重要性

- **標題元素的結構層次**：使用正確的標題元素以維持內容的結構層次非常重要。`h1` 元素是最高層級的標題，`h6` 元素是最低層級的標題。
- **語意化 HTML 元素**：這些元素為內容的結構提供意義。範例包括：
  - `<header>`：代表介紹性內容。
  - `<nav>`：包含導覽連結。
  - `<article>`：代表獨立的內容。
  - `<section>`：在文件中群組相關內容。
  - `<footer>`：定義區段或文件的頁尾。
  - `<blockquote>`：用來表述引用自其他來源的區段。使用來源作為 `cite` 屬性的值。
  - `<q>`：用來表述短的行內引用。

## HTML 表單元素和屬性

### 表單

- **`form` 元素**：用來創建供使用者輸入的 HTML 表單。
- **常見輸入類型**：
  - `text`、`email`、`radio`、`checkbox`、`number`。
- **`action` 屬性**：用來指定表單資料應送往的 URL。
- **`method` 屬性**：用來指定送出表單資料時使用的 HTTP 方法。最常見的方法是 `GET` 和 `POST`。

```html
<form method="value-goes-here" action="url-goes-here">
  <!-- inputs go inside here -->
</form>
```

- **`input` 元素**：用來創建用戶輸入的輸入欄位。
- **`type` 屬性**：用來指定輸入欄位的型別，例如 `text`、`email`、`number`、`radio`、`checkbox`。
- **`placeholder` 屬性**：用來顯示提示，告訴使用者在輸入欄位中應該輸入什麼。
- **`value` 屬性**：用來指定輸入欄位的值。
- **`name` 屬性**：用來為輸入欄位指定名稱，這個名稱在表單資料提交時作為鍵值。對於圓鈕，給予相同的 `name` 可將它們群組，使該群組中一次只能選擇一個選項。
- **`size` 屬性**：用來定義使用者輸入時應該可見的字元數。
- **`min` 屬性**：可用於像 `number` 這類輸入型別，指定輸入欄位允許的最小值。
- **`max` 屬性**：可用於像 `number` 這類輸入型別，指定輸入欄位允許的最大值。
- **`required` 屬性**：用來指定輸入欄位在提交表單前必須填寫。

:::interactive_editor

```html
<!-- Text input -->
<input 
  type="text"
  id="name"
  name="name"
  placeholder="e.g. Quincy Larson"
  size="20"
  required
/>

<!-- Number input -->
<input 
  type="number"
  id="quantity"
  name="quantity"
  min="2"
  max="10"
/>
```

:::

- **`label` 元素**：用來為輸入欄位創建標籤。
- **`for` 屬性**：用來指定標籤對應的輸入欄位。

:::interactive_editor

```html
<form action="">
  <label for="email">Email Address: </label>
  <input type="email" id="email" />
</form>
```

:::

- **`button` 元素**：用來創建可點擊的按鈕。按鈕也可以有 `type` 屬性，控制按鈕被作用時的行為。

:::interactive_editor

```html
<button type="submit">Submit Form</button>
```

:::

- **`fieldset` 元素**：用於將相關輸入欄位群組在一起。
- **`legend` 元素**：用於為輸入群組添加說明標題。

:::interactive_editor

```html
<!-- Radio group -->
<fieldset>
  <legend>Was this your first time at our hotel?</legend>

  <input id="yes-option" type="radio" name="hotel-stay" value="yes" />
  <label for="yes-option">Yes</label>

  <input id="no-option" type="radio" name="hotel-stay" value="no" />
  <label for="no-option">No</label>
</fieldset>

<!-- Checkbox group -->
<fieldset>
  <legend>
    Why did you choose to stay at our hotel? (Check all that apply)
  </legend>

  <input type="checkbox" id="location" name="location" value="location" />
  <label for="location">Location</label>

  <input type="checkbox" id="price" name="price" value="price" />
  <label for="price">Price</label>
</fieldset>
```

:::

## 操作 HTML 表格元素和屬性

- **Table element**：用於創建 HTML 表格。
- **表格標頭（`thead`）元素**：用於將 HTML 表格中的標頭內容分組。
- **表格列 (`tr`) 元素**：用於在 HTML 表格中創建一列。
- **表格標題（`th`）元素**：用於在 HTML 表格中創建標題儲存格。
- **表格主體（`tbody`）元素**：用於將 HTML 表格中的主體內容分組。
- **表格資料儲存格（`td`）元素**：用於在 HTML 表格中創建資料儲存格。
- **Table Foot (`tfoot`) 元素**：用於將 HTML 表格中的頁腳內容分組。
- **`caption` 元素**：用於為 HTML 表格添加標題。
- **`colspan` 屬性**：用來指定表格儲存格應該跨越的行數。

:::interactive_editor

```html
<table>
  <caption>Exam Grades</caption>

  <thead>
    <tr>
      <th>Last Name</th>
      <th>First Name</th>
      <th>Grade</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Davis</td>
      <td>Alex</td>
      <td>54</td>
    </tr>

    <tr>
      <td>Doe</td>
      <td>Samantha</td>
      <td>92</td>
    </tr>

    <tr>
      <td>Rodriguez</td>
      <td>Marcus</td>
      <td>88</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <td colspan="2">Average Grade</td>
      <td>78</td>
    </tr>
  </tfoot>
</table>
```

## 無障礙設計

- **網頁內容無障礙指引**：網頁內容無障礙指引（WCAG）是一套讓網頁內容對身心障礙者更友善的指導原則。WCAG 的四大原則是 POUR，分別代表可感知（Perceivable）、可操作（Operable）、可理解（Understandable）和強固（Robust）。
- **良好 `alt` 文字的重要性**：你應該使用 `alt` 屬性為圖片提供文字替代，這有助輔助技術理解圖片內容。
- **良好連結文字的重要性**：你應該使用具描述性的連結文字，幫助使用者理解連結的目的。
