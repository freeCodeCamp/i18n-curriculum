# --description--

## Kwa Nini Kusakinisha Python Kwenye Kompyuta Yako?

Kwa warsha zote na maabara, utatumia mhariri wa Python wa freeCodeCamp. Lakini ni muhimu kujifunza jinsi ya kusanidi Python kwenye kompyuta yako ya ndani.

## Kupakua Python

Njia rahisi zaidi ya kusakinisha Python kwenye Windows na Mac ni kupakua faili la kusakinisha kutoka kwenye tovuti rasmi ya Python. Pia tutazungumzia jinsi ya kuendesha Python kwenye Linux baadaye katika funzo hili.

Nenda `https://www.python.org/` na elekeza kipanya juu ya "Downloads". Dirisha la kidirisha litaonekana likionyesha toleo la sasa la Python kwa mfumo wako wa uendeshaji (OS).

## Kusakinisha Python kwenye macOS

Tutaangalia jinsi ya kusakinisha Python kwenye kompyuta inayotumia macOS kwanza:

- Bofya kitufe kinachoonyesha toleo la sasa la Python (kutoka kwenye dirisha lililotangulia), na utaanza kupakua faili la usakinishaji la `.pkg` moja kwa moja.
- Mara faili la usakinishaji la `.pkg` linapomalizika kupakuliwa, lifungue, kisha bofya "Endelea" katika dirisha linalofunguka.
- Endelea kubofya kitufe cha "Endelea" hadi ufike sehemu ya "Aina ya Usakinishaji". Huko, bofya kitufe cha "Sakinisha".
- Ingiza nenosiri lako ikiwa ni lazima, kisha anza usakinishaji.
- Wakati usakinishaji wa kifurushi unapoisha, unapaswa kuona ujumbe unaosema kuwa Python imesakinishwa kwa mafanikio.
- Fungua folda mpya ya Python iliyoundwa katika saraka yako ya Programu.
- Bonyeza mara mbili faili la `Install Certificates.command` na ruhusu mchakato wa terminal ukamilike.
- Hakikisha kuwa `Successfully installed certifi` na `update complete` zinaonekana katika dirisha la terminal.
- Funga dirisha la terminal na bofya "Funga" katika dirisha la msakinishaji. Usanidi wako sasa umekamilika!

## Kuhakiki Usakinishaji

Unaweza kuthibitisha usakinishaji kwa kufungua terminal yako na kuendesha `python --version` au `python3 --version`.

Pia unaweza kufungua mfasiri wa Python kwa kuendesha `python` au `python3` katika terminal. Mfasiri wa Python ni programu inayosoma msimbo wa Python, kuutafsiri kuwa maagizo ambayo kompyuta inaelewa, na kutekeleza maagizo hayo.

## Terminal ni Nini?

<dfn>Terminal</dfn> ni kiolesura cha maandishi kinachokuwezesha kuingiliana na kompyuta yako kwa kuandika amri. Kila mfumo wa uendeshaji huja na programu ya terminal ya msingi. Katika macOS, unaweza kutumia programu ya Terminal. Katika Windows, unaweza kutumia Command Prompt au PowerShell. Katika Linux, kila mazingira ya desktop yana programu yake ya terminal ya msingi, kama GNOME Terminal au Konsole.

## Kutumia `python` dhidi ya `python3`

Kumbuka kwamba, katika baadhi ya mifumo ya zamani ya macOS na Linux, `python` inaweza kuwa imehifadhiwa kwa Python 2, wakati `python3` ni kwa Python 3 hasa. Ikiwa unaendesha `python --version` na unaona toleo la Python 2 kama `Python 2.7.18`, basi inawezekana mfumo wako unategemea programu fulani iliyotengenezwa kwa toleo la zamani la Python. Ikiwa ni hivyo, unapaswa kutumia `python3` kuendesha msimbo wako wa Python kuanzia sasa. Python 2 ni mwisho wa maisha yake na haipaswi kutumika kwa ukuzaji mpya wowote.

## Kusakinisha Python kwenye Windows

Kusakinisha Python kwenye Windows, fuata hatua hizi:

- Nenda kwenye `https://www.python.org/`, na elekeza kidole juu ya "Downloads". Utapata dirisha linalosema "Download for Windows" na kitufe cha kupakua chenye toleo la sasa la Python.
- Bofya nambari ya toleo, na utaanza kupakua Meneja wa Usakinishaji wa Python (`.msix` kifurushi) moja kwa moja.
- Mara umemaliza kupakua Meneja wa Usakinishaji wa Python, bonyeza mara mbili juu yake na chagua "Sakinisha".
- Baada ya usakinishaji, amri za `python`, `py`, na `pymanager` zinapaswa kupatikana. Ikiwa hakuna runtime ya Python iliyosakinishwa, kuendesha `python` kutaweka moja moja kwa moja.
- Unapoweka runtime kwa mara ya kwanza, huenda ukaombwa kuongeza saraka kwenye `PATH` kwa ajili ya majina mengine ya amri, kama vile `python3.14.exe`. Kubali ombi hili la hiari ikiwa unataka kutumia majina hayo.


Unaweza kuthibitisha usakinishaji kwa kufungua shell ya mstari wa amri kama PowerShell na kuendesha `python --version`. Pia unaweza kufungua mfasiri wa Python kwa kuendesha `python`.

## Kusakinisha Python kwenye Linux

Kwa Python kwenye Linux, distros kuu kama Ubuntu, Debian, na Fedora huja na Python tayari.

Fungua tu terminal na endesha `python --version`, au `python3 --version`.

Kama hakuna amri yoyote inaonyesha toleo la Python 3, unaweza kutafuta kifurushi cha usakinishaji kwa aina yako ya Linux kwenye `https://www.python.org`, au tafuta mtandaoni njia inayopendekezwa ya kusakinisha Python kwa distro yako.
