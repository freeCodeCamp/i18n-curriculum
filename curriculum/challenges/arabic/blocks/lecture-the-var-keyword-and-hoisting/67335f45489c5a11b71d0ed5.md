# --interactive--

الرفع هو سلوك في JavaScript يربك المبتدئين غالبًا، لكن فهمه يساعدك على تجنب الأخطاء البرمجية الدقيقة في كودك. ببساطة، الرفع هو السلوك الافتراضي في JavaScript الذي ينقل الإعلانات إلى أعلى نطاقاتها خلال مرحلة الترجمة قبل تنفيذ الكود.

لفهم الرفع، من المهم معرفة أن JavaScript تعمل في مرحلتين: مرحلة الترجمة ومرحلة التنفيذ. خلال مرحلة الترجمة، يقوم محرك JavaScript بمراجعة كودك ويُعد مساحة ذاكرة للمتغيرات والدوال. هنا يظهر دور الرفع.

لنبدأ برفع المتغيرات، عندما تعلن عن متغير باستخدام الكلمة المفتاحية `var`، يقوم JavaScript برفع الإعلان إلى أعلى نطاقه. لكن من المهم ملاحظة أن الإعلان فقط هو الذي يُرفع، وليس التهيئة. هذا يعني أنه يمكنك استخدام متغير في كودك قبل إعلانه، لكن قيمته ستكون `undefined` حتى تعيّن له قيمة فعلية.

:::interactive_editor

```js
console.log(x); // undefined
var x = 5;
console.log(x); // 5
```

:::

في هذا الكود، رغم أننا نستخدم `x` قبل إعلانه، لا نحصل على خطأ، بل نحصل على `undefined`. هذا لأن JavaScript ترفع الإعلان `var x` إلى أعلى نطاقه، لكن لا ترفع التهيئة `x = 5`. كأن الكود أعيد كتابته هكذا:

:::interactive_editor

```js
var x;
console.log(x); // undefined
x = 5;
console.log(x); // 5
```

:::

يعمل رفع الدوال بشكل مختلف قليلاً. عندما تعلن عن دالة باستخدام صيغة إعلان `function`، يتم رفع اسم الدالة وجسمها معًا. هذا يعني أنه يمكنك استدعاء دالة قبل إعلانها في كودك. إليك مثالًا على رفع الدوال:

:::interactive_editor

```js
sayHello(); // "Hello, World!"

function sayHello(){
  console.log("Hello, World!");
}
```

:::

في هذه الحالة، يمكننا استدعاء `sayHello()` قبل إعلانها لأن الدالة كاملة تُرفع إلى أعلى نطاقها.

من المهم ملاحظة أن الرفع يعمل بشكل مختلف مع إعلانات `let` و `const` التي أُدخلت في ES6.

```js
console.log(y); // Throws a ReferenceError
let y = 10;
```

هذه الإعلانات تُرفع لكنها غير مهيأة ولا يمكنك الوصول إليها قبل الإعلان الفعلي في كودك. يُشار إلى هذا غالبًا بمنطقة الموت الزمنية.

فهم الرفع يساعدك على كتابة كود أنظف وأكثر توقعًا. مع ذلك، الاعتماد على الرفع قد يجعل كودك أصعب في القراءة والصيانة. كأفضل الممارسات، يُنصح بإعلان المتغيرات في أعلى نطاقها والدوال قبل استخدامها بغض النظر عن الرفع. هذا يجعل سلوك كودك أكثر وضوحًا وأسهل للفهم من قبل الآخرين، بما فيهم أنت في المستقبل.
