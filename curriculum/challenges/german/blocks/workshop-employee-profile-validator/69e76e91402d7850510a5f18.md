# --description--

Die Methode `.join(list)` ist das Gegenteil von `.split()`. Sie verbindet eine Liste von Strings zu einem einzigen String, wobei ein Trennzeichen verwendet wird. Zum Beispiel:

```py
parts = ['apple', 'banana', 'cherry']
joined = ' - '.join(parts)
print(joined)  # Output: apple - banana - cherry
```

Verbinden Sie die Elemente aus `address_parts` mit einem `|`-Zeichen, das von Leerzeichen umgeben ist, und weisen Sie das Ergebnis einer Variablen namens `rejoined` zu.

Geben Sie dann `rejoined` aus, sodass die Ausgabe lautet: `Rejoined: 123 Main Street | Springfield | IL`.
