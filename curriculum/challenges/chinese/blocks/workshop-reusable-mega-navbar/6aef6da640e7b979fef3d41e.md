# --description--

为了打开和关闭 `sub-menu`，你的 `Navbar` 组件需要记住 `sub-menu` 当前是否处于打开状态。组件记住且随时间可能变化的数据称为状态。每当状态变化时，React 会重新渲染组件，从而让页面显示新的值。

你将在后续课程中学到更多关于状态的内容。目前，你只需要知道可以通过 `useState` 钩子为函数组件添加状态。钩子是特殊的函数，允许你在组件中使用 React 的特色。因为本教程中 React 是通过 `script` 元素加载的，所以你可以通过 `React.useState` 访问该钩子：

```jsx
const [count, setCount] = React.useState(0);
```

`React.useState` 接收状态的初始值作为参数，并返回一个包含两个项的数组，这里通过数组解构进行拆包：

- `count` 是状态变量，保存当前值。
- `setCount` 是设置函数，你调用它来更新状态。

在 `Navbar` 组件内部，使用 `React.useState` 创建一个名为 `isOpen` 的状态变量和一个名为 `setIsOpen` 的设置函数。由于 `sub-menu` 应该初始为关闭状态，给它一个初始值 `false`。
