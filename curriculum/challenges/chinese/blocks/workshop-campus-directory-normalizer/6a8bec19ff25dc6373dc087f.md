# --description--

并非每个部门都保证有 `Dept_code`。当它缺失时，你需要一个备用方案，这样部门仍然能获得一个可用的 ID。

`||` 操作符如果左侧的值是 `truthy`，就返回左侧的值，否则返回右侧的值。

例如：当 `a` 是 `truthy` 时，`a || b` 计算结果为 `a`；当 `a` 是 `falsy`（比如 `undefined`、`null` 或 `""`）时，则回退到 `b`。

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

更新 `departmentId` 的赋值，使用 `||` 操作符。将 `departmentData.Dept_code` 作为左操作对象，模板字面 `` `dept-${i + 1}` `` 作为右操作对象。这样当 `departmentData.Dept_code` 是 falsy（包括 `undefined`）时，就会使用备用值。
