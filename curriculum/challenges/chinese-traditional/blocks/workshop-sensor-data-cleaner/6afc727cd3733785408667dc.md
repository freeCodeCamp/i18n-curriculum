# --description--

接著，你將使用列表推導式計算每個溫度與平均值的差距。這裡是語法的提醒：

```py
numbers = [1, 2, 3]
doubled = [num * 2 for num in numbers]
print(doubled) # [2, 4, 6]
```

創建一個名為 `differences` 的變數。使用列表生成式，為每個 `temperatures` 中的 `temperature` 指定一個包含 `temperature - average` 的列表。

然後，列印 `differences`，而不是 `temperatures`。
