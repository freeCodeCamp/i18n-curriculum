# --description--

Para processar os nomes dos departamentos e valores como entradas de array, use `Object.entries(rawData)`. Ele retorna um array de pares `[key, value]` para as propriedades enumeráveis do objeto com chaves do tipo string.

```js
const person = {
  name: "Alice",
  age: 30
};

console.log(Object.entries(person));
/*
Output: 
[ ["name", "Alice"], ["age", 30] ]
*/
```

Declare uma variável chamada `departmentEntries` e defina-a como `Object.entries(rawData)`.
Depois, registre `departmentEntries` no console para ver os pares `[key, value]` que ele produziu.
