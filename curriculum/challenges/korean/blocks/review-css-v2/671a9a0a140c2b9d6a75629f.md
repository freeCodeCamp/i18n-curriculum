## CSS 기초

- **CSS란?**: CSS(Cascading Style Sheets)는 HTML 요소에 스타일을 적용하는 스타일시트 언어입니다. CSS는 색상, 배경 이미지, 레이아웃 등 다양한 스타일을 지정하는 데 사용됩니다.
- **CSS 규칙의 기본 구조**: CSS 규칙은 선택자와 선언 블록 두 부분으로 구성됩니다. 선택자는 CSS에서 특정 HTML 요소를 식별하고 스타일을 적용하기 위한 패턴입니다. 선언 블록은 주어진 선택자에 대해 스타일 집합을 적용합니다.

## `width`와 `height` 속성 다루기

- **`width` 속성**: 이 속성은 요소의 너비를 지정합니다. 너비를 지정하지 않으면 기본적으로 `auto`로 설정됩니다. 이는 브라우저가 요소의 내용, 부모, 그리고 표시 유형에 따라 너비를 결정하도록 합니다.
- **`min-width` 속성**: 이 속성은 요소의 최솟값 너비를 지정합니다.
- **`max-width` 속성**: 이 속성은 요소의 최대 너비를 지정합니다.
- **`height` 속성**: 이 속성은 요소의 높이를 지정합니다. 마찬가지로, 높이는 기본적으로 `auto`로 설정되어 내부 내용에 맞춰 조정됩니다.
- **`min-height` 속성**: 이 속성은 요소의 최솟값 높이를 지정합니다.
- **`max-height` 속성**: 이 속성은 요소의 최대 높이를 지정합니다.

## 인라인, 블록, 인라인-블록 레벨 요소

- **인라인 레벨 요소**: 인라인 요소는 필요한 만큼의 너비만 차지하며 새 줄에서 시작하지 않습니다. 이 요소들은 콘텐츠 내에서 흐르며 텍스트나 다른 인라인 요소가 옆에 함께 나타날 수 있습니다. 일반적인 인라인 요소로는 `span`, `a`, `img` 요소가 있습니다.
- **블록 레벨 요소**: 블록 레벨 요소는 기본적으로 사용 가능한 전체 너비를 차지하며 컨테이너의 너비 전체에 걸쳐 확장됩니다. 일반적인 블록 레벨 요소로는 `div`, `p`, `section` 요소가 있습니다.
- **인라인-블록 레벨 요소**: `display` 속성을 사용해 요소를 `inline-block`으로 설정할 수 있습니다. 이 요소들은 인라인 요소처럼 동작하지만 블록 레벨 요소처럼 `width`와 `height`를 설정할 수 있습니다.

## 여백과 패딩

- **`margin` 속성**: 이 속성은 요소의 테두리와 주변 요소 사이, 요소 바깥에 공간을 적용할 때 사용합니다.
- **`margin` 축약형**: 1~4개의 값을 지정해 여백의 각 면을 설정할 수 있습니다. 한 값은 네 면 모두에 적용되고, 두 값은 `top`와 `bottom`에, 그다음 `right`와 `left`에 적용됩니다. 세 값은 `top`, 수평(`right`와 `left`), 그리고 `bottom`에 적용됩니다. 네 값은 `top`, `right`, `bottom`, `left`에 각각 적용됩니다.
- **`padding` 속성**: 이 속성은 요소 안쪽, 콘텐츠와 테두리 사이에 공간을 적용할 때 사용합니다.
- **`padding` 축약형**: 1~4개의 값을 지정해 패딩의 각 면을 설정할 수 있습니다. 한 값은 네 면 모두에 적용되고, 두 값은 `top`와 `bottom`에, 그다음 `right`와 `left`에 적용됩니다. 세 값은 `top`, 수평(`right`와 `left`), 그리고 `bottom`에 적용됩니다. 네 값은 `top`, `right`, `bottom`, `left`에 각각 적용됩니다.

## 배경 이미지

- **`background-image` 속성**: 이 속성은 요소에 배경 이미지를 설정하는 데 사용됩니다.
- **`background-size` 속성**: 이 속성은 배경 이미지의 크기를 설정합니다. `contain` 값은 이미지를 자르거나 늘리지 않고 가능한 크게 조절합니다. `cover` 값은 이미지의 가로세로 비율을 유지하면서 요소 전체를 덮도록 크기를 조절하여 이미지 일부가 잘릴 수 있습니다.
- **`background-repeat` 속성**: 기본적으로 배경 이미지는 요소를 채우기 위해 가로와 세로 모두 반복됩니다. `no-repeat` 값은 반복을 멈추고, `repeat-x`는 가로로만, `repeat-y`는 세로로만 반복합니다.
- **`background-position` 속성**: 이 속성은 배경 이미지가 요소 내에서 나타나는 위치를 설정합니다. `top`, `bottom`, `left`, `right`, `center` 같은 키워드나 픽셀, 백분율 값을 사용할 수 있습니다.
- **`background-attachment` 속성**: 이 속성은 배경 이미지가 콘텐츠와 함께 스크롤되는지 아니면 고정되는지를 결정합니다. 기본값은 `scroll`이며, `fixed`는 페이지가 스크롤되어도 화면에서 이미지가 고정된 위치에 있도록 합니다.
- **`background` 단축 속성**: 이 속성은 `background-image`, `background-position`, `background-attachment` 등 여러 배경 속성을 하나의 선언으로 결합할 수 있게 합니다.

## 테두리

- **`border` 속성**: 이 단축 속성은 테두리의 너비, 스타일, 색상을 한 번에 설정할 때 사용합니다. 일반적인 테두리 스타일로는 `solid`, `dashed`, `dotted`, `double`이 있습니다.
- **개별 테두리 면**: `border-top`, `border-right`, `border-bottom`, `border-left` 속성은 테두리의 각 면을 개별적으로 스타일링할 수 있게 합니다.
- **`outline` 속성**: 이 속성은 테두리와 비슷하게 요소 주위에 선을 만듭니다. `border`와 달리 `outline`은 요소의 크기나 레이아웃에 영향을 주지 않습니다.
- **`border-radius` 속성**: 이 속성은 요소의 테두리에 둥근 모서리를 만듭니다.

## CSS 특이성

- **인라인 CSS 특이성**: 인라인 CSS는 요소에 직접 적용되므로 가장 높은 특이성을 가집니다. 내부 또는 외부 CSS를 모두 재정의합니다. 인라인 스타일의 특이성 값은 (1, 0, 0, 0)입니다.
- **내부 CSS 특이성**: 내부 CSS는 HTML 문서의 `head` 섹션 내 `style` 요소에 정의됩니다. 인라인 스타일보다는 낮은 특이성을 가지며, 내부와 외부 CSS는 위치가 아니라 선택자에 의해 특이성이 결정되어 동일한 수준입니다.
- **외부 CSS 특이성**: 외부 CSS는 `head` 섹션의 `link` 요소를 통해 연결되며 별도의 `.css` 파일에 작성됩니다. 내부 CSS와 마찬가지로 선택자에 의해 특이성이 결정됩니다. 두 규칙의 특이성이 같으면 문서 내에서 나중에 나오는 규칙이 우선합니다. 외부 CSS는 대규모 프로젝트에서 유지보수에 가장 적합합니다.
- **범용 선택자(`*`)**: 문서 내 모든 요소와 일치하는 특수한 CSS 선택자입니다. 페이지의 모든 요소에 스타일을 적용할 때 유용하며, 브라우저 간 스타일 초기화나 정규화에 자주 사용됩니다. 범용 선택자는 가장 낮은 특이성 값을 가지며 (0, 0, 0, 0)입니다.
- **타입 선택자**: 태그 이름을 기준으로 요소를 선택합니다. 다른 선택자에 비해 상대적으로 낮은 특이성을 가지며, 특이성 값은 (0, 0, 0, 1)입니다.
- **클래스 선택자**: 점(`.`) 뒤에 클래스 이름을 붙여 정의합니다. 특이성 값은 (0, 0, 1, 0)으로 타입 선택자를 재정의할 수 있지만 ID 선택자와 인라인 스타일에는 재정의됩니다.
- **ID 선택자**: 해시 기호(`#`) 뒤에 ID 이름을 붙여 정의합니다. 타입 선택자와 클래스 선택자보다 훨씬 높은 특이성을 가지며 인라인 스타일보다는 낮습니다. 특이성 값은 (0, 1, 0, 0)입니다.
- **`!important` 키워드**: 스타일 규칙에 가장 높은 우선순위를 부여하여 다른 선언을 재정의하게 합니다. 사용 시 브라우저가 다른 선택자의 특이성에 관계없이 해당 스타일을 적용하도록 강제합니다. `!important`는 CSS 유지보수와 디버깅을 어렵게 만들 수 있으므로 주의해서 사용하세요.

## 절대 단위

- **`px` (픽셀)**: CSS에서 고정 크기 단위로, 치수를 정확하게 제어할 수 있습니다. 1px은 항상 1/96인치와 같습니다.
- **`in` (인치)**: 이 절대 단위는 96px과 같습니다.
- **`cm` (센티미터)**: 이 절대 단위는 25.2/64인치와 같습니다.
- **`mm` (밀리미터)**: 이 절대 단위는 1/10센티미터와 같습니다.
- **`q` (쿼터 밀리미터)**: 이 절대 단위는 1/40센티미터와 같습니다.
- **`pc` (파이카)**: 이 절대 단위는 1/6인치와 같습니다.
- **`pt` (포인트)**: 이 절대 단위는 1/72인치와 같습니다.

## 상대 단위

- **퍼센트(Percentages)**: 이 상대 단위는 크기, 치수 및 기타 속성을 부모 요소의 비율로 정의할 수 있게 합니다. 예를 들어, 요소에 `width: 50%;`를 설정하면 부모 컨테이너 너비의 절반을 차지합니다.
- **`em` 단위**: 이 단위는 요소의 폰트 크기를 기준으로 상대적입니다. `font-size` 속성에 `ems`를 사용하면 텍스트 크기가 부모 요소의 폰트 크기에 상대적입니다.
- **`rem` 단위**: 이 단위는 루트 요소인 `html` 요소의 폰트 크기를 기준으로 상대적입니다.
- **`vh` 단위**: `vh`는 `"viewport height"`의 약자로, `1vh`는 뷰포트 높이의 1%와 같습니다.
- **`vw` 단위**: `vw`는 `"viewport width"`의 약자로, `1vw`는 뷰포트 너비의 1%와 같습니다.

## `calc` 함수

- **`calc()` 함수**: `calc()` 함수를 사용하면 스타일시트 내에서 직접 계산을 수행하여 속성 값을 동적으로 결정할 수 있습니다. 즉, 뷰포트 크기나 다른 요소를 기준으로 치수를 계산하여 유연하고 반응형 사용자 인터페이스를 만들 수 있습니다.

## 가상 클래스

- **가상 클래스 정의**: 특정 상태나 위치에 따라 요소를 선택할 수 있는 특별한 CSS 키워드입니다.
- **`:active` 가상 클래스**: 버튼 클릭과 같이 요소의 활성 상태를 선택할 수 있습니다.
- **`:hover` 가상 클래스**: 요소에 마우스 커서가 올라갔을 때의 상태를 정의합니다.
- **`:focus` 가상 클래스**: 키보드 탐색이나 사용자가 폼 입력란을 클릭할 때 요소에 포커스가 생기면 스타일을 적용합니다.
- **`:first-child` 가상 클래스**: 부모 요소나 문서 내에서 첫 번째 요소를 선택합니다.
- **`:last-child` 가상 클래스**: 부모 요소나 문서 내에서 마지막 요소를 선택합니다.
- **`:first-of-type` 가상 클래스**: 부모 내에서 특정 요소 타입의 첫 번째 발생을 선택합니다.
- **`:last-of-type` 가상 클래스**: 부모 내에서 특정 요소 타입의 마지막 발생을 선택합니다.
- **`:nth-of-type(n)` 가상 클래스**: 같은 타입의 형제 요소 중 특정 위치에 있는 요소를 선택합니다.
- **`:visited` 가상 클래스**: 사용자가 방문한 링크를 대상으로 합니다.
- **`:enabled` 가상 클래스**: 현재 활성화된 폼 버튼이나 기타 요소를 대상으로 합니다.
- **`:disabled` 가상 클래스**: 비활성화된 상태의 인터랙티브 요소에 스타일을 적용합니다.
- **`:checked` 가상 클래스**: 체크된 상태임을 사용자에게 나타냅니다.

## 가상 요소

- **`::before` 가상 요소**: 이 가상 요소는 `content` 속성을 사용해 요소 바로 앞에 아이콘 같은 장식용 콘텐츠를 삽입합니다.
- **`::after` 가상 요소**: 이 가상 요소는 `content` 속성을 사용해 요소 바로 뒤에 아이콘 같은 장식용 콘텐츠를 삽입합니다.
- **`::first-letter` 가상 요소**: 이 가상 요소는 요소 내용의 첫 글자를 선택해 스타일을 지정할 수 있게 합니다.
- **`::marker` 가상 요소**: 이 가상 요소는 목록 항목의 마커(글머리 기호나 번호)를 선택해 스타일을 지정할 수 있게 합니다.

## CSS에서 색상을 다루는 다양한 방법

- **명명된 색상**: 브라우저가 인식하는 미리 정의된 색상 이름입니다. 예로 `blue`, `darkred`, `lightgreen` 등이 있습니다.
- **`rgb()` 함수**: RGB는 빨강(Red), 초록(Green), 파랑(Blue) 빛의 기본 색상입니다. 이 세 가지 색상을 다양한 강도로 조합해 다양한 색상을 만듭니다. `rgb()` 함수는 RGB 색상 모델을 사용해 색상을 정의합니다.
- **`rgba()` 함수**: 네 번째 값인 알파(투명도)를 추가해 색상의 투명도를 조절합니다.
- **`hsl()` 함수**: HSL은 색상(Hue), 채도(Saturation), 밝기(Lightness)를 나타내는 세 가지 주요 구성 요소입니다.
- **`hsla()` 함수**: 네 번째 값인 알파를 추가해 색상의 불투명도를 조절합니다.
- **16진수(Hexadecimal)**: 16진수 코드는 RGB 색상 모델을 나타내는 6자리 문자열입니다. "hex"는 0~9 숫자와 A~F 문자를 사용하는 16진수 체계를 의미합니다.

## `box-shadow` 속성

- **정의**: `box-shadow` 속성은 요소 주위에 하나 이상의 그림자를 적용합니다.
- **오프셋 값**: 수평(`offset-x`)과 수직(`offset-y`) 값을 지정해야 합니다. 양수 `offset-x`는 그림자를 오른쪽으로, 음수는 왼쪽으로 이동시킵니다. 양수 `offset-y`는 그림자를 아래로, 음수는 위로 이동시킵니다. 값이 `0`이면 단위를 생략할 수 있습니다.
- **블러 반경**: 선택적 값으로 그림자의 흐림 정도를 조절합니다. 지정하지 않으면 기본값은 `0`으로 선명한 가장자리를 만듭니다. 값이 클수록 그림자가 부드러워집니다.
- **확산 반경**: 선택적 값으로 그림자의 크기가 확장되거나 축소되는 정도를 조절합니다. 지정하지 않으면 기본값은 `0`입니다.
- **그림자 색상**: 명명된 색상, 16진수 값, `rgb()`, `rgba()`, `hsl()`, `hsla()` 함수로 색상을 지정할 수 있습니다.

## 그라디언트

- **선형 그라디언트**: 이 그라디언트는 직선 방향으로 색상이 점진적으로 혼합됩니다. 선의 방향과 사용되는 색상을 제어할 수 있습니다.

## CSS 변환 속성

- **정의**: 이 속성은 요소에 회전, 크기 조절, 기울이기, 이동(2D 또는 3D 공간에서)과 같은 다양한 변형을 적용할 수 있게 합니다.
- **`rotate()` 함수**: 이 함수는 요소를 중심을 기준으로 회전시키는 데 사용됩니다.

## 박스 모델

- **정의**: CSS 박스 모델에서 모든 요소는 박스로 둘러싸여 있습니다. 이 박스는 콘텐츠 영역, `padding`, `border`, `margin` 네 가지 구성 요소로 이루어져 있습니다.
- **콘텐츠 영역**: 콘텐츠 영역은 박스의 가장 안쪽 부분입니다. 텍스트나 이미지 같은 실제 콘텐츠가 들어 있는 공간입니다.
- **`padding`**: 패딩은 콘텐츠 영역 바로 다음에 오는 영역입니다. 콘텐츠 영역과 요소의 테두리 사이의 공간입니다.
- **`border`**: 테두리는 CSS 박스 모델에서 요소의 바깥 가장자리 또는 윤곽선입니다. 요소의 시각적 경계입니다.
- **`margin`**: 여백은 요소의 테두리 바깥 공간입니다. 요소와 주변 다른 요소 사이의 거리를 결정합니다.

## `content-box`와 `border-box` 속성 값

- **`box-sizing` 속성**: 이 속성은 HTML 요소의 전체 `width`와 `height`가 어떻게 계산되는지 결정합니다.
- **`content-box` 값**: `content-box` 모델에서는 요소에 설정한 `width`와 `height`가 콘텐츠 영역의 크기를 결정하며, `padding`과 `border`는 포함하지 않습니다.
- **`border-box` 값**: `border-box` 모델에서는 요소에 설정한 `width`와 `height`가 콘텐츠 영역, `padding`, `border`를 모두 포함합니다.

## CSS 필터 속성

- **정의**: 이 속성은 블러 효과 등 다양한 효과를 만드는 데 사용됩니다.
- **`blur()` 함수**: 이 함수는 요소에 블러를 적용합니다. 양은 픽셀 단위로 정의하며 블러 반경을 나타냅니다.

## CSS 플렉스박스와 플렉스 모델 소개

- **정의**: CSS 플렉스박스는 컨테이너 내에서 요소를 행과 열로 배치할 수 있는 1차원 레이아웃 모델입니다.
- **플렉스 모델**: 이 모델은 플렉스 컨테이너 내에서 플렉스 항목이 어떻게 배치되는지 정의합니다. 모든 플렉스 컨테이너는 주축과 교차 축 두 개의 축을 가집니다.

## `flex-direction` 속성

- **정의**: 이 속성은 주축의 방향을 설정합니다. `flex-direction`의 기본값은 `row`로, 모든 플렉스 항목을 브라우저 기본 언어 방향(왼쪽에서 오른쪽 또는 오른쪽에서 왼쪽)으로 같은 행에 배치합니다.
- **`flex-direction: row-reverse;`**: 행 내 항목의 순서를 반대로 뒤집습니다.
- **`flex-direction: column;`**: 플렉스 항목을 수평이 아닌 수직으로 정렬합니다.
- **`flex-direction: column-reverse;`**: 플렉스 항목의 수직 순서를 반대로 뒤집습니다.

## `flex-wrap` 속성

- **정의**: 이 속성은 플렉스 컨테이너 내에서 플렉스 항목들이 사용 가능한 공간에 맞게 어떻게 줄 바꿈되는지를 결정합니다. `flex-wrap`은 `nowrap`, `wrap`, `wrap-reverse` 세 가지 값을 가질 수 있습니다.
- **`flex-wrap: nowrap;`**: 기본값입니다. 플렉스 항목이 컨테이너 너비를 초과해도 새 줄로 감싸지 않습니다.
- **`flex-wrap: wrap;`**: 항목이 컨테이너 너비를 초과할 때 줄 바꿈을 합니다.
- **`flex-wrap: wrap-reverse;`**: 플렉스 항목을 역순으로 줄 바꿈합니다.
- **`flex-flow` 속성**: `flex-direction`과 `flex-wrap`의 단축 속성입니다.

## `justify-content` 속성

- **정의**: 이 속성은 플렉스 컨테이너의 주축을 따라 자식 요소들을 정렬합니다.
- **`justify-content: flex-start;`**: 이 경우 플렉스 항목들은 주축의 시작 부분에 정렬됩니다. 주축은 가로 또는 세로일 수 있습니다.
- **`justify-content: flex-end;`**: 이 경우 플렉스 항목들은 주축의 끝 부분에 정렬됩니다. 가로 또는 세로일 수 있습니다.
- **`justify-content: center;`**: 이 속성은 플렉스 항목들을 주축을 따라 가운데로 정렬합니다.
- **`justify-content: space-between;`**: 이 속성은 요소들을 주축을 따라 고르게 분배합니다.
- **`justify-content: space-around;`**: 이 속성은 플렉스 항목들을 주축 내에서 고르게 분배하며, 첫 번째 항목 앞과 마지막 항목 뒤에 공간을 추가합니다.
- **`justify-content: space-evenly;`**: 이 속성은 항목들을 주축을 따라 고르게 분배합니다.

## `align-items` 속성

- **정의**: 이 속성은 교차 축을 따라 항목을 배치하는 데 사용됩니다. 교차 축은 주축에 수직임을 기억하세요.
- **`align-items: center;`**: 교차 축을 따라 항목을 가운데 정렬하는 데 사용됩니다.
- **`align-items: flex-start;`**: 교차 축의 시작 부분에 항목을 정렬합니다.
- **`align-items: stretch;`**: 교차 축을 따라 플렉스 항목을 늘리는 데 사용됩니다.

## CSS `font-family` 속성

- **정의**: 폰트 패밀리는 공통 디자인을 공유하는 폰트 그룹입니다. 같은 패밀리에 속한 모든 폰트는 동일한 기본 서체를 기반으로 하지만 스타일, 굵기, 너비에 변형이 있습니다. 우선순위가 높은 것부터 낮은 순서로 여러 폰트 패밀리를 쉼표로 구분해 지정할 수 있습니다. 이러한 대체 폰트들은 대체 수단 역할을 합니다. 폰트 패밀리 목록 끝에는 항상 일반 폰트 패밀리를 포함해야 합니다.
- **일반적인 폰트 패밀리**: CSS에서 자주 사용하는 폰트 패밀리에는 serif, sans-serif, monospace, cursive, fantasy가 있습니다.

## 다양한 속성 선택자와 링크 다루기

- **정의**: `attribute` 선택자는 `href` 또는 `title` 같은 속성을 기준으로 HTML 요소를 선택할 수 있게 해줍니다.

## CSS 결합자 유형

- **자손 결합자(` `) *선택자 사이에 공백 한 칸***: 이 결합자는 지정된 부모 요소의 자손인 요소를 선택하는 데 사용됩니다.
- **자식 결합자(`>`)**: 이 결합자는 지정된 부모 요소의 직접 자식 요소를 선택합니다.
- **다음 형제 결합자(`+`)**: 이 결합자는 지정된 형제 요소 바로 다음에 오는 요소를 선택합니다.
- **이후 형제 결합자(`~`)**: 이 결합자는 지정된 요소 이후에 나오는 모든 형제 요소를 선택합니다.

## 고정, 상대 및 절대 위치 지정

- **고정 위치 지정**: 문서의 기본 흐름입니다. 요소들은 위에서 아래로, 왼쪽에서 오른쪽으로 차례대로 배치됩니다.
- **상대 위치 지정**: `top`, `left`, `right` 및 `bottom` 프로퍼티를 사용해 요소를 기본 문서 흐름 내에서 위치시킬 수 있습니다. 상대 위치 지정을 사용하면 요소들이 페이지 내 다른 요소와 겹치도록 만들 수도 있습니다.
- **절대 위치 지정**: 요소를 기본 문서 흐름에서 분리해 다른 요소와 독립적으로 동작하게 만듭니다.

## 고정 및 스티키 위치 지정

- **고정 위치 지정**: 요소가 `position: fixed`로 위치 지정되면 일반 문서 흐름에서 제거되고 뷰포트를 기준으로 배치되어 사용자가 스크롤해도 같은 위치에 유지됩니다. 이는 항상 보여야 하는 헤더나 내비게이션 바 같은 요소에 자주 사용됩니다.
- **스티키 위치 지정**: 이 위치 지정 방식은 상대 위치와 고정 위치의 혼합형으로 작동합니다. 처음에는 요소가 상대적으로 위치한 것처럼 문서 흐름 내에 머무르지만, 사용자가 특정 지점까지 스크롤하면 요소가 뷰포트(보통 상단)에 "붙어서" 고정된 것처럼 동작합니다. 이는 사용자가 특정 위치까지 스크롤할 때만 고정되는 스티키 내비게이션 바 같은 요소를 만들기에 적합합니다.

## `z-index` 속성 다루기

- **정의**: CSS에서 `z-index` 속성은 페이지에서 겹치는 위치 지정 요소들의 수직 쌓임 순서를 제어하는 데 사용됩니다.

## 미디어 쿼리

- **정의**: 개발자가 주로 뷰포트 너비를 기준으로 기기의 특성에 따라 다른 스타일을 적용할 수 있게 합니다.

## CSS 사용자 정의 속성(CSS 변수)

- **정의**: CSS 사용자 정의 속성, 즉 CSS 변수는 CSS 작성자가 문서 전체에서 재사용할 특정 값을 담기 위해 정의하는 항목입니다. 이는 더 효율적이고 유지 관리가 쉬우며 유연한 스타일시트를 만들 수 있게 하는 강력한 기능입니다. 사용자 정의 속성은 특히 테마 디자인을 만들 때 유용합니다. 서로 다른 테마에 맞는 속성 집합을 정의할 수 있습니다.

## CSS 그리드 기초

- **정의**: CSS 그리드는 웹 페이지에서 복잡한 레이아웃을 만들기 위한 2차원 레이아웃 시스템입니다. 그리드는 행과 열로 구성되며 그 사이에 간격이 있습니다. 그리드 레이아웃을 정의하려면 `display` 속성을 `grid`로 설정합니다.
- **`fr` (분수) 단위**: 이 단위는 그리드 컨테이너 내 공간의 분수를 나타냅니다. `fr` 단위를 사용해 유연한 그리드를 만들 수 있습니다.
- **트랙 사이 간격 만들기**: CSS 그리드에서 트랙 사이 간격을 만드는 세 가지 방법이 있습니다. `column-gap` 속성으로 열 사이 간격을, `row-gap` 속성으로 행 사이 간격을 만들 수 있습니다. 또는 `gap` 단축 속성으로 행과 열 모두의 간격을 설정할 수 있습니다.
- **`repeat()` 함수**: 이 함수는 트랙 목록에서 구간을 반복하는 데 사용됩니다. `grid-template-columns: 1fr 1fr 1fr;` 대신 `repeat()` 함수를 사용할 수 있습니다.
- **명시적 그리드**: `grid-template-columns` 또는 `grid-template-rows` 속성으로 선이나 트랙 수를 지정할 수 있습니다.
- **암시적 그리드**: 아이템이 그리드 밖에 배치되면 행과 열이 자동으로 생성됩니다.
- **`minmax()` 함수**: 이 함수는 트랙의 최소 및 최대 크기를 설정하는 데 사용됩니다.
- **그리드 자동 배치**: 브라우저가 자동 배치 알고리즘을 사용해 아이템을 배치합니다. `grid-auto-flow` 속성은 배치 방향과 빈 공간 채우기 여부를 `row`, `column`, `dense` 값으로 제어합니다.
- **선 기반 배치**: 모든 그리드는 선을 가집니다. 아이템이 어느 선에서 시작하는지 `grid-column-start`와 `grid-row-start` 속성으로 지정할 수 있습니다. 끝나는 선은 `grid-column-end`와 `grid-row-end` 속성으로 지정합니다. 또는 `grid-column`이나 `grid-row` 단축 속성을 사용할 수도 있습니다.
- **`grid-template-areas`**: 이 속성은 그리드에 배치할 아이템에 이름을 부여하는 데 사용됩니다.
- **정렬**: `justify-items`와 `align-items`로 그리드 영역 내 아이템 정렬을 제어합니다. 개별 그리드 아이템에는 `justify-self`와 `align-self`로 컨테이너에 설정된 정렬을 재정의할 수 있습니다.
