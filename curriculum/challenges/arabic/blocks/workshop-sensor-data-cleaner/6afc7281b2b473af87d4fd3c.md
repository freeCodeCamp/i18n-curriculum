# --description--

الآن عليك إقران كل درجة حرارة بمسمى خاص بها.

يمكن للدالة `map()` أن تأخذ أكثر من قابل للتكرار واحد. في كل استدعاء، تمرر عنصرًا واحدًا من كل قابل للتكرار إلى الدالة، لذا تحتاج الدالة إلى معلمة واحدة لكل قابل للتكرار:

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

أنشئ متغيرًا باسم `report`. عيّن له نتيجة تمرير دالة lambda، و`temperatures`، و`difference_labels` إلى `map()`، مع تغليفها بدالة `list()`. يجب أن تأخذ دالة lambda معلمتين، `temperature` و`difference_label`، وتُرجع `f'{temperature} °C ({difference_label})'`.

بعد ذلك، اطبع `report` بدلًا من `difference_labels`.
