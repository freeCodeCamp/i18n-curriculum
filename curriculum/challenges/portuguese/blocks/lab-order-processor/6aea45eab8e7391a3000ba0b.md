# --description--

Neste laboratório, você vai processar pedidos de comércio eletrônico e lidar com os erros que surgirem pelo caminho.

**Objetivo:** Cumprir as user stories abaixo e fazer todos os testes passarem para completar o laboratório.

Os dados com os quais você vai trabalhar têm a mesma estrutura das variáveis no código inicial:

- Um **pedido** é um dicionário com:
  - `order_id`: um inteiro que identifica o pedido.
  - `products`: uma lista de dicionários, cada um com um `product_id` e a `quantity` solicitada.
  - `discount_code`: uma string, ou `None` se o pedido não tiver código de desconto.
  - `status`: uma string que descreve o estado do pedido.
- Um **histórico de pedidos** é uma lista de pedidos.
- Um **inventário** é um dicionário cujas chaves são IDs de produtos e cujos valores são dicionários com o nome do `product`, a `quantity` em estoque e o `price` de uma unidade.
- Os **códigos de desconto** são um dicionário cujas chaves são os códigos e cujos valores são as taxas de desconto, por exemplo `0.1` para 10% de desconto.

**Histórias de Usuário:**

1. Você deve ter uma função chamada `find_order` com dois parâmetros: um ID de pedido e um histórico de pedidos, nesta ordem.
1. `find_order` deve:
   - retornar o pedido do histórico dado cujo `order_id` seja igual ao ID de pedido dado.
   - lançar um `ValueError` com a mensagem `Order ID {order_id} not found in order history.` se nenhum pedido corresponder ao ID dado.
1. Você deve ter uma função chamada `verify_availability` com dois parâmetros: um pedido e um inventário, nesta ordem.
1. `verify_availability` deve:
   - lançar um `ValueError` com a mensagem `Product ID {product_id} is not in the inventory.` se um produto do pedido estiver ausente no inventário dado.
   - lançar um `ValueError` com a mensagem `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.` se a quantidade solicitada de um produto for maior que a quantidade disponível no inventário dado.
   - não lançar nada se todos os produtos do pedido estiverem disponíveis na quantidade solicitada.
1. Você deve ter uma função chamada `get_discount_rate` com dois parâmetros: um pedido e os códigos de desconto, nesta ordem.
1. `get_discount_rate` deve:
   - retornar `0.0` se o `discount_code` do pedido for `None`.
   - lançar um `ValueError` com a mensagem `Invalid discount code: {discount_code}.` se o `discount_code` do pedido não estiver entre os códigos de desconto dados.
   - retornar a taxa do `discount_code` do pedido caso contrário.
1. Você deve ter uma função chamada `process_order` com quatro parâmetros: o ID do pedido a processar, um histórico de pedidos, um inventário e os códigos de desconto, nesta ordem.
1. `process_order` deve usar `find_order`, `verify_availability` e `get_discount_rate` para processar o pedido, e tratar o `ValueError` que elas lançam para que chamar `process_order` nunca lance erro.
1. Quando nenhum pedido no histórico dado corresponder ao ID dado, `process_order` deve:
   - imprimir `Error processing order {order_id}: {error message}`, onde `{error message}` é a mensagem do `ValueError` lançado por `find_order`, e não imprimir mais nada.
   - deixar o inventário e os códigos de desconto dados inalterados.
1. Quando o pedido existir mas não puder ser atendido, porque um produto está ausente no inventário, porque a quantidade solicitada não está disponível ou porque o código de desconto é inválido, `process_order` deve:
   - imprimir `Error processing order {order_id}: {error message}`, onde `{error message}` é a mensagem do `ValueError` lançado por `verify_availability` ou `get_discount_rate`.
   - definir o `status` do pedido como `failed`.
   - deixar o inventário e os códigos de desconto dados inalterados.
   - imprimir `Order {order_id} processing completed. Current status: failed`.
1. Quando o pedido puder ser atendido, `process_order` deve:
   - imprimir `Order {order_id} total: ${total}`, com o desconto aplicado e o total arredondado para duas casas decimais.
   - definir o `status` do pedido como `processed`.
   - subtrair as quantidades pedidas do inventário dado.
   - remover o código de desconto usado pelo pedido dos códigos de desconto dados, para que cada código só possa ser usado uma vez.
   - imprimir `Order {order_id} processing completed. Current status: processed`.

**Nota:** Você recebeu um inventário, histórico de pedidos e códigos de desconto que pode usar para testar seu código. Chame suas funções para experimentá-las, incluindo os casos que geram erros, mas comente essas chamadas antes de executar os testes, ou elas podem interferir nos testes.

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id, order_history, inventory, discount_codes):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
