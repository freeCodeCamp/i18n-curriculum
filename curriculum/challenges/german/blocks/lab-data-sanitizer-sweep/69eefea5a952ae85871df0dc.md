# --description--

In diesem Labor bereinigen Sie halbstrukturierte Logdateien, indem Sie nicht erlaubte Zeichen durch `#` ersetzen und verfolgen, wie viele Einträge verarbeitet wurden.

**Ziel:** Erfüllen Sie die untenstehenden User Stories und bestehen Sie alle Tests, um das Labor abzuschließen.

**User Stories:**

1. Sie sollten eine Funktionsdeklaration verwenden, um eine Funktion namens `sanitizeLog` mit zwei Parametern zu erstellen: `entry`, ein String, der einen Logeintrag darstellt, und `disallowedCharacters`, ein Array von einzeichenigen Strings, die die zu ersetzenden Zeichen darstellen.
1. Die Funktion sollte einen modifizierten `entry`-String zurückgeben, bei dem jedes nicht erlaubte Zeichen durch `#` ersetzt wurde. Die Übereinstimmung ist dabei case-sensitiv. Wenn zum Beispiel die nicht erlaubten Zeichen `["e", "E", "o", "r"]` sind, gibt `DEBUG: Server started on port 3000` `D#BUG: S##v## sta#t#d #n p##t 3000` zurück.
1. Sie sollten eine Funktion namens `cleanLogs` mit zwei Parametern erstellen: `logs`, ein Array von Strings, die Logeinträge darstellen, und `disallowedCharacters`, ein Array von einzeichenigen Strings, die die zu ersetzenden Zeichen darstellen.
1. `cleanLogs` sollte das gegebene Array von Logeinträgen der Reihe nach durchlaufen.
1. Wenn `cleanLogs` auf einen Logeintrag trifft, der den fatalen Marker `$` enthält, soll es stoppen und `Sanitizing stopped. Failure Reason: Fatal character occurred.` zurückgeben.
1. Ein Logeintrag, der mit dem Zeichen `/` beginnt, ist ein informativer Eintrag und soll nicht bereinigt werden. Sie sollten die Anzahl der informativen Einträge zählen.
1. Alle anderen Logeinträge sollen mit der Funktion `sanitizeLog` bereinigt werden. Sie sollten die Anzahl der bereinigten Einträge zählen.
1. Wenn `cleanLogs` ohne das Auftreten eines fatalen Markers fertig wird, soll es `Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.` zurückgeben, wobei `X` die Gesamtzahl der Einträge, `Y` die Anzahl der bereinigten Einträge und `Z` die Anzahl der informativen Einträge ist.

**Die folgenden Log-Arrays werden in den Tests verwendet:**

```js
let logs_1 = [
  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"
];

let logs_2 = [

  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
