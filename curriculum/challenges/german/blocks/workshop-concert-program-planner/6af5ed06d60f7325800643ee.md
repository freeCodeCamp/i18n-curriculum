# --description--

Um ein Element an einer bestimmten Position hinzuzufügen, können Sie die `insert()`-Methode verwenden. Sie nimmt den Index, an dem das neue Element eingefügt werden soll, gefolgt vom Element selbst. Die Elemente ab diesem Index rücken um eine Position nach rechts:

```py
fruits = ['apple', 'banana', 'cherry']
fruits.insert(1, 'blueberry')
print(fruits) # ['apple', 'blueberry', 'banana', 'cherry']
```

Der Dirigent möchte, dass die beiden slawischen Tänze nacheinander gespielt werden. Verwenden Sie `insert()`, um den String `Slavonic Dance No. 1` in `pieces` direkt vor `Slavonic Dance No. 8` einzufügen.
