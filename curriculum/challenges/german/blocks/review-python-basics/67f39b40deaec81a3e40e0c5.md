## Was ist Python?

- **Python**: Python ist eine universelle Programmiersprache, die für ihre Einfachheit und Benutzerfreundlichkeit bekannt ist.
- **Häufige Anwendungsfälle**: Python wird in den Bereichen Data Science, maschinelles Lernen, Webentwicklung, Cybersicherheit, eingebettete Systeme und IoT, Skripting, Automatisierung sowie bei Mikrocomputern wie dem Raspberry Pi und MicroPython-kompatiblen Boards eingesetzt.

## Variablen

- **Variablen deklarieren**: Um eine Variable zu deklarieren, beginnen Sie mit dem Variablennamen, gefolgt vom Zuweisungsoperator (`=`) und dann dem Wert. Dies kann eine Zahl, ein String, ein Boolean usw. sein. Hier sind einige Beispiele:

```py
name = 'John Doe'
age = 25
```

- **Benennungskonventionen für Variablen**: Hier sind die Benennungskonventionen, die Sie für Variablen verwenden sollten:

  - Variablennamen dürfen nur mit einem Buchstaben oder einem Unterstrich (`_`) beginnen, nicht mit einer Zahl.
  - Variablennamen können Buchstaben (`a-z`, `A-Z`), Ziffern (`0-9`) und Unterstriche (`_`) enthalten.
  - Variablennamen sind case-sensitiv: `age`, `Age` und `AGE` gelten als unterschiedlich.
  - Variablennamen dürfen keine reservierten Python-Schlüsselwörter wie `if`, `class` oder `def` sein.
  - Variablennamen mit mehreren Wörtern verwenden Unterstriche, wie in `snake_case`.
  - Variablennamen sollten ihren Zweck beschreiben, wie in `user_age`.
  - Ein-Buchstaben-Variablennamen sollten vermieden werden, wenn sie keine Bedeutung vermitteln.

## Kommentare

- **Einzeilige Kommentare**: Diese Art von Kommentar sollte für kurze Notizen in Ihrem Code verwendet werden.

```py
# This is a single line comment
```

- **Mehrzeilige Kommentare**: Sie können ein `#` am Anfang jeder Zeile verwenden, um Kommentare über mehrere Zeilen zu erstellen.

```py
# This is a multi-line comment.
# Here is some code commented out.
#
# name = 'John Doe'
# age = 25
```

## Ausgeben

- **`print()`-Funktion**: Um Daten im Terminal auszugeben, können Sie die `print()`-Funktion wie folgt verwenden:

```py
print('Hello world!') # Hello world!
```

Sie können mehrere Argumente an `print()` übergeben, indem Sie sie mit Kommas trennen. Standardmäßig fügt `print()` ein Leerzeichen zwischen den ausgegebenen Werten ein:

```py
print('Hello', 'world!') # Hello world!
```

## Häufige Datentypen in Python

- **Dynamische Typisierung**: Python ist eine dynamisch typisierte Sprache, das heißt, Sie müssen den Datentyp einer Variable nicht deklarieren. Python bestimmt den Typ anhand des zugewiesenen Werts.

- **Integer**: Eine ganze Zahl ohne Dezimalstellen:

```py
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- **Float**: Eine Zahl mit Dezimalstellen:

```py
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- **String**: Eine Folge von Zeichen, die in Anführungszeichen eingeschlossen sind:

```py
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- **Boolean**: Ein Wert, der entweder `True` oder `False` darstellt:

```py
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python hat weitere Datentypen. Sie lernen jeden einzelnen, wenn Sie ihn zum ersten Mal benötigen.

- **`type()`-Funktion**: Um den Typ einer Variable zu sehen, können Sie die `type()`-Funktion wie folgt verwenden:

```py
greeting = 'Hello there!'
age = 21

print(type(greeting)) # <class 'str'>
print(type(age)) # <class 'int'>
```

- **`isinstance()`-Funktion**: Diese wird verwendet, um zu überprüfen, ob eine Variable einem bestimmten Datentyp entspricht:

```py
greeting = 'Hello world'
name = 'John Doe'

print(isinstance(greeting, str)) # True
print(isinstance(name, int)) # False
```

Um gegen mehr als einen Typ zu prüfen, setzen Sie die Typen in runde Klammern, getrennt durch Kommas, und übergeben sie als zweiten Parameter. Das Ergebnis ist `True`, wenn der Wert eine Instanz eines der angegebenen Typen ist:

```py
account_balance = 12
print(isinstance(account_balance, (int, float))) # True
```

## Arbeiten mit Strings

- **Strings**: Strings sind Zeichenfolgen. In Python können Sie entweder einfache oder doppelte Anführungszeichen verwenden. Wählen Sie einen Stil und verwenden Sie ihn konsequent:

```py
developer = 'Jessica'
city = "Los Angeles"
```

- **Mehrzeilige Strings**: Dreifache einfache oder dreifache doppelte Anführungszeichen erlauben es, dass ein String sich über mehrere Zeilen erstreckt:

```py
message = """Hello
world!"""
print(message)
# Hello
# world!
```

- **Anführungszeichen innerhalb von Strings**: Sie können den entgegengesetzten Anführungszeichentyp um einen String verwenden, um das Escapen seiner Anführungszeichen zu vermeiden:

```py
msg = "It's a sunny day"
quote = 'She said, "Hello!"'
```

- **Escape-Sequenzen in Strings**: Sie können einen Backslash (`\`) verwenden, wenn Ihr String Anführungszeichen enthält, so:

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **Escape-Sequenzen**: Ein Backslash kombiniert mit einem anderen Zeichen kann ein Sonderzeichen darstellen. Zum Beispiel steht `\n` für einen Zeilenumbruch, `\t` für einen Tabulator und `\\` für einen einzelnen Backslash:

```py
print('Hello\nworld')
# Hello
# world

print('Name:\tAlice')  # Name:   Alice
print('C:\\Users\\Alice')  # C:\Users\Alice
```

- **`in`-Operator**: Dieser gibt einen Boolean zurück, der angibt, ob das Zeichen oder die Zeichen im String vorhanden sind oder nicht:

```py
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

- **Die Länge eines Strings ermitteln**: Die Funktion `len()` gibt die Anzahl der Zeichen in einem String zurück:

```py
developer = 'Jessica'

print(len(developer)) # 7
```

- **Zugriff auf Zeichen in Strings**: Sie können auf Zeichen in Strings mit der Klammernotation zugreifen, so:

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **Neu-Zuweisung und Unveränderlichkeit**: Strings sind unveränderlich, das heißt, Sie können sie nach ihrer Erstellung nicht ändern. Wenn Sie einer Variablen einen neuen Wert zuweisen, verweist sie auf einen anderen Wert. Der ursprüngliche String wird nicht verändert:

```py
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello
```

Eine direkte Änderung eines Strings ist nicht erlaubt:

```py
greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```

Ganze Zahlen, floats und Booleans sind ebenfalls unveränderlich.

- **String-Verkettung**: Um Strings zu verketten, können Sie den `+`-Operator verwenden, so:

```py
developer = 'Jessica'
print('My name is ' + developer + '.') # My name is Jessica.
```

- **String-Wiederholung**: Der Operator `*` wiederholt einen String eine angegebene Anzahl von Malen:

```py
print('ha' * 3) # hahaha
```

- **Verkettung von Strings mit Zahlen**: Die Verkettung eines Strings und einer Zahl führt zu einem `TypeError`:

```py
'Age: ' + 26 # TypeError: can only concatenate str (not "int") to str
```

Die Funktion `str()` wandelt die Zahl in einen String um, sodass sie verkettet werden kann:

```py
print('Age: ' + str(26)) # Age: 26
```

Eine andere Möglichkeit, Strings zu verketten, ist die Verwendung des `+=`-Operators. Dieser wird verwendet, um Verkettung und Zuweisung in einem Schritt durchzuführen, so:

```py
greeting = 'My name is '
developer = 'Jessica.'

greeting += developer
print(greeting) # My name is Jessica.
```

Der `*=` Operator wiederholt einen String und weist das Ergebnis der Variablen zu:

```py
sound = 'ha'
sound *= 3
print(sound) # hahaha
```

Sowohl `+=` als auch `*=` weisen der Variablen einen neuen String zu, ohne den ursprünglichen String zu verändern.

- **`f-strings`**: Dies steht für formatierte String-Literale. Damit können Sie Interpolation durchführen und auch Verkettungen mit einer kompakten und lesbaren Syntax erledigen:

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

Ersetzungsfelder in f-strings können Ausdrücke enthalten. Python wertet den Ausdruck aus und fügt seinen Wert in den String ein:

```py
num1 = 5
num2 = 10
print(f'The sum is {num1 + num2}') # The sum is 15
```

- **String-Slicing**: Dabei können Sie Teile eines Strings extrahieren. Hier ist die Grundsyntax:

```py
str[start:stop:step]
```

Der `start`-Index gibt an, wo die Extraktion beginnt. Der `stop`-Index ist nicht inklusive, das heißt, das Zeichen an diesem Index wird nicht mit einbezogen. Der `step` gibt das Intervall zwischen den ausgewählten Indizes an und ist standardmäßig `1`. Bei positivem `step` ist ein ausgelassener `start` standardmäßig der Anfang des Strings, und ein ausgelassener `stop` ist standardmäßig das Ende. `[:]` extrahiert den gesamten String. `[::-1]` kehrt den String um, indem es rückwärts vom letzten zum ersten Zeichen geht. Das Slicing verändert den ursprünglichen String nicht.

```py
message = 'Python is fun!'

print(message[0:6])  # Python
print(message[:6])  # Python
print(message[7:])  # is fun!
print(message[::2])  # Pto sfn
print(message[:])  # Python is fun!
print(message[::-1])  # !nuf si nohtyP
```

## Häufige String-Methoden

- **Methoden**: Eine Methode ist eine Funktion, die Sie auf einen Wert aufrufen. Um eine String-Methode aufzurufen, schreiben Sie den String oder dessen Variablennamen, gefolgt von einem Punkt und dem Methodenaufruf.

- **`str.upper()`**: Diese gibt einen neuen String zurück, bei dem alle Zeichen in Großbuchstaben umgewandelt wurden:

```py
developer = 'Jessica'

print(developer.upper()) # JESSICA
```

- **`str.lower()`**: Diese gibt einen neuen String zurück, bei dem alle Zeichen in Kleinbuchstaben umgewandelt wurden:

```py
developer = 'Jessica'

print(developer.lower()) # jessica
```

- **`str.strip()`**: Diese gibt eine Kopie des Strings zurück, bei der angegebene führende und abschließende Zeichen entfernt wurden (wenn kein Argument an die Methode übergeben wird, werden führende und abschließende Leerzeichen entfernt).

```py
greeting = '  hello world  '

trimmed_my_str = greeting.strip()
print(trimmed_my_str)  # hello world
```

- **`replace()`**: Diese Methode gibt einen neuen String zurück, bei dem alle Vorkommen des alten Strings durch einen neuen ersetzt wurden.

```py
greeting = 'hello world'

replaced_my_str = greeting.replace('hello', 'hi')
print(replaced_my_str)  # hi world
```

- **`split()`**: Diese Methode wird verwendet, um einen String mit einem angegebenen Trenner in eine Liste zu teilen. Ein Trenner ist ein String, der angibt, wo die Teilung erfolgen soll. Wenn kein Trenner angegeben wird, teilt `split()` am Leerzeichen.

```py
dashed_name = 'example-dashed-name'

split_words = dashed_name.split('-')
print(split_words)  # ['example', 'dashed', 'name']
```

- **`join()`**: Dies wird verwendet, um eine Sammlung von Strings mit einem Trennzeichen zu einem einzigen String zusammenzufügen.

```py
example_list = ['example', 'dashed', 'name']

joined_str = ' '.join(example_list)
print(joined_str)  # example dashed name
```

- **`str.startswith(prefix)`**: Diese gibt einen Boolean zurück, der angibt, ob ein String mit dem angegebenen Präfix beginnt:

```py
developer = 'Naomi'

result = developer.startswith('N')
print(result)  # True
```

- **`str.endswith(suffix)`**: Diese gibt einen Boolean zurück, der angibt, ob ein String mit dem angegebenen Suffix endet:

```py
developer = 'Naomi'

result = developer.endswith('N')
print(result)  # False
```

- **`str.find()`**: Diese Methode gibt den Index des ersten Vorkommens eines Teilstrings zurück. Wenn dieser nicht gefunden wird, wird `-1` zurückgegeben:

```py
developer = 'Naomi'

result = developer.find('N')
print(result)  # 0

city = 'Los Angeles'
print(city.find('New')) # -1
```

- **`str.count(substring)`**: Diese Methode zählt, wie oft ein Teilstring nicht überlappend in einem String vorkommt. Sobald eine Übereinstimmung gefunden wird, setzt die Suche nach dem Ende dieser Übereinstimmung fort:

```py
city = 'Los Angeles'
print(city.count('e')) # 2

# Matches do not overlap, so this is 2, not 3
print('aaaa'.count('aa')) # 2
```

- **`str.capitalize()`**: Diese gibt einen neuen String zurück, bei dem das erste Zeichen großgeschrieben und die anderen Zeichen kleingeschrieben sind:

```py
dessert = 'chocolate cake'
print(dessert.capitalize()) # Chocolate cake
```

- **`str.isupper()`**: Diese Methode gibt `True` zurück, wenn der String mindestens ein Zeichen mit Groß-/Kleinschreibung enthält und alle diese Zeichen Großbuchstaben sind. Andernfalls gibt sie `False` zurück:

```py
dessert = 'chocolate cake'
print(dessert.isupper()) # False
```

- **`str.islower()`**: Diese Methode gibt `True` zurück, wenn der String mindestens ein Zeichen mit Groß-/Kleinschreibung enthält und alle diese Zeichen Kleinbuchstaben sind. Andernfalls gibt sie `False` zurück:

```py
dessert = 'chocolate cake'
print(dessert.islower()) # True
```

- **`str.title()`**: Diese Methode gibt einen neuen String zurück, bei dem der erste Buchstabe jedes Wortes großgeschrieben und die übrigen Buchstaben kleingeschrieben sind:

```py
city = 'lOS aNGELES'
print(city.title()) # Los Angeles
```

## Weitere String-Operationen

- **Negative Slice-Grenzen**: Slice-Grenzen können rückwärts vom Ende eines Strings gezählt werden. Zum Beispiel extrahiert `[-3:]` die letzten drei Zeichen:

```py
employee_code = 'DEV-2026-JD-001'
print(employee_code[-3:]) # 001
```

- **Methodenverkettung**: Sie können mehrere String-Methoden in einem Ausdruck aufrufen. Jede Methode arbeitet auf dem Ergebnis des vorherigen Aufrufs:

```py
name = '  jANE dOE  '
print(name.strip().title()) # Jane Doe
```

## Häufig verwendete Operationen mit ganzen Zahlen und Fließkommazahlen

- **Grundlegende mathematische Operationen**: In Python können Sie grundlegende mathematische Operationen mit ganzen Zahlen und Fließkommazahlen durchführen, einschließlich Addition, Subtraktion, Multiplikation und Division:

```py
int_1 = 56
int_2 = 12
float_1 = 5.4
float_2 = 12.0

# Addition

print('Integer Addition:', int_1 + int_2) # Integer Addition: 68
print('Float Addition:', float_1 + float_2) # Float Addition: 17.4

# Subtraction

print('Int Subtraction:', int_1 - int_2) # Int Subtraction: 44
print('Float Subtraction:',  float_2 - float_1) # Float Subtraction: 6.6

# Multiplication

print('Int Multiplication:', int_1 * int_2) # Int Multiplication: 672
print('Float Multiplication:', float_2 * float_1) # Float Multiplication: 64.80000000000001

# Division

print('Division:', int_1 / int_2) # Division: 4.666666666666667
print('Float Division:', float_2 / float_1) # Float Division: 2.222222222222222
```

Wenn Sie einen Float und einen Integer addieren, wird das Ergebnis in einen Float umgewandelt, so:

```py
int_1 = 56
float_1 = 5.4

print(int_1 + float_1) # 61.4
```

- **Modulo-Operator (`%`)**: Dieser gibt den Rest zurück, wenn eine Zahl durch eine andere geteilt wird:

```py
int_1 = 56
int_2 = 12

print(int_1 % int_2) # 8
```

- **Ganzzahldivision (`//`)**: Dieser Operator wird verwendet, um zwei Zahlen zu dividieren und das Ergebnis auf die nächste ganze Zahl abzurunden:

```py
int_1 = 56
int_2 = 12

print(int_1 // int_2) # 4
```

- **Exponentiation-Operator (`**`)**: Dieser Operator wird verwendet, um eine Zahl mit der Potenz einer anderen zu potenzieren:

```py
int_1 = 4
int_2 = 2

print(int_1 ** int_2) # 16
```

- **Gleitkomma-Approximation**: Einige Dezimalbrüche können im Binärsystem nicht exakt dargestellt werden, daher werden sie als endliche Annäherungen gespeichert. Das kann kleine Rundungsfehler verursachen, wie das oben gezeigte Multiplikationsergebnis `64.80000000000001`.

```py
print(0.1 + 0.2) # 0.30000000000000004
```

- **`float()` Funktion**: Mit dieser Funktion können Sie eine ganze Zahl oder einen gültigen Dezimalstring in einen Float umwandeln oder einen speziellen Float-Wert erzeugen, der positive Unendlichkeit darstellt, die größer ist als jede endliche ganze Zahl oder Float:

```py
num = 4

print(float(num)) # 4.0
print(float('7.8')) # 7.8
print(float('inf')) # inf
```

- **`int()`-Funktion**: Sie können diese Funktion verwenden, um einen Float in einen Integer umzuwandeln.

```py
num = 4.0

print(int(num)) # 4
```

- **`round()` Funktion**: Mit einem Argument rundet diese Funktion eine Zahl auf die nächste ganze Zahl. Geben Sie ein zweites Argument an, um die Anzahl der Dezimalstellen zu bestimmen:

```py
num_1 = 3.4
num_2 = 7.7

print(round(num_1)) # 3
print(round(num_2)) # 8
print(round(3.14159, 2)) # 3.14
```

- **`abs()`-Funktion**: Diese wird verwendet, um den Absolutwert einer Zahl zurückzugeben:

```py
num = -13

print(abs(num)) # 13
```

- **`pow()` Funktion**: Diese Funktion potenziert eine Zahl mit einer anderen. Bei ganzzahligen Argumenten können Sie ein drittes, ungleich nulles Argument übergeben, um das Ergebnis modulo dieses Werts zu berechnen:

```py
result = pow(2, 3)
print(result)  # 8
print(pow(2, 3, 5)) # 3
```

## Erweiterte Zuweisungen

- **Erweiterte Zuweisung**: Die erweiterte Zuweisung wendet eine Operation auf eine Variable an und speichert das Ergebnis in derselben Variable, alles in einem Schritt.

```py
# Addition assignment
my_var = 10
my_var += 5

print(my_var) # 15

# Subtraction assignment
count = 14
count -= 3

print(count) # 11

# Multiplication assignment
product = 65
product *= 7

print(product) # 455

# Division assignment
price = 100
price /= 4

print(price) # 25.0

# Floor Division assignment
total_pages = 23
total_pages //= 5

print(total_pages) # 4

# Modulo assignment
bits = 35
bits %= 2

print(bits) # 1

# Exponentiation assignment
power = 2
power **= 3

print(power) # 8
```

```py
print(3 == 4) # False
```

- **Ungleich (`!=`)**: Prüft, ob zwei Werte ungleich sind:

```py
print(3 != 4) # True
```

```py
print(3 > 4) # False
```

```py
print(3 < 4) # True
```

```py
print(3 >= 4) # False
```

```py
print(3 <= 4) # True
```

## Arbeiten mit `if`-, `elif`- und `else`-Anweisungen

- **Codeblöcke und Einrückung**: Python verwendet Einrückungen, um Anweisungen zu einem Block zusammenzufassen, wie zum Beispiel den Körper einer Funktion oder einer Bedingung. Anweisungen im selben Block müssen die gleiche Einrückungsebene haben. Die Konvention ist, für jede Ebene vier Leerzeichen zu verwenden.

- **`pass` Anweisung**: `pass` macht nichts. Verwenden Sie es als Platzhalter, wo Python eine Anweisung verlangt, zum Beispiel bei einem leeren Bedingungskörper:

```py
age = 18
if age >= 18:
    pass
```

- **`if` Anweisungen**: Eine `if`-Anweisung führt ihren Körper aus, wenn Python die Bedingung als wahr behandelt.

```py
age = 18

if age >= 18:
    print('You are an adult') # You are an adult
```

- **`else` Klausel**: Eine `else`-Klausel führt ihren Körper aus, wenn Python alle vorherigen Bedingungen in derselben `if...elif...else`-Kette als falsch behandelt.

```py
age = 12

if age >= 18:
    print('You are an adult')
else:
    print('You are not an adult yet') # You are not an adult yet
```

- **`elif` Klausel**: Eine `elif`-Klausel prüft eine weitere Bedingung, wenn Python alle vorherigen Bedingungen in derselben Kette als falsch behandelt. Sie führt ihren Körper aus, wenn Python ihre eigene Bedingung als wahr behandelt.

```py
age = 16

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')  # You are a teenager
```

Sie können auch verschachtelte `if`-Anweisungen wie folgt verwenden:

```py
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

## Truthy- und Falsy-Werte

- **Wahrheitswertigkeit**: In Python hat jeder Wert einen inhärenten Boolean-Wert oder ein eingebautes Verständnis, ob er in einem logischen Kontext als `True` oder `False` behandelt werden soll. Viele Werte gelten als truthy, das heißt, sie werten in einem logischen Kontext zu `True`. Andere sind falsy, was bedeutet, dass sie zu `False` auswerten. Hier sind einige Beispiele für falsy-Werte:

```md
False
None
Integer 0
Float 0.0
Empty strings ''
```

Andere Werte wie Nicht-Null-Zahlen und nicht-leere Strings sind truthy.

## Arbeiten mit der `bool()`-Funktion

- **`bool()` Funktion**: Wenn Sie prüfen möchten, ob ein Wert truthy oder falsy ist, können Sie die eingebaute `bool()`-Funktion verwenden. Sie wandelt einen Wert explizit in sein Boolean-Äquivalent um und gibt `True` für truthy-Werte und `False` für falsy-Werte zurück. Hier sind einige Beispiele:

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

## Boolean-Operatoren und Kurzschlussauswertung

- **Boolean-Operatoren**: Das sind spezielle Operatoren, mit denen Sie mehrere Ausdrücke kombinieren können, um komplexere Entscheidungslogik in Ihrem Code zu erstellen. Es gibt drei Boolean-Operatoren in Python: `and`, `or` und `not`.
- **`and` Operator**: Dieser Operator nimmt zwei Operanden und gibt den ersten Operand zurück, wenn er falsy ist; andernfalls gibt er den zweiten Operand zurück. Beide Operanden müssen truthy sein, damit ein Ausdruck einen truthy-Wert ergibt.

```py
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

Sie können den `and`-Operator auch in Bedingungen wie folgt verwenden:

```py
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

- **`or`-Operator**: Dieser Operator gibt den ersten Operanden zurück, wenn dieser truthy ist; andernfalls gibt er den zweiten Operanden zurück. Ein `or`-Ausdruck ergibt einen truthy-Wert, wenn mindestens ein Operand truthy ist. Hier ist ein Beispiel:

```py
age = 19
is_employed = False

print(age or is_employed) # 19
```

Wie beim `and`-Operator können Sie den `or`-Operator in Bedingungen wie folgt verwenden:

```py
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

- **Kurzschlussauswertung**: Die `and`- und `or`-Operatoren sind als Kurzschlussoperatoren bekannt. Kurzschlussauswertung bedeutet, dass Python Werte von links nach rechts prüft und stoppt, sobald das endgültige Ergebnis bestimmt ist.
- **`not`-Operator**: Dieser Operator nimmt einen einzelnen Operanden und invertiert dessen Boolean-Wert. Er wandelt truthy-Werte in `False` und falsy-Werte in `True` um. Im Gegensatz zu den vorherigen Operatoren gibt `not` immer `True` oder `False` zurück. Hier sind einige Beispiele:

```py
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

Hier ist ein Beispiel für den `not`-Operator in einer Bedingung:

```py
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

## Identitätsoperatoren

- **Identität und Gleichheit**: Variablen verweisen auf Objekte. Der `is`-Operator prüft, ob zwei Operanden auf dasselbe Objekt verweisen, während `is not` prüft, ob sie auf unterschiedliche Objekte verweisen. Die Operatoren `==` und `!=` vergleichen stattdessen Werte. Verwenden Sie Gleichheitsoperatoren, wenn Sie Zahlen- oder Stringwerte vergleichen.
- **`None` und `NoneType`**: `None` steht für das Fehlen eines Werts. Es ist der einzige Wert des Datentyps `NoneType`.
- **Singletons**: `None`, `True` und `False` sind jeweils Singletons, das heißt, es gibt genau ein Objekt für jeden dieser Werte. Sie können diese Objekte mit Identitätsoperatoren prüfen.
- **Prüfen auf `None`**: Verwenden Sie `is None`, um auf einen fehlenden Wert zu prüfen, und `is not None`, um auf einen vorhandenen Wert zu prüfen. Sowohl `None` als auch `False` sind falsy, aber sie sind unterschiedliche Objekte:

```py
response = False

print(response is None) # False
print(response is not None) # True
print(response is True) # False
print(response is False) # True
```

- **Identität und Wahrheitswertigkeit**: Wenn `response` `True`, `False` oder `None` sein kann, unterscheidet `response is None` eine fehlende Antwort von einer negativen Antwort. Die Verwendung von `not response` würde sowohl `False` als auch `None` gleich behandeln. Für gewöhnliche Boolean-Flags verwenden Sie `if is_ready` oder `if not is_ready`. Verwenden Sie `is True` oder `is False`, wenn Sie speziell ein Boolean-Objekt von anderen möglichen Werten unterscheiden müssen.

## Vorrang der Boolean-Operatoren

- **Operatorpriorität und runde Klammern**: Wenn `and` und `or` im selben Ausdruck vorkommen, hat `and` eine höhere Priorität als `or`. Das bedeutet, dass `and` seine Operanden zuerst gruppiert, sodass `True or False and False` als `True or (False and False)` gruppiert wird:

```py
print(True or False and False) # True
```

Der linke Operand von `or` ist `True`, daher bedeutet Short-Circuiting, dass `False and False` nie ausgewertet wird und das Ergebnis `True` ist.

Sie können runde Klammern verwenden, um die Gruppierung zu ändern. Hier werden `True or False` zusammengefasst und zu `True` ausgewertet, und dann wird `True and False` zu `False` ausgewertet:

```py
print((True or False) and False) # False
```

## Häufige eingebaute Funktionen

- **`input()`-Funktion**: Diese wird verwendet, um den Benutzer zur Eingabe aufzufordern:

```py
name = input('What is your name?') # User types 'Kolade' and presses Enter
print('Hello', name) # Hello Kolade
```

- **`int()`-Funktion**: Diese Funktion wird verwendet, um eine Zahl, einen Boolean oder einen String, der eine ganze Zahl darstellt, in eine ganze Zahl umzuwandeln:

```py
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0

# A string representing a decimal number cannot be converted directly
# int('3.14') raises a ValueError
```

## Arbeiten mit Funktionen

- **Funktionen**: Funktionen sind wiederverwendbare Codeabschnitte, die ausgeführt werden, wenn Sie sie aufrufen. Um eine Funktion aufzurufen, müssen Sie den Funktionsnamen gefolgt von runden Klammern angeben:

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

- **Parameter und Argumente**: Parameter sind die Namen, die in einer Funktionsdefinition aufgeführt sind, wie `num_1` und `num_2` oben. Argumente sind die Werte, die beim Aufruf der Funktion übergeben werden, wie `3` und `4`.

Wenn Sie die Funktion mit einer falschen Anzahl von Argumenten aufrufen, erhalten Sie einen `TypeError`:

```py
def calculate_sum(a, b):
    print(a + b)

calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

- **Positionsargumente**: Diese Argumente werden anhand ihrer Position im Funktionsaufruf den Parametern zugeordnet.

```py
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

- **Schlüsselwortargumente**: Diese Argumente verwenden `name=value`, um einen Parameter nach Namen zuzuordnen. Sie können in einer anderen Reihenfolge als die Parameter erscheinen:

```py
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

- **Kombinieren von Argumenttypen**: Positionsargumente müssen vor Schlüsselwortargumenten stehen. Jeder Parameter kann nur einen Wert erhalten:

```py
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

- **`return` Anweisung**: Eine `return`-Anweisung beendet die Funktion und macht ihren Wert dort verfügbar, wo die Funktion aufgerufen wurde.

- **`None`**: `None` steht für das Fehlen eines Werts. Wenn eine Funktion keinen Wert explizit zurückgibt, ist der Standard-Rückgabewert `None`:

```py
def greet():
    print('hello')

result = greet() # hello
print(result) # None
```

## Gültigkeitsbereich in Python

Python hat zusätzliche Regeln für den Gültigkeitsbereich. Konzentrieren Sie sich vorerst auf den lokalen und globalen Gültigkeitsbereich.

- **Globaler Gültigkeitsbereich**: Eine Variable, die außerhalb einer Funktion erstellt wird, kann sowohl innerhalb als auch außerhalb von Funktionen verwendet werden.

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + (subtotal * tax)
    return total

print(get_total(100))  # 170.0
```

- **Lokaler Gültigkeitsbereich**: Eine Variable, die innerhalb einer Funktion erstellt wird, kann nur innerhalb dieser Funktion verwendet werden. Funktionsparameter sind ebenfalls lokale Variablen.

```py
def my_func():
    num = 10
    print(num)
```

- **Argumentübergabe und Parameter-Neuzuweisung**: Python übergibt Argumente durch Zuweisung. Ein Parameter ist ein lokaler Name, der zunächst auf das übergebene Objekt verweist; das Objekt wird nicht automatisch kopiert. Die Neuzuweisung des Parameters ändert nicht die Variable, die als Argument übergeben wurde:

```py
def double_number(number):
    number = number * 2
    print(number) # 20

original = 10
double_number(original)
print(original) # 10
```

## Anwenden von Funktionen und Gültigkeitsbereich

- **Leere Funktionskörper**: Sie können `pass` als Platzhalter in einem Funktionskörper verwenden. Eine Funktion, die nur `pass` enthält, gibt implizit `None` zurück:

```py
def placeholder():
    pass

print(placeholder()) # None
```

- **Namensüberschattung**: Wenn ein lokaler Parameter oder eine lokale Variable denselben Namen wie eine globale Variable hat, verwendet die Funktion den lokalen Namen. Die Neuzuweisung dieses lokalen Parameters ändert die globale Variable nicht:

```py
available_eggs = 5

def use_eggs(available_eggs, eggs_to_use):
    available_eggs -= eggs_to_use
    return available_eggs

print(use_eggs(available_eggs, 1)) # 4
print(available_eggs) # 5
```

- **Frühe Rückgaben**: Eine `return`-Anweisung beendet die Funktion sofort und macht ihren Wert dort verfügbar, wo die Funktion aufgerufen wurde. So können Sie frühzeitig zurückkehren, wenn eine Bedingung erfüllt ist:

```py
def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        return available_eggs
    return available_eggs - eggs_to_use

print(use_eggs(2, 3)) # 2
print(use_eggs(2, 1)) # 1
```

- **Aufrufen von Funktionen aus anderen Funktionen**: Eine Funktion kann eine andere Funktion aufrufen und deren Ergebnis verwenden oder zurückgeben:

```py
def use_eggs(available_eggs, eggs_to_use):
    return available_eggs - eggs_to_use

def make_fried_egg(available_eggs):
    return use_eggs(available_eggs, 1)

print(make_fried_egg(3)) # 2
```

- **Zuweisen von Rückgabewerten**: Das Zurückgeben eines neuen Werts aktualisiert nicht automatisch die als Argument übergebene Variable. Um sie zu aktualisieren, weisen Sie den Rückgabewert dieser Variablen erneut zu:

```py
available_eggs = use_eggs(available_eggs, 1)
print(available_eggs) # 4
```

## Strings übersetzen

- **`str.maketrans()`**: Die Zwei-String-Form von `str.maketrans()` nimmt Strings gleicher Länge und ordnet jedes Zeichen im ersten String dem entsprechenden Zeichen im zweiten zu. Die Tabelle speichert Zeichen als Unicode-Ordinals, Zahlen, die sie eindeutig identifizieren. Die Methode `translate()` wendet die Tabelle auf einen String an und gibt einen neuen String zurück. Zeichen, die nicht in der Tabelle enthalten sind, bleiben unverändert.

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc!'.translate(trans_table)
print(result)  # 123123!
```

## Validierung von Integer-Argumenten

- **Booleans und ganze Zahlen**: Python behandelt Booleans als eine spezielle Art von ganzen Zahlen, daher geben `isinstance(True, int)` und `isinstance(False, int)` beide `True` zurück. Wenn Sie eine ganze Zahl validieren, die kein Boolean sein darf, schließen Sie Boolean-Werte explizit aus:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True

value = True
print(isinstance(value, int) and not isinstance(value, bool)) # False

value = 5
print(isinstance(value, int) and not isinstance(value, bool)) # True
```

## Standardwerte für Parameter

- **Standardparameter**: Sie können einem Parameter einen Standardwert zuweisen. Wenn Sie beim Aufruf der Funktion kein Argument übergeben, verwendet Python diesen Standardwert:

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```
