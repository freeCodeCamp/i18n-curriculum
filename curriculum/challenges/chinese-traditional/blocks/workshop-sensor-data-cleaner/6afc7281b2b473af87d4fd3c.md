# --description--

現在你需要將每個溫度與其標籤配對。

`map()` 函式可以接受多個可迭代物件。每次呼叫時，它會從每個可迭代物件中傳遞一個項目給函式，因此函式需要有與可迭代物件數量相同的參數：

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

創建一個名為 `report` 的變數。將 `map()` 傳入一個 lambda 函式、`temperatures` 和 `difference_labels`，並用 `list()` 包裹後的結果指定給它。該 lambda 函式應該接受兩個參數，分別是 `temperature` 和 `difference_label`，並傳回 `f'{temperature} °C ({difference_label})'`。

然後，列印 `report`，而不是 `difference_labels`。
