# --description--

In Python sind Variablen Namen, die auf Objekte verweisen. Identitätsoperatoren prüfen, ob zwei Operanden auf dasselbe Objekt verweisen. Der `is`-Operator gibt `True` zurück, wenn dies der Fall ist, und sonst `False`. Der `is not`-Operator liefert das gegenteilige Ergebnis.

Identität unterscheidet sich von Gleichheit: `==` und `!=` vergleichen Werte, während `is` und `is not` die Objektidentität vergleichen. Verwenden Sie Gleichheitsoperatoren, wenn Sie Zahlen- oder Stringwerte vergleichen.

`None` steht für das Fehlen eines Werts. Es ist der einzige Wert des Datentyps `NoneType`.

Drei Objekte, die Sie mit Identitätsoperatoren prüfen können, sind `None`, `True` und `False`. Jedes ist ein Singleton, das heißt, es gibt genau ein Objekt für jedes davon.

## Prüfung auf `None`

Sie können `is None` verwenden, um zu prüfen, ob ein Wert fehlt, oder `is not None`, um zu prüfen, ob er vorhanden ist:

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None` ist falsy, aber es ist nicht dasselbe Objekt wie `False`. Zum Beispiel könnte eine Antwort `True` für ja, `False` für nein oder `None` sein, wenn keine Antwort gegeben wurde:

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

Die Verwendung von `if not response` würde dagegen sowohl `False` als auch `None` gleich behandeln. Die Identitätsprüfung unterscheidet eine negative Antwort von einer fehlenden Antwort.

## Prüfung auf `True` und `False`

Sie können Identität auch verwenden, um speziell auf die Boolean-Objekte zu prüfen:

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

Diese Prüfungen fragen, ob `response` genau `True`, `False` oder ein anderes Objekt als `None` ist. Sie testen nicht einfach die Wahrhaftigkeit.

Für gewöhnliche Boolean-Flags verwenden Sie direkte Wahrheitsprüfungen wie `if is_ready` oder `if not is_ready`. Verwenden Sie `is True` oder `is False`, wenn Sie speziell ein Boolean-Objekt von anderen möglichen Werten unterscheiden müssen, wie bei einer Antwort, die auch `None` sein kann.
