# --description--

Іноді число підходить для ваших обчислень, але виглядає трохи незавершеним, коли ви його виводите. Наприклад, якщо ви показуєте ціну, `12.50` може виглядати природніше, ніж `12.5`.

f-рядок дозволяє контролювати, як число виглядає при відображенні, не змінюючи початкове значення, тож ви можете й надалі використовувати його в обчисленнях.

## Як працюють специфікації формату

Вираз `f"{value:.2f}"` відображає `value` з точно двома цифрами після десяткової крапки.

У дужках кожен символ має конкретну роль:

- Двокрапка `:` вводить специфікацію формату
- `.2` вибирає два десяткові знаки
- `f` вибирає фіксований формат, який відображає число у десятковій нотації.

Це означає, що `print(f"{12.5:.2f}")` виводить `12.50`, при цьому початкове значення залишається незмінним:

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

Вихідні дані показують `12.50`, тому що специфікація формату `.2f` завжди відображає два десяткові знаки, тож Python доповнює результат нулем наприкінці. Значення, збережене в `value`, все ще `12.5`.


З іншого боку, форматування значення на кшталт `12.3456` з `.2f` дає `12.35`, бо число потрібно округлити для відображення:

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## Форматування за допомогою f-рядка дає рядок

f-рядок дає рядок:

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

Це означає, що ви можете зберегти отриманий рядок окремо і все одно використовувати початкове число в обчисленнях.

## Чим `round()` відрізняється від форматування f-рядком

Вираз на кшталт `round(value, 2)` дає числовий результат, який можна використовувати в подальших обчисленнях.

Вивід цього результату використовує звичайне відображення чисел у Python, тому нулі в кінці не гарантуються:

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## Форматування не змінює початкове значення

Як ви бачили раніше, деякі десяткові числа, як-от `0.1` і `0.2`, можна лише наближено подати у вигляді float. Тому їхня сума може виглядати трохи дивно при прямому виводі:

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

Як бачите, f-рядок округлює суму для відображення. Будь-які обчислення, що використовують `total`, все одно працюють із тим самим числом з плаваючою комою.
