# --description--

`departmentEntries`의 각 항목은 `[key, value]` 형태의 작은 배열입니다. 인덱스(`entry[0]`, `entry[1]`)로 접근하는 대신, 배열 구조 분해를 사용해 한 줄로 이름 있는 변수에 풀어낼 수 있습니다.

`departmentEntries[i]`를 `departmentName`과 `departmentData`로 구조 분해하세요. 그런 다음 두 개의 별도 `console.log()` 문을 사용하세요:
하나는 `departmentName`을 출력하고 다른 하나는 `departmentData`를 출력합니다.
