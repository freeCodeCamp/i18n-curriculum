# --description--

من المحتمل أنك تعرف بالفعل بعض الاختصارات الأساسية، التي ترثها من نظام التشغيل الخاص بك. اختصارات مثل <kbd>Ctrl</kbd> + <kbd>S</kbd> (ويندوز/لينكس) أو <kbd>Cmd</kbd> + <kbd>S</kbd> (ماك) للحفظ، و<kbd>Ctrl</kbd> + <kbd>C</kbd> أو <kbd>Cmd</kbd> + <kbd>C</kbd> للنسخ، و<kbd>Ctrl</kbd> + <kbd>V</kbd> أو <kbd>Cmd</kbd> + <kbd>V</kbd> للصق تعمل كلها في VS Code.

لكن هناك بعض الاختصارات الخاصة بالتطبيق والتي يمكنها رفع إنتاجيتك. يجدر بالذكر أن بعض هذه الاختصارات قد تختلف حسب نظام التشغيل.

على سبيل المثال، <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> يشغّل أداة التنسيق المهيأة لديك (مثل Prettier لمشروع جافاسكريبت) على الملف المفتوح حاليًا.

استخدم <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (ويندوز/لينكس) أو <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (ماك) للبحث في محتوى نصوص جميع الملفات في مساحة العمل. ثم استخدم <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (ويندوز/لينكس) أو <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (ماك) إذا أردت تشغيل البحث والاستبدال.

إذا احتجت إلى حذف سطر، <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (ويندوز/لينكس) أو <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (ماك) سيحذفه.

هل تحتاج إلى مساحة إضافية لكل كودك؟ <kbd>Ctrl</kbd> + <kbd>B</kbd> (ويندوز/لينكس)، أو <kbd>Cmd</kbd> + <kbd>B</kbd> (ماك)، يخفي الشريط الجانبي الذي يحتوي على قائمة الملفات وقائمة الإضافات.

أو ربما لا ترى كودك؟ <kbd>Ctrl</kbd> + <kbd>Plus</kbd> (ويندوز/لينكس)، أو <kbd>Cmd</kbd> + <kbd>Plus</kbd> (ماك)، يزيد تكبير المحرر، و<kbd>Ctrl</kbd> + <kbd>Minus</kbd> (ويندوز/لينكس)، أو <kbd>Cmd</kbd> + <kbd>Minus</kbd> (ماك)، يقلل التكبير.

ميزة مفيدة أخرى في VS Code هي التحرير متعدد الأسطر، الذي يسمح بإجراء تغييرات عبر عدة أسطر دفعة واحدة. على سبيل المثال، يمكنك وضع عدة مؤشرات باستخدام <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> و<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (ويندوز)، <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> و<kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (لينكس)، أو <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Down</kbd> و<kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Up</kbd> (ماك)، لتمديد المؤشر إلى أسطر متتالية. يمكنك أيضًا الضغط مع الاستمرار على <kbd>Alt</kbd> (ويندوز/لينكس) أو <kbd>Option</kbd> (ماك) والنقر لإضافة مؤشرات على أسطر منفصلة حيثما تحتاجها. بمجرد وضع المؤشرات، أي شيء تكتبه أو تحذفه سيطبق على كل تلك المواقع في نفس الوقت، مما يوفر الكثير من الوقت عند العمل مع كود متكرر.

أخيرًا، إذا نسيت أيًا من هذه الاختصارات، لديك دائمًا <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (ويندوز/لينكس) أو <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (ماك)، التي تفتح لوحة الأوامر لتختار ما تحتاجه.
