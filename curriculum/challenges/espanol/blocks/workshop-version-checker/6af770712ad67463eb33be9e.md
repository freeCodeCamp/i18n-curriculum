# --description--

Las tuplas son inmutables, así que no puedes agregar un elemento a `releases`. En lugar de eso, puedes usar el operador `+` para crear una nueva tupla que una los elementos de dos tuplas:

```py
numbers = (1, 2)
print(numbers + (3, 4)) # (1, 2, 3, 4)
```

`new_version` es una tupla en sí misma, así que `releases + new_version` agregaría sus tres números como elementos separados. Para agregarla como un solo elemento, envuélvela en una tupla con un elemento. Recuerda que una tupla con un solo elemento necesita una coma al final.

Al final de tu función, devuelve el resultado de unir `releases` y una tupla que contenga solo `new_version`.

    sorted_releases = tuple(sorted(releases, reverse=True))
    latest = sorted_releases[0]

    if installed not in releases:
        return 'not a known release', latest

        return 'up to date', latest

    if installed[0] < latest[0]:
        update_type = 'major update'
    elif installed[:2] < latest[:2]:
        update_type = 'minor update'
    else:
        update_type = 'patch update'

    return f'{update_type} available, releases behind: {releases_behind}', latest


def release_version(releases, release_type, base_version=None):
    if base_version is None:
        base_version = sorted(releases, reverse=True)[0]
    elif base_version not in releases:
        print(f'{base_version} is not a known release')
        return releases

    if release_type == 'major':
        new_version = (major + 1, 0, 0)
    elif release_type == 'minor':
        new_version = (major, minor + 1, 0)
    elif release_type == 'patch':
        new_version = (major, minor, patch + 1)
    else:
        print(f'{release_type} is not a valid release type')
        return releases

    if new_version in releases:
        print(f'{new_version} has already been released')
        return releases
