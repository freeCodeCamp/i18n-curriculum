## Arrays

- **Statische Arrays**: Haben eine feste Größe, die bei der Initialisierung bestimmt wird. Die Elemente werden an benachbarten Speicherstellen gespeichert, was den Zugriff sehr effizient macht. Ihre Größe kann während der Programmausführung nicht geändert werden.

- **Dynamische Arrays**: Können sich während der Programmausführung automatisch vergrößern oder verkleinern. Wenn das Array voll ist, werden seine Elemente in ein neues, größeres Array kopiert. Die neue Größe wird so gewählt, dass diese teuren Kopiervorgänge seltener auftreten.

- **Statische Arrays in Python**: Python enthält keine traditionellen statischen Arrays als eingebaute Datenstrukturen. Andere Sprachen wie Java unterstützen sie jedoch.

### Python-Listen (dynamische Arrays)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### Zeitkomplexitäten für dynamische Arrays

- **Zugreifen**: O(1)
- **Einfügen am Ende**: O(1), wenn Platz vorhanden ist, O(n), wenn eine Größenänderung nötig ist
- **Einfügen in der Mitte**: O(n), da die nachfolgenden Elemente verschoben werden müssen

### Auswahl zwischen statischen und dynamischen Arrays

- **Statische Arrays**: Wenn Sie die Anzahl der Elemente im Voraus kennen und häufig darauf zugreifen müssen.
- **Dynamische Arrays**: Wenn die Anzahl der Elemente unbekannt ist oder sich im Laufe der Zeit ändert, oder wenn Sie häufig Elemente einfügen und löschen.

## Stacks

- **Stacks**: Last-In, First-Out (LIFO) Datenstruktur. Stacks haben zwei Enden, oben und unten. Elemente werden nur oben hinzugefügt und entfernt.

- **Push-Operation**: Ein Element oben auf den Stack legen. Bei Verwendung einer Python-Liste dauert dies O(1), wenn Platz vorhanden ist, oder O(n), wenn eine Größenänderung nötig ist.

- **Pop-Operation**: Ein Element vom oberen Ende des Stacks entfernen. Zeitkomplexität: O(1). Speicherkomplexität: O(1).

```python
# Using a Python list as a stack, where the end of the list is the top
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operation
top_element = stack.pop()  # Returns 3
```

## Queues

- **Queues**: First-In, First-Out (FIFO) Datenstruktur. Queues haben zwei Enden, vorne und hinten. Elemente werden hinten hinzugefügt und vorne entfernt.

- **Enqueue-Operation**: Ein Element hinten in die Queue einfügen. Bei Verwendung einer Python-Liste dauert dies O(1), wenn Platz vorhanden ist, oder O(n), wenn eine Größenänderung nötig ist.

- **Dequeue-Operation**: Ein Element von vorne aus der Queue entfernen. Das nächste Element in der Reihe wird zum neuen vorderen Element. Zeitkomplexität: O(1). Speicherkomplexität: O(1).

```python
# Using a Python list as a queue, where the start of the list is the front
queue = []

# Enqueue operations
queue.append(1)
queue.append(2)
queue.append(3)

# Front element
front_element = queue[0]  # 1

# Dequeue operation
front_element = queue.pop(0)  # Returns 1
```

- **Hinweis**: Das Entfernen des ersten Elements einer Python-Liste mit `.pop(0)` verschiebt alle verbleibenden Elemente, daher dauert es O(n).

## Verkettete Listen

- **Verkettete Listen**: Lineare Datenstruktur, bei der jeder Knoten Daten und eine Referenz auf den nächsten Knoten speichert. Die Knoten sind wie eine Kette verbunden. Verkettete Listen haben keine feste Größe und können durch Aktualisieren der Verbindungen zwischen den Knoten wachsen oder schrumpfen.

- **Häufige Anwendungen**: Implementierung anderer Datenstrukturen wie Stacks, Queues und Deques sowie Graphalgorithmen wie Tiefensuche und Breitensuche.

### Einfach verkettete Listen

- **Struktur**: Jeder Knoten speichert Daten und eine Referenz auf den nächsten Knoten.
- **Durchlaufen**: Kann nur vorwärts gehen, vom Kopf bis zum Ende.
- **Kopf-Knoten**: Erster Knoten in der Liste, normalerweise der einzige direkt zugängliche Knoten. Das Durchlaufen beginnt hier.
- **End-Knoten**: Letzter Knoten in der Liste. Seine Referenz auf den nächsten Knoten ist `None`, was das Ende der Liste markiert.

#### Knoten einfügen

- **Einfügen am Anfang**: O(1) – den neuen Knoten mit dem alten Kopf verbinden und ihn zum neuen Kopf machen
- **Einfügen am Ende**: O(n) – bis zum Ende durchlaufen, dann den alten Endknoten mit dem neuen Knoten verbinden
- **Einfügen in der Mitte**: O(n) – bis zur Position durchlaufen, dann den vorherigen Knoten mit dem neuen Knoten und den neuen Knoten mit dem nächsten Knoten verbinden
- **Speicherkomplexität**: O(1) – es wird nur der neue Knoten erstellt

#### Knoten entfernen

- **Entfernen am Anfang**: O(1) – den nächsten Knoten zum neuen Kopf machen
- **Entfernen in der Mitte**: O(n) – bis zum Knoten durchlaufen, dann den vorherigen Knoten mit dem nächsten Knoten verbinden und so eine "Brücke" über den entfernten Knoten bilden
- **Entfernen am Ende**: O(n) – bis zum Ende durchlaufen, dann die Verbindung des vorherigen Knotens entfernen und ihn zum neuen Endknoten machen
- **Speicherkomplexität**: O(1) – es wird kein zusätzlicher Speicher benötigt

### Doppelt verkettete Listen

- **Struktur**: Jeder Knoten speichert Daten und zwei Referenzen: eine auf den nächsten Knoten und eine auf den vorherigen Knoten.
- **Durchlaufen**: Kann in beide Richtungen gehen.
- **End-Referenz**: Es ist üblich, eine Referenz auf den Endknoten in der Liste selbst zu speichern. Das ermöglicht das Hinzufügen von Knoten am Ende in O(1), ohne die Liste durchlaufen zu müssen, und das Starten eines Durchlaufs vom Ende.
- **Einfügen und Löschen**: Funktionieren wie bei einfach verketteten Listen, aber es müssen zwei Referenzen pro Knoten aktualisiert werden.
- **Speicher**: Benötigt mehr Speicher als einfach verkettete Listen, da jeder Knoten zwei Referenzen statt einer speichert.

## Wann welche Datenstruktur verwenden

- **Statische Arrays**: Wenn die Anzahl der Elemente im Voraus bekannt ist und schneller, häufiger Zugriff benötigt wird
- **Dynamische Arrays (Listen)**: Wenn Sie geordneten, indizierten Zugriff benötigen und die Größe nicht im Voraus kennen
- **Stacks**: Wenn das zuletzt hinzugefügte Element als erstes entfernt werden soll (LIFO)
- **Queues**: Wenn Elemente in der Reihenfolge verarbeitet werden sollen, in der sie hinzugefügt wurden (FIFO)
- **Einfach verkettete Listen**: Wenn sich die Größe oft ändert und Sie hauptsächlich am Anfang einfügen und entfernen
- **Doppelt verkettete Listen**: Wenn Sie in beide Richtungen durchlaufen oder Elemente am Ende effizient hinzufügen müssen und der zusätzliche Speicher pro Knoten akzeptabel ist
