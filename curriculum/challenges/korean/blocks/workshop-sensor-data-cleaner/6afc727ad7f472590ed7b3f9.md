# --description--

측정값을 다루기 전에 오류 코드를 제거해야 합니다.

이전 수업에서 배운 것처럼, `filter()` 함수는 함수가 참 같은 값을 반환하는 반복 가능한 항목만 유지합니다. 그 함수를 `def`로 정의하는 대신, 람다 함수를 직접 `filter()`에 전달할 수 있습니다:

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

`valid_readings`라는 변수를 만드세요. `filter()`에 람다 함수와 `readings`를 전달한 결과를 할당하세요. 람다 함수는 `reading`이라는 매개변수를 받고, `reading`이 `-999`와 같지 않은지 확인해야 합니다.

그런 다음 `readings` 대신 `valid_readings`를 출력하세요.
