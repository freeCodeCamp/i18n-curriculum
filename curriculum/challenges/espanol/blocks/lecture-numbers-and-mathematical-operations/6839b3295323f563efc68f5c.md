# --description--

Ya has usado la asignación aumentada con cadenas. Ahora, veamos cómo funciona con números. La asignación aumentada aplica una operación y almacena el resultado en la misma variable, todo en un solo paso.

La sintaxis básica de una asignación aumentada se ve así:

```python
variable <operator>= value
```

Para variables numéricas, esta es una forma más corta de escribir la siguiente asignación:

```python
variable = variable <operator> value
```

Por ejemplo, puedes usar la asignación aumentada para agregar `5` a una variable existente:

```python
my_var = 10
my_var += 5

print(my_var) # 15
```

Y aquí está lo mismo, pero sin asignación aumentada:

```python
my_var = 10
my_var = my_var + 5

print(my_var) # 15
```

La ventaja de la asignación aumentada es que ofrece una forma concisa y legible de actualizar el valor de una variable sin repetir el nombre de la variable. A su vez, esto reduce la redundancia y posibles errores que puedan surgir por un error tipográfico o algo similar.

Los operadores aritméticos y bit a bit tienen formas de asignación aumentada. Ya vimos el operador de asignación de suma (`+=`), así que veamos otros.

- El operador de asignación de resta (`-=`) resta el operando derecho de la variable izquierda y almacena la diferencia en la variable izquierda:

```python
count = 14
count -= 3

print(count) # 11
```

- El operador de asignación de multiplicación (`*=`) multiplica la variable izquierda por el operando derecho y almacena el producto nuevamente en la variable izquierda:
    

```python
product = 65
product *= 7

print(product) # 455
```

- El operador de asignación de división (`/=`) divide la variable izquierda por el derecho y almacena el resultado nuevamente en la variable izquierda:
    

```python
price = 100
price /= 4

print(price) # 25.0
```

- El operador de asignación de división entera (`//=`) divide con piso la variable izquierda por la derecha y almacena el resultado en la variable izquierda:
    

```python
total_pages = 23
total_pages //= 5

print(total_pages) # 4
```

- El operador de asignación módulo (`%=`) calcula el resto de la variable izquierda dividida por la derecha y lo almacena de nuevo en la variable izquierda:
    

```python
bits = 35
bits %= 2

print(bits) # 1
```

- El operador de asignación de exponenciación (`**=`) eleva la variable izquierda a la potencia del derecho y almacena el resultado nuevamente en la variable izquierda:
    

```python
power = 2
power **= 3

print(power) # 8
```
