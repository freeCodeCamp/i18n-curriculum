# --description--

Neste laboratório, você vai implementar uma estrutura de dados pilha usando funções. Uma pilha é uma estrutura de dados Last-In-First-Out (LIFO), onde os elementos são adicionados e removidos do topo.

Sua pilha será um dicionário cuja chave `collection` contém uma lista de elementos. O topo da pilha é o final da lista, então o último elemento da lista é o mais recentemente adicionado.

**Objetivo:** Cumprir as user stories abaixo e fazer todos os testes passarem para completar o laboratório.

**Histórias de Usuário:**

1. Você deve ter uma função `init_stack` que retorna um dicionário com a chave `collection` definida como uma lista vazia.
1. Você deve ter uma função `push` que recebe uma pilha e um elemento, e adiciona o elemento ao topo da pilha.
1. Você deve ter uma função `pop` que recebe uma pilha, remove e retorna seu elemento do topo, ou retorna `None` se a pilha estiver vazia.
1. Você deve ter uma função `peek` que recebe uma pilha, e retorna seu elemento do topo sem removê-lo, ou retorna `None` se a pilha estiver vazia.
1. Você deve ter uma função `is_empty` que recebe uma pilha, e retorna `True` se ela não contiver elementos, e `False` caso contrário.
1. Você deve ter uma função `clear` que recebe uma pilha, e remove todos os seus elementos.

**Nota:** A maioria dos testes depende das funções `init_stack` e `push`. Implemente-as primeiro, pois os testes para `pop`, `peek`, `is_empty` e `clear` exigem adicionar elementos à pilha.

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
