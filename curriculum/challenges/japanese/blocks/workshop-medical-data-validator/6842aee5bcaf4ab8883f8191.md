# --description--

前のレッスンで学んだように、辞書はキーと値のペアを保存します。各キーは辞書内で一意である必要があります。文字列はキーとしてよく使われます：

```py
person = {
    'name': 'John',
    'age': 33
}
```

`medical_records` リストは辞書を格納し、それぞれが患者を表します。`patient_id` リストに、キーが `P1001` で値が文字列の `medical_records` の辞書を追加してください。

# --hints--

あなたの `medical_records` リストには、1つの辞書が含まれているはずです。

```js
({ test: () => runPython(`
assert isinstance(medical_records[0], dict) and len(medical_records) == 1
`) })
```

辞書にはキー `patient_id` があり、その値は文字列 `P1001` である必要があります。

```js
({ test: () => runPython(`
assert medical_records[0].get("patient_id", None) == "P1001"
`) })
```
