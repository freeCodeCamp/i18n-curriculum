# --description--

解包讓你可以在一行中將列表的條款指定給多個變數。你可以使用帶星號的變數來收集剩下的條款成為一個列表：

```py
fruits = ['apple', 'banana', 'cherry']
first, *rest = fruits
print(first) # apple
print(rest) # ['banana', 'cherry']
```
