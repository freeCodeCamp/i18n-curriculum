# --description--

解包让你可以在一行中将列表的项赋值给多个变量。你可以使用带星号的变量将剩余的项收集到一个列表中：

```py
fruits = ['apple', 'banana', 'cherry']
first, *rest = fruits
print(first) # apple
print(rest) # ['banana', 'cherry']
```
