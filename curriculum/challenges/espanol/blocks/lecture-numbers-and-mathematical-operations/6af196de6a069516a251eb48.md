# --description--

A veces un número está bien para tus cálculos pero se ve un poco incompleto cuando lo imprimes. Si estás mostrando un precio, por ejemplo, `12.50` puede parecer más natural que `12.5`.

Una f-string te permite controlar cómo se ve un número al mostrarse, sin cambiar el valor original, para que puedas seguir usándolo en cálculos.

## Cómo funcionan las especificaciones de formato

La expresión `f"{value:.2f}"` muestra `value` con exactamente dos dígitos después del punto decimal.

Dentro de las llaves, cada carácter tiene un rol específico:

- El dos puntos `:` introduce la especificación de formato
- `.2` selecciona dos lugares decimales
- `f` selecciona la presentación de punto fijo, que muestra el número en notación decimal.

Eso significa que `print(f"{12.5:.2f}")` produce `12.50`, mientras que el valor inicial permanece sin cambios:

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

La salida muestra `12.50` porque la especificación de formato `.2f` siempre muestra dos lugares decimales, así que Python rellena el resultado con un cero al final. El valor almacenado en `value` sigue siendo `12.5`.


Por otro lado, formatear un valor como `12.3456` con `.2f` produce `12.35`, porque el número debe redondearse para mostrarse:

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## Formatear con una f-string produce una cadena

Una f-string produce una cadena:

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

Esto significa que puedes guardar la cadena resultante por separado y seguir usando el número original en cálculos.

## Cómo `round()` difiere del formateo con f-string

Una expresión como `round(value, 2)` te da un resultado numérico que puedes usar en cálculos posteriores.

Imprimir ese resultado usa la forma habitual de mostrar números en Python, por lo que no se garantizan ceros al final:

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## El formateo no cambia el valor subyacente

Como viste antes, algunos números decimales como `0.1` y `0.2` solo pueden aproximarse como floats. Por eso, su suma puede parecer un poco sorprendente cuando se imprime directamente:

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

Como puedes ver, la f-string redondea la suma para mostrarla. Cualquier cálculo que use `total` sigue usando el mismo valor de punto flotante.
