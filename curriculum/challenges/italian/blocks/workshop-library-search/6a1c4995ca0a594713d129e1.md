# --description--

Per catturare e gestire gli errori dal tuo blocco `try`, devi aggiungere un blocco `catch`. Puoi dichiarare un parametro per questo blocco per ispezionare l'effettivo oggetto errore che è stato lanciato.

```js
try {
  // Code that might throw an error
} catch (err) {
  // Code to handle the error
}
```

Subito sotto il tuo blocco `try`, aggiungi un blocco `catch` con un parametro chiamato `err`. All'interno del blocco, aggiorna il DOM impostando il `textContent` di `statusDisplay` su `err.message`.
