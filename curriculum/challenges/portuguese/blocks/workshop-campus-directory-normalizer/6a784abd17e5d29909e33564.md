# --description--

No momento, um `program` sabe a qual departamento pertence pelo `departmentId`, mas o departamento ainda não 
sabe quais programas pertencem a ele. Adicione cada `program.id` em `departmentsById[departmentId].programIds`.

Isso cria uma relação bidirecional: o departamento pode consultar seus programas através de `programIds` e cada programa pode consultar seu departamento através de `departmentId`, sem que nenhum dos objetos precise armazenar os dados completos do outro.

Antes de adicionar os IDs dos programas, exclua `console.log(programsById[program.id])` do passo anterior.

Registre `departmentsById[departmentId]` no console após o loop `departmentData.programs` terminar.
