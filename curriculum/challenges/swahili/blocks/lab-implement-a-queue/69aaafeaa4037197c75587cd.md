# --description--

Katika maabara hii, utatekeleza muundo wa data wa foleni kwa kutumia vitendakazi. Foleni ni muundo wa data wa Kwanza-Kuingia-Kwanza-Kutoka (FIFO) ambapo vipengele huongezwa nyuma ya foleni na kuondolewa mbele.

**Lengo:** Timiza hadithi za watumizi zilizo hapa chini na upite vipimo vyote ili kumaliza maabara.

**Hadithi za watumizi:**

1. Unapaswa kuwa na kitendakazi cha `initQueue` kinachorejesha kitu chenye sifa ya `collection` iliyowekwa kuwa safu ya data tupu.
1. Unapaswa kuwa na kitendakazi cha `enqueue` kinachoongeza kipengele mwishoni mwa foleni.
1. Unapaswa kuwa na kitendakazi cha `dequeue` kinachotoa na kurejesha kipengele cha mbele cha foleni, au `undefined` ikiwa hakipo.
1. Unapaswa kuwa na kitendakazi cha `front` kinachorejesha kipengele cha mbele cha foleni bila kukitoa, au `undefined` ikiwa hakipo.
1. Unapaswa kuwa na kitendakazi cha `size` kinachorejesha idadi ya vipengele katika foleni.
1. Unapaswa kuwa na kitendakazi cha `isEmpty` kinachorejesha `true` ikiwa foleni ni tupu na `false` vinginevyo.

**Kumbuka:** Vipimo vya `dequeue`, `front`, `size`, na `isEmpty` vinatumia kitendakazi cha `enqueue` kuongeza vipengele kwenye foleni, kwa hivyo ni bora kutekeleza `enqueue` kwanza. Kipimo cha mwisho kinahakikisha kwamba vitendakazi vyote vinavyofanya kazi pamoja.

# --solutions--

```js
function initQueue() {
  return {
    collection: []
  };
}

function print(queue) {
  console.log(queue.collection);
}

function enqueue(queue, element) {
  queue.collection.push(element);
}

function dequeue(queue) {
  return queue.collection.shift();
}

function front(queue) {
  return queue.collection[0];
}

function size(queue) {
  return queue.collection.length;
}

function isEmpty(queue) {
  return queue.collection.length === 0;
}
```
