# --description--

Не кожен відділ гарантовано має `Dept_code`. Потрібен запасний варіант на випадок, якщо його немає, щоб відділ все одно отримав придатний ідентифікатор.

Оператор `||` повертає своє ліве значення, якщо воно є `truthy`, інакше повертає праве значення.

Наприклад: `a || b` оцінюється як `a`, коли `a` є `truthy`, і переходить до `b`, коли `a` є `falsy` (наприклад, `undefined`, `null` або `""`).

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

Оновіть присвоєння `departmentId`, щоб використовувати оператор `||`. Використовуйте `departmentData.Dept_code` як лівий операнд і шаблонний рядок `` `dept-${i + 1}` `` як правий операнд. Це використовує запасний варіант щоразу, коли `departmentData.Dept_code` є falsy, включно з випадком, коли воно `undefined`.
