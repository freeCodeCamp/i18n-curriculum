# --interactive--

راجع المفاهيم أدناه للتحضير للاختبار التحضيري القادم.

## العمل مع HTML و CSS و JavaScript

بينما يوفر HTML و CSS هيكل الموقع، تضيف JavaScript التفاعلية للمواقع من خلال تمكين وظائف معقدة، مثل التعامل مع مُدخلات المستخدم، وتحريك العناصر، وحتى بناء تطبيقات ويب كاملة.

## أنواع البيانات في JavaScript

تساعد أنواع البيانات البرنامج على فهم نوع البيانات التي يتعامل معها، سواء كانت رقمًا أو نصًا أو غير ذلك.

- **Number**: الرقم يمثل كلًا من الأعداد الصحيحة والقيم العشرية. أمثلة على الأعداد الصحيحة تشمل 7، 19، و90.
- **Floating point**: الرقم العشري هو رقم يحتوي على فاصلة عشرية. أمثلة تشمل 3.14، 0.5، و0.0001.
- **String**: السلسلة النصية هي متتالية من الأحرف أو النص، محاطة بعلامات اقتباس. `"I like coding"` و `'JavaScript is fun'` أمثلة على السلاسل النصية.
- **Boolean**: القيمة المنطقية تمثل أحد قيمتين ممكنتين: `true` أو `false`. يمكنك استخدام القيمة المنطقية لتمثيل شرط، مثل `isLoggedIn = true`.
- **Undefined and Null**: القيمة `undefined` هي متغير تم الإعلان عنه لكنه لم يُعيَّن له قيمة. القيمة `null` هي قيمة فارغة، أو متغير تم تعيينه عمدًا إلى `null`.
- **Object**: الكائن هو مجموعة من أزواج المفتاح-القيمة. المفتاح هو اسم الخاصية، والقيمة هي قيمة الخاصية.

على سبيل المثال، يحتوي `{ name: "Fluffy", age: 3, type: "dog" }` على ثلاث خصائص: `name`، و`age`، و`type`.

- **Symbol**: نوع البيانات Symbol هو قيمة فريدة وغير قابلة للتغيير يمكن استخدامها كمُعرف لخصائص الكائنات.

رمزان تم إنشاؤهما بنفس الوصف لا يزالان قيمتين مميزتين مختلفتين.

- **BigInt**: عندما يكون الرقم كبيرًا جدًا بالنسبة لنوع بيانات `Number`، يمكنك استخدام نوع البيانات BigInt لتمثيل أعداد صحيحة بطول تعسفي.

بإضافة `n` إلى نهاية الرقم، يمكنك إنشاء BigInt.

## المتغيرات في JavaScript

- يمكن إعلان المتغيرات باستخدام الكلمة المفتاحية `let`.

- لتعيين قيمة لمتغير، يمكنك استخدام معامل التعيين `=`.

- المتغيرات المُعلنة باستخدام `let` يمكن إعادة تعيينها لقيمة جديدة.

- بالإضافة إلى `let`، يمكنك أيضًا استخدام `const` لإعلان متغير. ومع ذلك، لا يمكن إعادة تعيين متغير `const` لقيمة جديدة.

- تُستخدم المتغيرات المُعلنة باستخدام `const` في إعلان الثوابت التي لا يُسمح بتغييرها طوال الكود، مثل `PI` أو `MAX_SIZE`.

## اصطلاحات تسمية المتغيرات

- يجب أن تكون أسماء المتغيرات وصفية وذات معنى.
- يجب أن تكون أسماء المتغيرات بتنسيق تنسيق سنام الجمل مثل `cityName`، `isLoggedIn`، و `veryBigNumber`.
- يجب ألا تبدأ أسماء المتغيرات برقم. يجب أن تبدأ بحرف، أو `_`، أو `$`.
- يجب ألا تحتوي أسماء المتغيرات على مسافات أو أحرف خاصة، باستثناء `_` و `$`.
- يجب ألا تكون أسماء المتغيرات كلمات مفتاحية محجوزة.
- أسماء المتغيرات حساسة لحالة الأحرف. `age` و `Age` متغيران مختلفان.

## السلاسل النصية وثبات السلسلة في JavaScript

- السلاسل النصية هي متتاليات من الأحرف محاطة بعلامات اقتباس. يمكن إنشاؤها باستخدام علامات اقتباس مفردة أو مزدوجة.

- السلاسل النصية ثابتة في JavaScript. هذا يعني أنه بمجرد إنشاء سلسلة نصية، لا يمكنك تغيير الأحرف داخلها. ومع ذلك، يمكنك إعادة تعيين السلاسل النصية إلى قيمة جديدة.

## دمج السلاسل النصية في JavaScript

- الدمج هو عملية ربط عدة سلاسل نصية أو دمج السلاسل النصية مع المتغيرات التي تحتوي على نص. معامل `+` هو أحد أبسط وأكثر الطرق استخدامًا لدمج السلاسل النصية.

- إذا كنت بحاجة إلى إضافة أو إلحاق نص إلى سلسلة نصية موجودة، يمكنك استخدام معامل `+=`. هذا مفيد عندما تريد بناء سلسلة نصية بإضافة المزيد من النصوص إليها مع مرور الوقت.

- طريقة أخرى لدمج السلاسل النصية هي استخدام الدالة `concat()`. هذه الدالة تربط سلسلتين أو أكثر معًا.

## تسجيل الرسائل باستخدام `console.log()`

- تُستخدم دالة `console.log()` لتسجيل الرسائل في وحدة التحكم. إنها أداة مفيدة لتصحيح الأخطاء واختبار الكود الخاص بك.

## الفواصل المنقوطة في JavaScript

- تُستخدم الفواصل المنقوطة بشكل أساسي لتحديد نهاية العبارة. هذا يساعد محرك JavaScript على فهم فصل التعليمات الفردية، وهو أمر ضروري للتنفيذ الصحيح.

- تساعد الفواصل المنقوطة على منع الغموض في تنفيذ الكود وتضمن انتهاء العبارات بشكل صحيح.

## التعليقات في JavaScript

- أي سطر من الكود يتم التعليق عليه يتم تجاهله من قبل محرك جافاسكريبت. تُستخدم التعليقات لشرح الكود، تدوين الملاحظات، أو تعطيل الكود مؤقتًا.
- تُنشأ التعليقات ذات السطر الواحد باستخدام `//`.

- يتم إنشاء التعليقات متعددة الأسطر باستخدام `/*` لبدء التعليق و `*/` لإنهائه.

## JavaScript كلغة ذات نوع ديناميكي

- JavaScript هي لغة ذات نوع ديناميكي، مما يعني أنك لست مضطرًا لتحديد نوع البيانات للمتغير عند إعلانه. يقوم محرك JavaScript تلقائيًا بتحديد نوع البيانات بناءً على القيمة المعينة للمتغير.

- في اللغات ذات النوع الثابت مثل C#، يؤدي تعيين سلسلة نصية إلى متغير من نوع عدد صحيح إلى حدوث خطأ.

## استخدام معامل `typeof`

- يُستخدم معامل `typeof` للتحقق من نوع بيانات المتغير. يعيد سلسلة نصية تشير إلى نوع المتغير.

- مع ذلك، هناك سلوك معروف في JavaScript يتعلق بـ `null`. يعيد معامل `typeof` القيمة `"object"` لقيم `null`.

## أساسيات السلاسل النصية

- **التعريف**: السلسلة النصية هي متتالية من الأحرف محاطة بعلامات اقتباس مفردة أو مزدوجة أو علامات دقيقة. السلاسل النصية هي أنواع بيانات بدائية وثابتة. الثبات يعني أنه بمجرد إنشاء سلسلة نصية، لا يمكن تغييرها.
- **الوصول إلى الأحرف من سلسلة نصية**: للوصول إلى حرف من سلسلة نصية، يمكنك استخدام ترميز الأقواس وتمرير رقم الفهرس. الفهرس هو موقع الحرف داخل السلسلة النصية، ويبدأ من الصفر.

- **`\n` (حرف السطر الجديد)**: يمكنك إنشاء سطر جديد في سلسلة نصية باستخدام حرف السطر الجديد `\n`.

- **هروب السلاسل النصية**: يمكنك هروب الأحرف في سلسلة نصية بوضع شرطات مائلة عكسية (`\`) أمام علامات الاقتباس.

const statement = "She said, \"Hello!\"";

## القوالب الحرفية (السلاسل القالبية) واستيفاء السلاسل النصية

- **التعريف**: القوالب الحرفية تُعرف باستخدام علامات دقيقة (`). تسمح بمعالجة أسهل للسلاسل النصية، بما في ذلك تضمين المتغيرات مباشرة داخل السلسلة النصية، وهي ميزة تعرف بالاستيفاء.

:::interactive_editor

```js
const name = "Jessica";
const greeting = `Hello, ${name}!`; 
console.log(greeting); // "Hello, Jessica!"
```

## ASCII، دالة `charCodeAt()` ودالة `fromCharCode()`

- **ASCII**: ASCII (الرمز القياسي الأمريكي لتبادل المعلومات) هو معيار ترميز الأحرف يُستخدم لتمثيل الأحرف الإنجليزية الأساسية باستخدام قيم رقمية. الدروس السابقة قدمت `charCodeAt()` و`fromCharCode()` باستخدام أمثلة ASCII.
- **Unicode**: تستخدم سلاسل JavaScript الترميز الداخلي Unicode، وتحديدًا ترميز UTF-16. بالنسبة لأول 128 حرفًا (الحروف اللاتينية الأساسية، الأرقام، والرموز الشائعة)، تتطابق قيم Unicode مع رموز ASCII. لهذا السبب تستمر أمثلة ASCII في العمل في JavaScript.
- **طريقة `charCodeAt()`**: تعيد هذه الطريقة وحدة الترميز UTF-16 للحرف عند فهرس محدد. بالنسبة للحروف اللاتينية الأساسية، تتطابق هذه القيمة مع رمز ASCII.

- **دالة `fromCharCode()`**: تحول هذه الدالة رمز ASCII إلى الحرف المقابل له.

## دوال أخرى شائعة للسلاسل النصية

- **طريقة `indexOf`**: تُستخدم هذه الطريقة للبحث عن سلسلة فرعية داخل سلسلة نصية. إذا وُجدت السلسلة الفرعية، تُعيد `indexOf` الفهرس (أو الموضع) لأول ظهور لتلك السلسلة الفرعية. إذا لم تُعثر على السلسلة الفرعية، تُعيد `indexOf` القيمة -1، مما يشير إلى أن البحث لم يكن ناجحًا.

- **دالة `includes()`**: تُستخدم هذه الدالة للتحقق مما إذا كانت السلسلة النصية تحتوي على سلسلة فرعية محددة. إذا وُجدت السلسلة الفرعية داخل السلسلة النصية، تُعيد الدالة true. وإلا، تُعيد false.

- **طريقة `slice()`**: تستخرج هذه الطريقة جزءًا من السلسلة النصية وتُعيد سلسلة جديدة، دون تعديل السلسلة الأصلية. تأخذ معلمتين: فهرس البداية والفهرس الاختياري للنهاية.

- **دالة `toUpperCase()`**: تحول هذه الدالة جميع الأحرف إلى أحرف كبيرة وتُعيد سلسلة جديدة تحتوي على جميع الأحرف الكبيرة.

- **دالة `toLowerCase()`**: تحول هذه الدالة جميع الأحرف في السلسلة النصية إلى أحرف صغيرة.

- **دالة `replace()`**: تسمح لك هذه الدالة بالعثور على قيمة محددة (مثل كلمة أو حرف) في السلسلة النصية واستبدالها بقيمة أخرى. تُعيد الدالة سلسلة جديدة مع الاستبدال وتترك الأصلية دون تغيير لأن السلاسل النصية في JavaScript ثابتة.

- **طريقة `replaceAll()`**: تتيح لك هذه الطريقة العثور على كل تكرارات قيمة محددة (كلمة، حرف، أو نمط) في السلسلة النصية واستبدالها بقيمة أخرى. تعمل مثل `replace()`، لكنها لا تتوقف عند أول تطابق، بل تحدث كل التطابقات الموجودة في السلسلة النصية.

- **دالة `repeat()`**: تُستخدم هذه الدالة لتكرار سلسلة نصية عددًا محددًا من المرات.

- **دالة `trim()`**: تُستخدم هذه الدالة لإزالة الفراغات البيضاء من بداية ونهاية السلسلة النصية.

- **دالة `trimStart()`**: تزيل هذه الدالة الفراغات البيضاء من بداية (أو "بداية") السلسلة النصية.

- **دالة `trimEnd()`**: تزيل هذه الدالة الفراغات البيضاء من نهاية السلسلة النصية.

- **دالة `prompt()`**: هذه الدالة من `window` تُستخدم للحصول على معلومات من المستخدم عبر مربع حوار. تأخذ هذه الدالة معلمتين. المعلمة الأولى هي الرسالة التي ستظهر داخل مربع الحوار، عادةً لتحفيز المستخدم على إدخال معلومات. المعلمة الثانية هي قيمة افتراضية اختيارية تملأ حقل الإدخال مبدئيًا.

## العمل مع نوع البيانات Number

- **التعريف**: نوع `Number` في JavaScript يشمل الأعداد الصحيحة، الأعداد العشرية، `Infinity` و `NaN`. الأعداد العشرية هي أعداد تحتوي على فاصلة عشرية. `Infinity` الموجب هو عدد أكبر من أي عدد آخر، بينما `-Infinity` هو عدد أصغر من أي عدد آخر. `NaN` (`Not a Number`) يمثل قيمة رقمية غير صالحة مثل السلسلة النصية `"Jessica"`.

## العمليات الحسابية الشائعة

- **معامل الجمع**: هذا المعامل (`+`) يُستخدم لحساب مجموع رقمين أو أكثر.
- **معامل الطرح**: هذا المعامل (`-`) يُستخدم لحساب الفرق بين رقمين.
- **معامل الضرب**: هذا المعامل (`*`) يُستخدم لحساب حاصل ضرب رقمين أو أكثر.
- **معامل القسمة**: هذا المعامل (`/`) يُستخدم لحساب حاصل قسمة رقمين.
- **القسمة على صفر**: إذا حاولت القسمة على صفر، ستُعيد JavaScript `Infinity`.
- **معامل الباقي**: هذا المعامل (`%`) يُعيد باقي القسمة.
- **معامل الأس**: هذا المعامل (`**`) يرفع رقمًا إلى قوة رقم آخر.

## الحسابات مع الأرقام والسلاسل النصية

- **الشرح**: عند استخدام معامل `+` مع رقم وسلسلة نصية، تُجبر JavaScript الرقم على أن يصبح سلسلة نصية وتدمج القيمتين. عند استخدام معاملات `-`، `*` أو `/` مع سلسلة نصية ورقم، تُجبر JavaScript السلسلة النصية على أن تصبح رقمًا وتكون النتيجة رقمًا. بالنسبة لـ `null` و `undefined`، تعامل JavaScript `null` كـ 0 و `undefined` كـ `NaN` في العمليات الحسابية.

## أسبقية المعاملات

- **التعريف**: تحدد أسبقية المعاملات ترتيب تقييم العمليات في التعبير. تُقيّم المعاملات ذات الأسبقية الأعلى قبل تلك ذات الأسبقية الأقل. تُقيّم القيم داخل الأقواس أولًا، وتكون أسبقية الضرب والقسمة أعلى من الجمع والطرح. إذا كانت المعاملات لها نفس الأسبقية، تستخدم JavaScript الترابط.

- **التعريف**: يوضح المحدد الكمي اتجاه تقييم التعبير عندما توجد عدة معاملات من نفس النوع. يحدد ما إذا كان يجب تقييم التعبير من اليسار إلى اليمين (`left-associative`) أو من اليمين إلى اليسار (`right-associative`). على سبيل المثال، معامل الأس هو أيضًا من اليمين إلى اليسار.

## معاملات التزايد والتقليل

- **معامل التزايد**: يُستخدم هذا المعامل لزيادة القيمة بمقدار واحد. ترميز البادئة `++num` يزيد قيمة المتغير أولًا، ثم يُعيد القيمة الجديدة. ترميز اللاحقة `num++` يُعيد القيمة الحالية للمتغير أولًا، ثم يزيدها.

- **معامل التقليل**: يُستخدم هذا المعامل لتقليل القيمة بمقدار واحد. ترميز البادئة واللاحقة يعملان بنفس طريقة معامل التزايد.

## معاملات التعيين المركب

- **معامل التعيين الجمعي (`+=`)**: يقوم هذا المعامل بجمع القيم وتعيين النتيجة للمتغير.
- **معامل التعيين الطرحي (`-=`)**: يقوم هذا المعامل بطرح القيم وتعيين النتيجة للمتغير.
- **معامل التعيين الضربي (`*=`)**: يقوم هذا المعامل بضرب القيم وتعيين النتيجة للمتغير.
- **معامل التعيين القسمي (`/=`)**: يقوم هذا المعامل بقسمة القيم وتعيين النتيجة للمتغير.
- **معامل التعيين بالباقي (`%=`)**: يقوم هذا المعامل بقسمة المتغير على رقم معين ويُعيّن الباقي للمتغير.
- **معامل التعيين الأسّي (`**=`)**: يقوم هذا المعامل برفع المتغير لقوة رقم معين ويُعيّن النتيجة للمتغير.

## القيم المنطقية والمساواة

- **تعريف القيمة المنطقية**: القيمة المنطقية هي نوع بيانات يمكن أن يأخذ قيمتين فقط: `true` أو `false`.
- **معامل المساواة (`==`)**: يستخدم هذا المعامل إجبار النوع قبل التحقق من تساوي القيم.

- **معامل المساواة الصارمة (`===`)**: لا يقوم هذا المعامل بإجبار النوع ويتحقق من تساوي النوع والقيمة معًا.

- **معامل عدم المساواة (`!=`)**: يستخدم هذا المعامل إجبار النوع قبل التحقق من عدم تساوي القيم.
- **معامل عدم المساواة الصارمة (`!==`)**: لا يجري هذا المعامل إجبار النوع ويتحقق من عدم تساوي النوعين والقيم معًا.

## معاملات المقارنة

- **معامل أكبر من (`>`)**: يتحقق هذا المعامل مما إذا كانت القيمة على اليسار أكبر من القيمة على اليمين.
- **معامل أكبر من أو يساوي (`>=`)**: يتحقق هذا المعامل مما إذا كانت القيمة على اليسار أكبر من أو تساوي القيمة على اليمين.
- **معامل أقل من (`<`)**: يتحقق هذا المعامل مما إذا كانت القيمة على اليسار أقل من القيمة على اليمين.
- **معامل أقل من أو يساوي (`<=`)**: يتحقق هذا المعامل مما إذا كانت القيمة على اليسار أقل من أو تساوي القيمة على اليمين.

## المعاملات الأحادية

- **معامل الجمع الأحادي**: يحول هذا المعامل المعامل إلى رقم. إذا كان المعامل رقمًا بالفعل، يبقى كما هو.

- **معامل النفي الأحادي (`-`)**: يقوم هذا المعامل بعكس إشارة المعامل.

- **معامل النفي المنطقي (`!`)**: يعكس هذا المعامل القيمة المنطقية لمُعاملته. فإذا كانت القيمة `true` تصبح `false`، وإذا كانت `false` تصبح `true`.

## معاملات العمليات الثنائية على البتات

- **عامل `&` (bitwise AND)**: يُرجع هذا العامل 1 في كل موضع بت تكون فيه البتات المقابلة لكلا العاملين 1.
- **عامل التعيين `&=` (bitwise AND Assignment)**: يُنفذ هذا العامل عملية `bitwise AND` مع الرقم المحدد ويُعيد تعيين النتيجة إلى المتغير.
- **عامل `|` (bitwise OR)**: يُرجع هذا العامل 1 في كل موضع بت تكون فيه البتات المقابلة لأحد العاملين أو لكليهما 1.
- **عامل التعيين `|=` (bitwise OR Assignment)**: يُنفذ هذا العامل عملية `bitwise OR` مع الرقم المحدد ويُعيد تعيين النتيجة إلى المتغير.
- **عامل `^` (bitwise XOR)**: يُرجع هذا العامل 1 في كل موضع بت تكون فيه البتات المقابلة لأحد العاملين فقط، وليس لكليهما.
- **عامل `~` (bitwise NOT)**: يعكس هذا العامل التمثيل الثنائي للرقم.
- **عامل الإزاحة لليسار `<<` (Left Shift)**: يحرك هذا العامل كل البتات إلى اليسار بعدد محدد من المواقع.
- **عامل الإزاحة لليمين `>>` (Right Shift)**: يحرك هذا العامل كل البتات إلى اليمين.

## عبارات الشرط، القيم الصحيحة والخاطئة، والمعامل الثلاثي

- **`if/else if/else`**: يأخذ تعبير `if` شرطًا وينفذ كتلة من الكود إذا كان هذا الشرط `truthy`. إذا كان الشرط `false`، ينتقل إلى البند `else if`. إذا لم يكن أي من هذه الشروط `true`، ينفذ البند `else`. القيم `Truthy` هي أي قيم تُقيّم إلى `true` في سياق القيمة المنطقية مثل تعبير `if`. القيم `Falsy` هي القيم التي تُقيّم إلى `false` في سياق القيمة المنطقية.

:::interactive_editor

```js
const score = 87;

if (score >= 90) {
 console.log('You got an A'); 
} else if (score >= 80) {
 console.log('You got a B'); // You got a B
} else if (score >= 70) {
 console.log('You got a C');
} else {
 console.log('You failed! You need to study more!');
}
```

:::

- **المعامل الثلاثي**: يُستخدم هذا المعامل غالبًا كطريقة مختصرة لكتابة عبارات `if else`.

:::interactive_editor

```js
const temperature = 30;
const weather = temperature > 25 ? 'sunny' : 'cool';

console.log(`It's a ${weather} day!`); // It's a sunny day!
```

:::

## معاملات العمليات المنطقية الثنائية

- **عامل AND المنطقي (`&&`)**: يتحقق هذا العامل مما إذا كانت كلتا القيمتين `true`. إذا كانت كلتاهما `true`، فسيُعيد القيمة الثانية. إذا كانت إحدى القيمتين `falsy`، فسيُعيد القيمة `falsy`. إذا كانت كلتا القيمتين `falsy`، فسيُعيد أول قيمة `falsy`.

- **عامل OR المنطقي (`||`)**: يتحقق هذا العامل مما إذا كان أحد المعاملين على الأقل صحيحًا (truthy). 
- **عامل الدمج الصفري (`??`)**: يعيد هذا العامل قيمة فقط إذا كانت القيمة الأولى `null` أو `undefined`.

## كائن `Math`

- **دالة `Math.random()`**: تولد هذه الدالة رقمًا عشريًا عشوائيًا بين 0 (شامل) و1 (غير شامل). هذا يعني أن الناتج يمكن أن يكون 0، لكنه لن يصل أبدًا إلى 1.
- **دالة `Math.max()`**: تأخذ مجموعة أرقام وتُرجع القيمة العظمى.
- **دالة `Math.min()`**: تأخذ مجموعة أرقام وتُرجع القيمة الصغرى.
- **دالة `Math.ceil()`**: تقرب القيمة إلى أقرب عدد صحيح أكبر أو يساويها.
- **دالة `Math.floor()`**: تقرب القيمة إلى أقرب عدد صحيح أقل أو يساويها.
- **دالة `Math.round()`**: تقرب القيمة إلى أقرب عدد صحيح.

- **دالة `Math.trunc()`**: تزيل الجزء العشري من الرقم، وتُرجع الجزء الصحيح فقط بدون تقريب.
- **دالة `Math.sqrt()`**: تُرجع الجذر التربيعي لرقم.
- **دالة `Math.cbrt()`**: تُرجع الجذر التكعيبي لرقم.
- **دالة `Math.abs()`**: تُرجع القيمة المطلقة لرقم.
- **دالة `Math.pow()`**: تأخذ رقمين وترفع الأول لقوة الثاني.

## دوال الأرقام الشائعة

- **`isNaN()`**: تعني `NaN` "ليس رقمًا". هي قيمة خاصة تمثل نتيجة عددية غير قابلة للتمثيل أو غير معرفة. تُستخدم دالة `isNaN()` لتحديد ما إذا كانت القيمة `NaN` أم لا. توفر `Number.isNaN()` طريقة أكثر موثوقية للتحقق من قيم `NaN`، خاصة في الحالات التي قد يؤدي فيها إجبار النوع إلى نتائج غير متوقعة مع الدالة العالمية `isNaN()`.

- **طريقة `parseFloat()`**: تقوم هذه الطريقة بتحليل معلمة سلسلة نصية وتُرجع عددًا عشريًا عائمًا. صُممت لاستخراج رقم من بداية السلسلة النصية، حتى لو احتوت السلسلة على أحرف غير رقمية لاحقًا.
- **طريقة `parseInt()`**: تقوم هذه الطريقة بتحليل معلمة سلسلة نصية وتُرجع عددًا صحيحًا. تتوقف `parseInt()` عن التحليل عند أول توقف غير رقمي تواجهه. بالنسبة للأعداد العشرية العائمة، تُرجع الجزء الصحيح فقط. إذا لم تجد عددًا صحيحًا صالحًا في بداية السلسلة، تُرجع `NaN`.
- **طريقة `toFixed()`**: تُستدعى هذه الطريقة على رقم وتأخذ معلمة اختيارية واحدة، وهي عدد الأرقام التي تظهر بعد الفاصلة العشرية. تُرجع تمثيلًا نصيًا للرقم بعدد الأماكن العشرية المحددة.

## المقارنات وأنواع البيانات `null` و `undefined`

- **المقارنات و`undefined`**: المتغير يكون `undefined` إذا تم إعلانه دون تعيين قيمة. هي القيمة الافتراضية للمتغيرات غير المهيأة ومعلمات الدوال التي لم تُمرر لها معلمة. يتحول `undefined` إلى `NaN` في السياقات العددية، مما يجعل جميع المقارنات العددية مع `undefined` تُرجع `false`.

- **المقارنات و`null`**: يمثل نوع `null` غياب القيمة بشكل مقصود. يتحول `null` إلى `0` في السياقات الرقمية، مما قد يؤدي إلى سلوك غير متوقع في المقارنات الرقمية. على سبيل المثال، `null >= 0` تكون `true`، لكن `null > 0` تكون `false`.

- عند استخدام معامل المساواة (`==`)، يكون `null` و`undefined` متساويين فقط مع بعضهما البعض ومع نفسيهما.

- مع ذلك، عند استخدام معامل المساواة الصارمة (`===`)، الذي يتحقق من القيمة والنوع دون إجبار النوع، لا يكون `null` و`undefined` متساويين.

## عبارات `switch`

- **التعريف**: يقوم تعبير `switch` بتقييم تعبير ومطابقة قيمته مع سلسلة من بنود `case`. عند العثور على تطابق، يُنفذ كتلة الكود المرتبطة بذلك البند. يجب وضع تعبير `break` في نهاية كل بند، لإنهاء تنفيذه والمتابعة إلى التالي. بند `default` هو بند اختياري وينفذ فقط إذا لم يتطابق أي من البنود الأخرى. يُوضع بند `default` في نهاية تعبير `switch`.

:::interactive_editor

```js
const dayOfWeek = 3; 

switch (dayOfWeek) {
  case 1:
    console.log("It's Monday! Time to start the week strong.");
    break;
  case 2:
    console.log("It's Tuesday! Keep the momentum going.");
    break;
  case 3:
    console.log("It's Wednesday! We're halfway there.");
    break;
  case 4:
    console.log("It's Thursday! Almost the weekend.");
    break;
  case 5:
    console.log("It's Friday! The weekend is near.");
    break;
  case 6:
    console.log("It's Saturday! Enjoy your weekend.");
    break;
  case 7:
    console.log("It's Sunday! Rest and recharge.");
    break;
  default:
    console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

:::

## دوال JavaScript

- الدوال هي كتل قابلة لإعادة الاستخدام من الكود تؤدي مهمة محددة.
- يمكن إعلان الدوال باستخدام الكلمة المفتاحية `function` متبوعة باسم، وقائمة معلمات، وكتلة كود تؤدي المهمة.

:::interactive_editor

```js
function addNumbers(x, y, z) {
  return x + y + z;
}

console.log(addNumbers(5, 3, 8)); // Output: 16
```

:::

- المعلمات هي القيم التي تُمرر إلى الدالة عند استدعائها.
- استدعاء الدالة هو عملية تنفيذ الدالة في البرنامج بتحديد اسم الدالة متبوعًا بأقواس عادية، مع إمكانية تضمين المعلمات داخل الأقواس.
- عند انتهاء تنفيذ الدالة، سترجع دائمًا قيمة.
- افتراضيًا، تكون قيمة الإرجاع للدالة هي `undefined`.
- تُستخدم الكلمة المفتاحية `return` لتحديد القيمة التي سترجع من الدالة وتنهي تنفيذها.
- تسمح المعلمات الافتراضية للدوال بأن يكون لها قيم محددة مسبقًا تُستخدم إذا لم تُمرر معلمة عند استدعاء الدالة. هذا يجعل الدوال أكثر مرونة ويمنع الأخطاء في الحالات التي قد تُحذف فيها بعض المعلمات.

:::interactive_editor

```js
const calculateTotal = (amount, taxRate = 0.05) => {
  return amount + (amount * taxRate);
};

console.log(calculateTotal(100)); // Output: 105
```

:::

- الدوال المجهولة هي دوال بدون اسم يمكن تعيينها إلى متغيرات. بتعيينها إلى متغيرات، يمكنك إعادة استخدامها في أي مكان يمكن الوصول فيه إلى المتغير.

:::interactive_editor

```js
const multiplyNumbers = function(firstNumber, secondNumber) {
  return firstNumber * secondNumber;
};

console.log(multiplyNumbers(4, 5)); // Output: 20
```

:::

## الدوال السهمية

- الدوال السهمية هي طريقة أكثر اختصارًا لكتابة الدوال في JavaScript.

- عند تعريف دالة سهمية، لا تحتاج إلى الكلمة المفتاحية `function`.
- إذا كنت تستخدم معلمة واحدة فقط، يمكنك حذف الأقواس العادية حول قائمة المعلمات.

- إذا كان جسم الدالة يتكون من تعبير واحد فقط، يمكنك حذف الأقواس المتعرجة والكلمة المفتاحية `return`.

:::interactive_editor

```js
const square = number => number * number;

console.log(square(5)); // Output: 25
```

:::

## النطاق في البرمجة

- **النطاق العام**: هو أوسع نطاق في جافاسكريبت. المتغيرات المُعلنة في النطاق العام يمكن الوصول إليها من أي مكان في الكود وتُسمى متغيرات عامة.
- **النطاق المحلي**: يشير إلى المتغيرات المُعلنة داخل دالة. هذه المتغيرات يمكن الوصول إليها فقط داخل الدالة التي أُعلنت فيها وتُسمى متغيرات محلية.
- **نطاق الكتلة**: الكتلة هي مجموعة من العبارات المحاطة بأقواس متعرجة `{}` مثل عبارات `if` أو الحلقات.
- يوفر التسكين باستخدام `let` و `const` تحكمًا أدق في إمكانية الوصول إلى المتغيرات، مما يساعد على منع الأخطاء وجعل الكود أكثر توقعًا.

## أساسيات مصفوفات JavaScript

- **تعريف**: المصفوفة في JavaScript هي مجموعة مرتبة من القيم، كل منها معرف بواسطة فهرس رقمي. يمكن أن تكون القيم في المصفوفة من أنواع بيانات مختلفة، بما في ذلك الأرقام، والسلاسل النصية، والقيم المنطقية، والكائنات، وحتى مصفوفات أخرى. المصفوفات متجاورة في الذاكرة، مما يعني أن جميع العناصر مخزنة في كتلة متصلة من مواقع الذاكرة، مما يسمح بفهرسة فعالة والوصول السريع للعناصر حسب الفهرس.

- **الوصول إلى عناصر المصفوفة**: للوصول إلى عناصر المصفوفة، تحتاج إلى الإشارة إلى المصفوفة متبوعة برقم الفهرس داخل أقواس مربعة. المصفوفات في JavaScript تبدأ فهارسها من الصفر، أي أن العنصر الأول في الفهرس 0، والثاني في الفهرس 1، وهكذا. إذا حاولت الوصول إلى فهرس غير موجود، سترجع القيمة `undefined`.

- **خاصية `length`**: تُستخدم هذه الخاصية لإرجاع عدد العناصر في المصفوفة.

- **تحديث عناصر المصفوفة**: لتحديث عنصر في المصفوفة، تستخدم معامل التعيين (`=`) لتعيين قيمة جديدة للعنصر عند فهرس معين.

## المصفوفات ثنائية الأبعاد

- **تعريف**: المصفوفة ثنائية الأبعاد هي في الأساس مصفوفة من مصفوفات. تُستخدم لتمثيل بيانات ذات هيكل شبكي طبيعي، مثل رقعة الشطرنج، أو جدول بيانات، أو بكسلات في صورة. للوصول إلى عنصر في مصفوفة ثنائية الأبعاد، تحتاج إلى فهرسين: واحد للصف وآخر للعمود.

## التفكيك في المصفوفات

- **تعريف**: التفكيك في المصفوفات هو ميزة في JavaScript تسمح لك باستخراج القيم من المصفوفات وتعيينها إلى متغيرات بطريقة أكثر اختصارًا وقابلية للقراءة. توفر صيغة مريحة لفك عناصر المصفوفة إلى متغيرات منفصلة.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange"];

const [first, second, third] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(third); // "orange"
```

:::

- **صيغة rest**: تسمح لك بالتقاط العناصر المتبقية من المصفوفة التي لم تُفكك في مصفوفة جديدة.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange", "mango", "kiwi"];
const [first, second, ...rest] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(rest); // ["orange", "mango", "kiwi"]
```

:::

## طرق المصفوفة الشائعة

- **دالة `push()`**: تُستخدم لإضافة عناصر إلى نهاية المصفوفة وتُرجع الطول الجديد.

- **دالة `pop()`**: تُستخدم لإزالة العنصر الأخير من المصفوفة وتُرجع العنصر المُزال. إذا كانت المصفوفة فارغة، تُرجع `undefined`.

- **دالة `shift()`**: تُستخدم لإزالة العنصر الأول من المصفوفة وتُرجع العنصر المُزال. إذا كانت المصفوفة فارغة، تُرجع `undefined`.

- **دالة `unshift()`**: تُستخدم لإضافة عناصر إلى بداية المصفوفة وتُرجع الطول الجديد.

- **دالة `indexOf()`**: مفيدة لإيجاد أول فهرس لعنصر معين داخل المصفوفة. إذا لم يُعثر على العنصر، تُرجع `-1`.

- **طريقة `splice()`**: تُستخدم هذه الطريقة لإضافة أو إزالة عناصر من أي موقع في المصفوفة. قيمة الإرجاع لطريقة `splice()` ستكون مصفوفة بالعناصر التي أُزيلت من المصفوفة. إذا لم يُزل شيء، فستُرجع مصفوفة فارغة. هذه الطريقة تُغير المصفوفة الأصلية، حيث تُعدّلها في مكانها بدلاً من إنشاء مصفوفة جديدة. المعلمة الأولى تحدد الفهرس الذي يبدأ عنده تعديل المصفوفة. المعلمة الثانية هي عدد العناصر التي تريد إزالتها. المعلمات التالية هي العناصر التي تريد إضافتها.

- **دالة `includes()`**: تُستخدم للتحقق مما إذا كانت المصفوفة تحتوي على قيمة معينة. تُرجع `true` إذا وُجدت القيمة، و`false` خلاف ذلك.

- **دالة `concat()`**: تُنشئ مصفوفة جديدة بدمج مصفوفتين أو أكثر.

- **طريقة `slice()`**: تُرجع هذه الطريقة مصفوفة جديدة تحتوي على نسخة سطحية من جزء من المصفوفة الأصلية، محددة بفهارس البداية والنهاية. تحتوي المصفوفة الجديدة على مراجع لنفس العناصر في المصفوفة الأصلية (وليس نسخًا مكررة). هذا يعني أنه إذا كانت العناصر بدائية (مثل الأرقام أو السلاسل النصية)، تُنسخ القيم؛ أما إذا كانت العناصر كائنات أو مصفوفات، فتُنسخ المراجع وليس الكائنات نفسها.

- **صيغة النشر (spread syntax)**: تُستخدم لإنشاء نسخ سطحية من المصفوفة.

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const shallowCopiedArray = [...originalArray];

shallowCopiedArray.push(4);

console.log(originalArray); // [1, 2, 3]
console.log(shallowCopiedArray); // [1, 2, 3, 4]
```

:::

- **دالة `split()`**: تقسم سلسلة نصية إلى مصفوفة من السلاسل الفرعية وتحدد مكان كل تقسيم بناءً على فاصل معين. إذا لم يُحدد فاصل، تُرجع مصفوفة تحتوي على السلسلة الأصلية كعنصر واحد.

- **دالة `reverse()`**: تعكس ترتيب عناصر المصفوفة في مكانها.

- **دالة `join()`**: تجمع كل عناصر المصفوفة في سلسلة نصية واحدة، مع فصل كل عنصر بفاصل محدد. إذا لم يُحدد فاصل أو كان فارغًا (`""`)، تُجمع العناصر بدون فاصل.

## أساسيات الكائنات

- **تعريف**: الكائن هو هيكل بيانات يتكون من خصائص. تتكون الخاصية من مفتاح وقيمة. للوصول إلى بيانات من كائن، يمكنك استخدام ترميز النقطة أو ترميز الأقواس.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  city: "New York"
};

console.log(person.name);  // Alice
console.log(person["name"]); // Alice
```

:::

لتعيين خاصية لكائن موجود، يمكنك استخدام ترميز النقطة أو ترميز الأقواس مع معامل التعيين.

## حذف الخصائص من الكائن

- **معامل `delete`**: يُستخدم هذا المعامل لحذف خاصية من كائن.

## التحقق مما إذا كان للكائن خاصية

- **طريقة `hasOwnProperty()`**: تُرجع هذه الطريقة قيمة منطقية تشير إلى ما إذا كان للكائن الخاصية المحددة كخاصية خاصة به.

- **طريقة `Object.hasOwn()`**: هذه هي الطريقة الحديثة والمُوصى بها للتحقق مما إذا كان للكائن خاصية خاصة به (ليست موروثة). الصيغة هي `Object.hasOwn(object, propertyName)`. تُرجع `true` إذا كانت الخاصية موجودة في الكائن و`false` إذا لم تكن موجودة، بغض النظر عن قيمة الخاصية. هذا يجعلها أكثر أمانًا من `hasOwnProperty()` وأكثر موثوقية من `if (obj.prop)` عندما تكون القيم `0` أو `false` أو `null` أو `undefined`.

`Object.hasOwn()` يكتشف الخاصية الخاصة حتى عندما تكون قيمتها زائفة مثل `0`، أو `false`، أو `undefined`.

- **معامل `in`**: يُرجع هذا المعامل `true` إذا كانت الخاصية موجودة في الكائن.

## الوصول إلى الخصائص من الكائنات المسكنة

- **الوصول إلى البيانات**: الوصول إلى الخصائص من الكائنات المسكنة يتطلب استخدام ترميز النقطة أو ترميز الأقواس، تمامًا كما في الكائنات البسيطة. لكن عليك تسلسل هذه الطرق للوصول إلى البنية المسكنة.

## أنواع البيانات الأولية وغير الأولية

- **أنواع البيانات الأولية**: تشمل هذه الأنواع الأعداد، السلاسل النصية، القيم المنطقية، `null`، `undefined`، والرموز. تُسمى "أولية" لأنها تمثل قيمًا مفردة وليست كائنات. القيم الأولية غير قابلة للتغيير، بمعنى أنه بمجرد إنشائها لا يمكن تعديل قيمتها.
- **أنواع البيانات غير الأولية**: في JavaScript، هي الكائنات، التي تشمل الكائنات العادية، المصفوفات، والدوال. على عكس الأوليات، يمكن للأنواع غير الأولية أن تحتوي على قيم متعددة كخصائص أو عناصر.

## طرق الكائن

- **التعريف**: طرق الكائن هي دوال مرتبطة بكائن. تُعرف كخصائص للكائن ويمكنها الوصول إلى بيانات الكائن والتعامل معها. الكلمة المفتاحية `this` داخل الطريقة تشير إلى الكائن نفسه، مما يتيح الوصول إلى خصائصه.

## دالة البناء للكائن

- **التعريف**: في JavaScript، دالة البناء هي نوع خاص من الدوال تُستخدم لإنشاء وتهيئة الكائنات. تُستدعى باستخدام الكلمة المفتاحية `new` ويمكنها تهيئة الخصائص والطرق على الكائن الجديد. دالة البناء `Object()` تنشئ كائنًا فارغًا جديدًا.

## العمل مع معامل التسكين الاختياري (`?.`)

- **التعريف**: هذا المعامل يتيح لك الوصول بأمان إلى خصائص الكائن أو استدعاء الطرق دون القلق من وجودها.

:::interactive_editor

```ts
const user = {
  name: "John",
  profile: {
    email: "john@example.com",
    address: {
      street: "123 Main St",
      city: "Somewhere"
    }
  }
};

console.log(user.profile?.address?.street); // "123 Main St"
console.log(user.profile?.phone?.number);   // undefined
```

:::

## التفكيك للكائنات

- **التعريف**: التفكيك يسمح لك باستخراج القيم من الكائنات وتعيينها إلى متغيرات بطريقة أكثر إيجازًا ووضوحًا.

:::interactive_editor

```js
const person = { name: "Alice", age: 30, city: "New York" };

const { name, age } = person;

console.log(name); // Alice
console.log(age);  // 30
```

## العمل مع JSON

- **التعريف**: JSON تعني JavaScript Object Notation. هو تنسيق بيانات خفيف الوزن يعتمد على النص ويُستخدم عادة لتبادل البيانات بين الخادم وتطبيق الويب.

- **`JSON.stringify()`**: تُستخدم هذه الطريقة لتحويل كائن JavaScript إلى سلسلة JSON. هذا مفيد عند الرغبة في تخزين أو نقل البيانات بتنسيق يمكن مشاركته أو نقله بسهولة بين الأنظمة.

- **`JSON.parse()`**: تُحول هذه الطريقة سلسلة JSON مرة أخرى إلى كائن JavaScript. هذا مفيد عند استرجاع بيانات JSON من خادم ويب أو من localStorage وتحتاج إلى التعامل مع البيانات في تطبيقك.

## العمل مع الحلقات

- **حلقة `for`**: تُستخدم هذه الحلقة لتكرار كتلة من الكود عددًا معينًا من المرات. تنقسم هذه الحلقة إلى ثلاثة أجزاء: بيان التهيئة، الشرط، وبيان الزيادة/النقصان. يُنفذ بيان التهيئة قبل بدء الحلقة، وعادةً ما يُستخدم لتهيئة متغير عداد. يُقيّم الشرط قبل كل تكرار للحلقة. التكرار هو مرور واحد خلال الحلقة. إذا كان الشرط `true`، تُنفذ كتلة الكود داخل الحلقة. إذا كان الشرط `false`، تتوقف الحلقة وتنتقل إلى كتلة الكود التالية. يُنفذ بيان الزيادة/النقصان بعد كل تكرار للحلقة، وعادةً ما يُستخدم لزيادة أو نقصان متغير العداد.

:::interactive_editor

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

:::

- **حلقة `for...of`**: تُستخدم هذه الحلقة عندما تحتاج إلى التكرار على قيم من قابل للتكرار. أمثلة على القابل للتكرار هي المصفوفات والسلاسل النصية.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];

for (const num of numbers) {
  console.log(num);
}
```

:::

- **حلقة `for...in`**: تُستخدم هذه الحلقة بشكل أفضل عندما تحتاج إلى التكرار على خصائص كائن. ستتكرر هذه الحلقة على جميع الخصائص القابلة للعد في الكائن، بما في ذلك الخصائص الموروثة والخصائص غير الرقمية.

:::interactive_editor

```js
const fruit = {
  name: 'apple',
  color: 'red',
  price: 0.99
};

for (const prop in fruit) {
  console.log(fruit[prop]);
}
```

:::

- **حلقة `while`**: تُنفذ كتلة من الكود طالما أن الشرط `true`.

:::interactive_editor

```js
let i = 5;

while (i > 0) {
  console.log(i);
  i--;
}
```

:::

- **حلقة `do...while`**: تُنفذ كتلة الكود مرة واحدة على الأقل قبل التحقق من الشرط.

```js
let userInput;

do {
  userInput = prompt("Please enter a number between 1 and 10");
} while (Number(userInput) < 1 || Number(userInput) > 10);

alert("You entered a valid number!");
```

## جملتي `break` و `continue`

- **التعريف**: جملة `break` تُستخدم للخروج المبكر من الحلقة، بينما جملة `continue` تُستخدم لتخطي التكرار الحالي والانتقال إلى التكرار التالي.

## دالة البناء للسلسلة النصية وطريقة `toString()`

- **التعريف**: كائن السلسلة النصية يُستخدم لتمثيل تسلسل من الأحرف. تُنشأ كائنات السلسلة النصية باستخدام دالة البناء `String`، التي تغلف القيمة الأولية داخل كائن.

- **طريقة `toString()`**: تُحوّل هذه الطريقة القيمة إلى تمثيلها كسلسلة نصية. يمكن استخدامها للأعداد، القيم المنطقية، المصفوفات، والكائنات.

تقبل هذه الطريقة معاملًا اختياريًا يسمى radix وهو رقم من 2 إلى 36. يمثل هذا الرقم أساس العد، مثل الأساس 2 للثنائي أو الأساس 8 للأوكتال. إذا لم يُحدد radix، فإنه يُفترض الأساس 10، وهو النظام العشري.

## دالة البناء للعدد

- **التعريف**: دالة البناء `Number` تُستخدم لإنشاء كائن عدد. يحتوي كائن العدد على بعض الخصائص والطرق المفيدة مثل `isNaN` و`toFixed`. في معظم الأحيان، ستستخدم دالة البناء `Number` لتحويل أنواع بيانات أخرى إلى نوع العدد.

## أفضل الممارسات لتسمية المتغيرات والدوال

- **camelCasing**: حسب الاصطلاح، يستخدم مطورو JavaScript تسمية المتغيرات والدوال بطريقة camel casing. حيث تكون الكلمة الأولى كلها أحرف صغيرة والكلمات التالية تبدأ بحرف كبير. مثال: `isLoading`.

- **تسمية القيم المنطقية**: للمتغيرات المنطقية، من الممارسات الشائعة استخدام بادئات مثل "is"، "has"، أو "can".

- **تسمية الدوال**: يجب أن يوضح اسم الدالة بوضوح ما تقوم به. للدوال التي تُرجع قيمة منطقية (تُسمى غالبًا predicates)، يمكنك استخدام نفس البادئات "is"، "has"، أو "can". للدوال التي تسترجع بيانات، من الشائع البدء بكلمة "get". للدوال التي تعيّن بيانات، من الشائع البدء بكلمة "set". لدوال معالجي الأحداث، قد تستخدم بادئة "handle" أو لاحقة "Handler".

- **تسمية المتغيرات داخل الحلقات**: عند تسمية متغيرات التكرار في الحلقات، من الشائع استخدام أحرف مفردة مثل `i`، `j`، أو `k`.

## العمل مع المصفوفات المتفرقة

- **التعريف**: من الممكن وجود مصفوفات تحتوي على خانات فارغة. تُعرف الخانات الفارغة بأنها خانات لا تحتوي على أي شيء بداخلها. هذا يختلف عن خانات المصفوفة التي تحتوي على القيمة `undefined`. تُعرف هذه الأنواع من المصفوفات بالمصفوفات المتفرقة.

## أدوات التدقيق والتنسيق

- **اللينترز**: اللينتر هو أداة تحليل كود ثابتة تُشير إلى أخطاء البرمجة، الأخطاء البرمجية، أخطاء الأسلوب، والبنى المشبوهة. مثال شائع على اللينتر هو ESLint.
- **المُنسقات**: المُنسقات هي أدوات تُنسق الكود تلقائيًا ليتوافق مع دليل أسلوب محدد. مثال شائع على المُنسق هو Prettier.

## إدارة الذاكرة

- **التعريف**: إدارة الذاكرة هي عملية التحكم في الذاكرة، تخصيصها عند الحاجة وتحريرها عندما لا تكون مطلوبة. تستخدم جافاسكريبت إدارة ذاكرة تلقائية. هذا يعني أن جافاسكريبت (وخاصة محرك جافاسكريبت في متصفحك) يتولى تخصيص الذاكرة وإلغاء تخصيصها نيابةً عنك. لا تحتاج إلى تحرير الذاكرة صراحةً في كودك. تُسمى هذه العملية التلقائية غالبًا "جمع القمامة".

## الإغلاقات (Closures)

- **التعريف**: الإغلاق هو دالة لديها وصول إلى المتغيرات في نطاقها الخارجي (النطاق الحرفي المحيط)، حتى بعد أن تنتهي الدالة الخارجية من التنفيذ.

:::interactive_editor

```js
function outerFunction(x) {
  let y = 10;
  function innerFunction() {
    console.log(x + y);
  }
  return innerFunction;
}

let closure = outerFunction(5);
closure(); // 15
```

## الكلمة المفتاحية `var` والرفع (Hoisting)

- **التعريف**: كانت `var` هي الطريقة الأصلية لإعلان المتغيرات قبل 2015. لكن ظهرت بعض المشاكل مع `var` من حيث النطاق، إعادة الإعلان، وأكثر. لهذا السبب يستخدم برمجة JavaScript الحديثة `let` و`const` بدلاً منها.
- **إعادة إعلان المتغيرات باستخدام `var`**: إذا حاولت إعادة إعلان متغير باستخدام `let`، ستحصل على `SyntaxError`. لكن مع `var`، يُسمح بإعادة الإعلان.

- **`var` والنطاق**: المتغيرات المعلنة باستخدام `var` داخل كتلة (مثل جملة `if` أو حلقة `for`) تظل قابلة للوصول خارج تلك الكتلة.

- **الرفع**: هو السلوك الافتراضي لجافاسكريبت الذي ينقل الإعلانات إلى أعلى نطاقاتها خلال مرحلة الترجمة قبل تنفيذ الكود. عند إعلان متغير باستخدام الكلمة المفتاحية `var`، ترفع جافاسكريبت الإعلان إلى أعلى نطاقه.

عند إعلان دالة باستخدام صيغة إعلان الدالة، يتم رفع اسم الدالة وجسمها معًا. هذا يعني أنه يمكنك استدعاء الدالة قبل إعلانها في كودك.

الإعلانات التي تُجرى باستخدام `let` أو `const` تُرفع، لكنها غير مهيأة، ولا يمكنك الوصول إليها قبل الإعلان الفعلي في كودك. يُشار إلى هذا السلوك غالبًا باسم "منطقة الموت الزمنية".

## العمل مع الاستيراد، التصدير والوحدات

- **الوحدة**: هي وحدة كود مستقلة تغلف دوالًا، أصنافًا، أو متغيرات ذات صلة. لإنشاء وحدة، تكتب كود جافاسكريبت في ملف منفصل.
- **التصدير**: أي متغيرات، دوال، أو أصناف تريد إتاحتها لأجزاء أخرى من التطبيق يجب تصديرها صراحةً باستخدام الكلمة المفتاحية `export`. هناك نوعان من التصدير: التصدير المسمي والتصدير الافتراضي.
- **الاستيراد**: لاستخدام العناصر المصدرة في جزء آخر من التطبيق، تحتاج إلى استيرادها باستخدام الكلمة المفتاحية `import`. يمكن أن يكون الاستيراد مسميًا، افتراضيًا، أو استيراد مساحة أسماء.

```js
// Within a file called math.js, we export the following functions:

// Named export
export function add(num1, num2) {
  return num1 + num2;
}

// Default export
export default function subtract(num1, num2) {
  return num1 - num2;
}

// Within another file, we can import the functions from math.js.

// Named import - This line imports the add function.
// The name of the function must exactly match the one exported from math.js.
import { add } from './math.js';

// Default import - This line imports the subtract function.
// The name of the function can be anything.
import subtractFunc from './math.js';

// Namespace import - This line imports everything from the file.
import * as Math from './math.js';

console.log(add(5, 3)); // 8
console.log(subtractFunc(5, 3)); // 2
console.log(Math.add(5, 3)); // 8
console.log(Math.subtract(5, 3)); // 2
```

## دوال الاستدعاء (Callback Functions) وطريقة `forEach`

- **التعريف**: في JavaScript، دالة الاستدعاء الراجع هي دالة تُمرر كمعلمة إلى دالة أخرى، بحيث يمكن للدالة الخارجية استدعاؤها في نقطة معينة.
- **طريقة `forEach()`**: تُستخدم هذه الطريقة للتكرار على كل عنصر في المصفوفة وتنفيذ عملية على كل عنصر. يمكن أن تأخذ دالة الاستدعاء الراجع في `forEach` حتى ثلاث معلمات: العنصر الحالي، فهرس العنصر الحالي، والمصفوفة التي تم استدعاء `forEach` عليها.

## الدوال عالية الرتبة (Higher Order Functions)

- **التعريف**: الدالة عالية الرتبة تأخذ دالة أو أكثر كمعاملات وتُرجع دالة أو قيمة كنتيجة.

- **طريقة `map()`**: تُستخدم هذه الطريقة لإنشاء مصفوفة جديدة بتطبيق دالة معينة على كل عنصر من المصفوفة الأصلية. يمكن أن تقبل دالة الاستدعاء حتى ثلاث معلمات: العنصر الحالي، الفهرس، والمصفوفة التي استُدعيت عليها `map`.

- **طريقة `filter()`**: تُستخدم هذه الطريقة لإنشاء مصفوفة جديدة تحتوي على العناصر التي تجتاز اختبارًا محددًا، مما يجعلها مفيدة لاستخراج العناصر بشكل انتقائي بناءً على معايير. تمامًا مثل طريقة `map`، تقبل دالة الاستدعاء في `filter` نفس المعلمات الثلاث: العنصر الحالي، الفهرس، والمصفوفة.

- **طريقة `reduce()`**: تُستخدم هذه الطريقة لمعالجة مصفوفة وتكثيفها إلى قيمة واحدة. يمكن أن تكون هذه القيمة رقمًا، سلسلة نصية، كائنًا، أو حتى مصفوفة أخرى. تعمل `reduce()` بتطبيق دالة على كل عنصر في المصفوفة، بالترتيب، وتمرير نتيجة كل حساب إلى التالي. تُسمى هذه الدالة غالبًا دالة المخفض (reducer). تأخذ دالة المخفض معلمتين رئيسيتين: المجمع (accumulator) والقيمة الحالية. المجمع هو المكان الذي تخزن فيه نتيجة العمليات الجارية، والقيمة الحالية هي عنصر المصفوفة الجاري معالجته.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce(
  (accumulator, currentValue) => accumulator + currentValue,
  0
);

console.log(sum); // 15
```

:::

## تسلسل الطرق (Method Chaining)

- **التعريف**: تسلسل الطرق هو تقنية برمجية تتيح لك استدعاء عدة طرق على نفس الكائن في سطر واحد من الكود. يمكن لهذه التقنية أن تجعل كودك أكثر وضوحًا واختصارًا، خاصة عند تنفيذ سلسلة من العمليات على نفس الكائن.

## العمل مع طريقة `sort`

- **التعريف**: تُستخدم طريقة `sort` لترتيب عناصر المصفوفة وإرجاع مرجع للمصفوفة المرتبة. لا يتم إنشاء نسخة جديدة في هذه الحالة لأن العناصر تُرتب في مكانها.

إذا كنت بحاجة إلى ترتيب أرقام، فستحتاج إلى تمرير دالة مقارنة. تقوم طريقة `sort` بتحويل العناصر إلى سلاسل نصية ثم تقارن تسلسل وحدات الترميز UTF-16 الخاصة بها. وحدات ترميز UTF-16 هي القيم الرقمية التي تمثل الأحرف في السلسلة النصية. أمثلة على وحدات ترميز UTF-16 هي الأرقام 65 و66 و67 التي تمثل الأحرف "A" و"B" و"C" على التوالي. لذلك يظهر الرقم 200 قبل الرقم 3 في المصفوفة، لأن السلسلة النصية "200" تأتي قبل السلسلة "3" عند مقارنة وحدات ترميز UTF-16 الخاصة بها.

:::interactive_editor

```js
const numbers = [414, 200, 5, 10, 3];

numbers.sort((a, b) => a - b);

console.log(numbers); // [3, 5, 10, 200, 414]
```

:::

المعاملات `a` و `b` هما العنصران اللذان تتم مقارنتهما. يجب أن تُرجع دالة المقارنة قيمة سالبة إذا كان يجب أن يأتي `a` قبل `b`، وقيمة موجبة إذا كان يجب أن يأتي `a` بعد `b`، وصفر إذا كان `a` و `b` متساويين.

## العمل مع طريقتي `every` و `some`

- **طريقة `every()`**: تختبر هذه الطريقة ما إذا كانت جميع العناصر في المصفوفة تجتاز اختبارًا تنفذه دالة مقدمة. تُرجع طريقة `every()` القيمة `true` إذا أعادت الدالة المقدمة `true` لجميع العناصر في المصفوفة. إذا فشل أي عنصر في الاختبار، تُرجع الطريقة فورًا `false` وتتوقف عن فحص العناصر المتبقية.

- **طريقة `some()`**: تتحقق هذه الطريقة مما إذا كان على الأقل عنصر واحد يجتاز الاختبار. تُرجع طريقة `some()` القيمة `true` بمجرد أن تجد عنصرًا يجتاز الاختبار. إذا لم يجتاز أي عنصر الاختبار، تُرجع `false`.

## العمل مع DOM وواجهات برمجة التطبيقات للويب

- **API**: واجهة برمجة التطبيقات (Application Programming Interface) هي مجموعة من القواعد والبروتوكولات التي تسمح لتطبيقات البرمجيات بالتواصل مع بعضها وتبادل البيانات بكفاءة.
- **Web API**: واجهات برمجة التطبيقات للويب مصممة خصيصًا لتطبيقات الويب. غالبًا ما تُقسم هذه الأنواع من الواجهات إلى فئتين رئيسيتين: واجهات المتصفح وواجهات الطرف الثالث.
- **Browser APIs**: هذه الواجهات تتيح بيانات من المتصفح. كمطوِّر ويب، يمكنك الوصول إلى هذه البيانات والتعامل معها باستخدام JavaScript.
- **Third-Party APIs**: هذه الواجهات غير مدمجة في المتصفح افتراضيًا. عليك استدعاء كودها بطريقة ما. عادةً ما تحتوي على توثيق مفصل يشرح كيفية استخدام خدماتها. مثال على ذلك هو Google Maps API، الذي يمكنك استخدامه لعرض خرائط تفاعلية على موقعك.
- **DOM**: نموذج كائن الوثيقة (Document Object Model) هو واجهة برمجة تتيح لك التفاعل مع مستندات HTML. باستخدام DOM، يمكنك إضافة أو تعديل أو حذف عناصر في صفحة الويب. جذر شجرة DOM هو العنصر `html`. هو الحاوية العليا لكل محتوى مستند HTML. كل العقد الأخرى هي عناصر تابعة لهذا الجذر. تحت عقدة الجذر، نجد عقدًا أخرى في التسلسل الهرمي. عقدة الأصل هي عنصر يحتوي على عناصر أخرى. العقدة الفرعية هي عنصر موجود داخل عنصر آخر.
- **`navigator` Interface**: توفر هذه الواجهة معلومات عن بيئة المتصفح، مثل سلسلة وكيل المستخدم، النظام الأساسي، وإصدار المتصفح. سلسلة وكيل المستخدم هي نص يحدد المتصفح ونظام التشغيل المستخدم.
- **`window` Interface**: تمثل هذه الواجهة نافذة المتصفح التي تحتوي على مستند DOM. توفر طرقًا وخصائص للتفاعل مع نافذة المتصفح، مثل تغيير حجم النافذة، فتح نوافذ جديدة، والتنقل إلى عناوين URL مختلفة.

## العمل مع طرق `querySelector()` و `querySelectorAll()` و `getElementById()`

- **طريقة `getElementById()`**: تُستخدم هذه الطريقة للحصول على كائن يمثل عنصر HTML بالمعرف `id` المحدد. تذكر أن المعرفات يجب أن تكون فريدة في كل مستند HTML، لذا سترجع هذه الطريقة كائن عنصر واحد فقط.

- **طريقة `querySelector()`**: تُستخدم هذه الطريقة للحصول على أول عنصر في مستند HTML يطابق محدد CSS الممرر كمعلمة.

- **طريقة `querySelectorAll()`**: يمكنك استخدام هذه الطريقة للحصول على قائمة بجميع عناصر DOM التي تطابق محدد CSS معين.

## العمل مع طرق `innerText()` و `innerHTML()` و `createElement()` و `textContent()`

- **خاصية `innerHTML`**: هذه خاصية من خصائص الـ`Element` تُستخدم لتعيين أو تحديث أجزاء من ترميز HTML.

- **طريقة `createElement`**: تُستخدم لإنشاء عنصر HTML.

- **`innerText`**: تمثل محتوى النص المرئي لعنصر HTML وأبنائه.

- **`textContent`**: تُرجع محتوى النص العادي لعنصر، بما في ذلك كل النص داخل العناصر التابعة له.

## العمل مع طرق `appendChild()` و `removeChild()`

- **طريقة `appendChild()`**: تُستخدم هذه الطريقة لإضافة عقدة إلى نهاية قائمة الأبناء لعقدة الأصل المحددة.

- **طريقة `removeChild()`**: تُستخدم هذه الطريقة لإزالة عقدة من DOM.

## العمل مع طريقة `setAttribute()`

- **التعريف**: تُستخدم هذه الطريقة لتعيين خاصية لعنصر معين. إذا كانت الخاصية موجودة بالفعل، يتم تحديث قيمتها. وإلا، تتم إضافة خاصية جديدة مع القيمة المحددة.

## كائن الحدث (Event Object)

- **التعريف**: كائن `Event` هو حمولة تُفعّل عند تفاعل المستخدم مع صفحة الويب الخاصة بك بطريقة ما. يمكن أن تكون هذه التفاعلات أي شيء من نقر زر أو تركيز على مُدخَل إلى هز جهازه المحمول. جميع كائنات `Event` تحتوي على الخاصية `type`. تكشف هذه الخاصية عن نوع الحدث الذي فعّل الحمولة، مثل keydown أو click. تتوافق هذه القيم مع نفس القيم التي قد تمررها إلى `addEventListener()`، حيث يمكنك التقاط واستخدام كائن `Event`.

## طرق `addEventListener()` و `removeEventListener()`

- **طريقة `addEventListener`**: تُستخدم للاستماع للأحداث. تأخذ معاملين: الحدث الذي تريد الاستماع إليه ودالة تُستدعى عند وقوع الحدث. من الأمثلة الشائعة على الأحداث: أحداث النقر، وأحداث الإدخال، وأحداث التغيير.

:::interactive_editor

```html
<button id="btn">Click Me</button>
<script src="./index.js"></script>
```

```js
const btn = document.getElementById("btn");

btn.addEventListener("click", () => alert("You clicked the button"));
```

:::

- **طريقة `removeEventListener()`**: تُستخدم لإزالة مستمع حدث تمت إضافته سابقًا إلى عنصر باستخدام طريقة `addEventListener()`. هذا مفيد عندما تريد التوقف عن الاستماع لحدث معين على عنصر.

- **معالجات الأحداث المضمّنة**: معالجات الأحداث المضمّنة هي خصائص خاصة على عنصر HTML تُستخدم لتنفيذ كود JavaScript عند حدوث حدث. في JavaScript الحديثة، لا تُعتبر المعالجات المضمّنة أفضل الممارسات. يُفضل استخدام طريقة `addEventListener` بدلًا منها.

## حدث التغيير (Change Event)

- **التعريف**: حدث التغيير هو حدث خاص يُطلق عندما يقوم المستخدم بتعديل قيمة عناصر إدخال معينة. من الأمثلة على ذلك عندما يتم تحديد مربع اختيار أو زر اختيار، أو عندما يقوم المستخدم بالاختيار من أداة اختيار التاريخ أو قائمة منسدلة.

## تصاعد الحدث (Event Bubbling)

- **التعريف**: انتشار الحدث، أو التبليغ، يشير إلى كيفية "تصاعد" الحدث إلى الكائنات الأصلية عند تفعيله.
- **طريقة `stopPropagation()`**: تمنع هذه الطريقة استمرار انتشار الحدث.

## تفويض الحدث (Event Delegation)

- **التعريف**: تفويض الحدث هو عملية الاستماع للأحداث التي تصاعدت إلى عنصر أصل، بدلاً من التعامل معها مباشرة على العنصر الذي تسبب في إطلاقها.

## حدث DOMContentLoaded

- **التعريف**: يُطلق حدث `DOMContentLoaded` عندما يتم تحميل وتحليل كل شيء في مستند HTML. إذا كان لديك أوراق أنماط خارجية أو صور، فلن ينتظر حدث `DOMContentLoaded` تحميلها. سينتظر فقط تحميل HTML.

## العمل مع `style` و `classList`

- **خاصية `Element.style`**: هي خاصية للقراءة فقط تمثل النمط المضمّن لعنصر. يمكنك استخدام هذه الخاصية للحصول على النمط أو تعيينه لعنصر.

- **خاصية `Element.classList`**: هي خاصية للقراءة فقط يمكن استخدامها لإضافة أو إزالة أو تبديل الأصناف (الكلاسات) على عنصر.

## العمل مع طرق `setTimeout()` و `setInterval()`

- **طريقة `setTimeout()`**: تتيح لك تأخير تنفيذ إجراء لمدة زمنية محددة.

- **طريقة `setInterval()`**: تتيح هذه الطريقة تشغيل جزء من الكود بشكل متكرر بفاصل زمني محدد. بما أن `setInterval()` تستمر في تنفيذ الدالة المقدمة عند الفاصل المحدد، قد ترغب في إيقافها. لهذا، عليك استخدام طريقة `clearInterval()`.

## طريقة `requestAnimationFrame()`

- **التعريف**: تتيح لك هذه الطريقة جدولة الخطوة التالية من الرسوم المتحركة قبل إعادة رسم الشاشة التالية، مما ينتج تجربة سلسة وجذابة بصريًا. إعادة رسم الشاشة التالية تشير إلى اللحظة التي يقوم فيها المتصفح بتحديث العرض البصري لصفحة الويب. يحدث هذا عدة مرات في الثانية، عادة حوالي 60 مرة (أو 60 إطارًا في الثانية) على معظم الشاشات.

## واجهة برمجة تطبيقات الرسوم المتحركة على الويب (Web Animations API)

- **التعريف**: تتيح لك واجهة برمجة تطبيقات الرسوم المتحركة على الويب إنشاء والتحكم في الرسوم المتحركة مباشرة داخل JavaScript.

## واجهة برمجة تطبيقات اللوحة (Canvas API)

- **التعريف**: واجهة برمجة تطبيقات اللوحة هي أداة قوية تتيح لك التلاعب بالرسومات داخل ملف JavaScript الخاص بك. للعمل مع Canvas API، تحتاج أولًا إلى توفير عنصر `canvas` في HTML. هذا العنصر يعمل كسطح رسم يمكنك التلاعب به باستخدام طرق وخصائص الواجهات في Canvas API. تحتوي هذه الواجهة على واجهات مثل `HTMLCanvasElement`، و`CanvasRenderingContext2D`، و`CanvasGradient`، و`CanvasPattern`، و`TextMetrics` التي تحتوي على طرق وخصائص يمكنك استخدامها لإنشاء الرسومات في ملف JavaScript الخاص بك.

## فتح وإغلاق الحوارات والنوافذ المنبثقة (Modals) باستخدام JavaScript

- **تعريفات الحوارات والنوافذ المنبثقة**: تتيح الحوارات عرض معلومات أو إجراءات مهمة للمستخدمين. باستخدام عنصر الحوار المدمج في HTML، يمكنك بسهولة إنشاء هذه الحوارات (سواء كانت حوارات نمطية modal أو غير نمطية non-modal) في تطبيقات الويب الخاصة بك. الحوار النمطي هو نوع من الحوارات يجبر المستخدم على التفاعل معه قبل أن يتمكن من الوصول إلى بقية التطبيق أو صفحة الويب. بالمقابل، يسمح الحوار غير النمطي للمستخدم بالاستمرار في التفاعل مع أجزاء أخرى من الصفحة أو التطبيق حتى عندما يكون الحوار مفتوحًا. لا يمنع الوصول إلى بقية المحتوى.
- **طريقة `showModal()`**: تُستخدم لفتح نافذة نمطية (modal).

- **طريقة `close()`**: تُستخدم لإغلاق النافذة النمطية.

## خصائص ARIA الشائعة لإمكانية الوصول

- **خاصية `aria-expanded`**: تُستخدم لنقل حالة ميزة التبديل (أو الكشف) لمستخدمي قارئ الشاشة.

- **خاصية `aria-haspopup`**: تُستخدم هذه الحالة للإشارة إلى أن عنصرًا تفاعليًا سيُفعّل عنصرًا منبثقًا عند التنشيط. يمكنك استخدام خاصية `aria-haspopup` فقط عندما يكون للعنصر المنبثق أحد الأدوار التالية: `menu`، `listbox`، `tree`، `grid`، أو `dialog`. يجب أن تكون قيمة `aria-haspopup` إما أحد هذه الأدوار أو `true`، وهو ما يعادل `menu`.

- **خاصية `aria-checked`**: تُستخدم هذه الخاصية للإشارة إلى ما إذا كان العنصر في حالة محددة. تُستخدم غالبًا عند إنشاء مربعات اختيار مخصصة، أزرار اختيار، مفاتيح، وقوائم اختيار.

- **خاصية `aria-disabled`**: تُستخدم هذه الحالة للإشارة إلى أن العنصر معطل فقط للأشخاص الذين يستخدمون تقنيات مساعدة، مثل قارئات الشاشة.

- **خاصية `aria-selected`**: تُستخدم هذه الحالة للإشارة إلى أن العنصر محدد. يمكنك استخدام هذه الحالة على عناصر تحكم مخصصة مثل واجهة تبويبية، قائمة اختيار، أو شبكة.

- **خاصية `aria-controls`**: تُستخدم لربط عنصر مع عنصر آخر يتحكم به. يساعد هذا الأشخاص الذين يستخدمون تقنيات مساعدة على فهم العلاقة بين العناصر.

- **خاصية `hidden`**: تخفي الألواح غير النشطة عن كل من المستخدمين البصريين ومستخدمي تقنيات المساعدة.

## العمل مع المناطق الحية والمحتوى الديناميكي

- **خاصية `aria-live`**: تجعل جزءًا من صفحة الويب منطقة حية، مما يعني أن أي تحديثات داخل تلك المنطقة سيعلن عنها قارئ الشاشة حتى لا يفوت المستخدمون تغييرات مهمة.
- **قيمة `polite`**: تستخدم معظم المناطق الحية هذه القيمة. تعني هذه القيمة أن التحديث ليس عاجلًا، لذا يمكن لقارئ الشاشة الانتظار حتى ينهي أي إعلان جاري أو يكمل المستخدم الإجراء الحالي قبل الإعلان عن التحديث.

إليك مثالًا لمنطقة حية يتم تحديثها ديناميكيًا بواسطة JavaScript:

:::interactive_editor

```html
<div aria-live="polite" id="status"></div>

<button id="updateStatus">Update Status</button>

<script>
  const statusEl = document.getElementById("status");
  const btn = document.getElementById("updateStatus");

  btn.addEventListener("click", () => {
    statusEl.textContent = "Your file has been successfully uploaded.";
  });
</script>
```

:::

- **خاصية `contenteditable`**: تحول العنصر إلى محرر حي، مما يسمح للمستخدمين بتحديث محتواه كما لو كان حقل نصي. عندما لا يكون هناك مسمى أو عنوان مرئي لمنطقة قابلة للتحرير، أضف اسمًا يمكن الوصول إليه باستخدام خاصية `aria-label` لمساعدة مستخدمي قارئ الشاشة على فهم هدف المنطقة القابلة للتحرير.

## أحداث `focus` و `blur`

- **حدث `blur`**: يُطلق عندما يفقد العنصر التركيز.

- **حدث `focus`**: يُطلق عندما يحصل العنصر على التركيز.

## أنواع شائعة من رسائل الخطأ

- **SyntaxError**: تحدث هذه الأخطاء عندما تكتب شيئًا بشكل غير صحيح في كودك، مثل فقدان قوس أو قوس معقوف. فكر فيها كخطأ نحوي في جملة.

- **ReferenceError**: هناك عدة أنواع من أخطاء المرجع، تُثار بطرق مختلفة. النوع الأول من أخطاء المرجع هو المتغيرات غير المعرفة. مثال آخر على ReferenceError هو محاولة الوصول إلى متغير مُعلن باستخدام `let` أو `const` قبل تعريفه.

- **TypeError**: تحدث هذه الأخطاء عندما تحاول تنفيذ عملية على نوع خاطئ.

- **RangeError**: تحدث هذه الأخطاء عندما يحاول كودك استخدام قيمة خارج النطاق الذي يمكن لجافاسكريبت التعامل معه.

## جملة `throw`

- **التعريف**: تُستخدم جملة `throw` في JavaScript لرمي استثناء معرف من قبل المستخدم. الاستثناء في البرمجة هو حدث غير متوقع يحدث ويعطل التدفق الطبيعي للبرنامج.

## `try...catch...finally`

- **التعريف**: يُستخدم كتلة `try` لتغليف الكود الذي قد يرجع خطأً. تعمل كمساحة آمنة لتجربة شيء قد يفشل. تلتقط كتلة `catch` الأخطاء التي تحدث في كتلة try وتعالجها. يمكنك استخدام كائن الخطأ داخل catch لفحص ما حدث خطأً. تُنفذ كتلة `finally` بعد كتلتي try و catch، بغض النظر عما إذا حدث خطأ أم لا. تُستخدم عادةً لمهام التنظيف، مثل إغلاق الملفات أو تحرير الموارد.

:::interactive_editor

```js
function processInput(input) {
  if (typeof input !== "string") {
    throw new TypeError("Input must be a string.");
  }

  return input.toUpperCase();
}

try {
  console.log("Starting to process input...");
  const result1 = processInput("hello");
  console.log("Processed result:", result1);  // HELLO
  const result2 = processInput(9);  // throws TypeError
  console.log("Processed result:", result2);  // not executed
} catch (error) {
  console.error("Error occurred:", error.message);
} 
```

:::

## تقنيات تصحيح الأخطاء

- **تعليمة `debugger`**: تتيح لك هذه التعليمة إيقاف كودك عند سطر معين للتحقيق فيما يحدث في البرنامج.

- **نقاط التوقف**: تتيح نقاط التوقف إيقاف تنفيذ كودك عند سطر تختاره. بعد الإيقاف، يمكنك فحص المتغيرات، تقييم التعبيرات، وفحص مكدس الاستدعاءات.
- **المراقبون**: تتيح مراقبة التعبيرات متابعة قيم المتغيرات أو التعبيرات أثناء تشغيل الكود حتى لو كانت خارج النطاق الحالي.
- **التحليل**: يساعد التحليل في تحديد عنق الزجاجة في الأداء من خلال التقاط لقطات شاشة وتسجيل استخدام وحدة المعالجة المركزية، واستدعاءات الدوال، ووقت التنفيذ.
- **`console.dir()`**: تُستخدم هذه الطريقة لعرض قائمة تفاعلية بخواص كائن جافاسكريبت محدد. تعرض قائمة هرمية يمكن توسيعها لرؤية كل الخصائص المسكنة.

- **`console.table()`**: تعرض هذه الطريقة بيانات جدولة على شكل جدول في وحدة التحكم. تأخذ وسيطًا إلزاميًا واحدًا يجب أن يكون مصفوفة أو كائنًا، ووسيطًا اختياريًا لتحديد الخصائص (الأعمدة) التي تُعرض.

## التعبيرات النمطية والطرق الشائعة

- **تعريف**: التعبيرات النمطية، أو Regex، تُستخدم لإنشاء "نمط" يمكنك استخدامه للتحقق من سلسلة نصية، استخراج نص، والمزيد.

- **دالة البناء `RegExp`**: عندما تأتي النمط أو العلامات من متغيرات، يمكنك بناء نفس النوع من التعبير النمطي باستخدام دالة البناء `RegExp`. تقبل سلسلة نمط وسلسلة علامات اختيارية.

على سبيل المثال، `new RegExp(pattern, flags)` ينشئ تعبيرًا نمطيًا من تلك السلاسل.

- **طريقة `test()`**: تقبل هذه الطريقة سلسلة نصية لاختبار تطابقها مع التعبير النمطي. تُرجع قيمة منطقية إذا تطابقت السلسلة مع التعبير.

- **طريقة `match()`**: تقبل هذه الطريقة تعبيرًا نمطيًا، ويمكنك أيضًا تمرير سلسلة تُحوّل إلى تعبير نمطي. تُرجع طريقة `match` مصفوفة التطابقات للسلسلة.

- **طريقة `replace()`**: تقبل هذه الطريقة معاملين: التعبير النمطي للمطابقة (أو سلسلة)، والسلسلة التي تستبدل بها المطابقة (أو دالة تُنفذ على كل تطابق).

- **طريقة `replaceAll`**: تُستخدم هذه الطريقة لاستبدال كل حالات نمط معين بسلسلة جديدة. سترجع خطأ إذا أعطيتها تعبيرًا نمطيًا بدون المعدل العام (global modifier).

- **طريقة `matchAll`**: تُستخدم لاسترجاع كل التطابقات لتعبير نمطي معين في سلسلة نصية، بما في ذلك مجموعات الالتقاط، وتُرجعها كمكرر (iterator). المكرر هو كائن يسمح لك بالتنقل عبر مجموعة من العناصر.

## معدلات التعبير النمطي

- **تعريف**: المعدلات، المعروفة أيضًا بـ"الأعلام"، تُغير سلوك التعبير النمطي.
- **العلم `i`**: يجعل التعبير النمطي يتجاهل حالة الأحرف.

- **العلم `g`**: هذا العلم، أو المعدل العام، يسمح لتعبيرك النمطي بمطابقة النمط أكثر من مرة.

- **تعريف الوسم (Anchor)**: الوسم `^` في بداية التعبير النمطي يعني "مطابقة بداية السلسلة". الوسم `$` في نهاية التعبير يعني "مطابقة نهاية السلسلة".

- **العلم `m`**: الوسوم تبحث عن بداية ونهاية السلسلة بأكملها. لكن يمكنك جعل التعبير النمطي يتعامل مع عدة أسطر باستخدام العلم `m`، أو معدل متعدد الأسطر.

- **علامة `d`**: تضيف هذه العلامة مؤشرات البداية والنهاية للمطابقات ومجموعات الالتقاط إلى كائن المطابقة.

- **علامة `u`**: توسع هذه العلامة وظيفة التعبير النمطي لتسمح له بمطابقة أحرف يونيكود الخاصة. تمنحك علامة `u` إمكانية الوصول إلى أصناف خاصة مثل `Extended_Pictographic` لمطابقة معظم الرموز التعبيرية. هناك أيضًا علامة `v`، التي توسع وظيفة مطابقة اليونيكود أكثر.
- **علامة `y`**: يعد معدل اللزوجة مشابهًا جدًا لمعدل التعميم، مع بعض الاستثناءات. أهمها أن التعبير النمطي العام يبدأ من lastIndex ويبحث في بقية السلسلة عن تطابق آخر، بينما التعبير اللزج يعيد null ويعيد تعيين lastIndex إلى 0 إذا لم يكن هناك تطابق فوري عند lastIndex السابق.
- **علامة `s`**: يسمح معدل السطر الواحد للحرف البدل، الممثل بـ `.` في التعبير النمطي، بمطابقة فواصل الأسطر - مما يعامل السلسلة النصية كسطر واحد فقط.

## فئات الأحرف

- **الحرف البدل `.`**: فئات الأحرف هي صيغة خاصة يمكنك استخدامها لمطابقة مجموعات أو مجموعات فرعية من الأحرف. أول فئة أحرف يجب أن تتعلمها هي فئة الحرف البدل. يُمثل الحرف البدل بنقطة، ويطابق أي حرف مفرد باستثناء فواصل الأسطر. للسماح للحرف البدل بمطابقة فواصل الأسطر، تذكر أنه يجب استخدام العلم `s`.

- **`\d`**: سيطابق كل الأرقام (`0-9`) في السلسلة.

- **`\w`**: يُستخدم لمطابقة أي حرف كلمة (`a-zA-Z0-9_`) في السلسلة. يُعرف حرف الكلمة بأنه أي حرف من a إلى z أو A إلى Z، أو رقم من 0 إلى 9، أو الشرطة السفلية.

- **`\s`**: تمثل فئة الحروف البيضاء `\s` بواسطة الشرطة المائلة العكسية متبوعة بحرف `s`. تطابق هذه الفئة أي فراغ أبيض، بما في ذلك الأسطر الجديدة، والمسافات، وعلامات الجدولة، وأحرف الفراغ الخاصة في يونيكود.
- **نفي فئات الحروف الخاصة**: لنفي إحدى هذه الفئات، بدلاً من استخدام حرف صغير بعد الشرطة المائلة العكسية، يمكنك استخدام الحرف الكبير المقابل. على سبيل المثال، `\D` تطابق أي حرف واحد ليس رقميًا.

- **فئات الأحرف المخصصة**: يمكنك إنشاء فئات أحرف مخصصة بوضع الأحرف التي تريد مطابقتها داخل مجموعة من الأقواس المربعة.

على سبيل المثال، `/[abcdf]/` تطابق أي حرف من الحروف الموجودة داخل الأقواس.

## تأكيدات النظر للأمام والنظر للخلف

- **تعريف**: تسمح تأكيدات النظر للأمام والنظر للخلف بمطابقة أنماط محددة بناءً على وجود أو عدم وجود أنماط محيطة.
- **تأكيد النظر للأمام الإيجابي**: يطابق نمطًا عندما يتبعه نمط آخر. لبناء تأكيد نظر للأمام إيجابي، تبدأ بالنمط الذي تريد مطابقته، ثم تستخدم أقواسًا لتغليف النمط الذي تريد استخدامه كشرط. بعد القوس الافتتاحي، استخدم `?=` لتعريف النمط كتأكيد نظر للأمام إيجابي.

على سبيل المثال، `/free(?=code)/i` تطابق `free` عندما تتبعها `code`.

- **تأكيد النظر للأمام السلبي**: هو نوع من الشروط في التعبيرات النمطية للتحقق من أن نمطًا معينًا لا يحدث أمام السلسلة.

على سبيل المثال، `/free(?!code)/i` تطابق `free` عندما لا تتبعها `code`.

- **تأكيد النظر للخلف الإيجابي**: يطابق نمطًا فقط إذا سبق بنمط محدد آخر، دون تضمين النمط السابق في المطابقة.

على سبيل المثال، `/(?<=free)code/i` تطابق `code` عندما تسبقها `free`.

- **تأكيد النظر للخلف السلبي**: يضمن أن نمطًا لا يسبقه نمط محدد آخر. يطابق فقط إذا لم يسبقه النمط المحدد مباشرة، دون تضمين التسلسل السابق في المطابقة.

على سبيل المثال، `/(?<!free)code/i` تطابق `code` عندما لا تسبقها `free`.

## المحددات الكمية في التعبيرات النمطية

- **التعريف**: يحدد المحدد الكمي في التعبيرات النمطية عدد مرات ظهور نمط (أو جزء من نمط). يساعد في التحكم بعدد مرات تكرار الأحرف أو المجموعات في المطابقة.

على سبيل المثال، `/^\d{4}$/` تطابق سلسلة تحتوي بالضبط على أربعة أرقام.

- **`*`** : يطابق 0 أو أكثر من تكرارات العنصر السابق.
- **`+`**: يطابق 1 أو أكثر من تكرارات العنصر السابق.
- **`?`**: يطابق 0 أو 1 تكرار من العنصر السابق.
- **`{n}`**: يطابق بالضبط n تكرار من العنصر السابق.
- **`{n,}`**: يطابق n أو أكثر من تكرارات العنصر السابق.
- **`{n,m}`**: يطابق بين n و m تكرارات من العنصر السابق.

## مجموعات الالتقاط والمرجع العكسي

- **مجموعات الالتقاط**: تسمح لك مجموعة الالتقاط بـ"التقاط" جزء من السلسلة المطابقة لاستخدامه كما تريد. تُعرف مجموعات الالتقاط بالأقواس التي تحتوي على النمط المراد التقاطه، بدون أحرف قيادية مثل النظر للأمام.

على سبيل المثال، `/free(code)camp/i` تلتقط `code`.

- **المجموعات غير الالتقاطية**: تشبه مجموعة الالتقاط لكنها لا تخزن الجزء المطابق من السلسلة للاستخدام لاحقًا. تُعرف المجموعات غير الالتقاطية بـ `(?:...)`.

على سبيل المثال، `/free(?:code)camp/i` تجمع `code` دون التقاطها.

- **المرجع العكسي**: يشير المرجع العكسي في التعبيرات النمطية إلى طريقة لإعادة استخدام جزء من النمط الذي تم مطابقته سابقًا في نفس التعبير. يسمح لك بالإشارة إلى مجموعة ملتقطة (جزء من النمط داخل الأقواس) برقمها. على سبيل المثال، `$1` يشير إلى المجموعة الملتقطة الأولى.

:::interactive_editor

```js
const regex = /free(co+de)camp/i;
console.log("freecoooooooodecamp".replace(regex, "paid$1world"));
```

:::

- يمكنك استخدام المرجعيات الخلفية داخل التعبير النمطي نفسه لمطابقة نفس النص الذي التقطته مجموعة سابقة باستخدام الشرطة المائلة العكسية ورقم مجموعة الالتقاط. على سبيل المثال:

:::interactive_editor

```js
const regex = /(hello) \1/i;
console.log(regex.test("hello hello")); // true
console.log(regex.test("hello world")); // false
```

:::

## التحقق من صحة النماذج باستخدام JavaScript

- **واجهة برمجة التحقق من القيود (Constraint Validation API)**: بعض عناصر HTML، مثل `textarea` و`input`، تعرض واجهة برمجة تحقق من القيود. تتيح هذه الواجهة التأكد من أن القيمة التي يقدمها المستخدم لهذا العنصر تجتاز أي تحقق على مستوى HTML كتبته، مثل الحد الأدنى للطول أو مطابقة النمط.
- **طريقة `checkValidity()`**: تُرجع هذه الطريقة `true` إذا تطابق العنصر مع كل تحقق HTML (بناءً على خصائصه)، و`false` إذا فشل.

- **طريقة `reportValidity()`**: تخبر هذه الطريقة المتصفح بأن `input` غير صالح.

- **خاصية `validity`**: تُستخدم هذه الخاصية للحصول على حالة صلاحية عناصر التحكم في الموذج (مثل `<input>`, `<select>`, وغيرها) وتوفر معلومات حول ما إذا كان مُدخَل المستخدم يفي بالقيود المحددة لذلك العنصر (مثل الحقول `required`، قيود النمط، الحد الأقصى للطول، وغيرها).

- **خاصية `patternMismatch`**: ستكون `true` إذا لم تتطابق القيمة مع نمط التعبير النمطي المحدد.

## طريقة `preventDefault()`

- **التعريف**: لكل حدث يحدث في DOM سلوك افتراضي معين. على سبيل المثال، نقر مربع اختيار يبدل حالة ذلك المربع افتراضيًا. الضغط على <kbd>مفتاح المسافة</kbd> على زر مركّز يُفعّل ذلك الزر. طريقة `preventDefault()` على كائنات `Event` هذه توقف حدوث ذلك السلوك.

## إرسال النماذج

- **التعريف**: هناك ثلاث طرق لإرسال نموذج. الأولى هي عندما ينقر المستخدم زرًا في النموذج يحتوي على الخاصية `type` مضبوطة على `submit`. الثانية هي عندما يضغط المستخدم مفتاح <kbd>Enter</kbd> في أي حقل `input` قابل للتحرير داخل النموذج. الثالثة هي من خلال استدعاء جافاسكريبت لطريقتي `requestSubmit()` أو `submit()` على عنصر `form`.
- **خاصية `action`**: يجب أن تحتوي خاصية `action` على عنوان URL أو مسار نسبي للنطاق الحالي. هذا يحدد المكان الذي يحاول النموذج إرسال البيانات إليه - إذا لم تضبط خاصية `action`، سيرسل النموذج البيانات إلى عنوان الصفحة الحالي.

- **الخاصية `method`**: تقبل هذه الخاصية طريقة `HTTP` قياسية، مثل `GET` أو `POST`، وتستخدم تلك الطريقة عند إجراء الطلب إلى عنوان URL الخاص بالإجراء. وعندما لا تُضبط طريقة، فإن النموذج يلجأ افتراضيًا إلى طلب `GET`. وستُرمَّز بيانات النموذج بترميز URL على هيئة أزواج `name=value` وتُلحَق بعنوان URL الخاص بالإجراء كمعلمات استعلام.

- **خاصية `enctype`**: يقبل عنصر `form` خاصية `enctype` التي تمثل نوع الترميز المستخدم للبيانات. تقبل هذه الخاصية ثلاثة قيم فقط: `application/x-www-form-urlencoded` (الافتراضي، يرسل البيانات كجسم نموذج مشفر في URL)، `text/plain` (يرسل البيانات كنص عادي، في أزواج `name=value` مفصولة بأسطر جديدة)، أو `multipart/form-data`، المخصصة للتعامل مع النماذج التي تحتوي على رفع ملفات.

## كائن `date()` والطرق الشائعة

- **التعريف**: يُستخدم كائن `date()` لإنشاء وتعديل وتنسيق التواريخ والأوقات في JavaScript. على سبيل المثال، `const now = new Date();` ينشئ نسخة جديدة من كائن `Date` ويعينها إلى المتغير `now`. إذا سجلت قيمة `now` في وحدة التحكم، سترى التاريخ والوقت الحاليين بناءً على ساعة النظام في الكمبيوتر الذي يشغل الكود.

- **طريقة `Date.now()`**: تُستخدم هذه الطريقة للحصول على التاريخ والوقت الحاليين. تُرجع `Date.now()` عدد المللي ثانية منذ 1 يناير 1970، 00:00:00 بالتوقيت العالمي المنسق (UTC). يُعرف هذا باسم وقت العصر Unix. وقت العصر Unix هو طريقة شائعة لتمثيل التواريخ والأوقات في أنظمة الحاسوب لأنه عدد صحيح يمكن تخزينه والتعامل معه بسهولة. UTC تعني التوقيت العالمي المنسق، وهو المعيار الزمني الأساسي الذي ينظم العالم من خلاله الساعات والوقت.
- **طريقة `getDate()`**: تُستخدم هذه الطريقة للحصول على يوم من الشهر بناءً على التاريخ الحالي. تُرجع `getDate()` قيمة صحيحة بين 1 و31، حسب يوم الشهر. إذا كان التاريخ غير صالح، سترجع `NaN` (ليس رقمًا).

- **دالة `getMonth()`**: تُستخدم هذه الدالة للحصول على الشهر. يبدأ العد من الصفر، لذا يناير هو 0، فبراير هو 1، وهكذا. على سبيل المثال، استدعاء `getMonth()` على تاريخ في أكتوبر يعيد `9`. إذا كان الشهر غير صالح، فستُرجع `NaN`.

- **طريقة `getFullYear()`**: تُستخدم هذه الطريقة للحصول على السنة كاملة. إذا كانت السنة غير صالحة، سترجع `NaN`.

## طرق مختلفة لتنسيق التواريخ

- **طريقة `toISOString()`**: تُستخدم هذه الطريقة لتنسيق التاريخ بصيغة `ISO` الممتدة (ISO 8601). ISO 8601 هو معيار دولي لتمثيل التواريخ والأوقات. الصيغة هي `YYYY-MM-DDTHH:mm:ss.sssZ`.

- **طريقة `toLocaleDateString()`**: تُستخدم هذه الطريقة لتنسيق التاريخ بناءً على لغة المستخدم المحلية.

تقبل طريقة `toLocaleDateString()` معاملين اختياريين: اللغات (locales) والخيارات (options).

معامل اللغات هو سلسلة تمثل اللغة المراد استخدامها. على سبيل المثال، يمكنك تمرير `"en-US"` للإنجليزية (الولايات المتحدة) أو `"fr-FR"` للفرنسية (فرنسا). إذا لم تمرر معامل اللغات، تُستخدم اللغة الافتراضية. المعامل الاختياري الثاني هو معامل الخيارات، وهو كائن يسمح لك بتحديد تنسيق سلسلة التاريخ.

## دالة البناء `Audio` والطرق الشائعة

- **التعريف**: دالة البناء `Audio`، مثل دوال البناء الأخرى، هي دالة خاصة تُستدعى باستخدام الكلمة المفتاحية `new`. تُعيد عنصر `HTMLAudioElement`، يمكنك استخدامه لتشغيل الصوت للمستخدم أو إضافته إلى DOM ليتمكن المستخدم من التحكم به بنفسه. عند استدعاء دالة البناء، يمكنك اختيارياً تمرير عنوان URL كالمعلمة الوحيدة. يجب أن يشير هذا العنوان إلى مصدر ملف الصوت الذي تريد تشغيله. أو، إذا احتجت لتغيير المصدر ديناميكيًا، يمكنك تعيين العنوان إلى خاصية `src` لعنصر الصوت المعاد.
- **طريقة `play()`**: تُستخدم هذه الطريقة مع عناصر `audio` أو `video` لبدء تشغيل الوسائط.

- **طريقة `pause()`**: تُستخدم هذه الطريقة مع عناصر `audio` أو `video` لإيقاف تشغيل الوسائط مؤقتًا. تحافظ على الموضع الحالي، فإذا استُدعي `play()` يبدأ التشغيل من ذلك الموضع.

- **طريقة `addTextTrack()`**: تتيح لك تحديد مسار نصي مرتبط بعنصر الوسائط - وهو مفيد بشكل خاص لإضافة ترجمات إلى الفيديو.
- **طريقة `fastSeek()`**: تتيح لك هذه الطريقة تحريك موضع التشغيل إلى وقت محدد داخل الوسائط.

دالة البناء `Audio()` لها خصائص تمامًا كما لها طرق. تشمل هذه الخصائص:

- `currentTime`: للحصول على وقت التشغيل الحالي للصوت
- `loop`: لجعل الصوت يعاد تشغيله تلقائيًا باستمرار عند الوصول للنهاية
- `muted`: لكتم صوت عنصر الوسائط بغض النظر عن إعداد مستوى الصوت

## صيغ الصوت والفيديو المختلفة

- **نوع MIME**: نوع MIME، اختصار Multipurpose Internet Mail Extensions، هو طريقة معيارية للإشارة برمجيًا إلى نوع ملف. يمكن لنوع MIME أن يخبر التطبيق، مثل متصفحك، بكيفية التعامل مع ملف معين. في حالة الصوت والفيديو، يشير نوع MIME إلى أنه صيغة وسائط متعددة يمكن تضمينها في صفحة الويب.
- **عنصر `source`**: يُستخدم لتحديد نوع الملف والمصدر - ويمكن أن يشمل أنواعًا متعددة باستخدام عدة عناصر مصدر. عند القيام بذلك، يحدد المتصفح أفضل صيغة تناسب بيئة المستخدم الحالية.
- **MP3**: هو نوع من صيغ الملفات الرقمية المستخدمة لتخزين الموسيقى أو الصوت أو الصوتيات. هو نسخة مضغوطة من تسجيل صوتي تجعل حجم الملف أصغر، مما يسهل تخزينه ومشاركته. MP3 يحظى بأوسع دعم في المتصفحات ونوع MIME الخاص به هو `audio/mpeg`.
- **MP4**: MP4 هو نوع من صيغ الملفات الرقمية المستخدمة لتخزين الفيديو والصوت. يعمل كحاوية تحتوي على الفيديو (الصور) والصوت (الموسيقى أو الكلام) في ملف واحد. يمكن أن يكون لنوع MP4 نوع MIME إما `audio/mp4` أو `video/mp4`، حسب ما إذا كان ملف فيديو أو صوت فقط.
- الصيغ الأخرى تشمل `WMV` المرتبط بتطبيق Windows Media Player، و`OGG`، و`MKV`، و`AVI`، والمزيد.

## برامج الترميز (codecs)

- **تعريف**: برنامج الترميز، اختصارًا "الترميز/فك الترميز"، هو خوارزمية أو برنامج يمكنه تحويل الصوت والفيديو بين الصيغ التناظرية والرقمية. يمكن تحديد برامج الترميز كجزء من نوع MIME. الصيغة الأساسية لتعريف برنامج الترميز هي إضافة فاصلة منقوطة بعد نوع الوسائط، ثم `codecs=` وبرنامج الترميز.

## واجهة برمجة تطبيقات HTMLMediaElement

- **التعريف**: تُستخدم واجهة برمجة التطبيقات `HTMLMediaElement` للتحكم في سلوك عناصر الصوت والفيديو في صفحتك. تمتد من واجهة `HTMLElement` الأساسية، لذا لديك وصول إلى الخصائص والطرق الأساسية بالإضافة إلى أحداث مفيدة مثل `waiting`، و`ended`، و`canplay`، و`canplaythrough`، والمزيد. من أمثلة الطرق: `play()`، و`fastSeek()`، و`pause()`، و`canPlayType()` للتحقق مما إذا كان المتصفح قادرًا على تشغيل ملف صوتي.

## واجهة برمجة تطبيقات Media Capture and Streams

- **التعريف**: تُستخدم واجهة برمجة تطبيقات التقاط الوسائط وتدفقها (Media Capture and Streams API)، أو ما يُعرف بـ MediaStream API، لالتقاط الصوت والفيديو من جهازك. لاستخدام هذه الواجهة، عليك إنشاء كائن `MediaStream`. يمكنك فعل ذلك باستخدام دالة البناء، لكن هذا الكائن لن يكون مرتبطًا بمكونات الجهاز الفعلية للمستخدم. بدلًا من ذلك، توفر خاصية `mediaDevices` في كائن `global` navigator طريقة `getUserMedia()` التي يمكنك استخدامها.

## واجهة برمجة تطبيقات Screen Capture

- **تعريف**: تُستخدم واجهة برمجة تطبيقات Screen Capture لتسجيل شاشة المستخدم. تُتاح هذه الواجهة باستدعاء طريقة `getDisplayMedia()` لكائن `mediaDevices` واستهلاك تدفق الوسائط المرجع.

## واجهة برمجة تطبيقات MediaStream Recording

- **تعريف**: تعمل واجهة برمجة تطبيقات MediaStream Recording بالتوازي مع واجهات MediaStreams، مما يتيح لك تسجيل MediaStream (أو حتى عنصر `HTMLMediaElement` مباشرة).

## واجهة امتدادات مصدر الوسائط (Media Source Extensions API)

- **الموضوع**: تتيح لك واجهة برمجة التطبيقات Media Source Extensions API تمرير بث كاميرا المستخدم مباشرة إلى عنصر فيديو باستخدام خاصية `srcObject`.

## واجهة برمجة تطبيقات الصوت على الويب (Web Audio API)

- **التعريف**: واجهة برمجة التطبيقات Web Audio API هي التي تشغل كل ما يُسمع على الويب. تشمل هذه الواجهة كائنات مهمة مثل `AudioBuffer` (يمثل مخزنًا مؤقتًا يحتوي على بيانات صوتية) أو `AudioContext`، المستخدم لتمثيل رسم بياني لمعالجة الصوت.

## المجموعات (Sets) في جافاسكريبت

- الـ `Set` هو خيار مدمج لإدارة مجموعات البيانات.
- تضمن الـ Sets أن يظهر كل قيمة فيها مرة واحدة فقط، مما يجعلها مفيدة لإزالة التكرارات من المصفوفة أو التعامل مع مجموعات من القيم المميزة.
- يمكنك إنشاء `Set` باستخدام دالة البناء `Set()`.

- يمكن التلاعب بالمجموعات باستخدام هذه الطرق:

  - `add()`: يضيف عنصرًا جديدًا إلى الـ `Set`.
  - `delete()`: يحذف عنصرًا من الـ `Set`.
  - `has()`: يتحقق مما إذا كان عنصر موجودًا في الـ `Set`.
  - `clear()`: يمسح كل العناصر من الـ `Set`.
  - `keys()` و `values()`: كلاهما يعيد `SetIterator` يحتوي على قيم الـ `Set`. هما نفس الشيء لأن `keys()` هو اسم مستعار لـ `values()`.
  - `forEach()`: للتكرار على قيم الـ `Set`.

## المجموعات الضعيفة (Weaksets) في جافاسكريبت

- `WeakSet` هي مجموعة من الكائنات تسمح لك بتخزين كائنات مراجعها ضعيفة.

## الفرق بين Sets و WeakSets

- على عكس Sets، لا يدعم `WeakSet` الأنواع الأولية مثل الأرقام أو السلاسل النصية.
- يخزن `WeakSet` فقط الكائنات، والمرجع إلى تلك الكائنات "ضعيف"، مما يعني أنه إذا لم يُستخدم الكائن في مكان آخر في كودك، يتم إزالته تلقائيًا لتحرير الذاكرة.

## الخرائط (Maps) في جافاسكريبت

- `Map` هو كائن مدمج يحتفظ بأزواج المفتاح-القيمة تمامًا مثل الكائن العادي.
- تختلف الخرائط (Maps) عن كائنات جافاسكريبت القياسية في قدرتها على السماح بمفاتيح من أي نوع، بما في ذلك الكائنات والدوال.
- يوفر `Map` أداءً أفضل من الكائن القياسي عند الإضافة والإزالة المتكررة لأزواج المفتاح-القيمة.
- يمكنك إنشاء `Map` باستخدام دالة البناء `Map()`.

- يمكن التلاعب بالخرائط باستخدام هذه الطرق:

  - `set()`: يضيف زوج مفتاح-قيمة جديد إلى الـ `Map`.
  - `get()`: يسترجع قيمة مفتاح من الـ `Map`.
  - `delete()`: يحذف زوج مفتاح-قيمة من الـ `Map`.
  - `has()`: يتحقق مما إذا كان المفتاح موجودًا في الـ `Map`.
  - `clear()`: يزيل كل أزواج المفتاح-القيمة من الـ `Map`.

لاحظ أن كلًا من الخرائط والمجموعات تحتوي على خاصية `size` التي تعيد عدد العناصر الفريدة فيها.

## الخرائط الضعيفة (WeakMaps) في جافاسكريبت

- `WeakMap` هي مجموعة من أزواج المفتاح والقيمة مثل `Map`، لكنها تستخدم مراجع ضعيفة للمفاتيح. يجب أن يكون المفتاح كائنًا والقيم يمكن أن تكون أي شيء تريده.

## الفرق بين Maps و WeakMaps

- تشبه WeakMaps المجموعات الضعيفة (WeakSets) في أنها تخزن فقط الكائنات والمراجع إلى هذه الكائنات "ضعيفة".

## التخزين الدائم

- **التعريف**: يشير التخزين الدائم إلى طريقة لحفظ البيانات بحيث تبقى متاحة حتى بعد انقطاع التيار الكهربائي أو إعادة تشغيل الجهاز.

## إنشاء، قراءة، تحديث، حذف (CRUD)

- **إنشاء**: يشير هذا إلى عملية إنشاء بيانات جديدة. على سبيل المثال، في تطبيق ويب، قد يكون ذلك عندما يضيف المستخدم منشورًا جديدًا إلى مدونة.
- **قراءة**: هي العملية التي يتم فيها استرجاع البيانات من قاعدة بيانات. على سبيل المثال، عند زيارة منشور مدونة أو عرض ملفك الشخصي على موقع ويب، تقوم بعملية قراءة لجلب وعرض البيانات المخزنة في قاعدة البيانات.
- **تحديث**: يتضمن تعديل البيانات الموجودة في قاعدة البيانات. مثال على ذلك تحرير منشور مدونة أو تحديث معلومات ملفك الشخصي.
- **حذف**: هي العملية التي تزيل البيانات من قاعدة بيانات. على سبيل المثال، عند حذف منشور مدونة أو حساب، تقوم بعملية حذف.

## طرق HTTP

- **التعريف**: HTTP تعني بروتوكول نقل النص الفائق وهو الأساس لتواصل البيانات على الويب. هناك طرق HTTP تحدد الإجراءات التي يمكن تنفيذها على الموارد عبر الويب. الطرق الشائعة هي GET، POST، PUT، PATCH، DELETE.
- **طريقة `GET`**: تُستخدم لجلب البيانات من خادم.
- **طريقة `POST`**: تُستخدم لإرسال بيانات إلى خادم لإنشاء مورد جديد.
- **طريقة `PUT`**: تُستخدم لتحديث مورد عن طريق استبداله بالكامل.
- **طريقة `PATCH`**: تُستخدم لتحديث مورد جزئيًا.
- **طريقة `DELETE`**: تُستخدم لإزالة سجلات من قاعدة بيانات.

## خصائص `localStorage` و `sessionStorage`

- **واجهة برمجة تطبيقات التخزين على الويب**: توفر هذه الواجهة آلية للمتصفحات لتخزين أزواج المفتاح-القيمة داخل المتصفح نفسه، مما يسمح للمطوّرين بتخزين معلومات يمكن استخدامها عبر تحديثات الصفحة والجلسات المختلفة. المكوّنان الرئيسيان لواجهة برمجة تطبيقات التخزين على الويب هما خاصيتا `localStorage` و`sessionStorage`.
- **خاصية `localStorage`**: تمثل `localStorage` جزءًا من واجهة برمجة تطبيقات التخزين على الويب التي تسمح ببقاء البيانات حتى بعد إغلاق نافذة المتصفح أو تحديث الصفحة. تبقى هذه البيانات متاحة حتى يتم إزالتها صراحةً بواسطة التطبيق أو المستخدم.
- **طريقة `localStorage.setItem()`**: تُستخدم هذه الطريقة لتخزين زوج مفتاح-قيمة في `localStorage`.

- **طريقة `localStorage.getItem()`**: تُستخدم هذه الطريقة لاسترجاع قيمة مفتاح معين من `localStorage`.

- **طريقة `localStorage.removeItem()`**: تُستخدم هذه الطريقة لحذف عنصر محدد من `localStorage` باستخدام مفتاحه.

- **طريقة `localStorage.clear()`**: تُستخدم هذه الطريقة لمسح جميع البيانات المخزنة في `localStorage`.

- **خاصية `sessionStorage`**: تخزن البيانات التي تدوم فقط لجلسة المتصفح الحالية وتُمسح عند إغلاق تبويب أو نافذة المتصفح.
- **طريقة `sessionStorage.setItem()`**: تُستخدم هذه الطريقة لتخزين زوج مفتاح-قيمة في `sessionStorage`.

- **طريقة `sessionStorage.getItem()`**: تُستخدم هذه الطريقة لاسترجاع قيمة مفتاح معين من `sessionStorage`.

- **طريقة `sessionStorage.removeItem()`**: تُستخدم هذه الطريقة لحذف عنصر محدد من `sessionStorage` باستخدام مفتاحه.

- **طريقة `sessionStorage.clear()`**: تُستخدم هذه الطريقة لمسح جميع البيانات المخزنة في `sessionStorage`.

## العمل مع الكوكيز

- **التعريف**: الكوكيز، المعروفة أيضًا باسم كوكيز الويب أو كوكيز المتصفح، هي قطع صغيرة من البيانات يرسلها الخادم إلى متصفح المستخدم. تُخزن هذه الكوكيز على جهاز المستخدم وتُرسل مرة أخرى إلى الخادم مع الطلبات التالية. الكوكيز ضرورية لمساعدة تطبيقات الويب على الحفاظ على الحالة وتذكر معلومات المستخدم، وهذا مهم خصوصًا لأن HTTP هو بروتوكول عديم الحالة.
- **كوكيز الجلسة**: تدوم هذه الكوكيز فقط طوال مدة جلسة المستخدم على الموقع. بمجرد إغلاق المتصفح أو التبويب، تُحذف كوكيز الجلسة. تُستخدم عادةً لمهام مثل إبقاء المستخدم مسجلاً دخوله أثناء زيارته.
- **كوكيز آمنة**: تُرسل هذه الكوكيز فقط عبر HTTPS، مما يضمن عدم اعتراضها من قبل مهاجم أثناء النقل.
- **كوكيز HttpOnly**: لا يمكن الوصول إلى هذه الكوكيز أو تعديلها بواسطة جافاسكريبت التي تعمل في المتصفح، مما يجعلها أكثر أمانًا ضد هجمات البرمجة عبر المواقع (XSS).
- **رأس Set-Cookie**: عند زيارة موقع ويب، يمكن للخادم إرسال رأس Set-Cookie في استجابة HTTP. يخبر هذا الرأس المتصفح بحفظ كوكيز بمعلومات محددة. على سبيل المثال، قد يخزن معرفًا فريدًا يساعد الموقع على التعرف عليك في الزيارة التالية.
يمكنك تعيين كوكيز يدويًا في جافاسكريبت باستخدام `document.cookie`:

```js
document.cookie = "organization=freeCodeCamp; expires=Fri, 31 Dec 2021 23:59:59 GMT; path=/";
```

لحذف كوكيز، يمكنك تعيين تاريخ انتهاء صلاحيتها إلى وقت في الماضي.

## واجهة برمجة تطبيقات التخزين المؤقت (Cache API)

- **التعريف**: التخزين المؤقت هو عملية حفظ نسخ من الملفات في موقع تخزين مؤقت، بحيث يمكن الوصول إليها بسرعة أكبر. تُستخدم واجهة برمجة تطبيقات التخزين المؤقت لتخزين طلبات واستجابات الشبكة، مما يجعل تطبيقات الويب تعمل بكفاءة أكبر وحتى تعمل بدون اتصال. هي جزء من واجهة Service Worker الأوسع وأساس لإنشاء تطبيقات الويب التقدمية (PWAs) التي يمكنها العمل في ظروف شبكة غير موثوقة أو بطيئة.
واجهة التخزين المؤقت هي آلية تخزين تحفظ كائنات الطلب والاستجابة. عند إرسال طلب إلى خادم، يمكن للتطبيق تخزين الاستجابة واسترجاعها لاحقًا من التخزين المؤقت بدلاً من إرسال طلب جديد عبر الشبكة. هذا يقلل أوقات التحميل، ويوفر عرض النطاق الترددي، ويحسن تجربة المستخدم.
- **تخزين التخزين المؤقت**: يُستخدم لتخزين أزواج المفتاح-القيمة لطلبات HTTP واستجاباتها المقابلة. يتيح هذا استرجاع الموارد المطلوبة سابقًا بكفاءة، مما يقلل الحاجة لجلبها من الشبكة في الزيارات التالية ويحسن الأداء.
- **التحكم في التخزين المؤقت (Cache-Control)**: يمكن للمطورين تحديد مدة بقاء المورد المخزن مؤقتًا، وما إذا كان يجب إعادة التحقق منه أو تقديمه مباشرة من التخزين المؤقت.
- **الدعم بدون اتصال**: باستخدام واجهة التخزين المؤقت، يمكنك إنشاء تطبيقات ويب تركز على العمل بدون اتصال. على سبيل المثال، يمكن لتطبيق ويب تقدمي تقديم الأصول المخزنة مؤقتًا عندما يكون المستخدم غير متصل بالشبكة.

## الأنماط السلبية والتخزين على جانب العميل

- **التتبع المفرط**: يشير إلى ممارسة جمع وتخزين كمية كبيرة من بيانات المستخدم في التخزين على جانب العميل (مثل الكوكيز، التخزين المحلي، أو تخزين الجلسة) دون موافقة واضحة ومستنيرة أو حاجة مشروعة. غالبًا ما يشمل تتبع سلوك المستخدم وتفضيلاته وتفاعلاته عبر مواقع أو جلسات متعددة، مما قد ينتهك خصوصية المستخدم.
- **بصمة المتصفح**: تقنية تُستخدم لتتبع وتحديد المستخدمين بناءً على خصائص فريدة لجهازهم ومتصفحهم، بدلاً من الاعتماد على الكوكيز أو طرق التتبع التقليدية الأخرى. على عكس الكوكيز المخزنة محليًا على جهاز المستخدم، تجمع البصمة مجموعة من المعلومات التي يمكن استخدامها لإنشاء "بصمة" مميزة لجلسة متصفح المستخدم.
- **تخزين كلمات المرور في LocalStorage**: قد يبدو هذا نمطًا سلبيًا واضحًا، لكن تخزين أي بيانات حساسة مثل كلمات المرور في التخزين المحلي يشكل خطرًا أمنيًا. التخزين المحلي غير مشفر ويمكن الوصول إليه بسهولة. لذلك يجب ألا تخزن أي نوع من البيانات الحساسة هناك.

- **التعريف**: تُستخدم IndexedDB لتخزين البيانات المهيكلة في المتصفح. وهي مدمجة في متصفحات الويب الحديثة، مما يسمح لتطبيقات الويب بتخزين واسترجاع كائنات JavaScript بكفاءة.

## عمال التخزين المؤقت / الخدمة (Cache/Service Workers)

- **التعريف**: عامل الخدمة هو سكربت يعمل في الخلفية منفصل عن صفحة الويب الخاصة بك. يمكنه اعتراض طلبات الشبكة، الوصول إلى التخزين المؤقت، وجعل تطبيق الويب يعمل بدون اتصال. هذا مكوّن رئيسي في تطبيقات الويب التقدمية.

## أساسيات العمل مع الأصناف (Classes)

- **التعريف**: تُستخدم الأصناف في جافاسكريبت لتعريف مخططات لإنشاء الكائنات وتغليف البيانات. تشمل الأصناف دالة البناء التي تُستدعى تلقائيًا عند إنشاء كائن جديد من الصنف. تُستخدم لتهيئة خصائص الكائن. تُستخدم الكلمة المفتاحية `this` للإشارة إلى النسخة الحالية من الصنف. تحت دالة البناء، يمكن أن تحتوي الأصناف على ما يسمى بالطرق (methods). الطرق هي دوال معرفة داخل الصنف تؤدي عمليات أو إجراءات على بيانات أو حالة الصنف. تُستخدم لتعريف السلوكيات التي يمكن للنسخ من الصنف تنفيذها.

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);  // Gino
```

:::

لإنشاء نسخة جديدة من الصنف، استخدم الكلمة المفتاحية `new` متبوعة باسم الصنف.

يمكنك أيضًا إنشاء أصناف كتعبيرات صنف. حيث يكون الصنف مجهولًا ويتم تعيينه إلى متغير.

## وراثة الأصناف

- **التعريف**: في البرمجة، تسمح الوراثة بتعريف أصناف ترث الخصائص والطرق من الأصناف الأصلية. هذا يعزز إعادة استخدام الكود ويُنشئ علاقة هرمية بين الأصناف. الصنف الأصلي هو صنف يعمل كخطة أساسية للأصناف الأخرى. يحدد الخصائص والطرق التي ترثها الأصناف الأخرى. الصنف الفرعي هو صنف يرث الخصائص والطرق من صنف آخر. يمكن للأصناف الفرعية أيضًا توسيع وظائف الأصناف الأصلية بإضافة خصائص وطرق جديدة. في JavaScript، نستخدم الكلمة المفتاحية `extends` لتنفيذ الوراثة. تشير هذه الكلمة إلى أن الصنف هو صنف فرعي لصنف آخر.

تُستخدم الكلمة المفتاحية `super` للوصول إلى طرق ودوال البناء وحقول الصنف الأصلي.

:::interactive_editor

```js
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  constructor(brand, year, numDoors) {
    super(brand, year);
    this.numDoors = numDoors;
  }
}

const myCar = new Car("freeCodeCamp Motors", 2019, 4);
console.log(myCar.brand);  // freeCodeCamp Motors
console.log(myCar.year);  // 2019
console.log(myCar.numDoors);  // 4
```

## العمل مع الطرق والخصائص الثابتة

- **الطرق الثابتة**: تُستخدم هذه الطرق غالبًا للدوال المساعدة التي لا تحتاج إلى الوصول إلى حالة كائن معين. تُعرف داخل الأصناف لتغليف الوظائف ذات الصلة.

استخدم الكلمة المفتاحية `static` لتعريف طريقة ثابتة واستدعائها على الصنف نفسه.

الطرق الثابتة مفيدة أيضًا لتنفيذ "طرق المصنع". طريقة المصنع هي طريقة تعرفها بالإضافة إلى دالة البناء لإنشاء كائنات بناءً على معايير محددة.

- **الخصائص الثابتة**: تُستخدم هذه الخصائص لتعريف قيم أو سمات مرتبطة بالصنف نفسه، وليس بنسخ الصنف. الخصائص الثابتة مشتركة بين كل نسخ الصنف ويمكن الوصول إليها دون إنشاء نسخة من الصنف.

على سبيل المثال، `static numberOfWheels = 4;` يعرّف خاصية ثابتة داخل الصنف.

- التسكين هو مفهوم برمجي يسمح لك باستدعاء دالة بشكل متكرر حتى تصل إلى حالة أساسية.

إليك مثالًا على دالة مسكنة تحسب المضروب لعدد ما:

```js
function findFactorial(n) {
  if (n === 0) {
    return 1;
  }
  return n * findFactorial(n - 1);
}
```

في المثال أعلاه، تُستدعى الدالة `findFactorial` بشكل متكرر حتى يصل `n` إلى `0`. عندما يكون `n` هو `0`، يتم الوصول إلى الحالة الأساسية وتُرجع الدالة القيمة `1`. ثم تُرجع الدالة حاصل ضرب `n` في نتيجة الاستدعاء التكراري لـ `findFactorial(n - 1)`.

- تتيح لك العودية التعامل مع شيء ذو عمق غير معروف، مثل الكائنات/المصفوفات المسكنة بعمق، أو شجرة الملفات.
- تُستخدم مكدس الاستدعاء لتتبع استدعاءات الدوال في دالة عودية. في كل مرة تُستدعى دالة، تُضاف إلى مكدس الاستدعاء. عند الوصول إلى الحالة الأساسية، تُزال استدعاءات الدوال من المكدس.
- يجب تعريف الحالة الأساسية بعناية لأن استدعائها بلا نهاية قد يسبب تعطل الكود. ذلك لأن العودية تستمر في تراكم المزيد من استدعاءات الدوال حتى تنفد الذاكرة في النظام.
- تُستخدم العودية في حل المشكلات الرياضية مثل المضروب و فيبوناتشي، واستكشاف الأشجار والرسوم البيانية، وتوليد التباديل والتوافيق، وأكثر من ذلك.

## الخوارزميات وترميز Big O

- **الخوارزميات**: مجموعة من التعليمات غير الغامضة لحل مشكلة أو تنفيذ مهمة. يجب أن تنتهي الخوارزميات بعدد محدود من الخطوات، ويجب أن تكون كل خطوة دقيقة وغير غامضة.

- **ترميز Big O**: يصف أداء الخوارزمية في أسوأ الحالات، أو معدل النمو، مع زيادة حجم الإدخال. يركز على كيفية نمو استخدام الموارد مع حجم الإدخال، متجاهلًا العوامل الثابتة والحدود ذات الرتب الأقل.

### التعقيدات الزمنية الشائعة

- **O(1) - زمن ثابت**: تستغرق الخوارزمية نفس الوقت بغض النظر عن حجم الإدخال.

- **O(log n) - زمن لوغاريتمي**: يزداد الوقت ببطء مع نمو الإدخال. شائع في الخوارزميات التي تقلل حجم المشكلة بشكل متكرر (مثل البحث الثنائي).

- **O(n) - زمن خطي**: يزداد وقت التشغيل تناسبًا مع حجم الإدخال.

- **O(n log n) - زمن لوغاريتمي خطي**: تعقيد زمني شائع للخوارزميات الفعالة للترتيب مثل دمج الترتيب والفرز السريع.

- **O(n²) - زمن تربيعي**: يزداد وقت التشغيل تربيعيًا. غالبًا ما يظهر في الحلقات المتداخلة.

### التعقيد المكاني

- **O(1) - مساحة ثابتة**: تستخدم الخوارزمية نفس كمية الذاكرة بغض النظر عن حجم الإدخال.
- **O(n) - مساحة خطية**: يزداد استخدام الذاكرة تناسبًا مع حجم الإدخال.
- **O(n²) - مساحة تربيعية**: يزداد استخدام الذاكرة تربيعيًا مع حجم الإدخال.

## تقنيات حل المشكلات

- **فهم المشكلة**: اقرأ بيان المشكلة عدة مرات. حدد الإدخال، الناتج المتوقع، وكيفية تحويل الإدخال إلى الناتج.

- **الرمز الزائف**: وصف عالي المستوى لمنطق الخوارزمية مستقل عن اللغة. يستخدم لغة مكتوبة مشتركة مختلطة مع تراكيب برمجية مثل `IF`، `ELSE`، `FOR`، `WHILE`.

- **حالات الحافة**: إدخالات محددة وصحيحة تحدث عند حدود ما يجب أن تتعامل معه الخوارزمية. اعتبرها دائمًا واختبرها.

## المصفوفات

- **المصفوفات الثابتة**: لها حجم ثابت يحدد عند التهيئة. تُخزن العناصر في مواقع ذاكرة متجاورة. لا يمكن تغيير الحجم أثناء تنفيذ البرنامج.

- **المصفوفات الديناميكية**: يمكن أن تنمو أو تتقلص تلقائيًا أثناء تنفيذ البرنامج. تتعامل مع تغيير الحجم عبر النسخ التلقائي إلى مصفوفات أكبر عند الحاجة.

### تنفيذ المصفوفات الديناميكية في JavaScript

مصفوفات JavaScript هي مصفوفات ديناميكية. يمكنك الوصول إلى العناصر وتحديثها عبر الفهرس، إضافة عناصر باستخدام `push()`، وحذف عناصر باستخدام `pop()` أو `splice()`.

### التعقيدات الزمنية للمصفوفات الديناميكية

- **الوصول**: O(1)
- **الإدراج في النهاية**: O(1) في المتوسط، O(n) عند الحاجة لتغيير الحجم
- **الإدراج في الوسط**: O(n)
- **الحذف**: O(n) للوسط، O(1) للنهاية

## المكدسات

- **المكدسات**: هيكل بيانات يعتمد مبدأ آخر داخل، أول خارج (LIFO). تُضاف العناصر وتُزال من الأعلى فقط.

- **عملية الدفع (Push)**: إضافة عنصر إلى أعلى المكدس. التعقيد الزمني: O(1).

- **عملية السحب (Pop)**: إزالة عنصر من أعلى المكدس. التعقيد الزمني: O(1).

يمكن استخدام مصفوفة JavaScript كهيكل بيانات مكدس باستخدام `push()` لإضافة عناصر و`pop()` لحذفها.

## الطوابير

- **الطوابير**: هيكل بيانات يعتمد مبدأ أول داخل، أول خارج (FIFO). تُضاف العناصر إلى الخلف وتُزال من الأمام.

- **عملية الإدخال (Enqueue)**: إضافة عنصر إلى نهاية الطابور. التعقيد الزمني: O(1).

- **عملية الإخراج (Dequeue)**: إزالة عنصر من بداية الطابور. التعقيد الزمني: O(1).

يمكن لمصفوفة أن تمثل طابورًا باستخدام `push()` للإضافة و`shift()` للحذف. مع ذلك، تستغرق `shift()` وقتًا من نوع O(n) لأن العناصر المتبقية يجب أن تتحرك.

## القوائم المرتبطة

- **القوائم المرتبطة**: هيكل بيانات خطي حيث تحتوي كل عقدة على بيانات ومرجع للعقدة التالية. العقد متصلة كسلسلة.

### القوائم المرتبطة المفردة

- **الهيكل**: كل عقدة تحتوي على بيانات ومرجع واحد للعقدة التالية.
- **التنقل**: يمكن التحرك فقط للأمام من الرأس إلى الذيل.
- **عقدة الرأس**: أول عقدة في القائمة، عادةً العقدة الوحيدة التي يمكن الوصول إليها مباشرة.
- **عقدة الذيل**: آخر عقدة في القائمة، تشير إلى `null`.

### العمليات والتعقيدات الزمنية

- **الإدراج في البداية**: O(1)
- **الإدراج في النهاية**: O(n) - يجب التنقل إلى النهاية
- **الإدراج في الوسط**: O(n) - يجب التنقل إلى الموضع
- **الحذف من البداية**: O(1)
- **الحذف من النهاية**: O(n) - يجب التنقل لإيجاد العقدة السابقة
- **الحذف من الوسط**: O(n) - يجب التنقل لإيجاد العقدة

### القوائم المرتبطة المزدوجة

- **الهيكل**: كل عقدة تحتوي على بيانات ومرجعين: العقدة التالية والعقدة السابقة.
- **التنقل**: يمكن التحرك في كلا الاتجاهين.
- **الذاكرة**: تتطلب ذاكرة أكثر من القوائم المرتبطة المفردة بسبب المرجع الإضافي.

## متى تستخدم كل هيكل بيانات

- **المصفوفات (المصفوفات الديناميكية)**: عندما تحتاج وصول مرتب ومفهرس ولا تعرف الحجم مسبقاً
- **المكدسات**: لعمليات LIFO (وظيفة التراجع، تقييم التعبيرات، التراجع)
- **الطوابير**: لعمليات FIFO (جدولة المهام، البحث بالاتساع أولاً)
- **القوائم المرتبطة**: عند الحاجة لإدراج/حذف متكرر في البداية، حجم غير معروف، لا حاجة للوصول العشوائي

## خوارزميات البحث

تُتيح خوارزميات البحث البحث عن هدف ضمن قائمة معينة من العناصر.

في علوم الحاسوب، هناك خوارزميتان للبحث يجب أن تعرفهما. هما خوارزمية **البحث الخطي** وخوارزمية **البحث الثنائي**. من المهم فهم الفروقات بين هاتين الخوارزميتين ومتى تستخدم كل واحدة منهما.

### البحث الخطي

- يقوم البحث الخطي بتكرار العناصر في مصفوفة، ويفحص كل عنصر من البداية حتى يعثر على العنصر الهدف.
- إذا وُجد العنصر الهدف، يُعاد الفهرس الذي يقع فيه داخل المصفوفة.
- إذا لم يُعثر على الهدف، يُعاد `-1`، وهو ما يعني **فهرس غير صالح** في JavaScript.
- لأن البحث الخطي يفحص كل عنصر حتى يعثر على الهدف، فهو غير فعال لمصفوفة كبيرة من العناصر.
- تعقيد الزمن للبحث الخطي هو `O(n)` لأن الوقت اللازم للبحث في المصفوفة يزداد خطيًا مع حجم المصفوفة.
- تعقيد المساحة للبحث الخطي هو `O(1)` لأنه لا يحتاج إلى مساحة إضافية للبحث في المصفوفة.

### البحث الثنائي

- يعمل البحث الثنائي عن طريق تقسيم مصفوفة من العناصر إلى نصفين، وفحص ما إذا كانت القيمة الهدف في منتصف المصفوفة.
- الشرط لعمل البحث الثنائي هو أن تكون العناصر في المصفوفة مرتبة، إما تصاعديًا أو تنازليًا.
- البحث الثنائي هو خوارزمية أكثر كفاءة للبحث في مصفوفة كبيرة من العناصر لأنه يقسم المصفوفة إلى نصفين ويتجاهل أي نصف لا يحتوي على الهدف.
- إذا وُجد العنصر الهدف في منتصف المصفوفة، يُعاد فهرس العنصر الهدف.
- إذا لم يُعثر على العنصر، تتحقق الخوارزمية مما إذا كان العنصر الهدف في النصف الأيسر أو الأيمن من المصفوفة.
- تستمر في تقسيم الأجزاء المتبقية من المصفوفة إلى أنصاف حتى يُعثر على العنصر الهدف.
- إذا لم يُعثر على العنصر الهدف في المصفوفة، يُعاد `-1`،
- تعقيد الزمن للبحث الثنائي هو `O(log n)` لأن الوقت اللازم للبحث في المصفوفة يزداد لوغاريتميًا مع حجم المصفوفة.
- تعقيد المساحة للبحث الثنائي هو `O(1)` لأنه لا يحتاج إلى مساحة إضافية للبحث في المصفوفة.

### كيف يختلف البحث الخطي عن البحث الثنائي

- البحث الثنائي أكثر ملاءمة لمصفوفة كبيرة من العناصر مقارنة بالبحث الخطي.
- تعقيد الزمن للبحث الخطي هو `O(n)` لأن الوقت اللازم للبحث في المصفوفة يزداد خطيًا مع حجم المصفوفة.
- تعقيد الزمن للبحث الثنائي هو `O(log n)` لأن الوقت اللازم للبحث في المصفوفة يزداد لوغاريتميًا مع حجم المصفوفة.

## خوارزميات الفرز وتقنية القسمة والتغلب

في علوم الحاسوب، القسمة والتغلب هي تقنية تُستخدم لتقسيم المشكلة إلى مشكلات فرعية أصغر لتسهيل حلها. التكرار هو التقنية التي تُستخدم غالبًا في القسمة والتغلب، وهي استراتيجية قوية تُستخدم لتنفيذ العديد من خوارزميات الفرز الفعالة مثل فرز الدمج.

### فرز الدمج

- فرز الدمج هو خوارزمية فرز تتبع نهج القسمة والتغلب.
- يعمل عن طريق تقسيم المصفوفة بشكل متكرر إلى مصفوفات فرعية أصغر حتى تحتوي كل مصفوفة فرعية على عنصر واحد فقط.
- ثم يدمج المصفوفات الفرعية معًا بشكل متكرر بترتيب مرتب.
- تعقيد الزمن لفرز الدمج هو `O(n log n)` لأن المصفوفة تُقسم باستمرار إلى نصفين `(log n)` ثم تُدمج معًا `(O(n))`.
- تعقيد المساحة لفرز الدمج هو `O(n)` لأنه ليس خوارزمية فرز في المكان.

## نظرة عامة على الرسوم البيانية

الرسم البياني هو مجموعة من العقد (الرؤوس) متصلة بحواف (الاتصالات). يمكن لكل عقدة الاتصال بعدة عقد أخرى، مكونة شبكة. أنواع الرسوم البيانية المختلفة تشمل:

- **موجَّه**: الحواف لها اتجاه (من عقدة إلى أخرى)، وغالبًا ما تُمثَّل بخطوط مستقيمة وأسهم.
- **غير موجَّه**: الحواف بلا اتجاه، تُمثَّل بخطوط بسيطة.
- **عقدة معنونة**: كل عقدة مرتبطة بمسمى أو معرف.
- **دائري**: يحتوي على دورات (مسار يبدأ وينتهي عند نفس العقدة).
- **رسم بياني موجَّه لا دوري (DAG)**: رسم بياني موجَّه بلا دورات.
- **حافة معنونة**: كل حافة لها مسمى يُرسم عادةً بجانبها.
- **موزون**: الحواف لها أوزان (قيم) يمكن استخدامها في العمليات الحسابية.
- **منفصل**: يحتوي على مجموعتين أو أكثر من العقد (مكوِّنات) غير متصلة بأي حواف. يمكن أن تفتقر عقدتان إلى حافة مباشرة ومع ذلك يكون بينهما مسار.

تُستخدم الرسوم البيانية في تطبيقات متنوعة مثل الخرائط، الشبكات، أنظمة التوصية، وحل التبعيات.

## استعراضات الرسوم البيانية

تشمل زيارة جميع العقد في الرسم البياني. الخوارزميات الرئيسية هي:

- **البحث بالاتساع أولاً (BFS)**: يزور جميع العقد المجاورة قبل الانتقال إلى المستوى التالي في الرسم البياني.
  - **طابور**: يستخدم طابور (FIFO). تُعلَم العقدة البداية بأنها مُزارة وتُضاف إلى الطابور. طالما الطابور غير فارغ، تُزال العقدة الحالية من الطابور، وتُعلَم كل جيرانها غير المزارة بأنها مُزارة وتُضاف إلى الطابور.
  - **أقصر مسار**: يجد أقصر مسار في الرسوم البيانية غير الموزونة.
  - **ذاكرة**: يتطلب تخزين الطابور في الذاكرة، لذا قد تكون متطلبات المساحة كبيرة، خاصةً للرسوم التي تحتوي على عدد كبير من العقد في نفس المستوى.
  - **المكوِّنات المتصلة**: يمكن استخدامه أيضًا لإيجاد مكونات الرسم البياني المتصلة، ببدء بحث جديد من كل عقدة لم تُزر بعد.
  - **بحث فضاء الحالة**: يستخدم طابورًا لتتبع الحالات المختلفة أثناء بناء تراكيب الأقواس. تمثل كل حالة كمصفوفة تحتوي على السلسلة النصية الحالية، وعدد الأقواس المفتوحة المستخدمة حتى الآن، وعدد الأقواس المغلقة المستخدمة حتى الآن. يمكن إضافة قوس مفتوح فقط إذا كان عدد الأقواس المفتوحة أقل من عدد الأزواج. يمكن إضافة قوس مغلق فقط إذا حافظ على التوازن، بمعنى أن عدد الأقواس المفتوحة يجب أن يكون أكبر من عدد الأقواس المغلقة.

- **البحث بالعمق أولاً (DFS)**: يتبع كل فرع إلى أقصى عمق ممكن قبل التراجع.
  - **مكدس**: يستخدم مكدس (LIFO) أو الاستدعاء الذاتي. تُعلَم العقدة البداية بأنها مُزارة وتُضاف إلى المكدس. طالما المكدس غير فارغ، تُزال العقدة الحالية من المكدس، وتُعلَم جيرانها غير المزارة بأنها مُزارة وتُضاف إلى المكدس.
  - **ذاكرة**: يتطلب تخزين مكدس (أو مكدس استدعاءات الدالة عند استخدام الاستدعاء الذاتي) في الذاكرة، لذا قد تنمو متطلبات المساحة في الرسوم التي تحتوي على مسارات طويلة جدًا.
  - **حالات الاستخدام**: مفيد لاكتشاف الدورات، إيجاد المسارات، وإيجاد المكونات المتصلة.
  - **القيود**: لا يضمن دائمًا إيجاد أقصر مسار بين عقدتين في رسم بياني غير موزون.

## تمثيلات الرسوم البيانية

يمكن تمثيل الرسوم البيانية بطريقتين رئيسيتين:

- **قائمة الجوار**: لكل عقدة قائمة بجيرانها.
  - **التنفيذ**: كمصفوفة، حيث يمثل كل فهرس عقدة والمصفوفة المخزنة عند هذا الفهرس تحتوي على جيرانها. ككائن (أو `Map`)، حيث يمثل كل مفتاح عقدة والقيمة المرتبطة به (مصفوفة) تحتوي على جيرانها.
  - **المساحة**: فعالة من حيث المساحة للرسوم المتفرقة، بتعقيد مساحة `O(V + E)`، حيث `V` عدد العقد و`E` عدد الحواف.
  - **الجيران**: سهل التكرار على الجيران، إذ يتطلب فقط الوصول إلى القائمة المرتبطة بالعقدة.
  - **البحث عن الحافة**: أقل كفاءة من المصفوفات المجاورة لتحديد وجود حافة بين عقدتين. عادةً ما يستغرق `O(deg(v))` وقتًا، حيث `deg(v)` عدد جيران العقدة التي تفحصها، وفي أسوأ الحالات يمكن أن يكون `O(V)`.
  - **الأفضل لـ**: عادةً الخيار المفضل للسيناريوهات الواقعية، حيث الرسوم المتفرقة أكثر شيوعًا.

- **المصفوفة المجاورة**: مصفوفة ثنائية الأبعاد تمثل الصفوف والأعمدة العقد.
  - **القيم**: إذا كان الرسم غير موزون، تعني القيمة `1` وجود حافة تربط العقدتين، والقيمة `0` تعني عدم وجود حافة بينهما. إذا كان الرسم موزونًا، تمثل القيمة وزن الحافة التي تربط العقد.
  - **الحلقات الذاتية**: تمثل القيم في القطر ما إذا كانت كل عقدة لها حلقة ذاتية، وهي حافة تربط العقدة بنفسها.
  - **المساحة**: مكثفة المساحة للرسوم الكبيرة، مع متطلبات مساحة تربيعية كبيرة `O(V²)`، حيث `V` عدد العقد في الرسم.
  - **البحث عن الحافة**: سريع للتحقق من وجود حافة بين عقدتين، لأنه يستغرق وقتًا ثابتًا `O(1)`.
  - **الجيران**: غير فعال لإيجاد جيران العقدة، لأن البرنامج يجب أن يكرر على الصف أو العمود بأكمله. في أسوأ الحالات، يستغرق هذا `O(V)` وقتًا.
  - **الأفضل لـ**: مفيد للرسوم الكثيفة التي تحتوي على العديد من الحواف. غير فعال للرسوم المتفرقة التي تحتوي على عدد قليل من الحواف.

## خوارزمية أقصر مسار

- **خوارزمية أقصر مسار**: تحسب أقصر مسار بين العقد في رسم موزون وتُرجع كلًا من المسافات والمسارات المتبعة.
  - **المصفوفة المجاورة**: تمثل كل قيمة وزن (مسافة) الحافة بين عقدتين.
  - **الحواف المفقودة**: تعني القيمة `INF` (`Infinity`) عدم وجود حافة مباشرة.
  - **المسافات**: مصفوفة تتعقب أقصر مسافة معروفة من العقدة البداية إلى كل عقدة أخرى. في البداية، تُفترض كل العقد بعيدة إلى ما لا نهاية، والمسافة من العقدة البداية إلى نفسها دائمًا `0`.
  - **المسارات**: قائمة حيث كل إدخال هو مصفوفة من فهارس العقد تمثل المسار المتبع للوصول إلى كل عقدة.
  - **المزارة**: مصفوفة تتعقب العقد التي تمت معالجتها بالفعل حتى لا تُعاد زيارتها.
  - **أقرب عقدة غير مزارة**: الحلقة الرئيسية تعمل مرة واحدة لكل عقدة في الرسم، مختارةً أقرب عقدة غير مزارة في كل مرة.
  - **استرخاء الحافة**: لكل جار له حافة فعلية ولم يُزر بعد، تحقق إذا كان يمكن الوصول إليه بكفاءة أكبر عبر العقدة الحالية. إذا كانت المسافة الجديدة أفضل من المخزنة، حدّث المسافة والمسار.
  - **العقد غير القابلة للوصول**: عندما لا يُعثر على عقدة صالحة، تصبح كل العقد المتبقية غير قابلة للوصول، فتتوقف الحلقة مبكرًا.
  - **الهدف الاختياري**: معلمة `targetNode` اختيارية. عند عدم توفيرها، تحسب الدالة أقصر المسارات من `startNode` إلى كل العقد الأخرى في الرسم.

## الأشجار

الشجرة نوع خاص من الرسوم البيانية التي لا تحتوي على دورات ومتصلة. الخصائص الرئيسية تشمل:

- **لا دورية**: الشجرة لا تحتوي على حلقات أو دورات (مسارات يبدأ وينتهي عند نفس العقدة).
- **متصلة**: يمكن الوصول إلى كل عقدة من كل عقدة أخرى.

### مصطلحات الشجرة

- **عقدة الجذر**: أعلى نقطة في الشجرة. هي العقدة الوحيدة في الشجرة التي لا تملك عقدة أصل.
- **عقدة الأصل**: عقدة متصلة مباشرة بعقد أخرى تحتها.
- **عقدة فرعية**: عقدة متصلة مباشرة بعقدة فوقها.
- **ورقة**: عقدة لا تملك عقدًا فرعية.
- **العمق**: طول المسار من الجذر إلى تلك العقدة.
- **الارتفاع**: طول المسار من تلك العقدة نزولًا إلى ورقة. ارتفاع الشجرة هو ارتفاع عقدة الجذر.
- **الدرجة**: عدد العقد الفرعية لكل عقدة.
- **شجرة فرعية**: قسم من الشجرة هو شجرة بحد ذاته.
- **شجرة متوازنة**: شجرة يكون فيها ارتفاع الأشجار الفرعية اليسرى واليمنى لأي عقدة متقاربًا جدًا لضمان كفاءة العمليات.

### الأنواع الشائعة من الأشجار

الأنواع الأكثر شيوعًا من الأشجار هي:

- **الأشجار الثنائية**: كل عقدة لها طفلان كحد أقصى، طفل أيسر وطفل أيمن.

- **شجرة البحث الثنائي (BST)**: شجرة ثنائية حيث لكل عقدة، كل القيم في الشجرة الفرعية اليسرى أقل من قيمة العقدة، وكل القيم في الشجرة الفرعية اليمنى أكبر من قيمة العقدة. يجب أن تكون الأشجار الفرعية اليسرى واليمنى أيضًا أشجار بحث ثنائية.

- **الأشجار ذات التوازن الذاتي**: أشجار تحتوي على منطق داخلي إضافي يعيد توازن الشجرة عند الإدخالات أو الحذف التي تخلق حالة اختلال توازن. أمثلة شائعة تشمل أشجار AVL، أشجار الأحمر-الأسود، وأشجار B.

- **أشجار AVL**: نوع من أشجار البحث الثنائية ذات التوازن الذاتي حيث يختلف ارتفاع الأشجار الفرعية اليسرى واليمنى لأي عقدة بحد أقصى واحد.

- **أشجار الأحمر-الأسود**: نوع من أشجار البحث الثنائية ذات التوازن الذاتي حيث تُلوَّن كل عقدة باللون الأحمر أو الأسود.

- **أشجار B**: نوع من الأشجار ذات التوازن الذاتي حيث يمكن لكل عقدة أن تحتوي على مفاتيح متعددة وأكثر من طفلين.

## شجرة Trie

- **شجرة Trie**: تُعرف أيضًا بأشجار البادئة، تُستخدم لتخزين مجموعات من السلاسل النصية، حيث تمثل كل عقدة حرفًا.
- **عقدة الجذر**: لا تمثل أي حرف معين، لذا يمكن اعتبارها تمثل سلسلة فارغة.
- **البادئات**: أثناء التنقل في الشجرة من الجذر، يحدد المسار إلى عقدة بادئة معينة.
- **علامات نهاية الكلمة**: تُعيَّن علامات نهاية الكلمة للعقد التي تمثل كلمات كاملة.
- **البادئات المشتركة**: عندما تشترك عدة سلاسل في نفس البادئة، تتداخل مساراتها، لذا تُخزن البادئة مرة واحدة فقط. هذا يجعل شجرة Trie فعالة لمهام مثل الإكمال التلقائي وتصحيح الإملاء.
- **الإدخال**: يتطلب فقط إنشاء عقد جديدة للأحرف التي لا توجد بعد في الشجرة.
- **تعقيد الوقت**: تستغرق عمليات البحث والإدخال وقتًا `O(L)`، حيث `L` طول السلسلة.
- **الذاكرة**: قد تكون شجرة Trie غير فعالة إذا كان مجموعة السلاسل تحتوي على العديد من الأحرف الفريدة، لأن ذلك يتطلب تخزين العديد من الأحرف الفريدة كعقد منفصلة.

## طوابير الأولوية

- **طابور الأولوية**: نوع بيانات مجرد حيث لكل عنصر أولوية.
- **الطوابير والمكدسات**: الطوابير والمكدسات تأخذ بعين الاعتبار فقط ترتيب الإدخال، بينما طوابير الأولوية تأخذ بعين الاعتبار أولوية العناصر. الطوابير العادية تتبع FIFO (أول الداخلين أول الخارجين) والمكدسات تتبع LIFO (آخر الداخلين أول الخارجين).
- **ترتيب الإزالة**: عادةً يُزال العنصر ذو الأولوية الأعلى أولًا، لكن بعض التنفيذات قد تختار إزالة العنصر ذو الأولوية الأقل أولًا.
- **التعادل**: إذا كنت تحتاج إلى إزالة العناصر ذات الأولوية نفسها حسب ترتيب إدخالها، يمكنك تضمين عداد فريد لكسر التعادل.
- **التطبيقات**: إيجاد أقصر مسار بين موقعين، جدولة المهام في أنظمة التشغيل، محاكاة المرور، ضغط البيانات، وإدارة الشبكات.

## الحزم

الحزمة هي هيكل بيانات شجري متخصص له خاصية محددة جدًا تُسمى خاصية الحزمة.

تحدد خاصية الحزمة العلاقة بين عقدة الأصل والعقد الفرعية. هناك نوعان من الحزم:

- **الحزمة العظمى (Max-Heap)**: قيمة كل عقدة أصل أكبر من أو تساوي قيم أبنائها، وأكبر عنصر يكون في الجذر.

- **الحزمة الصغرى (Min-Heap)**: قيمة كل عقدة أصل أقل من أو تساوي قيم أبنائها، وأصغر عنصر يكون في الجذر.

لا يحتوي JavaScript على وحدة حزمة مدمجة، لكن يمكنك تنفيذ حزمة صغرى باستخدام مصفوفة.

- **تخزين كمصفوفة**: عادةً ما تُنفذ الحزم كمصفوفات للوصول بكفاءة إلى العقد الأصلية والفرعية. إذا حافظت الحزمة على هيكل شجرة ثنائية كاملة، فإن تنفيذ المصفوفة يتطلب عمليات حسابية بسيطة تعتمد على الفهارس لتحديد موقع العناصر.
- **الفهارس**: للعقدة عند الفهرس `i`، العقدة الأصل عند الفهرس `Math.floor((i - 1) / 2)`, الطفل الأيسر عند الفهرس `2 * i + 1`، والطفل الأيمن عند الفهرس `2 * i + 2`.
- **التفقد**: الحصول على القيمة الصغرى أو العظمى (حسب نوع الحزمة) دون إزالتها.
- **الإضافة**: يضيف عنصرًا في المكان المناسب للحفاظ على خاصية الحزمة. يُضاف العنصر الجديد في نهاية المصفوفة ثم يتحرك لأعلى، متبادلًا الأماكن مع أصله، حتى تُحفظ خاصية الحزمة (الانتفاخ لأعلى).
- **الإزالة**: يزيل العنصر ذو الأولوية الأعلى (في هذه الحالة، القيمة الأصغر). يحل العنصر الأخير في المصفوفة محل الجذر ثم يتحرك لأسفل، متبادلًا الأماكن مع أصغر طفل له، حتى تُحفظ خاصية الحزمة (الانتفاخ لأسفل).
- **الإضافة والإزالة معًا**: يجمع بين العمليتين في استدعاء واحد. هذا أكثر كفاءة من استدعائهما بشكل منفصل، خاصةً عندما تكون الحزمة كبيرة، لأنه ينفذ عملية إعادة ترتيب واحدة فقط.
- **التحويل إلى حزمة (Heapify)**: يحول مصفوفة موجودة إلى حزمة.
- **دالة المقارنة**: لا تُقارن المصفوفات تلقائيًا عنصرًا عنصرًا للترتيب في JavaScript، لذا تمرر دالة مقارنة إلى الحزمة تقارن الأولويات أولًا، مثل `new MinHeap((a, b) => a[0] - b[0])` للعناصر المخزنة كـ `[priority, element]`. القيم الأقل تمثل أولويات أعلى.
- **كسر التعادل المستقر**: تضمين عداد إدخال متزايد كالعنصر الثاني لكل عنصر، مثل: `[priority, counter, element]`. تقارن الأولويات أولًا ثم العدادات عند تساوي الأولويات: `new MinHeap((a, b) => (a[0] - b[0]) || (a[1] - b[1]))`.
- **تعقيد الوقت**: الإدخال والاستخراج للقيمة الصغرى أو العظمى هو `O(log n)`, التفقد هو `O(1)`, التحويل إلى حزمة هو `O(n)`, والبحث أو الحذف لعناصر عشوائية هو `O(n)`.
- **تعقيد المساحة**: `O(n)`, حيث `n` عدد العناصر التي تحتويها الحزمة.

## مقدمة في البرمجة الديناميكية

- **التعريف**: البرمجة الديناميكية هي تقنية خوارزمية تحل المشكلات المعقدة بتقسيمها إلى مشكلات فرعية أبسط وتخزين النتائج لتجنب الحسابات المتكررة.
- **المشكلات الفرعية المتداخلة**: تظهر نفس المشكلات الفرعية الصغيرة عدة مرات عند حل المشكلة الأكبر. بدلاً من إعادة حساب هذه المشكلات الفرعية مرارًا، نخزن حلولها.
- **البنية المثلى الفرعية**: الحل الأمثل للمشكلة يحتوي على حلول مثلى لمشكلاتها الفرعية. هذا يعني أنه يمكننا بناء أفضل حل من خلال دمج أفضل الحلول للأجزاء الأصغر.

## حلول البرمجة الديناميكية

- **التخزين المؤقت (النهج من الأعلى إلى الأسفل)**: يخزن التخزين المؤقت نتائج استدعاءات الدوال المكلفة ويعيد النتيجة المخزنة عند تكرار نفس المُدخلات.

- **الجدولة (النهج من الأسفل إلى الأعلى)**: يبني الحل من القاعدة إلى الأعلى، مع ملء جدول بحلول المشكلات الفرعية.

## تطبيقات العالم الحقيقي باستخدام البرمجة الديناميكية

- **تحسين المسارات**: تستخدم أنظمة GPS خوارزميات البرمجة الديناميكية لإيجاد أقصر المسارات بين المواقع.
- **معالجة النصوص**: تعتمد أدوات التدقيق الإملائي والإكمال التلقائي غالبًا على البرمجة الديناميكية لحساب مسافات التحرير بين الكلمات.
- **النمذجة المالية**: تستخدم استراتيجيات الاستثمار وتحسين المحافظ تقنيات البرمجة الديناميكية بشكل متكرر.
- **تخصيص الموارد**: تظهر مشكلة حقيبة الظهر ومتغيراتها في الجدولة والميزانية وإدارة الموارد.

## متى تستخدم البرمجة الديناميكية

يجب أن تفكر في استخدام البرمجة الديناميكية في السيناريوهات التالية:

- يمكن تقسيم المشكلة إلى مشكلات فرعية متداخلة.
- تظهر المشكلة بنية مثلى فرعية.
- الحل التكراري البسيط يتضمن حسابات متكررة.
- تحتاج إلى تحسين تعقيد الوقت على حساب تعقيد المساحة.

## الدوال النقية مقابل الدوال غير النقية

- الدالة النقية هي التي تنتج دائمًا نفس المخرجات لنفس المدخلات ولا تسبب أي تأثيرات جانبية. مخرجاتها تعتمد فقط على مدخلاتها، ولا تعدل أي حالة خارجية.
- الدوال غير النقية لها تأثيرات جانبية، وهي تغييرات في حالة البرنامج يمكن ملاحظتها خارج الدالة.

## البرمجة الوظيفية

- البرمجة الوظيفية هي نهج في تطوير البرمجيات يركز على استخدام الدوال لحل المشكلات، مع التركيز على ما يجب فعله بدلاً من كيفية فعله.
- تشجع البرمجة الوظيفية على استخدام تقنيات تساعد في تجنب التأثيرات الجانبية، مثل استخدام هياكل البيانات غير القابلة للتغيير والدوال ذات الرتبة العليا.
- عند استخدامها بشكل صحيح، تؤدي مبادئ البرمجة الوظيفية إلى كود أنظف وأسهل في الصيانة

## التطبيق الجزئي (Currying)

- التطبيق الجزئي هو تقنية في البرمجة الوظيفية تحول دالة ذات معلمات متعددة إلى سلسلة من الدوال، كل منها يأخذ معلمة واحدة.

على سبيل المثال، يحول التطبيق الجزئي استدعاء مثل `average(a, b, c)` إلى استدعاءات متتالية مثل `curriedAverage(a)(b)(c)`.

- التطبيق الجزئي يكون قويًا بشكل خاص عند العمل مع دوال تأخذ العديد من المعلمات.
- يجعل التطبيق الجزئي كودك أكثر مرونة وأسهل في إعادة الاستخدام.
- يمكنك استخدام الدوال السهمية لإنشاء دوال مطبقة جزئيًا بشكل أكثر إيجازًا:

```js
const curriedAverage = a => b => c => (a + b + c) / 3;
```

- رغم أن التطبيق الجزئي يمكن أن يؤدي إلى كود أكثر مرونة وقابلية لإعادة الاستخدام، إلا أنه قد يجعل الكود أصعب في القراءة إذا أُفرط في استخدامه.

- **جافاسكريبت المتزامنة** تُنفذ بشكل تسلسلي وتنتظر انتهاء العملية السابقة قبل الانتقال إلى التالية.
- **جافاسكريبت غير المتزامنة** تسمح بتنفيذ عمليات متعددة في الخلفية دون حظر الخيط الرئيسي.
- **الخيط (Thread)** هو تسلسل تعليمات يمكن تنفيذه بشكل مستقل عن تدفق البرنامج الرئيسي.
- **دوال الاستدعاء الراجع (Callback functions)** هي دوال تُمرر كمعلمات إلى دوال أخرى وتُنفذ بعد إتمام العملية أو نتيجة حدث.

## محرك جافاسكريبت وبيئة التشغيل

- **محرك جافاسكريبت** هو برنامج ينفذ كود جافاسكريبت في متصفح الويب. يعمل كمحول يأخذ الكود الخاص بك، ويحوّله إلى تعليمات يمكن للكمبيوتر فهمها والعمل بناءً عليها.
- V8 هو مثال على محرك جافاسكريبت طورته شركة Google.
- **بيئة تشغيل جافاسكريبت** هي البيئة التي يُنفذ فيها كود جافاسكريبت. تشمل محرك جافاسكريبت الذي يعالج وينفذ الكود، وميزات إضافية مثل متصفح الويب أو Node.js.

## واجهة Fetch API

- تتيح واجهة Fetch API لتطبيقات الويب إجراء طلبات شبكة، عادةً لاسترجاع أو إرسال بيانات إلى الخادم. توفر دالة `fetch()` التي يمكنك استخدامها لإجراء هذه الطلبات.
- يمكنك استرجاع نصوص، صور، صوت، JSON، وأنواع أخرى من البيانات باستخدام Fetch API.

## طرق HTTP لواجهة Fetch API

تدعم Fetch API عدة طرق HTTP للتفاعل مع الخادم. الطرق الأكثر شيوعًا هي:

- **GET**: تُستخدم لاسترجاع البيانات من الخادم. افتراضيًا، تستخدم Fetch API طريقة `GET` لاسترجاع البيانات.

لاستخدام البيانات المسترجعة، يجب تحويلها إلى صيغة JSON باستخدام دالة `.json()`:

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
```

في هذا الكود، تُرجع الدالة `fetch()` وعدًا، ويحوّل معالِج `.then()` الاستجابة المحققة إلى صيغة JSON.

- **POST**: تُستخدم لإرسال بيانات إلى الخادم. تُستخدم طريقة `POST` لإنشاء موارد جديدة على الخادم.

```js
fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Doe',
    email: 'john@example.com'
  })
})
```

في هذا المثال، نرسل طلب `POST` لإنشاء مستخدم جديد. حددنا الطريقة كـ `POST`، وضبطنا الرؤوس المناسبة، وضمنّا جسم الطلب بالبيانات التي نريد إرسالها. يجب أن يكون الجسم نصًا، لذا نستخدم `JSON.stringify()` لتحويل كائننا إلى سلسلة JSON.

- **PUT**: تُستخدم لتحديث البيانات على الخادم. تُستخدم طريقة `PUT` لتحديث الموارد الموجودة على الخادم.

للتحديث، حدد `method: 'PUT'` وضمّن البيانات المحدثة في جسم الطلب. يحدد عنوان URL المورد الذي سيتم تحديثه.

- **DELETE**: تُستخدم لحذف البيانات على الخادم. تُستخدم طريقة `DELETE` لحذف الموارد على الخادم.

حدد `method: 'DELETE'` واستخدم عنوان URL الذي يحدد المورد الذي تريد حذفه.

## الوعود (Promise) وتسلسل الوعود

- **الوعود** هي كائنات تمثل إتمام أو فشل عملية غير متزامنة وقيمتها الناتجة. تُعرف قيمة الوعد فقط عند إتمام العملية غير المتزامنة.
- إليك مثال لإنشاء وعد بسيط:

```js
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```

- تُستخدم طريقة `.then()` في الوعد لتحديد ما يجب أن يحدث عند الوفاء بالوعد، بينما تُستخدم `.catch()` لمعالجة أي أخطاء تحدث.

- **تسلسل الوعود**: من الميزات القوية للوعود أنه يمكننا ربط عدة عمليات غير متزامنة معًا. يمكن لكل `.then()` أن يعيد وعدًا جديدًا، مما يسمح لك بأداء سلسلة من العمليات غير المتزامنة واحدة تلو الأخرى.

طريقة `catch` تتولى معالجة أي أخطاء تحدث أثناء العملية. هذا يعني أنك لا تحتاج إلى إضافة معالجة الأخطاء لكل خطوة، مما يبسط كودك كثيرًا.

## استخدام `async/await` للتعامل مع الوعود

`async`/`await` يجعل كتابة وقراءة الكود غير المتزامن أسهل، وهو مبني على أساس الوعود.

- **async**: تُستخدم الكلمة المفتاحية `async` لتعريف دالة غير متزامنة. تُرجع الدالة `async` وعدًا (Promise) يُحلّ بالقيمة التي تُرجعها الدالة `async`.
- **await**: تُستخدم الكلمة المفتاحية `await` داخل دالة `async` لإيقاف تنفيذ الدالة مؤقتًا حتى يُحل الوعد. يمكن استخدامها فقط داخل دالة `async`.

- من أكبر مزايا `async/await` هو التعامل مع الأخطاء عبر كتل `try/catch`. إليك مثالًا:

```js
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

fetchData();
```

في المثال أعلاه، يحتوي كتلة `try` على الكود الذي قد يرجع خطأ، وكتلة `catch` تتولى معالجة الخطأ إذا حدث. هذا يجعل معالجة الأخطاء أكثر وضوحًا وسهولة في القراءة.

## الخاصية `async`

- تخبر الخاصية `async` المتصفح بتحميل ملف السكريبت بشكل غير متزامن مع استمرار تحليل مستند HTML.
- بمجرد تحميل السكريبت، يتوقف تحليل HTML، يُنفذ السكريبت، ثم يستأنف تحليل HTML.
- يجب استخدام `async` للسكريبتات المستقلة التي لا يهم ترتيب تنفيذها.

## الخاصية `defer`

- تقوم الخاصية `defer` أيضًا بتحميل السكريبت بشكل غير متزامن، لكنها تؤجل تنفيذ السكريبت حتى يتم تحليل مستند HTML بالكامل.
- تحافظ سكريبتات `defer` على ترتيب التنفيذ كما تظهر في مستند HTML.

- من المهم ملاحظة أن الخاصيتين `async` و `defer` يتم تجاهلهما للسكريبتات المضمّنة وتعملان فقط مع ملفات السكريبت الخارجية.

- عندما تكون الخاصيتان `async` و `defer` موجودتين معًا، تعطي الخاصية `async` الأولوية.

## واجهة برمجة تطبيقات تحديد الموقع الجغرافي

- توفر واجهة برمجة تطبيقات تحديد الموقع الجغرافي طريقة للمواقع لطلب موقع المستخدم.

- المثال أدناه يوضح طريقة `getCurrentPosition()` من الواجهة، والتي تُستخدم للحصول على الموقع الحالي للمستخدم.

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

في هذا الكود، نستدعي `getCurrentPosition` ونمرر لها دالة، ستُستدعى عند الحصول على الموقع بنجاح.

كائن `position` يحتوي على معلومات متنوعة، لكننا اخترنا هنا فقط `latitude` و `longitude`.

إذا حدثت مشكلة في الحصول على `position`، فسيتم تسجيل الخطأ في وحدة التحكم.

- من المهم احترام خصوصية المستخدم وطلب موقعه فقط عند الضرورة.
