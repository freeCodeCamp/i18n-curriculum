# --description--

Метод `__repr__` — це спеціальний метод, який має повертати рядкове представлення об’єкта, що може бути використане для його створення.

Наприклад, метод `__repr__` класу `Employee('Charlie', 'developer')` має повертати рядок `Employee('Charlie', 'developer')`, який є тим самим рядком, що використовується для створення об’єкта.

Якщо у вас є лапки навколо кожного значення, результат ламається, коли значення містить лапку. Для працівника на ім’я `O'Reilly` з рівнем `junior` ви отримаєте `Employee('O'Reilly', 'junior')`, що є недійсним, бо апостроф рано закриває рядок.

Вбудована функція Python `repr()` повертає рядкове представлення значення. Для рядків вона додає лапки та виконує екранування будь-яких символів, які цього потребують:

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

Усередині f-рядка ви можете додати `!r` після виразу, щоб застосувати до нього `repr()`:

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

Додайте вашому класу `Employee` метод `__repr__` з параметром `self`. Нехай він повертає рядок, який можна використати для створення об’єкта, застосовуючи `!r` до `self.name` і `self.level`, щоб зберегти будь-які лапки або зворотні скісні риски.
