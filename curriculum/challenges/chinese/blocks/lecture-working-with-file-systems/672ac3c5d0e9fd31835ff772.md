## 在 Windows 上使用文件资源管理器

要在 Windows 上使用资源管理器创建 file，你可以点击左上角的 "New" 选项。这样会显示你可以创建的不同类型的 file 列表。

![Windows 文件资源管理器，左上角用橙色框和箭头突出显示“新建”按钮，freeCodeCamp 文件夹中选中了新建文本文件。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-1.png)

你也可以在对应的应用程序中创建文件。

![Windows 文件资源管理器显示 Documents 里的 freeCodeCamp 文件夹，选中了新建文本文件。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-2.png)

让我们创建一个文本文件来演示这个过程。

当你点击 "New" 并选择文件类型时，你将在当前文件夹中看到一个默认名称的新文本文件。你可以根据需要重命名它。

![一个文本文件图标，文件名为 demo。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-3.png)

创建文件夹的过程完全相同。点击左上角的 "New" 按钮，然后选择 "Folder" 选项，或者右键点击空白处，进入 "New"，然后选择 "Folder" 选项。你将在当前位置看到一个新的空文件夹。

![Windows 文件资源管理器显示 freeCodeCamp 文件夹中新建的名为“新建文件夹”的文件夹。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-4.png)

### 重命名文件和文件夹

![Windows 文件资源管理器工具栏，重命名按钮显示为字母 A 和文本光标，用绿色框突出显示。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-5.png)

你可以通过选择文件或文件夹，然后点击顶部的“重命名”选项来重命名它们。当文件当前名称被高亮时，你可以开始输入新的文件名。按 <kbd>Enter</kbd> 确认更改。

或者，你可以右键点击文件或文件夹，选择“重命名”选项，或者使用 <kbd>F2</kbd> 键盘快捷键。输入新名称后按 <kbd>Enter</kbd> 确认更改。

### 移动文件和文件夹

如果你已将目标文件夹作为标签（页）打开，可以通过拖放将文件或文件夹移动到另一个文件夹中。

你也可以选择 file 或 folder，然后选择顶部的 "Cut" 选项。

![Windows 文件资源管理器工具栏，剪切按钮显示为剪刀，用绿色框突出显示。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-6.png)

然后，转到目标文件夹，点击顶部的 "Paste" 按钮进行粘贴。如果你之前复制或剪切了该文件，该按钮将被启用。

![Windows 文件资源管理器工具栏，粘贴按钮显示为剪贴板，用绿色框突出显示。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-7.png)

你也可以通过右键点击空白处，然后点击粘贴图标来完成此操作。这将从其原始位置移除该文件或文件夹。

### 删除文件和文件夹

要删除文件或文件夹，点击它然后点击顶部的垃圾桶图标。

![Windows 文件资源管理器工具栏，删除按钮显示为垃圾桶，用绿色框突出显示。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-8.png)

如果你右键点击它，也会看到“删除”选项。

## 在 macOS 上使用 Finder

太好了。现在让我们看看你如何在 macOS 上使用 Finder 来做到这一点。

Finder 是 macOS 上的默认文件管理器。

### 创建文件

要在 macOS 上创建文件，你需要打开一个允许你创建所需类型文档的应用。目前，Finder 中没有内置方法可以直接创建文件。

例如，要创建一个简单的纯文本文件，你可以打开 TextEdit 并储存你的文件。该进程对任何类型的文件都完全相同。

打开 TextEdit 有很多方法，其中之一是进入 Launchpad。

![macOS Launchpad 图标，一个包含彩色应用图块网格的圆角方块。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-9.png)

然后，搜索你想创建的文件类型对应的应用程序。在这里是“TextEdit”。点击图标打开应用。

![Launchpad 搜索栏中输入 TextEdit，下面显示 TextEdit 应用图标。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-10.png)

进入应用后，你应该能在 File 菜单中看到储存你的文件的选项。该菜单位于左上角，紧挨着 Apple 菜单图标。

![TextEdit 打开一个空白文档。绿色箭头指向 macOS 菜单栏，显示 TextEdit、文件、编辑、格式、视图、窗口和帮助。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-11.png)

在某个 App 菜单选项中，你应该看到一个用于储存文件的命令。这通常位于 File 菜单下。

![macOS 菜单栏特写，显示苹果标志，然后是 TextEdit、文件、编辑、格式、视图、窗口和帮助。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-12.png)

旁边你会看到保存文件的键盘快捷键。在 macOS 上通常是 <kbd>Command</kbd> + <kbd>S</kbd>。

![TextEdit 文件菜单打开，保存选项高亮，右侧显示其 Command + S 快捷键。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-13.png)

当你第一次保存 file 时，你应该会看到一个对话窗口，在那里你可以输入 file 的名称并选择位置。

通常，文件扩展名由应用自动添加，但你可以在保存文件之前更改它。

![TextEdit 保存对话框，保存为字段中显示 Untitled.txt，有文件夹浏览器，底部有取消和保存按钮。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-14.png)

保存文件后，你可以点击 Dock 中的 Finder 图标打开 Finder。

![macOS Dock 中的 Finder 图标，一个蓝白相间的笑脸。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-15.png)

你应该能在保存的位置看到新文件。

![Finder 窗口显示 freeCodeCamp 文件夹，里面有一个文件 demo.txt。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-16.png)

### 创建文件夹

要创建一个新文件夹，你应该前往想要创建该新文件夹的位置，然后右键点击空白处。你会看到一个选项列表。第一个选项是 "New Folder"。

![Finder 在空白区域打开的上下文菜单，顶部高亮显示新建文件夹。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-17.png)

如果你点击它，可以为你的新文件夹赋名。输入名称后按 <kbd>Enter</kbd> 确认。

![一个新的 Finder 文件夹，名为 untitled folder，名称处于编辑状态。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-18.png)

![同一个文件夹重命名为 freeCodeCamp。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-19.png)

### 移动文件和文件夹

在 Finder 中有多种方法可以移动文件和文件夹。如果你需要将它们移动到 Finder “Favorites” 部分列出的文件夹，只需拖放即可。

![Finder 窗口中，demo.txt 被拖动到收藏夹侧边栏的 Documents 上，绿色箭头指示。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-20.png)

如果你需要将它移动到不同的文件夹，你有两个选项。

你可以将目标文件夹作为标签（页）打开，然后将文件或文件夹拖放到该标签（页）中。

或者你可以使用键盘快捷键。首先用 <kbd>Command</kbd> + <kbd>C</kbd> 复制文件，进入新文件夹，然后使用 <kbd>Command</kbd> + <kbd>Option</kbd> + <kbd>V</kbd> 将文件或文件夹粘贴到该位置。这也会将它从原始文件夹中移除。

### 删除文件和文件夹

要删除一个文件或文件夹，你可以右键点击它并选择 "Move to trash"。

![demo.txt 的 Finder 上下文菜单，移动到废纸篓选项高亮。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-21.png)

![freeCodeCamp 文件夹的 Finder 上下文菜单，移动到废纸篓选项高亮。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-22.png)

你也可以将它们拖放到 Dock 上的垃圾图标中。这是等效的。

![macOS Dock 中的废纸篓图标，里面装满了揉皱的纸。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-23.png)

当 file 或 folder 在回收站中时，你可以右键点击它立即删除，或者你可以清空回收站以永久删除所有已删除的文件和文件夹。

![Finder 废纸篓窗口，demo.txt 的上下文菜单打开，列出打开、用…打开、放回、立即删除和清空废纸篓。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-24.png)
