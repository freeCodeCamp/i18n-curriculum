# --description--

- **再帰**: 関数が自分自身を呼び出す手法です。各呼び出しは元の問題のより小さなバージョンで動作し、さらなる再帰呼び出しを停止する底辺のケースに到達するまで続きます。
- **底辺のケース**: 再帰を停止させる条件です。底辺のケースは慎重に定義する必要があります。そうしないと、関数は自分自身を呼び出し続け、Pythonが`RecursionError`を発生させます。
- **再帰ケース**: 関数が再び自分自身を呼び出す部分で、底辺のケースに近づく引数（例えばカウントダウン時の`number - 1`）を使います。

```py
def recursive_countdown(number):
    if number < 1:  # Base case
        return
    print(number)
    recursive_countdown(number - 1)  # Recursive case

recursive_countdown(5)  # Prints 5, 4, 3, 2, 1
```

- **実行順序**: 再帰呼び出しの位置によって関数内の他のコードの実行タイミングが変わります。再帰呼び出しの前に置かれたコードは呼び出しが深くなるにつれて実行され、後に置かれたコードは呼び出しが戻るときに実行されます。`print()`を再帰呼び出しの後に移動すると、関数は数字を昇順で出力します:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)  # Prints 1, 2, 3, 4, 5
```

- **コールスタック**: Pythonがアクティブな関数呼び出しを管理するために使う後入れ先出しのデータ構造です。関数が呼び出されるたびに、その呼び出しのフレームがスタックの一番上に追加されます。フレームには関数の引数やローカル変数などの情報が含まれます。
- **呼び出しの再開**: 関数は再帰呼び出しを行うと一時停止します。底辺のケースが返されると、Pythonはその呼び出しをスタックの一番上から取り除き、以前の呼び出しが再帰呼び出しの後に再開され、後入れ先出しの順で戻ります:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

出力は次の通りです。

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

- **リストを再帰的に作成する**: 各呼び出しは再帰呼び出しが返ると再開し、その返された値を使います。以下の`countup`関数は底辺のケースで空のリストを返します。他の呼び出しは再帰呼び出しからリストを受け取り、自分の数字を追加してリストを返します:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(5))  # [1, 2, 3, 4, 5]
```

`1`の呼び出しは`[]`を受け取り`[1]`を返し、`2`の呼び出しは`[1]`を受け取り`[1, 2]`を返し、同様に`5`の呼び出しが`[1, 2, 3, 4, 5]`を返すまで続きます。

- **再帰の応用**: 再帰はカウントダウン、カウントアップ、リスト作成などの単純なタスクに対応できます。また、ファイルツリーの走査のように深さが未知の問題にも役立ちます。
