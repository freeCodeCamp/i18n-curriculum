# --description--

関数は別の関数を呼び出して、その戻り値を使うことができます。例えば：

```py
def calculate_sum(a, b):
    return a + b

def show_total(a, b):
    total = calculate_sum(a, b)
    print(total)

show_total(3, 4) # 7
```

ここでは、`show_total` が `calculate_sum` を呼び出し、その戻り値をローカル変数 `total` に代入し、出力しています。

次に、卵が利用可能かどうかを確認し、`use_eggs` を呼び出して使う関数を作成します。`print(available_eggs)` の文の下に、`available_eggs` を唯一のパラメータに持つ空の関数 `make_fried_egg` を定義してください。

関数の本体には今のところ `pass` キーワードを使ってください。

def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        print('The kitchen does not have enough eggs.')
        return available_eggs

    print(f'{eggs_to_use} egg(s) used out of {available_eggs} available.')
    return available_eggs - eggs_to_use

use_eggs(available_eggs, 1)
