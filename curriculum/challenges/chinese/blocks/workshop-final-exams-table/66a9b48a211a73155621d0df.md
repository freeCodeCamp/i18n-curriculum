# --description--

在本工作坊，你将通过为一组学生制作期末考试表格来练习使用 HTML 表格。

`table` 元素让你可以显示表格数据。表格数据是按行和列组织的信息，就像电子表格一样。

在你的 `body` 元素内嵌套一个 `table` 元素。在接下来的步骤中，你将为你的表格添加行、标题和数据。

# --hints--

你应该有一个 `table` 开始标签。

```js
assert.match(code, /<table>/i);
```

你应该有一个 `table` 结束标签。

```js
assert.match(code, /<\/table>/i);
```

你的 `table` 元素应该在 `body` 元素中。

```js
const tableEl = document.querySelector('table');
assert.strictEqual(tableEl?.parentElement?.tagName, 'BODY');
```
