# --description--

L'ordinamento per inserimento costruisce una porzione ordinata all'inizio della lista, un elemento alla volta. Inizia trattando il primo elemento come ordinato. Poi prende l'elemento successivo e lo sposta indietro nella porzione ordinata, spostando o scambiando ogni elemento più grande di una posizione a destra, finché non raggiunge un elemento che è minore o uguale a esso. Questo processo si ripete per ogni elemento rimanente finché tutta la lista non è ordinata.

L'ordinamento per inserimento ha complessità temporale quadratica nei casi medi e peggiori, ma funziona in tempo lineare quando la lista è già ordinata.

**Obiettivo:** Completa le storie utente qui sotto e fai passare tutti i test per completare il laboratorio.

**Storie utente:**

1. Devi definire una funzione chiamata `insertion_sort` con un parametro che rappresenta la lista di elementi.
1. La tua funzione `insertion_sort` deve ordinare la lista in loco dal più piccolo al più grande e restituirla.
1. La tua funzione `insertion_sort` deve seguire l'algoritmo di ordinamento per inserimento, inserendo ogni elemento, da sinistra a destra, nella sua posizione corretta all'interno della porzione ordinata all'inizio della lista.
1. La tua funzione `insertion_sort` deve smettere di spostare un elemento indietro non appena raggiunge un elemento che è minore o uguale a esso.
1. La tua funzione `insertion_sort` non deve usare né il metodo integrato `sort()` né la funzione `sorted()`.

**Nota:** Non devi importare moduli né usare metodi che aggiungono o rimuovono elementi dalla lista.

```py
def insertion_sort(items):
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j -= 1
        items[j + 1] = current
    return items
```
