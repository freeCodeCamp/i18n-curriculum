## Python ni nini?

- **Python**: Python ni lugha ya programu ya matumizi ya jumla inayojulikana kwa urahisi wake na matumizi rahisi.
- **Matumizi ya Kawaida**: Python hutumika katika sayansi ya data, ujifunzaji wa mashine, ukuzaji wa mtandao, usalama wa mtandao, mifumo iliyojengwa ndani na IoT, uandishi wa skripti, otomatiki, na kompyuta ndogo kama Raspberry Pi na bodi zinazolingana na MicroPython.

## Vigezo

- **Kutangaza Vigezo**: Ili kutangaza kigezo, anza na jina la kigezo likifuatiwa na opereta ya mgawo (`=`) kisha thamani. Hii inaweza kuwa nambari, mfuatano wa herufi, thamani ya kweli au siyo kweli, n.k. Hapa kuna mifano:

```py
name = 'John Doe'
age = 25
```

- **Mikataba ya Kuitwa kwa Vigezo**: Hapa ni mikataba unayopaswa kutumia kwa vigezo:

  - Majina ya vigezo yanaweza kuanza tu na herufi au mstari chini (`_`), si nambari.
  - Majina ya vigezo yanaweza kuwa na herufi (`a-z`, `A-Z`), nambari (`0-9`), na mistari chini (`_`).
  - Majina ya vigezo yanazingatia herufi kubwa na ndogo: `age`, `Age`, na `AGE` yote yanachukuliwa kuwa tofauti.
  - Majina ya vigezo hayawezi kuwa maneno muhimu yaliyohifadhiwa ya Python kama `if`, `class`, au `def`.
  - Majina ya vigezo yenye maneno mengi hutumia mistari chini, kama `snake_case`.
  - Majina ya vigezo yanapaswa kuelezea kusudi lao, kama `user_age`.
  - Epuka kutumia majina ya vigezo ya herufi moja ikiwa hayawasilishi maana.

## Maoni

- **Maoni ya mstari mmoja**: Aina hii ya maoni inapaswa kutumika kwa maelezo mafupi katika msimbo wako.

```py
# This is a single line comment
```

- **Maoni ya mistari mingi**: Unaweza kutumia `#` mwanzoni mwa kila mstari kuunda maoni yanayogusa mistari mingi.

```py
# This is a multi-line comment.
# Here is some code commented out.
#
# name = 'John Doe'
# age = 25
```

## Kuchapisha

- **Kitendakazi cha `print()`**: Ili kuchapisha data kwenye terminali, unaweza kutumia kitendakazi cha `print()` kama ifuatavyo:

```py
print('Hello world!') # Hello world!
```

Unaweza kupitisha hoja nyingi kwa `print()` kwa kuzitenganisha kwa koma. Kwa chaguo-msingi, `print()` huingiza nafasi kati ya thamani zao zinazoonyeshwa:

```py
print('Hello', 'world!') # Hello world!
```

## Aina za Data za Kawaida katika Python

- **Uainishaji wa Mabadiliko**: Python ni lugha inayotumia aina za data zinazobadilika, maana yake huna haja ya kutangaza aina ya data ya kigezo. Python huamua aina kutoka kwa thamani iliyopewa kigezo.

- **Nambari kamili**: Nambari kamili isiyo na sehemu za desimali:

```py
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- **Nambari ya Desimali (Float)**: Nambari yenye sehemu za desimali:

```py
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- **Mfuatano wa Herufi (String)**: Mfuatano wa herufi uliowekwa ndani ya nukuu:

```py
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- **Thamani ya Kweli au Siyo Kweli (Boolean)**: Thamani inayowakilisha `True` au `False`:

```py
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python ina aina nyingine za data. Utajifunza kila moja unapoihitaji kwa mara ya kwanza.

- **Kitendakazi cha `type()`**: Ili kuona aina ya variable, unaweza kutumia kitendakazi cha `type()` kama ifuatavyo:

```py
greeting = 'Hello there!'
age = 21

print(type(greeting)) # <class 'str'>
print(type(age)) # <class 'int'>
```

- **Kitendakazi cha `isinstance()`**: Hiki hutumika kuangalia kama kigezo kinaendana na aina fulani ya data:

```py
greeting = 'Hello world'
name = 'John Doe'

print(isinstance(greeting, str)) # True
print(isinstance(name, int)) # False
```

Ili kukagua dhidi ya aina zaidi ya moja, weka aina hizo ndani ya mabano ya kawaida, zikitenganishwa kwa koma, na zipitishe kama hoja ya pili. Matokeo ni `True` ikiwa thamani ni mfano wa aina yoyote iliyoorodheshwa:

```py
account_balance = 12
print(isinstance(account_balance, (int, float))) # True
```

## Kufanya kazi na mfuatano wa herufi

- **Mfuatano wa herufi**: Mfuatano wa herufi ni mfululizo wa herufi. Katika Python, unaweza kutumia nukuu moja au nukuu maradufu. Chagua mtindo mmoja na uutumie kwa uthabiti:

```py
developer = 'Jessica'
city = "Los Angeles"
```

- **Mfuatano wa herufi wa mistari mingi**: Nukuu tatu za moja au nukuu tatu maradufu huruhusu mfuatano wa herufi kupanuka kwenye mistari mingi:

```py
message = """Hello
world!"""
print(message)
# Hello
# world!
```

- **Nukuu ndani ya mfuatano wa herufi**: Unaweza kutumia aina ya nukuu tofauti kuzunguka mfuatano wa herufi ili kuepuka kuondoa alama za nukuu zake:

```py
msg = "It's a sunny day"
quote = 'She said, "Hello!"'
```

- **Kuepuka herufi katika mfuatano**: Unaweza kutumia mkwaju wa nyuma (`\`) ikiwa mfuatano wako una nukuu kama ifuatavyo:

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **Mfuatano wa kutoroka**: Mkwaju wa nyuma ukiambatana na herufi nyingine unaweza kuwakilisha herufi maalum. Kwa mfano, `\n` inawakilisha mstari mpya, `\t` inawakilisha tabo, na `\\` inawakilisha mkwaju wa nyuma mmoja:

```py
print('Hello\nworld')
# Hello
# world

print('Name:\tAlice')  # Name:   Alice
print('C:\\Users\\Alice')  # C:\Users\Alice
```

- **Opereta ya `in`**: Hii hurudisha thamani ya kweli au siyo kweli inayoonyesha kama herufi au herufi zipo ndani ya mfuatano au la:

```py
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

- **Kupata urefu wa mfuatano wa herufi**: Kitendakazi cha `len()` hurudisha idadi ya herufi katika mfuatano wa herufi:

```py
developer = 'Jessica'

print(len(developer)) # 7
```

- **Kupata herufi kutoka kwenye mfuatano wa herufi**: Unaweza kupata herufi kutoka kwenye mfuatano kwa kutumia uandishi wa mabano kama ifuatavyo:

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **Kuweka upya thamani na kutobadilika**: Mfuatano wa herufi haubadiliki, maana yake huwezi kuubadilisha baada ya kuundwa. Kuweka upya thamani ya kigezo kunafanya kigezo kiashirie thamani tofauti. Hii haibadilishi mfuatano wa herufi wa awali:

```py
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello
```

Mabadiliko ya moja kwa moja ya mfuatano wa herufi hayaruhusiwi:

```py
greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```

Nambari kamili, nambari za desimali, na thamani za kweli au siyo kweli pia hazibadiliki.

- **Kuunganisha mfuatano wa herufi**: Ili kuunganisha mfuatano wa herufi, unaweza kutumia opereta ya `+` kama ifuatavyo:

```py
developer = 'Jessica'
print('My name is ' + developer + '.') # My name is Jessica.
```

- **Kurudia mfuatano wa herufi**: Opereta `*` hurudia mfuatano wa herufi mara idadi iliyobainishwa:

```py
print('ha' * 3) # hahaha
```

- **Kuunganisha mfuatano wa herufi na nambari**: Kuunganisha mfuatano wa herufi na nambari husababisha `TypeError`:

```py
'Age: ' + 26 # TypeError: can only concatenate str (not "int") to str
```

Kitendakazi `str()` hubadilisha nambari kuwa mfuatano wa herufi ili iweze kuunganishwa:

```py
print('Age: ' + str(26)) # Age: 26
```

Njia nyingine ya kuunganisha mfuatano ni kutumia opereta ya `+=`. Hii hutumika kufanya kuunganisha na mgawo katika hatua moja kama ifuatavyo:

```py
greeting = 'My name is '
developer = 'Jessica.'

greeting += developer
print(greeting) # My name is Jessica.
```

Opereta `*=` hurudia mfuatano wa herufi na kuweka matokeo tena kwenye kigezo:

```py
sound = 'ha'
sound *= 3
print(sound) # hahaha
```

Zote `+=` na `*=` huweka mfuatano mpya wa herufi kwenye kigezo bila kubadilisha mfuatano wa awali.

- **`f-strings`**: Hii ni kifupi cha formatted string literals. Inakuwezesha kufanya uingizaji wa thamani na pia kuunganisha kwa sintaksia fupi na inayosomeka:

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

Sehemu za kubadilisha katika f-strings zinaweza kuwa na usemi wa kihesabu. Python huhesabu usemi huo na kuingiza thamani yake ndani ya mfuatano wa herufi:

```py
num1 = 5
num2 = 10
print(f'The sum is {num1 + num2}') # The sum is 15
```

- **Kuchukua sehemu ya mfuatano wa herufi (String slicing)**: Hii ni pale unapotaka kutoa sehemu ya mfuatano. Hapa ni sintaksia ya msingi:

```py
str[start:stop:step]
```

Kielezo cha `start` kinaeleza wapi uchimbaji huanza. Kielezo cha `stop` hakijumuishi, kwa hivyo herufi iliyoko kwenye kielezo hicho haijumuishwi. `step` inaeleza kipindi kati ya viashirio vilivyochaguliwa na kwa chaguo-msingi ni `1`. Kwa `step` chanya, `start` isiyotajwa huanza mwanzoni mwa mfuatano wa herufi, na `stop` isiyotajwa huisha mwishoni. `[:]` huchimba mfuatano mzima. `[::-1]` hurudisha mfuatano wa herufi kwa kurudi nyuma kutoka herufi ya mwisho hadi ya kwanza. Uchimbaji hauibadilishi mfuatano wa herufi wa awali.

```py
message = 'Python is fun!'

print(message[0:6])  # Python
print(message[:6])  # Python
print(message[7:])  # is fun!
print(message[::2])  # Pto sfn
print(message[:])  # Python is fun!
print(message[::-1])  # !nuf si nohtyP
```

## Njia za kawaida za mfuatano wa herufi

- **Njia**: Njia ni kitendakazi unachokitumia kwenye thamani. Ili kuita njia ya mfuatano wa herufi, andika mfuatano wa herufi au jina la kigezo chake kifuatiwe na nukta na wito wa njia.

- **`str.upper()`**: Hii hurudisha mfuatano mpya wa herufi wenye herufi zote kubadilishwa kuwa herufi kubwa:

```py
developer = 'Jessica'

print(developer.upper()) # JESSICA
```

- **`str.lower()`**: Hii hurudisha mfuatano mpya wa herufi wenye herufi zote kubadilishwa kuwa herufi ndogo:

```py
developer = 'Jessica'

print(developer.lower()) # jessica
```

- **`str.strip()`**: Hii hurudisha nakala ya mfuatano wa herufi yenye kuondoa herufi za mbele na nyuma zilizobainishwa (kama hakuna hoja imetolewa, huondoa nafasi za tupu za mbele na nyuma).

```py
greeting = '  hello world  '

trimmed_my_str = greeting.strip()
print(trimmed_my_str)  # hello world
```

- **`replace()`**: Hii hurudisha mfuatano mpya ambapo matukio yote ya mfuatano wa zamani yamebadilishwa na mfuatano mpya.

```py
greeting = 'hello world'

replaced_my_str = greeting.replace('hello', 'hi')
print(replaced_my_str)  # hi world
```

- **`split()`**: Hii hutumika kugawanya mfuatano wa herufi kuwa orodha kwa kutumia kitenzi kilichobainishwa. Kitenzi ni mfuatano wa herufi unaoelezea mahali pa kugawanya. Ikiwa hakuna kitenzi kilichobainishwa, `split()` hugawanya kwa nafasi tupu.

```py
dashed_name = 'example-dashed-name'

split_words = dashed_name.split('-')
print(split_words)  # ['example', 'dashed', 'name']
```

- **`join()`**: Hii hutumika kuunganisha mkusanyiko wa mfuatano wa herufi kuwa mfuatano mmoja kwa kutumia kizuizi.

```py
example_list = ['example', 'dashed', 'name']

joined_str = ' '.join(example_list)
print(joined_str)  # example dashed name
```

- **`str.startswith(prefix)`**: Hii hurudisha thamani ya kweli au siyo kweli ikionyesha kama mfuatano wa herufi unaanza na kiambishi awali kilichobainishwa:

```py
developer = 'Naomi'

result = developer.startswith('N')
print(result)  # True
```

- **`str.endswith(suffix)`**: Hii hurudisha thamani ya kweli au siyo kweli ikionyesha kama mfuatano wa herufi unaisha na kiambishi cha mwisho kilichobainishwa:

```py
developer = 'Naomi'

result = developer.endswith('N')
print(result)  # False
```

- **`str.find()`**: Hii hurudisha kielezo cha tukio la kwanza la sehemu ndogo ya mfuatano wa herufi. Ikiwa haipatikani, basi hurudisha `-1`:

```py
developer = 'Naomi'

result = developer.find('N')
print(result)  # 0

city = 'Los Angeles'
print(city.find('New')) # -1
```

- **`str.count(substring)`**: Hii huhesabu ni mara ngapi sehemu ndogo ya mfuatano wa herufi inaonekana bila kuingiliana na sehemu nyingine. Mara tu patakapopatikana mechi, utafutaji unaendelea baada ya mwisho wa mechi hiyo:

```py
city = 'Los Angeles'
print(city.count('e')) # 2

# Matches do not overlap, so this is 2, not 3
print('aaaa'.count('aa')) # 2
```

- **`str.capitalize()`**: Hii hurudisha mfuatano mpya wa herufi wenye herufi ya kwanza kuwa kubwa na zingine kuwa ndogo:

```py
dessert = 'chocolate cake'
print(dessert.capitalize()) # Chocolate cake
```

- **`str.isupper()`**: Hii hurudisha `True` ikiwa mfuatano wa herufi una angalau herufi moja yenye hali ya herufi na herufi zote zenye hali ya herufi ni herufi kubwa. Vinginevyo, hurudisha `False`:

```py
dessert = 'chocolate cake'
print(dessert.isupper()) # False
```

- **`str.islower()`**: Hii hurudisha `True` ikiwa mfuatano wa herufi una angalau herufi moja yenye hali ya herufi na herufi zote zenye hali ya herufi ni herufi ndogo. Vinginevyo, hurudisha `False`:

```py
dessert = 'chocolate cake'
print(dessert.islower()) # True
```

- **`str.title()`**: Hii hurudisha mfuatano mpya wa herufi ambapo herufi ya kwanza ya kila neno imeandikwa kwa herufi kubwa na herufi zilizobaki kwa herufi ndogo:

```py
city = 'lOS aNGELES'
print(city.title()) # Los Angeles
```

```py
employee_code = 'DEV-2026-JD-001'
print(employee_code[-3:]) # 001
```

- **Uunganishaji wa njia**: Unaweza kuita njia nyingi za mfuatano wa herufi katika usemi mmoja. Kila njia hufanya kazi kwa matokeo ya wito uliotangulia:

```py
name = '  jANE dOE  '
print(name.strip().title()) # Jane Doe
```

## Operesheni za kawaida zinazotumika na nambari kamili na nambari za desimali

- **Mifumo ya Msingi ya Hisabati**: Katika Python, unaweza kufanya mifumo ya msingi ya hisabati kwa kutumia nambari kamili na nambari za desimali ikiwa ni pamoja na kuongeza, kutoa, kuzidisha, na kugawanya:

```py
int_1 = 56
int_2 = 12
float_1 = 5.4
float_2 = 12.0

# Addition

print('Integer Addition:', int_1 + int_2) # Integer Addition: 68
print('Float Addition:', float_1 + float_2) # Float Addition: 17.4

# Subtraction

print('Int Subtraction:', int_1 - int_2) # Int Subtraction: 44
print('Float Subtraction:',  float_2 - float_1) # Float Subtraction: 6.6

# Multiplication

print('Int Multiplication:', int_1 * int_2) # Int Multiplication: 672
print('Float Multiplication:', float_2 * float_1) # Float Multiplication: 64.80000000000001

# Division

print('Division:', int_1 / int_2) # Division: 4.666666666666667
print('Float Division:', float_2 / float_1) # Float Division: 2.222222222222222
```

Unapoongeza nambari ya desimali na nambari kamili, matokeo yatageuzwa kuwa nambari ya desimali kama ifuatavyo:

```py
int_1 = 56
float_1 = 5.4

print(int_1 + float_1) # 61.4
```

- **Opereta wa Modulo (`%`)**: Huu hurudisha mabaki wakati nambari ikigawanywa na nambari nyingine:

```py
int_1 = 56
int_2 = 12

print(int_1 % int_2) # 8
```

- **Mgawanyo wa Floor (`//`)**: Opereta hii hutumika kugawanya nambari mbili na kuzungusha matokeo hadi nambari kamili iliyo karibu zaidi:

```py
int_1 = 56
int_2 = 12

print(int_1 // int_2) # 4
```

- **Opereta wa Nguvu (`**`)**: Opereta hii hutumika kuinua nambari hadi nguvu ya nyingine:

```py
int_1 = 4
int_2 = 2

print(int_1 ** int_2) # 16
```

- **Makadirio ya nambari za desimali**: Sehemu za desimali baadhi haziwezi kuwakilishwa kwa usahihi kabisa katika binary, hivyo huhifadhiwa kama makadirio ya mwisho. Hii inaweza kusababisha makosa madogo ya mizunguko, kama matokeo ya kuzidisha `64.80000000000001` hapo juu.

```py
print(0.1 + 0.2) # 0.30000000000000004
```

- **`float()` Function**: Unaweza kutumia kitendakazi hiki kubadilisha nambari kamili au mfuatano halali wa desimali kuwa nambari ya desimali, au kuunda thamani maalum ya nambari ya desimali inayowakilisha ukomo chanya, ambayo ni kubwa kuliko nambari kamili au desimali yoyote isiyo na ukomo:

```py
num = 4

print(float(num)) # 4.0
print(float('7.8')) # 7.8
print(float('inf')) # inf
```

- **Kitendakazi cha `int()`**: Unaweza kutumia kitendakazi hiki kubadilisha nambari ya desimali kuwa nambari kamili.

```py
num = 4.0

print(int(num)) # 4
```

- **`round()` Function**: Ukiwa na hoja moja, hii hurudisha nambari iliyozungushwa hadi nambari kamili iliyo karibu zaidi. Tumia hoja ya pili kubainisha idadi ya sehemu za desimali:

```py
num_1 = 3.4
num_2 = 7.7

print(round(num_1)) # 3
print(round(num_2)) # 8
print(round(3.14159, 2)) # 3.14
```

- **Kitendakazi cha `abs()`**: Hiki hutumika kurudisha thamani kamili ya nambari:

```py
num = -13

print(abs(num)) # 13
```

- **`pow()` Function**: Hii huinua nambari hadi nguvu ya nyingine. Ukiwa na hoja za nambari kamili, unaweza pia kupitisha hoja ya tatu isiyo sifuri ili kuhesabu matokeo modulo thamani hiyo:

```py
result = pow(2, 3)
print(result)  # 8
print(pow(2, 3, 5)) # 3
```

## Mgawo ulioboreshwa

- **Mgawo wa thamani ulioboreshwa**: Mgawo wa thamani ulioboreshwa hutumia operesheni kwenye kigezo na kuhifadhi matokeo tena kwenye kigezo hicho, yote kwa hatua moja.

```py
# Addition assignment
my_var = 10

bits = 35
bits %= 2

print(bits) # 1

# Exponentiation assignment
power = 2
power **= 3

print(power) # 8
```

```py
print(3 < 4) # True
```

```py
print(3 <= 4) # True
```

## Kufanya kazi na kauli za `if`, `elif`, na `else`

- **Vizuizi vya msimbo na kuingizwa**: Python hutumia kuingizwa kuunganisha kauli katika kizuizi, kama mwili wa kitendakazi au hali. Kauli katika kizuizi kimoja lazima zitumie kiwango kimoja cha kuingizwa. Mkataba ni kutumia nafasi nne kwa kila kiwango.

- **Kauli ya `pass`**: `pass` haufanyi chochote. Tumia kama kiwakilishi ambapo Python inahitaji kauli, kama mwili wa hali usio na chochote:

```py
age = 18
if age >= 18:
    pass
```

- **Kauli za `if`**: Kauli ya `if` hufanya mwili wake wakati Python inachukulia hali yake kuwa kweli.

```py
age = 18

if age >= 18:
    print('You are an adult') # You are an adult
```

- **Kifungu cha `else`**: Kifungu cha `else` hufanya mwili wake wakati Python inachukulia hali zote zilizotangulia katika mnyororo wa `if...elif...else` kuwa si kweli.

```py
age = 12

if age >= 18:
    print('You are an adult')
else:
    print('You are not an adult yet') # You are not an adult yet
```

- **Kifungu cha `elif`**: Kifungu cha `elif` kinajaribu hali nyingine wakati Python inachukulia hali zote zilizotangulia katika mnyororo huo kuwa si kweli. Hufanya mwili wake ikiwa Python inachukulia hali yake kuwa kweli.

```py
age = 16

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')  # You are a teenager
```

Unaweza pia kutumia taarifa za `if` zilizo pangwa ndani kama ifuatavyo:

```py
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

## Thamani za kweli na uongo

- **Ukweli wa thamani**: Katika Python, kila thamani ina thamani ya kweli au siyo kweli ya asili, au hisia iliyojengwa ndani kama inapaswa kutendewa kama `True` au `False` katika muktadha wa mantiki. Thamani nyingi zinachukuliwa kuwa za kweli, yaani, zinatathminiwa kuwa `True` katika muktadha wa mantiki. Nyingine ni za uongo, yaani, zinatathminiwa kuwa `False`. Hapa kuna mifano ya thamani za uongo:

```md
False
None
Integer 0
Float 0.0
Empty strings ''
```

Thamani nyingine kama nambari zisizo za sufuri, na mfuatano wa herufi usio tupu ni za kweli.

## Kufanya kazi na kitendakazi cha `bool()`

- **Kitendakazi cha `bool()`**: Ikiwa unataka kukagua kama thamani ni ya kweli au uongo, unaweza kutumia kitendakazi kilicho ndani cha `bool()`. Hukiibadilisha thamani kuwa sawa na thamani ya kweli au siyo kweli na hurudisha `True` kwa thamani za kweli na `False` kwa thamani za uongo. Hapa kuna mifano michache:

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

## Waendeshaji wa thamani ya kweli au siyo kweli na kupunguzwa kwa mzunguko

- **Opereta za thamani ya kweli au siyo kweli**: Hizi ni opereta maalum zinazokuwezesha kuunganisha usemi wa kihesabu zaidi kuunda mantiki tata ya maamuzi katika msimbo wako. Kuna opereta tatu za thamani ya kweli au siyo kweli katika Python: `and`, `or`, na `not`.
- **Opereta `and`**: Opereta hii huchukua hoja mbili na hurudisha hoja ya kwanza ikiwa ni ya uongo; vinginevyo, hurudisha hoja ya pili. Hoja zote mbili lazima ziwe za kweli ili usemi uzalishwe kuwa thamani ya kweli.

```py
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

Unaweza pia kutumia opereta ya `and` katika masharti kama ifuatavyo:

```py
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

- **Kigezo cha `or`**: Kigezo hiki hurudisha wapokeaji wa kwanza ikiwa ni thamani ya kweli; vinginevyo, hurudisha wapokeaji wa pili. Usemi wa `or` hutoa thamani ya kweli ikiwa angalau wapokeaji mmoja ana thamani ya kweli. Hapa kuna mfano:

```py
age = 19
is_employed = False

print(age or is_employed) # 19
```

Kama ilivyo kwa opereta ya `and`, unaweza kutumia opereta ya `or` katika masharti kama ifuatavyo:

```py
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

- **Kupunguza mizunguko**: Opereta za `and` na `or` zinajulikana kama opereta za kupunguza mizunguko. Kupunguza mizunguko maana yake ni Python huchunguza thamani kutoka kushoto kwenda kulia na kusitisha mara tu inapotambua matokeo ya mwisho.
- **Opereta ya `not`**: Opereta hii huchukua operandi moja na kubadilisha thamani yake ya kweli au siyo kweli. Hubadilisha thamani za kweli kuwa `False` na thamani za uongo kuwa `True`. Tofauti na opereta zilizopita, `not` daima hurudisha `True` au `False`. Hapa kuna mifano:

```py
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

Hapa kuna mfano wa opereta ya `not` katika sharti:

```py
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

## Opereta za utambulisho

- **Utambulisho na usawa**: Vigezo vinarejelea vitu. Opereta `is` hukagua kama hoja mbili zinarejelea kitu kimoja, wakati `is not` hukagua kama zinarejelea vitu tofauti. Opereta `==` na `!=` zinalinganisha thamani badala yake. Tumia opereta za usawa unapolinganishwa nambari au mfuatano wa herufi.
- **`None` na `NoneType`**: `None` inawakilisha kutokuwepo kwa thamani. Ni thamani pekee ya aina ya data `NoneType`.
- **Singletons**: `None`, `True`, na `False` kila moja ni singleton, maana kuna kitu kimoja tu kwa kila moja. Unaweza kuangalia vitu hivi kwa opereta za utambulisho.
- **Kukagua `None`**: Tumia `is None` kukagua thamani isiyopo na `is not None` kukagua thamani iliyopo. Zote `None` na `False` ni thamani za uongo, lakini ni vitu tofauti:

```py
response = False

print(response is None) # False
print(response is not None) # True
print(response is True) # False
print(response is False) # True
```

- **Utambulisho na ukweli**: Ikiwa `response` inaweza kuwa `True`, `False`, au `None`, `response is None` hutofautisha jibu lisilopo na jibu hasi. Kutumia `not response` kutatenda `False` na `None` sawa. Kwa bendera za kawaida za thamani ya kweli au siyo kweli, tumia `if is_ready` au `if not is_ready`. Tumia `is True` au `is False` unapohitaji kutofautisha kitu cha thamani ya kweli au siyo kweli kutoka kwa thamani nyingine.

## Kipaumbele cha opereta za thamani ya kweli au siyo kweli

- **Kipaumbele cha Vigezo na Mabano ya Kawaida**: Wakati `and` na `or` vinaonekana katika usemi mmoja, `and` ina kipaumbele cha juu kuliko `or`. Hii ina maana `and` huunganisha wapokeaji wake kwanza, kwa hivyo `True or False and False` huunganishwa kama `True or (False and False)`:

```py
print(True or False and False) # True
```

Wapokeaji wa kushoto wa `or` ni `True`, hivyo mchakato wa kukata njia (short-circuiting) una maana `False and False` haifanyiwi tathmini, na matokeo ni `True`.

Unaweza kutumia mabano ya kawaida kubadilisha muungano. Hapa, `True or False` huunganishwa pamoja na kutathminiwa kuwa `True`, kisha `True and False` hutathminiwa kuwa `False`:

```py
print((True or False) and False) # False
```

## Vitendakazi vya ndani maarufu

- **Kitendakazi cha `input()`**: Hiki hutumika kuomba mtumizi kuingiza data:

```py
name = input('What is your name?') # User types 'Kolade' and presses Enter
print('Hello', name) # Hello Kolade
```

- **Kitendakazi cha `int()`**: Hiki hutumika kubadilisha nambari, thamani ya kweli au siyo kweli, au mfuatano wa herufi unaowakilisha nambari kamili kuwa nambari kamili:

```py
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0

# A string representing a decimal number cannot be converted directly
# int('3.14') raises a ValueError
```

## Kufanya kazi na kitendakazi

- **Kitendakazi**: Kitendakazi ni vipande vya msimbo vinavyoweza kutumika tena vinavyotekelezwa unapovitoa wito. Ili kuita kitendakazi, unahitaji kurejelea jina la kitendakazi ikifuatiwa na mabano ya kawaida:

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

- **Vigezo na hoja**: Vigezo ni majina yaliyoorodheshwa katika ufafanuzi wa kitendakazi, kama `num_1` na `num_2` hapo juu. Hoja ni thamani zinazopitishwa wakati wa kuita kitendakazi, kama `3` na `4`.

Kama utaita kitendakazi bila idadi sahihi ya hoja, utapokea `TypeError`:

```py
def calculate_sum(a, b):
    print(a + b)

calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

- **Hoja za nafasi**: Hoja hizi zinaendana na vigezo kwa nafasi yao katika wito wa kitendakazi.

```py
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

- **Hoja za maneno muhimu**: Hoja hizi hutumia `name=value` kuendana na kigezo kwa jina. Zinaweza kuonekana kwa mpangilio tofauti na vigezo:

```py
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

- **Kuchanganya aina za hoja**: Hoja za nafasi lazima ziwe kabla ya hoja za maneno muhimu. Kila kigezo kinaweza kupokea thamani moja tu:

```py
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

- **Kauli ya `return`**: Kauli ya `return` huisha kitendakazi na kufanya thamani yake ipatikane mahali kitendakazi kilipotwaliwa wito.

- **`None`**: `None` inawakilisha kutokuwepo kwa thamani. Ikiwa kitendakazi hakirudishi thamani waziwazi, basi thamani ya default ya return ni `None`:

```py
def greet():
    print('hello')

result = greet() # hello
print(result) # None
```

## Wigo katika Python

Python ina sheria za ziada za wigo. Kwa sasa, makini na wigo wa ndani na wa kimataifa.

- **Wigo wa jumla**: Variable iliyoundwa nje ya kitendakazi inaweza kutumika ndani na nje ya vitendakazi.

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + (subtotal * tax)
    return total

print(get_total(100))  # 170.0
```

- **Wigo wa ndani**: Variable iliyoundwa ndani ya kitendakazi inaweza kutumika tu ndani ya kitendakazi hicho. Vigezo vya kitendakazi pia ni variable za wigo wa ndani.

```py
def my_func():
    num = 10
    print(num)
```

- **Kupitisha hoja na kuweka upya vigezo**: Python hupitisha hoja kwa mgawo wa thamani. Kigezo ni jina la ndani ambalo awali linarejelea kitu kilichotolewa; kitu hicho hakikopiwi moja kwa moja. Kuweka upya kigezo hakubadilishi kigezo kilichopitishwa kama hoja:

```py
def double_number(number):
    number = number * 2
    print(number) # 20

original = 10
double_number(original)
print(original) # 10
```

## Kutumia kitendakazi na wigo

- **Miili ya kitendakazi isiyo na kitu**: Unaweza kutumia `pass` kama kiwakilishi katika mwili wa kitendakazi. Kitendakazi chenye `pass` tu kinarudisha `None` kwa kimya:

```py
def placeholder():
    pass

print(placeholder()) # None
```

- **Kuficha majina**: Wakati kigezo cha ndani au kigezo kina jina sawa na kigezo cha kimataifa, kitendakazi hutumia jina la ndani. Kuweka upya kigezo hicho cha ndani hakubadilishi kigezo cha kimataifa:

```py
available_eggs = 5

def use_eggs(available_eggs, eggs_to_use):
    available_eggs -= eggs_to_use
    return available_eggs

print(use_eggs(available_eggs, 1)) # 4
print(available_eggs) # 5
```

- **Kurudisha mapema**: Kauli ya `return` huisha kitendakazi mara moja na kufanya thamani yake ipatikane mahali kitendakazi kilipotwaliwa wito. Hii inakuwezesha kurudisha mapema wakati hali inatimizwa:

```py
def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        return available_eggs
    return available_eggs - eggs_to_use

print(use_eggs(2, 3)) # 2
print(use_eggs(2, 1)) # 1
```

- **Kuita kitendakazi kutoka kwa vitendakazi vingine**: Kitendakazi kinaweza kuita kitendakazi kingine na kutumia au kurudisha matokeo yake:

```py
def use_eggs(available_eggs, eggs_to_use):
    return available_eggs - eggs_to_use

def make_fried_egg(available_eggs):
    return use_eggs(available_eggs, 1)

print(make_fried_egg(3)) # 2
```

- **Kuweka thamani zilizorejeshwa**: Kurudisha thamani mpya hakubadilishi moja kwa moja kigezo kilichopitishwa kama hoja. Ili kusahihisha, weka thamani iliyorejeshwa tena kwenye kigezo hicho:

```py
available_eggs = use_eggs(available_eggs, 1)
print(available_eggs) # 4
```

## Kutafsiri mfuatano wa herufi

- **`str.maketrans()`**: Aina ya mfuatano wa herufi mbili ya `str.maketrans()` huchukua mfuatano wa herufi wenye urefu sawa na kuoanisha kila herufi katika mfuatano wa kwanza na herufi inayolingana katika mfuatano wa pili. Jedwali huhifadhi herufi kama nambari za Unicode, nambari zinazowakilisha kwa kipekee. Njia ya `translate()` hutumia jedwali hilo kwenye mfuatano wa herufi na hurudisha mfuatano mpya. Herufi ambazo hazijajumuishwa kwenye jedwali hubaki kama zilivyo.

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc!'.translate(trans_table)
print(result)  # 123123!
```

## Kuhakiki hoja za nambari kamili

- **Thamani ya kweli au siyo kweli na nambari kamili**: Python hutenda thamani ya kweli au siyo kweli kama aina maalum ya nambari kamili, hivyo `isinstance(True, int)` na `isinstance(False, int)` zote hurudisha `True`. Unapohakiki nambari kamili ambayo haipaswi kuwa thamani ya kweli au siyo kweli, toa wazi thamani za kweli au siyo kweli:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True

value = True
print(isinstance(value, int) and not isinstance(value, bool)) # False

value = 5
print(isinstance(value, int) and not isinstance(value, bool)) # True
```

## Thamani za kigezo cha default

- **Vigezo vya default**: Unaweza kutoa thamani ya default kwa kigezo. Ikiwa hutoi hoja yake wakati wa kuita kitendakazi, Python itatumia thamani hiyo ya default:

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```
