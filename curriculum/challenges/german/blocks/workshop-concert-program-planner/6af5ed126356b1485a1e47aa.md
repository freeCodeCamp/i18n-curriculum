# --description--

Das Zuweisen einer Liste an eine andere Variable erstellt keine Kopie der Liste. Beide Variablen verweisen auf dieselbe Liste, daher wird die zweite Variable als Alias bezeichnet. Jede Änderung, die über eine der beiden Variablen vorgenommen wird, ist auch über die andere sichtbar.

Erstellen Sie eine Variable namens `printed_program` und weisen Sie ihr `pieces` zu. Verwenden Sie dann `append()`, um den String `Humoresque No. 7` als Zugabe ans Ende von `pieces` anzufügen, und geben Sie `printed_program` aus.

Im Terminal sehen Sie, dass die Zugabe auch in `printed_program` erscheint, obwohl Sie sie zu `pieces` hinzugefügt haben.

Damit ist Ihr Konzertprogrammplaner fertig.
