## Kitendakazi ni nini?

Vitendakazi ni vipande vya msimbo vinavyoweza kutumika tena ambavyo hufanya kazi unapovitoa wito. Python hutoa vitendakazi iliyo ndani, ikiwa ni pamoja na `print()`, ambavyo ulitumia katika mafundisho yaliyopita.

Kitendakazi kingine cha msaada kilicho jengwa ndani ni `input()`, ambacho hukuruhusu kuomba mtumizi kutoa ingizo:

```python
name = input('What is your name?') # User types "Kolade" and presses Enter  
print('Hello', name) # Output: Hello Kolade
```

Kwa upande mwingine, `int()` hubadilisha nambari, thamani ya kweli au siyo kweli, au mfuatano wa herufi unaowakilisha nambari kamili kuwa nambari kamili:

```python
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0 
```

## Kueleza na kuita kitendakazi

Pia unaweza kuandika vitendakazi vyako maalum. Ili kufanya hivyo, tumia neno kuu la `def`, ikifuatiwa na jina unalotaka kumpa kitendakazi chako, mabano ya kawaida, na nukta. Kisha kwenye mstari mpya, andika msimbo ambao kitendakazi chako kinapaswa kuutekeleza. Msimbo unaotekelezwa na kitendakazi pia huitwa mwili wa kitendakazi.

Hapa kuna mfano wa kitendakazi maalum kinachoitwa `hello` kinachochapisha mfuatano wa herufi `Hello World` kwenye terminali:

```python
def hello():
    print('Hello World')
```

Ili kuendesha kitendakazi, unahitaji kukitoa wito kwa jina lake likifuatiwa na mabano ya kawaida:

```python
hello() # Hello World
```

Angalia kivunjiko cha mstari kabla ya `print('Hello World')`. Kama unavyoweza kukumbuka kutoka kwa mafundisho yaliyopita, Python hutegemea kivunjiko cha mstari kuamua ni makundi gani ya tamko yanayohusiana. Makundi haya ya tamko huitwa blokki za msimbo.

## Kutumia vigezo na hoja

Hapa kuna kitendakazi kingine rahisi kinachochapisha jumla ya nambari mbili kwenye terminali:

```python
def calculate_sum(a, b):
    print(a + b)
```

Unaweza kuona kuwa kitendakazi chetu, `calculate_sum`, kina `a` na `b` ndani ya mabano yake, yamegawanywa kwa koma. Hivi huitwa vigezo. Fikiria vigezo kama vigezo vya kiwakilishi vinavyofanya kazi kama "nafasi" kwa thamani unazozipitisha kwenye vitendakazi unapovitoa wito.

Ili kutumia vigezo, lazima upitishe "hoja". Hoja ni thamani unazozipitisha kwenye kitendakazi unapokitoa wito.

Hivi ndivyo unavyotoa wito kwa kitendakazi cha `calculate_sum` ili kujumlisha nambari `3` na `1`:

```python
calculate_sum(3, 1) # 4
```

Kama utatoa wito kwa kitendakazi bila idadi sahihi ya hoja, utapata `TypeError`:

```python
calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

## Hoja za nafasi na za neno kuu

Hoja katika `calculate_sum(3, 1)` ni hoja za nafasi. Python huziunganisha na vigezo kwa nafasi yao: `3` inaenda kwa `a`, na `1` inaenda kwa `b`.

Hapa kuna kitendakazi ambapo mpangilio wa hoja ni muhimu:

```python
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

Ukibadilisha hoja za nafasi, `name` hupokea `25` na `age` hupokea `'Alice'`:

```python
introduce(25, 'Alice')
# My name is 25 and I am Alice years old.
```

Pia unaweza kupitisha hoja za neno kuu kwa kuandika jina la kigezo ikifuatiwa na `=` na thamani. Python huziunganisha hoja hizi kwa jina, hivyo unaweza kuziandika kwa mpangilio tofauti:

```python
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

Hapa, `name='Alice'` hupitisha `'Alice'` kwa kigezo cha `name`. Hii haitegemezi kuweka mabadiliko ya jina `name` nje ya kitendakazi.

Unaweza kuchanganya hoja za nafasi na hoja za neno kuu, lakini hoja za nafasi lazima ziwe kwanza:

```python
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

Kuweka hoja ya nafasi baada ya hoja ya neno kuu husababisha `SyntaxError`:

```python
introduce(name='Alice', 25)
# SyntaxError: positional argument follows keyword argument
```

Huwezi pia kutoa thamani kwa kigezo hicho mara zaidi ya moja:

```python
introduce('Alice', name='Bob', age=25)
# TypeError: introduce() got multiple values for argument 'name'
```

Katika wito huu, hoja ya nafasi `'Alice'` tayari inatoa thamani kwa `name`. Kupitisha `name='Bob'` kunatoa thamani ya pili kwa kigezo hicho hicho.

## Kurudisha thamani kutoka kwa vitendakazi

Vitendakazi pia hutumia neno kuu maalum la `return` kuondoka kwenye kitendakazi na kurudisha thamani. Kama hutumiwi waziwazi `return`, Python itarudisha `None` kwa chaguo-msingi.

Kama ulivyojifunza katika funzo kuhusu waendeshaji wa utambulisho, `None` inawakilisha kutokuwepo kwa thamani. Hapa, inaonyesha kuwa kitendakazi hakirudishi matokeo wazi.

Hapa kuna mfano:

```python
def calculate_sum(a, b):
    print(a + b)

my_sum = calculate_sum(3, 1) # 4
print(my_sum) # None
```

Unaweza kuona kuwa kitendakazi cha `calculate_sum` kinachapisha jumla ya `a` na `b`, lakini hakirudishi chochote waziwazi. Hivyo tunapoweka matokeo yake kwenye `my_sum`, thamani ni `None`. Ili kurekebisha hilo, unaweza kutumia neno kuu la `return` kurudisha matokeo:

```python
def calculate_sum(a, b):
    return a + b

my_sum = calculate_sum(3, 1)
print(my_sum) # 4
```

Sasa, `calculate_sum` inarudisha jumla ya `a` na `b`, ambayo huhifadhiwa katika `my_sum`.
