# --description--

在使用 Python 變數之前，了解資料型別非常重要。資料型別描述變數所持有的值的種類，例如數字或一段文字。程式語言使用資料型別，讓它們知道如何儲存和處理不同種類的資訊。

Python 是一種動態型別語言。這表示你在創建變數時不需要指定變數的資料型別。Python 會根據指派給變數的值來判斷型別。

以下是一些範例：

```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```

變數之後可以被指定不同型別的值：

```python
age = 25
age = 'Twenty-five'
```

在第二次指定之後，`age` 變成包含字串而非整數。

目前先專注於你在本模組中會使用的四種資料型別：

- 整數：沒有小數的整數，例如 `10` 或 `-5`。

```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- 浮點數：帶有小數點的數字，例如 `4.41` 或 `-0.4`。

```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- 字串：一連串被單引號或雙引號包圍的字元，例如 `'Hello world!'`。

```python
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- 布林值：一種真或假的型別，以 `True` 或 `False` 表示。

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python 還有其他資料型別。你會在第一次需要它們時學習。
