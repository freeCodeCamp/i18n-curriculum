# --description--

Як і в циклі `for`, у циклі `while` може бути умова `else`. Код в умові `else` виконується, коли цикл завершується нормально, але не виконується, якщо цикл зупиняється за допомогою `break`.

Додайте умову `else` до зовнішнього циклу `while`. Усередині неї виведіть рядок `All requests served`.

У списку є запит на зупинку, тому умова `else` поки що не виконається.

def run_elevator(requests, start_floor):
    current_floor = start_floor
    floors_traveled = 0

    while requests:
        target = requests.pop(0)

        if target == 'stop':
            print('Emergency stop!')
            break

        if target == current_floor:
            print(f'Already on floor {target}')
            continue

        while current_floor != target:
            if current_floor < target:
                current_floor += 1
            else:
                current_floor -= 1
            floors_traveled += 1

        print(f'Arrived at floor {current_floor}')
