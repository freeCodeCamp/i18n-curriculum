# --description--

既然你已经有了 `departmentId`，就用它将部门的数据保存到 `departmentsById` 中。

为 `departmentsById[departmentId]` 赋值一个包含以下内容的对象：

`id`：赋值为 `departmentId`，  
`code`：赋值为 `departmentData.Dept_code`，  
`name`：赋值为 `departmentName`  
`programIds`：一个空数组（你将在后续步骤中填充它）

最后，将 `departmentsById[departmentId]` 输出到控制台。
