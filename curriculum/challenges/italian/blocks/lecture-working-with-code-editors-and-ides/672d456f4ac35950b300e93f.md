# --description--

Probabilmente conosci già alcune delle scorciatoie di base, che derivano dal tuo sistema operativo. Scorciatoie come <kbd>Ctrl</kbd> + <kbd>S</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>S</kbd> (macOS) per salvare, <kbd>Ctrl</kbd> + <kbd>C</kbd> o <kbd>Cmd</kbd> + <kbd>C</kbd> per copiare, e <kbd>Ctrl</kbd> + <kbd>V</kbd> o <kbd>Cmd</kbd> + <kbd>V</kbd> per incollare funzionano tutte in VS Code.

Ma ci sono alcune scorciatoie specifiche dell'applicazione che possono comunque aumentare la tua produttività. Vale la pena notare che alcune di queste scorciatoie possono variare a seconda del sistema operativo.

Ad esempio, <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> eseguirà il formatter configurato (come Prettier, per un progetto JavaScript) sul file attualmente aperto.

Usa <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (macOS) per cercare il contenuto testuale di tutti i file nel tuo workspace. Poi usa <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (macOS) se vuoi eseguire una ricerca e sostituzione.

Se devi eliminare una riga, <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (macOS) la cancellerà.

Ti serve più spazio per tutto il tuo codice? <kbd>Ctrl</kbd> + <kbd>B</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>B</kbd> (macOS) nasconderanno la barra laterale, che contiene la lista dei file e il menu delle estensioni.

O magari non riesci proprio a vedere il tuo codice? <kbd>Ctrl</kbd> + <kbd>Plus</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Plus</kbd> (macOS) aumenteranno la scala dell’editor, mentre <kbd>Ctrl</kbd> + <kbd>Minus</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Minus</kbd> (macOS) la diminuiranno.

Un’altra funzionalità utile in VS Code è la modifica multipla su più righe, che ti permette di fare cambiamenti su diverse righe contemporaneamente. Ad esempio, puoi posizionare più cursori usando <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> e <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Windows), <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> e <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Linux), oppure <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Down</kbd> e <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Up</kbd> (macOS), per estendere il cursore su righe consecutive. Puoi anche tenere premuto <kbd>Alt</kbd> (Windows/Linux) o <kbd>Option</kbd> (macOS) e cliccare per aggiungere cursori su righe separate dove ti servono. Una volta posizionati i cursori, tutto ciò che digiti o elimini si applicherà simultaneamente a tutte quelle posizioni, risparmiando molto tempo quando lavori con codice ripetitivo.

Infine, se dimentichi una di queste scorciatoie, hai sempre <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS), che apre la command palette per selezionare qualsiasi cosa ti serva.
