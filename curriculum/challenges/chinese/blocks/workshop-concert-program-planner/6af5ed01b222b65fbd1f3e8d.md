# --description--

在本次工作坊中，你将通过计划一场管弦乐音乐会的节目来练习操作列表。

正如你在之前的课程中学到的，列表是一个有序的集合。你可以通过将用逗号分隔的项放在方括弧内来创建列表：

```py
fruits = ['apple', 'banana', 'cherry']
```

创建一个名为 `pieces` 的变量，并赋值一个包含字串 `Carnival Overture`、`Song to the Moon` 和 `Silent Woods`（按此顺序）的列表。
