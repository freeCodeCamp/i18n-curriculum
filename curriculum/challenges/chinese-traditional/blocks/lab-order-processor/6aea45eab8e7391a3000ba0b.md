# --description--

在這個實驗中，你將處理電子商務訂單並控制過程中出現的錯誤。

**目標：** 完成以下使用者故事並通過所有測試以完成實驗。

你將使用的資料結構與起始程式碼中的變數結構相同：

- 一個 **訂單** 是一個字典，包含：
  - `order_id`：一個識別訂單的整數。
  - `products`：一個字典列表，每個字典包含 `product_id` 和所需的 `quantity`。
  - `discount_code`：一個字串，若訂單沒有折扣碼則為 `None`。
  - `status`：描述訂單狀態的字串。
- 一個 **訂單歷史** 是訂單的列表。
- 一個 **庫存** 是一個字典，鍵是產品 ID，值是包含 `product` 名稱、庫存數量 `quantity` 和單價 `price` 的字典。
- **折扣碼** 是一個字典，鍵是折扣碼，值是折扣率，例如 `0.1` 代表 10% 折扣。

**使用者故事：**

1. 你應該有一個名為 `find_order` 的函式，帶有兩個參數：訂單 ID 和訂單歷史，順序如是。
1. `find_order` 應該：
   - 傳回給定訂單歷史中 `order_id` 與給定訂單 ID 相等的訂單。
   - 若無訂單符合給定訂單 ID，則引發 `ValueError`，訊息為 `Order ID {order_id} not found in order history.`。
1. 你應該有一個名為 `verify_availability` 的函式，帶有兩個參數：訂單和庫存，順序如是。
1. `verify_availability` 應該：
   - 若訂單中的產品在給定庫存中缺失，則引發 `ValueError`，訊息為 `Product ID {product_id} is not in the inventory.`。
   - 若訂單中某產品所需數量大於庫存數量，則引發 `ValueError`，訊息為 `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.`。
   - 若訂單中每個產品皆有足夠數量，則不引發任何錯誤。
1. 你應該有一個名為 `get_discount_rate` 的函式，帶有兩個參數：訂單和折扣碼，順序如是。
1. `get_discount_rate` 應該：
   - 若訂單的 `discount_code` 是 `None`，則傳回 `0.0`。
   - 若訂單的 `discount_code` 不在給定折扣碼中，則引發 `ValueError`，訊息為 `Invalid discount code: {discount_code}.`。
   - 否則傳回訂單的 `discount_code` 對應的折扣率。
1. 你應該有一個名為 `process_order` 的函式，帶有四個參數：要處理的訂單 ID、訂單歷史、庫存和折扣碼，順序如是。
1. `process_order` 應該使用 `find_order`、`verify_availability` 和 `get_discount_rate` 來處理訂單，並控制它們引發的 `ValueError`，使得呼叫 `process_order` 永遠不會引發錯誤。
1. 當給定訂單歷史中沒有訂單符合給定訂單 ID 時，`process_order` 應該：
   - 列印 `Error processing order {order_id}: {error message}`，其中 `{error message}` 是 `find_order` 引發的 `ValueError` 的訊息，且不列印其他內容。
   - 保持給定的庫存和折扣碼不變。
1. 當訂單存在但無法完成，因為產品缺貨、所需數量不足或折扣碼無效時，`process_order` 應該：
   - 列印 `Error processing order {order_id}: {error message}`，其中 `{error message}` 是 `verify_availability` 或 `get_discount_rate` 引發的 `ValueError` 的訊息。
   - 將訂單的 `status` 設為 `failed`。
   - 保持給定的庫存和折扣碼不變。
   - 列印 `Order {order_id} processing completed. Current status: failed`。
1. 當訂單可以完成時，`process_order` 應該：
   - 列印 `Order {order_id} total: ${total}`，套用折扣且總額四捨五入到小數點後兩位。
   - 將訂單的 `status` 設為 `processed`。
   - 從給定庫存中扣除訂購數量。
   - 從給定折扣碼中移除訂單使用的折扣碼，使每個折扣碼只能使用一次。
   - 列印 `Order {order_id} processing completed. Current status: processed`。

**注意：** 你已獲得一組庫存、訂單歷史和折扣碼，可用來測試你的程式。呼叫你的函式來嘗試，包括會引發錯誤的情況，但在執行測試前請將這些呼叫註解掉，否則可能會干擾測試。

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id, order_history, inventory, discount_codes):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
