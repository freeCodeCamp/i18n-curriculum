# --description--

Has actualizado el conteo local de huevos y lo has devuelto desde `make_fried_egg`. Ahora, asigna el valor devuelto a la variable global para actualizar tu inventario.

Recuerda que los parámetros de función son variables locales. Cuando pasas la variable global `available_eggs` a `make_fried_egg`, su parámetro local inicialmente se refiere al mismo entero. La asignación `available_eggs = use_eggs(available_eggs, 1)` reasigna solo ese parámetro local al conteo devuelto. No reasigna la variable global, que aún se refiere a `1`.

Para actualizar tu inventario real de cocina, sobrescribe la variable global `available_eggs` con el nuevo número de huevos que devuelve tu función `make_fried_egg`.

Al final de tu código, llama a la función `make_fried_egg`, pasando `available_eggs` como argumento, y asigna el resultado de nuevo a la variable global `available_eggs`.

available_eggs = 1

def check_kitchen_stock():

    print(f'- {available_eggs} eggs')

check_kitchen_stock()

def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        print('The kitchen does not have enough eggs.')
        return available_eggs

    print(f'{eggs_to_use} egg(s) used out of {available_eggs} available.')
    return available_eggs - eggs_to_use

use_eggs(available_eggs, 1)
print(available_eggs)

def make_fried_egg(available_eggs):
    has_enough_eggs = available_eggs >= 1

    if has_enough_eggs:
        available_eggs = use_eggs(available_eggs, 1)
        print('Made a fried egg. Yummy!')
    else:
        print('Could not make a fried egg. Not enough eggs!')

    return available_eggs
