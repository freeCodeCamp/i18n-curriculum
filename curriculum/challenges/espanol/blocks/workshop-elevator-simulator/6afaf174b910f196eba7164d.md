# --description--

El ascensor debe seguir atendiendo las solicitudes mientras queden. Un ciclo `while` es perfecto para esto, porque se repite mientras su condición sea verdadera. Aquí tienes un recordatorio de la sintaxis:

```py
while condition:
    # code to repeat
    ...
```

Una lista no vacía es verdadera y una lista vacía es falsa, así que puedes usar una lista como condición del ciclo para que se ejecute hasta que la lista esté vacía.

Crea un ciclo `while` que se ejecute mientras `requests` no esté vacía. Dentro del ciclo, usa `pop(0)` para eliminar la primera solicitud de `requests` y asígnala a una variable llamada `target`. Luego, imprime `target`.

Como `pop(0)` acorta la lista en cada iteración, la lista eventualmente queda vacía y el ciclo se detiene. Sin eso, la condición nunca sería falsa y el ciclo se ejecutaría para siempre.
