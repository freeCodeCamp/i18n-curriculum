# --description--

Neste passo, você vai armazenar cada `instructor` em `instructorsById`, usando seu próprio id como chave.
Assim como fez para `programs`, atribua a `instructorsById[instructor.id]` um objeto que
espalhe `instructor` e adicione `programId` (defina como `program.id`) e `departmentId`.

Antes de atribuir o objeto, exclua `console.log(instructor)` do passo anterior.

Registre `instructorsById[instructor.id]` no console para inspecionar o objeto armazenado.
