# --description--

## Tuple ni nini?

Tuple ni aina ya data ya Python inayotumika kuunda mfululizo wa thamani ulio pangwa. Tuple zinaweza kuwa na mchanganyiko wa aina za data kama hizi:

```py
developer = ('Alice', 34, 'Rust Developer')
```

Vigawanyo huunda tuple, kwa hivyo mabano ya kawaida ni hiari katika mgawo wa thamani kama huu:

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

Ili kuunda tuple yenye kipengele kimoja, unahitaji koma inayofuata:

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

Tuple tupu inaandikwa kama `()`.

Tuple ni sawa na orodha, lakini wakati orodha ni aina ya data inayoweza kubadilika, tuple ni isiyobadilika. Hii ina maana kwamba mara tuple itakapoundwa, rejea za vipengele vyake haviwezi kubadilishwa, kuongezwa, au kuondolewa.

Kama utajaribu kusahihisha kipengee kimoja ndani ya tuple, utapata `TypeError`:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## Vitu vinavyoweza kubadilika ndani ya tuple

Tuple inaweza kuwa na kitu kinachoweza kubadilika, kama orodha. Kutokuwa na mabadiliko kwa tuple hakuzuizi mabadiliko kwa kitu hicho kilicho ndani:

```py
def add_greeting(values):
    values[0].append('hi')

greetings = (['hello'],)
original_list = greetings[0]

add_greeting(greetings)
print(greetings) # (['hello', 'hi'],)
print(greetings[0] is original_list) # True
```

Kitendakazi kinabadilisha orodha ndani ya tuple. Tuple bado ina rejea kwa orodha ile ile. Kuweka orodha tofauti kwa `greetings[0]` kutasababisha `TypeError`, kwa sababu hiyo itabadilisha rejea ya kipengele cha tuple.

## Kupata vipengele vya tuple

Ili kupata kipengee kutoka kwenye tuple, unaweza kutumia uandishi wa mabano na nambari ya kielezo:

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

Kama unahitaji kupata vipengee kuanzia mwisho wa tuple, basi unaweza kutumia uandishi wa kielezo hasi. Hapa kuna mfano wa kutumia kielezo hasi kupata kipengee cha pili kutoka mwisho kwenye tuple:

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

Kama utajaribu kuingiza nambari ya kielezo inayozidi au sawa na urefu wa tuple, basi utapokea `IndexError` kama hii:

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## Kutumia kijenzi cha `tuple()`

Njia nyingine ya kuunda tuple ni kwa kutumia kijenzi cha `tuple()` kama hii:

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

Kwa kijenzi cha `tuple()`, unaweza kuingiza aina tofauti za inayoweza kurudiwa kama mfuatano wa herufi, orodha, na hata tuple nyingine.

## Kukagua kama kipengele kiko katika tuple

Ili kuangalia kama kipengee kiko ndani ya tuple, unaweza kutumia neno kuu la `in` kama hii:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## Kutolea thamani kutoka kwa tuple

Pia unaweza kutoa vipengee kutoka kwenye tuple kama ulivyofanya na orodha:

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

Katika mfano huu, `name` ina thamani ya `'Alice'`, `age` ina thamani ya `34`, na `job` ina thamani ya `'Rust Developer'`.

Kama unahitaji kukusanya vipengee vyote vilivyobaki kutoka kwenye tuple, unaweza kutumia opereta ya nyota (`*`) kama hii:

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

Hapa, `name` ina thamani ya `'Alice'`, na `rest` ni orodha iliyojumuisha nambari `34` na mfuatano wa herufi `'Rust Developer'`.

## Kutumia tuple katika mgawo wa thamani wa wakati mmoja

Unaweza kuunda tuple upande wa kulia wa mgawo wa thamani na kuifungua katika vigezo upande wa kushoto:

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

Python hutathmini usemi wote upande wa kulia kabla ya kuweka thamani zao kwa vigezo upande wa kushoto. Hii inakuwezesha kubadilisha thamani mbili bila kutumia kigezo cha muda mfupi:

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## Kurudisha tuple kutoka kwa kitendakazi

Kitendakazi kinaweza kurudisha tuple kwa kuweka thamani zilizoachwa kwa koma baada ya `return`:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

Thamani zilizoachwa kwa koma huunda tuple moja, ambayo kitendakazi hurudisha. Hapa, `return first, second` ni sawa na `return (first, second)`. Mabano ya kawaida ni hiari.

Unaweza kufungua tuple iliyorejeshwa moja kwa moja katika vigezo:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## Kukata tuples

Kama ilivyo kwa orodha, unaweza kutumia opereta ya kukata (slice) kwenye tuple ili kutoa sehemu yake. Hapa kuna mfano wa kutoa vipengee `'pie'` na `'cookies'` katika tuple tofauti:

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

Kumbuka kuwa nambari ya kwanza inaonyesha kielezo cha kuanzia kwa kutoa sehemu hiyo wakati nambari ya pili inaonyesha kielezo cha mwisho. Lakini kumbuka kuwa kipengee kilicho kwenye kielezo cha mwisho hakijajumuishwa katika tuple iliyotolewa.

## Kulinganisha tuple

Python hulinganisha tuple kwa mpangilio wa alfabeti. Hii ina maana inalinganisha vipengele vinavyolingana kutoka kushoto kwenda kulia. Kiwili cha kwanza kisicho sawa ndicho huamua matokeo:

```py
print((1, 9) < (2, 0)) # True
```

Hapa, `1` ni kidogo kuliko `2`, kwa hivyo tuple ya kwanza ni ndogo. Python haitaji kulinganisha `9` na `0`.

Kama vipengele vya kwanza ni sawa, Python huenda kwa kiwili kinachofuata:

```py
print((1, 3) < (1, 5)) # True
```

Tuple zote zinaanza na `1`, kwa hivyo Python hulinganisha `3` na `5` kuamua matokeo.

Kama vipengele vyote vinavyolingana ni sawa, tuple fupi ni ndogo. Tuple zenye urefu sawa na vipengele vinavyolingana ni sawa:

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

Thamani katika kiwili cha kwanza kisicho sawa lazima ziweze kuungwa mkono kwa kulinganisha mpangilio. Vinginevyo, Python hutoa `TypeError`:

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

Hapa, vipengele vya kwanza ni sawa, lakini Python haiwezi kupanga nambari `3` na mfuatano wa herufi `'five'`.

Vipengele vya baadaye havihitaji kulinganishwa ikiwa kiwili cha awali tayari kimeamua matokeo:

```py
print((1, 3) < (2, 'five')) # True
```

## Kuondoa vipengele kutoka kwa tuple

Ikiwa unahitaji kuondoa kipengee kutoka kwa tuple, haiwezekani kwa sababu tuple ni isiyobadilika. Kwa hivyo mfano huu utasababisha kosa:

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## Kuchagua kati ya tuple na orodha

Basi ni lini utatumia tuple badala ya orodha?

Kama unahitaji mkusanyiko wa vitu unaobadilika ambapo unaweza kuongeza, kuondoa, na kusahihisha vipengele, basi unapaswa kutumia orodha. Kama unahitaji mfululizo ambao rejea za vipengele vyake zinabaki thabiti, unaweza kutumia tuple. Kumbuka kwamba vitu vyovyote vinavyoweza kubadilika ndani yake bado vinaweza kubadilika.

Katika funzo lijalo, tutaangalia baadhi ya njia za kawaida utakazotumia unapotumia tuple.
