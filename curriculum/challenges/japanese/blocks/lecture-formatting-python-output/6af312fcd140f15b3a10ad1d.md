# --description--

前のレッスンで、数値と数学的操作について学んだ際に、f-stringで`.2f`のようなフォーマット指定子を使って数値の小数点以下の桁数を制御しました。

フォーマット指定子は、値が占めるスペースの量や配置場所も制御できます。これは、出力をきれいな列に揃えたいときに便利です。

## 最小幅と整列の設定

コロンの後の数字はフィールドの最小幅を設定し、値が占めるべき文字数を指定します。値がその幅より短い場合、Pythonはその幅に達するまでスペースを追加します。例を示します：

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

幅の前に特定の記号を使うと、値がフィールド内でどこに配置されるかを制御できます。以下がその記号です：

- Less than (`<`) は値を左に整列します
- Greater than (`>`) は値を右に整列します
- Caret (`^`) は値を中央に配置します。

これら3つの記号の動作例です：

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

`'Tea'`は3文字なので、Pythonは幅`8`に達するために5つのスペースを追加します。

- `<`の場合、スペースは値の後ろに付きます
- `>`の場合、スペースは値の前に付きます
- `^`の場合、スペースは両側に分割されてテキストが中央に配置されます。

スペースが均等に分割できない場合、余ったスペースは右側に付きます：

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

整列記号を省略すると、文字列はデフォルトで左揃え、数値は右揃えになります：

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## パディング文字の使用

デフォルトではPythonはスペースでパディングします。別の文字を使いたい場合は、整列記号の直前にその文字を挿入してください：

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

`*^9`では、`*`がパディング文字、`^`が中央揃え、`9`が最小幅です。パディング文字は整列記号と一緒にしか使えません。

## 幅と精度の組み合わせ

前のレッスンで学んだ精度と整列、幅を1つのフォーマット指定子で組み合わせることができます：

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

上の例のフォーマット指定子は、右揃え、最小幅`7`、小数点以下2桁を意味します。Pythonはまず数値を`4.50`（4文字）にフォーマットし、その前に3つのスペースを追加して幅`7`を満たします。

## ステートメント行の作成

ラベルと金額を1行にまとめられます。同じフォーマット指定子を各行に使うと、列が揃います：

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

各ラベルは `12` 文字のフィールド内で左揃えされ、ドットで埋められています。一方、各金額は `8` 文字のフィールド内で右揃えされているため、小数点が揃います。

## 幅は最小値であり最大値ではない

幅はパディングを追加するだけで、値を切り詰めることはありません。値が指定幅より長い場合は、値全体が表示されます：

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

数値も同様です。下の例では、フォーマットされた金額は8文字必要なので、指定幅`7`は無視されます：

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

`:7.2f`の`7`は最小幅であり、金額の長さの制限ではありません。Pythonは数値を収めるために桁を切り捨てることはありません。

だから、予想される値に十分な幅を選ばないと、列が揃わなくなります。

文字列の長さを制限したい場合は、フォーマット指定子に精度を追加してください。文字列の場合、精度は表示する最大文字数を設定します：

```py
label = 'Long description'

print(f'|{label:.8}|') # |Long des|
print(f'|{label:<12.8}|') # |Long des    |
```

`<12.8`では：

- `<`は値を左揃え
- `12`は最小幅
- `.8`は最大文字数です。

Pythonはまず文字列を8文字に切り詰め、その後12文字の幅にパディングします。

精度は文字列と数値で意味が異なります。`.2f`では`.2`が小数点以下の桁数を設定しますが、文字列では`.8`が最大文字数を設定します。
