# --description--

Probablemente ya estés familiarizado con algunos de los atajos básicos, que se heredan de tu sistema operativo. Atajos como <kbd>Ctrl</kbd> + <kbd>S</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>S</kbd> (macOS) para guardar, <kbd>Ctrl</kbd> + <kbd>C</kbd> o <kbd>Cmd</kbd> + <kbd>C</kbd> para copiar, y <kbd>Ctrl</kbd> + <kbd>V</kbd> o <kbd>Cmd</kbd> + <kbd>V</kbd> para pegar funcionan en VS Code.

Pero hay algunos que son específicos de la aplicación y aún pueden aumentar tu productividad. Vale la pena señalar que algunos de estos atajos pueden variar según el sistema operativo.

Por ejemplo, <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> ejecutará el formateador configurado (como Prettier, para un proyecto de JavaScript) en el archivo abierto actualmente.

Usa <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (macOS) para buscar el contenido de texto en todos los archivos de tu espacio de trabajo. Luego usa <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (macOS) si quieres hacer una búsqueda y reemplazo.

Si necesitas eliminar una línea, <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (macOS) la borrará.

¿Necesitas más espacio para todo tu código? <kbd>Ctrl</kbd> + <kbd>B</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>B</kbd> (macOS) ocultarán la barra lateral, que contiene la lista de archivos y el menú de extensiones.

¿O tal vez no puedes ver bien tu código? <kbd>Ctrl</kbd> + <kbd>Plus</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Plus</kbd> (macOS) aumentarán el zoom del editor, y <kbd>Ctrl</kbd> + <kbd>Minus</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Minus</kbd> (macOS) lo disminuirán.

Otra funcionalidad útil en VS Code es la edición en varias líneas, que te permite hacer cambios en varias líneas a la vez. Por ejemplo, puedes colocar múltiples cursores usando <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> y <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Windows), <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> y <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Linux), o <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Down</kbd> y <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Up</kbd> (macOS), para extender el cursor a líneas consecutivas. También puedes mantener presionado <kbd>Alt</kbd> (Windows/Linux) o <kbd>Option</kbd> (macOS) y hacer clic para agregar cursores en líneas separadas donde los necesites. Una vez colocados los cursores, cualquier cosa que escribas o elimines se aplicará simultáneamente en todas esas ubicaciones, lo que puede ahorrar mucho tiempo al trabajar con código repetitivo.

Finalmente, si olvidas alguno de estos atajos, siempre tienes <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows/Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS), que abre la paleta de comandos para que selecciones lo que necesites.
