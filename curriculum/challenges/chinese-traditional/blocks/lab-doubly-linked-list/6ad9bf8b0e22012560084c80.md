# --description--

在這個實驗中，你將建置一個雙向鏈結串列，其中每個節點都會同時保持對串列中下一個節點和前一個節點的引用。

**目標：** 完成以下使用者故事並通過所有測試以完成實驗。

**使用者故事：**

1. 你應該有一個名為 `DoublyLinkedList` 的類別。
1. `DoublyLinkedList` 應該有一個名為 `Node` 的巢狀類別，其 `__init__` 方法應該：
   - 接受一個 `element` 參數和一個預設為 `None` 的選用 `previous` 參數。
   - 將 `element` 屬性設為 `element` 參數的值。
   - 將 `previous` 屬性設為 `previous` 參數的值。
   - 將 `next` 屬性設為 `None`。
1. `DoublyLinkedList` 的 `__init__` 方法應將 `length` 屬性設為 `0`，並將 `head` 和 `tail` 屬性設為 `None`。
1. `DoublyLinkedList` 應該有一個 `is_empty` 方法，當列表沒有節點時回傳 `True`，否則回傳 `False`。
1. `DoublyLinkedList` 應該有一個 `add` 方法，接受一個 `element` 並：
   - 創建一個新的 `Node`，持有該 `element`，並將它加入列表尾端。
   - 將新節點的 `previous` 屬性設為加入前的尾節點，若列表為空則設為 `None`。
   - 更新列表的 `head`（當列表為空時）、`tail` 和 `length`。
   - 不要透過迴圈尋找列表尾端。
1. `DoublyLinkedList` 應該有一個 `remove` 方法，接受一個 `element` 並：
   - 移除所有 `element` 屬性等於該 `element` 的節點。
   - 正確維持剩餘節點的 `next` 和 `previous` 參考連結。
   - 必要時更新列表的 `head`、`tail` 和 `length`。
   - 若沒有節點符合或列表為空，則保持列表不變。
1. `DoublyLinkedList` 應該有一個 `reverse` 方法，能就地反轉節點的順序。
1. `DoublyLinkedList` 應該有一個 `to_list` 方法，回傳一個從 `head` 到 `tail` 節點的元素列表。

class DoublyLinkedList:
    class Node:
        def __init__(self, element, previous=None):
            self.element = element
            self.previous = previous
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None
        self.tail = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element, self.tail)
        if self.is_empty():
            self.head = node
        else:
            self.tail.next = node
        self.tail = node
        self.length += 1

    def remove(self, element):
        current_node = self.head
        while current_node is not None:
            next_node = current_node.next
            if current_node.element == element:
                if current_node.previous is not None:
                    current_node.previous.next = current_node.next
                else:
                    self.head = current_node.next
                if current_node.next is not None:
                    current_node.next.previous = current_node.previous
                else:
                    self.tail = current_node.previous
                self.length -= 1
            current_node = next_node

    def reverse(self):
        current_node = self.head
        while current_node is not None:
            current_node.previous, current_node.next = current_node.next, current_node.previous
            current_node = current_node.previous
        self.head, self.tail = self.tail, self.head

    def to_list(self):
        elements = []
        current_node = self.head
        while current_node is not None:
            elements.append(current_node.element)
            current_node = current_node.next
        return elements
