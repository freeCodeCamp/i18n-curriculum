# --description--

Ви успішно опрацювали як успішний, так і помилковий стани. Але що, якщо є код, який ви хочете виконати незалежно від результату? Саме для цього існує блок `finally`.

```js
try {
  // Code that might throw an error
} catch (err) {
  // Code to handle the error
} finally {
  // Code to run regardless of success or failure
}
```

Безпосередньо під вашим блоком `catch` додайте блок `finally`. Усередині нього встановіть властивість `value` у `bookInput` у порожній рядок (`""`), щоб очистити поле введення і користувач міг одразу ввести новий пошук.
