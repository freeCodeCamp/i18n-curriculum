# --description--

## 为什么要在本地安装 Python？

在所有的工作坊和实验中，你都会使用 freeCodeCamp 的 Python 编辑器。但学习如何在本地计算机上设置 Python 也很重要。

## 下载 Python

在 Windows 和 Mac 上安装 Python 最简单的方法是从官方 Python 网站下载安装程序。本课后面我们还会讲如何在 Linux 上运行 Python。

转到 `https://www.python.org/` 并将鼠标悬停在“Downloads”上。会弹出一个模态窗口，显示适用于你操作系统（OS）的当前 Python 版本。

## 在 macOS 上安装 Python

我们先讲如何在运行 macOS 的计算机上安装 Python：

- 点击显示当前 Python 版本的按钮（来自之前的弹窗），你将自动开始下载一个 `.pkg` 安装文件。
- `.pkg` 安装程序下载完成后，打开它，然后在弹出的窗口中点击“继续”。
- 持续点击“继续”按钮，直到进入“安装类型”部分。在那里，点击“安装”按钮。
- 如有必要，输入你的密码，然后开始安装。
- 当包安装完成后，你应该会看到一条消息，显示 Python 已成功安装。
- 打开你应用程序目录中新创建的 Python 文件夹。
- 双击 `Install Certificates.command` 文件，允许终端进程完成。
- 查看终端窗口中是否出现了 `Successfully installed certifi` 和 `update complete`。
- 关闭终端窗口，然后在安装程序窗口中点击“关闭”。你的设置现在完成了！

## 验证安装

你可以通过打开终端并运行 `python --version` 或 `python3 --version` 来验证安装。

你也可以通过在终端运行 `python` 或 `python3` 来打开 Python 解释器。Python 解释器是一个程序，它读取 Python 代码，将其翻译成计算机能理解的指令，并执行这些指令。

## 什么是终端？

<dfn>终端</dfn>是一个基于文本的界面，允许你通过输入命令与计算机交互。每个操作系统都自带默认的终端应用程序。在 macOS 上，你可以使用 Terminal 应用。在 Windows 上，你可以使用命令提示符或 PowerShell。在 Linux 上，每个桌面环境都有自己的默认终端应用，比如 GNOME Terminal 或 Konsole。

## 使用 `python` 和 `python3` 的区别

请注意，在一些较旧的 macOS 和 Linux 系统上，`python` 可能保留给 Python 2，而 `python3` 专门用于 Python 3。如果你运行 `python --version` 并看到类似 `Python 2.7.18` 的 Python 2 版本，那么你的操作系统可能依赖于一些用旧版本 Python 编写的软件。如果是这样，你应该使用 `python3` 来运行你的 Python 代码。Python 2 已经停止维护，不应再用于任何新开发。

## 在 Windows 上安装 Python

在 Windows 上安装 Python，请按照以下步骤操作：

- 访问 `https://www.python.org/`，将鼠标悬停在“Downloads”上。你会看到一个弹窗，显示“Download for Windows”和带有当前 Python 版本的下载按钮。
- 点击版本号，你将自动开始下载 Python 安装管理器（`.msix` 包）。
- 下载完成后，双击 Python 安装管理器并选择“安装”。
- 安装完成后，`python`、`py` 和 `pymanager` 命令应该可用。如果没有安装 Python 运行期，运行 `python` 会自动安装一个。
- 当你首次安装运行期时，可能会提示你将一个目录添加到你的 `PATH` 中，以便使用额外的别名，比如 `python3.14.exe`。如果你想使用这些别名，请接受这个可选提示。


你可以通过打开命令行外壳（如 PowerShell）并运行 `python --version` 来验证安装。你也可以通过运行 `python` 来打开 Python 解释器。

## 在 Linux 上安装 Python

对于 Linux，大多数主流发行版如 Ubuntu、Debian 和 Fedora 都自带 Python。

只需打开终端并运行 `python --version` 或 `python3 --version`。

如果两个命令都没有显示 Python 3 版本，你可以在 `https://www.python.org` 上查找适合你 Linux 发行版的安装包，或者在线搜索推荐的安装方法。
