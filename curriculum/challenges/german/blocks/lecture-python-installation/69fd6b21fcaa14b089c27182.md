## Installation eines Code-Editors oder einer IDE

In der vorherigen Lektion haben Sie gelernt, wie Sie Python auf Ihrem lokalen Gerät installieren. In dieser Lektion lernen Sie, wie Sie Python-Code lokal ausführen.

Bevor Sie mit dem lokalen Erstellen Ihrer Python-Skripte beginnen können, müssen Sie einen Code-Editor oder eine IDE installieren. IDE steht für integrierte Entwicklungsumgebung. Eine IDE kombiniert Funktionen wie einen Code-Editor, Testwerkzeuge und ein Terminal.

Ein beliebter Code-Editor, den viele Entwickler verwenden, ist VS Code. Besuchen Sie `https://code.visualstudio.com/download`, um VS Code herunterzuladen, das macOS, Windows und Linux unterstützt. Dieser Editor wird in dieser Lektion verwendet.

Weitere gängige Optionen für die Python-Entwicklung sind:

- PyCharm
- Spyder

## Erstellen einer Python-Datei

Nachdem Sie VS Code installiert haben, öffnen Sie es und wählen Sie `File`, dann `Open Folder`. Wählen Sie einen Ordner für Ihr Projekt aus oder erstellen Sie einen neuen. Für zusätzliches Üben außerhalb der Lektion könnten Sie einen Ordner namens `python-projects` verwenden.

Öffnen Sie den Explorer in der linken Seitenleiste von VS Code. Wählen Sie das Symbol `New File` aus, das wie ein Blatt Papier mit einem Pluszeichen aussieht. Erstellen Sie eine Datei namens `main.py` und drücken Sie <kbd>Enter</kbd>. Die `.py`-Erweiterung kennzeichnet sie als Python-Datei.

Öffnen Sie Ihre `main.py`-Datei und geben Sie folgenden Code ein:

```py
print("Hello, world!")
```

## Python-Erweiterung installieren

Um die offizielle Python-Erweiterung von Microsoft zu installieren, folgen Sie den untenstehenden Schritten:

### Methode A: Innerhalb der Anwendung

1. Öffnen Sie die Erweiterungsansicht, indem Sie auf das Symbol mit vier Bausteinen in der linken Aktivitätsleiste klicken. Alternativ drücken Sie <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (Windows / Linux) oder <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (macOS).
1. Geben Sie oben in die Suchleiste `Python` ein.
1. Suchen Sie das oberste Ergebnis mit dem Namen Python und stellen Sie sicher, dass der darunter angegebene Herausgeber Microsoft ist.
1. Klicken Sie auf die blaue Schaltfläche <kbd>Installieren</kbd>.

### Methode B: Terminal / Befehlszeile

Wenn Sie die Erweiterung lieber über ein Terminal installieren möchten, stellen Sie zuerst sicher, dass der Befehl `code` verfügbar ist. Öffnen Sie auf macOS die Befehlspalette, führen Sie `Shell Command: Install 'code' command in PATH` aus und starten Sie Ihr Terminal neu.

Installieren Sie dann die Python-Erweiterung mit folgendem Befehl:

```bash
code --install-extension ms-python.python
```

## Auswahl eines Python-Interpreters

Die Erweiterung fungiert als Brücke, enthält aber nicht die eigentlichen Python-Sprachdateien. Sie müssen einen Python-Interpreter separat von der offiziellen Python-Website installieren, falls Sie das noch nicht getan haben.

Sobald Python auf Ihrem Betriebssystem installiert ist, binden Sie es an Ihren Editor:

1. Öffnen Sie in VS Code einen beliebigen Ordner oder eine Datei mit der Endung `.py`.
1. Öffnen Sie die Befehlspalette mit <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows / Linux) oder <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS).
1. Geben Sie ein und wählen Sie `Python: Select Interpreter`.
1. Wählen Sie die installierte Python-3-Version aus der Liste Ihres Rechners aus. Sie wird nun nativ in der Statusleiste Ihres Arbeitsbereichs angezeigt.

## Ausführen Ihres Python-Skripts

Um diesen Code auszuführen, haben Sie mehrere Möglichkeiten. Die erste ist, auf die Schaltfläche zum Ausführen zu klicken, die wie ein Wiedergabe-Button oben rechts aussieht. Dadurch wird ein Terminal geöffnet und Ihr Python-Skript dort ausgeführt. Sie sollten den Text `Hello, world!` sehen.

Eine andere Möglichkeit ist, ein Terminal zu öffnen und das Programm manuell mit folgendem Befehl auszuführen:

```bash
python main.py
```

Sie müssen diesen Befehl aus dem Ordner ausführen, in dem `main.py` gespeichert ist. Wenn sich `main.py` beispielsweise in einem Ordner namens `python-projects` befindet, verwenden Sie zuerst Folgendes im Terminal:

```bash
cd python-projects
```

Dann führen Sie aus:

```bash
python main.py
```

## Verwendung von `python3` statt `python`

In einigen Umgebungen, besonders auf macOS- und Linux-Systemen, auf denen sowohl Python 2 als auch Python 3 installiert sind, müssen Sie möglicherweise `python3` anstelle von `python` verwenden. Das ist üblich, wenn der Befehl `python` entweder nicht existiert oder auf eine ältere Python-Version verweist.

```bash
python3 main.py
```

Während Sie im Kurs voranschreiten, führen Sie die Beispiele jeder Lektion lokal aus und erstellen Sie eigene Beispiele, um das Gelernte zu testen.
