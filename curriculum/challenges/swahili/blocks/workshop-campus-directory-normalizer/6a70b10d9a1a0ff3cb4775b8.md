# --description--

Sasa umeweka `departmentId`, itumie kuhifadhi data ya idara ndani ya `departmentsById`.

Weka thamani ya kitu chenye vitu vifuatavyo katika `departmentsById[departmentId]`:

`id`: weka thamani ya `departmentId`,  
`code`: weka thamani ya `departmentData.Dept_code`,  
`name`: weka thamani ya `departmentName`  
`programIds`: safu ya data tupu (utajaza hii katika hatua zijazo)

Mwisho, andika `departmentsById[departmentId]` kwenye konsoli.
