# --description--

Da Sie jetzt eine `departmentId` haben, verwenden Sie diese, um die Daten der Abteilung in `departmentsById` zu speichern.

Weisen Sie `departmentsById[departmentId]` ein Objekt zu, das Folgendes enthält:

`id`: setzen Sie auf `departmentId`,  
`code`: setzen Sie auf `departmentData.Dept_code`,  
`name`: setzen Sie auf `departmentName`  
`programIds`: ein leeres Array (dies füllen Sie in späteren Schritten aus)

Protokollieren Sie zuletzt `departmentsById[departmentId]` in der Konsole.
