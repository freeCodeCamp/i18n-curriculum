# --description--

In questo laboratorio, implementerai una struttura dati stack usando funzioni. Uno stack è una struttura dati Last-In-First-Out (LIFO) in cui gli elementi vengono aggiunti e rimossi dalla cima.

Il tuo stack sarà un dizionario il cui valore della chiave `collection` contiene una lista di elementi. La cima dello stack è la fine della lista, quindi l'ultimo elemento nella lista è quello aggiunto più di recente.

**Obiettivo:** Completa le storie utente qui sotto e fai passare tutti i test per completare il laboratorio.

**Storie utente:**

1. Dovresti avere una funzione `init_stack` che restituisce un dizionario con la chiave `collection` impostata su una lista vuota.
1. Dovresti avere una funzione `push` che prende uno stack e un elemento, e aggiunge l'elemento in cima allo stack.
1. Dovresti avere una funzione `pop` che prende uno stack, rimuove e restituisce il suo elemento in cima, oppure restituisce `None` se lo stack è vuoto.
1. Dovresti avere una funzione `peek` che prende uno stack, e restituisce il suo elemento in cima senza rimuoverlo, oppure restituisce `None` se lo stack è vuoto.
1. Dovresti avere una funzione `is_empty` che prende uno stack, e restituisce `True` se non contiene elementi, e `False` altrimenti.
1. Dovresti avere una funzione `clear` che prende uno stack, e rimuove tutti i suoi elementi.

**Nota:** La maggior parte dei test dipende dalle funzioni `init_stack` e `push`. Implementale prima, perché i test per `pop`, `peek`, `is_empty` e `clear` richiedono di aggiungere elementi allo stack.

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
