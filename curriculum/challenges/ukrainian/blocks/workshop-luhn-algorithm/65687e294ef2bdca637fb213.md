# --description--

Нехай `n` — це кількість символів у вхідному номері картки. Ваша реалізація має **часову складність O(n)**. Переклад і обертання рядка займають лінійний час. Створення зрізів непарних і парних позицій також займає лінійний час, а два цикли разом обробляють кожну цифру один раз. Додавання цих лінійних операцій все одно дає O(n).

Завершіть свій валідатор, повернувши, чи ділиться `total` на `10` без остачі.

def is_valid_card_number(card_number):
    card_translation = str.maketrans({'-': '', ' ': ''})
    card_number = card_number.translate(card_translation)

    sum_of_odd_digits = 0
    card_number_reversed = card_number[::-1]
    odd_digits = card_number_reversed[::2]

    for digit in odd_digits:
        sum_of_odd_digits += int(digit)

    sum_of_even_digits = 0
    even_digits = card_number_reversed[1::2]
    for digit in even_digits:
        number = int(digit) * 2
        if number >= 10:
            number = (number // 10) + (number % 10)
        sum_of_even_digits += number
    total = sum_of_odd_digits + sum_of_even_digits
