# --description--

Jetzt müssen Sie mögliche Probleme behandeln. Was passiert, wenn der Benutzer auf die Schaltfläche „Search“ klickt, ohne etwas in das Eingabefeld einzugeben?

Im Moment nimmt die Funktion diesen leeren String und gibt `" is available to borrow!"` zurück. Das ist nicht sehr hilfreich.

In solchen Situationen können Sie das Schlüsselwort `throw` verwenden, um einen `new Error()` zu werfen und die Ausführung der Funktion zu stoppen. Zum Beispiel:

```js
throw new Error("Your error message goes here");
```

Fügen Sie vor Ihrer erfolgreichen `return`-Anweisung eine `if`-Anweisung hinzu, die überprüft, ob der `title`-Parameter strikt gleich einem leeren String (`""`) ist.

Verwenden Sie innerhalb der `if`-Anweisung das Schlüsselwort `throw`, um einen `new Error()` zu werfen.
Geben Sie den genauen String `"Search field cannot be empty"` an den `Error`-Konstruktor weiter.

**Hinweis:** Wenn Sie nach dem Schreiben darauf klicken, erscheint nichts auf dem Bildschirm! Der Fehler stoppt den Click-Handler, weil er noch nicht abgefangen wird. Das beheben Sie in ein paar Schritten. Sie können aber jetzt schon die Konsole überprüfen, um zu bestätigen, dass Ihr Code funktioniert.
