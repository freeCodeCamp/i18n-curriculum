## 튜플이란 무엇인가요?

튜플은 값을 순서대로 나열한 수열을 만들 때 사용하는 Python 데이터 유형입니다. 튜플은 다음과 같이 다양한 데이터 유형을 혼합해서 담을 수 있습니다:

```py
developer = ('Alice', 34, 'Rust Developer')
```

쉼표가 튜플을 만들기 때문에, 이런 할당에서는 소괄호가 선택 사항입니다:

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

하나의 요소를 가진 튜플을 만들려면, 뒤에 쉼표가 필요합니다:

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

빈 튜플은 `()`로 작성합니다.

튜플은 리스트와 비슷하지만, 리스트가 변경 가능한 데이터 유형인 반면 튜플은 변경 불가능합니다. 즉, 튜플이 생성된 후에는 그 안의 요소를 변경할 수 없습니다.

튜플의 항목 중 하나를 수정하려고 하면 `TypeError`가 발생합니다:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## 튜플 요소 접근하기

튜플의 요소에 접근하려면 대괄호 표기법과 인덱스 번호를 사용할 수 있습니다:

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

튜플의 끝에서부터 요소에 접근해야 할 경우 음수 인덱싱을 사용할 수 있습니다. 다음은 튜플에서 끝에서 두 번째 요소에 음수 인덱스를 사용해 접근하는 예입니다:

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

튜플 길이보다 크거나 같은 인덱스 번호를 전달하면 다음과 같이 `IndexError`가 발생합니다:

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## `tuple()` 생성자 사용하기

튜플을 만드는 또 다른 방법은 `tuple()` 생성자를 사용하는 것입니다:

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

`tuple()` 생성자에는 문자열, 리스트, 심지어 다른 튜플 같은 다양한 반복 가능한 객체를 전달할 수 있습니다.

## 튜플에 요소가 있는지 확인하기

튜플에 특정 항목이 있는지 확인하려면 `in` 키워드를 사용할 수 있습니다:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## 튜플에서 값 풀기

리스트에서 했던 것처럼 튜플에서도 항목을 언팩할 수 있습니다:

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

이 예에서 `name`는 `'Alice'` 값을 가지며, `age`는 `34` 값을, `job`는 `'Rust Developer'` 값을 가집니다.

튜플에서 나머지 요소들을 모두 수집해야 할 경우 별표(`*`) 연산자를 사용할 수 있습니다:

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

여기서 `name`는 `'Alice'` 값을 가지며, `rest`는 숫자 `34`와 문자열 `'Rust Developer'`로 이루어진 리스트입니다.

## 동시에 할당할 때 튜플 사용하기

할당의 오른쪽에 튜플을 만들고 왼쪽 변수들에 언팩할 수 있습니다:

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

Python은 오른쪽의 모든 표현식을 평가한 후 왼쪽 변수에 값을 할당합니다. 이를 통해 임시 변수를 쓰지 않고 두 값을 교환할 수 있습니다:

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## 함수에서 튜플 반환하기

함수는 `return` 뒤에 쉼표로 구분된 값을 두어 튜플을 반환할 수 있습니다:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

쉼표로 구분된 값들이 하나의 튜플을 만들고 함수가 이를 반환합니다. 여기서 `return first, second`는 `return (first, second)`와 같으며, 소괄호는 선택 사항입니다.

반환된 튜플을 변수에 바로 언팩할 수 있습니다:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## 튜플 슬라이싱하기

리스트와 마찬가지로 튜플에서도 슬라이스 연산자를 사용해 일부를 추출할 수 있습니다. 다음은 `'pie'`와 `'cookies'` 항목을 별도의 튜플로 추출하는 예입니다:

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

첫 번째 숫자는 추출 시작 인덱스를 나타내고 두 번째 숫자는 종료 인덱스를 나타냅니다. 단, 종료 인덱스에 해당하는 항목은 추출된 튜플에 포함되지 않는다는 점을 기억하세요.

## 튜플 비교하기

Python은 튜플을 사전식으로 비교합니다. 즉, 왼쪽에서 오른쪽으로 대응하는 요소들을 비교하며, 첫 번째 다른 쌍이 결과를 결정합니다:

```py
print((1, 9) < (2, 0)) # True
```

여기서 `1`은 `2`보다 작으므로 첫 번째 튜플이 더 작습니다. Python은 `9`와 `0`을 비교할 필요가 없습니다.

첫 번째 요소가 같으면 Python은 다음 쌍으로 넘어갑니다:

```py
print((1, 3) < (1, 5)) # True
```

두 튜플 모두 `1`로 시작하므로 Python은 `3`과 `5`를 비교해 결과를 결정합니다.

모든 대응 요소가 같으면 더 짧은 튜플이 더 작습니다. 길이가 같고 대응 요소가 모두 같은 튜플은 같습니다:

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

첫 번째 다른 쌍의 값들은 순서 비교를 지원해야 합니다. 그렇지 않으면 Python은 `TypeError`를 발생시킵니다:

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

여기서는 첫 번째 요소가 같지만, Python은 정수 `3`과 문자열 `'five'`를 순서대로 비교할 수 없습니다.

이전 쌍이 이미 결과를 결정했다면 이후 요소들은 비교할 필요가 없습니다:

```py
print((1, 3) < (2, 'five')) # True
```

## 튜플에서 요소 제거하기

튜플에서 항목을 제거해야 한다면, 튜플은 변경 불가능하므로 불가능합니다. 따라서 이 예제는 오류가 발생할 것입니다:

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## 튜플과 리스트 중 선택하기

그렇다면 언제 리스트 대신 튜플을 사용해야 할까요?

요소를 추가, 제거, 업데이트할 수 있는 동적인 요소 모음이 필요하다면 리스트를 사용하세요. 고정되고 변경 불가능한 데이터 모음으로 작업한다면 튜플을 사용하세요.
