# --description--

Im Moment weiß ein `program`, zu welcher Abteilung es gehört, anhand von `departmentId`, aber die Abteilung weiß noch nicht, welche Programme zu ihr gehören.
Fügen Sie jede `program.id` in `departmentsById[departmentId].programIds` ein.

Das erzeugt eine zweiseitige Beziehung: Die Abteilung kann ihre Programme über `programIds` nachschlagen, und jedes Programm kann seine Abteilung über `departmentId` finden, ohne dass eines der Objekte die vollständigen Daten des anderen speichern muss.

Bevor Sie die Programm-IDs hinzufügen, löschen Sie `console.log(programsById[program.id])` aus dem vorherigen Schritt.

Geben Sie `departmentsById[departmentId]` in der Konsole aus, nachdem die Schleife über `departmentData.programs` beendet ist.
