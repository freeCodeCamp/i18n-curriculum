# --description--

- 再帰は、ベースケースに達するまで関数を繰り返し呼び出すことができるプログラミングの概念です。

以下は、数の階乗を計算する再帰関数の例です。

```py
def find_factorial(n):
    if n == 0:
        return 1
    return n * find_factorial(n - 1)
```

上の例では、`find_factorial` 関数が `n` が `0` に達するまで再帰的に呼び出されます。`n` が `0` のとき、ベースケースに達し関数は `1` を返します。その後、関数は `n` と `find_factorial(n - 1)` の再帰呼び出しの結果の積を返します。

- 再帰は、深くネストされた辞書やリスト、またはファイルツリーのような深さが不明なものを扱うことができます。
- 再帰関数の呼び出しを追跡するためにコールスタックが使われます。関数が呼び出されるたびにコールスタックに追加され、ベースケースに達すると関数呼び出しはスタックから削除されます。
- ベースケースは慎重に定義する必要があります。そうしないと、関数が自分自身を呼び出し続け、Pythonが `RecursionError` を発生させる場合があります。
- 再帰は、階乗やフィボナッチのような数学的問題の解決、ツリーやグラフの走査、順列や組み合わせの生成に役立ちます。
