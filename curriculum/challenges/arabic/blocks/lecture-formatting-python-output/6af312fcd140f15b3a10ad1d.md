# --description--

في درس سابق عن الأعداد والعمليات الرياضية، استخدمت مواصفة تنسيق مثل `.2f` في f-string للتحكم في عدد المنازل العشرية التي يظهرها الرقم.

يمكن لمواصفات التنسيق أيضًا التحكم في مقدار المساحة التي يشغلها القيمة ومكان وضعها. هذا مفيد عندما تريد أن تصطف المخرجات في أعمدة مرتبة.

## تعيين الحد الأدنى للعرض والمحاذاة

الرقم بعد النقطتين يحدد الحد الأدنى لعرض الحقل، وهو عدد الأحرف التي يجب أن تشغلها القيمة. إذا كانت القيمة أقصر من ذلك، تضيف Python مسافات حتى تصل إلى هذا العرض. إليك مثالًا:

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

استخدام رموز محددة قبل العرض يتحكم في مكان وضع القيمة داخل الحقل. هذه هي الرموز المحددة:

- أقل من (`<`) يحاذي القيمة إلى اليسار
- أكبر من (`>`) يحاذي القيمة إلى اليمين
- مؤشر الإدراج (`^`) يوسّط القيمة.

إليك هذه الرموز الثلاثة أثناء العمل:

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

تحتوي `'Tea'` على ثلاثة أحرف، لذا تضيف Python خمسة مسافات لتصل إلى عرض `8`.

- مع `<`، تذهب المسافات بعد القيمة
- مع `>`، تذهب المسافات قبلها
- مع `^`، تُقسّم المسافات بين الجانبين لتوسيط النص.

إذا لم يمكن تقسيم المساحة بالتساوي، تذهب المساحة الزائدة إلى اليمين:

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

إذا تركت رمز المحاذاة، تُحاذى السلاسل النصية إلى اليسار افتراضيًا، بينما تُحاذى الأعداد إلى اليمين:

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## استخدام حرف الحشو

افتراضيًا، تحشو Python بالمسافات. لاستخدام حرف مختلف للحشو، أدخل الحرف مباشرة قبل رمز المحاذاة:

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

في `*^9`، `*` هو حرف الحشو، و`^` يوسّط القيمة، و`9` هو الحد الأدنى للعرض. لاحظ أنه يمكنك استخدام حرف الحشو فقط مع رمز المحاذاة.

## دمج العرض والدقة

يمكنك دمج المحاذاة والعرض مع الدقة التي تعلمتها في الدرس السابق، كلها في مواصفة تنسيق واحدة:

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

تعني مواصفة التنسيق في المثال أعلاه: المحاذاة إلى اليمين، استخدام حد أدنى للعرض `7`، وعرض منزلتين عشريتين. تُنسق Python الرقم كـ `4.50` أولًا، وهو أربعة أحرف، ثم تضيف ثلاث مسافات أمامه لملء العرض `7`.

## بناء صف بيان

يمكنك وضع مسمى ومبلغ معًا في سطر واحد. إذا استخدمت نفس مواصفة التنسيق لكل صف، تصطف الأعمدة:

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

يُحاذى كل مسمى إلى اليسار في حقل عرضه `12` حرفًا ومُحشو بالنقاط، بينما يُحاذى كل مبلغ إلى اليمين في حقل عرضه `8` أحرف، بحيث تصطف الفواصل العشرية.

## العرض هو حد أدنى، وليس حدًا أقصى

العرض يضيف الحشو فقط. لا يختصر القيمة. إذا كانت القيمة أطول من العرض المحدد، تُعرض القيمة كاملة:

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

ينطبق نفس الشيء على الأعداد. في المثال أدناه، يحتاج المبلغ المنسق إلى ثمانية أحرف، لذا يتجاهل العرض المحدد `7`:

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

في `:7.2f`، الرقم `7` هو الحد الأدنى للعرض، وليس حدًا لطول المبلغ. لا تقطع Python الأرقام لجعلها تناسب العرض.

لهذا يجب اختيار عروض كبيرة بما يكفي للقيم التي تتوقعها، وإلا لن تصطف الأعمدة.

إذا أردت تحديد طول السلسلة النصية، أضف دقة إلى مواصفة التنسيق. بالنسبة للسلاسل النصية، تحدد الدقة الحد الأقصى لعدد الأحرف المعروضة:

```py
label = 'Long description'

print(f'|{label:.8}|') # |Long des|
print(f'|{label:<12.8}|') # |Long des    |
```

في `<12.8`:

- `<` يحاذي القيمة إلى اليسار
- `12` هو الحد الأدنى للعرض
- `.8` هو الحد الأقصى لعدد الأحرف.

تقص Python السلسلة إلى ثمانية أحرف أولًا، ثم تحشوها لتصل إلى عرض اثني عشر.

لاحظ أن الدقة تعني شيئًا مختلفًا للسلاسل النصية عنها للأعداد. مع `.2f`، تحدد `.2` عدد المنازل العشرية. مع السلسلة النصية، تحدد `.8` الحد الأقصى لعدد الأحرف.
