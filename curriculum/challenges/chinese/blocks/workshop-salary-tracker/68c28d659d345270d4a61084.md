# --description--

`__repr__` 方法是一个特殊的方法，应该返回一个可以用来实例化该对象的字符串表现。

例如，`Employee('Charlie', 'developer')` 的 `__repr__` 方法应返回字串 `Employee('Charlie', 'developer')`，该字串与用于创建该对象的字串相同。

如果你在每个值周围加上引用，当值中包含引用时结果会出错。对于一个名为 `O'Reilly`、级别为 `junior` 的员工，你会得到 `Employee('O'Reilly', 'junior')`，这不是有效的，因为撇号提前关闭了字串。

Python 的内置 `repr()` 函数返回一个值的字串表现形式。对于字串，它会添加引用并转义任何需要转义的字符：

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

在 f-string 中，你可以在表达式后添加 `!r` 来应用 `repr()`：

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

为你的 `Employee` 类添加一个带有 `self` 参数的 `__repr__` 方法。让它返回一个可以用来实例化对象的字串，对 `self.name` 和 `self.level` 使用 `!r`，以便保留任何引用或反斜线。
