# --description--

Neste laboratório, você vai implementar operações adicionais para uma estrutura de dados lista ligada, com base na classe `LinkedList` que criou na oficina anterior.

**Objetivo:** Cumprir as user stories abaixo e fazer todos os testes passarem para completar o laboratório.

**Histórias de Usuário:**

1. Sua classe `LinkedList` deve ter um método `contains` que recebe um elemento como argumento. Ele deve retornar `True` se o elemento existir na lista ligada e `False` caso contrário.
1. Sua classe `LinkedList` deve ter um método `get_at` que recebe um índice como argumento. Ele deve retornar o elemento no índice dado na lista ligada. Se o índice estiver fora dos limites, deve retornar `None`.
1. Sua classe `LinkedList` deve ter um método `insert_at` que recebe um índice e um elemento como argumentos. Ele deve inserir o elemento na posição dada na lista ligada e atualizar o atributo `length`. Um índice igual ao comprimento da lista é válido e deve adicionar o elemento no final. Se o índice estiver fora dos limites, não deve modificar a lista.
1. Sua classe `LinkedList` deve ter um método `remove_at` que recebe um índice como argumento. Ele deve remover o nó no índice dado na lista ligada e atualizar o atributo `length`. Se o índice estiver fora dos limites, não deve modificar a lista.
1. Sua classe `LinkedList` deve ter um método `clear` que remove todos os elementos da lista ligada, resetando-a para um estado vazio com `head` definido como `None` e `length` definido como `0`.

**Nota:** Alguns testes posteriores dependem de métodos anteriores. Por exemplo, se `get_at` não for implementado corretamente, testes para métodos como `insert_at` e `remove_at` podem falhar mesmo quando esses métodos estiverem quase corretos.

class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
