# --description--

このワークショップでは、オーケストラコンサートのプログラムを計画しながらリストの扱いを練習します。

前のレッスンで学んだように、リストは順序付けられたアイテムの集合です。リストは、カンマで区切ったアイテムを大括弧の中に入れて作成します。

```py
fruits = ['apple', 'banana', 'cherry']
```

`pieces` という名前の変数を作成し、`Carnival Overture`、`Song to the Moon`、`Silent Woods` の文字列をこの順番で含むリストを代入してください。
