## ما هي الدوال؟

الدوال هي قطع قابلة لإعادة الاستخدام من الكود تُنفذ عند استدعائها. يوفر Python دوال مدمجة، منها `print()` التي استخدمتها في الدروس السابقة.

دالة مدمجة مفيدة أخرى هي `input()`، التي تتيح لك طلب مُدخَل من المستخدم:

```python
name = input('What is your name?') # User types "Kolade" and presses Enter  
print('Hello', name) # Output: Hello Kolade
```

من ناحية أخرى، تقوم الدالة `int()` بتحويل رقم أو قيمة منطقية أو سلسلة نصية تمثل عددًا صحيحًا إلى عدد صحيح:

```python
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0 
```

## تعريف واستدعاء الدوال

يمكنك أيضًا كتابة دوال مخصصة خاصة بك. للقيام بذلك، استخدم الكلمة المفتاحية `def`، تليها الاسم الذي تريد إعطاءه للدالة، ثم زوج من الأقواس العادية، ونقطتين. بعد ذلك، في سطر جديد، اكتب الكود الذي يجب أن تنفذه الدالة. يُشار إلى الكود الذي تنفذه الدالة أيضًا باسم جسم الدالة.

إليك مثال على دالة مخصصة اسمها `hello` تطبع السلسلة النصية `Hello World` في الطرفية:

```python
def hello():
    print('Hello World')
```

لتشغيل الدالة، عليك استدعاؤها باسمها متبوعًا بزوج من الأقواس العادية:

```python
hello() # Hello World
```

لاحظ المسافة البادئة قبل `print('Hello World')`. كما تتذكر من الدروس السابقة، يعتمد Python على المسافة البادئة لتحديد مجموعات العبارات التي تنتمي معًا. تُسمى هذه المجموعات من العبارات كتل الكود.

## استخدام المعلمات والمعلمات

إليك دالة بسيطة أخرى تطبع مجموع رقمين في الطرفية:

```python
def calculate_sum(a, b):
    print(a + b)
```

يمكنك أن ترى أن دالتنا، `calculate_sum`، تحتوي على `a` و `b` داخل الأقواس العادية، مفصولتين بفاصلة. تُسمى هذه المعلمات. فكر في المعلمات كمتغيرات عنصر نائب تعمل كـ "فتحات" للقيم التي تمررها إلى الدوال عند استدعائها.

لاستخدام المعلمات، عليك تمرير "المعلمات". المعلمات هي القيم التي تمررها إلى الدالة عند استدعائها.

إليك كيفية استدعاء دالة `calculate_sum` لجمع الرقمين `3` و `1`:

```python
calculate_sum(3, 1) # 4
```

إذا استدعيت الدالة بدون العدد الصحيح من المعلمات، ستحصل على `TypeError`:

```python
calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

## المعلمات الموضعية والمعلمات المسماة

المعلمات في `calculate_sum(3, 1)` هي معلمات موضعية. تطابق Python هذه المعلمات مع المعلمات حسب موقعها: `3` تذهب إلى `a`، و`1` تذهب إلى `b`.

إليك دالة يكون فيها ترتيب المعلمات مهمًا:

```python
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

إذا قمت بتبديل المعلمات الموضعية، يستقبل `name` القيمة `25` ويستقبل `age` القيمة `'Alice'`:

```python
introduce(25, 'Alice')
# My name is 25 and I am Alice years old.
```

يمكنك أيضًا تمرير المعلمات المسماة بكتابة اسم المعلمة متبوعًا بـ `=` وقيمة. تطابق Python هذه المعلمات حسب الاسم، لذا يمكنك كتابتها بترتيب مختلف:

```python
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

هنا، `name='Alice'` تمرر `'Alice'` إلى المعلمة `name`. لا يتم تعيين متغير باسم `name` خارج الدالة.

يمكنك دمج المعلمات الموضعية والمعلمات المسماة، لكن يجب أن تأتي المعلمات الموضعية أولًا:

```python
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

وضع معلمة موضعية بعد معلمة مسماة يسبب `SyntaxError`:

```python
introduce(name='Alice', 25)
# SyntaxError: positional argument follows keyword argument
```

لا يمكنك أيضًا تزويد قيمة لنفس المعلمة أكثر من مرة:

```python
introduce('Alice', name='Bob', age=25)
# TypeError: introduce() got multiple values for argument 'name'
```

في هذا الاستدعاء، المعلمة الموضعية `'Alice'` تزود القيمة للمعلمة `name`. تمرير `name='Bob'` يزود قيمة ثانية لنفس المعلمة.

## إرجاع القيم من الدوال

تستخدم الدوال أيضًا الكلمة المفتاحية الخاصة `return` للخروج من الدالة وإرجاع قيمة. إذا لم تستخدم `return` صراحة، ستُرجع Python `None` افتراضيًا.

كما تعلمت في درس عوامل الهوية، `None` تمثل غياب القيمة. هنا، تشير إلى أن الدالة لم ترجع نتيجة صريحة.

إليك مثالاً:

```python
def calculate_sum(a, b):
    print(a + b)

my_sum = calculate_sum(3, 1) # 4
print(my_sum) # None
```

يمكنك أن ترى أن دالة `calculate_sum` تطبع مجموع `a` و `b`، لكنها لا تُرجع شيئًا صراحة. لذلك عندما نُعيّن نتيجتها إلى `my_sum`، تكون القيمة فعليًا `None`. لإصلاح ذلك، يمكنك استخدام الكلمة المفتاحية `return` لإرسال النتيجة:

```python
def calculate_sum(a, b):
    return a + b

my_sum = calculate_sum(3, 1)
print(my_sum) # 4
```

الآن، تُرجع `calculate_sum` مجموع `a` و `b`، الذي يُخزن في `my_sum`.
