# --description--

## ما هو الصف المرتب؟

الصف المرتب هو نوع بيانات في Python يُستخدم لإنشاء متتالية مرتبة من القيم. يمكن أن تحتوي الصفوف المرتبة على مجموعة مختلطة من أنواع البيانات مثل هذا:

```py
developer = ('Alice', 34, 'Rust Developer')
```

الفواصل تُنشئ الصف المرتب، لذا الأقواس العادية اختيارية في التعيين مثل هذا:

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

لإنشاء صف مرتب يحتوي على عنصر واحد، تحتاج إلى فاصلة لاحقة:

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

يُكتب الصف المرتب الفارغ كـ `()`.

الصفوف المرتبة تشبه القوائم، لكن بينما القوائم نوع بيانات قابل للتغيير، الصفوف المرتبة غير قابلة للتغيير. هذا يعني أنه بمجرد إنشاء الصف المرتب، لا يمكن استبدال مراجع عناصره أو إضافتها أو إزالتها.

إذا حاولت تحديث أحد العناصر في الصف المرتب، ستحصل على `TypeError`:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## الكائنات القابلة للتغيير داخل الصفوف المرتبة

يمكن أن يحتوي الصف المرتب على كائن قابل للتغيير، مثل قائمة. عدم قابلية تغيير الصف المرتب لا يمنع التغييرات على ذلك الكائن المحتوى:

```py
def add_greeting(values):
    values[0].append('hi')

greetings = (['hello'],)
original_list = greetings[0]

add_greeting(greetings)
print(greetings) # (['hello', 'hi'],)
print(greetings[0] is original_list) # True
```

الدالة تُغير القائمة داخل الصف المرتب. الصف المرتب لا يزال يحتفظ بمرجع لنفس القائمة. تعيين قائمة مختلفة إلى `greetings[0]` سيرجع `TypeError`، لأن ذلك سيُستبدَل مرجع عنصر الصف المرتب.

## الوصول إلى عناصر الصف المرتب

للوصول إلى عنصر من صف مرتب، يمكنك استخدام ترميز الأقواس ورقم الفهرس:

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

إذا كنت بحاجة إلى الوصول إلى عناصر بدءًا من نهاية الصف المرتب، يمكنك استخدام الفهرسة السالبة. إليك مثالًا على استخدام فهرس سالب للوصول إلى العنصر قبل الأخير في الصف المرتب:

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

إذا حاولت تمرير رقم فهرس يتجاوز أو يساوي طول الصف المرتب، فستتلقى `IndexError` مثل هذا:

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## استخدام دالة البناء `tuple()`

طريقة أخرى لإنشاء صف مرتب هي باستخدام دالة البناء `tuple()` مثل هذا:

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

بالنسبة إلى دالة البناء `tuple()`، يمكنك تمرير أنواع مختلفة من القابلات للتكرار مثل السلاسل النصية، القوائم، وحتى الصفوف المرتبة الأخرى.

## التحقق مما إذا كان عنصر موجودًا في الصف المرتب

للتحقق مما إذا كان عنصر موجودًا في صف مرتب، يمكنك استخدام الكلمة المفتاحية `in` مثل هذا:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## فك القيم من صف مرتب

يمكنك أيضًا فك تجميع العناصر من صف مرتب تمامًا كما فعلت مع القوائم:

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

في هذا المثال، القيمة في `name` هي `'Alice'`، والقيمة في `age` هي `34`، والقيمة في `job` هي `'Rust Developer'`.

إذا كنت بحاجة إلى جمع أي عناصر متبقية من صف مرتب، يمكنك استخدام عامل النجمة (`*`) مثل هذا:

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

هنا، القيمة في `name` هي `'Alice'`، و`rest` هي قائمة تتألف من الرقم `34` والسلسلة النصية `'Rust Developer'`.

## استخدام الصفوف المرتبة في التعيين المتزامن

يمكنك إنشاء صف مرتب على الجانب الأيمن من التعيين وفكّه إلى المتغيرات على الجانب الأيسر:

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

تُقيّم Python كل التعبيرات على الجانب الأيمن قبل تعيين قيمها إلى المتغيرات على الجانب الأيسر. هذا يسمح لك بتبديل قيمتين بدون متغير مؤقت:

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## إرجاع صف مرتب من دالة

يمكن للدالة إرجاع صف مرتب بوضع قيم مفصولة بفواصل بعد `return`:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

القيم المفصولة بفواصل تُنشئ صفًا مرتبًا واحدًا تُرجعه الدالة. هنا، `return first, second` يعادل `return (first, second)`. الأقواس العادية اختيارية.

يمكنك فك الصف المرتب المرجع مباشرة إلى متغيرات:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## تقطيع الصفوف المرتبة

تمامًا كما في القائمة، يمكنك استخدام عامل القطع على صف مرتب لاستخراج جزء منه. إليك مثالًا لاستخراج العناصر `'pie'` و`'cookies'` إلى صف مرتب منفصل:

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

تذكر أن الرقم الأول يمثل فهرس البداية للاستخراج بينما الرقم الثاني يمثل فهرس النهاية. لكن لاحظ أن العنصر عند فهرس النهاية غير مشمول في الصف المرتب المستخرج.

## مقارنة الصفوف المرتبة

تُقارن Python الصفوف المرتبة بطريقة معجمية. هذا يعني أنها تُقارن العناصر المقابلة من اليسار إلى اليمين. الزوج الأول غير المتساوي يحدد النتيجة:

```py
print((1, 9) < (2, 0)) # True
```

هنا، `1` أقل من `2`، لذا الصف المرتب الأول أصغر. لا تحتاج Python لمقارنة `9` و `0`.

إذا كانت العناصر الأولى متساوية، تنتقل Python إلى الزوج التالي:

```py
print((1, 3) < (1, 5)) # True
```

كلا الصفين يبدأان بـ `1`، لذا تُقارن Python `3` مع `5` لتحديد النتيجة.

إذا كانت كل العناصر المقابلة متساوية، يكون الصف المرتب الأقصر أصغر. الصفوف المرتبة ذات الطول نفسه والعناصر المقابلة المتساوية متساوية.

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

يجب أن تدعم القيم في الزوج الأول غير المتساوي مقارنة الترتيب. وإلا، تُرجع Python `TypeError`:

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

هنا، العناصر الأولى متساوية، لكن Python لا يمكنها ترتيب العدد الصحيح `3` والسلسلة النصية `'five'`.

العناصر اللاحقة لا تحتاج لأن تكون قابلة للمقارنة إذا كان الزوج السابق قد حدد النتيجة بالفعل:

```py
print((1, 3) < (2, 'five')) # True
```

## إزالة عناصر من صف مرتب

إذا كنت بحاجة إلى إزالة عنصر من صف مرتب، فهذا غير ممكن لأن الصفوف المرتبة غير قابلة للتغيير. لذا هذا المثال سينتج عنه خطأ:

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## الاختيار بين الصفوف المرتبة والقوائم

متى قد تستخدم صف مرتب بدلًا من قائمة؟

إذا كنت تحتاج إلى مجموعة ديناميكية من العناصر حيث يمكنك الإضافة والإزالة والتحديث، فاستخدم قائمة. إذا كنت تحتاج إلى متتالية تبقى مراجع عناصرها ثابتة، يمكنك استخدام صف مرتب. تذكر أن أي كائنات قابلة للتغيير يحتويها يمكن أن تتغير.

في الدرس التالي، سنلقي نظرة على بعض الطرق الشائعة التي ستستخدمها عند العمل مع الصفوف المرتبة.
