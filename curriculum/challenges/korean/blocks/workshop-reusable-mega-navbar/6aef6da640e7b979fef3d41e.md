# --description--

`sub-menu`를 열고 닫으려면 `Navbar` 컴포넌트가 `sub-menu`가 현재 열려 있는지 기억해야 합니다. 컴포넌트가 기억하고 시간이 지나면서 변할 수 있는 데이터를 상태라고 합니다. 상태가 변경될 때마다 React는 컴포넌트를 다시 렌더링하여 페이지에 새 값을 보여줍니다.

앞으로의 수업에서 상태에 대해 더 많이 배우게 됩니다. 지금은 `useState` 훅으로 함수형 컴포넌트에 상태를 추가할 수 있다는 것만 알면 됩니다. 훅은 컴포넌트에서 React 기능을 사용할 수 있게 해주는 특별한 함수입니다. 이 워크숍에서는 `script` 요소로 React가 로드되어 있으므로 `React.useState`로 훅에 접근할 수 있습니다:

```jsx
const [count, setCount] = React.useState(0);
```

`React.useState`는 상태의 초기값을 인수로 받고, 두 개의 항목이 들어 있는 배열을 반환하는데, 여기서는 배열 구조 분해로 이를 풀어냅니다:

- `count`는 현재 값을 담고 있는 상태 변수입니다.
- `setCount`는 상태를 업데이트하기 위해 호출하는 설정 함수입니다.

`Navbar` 컴포넌트 안에서 `React.useState`를 사용해 `isOpen`이라는 상태 변수와 `setIsOpen`이라는 설정 함수를 만드세요. `sub-menu`는 처음에 닫혀 있어야 하므로 초기값으로 `false`를 주세요.
