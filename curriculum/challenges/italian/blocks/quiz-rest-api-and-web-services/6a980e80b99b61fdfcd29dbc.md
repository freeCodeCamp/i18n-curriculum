Qual è la relazione tra un'API e un web service?

#### --distractors--

Ogni API è un web service, ma non ogni web service è un'API.

---

API e web service sono concetti identici.

---

### --question--

#### --text--

Quale delle seguenti affermazioni è vera riguardo SOAP rispetto a REST?

#### --distractors--

SOAP usa JSON ed è più flessibile di REST, quindi ideale per applicazioni moderne.

---

SOAP è il tipo di web service più usato oggi, avendo sostituito REST nella maggior parte dei sistemi.

---

SOAP supporta più formati di risposta, incluso testo semplice, JSON e dati binari.

#### --answer--

SOAP usa solo XML ed è comune nei sistemi enterprise che richiedono standard e sicurezza più rigidi.

### --question--

#### --text--

Qual è un vantaggio chiave dei microservizi rispetto a un monolite?

#### --distractors--

Debugging più semplice e meno chiamate di rete tra i servizi.

---

Un unico codice condiviso a cui contribuiscono tutti i team.

---

Gestione dell'infrastruttura più facile su tutti i servizi.

#### --answer--

Sviluppo più veloce, migliore isolamento dei guasti e possibilità di usare linguaggi diversi per ogni servizio.

### --question--

#### --text--

Quale delle seguenti è una sfida nell'adottare un'architettura a microservizi?

#### --distractors--

Un unico codice condiviso che rende facile coordinare le modifiche.

---

Sono necessarie meno chiamate di rete tra i componenti.

---

Il debugging diventa più semplice poiché tutto il codice gira in un unico processo.

#### --answer--

Il debugging diventa più complesso e c'è un maggiore overhead di rete tra i servizi.
