# --description--

Finalmente, para a propriedade `box-shadow` do marcador azul, substitua a cor nomeada pela função `hsla`.

A função `hsla` funciona exatamente como a função `hsl`, mas adiciona um quarto valor, alpha, que controla a opacidade da cor. Assim como com `rgba`, o valor alpha é um número de `0` a `1.0`. Aqui está a sintaxe básica:

```css
hsla(hue, saturation, lightness, alpha);
```

Use os valores `223` para matiz, `59%` para saturação, `31%` para luminosidade e `0.8` para o canal alpha.

E com isso, sua oficina de conjunto de marcadores coloridos está completa! Muito bem.

# --hints--
