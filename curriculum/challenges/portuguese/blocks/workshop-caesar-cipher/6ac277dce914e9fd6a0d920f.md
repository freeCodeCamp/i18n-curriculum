# --description--

Em Python, `bool` é uma subclasse de `int`, onde `True` se comporta como `1` e `False` como `0`. Isso significa que `isinstance()` trata valores booleanos como inteiros:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True
```

Por causa disso, sua função atualmente aceita `True` e `False` como valores de shift.
