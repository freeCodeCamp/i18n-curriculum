# --description--

- **Рекурсія**: техніка, у якій функція викликає сама себе. Кожен виклик працює з меншою версією початкової проблеми, доки не досягне базового випадку, який зупиняє подальші рекурсивні виклики.
- **Базовий випадок**: умова, яка зупиняє рекурсію. Ви повинні ретельно визначити базовий випадок. Інакше функція може продовжувати викликати сама себе, доки Python не викличе `RecursionError`.
- **Рекурсивний випадок**: частина функції, яка викликає функцію знову з аргументом, що наближає її до базового випадку, наприклад `number - 1` при зворотному відліку.

```py
def recursive_countdown(number):
    if number < 1:  # Base case
        return
    print(number)
    recursive_countdown(number - 1)  # Recursive case

recursive_countdown(5)  # Prints 5, 4, 3, 2, 1
```

- **Порядок виконання**: позиція рекурсивного виклику змінюється залежно від того, коли виконується інший код функції. Код, розміщений перед рекурсивним викликом, виконується під час заглиблення викликів, а код після нього — під час повернення викликів. Переміщення `print()` після рекурсивного виклику змушує функцію виводити числа у зростаючому порядку:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)  # Prints 1, 2, 3, 4, 5
```

- **Стек викликів**: структура даних типу останній увійшов — перший вийшов, яку Python використовує для відстеження активних викликів функцій. Кожного разу, коли викликається функція, Python додає кадр для цього виклику на вершину стеку. Кадр містить інформацію, таку як аргументи функції та локальні змінні.
- **Відновлення викликів**: виклик призупиняється, коли робить свій рекурсивний виклик. Коли базовий випадок повертається, Python видаляє цей виклик з вершини стеку, а попередні виклики відновлюються після свого рекурсивного виклику і повертаються у порядку останній увійшов — перший вийшов:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

Вихідні дані такі:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

- **Побудова списку рекурсивно**: кожен виклик відновлюється, коли його рекурсивний виклик повертає результат, а потім використовує це повернене значення. Функція `countup` нижче повертає порожній список у базовому випадку. Кожен інший виклик отримує список від свого рекурсивного виклику, додає своє число і повертає список:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(5))  # [1, 2, 3, 4, 5]
```

Виклик з `1` отримує `[]` і повертає `[1]`, виклик з `2` отримує `[1]` і повертає `[1, 2]`, і так далі, доки виклик з `5` не поверне `[1, 2, 3, 4, 5]`.

- **Застосування рекурсії**: рекурсія може впоратися з простими завданнями, такими як зворотний відлік, підрахунок вгору та побудова списку. Вона також корисна для задач з невідомою глибиною, наприклад, для обходу дерева файлів.
