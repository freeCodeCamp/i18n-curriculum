# --description--

In diesem Workshop üben Sie den Umgang mit `while`-Schleifen, indem Sie eine Funktion erstellen, die einen Aufzug simuliert, der zwischen Etagen fährt.

Definieren Sie eine Funktion namens `run_elevator` mit zwei Parametern: `requests`, eine Liste der Etagen, zu denen der Aufzug fahren soll, und `start_floor`, die Etage, auf der der Aufzug startet.

Erstellen Sie innerhalb der Funktion eine Variable namens `current_floor` und weisen Sie ihr `start_floor` zu.
