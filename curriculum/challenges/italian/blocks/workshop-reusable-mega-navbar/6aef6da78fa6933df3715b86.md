# --description--

L'ultima cosa da fare è aggiornare lo stato `isOpen` quando si clicca il pulsante `Apps`.

In React, rispondi agli eventi passando una funzione a un attributo evento su un elemento. Questi attributi sono scritti in camelCase, quindi un clic si gestisce con `onClick`:

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

Nota che `onClick` riceve una funzione. React chiama quella funzione ogni volta che il pulsante viene cliccato. Chiamare la funzione setter con un nuovo valore aggiorna lo stato, e React poi renderizza di nuovo il componente con quel nuovo valore.

Per alternare uno stato booleano tra `true` e `false`, puoi passare il valore opposto di quello attuale alla funzione setter usando l'operatore logico NOT (`!`).

Aggiungi un attributo `onClick` all'elemento `button`. Dagli una funzione freccia che chiama `setIsOpen` con il valore opposto di `isOpen`.

Clicca il pulsante `Apps` per aprire e chiudere il `sub-menu`.

Con questo, il tuo componente `Navbar` è completo!

# --hints--

Cliccando il pulsante `Apps` dovrebbe impostare il suo attributo `aria-expanded` su `"true"` e aggiungere la classe `sub-menu--open` al `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

Cliccando una seconda volta il pulsante `Apps` dovrebbe impostare di nuovo il suo attributo `aria-expanded` su `"false"` e rimuovere la classe `sub-menu--open` dal `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
