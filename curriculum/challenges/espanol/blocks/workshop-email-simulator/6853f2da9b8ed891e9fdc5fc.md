# --description--

Es hora de mostrar la información del remitente y del receptor. Para que los nombres se alineen ordenadamente uno debajo del otro, da al texto delante de cada nombre un ancho fijo con un especificador de formato.

Agrega dos sentencias de imprimir al método `display_full_email`:

- `'From:'` alineado a la izquierda con un ancho de `10`, seguido del nombre del remitente.
- `'To:'` alineado a la izquierda con un ancho de `10`, seguido del nombre del receptor.

Por ejemplo, con `Alice` como remitente y `Bob` como receptor, las dos líneas se verían así:

```md
From:     Alice
To:       Bob
```
