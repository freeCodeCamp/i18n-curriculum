# --description--

لقد تعلمت أن الأسماء تشير إلى الكائنات وأن القوائم قابلة للتغيير. دعنا نرى ماذا يحدث عندما يشير أكثر من اسم إلى نفس القائمة.

## مقارنة القوائم المتساوية والأسماء المستعارة

يمكن لقائمتين أن تحتويان على قيم متساوية دون أن تكونا نفس الكائن. تذكر أن `==` يتحقق من المساواة، بينما `is` يتحقق من الهوية:

```py
items = ['milk']
equal_items = ['milk']
alias = items

print(items == equal_items) # True
print(items is equal_items) # False
print(items is alias) # True
```

كل تعبير `['milk']` ينشئ قائمة منفصلة. مع ذلك، `alias = items` لا ينشئ نسخة. إنه يربط اسمًا آخر بالقائمة الموجودة. نسمي هذا الاسم الآخر اسمًا مستعارًا.

تغيير القائمة من خلال أي من الاسمين يظهر من خلال الاسم الآخر:

```py
items = ['milk']
equal_items = ['milk']
alias = items

alias.append('eggs')
print(items) # ['milk', 'eggs']
print(alias) # ['milk', 'eggs']
print(equal_items) # ['milk']
```

القائمة المنفصلة `equal_items` لم تتغير.

## تعديل قائمة عبر معلمة دالة

يتم تمرير المعلمات عبر التعيين. المعلمة هي اسم محلي مرتبط مبدئيًا بالكائن الذي يزوده المستدعي. Python لا تنسخ ذلك الكائن تلقائيًا.

هنا، المعلمة `items` ومتغير المستدعي `groceries` يشيران إلى نفس القائمة:

```py
def add_item(items):
    items.append('eggs')

groceries = ['milk']
add_item(groceries)
print(groceries) # ['milk', 'eggs']
```

استدعاء `append()` يعدل القائمة المشتركة. الدالة لا تحتوي على عبارة `return`، لذا ترجع `None`، لكن التغيير في القائمة لا يزال مرئيًا للمستدعي.

إعادة تعيين المعلمة المحلية لها تأثير مختلف:

```py
def replace_items(items):
    items = ['bread']

groceries = ['milk']
replace_items(groceries)
print(groceries) # ['milk']
```

التعيين يجعل الاسم المحلي `items` يشير إلى قائمة جديدة. لا يغير القائمة الأصلية أو يعيد تعيين متغير المستدعي `groceries`.

## إرجاع قائمة جديدة

يمكن للدالة إنشاء قائمة جديدة وإرجاعها بدلًا من تعديل القائمة المقدمة. عامل `+` يربط القوائم، مكونًا قائمة خارجية جديدة تحتوي على عناصرها:

```py
def with_extra_item(items):
    return items + ['eggs']

groceries = ['milk']
alias = groceries

groceries = with_extra_item(groceries)
print(groceries) # ['milk', 'eggs']
print(alias) # ['milk']
print(groceries is alias) # False
```

يقوم المستدعي بتعيين القائمة المرجعة إلى `groceries`. الاسم `alias` لا يزال يشير إلى القائمة الأصلية. استدعاء الدالة بدون تعيين أو استخدام قيمة الإرجاع يترك `groceries` تشير إلى تلك القائمة الأصلية أيضًا.

الربط ينشئ قائمة خارجية جديدة، لكنه لا ينسخ أي كائنات مسكنة. إذا كان العنصر نفسه قائمة، تحتوي القائمة الخارجية الجديدة على مرجع لتلك القائمة الداخلية نفسها.

## مقارنة `+` و `+=` للقوائم

بالنسبة للقوائم المدمجة، `items = items + [...]` ينشئ قائمة جديدة ويعيد تعيين `items`. بالمقابل، `items += [...]` يوسع القائمة الموجودة في مكانها:

```py
def add_with_plus(items):
    items = items + ['eggs']

def add_with_plus_equals(items):
    items += ['eggs']

groceries = ['milk']
alias = groceries

add_with_plus(groceries)
print(groceries) # ['milk']
print(alias) # ['milk']

add_with_plus_equals(groceries)
print(groceries) # ['milk', 'eggs']
print(alias) # ['milk', 'eggs']
```

في الدالة الأولى، الاسم المحلي فقط يشير إلى القائمة الجديدة. في الثانية، القائمة المشتركة تُعدل، والاسم المحلي لا يزال يشير إليها. لهذا السبب، لا يمكن استبدال `+=` بعملية الجمع متبوعة بالتعيين عندما توجد مراجع أخرى للقائمة.

## استخدام قائمة كمعلمة افتراضية

المعلمة الافتراضية توفر قيمة عندما يحذف المستدعي تلك المعلمة. إذا استخدمت قائمة فارغة كافتراضية، تنشئ Python تلك القائمة مرة واحدة عند تعريف الدالة. الاستدعاءات التي تحذف المعلمة تعيد استخدام نفس القائمة:

```py
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item('milk')) # ['milk']
print(add_item('eggs')) # ['milk', 'eggs']
```

الاستدعاء الثاني يستقبل القائمة التي غيرها الاستدعاء الأول. رغم أن لكل استدعاء اسم معلمة محلي خاص به، إلا أن ذلك الاسم يشير إلى نفس الكائن الافتراضي. القائمة لا تصبح فارغة مرة أخرى بين الاستدعاءات.

إذا كان يجب أن يبدأ كل استدعاء بقائمة جديدة عندما لا تُزود قائمة، استخدم `None` كافتراضي وأنشئ القائمة داخل الدالة:

```py
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item('milk')) # ['milk']
print(add_item('eggs')) # ['eggs']
```

هنا، `items = []` يُنفذ في كل مرة تُحذف المعلمة أو تُمرر صراحة كـ `None`، مما ينشئ قائمة جديدة لذلك الاستدعاء.

لا يزال بإمكانك تمرير قائمة موجودة ليتم تعديلها:

```py
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

groceries = []
add_item('milk', groceries)
add_item('eggs', groceries)
print(groceries) # ['milk', 'eggs']
```

التحقق `items is None` يميز بين القائمة المفقودة والقائمة الفارغة التي يزودها المستدعي. استخدام `if not items` سيطابق القائمة الفارغة أيضًا ويستبدلها بأخرى جديدة، لذا القائمة الفارغة للمستدعي لن تستقبل العنصر المضاف.

## تكرار المراجع إلى القوائم المسكنة

رأيت كيف يمكن لتكرار القائمة إنشاء قائمة مثل `[0] * 3`. التكرار ينشئ قائمة خارجية جديدة، لكنه يكرر المراجع لعناصرها بدلًا من نسخ تلك العناصر.

هذا مهم عندما يكون العنصر قابلًا للتغيير:

```py
rows = [[]] * 3
print(rows) # [[], [], []]
print(rows[0] is rows[1]) # True

rows[0].append('hello')
print(rows) # [['hello'], ['hello'], ['hello']]
```

التعبير `[[]]` ينشئ قائمة داخلية واحدة. تكرارها يضع مراجع لتلك القائمة الداخلية نفسها في كل المواقع الثلاثة. تعديلها عبر `rows[0]` يظهر في كل موقع.

مع `numbers = [0] * 3`، تعيين `numbers[0] = 1` يستبدل مرجع عنصر واحد؛ لا يعدل العدد الصحيح غير القابل للتغيير `0`. لهذا تبقى المواقع الأخرى `0`.

إذا كنت تحتاج قوائم داخلية منفصلة، أنشئ كل واحدة على حدة:

```py
rows = [[], [], []]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

فيما بعد في هذه الوحدة، ستتعلم كيف تنشئ تراكيب القوائم عددًا مختارًا من القوائم الداخلية المنفصلة.
