# --description--

Per aggiungere un elemento in una posizione specifica, puoi usare il metodo `insert()`. Prende l'indice in cui il nuovo elemento deve essere inserito, seguito dall'elemento stesso. Gli elementi da quell'indice in poi si spostano di una posizione a destra:

```py
fruits = ['apple', 'banana', 'cherry']
fruits.insert(1, 'blueberry')
print(fruits) # ['apple', 'blueberry', 'banana', 'cherry']
```

Il direttore d'orchestra vuole che i due balli slavi vengano eseguiti uno dopo l'altro. Usa `insert()` per aggiungere la stringa `Slavonic Dance No. 1` a `pieces`, proprio prima di `Slavonic Dance No. 8`.
