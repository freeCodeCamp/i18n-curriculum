# --description--

É hora de mostrar as informações do remetente e do destinatário. Para alinhar os nomes de forma organizada um abaixo do outro, dê ao texto na frente de cada nome uma largura fixa usando um especificador de formato.

Adicione duas declarações de imprimir ao método `display_full_email`:

- `'From:'` alinhado à esquerda com largura de `10`, seguido pelo nome do remetente.
- `'To:'` alinhado à esquerda com largura de `10`, seguido pelo nome do destinatário.

Por exemplo, com `Alice` como remetente e `Bob` como destinatário, as duas linhas ficariam assim:

```md
From:     Alice
To:       Bob
```
