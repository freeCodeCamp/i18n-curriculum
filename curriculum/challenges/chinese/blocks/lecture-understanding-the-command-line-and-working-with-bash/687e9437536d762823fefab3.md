# --description--

让我们了解你可以使用的命令行快捷，以加快生产力。

终端和命令行快捷可以帮助你简化工作流程并最大化你的生产力。对于 Linux 和 macOS，这两者都可以追溯到 Unix，许多这些快捷将是相同的。但对于 Windows，会有一些差异。

## <kbd>上箭头</kbd> 和 <kbd>下箭头</kbd> 快捷键

第一个快捷键是 <kbd>上箭头</kbd> 键。按下这个键可以让你一次向后浏览一条命令历史。然后，<kbd>下箭头</kbd> 键可以用来向前浏览命令历史。这两个键让你能够快速浏览之前运行过的命令，找到需要再次运行的命令。

## 使用 <kbd>Tab</kbd> 键自动补全

许多 shell 还提供自动补全功能，根据你开始输入的内容推荐命令。<kbd>Tab</kbd> 键可以用来补全建议的剩余部分，快速填充你的命令行完整语法。具体建议内容取决于 shell、你正在输入的命令以及 shell 的配置。例如，当你输入命令名称时，Bash 和 zsh 会建议匹配的命令；当你输入参数时，它们通常建议匹配的文件和目录名称。PowerShell 可以补全命令、参数名称、变量和文件路径。

## <kbd>Control</kbd> + <kbd>L</kbd> 快捷键

有时命令会在终端产生大量输出。这些额外的信息可能会干扰你的工作流程。在基于 *nix 的 Linux 和 macOS 终端中，你可以按 <kbd>Control</kbd> + <kbd>L</kbd> 清除整个屏幕，开始一个干净的提示符。在 PowerShell 中，<kbd>Control</kbd> + <kbd>L</kbd> 也默认清屏，你还可以运行 `cls` 命令达到同样效果。

## <kbd>Control</kbd> + <kbd>C</kbd> 快捷键

如果你需要中止命令执行，可以按 <kbd>Control</kbd> + <kbd>C</kbd>。这会向前台运行的命令发送中止请求，通常会停止该命令并返回一个新的提示符，让你继续处理其他任务。有些程序会自行处理这个请求，可能会要求你确认或继续运行。对于 PowerShell 用户，<kbd>Control</kbd> + <kbd>C</kbd> 也用于拷贝文本——只有在没有选中文本拷贝时，它才会中止命令。

## 基于 *nix 的终端快捷键

接下来的几个快捷只在基于 *nix 的终端中可用，且没有 PowerShell 备选。

有时你需要多任务处理，在处理另一个任务时暂停当前命令。按 <kbd>Control</kbd> + <kbd>Z</kbd> 会挂起前台运行的命令，并返回命令行，让你继续工作。挂起的命令是暂停状态，不再运行。如果你想让它在后台继续运行，使用 `bg` 命令；当你需要将它恢复到前台时，使用 `fg` 命令。

最后，有些命令你可能需要连续运行两次。你可以按 <kbd>上箭头</kbd> 键向后浏览到之前运行的命令，也可以在命令行输入两个感叹号（`!!`）并按 <kbd>Enter</kbd> ——这会自动运行上一次执行的命令。
