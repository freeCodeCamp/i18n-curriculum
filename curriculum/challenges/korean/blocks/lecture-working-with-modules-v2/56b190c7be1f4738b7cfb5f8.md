# --description--

이전 수업에서 배운 것처럼, 모듈은 관련된 코드를 묶은 Python 파일로, 다른 Python 파일에서 재사용할 수 있습니다.

직접 모듈을 작성해서 스크립트에 가져올 수도 있습니다. 직접 모듈을 만드는 것은 코드를 체계적으로 정리하는 좋은 방법입니다. 하나의 아주 긴 파일 대신, 관련 코드를 묶은 작은 파일들로 나누고 필요할 때마다 가져와 사용하세요.

예를 들어, 온도 변환을 위한 두 개의 함수와 그중 하나가 작동하는지 확인하는 함수 호출이 포함된 `temperature.py` 파일을 만들었다고 가정해 보세요:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

이 파일을 직접 실행하면 다음과 같은 출력이 나옵니다:

```md
212.0
```

이제 `temperature.py`와 같은 폴더에 `main.py`라는 다른 파일을 만든다고 가정해 보세요. 로컬 모듈의 함수를 사용하려면 `.py` 확장자를 뺀 모듈 이름으로 가져오세요:

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

`main.py` 파일을 실행하면 다음과 같은 출력이 나옵니다:

```md
212.0
100.0
```

`temperature`가 가져와질 때, Python은 `temperature.py`의 모든 코드를 위에서 아래로 실행합니다. 그래서 `main.py`가 `fahrenheit_to_celsius()`만 호출했는데도 `212.0`이 출력됩니다. 이런 확인용 코드는 보통 파일을 직접 실행할 때만 실행하고, 매번 가져올 때마다 실행하지 않길 원합니다.

이를 제어하려면 흔히 쓰이는 Python 관용구를 사용할 수 있습니다:

```python
if __name__ == '__main__':
    # Code
```

`__name__`는 파이썬 내장 특별 변수입니다.

Python 파일이 직접 실행될 때, Python은 이 변수의 값을 문자열 `__main__`으로 설정합니다.

하지만 파이썬 파일이 다른 파이썬 스크립트에 모듈로 가져와질 경우, `__name__` 변수의 값은 그 모듈 이름(보통 `.py` 확장자를 뺀 파일 이름)으로 설정됩니다.

그래서 Python 스크립트에서 이 조건문을 자주 볼 수 있습니다. 이 조건문 안에는 Python 스크립트가 메인 프로그램으로 실행될 때만 실행하고 싶은 코드가 들어 있습니다. 스크립트가 모듈로 가져와지면 이 블록 안의 코드는 실행되지 않습니다.

이것은 파이썬 스크립트가 두 가지 용도로 사용될 수 있게 해줍니다. 직접 실행되어 주요 로직을 수행하거나, 다른 모듈에 가져와져 주요 로직을 실행하지 않고 사용할 수 있습니다.

다음은 이 관용구를 사용하도록 업데이트된 `temperature.py` 파일입니다. `__name__`의 값도 출력해서 어떻게 변하는지 볼 수 있습니다:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

이 파일을 직접 실행하면 Python이 `__name__`을 `'__main__'`으로 설정해서 조건이 `True`가 되고 `if` 블록 안의 코드가 실행됩니다. 출력은 다음과 같습니다:

```md
The value of __name__ is: __main__
212.0
```

대신 `main.py` 파일을 실행하면 다음과 같은 출력이 나옵니다:

```md
The value of __name__ is: temperature
100.0
```

`if` 블록 밖의 `print()` 호출은 `temperature`가 가져와질 때도 실행되어, `__name__`의 값이 이제 모듈 이름인 `temperature`임을 보여줍니다.

하지만 `__name__`이 `'__main__'`과 같지 않으므로 `if` 블록 안의 코드는 실행되지 않아 `212.0`은 출력되지 않습니다. 다른 출력은 `main.py`의 함수 호출에서 나온 `100.0`뿐입니다.
