# --description--

遞迴呼叫會一次往下走一層樹，但它們需要一個停止的地方。

當往右邊的下一個節點不存在時，`_insert` 會以 `None` 作為 `node` 被呼叫。那就是新值應該放置的空位。現在你的方法會嘗試存取 `None` 的 `node.key`，並引發錯誤。

在 `_insert` 方法的開頭，現有的 `if` 述語之前，加入基底案例：一個檢查 `node is None` 的 `if` 述語，並傳回一個帶有指定 `key` 的新 `TreeNode`。先前的呼叫會將這個新節點指定給其父節點的 `node.left` 或 `node.right`。
