# --description--

En el desarrollo de software, una biblioteca es como una caja de herramientas para desarrolladores.

En lugar de tener que implementar cada parte del código tú mismo desde cero, una biblioteca te ofrece código preescrito y reutilizable, como funciones, clases y estructuras de datos que puedes usar en tus proyectos.

La biblioteca estándar de Python es una colección de módulos y paquetes incluidos con Python. Los paquetes de terceros se desarrollan por separado y generalmente necesitan ser instalados antes de que puedas usarlos. La biblioteca estándar ofrece soluciones para tareas comunes de programación, tales como:

* Interactuando con el sistema operativo.

* Trabajando con archivos.

* Redes.

* Trabajando con fecha y hora.

* Realizando operaciones matemáticas.

* Usando expresiones regulares.

* Probando y depurando tu código.

* ¡Y mucho más!

Algunos ejemplos de módulos de la biblioteca estándar son `math`, `random`, `re` (abreviatura de "expresiones regulares") y `datetime`.

El módulo `math` tiene funciones útiles para realizar operaciones matemáticas más complejas.

El módulo `random` es útil para generar números aleatorios.

El módulo `re` se usa para trabajar con expresiones regulares.

El módulo `datetime` es útil para trabajar con fechas y horas en Python.

Los módulos pueden proporcionar clases además de funciones y constantes. Aquí hay un ejemplo de una clase del módulo `datetime`. Creamos un objeto date que representa el 15 de julio de 1959. Luego, asignamos ese objeto `date` a una variable y accedemos al día, mes y año individualmente usando notación de punto:

```python
import datetime
birthday = datetime.date(1959, 7, 15)
print(birthday.day)    # 15
print(birthday.month)  # 7
print(birthday.year)   # 1959
```

Para encontrar un módulo para una tarea en particular, navega por la [referencia de la biblioteca estándar de Python](https://docs.python.org/3/library/index.html), donde los módulos están agrupados por tema. La documentación de cada módulo explica qué ofrece y cómo usarlo. Por ejemplo, la [documentación de `datetime`](https://docs.python.org/3/library/datetime.html) describe las clases y métodos disponibles para trabajar con fechas y horas.

También puedes usar la función `help()` para mostrar la documentación de un módulo o función. Ten en cuenta que `help()` no está disponible actualmente en el editor de freeCodeCamp.

Por ejemplo, este código muestra información sobre el módulo `math`:

```py
import math
help(math)
```

Aquí hay un extracto de la salida:

```md
Help on built-in module math:

NAME
    math

DESCRIPTION
    This module provides access to the mathematical functions
    defined by the C standard.

FUNCTIONS
    acos(x, /)
        Return the arc cosine (measured in radians) of x.

...
...
...
```

También puedes obtener la documentación de una función específica:

```py
import math
help(math.comb)
```

Este es el resultado:

```md
Help on built-in function comb in module math:

comb(n, k, /)
    Number of ways to choose k items from n items without repetition and without order.
    
    Evaluates to n! / (k! * (n - k)!) when k <= n and evaluates
    to zero when k > n.
    
    Also called the binomial coefficient because it is equivalent
    to the coefficient of k-th term in polynomial expansion of the
    expression (1 + x)**n.
    
    Raises TypeError if either of the arguments are not integers.
    Raises ValueError if either of the arguments are negative.
```

Para descubrir qué nombres proporciona un módulo, puedes usar la función `dir()`. Enumera funciones, como `math.floor` para redondear un número hacia abajo, y constantes, como `math.e` (número de Euler) y `math.pi`. También enumera algunos otros nombres que aprenderás más adelante en el currículo:

```py

print(dir(math))
```
