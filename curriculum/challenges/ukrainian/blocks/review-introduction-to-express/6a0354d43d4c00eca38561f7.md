## Що таке Express.js?

- **Express**: Мінімалістичний і гнучкий веб-фреймворк на базі Node.js, який полегшує створення веб-серверів і API.
- **Встановлення Express**: `npm install express`
- **Що можна створити з Express**: веб-застосунки, RESTful API, бекенди SPA, сервіси з великою кількістю підпрограмного забезпечення, і все, що працює на сервері з HTTP.
- **Підпрограмне забезпечення (middleware)**: Код, який виконується між отриманням запиту і відправленням відповіді. Використовується для обробки помилок, валідації вхідних даних, зміни даних запиту або відповіді тощо. Можна ланцюжком підключати кілька middleware-функцій.
- **Плагіни**: Зовнішні npm-модулі, які розширюють Express, зазвичай реалізовані як middleware.

## Створення базового застосунку Express

```javascript
const express = require("express");
const app = express();
const port = 3000;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

- `require("express")` — завантажує бібліотеку Express.
- `express()` — фабрична функція, яка створює і повертає новий екземпляр застосунку Express.
- `app` — головний об’єкт сервера з доступом до методів, таких як `.get()`, `.post()` і `.listen()`.
- `port` — мережевий кінцевий пункт, на якому застосунок слухає. Порт `3000` часто використовується для локальної розробки.
- `app.listen(port, callback)` — запускає сервер і починає слухати вхідні HTTP-запити.

## Маршрутизація в Express

- **Маршрут**: Правило, яке вказує застосунку, як реагувати, коли клієнт робить запит на певний URL з певним HTTP-методом.
- **Методи маршруту**: `app.get()`, `app.post()`, `app.put()`, `app.delete()` — кожен обробляє запити відповідним HTTP-методом.
- **Статичний шлях маршруту**: Фіксований URL, як `/home` або `/menu/drinks`.
- **Динамічний шлях маршруту (параметр маршруту)**: Заповнювач у URL, який захоплює значення, з префіксом `:`, наприклад `/post/:postId`.
- **`req.params`**: Об’єкт, що містить динамічні значення, захоплені з URL. Наприклад, запит до `/post/42` повертає `req.params.postId === "42"`.

### Обробники маршрутів

- **Обробник маршруту** — це функція зворотного виклику `(req, res) => { ... }`, яка виконується, коли запит відповідає маршруту.
- `req` — містить інформацію про вхідний запит (параметри, рядки запиту, заголовки, тіло).
- `res` — використовується для відправлення відповіді клієнту.

## Методи відповіді

| Метод | Що робить |
| --- | --- |
| `res.send()` | Відправляє відповідь — простий текст, HTML, JSON або бінарні дані. |
| `res.json()` | Відправляє JSON-відповідь; автоматично конвертує JavaScript-об’єкт. |
| `res.status(code)` | Встановлює HTTP-код стану; зазвичай ланцюжком з `res.send()` або `res.json()`. |
| `res.redirect(url)` | Перенаправляє клієнта на інший URL. |
| `res.render(view, data)` | Відтворює шаблон і відправляє отриманий HTML. |

## Ланцюжкові обробники маршрутів з `app.route()`

- `app.route(path)` групує кілька обробників HTTP-методів для одного шляху, щоб уникнути повторення.

```javascript
app
  .route("/user")
  .get((req, res) => { res.send("Fetching user data"); })
  .post((req, res) => { res.send("Creating a user"); })
  .put((req, res) => { res.send("Updating the user"); })
  .delete((req, res) => { res.send("Deleting the user"); });
```

## Модульна маршрутизація з `express.Router()`

- `express.Router()` створює об’єкт маршрутизатора — як маленький застосунок Express — на якому можна визначати маршрути, а потім монтувати його в основний застосунок.
- Монтуйте маршрутизатор за допомогою `app.use(path, router)`. Маршрути всередині маршрутизатора відносні до шляху монтування.
- **Переваги**: розділяє обов’язки, зберігає основний файл чистим, робить маршрути повторно використовуваними і легшими для масштабування.

```javascript
// userRoutes.js
const express = require("express");
const router = express.Router();
router.get("/", (req, res) => { res.send("List of users"); });
router.get("/:id", (req, res) => { res.send(`User ${req.params.id}`); });
module.exports = router;

// app.js
app.use("/users", userRoutes); // mounts the router at /users
```

## Обслуговування статичних файлів

- **Статичні файли**: Ресурси, як-от зображення, CSS і клієнтський JavaScript, які подаються без обробки на сервері.
- `express.static(directory)` — вбудоване підпрограмне забезпечення, яке подає файли з вказаної папки.
- Якщо запитуваний файл не знайдено, Express автоматично відповідає 404.
- Для окремих статичних файлів не потрібні визначення маршрутів.

```javascript
app.use(express.static(path.join(__dirname, "public")));
```

- Ви можете подавати файли з кількох директорій, викликаючи `app.use()` кілька разів, за бажанням із шляхом монтування:

```javascript
app.use(express.static(path.join(__dirname, "public")));
app.use("/images", express.static(path.join(__dirname, "images")));
```
