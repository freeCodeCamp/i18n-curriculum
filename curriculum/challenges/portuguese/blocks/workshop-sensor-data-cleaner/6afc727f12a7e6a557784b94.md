# --description--

Para obter um rótulo para cada diferença, você precisa de uma expressão condicional antes do `for` em vez de um `if` no final:

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

Remova o `if` no final da sua list comprehension. Depois, mude a expressão antes do `for` para uma expressão condicional que avalie para `f'+{difference} °C'` se `difference` for maior que `0` e para `f'{difference} °C'` em vez disso. Números negativos já têm o sinal `-`, então só precisam da unidade.
