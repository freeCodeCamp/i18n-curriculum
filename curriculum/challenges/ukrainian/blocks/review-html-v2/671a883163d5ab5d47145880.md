## Основи HTML

- **Роль HTML**: HTML (Hypertext Markup Language) є основою структури вебсторінки, визначаючи елементи сторінки.
- **Елементи HTML**: Використовуються для представлення вмісту на сторінці. Більшість з них складаються з відкриваючого та кінцевого тегів (наприклад, `<h1></h1>`, `<p></p>`).
- **Структура HTML**: HTML складається з `head` та `body`, де структуровані метадані, стилі та вміст.
- **Загальні елементи HTML**: Заголовки (`<h1>` - `<h6>`), абзаци (`<p>`) та контейнери div (`<div>`).
- **Елементи `div`**: Елемент `div` — це загальний HTML-елемент, який не має семантичного значення. Використовується як загальний контейнер для інших HTML-елементів.
- **Порожні елементи**: Не мають кінцевого тегу (наприклад, `<img>`).
- **Атрибути**: Додають метадані та поведінку елементам.

## Ідентифікатори та групування

- **Ідентифікатори (ID)**: Унікальні ідентифікатори елементів.
- **Класи**: Групування елементів для стилізації та поведінки.

## Шаблонний код і кодування

- **Шаблонний код HTML**: Базова структура вебсторінки, що включає елементи `DOCTYPE`, `html`, `head` та `body`. Його слід використовувати як відправну точку для HTML-документа.
- **Кодування символів UTF-8**: Забезпечення універсального відображення символів.

## Важливість семантичного HTML

- **Структурна ієрархія для заголовків**: Важливо використовувати правильний заголовок, щоб зберегти структурну ієрархію вмісту. Елемент `h1` є найвищим рівнем заголовка, а `h6` — найнижчим.
- **Семантичні HTML-елементи**: Ці елементи надають значення структурі вмісту. Приклади включають:
  - `<header>`: представляє вступний вміст.
  - `<nav>`: містить навігаційні посилання.
  - `<article>`: представляє автономний вміст.
  - `<section>`: групує пов’язаний вміст у документі.
  - `<footer>`: визначає нижній колонтитул для розділу або документа.
  - `<blockquote>`: використовується для представлення цитованого розділу з іншого джерела. Використовуйте джерело як значення атрибута `cite`.
  - `<q>`: використовується для короткої рядкової цитати.

## Елементи та атрибути форм HTML

### Форми

- **Елемент `form`**: використовується для створення HTML-форми для введення користувачем.
- **Загальні типи вхідних даних**:
  - `text`, `email`, `radio`, `checkbox`, `number`.
- **Атрибут `action`**: використовується для вказівки URL, куди мають бути надіслані дані форми.
- **Атрибут `method`**: використовується для вказівки HTTP-методу, який слід застосувати при надсиланні даних форми. Найпоширеніші методи — `GET` і `POST`.

```html
<form method="value-goes-here" action="url-goes-here">
  <!-- inputs go inside here -->
</form>
```

- **`input` елемент**: використовується для створення поля введення для користувача.
- **`type` атрибут**: використовується, щоб вказати тип поля введення, наприклад, `text`, `email`, `number`, `radio`, `checkbox`.
- **`placeholder` атрибут**: використовується, щоб показати підказку користувачу, що потрібно ввести у поле введення.
- **`value` атрибут**: використовується, щоб вказати значення поля введення.
- **`name` атрибут**: використовується, щоб призначити ім’я полю введення, яке слугує ключем при відправленні даних форми. Для радіокнопок, якщо призначити однакове `name`, вони об’єднуються в групу, і можна вибрати лише одну опцію з групи одночасно.
- **`size` атрибут**: використовується, щоб визначити кількість символів, які мають бути видимі під час введення в поле.
- **`min` атрибут**: може використовуватися з типами введення, такими як `number`, щоб вказати мінімальне допустиме значення в полі введення.
- **`max` атрибут**: може використовуватися з типами введення, такими як `number`, щоб вказати максимальне допустиме значення в полі введення.
- **`required` атрибут**: використовується, щоб вказати, що поле введення має бути заповнене перед відправленням форми.

:::interactive_editor

```html
<!-- Text input -->
<input 
  type="text"
  id="name"
  name="name"
  placeholder="e.g. Quincy Larson"
  size="20"
  required
/>

<!-- Number input -->
<input 
  type="number"
  id="quantity"
  name="quantity"
  min="2"
  max="10"
/>
```

:::

- **Елемент `label`**: використовується для створення мітки для поля введення.
- **Атрибут `for`**: використовується, щоб вказати, для якого поля введення призначена мітка.

:::interactive_editor

```html
<form action="">
  <label for="email">Email Address: </label>
  <input type="email" id="email" />
</form>
```

:::

- **Елемент `button`**: використовується для створення активної кнопки. Кнопка також може мати атрибут `type`, який контролює поведінку кнопки при її активації.

:::interactive_editor

```html
<button type="submit">Submit Form</button>
```

:::

- **Елемент `fieldset`**: використовується для групування пов’язаних полів введення.
- **Елемент `legend`**: використовується для додавання підпису, що описує групу полів введення.

:::interactive_editor

```html
<!-- Radio group -->
<fieldset>
  <legend>Was this your first time at our hotel?</legend>

  <input id="yes-option" type="radio" name="hotel-stay" value="yes" />
  <label for="yes-option">Yes</label>

  <input id="no-option" type="radio" name="hotel-stay" value="no" />
  <label for="no-option">No</label>
</fieldset>

<!-- Checkbox group -->
<fieldset>
  <legend>
    Why did you choose to stay at our hotel? (Check all that apply)
  </legend>

  <input type="checkbox" id="location" name="location" value="location" />
  <label for="location">Location</label>

  <input type="checkbox" id="price" name="price" value="price" />
  <label for="price">Price</label>
</fieldset>
```

:::

## Робота з елементами та атрибутами таблиць HTML

- **Елемент таблиці**: використовується для створення HTML-таблиці.
- **Елемент заголовка таблиці (`thead`)**: використовується для групування заголовкового вмісту в HTML-таблиці.
- **Елемент рядка таблиці (`tr`)**: використовується для створення рядка в HTML-таблиці.
- **Елемент заголовної клітинки таблиці (`th`)**: використовується для створення заголовної клітинки в HTML-таблиці.
- **Елемент тіла таблиці (`tbody`)**: використовується для групування основного вмісту в HTML-таблиці.
- **Елемент клітинки даних таблиці (`td`)**: використовується для створення клітинки з даними в HTML-таблиці.
- **Елемент нижнього колонтитула таблиці (`tfoot`)**: використовується для групування нижнього колонтитула в HTML-таблиці.
- **Елемент `caption`**: використовується для додавання заголовка HTML-таблиці.
- **Атрибут `colspan`**: використовується для вказівки кількості стовпців, які має охоплювати клітинка таблиці.

:::interactive_editor

```html
<table>
  <caption>Exam Grades</caption>

  <thead>
    <tr>
      <th>Last Name</th>
      <th>First Name</th>
      <th>Grade</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Davis</td>
      <td>Alex</td>
      <td>54</td>
    </tr>

    <tr>
      <td>Doe</td>
      <td>Samantha</td>
      <td>92</td>
    </tr>

    <tr>
      <td>Rodriguez</td>
      <td>Marcus</td>
      <td>88</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <td colspan="2">Average Grade</td>
      <td>78</td>
    </tr>
  </tfoot>
</table>
```

:::

## Доступність

- **Керівництво з доступності веб-вмісту**: Керівництво з доступності веб-вмісту (WCAG) — це набір принципів для підвищення доступності веб-вмісту для людей з інвалідністю. Чотири принципи WCAG — POUR, що означає сприйнятливість, керованість, зрозумілість і надійність.
- **Важливість якісного тексту `alt`**: Ви повинні використовувати атрибут `alt`, щоб надати текстову альтернативу для зображень. Це допомагає допоміжним технологіям розуміти вміст зображення.
- **Важливість якісного тексту посилання**: Використовуйте описовий текст посилання, щоб допомогти користувачам зрозуміти призначення посилання.
