# --description--

Der Gültigkeitsbereich bestimmt, wo Sie eine Variable in Ihrem Code verwenden können.

Python hat zusätzliche Regeln für den Gültigkeitsbereich. Konzentrieren Sie sich vorerst auf den lokalen und globalen Gültigkeitsbereich.

Eine Variable, die außerhalb einer Funktion erstellt wird, hat globalen Gültigkeitsbereich. Sie können sie sowohl innerhalb als auch außerhalb von Funktionen verwenden.

Eine Variable, die innerhalb einer Funktion erstellt wird, hat lokalen Gültigkeitsbereich. Sie können sie nur innerhalb dieser Funktion verwenden. Funktionsparameter sind ebenfalls lokale Variablen.

Hier ist ein Beispiel für lokalen und globalen Gültigkeitsbereich:

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

Die Variable `tax_rate` ist global, weil sie außerhalb der Funktion erstellt wurde. Die Funktion `calculate_tax` kann sie lesen, und auch der zweite `print()`-Aufruf kann sie lesen.

Der Parameter `price` und die Variable `tax` sind lokal für `calculate_tax`. Sie sind verfügbar, solange diese Funktion läuft, aber nicht außerhalb davon. Der letzte `print()`-Aufruf löst einen `NameError` aus, weil `tax` im globalen Gültigkeitsbereich nicht definiert ist.
