# --description--

`type` 속성은 브라우저에 `input`이 어떤 종류의 데이터를 받아야 하는지 알려줍니다. `type` 속성의 일반적인 값들은 다음과 같습니다:

- `text`: 한 줄 텍스트 필드
- `email`: 사용자가 유효한 이메일 주소를 입력했는지 확인하는 텍스트 필드
- `number`: 숫자를 위한 필드
- `radio`와 `checkbox`: 사용자가 선택할 수 있는 옵션

다음은 텍스트 입력의 예입니다:

```html
<input type="text">
```

기존 `input` 요소에 `type` 속성을 `"text"`로 추가하세요.

또한 `input` 요소에 `id` 속성을 `"full-name"` 값으로 지정하세요. 이 값은 `label` 요소의 `for` 속성과 일치하여 두 요소를 연결합니다.

사용자가 전체 이름을 입력하면 `input`은 일반 텍스트를 받습니다.
