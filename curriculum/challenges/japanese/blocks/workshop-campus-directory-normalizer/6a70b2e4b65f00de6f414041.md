# --description--

各部署には `programs` 配列がネストされています。既存のループの中に2つ目の `for` ループを追加し、`j = 0` から `departmentData.programs.length` まで `departmentData.programs` を繰り返してください。

この新しいループの中で、`program` という変数を宣言し、`departmentData.programs[j]` を代入してコンソールにログを出力してください。

コードから `console.log(departmentsById[departmentId])` の行も削除してください。
