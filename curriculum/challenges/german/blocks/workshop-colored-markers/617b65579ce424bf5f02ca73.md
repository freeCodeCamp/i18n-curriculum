# --description--

Ein <dfn>Farbmodell</dfn> ist ein System zur Darstellung von Farben. Es gibt zwei Hauptfarbmodelle: das <dfn>additive</dfn> RGB-Modell, das in elektronischen Geräten verwendet wird, und das <dfn>subtraktive</dfn> CMYK-Modell (Cyan, Magenta, Gelb, Schwarz), das im Druck eingesetzt wird.

In diesem Projekt arbeiten Sie mit dem RGB-Modell. RGB steht für Rot, Grün und Blau, die Grundfarben des Lichts. Diese drei Farben werden in verschiedenen Schattierungen kombiniert, um eine große Farbpalette zu erzeugen. Bei RGB beginnen die Farben als Schwarz und ändern sich, wenn unterschiedliche Mengen von Rot, Grün und Blau hinzugefügt werden.

Eine Möglichkeit, dies zu sehen, ist die CSS-`rgb`-Funktion, mit der Sie Farben mithilfe des RGB-Farbmodells definieren können.

Erstellen Sie eine neue CSS-Regel, die die Klasse `container` anspricht, und setzen Sie deren `background-color` mit `rgb(0, 0, 0)` auf Schwarz.
