# --description--

有时候数字用于计算没问题，但打印出来看起来有点不完整。例如，显示价格时，`12.50` 可能比 `12.5` 更自然。

f-string 让你控制数字显示的样式，而不改变原始值，这样你还能继续用它做计算。

## 格式规格说明是如何工作的

表达式 `f"{value:.2f}"` 会显示 `value`，小数点后正好两位数字。

花括弧内，每个字符都有特定作用：

- 冒号 `:` 引入格式规格说明
- `.2` 选择两位小数
- `f` 选择不动点形式，以十进制显示数字。

这意味着 `print(f"{12.5:.2f}")` 会输出 `12.50`，但初始值保持不变：

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

输出显示 `12.50`，因为 `.2f` 格式规格说明总是显示两位小数，所以 Python 用尾随零补齐。`value` 中保存的值仍然是 `12.5`。


另一方面，用 `.2f` 格式化像 `12.3456` 这样的值会得到 `12.35`，因为数字必须四舍五入后显示：

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## 用 F-String 格式化会产生一个字串

f-string 会产生一个字串：

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

这意味着你可以单独保存结果字串，同时仍然用原始数字做计算。

## `round()` 与 F-String 格式化的区别

像 `round(value, 2)` 这样的表达式会给你一个数值结果，可以继续用于计算。

打印该结果时，Python 使用通常的数字显示方式，所以尾随零不一定会显示：

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## 格式化不会改变底层值

正如你之前看到的，像 `0.1` 和 `0.2` 这样的十进制数字只能近似为浮点数。因此，它们的和直接打印时可能看起来有点意外：

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

如你所见，f-string 会对和进行四舍五入以供显示。任何使用 `total` 的计算仍然使用相同的浮点数值。
