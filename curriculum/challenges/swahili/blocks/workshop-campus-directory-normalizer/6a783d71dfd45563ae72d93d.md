# --description--

Sasa ongeza mzunguko wa tatu ndani ya mzunguko wa programu ili upite juu ya kila mwalimu.
Tumia `for...of` kupita juu ya safu ya data ya `program["instructors"]`. Tumia `instructor` kama kigezo cha mzunguko na andika kila kitu cha mwalimu kwenye kumbukumbu.

Pia unapaswa kuondoa mstari wa `console.log(program)` kutoka kwenye msimbo wako.

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, "log");
const getLogs = () => globalThis.spy.calls.map(call => call?.[0]);
```

# --after-each--

```js
globalThis.spy.restore();
delete globalThis.spy;
```

```js
assert.notMatch(
  __helpers.removeJSComments(code),
  /console\s*\.\s*log\s*\(\s*program\s*\)/
);
```

Unapaswa kuunda mzunguko wa `for...of` unaorudia juu ya `program['instructors']`.

```js
assert.match(
  __helpers.removeJSComments(code),
  /for\s*\(\s*(?:const|let)\s+instructor\s+of\s+program\s*\[\s*['"]instructors['"]\s*\]\s*\)\s*\{[\s\S]*\}/
);
```

Unapaswa kuandika `instructor` kwenye konsoli ndani ya mzunguko.

```js
const expectedInstructors = Object.values(rawData)
  .flatMap(dept => dept.programs)
  .flatMap(program => program.instructors);

const logs = getLogs();

assert.isTrue(
  expectedInstructors.every(instructor =>
    logs.some(log => JSON.stringify(log) === JSON.stringify(instructor))
  )
);
```
