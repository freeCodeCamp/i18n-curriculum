# --description--

如果 `key` 既不小於也不大於 `node.key`，你就找到了要刪除的節點。如何刪除它取決於它的子節點。

如果該節點沒有左子節點，它的右子節點可以取代它。這也涵蓋了沒有子節點的節點：在那種情況下，`node.right` 也是 `None`，所以該節點會被 `None` 取代。

為你的第二個 `if` 述語添加一個 `else` 語句。在裡面，添加一個 `if` 述語來檢查 `node.left` 是否為 `None`，並從中傳回 `node.right`。
