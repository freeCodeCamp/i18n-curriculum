## بايثون في بيئة العمل المحلية الخاصة بك

- **التثبيت**: أفضل طريقة لتثبيت Python على Windows وMac وLinux هي تنزيل المثبت من الموقع الرسمي لـ Python (`https://www.python.org/`).
- **الطرفية**: واجهة نصية تتيح لك التفاعل مع الكمبيوتر عبر كتابة الأوامر. كل نظام تشغيل يأتي مع تطبيق طرفية افتراضي. على macOS، يمكنك استخدام تطبيق Terminal. على Windows، يمكنك استخدام Command Prompt أو PowerShell. على Linux، لكل بيئة سطح مكتب تطبيق طرفية افتراضي خاص بها، مثل GNOME Terminal أو Konsole.
- **IDE**: IDE تعني بيئة العمل المتكاملة وتحتوي على ميزات تشمل محرر كود، أدوات اختبار، طرفية والمزيد.
- **محررات الكود وبيئات العمل الشائعة لـ Python**: VS Code، PyCharm، وSpyder
- **تشغيل الكود محليًا**: لتشغيل كود Python، لديك عدة خيارات. الخيار الأول هو النقر على زر التشغيل في VS Code الذي يشبه زر التشغيل الموجود في الزاوية العلوية اليمنى. هذا سيفتح طرفية ويشغل سكريبت Python الخاص بك هناك.

الخيار الآخر هو فتح طرفية وتشغيل البرنامج يدويًا. إليك مثال لتشغيل برنامج يسمى `main.py`:

```bash
python main.py
```

يجب تشغيل هذا الأمر من المجلد الذي تم حفظ `main.py` فيه. على سبيل المثال، إذا كان `main.py` داخل مجلد يسمى `python-projects`، استخدم أولاً الأمر التالي في الطرفية:

```bash
cd python-projects
```

ثم شغّل:

```bash
python main.py
```

## استخدام القشرة التفاعلية لبايثون

- **التعريف**: القشرة التفاعلية هي برنامج يتيح لك كتابة الأوامر واحدة تلو الأخرى ورؤية النتائج. افتح تطبيق الطرفية واكتب `python` ثم اضغط <kbd>Enter</kbd>. سيبدأ هذا قشرة تفاعلية للغة Python. الرمز `>>>` يعني أن Python تنتظر منك كتابة أمر. جرّب طباعة `"Hello, world!"` في الطرفية:

```bash
print("Hello, world!")
```

يجب أن ترى النص يظهر هكذا:

```bash
>>> print("Hello, world!")
Hello, world!
```

بعد طباعة النص، تعود بايثون إلى التالي:

```bash
>>>
```

هذا يعني أنه يمكنك كتابة أمر آخر.

- **دورة القراءة، التقييم، الطباعة، التكرار (REPL)**: كلما كتبت أوامر، سيقرأ المفسر المُدخل، يُقيّمه، يطبع النتيجة، ثم يعود ليعرض `>>>` لتتمكن من كتابة المزيد من الأوامر.
