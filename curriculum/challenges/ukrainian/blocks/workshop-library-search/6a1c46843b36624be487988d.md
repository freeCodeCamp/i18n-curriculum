# --description--

Тепер потрібно опрацювати потенційні проблеми. Що якщо користувач натисне на кнопку «Пошук», нічого не ввівши у поле введення?

Зараз функція приймає цей порожній рядок і повертає `" is available to borrow!"`. Це не дуже корисно.

У таких ситуаціях можна використати ключове слово `throw`, щоб викинути `new Error()` і зупинити виконання функції. Наприклад:

```js
throw new Error("Your error message goes here");
```

Перед успішною інструкцією `return` додайте інструкцію `if`, яка перевіряє, чи параметр `title` строго дорівнює порожньому рядку (`""`).

Всередині інструкції `if` використайте ключове слово `throw`, щоб викинути `new Error()`.
Передайте точний рядок `"Search field cannot be empty"` у конструктор `Error`.

**Примітка:** Якщо ви натиснете кнопку Пошук після цього, на екрані нічого не з’явиться! Помилка зупиняє обробник натискання, бо її ще ніхто не ловить. Ви виправите це за кілька кроків. Але поки що можете перевірити консоль, щоб переконатися, що ваш код працює.
