# --description--

在本实验中，你将构建一个双向链表，其中每个节点都保存对列表中下一个节点和上一个节点的引用。

**目标：**实现以下用户需求并通过所有测试以完成实验。

**用户故事：**

1. 你应该有一个名为 `DoublyLinkedList` 的类。
1. `DoublyLinkedList` 应该有一个名为 `Node` 的嵌套类，其 `__init__` 方法应该：
   - 接受一个 `element` 参数和一个可选的 `previous` 参数，该参数默认为 `None`。
   - 将 `element` 属性设置为 `element` 参数的值。
   - 将 `previous` 属性设置为 `previous` 参数的值。
   - 将 `next` 属性设置为 `None`。
1. `DoublyLinkedList` 的 `__init__` 方法应该将 `length` 属性设置为 `0`，并将 `head` 和 `tail` 属性设置为 `None`。
1. `DoublyLinkedList` 应该有一个 `is_empty` 方法，当列表中没有节点时返回 `True`，否则返回 `False`。
1. `DoublyLinkedList` 应该有一个接受 `element` 的 `add` 方法，并且：
   - 创建一个包含该 `element` 的新 `Node`，并将其添加到列表末尾。
   - 将新节点的 `previous` 属性设置为添加前的尾节点；如果列表为空，则设置为 `None`。
   - 更新列表的 `head`（当列表为空时）、`tail` 和 `length`。
   - 不通过循环遍历列表来查找其末尾。
1. `DoublyLinkedList` 应该有一个接受 `element` 的 `remove` 方法，并且：
   - 删除 `element` 等于给定 `element` 的每个节点。
   - 使其余节点的 `next` 和 `previous` 引用保持正确链接。
   - 在需要时更新列表的 `head`、`tail` 和 `length`。
   - 如果没有节点匹配或列表为空，则保持列表不变。
1. `DoublyLinkedList` 应该有一个 `reverse` 方法，用于原地反转节点的顺序。
1. `DoublyLinkedList` 应该有一个 `to_list` 方法，返回链表中从 `head` 到 `tail` 的元素列表。

class DoublyLinkedList:
    class Node:
        def __init__(self, element, previous=None):
            self.element = element
            self.previous = previous
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None
        self.tail = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element, self.tail)
        if self.is_empty():
            self.head = node
        else:
            self.tail.next = node
        self.tail = node
        self.length += 1

    def remove(self, element):
        current_node = self.head
        while current_node is not None:
            next_node = current_node.next
            if current_node.element == element:
                if current_node.previous is not None:
                    current_node.previous.next = current_node.next
                else:
                    self.head = current_node.next
                if current_node.next is not None:
                    current_node.next.previous = current_node.previous
                else:
                    self.tail = current_node.previous
                self.length -= 1
            current_node = next_node

    def reverse(self):
        current_node = self.head
        while current_node is not None:
            current_node.previous, current_node.next = current_node.next, current_node.previous
            current_node = current_node.previous
        self.head, self.tail = self.tail, self.head

    def to_list(self):
        elements = []
        current_node = self.head
        while current_node is not None:
            elements.append(current_node.element)
            current_node = current_node.next
        return elements
