# --description--

Kutoa vitu huru hukuwezesha kuweka thamani ya vitu vya orodha katika vigezo vingi kwa mstari mmoja. Unaweza kutumia kigezo kilicho na nyota kukusanya vitu vilivyobaki katika orodha:

```py
fruits = ['apple', 'banana', 'cherry']
first, *rest = fruits
print(first) # apple
print(rest) # ['banana', 'cherry']
```

Toa vitu vya `pieces` katika vigezo vitatu: `opening` kwa kipengee cha kwanza, `middle` kwa vitu vyote vilivyo katikati, na `closing` kwa kipengee cha mwisho. Kisha, chapisha `opening`, `middle`, na `closing` kwa wito tofauti wa `print()` tatu.
