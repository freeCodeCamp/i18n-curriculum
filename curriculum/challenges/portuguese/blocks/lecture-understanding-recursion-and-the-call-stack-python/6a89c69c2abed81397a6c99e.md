# --description--

Recursão é uma técnica em que uma função chama a si mesma. Cada chamada trabalha em uma versão menor do problema original até atingir uma condição que para a recursão. Essa condição de parada é chamada de caso base.

Funções recursivas podem resolver problemas com profundidade desconhecida, como percorrer uma árvore de arquivos. Elas também podem realizar tarefas mais simples, como contar regressivamente a partir de um número dado.

Aqui está uma função chamada `recursive_countdown` que aceita um número e o imprime:

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

Chamar a função imprime `5`, mas ainda não conta regressivamente. Antes de fazer a função chamar a si mesma, você precisa definir seu caso base. Sem um caso base alcançável, a função continuará se chamando. O Python eventualmente para as chamadas e gera um `RecursionError`.

Para essa contagem regressiva, a função deve parar quando `number` for menor que `1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

A declaração `if` é o caso base. Quando `number` é menor que `1`, o `return` termina aquela chamada da função.

A função ainda precisa de um caso recursivo. O caso recursivo chama a função novamente com um argumento que a aproxima do caso base. Para contar regressivamente, chame `recursive_countdown` com `number - 1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

Isso imprime os números `5`, `4`, `3`, `2` e `1`.

A posição da chamada recursiva muda quando os números são impressos. Se a chamada `print()` vier depois da chamada recursiva, a função imprime os números em ordem crescente:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

Isso imprime os números `1`, `2`, `3`, `4` e `5`. Para entender por quê, você precisa entender a pilha de chamadas.

A pilha de chamadas é uma estrutura de dados last-in, first-out que o Python usa para acompanhar as chamadas de função ativas. Quando uma função é chamada, o Python adiciona um frame para essa chamada no topo da pilha. O frame contém informações como os argumentos da função e variáveis locais.

Considere esta versão da contagem regressiva:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

A saída é:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

A chamada para `recursive_countdown(3)` pausa quando chama `recursive_countdown(2)`. A chamada com `2` pausa quando chama a função com `1`, e a chamada com `1` pausa quando chama a função com `0`.

A chamada com `0` alcança o caso base e retorna. O Python remove essa chamada do topo da pilha, então a chamada com `1` retoma após sua chamada recursiva. As chamadas restantes então retomam e retornam em ordem inversa: `1`, `2` e `3`.

Toda função recursiva precisa de um caso base e um caso recursivo que o aproxime. Quando o caso base retorna, as chamadas anteriores retomam na ordem last-in, first-out.
