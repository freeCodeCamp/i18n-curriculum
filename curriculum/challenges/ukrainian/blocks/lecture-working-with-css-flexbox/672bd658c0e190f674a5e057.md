# --interactive--

Властивості flex керують тим, як елементи поводяться всередині гнучкого макета — від розподілу на рівні контейнера до самовирівнювання на рівні елемента. У цьому уроці ми розглянемо деякі з найпоширеніших: `flex-wrap`, `flex-flow`, `justify-content`, `align-items` та `align-self`.

## Обгортання елементів за допомогою `flex-wrap`

Почнемо з `flex-wrap`. Ця властивість визначає, як гнучкі елементи обгортаються всередині контейнера flex, щоб поміститися у доступний простір. `flex-wrap` може приймати три можливі значення: `nowrap`, `wrap` і `wrap-reverse`. `nowrap` — це значення за замовчуванням: гнучкі елементи не будуть переноситися на новий рядок, навіть якщо їх ширина перевищує ширину контейнера.

У наведеному нижче коді є три елементи `div`. Давайте звернемо увагу на `width`. Контейнер `main` з кордоном має `width` `200px`, а три дочірні елементи `div` разом мають `width` `240px` (по `80px` кожен):

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  display: flex;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Ширина `div` елементів перевищує ширину їхнього контейнера, але за замовчуванням вони будуть стиснені, щоб поміститися у доступний простір. Якщо ви хочете, щоб вони переносилися, коли перевищують ширину контейнера, ви можете встановити `flex-wrap: wrap` на контейнері flex:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  display: flex;
  flex-wrap: wrap;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

## Поєднання напрямку та обгортання за допомогою `flex-flow`

Гнучкі елементи `div` будуть розташовані в рядках, коли вони перевищують ширину контейнера. Ви можете обгорнути гнучкі елементи у зворотному порядку за допомогою `flex-wrap: wrap-reverse`. Властивість `flex-flow` є скороченою властивістю для `flex-direction` і `flex-wrap`. У цьому прикладі ми встановили `flex-direction` у `column` і `flex-wrap` у `wrap-reverse`:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  height: 120px;
  display: flex;
  flex-flow: column wrap-reverse;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

## Вирівнювання елементів уздовж головної осі за допомогою `justify-content`

Чудово. Тепер поговоримо про `justify-content`. `justify-content` вирівнює дочірні елементи вздовж головної осі контейнера flex. Якщо ви призначите значення `flex-start` властивості `justify-content`, гнучкі елементи будуть вирівняні на початку головної осі. Це може бути горизонтально або вертикально:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: flex-start;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

За допомогою `justify-content: flex-end` гнучкі елементи вирівнюються в кінці головної осі, горизонтально або вертикально.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: flex-end;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Щоб центровано розташувати гнучкі елементи вздовж головної осі, можна використати `justify-content: center`.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: center;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Щоб розподілити елементи вздовж головної осі без пробілів на краях, можна використати `justify-content: space-between`. Перший елемент розташовується на початку головної осі, останній — в кінці, а решта простору розподіляється між сусідніми елементами.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: space-between;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

`justify-content: space-around` рівномірно розподіляє гнучкі елементи вздовж головної осі, додаючи пробіл перед першим і після останнього елемента. Цей додатковий пробіл становить половину простору між кожною парою сусідніх елементів. Якщо є лише один елемент для розподілу, він буде по центру.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: space-around;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

І нарешті, `justify-content: space-evenly` рівномірно розподіляє елементи вздовж головної осі. Пробіл між елементами та пробіли перед першим і після останнього елементів однакові:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: space-evenly;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

## Вирівнювання елементів уздовж поперечної осі за допомогою `align-items`

Чудово. Тепер ви знаєте, як розподіляти гнучкі елементи вздовж головної осі. Але ви також можете захотіти розподілити їх вздовж поперечної осі. Пам’ятайте, що поперечна вісь перпендикулярна до головної осі. Це можна зробити за допомогою властивості `align-items`. Щоб центровано розташувати елементи вздовж поперечної осі, просто додайте `align-items: center` до контейнера flex:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: center;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

У цьому прикладі гнучкі елементи центровані вздовж поперечної осі, яка за замовчуванням вертикальна. Якщо поперечна вісь горизонтальна, вони будуть центровані горизонтально. Натомість `align-items: flex-start` вирівнює елементи на початку поперечної осі:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: flex-start;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Протилежністю є `align-items: flex-end`. Вона вирівнює гнучкі елементи в кінці поперечної осі, вертикально або горизонтально.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: flex-end;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Щоб розтягнути гнучкі елементи вздовж поперечної осі, можна використати `align-items: stretch`. Це впливає лише на елементи, розмір яких на поперечній осі встановлений як `auto`; елементи з явним розміром на поперечній осі (наприклад, заданою `height` у контейнері з рядками) не розтягуватимуться. Впливові елементи заповнять контейнер у напрямку поперечної осі.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: stretch;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
  height: auto;
}
```

:::

## Перевизначення вирівнювання для окремого елемента за допомогою `align-self`

І нарешті, ви можете використати властивість `align-self`, щоб призначити інше вирівнювання по поперечній осі для окремого гнучкого елемента. Наприклад, ви можете розтягнути його за допомогою `align-self: stretch`.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: flex-start;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
  align-self: stretch;
}
```

:::

Ви можете центровано розташувати його за допомогою `align-self: center`.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
```

```css
#third-div {
  background-color: #4da3b2;
  align-self: center;
}
```

:::

Ви можете вирівняти його на початку поперечної осі за допомогою `align-self: flex-start`.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">

  <div id="first-div"></div>

```


:::

Існують інші властивості та значення flex, які ви можете обрати для створення адаптивного макета, який ви уявляєте, але ці — найпоширеніші. Використовуючи ці CSS-властивості flex і свої нові знання про модель CSS flex, ви можете почати створювати адаптивні макети для плавного та інклюзивного користувацького досвіду на різних пристроях.
