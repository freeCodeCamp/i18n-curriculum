# --description--

En este laboratorio, implementarás una estructura de datos pila usando funciones. Una pila es una estructura de datos LIFO (último en entrar, primero en salir) donde los elementos se agregan y se eliminan desde la parte superior.

Tu pila será un diccionario cuya clave `collection` contiene una lista de elementos. La cima de la pila es el final de la lista, así que el último elemento en la lista es el que se agregó más recientemente.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

**Historias de usuario:**

1. Debes tener una función `init_stack` que devuelva un diccionario con una clave `collection` establecida en una lista vacía.
1. Debes tener una función `push` que tome una pila y un elemento, y agregue el elemento a la cima de la pila.
1. Debes tener una función `pop` que tome una pila, y elimine y devuelva su elemento superior, o devuelva `None` si la pila está vacía.
1. Debes tener una función `peek` que tome una pila, y devuelva su elemento superior sin eliminarlo, o devuelva `None` si la pila está vacía.
1. Debes tener una función `is_empty` que tome una pila, y devuelva `True` si no contiene elementos, y `False` en caso contrario.
1. Debes tener una función `clear` que tome una pila, y elimine todos sus elementos.

**Nota:** La mayoría de las pruebas dependen de las funciones `init_stack` y `push`. Implémentalas primero, ya que las pruebas para `pop`, `peek`, `is_empty` y `clear` requieren agregar elementos a la pila.

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
