# --description--

読み取り値を扱う前に、エラーコードを取り除く必要があります。

前のレッスンで学んだように、`filter()` 関数は関数が真値を返すイテラブルの要素だけを保持します。その関数を `def` で定義する代わりに、lambda 関数を直接 `filter()` に渡すことができます：

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

`valid_readings` という変数を作成してください。`filter()` に lambda 関数と `readings` を渡した結果を代入します。lambda 関数は `reading` というパラメータを取り、`reading` が `-999` と等しくないかどうかをチェックする必要があります。

その後、`readings` の代わりに `valid_readings` を出力してください。
