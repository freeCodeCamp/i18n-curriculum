# --description--

Wenn die Major-Versionen gleich sind, müssen Sie die Minor-Versionen vergleichen. Wenn die Minor-Versionen unterschiedlich sind, handelt es sich um ein Minor-Update: Die neuere Version fügt neue Funktionen hinzu, die weiterhin mit der älteren Version kompatibel sind.

Das Ausschneiden eines Tuples ergibt ein neues Tuple, und der Vergleich von Tuples stoppt beim ersten Elementpaar, das sich unterscheidet. Zum Beispiel ist `(2, 1) < (2, 2)` `True`, weil die ersten Elemente gleich sind und `1` kleiner als `2` ist.

Fügen Sie eine `elif`-Klausel hinzu, die überprüft, ob der Ausschnitt von `installed`, der die ersten beiden Elemente enthält, kleiner ist als derselbe Ausschnitt von `latest`. Wenn das der Fall ist, weisen Sie den String `minor update` der Variable `update_type` zu.
