# --description--

Der Operator `or` wird verwendet, um zu prüfen, ob mindestens eine von zwei Bedingungen wahr ist. So können Sie ihn mit einem Vergleich in einer `if`-Anweisung verwenden:

```py
day = 'Sunday'
is_raining = False

if day == 'Sunday' or is_raining:
    print('Stay at home')
```

Im obigen Beispiel wird `Stay at home` ausgegeben, weil die erste Bedingung wahr ist, obwohl `is_raining` `False` ist.

Zusätzliche Gebühren sollten auch an Wochenenden gelten. Aktualisieren Sie die Bedingung der Zeile `if show_time == 'Evening':`, indem Sie den Operator `or` verwenden, um die bestehende Bedingung mit einer zweiten Bedingung zu kombinieren, die prüft, ob `is_weekend` wahr ist.
