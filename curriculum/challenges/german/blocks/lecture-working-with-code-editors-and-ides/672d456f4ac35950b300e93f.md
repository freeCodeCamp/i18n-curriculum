# --description--

Sie sind wahrscheinlich bereits mit einigen der grundlegenden Tastenkombinationen vertraut, die von Ihrem Betriebssystem übernommen werden. Tastenkombinationen wie <kbd>Ctrl</kbd> + <kbd>S</kbd> (Windows/Linux) oder <kbd>Cmd</kbd> + <kbd>S</kbd> (macOS) zum Speichern, <kbd>Ctrl</kbd> + <kbd>C</kbd> oder <kbd>Cmd</kbd> + <kbd>C</kbd> zum Kopieren und <kbd>Ctrl</kbd> + <kbd>V</kbd> oder <kbd>Cmd</kbd> + <kbd>V</kbd> zum Einfügen funktionieren alle in VS Code.

Es gibt jedoch einige, die an die Anwendung gebunden sind und Ihre Produktivität trotzdem steigern können. Es ist wichtig zu beachten, dass einige dieser Tastenkombinationen je nach Betriebssystem unterschiedlich sein können.

Zum Beispiel führt <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> den von Ihnen konfigurierten Formatter (wie Prettier für ein JavaScript-Projekt) auf der aktuell geöffneten Datei aus.

Verwenden Sie <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (Windows/Linux) oder <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (macOS), um den Textinhalt aller Dateien in Ihrem Arbeitsbereich zu durchsuchen. Verwenden Sie dann <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (Windows/Linux) oder <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (macOS), wenn Sie eine Suchen-und-Ersetzen-Funktion ausführen möchten.

Wenn Sie eine Zeile entfernen müssen, löscht <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (Windows/Linux) oder <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (macOS) diese.

Brauchen Sie mehr Platz für Ihren gesamten Code? <kbd>Ctrl</kbd> + <kbd>B</kbd> (Windows/Linux) oder <kbd>Cmd</kbd> + <kbd>B</kbd> (macOS) blendet die Seitenleiste aus, die die Dateiliste und das Erweiterungsmenü enthält.

Oder sehen Sie Ihren Code einfach nicht? <kbd>Ctrl</kbd> + <kbd>Plus</kbd> (Windows/Linux) oder <kbd>Cmd</kbd> + <kbd>Plus</kbd> (macOS) vergrößert die Skalierung des Editors, und <kbd>Ctrl</kbd> + <kbd>Minus</kbd> (Windows/Linux) oder <kbd>Cmd</kbd> + <kbd>Minus</kbd> (macOS) verkleinert sie.

Eine weitere hilfreiche Funktion in VS Code ist die Mehrzeilenbearbeitung, mit der Sie Änderungen gleichzeitig über mehrere Zeilen vornehmen können. Zum Beispiel können Sie mehrere Cursor setzen, indem Sie <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> und <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Windows), <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> und <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Linux) oder <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Down</kbd> und <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Up</kbd> (macOS) verwenden, um den Cursor auf aufeinanderfolgende Zeilen auszudehnen. Sie können auch <kbd>Alt</kbd> (Windows/Linux) oder <kbd>Option</kbd> (macOS) gedrückt halten und klicken, um an verschiedenen Stellen auf separaten Zeilen Cursor hinzuzufügen, wo immer Sie sie brauchen. Sobald die Cursor gesetzt sind, wird alles, was Sie tippen oder löschen, gleichzeitig an all diesen Stellen angewendet, was viel Zeit sparen kann, wenn Sie mit sich wiederholendem Code arbeiten.

Wenn Sie schließlich eine dieser Tastenkombinationen vergessen, haben Sie immer <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows/Linux) oder <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS), die die Befehlspalette öffnen, damit Sie alles auswählen können, was Sie brauchen.
