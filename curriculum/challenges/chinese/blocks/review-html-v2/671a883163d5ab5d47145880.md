## HTML 基础

- **HTML 的作用**：HTML（超文本标记语言）是网页结构的基础，用于定义网页的元素。
- **超文本标记语言 元素**：用于表现页面上的内容。大多数由一个起始标签和一个结束标签组成（例如，`<h1></h1>`、`<p></p>`）。
- **HTML 结构**：HTML 由 `head` 和 `body` 组成，分别用于组织元数据、样式和内容。
- **常见超文本标记语言元素**：标题（`<h1>` - `<h6>`）、段落（`<p>`）和 div 容器（`<div>`）。
- **`div` 元素**：`div` 元素是一个通用的 HTML 元素，没有语义含义。 它被用作容纳其他 HTML 元素的通用容器。
- **空元素**：没有闭合标签（例如，`<img>`）。
- **属性**：用于为元素添加元数据和行为。

## 标识符和分组

- **ID**：元素的唯一标识符。
- **Class**：用于将元素分组，以便进行样式或行为控制。

## 模板和编码

- **HTML 模板**：网页的基本结构，包括 `DOCTYPE`、`html`、`head` 和 `body` 元素。 它应该作为 HTML 文档的起始点。
- **UTF-8 字符编码**：确保通用字符显示。

## 语义化 HTML 的重要性

- **标题元素的结构层次**：使用正确的标题元素以维护内容的结构层次非常重要。`h1` 元素是最高级别的标题，`h6` 元素是最低级别的标题。
- **语义化 HTML 元素**：这些元素为内容结构赋予意义。示例包括：
  - `<header>`：表现介绍性内容。
  - `<nav>`：包含导航链接。
  - `<article>`：表现独立的内容。
  - `<section>`：在文档中分组相关内容。
  - `<footer>`：定义某个部分或文档的页脚。
  - `<blockquote>`：用于表现引用自其他来源的部分。使用引用源作为 `cite` 属性的值。
  - `<q>`：用于表现简短的内联引用。

## HTML 表单元素和属性

### 表单

- **`form` 元素**：用于创建用户输入的 HTML 表单。
- **常见输入类型**：
  - `text`、`email`、`radio`、`checkbox`、`number`。
- **`action` 属性**：用于指定表单数据应发送到的 URL。
- **`method` 属性**：用于指定发送表单数据时使用的 HTTP 方法。最常用的方法是 `GET` 和 `POST`。

```html
<form method="value-goes-here" action="url-goes-here">
  <!-- inputs go inside here -->
</form>
```

- **`input` 元素**：用于创建用户输入的输入字段。
- **`type` 属性**：用于指定输入字段的类型，例如 `text`、`email`、`number`、`radio`、`checkbox`。
- **`placeholder` 属性**：用于向用户显示提示，告诉他们在输入字段中应输入什么。
- **`value` 属性**：用于指定输入的值。如果输入类型是 `button`，`value` 属性可用于设置按钮文本。
- **`name` 属性**：用于为输入字段赋名，提交表单数据时作为键使用。对于单选按钮，赋予相同的 `name` 会将它们分组，使得组内只能选择一个选项。
- **`size` 属性**：用于定义用户输入时应显示的字符数。
- **`min` 属性**：可与 `number` 等输入类型一起使用，指定输入字段允许的最小值。
- **`max` 属性**：可与 `number` 等输入类型一起使用，指定输入字段允许的最大值。
- **`required` 属性**：用于指定提交表单前必须填写该输入字段。

:::interactive_editor

```html
<!-- Text input -->
<input 
  type="text"
  id="name"
  name="name"
  placeholder="e.g. Quincy Larson"
  size="20"
  required
/>

<!-- Number input -->
<input 
  type="number"
  id="quantity"
  name="quantity"
  min="2"
  max="10"
/>

<!-- Button -->
<input type="button" value="Show Alert" />
```

:::

- **`label` 元素**：用于为输入字段创建标签。
- **`for` 属性**：用于指定标签对应的输入字段。

:::interactive_editor

```html
<form action="">
  <label for="email">Email Address: </label>
  <input type="email" id="email" />
</form>
```

:::

- **`button` 元素**：用于创建可点击的按钮。按钮也可以有一个 `type` 属性，用于控制按钮被激活时的行为。

:::interactive_editor

```html
<button type="submit">Submit Form</button>
```

:::

- **`fieldset` 元素**：用于将相关输入归类在一起。
- **`legend` 元素**：用于添加说明输入组的标题。

:::interactive_editor

```html
<!-- Radio group -->
<fieldset>
  <legend>Was this your first time at our hotel?</legend>

  <input id="yes-option" type="radio" name="hotel-stay" value="yes" />
  <label for="yes-option">Yes</label>

  <input id="no-option" type="radio" name="hotel-stay" value="no" />
  <label for="no-option">No</label>
</fieldset>

<!-- Checkbox group -->
<fieldset>
  <legend>
    Why did you choose to stay at our hotel? (Check all that apply)
  </legend>

  <input type="checkbox" id="location" name="location" value="location" />
  <label for="location">Location</label>

  <input type="checkbox" id="price" name="price" value="price" />
  <label for="price">Price</label>
</fieldset>
```

:::

## 使用 HTML 表格元素和属性

- **表格元素**：用于创建 HTML 表格。
- **表头 (`thead`) 元素**: 用来分组HTML表中的标题内容。
- **表格行（`tr`）元素**：用于在 HTML 表格中创建一行。
- **表头单元格（`th`）元素**：用于在 HTML 表格中创建表头单元格。
- **表体（`tbody`）元素**：用于在 HTML 表格中对正文内容进行分组。
- **表格数据单元格（`td`）元素**：用于在 HTML 表格中创建数据单元格。
- **表脚（`tfoot`）元素**：用于在 HTML 表格中对表脚内容进行分组。
- **`caption` 元素**：用于为 HTML 表格添加标题。
- **`colspan`元素**：用于指定表格单元格跨列数。

:::interactive_editor

```html
<table>
  <caption>Exam Grades</caption>

  <thead>
    <tr>
      <th>Last Name</th>
      <th>First Name</th>
      <th>Grade</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Davis</td>
      <td>Alex</td>
      <td>54</td>
    </tr>

    <tr>
      <td>Doe</td>
      <td>Samantha</td>
      <td>92</td>
    </tr>

    <tr>
      <td>Rodriguez</td>
      <td>Marcus</td>
      <td>88</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <td colspan="2">Average Grade</td>
      <td>78</td>
    </tr>
  </tfoot>
</table>
```

## 无障碍

- **网页内容无障碍指南**：网页内容无障碍指南（WCAG）是一套使网页内容对残障人士更易访问的指南。WCAG 的四个原则是 POUR，代表可感知（Perceivable）、可操作（Operable）、可理解（Understandable）和健壮（Robust）。
- **良好 `alt` 文本的重要性**：你应该使用 `alt` 属性为图像提供文本备选，这有助于辅助技术理解图像内容。
- **良好链接文本的重要性**：你应该使用描述性的链接文本，帮助用户理解链接的目的。
