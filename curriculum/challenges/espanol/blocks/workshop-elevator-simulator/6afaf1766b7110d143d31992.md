# --description--

Ahora mismo, el ascensor salta directamente a cada piso. Un ascensor real se mueve un piso a la vez hasta llegar a su objetivo.

Después de imprimir `target`, crea un ciclo `while` anidado que se ejecute mientras `current_floor` no sea igual a `target`. Dentro, usa una sentencia `if` para verificar si `current_floor` es menor que `target`. Si lo es, aumenta `current_floor` en `1`. De lo contrario, disminuye `current_floor` en `1`.

Cada iteración acerca el ascensor un piso más a `target`, así que `current_floor` eventualmente se vuelve igual a `target` y el ciclo anidado se detiene.
