# --description--

递归调用每次沿着树向下走一层，但它们需要一个停止的地方。有两种分支：

- `node.key` 与 `key` 相等：你找到了包含你要查找值的节点。
- `node` 是 `None`：搜索越过了叶子节点，因此该值不在树中。

在 `_search` 方法的开头，在你现有的 `if` 语句之前，添加一个 `if` 语句，检查 `node` 是否为 `None` 或者 `node.key` 是否与 `key` 相等，并从中返回 `node`。这样，该方法要么返回包含该值的节点，要么返回 `None`（如果该值不在树中）。
