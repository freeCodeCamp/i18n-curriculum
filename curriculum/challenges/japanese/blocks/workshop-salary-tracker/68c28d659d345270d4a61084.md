# --description--

`__repr__` メソッドは、オブジェクトをインスタンス化するために使える文字列の表現を返す特別なメソッドです。

例えば、`__repr__` の `Employee('Charlie', 'developer')` メソッドは、オブジェクトを作成するのに使われたのと同じ文字列 `Employee('Charlie', 'developer')` を返すべきです。

各値の周りに引用符がある場合、値に引用符が含まれると結果が壊れます。例えば、名前が`O'Reilly`でレベルが`junior`の社員の場合、`Employee('O'Reilly', 'junior')`となり、アポストロフィが文字列を早期に閉じてしまうため有効ではありません。

Pythonの組み込み`repr()`関数は値の文字列表現を返します。文字列の場合は、引用符を追加し、必要な文字をエスケープします：

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

f文字列の中で、式の後に`!r`を追加すると、その式に`repr()`が適用されます：

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

`Employee`クラスに`self`パラメータを持つ`__repr__`メソッドを追加してください。`self.name`と`self.level`に`!r`を使って、引用符やバックスラッシュが保持されるようにし、オブジェクトを生成するために使える文字列を返すようにしてください。
