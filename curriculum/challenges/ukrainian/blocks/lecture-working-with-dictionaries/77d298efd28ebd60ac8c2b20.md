# --description--

Ви навчилися створювати словники, отримувати доступ до їхніх значень і оновлювати їх. Тепер ви використаєте методи словників, копіюватимете словники та дослідите, як функції можуть їх змінювати.

Кожен приклад методу словника нижче починається з цього словника:

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## Методи словника

У словників також є корисні методи для виконання загальних операцій.

Метод `.get()` отримує значення, пов’язане з ключем. Він схожий на дужкову нотацію, яку ви вивчали в попередньому уроці, але його перевага в тому, що ви можете встановити значення за замовчуванням, щоб не отримати помилку, якщо ключ не існує:

```python
dictionary.get(key, default)
```

У цьому прикладі, якщо ключ `toppings` не існує, буде повернуто порожній список — це значення за замовчуванням, яке ми передаємо як другий аргумент. Але якщо `toppings` існує, буде повернено це значення:

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

Методи `.keys()` і `.values()` повертають об’єкт-подання з усіма ключами та значеннями словника відповідно:

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

Об’єкт-подання — це просто спосіб побачити вміст словника без створення окремої копії даних.

Метод `.items()` повертає об’єкт-подання з усіма парами ключ-значення в словнику, включно з ключами і значеннями:

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

Метод `.clear()` видаляє всі пари ключ-значення зі словника:

```python
pizza.clear()
```

Метод `.pop()` видаляє пару ключ-значення з ключем, який ви вказуєте як перший аргумент, і повертає її значення. Якщо ключ не існує, він повертає значення за замовчуванням, яке ви вказуєте як другий аргумент. Якщо ключ не існує і ви не передали значення за замовчуванням, виникає `KeyError`:

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

У Python 3.7 і новіших версіях метод `.popitem()` видаляє останній доданий елемент:

```python
pizza.popitem()
```

Метод `.update()` оновлює пари ключ-значення парами ключ-значення з іншого словника. Якщо у них є спільні ключі, їхні значення перезаписуються.

У цьому прикладі ми оновлюємо словник `pizza`. Ключ `price` існує в обох словниках, тому його значення буде замінене на `15`.

Але `total_time` — новий ключ, тому він буде доданий до словника `pizza` як нова пара ключ-значення:

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

Ось новий словник з оновленим `price` і новим `total_time`. Зверніть увагу, що ціна тепер `15`, а `total_time` — це нова пара ключ-значення:

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### Присвоєння та поверхневі копії

Як ви вивчили з масивами, присвоєння словника іншій змінній створює псевдонім. Обидва імені посилаються на один і той самий об’єкт:

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

Щоб створити окремий зовнішній словник, використовуйте метод `.copy()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

Заміна запису в `copied_settings` не замінює відповідний запис у `settings`. Однак `.copy()` створює **поверхневу копію**: він створює новий зовнішній словник, ключі та значення якого посилаються на ті самі об’єкти, що й у початковому словнику. Вкладені змінні об’єкти все ще спільні:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

Два словники — це різні об’єкти, але їхні записи `languages` посилаються на той самий список. Додавання до цього списку видно через обидва словники. Заміна `copied_settings['languages']` на новий список змінить лише цей запис у копії.

Ви також можете створити поверхневу копію, передавши словник у `dict()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

Як і `.copy()`, `dict(settings)` створює новий зовнішній словник, але вкладений список все ще спільний. Заміна запису в будь-якому словнику впливає лише на цей словник, тоді як зміна спільного списку видима через обидва.

## Мутація словника через параметр функції

Ті самі правила передачі аргументів, які ви вивчили з масивами, застосовуються до словників. Параметр спочатку посилається на об’єкт, переданий як аргумент. Оновлення запису через цей параметр мутує спільний словник:

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

Функція повертає рядок статусу, тоді як `preferences` змінюється через спільний референс. Повернення значення і мутація об’єкта — це окремі ефекти. Функції не потрібно повертати словник, щоб зміни були видимі поза функцією. Переназначення локального параметра на інший словник не замінить словник, на який посилається `preferences`.

## Використання словника як аргументу за замовчуванням

Пам’ятайте, що список за замовчуванням створюється під час визначення функції і повторно використовується в усіх викликах, які пропускають цей аргумент. Словник за замовчуванням поводиться так само:

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

Другий виклик повторно використовує словник, змінений першим викликом. Це означає, що налаштування накопичуються між незалежними викликами, навіть якщо кожен виклик має своє локальне ім’я параметра.

Коли кожен виклик має починатися з нового словника, використовуйте шаблон `None` за замовчуванням:

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

Кожен виклик, який пропускає `settings` або передає `None`, створює новий словник. Передача існуючого словника все ще дозволяє функції мутувати цей об’єкт. Використовуйте тут `settings is None`: `if not settings` також співпадатиме з порожнім словником, переданим як аргумент, і замінить його новим локальним словником.
