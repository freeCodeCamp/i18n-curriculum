# --description--

在終端機中，你應該會看到類似 `<filter object at 0x...>` 的東西，而不是讀取值。這是因為 `filter()` 傳回的是一個迭代器，它一次給你一個項目，而不是將所有項目都存放在列表中。

要將迭代器的項目收集到列表中，你可以將它傳入 `list()` 函式：

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

將指定給 `valid_readings` 的 `filter()` 呼叫包裹在 `list()` 呼叫中。在終端機中，你應該會看到沒有 `-999` 錯誤碼的讀取值。
