# --description--

並非每個部門都保證有 `Dept_code`。當它缺失時，你需要一個備用方案，讓該部門仍能獲得可用的 ID。

`||` 運算子會傳回左邊的值，如果該值是 `truthy`，否則傳回右邊的值。

例如：當 `a` 是 `truthy` 時，`a || b` 會計算為 `a`，當 `a` 是 `falsy`（像是 `undefined`、`null` 或 `""`）時，則會退回到 `b`。

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

更新 `departmentId` 的指派，使用 `||` 運算子。將 `departmentData.Dept_code` 作為左邊的運算元，模板字串 `` `dept-${i + 1}` `` 作為右邊的運算元。當 `departmentData.Dept_code` 是 falsy（包括 `undefined`）時，會使用備用值。
