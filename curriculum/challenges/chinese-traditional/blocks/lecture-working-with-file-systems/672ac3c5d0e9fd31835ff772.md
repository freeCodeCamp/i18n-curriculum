## 在 Windows 上使用檔案總管

要在 Windows 使用 Explorer 創建檔案，你可以點擊左上角的「New」選項。這將顯示你可以創建的不同檔案型別的列表。

![Windows 檔案總管，左上角以橘色方框和箭頭標示「New」按鈕，freeCodeCamp 檔案資料夾中選取了「New Text Document」。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-1.png)

你也可以在對應的應用程式中創建檔案。

![Windows 檔案總管顯示 Documents 裡的 freeCodeCamp 檔案資料夾，選取了「New Text Document」。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-2.png)

讓我們創建一個文字檔來示範這個過程。

當你點擊「New」並選擇檔案型別時，你會在目前資料夾中看到一個具有預設名稱的新程式本文檔。你可以根據需要重新命名它。

![一個文字文件圖示，檔名為 demo。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-3.png)

建立資料夾的處理程序完全相同。點擊左上角的「New」按鈕，然後選擇「Folder」選項，或是在空白處按右鍵並前往「New」，接著選擇「Folder」選項。你會在目前位置看到一個新的空資料夾。

![Windows 檔案總管顯示 freeCodeCamp 檔案資料夾中一個名為 New folder 的新資料夾。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-4.png)

### 重新命名檔案和資料夾

![Windows 檔案總管工具列，綠色方框標示「Rename」按鈕，顯示為字母 A 旁有文字游標。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-5.png)

你可以選取檔案和資料夾，然後點擊上方的「重新命名」選項來重新命名。當檔案的現有名稱被標明時，你就可以開始輸入新的檔案名稱。按下 <kbd>Enter</kbd> 以確認變更。

或者，你也可以對檔案或資料夾按右鍵，選擇「重新命名」選項，或使用 <kbd>F2</kbd> 鍵盤快速鍵。輸入新名稱後按 <kbd>Enter</kbd> 以確認變更。

### 移動檔案和資料夾

如果你已將目標資料夾以分頁方式開啟，你可以透過拖放將檔案或資料夾移動到另一個資料夾中。

你也可以選擇該檔案或資料夾，然後在頂部選擇「剪下」選項。

![Windows 檔案總管工具列，綠色方框標示「Cut」按鈕，圖示為剪刀。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-6.png)

然後，前往目標資料夾，並點擊上方的「貼上」按鈕進行貼上。如果你先前複製或剪下了該檔案，這個按鈕將會被啟用。

![Windows 檔案總管工具列，綠色方框標示「Paste」按鈕，圖示為剪貼簿。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-7.png)

你也可以透過在空白處按右鍵，然後點擊貼上圖示來完成此操作。這將會將檔案或資料夾從其原始位置移除。

### 刪除檔案和資料夾

要刪除檔案或資料夾，點選它然後點擊上方的垃圾桶圖示。

![Windows 檔案總管工具列，綠色方框標示「Delete」按鈕，圖示為垃圾桶。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-8.png)

如果你對檔案或資料夾按右鍵，也會看到「Delete」選項。

## 在 macOS 上使用 Finder

太好了。現在讓我們看看你如何在 macOS 上使用 Finder 來做到這一點。

Finder 是 macOS 上的預設檔案管理員。

### 建立檔案

要在 macOS 上創建檔案，你需要打開一個允許你創建所需文件型別的應用程式。目前，Finder 中沒有內建的方式可以直接創建檔案。

例如，要創建一個簡單的純文字程式本文檔，你可以打開 TextEdit 並存檔你的檔案。這個處理程序對任何類型的檔案都完全相同。

開啟 TextEdit 有很多方法，其中一種是前往 Launchpad。

![macOS Launchpad 圖示，一個圓角方形，內含彩色應用程式圖塊的網格。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-9.png)

接著搜尋你想要創建的檔案類型的應用程式。這裡是「TextEdit」。點擊圖示開啟應用程式。

![Launchpad 搜尋欄輸入 TextEdit，下面顯示 TextEdit 應用程式圖示。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-10.png)

一旦你進入應用程式，你應該會在 File 選單中看到一個存檔你的檔案的選項。此選單位於左上角，緊鄰 Apple 圖示旁邊。

![TextEdit 開啟空白文件。綠色箭頭指向 macOS 功能表列，列出 TextEdit、File、Edit、Format、View、Window 和 Help。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-11.png)

在其中一個 App 選單選項中，你應該會看到一個將檔案存檔的指令。這通常位於檔案選單下。

![macOS 功能表列特寫，顯示蘋果標誌，接著是 TextEdit、File、Edit、Format、View、Window 和 Help。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-12.png)

旁邊會顯示存檔的鍵盤快速鍵，macOS 通常是 <kbd>Command</kbd> + <kbd>S</kbd>。

![TextEdit 的 File 功能表展開，標示 Save，右側顯示 Command + S 快捷鍵。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-13.png)

當你第一次儲存檔案時，你應該會看到一個對話，在那裡你可以輸入檔案名稱並選擇位置。

通常，副檔名是由應用程式自動添加，但你可以在儲存檔案之前更改它。

![TextEdit 儲存對話框，Save As 欄位顯示 Untitled.txt，有資料夾瀏覽器，底部有 Cancel 和 Save 按鈕。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-14.png)

儲存檔案後，你可以點擊 Dock 上的 Finder 圖示來開啟 Finder。

![macOS Dock 中的 Finder 圖示，一個藍白相間的笑臉。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-15.png)

你應該會在儲存檔案的資料夾中看到你的新檔案。

![Finder 視窗顯示 freeCodeCamp 檔案資料夾，裡面有一個檔案 demo.txt。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-16.png)

### 建立資料夾

要創建新資料夾，你應該前往你想要創建該新資料夾的位置，然後在空白處按右鍵。你會看到一個選項列表。第一個選項是「New Folder」。

![Finder 在空白處開啟的右鍵選單，頂端標示 New Folder。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-17.png)

如果你點擊它，就可以為你的新資料夾指定名稱。輸入名稱後按 <kbd>Enter</kbd> 以確認。

![一個新的 Finder 資料夾，名為 untitled folder，名稱正被編輯中。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-18.png)

![同一個資料夾改名為 freeCodeCamp。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-19.png)

### 移動檔案和資料夾

在 Finder 中有多種方法可以移動檔案和資料夾。如果你需要將它們移動到列在 Finder「最愛」區段的資料夾，你只需拖放即可。

![Finder 視窗中，demo.txt 被拖曳到 Favorites 側邊欄的 Documents，綠色箭頭指示。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-20.png)

如果你需要將它移動到不同的資料夾，你有兩個選項。

你可以將目標資料夾以分頁方式開啟，然後將檔案或資料夾拖放到該分頁中。

或者你可以使用鍵盤快速鍵。首先用 <kbd>Command</kbd> + <kbd>C</kbd> 複製檔案，前往新資料夾，然後使用 <kbd>Command</kbd> + <kbd>Option</kbd> + <kbd>V</kbd> 將檔案或資料夾貼上到該位置。這也會將它從原本的資料夾移除。

### 刪除檔案和資料夾

要刪除一個檔案或資料夾，你可以對它按右鍵並選擇「移動到垃圾桶」。

![demo.txt 的 Finder 右鍵選單，標示 Move to Trash。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-21.png)

![freeCodeCamp 資料夾的 Finder 右鍵選單，標示 Move to Trash。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-22.png)

你也可以將它們拖放到 Dock 上的垃圾桶圖示。這是等價的。

![macOS Dock 中的垃圾桶圖示，裡面裝著揉皺的紙張。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-23.png)

當檔案或資料夾在垃圾桶中時，你可以右鍵點擊它立即刪除，或者你可以清空垃圾桶以永久移除所有已刪除的檔案和資料夾。

![Finder 垃圾桶視窗，demo.txt 的右鍵選單展開，列出 Open、Open With、Put Back、Delete Immediately 和 Empty Trash。](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-24.png)
