## Express.jsとは？

- **Express**：Node.js上に構築された最小限で柔軟なウェブフレームワークで、ウェブサーバーやAPIの構築を簡単にします。
- **Expressのインストール**：`npm install express`
- **Expressで作れるもの**：ウェブアプリ、RESTful API、SPAのバックエンド、ミドルウェアを多用するサービス、HTTPを使うサーバーサイドのあらゆるもの。
- **ミドルウェア**：リクエスト受信とレスポンス送信の間で動作するコードです。エラー処理、入力バリデーション、リクエストやレスポンスのデータ変更などに使います。複数のミドルウェア関数を連結できます。
- **プラグイン**：Expressを拡張する外部のnpmモジュールで、通常はミドルウェアとして実装されます。

## 基本的なExpressアプリの作成

```javascript
const express = require("express");
const app = express();
const port = 3000;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

- `require("express")` — Expressライブラリを読み込みます。
- `express()` — 新しいExpressアプリケーションインスタンスを作成して返すファクトリー関数です。
- `app` — `.get()`、`.post()`、`.listen()`などのメソッドにアクセスできるメインのサーバーオブジェクトです。
- `port` — アプリがリッスンするネットワークのエンドポイントです。ローカル開発ではポート`3000`がよく使われます。
- `app.listen(port, callback)` — サーバーを起動し、HTTPリクエストの受信を開始します。

## Expressのルーティング

- **ルート**：クライアントが特定のURLに特定のHTTPメソッドでリクエストしたときに、アプリがどう応答するかを決めるルールです。
- **ルートメソッド**：`app.get()`、`app.post()`、`app.put()`、`app.delete()` — それぞれ対応するHTTPメソッドのリクエストを処理します。
- **静的ルートパス**：`/home`や`/menu/drinks`のような固定のURLです。
- **動的ルートパス（ルートパラメータ）**：URL内の値をキャプチャするプレースホルダーで、`:`が接頭辞として付きます。例えば`/post/:postId`です。
- **`req.params`**：URLからキャプチャされた動的値を含むオブジェクトです。例えば`/post/42`へのリクエストでは`req.params.postId === "42"`が得られます。

### ルートハンドラ

- **ルートハンドラ**は、リクエストがルートにマッチしたときに実行されるコールバック関数`(req, res) => { ... }`です。
- `req` — 受信したリクエストの情報（パラメータ、クエリ文字列、ヘッダー、ボディ）を含みます。
- `res` — クライアントにレスポンスを送るために使います。

## レスポンスメソッド

| メソッド | 内容 |
| --- | --- |
| `res.send()` | プレーンテキスト、HTML、JSON、バイナリデータなどのレスポンスを送信します。 |
| `res.json()` | JSONレスポンスを送信します。JavaScriptオブジェクトを自動的に変換します。 |
| `res.status(code)` | HTTPステータスコードを設定します。通常`res.send()`や`res.json()`とチェーンで使います。 |
| `res.redirect(url)` | クライアントを別のURLにリダイレクトします。 |
| `res.render(view, data)` | テンプレートエンジンのビューをレンダリングしてHTMLを送信します。 |

## `app.route()`によるチェーン可能なルートハンドラ

- `app.route(path)`は同じパスに対する複数のHTTPメソッドハンドラをまとめて、繰り返しを避けます。

```javascript
app
  .route("/user")
  .get((req, res) => { res.send("Fetching user data"); })
  .post((req, res) => { res.send("Creating a user"); })
  .put((req, res) => { res.send("Updating the user"); })
  .delete((req, res) => { res.send("Deleting the user"); });
```

## `express.Router()`によるモジュール化ルーティング

- `express.Router()`はルーターオブジェクトを作成します。これはミニExpressアプリのようなもので、ルートを定義してメインアプリにマウントできます。
- `app.use(path, router)`でルーターをマウントします。ルーター内のルートはマウントパスに対して相対的です。
- **利点**：関心事を分離し、メインファイルをすっきりさせ、ルートを再利用しやすくスケールしやすくします。

```javascript
// userRoutes.js
const express = require("express");
const router = express.Router();
router.get("/", (req, res) => { res.send("List of users"); });
router.get("/:id", (req, res) => { res.send(`User ${req.params.id}`); });
module.exports = router;

// app.js
app.use("/users", userRoutes); // mounts the router at /users
```

## 静的ファイルの提供

- **静的ファイル**：画像、CSS、クライアントサイドJavaScriptなど、サーバー側で処理せずに直接提供されるアセットです。
- `express.static(directory)` — 指定したフォルダーからファイルを提供する組み込みミドルウェアです。
- 要求されたファイルが見つからない場合、Expressは自動的に404を返します。
- 個別の静的ファイルに対してルート定義は不要です。

```javascript
app.use(express.static(path.join(__dirname, "public")));
```

- `app.use()`を複数回呼び出して、複数のディレクトリから提供することもできます。マウントパスを指定することも可能です：

```javascript
app.use(express.static(path.join(__dirname, "public")));
app.use("/images", express.static(path.join(__dirname, "images")));
```
