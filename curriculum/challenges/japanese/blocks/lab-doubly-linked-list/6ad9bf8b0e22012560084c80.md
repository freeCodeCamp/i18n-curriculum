# --description--

このラボでは、各ノードがリスト内の次のノードと前のノードの両方を参照する双方向連結リストを作成します。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

**ユーザーストーリー：**

1. `DoublyLinkedList` という名前のクラスを作成する必要があります。
1. `DoublyLinkedList` には `Node` という名前のネストされたクラスがあり、その `__init__` メソッドは次の処理を行う必要があります:
   - `element` パラメータと、デフォルト値が `None` であるオプションの `previous` パラメータを受け取る。
   - `element` 属性に `element` パラメータの値を設定する。
   - `previous` 属性に `previous` パラメータの値を設定する。
   - `next` 属性に `None` を設定する。
1. `DoublyLinkedList` の `__init__` メソッドは、`length` 属性を `0` に、`head` 属性と `tail` 属性を `None` に設定する必要があります。
1. `DoublyLinkedList` には `is_empty` メソッドがあり、リストにノードがない場合は `True` を、それ以外の場合は `False` を返す必要があります。
1. `DoublyLinkedList` には `element` を受け取る `add` メソッドがあり、次の処理を行う必要があります:
   - その `element` を保持する新しい `Node` を作成し、リストの末尾に追加する。
   - 新しいノードの `previous` 属性に、追加前に tail だったノードを設定する。リストが空だった場合は `None` を設定する。
   - リストが空だった場合は `head` を、さらに `tail` と `length` を更新する。
   - リストの末尾を探すためにリストをループしない。
1. `DoublyLinkedList` には `element` を受け取る `remove` メソッドがあり、次の処理を行う必要があります:
   - `element` が指定された `element` と等しいすべてのノードを削除する。
   - 残りのノードの `next` 参照と `previous` 参照が正しくリンクされた状態を保つ。
   - 必要に応じて、リストの `head`、`tail`、`length` を更新する。
   - 一致するノードがない場合、またはリストが空の場合は、リストを変更しない。
1. `DoublyLinkedList` には、ノードの順序をその場で逆にする `reverse` メソッドがある必要があります。
1. `DoublyLinkedList` には、`head` から `tail` までの連結リストの要素をリストとして返す `to_list` メソッドがある必要があります。

class DoublyLinkedList:
    class Node:
        def __init__(self, element, previous=None):
            self.element = element
            self.previous = previous
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None
        self.tail = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element, self.tail)
        if self.is_empty():
            self.head = node
        else:
            self.tail.next = node
        self.tail = node
        self.length += 1

    def remove(self, element):
        current_node = self.head
        while current_node is not None:
            next_node = current_node.next
            if current_node.element == element:
                if current_node.previous is not None:
                    current_node.previous.next = current_node.next
                else:
                    self.head = current_node.next
                if current_node.next is not None:
                    current_node.next.previous = current_node.previous
                else:
                    self.tail = current_node.previous
                self.length -= 1
            current_node = next_node

    def reverse(self):
        current_node = self.head
        while current_node is not None:
            current_node.previous, current_node.next = current_node.next, current_node.previous
            current_node = current_node.previous
        self.head, self.tail = self.tail, self.head

    def to_list(self):
        elements = []
        current_node = self.head
        while current_node is not None:
            elements.append(current_node.element)
            current_node = current_node.next
        return elements
