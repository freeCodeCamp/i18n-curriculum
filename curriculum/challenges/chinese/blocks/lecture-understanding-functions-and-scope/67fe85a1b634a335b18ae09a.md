# --description--

作用域决定了你在代码中可以在哪里使用一个变量。

Python 有额外的作用域规则。现在，先专注于局部作用域和全局作用域。

在函数外创建的变量具有全局作用域。你可以在函数内外都使用它。

在函数内创建的变量具有局部作用域。你只能在该函数内部使用它。函数参数也是局部变量。

下面是局部作用域和全局作用域的示例：

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

`tax_rate` 变量是全局的，因为它是在函数外创建的。`calculate_tax` 函数可以读取它，第二个 `print()` 调用也可以读取它。

`price` 参数和 `tax` 变量是 `calculate_tax` 的局部变量。它们在该函数运行时可用，但在函数外不可用。最后一个 `print()` 调用引起了 `NameError`，因为 `tax` 没有在全局作用域中定义。
