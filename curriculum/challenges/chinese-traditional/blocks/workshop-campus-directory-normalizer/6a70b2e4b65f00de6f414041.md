# --description--

每個部門裡面都巢狀有一個 `programs` 陣列。請在現有的迴圈裡面新增第二個 `for` 迴圈，從 `j = 0` 迭代到 `departmentData.programs.length`，遍歷 `departmentData.programs`。

在這個新的迴圈裡，宣告一個名為 `program` 的變數，設定為 `departmentData.programs[j]`，並將它輸出到主控台。

你也應該從程式碼中移除 `console.log(departmentsById[departmentId])` 這一行。
