# --interactive--

Sifa ya `text-decoration` inakuwezesha kuongeza mistari ya mapambo kwenye maandishi.

Kwa thamani yake ya awali ya `none`, hutumika sana kuondoa mstari wa chini wa kawaida ambao vivinjari huongeza kwa viungo wakati unahitaji kubinafsisha viungo hivyo.

```css
a {
  text-decoration: none;
}
```

Ingawa hutumika sana kwa viungo, `text-decoration` pia inaweza kupamba maandishi mengine.

## Thamani Nyingine za Sifa ya `text-decoration`

Mbali na `none`, thamani nyingine za sifa ya `text-decoration` ni:

- `underline`
- `overline`
- `line-through`

Kama majina ya thamani zinavyoonyesha, `underline` huongeza mstari chini ya maandishi, `overline` huongeza mstari juu ya maandishi, na `line-through` huongeza mstari katikati ya maandishi, kama kufuta maandishi hayo.

## Kuna Zaidi Kuhusu Sifa ya `text-decoration`

Sifa ya `text-decoration` ni sifa ya ufupisho inayochanganya sifa zifuatazo:

- `text-decoration-line`: `none`, `underline`, `overline`, na `line-through`
- `text-decoration-color`: Rangi ya mstari.
- `text-decoration-style`: `solid`, `double`, `dotted`, `dashed`, au `wavy`.
- `text-decoration-thickness`: Unene wa mstari.

Kwa mfano, hii huongeza mstari mwekundu wenye mizunguko kwenye aya:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

Na hii huongeza mstari wa juu wa kijani mara mbili kwenye aya:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

Unaweza pia kuchanganya aina za mistari ikiwa unataka:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
