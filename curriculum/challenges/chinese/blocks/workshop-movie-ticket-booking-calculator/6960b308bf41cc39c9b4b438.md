# --description--

`or` 操作符用于检查两个条件中是否至少有一个为真。下面是你如何在 `if` 语句中用它来进行比较：

```py
day = 'Sunday'
is_raining = False

if day == 'Sunday' or is_raining:
    print('Stay at home')
```

在上面的例子中，`Stay at home` 被打印出来，因为第一个条件为真，尽管 `is_raining` 是 `False`。

额外费用也应该在周末收取。通过使用 `or` 操作符，将 `if show_time == 'Evening':` 这一行的条件更新为将现有条件与第二个检查 `is_weekend` 是否为真值的条件结合起来。
