# --description--

En este taller, trabajarás con un directorio inteligente del campus y crearás tablas de consulta a partir de datos anidados.
Usarás estas tablas de consulta para realizar búsquedas rápidas y eficientes. Se te ha proporcionado el `rawData`.

Tómate un momento para observar su forma: cada clave es el nombre de un departamento y su valor contiene un `Dept_code` junto con
un arreglo `programs`. Cada programa luego contiene su propio arreglo de `instructors`.

Para comenzar, registra `rawData` en la consola para que puedas inspeccionar esta estructura anidada antes de trabajar con ella.

# --after-each--
