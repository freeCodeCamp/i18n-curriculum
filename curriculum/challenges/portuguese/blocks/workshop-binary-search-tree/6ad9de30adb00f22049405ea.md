# --description--

Agora crie uma classe chamada `BinarySearchTree` para representar a própria árvore. Dê a ela um método `__init__` que receba apenas `self`.

Uma árvore nova não tem nós, então defina um atributo `root` como `None` dentro do método `__init__`.
