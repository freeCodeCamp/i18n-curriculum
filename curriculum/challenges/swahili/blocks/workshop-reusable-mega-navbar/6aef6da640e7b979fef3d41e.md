# --description--

Ili kufungua na kufunga `sub-menu`, sehemu yako ya `Navbar` inahitaji kukumbuka kama `sub-menu` iko wazi kwa sasa. Data ambayo sehemu inakumbuka, na ambayo inaweza kubadilika kwa muda, huitwa state. Kila wakati state inapotabadilika, React huonyesha sehemu tena ili ukurasa uonyeshe thamani mpya.

Utajifunza zaidi kuhusu state katika mafundisho yajayo. Kwa sasa, unahitaji tu kujua kwamba unaweza kuongeza state kwenye sehemu ya kitendakazi kwa kutumia `useState` hook. Hooks ni kitendakazi maalum kinachokuwezesha kutumia vipengele vya React katika sehemu zako. Kwa sababu React imeingizwa kwa kipengele cha `script` katika warsha hii, unaweza kupata hook kama `React.useState`:

```jsx
const [count, setCount] = React.useState(0);
```

`React.useState` huchukua thamani ya awali ya state kama hoja yake na hurudisha safu ya data yenye vitu viwili, ambavyo vinatolewa hapa kwa ufumbuzi wa muundo wa safu ya data:

- `count` ni kigezo cha state, kinachoshikilia thamani ya sasa.
- `setCount` ni kitendakazi cha kuweka thamani, unachokitumia kufanya sasisho la state.

Ndani ya sehemu ya `Navbar`, tumia `React.useState` kuunda kigezo cha state kinachoitwa `isOpen` na kitendakazi cha kuweka thamani kinachoitwa `setIsOpen`. Kwa kuwa `sub-menu` inapaswa kuanza ikiwa imefungwa, mpe thamani ya awali ya `false`.
