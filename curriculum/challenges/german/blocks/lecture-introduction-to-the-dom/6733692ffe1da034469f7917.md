# --interactive--

Es wird Situationen geben, in denen Sie die Stile eines HTML-Elements innerhalb Ihrer JavaScript-Datei manipulieren müssen. Ein Beispiel dafür ist, wenn Sie ein Menü ausblenden oder anzeigen möchten, wenn ein Benutzer auf eine Schaltfläche klickt.

In dieser Lektion lernen Sie, wie Sie Stile mit den Eigenschaften `Element.style` und `Element.classList` manipulieren.

Die Eigenschaft `Element.style` ist eine schreibgeschützte Eigenschaft, die den inline-Stil eines Elements darstellt. Sie können diese Eigenschaft verwenden, um den Stil eines Elements abzurufen oder festzulegen.

Hier ist ein Beispiel für ein Absatz-Element mit der `id` `para`:

```html
<p id="para">This is a paragraph</p>
```

Sie können die Eigenschaft `style` verwenden, um die Farbe des Absatz-Elements auf Rot zu ändern:

:::interactive_editor

```html
<p id="para">This is a paragraph</p>
<script src="index.js"></script>
```

```js
const paraEl = document.getElementById("para");
paraEl.style.color = "red";
```

:::

Die Eigenschaft `style` kann verwendet werden, um viele CSS-Eigenschaften festzulegen, wie `color`, `background-color`, `font-size`, `font-weight` und so weiter.

Eine weitere Möglichkeit, Stile zu manipulieren, ist die Verwendung der Eigenschaft `Element.classList`. Die Eigenschaft `classList` ist eine schreibgeschützte Eigenschaft, mit der Sie Klassen zu einem Element hinzufügen, entfernen oder umschalten können. Schauen wir uns ein paar Beispiele an.

In diesem Beispiel fügen Sie einem Absatz-Element mit der `id` `para` eine Klasse namens `highlight` hinzu. Im CSS setzen wir die Klasse `highlight` so, dass sie die Hintergrundfarbe des Absatz-Elements auf Gelb ändert. Im JavaScript fügen wir dem Absatz-Element die Klasse `highlight` mit der Methode `classList.add()` hinzu.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />
<p id="para">This is a paragraph</p>
<script src="index.js"></script>
```

```css
.highlight {
  background-color: yellow;
}
```

```js
const paraEl = document.getElementById("para");
paraEl.classList.add("highlight");
```

:::

Sie können auch mehrere Klassen zu einem Element hinzufügen, indem Sie sie als Argumente an die Methode `classList.add()` übergeben:

```js
classList.add("class1", "class2", "class3");
```

Wenn Sie eine Klasse von einem Element entfernen müssen, können Sie die Methode `classList.remove()` wie folgt verwenden:

```js
classList.remove("highlight");
```

Um eine Klasse bei einem Element umzuschalten, können Sie die Methode `classList.toggle()` verwenden. In diesem Beispiel haben wir ein `button`-Element mit der `id` `toggle-btn` und ein `nav`-Element mit der `id` `menu`. Im CSS haben wir einige Styles für das Menü und eine Klasse namens `show` hinzugefügt, die die `display`-Eigenschaft der `.menu` auf `block` ändert. Im JavaScript greifen wir mit der Methode `getElementById()` auf das Menü-Element und das `button`-Element zu. Dann fügen wir dem `button`-Element einen Ereignis-Listener hinzu, der die Klasse `show` auf dem `.menu`-Element umschaltet, wenn auf den Button geklickt wird:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />
<button id="toggle-btn">Toggle Menu</button>

<nav id="menu" class="menu">
  <ul>
    <li>Home</li>
    <li>About</li>
    <li>Products</li>
  </ul>
</nav>
<script src="index.js"></script>
```

```css
.menu {
  display: none;
  background-color: lightgray;
  width: 50%;
  padding: 10px;
}

.menu.show {
  display: block;
}
```

```js
const menu = document.getElementById("menu");
const toggleBtn = document.getElementById("toggle-btn");

toggleBtn.addEventListener("click", () => menu.classList.toggle("show"));
```

:::

Wenn ein Benutzer auf die Schaltfläche klickt, wird die Klasse `show` zum `.menu`-Element hinzugefügt, und das Menü wird angezeigt. Wenn der Benutzer erneut auf die Schaltfläche klickt, wird die Klasse `show` vom `.menu`-Element entfernt, und das Menü wird ausgeblendet.

Durch die Verwendung von Methoden und Eigenschaften wie `style`, `add()`, `remove()` und `toggle()` können Sie die Stile eines Elements mit JavaScript einfach manipulieren und so dynamische und interaktive Webseiten erstellen.
