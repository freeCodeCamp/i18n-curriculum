# --description--

É hora de construir uma árvore. Depois das classes, crie uma variável chamada `bst` e atribua a ela uma nova instância de `BinarySearchTree`. Em seguida, crie uma lista chamada `nodes` com os valores `50`, `30`, `20`, `40`, `70`, `60` e `80`, nesta ordem.

Por fim, use um `for` loop com `node` como variável do loop para inserir cada valor de `nodes` em `bst`.

O primeiro valor, `50`, se torna a raiz. Cada um dos outros valores vai para a esquerda ou para a direita em cada nó até encontrar um espaço vazio, o que resulta nesta árvore:

```md
        50
      /    \
    30      70
   /  \    /  \
  20  40  60  80
```

class TreeNode:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None


class BinarySearchTree:
    def __init__(self):
        self.root = None

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node

    def insert(self, key):
        self.root = self._insert(self.root, key)
