# --description--

함수는 다른 함수를 호출하고 그 반환값을 사용할 수 있습니다. 예를 들어:

```py
def calculate_sum(a, b):
    return a + b

def show_total(a, b):
    total = calculate_sum(a, b)
    print(total)

show_total(3, 4) # 7
```

여기서 `show_total`은 `calculate_sum`을 호출하고, 반환값을 지역 변수 `total`에 할당한 다음 출력합니다.

다음으로, 달걀이 있는지 확인하고 `use_eggs`를 호출해 사용하는 함수를 만들겠습니다. `print(available_eggs)` 문 아래에 `available_eggs`를 유일한 매개변수로 받는 빈 함수 `make_fried_egg`를 정의하세요.

함수 본문 안에는 일단 `pass` 키워드를 사용하세요.

    if eggs_to_use > available_eggs:
        print('The kitchen does not have enough eggs.')
        return available_eggs

    print(f'{eggs_to_use} egg(s) used out of {available_eggs} available.')
