# --description--

Nesta oficina, você vai praticar trabalhar com listas planejando o programa de um concerto de orquestra.

Como você aprendeu nas lições anteriores, uma lista é uma coleção ordenada de itens. Você cria uma lista colocando itens separados por vírgulas dentro de colchetes:

```py
fruits = ['apple', 'banana', 'cherry']
```

Crie uma variável chamada `pieces` e atribua a ela uma lista contendo as strings `Carnival Overture`, `Song to the Moon` e `Silent Woods`, nesta ordem.
