# --description--

이 실습에서는 각 노드가 리스트에서 다음 노드와 이전 노드를 모두 참조하는 이중 연결 리스트를 만드세요.

**목표:** 아래 사용자 스토리를 충족하고 모든 테스트를 통과하여 실습을 완료하세요.

**사용자 스토리:**

1. `DoublyLinkedList`라는 이름의 클래스가 있어야 합니다.
1. `DoublyLinkedList`는 `Node`라는 이름의 중첩된 클래스를 가져야 하며, 그 `__init__` 메서드는 다음을 수행해야 합니다:
   - `element` 매개변수와, 기본값이 `None`인 선택적 `previous` 매개변수를 받습니다.
   - `element` 속성을 `element` 매개변수의 값으로 설정합니다.
   - `previous` 속성을 `previous` 매개변수의 값으로 설정합니다.
   - `next` 속성을 `None`으로 설정합니다.
1. `DoublyLinkedList`의 `__init__` 메서드는 `length` 속성을 `0`으로, `head`와 `tail` 속성을 `None`으로 설정해야 합니다.
1. `DoublyLinkedList`는 리스트에 노드가 없으면 `True`를, 그렇지 않으면 `False`를 반환하는 `is_empty` 메서드를 가져야 합니다.
1. `DoublyLinkedList`는 `element`를 받는 `add` 메서드를 가져야 하며, 이 메서드는 다음을 수행해야 합니다:
   - 해당 `element`를 담은 새 `Node`를 만들어 리스트 끝에 추가합니다.
   - 새 노드의 `previous` 속성을, 추가 전에 꼬리였던 노드로 설정합니다. 리스트가 비어 있었다면 `None`으로 설정합니다.
   - 리스트가 비어 있었다면 `head`를, 그리고 `tail`과 `length`를 갱신합니다.
   - 리스트 끝을 찾기 위해 리스트를 순회하지 않습니다.
1. `DoublyLinkedList`는 `element`를 받는 `remove` 메서드를 가져야 하며, 이 메서드는 다음을 수행해야 합니다:
   - `element`가 주어진 `element`와 같은 모든 노드를 제거합니다.
   - 남아 있는 노드들의 `next`와 `previous` 참조가 올바르게 연결된 상태를 유지합니다.
   - 필요한 경우 리스트의 `head`, `tail`, `length`를 갱신합니다.
   - 일치하는 노드가 없거나 리스트가 비어 있으면 리스트를 변경하지 않습니다.
1. `DoublyLinkedList`는 노드의 순서를 제자리에서 뒤집는 `reverse` 메서드를 가져야 합니다.
1. `DoublyLinkedList`는 연결 리스트의 요소를 `head`부터 `tail`까지 리스트로 반환하는 `to_list` 메서드를 가져야 합니다.

class DoublyLinkedList:
    class Node:
        def __init__(self, element, previous=None):
            self.element = element
            self.previous = previous
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None
        self.tail = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element, self.tail)
        if self.is_empty():
            self.head = node
        else:
            self.tail.next = node
        self.tail = node
        self.length += 1

    def remove(self, element):
        current_node = self.head
        while current_node is not None:
            next_node = current_node.next
            if current_node.element == element:
                if current_node.previous is not None:
                    current_node.previous.next = current_node.next
                else:
                    self.head = current_node.next
                if current_node.next is not None:
                    current_node.next.previous = current_node.previous
                else:
                    self.tail = current_node.previous
                self.length -= 1
            current_node = next_node

    def reverse(self):
        current_node = self.head
        while current_node is not None:
            current_node.previous, current_node.next = current_node.next, current_node.previous
            current_node = current_node.previous
        self.head, self.tail = self.tail, self.head

    def to_list(self):
        elements = []
        current_node = self.head
        while current_node is not None:
            elements.append(current_node.element)
            current_node = current_node.next
        return elements
