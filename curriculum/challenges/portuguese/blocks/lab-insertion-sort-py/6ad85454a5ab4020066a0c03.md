# --description--

A ordenação por inserção constrói uma parte ordenada no início da lista, um elemento por vez. Começa tratando o primeiro elemento como ordenado. Depois, pega o próximo elemento e o move para trás dentro da parte ordenada, deslocando ou trocando cada elemento maior uma posição para a direita, até encontrar um elemento que seja menor ou igual a ele. Isso se repete para cada elemento restante até que toda a lista esteja ordenada.

A ordenação por inserção tem complexidade quadrática no tempo nos casos médio e pior, mas executa em tempo linear quando a lista já está ordenada.

**Objetivo:** Cumprir as user stories abaixo e fazer todos os testes passarem para completar o laboratório.

**Histórias de Usuário:**

1. Você deve definir uma função chamada `insertion_sort` com um parâmetro que representa a lista de itens.
1. Sua função `insertion_sort` deve ordenar a lista no lugar, do menor para o maior, e retorná-la.
1. Sua função `insertion_sort` deve seguir o algoritmo de ordenação por inserção, inserindo cada elemento, da esquerda para a direita, em sua posição correta dentro da parte ordenada no início da lista.
1. Sua função `insertion_sort` deve parar de mover um elemento para trás assim que encontrar um elemento que seja menor ou igual a ele.
1. Sua função `insertion_sort` não deve usar nem o método embutido `sort()` nem a função `sorted()`.

**Nota:** Você não deve importar nenhum módulo nem usar métodos que adicionem ou removam itens da lista.

```py
def insertion_sort(items):
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j -= 1
        items[j + 1] = current
    return items
```
