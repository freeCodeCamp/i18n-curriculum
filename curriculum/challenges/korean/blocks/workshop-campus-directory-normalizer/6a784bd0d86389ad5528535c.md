# --description--

각 프로그램은 고유한 `instructors` 배열을 가지고 있습니다. 프로그램 루프 안에 중첩된 세 번째 `for` 루프를 추가하여 `k = 0`부터 `program.instructors.length`까지 `program.instructors`를 반복하세요.

강사 루프를 추가하기 전에 이전 단계에서 `console.log(departmentsById[departmentId])`를 삭제하세요.

이 루프 안에서 `instructor`라는 변수를 선언하고 `program.instructors[k]`로 설정한 다음, `instructor`를 콘솔에 출력하세요.
