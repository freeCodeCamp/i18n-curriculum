# --description--

Bubble sort hufanya kazi kwa kurudia kurudia kupita kwenye orodha, kulinganisha vipengele vinavyopakana, na kubadilishana nafasi ikiwa viko nje ya mpangilio. Baada ya kila mzunguko, thamani kubwa zaidi isiyopangwa "huinuka" hadi mwisho wa orodha. Algoriti inasimama wakati mzunguko mzima unakamilika bila kubadilishana nafasi yoyote.

Bubble sort ina ugumu wa wakati wa mduara wa mraba katika hali ya wastani na mbaya zaidi, kwa hivyo haitumiki sana katika vitendo.

**Lengo:** Timiza hadithi za watumizi zilizo hapa chini na upite vipimo vyote ili kumaliza maabara.

**Hadithi za watumizi:**

1. Unapaswa kufafanua kitendakazi kinachoitwa `bubble_sort` chenye kigezo kimoja kinachowakilisha orodha ya vitu.
1. Kitendakazi chako cha `bubble_sort` kinapaswa kupanga orodha hapo hapo kutoka kidogo hadi kikubwa na kurudisha orodha hiyo.
1. Kitendakazi chako cha `bubble_sort` kinapaswa kufuata algoriti ya bubble sort, likilinganisha vipengele vinavyopakana na kubadilishana nafasi tu wakati kipengele cha kushoto ni kikubwa kuliko cha kulia.
1. Kitendakazi chako cha `bubble_sort` kinapaswa kusimama mara tu mzunguko kupitia orodha unakamilika bila kubadilishana nafasi.
1. Kitendakazi chako cha `bubble_sort` hakipaswi kutumia njia ya `sort()` iliyojengwa ndani wala kitendakazi cha `sorted()`.

**Kumbuka:** Hupaswi ku-import moduli yoyote katika msimbo wako.

```js
({
  test: () =>
    runPython(`
from collections import UserList

class CustomList(UserList):
    def __init__(self, *args, **kwargs):
        self._record = []
        super().__init__(*args, **kwargs)

    def __setitem__(self, key, value):
        self._record.append((key, value))
        super().__setitem__(key, value)

def expected_swaps(items):
    items = list(items)
    swaps = []
    swapped = True
    while swapped:
        swapped = False
        for j in range(len(items) - 1):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swaps.append({(j, items[j]), (j + 1, items[j + 1])})
                swapped = True
    return swaps

for values in ([33, 1, 89, 2, 67, 245], [4, 4, 2, 2, 1, 4, 3]):
    list_to_sort = CustomList(values)
    bubble_sort(list_to_sort)
    record = list_to_sort._record
    expected = expected_swaps(values)
    assert len(record) == 2 * len(expected)
    actual = [set(record[i:i + 2]) for i in range(0, len(record), 2)]
    assert actual == expected
    `)
});
```

```py
def bubble_sort(items):
    n = len(items)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swapped = True
        if not swapped:
            break
    return items
```
