# --description--

在本次工作坊中，你将通过创建一个检查应用是否需要更新的程序来练习使用元组。

每个软件版本都会有一个版本号，这样人们可以区分不同版本并知道哪个是更新的。一个常见的约定是使用三个用点分隔的数字，格式为 `MAJOR.MINOR.PATCH`：

- 当有可能导致旧代码或文件无法与新版本兼容的大改动时，`MAJOR` 数字会增加。
- 当以兼容之前版本的方式添加新特色时，`MINOR` 数字会增加。
- 当进行小修复，比如修复错误但不添加新特色时，`PATCH` 数字会增加。

像 `2.1.0` 这样的版本可以用一个包含三个整数的元组来保存：主版本号、次版本号和补丁号。

创建一个名为 `releases` 的变量，并赋值一个包含以下版本元组的元组，顺序保持不变：

```py
(1, 9, 0), (2, 0, 0), (1, 9, 1), (2, 1, 0),
(2, 1, 1), (2, 2, 0), (1, 9, 2), (2, 2, 1)
```

这些版本按发布顺序列出，而不是从最低版本到最高版本。即使版本 `2.0.0` 已发布，旧的 `1.9` 系列仍在不断修复。
