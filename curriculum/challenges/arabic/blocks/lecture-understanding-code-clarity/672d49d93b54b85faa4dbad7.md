# --description--

تمامًا كما يمكن للنقطة (`.`) أن تشير إلى نهاية جملة في اللغة الإنجليزية، يمكن استخدام الفاصلة المنقوطة (`;`) لتحديد نهاية بيان في JavaScript. مع ذلك، لا تعني البيانات بالضرورة نفس الشيء كسطر واحد من الكود المصدري. يمكن أن يمتد البيان عبر عدة أسطر، ويمكن أن يحتوي السطر الواحد على أكثر من بيان.

على سبيل المثال:

```js
let variableOne = 5;
let variableTwo = 10;
```

في هذا الكود، تجعل الفواصل المنقوطة نهاية كل بيان واضحة وصريحة. كما أن JavaScript تحتوي على ميزة الإدراج التلقائي للفواصل المنقوطة (ASI)، التي تسمح لهذه الإعلانات بالبقاء صحيحة دون الحاجة إلى فواصل منقوطة صريحة:

```js
let variableOne = 5
let variableTwo = 10
```

في هذا المثال، تسمح ASI لـ JavaScript بمعاملة كل إعلان كبيان منفصل رغم عدم وجود فواصل منقوطة. مع ذلك، لا تقوم ASI ببساطة بإدراج فاصلة منقوطة بعد كل فاصل سطر.

على سبيل المثال، يمكن أن يسبب فاصل السطر بعد بيان `return` سلوكًا غير متوقع:

```js
function getValue() {
  return
  {
    value: 42
  };
}
```

هنا، تقوم ASI بإدراج فاصلة منقوطة بعد `return`، لذا تُرجع الدالة `undefined` بدلًا من الكائن. كتابة الكائن في نفس السطر يتجنب هذا السلوك:

```js
function getValue() {
  return {
    value: 42
  };
}
```

هذا يوضح لماذا لا تتطابق فواصل الأسطر دائمًا مع حدود البيانات.

يمكن أن تكون الفواصل المنقوطة مفيدة أيضًا عندما يسمح فاصل السطر بخلاف ذلك بتفسير قطعتين من الكود كتعبير واحد. التعبير عن دالة تُنفذ فور تعريفها (IIFE) هو دالة تُشغّل بمجرد تعريفها. إحدى طرق إنشاء IIFE هي تغليف دالة مجهولة، وهي دالة بلا اسم، داخل أقواس عادية ثم إضافة `()` في النهاية لاستدعائها. يمكن أن تسبب IIFE مشكلة عندما لا ينتهي البيان السابق بفاصلة منقوطة:

```js
const message = "Hello"

(function () {
  console.log(message);
})()
```

هنا، لا تُدرج JavaScript فاصلة منقوطة بعد إعلان السلسلة النصية لأن `(` التالية يمكن أن تواصل تعبير المُهيئ. تقوم JavaScript بتحليل المُهيئ كاستدعاء للسلسلة النصية `"Hello"`، مع التعبير الدالي كمعلمة. هذا يؤدي إلى رمي `TypeError` قبل أن تعمل IIFE. إضافة فاصلة منقوطة تنهي الإعلان قبل IIFE:

```js
const message = "Hello";

(function () {
  console.log(message);
})()
```

الفاصلة المنقوطة الصريحة تحافظ على إعلان المتغير وIIFE كبيانات منفصلة.

تُستخدم الفواصل المنقوطة في العديد من لغات البرمجة، بما في ذلك C وC++ وJava. تختلف قواعدها الدقيقة بين اللغات، لكنها عادةً تساعد في تحديد مكان انتهاء البيانات.

المُجمّع يترجم الكود المصدري إلى شكل آخر، مثل كود الآلة، أو البايت كود، أو تمثيل وسيط، حسب اللغة والمُجمّع. لا ينتج التجميع بالضرورة ملفًا تنفيذيًا مستقلًا.

الاستخدام المتسق للفواصل المنقوطة يمكن أن يجعل حدود البيانات أوضح ويجعل الكود أسهل في القراءة والصيانة.
