# --description--

等於平均值的溫度會被標示為 `0.0 °C`，這樣讀起來不太好。它應該被標示為 `average`。

你可以透過在 `else` 後面寫另一個條件運算式來串鏈條件運算式。如果第一個條件為假，Python 就會評估下一個條件運算式：

```py
labels = [
    'large' if num > 100
    else 'medium' if num > 10
    else 'small'
    for num in numbers
]
```

更新你的條件運算式，使其在 `difference` 大於 `0` 時評估為 `f'+{difference} °C'`，在 `difference` 小於 `0` 時評估為 `f'{difference} °C'`，否則評估為字串 `average`。
