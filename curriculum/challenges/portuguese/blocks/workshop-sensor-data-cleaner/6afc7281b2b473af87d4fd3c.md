# --description--

Agora você precisa combinar cada temperatura com seu rótulo.

A função `map()` pode receber mais de um iterável. A cada chamada, ela passa um item de cada iterável para a função, então a função precisa de um parâmetro para cada iterável:

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

Crie uma variável chamada `report`. Atribua a ela o resultado de passar para `map()` uma função lambda, `temperatures` e `difference_labels`, tudo envolvido em uma chamada `list()`. A função lambda deve receber dois parâmetros, `temperature` e `difference_label`, e retornar `f'{temperature} °C ({difference_label})'`.

Depois, imprima `report` em vez de `difference_labels`.
