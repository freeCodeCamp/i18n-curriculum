# --description--

Katika maabara hii, utajenga darasa la vitu la foleni. Foleni hufuata kanuni ya FIFO (ya kwanza kuingia, ya kwanza kutoka: vitu huongezwa mwisho wa foleni na kuondolewa mwanzoni.

**Lengo:** Timiza hadithi za watumizi zilizo hapa chini na upite vipimo vyote ili kumaliza maabara.

**Hadithi za watumizi:**

1. Unapaswa kufafanua darasa la vitu linaloitwa `Queue`. Kielelezo kipya cha `Queue` kinapaswa kuanza tupu.

1. Darasa la vitu la `Queue` linapaswa kuwa na njia zifuatazo:

   - `enqueue`: hupokea kipengele na kuiongeza mwisho wa foleni.
   - `dequeue`: huondoa kipengele kilicho mwanzoni mwa foleni na kurudisha. Ikiwa foleni ni tupu, inapaswa kurudisha `None`.
   - `front`: hurudisha kipengele kilicho mwanzoni mwa foleni bila kuiondoa. Ikiwa foleni ni tupu, inapaswa kurudisha `None`.
   - `size`: hurudisha idadi ya vipengele vilivyomo katika foleni.
   - `is_empty`: hurudisha `True` ikiwa foleni haina vipengele, na `False` vinginevyo.

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
