# --description--

المتغير الذي يُعلن داخل دالة يكون مرئيًا فقط داخل تلك الدالة. يُسمى هذا نطاق المتغير، وهذا النطاق الخاص يُسمى النطاق المحلي. المتغيرات التي تُعلن خارج الدالة تُسمى متغيرات عامة وتكون مرئية في جميع أنحاء البرنامج. على سبيل المثال، الكود التالي سيرجع خطأ:

```js
function myFunction() {
  let x = 10;
}

console.log(x);
```

المتغير `x` مُعلن داخل الدالة `myFunction` ولا يكون مرئيًا خارج الدالة. الكود سيرجع خطأ `ReferenceError` لأن `x` غير معرف.

إذا أعلنت متغيرًا خارج دالة، يُسمى متغيرًا عامًا ويكون مرئيًا في جميع أنحاء البرنامج. على سبيل المثال، الكود التالي سيعمل:

```js
let x = 10;

function myFunction() {
  console.log(x);
}

myFunction();
```

إذا أُعلن متغير بنفس الاسم داخل الدالة، فإنه يحجب المتغير الخارجي.
