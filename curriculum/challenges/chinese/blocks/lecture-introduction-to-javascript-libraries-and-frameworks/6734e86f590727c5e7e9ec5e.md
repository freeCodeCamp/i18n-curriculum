# --description--

React 是最受欢迎的 JavaScript 库之一，用于创建用户界面和网页应用。它最初由 Facebook（现为 Meta）开发，因其效率、灵活性和特色，在网页开发中获得了极大的人气。

React 的一个基本概念是创建可复用的用户界面组件。这些组件，比如按钮、卡片和头像，可以轻松地在你的应用中重复使用。你可以将这些组件嵌套在彼此内部，以构建更复杂、动态的视图。

React 的一个关键优势是这些自定义组件可以在数据变化时独立更新和渲染。

与传统 JavaScript 需要直接操作 DOM（文档对象模型）不同，React 使用虚拟 DOM，从而提升性能和效率。你将在后续课程中了解更多关于虚拟 DOM 及其工作原理的内容。

除了可重用组件，React 还提供了一种强大的方式来管理你的应用状态。状态指的是决定组件如何渲染和行为的数据。

使用 React，你可以轻松跟踪和更新组件的状态，确保 UI 反映最新的数据。你将在后续课程中学习更多关于状态操作的内容。

虽然 JavaScript 生态系统中有许多库，但 freeCodeCamp 主要教授 React，因为它在行业中被广泛使用且需求量大。

在接下来的几节课中，你将深入学习创建自定义组件、管理状态等内容。
