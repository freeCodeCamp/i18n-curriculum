## Класи та об’єкти в Python

- **Визначення класу**: Клас — це шаблон для створення об’єктів. Він визначає поведінку об’єкта через його атрибути та методи. Ось базовий приклад визначення класу в Python:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **Імена класів**: За конвенцією, імена класів використовують PascalCase: кожне слово починається з великої літери, і між словами немає підкреслень, як у `Dog` або `ShoppingCart`.

- **Метод `__init__()`**: Python автоматично викликає `__init__()` щоразу, коли ви створюєте новий об’єкт. Він використовується для налаштування ініціальних атрибутів об’єкта.

- **Параметр `self`**: `self` посилається на конкретний об’єкт, над яким працює метод. Python передає його автоматично, коли ви викликаєте метод об’єкта, тому ви не пишете його у виклику. `self` — це конвенційна назва, але він завжди є першим параметром методу екземпляра.

- **Створення об’єктів**: Об’єкти — це екземпляри класу. Вони створюються викликом класу з необхідними аргументами.

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **Виклик методів об’єктів**: Ви можете викликати методи об’єктів, щоб виконувати дії або отримувати інформацію.

```python
object_name1.method_name()
object_name2.method_name()
```

- **Відмінність між класом і об’єктом**: Клас — це багаторазовий шаблон, а об’єкт — конкретний екземпляр цього класу з реальними даними.

## Атрибути

- **Атрибути екземпляра**: Зазвичай визначаються в `__init__()` з використанням `self` і є унікальними для кожного об’єкта.
- **Атрибути класу**: Визначаються безпосередньо всередині класу і спільні для всіх екземплярів.

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **Динамічна робота з атрибутами**: Іноді ім’я атрибута відоме лише під час виконання, наприклад, коли воно надходить від користувача або з циклу. У такому випадку ви не можете написати `object.name`, тому використовуєте функції, які приймають ім’я як рядок:

  - `getattr(obj, name)` повертає значення атрибута. Він викликає `AttributeError`, якщо атрибут не існує, якщо ви не передасте значення за замовчуванням як третій аргумент.
  - `setattr(obj, name, value)` створює або оновлює атрибут.
  - `hasattr(obj, name)` повертає `True`, якщо атрибут існує, інакше `False`.
  - `delattr(obj, name)` видаляє атрибут.

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **Перевірка атрибутів за допомогою `dir()`**: Функція `dir()` повертає список імен атрибутів і методів об’єкта. Поєднуйте її з `callable()`, щоб відокремити методи від атрибутів даних.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## Методи

- **Методи**: Функції, визначені всередині класу, які працюють з атрибутами об’єкта.

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **Доступ до методів**: Викликайте методи об’єктів за допомогою точкової нотації. Ось приклад виклику методу `describe` на двох різних об’єктах car:

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## Dunder (магічні) методи

- **Визначення**: Спеціальні методи, які починаються і закінчуються подвійним підкресленням (наприклад, `__init__`, `__len__`, `__str__`, `__eq__`). Python використовує їх внутрішньо для вбудованих операцій.

- **Поведінка без кастомних спеціальних методів**: Python не здогадується, як вбудовані операції мають використовувати атрибути кастомного об’єкта. Він використовує успадковану поведінку за замовчуванням, якщо вона є, і викликає `TypeError` для непідтримуваних операцій.

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **Що змінюють кастомні методи**: `__len__()` змушує `len()` повертати кількість сторінок замість помилки. `__str__()` замінює стандартне представлення на читабельне резюме. `__eq__()` змушує `==` порівнювати кількість сторінок замість перевірки, чи обидва імена посилаються на один і той самий об’єкт.

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **Непрямий виклик dunder-методів**: Вам не потрібно викликати dunder-методи напряму. Замість цього Python автоматично викликає їх, коли відбуваються певні дії. Ці операції включають:

  - **арифметичні дії, такі як додавання, віднімання, множення, ділення та інші**. `__add__()` викликається для додавання, `__sub__()` для віднімання, `__mul__()` для множення, а `__truediv__()` для ділення.
        
  - **операції з рядками, такі як конкатенація, повторення, форматування та перетворення в текст**. `__add__()` викликається для конкатенації, `__mul__()` для повторення, `__format__()` для форматування, `__str__()` і `__repr__()` для перетворення в текст тощо.
        
  - **операції порівняння, такі як рівність, менше, більше та інші**. `__eq__()` викликається для перевірки рівності, `__lt__()` для менше, `__gt__()` для більше тощо.
        
  - **операції ітерації, такі як зробити об’єкт ітерованим та переходити до наступних елементів**. `__iter__()` викликається для повернення ітератора, а `__next__()` — для отримання наступного елемента.

## Приклад із реального життя: кошик для покупок

- **Клас Cart з dunder-методами**: Дозволяє додавати, видаляти, ітерувати та перевіряти вміст із вбудованою поведінкою.

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## Спільна робота об’єктів

- **Передача об’єктів як аргументів**: Об’єкти можна передавати конструкторам інших класів, так само як числа або рядки.

- **Зберігання об’єктів у атрибутах**: Об’єкт можна зберігати в атрибуті іншого об’єкта. Тоді ви можете викликати методи через цей атрибут, ланцюжком точкової нотації, як у `receiver.inbox.receive_email(email)`.

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## Робота з датами і часом

- **Отримання поточної дати і часу**: Виклик `datetime.datetime.now()` повертає поточні дату і час як об’єкт `datetime`.

- **Збереження мітки часу в екземплярі**: Викличте `datetime.datetime.now()` всередині `__init__()` і призначте результат атрибуту, щоб зафіксувати час створення об’єкта.

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **Форматування за допомогою `strftime()`**: Метод `strftime()` перетворює об’єкт `datetime` у рядок, використовуючи коди форматування: `%Y` для чотиризначного року, `%m` для місяця, `%d` для дня, `%H` для години (24-годинний формат), `%M` для хвилин і `%S` для секунд. Будь-які інші символи, як-от `-`, `/`, `:`, або пробіли, зберігаються як літеральні роздільники.

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
