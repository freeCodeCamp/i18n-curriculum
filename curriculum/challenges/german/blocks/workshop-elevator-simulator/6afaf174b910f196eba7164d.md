# --description--

Der Aufzug sollte weiterhin Anfragen bedienen, solange noch welche übrig sind. Eine `while`-Schleife ist dafür perfekt, weil sie sich wiederholt, solange ihre Bedingung wahr ist. Hier eine Erinnerung an die Syntax:

```py
while condition:
    # code to repeat
    ...
```

Eine nicht-leere Liste ist wahrheitswertig und eine leere Liste ist falsch, daher können Sie eine Liste als Bedingung der Schleife verwenden, damit sie läuft, bis die Liste leer ist.

Erstellen Sie eine `while`-Schleife, die läuft, solange `requests` nicht leer ist. Verwenden Sie innerhalb der Schleife `pop(0)`, um die erste Anfrage aus `requests` zu entfernen und weisen Sie sie einer Variablen namens `target` zu. Geben Sie dann `target` aus.

Da `pop(0)` die Liste bei jeder Iteration kürzer macht, wird die Liste schließlich leer und die Schleife stoppt. Ohne das würde die Bedingung nie falsch werden und die Schleife würde endlos laufen.
