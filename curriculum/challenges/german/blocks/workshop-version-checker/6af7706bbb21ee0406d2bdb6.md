# --description--

Als Nächstes schreiben Sie eine Funktion, um eine neue Version zu veröffentlichen.

Definieren Sie unter Ihrer Funktion `check_for_update` eine Funktion namens `release_version` mit drei Parametern: `releases`, `release_type` und `base_version`. Geben Sie `base_version` einen Standardwert von `None`. Das ist die Version, von der aus die neue Version erstellt wird, und `None` bedeutet, dass von der neuesten Version aus gebaut wird.

Verwenden Sie innerhalb der Funktion eine `if`-Anweisung, um zu prüfen, ob `base_version` `None` ist. Falls ja, weisen Sie `base_version` das erste Element von `releases` zu, sortiert von der höchsten bis zur niedrigsten Version.

releases = (

def check_for_update(installed, releases):
    sorted_releases = tuple(sorted(releases, reverse=True))
    latest = sorted_releases[0]

    if installed not in releases:
        return 'not a known release', latest

    if installed == latest:
        return 'up to date', latest

    if installed[0] < latest[0]:
        update_type = 'major update'
    elif installed[:2] < latest[:2]:
        update_type = 'minor update'
    else:
        update_type = 'patch update'

    releases_behind = sorted_releases.index(installed)
    return f'{update_type} available, releases behind: {releases_behind}', latest
