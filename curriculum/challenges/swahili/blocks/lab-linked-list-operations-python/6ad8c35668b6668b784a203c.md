# --description--

Katika warsha hii, utatekeleza shughuli za ziada kwa muundo wa data wa orodha iliyounganishwa, ukijenga juu ya darasa la `LinkedList` ulilotengeneza katika warsha iliyopita.

**Lengo:** Timiza hadithi za watumizi zilizo hapa chini na upite vipimo vyote ili kumaliza maabara.

**Hadithi za watumizi:**

1. Darasa lako la `LinkedList` linapaswa kuwa na njia ya `contains` inayochukua kipengele kama hoja yake. Inapaswa kurudisha `True` ikiwa kipengele kiko katika orodha iliyounganishwa, na `False` vinginevyo.
1. Darasa lako la `LinkedList` linapaswa kuwa na njia ya `get_at` inayochukua kielezo kama hoja yake. Inapaswa kurudisha kipengele kilichopo kwenye kielezo hicho katika orodha iliyounganishwa. Ikiwa kielezo kiko nje ya mipaka, inapaswa kurudisha `None`.
1. Darasa lako la `LinkedList` linapaswa kuwa na njia ya `insert_at` inayochukua kielezo na kipengele kama hoja zake. Inapaswa kuingiza kipengele kwenye nafasi iliyotolewa katika orodha iliyounganishwa na kusasisha sifa ya `length`. Kielezo kinacholingana na urefu wa orodha ni halali na kinapaswa kuongeza kipengele mwishoni. Ikiwa kielezo kiko nje ya mipaka, haipaswi kubadilisha orodha.
1. Darasa lako la `LinkedList` linapaswa kuwa na njia ya `remove_at` inayochukua kielezo kama hoja yake. Inapaswa kuondoa nodi iliyopo kwenye kielezo hicho katika orodha iliyounganishwa na kusasisha sifa ya `length`. Ikiwa kielezo kiko nje ya mipaka, haipaswi kubadilisha orodha.
1. Darasa lako la `LinkedList` linapaswa kuwa na njia ya `clear` inayofuta vipengele vyote kutoka katika orodha iliyounganishwa, ikirejesha hali ya orodha kuwa tupu kwa kuweka `head` kuwa `None` na `length` kuwa `0`.

**Kumbuka:** Baadhi ya mitihani ya baadaye inategemea njia za awali. Kwa mfano, ikiwa `get_at` haijatekelezwa kwa usahihi, mitihani ya njia kama `insert_at` na `remove_at` inaweza kushindwa hata kama njia hizo zina karibu kuwa sahihi.

```py
class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
```
