## Instalando um editor de código ou IDE

Na lição anterior, você aprendeu como instalar Python no seu dispositivo local. Nesta lição, você vai aprender como executar código Python localmente.

Antes de começar a criar seus scripts Python localmente, você precisará instalar um editor de código ou IDE. IDE significa ambiente de desenvolvimento integrado. Um IDE combina recursos como editor de código, ferramentas de teste e um terminal.

Um editor de código popular que muitos desenvolvedores usam é o VS Code. Visite `https://code.visualstudio.com/download` para baixar o VS Code, que suporta macOS, Windows e Linux. Este é o editor que será usado nesta lição.

Outras opções comuns para desenvolvimento em Python incluem:

- PyCharm
- Spyder

## Criando um arquivo Python

Depois de instalar o VS Code, abra-o e selecione `File`, depois `Open Folder`. Escolha ou crie uma pasta para seu projeto. Para prática extra fora da lição, você pode querer uma pasta chamada `python-projects`.

Abra o Explorer na barra lateral esquerda do VS Code. Selecione o ícone `New File`, que parece uma folha de papel com um sinal de mais. Crie um arquivo chamado `main.py` e pressione <kbd>Enter</kbd>. A extensão `.py` identifica que é um arquivo Python.

Abra seu arquivo `main.py` e digite o seguinte código:

```py
print("Hello, world!")
```

## Instalar a extensão Python

Para instalar a extensão oficial Python da Microsoft, siga os passos específicos abaixo:

### Método A: Dentro da aplicação

1. Abra a visualização de Extensões clicando no ícone de quatro blocos na barra de atividades do lado esquerdo. Alternativamente, pressione <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (Windows / Linux) ou <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (macOS).
1. Digite `Python` na barra de busca no topo.
1. Procure pelo resultado principal chamado Python, certificando-se que o editor listado abaixo seja Microsoft.
1. Clique no botão azul <kbd>Install</kbd>.

### Método B: Terminal / Linha de comando

Se preferir instalar a extensão pelo terminal, primeiro certifique-se de que o comando `code` está disponível. No macOS, abra a Paleta de Comandos, execute `Shell Command: Install 'code' command in PATH` e reinicie seu terminal.

Então instale a extensão Python executando:

```bash
code --install-extension ms-python.python
```

## Selecionando um interpretador Python

A extensão funciona como uma ponte, mas não contém os arquivos reais da linguagem Python. Você deve instalar um interpretador Python separadamente no site oficial do Python, caso ainda não tenha feito isso.

Depois que o Python estiver instalado no seu sistema operacional, vincule-o ao seu editor:

1. No VS Code, abra qualquer pasta ou um arquivo que termine em `.py`.
1. Abra a Paleta de Comandos usando <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows / Linux) ou <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS).
1. Digite e selecione `Python: Select Interpreter`.
1. Escolha a versão instalada do Python 3 na lista da sua máquina. Ela agora aparecerá nativamente na barra de status do seu espaço de trabalho.

## Executando seu script Python

Para executar esse código, você tem algumas opções. A primeira é clicar no botão de executar, que parece um botão de play localizado no canto superior direito. Isso abrirá um terminal e executará seu script Python lá. Você deve ver o texto `Hello, world!`

Outra opção é abrir um terminal e executar o programa manualmente usando:

```bash
python main.py
```

Você deve executar este comando na pasta onde `main.py` está salvo. Por exemplo, se `main.py` estiver dentro de uma pasta chamada `python-projects`, primeiro use o seguinte no terminal:

```bash
cd python-projects
```

Depois execute:

```bash
python main.py
```

## Usando `python3` em vez de `python`

Em alguns ambientes, especialmente em sistemas macOS e Linux onde Python 2 e Python 3 estão instalados, pode ser necessário usar `python3` em vez de `python`. Isso é comum quando o comando `python` não existe ou aponta para uma versão mais antiga do Python.

```bash
python3 main.py
```
