## 什么是函数？

函数是可重用的代码片段，当你调用它们时会运行。Python 提供了内置函数，包括你在之前课程中使用过的 `print()`。

另一个有用的内置函数是 `input()`，它允许你提示用户输入：

```python
name = input('What is your name?') # User types "Kolade" and presses Enter  
print('Hello', name) # Output: Hello Kolade
```

另一方面，`int()` 会将数字、布尔值或表现整数的字串转换为整数：

```python
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0 
```

## 定义和调用函数

你也可以编写你自己的自定义函数。为此，你使用 `def` 关键字，后跟你想给函数命名的名称、一对括号和冒号。然后在新的一行，编写你的函数应运行的代码。函数运行的代码也称为函数的体。

这是一个名为 `hello` 的自定义函数示例，它将字串 `Hello World` 打印到终端：

```python
def hello():
    print('Hello World')
```

要运行该函数，你需要用它的名称调用它，后面跟一对括号：

```python
hello() # Hello World
```

注意 `print('Hello World')` 前的缩排。正如你可能从之前的课程中回忆的那样，Python 依赖缩排来确定哪些语句组属于同一组。这些语句组称为代码块。

## 使用参数和参数值

这是另一个简单的函数，用于在终端打印两个数字的和：

```python
def calculate_sum(a, b):
    print(a + b)
```

你可以看到我们的函数 `calculate_sum` 在它的括号中有 `a` 和 `b`，它们由逗号分隔。这些被称为参数。将参数视为占位符变量，作为你调用函数时传入值的“槽”。

要使用参数，你必须传入“arguments”。arguments 是你在调用函数时传递给函数的值。

以下是如何调用 `calculate_sum` 函数来将数字 `3` 和 `1` 相加：

```python
calculate_sum(3, 1) # 4
```

如果你调用函数时参数数量不正确，你将得到一个 `TypeError`：

```python
calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

## 位置参数和关键字参数

`calculate_sum(3, 1)` 中的参数是位置参数。Python 根据它们的位置将它们匹配到参数：`3` 传给 `a`，`1` 传给 `b`。

这是一个参数顺序很重要的函数：

```python
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

如果你交换位置参数，`name` 会接收 `25`，`age` 会接收 `'Alice'`：

```python
introduce(25, 'Alice')
# My name is 25 and I am Alice years old.
```

你也可以通过写参数名后跟 `=` 和一个值来传递关键字参数。Python 根据名字匹配这些参数，所以你可以用不同的顺序写它们：

```python
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

这里，`name='Alice'` 把 `'Alice'` 传给了 `name` 参数。它不会在函数外部赋值一个名为 `name` 的变量。

你可以组合使用位置参数和关键字参数，但位置参数必须放在前面：

```python
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

在关键字参数后放置位置参数会导致 `SyntaxError`：

```python
introduce(name='Alice', 25)
# SyntaxError: positional argument follows keyword argument
```

你也不能为同一个参数提供多次值：

```python
introduce('Alice', name='Bob', age=25)
# TypeError: introduce() got multiple values for argument 'name'
```

在这个调用中，位置参数 `'Alice'` 已经为 `name` 提供了值。传递 `name='Bob'` 会为同一个参数提供第二个值。

## 从函数返回值

函数还使用特殊的 `return` 关键字来退出函数并返回一个值。如果你不显式使用 `return`，Python 默认会返回 `None`。

正如你在同一性操作符的课程中学到的，`None` 表示没有值。在这里，它表示函数没有显式返回结果。

这是一个示例：

```python
def calculate_sum(a, b):
    print(a + b)

my_sum = calculate_sum(3, 1) # 4
print(my_sum) # None
```

你可以看到 `calculate_sum` 函数打印了 `a` 和 `b` 的和，但它没有显式返回任何内容。所以当我们将它的结果赋值给 `my_sum` 时，值实际上是 `None`。为了解决这个问题，你可以使用 `return` 关键字来返回结果：

```python
def calculate_sum(a, b):
    return a + b

my_sum = calculate_sum(3, 1)
print(my_sum) # 4
```

现在，`calculate_sum` 返回 `a` 和 `b` 的和，该和被保存到 `my_sum` 中。
