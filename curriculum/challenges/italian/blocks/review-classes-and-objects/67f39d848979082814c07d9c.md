## Classi e oggetti in Python

- **Definizione di classe**: Una classe è un modello per creare oggetti. Definisce il comportamento che un oggetto avrà tramite i suoi attributi e metodi. Ecco un esempio base di definizione di una classe in Python:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **Nomi delle classi**: Per convenzione, i nomi delle classi usano PascalCase: ogni parola inizia con una lettera maiuscola e non ci sono underscore, come in `Dog` o `ShoppingCart`.

- **Il metodo `__init__()`**: Python chiama automaticamente `__init__()` ogni volta che crei un nuovo oggetto. Serve per impostare gli attributi iniziali dell'oggetto.

- **Il parametro `self`**: `self` si riferisce all'oggetto specifico su cui il metodo sta lavorando. Python lo passa automaticamente quando chiami un metodo su un oggetto, quindi non lo scrivi nella chiamata. `self` è il nome convenzionale, ma è sempre il primo parametro di un metodo di istanza.

- **Creazione di oggetti**: Gli oggetti sono istanze di una classe. Vengono creati chiamando la classe con gli argomenti necessari.

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **Chiamare metodi sugli oggetti**: Puoi chiamare metodi sugli oggetti per eseguire azioni o recuperare informazioni.

```python
object_name1.method_name()
object_name2.method_name()
```

- **Differenza tra classe e oggetto**: Una classe è un modello riutilizzabile, mentre un oggetto è un’istanza specifica di quella classe con dati reali.

## Attributi

- **Attributi di istanza**: Di solito definiti in `__init__()` usando `self`, e unici per ogni oggetto.
- **Attributi di classe**: Definiti direttamente all'interno della classe e condivisi da tutte le istanze.

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **Gestire gli attributi dinamicamente**: A volte il nome dell'attributo è noto solo a runtime, per esempio quando arriva dall'input dell'utente o da un loop. In quel caso non puoi scrivere `object.name`, quindi usi funzioni che prendono il nome come stringa:

  - `getattr(obj, name)` restituisce il valore dell'attributo. Solleva un `AttributeError` se l'attributo non esiste, a meno che non passi un valore predefinito come terzo argomento.
  - `setattr(obj, name, value)` crea o aggiorna un attributo.
  - `hasattr(obj, name)` restituisce `True` se l'attributo esiste, altrimenti `False`.
  - `delattr(obj, name)` elimina un attributo.

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **Ispezionare gli attributi con `dir()`**: La funzione `dir()` restituisce una lista con i nomi degli attributi e dei metodi di un oggetto. Combinala con `callable()` per separare i metodi dagli attributi dati.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## Metodi

- **Metodi**: Funzioni definite all’interno di una classe che operano sugli attributi dell’oggetto.

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **Consultare metodi**: Chiama i metodi sugli oggetti usando la notazione a punto. Ecco un esempio di chiamata del metodo `describe` su due diversi oggetti auto:

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## Metodi dunder (magici)

- **Definizione**: Metodi speciali che iniziano e finiscono con un doppio underscore (es. `__init__`, `__len__`, `__str__`, `__eq__`). Python li usa internamente per operazioni integrate.

- **Comportamento senza metodi speciali personalizzati**: Python non deduce come le operazioni integrate dovrebbero usare gli attributi di un oggetto personalizzato. Usa il comportamento predefinito ereditato dove disponibile e solleva un `TypeError` per operazioni non supportate.

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **Cosa cambiano i metodi personalizzati**: `__len__()` fa sì che `len()` restituisca il numero di pagine invece di sollevare un errore. `__str__()` sostituisce la rappresentazione predefinita con un riepilogo leggibile. `__eq__()` fa sì che `==` confronti il numero di pagine invece di verificare se entrambi i nomi si riferiscono allo stesso oggetto.

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **Chiamare i metodi dunder indirettamente**: Non devi chiamare direttamente i metodi dunder. Python li chiama automaticamente quando avvengono certe azioni. Queste operazioni includono:

  - **operazioni aritmetiche come addizione, sottrazione, moltiplicazione, divisione e altre**. `__add__()` viene chiamato per l’addizione, `__sub__()` per la sottrazione, `__mul__()` per la moltiplicazione e `__truediv__()` per la divisione.
        
  - **operazioni sulle stringhe come concatenazione, ripetizione, formattazione e conversione in testo**. `__add__()` viene chiamato per la concatenazione, `__mul__()` per la ripetizione, `__format__()` per la formattazione, `__str__()` e `__repr__()` per la conversione in testo, e così via.
        
  - **operazioni di confronto come uguaglianza, minore di, maggiore di e altre**. `__eq__()` viene chiamato per i controlli di uguaglianza, `__lt__()` per minore di, `__gt__()` per maggiore di, e così via.
        
  - **operazioni di iterazione come rendere un oggetto iterabile e avanzare attraverso gli elementi**. `__iter__()` viene chiamato per restituire un iteratore e `__next__()` per ottenere il prossimo elemento.

## Esempio reale: carrello della spesa

- **Classe Cart con metodi dunder**: Permette di aggiungere, rimuovere, iterare e controllare il contenuto con comportamento integrato.

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## Oggetti che lavorano insieme

- **Passare oggetti come argomenti**: Gli oggetti possono essere passati ai costruttori di altre classi, proprio come numeri o stringhe.

- **Archiviare oggetti negli attributi**: Un oggetto può essere archiviato nell'attributo di un altro oggetto. Puoi quindi chiamare metodi tramite quell'attributo concatenando la notazione a punto, come in `receiver.inbox.receive_email(email)`.

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## Lavorare con date e orari

- **Ottenere la data e l'ora correnti**: Chiamare `datetime.datetime.now()` restituisce la data e l'ora correnti come oggetto `datetime`.

- **Archiviare un timestamp su un'istanza**: Chiama `datetime.datetime.now()` dentro `__init__()` e assegna il risultato a un attributo per registrare quando l'oggetto è stato creato.

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **Formattare con `strftime()`**: Il metodo `strftime()` trasforma un oggetto `datetime` in una stringa, usando codici di formato: `%Y` per l'anno a quattro cifre, `%m` per il mese, `%d` per il giorno, `%H` per l'ora (formato 24 ore), `%M` per i minuti e `%S` per i secondi. Qualsiasi altro carattere, come `-`, `/`, `:` o spazi, viene mantenuto come separatore letterale.

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
