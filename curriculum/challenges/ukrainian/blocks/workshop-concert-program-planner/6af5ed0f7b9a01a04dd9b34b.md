# --description--

Розпакування дозволяє призначити елементи списку кільком змінним в одному рядку. Ви можете використати змінну зі зірочкою, щоб зібрати всі залишкові елементи у список:

```py
fruits = ['apple', 'banana', 'cherry']
first, *rest = fruits
print(first) # apple
print(rest) # ['banana', 'cherry']
```

Розпакуйте `pieces` у три змінні: `opening` для першого елемента, `middle` для всіх елементів посередині та `closing` для останнього елемента. Потім виведіть `opening`, `middle` і `closing` у трьох окремих викликах `print()`.
