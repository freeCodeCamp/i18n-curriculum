# --description--

A temperatura igual à média recebe o rótulo `0.0 °C`, que não fica bom. Ela deveria receber o rótulo `average` em vez disso.

Você pode encadear expressões condicionais escrevendo outra expressão condicional após `else`. Se a primeira condição for falsa, o Python avalia a próxima expressão condicional:

```py
labels = [
    'large' if num > 100
    else 'medium' if num > 10
    else 'small'
    for num in numbers
]
```

Atualize sua expressão condicional para que ela avalie para `f'+{difference} °C'` se `difference` for maior que `0`, para `f'{difference} °C'` se `difference` for menor que `0` e para a string `average` caso contrário.
