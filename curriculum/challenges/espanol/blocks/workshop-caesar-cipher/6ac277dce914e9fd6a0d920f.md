# --description--

En Python, `bool` es una subclase de `int`, donde `True` se comporta como `1` y `False` como `0`. Esto significa que `isinstance()` trata los valores booleanos como enteros:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True
```

Por esto, tu función actualmente acepta `True` y `False` como valores de shift.

Usa el operador `or` para agregar una segunda condición a tu sentencia `if` que verifique si `shift` es un booleano con `isinstance(shift, bool)`. Así, tu función también devuelve `Shift must be an integer value.` cuando `shift` es `True` o `False`.
