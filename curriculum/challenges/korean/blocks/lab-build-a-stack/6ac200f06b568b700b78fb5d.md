# --description--

이 실습에서는 함수를 사용해 스택 자료 구조를 구현할 것입니다. 스택은 후입선출(LIFO) 자료 구조로, 요소가 위쪽에서 추가되고 제거됩니다.

스택은 `collection` 키가 요소 목록을 담고 있는 딕셔너리입니다. 스택의 맨 위는 목록의 끝이며, 목록의 마지막 요소가 가장 최근에 추가된 요소입니다.

**목표:** 아래 사용자 스토리를 충족하고 모든 테스트를 통과하여 실습을 완료하세요.

**사용자 스토리:**

1. `collection` 키가 빈 리스트로 설정된 딕셔너리를 반환하는 `init_stack` 함수를 만들어야 합니다.
1. 스택과 요소를 받아 요소를 스택의 맨 위에 추가하는 `push` 함수를 만들어야 합니다.
1. 스택을 받아 맨 위 요소를 제거하고 반환하거나, 스택이 비어 있으면 `None`을 반환하는 `pop` 함수를 만들어야 합니다.
1. 스택을 받아 맨 위 요소를 제거하지 않고 반환하거나, 스택이 비어 있으면 `None`을 반환하는 `peek` 함수를 만들어야 합니다.
1. 스택을 받아 요소가 없으면 `True`, 그렇지 않으면 `False`를 반환하는 `is_empty` 함수를 만들어야 합니다.
1. 스택을 받아 모든 요소를 지우는 `clear` 함수를 만들어야 합니다.

**참고:** 대부분의 테스트는 `init_stack`과 `push` 함수에 의존합니다. 먼저 이 함수들을 구현하세요. `pop`, `peek`, `is_empty`, `clear` 테스트는 스택에 요소를 추가해야 하므로 먼저 구현해야 합니다.

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
