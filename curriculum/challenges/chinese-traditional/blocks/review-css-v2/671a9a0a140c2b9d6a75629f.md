## CSS 基礎知識

- **什麼是 CSS？**：層疊樣式表（CSS）是一種用來套用樣式到 HTML 元素的樣式表語言。CSS 用於設定顏色、背景圖片、版面配置等。
- **CSS 規則的基本結構**：CSS 規則由兩個主要部分組成：選擇器和宣告區塊。選擇器是 CSS 中用來識別並定位特定 HTML 元素以套用樣式的模式。宣告區塊則是為指定的選擇器套用一組樣式。

## 操作 `width` 和 `height` 屬性

- **`width` 屬性**：此屬性指定元素的寬度。如果你沒有指定寬度，則預設值為 `auto`。這讓瀏覽器根據元素的內容、父元素和顯示型別來決定元素的寬度。
- **`min-width` 屬性**：此屬性指定元素的最小寬度。
- **`max-width` 屬性**：此屬性指定元素的最大寬度。
- **`height` 屬性**：此屬性指定元素的高度。同樣地，高度預設值為 `auto`，表示它會根據內部內容調整。
- **`min-height` 屬性**：此屬性指定元素的最小高度。
- **`max-height` 屬性**：此屬性指定元素的最大高度。

## 行內、區塊和行內區塊層級元素

- **行內元素**：行內元素只佔用它們所需的寬度，且不會換行。這些元素會在內容中流動，允許文字和其他行內元素並排顯示。常見的行內元素有 `span`、`a` 和 `img` 元素。
- **區塊元素**：區塊元素預設會佔滿其容器的整個寬度，橫跨容器的寬度。常見的區塊元素有 `div`、`p` 和 `section` 元素。
- **行內區塊元素**：你可以使用 `display` 屬性將元素設定為 `inline-block`。這些元素行為類似行內元素，但可以像區塊元素一樣設定 `width` 和 `height`。

## 外距和內距

- **`margin` 屬性**：此屬性用於在元素的邊框與周圍元素之間套用外部間距。
- **`margin` 簡寫**：你可以指定 1–4 個值來設定邊界的各邊。一個值套用到所有四個邊；兩個值設定 `top` 和 `bottom`，然後是 `right` 和 `left`；三個值設定 `top`、水平（`right` 和 `left`），然後是 `bottom`；四個值設定 `top`、`right`、`bottom`、`left`。
- **`padding` 屬性**：此屬性用於在元素內部、內容與其邊框之間應用間距。
- **`padding` 簡寫**：你可以指定 1–4 個值來設定內距的各邊。一個值套用於所有四邊；兩個值設定 `top` 和 `bottom`，然後是 `right` 和 `left`；三個值設定 `top`、水平（`right` 和 `left`），然後是 `bottom`；四個值設定 `top`、`right`、`bottom`、`left`。

## 背景圖片

- **`background-image` 屬性**：此屬性用於設定元素的背景圖片。
- **`background-size` 屬性**：此屬性設定背景圖片的大小。`contain` 值會將圖片縮放到最大而不裁切或拉伸。`cover` 值會將圖片縮放以涵蓋整個元素，同時保持其長寬比，可能會裁切部分圖片。
- **`background-repeat` 屬性**：預設情況下，背景圖片會在水平方向和垂直方向重複以填滿元素。`no-repeat` 值會停止圖片重複，`repeat-x` 水平重複，`repeat-y` 垂直重複。
- **`background-position` 屬性**：此屬性設定背景圖片在元素內的位置。你可以使用關鍵字如 `top`、`bottom`、`left`、`right` 和 `center`，或是像素和百分比值。
- **`background-attachment` 屬性**：此屬性決定背景圖片是隨內容捲動還是固定不動。預設值為 `scroll`，而 `fixed` 則會讓圖片在頁面捲動時保持在螢幕上的相同位置。
- **`background` 簡寫屬性**：此屬性允許你將多個背景屬性（如 `background-image`、`background-position` 和 `background-attachment`）合併成一個宣告。

## 邊框

- **`border` 屬性**：這是一個簡寫屬性，用於一次設定邊框的寬度、樣式和顏色。常見的邊框樣式包括 `solid`、`dashed`、`dotted` 和 `double`。
- **個別邊框邊**：`border-top`、`border-right`、`border-bottom` 和 `border-left` 屬性讓你分別設定邊框的每一邊。
- **`outline` 屬性**：此屬性會在元素周圍產生一條線，類似邊框。但與 `border` 不同的是，`outline` 不會影響元素的尺寸或版面配置。
- **`border-radius` 屬性**：此屬性用於創建元素邊框的圓角。

## CSS 特異性

- **行內 CSS 特異性**：行內 CSS 擁有最高的特異性，因為它直接套用在元素上，會覆蓋任何內部或外部 CSS。行內樣式的特異性值為 (1, 0, 0, 0)。
- **內部 CSS 特異性**：內部 CSS 定義在 HTML 文件的 `head` 區段的 `style` 元素中。它的特異性低於行內樣式。內部和外部 CSS 具有相同的特異性層級，這由選擇器決定，而非位置。
- **外部 CSS 特異性**：外部 CSS 透過 `head` 區段的 `link` 元素連結，並寫在獨立的 `.css` 檔案中。與內部 CSS 一樣，其特異性由選擇器決定。當兩條規則特異性相同時，來源順序決定勝負：文件中後出現的規則優先。外部 CSS 對大型專案提供最佳的維護性。
- **通用選擇器 (`*`)**：這是一種特殊的 CSS 選擇器，匹配文件中的任何元素。常用於對頁面所有元素套用樣式，有助於重置或標準化不同瀏覽器的樣式。通用選擇器的特異性值最低，為 (0, 0, 0, 0)。
- **型別選擇器**：這些選擇器根據標籤名稱選取元素。型別選擇器的特異性相對較低，特異性值為 (0, 0, 0, 1)。
- **類別選擇器**：這些選擇器由句點 (`.`) 後接類別名稱定義。類別選擇器的特異性值為 (0, 0, 1, 0)，表示它們可以覆蓋型別選擇器，但會被 ID 選擇器和行內樣式覆蓋。
- **ID 選擇器**：ID 選擇器由井字號 (`#`) 後接 ID 名稱定義。ID 選擇器的特異性非常高，高於型別和類別選擇器，但低於行內樣式。特異性值為 (0, 1, 0, 0)。
- **`!important` 關鍵字**：用來賦予樣式規則最高優先權，允許它覆蓋該屬性的其他宣告。使用時會強制瀏覽器套用指定樣式，無視其他選擇器的特異性。使用 `!important` 時應謹慎，因為它可能讓你的 CSS 更難維護和偵錯。

## 絕對單位

- **`px`（像素）**：這是 CSS 中的絕對單位，為固定大小的測量單位，提供精確的尺寸控制。1px 永遠等於 1/96 英吋。
- **`in`（英吋）**：這個絕對單位等於 96px。
- **`cm`（公分）**：這個絕對單位等於 25.2/64 英吋。
- **`mm`（毫米）**：這個絕對單位等於 1/10 公分。
- **`q`（四分之一毫米）**：這個絕對單位等於 1/40 公分。
- **`pc`（派卡）**：這個絕對單位等於 1/6 英吋。
- **`pt`（點）**：這個絕對單位等於 1/72 英吋。

## 相對單位

- **百分比**：這些相對單位允許你將尺寸、大小和其他屬性定義為其父元素的比例。舉例來說，如果你在元素上設定 `width: 50%;`，它將佔據父容器寬度的一半。
- **`em` 單位**：這些單位是相對於元素的字型大小。如果你在 `font-size` 屬性中使用 `ems`，文字大小將相對於父元素的字型大小。
- **`rem` 單位**：這些單位是相對於根元素的字型大小，也就是 `html` 元素。
- **`vh` 單位**：`vh` 代表 `"viewport height"`，而 `1vh` 等於視窗高度的 1%。
- **`vw` 單位**：`vw` 代表 `"viewport width"`，而 `1vw` 等於視窗寬度的 1%。

## `calc` 函式（程式）

- **`calc()` 函式（程式）**：使用 `calc()` 函式（程式），你可以直接在你的樣式表中執行計算，以動態決定屬性值。這表示你可以透過根據視窗大小或其他元素計算尺寸，來創建彈性且響應式的使用者介面。

## 偽類

- **偽類定義**：這些是特殊的 CSS 關鍵字，允許你根據元素的特定狀態或位置來選取元素。
- **`:active` 偽類**：此偽類讓你選取元素的作用中狀態，例如按鈕被點擊時。
- **`:hover` 偽類**：此偽類定義元素的暫留狀態。
- **`:focus` 偽類**：當元素獲得焦點時（通常透過鍵盤導航或使用者點擊表單輸入框），此偽類會套用樣式。
- **`:first-child` 偽類**：選取父元素或文件中的第一個元素。
- **`:last-child` 偽類**：選取父元素或文件中的最後一個元素。
- **`:first-of-type` 偽類**：選取父元素中第一個特定元素類型的出現。
- **`:last-of-type` 偽類**：選取父元素中最後一個特定元素類型的出現。
- **`:nth-of-type(n)` 偽類**：根據同類型兄弟元素中的位置，選取父元素中的特定元素。
- **`:visited` 偽類**：選取使用者已造訪的連結。
- **`:enabled` 偽類**：用於選取目前啟用的表單按鈕或其他元素。
- **`:disabled` 偽類**：讓你為處於停用狀態的互動元素套用樣式。
- **`:checked` 偽類**：用於向使用者表示該元素已被勾選。

## 偽元素

- **`::before` 偽元素**：此偽元素使用 `content` 屬性在元素之前插入像圖示這樣的裝飾性內容。
- **`::after` 偽元素**：此偽元素使用 `content` 屬性在元素之後插入像圖示這樣的裝飾性內容。
- **`::first-letter` 偽元素**：此偽元素會標的元素內容的第一個字母，讓你可以為它設定樣式。
- **`::marker` 偽元素**：此偽元素讓你選取列表項目的標記（項目符號或編號）以進行樣式設定。

## 在 CSS 中使用顏色的不同方式

- **命名顏色**：這些顏色是瀏覽器預定義的顏色名稱。範例包括 `blue`、`darkred`、`lightgreen`。
- **`rgb()` 函式**：RGB 代表紅、綠、藍，是光的三原色。這三種顏色以不同強度組合，產生廣泛的顏色。`rgb()` 函式允許你使用 RGB 色彩模型定義顏色。
- **`rgba()` 函式**：此函式增加第四個值 alpha，控制顏色的透明度。
- **`hsl()` 函式**：HSL 代表色相、飽和度和亮度，是定義顏色的三個關鍵組成部分。
- **`hsla()` 函式**：此函式增加第四個值 alpha，控制顏色的不透明度。
- **十六進位**：十六進位碼（hex code）是一個六字元字串，用於表示 RGB 色彩模型中的顏色。「hex」指的是使用 0 到 9 及 A 到 F 的十六進位數字系統。

## `box-shadow` 屬性

- **定義**：`box-shadow` 屬性用於在元素周圍套用一個或多個陰影。
- **偏移值**：你必須指定水平（`offset-x`）和垂直（`offset-y`）的偏移值。正的 `offset-x` 會將陰影向右移動，負值則向左移動。正的 `offset-y` 會將陰影向下移動，負值則向上移動。若值為 `0`，則不需包含單位。
- **模糊半徑**：此選用值控制陰影的模糊程度。若未指定，預設為 `0`，產生銳利邊緣。數值越高，陰影越柔和。
- **擴散半徑**：此選用值控制陰影的擴展或收縮程度。若未指定，預設為 `0`。
- **陰影顏色**：你可以使用命名顏色、十六進位值、`rgb()`、`rgba()`、`hsl()` 或 `hsla()` 函式來指定顏色。

## 漸層

- **線性漸層**：這些漸層沿直線在顏色間產生漸變。你可以控制這條線的方向和使用的顏色。

## CSS 轉換屬性

- **定義**：此屬性允許你對元素套用各種轉換，例如旋轉、縮放、傾斜或在 2D 或 3D 空間中平移（移動）。
- **`rotate()` 函式**：此函式用於繞元素中心旋轉元素。

## 盒模型

- **定義**：在 CSS 盒模型中，每個元素都被一個盒子包圍。這個盒子由四個組件組成：內容區域、`padding`、`border`、`margin`。
- **內容區域**：內容區域是盒子最內層的部分。它是包含元素實際內容（例如文字或影像）的空間。
- **`padding`**：padding 是緊接內容區域之後的區域。它是內容區域與元素邊框之間的空間。
- **`border`**：border 是 CSS 盒模型中元素的外緣或輪廓。它是元素的視覺邊界。
- **`margin`**：margin 是元素邊框外的空間。它決定元素與周圍其他元素之間的距離。

## `content-box` 和 `border-box` 屬性值

- **`box-sizing` 屬性**：此屬性用來決定 HTML 元素的總 `width` 和 `height` 如何計算。
- **`content-box` 值**：在 `content-box` 模型中，你為元素設定的 `width` 和 `height` 決定內容區域的尺寸，但不包含 `padding` 和 `border`。
- **`border-box` 值**：使用 `border-box` 時，你為元素設定的 `width` 和 `height` 包含內容區域、`padding` 和 `border`。

## CSS 濾鏡屬性

- **定義**：此屬性可用來創建各種效果，例如模糊。
- **`blur()` 函式**：此函式對元素套用模糊效果。數值以像素為單位，代表模糊半徑。

## CSS Flexbox 與 Flex 模型簡介

- **定義**：CSS flexbox 是一種一維版面模型，允許你在容器內以列和行排列元素。
- **彈性模型**：此模型定義彈性項目在彈性容器內的排列方式。每個彈性容器有兩個軸：主軸和交叉軸。

## `flex-direction` 屬性

- **定義**：此屬性設定主軸的方向。`flex-direction` 的預設值為 `row`，會將所有彈性項目放在同一列，方向依瀏覽器預設語言（從左到右或從右到左）。
- **`flex-direction: row-reverse;`**：此設定會反轉列中項目的順序。
- **`flex-direction: column;`**：此設定會將彈性項目垂直排列，而非水平。
- **`flex-direction: column-reverse;`**：此設定會反轉彈性項目垂直排列的順序。

## `flex-wrap` 屬性

- **定義**：此屬性決定彈性容器內的彈性項目如何換行以適應可用空間。`flex-wrap` 可接受三個值：`nowrap`、`wrap` 和 `wrap-reverse`。
- **`flex-wrap: nowrap;`**：預設值。彈性項目不會換行，即使其寬度超過容器寬度。
- **`flex-wrap: wrap;`**：當項目超過容器寬度時，會換行。
- **`flex-wrap: wrap-reverse;`**：項目會反向換行。
- **`flex-flow` 屬性**：是 `flex-direction` 和 `flex-wrap` 的縮寫屬性。

## `justify-content` 屬性

- **定義**：此屬性沿著彈性容器的主軸對齊子元素。
- **`justify-content: flex-start;`**：在這種情況下，彈性項目會對齊到主軸的起點。這可以是水平或垂直方向。
- **`justify-content: flex-end;`**：在這種情況下，彈性項目會沿主軸的末端對齊，無論是水平還是垂直方向。
- **`justify-content: center;`**：這會將彈性項目沿主軸置中。
- **`justify-content: space-between;`**：這會沿主軸均勻分配元素。
- **`justify-content: space-around;`**：這會在主軸內均勻分配彈性項目，並在第一個項目前及最後一個項目後添加空間。
- **`justify-content: space-evenly;`**：這會沿主軸平均分配項目。

## `align-items` 屬性

- **定義**：此屬性用於沿交叉軸分配項目。請記住交叉軸垂直於主軸。
- **`align-items: center;`**：這用於沿交叉軸置中項目。
- **`align-items: flex-start;`**：這會將項目對齊到交叉軸的起點。
- **`align-items: stretch;`**：這用於沿交叉軸拉伸彈性項目。

## CSS `font-family` 屬性

- **定義**：字型家族是一組共享共同設計的字型。屬於同一家族的字型基於相同核心字體，但在樣式、粗細和寬度上有變化。你可以依優先順序指定多個字型家族，從最高到最低，用逗號分隔。這些替代字型會作為備援選項。字型家族列表最後應始終包含泛型字型家族。
- **常見字型家族**：以下是 CSS 中常用的字型家族：serif、sans-serif、monospace、cursive、fantasy。

## 使用不同屬性選擇器和聯結

- **定義**：`attribute` 選擇器允許你根據 HTML 元素的屬性（例如 `href` 或 `title` 屬性）來標的元素。

## 不同型別的 CSS 組合器

- **後代組合器（` `）*選擇器間一個空格**：此組合器用於選取指定父元素的後代元素。
- **子組合器（`>`）**：此組合器用於選取指定父元素的直接子元素。
- **相鄰兄弟組合器（`+`）**：此組合器選取緊接在指定兄弟元素後的元素。
- **後續兄弟組合器（`~`）**：此組合器選取指定元素之後的所有兄弟元素。

## 靜態、相對和絕對定位

- **靜態定位**：這是文件的正常流程。元素依序從上到下、從左到右定位。
- **相對定位**：這允許你使用 `top`、`left`、`right` 和 `bottom` 屬性在正常文件流程中定位元素。你也可以使用相對定位讓元素與頁面上的其他元素重疊。
- **絕對定位**：這讓你可以將元素從正常的文件流程中取出，使其行為獨立於其他元素。

## 固定與黏性定位

- **固定定位**：當元素使用 `position: fixed` 定位時，它會從正常的文件流程中移除，並相對於視窗定位，這表示即使使用者滾動，該元素仍會保持在相同位置。這通常用於像標頭或導覽列這類需要始終保持可見的元素。
- **Sticky Positioning**：這種類型的定位會作為相對定位和固定定位的混合體。最初，元素的行為就像是相對定位，保持在文件的流程中。然而，一旦使用者將元素捲動過某個點，它就會「黏」在視窗（通常是頂部），並且行為就像是固定定位。這非常適合用來建立像是黏性導覽列這類元素，只有當使用者捲動到某個位置時才會變成固定。

## 使用 `z-index` 屬性

- **定義**：CSS 中的 `z-index` 屬性用於控制頁面上重疊定位元素的垂直堆疊順序。

## CSS 訂製屬性（CSS 變數）

- **定義**：CSS 訂製屬性，也稱為 CSS 變數，是由 CSS 作者定義的實體，包含特定值以便在整個文件中重複使用。它們是一項強大的功能，允許更高效、可維護且靈活的樣式表。訂製屬性在建立可主題化設計時特別有用。你可以為不同主題定義一組屬性。

## CSS Grid 基礎

- **定義**：CSS Grid 是一種二維佈局系統，用於在網頁中創建複雜的佈局。Grid 會有列和行，並且它們之間會有間隙。要定義一個 grid 佈局，你需要將 `display` 屬性設為 `grid`。
- **`fr`（分數）單位**：這個單位代表 grid 容器內空間的一部分。你可以使用 `fr` 單位來創建彈性的 grid。
- **在軌道間創建間隙**：在 CSS grid 中，有三種方法可以在軌道間創建間隙。你可以使用 `column-gap` 屬性來創建行之間的間隙。你可以使用 `row-gap` 屬性來創建列之間的間隙。或者你可以使用 `gap` 簡寫屬性來同時為行和列創建間隙。
- **`repeat()` 函式**：這個函式用於重複軌道列表中的部分。你可以用 `repeat()` 函式來代替寫 `grid-template-columns: 1fr 1fr 1fr;`。
- **明確的 Grid**：你可以使用 `grid-template-columns` 或 `grid-template-rows` 屬性來指定線或軌道的數量。
- **隱式的 Grid**：當項目被放置在 grid 之外時，會自動為這些超出範圍的元素創建列和行。
- **`minmax()` 函式**：這個函式用於設定軌道的最小和最大尺寸。
- **Grid 自動排列**：瀏覽器會使用自動排列演算法自動放置項目。`grid-auto-flow` 屬性控制此行為，使用像是 `row`、`column` 或 `dense` 的值來影響排列方向以及是否回填空隙。
- **基於線的放置**：所有 grid 都有線。要指定項目在哪條線開始，可以使用 `grid-column-start` 和 `grid-row-start` 屬性。要指定項目在哪條線結束，可以使用 `grid-column-end` 和 `grid-row-end` 屬性。你也可以選擇使用 `grid-column` 或 `grid-row` 簡寫屬性。
- **`grid-template-areas`**：這個屬性用來為你將要在 grid 上定位的項目提供名稱。
- **對齊**：使用 `justify-items` 和 `align-items` 來控制項目在其 grid 區域內的對齊方式。對單一 grid 項目使用 `justify-self` 和 `align-self` 來覆寫容器設定的對齊方式。
