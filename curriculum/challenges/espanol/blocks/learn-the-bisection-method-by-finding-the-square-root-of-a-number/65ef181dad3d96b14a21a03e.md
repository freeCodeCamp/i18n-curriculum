# --description--

El método de bisección, también conocido como el método de búsqueda binaria, usa una búsqueda binaria para encontrar las raíces de una función de valor real. Funciona reduciendo un intervalo donde se encuentra una raíz hasta que converge a un valor dentro de una tolerancia especificada.

En este proyecto, usarás el método de bisección para encontrar la raíz cuadrada aproximada de un número.

Comienza creando una función llamada `square_root_bisection`. Deja los parámetros vacíos por ahora.
