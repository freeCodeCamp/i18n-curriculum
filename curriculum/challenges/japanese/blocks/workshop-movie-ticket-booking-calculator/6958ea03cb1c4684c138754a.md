# --description--

この最後のステップでは、前のステップで計算した値を使って映画のチケットの最終価格を計算します。

最終的なチケット価格は、基本価格に追加料金とサービス料金を加え、そこから割引を差し引いて計算します。

ある数から別の数を引くには、減算演算子の `-` を使います。同じ式の中で `+` 演算子と組み合わせることもできます。

```py
total_cost = 50
shipping = 5
coupon = 10

amount_due = total_cost + shipping - coupon
print(amount_due)  # 45
```

最後の`if`文の本体内で、サービス料金を出力する行の下に、チケットの最終価格を計算し、`final_price`という変数にストアしてください。

最後に、f文字列を使って`Final price of ticket:`とスペース、その後に小数点以下2桁でフォーマットした`final_price`を出力してください。

base_price = 15
age = 21
seat_type = 'Gold'
show_time = 'Evening'

if age > 17:
    print('User is eligible to book a ticket')

    print('User is eligible for Evening shows')

    print('User is not eligible for Evening shows')

is_member = False

if is_member and age >= 21:
    discount = 3

    print('User does not qualify for membership discount')
print(f'Discount: {discount:.2f}')

extra_charges = 0
if show_time == 'Evening' or is_weekend:
    extra_charges = 2
    print('Extra charges will be applied')
else:
    print('No extra charges will be applied')
print(f'Extra charges: {extra_charges:.2f}')

if age >= 21 or age >= 18 and (show_time != 'Evening' or is_member):
    print('Ticket booking condition satisfied')

    service_charges = 0
    if seat_type == 'Premium':
        service_charges = 5
