# --description--

Aprendamos sobre los atajos de línea de comandos que puedes usar para acelerar la productividad.

Los atajos de terminal y línea de comandos pueden ayudarte a optimizar tus flujos de trabajo y maximizar tu productividad. Para Linux y macOS, que ambos pueden rastrear sus raíces hasta Unix, muchos de estos atajos serán los mismos. Pero para Windows, habrá algunas diferencias.

## Los atajos de <kbd>flecha arriba</kbd> y <kbd>flecha abajo</kbd>

El primer atajo es la tecla <kbd>Flecha arriba</kbd>. Presionarla te permite retroceder en el historial de comandos, uno a la vez. La tecla <kbd>Flecha abajo</kbd> se usa para avanzar en el historial de comandos. Estas dos teclas te permiten recorrer rápidamente los comandos que has ejecutado para encontrar uno que necesites volver a usar.

## Autocompletado con la tecla <kbd>Tab</kbd>

Muchos shells también ofrecen una funcionalidad de autocompletado, proponiendo comandos basados en lo que has empezado a escribir. La tecla <kbd>Tab</kbd> se puede usar para completar el resto de la sugerencia, llenando rápidamente tu línea de comandos con la sintaxis completa. Lo que se sugiere depende del shell, del comando que estés escribiendo y de cómo esté configurado tu shell. Por ejemplo, cuando escribes un nombre de comando, Bash y zsh sugieren comandos que coinciden, y cuando escribes un argumento, suelen sugerir nombres de archivos y directorios que coinciden. PowerShell puede completar comandos, nombres de parámetros, variables y rutas de archivos.

## El atajo <kbd>Control</kbd> + <kbd>L</kbd>

A veces un comando puede generar mucha salida en tu terminal. Este ruido extra puede estorbar o interrumpir tu flujo de trabajo. En terminales basados en *nix que se encuentran en Linux y macOS, puedes presionar <kbd>Control</kbd> + <kbd>L</kbd> para limpiar toda la pantalla y empezar con un prompt limpio. En PowerShell, <kbd>Control</kbd> + <kbd>L</kbd> también limpia la pantalla por defecto, y puedes usar el comando `cls` para el mismo resultado.

## El atajo <kbd>Control</kbd> + <kbd>C</kbd>

Si necesitas interrumpir un comando para detener su ejecución, puedes presionar <kbd>Control</kbd> + <kbd>C</kbd>. Esto envía una solicitud de interrupción al comando que se está ejecutando en primer plano, lo que generalmente lo detiene y te devuelve a un nuevo prompt, permitiéndote continuar con lo que necesites hacer. Algunos programas manejan esta solicitud por sí mismos, por lo que podrían pedirte que confirmes o que continúen ejecutándose. Para los usuarios de PowerShell, <kbd>Control</kbd> + <kbd>C</kbd> también se usa para copiar texto, y solo interrumpe un comando cuando el contexto no es ambiguo (como cuando no hay texto seleccionado para copiar).

## Atajos para terminales basados en *nix

Los siguientes atajos están disponibles solo en terminales basados en *nix, y no tienen una alternativa en PowerShell.

Puede haber momentos en que necesites hacer multitarea, pausando un comando mientras trabajas en otro. Presionar <kbd>Control</kbd> + <kbd>Z</kbd> suspende el comando que se está ejecutando en primer plano y te devuelve a la línea de comandos, donde puedes continuar tu trabajo. Un comando suspendido está pausado, no se está ejecutando. Si quieres que siga ejecutándose en segundo plano, usa el comando `bg`. Cuando necesites traerlo de vuelta al primer plano, usa el comando `fg`.

Y finalmente, puede haber comandos que necesites ejecutar dos veces seguidas. Puedes presionar la tecla <kbd>Flecha arriba</kbd> para retroceder al comando ejecutado previamente, pero también puedes escribir dos signos de exclamación (`!!`) en la línea de comandos y presionar <kbd>Enter</kbd>: esto ejecutará automáticamente el último comando ejecutado.

Muchos terminales ofrecen aún más atajos, y te animo a leer la documentación de tu configuración particular para encontrar los atajos que mejor funcionen para ti. Pero estos atajos universales básicos deberían servir como un excelente punto de partida para maximizar tu productividad y convertirte en un experto en terminal.
