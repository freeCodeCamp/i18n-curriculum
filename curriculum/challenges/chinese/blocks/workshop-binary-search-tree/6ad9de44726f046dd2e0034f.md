# --description--

如果 `key` 既不小于也不大于 `node.key`，你就找到了要删除的节点。如何删除它取决于它的子节点。

如果该节点没有左子节点，它的右子节点可以代替它的位置。这也涵盖了没有子节点的情况：在这种情况下，`node.right` 也是 `None`，所以该节点被替换为 `None`。

为你的第二个 `if` 语句添加一个 `else` 分支。在其中添加一个 `if` 语句，检查 `node.left` 是否为 `None`，并从中返回 `node.right`。
