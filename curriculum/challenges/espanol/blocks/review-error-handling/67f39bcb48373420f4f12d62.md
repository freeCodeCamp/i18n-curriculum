## Errores comunes en Python

- **`SyntaxError`**: El error que Python lanza cuando tu código no sigue sus reglas de sintaxis. Por ejemplo, el código `print("Hello there"` generará un error de sintaxis con el mensaje, `SyntaxError: '(' was never closed`, porque falta un paréntesis de cierre.
- **`NameError`**: Python lanza un `NameError` cuando intentas acceder a una variable o función que no has definido. Por ejemplo, si tienes la línea `print(username)` en tu código sin haber definido primero una variable `username`, obtendrás un error de nombre con el mensaje `NameError: name 'username' is not defined`.
- **`TypeError`**: Este es el error que Python lanza cuando una operación o función se aplica a un objeto de un tipo inapropiado. Por ejemplo, si intentas sumar una cadena a un número, obtendrás el error `TypeError: can only concatenate str (not "int") to str`.
- **`IndexError`**: Obtendrás un `IndexError` si accedes a un índice que no existe en una lista u otras secuencias como tuplas y cadenas. Por ejemplo, en una cadena `Hello world`, el índice del último carácter es `10`. Si accedes a un carácter así, `greet = "hello world"; print(greet[11])`, obtendrás un error con el mensaje `IndexError: string index out of range`.
- **`AttributeError`**: Python lanza este error cuando intentas usar un método o propiedad que no existe en un objeto de ese tipo. Por ejemplo, llamar a `.append()` en una cadena como `"hello".append("!")` generará un error con el mensaje `AttributeError: 'str' object has no attribute 'append'`.

## Buenas técnicas de depuración en Python

- **Usar la función `print`**: Insertar sentencias `print()` en varios puntos de tu código mientras depuras te ayuda a ver los valores de las variables y cómo fluye tu código.
- **Usar el depurador integrado de Python (`pdb`)**: Python proporciona el módulo `pdb` para depuración como parte de la biblioteca estándar. Llamar a `pdb.set_trace()` pausa la ejecución y abre un prompt interactivo. Puedes ingresar `help` para listar comandos, `whatis` para inspeccionar el tipo de una expresión, y `continue` (o sus alias `cont` y `c`) para reanudar la ejecución del programa.
- **Aprovechar las herramientas de depuración de IDEs**: Los entornos de desarrollo integrados (IDEs) y editores de código como PyCharm y VS Code ofrecen herramientas visuales para depurar. Por ejemplo, VS Code ofrece lo siguiente:
  - **Puntos de interrupción**: Haz clic en la canaleta del editor para colocar un punto de interrupción (representado por un punto rojo) donde la ejecución debe pausar.
  - **Inspección de variables y consola de depuración**: Pasa el cursor sobre variables o inspecciona el panel de Variables para ver valores actuales, y usa la consola de depuración para evaluar expresiones interactivamente.
  - **Controles de pasos**:
    - **Continuar (<kbd>F5</kbd>)**: Reanuda la ejecución hasta el siguiente punto de interrupción.
    - **Saltar sobre (<kbd>F10</kbd>)**: Ejecuta la línea actual y pasa a la siguiente sin entrar en llamadas a funciones.
    - **Entrar en (<kbd>F11</kbd>)**: Entra dentro de la función llamada para recorrer sus líneas.
    - **Salir de (<kbd>Shift</kbd> + <kbd>F11</kbd>)**: Termina la función actual y regresa a la que la llamó.

## Manejo de excepciones

- **`try...except`**: Se usa para ejecutar un bloque de código que podría lanzar una excepción. El bloque `try` es donde anticipas que podría ocurrir un error, mientras que el bloque `except` captura una excepción específica y se ejecuta si ese error ocurre. Aquí tienes un ejemplo:

  ```py
  try:
    print(22 / 0)
  except ZeroDivisionError:
    print('You can\'t divide by zero!')
    # You can't divide by zero!
  ```

  También puedes encadenar múltiples bloques `except` para manejar más tipos de excepciones:

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

  También puedes capturar varios tipos de excepciones en una sola cláusula `except` agrupándolas en una tupla:

  ```py
  try:
    number = int(input('Enter a number: '))
    result = 10 / number
  except (ValueError, ZeroDivisionError) as e:
    print(f'Error occurred: {e}')
  ```

- **`else` y `finally`**: Estos bloques extienden `try...except`. Si no ocurre ninguna excepción, se ejecuta el bloque `else`. El bloque `finally` siempre se ejecuta sin importar si hubo errores.

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **Objeto excepción**: Esto te permite acceder a la excepción misma para una mejor depuración e imprimir el mensaje de error directo. Para acceder al objeto excepción, debes usar la palabra clave `as`. Aquí tienes un ejemplo:

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **La sentencia `raise`**: Permite lanzar manualmente una excepción. Puedes usarla para lanzar una excepción cuando se cumple cierta condición:

  ```py
  def divide(a, b):
      if b == 0:
          raise ZeroDivisionError('You cannot divide by zero')
      return a / b
  ```

  Usar `raise` sin argumentos dentro de un bloque `except` vuelve a lanzar la excepción actual que se está manejando. Esto te permite registrar el error o hacer limpieza mientras sigues propagando la excepción en la pila de llamadas:

  ```py
  def process_data(data):
      try:
          result = int(data)
          return result * 2
      except ValueError:
          print('Logging: Invalid data received')
          raise
  ```

- **La sentencia `assert`**: La sentencia `assert` verifica suposiciones durante la depuración y lanza un `AssertionError` cuando la condición es falsa. Como Python elimina las afirmaciones cuando se ejecuta en modo optimizado (`-O`), no se deben usar para validaciones críticas de entrada que siempre deben ejecutarse. En su lugar, usa una condición explícita y `raise` para las comprobaciones necesarias.

## Señalización de excepciones

- **Excepciones personalizadas**: La sentencia `raise` también es útil cuando creas tus propias excepciones personalizadas subclasificando `Exception`. Esto te permite lanzar errores con lógica y mensajes específicos del dominio:

  ```py
  class InvalidCredentialsError(Exception):
      def __init__(self, message="Invalid username or password"):
          self.message = message
          super().__init__(self.message)

  def login(username, password):
      stored_username = "admin"
      stored_password = "password123"
      
      if username != stored_username or password != stored_password:
          raise InvalidCredentialsError()
      
      return f"Welcome, {username}!"
  ```

  Aquí tienes cómo usar la función `login` con la excepción `InvalidCredentialsError`:

  ```py
  # failed login attempt
  try:
      message = login("user", "wrongpassword")
  except InvalidCredentialsError as e:
      print(f"Login failed: {e}")
  else:
      print(message)

  # successful login attempt
  try:
      message = login("admin", "password123")
  except InvalidCredentialsError as e:
      # This block is not executed because the login was successful
      print(f"Login failed: {e}")
  else:
      # The else block runs if the 'try' block completes without an exception
      print(message)
  ```

- **Encadenamiento de excepciones**: La sentencia `raise` puede usarse con la palabra clave `from` para encadenar excepciones. Usar `from None` suprime el contexto original de la excepción en el traceback mostrado, mientras que `from e` registra explícitamente la excepción original como la causa:

  ```py
  def parse_config(filename):
      try:
          with open(filename, 'r') as file:
              data = file.read()
              return int(data)
      except FileNotFoundError:
          raise ValueError('Configuration file is missing') from None
      except ValueError as e:
          raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```
