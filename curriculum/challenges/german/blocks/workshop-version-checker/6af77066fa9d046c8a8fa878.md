# --description--

Wenn die installierte Version nicht die neueste ist, sollte Ihre Funktion angeben, welche Art von Update verfügbar ist. Wenn sich die Hauptnummern unterscheiden, handelt es sich um ein Major-Update. Das bedeutet, dass die neuere Version große Änderungen enthält, die mit der älteren Version möglicherweise nicht kompatibel sind.

Sie können auf die Hauptnummer einer Version mit dem Index `0` zugreifen. Fügen Sie eine `if`-Anweisung hinzu, die überprüft, ob die Hauptnummer von `installed` kleiner ist als die Hauptnummer von `latest`. Falls ja, erstellen Sie eine Variable namens `update_type` und weisen ihr den String `major update` zu.
