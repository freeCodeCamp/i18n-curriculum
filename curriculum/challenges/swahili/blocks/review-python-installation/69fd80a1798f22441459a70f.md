## Kufunga Python katika Mazingira Yako ya Ndani

- **Ufungaji**: Njia rahisi zaidi ya kufunga Python kwenye Windows na macOS ni kupakua kifungaji kutoka kwenye tovuti rasmi ya Python (`https://www.python.org/`). Kwenye Linux, usambazaji mkubwa kama Ubuntu, Debian, na Fedora tayari unajumuisha Python, hivyo angalia toleo lililowekwa kwanza na ufungue kifurushi maalum cha usambazaji ikiwa Python 3 haipo.
- **Kuweka kwenye macOS**: Pakua na fungua kifungaji cha `.pkg` na fuata maelekezo. Ukimaliza, bofya mara mbili faili ya `Install Certificates.command` na acha mchakato wa terminal ukamilike ili kumaliza usanidi.
- **Kuweka kwenye Windows**: Pakua na endesha Meneja wa Ufungaji wa Python `.msix`. Baadaye, amri za `python`, `py`, na `pymanager` zitapatikana, kuendesha `python` bila runtime iliyowekwa kutasakinisha moja moja kwa moja, na unaweza kukubali ombi la hiari la kuongeza saraka ya majina mbadala (kwa amri kama `python3.14.exe`) kwenye `PATH` yako.
- **Kuweka kwenye Linux**: Fungua terminal na endesha `python --version` au `python3 --version`. Ikiwa hakuna inayoonyesha toleo la Python 3, tafuta kifurushi cha ufungaji kwenye `https://www.python.org/` au tafuta mtandaoni njia inayopendekezwa ya kufunga Python kwa usambazaji wako.

## Kuhakiki Usakinishaji

- **Kukagua toleo**: Thibitisha ufungaji kwa kuendesha `python --version` au `python3 --version` kwenye terminal.
- **`python` dhidi ya `python3`**: Kwenye baadhi ya mifumo ya zamani ya macOS na Linux, `python` inaweza kumaanisha Python 2. Ikiwa `python --version` inaonyesha toleo la Python 2, tumia `python3` kwa msimbo wako kuanzia wakati huo. Python 2 imeisha muda wake na haipaswi kutumika kwa ukuzaji mpya.

## Terminal

- **Ufafanuzi**: Terminal ni kiolesura cha maandishi kinachokuwezesha kuingiliana na kompyuta yako kwa kuandika amri. Kila mfumo wa uendeshaji huja na programu ya terminal ya msingi. Kwenye macOS, unaweza kutumia programu ya Terminal. Kwenye Windows, unaweza kutumia Command Prompt au PowerShell. Kwenye Linux, kila mazingira ya desktop yana programu yake ya terminal ya msingi, kama GNOME Terminal au Konsole.

## Wahariri wa Msimbo na IDE

- **IDE**: IDE inasimama kwa Integrated Development Environment, na ina vipengele kama mhariri wa msimbo, zana za majaribio, terminal, na zaidi.
- **Wahariri maarufu wa msimbo na IDE kwa Python**: VS Code, PyCharm, na Spyder.

## Kuendesha Skripti za Python

- **Kuweka mhariri wako**: Fungua saraka ya mradi wako katika VS Code na tengeneza faili la `.py`. Sakinisha ugani wa Python wa Microsoft kutoka kwenye mtazamo wa Extensions au kwa kuendesha `code --install-extension ms-python.python` (kwenye macOS, amri ya `code` lazima iongezwe kwenye `PATH` yako kwanza). Ugani huu unaongeza msaada wa Python kwa mhariri lakini haufungi Python yenyewe.
- **Kuchagua tafsiri**: Endesha `Python: Select Interpreter` kutoka kwenye Command Palette kuonyesha mhariri tafsiri ya Python 3 uliyoiweka awali.
- **Kuendesha msimbo wako**: Bofya kitufe cha kuendesha (ikoni ya kucheza upande wa juu kulia wa VS Code) kuendesha faili ya sasa kwenye terminal. Pia unaweza kuendesha skripti moja kwa moja kutoka terminal. Kwa mfano, ikiwa saraka ya mradi wako ni `python-projects` na skripti yako ni `main.py`, fungua terminal katika saraka inayojumuisha `python-projects`, kisha ingia kwenye saraka ya mradi na uendeshe skripti:

```bash
cd python-projects
python main.py
```

Tumia `python3 main.py` badala yake ikiwa `python3` ndiyo amri inayoripoti toleo la Python 3 kwenye mfumo wako.

## Kutumia Python Interactive Shell

- **Kuanza shell**: Fungua terminal na endesha `python` au `python3` (tumia ile iliyoripoti toleo la Python 3). Onyo la `>>>` lina maana Python inasubiri amri. Jaribu kuchapisha `"Hello, world!"`:

```python
print("Hello, world!")
```

- **Mzunguko wa Soma, Tambua, Chapisha, Rudia (REPL)**: Tafsiri husoma ingizo lako, hutathmini, huchapisha matokeo, na hurudia kwenye onyo la `>>>` ili uandike amri nyingine.
- **Ingizo batili**: Kuingiza kitu kisicho halali kama Python, kama `something random`, husababisha ujumbe wa `SyntaxError: invalid syntax`, na shell hurudi kwenye onyo.
- **Kutoka shell**: Andika `exit()`, bonyeza <kbd>Ctrl</kbd> + <kbd>D</kbd> kwenye macOS au Linux, au bonyeza <kbd>Ctrl</kbd> + <kbd>Z</kbd> kisha <kbd>Enter</kbd> kwenye Windows.
- **Wakati wa kuitumia**: Shell ya mwingiliano ni bora kwa majaribio madogo na uchunguzi wa haraka. Kwa programu ndefu au kazi katika mafaili mengi, tumia mhariri wa msimbo au IDE.
