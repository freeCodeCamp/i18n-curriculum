# --description--

このラボでは、前回のワークショップで作成した`LinkedList`クラスを基に、連結リストのデータ構造に対する追加の操作を実装します。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

**ユーザーストーリー：**

1. あなたの`LinkedList`クラスには、要素を引数に取る`contains`メソッドが必要です。連結リストにその要素が存在する場合は`True`を返し、存在しない場合は`False`を返してください。
1. あなたの`LinkedList`クラスには、インデックスを引数に取る`get_at`メソッドが必要です。連結リストの指定されたインデックスの要素を返してください。インデックスが範囲外の場合は`None`を返してください。
1. あなたの`LinkedList`クラスには、インデックスと要素を引数に取る`insert_at`メソッドが必要です。連結リストの指定された位置に要素を挿入し、`length`属性を更新してください。リストの長さと等しいインデックスは有効で、末尾に要素を追加します。インデックスが範囲外の場合はリストを変更しないでください。
1. あなたの`LinkedList`クラスには、インデックスを引数に取る`remove_at`メソッドが必要です。連結リストの指定されたインデックスのノードを削除し、`length`属性を更新してください。インデックスが範囲外の場合はリストを変更しないでください。
1. あなたの`LinkedList`クラスには、`clear`メソッドが必要です。連結リストのすべての要素を削除し、`head`を`None`に、`length`を`0`にリセットしてください。

**注意:** 後のテストは前のメソッドに依存しています。例えば、`get_at`が正しく実装されていないと、`insert_at`や`remove_at`のテストがほぼ正しい場合でも失敗することがあります。

class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
