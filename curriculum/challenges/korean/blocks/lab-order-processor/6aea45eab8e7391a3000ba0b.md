# --description--

이 실습에서는 전자상거래 주문을 처리하고 그 과정에서 발생하는 오류를 다루게 됩니다.

**목표:** 아래 사용자 스토리를 충족하고 모든 테스트를 통과하여 실습을 완료하세요.

작업할 데이터는 시작 코드의 변수들과 같은 구조를 가지고 있습니다:

- **주문**은 다음을 포함하는 딕셔너리입니다:
  - `order_id`: 주문을 식별하는 정수입니다.
  - `products`: 각 항목이 `product_id`와 요청된 `quantity`를 포함하는 딕셔너리인 목록입니다.
  - `discount_code`: 문자열이거나, 주문에 할인 코드가 없으면 `None`입니다.
  - `status`: 주문 상태를 설명하는 문자열입니다.
- **주문 내역**은 주문들의 목록입니다.
- **재고(inventory)**는 키가 제품 ID이고 값이 `product` 이름, 재고 `quantity`, 단위당 `price`를 포함하는 사전입니다.
- **할인 코드**는 키가 코드이고 값이 할인율인 딕셔너리이며, 예를 들어 10% 할인은 `0.1`입니다.

**사용자 스토리:**

1. `find_order`라는 이름의 함수가 있어야 하며, 매개변수 두 개를 받는데 순서대로 주문 ID와 주문 내역입니다.
1. `find_order`는:
   - 주어진 주문 내역에서 `order_id`가 주어진 주문 ID와 같은 주문을 반환해야 합니다.
   - 주어진 주문 ID와 일치하는 주문이 없으면 `Order ID {order_id} not found in order history.` 메시지와 함께 `ValueError`를 발생시켜야 합니다.
1. `verify_availability`라는 이름의 함수가 있어야 하며, 매개변수 두 개를 받는데 순서대로 주문과 재고입니다.
1. `verify_availability`는:
   - 주문에 있는 상품이 주어진 재고에 없으면 `Product ID {product_id} is not in the inventory.` 메시지와 함께 `ValueError`를 발생시켜야 합니다.
   - 주문한 수량이 재고 수량보다 많으면 `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.` 메시지와 함께 `ValueError`를 발생시켜야 합니다.
   - 주문의 모든 상품이 요청한 수량만큼 재고에 있으면 오류를 발생시키지 않아야 합니다.
1. `get_discount_rate`라는 이름의 함수가 있어야 하며, 매개변수 두 개를 받는데 순서대로 주문과 할인 코드입니다.
1. `get_discount_rate`는:
   - 주문의 `discount_code`가 `None`이면 `0.0`을 반환해야 합니다.
   - 주문의 `discount_code`가 주어진 할인 코드에 없으면 `Invalid discount code: {discount_code}.` 메시지와 함께 `ValueError`를 발생시켜야 합니다.
   - 그렇지 않으면 주문의 `discount_code`에 해당하는 할인율을 반환해야 합니다.
1. `process_order`라는 이름의 함수가 있어야 하며, 매개변수 네 개를 받는데 순서대로 처리할 주문 ID, 주문 내역, 재고, 할인 코드입니다.
1. `process_order`는 `find_order`, `verify_availability`, `get_discount_rate`를 사용해 주문을 처리하고, 이들이 발생시키는 `ValueError`를 처리하여 `process_order` 호출 시 오류가 발생하지 않도록 해야 합니다.
1. 주어진 주문 내역에 주어진 주문 ID와 일치하는 주문이 없으면 `process_order`는:
   - `Error processing order {order_id}: {error message}`를 출력하는데, 여기서 `{error message}`는 `find_order`가 발생시킨 `ValueError` 메시지이며, 다른 출력은 하지 않아야 합니다.
   - 주어진 재고와 할인 코드는 변경하지 않아야 합니다.
1. 주문이 존재하지만 재고에 상품이 없거나 요청 수량이 부족하거나 할인 코드가 유효하지 않아 처리할 수 없으면 `process_order`는:
   - `Error processing order {order_id}: {error message}`를 출력하는데, 여기서 `{error message}`는 `verify_availability` 또는 `get_discount_rate`가 발생시킨 `ValueError` 메시지입니다.
   - 주문의 `status`를 `failed`로 설정해야 합니다.
   - 주어진 재고와 할인 코드는 변경하지 않아야 합니다.
   - `Order {order_id} processing completed. Current status: failed`를 출력해야 합니다.
1. 주문을 처리할 수 있으면 `process_order`는:
   - 할인 적용 후 총액을 소수점 둘째 자리까지 반올림하여 `Order {order_id} total: ${total}`을 출력해야 합니다.
   - 주문의 `status`를 `processed`로 설정해야 합니다.
   - 주문한 수량만큼 재고에서 차감해야 합니다.
   - 주문이 사용한 할인 코드를 할인 코드 목록에서 제거하여 각 코드를 한 번만 사용할 수 있게 해야 합니다.
   - `Order {order_id} processing completed. Current status: processed`를 출력해야 합니다.

**참고:** 테스트에 사용할 수 있는 재고, 주문 내역, 할인 코드가 제공되었습니다. 오류가 발생하는 경우를 포함해 함수를 호출해 보되, 테스트 실행 전에 해당 호출을 주석 처리하세요. 그렇지 않으면 테스트에 영향을 줄 수 있습니다.

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id, order_history, inventory, discount_codes):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
