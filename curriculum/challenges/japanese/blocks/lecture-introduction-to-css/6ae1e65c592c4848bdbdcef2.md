# --interactive--

`text-decoration` プロパティはテキストに装飾線を追加できます。

初期値は `none` で、ブラウザがリンクに自動で付ける下線をカスタマイズしたいときに、その下線を消すためによく使われます。

```css
a {
  text-decoration: none;
}
```

リンクに使われることが多いですが、`text-decoration` は他のテキストにも装飾を付けられます。

## `text-decoration` プロパティの他の値

`none` 以外の `text-decoration` プロパティの値は次の通りです：

- `underline`
- `overline`
- `line-through`

値の名前が示す通り、`underline` はテキストの下に線を引き、`overline` はテキストの上に線を引き、`line-through` はテキストの中央に線を引いて取り消し線のようにします。

## `text-decoration` プロパティにはもっとあります

`text-decoration` プロパティは実は省略形プロパティで、次のプロパティをまとめています：

- `text-decoration-line`: `none`、`underline`、`overline`、`line-through`
- `text-decoration-color`: 線の色。
- `text-decoration-style`: `solid`、`double`、`dotted`、`dashed`、または `wavy`。
- `text-decoration-thickness`: 線の太さ。

例えば、これで段落に赤い波線を追加します：

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

そしてこれで段落に緑の二重オーバーラインを追加します：

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

線の種類を組み合わせることもできます：

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
