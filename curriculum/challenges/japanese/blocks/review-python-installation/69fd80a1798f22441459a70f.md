## ローカル環境でのPython

- **インストール**: Windows、Mac、LinuxでPythonをインストールする最も良い方法は、公式Pythonウェブサイト（`https://www.python.org/`）からインストーラーをダウンロードすることです。
- **ターミナル**: コマンドを入力してコンピューターとやり取りできるテキストベースのインターフェースです。各OSにはデフォルトのターミナルアプリが付属しています。macOSではTerminalアプリを使えます。WindowsではCommand PromptやPowerShellを使えます。Linuxでは、GNOME TerminalやKonsoleなど、各デスクトップ環境にそれぞれのデフォルトターミナルアプリがあります。
- **IDE**: IDEは統合開発環境の略で、コードエディター、テストツール、ターミナルなどの機能を備えています。
- **Python向けの人気コードエディターとIDE**: VS Code、PyCharm、Spyder
- **ローカルでコードを実行する**: Pythonコードを実行するにはいくつかの方法があります。最初の方法は、VS Codeの右上にある再生ボタンのような実行ボタンをクリックすることです。これでターミナルが開き、Pythonスクリプトがそこで実行されます。

もう1つの方法はターミナルを開いて手動でプログラムを実行することです。例えば、`main.py`というプログラムを実行する例は以下の通りです。

```bash
python main.py
```

このコマンドは`main.py`が保存されているフォルダから実行する必要があります。例えば、`main.py`が`python-projects`というフォルダ内にある場合、まずターミナルで以下を使います。

```bash
cd python-projects
```

次に以下を実行します。

```bash
python main.py
```

## Pythonインタラクティブシェルの使い方

- **定義**: インタラクティブシェルは、コマンドを1つずつ入力して結果を確認できるプログラムです。ターミナルアプリを開き、`python` と入力して <kbd>Enter</kbd> を押してください。これでPythonのインタラクティブシェルが起動します。`>>>` の記号はPythonがコマンドの入力を待っていることを示します。ターミナルに `"Hello, world!"` を出力してみましょう:

```python
print("Hello, world!")
```

以下のようにテキストが表示されるはずです。

```md
>>> print("Hello, world!")
Hello, world!
```

テキストが表示された後、Pythonは以下に戻ります。

```md
>>>
```

これはさらにコマンドを入力できる状態です。

- **読み取り、評価、出力、ループサイクル（REPL）**: コマンドを入力すると、インタープリターが入力を読み取り、評価し、結果を出力し、再び`>>>`を表示してさらにコマンドを入力できるようにループします。
