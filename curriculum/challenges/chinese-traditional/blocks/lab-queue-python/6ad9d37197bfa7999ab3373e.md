# --description--

在這個實驗中，你將建置一個佇列類別。佇列遵循 FIFO（先進先出）原則：元素會被加入佇列的尾端，並從前端移除。

**目標：** 完成以下使用者故事並通過所有測試以完成實驗。

**使用者故事：**

1. 你應該定義一個名為 `Queue` 的類別。`Queue` 的新實體應該從空的狀態開始。

1. `Queue` 類別應該包含以下方法：

   - `enqueue`：接收一個元素並將它加入佇列的尾端。
   - `dequeue`：移除佇列前端的元素並傳回它。如果佇列為空，應傳回 `None`。
   - `front`：傳回佇列前端的元素但不移除它。如果佇列為空，應傳回 `None`。
   - `size`：傳回佇列中元素的數量。
   - `is_empty`：如果佇列沒有元素，傳回 `True`，否則傳回 `False`。

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
