# --description--

Agora, mostre também os timestamps na listagem de e-mails. Atualize o método `__str__` para adicionar ` | Time: ` seguido do timestamp, formatado como `'%Y-%m-%d %H:%M'`, após o assunto:

```md
[status] From: sender | Subject: subject | Time: time
```

Para manter a coluna `Time` alinhada, alinhe o assunto à esquerda em uma largura de `15`. Essa largura é apenas um mínimo, então um assunto mais longo ainda será exibido por completo e empurrará o `Time` para fora da linha. Corte o assunto para os seus primeiros `15` caracteres antes de formatar para evitar isso.

Por exemplo, um e-mail com um assunto curto e outro com um assunto longo seriam:

```md
[Unread] From: Alice      | Subject: Hello           | Time: 2025-01-15 09:30
[Unread] From: Alice      | Subject: Quarterly budge | Time: 2025-01-15 09:30
```

import datetime

class Email:
