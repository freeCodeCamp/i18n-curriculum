# --description--

Erstellen Sie nun eine Variable namens `extra_charges` und weisen Sie ihr den Wert `0` zu. Diese Variable stellt die zusätzlichen Gebühren dar, die für Kinokarten bei Abendvorstellungen angewendet werden.

Der Gleichheitsoperator (`==`) prüft, ob zwei Werte gleich sind, und ergibt `True` oder `False`. Er unterscheidet sich vom Zuweisungsoperator (`=`), der einen Wert in einer Variable speichert:

```py
color = 'red' # Assigns 'red' to color
print(color == 'red') # True
print(color == 'blue') # False
```
