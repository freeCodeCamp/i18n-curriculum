テーブルに行とデータセルを追加する正しい方法はどれですか？

#### --distractors--

```html
<table>
  <tr>
    <data>Davis</data>
    <data>Alex</data>
    <data>54</data>
  </tr>
</table>
```

---

```html
<table>
  <tr>
    <cell>Davis</cell>
    <cell>Alex</cell>
    <cell>54</cell>
  </tr>
</table>
```

---

```html
<table>
  <row>
    <td>Davis</td>
    <td>Alex</td>
    <td>54</td>
  </row>
</table>
```

#### --answer--

```html
<table>
  <tr>
    <td>Davis</td>
    <td>Alex</td>
    <td>54</td>
  </tr>
</table>
```

### --question--

#### --text--

`title`要素の役割は何ですか？

#### --distractors--

ユーザーがウェブページのソースコードを編集できるようにする要素。

---

ウェブページ内の要素のレイアウトと配置を定義する要素。

---

動画やマルチメディアコンテンツをHTMLドキュメントに直接埋め込むための要素。

#### --answer--

ドキュメントのタイトルを指定し、ブラウザのタブやウィンドウに表示されます。
