# --description--

Sie sollten auch den Fall behandeln, wenn der Benutzer keinen Anspruch auf einen Mitgliederrabatt hat.

Fügen Sie eine `else`-Klausel zu Ihrer `if`-Anweisung hinzu und geben Sie `User does not qualify for membership discount` im Körper von `else` aus.

Sie möchten auch den aktualisierten Wert von `discount` anzeigen. Da es sich um einen Geldbetrag handelt, sollte er mit zwei Dezimalstellen dargestellt werden.

Wie Sie in einer vorherigen Lektion gelernt haben, können Sie dies mit der Formatangabe `.2f` innerhalb eines f-Strings tun. Das funktioniert auch mit ganzen Zahlen, sodass ein Wert wie `3` als `3.00` angezeigt wird.

Verwenden Sie unterhalb der `if...else`-Anweisung einen f-String, um `Discount:` gefolgt von einem Leerzeichen und `discount` formatiert auf zwei Dezimalstellen auszugeben. Überprüfen Sie dann die Ausgabe im Terminal.
