# --description--

正则表达式可以包含由反斜线（`\`）后跟一个字符组成的特殊序列。这些序列有特殊含义。以下是一些最常见的：

- `\d` 匹配任何十进制数字，包括 `0` 到 `9`。

- `\w` 匹配任何单词字符：字母、数字和下划线（`_`）。

- `\s` 匹配任何空白字符，比如空格、标签（页）或换行符。

- `\D`、`\W` 和 `\S` 匹配它们小写版本的相反内容。例如，`\D` 匹配任何非数字字符。

不过有个问题。Python 字串也使用反斜线来写转义序列，比如 `\n`（换行）或 `\t`（标签（页））：

```python
print('Tab:\tdone') # Tab:    done
```

这意味着普通 Python 字串中的反斜线可能会在 `re` 模块看到它之前被 Python 解释。根据后面的字符，这可能会改变你的模式或让 Python 显示警告。

为避免这种情况，你可以使用未经处理的字串。通过在开头引号前添加字母 `r`（或 `R`）来创建未经处理的字串。未经处理的字串将反斜线视为字面字符，而不是转义序列：

```python
print(r'Tab:\tdone') # Tab:\tdone
```

因此，养成总是将正则表达式模式写成未经处理字串的好习惯：

```python
import re

room = 'Room 42B'
print(re.search(r'\d', room))
# <re.Match object; span=(5, 6), match='4'>
```

注意 `re.search` 返回它找到的第一个匹配项。这里，`\d` 匹配单个数字，所以匹配结果只有 `4`。如果想匹配多个数字，你可能需要使用量词。

量词指定前述的字符或序列可以重复多少次。`+` 量词匹配前述字符一次或多次。

所以，虽然 `\d` 匹配单个数字，`\d+` 匹配连续一个或多个数字：

```python
import re

room = 'Room 42B'
print(re.search(r'\d+', room))
# <re.Match object; span=(5, 7), match='42'>
```

以下是其他常见的量词：

- `*` 匹配前述字符零次或多次。

- `?` 匹配前述字符零次或一次，使其成为可选的。

- `{n}` 精确匹配前述字符 `n` 次。

- `{n,m}` 匹配前述字符至少 `n` 次，至多 `m` 次。

```python
import re

print(re.search(r'go*al', 'What a goooal!'))
# <re.Match object; span=(7, 13), match='goooal'>

print(re.search(r'colou?r', 'My favorite color is blue'))
# <re.Match object; span=(12, 17), match='color'>

print(re.search(r'\d{4}', 'Room 42, built in 1987'))
# <re.Match object; span=(18, 22), match='1987'>
```

你可以在同一个模式中组合字面字符、特殊序列和量词。例如，模式 `r'\d+ items'` 匹配一个或多个数字，后跟一个空格和单词 `items`。你还可以结合使用 `re.IGNORECASE` 标记，使字母可以是小写或大写：

```python
import re

cart = 'You have 3 ITEMS in your cart.'
print(re.search(r'\d+ items', cart, re.IGNORECASE))
# <re.Match object; span=(9, 16), match='3 ITEMS'>
```
