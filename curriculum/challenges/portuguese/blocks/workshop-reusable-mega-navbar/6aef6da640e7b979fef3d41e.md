# --description--

Para abrir e fechar o `sub-menu`, seu componente `Navbar` precisa lembrar se o `sub-menu` está aberto no momento. Dados que um componente lembra e que podem mudar com o tempo são chamados de estado. Sempre que o estado muda, o React re-renderiza o componente para que a página mostre o novo valor.

Você vai aprender muito mais sobre estado nas próximas lições. Por enquanto, só precisa saber que pode adicionar estado a um componente funcional com o hook `useState`. Hooks são funções especiais que permitem usar recursos do React nos seus componentes. Como o React está carregado com um elemento `script` nesta oficina, você pode acessar o hook como `React.useState`:

```jsx
const [count, setCount] = React.useState(0);
```

`React.useState` recebe o valor inicial do estado como argumento e retorna um array com dois itens, que são desestruturados aqui com desestruturação de array:

- `count` é a variável de estado, que guarda o valor atual.
- `setCount` é a função setter, que você chama para atualizar o estado.

Dentro do componente `Navbar`, use `React.useState` para criar uma variável de estado chamada `isOpen` e uma função setter chamada `setIsOpen`. Como o `sub-menu` deve começar fechado, dê a ele um valor inicial `false`.
