# --description--

Até agora, você usou `re.search` para buscar um padrão em qualquer lugar de uma string. O módulo `re` tem muitas outras funções que trabalham com padrões regex. Nesta lição, você vai aprender sobre algumas das mais úteis.

## A função `match`

A função `match` funciona como `search`, mas ela só busca o padrão no início da string. Ela retorna um objeto de correspondência se o começo da string corresponder ao padrão, e `None` caso contrário:

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

No segundo exemplo, a string contém dígitos, então `re.search` os encontraria. Mas a string não começa com dígitos, então `re.match` retorna `None`.

## A função `fullmatch`

O padrão `r'\d+:\d+'` corresponde a um ou mais dígitos, seguidos por dois pontos e um ou mais dígitos. Essa é a forma de um horário como `10:30`.

Imagine que você quer verificar se uma entrada do usuário é um horário, e nada mais. Se você usar `re.search`, vai encontrar um problema:

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

Isso retorna um objeto de correspondência, mesmo que `10:30pm` não siga o formato esperado. Isso acontece porque `re.search` busca o padrão em qualquer lugar da string e ignora quaisquer caracteres extras ao redor da correspondência. `re.match` teria o mesmo problema, porque `10:30pm` começa com um horário válido.

Quando você está validando dados, geralmente quer que a string inteira siga o padrão. Para isso, você pode usar a função `fullmatch`. Ela retorna um objeto de correspondência somente quando o padrão corresponde à string inteira, e `None` caso contrário:

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## A função `findall`

`search`, `match` e `fullmatch` retornam no máximo uma correspondência. Quando você quer todas as correspondências em uma string, pode usar a função `findall`. Ela retorna uma lista de strings com todas as correspondências que encontrar:

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

Se não houver correspondências, `findall` retorna uma lista vazia:

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## A função `sub`

A função `sub` substitui cada correspondência de um padrão por outra string. Ela recebe o padrão, a string de substituição e a string para buscar, e retorna uma nova string:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub` também tem dois parâmetros opcionais. O primeiro é `count`, que limita quantas correspondências serão substituídas:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

O segundo é `flags`. Como as outras funções, `sub` pode usar flags como `re.IGNORECASE`:

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

Sempre passe `count` e `flags` como argumentos nomeados. Se você passar `re.IGNORECASE` como quarto argumento posicional, o Python vai tratá-lo como o valor de `count` em vez disso.
