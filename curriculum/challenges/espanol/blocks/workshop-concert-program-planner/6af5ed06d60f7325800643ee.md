# --description--

Para agregar un elemento en una posición específica, puedes usar el método `insert()`. Este recibe el índice donde debe ir el nuevo elemento, seguido del elemento mismo. Los elementos desde ese índice en adelante se desplazan una posición a la derecha:

```py
fruits = ['apple', 'banana', 'cherry']
fruits.insert(1, 'blueberry')
print(fruits) # ['apple', 'blueberry', 'banana', 'cherry']
```

El director quiere que las dos danzas eslavas se toquen una tras otra. Usa `insert()` para agregar la cadena `Slavonic Dance No. 1` a `pieces`, justo antes de `Slavonic Dance No. 8`.
