# --description--

年齡至少為 `18` 歲但未滿 `21` 歲的使用者可以訂票，但僅限於 `show_time` 不是 `Evening` 的時段。

不等於運算子（`!=`）用來檢查兩個值是否不相等。當值不同時，它會評估為 `True`，當值相同時，評估為 `False`：

```py
day = 'Monday'
print(day != 'Sunday') # True
print(day != 'Monday') # False
```

當在同一個表達式中同時使用 `and` 和 `or` 時，`and` 的優先權高於 `or`。這表示用 `and` 連接的條件會先被群組起來，該群組的結果再與 `or` 條件結合：

```py
has_key = True
knows_code = False
is_daytime = False

print(has_key or knows_code and is_daytime) # True
```

在上述範例中，`knows_code and is_daytime` 會先被評估，結果是 `False`。整個表達式接著變成 `has_key or False`，結果是 `True`。

更新 `if age >= 21:` 行的條件。使用 `and` 運算子來建構一個表達式，檢查 `age` 是否大於或相等於 `18` 且 `show_time` 不等於 `Evening`。然後使用 `or` 運算子將該表達式與現有條件結合。不要創建新的變數。
