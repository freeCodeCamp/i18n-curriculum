# --description--

Sie haben gelernt, wie man Dictionaries erstellt und deren Werte zugreift und aktualisiert. Jetzt werden Sie Dictionary-Methoden verwenden, Dictionaries kopieren und untersuchen, wie Funktionen diese verändern können.

Jedes Beispiel für eine Dictionary-Methode unten beginnt mit diesem Dictionary:

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## Methoden von Dictionaries

Dictionaries haben auch hilfreiche Methoden, um häufige Operationen durchzuführen.

Die `.get()`-Methode ruft den Wert ab, der mit einem Schlüssel verknüpft ist. Sie ist ähnlich wie die Klammernotation, die Sie in der vorherigen Lektion gelernt haben, aber ihr Vorteil ist, dass Sie einen Standardwert festlegen können, sodass kein Fehler auftritt, wenn der Schlüssel nicht existiert:

```python
dictionary.get(key, default)
```

In diesem Beispiel, wenn der Schlüssel `toppings` nicht existiert, wird eine leere Liste zurückgegeben, die der Standardwert ist, den wir hier als zweiten Parameter übergeben. Wenn `toppings` jedoch existiert, wird dieser Wert zurückgegeben:

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

Die `.keys()`- und `.values()`-Methoden geben jeweils ein View-Objekt mit allen Schlüsseln und Werten im Dictionary zurück:

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

Ein View-Objekt ist einfach eine Möglichkeit, den Inhalt eines Dictionaries zu sehen, ohne eine separate Kopie der Daten zu erstellen.

Die `.items()`-Methode gibt ein View-Objekt mit allen Schlüssel-Wert-Paaren im Dictionary zurück, einschließlich der Schlüssel und Werte:

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

Die `.clear()`-Methode entfernt alle Schlüssel-Wert-Paare aus dem Dictionary:

```python
pizza.clear()
```

Die `.pop()`-Methode entfernt das Schlüssel-Wert-Paar mit dem Schlüssel, den Sie als erstes Argument angeben, und gibt dessen Wert zurück. Wenn der Schlüssel nicht existiert, wird der Standardwert zurückgegeben, den Sie als zweiten Parameter angeben. Wenn der Schlüssel nicht existiert und Sie keinen Standardwert angeben, wird ein `KeyError` ausgelöst:

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

In Python 3.7 und neueren Versionen entfernt die `.popitem()`-Methode das zuletzt eingefügte Element:

```python
pizza.popitem()
```

Die `.update()`-Methode aktualisiert die Schlüssel-Wert-Paare mit den Schlüssel-Wert-Paaren eines anderen Dictionaries. Wenn sie gemeinsame Schlüssel haben, werden deren Werte überschrieben.

In diesem Beispiel aktualisieren wir das `pizza`-Dictionary. Der Schlüssel `price` existiert in beiden, daher wird sein Wert durch `15` ersetzt.

Aber `total_time` ist neu, daher wird es als neues Schlüssel-Wert-Paar zum `pizza`-Dictionary hinzugefügt:

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

Dies ist das neue Dictionary mit dem aktualisierten `price` und dem neuen `total_time`. Beachten Sie, wie der Preis jetzt `15` ist und `total_time` ein neues Schlüssel-Wert-Paar ist:

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### Zuweisung und flache Kopien

Wie Sie bei Listen gelernt haben, erzeugt das Zuweisen eines Dictionaries an eine andere Variable einen Alias. Beide Namen verweisen auf dasselbe Objekt:

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

Um ein separates äußeres Dictionary zu erstellen, verwenden Sie die `.copy()`-Methode:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

Das Ersetzen eines Eintrags in `copied_settings` ersetzt nicht den entsprechenden Eintrag in `settings`. Allerdings erzeugt `.copy()` eine **flache Kopie**: Es wird ein neues äußeres Dictionary erstellt, dessen Schlüssel und Werte auf dieselben Objekte verweisen wie im ursprünglichen Dictionary. Verschachtelte veränderbare Objekte werden weiterhin geteilt:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

Die beiden Dictionaries sind unterschiedliche Objekte, aber ihre `languages`-Einträge verweisen auf dieselbe Liste. Das Anhängen an diese Liste ist durch beide Dictionaries sichtbar. Das Ersetzen von `copied_settings['languages']` durch eine neue Liste würde stattdessen nur diesen Eintrag in der Kopie ändern.

Sie können auch eine flache Kopie erstellen, indem Sie ein Dictionary an `dict()` übergeben:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

Wie `.copy()` erstellt `dict(settings)` ein neues äußeres Dictionary, aber die verschachtelte Liste wird weiterhin geteilt. Das Ersetzen eines Eintrags in einem der Dictionaries betrifft nur dieses Dictionary, während das Ändern der geteilten Liste durch beide sichtbar ist.

## Ein Dictionary über einen Funktionsparameter mutieren

Die gleichen Regeln zur Argumentübergabe, die Sie bei Listen gelernt haben, gelten auch für Dictionaries. Ein Parameter verweist zunächst auf das als Argument übergebene Objekt. Das Aktualisieren eines Eintrags über diesen Parameter mutiert das geteilte Dictionary:

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

Die Funktion gibt einen Status-String zurück, während sich `preferences` über die geteilte Referenz ändert. Einen Wert zurückzugeben und ein Objekt zu mutieren sind getrennte Effekte. Die Funktion muss das Dictionary nicht zurückgeben, damit die Änderungen außerhalb der Funktion sichtbar sind. Das Neu-Zuweisen des lokalen Parameters an ein anderes Dictionary würde das von `preferences` referenzierte Dictionary nicht ersetzen.

## Ein Dictionary als Standardargument verwenden

Erinnern Sie sich, dass eine Standardliste beim Definieren der Funktion erstellt und bei Aufrufen, die das Argument weglassen, wiederverwendet wird. Ein Standard-Dictionary verhält sich genauso:

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

Der zweite Aufruf verwendet das Dictionary wieder, das vom ersten Aufruf verändert wurde. Das bedeutet, dass sich Einstellungen über unabhängige Aufrufe hinweg ansammeln, obwohl jeder Aufruf seinen eigenen lokalen Parameternamen hat.

Wenn jeder Aufruf mit einem frischen Dictionary starten soll, verwenden Sie das `None`-Standardmuster:

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

Jeder Aufruf, der `settings` weglässt oder `None` übergibt, erstellt ein frisches Dictionary. Das Übergeben eines bestehenden Dictionaries erlaubt der Funktion weiterhin, dieses Objekt zu mutieren. Verwenden Sie hier `settings is None`: `if not settings` würde auch ein leeres Dictionary als Argument erkennen und es durch ein neues lokales Dictionary ersetzen.
