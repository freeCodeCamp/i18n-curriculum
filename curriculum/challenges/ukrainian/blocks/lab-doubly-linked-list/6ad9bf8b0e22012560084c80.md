# --description--

У цій лабораторній роботі ви побудуєте двонаправлений зв’язаний список, де кожен вузол зберігає референс як на наступний, так і на попередній вузол у списку.

**Мета:** Виконайте наведені нижче історії користувача та пройдіть усі тести, щоб завершити лабораторну роботу.

**Історія користувача:**

1. У вас має бути клас з назвою `DoublyLinkedList`.
1. `DoublyLinkedList` має містити вкладений клас з назвою `Node`, чий метод `__init__` повинен:
   - приймати параметр `element` та необов’язковий параметр `previous`, який за замовчуванням дорівнює `None`.
   - встановлювати атрибут `element` у значення параметра `element`.
   - встановлювати атрибут `previous` у значення параметра `previous`.
   - встановлювати атрибут `next` у `None`.
1. Метод `__init__` класу `DoublyLinkedList` має встановлювати атрибут `length` у `0`, а атрибути `head` і `tail` — у `None`.
1. `DoublyLinkedList` має містити метод `is_empty`, який повертає `True`, якщо у списку немає вузлів, і `False` в іншому випадку.
1. `DoublyLinkedList` має містити метод `add`, який приймає `element` і:
   - створює новий `Node`, що містить цей `element`, і додає його в кінець списку;
   - встановлює атрибут `previous` нового вузла у вузол, який був хвостом до додавання, або у `None`, якщо список був порожній;
   - оновлює `head` (якщо список був порожній), `tail` і `length` списку;
   - не проходить циклом по списку для пошуку його кінця.
1. `DoublyLinkedList` має містити метод `remove`, який приймає `element` і:
   - видаляє кожен вузол, чий `element` дорівнює заданому `element`;
   - підтримує коректно зв’язані референси `next` і `previous` для решти вузлів;
   - оновлює `head`, `tail` і `length` списку за потреби;
   - залишає список без змін, якщо жоден вузол не підходить або якщо список порожній.
1. `DoublyLinkedList` має містити метод `reverse`, який змінює порядок вузлів на місці.
1. `DoublyLinkedList` має містити метод `to_list`, який повертає список елементів зв’язаного списку від `head` до `tail`.

class DoublyLinkedList:
    class Node:
        def __init__(self, element, previous=None):
            self.element = element
            self.previous = previous
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None
        self.tail = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element, self.tail)
        if self.is_empty():
            self.head = node
        else:
            self.tail.next = node
        self.tail = node
        self.length += 1

    def remove(self, element):
        current_node = self.head
        while current_node is not None:
            next_node = current_node.next
            if current_node.element == element:
                if current_node.previous is not None:
                    current_node.previous.next = current_node.next
                else:
                    self.head = current_node.next
                if current_node.next is not None:
                    current_node.next.previous = current_node.previous
                else:
                    self.tail = current_node.previous
                self.length -= 1
            current_node = next_node

    def reverse(self):
        current_node = self.head
        while current_node is not None:
            current_node.previous, current_node.next = current_node.next, current_node.previous
            current_node = current_node.previous
        self.head, self.tail = self.tail, self.head

    def to_list(self):
        elements = []
        current_node = self.head
        while current_node is not None:
            elements.append(current_node.element)
            current_node = current_node.next
        return elements
