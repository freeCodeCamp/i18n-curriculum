# --description--

在 Python 中，變數是指向物件的名稱。身分運算子用來檢查兩個運算元是否指向同一個物件。`is` 運算子如果是，則傳回 `True`，否則傳回 `False`。`is not` 運算子則傳回相反的結果。

身分與相等性不同：`==` 和 `!=` 比較值，而 `is` 和 `is not` 比較物件身分。比較數字或字串值時，請使用等號運算子。

`None` 代表沒有值。它是 `NoneType` 型別中唯一的值。

你可以用身分運算子檢查的三個物件是 `None`、`True` 和 `False`。它們都是單例，代表每個物件只有一個實例。

## 檢查 `None`

你可以用 `is None` 來檢查值是否缺失，或用 `is not None` 來檢查值是否存在：

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None` 是假值，但它不是與 `False` 相同的物件。舉例來說，回應可能是 `True` 表示是，`False` 表示否，或 `None` 表示尚未回答：

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

改用 `if not response` 會將 `False` 和 `None` 一視同仁。身分檢查能區分否定回答和缺失回答。

## 檢查 `True` 和 `False`

你也可以用身分來特別檢查布林物件：

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

這些檢查會判斷 `response` 是否正好是 `True`、`False`，或是非 `None` 的其他物件。它們不只是測試真假性。

對於一般布林旗標，使用直接的真假測試，例如 `if is_ready` 或 `if not is_ready`。當你特別需要區分布林物件與其他可能值（例如回應也可能是 `None`）時，才使用 `is True` 或 `is False`。
