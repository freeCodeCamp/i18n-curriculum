# --description--

为了使页面样式在移动端看起来与在桌面或笔记本电脑上相似，你需要添加一个带有特殊 `content` 属性的 `meta` 元素。

viewport `meta` 元素向浏览器提供如何控制页面在不同设备上维度和缩放的指令，特别是在移动电话和平板电脑上。下面是一个示例：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

`width=device-width` 部分告诉浏览器将页面宽度设置为与设备屏幕宽度匹配。`initial-scale=1.0` 设置页面首次装载时的初始缩放级别。值为 `1.0` 表示页面以 `100%` 缩放显示，没有缩放。

如果没有这个元素，移动浏览器通常会以桌面屏幕宽度渲染页面，然后再缩小，这可能导致文本非常小且难以阅读。

# --hints--

你应该有两个 `meta` 元素。

```js
assert.lengthOf(document.querySelectorAll('meta'), 2);
```

你的 `meta` 元素应该有一个 `name` 属性，其值为 `viewport`。

```js
assert.exists(document.querySelector('meta[name="viewport"]'));
```

你的 `meta` 元素应该有一个 `content` 属性，其值为 `width=device-width, initial-scale=1.0`。

```js
assert.equal(document.querySelector('meta[name="viewport"]')?.getAttribute('content'), 'width=device-width, initial-scale=1.0');
```
