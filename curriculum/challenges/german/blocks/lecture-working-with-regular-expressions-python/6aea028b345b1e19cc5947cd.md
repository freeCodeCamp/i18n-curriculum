# --description--

Ein regulärer Ausdruck, oder Regex, ist ein Muster, das verwendet wird, um eine Folge von Zeichen in einem Text zu finden.

Sie haben bereits den Operator `in` verwendet, um zu prüfen, ob ein String eine genaue Teilfolge enthält. Es gibt jedoch Fälle, in denen Sie den genauen Text, den Sie suchen, nicht kennen, sondern nur seine Form. Zum Beispiel möchten Sie vielleicht überprüfen, ob ein String mit einigen Buchstaben beginnt, gefolgt von einigen Ziffern, oder ob ein Benutzername nur aus erlaubten Zeichen besteht.

Reguläre Ausdrücke ermöglichen es Ihnen, solche Muster zu beschreiben und zu prüfen, ob ein String ihnen entspricht. Sie werden häufig verwendet, um Eingaben zu validieren, Texte zu durchsuchen und Informationen aus Strings zu extrahieren.

Um in Python reguläre Ausdrücke zu verwenden, müssen Sie das `re`-Modul importieren, das Teil der Standardbibliothek ist:

```python
import re
```

Das einfachste Regex-Muster ist ein wörtliches Muster: eine Folge von Zeichen, die genau so erscheinen müssen, wie sie geschrieben sind. Zum Beispiel entspricht das Muster `'cat'` den Buchstaben `c`, `a` und `t` nacheinander.

Um nach einem Muster in einem String zu suchen, können Sie die `search`-Funktion aus dem `re`-Modul verwenden. Sie nimmt das Muster als erstes Argument und den zu durchsuchenden String als zweites Argument:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

Wenn `re.search` das Muster irgendwo im String findet, gibt es ein Match-Objekt zurück. Das ausgegebene Match-Objekt sagt Ihnen zwei Dinge:

- `match='cat'` ist der Text, der dem Muster entspricht.

- `span=(4, 7)` ist die Position des Treffers im String. Der Treffer beginnt bei Index `4` und endet direkt vor Index `7`.

Diese Informationen können Sie auch mit den Methoden `group` und `span` des Match-Objekts abrufen:

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

Wenn das Muster nicht gefunden wird, gibt `re.search` `None` zurück:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

Standardmäßig ist die Regex-Suche case-sensitiv. Das bedeutet, dass das Muster `'Cat'` nicht mit dem Text `cat` übereinstimmt:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

Um zu ändern, wie ein Muster abgeglichen wird, können Sie ein Flag als drittes Argument an `re.search` übergeben. Das Flag `re.IGNORECASE` macht die Suche case-insensitiv, sodass Groß- und Kleinbuchstaben als gleich behandelt werden:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
