# --description--

<dfn>カラーモデル</dfn>は色を表すためのシステムです。主なカラーモデルは2つあり、電子機器で使われる<dfn>加法</dfn>のRGBモデルと、印刷で使われる<dfn>減法</dfn>のCMYK（シアン、マゼンタ、イエロー、ブラック）モデルです。

このプロジェクトではRGBモデルを使います。RGBは光の三原色である赤、緑、青を表します。この3色がさまざまな濃淡で組み合わさり、多彩な色を作り出します。RGBでは色は黒から始まり、赤、緑、青の異なるレベルが加わることで変化します。

これを確認する方法の一つがCSSの`rgb`関数で、RGBカラーモデルを使って色を定義できます。

クラス`container`を対象にした新しいCSSルールを作成し、`background-color`を`rgb(0, 0, 0)`の黒に設定してください。
