# --description--

- التكرار هو مفهوم برمجي يسمح لك باستدعاء دالة بشكل متكرر حتى تصل إلى حالة أساسية.

إليك مثالًا على دالة مسكنة تحسب المضروب لعدد ما:

```py
def find_factorial(n):
    if n == 0:
        return 1
    return n * find_factorial(n - 1)
```

في المثال أعلاه، تُستدعى الدالة `find_factorial` بشكل متكرر حتى تصل قيمة `n` إلى `0`. عندما تكون `n` تساوي `0`، تُحقق الحالة الأساسية وتُرجع الدالة القيمة `1`. ثم تُرجع الدالة حاصل ضرب `n` في نتيجة الاستدعاء التكراري لـ `find_factorial(n - 1)`.

- يسمح التكرار بالتعامل مع شيء ذو عمق غير معروف، مثل القواميس والقوائم المسكنة بعمق، أو شجرة الملفات.
- تُستخدم مكدس الاستدعاءات لتتبع استدعاءات الدالة في دالة تكرارية. في كل مرة تُستدعى فيها دالة، تُضاف إلى مكدس الاستدعاءات. عند الوصول إلى الحالة الأساسية، تُزال استدعاءات الدالة من المكدس.
- يجب تعريف الحالة الأساسية بعناية. وإلا، قد تستمر الدالة في استدعاء نفسها حتى يرفع Python خطأ `RecursionError`.
- التكرار مفيد لحل المشكلات الرياضية مثل المضروب وFibonacci، وتصفح الأشجار والرسوم البيانية، وتوليد التباديل والتوافيق.
