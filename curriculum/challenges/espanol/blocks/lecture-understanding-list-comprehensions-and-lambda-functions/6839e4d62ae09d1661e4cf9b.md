# --description--

Durante las últimas lecciones, te has estado familiarizando con el trabajo con bucles como este:

```py
even_numbers = []

for num in range(21):
    if num % 2 == 0:
        even_numbers.append(num)

print(even_numbers)
```

Este ejemplo crea una nueva lista vacía llamada `even_numbers` y recorre una secuencia de números entre `0` y `20`. Dentro del ciclo, hay una condición que verifica si el número actual tiene un residuo de `0` al dividirse por `2`. Esto se usa para determinar si el número es par. Si la condición es `True`, entonces el `num` actual se agrega al final de la lista `even_numbers`. Finalmente, imprimimos la lista `even_numbers` en la consola.

## ¿Qué es la comprensión de listas?

Aunque este código funciona, hay una forma más concisa de escribirlo usando comprensión de listas. La comprensión de listas te permite crear una nueva lista en una sola línea escribiendo un ciclo directamente dentro de corchetes. Esto hace que el código sea más corto y a menudo más fácil de leer.

La sintaxis básica de una comprensión de listas se ve así:

```py
[expression for item in iterable]
```

Para cada elemento en el iterable, se evalúa la expresión antes de `for` y el resultado se agrega a la nueva lista. Aquí tienes un ejemplo que crea una lista con cada número de `0` a `4` multiplicado por `2`:

```py
doubled = [num * 2 for num in range(5)]
print(doubled) # [0, 2, 4, 6, 8]
```

## Filtrar con un `if` al final

Opcionalmente, puedes agregar una condición `if` al final de una comprensión de listas. Solo los elementos para los cuales la condición es verdadera se agregan a la nueva lista, mientras que los otros se omiten.

Aquí está el ejemplo de números pares de antes, refactorizado usando comprensión de listas:

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

En este ejemplo refactorizado, la lista `even_numbers` se crea usando una sola línea de código. La comprensión de listas recorre los números desde `0` hasta `20` e incluye solo aquellos que son divisibles por `2`. Este enfoque es más compacto y elimina la necesidad de un ciclo y un bloque condicional separados.

## Crear listas internas separadas

Antes aprendiste que `[[]] * 3` repite referencias a una sola lista interna. Una comprensión puede crear una lista interna separada en cada iteración:

```py
rows = [[] for _ in range(3)]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

La expresión `[]` se evalúa en cada iteración, por lo que cada posición se refiere a una lista diferente. La variable del ciclo no se usa en la expresión; el rango solo controla cuántas listas se crean.

Cuando no se necesita una variable de ciclo, los desarrolladores de Python la nombran convencionalmente `_` para indicar que su valor se ignora intencionalmente. `_` sigue siendo un nombre de variable común.

## Uso de expresiones condicionales en comprensiones de listas

Hasta ahora has usado `if` y `else` para escribir sentencias condicionales. Python también tiene una expresión condicional, que se escribe en una sola línea y produce un valor. Aquí está su sintaxis:

```py
value_if_true if condition else value_if_false
```

Si la condición es verdadera, toda la expresión evalúa al valor antes de `if`. De lo contrario, evalúa al valor después de `else`. Aquí tienes un ejemplo:

```py
num = 7
label = 'Even' if num % 2 == 0 else 'Odd'
print(label) # Odd
```

Como `7` no es divisible de manera uniforme por `2`, la condición es `False` y se asigna `'Odd'` a `label`.

Puedes usar una expresión condicional como la expresión antes de `for` en una comprensión de listas. En ese caso, elige un valor para cada elemento del iterable, por lo que la nueva lista tiene el mismo número de elementos que la original. Esto es diferente de un `if` al final, que puede excluir elementos de la nueva lista.

Veamos un ejemplo:

```py
numbers = [1, 2, 3, 4, 5]
result = [(num, 'Even') if num % 2 == 0 else (num, 'Odd') for num in numbers]
print(result)
```

En este ejemplo, tenemos una lista de números y queremos crear una nueva lista de tuplas que indiquen cuáles números son pares o impares. En la primera parte de la comprensión de listas, usamos una expresión condicional `if`/`else` para verificar si el número es divisible por `2`. Si es así, el resultado es una tupla con ese número seguida de la palabra `Even`. De lo contrario, el resultado es una tupla con el número seguida de la palabra `Odd`.

Aquí está cómo se ve el resultado impreso en la consola:

```py
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

## Filtrar listas con `filter()`

Otra forma de crear una lista a partir de un iterable existente es la función `filter()`. Aquí tienes un ejemplo de cómo crear una nueva lista con solo palabras de más de cuatro caracteres:

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

La función `filter()` se usa para seleccionar elementos de un iterable que cumplen una condición específica. La función `filter()` acepta una función y un iterable como argumentos. En este ejemplo, pasamos una función `is_long_word` a la función `filter()` para verificar si el número de caracteres en la palabra actual es mayor que `4`. `is_long_word` se escribe sin paréntesis porque estás pasando la función en sí, no llamándola. La función `filter()` llama a `is_long_word` en cada palabra por ti. Al igual que `zip()`, la función `filter()` devuelve un iterador, que solo da las palabras que cumplen la condición. La función `list()` recoge esas palabras en una nueva lista, que se asigna a la variable `long_words`.

## Transformar listas con `map()`

Además de la función `filter()`, hay algunas funciones más que son útiles cuando trabajas con listas. Otra función que debes conocer es la función `map()`, que toma un iterable y aplica una función a cada uno de sus elementos. Aquí tienes un ejemplo de cómo usar la función `map()` para convertir una lista de temperaturas de Celsius a Fahrenheit:

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

Al igual que la función `filter()`, `map()` acepta una función y un iterable como argumentos. La función `to_fahrenheit` toma una temperatura y la convierte de Celsius a Fahrenheit. De nuevo, `to_fahrenheit` se pasa sin paréntesis, y `map()` la llama en cada temperatura de la lista `celsius`. La función `map()` también devuelve un iterador, esta vez de los valores convertidos, por lo que se usa `list()` nuevamente para recogerlos en una lista.

## Sumar valores con `sum()`

La última función que veremos es la función `sum()`. Esta función se usa para obtener la suma de un iterable como una lista o una tupla. Aquí tienes un ejemplo de cómo usar la función `sum()`:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

También puede pasar un argumento opcional `start` que establece el valor inicial para la suma. Aquí hay un ejemplo actualizado usando el argumento `start` como un argumento posicional:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

También puede optar por usar el argumento `start` como un argumento de palabra clave en lugar de esto:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

Ambas versiones producirán el mismo resultado, pero el argumento de palabra clave es un poco más explícito.

La comprensión de listas, así como otras funciones como `map()`, `filter()` y `sum()`, pueden parecer un poco confusas al principio. Pero con suficiente práctica y tiempo, comenzarás a sentirte más cómodo usándolas en tus programas de Python.
