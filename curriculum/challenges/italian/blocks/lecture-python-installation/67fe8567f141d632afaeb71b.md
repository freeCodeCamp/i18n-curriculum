# --description--

## Perché installare Python localmente?

Per tutti i workshop e i laboratori, userai l'editor Python di freeCodeCamp. Ma è importante imparare a configurare Python sulla tua macchina locale.

## Scaricare Python

Il modo più semplice per installare Python su Windows e Mac è scaricare il programma di installazione dal sito ufficiale di Python. Più avanti in questa lezione vedremo anche come eseguire Python su Linux.

Vai su `https://www.python.org/` e passa con il mouse su "Downloads". Apparirà una finestra modale che mostra la versione attuale di Python per il tuo sistema operativo (OS).

## Installare Python su macOS

Vediamo prima come installare Python su un computer con macOS:

- Clicca sul pulsante che mostra la versione corrente di Python (dal precedente modale) e inizierai automaticamente a scaricare un file di installazione `.pkg`.
- Una volta terminato il download del programma di installazione `.pkg`, aprilo e clicca su "Continua" nella finestra che si apre.
- Continua a cliccare il pulsante "Continua" fino ad arrivare alla sezione "Tipo di installazione". Qui, clicca sul pulsante "Installa".
- Inserisci la tua password se necessario, quindi avvia l'installazione.
- Quando l'installazione del pacchetto termina, dovresti vedere un messaggio che conferma che Python è stato installato con successo.
- Apri la nuova cartella Python nella tua directory Applicazioni.
- Fai doppio clic sul file `Install Certificates.command` e lascia che il processo nel terminale si completi.
- Verifica che nel terminale compaiano i messaggi `Successfully installed certifi` e `update complete`.
- Chiudi la finestra del terminale e clicca su "Chiudi" nella finestra dell'installatore. La configurazione è ora completa!

## Verificare l'installazione

Puoi verificare l'installazione aprendo il terminale ed eseguendo `python --version` o `python3 --version`.

Puoi anche aprire l'interprete Python eseguendo `python` o `python3` nel terminale. Un interprete Python è un programma che legge il codice Python, lo traduce in istruzioni che il computer capisce ed esegue quelle istruzioni.

## Cos'è un terminale?

Un <dfn>terminal</dfn> è un'interfaccia testuale che ti permette di interagire con il computer digitando comandi. Ogni sistema operativo ha un'app terminale predefinita. Su macOS puoi usare l'app Terminal. Su Windows puoi usare Prompt dei comandi o PowerShell. Su Linux ogni ambiente desktop ha la sua app terminale predefinita, come GNOME Terminal o Konsole.

## Usare `python` vs. `python3`

Nota che, su alcuni sistemi macOS e Linux più vecchi, `python` può essere riservato a Python 2, mentre `python3` è specifico per Python 3. Se esegui `python --version` e vedi una versione di Python 2 come `Python 2.7.18`, allora è possibile che il tuo OS dipenda da qualche software scritto nella versione più vecchia di Python. In questo caso, dovresti usare `python3` per eseguire il tuo codice Python d'ora in poi. Python 2 è a fine ciclo di vita e non dovrebbe essere usato per nessun nuovo sviluppo.

## Installare Python su Windows

Per installare Python su Windows, segui questi passaggi:

- Vai su `https://www.python.org/` e passa il mouse su "Downloads". Dovresti vedere un modale che dice "Download per Windows" e un pulsante di download con la versione corrente di Python.
- Clicca sul numero della versione e inizierai automaticamente a scaricare il Python Install Manager (pacchetto `.msix`).
- Una volta terminato il download del Python Install Manager, fai doppio clic su di esso e seleziona "Installa".
- Dopo l'installazione, i comandi `python`, `py` e `pymanager` dovrebbero essere disponibili. Se non è installato alcun runtime Python, eseguire `python` ne installerà uno automaticamente.
- Quando installi un runtime per la prima volta, potresti ricevere una richiesta opzionale di aggiungere una directory al tuo `PATH` per alias aggiuntivi, come `python3.14.exe`. Accetta questa richiesta opzionale se vuoi usare quegli alias.


Puoi verificare l'installazione aprendo una shell a riga di comando come PowerShell ed eseguendo `python --version`. Puoi anche aprire l'interprete Python eseguendo `python`.

## Installare Python su Linux

Per Python su Linux, la maggior parte delle distribuzioni principali come Ubuntu, Debian e Fedora include Python.

Apri semplicemente un terminale ed esegui `python --version` o `python3 --version`.

Se nessuno dei due comandi mostra una versione di Python 3, puoi cercare un pacchetto di installazione per la tua distribuzione Linux su `https://www.python.org` oppure cercare online il modo consigliato per installare Python per la tua distro.
