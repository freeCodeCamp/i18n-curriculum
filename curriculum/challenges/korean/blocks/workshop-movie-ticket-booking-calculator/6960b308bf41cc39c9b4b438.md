# --description--

`or` 연산자는 두 조건 중 적어도 하나가 참인지 확인할 때 사용합니다. `if` 문에서 비교와 함께 사용하는 방법은 다음과 같습니다:

```py
day = 'Sunday'
is_raining = False

if day == 'Sunday' or is_raining:
    print('Stay at home')
```

위 예제에서는 첫 번째 조건이 참이기 때문에 `is_raining`이 `False`임에도 불구하고 `Stay at home`이 출력됩니다.

주말에도 추가 요금이 적용되어야 합니다. `if show_time == 'Evening':` 줄의 조건을 `or` 연산자를 사용해 기존 조건과 `is_weekend`가 참인지 확인하는 두 번째 조건을 결합하도록 업데이트하세요.
