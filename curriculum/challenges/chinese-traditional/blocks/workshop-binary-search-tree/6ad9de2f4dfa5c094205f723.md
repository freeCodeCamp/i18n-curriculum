# --description--

每個節點最多可以有兩個子節點。

在 `__init__` 方法中，創建一個 `left` 屬性和一個 `right` 屬性，並將兩者都設為 `None`，以表述新節點一開始沒有子節點。

沒有子節點的節點稱為葉節點。

# --hints--

你應該在 `__init__` 方法中將 `self.left` 設為 `None`。

```js
({
  test: () =>
    runPython(`
    assert TreeNode(5).left is None
  `)
})
```

你應該在 `__init__` 方法中將 `self.right` 設為 `None`。

```js
({
  test: () =>
    runPython(`
    assert TreeNode(5).right is None
  `)
})
```
