# --description--

最後に、`append` の呼び出しの下で、`node.right` と `result` を使って `self._inorder_traversal` を呼び出し、右のサブツリーを訪問してください。

二分探索木では、ノードの左のサブツリーの値はノードの値より小さく、右のサブツリーの値はより大きいです。したがって、左のサブツリー、次にノード、最後に右のサブツリーを訪問することで、キーを小さい順から大きい順に集めることができます。

class BinarySearchTree:
    def __init__(self):
        self.root = None

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node

    def insert(self, key):
        self.root = self._insert(self.root, key)

    def _inorder_traversal(self, node, result):
        if node:
            self._inorder_traversal(node.left, result)
