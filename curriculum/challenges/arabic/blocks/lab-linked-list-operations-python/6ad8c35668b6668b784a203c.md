# --description--

في هذه الورشة، ستنفذ عمليات إضافية على هيكل البيانات قائمة مرتبطة، بناءً على صنف `LinkedList` الذي أنشأته في ورشة العمل السابقة.

**الهدف:** إكمال قصص المستخدم أدناه واجتياز جميع الاختبارات لإتمام المختبر.

**قصص المستخدم:**

1. يجب أن يحتوي صنف `LinkedList` على طريقة `contains` تأخذ عنصرًا كمعلمتها. يجب أن تُرجع `True` إذا كان العنصر موجودًا في القائمة المرتبطة، و`False` خلاف ذلك.
1. يجب أن يحتوي صنف `LinkedList` على طريقة `get_at` تأخذ فهرسًا كمعلمتها. يجب أن تُرجع العنصر عند الفهرس المعطى في القائمة المرتبطة. إذا كان الفهرس خارج النطاق، يجب أن تُرجع `None`.
1. يجب أن يحتوي صنف `LinkedList` على طريقة `insert_at` تأخذ فهرسًا وعنصرًا كمعلمتين. يجب أن تُدرج العنصر في الموضع المعطى في القائمة المرتبطة وتُحدث خاصية `length`. الفهرس الذي يساوي طول القائمة صالح ويجب أن يضيف العنصر في النهاية. إذا كان الفهرس خارج النطاق، لا يجب تعديل القائمة.
1. يجب أن يحتوي صنف `LinkedList` على طريقة `remove_at` تأخذ فهرسًا كمعلمتها. يجب أن تزيل العقدة عند الفهرس المعطى في القائمة المرتبطة وتُحدث خاصية `length`. إذا كان الفهرس خارج النطاق، لا يجب تعديل القائمة.
1. يجب أن يحتوي صنف `LinkedList` على طريقة `clear` تزيل كل العناصر من القائمة المرتبطة، مع إعادة تعيينها إلى حالة فارغة بحيث تكون `head` مساوية لـ `None` و`length` مساوية لـ `0`.

**ملاحظة:** تعتمد بعض الاختبارات اللاحقة على الطرق السابقة. على سبيل المثال، إذا لم تُنفذ طريقة `get_at` بشكل صحيح، قد تفشل اختبارات الطرق مثل `insert_at` و`remove_at` حتى لو كانت تلك الطرق قريبة من الصحة.

class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
