## Nini Programu ya Kielekezi ya Vitu?

- **Programu inayotumia darasa la vitu**: Mtindo wa programu ambapo wasanidi programu hutendea kila kitu katika msimbo wao kama kitu halisi cha dunia. Inajulikana sana kama OOP. Kanuni kuu nne zinazokusaidia kupanga na kusimamia msimbo kwa ufanisi ni **ufungaji**, **urithi**, **polimofizimu**, na **ufupishaji**.
- **Darasa la vitu**: Rasimu ya kuunda vitu. Kila kitu kinachoundwa kutoka kwa darasa lina sifa za kipengele zinazobainisha data na njia zinazobainisha tabia za kitu hicho.

## Nini Ufungaji (Encapsulation)?

- **Ufungaji**: Kuunganisha sifa na njia za kitu katika kitengo kimoja. Hukuruhusu kuficha hali ya ndani ya kitu nyuma ya seti rahisi ya njia na sifa za umma zinazofanya kazi kama milango. Nyuma ya milango hiyo kuna sifa na njia za faragha zinazodhibiti jinsi data inavyobadilika na nani anaweza kuiona.
- **Mfano wa ufungaji**: Ikiwa unataka kufuatilia salio la pochi, utaruhusu kuweka na kutoa fedha, lakini hutaki mtu yeyote kuingilia salio la pochi moja kwa moja:

```py
class Wallet:
   def __init__(self, balance):
       self.__balance = balance # Private attribute

   def deposit(self, amount):
       if amount > 0:
           self.__balance += amount # Add to the balance safely

   def withdraw(self, amount):
       if 0 < amount <= self.__balance:
           self.__balance -= amount # Remove from the balance safely

account = Wallet(500)
print(account.__balance) # AttributeError: 'Wallet' object has no attribute '__balance'
```

- **Tofauti kati ya kuweka kiambishi awali cha mstari mmoja na wa mistari miwili kwa sifa za kipengele**: Kuweka kiambishi awali cha mstari mmoja kwa sifa na njia inaashiria kuwa ni kwa matumizi ya ndani tu. Hii ni mkataba tu, na Python haizuizi upatikanaji wake kutoka nje ya darasa. Kuweka kiambishi awali cha mistari miwili husababisha mchakato wa kubadilisha jina, ambao hubadilisha `__balance` kuwa `_Wallet__balance`. Hii husaidia kuepuka migongano ya majina kwa bahati mbaya katika madarasa ya watoto, lakini haifanyi upatikanaji wa nje kuwa mgumu:

```py
print(account._Wallet__balance) # 500
```

## Nini ni wapokeaji na wapezaji?

- **Wapokeaji na Wapezaji**: Njia zinazokuwezesha kudhibiti jinsi sifa za darasa zinavyopatikana na kubadilishwa. Unapata thamani kwa wapokeaji na unaweka thamani kwa wapezaji.
- **Sifa**: Zinawaunganisha wapokeaji na wapezaji, na kuruhusu upatikanaji wa data. Zinatumia mantiki ya ziada nyuma ya pazia wakati unapata, unaweka, au unafuta thamani.
- **Kwa nini sifa badala ya njia**: Sifa hutumika badala ya njia kwa ajili ya usomaji bora na msimbo safi. Zinakuwezesha kupata thamani kwa uandishi wa nukta, kama sifa za kawaida, bila mabano ya kawaida.
- **Vifunguo**: Kifunguo ni kitendakazi kinachobadilisha au kufunika vitendakazi vingine, au madarasa, bila kubadilisha msimbo wao wa awali. Unaweka kifunguo kwa kuweka `@decorator_name` moja kwa moja juu ya ufafanuzi wa kitendakazi au darasa. Kwa mfano, kuweka kifunguo cha `@property` juu ya njia hubadilisha kuwa sifa, hivyo inaweza kupatikana kama sifa huku ikipiga wito wa njia iliyofunguliwa ndani.
- **Kuunda mpokeaji**: Kuunda mpokeaji, tumia kifunguo cha `@property`. Hapa kuna mpokeaji anayeleta mduara wa mduara:

```py
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self): # A getter to get the radius
        return self._radius
  
    @property
    def area(self):  # A getter to calculate area
        return 3.14 * (self._radius ** 2)

my_circle = Circle(3)

print(my_circle.radius) # 3
print(my_circle.area) # 28.26
```

- **Kuunda mpezaji**: Kuunda mpezaji atakayoweka mduara, lazima ueleze njia nyingine yenye jina sawa na utumie `@<property_name>.setter` juu yake:

```py
class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def radius(self):  # A getter to get the radius
        return self._radius

    @radius.setter
    def radius(self, value):  # A setter to set the radius
        if value <= 0:
            raise ValueError('Radius must be positive')
        self._radius = value

my_circle = Circle(3)
print('Initial radius:', my_circle.radius) # Initial radius: 3

my_circle.radius = 8
print('After modifying the radius:', my_circle.radius) # After modifying the radius: 8
```

- **Jinsi Python inavyoshughulikia wapokeaji na wapezaji**: Mara unapofafanua wapokeaji na wapezaji, Python huwaita moja kwa moja kila wakati unapotumia sintaksia ya kawaida ya sifa hivi:

```py
my_circle.radius # This will call the getter
my_circle.radius = 4 # This will call the setter
```

Ndani ya mpezaji, haufai kuweka jina la sifa yenyewe kwa sababu hiyo itasababisha `RecursionError`.

- **Mfuta**: Baada ya kuweka na kupata thamani kwa mpezaji na mpokeaji, unaweza kudhibiti jinsi inavyofutwa kwa `deleter`. Mfuta hufanya mantiki maalum wakati unapotumia tamko la `del` kwenye sifa. Kuunda mfuta, tumia dekoreta wa `@<property_name>.deleter`.

```py
  # Deleter
    @radius.deleter
    def radius(self):
        print("Deleting radius...")
        del self._radius
```

## Nini ni urithi na unavyosaidia kutumia msimbo tena?

- **Urithi**: Mchakato ambapo darasa la mtoto hutumia sifa na njia za darasa la mzazi. Urithi husaidia kutumia msimbo tena, hutoa hierarkia wazi, na kubadilisha tabia bila kuandika msimbo upya. Kutekeleza urithi, darasa la mtoto huchukua jina la darasa la mzazi:

```py
class Parent:
    # Parent attributes and methods

class Child(Parent):
    # Child inherits, extends, and/or overrides where necessary
```

- **Urithi wa moja kwa moja na wa mara nyingi**: Wakati darasa la mtoto linarithi sifa na njia kutoka kwa mzazi mmoja, kama unavyoona hapo juu, mchakato huo huitwa **urithi wa moja kwa moja**. Wakati darasa la mtoto linarithi sifa na njia kutoka kwa wazazi zaidi ya mmoja, hiyo ni **urithi wa mara nyingi**. Hapa ni sintaksia yake:

```py
class Parent:
    # Attributes and methods for Parent

class Child:
    # Attributes and methods for Child

class GrandChild(Parent, Child):
    # GrandChild inherits from both Parent and Child
    # GrandChild can combine or override behavior from each
```

- **Kitendakazi cha `super()`**: Kitendakazi kinachokuwezesha **kuita** njia kutoka kwa darasa la mzazi, wakati darasa lina utekelezaji tofauti wa njia hiyo, au linaongeza njia hiyo, bila kuandika msimbo mara mbili.

## Nini ni polimofizimu na inavyosaidia kutumia msimbo tena?

- **Polimofizimu**: Kanuni ya OOP inayoruhusu madarasa tofauti kutumia jina moja la njia, lakini kila darasa linautekeleza tofauti wakati linapoitwa. Hapa ni sintaksia yake:

```py
class A:
   def action(self): ...

class B:
   def action(self): ...

class C:
   def action(self): ...

Class().method()  # Works for A, B, or C
```

- **Polimofizimu inayotegemea urithi**: Mzazi huandaa njia, na kila darasa la mtoto huibadilisha kwa matumizi yao.

## Nini ni mchakato wa kubadilisha majina na unafanya kazi vipi?

- **Mchakato wa kubadilisha majina**: Ni mchakato ambapo Python hubadilisha jina la sifa lililo na kiambishi awali cha mistari miwili kwa kuongeza mstari chini na jina la darasa kama kiambishi awali, kubadilisha `__attribute` kuwa `_ClassName__attribute`.
- **Madhumuni ya mchakato wa kubadilisha majina**: Madhumuni kuu ni kuzuia kufunikwa kwa sifa na njia kwa bahati mbaya wakati unapotumia urithi. Hapa kuna mfano wa msimbo unaoelezea hili kwa urahisi:

```py
class Parent:
    def __init__(self):
        self.__data = 'Parent data'

class Child(Parent):
    def __init__(self):
        super().__init__()
        self.__data = 'Child data'

c = Child()
print(c.__dict__) # {'_Parent__data': 'Parent data', '_Child__data': 'Child data'}
```

## Nini ni ufupishaji na unavyosaidia kuweka mifumo ngumu imepangwa?

- **Ufupishaji**: Dhana ya programu ambapo maelezo magumu ya utekelezaji wa kitu au mfumo yanafichwa na kuonyeshwa tu vipengele muhimu. Katika Python na lugha nyingine za programu, ufupishaji hurahisisha mifumo ngumu kwa kuongeza upatikanaji tena.
- **Mfano wa ufupishaji**: Mfano mzuri wa ufupishaji katika maisha ya kila siku ni gari linakuruhusu kutumia tu gurudumu, pedali, na shifta bila kujua jinsi injini au breki zinavyofanya kazi.
- **Jinsi Python inatekeleza ufupishaji**: Unaweza kuunda ufupishaji kwa vitendakazi na madarasa ya kawaida kwa kuficha maelezo ya utekelezaji nyuma ya kiolesura rahisi. Kwa violesura rasmi zaidi, moduli ya `abc` ya Python hutoa darasa msaidizi la `ABC` na kifunguo cha `@abstractmethod`. Darasa la msingi la ufupishaji linafafanua njia na sifa za kawaida ambazo madarasa halisi yanatarajiwa kutoa.
- **Jinsi njia za ufupishaji zinafafanuliwa**: Njia ya ufupishaji inafafanuliwa kwa `@abstractmethod`. Darasa linaweza tu kuanzishwa ikiwa linatoa au kurithi utekelezaji halisi wa njia zake zote za ufupishaji. Darasa la mtoto linaloacha njia yoyote ya ufupishaji bila utekelezaji hubaki kuwa la ufupishaji. Njia ya ufupishaji bado inaweza kuwa na utekelezaji wa msingi, ambao madarasa ya watoto yanaweza kuitumia kwa `super()`. Kurithi kutoka `ABC` pekee hakuzuizi kuanzishwa: `ABC()` na madarasa yasiyo na njia za ufupishaji yanaweza kuanzishwa. Sintaksia ya msingi ya ufupishaji ni kama ifuatavyo:

```py
from abc import ABC, abstractmethod

# Define an abstract base class
class AbstractClass(ABC):
    @abstractmethod
    def abstract_method(self):
        pass

# Concrete subclass that implements the abstract method
class ConcreteClassOne(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassOne')

# Another concrete subclass
class ConcreteClassTwo(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassTwo')

AbstractClass() # TypeError
ConcreteClassOne().abstract_method() # Implementation in ConcreteClassOne
```

## Uwawakilishi wa vitu

- **Njia ya `__repr__`**: Njia maalum inayorejesha uwakilishi wa mfuatano wa herufi wa kitu. Kwa kawaida, mfuatano huo unapaswa kuonekana kama msimbo ulio tumika kuunda kitu hicho. Kwa mfano, `Employee('Charlie', 'developer')` inapaswa kuwakilishwa kama `Employee('Charlie', 'developer')`.
- **Kitendakazi cha `repr()`**: Unapoitisha `repr()` kwa kitu, Python hupiga wito wa njia ya `__repr__` ya kitu hicho ndani. Kwa mfuatano wa herufi, `repr()` huongeza nukuu na kuondoa waharibifu wowote unaohitajika:

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

- **Mabadiliko ya `!r`**: Ndani ya f-string, kuongeza `!r` baada ya usemi wa kihesabu hutumia `repr()` kwa usemi huo. Kutumia `!r` katika `__repr__` kunahakikisha uwakilishi ni halali wakati thamani ina nukuu au mkwaju wa nyuma, tofauti na kuzunguka thamani kwa nukuu kwa mkono:

```py
class Employee:
    def __init__(self, name, level):
        self.name = name
        self.level = level

    def __repr__(self):
        return f'Employee({self.name!r}, {self.level!r})'

print(repr(Employee("O'Reilly", 'junior'))) # Employee("O'Reilly", 'junior')
```

## Mifungu ya maelezo na ukaguzi wa aina

- **Mifungu ya maelezo**: Mfuatano wa herufi unaowekwa kama tamko la kwanza katika darasa au kitendakazi ili kuandika maelezo yake. Mifungu ya maelezo kawaida huwekwa ndani ya alama za nukuu maradufu tatu:

```py
class Movie:
    """Parent class representing a movie."""

def add(x, y):
    """A function that returns the sum of two numbers."""
    return x + y
```

- **`isinstance()` dhidi ya `type()`**: `isinstance(obj, ClassName)` hurudisha `True` ikiwa `obj` ni mfano wa `ClassName` au mojawapo ya madarasa yake ya watoto, kwa sababu inazingatia mnyororo mzima wa urithi. Ili kuangalia darasa moja halisi, linganisha badala yake `type(obj)`:

```py
class Movie:
    pass

class TVSeries(Movie):
    pass

series = TVSeries()
print(isinstance(series, Movie)) # True
print(type(series) == Movie) # False
print(type(series) == TVSeries) # True
```

## Makosa maalum yenye muktadha wa ziada

- **Kuhifadhi muktadha kwenye hitilafu**: Hitilafu maalum inaweza kupokea data ya ziada pamoja na ujumbe wake. Kupiga wito `super().__init__(message)` huruhusu darasa la `Exception` lililojengwa ndani kuhifadhi na kuonyesha ujumbe, na unaweza kisha kuhifadhi data ya ziada kama sifa. Unaposhika hitilafu, unaweza kusoma sifa hiyo kusaidia katika kurekebisha makosa:

```py
class MediaError(Exception):
    """Custom exception for media-related errors."""

    def __init__(self, message, obj):
        super().__init__(message)
        self.obj = obj

try:
    raise MediaError('Only Movie or TVSeries instances can be added', 42)
except MediaError as e:
    print(f'Media Error: {e}') # Media Error: Only Movie or TVSeries instances can be added
    print(f'Unable to add {e.obj}: {type(e.obj)}') # Unable to add 42: <class 'int'>
```

## Vidokezo vya aina

- **Vidokezo vya aina**: Maelezo ya hiari yanayoashiria kwa wasanidi programu wengine aina ya data inayotarajiwa kwa kigezo, parameta, au thamani ya return. Python haiwafanyi kazi hizi wakati wa utekelezaji.
- **Vidokezo vya aina vya parameta na return**: Unaongeza kidokezo cha aina ya parameta kwa kuweka nukta ya wima baada ya jina la parameta, na kidokezo cha aina ya return kwa `-> return_type` baada ya orodha ya parameta. Kwa kuwa `__init__` ni mzalishaji ambaye thamani yake ya return lazima iwe `None`, kidokezo chake cha return ni `None`:

```py
class Product:
    def __init__(self, name: str, price: float) -> None:
        self.name = name
        self.price = price

    def is_affordable(self, budget: float) -> bool:
        return self.price <= budget
```

- **Madarasa maalum na orodha kama aina**: Unaweza kutumia madarasa yako kama vidokezo vya aina, na `list[ClassName]` inaelezea orodha yenye vitu vya darasa hilo:

```py
class DiscountStrategy:
    pass

class DiscountEngine:
    def __init__(self, strategies: list[DiscountStrategy]) -> None:
        self.strategies = strategies
```
