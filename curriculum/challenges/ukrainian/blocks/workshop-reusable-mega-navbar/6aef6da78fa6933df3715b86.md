# --description--

Останнє, що потрібно зробити — оновити стан `isOpen`, коли натискають на кнопку `Apps`.

У React ви реагуєте на події, передаючи функцію в атрибут події на елементі. Ці атрибути пишуться у верблюжому регістрі, тому натискання обробляється за допомогою `onClick`:

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

Зверніть увагу, що `onClick` отримує функцію. React викликає цю функцію щоразу, коли натискають кнопку. Виклик функції-встановлювача з новим значенням оновлює стан, і React потім повторно відтворює компонент із цим новим значенням.

Щоб переключати булевий стан між `true` і `false`, ви можете передати протилежне його поточному значенню значення у функцію-встановлювач, використовуючи логічний оператор НЕ (`!`).

Додайте атрибут `onClick` до елемента `button`. Надайте йому стрілкову функцію, яка викликає `setIsOpen` з протилежним значенням `isOpen`.

Натисніть кнопку `Apps`, щоб відкрити та закрити `sub-menu`.

От і все, ваш компонент `Navbar` готовий!

# --hints--

Натискання кнопки `Apps` має встановити атрибут `aria-expanded` у значення `"true"` і додати клас `sub-menu--open` до `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

Повторне натискання кнопки `Apps` має встановити атрибут `aria-expanded` назад у значення `"false"` і видалити клас `sub-menu--open` з `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
