# --description--

- **Rekursion**: Eine Technik, bei der eine Funktion sich selbst aufruft. Jeder Aufruf arbeitet an einer kleineren Version des ursprünglichen Problems, bis er einen Basisfall erreicht, der weitere rekursive Aufrufe stoppt.
- **Basisfall**: Die Bedingung, die die Rekursion stoppt. Sie sollten den Basisfall sorgfältig definieren. Andernfalls kann die Funktion sich immer weiter selbst aufrufen, bis Python einen `RecursionError` auslöst.
- **Rekursiver Fall**: Der Teil der Funktion, der die Funktion erneut mit einem Argument aufruft, das sie dem Basisfall näherbringt, wie zum Beispiel `number - 1` beim Herunterzählen.

```py
def recursive_countdown(number):
    if number < 1:  # Base case
        return
    print(number)
    recursive_countdown(number - 1)  # Recursive case

recursive_countdown(5)  # Prints 5, 4, 3, 2, 1
```

- **Ausführungsreihenfolge**: Die Position des rekursiven Aufrufs ändert sich, wenn der andere Code der Funktion ausgeführt wird. Code, der vor dem rekursiven Aufruf steht, läuft, während die Aufrufe tiefer gehen, während Code, der danach steht, ausgeführt wird, wenn die Aufrufe zurückkehren. Wenn Sie `print()` nach dem rekursiven Aufruf platzieren, gibt die Funktion die Zahlen in aufsteigender Reihenfolge aus:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)  # Prints 1, 2, 3, 4, 5
```

- **Aufrufstapel**: Eine Last-in-first-out-Datenstruktur, die Python verwendet, um aktive Funktionsaufrufe zu verfolgen. Jedes Mal, wenn eine Funktion aufgerufen wird, fügt Python einen Frame für diesen Aufruf oben auf den Stapel hinzu. Der Frame enthält Informationen wie die Argumente der Funktion und lokale Variablen.
- **Fortsetzen von Aufrufen**: Ein Aufruf pausiert, wenn er seinen rekursiven Aufruf macht. Wenn der Basisfall zurückkehrt, entfernt Python diesen Aufruf vom oberen Ende des Stapels, und die vorherigen Aufrufe werden nach ihrem rekursiven Aufruf fortgesetzt und kehren in Last-in-first-out-Reihenfolge zurück:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

Die Ausgabe ist:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

- **Rekursive Listenbildung**: Jeder Aufruf wird fortgesetzt, wenn sein rekursiver Aufruf zurückkehrt, und verwendet dann den zurückgegebenen Wert. Die untenstehende `countup`-Funktion gibt im Basisfall eine leere Liste zurück. Jeder andere Aufruf erhält die Liste von seinem rekursiven Aufruf, fügt seine eigene Zahl hinzu und gibt die Liste zurück:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(5))  # [1, 2, 3, 4, 5]
```

Der Aufruf mit `1` erhält `[]` und gibt `[1]` zurück, der Aufruf mit `2` erhält `[1]` und gibt `[1, 2]` zurück, und so weiter, bis der Aufruf mit `5` `[1, 2, 3, 4, 5]` zurückgibt.

- **Anwendungen der Rekursion**: Rekursion kann einfache Aufgaben wie Herunterzählen, Hochzählen und Listenbildung bewältigen. Sie ist auch nützlich für Probleme mit unbekannter Tiefe, wie das Durchlaufen eines Dateibaums.
