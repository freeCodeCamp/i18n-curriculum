# --description--

Sie haben gelernt, dass eine Zuweisung ein Alias erstellt und dass die `.copy()`-Methode eines Wörterbuchs eine flache Kopie erzeugt. Eine flache Kopie hat ein separates äußeres Wörterbuch, aber verschachtelte Objekte werden weiterhin geteilt. Jetzt, da Sie wissen, wie man Module importiert, können Sie auch das eingebaute `copy`-Modul der Standardbibliothek verwenden, um verschachtelte Sammlungen zu kopieren.

## Erstellen einer tiefen Kopie

Die Funktion `copy.deepcopy()` kopiert verschachtelte Sammlungen rekursiv. Für ein Wörterbuch, das eine Liste enthält, erstellt sie ein neues äußeres Wörterbuch und eine separate verschachtelte Liste:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
deep_copy = copy.deepcopy(original)

print(deep_copy == original) # True
print(deep_copy is original) # False
print(deep_copy['items'] is original['items']) # False

deep_copy['items'].append('fruit')
print(original['items']) # ['bread', 'cheese']
print(deep_copy['items']) # ['bread', 'cheese', 'fruit']
```

Die Wörterbücher haben zunächst gleichen Inhalt, aber weder das äußere Wörterbuch noch die verschachtelte Liste werden geteilt. Das Anhängen an die kopierte Liste lässt die ursprüngliche Liste unverändert.

## Vergleich von Zuweisung, flacher Kopie und tiefer Kopie

Lassen Sie uns alle drei Formen aus demselben Wörterbuch erstellen:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
alias = original
shallow_copy = original.copy()
deep_copy = copy.deepcopy(original)

print(alias is original) # True
print(shallow_copy is original) # False
print(deep_copy is original) # False

print(alias['items'] is original['items']) # True
print(shallow_copy['items'] is original['items']) # True
print(deep_copy['items'] is original['items']) # False
```

Fahren Sie mit diesen Objekten fort und ändern Sie einen Eintrag auf oberster Ebene über jeden Namen:

```python
alias['name'] = 'Picnic'
shallow_copy['name'] = 'Snack'
deep_copy['name'] = 'Dinner'

print(original['name']) # Picnic
print(alias['name']) # Picnic
print(shallow_copy['name']) # Snack
print(deep_copy['name']) # Dinner
```

Der Alias verweist auf das ursprüngliche Wörterbuch, daher ändert eine Zuweisung über `alias` dieses Wörterbuch. Jede Kopie hat ihr eigenes äußeres Wörterbuch, sodass das Ersetzen des `name`-Eintrags nur diese Kopie betrifft.

Als Nächstes verändern Sie die verschachtelten Listen:

```python
alias['items'].append('water')
shallow_copy['items'].append('fruit')
deep_copy['items'].append('soup')

print(original['items']) # ['bread', 'cheese', 'water', 'fruit']
print(alias['items']) # ['bread', 'cheese', 'water', 'fruit']
print(shallow_copy['items']) # ['bread', 'cheese', 'water', 'fruit']
print(deep_copy['items']) # ['bread', 'cheese', 'soup']
```

Das ursprüngliche Wörterbuch, sein Alias und die flache Kopie verweisen alle auf dieselbe Liste. Änderungen über eine dieser Referenzen sind auch über die anderen sichtbar. Die tiefe Kopie hat ihre eigene Liste, sodass deren Änderungen getrennt bleiben.

Das funktioniert auch mit Wörterbüchern, die in Listen verschachtelt sind:

```python
import copy

original = {'meals': [{'name': 'Lunch', 'items': ['bread']}]}
deep_copy = copy.deepcopy(original)
deep_copy['meals'][0]['items'].append('fruit')

print(original['meals'][0]['items']) # ['bread']
print(deep_copy['meals'][0]['items']) # ['bread', 'fruit']
```

Hier kopiert `deepcopy()` das äußere Wörterbuch, die `meals`-Liste, das Wörterbuch in dieser Liste und dessen `items`-Liste. Das Beispiel verwendet eingebaute Wörterbücher und Listen; tiefe Kopien bedeuten nicht, dass jedes mögliche Python-Objekt dupliziert wird.

Verwenden Sie Zuweisung, wenn Sie einen weiteren Namen für dasselbe Objekt wollen. Verwenden Sie eine flache Kopie, wenn eine separate äußere Sammlung ausreicht und das Teilen verschachtelter Objekte akzeptabel ist. Verwenden Sie eine tiefe Kopie, wenn Änderungen an diesen verschachtelten Sammlungen die ursprünglichen Sammlungen unverändert lassen sollen.
