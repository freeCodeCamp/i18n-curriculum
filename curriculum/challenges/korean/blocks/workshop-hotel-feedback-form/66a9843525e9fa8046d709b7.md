# --description--

워크숍의 마지막 단계에서는 폼에 제출 버튼을 추가해야 합니다.

`type` 속성이 `submit`으로 설정된 `button` 요소는 클릭하면 폼을 제출합니다. 폼 데이터는 `form` 요소에 이전에 추가한 `method` 속성의 HTTP 메서드를 사용하여 `action` 속성에 지정된 URL로 전송됩니다.

다음은 제출 버튼의 예입니다:

```html
<button type="submit">Let's Talk</button>
```

`textarea` 요소 아래에 `type`이 `submit`으로 설정된 `button` 요소를 추가하고 텍스트는 `Submit`으로 설정하세요.

이로써 호텔 피드백 폼이 완성되었습니다!

# --hints--

`form` 안에 `button` 요소가 있어야 합니다.

```js
assert.exists(document.querySelector('form button'));
```

`button` 요소에 `type` 속성이 `"submit"`으로 설정되어 있어야 합니다.

```js
assert.exists(document.querySelector('button[type="submit"]'));
```

`button` 요소의 텍스트 내용은 `Submit`이어야 합니다.

```js
assert.strictEqual(document.querySelector('button')?.textContent.trim(), 'Submit');
```
