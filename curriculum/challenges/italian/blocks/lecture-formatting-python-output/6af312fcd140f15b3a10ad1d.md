# --description--

In una lezione precedente su numeri e operazioni matematiche, hai usato una specifica di formato come `.2f` in una f-string per controllare quante cifre decimali mostra un numero.

Le specifiche di formato possono anche controllare quanto spazio occupa un valore e dove si posiziona. Questo è utile quando vuoi che l'output sia allineato in colonne ordinate.

## Impostare una larghezza minima e l'allineamento

Un numero dopo i due punti imposta la larghezza minima del campo, cioè il numero di caratteri che il valore dovrebbe occupare. Se il valore è più corto, Python aggiunge spazi fino a raggiungere quella larghezza. Ecco un esempio:

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

Usare simboli specifici prima della larghezza controlla dove si posiziona il valore all'interno del campo. Ecco questi simboli specifici:

- Meno di (`<`) allinea il valore a sinistra
- Maggiore di (`>`) allinea il valore a destra
- Accento circonflesso (`^`) centra il valore.

Ecco questi tre simboli in azione:

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

`'Tea'` contiene tre caratteri, quindi Python aggiunge cinque spazi per raggiungere una larghezza di `8`.

- Con `<`, gli spazi vanno dopo il valore
- Con `>`, gli spazi vanno prima
- Con `^`, gli spazi sono divisi su entrambi i lati per centrare il testo.

Se lo spazio non può essere diviso equamente, lo spazio extra va a destra:

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

Se ometti il simbolo di allineamento, le stringhe sono allineate a sinistra per impostazione predefinita, mentre i numeri sono allineati a destra:

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## Usare un carattere di riempimento

Per impostazione predefinita, Python aggiunge spazi. Per usare un carattere diverso per la spaziatura interna, inserisci il carattere subito prima del simbolo di allineamento:

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

In `*^9`, il `*` è il carattere di riempimento, `^` centra il valore e `9` è la larghezza minima. Nota che puoi usare un carattere di riempimento solo insieme a un simbolo di allineamento.

## Combinare larghezza e precisione

Puoi combinare allineamento e larghezza con la precisione che hai imparato nella lezione precedente, tutto in una sola specifica di formato:

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

La specifica di formato nell'esempio sopra significa: allinea a destra, usa una larghezza minima di `7` e mostra due cifre decimali. Python formatta prima il numero come `4.50`, che è lungo quattro caratteri, e poi aggiunge tre spazi davanti per riempire la larghezza di `7`.

## Costruire una riga di istruzione

Puoi mettere un'etichetta e un importo insieme su una riga. Se usi la stessa specifica di formato per ogni riga, le colonne si allineano:

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

Ogni etichetta è allineata a sinistra in un campo di `12` caratteri e riempita con punti, mentre ogni importo è allineato a destra in un campo di `8` caratteri, così i punti decimali si allineano.

## La larghezza è un minimo, non un massimo

La larghezza aggiunge solo spaziatura. Non tronca mai un valore. Se il valore è più lungo della larghezza specificata, viene mostrato tutto il valore:

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

Lo stesso vale per i numeri. Nell'esempio sotto, l'importo formattato ha bisogno di otto caratteri, quindi ignora la larghezza specificata di `7`:

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

In `:7.2f`, il `7` è una larghezza minima, non un limite su quanto può essere lungo l'importo. Python non tronca mai le cifre per far entrare un numero.

Per questo dovresti scegliere larghezze abbastanza grandi per i valori che ti aspetti, altrimenti le colonne non si allineeranno.

Se vuoi limitare la lunghezza di una stringa, aggiungi una precisione alla specifica di formato. Per le stringhe, la precisione imposta il numero massimo di caratteri da mostrare:

```py
label = 'Long description'

print(f'|{label:.8}|') # |Long des|
print(f'|{label:<12.8}|') # |Long des    |
```

In `<12.8`:

- `<` allinea il valore a sinistra
- `12` è la larghezza minima
- `.8` è il numero massimo di caratteri.

Python taglia la stringa a otto caratteri prima, poi la riempie fino a una larghezza di dodici.

Nota che la precisione significa qualcosa di diverso per le stringhe rispetto ai numeri. Con `.2f`, `.2` imposta il numero di cifre decimali. Con una stringa, `.8` imposta il numero massimo di caratteri.
