# --interactive--

`text-decoration` 属性允许你为文本添加装饰线。

它的初始值是 `none`，通常用于去除浏览器为链接添加的默认下划线，当你需要自定义这些链接时非常有用。

```css
a {
  text-decoration: none;
}
```

虽然通常用于链接，`text-decoration` 也可以装饰其他文本。

## `text-decoration` 属性的其他值

除了 `none`，`text-decoration` 属性的其他值有：

- `underline`
- `overline`
- `line-through`

正如这些值的名称所示，`underline` 会在文本下方添加一条线，`overline` 会在文本上方添加一条线，而 `line-through` 会在文本中间添加一条线，就像划掉文本一样。

## `text-decoration` 属性的更多内容

`text-decoration` 属性实际上是一个简写属性，组合了以下属性：

- `text-decoration-line`：`none`、`underline`、`overline` 和 `line-through`
- `text-decoration-color`：线条的颜色。
- `text-decoration-style`：`solid`、`double`、`dotted`、`dashed` 或 `wavy`。
- `text-decoration-thickness`：线条的粗细。

例如，这会为段落添加一条红色波浪线：

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

这会为段落添加一条绿色双重上划线：

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

你也可以根据需要组合多种线条类型：

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
