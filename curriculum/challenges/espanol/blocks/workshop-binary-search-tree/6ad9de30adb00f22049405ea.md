# --description--

La raíz es el nodo más alto del árbol, y se puede acceder a todos los demás nodos desde ella.

Ahora crea una clase llamada `BinarySearchTree` para representar el árbol en sí. Dale un método `__init__` que solo tome `self`.

Un árbol nuevo no tiene nodos, así que establece un atributo `root` en `None` dentro del método `__init__`.
