# --description--

يعتمد المطوّرون المحترفون على مجموعة متنوعة من الأدوات لزيادة الإنتاجية وجودة الكود. دعنا نتعرف على هذه الأدوات، بما في ذلك تلك التي تبدو واضحة جدًا.

الأداة الأولى هي الكمبيوتر نفسه. الكمبيوتر هو بيئة العمل الأساسية للتطوير. يمكن أن يكون جهاز مكتبي ثقيل أو حاسوب محمول قابل للحمل يعمل بنظام تشغيل Windows أو macOS أو Linux.

غالبًا ما يختار المطوّرون المحترفون حواسيب ذات قدرة معالجة سريعة وذاكرة وصول عشوائي كبيرة للتعامل مع المهام التي تستهلك موارد كثيرة.

بعد الكمبيوتر يأتي برنامج لكتابة وتحرير الكود مباشرة على ذلك الكمبيوتر. هذا هو محرر الكود أو بيئة التطوير المتكاملة (IDE).

توفر بيئات التطوير المتكاملة مثل Visual Studio وIntelliJ IDEA وPyCharm ميزات قوية مثل إكمال الكود، وتصحيح الأخطاء، ودعم الطرفية المدمجة.

يُعد Visual Studio Code (VS Code) في الأساس محرر كود، لكنه يوفر أيضًا هذه الوظائف من خلال مكتبته الغنية من الإضافات.

من محررات الكود الأخرى Sublime Text وNotepad++.

عندما تكتب كودًا باستخدام محررات الكود وبيئات التطوير المتكاملة، تحتاج إلى تتبع التغييرات التي تجريها على ذلك الكود. الأداة التي تتيح لك تتبع هذه التغييرات هي نظام التحكم في الإصدارات.

Git هو نظام التحكم في الإصدارات الأكثر استخدامًا في مجتمع التطوير.

توفر منصات مثل GitHub وGitLab وBitbucket خدمات استضافة سحابية لمستودعات Git الخاصة بك. تتيح هذه المنصات التعاون مع مطوّرين آخرين، وتمكنك من العمل على فروع متعددة، وتسهل دمج تغييرات الكود.

مديرو الحزم هم أداة حيوية أخرى. يساعدون المطوّرين على تبسيط عملية إضافة وتحديث وإزالة المكتبات واعتمادات المشروع.

أمثلة على مديري الحزم الشائعة هي:

* npm وYarn وpnpm لـ JavaScript
* pip لـ Python
* Composer لـ PHP
* Maven لـ Java

بعد كتابة الكود باستخدام أدوات مختلفة، يختبر المطوّرون ذلك الكود للتأكد من أنه يعمل كما هو متوقع.

لهذا، يستخدم المطوّرون أُطُر اختبار مثل Cypress وPlaywright وSelenium وغيرها. هناك أيضًا أُطُر اختبار خاصة بكل لغة. الأمثلة هي:

* Jest لـ JavaScript
* pytest لـ Python
* JUnit لـ Java
* PHPUnit لـ PHP

لا تحتاج فقط إلى اختبار الكود للتأكد من عمله كما هو متوقع، بل تحتاج أيضًا إلى اختبار الشكل المرئي للكود للمستخدمين النهائيين. يستخدم المطوّرون متصفحات الويب لهذا الغرض.

تقدم المتصفحات الحديثة مثل Chrome وFirefox وEdge وSafari أدوات مطوّر لفحص كود HTML وCSS وJavaScript. هناك أيضًا أدوات لتصحيح الأخطاء وتحليل الأداء.

تساعد هذه الأدوات المطوّرين على اختبار وتحسين تطبيقات الويب عبر متصفحات مختلفة للمستخدمين النهائيين.
