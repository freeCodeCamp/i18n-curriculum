# --description--

메이저 번호가 같으면 마이너 번호를 비교해야 합니다. 마이너 번호가 다르면 마이너 업데이트입니다: 새 버전은 이전 버전과 호환되는 새로운 기능을 추가합니다.

튜플을 슬라이스하면 새 튜플이 생성되고, 튜플 비교는 처음으로 다른 요소 쌍에서 정지합니다. 예를 들어 `(2, 1) < (2, 2)`는 `True`인데, 첫 번째 요소가 같고 `1`이 `2`보다 작기 때문입니다.

`installed`의 처음 두 요소를 포함하는 슬라이스가 `latest`의 같은 슬라이스보다 작은지 확인하는 `elif` 절을 추가하세요. 그렇다면 문자열 `minor update`를 `update_type`에 할당하세요.
