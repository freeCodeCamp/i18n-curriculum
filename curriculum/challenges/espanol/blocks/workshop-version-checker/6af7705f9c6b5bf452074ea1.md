# --description--

Para encontrar la última versión, necesitas que las versiones estén en orden. Las tuplas se comparan elemento por elemento, de izquierda a derecha, así que ordenar una colección de tuplas de versiones las pone en el orden correcto de versiones.

Define una función llamada `check_for_update` con dos parámetros, `installed` y `releases`. Dentro de ella, crea una variable llamada `sorted_releases` y asígnale el resultado de llamar a `sorted()` con `releases` como argumento.

Luego, imprime `sorted_releases`.
