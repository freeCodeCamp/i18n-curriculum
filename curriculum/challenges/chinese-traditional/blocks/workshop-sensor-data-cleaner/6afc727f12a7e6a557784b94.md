# --description--

要為每個差異取得標籤，你需要在 `for` 之前使用條件運算式，而不是在後面加 `if`：

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

從你的列表推導式中移除後面的 `if`。接著，將 `for` 前的運算式改成條件運算式，當 `difference` 大於 `0` 時求值為 `f'+{difference} °C'`，否則求值為 `f'{difference} °C'`。負數已經有 `-` 符號，所以只需要單位。
