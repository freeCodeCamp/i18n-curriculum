# --description--

Uma expressão regular, ou regex, é um padrão usado para buscar uma sequência de caracteres em texto.

Você já usou o operador `in` para verificar se uma string contém uma substring exata. Mas há casos em que você não sabe o texto exato que está procurando, apenas sua forma. Por exemplo, pode querer verificar se uma string começa com algumas letras seguidas de alguns dígitos, ou se um nome de usuário é formado apenas por caracteres permitidos.

Expressões regulares permitem descrever padrões assim e verificar se uma string corresponde a eles. Elas são comumente usadas para validar entrada, buscar em textos e extrair informações de strings.

Em Python, para usar expressões regulares você precisa importar o módulo `re`, que faz parte da biblioteca padrão:

```python
import re
```

O padrão regex mais simples é um padrão literal: uma sequência de caracteres que deve aparecer exatamente como escrita. Por exemplo, o padrão `'cat'` corresponde às letras `c`, `a` e `t`, uma após a outra.

Para buscar um padrão dentro de uma string, você pode usar a função `search` do módulo `re`. Ela recebe o padrão como primeiro argumento e a string para buscar como segundo argumento:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

Quando `re.search` encontra o padrão em qualquer lugar da string, retorna um objeto de correspondência. O objeto impresso mostra duas coisas:

- `match='cat'` é o texto que correspondeu ao padrão.

- `span=(4, 7)` é a localização da correspondência na string. A correspondência começa no índice `4` e termina logo antes do índice `7`.

Você também pode obter essa informação do objeto de correspondência com seus métodos `group` e `span`:

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

Quando o padrão não é encontrado, `re.search` retorna `None`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

Por padrão, a correspondência de regex é sensível a maiúsculas e minúsculas. Isso significa que o padrão `'Cat'` não corresponde ao texto `cat`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

Para mudar como um padrão é correspondido, você pode passar uma flag como terceiro argumento para `re.search`. A flag `re.IGNORECASE` torna a busca insensível a maiúsculas e minúsculas, então letras maiúsculas e minúsculas são tratadas como iguais:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
