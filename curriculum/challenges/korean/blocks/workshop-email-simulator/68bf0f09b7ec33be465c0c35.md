# --description--

`__str__` 메서드 끝에서 이메일 요약을 다음 형식으로 반환하세요:

```md
[status] From: sender | Subject: subject
```

여기서 `status`은 이메일 상태, `sender`는 발신자 이름, `subject`은 이메일 제목입니다.

여러 개의 요약이 한 줄씩 출력될 때, 각 부분이 표 열처럼 정렬되면 읽기 더 쉽습니다. `Read`가 `Unread`보다 짧고 발신자 이름 길이가 다르므로, 각 부분에 고정 너비를 주기 위해 형식 지정자를 사용하세요.

- `status`를 너비 `6`에 왼쪽 정렬하세요.
- 발신자 이름을 너비 `10`에 왼쪽 정렬하세요.

예를 들어, `Alice`가 보낸 읽은 이메일의 제목이 `Hello`라면 다음과 같이 보일 것입니다:

```md
[Read  ] From: Alice      | Subject: Hello
```

# --hints--

`__str__` 메서드는 `status`를 너비 `6`에 왼쪽 정렬하고 발신자 이름을 너비 `10`에 왼쪽 정렬한 이메일 요약을 반환해야 합니다.

```js
({
    test: () => runPython(`
        _email = Email(User('Alice'), User('Bob'), 'Hello', 'How are you?')
        assert str(_email) == '[Unread] From: Alice      | Subject: Hello'
        _email.read = True
        assert str(_email) == '[Read  ] From: Alice      | Subject: Hello'
    `)
})
```
