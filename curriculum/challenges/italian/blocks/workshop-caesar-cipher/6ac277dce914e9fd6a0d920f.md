# --description--

In Python, `bool` è una sottoclasse di `int`, dove `True` si comporta come `1` e `False` come `0`. Questo significa che `isinstance()` considera i valori booleani come numeri interi:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True
```

Per questo motivo, la tua funzione attualmente accetta `True` e `False` come valori di shift.

Usa l'operatore `or` per aggiungere una seconda condizione alla tua istruzione `if` che verifica se `shift` è un booleano con `isinstance(shift, bool)`. In questo modo, la tua funzione restituisce anche `Shift must be an integer value.` quando `shift` è `True` o `False`.
