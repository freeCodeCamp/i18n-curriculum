# --description--

Nelle lezioni precedenti, hai definito funzioni usando la parola chiave `def` in questo modo:

```py
def square(num):
    return num ** 2

print(square(4)) # 16
```

Nella lezione precedente, hai passato funzioni come `is_long_word` e `to_fahrenheit` a `map()` e `filter()`. Una funzione che accetta un'altra funzione come argomento si chiama funzione di ordine superiore. Definire una funzione separata con `def` ogni volta che devi passare una funzione breve a una funzione di ordine superiore può risultare un po' verboso. Invece, puoi scrivere una funzione lambda, che è una funzione senza nome, direttamente dove ti serve.

La sintassi di una funzione lambda è la seguente:

```py
lambda parameters: expression
```

Dopo la parola chiave `lambda`, elenchi i parametri della funzione. I due punti separano i parametri da una singola espressione, e il risultato di quell'espressione viene restituito automaticamente, senza bisogno di un'istruzione `return`.

Ecco come appare la funzione `square()` rifattorizzata in una funzione lambda:

```py
lambda num: num ** 2
```

Qui, `num` è il parametro, e `num ** 2` è l'espressione il cui risultato viene restituito. Come detto prima, le funzioni lambda sono anonime, quindi questa funzione non ha più il nome `square` associato.

Una funzione lambda può avere anche più di un parametro. Proprio come con le funzioni definite con `def`, separi i parametri con le virgole:

```py
lambda a, b: a + b
```

Questa funzione lambda prende due parametri, `a` e `b`, e restituisce la loro somma.

Le funzioni lambda sono ottime quando devi passarle a funzioni di ordine superiore come questa:

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

In questo esempio, abbiamo una lista di numeri e vogliamo creare una nuova lista con i numeri pari. Quindi passiamo una funzione lambda come uno degli argomenti alla funzione `filter()`. La funzione `filter()` chiama la funzione lambda su ogni numero e mantiene solo i numeri per cui `x % 2 == 0` è `True`. Poi `list()` li raccoglie in una nuova lista contenente i numeri `2` e `4`.

Quando usi le funzioni lambda è importante seguire le buone pratiche. Per esempio, non è una buona pratica assegnare una funzione lambda a una variabile in questo modo:

```py
numbers = [1, 2, 3, 4, 5]

square = lambda x: x ** 2
squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Questo vanifica lo scopo di usare funzioni anonime. In questo caso, dovresti usare una funzione normale, come questa:

```py
numbers = [1, 2, 3, 4, 5]

def square(num):
    return num ** 2

squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Inoltre, dovresti evitare di creare funzioni lambda difficili da leggere o inutilmente complicate, come questa:

```py
result = (lambda x: (x**2 + 2*x - 1) if x > 0 else (x**3 - x + 4))(3)
print(result)  # 14
```

Anche se questa funzione funziona correttamente e produce il risultato giusto `14`, non è facile da leggere o da capire. In questo caso, sarebbe meglio creare una funzione separata con un’istruzione `if/else` e poi chiamare quella funzione:

```py
def calculate_expression(x):
    if x > 0:
        return x**2 + 2*x - 1
    else:
        return x**3 - x + 4

print(calculate_expression(3))  # 14
```

Sia le funzioni regolari sia le funzioni lambda hanno i loro casi d'uso nei programmi Python. Se devi gestire una singola espressione in linea, potresti considerare di usare una funzione lambda. Altrimenti, usare una funzione regolare è la scelta migliore.
