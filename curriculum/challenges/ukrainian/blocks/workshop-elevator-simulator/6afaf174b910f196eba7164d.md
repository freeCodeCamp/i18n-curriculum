# --description--

Ліфт має продовжувати обслуговувати запити, доки вони залишаються. Цикл `while` ідеально підходить для цього, бо він повторюється, доки його умова істинна. Ось нагадування про синтаксис:

```py
while condition:
    # code to repeat
    ...
```

Непорожній список є істинним, а порожній — хибним, тому ви можете використовувати список як умову циклу, щоб він працював, доки список не стане порожнім.

Створіть цикл `while`, який працюватиме, доки `requests` не порожній. Усередині циклу використайте `pop(0)`, щоб видалити перший запит із `requests` і призначити його змінній з ім’ям `target`. Потім виведіть `target`.

Оскільки `pop(0)` скорочує список на кожній ітерації, список зрештою стає порожнім і цикл зупиняється. Без цього умова ніколи не стане хибною, і цикл працюватиме вічно.
