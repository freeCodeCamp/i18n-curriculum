# --description--

最後の操作は値を削除することです。`BinarySearchTree`クラスの中に、`self`、`node`、`key`の3つのパラメータを持つ`_delete`という名前のメソッドを作成してください。`_insert`と同様に、変更後のサブツリーを返します。

まず、削除するノードを見つけるところから始めます。これは`_insert`で行った方法と同じです。`key`が`node.key`より小さいかどうかをチェックする`if`文を追加し、`self._delete`を`node.left`と`key`で呼び出した結果を`node.left`に代入してください。次に、`key`が`node.key`より大きい場合に右のサブツリーで同じ処理を行う`elif`節を追加します。

最後に、メソッドの最後で`node`を返してください。
