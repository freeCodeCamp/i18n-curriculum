# --description--

터미널에서 readings 대신 `<filter object at 0x...>` 같은 것이 보일 거예요. 이는 `filter()`가 리스트에 모두 저장하지 않고 한 번에 하나씩 항목을 제공하는 이터레이터를 반환하기 때문입니다.

이터레이터의 항목들을 리스트로 모으려면 `list()` 함수에 전달하면 됩니다:

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

`valid_readings`에 할당된 `filter()` 호출을 `list()` 호출로 감싸세요. 그러면 터미널에서 `-999` 오류 코드 없이 readings가 보일 거예요.
