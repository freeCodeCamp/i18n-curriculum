# --instructions--

En este proyecto, visualizarás y realizarás cálculos a partir de datos de exámenes médicos usando `matplotlib`, `seaborn` y `pandas`. Los valores del conjunto de datos (dataset) se recogieron durante los exámenes médicos.

## Descripción de datos

Las filas del conjunto de datos representan a los pacientes y las columnas representan información como medidas corporales, resultados de varios análisis de sangre y opciones de estilo de vida. Utilizarás el conjunto de datos para explorar la relación entre enfermedades cardiacas, medidas del cuerpo, indicadores sanguíneos y opciones de estilo de vida.

Nombre del archivo: medical_examination.csv

| Funcionalidad | Tipo de variable | Variable      | Tipo de valor |
|:-------------:|:----------------:|:-------------:|:-------------:|
| Edad | Funcionalidad objetiva | `age` | int (días) |
| Altura | Funcionalidad objetiva | `height` | int (cm) |
| Peso | Funcionalidad objetiva | `weight` | float (kg) |
| Género | Funcionalidad objetiva | `gender` | código categórico |
| Presión arterial sistólica | Funcionalidad de examen | `ap_hi` | int |
| Presión arterial diastólica | Funcionalidad de examen | `ap_lo` | int |
| Colesterol | Funcionalidad de examen | `cholesterol` | 1: normal, 2: por encima de lo normal, 3: muy por encima de lo normal |
| Glucosa | Funcionalidad de examen | `gluc` | 1: normal, 2: por encima de lo normal, 3: muy por encima de lo normal |
| Fumar | Funcionalidad subjetiva | `smoke` | binario |
| Consumo de alcohol | Funcionalidad subjetiva | `alco` | binario |
| Actividad física | Funcionalidad subjetiva | `active` | binario |
| Presencia o ausencia de enfermedad cardiovascular | Variable objetivo | `cardio` | binario |


## Instrucciones

Crear un gráfico similar a `examples/Figure_1.png`, donde mostramos las cifras de resultados buenos y malos para las variables `cholesterol`, `gluc`, `alco`, `active` y `smoke` en los pacientes con `cardio=1` y `cardio=0` en diferentes paneles.

Por cada número en el archivo `medical_data_visualizer.py` agrege el codigo del numero de instruccion asociado a continuación.

1. Importa los datos de `medical_examination.csv` y asígnalos a la variable `df`.
2. Agrega una columna `overweight` a los datos. Para determinar si una persona tiene sobrepeso, primero calcula su IMC dividiendo su peso en kilogramos por el cuadrado de su altura en metros. Si ese valor es > 25, entonces la persona tiene sobrepeso. Usa el valor `0` para NO sobrepeso y el valor `1` para sobrepeso.
3. Normaliza los datos haciendo que `0` siempre sea bueno y `1` siempre sea malo. Si el valor de `cholesterol` o `gluc` es 1, cambia el valor a `0`. Si el valor es mayor que `1`, cambia el valor a `1`.
4. Dibuja el gráfico categórico en la función `draw_cat_plot`.
5. Crea un DataFrame para el gráfico categórico usando `pd.melt` con los valores de `cholesterol`, `gluc`, `smoke`, `alco`, `active` y `overweight` en la variable `df_cat`.
6. Agrupa y reformatea los datos en `df_cat` para dividirlos por `cardio`. Muestra los conteos de cada funcionalidad. Tendrás que renombrar una de las columnas para que `catplot` funcione correctamente.
7. Convierte los datos a formato `long` y crea un gráfico que muestre los conteos de valores de las funcionalidades categóricas usando el método importado de la biblioteca seaborn: `sns.catplot()`.
8. Obtén la figura para la salida y guárdala en la variable `fig`.
9. No modifiques las siguientes dos líneas.
10. Dibuja el mapa de calor en la función `draw_heat_map`.
11. Limpia los datos en la variable `df_heat` filtrando los siguientes segmentos de pacientes que representan datos incorrectos:
    - la presión diastólica es mayor que la sistólica (mantén los datos correctos con `(df['ap_lo'] <= df['ap_hi'])`)
    - la altura es menor que el percentil 2.5 (mantén los datos correctos con `(df['height'] >= df['height'].quantile(0.025))`)
    - la altura es mayor que el percentil 97.5
    - el peso es menor que el percentil 2.5
    - el peso es mayor que el percentil 97.5
12. Calcula la matriz de correlación y guárdala en la variable `corr`.
13. Genera una máscara para el triángulo superior y guárdala en la variable `mask`.
14. Configura la figura de `matplotlib`.
15. Grafica la matriz de correlación usando el método importado de la biblioteca `seaborn`: `sns.heatmap()`.
16. No modifiques las siguientes dos líneas.
