# --description--

이번 단계에서는 각 `instructor`를 자신의 id를 키로 하여 `instructorsById`에 저장하세요.
`programs`에서 했던 것처럼, `instructorsById[instructor.id]`에
`instructor`를 펼치고 `programId`(값은 `program.id`로 설정)와 `departmentId`를 추가한 객체를 할당하세요.

객체를 할당하기 전에 이전 단계에서 사용한 `console.log(instructor)`를 삭제하세요.

저장된 객체를 확인하기 위해 `instructorsById[instructor.id]`를 콘솔에 출력하세요.
