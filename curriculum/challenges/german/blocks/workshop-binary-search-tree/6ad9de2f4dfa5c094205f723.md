# --description--

Jeder Knoten kann bis zu zwei Kinder haben.

Erstellen Sie innerhalb der `__init__`-Methode ein `left`-Attribut und ein `right`-Attribut und setzen Sie beide auf `None`, um einen neuen Knoten darzustellen, der ohne Kinder startet.

Ein Knoten ohne Kinder wird Blattknoten genannt.
