# --description--

ノードに2つの子がいる場合、ツリーの順序を保ちながらその値を別の値に置き換える必要があります。適切な選択はそのノードのinorder successorです。これはinorder走査でそのノードの直後に来る値です。

inorder successorはノードの右サブツリーの中で最小の値で、右の子からできるだけ左に進むことで見つけられます。

`BinarySearchTree`クラスの中に、`self`と`node`の2つのパラメータを持つ`_min_value`という名前のメソッドを作成してください。その中で、`while`ループを使い、`node.left`が`None`でない限り`node.left`を`node`に代入します。ループの後に`node.key`を返してください。
