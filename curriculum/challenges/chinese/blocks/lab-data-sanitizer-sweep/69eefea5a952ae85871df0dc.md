# --description--

在本实验中，你将通过用 `#` 替换不允许的字符来清理半结构化日志文件，并跟踪处理了多少条日志条目。

**目标：**实现以下用户需求并通过所有测试以完成实验。

**用户故事：**

1. 你应该使用函数声明来创建一个名为 `sanitizeLog` 的函数，该函数有两个参数：`entry`，表示日志条目的字串，以及 `disallowedCharacters`，表示要替换的单字符字串数组。
1. 该函数应返回修改后的 `entry` 字串，其中每个不允许的字符都被替换为 `#`。匹配应区分大小写。例如，如果不允许的字符是 `["e", "E", "o", "r"]`，那么 `DEBUG: Server started on port 3000` 应返回 `D#BUG: S##v## sta#t#d #n p##t 3000`。
1. 你应该创建一个名为 `cleanLogs` 的函数，带有两个参数：`logs`，表示日志条目的字串数组，以及 `disallowedCharacters`，表示要替换的单字符字串数组。
1. `cleanLogs` 应按顺序迭代给定的日志条目数组。
1. 当 `cleanLogs` 遇到包含致命标记 `$` 的日志条目时，应停止并返回 `Sanitizing stopped. Failure Reason: Fatal character occurred.`。
1. 以 `/` 字符开头的日志条目是信息条目，不应被清理。你应统计信息条目的数量。
1. 所有其他日志条目应使用 `sanitizeLog` 函数进行清理。你应统计已清理条目的数量。
1. 如果 `cleanLogs` 在未遇到致命标记的情况下完成，应返回 `Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.`，其中 `X` 是条目总数，`Y` 是已清理条目数，`Z` 是信息条目数。

**以下日志数组用于测试：**

```js
let logs_1 = [
  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"
];

let logs_2 = [
  "FATAL: System overload detected, shutting down",
  "DEBUG: token=def456$ refreshed for session",
  "ERROR: Null pointer exception in module auth"
];

let logs_3 = [
  "ERROR: Failed to connect to db, retry=3",
  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
