# --description--

在本实验中，你将找到单笔股票交易能获得的最大利润。你会得到每一天的股票价格，你可以在某一天买入一股，然后在之后的某一天卖出。你的目标是找到你能获得的最高利润，即卖出价格减去买入价格。

例如，对于价格 `[7, 1, 5, 3, 6, 4]`，最佳交易是在第 `1` 天以价格 `1` 买入，并在第 `4` 天以价格 `6` 卖出，利润为 `5`。你不能在价格为 `1` 时买入然后在价格为 `7` 时卖出，因为价格 `7` 出现在价格 `1` 之前。

列表可能非常长，所以你的方案应该是高效的。比较每一对买卖日期的组合需要二次时间复杂度，`O(n²)`。相反，找到一种只遍历列表一次的方法，使你的方案能在线性时间，`O(n)` 内运行。

**目标：**实现以下用户需求并通过所有测试以完成实验。

**用户故事：**

1. 你应该有一个名为 `max_profit` 的函数，它有一个参数，表示一个正整数列表，每个元素是当天的股票价格。
1. `max_profit` 应该返回通过在某一天买入并在之后某一天卖出所能获得的最高利润。
1. 如果没有交易能获利，或者 `prices` 少于两个元素，`max_profit` 应该返回 `0`。
1. `max_profit` 不应该修改 `prices`。
1. `max_profit` 应该在线性时间，`O(n)` 内运行，其中 `n` 是 `prices` 的长度。

**注意：** 不要检查每一对日期，而是尝试在遍历列表时跟踪你见过的最低价格，并计算当天卖出的利润。

```py
def max_profit(prices):
    lowest_price = float("inf")
    best_profit = 0

    for price in prices:
        if price < lowest_price:
            lowest_price = price
        elif price - lowest_price > best_profit:
            best_profit = price - lowest_price

    return best_profit
```
