# --description--

现在是显示发件人和收件人信息的时候了。为了让名字整齐地排列在彼此下面，给每个名字前面的文本使用格式说明符设置固定宽度。

为 `display_full_email` 方法添加两个打印语句：

- `'From:'` 左对齐，宽度为 `10`，后面跟着发件人的名字。
- `'To:'` 左对齐，宽度为 `10`，后面跟着收件人的名字。

例如，发件人是 `Alice`，收件人是 `Bob`，这两行看起来会是这样：

```md
From:     Alice
To:       Bob
```
