## Python 클래스와 객체

- **클래스 정의**: 클래스는 객체를 생성하기 위한 청사진입니다. 객체가 가질 속성과 메서드를 통해 객체의 동작을 정의합니다. 다음은 Python에서 클래스 정의의 기본 예시입니다:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **클래스 이름**: 관례상 클래스 이름은 PascalCase를 사용합니다. 각 단어는 대문자로 시작하고 밑줄은 없으며, 예를 들어 `Dog`나 `ShoppingCart`처럼 씁니다.

- **`__init__()` 메서드**: Python은 새 객체를 만들 때마다 자동으로 `__init__()`를 호출합니다. 이 메서드는 객체의 초기 속성을 설정하는 데 사용됩니다.

- **`self` 매개변수**: `self`는 메서드가 작업하는 특정 객체를 가리킵니다. 객체에서 메서드를 호출할 때 Python이 자동으로 전달하므로 호출 시 직접 쓰지 않습니다. `self`는 관례적인 이름이며, 인스턴스 메서드의 첫 번째 매개변수입니다.

- **객체 생성**: 객체는 클래스의 인스턴스입니다. 필요한 인수를 사용해 클래스를 호출하여 생성합니다.

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **객체에서 메서드 호출**: 객체에서 메서드를 호출해 동작을 수행하거나 정보를 가져올 수 있습니다.

```python
object_name1.method_name()
object_name2.method_name()
```

- **클래스와 객체의 차이**: 클래스는 재사용 가능한 템플릿이고, 객체는 실제 데이터를 가진 클래스의 특정 인스턴스입니다.

## 속성

- **인스턴스 속성**: 보통 `__init__()`에서 `self`를 사용해 정의하며, 각 객체마다 고유합니다.
- **클래스 속성**: 클래스 내부에 직접 정의되며 모든 인스턴스가 공유합니다.

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **속성을 동적으로 다루기**: 때때로 속성 이름이 실행 시점에만 알려질 때가 있습니다. 예를 들어 사용자 입력이나 반복문에서 올 때 그렇습니다. 이 경우 `object.name`처럼 쓸 수 없으니 이름을 문자열로 받는 함수를 사용합니다:

  - `getattr(obj, name)`는 속성 값을 반환합니다. 속성이 없으면 `AttributeError`를 발생시키지만, 세 번째 인수로 기본값을 주면 예외를 발생시키지 않습니다.
  - `setattr(obj, name, value)`는 속성을 생성하거나 업데이트합니다.
  - `hasattr(obj, name)`는 속성이 있으면 `True`, 없으면 `False`를 반환합니다.
  - `delattr(obj, name)`는 속성을 삭제합니다.

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **`dir()`로 속성 검사하기**: `dir()` 함수는 객체의 속성과 메서드 이름 목록을 반환합니다. `callable()`과 함께 사용하면 메서드와 데이터 속성을 구분할 수 있습니다.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## 메서드

- **메서드**: 클래스 내부에 정의된 함수로, 객체의 속성에 작용합니다.

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **메서드 접근**: 점 표기법을 사용해 객체에서 메서드를 호출합니다. 다음은 두 개의 서로 다른 자동차 객체에서 `describe` 메서드를 호출하는 예시입니다:

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## 더블 언더스코어(매직) 메서드

- **정의**: 앞뒤에 이중 밑줄이 붙은 특별한 메서드(e.g., `__init__`, `__len__`, `__str__`, `__eq__`)입니다. Python은 내장 연산을 위해 내부적으로 사용합니다.

- **사용자 정의 특수 메서드 없이 동작**: Python은 내장 연산이 사용자 정의 객체의 속성을 어떻게 사용할지 추론하지 않습니다. 가능한 경우 상속받은 기본 동작을 사용하고, 지원하지 않는 연산에는 `TypeError`를 발생시킵니다.

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **사용자 정의 메서드가 바꾸는 것**: `__len__()`은 `len()`이 오류 대신 페이지 수를 반환하게 합니다. `__str__()`은 기본 표현을 읽기 쉬운 요약으로 대체합니다. `__eq__()`는 `==`가 두 이름이 같은 객체인지 확인하는 대신 페이지 수를 비교하게 합니다.

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **더블 언더스코어 메서드 간접 호출**: 직접 호출할 필요 없이, 특정 동작이 발생할 때 Python이 자동으로 호출합니다. 이 동작에는 다음이 포함됩니다:

  - **덧셈, 뺄셈, 곱셈, 나눗셈 등 산술 연산**. 덧셈에는 `__add__()`, 뺄셈에는 `__sub__()`, 곱셈에는 `__mul__()`, 나눗셈에는 `__truediv__()`이 호출됩니다.
        
  - **문자열 연결, 반복, 포맷팅, 텍스트 변환 등 문자열 연산**. 연결에는 `__add__()`, 반복에는 `__mul__()`, 포맷팅에는 `__format__()`, 텍스트 변환에는 `__str__()`와 `__repr__()` 등이 호출됩니다.
        
  - **동등성, 작음, 큼 등 비교 연산**. 동등성 검사에는 `__eq__()`, 작음에는 `__lt__()`, 큼에는 `__gt__()` 등이 호출됩니다.
        
  - **객체를 반복 가능하게 만들고 항목을 순차적으로 처리하는 반복 작업**. `__iter__()`는 반복자를 반환하기 위해 호출되고 `__next__()`는 다음 항목을 가져오기 위해 호출됩니다.

## 실제 예시: 쇼핑 카트

- **더블 언더스코어 메서드를 가진 카트 클래스**: 내장 동작으로 항목 추가, 삭제, 반복, 내용 확인을 할 수 있습니다.

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## 객체들이 함께 작동하기

- **객체를 인수로 전달하기**: 객체는 숫자나 문자열처럼 다른 클래스의 생성자에 전달할 수 있습니다.

- **속성에 객체 저장하기**: 한 객체를 다른 객체의 속성에 저장할 수 있습니다. 그런 다음 점 표기법을 체이닝하여 `receiver.inbox.receive_email(email)`처럼 그 속성을 통해 메서드를 호출할 수 있습니다.

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## 날짜와 시간 다루기

- **현재 날짜와 시간 얻기**: `datetime.datetime.now()`를 호출하면 현재 날짜와 시간이 `datetime` 객체로 반환됩니다.

- **인스턴스에 타임스탬프 저장하기**: `__init__()` 안에서 `datetime.datetime.now()`를 호출하고 결과를 속성에 할당하여 객체가 생성된 시점을 기록합니다.

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **`strftime()`으로 포맷 지정하기**: `strftime()` 메서드는 `datetime` 객체를 문자열로 변환하며, 포맷 코드를 사용합니다: `%Y`는 4자리 연도, `%m`은 월, `%d`는 일, `%H`는 24시간제 시, `%M`은 분, `%S`는 초입니다. `-`, `/`, `:`, 공백 같은 다른 문자는 그대로 구분자로 유지됩니다.

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
