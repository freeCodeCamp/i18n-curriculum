# --description--

في هذا المختبر، ستنفذ هيكل بيانات الطابور باستخدام الدوال. الطابور هو هيكل بيانات من نوع الأول يدخل أولاً يخرج أولاً (FIFO) حيث تُضاف العناصر إلى نهاية الطابور وتُزال من بدايته.

**الهدف:** إكمال قصص المستخدم أدناه واجتياز جميع الاختبارات لإتمام المختبر.

**قصص المستخدم:**

1. يجب أن تملك دالة `initQueue` تُرجع كائنًا يحتوي على خاصية `collection` مضبوطة على مصفوفة فارغة.
1. يجب أن تملك دالة `enqueue` تضيف عنصرًا إلى نهاية الطابور.
1. يجب أن تملك دالة `dequeue` تزيل وتُرجع العنصر الأمامي من الطابور، أو `undefined` إذا لم يكن هناك عنصر.
1. يجب أن تملك دالة `front` تُرجع العنصر الأمامي من الطابور دون إزالته، أو `undefined` إذا لم يكن هناك عنصر.
1. يجب أن تملك دالة `size` تُرجع عدد العناصر في الطابور.
1. يجب أن تملك دالة `isEmpty` تُرجع `true` إذا كان الطابور فارغًا و`false` خلاف ذلك.

**ملاحظة:** تستخدم اختبارات `dequeue` و`front` و`size` و`isEmpty` دالة `enqueue` لإضافة العناصر إلى الطابور، لذلك من الأفضل تنفيذ دالة `enqueue` أولًا. الاختبار النهائي يتحقق من أن جميع دوالك تعمل معًا بشكل صحيح.

# --solutions--

```js
function initQueue() {
  return {
    collection: []
  };
}

function print(queue) {
  console.log(queue.collection);
}

function enqueue(queue, element) {
  queue.collection.push(element);
}

function dequeue(queue) {
  return queue.collection.shift();
}

function front(queue) {
  return queue.collection[0];
}

function size(queue) {
  return queue.collection.length;
}

function isEmpty(queue) {
  return queue.collection.length === 0;
}
```
