# --description--

现在你可以在 JSX 中使用 `isOpen` 状态。先从 `button` 元素开始。

`aria-expanded` 属性告诉辅助技术（例如屏幕阅读器）按钮控制的内容是显示（`"true"`）还是隐藏（`"false"`）。目前，它的值始终是 `"false"`。

记住，括弧状的花括弧让你可以在 JSX 中嵌入 JavaScript 表达式。这对属性值也适用，所以你可以使用三元操作符根据条件选择一个值：

```jsx
<p title={isDarkMode ? "Dark theme" : "Light theme"}>Theme</p>
```

更新 `button` 的 `aria-expanded` 属性，使其在 `isOpen` 为 `true` 时值为 `"true"`，在 `isOpen` 为 `false` 时值为 `"false"`。

# --hints--
