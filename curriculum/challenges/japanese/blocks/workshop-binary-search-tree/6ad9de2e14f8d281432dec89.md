# --description--

前のレッスンではツリーについて学びました。二分木は、各ノードが最大で2つの子を持つツリーで、その子は左の子と右の子と呼ばれます。

二分探索木（BST）は値を順序付けて保持する二分木です。すべてのノードに対して、その左のサブツリーの値はノードの値より小さく、右のサブツリーの値はノードの値より大きくなっています。

<img alt="a binary search tree" src="https://cdn.freecodecamp.org/curriculum/python/bst-example.png" style="background-color: white; height:500px; width:500px; padding: 10px; display: block; margin-right: auto; margin-left: auto; margin-bottom: 1.2rem;">

このワークショップでは、二分探索木を構築し、それを走査する方法を学びます。

まず、ツリーの単一のノードを表すために `TreeNode` という名前のクラスを作成してください。`__init__` メソッドを用意し、パラメータとして `self` と `key` を受け取り、`key` を `self.key` に代入してください。
