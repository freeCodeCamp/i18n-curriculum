# --description--

사용자가 빈 필드로 검색하려고 하면 함수가 실행을 멈추고 오류를 발생시킬 것입니다.

하지만 사용자가 `library` 배열에 없는 책을 검색하면 어떻게 할까요? 그 예외도 처리해야 합니다.

첫 번째 `if` 문 아래에 두 번째 `if` 문을 만드세요. 조건 안에서 논리 NOT 연산자(`!`)와 `.includes()` 메서드를 사용해 `library` 배열에 함수에 전달된 `title`이 포함되어 있지 않은지 확인하세요.

`if` 문 안에서 `throw` 키워드를 사용해 `new Error()`를 발생시키세요. `Error` 생성자에 `title + " not found!"` 표현식을 전달하세요.
