# --description--

Benvenuto al workshop di ricerca libri in biblioteca! In questo progetto costruirai una ricerca per titolo di libro gestendo gli errori in modo elegante usando `try`, `catch`, `throw` e `finally`.

Ti è stato fornito un array di libri disponibili chiamato `library`, oltre ad alcune variabili DOM di base per gestire l'input dell'utente.

Se guardi in fondo al file `script.js`, c'è un listener di evento allegato a `searchBtn`. Quando viene cliccato, si aspetta di chiamare una funzione chiamata `findBook`, passando l'input dell'utente.

Per iniziare, dichiara una funzione vuota chiamata `findBook`. Questa funzione dovrebbe prendere un singolo parametro chiamato `title`.
