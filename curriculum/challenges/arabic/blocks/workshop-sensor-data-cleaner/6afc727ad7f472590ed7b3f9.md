# --description--

قبل العمل مع القراءات، عليك إزالة رموز الخطأ.

كما تعلمت في الدروس السابقة، تحتفظ الدالة `filter()` فقط بالعناصر القابلة للتكرار التي تُرجع دالة لها قيمة صحيحة. بدلًا من تعريف تلك الدالة باستخدام `def`، يمكنك تمرير دالة lambda مباشرة إلى `filter()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

أنشئ متغيرًا باسم `valid_readings`. عيّن له نتيجة تمرير دالة lambda و`readings` إلى `filter()`. يجب أن تأخذ دالة lambda معلمة باسم `reading` وتتحقق مما إذا كانت `reading` لا تساوي `-999`.

ثم، اطبع `valid_readings` بدلًا من `readings`.
