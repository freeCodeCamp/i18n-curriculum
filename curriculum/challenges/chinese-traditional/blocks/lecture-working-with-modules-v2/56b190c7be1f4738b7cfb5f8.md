# --description--

如你在上一課所學，模組是將相關程式碼群組在一起的 Python 檔案，讓你可以在其他 Python 檔案中重複使用。

你也可以自己撰寫模組並將它們匯入你的腳本。創建自己的模組是組織程式碼的好方法。你不必只有一個很長的檔案，而是可以將程式碼拆分成較小的檔案，每個檔案群組相關程式碼，然後在需要的地方匯入它們。

舉例來說，假設你創建了一個 `temperature.py` 檔案，裡面有兩個用於溫度轉換的函式，以及一個函式呼叫來檢查其中一個函式是否正常運作：

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

如果你直接執行這個檔案，輸出會是：

```md
212.0
```

現在，假設你在與 `temperature.py` 相同的資料夾中創建另一個名為 `main.py` 的檔案。要使用你區域模組中的函式，你可以使用模組名稱（不帶 `.py` 副檔名）來匯入它：

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

如果你執行 `main.py` 檔案，輸出會是：

```md
212.0
100.0
```

當匯入 `temperature` 時，Python 會從上到下執行 `temperature.py` 中的所有程式碼。這就是為什麼即使 `main.py` 只呼叫 `fahrenheit_to_celsius()`，仍會列印出 `212.0`。像這樣的程式碼檢查通常是你只想在直接執行檔案時運行，而不是每次匯入時都執行。

為了控制這點，你可以使用一個常見的 Python 慣用法：

```python
if __name__ == '__main__':
    # Code
```

`__name__` 是 Python 中一個特殊的內建變數。

當 Python 檔案被直接執行時，Python 會將這個變數的值設為字串 `__main__`。

但是如果 Python 檔案被匯入為另一個 Python 腳本的模組，則 `__name__` 變數的值會被設定為該模組的名稱（通常是沒有 `.py` 副檔名的檔名）。

這就是為什麼你經常會在 Python 腳本中看到這個條件判斷。它包含你只想在 Python 腳本作為主程式執行時才運行的程式碼。如果腳本被匯入為模組，該區塊內的程式碼就不會執行。

這很有幫助，因為它允許 Python 腳本有兩種用途。它們可以直接執行以執行主要邏輯，或者可以匯入到另一個模組中而不執行主要邏輯。

這是更新後使用此慣用法的 `temperature.py` 檔案。它也會列印 `__name__` 的值，讓你看到它如何變化：

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

如果你直接執行這個檔案，Python 會將 `__name__` 設為 `'__main__'`，因此條件為 `True`，`if` 區塊內的程式碼會執行。輸出如下：

```md
The value of __name__ is: __main__
212.0
```

如果你改為執行 `main.py` 檔案，輸出會是：

```md
The value of __name__ is: temperature
100.0
```

`print()` 呼叫在 `if` 區塊外，當匯入 `temperature` 時仍會執行，並顯示 `__name__` 的值現在是模組名稱 `temperature`。

但因為 `__name__` 不等於 `'__main__'`，`if` 區塊內的程式碼不會執行，所以不會列印 `212.0`。唯一的其他輸出是 `100.0`，它來自 `main.py` 中的函式呼叫。
