# --description--

Vamos aprender como o idioma do seu sistema e as configurações do teclado podem afetar as oficinas de Bash e PostgreSQL.

Muitas ferramentas de programação esperam que os comandos usem caracteres padrão do teclado em inglês. Nas oficinas de Bash e PostgreSQL, isso é especialmente importante para símbolos como ponto e vírgula (`;`), aspas, barras e outros caracteres especiais.

Se seu sistema operacional ou layout de teclado usa uma configuração de idioma não inglesa, alguns caracteres podem se comportar de forma diferente do esperado. Isso pode causar erros confusos ao digitar comandos SQL ou comandos no terminal.

Para ter a melhor experiência durante essas oficinas, recomenda-se trocar temporariamente para o layout de teclado inglês (EUA) enquanto completa o curso. Isso é especialmente útil se comandos em Bash ou PostgreSQL estiverem produzindo caracteres inesperados ou erros de sintaxe ao digitar símbolos como `;` ou `\`.

O GitHub Codespaces usa o layout de teclado local, então mudar o layout no seu computador também afetará a digitação dentro do Codespaces.

No Windows:

1. Abra **Configurações** > **Hora e idioma** > **Idioma e região**
2. Adicione **Inglês (Estados Unidos)** se ainda não estiver instalado
3. Em layouts de teclado, selecione o teclado **US**
4. Mova o layout de teclado US para o topo da lista, se necessário

No macOS:

1. Abra **Configurações do sistema** > **Teclado** > **Fontes de entrada**
2. Adicione o layout de teclado **Inglês (US)**
3. Certifique-se de que o layout US esteja selecionado como teclado ativo

Em distribuições Linux como Ubuntu, Debian ou Mint:

1. Abra as configurações de teclado do sistema
2. Adicione o layout de teclado **Inglês (US)**
3. Mova-o para o topo da lista de layouts de teclado, se possível

Alguns sistemas Linux também permitem verificar e mudar o layout do teclado pelo terminal. Primeiro, verifique seu layout atual:

```bash
setxkbmap -query
```

Depois, mude para o layout US:

```bash
setxkbmap us
```

Após trocar o layout, teste os seguintes caracteres em uma caixa de texto ou terminal:

```md
; : / \ | ' " $ { } [ ] ( )
```

Se os símbolos aparecerem corretamente, seu layout de teclado provavelmente está configurado adequadamente.

Alguns layouts não ingleses tratam caracteres como `'` e `"` como teclas mortas, ou seja, elas esperam uma tecla seguinte em vez de digitar imediatamente. Depois de mudar para o layout US, esses caracteres devem ser digitados instantaneamente. Se algum caractere ainda não aparecer imediatamente, isso indica que seu layout não foi totalmente alterado.

Se você usa um layout físico de teclado não US, como AZERTY, QWERTZ ou variantes regionais de QWERTY, as teclas de símbolos podem estar em posições físicas diferentes. Nesse caso, use o teclado virtual ou visualizador de teclado do seu sistema operacional para localizar teclas como `;`, `/`, `\`, `|`, `'` e `"` após mudar para o layout US.

Usar o layout de teclado inglês (US) ajuda a garantir que os comandos Bash e PostgreSQL funcionem exatamente como esperado durante toda a oficina.

Quando terminar as oficinas, você pode voltar para o layout de teclado original.
