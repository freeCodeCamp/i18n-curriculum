## 在你的區域環境安裝 Python

- **安裝**：在 Windows 和 macOS 上安裝 Python 最簡單的方法是從官方 Python 網站（`https://www.python.org/`）下載安裝程式。在 Linux 上，大多數主要發行版如 Ubuntu、Debian 和 Fedora 已經包含 Python，因此你可以先檢查已安裝的版本，只有在缺少 Python 3 時才安裝特定發行版的套件。
- **macOS 設定**：下載並開啟 `.pkg` 安裝程式，然後依照提示操作。完成後，雙擊 `Install Certificates.command` 檔案，讓終端機完成處理以完成設定。
- **Windows 設定**：下載並執行 `.msix` Python 安裝管理器。之後，`python`、`py` 和 `pymanager` 指令即可使用，執行 `python` 若尚未安裝執行期會自動安裝，並且你可以接受選用提示，將別名目錄（例如 `python3.14.exe` 這類指令）加入你的 `PATH`。
- **Linux 設定**：開啟終端機並執行 `python --version` 或 `python3 --version`。如果兩者都沒有顯示 Python 3 版本，請到 `https://www.python.org/` 找安裝套件，或線上搜尋你發行版推薦的安裝方式。

## 驗證安裝

- **檢查版本**：在終端機執行 `python --version` 或 `python3 --version` 以確認安裝。
- **`python` 與 `python3`**：在某些較舊的 macOS 和 Linux 系統中，`python` 可能指向 Python 2。如果 `python --version` 顯示 Python 2 版本，從此以後請使用 `python3` 來執行你的程式。Python 2 已經終止支援，不應用於新開發。

## 終端機

- **定義**：終端機是一種以文字為基礎的介面，讓你透過輸入指令與你的電腦互動。每個作業系統都附帶預設的終端機應用程式。macOS 可使用 Terminal 應用程式，Windows 可使用命令提示字元或 PowerShell，Linux 則依桌面環境不同有各自的預設終端機應用程式，如 GNOME Terminal 或 Konsole。

## 程式碼編輯器與整合開發環境

- **IDE**：IDE 是整合開發環境的縮寫，具備程式碼編輯器、測試工具、終端機等多種功能。
- **Python 常用的程式碼編輯器與 IDE**：VS Code、PyCharm 和 Spyder。

## 執行 Python 腳本

- **設定你的編輯器**：在 VS Code 開啟你的專案資料夾並建立 `.py` 檔案。從擴充套件檢視安裝 Microsoft 的 Python 擴充套件，或執行 `code --install-extension ms-python.python`（macOS 需先將 `code` 指令加入你的 `PATH`）。該擴充套件為編輯器新增 Python 支援，但不會安裝 Python 本身。
- **選擇直譯器**：從命令面板執行 `Python: Select Interpreter`，指向你先前安裝的 Python 3 直譯器。
- **執行你的程式碼**：點擊執行按鈕（VS Code 右上角的播放圖示）在終端機執行目前檔案。你也可以從終端機手動執行腳本。例如，若你的專案資料夾是 `python-projects`，腳本是 `main.py`，請在包含 `python-projects` 的資料夾開啟終端機，然後進入專案資料夾並執行腳本：

```bash
cd python-projects
python main.py
```

如果你的系統中 `python3` 指令顯示 Python 3 版本，請改用 `python3 main.py`。

## 使用 Python 互動式 Shell

- **啟動互動式直譯器**：開啟終端機並執行 `python` 或 `python3`（使用顯示 Python 3 版本的指令）。`>>>` 提示符表示 Python 正在等待指令。試著列印 `"Hello, world!"`：

```python
print("Hello, world!")
```

- **讀取、求值、列印、迴圈循環（REPL）**：直譯器會讀取你的輸入，求值後列印結果，然後回到 `>>>` 提示符，讓你繼續輸入下一個指令。
- **無效輸入**：輸入非有效 Python 程式碼，例如 `something random`，會產生 `SyntaxError: invalid syntax` 訊息，並回到提示符。
- **離開直譯器**：輸入 `exit()`，或在 macOS 或 Linux 按 <kbd>Ctrl</kbd> + <kbd>D</kbd>，Windows 則按 <kbd>Ctrl</kbd> + <kbd>Z</kbd> 後再按 <kbd>Enter</kbd>。
- **何時使用**：互動式直譯器適合小型實驗和快速探索。若是較長的程式或跨多個檔案的工作，請使用程式碼編輯器或 IDE。
