# --interactive--

يُستخدم عنصر الكود المضمّن لتمثيل مقتطفات برمجية قصيرة داخل النص. من الاستخدامات الشائعة لعنصر الكود المقالات التقنية وصفحات التوثيق.

إليك مثالًا على استخدام عنصر `code` لعرض مقتطف برمجي من CSS:

:::interactive_editor

```html
<p>
  To set the text color to blue in CSS, use the following code:
  <code>color: blue;</code>
</p>
```

:::

في هذا المثال، تُستخدم خاصية `color` في CSS لتعيين لون النص إلى `blue`. عند تغليف هذا المقتطف البرمجي داخل وسم `<code>`، يُخبر المتصفح أن النص هو كود مضمّن.

يطبق المتصفح أنماطًا افتراضية على المحتوى داخل عنصر `code`. النمط الافتراضي هو خط أحادي المسافة.

عنصر `code` مخصص لتمثيل سطر واحد من الكود. إذا أردت تمثيل عدة أسطر من الكود، يجب وضع عنصر `code` داخل عنصر النص المهيأ مسبقًا.

يُستخدم عنصر النص المنسق مسبقًا لتمثيل نص منسق مسبقًا. إليك مثالًا على استخدام هذا العنصر لعرض إعلان CSS:

:::interactive_editor

```html
<pre>
  <code>
    body {
      color: red;
    }
  </code>
</pre>
```

:::

عند استخدام عنصر `pre`، يجب الانتباه إلى المسافات لأنه سيعرض النص تمامًا كما هو مكتوب في مستند HTML.

في المتصفح، سترى أن الكود مُزاح عدة مسافات إلى اليمين. إذا غيرت المسافة البادئة في مثال الكود، سترى اختلافًا في المسافة البادئة على الشاشة.

عند تضمين أمثلة كود داخل مستند HTML، استخدم عنصر `code` للمقتطفات المضمّنة القصيرة.

إذا احتجت إلى عرض مقتطفات برمجية أطول، يجب استخدام عنصري `pre` و `code` معًا.
