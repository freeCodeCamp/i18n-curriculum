# --description--

Neste laboratório, você vai implementar uma estrutura de dados de fila usando funções. Uma fila é uma estrutura de dados First-In-First-Out (FIFO) onde os elementos são adicionados ao final da fila e removidos do início.

**Objetivo:** Cumprir as user stories abaixo e fazer todos os testes passarem para completar o laboratório.

**Histórias de Usuário:**

1. Você deve ter uma função `initQueue` que retorna um objeto com uma propriedade `collection` definida como um array vazio.
1. Você deve ter uma função `enqueue` que adiciona um elemento ao final da fila.
1. Você deve ter uma função `dequeue` que remove e retorna o elemento da frente da fila, ou `undefined` se não houver nenhum.
1. Você deve ter uma função `front` que retorna o elemento da frente da fila sem removê-lo, ou `undefined` se não houver nenhum.
1. Você deve ter uma função `size` que retorna o número de elementos na fila.
1. Você deve ter uma função `isEmpty` que retorna `true` se a fila estiver vazia e `false` caso contrário.

**Nota:** Os testes para `dequeue`, `front`, `size` e `isEmpty` usam a função `enqueue` para adicionar elementos à fila, então é melhor implementar `enqueue` primeiro. O teste final verifica se todas as suas funções funcionam juntas.

Você deve ter uma `enqueue` função.

```js
assert.isFunction(enqueue);
```

A função `enqueue` deve adicionar um elemento ao final da fila.

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
assert.deepEqual(queue.collection, ['first', 'second']);
```

```js
assert.isFunction(dequeue);
```

A função `dequeue` deve remover e retornar o elemento da frente da fila.

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
enqueue(queue, 'third');
assert.strictEqual(dequeue(queue), 'first');
assert.strictEqual(dequeue(queue), 'second');
assert.lengthOf(queue.collection, 1);
```

```js

```

`enqueue` deve continuar adicionando elementos ao final da fila mesmo depois que elementos forem removidos da frente.

```js
enqueue(queue, 'third');
assert.deepEqual(queue.collection, ['second', 'third']);
```

A função `isEmpty` deve retornar `false` para uma fila não vazia.


```js

enqueue(queue, 'first');
enqueue(queue, 'second');
queue.collection.shift();
queue.collection.shift();
assert.isTrue(isEmpty(queue));
```

```js
assert.strictEqual(dequeue(queue), 'third');
assert.strictEqual(dequeue(queue), 'fourth');
assert.isTrue(isEmpty(queue));
```

# --solutions--

```js
function initQueue() {
  return {
    collection: []
  };
}

function print(queue) {
  console.log(queue.collection);
}

function enqueue(queue, element) {
  queue.collection.push(element);
}

function dequeue(queue) {
  return queue.collection.shift();
}

function front(queue) {
  return queue.collection[0];
}

function size(queue) {
  return queue.collection.length;
}

function isEmpty(queue) {
  return queue.collection.length === 0;
}
```
