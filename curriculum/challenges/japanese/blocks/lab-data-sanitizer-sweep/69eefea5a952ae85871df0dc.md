# --description--

このラボでは、許可されていない文字を`#`に置き換えて半構造化ログファイルをクリーンアップし、処理されたエントリー数を追跡します。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

**ユーザーストーリー：**

1. 関数宣言を使って、`sanitizeLog`という名前の関数を作成してください。この関数は2つのパラメータを持ちます。`entry`はログエントリーを表す文字列、`disallowedCharacters`は置き換える単一文字の文字列の配列です。
1. この関数は、許可されていない各文字を`#`に置き換えた修正済みの`entry`文字列を返す必要があります。マッチングは大文字小文字を区別します。例えば、許可されていない文字が`["e", "E", "o", "r"]`の場合、`DEBUG: Server started on port 3000`は`D#BUG: S##v## sta#t#d #n p##t 3000`を返します。
1. `cleanLogs`という名前の関数を作成してください。この関数は2つのパラメータを持ちます。`logs`はログエントリーの文字列配列、`disallowedCharacters`は置き換える単一文字の文字列の配列です。
1. `cleanLogs`は与えられたログエントリーの配列を順番に繰り返す必要があります。
1. `cleanLogs`が致命的なマーカー`$`を含むログエントリーに到達したら、処理を停止し、`Sanitizing stopped. Failure Reason: Fatal character occurred.`を返す必要があります。
1. `/`文字で始まるログエントリーは情報エントリーであり、サニタイズしないでください。情報エントリーの数をカウントしてください。
1. その他のすべてのログエントリーは`sanitizeLog`関数を使ってサニタイズしてください。サニタイズされたエントリーの数をカウントしてください。
1. `cleanLogs`が致命的なマーカーに遭遇せずに終了した場合、`Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.`を返してください。ここで`X`はエントリーの総数、`Y`はサニタイズされたエントリー数、`Z`は情報エントリー数です。

**以下のログ配列がテストで使用されます：**

```js
let logs_1 = [
  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"
];

let logs_2 = [
  "FATAL: System overload detected, shutting down",
  "DEBUG: token=def456$ refreshed for session",
  "ERROR: Null pointer exception in module auth"
];

let logs_3 = [
  "ERROR: Failed to connect to db, retry=3",
  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
