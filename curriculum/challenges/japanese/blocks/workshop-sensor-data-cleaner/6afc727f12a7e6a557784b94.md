# --description--

すべての差分にラベルを付けるには、末尾の `if` の代わりに `for` の前に条件式が必要です。

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

リスト内包表記の末尾にある `if` を削除してください。その後、`for` の前の式を条件式に変更し、`difference` が `0` より大きい場合は `f'+{difference} °C'` を評価し、それ以外の場合は `f'{difference} °C'` を評価するようにしてください。負の数にはすでに `-` 記号が付いているので、単位だけを付ければ十分です。
