## Installare un editor di codice o un IDE

Nella lezione precedente, hai imparato come installare Python sul tuo dispositivo locale. In questa lezione, imparerai come eseguire codice Python in locale.

Prima di poter iniziare a creare i tuoi script Python in locale, devi installare un editor di codice o un IDE. IDE sta per ambiente di sviluppo integrato. Un IDE combina funzionalità come un editor di codice, strumenti di test e un terminale.

Un editor di codice popolare usato da molti sviluppatori è VS Code. Visita `https://code.visualstudio.com/download` per scaricare VS Code, che supporta macOS, Windows e Linux. Questo è l'editor che useremo in questa lezione.

Altre scelte comuni per lo sviluppo Python includono:

- PyCharm
- Spyder

## Creare un file Python

Dopo aver installato VS Code, aprilo e seleziona `File`, poi `Open Folder`. Scegli o crea una cartella per il tuo progetto. Per esercitarti ulteriormente al di fuori della lezione, potresti voler avere una cartella chiamata `python-projects`.

Apri Explorer nella barra laterale sinistra di VS Code. Seleziona l'icona `New File`, che sembra un foglio con un segno più. Crea un file chiamato `main.py` e premi <kbd>Enter</kbd>. L'estensione `.py` lo identifica come un file Python.

Apri il file `main.py` e digita il seguente codice:

```py
print("Hello, world!")
```

## Installa l'estensione Python

Per installare l'estensione Python ufficiale di Microsoft, segui i passaggi specifici qui sotto:

### Metodo A: Dentro l'applicazione

1. Apri la vista Estensioni cliccando l'icona di quattro blocchi sulla barra delle attività a sinistra. In alternativa, premi <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (Windows / Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (macOS).
1. Digita `Python` nella barra di ricerca in alto.
1. Cerca il primo risultato chiamato Python, assicurandoti che l'editore indicato sotto sia Microsoft.
1. Clicca il pulsante blu <kbd>Installa</kbd>.

### Metodo B: Terminale / Riga di comando

Se preferisci installare l'estensione da terminale, assicurati prima che il comando `code` sia disponibile. Su macOS, apri la Command Palette, esegui `Shell Command: Install 'code' command in PATH` e riavvia il terminale.

Poi installa l'estensione Python eseguendo:

```bash
code --install-extension ms-python.python
```

## Selezionare un interprete Python

L'estensione funge da ponte, ma non contiene i file del linguaggio Python vero e proprio. Devi installare un interprete Python separatamente dal sito ufficiale di Python se non l'hai già fatto.

Una volta installato Python sul tuo sistema operativo, collegalo al tuo editor:

1. In VS Code, apri una cartella qualsiasi o un file che termina con `.py`.
1. Apri la Command Palette usando <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows / Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS).
1. Digita e seleziona `Python: Select Interpreter`.
1. Scegli la versione di Python 3 installata dalla lista del tuo computer. Ora apparirà nativamente nella barra di stato del tuo spazio di lavoro.

## Eseguire il tuo script Python

Per eseguire questo codice, hai alcune opzioni. La prima è cliccare il pulsante di esecuzione che sembra un pulsante play situato nell'angolo in alto a destra. Questo aprirà un terminale ed eseguirà il tuo script Python lì. Dovresti vedere il testo `Hello, world!`

Un’altra opzione è aprire un terminale ed eseguire manualmente il programma usando:

```bash
python main.py
```

Devi eseguire questo comando dalla cartella dove è salvato `main.py`. Per esempio, se `main.py` si trova dentro una cartella chiamata `python-projects`, usa prima questo comando nel terminale:

```bash
cd python-projects
```

Poi esegui:

```bash
python main.py
```

## Usare `python3` invece di `python`

In alcuni ambienti, specialmente su sistemi macOS e Linux dove sono installate sia Python 2 che Python 3, potresti dover usare `python3` invece di `python`. Questo è comune quando il comando `python` non esiste o punta a una versione più vecchia di Python.

```bash
python3 main.py
```
