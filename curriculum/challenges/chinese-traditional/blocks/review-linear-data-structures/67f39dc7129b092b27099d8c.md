## 陣列

- **靜態陣列**：大小在初始化時決定且固定。元素存放在相鄰的記憶體位置，使得存取非常高效。程式執行時無法改變其大小。

- **動態陣列**：程式執行時可以自動擴增或縮減。當陣列已滿時，會將元素複製到一個新的、更大的陣列。新大小的選擇是為了讓這些昂貴的複製操作發生得較少。

- **Python 的靜態陣列**：Python 沒有將傳統靜態陣列作為內建資料結構。其他語言，如 Java，則有支援。

### Python 列表（動態陣列）

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### 動態陣列的時間複雜度

- **存取**：O(1)
- **尾端插入**：若有空間為 O(1)，需要調整大小時為 O(n)
- **中間插入**：O(n)，因為後面的元素需要重新定位

### 靜態陣列與動態陣列的選擇

- **靜態陣列**：當你事先知道元素數量且需要頻繁存取時。
- **動態陣列**：當元素數量未知或會隨時間變化，或你會頻繁插入和刪除元素時。

## 堆疊

- **堆疊**：後進先出（LIFO）的資料結構。堆疊有兩端，頂端和底端。元素只能從頂端添加和移除。

- **推入操作**：將元素添加到堆疊頂端。使用 Python 列表時，若有空間則為 O(1) 時間，需調整大小時為 O(n)。

- **彈出操作**：從堆疊頂端移除元素。時間複雜度：O(1)。空間複雜度：O(1)。

```python
# Using a Python list as a stack, where the end of the list is the top
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operation
top_element = stack.pop()  # Returns 3
```

## 佇列

- **佇列**：先進先出（FIFO）的資料結構。佇列有兩端，前端和後端。元素從後端添加，從前端移除。

- **入佇列操作**：將元素添加到佇列後端。使用 Python 列表時，若有空間則為 O(1) 時間，需調整大小時為 O(n)。

- **出佇列操作**：從佇列前端移除元素。下一個元素成為新的前端。時間複雜度：O(1)。空間複雜度：O(1)。

```python
# Using a Python list as a queue, where the start of the list is the front
queue = []

# Enqueue operations
queue.append(1)
queue.append(2)
queue.append(3)

# Front element
front_element = queue[0]  # 1

# Dequeue operation
front_element = queue.pop(0)  # Returns 1
```

- **注意**：使用 `.pop(0)` 移除 Python 列表的第一個元素會重新定位所有剩餘元素，因此需要 O(n) 時間。

## 鏈結串列

- **鏈結串列**：線性資料結構，每個節點儲存資料和指向下一個節點的引用。節點像串鏈一樣連接。鏈結串列沒有固定大小，可以透過更新節點間的連結來擴增或縮減。

- **常見用途**：實作其他資料結構，如堆疊、佇列和雙端佇列，以及圖形演算法如深度優先搜尋和廣度優先搜尋。

### 單向鏈結串列

- **結構**：每個節點儲存資料和一個指向下一個節點的引用。
- **巡訪**：只能向前移動，從頭節點到尾節點。
- **頭節點**：列表中的第一個節點，通常是唯一可直接存取的節點。巡訪從這裡開始。
- **尾節點**：列表中的最後一個節點。其指向下一個節點的引用為 `None`，標示列表結束。

#### 插入節點

- **開頭插入**：O(1) - 將新節點連結到舊頭節點，並使其成為新頭節點
- **尾端插入**：O(n) - 必須巡訪到尾端，然後將尾節點連結到新節點
- **中間插入**：O(n) - 必須巡訪到指定位置，然後將前一節點連結到新節點，新節點連結到下一節點
- **空間複雜度**：O(1) - 只建立新節點

#### 移除節點

- **開頭移除**：O(1) - 使下一個節點成為新頭節點
- **中間移除**：O(n) - 必須巡訪到該節點，然後將前一節點連結到下一節點，形成跨越被移除節點的「橋樑」
- **尾端移除**：O(n) - 必須巡訪到尾端，然後移除前一節點的連結，使其成為新尾節點
- **空間複雜度**：O(1) - 不需額外記憶體

### 雙向鏈結串列

- **結構**：每個節點儲存資料和兩個引用：一個指向下一個節點，一個指向前一個節點。
- **巡訪**：可以雙向移動。
- **尾節點引用**：通常會在列表中保留尾節點的引用。這允許在 O(1) 時間內於尾端新增節點，無需巡訪列表，並可從尾端開始巡訪。
- **插入與刪除**：與單向鏈結串列相同，但每個節點需更新兩個引用。
- **記憶體**：比單向鏈結串列需要更多記憶體，因為每個節點儲存兩個引用而非一個。

## 何時使用各種資料結構

- **靜態陣列**：當元素數量事先已知且需要快速、頻繁存取時
- **動態陣列（列表）**：當你需要有序且可索引的存取，且事先不知道大小時
- **堆疊**：當最後加入的元素應該是第一個被移除（LIFO）時
- **佇列**：當元素應該依加入順序被處理（FIFO）時
- **單向鏈結串列**：當大小經常變動且主要在開頭插入和移除時
- **雙向鏈結串列**：當你需要雙向巡訪或有效率地在尾端新增元素，且可接受每個節點額外的記憶體時
