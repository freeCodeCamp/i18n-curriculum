# --description--

En este taller, practicarás trabajar con listas planificando el programa de un concierto de orquesta.

Como aprendiste en las lecciones anteriores, una lista es una colección ordenada de elementos. Creas una lista colocando elementos separados por comas dentro de corchetes:

```py
fruits = ['apple', 'banana', 'cherry']
```

Crea una variable llamada `pieces` y asígnale una lista que contenga las cadenas `Carnival Overture`, `Song to the Moon` y `Silent Woods`, en ese orden.
