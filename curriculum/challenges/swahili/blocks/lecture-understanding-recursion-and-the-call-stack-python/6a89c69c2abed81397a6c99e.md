# --description--

Recursion ni mbinu ambayo kitendakazi hujipigia wito. Kila wito hufanya kazi kwenye toleo dogo la tatizo la awali hadi lifikie hali inayosimamisha recursion. Hali hiyo ya kusimamisha huitwa kesi ya msingi.

Vitendakazi vya recursive vinaweza kutatua matatizo yenye kina kisichojulikana, kama vile kupita kwenye mpangilio wa faili. Pia vinaweza kufanya kazi rahisi, kama kuhesabu chini kutoka nambari fulani.

Hapa kuna kitendakazi kinachoitwa `recursive_countdown` kinachokubali nambari na kuichapisha:

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

Kupiga wito kitendakazi huchapisha `5`, lakini bado hakihesabu chini. Kabla ya kitendakazi kujipigia wito, unahitaji kufafanua kesi yake ya msingi. Bila kesi ya msingi inayoweza kufikiwa, kitendakazi kitaendelea kujipigia wito. Hatimaye Python husitisha wito na kutoa `RecursionError`.

Kwa hesabu hii ya chini, kitendakazi kinapaswa kusimama wakati `number` ni chini ya `1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

Sentensi ya `if` ni kesi ya msingi. Wakati `number` ni chini ya `1`, `return` husitisha wito hilo la kitendakazi.

Kitendakazi bado kinahitaji kesi ya recursive. Kesi ya recursive hujipigia wito tena na hoja inayosogeza kuelekea kesi ya msingi. Ili kuhesabu chini, piga wito `recursive_countdown` na `number - 1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

Hii huchapisha nambari `5`, `4`, `3`, `2`, na `1`.

Msimamo wa wito wa recursive hubadilika wakati nambari zinachapishwa. Ikiwa wito wa `print()` unakuja baada ya wito wa recursive, kitendakazi huchapisha nambari kwa mpangilio wa kuongezeka:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

Hii huchapisha nambari `1`, `2`, `3`, `4`, na `5`. Ili kuelewa kwanini, unahitaji kuelewa mpangilio wa wito.

Mpangilio wa wito ni muundo wa data wa last-in, first-out ambao Python hutumia kufuatilia wito hai za vitendakazi. Wakati kitendakazi kinapopigiwa wito, Python huongeza fremu kwa wito huo juu ya mpangilio. Fremu ina taarifa kama hoja za kitendakazi na vigezo vya ndani.

Fikiria toleo hili la hesabu ya chini:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

Matokeo ni:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

Wito wa `recursive_countdown(3)` unasimama wakati unapopiga wito `recursive_countdown(2)`. Wito wenye `2` unasimama wakati unapiga wito wa kitendakazi wenye `1`, na wito wenye `1` unasimama wakati unapiga wito wa kitendakazi wenye `0`.

Wito wenye `0` unafikia kesi ya msingi na kurudi. Python huondoa wito huo kutoka juu ya mpangilio, hivyo wito wenye `1` unaendelea baada ya wito wake wa recursive. Wito zilizobaki zinaendelea na kurudi kwa mpangilio wa kinyume: `1`, `2`, na `3`.

Kila kitendakazi cha recursive kinahitaji kesi ya msingi na kesi ya recursive inayosogeza kuelekea kwake. Wakati kesi ya msingi inaporudi, wito wa awali unaendelea kwa mpangilio wa last-in, first-out.
