# --description--

Протягом останніх кількох уроків ви звикали працювати з циклами ось так:

```py
even_numbers = []

for num in range(21):
    if num % 2 == 0:
        even_numbers.append(num)

print(even_numbers)
```

Цей приклад створює новий порожній список з назвою `even_numbers` і проходить циклом по послідовності чисел між `0` та `20`. Всередині циклу є умова, яка перевіряє, чи має поточне число остачу `0` при діленні на `2`. Це використовується, щоб визначити, чи є число парним. Якщо умова `True`, тоді поточне `num` додається в кінець списку `even_numbers`. Нарешті, ми виводимо список `even_numbers` у консоль.

## Що таке list comprehension?

Хоч цей код і працює, існує більш лаконічний спосіб записати те саме, використовуючи list comprehension. List comprehension дозволяє створити новий список в одному рядку, написавши цикл безпосередньо в квадратних дужках. Це робить код коротшим і часто легшим для читання.

Базовий синтаксис list comprehension виглядає так:

```py
[expression for item in iterable]
```

Для кожного елемента в ітерованому об’єкті обчислюється вираз перед `for`, і результат додається до нового списку. Ось приклад, який створює список, де кожне число від `0` до `4` помножене на `2`:

```py
doubled = [num * 2 for num in range(5)]
print(doubled) # [0, 2, 4, 6, 8]
```

## Фільтрація з кінцевим `if`

За бажанням, ви можете додати умову `if` в кінці list comprehension. До нового списку додаються лише ті елементи, для яких умова істинна, інші пропускаються.

Ось приклад з парними числами, перероблений із використанням list comprehension:

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

У цьому переробленому прикладі список `even_numbers` створюється за допомогою одного рядка коду. List comprehension проходить по числах від `0` до `20` і включає лише ті, що діляться на `2` без остачі. Такий підхід компактніший і усуває потребу в окремому циклі та блоці умови.

## Створення окремих внутрішніх списків

Раніше ви дізналися, що `[[]] * 3` повторює посилання на один внутрішній список. Натомість comprehension може створювати окремий внутрішній список на кожній ітерації:

```py
rows = [[] for _ in range(3)]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

Вираз `[]` обчислюється на кожній ітерації, тому кожна позиція посилається на різний список. Змінна циклу не використовується у виразі; діапазон лише контролює, скільки списків створити.

Коли змінна циклу не потрібна, розробники Python зазвичай називають її `_`, щоб показати, що її значення навмисно ігнорується. `_` все одно є звичайною назвою змінної.

## Використання умовних виразів у list comprehension

До цього ви використовували `if` та `else` для написання умовних інструкцій. Python також має умовний вираз, який записується в одному рядку і повертає значення. Ось його синтаксис:

```py
value_if_true if condition else value_if_false
```

Якщо умова істинна, весь вираз обчислюється у значення перед `if`. Інакше він обчислюється у значення після `else`. Ось приклад:

```py
num = 7
label = 'Even' if num % 2 == 0 else 'Odd'
print(label) # Odd
```

Оскільки `7` не ділиться на `2` без остачі, умова є `False`, і до `label` призначається `'Odd'`.

Ви можете використовувати умовний вираз як вираз перед `for` у list comprehension. У такому випадку він вибирає значення для кожного елемента ітерованого об’єкта, тому новий список має таку ж кількість елементів, як і оригінал. Це відрізняється від кінцевого `if`, який може виключати елементи з нового списку.

Давайте розглянемо приклад:

```py
numbers = [1, 2, 3, 4, 5]
result = [(num, 'Even') if num % 2 == 0 else (num, 'Odd') for num in numbers]
print(result)
```

У цьому прикладі у нас є список чисел, і ми хочемо створити новий список кортежів, які вказують, які числа парні, а які непарні. У першій частині спискового включення ми використовуємо умовний вираз `if`/`else`, щоб перевірити, чи число ділиться на `2` без остачі. Якщо так, результатом є кортеж із цього числа, за яким слідує слово `Even`. Інакше результатом є кортеж із числа, за яким слідує слово `Odd`.

Ось як виглядає результат, виведений у консоль:

```py
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

## Фільтрація списків за допомогою `filter()`

Ще один спосіб створити список на основі існуючого ітерованого об’єкта — це функція `filter()`. Ось приклад створення нового списку лише зі словами довжиною більше чотирьох символів:

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

Функція `filter()` використовується для вибору елементів з ітерованого об’єкта, які відповідають певній умові. Функція `filter()` приймає функцію та ітерований об’єкт як аргументи. У цьому прикладі ми передаємо функцію `is_long_word` у `filter()`, щоб перевірити, чи кількість символів у поточному слові більша за `4`. `is_long_word` записана без круглих дужок, бо ви передаєте саму функцію, а не викликаєте її. Функція `filter()` викликає `is_long_word` для кожного слова. Як і `zip()`, `filter()` повертає ітератор, який дає лише слова, що відповідають умові. Функція `list()` збирає ці слова в новий список, який призначається змінній `long_words`.

## Трансформація списків за допомогою `map()`

Окрім функції `filter()`, є ще кілька функцій, які корисні при роботі зі списками. Ще одна функція, про яку варто знати, — це функція `map()`, яка приймає ітерований об’єкт і застосовує функцію до кожного його елемента. Ось приклад використання функції `map()` для перетворення списку температур із Цельсія у Фаренгейти:

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

Так само, як і `filter()`, `map()` приймає функцію та ітерований об’єкт як аргументи. Функція `to_fahrenheit` приймає температуру і конвертує її з Цельсія у Фаренгейт. Знову ж таки, `to_fahrenheit` передається без круглих дужок, і `map()` викликає її для кожної температури у списку `celsius`. Функція `map()` також повертає ітератор, цього разу з конвертованими значеннями, тому `list()` знову використовується для збору їх у список.

## Підсумовування значень за допомогою `sum()`

Остання функція, яку ми розглянемо, — це функція `sum()`. Ця функція використовується для отримання суми з ітерованого об’єкта, наприклад списку або кортежу. Ось приклад використання функції `sum()`:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

Ви також можете передати необов’язковий аргумент `start`, який встановлює ініціальне значення для сумування. Ось оновлений приклад із використанням аргументу `start` як позиційного аргументу:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

Ви також можете вибрати використання аргументу `start` як ключового слова ось так:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

Обидві версії дадуть однаковий результат, але ключовий аргумент є трохи більш явним.

List comprehension, а також інші функції, як `map()`, `filter()` і `sum()`, можуть спочатку здатися трохи заплутаними. Але з достатньою практикою і часом ви почнете почуватися впевненіше, використовуючи їх у своїх програмах на Python.
