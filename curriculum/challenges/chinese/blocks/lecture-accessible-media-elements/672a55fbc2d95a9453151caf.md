# --interactive--

由于身体残疾、重复性劳损或个人偏好，许多用户依赖键盘而不是鼠标。 这包括使用屏幕阅读器的用户和可能没有可用鼠标的用户。 键盘无障碍可确保这些用户无障碍地有效浏览网络应用程序。

让我们来看看一些让网络应用程序键盘无障碍的实用技术。

许多用户依赖 <kbd>Tab</kbd> 键在网页上的交互元素之间移动。浏览器默认允许用户按照 HTML 中出现的顺序通过链接、按钮和表单字段等元素进行切换。这称为自然标签顺序。

有时，你可能想要调整哪些元素可对焦，或更改它们的对焦顺序。 `tabindex` 属性允许你这样做。

这是基本语法：

```html
<element tabindex="number">Element Text</element>
```

`tabindex` 的值决定了元素在键盘导航中的行为：

`tabindex="0"` 将元素添加到自然的标签顺序中。

按 Tab 键时，焦点会按 HTML 顺序依次从 `button` 到 `div`，再到链接。

点击预览窗口空白处的任意位置。然后使用 <kbd>Tab</kbd> 键观察焦点在不同元素之间移动。要与示例交互，你需要启用交互式编辑器。

:::interactive_editor

```html
<button>First</button>
<div tabindex="0">Second</div>
<a href="#">Third</a>
```

:::

`tabindex="-1"` 使元素可以通过程序获得焦点。这对于管理通常不可聚焦的元素的焦点非常有用，例如标题、容器、对话或错误信息：

```html
<p tabindex="-1">Sorry, there was an error with your submission.</p>
```

在此示例中，段落不属于正常的标签顺序，因此用户无法通过按 <kbd>Tab</kbd> 键访问它。然而，如果你通过脚本将焦点设置到该元素，消息将引起用户注意。你将在 JavaScript 课程中学习更多关于此技术的内容。

当 `tabindex` 大于 `0` 时，它设置了自定义的标签（页）顺序。因此，具有较低正值的元素会先获得焦点。

在词示例中，Tab 将首先聚焦 `input` 的 `tabindex="1"`，然后是 `2`，然后是 `3`，不管它们在 HTML 中的顺序如何。

```html
<input tabindex="2">
<input tabindex="1">
<input tabindex="3">
```

自定义正值有时会用于复杂的部件中，例如需要特定导航顺序的工具栏。 但是，我们不鼓励使用这种方法，因为它会使导航变得混乱且难以维护，尤其是在页面增长或更改时。

`accesskey` 是另一个属性，你可以用它使你的网页项目支持键盘访问。它允许你定义一个密钥，用于聚焦或激活特定元素。

这是一个交互式示例，你可以按照以下建议进行尝试（请先启用交互式编辑器）：

- `accesskey="s"` 为 `Save` 按钮分配了 <kbd>S</kbd> 键。在大多数浏览器中，按下 <kbd>ALT</kbd> + <kbd>S</kbd>（Windows）和 <kbd>CTRL</kbd> + <kbd>Option</kbd> + <kbd>S</kbd>（Mac）将激活此按钮。
- `accesskey="c"` 为 `Cancel` 按钮设置了 <kbd>C</kbd> 键，允许用户使用 <kbd>ALT</kbd> + <kbd>C</kbd>（Windows）和 <kbd>CTRL</kbd> + <kbd>Option</kbd> + <kbd>C</kbd>（Mac）激活它。
- `accesskey="h"` 为 `Home` 链接分配了 <kbd>H</kbd> 键，允许用户使用 <kbd>ALT</kbd> + <kbd>H</kbd>（Windows）和 <kbd>CTRL</kbd> + <kbd>Option</kbd> + <kbd>H</kbd>（Mac）导航到主页。

请注意，激活 `accesskey` 的确切按键组合可能因浏览器和操作系统而异。通常在 Windows 上是 <kbd>ALT</kbd> + <kbd>指定键</kbd>，在 Mac 上是 <kbd>CTRL</kbd> + <kbd>Option</kbd> + <kbd>指定键</kbd>。

`accesskey` 属性可能会带来问题，因为它可能与现有快捷键冲突，或在不同设备和键盘上表现不一致，而且用户通常不容易发现或记住。

如果你选择使用 `accesskey`，应当为用户提供明确的指导，但在大多数情况下，最好避免在网站和网络应用程序中使用 `accesskey`。

:::interactive_editor

```html
<button accesskey="s">Save</button>
<button accesskey="c">Cancel</button>
<a href="index.html" accesskey="h">Home</a>
```

:::

在应用程序中实现键盘无障碍的另一种方法是确保提供清晰的焦点指示。 如果觉得默认的浏览器焦点指示器不够好，可以通过选择元素的焦点状态来覆盖它。

这是为 `button` 元素设置焦点状态样式的示例。点击预览窗口空白处的任意位置，然后按 <kbd>Tab</kbd> 键聚焦按钮。要与示例交互，你需要启用交互式编辑器。

:::interactive_editor

```html
<link href="styles.css" rel="stylesheet">

<button>Example button</button>
```

```css
button:focus {
  outline: 2px solid #005fcc;
}
```

:::

`outline` 属性用于定义元素周围的轮廓。 本例将轮廓设置为蓝色实线，厚度设置为 2 像素。 焦点指示器的样式应能明显看出当前哪个元素有焦点。 为了便于访问，指示器与其覆盖的背景颜色的对比度必须至少达到 3:1。

你还应避免键盘陷阱，当用户无法将焦点从模态和弹出窗口等组件中的某个元素上移开时，就会出现键盘陷阱。
