# --description--

- 재귀는 기본 사례에 도달할 때까지 함수를 반복해서 호출할 수 있게 하는 프로그래밍 개념입니다.

다음은 숫자의 팩토리얼을 계산하는 재귀 함수 예시입니다:

```py
def find_factorial(n):
    if n == 0:
        return 1
    return n * find_factorial(n - 1)
```

위 예제에서 `find_factorial` 함수는 `n`이 `0`에 도달할 때까지 재귀적으로 호출됩니다. `n`이 `0`이면 기본 사례에 도달하여 함수가 `1`을 반환합니다. 그런 다음 함수는 `n`과 `find_factorial(n - 1)`의 재귀 호출 결과의 곱을 반환합니다.

- 재귀는 깊이가 알 수 없는, 예를 들어 깊게 중첩된 딕셔너리와 리스트 또는 파일 트리 같은 것을 처리할 수 있게 합니다.
- 재귀 함수의 함수 호출을 추적하기 위해 호출 스택이 사용됩니다. 함수가 호출될 때마다 호출 스택에 추가됩니다. 기본 사례에 도달하면 함수 호출이 스택에서 제거됩니다.
- 기본 사례를 신중하게 정의해야 합니다. 그렇지 않으면 함수가 계속 자신을 호출하여 Python이 `RecursionError`를 발생시킬 수 있습니다.
- 재귀는 팩토리얼과 피보나치 같은 수학 문제 해결, 트리와 그래프 탐색, 순열과 조합 생성에 유용합니다.
