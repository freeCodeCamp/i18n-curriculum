# --description--

마이너 릴리스는 마이너 번호를 `1`만큼 증가시키고 패치 번호를 `0`으로 재설정하며, 패치 릴리스는 패치 번호만 `1`만큼 증가시킵니다.

`release_type`이 문자열 `minor`와 같은지 확인하는 `elif` 절을 추가하세요. 그렇다면 `major`, `minor + 1`, `0`을 포함하는 튜플을 `new_version`에 할당하세요.

그다음 `release_type`이 문자열 `patch`와 같은지 확인하는 또 다른 `elif` 절을 추가하세요. 그렇다면 `major`, `minor`, `patch + 1`을 포함하는 튜플을 `new_version`에 할당하세요.
