# --description--

Una expresión regular, o regex, es un patrón usado para coincidir con una secuencia de caracteres en un texto.

Ya has usado el operador `in` para comprobar si una cadena contiene una subcadena exacta. Pero hay casos en los que no sabes el texto exacto que buscas, solo su forma. Por ejemplo, podrías querer verificar que una cadena comienza con algunas letras seguidas de algunos dígitos, o que un nombre de usuario está formado solo por caracteres permitidos.

Las expresiones regulares te permiten describir patrones como estos y comprobar si una cadena coincide con ellos. Se usan comúnmente para validar entradas, buscar en textos y extraer piezas de información de cadenas.

En Python, para usar expresiones regulares necesitas importar el módulo `re`, que forma parte de la biblioteca estándar:

```python
import re
```

El patrón regex más simple es un patrón literal: una secuencia de caracteres que debe aparecer exactamente como está escrita. Por ejemplo, el patrón `'cat'` coincide con las letras `c`, `a` y `t`, una tras otra.

Para buscar un patrón dentro de una cadena, puedes usar la función `search` del módulo `re`. Toma el patrón como su primer argumento y la cadena donde buscar como su segundo argumento:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

Cuando `re.search` encuentra el patrón en cualquier parte de la cadena, devuelve un objeto match. El objeto match impreso te dice dos cosas:

- `match='cat'` es el texto que coincidió con el patrón.

- `span=(4, 7)` es la ubicación de la coincidencia en la cadena. La coincidencia comienza en el índice `4` y termina justo antes del índice `7`.

También puedes obtener esta información del objeto match con sus métodos `group` y `span`:

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

Cuando no se encuentra el patrón, `re.search` devuelve `None`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

Por defecto, la coincidencia con regex distingue mayúsculas y minúsculas. Esto significa que el patrón `'Cat'` no coincide con el texto `cat`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

Para cambiar cómo se busca un patrón, puedes pasar una bandera como tercer argumento a `re.search`. La bandera `re.IGNORECASE` hace que la búsqueda no distinga entre mayúsculas y minúsculas, así que las letras mayúsculas y minúsculas se tratan igual:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
