## Algoritmos y notación Big O

- **Algoritmos**: Un conjunto de instrucciones claras para resolver un problema o realizar una tarea. Los algoritmos deben terminar en un número finito de pasos y cada paso debe ser preciso y sin ambigüedades.

- **Notación Big O**: Describe un límite superior asintótico en el uso de recursos de un algoritmo a medida que aumenta el tamaño de la entrada. Big O mide esta tendencia general de escalado por separado de si estás viendo un escenario mejor, promedio o peor, ignorando factores constantes y términos menores.

### Complejidades de tiempo comunes

- **O(1) - Tiempo constante**: El algoritmo toma el mismo tiempo sin importar el tamaño de la entrada.

```python
def check_even_or_odd(number):
    if number % 2 == 0:
        return 'Even'
    else:
        return 'Odd'
```

- **O(log n) - Tiempo logarítmico**: Un límite superior en el tiempo de ejecución que crece como máximo logarítmicamente con el tamaño de la entrada. Cuando el límite es ajustado, el algoritmo se ejecuta en tiempo logarítmico. Esto ocurre comúnmente cuando el tamaño del problema se reduce repetidamente por una fracción constante, como en la búsqueda binaria.

- **O(n) - Tiempo lineal**: Un límite superior en el tiempo de ejecución que crece como máximo linealmente con el tamaño de la entrada. Cuando el límite es ajustado, el tiempo de ejecución crece proporcionalmente al tamaño de la entrada.

```python
for grade in grades:
    print(grade)
```

- **O(n log n) - Tiempo log-lineal**: Común en ordenamientos eficientes por divide y vencerás. Merge Sort tiene complejidad O(n log n) en el peor caso. Quick Sort tiene complejidad O(n log n) en el caso promedio, pero su peor caso es O(n²).

- **O(n²) - Tiempo cuadrático**: Un límite superior en el tiempo de ejecución que crece como máximo cuadráticamente con el tamaño de la entrada. Cuando el límite es ajustado, el tiempo de ejecución crece proporcionalmente al cuadrado del tamaño de la entrada. Esto ocurre en ciclos anidados donde cada ciclo realiza n iteraciones.

```python
for i in range(n):
    for j in range(n):
        print("Hello, World!")
```

- **O(2ⁿ) - Tiempo exponencial**: Un límite superior exponencial en el tiempo de ejecución. Cuando el límite es ajustado, la tasa de crecimiento es proporcional a 2ⁿ, que se duplica cada vez que n aumenta en uno.

- **O(n!) - Tiempo factorial**: Un límite superior factorial en el tiempo de ejecución. Cuando el límite es ajustado, la tasa de crecimiento es proporcional a n!, el número de permutaciones de n elementos distintos.

### Complejidad espacial

- **O(1) - Espacio constante**: El uso de memoria está limitado por una constante independiente del tamaño de la entrada.

- **O(n) - Espacio lineal**: El uso de memoria crece como máximo linealmente con el tamaño de la entrada. Cuando el límite es ajustado, el uso de memoria crece proporcionalmente al tamaño de la entrada.

- **O(n²) - Espacio cuadrático**: El uso de memoria crece como máximo cuadráticamente con el tamaño de la entrada. Cuando el límite es ajustado, el uso de memoria crece proporcionalmente al cuadrado del tamaño de la entrada.

- **O(2ⁿ) - Espacio exponencial**: Un límite superior exponencial en el uso de memoria. Cuando el límite es ajustado, el uso de memoria crece proporcionalmente a 2ⁿ.

- **O(n!) - Espacio factorial**: Un límite superior factorial en el uso de memoria. Cuando el límite es ajustado, el uso de memoria crece proporcionalmente a n!.

## Técnicas para resolver problemas

- **Entender el problema**: Lee la declaración del problema varias veces. Identifica la entrada, la salida esperada y cómo transformar la entrada en salida.

- **Selección de algoritmo y estructura de datos**: Compara algoritmos alternativos según sus requerimientos de tiempo y espacio, y elige estructuras de datos adecuadas para el problema.

- **Pseudocódigo**: Descripción de alto nivel de la lógica del algoritmo que es independiente del lenguaje, usando lenguaje común mezclado con estructuras de programación como `IF`, `ELSE`, `FOR` y `WHILE`.

```md
GET original_string
SET reversed_string = ""

FOR EACH character IN original_string:
    ADD character TO THE BEGINNING OF reversed_string

DISPLAY reversed_string
```

- **Implementación**: Escribe código limpio, legible y modular basado en tu plan de pseudocódigo. Usa herramientas integradas apropiadas para tareas comunes.

- **Casos límite**: Entradas específicas y válidas que ocurren en los límites de lo que un algoritmo debe manejar. Siempre considera y prueba casos límite.

- **Pruebas y refinamiento**: Prueba tu código con los ejemplos y casos límite proporcionados. Depura errores, verifica los resultados y mejora la solución para aumentar claridad o eficiencia.

## Arreglos

- **Arreglos estáticos**: Tienen un tamaño fijo establecido al crearse, con elementos almacenados en memoria contigua. Esta disposición adyacente permite acceso indexado rápido en tiempo constante (O(1)). Elige un arreglo estático cuando el número máximo de elementos se conoce estrictamente de antemano.

- **Arreglos dinámicos**: Pueden crecer o reducirse automáticamente durante la ejecución del programa. Cuando se quedan sin espacio, manejan el redimensionamiento internamente asignando un bloque de memoria más grande y copiando los elementos existentes.

**Nota:** Python no tiene un arreglo estático integrado tradicional. Las listas de Python son arreglos dinámicos.

### Listas en Python (arreglos dinámicos)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### Complejidades de tiempo para arreglos dinámicos

- **Acceso**: O(1)

- **Insertar al final**: O(1) en promedio, O(n) cuando se requiere redimensionar

- **Insertar en medio**: O(n)

- **Eliminar**: O(n) para medio, O(1) para final

## Pilas

- **Pilas**: Estructura de datos LIFO (último en entrar, primero en salir). Los elementos se agregan y eliminan solo desde la cima.

- **Operación push**: Agregar un elemento al tope de la pila. Para la implementación con listas de Python abajo, un push ordinario toma tiempo O(1) y espacio adicional O(1). Un push que requiere redimensionar puede tomar tiempo O(n) y espacio adicional O(n).

- **Operación pop**: Remover un elemento del tope de la pila. La complejidad temporal es típicamente O(1) y el espacio adicional requerido suele ser O(1).

```python
# Using Python list as stack
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operations
top_element = stack.pop()  # Returns 3
```

## Colas

- **Colas**: Estructura de datos FIFO (primero en entrar, primero en salir) donde los elementos se agregan al final y se eliminan del frente.

- **Operación enqueue**: Agregar un elemento al final de la cola. Complejidad temporal: O(1), complejidad espacial: O(1).

- **Operación dequeue**: Remover un elemento del frente de la cola. Complejidad temporal: O(1), complejidad espacial: O(1).

## Listas enlazadas

- **Listas enlazadas**: Estructura de datos lineal donde cada nodo contiene datos y una referencia al siguiente nodo. Los nodos están conectados como una cadena.

### Listas enlazadas simples

- **Estructura**: Cada nodo tiene datos y una referencia al siguiente nodo.

- **Recorrido**: Solo puede avanzar desde la cabeza hasta la cola.

- **Nodo cabeza**: Primer nodo en la lista, usualmente el único nodo accesible directamente.

- **Nodo cola**: Último nodo en la lista, apunta a `None`.

### Implementación de lista enlazada

- **Clase nodo**: Una clase `Node` anidada representa nodos individuales. Cada nodo contiene datos y una referencia al siguiente nodo.

- **Inicialización**: La referencia `head` comienza como `None` porque la lista no tiene nodos. La referencia `next` de cada nuevo nodo comienza como `None` porque aún no tiene sucesor.

- **Seguimiento de longitud**: Una variable de longitud mantiene el conteo de nodos en la lista.

- **`is_empty()`**: Verifica si la lista está vacía comprobando si `head` es `None`.

- **Agregar al final**: Recorre desde la cabeza hasta llegar al último nodo, luego actualiza su referencia `next` para apuntar al nuevo nodo. Si la lista está vacía, el nuevo nodo se convierte en la cabeza.

```python
class LinkedList:
    class Node:
        def __init__(self, data):
            self.data = data
            self.next = None

    def __init__(self):
        self.head = None
        self.length = 0

    def is_empty(self):
        return self.head is None

    def append(self, data):
        new_node = self.Node(data)

        if self.is_empty():
            self.head = new_node
        else:
            current = self.head

            while current.next:
                current = current.next

            current.next = new_node

        self.length += 1
```

### Operaciones y complejidades de tiempo

- **Insertar al inicio**: O(1)

- **Insertar al final**: O(n) - se debe recorrer hasta el final

- **Insertar en medio**: O(n) - se debe recorrer hasta la posición

- **Eliminar desde el inicio**: O(1)

- **Eliminar desde el final**: O(n) - se debe recorrer para encontrar el nodo anterior

- **Eliminar desde el medio**: O(n) - se debe recorrer para encontrar el nodo

### Inserción y eliminación

- **Inserción al inicio**: Crea un nuevo nodo, establece su referencia `next` al nodo cabeza actual y actualiza la cabeza para que apunte al nuevo nodo.

- **Inserción al final**: Recorre hasta el último nodo y actualiza su referencia `next` para apuntar al nuevo nodo.

- **Inserción en medio**: Recorre hasta el nodo antes de la posición deseada. Actualiza la referencia `next` del nuevo nodo para apuntar al siguiente nodo, luego actualiza la referencia `next` del nodo anterior para apuntar al nuevo nodo.

- **Eliminación desde el inicio**: Actualiza la cabeza para que apunte al segundo nodo.

- **Eliminación desde el final**: Recorre hasta el penúltimo nodo y actualiza su referencia `next` a `None`.

- **Eliminación desde el medio**: Encuentra el nodo antes del nodo objetivo y actualiza su referencia `next` para saltar el nodo objetivo.

- **Eliminar por valor**: Mantén seguimiento del nodo anterior mientras recorres. Si el objetivo es la cabeza, actualiza la cabeza directamente. Si no se encuentra el valor, retorna sin modificar la lista ni su longitud. Decrementa la longitud solo después de una eliminación exitosa.

### Complejidades de espacio auxiliar

- **Inserción al inicio**: Espacio auxiliar O(1), excluyendo el almacenamiento requerido para el nuevo nodo.

- **Inserción al final**: Espacio auxiliar O(1), excluyendo el almacenamiento requerido para el nuevo nodo.

- **Inserción en medio**: Espacio auxiliar O(1), excluyendo el almacenamiento requerido para el nuevo nodo.

- **Eliminación desde el inicio**: Espacio auxiliar O(1).

- **Eliminación desde el final**: Espacio auxiliar O(1).

- **Eliminación desde el medio**: Espacio auxiliar O(1).

### Listas doblemente enlazadas

- **Estructura**: Cada nodo tiene datos y dos referencias: al siguiente nodo y al nodo anterior.

- **Recorrido**: Puede moverse en ambas direcciones.

- **Memoria**: Requiere más memoria que las listas enlazadas simples debido a la referencia extra.

- **Referencia a la cola**: Mantener una referencia al último nodo permite recorrer hacia atrás usando las referencias anteriores.

## Mapas hash y conjuntos

### Mapas y mapas hash

- **Tipo abstracto de datos (ADT) vs. implementación**: Un ADT define la *interfaz*—especificando qué operaciones soporta una estructura de datos y cómo se comporta lógicamente. Una implementación concreta define el mecanismo interno, mostrando *cómo* se construyen y ejecutan esas operaciones en memoria.

- **Mapa (ADT)**: Un tipo abstracto de datos que define una colección de claves únicas mapeadas a valores. Establece las reglas de lo que un mapa puede hacer sin dictar su almacenamiento interno.

- **Mapa hash**: Una implementación concreta del ADT Mapa que usa una función hash para calcular ubicaciones de almacenamiento en un arreglo subyacente para búsquedas rápidas.

### Diccionarios en Python (mapas hash)

```python
# Creating dictionaries
my_dictionary = {
    "A": 1,
    "B": 2,
    "C": 3
}

# Alternative creation
my_dictionary = dict(A=1, B=2, C=3)

# Access and modify
value = my_dictionary["A"]  # 1
my_dictionary["A"] = 4      # Update value
del my_dictionary["A"]      # Remove key-value pair

# Check membership
"C" in my_dictionary

# Get keys, values, items
my_dictionary.keys()
my_dictionary.values()
my_dictionary.items()
```

### Complejidades de tiempo para mapas hash

- **Caso promedio**: O(1) para insertar, obtener, eliminar

- **Peor caso**: O(n) cuando ocurren muchas colisiones hash

### Complejidades de espacio auxiliar para mapas hash

- **Inserción**: Espacio adicional O(1) para inserción ordinaria. El redimensionamiento puede requerir espacio adicional O(n).

- **Búsqueda**: Espacio auxiliar O(1).

- **Eliminación**: Espacio auxiliar O(1).

### Conjuntos

- **Conjuntos**: Colecciones no ordenadas de elementos únicos. No permiten duplicados ni mantienen un orden específico.

- **Elementos de conjuntos**: Los conjuntos pueden contener números, cadenas y tuplas que contienen solo números y cadenas. Las listas, diccionarios y otros conjuntos no pueden ser elementos de un conjunto. Una tupla que contiene una lista no puede ser elemento de un conjunto, aunque la tupla sea inmutable.

```python
# Creating sets
numbers = {1, 2, 3, 4}
empty_set = set()  # Must use set(), not {}

# Add and remove elements
numbers.add(5)
numbers.remove(4)      # Raises KeyError if not found
numbers.discard(4)     # No error if not found

# Remove and return an arbitrary element
numbers.pop()

# Remove all elements
numbers.clear()

# Get the number of elements
len(numbers)
```

### Operaciones con conjuntos

```python
set_a = {1, 2, 3, 4}
set_b = {2, 3, 4, 5, 6}

# Union, intersection, difference, symmetric difference
set_a.union(set_b)                  # or set_a | set_b
set_a.intersection(set_b)           # or set_a & set_b
set_a.difference(set_b)             # or set_a - set_b
set_a.symmetric_difference(set_b)   # or set_a ^ set_b

# Subset and superset checks
set_a.issubset(set_b)
set_a.issuperset(set_b)
set_a.isdisjoint(set_b)

# Membership testing
5 in numbers
```

### Complejidades de tiempo para conjuntos

- **Caso promedio**: O(1) para agregar, eliminar, probar membresía

- **Peor caso**: O(n) debido a colisiones hash

- **Consulta de longitud**: O(1) usando `len()`.

### Complejidades de espacio auxiliar para conjuntos

- **Inserción**: Espacio adicional O(1) para inserción ordinaria. El redimensionamiento puede requerir espacio adicional O(n).

- **Búsqueda**: Espacio auxiliar O(1).

- **Eliminación**: Espacio auxiliar O(1).

- **Consulta de longitud**: Espacio auxiliar O(1).

## Colisiones de hash

- **Colisión hash**: Diferentes claves pueden producir el mismo valor hash. En una tabla hash, las colisiones también ocurren cuando diferentes valores hash mapean al mismo índice del arreglo. Las entradas que comparten un índice deben manejarse con una estrategia de resolución de colisiones.

- **Estrategias de resolución de colisiones**:

  - **Encadenamiento**: Cada índice del arreglo apunta a una lista enlazada que almacena todas las entradas que mapean a ese mismo índice de cubeta.

  - **Dirección abierta**: Busca el siguiente índice disponible en el arreglo usando una secuencia predefinida cuando ocurre una colisión.

## Cuándo usar cada estructura de datos

- **Listas**: Cuando necesitas acceso ordenado e indexado y no conoces el tamaño de antemano.

- **Pilas**: Para operaciones LIFO (funcionalidad de deshacer, evaluación de expresiones, backtracking).

- **Colas**: Para operaciones FIFO (planificación de tareas, búsqueda en anchura).

- **Listas enlazadas**: Cuando hay inserciones/eliminaciones frecuentes al inicio, tamaño desconocido, no se necesita acceso aleatorio.

- **Mapas hash**: Para búsquedas rápidas clave-valor, conteo de ocurrencias, caché.

- **Conjuntos**: Para verificar unicidad, operaciones matemáticas de conjuntos, eliminar duplicados.
