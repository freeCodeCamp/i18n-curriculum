# --description--

أنشئ الآن متغيرًا باسم `extra_charges` وعيّنه إلى القيمة `0`. هذا سيمثل الرسوم الإضافية التي تُطبّق على تذكرة الفيلم للعروض المسائية.

معامل المساواة (`==`) يتحقق مما إذا كانت قيمتان متساويتين ويُقيّم إلى `True` أو `False`. وهو يختلف عن معامل التعيين (`=`) الذي يخزن قيمة في متغير:

```py
color = 'red' # Assigns 'red' to color
print(color == 'red') # True
print(color == 'blue') # False
```

بعد ذلك، أنشئ جملة `if` للتحقق مما إذا كانت قيمة `show_time` تساوي السلسلة النصية `Evening`. داخل جسم جملة `if`، حدّث قيمة `extra_charges` إلى `2` واطبع في الطرفية الرسالة `Extra charges will be applied`.
