# --description--

添加一个名为 `is_empty` 的方法，该方法返回 `self.length == 0`。

你将使用这个方法来查看列表是否为空。当 `self.length` 为 `0` 时，它返回 `True`，表示列表没有节点。

如果 `self.length` 大于 `0`，它返回 `False`，表示该列表至少有一个节点。
