## ما هو Python؟

- **Python**: Python هي لغة برمجة عامة تُعرف ببساطتها وسهولة استخدامها.
- **حالات الاستخدام الشائعة**: تُستخدم Python في علم البيانات، تعلم الآلة، تطوير الويب، الأمن السيبراني، الأنظمة المدمجة وإنترنت الأشياء، البرمجة النصية، الأتمتة، وأجهزة الحوسبة الصغيرة مثل Raspberry Pi واللوحات المتوافقة مع MicroPython.

## المتغيرات

- **إعلان المتغيرات**: لإعلان متغير، تبدأ باسم المتغير متبوعًا بمعامل التعيين (`=`) ثم القيمة. يمكن أن تكون القيمة رقمًا، سلسلة نصية، قيمة منطقية، إلخ. إليك بعض الأمثلة:

```py
name = 'John Doe'
age = 25
```

- **اصطلاحات تسمية المتغيرات**: إليك الاصطلاحات التي يجب استخدامها لتسمية المتغيرات:

  - يمكن لأسماء المتغيرات أن تبدأ بحرف أو بشرطة سفلية (`_`) فقط، وليس برقم.
  - يمكن لأسماء المتغيرات أن تحتوي على أحرف (`a-z`، `A-Z`)، أرقام (`0-9`)، وشرطات سفلية (`_`).
  - أسماء المتغيرات حساسة لحالة الأحرف: `age`، `Age`، و`AGE` تُعتبر أسماء مختلفة.
  - لا يمكن أن تكون أسماء المتغيرات من الكلمات المفتاحية المحجوزة في Python مثل `if`، `class`، أو `def`.
  - تستخدم أسماء المتغيرات متعددة الكلمات الشرطات السفلية، كما في `snake_case`.
  - يجب أن تصف أسماء المتغيرات غرضها، كما في `user_age`.
  - يُفضل تجنب أسماء المتغيرات ذات الحرف الواحد إذا لم تكن توصل معنى.

## التعليقات

- **التعليقات ذات السطر الواحد**: يُستخدم هذا النوع من التعليقات للملاحظات القصيرة في الكود الخاص بك.

```py
# This is a single line comment
```

- **تعليقات متعددة الأسطر**: يمكنك استخدام `#` في بداية كل سطر لإنشاء تعليقات تمتد عبر عدة أسطر.

```py
# This is a multi-line comment.
# Here is some code commented out.
#
# name = 'John Doe'
# age = 25
```

## الطباعة

- **دالة `print()`**: لطباعة البيانات على الطرفية، يمكنك استخدام الدالة `print()` بهذه الطريقة:

```py
print('Hello world!') # Hello world!
```

يمكنك تمرير عدة معلمات إلى `print()` بفصلها بفواصل. افتراضيًا، تُدرج `print()` مسافة بين القيم المعروضة:

```py
print('Hello', 'world!') # Hello world!
```

## أنواع البيانات الشائعة في Python

- **الكتابة الديناميكية**: Python لغة ذات كتابة ديناميكية، مما يعني أنك لا تحتاج إلى إعلان نوع بيانات المتغير. Python تحدد النوع بناءً على القيمة المُعيَّنة للمتغير.

- **عدد صحيح**: رقم كامل بدون كسور عشرية:

```py
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- **عدد عشري (float)**: رقم يحتوي على كسور عشرية:

```py
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- **سلسلة نصية**: متتالية من الأحرف محاطة بعلامات اقتباس:

```py
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- **قيمة منطقية**: قيمة تمثل إما `True` أو `False`:

```py
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

لدى Python أنواع بيانات أخرى. ستتعلم كل نوع منها عند حاجتك إليه لأول مرة.

- **دالة `type()`**: لرؤية نوع المتغير، يمكنك استخدام الدالة `type()` بهذه الطريقة:

```py
greeting = 'Hello there!'
age = 21

print(type(greeting)) # <class 'str'>
print(type(age)) # <class 'int'>
```

- **دالة `isinstance()`**: تُستخدم للتحقق مما إذا كان المتغير يطابق نوع بيانات معين:

```py
greeting = 'Hello world'
name = 'John Doe'

print(isinstance(greeting, str)) # True
print(isinstance(name, int)) # False
```

للتحقق من أكثر من نوع واحد، ضع الأنواع داخل أقواس عادية مفصولة بفواصل، ومررها كالمعلمة الثانية. تكون النتيجة `True` إذا كانت القيمة من نوع أي من الأنواع المدرجة:

```py
account_balance = 12
print(isinstance(account_balance, (int, float))) # True
```

## العمل مع السلاسل النصية

- **سلاسل نصية**: السلاسل النصية هي متتاليات من الأحرف. في Python، يمكنك استخدام علامات اقتباس مفردة أو مزدوجة. اختر نمطًا واحدًا واستخدمه باستمرار:

```py
developer = 'Jessica'
city = "Los Angeles"
```

- **سلاسل نصية متعددة الأسطر**: تسمح علامات الاقتباس المفردة الثلاثية أو المزدوجة الثلاثية بأن تمتد السلسلة النصية عبر عدة أسطر:

```py
message = """Hello
world!"""
print(message)
# Hello
# world!
```

- **علامات الاقتباس داخل السلاسل النصية**: يمكنك استخدام نوع الاقتباس المعاكس حول السلسلة النصية لتجنب الهروب من علامات الاقتباس الخاصة بها:

```py
msg = "It's a sunny day"
quote = 'She said, "Hello!"'
```

- **الهروب في السلاسل النصية**: يمكنك استخدام الشرطة المائلة العكسية (`\`) إذا كانت السلسلة تحتوي على علامات اقتباس هكذا:

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **تخطى التسلسل**: الشرطة المائلة العكسية مع حرف آخر يمكن أن تمثل حرفًا خاصًا. على سبيل المثال، `\n` تمثل سطرًا جديدًا، `\t` تمثل تبويبًا، و`\\` تمثل شرطة مائلة عكسية واحدة:

```py
print('Hello\nworld')
# Hello
# world

print('Name:\tAlice')  # Name:   Alice
print('C:\\Users\\Alice')  # C:\Users\Alice
```

- **معامل `in`**: يُرجع قيمة منطقية تحدد ما إذا كان الحرف أو الأحرف موجودة في السلسلة النصية أم لا:

```py
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

- **الحصول على طول سلسلة نصية**: تُرجع الدالة `len()` عدد الأحرف في السلسلة النصية:

```py
developer = 'Jessica'

print(len(developer)) # 7
```

- **الوصول إلى الأحرف في السلاسل النصية**: يمكنك الوصول إلى الأحرف باستخدام ترميز الأقواس هكذا:

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **إعادة التعيين وعدم القابلية للتغيير**: السلاسل النصية غير قابلة للتغيير، مما يعني أنك لا تستطيع تعديلها بعد إنشائها. إعادة تعيين متغير تجعله يشير إلى قيمة مختلفة، لكنها لا تعدل السلسلة النصية الأصلية:

```py
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello
```

لا يُسمح بالتعديل المباشر للسلسلة النصية:

```py
greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```

الأعداد الصحيحة، الأعداد العشرية، والقيم المنطقية أيضًا لا تتغير.

- **ربط السلاسل النصية**: لربط السلاسل النصية، يمكنك استخدام معامل `+` هكذا:

```py
developer = 'Jessica'
print('My name is ' + developer + '.') # My name is Jessica.
```

- **تكرار السلاسل النصية**: يُكرر العامل `*` السلسلة النصية عددًا محددًا من المرات:

```py
print('ha' * 3) # hahaha
```

- **ربط السلاسل النصية بالأعداد**: ربط سلسلة نصية برقم يرفع خطأ `TypeError`:

```py
'Age: ' + 26 # TypeError: can only concatenate str (not "int") to str
```

تحول الدالة `str()` الرقم إلى سلسلة نصية ليتمكن من الربط:

```py
print('Age: ' + str(26)) # Age: 26
```

طريقة أخرى لربط السلاسل النصية هي باستخدام معامل `+=`. يُستخدم هذا لأداء الربط والتعيين في خطوة واحدة هكذا:

```py
greeting = 'My name is '
developer = 'Jessica.'

greeting += developer
print(greeting) # My name is Jessica.
```

عامل `*=` يكرر السلسلة النصية ويُعيّن النتيجة مرة أخرى للمتغير:

```py
sound = 'ha'
sound *= 3
print(sound) # hahaha
```

كلا العاملين `+=` و`*=` يعينان سلسلة نصية جديدة للمتغير دون تعديل السلسلة النصية الأصلية.

- **`f-strings`**: اختصار لـ formatted string literals. تتيح لك التعامل مع الاستيفاء وأيضًا إجراء بعض الربط بصيغة مختصرة وقابلة للقراءة:

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

يمكن أن تحتوي حقول الاستبدال في f-strings على تعبيرات. تُقيّم Python التعبير وتُدرج قيمته في السلسلة النصية:

```py
num1 = 5
num2 = 10
print(f'The sum is {num1 + num2}') # The sum is 15
```

- **تقطيع السلاسل النصية**: هو استخراج أجزاء من السلسلة النصية. الصيغة الأساسية هي:

```py
str[start:stop:step]
```

يشير فهرس `start` إلى مكان بدء الاستخراج. فهرس `stop` غير شامل، لذا لا يُضمّن الحرف عند هذا الفهرس. يحدد `step` الفاصل بين الفهارس المختارة ويأخذ القيمة الافتراضية `1`. مع `step` موجبة، إذا لم يُذكر `start` فيُعتبر بداية السلسلة النصية، وإذا لم يُذكر `stop` فيُعتبر نهاية السلسلة. التعبير `[:]` يستخرج السلسلة النصية كاملة. التعبير `[::-1]` يعكس السلسلة النصية بالتنقل عكسيًا من الحرف الأخير إلى الأول. التقطيع لا يغيّر السلسلة النصية الأصلية.

```py
message = 'Python is fun!'

print(message[0:6])  # Python
print(message[:6])  # Python
print(message[7:])  # is fun!
print(message[::2])  # Pto sfn
print(message[:])  # Python is fun!
print(message[::-1])  # !nuf si nohtyP
```

## طرق السلاسل النصية الشائعة

- **الطرق**: الطريقة هي دالة تستدعيها على قيمة. لاستدعاء طريقة سلسلة نصية، اكتب السلسلة أو اسم متغيرها متبوعًا بنقطة ثم استدعاء الطريقة.

- **`str.upper()`**: تُرجع سلسلة جديدة مع تحويل جميع الأحرف إلى أحرف كبيرة:

```py
developer = 'Jessica'

print(developer.upper()) # JESSICA
```

- **`str.lower()`**: تُرجع سلسلة جديدة مع تحويل جميع الأحرف إلى أحرف صغيرة:

```py
developer = 'Jessica'

print(developer.lower()) # jessica
```

- **`str.strip()`**: تُرجع نسخة من السلسلة مع إزالة الأحرف المحددة من البداية والنهاية (إذا لم تُمرر معلمة، تزيل الفراغات من البداية والنهاية).

```py
greeting = '  hello world  '

trimmed_my_str = greeting.strip()
print(trimmed_my_str)  # hello world
```

- **`replace()`**: تُرجع سلسلة جديدة مع استبدال كل تكرارات السلسلة القديمة بسلسلة جديدة.

```py
greeting = 'hello world'

replaced_my_str = greeting.replace('hello', 'hi')
print(replaced_my_str)  # hi world
```

- **`split()`**: تُستخدم لتقسيم سلسلة نصية إلى قائمة باستخدام فاصل محدد. الفاصل هو سلسلة نصية تحدد مكان التقسيم. إذا لم يُحدد فاصل، فإن `split()` تقسم عند الفراغات.

```py
dashed_name = 'example-dashed-name'

split_words = dashed_name.split('-')
print(split_words)  # ['example', 'dashed', 'name']
```

- **`join()`**: تُستخدم لدمج مجموعة من السلاسل النصية في سلسلة واحدة مع فاصل محدد.

```py
example_list = ['example', 'dashed', 'name']

joined_str = ' '.join(example_list)
print(joined_str)  # example dashed name
```

- **`str.startswith(prefix)`**: تُرجع قيمة منطقية تشير إلى ما إذا كانت السلسلة تبدأ بالبادئة المحددة:

```py
developer = 'Naomi'

result = developer.startswith('N')
print(result)  # True
```

- **`str.endswith(suffix)`**: تُرجع قيمة منطقية تشير إلى ما إذا كانت السلسلة تنتهي باللاحقة المحددة:

```py
developer = 'Naomi'

result = developer.endswith('N')
print(result)  # False
```

- **`str.find()`**: تُرجع فهرس أول ظهور لسلسلة فرعية. إذا لم تُعثر على السلسلة الفرعية، تُرجع `-1`:

```py
developer = 'Naomi'

result = developer.find('N')
print(result)  # 0

city = 'Los Angeles'
print(city.find('New')) # -1
```

- **`str.count(substring)`**: يحسب هذا عدد المرات التي تظهر فيها سلسلة فرعية في سلسلة نصية دون تداخل. بمجرد العثور على تطابق، يستمر البحث بعد نهاية ذلك التطابق:

```py
city = 'Los Angeles'
print(city.count('e')) # 2

# Matches do not overlap, so this is 2, not 3
print('aaaa'.count('aa')) # 2
```

- **`str.capitalize()`**: تُرجع سلسلة جديدة مع تحويل الحرف الأول إلى كبير وباقي الأحرف إلى صغيرة:

```py
dessert = 'chocolate cake'
print(dessert.capitalize()) # Chocolate cake
```

- **`str.isupper()`**: تُرجع `True` إذا احتوت السلسلة النصية على حرف واحد على الأقل بحالة كتابة وكانت كل الأحرف المكتوبة كبيرة. وإلا، تُرجع `False`:

```py
dessert = 'chocolate cake'
print(dessert.isupper()) # False
```

- **`str.islower()`**: تُرجع `True` إذا احتوت السلسلة النصية على حرف واحد على الأقل بحالة كتابة وكانت كل الأحرف المكتوبة صغيرة. وإلا، تُرجع `False`:

```py
dessert = 'chocolate cake'
print(dessert.islower()) # True
```

- **`str.title()`**: تُرجع سلسلة نصية جديدة مع جعل الحرف الأول من كل كلمة كبيرًا وباقي الأحرف صغيرة:

```py
city = 'lOS aNGELES'
print(city.title()) # Los Angeles
```

## المزيد من عمليات السلاسل النصية

- **حدود القطع السلبية**: يمكن لحدود القطع أن تعد من نهاية السلسلة النصية إلى بدايتها. على سبيل المثال، `[-3:]` يستخرج آخر ثلاثة أحرف:

```py
employee_code = 'DEV-2026-JD-001'
print(employee_code[-3:]) # 001
```

- **تسلسل الطرق**: يمكنك استدعاء عدة طرق على السلسلة النصية في تعبير واحد. كل طريقة تعمل على نتيجة الاستدعاء السابق:

```py
name = '  jANE dOE  '
print(name.strip().title()) # Jane Doe
```

## العمليات الشائعة المستخدمة مع الأعداد الصحيحة والأعداد العشرية

- **العمليات الحسابية الأساسية**: في Python، يمكنك إجراء العمليات الحسابية الأساسية مع الأعداد الصحيحة والأعداد العشرية مثل الجمع والطرح والضرب والقسمة:

```py
int_1 = 56
int_2 = 12
float_1 = 5.4
float_2 = 12.0

# Addition

print('Integer Addition:', int_1 + int_2) # Integer Addition: 68
print('Float Addition:', float_1 + float_2) # Float Addition: 17.4

# Subtraction

print('Int Subtraction:', int_1 - int_2) # Int Subtraction: 44
print('Float Subtraction:',  float_2 - float_1) # Float Subtraction: 6.6

# Multiplication

print('Int Multiplication:', int_1 * int_2) # Int Multiplication: 672
print('Float Multiplication:', float_2 * float_1) # Float Multiplication: 64.80000000000001

# Division

print('Division:', int_1 / int_2) # Division: 4.666666666666667
print('Float Division:', float_2 / float_1) # Float Division: 2.222222222222222
```

عند جمع عدد عشري وعدد صحيح، تتحول النتيجة إلى عدد عشري هكذا:

```py
int_1 = 56
float_1 = 5.4

print(int_1 + float_1) # 61.4
```

- **معامل باقي القسمة (`%`)**: يُرجع الباقي عند قسمة رقم على رقم آخر:

```py
int_1 = 56
int_2 = 12

print(int_1 % int_2) # 8
```

- **القسمة الأرضية (`//`)**: يُستخدم لقسمة رقمين وتقريب النتيجة إلى أقرب عدد صحيح أقل أو يساوي الناتج:

```py
int_1 = 56
int_2 = 12

print(int_1 // int_2) # 4
```

- **معامل الأس (`**`)**: يُستخدم لرفع رقم إلى قوة رقم آخر:

```py
int_1 = 4
int_2 = 2

print(int_1 ** int_2) # 16
```

- **تقريب الأعداد العشرية العائمة**: بعض الكسور العشرية لا يمكن تمثيلها بدقة في النظام الثنائي، لذا تُخزن كتقريبات محدودة. هذا قد يسبب أخطاء تقريب صغيرة، مثل نتيجة الضرب `64.80000000000001` أعلاه.

```py
print(0.1 + 0.2) # 0.30000000000000004
```

- **دالة `float()`**: يمكنك استخدام هذه الدالة لتحويل عدد صحيح أو سلسلة عشرية صالحة إلى عدد عشري عائم، أو لإنشاء قيمة عائمة خاصة تمثل اللانهاية الموجبة، وهي أكبر من أي عدد صحيح أو عشري عائم محدود:

```py
num = 4

print(float(num)) # 4.0
print(float('7.8')) # 7.8
print(float('inf')) # inf
```

- **دالة `int()`**: يمكنك استخدام هذه الدالة لتحويل عدد عشري إلى عدد صحيح.

```py
num = 4.0

print(int(num)) # 4
```

- **دالة `round()`**: مع معلمة واحدة، تقرب الرقم إلى أقرب عدد صحيح. مرر معلمة ثانية لتحديد عدد المنازل العشرية:

```py
num_1 = 3.4
num_2 = 7.7

print(round(num_1)) # 3
print(round(num_2)) # 8
print(round(3.14159, 2)) # 3.14
```

- **دالة `abs()`**: تُستخدم لإرجاع القيمة المطلقة لرقم:

```py
num = -13

print(abs(num)) # 13
```

- **دالة `pow()`**: ترفع رقمًا إلى قوة رقم آخر. مع المعاملات الصحيحة، يمكنك تمرير معلمة ثالثة غير صفرية لحساب النتيجة حسب باقي القسمة على تلك القيمة:

```py
result = pow(2, 3)
print(result)  # 8
print(pow(2, 3, 5)) # 3
```

## العمل مع عبارات `if` و `elif` و `else`

- **كتل الكود والمسافة البادئة**: تستخدم Python المسافة البادئة لتجميع العبارات في كتلة، مثل جسم دالة أو شرط. يجب أن تستخدم العبارات في نفس الكتلة نفس مستوى المسافة البادئة. الاصطلاح هو استخدام أربع مسافات لكل مستوى.

- **عبارة `pass`**: `pass` لا تفعل شيئًا. استخدمها كعنصر نائب حيث تتطلب Python وجود عبارة، مثل جسم شرط فارغ:

```py
age = 18
if age >= 18:
    pass
```

- **عبارات `if`**: تنفذ عبارة `if` جسمها عندما تعتبر Python شرطها صحيحًا.

```py
age = 18

if age >= 18:
    print('You are an adult') # You are an adult
```

- **بند `else`**: ينفذ بند `else` جسمه عندما تعتبر Python أن جميع الشروط السابقة في نفس سلسلة `if...elif...else` خاطئة.

```py
age = 12

if age >= 18:
    print('You are an adult')
else:
    print('You are not an adult yet') # You are not an adult yet
```

- **بند `elif`**: يختبر بند `elif` شرطًا آخر عندما تعتبر Python أن جميع الشروط السابقة في نفس السلسلة خاطئة. ينفذ جسمه إذا اعتبرت Python شرطه صحيحًا.

```py
age = 16

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')  # You are a teenager
```

يمكنك أيضًا استخدام جمل `if` متداخلة بهذا الشكل:

```py
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

## القيم الصحيحة والخاطئة (Truthy and Falsy)

- **القيمة المنطقية**: في Python، لكل قيمة قيمة منطقية ضمنية، أو إحساس مدمج بما إذا كان يجب معاملتها كـ `True` أو `False` في سياق منطقي. العديد من القيم تُعتبر صحيحة، أي تُقيّم إلى `True` في السياق المنطقي. وأخرى تُعتبر خاطئة، أي تُقيّم إلى `False`. إليك بعض الأمثلة على القيم الخاطئة:

```md
False
None
Integer 0
Float 0.0
Empty strings ''
```

القيم الأخرى مثل الأعداد غير الصفرية والسلاسل النصية غير الفارغة تُعتبر صحيحة (truthy).

## العمل مع الدالة `bool()`

- **دالة `bool()`**: إذا أردت التحقق مما إذا كانت القيمة صحيحة أو خاطئة، يمكنك استخدام الدالة المدمجة `bool()`. تحوّل القيمة صراحةً إلى مكافئها المنطقي وتُرجع `True` للقيم الصحيحة و`False` للقيم الخاطئة. إليك بعض الأمثلة:

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

## العوامل المنطقية والاختصار في التقييم

- **العوامل المنطقية**: هذه عوامل خاصة تسمح لك بدمج عدة تعبيرات لإنشاء منطق اتخاذ قرار أكثر تعقيدًا في كودك. هناك ثلاثة عوامل منطقية في Python: `and`، `or`، و`not`.
- **عامل `and`**: يأخذ هذا العامل معاملين ويُرجع المعامل الأول إذا كان خاطئًا؛ وإلا يُرجع المعامل الثاني. يجب أن يكون كلا المعاملين صحيحين لكي تكون نتيجة التعبير صحيحة.

```py
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

يمكنك أيضًا استخدام عامل `and` في الشروط بهذا الشكل:

```py
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

- **عامل `or`**: يُرجع هذا العامل المعامل الأول إذا كان قيمة صحيحة؛ وإلا يُرجع المعامل الثاني. ينتج عن تعبير `or` قيمة صحيحة إذا كان أحد المعاملين على الأقل قيمة صحيحة. إليك مثالًا:

```py
age = 19
is_employed = False

print(age or is_employed) # 19
```

تمامًا كما في عامل `and`، يمكنك استخدام عامل `or` في الشروط بهذا الشكل:

```py
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

- **القطع المبكر**: يُعرف عاملَي `and` و`or` بعوامل القطع المبكر. القطع المبكر يعني أن Python يتحقق من القيم من اليسار إلى اليمين ويتوقف بمجرد تحديد النتيجة النهائية.
- **عامل `not`**: يأخذ عاملًا واحدًا ويعكس قيمته المنطقية. يحول القيم الصحيحة إلى `False` والقيم الخاطئة إلى `True`. على عكس العوامل السابقة، `not` دائمًا يُرجع `True` أو `False`. إليك بعض الأمثلة:

```py
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

إليك مثالًا على استخدام عامل `not` في شرط:

```py
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

## عوامل الهوية

- **الهوية والمساواة**: المتغيرات تشير إلى كائنات. عامل `is` يتحقق مما إذا كان المعاملان يشيران إلى نفس الكائن، بينما `is not` يتحقق مما إذا كانا يشيران إلى كائنين مختلفين. أما العاملان `==` و`!=` فيقارنون القيم بدلاً من الهوية. استخدم عوامل المساواة عند مقارنة قيم الأعداد أو السلاسل النصية.
- **`None` و`NoneType`**: `None` تمثل غياب القيمة. هي القيمة الوحيدة لنوع البيانات `NoneType`.
- **الكائنات المفردة (Singletons)**: كل من `None` و`True` و`False` هي كائنات مفردة، بمعنى وجود كائن واحد فقط لكل منها. يمكنك التحقق من هذه الكائنات باستخدام عوامل الهوية.
- **التحقق من `None`**: استخدم `is None` للتحقق من قيمة مفقودة و`is not None` للتحقق من وجود قيمة. كل من `None` و`False` تُعتبران خاطئتين، لكنهما كائنان مختلفان:

```py
response = False

print(response is None) # False
print(response is not None) # True
print(response is True) # False
print(response is False) # True
```

- **الهوية والقيمة المنطقية**: إذا كان `response` يمكن أن يكون `True` أو `False` أو `None`، فإن `response is None` يميز بين إجابة مفقودة وإجابة سلبية. استخدام `not response` يعامل كل من `False` و`None` بنفس الطريقة. للعلامات المنطقية العادية، استخدم `if is_ready` أو `if not is_ready`. استخدم `is True` أو `is False` عندما تحتاج تحديدًا إلى التمييز بين كائن منطقي وقيم أخرى محتملة.

## أسبقية العوامل المنطقية

- **أسبقية العوامل والأقواس العادية**: عندما يظهر `and` و `or` في نفس التعبير، يكون لـ `and` أسبقية أعلى من `or`. هذا يعني أن `and` يجمع معاملاته أولًا، لذا يُجمع التعبير `True or False and False` كالتالي: `True or (False and False)`:

```py
print(True or False and False) # True
```

المعامل الأيسر لـ `or` هو `True`، لذا يعني القصر أن `False and False` لا يُقيّم أبدًا، والنتيجة هي `True`.

يمكنك استخدام الأقواس العادية لتغيير التجميع. هنا، يُجمع `True or False` معًا ويُقيّم إلى `True`، ثم يُقيّم `True and False` إلى `False`:

```py
print((True or False) and False) # False
```

## العمل مع الدوال

- **الدوال**: الدوال هي قطع قابلة لإعادة الاستخدام من الكود تُنفذ عند استدعائها. لاستدعاء دالة، تحتاج إلى ذكر اسم الدالة متبوعًا بمجموعة من الأقواس:

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

- **المعلمات والمعاملات**: المعلمات هي الأسماء المدرجة في تعريف الدالة، مثل `num_1` و`num_2` أعلاه. المعاملات هي القيم التي تُمرر عند استدعاء الدالة، مثل `3` و`4`.

إذا استدعيت الدالة بدون العدد الصحيح من المعلمات، ستحصل على `TypeError`:

```py
def calculate_sum(a, b):
    print(a + b)

calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

- **المعاملات الموضعية**: هذه المعاملات تُطابق المعلمات حسب موقعها في استدعاء الدالة.

```py
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

- **المعاملات المسماة**: تستخدم هذه المعاملات `name=value` لمطابقة معلمة بالاسم. يمكن أن تظهر بترتيب مختلف عن المعلمات:

```py
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

- **دمج أنواع المعاملات**: يجب أن تأتي المعاملات الموضعية قبل المعاملات المسماة. يمكن لكل معلمة استقبال قيمة واحدة فقط:

```py
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

- **عبارة `return`**: تنهي عبارة `return` الدالة وتجعل قيمتها متاحة حيث تم استدعاء الدالة.

- **`None`**: تمثل `None` غياب القيمة. إذا لم تُرجع الدالة قيمة صراحةً، فإن قيمة الإرجاع الافتراضية هي `None`:

```py
def greet():
    print('hello')

result = greet() # hello
print(result) # None
```

## النطاق في Python

لدى Python قواعد نطاق إضافية. ركز الآن على النطاق المحلي والعام.

- **النطاق العام**: المتغير الذي يُنشأ خارج الدالة يمكن استخدامه داخل الدوال وخارجها.

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + (subtotal * tax)
    return total

print(get_total(100))  # 170.0
```

- **النطاق المحلي**: المتغير الذي يُنشأ داخل دالة يمكن استخدامه فقط داخل تلك الدالة. معلمات الدالة هي أيضًا متغيرات محلية.

```py
def my_func():
    num = 10
    print(num)
```

- **تمرير المعاملات وإعادة تعيين المعلمات**: تمرر Python المعاملات عن طريق التعيين. المعلمة هي اسم محلي يشير مبدئيًا إلى الكائن الممرر؛ لا يتم نسخ الكائن تلقائيًا. إعادة تعيين المعلمة لا تعيد تعيين المتغير الممرر كمعامل:

```py
def double_number(number):
    number = number * 2
    print(number) # 20

original = 10
double_number(original)
print(original) # 10
```

## تطبيق الدوال والنطاق

- **أجسام الدوال الفارغة**: يمكنك استخدام `pass` كعنصر نائب في جسم الدالة. الدالة التي تحتوي فقط على `pass` تُرجع ضمنيًا `None`:

```py
def placeholder():
    pass

print(placeholder()) # None
```

- **تظليل الأسماء**: عندما يكون للمعلمة المحلية أو المتغير نفس اسم متغير عام، تستخدم الدالة الاسم المحلي. إعادة تعيين تلك المعلمة المحلية لا تغير المتغير العام:

```py
available_eggs = 5

def use_eggs(available_eggs, eggs_to_use):
    available_eggs -= eggs_to_use
    return available_eggs

print(use_eggs(available_eggs, 1)) # 4
print(available_eggs) # 5
```

- **الإرجاع المبكر**: تنهي عبارة `return` الدالة فورًا وتجعل قيمتها متاحة حيث تم استدعاؤها. هذا يسمح لك بالإرجاع مبكرًا عند تحقق شرط:

```py
def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        return available_eggs
    return available_eggs - eggs_to_use

print(use_eggs(2, 3)) # 2
print(use_eggs(2, 1)) # 1
```

- **استدعاء الدوال من دوال أخرى**: يمكن للدالة استدعاء دالة أخرى واستخدام أو إرجاع نتيجتها:

```py
def use_eggs(available_eggs, eggs_to_use):
    return available_eggs - eggs_to_use

def make_fried_egg(available_eggs):
    return use_eggs(available_eggs, 1)

print(make_fried_egg(3)) # 2
```

- **تعيين القيم المرجعة**: إرجاع قيمة جديدة لا يحدث تحديثًا تلقائيًا للمتغير الممرر كمعامل. لتحديثه، عيّن القيمة المرجعة مرة أخرى لذلك المتغير:

```py
available_eggs = use_eggs(available_eggs, 1)
print(available_eggs) # 4
```

## ترجمة السلاسل النصية

- **`str.maketrans()`**: الشكل ذو السلسلتين من `str.maketrans()` يأخذ سلسلتين متساويتين في الطول ويربط كل حرف في السلسلة الأولى بالحرف المقابل في الثانية. يخزن الجدول الأحرف كأعداد صحيحة يونيكود، وهي أرقام تحددها بشكل فريد. تطبق طريقة `translate()` الجدول على سلسلة نصية وتُرجع سلسلة جديدة. الأحرف غير المدرجة في الجدول تبقى دون تغيير.

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc!'.translate(trans_table)
print(result)  # 123123!
```

## التحقق من صحة المعاملات الصحيحة

- **القيم المنطقية والأعداد الصحيحة**: تعامل Python القيم المنطقية كنوع خاص من الأعداد الصحيحة، لذا `isinstance(True, int)` و`isinstance(False, int)` كلاهما يُرجع `True`. عند التحقق من صحة عدد صحيح يجب ألا يكون قيمة منطقية، استبعد القيم المنطقية صراحةً:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True

value = True
print(isinstance(value, int) and not isinstance(value, bool)) # False

value = 5
print(isinstance(value, int) and not isinstance(value, bool)) # True
```

## القيم الافتراضية للمعلمات

- **المعلمات الافتراضية**: يمكنك تزويد معلمة بقيمة افتراضية. إذا حذفت معاملها عند استدعاء الدالة، تستخدم Python تلك القيمة الافتراضية:

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```
