# --description--

让我们了解一下终端，以及它与命令行的区别。

命令行是一个基本的文本输入接口，允许用户输入“命令”，通常以一串字符的形式，并通过按 <kbd>Enter</kbd> 键提交或执行它们。你最常见的命令行接口通常是在终端中看到的。

终端是一个特殊的应用，提供命令行接口以执行超出基本读写操作的系统级命令。你也可能听说过“终端模拟器”，它们本质上是将基本终端接口封装起来以提供额外特色或功能性的应用。但对于大多数通用的用途，你也可以安全地将它们称为“终端”。

最后，我们还需要讨论“shell”。shell 是包装命令行并将你的输入解释为命令，返回输出的软件。

但是你如何访问你系统上的终端？

如果你使用的是现代版本的 Windows，可能会有两个不同的选项。Windows 开箱即用地提供了两个不同的 shell 应用：PowerShell 和命令提示符。

这两个 shell 都配有各自的终端应用（名称与各自的 shell 相同），所以你可以通过应用菜单启动 PowerShell 终端或命令提示符终端。

Windows 还提供了一个相对较新且现代化的终端模拟器，恰如其分地命名为 Windows Terminal。

你可以从 Windows Store 安装这个应用，然后像启动 PowerShell 或命令提示符终端一样启动它。Windows Terminal 的优势在于，它允许你从同一个应用访问 PowerShell 和命令提示符 shell，以及如果你配置了 Windows Subsystem for Linux，还可以访问相应的 Linux shell。

在 macOS 上，有一个恰如其分命名为“Terminal”的终端。你可以通过聚焦搜索或应用启动器访问它。也支持第三方终端模拟器，比如 iTerm 或 Ghostty。你可以从它们的主页安装这些应用。

在 Linux 上，默认终端（以及你如何启动它）高度依赖于你使用的发行版和桌面环境。第三方终端模拟器也有很好的支持。例如，你可以在 Arch Linux 中设置 kitty —— 并且你可以通过诸如 wofi 这样的应用管理器启动它。

Linux 可以说拥有最多样化的终端应用可供选择。大多数这些应用都可以通过你的发行版的包管理器安装。

“终端”、“shell”和“命令行”之间的区别有时看起来相当学究气。大多数情况下，这些术语可以互换使用。但了解它们各自的具体含义以及这些含义是什么非常重要。
