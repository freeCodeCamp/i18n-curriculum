# --description--

버블 정렬은 리스트를 반복해서 순회하며 인접한 요소들을 비교하고, 순서가 잘못된 경우 서로 교환하는 방식으로 작동합니다. 각 순회가 끝나면 가장 큰 정렬되지 않은 값이 리스트의 끝으로 "버블처럼 떠오릅니다". 교환이 한 번도 일어나지 않은 상태로 한 번의 전체 순회가 완료되면 알고리즘이 정지합니다.

버블 정렬은 평균 및 최악의 경우에 이차 시간 복잡도를 가지므로 실제로는 거의 사용되지 않습니다.

**목표:** 아래 사용자 스토리를 충족하고 모든 테스트를 통과하여 실습을 완료하세요.

**사용자 스토리:**

1. 항목 리스트를 나타내는 하나의 매개변수를 가진 `bubble_sort`라는 이름의 함수를 정의하세요.
1. `bubble_sort` 함수는 리스트를 제자리에서 가장 작은 값부터 가장 큰 값 순으로 정렬하고 반환해야 합니다.
1. `bubble_sort` 함수는 버블 정렬 알고리즘을 따라 인접한 요소들을 비교하며 왼쪽 요소가 오른쪽 요소보다 클 때만 교환해야 합니다.
1. `bubble_sort` 함수는 교환 없이 한 번의 순회가 완료되면 즉시 정지해야 합니다.
1. `bubble_sort` 함수는 내장된 `sort()` 메서드나 `sorted()` 함수를 사용하지 않아야 합니다.

**참고:** 코드에서 어떤 모듈도 가져오지 않아야 합니다.

    def __init__(self, *args, **kwargs):

    def __setitem__(self, key, value):
        self._record.append((key, value))
        super().__setitem__(key, value)

def expected_swaps(items):
    items = list(items)
    swaps = []
    swapped = True
    while swapped:
        swapped = False
        for j in range(len(items) - 1):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swaps.append({(j, items[j]), (j + 1, items[j + 1])})

```py
def bubble_sort(items):
    n = len(items)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swapped = True
        if not swapped:
            break
    return items
```
