# --description--

Assim como um `for` loop, um `while` loop pode ter uma cláusula `else`. O código na cláusula `else` é executado quando o loop termina normalmente, mas não quando o loop é interrompido por `break`.

Adicione uma cláusula `else` ao `while` loop externo. Dentro dela, imprima a string `All requests served`.

Há uma requisição de parada na lista, então a cláusula `else` não será executada por enquanto.

def run_elevator(requests, start_floor):
    current_floor = start_floor
    floors_traveled = 0

    while requests:
        target = requests.pop(0)

        if target == 'stop':
            print('Emergency stop!')
            break

        if target == current_floor:
            print(f'Already on floor {target}')
            continue

        while current_floor != target:
            if current_floor < target:
                current_floor += 1
            else:
                current_floor -= 1
            floors_traveled += 1

        print(f'Arrived at floor {current_floor}')
