# --description--

各ノードは最大で2つの子を持つことができます。

`__init__` メソッド内で、`left` 属性と `right` 属性を作成し、どちらも `None` に設定して、子を持たない新しいノードを表してください。

子を持たないノードは葉ノードと呼ばれます。
