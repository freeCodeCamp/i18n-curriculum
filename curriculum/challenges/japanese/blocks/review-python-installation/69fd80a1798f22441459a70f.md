## ローカル環境へのPythonのインストール

- **インストール**: WindowsやmacOSでPythonをインストールする最も簡単な方法は、公式Pythonウェブサイト（`https://www.python.org/`）からインストーラーをダウンロードすることです。Linuxでは、Ubuntu、Debian、Fedoraなどの主要なディストリビューションの多くにPythonがすでに含まれているため、まずインストール済みのバージョンを確認し、Python 3がない場合にのみディストリビューション固有のパッケージをインストールしてください。
- **macOSでのセットアップ**: `.pkg`インストーラーをダウンロードして開き、指示に従ってください。完了したら、`Install Certificates.command`ファイルをダブルクリックし、ターミナルの処理が完了するまで待ってセットアップを終了させます。
- **Windowsでのセットアップ**: `.msix`のPythonインストールマネージャーをダウンロードして実行します。その後、`python`、`py`、`pymanager`コマンドが利用可能になり、ランタイムがインストールされていない状態で`python`を実行すると自動的にインストールされます。また、`python3.14.exe`のようなコマンド用のエイリアスディレクトリを`PATH`に追加するオプションのプロンプトを受け入れることができます。
- **Linuxでのセットアップ**: ターミナルを開き、`python --version`または`python3 --version`を実行してください。どちらもPython 3のバージョンを報告しない場合は、`https://www.python.org/`でインストールパッケージを探すか、ディストリビューションに推奨されるPythonのインストール方法をオンラインで検索してください。

## インストールの確認

- **バージョンの確認**: ターミナルで`python --version`または`python3 --version`を実行してインストールを確認してください。
- **`python`と`python3`の違い**: 古いmacOSやLinuxシステムでは、`python`がPython 2を指す場合があります。`python --version`がPython 2のバージョンを報告したら、それ以降はコードで`python3`を使ってください。Python 2はサポート終了しており、新しい開発には使用しないでください。

## ターミナル

- **定義**: ターミナルは、コマンドを入力してコンピューターとやり取りするテキストベースのインターフェースです。各オペレーティングシステムにはデフォルトのターミナルアプリが付属しています。macOSではTerminalアプリを使い、WindowsではコマンドプロンプトやPowerShellを使えます。Linuxでは、GNOME TerminalやKonsoleなど、各デスクトップ環境に固有のデフォルトターミナルアプリがあります。

## コードエディターとIDE

- **IDE**: IDEは統合開発環境の略で、コードエディター、テストツール、ターミナルなどの機能を備えています。
- **Python向けの人気コードエディターとIDE**: VS Code、PyCharm、Spyderです。

## Pythonスクリプトの実行

- **エディターのセットアップ**: VS Codeでプロジェクトフォルダーを開き、`.py`ファイルを作成してください。拡張機能ビューから、または`code --install-extension ms-python.python`を実行してMicrosoftのPython拡張機能をインストールします（macOSでは事前に`code`コマンドを`PATH`に追加する必要があります）。この拡張機能はエディターにPythonサポートを追加しますが、Python自体はインストールしません。
- **インタープリターの選択**: コマンドパレットから`Python: Select Interpreter`を実行し、先にインストールしたPython 3のインタープリターを指定してください。
- **コードの実行**: VS Codeの右上にある再生ボタン（プレイアイコン）をクリックすると、現在のファイルがターミナルで実行されます。ターミナルから手動でスクリプトを実行することもできます。例えば、プロジェクトフォルダーが`python-projects`でスクリプトが`main.py`の場合、`python-projects`を含むフォルダーでターミナルを開き、プロジェクトフォルダーに移動してスクリプトを実行します：

```bash
cd python-projects
python main.py
```

システムでPython 3のバージョンを報告するコマンドが`python3`の場合は、代わりに`python3 main.py`を使ってください。

## Pythonインタラクティブシェルの使い方

- **シェルの起動**: ターミナルを開き、`python`または`python3`（Python 3のバージョンを報告した方）を実行してください。`>>>`プロンプトはPythonがコマンドを待っていることを示します。`"Hello, world!"`を出力してみましょう：

```python
print("Hello, world!")
```

- **読み取り、評価、出力、ループサイクル（REPL）**: インタープリターは入力を読み取り、評価し、結果を出力し、再び`>>>`プロンプトに戻って次のコマンドを入力できるようにします。
- **無効な入力**: `something random`のような有効なPythonでない入力をすると、`SyntaxError: invalid syntax`というメッセージが表示され、シェルはプロンプトに戻ります。
- **シェルの終了**: `exit()`と入力するか、macOSやLinuxでは<kbd>Ctrl</kbd> + <kbd>D</kbd>を押し、Windowsでは<kbd>Ctrl</kbd> + <kbd>Z</kbd>を押してから<kbd>Enter</kbd>を押してください。
- **使うタイミング**: インタラクティブシェルは小さな実験や素早い探索に最適です。複数ファイルにまたがる長いプログラムや作業には、コードエディターやIDEを使ってください。
