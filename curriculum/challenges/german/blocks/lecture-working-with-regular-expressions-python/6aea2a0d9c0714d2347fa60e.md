# --description--

Bisher haben Sie `re.search` verwendet, um ein Muster irgendwo in einem String zu suchen. Das `re`-Modul bietet viele weitere Funktionen, die mit Regex-Mustern arbeiten. In dieser Lektion lernen Sie einige der nützlichsten kennen.

## Die `match`-Funktion

Die `match`-Funktion funktioniert wie `search`, sucht das Muster aber nur am Anfang des Strings. Sie gibt ein Match-Objekt zurück, wenn der Anfang des Strings dem Muster entspricht, und `None` sonst:

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

Im zweiten Beispiel enthält der String Ziffern, daher würde `re.search` sie finden. Aber der String beginnt nicht mit Ziffern, deshalb gibt `re.match` `None` zurück.

## Die `fullmatch`-Funktion

Das Muster `r'\d+:\d+'` entspricht einer oder mehreren Ziffern, gefolgt von einem Doppelpunkt und wieder einer oder mehreren Ziffern. So sieht eine Uhrzeit wie `10:30` aus.

Stellen Sie sich vor, Sie möchten prüfen, ob eine Benutzereingabe eine Uhrzeit ist und sonst nichts. Wenn Sie `re.search` verwenden, gibt es ein Problem:

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

Dies gibt ein Match-Objekt zurück, obwohl `10:30pm` nicht dem erwarteten Format entspricht. Das liegt daran, dass `re.search` das Muster irgendwo im String sucht und zusätzliche Zeichen um den Treffer herum ignoriert. `re.match` hätte dasselbe Problem, weil `10:30pm` mit einer gültigen Uhrzeit beginnt.

Wenn Sie Daten validieren, möchten Sie normalerweise, dass der gesamte String dem Muster entspricht. Dafür können Sie die `fullmatch`-Funktion verwenden. Sie gibt nur dann ein Match-Objekt zurück, wenn das Muster den gesamten String abdeckt, und sonst `None`:

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## Die `findall`-Funktion

`search`, `match` und `fullmatch` liefern höchstens einen Treffer. Wenn Sie jeden Treffer in einem String finden möchten, können Sie die `findall`-Funktion verwenden. Sie gibt eine Liste von Strings mit allen gefundenen Treffern zurück:

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

Wenn keine Treffer vorhanden sind, gibt `findall` eine leere Liste zurück:

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## Die `sub`-Funktion

Die `sub`-Funktion ersetzt jeden Treffer eines Musters durch einen anderen String. Sie nimmt das Muster, den Ersatzstring und den zu durchsuchenden String und gibt einen neuen String zurück:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub` hat auch zwei optionale Parameter. Der erste ist `count`, der begrenzt, wie viele Treffer ersetzt werden:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

Der zweite ist `flags`. Wie die anderen Funktionen kann `sub` Flags wie `re.IGNORECASE` verwenden:

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

Geben Sie `count` und `flags` immer als Schlüsselwortargumente an. Wenn Sie `re.IGNORECASE` als viertes Positionsargument übergeben, behandelt Python es stattdessen als Wert für `count`.
