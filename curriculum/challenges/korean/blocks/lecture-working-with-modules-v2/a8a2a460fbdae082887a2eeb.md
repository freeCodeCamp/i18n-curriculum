# --description--

소프트웨어 개발에서 라이브러리는 개발자를 위한 도구 상자와 같습니다.

코드를 처음부터 전부 직접 구현하는 대신, 라이브러리는 함수, 클래스, 자료 구조 같은 미리 작성되고 재사용 가능한 코드를 제공하여 프로젝트에서 사용할 수 있게 합니다.

Python 표준 라이브러리는 Python에 포함된 모듈과 패키지 모음입니다. 서드파티 패키지는 별도로 개발되며 보통 사용하기 전에 설치해야 합니다. 표준 라이브러리는 다음과 같은 일반적인 프로그래밍 작업에 대한 해결책을 제공합니다:

* 운영 체제와 상호작용하기

* 파일 작업하기

* 네트워킹

* 날짜와 시간 다루기

* 수학 연산 수행하기

* 정규 표현식 사용하기

* 코드 테스트 및 디버깅

* 그리고 더 많은 기능들!

표준 라이브러리 모듈의 예로는 `math`, `random`, `re`(정규 표현식의 약자), 그리고 `datetime`이 있습니다.

`math` 모듈은 더 복잡한 수학 연산을 수행하는 데 유용한 함수들을 제공합니다.

`random` 모듈은 난수 생성에 도움을 줍니다.

`re` 모듈은 정규 표현식을 다루는 데 사용됩니다.

`datetime` 모듈은 Python에서 날짜와 시간을 다루는 데 유용합니다.

모듈은 함수와 상수뿐만 아니라 클래스를 제공할 수도 있습니다. 다음은 `datetime` 모듈의 클래스 예시입니다. 1959년 7월 15일을 나타내는 날짜 객체를 생성한 후, 그 `date` 객체를 변수에 할당하고 점 표기법을 사용해 일, 월, 연도를 각각 접근합니다:

```python
import datetime
birthday = datetime.date(1959, 7, 15)
print(birthday.day)    # 15
print(birthday.month)  # 7
print(birthday.year)   # 1959
```

특정 작업에 맞는 모듈을 찾으려면 [Python 표준 라이브러리 참조](https://docs.python.org/3/library/index.html)를 살펴보세요. 여기서는 모듈들이 주제별로 그룹화되어 있습니다. 각 모듈 문서는 제공하는 기능과 사용법을 설명합니다. 예를 들어, [`datetime` 문서](https://docs.python.org/3/library/datetime.html)는 날짜와 시간을 다루기 위한 클래스와 메서드를 설명합니다.

`help()` 함수를 사용해 모듈이나 함수의 문서를 출력할 수도 있습니다. 다만 `help()`는 현재 freeCodeCamp 편집기에서는 사용할 수 없습니다.

예를 들어, 이 코드는 `math` 모듈에 대한 정보를 출력합니다:

```py
import math
help(math)
```

출력 결과의 일부는 다음과 같습니다:

```md
Help on built-in module math:

NAME
    math

DESCRIPTION
    This module provides access to the mathematical functions
    defined by the C standard.

FUNCTIONS
    acos(x, /)
        Return the arc cosine (measured in radians) of x.

...
...
...
```

특정 함수에 대한 문서도 얻을 수 있습니다:

```py
import math
help(math.comb)
```

출력 결과는 다음과 같습니다:

```md
Help on built-in function comb in module math:

comb(n, k, /)
    Number of ways to choose k items from n items without repetition and without order.
    
    Evaluates to n! / (k! * (n - k)!) when k <= n and evaluates
    to zero when k > n.
    
    Also called the binomial coefficient because it is equivalent
    to the coefficient of k-th term in polynomial expansion of the
    expression (1 + x)**n.
    
    Raises TypeError if either of the arguments are not integers.
    Raises ValueError if either of the arguments are negative.
```

모듈이 제공하는 이름을 알아보려면 `dir()` 함수를 사용하세요. 이 함수는 숫자를 내림하는 `math.floor` 같은 함수와 오일러 수인 `math.e`, 원주율인 `math.pi` 같은 상수를 나열합니다. 또한 커리큘럼에서 나중에 배우게 될 다른 이름들도 나열합니다:

```py
import math
print(dir(math))
```
