# --description--

次に、リスト内包表記を使って各温度が平均からどれだけ離れているかを計算します。構文の復習はこちらです：

```py
numbers = [1, 2, 3]
doubled = [num * 2 for num in numbers]
print(doubled) # [2, 4, 6]
```

`differences` という名前の変数を作成してください。リスト内包表記を使って、`temperatures` の各 `temperature` に対して `temperature - average` を含むリストを代入してください。

その後、`temperatures` の代わりに `differences` を出力してください。
