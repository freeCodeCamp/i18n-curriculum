#### --text--

Який із наведених прикладів є рекурсією?

#### --distractors--

```py

    result = 1
    while n > 0:
        result *= n
        n -= 1
    return result
```

---

```py
def factorial(n):
    numbers = [number for number in range(1, n + 1)]
    result = 1
    for number in numbers:
        result *= number
    return result
```

---

```py
def factorial(n):
    result = 1
    for number in range(n, 0, -1):

```

#### --answer--

```py
def factorial(n):
    if n == 0 or n == 1:
        return 1
    return n * factorial(n - 1)
```
