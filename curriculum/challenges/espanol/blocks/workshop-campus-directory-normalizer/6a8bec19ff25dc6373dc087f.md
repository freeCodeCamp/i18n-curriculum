# --description--

No todos los departamentos tienen garantizado un `Dept_code`. Necesitas un respaldo para cuando falta, para que el departamento aún tenga un id usable.

El operador `||` devuelve su valor de la izquierda si ese valor es `truthy`, de lo contrario devuelve el valor de la derecha.

Por ejemplo: `a || b` evalúa a `a` cuando `a` es `truthy`, y usa como respaldo `b` cuando `a` es `falsy` (como `undefined`, `null` o `""`).

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

Actualiza la asignación de `departmentId` para usar el operador `||`. Usa `departmentData.Dept_code` como operando izquierdo y el literal de plantilla `` `dept-${i + 1}` `` como operando derecho. Esto usa el respaldo siempre que `departmentData.Dept_code` sea falsy, incluso cuando es `undefined`.
