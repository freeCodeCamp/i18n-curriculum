# --description--

이전 수업에서 트리에 대해 배웠습니다. 이진 트리는 각 노드가 최대 두 개의 자식을 가지는 트리로, 왼쪽 자식과 오른쪽 자식이라고 부릅니다.

이진 탐색 트리(BST)는 값을 정렬 상태로 유지하는 이진 트리입니다. 모든 노드에 대해 왼쪽 부분 트리의 모든 값은 노드의 값보다 작고, 오른쪽 부분 트리의 모든 값은 노드의 값보다 큽니다.

<img alt="a binary search tree" src="https://cdn.freecodecamp.org/curriculum/python/bst-example.png" style="background-color: white; height:500px; width:500px; padding: 10px; display: block; margin-right: auto; margin-left: auto; margin-bottom: 1.2rem;">

이 워크숍에서는 이진 탐색 트리를 만들고 이를 순회하는 방법을 배웁니다.

먼저 `TreeNode`라는 이름의 클래스를 만들어 트리의 단일 노드를 나타내세요. `self`와 `key` 두 매개변수를 가진 `__init__` 메서드를 만들고, `key`를 `self.key`에 할당하세요.
