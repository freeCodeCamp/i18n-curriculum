# --description--

Wigo unaamua wapi unaweza kutumia kigezo katika msimbo wako.

Python ina sheria za ziada za wigo. Kwa sasa, makini na wigo wa ndani na wa kimataifa.

Kigezo kilichotengenezwa nje ya kitendakazi kina wigo wa kimataifa. Unaweza kukitumia ndani na nje ya vitendakazi.

Kigezo kilichotengenezwa ndani ya kitendakazi kina wigo wa ndani. Unaweza kukitumia tu ndani ya kitendakazi hicho. Vigezo vya kitendakazi pia ni vigezo vya ndani.

Hapa kuna mfano wa wigo wa ndani na wa kimataifa:

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

Kigezo `tax_rate` ni cha kimataifa kwa sababu kimeundwa nje ya kitendakazi. Kitendakazi `calculate_tax` kinaweza kukisoma, na wito wa pili wa `print()` pia unaweza kukisoma.

Kigezo `price` na kigezo `tax` ni vya ndani kwa `calculate_tax`. Vinapatikana wakati kitendakazi hicho kinaendesha, lakini siyo nje yake. Wito wa mwisho wa `print()` husababisha `NameError` kwa sababu `tax` haijafafanuliwa katika wigo wa kimataifa.

Python hupitisha hoja kwa mgawo wa thamani. Unapofanya wito wa kitendakazi, kila kigezo hugeuka jina la ndani ambalo awali linahusiana na kitu kilichotolewa kama hoja yake. Python haiandikii nakala ya kitu hicho moja kwa moja.

Kuweka thamani mpya kwa kigezo hufanya jina hilo la ndani lihusiane na kitu tofauti. Hii haibadilishi variable uliyotuma kwa kitendakazi:

```python
def double_number(number):
    number = number * 2
    print(number) # 20

original = 10
double_number(original)
print(original) # 10
```

Wakati `double_number(original)` inapoitwa, `number` na `original` zote awali zinahusiana na nambari kamili `10`. Mgawo wa thamani `number = number * 2` hufanya kigezo cha ndani `number` kihusiane na `20`. Variable `original` bado inahusiana na `10`, kwa hivyo kuichapisha baada ya wito wa kitendakazi kunaonyesha thamani yake haijabadilika.
