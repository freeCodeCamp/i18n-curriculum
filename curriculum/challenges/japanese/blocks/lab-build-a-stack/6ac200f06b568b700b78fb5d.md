# --description--

このラボでは、関数を使ってスタックのデータ構造を実装します。スタックは後入れ先出し（LIFO）のデータ構造で、要素は上から追加および削除されます。

スタックは、`collection`キーに要素のリストを持つ辞書です。スタックのトップはリストの末尾なので、リストの最後の要素が最も最近追加されたものです。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

**ユーザーストーリー：**

1. `init_stack`関数を用意し、`collection`キーが空のリストに設定された辞書を返してください。
1. `push`関数を用意し、スタックと要素を受け取り、その要素をスタックのトップに追加してください。
1. `pop`関数を用意し、スタックを受け取り、トップの要素を削除して返すか、スタックが空の場合は`None`を返してください。
1. `peek`関数を用意し、スタックを受け取り、トップの要素を削除せずに返すか、スタックが空の場合は`None`を返してください。
1. `is_empty`関数を用意し、スタックを受け取り、要素がなければ`True`、そうでなければ`False`を返してください。
1. `clear`関数を用意し、スタックを受け取り、すべての要素を削除してください。

**注意:** ほとんどのテストは`init_stack`と`push`関数に依存しています。まずそれらを実装してください。`pop`、`peek`、`is_empty`、`clear`のテストはスタックに要素を追加する必要があります。

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
