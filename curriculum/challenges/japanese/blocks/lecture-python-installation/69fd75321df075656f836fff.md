# --description--

前のレッスンでは、Pythonスクリプトをローカルで実行する方法を学びました。時には、完全なプログラムを作成せずに短いPythonコードをテストしたい場合があります。Pythonのインタラクティブシェルを使えば、それができます。

まずは、ターミナルとは何かを復習しましょう。

ターミナルは、コマンドを入力してコンピューターとやり取りできるテキストベースのインターフェースです。各オペレーティングシステムにはデフォルトのターミナルアプリが付属しています。macOSではTerminalアプリを使えます。WindowsではCommand PromptやPowerShellが使えます。Linuxでは、GNOME TerminalやKonsoleなど、デスクトップ環境ごとにデフォルトのターミナルアプリがあります。

ターミナルアプリを開き、`python` または `python3` と入力して <kbd>Enter</kbd> を押すと、Pythonのインタラクティブシェルが起動します。インストール確認時にPython 3のバージョンが表示されたコマンドを使ってください。インタラクティブシェルは、コマンドを1つずつ入力して結果を確認できるプログラムです。

新しいセッションを始めると、最初にこのような出力が表示されることがあります。

```md
Python 3.12.2 (main, Mar 21 2024, 22:48:26) [Clang 14.0.3 (clang-1403.0.22.14.1)] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>> 
```

`>>>`の記号は、Pythonがコマンドの入力を待っていることを意味します。ターミナルに`"Hello, world!"`を出力してみましょう。

```py
print("Hello, world!")
```

以下のようにテキストが表示されるはずです。

```md
>>> print("Hello, world!")
Hello, world!
```

テキストが表示された後、Pythonは以下に戻ります。

```md
>>>
```

これはさらにコマンドを入力できる状態です。

Pythonインタープリターは、read-eval-printループ（REPL）に従います。入力を読み取り、評価し、結果を出力し、そして `>>>` プロンプトに戻ります。

もし無効なコマンドを入力したらどうなるでしょうか？

```md
>>> something random
```

Pythonインタプリタは同じREPLプロセスを実行しますが、この場合はエラーメッセージが表示されます。

```md
>>> something random
  File "<stdin>", line 1
    something random
              ^^^^^^
SyntaxError: invalid syntax
```

インタラクティブシェルを終了するには、`exit()` と入力するか、macOSやLinuxでは <kbd>Ctrl</kbd> + <kbd>D</kbd> を押し、Windowsでは <kbd>Ctrl</kbd> + <kbd>Z</kbd> を押してから <kbd>Enter</kbd> を押してください。

Pythonのインタラクティブシェルは、コードの小さな実験や基本的な探索に最適です。コースの残りのレッスンを進める際に、新しく学んだメソッドをインタラクティブシェルで試してみてください。

より長いプログラムや複数のファイルを扱う場合は、コードエディターやIDEを使ってください。
