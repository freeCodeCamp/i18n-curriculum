# --description--

Damit das Styling der Seite auf Mobilgeräten ähnlich aussieht wie auf einem Desktop oder Laptop, müssen Sie ein `meta`-Element mit einem speziellen `content`-Attribut hinzufügen.

Das viewport-`meta`-Element gibt dem Browser Anweisungen, wie die Abmessungen und das Skalieren der Seite auf verschiedenen Geräten, insbesondere auf Mobiltelefonen und Tablets, gesteuert werden sollen. Hier ist ein Beispiel:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

Der Teil `width=device-width` weist den Browser an, die Breite der Seite an die Bildschirmbreite des Geräts anzupassen. Das `initial-scale=1.0` legt den anfänglichen Zoomfaktor fest, wenn die Seite zum ersten Mal geladen wird. Ein Wert von `1.0` bedeutet, dass die Seite mit `100%` Zoom ohne Skalierung angezeigt wird.

Ohne dieses Element rendern mobile Browser die Seite normalerweise mit der Breite eines Desktop-Bildschirms und skalieren sie dann herunter, was zu winzigem, schwer lesbarem Text führen kann.

# --hints--

Ihr Code sollte zwei `meta`-Elemente enthalten.

```js
assert.lengthOf(document.querySelectorAll('meta'), 2);
```

Ihr `meta`-Element sollte ein `name`-Attribut mit dem Wert `viewport` haben.

```js
assert.exists(document.querySelector('meta[name="viewport"]'));
```

Ihr `meta`-Element sollte ein `content`-Attribut mit dem Wert `width=device-width, initial-scale=1.0` haben.

```js
assert.equal(document.querySelector('meta[name="viewport"]')?.getAttribute('content'), 'width=device-width, initial-scale=1.0');
```
