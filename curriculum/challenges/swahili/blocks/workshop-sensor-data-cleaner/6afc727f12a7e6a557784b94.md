# --description--

Ili kupata lebo kwa kila tofauti, unahitaji usemi wa kihesabu wa masharti kabla ya `for` badala ya `if` inayofuata mwishoni:

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

Ondoa `if` inayofuata mwishoni kutoka kwenye orodha yako ya dhihirisho. Kisha, badilisha usemi kabla ya `for` kuwa usemi wa kihesabu wa masharti unaothamini kuwa `f'+{difference} °C'` ikiwa `difference` ni kubwa kuliko `0`, na kuwa `f'{difference} °C'` vinginevyo. Nambari hasi tayari zina alama ya `-`, hivyo zinahitaji tu kitengo.
