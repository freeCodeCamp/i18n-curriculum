# --interactive--

플렉스 속성은 컨테이너 수준의 배치부터 항목 수준의 자체 정렬까지 플렉스 레이아웃 내에서 요소가 어떻게 동작하는지 제어합니다. 이 수업에서는 가장 자주 사용하는 `flex-wrap`, `flex-flow`, `justify-content`, `align-items`, `align-self`를 다룹니다.

`flex-wrap`부터 시작해 보겠습니다. 이 속성은 플렉스 항목이 플렉스 컨테이너 내에서 사용 가능한 공간에 맞게 어떻게 감싸지는지를 결정합니다. `flex-wrap`은 `nowrap`, `wrap`, `wrap-reverse` 세 가지 값을 가질 수 있습니다. 기본값은 `nowrap`으로, 플렉스 항목이 컨테이너 너비를 초과해도 새 줄로 감싸지지 않습니다.

아래 코드에는 세 개의 `div` 요소가 있습니다. `width`에 주목해 보세요. 테두리가 있는 `main` 컨테이너의 `width`는 `200px`이고, 세 개의 자식 `div` 요소의 `width` 합은 `240px`(`80px`씩)입니다:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  display: flex;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

`div` 요소들의 너비가 컨테이너 너비를 초과하지만, 기본적으로는 사용 가능한 공간에 맞게 축소됩니다. 만약 컨테이너 너비를 초과할 때 감싸기를 원한다면, 플렉스 컨테이너에 `flex-wrap: wrap`를 설정하세요:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  display: flex;
  flex-wrap: wrap;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

`div` 요소들은 컨테이너 너비를 초과하면 행으로 재배치됩니다. `flex-wrap: wrap-reverse`을 사용하면 플렉스 항목들을 역순으로 감쌀 수 있습니다. `flex-flow` 속성은 `flex-direction`과 `flex-wrap`의 단축 속성입니다. 이 예제에서는 `flex-direction`를 `column`으로, `flex-wrap`을 `wrap-reverse`으로 설정했습니다:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  height: 120px;
  display: flex;
  flex-flow: column wrap-reverse;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

좋습니다. 이제 `justify-content`에 대해 이야기해 보겠습니다. `justify-content`은 플렉스 컨테이너의 주축을 따라 자식 요소들을 정렬합니다. `flex-start`에 `justify-content` 값을 할당하면 플렉스 항목들이 주축의 시작 부분에 정렬됩니다. 이 주축은 수평 또는 수직일 수 있습니다:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: flex-start;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

`justify-content: flex-end`을 사용하면 플렉스 항목들이 주축의 끝 부분에 정렬됩니다, 수평이든 수직이든 상관없습니다.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css

  display: flex;
  justify-content: flex-end;
  border: 2px solid #444;

  width: 80px;

}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;

```

주축을 따라 플렉스 항목들을 가운데 정렬하려면 `justify-content: center`를 사용하세요.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: center;
  border: 2px solid #444;

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
```

주축을 따라 요소들을 가장자리 공간 없이 배치하려면 `justify-content: space-between`을 사용할 수 있습니다. 첫 번째 항목은 주축 시작에, 마지막 항목은 주축 끝에 위치하며, 나머지 공간은 인접한 항목들 사이에 분배됩니다.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: space-between;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

`justify-content: space-around`는 플렉스 항목을 주축을 따라 고르게 분배하며, 첫 번째 항목 앞과 마지막 항목 뒤에 공간을 추가합니다. 이 추가 공간은 인접한 항목 쌍 사이 공간의 절반입니다. 만약 배치할 항목이 하나뿐이라면 중앙에 위치합니다.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: space-around;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

마지막으로 `justify-content: space-evenly`는 항목들을 주축을 따라 균등하게 분배합니다. 항목들 사이 공간과 첫 번째 및 마지막 항목 앞뒤 공간이 정확히 동일합니다:

좋습니다. 이제 플렉스 항목들을 주축을 따라 분배하는 방법을 알았습니다. 하지만 교차 축을 따라 분배하고 싶을 수도 있습니다. 교차 축은 주축에 수직임을 기억하세요. `align-items` 속성으로 할 수 있습니다. 교차 축을 따라 항목들을 가운데 정렬하려면 플렉스 컨테이너에 `align-items: center`를 추가하세요:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: center;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

이 예제에서 플렉스 항목들은 기본적으로 수직인 교차 축을 따라 가운데 정렬됩니다. 교차 축이 수평이라면 수평으로 가운데 정렬됩니다. 반면 `align-items: flex-start`은 항목들을 교차 축의 시작 부분에 정렬합니다:

:::interactive_editor


플렉스 항목을 교차 축을 따라 늘리려면 `align-items: stretch`를 사용할 수 있습니다. 이 속성은 교차 축 크기가 `auto`인 항목에만 영향을 주며, 교차 축에 명시적 크기(예: 행 컨테이너에서 설정된 `height`)가 있는 항목은 늘어나지 않습니다. 영향을 받는 항목은 교차 축 방향으로 컨테이너를 채웁니다.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: stretch;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
  height: auto;
}
```
