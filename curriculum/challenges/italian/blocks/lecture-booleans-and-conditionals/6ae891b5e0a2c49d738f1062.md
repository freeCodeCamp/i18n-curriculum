# --description--

In Python, le variabili sono nomi che si riferiscono a oggetti. Gli operatori di identità verificano se due operandi si riferiscono allo stesso oggetto. L'operatore `is` restituisce `True` se è così, e `False` altrimenti. L'operatore `is not` restituisce il risultato opposto.

L'identità è diversa dall'uguaglianza: `==` e `!=` confrontano i valori, mentre `is` e `is not` confrontano l'identità dell'oggetto. Usa gli operatori di uguaglianza quando confronti valori numerici o stringhe.

`None` rappresenta l'assenza di un valore. È l'unico valore del tipo di dato `NoneType`.

Tre oggetti che puoi verificare con gli operatori di identità sono `None`, `True` e `False`. Ognuno è un singleton, cioè esiste esattamente un solo oggetto per ciascuno.

## Verifica di `None`

Puoi usare `is None` per verificare se un valore manca, oppure `is not None` per verificare se è presente:

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None` è falsy, ma non è lo stesso oggetto di `False`. Per esempio, una risposta potrebbe essere `True` per sì, `False` per no, o `None` se non è stata data alcuna risposta:

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

Usare invece `if not response` tratterebbe allo stesso modo sia `False` che `None`. Il controllo di identità distingue una risposta negativa da una risposta mancante.

## Verifica di `True` e `False`

Puoi anche usare l'identità per verificare specificamente gli oggetti booleani:

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

Questi controlli chiedono se `response` è esattamente `True`, `False` o un oggetto diverso da `None`. Non testano semplicemente la veridicità.

Per flag booleani ordinari, usa test diretti di veridicità come `if is_ready` o `if not is_ready`. Usa `is True` o `is False` quando hai bisogno di distinguere specificamente un oggetto booleano da altri valori possibili, come con una risposta che può essere anche `None`.
