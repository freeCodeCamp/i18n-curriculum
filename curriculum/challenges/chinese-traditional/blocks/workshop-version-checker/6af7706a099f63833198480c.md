# --description--

傳回一個包含 f-string 和 `latest` 的元組。這個 f-string 應該包含 `update_type` 的值，接著是字串 ` available, releases behind: `，最後是 `releases_behind` 的值。舉例來說，`major update available, releases behind: 5`。

然後，將你對 `check_for_update` 的呼叫中 `(2, 2, 1)` 的引數改成 `(2, 1, 0)`。你應該會在終端機看到 `Status: minor update available, releases behind: 3`。
