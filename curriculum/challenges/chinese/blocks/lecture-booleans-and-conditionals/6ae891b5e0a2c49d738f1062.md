# --description--

在 Python 中，变量是指向对象的名称。同一性操作符检查两个操作对象是否指向同一个对象。`is` 操作符如果是同一个对象则返回 `True`，否则返回 `False`。`is not` 操作符返回相反的结果。

同一性不同于相等性：`==` 和 `!=` 比较值，而 `is` 和 `is not` 比较对象的同一性。比较数字或字串值时使用相等操作符。

`None` 表示值的缺失。它是 `NoneType` 数据类型的唯一值。

你可以用同一性操作符检查的三个对象是 `None`、`True` 和 `False`。它们都是单例，意味着每个只有一个对象实例。

## 检查 `None`

你可以用 `is None` 来检查值是否缺失，或者用 `is not None` 来检查值是否存在：

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None` 是假值，但它不是与 `False` 相同的对象。例如，响应可以是 `True` 表示是，`False` 表示否，或者 `None` 表示没有给出答案：

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

如果改用 `if not response`，则会把 `False` 和 `None` 一视同仁。同一性检查区分了否定答案和缺失答案。

## 检查 `True` 和 `False`

你也可以用同一性专门检查布尔对象：

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

这些检查判断 `response` 是否正好是 `True`、`False`，或者是除 `None` 以外的对象。它们不仅仅测试真假性。

对于常规的布尔标记，使用直接的真假测试，比如 `if is_ready` 或 `if not is_ready`。当你特别需要区分布尔对象和其他可能值时，比如响应也可能是 `None`，才使用 `is True` 或 `is False`。
