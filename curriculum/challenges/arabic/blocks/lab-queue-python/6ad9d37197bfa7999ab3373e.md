# --description--

في هذا المختبر، ستبني صنف قائمة انتظار. تتبع قائمة الانتظار مبدأ FIFO (الأول داخل، الأول خارج): تُضاف العناصر إلى نهاية القائمة وتُزال من البداية.

**الهدف:** إكمال قصص المستخدم أدناه واجتياز جميع الاختبارات لإتمام المختبر.

**قصص المستخدم:**

1. عرّف صنفًا باسم `Queue`. يجب أن تبدأ نسخة جديدة من `Queue` فارغة.

1. يجب أن يحتوي صنف `Queue` على الطرق التالية:

   - `enqueue`: يأخذ عنصرًا ويضيفه إلى نهاية قائمة الانتظار.
   - `dequeue`: يزيل العنصر من بداية قائمة الانتظار ويُرجعه. إذا كانت القائمة فارغة، يجب أن تُرجع `None`.
   - `front`: يُرجع العنصر في بداية قائمة الانتظار دون إزالته. إذا كانت القائمة فارغة، يجب أن تُرجع `None`.
   - `size`: يُرجع عدد العناصر في قائمة الانتظار.
   - `is_empty`: يُرجع `True` إذا لم تحتوي قائمة الانتظار على عناصر، و`False` خلاف ذلك.

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
