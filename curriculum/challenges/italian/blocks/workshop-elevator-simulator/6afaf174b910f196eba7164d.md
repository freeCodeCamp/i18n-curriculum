# --description--

L'ascensore dovrebbe continuare a servire le richieste finché ce ne sono di disponibili. Un `while` loop è perfetto per questo, perché si ripete finché la sua condizione è vera. Ecco un promemoria della sintassi:

```py
while condition:
    # code to repeat
    ...
```

Una lista non vuota è truthy e una lista vuota è falsy, quindi puoi usare una lista come condizione del loop per farlo eseguire finché la lista non è vuota.

Crea un `while` loop che gira finché `requests` non è vuota. All'interno del loop, usa `pop(0)` per rimuovere la prima richiesta da `requests` e assegnala a una variabile chiamata `target`. Poi, stampa `target`.

Poiché `pop(0)` accorcia la lista a ogni iterazione, la lista alla fine diventa vuota e il loop si ferma. Senza questo, la condizione non diventerebbe mai falsa e il loop girerebbe all'infinito.
