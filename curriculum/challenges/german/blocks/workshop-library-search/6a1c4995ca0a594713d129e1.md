# --description--

Um die Fehler aus Ihrem `try`-Block abzufangen und zu behandeln, müssen Sie einen `catch`-Block hinzufügen. Sie können für diesen Block einen Parameter deklarieren, um das tatsächlich geworfene Fehlerobjekt zu untersuchen.

```js
try {
  // Code that might throw an error
} catch (err) {
  // Code to handle the error
}
```

Fügen Sie direkt unter Ihrem `try`-Block einen `catch`-Block mit einem Parameter namens `err` hinzu. Aktualisieren Sie innerhalb des Blocks das DOM, indem Sie den `textContent` von `statusDisplay` auf `err.message` setzen.
