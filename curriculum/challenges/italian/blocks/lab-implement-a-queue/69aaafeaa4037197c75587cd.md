# --description--

In questo laboratorio implementerai una struttura dati coda usando funzioni. Una coda è una struttura dati First-In-First-Out (FIFO) dove gli elementi vengono aggiunti alla fine della coda e rimossi dalla parte anteriore.

**Obiettivo:** Completa le storie utente qui sotto e fai passare tutti i test per completare il laboratorio.

**Storie utente:**

1. Dovresti avere una funzione `initQueue` che restituisce un oggetto con una proprietà `collection` impostata su un array vuoto.
1. Dovresti avere una funzione `enqueue` che aggiunge un elemento alla coda.
1. Dovresti avere una funzione `dequeue` che rimuove e restituisce l'elemento in testa alla coda, o `undefined` se non ce n'è uno.
1. Dovresti avere una funzione `front` che restituisce l'elemento in testa alla coda senza rimuoverlo, o `undefined` se non ce n'è uno.
1. Dovresti avere una funzione `size` che restituisce il numero di elementi nella coda.
1. Dovresti avere una funzione `isEmpty` che restituisce `true` se la coda è vuota e `false` altrimenti.

**Nota:** I test per `dequeue`, `front`, `size` e `isEmpty` usano la funzione `enqueue` per aggiungere elementi alla coda, quindi è meglio implementare prima `enqueue`. L'ultimo test verifica che tutte le tue funzioni funzionino insieme.

# --solutions--

```js
function initQueue() {
  return {
    collection: []
  };
}

function print(queue) {
  console.log(queue.collection);
}

function enqueue(queue, element) {
  queue.collection.push(element);
}

function dequeue(queue) {
  return queue.collection.shift();
}

function front(queue) {
  return queue.collection[0];
}

function size(queue) {
  return queue.collection.length;
}

function isEmpty(queue) {
  return queue.collection.length === 0;
}
```
