# --description--

Sasa unahitaji kuoanisha kila joto na lebo yake.

Kitendakazi cha `map()` kinaweza kuchukua zaidi ya iterable moja. Kila wito, hupitisha kipengee kimoja kutoka kila iterable kwa kitendakazi, kwa hivyo kitendakazi kinahitaji kigezo kimoja kwa kila iterable:

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

Unda kigezo kinachoitwa `report`. Weka thamani yake matokeo ya kupitisha kitendakazi cha `map()` pamoja na kitendakazi cha lambda, `temperatures`, na `difference_labels`, vikiwa vimefungwa katika wito wa `list()`. Kitendakazi cha lambda kinapaswa kuchukua vigezo viwili, `temperature` na `difference_label`, na kurudisha `f'{temperature} °C ({difference_label})'`.

Kisha, chapisha `report` badala ya `difference_labels`.
