# --description--

等于平均值的温度被标记为 `0.0 °C`，读起来不太好。它应该被标记为 `average`。

你可以通过在 `else` 后写另一个条件式来串联条件式。如果第一个条件为假，Python 会评估下一个条件式：

```py
labels = [
    'large' if num > 100
    else 'medium' if num > 10
    else 'small'
    for num in numbers
]
```

更新你的条件式，使其在 `difference` 大于 `0` 时评估为 `f'+{difference} °C'`，在 `difference` 小于 `0` 时评估为 `f'{difference} °C'`，否则评估为字串 `average`。
