# --description--

Nem todo instrutor tem uma propriedade `email`. Para um instrutor sem essa propriedade, atribuir a `instructorsByEmail[instructor.email]` criaria uma entrada com a chave string `"undefined"`.

Antes de adicionar o bloco `if`, exclua `console.log(instructorsById[instructor.id])` do passo anterior.

Adicione um bloco `if (instructor.email)`. Dentro dele, atribua `instructor.id` a `instructorsByEmail[instructor.email]`. Essa tabela permite buscar o ID de um instrutor pelo e-mail e depois recuperar o registro do instrutor.
