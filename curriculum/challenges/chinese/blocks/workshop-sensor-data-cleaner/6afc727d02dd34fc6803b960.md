# --description--

在终端中，你会看到一些值像 `-3.6999999999999993` 而不是 `-3.7`。这是因为浮点数无法精确表现每个小数，所以在算术操作后可能会出现小的误差。

`round()` 函数会将数字四舍五入到你作为第二个参数传入的小数位数：

```py
print(round(3.14159, 2)) # 3.14
```

将 `temperature - average` 包裹在 `round()` 调用中，将每个差值四舍五入到一位小数。
