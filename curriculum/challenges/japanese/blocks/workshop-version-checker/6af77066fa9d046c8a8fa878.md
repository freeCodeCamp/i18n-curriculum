# --description--

インストールされているバージョンが最新でない場合、関数はどの種類のアップデートが利用可能かを伝える必要があります。メジャー番号が異なる場合、それはメジャーアップデートです。つまり、新しいリリースには古いバージョンでは動作しないかもしれない大きな変更が含まれています。

バージョンのメジャー番号にはインデックス`0`でアクセスできます。`installed`のメジャー番号が`latest`のメジャー番号より小さいかどうかをチェックする`if`文を追加してください。もしそうなら、`update_type`という変数を作成し、文字列`major update`を代入してください。

# --hints--

```js

assert body.is_equivalent("update_type = 'major update'")
`) });
```
