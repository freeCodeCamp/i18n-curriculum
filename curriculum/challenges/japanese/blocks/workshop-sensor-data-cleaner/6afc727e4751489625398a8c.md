# --description--

今度は差分を `+3.6 °C` のようなテキストラベルに変換します。正の数は符号なしで出力されるので、前に `+` を付ける必要があります。

条件を満たす項目だけを含めるには、リスト内包表記の末尾に `if` を追加できます。

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

`difference_labels` という変数を作成してください。リスト内包表記を使って、`differences` の各 `difference` に対して `difference` が `0` より大きい場合のみ `f'+{difference} °C'` を含むリストを代入してください。

その後、`differences` の代わりに `difference_labels` を出力してください。

ターミナルには7つの温度に対して3つのラベルだけが表示されます。末尾の `if` は条件に合わない項目を除外するため、どの温度にどのラベルが対応しているか分かりません。次のステップでこれを修正します。
