# --description--

只要還有任何請求，電梯就應該持續服務。`while` 迴圈非常適合這個用途，因為它會在條件為真時重複執行。這裡提醒你語法如下：

```py
while condition:
    # code to repeat
    ...
```

非空的列表為真，空列表為假，所以你可以用列表作為迴圈的條件，讓它持續執行直到列表為空。

建立一個 `while` 迴圈，只要 `requests` 不為空就持續執行。在迴圈內，使用 `pop(0)` 從 `requests` 移除第一個請求，並指定給名為 `target` 的變數。接著，列印 `target`。

因為每次執行 `pop(0)` 都會讓列表變短，列表最終會變空，迴圈也會停止。若沒有這個動作，條件永遠不會變成假，迴圈就會無限執行。
