現在在 department 迴圈內添加第二個迴圈，對每個 `program` 進行迭代，並使用 `program` 作為迴圈變數。  
使用 `for...of` 迴圈來迭代 `programs` 陣列，並將每個 `program` 物件記錄到主控台。

你也應該從程式碼中移除 `console.log(programs)` 這一行。

這裡提醒你如何使用 `for...of` 迴圈：

```js
const dishes = [
  { id: "FOOD101", name: "Margherita Pizza", price: 14 },
  { id: "FOOD102", name: "Chicken Tacos", price: 12 }
];

for (const dish of dishes) {
  console.log(dish);
}

// { id: "FOOD101", name: "Margherita Pizza", price: 14 }
// { id: "FOOD102", name: "Chicken Tacos", price: 12 }
```
