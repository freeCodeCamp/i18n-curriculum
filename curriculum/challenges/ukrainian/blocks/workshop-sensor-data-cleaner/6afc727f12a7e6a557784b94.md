# --description--

Щоб отримати мітку для кожної різниці, вам потрібен умовний вираз перед `for` замість кінцевого `if`:

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

Видаліть кінцевий `if` зі свого спискового включення. Потім змініть вираз перед `for` на умовний вираз, який оцінюється як `f'+{difference} °C'`, якщо `difference` більше за `0`, і як `f'{difference} °C'` інакше. Від’ємні числа вже мають знак `-`, тому їм потрібна лише одиниця виміру.
