# --description--

插入排序會在列表開頭逐步建置一個已排序的部分，每次處理一個元素。它從將第一個元素視為已排序開始，接著取下一個元素並將它往後移動到已排序部分，將每個較大的元素向右移動或交換一個位置，直到遇到一個小於或相等的元素為止。這個過程會對剩下的每個元素重複，直到整個列表排序完成。

插入排序在平均和最壞情況下具有二次時間複雜度，但當列表已經排序時，它會以線性時間執行。

**目標：** 完成以下使用者故事並通過所有測試以完成實驗。

**使用者故事：**

1. 你應該定義一個名為 `insertion_sort` 的函式，並帶有一個代表項目列表的參數。
1. 你的 `insertion_sort` 函式應該就地將列表從小到大排序並傳回它。
1. 你的 `insertion_sort` 函式應該遵循插入排序演算法，從左到右將每個元素插入到列表開頭已排序部分的正確位置。
1. 你的 `insertion_sort` 函式在遇到小於或相等的元素時，應該停止將元素往後移動。
1. 你的 `insertion_sort` 函式不應使用內建的 `sort()` 方法或 `sorted()` 函式。

**注意：** 你不應該匯入任何模組或使用會新增或移除列表項目的方法。

```py
def insertion_sort(items):
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j -= 1
        items[j + 1] = current
    return items
```
