# --description--

アンパックを使うと、リストの要素を1行で複数の変数に代入できます。残りの要素をリストとしてまとめるには、スター付き変数を使えます。

```py
fruits = ['apple', 'banana', 'cherry']
first, *rest = fruits
print(first) # apple
print(rest) # ['banana', 'cherry']
```

`pieces`を3つの変数にアンパックしてください。最初の要素は`opening`に、間のすべての要素は`middle`に、最後の要素は`closing`に代入します。その後、`opening`、`middle`、`closing`をそれぞれ別々の`print()`で出力してください。
