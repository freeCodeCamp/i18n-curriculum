# --description--

In diesem Workshop üben Sie List Comprehensions und Lambda-Funktionen, indem Sie die Messwerte eines Temperatursensors bereinigen und mit der üblichen Durchschnittstemperatur seines Standorts vergleichen.

Der Sensor meldet Temperaturen in Zehntel Grad Celsius, daher bedeutet ein Wert von `215` `21.5` °C. Wenn er die Temperatur nicht messen kann, schreibt er stattdessen den Fehlercode `-999`.

Erstellen Sie eine Variable namens `readings` und weisen Sie ihr die Liste `[215, 243, -999, 280, 316, 339, -999, 262, 305]` zu.

Erstellen Sie dann eine Variable namens `average_temperature` und weisen Sie ihr den Float-Wert `28.0` zu. Dies ist die übliche Durchschnittstemperatur für den Standort, bereits in Grad Celsius, und Sie werden die Messwerte damit vergleichen.
