# --description--

Katika maabara hii, utasafisha mafaili ya kumbukumbu yenye muundo wa nusu kwa kubadilisha herufi zisizoruhusiwa na `#` na kufuatilia ni maingizo mangapi yamechakatwa.

**Lengo:** Timiza hadithi za watumizi zilizo hapa chini na upite vipimo vyote ili kumaliza maabara.

**Hadithi za watumizi:**

1. Unapaswa kutumia tamko la kitendakazi kuunda kitendakazi kinachoitwa `sanitizeLog` chenye vigezo viwili: `entry`, mfuatano wa herufi unaowakilisha ingizo la kumbukumbu, na `disallowedCharacters`, safu ya data ya mfuatano wa herufi moja inayowakilisha herufi za kubadilisha.
1. Kitendakazi kinapaswa kurudisha mfuatano wa herufi wa `entry` uliobadilishwa ambapo kila herufi isiyoruhusiwa imebadilishwa na `#`. Ulinganifu unapaswa kuwa na utofauti wa herufi kubwa na ndogo. Kwa mfano, ikiwa herufi zisizoruhusiwa ni `["e", "E", "o", "r"]`, basi `DEBUG: Server started on port 3000` hurudisha `D#BUG: S##v## sta#t#d #n p##t 3000`.
1. Unapaswa kuunda kitendakazi kinachoitwa `cleanLogs` chenye vigezo viwili: `logs`, safu ya data ya mfuatano wa herufi inayowakilisha maingizo ya kumbukumbu, na `disallowedCharacters`, safu ya data ya mfuatano wa herufi moja inayowakilisha herufi za kubadilisha.
1. `cleanLogs` inapaswa kurudia juu ya safu ya maingizo ya kumbukumbu kwa mpangilio.
1. Wakati `cleanLogs` inafikia ingizo la kumbukumbu lenye alama hatari `$`, inapaswa kuacha na kurudisha `Sanitizing stopped. Failure Reason: Fatal character occurred.`
1. Ingizo la kumbukumbu linaloanza na herufi `/` ni ingizo la taarifa na halipaswi kusafishwa. Unapaswa kuhesabu maingizo ya taarifa.
1. Maingizo mengine yote ya kumbukumbu yanapaswa kusafishwa kwa kutumia kitendakazi cha `sanitizeLog`. Unapaswa kuhesabu maingizo yaliyosafishwa.
1. Ikiwa `cleanLogs` inamaliza bila kukutana na alama hatari, inapaswa kurudisha `Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.`, ambapo `X` ni jumla ya maingizo, `Y` ni idadi ya maingizo yaliyosafishwa, na `Z` ni idadi ya maingizo ya taarifa.

**Safu zifuatazo za kumbukumbu zinatumika katika mitihani:**

```js

  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"

let logs_2 = [

];

let logs_3 = [

  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
