# --description--

Has aprendido que la asignación crea un alias y que el método `.copy()` de un diccionario crea una copia superficial. Una copia superficial tiene un diccionario externo separado, pero los objetos anidados siguen siendo compartidos. Ahora que sabes cómo importar módulos, también puedes usar el módulo `copy` de la biblioteca estándar para copiar colecciones anidadas.

## Crear una copia profunda

La función `copy.deepcopy()` copia recursivamente colecciones anidadas. Para un diccionario que contiene una lista, crea un nuevo diccionario externo y una lista anidada separada:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
deep_copy = copy.deepcopy(original)

print(deep_copy == original) # True
print(deep_copy is original) # False
print(deep_copy['items'] is original['items']) # False

deep_copy['items'].append('fruit')
print(original['items']) # ['bread', 'cheese']
print(deep_copy['items']) # ['bread', 'cheese', 'fruit']
```

Los diccionarios inicialmente tienen contenidos iguales, pero ni el diccionario externo ni la lista anidada se comparten entre ellos. Agregar elementos a la lista copiada deja la lista original sin cambios.

## Comparar asignación, copia superficial y copia profunda

Vamos a crear las tres formas a partir del mismo diccionario:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
alias = original
shallow_copy = original.copy()
deep_copy = copy.deepcopy(original)

print(alias is original) # True
print(shallow_copy is original) # False
print(deep_copy is original) # False

print(alias['items'] is original['items']) # True
print(shallow_copy['items'] is original['items']) # True
print(deep_copy['items'] is original['items']) # False
```

Continuando con estos objetos, cambia una entrada de nivel superior a través de cada nombre:

```python
alias['name'] = 'Picnic'
shallow_copy['name'] = 'Snack'
deep_copy['name'] = 'Dinner'

print(original['name']) # Picnic
print(alias['name']) # Picnic
print(shallow_copy['name']) # Snack
print(deep_copy['name']) # Dinner
```

El alias se refiere al diccionario original, por lo que asignar a través de `alias` cambia ese diccionario. Cada copia tiene su propio diccionario externo, así que reemplazar su entrada `name` afecta solo a esa copia.

Luego, modifica las listas anidadas:

```python
alias['items'].append('water')
shallow_copy['items'].append('fruit')
deep_copy['items'].append('soup')

print(original['items']) # ['bread', 'cheese', 'water', 'fruit']
print(alias['items']) # ['bread', 'cheese', 'water', 'fruit']
print(shallow_copy['items']) # ['bread', 'cheese', 'water', 'fruit']
print(deep_copy['items']) # ['bread', 'cheese', 'soup']
```

El diccionario original, su alias y la copia superficial se refieren a la misma lista. Los cambios a través de cualquiera de esas referencias son visibles en las otras. La copia profunda tiene su propia lista, por lo que sus cambios permanecen separados.

Esto también funciona con diccionarios anidados dentro de listas:

```python
import copy

original = {'meals': [{'name': 'Lunch', 'items': ['bread']}]}
deep_copy = copy.deepcopy(original)
deep_copy['meals'][0]['items'].append('fruit')

print(original['meals'][0]['items']) # ['bread']
print(deep_copy['meals'][0]['items']) # ['bread', 'fruit']
```

Aquí, `deepcopy()` copia el diccionario externo, la lista `meals`, el diccionario dentro de esa lista y su lista `items`. El ejemplo usa diccionarios y listas integrados; copiar profundamente no significa que se duplique cada posible objeto de Python.

Usa asignación cuando quieras otro nombre para el mismo objeto. Usa una copia superficial cuando un conjunto externo separado sea suficiente y compartir objetos anidados sea aceptable. Usa una copia profunda cuando los cambios en estas colecciones anidadas deban dejar las colecciones originales sin cambios.
