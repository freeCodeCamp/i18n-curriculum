## Usando o Explorador de Arquivos no Windows

Para criar um arquivo no Windows usando o Explorer, você pode clicar na opção "Novo" no canto superior esquerdo. Isso mostrará uma lista dos diferentes tipos de arquivos que você pode criar.

![Explorador de arquivos do Windows com o botão Novo destacado por uma caixa e uma seta laranja no canto superior esquerdo, e um Novo Documento de Texto selecionado na pasta freeCodeCamp Files.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-1.png)

Você também pode criar arquivos em suas aplicações correspondentes.

![Explorador de arquivos do Windows mostrando a pasta freeCodeCamp Files dentro de Documentos, com um Novo Documento de Texto selecionado.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-2.png)

Vamos criar um arquivo de texto para mostrar o processo.

Quando você clicar em "Novo" e selecionar o tipo de arquivo, verá um novo arquivo de texto na sua pasta atual com um nome padrão. Você pode renomeá-lo se quiser.

![Ícone de documento de texto com o nome do arquivo demo.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-3.png)

O processo de criar pastas é exatamente o mesmo. Clique no botão "Novo" no canto superior esquerdo e depois selecione a opção "Pasta" ou clique com o botão direito em um espaço vazio e vá em "Novo." Então, selecione a opção "Pasta." Você verá uma nova pasta vazia na sua localização atual.

![Explorador de arquivos do Windows mostrando uma nova pasta chamada Nova pasta na pasta freeCodeCamp Files.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-4.png)

### Renomeando arquivos e pastas

![Barra de ferramentas do Explorador de arquivos do Windows com o botão Renomear, mostrado como a letra A ao lado de um cursor de texto, destacado por uma caixa verde.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-5.png)

Você pode renomear arquivos e pastas selecionando-os e clicando na opção "Renomear" no topo. Quando o nome atual do arquivo estiver destacado, você pode começar a escrever o novo nome do arquivo. Pressione <kbd>Enter</kbd> para confirmar as alterações.

Alternativamente, você pode clicar com o botão direito no arquivo ou pasta e selecionar a opção "Renomear" ou usar o atalho de teclado <kbd>F2</kbd>. Escreva o novo nome e pressione <kbd>Enter</kbd> para confirmar as alterações.

### Movendo arquivos e pastas

Você pode mover um arquivo ou pasta para outra pasta arrastando e soltando-o na pasta de destino, se você a tiver aberta como uma aba.

Você também pode selecionar o arquivo ou a pasta e selecionar a opção "Recortar" no topo.

![Barra de ferramentas do Explorador de arquivos do Windows com o botão Recortar, mostrado como uma tesoura, destacado por uma caixa verde.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-6.png)

Então, vá para a pasta de destino e cole clicando no botão "Colar" na parte superior. Se você copiou ou recortou o arquivo anteriormente, este botão será ativado.

![Barra de ferramentas do Explorador de arquivos do Windows com o botão Colar, mostrado como uma prancheta, destacado por uma caixa verde.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-7.png)

Você também pode fazer isso clicando com o botão direito em um espaço vazio e depois clicando no ícone de colar. Isso removerá o arquivo ou a pasta de sua localização original.

### Excluindo arquivos e pastas

Para excluir um arquivo ou pasta, clique nele e depois clique no ícone da Lixeira no topo.

![Barra de ferramentas do Explorador de arquivos do Windows com o botão Excluir, mostrado como uma lixeira, destacado por uma caixa verde.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-8.png)

Você também encontrará a opção "Excluir" se clicar com o botão direito sobre ele.

## Usando o Finder no macOS

Ótimo. Agora vamos ver como você pode fazer isso no macOS usando o Finder.

Finder é o gerenciador de arquivos padrão no macOS.

### Criando arquivos

Para criar um arquivo no macOS, você precisa abrir um aplicativo que permita criar o tipo de documento que você precisa criar. Atualmente, não existe uma forma integrada de criar um arquivo diretamente no Finder.

Por exemplo, para criar um arquivo de texto simples, você pode abrir o TextEdit e salvar seu arquivo. O processo funciona exatamente da mesma forma para qualquer tipo de arquivo.

Existem várias maneiras de abrir o TextEdit. Uma delas é ir ao Launchpad.

![Ícone do Launchpad do macOS, um quadrado arredondado contendo uma grade de blocos coloridos de apps.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-9.png)

Então, busque um app onde você possa criar o tipo de arquivo que deseja. Neste caso, seria o "TextEdit." Clique no ícone para abrir o app.

![Campo de busca do Launchpad contendo o texto TextEdit, com o ícone do app TextEdit abaixo.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-10.png)

Uma vez dentro do aplicativo, você deve ver uma opção para salvar seu arquivo no menu File. Este menu está localizado no canto superior esquerdo, ao lado do ícone do menu Apple.

![TextEdit aberto com um documento vazio. Uma seta verde aponta para a barra de menu do macOS, que lista TextEdit, Arquivo, Editar, Formatar, Visualizar, Janela e Ajuda.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-11.png)

Em uma das opções do menu do App, você deve ver um comando para salvar o arquivo. Isso geralmente está no menu Arquivo.

![Close-up da barra de menu do macOS mostrando o logo da Apple, depois TextEdit, Arquivo, Editar, Formatar, Visualizar, Janela e Ajuda.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-12.png)

Ao lado, você verá o atalho de teclado para salvar seu arquivo. Geralmente é <kbd>Command</kbd> + <kbd>S</kbd> no macOS.

![Menu Arquivo do TextEdit aberto, com Salvar destacado e seu atalho Command + S mostrado à direita.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-13.png)

Quando você salvar o arquivo pela primeira vez, deverá ver uma janela de diálogo, onde pode escrever o nome do arquivo e escolher um local.

Normalmente, a extensão do arquivo é adicionada automaticamente pela aplicação mas você pode alterá-la antes de salvar o arquivo.

![Diálogo de salvar do TextEdit com Untitled.txt no campo Salvar como, um navegador de pastas, e botões Cancelar e Salvar na parte inferior.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-14.png)

Depois de salvar o arquivo, você pode abrir o Finder clicando no ícone do Finder no Dock.

![Ícone do Finder no Dock do macOS, um rosto sorridente azul e branco.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-15.png)

Você deve ver seu novo arquivo na pasta onde o salvou.

![Janela do Finder mostrando a pasta freeCodeCamp Files contendo um arquivo, demo.txt.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-16.png)

### Criando pastas

Para criar uma nova pasta, você deve ir até o local onde deseja criar essa nova pasta e clicar com o botão direito em um espaço vazio. Você verá uma lista de opções. A primeira opção é "Nova Pasta."

![Menu de contexto do Finder aberto em uma área vazia, com Nova pasta destacada no topo da lista.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-17.png)

Se você clicar nele, pode atribuir um nome à sua nova pasta. Escreva o nome e pressione <kbd>Enter</kbd> para confirmar.

![Nova pasta do Finder chamada pasta sem título, com o nome destacado para edição.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-18.png)

![A mesma pasta renomeada para freeCodeCamp.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-19.png)

### Movendo arquivos e pastas

Existem várias maneiras de mover arquivos e pastas no Finder. Se você precisar movê-los para uma pasta listada na seção "Favorites" do seu Finder, você pode simplesmente arrastar e soltar.

![Janela do Finder com demo.txt sendo arrastado para Documentos na barra lateral Favoritos, mostrado por setas verdes.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-20.png)

Se você precisar movê-lo para uma pasta diferente, você tem duas opções.

Você pode abrir a pasta de destino como uma aba e arrastar e soltar o arquivo ou a pasta na aba.

Ou você pode usar atalhos de teclado. Primeiro, copie o arquivo com <kbd>Command</kbd> + <kbd>C</kbd>, vá para a nova pasta e então use <kbd>Command</kbd> + <kbd>Option</kbd> + <kbd>V</kbd> para colar o arquivo ou pasta nesse local. Isso também o removerá da pasta original.

### Excluindo arquivos e pastas

Para excluir um arquivo ou pasta, você pode clicar com o botão direito nele e selecionar "Mover para a lixeira."

![Menu de contexto do Finder para demo.txt com Mover para a lixeira destacado.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-21.png)

![Menu de contexto do Finder para a pasta freeCodeCamp com Mover para a lixeira destacado.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-22.png)

Você também pode arrastá-los e soltá-los no ícone da lixeira no Dock. Isto é equivalente.

![Ícone da Lixeira no Dock do macOS, uma lixeira cheia de papéis amassados.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-23.png)

Quando o arquivo ou a pasta estiver na lixeira, você pode clicar com o botão direito nele para deletá-lo imediatamente ou pode esvaziar a lixeira para remover todos os arquivos e pastas deletados permanentemente.

![Janela da Lixeira do Finder com o menu de contexto para demo.txt aberto, listando Abrir, Abrir com, Colocar de volta, Excluir imediatamente e Esvaziar lixeira.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-24.png)
