# --interactive--

تُتيح خاصية `text-decoration` إضافة خطوط زخرفية إلى النص.

بقيمة البداية `none`، تُستخدم عادةً لإزالة الخط السفلي الافتراضي الذي تضيفه المتصفحات إلى الروابط عند الحاجة لتخصيص هذه الروابط.

```css
a {
  text-decoration: none;
}
```

رغم استخدامها الشائع مع الروابط، يمكن لـ `text-decoration` أيضًا زخرفة نصوص أخرى.

## قيم أخرى لخاصية `text-decoration`

بجانب `none`، القيم الأخرى لخاصية `text-decoration` هي:

- `underline`
- `overline`
- `line-through`

كما توضح أسماء القيم، تضيف `underline` خطًا تحت النص، و`overline` خطًا فوق النص، و`line-through` خطًا في منتصف النص، كأنه إلغاء للنص.

## المزيد عن خاصية `text-decoration`

في الواقع، خاصية `text-decoration` هي خاصية مختصرة تجمع الخصائص التالية:

- `text-decoration-line`: القيم `none`، `underline`، `overline`، و`line-through`
- `text-decoration-color`: لون الخط.
- `text-decoration-style`: القيم `solid`، `double`، `dotted`، `dashed`، أو `wavy`.
- `text-decoration-thickness`: سمك الخط.

على سبيل المثال، هذا يضيف خطًا أحمر متموجًا إلى فقرة:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

وهذا يضيف خطًا مزدوجًا أخضر فوق فقرة:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

يمكنك أيضًا دمج أنواع الخطوط إذا أردت:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
