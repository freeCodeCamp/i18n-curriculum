## 為什麼要在本機安裝 Python？

在所有的工作坊和實驗中，你都會使用 freeCodeCamp 的 Python 編輯器。但學會如何在你的區域電腦上設定 Python 也很重要。

## 下載 Python

在 Windows 和 Mac 上安裝 Python 最簡單的方法是從官方 Python 網站下載安裝程式。我們稍後也會介紹如何在 Linux 上執行 Python。

前往 `https://www.python.org/` 並將滑鼠暫留在「Downloads」上。會跳出一個視窗，顯示你作業系統（OS）目前的 Python 版本。

## 在 macOS 上安裝 Python

我們先介紹如何在 macOS 電腦上安裝 Python：

- 點擊顯示目前 Python 版本的按鈕（來自先前的視窗），系統會自動開始下載 `.pkg` 安裝檔。
- `.pkg` 安裝檔下載完成後，打開它，然後在開啟的視窗中點擊「繼續」。
- 持續點擊「繼續」按鈕，直到看到「安裝類型」部分，然後點擊「安裝」按鈕。
- 如有需要，輸入你的密碼，然後開始安裝。
- 套件安裝完成後，你應該會看到 Python 已成功安裝的訊息。
- 打開你應用程式目錄中新創建的 Python 資料夾。
- 雙擊 `Install Certificates.command` 檔案，並允許終端機處理程序完成。
- 確認終端機視窗中出現 `Successfully installed certifi` 和 `update complete`。
- 關閉終端機視窗，並在安裝程式視窗中點擊「關閉」。你的設定現在完成了！

## 驗證安裝

你可以打開終端機，執行 `python --version` 或 `python3 --version` 來驗證安裝。

你也可以在終端機中執行 `python` 或 `python3` 來開啟 Python 直譯器。Python 直譯器是一個程式，它會讀取 Python 程式碼，將其轉譯成電腦能理解的指令，並執行這些指令。

## 什麼是終端機？

<dfn>終端機</dfn>是一種以文字為基礎的介面，讓你透過輸入指令與電腦互動。每個作業系統都會附帶預設的終端機應用程式。macOS 可以使用 Terminal 應用程式，Windows 可以使用命令提示字元或 PowerShell，Linux 則依桌面環境不同，有 GNOME Terminal 或 Konsole 等預設終端機。

## 使用 `python` 與 `python3` 的差異

請注意，在某些較舊的 macOS 和 Linux 系統中，`python` 可能是保留給 Python 2 使用，而 `python3` 則是專門給 Python 3。如果你執行 `python --version`，看到像 `Python 2.7.18` 這樣的 Python 2 版本，那可能是你的作業系統依賴某些用舊版 Python 撰寫的軟體。如果是這樣，你應該改用 `python3` 來執行 Python 程式。Python 2 已經終止支援，不應用於任何新開發。

## 在 Windows 上安裝 Python

在 Windows 上安裝 Python，請依照以下步驟：

- 前往 `https://www.python.org/`，並暫留在「Downloads」上方。你會看到一個視窗顯示「Download for Windows」和帶有目前 Python 版本的下載按鈕。
- 點擊版本號，系統會自動開始下載 Python 安裝管理器（`.msix` 軟體包）。
- 下載完成後，雙擊 Python 安裝管理器並選擇「安裝」。
- 安裝完成後，`python`、`py` 和 `pymanager` 指令應該可用。如果沒有安裝 Python 執行期，執行 `python` 會自動安裝一個。
- 當你第一次安裝執行期時，系統可能會提示你將一個目錄加入你的 `PATH`，以便使用額外的別名，例如 `python3.14.exe`。如果你想使用這些別名，請接受這個選用提示。


你可以打開命令列殼層（例如 PowerShell），執行 `python --version` 來驗證安裝。你也可以執行 `python` 來開啟 Python 直譯器。

## 在 Linux 上安裝 Python

在 Linux 上，大多數主要發行版如 Ubuntu、Debian 和 Fedora 都預載 Python。

只要打開終端機並執行 `python --version` 或 `python3 --version`。

如果兩個指令都沒有顯示 Python 3 版本，你可以在 `https://www.python.org` 搜尋適合你 Linux 發行版的安裝套件，或在線上搜尋該發行版推薦的 Python 安裝方式。
