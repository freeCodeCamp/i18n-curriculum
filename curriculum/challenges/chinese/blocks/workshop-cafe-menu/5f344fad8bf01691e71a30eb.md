# --description--

到目前为止，你对内容的展示和外观控制有限。为改变这一点，你将使用 CSS。

向页面添加 CSS 的一种方法是使用 `style` 元素，通常放在 `head` 标签内。`style` 标签内的任何 CSS 规则都会应用到整个页面。下面是一个示例：

```html
<style>
  p {
    color: green;
  }
</style>
```

在 `head` 元素内添加一个 `style` 元素。

# --hints--

你的代码应该包含一个 `style` 元素。

```js
assert.exists(document.querySelector('style:not(.fcc-hide-header)'));
```

你的代码应有一个闭合的 `</style>` 标签。

```js
assert.match(code, /<\/style\s*>/i);
```

你的 `style` 元素都应嵌套在 `head` 元素中。

```js
assert.exists(document.querySelector('head > style:not(.fcc-hide-header)'));
```
