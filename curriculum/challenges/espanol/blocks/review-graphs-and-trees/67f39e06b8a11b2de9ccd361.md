## Resumen de grafos

Un grafo es un conjunto de nodos (vértices) conectados por aristas (conexiones). Cada nodo puede conectarse a múltiples otros nodos, formando una red. Los diferentes tipos de grafos incluyen:

- Dirigidos: las aristas tienen dirección (de un nodo a otro), a menudo representados con líneas rectas y flechas.
- No dirigidos: las aristas no tienen dirección, representados con líneas simples.
- Vértice: cada nodo está asociado con una etiqueta o identificador.
- Cíclicos: contienen ciclos (un camino que comienza y termina en el mismo nodo).
- Acíclicos (DAG): no contienen ciclos.
- Etiquetados en aristas: cada arista tiene una etiqueta usualmente dibujada junto a la arista correspondiente.
- Ponderados: las aristas tienen pesos (valores) asociados que pueden usarse para operaciones aritméticas.
- Desconectados: contienen dos o más nodos que no están conectados por ninguna arista.

Los grafos se usan en varias aplicaciones como mapas, redes, sistemas de recomendación, resolución de dependencias.

## Recorridos en grafos

Esto implica visitar todos los nodos en un grafo. Los dos algoritmos principales son:

- **Búsqueda en anchura (BFS)**
  - Usa una cola.
  - Explora nivel por nivel.
  - Encuentra el camino más corto en grafos no ponderados.

- **Búsqueda en profundidad (DFS)**
  - Usa una pila (o recursión).
  - Explora una rama completamente antes de retroceder.
  - Útil para detección de ciclos y búsqueda de caminos.

## Representaciones de grafos

Los grafos pueden representarse de dos formas principales:

- **Lista de adyacencia**
  - Cada nodo tiene una lista de sus vecinos.
  - Eficiente en espacio para grafos dispersos.
  - Fácil para iterar sobre vecinos.

- **Matriz de adyacencia**
  - Un arreglo 2D donde filas y columnas representan nodos.
  - Consume mucho espacio para grafos grandes.
  - Rápido para verificar si existe una arista entre dos nodos.

## Árboles

Un árbol es un tipo especial de grafo que es acíclico y conectado. Propiedades clave incluyen:

- No tienen ciclos ni bucles (caminos donde el nodo inicial y final son el mismo).
- Deben estar conectados (cada nodo puede alcanzarse desde cualquier otro nodo).

### Tipos comunes de árboles

Los tipos más comunes de árboles son:

- Árboles binarios
  - Cada nodo tiene como máximo dos hijos, uno izquierdo y uno derecho.

- Árboles de búsqueda binaria (BST)
  - Un árbol binario en el que cada hijo izquierdo es menor que su padre, y cada hijo derecho es mayor que su padre.


## Tries

También conocidos como árboles prefijos, se usan para almacenar conjuntos de cadenas, donde cada nodo representa un carácter.

Los prefijos compartidos se almacenan solo una vez, haciéndolos eficientes para tareas como autocompletar y corrección ortográfica.

Las operaciones de búsqueda e inserción tienen complejidad de tiempo O(L), donde L es la longitud de la cadena.

## Colas de prioridad

Una cola de prioridad es un tipo abstracto de datos donde cada elemento tiene una prioridad.

Las colas y pilas consideran solo el orden de inserción, mientras que las colas de prioridad consideran la prioridad de los elementos.

Las colas estándar siguen FIFO (primero en entrar, primero en salir) y las pilas siguen LIFO (último en entrar, primero en salir). Sin embargo, en una cola de prioridad, los elementos con mayor prioridad se atienden antes que los de menor prioridad, sin importar el orden de inserción.

## Montículos

Es una estructura de datos basada en árboles con una propiedad muy específica llamada propiedad de montículo.

La propiedad de montículo determina la relación entre nodos padre e hijo. Hay dos tipos de montículos:

- Montículo máximo
  - El valor de cada nodo padre es mayor o igual que los valores de sus hijos.
  - El elemento más grande está en la raíz.

- Montículo mínimo
  - El valor de cada nodo padre es menor o igual que los valores de sus hijos.
  - El elemento más pequeño está en la raíz.

### Ejemplo del módulo `heapq` en Python

```py
import heapq

# Create empty heap
my_heap = []

# Insert elements
heapq.heappush(my_heap, 9)
heapq.heappush(my_heap, 3)
heapq.heappush(my_heap, 5)
print(my_heap) # [3, 9, 5]

# Remove smallest element
print(heapq.heappop(my_heap))  # 3
print(my_heap) # [5, 9]

# Push + Pop in one step
print(heapq.heappushpop(my_heap, 7)) # 5
print(my_heap) # [7, 9]

# Transform list into heap
nums = [5, 7, 3, 1]
heapq.heapify(nums)
```

### Uso de prioridades

```py
my_heap = []
heapq.heappush(my_heap, (3, "A"))
heapq.heappush(my_heap, (2, "B"))
heapq.heappush(my_heap, (1, "C"))

# Removes lowest number = highest priority
print(heapq.heappop(my_heap))  # (1, "C")
```
