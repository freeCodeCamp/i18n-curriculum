# --description--

年龄至少为 `18` 岁但未满 `21` 岁的用户可以预订票，但仅当 `show_time` 不是 `Evening` 时。

不等操作符（`!=`）用于检查两个值是否不相等。当两个值不同，它的结果是 `True`；当两个值相同时，结果是 `False`：

```py
day = 'Monday'
print(day != 'Sunday') # True
print(day != 'Monday') # False
```

当在同一个表达式中同时使用 `and` 和 `or` 时，`and` 的优先级高于 `or`。这意味着用 `and` 连接的条件会先被组合计算，然后该组合的结果再与 `or` 条件结合：

```py
has_key = True
knows_code = False
is_daytime = False

print(has_key or knows_code and is_daytime) # True
```

在上面的例子中，`knows_code and is_daytime` 会先被计算，结果是 `False`。整个表达式随后变成 `has_key or False`，结果是 `True`。
