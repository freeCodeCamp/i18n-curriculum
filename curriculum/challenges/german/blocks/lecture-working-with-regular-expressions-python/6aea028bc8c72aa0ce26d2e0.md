# --description--

Reguläre Ausdrücke können spezielle Folgen enthalten, die aus einem Backslash (`\`) gefolgt von einem Zeichen bestehen. Diese Folgen haben eine besondere Bedeutung. Hier sind einige der gebräuchlichsten:

- `\d` entspricht jeder Dezimalziffer, einschließlich `0` bis `9`.

- `\w` entspricht jedem Wortzeichen: Buchstaben, Ziffern und dem Unterstrich (`_`).

- `\s` entspricht jedem Leerzeichen, wie einem Leerzeichen, einem Tabulator oder einem Zeilenumbruch.

- `\D`, `\W` und `\S` entsprechen dem Gegenteil ihrer Kleinbuchstaben-Versionen. Zum Beispiel entspricht `\D` jedem Zeichen, das keine Ziffer ist.

Es gibt jedoch einen Haken. Python-Strings verwenden ebenfalls Backslashes, um Escape-Sequenzen wie `\n` (ein Zeilenumbruch) oder `\t` (ein Tabulator) zu schreiben:

```python
print('Tab:\tdone') # Tab:    done
```

Das bedeutet, dass ein Backslash in einem normalen Python-String von Python interpretiert werden kann, bevor das `re`-Modul ihn überhaupt sieht. Je nach folgendem Zeichen kann das Ihr Muster verändern oder Python eine Warnung anzeigen lassen.

Um das zu vermeiden, können Sie einen rohen String verwenden. Sie erstellen einen rohen String, indem Sie den Buchstaben `r` (oder `R`) vor das öffnende Anführungszeichen setzen. Rohe Strings behandeln Backslashes als buchstäbliche Zeichen und nicht als Escape-Sequenzen:

```python
print(r'Tab:\tdone') # Tab:\tdone
```

Aus diesem Grund ist es gute Praxis, Regex-Muster immer als rohe Strings zu schreiben:

```python
import re

room = 'Room 42B'
print(re.search(r'\d', room))
# <re.Match object; span=(5, 6), match='4'>
```

Beachten Sie, dass `re.search` den ersten gefundenen Treffer zurückgibt. Hier entspricht `\d` einer einzelnen Ziffer, daher ist der Treffer nur `4`. Um mehr als eine einzelne Ziffer zu erfassen, möchten Sie möglicherweise einen Quantifizierer verwenden.

Quantifizierer geben an, wie oft das vorhergehende Zeichen oder die vorhergehende Folge wiederholt werden kann. Der Quantifizierer `+` entspricht dem vorhergehenden Zeichen einmal oder mehrmals.

Während `\d` also eine einzelne Ziffer entspricht, entspricht `\d+` einer oder mehreren Ziffern hintereinander:

```python
import re

room = 'Room 42B'
print(re.search(r'\d+', room))
# <re.Match object; span=(5, 7), match='42'>
```

Hier sind weitere gebräuchliche Quantifizierer:

- `*` entspricht dem vorhergehenden Zeichen null- oder mehrmals.

- `?` entspricht dem vorhergehenden Zeichen null- oder einmal und macht es optional.

- `{n}` entspricht dem vorhergehenden Zeichen genau `n`-mal.

- `{n,m}` entspricht dem vorhergehenden Zeichen von `n` bis `m`-mal.

```python
import re

print(re.search(r'go*al', 'What a goooal!'))
# <re.Match object; span=(7, 13), match='goooal'>

print(re.search(r'colou?r', 'My favorite color is blue'))
# <re.Match object; span=(12, 17), match='color'>

print(re.search(r'\d{4}', 'Room 42, built in 1987'))
# <re.Match object; span=(18, 22), match='1987'>
```

Sie können literale Zeichen, spezielle Folgen und Quantifizierer im selben Muster kombinieren. Zum Beispiel entspricht das Muster `r'\d+ items'` einer oder mehreren Ziffern, gefolgt von einem Leerzeichen und dem Wort `items`. Sie können es auch mit dem Flag `re.IGNORECASE` kombinieren, sodass die Buchstaben entweder Klein- oder Großbuchstaben sein können:

```python
import re

cart = 'You have 3 ITEMS in your cart.'
print(re.search(r'\d+ items', cart, re.IGNORECASE))
# <re.Match object; span=(9, 16), match='3 ITEMS'>
```
