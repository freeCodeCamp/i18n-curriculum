# --description--

## تثبيت محرر كود أو بيئة تطوير متكاملة

في الدرس السابق، تعلمت كيفية تثبيت Python على جهازك المحلي. في هذا الدرس، ستتعلم كيفية تشغيل كود Python محليًا.

قبل أن تبدأ في بناء سكريبتات Python محليًا، تحتاج إلى تثبيت محرر كود أو IDE. IDE تعني بيئة التطوير المتكاملة. تجمع IDE بين ميزات مثل محرر الكود، وأدوات الاختبار، والنافذة الطرفية.

أحد محررات الكود الشهيرة التي يستخدمها العديد من المطوّرين هو VS Code. زر `https://code.visualstudio.com/download` لتحميل VS Code، الذي يدعم macOS وWindows وLinux. هذا هو المحرر الذي ستستخدمه في هذا الدرس.

خيارات شائعة أخرى لتطوير Python تشمل ما يلي:

- PyCharm
- Spyder

## إنشاء ملف Python

بعد تثبيت VS Code، افتحه واختر `File` ثم `Open Folder`. اختر مجلدًا لمشروعك أو أنشئ واحدًا جديدًا. للممارسة الإضافية خارج الدرس، قد ترغب في مجلد باسم `python-projects`.

افتح مستكشف الملفات في الشريط الجانبي الأيسر لـ VS Code. اختر أيقونة `New File` التي تبدو كقطعة ورق مع علامة زائد. أنشئ ملفًا باسم `main.py` واضغط <kbd>Enter</kbd>. امتداد `.py` يحدد أنه ملف Python.

افتح ملف `main.py` واكتب الكود التالي:

```py
print("Hello, world!")
```

## تثبيت امتداد Python

لتثبيت امتداد Python الرسمي من Microsoft، اتبع الخطوات المحددة أدناه:

### الطريقة أ: داخل التطبيق

1. افتح عرض الامتدادات بالنقر على أيقونة أربع كتل بناء في شريط النشاط على الجانب الأيسر. بدلاً من ذلك، اضغط <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (Windows / Linux) أو <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (macOS).
1. اكتب `Python` في شريط البحث في الأعلى.
1. ابحث عن النتيجة الأولى المسماة Python، مع التأكد من أن الناشر أسفلها هو Microsoft.
1. انقر على زر <kbd>Install</kbd> الأزرق.

### الطريقة ب: الطرفية / سطر الأوامر

إذا فضلت تثبيت الامتداد من الطرفية، تأكد أولًا من توفر أمر `code`. على macOS، افتح لوحة الأوامر، نفذ `Shell Command: Install 'code' command in PATH`، ثم أعد تشغيل الطرفية.

ثم ثبّت امتداد Python بتشغيل الأمر التالي:

```bash
code --install-extension ms-python.python
```

## اختيار مفسر Python

الامتداد يعمل كجسر، لكنه لا يحتوي على ملفات لغة Python الفعلية. يجب تثبيت مفسر Python بشكل منفصل من الموقع الرسمي لـ Python إذا لم تكن قد فعلت ذلك بالفعل.

بمجرد تثبيت Python على نظام التشغيل، اربطه بمحررك:

1. في VS Code، افتح أي مجلد أو ملف ينتهي بـ `.py`.
1. افتح لوحة الأوامر باستخدام <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows / Linux) أو <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS).
1. اكتب واختر `Python: Select Interpreter`.
1. اختر إصدار Python 3 المثبت من قائمة جهازك. سيظهر الآن بشكل طبيعي في شريط حالة مساحة العمل.

## تشغيل سكريبت Python الخاص بك

لتشغيل هذا الكود، لديك عدة خيارات. الخيار الأول هو النقر على زر التشغيل الذي يشبه زر التشغيل الموجود في الزاوية العلوية اليمنى. هذا سيفتح نافذة طرفية ويشغل سكريبت Python هناك. يجب أن ترى النص `Hello, world!`

خيار آخر هو فتح محطة طرفية وتشغيل البرنامج يدويًا باستخدام:

```bash
python main.py
```

يجب تشغيل هذا الأمر من المجلد الذي تم حفظ `main.py` فيه. على سبيل المثال، إذا كان `main.py` داخل مجلد يسمى `python-projects`، استخدم أولاً الأمر التالي في الطرفية:

```bash
cd python-projects
```

ثم شغّل:

```bash
python main.py
```

## استخدام `python3` بدلاً من `python`

في بعض بيئات العمل، خاصة على أنظمة macOS وLinux حيث يتم تثبيت Python 2 وPython 3 معًا، قد تحتاج إلى استخدام `python3` بدلًا من `python`. هذا شائع عندما لا يوجد أمر `python` أو يشير إلى إصدار أقدم من Python.

```bash
python3 main.py
```

مع تقدمك في الدورة، شغّل أمثلة كل درس محليًا وأنشئ أمثلة خاصة بك لاختبار ما تعلمته.
