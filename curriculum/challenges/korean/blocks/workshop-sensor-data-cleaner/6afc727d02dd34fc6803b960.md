# --description--

터미널에서 `-3.7` 대신 `-3.6999999999999993` 같은 값이 보일 수 있습니다. 이는 부동소수점이 모든 소수를 정확히 나타낼 수 없기 때문에 산술 연산 후에 작은 오차가 발생할 수 있기 때문입니다.

`round()` 함수는 두 번째 인수로 전달한 소수점 자리수까지 숫자를 반올림합니다:

```py
print(round(3.14159, 2)) # 3.14
```

`temperature - average`를 `round()` 호출로 감싸서 각 차이를 소수점 한 자리까지 반올림하세요.
