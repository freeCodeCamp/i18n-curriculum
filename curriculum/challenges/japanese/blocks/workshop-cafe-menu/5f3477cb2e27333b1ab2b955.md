# --description--

`styles.css` ファイルをリンクして、スタイルを再び適用できるようにしましょう。

`link` 要素は、スタイルシートやサイトアイコンなどの外部リソースにリンクするために使います。外部の CSS にリンクするための `link` 要素の基本的な構文は次の通りです：

```html
<link rel="stylesheet" href="styles.css" />
```

`rel` 属性は、リンクされたリソースと HTML ドキュメントの関係を指定します。この場合、リンクされたリソースが `stylesheet` であることを指定する必要があります。`href` 属性は外部リソースの場所を指定します。

`head` 要素の中に `link` 要素を追加してください。`rel` 属性には `"stylesheet"` を、`href` 属性には `"styles.css"` を指定します。

**注意：** `link` 要素は void 要素で、終了タグがありません。void 要素は `<element></element>` ではなく `<element>` と書く必要があります。

# --hints--

コードには `link` 要素が含まれている必要があります。

```js
const link = document.querySelector('link');
assert.isNotNull(link);
```

`link`要素は空要素なので、終了タグ`</link>`は不要です。

```js
assert.notMatch(code, /<\/link>/i);
```

既存の`head`要素は変更しないでください。終了タグを削除していないことを確認してください。

```js
const headElementCount = document.querySelectorAll('head')?.length;
assert.strictEqual(headElementCount, 1);
```

`link` 要素が1つあるはずです。

```js
const linkElementCount = document.querySelectorAll('link')?.length;
assert.strictEqual(linkElementCount, 1);
```

`link` 要素は `head` 要素の中にある必要があります。

```js
const link = document.querySelector('head > link');
assert.isNotNull(link);
```

`link`要素には値が`stylesheet`の`rel`属性が必要です。

```js
const linkRelValue = document.querySelector('link')?.getAttribute('rel');
assert.strictEqual(linkRelValue, 'stylesheet');
```

`link`要素には値が`styles.css`の`href`属性が必要です。

```js
const linkHrefValue = document.querySelector('link')?.dataset?.href;
assert.strictEqual(linkHrefValue, 'styles.css');

```
