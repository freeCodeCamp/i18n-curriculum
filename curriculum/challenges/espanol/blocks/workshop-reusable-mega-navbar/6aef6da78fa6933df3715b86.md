# --description--

Lo último que queda por hacer es actualizar el estado `isOpen` cuando se hace clic en el botón `Apps`.

En React, respondes a los eventos pasando una función a un atributo de evento en un elemento. Estos atributos se escriben en camelcase, así que un clic se maneja con `onClick`:

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

Fíjate que `onClick` recibe una función. React llama a esa función cada vez que se hace clic en el botón. Llamar a la función setter con un nuevo valor actualiza el estado, y React vuelve a renderizar el componente con ese nuevo valor.

Para alternar un estado booleano entre `true` y `false`, puedes pasar el valor opuesto al actual a la función setter usando el operador lógico NOT (`!`).

Agrega un atributo `onClick` al elemento `button`. Dale una función flecha que llame a `setIsOpen` con el valor opuesto de `isOpen`.

Haz clic en el botón `Apps` para abrir y cerrar el `sub-menu`.

Con eso, tu componente `Navbar` está completo.

# --hints--

Al hacer clic en el botón `Apps` debe establecerse su atributo `aria-expanded` en `"true"` y agregarse la clase `sub-menu--open` al `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

Al hacer clic por segunda vez en el botón `Apps` debe establecerse su atributo `aria-expanded` en `"false"` y eliminarse la clase `sub-menu--open` del `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
