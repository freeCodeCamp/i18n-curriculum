# --description--

Pythonでは、`bool`は`int`のサブクラスであり、`True`は`1`のように、`False`は`0`のように振る舞います。つまり、`isinstance()`はブール値を整数として扱います。

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True
```

このため、現在の関数は`True`と`False`をシフト値として受け入れています。

`or`演算子を使って、`if`文に`shift`がブール値かどうかを`isinstance(shift, bool)`でチェックする2つ目の条件を追加してください。こうすることで、`shift`が`True`または`False`の場合にも関数は`Shift must be an integer value.`を返します。
