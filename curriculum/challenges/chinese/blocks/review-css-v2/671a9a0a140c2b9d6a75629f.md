## CSS 基础

- **什么是 CSS？**：层叠样式表（CSS）是一种用于为 HTML 元素应用样式的样式表语言。CSS 用于颜色、背景图像、版型等。
- **CSS 规则的基本结构**：CSS 规则由两个主要部分组成：选择器和声明块。选择器是 CSS 中用于识别和定位特定 HTML 元素以应用样式的模式。声明块为给定的选择器或选择器组应用一组样式。

## 使用 `width` 和 `height` 属性

- **`width` 属性**：此属性指定元素的宽度。如果你没有指定宽度，则默认值为 `auto`。这允许浏览器根据元素的内容、父元素和显示类型来确定元素的宽度。
- **`min-width` 属性**：此属性指定元素的最小宽度。
- **`max-width` 属性**：此属性指定元素的最大宽度。
- **`height` 属性**：此属性指定元素的高度。同样，高度默认值为 `auto`，意味着它会根据内部内容自动调整。
- **`min-height` 属性**：此属性指定元素的最小高度。
- **`max-height` 属性**：此属性指定元素的最大高度。

## 内联、块和内联块级元素

- **内联级元素**：内联元素只占据它们所需的宽度，不会另起一行。这些元素在内容中流动，允许文本和其他内联元素并排显示。常见的内联元素有 `span`、`a` 和 `img` 元素。
- **块级元素**：块级元素默认占据其容器的全部可用宽度，横跨容器的宽度。常见的块级元素有 `div`、`p` 和 `section` 元素。
- **内联块级元素**：你可以通过使用 `display` 属性将元素设置为 `inline-block`。这些元素表现得像内联元素，但可以像块级元素一样设置 `width` 和 `height`。

## 外边距和内边距

- **`margin` 属性**：该属性用于在元素外部、元素边框和周围元素之间设置空间。
- **`margin` 简写**：你可以指定 1-4 个值来设置各个外边距。 一个值适用于所有四边；两个值设置的先是 `top` 和 `bottom`，然后是 `right` 和 `left`；三个值设置的先是 `top`、水平的边（`right` 和 `left`），然后是 `bottom`；四个值依次设置的是 `top`、`right`、`bottom`、`left`。
- **`padding` 属性**：该属性用于在元素内部的内容和边框之间设置空间。
- **`padding` 简写**：你可以指定 1-4 个值来设置各个内边距。 一个值适用于所有四边；两个值设置的先是 `top` 和 `bottom`，然后是 `right` 和 `left`；三个值设置的先是 `top`、水平的边（`right` 和 `left`），然后是 `bottom`；四个值依次设置的是 `top`、`right`、`bottom`、`left`。

## 背景图像

- **`background-image` 属性**：此属性用于为元素设置背景图像。
- **`background-size` 属性**：此属性设置背景图像的大小。`contain` 值会将图像缩放到尽可能大，但不会裁剪或拉伸图像。`cover` 值会将图像缩放以覆盖整个元素，同时保持其宽高比，可能会裁剪图像的一部分。
- **`background-repeat` 属性**：默认情况下，背景图像会在水平和垂直方向重复以填充元素。`no-repeat` 值阻止图像重复，`repeat-x` 在水平方向重复，`repeat-y` 在垂直方向重复。
- **`background-position` 属性**：此属性设置背景图像在元素内的位置。你可以使用关键字如 `top`、`bottom`、`left`、`right` 和 `center`，也可以使用像素或百分比值。
- **`background-attachment` 属性**：此属性决定背景图像是随内容滚动还是固定不动。默认值是 `scroll`，而 `fixed` 会使图像在页面滚动时保持在屏幕上的相同位置。
- **`background` 简写属性**：此属性允许你将多个背景属性（如 `background-image`、`background-position` 和 `background-attachment`）合并为一个声明。

## 边框

- **`border` 属性**：这是一个简写属性，用于一次性设置边框的宽度、样式和颜色。常见的边框样式包括 `solid`、`dashed`、`dotted` 和 `double`。
- **单独的边框边**：`border-top`、`border-right`、`border-bottom` 和 `border-left` 属性允许你分别为边框的每一边设置样式。
- **`outline` 属性**：此属性在元素周围创建一条线，类似于边框。与 `border` 不同，`outline` 不影响元素的尺寸或布局。
- **`border-radius` 属性**：此属性用于创建元素边框的圆角。

## CSS 优先级

- **内联 CSS 特异性**：内联 CSS 具有最高的特异性，因为它直接应用于元素。它会覆盖任何内部或外部 CSS。内联样式的特异性值为 (1, 0, 0, 0)。
- **内部 CSS 特异性**：内部 CSS 定义在 HTML 文档 `head` 部分的 `style` 元素中。它的特异性低于内联样式。内部和外部 CSS 具有相同的特异性级别，特异性由选择器决定，而非位置。
- **外部 CSS 特异性**：外部 CSS 通过 `head` 部分的 `link` 元素链接，写在单独的 `.css` 文件中。与内部 CSS 一样，其特异性由所用选择器决定。当两个规则特异性相同时，源代码顺序决定优先级：文档中后出现的规则优先。外部 CSS 对大型项目提供最佳的维护性。
- **通用选择器 (`*`)**：这是一种特殊的 CSS 选择器，匹配文档中的任何元素。它常用于为页面上的所有元素应用样式，有助于重置或规范不同浏览器的样式。通用选择器的特异性值最低，为 (0, 0, 0, 0)。
- **类型选择器**：这些选择器根据标签名定位元素。类型选择器的特异性相对较低，特异性值为 (0, 0, 0, 1)。
- **类选择器**：这些选择器由一个点号（`.`）后跟类名定义。类选择器的特异性值为 (0, 0, 1, 0)，意味着类选择器可以覆盖类型选择器，但会被 ID 选择器和内联样式覆盖。
- **ID 选择器**：ID 选择器由井号（`#`）后跟 ID 名称定义。ID 选择器具有非常高的特异性，高于类型选择器和类选择器，但低于内联样式。ID 选择器的特异性值为 (0, 1, 0, 0)。
- **`!important` 关键字**：用于赋予样式规则最高优先级，允许它覆盖该属性的任何其他声明。使用时会强制浏览器应用指定样式，无视其他选择器的特异性。使用 `!important` 时应谨慎，因为它可能使 CSS 更难维护和调试。

## 绝对单位

- **`px`（像素）**：这是 CSS 中的绝对单位，是固定大小的测量单位，提供对尺寸的精确控制。1px 始终等于 1/96 英寸。
- **`in`（英寸）**：该绝对单位等于 96px。
- **`cm`（厘米）**：该绝对单位等于 25.2/64 英寸。
- **`mm`（毫米）**：该绝对单位等于 1/10 厘米。
- **`q`（四分之一毫米）**：该绝对单位等于 1/40 厘米。
- **`pc`（派卡）**：该绝对单位等于 1/6 英寸。
- **`pt`（点）**：该绝对单位等于 1/72 英寸。

## 相对单位

- **百分比**：这些相对单位允许你将尺寸、维度和其他属性定义为其父元素的比例。例如，如果你为一个元素设置了 `width: 50%;`，它将占据其父容器宽度的一半。
- **`em` 单位**：这些单位相对于元素的字体大小。如果你在 `font-size` 属性中使用 `ems`，文本的大小将相对于父元素的字体大小。
- **`rem` 单位**：这些单位相对于根元素的字体大小，即 `html` 元素。
- **`vh` 单位**：`vh` 代表 `"viewport height"`，`1vh` 等于视口高度的 1%。
- **`vw` 单位**：`vw` 代表 `"viewport width"`，`1vw` 等于视口宽度的 1%。

## `calc` 函数

- **`calc()` 函数**：使用 `calc()` 函数，你可以直接在样式表中执行计算，动态确定属性值。 这意味着，你可以根据视口尺寸或其他元素计算尺寸，创建灵活的响应式用户界面。

## 伪类

- **伪类定义**：这些是特殊的 CSS 关键字，允许你根据元素的特定状态或位置选择元素。
- **`:active` 伪类**：此伪类让你选择元素的激活状态，比如点击按钮时。
- **`:hover` 伪类**：此伪类定义元素的悬停状态。
- **`:focus` 伪类**：当元素获得焦点时（通常通过键盘导航或用户点击表单输入），此伪类应用样式。
- **`:first-child` 伪类**：选择父元素或文档中的第一个元素。
- **`:last-child` 伪类**：选择父元素或文档中的最后一个元素。
- **`:first-of-type` 伪类**：选择父元素中某种特定元素类型的第一个出现。
- **`:last-of-type` 伪类**：选择父元素中某种特定元素类型的最后一个出现。
- **`:nth-of-type(n)` 伪类**：允许你根据同类型兄弟元素中的位置选择特定元素。
- **`:visited` 伪类**：选择用户已访问的链接。
- **`:enabled` 伪类**：用于选择当前启用的表单按钮或其他元素。
- **`:disabled` 伪类**：让你为禁用状态的交互元素设置样式。
- **`:checked` 伪类**：用于指示元素已被选中。

## 伪元素

- **`::before` 伪元素**：该伪元素使用 `content` 属性在元素前插入图标等装饰内容。
- **`::after` 伪元素**：该伪元素使用 `content` 属性在元素后插入图标等装饰内容。
- **`::first-letter` 伪元素**：该伪元素的目标是元素内容的第一个字母，允许你对其进行样式设置。
- **`::marker` 伪元素**：该伪元素能让你选择列表项的标记（项目符号或编号）进行样式设置。

## 在 CSS 中使用颜色的不同方法

- **命名颜色**：这些颜色是浏览器识别的预定义颜色名称。示例包括 `blue`、`darkred`、`lightgreen`。
- **`rgb()` 函数**：RGB 代表红、绿、蓝，是光的三原色。这三种颜色以不同强度组合，创造出丰富的颜色。`rgb()` 函数允许你使用 RGB 颜色模型定义颜色。
- **`rgba()` 函数**：此函数增加了第四个值 alpha，用于控制颜色的透明度。
- **`hsl()` 函数**：HSL 代表色相、饱和度和亮度，是定义颜色的三个关键组成部分。
- **`hsla()` 函数**：此函数增加了第四个值 alpha，用于控制颜色的不透明度。
- **十六进制**：十六进制代码（简称 hex）是一个六字符字符串，用于表示 RGB 颜色模型中的颜色。“hex” 指的是基数为 16 的数字系统，使用数字 0 到 9 和字母 A 到 F。

## `box-shadow` 属性

- **定义**：`box-shadow` 属性用于在元素周围应用一个或多个阴影。
- **偏移值**：必须指定水平（`offset-x`）和垂直（`offset-y`）偏移值。正的 `offset-x` 将阴影向右移动，负值向左移动。正的 `offset-y` 将阴影向下移动，负值向上移动。如果值为 `0`，则无需包含单位。
- **模糊半径**：此可选值控制阴影的模糊程度。如果未包含，默认为 `0`，产生锐利边缘。值越大，阴影越柔和。
- **扩散半径**：此可选值控制阴影的扩展或收缩程度。如果未包含，默认为 `0`。
- **阴影颜色**：你可以使用命名颜色、十六进制值、`rgb()`、`rgba()`、`hsl()` 或 `hsla()` 函数指定颜色。

## 梯度

- **线性渐变**：这些渐变沿直线创建颜色的渐变混合。你可以控制这条线的方向和使用的颜色。

## CSS 变换属性

- **定义**：此属性允许你对元素应用各种变换，如旋转、缩放、倾斜或在二维或三维空间中平移（移动）。
- **`rotate()` 函数**：此函数用于围绕元素中心旋转元素。

## 盒模型

- **定义**：在 CSS 盒模型中，每个元素都被一个盒子包围。 这个盒子由四个部分组成：内容区域、`padding`、`border`、`margin`。
- **内容区域**：内容区域是盒子的最内层部分。 它是包含文本或图像等元素实际内容的空间。
- **`padding`**：内边距是紧邻内容区域的部分。 它是内容区域与元素边框之间的空间。
- **`border`**：边框是元素在盒模型中的最外层轮廓。 这是元素的视觉边界。
- **`margin`**：外边距是元素边框之外的空间。 用于控制该元素与周围其他元素之间的距离。

## `content-box` 和 `border-box` 属性值

- **`box-sizing` 属性**：此属性用于确定 HTML 元素的总 `width` 和 `height` 如何计算。
- **`content-box` 值**：在 `content-box` 模型中，你为元素设置的 `width` 和 `height` 决定内容区域的尺寸，但不包括 `padding` 和 `border`。
- **`border-box` 值**：使用 `border-box` 时，你为元素设置的 `width` 和 `height` 包括内容区域、`padding` 和 `border`。

## CSS 滤镜属性

- **定义**：此属性可用于创建各种效果，如模糊。
- **`blur()` 函数**：此函数为元素应用模糊效果。模糊量以像素为单位，表示模糊半径。

## CSS Flexbox 和 Flex 模型简介

- **定义**：CSS flexbox 是一种一维版型模型，允许你在容器内按行或列排列元素。
- **Flex 模型**：此模型定义了 flex 容器内 flex 项的排列方式。每个 flex 容器有两个轴：主轴和交叉轴。

## `flex-direction` 属性

- **定义**：此属性设置主轴的方向。`flex-direction` 的默认值是 `row`，将所有 flex 项放在同一行，方向与浏览器默认语言方向一致（从左到右或从右到左）。
- **`flex-direction: row-reverse;`**：此设置会反转行内项目的顺序。
- **`flex-direction: column;`**：此设置将 flex 项垂直排列，而非水平。
- **`flex-direction: column-reverse;`**：此设置会垂直反转 flex 项的顺序。

## `flex-wrap` 属性

- **定义**：该属性决定了弹性容器内的弹性项目如何换行以适应可用空间。`flex-wrap` 可取三个值：`nowrap`、`wrap` 和 `wrap-reverse`。
- **`flex-wrap: nowrap;`**：这是默认值。即使弹性项目宽度超过容器宽度，也不会换行。
- **`flex-wrap: wrap;`**：当弹性项目宽度超过容器宽度时，该属性会使项目换行。
- **`flex-wrap: wrap-reverse;`**：该属性使弹性项目以相反顺序换行。
- **`flex-flow` 属性**：这是 `flex-direction` 和 `flex-wrap` 的简写属性。

## `justify-content` 属性

- **定义**：此属性沿着弹性容器的主轴对齐子元素。
- **`justify-content: flex-start;`**：在这种分支中，弹性项将对齐到主轴的起点。这可以是水平或垂直方向。
- **`justify-content: flex-end;`**：在这种情况下，弹性项沿主轴的末端对齐，水平或垂直方向。
- **`justify-content: center;`**：这会将弹性项沿主轴居中。
- **`justify-content: space-between;`**：这将沿主轴均匀分布元素。
- **`justify-content: space-around;`**：这将在主轴内均匀分布弹性项，在第一个项之前和最后一个项之后添加空白。
- **`justify-content: space-evenly;`**：这会沿主轴均匀分布这些项。

## `align-items` 属性

- **定义**：此属性用于沿交叉轴分布项。请记住，交叉轴垂直于主轴。
- **`align-items: center;`**：用于沿交叉轴居中这些项。
- **`align-items: flex-start;`**：这将项对齐到交叉轴的起点。
- **`align-items: stretch;`**：用于沿交叉轴拉伸弹性项。

## CSS `font-family` 属性

- **定义**：字体族是一组共享通用设计的字体。 属于同一字体族的所有字体均基于同一核心字型，但它们的风格、粗细和宽度会有所变化。 你可以通过逗号分隔，按优先级从高到低指定多个字体族。 这些备用字体将作为回退选项。 你应始终在字体族列表末尾包含一个通用字体族。
- **常见字体族**：以下是 CSS 中使用的一些常见字体族：serif、sans-serif、monospace、cursive、fantasy。

## 使用不同的属性选择器和链接

- **定义**: 通过 `attribute` 选择器，你可以根据 HTML 元素的属性来定位这些元素，如 `href` 或 `title` 属性。

## 不同类型的 CSS 组合选择器

- **后代组合器（` `）*选择器间的单个空格**：此组合器用于选择指定父元素的所有后代元素。
- **子组合器（`>`）**：此组合器用于选择指定父元素的直接子元素。
- **相邻兄弟组合器（`+`）**：此组合器选择紧跟在指定兄弟元素之后的元素。
- **通用兄弟组合器（`~`）**：此组合器选择指定元素之后的所有兄弟元素。

## 静态、相对和绝对定位

- **静态定位**：这是文档的正常流。元素按从上到下、从左到右的顺序依次定位。
- **相对定位**：允许你使用 `top`、`left`、`right` 和 `bottom` 属性在正常文档流程中定位元素。 你还可以使用相对定位来使元素与页面上的其他元素重叠。
- **绝对定位**：允许你将一个元素从正常的文档流程中分离出来，使其行为独立于其他元素。

## 固定和粘性定位

- **固定定位**：当元素使用 `position: fixed` 定位时，它会从正常的文档流中移除，并相对于视口定位，这意味着即使用户滚动页面，元素也会保持在相同位置。通常用于需要始终可见的元素，如头部或导航栏。
- **粘性定位**：这种定位方式是相对定位和固定定位的混合体。最初，元素表现得像相对定位，保持在文档流中。但当用户滚动到一定位置后，元素会“粘”在视口（通常是顶部），表现得像固定定位。这非常适合创建粘性导航栏，只有当用户滚动到特定位置时才变为固定。

## 使用 `z-index` 属性

- **定义**：CSS 中的 `z-index` 属性用于控制页面上堆叠的已定位元素的垂直顺序。

## 媒体查询

- **定义**：媒体查询允许开发人员根据设备的特性，主要是视口宽度，应用不同的样式。

## CSS 自定义属性（CSS 变量）

- **定义**：CSS 自定义属性，也称为 CSS 变量，是由 CSS 作者定义的实体，包含可在整个文档中重复使用的特定值。它们是一个强大的功能，允许创建更高效、易维护且灵活的样式表。自定义属性在创建可主题化设计时尤其有用。你可以为不同主题定义一组属性。

## CSS Grid 基础

- **定义**：CSS Grid 是一种二维版型系统，用于创建网页中的复杂版型。网格包含行和列，并且它们之间有间隙。要定义网格版型，你需要将 `display` 属性设置为 `grid`。
- **`fr`（分数）单位**：该单位表示网格容器内空间的一部分。你可以使用 `fr` 单位来创建灵活的网格。
- **创建轨道间隙**：在 CSS 网格中，有三种方法可以创建轨道间隙。你可以使用 `column-gap` 属性来创建列间隙。你可以使用 `row-gap` 属性来创建行间隙。或者你可以使用 `gap` 简写属性来同时创建行和列的间隙。
- **`repeat()` 函数**：该函数用于重复轨道列表中的部分。你可以用 `repeat()` 函数替代写法 `grid-template-columns: 1fr 1fr 1fr;`。
- **显式网格**：你可以使用 `grid-template-columns` 或 `grid-template-rows` 属性来指定线或轨道的数量。
- **隐式网格**：当项放置在网格外时，浏览器会自动为这些外部元素创建行和列。
- **`minmax()` 函数**：该函数用于设置轨道的最小和最大尺寸。
- **网格自动布局**：浏览器使用自动布局算法自动放置项。`grid-auto-flow` 属性控制此行为，使用 `row`、`column` 或 `dense` 等值来影响放置方向以及是否回填空隙。
- **基于线的放置**：所有网格都有线。要指定项在某条线上的起始位置，可以使用 `grid-column-start` 和 `grid-row-start` 属性。要指定项在某条线上的结束位置，可以使用 `grid-column-end` 和 `grid-row-end` 属性。你也可以选择使用 `grid-column` 或 `grid-row` 简写属性。
- **`grid-template-areas`**：该属性用于为你将在网格上定位的项提供名称。
- **对齐**：使用 `justify-items` 和 `align-items` 控制项在其网格区域内的对齐方式。使用 `justify-self` 和 `align-self` 在单个网格项上覆写容器设置的对齐。
