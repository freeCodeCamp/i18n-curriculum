# --description--

До цього моменту ви використовували `re.search`, щоб шукати шаблон у будь-якому місці рядка. Модуль `re` має багато інших функцій, які працюють із регулярними виразами. У цьому уроці ви дізнаєтеся про деякі з найкорисніших.

## Функція `match`

Функція `match` працює як `search`, але вона шукає шаблон лише на початку рядка. Вона повертає об’єкт збігу, якщо початок рядка відповідає шаблону, і `None` в іншому випадку:

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

У другому прикладі рядок містить цифри, тому `re.search` їх знайде. Але рядок не починається з цифр, тому `re.match` повертає `None`.

## Функція `fullmatch`

Шаблон `r'\d+:\d+'` відповідає одному або більше цифрам, за якими слідує двокрапка і ще одна або більше цифр. Це форма часу, наприклад `10:30`.

Уявіть, що ви хочете перевірити, чи є вхідні дані користувача часом і нічим іншим. Якщо ви використаєте `re.search`, виникне проблема:

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

Це повертає об’єкт збігу, хоча `10:30pm` не відповідає очікуваному формату. Це тому, що `re.search` шукає шаблон у будь-якому місці рядка і ігнорує будь-які додаткові символи навколо збігу. `re.match` матиме ту ж проблему, бо `10:30pm` починається з дійсного часу.

Коли ви перевіряєте дані, зазвичай хочете, щоб увесь рядок відповідав шаблону. Для цього можна використати функцію `fullmatch`. Вона повертає об’єкт збігу лише тоді, коли шаблон співпадає з усім рядком, і `None` в іншому випадку:

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## Функція `findall`

`search`, `match` і `fullmatch` повертають не більше одного збігу. Якщо ви хочете знайти всі збіги в рядку, використовуйте функцію `findall`. Вона повертає список рядків із усіма знайденими збігами:

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

Якщо збігів немає, `findall` повертає порожній список:

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## Функція `sub`

Функція `sub` замінює кожен збіг шаблону іншим рядком. Вона приймає шаблон, рядок для заміни та рядок для пошуку, і повертає новий рядок:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub` також має два необов’язкові параметри. Перший — `count`, який обмежує кількість замінених збігів:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

Другий — `flags`. Як і інші функції, `sub` може використовувати прапорці, наприклад `re.IGNORECASE`:

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

Завжди передавайте `count` і `flags` як ключові аргументи. Якщо передати `re.IGNORECASE` як четвертий позиційний аргумент, Python сприйме його як значення `count`.
