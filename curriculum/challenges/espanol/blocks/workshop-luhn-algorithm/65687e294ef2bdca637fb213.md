# --description--

Sea `n` el número de caracteres en la cadena del número de tarjeta de entrada. Tu implementación tiene **complejidad temporal O(n)**. Traducir y revertir la cadena toma tiempo lineal. Crear los segmentos de posiciones impares y pares también toma tiempo lineal, y los dos ciclos juntos procesan cada dígito una vez. Sumar estas operaciones lineales sigue dando O(n).

Completa tu validador devolviendo si `total` es divisible por `10`.

def is_valid_card_number(card_number):
    card_translation = str.maketrans({'-': '', ' ': ''})
    card_number = card_number.translate(card_translation)

    sum_of_odd_digits = 0
    card_number_reversed = card_number[::-1]
    odd_digits = card_number_reversed[::2]

    for digit in odd_digits:
        sum_of_odd_digits += int(digit)

    sum_of_even_digits = 0
    even_digits = card_number_reversed[1::2]
    for digit in even_digits:
        number = int(digit) * 2
        if number >= 10:
            number = (number // 10) + (number % 10)
        sum_of_even_digits += number
    total = sum_of_odd_digits + sum_of_even_digits
