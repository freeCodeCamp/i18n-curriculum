# --description--

Wakati mwingine nambari ni nzuri kwa ajili ya mahesabu yako lakini inaonekana haijakamilika unapoichapisha. Ikiwa unaonyesha bei, kwa mfano, `12.50` inaweza kuonekana ya kawaida zaidi kuliko `12.5`.

F-string inakuwezesha kudhibiti jinsi nambari inavyoonekana unapoionyesha, bila kubadilisha thamani halisi, hivyo unaweza kuendelea kuitumia katika mahesabu.

## Jinsi Maelezo ya Muundo Hufanya Kazi

Usemi wa kihesabu `f"{value:.2f}"` unaonyesha `value` na nambari mbili kamili baada ya nukta ya desimali.

Ndani ya mabano, kila herufi ina jukumu maalum:

- Nukta mbili `:` huanzisha maelezo ya muundo
- `.2` huchagua nafasi mbili za desimali
- `f` huchagua muonekano wa fixed-point, unaoonyesha nambari kwa noti ya desimali.

Hii inamaanisha `print(f"{12.5:.2f}")` hutengeneza `12.50`, huku ikiacha thamani ya awali isiyobadilika:

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

Matokeo yanaonyesha `12.50` kwa sababu maelezo ya muundo `.2f` yanaonyesha daima nafasi mbili za desimali, hivyo Python huongeza sifuri mwishoni. Thamani iliyohifadhiwa katika `value` bado ni `12.5`.


Kwa upande mwingine, kuunda muundo kwa thamani kama `12.3456` kwa `.2f` hutengeneza `12.35`, kwa sababu nambari lazima ipunguzwe kwa ajili ya kuonyeshwa:

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## Kuunda Muundo kwa F-String Hutengeneza Mfuatano wa Herufi

F-string hutengeneza mfuatano wa herufi:

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

Hii inamaanisha unaweza kuhifadhi mfuatano wa herufi uliotokana kando na bado kutumia nambari halisi katika mahesabu.

## Jinsi `round()` Inavyotofautiana na Kuunda Muundo wa F-String

Usemi wa kihesabu kama `round(value, 2)` hukupa matokeo ya nambari ambayo unaweza kuitumia katika mahesabu zaidi.

Kuchapisha matokeo hayo hutumia muonekano wa kawaida wa nambari wa Python, hivyo sifuri za mwisho hazihakikishwi:

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## Kuunda Muundo Hakubadilishi Thamani ya Msingi

Kama ulivyoona awali, baadhi ya nambari za desimali kama `0.1` na `0.2` zinaweza tu kukadiriwa kama floats. Kwa hiyo, jumla yao inaweza kuonekana ya kushangaza kidogo unapoichapisha moja kwa moja:

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

Kama unavyoona, f-string hupunguza jumla kwa ajili ya kuonyeshwa. Hesabu yoyote inayotumia `total` bado inatumia thamani ile ile ya floating-point.
