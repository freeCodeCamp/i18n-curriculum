# --description--

## Warum Python lokal installieren?

Für alle Workshops und Labs verwenden Sie den Python-Editor von freeCodeCamp. Es ist jedoch wichtig, zu lernen, wie man Python auf dem eigenen Rechner einrichtet.

## Python herunterladen

Der einfachste Weg, Python auf Windows und Mac zu installieren, ist das Herunterladen des Installationsprogramms von der offiziellen Python-Website. Später in dieser Lektion gehen wir auch darauf ein, wie man Python unter Linux ausführt.

Gehen Sie zu `https://www.python.org/` und fahren Sie mit der Maus über „Downloads“. Ein Fenster erscheint, das die aktuelle Version von Python für Ihr Betriebssystem (OS) anzeigt.

## Python auf macOS installieren

Zuerst erklären wir, wie Sie Python auf einem Computer mit macOS installieren:

- Klicken Sie auf die Schaltfläche mit der aktuellen Python-Version (aus dem vorherigen Modal), und der Download einer `.pkg`-Installationsdatei startet automatisch.
- Sobald der `.pkg`-Installer heruntergeladen ist, öffnen Sie ihn und klicken im sich öffnenden Fenster auf „Weiter“.
- Klicken Sie weiter auf die Schaltfläche „Weiter“, bis Sie zum Abschnitt „Installationstyp“ gelangen. Dort klicken Sie auf die Schaltfläche „Installieren“.
- Geben Sie bei Bedarf Ihr Passwort ein und starten Sie die Installation.
- Wenn die Paketinstallation abgeschlossen ist, sollten Sie eine Meldung sehen, dass Python erfolgreich installiert wurde.
- Öffnen Sie den neu erstellten Python-Ordner in Ihrem Anwendungsordner.
- Doppelklicken Sie auf die Datei `Install Certificates.command` und lassen Sie den Terminalprozess abschließen.
- Überprüfen Sie, ob im Terminalfenster `Successfully installed certifi` und `update complete` angezeigt werden.
- Schließen Sie das Terminalfenster und klicken Sie im Installationsfenster auf „Schließen“. Ihre Einrichtung ist jetzt abgeschlossen!

## Die Installation überprüfen

Sie können die Installation überprüfen, indem Sie Ihr Terminal öffnen und `python --version` oder `python3 --version` ausführen.

Sie können den Python-Interpreter auch öffnen, indem Sie im Terminal `python` oder `python3` ausführen. Ein Python-Interpreter ist ein Programm, das Python-Code liest, ihn in Anweisungen übersetzt, die der Computer versteht, und diese Anweisungen ausführt.

## Was ist ein Terminal?

Ein <dfn>Terminal</dfn> ist eine textbasierte Schnittstelle, mit der Sie durch Eingabe von Befehlen mit Ihrem Computer interagieren können. Jedes Betriebssystem verfügt über eine Standard-Terminal-App. Unter macOS können Sie die Terminal-App verwenden. Unter Windows können Sie die Eingabeaufforderung oder PowerShell nutzen. Unter Linux hat jede Desktop-Umgebung ihre eigene Standard-Terminal-App, wie GNOME Terminal oder Konsole.

## Verwendung von `python` vs. `python3`

Beachten Sie, dass auf einigen älteren macOS- und Linux-Systemen `python` für Python 2 reserviert sein kann, während `python3` speziell für Python 3 ist. Wenn Sie `python --version` ausführen und eine Python-2-Version wie `Python 2.7.18` sehen, ist es möglich, dass Ihr Betriebssystem auf Software angewiesen ist, die in der älteren Python-Version geschrieben wurde. In diesem Fall sollten Sie `python3` verwenden, um Ihren Python-Code künftig auszuführen. Python 2 ist am Ende seines Lebenszyklus und sollte für keine neue Entwicklung mehr verwendet werden.

## Python auf Windows installieren

Um Python unter Windows zu installieren, gehen Sie wie folgt vor:

- Gehen Sie zu `https://www.python.org/` und fahren Sie mit der Maus über „Downloads“. Es sollte ein Modal erscheinen, das „Download für Windows“ anzeigt, sowie eine Schaltfläche zum Herunterladen der aktuellen Python-Version.
- Klicken Sie auf die Versionsnummer, und der Download des Python Install Managers (`.msix`-Paket) startet automatisch.
- Sobald der Python Install Manager heruntergeladen ist, doppelklicken Sie darauf und wählen „Installieren“.
- Nach der Installation sollten die Befehle `python`, `py` und `pymanager` verfügbar sein. Wenn keine Python-Laufzeit installiert ist, wird durch Ausführen von `python` automatisch eine installiert.
- Beim ersten Installieren einer Laufzeit werden Sie möglicherweise aufgefordert, ein Verzeichnis zu Ihrem `PATH` hinzuzufügen, um zusätzliche Aliase wie `python3.14.exe` zu verwenden. Akzeptieren Sie diese optionale Aufforderung, wenn Sie diese Aliase nutzen möchten.


Sie können die Installation überprüfen, indem Sie eine Befehlszeilenschnittstelle wie PowerShell öffnen und `python --version` ausführen. Sie können den Python-Interpreter auch öffnen, indem Sie `python` ausführen.

## Python auf Linux installieren

Für Python unter Linux sind die meisten großen Distributionen wie Ubuntu, Debian und Fedora bereits mit Python ausgestattet.

Öffnen Sie einfach ein Terminal und führen Sie `python --version` oder `python3 --version` aus.

Wenn keiner der Befehle eine Python-3-Version anzeigt, können Sie auf `https://www.python.org` nach einem Installationspaket für Ihre Linux-Distribution suchen oder online nach der empfohlenen Methode zur Installation von Python für Ihre Distribution suchen.
