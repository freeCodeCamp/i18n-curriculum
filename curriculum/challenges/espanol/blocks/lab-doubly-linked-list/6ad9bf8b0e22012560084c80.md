# --description--

En este laboratorio, construirás una lista doblemente enlazada, donde cada nodo mantiene una referencia tanto al nodo siguiente como al anterior en la lista.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

**Historias de usuario:**

1. Debes tener una clase llamada `DoublyLinkedList`.
1. `DoublyLinkedList` debe tener una clase anidada llamada `Node`, cuyo método `__init__` debe:
   - recibir un parámetro `element` y un parámetro opcional `previous` que por defecto es `None`.
   - asignar el atributo `element` con el valor del parámetro `element`.
   - asignar el atributo `previous` con el valor del parámetro `previous`.
   - asignar el atributo `next` a `None`.
1. El método `__init__` de `DoublyLinkedList` debe asignar el atributo `length` a `0`, y los atributos `head` y `tail` a `None`.
1. `DoublyLinkedList` debe tener un método `is_empty` que devuelva `True` si la lista no tiene nodos, y `False` en caso contrario.
1. `DoublyLinkedList` debe tener un método `add` que reciba un `element` y:
   - cree un nuevo `Node` que contenga ese `element` y lo agregue al final de la lista.
   - asigne el atributo `previous` del nuevo nodo al nodo que era el tail antes de la adición, o `None` si la lista estaba vacía.
   - actualice el `head` (cuando la lista estaba vacía), el `tail` y la `length` de la lista.
   - no recorra la lista para encontrar su final.
1. `DoublyLinkedList` debe tener un método `remove` que reciba un `element` y:
   - elimine todos los nodos cuyo `element` sea igual al `element` dado.
   - mantenga correctamente enlazadas las referencias `next` y `previous` de los nodos restantes.
   - actualice el `head`, el `tail` y la `length` de la lista cuando sea necesario.
   - deje la lista sin cambios si ningún nodo coincide o si la lista está vacía.
1. `DoublyLinkedList` debe tener un método `reverse` que invierta el orden de los nodos en el lugar.
1. `DoublyLinkedList` debe tener un método `to_list` que devuelva una lista con los elementos de la lista enlazada, desde el `head` hasta el `tail`.

class DoublyLinkedList:
    class Node:
        def __init__(self, element, previous=None):
            self.element = element
            self.previous = previous
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None
        self.tail = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element, self.tail)
        if self.is_empty():
            self.head = node
        else:
            self.tail.next = node
        self.tail = node
        self.length += 1

    def remove(self, element):
        current_node = self.head
        while current_node is not None:
            next_node = current_node.next
            if current_node.element == element:
                if current_node.previous is not None:
                    current_node.previous.next = current_node.next
                else:
                    self.head = current_node.next
                if current_node.next is not None:
                    current_node.next.previous = current_node.previous
                else:
                    self.tail = current_node.previous
                self.length -= 1
            current_node = next_node

    def reverse(self):
        current_node = self.head
        while current_node is not None:
            current_node.previous, current_node.next = current_node.next, current_node.previous
            current_node = current_node.previous
        self.head, self.tail = self.tail, self.head

    def to_list(self):
        elements = []
        current_node = self.head
        while current_node is not None:
            elements.append(current_node.element)
            current_node = current_node.next
        return elements
