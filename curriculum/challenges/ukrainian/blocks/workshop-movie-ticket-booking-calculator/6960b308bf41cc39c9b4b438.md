# --description--

Оператор `or` використовується, щоб перевірити, чи є істинною принаймні одна з двох умов. Ось як ви можете його використати з порівнянням в інструкції `if`:

```py
day = 'Sunday'
is_raining = False

if day == 'Sunday' or is_raining:
    print('Stay at home')
```

У наведеному вище прикладі виводиться `Stay at home`, тому що перша умова істинна, навіть якщо `is_raining` має значення `False`.

Додаткові збори також мають застосовуватися у вихідні. Оновіть умову в рядку `if show_time == 'Evening':`, використовуючи оператор `or`, щоб поєднати існуючу умову з другою, яка перевіряє, чи є `is_weekend` істинним.
