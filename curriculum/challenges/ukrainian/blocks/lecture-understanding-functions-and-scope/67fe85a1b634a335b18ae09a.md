# --description--

Область видимості визначає, де ви можете використовувати змінну у своєму коді.

У Python є додаткові правила області видимості. Наразі зосередьтеся на локальній та глобальній області видимості.

Змінна, створена поза функцією, має глобальну область видимості. Ви можете використовувати її як всередині, так і поза функціями.

Змінна, створена всередині функції, має локальну область видимості. Ви можете використовувати її лише всередині цієї функції. Параметри функції також є локальними змінними.

Ось приклад локальної та глобальної області видимості:

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

Змінна `tax_rate` є глобальною, бо вона створена поза функцією. Функція `calculate_tax` може її читати, і другий виклик `print()` також може її читати.

Параметр `price` і змінна `tax` є локальними для `calculate_tax`. Вони доступні, поки ця функція виконується, але не поза нею. Останній виклик `print()` викликає `NameError`, бо `tax` не визначена в глобальній області видимості.
