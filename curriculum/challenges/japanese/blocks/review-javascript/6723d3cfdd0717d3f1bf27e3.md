# --interactive--

次の準備試験に備えて、以下の概念を復習してください。

## HTML、CSS、JavaScriptの扱い方

HTMLとCSSはウェブサイトの構造を提供しますが、JavaScriptはユーザー入力の処理、要素のアニメーション、さらには完全なウェブアプリケーションの構築など、複雑な機能を可能にしてウェブサイトにインタラクティブ性をもたらします。

## JavaScriptのデータ型

データ型は、プログラムが扱うデータの種類（数値、テキストなど）を理解するのに役立ちます。

- **Number**: 数値は整数と浮動小数点の両方を表します。整数の例には7、19、90があります。 
- **Floating point**: 浮動小数点数は小数点を含む数値です。例は3.14、0.5、0.0001です。
- **String**: 文字列は引用符で囲まれた文字やテキストの並びです。`"I like coding"` と `'JavaScript is fun'` は文字列の例です。
- **Boolean**: ブール値は`true` または `false` のいずれかの値を表します。条件を表すのに使えます。例えば`isLoggedIn = true` のように。
- **Undefined and Null**: `undefined` は宣言されたが値が代入されていない変数の値です。`null` は空の値、つまり意図的に`null` が代入された変数の値です。
- **Object**: オブジェクトはキーと値のペアの集合です。キーはプロパティ名、値はプロパティの値です。

例えば、`{ name: "Fluffy", age: 3, type: "dog" }` は3つのプロパティ、`name`、`age`、`type` を持っています。

- **Symbol**: Symbolデータ型はオブジェクトのプロパティの識別子として使える、ユニークで不変の値です。

同じ説明で作成された2つのシンボルは、それでも別々の値です。

- **BigInt**: 数値が`Number` データ型で扱えないほど大きい場合、BigIntデータ型を使って任意の長さの整数を表せます。

数値の末尾に`n` を付けることでBigIntを作成できます。

## JavaScriptの変数

- 変数は`let` キーワードを使って宣言できます。

- 変数に値を代入するには、代入演算子`=` を使います。

- `let` を使って宣言された変数は新しい値に再代入できます。

- `let` 以外に`const` も変数宣言に使えます。ただし、`const` 変数は再代入できません。

- `const` を使って宣言された変数は、コード全体で変更が許されない定数の宣言に使われます。例えば`PI` や `MAX_SIZE` などです。

## 変数名の慣例

- 変数名は説明的で意味のあるものにしてください。
- 変数名は`cityName`、`isLoggedIn`、`veryBigNumber` のようにキャメルケースにしてください。
- 変数名は数字で始めてはいけません。文字、`_`、`$` で始める必要があります。
- 変数名にスペースや特殊文字は使えません。ただし`_` と `$` は例外です。
- 変数名は予約語にしてはいけません。
- 変数名は大文字と小文字を区別します。`age` と `Age` は別の変数です。

## JavaScriptの文字列と文字列の不変性

- 文字列は引用符で囲まれた文字の並びです。シングルクォートと二重引用符の両方で作成できます。

- JavaScriptの文字列は不変です。つまり、一度作成された文字列の文字を変更できません。ただし、新しい値に再代入することは可能です。

## JavaScriptの文字列連結

- 連結は複数の文字列を結合したり、文字列とテキストを保持する変数を組み合わせる処理です。`+` 演算子は文字列連結で最も簡単でよく使われる方法の一つです。

- 既存の文字列に追加や追記をしたい場合は、`+=` 演算子を使えます。これは時間をかけて文字列にテキストを追加したいときに便利です。

- 文字列を連結する別の方法として`concat()` メソッドがあります。このメソッドは2つ以上の文字列を結合します。

## `console.log()` でのメッセージのログ出力

- `console.log()` メソッドはコンソールにメッセージをログ出力するために使います。コードのデバッグやテストに役立つツールです。

## JavaScriptのセミコロン

- セミコロンは主に文の終わりを示すために使います。これによりJavaScriptエンジンは個々の命令の区切りを理解し、正しい実行が可能になります。

- セミコロンはコード実行の曖昧さを防ぎ、文が正しく終了していることを保証します。

## JavaScriptのコメント

- コメントアウトされたコード行はJavaScriptエンジンに無視されます。コメントはコードの説明、メモ、または一時的にコードを無効にするために使います。
- 一行コメントは`//` を使って作成します。

- 複数行コメントは`/*` で開始し、`*/` で終了します。

## 動的型付け言語としてのJavaScript

- JavaScriptは動的型付け言語であり、変数を宣言するときにデータ型を指定する必要はありません。JavaScriptエンジンが変数に代入された値に基づいて自動的にデータ型を判断します。

- C#のような静的型付け言語では、文字列を整数変数に代入するとエラーになります。

## `typeof` 演算子の使用

- `typeof` 演算子は変数のデータ型をチェックするために使います。変数の型を示す文字列を返します。

- しかし、JavaScriptには`null` に関してよく知られた癖があります。`typeof` 演算子は`null` の値に対して`"object"` を返します。

## 文字列の基本

- **定義**: 文字列はシングルクォート、ダブルクォート、またはバックティックで囲まれた文字の並びです。文字列はプリミティブなデータ型であり、不変です。不変とは、一度作成された文字列は変更できないことを意味します。 
- **文字列からの文字のアクセス**: 文字列の文字にアクセスするにはブラケット記法を使い、インデックス番号を渡します。インデックスは文字列内の文字の位置で、ゼロベースです。

- **`\n`（改行文字）**: `\n` 改行文字を使って文字列内に改行を作成できます。

- **文字列のエスケープ**: 文字列内の文字をエスケープするには、引用符の前にバックスラッシュ（`\`）を置きます。

:::interactive_editor

```js
const statement = "She said, \"Hello!\"";
console.log(statement); // She said, "Hello!"
```

:::

## テンプレートリテラル（テンプレート文字列）と文字列の補間

- **定義**: テンプレートリテラルはバックティック（`）で定義されます。変数を文字列内に直接埋め込む文字列補間という機能を含み、文字列操作が簡単になります。

:::interactive_editor

```js
const name = "Jessica";
const greeting = `Hello, ${name}!`; 
console.log(greeting); // "Hello, Jessica!"
```

:::

## ASCII、`charCodeAt()` メソッドと`fromCharCode()` メソッド

- **ASCII**: ASCII（American Standard Code for Information Interchange）は、基本的な英字を数値で表す文字コードの標準です。以前のレッスンでは、ASCIIの例を使って`charCodeAt()` と `fromCharCode()` を紹介しました。
- **Unicode**: JavaScriptの文字列は内部的にUnicode、特にUTF-16エンコーディングを使っています。最初の128文字（基本ラテン文字、数字、一般的な記号）については、Unicodeの値はASCIIコードと一致します。だからASCIIベースの例がJavaScriptでも動作します。
- **`charCodeAt()` メソッド**: このメソッドは指定したインデックスの文字のUTF-16コードユニットを返します。基本ラテン文字の場合、この値はASCIIコードと一致します。

- **`fromCharCode()` メソッド**: このメソッドはASCIIコードを対応する文字に変換します。

## その他の一般的な文字列メソッド

- **`indexOf` メソッド**: このメソッドは文字列内で部分文字列を検索します。部分文字列が見つかると、`indexOf` はその最初の出現位置のインデックスを返します。見つからなければ`indexOf` は-1を返し、検索が失敗したことを示します。

- **`includes()` メソッド**: このメソッドは文字列が特定の部分文字列を含むかどうかをチェックします。含まれていればtrue、そうでなければfalseを返します。

- **`slice()` メソッド**: このメソッドは文字列の一部を抽出して新しい文字列を返します。元の文字列は変更されません。開始インデックスと省略可能な終了インデックスの2つのパラメータを取ります。

- **`toUpperCase()` メソッド**: このメソッドはすべての文字を大文字に変換し、大文字のみの新しい文字列を返します。

- **`toLowerCase()` メソッド**: このメソッドは文字列内のすべての文字を小文字に変換します。

- **`replace()` メソッド**: このメソッドは文字列内の指定した値（単語や文字など）を別の値に置き換えます。新しい文字列を返し、元の文字列は変更しません。これはJavaScriptの文字列が不変であるためです。

- **`replaceAll()` メソッド**: このメソッドは文字列内の指定した値（単語、文字、またはパターン）のすべての出現箇所を見つけて別の値に置き換えます。`replace()` と似ていますが、最初の一致で止まらず、文字列内のすべての一致を更新します。

- **`repeat()` メソッド**: このメソッドは文字列を指定回数繰り返します。

- **`trim()` メソッド**: このメソッドは文字列の先頭と末尾の空白を削除します。

- **`trimStart()` メソッド**: このメソッドは文字列の先頭（開始位置）の空白を削除します。

- **`trimEnd()` メソッド**: このメソッドは文字列の末尾の空白を削除します。

- **`prompt()` メソッド**: `window` のこのメソッドは、ダイアログボックスの形でユーザーから情報を取得します。このメソッドは2つの引数を取ります。1つ目はダイアログボックス内に表示されるメッセージで、通常はユーザーに情報入力を促します。2つ目は省略可能なデフォルト値で、入力フィールドに初期表示されます。

## Numberデータ型の扱い方

- **定義**: JavaScriptの`Number` 型には整数、浮動小数点数、`Infinity`、`NaN` が含まれます。浮動小数点数は小数点を含む数値です。正の`Infinity` は他のどの数値よりも大きい数で、`-Infinity` は他のどの数値よりも小さい数です。`NaN`（`Not a Number`）は文字列`"Jessica"` のような無効な数値を表します。

## 一般的な算術演算

- **加算演算子**: この演算子（`+`）は、2つ以上の数値の合計を計算するために使います。
- **減算演算子**: この演算子（`-`）は、2つの数値の差を計算するために使います。
- **乗算演算子**: この演算子（`*`）は、2つ以上の数値の積を計算するために使います。
- **除算演算子**: この演算子（`/`）は、2つの数値の商を計算するために使います。
- **ゼロ除算**: 0で割ろうとすると、JavaScriptは`Infinity`を返します。
- **剰余演算子**: この演算子（`%`）は、割り算の余りを返します。
- **べき乗演算子**: この演算子（`**`）は、ある数値を別の数値のべき乗にします。

## 数値と文字列の計算

- **説明**: `+`演算子を数値と文字列で使うと、JavaScriptは数値を文字列に変換して両者を連結します。`-`、`*`、`/`演算子を文字列と数値で使うと、JavaScriptは文字列を数値に変換し、結果は数値になります。`null`と`undefined`の場合、JavaScriptは数学的演算で`null`を0として扱い、`undefined`を`NaN`として扱います。

## 演算子の優先順位

- **定義**: 演算子の優先順位は式の中でどの順番で演算が評価されるかを決めます。優先順位が高い演算子は低いものより先に評価されます。括弧内の値は最初に評価され、乗算・除算は加算・減算より優先されます。もし演算子の優先順位が同じ場合は、JavaScriptは結合規則を使います。

- **定義**: 結合性は、同じ種類の複数の演算子が存在する場合に式がどの方向に評価されるかを示します。式が左から右（`left-associative`）に評価されるか、右から左（`right-associative`）に評価されるかを定義します。例えば、べき乗演算子は右から左の結合性を持ちます。

## インクリメントとデクリメント演算子

- **インクリメント演算子**: この演算子は値を1増やします。接頭辞表記`++num` は変数の値を先に増やしてから新しい値を返します。後置表記`num++` は現在の値を先に返してから増やします。

- **デクリメント演算子**: この演算子は値を1減らします。接頭辞表記と後置表記はインクリメント演算子と同様に動作します。

## 複合代入演算子

- **加算代入（`+=`）演算子**: この演算子は値の加算を行い、その結果を変数に代入します。
- **減算代入（`-=`）演算子**: この演算子は値の減算を行い、その結果を変数に代入します。
- **乗算代入（`*=`）演算子**: この演算子は値の乗算を行い、その結果を変数に代入します。
- **除算代入（`/=`）演算子**: この演算子は値の除算を行い、その結果を変数に代入します。
- **剰余代入（`%=`）演算子**: この演算子は変数を指定した数で割り、その余りを変数に代入します。
- **べき乗代入（`**=`）演算子**: この演算子は変数を指定した数のべき乗にし、その結果を再代入します。

## ブール値と等価性

- **ブール値の定義**: ブール値は`true` または `false` の2つの値しか持てないデータ型です。 
- **等価（`==`）演算子**: この演算子は値が等しいかをチェックする前に型変換を行います。

- **厳密等価（`===`）演算子**: この演算子は型変換を行わず、型と値の両方が等しいかをチェックします。

- **不等価（`!=`）演算子**: この演算子は値が等しくないかをチェックする前に型変換を行います。
- **厳密不等価（`!==`）演算子**: この演算子は型変換を行わず、型と値の両方が等しくないかをチェックします。

## 比較演算子

- **より大きい（`>`）演算子**: 左側の値が右側より大きいかをチェックします。
- **以上（`>=`）演算子**: 左側の値が右側以上かをチェックします。
- **より小さい（`<`）演算子**: 左側の値が右側より小さいかをチェックします。
- **以下（`<=`）演算子**: 左側の値が右側以下かをチェックします。

## 単項演算子

- **単項プラス演算子**: この演算子はオペランドを数値に変換します。すでに数値なら変更しません。

- **単項マイナス（`-`）演算子**: この演算子はオペランドの符号を反転させます。

- **論理否定（`!`）演算子**: この演算子はオペランドのブール値を反転させます。オペランドが`true` なら`false` に、`false` なら`true` になります。

## ビット演算子

- **ビットAND（`&`）演算子**: この演算子は両方のオペランドの対応するビットが1の位置に1を返します。 
- **ビットAND代入（`&=`）演算子**: この演算子は指定した数で`bitwise AND` 演算を行い、結果を変数に再代入します。
- **ビットOR（`|`）演算子**: この演算子はどちらかまたは両方のオペランドの対応するビットが1の位置に1を返します。 
- **ビットOR代入（`|=`）演算子**: この演算子は指定した数で`bitwise OR` 演算を行い、結果を変数に再代入します。
- **ビットXOR（`^`）演算子**: この演算子はどちらか一方のオペランドの対応するビットが1の位置に1を返します（両方は除く）。 
- **ビットNOT（`~`）演算子**: この演算子は数値の2進数表現を反転させます。
- **左シフト（`<<`）演算子**: この演算子はすべてのビットを指定した数だけ左にシフトします。 
- **右シフト（`>>`）演算子**: この演算子はすべてのビットを右にシフトします。

## 条件文、真値、偽値、三項演算子

- **`if/else if/else`**: `if` 文は条件を取り、その条件が`truthy` の場合にコードブロックを実行します。条件が`false` の場合は`else if` ブロックに移ります。どの条件も`true` でなければ`else` 節を実行します。`Truthy` 値は`if` 文のようなブール文脈で`true` になる値です。`Falsy` 値はブール文脈で`false` になる値です。

:::interactive_editor

```js
const score = 87;

if (score >= 90) {
 console.log('You got an A'); 
} else if (score >= 80) {
 console.log('You got a B'); // You got a B
} else if (score >= 70) {
 console.log('You got a C');
} else {
 console.log('You failed! You need to study more!');
}
```

:::

- **三項演算子**: この演算子は`if else` 文を短く書くためによく使われます。

:::interactive_editor

```js
const temperature = 30;
const weather = temperature > 25 ? 'sunny' : 'cool';

console.log(`It's a ${weather} day!`); // It's a sunny day!
```

:::

## 二項論理演算子

- **論理AND（`&&`）演算子**: この演算子は両方のオペランドが`true`かをチェックします。両方が`true`なら2番目の値を返します。どちらかのオペランドが`falsy`なら`falsy`値を返します。両方が`falsy`なら最初の`falsy`値を返します。

- **論理OR（`||`）演算子**: この演算子は少なくとも1つのオペランドが真値かをチェックします。 
- **Nullish合体演算子（`??`）**: この演算子は最初の値が`null`または`undefined`の場合のみ値を返します。

## `Math` オブジェクト

- **`Math.random()` メソッド**: このメソッドは0（含む）から1（含まない）までのランダムな浮動小数点数を生成します。つまり0は出る可能性がありますが、1には決して達しません。
- **`Math.max()` メソッド**: このメソッドは複数の数値の中から最大値を返します。
- **`Math.min()` メソッド**: このメソッドは複数の数値の中から最小値を返します。
- **`Math.ceil()` メソッド**: このメソッドは値を最も近い大きい整数に切り上げます。
- **`Math.floor()` メソッド**: このメソッドは値を最も近い小さい整数に切り捨てます。
- **`Math.round()` メソッド**: このメソッドは値を最も近い整数に四捨五入します。

- **`Math.trunc()` メソッド**: このメソッドは数値の小数部分を切り捨て、整数部分だけを返します（丸めはしません）。
- **`Math.sqrt()` メソッド**: このメソッドは数値の平方根を返します。
- **`Math.cbrt()` メソッド**: このメソッドは数値の立方根を返します。
- **`Math.abs()` メソッド**: このメソッドは数値の絶対値を返します。
- **`Math.pow()` メソッド**: このメソッドは2つの数値を取り、1つ目の数値を2つ目の数値のべき乗にします。

## 一般的な数値メソッド

- **`isNaN()`**: `NaN` は「Not-a-Number」を表します。これは表現できないか未定義の数値結果を示す特別な値です。`isNaN()` 関数プロパティは値が `NaN` かどうかを判定するために使われます。`Number.isNaN()` は、特に型変換によってグローバルの `isNaN()` 関数で予期しない結果が生じる場合に、`NaN` 値をより確実にチェックする方法を提供します。

- **`parseFloat()` メソッド**: このメソッドは文字列の引数を解析し、浮動小数点数を返します。文字列の先頭から数値を抽出するよう設計されており、後半に数値以外の文字があっても問題ありません。
- **`parseInt()` メソッド**: このメソッドは文字列の引数を解析し、整数を返します。`parseInt()` は最初に出会った数字以外の文字で解析を停止します。浮動小数点数の場合は整数部分のみを返します。文字列の先頭に有効な整数が見つからない場合は `NaN` を返します。
- **`toFixed()` メソッド**: このメソッドは数値に対して呼び出され、1つのオプション引数（小数点以下の桁数）を取ります。指定された小数点以下の桁数で数値の文字列表現を返します。

## 比較と `null` および `undefined` データ型

- **比較と `undefined`**: 変数が `undefined` であるとは、宣言はされたが値が代入されていない状態を指します。これは初期化されていない変数や引数が渡されなかった関数パラメータのデフォルト値です。`undefined` は数値コンテキストで `NaN` に変換されるため、`undefined` との数値比較はすべて `false` になります。

- **`null` と比較**: `null` 型は値が意図的に存在しないことを表します。`null` は数値コンテキストでは `0` に変換されるため、数値比較で予期しない動作を引き起こす場合があります。例えば、`null >= 0` は `true` ですが、`null > 0` は `false` です。

- 等値演算子（`==`）を使う場合、`null` と `undefined` はお互いと自分自身にのみ等しいです。

- しかし、型変換を行わずに値と型の両方を比較する厳密等値演算子（`===`）を使う場合、`null` と `undefined` は等しくありません。

## `switch` 文

- **定義**: `switch` 文は式を評価し、その値を一連の `case` 節と照合します。マッチが見つかると、そのケースに関連付けられたコードブロックが実行されます。各ケースの最後には `break` 文を置いて、その実行を終了し次に進む必要があります。`default` ケースは任意のケースで、他のケースにマッチしなかった場合のみ実行されます。`default` ケースは `switch` 文の最後に置かれます。

:::interactive_editor

```js
const dayOfWeek = 3; 

switch (dayOfWeek) {
  case 1:
    console.log("It's Monday! Time to start the week strong.");
    break;
  case 2:
    console.log("It's Tuesday! Keep the momentum going.");
    break;
  case 3:
    console.log("It's Wednesday! We're halfway there.");
    break;
  case 4:
    console.log("It's Thursday! Almost the weekend.");
    break;
  case 5:
    console.log("It's Friday! The weekend is near.");
    break;
  case 6:
    console.log("It's Saturday! Enjoy your weekend.");
    break;
  case 7:
    console.log("It's Sunday! Rest and recharge.");
    break;
  default:
    console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

:::

## JavaScript 関数

- 関数は特定のタスクを実行する再利用可能なコードのブロックです。
- 関数は`function`キーワードの後に名前、パラメータのリスト、そしてタスクを実行するコードのブロックを続けて定義できます。

:::interactive_editor

```js
function addNumbers(x, y, z) {
  return x + y + z;
}

console.log(addNumbers(5, 3, 8)); // Output: 16
```

:::

- 引数は関数が呼び出されるときに渡される値です。
- 関数呼び出しとは、関数の名前の後に丸括弧を付けて、必要に応じて丸括弧内に引数を含めてプログラム内で関数を実行するプロセスです。
- 関数が実行を終えると、必ず戻り値を返します。
- デフォルトでは、関数の戻り値は`undefined`です。
- `return`キーワードは関数から返す値を指定し、関数の実行を終了させます。
- デフォルトパラメータは、関数が呼び出されたときに引数が渡されなかった場合に使われるあらかじめ定義された値を関数に持たせることができます。これにより関数がより柔軟になり、特定の引数が省略された場合のエラーを防げます。

:::interactive_editor

```js
const calculateTotal = (amount, taxRate = 0.05) => {
  return amount + (amount * taxRate);
};

console.log(calculateTotal(100)); // Output: 105
```

:::

- 無名関数は名前を持たない関数で、変数に代入できます。変数に代入することで、その変数がアクセス可能な場所ならどこでも再利用できます。

:::interactive_editor

```js
const multiplyNumbers = function(firstNumber, secondNumber) {
  return firstNumber * secondNumber;
};

console.log(multiplyNumbers(4, 5)); // Output: 20
```

:::

## アロー関数

- アロー関数はJavaScriptで関数を書くより簡潔な方法です。

- アロー関数を定義するときは`function`キーワードは不要です。
- パラメータが1つだけの場合、パラメータリストの丸括弧を省略できます。

- 関数本体が単一の式だけの場合、波括弧と`return`キーワードを省略できます。

:::interactive_editor

```js
const square = number => number * number;

console.log(square(5)); // Output: 25
```

:::

## プログラミングにおけるスコープ

- **グローバルスコープ**: これは JavaScript の最も外側のスコープです。グローバルスコープで宣言された変数はコードのどこからでもアクセスでき、グローバル変数と呼ばれます。
- **ローカルスコープ**: 関数内で宣言された変数を指します。これらの変数は宣言された関数内でのみアクセス可能で、ローカル変数と呼ばれます。
- **ブロックスコープ**: ブロックは波括弧（`{}`）で囲まれた文の集合で、`if` 文やループなどが該当します。
- `let` と `const` によるブロックスコープは変数のアクセス制御をさらに細かくし、エラー防止やコードの予測可能性向上に役立ちます。

## JavaScript 配列の基本

- **定義**: JavaScript の配列は、数値のインデックスで識別される値の順序付きコレクションです。配列内の値は数値、文字列、ブール値、オブジェクト、さらには他の配列など異なるデータ型を含めることができます。配列はメモリ上で連続して格納されているため、インデックスによる効率的なアクセスが可能です。

- **配列からの要素アクセス**: 配列の要素にアクセスするには、配列名の後に大括弧内にインデックス番号を指定します。JavaScript の配列はゼロベースのインデックスで、最初の要素はインデックス0、2番目はインデックス1です。存在しないインデックスにアクセスしようとすると、JavaScript は `undefined` を返します。

- **`length` プロパティ**: このプロパティは配列内のアイテム数を返します。

- **配列の要素更新**: 配列の要素を更新するには、代入演算子（`=`）を使って特定のインデックスの要素に新しい値を代入します。

## 二次元配列

- **定義**: 二次元配列は基本的に配列の配列です。チェス盤、スプレッドシート、画像のピクセルなど、格子状の構造を表現するのに使われます。二次元配列の要素にアクセスするには、行と列の2つのインデックスが必要です。

## 配列の分割代入

- **定義**: 配列の分割代入は、配列から値を抽出して変数に簡潔かつ読みやすく代入できる JavaScript の機能です。配列の要素を個別の変数に展開する便利な構文を提供します。

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange"];

const [first, second, third] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(third); // "orange"
```

:::

- **rest構文**: 分割代入されなかった残りの配列要素を新しい配列としてまとめることができます。

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange", "mango", "kiwi"];
const [first, second, ...rest] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(rest); // ["orange", "mango", "kiwi"]
```

:::

## 一般的な配列メソッド

- **`push()` メソッド**: このメソッドは配列の末尾に要素を追加し、新しい配列の長さを返します。

- **`pop()` メソッド**: このメソッドは配列の最後の要素を削除し、その削除した要素を返します。配列が空の場合は `undefined` を返します。

- **`shift()` メソッド**: このメソッドは配列の最初の要素を削除し、その削除した要素を返します。配列が空の場合は `undefined` を返します。

- **`unshift()` メソッド**: このメソッドは配列の先頭に要素を追加し、新しい配列の長さを返します。

- **`indexOf()` メソッド**: このメソッドは配列内の特定の要素の最初のインデックスを見つけるのに便利です。要素が見つからない場合は `-1` を返します。

- **`splice()` メソッド**: このメソッドは配列の任意の位置から要素を追加または削除します。`splice()` メソッドの戻り値は削除された要素の配列です。何も削除されなければ空の配列が返されます。このメソッドは元の配列を変更し、新しい配列は作成しません。最初の引数は配列の変更を開始するインデックス、2番目は削除する要素数、続く引数は追加する要素です。

- **`includes()` メソッド**: このメソッドは配列に特定の値が含まれているかをチェックします。指定した要素が含まれていれば `true` を返し、そうでなければ `false` を返します。

- **`concat()` メソッド**: このメソッドは2つ以上の配列を結合して新しい配列を作成します。

- **`slice()` メソッド**: このメソッドは元の配列の一部を指定した開始・終了インデックスで浅くコピーした新しい配列を返します。新しい配列は元の配列と同じ要素の参照を含みます（複製ではありません）。つまり、要素がプリミティブ（数値や文字列など）なら値がコピーされますが、要素がオブジェクトや配列の場合は参照がコピーされ、オブジェクト自体はコピーされません。

- **スプレッド構文**: スプレッド構文は配列の浅いコピーを作成するために使われます。

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const shallowCopiedArray = [...originalArray];

shallowCopiedArray.push(4);

console.log(originalArray); // [1, 2, 3]
console.log(shallowCopiedArray); // [1, 2, 3, 4]
```

:::

- **`split()` メソッド**: このメソッドは文字列を指定した区切り文字で分割し、部分文字列の配列を作成します。区切り文字が指定されない場合は、元の文字列を単一要素とする配列を返します。

- **`reverse()` メソッド**: このメソッドは配列をその場で逆順に並べ替えます。

- **`join()` メソッド**: このメソッドは配列のすべての要素を指定した区切り文字で連結して1つの文字列にします。区切り文字が指定されないか空文字（`""`）の場合は区切りなしで連結されます。

## オブジェクトの基本

- **定義**: オブジェクトはプロパティで構成されるデータ構造です。プロパティはキーと値から成ります。オブジェクトのデータにアクセスするには、ドット記法かブラケット記法を使います。

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  city: "New York"
};

console.log(person.name);  // Alice
console.log(person["name"]); // Alice
```

:::

既存のオブジェクトのプロパティを設定するには、ドット記法かブラケット記法と代入演算子を使います。

## オブジェクトからプロパティを削除する

- **`delete` 演算子**: この演算子はオブジェクトからプロパティを削除するために使います。

## オブジェクトにプロパティがあるか確認する

- **`hasOwnProperty()` メソッド**: このメソッドはオブジェクトが指定したプロパティを自身のプロパティとして持っているかどうかをブール値で返します。

- **`Object.hasOwn()` メソッド**: これはオブジェクトが自身のプロパティを持っているか（継承されたものではなく）を確認する、現代的で推奨される方法です。構文は `Object.hasOwn(object, propertyName)` です。プロパティがオブジェクトに存在すれば `true` を返し、存在しなければ `false` を返します。プロパティの値に関係なく判定されるため、`hasOwnProperty()` より安全で、値が `0`、`false`、`null`、`undefined` の場合でも `if (obj.prop)` より信頼性があります。

`Object.hasOwn()` は、値が `0`、`false`、または `undefined` のような偽値であっても、オブジェクト自身のプロパティを検出します。

- **`in` 演算子**: この演算子はオブジェクトにプロパティが存在すれば `true` を返します。

## ネストされたオブジェクトのプロパティにアクセスする

- **データアクセス**: ネストされたオブジェクトのプロパティにアクセスするには、単純なオブジェクトのプロパティアクセスと同様にドット記法かブラケット記法を使います。ただし、ネスト構造を掘り下げるためにこれらのアクセスをチェーンする必要があります。

## プリミティブ型と非プリミティブ型のデータ型

- **プリミティブ型データ**: これらのデータ型には数値、文字列、ブール値、`null`、`undefined`、シンボルが含まれます。これらは単一の値を表し、オブジェクトではないため「プリミティブ」と呼ばれます。プリミティブ値は不変で、一度作成されると値を変更できません。
- **非プリミティブ型データ**: JavaScript ではこれらはオブジェクトで、通常のオブジェクト、配列、関数が含まれます。プリミティブとは異なり、非プリミティブ型は複数の値をプロパティや要素として保持できます。

## オブジェクトメソッド

- **定義**: オブジェクトメソッドはオブジェクトに関連付けられた関数です。オブジェクトのプロパティとして定義され、オブジェクトのデータにアクセスし操作できます。メソッド内の `this` キーワードはオブジェクト自身を指し、そのプロパティにアクセス可能にします。

## オブジェクトコンストラクタ

- **定義**: JavaScript ではコンストラクタはオブジェクトを作成・初期化する特別な関数です。`new` キーワードで呼び出され、新しく作成されたオブジェクトのプロパティやメソッドを初期化できます。`Object()` コンストラクタは新しい空のオブジェクトを作成します。

## オプショナルチェーン演算子（`?.`）の使い方

- **定義**: この演算子は、存在するかどうかを気にせずにオブジェクトのプロパティに安全にアクセスしたりメソッドを呼び出したりできます。

:::interactive_editor

```ts
const user = {
  name: "John",
  profile: {
    email: "john@example.com",
    address: {
      street: "123 Main St",
      city: "Somewhere"
    }
  }
};

console.log(user.profile?.address?.street); // "123 Main St"
console.log(user.profile?.phone?.number);   // undefined
```

:::

## オブジェクトの分割代入

- **定義**: オブジェクトの分割代入は、オブジェクトから値を抽出して変数に簡潔かつ読みやすく代入できる機能です。

:::interactive_editor

```js
const person = { name: "Alice", age: 30, city: "New York" };

const { name, age } = person;

console.log(name); // Alice
console.log(age);  // 30
```

:::

## JSONの扱い方

- **定義**: JSON は JavaScript Object Notation の略で、サーバーとウェブアプリケーション間でデータを交換するためによく使われる軽量のテキストベースのデータ形式です。

- **`JSON.stringify()`**: このメソッドは JavaScript オブジェクトを JSON 文字列に変換します。データをシステム間で簡単に共有・転送したい場合に便利です。

- **`JSON.parse()`**: このメソッドは JSON 文字列を JavaScript オブジェクトに戻します。ウェブサーバーや localStorage から JSON データを取得し、アプリケーション内で操作したい場合に使います。

## ループの使い方

- **`for` ループ**: このループはコードブロックを指定回数繰り返すために使います。初期化文、条件、増減文の3つの部分に分かれています。初期化文はループ開始前に実行され、通常はカウンタ変数の初期化に使います。条件は各繰り返し前に評価されます。繰り返しはループを1回通過することです。条件が `true` の場合、ループ内のコードが実行されます。条件が `false` の場合、ループは停止し次のコードに進みます。増減文は各繰り返し後に実行され、通常はカウンタ変数の増減に使います。

:::interactive_editor

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

:::

- **`for...of` ループ**: このループはイテラブルの値を繰り返す必要があるときに使います。イテラブルの例は配列や文字列です。

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];

for (const num of numbers) {
  console.log(num);
}
```

:::

- **`for...in` ループ**: このループはオブジェクトのプロパティを繰り返すのに最適です。列挙可能なすべてのプロパティ（継承されたものや数値以外のプロパティも含む）を反復します。

:::interactive_editor

```js
const fruit = {
  name: 'apple',
  color: 'red',
  price: 0.99
};

for (const prop in fruit) {
  console.log(fruit[prop]);
}
```

:::

- **`while` ループ**: このループは条件が `true` の間、コードブロックを実行し続けます。

:::interactive_editor

```js
let i = 5;

while (i > 0) {
  console.log(i);
  i--;
}
```

:::

- **`do...while` ループ**: このループは条件をチェックする前に少なくとも1回はコードブロックを実行します。

```js
let userInput;

do {
  userInput = prompt("Please enter a number between 1 and 10");
} while (Number(userInput) < 1 || Number(userInput) > 10);

alert("You entered a valid number!");
```

## `break` と `continue` 文

- **定義**: `break` 文はループを早期に終了するために使い、`continue` 文は現在の繰り返しをスキップして次の繰り返しに進みます。

## String コンストラクタと `toString()` メソッド

- **定義**: 文字列オブジェクトは文字のシーケンスを表すために使います。文字列オブジェクトは `String` コンストラクタ関数で作成され、プリミティブ値をオブジェクトでラップします。

- **`toString()` メソッド**: このメソッドは値を文字列表現に変換します。数値、ブール値、配列、オブジェクトに使えます。

このメソッドはオプションの基数（2から36の数値）を受け入れます。この基数は基数を表し、例えば2は2進数、8は8進数です。基数が指定されない場合はデフォルトで10進数になります。

## Number コンストラクタ

- **定義**: `Number` コンストラクタは数値オブジェクトを作成します。数値オブジェクトは `isNaN` や `toFixed` メソッドなど便利なプロパティやメソッドを含みます。ほとんどの場合、他のデータ型を数値型に変換するために `Number` コンストラクタを使います。

## 変数と関数の命名に関するベストプラクティス

- **キャメルケース**: 慣例として、JavaScript 開発者は変数や関数の命名にキャメルケースを使います。キャメルケースは最初の単語がすべて小文字で、続く単語の先頭が大文字になる書き方です。例：`isLoading`。

- **ブール値の命名**: ブール変数には「is」「has」「can」などの接頭辞を使うのが一般的です。

- **関数の命名**: 関数名はその関数が何をするかを明確に示すべきです。ブール値を返す関数（述語関数）には「is」「has」「can」などの接頭辞を使えます。データを取得する関数は「get」で始めることが多く、データを設定する関数は「set」で始めることが多いです。イベントハンドラ関数は「handle」を接頭辞にしたり、「Handler」を接尾辞にしたりします。

- **ループ内の変数命名**: ループのイテレータ変数には `i`、`j`、`k` のような単一文字を使うのが一般的です。

## スパース配列の扱い方

- **定義**: 空のスロットを持つ配列を作ることが可能です。空のスロットとは何も入っていないスロットを指します。これは `undefined` の値を持つスロットとは異なります。このような配列はスパース配列と呼ばれます。

## リンターとフォーマッター

- **リンター**: リンターは静的コード解析ツールで、プログラミングエラー、バグ、スタイルの誤り、疑わしい構文を検出します。一般的なリンターの例は ESLint です。
- **フォーマッター**: フォーマッターはコードを特定のスタイルガイドに従って自動的に整形するツールです。一般的なフォーマッターの例は Prettier です。

## メモリ管理

- **定義**: メモリ管理はメモリを制御し、必要なときに割り当て、不要になったら解放するプロセスです。JavaScript は自動メモリ管理を使っています。つまり、JavaScript（特にウェブブラウザの JavaScript エンジン）がメモリの割り当てと解放を自動で行います。コード内で明示的にメモリを解放する必要はありません。この自動プロセスは「ガベージコレクション」と呼ばれます。

## クロージャ

- **定義**: クロージャは、外側の（囲んでいる）レキシカルスコープの変数にアクセスできる関数です。外側の関数が戻った後でもアクセス可能です。

:::interactive_editor

```js
function outerFunction(x) {
  let y = 10;
  function innerFunction() {
    console.log(x + y);
  }
  return innerFunction;
}

let closure = outerFunction(5);
closure(); // 15
```

:::

## `var` キーワードとホイスティング

- **定義**: `var` は2015年以前に変数を宣言するための元々の方法でした。しかし `var` にはスコープや再宣言などの問題がありました。そのため現代の JavaScript では `let` と `const` が使われています。
- **`var` での変数の再宣言**: `let` を使って変数を再宣言しようとすると `SyntaxError` が発生します。しかし `var` では変数の再宣言が許可されています。

- **`var` とスコープ**: `var` でブロック内（`if` 文や `for` ループなど）に宣言された変数は、そのブロックの外でもアクセス可能です。

- **ホイスティング**: これは JavaScript のデフォルトの動作で、コード実行前のコンパイル段階で宣言をそれぞれのスコープの先頭に移動させます。`var` キーワードで変数を宣言すると、その宣言はスコープの先頭にホイスティングされます。

関数宣言構文で関数を宣言すると、関数名と関数本体の両方がホイスティングされます。つまり、コード内で宣言前に関数を呼び出せます。

`let` または `const` で宣言された変数はホイスティングされますが初期化されず、コード内の実際の宣言前にアクセスできません。この動作は「一時的デッドゾーン」と呼ばれます。

## インポート、エクスポート、モジュールの操作

- **モジュール**: 関連する関数、クラス、変数をまとめた自己完結型のコード単位です。モジュールを作成するには、JavaScriptコードを別ファイルに書きます。
- **エクスポート**: アプリケーションの他の部分で使いたい変数、関数、クラスは、`export` キーワードを使って明示的にエクスポートする必要があります。エクスポートには名前付きエクスポートとデフォルトエクスポートの2種類があります。
- **インポート**: エクスポートされたものをアプリケーションの別の部分で使うには、`import` キーワードを使ってインポートします。インポートには名前付きインポート、デフォルトインポート、名前空間インポートがあります。

```js
// Within a file called math.js, we export the following functions:

// Named export
export function add(num1, num2) {
  return num1 + num2;
}

// Default export
export default function subtract(num1, num2) {
  return num1 - num2;
}

// Within another file, we can import the functions from math.js.

// Named import - This line imports the add function.
// The name of the function must exactly match the one exported from math.js.
import { add } from './math.js';

// Default import - This line imports the subtract function.
// The name of the function can be anything.
import subtractFunc from './math.js';

// Namespace import - This line imports everything from the file.
import * as Math from './math.js';

console.log(add(5, 3)); // 8
console.log(subtractFunc(5, 3)); // 2
console.log(Math.add(5, 3)); // 8
console.log(Math.subtract(5, 3)); // 2
```

## コールバック関数と`forEach`メソッド

- **定義**: JavaScriptにおけるコールバック関数とは、別の関数に引数として渡され、その外側の関数が特定のタイミングで呼び出す関数のことです。
- **`forEach()` メソッド**: このメソッドは配列の各要素を繰り返し処理し、各要素に対して操作を行うために使われます。`forEach` のコールバック関数は最大で3つの引数を受け取ることができ、現在の要素、現在の要素のインデックス、そして `forEach` が呼び出された配列が渡されます。

## 高階関数

- **定義**: 高階関数とは、引数として1つ以上の関数を受け取り、結果として関数または値を返す関数のことです。

- **`map()`メソッド**: このメソッドは、元の配列の各要素に指定した関数を適用して新しい配列を作成するために使われます。コールバック関数は最大3つの引数を受け取ることができ、現在の要素、現在の要素のインデックス、そして`map`が呼び出された配列です。

- **`filter()`メソッド**: このメソッドは、指定したテストに合格した要素だけを含む新しい配列を作成するために使われます。条件に基づいてアイテムを選択的に抽出するのに便利です。`map`メソッドと同様に、`filter`メソッドのコールバック関数も現在処理中の要素、インデックス、配列の3つの引数を受け取ります。

- **`reduce()`メソッド**: このメソッドは配列を処理して単一の値にまとめるために使われます。この単一の値は数値、文字列、オブジェクト、または別の配列である場合があります。`reduce()`メソッドは配列の各要素に順番に関数を適用し、各計算結果を次に渡していきます。この関数はしばしばリデューサ関数と呼ばれます。リデューサ関数は主に2つのパラメータを取ります：アキュムレータ（累積値）と現在の値です。アキュムレータは処理の途中結果を保存し、現在の値は処理中の配列要素です。

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce(
  (accumulator, currentValue) => accumulator + currentValue,
  0
);

console.log(sum); // 15
```

:::

## メソッドチェーン

- **定義**: メソッドチェーンは、同じオブジェクトに対して複数のメソッドを1行で連続して呼び出すプログラミング手法です。この手法は、同じオブジェクトに対する一連の操作を行う際にコードをより読みやすく簡潔にします。

## `sort`メソッドの操作

- **定義**: `sort`メソッドは配列の要素をソートし、ソート済みの配列への参照を返します。この場合、コピーは作成されず、要素はその場でソートされます。

数値をソートする必要がある場合は、比較関数を渡す必要があります。`sort`メソッドは要素を文字列に変換し、それらのUTF-16コード単位のシーケンスを比較します。UTF-16コード単位は文字列内の文字を表す数値です。例えば、65、66、67はそれぞれ文字「A」、「B」、「C」を表します。したがって、配列内で数値の200は3より前に現れます。これは文字列「200」が文字列「3」よりUTF-16コード単位の比較で先に来るためです。

:::interactive_editor

```js
const numbers = [414, 200, 5, 10, 3];

numbers.sort((a, b) => a - b);

console.log(numbers); // [3, 5, 10, 200, 414]
```

:::

パラメータ`a`と`b`は比較される2つの要素です。比較関数は、`a`が`b`より前に来るべき場合は負の値を返し、`a`が`b`より後に来るべき場合は正の値を返し、`a`と`b`が等しい場合は0を返すべきです。

## `every`と`some`メソッドの操作

- **`every()`メソッド**: このメソッドは配列内のすべての要素が、提供された関数によるテストに合格するかどうかを判定します。`every()`メソッドは、提供された関数が配列のすべての要素に対して`true`を返した場合に`true`を返します。もし1つでも要素がテストに失敗した場合、メソッドは即座に`false`を返し、残りの要素のチェックを停止します。

- **`some()`メソッド**: このメソッドは少なくとも1つの要素がテストに合格するかどうかをチェックします。`some()`メソッドは、テストに合格する要素を見つけた時点で`true`を返します。もし合格する要素がなければ`false`を返します。

## DOMとWeb APIの操作

- **API**: API（アプリケーションプログラミングインターフェース）は、ソフトウェアアプリケーション同士が効率的に通信しデータを交換するためのルールとプロトコルのセットです。
- **Web API**: Web APIはウェブアプリケーション向けに特化されたAPIです。これらのAPIは主にブラウザAPIとサードパーティAPIの2つに分けられます。
- **ブラウザAPI**: これらのAPIはブラウザからデータを公開します。ウェブ開発者はJavaScriptを使ってこのデータにアクセスし操作できます。
- **サードパーティAPI**: これらはデフォルトではブラウザに組み込まれていません。コードを何らかの方法で取得する必要があります。通常、サービスの使い方を説明した詳細なドキュメントがあります。例として、Google Maps APIがあり、ウェブサイトにインタラクティブな地図を表示できます。
- **DOM**: DOMはDocument Object Modelの略で、HTMLドキュメントとやり取りするためのプログラミングインターフェースです。DOMを使うと、ウェブページの要素を追加、変更、削除できます。DOMツリーのルートは`html`要素で、HTMLドキュメントのすべてのコンテンツの最上位コンテナです。その他のノードはすべてこのルートノードの子孫です。ルートノードの下には階層的に他のノードがあります。親ノードは他の要素を含む要素で、子ノードは他の要素に含まれる要素です。
- **`navigator`インターフェース**: ブラウザ環境に関する情報（ユーザーエージェント文字列、プラットフォーム、ブラウザのバージョンなど）を提供します。ユーザーエージェント文字列は使用中のブラウザとOSを識別するテキスト文字列です。
- **`window`インターフェース**: DOMドキュメントを含むブラウザウィンドウを表します。ウィンドウのサイズ変更、新しいウィンドウの開閉、異なるURLへの移動などの操作に使うメソッドやプロパティを提供します。

## `querySelector()`、`querySelectorAll()`、`getElementById()`メソッドの操作

- **`getElementById()`メソッド**: 指定した`id`を持つHTML要素を表すオブジェクトを取得するために使います。idはHTMLドキュメント内で一意でなければならないため、このメソッドは1つのElementオブジェクトだけを返します。

- **`querySelector()`メソッド**: 引数として渡されたCSSセレクターに一致するHTMLドキュメント内の最初の要素を取得するために使います。

- **`querySelectorAll()`メソッド**: 指定したCSSセレクターに一致するすべてのDOM要素のリストを取得するために使います。

## `innerText()`、`innerHTML()`、`createElement()`、`textContent()`メソッドの操作

- **`innerHTML`プロパティ**: `Element`のプロパティで、HTMLマークアップの一部を設定または更新するために使います。

- **`createElement`メソッド**: HTML要素を作成するために使います。

- **`innerText`**: HTML要素とその子孫の可視テキストコンテンツを表します。

- **`textContent`**: 要素のプレーンテキストコンテンツを返します。子孫のすべてのテキストを含みます。

## `appendChild()`と`removeChild()`メソッドの操作

- **`appendChild()`メソッド**: 指定した親ノードの子リストの末尾にノードを追加するために使います。

- **`removeChild()`メソッド**: DOMからノードを削除するために使います。

## `setAttribute()`メソッドの操作

- **定義**: このメソッドは指定した要素の属性を設定します。属性がすでに存在する場合は値を更新し、存在しなければ新しい属性を値付きで追加します。

## イベントオブジェクト

- **定義**: `Event`オブジェクトは、ユーザーがウェブページと何らかの形でやり取りしたときに発生するペイロードです。これらのやり取りは、ボタンのクリックや入力へのフォーカス、モバイルデバイスの振動など多岐にわたります。すべての`Event`オブジェクトは`type`プロパティを持ちます。このプロパティは、keydownやclickなど、ペイロードを発生させたイベントの種類を示します。これらの値は`addEventListener()`に渡す値と対応しており、そこで`Event`オブジェクトをキャプチャして利用できます。

## `addEventListener()`と`removeEventListener()`メソッド

- **`addEventListener`メソッド**: イベントを監視するために使います。2つの引数を取り、1つ目は監視したいイベント、2つ目はイベント発生時に呼び出される関数です。よくあるイベント例はクリックイベント、入力イベント、変更イベントです。

:::interactive_editor

```html
<button id="btn">Click Me</button>
<script src="./index.js"></script>
```

```js
const btn = document.getElementById("btn");

btn.addEventListener("click", () => alert("You clicked the button"));
```

:::

- **`removeEventListener()`メソッド**: 以前に`addEventListener()`メソッドで追加したイベントリスナーを削除するために使います。特定のイベントの監視を停止したい場合に便利です。

- **インラインイベントハンドラ**: インラインイベントハンドラは、イベント発生時にJavaScriptコードを実行するためのHTML要素の特別な属性です。現代のJavaScriptでは、インラインイベントハンドラはベストプラクティスとは見なされていません。代わりに`addEventListener`メソッドを使うことが推奨されます。

## changeイベント

- **定義**: changeイベントは、ユーザーが特定の入力要素の値を変更したときに発火する特別なイベントです。例としては、チェックボックスやラジオボタンの選択、日付ピッカーやドロップダウンメニューからの選択などがあります。

## イベントバブリング

- **定義**: イベントバブリング（伝播）は、イベントが発生したときに親オブジェクトへ「バブルアップ」する仕組みを指します。
- **`stopPropagation()`メソッド**: このメソッドはイベントのさらなる伝播を防ぎます。

## イベントデリゲーション

- **定義**: イベントデリゲーションは、イベントがバブリングして親に届いたものを監視し、イベントを発生させた要素で直接処理するのではなく親で処理する方法です。

## DOMContentLoaded

- **定義**: `DOMContentLoaded`イベントは、HTMLドキュメントのすべてが読み込みと解析を終えたときに発火します。外部スタイルシートや画像がある場合、`DOMContentLoaded`イベントはそれらの読み込みを待ちません。HTMLの読み込みだけを待ちます。

## `style`と`classList`の操作

- **`Element.style`プロパティ**: 読み取り専用のプロパティで、要素のインラインスタイルを表します。このプロパティを使って要素のスタイルを取得または設定できます。

- **`Element.classList`プロパティ**: 読み取り専用のプロパティで、要素のクラスを追加、削除、切り替えできます。

## `setTimeout()`と`setInterval()`メソッドの操作

- **`setTimeout()`メソッド**: 指定した時間だけ処理を遅延させるために使います。

- **`setInterval()`メソッド**: 指定した間隔でコードを繰り返し実行します。`setInterval()`は指定した間隔で関数を実行し続けるため、停止したい場合は`clearInterval()`メソッドを使います。

## `requestAnimationFrame()`メソッド

- **定義**: このメソッドは、次の画面の再描画前にアニメーションの次のステップをスケジュールできるため、滑らかで視覚的に魅力的な体験を実現します。次の画面の再描画とは、ブラウザがウェブページの表示を更新する瞬間のことで、通常は1秒間に約60回（60フレーム/秒）発生します。

## Web Animations API（ウェブアニメーションAPI）

- **定義**: Web Animations APIは、JavaScript内で直接アニメーションを作成・制御できる機能です。

## Canvas API

- **定義**: Canvas APIは、JavaScriptファイル内でグラフィックスを操作できる強力なツールです。Canvas APIを使うには、まずHTMLに`canvas`要素を用意します。この要素は描画面として機能し、Canvas APIのインターフェースのインスタンスメソッドやプロパティで操作できます。このAPIには`HTMLCanvasElement`、`CanvasRenderingContext2D`、`CanvasGradient`、`CanvasPattern`、`TextMetrics`などのインターフェースがあり、JavaScriptファイル内でグラフィックスを作成するためのメソッドやプロパティを含みます。

## JavaScriptでダイアログとモーダルの開閉

- **モーダルとダイアログの定義**: ダイアログはユーザーに重要な情報や操作を表示するためのものです。HTMLの組み込みdialog要素を使うと、ウェブアプリで簡単にモーダルおよび非モーダルのダイアログを作成できます。モーダルダイアログは、ユーザーが他のアプリケーションやウェブページの部分にアクセスする前に必ず操作しなければならないダイアログです。一方、非モーダルダイアログは開いていても他の部分と引き続きやり取りでき、他のコンテンツへのアクセスを妨げません。
- **`showModal()`メソッド**: モーダルを開くために使います。

- **`close()`メソッド**: モーダルを閉じるために使います。

## よく使われる ARIA アクセシビリティ属性

- **`aria-expanded` 属性**: トグル（または開閉）機能の状態をスクリーンリーダーユーザーに伝えるために使われます。

- **`aria-haspopup` 属性**: この状態は、インタラクティブな要素がアクティブになるとポップアップ要素を呼び出すことを示すために使われます。`aria-haspopup` 属性は、ポップアップが次のいずれかの役割を持つ場合にのみ使用できます：`menu`、`listbox`、`tree`、`grid`、または `dialog`。`aria-haspopup` の値はこれらの役割のいずれか、または `true`（`menu` と同じ）でなければなりません。

- **`aria-checked` 属性**: 要素がチェックされた状態かどうかを示すために使われます。カスタムのチェックボックス、ラジオボタン、スイッチ、リストボックスを作成するときに最もよく使われます。

- **`aria-disabled` 属性**: この状態は、スクリーンリーダーなどの支援技術を使う人に対してのみ要素が無効であることを示すために使われます。

- **`aria-selected` 属性**: 要素が選択されていることを示すために使われます。タブ付きインターフェース、リストボックス、グリッドなどのカスタムコントロールで使うことができます。

- **`aria-controls` 属性**: 要素と、その要素が制御する別の要素を関連付けるために使われます。これにより支援技術を使う人が要素間の関係を理解しやすくなります。

- **`hidden` 属性**: 非アクティブなパネルを視覚的にも支援技術ユーザーにも隠します。

## ライブリージョンと動的コンテンツの扱い方

- **`aria-live` 属性**: ウェブページの一部をライブリージョンにし、そのエリア内の更新がスクリーンリーダーで読み上げられるようにして、ユーザーが重要な変更を見逃さないようにします。
- **`polite` の値**: ほとんどのライブリージョンはこの値を使います。この値は更新が緊急でないことを意味し、スクリーンリーダーは現在の読み上げやユーザーの操作が終わるまで待ってから更新を読み上げます。

JavaScriptで動的に更新されるライブリージョンの例です：

:::interactive_editor

```html
<div aria-live="polite" id="status"></div>

<button id="updateStatus">Update Status</button>

<script>
  const statusEl = document.getElementById("status");
  const btn = document.getElementById("updateStatus");

  btn.addEventListener("click", () => {
    statusEl.textContent = "Your file has been successfully uploaded.";
  });
</script>
```

:::

- **`contenteditable` 属性**: 要素をライブエディターに変え、ユーザーがテキストフィールドのように内容を更新できるようにします。contenteditable領域に目に見えるラベルや見出しがない場合は、`aria-label` 属性でアクセシブルな名前を付けて、スクリーンリーダーユーザーが編集可能なエリアの目的を理解できるようにしてください。

## `focus` と `blur` イベント

- **`blur` イベント**: 要素がフォーカスを失ったときに発火します。

- **`focus` イベント**: 要素がフォーカスを受け取ったときに発火します。

## よくあるエラーメッセージの種類

- **SyntaxError**: コード内で括弧やブラケットの閉じ忘れなど、文法的な誤りがある場合に発生します。文の文法ミスのようなものです。

- **ReferenceError**: いくつかの種類があり、異なる状況で発生します。最初のタイプは未定義の変数を参照した場合です。もう1つの例は、`let`や`const`で宣言された変数を定義前にアクセスしようとした場合です。

- **TypeError**: 間違った型に対して操作を行おうとした場合に発生します。

- **RangeError**: JavaScriptが扱える範囲外の値を使おうとした場合に発生します。

## `throw`文

- **定義**: JavaScriptの`throw`文は、ユーザー定義の例外をスローするために使います。プログラミングにおける例外とは、予期しない出来事が起きてプログラムの通常の流れが中断されることです。

## `try...catch...finally`

- **定義**: `try`ブロックはエラーが発生する可能性のあるコードを囲むために使います。安全に試すためのスペースとして機能します。`catch`ブロックはtryブロック内で発生したエラーをキャッチして処理します。catch内のエラーオブジェクトを使って何が問題だったか調べられます。`finally`ブロックはtryとcatchの後に実行され、エラーの有無にかかわらず実行されます。ファイルのクローズやリソースの解放などの後片付けに使われます。

:::interactive_editor

```js
function processInput(input) {
  if (typeof input !== "string") {
    throw new TypeError("Input must be a string.");
  }

  return input.toUpperCase();
}

try {
  console.log("Starting to process input...");
  const result1 = processInput("hello");
  console.log("Processed result:", result1);  // HELLO
  const result2 = processInput(9);  // throws TypeError
  console.log("Processed result:", result2);  // not executed
} catch (error) {
  console.error("Error occurred:", error.message);
} 
```

:::

## デバッグ手法

- **`debugger`文**: コードの特定の行で処理を一時停止し、プログラムの状態を調査できるようにします。

- **ブレークポイント**: 任意の行でコードの実行を一時停止できます。停止後、変数の値を調べたり式を評価したり、コールスタックを確認できます。
- **ウォッチャー**: ウォッチ式は、現在のスコープ外でもコード実行中の変数や式の値を監視できます。
- **プロファイリング**: CPU使用率、関数呼び出し、実行時間を記録し、パフォーマンスのボトルネックを特定するのに役立ちます。
- **`console.dir()`**: 指定したJavaScriptオブジェクトのプロパティをインタラクティブなリストで表示します。階層的なリストで、ネストされたプロパティも展開して確認できます。

- **`console.table()`**: コンソールに表形式でデータを表示します。必須引数は配列またはオブジェクトで、オプション引数で表示するプロパティ（列）を指定できます。

## 正規表現と一般的なメソッド

- **定義**: 正規表現（Regex）は「パターン」を作成するために使われ、そのパターンを使って文字列をチェックしたり、テキストを抽出したりできます。

- **`RegExp` コンストラクタ**: パターンやフラグが変数から来る場合、`RegExp` コンストラクタを使って同じ種類の正規表現を作成できます。これはパターンの文字列とオプションのフラグ文字列を受け取ります。

例えば、`new RegExp(pattern, flags)` はそれらの文字列から正規表現を作成します。

- **`test()` メソッド**: このメソッドは文字列を受け取り、その文字列が正規表現にマッチするかどうかを判定します。マッチすればブール値を返します。

- **`match()` メソッド**: このメソッドは正規表現を受け取りますが、文字列を渡すと正規表現に変換されます。`match` メソッドは文字列のマッチ配列を返します。

- **`replace()` メソッド**: このメソッドは2つの引数を受け取ります。1つ目はマッチさせる正規表現（または文字列）、2つ目はマッチした部分を置き換える文字列（または各マッチに対して実行する関数）です。

- **`replaceAll` メソッド**: このメソッドは指定したパターンのすべての出現箇所を新しい文字列に置き換えます。グローバル修飾子なしの正規表現を渡すとエラーが発生します。

- **`matchAll` メソッド**: このメソッドは文字列内の正規表現にマッチするすべての結果（キャプチャグループを含む）を取得し、イテレータとして返します。イテレータはコレクションの要素を順に処理できるオブジェクトです。

## 正規表現の修飾子

- **定義**: 修飾子（フラグとも呼ばれます）は正規表現の動作を変更します。
- **`i` フラグ**: このフラグは正規表現を大文字小文字を区別しないようにします。

- **`g` フラグ**: このフラグ（グローバル修飾子）は正規表現がパターンに複数回マッチすることを可能にします。

- **アンカーの定義**: `^` アンカーは正規表現の先頭に置き、「文字列の先頭にマッチする」ことを示します。`$` アンカーは正規表現の末尾に置き、「文字列の末尾にマッチする」ことを示します。

- **`m` フラグ**: アンカーは文字列全体の先頭と末尾を探しますが、`m` フラグ（マルチライン修飾子）を使うと複数行に対応できます。

- **`d` フラグ**: このフラグは、マッチとキャプチャグループの開始および終了インデックスをマッチオブジェクトに追加します。

- **`u` フラグ**: このフラグを使うと、正規表現の機能が拡張され、特殊なユニコード文字にもマッチできるようになります。`u` フラグを使うことで、`Extended_Pictographic` のような特別なクラスにアクセスでき、多くの絵文字にもマッチできます。また、`v` フラグもあり、ユニコードマッチングの機能をさらに拡張します。
- **`y` フラグ**: スティッキーモディファイアは、グローバルモディファイアと非常によく似ていますが、いくつか例外があります。最大の違いは、グローバルな正規表現は lastIndex から始めて文字列の残り全体を検索して次のマッチを探しますが、スティッキーな正規表現は前回の lastIndex ですぐにマッチしなければ null を返し、lastIndex を 0 にリセットします。
- **`s` フラグ**: シングルラインモディファイアは、正規表現内で `.` で表されるワイルドカード文字が改行にもマッチできるようにします。つまり、文字列全体を 1 行のテキストとして扱うことができます。

## 文字クラス

- **ワイルドカード `.`**: 文字クラスは文字の集合や部分集合にマッチさせるための特別な構文です。最初に覚えるべき文字クラスはワイルドカードクラスです。ワイルドカードはピリオド（ドット）で表され、改行を除く任意の1文字にマッチします。改行にもマッチさせるには`s` フラグを使う必要があります。

- **`\d`**: これは文字列内のすべての数字（`0-9`）にマッチします。

- **`\w`**: これは文字列内の任意の単語文字（`a-zA-Z0-9_`）にマッチします。単語文字とは、aからzまたはAからZの任意の文字、0から9の数字、またはアンダースコア文字を指します。

- **`\s`**: 空白文字クラス `\s` はバックスラッシュに続く `s` で表されます。この文字クラスは改行、スペース、タブ、特殊なユニコード空白文字を含む任意の空白にマッチします。
- **特殊文字クラスの否定**: これらの文字クラスを否定するには、バックスラッシュの後に小文字ではなく大文字を使います。例えば、`\D` は数字以外の任意の単一文字にマッチします。

- **カスタム文字クラス**: マッチさせたい文字を大括弧で囲むことで、カスタム文字クラスを作成できます。

例えば、`/[abcdf]/` は括弧内のいずれかの文字にマッチします。

## 先読みと後読みアサーション

- **定義**: 先読みと後読みアサーションは、周囲のパターンの有無に基づいて特定のパターンにマッチさせることを可能にします。
- **肯定先読みアサーション**: このアサーションは、あるパターンの後に別のパターンが続く場合にマッチします。肯定先読みを作るには、まずマッチさせたいパターンを書き、その後に条件として使いたいパターンを丸括弧で囲み、開き括弧の直後に`?=`を使います。

例えば、`/free(?=code)/i` は `free` の後に `code` が続く場合にマッチします。

- **否定先読みアサーション**: これは正規表現で、特定のパターンが文字列の先に存在しないことを確認する条件です。

例えば、`/free(?!code)/i` は `free` の後に `code` が続かない場合にマッチします。

- **肯定後読みアサーション**: このアサーションは、特定のパターンの直前に別のパターンがある場合にのみマッチし、直前のパターンはマッチ結果に含めません。

例えば、`/(?<=free)code/i` は `free` に続く `code` にマッチします。

- **否定後読みアサーション**: このアサーションは、特定のパターンの直前に別のパターンがないことを保証します。指定されたパターンが直前にない場合にのみマッチし、直前のパターンはマッチ結果に含めません。

例えば、`/(?<!free)code/i` は `free` に続かない `code` にマッチします。

## 正規表現の量指定子

- **定義**: 正規表現の量指定子は、パターン（またはパターンの一部）が何回出現するかを指定します。これにより、文字やグループの出現回数を制御できます。

例えば、`/^\d{4}$/` はちょうど4桁の数字のみを含む文字列にマッチします。

- **`*`** : 直前の要素が0回以上繰り返されることにマッチします。
- **`+`**: 直前の要素が1回以上繰り返されることにマッチします。
- **`?`**: 直前の要素が0回または1回現れることにマッチします。
- **`{n}`**: 直前の要素がちょうどn回現れることにマッチします。
- **`{n,}`**: 直前の要素がn回以上現れることにマッチします。
- **`{n,m}`**: 直前の要素がn回からm回の間で現れることにマッチします。

## キャプチャグループとバックリファレンス

- **キャプチャグループ**: キャプチャグループはマッチした文字列の一部を「キャプチャ」し、必要に応じて利用できるようにします。キャプチャグループは丸括弧で囲まれたパターンで定義され、先読みのような先頭文字はありません。

例えば、`/free(code)camp/i` は `code` をキャプチャします。

- **非キャプチャグループ**: 非キャプチャグループはキャプチャグループに似ていますが、マッチした部分を保存しません。非キャプチャグループは `(?:...)` で定義されます。

例えば、`/free(?:code)camp/i` は `code` をグループ化しますがキャプチャはしません。

- **バックリファレンス**: 正規表現のバックリファレンスは、同じ式内で以前にマッチした部分を再利用する方法です。キャプチャグループ（丸括弧内のパターン）を番号で参照できます。例えば、`$1` は最初のキャプチャグループを指します。

:::interactive_editor

```js
const regex = /free(co+de)camp/i;
console.log("freecoooooooodecamp".replace(regex, "paid$1world"));
```

:::

- バックリファレンスは正規表現内で、バックスラッシュとキャプチャグループ番号を使って、以前にキャプチャしたテキストと同じものにマッチさせることができます。例えば：

:::interactive_editor

```js
const regex = /(hello) \1/i;
console.log(regex.test("hello hello")); // true
console.log(regex.test("hello world")); // false
```

:::

## JavaScriptでのフォームバリデーション

- **制約バリデーションAPI**: `textarea` や `input` のような特定のHTML要素は制約バリデーションAPIを公開しています。このAPIを使うと、ユーザーが入力した値が最小長さやパターンマッチなどのHTMLレベルのバリデーションを通過しているかを確認できます。
- **`checkValidity()` メソッド**: このメソッドは、要素がすべてのHTMLバリデーション（属性に基づく）を通過していれば`true`を返し、失敗すれば`false`を返します。

- **`reportValidity()` メソッド**: このメソッドはブラウザに対して`input`が無効であることを伝えます。

- **`validity` プロパティ**: このプロパティは、フォームコントロール（`<input>`、`<select>`など）の有効性状態を取得するために使われ、ユーザーの入力がその要素に定義された制約（例：`required` フィールド、パターン制約、最大長など）を満たしているかどうかの情報を提供します。

- **`patternMismatch` プロパティ**: このプロパティは値が指定された正規表現パターンにマッチしない場合に`true`になります。

## `preventDefault()` メソッド

- **定義**: DOMで発生するすべてのイベントには何らかのデフォルトの動作があります。例えば、チェックボックスのクリックイベントは、そのチェックボックスの状態を切り替えます。フォーカスされたボタンで<kbd>Spacebar</kbd>を押すと、そのボタンがアクティブになります。これらの`Event`オブジェクトの`preventDefault()`メソッドは、その動作を停止します。

## フォームの送信

- **定義**: フォームが送信される方法は3つあります。1つ目は、フォーム内の`type`属性が`submit`に設定されたボタンをユーザーがクリックした場合です。2つ目は、フォーム内の編集可能な`input`フィールドでユーザーが<kbd>Enter</kbd>キーを押した場合です。3つ目は、JavaScriptで`form`要素の`requestSubmit()`または`submit()`メソッドを呼び出す場合です。
- **`action`属性**: `action`属性にはURLまたは現在のドメインに対する相対パスを指定する必要があります。この値はフォームがデータを送信しようとする場所を決定します。`action`属性を設定しない場合、フォームは現在のページのURLにデータを送信します。

- **`method`属性**: この属性は`HTTP`メソッド（`GET`や`POST`など）を受け入れ、アクションURLへのリクエストにそのメソッドを使います。メソッドが設定されていない場合、フォームはデフォルトで`GET`リクエストになります。フォーム内のデータは`name=value`ペアとしてURLエンコードされ、クエリパラメータとしてアクションURLに追加されます。

- **`enctype`属性**: `form`要素は`enctype`属性を受け入れ、データのエンコードタイプを表します。この属性は3つの値のみを受け入れます：`application/x-www-form-urlencoded`（デフォルトで、データをURLエンコードされたフォームボディとして送信）、`text/plain`（データをプレーンテキスト形式で、`name=value`ペアを改行で区切って送信）、および`multipart/form-data`で、ファイルアップロードを含むフォームの処理に特化しています。

## `date()` オブジェクトとよく使われるメソッド

- **定義**: `date()` オブジェクトはJavaScriptで日付と時刻を作成、操作、フォーマットするために使われます。例えば、`const now = new Date();` は `Date` オブジェクトの新しいインスタンスを作成し、変数 `now` に代入します。`now` の値をコンソールに出力すると、コードを実行しているコンピュータのシステム時計に基づく現在の日付と時刻が表示されます。

- **`Date.now()` メソッド**: このメソッドは現在の日付と時刻を取得するために使われます。`Date.now()` は1970年1月1日00:00:00 UTCからのミリ秒数を返します。これはUnixエポック時間として知られています。Unixエポック時間は整数で表されるため、コンピューターシステムで日付や時刻を表す一般的な方法です。UTCは協定世界時（Universal Time Coordinated）の略で、世界が時計や時間を調整するための基準となる時間です。
- **`getDate()` メソッド**: このメソッドは現在の日付に基づいて月の日を取得します。`getDate()` は1から31までの整数値を返します。日付が無効な場合は`NaN`（Not a Number）を返します。

- **`getMonth()` メソッド**: このメソッドは月を取得します。月はゼロベースなので、1月は0、2月は1、という具合です。例えば、10月の日付に対して `getMonth()` を呼び出すと `9` が返ります。無効な月の場合は `NaN` を返します。

- **`getFullYear()` メソッド**: このメソッドは西暦年を取得します。無効な年の場合は`NaN`を返します。

## 日付のさまざまなフォーマット方法

- **`toISOString()` メソッド**: このメソッドは日付を拡張`ISO`（ISO 8601）形式でフォーマットします。ISO 8601は日付と時刻を表す国際標準です。フォーマットは`YYYY-MM-DDTHH:mm:ss.sssZ`です。

- **`toLocaleDateString()` メソッド**: このメソッドはユーザーのロケールに基づいて日付をフォーマットします。

`toLocaleDateString()` メソッドは2つのオプションパラメータを受け取ります：localesとoptionsです。

localesパラメータは使用するロケールを表す文字列です。例えば、英語（アメリカ合衆国）なら`"en-US"`、フランス語（フランス）なら`"fr-FR"`を渡せます。localesパラメータを渡さない場合はデフォルトのロケールが使われます。2つ目のオプションパラメータはoptionsで、日付文字列のフォーマットを指定できるオブジェクトです。

## `Audio` コンストラクタと一般的なメソッド

- **定義**: `Audio` コンストラクタは他のコンストラクタと同様に、`new` キーワードで呼び出される特別な関数です。これは`HTMLAudioElement` を返し、それを使ってユーザーにオーディオを再生したり、ユーザーが自分で操作できるようにDOMに追加したりできます。コンストラクタを呼び出す際に、オプションでURLを（唯一の）引数として渡せます。このURLは再生したいオーディオファイルのソースを指すべきです。あるいは、ソースを動的に変更する必要がある場合は、返されたオーディオ要素の`src` プロパティにURLを代入できます。
- **`play()` メソッド**: このメソッドは`audio` または`video` 要素で使い、メディアの再生を開始します。

- **`pause()` メソッド**: このメソッドは`audio` または`video` 要素で使い、メディアの再生を一時停止します。現在の位置を維持するため、`play()` が呼ばれるとその位置から再生が始まります。

- **`addTextTrack()` メソッド**: このメソッドはメディア要素に字幕などのテキストトラックを関連付けるために使います。
- **`fastSeek()` メソッド**: このメソッドは再生位置をメディア内の特定の時間に移動させます。

`Audio()` コンストラクタにはメソッドだけでなくプロパティもあります。主なプロパティは以下の通りです：

- `currentTime`: オーディオの現在の再生時間を取得するためのもの
- `loop`: 再生が終わると自動的に再スタートして連続再生するためのもの
- `muted`: 音量設定に関係なくメディア要素の音声出力を消音するためのもの

## さまざまなオーディオとビデオのフォーマット

- **MIMEタイプ**: MIMEタイプはMultipurpose Internet Mail Extensionsの略で、ファイルタイプをプログラム的に示す標準化された方法です。MIMEタイプはブラウザなどのアプリケーションに特定のファイルの扱い方を伝えます。オーディオやビデオの場合、MIMEタイプはウェブページに埋め込めるマルチメディア形式であることを示します。
- **`source` 要素**: これはファイルタイプとソースを指定するために使われ、複数の異なるタイプを複数のsource要素で指定できます。こうするとブラウザはユーザーの環境に最適なフォーマットを選択します。
- **MP3**: 音楽や音声、サウンドを保存するためのデジタルファイル形式の一種です。圧縮された音声録音でファイルサイズが小さくなり、保存や共有がしやすくなっています。MP3は最も広くブラウザでサポートされており、MIMEタイプは`audio/mpeg`です。
- **MP4**: 動画と音声を保存するためのデジタルファイル形式です。映像（画像）と音声（音楽や音声）を1つのファイルにまとめるコンテナとして機能します。MP4は動画ファイルか音声のみかによって、MIMEタイプが`audio/mp4` または`video/mp4` になります。
- その他のフォーマットには、Windows Media Playerアプリに関連する`WMV`、`OGG`、`MKV`、`AVI`などがあります。

## コーデック

- **定義**: コーデック（encoder/decoderの略）は音声や映像をアナログとデジタルの間で変換するアルゴリズムやソフトウェアです。コーデックはMIMEタイプの一部として指定できます。基本的な構文はメディアタイプの後にセミコロンを付け、`codecs=`とコーデック名を続けます。

## HTMLMediaElement API

- **定義**: `HTMLMediaElement` APIはページ上のオーディオやビデオ要素の動作を制御するために使われます。これは基本の`HTMLElement` インターフェースを拡張しており、基本的なプロパティやメソッドに加え、`waiting`、`ended`、`canplay`、`canplaythrough` などの便利なイベントも利用できます。メソッドの例には、ブラウザがオーディオファイルを再生可能かどうかを確認するための`play()`、`fastSeek()`、`pause()`、`canPlayType()` があります。

## メディアキャプチャとストリームAPI

- **定義**: Media Capture and Streams API（MediaStream APIとも呼ばれます）はデバイスから音声や映像をキャプチャするために使います。APIを使うには`MediaStream`オブジェクトを作成する必要があります。コンストラクタで作成することもできますが、ユーザーのハードウェアに紐づきません。代わりに`global`ナビゲータオブジェクトの`mediaDevices`プロパティに`getUserMedia()`メソッドが用意されています。

## スクリーンキャプチャAPI

- **定義**: Screen Capture APIはユーザーの画面を録画するために使います。このAPIは`mediaDevices`オブジェクトの`getDisplayMedia()`メソッドを呼び出し、返されたメディアストリームを利用して公開されます。

## メディアストリーム録画 API

- **定義**: MediaStream Recording APIはMediaStreams APIと連携し、MediaStream（または`HTMLMediaElement`）を録画できるようにします。

## Media Source Extensions API（メディアソース拡張API）

- **トピック**: Media Source Extensions APIはユーザーのウェブカメラ映像を`srcObject` プロパティを使ってビデオ要素に直接渡せるようにします。

## Web Audio API（ウェブオーディオAPI）

- **定義**: Web Audio APIはウェブ上のすべての音声を支えています。このAPIには、オーディオデータを特に含むバッファを表す`AudioBuffer` や、オーディオ処理グラフを表す`AudioContext` など重要なオブジェクトが含まれています。

## JavaScriptのSet

- `Set` はデータコレクションを管理する組み込みのオプションです。
- Setは各値が一度だけ現れることを保証し、配列の重複を排除したり、異なる値のコレクションを扱うのに便利です。
- `Set()` コンストラクタを使って `Set` を作成できます。

- Setは以下のメソッドで操作できます：

  - `add()`: `Set` に新しい要素を追加します。
  - `delete()`: `Set` から要素を削除します。
  - `has()`: `Set` に要素が存在するか確認します。
  - `clear()`: `Set` からすべての要素を削除します。
  - `keys()` と `values()`: どちらも `SetIterator` の値を含む `Set` を返します。`keys()` は `values()` の別名なので同じです。
  - `forEach()`: `Set` の値を繰り返し処理するためのものです。

## JavaScriptのWeakSet

- `WeakSet`は弱参照でオブジェクトを格納できるコレクションです。

## SetとWeakSetの違い

- Setとは異なり、`WeakSet`は数値や文字列のようなプリミティブをサポートしません。
- `WeakSet`はオブジェクトのみを格納し、その参照は「弱い」ため、コード内で他に使われていなければ自動的にメモリから解放されます。

## JavaScriptのMap

- `Map` は、オブジェクトと同じようにキーと値のペアを保持する組み込みオブジェクトです。
- Map は標準の JavaScript オブジェクトと異なり、オブジェクトや関数を含むあらゆる型をキーとして使用できます。
- キーと値のペアを頻繁に追加・削除する場合、`Map` は標準のオブジェクトよりも優れたパフォーマンスを発揮します。
- `Map()` コンストラクタを使用して `Map` を作成できます。

- Mapは以下のメソッドで操作できます：

  - `set()`: `Map`に新しいキーと値のペアを追加します。
  - `get()`: `Map`からキーの値を取得します。
  - `delete()`: `Map`からキーと値のペアを削除します。
  - `has()`: `Map`にキーが存在するか確認します。
  - `clear()`: `Map`のすべてのキーと値のペアを削除します。

Maps と Sets の両方に、ユニークな要素の数を返す `size` プロパティがあることに注意してください。

## JavaScriptのWeakMap

- `WeakMap`は`Map`のようなキーと値のペアのコレクションですが、キーへの参照が弱いものです。キーはオブジェクトでなければならず、値は任意のものを格納できます。

## Maps と WeakMaps の違い

- WeakMaps は WeakSets と似ていて、オブジェクトのみを格納し、それらのオブジェクトへの参照が「弱い」ものです。

## 作成、読み取り、更新、削除（CRUD）

- **作成**: 新しいデータを作成するプロセスを指します。例えば、ウェブアプリでユーザーがブログに新しい投稿を追加する場合です。
- **読み取り**: データベースからデータを取得する操作です。例えば、ブログ投稿を閲覧したりウェブサイトでプロフィールを表示するときに、データベースに保存されたデータを取得して表示しています。
- **更新**: データベース内の既存データを変更することです。例えば、ブログ投稿を編集したりプロフィール情報を更新する場合です。
- **削除**: データベースからデータを削除する操作です。例えば、ブログ投稿やアカウントを削除するときに行われます。

## HTTPメソッド

- **定義**: HTTPはHypertext Transfer Protocolの略で、ウェブ上のデータ通信の基盤です。HTTPメソッドはウェブ上のリソースに対して実行できる操作を定義しています。一般的なメソッドにはGET、POST、PUT、PATCH、DELETEがあります。
- **`GET` メソッド**: サーバーからデータを取得するために使われます。
- **`POST` メソッド**: 新しいリソースを作成するためにサーバーにデータを送信する際に使われます。
- **`PUT` メソッド**: リソースを完全に置き換えて更新するために使われます。
- **`PATCH` メソッド**: リソースを部分的に更新するために使われます。
- **`DELETE` メソッド**: データベースからレコードを削除するために使われます。

## `localStorage` と `sessionStorage` プロパティ

- **Web Storage API**: このAPIはブラウザ内にキーと値のペアを保存する仕組みを提供し、開発者が異なるページのリロードやセッションをまたいで情報を保存できるようにします。Web Storage APIの主なコンポーネントは`localStorage` と `sessionStorage` プロパティです。
- **`localStorage` プロパティ**: `localStorage` はブラウザのウィンドウが閉じられたりページが更新された後でもデータを保持できるWeb Storage APIの部分です。このデータはアプリケーションやユーザーによって明示的に削除されるまで利用可能です。
- **`localStorage.setItem()` メソッド**: このメソッドは`localStorage` にキーと値のペアを保存するために使われます。

- **`localStorage.getItem()` メソッド**: このメソッドは`localStorage` から指定されたキーの値を取得するために使われます。

- **`localStorage.removeItem()` メソッド**: このメソッドはキーを使って`localStorage` から特定のアイテムを削除するために使われます。

- **`localStorage.clear()` メソッド**: このメソッドは`localStorage` に保存されたすべてのデータをクリアするために使われます。

- **`sessionStorage` プロパティ**: 現在のセッションのみ持続し、ブラウザのタブやウィンドウが閉じられるとクリアされるデータを保存します。
- **`sessionStorage.setItem()` メソッド**: このメソッドは`sessionStorage` にキーと値のペアを保存するために使われます。

- **`sessionStorage.getItem()` メソッド**: このメソッドは`sessionStorage` から指定されたキーの値を取得するために使われます。

- **`sessionStorage.removeItem()` メソッド**: このメソッドはキーを使って`sessionStorage` から特定のアイテムを削除するために使われます。

- **`sessionStorage.clear()` メソッド**: このメソッドは`sessionStorage` に保存されたすべてのデータをクリアするために使われます。

## クッキーの扱い方

- **定義**: クッキーはウェブクッキーやブラウザクッキーとも呼ばれ、サーバーがユーザーのウェブブラウザに送信する小さなデータ片です。これらのクッキーはユーザーのデバイスに保存され、後続のリクエストとともにサーバーに送信されます。HTTPがステートレスなプロトコルであるため、クッキーはウェブアプリが状態を維持しユーザー情報を記憶するのに不可欠です。
- **セッションクッキー**: これらのクッキーはユーザーのウェブサイトでのセッションの間だけ持続します。ユーザーがブラウザやタブを閉じるとセッションクッキーは削除されます。通常、訪問中のログイン状態を維持するために使われます。
- **セキュアクッキー**: これらのクッキーはHTTPS経由でのみ送信され、通信途中で攻撃者に傍受されることを防ぎます。
- **HttpOnlyクッキー**: これらのクッキーはブラウザで実行されるJavaScriptからアクセスや変更ができず、クロスサイトスクリプティング（XSS）攻撃に対してより安全です。
- **Set-Cookieヘッダー**: ウェブサイトを訪問すると、サーバーはHTTPレスポンスでSet-Cookieヘッダーを送信できます。このヘッダーはブラウザに特定の情報を持つクッキーを保存するよう指示します。例えば、次回訪問時にユーザーを識別するためのユニークIDを保存することがあります。
JavaScriptでクッキーを手動で設定するには`document.cookie` を使います。

```js
document.cookie = "organization=freeCodeCamp; expires=Fri, 31 Dec 2021 23:59:59 GMT; path=/";
```

クッキーを削除するには、有効期限を過去の日時に設定してください。

## Cache API

- **定義**: キャッシュはファイルのコピーを一時的な保存場所に保存し、より速くアクセスできるようにするプロセスです。Cache APIはネットワークリクエストとレスポンスを保存し、ウェブアプリの効率を高め、オフラインでも動作させるために使われます。これはService Worker APIの一部であり、不安定または遅いネットワーク環境でも動作するプログレッシブウェブアプリ（PWA）を作るのに重要です。
Cache APIはRequestとResponseオブジェクトを保存するストレージ機構です。サーバーへのリクエストが行われると、アプリはレスポンスを保存し、後で新たなネットワークリクエストを行わずにキャッシュから取得できます。これにより読み込み時間が短縮され、帯域幅が節約され、ユーザー体験が向上します。
- **キャッシュストレージ**: HTTPリクエストとそれに対応するレスポンスのキーと値のペアを保存します。これにより、以前にリクエストしたリソースを効率的に取得でき、再訪時にネットワークから取得する必要が減りパフォーマンスが向上します。
- **Cache-Control**: 開発者はキャッシュされたリソースをどのくらいの期間保持するか、再検証するか、直接キャッシュから提供するかを定義できます。
- **オフライン対応**: Cache APIを使うことでオフラインファーストのウェブアプリを作成できます。例えば、PWAはユーザーがネットワークから切断されている場合でもキャッシュされた資産を提供できます。

## ネガティブパターンとクライアントサイドストレージ

- **過剰なトラッキング**: これはクッキー、ローカルストレージ、セッションストレージなどのクライアントサイドストレージに、明確な同意や正当な理由なしに過剰なユーザーデータを収集・保存する行為を指します。複数のサイトやセッションにわたってユーザーの行動や好み、インタラクションを追跡し、ユーザーのプライバシーを侵害する場合があります。
- **ブラウザフィンガープリンティング**: クッキーや従来のトラッキング方法に頼らず、デバイスやブラウザの固有の特徴に基づいて個々のユーザーを追跡・識別する手法です。クッキーはユーザーのデバイスにローカル保存されますが、フィンガープリンティングはユーザーのブラウザセッションの特徴を収集して独自の「指紋」を作成します。
- **LocalStorageにパスワードを設定すること**: これは明らかに悪いパターンの一例ですが、パスワードなどの機密データをローカルストレージに保存することはセキュリティリスクがあります。ローカルストレージは暗号化されておらず簡単にアクセスできるため、機密データを保存してはいけません。

## クラスの基本操作

- **定義**: JavaScript のクラスはオブジェクトを作成しデータをカプセル化するための設計図を定義します。クラスにはコンストラクタという特別なメソッドがあり、新しいオブジェクトがクラスから作成されると自動的に呼び出されます。コンストラクタはオブジェクトのプロパティを初期化するために使われます。ここで `this` キーワードはクラスの現在のインスタンスを指します。コンストラクタの下にはメソッドと呼ばれるものがあり、これはクラス内で定義された関数で、クラスのデータや状態に対して操作を行います。メソッドはクラスのインスタンスが実行できる動作を定義します。

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);  // Gino
```

:::

クラスの新しいインスタンスを作成するには、`new` キーワードに続けてクラス名を使います。

クラスはクラス式としても作成できます。これはクラスが匿名で変数に代入される形です。

## クラスの継承

- **定義**: プログラミングにおける継承は、親クラスからプロパティやメソッドを引き継ぐクラスを定義することを指します。これによりコードの再利用が促進され、クラス間の階層的な関係が確立されます。親クラスは他のクラスの設計図のようなもので、プロパティやメソッドを定義し、それを他のクラスが継承します。子クラスは別のクラスのプロパティやメソッドを継承し、新しいプロパティやメソッドを追加して親クラスの機能を拡張できます。JavaScript では `extends` キーワードを使って継承を実装します。このキーワードはあるクラスが別のクラスの子クラスであることを示します。

`super` キーワードは親クラスのメソッド、コンストラクタ、フィールドにアクセスするために使われます。

:::interactive_editor

```js
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  constructor(brand, year, numDoors) {
    super(brand, year);
    this.numDoors = numDoors;
  }
}

const myCar = new Car("freeCodeCamp Motors", 2019, 4);
console.log(myCar.brand);  // freeCodeCamp Motors
console.log(myCar.year);  // 2019
console.log(myCar.numDoors);  // 4
```

:::

## 静的メソッドと静的プロパティの扱い方

- **静的メソッド**: これらのメソッドはオブジェクトの特定の状態にアクセスする必要がないユーティリティ関数としてよく使われます。クラス内で定義され、関連する機能をカプセル化します。

`static` キーワードを使って静的メソッドを定義し、そのクラス自体で呼び出します。

静的メソッドは「ファクトリ」メソッドの実装にも役立ちます。ファクトリメソッドはコンストラクタに加えて定義し、特定の条件に基づいてオブジェクトを作成するメソッドです。

- **静的プロパティ**: これらはクラス自体に関連付けられた値や属性を定義するために使われます。静的プロパティはクラスのすべてのインスタンスで共有され、インスタンスを作成しなくてもアクセスできます。

例えば、`static numberOfWheels = 4;` はクラス内に静的プロパティを定義します。

- 再帰は、基本ケースに到達するまで関数を繰り返し呼び出すことができるプログラミングの概念です。

以下は、数の階乗を計算する再帰関数の例です。

```js
function findFactorial(n) {
  if (n === 0) {
    return 1;
  }
  return n * findFactorial(n - 1);
}
```

上の例では、`findFactorial` 関数が `n` が `0` に達するまで再帰的に呼び出されます。`n` が `0` のとき、基本ケースに到達し関数は `1` を返します。その後、関数は `n` と `findFactorial(n - 1)` への再帰呼び出しの結果の積を返します。

- 再帰を使うと、深くネストされたオブジェクトや配列、またはファイルツリーのような未知の深さのものを扱うことができます。
- 再帰関数の呼び出しを追跡するためにコールスタックが使われます。関数が呼び出されるたびにコールスタックに追加され、基本ケースに到達すると関数呼び出しはスタックから削除されます。
- 基本ケースは慎重に定義する必要があります。無限に呼び出すとコードがクラッシュする可能性があります。これは再帰がどんどん関数呼び出しを積み重ね、システムのメモリが不足するためです。
- 再帰は階乗やフィボナッチのような数学的問題の解決、ツリーやグラフの走査、順列や組み合わせの生成などに使われます。

## アルゴリズムとビッグO記法

- **アルゴリズム**: 問題を解決したりタスクを実行したりするための明確な手順の集合です。アルゴリズムは有限のステップで終了し、各ステップは正確かつ明確でなければなりません。

- **ビッグO記法**: 入力サイズが増加したときのアルゴリズムの最悪ケースの性能や成長率を表します。定数や低次の項は無視し、入力サイズに対するリソース使用量の増え方に注目します。

### よくある時間計算量

- **O(1) - 定数時間**: 入力サイズに関係なく一定の時間で処理が終わります。

- **O(log n) - 対数時間**: 入力が増えても時間の増加がゆっくりです。問題サイズを繰り返し一定割合で減らすアルゴリズム（例：二分探索）に多いです。

- **O(n) - 線形時間**: 実行時間が入力サイズに比例して増えます。

- **O(n log n) - 線形対数時間**: マージソートやクイックソートなど効率的なソートアルゴリズムの一般的な時間計算量です。

- **O(n²) - 二次時間**: 実行時間が二次関数的に増えます。ネストしたループでよく見られます。

### 空間計算量

- **O(1) - 定数空間**: 入力サイズに関係なく一定のメモリを使います。
- **O(n) - 線形空間**: メモリ使用量が入力サイズに比例して増えます。
- **O(n²) - 二次空間**: メモリ使用量が二次関数的に増えます。

## 問題解決の手法

- **問題の理解**: 問題文を何度も読み、入力、期待される出力、入力から出力への変換方法を特定します。

- **疑似コード**: 言語に依存しないアルゴリズムの高レベルな説明です。一般的な文章と`IF`、`ELSE`、`FOR`、`WHILE`などのプログラミング構造を混ぜて書きます。

- **エッジケース**: アルゴリズムが扱う境界にある特定の有効な入力です。必ず考慮しテストしてください。

## 配列

- **静的配列**: 初期化時にサイズが固定されます。要素は隣接したメモリ領域に格納され、実行中にサイズ変更はできません。

- **動的配列**: 実行中に自動でサイズが増減します。必要に応じてより大きな配列にコピーしてリサイズを処理します。

### JavaScriptでの動的配列の実装

JavaScriptの配列は動的配列です。インデックスで要素にアクセス・更新でき、`push()` で要素を追加し、`pop()` や `splice()` で要素を削除できます。

### 動的配列の時間計算量

- **アクセス**: O(1)
- **末尾への挿入**: 平均O(1)、リサイズ時はO(n)
- **途中への挿入**: O(n)
- **削除**: 途中はO(n)、末尾はO(1)

## スタック

- **スタック**: 後入れ先出し（LIFO）のデータ構造。要素は上から追加・削除されます。

- **プッシュ操作**: スタックの上に要素を追加します。時間計算量はO(1)。

- **ポップ操作**: スタックの上から要素を削除します。時間計算量はO(1)。

JavaScriptの配列は、`push()` で要素を追加し、`pop()` で削除することでスタックとして使えます。

## キュー

- **キュー**: 先入れ先出し（FIFO）のデータ構造。要素は後ろに追加され、前から削除されます。

- **エンキュー操作**: キューの後ろに要素を追加します。時間計算量はO(1)。

- **デキュー操作**: キューの前から要素を削除します。時間計算量はO(1)。

配列は、`push()` でエンキューし、`shift()` でデキューすることでキューを表現できます。ただし、`shift()` は残りの要素を移動させるため O(n) の時間がかかります。

## 連結リスト

- **連結リスト**: 各ノードがデータと次のノードへの参照を持つ線形データ構造。ノードは鎖のようにつながっています。

### 単方向連結リスト

- **構造**：各ノードはデータと次のノードへの1つの参照を持ちます。
- **走査**：先頭から末尾へ一方向にしか進めません。
- **先頭ノード**：リストの最初のノードで、通常は唯一直接アクセスできるノードです。
- **末尾ノード**：リストの最後のノードで、`null`を指します。

### 操作と時間計算量

- **先頭への挿入**: O(1)
- **末尾への挿入**: O(n) - 末尾まで走査が必要
- **途中への挿入**: O(n) - 挿入位置まで走査が必要
- **先頭からの削除**: O(1)
- **末尾からの削除**: O(n) - 前のノードを探すため走査が必要
- **途中からの削除**: O(n) - 削除ノードを探すため走査が必要

### 双方向連結リスト

- **構造**: 各ノードはデータと2つの参照（次ノードと前ノード）を持ちます。
- **走査**: 双方向に移動可能です。
- **メモリ**: 追加の参照があるため単方向連結リストより多くのメモリを使います。

## それぞれのデータ構造の使いどころ

- **配列（動的配列）**：順序付きでインデックスによるアクセスが必要で、サイズが事前にわからない場合
- **スタック**：LIFO操作が必要な場合（元に戻す機能、式の評価、バックトラッキング）
- **キュー**：FIFO操作が必要な場合（タスクスケジューリング、幅優先探索）
- **連結リスト**：先頭での頻繁な挿入・削除があり、サイズが不明でランダムアクセスが不要な場合

## 検索アルゴリズム

検索アルゴリズムは、特定のリスト内でターゲットを検索するためのものです。

コンピューターサイエンスでは、知っておくべき検索アルゴリズムが2つあります。これらは**線形探索**と**二分探索**のアルゴリズムです。両者の違いと、それぞれを使うべき状況を理解することが重要です。

### 線形探索

- 線形探索は、配列の最初から順に各要素を反復してチェックし、ターゲットの要素が見つかるまで続けます。
- ターゲットの要素が見つかれば、その要素が配列内にあるインデックスを返します。
- ターゲットが見つからなければ、JavaScriptで**無効なインデックス**を意味する`-1`を返します。
- 線形探索はターゲットが見つかるまで全ての要素をチェックするため、大きな配列には効率的ではありません。
- 線形探索の時間計算量は`O(n)`で、配列のサイズに比例して検索時間が増加します。
- 線形探索の空間計算量は`O(1)`で、検索に追加の空間を必要としません。

### 二分探索

- 二分探索は、配列を半分に分割し、ターゲットの値が配列の中央にあるかをチェックすることで動作します。
- 二分探索が機能する条件は、配列の要素が昇順または降順にソートされていることです。
- 二分探索は配列を半分に分割し、ターゲットが存在しない半分を無視するため、大きな配列の検索により効率的なアルゴリズムです。
- ターゲットの要素が配列の中央に見つかれば、そのインデックスを返します。
- 要素が見つからなければ、ターゲットが配列の左半分か右半分にあるかをチェックします。
- ターゲットが見つかるまで、残りの配列部分を半分に分割し続けます。
- 配列内にターゲットが見つからなければ、`-1`を返します。
- 二分探索の時間計算量は`O(log n)`で、配列のサイズに対して対数的に検索時間が増加します。
- 二分探索の空間計算量は`O(1)`で、検索に追加の空間を必要としません。

### 線形探索と二分探索の違い

- 二分探索は線形探索よりも大きな配列に適しています。
- 線形探索の時間計算量は`O(n)`で、配列のサイズに比例して検索時間が増加します。
- 二分探索の時間計算量は`O(log n)`で、配列のサイズに対して対数的に検索時間が増加します。

## ソートアルゴリズムと分割統治法

コンピューターサイエンスでは、分割統治法は問題をより小さな部分問題に分割して解きやすくする手法です。分割統治法では再帰がよく使われ、多くの効率的なソートアルゴリズム（例えばマージソート）を実装する強力な戦略です。

### マージソート

- マージソートは分割統治法に従うソートアルゴリズムです。
- 配列を再帰的に小さなサブ配列に分割し、各サブ配列が1つの要素だけになるまで続けます。
- その後、サブ配列を繰り返しマージしてソートされた順序に戻します。
- マージソートの時間計算量は`O(n log n)`で、配列が継続的に半分に分割され`(log n)`、その後マージされるため`(O(n))`です。
- マージソートの空間計算量は`O(n)`で、インプレースソートアルゴリズムではありません。

## グラフの概要

グラフはノード（頂点）とエッジ（接続）からなる集合です。各ノードは複数の他のノードと接続し、ネットワークを形成します。グラフの種類には以下があります：

- **有向**: エッジには方向があり（あるノードから別のノードへ）、直線と矢印で表されることが多いです。
- **無向**: エッジに方向がなく、単純な線で表されます。
- **頂点ラベル付き**: 各ノードにラベルや識別子が関連付けられています。
- **循環**: サイクル（開始ノードと終了ノードが同じ経路）を含みます。
- **有向非循環グラフ（DAG）**: サイクルを持たない有向グラフです。
- **エッジラベル付き**: 各エッジにラベルがあり、通常は対応するエッジの隣に描かれます。
- **重み付き**: エッジに重み（値）があり、算術演算に使われます。
- **非連結**: 2つ以上のノード群（コンポーネント）がエッジで接続されていません。2つのノード間に直接のエッジがなくても、経路が存在する場合があります。

グラフは地図、ネットワーク、推薦システム、依存関係の解決など、さまざまなアプリケーションで使われます。

## グラフの走査

グラフのすべてのノードを訪問することです。主なアルゴリズムは：

- **幅優先探索（BFS）**: グラフの次のレベルに進む前に、すべての隣接ノードを訪問します。
  - **キュー**: キュー（FIFO）を使います。開始ノードは訪問済みとしてマークされ、キューに追加されます。キューが空でない間、現在のノードをデキューし、その未訪問の隣接ノードを訪問済みとしてマークし、キューに追加します。
  - **最短経路**: 重みなしグラフで最短経路を見つけます。
  - **メモリ**: キューをメモリに保持する必要があり、特に同じレベルに多くのノードがあるグラフでは空間要件が大きくなります。
  - **連結成分**: 未訪問の各ノードから新しい探索を開始することで、連結グラフの成分を見つけるのにも使えます。
  - **状態空間探索**: 括弧の組み合わせを構築する際に異なる状態を追跡するためにキューを使います。各状態は、現在構築中の文字列、これまでに使った開き括弧の数、閉じ括弧の数を含む配列で表されます。開き括弧は、使った数がペア数より少ない場合にのみ追加できます。閉じ括弧は、バランスを保つために、開き括弧の数が閉じ括弧より多い場合にのみ追加できます。

- **深さ優先探索（DFS）**: 各枝をできるだけ深くたどり、行き止まりになったら戻ります。
  - **スタック**: スタック（LIFO）または再帰を使います。開始ノードは訪問済みとしてマークされ、スタックに追加されます。スタックが空でない間、現在のノードをポップし、その未訪問の隣接ノードを訪問済みとしてマークし、スタックに追加します。
  - **メモリ**: スタック（または再帰時の関数呼び出しスタック）をメモリに保持する必要があり、非常に長い経路を持つグラフでは空間要件が増えます。
  - **用途**: サイクル検出、経路探索、連結成分の検出に役立ちます。
  - **制限**: 重みなしグラフで2つのノード間の最短経路を必ずしも見つけられるとは限りません。

## グラフの表現方法

グラフは主に2つの方法で表現されます：

- **隣接リスト**: 各ノードは隣接ノードのリストを持ちます。
  - **実装**: 各インデックスがノードを表し、そのインデックスに格納された配列が隣接ノードを含む配列として実装されます。オブジェクト（または`Map`）としても実装でき、各キーがノードを表し、そのキーに関連付けられた値（配列）が隣接ノードを含みます。
  - **空間**: 疎なグラフに対して空間効率が良く、`V`が頂点数（ノード数）、`E`がエッジ数のとき、`O(V + E)`の空間計算量です。
  - **隣接ノード**: ノードに関連付けられたリストにアクセスするだけで隣接ノードを繰り返し処理できるため簡単です。
  - **エッジ検索**: 2つのノード間にエッジがあるかを判定するのは隣接行列より効率が悪く、通常`O(deg(v))`の時間がかかります。ここで`deg(v)`は調べるノードの隣接ノード数で、最悪の場合`O(V)`になることもあります。
  - **最適用途**: 実際のシナリオでは疎なグラフが多いため、通常はこちらが好まれます。

- **隣接行列**: 行と列がノードを表す2次元配列です。
  - **値**: グラフが重みなしの場合、`1`はノード間にエッジがあることを示し、`0`はエッジがないことを示します。重み付きの場合、値はノード間のエッジの重みを表します。
  - **自己ループ**: 対角線上の値は、各ノードが自身に接続する自己ループを持つかどうかを表します。
  - **空間**: 大きなグラフでは空間消費が大きく、ノード数`V`に対して二次の空間`O(V²)`が必要です。
  - **エッジ検索**: 2つのノード間にエッジがあるかを定数時間`O(1)`で高速にチェックできます。
  - **隣接ノード**: ノードの隣接ノードを見つけるのは非効率で、行または列全体を繰り返し処理する必要があります。最悪の場合、`O(V)`の時間がかかります。
  - **最適用途**: エッジが多い密なグラフに適しています。エッジが少ない疎なグラフには非効率です。

## 最短経路アルゴリズム

- **最短経路アルゴリズム**: 重み付きグラフのノード間の最短経路を計算し、距離と経路の両方を返します。
  - **隣接行列**: 各値は2つのノード間のエッジの重み（距離）を表します。
  - **エッジがない場合**: `INF`（`Infinity`）の値は直接のエッジがないことを意味します。
  - **距離**: 開始ノードから他のすべてのノードへの既知の最短距離を追跡する配列です。初めはすべてのノードが無限遠とみなされ、開始ノードから自身への距離は常に`0`です。
  - **経路**: 各エントリがノードのインデックスの配列で、各ノードに到達するためのルートを表します。
  - **訪問済み**: すでに処理されたノードを追跡する配列で、再訪問を防ぎます。
  - **最も近い未訪問ノード**: メインループはグラフの各ノードに対して1回ずつ実行され、その都度最も近い未訪問ノードを選びます。
  - **エッジ緩和**: 訪問していない実際のエッジを持つ隣接ノードごとに、現在のノードを経由してより効率的に到達できるかをチェックします。新しい距離が既存の距離より良ければ、距離と経路を更新します。
  - **到達不能ノード**: 有効なノードが見つからない場合、残りのノードはすべて到達不能であり、ループは早期に停止します。
  - **オプションのターゲット**: `targetNode`パラメータはオプションです。指定しない場合、関数は`startNode`からグラフ内のすべての他のノードへの最短経路を計算します。

## 木

木は非循環かつ連結な特別なグラフです。主な特徴は：

- **非循環**: 木にはループやサイクル（開始ノードと終了ノードが同じ経路）がありません。
- **連結**: すべてのノードは他のすべてのノードから到達可能です。

### 木の用語

- **ルートノード**: 木の最上部にあるノードで、親ノードを持たない唯一のノードです。
- **親ノード**: 直下のノードと直接つながっているノードです。
- **子ノード**: 直上のノードと直接つながっているノードです。
- **葉ノード**: 子ノードを持たないノードです。
- **深さ**: ルートからそのノードまでの経路の長さです。
- **高さ**: そのノードから葉ノードまでの経路の長さです。木の高さはルートノードの高さです。
- **次数**: 各ノードが持つ子ノードの数です。
- **サブツリー**: 木の一部であり、それ自体が木である部分です。
- **平衡木**: 任意のノードの左右のサブツリーの高さが非常に近く、操作が効率的に行えるようにした木です。

### 一般的な木の種類

代表的な木の種類は：

- **二分木**: 各ノードは最大で2つの子ノード（左と右）を持ちます。

- **二分探索木（BST）**: 各ノードについて、左のサブツリーのすべての値はノードの値より小さく、右のサブツリーのすべての値はノードの値より大きい二分木です。左と右のサブツリーもそれぞれ二分探索木である必要があります。

- **自己平衡木**: 挿入や削除によって不均衡な状態が生じたときに、内部のロジックで木のバランスを取り直す木です。代表例はAVL木、赤黒木、B木です。

- **AVL木**: 任意のノードの左右のサブツリーの高さの差が最大で1の自己平衡二分探索木です。

- **赤黒木**: 各ノードが赤または黒に色付けされている自己平衡二分探索木です。

- **B木**: 各ノードが複数のキーと2つ以上の子ノードを持てる自己平衡木です。

## トライ木

- **トライ木**: 接頭辞木とも呼ばれ、文字列の集合を格納するために使われ、各ノードが1文字を表します。
- **ルートノード**: 特定の文字を表さず、空文字列を表すと考えられます。
- **接頭辞**: ルートからトライ木をたどる経路が特定の接頭辞を定義します。
- **単語終端マーカー**: 完全な単語を表すノードには単語終端マーカーが付けられます。
- **共有接頭辞**: 複数の文字列が同じ接頭辞を共有すると、その経路が重なり、接頭辞は一度だけ格納されます。これにより、オートコンプリートやスペルチェックなどに効率的です。
- **挿入**: トライ木にまだ存在しない文字に対してのみ新しいノードを作成します。
- **時間計算量**: 検索と挿入は文字列の長さ`L`に対して`O(L)`の時間がかかります。
- **メモリ**: 文字列集合に多くのユニークな文字がある場合、各文字を個別のノードとして格納する必要があるため、メモリ効率が悪くなる場合があります。

## 優先キュー

- **優先キュー**: 各要素に優先度がある抽象データ型です。
- **キューとスタック**: キューとスタックは挿入順序のみを考慮しますが、優先キューは要素の優先度を考慮します。標準のキューはFIFO（先入れ先出し）、スタックはLIFO（後入れ先出し）です。
- **削除順序**: 通常は最も優先度の高い要素が最初に削除されますが、実装によっては最も優先度の低い要素を先に削除する場合もあります。
- **同順位の処理**: 同じ優先度の要素を挿入順に削除したい場合は、一意のカウンターを追加して同順位の処理を分けることができます。
- **用途**: 2地点間の最短経路探索、OSのタスクスケジューリング、交通シミュレーション、データ圧縮、ネットワーク管理などに使われます。

## ヒープ

ヒープは、ヒープ特性と呼ばれる非常に特定の特性を持つ、特殊な木構造のデータ構造です。

ヒープ特性は親ノードと子ノードの関係を決めます。ヒープには2種類あります：

- **最大ヒープ**: 各親ノードの値は子ノードの値以上であり、最大の要素がルートにあります。

- **最小ヒープ**: 各親ノードの値は子ノードの値以下であり、最小の要素がルートにあります。

JavaScriptには組み込みのヒープモジュールはありませんが、配列を使って最小ヒープを実装できます。

- **配列による格納**: ヒープは通常、親ノードと子ノードに効率的にアクセスするために配列で実装されます。ヒープが完全二分木の構造を維持している場合、配列のインデックスに基づく単純な算術演算だけで要素の位置を見つけられます。
- **インデックス**: インデックス`i`のノードの親は`Math.floor((i - 1) / 2)`、左の子は`2 * i + 1`、右の子は`2 * i + 2`にあります。
- **Peek**: ヒープ特性を保ったまま、最小値または最大値（ヒープの種類による）を取得します。
- **Push**: ヒープ特性を保つために、要素を適切な位置に追加します。新しい要素は配列の末尾に追加され、親と入れ替えながら上に移動し（バブルアップ）、ヒープ特性が保たれます。
- **Pop**: 最も優先度の高い要素（この場合は最小値）を削除します。配列の最後の要素がルートに置き換わり、子と入れ替えながら下に移動し（バブルダウン）、ヒープ特性が保たれます。
- **PushPop**: これら2つの操作を1回の呼び出しで行います。特にヒープが大きい場合、個別に呼び出すより効率的で、再配置操作が1回だけ行われます。
- **Heapify**: 既存の配列をヒープに変換します。
- **比較コールバック**: JavaScriptの配列は自動的に要素ごとに比較されないため、優先度を比較する関数をヒープに渡します。例えば、`[priority, element]`として格納されたアイテムに対しては`new MinHeap((a, b) => a[0] - b[0])`のようにします。値が小さいほど優先度が高いことを表します。
- **安定した同順位処理**: 各アイテムの2番目の要素として増加する挿入カウンターを含めます。例: `[priority, counter, element]`。優先度をまず比較し、同じ場合はカウンターを比較します。`new MinHeap((a, b) => (a[0] - b[0]) || (a[1] - b[1]))`。
- **時間計算量**: 最小値または最大値の挿入と抽出は`O(log n)`、Peekは`O(1)`、Heapifyは`O(n)`、任意の要素の検索や削除は`O(n)`です。
- **空間計算量**: ヒープに含まれる要素数を`n`とすると`O(n)`です。

## 動的計画法の紹介

- **定義**: 動的計画法は複雑な問題をより単純な部分問題に分割し、結果を保存して重複計算を避けるアルゴリズム手法です。
- **重複部分問題**: 大きな問題を解く際に同じ小さな問題が何度も現れます。これらを繰り返し計算する代わりに結果を保存します。
- **最適部分構造**: 問題の最適解は部分問題の最適解から構成されます。つまり、小さな部分の最適解を組み合わせて最適解を作れます。

## 動的計画法の解法

- **メモ化（トップダウンアプローチ）**: 高コストな関数呼び出しの結果を保存し、同じ入力が再度現れたときにキャッシュされた結果を返します。

- **タビュレーション（ボトムアップアプローチ）**: 下から順に解を構築し、部分問題の解をテーブルに埋めていきます。

## 動的計画法を使った実世界のアプリケーション

- **ルート最適化**：GPSシステムは動的計画法のアルゴリズムを使って、場所間の最短経路を見つけます。
- **テキスト処理**：スペルチェッカーやオートコンプリート機能は、単語間の編集距離を計算するために動的計画法をよく利用します。
- **金融モデリング**：投資戦略やポートフォリオの最適化には動的計画法の手法が頻繁に使われます。
- **資源配分**：ナップサック問題やその派生問題は、スケジューリング、予算管理、資源管理に現れます。

## 動的計画法を使うべき場合

次のような場合に動的計画法の使用を検討してください：

- 問題が重複する部分問題に分解できる。
- 問題が最適部分構造を持つ。
- 単純な再帰的解法では計算が繰り返される。
- 時間計算量を優先し、空間計算量を犠牲にしてもよい。

## 純粋関数と不純関数

- 純粋関数は同じ入力に対して常に同じ出力を返し、副作用がありません。出力は入力のみに依存し、外部の状態を変更しません。
- 不純関数は副作用を持ち、関数外のプログラムの状態に変化をもたらします。

## 関数型プログラミング

- 関数型プログラミングは、問題を解決するために関数の利用を重視し、「何をするか」にフォーカスするソフトウェア開発の手法です。
- 関数型プログラミングは、副作用を避けるために不変のデータ構造や高階関数の使用などの手法を推奨します。
- 正しく使うと、関数型プログラミングの原則はよりクリーンで保守しやすいコードにつながります。

## カリー化

- カリー化は複数の引数を取る関数を、1つの引数を取る関数の連続に変換する関数型プログラミングの手法です。

例えば、カリー化は `average(a, b, c)` の呼び出しを連続した呼び出し `curriedAverage(a)(b)(c)` に変換します。

- カリー化は多くの引数を取る関数で特に強力です。
- カリー化によりコードが柔軟で再利用しやすくなります。
- アロー関数を使うとカリー化関数をより簡潔に作成できます。

```js
const curriedAverage = a => b => c => (a + b + c) / 3;
```

- ただし、カリー化を多用しすぎるとコードの可読性が下がる場合があります。

- **同期的 JavaScript** は順番に実行され、前の操作が終わるまで次に進みません。
- **非同期的 JavaScript** はメインスレッドをブロックせずに複数の操作をバックグラウンドで実行できます。
- **スレッド** はメインプログラムの流れとは独立して実行できる命令の連続です。
- **コールバック関数** は他の関数に引数として渡され、操作完了後やイベント発生時に実行される関数です。

## JavaScript エンジンと JavaScript ランタイム

- **JavaScriptエンジン**はウェブブラウザでJavaScriptコードを実行するプログラムです。コードを受け取り、コンピュータが理解して動作できる命令に変換します。
- V8はGoogleが開発したJavaScriptエンジンの例です。
- **JavaScriptランタイム**はJavaScriptコードが実行される環境で、コードを処理・実行するJavaScriptエンジンと、ウェブブラウザやNode.jsのような追加機能を含みます。

## Fetch API

- Fetch API はウェブアプリがサーバーにネットワークリクエストを送るための仕組みで、データの取得や送信に使われます。`fetch()` メソッドを使ってリクエストを行います。
- テキスト、画像、音声、JSON など様々なデータを Fetch API で取得できます。

## Fetch API の HTTP メソッド

Fetch API はサーバーとやり取りするために様々な HTTP メソッドをサポートしています。一般的なメソッドは以下の通りです。

- **GET**: サーバーからデータを取得するために使います。デフォルトでは Fetch API は `GET` メソッドを使ってデータを取得します。

取得したデータを使うには `.json()` メソッドで JSON 形式に変換する必要があります。

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
```

このコードでは、`fetch()` はPromiseを返し、`.then()` ハンドラが解決されたレスポンスをJSON形式に変換しています。

- **POST**: サーバーにデータを送信し、新しいリソースを作成するために使います。`POST` メソッドを使います。

```js
fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Doe',
    email: 'john@example.com'
  })
})
```

この例では新しいユーザーを作成するために `POST` リクエストを送っています。メソッドは `POST` に設定し、適切なヘッダーを指定し、送信したいデータをボディに含めています。ボディは文字列である必要があるため、`JSON.stringify()` でオブジェクトを JSON 文字列に変換しています。

- **PUT**: サーバー上の既存データを更新するために使います。`PUT` メソッドを使います。

更新の場合は、`method: 'PUT'` を指定し、リクエストボディに更新データを含めます。URLは更新対象のリソースを特定します。

- **DELETE**: サーバー上のデータを削除するために使います。`DELETE` メソッドを使います。

`method: 'DELETE'` を設定し、削除対象のリソースを特定するURLを使います。

## Promise と Promise チェーン

- **Promise**は非同期操作の最終的な完了または失敗と、その結果の値を表すオブジェクトです。Promiseの値は非同期操作が完了したときにのみわかります。
- シンプルなPromiseを作成する例はこちらです：

```js
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```

- `.then()` メソッドはPromiseが成功したときに実行する処理を指定し、`.catch()` はエラーが発生したときの処理を行います。

- **Promiseチェーン**: Promiseの強力な機能の一つは複数の非同期処理を連鎖させられることです。各 `.then()` は新しいPromiseを返し、非同期処理を順番に実行できます。

`catch` メソッドは処理中に発生したエラーを処理します。これにより各ステップでエラー処理を書く必要がなくなり、コードが大幅に簡潔になります。

## `async/await` を使った Promise の扱い方

`async`/`await` はPromiseの上に構築されており、非同期コードの記述と読み取りを簡単にします。

- **async**: `async` キーワードは非同期関数を定義するために使用します。`async` 関数は Promise を返し、その Promise は `async` 関数が返す値で解決されます。
- **await**: `await` キーワードは `async` 関数の内部で使用し、Promise が解決されるまで関数の実行を一時停止します。`async` 関数の内部でのみ使用できます。

- `async/await` の最大の利点の一つは `try/catch` ブロックによるエラー処理です。以下は例です。

```js
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

fetchData();
```

上の例では `try` ブロックにエラーが発生する可能性のあるコードがあり、`catch` ブロックがエラーを処理します。これによりエラー処理がより簡潔で読みやすくなります。

## `async` 属性

- `async` 属性はブラウザにスクリプトファイルを非同期にダウンロードしながらHTMLドキュメントの解析を続けるよう指示します。
- スクリプトがダウンロードされるとHTML解析は一時停止し、スクリプトが実行され、その後HTML解析が再開されます。
- 実行順序が重要でない独立したスクリプトには`async` を使うべきです。

## `defer` 属性

- `defer` 属性もスクリプトを非同期にダウンロードしますが、HTMLドキュメントの解析が完全に終わるまでスクリプトの実行を遅延させます。
- `defer` スクリプトはHTMLドキュメントに現れる順序で実行順序を維持します。

- `async` と `defer` 属性はインラインスクリプトには無視され、外部スクリプトファイルにのみ有効です。

- `async` と `defer` 属性が両方ある場合は `async` 属性が優先されます。

## Geolocation API

- Geolocation API はウェブサイトがユーザーの位置情報を取得する方法を提供します。

- 以下の例は、ユーザーの現在位置を取得するために使用されるAPIの`getCurrentPosition()`メソッドを示しています。

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

このコードでは、`getCurrentPosition`を呼び出し、位置情報が正常に取得されたときに呼び出される関数を渡しています。

`position` オブジェクトには様々な情報が含まれていますが、ここでは `latitude` と `longitude` のみを選択しています。

`position` の取得に問題がある場合は、エラーがコンソールに出力されます。

- ユーザーのプライバシーを尊重し、必要な場合にのみ位置情報をリクエストすることが重要です。
