# --description--

Se te ha proporcionado un modelo básico. Comienza agregando un elemento `link` dentro del elemento `head`. Para ese elemento `link`, establece el atributo `rel` en `stylesheet` y el atributo `href` en `./styles.css`.

# --hints--

Debes tener un elemento `link`.

```js
assert.exists(document.querySelector("head>link"));
```

El elemento `link` debe tener un atributo `rel` y un atributo `href` establecido en `stylesheet` y `./styles.css`.

```js
const link = document.querySelector("head>link");
assert.equal(link?.getAttribute("rel"), "stylesheet");
const href = link?.getAttribute("data-href");
console.log(href)
assert.oneOf(href, ["./styles.css", "styles.css"]);
```
