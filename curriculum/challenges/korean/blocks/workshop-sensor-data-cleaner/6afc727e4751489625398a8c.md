# --description--

이제 차이를 `+3.6 °C` 같은 텍스트 레이블로 바꾸세요. 양수는 부호 없이 출력되므로, 앞에 `+`를 추가해야 합니다.

조건을 만족하는 항목만 포함하려면, 리스트 내포 끝에 후행 `if`를 추가할 수 있습니다:

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

`difference_labels`라는 변수를 만드세요. 리스트 내포를 사용해 `differences`의 각 `difference`에 대해 `difference`가 `0`보다 클 때만 `f'+{difference} °C'`를 포함하는 리스트를 할당하세요.

그런 다음 `differences` 대신 `difference_labels`를 출력하세요.

터미널에서는 7개의 온도 중 3개의 레이블만 보입니다. 후행 `if`는 조건에 맞지 않는 항목을 제외하므로, 각 레이블이 어떤 온도에 속하는지 알 수 없습니다. 다음 단계에서 이 문제를 고치세요.
