# --description--

Antes de trabalhar com as leituras, você precisa remover os códigos de erro.

Como você aprendeu nas lições anteriores, a função `filter()` mantém apenas os itens de um iterável para os quais uma função retorna um valor truthy. Em vez de definir essa função com `def`, você pode passar uma função lambda diretamente para `filter()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

Crie uma variável chamada `valid_readings`. Atribua a ela o resultado de passar para `filter()` uma função lambda e `readings`. A função lambda deve receber um parâmetro chamado `reading` e verificar se `reading` não é igual a `-999`.

Depois, imprima `valid_readings` em vez de `readings`.
