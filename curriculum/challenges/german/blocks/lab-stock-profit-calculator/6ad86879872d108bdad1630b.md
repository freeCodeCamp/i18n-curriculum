# --description--

In diesem Labor finden Sie den besten Gewinn, den Sie aus einem einzelnen Aktienhandel erzielen können. Sie erhalten den Preis einer Aktie an jedem Tag, und Sie können an einem Tag eine Aktie kaufen und an einem späteren Tag verkaufen. Ihr Ziel ist es, den höchsten Gewinn zu finden, den Sie erzielen können, also den Verkaufspreis minus den Kaufpreis.

Zum Beispiel ist bei den Preisen `[7, 1, 5, 3, 6, 4]` der beste Handel, am Tag `1` zu einem Preis von `1` zu kaufen und am Tag `4` zu einem Preis von `6` zu verkaufen, was einen Gewinn von `5` ergibt. Sie können nicht bei `1` kaufen und bei `7` verkaufen, weil der Preis von `7` vor dem Preis von `1` liegt.

Die Liste kann sehr lang sein, daher sollte Ihre Lösung effizient sein. Jeden möglichen Kauf- und Verkaufstag zu vergleichen würde quadratische Zeit, `O(n²)`, benötigen. Finden Sie stattdessen eine Möglichkeit, die Liste nur einmal zu durchlaufen, sodass Ihre Lösung in linearer Zeit, `O(n)`, läuft.

**Ziel:** Erfüllen Sie die untenstehenden User Stories und bestehen Sie alle Tests, um das Labor abzuschließen.

**User Stories:**

1. Sie sollten eine Funktion namens `max_profit` haben, die einen Parameter hat, der eine Liste von positiven ganzen Zahlen darstellt, wobei jedes Element den Preis der Aktie an diesem Tag ist.
1. `max_profit` sollte den höchsten Gewinn zurückgeben, der durch Kauf an einem Tag und Verkauf an einem späteren Tag erzielt werden kann.
1. Wenn kein Handel Gewinn bringt oder `prices` weniger als zwei Elemente hat, sollte `max_profit` `0` zurückgeben.
1. `max_profit` sollte `prices` nicht verändern.
1. `max_profit` sollte in linearer Zeit, `O(n)`, laufen, wobei `n` die Länge von `prices` ist.

**Hinweis:** Statt jeden Tag mit jedem anderen zu vergleichen, versuchen Sie, den bisher niedrigsten Preis zu verfolgen, während Sie die Liste durchgehen, und berechnen Sie den Gewinn, wenn Sie am aktuellen Tag verkaufen.

```py
def max_profit(prices):
    lowest_price = float("inf")
    best_profit = 0

    for price in prices:
        if price < lowest_price:
            lowest_price = price
        elif price - lowest_price > best_profit:
            best_profit = price - lowest_price

    return best_profit
```
