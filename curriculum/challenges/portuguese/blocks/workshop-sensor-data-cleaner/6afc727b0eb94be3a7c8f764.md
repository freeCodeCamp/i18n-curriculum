# --description--

A função `map()` chama uma função em cada item de um iterável e retorna um iterador dos resultados. Assim como com `filter()`, você pode passar uma função lambda:

```py
prices = [10, 20, 30]
discounted = list(map(
    lambda price: price * 0.9,
    prices
))
print(discounted) # [9.0, 18.0, 27.0]
```

Agora você precisa converter as leituras válidas de décimos de grau para graus.

Crie uma variável chamada `temperatures`. Atribua a ela o resultado de passar para `map()` uma função lambda e `valid_readings`, envoltos em uma chamada `list()`. A função lambda deve receber um parâmetro chamado `reading` e retornar `reading` dividido por `10`.

Depois, imprima `temperatures` em vez de `valid_readings`.
