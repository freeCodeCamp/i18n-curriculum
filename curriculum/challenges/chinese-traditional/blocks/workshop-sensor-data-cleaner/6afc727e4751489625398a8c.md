# --description--

現在你將把差異轉換成像 `+3.6 °C` 這樣的文字標籤。正數列印時不會帶符號，所以你需要在它們前面加上 `+`。

若只想包含符合條件的項目，可以在列表推導式的末尾加上尾隨的 `if`：

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

創建一個名為 `difference_labels` 的變數。使用列表生成式，為每個 `differences` 中的 `difference` 指定一個列表，內容是 `f'+{difference} °C'`，但只包含 `difference` 大於 `0` 的項目。

然後，列印 `difference_labels`，而不是 `differences`。

在終端機中，你會看到 7 個溫度中只有 3 個標籤。尾隨的 `if` 會排除不符合條件的項目，因此無法判斷每個標籤對應哪個溫度。你會在下一步修正這個問題。
