# --description--

最後，為藍色標記的 `box-shadow` 屬性，將命名顏色替換為 `hsla` 函式。

`hsla` 函式的運作方式和 `hsl` 函式一樣，但多了第四個值 alpha，用來控制顏色的不透明度。和 `rgba` 一樣，alpha 值是介於 `0` 到 `1.0` 的數字。基本語法如下：

```css
hsla(hue, saturation, lightness, alpha);
```

使用 `223` 作為色相，`59%` 作為飽和度，`31%` 作為亮度，以及 `0.8` 作為 alpha 通道。

這樣，你的彩色標記工作坊就完成了！做得好。

# --hints--

你的 `.blue` CSS 規則應該有一個 `box-shadow` 簡寫屬性，且值為 `0 0 20px 0 hsla(223, 59%, 31%, 0.8)`。

```js
assert.strictEqual(new __helpers.CSSHelp(document).getStyle('.blue')?.boxShadow, 'rgba(32, 59, 126, 0.8) 0px 0px 20px 0px');
```
