# --description--

在之前的課程中，你一直是用 `def` 關鍵字來定義函式（程式），像這樣：

```py
def square(num):
    return num ** 2

print(square(4)) # 16
```

在上一課中，你將像 `is_long_word` 和 `to_fahrenheit` 這樣的函式傳遞給 `map()` 和 `filter()`。接受另一個函式作為引數的函式稱為高階函式。每次需要將一個簡短的函式傳遞給高階函式時，都用 `def` 定義一個獨立的函式會有點冗長。相反地，你可以直接在需要的地方寫一個 lambda 函式，這是一種沒有名稱的函式。

lambda 函式的語法看起來像這樣：

```py
lambda parameters: expression
```

在 `lambda` 關鍵字之後，列出函式的參數。冒號將參數與單一表達式分開，該表達式的結果會自動傳回，無需使用 `return` 述語。

以下是將 `square()` 函式（程式）重構為 lambda 函式（程式）後的樣子：

```py
lambda num: num ** 2
```

這裡，`num` 是參數，而 `num ** 2` 是會被傳回結果的表達式。如前所述，lambda 函式是匿名的，因此這個函式不再有名稱 `square` 相關聯。

lambda 函式也可以有多個參數。就像用 `def` 定義的函式一樣，你用逗號分隔參數：

```py
lambda a, b: a + b
```

這個 lambda 函式接受兩個參數 `a` 和 `b`，並傳回它們的和。

當你需要將函式傳遞給高階函式時，lambda 函式非常適合用在這種情況：

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

在這個例子中，我們有一個數字列表，想要創建一個新的偶數列表。因此，我們將一個 lambda 函式作為引數傳入 `filter()` 函式。`filter()` 函式會對每個數字呼叫這個 lambda 函式，並只保留對於 `x % 2 == 0` 為 `True` 的數字。接著 `list()` 將它們收集成一個包含數字 `2` 和 `4` 的新列表。

在使用 lambda 函式（程式）時，了解最佳實務非常重要。例如，將 lambda 函式（程式）指定給變數像這樣並不是一個好的做法：

```py
numbers = [1, 2, 3, 4, 5]

square = lambda x: x ** 2
squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

這違背了使用匿名函式（程式）的目的。在這種情況下，你應該使用一般函式（程式），像這樣：

```py
numbers = [1, 2, 3, 4, 5]

def square(num):
    return num ** 2

squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

此外，你應該避免建立難以閱讀或不必要複雜的 lambda 函式（程式），例如這樣：

```py
result = (lambda x: (x**2 + 2*x - 1) if x > 0 else (x**3 - x + 4))(3)
print(result)  # 14
```

雖然這個函式（程式）執行正常並產生正確的結果 `14`，但它不容易閱讀或觀看。在這種情況下，為你的程式碼創建一個帶有 `if/else` 述語的獨立函式（程式），然後呼叫該函式會比較好：

```py
def calculate_expression(x):
    if x > 0:
        return x**2 + 2*x - 1
    else:
        return x**3 - x + 4

print(calculate_expression(3))  # 14
```

在 Python 程式中，普通函式和 lambda 函式各有其使用場合。如果你處理的是單一行內表達式，則可以考慮使用 lambda 函式。否則，使用普通函式會是更好的選擇。
