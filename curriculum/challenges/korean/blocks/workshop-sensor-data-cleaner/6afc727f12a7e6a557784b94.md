# --description--

모든 차이에 대해 레이블을 얻으려면, 끝에 오는 `if` 대신 `for` 앞에 조건 표현식을 사용하세요:

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

리스트 내포에서 끝에 있는 `if`를 제거하세요. 그런 다음, `for` 앞의 표현식을 `difference`가 `0`보다 클 때 `f'+{difference} °C'`로 평가되고, 그렇지 않을 때는 `f'{difference} °C'`로 평가되는 조건부 표현식으로 바꾸세요. 음수는 이미 `-` 기호가 있으므로 단위만 붙이면 됩니다.
