# --interactive--

複習下列概念，為即將到來的準備考試做好準備。

## 操作 HTML、CSS 和 JavaScript

HTML 和 CSS 提供網站的結構，而 JavaScript 則為網站帶來互動性，讓網站能夠實現複雜的功能，例如處理使用者輸入、動畫效果，甚至建立完整的網頁應用程式。

## JavaScript 中的資料型別

資料型別幫助程式理解它正在處理的是哪一種資料，不論是數字、文字還是其他型別。

- **Number**：數字代表整數和浮點數值。整數的例子有 7、19 和 90。
- **Floating point**：浮點數是帶有小數點的數字。例如 3.14、0.5 和 0.0001。
- **String**：字串是一連串的字元或文字，需用引號包住。`"I like coding"` 和 `'JavaScript is fun'` 都是字串的例子。
- **Boolean**：布林值代表兩種可能的值之一：`true` 或 `false`。你可以用布林值來表示條件，例如 `isLoggedIn = true`。
- **Undefined 和 Null**：`undefined` 值是指已宣告但尚未指定值的變數。`null` 值則是空值，或是刻意將變數指定為 `null`。
- **Object**：物件是一種鍵值對的群集。鍵是屬性名稱，值則是屬性值。

例如，`{ name: "Fluffy", age: 3, type: "dog" }` 有三個屬性：`name`、`age` 和 `type`。

- **Symbol**：Symbol 資料型別是一個獨特且不可變的值，可用作物件屬性的識別符。

兩個使用相同描述建立的符號仍然是不同的值。

- **BigInt**：當數字太大，超出 `Number` 資料型別的範圍時，你可以使用 BigInt 資料型別來表示任意長度的整數。

只要在數字後面加上 `n`，就能建立 BigInt。

## JavaScript 中的變數

- 你可以使用 `let` 關鍵字來宣告變數。

- 若要為變數指定值，可以使用指定運算子 `=`。

- 使用 `let` 宣告的變數可以重新指定新值。

- 除了 `let` 之外，你也可以用 `const` 來宣告變數。不過，`const` 變數不能被重新指定新值。

- 使用 `const` 宣告的變數，常用於宣告常數，這些值在整個程式碼中都不允許變動，例如 `PI` 或 `MAX_SIZE`。

## 變數命名慣例

- 變數名稱應該具描述性且有意義。
- 變數名稱應採用駝峰式命名法，例如 `cityName`、`isLoggedIn` 和 `veryBigNumber`。
- 變數名稱不能以數字開頭，必須以字母、`_` 或 `$` 開頭。
- 變數名稱不能包含空格或特殊字元，除了 `_` 和 `$`。
- 變數名稱不能是保留關鍵字。
- 變數名稱區分大小寫。`age` 和 `Age` 是不同的變數。

## JavaScript 中的字串與字串不變性

- 字串是用引號包住的一連串字元。你可以用單引號或雙引號建立字串。

- 在 JavaScript 中，字串是不可變的。這表示一旦建立字串，就不能改變字串中的字元。不過，你仍然可以將字串重新指定為新值。

## JavaScript 中的字串串接

- 串接是將多個字串連接起來，或將含有文字的變數與字串結合的過程。`+` 運算子是最簡單且最常用的字串串接方法之一。

- 如果你需要在現有字串後面新增內容，可以使用 `+=` 運算子。這在你想隨時間逐步擴充字串時很有用。

- 另一種串接字串的方法是使用 `concat()` 方法。這個方法可以將兩個或多個字串合併在一起。

## 使用 `console.log()` 記錄訊息

- `console.log()` 方法用來將訊息記錄到主控台。這是偵錯和測試程式碼時很有幫助的工具。

## JavaScript 中的分號

- 分號主要用來標示述語的結尾。這有助於 JavaScript 引擎理解每個指令的分隔，對正確執行來說非常重要。

- 分號有助於避免程式執行時產生歧義，並確保述語正確結束。

## JavaScript 中的註解

- 任何被註解掉的程式碼行都會被 JavaScript 引擎忽略。註解用來說明程式碼、做筆記或暫時停用程式碼。
- 單行註解可用 `//` 建立。

- 多行註解則用 `/*` 開始註解，並用 `*/` 結束註解。

## JavaScript 是動態型別語言

- JavaScript 是動態型別語言，這表示你在宣告變數時不需要指定資料型別。JavaScript 引擎會根據指定給變數的值自動判斷資料型別。

- 在像 C# 這樣的靜態型別語言中，將字串指定給整數變數會導致錯誤。

## 使用 `typeof` 運算子

- `typeof` 運算子用來檢查變數的資料型別。它會傳回一個字串，指出變數的型別。

- 不過，JavaScript 在 `null` 上有個眾所皆知的怪癖。`typeof` 運算子對 `"object"` 值會傳回 `null`。

## 字串基礎

- **定義**：字串是一連串用單引號、雙引號或反引號包住的字元。字串屬於原始資料型別，且具有不可變性。不變性代表字串一旦建立就無法更改。
- **從字串存取字元**：你可以用中括號標記法並傳入索引數字來存取字串中的字元。索引是字元在字串中的位置，從 0 開始。

- **`\n`（換行字元）**：你可以用 `\n` 換行字元在字串中產生換行。

- **跳脫字串**：你可以在字串中的引號前面放置反斜線（`\`）來跳脫字元。

:::interactive_editor

```js
const statement = "She said, \"Hello!\"";
console.log(statement); // She said, "Hello!"
```

:::

## 樣板字面值（樣板字串）與字串插值

- **定義**：樣板字面值用反引號（`）定義。它們讓字串操作更容易，包括直接在字串中嵌入變數，這個功能稱為字串插值。

:::interactive_editor

```js
const name = "Jessica";
const greeting = `Hello, ${name}!`; 
console.log(greeting); // "Hello, Jessica!"
```

:::

## ASCII、`charCodeAt()` 方法與 `fromCharCode()` 方法

- **ASCII**：ASCII（American Standard Code for Information Interchange）是一種字元編碼標準，用數值來表述基本英文字元。早期課程介紹了使用 ASCII 範例的 `charCodeAt()` 和 `fromCharCode()`。
- **Unicode**：JavaScript 字串在內部使用 Unicode，特別是 UTF-16 編碼。對於前 128 個字元（基本拉丁字母、數字和常用符號），Unicode 值與 ASCII 程式碼相符。這就是為什麼基於 ASCII 的範例在 JavaScript 中仍然有效。
- **`charCodeAt()` 方法**：此方法會傳回指定索引處字元的 UTF-16 編碼單元。對於基本拉丁字元，此值與 ASCII 碼相符。

- **`fromCharCode()` 方法**：這個方法會將 ASCII 代碼轉換成對應的字元。

## 其他常見字串方法

- **`indexOf` 方法**：這個方法用來在字串中搜尋子字串。如果找到子字串，`indexOf` 會傳回該子字串第一次出現的索引（位置）；如果找不到，`indexOf` 則會傳回 -1，表示搜尋失敗。

- **`includes()` 方法**：這個方法用來檢查字串是否包含特定子字串。如果找到，方法會傳回 true，否則傳回 false。

- **`slice()` 方法**：此方法擷取字串的一部分並傳回新的字串，而不修改原始字串。它接受兩個參數：起始索引和選用的結束索引。

- **`toUpperCase()` 方法**：這個方法會將所有字元轉換為大寫字母，並傳回一個全為大寫的新字串。

- **`toLowerCase()` 方法**：這個方法會將字串中的所有字元轉換為小寫。

- **`replace()` 方法**：這個方法讓你在字串中尋找特定值（如單字或字元），並將其取代為其他值。該方法會傳回一個帶有替換內容的新字串，原始字串不會被改變，因為 JavaScript 字串是不可變的。

- **`replaceAll()` 方法**：此方法允許你在字串中尋找指定值（字、字元或樣式）的所有出現，並將它們替換為另一個值。它的運作方式類似 `replace()`，但不會在找到第一個符合項目後停止，而是更新字串中找到的每一個符合項目。

- **`repeat()` 方法**：這個方法用來將字串重複指定次數。

- **`trim()` 方法**：這個方法用來移除字串開頭和結尾的空白字元。

- **`trimStart()` 方法**：這個方法會移除字串開頭（或「起始」）的空白字元。

- **`trimEnd()` 方法**：這個方法會移除字串結尾的空白字元。

- **`prompt()` 方法**：這個 `window` 的方法用來透過對話盒向使用者取得資訊。這個方法接受兩個引數。第一個引數是訊息，會顯示在對話盒中，通常用來提示使用者輸入資訊。第二個引數是預設值（選填），會預先填入輸入欄位。

## 操作 Number 資料型別

- **定義**：JavaScript 的 `Number` 型別包含整數、浮點數、`Infinity` 和 `NaN`。浮點數是帶有小數點的數字。正 `Infinity` 是大於任何其他數字的數值，而 `-Infinity` 則是小於任何其他數字的數值。`NaN`（`Not a Number`）代表無效的數值，例如字串 `"Jessica"`。

## 常見算術運算

- **加法運算子**：這個運算子（`+`）用來計算兩個或多個數字的總和。
- **減法運算子**：這個運算子（`-`）用來計算兩個數字的差值。
- **乘法運算子**：這個運算子（`*`）用來計算兩個或多個數字的乘積。
- **除法運算子**：這個運算子（`/`）用來計算兩個數字的商。
- **除以零**：如果你嘗試除以零，JavaScript 會傳回 `Infinity`。
- **餘數運算子**：這個運算子（`%`）會傳回除法的餘數。
- **指數運算子**：這個運算子（`**`）會將一個數字提升到另一個數字的次方。

## 數字與字串的運算

- **說明**：當你使用 `+` 運算子搭配數字和字串時，JavaScript 會將數字強制轉換成字串並將兩者串接起來。當你使用 `-`、`*` 或 `/` 運算子搭配字串和數字時，JavaScript 會將字串強制轉換成數字，結果會是數字。對於 `null` 和 `undefined`，JavaScript 在數學運算中會將 `null` 視為 0，將 `undefined` 視為 `NaN`。

## 運算子優先順序

- **定義**：運算子優先決定運算式中操作的評估順序。優先較高的運算子會先於優先較低的運算子被評估。括號內的值會先被評估，且乘法／除法的優先會高於加法／減法。如果運算子具有相同的優先，則 JavaScript 會使用結合性。

- **定義**：結合性告訴我們當存在多個相同類型的運算子時，表達式的求值方向。它定義表達式是應該從左到右（`left-associative`）還是從右到左（`right-associative`）求值。例如，指數運算子也是從右到左結合的。

## 累加與遞減運算子

- **累加運算子**：這個運算子用來將值加 1。前置式 `++num` 會先將變數的值加 1，再傳回新值。後置式 `num++` 則會先傳回目前的值，再將其加 1。

- **遞減運算子**：這個運算子用來將值減 1。前置式和後置式的運作方式與累加運算子相同。

## 複合指定運算子

- **加法指定（`+=`）運算子**：這個運算子會將值相加，並將結果指定給變數。
- **減法指定（`-=`）運算子**：這個運算子會將值相減，並將結果指定給變數。
- **乘法指定（`*=`）運算子**：這個運算子會將值相乘，並將結果指定給變數。
- **除法指定（`/=`）運算子**：這個運算子會將值相除，並將結果指定給變數。
- **餘數指定（`%=`）運算子**：這個運算子會將變數除以指定數字，並將餘數指定給變數。
- **次方指定（`**=`）運算子**：這個運算子會將變數提升為指定數字的次方，並將結果重新指定給變數。

## 布林值與相等性

- **布林值定義**：布林值是一種只能有兩個值的資料型別：`true` 或 `false`。
- **相等（`==`）運算子**：這個運算子在檢查值是否相等前會進行型別轉換。

- **嚴格相等（`===`）運算子**：這個運算子不會進行型別轉換，會檢查型別和值是否都相等。

- **不相等 (`!=`) 運算子**：此運算子在檢查值是否不相等之前會使用型別強制轉換。
- **嚴格不相等 (`!==`) 運算子**：此運算子不執行型別強制轉換，並檢查型別和數值是否皆不相等。

## 比較運算子

- **大於（`>`）運算子**：這個運算子會檢查左邊的值是否大於右邊的值。
- **大於等於（`>=`）運算子**：這個運算子會檢查左邊的值是否大於或等於右邊的值。
- **小於（`<`）運算子**：這個運算子會檢查左邊的值是否小於右邊的值。
- **小於等於（`<=`）運算子**：這個運算子會檢查左邊的值是否小於或等於右邊的值。

## 一元運算子

- **一元加號運算子**：這個運算子會將其運算元轉換為數字。如果運算元本來就是數字，則不變。

- **一元負號（`-`）運算子**：這個運算子會將運算元取負值。

- **邏輯 NOT（`!`）運算子**：這個運算子會反轉運算元的布林值。如果運算元是 `true`，就會變成 `false`；如果是 `false`，就會變成 `true`。

## 位元運算子

- **位元 AND（`&`）運算子**：這個運算子會在兩個運算元的每個位元位置上，若兩者皆為 1，則傳回 1。
- **位元 AND 指定（`&=`）運算子**：這個運算子會對指定數字進行 `bitwise AND` 運算，並將結果重新指定給變數。
- **位元 OR（`|`）運算子**：這個運算子會在兩個運算元的每個位元位置上，只要其中之一為 1，就傳回 1。
- **位元 OR 指定（`|=`）運算子**：這個運算子會對指定數字進行 `bitwise OR` 運算，並將結果重新指定給變數。
- **位元 XOR（`^`）運算子**：這個運算子會在兩個運算元的每個位元位置上，僅當其中一個為 1（但不是兩者同時為 1）時傳回 1。
- **位元 NOT（`~`）運算子**：這個運算子會將數字的二進位表示反轉。
- **左移（`<<`）運算子**：這個運算子會將所有位元向左移動指定的位數。
- **右移（`>>`）運算子**：這個運算子會將所有位元向右移動。

## 條件判斷、Truthy 值、Falsy 值與三元運算子

- **`if/else if/else`**：`if` 判斷式會帶入一個條件，若該條件為 `truthy`，則執行一段程式碼區塊。如果條件為 `false`，則會進入 `else if` 區塊。如果這些條件都不是 `true`，則會執行 `else` 語句。`Truthy` 值是在布林情境（如 `true` 判斷式）下會被評估為 `if` 的任何值。`Falsy` 值則是在布林情境下會被評估為 `false` 的值。

:::interactive_editor

```js
const score = 87;

if (score >= 90) {
 console.log('You got an A'); 
} else if (score >= 80) {
 console.log('You got a B'); // You got a B
} else if (score >= 70) {
 console.log('You got a C');
} else {
 console.log('You failed! You need to study more!');
}
```

:::

- **三元運算子**：這個運算子常用來簡化 `if else` 判斷式的寫法。

:::interactive_editor

```js
const temperature = 30;
const weather = temperature > 25 ? 'sunny' : 'cool';

console.log(`It's a ${weather} day!`); // It's a sunny day!
```

:::

## 二元邏輯運算子

- **邏輯 AND (`&&`) 運算子**：此運算子會檢查兩個運算元是否皆為 `true`。如果兩者皆為 `true`，則會傳回第二個值。如果任一運算元為 `falsy`，則會傳回該 `falsy` 值。如果兩個運算元皆為 `falsy`，則會傳回第一個 `falsy` 值。

- **邏輯 OR (`||`) 運算子**：此運算子會檢查是否至少有一個運算元為真值。
- **Nullish Coalescing (`??`) 運算子**：只有當第一個值是 `null` 或 `undefined` 時，這個運算子才會傳回該值。

## `Math` 物件

- **`Math.random()` 方法**：這個方法會產生一個介於 0（包含）和 1（不包含）之間的隨機浮點數。也就是說，可能的輸出可以是 0，但永遠不會到達 1。
- **`Math.max()` 方法**：這個方法會取一組數字並傳回最大值。
- **`Math.min()` 方法**：這個方法會取一組數字並傳回最小值。
- **`Math.ceil()` 方法**：這個方法會將數值無條件進位到最接近的整數。
- **`Math.floor()` 方法**：這個方法會將數值無條件捨去到最接近的整數。
- **`Math.round()` 方法**：這個方法會將數值四捨五入到最接近的整數。

- **`Math.trunc()` 方法**：這個方法會移除數字的小數部分，只傳回整數部分，不會進行四捨五入。
- **`Math.sqrt()` 方法**：這個方法會傳回數字的平方根。
- **`Math.cbrt()` 方法**：這個方法會傳回數字的立方根。
- **`Math.abs()` 方法**：這個方法會傳回數字的絕對值。
- **`Math.pow()` 方法**：這個方法會將第一個數字提升為第二個數字的次方。

## 常見的數字方法

- **`isNaN()`**：`NaN` 代表「不是數字」（Not-a-Number）。這是一個特殊值，用來表示無法表示或未定義的數值結果。`isNaN()` 函式屬性用來判斷一個值是否為 `NaN`。`Number.isNaN()` 提供了一種更可靠的方式來檢查 `NaN` 值，特別是在型別轉換可能導致全域 `isNaN()` 函式出現非預期結果的情況下。

- **`parseFloat()` 方法**：這個方法會解析字串引數並傳回一個浮點數。它設計用來從字串開頭擷取數字，即使字串後面有非數字字元也沒關係。
- **`parseInt()` 方法**：這個方法會解析字串引數並傳回一個整數。`parseInt()` 在遇到第一個非數字時就會停止解析。對於浮點數，它只會傳回整數部分。如果在字串開頭找不到有效的整數，則會傳回 `NaN`。
- **`toFixed()` 方法**：這個方法是針對數字呼叫的，並接受一個選用的引數，指定小數點後要顯示幾位數。它會傳回指定小數位數的字串表示。

## 比較運算與 `null` 和 `undefined` 資料型別

- **比較運算與 `undefined`**：當變數已宣告但尚未指定值時，就是 `undefined`。這是未初始化變數和未傳入引數的函式參數的預設值。`undefined` 在數值運算時會轉換為 `NaN`，因此所有與 `undefined` 的數值比較都會傳回 `false`。

- **比較與 `null`**：`null` 型別代表有意的值缺失。在數值上下文中，`null` 會轉換為 `0`，這可能導致數值比較時出現意外行為。例如，`null >= 0` 是 `true`，但 `null > 0` 是 `false`。

- 使用等號運算子（`==`）時，`null` 和 `undefined` 只會彼此相等，也只等於它們自己。

- 但是，使用嚴格等號運算子（`===`）時，該運算子在比較時不會進行型別轉換，會同時檢查值和型別，`null` 和 `undefined` 不相等。

## `switch` 陳述式

- **定義**：`switch` 述語會評估一個表達式，並將其值與一系列的 `case` 語句比對。當找到匹配時，會執行該 case 相關的程式碼區塊。每個 case 的結尾應放置一個 `break` 述語，以終止其執行並繼續執行下一個。`default` case 是一個選用的 case，只有在其他 case 都不匹配時才會執行。`default` case 放置於 `switch` 述語的結尾。

:::interactive_editor

```js
const dayOfWeek = 3; 

switch (dayOfWeek) {
  case 1:
    console.log("It's Monday! Time to start the week strong.");
    break;
  case 2:
    console.log("It's Tuesday! Keep the momentum going.");
    break;
  case 3:
    console.log("It's Wednesday! We're halfway there.");
    break;
  case 4:
    console.log("It's Thursday! Almost the weekend.");
    break;
  case 5:
    console.log("It's Friday! The weekend is near.");
    break;
  case 6:
    console.log("It's Saturday! Enjoy your weekend.");
    break;
  case 7:
    console.log("It's Sunday! Rest and recharge.");
    break;
  default:
    console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

:::

## JavaScript 函式

- 函式（程式）是可重複使用的程式碼區塊，用來執行特定任務。
- 函式（程式）可以使用 `function` 關鍵字定義，後接名稱、一個參數列表，以及執行任務的程式碼區塊。

:::interactive_editor

```js
function addNumbers(x, y, z) {
  return x + y + z;
}

console.log(addNumbers(5, 3, 8)); // Output: 16
```

:::

- 引數是在呼叫函式時傳遞給該函式的值。
- 函式（程式）呼叫是在程式中透過指定函式名稱，後接小括弧，並可選擇性地在小括弧內包含引數，來執行函式（程式）的處理程序。
- 當一個函式（程式）完成執行時，它將始終傳回一個值。
- 預設情況下，函式（程式）的返回值是 `undefined`。
- `return` 關鍵字用於指定從函式中傳回的值，並結束函式執行。
- 預設值參數允許函式（程式）擁有預先定義的值，當呼叫函式時若未提供引數，將使用這些值。這使函式（程式）更具彈性，並防止在某些引數可能被省略的情況下發生錯誤。

:::interactive_editor

```js
const calculateTotal = (amount, taxRate = 0.05) => {
  return amount + (amount * taxRate);
};

console.log(calculateTotal(100)); // Output: 105
```

:::

- 匿名函式是沒有名稱的函式，可以指定給變數。透過將它們指定給變數，你可以在變數可存取的任何地方重複使用它們。

:::interactive_editor

```js
const multiplyNumbers = function(firstNumber, secondNumber) {
  return firstNumber * secondNumber;
};

console.log(multiplyNumbers(4, 5)); // Output: 20
```

:::

## 箭頭函式

- 箭頭函式是在 JavaScript 中撰寫函式（程式）的更簡潔方式。

- 在定義箭頭函式時，你不需要 `function` 關鍵字。
- 如果你使用單一參數，可以省略參數列周圍的小括弧。

- 如果函式（程式）主體只包含單一個表達式、運算式，你可以省略大括號和 `return` 關鍵字。

:::interactive_editor

```js
const square = number => number * number;

console.log(square(5)); // Output: 25
```

:::

## 程式設計中的範圍

- **全域範圍**：這是 JavaScript 中最外層的範圍。在全域範圍宣告的變數可以在程式碼的任何地方存取，稱為全域變數。
- **區域範圍**：指的是在函式內宣告的變數。這些變數只能在宣告它們的函式內部存取，稱為區域變數。
- **區塊範圍**：區塊是由大括號 `{}` 包住的一組陳述式，例如在 `if` 陳述式或迴圈中。
- 使用 `let` 和 `const` 進行區塊範圍宣告，可以更細緻地控制變數的可存取性，有助於避免錯誤並讓你的程式碼更可預測。

## JavaScript 陣列基礎

- **定義**：JavaScript 陣列是一種有序的值群集，每個值都由數字索引標識。陣列中的值可以是不同的資料型別，包括數字、字串、布林值、物件，甚至其他陣列。陣列在記憶體中是連續儲存的，這表示所有元素都存放在一個連續的記憶體區塊中，因此可以高效地透過索引存取元素。

- **從陣列存取元素**：要從陣列存取元素，你需要參考陣列名稱，後面接方括號內的索引號碼。JavaScript 陣列是從零開始編號的，也就是說第一個元素的索引是 0，第二個是 1，以此類推。如果你嘗試存取不存在的索引，JavaScript 會傳回 `undefined`。

- **`length` 屬性**：這個屬性用來傳回陣列中的項目數量。

- **更新陣列中的元素**：要更新陣列中的元素，可以使用指定運算子（`=`）將新值指定給特定索引的元素。

## 二維陣列

- **定義**：二維陣列本質上就是陣列中的陣列。它用來表示具有自然網格結構的資料，例如西洋棋盤、試算表或圖片中的像素。要存取二維陣列中的元素，你需要兩個索引：一個代表列，一個代表行。

## 陣列解構賦值

- **定義**：陣列解構賦值是 JavaScript 的一項功能，讓你可以從陣列中擷取值並更簡潔、易讀地指定給變數。它提供了一種方便的語法，將陣列元素拆解到不同的變數中。

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange"];

const [first, second, third] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(third); // "orange"
```

:::

- **剩餘語法**：這讓你可以將尚未解構的陣列剩餘元素收集到一個新的陣列中。

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange", "mango", "kiwi"];
const [first, second, ...rest] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(rest); // ["orange", "mango", "kiwi"]
```

:::

## 常見的陣列方法

- **`push()` 方法**：這個方法用來將元素新增到陣列的結尾，並傳回新的長度。

- **`pop()` 方法**：這個方法用來移除陣列的最後一個元素，並傳回被移除的元素。如果陣列為空，則傳回值為 `undefined`。

- **`shift()` 方法**：這個方法用來移除陣列的第一個元素，並傳回被移除的元素。如果陣列為空，則傳回值為 `undefined`。

- **`unshift()` 方法**：這個方法用來將元素新增到陣列的開頭，並傳回新的長度。

- **`indexOf()` 方法**：這個方法用來尋找特定元素在陣列中第一次出現的索引。如果找不到該元素，則傳回 `-1`。

- **`splice()` 方法**：這個方法用來在陣列的任意位置新增或移除元素。`splice()` 方法的傳回值會是一個包含被移除項目的陣列。如果沒有移除任何元素，則會傳回空陣列。這個方法會改變原始陣列，直接在原地修改，而不是建立新陣列。第一個引數指定開始修改陣列的索引，第二個引數是你想移除的元素數量，後續的引數則是你想新增的元素。

- **`includes()` 方法**：這個方法用來檢查陣列是否包含特定值。如果陣列包含指定元素，則傳回 `true`，否則傳回 `false`。

- **`concat()` 方法**：這個方法會合併兩個或多個陣列，產生一個新陣列。

- **`slice()` 方法**：此方法傳回一個新的陣列，該陣列包含原始陣列中由起始和結束索引指定的部分淺層複製。新陣列包含對與原始陣列相同元素的參考（而非複製品）。這表示如果元素是原始型別（例如數字或字串），則值會被複製；但如果元素是物件或陣列，則會複製參考，而非物件本身。

- **展開語法（Spread Syntax）**：展開語法用來建立陣列的淺層複製。

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const shallowCopiedArray = [...originalArray];

shallowCopiedArray.push(4);

console.log(originalArray); // [1, 2, 3]
console.log(shallowCopiedArray); // [1, 2, 3, 4]
```

:::

- **`split()` 方法**：這個方法會將字串依據指定的分隔符拆分成子字串陣列。如果沒有提供分隔符，則方法會傳回一個只包含原始字串的陣列。

- **`reverse()` 方法**：這個方法會將陣列內容原地反轉。

- **`join()` 方法**：這個方法會將陣列所有元素串接成一個字串，每個元素之間用指定的分隔符分隔。如果沒有提供分隔符，或使用空字串（`""`），則元素會直接串接在一起，不加任何分隔符。

## 物件基礎

- **定義**：物件是一種由屬性組成的資料結構。屬性由鍵和值組成。要從物件存取資料，可以使用點記法或中括號記法。

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  city: "New York"
};

console.log(person.name);  // Alice
console.log(person["name"]); // Alice
```

:::

要設定現有物件的屬性，可以搭配指定運算子，使用點記法或中括號記法。

## 從物件移除屬性

- **`delete` 運算子**：這個運算子用來從物件中移除屬性。

## 檢查物件是否有某個屬性

- **`hasOwnProperty()` 方法**：這個方法會傳回一個布林值，表示物件是否擁有指定的自有屬性。

- **`Object.hasOwn()` 方法**：這是現代且推薦的方式，用來檢查物件是否擁有某個屬性（非繼承而來）。語法為 `Object.hasOwn(object, propertyName)`。如果該屬性存在於物件上，則傳回 `true`，不存在則傳回 `false`，不論該屬性的值為何。這使得它比 `hasOwnProperty()` 更安全，也比在值可能是 `0`、`false`、`null` 或 `undefined` 時使用 `if (obj.prop)` 更可靠。

`Object.hasOwn()` 即使在屬性值為假值（如 `0`、`false` 或 `undefined`）時，也能偵測到該屬性是物件自身的屬性。

- **`in` 運算子**：這個運算子如果屬性存在於物件中，會傳回 `true`。

## 存取巢狀物件的屬性

- **存取資料**：存取巢狀物件的屬性時，和存取一般物件屬性一樣，可以用點記法或中括號記法。不過，你需要串接這些存取方式，才能深入巢狀結構。

## 原生與非原生資料型別

- **原生資料型別**：這些型別包含數字、字串、布林值、`null`、`undefined` 和符號。這些型別稱為「原生」，因為它們只代表單一值，且不是物件。原生值是不可變的，也就是說一旦建立，其值就不能更改。
- **非原生資料型別**：在 JavaScript 中，這些是物件，包括一般物件、陣列和函式。與原生型別不同，非原生型別可以以屬性或元素的形式儲存多個值。

## 物件方法

- **定義**：物件方法是與物件相關聯的函式。它們被定義為物件的屬性，並且可以存取和操作物件的資料。在方法內部使用 `this` 關鍵字時，會指向該物件本身，讓你可以存取它的屬性。

## 物件建構式

- **定義**：在 JavaScript 中，建構式是一種特殊的函式，用來建立並初始化物件。它必須搭配 `new` 關鍵字呼叫，並可在新建立的物件上初始化屬性和方法。`Object()` 建構式會建立一個新的空物件。

## 使用選用串鏈運算子（`?.`）

- **定義**：這個運算子讓你可以安全地存取物件屬性或呼叫方法，而不用擔心它們是否存在。

:::interactive_editor

```ts
const user = {
  name: "John",
  profile: {
    email: "john@example.com",
    address: {
      street: "123 Main St",
      city: "Somewhere"
    }
  }
};

console.log(user.profile?.address?.street); // "123 Main St"
console.log(user.profile?.phone?.number);   // undefined
```

:::

## 物件解構賦值

- **定義**：物件解構賦值讓你可以從物件中擷取值，並更簡潔、易讀地指定給變數。

:::interactive_editor

```js
const person = { name: "Alice", age: 30, city: "New York" };

const { name, age } = person;

console.log(name); // Alice
console.log(age);  // 30
```

:::

## 使用 JSON

- **定義**：JSON 代表 JavaScript 物件標記法。它是一種輕量級、以文字為基礎的資料格式，常用於伺服器與網頁應用程式之間的資料交換。

- **`JSON.stringify()`**：這個方法用來將 JavaScript 物件轉換成 JSON 字串。當你想要以容易分享或傳輸的格式儲存或傳送資料時，這會很有用。

- **`JSON.parse()`**：這個方法會將 JSON 字串轉換回 JavaScript 物件。當你從網頁伺服器或 localStorage 取得 JSON 資料，並需要在應用程式中操作這些資料時，這會很有用。

## 使用迴圈

- **`for` 迴圈**：這種迴圈用來重複執行某段程式碼指定次數。這個迴圈分為三個部分：初始化陳述式、條件判斷和遞增／遞減陳述式。初始化陳述式在迴圈開始前執行，通常用來初始化計數變數。條件判斷在每次迴圈執行前評估。每執行一次迴圈稱為一次「迭代」。如果條件為 `true`，則執行迴圈內的程式碼區塊；如果條件為 `false`，則結束迴圈，繼續執行下一段程式碼。遞增／遞減陳述式在每次迭代後執行，通常用來增加或減少計數變數。

:::interactive_editor

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

:::

- **`for...of` 迴圈**：這種迴圈適合用來遍歷可迭代物件的值。可迭代物件的例子有陣列和字串。

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];

for (const num of numbers) {
  console.log(num);
}
```

:::

- **`for...in` 迴圈**：這種迴圈最適合用來遍歷物件的屬性。它會遍歷物件所有可列舉的屬性，包括繼承的屬性和非數字屬性。

:::interactive_editor

```js
const fruit = {
  name: 'apple',
  color: 'red',
  price: 0.99
};

for (const prop in fruit) {
  console.log(fruit[prop]);
}
```

:::

- **`while` 迴圈**：這種迴圈只要條件為 `true`，就會持續執行程式碼區塊。

:::interactive_editor

```js
let i = 5;

while (i > 0) {
  console.log(i);
  i--;
}
```

:::

- **`do...while` 迴圈**：這種迴圈會在檢查條件之前，至少執行一次程式碼區塊。

```js
let userInput;

do {
  userInput = prompt("Please enter a number between 1 and 10");
} while (Number(userInput) < 1 || Number(userInput) > 10);

alert("You entered a valid number!");
```

## `break` 和 `continue` 陳述式

- **定義**：`break` 陳述式用來提前離開迴圈，而 `continue` 陳述式則用來跳過本次迭代，直接進入下一次。

## 字串建構式與 `toString()` 方法

- **定義**：字串物件用來表示一連串字元。字串物件是使用 `String` 建構式函式建立的，這會將原生值包裝成物件。

- **`toString()` 方法**：這個方法會將值轉換為字串表示。你可以用它來處理數字、布林值、陣列和物件。

這個方法可以接受一個選用的進位基數（radix），範圍是 2 到 36。這個基數代表進位制，例如 2 代表二進位，8 代表八進位。如果沒有指定基數，預設是 10，也就是十進位。

## 數字建構式

- **定義**：`Number` 建構式用來建立數字物件。數字物件包含一些有用的屬性和方法，例如 `isNaN` 和 `toFixed` 方法。大多數情況下，你會用 `Number` 建構式將其他資料型別轉換為數字型別。

## 命名變數與函式的最佳實踐

- **駝峰式命名（camelCasing）**：依照慣例，JavaScript 開發者會使用駝峰式命名法來命名變數和函式。駝峰式命名法是指第一個單字全部小寫，後面的單字首字母大寫。例如：`isLoading`。

- **命名布林值**：對於布林變數，常見做法是加上「is」、「has」或「can」等前綴。

- **命名函式**：函式名稱應該清楚表達函式的用途。對於傳回布林值的函式（通常稱為判斷式），你可以使用「is」、「has」或「can」等前綴。當你有用來取得資料的函式時，通常會以「get」開頭；用來設定資料的函式則以「set」開頭。事件處理函式則可以用「handle」作為前綴，或以「Handler」作為後綴。

- **在迴圈中命名變數**：在迴圈中命名迭代變數時，常見做法是使用單一字母，例如 `i`、`j` 或 `k`。

## 使用稀疏陣列

- **定義**：陣列中可以有空槽。空槽指的是沒有任何內容的槽，這和槽內的值為 `undefined` 不同。這類陣列稱為稀疏陣列。

## 程式碼檢查工具與格式化工具

- **Linter（程式碼檢查工具）**：Linter 是一種靜態程式碼分析工具，用來標記程式錯誤、臭蟲、風格錯誤和可疑結構。常見的 linter 工具有 ESLint。
- **Formatter（格式化工具）**：Formatter 是自動將你的程式碼格式化成特定風格指南的工具。常見的 formatter 工具有 Prettier。

## 記憶體管理

- **定義**：記憶體管理是指控制記憶體的過程，包括在需要時分配記憶體，以及在不再需要時釋放記憶體。JavaScript 採用自動記憶體管理，這表示 JavaScript（更精確來說，是你瀏覽器中的 JavaScript 引擎）會自動幫你處理記憶體的分配與釋放。你不需要在程式碼中明確釋放記憶體。這個自動過程通常稱為「垃圾回收」（garbage collection）。

## 閉包

- **定義**：閉包是一種函式，即使外部（包覆）函式已經傳回，仍然可以存取其外部語彙範圍中的變數。

:::interactive_editor

```js
function outerFunction(x) {
  let y = 10;
  function innerFunction() {
    console.log(x + y);
  }
  return innerFunction;
}

let closure = outerFunction(5);
closure(); // 15
```

:::

## `var` 關鍵字與提升（Hoisting）

- **定義**：`var` 是 2015 年以前宣告變數的原始方式。但 `var` 在範圍、重複宣告等方面有一些問題。因此現代 JavaScript 程式設計都改用 `let` 和 `const`。
- **用 `var` 重複宣告變數**：如果你嘗試用 `let` 重複宣告變數，會出現 `SyntaxError`。但用 `var` 則允許重複宣告變數。

- **`var` 與範圍**：用 `var` 在區塊（例如 `if` 陳述式或 `for` 迴圈）內宣告的變數，仍然可以在該區塊外部存取。

- **提升（Hoisting）**：這是 JavaScript 的預設行為，在執行程式碼前的編譯階段，會將宣告提升到各自範圍的最上方。當你用 `var` 關鍵字宣告變數時，JavaScript 會將宣告提升到其範圍頂端。

當你用函式宣告語法宣告函式時，函式名稱和函式主體都會被提升。這表示你可以在程式碼中宣告前就呼叫該函式。

用 `let` 或 `const` 宣告的變數也會被提升，但不會被初始化，而且在程式碼中實際宣告前無法存取。這種行為通常稱為「暫時性死區」（temporal dead zone）。

## 使用匯入、匯出和模組

- **模組**：這是一個自我封裝的程式碼單元，用來封裝相關的函式、類別或變數。要建立一個模組，你需要將 JavaScript 程式碼寫在一個獨立的檔案中。
- **匯出**：任何你想讓應用程式其他部分可以取用的變數、函式或類別，都需要用 `export` 關鍵字明確匯出。匯出有兩種型態：具名匯出和預設匯出。
- **匯入**：要在應用程式的其他部分使用已匯出的項目，你需要用 `import` 關鍵字來匯入。匯入的型態有具名匯入、預設匯入和命名空間匯入。

```js
// Within a file called math.js, we export the following functions:

// Named export
export function add(num1, num2) {
  return num1 + num2;
}

// Default export
export default function subtract(num1, num2) {
  return num1 - num2;
}

// Within another file, we can import the functions from math.js.

// Named import - This line imports the add function.
// The name of the function must exactly match the one exported from math.js.
import { add } from './math.js';

// Default import - This line imports the subtract function.
// The name of the function can be anything.
import subtractFunc from './math.js';

// Namespace import - This line imports everything from the file.
import * as Math from './math.js';

console.log(add(5, 3)); // 8
console.log(subtractFunc(5, 3)); // 2
console.log(Math.add(5, 3)); // 8
console.log(Math.subtract(5, 3)); // 2
```

## 回呼函式與 `forEach` 方法

- **定義**：在 JavaScript 中，回呼函式是一個作為引數傳遞給另一個函式，並在主要函式執行完畢後被執行的函式。
- **`forEach()` 方法**：這個方法用來對陣列中的每個元素進行迭代，並對每個元素執行一個操作。`forEach` 中的回呼函式最多可以接受三個引數：目前的元素、目前元素的索引，以及呼叫 `forEach` 的那個陣列。

## 高階函式

- **定義**：高階函式會將一個或多個函式作為引數，並傳回一個函式或值作為結果。

- **`map()` 方法**：這個方法用來對原始陣列的每個元素套用指定函式，並產生一個新的陣列。回呼函式最多可以接受三個引數：目前的元素、目前元素的索引，以及呼叫 `map` 的那個陣列。

- **`filter()` 方法**：這個方法用來建立一個新陣列，內容為通過指定測試的元素，非常適合根據條件篩選出特定項目。就像 `map` 方法一樣，`filter` 方法的回呼函式也接受三個引數：目前處理的元素、索引，以及陣列本身。

- **`reduce()` 方法**：這個方法用來處理一個陣列並將其濃縮成單一值。這個值可以是數字、字串、物件，甚至是另一個陣列。`reduce()` 方法會依序對陣列中的每個元素套用一個函式，並將每次計算的結果傳遞給下一次。這個函式通常稱為 reducer 函式。reducer 函式有兩個主要參數：累加器（accumulator）和目前值。累加器用來儲存運算的累積結果，而目前值則是正在處理的陣列元素。

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce(
  (accumulator, currentValue) => accumulator + currentValue,
  0
);

console.log(sum); // 15
```

:::

## 方法串鏈

- **定義**：方法串鏈是一種程式設計技巧，讓你可以在同一個物件上連續呼叫多個方法，並寫在同一行程式碼中。這種技巧能讓你的程式碼更易讀且精簡，特別是在對同一個物件進行一連串操作時。

## 使用 `sort` 方法

- **定義**：`sort` 方法用來對陣列元素進行排序，並傳回排序後的陣列參考。這個方法是就地排序，不會產生新的複本。

如果你需要排序數字，則必須傳入比較函式。`sort` 方法會將元素轉換成字串，然後比較它們的 UTF-16 編碼序列。UTF-16 編碼是用來表示字串中字元的數值。UTF-16 編碼的例子有數字 65、66 和 67，分別代表字元「A」、「B」和「C」。因此，在陣列中數字 200 會出現在數字 3 之前，因為字串「200」在比較 UTF-16 編碼時會排在字串「3」之前。

:::interactive_editor

```js
const numbers = [414, 200, 5, 10, 3];

numbers.sort((a, b) => a - b);

console.log(numbers); // [3, 5, 10, 200, 414]
```

:::

`a` 和 `b` 這兩個參數是被比較的兩個元素。比較函式如果傳回負值，代表 `a` 應排在 `b` 前面；如果傳回正值，代表 `a` 應排在 `b` 後面；如果傳回零，則代表 `a` 和 `b` 相等。

## 使用 `every` 和 `some` 方法

- **`every()` 方法**：這個方法用來測試陣列中的所有元素是否都通過由指定函式實作的測試。`every()` 方法會在所有元素都傳回 `true` 時傳回 `true`。只要有一個元素未通過測試，這個方法就會立即傳回 `false`，並停止檢查剩下的元素。

- **`some()` 方法**：這個方法用來檢查是否至少有一個元素通過測試。`some()` 方法只要找到一個通過測試的元素就會立即傳回 `true`。如果沒有任何元素通過測試，則傳回 `false`。

## 操作 DOM 和 Web API

- **API**：API（應用程式介面）是一組規則和協定，讓軟體應用程式之間能夠彼此溝通並高效交換資料。
- **Web API**：Web API 是專為網頁應用程式設計的 API。這類 API 通常分為兩大類：瀏覽器 API 和第三方 API。
- **瀏覽器 API**：這些 API 會公開瀏覽器中的資料。身為網頁開發者，你可以用 JavaScript 存取並操作這些資料。
- **第三方 API**：這些 API 並非預設內建於瀏覽器。你必須以某種方式取得它們的程式碼。通常這些 API 都會有詳細的文件說明如何使用其服務。例如 Google Maps API，你可以用它在網站上顯示互動地圖。
- **DOM**：DOM 代表文件物件模型（Document Object Model）。它是一個讓你與 HTML 文件互動的程式設計介面。透過 DOM，你可以新增、修改或刪除網頁上的元素。DOM 樹的根節點是 `html` 元素。它是 HTML 文件所有內容的最上層容器。所有其他節點都是這個根節點的子孫。接著，在根節點下方，我們會看到階層中的其他節點。父節點是包含其他元素的元素；子節點則是被包含在其他元素內的元素。
- **`navigator` 介面**：這個介面提供有關瀏覽器環境的資訊，例如使用者代理字串、平台和瀏覽器版本。使用者代理字串是一段用來識別瀏覽器和作業系統的文字。
- **`window` 介面**：這個介面代表包含 DOM 文件的瀏覽器視窗。它提供與瀏覽器視窗互動的方法和屬性，例如調整視窗大小、開啟新視窗，以及導覽到不同的 URL。

## 使用 `querySelector()`、`querySelectorAll()` 和 `getElementById()` 方法

- **`getElementById()` 方法**：這個方法用來取得具有指定 `id` 的 HTML 元素物件。請記得，每個 HTML 文件中的 id 必須是唯一的，所以這個方法只會傳回一個 Element 物件。

- **`querySelector()` 方法**：這個方法用來取得 HTML 文件中第一個符合所傳入 CSS 選擇器的元素。

- **`querySelectorAll()` 方法**：你可以用這個方法取得所有符合特定 CSS 選擇器的 DOM 元素列表。

## 使用 `innerText()`、`innerHTML()`、`createElement()` 和 `textContent()` 方法

- **`innerHTML` 屬性**：這是 `Element` 的一個屬性，用來設定或更新 HTML 標記的部分內容。

- **`createElement` 方法**：這個方法用來建立一個 HTML 元素。

- **`innerText`**：這代表 HTML 元素及其所有子孫的可見文字內容。

- **`textContent`**：這會傳回元素內所有子孫的純文字內容。

## 使用 `appendChild()` 和 `removeChild()` 方法

- **`appendChild()` 方法**：這個方法用來將一個節點新增到指定父節點的子節點清單末端。

- **`removeChild()` 方法**：這個方法用來從 DOM 中移除一個節點。

## 使用 `setAttribute()` 方法

- **定義**：這個方法用來為指定元素設定屬性。如果該屬性已存在，則會更新其值；否則會新增一個具有指定值的新屬性。

## 事件物件

- **定義**：`Event` 物件是在使用者以某種方式與你的網頁互動時觸發的資料載體。這些互動可以是點擊按鈕、聚焦輸入框，甚至搖動行動裝置。所有 `Event` 物件都會有 `type` 屬性。這個屬性會顯示觸發該資料載體的事件型態，例如 keydown 或 click。這些值會對應到你在 `addEventListener()` 中可能傳入的值，讓你可以捕捉並運用 `Event` 物件。

## `addEventListener()` 和 `removeEventListener()` 方法

- **`addEventListener` 方法**：這個方法用來監聽事件。它接受兩個引數：你想監聽的事件，以及事件發生時要呼叫的函式。一些常見的事件範例包括 click 事件、input 事件和 change 事件。

:::interactive_editor

```html
<button id="btn">Click Me</button>
<script src="./index.js"></script>
```

```js
const btn = document.getElementById("btn");

btn.addEventListener("click", () => alert("You clicked the button"));
```

:::

- **`removeEventListener()` 方法**：這個方法用來移除先前用 `addEventListener()` 方法加到元素上的事件監聽器。當你想停止監聽某個元素上的特定事件時，這個方法就很有用。

- **行內事件處理常式**：行內事件處理常式是 HTML 元素上的特殊屬性，用來在事件發生時執行 JavaScript 程式碼。在現代 JavaScript 中，行內事件處理常式已不被視為最佳做法。建議改用 `addEventListener` 方法。

## Change 事件

- **定義**：change 事件是一種特殊事件，當使用者修改某些輸入元素的值時會被觸發。例如勾選核取方塊或單選按鈕，或是從日期選擇器或下拉選單中做出選擇時。

## 事件冒泡

- **定義**：事件冒泡，或稱傳播，指的是當事件被觸發時，該事件如何「冒泡」至父物件。
- **`stopPropagation()` 方法**：此方法可防止事件的進一步傳播。

## 事件委派

- **定義**：事件委派是指監聽已經冒泡到父層的事件，而不是直接在觸發事件的元素上處理。

## DOMContentLoaded

- **定義**：`DOMContentLoaded` 事件會在 HTML 文件的所有內容都載入並解析完成時觸發。如果有外部樣式表或圖片，`DOMContentLoaded` 事件不會等待它們載入完成，只會等 HTML 載入完成。

## 使用 `style` 和 `classList`

- **`Element.style` 屬性**：這個屬性是唯讀屬性，代表元素的行內樣式。你可以用這個屬性來取得或設定元素的樣式。

- **`Element.classList` 屬性**：這個屬性是唯讀屬性，可以用來新增、移除或切換元素上的類別。

## 使用 `setTimeout()` 和 `setInterval()` 方法

- **`setTimeout()` 方法**：這個方法讓你可以延遲執行某個動作一段指定的時間。

- **`setInterval()` 方法**：此方法會在設定的間隔內重複執行一段程式碼。由於 `setInterval()` 會持續在指定的間隔執行所提供的函式，你可能會想要停止它。為此，你必須使用 `clearInterval()` 方法。

## `requestAnimationFrame()` 方法

- **定義**：這個方法讓你可以在下一次螢幕重繪前排程動畫的下一步，帶來流暢且視覺效果佳的體驗。下一次螢幕重繪指的是瀏覽器重新整理網頁畫面的時刻。這個動作每秒會發生多次，通常在大多數顯示器上約為 60 次（即每秒 60 影格）。

## 網頁動畫 API

- **定義**：Web Animations API 讓你可以直接在 JavaScript 中建立和控制動畫。

## Canvas API

- **定義**：Canvas API 是一個強大的工具，讓你可以直接在 JavaScript 檔案中操作圖形。要使用 Canvas API，首先需要在 HTML 中提供一個 `canvas` 元素。這個元素就像一個繪圖表面，你可以用 Canvas API 介面的實體方法和屬性來操作它。這個 API 包含像 `HTMLCanvasElement`、`CanvasRenderingContext2D`、`CanvasGradient`、`CanvasPattern` 和 `TextMetrics` 這些介面，你可以用它們的方法和屬性在 JavaScript 檔案中建立圖形。

## 用 JavaScript 開啟與關閉對話框和模態視窗

- **模態與對話框定義**：對話框讓你可以向使用者顯示重要資訊或操作。利用 HTML 內建的 dialog 元素，你可以輕鬆在網頁應用程式中建立這些對話框（包含模態和非模態對話框）。模態對話框是一種強制使用者必須先與其互動，才能存取應用程式或網頁其他部分的對話框。相對地，非模態對話框則允許使用者即使對話框開啟時，仍可繼續與頁面或應用程式其他部分互動，不會阻止存取其他內容。
- **`showModal()` 方法**：這個方法用來開啟模態視窗。

- **`close()` 方法**：這個方法用來關閉模態視窗。

## 常見的 ARIA 無障礙屬性

- **`aria-expanded` 屬性**：用於向螢幕閱讀器使用者傳達切換（或揭露）特性的狀態。

- **`aria-haspopup` 屬性**：此狀態用於表示互動元素在啟動時會觸發彈出元素。你只能在彈出元素具有以下角色之一時使用 `aria-haspopup` 屬性：`menu`、`listbox`、`tree`、`grid` 或 `dialog`。`aria-haspopup` 的值必須是這些角色之一，或是 `true`（等同於 `menu`）。

- **`aria-checked` 屬性**：此屬性用於顯示元素是否處於已勾選狀態。它最常用於建立訂製的核取方塊、圓鈕、切換開關和列表框時。

- **`aria-disabled` 屬性**：此狀態用於僅向使用輔助技術（例如螢幕閱讀器）的人員顯示該元素已被停用。

- **`aria-selected` 屬性**：此狀態用於顯示元素已被選取。你可以在訂製控制元件，如分頁介面、列表框或格線中使用此狀態。

- **`aria-controls` 屬性**：用來將一個元素與它所控制的另一個元素關聯起來。這有助於使用輔助技術的人理解這些元素之間的關係。

- **`hidden` 屬性**：將非作用中的面板隱藏，對視覺及輔助技術使用者皆然。

## 使用 Live Regions 和動態內容

- **`aria-live` 屬性**：使網頁的一部分成為即時區域，表示該區域內的任何更新都會由螢幕閱讀器宣告，讓使用者不會錯過重要變更。
- **`polite` 值**：大多數即時區域使用此值。此值表示更新並非緊急，因此螢幕閱讀器可以等到完成任何當前的公告或使用者完成當前操作後，再宣布該更新。

這是一個由 JavaScript 動態更新的即時區域範例：

:::interactive_editor

```html
<div aria-live="polite" id="status"></div>

<button id="updateStatus">Update Status</button>

<script>
  const statusEl = document.getElementById("status");
  const btn = document.getElementById("updateStatus");

  btn.addEventListener("click", () => {
    statusEl.textContent = "Your file has been successfully uploaded.";
  });
</script>
```

:::

- **`contenteditable` 屬性**：將元素變成即時編輯器，允許使用者像編輯文字欄位一樣更新其內容。當 contenteditable 區域沒有可見的標籤或標題時，請使用 `aria-label` 屬性為其添加可存取名稱，以協助螢幕閱讀器使用者了解可編輯區域的用途。

## `focus` 和 `blur` 事件

- **`blur` 事件**：當元素失去焦點時觸發。

- **`focus` 事件**：當元素獲得焦點時觸發。

## 常見錯誤訊息類型

- **SyntaxError**：當你在程式碼中寫錯東西時（例如漏掉括號或中括號）就會發生這種錯誤。可以把它想像成句子裡的文法錯誤。

- **ReferenceError**：ReferenceError 有多種型態，會因不同情況而觸發。第一種是變數未定義。另一個例子是嘗試在用 `let` 或 `const` 宣告變數之前存取該變數時，也會發生 ReferenceError。

- **TypeError**：當你嘗試對錯誤型別的資料進行操作時，就會發生這種錯誤。

- **RangeError**：當你的程式碼嘗試使用超出 JavaScript 可處理範圍的值時，就會發生這種錯誤。

## `throw` 述語

- **定義**：JavaScript 中的 `throw` 述語用於丟出使用者定義的例外。程式設計中的例外，是指當發生意外事件並中斷程式的正常流程時。

## `try...catch...finally`

- **定義**：`try` 區塊用來包住可能會丟出錯誤的程式碼。它就像一個安全區塊，可以嘗試執行可能失敗的操作。`catch` 區塊會捕捉並處理 try 區塊中發生的錯誤。你可以在 catch 中使用錯誤物件來檢查發生了什麼問題。`finally` 區塊則會在 try 和 catch 區塊之後執行，不論是否發生錯誤。這通常用於清理工作，例如關閉檔案或釋放資源。

:::interactive_editor

```js
function processInput(input) {
  if (typeof input !== "string") {
    throw new TypeError("Input must be a string.");
  }

  return input.toUpperCase();
}

try {
  console.log("Starting to process input...");
  const result1 = processInput("hello");
  console.log("Processed result:", result1);  // HELLO
  const result2 = processInput(9);  // throws TypeError
  console.log("Processed result:", result2);  // not executed
} catch (error) {
  console.error("Error occurred:", error.message);
} 
```

:::

## 偵錯技巧

- **`debugger` 述語**：這個述語讓你可以在程式的特定行暫停執行，以便調查程式的狀態。

- **中斷點**：中斷點讓你可以在指定的程式碼行暫停執行。暫停後，你可以檢查變數、評估表達式，並檢視呼叫堆疊。
- **監看**：監看表達式讓你在程式執行時，即使變數或表達式不在目前作用域內，也能持續監控它們的值。
- **效能分析**：效能分析有助於你找出效能瓶頸，方法是擷取螢幕截圖、記錄 CPU 使用率、函式呼叫和執行時間。
- **`console.dir()`**：這個方法用來顯示指定 JavaScript 物件的互動式屬性列表。它會以階層式清單輸出，可以展開以檢視所有巢狀屬性。

- **`console.table()`**：這個方法會將表格資料以表格形式顯示在主控台。它至少需要一個引數，必須是陣列或物件，還可以有一個選用引數來指定要顯示哪些屬性（行）。

## 正規表示式與常用方法

- **定義**：正規表示式（Regular Expressions，簡稱 Regex）用來建立一個「樣式」，你可以用這個樣式來檢查字串、擷取文字等。

- **`RegExp` 建構式**：當你的樣式或旗標來自變數時，你可以使用 `RegExp` 建構式建立相同類型的正規表達式。它接受一個樣式字串和一個選用的旗標字串。

例如，`new RegExp(pattern, flags)` 從這些字串建立一個正規表達式。

- **`test()` 方法**：這個方法接受一個字串，這個字串就是要用正規表示式測試是否符合的內容。這個方法會傳回一個布林值，表示該字串是否符合正規表示式。

- **`match()` 方法**：這個方法接受一個正規表示式，你也可以傳入一個字串，該字串會被轉換成正規表示式。`match` 方法會傳回該字串的符合項目陣列。

- **`replace()` 方法**：這個方法接受兩個引數：要比對的正規表示式（或字串），以及要用來取代符合項目的字串（或針對每個符合項目執行的函式）。

- **`replaceAll` 方法**：這個方法用來將指定樣式的所有出現位置都取代成新的字串。如果你給它一個沒有全域修飾詞的正規表示式，這個方法會丟出錯誤。

- **`matchAll` 方法**：這個方法用來擷取字串中所有符合指定正規表示式的項目（包含擷取群組），並以迭代器的形式傳回。迭代器是一種可以讓你逐一走訪（或「迭代」）一個項目群集的物件。

## 正規表示式修飾詞

- **定義**：修飾詞（Modifiers），又稱為「旗標」，用來改變正規表示式的行為。
- **`i` 旗標**：這個旗標讓正規表示式忽略大小寫。

- **`g` 旗標**：這個旗標，也就是全域修飾詞，讓你的正規表示式可以多次比對樣式。

- **錨點定義**：`^` 錨點放在正規表示式的開頭，表示「比對字串的開頭」；`$` 錨點放在正規表示式的結尾，表示「比對字串的結尾」。

- **`m` 旗標**：錨點會尋找整個字串的開頭和結尾。但你可以用 `m` 旗標（多行修飾詞）讓正規表示式處理多行內容。

- **`d` 標誌**：此標誌會將匹配和捕獲群組的起始與結束索引加入匹配物件中。

- **`u` Flag**：這個旗標擴展了正規表達式的功能，讓它能匹配特殊的 unicode 字元。`u` 旗標讓你可以使用像 `Extended_Pictographic` 這樣的特殊類別，以匹配大部分的表情符號。還有一個 `v` 旗標，進一步擴展了 unicode 匹配的功能。
- **`y` Flag**：sticky 修飾詞的行為與 global 修飾詞非常相似，但有一些例外。最大差異是 global 正規表達式會從 lastIndex 開始，搜尋字串剩餘部分的所有匹配；而 sticky 正規表達式如果在先前的 lastIndex 位置沒有立即匹配，會傳回 null 並將 lastIndex 重設為 0。
- **`s` Flag**：single-line 修飾詞允許正規表達式中的萬用字元（用 `.` 表示）匹配換行字元——實際上將字串視為單行文字。

## 字元類別

- **萬用字元 `.`**：字元類別是一種特殊語法，可以用來比對一組或子集的字元。你應該先學會的第一個字元類別是萬用字元類別。萬用字元用一個句點（dot）表示，可以比對任何單一字元，除了換行字元。如果你想讓萬用字元類別也能比對換行字元，記得要加上 `s` 旗標。

- **`\d`**：這會比對字串中的所有數字（`0-9`）。

- **`\w`**：用來匹配字串中的任何字元字元（`a-zA-Z0-9_`）。字元字元定義為任何字母（a 到 z 或 A 到 Z）、數字（0 到 9）或底線字元。

- **`\s`**：空白字元類別 `\s` 是由反斜線後接 `s` 表示。此字元類別會匹配任何空白字元，包括換行、空格、製表符和特殊的 Unicode 空白字元。
- **否定特殊字元類別**：要否定這些字元類別之一，不使用反斜線後的小寫字母，而是使用大寫字母。例如，`\D` 匹配任何非數字字元。

- **自訂字元類別**：你可以將想匹配的字元放在一組方括號內，來建立自訂的字元類別。

例如，`/[abcdf]/` 匹配括號內的任一字元。

## 前瞻與後顧斷言

- **定義**：前瞻（lookahead）和後顧（lookbehind）斷言讓你可以根據前後是否有特定樣式來比對某個樣式。
- **正向前瞻斷言**：這種斷言會在某個樣式後面還有另一個樣式時才比對。要建立正向前瞻，先寫你想比對的樣式，然後用小括號包住你想當作條件的樣式。在開括號後面加上 `?=`，就能定義這個條件為正向前瞻。

例如，`/free(?=code)/i` 會匹配後面接著 `code` 的 `free`。

- **負向前瞻斷言**：這是一種在正規表示式中用來檢查某個樣式後面沒有出現特定樣式的條件。

例如，`/free(?!code)/i` 會匹配當後面沒有接 `code` 的 `free`。

- **正向後顧斷言**：這種斷言只會在某個樣式前面有另一個特定樣式時才比對，而且不會把前面的樣式包含在比對結果裡。

例如，`/(?<=free)code/i` 會匹配前面是 `free` 的 `code`。

- **負向後顧斷言**：這種斷言確保某個樣式前面沒有另一個特定樣式。只有在指定樣式前面沒有出現給定序列時才會比對，而且不會把前面的序列包含在比對結果裡。

例如，`/(?<!free)code/i` 會匹配當前面沒有 `free` 時的 `code`。

## 正規表示式量詞

- **定義**：正規表達式中的量詞用來指定一個樣式（或樣式的一部分）應該出現多少次。它們幫助控制字元或群組在匹配中出現的次數。

例如，`/^\d{4}$/` 匹配恰好包含四個數字的字串。

- **`*`** ：比對前一個元素出現 0 次或多次。
- **`+`**：比對前一個元素出現 1 次或多次。
- **`?`**：比對前一個元素出現 0 次或 1 次。
- **`{n}`**：比對前一個元素恰好出現 n 次。
- **`{n,}`**：比對前一個元素出現 n 次或更多次。
- **`{n,m}`**：比對前一個元素出現 n 到 m 次。

## 擷取群組與反向參照

- **擷取群組**：擷取群組讓你可以「擷取」比對到的字串片段，方便你後續使用。擷取群組用小括號包住要擷取的樣式，前面不用加像前瞻那樣的特殊字元。

例如，`/free(code)camp/i` 會捕獲 `code`。

- **非捕獲群組**：非捕獲群組類似於捕獲群組，但不會儲存字串中符合的部分以供後續使用。非捕獲群組由 `(?:...)` 定義。

例如，`/free(?:code)camp/i` 將 `code` 群組起來但不捕獲它。

- **反向參照**：正規表示式中的反向參照是一種重複利用先前比對到的樣式的方法。它讓你可以用數字來指向某個擷取群組（也就是用括號包住的樣式）。例如，`$1` 代表第一個擷取群組。

:::interactive_editor

```js
const regex = /free(co+de)camp/i;
console.log("freecoooooooodecamp".replace(regex, "paid$1world"));
```

:::

- 你可以在正規表示式本身內使用反向引用，以反斜線和捕獲群組編號來匹配先前群組所捕獲的相同文字。例如：

:::interactive_editor

```js
const regex = /(hello) \1/i;
console.log(regex.test("hello hello")); // true
console.log(regex.test("hello world")); // false
```

:::

## 用 JavaScript 驗證表單

- **條件驗證 API**：某些 HTML 元素（像是 `textarea` 和 `input` 元素）會提供條件驗證 API。這個 API 讓你可以確認使用者在該元素輸入的值是否通過你寫的 HTML 層級驗證（例如最小長度或樣式比對）。
- **`checkValidity()` 方法**：這個方法會在元素通過所有 HTML 驗證（根據其屬性）時傳回 `true`，驗證失敗時傳回 `false`。

- **`reportValidity()` 方法**：這個方法會告訴瀏覽器 `input` 是無效的。

- **`validity` 屬性**：此屬性用來取得表單控制元件（如 `<input>`、`<select>` 等）的有效性狀態，並提供有關使用者輸入是否符合該元素所定義條件（例如 `required` 欄位、樣式條件、最大長度等）的資訊。

- **`patternMismatch` 屬性**：如果值不符合指定的正規表示式樣式，這個屬性會是 `true`。

## `preventDefault()` 方法

- **定義**：DOM 中每個觸發的事件都有某種預設行為。預設情況下，點擊核取方塊會切換該核取方塊的狀態。當焦點在按鈕上時，按下 <kbd>空白鍵</kbd> 會啟動該按鈕。這些 `Event` 物件上的 `preventDefault()` 方法會阻止這些預設行為發生。

## 提交表單

- **定義**：表單有三種提交方式。第一種是使用者點擊表單中 `type` 屬性設為 `submit` 的按鈕。第二種是使用者在表單中任何可編輯的 `input` 欄位按下 <kbd>Enter</kbd> 鍵。第三種是透過 JavaScript 呼叫 `form` 元素的 `requestSubmit()` 或 `submit()` 方法。
- **`action` 屬性**：`action` 屬性應包含 URL 或當前網域的相對路徑。此值決定表單嘗試將資料送往何處——如果未設定 `action` 屬性，表單將會將資料送到當前頁面的 URL。

- **`method` 屬性**：這個屬性接受標準的 `HTTP` 方法，例如 `GET` 或 `POST`，並在向 action URL 發送請求時使用該方法。如果沒有設定方法，表單預設會用 `GET` 請求。表單中的資料會以 `name=value` 配對的 URL 編碼方式，附加在 action URL 作為查詢參數。

- **`enctype` 屬性**：`form` 元素接受一個 `enctype` 屬性，代表要用哪種編碼方式傳送資料。這個屬性只接受三種值：`application/x-www-form-urlencoded`（預設，將資料以 URL 編碼的表單主體傳送）、`text/plain`（以純文字方式傳送資料，`name=value` 配對以新行分隔）、或 `multipart/form-data`，專門用於處理有檔案上傳的表單。

## `date()` 物件和常用方法

- **定義**：`date()` 物件用於在 JavaScript 中建立、操作和格式化日期與時間。例如，`const now = new Date();` 建立一個 `Date` 物件的新實體並指派給變數 `now`。如果你將 `now` 的值輸出到主控台，你會看到根據執行程式的電腦系統時鐘的當前日期和時間。

- **`Date.now()` 方法**：此方法用於取得目前的日期和時間。`Date.now()` 傳回自 1970 年 1 月 1 日 00:00:00 UTC 起的毫秒數。這稱為 Unix 紀元時間。Unix 紀元時間是在電腦系統中常用來表述日期和時間的方式，因為它是一個整數，能夠輕鬆儲存和操作。UTC 代表協調世界時，是全球調整時鐘和時間的主要時間標準。
- **`getDate()` 方法**：此方法用於根據當前日期取得一個月份中的日期。`getDate()` 會傳回介於 1 和 31 之間的整數值，取決於當天的日期。如果日期無效，則會傳回 `NaN`（非數字）。

- **`getMonth()` 方法**：此方法用於取得月份。月份是從零開始計數的，因此一月是 0，二月是 1，依此類推。例如，在十月的日期上呼叫 `getMonth()` 會回傳 `9`。如果月份無效，則回傳 `NaN`。

- **`getFullYear()` 方法**：這個方法用來取得完整年份。如果年份無效，會傳回 `NaN`。

## 不同的日期格式化方式

- **`toISOString()` 方法**：這個方法用來將日期格式化為延伸 `ISO`（ISO 8601）格式。ISO 8601 是一個國際標準的日期和時間表示方式。格式為 `YYYY-MM-DDTHH:mm:ss.sssZ`。

- **`toLocaleDateString()` 方法**：這個方法會根據使用者的語系格式化日期。

`toLocaleDateString()` 方法接受兩個選用參數：locales 和 options。

locales 參數是一個字串，代表要使用的語系。例如，你可以傳入 `"en-US"` 代表英文（美國），或 `"fr-FR"` 代表法文（法國）。如果你沒有傳入 locales 參數，會使用預設語系。第二個選用參數是 options 參數。這個參數是一個物件，可以讓你指定日期字串的格式。

## `Audio` 建構式與常用方法

- **定義**：`Audio` 建構式，像其他建構式一樣，是一個使用 `new` 關鍵字呼叫的特殊函式（程式）。它會傳回一個 `HTMLAudioElement`，你可以用來為使用者播放音訊，或附加到 DOM 讓使用者自行控制。當你呼叫建構式時，可以選用傳入一個 URL 作為（唯一）引數。這個 URL 應該指向你想播放的音訊檔案來源。或者，如果你需要動態變更來源，可以將 URL 指定給傳回的音訊元素的 `src` 屬性。
- **`play()` 方法**：此方法用於 `audio` 或 `video` 元素，以開始播放媒體。

- **`pause()` 方法**：此方法用於 `audio` 或 `video` 元素，以暫停媒體播放。它會維持目前播放位置，因此如果呼叫 `play()`，會從該位置繼續播放。

- **`addTextTrack()` 方法**：這個方法讓你可以指定一個文字軌道與媒體元素關聯——這對於為影片添加字幕特別有用。
- **`fastSeek()` 方法**：這個方法讓你可以將播放位置移動到媒體中的特定時間點。

`Audio()` 建構式除了有方法，也有屬性。這些屬性包括：

- `currentTime`：取得音訊目前的播放時間
- `loop`：讓音訊持續播放，當播放結束時自動重新開始
- `muted`：靜音媒體元素的音訊輸出，不論音量設定為何

## 不同的音訊與影片格式

- **MIME 類型**：MIME 類型，全名為多用途網際郵件擴充（Multipurpose Internet Mail Extensions），是一種以程式方式標示檔案類型的標準方式。MIME 類型可以告訴應用程式（例如你的瀏覽器）如何處理特定檔案。對於音訊和影片，MIME 類型表示它是一種可嵌入網頁的多媒體格式。
- **`source` 元素**：用於指定檔案類型和來源——可以透過多個 source 元素包含多種不同類型。瀏覽器會根據使用者當前環境判斷最佳格式。
- **MP3**：一種用於儲存音樂、音訊或聲音的數位檔案格式。它是聲音錄音的壓縮版本，使檔案大小更小，更容易儲存和分享。MP3 擁有最廣泛的瀏覽器支援，MIME 類型為 `audio/mpeg`。
- **MP4**：一種用於儲存影片和音訊的數位檔案格式。它作為一個容器，同時包含影片（影像）和聲音（音樂或語音）於一個檔案中。MP4 的 MIME 類型可為 `audio/mp4` 或 `video/mp4`，視是否為影片檔或僅音訊而定。
- 其他格式還有與 Windows Media Player 相關的 `WMV`、`OGG`、`MKV`、`AVI` 等。

## 編解碼器（codecs）

- **定義**：codec 是「編碼器／解碼器」（encoder/decoder）的縮寫，是一種可以在類比和數位格式之間轉換音訊和影片的演算法或軟體。codec 可以作為 MIME 類型的一部分來指定。定義 codec 的基本語法是在媒體型別後加分號，然後 `codecs=` 和 codec。

## HTMLMediaElement API

- **定義**：`HTMLMediaElement` API 用於控制頁面上的音訊和影片元素行為。它擴充了基底的 `HTMLElement` 介面，因此你可以存取基底屬性、方法，以及像 `waiting`、`ended`、`canplay`、`canplaythrough` 等有用事件。方法範例包括 `play()`、`fastSeek()`、`pause()`，以及用於檢查瀏覽器是否可能播放音訊檔的 `canPlayType()`。

## 媒體擷取與串流 API

- **定義**：Media Capture and Streams API（又稱 MediaStream API）用來從你的裝置擷取音訊和影片。要使用這個 API，你需要建立 `MediaStream` 物件。雖然可以用建構式建立，但這樣不會和使用者的硬體綁定。正確做法是使用 `mediaDevices` navigator 物件的 `global` 屬性下的 `getUserMedia()` 方法。

## 螢幕擷取 API

- **定義**：螢幕擷取 API 用來錄製使用者的螢幕。這個 API 透過呼叫 `getDisplayMedia()` 物件的 `mediaDevices` 方法並使用傳回的媒體串流來實現。

## MediaStream 錄製 API

## JavaScript 中的 Set

- `Set` 是用來管理資料群集的內建選項。
- Sets 確保其中的每個值只出現一次，使其適合用來消除陣列中的重複項目或處理不同值的群集。
- 你可以使用 `Set()` 建構式來建立一個 `Set`。

- Set 可以用以下方法操作：

  - `add()`: 為 `Set` 添加一個新元素。
  - `delete()`：從 `Set` 中移除一個元素。
  - `has()`：檢查元素是否存在於 `Set` 中。
  - `clear()`：從 `Set` 中移除所有元素。
  - `keys()` 和 `values()`：兩者都傳回一個包含 `Set` 值的 `SetIterator`。它們是相同的，因為 `keys()` 是 `values()` 的別名。
  - `forEach()`：用於遍歷 `Set` 的值。

## JavaScript 中的 WeakSet

- `WeakSet` 是一種只儲存物件、且物件參照為弱參照的群集。

## Set 與 WeakSet 的比較

- 和 Set 不同，`WeakSet` 不支援像數字或字串這樣的原始型別。
- `WeakSet` 只儲存物件，而且對這些物件的參照是「弱」的，也就是說如果該物件在程式其他地方沒有被使用，會自動移除以釋放記憶體。

## JavaScript 中的 Map

- `Map` 是一種內建物件，持有鍵值對，類似物件。
- Maps 與標準 JavaScript 物件不同，因為它允許任何型別的鍵，包括物件和函式。
- 在頻繁新增和移除鍵值對時，`Map` 提供比標準物件更好的效能。
- 你可以使用 `Map()` 建構式來建立一個 `Map`。

- Map 可以用以下方法操作：

  - `set()`：將新鍵值配對加入 `Map`。
  - `get()`：從 `Map` 取得某個鍵的值。
  - `delete()`：從 `Map` 移除某個鍵值配對。
  - `has()`：檢查某個鍵是否存在於 `Map`。
  - `clear()`：移除 `Map` 中所有鍵值配對。

請注意，Maps 和 Sets 都有 `size` 屬性，該屬性會傳回其中唯一元素的數量。

## JavaScript 中的 WeakMap

- `WeakMap` 是一種和 `Map` 類似的鍵值配對群集，但鍵是弱參照。鍵必須是物件，值則可以是任何你想要的型別。

## Maps 與 WeakMaps

- WeakMaps 與 WeakSets 類似，只能儲存物件，且對這些物件的引用是「弱引用」。

## 持久儲存

- **定義**：持久性儲存是指一種儲存資料的方式，即使在關閉電源或重新啟動裝置後，資料仍然可用。

## 創建、讀取、更新、刪除（CRUD）

- **創建**：這是指創建新資料的處理程序。例如，在網頁應用程式中，這可能是當使用者為部落格添加新文章時。
- **讀取**：這是從資料庫擷取資料的操作行為。例如，當你瀏覽部落格文章或查看網站上的評測時，你正在執行讀取操作行為以擷取並顯示儲存在資料庫中的資料。
- **更新**：這涉及修改資料庫中現有的資料。範例包括編輯部落格文章或更新你的評測資訊。
- **刪除**：這是從資料庫中移除資料的操作行為。例如，當你刪除一篇部落格文章或帳號時，你正在執行刪除操作行為。

## HTTP 方法

- **定義**：HTTP 代表超文字傳輸協定，它是網路上資料通訊的基礎。有 HTTP 方法定義了可以對網路上的資源執行的動作。常見的方法有 GET、POST、PUT、PATCH、DELETE。
- **`GET` 方法**：這用於從伺服器擷取資料。
- **`POST` 方法**：這用於將資料提交到伺服器，該伺服器會創建一個新的資源。
- **`PUT` 方法**：這用於透過完全取代來更新資源。
- **`PATCH` 方法**：這用於部分更新資源。
- **`DELETE` 方法**：這用於從資料庫中移除記錄。

## `localStorage` 和 `sessionStorage` 屬性

- **Web Storage API**：此 API 提供瀏覽器在瀏覽器內部儲存鍵值對的機制，讓開發者能夠儲存可跨不同頁面重新載入和工作階段使用的資訊。Web Storage API 的兩個主要組件是 `localStorage` 和 `sessionStorage` 屬性。
- **`localStorage` 屬性**：`localStorage` 是 Web Storage API 的零件，允許資料即使在瀏覽器視窗關閉或頁面重新整理後仍然持續存在。這些資料會一直保留，直到應用程式或使用者明確地將其移除。
- **`localStorage.setItem()` 方法**：此方法用於在 `localStorage` 中儲存一組鍵值配對。

- **`localStorage.getItem()` 方法**：此方法用於從 `localStorage` 取得指定鍵的值。

- **`localStorage.removeItem()` 方法**：此方法用於使用其鍵從 `localStorage` 中移除特定項目。

- **`localStorage.clear()` 方法**：此方法用於清除 `localStorage` 中所有儲存的資料。

- **`sessionStorage` 屬性**：儲存只在當前工作階段持續的資料，並且在瀏覽器分頁或視窗關閉時清除。
- **`sessionStorage.setItem()` 方法**：此方法用於在 `sessionStorage` 中儲存一個鍵值對組。

- **`sessionStorage.getItem()` 方法**：此方法用於從 `sessionStorage` 中取得指定鍵的值。

- **`sessionStorage.removeItem()` 方法**：此方法用於使用其鍵從 `sessionStorage` 中移除特定項目。

- **`sessionStorage.clear()` 方法**：此方法用於清除儲存在 `sessionStorage` 中的所有資料。

## 操作 Cookies

- **定義**：Cookies，也稱為網頁 Cookies 或瀏覽器 Cookies，是伺端傳送給使用者網頁瀏覽器的小塊資料。這些 Cookies 會儲存在使用者的裝置上，並在後續請求時回傳給伺端。Cookies 對於協助網頁應用程式維護狀態並記住使用者資訊至關重要，這在 HTTP 是無狀態協定的情況下尤其重要。
- **工作階段 Cookie**：這些 Cookie 僅在使用者於網站上的工作階段期間有效。一旦使用者關閉瀏覽器或分頁，工作階段 Cookie 即會被刪除。這些 Cookie 通常用於在使用者訪問期間保持登入狀態等任務。
- **安全 Cookie**：這些 Cookie 僅會透過 HTTPS 傳送，確保它們在傳輸過程中不會被攻擊者攔截。
- **HttpOnly Cookies**：這些 cookies 無法被瀏覽器中執行的 JavaScript 存取或修改，使它們在防範跨站腳本攻擊（XSS）方面更為安全。
- **Set-Cookie 標頭**：當你造訪網站時，伺服端可以在 HTTP 回應中傳送 Set-Cookie 標頭。此標頭會告訴你的瀏覽器存檔一個帶有特定資訊的 cookie。例如，它可能會儲存一個唯一 ID，幫助網站在你下次造訪時辨識你。  
你可以使用 `document.cookie` 在 JavaScript 中手動設定 cookie：

```js
document.cookie = "organization=freeCodeCamp; expires=Fri, 31 Dec 2021 23:59:59 GMT; path=/";
```

要刪除 cookie，你可以將其過期時間設定為過去的時間。

## 快取 API

- **定義**：快取是將檔案的副本儲存在暫存位置的過程，以便能更快速地存取。Cache API 用於儲存網路請求和回應，使網頁應用程式能更高效地運作，甚至能離線運作。它是更廣泛的 Service Worker API 的一部分，對於建立能在不穩定或緩慢網路條件下運作的漸進式網頁應用程式（PWA）至關重要。  
Cache API 是一種儲存機制，用於儲存 Request 和 Response 物件。當向伺服器發出請求時，應用程式可以將回應儲存起來，之後從快取中取回，而不必重新發出網路請求。這樣可以減少載入時間、節省頻寬，並提升整體使用者體驗。
- **快取儲存**：這用於儲存 HTTP 請求及其對應回應的鍵值對組。這可啟用高效檢索先前請求的資源，減少後續造訪時從網路擷取的需求，並提升效率。
- **Cache-Control**：開發者可以定義快取資源應該保留多久，以及是否應該重新驗證或直接從快取提供。
- **離線支援**：透過使用 Cache API，你可以創建離線優先的網頁應用程式。舉例來說，PWA 可以在使用者與網路斷線時提供快取的資源。

## 負面樣式和客戶端儲存

- **過度追蹤**：指在未取得明確、知情同意或合法需求的情況下，於客戶端儲存空間（例如 cookies、區域儲存或工作階段儲存）中收集並儲存過多使用者資料的行為。這通常涉及跨多個網站或工作階段追蹤使用者行為、偏好和互動，可能侵犯使用者隱私。
- **瀏覽器指紋辨識**：一種用於追蹤和識別個別使用者的技術，根據其裝置和瀏覽器的獨特特徵，而非依賴 cookie 或其他傳統追蹤方法。與儲存在使用者裝置上的 cookie 不同，指紋辨識涉及收集一系列資訊，用以創建使用者瀏覽器工作階段的獨特「指紋」。
- **在 LocalStorage 中設定密碼**：這看起來可能是更明顯的負面樣式，但在區域的儲存中設定任何敏感資料如密碼會帶來安全風險。Local Storage 沒有加密且很容易被存取、取用。所以你絕不應該將任何類型的敏感資料儲存在那裡。

## IndexedDB

- **定義**：IndexedDB 用於在瀏覽器中儲存結構化資料。這是內建於現代網頁瀏覽器中，允許網頁應用程式高效地儲存和擷取 JavaScript 物件。

- **定義**：Service Worker 是一個在背景中執行且與你的網頁分離的腳本。它可以攔截網路請求、存取快取，並使網頁應用程式能離線運作。這是漸進式網頁應用程式的重要組件。

## 類別的基本操作

- **定義**：在 JavaScript 中，類別用來定義創建物件和封裝資料的藍圖。類別包含一個建構式（constructor），這是一個特殊的方法，當從類別建立新物件時會自動呼叫。它用來初始化物件的屬性。在這裡會用到 `this` 關鍵字來指向目前類別的實體。建構式下方可以定義所謂的方法。方法是在類別內定義的函式，用來對類別的資料或狀態執行動作或操作。它們用來定義類別實體可以執行的行為。

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);  // Gino
```

:::

要建立類別的新實體，你會使用 `new` 關鍵字，後面接類別名稱。

你也可以用類別表示式來建立類別。這種方式下，類別是匿名的，並指派給一個變數。

## 類別繼承

- **定義**：在程式設計中，繼承允許你定義可以繼承父類別屬性和方法的類別。這促進程式碼重複利用，並建立類別之間的階層關係。父類別就像其他類別的藍圖，定義了會被其他類別繼承的屬性和方法。子類別則是繼承其他類別屬性和方法的類別。子類別也可以透過新增屬性和方法來擴充父類別的功能。在 JavaScript 中，我們使用 `extends` 關鍵字來實作繼承。這個關鍵字表示某個類別是另一個類別的子類別。

`super` 關鍵字用來存取父類別的方法、建構式和欄位。

:::interactive_editor

```js
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  constructor(brand, year, numDoors) {
    super(brand, year);
    this.numDoors = numDoors;
  }
}

const myCar = new Car("freeCodeCamp Motors", 2019, 4);
console.log(myCar.brand);  // freeCodeCamp Motors
console.log(myCar.year);  // 2019
console.log(myCar.numDoors);  // 4
```

:::

## 操作靜態方法與靜態屬性

- **靜態方法**：這些方法通常用於不需要存取物件特定狀態的工具函式。它們定義在類別內，用來封裝相關功能。

使用 `static` 關鍵字定義靜態方法，並直接在類別本身呼叫它。

靜態方法也很適合實作「工廠方法」。工廠方法是你在建構式之外定義，用來根據特定條件建立物件的方法。

- **靜態屬性**：這些屬性用來定義與類別本身相關的值或屬性，而不是與類別實體相關。靜態屬性會在所有類別實體間共用，且不需建立實體即可存取。

例如，`static numberOfWheels = 4;` 在類別內定義一個靜態屬性。

- 遞迴是一種程式設計概念，允許你重複呼叫一個函式，直到達到基底案例為止。

這是一個計算數字階乘的遞迴函式（程式）範例：

```js
function findFactorial(n) {
  if (n === 0) {
    return 1;
  }
  return n * findFactorial(n - 1);
}
```

在上述範例中，`findFactorial` 函式（程式）會遞迴呼叫直到 `n` 達到 `0`。當 `n` 是 `0` 時，達到基底情況，函式（程式）傳回 `1`。接著函式（程式）傳回 `n` 與遞迴呼叫 `findFactorial(n - 1)` 結果的乘積。

- 遞迴允許你處理深度未知的事物，例如深度巢狀的物件/陣列，或檔案樹。
- 呼叫堆疊用於追蹤遞迴函式中的函式呼叫。每次呼叫函式時，該函式會被添加到呼叫堆疊中。當達到基底案例時，函式呼叫會從堆疊中移除。
- 你應該仔細定義基底案例，因為無限次呼叫它可能會導致你的程式碼當機。這是因為遞迴會持續堆疊越來越多的函式呼叫，直到系統耗盡記憶體。
- 遞迴用於解決數學問題，例如階乘和 Fibonacci、遍歷樹和圖、產生排列組合等等。

## 演算法與大 O 符號

- **演算法**：解決問題或執行任務的一組明確指令。演算法必須在有限步驟內完成，每一步都必須精確且明確。

- **大 O 符號**：描述演算法在輸入規模增加時的最壞情況效能或成長率。它關注資源使用如何隨輸入大小成長，忽略常數因子和低階項。

### 常見時間複雜度

- **O(1) - 常數時間**：演算法執行時間不受輸入大小影響。

- **O(log n) - 對數時間**：隨輸入增長時間緩慢增加。常見於反覆將問題規模縮小的演算法（如二分搜尋）。

- **O(n) - 線性時間**：執行時間與輸入大小成正比。

- **O(n log n) - 線性對數時間**：高效排序演算法如合併排序和快速排序的常見時間複雜度。

- **O(n²) - 平方時間**：執行時間以平方速度增加。常見於巢狀迴圈。

### 空間複雜度

- **O(1) - 常數空間**：演算法使用的記憶體不隨輸入大小改變。
- **O(n) - 線性空間**：記憶體使用與輸入大小成正比。
- **O(n²) - 平方空間**：記憶體使用以平方速度增加。

## 問題解決技巧

- **理解問題**：多次閱讀問題描述。辨識輸入、預期輸出，以及如何將輸入轉換為輸出。

- **偽程式碼**：用高階語言描述演算法邏輯，與程式語言無關。使用常見書寫語言混合程式結構如 `IF`、`ELSE`、`FOR`、`WHILE`。

- **邊界案例**：在演算法應處理範圍邊界出現的特定有效輸入。務必考慮並測試邊界案例。

## 陣列

- **靜態陣列**：初始化時大小固定。元素存放於相鄰記憶體位置。執行期間大小不可變。

- **動態陣列**：執行期間可自動增減大小。透過自動複製到更大陣列來調整大小。

### JavaScript 中的動態陣列實作

JavaScript 陣列是動態陣列。你可以透過索引存取和更新元素，使用 `push()` 新增元素，使用 `pop()` 或 `splice()` 移除元素。

### 動態陣列的時間複雜度

- **存取**：O(1)
- **尾端插入**：平均 O(1)，調整大小時 O(n)
- **中間插入**：O(n)
- **刪除**：中間 O(n)，尾端 O(1)

## 堆疊

- **堆疊**：後進先出（LIFO）資料結構。元素只能從頂端新增和移除。

- **推入操作**：將元素加入堆疊頂端。時間複雜度：O(1)。

- **彈出操作**：從堆疊頂端移除元素。時間複雜度：O(1)。

JavaScript 陣列可以當作堆疊使用，使用 `push()` 新增元素，使用 `pop()` 移除元素。

## 佇列

- **佇列**：先進先出（FIFO）資料結構。元素從尾端加入，從前端移除。

- **入列操作**：將元素加入佇列尾端。時間複雜度：O(1)。

- **出列操作**：從佇列前端移除元素。時間複雜度：O(1)。

陣列可以當作佇列使用，使用 `push()` 進行入佇列，使用 `shift()` 進行出佇列。但 `shift()` 的時間複雜度是 O(n)，因為剩餘元素必須移動。

## 鏈結串列

- **鏈結串列**：線性資料結構，每個節點包含資料和指向下一節點的參考。節點像串鏈般連接。

### 單向鏈結串列

- **結構**：每個節點都有資料和一個指向下一個節點的引用。
- **遍歷**：只能從頭部向尾部前進。
- **Head Node**：列表中的第一個節點，通常是唯一可直接存取的節點。
- **尾節點**：列表中的最後節點，指向 `null`。

### 操作與時間複雜度

- **開頭插入**：O(1)
- **尾端插入**：O(n) - 需巡訪至尾端
- **中間插入**：O(n) - 需巡訪至指定位置
- **開頭刪除**：O(1)
- **尾端刪除**：O(n) - 需巡訪尋找前一節點
- **中間刪除**：O(n) - 需巡訪尋找節點

### 雙向鏈結串列

- **結構**：每個節點有資料和兩個參考：下一節點與前一節點。
- **巡訪**：可雙向移動。
- **記憶體**：因多一個參考，需比單向鏈結串列更多記憶體。

## 何時使用各種資料結構

- **陣列（動態陣列）**：當你需要有序、索引存取且事先不知道大小時
- **堆疊**：用於 LIFO 操作（復原功能、表達式評估、回溯）
- **佇列**：用於 FIFO 操作（任務排程、廣度優先搜尋）
- **鏈結串列**：當頻繁在開頭插入/刪除、大小未知、且不需要隨機存取時

## 搜尋演算法

搜尋演算法讓你在特定的項目列表中搜尋標的。

在計算機科學中，有兩種搜尋演算法你應該了解。它們是**線性搜尋**和**二分搜尋法**演算法。了解這兩種演算法的差異以及何時使用各自非常重要。

### 線性搜尋

- 線性搜尋會迭代一個陣列的項目，從開始檢查每個項目直到找到標的項目。
- 如果找到標的項目，則傳回該標的在陣列中的索引。
- 如果找不到標的，則傳回 `-1`，這在 JavaScript 中代表**無效索引**。
- 因為線性搜尋會檢查每個項目直到找到標的，所以對於大量項目的陣列來說並不高效。
- 線性搜尋的時間複雜度是 `O(n)`，因為搜尋整個陣列所需的時間會隨著陣列大小線性增加。
- 線性搜尋的空間複雜度是 `O(1)`，因為它不需要任何額外空間來搜尋陣列。

### 二元搜尋

- 二分搜尋法透過將陣列的項目對半分割，並檢查標的值是否位於陣列中間來運作。
- 二分搜尋法能運作的條件是陣列中的項目必須已排序，且排序方式為遞增或遞減。
- 二分搜尋法是一種更高效的演算法，用於搜尋大量陣列中的條款，因為它將陣列分成兩半，並忽略任何未找到標的的那一半。
- 如果在陣列中間找到標的項目，則會傳回該標的項目的索引。
- 如果找不到該項目，演算法會檢查標的項目是在陣列的左半部還是右半部。
- 它會持續將陣列剩餘的零件一分為二，直到找到標的項目。
- 如果在陣列中找不到標的項目，則傳回 `-1`，
- 二分搜尋法的時間複雜度是 `O(log n)`，因為搜尋陣列所需的時間會隨著陣列大小以對數方式成長。
- 二分搜尋法的空間複雜度是 `O(1)`，因為它不需要任何額外空間來搜尋陣列。

### 線性搜尋與二元搜尋的差異

- 與線性搜尋相比，二分搜尋法更適合用於大型陣列的條款。
- 線性搜尋的時間複雜度是 `O(n)`，因為搜尋整個陣列所需的時間會隨著陣列大小線性增加。
- 二分搜尋法的時間複雜度是 `O(log n)`，因為搜尋陣列所需的時間會隨著陣列大小以對數方式成長。

## 排序演算法與分治法

在計算機科學中，分而治之是一種用來將問題拆解成較小子問題的技術，使其更容易解決。遞迴是分而治之中常用的技術，而分而治之是一種強大的策略，用於實作許多高效的排序演算法，如合併排序。

### 合併排序

- 合併排序是一種遵循分而治之方法的排序演算法。
- 它透過遞迴地將一個 array 拆分成更小的子 array，直到每個子 array 只包含一個元素。
- 然後它會反覆將子陣列合併回去，並以排序的順序排列。
- 合併排序的時間複雜度是 `O(n log n)`，因為陣列不斷被對半切分 `(log n)`，然後再合併在一起 `(O(n))`。
- 合併排序的空間複雜度是 `O(n)`，因為它不是就地排序演算法。

## 圖形概述

圖形是一組由邊（連接）連結的節點（頂點）。每個節點可連接多個其他節點，形成網路。圖形類型包括：

- **有向圖**：邊有方向（從一個節點指向另一個節點），通常用直線和箭頭表示。
- **無向圖**：邊沒有方向，用簡單的線條表示。
- **節點標籤**：每個節點都會有一個標籤或識別符。
- **有環圖**：包含環路（起點和終點相同的路徑）。
- **有向無環圖（DAG）**：一種沒有環路的有向圖。
- **邊標籤**：每條邊都有標籤，通常標示在邊的旁邊。
- **加權圖**：邊帶有權重（數值），可用來進行算術運算。
- **非連通圖**：包含兩個或以上不相連的節點群組（組件）。兩個節點即使沒有直接邊相連，也可能存在路徑相通。

圖形被用於各種應用，例如地圖、網路、推薦系統和相依性決議。

## 圖形巡訪

涉及拜訪圖中所有節點。兩種主要演算法：

- **廣度優先搜尋（BFS）**：先拜訪所有鄰近節點，再移動到圖的下一層。
  - **佇列**：使用佇列（先進先出）。起始節點標記為已拜訪並加入佇列。當佇列不空時，從佇列中取出目前節點，將其所有未拜訪的鄰居標記為已拜訪並加入佇列。
  - **最短路徑**：在無權重圖中尋找最短路徑。
  - **記憶體**：需要在記憶體中存放佇列，對於同一層有大量節點的圖，空間需求可能相當大。
  - **連通組件**：也可用於尋找連通的圖組件，從每個尚未拜訪的節點開始新的搜尋。
  - **狀態空間搜尋**：使用佇列追蹤不同狀態以生成括號組合。每個狀態以陣列表示，包含目前生成的字串、已使用的開括號數量和已使用的閉括號數量。只有當已使用的開括號數小於配對數時，才能加入開括號。只有在保持平衡（已使用開括號數多於閉括號數）時，才能加入閉括號。

- **深度優先搜尋（DFS）**：沿著每個分支盡可能深入，然後回溯。
  - **堆疊**：使用堆疊（後進先出）或遞迴。起始節點標記為已拜訪並加入堆疊。當堆疊不空時，彈出目前節點，將其所有未拜訪的鄰居標記為已拜訪並加入堆疊。
  - **記憶體**：需要在記憶體中存放堆疊（或使用遞迴時的函式呼叫堆疊），對於路徑很長的圖，空間需求可能增加。
  - **使用情境**：適用於偵測環路、尋找路徑和尋找連通組件。
  - **限制**：不一定能保證在無權重圖中找到兩節點間的最短路徑。

## 圖形表示法

圖形主要有兩種表示方式：

- **鄰接列表**：每個節點有一個鄰居列表。
  - **實作**：可用陣列表示，每個索引代表一個節點，該索引處的陣列包含其鄰居。也可用物件（或 `Map`）表示，每個鍵代表節點，對應的值（陣列）包含其鄰居。
  - **空間**：對於稀疏圖空間高效，空間複雜度為 `O(V + E)`，其中 `V` 是節點數，`E` 是邊數。
  - **鄰居**：易於迭代鄰居，因為只需存取節點相關的列表。
  - **邊查找**：判斷兩節點間是否有邊不如鄰接矩陣高效，通常需 `O(deg(v))` 時間，其中 `deg(v)` 是該節點的鄰居數，最壞情況可達 `O(V)`。
  - **適用情境**：通常是現實場景中較常用的選擇，因為稀疏圖較普遍。

- **鄰接矩陣**：一個二維陣列，列和行代表節點。
  - **數值**：若圖無權重，值為 `1` 表示節點間有邊，值為 `0` 表示無邊。若有權重，值代表連接節點的邊的權重。
  - **自環**：對角線上的值表示節點是否有自環（連接自身的邊）。
  - **空間**：對大型圖空間需求大，為二次方空間 `O(V²)`，其中 `V` 是節點數。
  - **邊查找**：判斷兩節點間是否有邊非常快，為常數時間 `O(1)`。
  - **鄰居**：尋找節點鄰居效率低，因需遍歷整行或整列，最壞情況為 `O(V)`。
  - **適用情境**：適合邊數多的密集圖，對稀疏圖效率不佳。

## 最短路徑演算法

- **最短路徑演算法**：計算加權圖中節點間的最短路徑，並回傳距離和路徑。
  - **鄰接矩陣**：每個值代表兩節點間邊的權重（距離）。
  - **缺失邊**：值為 `INF`（`Infinity`）表示沒有直接邊。
  - **距離**：一個陣列，追蹤從起始節點到其他節點的最短已知距離。初始時，所有節點距離假設為無限遠，起始節點到自身距離為 `0`。
  - **路徑**：一個列表，每個項目是節點索引陣列，代表到達該節點的路徑。
  - **已拜訪**：一個陣列，追蹤已處理的節點，避免重複拜訪。
  - **最近未拜訪節點**：主迴圈對每個節點執行一次，每次選擇最近的未拜訪節點。
  - **邊鬆弛**：對每個有實際邊且未拜訪的鄰居，檢查是否能透過目前節點更有效率地到達。若新距離較短，更新距離和路徑。
  - **無法抵達節點**：當找不到有效節點時，剩餘節點皆無法抵達，迴圈提前結束。
  - **選用目標**：`targetNode` 參數為選填。若未提供，函式會計算從 `startNode` 到所有其他節點的最短路徑。

## 樹

樹是特殊的圖，無環且連通。主要特性：

- **無環**：樹沒有迴圈或環路（起點和終點相同的路徑）。
- **連通**：每個節點都能從其他節點抵達。

### 樹的術語

- **根節點**：樹的最頂端節點，是唯一沒有父節點的節點。
- **父節點**：直接連接到下方其他節點的節點。
- **子節點**：直接連接到上方節點的節點。
- **葉節點**：沒有子節點的節點。
- **深度**：從根節點到該節點的路徑長度。
- **高度**：從該節點到葉節點的路徑長度。樹的高度即為根節點的高度。
- **度數**：每個節點擁有的子節點數量。
- **子樹**：樹的一部分，本身也是一棵樹。
- **平衡樹**：任一節點的左右子樹高度相近，確保操作維持高效。

### 常見的樹型

最常見的樹型有：

- **二元樹**：每個節點最多有兩個子節點，分別是左子節點和右子節點。

- **二元搜尋樹（BST）**：一種二元樹，對每個節點，其左子樹所有值均小於該節點值，右子樹所有值均大於該節點值。左右子樹本身也必須是二元搜尋樹。

- **自我平衡樹**：包含額外內部邏輯，當插入或刪除造成不平衡時會重新平衡樹。常見例子有 AVL 樹、紅黑樹和 B 樹。

- **AVL 樹**：一種自我平衡的二元搜尋樹，任一節點的左右子樹高度最多相差 1。

- **紅黑樹**：一種自我平衡的二元搜尋樹，每個節點有紅色或黑色標記。

- **B 樹**：一種自我平衡樹，每個節點可有多個鍵值和超過兩個子節點。

## 字首樹（Trie）

- **Trie 樹**：又稱前綴樹，用於儲存字串集合，每個節點代表一個字元。
- **根節點**：根節點不代表特定字元，可視為代表空字串。
- **前綴**：從根節點往下巡訪時，到達某節點的路徑定義了一個特定前綴。
- **字尾標記**：代表完整字串的節點會被標記為字尾。
- **共用前綴**：多個字串共用相同前綴時，路徑會重疊，前綴只儲存一次，使 Trie 在自動完成和拼字檢查等任務中高效。
- **插入**：只需為 Trie 中尚不存在的字元創建新節點。
- **時間複雜度**：搜尋和插入操作為 `O(L)`，其中 `L` 是字串長度。
- **記憶體**：若字串集合中有許多獨特字元，Trie 可能效率不佳，因需為每個獨特字元存放節點。

## 優先佇列

- **優先佇列**：一種抽象資料型態，每個元素有優先權。
- **佇列和堆疊**：佇列和堆疊只考慮插入順序，優先佇列則考慮元素優先權。標準佇列遵循 FIFO（先進先出），堆疊遵循 LIFO（後進先出）。
- **移除順序**：通常優先移除優先權最高的元素，但有些實作也可能先移除優先權最低的元素。
- **平手處理**：若需同優先權元素依插入順序移除，可加入唯一計數器以打破平手。
- **應用**：尋找兩地間最短路徑、作業系統排程、交通模擬、資料壓縮和網路管理。

## 堆積（Heap）

堆積是一種特殊的樹狀資料結構，具有稱為堆積性質的特定屬性。

堆積性質決定父節點與子節點的關係。有兩種堆積：

- **最大堆積**：每個父節點的值大於或等於其子節點的值，且最大元素位於根節點。

- **最小堆積**：每個父節點的值小於或等於其子節點的值，且最小元素位於根節點。

JavaScript 沒有內建的堆積模組，但你可以使用陣列實作一個最小堆積。

- **陣列儲存**：堆積通常以陣列實作，以有效存取父節點和子節點。若堆積維持完整二元樹結構，陣列實作只需根據索引進行簡單數學運算即可找到元素位置。
- **索引**：對於索引為 `i` 的節點，父節點位於 `Math.floor((i - 1) / 2)`，左子節點位於 `2 * i + 1`，右子節點位於 `2 * i + 2`。
- **窺視（Peek）**：取得最小或最大值（視堆積類型而定）而不移除。
- **推入（Push）**：將元素加入適當位置以維持堆積性質。新元素加入陣列末端，然後向上移動，與父節點交換位置，直到堆積性質被維持（冒泡上升）。
- **彈出（Pop）**：移除優先權最高的元素（此處為最小值）。陣列最後一個元素取代根節點，然後向下移動，與較小的子節點交換位置，直到堆積性質被維持（冒泡下降）。
- **推入彈出（PushPop）**：將推入和彈出合併為一次呼叫。比起分別呼叫更高效，尤其在堆積很大時，因只需執行一次重新排序操作。
- **堆化（Heapify）**：將現有陣列轉換成堆積。
- **比較回呼**：JavaScript 陣列不會自動逐元素比較排序，需傳入比較函式給堆積，先比較優先權，例如 `new MinHeap((a, b) => a[0] - b[0])`，其中元素以 `[priority, element]` 儲存。數值越小代表優先權越高。
- **穩定平手打破**：在每個項目中加入遞增的插入計數器作為第二元素，如 `[priority, counter, element]`。先比較優先權，若相等再比較計數器：`new MinHeap((a, b) => (a[0] - b[0]) || (a[1] - b[1]))`。
- **時間複雜度**：插入和取出最小或最大值為 `O(log n)`，窺視為 `O(1)`，堆化為 `O(n)`，搜尋或刪除任意元素為 `O(n)`。
- **空間複雜度**：`O(n)`，其中 `n` 是堆積中元素數量。

## 動態規劃簡介

- **定義**：動態規劃是一種演算法技巧，透過將複雜問題拆解成較簡單子問題並儲存結果，避免重複計算。
- **重疊子問題**：解決較大問題時，會多次遇到相同的較小問題。透過儲存解答避免重複計算。
- **最優子結構**：問題的最優解包含其子問題的最優解。表示可透過組合子問題的最佳解來構建整體最佳解。

## 動態規劃解法

- **備忘錄法（自頂向下）**：備忘錄法儲存昂貴函式呼叫的結果，當相同輸入再次出現時回傳快取結果。

- **表格法（自底向上）**：表格法從底層開始建立解答，填滿子問題解答的表格。

## 使用動態規劃的實際應用

- **路徑最佳化**：GPS 系統使用動態規劃演算法來尋找地點之間的最短路徑。
- **文字處理**：拼字檢查和自動完成功能經常依賴動態規劃來計算單字之間的編輯距離。
- **財務建模**：投資策略和投資組合最佳化常常運用動態規劃技術。
- **資源分配**：背包問題及其變體出現在排程、預算和資源管理中。

## 何時使用動態規劃

你應該在以下情況考慮使用動態規劃：

- 問題可以拆解成重疊的子問題。
- 問題具有最佳子結構。
- 簡單的遞迴解法會涉及重複計算。
- 你需要以空間複雜度為代價來優化時間複雜度。

## 純函式與不純函式

- 純函式指的是對相同輸入永遠產生相同輸出，且沒有任何副作用的函式。它的輸出只依賴輸入，不會修改任何外部狀態。
- 不純函式則會產生副作用，也就是會對程式狀態造成外部可觀察的變化。

## 函數式程式設計

- 函式式程式設計是一種軟體開發方法，強調使用函式來解決問題，著重於需要完成的事情，而非如何完成。
- 函式式程式設計鼓勵使用有助於避免副作用的技術，例如使用不可變的資料結構和高階函式。
- 當正確使用時，函式程式設計原則能帶來更乾淨且更易維護的程式碼

## 柯里化（Currying）

- 柯里化是一種函數式程式設計技巧，能將帶有多個引數的函式轉換為一連串只帶單一引數的函式。

例如，柯里化會將呼叫 `average(a, b, c)` 轉換成連續呼叫 `curriedAverage(a)(b)(c)`。

- 柯里化在處理帶有多個引數的函式時特別強大。
- 柯里化讓你的程式碼更靈活、更容易重複利用。
- 你可以用箭頭函式更簡潔地建立柯里化函式：

```js
const curriedAverage = a => b => c => (a + b + c) / 3;
```

- 雖然柯里化能讓程式碼更靈活、可重用，但過度使用會讓程式碼難以閱讀。

- **同步（Synchronous）JavaScript** 會依序執行，每個操作都會等前一個完成後才繼續。
- **非同步（Asynchronous）JavaScript** 允許多個操作在背景同時執行，不會阻塞主執行緒。
- **執行緒（Thread）** 是一組可以獨立於主程式流程執行的指令序列。
- **回呼函式（Callback functions）** 是作為引數傳遞給其他函式，並在操作完成或事件發生時執行的函式。

## JavaScript 引擎與 JavaScript 執行期

- **JavaScript 引擎** 是一個在網頁瀏覽器中執行 JavaScript 程式碼的程式。它像一個轉換器，將你的程式碼轉換成電腦能理解並依此運作的指令。
- V8 是 Google 開發的 JavaScript 引擎範例。
- **JavaScript runtime** 是執行 JavaScript 程式碼的環境。它包含處理並執行程式碼的 JavaScript 引擎，以及像是網頁瀏覽器或 Node.js 等額外的特性。

## Fetch API

- Fetch API 讓網頁應用程式可以發送網路請求，通常用來從伺服器擷取或傳送資料。它提供一個 `fetch()` 方法，你可以用來發送這些請求。
- 你可以用 Fetch API 擷取文字、圖片、音訊、JSON 及其他型態的資料。

## Fetch API 的 HTTP 方法

Fetch API 支援多種 HTTP 方法與伺服器互動。最常用的方法有：

- **GET**：用來從伺服器擷取資料。預設情況下，Fetch API 會使用 `GET` 方法來擷取資料。

若要使用擷取到的資料，必須用 `.json()` 方法將其轉換為 JSON 格式：

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
```

在這段程式碼中，`fetch()` 傳回一個 Promise，而 `.then()` 處理常式將決議的回應轉換為 JSON 格式。

- **POST**：用來傳送資料到伺服器。`POST` 方法用來在伺服器上建立新資源。

```js
fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Doe',
    email: 'john@example.com'
  })
})
```

在這個範例中，我們發送一個 `POST` 請求來建立新使用者。我們指定方法為 `POST`，設置適當的標頭，並在 body 中包含要傳送的資料。body 必須是字串，因此我們用 `JSON.stringify()` 將物件轉換為 JSON 字串。

- **PUT**：用來在伺服器上更新資料。`PUT` 方法用來更新伺服器上的現有資源。

要更新資料，指定 `method: 'PUT'` 並在請求主體中包含更新的資料。URL 指定要更新的資源。

- **DELETE**：用來在伺服器上刪除資料。`DELETE` 方法用來刪除伺服器上的資源。

設定 `method: 'DELETE'` 並使用識別要移除資源的 URL。

## Promise 與 Promise 串鏈

- **Promises** 是表述非同步操作最終完成或失敗及其結果值的物件。只有在非同步操作完成後，才會知道 promise 的值。
- 這裡有一個創建簡單 promise 的範例：

```js
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```

- `.then()` 方法用於指定 Promise 成功時應該執行的動作，而 `.catch()` 用於處理發生的錯誤。

- **Promise 串鏈**：Promise 的強大功能之一是可以串接多個非同步操作。每個 `.then()` 都可以回傳一個新的 Promise，讓你依序執行一連串非同步操作。

`catch` 方法會處理過程中發生的任何錯誤。這表示你不需要在每個步驟都加上錯誤處理，能大幅簡化程式碼。

## 使用 `async/await` 處理 Promise

`async`/`await` 使撰寫和閱讀非同步程式碼更容易，它是建立在 Promises 之上的。

- **async**：`async` 關鍵字用來定義非同步函式。`async` 函式會回傳一個 Promise，該 Promise 會以 `async` 函式回傳的值來解析。
- **await**：`await` 關鍵字用在 `async` 函式內，用來暫停函式執行直到 Promise 解析完成。只能用在 `async` 函式內。

- `async/await` 最大的優點之一是可以透過 `try/catch` 區塊進行錯誤處理。以下是範例：

```js
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

fetchData();
```

在上面的範例中，`try` 區塊包含可能丟出錯誤的程式碼，而 `catch` 區塊則在發生錯誤時處理錯誤。這讓錯誤處理更直接且易讀。

## `async` 屬性

- `async` 屬性告訴瀏覽器在繼續解析 HTML 文件的同時非同步下載腳本檔案。
- 腳本下載完成後，HTML 解析會暫停，腳本會執行，然後 HTML 解析會繼續。
- 你應該為執行順序不重要的獨立腳本使用 `async`。

## `defer` 屬性

- `defer` 屬性也會非同步下載腳本，但會延緩腳本的執行直到 HTML 文件完全解析之後。
- `defer` 腳本維護它們在 HTML 文件中出現的執行順序。

- 請注意，`async` 和 `defer` 屬性對行內腳本無效，只適用於外部腳本檔案。

- 當 `async` 和 `defer` 屬性同時存在時，`async` 屬性優先。

## 地理位置 API

- Geolocation API 提供網站請求使用者位置的方法。

- 以下範例示範了 API 的 `getCurrentPosition()` 方法，用來取得使用者的當前位置。

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

在這段程式碼中，我們呼叫了 `getCurrentPosition` 並傳入一個函式，當成功取得位置時該函式會被呼叫。

`position` 物件包含多種資訊，但這裡我們只取用 `latitude` 和 `longitude`。

如果取得 `position` 時發生問題，錯誤將會記錄到主控台。

- 尊重使用者的隱私非常重要，且僅在必要時請求他們的位置。
