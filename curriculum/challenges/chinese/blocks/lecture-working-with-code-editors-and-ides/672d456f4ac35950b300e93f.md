# --description--

你可能已经熟悉一些基本的快捷键，这些快捷键是继承自你的操作系统的。像 <kbd>Ctrl</kbd> + <kbd>S</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>S</kbd>（macOS）用于储存，<kbd>Ctrl</kbd> + <kbd>C</kbd> 或 <kbd>Cmd</kbd> + <kbd>C</kbd> 用于拷贝，<kbd>Ctrl</kbd> + <kbd>V</kbd> 或 <kbd>Cmd</kbd> + <kbd>V</kbd> 用于粘贴，这些快捷键在 VS Code 中都适用。

但有一些快捷键是应用特定的，仍然可以提升你的生产力。值得注意的是，这些快捷键在不同操作系统上可能有所不同。

例如，<kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> 会在当前打开的文件上运行你配置的格式化工具（比如针对 JavaScript 项目的 Prettier）。

使用 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>（macOS）可以搜索工作区内所有文件的文本内容。如果你想执行查找和替换，可以使用 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd>（macOS）。

如果你需要删除一行，<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>（macOS）会帮你删除它。

需要为你的代码腾出更多空间吗？<kbd>Ctrl</kbd> + <kbd>B</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>B</kbd>（macOS）会隐藏侧边栏，侧边栏里有文件列表和扩展（程序、功能）菜单。

或者你看不清代码了？<kbd>Ctrl</kbd> + <kbd>Plus</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Plus</kbd>（macOS）会放大编辑器，<kbd>Ctrl</kbd> + <kbd>Minus</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Minus</kbd>（macOS）会缩小编辑器。

VS Code 另一个有用的特色是多行编辑，它允许你一次修改多行。例如，你可以通过 <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> 和 <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd>（Windows）、<kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> 和 <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd>（Linux）、或 <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Down</kbd> 和 <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Up</kbd>（macOS）放置多个光标，扩展光标到连续的行。你也可以按住 <kbd>Alt</kbd>（Windows/Linux）或 <kbd>Option</kbd>（macOS）并点击，在你需要的不同行添加光标。光标放置好后，你输入或删除的任何内容都会同时应用到所有这些位置，这在处理重复代码时能节省大量时间。

最后，如果你忘记了任何快捷键，你总可以使用 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（macOS）打开命令面板，选择你需要的任何命令。
