# --description--

El ordenamiento burbuja funciona al recorrer repetidamente una lista, comparando elementos adyacentes y cambiándolos de lugar si están desordenados. Después de cada pasada, el valor más grande sin ordenar "burbujea" hasta el final de la lista. El algoritmo se detiene cuando una pasada completa termina sin ningún intercambio.

El ordenamiento burbuja tiene una complejidad temporal cuadrática en los casos promedio y peor, por lo que rara vez se usa en la práctica.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

**Historias de usuario:**

1. Debes definir una función llamada `bubble_sort` con un parámetro que represente la lista de elementos.
1. Tu función `bubble_sort` debe ordenar la lista en el lugar de menor a mayor y devolverla.
1. Tu función `bubble_sort` debe seguir el algoritmo de ordenamiento burbuja, comparando elementos adyacentes y cambiándolos solo cuando el elemento de la izquierda sea mayor que el de la derecha.
1. Tu función `bubble_sort` debe detenerse tan pronto como una pasada por la lista termine sin ningún intercambio.
1. Tu función `bubble_sort` no debe usar ni el método integrado `sort()` ni la función `sorted()`.

**Nota:** No debes importar ningún módulo en tu código.

Tu función `bubble_sort` debe seguir el algoritmo de ordenamiento burbuja, intercambiando elementos adyacentes solo cuando el elemento de la izquierda sea mayor que el de la derecha.

```js
({
  test: () =>
    runPython(`
from collections import UserList

class CustomList(UserList):
    def __init__(self, *args, **kwargs):
        self._record = []
        super().__init__(*args, **kwargs)

    def __setitem__(self, key, value):
        self._record.append((key, value))
        super().__setitem__(key, value)

def expected_swaps(items):
    items = list(items)
    swaps = []
    swapped = True
    while swapped:
        swapped = False
        for j in range(len(items) - 1):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swaps.append({(j, items[j]), (j + 1, items[j + 1])})
                swapped = True
    return swaps

for values in ([33, 1, 89, 2, 67, 245], [4, 4, 2, 2, 1, 4, 3]):
    list_to_sort = CustomList(values)
    bubble_sort(list_to_sort)
    record = list_to_sort._record
    expected = expected_swaps(values)
    assert len(record) == 2 * len(expected)
    actual = [set(record[i:i + 2]) for i in range(0, len(record), 2)]
    assert actual == expected
    `)
});
```

```py
def bubble_sort(items):
    n = len(items)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swapped = True
        if not swapped:
            break
    return items
```
