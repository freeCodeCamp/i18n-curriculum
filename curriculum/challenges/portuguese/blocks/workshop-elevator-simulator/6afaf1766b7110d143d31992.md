# --description--

No momento, o elevador pula direto para cada andar. Um elevador real se move um andar de cada vez até alcançar seu alvo.

Depois de imprimir `target`, crie um `while` aninhado que execute enquanto `current_floor` for diferente de `target`. Dentro dele, use uma declaração `if` para verificar se `current_floor` é menor que `target`. Se for, aumente `current_floor` em `1`. Caso contrário, diminua `current_floor` em `1`.

Cada iteração move o elevador um andar mais perto do `target`, então `current_floor` eventualmente se torna igual a `target` e o loop aninhado para.
