# --description--

當主要版本號相等時，你需要比較次要版本號。如果次要版本號不同，這就是次要更新：較新的版本加入了仍可與舊版本相容的新功能。

切片一個 tuple 會得到一個新的 tuple，而 tuple 的比較會在第一組不同的元素處停止。舉例來說，`(2, 1) < (2, 2)` 是 `True`，因為第一個元素相等且 `1` 小於 `2`。

新增一個 `elif` 語句，檢查 `installed` 的前兩個元素切片是否小於 `latest` 的相同切片。如果是，將字串 `minor update` 指定給 `update_type`。
