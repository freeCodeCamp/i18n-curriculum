# --description--

<dfn>색상 모델</dfn>은 색상을 나타내는 체계입니다. 주요 색상 모델은 두 가지가 있는데, 전자 기기에서 사용하는 <dfn>가산</dfn> RGB 모델과 인쇄에서 사용하는 <dfn>감산</dfn> CMYK(시안, 마젠타, 노랑, 검정) 모델입니다.

이 프로젝트에서는 RGB 모델을 다룹니다. RGB는 빛의 기본 색상인 빨강, 초록, 파랑을 나타냅니다. 이 세 가지 색상이 다양한 농도로 결합되어 폭넓은 색상을 만듭니다. RGB에서는 색상이 검정에서 시작해 빨강, 초록, 파랑의 서로 다른 수준이 더해지면서 변합니다.

이를 확인하는 방법 중 하나는 CSS `rgb` 함수로, RGB 색상 모델을 사용해 색상을 정의할 수 있습니다.

클래스 `container`를 대상으로 하는 새로운 CSS 규칙을 만들고 `background-color`를 사용해 `rgb(0, 0, 0)`를 검정으로 설정하세요.
