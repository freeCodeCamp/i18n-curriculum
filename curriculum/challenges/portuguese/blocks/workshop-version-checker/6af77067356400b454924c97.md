# --description--

Quando os números major são iguais, você precisa comparar os números minor. Se os números minor forem diferentes, é uma atualização minor: a versão mais nova adiciona novos recursos que ainda funcionam com a versão antiga.

Fatiar uma tupla gera uma nova tupla, e a comparação de tuplas para na primeira dupla de elementos que diferem. Por exemplo, `(2, 1) < (2, 2)` é `True`, porque os primeiros elementos são iguais e `1` é menor que `2`.

Adicione uma cláusula `elif` que verifique se o slice de `installed` contendo seus dois primeiros elementos é menor que o mesmo slice de `latest`. Se for, atribua a string `minor update` a `update_type`.
