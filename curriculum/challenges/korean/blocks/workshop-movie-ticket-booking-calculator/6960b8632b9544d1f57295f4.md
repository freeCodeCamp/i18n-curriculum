# --description--

`18`세 이상이지만 `21`세 미만인 사용자는 `show_time`이 `Evening`이 아닐 때만 티켓을 예약할 수 있습니다.

부등 연산자(`!=`)는 두 값이 같지 않은지 확인합니다. 값이 다르면 `True`를, 같으면 `False`를 반환합니다:

```py
day = 'Monday'
print(day != 'Sunday') # True
print(day != 'Monday') # False
```

`and`와 `or`가 같은 표현식에 사용될 때, `and`가 `or`보다 우선순위가 높습니다. 즉, `and`로 연결된 조건들이 먼저 그룹화되고, 그 그룹의 결과가 `or` 조건과 결합됩니다:

```py
has_key = True
knows_code = False
is_daytime = False

print(has_key or knows_code and is_daytime) # True
```

위 예제에서 `knows_code and is_daytime`가 먼저 평가되어 결과는 `False`입니다. 전체 표현식은 `has_key or False`가 되어 `True`가 됩니다.

`if age >= 21:` 줄의 조건을 업데이트하세요. `and` 연산자를 사용해 `age`가 `18` 이상이고 `show_time`가 `Evening`가 아닌지 확인하는 표현식을 만드세요. 그런 다음 `or` 연산자를 사용해 그 표현식을 기존 조건과 결합하세요. 새 변수를 만들지 마세요.
