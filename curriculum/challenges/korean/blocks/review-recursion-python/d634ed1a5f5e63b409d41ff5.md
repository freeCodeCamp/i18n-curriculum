# --description--

- **재귀**: 함수가 자기 자신을 호출하는 기법입니다. 각 호출은 원래 문제의 더 작은 버전에서 작동하며, 더 이상의 재귀 호출을 멈추는 밑변에 도달할 때까지 계속됩니다.
- **밑변**: 재귀를 멈추는 조건입니다. 밑변을 신중하게 정의해야 합니다. 그렇지 않으면 함수가 계속 자기 자신을 호출하여 Python이 `RecursionError`를 발생시킬 수 있습니다.
- **재귀 케이스**: 함수가 밑변에 가까워지도록 인수(예: 카운트다운할 때 `number - 1`)와 함께 다시 함수를 호출하는 부분입니다.

```py
def recursive_countdown(number):
    if number < 1:  # Base case
        return
    print(number)
    recursive_countdown(number - 1)  # Recursive case

recursive_countdown(5)  # Prints 5, 4, 3, 2, 1
```

- **실행 순서**: 함수 내 다른 코드가 실행될 때 재귀 호출 위치가 달라집니다. 재귀 호출 전에 위치한 코드는 호출이 깊어질 때 실행되고, 호출 후에 위치한 코드는 호출이 반환될 때 실행됩니다. `print()`를 재귀 호출 뒤로 옮기면 함수가 숫자를 오름차순으로 출력합니다:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)  # Prints 1, 2, 3, 4, 5
```

- **호출 스택**: Python이 활성 함수 호출을 추적하는 데 사용하는 후입선출 자료 구조입니다. 함수가 호출될 때마다 Python은 해당 호출에 대한 프레임을 스택 맨 위에 추가합니다. 이 프레임에는 함수의 인수와 지역 변수 같은 정보가 포함됩니다.
- **호출 재개**: 호출은 재귀 호출을 할 때 일시 정지합니다. 밑변이 반환되면 Python은 스택 맨 위에서 해당 호출을 제거하고, 이전 호출들은 재귀 호출 이후에 다시 실행되어 후입선출 순서로 반환됩니다:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

출력은 다음과 같습니다:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

- **재귀적으로 리스트 만들기**: 각 호출은 재귀 호출이 반환될 때 재개되어 반환된 값을 사용합니다. 아래 `countup` 함수는 밑변에서 빈 리스트를 반환합니다. 다른 호출들은 재귀 호출로부터 리스트를 받아 자신의 숫자를 추가한 후 리스트를 반환합니다:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(5))  # [1, 2, 3, 4, 5]
```

`1`인 호출은 `[]`를 받아 `[1]`을 반환하고, `2`인 호출은 `[1]`을 받아 `[1, 2]`를 반환하며, 이런 식으로 `5`인 호출이 `[1, 2, 3, 4, 5]`를 반환할 때까지 계속됩니다.

- **재귀의 활용**: 재귀는 카운트다운, 카운트업, 리스트 만들기 같은 간단한 작업을 처리할 수 있습니다. 또한 파일 트리 탐색처럼 깊이를 알 수 없는 문제에도 유용합니다.
