# --description--

Hadi sasa, umeweza kutumia `re.search` kutafuta muundo mahali popote ndani ya mfuatano wa herufi. Moduli ya `re` ina vitendakazi vingine vingi vinavyofanya kazi na mifumo ya usemi wa kawaida. Katika funzo hili, utafundishwa kuhusu baadhi ya vitendakazi vinavyotumika zaidi.

## Kitendakazi cha `match`

Kitendakazi cha `match` hufanya kazi kama `search`, lakini kinatafuta muundo tu mwanzoni mwa mfuatano wa herufi. Hurejesha kitu cha mechi ikiwa mwanzo wa mfuatano unalingana na muundo, na `None` vinginevyo:

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

Katika mfano wa pili, mfuatano una tarakimu, hivyo `re.search` ingebaini. Lakini mfuatano hauanza na tarakimu, kwa hivyo `re.match` hurudisha `None`.

## Kitendakazi cha `fullmatch`

Muundo `r'\d+:\d+'` unalingana na tarakimu moja au zaidi, ikifuatiwa na nukta ya wima na tarakimu moja au zaidi. Huu ni muundo wa saa kama `10:30`.

Fikiria unataka kuthibitisha kuwa ingizo la mtumizi ni saa, na si kitu kingine chochote. Ukitumia `re.search`, utapata tatizo:

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

Hii hurudisha kitu cha mechi, ingawa `10:30pm` haifuati muundo uliotarajiwa. Hii ni kwa sababu `re.search` hutafuta muundo mahali popote ndani ya mfuatano, na husahau herufi za ziada zilizo karibu na mechi. `re.match` ingekuwa na tatizo sawa, kwa sababu `10:30pm` huanza na saa halali.

Unapothibitisha data, kawaida unataka mfuatano mzima ufuate muundo. Kwa hiyo, unaweza kutumia kitendakazi cha `fullmatch`. Hurejesha kitu cha mechi tu wakati muundo unalingana na mfuatano mzima, na `None` vinginevyo:

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## Kitendakazi cha `findall`

`search`, `match`, na `fullmatch` hukupa mechi moja tu angalau. Unapotaka kila mechi ndani ya mfuatano, unaweza kutumia kitendakazi cha `findall`. Hurejesha orodha ya mfuatano wa herufi yenye mechi zote anazopata:

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

Kama hakuna mechi, `findall` hurudisha orodha tupu:

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## Kitendakazi cha `sub`

Kitendakazi cha `sub` hubadilisha kila mechi ya muundo na mfuatano mwingine wa herufi. Kinachukua muundo, mfuatano wa herufi wa kubadilisha, na mfuatano wa kutafuta, na hurudisha mfuatano mpya:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub` pia ina vigezo viwili hiari. Kwanza ni `count`, kinachozuia ni mechi ngapi zitabadilishwa:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

Pili ni `flags`. Kama vitendakazi vingine, `sub` inaweza kutumia bendera kama `re.IGNORECASE`:

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

Daima pitia `count` na `flags` kama hoja za maneno muhimu. Ikiwa utapitia `re.IGNORECASE` kama hoja ya nne ya nafasi, Python itailipa kama thamani ya `count` badala yake.
