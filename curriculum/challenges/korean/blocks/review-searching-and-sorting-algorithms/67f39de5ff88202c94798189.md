## 검색 알고리즘

- **목적**: 검색 알고리즘은 항목 목록에서 목표를 찾을 수 있게 해줍니다.
- **검색 알고리즘의 종류**: 두 가지 일반적인 검색 알고리즘은 선형 검색과 이진 검색입니다. 이들의 차이를 이해하면 언제 각각을 사용해야 하는지 알 수 있습니다.

### 선형 검색

- **선형 검색 알고리즘**: 목록의 각 항목을 처음부터 끝까지 순차적으로 확인하며 목표를 찾습니다.
- **성공적인 검색**: 목표 항목을 찾으면 해당 항목이 위치한 인덱스를 반환합니다.
- **실패한 검색**: 강의 구현에서는 목표를 찾지 못했음을 나타내기 위해 `-1`을 반환합니다. Python에서 `-1`은 비어 있지 않은 목록의 마지막 요소를 가리키므로, 결과를 인덱스로 사용하기 전에 `-1`인지 확인하세요. 그렇지 않으면 실패한 검색이 마지막 요소를 잘못 가져올 수 있습니다.
- **효율성**: 선형 검색은 각 항목을 순차적으로 확인하기 때문에 큰 목록에서는 비효율적일 수 있습니다.
- **시간 복잡도**: 목록 크기에 따라 검색 시간이 선형적으로 증가하므로 `O(n)`입니다.
- **공간 복잡도**: 입력 크기와 상관없이 일정한 추가 공간만 사용하므로 `O(1)`입니다.

### 이진 검색

- **이진 검색 알고리즘**: 정렬된 리스트를 반복해서 반으로 나누어 목표 값을 찾는 효율적인 검색 알고리즘입니다.
- **정렬된 입력 전제 조건**: 이진 검색은 입력 리스트가 오름차순으로 정렬되어 있어야 합니다.
- **검색 범위 초기화**: 첫 번째 요소의 인덱스인 `low = 0`과 마지막 요소의 인덱스인 `high = len(arr) - 1`로 초기화하세요. 이 변수들은 검색하는 포함 범위를 정의합니다.
- **검색 지속 조건**: `low <= high`인 동안 검색을 계속하세요. `low > high`가 되면 검색 범위가 비어 목표를 찾지 못한 것입니다.
- **중간점 계산**: 정수 나눗셈을 사용해 중간 인덱스를 계산하세요: `mid = (low + high) // 2`.
- **목표 비교**: 목표 값과 `arr[mid]`를 비교하세요. 같으면 목표를 인덱스 `mid`에서 찾은 것입니다.
- **하한 업데이트**: `arr[mid] < target`이면 목표가 리스트에 존재한다면 오른쪽 절반에 있어야 합니다. 중간점과 그 이전 요소들을 제외하려면 `low = mid + 1`로 업데이트하세요.
- **상한 업데이트**: `arr[mid] > target`이면 목표가 리스트에 존재한다면 왼쪽 절반에 있어야 합니다. 중간점과 그 이후 요소들을 제외하려면 `high = mid - 1`로 업데이트하세요.
- **강의 성공 검색**: 강의 구현은 목표를 찾으면 그 인덱스를 반환합니다.
- **강의 실패 검색**: 강의 구현은 검색 범위가 비어지면 `-1`을 반환합니다.
- **워크숍 경로 추적**: 워크숍 구현은 빈 `path_to_target` 리스트를 초기화하고 검색 중 방문한 각 중간점의 값을 추가합니다.
- **워크숍 성공 검색**: 목표를 찾으면 워크숍은 `path_to_target`과 목표를 찾은 인덱스를 알리는 메시지를 포함하는 튜플을 반환합니다.
- **워크숍 실패 검색**: 검색 범위가 비어지면 워크숍은 빈 리스트와 `"Value not found"` 메시지를 반환합니다.
- **시간 복잡도**: 각 비교 후 검색 범위가 대략 절반으로 줄어들기 때문에 `O(log n)`입니다.
- **공간 복잡도**: 강의 구현은 `low`, `high`, `mid` 같은 변수에 대해 `O(1)` 보조 공간을 사용합니다. 워크숍 구현은 검색 중 방문한 중간점 값을 저장하는 `path_to_target` 때문에 `O(log n)` 보조 공간을 사용합니다.

### 선형 검색과 이진 검색의 차이점

- **전제 조건**: 선형 검색은 정렬된 목록이 필요 없지만, 이진 검색은 입력 데이터가 오름차순으로 정렬되어 있어야 합니다.
- **확장성**: 이진 검색은 선형 검색보다 큰 목록에 더 적합합니다.
- **시간 복잡도 비교**: 선형 검색은 `O(n)`이고, 이진 검색은 `O(log n)`입니다.

## 정렬 알고리즘과 분할 정복

- **분할 정복**: 문제를 더 작은 하위 문제로 나누어 해결하기 쉽게 만드는 기법입니다. 재귀를 사용해 구현하는 경우가 많으며, 병합 정렬 같은 효율적인 정렬 알고리즘에서 흔히 사용됩니다.

### 병합 정렬

- **병합 정렬 알고리즘**: 분할 정복 방식을 따르는 정렬 알고리즘입니다.
- **기본 사례**: 요소가 0개 또는 1개인 목록은 이미 정렬되어 있으므로 `len(array) <= 1`일 때 재귀가 멈춥니다.
- **목록 분할**: 목록을 두 개의 슬라이스된 절반으로 나누고 각각을 재귀적으로 정렬합니다.
- **하위 목록 병합**: 두 정렬된 절반의 다음 병합되지 않은 요소를 비교해 더 작은 요소를 다음 출력 위치에 복사하고 인덱스를 이동합니다. 한쪽 절반이 모두 소진되면 다른 절반의 남은 모든 요소를 복사합니다.
- **워크숍 구현**: 워크숍은 슬라이스된 절반을 만들고 병합된 값을 원래 목록에 다시 써서 `sorted_index`를 각 쓰기 후에 증가시킵니다. 원래 목록을 수정해도 슬라이스된 절반이 추가 저장소를 필요로 하므로 인플레이스 정렬 알고리즘은 아닙니다.
- **시간 복잡도**: 목록을 반복해서 반으로 나누어(`log n` 단계) 각 단계에서 요소 병합에 `O(n)` 시간이 걸려 `O(n log n)`입니다.
- **공간 복잡도**: 병합 정렬은 하위 목록 병합에 추가 메모리가 필요해 인플레이스 정렬이 아니므로 `O(n)`입니다.
