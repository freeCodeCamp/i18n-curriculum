# --description--

Come un `for` loop, un `while` loop può avere una clausola `else`. Il codice nella clausola `else` viene eseguito quando il loop termina normalmente, ma non quando il loop viene interrotto da `break`.

Aggiungi una clausola `else` al `while` loop esterno. Al suo interno, stampa la stringa `All requests served`.

C'è una richiesta di stop nella lista, quindi la clausola `else` non verrà eseguita per ora.

def run_elevator(requests, start_floor):
    current_floor = start_floor
    floors_traveled = 0

    while requests:
        target = requests.pop(0)

        if target == 'stop':
            print('Emergency stop!')
            break

        if target == current_floor:
            print(f'Already on floor {target}')
            continue

        while current_floor != target:
            if current_floor < target:
                current_floor += 1
            else:
                current_floor -= 1
            floors_traveled += 1

        print(f'Arrived at floor {current_floor}')
