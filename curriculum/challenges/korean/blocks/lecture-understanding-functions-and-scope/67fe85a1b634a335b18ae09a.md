# --description--

범위는 코드에서 변수를 어디에서 사용할 수 있는지 결정합니다.

Python에는 추가적인 범위 규칙이 있습니다. 지금은 지역 범위와 전역 범위에 집중하세요.

함수 밖에서 생성된 변수는 전역 범위를 가집니다. 함수 안팎 모두에서 사용할 수 있습니다.

함수 안에서 생성된 변수는 지역 범위를 가집니다. 그 함수 안에서만 사용할 수 있습니다. 함수 매개변수도 지역 변수입니다.

다음은 지역 범위와 전역 범위의 예입니다:

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

`tax_rate` 변수는 함수 밖에서 생성되었기 때문에 전역 변수입니다. `calculate_tax` 함수가 읽을 수 있고, 두 번째 `print()` 호출도 읽을 수 있습니다.

`price` 매개변수와 `tax` 변수는 `calculate_tax`에 지역적입니다. 그 함수가 실행되는 동안에만 사용할 수 있고, 함수 밖에서는 사용할 수 없습니다. 마지막 `print()` 호출은 `tax`가 전역 범위에 정의되어 있지 않아 `NameError`를 발생시킵니다.
