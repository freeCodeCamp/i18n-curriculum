# --description--

Ahora necesitas enlazar el archivo `styles.css`, para que los estilos se apliquen de nuevo.

El elemento `link` te permite enlazar recursos externos como hojas de estilo e íconos del sitio. Aquí está la sintaxis básica para usar el elemento `link` para enlazar un CSS externo:

```html
<link rel="stylesheet" href="styles.css" />
```

El atributo `rel` especifica la relación entre el recurso enlazado y el documento HTML. En este caso, necesitas especificar que este recurso enlazado es una `stylesheet`. El atributo `href` especifica la ubicación del recurso externo.

Dentro del elemento `head`, agrega un elemento `link`. Dale un atributo `rel` con el valor `"stylesheet"` y un atributo `href` con el valor `"styles.css"`.

**Nota:** El elemento `link` es un elemento vacío, lo que significa que no tiene etiqueta de cierre. Los elementos vacíos deben escribirse como `<element>` en lugar de `<element></element>`.
