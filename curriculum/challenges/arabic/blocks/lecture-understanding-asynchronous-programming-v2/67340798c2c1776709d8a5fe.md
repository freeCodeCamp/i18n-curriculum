# --description--

تلعب الخاصيتان `async` و`defer` في عناصر `script` بلغة HTML دورًا مهمًا في كيفية تحميل وتنفيذ ملفات JavaScript في صفحات الويب. فهمهما يحسن أداء موقعك وتجربة المستخدم. عند تضمين `script` في ملف HTML، يكون شكله كالتالي:

```js
<script src="example.js"></script>
```

عندما يجد المتصفح وسم `script` هذا، يتوقف عن تحليل HTML، يحمل السكريبت، ينفذه، ثم يستأنف تحليل HTML. هذا قد يبطئ تحميل صفحة الويب، خاصة إذا كانت السكريبتات كبيرة.

هنا يأتي دور الخاصيتين `async` و `defer`. توفران طرقًا لتحميل السكريبتات بشكل أكثر كفاءة.

لنبدأ بالخاصية `async`:

```js
<script src="example.js" async></script>
```

بإضافة الخاصية `async` إلى وسم `script`، يستمر المتصفح في تحليل HTML أثناء تحميل السكريبت. بمجرد اكتمال تحميل السكريبت، يوقف المتصفح تحليل HTML، ينفذ السكريبت، ثم يستأنف تحليل HTML. هذا يسرع تحميل الصفحة بشكل كبير.

من المهم ملاحظة أن السكربتات غير المتزامنة تُنفَّذ بمجرد تنزيلها، مما يعني أنها قد لا تعمل بالترتيب الصحيح الذي نرغب فيه. وهنا يأتي دور الخاصية `defer` للإنقاذ. لنلقِ نظرة على شكل الخاصية `defer`:

```js
<script src="example.js" defer></script>
```

خاصية `defer` تشبه خاصية `async`. مع ذلك، لا تُنفذ السكربتات التي تحمل خاصية defer فور تنزيلها. بل تنتظر حتى يكتمل تحليل HTML. بالإضافة إلى ذلك، تُنفذ السكربتات التي تحمل خاصية defer بالترتيب الذي تظهر به في كود HTML.

باختصار، استخدم `async` للسكريبتات التي لا يهم ترتيب تنفيذها، واستخدم `defer` عندما تحتاج إلى ضمان تنفيذ السكريبتات بالترتيب الصحيح. كلا الخاصيتين تحسنان أوقات تحميل الصفحة بشكل كبير بالسماح للمتصفح بمواصلة تحليل HTML أثناء تحميل السكريبتات في الخلفية.
