# --description--

لمعالجة أسماء الأقسام والقيم كمدخلات في مصفوفة، استخدم `Object.entries(rawData)`. تُرجع مصفوفة من أزواج `[key, value]` لخصائص الكائن القابلة للتعداد والتي تستخدم مفاتيح نصية خاصة به.

```js
const person = {
  name: "Alice",
  age: 30
};

console.log(Object.entries(person));
/*
Output: 
[ ["name", "Alice"], ["age", 30] ]
*/
```

أعلن عن متغير باسم `departmentEntries` وضعه مساويًا لـ `Object.entries(rawData)`.
ثم سجّل `departmentEntries` في وحدة التحكم لرؤية أزواج `[key, value]` التي أنتجها.
