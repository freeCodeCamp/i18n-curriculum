# --description--

시스템 언어와 키보드 설정이 Bash와 PostgreSQL 워크숍에 어떻게 영향을 미치는지 알아보세요.

많은 프로그래밍 도구는 명령어에 표준 영어 키보드 문자를 사용하기를 기대합니다. Bash와 PostgreSQL 워크숍에서는 특히 세미콜론(`;`), 따옴표, 슬래시, 그리고 기타 특수 문자가 중요합니다.

운영체제나 키보드 레이아웃이 비영어권 언어 설정을 사용하는 경우, 일부 문자가 예상과 다르게 동작할 수 있습니다. 이로 인해 SQL 명령어나 터미널 명령어 입력 시 혼란스러운 오류가 발생할 수 있습니다.

워크숍을 진행하는 동안 최상의 경험을 위해서는 코스를 완료하는 동안 일시적으로 영어(미국) 키보드 레이아웃으로 전환하는 것이 권장됩니다. 특히 Bash나 PostgreSQL 명령어에서 `;` 또는 `\` 같은 기호를 입력할 때 예상치 못한 문자나 구문 오류가 발생한다면 더욱 도움이 됩니다.

GitHub Codespaces는 로컬 키보드 레이아웃을 사용하므로, 컴퓨터에서 레이아웃을 변경하면 Codespaces 내 입력에도 영향을 미칩니다.

Windows에서:

1. **설정** > **시간 및 언어** > **언어 및 지역**을 엽니다
2. **English (United States)**가 설치되어 있지 않으면 추가하세요
3. 키보드 레이아웃에서 **US** 키보드를 선택하세요
4. 필요하면 US 키보드 레이아웃을 목록 맨 위로 이동하세요

macOS에서:

1. **시스템 설정** > **키보드** > **입력 소스**를 엽니다
2. **English (US)** 키보드 레이아웃을 추가하세요
3. US 레이아웃이 활성 키보드로 선택되어 있는지 확인하세요

Ubuntu, Debian, Mint 같은 Linux 배포판에서:

1. 시스템 키보드 설정을 엽니다
2. **English (US)** 키보드 레이아웃을 추가하세요
3. 가능하면 키보드 레이아웃 목록 맨 위로 이동하세요

일부 Linux 시스템은 터미널에서 키보드 레이아웃을 확인하고 변경할 수도 있습니다. 먼저 현재 레이아웃을 확인하세요:

```bash
setxkbmap -query
```

그런 다음 US 레이아웃으로 전환하세요:

```bash
setxkbmap us
```

레이아웃을 전환한 후 텍스트 상자나 터미널에서 다음 문자를 테스트하세요:

```md
; : / \ | ' " $ { } [ ] ( )
```

기호가 올바르게 표시되면 키보드 레이아웃이 제대로 설정된 것입니다.

일부 비영어권 레이아웃은 `'`와 `"` 같은 문자를 데드 키로 처리하여 즉시 입력하지 않고 다음 키 입력을 기다립니다. US 레이아웃으로 전환하면 이 문자들은 즉시 입력되어야 합니다. 만약 문자가 바로 나타나지 않는다면 레이아웃이 완전히 전환되지 않은 신호입니다.

AZERTY, QWERTZ, 또는 지역별 QWERTY 변형 같은 비-US 물리적 키보드 레이아웃을 사용하는 경우, 기호 키가 물리적으로 다른 위치에 있을 수 있습니다. 이 경우 운영체제의 화면 키보드나 키보드 뷰어를 사용해 US 레이아웃 전환 후 `;`, `/`, `\`, `|`, `'`, `"` 같은 키 위치를 확인하세요.

영어(미국) 키보드 레이아웃을 사용하면 워크숍 내내 Bash와 PostgreSQL 명령어가 정확히 예상대로 동작하도록 도와줍니다.

워크숍을 마친 후에는 원래 키보드 레이아웃으로 다시 전환할 수 있습니다.
