# --description--

Em Python, variáveis são nomes que se referem a objetos. Operadores de identidade verificam se dois operandos se referem ao mesmo objeto. O operador `is` retorna `True` se for o caso e `False` caso contrário. O operador `is not` retorna o resultado oposto.

Identidade é diferente de igualdade: `==` e `!=` comparam valores, enquanto `is` e `is not` comparam a identidade do objeto. Use operadores de igualdade ao comparar valores numéricos ou strings.

`None` representa a ausência de um valor. É o único valor do tipo de dado `NoneType`.

Três objetos que você pode verificar com operadores de identidade são `None`, `True` e `False`. Cada um é um singleton, ou seja, existe exatamente um objeto para cada um.

## Verificando `None`

Você pode usar `is None` para verificar se um valor está ausente, ou `is not None` para verificar se está presente:

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None` é considerado falso, mas não é o mesmo objeto que `False`. Por exemplo, uma resposta pode ser `True` para sim, `False` para não, ou `None` se nenhuma resposta foi dada:

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

Usar `if not response` em vez disso trataria `False` e `None` da mesma forma. A verificação de identidade distingue uma resposta negativa de uma resposta ausente.

## Verificando `True` e `False`

Você também pode usar identidade para verificar especificamente os objetos booleanos:

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

Essas verificações perguntam se `response` é exatamente `True`, `False` ou um objeto diferente de `None`. Elas não testam apenas a veracidade.

Para flags booleanas comuns, use testes diretos de verdade como `if is_ready` ou `if not is_ready`. Use `is True` ou `is False` quando precisar distinguir especificamente um objeto booleano de outros valores possíveis, como em uma resposta que também pode ser `None`.
