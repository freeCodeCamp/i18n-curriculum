# --description--

In questo workshop lavorerai con una directory intelligente del campus e creerai tabelle di ricerca da dati annidati.
Userai queste tabelle di ricerca per eseguire ricerche rapide ed efficienti. I `rawData` ti sono stati forniti.

Prenditi un momento per osservare la sua forma: ogni chiave è il nome di un dipartimento e il suo valore contiene un `Dept_code` insieme a
un array di `programs`. Ogni programma contiene poi il proprio array di `instructors`.

Per cominciare, registra `rawData` nella console così potrai ispezionare questa struttura annidata prima di lavorarci.

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, "log");
const getLogs = () => globalThis.spy.calls.map(call => call?.[0]);
```

# --after-each--

```js
globalThis.spy.restore();
delete globalThis.spy;
```

# --hints--

Dovresti registrare il `rawData` nella console.

```js
assert.include(getLogs(), rawData);
```
