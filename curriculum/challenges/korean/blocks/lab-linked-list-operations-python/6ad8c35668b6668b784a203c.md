이번 실습에서는 이전 워크숍에서 만든 `LinkedList` 클래스를 기반으로 연결 리스트 자료 구조에 추가 연산을 구현할 것입니다.

**목표:** 아래 사용자 스토리를 충족하고 모든 테스트를 통과하여 실습을 완료하세요.

**사용자 스토리:**

1. `LinkedList` 클래스에는 요소를 인수로 받는 `contains` 메서드가 있어야 합니다. 이 메서드는 요소가 연결 리스트에 존재하면 `True`를, 그렇지 않으면 `False`를 반환해야 합니다.
1. `LinkedList` 클래스에는 인덱스를 인수로 받는 `get_at` 메서드가 있어야 합니다. 이 메서드는 주어진 인덱스에 있는 요소를 반환해야 합니다. 인덱스가 범위를 벗어나면 `None`을 반환해야 합니다.
1. `LinkedList` 클래스에는 인덱스와 요소를 인수로 받는 `insert_at` 메서드가 있어야 합니다. 이 메서드는 주어진 위치에 요소를 삽입하고 `length` 속성을 업데이트해야 합니다. 인덱스가 리스트 길이와 같으면 유효하며 요소를 리스트 끝에 추가해야 합니다. 인덱스가 범위를 벗어나면 리스트를 수정하지 않아야 합니다.
1. `LinkedList` 클래스에는 인덱스를 인수로 받는 `remove_at` 메서드가 있어야 합니다. 이 메서드는 주어진 인덱스에 있는 노드를 제거하고 `length` 속성을 업데이트해야 합니다. 인덱스가 범위를 벗어나면 리스트를 수정하지 않아야 합니다.
1. `LinkedList` 클래스에는 모든 요소를 제거하고 `head`를 `None`으로, `length`를 `0`으로 초기화하는 `clear` 메서드가 있어야 합니다.

**참고:** 이후 테스트 중 일부는 이전 메서드에 의존합니다. 예를 들어 `get_at`이 제대로 구현되지 않으면 `insert_at`과 `remove_at` 같은 메서드 테스트가 거의 맞게 구현되어도 실패할 수 있습니다.

```py
class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
```
