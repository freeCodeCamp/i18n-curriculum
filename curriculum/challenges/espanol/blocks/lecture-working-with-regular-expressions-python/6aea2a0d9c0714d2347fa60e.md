# --description--

Hasta ahora, has usado `re.search` para buscar un patrón en cualquier parte de una cadena. El módulo `re` tiene muchas otras funciones que trabajan con patrones regex. En esta lección, aprenderás sobre algunas de las más útiles.

## La función `match`

La función `match` funciona como `search`, pero solo busca el patrón al inicio de la cadena. Devuelve un objeto match si el comienzo de la cadena coincide con el patrón, y `None` en caso contrario:

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

En el segundo ejemplo, la cadena contiene dígitos, así que `re.search` los encontraría. Pero la cadena no empieza con dígitos, por eso `re.match` devuelve `None`.

## La función `fullmatch`

El patrón `r'\d+:\d+'` coincide con uno o más dígitos, seguido de dos puntos y uno o más dígitos. Esta es la forma de una hora como `10:30`.

Imagina que quieres verificar que una entrada del usuario sea una hora, y nada más. Si usas `re.search`, encontrarás un problema:

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

Esto devuelve un objeto match, aunque `10:30pm` no sigue el formato esperado. Eso es porque `re.search` busca el patrón en cualquier parte de la cadena e ignora cualquier carácter extra alrededor de la coincidencia. `re.match` tendría el mismo problema, porque `10:30pm` empieza con una hora válida.

Cuando validas datos, usualmente quieres que toda la cadena siga el patrón. Para eso, puedes usar la función `fullmatch`. Devuelve un objeto match solo cuando el patrón coincide con toda la cadena, y `None` en caso contrario:

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## La función `findall`

`search`, `match` y `fullmatch` te dan como máximo una coincidencia. Cuando quieres todas las coincidencias en una cadena, puedes usar la función `findall`. Devuelve una lista de cadenas con todas las coincidencias que encuentra:

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

Si no hay coincidencias, `findall` devuelve una lista vacía:

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## La función `sub`

La función `sub` reemplaza cada coincidencia de un patrón con otra cadena. Toma el patrón, la cadena de reemplazo y la cadena donde buscar, y devuelve una nueva cadena:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub` también tiene dos parámetros opcionales. El primero es `count`, que limita cuántas coincidencias se reemplazan:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

El segundo es `flags`. Como las otras funciones, `sub` puede usar banderas como `re.IGNORECASE`:

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

Siempre pasa `count` y `flags` como argumentos con nombre. Si pasas `re.IGNORECASE` como cuarto argumento posicional, Python lo tratará como el valor de `count` en su lugar.
