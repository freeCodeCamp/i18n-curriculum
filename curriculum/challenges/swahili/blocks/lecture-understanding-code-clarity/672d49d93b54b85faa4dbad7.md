# --description--

Kama vile nukta (`.`) inaweza kuashiria mwisho wa sentensi katika Kiingereza, nusu nukta (`;`) inaweza kutumika kuashiria mwisho wa tamko katika JavaScript. Hata hivyo, tamko si lazima lifanane na mistari ya msimbo wa chanzo. Tamko linaweza kuenea kwenye mistari mingi, na mstari mmoja unaweza kuwa na tamko zaidi ya moja.

Kwa mfano:

```js
let variableOne = 5;
let variableTwo = 10;
```

Katika msimbo huu, nusu nukta zinafanya mwisho wa kila tamko kuwa wazi. JavaScript pia ina Automatic Semicolon Insertion (ASI), ambayo inaruhusu tamko hizi kubaki halali bila nusu nukta wazi:

```js
let variableOne = 5
let variableTwo = 10
```

Katika mfano huu, ASI inaruhusu JavaScript kutambua kila tamko kama tamko tofauti ingawa hakuna nusu nukta. Hata hivyo, ASI haisi tu kuweka nusu nukta baada ya kila kuvunjika kwa mstari.

Kwa mfano, kuvunjika kwa mstari baada ya tamko la `return` kunaweza kusababisha tabia isiyotarajiwa:

```js
function getValue() {
  return
  {
    value: 42
  };
}
```

Hapa, ASI inaweka nusu nukta baada ya `return`, hivyo kitendakazi kinarejesha `undefined` badala ya kitu hicho. Kuandika kitu hicho kwenye mstari mmoja kunazuia tabia hii:

```js
function getValue() {
  return {
    value: 42
  };
}
```

Hii inaonyesha kwanini kuvunjika kwa mistari na mipaka ya tamko si mara zote vitu sawa.

Nusu nukta pia zinaweza kuwa muhimu wakati kuvunjika kwa mstari kunaweza kuruhusu vipande viwili vya msimbo kufasiriwa kama usemi wa kihesabu mmoja. Kitendakazi kinachoendeshwa mara moja (immediately invoked function expression - IIFE) ni kitendakazi kinachoendeshwa mara tu kinapofafanuliwa. Njia moja ya kuunda IIFE ni kuzungusha kitendakazi kisicho na jina (anonymous function) ndani ya mabano ya kawaida na kuongeza `()` mwishoni kuitisha. IIFE inaweza kusababisha tatizo wakati tamko lililotangulia halimalizwi na nusu nukta:

```js
const message = "Hello"

(function () {
  console.log(message);
})()
```

Hapa, JavaScript haiongezi nusu nukta baada ya tamko la mfuatano wa herufi kwa sababu `(` inayofuata inaweza kuendelea na usemi wa kuanzisha. JavaScript inachanganuzi usemi wa kuanzisha kama wito kwa mfuatano wa herufi `"Hello"`, na usemi wa kitendakazi kama hoja. Hii hutupa `TypeError` kabla ya IIFE kuweza kuendeshwa. Kuongeza nusu nukta kunamaliza tamko kabla ya IIFE:

```js
const message = "Hello";

(function () {
  console.log(message);
})()
```

Nusu nukta wazi huweka tamko la kigezo na IIFE kama tamko tofauti.

Nusu nukta hutumika katika lugha nyingi za programu, ikiwa ni pamoja na C, C++, na Java. Sheria zao halisi zinatofautiana kati ya lugha, lakini kwa kawaida husaidia kuonyesha mahali tamko linamalizika.

Kibadilishaji (compiler) hubadilisha msimbo wa chanzo kuwa aina nyingine, kama msimbo wa mashine, bytecode, au uwakilishi wa kati, kulingana na lugha na kibadilishaji. Ubadilishaji hauwezi lazima uzalishe faili huru inayoweza kuendeshwa.

Kutumia nusu nukta kwa uthabiti kunaweza kufanya mipaka ya tamko kuwa wazi zaidi na kufanya msimbo uwe rahisi kusoma na kudumisha.
