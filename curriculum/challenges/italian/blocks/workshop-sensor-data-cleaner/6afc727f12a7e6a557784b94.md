# --description--

Per ottenere un'etichetta per ogni differenza, ti serve un'espressione condizionale prima di `for` invece di un `if` finale:

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

Rimuovi l'`if` finale dalla tua list comprehension. Poi, cambia l'espressione prima di `for` in un'espressione condizionale che valuti a `f'+{difference} °C'` se `difference` è maggiore di `0`, e a `f'{difference} °C'` altrimenti. I numeri negativi hanno già il segno `-`, quindi serve solo l'unità.
