## تثبيت Python في بيئة العمل المحلية

- **التثبيت**: أسهل طريقة لتثبيت Python على Windows وmacOS هي تنزيل المثبّت من الموقع الرسمي لـ Python (`https://www.python.org/`). على Linux، معظم التوزيعات الرئيسية مثل Ubuntu وDebian وFedora تتضمن Python بالفعل، لذا تحقق من الإصدار المثبت أولاً ولا تثبت حزمة خاصة بالتوزيعة إلا إذا كان Python 3 مفقودًا.
- **الإعداد على macOS**: نزّل وافتح المثبّت `.pkg` واتبع التعليمات. عند الانتهاء، انقر نقرًا مزدوجًا على ملف `Install Certificates.command` ودع عملية الطرفية تكتمل لإنهاء الإعداد.
- **الإعداد على Windows**: نزّل وشغّل مدير تثبيت Python `.msix`. بعد ذلك، تصبح أوامر `python` و`py` و`pymanager` متاحة، وتشغيل `python` بدون وجود بيئة تشغيل مثبتة سيقوم بتثبيتها تلقائيًا، ويمكنك قبول المطالبة الاختيارية لإضافة دليل الأسماء المستعارة (لأوامر مثل `python3.14.exe`) إلى متغير `PATH`.
- **الإعداد على Linux**: افتح الطرفية وشغّل `python --version` أو `python3 --version`. إذا لم يعرض أي منهما إصدار Python 3، ابحث عن حزمة تثبيت في `https://www.python.org/` أو ابحث عبر الإنترنت عن الطريقة الموصى بها لتثبيت Python لتوزيعتك.

## التحقق من التثبيت

- **التحقق من الإصدار**: أكد التثبيت بتشغيل `python --version` أو `python3 --version` في الطرفية.
- **`python` مقابل `python3`**: في بعض أنظمة macOS وLinux القديمة، قد يشير `python` إلى Python 2. إذا أظهر `python --version` إصدار Python 2، استخدم `python3` في كودك من تلك اللحظة. Python 2 انتهى دعمه ولا يجب استخدامه في التطوير الجديد.

## الطرفية

- **التعريف**: الطرفية هي واجهة نصية تتيح لك التفاعل مع الكمبيوتر بكتابة الأوامر. كل نظام تشغيل يأتي مع تطبيق طرفية افتراضي. على macOS، يمكنك استخدام تطبيق Terminal. على Windows، يمكنك استخدام Command Prompt أو PowerShell. على Linux، لكل بيئة سطح مكتب تطبيق طرفية افتراضي خاص بها، مثل GNOME Terminal أو Konsole.

## محررات الكود وبيئات التطوير المتكاملة

- **IDE**: IDE تعني بيئة تطوير متكاملة، وتحتوي على ميزات تشمل محرر كود، أدوات اختبار، طرفية، والمزيد.
- **محررات الكود وبيئات التطوير المتكاملة الشهيرة لـ Python**: VS Code، PyCharm، وSpyder.

## تشغيل سكريبتات Python

- **إعداد المحرر**: افتح مجلد مشروعك في VS Code وأنشئ ملف `.py`. ثبّت امتداد Python من Microsoft من عرض الامتدادات أو بتشغيل `code --install-extension ms-python.python` (على macOS، يجب إضافة أمر `code` إلى متغير `PATH` أولاً). يضيف الامتداد دعم Python للمحرر لكنه لا يثبت Python نفسه.
- **اختيار المفسر**: شغّل الأمر `Python: Select Interpreter` من لوحة الأوامر لتوجيه المحرر إلى مفسر Python 3 الذي ثبتّه سابقًا.
- **تشغيل الكود**: انقر على زر التشغيل (رمز التشغيل في الزاوية العليا اليمنى من VS Code) لتشغيل الملف الحالي في الطرفية. يمكنك أيضًا تشغيل سكريبت يدويًا من الطرفية. على سبيل المثال، إذا كان مجلد مشروعك `python-projects` والسكريبت هو `main.py`، افتح طرفية في المجلد الذي يحتوي على `python-projects`، ثم انتقل إلى مجلد المشروع وشغّل السكريبت:

```bash
cd python-projects
python main.py
```

استخدم `python3 main.py` بدلاً من ذلك إذا كان `python3` هو الأمر الذي يعرض إصدار Python 3 على نظامك.

## استخدام القشرة التفاعلية لـ Python

- **بدء القشرة التفاعلية**: افتح طرفية وشغّل `python` أو `python3` (استخدم الأمر الذي عرض إصدار Python 3). يعني موجه `>>>` أن Python ينتظر أمرًا. جرّب طباعة `"Hello, world!"`:

```python
print("Hello, world!")
```

- **دورة القراءة، التقييم، الطباعة، التكرار (REPL)**: يقرأ المفسر مُدخلك، يقيمه، يطبع النتيجة، ثم يعود إلى موجه `>>>` لتتمكن من كتابة أمر آخر.
- **المدخلات غير الصالحة**: إدخال شيء غير صالح في Python، مثل `something random`، ينتج رسالة `SyntaxError: invalid syntax`، وتعود القشرة إلى الموجه.
- **الخروج من القشرة**: اكتب `exit()`، اضغط <kbd>Ctrl</kbd> + <kbd>D</kbd> على macOS أو Linux، أو اضغط <kbd>Ctrl</kbd> + <kbd>Z</kbd> ثم <kbd>Enter</kbd> على Windows.
- **متى تستخدمها**: القشرة التفاعلية مناسبة للتجارب الصغيرة والاستكشاف السريع. للبرامج الأطول أو العمل عبر ملفات متعددة، استخدم محرر كود أو IDE.
