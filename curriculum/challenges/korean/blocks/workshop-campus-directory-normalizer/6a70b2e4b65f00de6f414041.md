# --description--

각 부서에는 중첩된 `programs` 배열이 있습니다. 기존 반복문 안에 두 번째 `for` 반복문을 추가하여 `j = 0`부터 `departmentData.programs.length`까지 `departmentData.programs`를 순회하세요.

이 새 반복문 안에서 `program`이라는 변수를 선언하고 `departmentData.programs[j]`로 설정한 뒤, 이를 콘솔에 출력하세요.

코드에서 `console.log(departmentsById[departmentId])` 줄도 삭제하세요.
