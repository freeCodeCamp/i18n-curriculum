# --description--

Ora mostra anche i timestamp nell'elenco delle email. Aggiorna il metodo `__str__` per aggiungere ` | Time: ` seguito dal timestamp, formattato come `'%Y-%m-%d %H:%M'`, dopo l'oggetto:

```md
[status] From: sender | Subject: subject | Time: time
```

Per mantenere allineata la colonna `Time`, allinea a sinistra l'oggetto con una larghezza di `15`. La larghezza è solo un minimo, quindi un oggetto più lungo verrà comunque stampato per intero e spingerà `Time` fuori allineamento. Prima di formattare, taglia l'oggetto ai suoi primi `15` caratteri per evitare questo.

Per esempio, un'email con un oggetto corto e una con un oggetto lungo sarebbero:

```md
[Unread] From: Alice      | Subject: Hello           | Time: 2025-01-15 09:30
[Unread] From: Alice      | Subject: Quarterly budge | Time: 2025-01-15 09:30
```

import datetime

class Email:
    def __init__(self, sender, receiver, subject, body):

        self.receiver = receiver
        self.subject = subject

        print(f"{'Body:':<10}{self.body}")
        print(f"{'':-^29}\n")

    def __str__(self):
        status = 'Read' if self.read else 'Unread'

class User:

    def send_email(self, receiver, subject, body):

class Inbox:

        self.emails.append(email)

        if not self.emails:
            print('Your inbox is empty.\n')
            return
        print('\nYour Emails:')

            print('Invalid email number.\n')

        if not self.emails:
            print('Inbox is empty.\n')
            return
        actual_index = index - 1

            print('Invalid email number.\n')
            return
