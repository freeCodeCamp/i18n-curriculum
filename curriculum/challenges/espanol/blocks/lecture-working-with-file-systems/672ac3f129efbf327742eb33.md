# --description--

Aprendamos cómo buscar archivos y carpetas en Windows y macOS.

Comenzaremos con Windows. Puedes buscar desde la barra de tareas o desde el Explorador de archivos.

Para buscar desde la barra de tareas, escribe el nombre del archivo o carpeta que estás buscando. También puedes buscar por palabras clave. Verás resultados de todo tu PC y de OneDrive.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-1.png" alt="Windows 11 taskbar with Start button, search bar, Task View, and Chrome icon">

Si solo quieres ver documentos, puedes hacer clic en la pestaña "Documentos". También tienes pestañas para aplicaciones y resultados web.

Otra alternativa es usar el Explorador de archivos de búsqueda. Lo encontrarás en la parte superior derecha de la ventana del Explorador, donde puedes ver "Buscar documentos".

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-2.png" alt="Windows File Explorer with the Search Documents box highlighted on the top right">

Tienes tres opciones para definir el alcance de la búsqueda:

- Puedes buscar desde Inicio para encontrar archivos de tu PC y de la nube rápidamente.

- Puedes buscar desde una carpeta para encontrar archivos almacenados dentro de ella.

- Puedes buscar desde Este PC para una búsqueda lenta pero en profundidad.

Así es como puedes buscar archivos y carpetas en Windows. Ahora veamos cómo puedes hacerlo en macOS.

Primero, puedes usar Spotlight, una herramienta que te ayuda a encontrar archivos en tu Mac. Para abrir Spotlight, ve a la barra de menú en la parte superior derecha y busca la lupa.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-3.png" alt="macOS menu bar featuring system icons including the magnifying glass Spotlight icon">

Si no ves este ícono en la barra de menú, puedes agregarlo en la configuración del Control Center.

Ve a tu configuración, filtra por "Control Center", haz clic en esta opción y luego desplázate hacia abajo hasta encontrar la opción "Spotlight".

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-4.png" alt="macOS Control Center settings window showing Spotlight set to Show in Menu Bar">

También puedes usar un atajo de teclado para abrir Spotlight: <kbd>Command</kbd> + <kbd>Spacebar</kbd>.

Cuando abres Spotlight, verás la búsqueda de Spotlight, donde puedes buscar cualquier archivo o carpeta escribiendo su nombre.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-5.png" alt="macOS Spotlight Search bar open on screen">

Cuando empiezas a escribir, verás los resultados agrupados por categoría, incluyendo sugerencias, carpetas, presentaciones, fotos, documentos y búsquedas relacionadas.

También puedes expandir una categoría específica haciendo clic en "Mostrar más".

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-6.png" alt="macOS Spotlight Search displaying search results for freeCodeCamp">

Otra forma de buscar archivos que has abierto recientemente es abrir Finder haciendo clic en el ícono de Finder en el Dock.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-7.png" alt="macOS Dock featuring the blue Finder icon alongside Launchpad and Google Chrome icons">

Luego, ve a "Recientes" en la barra lateral de Finder.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-8.png" alt="macOS Finder sidebar with the Recents option highlighted under Favorites">

Y allí encontrarás todos los archivos que has visto recientemente.

Así es cómo puedes buscar archivos y carpetas en macOS. Con estas herramientas de búsqueda, puedes optimizar tu flujo de trabajo y encontrar los archivos y carpetas que necesitas muy rápidamente.
