# --description--

У цій лабораторній роботі ви реалізуєте структуру даних стек за допомогою функцій. Стек — це структура даних типу «останній зайшов — перший вийшов» (LIFO), де елементи додаються та видаляються з вершини.

Ваш стек буде словником, у якому ключ `collection` містить список елементів. Верхівка стеку — це кінець списку, тому останній елемент у списку — це найновіший доданий.

**Мета:** Виконайте наведені нижче історії користувача та пройдіть усі тести, щоб завершити лабораторну роботу.

**Історія користувача:**

1. Ви повинні мати функцію `init_stack`, яка повертає словник із ключем `collection`, встановленим у порожній список.
1. Ви повинні мати функцію `push`, яка приймає стек і елемент, і додає цей елемент на верхівку стеку.
1. Ви повинні мати функцію `pop`, яка приймає стек, видаляє і повертає його верхній елемент, або повертає `None`, якщо стек порожній.
1. Ви повинні мати функцію `peek`, яка приймає стек і повертає його верхній елемент без видалення, або повертає `None`, якщо стек порожній.
1. Ви повинні мати функцію `is_empty`, яка приймає стек і повертає `True`, якщо він не містить елементів, і `False` в іншому випадку.
1. Ви повинні мати функцію `clear`, яка приймає стек і видаляє всі його елементи.

**Примітка:** Більшість тестів залежать від функцій `init_stack` і `push`. Реалізуйте їх першими, оскільки тести для `pop`, `peek`, `is_empty` і `clear` вимагають додавання елементів у стек.

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
