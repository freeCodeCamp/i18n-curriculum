# --description--

Neste workshop, você praticará trabalhar com tabelas HTML construindo uma tabela de exame final para um grupo de estudantes.

O elemento `table` permite exibir dados tabulares. Dados tabulares são informações organizadas em linhas e colunas, como em uma planilha.

Dentro do seu elemento `body`, aninhe um elemento `table`. Nos próximos passos, você vai adicionar linhas, títulos e dados à sua tabela.

# --hints--

Você deve ter uma tag de abertura de `table`.

```js
assert.match(code, /<table>/i);
```

Você deve ter uma tag de fechamento de `table`.

```js
assert.match(code, /<\/table>/i);
```

O elemento `table` deve estar dentro do elemento `body`.

```js
const tableEl = document.querySelector('table');
assert.strictEqual(tableEl?.parentElement?.tagName, 'BODY');
```
