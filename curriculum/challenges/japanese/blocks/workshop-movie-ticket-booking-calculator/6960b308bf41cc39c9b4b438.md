# --description--

`or`演算子は、2つの条件のうち少なくとも1つが真かどうかを確認するために使います。`if`文の比較での使い方は次の通りです：

```py
day = 'Sunday'
is_raining = False

if day == 'Sunday' or is_raining:
    print('Stay at home')
```

上の例では、`is_raining`が`False`でも最初の条件が真なので、`Stay at home`が出力されます。

週末にも追加料金が適用されるべきです。`if show_time == 'Evening':`の条件を、`or`演算子を使って既存の条件と`is_weekend`が真かどうかを確認する2つ目の条件を組み合わせるように更新してください。
