# --description--

Katika mafundisho yaliyopita, umekuwa ukitengeneza kitendakazi kwa kutumia neno kuu `def` kama hii:

```py
def square(num):
    return num ** 2

print(square(4)) # 16
```

Katika funzo lililopita, ulipeleka vitendakazi kama `is_long_word` na `to_fahrenheit` kwa `map()` na `filter()`. Kitendakazi kinachokubali kitendakazi kingine kama hoja huitwa kitendakazi ya daraja la juu. Kueleza kitendakazi tofauti kwa kutumia `def` kila wakati unapotaka kupeleka kitendakazi kifupi kwa kitendakazi ya daraja la juu kunaweza kuwa na maneno mengi. Badala yake, unaweza kuandika kitendakazi cha lambda, ambacho ni kitendakazi kisicho na jina, moja kwa moja mahali unaponahitaji.

Sintaksia ya kitendakazi cha lambda inaonekana hivi:

```py
lambda parameters: expression
```

Baada ya neno kuu `lambda`, unaorodhesha vigezo vya kitendakazi. Nukta inatenganisha vigezo na usemi wa kihesabu mmoja, na matokeo ya usemi huo hurudishwa moja kwa moja, bila haja ya tamko la `return`.

Hivi ndivyo kitendakazi cha `square()` kinavyoonekana kinapobadilishwa kuwa kitendakazi cha lambda:

```py
lambda num: num ** 2
```

Hapa, `num` ni kigezo, na `num ** 2` ni usemi wa kihesabu ambao matokeo yake hurudishwa. Kama ilivyotajwa awali, vitendakazi vya lambda havina majina, kwa hivyo kitendakazi hiki hakina tena jina `square` linalohusishwa nacho.

Kitendakazi cha lambda pia kinaweza kuwa na vigezo zaidi ya kimoja. Kama ilivyo kwa vitendakazi vilivyoelezwa kwa `def`, unagawa vigezo kwa kutumia koma:

```py
lambda a, b: a + b
```

Kitendakazi hiki cha lambda kinachukua vigezo viwili, `a` na `b`, na hurudisha jumla yao.

Vitendakazi vya lambda ni vizuri wakati unahitaji kuvipeleka kwa vitendakazi vya daraja la juu kama hivi:

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

Katika mfano huu, tuna orodha ya nambari na tunataka kuunda orodha mpya ya nambari za hata. Kwa hivyo tunapeleka kitendakazi cha lambda kama moja ya hoja kwa kitendakazi cha `filter()`. Kitendakazi cha `filter()` hufanya wito kwa kitendakazi cha lambda kwa kila nambari, na kuhifadhi tu nambari ambazo `x % 2 == 0` ni `True`. Kisha `list()` hukusanya nambari hizo katika orodha mpya yenye nambari `2` na `4`.

Unapofanya kazi na kitendakazi za lambda ni muhimu kuwa na ufahamu wa mbinu bora. Kwa mfano, si mbinu nzuri kuweka kitendakazi cha lambda kwenye kigezo kama hiki:

```py
numbers = [1, 2, 3, 4, 5]

square = lambda x: x ** 2
squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Hii inavunja madhumuni ya kutumia kitendakazi kisicho na jina. Katika kesi hii, unapaswa kutumia kitendakazi cha kawaida, kama hiki:

```py
numbers = [1, 2, 3, 4, 5]

def square(num):
    return num ** 2

squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Pia, unapaswa kuepuka kuunda kitendakazi za lambda ambazo ni ngumu kusoma au tata bila sababu, kama hiki:

```py
result = (lambda x: (x**2 + 2*x - 1) if x > 0 else (x**3 - x + 4))(3)
print(result)  # 14
```

Ingawa kitendakazi hiki kinafanya kazi vizuri na kinatoa matokeo sahihi ya `14`, si rahisi kusoma au kuangalia. Katika kesi hii, itakuwa bora kuunda kitendakazi tofauti chenye tamko la `if/else`, kisha kuita kitendakazi hicho:

```py
def calculate_expression(x):
    if x > 0:
        return x**2 + 2*x - 1
    else:
        return x**3 - x + 4

print(calculate_expression(3))  # 14
```

Zote kitendakazi za kawaida na kitendakazi cha lambda zina matumizi yao katika programu za Python. Ikiwa unashughulika na usemi wa kihesabu mmoja ndani ya mstari, basi unaweza kuzingatia kutumia kitendakazi cha lambda. Vinginevyo, kutumia kitendakazi cha kawaida ndicho kinachopaswa kufanywa.
