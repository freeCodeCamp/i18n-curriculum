# --description--

Jambo la mwisho la kufanya ni kusahisha hali ya `isOpen` wakati kitufe cha `Apps` kinapobofyanwa.

Katika React, unajibu matukio kwa kupitisha kitendakazi kwa sifa ya tukio kwenye kipengele. Sifa hizi zinaandikwa kwa camelCase, kwa hivyo bofya hutendewa na `onClick`:

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

Tambua kwamba `onClick` hupokea kitendakazi. React huwita kitendakazi hicho kila wakati kitufe kinapobofyanwa. Kufanya wito kwa kitendakazi cha kuweka thamani na thamani mpya husasisha hali, na React kisha huonyesha tena sehemu hiyo kwa thamani hiyo mpya.

Ili kubadilisha hali ya thamani ya kweli au siyo kweli kati ya `true` na `false`, unaweza kupitisha kinyume cha thamani yake ya sasa kwa kitendakazi cha kuweka thamani kwa kutumia kielezi cha mantiki cha NOT (`!`).

Ongeza sifa ya `onClick` kwenye kipengele cha `button`. Ipe kitendakazi cha mshale kinachofanya wito wa `setIsOpen` kwa kinyume cha `isOpen`.

Bofya kitufe cha `Apps` kufungua na kufunga `sub-menu`.

Kwa hivyo, sehemu yako ya `Navbar` imekamilika!

# --hints--

Kubofya kitufe cha `Apps` kunapaswa kuweka sifa yake ya `aria-expanded` kuwa `"true"` na kuongeza darasa la `sub-menu--open` kwenye `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

Kubofya kitufe cha `Apps` mara ya pili kunapaswa kuweka sifa yake ya `aria-expanded` kurudi kuwa `"false"` na kuondoa darasa la `sub-menu--open` kutoka kwenye `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
