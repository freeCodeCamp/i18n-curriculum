# --description--

Die rekursiven Aufrufe gehen den Baum jeweils eine Ebene hinunter, aber sie brauchen einen Punkt, an dem sie stoppen. Es gibt zwei Fälle:

- `node.key` ist gleich `key`: Sie haben den Knoten mit dem gesuchten Wert gefunden.
- `node` ist `None`: die Suche ist über ein Blatt hinausgegangen, daher ist der Wert nicht im Baum.

Fügen Sie am Anfang der `_search`-Methode, vor Ihrer bestehenden `if`-Anweisung, eine `if`-Anweisung hinzu, die prüft, ob `node` `None` ist oder ob `node.key` gleich `key` ist, und geben Sie `node` daraus zurück. So gibt die Methode den Knoten mit dem Wert zurück oder `None`, wenn der Wert nicht im Baum ist.
