## Noções básicas de CSS

- **O que é CSS?**: Cascading Style Sheets (CSS) é uma linguagem de folhas de estilo usada para aplicar estilos a elementos HTML. CSS é usado para cores, imagens de fundo, layouts e muito mais.
- **Anatomia básica de uma regra CSS**: Uma regra CSS é composta por duas partes principais: um seletor e um bloco de declaração. Um seletor é um padrão usado no CSS para identificar e direcionar elementos HTML específicos para estilização. Um bloco de declaração aplica um conjunto de estilos para um seletor ou seletores dados.

## Trabalhando com as propriedades `width` e `height`

- **Propriedade `width`**: Esta propriedade especifica a largura de um elemento. Se você não especificar uma largura, o padrão será definido como `auto`. Isso permite que o navegador determine a largura do elemento com base no seu conteúdo, pai e tipo de exibição.
- **Propriedade `min-width`**: Esta propriedade especifica a largura mínima para um elemento.
- **Propriedade `max-width`**: Esta propriedade especifica a largura máxima para um elemento.
- **Propriedade `height`**: Esta propriedade especifica a altura de um elemento. Da mesma forma, a altura é `auto` por padrão, o que significa que ela se ajustará ao conteúdo interno.
- **Propriedade `min-height`**: Esta propriedade especifica a altura mínima para um elemento.
- **Propriedade `max-height`**: Esta propriedade especifica a altura máxima para um elemento.

## Elementos em Nível Inline, Block e Inline-Block

- **Elementos inline**: Elementos inline ocupam apenas a largura necessária e não começam em uma nova linha. Esses elementos fluem dentro do conteúdo, permitindo que texto e outros elementos inline apareçam ao lado deles. Elementos inline comuns são os elementos `span`, `a` e `img`.
- **Elementos block**: Elementos block ocupam toda a largura disponível por padrão, estendendo-se pela largura do seu container. Alguns elementos block comuns são `div`, `p` e `section`.
- **Elementos inline-block**: Você pode definir um elemento como `inline-block` usando a propriedade `display`. Esses elementos se comportam como inline, mas podem ter `width` e `height` definidos como elementos block.

## Margem e Preenchimento

- **Propriedade `margin`**: Esta propriedade é usada para aplicar espaço fora do elemento, entre a borda do elemento e os elementos ao redor.
- **Abreviação de `margin`**: Você pode especificar de 1 a 4 valores para definir os lados da margem. Um valor se aplica aos quatro lados; dois valores definem `top` e `bottom` e depois `right` e `left`; três valores definem `top`, horizontal (`right` e `left`) e depois `bottom`; quatro valores definem `top`, `right`, `bottom`, `left`.
- **Propriedade `padding`**: Esta propriedade é usada para aplicar espaço dentro do elemento, entre o conteúdo e sua borda.
- **Atalho de `padding`**: Você pode especificar de 1 a 4 valores para definir os lados do padding. Um valor se aplica aos quatro lados; dois valores definem `top` e `bottom` e depois `right` e `left`; três valores definem `top`, horizontal (`right` e `left`) e depois `bottom`; quatro valores definem `top`, `right`, `bottom`, `left`.

## Imagens de fundo

- **Propriedade `background-image`**: Essa propriedade é usada para definir uma imagem de fundo para um elemento.
- **Propriedade `background-size`**: Essa propriedade define o tamanho da imagem de fundo. O valor `contain` escala a imagem o máximo possível sem cortar ou esticar. O valor `cover` escala a imagem para cobrir todo o elemento mantendo sua proporção, o que pode cortar parte da imagem.
- **Propriedade `background-repeat`**: Por padrão, imagens de fundo se repetem horizontal e verticalmente para preencher o elemento. O valor `no-repeat` impede a repetição, `repeat-x` repete horizontalmente e `repeat-y` repete verticalmente.
- **Propriedade `background-position`**: Essa propriedade define onde a imagem de fundo aparece dentro do elemento. Você pode usar palavras-chave como `top`, `bottom`, `left`, `right` e `center`, ou valores em pixels e porcentagem.
- **Propriedade `background-attachment`**: Essa propriedade determina se a imagem de fundo rola junto com o conteúdo ou permanece fixa. O valor padrão é `scroll`, enquanto `fixed` mantém a imagem na mesma posição na tela quando a página é rolada.
- **Propriedade abreviada `background`**: Essa propriedade permite combinar várias propriedades de fundo, como `background-image`, `background-position` e `background-attachment`, em uma única declaração.

## Bordas

- **Propriedade `border`**: Essa é uma propriedade abreviada usada para definir a largura, estilo e cor de uma borda de uma vez só. Estilos comuns de borda incluem `solid`, `dashed`, `dotted` e `double`.
- **Lados individuais da borda**: As propriedades `border-top`, `border-right`, `border-bottom` e `border-left` permitem estilizar cada lado da borda separadamente.
- **Propriedade `outline`**: Essa propriedade cria uma linha ao redor de um elemento, semelhante a uma borda. Diferente da `border`, o `outline` não afeta as dimensões ou o layout do elemento.
- **Propriedade `border-radius`**: Essa propriedade é usada para criar cantos arredondados na borda de um elemento.

## Especificidade do CSS

- **Especificidade do CSS inline**: O CSS inline tem a maior especificidade porque é aplicado diretamente ao elemento. Ele sobrescreve qualquer CSS interno ou externo. O valor de especificidade para estilos inline é (1, 0, 0, 0).
- **Especificidade do CSS interno**: O CSS interno é definido dentro de um elemento `style` na seção `head` do documento HTML. Ele tem especificidade menor que os estilos inline. Tanto o CSS interno quanto o externo compartilham o mesmo nível de especificidade, que é determinado pelos seletores usados, não pela localização.
- **Especificidade do CSS externo**: O CSS externo é vinculado via um elemento `link` na seção `head` e é escrito em arquivos `.css` separados. Assim como o CSS interno, sua especificidade é determinada pelos seletores usados. Quando duas regras têm especificidade igual, a ordem no código determina o vencedor: a regra que aparece depois no documento tem precedência. O CSS externo oferece a melhor manutenção para projetos maiores.
- **Seletor universal (`*`)**: Esse é um tipo especial de seletor CSS que corresponde a qualquer elemento no documento. É frequentemente usado para aplicar um estilo a todos os elementos da página, o que pode ser útil para resetar ou normalizar estilos entre navegadores. O seletor universal tem o menor valor de especificidade de qualquer seletor. Ele contribui com 0 para todas as partes do valor de especificidade (0, 0, 0, 0).
- **Seletores de tipo**: Esses seletores direcionam elementos com base no nome da tag. Seletores de tipo têm especificidade relativamente baixa comparada a outros seletores. O valor de especificidade para um seletor de tipo é (0, 0, 0, 1).
- **Seletores de classe**: Esses seletores são definidos por um ponto (`.`) seguido do nome da classe. O valor de especificidade para um seletor de classe é (0, 0, 1, 0). Isso significa que seletores de classe podem sobrescrever seletores de tipo, mas podem ser sobrescritos por seletores de ID e estilos inline.
- **Seletores de ID**: Seletores de ID são definidos por um símbolo de hash (`#`) seguido do nome do ID. Seletores de ID têm especificidade muito alta, maior que seletores de tipo e classe, mas menor que estilos inline. O valor de especificidade para um seletor de ID é (0, 1, 0, 0).
- **Palavra-chave `!important`**: usada para dar a uma regra de estilo a maior prioridade, permitindo que ela sobrescreva qualquer outra declaração para uma propriedade. Quando usada, força o navegador a aplicar o estilo especificado, independentemente da especificidade dos outros seletores. Você deve ter cuidado ao usar `!important` porque pode tornar seu CSS mais difícil de manter e depurar.

## Unidades Absolutas

- **`px` (Pixels)**: Unidade absoluta fixa de medida no CSS, que oferece controle preciso sobre dimensões. Isso significa que 1px é sempre igual a 1/96 de polegada.
- **`in` (Polegada)**: Unidade absoluta igual a 96px.
- **`cm` (Centímetros)**: Unidade absoluta igual a 25.2/64 de polegada.
- **`mm` (Milímetros)**: Unidade absoluta igual a 1/10 de centímetro.
- **`q` (Quarto de milímetro)**: Unidade absoluta igual a 1/40 de centímetro.
- **`pc` (Picas)**: Unidade absoluta igual a 1/6 de polegada.
- **`pt` (Pontos)**: Unidade absoluta igual a 1/72 de polegada.

## Unidades Relativas

- **Porcentagens**: Essas unidades relativas permitem definir tamanhos, dimensões e outras propriedades como uma proporção do elemento pai. Por exemplo, se você definir `width: 50%;` em um elemento, ele ocupará metade da largura do container pai.
- **Unidade `em`**: Essas unidades são relativas ao tamanho da fonte do elemento. Se você usar `ems` para a propriedade `font-size`, o tamanho do texto será relativo ao tamanho da fonte do elemento pai.
- **Unidade `rem`**: Essas unidades são relativas ao tamanho da fonte do elemento raiz, que é o elemento `html`.
- **Unidade `vh`**: `vh` significa `"viewport height"` e `1vh` equivale a 1% da altura do viewport.
- **Unidade `vw`**: `vw` significa `"viewport width"` e `1vw` equivale a 1% da largura do viewport.

## Função `calc`

- **Função `calc()`**: Com a função `calc()`, você pode realizar cálculos diretamente dentro das suas folhas de estilo para determinar valores de propriedades de forma dinâmica. Isso significa que você pode criar interfaces de usuário flexíveis e responsivas calculando dimensões com base no tamanho da viewport ou em outros elementos.

## Pseudo-classes

- **Definição de pseudo-classes**: São palavras-chave especiais do CSS que permitem selecionar um elemento com base em seu estado ou posição específica.
- **Pseudo-classe `:active`**: Essa pseudo-classe permite selecionar o estado ativo de um elemento, como ao clicar em um botão.
- **Pseudo-classe `:hover`**: Essa pseudo-classe define o estado de hover de um elemento.
- **Pseudo-classe `:focus`**: Essa pseudo-classe aplica estilos quando um elemento recebe foco, normalmente por navegação via teclado ou quando o usuário clica em uma entrada de formulário.
- **Pseudo-classe `:first-child`**: Essa pseudo-classe seleciona o primeiro elemento dentro de um elemento pai ou do documento.
- **Pseudo-classe `:last-child`**: Essa pseudo-classe seleciona o último elemento dentro de um elemento pai ou do documento.
- **Pseudo-classe `:first-of-type`**: Essa pseudo-classe seleciona a primeira ocorrência de um tipo específico de elemento dentro do seu pai.
- **Pseudo-classe `:last-of-type`**: Essa pseudo-classe seleciona a última ocorrência de um tipo específico de elemento dentro do seu pai.
- **Pseudo-classe `:nth-of-type(n)`**: Essa pseudo-classe permite selecionar um elemento específico dentro do seu pai com base na posição entre irmãos do mesmo tipo.
- **Pseudo-classe `:visited`**: Essa pseudo-classe direciona um link que o usuário já visitou.
- **Pseudo-classe `:enabled`**: Essa pseudo-classe é usada para direcionar botões de formulário ou outros elementos que estão habilitados.
- **Pseudo-classe `:disabled`**: Essa pseudo-classe permite estilizar um elemento interativo no modo desabilitado.
- **Pseudo-classe `:checked`**: Essa pseudo-classe é usada para indicar ao usuário que está marcado.

## Pseudo-elementos

- **Pseudo-elemento `::before`**: Este pseudo-elemento usa a propriedade `content` para inserir conteúdo cosmético como ícones logo antes do elemento.
- **Pseudo-elemento `::after`**: Este pseudo-elemento usa a propriedade `content` para inserir conteúdo cosmético como ícones logo após o elemento.
- **Pseudo-elemento `::first-letter`**: Este pseudo-elemento seleciona a primeira letra do conteúdo de um elemento, permitindo que você a estilize.
- **Pseudo-elemento `::marker`**: Este pseudo-elemento permite que você selecione o marcador (bullet ou numeração) dos itens da lista para estilização.

## Diferentes Formas de Trabalhar com Cores em CSS

- **Cores nomeadas**: Essas cores são nomes pré-definidos reconhecidos pelos navegadores. Exemplos incluem `blue`, `darkred`, `lightgreen`.
- **Função `rgb()`**: RGB significa Red, Green e Blue, as cores primárias da luz. Essas três cores são combinadas em diferentes intensidades para criar uma ampla gama de cores. A função `rgb()` permite definir cores usando o modelo de cor RGB.
- **Função `rgba()`**: Essa função adiciona um quarto valor, alpha, que controla a transparência da cor.
- **Função `hsl()`**: HSL significa Hue, Saturation e Lightness — três componentes chave que definem uma cor.
- **Função `hsla()`**: Essa função adiciona um quarto valor, alpha, que controla a opacidade da cor.
- **Hexadecimal**: Um código hex (abreviação de código hexadecimal) é uma string de seis caracteres usada para representar cores no modelo RGB. O "hex" refere-se ao sistema numérico base 16, que usa dígitos de 0 a 9 e letras de A a F.

## Propriedade `box-shadow`

- **Definição**: A propriedade `box-shadow` aplica uma ou mais sombras ao redor de um elemento.
- **Valores de offset**: Você deve especificar valores horizontal (`offset-x`) e vertical (`offset-y`). Um `offset-x` positivo move a sombra para a direita, enquanto valores negativos a movem para a esquerda. Um `offset-y` positivo move a sombra para baixo, enquanto valores negativos a movem para cima. Se o valor for `0`, não é necessário incluir unidade.
- **Raio de desfoque**: Esse valor opcional controla o quão borrada a sombra aparece. Se não incluído, o padrão é `0`, que cria bordas nítidas. Quanto maior o valor, mais suave a sombra.
- **Raio de expansão**: Esse valor opcional controla o quanto a sombra se expande ou encolhe. Se não incluído, o padrão é `0`.
- **Cor da sombra**: Você pode especificar a cor usando cores nomeadas, valores hex, funções `rgb()`, `rgba()`, `hsl()` ou `hsla()`.

## Gradientes

- **Gradientes lineares**: Esses gradientes criam uma mistura gradual entre cores ao longo de uma linha reta. Você pode controlar a direção dessa linha e as cores usadas.

## Propriedade CSS Transform

- **Definição**: Essa propriedade permite aplicar várias transformações a elementos, como rotacionar, escalar, inclinar ou transladar (mover) em espaço 2D ou 3D.
- **Função `rotate()`**: Essa função é usada para rotacionar um elemento ao redor do seu centro.

## O Modelo de Caixa

- **Definição**: No modelo de caixa do CSS, todo elemento é cercado por uma caixa. Essa caixa consiste em quatro componentes: a área de conteúdo, `padding`, `border` e `margin`.
- **Área de Conteúdo**: A área de conteúdo é a parte mais interna da caixa. É o espaço que contém o conteúdo real de um elemento, como texto ou imagens.
- **`padding`**: O padding é a área imediatamente após a área de conteúdo. É o espaço entre a área de conteúdo e a borda de um elemento.
- **`border`**: A borda é a borda externa ou contorno de um elemento no modelo de caixa CSS. É o limite visual do elemento.
- **`margin`**: A margem é o espaço fora da borda de um elemento. Ela determina a distância entre um elemento e outros elementos ao seu redor.

## Os Valores da Propriedade `content-box` e `border-box`

- **Propriedade `box-sizing`**: Essa propriedade é usada para determinar como o `width` e o `height` totais são calculados para um elemento HTML.
- **Valor `content-box`**: No modelo `content-box`, o `width` e o `height` que você define para um elemento determinam as dimensões da área de conteúdo, mas não incluem o `padding` e a `border`.
- **Valor `border-box`**: Com `border-box`, o `width` e o `height` que você define para um elemento incluem a área de conteúdo, o `padding` e a `border`.

## Propriedade CSS Filter

- **Definição**: Essa propriedade pode ser usada para criar vários efeitos, como desfoque.
- **Função `blur()`**: Essa função aplica um desfoque ao elemento. A quantidade é definida em pixels e representa o raio do desfoque.

## Introdução ao CSS Flexbox e ao Modelo Flexível

- **Definição**: O flexbox CSS é um modelo de layout unidimensional que permite organizar elementos em linhas e colunas dentro de um container.
- **Modelo flex**: Esse modelo define como os itens flexíveis são organizados dentro de um container flexível. Todo container flex tem dois eixos: o eixo principal e o eixo cruzado.

## A Propriedade `flex-direction`

- **Definição**: Essa propriedade define a direção do eixo principal. O valor padrão de `flex-direction` é `row`, que coloca todos os itens flexíveis na mesma linha, na direção do idioma padrão do seu navegador (da esquerda para a direita ou da direita para a esquerda).
- **`flex-direction: row-reverse;`**: Isso inverte a ordem dos itens na linha.
- **`flex-direction: column;`**: Isso alinha os itens flexíveis verticalmente em vez de horizontalmente.
- **`flex-direction: column-reverse;`**: Isso inverte a ordem dos itens flexíveis verticalmente.

## A Propriedade `flex-wrap`

- **Definição**: Esta propriedade determina como os itens flexíveis são quebrados dentro de um container flexível para caber no espaço disponível. `flex-wrap` pode assumir três valores possíveis: `nowrap`, `wrap` e `wrap-reverse`.
- **`flex-wrap: nowrap;`**: Valor padrão. Os itens flexíveis não serão quebrados em uma nova linha, mesmo que sua largura exceda a do container.
- **`flex-wrap: wrap;`**: Esta propriedade fará com que os itens sejam quebrados quando excederem a largura do container.
- **`flex-wrap: wrap-reverse;`**: Esta propriedade quebra os itens flexíveis em ordem reversa.
- **Propriedade `flex-flow`**: Propriedade abreviada para `flex-direction` e `flex-wrap`.

## A Propriedade `justify-content`

- **Definição**: Esta propriedade alinha os elementos filhos ao longo do eixo principal do contêiner flexível.
- **`justify-content: flex-start;`**: Neste caso, os itens flex serão alinhados ao início do eixo principal. Isso pode ser horizontal ou vertical.
- **`justify-content: flex-end;`**: Neste caso, os itens flex são alinhados ao final do eixo principal, horizontalmente ou verticalmente.
- **`justify-content: center;`**: Isso centraliza os itens flex ao longo do eixo principal.
- **`justify-content: space-between;`**: Isso distribuirá os elementos uniformemente ao longo do eixo principal.
- **`justify-content: space-around;`**: Isso distribuirá os itens flex de forma uniforme dentro do eixo principal, adicionando um espaço antes do primeiro item e depois do último item.
- **`justify-content: space-evenly;`**: Isso distribui os itens uniformemente ao longo do eixo principal.

## A Propriedade `align-items`

- **Definição**: Esta propriedade é usada para distribuir itens ao longo do eixo cruzado. Lembre-se que o eixo cruzado é perpendicular ao eixo principal.
- **`align-items: center;`**: Isso é usado para centralizar os itens ao longo do eixo cruzado.
- **`align-items: flex-start;`**: Isso alinha os itens ao início do eixo cruzado.
- **`align-items: stretch;`**: Isso é usado para esticar os itens flex ao longo do eixo cruzado.

## Propriedade CSS `font-family`

- **Definição**: Uma família de fontes é um grupo de fontes que compartilham um design comum. Todas as fontes que pertencem à mesma família são baseadas no mesmo tipo de letra principal, mas também apresentam variações em estilo, espessura e largura. Você pode especificar múltiplas famílias de fontes em ordem de prioridade, da mais alta para a mais baixa, separando-as por vírgulas. Essas fontes alternativas funcionarão como opções de fallback. Você deve sempre incluir uma família de fontes genérica no final da lista de font-family.

## Trabalhando com Diferentes Seletores de Atributos e Links

- **Definição**: O seletor `attribute` permite que você direcione elementos HTML com base em seus atributos como os atributos `href` ou `title`.

## Diferentes Tipos de Combinadores CSS

- **Combinador descendente (` `)\* um espaço único entre seletores**: Esse combinador é usado para direcionar elementos que são descendentes de um elemento pai especificado.
- **Combinador filho (`>`)**: Esse combinador é usado para selecionar elementos que são filhos diretos de um elemento pai especificado.
- **Combinador irmão imediato (`+`)**: Esse combinador seleciona um elemento que segue imediatamente um elemento irmão especificado.
- **Combinador irmão subsequente (`~`)**: Esse combinador seleciona todos os irmãos de um elemento especificado que vêm depois dele.

## Posicionamento Estático, Relativo e Absoluto

- **Posicionamento Estático**: Este é o fluxo normal para o documento. Os elementos são posicionados de cima para baixo e da esquerda para a direita um após o outro.
- **Posicionamento Relativo**: Isso permite que você use as propriedades `top`, `left`, `right` e `bottom` para posicionar o elemento dentro do fluxo normal do documento. Você também pode usar o posicionamento relativo para fazer com que elementos se sobreponham a outros elementos na página.
- **Posicionamento Absoluto**: Isso permite que você retire um elemento do fluxo normal do documento, fazendo com que ele se comporte de forma independente dos outros elementos.

## Posicionamento Fixo e Fixo Adesivo

- **Posicionamento fixo**: Quando um elemento é posicionado com `position: fixed`, ele é removido do fluxo normal do documento e colocado em relação à viewport, ou seja, permanece na mesma posição mesmo quando o usuário rola a página. Isso é frequentemente usado para elementos como cabeçalhos ou barras de navegação que precisam permanecer visíveis o tempo todo.
- **Posicionamento sticky**: Esse tipo de posicionamento funciona como um híbrido entre o posicionamento relativo e fixo. Inicialmente, o elemento se comporta como se estivesse posicionado relativamente, permanecendo dentro do fluxo do documento. No entanto, quando o usuário rola a página e o elemento ultrapassa um certo ponto, ele "gruda" na viewport (geralmente no topo) e se comporta como se estivesse fixo. Isso é ótimo para criar elementos como barras de navegação sticky, que só ficam fixas quando o usuário rola até uma certa posição.

## Trabalhando com a propriedade `z-index`

- **Definição**: A propriedade `z-index` no CSS é usada para controlar a ordem de empilhamento vertical de elementos posicionados que se sobrepõem na página.

## Consultas de Mídia

- **Definição**: Isso permite que os desenvolvedores apliquem estilos diferentes com base nas características do dispositivo, principalmente na largura do viewport.

## Propriedades Personalizadas CSS (Variáveis CSS)

- **Definição**: Propriedades personalizadas do CSS, também conhecidas como variáveis CSS, são entidades definidas pelos autores de CSS que contêm valores específicos para serem reutilizados ao longo de um documento. Elas são um recurso poderoso que permite folhas de estilo mais eficientes, fáceis de manter e flexíveis. Propriedades personalizadas são particularmente úteis na criação de designs temáticos. Você pode definir um conjunto de propriedades para diferentes temas.

## Noções básicas de CSS Grid

- **Definição**: CSS Grid é um sistema de layout bidimensional usado para criar layouts complexos em páginas web. Grades terão linhas e colunas com gaps entre elas. Para definir um layout de grade, você deve definir a propriedade `display` como `grid`.
- **Unidade `fr` (fracionária)**: Essa unidade representa uma fração do espaço dentro do container de grade. Você pode usar a unidade `fr` para criar grades flexíveis.
- **Criando gaps entre tracks**: Existem três maneiras de criar gaps entre tracks na grade CSS. Você pode usar a propriedade `column-gap` para criar gaps entre colunas. Pode usar a propriedade `row-gap` para criar gaps entre linhas. Ou pode usar a propriedade abreviada `gap` para criar gaps entre linhas e colunas.
- **Função `repeat()`**: Essa função é usada para repetir seções na lista de tracks. Em vez de escrever `grid-template-columns: 1fr 1fr 1fr;`, você pode usar a função `repeat()`.
- **Grade explícita**: Você pode especificar o número de linhas ou tracks usando as propriedades `grid-template-columns` ou `grid-template-rows`.
- **Grade implícita**: Quando itens são posicionados fora da grade, linhas e colunas são criadas automaticamente para esses elementos externos.
- **Função `minmax()`**: Essa função é usada para definir os tamanhos mínimo e máximo para uma track.
- **Auto posicionamento da grade**: O navegador posiciona automaticamente os itens usando o algoritmo de auto posicionamento. A propriedade `grid-auto-flow` controla esse comportamento, usando valores como `row`, `column` ou `dense` para influenciar a direção do posicionamento e se espaços vazios são preenchidos.
- **Posicionamento baseado em linhas**: Todas as grades têm linhas. Para especificar onde o item começa em uma linha, você pode usar as propriedades `grid-column-start` e `grid-row-start`. Para especificar onde o item termina na linha, pode usar `grid-column-end` e `grid-row-end`. Você também pode usar as propriedades abreviadas `grid-column` ou `grid-row`.
- **`grid-template-areas`**: Essa propriedade é usada para fornecer um nome para os itens que você vai posicionar na grade.
- **Alinhamento:** Use `justify-items` e `align-items` para controlar como os itens são alinhados dentro de suas áreas na grade. Use `justify-self` e `align-self` em itens individuais para sobrescrever o alinhamento definido no container.
