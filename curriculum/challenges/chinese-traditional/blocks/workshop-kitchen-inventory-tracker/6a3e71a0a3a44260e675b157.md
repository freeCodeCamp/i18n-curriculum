# --description--

一個函式可以呼叫另一個函式並使用它傳回的值。舉例來說：

```py
def calculate_sum(a, b):
    return a + b

def show_total(a, b):
    total = calculate_sum(a, b)
    print(total)

show_total(3, 4) # 7
```

在這裡，`show_total` 呼叫 `calculate_sum`，將它傳回的值指定給區域的變數 `total`，並將其列印出來。

接下來，你將創建一個函式，用來檢查是否有雞蛋可用，並呼叫 `use_eggs` 來使用它。在你的 `print(available_eggs)` 述語下方，定義一個名為 `make_fried_egg` 的空函式，它以 `available_eggs` 作為唯一的參數。

目前在函式主體內使用 `pass` 關鍵字。

    if eggs_to_use > available_eggs:

        return available_eggs

    print(f'{eggs_to_use} egg(s) used out of {available_eggs} available.')
    return available_eggs - eggs_to_use
