# --description--

Nelle ultime lezioni ti sei abituato a lavorare con loop come questo:

```py
even_numbers = []

for num in range(21):
    if num % 2 == 0:
        even_numbers.append(num)

print(even_numbers)
```

Questo esempio crea una nuova lista vuota chiamata `even_numbers` e itera su una sequenza di numeri tra `0` e `20`. All’interno del loop, c’è una condizione che verifica se il numero corrente ha un resto di `0` quando viene diviso per `2`. Questo serve a determinare se il numero è pari. Se la condizione è `True`, allora il `num` corrente viene aggiunto in coda alla lista `even_numbers`. Infine, stampiamo la lista `even_numbers` sulla console.

## Che cos'è la list comprehension?

Anche se questo codice funziona, esiste un modo più conciso per scriverlo usando invece la list comprehension. La list comprehension ti permette di creare una nuova lista in una sola riga scrivendo un loop direttamente all'interno delle parentesi quadre. Questo rende il codice più breve e spesso più facile da leggere.

La sintassi base di una list comprehension è la seguente:

```py
[expression for item in iterable]
```

Per ogni elemento nell'iterabile, viene valutata l'espressione prima di `for` e il risultato viene aggiunto alla nuova lista. Ecco un esempio che crea una lista con ogni numero da `0` a `4` moltiplicato per `2`:

```py
doubled = [num * 2 for num in range(5)]
print(doubled) # [0, 2, 4, 6, 8]
```

## Filtrare con un `if` finale

Opzionalmente, puoi aggiungere una condizione `if` alla fine di una list comprehension. Solo gli elementi per cui la condizione è vera vengono aggiunti alla nuova lista, mentre gli altri vengono saltati.

Ecco l'esempio dei numeri pari visto prima, rifattorizzato usando la list comprehension:

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

In questo esempio rifattorizzato, la lista `even_numbers` viene creata con una sola riga di codice. La list comprehension itera sui numeri da `0` a `20` e include solo quelli divisibili per `2`. Questo approccio è più compatto ed elimina la necessità di un loop e di un blocco condizionale separati.

## Creare liste interne separate

In precedenza hai imparato che `[[]] * 3` ripete i riferimenti a una sola lista interna. Una comprehension può invece creare una lista interna separata a ogni iterazione:

```py
rows = [[] for _ in range(3)]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

L'espressione `[]` viene valutata a ogni iterazione, quindi ogni posizione fa riferimento a una lista diversa. La variabile del loop non viene usata nell'espressione; il range controlla solo quante liste vengono create.

Quando una variabile del loop non è necessaria, gli sviluppatori Python la chiamano convenzionalmente `_` per segnalare che il suo valore è intenzionalmente ignorato. `_` è comunque un nome di variabile ordinario.

## Usare espressioni condizionali nelle list comprehension

Finora hai usato `if` e `else` per scrivere istruzioni condizionali. Python ha anche un'espressione condizionale, che si scrive in una sola riga e produce un valore. Ecco la sua sintassi:

```py
value_if_true if condition else value_if_false
```

Se la condizione è vera, l'intera espressione valuta al valore prima di `if`. Altrimenti, valuta al valore dopo `else`. Ecco un esempio:

```py
num = 7
label = 'Even' if num % 2 == 0 else 'Odd'
print(label) # Odd
```

Poiché `7` non è divisibile esattamente per `2`, la condizione è `False` e a `label` viene assegnato `'Odd'`.

Puoi usare un'espressione condizionale come espressione prima di `for` in una list comprehension. In questo caso, sceglie un valore per ogni elemento nell'iterabile, quindi la nuova lista ha lo stesso numero di elementi dell'originale. Questo è diverso da un `if` finale, che può escludere elementi dalla nuova lista.

Diamo un'occhiata a un esempio:

```py
numbers = [1, 2, 3, 4, 5]
result = [(num, 'Even') if num % 2 == 0 else (num, 'Odd') for num in numbers]
print(result)
```

In questo esempio, abbiamo una lista di numeri e vogliamo creare una nuova lista di tuple che indicano quali numeri sono pari o dispari. Nella prima parte della list comprehension, usiamo un'espressione condizionale `if`/`else` per verificare se il numero è divisibile per `2`. In tal caso, il risultato è una tupla con quel numero seguito dalla parola `Even`. Altrimenti, il risultato è una tupla con il numero seguito dalla parola `Odd`.

Ecco come appare il risultato stampato sulla console:

```py
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

## Filtrare liste con `filter()`

Un altro modo per creare una lista a partire da un iterabile esistente è la funzione `filter()`. Ecco un esempio di creazione di una nuova lista contenente solo parole più lunghe di quattro caratteri:

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

La funzione `filter()` serve a selezionare elementi da un iterabile che soddisfano una condizione specifica. La funzione `filter()` accetta come argomenti una funzione e un iterabile. In questo esempio, passiamo una funzione `is_long_word` a `filter()` per verificare se il numero di caratteri nella parola corrente è maggiore di `4`. `is_long_word` è scritta senza parentesi perché stai passando la funzione stessa, non la stai chiamando. La funzione `filter()` chiama `is_long_word` su ogni parola per te. Come `zip()`, `filter()` restituisce un iteratore, che fornisce solo le parole che soddisfano la condizione. La funzione `list()` raccoglie queste parole in una nuova lista, che viene assegnata alla variabile `long_words`.

## Trasformare liste con `map()`

Oltre alla funzione `filter()`, ci sono altre funzioni utili quando si lavora con le liste. Un’altra funzione da conoscere è la funzione `map()`, che prende un iterabile e applica una funzione a ciascuno dei suoi elementi. Ecco un esempio di utilizzo della funzione `map()` per convertire una lista di temperature da Celsius a Fahrenheit:

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

Proprio come la funzione `filter()`, `map()` accetta una funzione e un iterabile come argomenti. La funzione `to_fahrenheit` prende una temperatura e la converte da Celsius a Fahrenheit. Anche in questo caso, `to_fahrenheit` viene passata senza parentesi, e `map()` la chiama su ogni temperatura nella lista `celsius`. La funzione `map()` restituisce anch'essa un iteratore, questa volta dei valori convertiti, quindi si usa di nuovo `list()` per raccoglierli in una lista.

## Sommare valori con `sum()`

L’ultima funzione che vedremo è la funzione `sum()`. Questa funzione serve per ottenere la somma da un iterabile come una lista o una tupla. Ecco un esempio di utilizzo della funzione `sum()`:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

Puoi anche passare un argomento `start` opzionale che imposta il valore iniziale per la somma. Ecco un esempio aggiornato che usa l’argomento `start` come argomento posizionale:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

Puoi anche scegliere di usare l’argomento `start` come argomento con nome in questo modo:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

Entrambe le versioni produrranno lo stesso risultato, ma l’argomento con nome è un po’ più esplicito.

La list comprehension così come altre funzioni come `map()`, `filter()` e `sum()` possono sembrare un po’ confuse all’inizio. Ma con abbastanza pratica e tempo, inizierai a sentirti più a tuo agio nell’usarle nei tuoi programmi Python.
