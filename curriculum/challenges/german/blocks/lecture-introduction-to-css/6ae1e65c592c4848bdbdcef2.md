# --interactive--

Die Eigenschaft `text-decoration` ermöglicht es Ihnen, dekorative Linien zu Text hinzuzufügen.

Mit ihrem Anfangswert `none` wird sie häufig verwendet, um die standardmäßige Unterstreichung zu entfernen, die Browser Links hinzufügen, wenn eine Anpassung dieser Links erforderlich ist.

```css
a {
  text-decoration: none;
}
```

Obwohl sie häufig für Links verwendet wird, kann `text-decoration` auch anderen Text dekorieren.

## Weitere Werte der Eigenschaft `text-decoration`

Neben `none` sind weitere Werte der Eigenschaft `text-decoration`:

- `underline`
- `overline`
- `line-through`

Wie die Namen der Werte andeuten, fügt `underline` eine Linie unter dem Text hinzu, `overline` eine Linie über dem Text, und `line-through` eine Linie genau in der Mitte des Textes, als würde der Text durchgestrichen.

## Mehr zur Eigenschaft `text-decoration`

Die Eigenschaft `text-decoration` ist tatsächlich eine Kurzschreibweise-Eigenschaft, die die folgenden Eigenschaften kombiniert:

- `text-decoration-line`: `none`, `underline`, `overline` und `line-through`
- `text-decoration-color`: Die Farbe der Linie.
- `text-decoration-style`: `solid`, `double`, `dotted`, `dashed` oder `wavy`.
- `text-decoration-thickness`: Die Dicke der Linie.

Zum Beispiel fügt dies einem Absatz eine rote, gewellte Linie hinzu:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

Und dies fügt einem Absatz eine doppelte grüne Überlinie hinzu:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

Sie können auch Linientypen kombinieren, wenn Sie möchten:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
