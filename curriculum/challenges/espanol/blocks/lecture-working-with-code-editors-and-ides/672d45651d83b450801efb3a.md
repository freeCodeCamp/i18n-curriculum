# --description--

Para comenzar, debes saber que VS Code considera los proyectos como "workspaces". El workspace es el directorio que abriste en VS Code.

Para comenzar, necesitarás usar una interfaz de línea de comandos para crear una nueva carpeta para tu nuevo proyecto. Un directorio es otro nombre para una carpeta.

Las interfaces de línea de comandos, o CLI para abreviar, te permiten interactuar con tu sistema operativo mediante comandos basados en texto. Aprenderás más sobre estas herramientas en futuras lecciones.

Si estás en Windows, puedes usar el Command Prompt o PowerShell. Si estás en una Mac, puedes abrir tu aplicación Terminal.

Una vez que la línea de comandos esté abierta, navega a tu directorio personal. En el Command Prompt, escribe `cd /d %USERPROFILE%` y presiona <kbd>Enter</kbd> en tu teclado. En PowerShell o en el Terminal de macOS, escribe `cd ~` y presiona <kbd>Enter</kbd>. Luego escribe el comando `mkdir my-project` y presiona <kbd>Enter</kbd>. `mkdir`, o "make directory", es el comando que se usa para crear un nuevo directorio. Después deberías abrir tu nuevo directorio con VS Code.

También hay otras formas de abrir un directorio en VS Code.

Dependiendo de tu sistema operativo, podrías tener un menú contextual (o una opción al hacer clic derecho) para abrir VS Code directamente desde tu explorador de archivos. También podrías elegir hacer doble clic en la aplicación VS Code. Si te sientes cómodo con la línea de comandos, puedes ejecutar el comando `code /path/to/folder`.

En macOS, el comando `code` no está disponible en el Terminal hasta que lo habilites. Abre VS Code, presiona <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> para abrir la paleta de comandos, luego busca y ejecuta `Shell Command: Install 'code' command in PATH`. Después de eso, el comando `code` funcionará desde el Terminal.

Una vez abierto, deberías ver un nuevo workspace en blanco.

Para crear un nuevo archivo, haz clic en el menú `File` en la esquina superior izquierda y selecciona `New File...`. Luego nombra tu archivo `index.html` y haz clic en `Save`.

Ahora deberías ver tu nuevo archivo en la pestaña de explorador. Intenta agregar algo de HTML a tu archivo `index.html`.

Ahora podrías sentir la tentación de abrir el archivo HTML directamente en tu navegador. Aunque eso puede funcionar, también puede llevar a todo tipo de errores inesperados, como que el CSS no se cargue correctamente.

En su lugar, debes poner tu archivo HTML detrás de un servidor web adecuado. Eso puede sonar como una tarea intimidante si eres nuevo en la codificación, pero en realidad hay una manera de hacer esto directamente desde VS Code.

Primero necesitarás obtener la extensión Live Server, que está disponible gratis en el marketplace.

Haz clic en la pestaña de Extensiones en la barra lateral izquierda y escribe `Live Server` en la barra de búsqueda.

Una vez que la tengas instalada, deberías ver un botón `Go Live` en tu barra de estado. Asegúrate de tener abierto tu archivo HTML y luego haz clic en él.

Tu nueva página debería abrirse automáticamente en una nueva pestaña del navegador. Si no es así, puedes ir directamente a `http://localhost:5500/`.

¡Felicidades! Ahora has configurado tu propio proyecto en VS Code y puedes ver tus cambios con Live Server.
