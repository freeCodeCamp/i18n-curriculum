# --description--

La temperatura uguale alla media riceve l'etichetta `0.0 °C`, che non si legge bene. Dovrebbe ricevere invece l'etichetta `average`.

Puoi concatenare espressioni condizionali scrivendo un'altra espressione condizionale dopo `else`. Se la prima condizione è falsa, Python valuta la successiva espressione condizionale:

```py
labels = [
    'large' if num > 100
    else 'medium' if num > 10
    else 'small'
    for num in numbers
]
```

Aggiorna la tua espressione condizionale in modo che valuti a `f'+{difference} °C'` se `difference` è maggiore di `0`, a `f'{difference} °C'` se `difference` è minore di `0`, e alla stringa `average` altrimenti.
