# --description--

マイナーリリースはマイナー番号を`1`増やし、パッチ番号を`0`にリセットします。一方、パッチリリースはパッチ番号だけを`1`増やします。

`release_type`が文字列の`minor`と等しいかどうかをチェックする`elif`節を追加してください。もしそうなら、`major`、`minor + 1`、`0`を含むタプルを`new_version`に代入してください。

次に、`release_type`が文字列の`patch`と等しいかどうかをチェックする別の`elif`節を追加してください。もしそうなら、`major`、`minor`、`patch + 1`を含むタプルを`new_version`に代入してください。
