# --description--

이 워크숍에서는 학생 그룹의 기말 시험 표를 만들어 HTML 표를 다루는 연습을 합니다.

`table` 요소는 표 형식 데이터를 표시할 수 있게 해줍니다. 표 형식 데이터는 스프레드시트처럼 행과 열로 구성된 정보입니다.

`body` 요소 안에 `table` 요소를 중첩하세요. 다음 단계에서 표에 행, 제목, 데이터를 추가할 것입니다.

# --hints--

열린 `table` 태그가 있어야 합니다.

```js
assert.match(code, /<table>/i);
```

닫힌 `table` 태그가 있어야 합니다.

```js
assert.match(code, /<\/table>/i);
```

`table` 요소는 `body` 요소 안에 있어야 합니다.

```js
const tableEl = document.querySelector('table');
assert.strictEqual(tableEl?.parentElement?.tagName, 'BODY');
```
