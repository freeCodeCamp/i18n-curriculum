# --description--

Você aprendeu que a atribuição cria um alias e que o método `.copy()` de um dicionário cria uma cópia rasa. Uma cópia rasa tem um dicionário externo separado, mas os objetos aninhados ainda são compartilhados. Agora que você sabe como importar módulos, pode usar o módulo `copy` da biblioteca padrão para copiar coleções aninhadas também.

## Criando uma cópia profunda

A função `copy.deepcopy()` copia recursivamente coleções aninhadas. Para um dicionário que contém uma lista, ela cria um novo dicionário externo e uma lista aninhada separada:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
deep_copy = copy.deepcopy(original)

print(deep_copy == original) # True
print(deep_copy is original) # False
print(deep_copy['items'] is original['items']) # False

deep_copy['items'].append('fruit')
print(original['items']) # ['bread', 'cheese']
print(deep_copy['items']) # ['bread', 'cheese', 'fruit']
```

Os dicionários inicialmente têm conteúdos iguais, mas nem o dicionário externo nem a lista aninhada são compartilhados entre eles. Adicionar à lista copiada deixa a lista original inalterada.

## Comparando atribuição, cópia rasa e cópia profunda

Vamos criar as três formas a partir do mesmo dicionário:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
alias = original
shallow_copy = original.copy()
deep_copy = copy.deepcopy(original)

print(alias is original) # True
print(shallow_copy is original) # False
print(deep_copy is original) # False

print(alias['items'] is original['items']) # True
print(shallow_copy['items'] is original['items']) # True
print(deep_copy['items'] is original['items']) # False
```

Continuando com esses objetos, altere uma entrada de nível superior por cada nome:

```python
alias['name'] = 'Picnic'
shallow_copy['name'] = 'Snack'
deep_copy['name'] = 'Dinner'

print(original['name']) # Picnic
print(alias['name']) # Picnic
print(shallow_copy['name']) # Snack
print(deep_copy['name']) # Dinner
```

O alias se refere ao dicionário original, então atribuir através de `alias` altera esse dicionário. Cada cópia tem seu próprio dicionário externo, então substituir sua entrada `name` afeta apenas essa cópia.

Em seguida, modifique as listas aninhadas:

```python
alias['items'].append('water')
shallow_copy['items'].append('fruit')
deep_copy['items'].append('soup')

print(original['items']) # ['bread', 'cheese', 'water', 'fruit']
print(alias['items']) # ['bread', 'cheese', 'water', 'fruit']
print(shallow_copy['items']) # ['bread', 'cheese', 'water', 'fruit']
print(deep_copy['items']) # ['bread', 'cheese', 'soup']
```

O dicionário original, seu alias e a cópia rasa referem-se todos à mesma lista. Alterações feitas por qualquer uma dessas referências são visíveis pelas outras. A cópia profunda tem sua própria lista, então suas alterações permanecem separadas.

Isso também funciona com dicionários aninhados dentro de listas:

```python
import copy

original = {'meals': [{'name': 'Lunch', 'items': ['bread']}]}
deep_copy = copy.deepcopy(original)
deep_copy['meals'][0]['items'].append('fruit')

print(original['meals'][0]['items']) # ['bread']
print(deep_copy['meals'][0]['items']) # ['bread', 'fruit']
```

Aqui, `deepcopy()` copia o dicionário externo, a lista `meals`, o dicionário dentro dessa lista e sua lista `items`. O exemplo usa dicionários e listas embutidos; copiar profundamente não significa que todo objeto Python possível seja duplicado.

Use atribuição quando quiser outro nome para o mesmo objeto. Use uma cópia rasa quando um conjunto externo separado for suficiente e compartilhar objetos aninhados for aceitável. Use uma cópia profunda quando alterações nessas coleções aninhadas não devem modificar as coleções originais.
