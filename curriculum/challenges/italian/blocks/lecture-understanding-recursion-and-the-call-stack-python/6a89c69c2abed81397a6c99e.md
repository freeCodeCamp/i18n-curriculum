# --description--

La ricorsione è una tecnica in cui una funzione chiama se stessa. Ogni chiamata lavora su una versione più piccola del problema originale fino a raggiungere una condizione che ferma la ricorsione. Questa condizione di arresto si chiama caso base.

Le funzioni ricorsive possono risolvere problemi con una profondità sconosciuta, come attraversare un albero dei file. Possono anche eseguire compiti più semplici, come contare all'indietro da un numero dato.

Ecco una funzione chiamata `recursive_countdown` che accetta un numero e lo stampa:

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

Chiamare la funzione stampa `5`, ma non conta ancora all'indietro. Prima di far sì che la funzione chiami se stessa, devi definire il suo caso base. Senza un caso base raggiungibile, la funzione continuerà a chiamarsi. Python alla fine interrompe le chiamate e genera un `RecursionError`.

Per questo conto alla rovescia, la funzione dovrebbe fermarsi quando `number` è minore di `1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

L'istruzione `if` è il caso base. Quando `number` è minore di `1`, `return` termina quella chiamata della funzione.

La funzione ha ancora bisogno di un caso ricorsivo. Il caso ricorsivo chiama di nuovo la funzione con un argomento che la avvicina al caso base. Per contare all'indietro, chiama `recursive_countdown` con `number - 1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

Questo stampa i numeri `5`, `4`, `3`, `2` e `1`.

La posizione della chiamata ricorsiva cambia quando i numeri vengono stampati. Se la chiamata a `print()` viene dopo la chiamata ricorsiva, la funzione stampa i numeri in ordine crescente:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

Questo stampa i numeri `1`, `2`, `3`, `4` e `5`. Per capire perché, devi comprendere lo stack delle chiamate.

Lo stack delle chiamate è una struttura dati last-in, first-out che Python usa per tenere traccia delle chiamate di funzione attive. Quando una funzione viene chiamata, Python aggiunge un frame per quella chiamata in cima allo stack. Il frame contiene informazioni come gli argomenti della funzione e le variabili locali.

Considera questa versione del conto alla rovescia:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

L'output è:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

La chiamata a `recursive_countdown(3)` si mette in pausa quando chiama `recursive_countdown(2)`. La chiamata con `2` si mette in pausa quando chiama la funzione con `1`, e la chiamata con `1` si mette in pausa quando chiama la funzione con `0`.

La chiamata con `0` raggiunge il caso base e ritorna. Python rimuove quella chiamata dalla cima dello stack, quindi la chiamata con `1` riprende dopo la sua chiamata ricorsiva. Le chiamate rimanenti poi riprendono e ritornano in ordine inverso: `1`, `2` e `3`.

Ogni funzione ricorsiva ha bisogno di un caso base e di un caso ricorsivo che si avvicini a esso. Quando il caso base ritorna, le chiamate precedenti riprendono in ordine last-in, first-out.
