# --description--

在過去的幾堂課中，你已經開始習慣這樣使用迴圈：

```py
even_numbers = []

for num in range(21):
    if num % 2 == 0:
        even_numbers.append(num)

print(even_numbers)
```

此範例創建一個名為 `even_numbers` 的新空列表，並對介於 `0` 和 `20` 之間的數字序列進行迴圈。在迴圈內，有一個條件判斷目前的數字除以 `2` 後是否餘數為 `0`。這用來判斷該數字是否為偶數。如果條件為 `True`，則將目前的 `num` 附加到 `even_numbers` 列表的末尾。最後，我們將 `even_numbers` 列表列印到主控台。

## 什麼是列表推導式？

雖然這段程式碼可以運作，但有一種更簡潔的寫法是使用列表生成式。列表生成式允許你在一行內直接在方括號中寫迴圈來創建新列表。這讓程式碼更短且通常更容易閱讀。

列表生成式的基本語法如下：

```py
[expression for item in iterable]
```

對於可迭代物件中的每個項目，會先計算 `for` 前的表達式，然後將結果加入新列表。以下是一個範例，創建一個列表，裡面是從 `0` 到 `4` 的每個數字乘以 `2`：

```py
doubled = [num * 2 for num in range(5)]
print(doubled) # [0, 2, 4, 6, 8]
```

## 使用尾端的 `if` 進行篩選

你可以選擇在列表生成式的尾端加上 `if` 條件。只有條件為真值的項目會被加入新列表，其他項目會被跳過。

以下是之前的偶數範例，使用列表生成式重構後的寫法：

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

在這個重構的範例中，`even_numbers` 列表是使用一行程式碼創建的。列表推導式迴圈遍歷從 `0` 到 `20` 的數字，並且只包含能被 `2` 整除的數字。這種方法更為簡潔，並且省略了額外的迴圈和條件區塊。

## 創建獨立的內部列表

之前你學過 `[[]] * 3` 是重複參考同一個內部列表。列表生成式則可以在每次迭代時創建獨立的內部列表：

```py
rows = [[] for _ in range(3)]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

表達式 `[]` 在每次迭代時都會被計算，因此每個位置都指向不同的列表。迴圈變數沒有被用在表達式中；範圍只是控制創建多少個列表。

當不需要使用迴圈變數時，Python 開發者慣例用 `_` 來命名，表示這個值是故意被忽略的。`_` 仍然是普通的變數名稱。

## 在列表推導式中使用條件運算式

到目前為止，你已經使用過 `if` 和 `else` 來寫條件敘述。Python 也有條件運算式，它寫在一行內並會產生一個值。語法如下：

```py
value_if_true if condition else value_if_false
```

如果條件為真值，整個運算式會計算為 `if` 前的值。否則，會計算為 `else` 後的值。以下是一個範例：

```py
num = 7
label = 'Even' if num % 2 == 0 else 'Odd'
print(label) # Odd
```

因為 `7` 無法被 `2` 整除，條件為 `False`，所以 `'Odd'` 被指定給 `label`。

你可以在列表生成式中將條件運算式用作 `for` 前的表達式。這樣會為可迭代物件中的每個項目選擇一個值，因此新列表的項目數與原始列表相同。這和尾端的 `if` 不同，後者會排除不符合條件的項目。

讓我們來看一個範例：

```py
numbers = [1, 2, 3, 4, 5]
result = [(num, 'Even') if num % 2 == 0 else (num, 'Odd') for num in numbers]
print(result)
```

在這個範例中，我們有一個數字列表，想要創建一個新的元組列表，標示哪些數字是偶數或奇數。在列表生成式的第一部分，我們使用 `if`/`else` 條件運算式來檢查該數字是否能被 `2` 整除。如果是，結果就是該數字後面接著字串 `Even` 的元組。否則，結果就是該數字後面接著字串 `Odd` 的元組。

以下是在主控台中列印結果的樣子：

```py
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

## 使用 `filter()` 篩選列表

另一種從現有可迭代物件創建列表的方法是使用 `filter()` 函式。以下是一個只創建長度超過四個字元的字的新列表的範例：

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

`filter()` 函式用來從可迭代物件中選出符合特定條件的元素。`filter()` 函式接受一個函式和一個可迭代物件作為引數。在這個範例中，我們將 `is_long_word` 函式傳入 `filter()`，用來檢查目前字串的字元數是否大於 `4`。`is_long_word` 沒有加小括號，因為你是傳入函式本身，而不是呼叫它。`filter()` 會幫你對每個字串呼叫 `is_long_word`。和 `zip()` 一樣，`filter()` 回傳一個迭代器，只包含符合條件的字串。`list()` 函式會將這些字串收集成新列表，並指定給 `long_words` 變數。

## 使用 `map()` 轉換列表

除了 `filter()` 函式之外，還有一些在處理列表時很有用的函式。另一個需要注意的函式是 `map()`，它會接受一個可迭代物件並對其每個元素套用一個函式。以下是使用 `map()` 函式將攝氏溫度列表轉換為華氏溫度的範例：

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

和 `filter()` 函式一樣，`map()` 也接受一個函式和一個可迭代物件作為引數。`to_fahrenheit` 函式會將溫度從攝氏轉換為華氏。同樣地，`to_fahrenheit` 沒有加小括號，`map()` 會對 `celsius` 列表中的每個溫度呼叫它。`map()` 也會回傳一個迭代器，這次是轉換後的值，因此再次使用 `list()` 將它們收集成列表。

## 使用 `sum()` 加總數值

我們將要看的最後一個函式是 `sum()` 函式。這個函式用來從可迭代物件（例如列表或元組）取得總和。以下是使用 `sum()` 函式的範例：

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

你也可以傳入選用的 `start` 引數，該引數設定加總的初始值。以下是使用 `start` 引數作為位置引數的更新範例：

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

你也可以選擇將 `start` 引數作為關鍵字引數這樣使用：

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

兩個版本都會產生相同的結果，但關鍵字引數會比較明確。

列表推導式以及其他函式（程式）像是 `map()`、`filter()` 和 `sum()` 一開始可能會讓人感到有點困惑。但只要有足夠的練習和時間，你會開始感覺在你的 Python 程式中使用它們更加得心應手。
