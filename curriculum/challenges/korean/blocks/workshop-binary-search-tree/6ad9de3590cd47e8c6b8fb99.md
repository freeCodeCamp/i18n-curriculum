# --description--

이제 클래스 사용자가 호출할 메서드를 만드세요. `BinarySearchTree` 클래스 안에 `self`와 `key` 두 개의 매개변수를 가진 `insert` 메서드를 만드세요.

class TreeNode:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None


class BinarySearchTree:
    def __init__(self):
        self.root = None

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node
