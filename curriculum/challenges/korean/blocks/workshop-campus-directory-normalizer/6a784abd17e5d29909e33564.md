# --description--

현재 `program`은 `departmentId`로 자신이 속한 부서를 알고 있지만, 부서는 아직 어떤 프로그램이 속해 있는지 모릅니다.
각 `program.id`를 `departmentsById[departmentId].programIds`에 추가하세요.

이렇게 하면 양방향 관계가 만들어집니다: 부서는 `programIds`를 통해 자신의 프로그램을 조회할 수 있고, 각 프로그램은 `departmentId`를 통해 자신의 부서를 조회할 수 있습니다. 이때 어느 객체도 상대방의 전체 데이터를 저장할 필요가 없습니다.

프로그램 ID를 추가하기 전에 이전 단계에서 `console.log(programsById[program.id])`를 삭제하세요.

`departmentData.programs` 반복문이 끝난 후에 `departmentsById[departmentId]`를 콘솔에 기록하세요.
