# --description--

Zeigen Sie nun den Zeitstempel an, wenn Sie die vollständige E-Mail anzeigen.

Unter dem Betreff geben Sie `'Received:'` linksbündig mit einer Breite von `10` aus, gefolgt vom Zeitstempel, der mit `strftime` im Format `'%Y-%m-%d %H:%M'` formatiert ist. Verwenden Sie das folgende Format:

```md
Received: date
```

Dabei ist `date` im Format `'%Y-%m-%d %H:%M'` formatiert. `Received:` ist der längste davon, weshalb alle eine Breite von `10` verwenden: Es bleibt genau ein Leerzeichen danach.

    def list_emails(self):
        if not self.emails:
            print('Your inbox is empty.\n')
            return
        print('\nYour Emails:')
        for i, email in enumerate(self.emails, start=1):
            print(f'{i:>2}. {email}')

    def read_email(self, index):
        if not self.emails:
            print('Inbox is empty.\n')
            return
        actual_index = index - 1
        if actual_index < 0 or actual_index >= len(self.emails):
            print('Invalid email number.\n')
            return
        self.emails[actual_index].display_full_email()

    def delete_email(self, index):
        if not self.emails:
            print('Inbox is empty.\n')
            return
        actual_index = index - 1
        if actual_index < 0 or actual_index >= len(self.emails):
            print('Invalid email number.\n')
