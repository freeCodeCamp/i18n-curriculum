# --description--

`map()` 함수는 반복 가능한 각 항목에 함수를 호출하고 결과의 반복자를 반환합니다. `filter()`와 마찬가지로, 람다 함수를 전달할 수 있습니다:

```py
prices = [10, 20, 30]
discounted = list(map(
    lambda price: price * 0.9,
    prices
))
print(discounted) # [9.0, 18.0, 27.0]
```

이제 유효한 측정값을 10분의 1도 단위에서 도 단위로 변환해야 합니다.

`temperatures`라는 변수를 만들고, `map()`에 람다 함수와 `valid_readings`를 전달한 결과를 `list()`로 감싸서 할당하세요. 람다 함수는 `reading`이라는 매개변수를 받아서 `reading`을 `10`으로 나눈 값을 반환해야 합니다.

그런 다음 `valid_readings` 대신 `temperatures`를 출력하세요.
