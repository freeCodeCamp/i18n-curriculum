## Instalando Python no seu ambiente local

- **Instalação**: A maneira mais fácil de instalar Python no Windows e macOS é baixar o instalador do site oficial do Python (`https://www.python.org/`). No Linux, a maioria das distribuições principais como Ubuntu, Debian e Fedora já inclui Python, então você deve verificar a versão instalada primeiro e só instalar um pacote específico da distribuição se o Python 3 estiver ausente.
- **Configuração no macOS**: Baixe e abra o instalador `.pkg` e siga as instruções. Quando terminar, dê um clique duplo no arquivo `Install Certificates.command` e deixe o processo no terminal completar para finalizar a configuração.
- **Configuração no Windows**: Baixe e execute o Python Install Manager `.msix`. Depois disso, os comandos `python`, `py` e `pymanager` ficam disponíveis, executar `python` sem um runtime instalado instalará um automaticamente, e você pode aceitar o prompt opcional para adicionar um diretório de aliases (para comandos como `python3.14.exe`) ao seu `PATH`.
- **Configuração no Linux**: Abra um terminal e execute `python --version` ou `python3 --version`. Se nenhum deles mostrar uma versão do Python 3, procure um pacote de instalação em `https://www.python.org/` ou pesquise online a forma recomendada de instalar Python para sua distribuição.

## Verificando a instalação

- **Verificando a versão**: Confirme a instalação executando `python --version` ou `python3 --version` em um terminal.
- **`python` vs. `python3`**: Em alguns sistemas macOS e Linux mais antigos, `python` pode se referir ao Python 2. Se `python --version` mostrar uma versão do Python 2, use `python3` para seu código a partir de então. Python 2 está fora de suporte e não deve ser usado para novos desenvolvimentos.

## Terminal

- **Definição**: Um terminal é uma interface baseada em texto que permite interagir com seu computador digitando comandos. Cada sistema operacional vem com um app de terminal padrão. No macOS, você pode usar o app Terminal. No Windows, pode usar o Prompt de Comando ou PowerShell. No Linux, cada ambiente de desktop tem seu próprio app de terminal padrão, como GNOME Terminal ou Konsole.

## Editores de código e IDEs

- **IDE**: IDE significa ambiente de desenvolvimento integrado, e ele tem recursos incluindo um editor de código, ferramentas de teste, um terminal e mais.
- **Editores de código e IDEs populares para Python**: VS Code, PyCharm e Spyder.

## Executando scripts Python

- **Configurando seu editor**: Abra a pasta do seu projeto no VS Code e crie um arquivo `.py`. Instale a extensão Python da Microsoft pela visualização de Extensões ou executando `code --install-extension ms-python.python` (no macOS, o comando `code` deve ser adicionado ao seu `PATH` primeiro). A extensão adiciona suporte a Python no editor, mas não instala o Python em si.
- **Escolhendo um interpretador**: Execute `Python: Select Interpreter` na Paleta de Comandos para apontar o editor para um interpretador Python 3 que você instalou anteriormente.
- **Executando seu código**: Clique no botão de executar (ícone de play no canto superior direito do VS Code) para executar o arquivo atual em um terminal. Você também pode executar um script manualmente a partir de um terminal. Por exemplo, se a pasta do seu projeto for `python-projects` e seu script for `main.py`, abra um terminal na pasta que contém `python-projects`, depois entre na pasta do projeto e execute o script:

```bash
cd python-projects
python main.py
```

Use `python3 main.py` em vez disso se `python3` for o comando que mostra a versão do Python 3 no seu sistema.

## Usando o shell interativo do Python

- **Iniciando o shell**: Abra um terminal e execute `python` ou `python3` (use aquele que mostrou uma versão do Python 3). O prompt `>>>` significa que o Python está esperando um comando. Tente imprimir `"Hello, world!"`:

```python
print("Hello, world!")
```

- **Ciclo Read, Evaluate, Print, Loop (REPL)**: O interpretador lê sua entrada, avalia, imprime o resultado e volta ao prompt `>>>` para que você possa digitar outro comando.
- **Entrada inválida**: Digitar algo que não seja Python válido, como `something random`, gera uma mensagem `SyntaxError: invalid syntax` e o shell retorna ao prompt.
- **Saindo do shell**: Digite `exit()`, pressione <kbd>Ctrl</kbd> + <kbd>D</kbd> no macOS ou Linux, ou pressione <kbd>Ctrl</kbd> + <kbd>Z</kbd> seguido de <kbd>Enter</kbd> no Windows.
- **Quando usar**: O shell interativo é melhor para pequenos experimentos e exploração rápida. Para programas maiores ou trabalho em vários arquivos, use um editor de código ou IDE.
