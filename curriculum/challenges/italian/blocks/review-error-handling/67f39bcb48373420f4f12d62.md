## Errori comuni in Python

- **`SyntaxError`**: L'errore che Python genera quando il tuo codice non segue le sue regole di sintassi. Per esempio, il codice `print("Hello there"` causerà un errore di sintassi con il messaggio, `SyntaxError: '(' was never closed`, perché manca una parentesi di chiusura.
- **`NameError`**: Python genera un `NameError` quando provi a consultare una variabile o funzione che non hai definito. Per esempio, se hai la riga `print(username)` nel tuo codice senza aver prima definito una variabile `username`, otterrai un errore con il messaggio `NameError: name 'username' is not defined`.
- **`TypeError`**: Questo è l'errore che Python genera quando un'operazione o funzione viene applicata a un oggetto di tipo non appropriato. Per esempio, se provi ad aggiungere una stringa a un numero, otterrai l'errore `TypeError: can only concatenate str (not "int") to str`.
- **`IndexError`**: Otterrai un `IndexError` se accedi a un indice che non esiste in una lista o in altre sequenze come tuple e stringhe. Per esempio, in una stringa `Hello world`, l'indice dell'ultimo carattere è `10`. Se provi ad accedere a un carattere così, `greet = "hello world"; print(greet[11])`, otterrai un errore con il messaggio `IndexError: string index out of range`.
- **`AttributeError`**: Python genera questo errore quando provi a usare un metodo o una proprietà che non esiste in un oggetto di quel tipo. Per esempio, chiamare `.append()` su una stringa come `"hello".append("!")` causerà un errore con il messaggio `AttributeError: 'str' object has no attribute 'append'`.

## Buone tecniche di debugging in Python

- **Usare la funzione `print`**: Inserire istruzioni `print()` in vari punti del tuo codice durante il debugging ti aiuta a vedere i valori delle variabili e come scorre il tuo codice.
- **Usare il debugger integrato di Python (`pdb`)**: Python fornisce il modulo `pdb` per il debugging come parte della libreria standard. Chiamare `pdb.set_trace()` mette in pausa l'esecuzione e apre un prompt interattivo. Puoi digitare `help` per elencare i comandi, `whatis` per ispezionare il tipo di un'espressione, e `continue` (o i suoi alias `cont` e `c`) per riprendere l'esecuzione del programma.
- **Sfruttare gli strumenti di debugging degli IDE**: Gli ambienti di sviluppo integrati (IDE) e gli editor di codice come PyCharm e VS Code offrono strumenti di debugging visivi. Per esempio, VS Code fornisce:
  - **Breakpoint**: Clicca nel margine interno dell'editor per posizionare un breakpoint (rappresentato da un punto rosso) dove l'esecuzione deve fermarsi.
  - **Ispezione delle variabili e console di debug**: Passa il mouse sulle variabili o consulta il pannello Variabili per vedere i valori attuali, e usa la console di debug per valutare espressioni in modo interattivo.
  - **Controlli di avanzamento**:
    - **Continua (<kbd>F5</kbd>)**: Riprende l'esecuzione fino al prossimo breakpoint.
    - **Step Over (<kbd>F10</kbd>)**: Esegue la riga corrente e passa alla successiva senza entrare nelle chiamate di funzione.
    - **Step Into (<kbd>F11</kbd>)**: Entra nella funzione chiamata per eseguire passo passo le sue righe.
    - **Step Out (<kbd>Shift</kbd> + <kbd>F11</kbd>)**: Termina la funzione corrente e torna al chiamante.

## Gestione delle eccezioni

- **`try...except`**: Serve per eseguire un blocco di codice che potrebbe generare un'eccezione. Il blocco `try` è dove prevedi che possa verificarsi un errore, mentre il blocco `except` cattura una specifica eccezione e viene eseguito se quell'errore si verifica. Ecco un esempio:

  ```py
  try:
    print(22 / 0)
  except ZeroDivisionError:
    print('You can\'t divide by zero!')
    # You can't divide by zero!
  ```

  Puoi anche concatenare più blocchi `except` per gestire più tipi di eccezioni:

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

  Puoi anche catturare più tipi di eccezioni in un'unica clausola `except` raggruppandole in una tupla:

  ```py
  try:
    number = int(input('Enter a number: '))
    result = 10 / number
  except (ValueError, ZeroDivisionError) as e:
    print(f'Error occurred: {e}')
  ```

- **`else` e `finally`**: Questi blocchi estendono `try...except`. Se non si verifica nessuna eccezione, viene eseguito il blocco `else`. Il blocco `finally` viene sempre eseguito indipendentemente dagli errori.

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **Oggetto eccezione**: Ti permette di accedere all'eccezione stessa per un debugging migliore e per stampare il messaggio di errore diretto. Per accedere all'oggetto eccezione, devi usare la parola chiave `as`. Ecco un esempio:

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **L'istruzione `raise`**: Ti permette di generare manualmente un'eccezione. Puoi usarla per lanciare un'eccezione quando si verifica una certa condizione:

  ```py
  def divide(a, b):
      if b == 0:
          raise ZeroDivisionError('You cannot divide by zero')
      return a / b
  ```

  Usare `raise` senza argomenti all'interno di un blocco `except` rilancia l'eccezione corrente che si sta gestendo. Questo ti permette di registrare l'errore o eseguire operazioni di pulizia mantenendo però la propagazione dell'eccezione nella catena delle chiamate:

  ```py
  def process_data(data):
      try:
          result = int(data)
          return result * 2
      except ValueError:
          print('Logging: Invalid data received')
          raise
  ```

- **L'istruzione `assert`**: L'istruzione `assert` verifica delle ipotesi durante il debugging e genera un `AssertionError` quando la condizione è falsa. Poiché Python rimuove le asserzioni quando viene eseguito in modalità ottimizzata (`-O`), le asserzioni non dovrebbero essere usate per validazioni critiche degli input che devono sempre essere eseguite. Usa invece una condizione esplicita e `raise` per i controlli obbligatori.

## Segnalazione delle eccezioni

- **Eccezioni personalizzate**: L'istruzione `raise` è utile anche quando crei eccezioni personalizzate derivando dalla classe `Exception`. Questo ti permette di lanciare errori con logiche e messaggi specifici del dominio:

  ```py
  class InvalidCredentialsError(Exception):
      def __init__(self, message="Invalid username or password"):
          self.message = message
          super().__init__(self.message)

  def login(username, password):
      stored_username = "admin"
      stored_password = "password123"
      
      if username != stored_username or password != stored_password:
          raise InvalidCredentialsError()
      
      return f"Welcome, {username}!"
  ```

  Ecco come puoi usare la funzione `login` con l'eccezione `InvalidCredentialsError`:

  ```py
  # failed login attempt
  try:
      message = login("user", "wrongpassword")
  except InvalidCredentialsError as e:
      print(f"Login failed: {e}")
  else:
      print(message)

  # successful login attempt
  try:
      message = login("admin", "password123")
  except InvalidCredentialsError as e:
      # This block is not executed because the login was successful
      print(f"Login failed: {e}")
  else:
      # The else block runs if the 'try' block completes without an exception
      print(message)
  ```

- **Concatenamento delle eccezioni**: L'istruzione `raise` può essere usata con la parola chiave `from` per concatenare eccezioni. Usare `from None` sopprime il contesto dell'eccezione originale nel traceback mostrato, mentre `from e` registra esplicitamente l'eccezione originale come causa:

  ```py
  def parse_config(filename):
      try:
          with open(filename, 'r') as file:
              data = file.read()
              return int(data)
      except FileNotFoundError:
          raise ValueError('Configuration file is missing') from None
      except ValueError as e:
          raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```
