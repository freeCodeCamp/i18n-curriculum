# --description--

En este laboratorio, construirás una clase de cola. Una cola sigue el principio FIFO (primero en entrar, primero en salir): los elementos se agregan al final de la cola y se eliminan desde el frente.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

**Historias de usuario:**

1. Debes definir una clase llamada `Queue`. Una nueva instancia de `Queue` debe comenzar vacía.

1. La clase `Queue` debe tener los siguientes métodos:

   - `enqueue`: toma un elemento y lo agrega al final de la cola.
   - `dequeue`: elimina el elemento al frente de la cola y lo devuelve. Si la cola está vacía, debe devolver `None`.
   - `front`: devuelve el elemento al frente de la cola sin eliminarlo. Si la cola está vacía, debe devolver `None`.
   - `size`: devuelve el número de elementos en la cola.
   - `is_empty`: devuelve `True` si la cola no tiene elementos, y `False` en caso contrario.

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
