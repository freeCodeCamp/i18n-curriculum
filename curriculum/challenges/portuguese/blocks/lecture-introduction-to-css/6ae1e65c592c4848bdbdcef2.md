# --interactive--

A propriedade `text-decoration` permite adicionar linhas decorativas ao texto.

Com seu valor inicial `none`, é comumente usada para remover o sublinhado padrão que os navegadores adicionam aos links quando é necessário personalizar esses links.

```css
a {
  text-decoration: none;
}
```

Embora seja comumente usada para links, `text-decoration` também pode decorar outros textos.

## Outros valores da propriedade `text-decoration`

Além de `none`, outros valores da propriedade `text-decoration` são:

- `underline`
- `overline`
- `line-through`

Como os nomes dos valores indicam, `underline` adiciona uma linha abaixo do texto, `overline` adiciona uma linha acima do texto e `line-through` adiciona uma linha bem no meio do texto, como se cancelasse o texto.

## Há mais na propriedade `text-decoration`

A propriedade `text-decoration` é na verdade uma propriedade abreviada que combina as seguintes propriedades:

- `text-decoration-line`: `none`, `underline`, `overline` e `line-through`
- `text-decoration-color`: A cor da linha.
- `text-decoration-style`: `solid`, `double`, `dotted`, `dashed` ou `wavy`.
- `text-decoration-thickness`: A espessura da linha.

Por exemplo, isso adiciona uma linha vermelha ondulada a um parágrafo:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

E isso adiciona uma overline verde double a um parágrafo:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

Você também pode combinar tipos de linha se quiser:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
