# --description--

在這個工作坊中，你將透過建置一個檢查應用程式是否需要更新的程式，練習使用 tuple。

每個軟體版本發佈時都會有一個版本號，讓人們能分辨不同版本並知道哪個是較新的版本。常見的慣例是使用三個以點分隔的數字，格式為 `MAJOR.MINOR.PATCH`：

- `MAJOR` 數字會在重大變更時增加，這些變更可能會導致舊的程式碼或檔案無法與新版本相容。
- `MINOR` 數字會在新增特性且仍與先前版本相容時增加。
- `PATCH` 數字會在進行小修正（例如除錯）且不新增特性時增加。

像是 `2.1.0` 這樣的版本號可以用包含三個整數的 tuple 來儲存：分別是 major、minor 和 patch 數字。

創建一個名為 `releases` 的變數，並指定一個 tuple，裡面包含以下版本 tuple，且順序與描述中相同：

```py
(1, 9, 0), (2, 0, 0), (1, 9, 1), (2, 1, 0),
(2, 1, 1), (2, 2, 0), (1, 9, 2), (2, 2, 1)
```

這些版本是依照發佈順序列出，而非從最低到最高版本排序。舊的 `1.9` 系列即使在版本 `2.0.0` 發佈後仍持續有修正。
