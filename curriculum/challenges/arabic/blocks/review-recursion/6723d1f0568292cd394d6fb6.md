# --description--

- التسكين هو مفهوم برمجي يسمح لك باستدعاء دالة بشكل متكرر حتى تصل إلى حالة أساسية.

إليك مثالًا على دالة مسكنة تحسب المضروب لعدد ما:

```js
function findFactorial(n) {
  if (n === 0) {
    return 1;
  }
  return n * findFactorial(n - 1);
}
```

في المثال أعلاه، تُستدعى الدالة `findFactorial` بشكل متكرر حتى يصل `n` إلى `0`. عندما يكون `n` هو `0`، يتم الوصول إلى الحالة الأساسية وتُرجع الدالة القيمة `1`. ثم تُرجع الدالة حاصل ضرب `n` في نتيجة الاستدعاء التكراري لـ `findFactorial(n - 1)`.

- تتيح لك العودية التعامل مع شيء ذو عمق غير معروف، مثل الكائنات/المصفوفات المسكنة بعمق، أو شجرة الملفات.
- تُستخدم مكدس الاستدعاء لتتبع استدعاءات الدوال في دالة عودية. في كل مرة تُستدعى دالة، تُضاف إلى مكدس الاستدعاء. عند الوصول إلى الحالة الأساسية، تُزال استدعاءات الدوال من المكدس.
- يجب تعريف الحالة الأساسية بعناية لأن استدعائها بلا نهاية قد يسبب تعطل الكود. ذلك لأن العودية تستمر في تراكم المزيد من استدعاءات الدوال حتى تنفد الذاكرة في النظام.
- تُستخدم العودية في حل المشكلات الرياضية مثل المضروب و فيبوناتشي، واستكشاف الأشجار والرسوم البيانية، وتوليد التباديل والتوافيق، وأكثر من ذلك.
