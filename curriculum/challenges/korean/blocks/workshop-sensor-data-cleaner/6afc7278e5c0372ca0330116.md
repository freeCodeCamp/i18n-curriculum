# --description--

이 워크숍에서는 온도 센서의 측정값을 정리하고 해당 위치의 일반적인 평균 온도와 비교하면서 리스트 내포와 lambda 함수를 연습하세요.

센서는 온도를 섭씨 0.1도 단위로 보고하므로, `215`라는 측정값은 `21.5` °C를 의미합니다. 온도를 읽지 못할 경우에는 대신 오류 코드 `-999`를 기록합니다.

`readings`라는 변수를 만들고 리스트 `[215, 243, -999, 280, 316, 339, -999, 262, 305]`를 할당하세요.

그다음 `average_temperature`라는 변수를 만들고 실수 `28.0`을 할당하세요. 이 값은 이미 섭씨 단위인 해당 위치의 일반적인 평균 온도이며, 측정값과 비교할 것입니다.
