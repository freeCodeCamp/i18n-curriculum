# --description--

Давайте дізнаємося, що таке термінал і чим він відрізняється від командного рядка.

Командний рядок — це базовий інтерфейс введення тексту, який дозволяє користувачу вводити «команди», зазвичай у вигляді послідовності символів, і відправляти або виконувати їх, зазвичай натискаючи клавішу <kbd>Enter</kbd>. Найчастіше ви побачите інтерфейси командного рядка всередині терміналу.

Термінал — це спеціальний застосунок, який пропонує інтерфейс командного рядка для виконання системних команд, що виходять за межі базових операцій читання/запису. Ви також можете почути про "емулятори терміналу" — це, по суті, застосунки, які обгортають базовий інтерфейс терміналу, щоб надати додаткові функції або можливості. Але для більшості загальних випадків ви можете безпечно називати їх просто "терміналами".

Нарешті, нам також потрібно поговорити про "шелли". Шелл — це програмне забезпечення, яке обгортає командний рядок і інтерпретує ваші введення як команди, повертаючи вихідні дані.

Але як ви можете отримати доступ до терміналу у своїй системі?

Якщо ви використовуєте сучасну версію Windows, у вас, ймовірно, буде два різні варіанти. Windows пропонує дві окремі shell-програми з коробки: PowerShell і Command Prompt.

Обидва ці shell мають власні термінальні застосунки (які носять ім’я відповідного shell), тож ви можете скористатися меню застосунків, щоб запустити або термінал PowerShell, або термінал Command Prompt.

Windows також пропонує відносно новий і модернізований емулятор терміналу, який має назву Windows Terminal.

Ви можете встановити цей застосунок із Windows Store, а потім запускати його так само, як і термінали PowerShell або Command Prompt. Перевага Windows Terminal у тому, що він дозволяє отримати доступ до shell PowerShell і Command Prompt з одного застосунку, а також до відповідного Linux shell, якщо ви налаштували Windows Subsystem for Linux.

На macOS є термінал, який має назву «Terminal». Ви можете отримати до нього доступ через пошук Spotlight або через лаунчер застосунків. Також підтримуються сторонні емулятори терміналу, такі як iTerm або Ghostty. Ви можете встановити ці застосунки з їхніх домашніх сторінок.

У Linux термінал за замовчуванням (і спосіб його запуску) сильно залежить від дистрибутива та середовища робочого столу, яке ви використовуєте. Існує багато підтримки сторонніх емуляторів терміналу. Наприклад, ви можете налаштувати kitty в Arch Linux — і запускати його через менеджер застосунків, такий як wofi.

Linux, мабуть, має найбільший вибір застосунків терміналу. Більшість із них можна встановити через менеджер пакетів вашого дистрибутива.

Різниця між «терміналом», «shell» і «командним рядком» іноді може здаватися надто педантичною. І здебільшого ці терміни можна використовувати взаємозамінно. Але важливо знати, що вони мають конкретні значення і які саме.
