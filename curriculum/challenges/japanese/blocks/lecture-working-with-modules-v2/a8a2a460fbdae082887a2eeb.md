# --description--

ソフトウェア開発において、ライブラリは開発者のための道具箱のようなものです。

コードのすべての部分を最初から自分で実装する代わりに、ライブラリは関数、クラス、データ構造など、プロジェクトで使えるあらかじめ書かれた再利用可能なコードを提供してくれます。

Python標準ライブラリは、Pythonに含まれるモジュールとパッケージのコレクションです。サードパーティのパッケージは別に開発されており、通常は使用前にインストールする必要があります。標準ライブラリは、以下のような一般的なプログラミングタスクの解決策を提供します：

* オペレーティングシステムとのやり取り

* ファイル操作

* ネットワーキング

* 日付と時刻の操作

* 数学的演算の実行

* 正規表現の使用

* コードのテストとデバッグ

* その他多数

標準ライブラリのモジュールの例には、`math`、`random`、`re`（「正規表現」の略）、および`datetime`があります。

`math`モジュールには、より複雑な数学的演算を行うための便利な関数が含まれています。

`random`モジュールは乱数生成に役立ちます。

`re`モジュールは正規表現の操作に使われます。

`datetime`モジュールは、Pythonで日付や時刻を扱うのに役立ちます。

モジュールは関数や定数だけでなくクラスも提供できます。ここに`datetime`モジュールのクラスの例があります。1959年7月15日を表すdateオブジェクトを作成し、その`date`オブジェクトを変数に代入して、ドット記法を使って日、月、年を個別にアクセスします：

```python
import datetime
birthday = datetime.date(1959, 7, 15)
print(birthday.day)    # 15
print(birthday.month)  # 7
print(birthday.year)   # 1959
```

特定のタスクに適したモジュールを見つけるには、[Python Standard Library reference](https://docs.python.org/3/library/index.html)を参照してください。モジュールはトピックごとに分類されています。各モジュールのドキュメントには、提供内容と使い方が説明されています。例えば、[`datetime`のドキュメント](https://docs.python.org/3/library/datetime.html)には、日付や時刻を扱うためのクラスやメソッドが記載されています。

また、`help()`関数を使ってモジュールや関数のドキュメントを表示することもできます。なお、`help()`は現在freeCodeCampのエディターでは利用できません。

例えば、このコードは`math`モジュールに関する情報を表示します：

```py
import math
help(math)
```

出力の抜粋は次の通りです：

```md
Help on built-in module math:

NAME
    math

DESCRIPTION
    This module provides access to the mathematical functions
    defined by the C standard.

FUNCTIONS
    acos(x, /)
        Return the arc cosine (measured in radians) of x.

...
...
...
```

特定の関数のドキュメントを取得することもできます：

```py
import math
help(math.comb)
```

これが出力です：

```md
Help on built-in function comb in module math:

comb(n, k, /)
    Number of ways to choose k items from n items without repetition and without order.
    
    Evaluates to n! / (k! * (n - k)!) when k <= n and evaluates
    to zero when k > n.
    
    Also called the binomial coefficient because it is equivalent
    to the coefficient of k-th term in polynomial expansion of the
    expression (1 + x)**n.
    
    Raises TypeError if either of the arguments are not integers.
    Raises ValueError if either of the arguments are negative.
```

モジュールが提供する名前を調べるには、`dir()`関数を使います。これは、数値を切り捨てる`math.floor`のような関数や、`math.e`（オイラー数）や`math.pi`のような定数を一覧表示します。また、カリキュラムの後半で学ぶ他の名前もリストアップされます：

```py

print(dir(math))
```
