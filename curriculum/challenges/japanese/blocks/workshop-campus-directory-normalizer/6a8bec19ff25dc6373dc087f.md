# --description--

すべての学部に `Dept_code` があるとは限りません。欠けている場合に備えたフォールバックが必要で、そうすれば学部にも使用可能な ID が付与されます。

`||` 演算子は左側の値が `truthy` の場合はその値を返し、そうでなければ右側の値を返します。

例えば、`a || b` は `a` が `truthy` の場合は `a` に評価され、`a` が `falsy`（`undefined`、`null`、または `""` のような）場合は `b` にフォールバックします。

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

`departmentId` の代入を `||` 演算子を使うように更新してください。左オペランドに `departmentData.Dept_code` を使い、右オペランドにテンプレートリテラル `` `dept-${i + 1}` `` を使います。これにより、`departmentData.Dept_code` が `undefined` を含めて falsy の場合にフォールバックが使われます。
