# --description--

Após verificar se a caixa de entrada está vazia, imprima a mensagem `\nYour Emails:`. Depois disso, itere através de todos os e-mails na caixa de entrada usando um loop `for` com enumeração. Esta é a sintaxe para enumeração com um número inicial: `enumerate(iterable, start=start_number)`.

Use enumeração para numerar os emails começando a partir de `1`. Use `i` (o índice) e `email` (o objeto email) como as variáveis de iteração.

Dentro do loop, imprima uma f-string com o índice da iteração alinhado à direita em uma largura de `2`, seguido de um `.`, depois um espaço e a representação em string do objeto e-mail neste formato:

```md
 i. string_representation
```

Onde `i` é o índice e `string_representation` é a representação do objeto e-mail. Alinhar o número à direita mantém a lista alinhada quando a caixa de entrada tem 10 ou mais e-mails.
