# --description--

모바일에서 페이지 스타일이 데스크톱이나 노트북과 비슷하게 보이도록 하려면, 특별한 `content` 속성을 가진 `meta` 요소를 추가해야 합니다.

뷰포트 `meta` 요소는 브라우저에 페이지의 크기와 배율을 다양한 기기, 특히 휴대폰과 태블릿에서 어떻게 제어할지 지시합니다. 예시는 다음과 같습니다:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

`width=device-width` 부분은 브라우저에 페이지 너비를 기기의 화면 너비에 맞추도록 지시합니다. `initial-scale=1.0`은 페이지가 처음 로드될 때 초기 줌 레벨을 설정합니다. `1.0` 값은 페이지가 `100%` 줌으로, 배율 없이 표시된다는 뜻입니다.

이 요소가 없으면 모바일 브라우저는 보통 데스크톱 화면 너비로 페이지를 렌더링한 뒤 축소하여 표시하는데, 이로 인해 글자가 너무 작아 읽기 어려울 수 있습니다.

# --hints--

코드에는 `meta` 요소가 두 개 있어야 합니다.

```js
assert.lengthOf(document.querySelectorAll('meta'), 2);
```

`meta` 요소에는 값이 `viewport`인 `name` 속성이 있어야 합니다.

```js
assert.exists(document.querySelector('meta[name="viewport"]'));
```

`meta` 요소에는 값이 `width=device-width, initial-scale=1.0`인 `content` 속성이 있어야 합니다.

```js
assert.equal(document.querySelector('meta[name="viewport"]')?.getAttribute('content'), 'width=device-width, initial-scale=1.0');
```
