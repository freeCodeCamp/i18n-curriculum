## Verwendung des Datei-Explorers unter Windows

Um eine Datei unter Windows mit dem Explorer zu erstellen, können Sie auf die Option „Neu“ oben links klicken. Dadurch wird Ihnen eine Liste der verschiedenen Dateitypen angezeigt, die Sie erstellen können.

![Windows-Datei-Explorer mit dem "Neu"-Button, der oben links durch ein orangefarbenes Kästchen und einen Pfeil hervorgehoben ist, und einem ausgewählten neuen Textdokument im Ordner freeCodeCamp Files.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-1.png)

Sie können Dateien auch in den entsprechenden Anwendungen erstellen.

![Windows-Datei-Explorer zeigt den Ordner freeCodeCamp Files im Bereich Dokumente, mit einem ausgewählten neuen Textdokument.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-2.png)

Lassen Sie uns eine Textdatei erstellen, um Ihnen den Vorgang zu zeigen.

Wenn Sie auf „Neu“ klicken und den Dateityp auswählen, sehen Sie eine neue Textdatei in Ihrem aktuellen Ordner mit einem Standardnamen. Sie können sie bei Bedarf umbenennen.

![Ein Symbol für ein Textdokument mit dem Dateinamen demo.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-3.png)

Der Vorgang zum Erstellen von Ordnern ist genau derselbe. Klicken Sie oben links auf die Schaltfläche „Neu“ und wählen Sie dann die Option „Ordner“ oder klicken Sie mit der rechten Maustaste auf eine freie Stelle und gehen Sie zu „Neu“. Wählen Sie dann die Option „Ordner“. Sie sehen einen neuen leeren Ordner an Ihrem aktuellen Speicherort.

![Windows-Datei-Explorer zeigt einen neuen Ordner namens Neuer Ordner im Ordner freeCodeCamp Files.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-4.png)

### Umbenennen von Dateien und Ordnern

![Windows-Datei-Explorer-Symbolleiste mit dem Umbenennen-Button, dargestellt als Buchstabe A neben einem Textcursor, hervorgehoben durch ein grünes Kästchen.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-5.png)

Sie können Dateien und Ordner umbenennen, indem Sie sie auswählen und auf die Option „Umbenennen“ oben klicken. Wenn der aktuelle Name der Datei markiert ist, können Sie den neuen Namen der Datei eingeben. Drücken Sie <kbd>Enter</kbd>, um die Änderungen zu bestätigen.

Alternativ können Sie mit der rechten Maustaste auf die Datei oder den Ordner klicken und die Option „Umbenennen“ auswählen oder die Tastenkombination <kbd>F2</kbd> verwenden. Schreiben Sie den neuen Namen und drücken Sie <kbd>Enter</kbd>, um die Änderungen zu bestätigen.

### Verschieben von Dateien und Ordnern

Sie können eine Datei oder einen Ordner in einen anderen Ordner verschieben, indem Sie sie in den Zielordner ziehen und dort ablegen, wenn Sie diesen als Tab geöffnet haben.

Sie können auch die Datei oder den Ordner auswählen und oben die Option „Ausschneiden“ wählen.

![Windows-Datei-Explorer-Symbolleiste mit dem Ausschneiden-Button, dargestellt als Schere, hervorgehoben durch ein grünes Kästchen.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-6.png)

Gehen Sie dann zum Zielordner und fügen Sie sie ein, indem Sie oben auf die Schaltfläche „Einfügen“ klicken. Wenn Sie die Datei zuvor kopiert oder ausgeschnitten haben, ist diese Schaltfläche aktiviert.

![Windows-Datei-Explorer-Symbolleiste mit dem Einfügen-Button, dargestellt als Zwischenablage, hervorgehoben durch ein grünes Kästchen.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-7.png)

Sie können dies auch tun, indem Sie mit der rechten Maustaste auf eine freie Stelle klicken und dann auf das Einfügesymbol klicken. Dadurch wird die Datei oder der Ordner aus dem ursprünglichen Speicherort entfernt.

### Löschen von Dateien und Ordnern

Um eine Datei oder einen Ordner zu löschen, klicken Sie darauf und dann auf das Papierkorb-Symbol oben.

![Windows-Datei-Explorer-Symbolleiste mit dem Löschen-Button, dargestellt als Papierkorb, hervorgehoben durch ein grünes Kästchen.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-8.png)

Sie finden auch eine "Löschen"-Option, wenn Sie mit der rechten Maustaste darauf klicken.

## Verwendung von Finder auf macOS

Gut. Schauen wir uns nun an, wie Sie dies auf macOS mit Finder machen können.

Finder ist der Standard-Dateimanager auf macOS.

### Erstellen von Dateien

Um eine Datei auf macOS zu erstellen, müssen Sie eine Anwendung öffnen, mit der Sie den Typ des Dokuments erstellen können, den Sie benötigen. Derzeit gibt es keine eingebaute Möglichkeit, eine Datei direkt im Finder zu erstellen.

Zum Beispiel können Sie, um eine einfache Textdatei zu erstellen, TextEdit öffnen und Ihre Datei speichern. Der Vorgang funktioniert für jeden Dateityp genau gleich.

Es gibt viele Möglichkeiten, TextEdit zu öffnen. Eine davon ist, zum Launchpad zu gehen.

![Das macOS-Launchpad-Symbol, ein abgerundetes Quadrat mit einem Raster aus farbigen App-Kacheln.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-9.png)

Suchen Sie dann nach einer App, mit der Sie die Art von Datei erstellen können, die Sie benötigen. In diesem Fall wäre das "TextEdit." Klicken Sie auf das Symbol, um die App zu öffnen.

![Das Suchfeld im Launchpad mit dem Text TextEdit, darunter das TextEdit-App-Symbol.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-10.png)

Sobald Sie in der App sind, sollten Sie im Menü „Datei“ eine Option zum Speichern Ihrer Datei sehen. Dieses Menü befindet sich oben links, neben dem Apple-Menü-Symbol.

![TextEdit geöffnet mit einem leeren Dokument. Ein grüner Pfeil zeigt nach oben zur macOS-Menüleiste, die TextEdit, Datei, Bearbeiten, Format, Ansicht, Fenster und Hilfe auflistet.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-11.png)

In einem der App-Menüoptionen sollten Sie einen Befehl zum Speichern der Datei sehen. Dieser befindet sich normalerweise im Menü „Datei“.

![Eine Nahaufnahme der macOS-Menüleiste mit dem Apple-Logo, dann TextEdit, Datei, Bearbeiten, Format, Ansicht, Fenster und Hilfe.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-12.png)

Daneben sehen Sie die Tastenkombination zum Speichern Ihrer Datei. Diese ist auf macOS normalerweise <kbd>Command</kbd> + <kbd>S</kbd>.

![Das geöffnete Datei-Menü von TextEdit, mit hervorgehobener Option Speichern und der Tastenkombination Command + S rechts daneben.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-13.png)

Wenn Sie die Datei zum ersten Mal speichern, sollten Sie ein Dialogfenster sehen, in dem Sie den Namen der Datei eingeben und einen Speicherort auswählen können.

Normalerweise wird die Dateiendung von der Anwendung automatisch hinzugefügt, aber Sie können sie vor dem Speichern ändern.

![Der Speicherdialog von TextEdit mit Untitled.txt im Feld Speichern unter, einem Ordnerbrowser und den Schaltflächen Abbrechen und Speichern unten.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-14.png)

Nachdem Sie die Datei gespeichert haben, können Sie Finder öffnen, indem Sie auf das Finder-Symbol im Dock klicken.

![Das Finder-Symbol im macOS-Dock, ein blau-weißes lächelndes Gesicht.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-15.png)

Sie sollten Ihre neue Datei in dem Ordner sehen, in dem Sie sie gespeichert haben.

![Ein Finder-Fenster zeigt den Ordner freeCodeCamp Files mit einer Datei, demo.txt.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-16.png)

### Erstellen von Ordnern

Um einen neuen Ordner zu erstellen, gehen Sie an den Ort, an dem Sie den neuen Ordner erstellen möchten, und klicken Sie mit der rechten Maustaste auf eine freie Stelle. Sie sehen eine Liste von Optionen. Die erste Option ist „Neuer Ordner“.

![Ein Finder-Kontextmenü, geöffnet auf einer leeren Fläche, mit hervorgehobener Option Neuer Ordner ganz oben in der Liste.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-17.png)

Wenn Sie darauf klicken, können Sie Ihrem neuen Ordner einen Namen zuweisen. Schreiben Sie den Namen und drücken Sie <kbd>Enter</kbd>, um zu bestätigen.

![Ein neuer Finder-Ordner namens unbenannter Ordner, dessen Name zum Bearbeiten hervorgehoben ist.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-18.png)

![Der gleiche Ordner wurde in freeCodeCamp umbenannt.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-19.png)

### Verschieben von Dateien und Ordnern

Es gibt mehrere Möglichkeiten, Dateien und Ordner im Finder zu verschieben. Wenn Sie sie in einen Ordner verschieben müssen, der im Bereich „Favoriten“ Ihres Finders aufgeführt ist, können Sie sie einfach per Drag & Drop verschieben.

![Ein Finder-Fenster, in dem demo.txt auf Dokumente im Favoritenbereich gezogen wird, dargestellt durch grüne Pfeile.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-20.png)

Wenn Sie sie in einen anderen Ordner verschieben müssen, haben Sie zwei Optionen.

Sie können entweder den Zielordner als Tab öffnen und die Datei oder den Ordner in diesen Tab ziehen und dort ablegen.

Oder Sie können Tastenkombinationen verwenden. Kopieren Sie zuerst die Datei mit <kbd>Command</kbd> + <kbd>C</kbd>, gehen Sie zum neuen Ordner und verwenden Sie dann <kbd>Command</kbd> + <kbd>Option</kbd> + <kbd>V</kbd>, um die Datei oder den Ordner an diesem Ort einzufügen. Dadurch wird sie auch aus dem ursprünglichen Ordner entfernt.

### Löschen von Dateien und Ordnern

Um eine Datei oder einen Ordner zu löschen, können Sie mit der rechten Maustaste darauf klicken und „In den Papierkorb legen“ auswählen.

![Das Finder-Kontextmenü für demo.txt mit hervorgehobener Option In den Papierkorb legen.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-21.png)

![Das Finder-Kontextmenü für den Ordner freeCodeCamp mit hervorgehobener Option In den Papierkorb legen.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-22.png)

Sie können sie auch per Drag & Drop in das Papierkorb-Symbol im Dock ziehen. Das ist gleichwertig.

![Das Papierkorb-Symbol im macOS-Dock, ein Behälter gefüllt mit zerknülltem Papier.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-23.png)

Wenn sich die Datei oder der Ordner im Papierkorb befindet, können Sie mit der rechten Maustaste darauf klicken, um sie sofort zu löschen, oder Sie können den Papierkorb leeren, um alle gelöschten Dateien und Ordner dauerhaft zu entfernen.

![Das Finder-Papierkorb-Fenster mit geöffnetem Kontextmenü für demo.txt, das Öffnen, Öffnen mit, Zurücklegen, Sofort löschen und Papierkorb entleeren auflistet.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-24.png)
