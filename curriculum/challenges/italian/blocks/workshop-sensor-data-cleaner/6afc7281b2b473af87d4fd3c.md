# --description--

Ora devi abbinare ogni temperatura alla sua etichetta.

La funzione `map()` può prendere più di un iterabile. Ad ogni chiamata, passa un elemento da ogni iterabile alla funzione, quindi la funzione deve avere un parametro per ogni iterabile:

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

Crea una variabile chiamata `report`. Assegna a essa il risultato di passare a `map()` una funzione lambda, `temperatures` e `difference_labels`, racchiusi in una chiamata a `list()`. La funzione lambda deve prendere due parametri, `temperature` e `difference_label`, e restituire `f'{temperature} °C ({difference_label})'`.

Poi, stampa `report` invece di `difference_labels`.
