# --description--

In questo laboratorio costruirai una lista doppiamente concatenata, dove ogni nodo mantiene un riferimento sia al nodo successivo sia a quello precedente nella lista.

**Obiettivo:** Completa le storie utente qui sotto e fai passare tutti i test per completare il laboratorio.

**Storie utente:**

1. Devi avere una classe chiamata `DoublyLinkedList`.
1. `DoublyLinkedList` deve avere una classe annidata chiamata `Node`, il cui metodo `__init__` deve:
   - accettare un parametro `element` e un parametro opzionale `previous` che ha come valore predefinito `None`.
   - impostare l'attributo `element` al valore del parametro `element`.
   - impostare l'attributo `previous` al valore del parametro `previous`.
   - impostare l'attributo `next` su `None`.
1. Il metodo `__init__` di `DoublyLinkedList` deve impostare l'attributo `length` a `0` e gli attributi `head` e `tail` su `None`.
1. `DoublyLinkedList` deve avere un metodo `is_empty` che restituisce `True` se la lista non ha nodi, e `False` altrimenti.
1. `DoublyLinkedList` deve avere un metodo `add` che accetta un `element` e:
   - crea un nuovo `Node` che contiene quell'`element` e lo aggiunge alla fine della lista.
   - imposta l'attributo `previous` del nuovo nodo sul nodo che era il tail prima dell'aggiunta, oppure su `None` se la lista era vuota.
   - aggiorna `head` (quando la lista era vuota), `tail` e `length` della lista.
   - non deve iterare nella lista per trovare la fine.
1. `DoublyLinkedList` deve avere un metodo `remove` che accetta un `element` e:
   - rimuove ogni nodo il cui `element` è uguale all'`element` dato.
   - mantiene i riferimenti `next` e `previous` dei nodi rimanenti collegati correttamente.
   - aggiorna `head`, `tail` e `length` della lista quando necessario.
   - lascia la lista invariata se nessun nodo corrisponde o se la lista è vuota.
1. `DoublyLinkedList` deve avere un metodo `reverse` che inverte l'ordine dei nodi sul posto.
1. `DoublyLinkedList` deve avere un metodo `to_list` che restituisce una lista degli elementi nella lista concatenata, da `head` a `tail`.

class DoublyLinkedList:
    class Node:
        def __init__(self, element, previous=None):
            self.element = element
            self.previous = previous
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None
        self.tail = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element, self.tail)
        if self.is_empty():
            self.head = node
        else:
            self.tail.next = node
        self.tail = node
        self.length += 1

    def remove(self, element):
        current_node = self.head
        while current_node is not None:
            next_node = current_node.next
            if current_node.element == element:
                if current_node.previous is not None:
                    current_node.previous.next = current_node.next
                else:
                    self.head = current_node.next
                if current_node.next is not None:
                    current_node.next.previous = current_node.previous
                else:
                    self.tail = current_node.previous
                self.length -= 1
            current_node = next_node

    def reverse(self):
        current_node = self.head
        while current_node is not None:
            current_node.previous, current_node.next = current_node.next, current_node.previous
            current_node = current_node.previous
        self.head, self.tail = self.tail, self.head

    def to_list(self):
        elements = []
        current_node = self.head
        while current_node is not None:
            elements.append(current_node.element)
            current_node = current_node.next
        return elements
