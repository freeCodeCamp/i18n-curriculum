# --description--

Tuple sind unveränderlich, daher können Sie kein Element zu `releases` hinzufügen. Stattdessen können Sie den Operator `+` verwenden, um ein neues Tuple zu erstellen, das die Elemente von zwei Tuples verbindet:

```py
numbers = (1, 2)
print(numbers + (3, 4)) # (1, 2, 3, 4)
```

`new_version` ist selbst ein Tuple, daher würde `releases + new_version` seine drei Zahlen als separate Elemente hinzufügen. Um es als einzelnes Element hinzuzufügen, verpacken Sie es in ein Tuple mit einem Element. Denken Sie daran, dass ein Tuple mit einem Element ein abschließendes Komma benötigt.

Geben Sie am Ende Ihrer Funktion das Ergebnis der Verbindung von `releases` und einem Tuple zurück, das nur `new_version` enthält.

    sorted_releases = tuple(sorted(releases, reverse=True))

        return 'not a known release', latest

    else:

    if base_version is None:
        base_version = sorted(releases, reverse=True)[0]
    elif base_version not in releases:
        print(f'{base_version} is not a known release')
        return releases

    elif release_type == 'minor':

    elif release_type == 'patch':
        new_version = (major, minor, patch + 1)
    else:
        print(f'{release_type} is not a valid release type')
        return releases

    if new_version in releases:
        print(f'{new_version} has already been released')
        return releases
