# --description--

Nicht jede Abteilung hat garantiert einen `Dept_code`. Sie benötigen einen Fallback für den Fall, dass dieser fehlt, damit die Abteilung trotzdem eine verwendbare ID erhält.

Der Operator `||` gibt seinen linken Wert zurück, wenn dieser `truthy` ist, andernfalls gibt er den rechten Wert zurück.

Zum Beispiel: `a || b` wertet zu `a` aus, wenn `a` `truthy` ist, und fällt auf `b` zurück, wenn `a` `falsy` ist (wie `undefined`, `null` oder `""`).

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

Aktualisieren Sie die `departmentId`-Zuweisung, um den Operator `||` zu verwenden. Verwenden Sie `departmentData.Dept_code` als linken Operanden und den Template-Literal `` `dept-${i + 1}` `` als rechten Operanden. So wird der Fallback verwendet, wann immer `departmentData.Dept_code` falsy ist, einschließlich wenn es `undefined` ist.
