## Python 中的常见错误

- **`SyntaxError`**：当你的代码不符合语法规则时，Python 会引发的错误。例如，代码 `print("Hello there"` 会导致语法错误，错误信息为 `SyntaxError: '(' was never closed`，因为代码缺少一个闭合的括号。
- **`NameError`**：当你尝试访问未定义的变量或函数时，Python 会引发 `NameError`。例如，如果你的代码中有 `print(username)`，但没有先定义 `username` 变量，就会出现错误，错误信息为 `NameError: name 'username' is not defined`。
- **`TypeError`**：当对不合适类型的对象执行操作或调用函数时，Python 会引发此错误。例如，如果你尝试将字符串与数字相加，会得到错误 `TypeError: can only concatenate str (not "int") to str`。
- **`IndexError`**：如果你访问列表或其他序列（如元组和字串）中不存在的索引，就会得到 `IndexError`。例如，在字符串 `Hello world` 中，最后一个字符的索引是 `10`。如果你这样访问字符，`greet = "hello world"; print(greet[11])`，会出现错误，错误信息为 `IndexError: string index out of range`。
- **`AttributeError`**：当你尝试使用某个类型对象不存在的方法或属性时，Python 会引发此错误。例如，在字符串上调用 `.append()`，如 `"hello".append("!")`，会导致错误，错误信息为 `AttributeError: 'str' object has no attribute 'append'`。

## Python 中的良好调试技巧

- **使用 `print` 函数**：在调试时，在代码的各个位置插入 `print()` 语句，帮助你查看变量的值和代码的执行流程。
- **使用 Python 内置调试器 (`pdb`)**：Python 提供了 `pdb` 模块作为标准函数库的一部分用于调试。调用 `pdb.set_trace()` 会暂停执行并打开交互式提示符。你可以输入 `help` 查看命令列表，输入 `whatis` 检查表达式的类型，输入 `continue`（或其别名 `cont` 和 `c`）继续程序执行。
- **利用集成开发环境调试工具**：集成开发环境（IDE）和代码编辑器如 PyCharm 和 VS Code 提供可视化调试工具。例如，VS Code 提供以下功能：
  - **断点**：点击编辑器边栏放置断点（用红点表示），程序执行到此处会暂停。
  - **变量查看和调试控制台**：将鼠标悬停在变量上或查看变量窗格以查看当前值，使用调试控制台交互式计算表达式。
  - **单步控制**：
    - **继续 (<kbd>F5</kbd>)**：继续执行直到下一个断点。
    - **单步跳过 (<kbd>F10</kbd>)**：执行当前行并跳到下一行，不进入函数调用内部。
    - **单步进入 (<kbd>F11</kbd>)**：进入被调用函数内部逐行执行。
    - **单步跳出 (<kbd>Shift</kbd> + <kbd>F11</kbd>)**：执行完当前函数并返回调用处。

## 异常处理

- **`try...except`**：用于执行可能引发异常的代码块。`try` 块是你预期可能出错的代码部分，而 `except` 块捕获指定的异常并在该异常发生时执行。示例如下：

  ```py
  try:
    print(22 / 0)
  except ZeroDivisionError:
    print('You can\'t divide by zero!')
    # You can't divide by zero!
  ```

  你也可以链式使用多个 `except` 块，以处理更多类型的异常：

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

  你也可以通过将多个异常类型放入元组，在单个 `except` 子句中捕获多种异常：

  ```py
  try:
    number = int(input('Enter a number: '))
    result = 10 / number
  except (ValueError, ZeroDivisionError) as e:
    print(f'Error occurred: {e}')
  ```

- **`else` 和 `finally`**：这两个块扩展了 `try...except`。如果没有异常发生，`else` 块会执行。`finally` 块无论是否发生错误都会执行。

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **异常对象**：允许你访问异常本身，以便更好地调试和打印直接的错误信息。要访问异常对象，需要使用 `as` 关键字。示例如下：

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **`raise` 语句**：允许你手动引发异常。当满足某个条件时，可以用它来抛出异常：

  ```py
  def divide(a, b):
      if b == 0:
          raise ZeroDivisionError('You cannot divide by zero')
      return a / b
  ```

  在 `except` 块内不带参数使用 `raise` 会重新引发当前正在处理的异常。这允许你在记录错误或执行清理操作的同时，将异常继续向上传递调用栈：

  ```py
  def process_data(data):
      try:
          result = int(data)
          return result * 2
      except ValueError:
          print('Logging: Invalid data received')
          raise
  ```

- **`assert` 语句**：`assert` 用于调试时检查假设条件，如果条件为假则引发 `AssertionError`。由于 Python 在优化模式（`-O`）下会移除断言，因此断言不应用于必须始终执行的关键输入验证。对于必须检查的条件，应使用显式条件和 `raise`。

## 异常信号

- **自定义异常**：通过继承 `Exception` 创建自定义异常时，`raise` 语句也非常有用。这样你可以抛出带有特定领域逻辑和消息的错误：

  ```py
  class InvalidCredentialsError(Exception):
      def __init__(self, message="Invalid username or password"):
          self.message = message
          super().__init__(self.message)

  def login(username, password):
      stored_username = "admin"
      stored_password = "password123"
      
      if username != stored_username or password != stored_password:
          raise InvalidCredentialsError()
      
      return f"Welcome, {username}!"
  ```

  下面是如何使用带有 `InvalidCredentialsError` 异常的 `login` 函数示例：

  ```py
  # failed login attempt
  try:
      message = login("user", "wrongpassword")
  except InvalidCredentialsError as e:
      print(f"Login failed: {e}")
  else:
      print(message)

  # successful login attempt
  try:
      message = login("admin", "password123")
  except InvalidCredentialsError as e:
      # This block is not executed because the login was successful
      print(f"Login failed: {e}")
  else:
      # The else block runs if the 'try' block completes without an exception
      print(message)
  ```

- **异常链**：`raise` 语句可以与 `from` 关键字一起使用来链式引发异常。使用 `from None` 会抑制原始异常上下文在追踪信息中的显示，而使用 `from e` 则显式记录原始异常作为原因：

  ```py
  def parse_config(filename):
      try:
          with open(filename, 'r') as file:
              data = file.read()
              return int(data)
      except FileNotFoundError:
          raise ValueError('Configuration file is missing') from None
      except ValueError as e:
          raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```
