# --description--

Muitos de vocês já usam computadores há algum tempo. Mas talvez não tenham pensado nas formas mais seguras ou protegidas de fazer login no seu computador.

Se você usa um Mac ou um PC, existem várias maneiras de fazer login no seu computador com segurança.

A primeira coisa que você deve fazer é garantir que seu computador esteja protegido por senha.

Para usuários do Windows, comece abrindo o menu Iniciar e selecionando Configurações. A partir daí, vá para Accounts e depois Sign-in options. Você pode então configurar uma senha para o seu computador.

*Nota: Se você encontrar alguma dificuldade ou estiver usando uma versão diferente do Windows, consulte a documentação oficial da Microsoft ou os recursos de suporte para instruções detalhadas adaptadas à sua versão específica.*

Ao criar sua senha, certifique-se de que ela seja longa e complexa. Você pode usar uma combinação de letras, números e caracteres especiais para torná-la mais segura.

Escolher uma senha fácil como `12345` ou `password` não é uma boa ideia. Eles são fáceis de adivinhar e podem ser facilmente hackeados.

Além disso, não use senhas baseadas em informações pessoais como seu nome, aniversário ou endereço. Esses também são fáceis para hackers adivinharem.

Quando criar sua senha, também é uma boa ideia configurar a autenticação de dois fatores (2FA). A 2FA funciona como uma camada extra de segurança e exige uma segunda forma de verificação para garantir que a pessoa tentando acessar a conta seja realmente o usuário autorizado.

Se você usa Mac, pode clicar no menu Apple e depois ir para Configurações do sistema. De lá, vá para Usuários e grupos e configure uma senha para seu computador.

Alguns computadores Mac vêm com o recurso Touch ID, que é frequentemente considerado mais seguro do que senhas comuns. Esse recurso permite que você faça login no computador usando sua impressão digital.

Para usuários do Windows, o recurso Windows Hello oferece uma forma mais segura de entrar. Ele usa métodos biométricos como reconhecimento facial ou impressões digitais para autenticação, oferecendo uma alternativa às senhas tradicionais.

Depois de terminar esta lição, pesquise esses recursos adicionais de segurança e configure-os para manter seu computador protegido.
