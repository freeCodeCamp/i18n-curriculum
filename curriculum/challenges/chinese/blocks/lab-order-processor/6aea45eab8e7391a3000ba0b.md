# --description--

在本实验中，你将处理电子商务订单并处理过程中出现的错误。

**目标：**实现以下用户需求并通过所有测试以完成实验。

你将处理的数据结构与起始代码中的变量结构相同：

- 一个**订单**是一个字典，包含：
  - `order_id`：一个标识订单的整数。
  - `products`：一个字典列表，每个字典包含一个 `product_id` 和请求的 `quantity`。
  - `discount_code`：一个字串，如果订单没有折扣码则为 `None`。
  - `status`：一个描述订单状态的字串。
- 一个**订单历史**是一个订单列表。
- 一个**库存**是一个字典，其键是产品 ID，值是包含 `product` 名称、库存 `quantity` 和单价 `price` 的字典。
- **折扣码**是一个字典，其键是折扣码，值是折扣率，例如 `0.1` 表示 10% 折扣。

**用户故事：**

1. 你应该有一个名为 `find_order` 的函数，带有两个参数：订单 ID 和订单历史，顺序如是。
1. `find_order` 应该：
   - 返回给定订单历史中 `order_id` 与给定订单 ID 相等的订单。
   - 如果没有订单匹配给定订单 ID，则引发带有消息 `Order ID {order_id} not found in order history.` 的 `ValueError`。
1. 你应该有一个名为 `verify_availability` 的函数，带有两个参数：订单和库存，顺序如是。
1. `verify_availability` 应该：
   - 如果订单中的产品在给定库存中缺失，则引发带有消息 `Product ID {product_id} is not in the inventory.` 的 `ValueError`。
   - 如果请求的产品数量大于给定库存中的数量，则引发带有消息 `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.` 的 `ValueError`。
   - 如果订单中的每个产品都以请求的数量可用，则不引发任何错误。
1. 你应该有一个名为 `get_discount_rate` 的函数，带有两个参数：订单和折扣码，顺序如是。
1. `get_discount_rate` 应该：
   - 如果订单的 `discount_code` 是 `None`，则返回 `0.0`。
   - 如果订单的 `discount_code` 不在给定折扣码中，则引发带有消息 `Invalid discount code: {discount_code}.` 的 `ValueError`。
   - 否则返回订单的 `discount_code` 对应的折扣率。
1. 你应该有一个名为 `process_order` 的函数，带有四个参数：要处理的订单 ID、订单历史、库存和折扣码，顺序如是。
1. `process_order` 应该使用 `find_order`、`verify_availability` 和 `get_discount_rate` 来处理订单，并处理它们引发的 `ValueError`，确保调用 `process_order` 永远不会引发错误。
1. 当给定订单历史中没有订单匹配给定订单 ID 时，`process_order` 应该：
   - 打印 `Error processing order {order_id}: {error message}`，其中 `{error message}` 是 `find_order` 引发的 `ValueError` 的消息，并且不打印其他内容。
   - 保持给定的库存和折扣码不变。
1. 当订单存在但无法完成时，因为产品缺失、请求数量不足或折扣码无效，`process_order` 应该：
   - 打印 `Error processing order {order_id}: {error message}`，其中 `{error message}` 是 `verify_availability` 或 `get_discount_rate` 引发的 `ValueError` 的消息。
   - 将订单的 `status` 设置为 `failed`。
   - 保持给定的库存和折扣码不变。
   - 打印 `Order {order_id} processing completed. Current status: failed`。
1. 当订单可以完成时，`process_order` 应该：
   - 打印 `Order {order_id} total: ${total}`，应用折扣且总额四舍五入到两位小数。
   - 将订单的 `status` 设置为 `processed`。
   - 从给定库存中扣除订购的数量。
   - 从给定折扣码中移除订单使用的折扣码，确保每个折扣码只能使用一次。
   - 打印 `Order {order_id} processing completed. Current status: processed`。

**注意：** 你已获得一个库存、订单历史和折扣码，可以用来测试你的代码。调用你的函数尝试，包括会引发错误的情况，但在运行测试前请注释掉这些调用，否则可能会干扰测试。

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id, order_history, inventory, discount_codes):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
