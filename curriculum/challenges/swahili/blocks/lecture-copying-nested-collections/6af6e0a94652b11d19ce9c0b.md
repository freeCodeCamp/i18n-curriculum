# --description--

Umejifunza kwamba mgawo wa thamani huunda jina lingine na kwamba njia ya kamusi ya `.copy()` huunda nakala ya kina kidogo (shallow copy). Nakala ya kina kidogo ina kamusi ya nje tofauti, lakini vitu vilivyopangwa ndani bado vinashirikiwa. Sasa unajua jinsi ya import moduli, unaweza kutumia moduli ya `copy` ya maktaba ya kawaida ku-copy makusanyo yaliyopangwa ndani pia.

## Kuunda Nakala ya Kina

Kitendakazi cha `copy.deepcopy()` hufanya nakala kwa kurudia makusanyo yaliyopangwa ndani. Kwa kamusi inayojumuisha orodha, huunda kamusi mpya ya nje na orodha tofauti iliyopangwa ndani:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
deep_copy = copy.deepcopy(original)

print(deep_copy == original) # True
print(deep_copy is original) # False
print(deep_copy['items'] is original['items']) # False

deep_copy['items'].append('fruit')
print(original['items']) # ['bread', 'cheese']
print(deep_copy['items']) # ['bread', 'cheese', 'fruit']
```

Kamusi hizo zina maudhui sawa mwanzoni, lakini kamusi ya nje wala orodha iliyopangwa ndani hazishirikiani kati yao. Kuongeza kwenye orodha iliyonakiliwa haufanyi orodha ya awali kubadilika.

## Kulinganisha Mgawo wa Thamani, Nakala ya Kina Kidogo, na Nakala ya Kina

Tufanye aina zote tatu kutoka kwa kamusi ile ile:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
alias = original
shallow_copy = original.copy()
deep_copy = copy.deepcopy(original)

print(alias is original) # True
print(shallow_copy is original) # False
print(deep_copy is original) # False

print(alias['items'] is original['items']) # True
print(shallow_copy['items'] is original['items']) # True
print(deep_copy['items'] is original['items']) # False
```

Tukiendelea na vitu hivi, badilisha kipengele cha ngazi ya juu kupitia kila jina:

```python
alias['name'] = 'Picnic'
shallow_copy['name'] = 'Snack'
deep_copy['name'] = 'Dinner'

print(original['name']) # Picnic
print(alias['name']) # Picnic
print(shallow_copy['name']) # Snack
print(deep_copy['name']) # Dinner
```

Jina lingine (alias) linarejelea kamusi ya awali, hivyo kuweka thamani kupitia `alias` hubadilisha kamusi hiyo. Kila nakala ina kamusi yake ya nje, hivyo kubadilisha kipengele cha `name` huathiri nakala hiyo tu.

Ifuatayo, badilisha orodha zilizopangwa ndani:

```python
alias['items'].append('water')
shallow_copy['items'].append('fruit')
deep_copy['items'].append('soup')

print(original['items']) # ['bread', 'cheese', 'water', 'fruit']
print(alias['items']) # ['bread', 'cheese', 'water', 'fruit']
print(shallow_copy['items']) # ['bread', 'cheese', 'water', 'fruit']
print(deep_copy['items']) # ['bread', 'cheese', 'soup']
```

Kamusi ya awali, jina lake lingine, na nakala ya kina kidogo zote zinarejelea orodha ile ile. Mabadiliko kupitia rejea yoyote kati ya hizo yanaonekana kwa zingine. Nakala ya kina ina orodha yake, hivyo mabadiliko yake hubaki tofauti.

Hii pia hufanya kazi na kamusi zilizopangwa ndani ya orodha:

```python
import copy

original = {'meals': [{'name': 'Lunch', 'items': ['bread']}]}
deep_copy = copy.deepcopy(original)
deep_copy['meals'][0]['items'].append('fruit')

print(original['meals'][0]['items']) # ['bread']
print(deep_copy['meals'][0]['items']) # ['bread', 'fruit']
```

Hapa, `deepcopy()` hufanya nakala ya kamusi ya nje, orodha ya `meals`, kamusi ndani ya orodha hiyo, na orodha yake ya `items`. Mfano unatumia kamusi na orodha zilizojengwa ndani; nakala ya kina haimaanishi kila kitu cha Python kinanakiliwa.

Tumia mgawo wa thamani unapohitaji jina lingine kwa kitu kile kile. Tumia nakala ya kina kidogo unapohitaji mkusanyo wa nje tofauti na kushiriki vitu vilivyopangwa ndani ni sawa. Tumia nakala ya kina unapotaka mabadiliko kwenye makusanyo yaliyopangwa ndani yasibadilishe makusanyo ya awali.
