# --description--

طريقة `__repr__` هي طريقة خاصة من المفترض أن تُرجع تمثيلًا كسلسلة نصية للكائن يمكن استخدامها لإنشائه.

على سبيل المثال، يجب أن تُرجع طريقة `__repr__` الخاصة بـ `Employee('Charlie', 'developer')` السلسلة النصية `Employee('Charlie', 'developer')`، وهي نفس السلسلة المستخدمة لإنشاء الكائن.

إذا وضعت علامات اقتباس حول كل قيمة، فإن النتيجة تتعطل عندما تحتوي القيمة على اقتباس. على سبيل المثال، لموظف اسمه `O'Reilly` بمستوى `junior`، ستحصل على `Employee('O'Reilly', 'junior')`، وهذا غير صالح لأن الفاصلة العليا تغلق السلسلة النصية مبكرًا.

الدالة المدمجة `repr()` في Python تُرجع تمثيلًا نصيًا لقيمة. بالنسبة للسلاسل النصية، تضيف علامات الاقتباس وتهرب أي أحرف تحتاج لذلك:

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

داخل سلسلة f، يمكنك إضافة `!r` بعد التعبير لتطبيق `repr()` عليه:

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

أضف إلى صنف `Employee` طريقة `__repr__` بمعلمة `self`. اجعلها تُرجع سلسلة نصية يمكن استخدامها لإنشاء الكائن، باستخدام `!r` على `self.name` و`self.level` بحيث تُحفظ أي علامات اقتباس أو شرطات مائلة عكسية.
