# --description--

`departmentEntries` 中的每个条目本身是一个形如 `[key, value]` 的小数组。你可以使用数组解构来将它们一行内解包到具名变量中，而不是通过索引（`entry[0]`、`entry[1]`）访问它们。

将 `departmentEntries[i]` 解构为 `departmentName` 和 `departmentData`。然后使用两个独立的
`console.log()` 语句：一个用于日志 `departmentName`，另一个用于日志 `departmentData`。

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, 'log');
const getLogs = () => globalThis.spy.calls.map((call) => call?.[0]);
```

```js
globalThis.spy.restore();
delete globalThis.spy;
```
