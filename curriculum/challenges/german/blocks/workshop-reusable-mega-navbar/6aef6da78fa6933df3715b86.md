# --description--

Das Letzte, was Sie tun müssen, ist, den `isOpen`-Status zu aktualisieren, wenn auf die `Apps`-Schaltfläche geklickt wird.

In React reagieren Sie auf Ereignisse, indem Sie einer Ereignis-Attribut an einem Element eine Funktion übergeben. Diese Attribute werden in CamelCase geschrieben, daher wird ein Klick mit `onClick` behandelt:

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

Beachten Sie, dass `onClick` eine Funktion erhält. React ruft diese Funktion jedes Mal auf, wenn die Schaltfläche geklickt wird. Das Aufrufen der Setter-Funktion mit einem neuen Wert aktualisiert den Status, und React rendert dann die Komponente mit diesem neuen Wert neu.

Um einen Boolean-Status zwischen `true` und `false` umzuschalten, können Sie der Setter-Funktion das Gegenteil seines aktuellen Werts mit dem logischen NICHT-Operator (`!`) übergeben.

Fügen Sie dem `button`-Element ein `onClick`-Attribut hinzu. Geben Sie ihm eine Pfeilfunktion, die `setIsOpen` mit dem Gegenteil von `isOpen` aufruft.

Klicken Sie auf die `Apps`-Schaltfläche, um das `sub-menu` zu öffnen und zu schließen.

Damit ist Ihre `Navbar`-Komponente fertig!

# --hints--

Das Klicken auf die `Apps`-Schaltfläche sollte das `aria-expanded`-Attribut auf `"true"` setzen und die Klasse `sub-menu--open` zum `sub-menu` hinzufügen.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

Das zweite Klicken auf die `Apps`-Schaltfläche sollte das `aria-expanded`-Attribut wieder auf `"false"` setzen und die Klasse `sub-menu--open` vom `sub-menu` entfernen.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
