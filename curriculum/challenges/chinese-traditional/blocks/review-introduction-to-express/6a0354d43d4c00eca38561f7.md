## 什麼是 Express.js？

- **Express**：基於 Node.js 的極簡且彈性的網頁框架，讓建置網頁伺服器和 API 更簡單。
- **安裝 Express**：`npm install express`
- **用 Express 可以建置**：網頁應用、RESTful API、SPA 後端、中介層密集的服務，以及任何使用 HTTP 的伺服端應用。
- **中介層**：在接收請求和送出回應之間執行的程式碼。用於錯誤處理、輸入驗證、修改請求或回應資料等。可串接多個中介層函式。
- **外掛程式**：擴充 Express 的外部 npm 模組，通常實作為中介層。

## 建立基本的 Express 應用程式

```javascript
const express = require("express");
const app = express();
const port = 3000;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

- `require("express")` — 載入 Express 程式庫。
- `express()` — 工廠函式，創建並回傳新的 Express 應用程式實體。
- `app` — 主要伺服器物件，能使用 `.get()`、`.post()` 和 `.listen()` 等方法。
- `port` — 應用程式監聽的網路端點。埠號 `3000` 是區域開發常用。
- `app.listen(port, callback)` — 啟動伺服器並開始監聽進來的 HTTP 請求。

## Express 中的路由

- **路由**：告訴應用程式當客戶端以特定 HTTP 方法請求特定 URL 時，如何回應的規則。
- **路由方法**：`app.get()`、`app.post()`、`app.put()`、`app.delete()` — 各自處理對應 HTTP 方法的請求。
- **靜態路由路徑**：固定的 URL，如 `/home` 或 `/menu/drinks`。
- **動態路由路徑（路由參數）**：URL 中的佔位符，用 `:` 為前綴，例如 `/post/:postId`。
- **`req.params`**：包含從 URL 捕捉的動態值的物件。例如，對 `/post/42` 的請求會得到 `req.params.postId === "42"`。

### 路由處理常式

- **路由處理常式** 是當請求符合路由時執行的回呼函式 `(req, res) => { ... }`。
- `req` — 包含關於進來請求的資訊（參數、查詢字串、標頭、主體）。
- `res` — 用來送出回應給客戶端。

## 回應方法

| 方法 | 功能說明 |
| --- | --- |
| `res.send()` | 傳送回應 — 純文字、HTML、JSON 或二進位資料。 |
| `res.json()` | 傳送 JSON 回應；自動將 JavaScript 物件轉換。 |
| `res.status(code)` | 設定 HTTP 狀態碼；通常與 `res.send()` 或 `res.json()` 串接使用。 |
| `res.redirect(url)` | 導向客戶端至不同 URL。 |
| `res.render(view, data)` | 呈現模板引擎視圖並傳送產生的 HTML。 |

## 使用 `app.route()` 串鏈路由處理常式

- `app.route(path)` 將同一路徑的多個 HTTP 方法處理常式群組起來，避免重複路徑。

```javascript
app
  .route("/user")
  .get((req, res) => { res.send("Fetching user data"); })
  .post((req, res) => { res.send("Creating a user"); })
  .put((req, res) => { res.send("Updating the user"); })
  .delete((req, res) => { res.send("Deleting the user"); });
```

## 使用 `express.Router()` 進行模組化路由

- `express.Router()` 創建路由器物件 — 類似迷你 Express 應用程式 — 你可以在上面定義路由，然後掛載到主應用程式。
- 使用 `app.use(path, router)` 掛載路由器。路由器內的路由相對於掛載路徑。
- **好處**：分離關注點、保持主檔案整潔，並讓路由可重用且更易擴充。

```javascript
// userRoutes.js
const express = require("express");
const router = express.Router();
router.get("/", (req, res) => { res.send("List of users"); });
router.get("/:id", (req, res) => { res.send(`User ${req.params.id}`); });
module.exports = router;

// app.js
app.use("/users", userRoutes); // mounts the router at /users
```

## 提供靜態檔案服務

- **靜態檔案**：像是圖片、CSS 和客戶端 JavaScript 等資產，直接提供而不經伺服器端處理。
- `express.static(directory)` — 內建中介層，從指定資料夾提供檔案。
- 若請求的檔案不存在，Express 會自動回應 404。
- 不需要為單一靜態檔案定義路由。

```javascript
app.use(express.static(path.join(__dirname, "public")));
```

- 你可以透過多次呼叫 `app.use()`，並選用掛載路徑，從多個目錄提供服務：

```javascript
app.use(express.static(path.join(__dirname, "public")));
app.use("/images", express.static(path.join(__dirname, "images")));
```
