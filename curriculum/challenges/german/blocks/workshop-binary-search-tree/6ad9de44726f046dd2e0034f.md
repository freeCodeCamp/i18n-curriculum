# --description--

Wenn `key` weder kleiner noch größer als `node.key` ist, haben Sie den Knoten gefunden, der gelöscht werden soll. Wie Sie ihn löschen, hängt von seinen Kindern ab.

Hat der Knoten kein linkes Kind, kann sein rechtes Kind seinen Platz einnehmen. Das gilt auch für Knoten ohne Kinder: In diesem Fall ist `node.right` ebenfalls `None`, sodass der Knoten durch `None` ersetzt wird.

Fügen Sie Ihrer zweiten `if`-Anweisung eine `else`-Klausel hinzu. Fügen Sie darin eine `if`-Anweisung hinzu, die prüft, ob `node.left` `None` ist, und geben Sie daraus `node.right` zurück.
