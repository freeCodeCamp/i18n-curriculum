## Python 常見錯誤

- **`SyntaxError`**：當你的程式碼不符合語法規則時，Python 會引發的錯誤。例如，程式碼 `print("Hello there"` 會導致語法錯誤，錯誤訊息為 `SyntaxError: '(' was never closed`，因為程式碼缺少了閉合的括號。
- **`NameError`**：當你嘗試存取尚未定義的變數或函式時，Python 會引發 `NameError`。例如，如果你的程式碼中有 `print(username)`，但沒有先定義 `username` 變數，就會得到錯誤訊息 `NameError: name 'username' is not defined`。
- **`TypeError`**：當對不適合的型別物件執行操作或函式時，Python 會引發此錯誤。例如，嘗試將字串與數字相加時，會得到錯誤訊息 `TypeError: can only concatenate str (not "int") to str`。
- **`IndexError`**：如果你存取列表或其他序列（如元組和字串）中不存在的索引，會得到 `IndexError`。例如，在字串 `Hello world` 中，最後一個字元的索引是 `10`。如果你嘗試這樣存取字元：`greet = "hello world"; print(greet[11])`，會得到錯誤訊息 `IndexError: string index out of range`。
- **`AttributeError`**：當你嘗試使用某個物件型別不存在的方法或屬性時，Python 會引發此錯誤。例如，對字串呼叫 `.append()`，像是 `"hello".append("!")`，會導致錯誤訊息 `AttributeError: 'str' object has no attribute 'append'`。

## Python 偵錯技巧

- **使用 `print` 函式**：在偵錯時，在程式碼的不同位置插入 `print()` 陳述式，有助於你查看變數的值和程式流程。
- **使用 Python 內建除錯器 (`pdb`)**：Python 提供 `pdb` 模組作為標準程式庫的一部分來進行除錯。呼叫 `pdb.set_trace()` 會暫停執行並開啟互動式提示。你可以輸入 `help` 列出指令，`whatis` 檢查表達式的型別，還有 `continue`（或其別名 `cont` 和 `c`）來繼續程式執行。
- **利用整合開發環境（IDE）除錯工具**：像 PyCharm 和 VS Code 這類整合開發環境與程式碼編輯器提供視覺化除錯工具。例如，VS Code 提供以下功能：
  - **中斷點**：點擊編輯器邊欄放置中斷點（以紅點表示），程式執行會在此暫停。
  - **變數檢視與除錯主控台**：暫留在變數上或檢視變數面板以查看當前值，並使用除錯主控台互動式評估表達式。
  - **步進控制**：
    - **繼續 (<kbd>F5</kbd>)**：繼續執行直到下一個中斷點。
    - **跳過 (<kbd>F10</kbd>)**：執行當前語句並移至下一行，不會進入函式呼叫。
    - **進入 (<kbd>F11</kbd>)**：進入被呼叫的函式內部逐行執行。
    - **跳出 (<kbd>Shift</kbd> + <kbd>F11</kbd>)**：完成目前函式並返回呼叫端。

## 例外處理

- **`try...except`**：用來執行可能會引發例外的程式區塊。`try` 區塊是你預期可能發生錯誤的地方，而 `except` 區塊會捕捉指定的例外並在該錯誤發生時執行。範例如下：

  ```py
  try:
    print(22 / 0)
  except ZeroDivisionError:
    print('You can\'t divide by zero!')
    # You can't divide by zero!
  ```

  你也可以串接多個 `except` 區塊，以處理更多種類的例外：

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

  你也可以在單一個 `except` 子句中用元組將多種例外類型群組起來捕捉：

  ```py
  try:
    number = int(input('Enter a number: '))
    result = 10 / number
  except (ValueError, ZeroDivisionError) as e:
    print(f'Error occurred: {e}')
  ```

- **`else` 和 `finally`**：這些區塊是 `try...except` 的延伸。如果沒有發生例外，會執行 `else` 區塊。`finally` 區塊無論是否有錯誤都會執行。

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **例外物件**：讓你能存取例外本身，方便除錯和直接列印錯誤訊息。要存取例外物件，需要使用 `as` 關鍵字。範例如下：

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **`raise` 陳述式**：允許你手動引發例外。當某個條件成立時，你可以用它來丟出例外：

  ```py
  def divide(a, b):
      if b == 0:
          raise ZeroDivisionError('You cannot divide by zero')
      return a / b
  ```

  在 `except` 區塊內使用不帶引數的 `raise`，會重新引發目前正在處理的例外。這讓你可以在記錄錯誤或執行清理後，仍將例外往上層堆疊傳遞：

  ```py
  def process_data(data):
      try:
          result = int(data)
          return result * 2
      except ValueError:
          print('Logging: Invalid data received')
          raise
  ```

- **`assert` 述語**：`assert` 述語在偵錯時用來檢查假設，當條件為假時會引發 `AssertionError`。由於 Python 在最佳化模式（`-O`）下會移除所有 assert，因此 assert 不應用於那些必須始終執行的重要輸入驗證。對於這類必要檢查，請改用明確的條件判斷和 `raise`。

## 例外訊號

- **自訂例外**：當你繼承 `Exception` 類別創建自訂例外時，`raise` 陳述式也很有用。這讓你能以特定領域邏輯和訊息丟出錯誤：

  ```py
  class InvalidCredentialsError(Exception):
      def __init__(self, message="Invalid username or password"):
          self.message = message
          super().__init__(self.message)

  def login(username, password):
      stored_username = "admin"
      stored_password = "password123"
      
      if username != stored_username or password != stored_password:
          raise InvalidCredentialsError()
      
      return f"Welcome, {username}!"
  ```

  以下示範如何搭配 `InvalidCredentialsError` 例外使用 `login` 函式：

  ```py
  # failed login attempt
  try:
      message = login("user", "wrongpassword")
  except InvalidCredentialsError as e:
      print(f"Login failed: {e}")
  else:
      print(message)

  # successful login attempt
  try:
      message = login("admin", "password123")
  except InvalidCredentialsError as e:
      # This block is not executed because the login was successful
      print(f"Login failed: {e}")
  else:
      # The else block runs if the 'try' block completes without an exception
      print(message)
  ```

- **例外串鏈**：`raise` 陳述式可搭配 `from` 關鍵字串鏈例外。使用 `from None` 可抑制原始例外背景在追蹤堆疊中的顯示，而 `from e` 則明確記錄原始例外為原因：

  ```py
  def parse_config(filename):
      try:
          with open(filename, 'r') as file:
              data = file.read()
              return int(data)
      except FileNotFoundError:
          raise ValueError('Configuration file is missing') from None
      except ValueError as e:
          raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```
