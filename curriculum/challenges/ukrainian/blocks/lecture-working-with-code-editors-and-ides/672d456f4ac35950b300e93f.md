# --description--

Ви, ймовірно, вже знайомі з деякими базовими комбінаціями клавіш, які успадковані від вашої операційної системи. Комбінації, як-от <kbd>Ctrl</kbd> + <kbd>S</kbd> (Windows/Linux) або <kbd>Cmd</kbd> + <kbd>S</kbd> (macOS) для збереження, <kbd>Ctrl</kbd> + <kbd>C</kbd> або <kbd>Cmd</kbd> + <kbd>C</kbd> для копіювання, і <kbd>Ctrl</kbd> + <kbd>V</kbd> або <kbd>Cmd</kbd> + <kbd>V</kbd> для вставлення, працюють у VS Code.

Але є кілька, які специфічні для застосунку і все одно можуть підвищити вашу продуктивність. Варто зазначити, що деякі з цих скорочень можуть відрізнятися залежно від операційної системи.

Наприклад, <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> запустить налаштований форматер (наприклад, Prettier для проєкту на JavaScript) для поточного відкритого файлу.

Використовуйте <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (Windows/Linux) або <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (macOS), щоб шукати текстовий вміст у всіх файлах вашої робочої області. Потім використовуйте <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (Windows/Linux) або <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (macOS), якщо хочете виконати пошук і заміну.

Якщо потрібно видалити рядок, <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (Windows/Linux) або <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (macOS) це зробить.

Потрібно більше місця для всього вашого коду? <kbd>Ctrl</kbd> + <kbd>B</kbd> (Windows/Linux) або <kbd>Cmd</kbd> + <kbd>B</kbd> (macOS) приховає бічну панель, де знаходяться список файлів і меню розширень.

Або, можливо, ви просто не бачите свій код? <kbd>Ctrl</kbd> + <kbd>Plus</kbd> (Windows/Linux) або <kbd>Cmd</kbd> + <kbd>Plus</kbd> (macOS) збільшить масштаб редактора, а <kbd>Ctrl</kbd> + <kbd>Minus</kbd> (Windows/Linux) або <kbd>Cmd</kbd> + <kbd>Minus</kbd> (macOS) зменшить його.

Ще одна корисна функція у VS Code — редагування кількох рядків одночасно, що дозволяє вносити зміни одразу в кілька рядків. Наприклад, ви можете розмістити кілька курсорів, використовуючи <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> і <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Windows), <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> і <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Linux), або <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Down</kbd> і <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Up</kbd> (macOS), щоб розширити курсор на послідовні рядки. Також можна натиснути і утримувати <kbd>Alt</kbd> (Windows/Linux) або <kbd>Option</kbd> (macOS) і натиснути мишею, щоб додати курсори на окремих рядках там, де потрібно. Після розміщення курсорів усе, що ви вводите або видаляєте, застосовується одночасно до всіх цих місць, що значно економить час при роботі з повторюваним кодом.

Нарешті, якщо ви забудете будь-яку з цих комбінацій, завжди можна натиснути <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows/Linux) або <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS), щоб відкрити палітру команд і вибрати все, що вам потрібно.
