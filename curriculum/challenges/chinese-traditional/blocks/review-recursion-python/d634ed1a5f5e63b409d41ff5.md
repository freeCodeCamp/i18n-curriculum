# --description--

- 遞迴是一種程式設計概念，允許你重複呼叫函式直到達到基底情況。

這是一個計算數字階乘的遞迴函式（程式）範例：

```py
def find_factorial(n):
    if n == 0:
        return 1
    return n * find_factorial(n - 1)
```

在上述範例中，`find_factorial` 函式會遞迴呼叫直到 `n` 等於 `0`。當 `n` 是 `0` 時，達到基底情況，函式傳回 `1`。接著函式傳回 `n` 與遞迴呼叫 `find_factorial(n - 1)` 結果的乘積。

- 遞迴讓你能處理深度未知的結構，例如深度巢狀的字典和列表，或檔案樹。
- 呼叫堆疊用來追蹤遞迴函式中的函式呼叫。每次函式被呼叫時，會加入呼叫堆疊。當達到基底情況時，函式呼叫會從堆疊中移除。
- 你應該謹慎定義基底情況，否則函式會持續呼叫自己直到 Python 引發 `RecursionError`。
- 遞迴對解決數學問題（如階乘和費氏數列）、遍歷樹和圖，以及產生排列組合非常有用。
