# --description--

`__str__` メソッドの最後で、次の形式でメールの要約を返してください。

```md
[status] From: sender | Subject: subject
```

ここで `status` はメールのステータス、`sender` は送信者の名前、`subject` はメールの件名です。

複数の要約が縦に並んで出力される場合、各部分がテーブルの列のように揃っていると読みやすくなります。`Read` は `Unread` より短く、送信者名の長さも異なるため、フォーマット指定子を使ってそれぞれに固定幅を設定してください。

- `status` を幅 `6` で左寄せにしてください。
- 送信者名を幅 `10` で左寄せにしてください。

例えば、件名が `Hello` の `Alice` からの既読メールはこのように表示されます：

```md
[Read  ] From: Alice      | Subject: Hello
```

# --hints--

`__str__` メソッドは、`status` を幅 `6` で左寄せし、送信者名を幅 `10` で左寄せしたメールの要約を返す必要があります。

```js
({
    test: () => runPython(`
        _email = Email(User('Alice'), User('Bob'), 'Hello', 'How are you?')
        assert str(_email) == '[Unread] From: Alice      | Subject: Hello'
        _email.read = True
        assert str(_email) == '[Read  ] From: Alice      | Subject: Hello'
    `)
})
```
