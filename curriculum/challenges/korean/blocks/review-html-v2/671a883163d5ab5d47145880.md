## HTML 기본

- **HTML의 역할**: HTML(Hypertext Markup Language)은 웹 구조의 기초로, 웹 페이지의 요소를 정의합니다.
- **HTML 요소**: 페이지의 내용을 나타내는 데 사용됩니다. 대부분은 여는 태그와 닫는 태그로 구성됩니다(예: `<h1></h1>`, `<p></p>`).
- **HTML 구조**: HTML은 `head`와 `body`로 구성되며, 메타데이터, 스타일, 콘텐츠가 구조화됩니다.
- **일반적인 HTML 요소**: 제목(`<h1>` - `<h6>`), 단락(`<p>`), 그리고 div 컨테이너(`<div>`).
- **`div` 요소**: `div` 요소는 의미론적 의미가 없는 일반적인 HTML 요소입니다. 다른 HTML 요소를 담는 일반 컨테이너로 사용됩니다.
- **Void 요소**: 닫는 태그가 없는 요소(예: `<img>`).
- **속성**: 요소에 메타데이터와 동작을 추가합니다.

## 식별자와 그룹화

- **ID**: 고유한 요소 식별자입니다.
- **클래스**: 스타일과 동작을 위해 요소를 그룹화합니다.

## 보일러플레이트와 인코딩

- **HTML 보일러플레이트**: 웹 페이지의 기본 구조로, `DOCTYPE`, `html`, `head`, `body` 요소를 포함합니다. HTML 문서의 시작점으로 사용해야 합니다.
- **UTF-8 문자 인코딩**: 모든 문자가 올바르게 표시되도록 보장합니다.

## 시맨틱 HTML의 중요성

- **제목 요소의 구조적 계층**: 콘텐츠의 구조적 계층을 유지하려면 올바른 제목 요소를 사용하는 것이 중요합니다. `h1` 요소는 가장 높은 수준의 제목이고 `h6` 요소는 가장 낮은 수준의 제목입니다.
- **시맨틱 HTML 요소**: 이 요소들은 콘텐츠 구조에 의미를 부여합니다. 예시는 다음과 같습니다:
  - `<header>`: 소개 콘텐츠를 나타냅니다.
  - `<nav>`: 내비게이션 링크를 포함합니다.
  - `<article>`: 독립적인 콘텐츠를 나타냅니다.
  - `<section>`: 문서 내 관련 콘텐츠를 그룹화합니다.
  - `<footer>`: 섹션이나 문서의 푸터를 정의합니다.
  - `<blockquote>`: 다른 출처에서 인용한 부분을 나타낼 때 사용합니다. `cite` 속성에 출처를 지정하세요.
  - `<q>`: 짧은 인라인 인용문을 나타낼 때 사용합니다.

## HTML 폼 요소와 속성

### 폼

- **`form` 요소**: 사용자 입력을 위한 HTML 폼을 생성할 때 사용합니다.
- **일반 입력 유형**:
  - `text`, `email`, `radio`, `checkbox`, `number`.
- **`action` 속성**: 폼 데이터가 전송될 URL을 지정할 때 사용합니다.
- **`method` 속성**: 폼 데이터를 전송할 때 사용할 HTTP 메서드를 지정합니다. 가장 일반적인 메서드는 `GET`과 `POST`입니다.

```html
<form method="value-goes-here" action="url-goes-here">
  <!-- inputs go inside here -->
</form>
```

- **`input` 요소**: 사용자 입력을 받는 입력 필드를 만드는 데 사용합니다.
- **`type` 속성**: 입력 필드의 유형을 지정하는 데 사용합니다. 예: `text`, `email`, `number`, `radio`, `checkbox`.
- **`placeholder` 속성**: 입력 필드에 무엇을 입력해야 하는지 사용자에게 힌트를 보여주는 데 사용합니다.
- **`value` 속성**: 입력값을 지정하는 데 사용합니다. 입력 필드의 유형이 `button`이면 `value` 속성으로 버튼 텍스트를 설정할 수 있습니다.
- **`name` 속성**: 입력 필드에 이름을 지정하는 데 사용하며, 폼 데이터를 제출할 때 키로 쓰입니다. 라디오 버튼에 같은 `name`을 지정하면 하나로 묶여, 그룹 안에서 한 번에 하나의 옵션만 선택할 수 있습니다.
- **`size` 속성**: 사용자가 입력할 때 화면에 보이는 문자 수를 정하는 데 사용합니다.
- **`min` 속성**: `number` 같은 입력 유형에서 입력 필드에 허용되는 최솟값을 지정할 때 사용할 수 있습니다.
- **`max` 속성**: `number` 같은 입력 유형에서 입력 필드에 허용되는 최댓값을 지정할 때 사용할 수 있습니다.
- **`required` 속성**: 폼을 제출하기 전에 입력 필드를 반드시 채워야 한다고 지정하는 데 사용합니다.

:::interactive_editor

```html
<!-- Text input -->
<input 
  type="text"
  id="name"
  name="name"
  placeholder="e.g. Quincy Larson"
  size="20"
  required
/>

<!-- Number input -->
<input 
  type="number"
  id="quantity"
  name="quantity"
  min="2"
  max="10"
/>

<!-- Button -->
<input type="button" value="Show Alert" />
```

:::

- **`label` 요소**: 입력 필드에 대한 레이블을 생성할 때 사용합니다.
- **`for` 속성**: 레이블이 어떤 입력 필드에 해당하는지 지정할 때 사용합니다.

:::interactive_editor

```html
<form action="">
  <label for="email">Email Address: </label>
  <input type="email" id="email" />
</form>
```

:::

- **`button` 요소**: 클릭 가능한 버튼을 생성할 때 사용합니다. 버튼은 `type` 속성을 가질 수 있으며, 활성화 시 버튼의 동작을 제어합니다.

:::interactive_editor

```html
<button type="submit">Submit Form</button>
```

:::

- **`fieldset` 요소**: 관련 입력들을 그룹화합니다.
- **`legend` 요소**: 입력 그룹을 설명하는 캡션을 추가합니다.

:::interactive_editor

```html
<!-- Radio group -->
<fieldset>
  <legend>Was this your first time at our hotel?</legend>

  <input id="yes-option" type="radio" name="hotel-stay" value="yes" />
  <label for="yes-option">Yes</label>

  <input id="no-option" type="radio" name="hotel-stay" value="no" />
  <label for="no-option">No</label>
</fieldset>

<!-- Checkbox group -->
<fieldset>
  <legend>
    Why did you choose to stay at our hotel? (Check all that apply)
  </legend>

  <input type="checkbox" id="location" name="location" value="location" />
  <label for="location">Location</label>

  <input type="checkbox" id="price" name="price" value="price" />
  <label for="price">Price</label>
</fieldset>
```

:::

## HTML 표 요소와 속성 다루기

- **표 요소**: HTML 표를 만듭니다.
- **표 헤드(`thead`) 요소**: 표의 헤더 콘텐츠를 그룹화합니다.
- **표 행(`tr`) 요소**: 표에 행을 만듭니다.
- **표 헤더 셀(`th`) 요소**: 표의 헤더 셀을 만듭니다.
- **표 본문(`tbody`) 요소**: 표의 본문 콘텐츠를 그룹화합니다.
- **표 데이터 셀(`td`) 요소**: 표의 데이터 셀을 만듭니다.
- **표 푸터(`tfoot`) 요소**: 표의 푸터 콘텐츠를 그룹화합니다.
- **`caption` 요소**: HTML 표의 제목을 추가합니다.
- **`colspan` 속성**: 표 셀이 차지할 열 수를 지정합니다.

:::interactive_editor

```html
<table>
  <caption>Exam Grades</caption>

  <thead>
    <tr>
      <th>Last Name</th>
      <th>First Name</th>
      <th>Grade</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Davis</td>
      <td>Alex</td>
      <td>54</td>
    </tr>

    <tr>
      <td>Doe</td>
      <td>Samantha</td>
      <td>92</td>
    </tr>

    <tr>
      <td>Rodriguez</td>
      <td>Marcus</td>
      <td>88</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <td colspan="2">Average Grade</td>
      <td>78</td>
    </tr>
  </tfoot>
</table>
```

:::

## 접근성

- **웹 콘텐츠 접근성 지침**: 웹 콘텐츠 접근성 지침(WCAG)은 장애가 있는 사람들이 웹 콘텐츠에 더 쉽게 접근할 수 있도록 만든 지침 모음입니다. WCAG의 네 가지 원칙은 인지 가능(Perceivable), 조작 가능(Operable), 이해 가능(Understandable), 견고함(Robust)을 의미하는 POUR입니다.
- **좋은 `alt` 텍스트의 중요성**: 이미지에 대해 `alt` 속성을 사용해 텍스트 대체물을 제공해야 합니다. 이는 보조 기술이 이미지 내용을 이해하는 데 도움을 줍니다.
- **좋은 링크 텍스트의 중요성**: 사용자가 링크의 목적을 이해할 수 있도록 설명적인 링크 텍스트를 사용해야 합니다.
