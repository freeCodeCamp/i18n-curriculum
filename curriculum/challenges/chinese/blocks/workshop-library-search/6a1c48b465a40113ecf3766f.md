# --description--

如果用户尝试用空字段进行查找，你的函数现在会停止运行并抛出误差。

但是如果用户查找的书不在你的 `library` 数组中呢？你也需要处理那个异常。

在你的第一个 `if` 语句下面，创建第二个 `if` 语句。在条件中，使用逻辑非操作符（`!`）和 `.includes()` 方法来检查 `library` 数组是否不包含传入函数的 `title`。

在 `if` 语句内部，使用 `throw` 关键字抛出一个 `new Error()`。将表达式 `title + " not found!"` 传入 `Error` 构造函数。
