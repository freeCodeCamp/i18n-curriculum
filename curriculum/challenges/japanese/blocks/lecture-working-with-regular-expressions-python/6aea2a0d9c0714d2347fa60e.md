# --description--

これまでに、`re.search`を使って文字列のどこかにパターンがあるかを探してきました。`re`モジュールには正規表現パターンを扱う他の多くの関数があります。このレッスンでは、その中でも特に便利なものをいくつか学びます。

## `match`関数

`match`関数は`search`と似ていますが、文字列の先頭だけでパターンを探します。文字列の先頭がパターンにマッチするとマッチオブジェクトを返し、そうでなければ`None`を返します。

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

2つ目の例では、文字列に数字が含まれているので`re.search`は見つけます。しかし文字列の先頭が数字ではないため、`re.match`は`None`を返します。

## `fullmatch`関数

パターン`r'\d+:\d+'`は、1つ以上の数字の後にコロン、さらに1つ以上の数字が続くものにマッチします。これは`10:30`のような時間の形です。

ユーザーの入力が時間だけで、それ以外の文字がないかをチェックしたいとします。`re.search`を使うと問題が起きます。

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

これはマッチオブジェクトを返しますが、`10:30pm`は期待される形式に従っていません。なぜなら`re.search`は文字列のどこにでもパターンを探し、マッチの周りの余分な文字を無視するからです。`re.match`も同じ問題があり、`10:30pm`は有効な時間で始まっているからです。

データを検証するときは、通常文字列全体がパターンに従うことを望みます。そのために`fullmatch`関数を使います。これはパターンが文字列全体にマッチした場合のみマッチオブジェクトを返し、そうでなければ`None`を返します。

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## `findall`関数

`search`、`match`、`fullmatch`は最大で1つのマッチしか返しません。文字列中のすべてのマッチを取得したい場合は、`findall`関数を使います。これは見つけたすべてのマッチを文字列のリストで返します。

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

マッチがない場合、`findall`は空のリストを返します。

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## `sub`関数

`sub`関数はパターンにマッチしたすべての部分を別の文字列で置き換えます。パターン、置き換え文字列、検索対象の文字列を受け取り、新しい文字列を返します。

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub`には2つのオプションのパラメータがあります。1つ目は`count`で、置き換えるマッチの数を制限します。

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

2つ目は`flags`です。他の関数と同様に、`sub`も`re.IGNORECASE`のようなフラグを使えます。

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

`count`と`flags`は必ずキーワード引数として渡してください。`re.IGNORECASE`を4番目の位置引数として渡すと、Pythonはそれを`count`の値として扱います。
