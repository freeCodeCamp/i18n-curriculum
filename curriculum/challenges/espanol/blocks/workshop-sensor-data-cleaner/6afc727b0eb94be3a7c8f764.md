# --description--

La función `map()` llama a una función en cada elemento de un iterable y devuelve un iterador con los resultados. Al igual que con `filter()`, puedes pasarle una función lambda:

```py
prices = [10, 20, 30]
discounted = list(map(
    lambda price: price * 0.9,
    prices
))
print(discounted) # [9.0, 18.0, 27.0]
```

Ahora necesitas convertir las lecturas válidas de décimas de grado a grados.

Crea una variable llamada `temperatures`. Asígnale el resultado de pasar a `map()` una función lambda y `valid_readings`, envuelto en una llamada a `list()`. La función lambda debe tomar un parámetro llamado `reading` y devolver `reading` dividido por `10`.

Luego, imprime `temperatures` en lugar de `valid_readings`.
