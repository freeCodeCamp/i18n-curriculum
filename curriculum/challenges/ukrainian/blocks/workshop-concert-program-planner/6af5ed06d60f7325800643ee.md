# --description--

Щоб додати елемент на певну позицію, ви можете використати метод `insert()`. Він приймає індекс, куди слід вставити новий елемент, а потім сам елемент. Елементи, починаючи з цього індексу, зсуваються на одну позицію вправо:

```py
fruits = ['apple', 'banana', 'cherry']
fruits.insert(1, 'blueberry')
print(fruits) # ['apple', 'blueberry', 'banana', 'cherry']
```

Диригент хоче, щоб два слов’янські танці виконувалися один за одним. Використайте `insert()`, щоб додати рядок `Slavonic Dance No. 1` у `pieces` безпосередньо перед `Slavonic Dance No. 8`.
