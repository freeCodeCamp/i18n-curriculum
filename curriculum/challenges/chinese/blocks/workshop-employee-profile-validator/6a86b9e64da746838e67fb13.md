# --description--

`.strip()` 方法会移除字串两端的空白字符。

```python
messy = '  hello world  '
clean = messy.strip()
print(clean)  # Output: hello world
```

你可以将 `.strip()` 和 `.title()` 链式调用，以去除字串两端的空白并将每个单词的首字母大写。每个方法都作用于前一个调用的结果。这里，`.title()` 作用于 `.strip()` 返回的字串：

```python
messy = '  hello world  '
clean = messy.strip().title()
print(clean)  # Output: Hello World
```
