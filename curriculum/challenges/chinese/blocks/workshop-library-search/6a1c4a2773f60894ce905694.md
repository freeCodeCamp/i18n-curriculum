# --description--

对于高级的调试，你可以使用 `debugger` 语句来暂停你的 JavaScript 执行并检查你的程序。

在你的 `catch` 块内，紧接着 `console.error()` 语句下面，添加一个 `debugger;` 语句。

**注意：** 打开浏览器的开发者工具后，查找一本不存在的书或将输入留空并点击查找。产生的错误会进入 `catch` 块，执行将在 `debugger;` 语句处暂停。
