# --interactive--

**注意**：いくつかのインタラクティブな例では、まだ学んでいないCSSが使われている場合があります。コードのすべてを理解しようと心配しないでください。これらの例の目的は、デザインコンセプトのプレビューを見せて、仕組みをよりよく理解してもらうことです。プレビューを見るには、インタラクティブエディターを有効にしてください。

ウェブデザインには、トップナビゲーションバー、サイドバー、フッターなど、さまざまな種類のナビゲーション補助があります。しかし、サイトが複雑で階層が深い場合は、パンくずリストの使用を検討するとよいでしょう。

パンくずリストは、ユーザーがサイトの階層のどこにいるかを示すナビゲーション補助です。以下は、架空の電子機器サイトのパンくずリストの例です。

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="breadcrumbs">
  Home / Electronics / Phones / Smartphone XYZ
</div>
```

```css
.breadcrumbs {
  font-size: 0.9rem;
  color: #555;
  margin: 1rem 0;
}
```

:::

ほとんどのウェブサイトでは、パンくずリストはページの上部に表示され、現在のページがサイト構造のどこに位置しているかを示します。この例では、`Smartphone XYZ` という商品は `Phones` カテゴリの中にあり、そのカテゴリは `Electronics` カテゴリの中にあり、さらにそのカテゴリは `Home` ページからリンクされています。パンくずリストは、ユーザーがどのような経路でそのページにたどり着いたかにかかわらず、この同じ経路を表示します。ホームページからリンクをたどった人も、検索結果から直接商品ページに来た人も、どちらも `Home / Electronics / Phones / Smartphone XYZ` と表示されます。サイトで商品や特定の情報を探しているときに、パンくずリストを目にしたことがおそらくあるでしょう。

パンくずリストを使うことで、ユーザーがサイトの階層のどこにいるかを理解しやすくなり、現在のページより上位の広い範囲のページへ移動する方法もわかりやすくなります。これは特に、検索結果や外部リンクから来たユーザーが、今いるページの文脈を理解する必要がある場合に役立ちます。

一部のウェブサイトでは、ブラウザの履歴のようにユーザーが実際に訪れたページを追跡する別の種類のパンくずリストを使っています。このレッスンでは、最も一般的な階層ベースのパンくずリストに焦点を当てています。

## 区切り文字の選び方

パンくずリストを設計するときに考慮すべき点がいくつかあります。まず、区切り文字を決めることです。区切り文字は階層の異なるレベルを分ける記号です。一般的な区切り文字には、大なり記号（`>`）、右向きの引用符（`»`）、スラッシュ（`/`）があります。

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="breadcrumbs">
  Home &gt; Electronics &gt; Phones &gt; Smartphone XYZ
</div>
```

```css
.breadcrumbs {
  font-size: 0.9rem;
  color: #555;
  margin: 1rem 0;
}
```

:::

## 配置

次に考慮すべきはパンくずリストの配置です。パンくずリストは通常、ページの上部に配置され、メインナビゲーションバーの上か下に置かれます。ユーザーがパンくずリストを見つけるのに苦労しないよう、見やすく分かりやすい場所に配置してください。

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<nav class="main-nav">
  <a href="#">Home</a>
  <a href="#">Electronics</a>
  <a href="#">Phones</a>
</nav>
<div class="breadcrumbs">
  Home &gt; Electronics &gt; Phones &gt; Smartphone XYZ
</div>
```

```css
.main-nav {
  background-color: #333;
  padding: 1rem;
}

.main-nav a {
  color: white;
  margin-right: 1rem;
  text-decoration: none;
}

.breadcrumbs {
  font-size: 0.9rem;
  color: #555;
  margin: 1rem 0;
}
```

:::

この例では、メインナビゲーションに`Phones`へのリンクが含まれていますが、`Phones`は`Electronics`の中のカテゴリーです。これは問題ありません。なぜなら、メインナビゲーションのリンクは人気のあるページへのショートカットであることが多く、必ずしもトップレベルのカテゴリーである必要はないからです。パンくずリストは完全な階層を示しているので、ユーザーは`Phones`が`Electronics`の下にあることを確認できます。

## サイズ

もう一つの考慮点はパンくずリストのサイズです。パンくずリストは読みやすい大きさである必要がありますが、ページのスペースを取りすぎないようにしなければなりません。パンくずリストは主なナビゲーションツールとしてではなく、補助的なナビゲーション手段として使われることを覚えておいてください。情報量が多いページでは、ユーザーはパンくずリストを使って自分が階層のどこにいるかを簡単に把握し、親ページへ移動できます。

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="breadcrumbs">
  Home &gt; Electronics &gt; Phones &gt; Smartphone XYZ
</div>
<p>
  Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.
</p>
```

```css
.breadcrumbs {
  font-size: 1rem;
  color: #555;
  margin: 1rem 0;
}   

p {
  font-size: 1.2rem;
  line-height: 1.6;
}
```

:::

## パンくずリストを使うタイミング

では、いつパンくずリストをサイトで使うべきでしょうか？サイトがシンプルで階層が浅い場合は、パンくずリストは必要ないかもしれません。階層が浅いとは、ナビゲーションのレベルが少ないことを意味し、パンくずリストの価値があまりない場合があります。一般的に、パンくずリストはeコマースサイト、ニュースサイト、技術文書サイトのような階層が深いサイトでよく見られます。
