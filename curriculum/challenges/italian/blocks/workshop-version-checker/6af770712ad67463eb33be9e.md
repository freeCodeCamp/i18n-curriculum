# --description--

Le tuple sono immutabili, quindi non puoi aggiungere un elemento a `releases`. Invece, puoi usare l'operatore `+` per creare una nuova tupla che unisce gli elementi di due tuple:

```py
numbers = (1, 2)
print(numbers + (3, 4)) # (1, 2, 3, 4)
```

`new_version` è una tupla a sé, quindi `releases + new_version` aggiungerebbe i suoi tre numeri come elementi separati. Per aggiungerla come un singolo elemento, racchiudila in una tupla con un solo elemento. Ricorda che una tupla con un solo elemento ha bisogno di una virgola finale.

Alla fine della tua funzione, restituisci il risultato dell'unione di `releases` e di una tupla contenente solo `new_version`.

    sorted_releases = tuple(sorted(releases, reverse=True))

        return 'not a known release', latest

    elif installed[:2] < latest[:2]:
        update_type = 'minor update'
    else:
        update_type = 'patch update'

    return f'{update_type} available, releases behind: {releases_behind}', latest

    if base_version is None:
        base_version = sorted(releases, reverse=True)[0]

        print(f'{base_version} is not a known release')
        return releases

    elif release_type == 'patch':
        new_version = (major, minor, patch + 1)
    else:
        print(f'{release_type} is not a valid release type')
        return releases

    if new_version in releases:
        print(f'{new_version} has already been released')
        return releases
