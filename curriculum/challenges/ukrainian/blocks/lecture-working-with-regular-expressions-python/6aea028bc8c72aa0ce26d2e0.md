# --description--

Регулярні вирази можуть містити спеціальні послідовності, які складаються зі зворотної скісної риски (`\`), за якою йде символ. Ці послідовності мають особливе значення. Ось деякі з найпоширеніших:

- `\d` відповідає будь-якому десятковому знаку, включно з `0` до `9`.

- `\w` відповідає будь-якому словесному символу: літерам, цифрам і підкресленню (`_`).

- `\s` відповідає будь-якому пробільному символу, такому як пробіл, табуляція або новий рядок.

- `\D`, `\W` і `\S` відповідають протилежному до їхніх версій у нижньому регістрі. Наприклад, `\D` відповідає будь-якому символу, який не є цифрою.

Але є одна особливість. Рядки в Python також використовують зворотні скісні риски для запису керованих послідовностей, таких як `\n` (новий рядок) або `\t` (табуляція):

```python
print('Tab:\tdone') # Tab:    done
```

Це означає, що зворотна скісна риска в звичайному рядку Python може бути інтерпретована Python до того, як модуль `re` її побачить. Залежно від символу, що йде після, це може змінити ваш шаблон або викликати попередження Python.

Щоб уникнути цього, можна використовувати сирий рядок. Ви створюєте сирий рядок, додавши літеру `r` (або `R`) перед відкриваючою лапкою. Сирі рядки трактують зворотні скісні риски як буквальні символи, а не як керовані послідовності:

```python
print(r'Tab:\tdone') # Tab:\tdone
```

З цієї причини рекомендується завжди писати шаблони регулярних виразів як сирі рядки:

```python
import re

room = 'Room 42B'
print(re.search(r'\d', room))
# <re.Match object; span=(5, 6), match='4'>
```

Зверніть увагу, що `re.search` повертає перше знайдене співпадіння. Тут `\d` відповідає одній цифрі, тому співпадіння — це лише `4`. Щоб знайти більше ніж одну цифру, варто використати квантор.

Квантори вказують, скільки разів попередній символ або послідовність можуть повторюватися. Квантор `+` відповідає попередньому символу один або більше разів.

Отже, якщо `\d` відповідає одній цифрі, то `\d+` відповідає одній або кільком цифрам підряд:

```python
import re

room = 'Room 42B'
print(re.search(r'\d+', room))
# <re.Match object; span=(5, 7), match='42'>
```

Ось інші поширені квантори:

- `*` відповідає попередньому символу нуль або більше разів.

- `?` відповідає попередньому символу нуль або один раз, роблячи його необов’язковим.

- `{n}` відповідає попередньому символу рівно `n` разів.

- `{n,m}` відповідає попередньому символу від `n` до `m` разів.

```python
import re

print(re.search(r'go*al', 'What a goooal!'))
# <re.Match object; span=(7, 13), match='goooal'>

print(re.search(r'colou?r', 'My favorite color is blue'))
# <re.Match object; span=(12, 17), match='color'>

print(re.search(r'\d{4}', 'Room 42, built in 1987'))
# <re.Match object; span=(18, 22), match='1987'>
```

Ви можете поєднувати буквальні символи, спеціальні послідовності та квантори в одному шаблоні. Наприклад, шаблон `r'\d+ items'` відповідає одній або кільком цифрам, за якими йде пробіл і слово `items`. Ви також можете поєднати це з прапорцем `re.IGNORECASE`, щоб літери могли бути як у нижньому, так і у верхньому регістрі:

```python
import re

cart = 'You have 3 ITEMS in your cart.'
print(re.search(r'\d+ items', cart, re.IGNORECASE))
# <re.Match object; span=(9, 16), match='3 ITEMS'>
```
