# --description--

Wie eine `for`-Schleife kann auch eine `while`-Schleife eine `else`-Klausel haben. Der Code in der `else`-Klausel wird ausgeführt, wenn die Schleife normal endet, aber nicht, wenn die Schleife durch `break` gestoppt wird.

Fügen Sie der äußeren `while`-Schleife eine `else`-Klausel hinzu. Geben Sie darin den String `All requests served` aus.

In der Liste gibt es eine Stopp-Anfrage, daher wird die `else`-Klausel vorerst nicht ausgeführt.

def run_elevator(requests, start_floor):
    current_floor = start_floor
    floors_traveled = 0

    while requests:
        target = requests.pop(0)

        if target == 'stop':
            print('Emergency stop!')
            break

        if target == current_floor:
            print(f'Already on floor {target}')
            continue

        while current_floor != target:
            if current_floor < target:
                current_floor += 1
            else:
                current_floor -= 1
            floors_traveled += 1

        print(f'Arrived at floor {current_floor}')
