# --description--

Finora hai usato `re.search` per cercare un pattern in qualsiasi punto di una stringa. Il modulo `re` ha molte altre funzioni che lavorano con espressioni regolari. In questa lezione, imparerai alcune delle più utili.

## La funzione `match`

La funzione `match` funziona come `search`, ma cerca il pattern solo all'inizio della stringa. Restituisce un oggetto match se l'inizio della stringa corrisponde al pattern, e `None` altrimenti:

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

Nel secondo esempio, la stringa contiene cifre, quindi `re.search` le troverebbe. Ma la stringa non inizia con cifre, quindi `re.match` restituisce `None`.

## La funzione `fullmatch`

Il pattern `r'\d+:\d+'` corrisponde a una o più cifre, seguite da due punti e da una o più cifre. Questa è la forma di un orario come `10:30`.

Immagina di voler verificare che un input utente sia un orario, e nient'altro. Se usi `re.search`, incontrerai un problema:

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

Questo restituisce un oggetto match, anche se `10:30pm` non segue il formato previsto. Questo perché `re.search` cerca il pattern in qualsiasi punto della stringa e ignora eventuali caratteri extra intorno alla corrispondenza. `re.match` avrebbe lo stesso problema, perché `10:30pm` inizia con un orario valido.

Quando convalidi dati, di solito vuoi che l'intera stringa segua il pattern. Per questo puoi usare la funzione `fullmatch`. Restituisce un oggetto match solo quando il pattern corrisponde all'intera stringa, e `None` altrimenti:

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## La funzione `findall`

`search`, `match` e `fullmatch` restituiscono al massimo una corrispondenza. Quando vuoi tutte le corrispondenze in una stringa, puoi usare la funzione `findall`. Restituisce una lista di stringhe con tutte le corrispondenze trovate:

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

Se non ci sono corrispondenze, `findall` restituisce una lista vuota:

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## La funzione `sub`

La funzione `sub` sostituisce ogni corrispondenza di un pattern con un'altra stringa. Prende il pattern, la stringa di sostituzione e la stringa da cercare, e restituisce una nuova stringa:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub` ha anche due parametri opzionali. Il primo è `count`, che limita quante corrispondenze vengono sostituite:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

Il secondo è `flags`. Come le altre funzioni, `sub` può usare flag come `re.IGNORECASE`:

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

Passa sempre `count` e `flags` come argomenti keyword. Se passi `re.IGNORECASE` come quarto argomento posizionale, Python lo tratterà come valore di `count` invece.
