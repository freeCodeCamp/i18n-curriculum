# --description--

当主版本号相等时，你需要比较次版本号。如果次版本号不同，则是次要更新：较新的版本添加了仍然兼容旧版本的新特色。

切片一个元组会得到一个新元组，元组比较会在第一个不同的元素点对处停止。例如，`(2, 1) < (2, 2)` 是 `True`，因为第一个元素相等且 `1` 小于 `2`。

添加一个 `elif` 分支，检查 `installed` 的前两个元素切片是否小于 `latest` 的相同切片。如果是，则将字串 `minor update` 赋值给 `update_type`。
