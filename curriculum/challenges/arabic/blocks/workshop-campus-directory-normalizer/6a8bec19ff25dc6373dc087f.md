# --description--

ليس كل قسم مضمون أن يحتوي على `Dept_code`. تحتاج إلى النظام البديل عندما يكون مفقودًا، حتى يحصل القسم على معرف قابل للاستخدام.

يُرجع العامل `||` القيمة الموجودة على اليسار إذا كانت تلك القيمة `truthy`، وإلا يُرجع القيمة الموجودة على اليمين.

على سبيل المثال: `a || b` تُقيّم إلى `a` عندما تكون `a` `truthy`، وتستخدم النظام البديل `b` عندما تكون `a` `falsy` (مثل `undefined`، `null`، أو `""`).

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

حدّث تعيين `departmentId` لاستخدام العامل `||`. استخدم `departmentData.Dept_code` كالمُعامل الأيسر وعبارة القالب `` `dept-${i + 1}` `` كالمُعامل الأيمن. يستخدم هذا النظام البديل كلما كانت قيمة `departmentData.Dept_code` زائفة، بما في ذلك عندما تكون `undefined`.
