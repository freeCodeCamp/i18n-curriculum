# --description--

총합을 계산했으니 재고를 출력하세요. Python에서는 `print()` 함수와 **f-strings**(서식 문자열 리터럴)를 사용해 텍스트와 변수를 쉽게 함께 출력할 수 있습니다.

예를 들어:

```py
name = 'Alice'
print(f'Hello, {name}!') # Output: Hello, Alice!
```

`check_kitchen_stock` 함수 안에서 `total_items` 변수 아래에 다음 네 개의 정확한 print 문을 추가하세요:

1. `print(f'The kitchen has {total_items} total items:')`
2. `print(f'- {available_eggs} eggs')`
3. `print(f'- {available_flour} flour')`
4. `print(f'- {available_sugar} sugar')`
