# --description--

Per aprire e chiudere il `sub-menu`, il tuo componente `Navbar` deve ricordare se il `sub-menu` è attualmente aperto. I dati che un componente ricorda e che possono cambiare nel tempo si chiamano stato. Ogni volta che lo stato cambia, React renderizza di nuovo il componente in modo che la pagina mostri il nuovo valore.

Imparerai molto di più sullo stato nelle prossime lezioni. Per ora, devi solo sapere che puoi aggiungere lo stato a un componente funzionale con l'hook `useState`. Gli hook sono funzioni speciali che ti permettono di usare le funzionalità di React nei tuoi componenti. Poiché React è caricato con un elemento `script` in questo workshop, puoi consultare l'hook come `React.useState`:

```jsx
const [count, setCount] = React.useState(0);
```

`React.useState` prende come argomento il valore iniziale dello stato e restituisce un array con due elementi, che vengono destrutturati qui con la destrutturazione degli array:

- `count` è la variabile di stato, che contiene il valore corrente.
- `setCount` è la funzione setter, che chiami per aggiornare lo stato.

All'interno del componente `Navbar`, usa `React.useState` per creare una variabile di stato chiamata `isOpen` e una funzione setter chiamata `setIsOpen`. Poiché il `sub-menu` dovrebbe iniziare chiuso, assegna come valore iniziale `false`.
