# --description--

生産性を上げるために使えるコマンドラインのショートカットについて学びましょう。

ターミナルやコマンドラインのショートカットは、作業の効率化や生産性の最大化に役立ちます。LinuxとmacOSはどちらもUnixにルーツがあるため、多くのショートカットは共通しています。しかしWindowsではいくつか違いがあります。

最初のショートカットは<kbd>Up Arrow</kbd>キーです。このキーを押すと、コマンド履歴を1つずつ遡ってサイクルできます。次に<kbd>Down Arrow</kbd>キーは、コマンド履歴を順に進めるために使えます。この2つのキーで、以前に実行したコマンドを素早く見つけて再実行できます。

多くのシェルにはオートコンプリート機能もあり、入力を始めた内容に基づいてコマンドを提案します。<kbd>Tab</kbd>キーを使うと提案の残りを補完し、コマンドラインに完全な構文を素早く入力できます。これらの提案の生成方法はシェルによって異なります。例えば、zshでは最近のコマンド履歴に基づいていますが、PowerShellでは利用可能なコマンド、変数、引数に基づいており、使用頻度の重みは低くなっています。

時にはコマンドの出力が大量になり、端末画面が見づらくなったり作業の妨げになることがあります。LinuxやmacOSの*nix系端末では、<kbd>Control</kbd> + <kbd>L</kbd>を押すと画面全体がクリアされ、きれいなプロンプトから再開できます。PowerShellでも<kbd>Control</kbd> + <kbd>L</kbd>で画面がクリアされ、同じ結果を得るには`cls`コマンドを実行できます。

コマンドの実行を中断したい場合は、<kbd>Control</kbd> + <kbd>C</kbd>でプロセスを強制終了できます。これによりコマンドが終了し、新しいプロンプトが表示されて他の作業を続けられます。PowerShellでは<kbd>Control</kbd> + <kbd>C</kbd>はテキストのコピーにも使われ、コピー対象のテキストが選択されていない場合のみプロセスの終了に使えます。

次のいくつかのショートカットは*nix系ターミナルでのみ利用可能で、PowerShellには対応するものがありません。

複数の作業を同時に行いたい場合、あるプロセスやコマンドをバックグラウンドで実行しながら別の作業ができます。<kbd>Control</kbd> + <kbd>Z</kbd>を押すと現在のプロセスがバックグラウンドタスクに移され、コマンドラインに戻って作業を続けられます。バックグラウンドタスクにフォーカスを戻したいときは`fg`を使って復元できます。

最後に、連続して同じコマンドを実行したい場合があります。<kbd>Up Arrow</kbd>キーで直前のコマンドに遡れますが、コマンドラインに感嘆符を2つ（`!!`）入力して<kbd>Enter</kbd>を押すと、最後に実行したコマンドが自動的に再実行されます。

多くのターミナルにはさらに多くのショートカットがあり、使っている環境のドキュメントを読むことをお勧めします。ですが、ここで紹介した基本的な共通ショートカットは、生産性を最大化しターミナルの達人になるための良い出発点になるでしょう。
