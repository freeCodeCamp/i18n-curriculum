# --interactive--

Flex-Eigenschaften steuern, wie Elemente innerhalb eines Flex-Layouts funktionieren, von der Verteilung auf Container-Ebene bis zur Selbst-Ausrichtung auf Element-Ebene. In dieser Lektion behandeln wir einige der am häufigsten verwendeten: `flex-wrap`, `flex-flow`, `justify-content`, `align-items` und `align-self`.

Beginnen wir mit `flex-wrap`. Diese Eigenschaft bestimmt, wie Flex-Elemente innerhalb eines Flex-Containers umgebrochen werden, um in den verfügbaren Platz zu passen. `flex-wrap` kann drei mögliche Werte annehmen: `nowrap`, `wrap` und `wrap-reverse`. `nowrap` ist der Standardwert: Flex-Elemente werden nicht in eine neue Zeile umgebrochen, selbst wenn ihre Breite die Breite des Containers überschreitet.

Im folgenden Code haben wir drei `div`-Elemente. Konzentrieren wir uns auf die `width`. Der mit einem Rahmen versehene `main`-Container hat eine `width` von `200px`, während seine drei untergeordneten `div`-Elemente zusammen eine `width` von `240px` (`80px` jeweils) haben:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  display: flex;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Die Breite der `div`-Elemente überschreitet die Breite ihres Containers, aber standardmäßig werden sie verkleinert, um in den verfügbaren Platz zu passen. Wenn Sie möchten, dass sie umgebrochen werden, wenn sie die Breite ihres Containers überschreiten, können Sie `flex-wrap: wrap` auf dem Flex-Container setzen:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  display: flex;
  flex-wrap: wrap;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Die `div`-Elemente werden in Reihen neu angeordnet, wenn sie die Breite ihres Containers überschreiten. Sie können Flex-Elemente auch in umgekehrter Reihenfolge umbrechen mit `flex-wrap: wrap-reverse`. Die `flex-flow`-Eigenschaft ist eine Kurzschreibweise-Eigenschaft für `flex-direction` und `flex-wrap`. In diesem Beispiel setzen wir `flex-direction` auf `column` und `flex-wrap` auf `wrap-reverse`:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  height: 120px;
  display: flex;
  flex-flow: column wrap-reverse;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Super. Nun sprechen wir über `justify-content`. `justify-content` richtet die Kindelemente entlang der Hauptachse des Flex-Containers aus. Wenn Sie den Wert `flex-start` der `justify-content` zuweisen, werden die Flex-Elemente am Anfang der Hauptachse ausgerichtet. Das kann horizontal oder vertikal sein:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: flex-start;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Mit `justify-content: flex-end` werden Flex-Elemente am Ende der Hauptachse ausgerichtet, horizontal oder vertikal.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: flex-end;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Um die Flex-Elemente entlang der Hauptachse zu zentrieren, können Sie `justify-content: center` verwenden.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: center;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Um die Elemente entlang der Hauptachse ohne Abstand an den Rändern zu verteilen, können Sie `justify-content: space-between` verwenden. Das erste Element sitzt am Anfang der Hauptachse, das letzte Element am Ende, und der verbleibende Platz wird zwischen benachbarten Elementen verteilt.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: space-between;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

`justify-content: space-around` verteilt die Flex-Elemente gleichmäßig entlang der Hauptachse und fügt vor dem ersten und nach dem letzten Element einen Abstand hinzu. Dieser zusätzliche Abstand entspricht der Hälfte des Abstands zwischen jeweils zwei benachbarten Elementen. Wenn nur ein Element verteilt wird, wird es zentriert.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: space-around;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Und nicht zuletzt gibt es `justify-content: space-evenly`, das die Elemente gleichmäßig entlang der Hauptachse verteilt. Der Abstand zwischen den Elementen und der Abstand vor dem ersten und nach dem letzten Element sind genau gleich:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: space-evenly;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

Super. Jetzt wissen Sie, wie Sie Flex-Elemente entlang der Hauptachse verteilen. Aber Sie möchten sie vielleicht auch entlang der Querachse verteilen. Denken Sie daran, dass die Querachse senkrecht zur Hauptachse steht. Das können Sie mit der `align-items`-Eigenschaft tun. Um die Elemente entlang der Querachse zu zentrieren, müssen Sie nur `align-items: center` zum Flex-Container hinzufügen:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: center;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

In diesem Beispiel sind die Flex-Elemente entlang der Querachse zentriert, die standardmäßig vertikal ist. Wenn die Querachse horizontal ist, werden sie stattdessen horizontal zentriert. Im Gegensatz dazu richtet `align-items: flex-start` die Elemente am Anfang der Querachse aus:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: flex-start;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Das Gegenteil ist `align-items: flex-end`. Damit werden Flex-Elemente am Ende der Querachse ausgerichtet, vertikal oder horizontal.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: flex-end;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

Um die Flex-Elemente entlang der Querachse zu strecken, können Sie `align-items: stretch` verwenden. Dies betrifft nur Elemente, deren Größe auf der Querachse `auto` ist; Elemente mit einer expliziten Größe auf der Querachse (zum Beispiel eine festgelegte `height` in einem Zeilen-Container) werden nicht gestreckt. Die betroffenen Elemente füllen den Container in Richtung der Querachse aus.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: stretch;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
  height: auto;
}
```

:::

Es gibt weitere Flex-Eigenschaften und Werte, aus denen Sie wählen können, um das responsive Layout zu erstellen, das Sie sich vorstellen, aber dies sind die am häufigsten verwendeten.
