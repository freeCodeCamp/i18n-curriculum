# --description--

このラボでは、すべてのHTMLとCSSが提供されています。TypeScriptを使ってバイクショップのページの機能を完成させてください。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

**ユーザーストーリー：**

1. `'Sport'`、`'Cruiser'`、`'Touring'`、`'Dirt'`、`'Adventure'`、`'Naked'`、`'Electric'` のいずれかの値を取る `Category` という名前の `type` を作成する必要があります。
2. 次のプロパティを持つ `Motorcycle` という名前の `interface` を作成する必要があります: `string` 型の `id`、`string` 型の `name`、`string` 型の `manufacturer`、`Category` 型の `category`、`number` 型の `price`、`string` 型の `image_url`、`Date` 型の `created_at` プロパティ、`string` 型の `description`、そして `number` 型の `year`。 
3. `Motorcycle` オブジェクトの配列で解決される `Promise` を返す、`fetchMotorcycles` という名前の関数を作成する必要があります。
4. `https://cdn.freecodecamp.org/curriculum/labs/data/motorcycle-shop/motorcycles.json` エンドポイントから `Motorcycle` のデータを読み込む必要があります。
5. 1つの `Motorcycle` オブジェクトをパラメータとして受け取り、バイクのカードを整形された HTML 文字列として返す、`renderMotorcycleCard` という名前の関数を作成する必要があります。
   1. `renderMotorcycleCard` 関数は、`Motorcycle` 型の `motorcycle` というパラメータを受け取る必要があります。 
   2. `renderMotorcycleCard` 関数は、motorcycle-card コンポーネントを構成する HTML 要素の文字列を返す必要があります。関数の戻り値の型は `string` である必要があります。 
   3. 各 motorcycle-card コンポーネントには、`motorcycle-card` クラスを持つ外側のコンテナ要素が必要です。 
   4. 各 motorcycle-card コンポーネントには、有効な画像を持ち、`motorcycle-card-image` クラスを持つ `img` 要素が必要です。
   5. 各 motorcycle-card コンポーネントには、`motorcycle-card-year-badge` クラスを持ち、年をプレーンテキストで表示する要素が必要です。
   6. 各 motorcycle-card コンポーネントには、`motorcycle-card-title` クラスを持ち、バイクの名前をプレーンテキストで表示する要素が必要です。
   7. 各 motorcycle-card コンポーネントには、`motorcycle-card-manufacturer` クラスを持ち、バイクのメーカー名をプレーンテキストで表示する要素が必要です。
   8. 各 motorcycle-card コンポーネントには、`motorcycle-card-category` クラスを持ち、バイクのカテゴリをプレーンテキストで表示する要素が必要です。 
   9. 各 motorcycle-card コンポーネントには、`motorcycle-card-description` クラスを持ち、バイクの説明をプレーンテキストで表示する要素が必要です。 
   10. 各 motorcycle-card コンポーネントには、`motorcycle-card-price` クラスを持ち、バイクの価格をプレーンテキストで表示する要素が必要です。
6. `MotorcycleGalleryApp` という名前のクラスが必要です。 
   1. このクラスには `allMotorcycles` という `private` メンバーが必要で、`Motorcycle` オブジェクトの配列として静的に型付けされ、空の配列に設定されている必要があります。
   2. このクラスには `loadData` という名前の `public` 関数が必要です。この関数は `async` として定義され、`fetchMotorcycles` を呼び出し、返されたデータを `allMotorcycles` クラスプロパティに保存する必要があります。
   3. このクラスには、名前に `filterTerm` を含む `allMotorcycles` 内のバイクカードを、id が `motorcycle-grid` の要素の中に描画する、`renderMotorcycles` という名前の public 関数が必要です。
   4. このクラスには `private` プロパティ `filterTerm` が必要で、文字列として静的に型付けされている必要があります。
7. 表示されるバイクカードの数を、id が `results-number` の要素に表示する必要があります。
8. `input` イベントのたびに、`filterTerm` プロパティを `#name-filter-input` の値に更新する必要があります。各イベントの後、表示されるバイクカードと `results-number` を更新する必要があります。
9. `MotorcycleGalleryApp` のインスタンスを作成し、その `loadData` メソッドを await して、読み込んだバイクカードを表示し、`results-number` の件数を更新する必要があります。

type Category = 
  | 'Sport'
  | 'Cruiser'
  | 'Touring'
  | 'Dirt'
  | 'Adventure'
  | 'Naked'
  | 'Electric';

interface Motorcycle {
  id: string;
  name: string;
  manufacturer: string;
  category: Category;
  price: number;
  image_url: string;
  description: string;
  year: number;
  created_at: Date;
}


async function fetchMotorcycles():  Promise<Motorcycle[]> {
    const res = await fetch(`https://cdn.freecodecamp.org/curriculum/labs/data/motorcycle-shop/motorcycles.json`);
    const motorcycles = await res.json();
    return [...motorcycles].map((m: Motorcycle) => ({ ...m, created_at: new Date(m.created_at) })).sort((a, b) => 
      b.created_at.getTime() - a.created_at.getTime()
    );
}

function renderMotorcycleCard(motorcycle: Motorcycle): string {
    return `
      <div class="motorcycle-card">
        <div class="motorcycle-card-image-container">
          <img
            src="${motorcycle.image_url}"
            alt="${motorcycle.name}"
            class="motorcycle-card-image"
          />
          <div class="motorcycle-card-year-badge">
            ${motorcycle.year}
          </div>
        </div>
        <div class="motorcycle-card-content">
          <div class="motorcycle-card-header">

class MotorcycleGalleryApp {
  private allMotorcycles: Motorcycle[] = [];
  private filterTerm: string = '';
  constructor() {
    this.init();
  }

  async loadData(): Promise<void> {
    await this.loadMotorcycles();
  }

  private async init(): Promise<void> {
    this.setupEventListeners();
  }

  private async loadMotorcycles(): Promise<void> {
    this.showLoading(true);
    try {
      const data = await fetchMotorcycles();
      this.allMotorcycles = [...data];
    } catch (error) {
      console.error('Error loading motorcycles:', error);
    } finally {
      this.showLoading(false);
    }
  }

  private setupEventListeners(): void {
    const nameFilterInput = document.getElementById('name-filter-input') as HTMLInputElement;
    if (nameFilterInput) {
      nameFilterInput.addEventListener('input', (event: Event) => {
        const {value} = event.target as HTMLInputElement;
        this.filterTerm = value;
        this.render();
      });
    }
  }
 
  render(): void {
    this.renderResultsCount();
    this.renderMotorcycles();
  }

  private renderResultsCount(): void {
    const resultsNumber = document.getElementById('results-number');
    if (resultsNumber) {
      resultsNumber.textContent = this.allMotorcycles.filter((m: Motorcycle) => m.name.toLowerCase().includes(this.filterTerm.toLowerCase())).length.toString();
    }
  }

  renderMotorcycles(): void {
    const container = document.getElementById('motorcycle-grid');
    const noResults = document.getElementById('no-results');
    if (!container) return;

    if (noResults) {
      noResults.style.display = 'none';
    }

    const filteredResults = this.allMotorcycles.filter((m: Motorcycle) => m.name.toLowerCase().includes(this.filterTerm.toLowerCase()));

    if (filteredResults.length === 0 && noResults) {
      container.innerHTML = '';
      container.style.display = 'none';
      noResults.style.display = 'block';
      return;
    }

    container.style.display = 'grid';
    container.innerHTML = filteredResults
      .map(renderMotorcycleCard)
      .join('');
  }

  private showLoading(show: boolean): void {
    const loadingContainer = document.getElementById('loading-container');
    const motorcycleGrid = document.getElementById('motorcycle-grid');
    if (loadingContainer) {
      loadingContainer.style.display = show ? 'flex' : 'none';
    }
    if (motorcycleGrid) {
      motorcycleGrid.style.display = show ? 'none' : 'grid';
    }
  }
}

document.addEventListener('DOMContentLoaded',async () => {
   const gallery = new MotorcycleGalleryApp();
   await gallery.loadData();
   gallery.render();
});
