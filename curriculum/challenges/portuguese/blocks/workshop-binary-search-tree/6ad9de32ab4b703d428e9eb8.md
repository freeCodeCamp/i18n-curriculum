# --description--

Adicione uma cláusula `elif` à sua declaração `if` que verifica se `key` é maior que `node.key`. Dentro dela, faça uma chamada a `self._insert` com `node.right` e `key`, e atribua o resultado a `node.right`.

Se `key` for igual a `node.key`, nenhum dos ramos será executado, então valores duplicados não são adicionados à árvore.
