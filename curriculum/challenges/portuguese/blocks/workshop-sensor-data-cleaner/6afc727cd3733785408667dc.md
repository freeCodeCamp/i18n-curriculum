```py

print(doubled) # [2, 4, 6]
```

Crie uma variável chamada `differences`. Use uma list comprehension para atribuir a ela uma lista contendo `temperature - average` para cada `temperature` em `temperatures`.

Depois, imprima `differences` em vez de `temperatures`.
