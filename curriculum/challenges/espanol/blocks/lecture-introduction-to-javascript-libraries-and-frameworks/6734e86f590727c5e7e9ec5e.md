# --description--

React es una de las bibliotecas de JavaScript más populares para construir interfaces de usuario y aplicaciones web. Originalmente desarrollada en Facebook, ahora Meta, React ha ganado una gran popularidad en el desarrollo web debido a su eficiencia, flexibilidad y funcionalidades.

Un concepto fundamental en React es la creación de componentes de interfaz de usuario reutilizables. Estos componentes, como botones, tarjetas y avatares, se pueden reutilizar fácilmente en toda tu aplicación. Puedes anidar estos componentes unos dentro de otros para construir interfaces más complejas y dinámicas.

Una de las ventajas clave de React es que estos componentes personalizados pueden actualizarse y renderizarse independientemente a medida que cambian los datos.

A diferencia del JavaScript tradicional, que requiere manipulación directa del DOM (Document Object Model), React usa un DOM virtual, lo que mejora el rendimiento y la eficiencia. Aprenderás más sobre el DOM virtual y cómo funciona en las próximas lecciones.

Además de componentes reutilizables, React también proporciona una manera poderosa de gestionar el estado de la aplicación. El estado se refiere a los datos que determinan cómo se renderiza y se comporta un componente.

Con React, puedes rastrear y actualizar fácilmente el estado de los componentes, asegurando que la interfaz refleje los datos más actuales. Aprenderás más sobre cómo trabajar con el estado en lecciones futuras.

Aunque existen muchas bibliotecas dentro del ecosistema de JavaScript, freeCodeCamp enseña principalmente React debido a su uso generalizado y demanda en la industria.

En las próximas lecciones profundizarás en la construcción de componentes personalizados, la gestión del estado y más.
