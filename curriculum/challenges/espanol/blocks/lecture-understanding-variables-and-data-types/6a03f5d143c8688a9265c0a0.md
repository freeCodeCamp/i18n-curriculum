# --description--

En la lección anterior, aprendiste sobre los tipos de datos comunes en Python, incluyendo los tipos cadena, entero y float. A medida que desarrolles tus programas, necesitarás aprender a ver el tipo de una variable.

Aquí tienes una variable de ejemplo:

```py
developer = 'Devin'
```

Para ver qué tipo es `developer`, puedes usar la función `type()` así:

```py
developer = 'Devin'

print(type(developer)) # <class 'str'>
```

La salida de `<class 'str'>` significa que `developer` es un tipo cadena.

Si no proporcionas ningún argumento a la función `type()`, recibirás el siguiente mensaje de error:

```md
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: type() takes 1 or 3 arguments
```

Aquí están los tipos de datos que has aprendido hasta ahora, junto con lo que la función `type()` imprime para cada uno:

```python
my_integer_var = 10
print(type(my_integer_var))  # <class 'int'>

my_float_var = 4.50
print(type(my_float_var))  # <class 'float'>

my_string_var = 'hello'
print(type(my_string_var))  # <class 'str'>

my_boolean_var = True
print(type(my_boolean_var))  # <class 'bool'>
```

Habrá momentos en tu programa en los que necesites verificar que una variable en particular sea de un tipo específico antes de realizar operaciones sobre ella. Aquí es donde la función `isinstance()` resulta útil.

Aquí tienes una variable de ejemplo con una cadena asignada:

```py
account_balance = '12'
```

Si intentas realizar operaciones matemáticas como la división usando la variable `account_balance`, recibirás un mensaje de error.

```py
account_balance = '12'

account_balance / 2

# Traceback (most recent call last):
#   File "<stdin>", line 1, in <module>
# TypeError: unsupported operand type(s) for /: 'str' and 'int'
```

Para ver si `account_balance` es un entero, puedes verificarlo usando la función `isinstance()` así:

```py
account_balance = '12'

isinstance(account_balance, int) # False
```

La función integrada `isinstance()` te permite verificar si una variable coincide con un tipo de dato específico. Toma un valor y el tipo contra el que quieres comprobarlo, y luego devuelve un booleano. En este caso, como `account_balance` es una cadena, devolverá `False`.

La función `isinstance()` también te permite verificar múltiples tipos a la vez.

Aquí tienes un ejemplo verificando si `account_balance` es un `int` o `float`:

```py
account_balance = 12
isinstance(account_balance, (int, float)) # True
```

En este ejemplo, `account_balance` es un entero, por lo que `isinstance()` devuelve `True`. Si `account_balance` fuera `12.0`, `isinstance()` aún devolvería `True` porque estás verificando enteros o floats.

En futuros talleres y laboratorios, usarás las funciones `type()` y `isinstance()` para asegurarte de que tus variables contienen los tipos de datos correctos antes de realizar operaciones sobre ellas.
