# --description--

在處理讀數之前，你需要先移除錯誤代碼。

如你在前面的課程中所學，`filter()` 函式只保留可疊代物件中，函式回傳為真值的項目。你可以不用用 `def` 定義該函式，而是直接將 lambda 函式傳給 `filter()`：

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

創建一個名為 `valid_readings` 的變數。將傳入 `filter()` 的 lambda 函式和 `readings` 的結果指定給它。該 lambda 函式應該接受一個名為 `reading` 的參數，並檢查 `reading` 是否不等於 `-999`。

然後，列印 `valid_readings`，而不是 `readings`。
