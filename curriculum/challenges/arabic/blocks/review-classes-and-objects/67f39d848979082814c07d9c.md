## أصناف وكائنات Python

- **تعريف الصنف**: الصنف هو مخطط لإنشاء الكائنات. يحدد السلوك الذي سيكون للكائن من خلال خصائصه وطرقه. إليك مثالًا أساسيًا لتعريف صنف في Python:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **أسماء الأصناف**: حسب الاصطلاح، تستخدم أسماء الأصناف ترميز PascalCase: تبدأ كل كلمة بحرف كبير ولا توجد شرطات سفلية، كما في `Dog` أو `ShoppingCart`.

- **دالة `__init__()`**: تستدعي Python دالة `__init__()` تلقائيًا في كل مرة تنشئ فيها كائنًا جديدًا. تُستخدم لإعداد الخصائص الأولية للكائن.

- **معلمة `self`**: تشير `self` إلى الكائن المحدد الذي تعمل عليه الطريقة. تمررها Python تلقائيًا عند استدعاء طريقة على كائن، لذلك لا تكتبها في الاستدعاء. `self` هو الاسم الاصطلاحي، لكنها دائمًا المعلمة الأولى لطريقة المثيل.

- **إنشاء الكائنات**: الكائنات هي نسخ من الصنف. تُنشأ باستدعاء الصنف مع المعاملات اللازمة.

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **استدعاء الطرق على الكائنات**: يمكنك استدعاء الطرق على الكائنات لأداء إجراءات أو استرجاع معلومات.

```python
object_name1.method_name()
object_name2.method_name()
```

- **الفرق بين الصنف والكائن**: الصنف هو قالب قابل لإعادة الاستخدام، بينما الكائن هو نسخة محددة من ذلك الصنف تحتوي على بيانات فعلية.

## الخصائص

- **الخصائص الخاصة بالمثيل**: تُعرّف عادةً في `__init__()` باستخدام `self`، وتكون فريدة لكل كائن.
- **الخصائص الخاصة بالصنف**: تُعرّف مباشرة داخل الصنف وتُشترك بها جميع المثيلات.

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **التعامل مع الخصائص ديناميكيًا**: أحيانًا يكون اسم الخاصية معروفًا فقط أثناء وقت التشغيل، مثلًا عندما يأتي من مُدخَل المستخدم أو حلقة. في هذه الحالة لا يمكنك كتابة `object.name`، فتستخدم دوال تأخذ الاسم كسلسلة نصية:

  - `getattr(obj, name)` تُرجع قيمة الخاصية. ترجع خطأ `AttributeError` إذا لم توجد الخاصية، إلا إذا مررت قيمة افتراضية كمعلمة ثالثة.
  - `setattr(obj, name, value)` تنشئ خاصية أو تحدّثها.
  - `hasattr(obj, name)` تُرجع `True` إذا وُجدت الخاصية، وإلا `False`.
  - `delattr(obj, name)` تحذف خاصية.

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **فحص الخصائص باستخدام `dir()`**: تُرجع دالة `dir()` قائمة بأسماء خصائص وطُرُق الكائن. اجمعها مع `callable()` لفصل الطُرُق عن خصائص البيانات.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## الطرق

- **الطرق**: دوال معرفة داخل الصنف تعمل على خصائص الكائن.

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **الوصول إلى الطرق**: استدعِ الطرق على الكائنات باستخدام ترميز النقطة. إليك مثالًا لاستدعاء طريقة `describe` على كائنين مختلفين من صنف السيارة:

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## الطرق الخاصة (Dunder)

- **التعريف**: طرق خاصة تبدأ وتنتهي بشرطتين سفليتين مزدوجتين (مثل `__init__`, `__len__`, `__str__`, `__eq__`). يستخدمها Python داخليًا للعمليات المدمجة.

- **السلوك بدون طرق خاصة مخصصة**: لا تستنتج Python كيف تستخدم العمليات المدمجة خصائص كائن مخصص. تستخدم السلوك الافتراضي الموروث حيث يتوفر وترجع خطأ `TypeError` للعمليات غير المدعومة.

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **ما تغيّره الطرق المخصصة**: تجعل `__len__()` دالة `len()` تُرجع عدد الصفحات بدلًا من إرجاع خطأ. تستبدل `__str__()` التمثيل الافتراضي بملخص قابل للقراءة. تجعل `__eq__()` عامل `==` يقارن عدد الصفحات بدلًا من التحقق مما إذا كان الاسمان يشيران إلى نفس الكائن.

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **استدعاء الطرق الخاصة بشكل غير مباشر**: لا تحتاج إلى استدعاء الطرق الخاصة مباشرة. بدلاً من ذلك، يستدعيها Python تلقائيًا عند حدوث إجراءات معينة. تشمل هذه العمليات:

  - **العمليات الحسابية مثل الجمع، الطرح، الضرب، القسمة، وغيرها**. تُستدعى `__add__()` للجمع، `__sub__()` للطرح، `__mul__()` للضرب، و `__truediv__()` للقسمة.
        
  - **عمليات السلاسل النصية مثل الربط، التكرار، التنسيق، والتحويل إلى نص**. تُستدعى `__add__()` للربط، `__mul__()` للتكرار، `__format__()` للتنسيق، و `__str__()` و `__repr__()` للتحويل إلى نص، وهكذا.
        
  - **عمليات المقارنة مثل المساواة، الأصغر من، الأكبر من، وغيرها**. تُستدعى `__eq__()` لفحص المساواة، `__lt__()` للأصغر من، `__gt__()` للأكبر من، وهكذا.
        
  - **عمليات التكرار مثل جعل الكائن قابلًا للتكرار والتنقل بين العناصر**. تُستدعى `__iter__()` لإرجاع مكرر و`__next__()` لجلب العنصر التالي.

## مثال واقعي: عربة التسوق

- **صنف العربة مع الطرق الخاصة**: يسمح بالإضافة، الإزالة، التكرار، والتحقق من المحتويات بسلوك مدمج.

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## عمل الكائنات معًا

- **تمرير الكائنات كمعلمات**: يمكن تمرير الكائنات إلى دوال البناء في أصناف أخرى، تمامًا مثل الأرقام أو السلاسل النصية.

- **تخزين الكائنات في الخصائص**: يمكن تخزين كائن داخل خاصية كائن آخر. بعدها يمكنك استدعاء الطرق عبر تلك الخاصية باستخدام تسلسل ترميز النقطة، كما في `receiver.inbox.receive_email(email)`.

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## العمل مع التواريخ والأوقات

- **الحصول على التاريخ والوقت الحاليين**: استدعاء `datetime.datetime.now()` يُرجع التاريخ والوقت الحاليين ككائن `datetime`.

- **تخزين طابع زمني على المثيل**: استدعِ `datetime.datetime.now()` داخل `__init__()` وعيّن النتيجة إلى خاصية لتسجيل وقت إنشاء الكائن.

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **التنسيق باستخدام `strftime()`**: تحوّل طريقة `strftime()` كائن `datetime` إلى سلسلة نصية باستخدام رموز التنسيق: `%Y` للسنة بأربعة أرقام، `%m` للشهر، `%d` لليوم، `%H` للساعة (بنظام 24 ساعة)، `%M` للدقائق، و`%S` للثواني. تُحافظ على أي حروف أخرى مثل `-`، `/`، `:`، أو الفراغات كفواصل حرفية.

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
