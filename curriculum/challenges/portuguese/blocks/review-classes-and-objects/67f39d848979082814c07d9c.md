## Classes e objetos em Python

- **Definição de classe**: Uma classe é um modelo para criar objetos. Ela define o comportamento que um objeto terá por meio de seus atributos e métodos. Aqui está um exemplo básico de definição de classe em Python:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **Nomes de classe**: Por convenção, os nomes de classe usam PascalCase: cada palavra começa com letra maiúscula e não há underscores, como em `Dog` ou `ShoppingCart`.

- **O método `__init__()`**: Python chama `__init__()` automaticamente toda vez que você cria um novo objeto. Ele é usado para configurar os atributos iniciais do objeto.

- **O parâmetro `self`**: `self` se refere ao objeto específico em que o método está trabalhando. Python o passa automaticamente quando você chama um método em um objeto, então você não o escreve na chamada. `self` é o nome convencional, mas é sempre o primeiro parâmetro de um método de instância.

- **Criando objetos**: Objetos são instâncias de uma classe. Eles são criados ao chamar a classe com os argumentos necessários.

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **Chamando métodos em objetos**: Você pode chamar métodos em objetos para executar ações ou obter informações.

```python
object_name1.method_name()
object_name2.method_name()
```

- **Diferença entre classe e objeto**: Uma classe é um modelo reutilizável, enquanto um objeto é uma instância específica dessa classe com dados reais.

## Atributos

- **Atributos de instância**: Geralmente definidos em `__init__()` usando `self`, e únicos para cada objeto.
- **Atributos de classe**: Definidos diretamente dentro da classe e compartilhados por todas as instâncias.

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **Manipulando atributos dinamicamente**: Às vezes o nome do atributo só é conhecido em tempo de execução, por exemplo quando vem da entrada do usuário ou de um loop. Nesse caso você não pode escrever `object.name`, então usa funções que recebem o nome como string:

  - `getattr(obj, name)` retorna o valor do atributo. Lança um `AttributeError` se o atributo não existir, a menos que você passe um valor padrão como terceiro argumento.
  - `setattr(obj, name, value)` cria ou atualiza um atributo.
  - `hasattr(obj, name)` retorna `True` se o atributo existir, caso contrário `False`.
  - `delattr(obj, name)` exclui um atributo.

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **Inspecionando atributos com `dir()`**: A função `dir()` retorna uma lista com os nomes dos atributos e métodos de um objeto. Combine com `callable()` para separar métodos de atributos de dados.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## Métodos

- **Métodos**: Funções definidas dentro de uma classe que operam nos atributos do objeto.

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **Acessando métodos**: Faça chamadas de métodos em objetos usando a notação de ponto. Aqui está um exemplo de chamada do método `describe` em dois objetos carro diferentes:

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## Métodos dunder (mágicos)

- **Definição**: Métodos especiais que começam e terminam com dois underscores (por exemplo, `__init__`, `__len__`, `__str__`, `__eq__`). O Python os usa internamente para operações embutidas.

- **Comportamento sem métodos especiais personalizados**: Python não infere como operações embutidas devem usar os atributos de um objeto personalizado. Ele usa o comportamento padrão herdado quando disponível e lança um `TypeError` para operações não suportadas.

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **O que os métodos personalizados mudam**: `__len__()` faz `len()` retornar a contagem de páginas em vez de lançar um erro. `__str__()` substitui a representação padrão por um resumo legível. `__eq__()` faz `==` comparar a contagem de páginas em vez de verificar se ambos os nomes referem-se ao mesmo objeto.

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **Chamando métodos dunder indiretamente**: Você não precisa chamar métodos dunder diretamente. Em vez disso, o Python os chama automaticamente quando certas ações acontecem. Essas operações incluem:

  - **operações aritméticas como adição, subtração, multiplicação, divisão e outras**. `__add__()` é chamado para adição, `__sub__()` para subtração, `__mul__()` para multiplicação e `__truediv__()` para divisão.
        
  - **operações com strings como concatenação, repetição, formatação e conversão para texto**. `__add__()` é chamado para concatenação, `__mul__()` para repetição, `__format__()` para formatação, `__str__()` e `__repr__()` para conversão em texto, e assim por diante.
        
  - **operações de comparação como igualdade, menor que, maior que e outras**. `__eq__()` é chamado para checagens de igualdade, `__lt__()` para menor que, `__gt__()` para maior que, e assim por diante.
        
  - **operações de iteração como tornar um objeto iterável e avançar pelos itens**. `__iter__()` é chamado para retornar um iterador e `__next__()` para obter o próximo item.

## Exemplo do mundo real: carrinho de compras

- **Classe Cart com métodos dunder**: permite adicionar, remover, iterar e verificar conteúdos com comportamento embutido.

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## Objetos trabalhando juntos

- **Passando objetos como argumentos**: Objetos podem ser passados para construtores de outras classes, assim como números ou strings.

- **Armazenando objetos em atributos**: Um objeto pode ser armazenado no atributo de outro objeto. Você pode então chamar métodos através desse atributo encadeando a notação de ponto, como em `receiver.inbox.receive_email(email)`.

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## Trabalhando com datas e horários

- **Obtendo a data e hora atuais**: Chamar `datetime.datetime.now()` retorna a data e hora atuais como um objeto `datetime`.

- **Armazenando um timestamp em uma instância**: Chame `datetime.datetime.now()` dentro de `__init__()` e atribua o resultado a um atributo para registrar quando o objeto foi criado.

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **Formatando com `strftime()`**: O método `strftime()` transforma um objeto `datetime` em uma string, usando códigos de formato: `%Y` para o ano com quatro dígitos, `%m` para o mês, `%d` para o dia, `%H` para a hora (relógio 24h), `%M` para os minutos e `%S` para os segundos. Qualquer outro caractere, como `-`, `/`, `:` ou espaços, é mantido como separador literal.

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
