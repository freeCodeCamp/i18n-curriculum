# --description--

Температура, що дорівнює середній, отримує мітку `0.0 °C`, що читається не дуже добре. Замість цього вона має отримувати мітку `average`.

Ви можете ланцюжити умовні вирази, написавши ще один умовний вираз після `else`. Якщо перша умова хибна, Python оцінює наступний умовний вираз:

```py
labels = [
    'large' if num > 100
    else 'medium' if num > 10
    else 'small'
    for num in numbers
]
```

Оновіть свій умовний вираз так, щоб він оцінювався у `f'+{difference} °C'`, якщо `difference` більше за `0`, у `f'{difference} °C'`, якщо `difference` менше за `0`, і в рядок `average` в інших випадках.
