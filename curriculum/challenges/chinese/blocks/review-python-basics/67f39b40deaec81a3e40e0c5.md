## 什么是 Python？

- **Python**：Python 是一种通用的编程语言，以其简洁和易用著称。
- **常见用途**：Python 被用于数据科学、机器学习、网页开发、网络安全、嵌入式系统和物联网、脚本编写、自动化，以及树莓派和兼容 MicroPython 的微型计算机等。

## 变量

- **声明变量**：声明变量时，先写变量名，后跟赋值操作符（`=`），然后是值。值可以是数字、字串、布尔值等。以下是一些示例：

```py
name = 'John Doe'
age = 25
```

- **变量命名规范**：变量命名应遵循以下规则：

  - 变量名只能以字母或下划线（`_`）开头，不能以数字开头。
  - 变量名可以包含字母（`a-z`、`A-Z`）、数字（`0-9`）和下划线（`_`）。
  - 变量名区分大小写：`age`、`Age` 和 `AGE` 都被视为不同的变量。
  - 变量名不能是 Python 的保留关键字，如 `if`、`class` 或 `def`。
  - 多词变量名使用下划线分隔，如 `snake_case`。
  - 变量名应描述其用途，如 `user_age`。
  - 当单字母变量名无法传达含义时，应避免使用。

## 注释

- **单行评论**：这种评论用于代码中的简短注释。

```py
# This is a single line comment
```

- **多行评论**：你可以在每行开头使用 `#` 来创建跨多行的评论。

```py
# This is a multi-line comment.
# Here is some code commented out.
#
# name = 'John Doe'
# age = 25
```

## 打印

- **`print()` 函数**：要将数据打印到终端，你可以像这样使用 `print()` 函数：

```py
print('Hello world!') # Hello world!
```

你可以通过逗号分隔向 `print()` 传递多个参数。默认情况下，`print()` 会在它们显示的值之间插入一个空格：

```py
print('Hello', 'world!') # Hello world!
```

## Python 中常见的数据类型

- **动态类型指派**：Python 是动态类型指派语言，意味着你不需要声明变量的数据类型。Python 会根据赋给变量的值自动确定类型。

- **整数**：没有小数部分的整数：

```py
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- **浮点数**：带小数的数字：

```py
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- **字串**：用引号括起来的字符序列：

```py
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- **布尔值**：表示 `True` 或 `False` 的值：

```py
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python 还有其他数据类型。你将在首次需要时学习每一种。

- **`type()` 函数**：要查看变量的类型，你可以像这样使用 `type()` 函数：

```py
greeting = 'Hello there!'
age = 21

print(type(greeting)) # <class 'str'>
print(type(age)) # <class 'int'>
```

- **`isinstance()` 函数**：用于检查变量是否匹配特定数据类型：

```py
greeting = 'Hello world'
name = 'John Doe'

print(isinstance(greeting, str)) # True
print(isinstance(name, int)) # False
```

要检查多个类型，将类型放在括号内，用逗号分隔，并作为第二个参数传入。如果值是任意列出类型的实例，结果为 `True`：

```py
account_balance = 12
print(isinstance(account_balance, (int, float))) # True
```

## 字串操作

- **字串**：字串是字符的序列。在 Python 中，你可以使用单引号或双引号。选择一种风格并保持一致：

```py
developer = 'Jessica'
city = "Los Angeles"
```

- **多行字串**：三重单引号或三重双引号允许字串跨多行：

```py
message = """Hello
world!"""
print(message)
# Hello
# world!
```

- **字串内的引号**：你可以使用相反类型的引号包围字串，以避免转义其中的引号：

```py
msg = "It's a sunny day"
quote = 'She said, "Hello!"'
```

- **转义字串**：如果字串中包含引号，可以使用反斜线（`\`）转义，如下：

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **转义序列**：反斜线与另一个字符组合表示特殊字符。例如，`\n` 表示换行，`\t` 表示制表符，`\\` 表示单个反斜线：

```py
print('Hello\nworld')
# Hello
# world

print('Name:\tAlice')  # Name:   Alice
print('C:\\Users\\Alice')  # C:\Users\Alice
```

- **`in` 操作符**：返回布尔值，表示字符是否存在于字串中：

```py
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

- **获取字串长度**：`len()` 函数返回字串中的字符数：

```py
developer = 'Jessica'

print(len(developer)) # 7
```

- **访问字串中的字符**：可以用方括弧表示法访问字串中的字符，如下：

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **重新赋值和不可变性**：字串是不可变的，这意味着创建后不能更改。重新赋值变量会让它引用不同的值，但不会修改原始字串：

```py
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello
```

不允许直接修改字串：

```py
greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```

整数、浮点数和布尔值也是不可变的。

- **字串串接**：可以使用 `+` 操作符串接字串，如下：

```py
developer = 'Jessica'
print('My name is ' + developer + '.') # My name is Jessica.
```

- **字串重复**：`*` 操作符会重复字串指定的次数：

```py
print('ha' * 3) # hahaha
```

- **字串与数字的连接**：将字串和数字连接会引发 `TypeError`：

```py
'Age: ' + 26 # TypeError: can only concatenate str (not "int") to str
```

`str()` 函数将数字转换为字串，以便进行连接：

```py
print('Age: ' + str(26)) # Age: 26
```

另一种串接方式是使用 `+=` 操作符，它在同一步骤中执行串接和赋值，如下：

```py
greeting = 'My name is '
developer = 'Jessica.'

greeting += developer
print(greeting) # My name is Jessica.
```

`*=` 操作符重复字串并将结果赋值回变量：

```py
sound = 'ha'
sound *= 3
print(sound) # hahaha
```

`+=` 和 `*=` 都是将新字串赋值给变量，而不修改原始字串。

- **`f-strings`**：即格式化字串字面值，允许你用简洁易读的语法进行插值和串接：

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

f-strings 中的替换字段可以包含表达式。Python 会计算表达式并将其值插入字串中：

```py
num1 = 5
num2 = 10
print(f'The sum is {num1 + num2}') # The sum is 15
```

- **字串切片**：提取字串的部分内容。基本语法如下：

```py
str[start:stop:step]
```

`start` 索引指定提取的起始位置。`stop` 索引是不包含的，因此该索引处的字符不包括在内。`step` 指定选取索引的间隔，默认值为 `1`。当 `step` 为正时，省略的 `start` 默认为字串开头，省略的 `stop` 默认为字串结尾。`[:]` 提取整个字串。`[::-1]` 通过从最后一个字符向第一个字符反向步进来反转字串。切片不会修改原始字串。

```py
message = 'Python is fun!'

print(message[0:6])  # Python
print(message[:6])  # Python
print(message[7:])  # is fun!
print(message[::2])  # Pto sfn
print(message[:])  # Python is fun!
print(message[::-1])  # !nuf si nohtyP
```

## 常用字串方法

- **方法**：方法是你对一个值调用的函数。调用字串方法时，写出字串或其变量名，后跟点号和方法调用。

- **`str.upper()`**：这将返回一个所有字符都转换为大写的新建字串：

```py
developer = 'Jessica'

print(developer.upper()) # JESSICA
```

- **`str.lower()`**：这将返回一个所有字符都转换为小写的新建字串：

```py
developer = 'Jessica'

print(developer.lower()) # jessica
```

- **`str.strip()`**：这将返回一个字串的拷贝，移除指定的前导和尾随字符（如果没有传递参数给该方法，则移除前导和尾随的空白字符）。

```py
greeting = '  hello world  '

trimmed_my_str = greeting.strip()
print(trimmed_my_str)  # hello world
```

- **`replace()`**：返回替换所有旧字串为新字串后的新字串：

```py
greeting = 'hello world'

replaced_my_str = greeting.replace('hello', 'hi')
print(replaced_my_str)  # hi world
```

- **`split()`**：用于使用指定的分隔符将字串拆分成列表。分隔符是指定拆分位置的字串。如果未指定分隔符，`split()` 会以空白字符拆分。

```py
dashed_name = 'example-dashed-name'

split_words = dashed_name.split('-')
print(split_words)  # ['example', 'dashed', 'name']
```

- **`join()`**：用于将一个字符串集合用分隔符连接成一个字符串。

```py
example_list = ['example', 'dashed', 'name']

joined_str = ' '.join(example_list)
print(joined_str)  # example dashed name
```

- **`str.startswith(prefix)`**：这将返回一个布尔值，指示字串是否以指定的前缀开始：

```py
developer = 'Naomi'

result = developer.startswith('N')
print(result)  # True
```

- **`str.endswith(suffix)`**：这将返回一个布尔值，指示字串是否以指定的后缀结尾：

```py
developer = 'Naomi'

result = developer.endswith('N')
print(result)  # False
```

- **`str.find()`**：返回子字串首次出现的索引。如果未找到，则返回 `-1`：

```py
developer = 'Naomi'

result = developer.find('N')
print(result)  # 0

city = 'Los Angeles'
print(city.find('New')) # -1
```

- **`str.count(substring)`**：计算子字串在字串中出现了多少次（不重叠）。一旦找到匹配，搜索会从该匹配结束后继续：

```py
city = 'Los Angeles'
print(city.count('e')) # 2

# Matches do not overlap, so this is 2, not 3
print('aaaa'.count('aa')) # 2
```

- **`str.capitalize()`**：这将返回一个新建的字串，其中第一个字符大写，其他字符小写：

```py
dessert = 'chocolate cake'
print(dessert.capitalize()) # Chocolate cake
```

- **`str.isupper()`**：如果字串包含至少一个有大小写的字符且所有有大小写的字符均为大写，则返回 `True`。否则返回 `False`：

```py
dessert = 'chocolate cake'
print(dessert.isupper()) # False
```

- **`str.islower()`**：如果字串包含至少一个有大小写的字符且所有有大小写的字符均为小写，则返回 `True`。否则返回 `False`：

```py
dessert = 'chocolate cake'
print(dessert.islower()) # True
```

- **`str.title()`**：返回一个新字串，其中每个单词的首字母大写，其余字母小写：

```py
city = 'lOS aNGELES'
print(city.title()) # Los Angeles
```

## 更多字串操作

- **负数切片边界**：切片边界可以从字串末尾向后计数。例如，`[-3:]` 提取最后三个字符：

```py
employee_code = 'DEV-2026-JD-001'
print(employee_code[-3:]) # 001
```

- **方法链**：你可以在一个表达式中调用多个字串方法。每个方法作用于前一个调用的结果：

```py
name = '  jANE dOE  '
print(name.strip().title()) # Jane Doe
```

## 整数和浮点数的常用操作

- **基本数学操作**：在 Python 中，你可以对整数和浮点数进行基本的数学操作，包括加法、减法、乘法和除法：

```py
int_1 = 56
int_2 = 12
float_1 = 5.4
float_2 = 12.0

# Addition

print('Integer Addition:', int_1 + int_2) # Integer Addition: 68
print('Float Addition:', float_1 + float_2) # Float Addition: 17.4

# Subtraction

print('Int Subtraction:', int_1 - int_2) # Int Subtraction: 44
print('Float Subtraction:',  float_2 - float_1) # Float Subtraction: 6.6

# Multiplication

print('Int Multiplication:', int_1 * int_2) # Int Multiplication: 672
print('Float Multiplication:', float_2 * float_1) # Float Multiplication: 64.80000000000001

# Division

print('Division:', int_1 / int_2) # Division: 4.666666666666667
print('Float Division:', float_2 / float_1) # Float Division: 2.222222222222222
```

当加法操作中包含浮点数和整数时，结果会转换为浮点数，如下：

```py
int_1 = 56
float_1 = 5.4

print(int_1 + float_1) # 61.4
```

- **取模运算符（`%`）**：返回两个数相除的余数：

```py
int_1 = 56
int_2 = 12

print(int_1 % int_2) # 8
```

- **向下取整除法（`//`）**：除法后向下取整到最接近的整数：

```py
int_1 = 56
int_2 = 12

print(int_1 // int_2) # 4
```

- **幂运算符（`**`）**：用于计算一个数的幂：

```py
int_1 = 4
int_2 = 2

print(int_1 ** int_2) # 16
```

- **浮点数近似**：某些十进制分数无法用二进制精确表示，因此以有限近似值存储。这可能导致小的舍入误差，比如上面 `64.80000000000001` 的乘法结果。

```py
print(0.1 + 0.2) # 0.30000000000000004
```

- **`float()` 函数**：你可以用此函数将整数或有效的十进制字串转换为浮点数，或者创建表示正无穷大的特殊浮点值，它比任何有限整数或浮点数都大：

```py
num = 4

print(float(num)) # 4.0
print(float('7.8')) # 7.8
print(float('inf')) # inf
```

- **`int()` 函数**：将浮点数转换为整数：

```py
num = 4.0

print(int(num)) # 4
```

- **`round()` 函数**：传入一个参数时，将数字四舍五入到最接近的整数。传入第二个参数可指定小数位数：

```py
num_1 = 3.4
num_2 = 7.7

print(round(num_1)) # 3
print(round(num_2)) # 8
print(round(3.14159, 2)) # 3.14
```

- **`abs()` 函数**：返回数字的绝对值：

```py
num = -13

print(abs(num)) # 13
```

- **`pow()` 函数**：将一个数字提升到另一个数字的幂。对于整数参数，可以传入第三个非零参数计算模值：

```py
result = pow(2, 3)
print(result)  # 8
print(pow(2, 3, 5)) # 3
```

## 使用 `if`、`elif` 和 `else` 语句

- **代码块和缩排**：Python 使用缩排将语句分组为块，例如函数体或条件体。相同块内的语句必须使用相同缩排级别。惯例是每级缩排使用四个空格。

- **`pass` 语句**：`pass` 不执行任何操作。用作占位符，当 Python 需要语句但你暂时不想写任何代码时使用，例如空条件体：

```py
age = 18
if age >= 18:
    pass
```

- **`if` 语句**：当 Python 将条件视为真时，`if` 语句会运行它的体。

```py
age = 18

if age >= 18:
    print('You are an adult') # You are an adult
```

- **`else` 子句**：当 Python 认为同一 `if...elif...else` 链中所有前述条件都为假时，`else` 子句会执行其体。

```py
age = 12

if age >= 18:
    print('You are an adult')
else:
    print('You are not an adult yet') # You are not an adult yet
```

- **`elif` 子句**：当 Python 认为同一链中所有前述条件都为假时，`elif` 子句会测试另一个条件。如果 Python 认为它自己的条件为真，则执行其体。

```py
age = 16

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')  # You are a teenager
```

你也可以使用嵌套的 `if` 语句，如下：

```py
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

## 真值和假值

- **真值性**：在 Python 中，每个值都有内在的布尔值，表示在逻辑上下文中应被视为 `True` 还是 `False`。许多值被视为真值，即在逻辑上下文中求值为 `True`。其他值为假值，求值为 `False`。以下是一些假值示例：

```md
False
None
Integer 0
Float 0.0
Empty strings ''
```

其他值如非零数字和非空字串是真值。

## 使用 `bool()` 函数

- **`bool()` 函数**：如果你想检查一个值是真值还是假值，可以使用内置的 `bool()` 函数。它显式将值转换为布尔等价，并对真值返回 `True`，对假值返回 `False`。以下是几个示例：

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

## 布尔操作符与短路求值

- **布尔操作符**：这些特殊操作符允许你组合多个表达式，在代码中创建更复杂的决策逻辑。Python 有三个布尔操作符：`and`、`or` 和 `not`。
- **`and` 操作符**：该操作符接受两个操作对象，如果第一个操作对象是假值，则返回第一个操作对象；否则返回第二个操作对象。表达式要为真值，两个操作对象都必须为真值。

```py
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

你也可以在条件语句中使用 `and` 操作符，如下：

```py
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

- **`or` 操作符**：该操作符返回第一个操作对象（如果它为真值）；否则返回第二个操作对象。`or` 表达式如果至少有一个操作对象为真值，则结果为真值。示例如下：

```py
age = 19
is_employed = False

print(age or is_employed) # 19
```

和 `and` 操作符一样，你也可以在条件语句中使用 `or` 操作符：

```py
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

- **短路求值**：`and` 和 `or` 操作符被称为短路操作符。短路求值意味着 Python 从左到右检查值，一旦确定最终结果就停止。
- **`not` 操作符**：接受单个操作数，取反其布尔值。将真值转换为 `False`，假值转换为 `True`。与之前的操作符不同，`not` 总是返回 `True` 或 `False`。示例如下：

```py
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

下面是 `not` 操作符在条件语句中的示例：

```py
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

## 同一性操作符

- **同一性和相等性**：变量引用对象。`is` 操作符检查两个操作对象是否引用同一对象，`is not` 检查是否引用不同对象。`==` 和 `!=` 操作符比较值。比较数字或字串值时应使用相等操作符。
- **`None` 和 `NoneType`**：`None` 表示无值。它是 `NoneType` 数据类型的唯一值。
- **单例**：`None`、`True` 和 `False` 都是单例，意味着每个只有一个对象。你可以用同一性操作符检查这些对象。
- **检查 `None`**：用 `is None` 检查缺失值，用 `is not None` 检查存在值。`None` 和 `False` 都是假值，但它们是不同对象：

```py
response = False

print(response is None) # False
print(response is not None) # True
print(response is True) # False
print(response is False) # True
```

- **同一性和真值性**：如果 `response` 可能是 `True`、`False` 或 `None`，`response is None` 区分缺失答案和否定答案。使用 `not response` 会将 `False` 和 `None` 一视同仁。对于普通布尔标记，使用 `if is_ready` 或 `if not is_ready`。当你需要特别区分布尔对象和其他可能值时，使用 `is True` 或 `is False`。

## 布尔操作符优先级

- **操作符优先级和括号**：当 `and` 和 `or` 出现在同一表达式中时，`and` 的优先级高于 `or`。这意味着 `and` 会先组合它的操作对象，所以 `True or False and False` 会被组合为 `True or (False and False)`：

```py
print(True or False and False) # True
```

`or` 的左操作对象是 `True`，因此短路意味着 `False and False` 不会被计算，结果是 `True`。

你可以使用括号改变组合方式。这里，`True or False` 被组合在一起并计算为 `True`，然后 `True and False` 计算为 `False`：

```py
print((True or False) and False) # False
```

```py
name = input('What is your name?') # User types 'Kolade' and presses Enter
print('Hello', name) # Hello Kolade
```

## 函数操作

- **函数**：函数是可重用的代码块，调用时执行。调用函数时，需要引用函数名，后跟一对括号：

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

- **参数和实参**：参数是函数定义中列出的名称，如上例中的 `num_1` 和 `num_2`。实参是调用函数时传入的值，如 `3` 和 `4`。

如果调用函数时参数数量不正确，会抛出 `TypeError`：

```py
def calculate_sum(a, b):
    print(a + b)

calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

- **位置参数**：这些实参按调用时的位置与参数匹配。

```py
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

- **关键字参数**：这些实参使用 `name=value` 形式按名称匹配参数。它们可以与参数顺序不同：

```py
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

- **参数类型组合**：位置参数必须在关键字参数之前。每个参数只能接收一个值：

```py
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

- **`return` 语句**：`return` 语句结束函数，并将其值返回到调用处。

- **`None`**：`None` 表示无值。如果函数没有显式返回值，默认返回 `None`：

```py
def greet():
    print('hello')

result = greet() # hello
print(result) # None
```

## Python 中的作用域

Python 有额外的作用域规则。现在，先专注于局部作用域和全局作用域。

- **全局作用域**：在函数外部创建的变量可以在函数内外使用。

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + (subtotal * tax)
    return total

print(get_total(100))  # 170.0
```

- **局部作用域**：在函数内部创建的变量只能在该函数内使用。函数参数也是局部变量。

```py
def my_func():
    num = 10
    print(num)
```

- **参数传递和参数重新赋值**：Python 通过赋值传递参数。参数是局部名称，最初引用传入的对象；对象不会自动复制。重新赋值参数不会重新赋值传入的变量：

```py
def double_number(number):
    number = number * 2
    print(number) # 20

original = 10
double_number(original)
print(original) # 10
```

## 应用函数和作用域

- **空函数体**：你可以在函数体中使用 `pass` 作为占位符。只包含 `pass` 的函数隐式返回 `None`：

```py
def placeholder():
    pass

print(placeholder()) # None
```

- **名称遮蔽**：当局部参数或变量与全局变量同名时，函数使用局部名称。重新赋值该局部参数不会改变全局变量：

```py
available_eggs = 5

def use_eggs(available_eggs, eggs_to_use):
    available_eggs -= eggs_to_use
    return available_eggs

print(use_eggs(available_eggs, 1)) # 4
print(available_eggs) # 5
```

- **提前返回**：`return` 语句立即结束函数，并将其值返回到调用处。这允许你在满足条件时提前返回：

```py
def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        return available_eggs
    return available_eggs - eggs_to_use

print(use_eggs(2, 3)) # 2
print(use_eggs(2, 1)) # 1
```

- **函数调用其他函数**：函数可以调用另一个函数，并使用或返回其结果：

```py
def use_eggs(available_eggs, eggs_to_use):
    return available_eggs - eggs_to_use

def make_fried_egg(available_eggs):
    return use_eggs(available_eggs, 1)

print(make_fried_egg(3)) # 2
```

- **赋值返回值**：返回新值不会自动更新作为实参传入的变量。要更新它，需将返回值赋回该变量：

```py
available_eggs = use_eggs(available_eggs, 1)
print(available_eggs) # 4
```

## 字串转换

- **`str.maketrans()`**：`str.maketrans()` 的双字串形式接受等长的两个字串，将第一个字串中的每个字符映射到第二个字串中对应的字符。映射表以 Unicode 编码数字存储字符。`translate()` 方法应用该映射表到字串并返回新字串。未包含在映射表中的字符保持不变。

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc!'.translate(trans_table)
print(result)  # 123123!
```

## 验证整数参数

- **布尔值和整数**：Python 将布尔值视为特殊的整数，因此 `isinstance(True, int)` 和 `isinstance(False, int)` 都返回 `True`。验证必须非布尔的整数时，应显式排除布尔值：

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True

value = True
print(isinstance(value, int) and not isinstance(value, bool)) # False

value = 5
print(isinstance(value, int) and not isinstance(value, bool)) # True
```

## 默认参数值

- **默认参数**：你可以为参数提供默认值。调用函数时如果省略该参数，Python 会使用默认值：

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```
