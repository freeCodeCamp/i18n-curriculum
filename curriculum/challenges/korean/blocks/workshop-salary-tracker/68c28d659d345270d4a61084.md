# --description--

`__repr__` 메서드는 객체를 생성하는 데 사용할 수 있는 문자열 표현을 반환해야 하는 특별한 메서드입니다.

예를 들어, `__repr__`의 `Employee('Charlie', 'developer')` 메서드는 객체를 생성하는 데 사용된 문자열과 같은 `Employee('Charlie', 'developer')` 문자열을 반환해야 합니다.

각 값에 따옴표가 있으면, 값에 따옴표가 포함될 때 결과가 깨집니다. 예를 들어 이름이 `O'Reilly`이고 레벨이 `junior`인 직원의 경우, `Employee('O'Reilly', 'junior')`가 되는데, 이는 아포스트로피가 문자열을 일찍 닫기 때문에 유효하지 않습니다.

Python의 내장 `repr()` 함수는 값의 문자열 표현을 반환합니다. 문자열의 경우, 따옴표를 추가하고 필요한 문자를 이스케이프합니다:

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

f-문자열 안에서는 표현식 뒤에 `!r`을 추가해 `repr()`을 적용할 수 있습니다:

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

`Employee` 클래스에 `self` 매개변수를 가진 `__repr__` 메서드를 만드세요. `self.name`과 `self.level`에 `!r`을 사용해 따옴표나 역슬래시가 보존되도록 하여 객체를 생성하는 데 사용할 수 있는 문자열을 반환하게 하세요.
