# --description--

Nas últimas aulas, você tem se familiarizado com o uso de loops assim:

```py
even_numbers = []

for num in range(21):
    if num % 2 == 0:
        even_numbers.append(num)

print(even_numbers)
```

Este exemplo cria uma nova lista vazia chamada `even_numbers` e percorre uma sequência de números entre `0` e `20`. Dentro do loop, há uma condição que verifica se o número atual tem um resto de `0` quando dividido por `2`. Isto é usado para determinar se o número é par. Se a condição for `True`, então o `num` atual é adicionado ao final da lista `even_numbers`. Finalmente, imprimimos a lista `even_numbers` no console.

## O que é list comprehension?

Embora esse código funcione, existe uma forma mais concisa de escrevê-lo usando list comprehension. A list comprehension permite criar uma nova lista em uma única linha escrevendo um loop diretamente dentro de colchetes. Isso torna o código mais curto e frequentemente mais fácil de ler.

A sintaxe básica de uma list comprehension é assim:

```py
[expression for item in iterable]
```

Para cada item no iterável, a expressão antes do `for` é avaliada, e o resultado é adicionado à nova lista. Aqui está um exemplo que cria uma lista com cada número de `0` a `4` multiplicado por `2`:

```py
doubled = [num * 2 for num in range(5)]
print(doubled) # [0, 2, 4, 6, 8]
```

## Filtrando com um `if` no final

Opcionalmente, você pode adicionar uma condição `if` no final de uma list comprehension. Apenas os itens para os quais a condição é verdadeira são adicionados à nova lista, enquanto os outros são ignorados.

Aqui está o exemplo dos números pares de antes, reescrito usando list comprehension:

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

Neste exemplo refatorado, a lista `even_numbers` é criada usando uma única linha de código. A list comprehension percorre os números de `0` a `20` e inclui apenas aqueles que são divisíveis por `2`. Esta abordagem é mais compacta e elimina a necessidade de um loop separado e um bloco condicional.

## Criando listas internas separadas

Anteriormente, você aprendeu que `[[]] * 3` repete referências para uma única lista interna. Uma comprehension pode criar uma lista interna separada a cada iteração:

```py
rows = [[] for _ in range(3)]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

A expressão `[]` é avaliada em cada iteração, então cada posição se refere a uma lista diferente. A variável do loop não é usada na expressão; o range apenas controla quantas listas são criadas.

Quando uma variável de loop não é necessária, desenvolvedores Python a nomeiam convencionalmente como `_` para indicar que seu valor é intencionalmente ignorado. `_` ainda é um nome de variável comum.

## Usando expressões condicionais em list comprehensions

Até agora, você usou `if` e `else` para escrever declarações condicionais. Python também tem uma expressão condicional, que é escrita em uma única linha e produz um valor. Aqui está sua sintaxe:

```py
value_if_true if condition else value_if_false
```

Se a condição for verdadeira, toda a expressão avalia para o valor antes do `if`. Caso contrário, avalia para o valor depois do `else`. Aqui está um exemplo:

```py
num = 7
label = 'Even' if num % 2 == 0 else 'Odd'
print(label) # Odd
```

Como `7` não é divisível por `2` de forma exata, a condição é `False`, e `'Odd'` é atribuído a `label`.

Você pode usar uma expressão condicional como a expressão antes do `for` em uma list comprehension. Nesse caso, ela escolhe um valor para cada item no iterável, então a nova lista tem o mesmo número de itens que a original. Isso é diferente de um `if` no final, que pode excluir itens da nova lista.

Vamos dar uma olhada em um exemplo:

```py
numbers = [1, 2, 3, 4, 5]
result = [(num, 'Even') if num % 2 == 0 else (num, 'Odd') for num in numbers]
print(result)
```

Neste exemplo, temos uma lista de números e queremos criar uma nova lista de tuplas indicando quais números são pares ou ímpares. Na primeira parte da list comprehension, usamos uma expressão condicional `if`/`else` para verificar se o número é divisível por `2`. Se for, o resultado é uma tupla com esse número seguida da palavra `Even`. Caso contrário, o resultado é uma tupla com o número seguida da palavra `Odd`.

Aqui está como o resultado aparece impresso no console:

```py
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

## Filtrando listas com `filter()`

Outra forma de criar uma lista a partir de um iterável existente é a função `filter()`. Aqui está um exemplo de como criar uma nova lista apenas com palavras com mais de quatro caracteres:

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

A função `filter()` é usada para selecionar elementos de um iterável que atendem a uma condição específica. A função `filter()` aceita uma função e um iterável como argumentos. Neste exemplo, estamos passando uma função `is_long_word` para a função `filter()` para verificar se o número de caracteres na palavra atual é maior que `4`. `is_long_word` é escrita sem parênteses porque você está passando a função em si, não chamando-a. A função `filter()` chama `is_long_word` em cada palavra para você. Assim como `zip()`, a função `filter()` retorna um iterador, que fornece apenas as palavras que atendem à condição. A função `list()` coleta essas palavras em uma nova lista, que é atribuída à variável `long_words`.

## Transformando listas com `map()`

Além da função `filter()`, existem mais algumas funções que são úteis ao trabalhar com listas. Outra função para ficar atento é a função `map()`, que recebe um iterável e aplica uma função a cada um de seus elementos. Aqui está um exemplo de uso da função `map()` para converter uma lista de temperaturas de Celsius para Fahrenheit:

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

Assim como a função `filter()`, `map()` aceita uma função e um iterável como argumentos. A função `to_fahrenheit` recebe uma temperatura e a converte de Celsius para Fahrenheit. Novamente, `to_fahrenheit` é passada sem parênteses, e `map()` a chama em cada temperatura da lista `celsius`. A função `map()` também retorna um iterador, desta vez dos valores convertidos, então `list()` é usada novamente para coletá-los em uma lista.

## Somando valores com `sum()`

A última função que vamos analisar é a função `sum()`. Esta função é usada para obter a soma de um iterável como uma lista ou tupla. Aqui está um exemplo de uso da função `sum()`:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

Você também pode passar um argumento opcional `start` que define o valor inicial para a soma. Aqui está um exemplo atualizado usando o argumento `start` como um argumento posicional:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

Você também pode optar por usar o argumento `start` como um argumento nomeado assim:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

Ambas as versões produzirão o mesmo resultado, mas o argumento de palavra-chave é um pouco mais explícito.

Compreensão de listas assim como outras funções como `map()`, `filter()` e `sum()` podem parecer um pouco confusas no começo. Mas com prática e tempo suficientes, você começará a se sentir mais confortável usando-os em seus programas Python.
