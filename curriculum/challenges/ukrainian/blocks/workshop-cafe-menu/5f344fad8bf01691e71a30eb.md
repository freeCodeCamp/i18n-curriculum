# --description--

До цього моменту у вас був обмежений контроль над презентацією та виглядом вашого вмісту. Щоб це змінити, ви будете використовувати CSS.

Один зі способів додати CSS на сторінку — це використати `style` елемент, який зазвичай розміщують у `head` тегу. Будь-яке CSS правило всередині `style` тегу застосовується до всієї сторінки. Ось приклад:

```html
<style>
  p {
    color: green;
  }
</style>
```

Додайте `style` елемент всередині `head` елемента.

# --hints--

У вашому коді має бути `style` елемент.

```js
assert.exists(document.querySelector('style:not(.fcc-hide-header)'));
```

Ваш код має містити закриваючий тег `</style>`.

```js
assert.match(code, /<\/style\s*>/i);
```

Ваш елемент `style` має бути вкладений у ваш елемент `head`.

```js
assert.exists(document.querySelector('head > style:not(.fcc-hide-header)'));
```
