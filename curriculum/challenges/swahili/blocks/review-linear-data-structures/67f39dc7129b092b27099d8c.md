## Safu za data

- **Safu za data za kudumu**: Zina ukubwa thabiti unaoamuliwa wakati wa uanzishaji. Vipengele vinahifadhiwa katika maeneo ya kumbukumbu yanayopakana, ambayo hufanya upatikanaji kuwa wa haraka sana. Ukubwa wao hauwezi kubadilika wakati programu inaendelea kukimbia.

- **Safu za data zinazobadilika**: Zinaweza kukua au kupungua kiotomatiki wakati programu inaendelea kukimbia. Safu ikijaa, vipengele vyake huhamishwa kwenye safu mpya kubwa zaidi. Ukubwa mpya huchaguliwa ili nakala hizi ghali zisifanyike mara kwa mara.

- **Safu za data za kudumu katika Python**: Python haina safu za data za kudumu za jadi kama muundo wa data uliyojengwa ndani. Lugha nyingine, kama Java, zinaunga mkono safu hizo.

### Orodha za Python (safu za mabadiliko)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### Ugumu wa wakati kwa safu za mabadiliko

- **Upatikanaji**: O(1)
- **Ingiza mwishoni**: O(1) ikiwa kuna nafasi, O(n) wakati uanzishaji upya unahitajika
- **Ingiza katikati**: O(n) kwa sababu vipengele vilivyoko baada yake vinahitaji kuhamishwa

### Kuchagua kati ya safu za data za kudumu na zinazobadilika

- **Safu za data za kudumu**: Unapojua idadi ya vipengele mapema na unahitaji kuzipata mara kwa mara.
- **Safu za data zinazobadilika**: Unapokuwa idadi ya vipengele haijulikani au hubadilika kwa muda, au unapokuwa unafanya mara kwa mara uingizaji na ufutaji wa vipengele.

## Staki

- **Stacki**: Muundo wa data wa Last-In, First-Out (LIFO). Stacki zina ncha mbili, juu na chini. Vipengele huongezwa na kuondolewa kutoka juu tu.

- **Operesheni ya Push**: Kuongeza kipengele juu ya stacki. Unapotumia orodha ya Python, hii huchukua muda wa O(1) ikiwa kuna nafasi, au O(n) wakati uanzishaji upya unahitajika.

- **Operesheni ya Pop**: Kuondoa kipengele kutoka juu ya stacki. Ugumu wa muda: O(1). Ugumu wa nafasi: O(1).

```python
# Using a Python list as a stack, where the end of the list is the top
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operation
top_element = stack.pop()  # Returns 3
```

## Foleni

- **Queue**: Muundo wa data wa First-In, First-Out (FIFO). Queue zina ncha mbili, mbele na nyuma. Vipengele huongezwa nyuma na kuondolewa mbele.

- **Operesheni ya Enqueue**: Kuongeza kipengele nyuma ya queue. Unapotumia orodha ya Python, hii huchukua muda wa O(1) ikiwa kuna nafasi, au O(n) wakati uanzishaji upya unahitajika.

- **Operesheni ya Dequeue**: Kuondoa kipengele kutoka mbele ya queue. Kipengele kinachofuata kinakuwa mbele mpya. Ugumu wa muda: O(1). Ugumu wa nafasi: O(1).

```python
# Using a Python list as a queue, where the start of the list is the front
queue = []

# Enqueue operations
queue.append(1)
queue.append(2)
queue.append(3)

# Front element
front_element = queue[0]  # 1

# Dequeue operation
front_element = queue.pop(0)  # Returns 1
```

- **Kumbuka**: Kuondoa kipengele cha kwanza katika orodha ya Python kwa kutumia `.pop(0)` kunahamisha vipengele vyote vilivyobaki, hivyo huchukua muda wa O(n).

## Orodha zilizounganishwa

- **Orodha zilizounganishwa**: Muundo wa data wa mstari ambapo kila nodi huhifadhi data na rejea kwa nodi inayofuata. Nodi zinaunganishwa kama mnyororo. Orodha zilizounganishwa hazina ukubwa thabiti na zinaweza kukua au kupungua kwa kusasisha uhusiano kati ya nodi.

- **Matumizi ya kawaida**: Kutekeleza miundo mingine ya data, kama stacki, queue, na deque, pamoja na algoriti za grafu kama utafutaji wa kina kwanza na utafutaji wa upana kwanza.

### Orodha zilizounganishwa za peke yake

- **Muundo**: Kila nodi huhifadhi data na rejea moja kwa nodi inayofuata.
- **Kupitia**: Inaweza kusogea mbele tu, kutoka kichwa hadi mkia.
- **Nodi ya kichwa**: Nodi ya kwanza katika orodha, kawaida ndiyo nodi pekee inayopatikana moja kwa moja. Kupitia huanza hapa.
- **Nodi ya mkia**: Nodi ya mwisho katika orodha. Rejea yake kwa nodi inayofuata ni `None`, ambayo inaashiria mwisho wa orodha.

#### Kuingiza nodi

- **Ingiza mwanzoni**: O(1) - ungana nodi mpya na kichwa cha zamani na uitengeneze kichwa kipya
- **Ingiza mwishoni**: O(n) - lazima upitie hadi mwisho, kisha unganishe mkia na nodi mpya
- **Ingiza katikati**: O(n) - lazima upitie hadi nafasi, kisha unganishe nodi ya awali na nodi mpya na nodi mpya na nodi inayofuata
- **Ugumu wa nafasi**: O(1) - nodi mpya tu ndio huundwa

#### Kuondoa nodi

- **Ondoa mwanzoni**: O(1) - fanya nodi inayofuata kuwa kichwa kipya
- **Ondoa katikati**: O(n) - lazima upitie hadi nodi, kisha unganishe nodi ya awali na nodi inayofuata, kuunda "daraja" juu ya nodi iliyotolewa
- **Ondoa mwishoni**: O(n) - lazima upitie hadi mwisho, kisha ondoa uhusiano wa nodi ya awali, na kuitengeneza mkia mpya
- **Ugumu wa nafasi**: O(1) - hakuna kumbukumbu ya ziada inayohitajika

### Orodha zilizounganishwa mara mbili

- **Muundo**: Kila nodi huhifadhi data na rejea mbili: moja kwa nodi inayofuata na moja kwa nodi ya awali.
- **Kupitia**: Inaweza kusogea katika mwelekeo yote miwili.
- **Rejea ya mkia**: Ni kawaida kuweka rejea ya nodi ya mkia ndani ya orodha yenyewe. Hii huruhusu kuongeza nodi mwishoni kwa muda wa O(1), bila kupitia orodha, na kuanza kupitia kutoka mwisho.
- **Kuingiza na kufuta**: Hufanya kazi kama katika orodha iliyounganishwa mara moja, lakini rejea mbili kwa nodi lazima zisasiswe.
- **Kumbukumbu**: Inahitaji kumbukumbu zaidi kuliko orodha iliyounganishwa mara moja kwa sababu kila nodi huhifadhi rejea mbili badala ya moja.

## Wakati wa kutumia kila muundo wa data

- **Safu za data za kudumu**: Unapojua idadi ya vipengele mapema na unahitaji upatikanaji wa haraka na wa mara kwa mara
- **Safu za data zinazobadilika (Orodha)**: Unapohitaji upatikanaji uliopangwa, wenye kielezo na haujui ukubwa mapema
- **Stacki**: Unapotaka kipengele cha mwisho kuongezwa kuwa cha kwanza kuondolewa (LIFO)
- **Queue**: Unapotaka vipengele kushughulikiwa kwa mpangilio waliongezwa (FIFO)
- **Orodha zilizounganishwa mara moja**: Unapokuwa ukubwa hubadilika mara kwa mara na unafanya zaidi uingizaji na ufutaji mwanzoni
- **Orodha zilizounganishwa mara mbili**: Unapohitaji kupitia katika mwelekeo yote miwili au kuongeza vipengele mwishoni kwa ufanisi, na kumbukumbu ya ziada kwa nodi inakubalika
