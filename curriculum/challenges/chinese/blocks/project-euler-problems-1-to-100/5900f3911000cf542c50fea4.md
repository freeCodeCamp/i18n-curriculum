# --description--

数字 3797 有一个有趣的属性。它本身是素数，可以从左到右连续去掉数字，并且每一步仍然是素数：3797、797、97 和 7。同样，我们也可以从右到左操作：3797、379、37 和 3。

找到从左到右和从右到左都可截断的唯一`n`（8 &lt;= `n` &lt;= 11）个素数之和。

注意：2,3,5和7不被认为是可截断的素数。
