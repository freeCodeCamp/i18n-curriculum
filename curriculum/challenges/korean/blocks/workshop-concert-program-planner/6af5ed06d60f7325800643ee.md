# --description--

특정 위치에 항목을 추가하려면 `insert()` 메서드를 사용하세요. 이 메서드는 새 항목이 들어갈 인덱스와 그 다음에 항목 자체를 받습니다. 해당 인덱스부터 뒤에 있는 항목들은 한 칸씩 오른쪽으로 밀립니다.

```py
fruits = ['apple', 'banana', 'cherry']
fruits.insert(1, 'blueberry')
print(fruits) # ['apple', 'blueberry', 'banana', 'cherry']
```

지휘자는 두 개의 슬라브 무곡이 연달아 연주되길 원합니다. `insert()`를 사용해 문자열 `Slavonic Dance No. 1`을 `pieces`에 `Slavonic Dance No. 8` 바로 앞에 추가하세요.
