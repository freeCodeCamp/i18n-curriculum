# --description--

遞迴呼叫會一次往下走一個樹的層次，但它們需要一個停止的地方。有兩種情況：

- `node.key` 相等於 `key`：你找到你正在尋找的值的節點。
- `node` 是 `None`：搜尋超過了葉節點，所以該值不在樹中。

在 `_search` 方法的開頭，在你現有的 `if` 述語之前，新增一個 `if` 述語來檢查 `node` 是否為 `None` 或 `node.key` 是否相等於 `key`，並從中傳回 `node`。這樣，該方法會傳回包含該值的節點，或者如果該值不在樹中則傳回 `None`。
