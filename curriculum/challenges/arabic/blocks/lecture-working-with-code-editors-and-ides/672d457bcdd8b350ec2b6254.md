# --description--

امتداد Better Comments يوفّر تمييزًا خاصًا لأنواع محددة من تعليقات الكود. على سبيل المثال، يبرز تعليقات "TODO"، بالإضافة إلى صيغة نحوية تشير إلى الأسئلة أو التحذيرات.

يميز Code Spell Checker الكلمات التي تحتوي على أخطاء إملائية في كودك. وبما أنه مصمم لملفات الكود، فإنه يأخذ في الاعتبار أشياء مثل camel case.

يجعل Error Lens أخطاء الكود أصعب في التغاضي عنها. بدلًا من الاعتماد على التسطير الذي يعرضه VS Code افتراضيًا، يبرز هذا الامتداد السطر بأكمله ويعرض رسالة الخطأ مضمَّنة.

يضيف Indent Rainbow ألوانًا لمستويات التراجع المختلفة في الكود. وبالاشتراك مع تلوين أزواج الأقواس الأصلي في VS Code، يساعد هذا بشكل كبير في تحديد نطاق الكود الذي تعمل عليه.

أو ربما تبحث عن شيء أكثر عملية؟ فكّر في مساعد ذكي، مثل GitHub Copilot أو Tabnine، ليقدم لك اقتراحات مضمَّنة أثناء كتابة الكود.

حزمة أيقونات، مثل VS Code Great Icons، تساعد في جعل شجرة الملفات أنظف وأسهل للفهم بنظرة سريعة. وامتداد مثل Colorize يساعدك على فهم القيم في خصائص CSS الخاصة بك.

ستحتاج أيضًا إلى امتدادات خاصة باللغات لمشاريعك. إذا كنت تستخدم JavaScript، فغالبًا ما تحتاج إلى ESLint وPrettier لفحص وتنسيق الكود. وإذا كنت تستخدم TypeScript، فقد ترغب في Pretty TypeScript Errors لرسائل أسهل في القراءة.

أخيرًا، يمكنك أيضًا الاستمتاع قليلاً مع محررك. VS Code Pets يوفّر حيوانات أليفة افتراضية قابلة للتخصيص لتبقيك رفيقًا أثناء إصلاح الأخطاء البرمجية.

يُنشئ Power Mode تأثيرات بصرية لافتة عندما تحقق "combo" عاليًا بكتابة المزيد من الكود.

Discord Presence يتيح لك عرض ما تعمل عليه لجميع أصدقائك.

وهناك الكثير من الإضافات الأخرى. استكشف سوق الإضافات لترى ما يناسبك أكثر.
