# --description--

再帰は、関数が自分自身を呼び出す手法です。各呼び出しは元の問題のより小さなバージョンに取り組み、再帰を停止させる条件に達するまで続きます。その停止条件を基底ケースと呼びます。

再帰関数は、ファイルツリーの走査のように深さが不明な問題を解決できます。また、与えられた数からカウントダウンするなど、より単純なタスクも実行できます。

`recursive_countdown` という名前の関数があり、数値を受け取りそれを出力します。

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

この関数を呼び出すと `5` が出力されますが、まだカウントダウンはしません。関数が自分自身を呼び出す前に、基底ケースを定義する必要があります。到達可能な基底ケースがなければ、関数は自分自身を呼び続けます。Pythonは最終的に呼び出しを停止し、`RecursionError` を発生させます。

このカウントダウンでは、`number` が `1` 未満になったら関数を停止させる必要があります。

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

`if` 文が基底ケースです。`number` が `1` 未満のとき、`return` によってその関数呼び出しが終了します。

関数にはまだ再帰ケースが必要です。再帰ケースは基底ケースに近づく引数で関数を再度呼び出します。カウントダウンするには、`number - 1` を引数にして `recursive_countdown` を呼び出します。

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

これにより、`5`、`4`、`3`、`2`、`1` の数字が出力されます。

数字の出力順は再帰呼び出しの位置によって変わります。`print()` の呼び出しが再帰呼び出しの後にある場合、関数は数字を昇順で出力します。

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

これにより、`1`、`2`、`3`、`4`、`5` の数字が出力されます。なぜそうなるかを理解するには、コールスタックを理解する必要があります。

コールスタックは後入れ先出しのデータ構造で、Pythonがアクティブな関数呼び出しを管理するために使います。関数が呼び出されると、Pythonはその呼び出しのフレームをスタックの一番上に追加します。フレームには関数の引数やローカル変数などの情報が含まれます。

このカウントダウンのバージョンを考えてみましょう。

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

出力は次の通りです。

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

`recursive_countdown(3)` の呼び出しは `recursive_countdown(2)` を呼び出すと一時停止します。`2` の呼び出しは `1` の関数呼び出しで一時停止し、`1` の呼び出しは `0` の関数呼び出しで一時停止します。

`0` の呼び出しは基底ケースに達して戻ります。Pythonはその呼び出しをスタックの一番上から削除し、`1` の呼び出しは再帰呼び出しの後に再開します。残りの呼び出しも逆順に再開して戻ります：`1`、`2`、`3` の順です。

すべての再帰関数には基底ケースとそれに向かう再帰ケースが必要です。基底ケースが戻ると、以前の呼び出しは後入れ先出しの順で再開します。
