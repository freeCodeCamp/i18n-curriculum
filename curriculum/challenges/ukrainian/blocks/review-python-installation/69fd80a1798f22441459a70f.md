## Встановлення Python у вашому локальному середовищі

- **Встановлення**: Найпростіший спосіб встановити Python на Windows і macOS — скачати інсталятор з офіційного сайту Python (`https://www.python.org/`). На Linux більшість основних дистрибутивів, таких як Ubuntu, Debian і Fedora, вже містять Python, тому спочатку перевірте встановлену версію і встановлюйте пакет, специфічний для дистрибутиву, лише якщо Python 3 відсутній.
- **Налаштування на macOS**: Скачайте та відкрийте інсталятор `.pkg` і дотримуйтесь підказок. Коли він завершиться, двічі натисніть на файл `Install Certificates.command` і дочекайтеся завершення процесу в терміналі, щоб завершити налаштування.
- **Налаштування на Windows**: Скачайте та запустіть `.msix` Python Install Manager. Після цього будуть доступні команди `python`, `py` та `pymanager`, запуск `python` без встановленого середовища виконання автоматично встановить його, і ви можете погодитися на додатковий запит про додавання каталогу псевдонімів (для команд на кшталт `python3.14.exe`) до вашого `PATH`.
- **Налаштування на Linux**: Відкрийте термінал і виконайте `python --version` або `python3 --version`. Якщо жодна з команд не показує версію Python 3, шукайте пакет для встановлення на `https://www.python.org/` або знайдіть в інтернеті рекомендований спосіб встановлення Python для вашого дистрибутиву.

## Перевірка встановлення

- **Перевірка версії**: Підтвердіть встановлення, виконавши `python --version` або `python3 --version` у терміналі.
- **`python` проти `python3`**: На деяких старіших системах macOS і Linux `python` може позначати Python 2. Якщо `python --version` показує версію Python 2, використовуйте `python3` для свого коду надалі. Python 2 більше не підтримується і не повинен використовуватися для нової розробки.

## Термінал

- **Визначення**: Термінал — це текстовий інтерфейс, який дозволяє взаємодіяти з комп’ютером, вводячи команди. Кожна операційна система має свій застосунок термінала за замовчуванням. На macOS можна використовувати застосунок Terminal. На Windows — Command Prompt або PowerShell. На Linux кожне робоче середовище має свій стандартний застосунок термінала, наприклад GNOME Terminal або Konsole.

## Редактори коду та IDE

- **IDE**: IDE означає інтегроване середовище розробки, яке має функції, включно з редактором коду, інструментами тестування, терміналом та іншими.
- **Популярні редактори коду та IDE для Python**: VS Code, PyCharm і Spyder.

## Запуск скриптів Python

- **Налаштування редактора**: Відкрийте папку проєкту у VS Code і створіть файл з розширенням `.py`. Встановіть розширення Python від Microsoft через перегляд розширень або виконавши `code --install-extension ms-python.python` (на macOS спочатку потрібно додати команду `code` до вашого `PATH`). Це розширення додає підтримку Python у редактор, але не встановлює сам Python.
- **Вибір інтерпретатора**: Виконайте команду `Python: Select Interpreter` у палітрі команд, щоб вказати редактору інтерпретатор Python 3, який ви встановили раніше.
- **Запуск коду**: Натисніть кнопку запуску (іконка відтворення у верхньому правому куті VS Code), щоб запустити поточний файл у терміналі. Ви також можете запускати скрипт вручну з термінала. Наприклад, якщо ваша папка проєкту — `python-projects`, а скрипт — `main.py`, відкрийте термінал у папці, що містить `python-projects`, потім перейдіть у папку проєкту і запустіть скрипт:

```bash
cd python-projects
python main.py
```

Використовуйте `python3 main.py`, якщо команда `python3` у вашій системі показує версію Python 3.

## Використання інтерактивної оболонки Python

- **Запуск інтерактивної оболонки**: Відкрийте термінал і виконайте `python` або `python3` (використовуйте ту, що показала версію Python 3). Запрошення `>>>` означає, що Python чекає на команду. Спробуйте вивести `"Hello, world!"`:

```python
print("Hello, world!")
```

- **Цикл читання, оцінки, виведення, повторення (REPL)**: Інтерпретатор читає ваші вхідні дані, оцінює їх, виводить результат і повертається до запрошення `>>>`, щоб ви могли ввести наступну команду.
- **Неправильний ввід**: Якщо ввести щось, що не є дійсним Python, наприклад `something random`, з’явиться повідомлення `SyntaxError: invalid syntax`, і оболонка повернеться до запрошення.
- **Вихід з оболонки**: Введіть `exit()`, натисніть <kbd>Ctrl</kbd> + <kbd>D</kbd> на macOS або Linux, або <kbd>Ctrl</kbd> + <kbd>Z</kbd> з наступним <kbd>Enter</kbd> на Windows.
- **Коли використовувати**: Інтерактивна оболонка найкраще підходить для невеликих експериментів і швидкого дослідження. Для довших програм або роботи з кількома файлами використовуйте редактор коду або IDE.
