# --description--

이전 수업에서 숫자와 수학 연산에 대해 배울 때, f-문자열에서 `.2f` 같은 형식 지정자를 사용해 숫자의 소수점 자릿수를 조절했어요.

형식 지정자는 값이 차지하는 공간 크기와 위치도 조절할 수 있어요. 출력 결과를 깔끔한 열로 정렬하고 싶을 때 유용합니다.

## 최솟값 너비와 정렬 설정하기

콜론 뒤에 오는 숫자는 필드의 최솟값 너비를 설정하는데, 이는 값이 차지해야 하는 문자 수입니다. 값이 이보다 짧으면 Python이 공간을 추가해 그 너비를 맞춥니다. 예를 들어 보세요:

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

너비 앞에 특정 기호를 사용하면 값이 필드 내에서 어디에 위치할지 조절할 수 있습니다. 다음은 그 기호들입니다:

- Less than (`<`)는 값을 왼쪽에 정렬합니다
- Greater than (`>`)는 값을 오른쪽에 정렬합니다
- Caret (`^`)는 값을 가운데에 정렬합니다.

이 세 기호가 어떻게 작동하는지 예를 들어 보겠습니다:

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

`'Tea'`는 세 글자로 구성되어 있어서 Python이 너비 `8`을 맞추기 위해 다섯 칸의 공백을 추가합니다.

- `<`를 사용하면 공백이 값 뒤에 옵니다
- `>`를 사용하면 공백이 값 앞에 옵니다
- `^`를 사용하면 공백이 양쪽에 나누어져 텍스트가 가운데 정렬됩니다.

공백을 균등하게 나눌 수 없으면 남는 공백은 오른쪽에 옵니다:

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

정렬 기호를 생략하면 문자열은 기본적으로 왼쪽 정렬되고 숫자는 오른쪽 정렬됩니다:

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## 채우기 문자 사용하기

기본적으로 Python은 공백으로 패딩합니다. 다른 문자를 패딩에 사용하려면 정렬 기호 바로 앞에 그 문자를 넣으세요:

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

`*^9`에서 `*`는 채우기 문자, `^`는 값을 가운데 정렬, `9`는 최솟값 너비입니다. 채우기 문자는 정렬 기호와 함께만 사용할 수 있다는 점을 기억하세요.

## 너비와 정밀도 결합하기

이전 수업에서 배운 정밀도와 너비, 정렬을 하나의 형식 지정자에 모두 결합할 수 있습니다:

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

위 예제의 형식 지정자는 오른쪽 정렬, 최솟값 너비 `7`, 소수점 둘째 자리까지 표시를 의미합니다. Python은 먼저 숫자를 `4.50`으로 포맷하는데, 이는 네 글자 길이이고, 그 앞에 세 칸의 공백을 추가해 너비 `7`을 채웁니다.

## 문장 행 만들기

레이블과 금액을 한 줄에 함께 넣을 수 있습니다. 모든 행에 같은 형식 지정자를 사용하면 열이 정렬됩니다:

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

각 레이블은 `12` 문자 필드에서 왼쪽 정렬되고 점으로 패딩되며, 각 금액은 `8` 문자 필드에서 오른쪽 정렬되어 소수점이 일치합니다.

## 너비는 최솟값이지 최댓값이 아닙니다

너비는 패딩만 추가할 뿐 값을 잘라내지 않습니다. 값이 지정한 너비보다 길면 전체 값이 표시됩니다:

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

숫자도 마찬가지입니다. 아래 예제에서 포맷된 금액은 여덟 글자가 필요해서 지정한 너비 `7`을 무시합니다:

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

`:7.2f`에서 `7`은 최솟값 너비이지 금액 길이 제한이 아닙니다. Python은 숫자를 맞추기 위해 자릿수를 잘라내지 않습니다.

그래서 예상하는 값에 맞게 충분히 큰 너비를 선택해야 열이 제대로 정렬됩니다.

문자열 길이를 제한하려면 형식 지정자에 정밀도를 추가하세요. 문자열의 정밀도는 표시할 최대 문자 수를 설정합니다:

```py
label = 'Long description'

print(f'|{label:.8}|') # |Long des|
print(f'|{label:<12.8}|') # |Long des    |
```

`<12.8`에서:

- `<`는 값을 왼쪽 정렬합니다
- `12`는 최솟값 너비입니다
- `.8`은 최대 문자 수입니다.

Python은 먼저 문자열을 8자로 자르고, 그다음 12 너비로 패딩합니다.

정밀도는 문자열과 숫자에서 의미가 다릅니다. `.2f`에서 `.2`는 소수점 자릿수를 설정하지만, 문자열에서는 `.8`이 최대 문자 수를 설정합니다.
