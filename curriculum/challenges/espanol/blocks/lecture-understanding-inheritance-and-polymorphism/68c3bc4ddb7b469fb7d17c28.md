# --description--

El polimorfismo es el siguiente concepto clave de la programación orientada a objetos (OOP) del que hablaremos.

Con el polimorfismo, tienes acceso a una interfaz donde puedes interactuar con muchos objetos del mismo tipo.

Veamos más a fondo el polimorfismo y cómo te permite reutilizar código.

El polimorfismo permite que métodos en diferentes clases compartan el mismo nombre pero realicen tareas distintas. Llamas al mismo nombre de método en diferentes objetos, y cada uno responde a su manera.

Aquí está el ejemplo básico de polimorfismo:

```py
class A:
   def action(self): ...

class B:
   def action(self): ...

class C:
   def action(self): ...

A().action()
B().action()
C().action()
```

Aquí tienes un ejemplo usando diferentes sonidos de animales para mostrar el polimorfismo:

```py
class Cat:
   def speak(self):
       return "A cat meows"

class Bird:
   def speak(self):
       return "A bird tweets"
  
class Monkey:
   def speak(self):
       return "A monkey ooh ooh aah aah ooh ooh aah aah"

def animal_sound(animal):
   print(animal.speak())

animal_sound(Cat())
animal_sound(Bird())
animal_sound(Monkey())
```

En este ejemplo, `animal_sound()` es una función que recibe cualquier objeto con un método `speak()`.

Cuando pasas un `Cat`, `Bird` o `Monkey`, se llama al método `speak()` del objeto y se imprime el resultado. Debido a que cada clase define `speak()` de manera diferente, obtienes diferentes salidas de la misma función. Eso es el polimorfismo en acción.

Aquí tienes otro ejemplo, esta vez con instancias y un atributo:

```py
class Twitter:
   def __init__(self, content):
       self.content = content

   def post(self):
       return f"🐦 Tweet: '{self.content}' (280 chars max)"

class Instagram:
   def __init__(self, content):
       self.content = content

   def post(self):
       return f"📸 Instagram Post: '{self.content}' + ✨ filters"

class LinkedIn:
   def __init__(self, content):
       self.content = content

   def post(self):
       return f"💼 LinkedIn Article: '{self.content}' (Professional Mode)"

def start(social_media):
   print(social_media.post())  # Calls .post() on any object

# Instances
tweet = Twitter('Just learned Python polymorphism!')
photo = Instagram('Sunset vibes 🌅')
article = LinkedIn('Why OOP matters in 2024')

# The polymorphic calls - same function, different outputs
start(tweet) # 🐦 Tweet: 'Just learned Python polymorphism!' (280 chars max)
start(photo) # 📸 Instagram Post: 'Sunset vibes 🌅' + ✨ filters
start(article) # 💼 LinkedIn Article: 'Why OOP matters in 2024' (Professional Mode)
```

También existe un tipo de polimorfismo llamado **polimorfismo basado en herencia**.

En el polimorfismo basado en herencia, una clase padre define un método, y múltiples clases hijas sobrescriben ese método a su manera. Luego puedes llamar al mismo método en cualquier objeto hijo, y se comporta de manera diferente dependiendo de a qué clase hija pertenece.

Aquí tienes un ejemplo:

```py
class Animal:
   def speak(self):
       return 'Some generic sound'

class Cat(Animal):
   def speak(self):
       return 'A cat meows'

class Dog(Animal):
   def speak(self):
       return 'A dog barks woof woof'

class Monkey(Animal):
   def speak(self):
       return 'A monkey ooh ooh aah aah ooh ooh aah aah'
  
print(Cat().speak()) # A cat meows
print(Dog().speak()) # A dog barks woof woof
print(Monkey().speak()) # A monkey ooh ooh aah aah ooh ooh aah aah
print(Animal().speak()) # Some generic sound
```

Puedes ver que cada clase hija de la clase padre `Animal` sobrescribe el método `speak()` para proporcionar su propia implementación. Así que cuando llamas al método `speak()` en una instancia de cada subclase, devuelve el sonido específico asociado con ese animal.

También puedes llevarlo más lejos y hacer la llamada en una lista, luego recorrer la lista para mostrar lo que el método `speak()` devuelve para cada uno:

```py
animals = [Cat(), Dog(), Monkey()]

for animal in animals:
   print(animal.speak())

# Output:
# A cat meows
# A dog barks woof woof
# A monkey ooh ooh aah aah ooh ooh aah aah
```
