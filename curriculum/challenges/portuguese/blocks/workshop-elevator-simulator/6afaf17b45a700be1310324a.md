# --description--

Um elevador também precisa de uma parada de emergência. Nesta simulação, a string `stop` na lista de requisições representa alguém apertando o botão de parada de emergência.

A declaração `break` sai imediatamente de um loop, pulando todas as iterações restantes.

Depois de atribuir `target` e antes da sua outra declaração `if`, adicione uma declaração `if` que verifica se `target` é igual à string `stop`. Se for, imprima a string `Emergency stop!` e use `break` para parar o elevador.

Essa verificação precisa vir antes do loop `while` aninhado, porque comparar um inteiro com uma string usando `<` gera um `TypeError`.
