# --description--

Fügen Sie Ihrer `if`-Anweisung eine `elif`-Klausel hinzu, die überprüft, ob `key` größer als `node.key` ist. Rufen Sie darin `self._insert` mit `node.right` und `key` auf und weisen Sie das Ergebnis `node.right` zu.

Wenn `key` gleich `node.key` ist, wird kein Zweig ausgeführt, sodass doppelte Werte nicht zum Baum hinzugefügt werden.
