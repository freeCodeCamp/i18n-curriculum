## 파이썬이란?

- **Python**: Python은 단순하고 사용하기 쉬운 범용 프로그래밍 언어로 알려져 있습니다.
- **주요 사용 사례**: Python은 데이터 과학, 머신러닝, 웹 개발, 사이버보안, 임베디드 시스템 및 IoT, 스크립팅, 자동화, 그리고 Raspberry Pi 및 MicroPython 호환 보드와 같은 마이크로컴퓨터에 사용됩니다.

## 변수

- **변수 선언**: 변수를 선언하려면 변수 이름 다음에 대입 연산자(`=`)를 쓰고 값을 할당합니다. 값은 숫자, 문자열, 불리언 등일 수 있습니다. 예시는 다음과 같습니다:

```py
name = 'John Doe'
age = 25
```

- **변수 이름 규칙**: 변수 이름에 적용할 규칙은 다음과 같습니다:

  - 변수 이름은 숫자가 아닌 문자나 밑줄(`_`)로만 시작할 수 있습니다.
  - 변수 이름에는 문자(`a-z`, `A-Z`), 숫자(`0-9`), 밑줄(`_`)을 포함할 수 있습니다.
  - 변수 이름은 대소문자를 구분합니다: `age`, `Age`, `AGE`는 모두 서로 다른 이름으로 간주됩니다.
  - 변수 이름은 `if`, `class`, `def`와 같은 Python 예약어일 수 없습니다.
  - 여러 단어로 된 변수 이름은 `snake_case`처럼 밑줄을 사용합니다.
  - 변수 이름은 `user_age`처럼 목적을 설명해야 합니다.
  - 의미를 전달하지 않는 한 한 글자 변수 이름은 피하세요.

## 주석

- **한 줄 주석**: 이 주석은 코드 내 짧은 메모를 위해 사용하세요.

```py
# This is a single line comment
```

- **여러 줄 주석**: 여러 줄에 걸쳐 주석을 만들려면 각 줄의 시작에 `#`를 사용할 수 있습니다.

```py
# This is a multi-line comment.
# Here is some code commented out.
#
# name = 'John Doe'
# age = 25
```

## 출력하기

- **`print()` 함수**: 터미널에 데이터를 출력하려면 다음과 같이 `print()` 함수를 사용할 수 있습니다:

```py
print('Hello world!') # Hello world!
```

`print()`에 여러 인수를 쉼표로 구분하여 전달할 수 있습니다. 기본적으로 `print()`는 출력된 값들 사이에 공백을 삽입합니다:

```py
print('Hello', 'world!') # Hello world!
```

## 파이썬의 일반적인 데이터 타입

- **동적 타이핑**: Python은 동적 타이핑 언어로, 변수의 데이터 타입을 선언할 필요가 없습니다. Python은 변수에 할당된 값으로부터 타입을 결정합니다.

- **정수**: 소수점이 없는 전체 숫자:

```py
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- **부동소수점**: 소수점이 있는 숫자입니다:

```py
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- **문자열**: 따옴표로 감싼 문자들의 연속입니다:

```py
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- **불리언**: `True` 또는 `False` 값을 나타냅니다:

```py
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python에는 다른 데이터 타입도 있습니다. 필요할 때마다 하나씩 배우게 됩니다.

- **`type()` 함수**: 변수의 타입을 확인하려면 다음과 같이 `type()` 함수를 사용할 수 있습니다:

```py
greeting = 'Hello there!'
age = 21

print(type(greeting)) # <class 'str'>
print(type(age)) # <class 'int'>
```

- **`isinstance()` 함수**: 특정 데이터 타입과 일치하는지 확인할 때 사용합니다:

```py
greeting = 'Hello world'
name = 'John Doe'

print(isinstance(greeting, str)) # True
print(isinstance(name, int)) # False
```

여러 타입을 검사하려면 타입들을 괄호 안에 쉼표로 구분해 넣고 두 번째 인수로 전달하세요. 값이 나열된 타입 중 하나의 인스턴스면 결과는 `True`입니다:

```py
account_balance = 12
print(isinstance(account_balance, (int, float))) # True
```

## 문자열 다루기

- **문자열**: 문자열은 문자들의 수열입니다. Python에서는 작은따옴표나 큰따옴표 중 하나를 사용할 수 있습니다. 한 가지 스타일을 선택해 일관되게 사용하세요:

```py
developer = 'Jessica'
city = "Los Angeles"
```

- **여러 줄 문자열**: 세 개의 작은따옴표 또는 세 개의 큰따옴표를 사용하면 문자열을 여러 줄에 걸쳐 작성할 수 있습니다:

```py
message = """Hello
world!"""
print(message)
# Hello
# world!
```

- **문자열 안의 따옴표**: 문자열 안에 있는 따옴표를 이스케이프하지 않으려면 반대 종류의 따옴표를 사용할 수 있습니다:

```py
msg = "It's a sunny day"
quote = 'She said, "Hello!"'
```

- **문자열 이스케이프**: 문자열에 따옴표가 포함될 경우 역슬래시(`\`)를 사용해 이스케이프할 수 있습니다:

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **이스케이프 시퀀스**: 역슬래시와 다른 문자가 결합되어 특수 문자를 나타낼 수 있습니다. 예를 들어, `\n`은 줄바꿈, `\t`는 탭, `\\`는 단일 역슬래시를 나타냅니다:

```py
print('Hello\nworld')
# Hello
# world

print('Name:\tAlice')  # Name:   Alice
print('C:\\Users\\Alice')  # C:\Users\Alice
```

- **`in` 연산자**: 문자열에 특정 문자나 문자가 존재하는지 여부를 불리언으로 반환합니다:

```py
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

- **문자열 길이 구하기**: `len()` 함수는 문자열에 포함된 문자 수를 반환합니다:

```py
developer = 'Jessica'

print(len(developer)) # 7
```

- **문자열에서 문자 접근하기**: 대괄호 표기법을 사용해 문자열의 문자를 접근할 수 있습니다:

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **재할당과 불변성**: 문자열은 불변이므로 생성된 후 변경할 수 없습니다. 변수를 재할당하면 다른 값을 참조하게 되며 원래 문자열을 수정하지 않습니다:

```py
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello
```

문자열을 직접 수정하는 것은 허용되지 않습니다:

```py
greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```

정수, 부동소수점, 불리언도 불변입니다.

- **문자열 연결**: 문자열을 연결하려면 `+` 연산자를 사용할 수 있습니다:

```py
developer = 'Jessica'
print('My name is ' + developer + '.') # My name is Jessica.
```

- **문자열 반복**: `*` 연산자는 문자열을 지정한 횟수만큼 반복합니다:

```py
print('ha' * 3) # hahaha
```

- **문자열과 숫자 연결**: 문자열과 숫자를 연결하면 `TypeError`가 발생합니다:

```py
'Age: ' + 26 # TypeError: can only concatenate str (not "int") to str
```

`str()` 함수는 숫자를 문자열로 변환하여 연결할 수 있게 합니다:

```py
print('Age: ' + str(26)) # Age: 26
```

또 다른 방법은 `+=` 연산자를 사용하는 것입니다. 이 연산자는 연결과 할당을 동시에 수행합니다:

```py
greeting = 'My name is '
developer = 'Jessica.'

greeting += developer
print(greeting) # My name is Jessica.
```

`*=` 연산자는 문자열을 반복하고 결과를 변수에 다시 할당합니다:

```py
sound = 'ha'
sound *= 3
print(sound) # hahaha
```

`+=`와 `*=` 모두 원래 문자열을 수정하지 않고 변수에 새 문자열을 할당합니다.

- **`f-strings`**: 포맷된 문자열 리터럴의 줄임말로, 보간과 연결을 간결하고 읽기 쉽게 처리할 수 있습니다:

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

f-strings의 치환 필드에는 표현식을 넣을 수 있습니다. Python은 표현식을 평가하고 그 값을 문자열에 삽입합니다:

```py
num1 = 5
num2 = 10
print(f'The sum is {num1 + num2}') # The sum is 15
```

- **문자열 슬라이싱**: 문자열의 일부를 추출하는 방법입니다. 기본 구문은 다음과 같습니다:

```py
str[start:stop:step]
```

`start` 인덱스는 추출이 시작되는 위치를 지정합니다. `stop` 인덱스는 포함하지 않으므로 해당 위치의 문자는 포함되지 않습니다. `step`은 선택된 인덱스 간격을 지정하며 기본값은 `1`입니다. 양수 `step`일 때, 생략된 `start`는 문자열 시작, 생략된 `stop`은 문자열 끝을 기본값으로 합니다. `[:]`는 전체 문자열을 추출합니다. `[::-1]`은 마지막 문자부터 첫 문자까지 거꾸로 문자열을 반환합니다. 슬라이싱은 원래 문자열을 수정하지 않습니다.

```py
message = 'Python is fun!'

print(message[0:6])  # Python
print(message[:6])  # Python
print(message[7:])  # is fun!
print(message[::2])  # Pto sfn
print(message[:])  # Python is fun!
print(message[::-1])  # !nuf si nohtyP
```

## 자주 쓰이는 문자열 메서드

- **메서드**: 메서드는 값에 대해 호출하는 함수입니다. 문자열 메서드를 호출하려면 문자열 또는 해당 변수 이름 뒤에 점(.)과 메서드 호출을 작성하세요.

- **`str.upper()`**: 모든 문자를 대문자로 변환한 새 문자열을 반환합니다:

```py
developer = 'Jessica'

print(developer.upper()) # JESSICA
```

- **`str.lower()`**: 모든 문자를 소문자로 변환한 새 문자열을 반환합니다:

```py
developer = 'Jessica'

print(developer.lower()) # jessica
```

- **`str.strip()`**: 지정한 앞뒤 문자를 제거한 문자열 복사본을 반환합니다(인수가 없으면 앞뒤 공백을 제거).

```py
greeting = '  hello world  '

trimmed_my_str = greeting.strip()
print(trimmed_my_str)  # hello world
```

- **`replace()`**: 문자열 내 모든 특정 문자열을 새 문자열로 교체한 결과를 반환합니다:

```py
greeting = 'hello world'

replaced_my_str = greeting.replace('hello', 'hi')
print(replaced_my_str)  # hi world
```

- **`split()`**: 지정한 구분자를 사용해 문자열을 리스트로 나누는 데 사용합니다. 구분자는 어디서 나눌지 지정하는 문자열입니다. 구분자를 지정하지 않으면 `split()`은 공백을 기준으로 나눕니다.

```py
dashed_name = 'example-dashed-name'

split_words = dashed_name.split('-')
print(split_words)  # ['example', 'dashed', 'name']
```

- **`join()`**: 여러 문자열을 구분자를 사용해 하나의 문자열로 합칠 때 사용합니다.

```py
example_list = ['example', 'dashed', 'name']

joined_str = ' '.join(example_list)
print(joined_str)  # example dashed name
```

- **`str.startswith(prefix)`**: 문자열이 지정한 접두사로 시작하는지 여부를 불리언으로 반환합니다:

```py
developer = 'Naomi'

result = developer.startswith('N')
print(result)  # True
```

- **`str.endswith(suffix)`**: 문자열이 지정한 접미사로 끝나는지 여부를 불리언으로 반환합니다:

```py
developer = 'Naomi'

result = developer.endswith('N')
print(result)  # False
```

- **`str.find()`**: 부분 문자열이 처음 나타나는 인덱스를 반환합니다. 찾지 못하면 `-1`을 반환합니다:

```py
developer = 'Naomi'

result = developer.find('N')
print(result)  # 0

city = 'Los Angeles'
print(city.find('New')) # -1
```

- **`str.count(substring)`**: 이 메서드는 문자열에서 겹치지 않는 부분 문자열이 몇 번 나타나는지 셉니다. 일치하는 부분을 찾으면, 검색은 그 부분의 끝 이후부터 계속됩니다:

```py
city = 'Los Angeles'
print(city.count('e')) # 2

# Matches do not overlap, so this is 2, not 3
print('aaaa'.count('aa')) # 2
```

- **`str.capitalize()`**: 첫 문자는 대문자로, 나머지는 소문자로 변환한 새 문자열을 반환합니다:

```py
dessert = 'chocolate cake'
print(dessert.capitalize()) # Chocolate cake
```

- **`str.isupper()`**: 문자열에 대문자 문자가 하나 이상 포함되어 있고 모든 대문자 문자가 대문자일 경우 `True`를 반환합니다. 그렇지 않으면 `False`를 반환합니다:

```py
dessert = 'chocolate cake'
print(dessert.isupper()) # False
```

- **`str.islower()`**: 문자열에 소문자 문자가 하나 이상 포함되어 있고 모든 소문자 문자가 소문자일 경우 `True`를 반환합니다. 그렇지 않으면 `False`를 반환합니다:

```py
dessert = 'chocolate cake'
print(dessert.islower()) # True
```

- **`str.title()`**: 각 단어의 첫 글자는 대문자로, 나머지 글자는 소문자로 변환한 새 문자열을 반환합니다:

```py
city = 'lOS aNGELES'
print(city.title()) # Los Angeles
```

## 문자열 추가 작업

- **음수 슬라이스 경계**: 슬라이스 경계는 문자열 끝에서부터 역방향으로 셀 수 있습니다. 예를 들어, `[-3:]`는 마지막 세 문자를 추출합니다:

```py
employee_code = 'DEV-2026-JD-001'
print(employee_code[-3:]) # 001
```

- **메서드 체이닝**: 한 표현식에서 여러 문자열 메서드를 호출할 수 있습니다. 각 메서드는 이전 호출 결과에 대해 작동합니다:

```py
name = '  jANE dOE  '
print(name.strip().title()) # Jane Doe
```

## 정수와 부동소수점에 자주 사용하는 연산

- **기본 수학 연산**: Python에서는 정수와 부동소수점 숫자에 대해 덧셈, 뺄셈, 곱셈, 나눗셈 같은 기본 수학 연산을 할 수 있습니다:

```py
int_1 = 56
int_2 = 12
float_1 = 5.4
float_2 = 12.0

# Addition

print('Integer Addition:', int_1 + int_2) # Integer Addition: 68
print('Float Addition:', float_1 + float_2) # Float Addition: 17.4

# Subtraction

print('Int Subtraction:', int_1 - int_2) # Int Subtraction: 44
print('Float Subtraction:',  float_2 - float_1) # Float Subtraction: 6.6

# Multiplication

print('Int Multiplication:', int_1 * int_2) # Int Multiplication: 672
print('Float Multiplication:', float_2 * float_1) # Float Multiplication: 64.80000000000001

# Division

print('Division:', int_1 / int_2) # Division: 4.666666666666667
print('Float Division:', float_2 / float_1) # Float Division: 2.222222222222222
```

부동소수점과 정수를 더하면 결과는 부동소수점으로 변환됩니다:

```py
int_1 = 56
float_1 = 5.4

print(int_1 + float_1) # 61.4
```

- **나머지 연산자(`%`)**: 두 수를 나눈 나머지를 반환합니다:

```py
int_1 = 56
int_2 = 12

print(int_1 % int_2) # 8
```

- **몫 연산자(`//`)**: 두 수를 나누고 결과를 내림하여 정수로 반환합니다:

```py
int_1 = 56
int_2 = 12

print(int_1 // int_2) # 4
```

- **거듭제곱 연산자(`**`)**: 한 수를 다른 수의 거듭제곱으로 올립니다:

```py
int_1 = 4
int_2 = 2

print(int_1 ** int_2) # 16
```

- **부동소수점 근사**: 일부 십진 분수는 이진으로 정확히 표현할 수 없어 유한 근사값으로 저장됩니다. 이로 인해 위의 `64.80000000000001`과 같은 작은 반올림 오차가 발생할 수 있습니다.

```py
print(0.1 + 0.2) # 0.30000000000000004
```

- **`float()` 함수**: 이 함수는 정수나 유효한 십진 문자열을 부동소수점으로 변환하거나, 유한한 정수나 부동소수점보다 큰 양의 무한대를 나타내는 특수 부동소수점 값을 생성할 때 사용합니다:

```py
num = 4

print(float(num)) # 4.0
print(float('7.8')) # 7.8
print(float('inf')) # inf
```

- **`int()` 함수**: 부동소수점을 정수로 변환할 때 사용합니다:

```py
num = 4.0

print(int(num)) # 4
```

- **`round()` 함수**: 인수가 하나일 때 숫자를 가장 가까운 정수로 반올림합니다. 두 번째 인수를 전달하면 소수점 자릿수를 지정할 수 있습니다:

```py
num_1 = 3.4
num_2 = 7.7

print(round(num_1)) # 3
print(round(num_2)) # 8
print(round(3.14159, 2)) # 3.14
```

- **`abs()` 함수**: 숫자의 절댓값을 반환합니다:

```py
num = -13

print(abs(num)) # 13
```

- **`pow()` 함수**: 이 함수는 숫자를 다른 숫자의 거듭제곱으로 올립니다. 정수 인수일 경우 세 번째 0이 아닌 인수를 전달해 결과를 그 값으로 나눈 나머지로 계산할 수 있습니다:

```py
result = pow(2, 3)
print(result)  # 8
print(pow(2, 3, 5)) # 3
```

## `if`, `elif`, `else` 문 다루기

- **코드 블록과 들여쓰기**: Python은 들여쓰기를 사용해 함수나 조건문의 본문과 같은 문장들을 블록으로 묶습니다. 같은 블록 내 문장들은 동일한 들여쓰기 수준을 사용해야 합니다. 관례적으로 각 수준마다 네 칸의 공백을 사용합니다.

- **`pass` 문**: `pass`는 아무 동작도 하지 않습니다. Python이 문장을 요구하는 곳, 예를 들어 빈 조건문 본문에 자리 표시자로 사용하세요:

```py
age = 18
if age >= 18:
    pass
```

- **`if` 문**: `if` 문은 조건이 참으로 평가될 때 본문을 실행합니다.

```py
age = 18

if age >= 18:
    print('You are an adult') # You are an adult
```

- **`else` 절**: `else` 절은 같은 `if...elif...else` 체인에서 앞선 모든 조건이 거짓으로 평가될 때 본문을 실행합니다.

```py
age = 12

if age >= 18:
    print('You are an adult')
else:
    print('You are not an adult yet') # You are not an adult yet
```

- **`elif` 절**: `elif` 절은 같은 체인에서 앞선 모든 조건이 거짓일 때 다른 조건을 검사합니다. 자신의 조건이 참이면 본문을 실행합니다.

```py
age = 16

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')  # You are a teenager
```

중첩된 `if` 문장도 사용할 수 있습니다:

```py
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

## 참 같은 값과 거짓 같은 값

- **참과 거짓 값**: Python에서 모든 값은 논리적 맥락에서 `True` 또는 `False`로 처리되는 내재된 불리언 값을 가집니다. 많은 값이 참 같은 값으로 간주되어 논리적 맥락에서 `True`로 평가됩니다. 반면 거짓 같은 값은 `False`로 평가됩니다. 다음은 거짓 같은 값의 예입니다:

```md
False
None
Integer 0
Float 0.0
Empty strings ''
```

0이 아닌 숫자나 빈 문자열이 아닌 값은 참 같은 값입니다.

## `bool()` 함수 다루기

- **`bool()` 함수**: 값이 참인지 거짓인지 확인하려면 내장 `bool()` 함수를 사용하세요. 이 함수는 값을 명시적으로 불리언으로 변환해 참 같은 값은 `True`, 거짓 같은 값은 `False`를 반환합니다. 몇 가지 예는 다음과 같습니다:

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

## 불리언 연산자와 단축 평가

- **불리언 연산자**: 이들은 여러 표현식을 결합해 코드에서 더 복잡한 의사결정 논리를 만들 수 있게 하는 특수 연산자입니다. Python에는 `and`, `or`, `not` 세 가지 불리언 연산자가 있습니다.
- **`and` 연산자**: 이 연산자는 두 피연산자를 받아 첫 번째가 거짓 같으면 그 값을 반환하고, 그렇지 않으면 두 번째 값을 반환합니다. 표현식이 참 같으려면 두 피연산자 모두 참 같아야 합니다.

```py
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

조건문에서 `and` 연산자를 이렇게 사용할 수도 있습니다:

```py
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

- **`or` 연산자**: 이 연산자는 첫 번째 피연산자가 참 같으면 그 값을 반환하고, 그렇지 않으면 두 번째 피연산자를 반환합니다. `or` 표현식은 적어도 하나의 피연산자가 참 같으면 참 같은 값을 결과로 냅니다. 다음은 예시입니다:

```py
age = 19
is_employed = False

print(age or is_employed) # 19
```

`and` 연산자처럼 조건문에서 `or` 연산자를 이렇게 사용할 수 있습니다:

```py
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

- **단락 평가**: `and`와 `or` 연산자는 단락 평가 연산자로, 왼쪽에서 오른쪽으로 값을 검사하며 최종 결과가 결정되면 즉시 평가를 멈춥니다.
- **`not` 연산자**: 단일 피연산자를 받아 불리언 값을 반전시킵니다. 참 같은 값은 `False`로, 거짓 같은 값은 `True`로 변환합니다. 이전 연산자와 달리 `not`는 항상 `True` 또는 `False`를 반환합니다. 예시는 다음과 같습니다:

```py
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

조건문에서 `not` 연산자 예시는 다음과 같습니다:

```py
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

## 동일성 연산자

- **동일성과 동등성**: 변수는 객체를 참조합니다. `is` 연산자는 두 피연산자가 같은 객체를 참조하는지 확인하고, `is not`은 다른 객체를 참조하는지 확인합니다. `==`와 `!=` 연산자는 값 자체를 비교합니다. 숫자나 문자열 값을 비교할 때는 동등 연산자를 사용하세요.
- **`None`과 `NoneType`**: `None`은 값이 없음을 나타내며, `NoneType` 데이터 타입의 유일한 값입니다.
- **싱글턴**: `None`, `True`, `False`는 각각 하나뿐인 객체입니다. 동일성 연산자로 이 객체들을 확인할 수 있습니다.
- **`None` 확인**: 값이 없음을 확인하려면 `is None`을, 값이 있음을 확인하려면 `is not None`을 사용하세요. `None`과 `False`는 모두 거짓 같지만 서로 다른 객체입니다:

```py
response = False

print(response is None) # False
print(response is not None) # True
print(response is True) # False
print(response is False) # True
```

- **동일성과 참/거짓 구분**: `response`가 `True`, `False`, `None`일 수 있을 때, `response is None`은 답변이 없음을 부정적인 답변과 구분합니다. `not response`는 `False`와 `None`을 동일하게 처리합니다. 일반적인 불리언 플래그에는 `if is_ready` 또는 `if not is_ready`를 사용하세요. 불리언 객체를 다른 값과 구분해야 할 때는 `is True` 또는 `is False`를 사용하세요.

## 불리언 연산자 우선순위

- **연산자 우선순위와 소괄호**: `and`와 `or`가 같은 표현식에 있을 때, `and`가 `or`보다 우선순위가 높습니다. 즉, `and`가 먼저 피연산자들을 묶어서 `True or False and False`는 `True or (False and False)`로 묶입니다:

```py
print(True or False and False) # True
```

`or`의 왼쪽 피연산자가 `True`이므로, 단락 평가로 인해 `False and False`는 평가되지 않고 결과는 `True`가 됩니다.

소괄호를 사용해 묶음을 바꿀 수 있습니다. 여기서는 `True or False`가 먼저 묶여 `True`가 되고, 그 다음에 `True and False`가 평가되어 `False`가 됩니다:

```py
print((True or False) and False) # False
```

print(int(3.14)) # 3

## 함수 다루기

- **함수**: 함수는 호출할 때 실행되는 재사용 가능한 코드 조각입니다. 함수를 호출하려면 함수 이름 뒤에 소괄호를 붙여 참조하세요:

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

- **매개변수와 인수**: 매개변수는 함수 정의에 나열된 이름들로, 위 예시의 `num_1`과 `num_2`가 해당합니다. 인수는 함수를 호출할 때 전달하는 값들로, 예를 들어 `3`과 `4`가 있습니다.

인수가 올바른 개수로 전달되지 않으면 `TypeError`가 발생합니다:

```py
def calculate_sum(a, b):
    print(a + b)

calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

- **위치 인수**: 이 인수들은 함수 호출에서 위치에 따라 매개변수와 매칭됩니다.

```py
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

- **키워드 인수**: 이 인수들은 `name=value` 형식으로 매개변수 이름과 매칭됩니다. 매개변수 순서와 다르게 나타날 수 있습니다:

```py
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

- **인수 유형 결합**: 위치 인수는 키워드 인수보다 먼저 와야 하며, 각 매개변수는 하나의 값만 받을 수 있습니다:

```py
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

- **`return` 문**: `return` 문은 함수를 종료하고 호출된 곳에 값을 반환합니다.

- **`None`**: `None`은 값이 없음을 나타냅니다. 함수가 명시적으로 값을 반환하지 않으면 기본 반환값은 `None`입니다:

```py
def greet():
    print('hello')

result = greet() # hello
print(result) # None
```

## 파이썬의 범위

Python에는 추가적인 범위 규칙이 있습니다. 지금은 지역 범위와 전역 범위에 집중하세요.

- **전역 범위**: 함수 외부에서 생성된 변수는 함수 안팎 모두에서 사용할 수 있습니다.

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + (subtotal * tax)
    return total

print(get_total(100))  # 170.0
```

- **지역 범위**: 함수 내부에서 생성된 변수는 그 함수 내에서만 사용할 수 있습니다. 함수 매개변수도 지역 변수입니다.

```py
def my_func():
    num = 10
    print(num)
```

- **인수 전달과 매개변수 재할당**: Python은 인수를 할당 방식으로 전달합니다. 매개변수는 처음에 전달된 객체를 참조하는 지역 이름이며, 객체가 자동으로 복사되지는 않습니다. 매개변수를 재할당해도 인수로 전달된 변수는 재할당되지 않습니다:

```py
def double_number(number):
    number = number * 2
    print(number) # 20

original = 10
double_number(original)
print(original) # 10
```

## 함수와 범위 적용

- **빈 함수 본문**: 함수 본문에 `pass`를 자리 표시자로 사용할 수 있습니다. `pass`만 포함된 함수는 암묵적으로 `None`을 반환합니다:

```py
def placeholder():
    pass

print(placeholder()) # None
```

- **이름 가리기**: 지역 매개변수나 변수가 전역 변수와 같은 이름일 때 함수는 지역 이름을 사용합니다. 지역 매개변수를 재할당해도 전역 변수는 변경되지 않습니다:

```py
available_eggs = 5

def use_eggs(available_eggs, eggs_to_use):
    available_eggs -= eggs_to_use
    return available_eggs

print(use_eggs(available_eggs, 1)) # 4
print(available_eggs) # 5
```

- **조기 반환**: `return` 문은 즉시 함수를 종료하고 호출된 곳에 값을 반환합니다. 조건이 충족되면 조기 반환할 수 있습니다:

```py
def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        return available_eggs
    return available_eggs - eggs_to_use

print(use_eggs(2, 3)) # 2
print(use_eggs(2, 1)) # 1
```

- **다른 함수 호출**: 함수는 다른 함수를 호출해 그 결과를 사용하거나 반환할 수 있습니다:

```py
def use_eggs(available_eggs, eggs_to_use):
    return available_eggs - eggs_to_use

def make_fried_egg(available_eggs):
    return use_eggs(available_eggs, 1)

print(make_fried_egg(3)) # 2
```

- **반환값 할당**: 새 값을 반환해도 인수로 전달된 변수가 자동으로 업데이트되지는 않습니다. 업데이트하려면 반환값을 해당 변수에 다시 할당하세요:

```py
available_eggs = use_eggs(available_eggs, 1)
print(available_eggs) # 4
```

## 문자열 변환

- **`str.maketrans()`**: `str.maketrans()`의 두 문자열 형태는 길이가 같은 문자열을 받아 첫 번째 문자열의 각 문자를 두 번째 문자열의 대응 문자에 매핑합니다. 이 표는 문자를 고유하게 식별하는 유니코드 순서 값으로 저장합니다. `translate()` 메서드는 이 표를 문자열에 적용해 새 문자열을 반환합니다. 표에 포함되지 않은 문자는 변경되지 않습니다.

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc!'.translate(trans_table)
print(result)  # 123123!
```

## 정수 인수 검증

- **불리언과 정수**: Python은 불리언을 특수한 정수로 취급해 `isinstance(True, int)`와 `isinstance(False, int)`가 모두 `True`를 반환합니다. 불리언이 아닌 정수를 검증할 때는 불리언 값을 명시적으로 제외하세요:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True

value = True
print(isinstance(value, int) and not isinstance(value, bool)) # False

value = 5
print(isinstance(value, int) and not isinstance(value, bool)) # True
```

## 기본 매개변수 값

- **기본 매개변수**: 매개변수에 기본값을 지정할 수 있습니다. 함수를 호출할 때 인수를 생략하면 Python이 그 기본값을 사용합니다:

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```
