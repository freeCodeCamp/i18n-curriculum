# --description--

Una funzione può chiamare un'altra funzione e usare il valore restituito. Per esempio:

```py
def calculate_sum(a, b):
    return a + b

def show_total(a, b):
    total = calculate_sum(a, b)
    print(total)

show_total(3, 4) # 7
```

Qui, `show_total` chiama `calculate_sum`, assegna il valore restituito alla variabile locale `total` e lo stampa.

Successivamente, creerai una funzione che verifica se un uovo è disponibile e chiama `use_eggs` per usarlo. Sotto l'istruzione `print(available_eggs)`, definisci una funzione vuota chiamata `make_fried_egg` che prende `available_eggs` come suo unico parametro.

Usa la parola chiave `pass` all'interno del corpo per ora.
