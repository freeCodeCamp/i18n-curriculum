Mit dem jetzt enthaltenen Trinkgeld haben Sie den Gesamtbetrag für die gesamte Gruppe. Sie müssen ermitteln, wie viel jede Person schuldet, indem Sie die Gesamtrechnung durch die Anzahl der Freunde teilen.

In Python verwenden Sie den Schrägstrich `/`, um eine Division durchzuführen. Zum Beispiel:

```py
half = 10 / 2
```

Erstellen Sie eine Variable namens `final_bill` und weisen Sie ihr das Ergebnis der Division von `running_total` durch `num_of_friends` zu.

Verwenden Sie abschließend eine f-String, um `Bill per person:` gefolgt von einem Leerzeichen und `final_bill` mit zwei Dezimalstellen formatiert auszugeben.
