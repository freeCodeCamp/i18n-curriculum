# --description--

`Apps`ボタンがクリックされたときに`isOpen`の状態を更新することが最後の作業です。

Reactでは、要素のイベント属性に関数を渡してイベントに対応します。これらの属性はキャメルケースで書かれるため、クリックは`onClick`で処理されます：

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

`onClick`が関数を受け取ることに注目してください。ボタンがクリックされるたびにReactがその関数を呼び出します。セッター関数を新しい値で呼び出すと状態が更新され、Reactはその新しい値でコンポーネントを再レンダリングします。

ブール値の状態を`true`と`false`で切り替えるには、論理NOT演算子（`!`）を使って現在の値の反対をセッター関数に渡せます。

`button`要素に`onClick`属性を追加してください。`isOpen`の反対の値を引数にして`setIsOpen`を呼び出すアロー関数を渡してください。

`Apps`ボタンをクリックして`sub-menu`を開閉してください。

これで、`Navbar`コンポーネントが完成です！

# --hints--

`Apps`ボタンをクリックすると、その`aria-expanded`属性が`"true"`に設定され、`sub-menu`に`sub-menu--open`クラスが追加される必要があります。

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

`Apps`ボタンを2回目にクリックすると、その`aria-expanded`属性が`"false"`に戻され、`sub-menu`から`sub-menu--open`クラスが削除される必要があります。

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
