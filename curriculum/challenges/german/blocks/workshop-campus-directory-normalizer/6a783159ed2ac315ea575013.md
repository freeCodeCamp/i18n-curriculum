Innerhalb der Abteilungsschleife verwenden Sie den aktuellen Abteilungsschlüssel `dept`, um mit `rawData[dept]` auf die Daten dieser Abteilung zuzugreifen.
Greifen Sie dann auf die Eigenschaft `programs` zu, speichern Sie das Array in einer Variablen namens
`programs` und geben Sie `programs` in der Konsole aus.

Sie sollten außerdem die Zeile `console.log(dept)` löschen.
