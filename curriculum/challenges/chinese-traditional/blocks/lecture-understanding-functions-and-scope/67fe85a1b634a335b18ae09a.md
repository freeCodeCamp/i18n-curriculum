# --description--

範圍決定你可以在程式碼中在哪裡使用變數。

Python 有額外的範圍規則。現在先專注於區域範圍和全域範圍。

在函式外創建的變數具有全域範圍。你可以在函式內外都使用它。

在函式內創建的變數具有區域範圍。你只能在該函式內使用它。函式參數也是區域變數。

這裡是一個區域範圍和全域範圍的範例：

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

`tax_rate` 變數是全域的，因為它是在函式外創建的。`calculate_tax` 函式可以讀取它，第二個 `print()` 呼叫也可以讀取它。

`price` 參數和 `tax` 變數是 `calculate_tax` 的區域變數。它們在該函式執行期間可用，但在函式外不可用。最後一個 `print()` 呼叫會引發 `NameError`，因為 `tax` 在全域範圍中未定義。
