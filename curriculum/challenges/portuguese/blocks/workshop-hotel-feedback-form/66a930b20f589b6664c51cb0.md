# --description--

O atributo `type` informa ao navegador que tipo de dado um `input` deve aceitar. Alguns valores comuns para o atributo `type` são:

- `text`: um campo de texto de uma linha
- `email`: um campo de texto que verifica se o usuário insere um endereço de e-mail válido
- `number`: um campo para números
- `radio` e `checkbox`: opções que o usuário pode selecionar

Aqui está um exemplo de uma entrada de texto:

```html
<input type="text">
```

Para o elemento `input` existente, adicione um atributo `type` definido como `"text"`.

Também dê ao elemento `input` um atributo `id` com o valor `"full-name"`. Isso corresponde ao atributo `for` no seu elemento `label`, que conecta os dois.

Quando um usuário fornece seu nome completo, a `input` aceitará texto simples.
