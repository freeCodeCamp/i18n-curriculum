# --description--

在本实验中，你将构建一个简单的预算应用程序，该应用程序跟踪不同类别的支出，并能在图上显示相对支出百分比。

**目标：**实现以下用户需求并通过所有测试以完成实验。

**用户故事：**

1. 你应该有一个 `Category` 类，该类接受一个名称作为参数。
1. `Category` 类应有一个实例属性 `ledger`，它是一个列表，包含事务列表。
1. `Category` 类应具有以下方法：

   - 一个接受金额和可选描述的 `deposit` 方法。如果未提供描述，则应默认为空字串。该方法应以 `{'amount': amount, 'description': description}` 形式将一个对象追加到 `ledger` 列表中。
   - 一个接受金额和可选描述（默认为空字串）的 `withdraw` 方法。该方法应将传入的金额作为负数保存到 `ledger` 中，并且如果取款成功则返回 `True`，否则返回 `False`。
   - 一个基于 `ledger` 返回当前类别余额的 `get_balance` 方法。
   - 一个接受金额和另一个 `Category` 实例的 `transfer` 方法，从当前类别中以描述 `Transfer to [Destination]` 提取该金额，并以描述 `Transfer from [Source]` 存入另一个类别，其中 `[Destination]` 和 `[Source]` 应替换为目标和源类别的名称。转账成功时该方法应 return `True`，否则 `False`。
   - 一个接受金额并在超过余额时返回 `False`，否则返回 `True` 的 `check_funds` 方法。该方法必须被 `withdraw` 和 `transfer` 方法同时使用。

1. 当打印 `Category` 对象时，它应：  
   - 显示一行 30 个字符的标题，类别名称居中显示在 `*` 字符之间。  
   - 将每个 `ledger` 条目列出，描述最多 23 个字符左对齐，金额右对齐（两位小数，最多 7 个字符）。  
   - 显示最后一行 `Total: [balance]`，其中 `[balance]` 应替换为类别总计。
   
   这里是一个示例用法：
   
   ```py
   food = Category('Food')
   food.deposit(1000, 'initial deposit')
   food.withdraw(10.15, 'groceries')
   food.withdraw(15.89, 'restaurant and more food for dessert')
   clothing = Category('Clothing')
   food.transfer(50, clothing)
   print(food)
   ```

   下面是输出示例：

   ```md
   *************Food*************
   initial deposit        1000.00
   groceries               -10.15
   restaurant and more foo -15.89
   Transfer to Clothing    -50.00
   Total: 923.96
   ```

1. 你应该有一个位于 `Category` 类外部的函数，名为 `create_spend_chart(categories)`，它接受一个类别列表并返回一个条形图字符串。构建图表时：

   - 以标题 `Percentage spent by category` 开始。
   - 仅从提款计算百分比，不包括存款。百分比应为每个类别支出金额占所有类别总支出的百分比（向下取整到最接近的 10）。
   - y 轴从 `100` 标记到 `0`，步长为 10。
   - 使用 `o` 字符表示条形。
   - 在最后一个栏杆后两格处包含一条水平线。
   - 在条形图下方垂直书写类别名称。

   该函数将测试最多四个类别。

   确保完全匹配示例输出的间距：

   ```md
   Percentage spent by category
   100|          
    90|          
    80|          
    70|          
    60| o        
    50| o        
    40| o        
    30| o        
    20| o  o     
    10| o  o  o  
     0| o  o  o  
       ----------
        F  C  A  
        o  l  u  
        o  o  t  
        d  t  o  
           h     
           i     
           n     
           g     
   ```

class Category:

    def __init__(self, name):
        self.name = name
        self.ledger = []
        self.balance = 0
        self.spent = 0

    def __str__(self):
        first_line = f'{self.name.center(30, "*")}\n'
        lines = ''
        total = f'Total: {format(self.balance, ".2f")}'

        for n in range(len(self.ledger)):
            descr = self.ledger[n]["description"][:23]
            am = format(float(self.ledger[n]["amount"]), ".2f")[:7]
            lines += f'{descr:<23}{am:>7}\n'

        return f'{first_line}{lines}{total}'

    def deposit(self, amount, description=''):
        self.ledger.append({
            'amount': float(amount),
            'description': description
        })
        self.balance += float(amount)

    def withdraw(self, amount, description=''):
        if self.check_funds(amount):
            self.ledger.append({
                'amount': -float(amount),
                'description': description
            })
            self.balance -= float(amount)
            self.spent += float(amount)
            return True
        else:
            return False

    def get_balance(self):
        return self.balance

    def transfer(self, amount, category):
        if self.check_funds(amount):
            # withdraw
            self.ledger.append({
                'amount': -float(amount),
                'description': f'Transfer to {category.name}'
            })
            self.balance -= float(amount)
            self.spent += float(amount)

            # deposit
            category.deposit(amount, f'Transfer from {self.name}')
            return True
        else:
            return False

    def check_funds(self, amount):
        if float(amount) > self.balance:
            return False
        else:
            return True


def create_spend_chart(categories):
    # Step 1: Calculate total spending
    total_spent = sum(category.spent for category in categories)

    # Step 2: Calculate each category's percentage
    percentages = [int((category.spent / total_spent * 100) // 10) * 10 if total_spent else 0 for category in categories]

    # Step 3: Start building the chart
    chart_lines = ["Percentage spent by category"]

    # Step 4: Draw bars from 100% down to 0%
    for level in range(100, -1, -10):
        line = f"{level:>3}| "

        for percentage in percentages:
            if percentage >= level:
                line += "o  "
            else:
                line += "   "

        chart_lines.append(line)

    # Step 5: Draw the horizontal separator
    separator = "    " + "-" * (len(categories) * 3 + 1)
    chart_lines.append(separator)

    # Step 6: Find the longest category name
    max_name_length = max(
        (len(category.name) for category in categories),
        default=0
    )

    # Step 7: Print category names vertically
    for i in range(max_name_length):
        label_line = "     "

        for c in categories:
            if i < len(c.name):
                label_line += c.name[i]
            else:
                label_line += " "

            label_line += "  "

        chart_lines.append(label_line)

    # Step 8: Join all lines and return the chart
    return "\n".join(chart_lines)
