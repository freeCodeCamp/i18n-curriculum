# --description--

在之前的課程中，你學習了樹的概念。二元樹是一種每個節點最多有兩個子節點的樹，這兩個子節點分別稱為左子節點和右子節點。

二元搜尋樹（BST）是一種保持值有序的二元樹：對於每個節點，其左子樹中的所有值都比該節點的值小，而右子樹中的所有值都比該節點的值大。

<img alt="a binary search tree" src="https://cdn.freecodecamp.org/curriculum/python/bst-example.png" style="background-color: white; height:500px; width:500px; padding: 10px; display: block; margin-right: auto; margin-left: auto; margin-bottom: 1.2rem;">

在這個工作坊中，你將建置一棵二元搜尋樹並學習如何巡訪它。

首先創建一個名為 `TreeNode` 的類別來表述樹中的單一節點。給它一個帶有兩個參數 `self` 和 `key` 的 `__init__` 方法，並將 `key` 指定給 `self.key`。
