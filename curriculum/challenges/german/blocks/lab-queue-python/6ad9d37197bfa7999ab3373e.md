# --description--

In diesem Labor erstellen Sie eine Warteschlangen-Klasse. Eine Warteschlange folgt dem FIFO-Prinzip (first-in, first-out): Elemente werden hinten an die Warteschlange angefügt und vorne entfernt.

**Ziel:** Erfüllen Sie die untenstehenden User Stories und bestehen Sie alle Tests, um das Labor abzuschließen.

**User Stories:**

1. Sie sollten eine Klasse namens `Queue` definieren. Eine neue Instanz von `Queue` sollte leer starten.

1. Die `Queue`-Klasse sollte folgende Methoden haben:

   - `enqueue`: nimmt ein Element und fügt es hinten an die Warteschlange an.
   - `dequeue`: entfernt das Element vorne aus der Warteschlange und gibt es zurück. Wenn die Warteschlange leer ist, sollte `None` zurückgegeben werden.
   - `front`: gibt das Element vorne in der Warteschlange zurück, ohne es zu entfernen. Wenn die Warteschlange leer ist, sollte `None` zurückgegeben werden.
   - `size`: gibt die Anzahl der Elemente in der Warteschlange zurück.
   - `is_empty`: gibt `True` zurück, wenn die Warteschlange keine Elemente hat, und sonst `False`.

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
