# --description--

`index()` 메서드는 튜플에서 요소가 처음 나타나는 인덱스를 반환합니다. `sorted_releases`가 최신 버전부터 오래된 버전 순으로 정렬되어 있으므로, 설치된 버전의 인덱스는 더 최신 릴리스 수와 같습니다.

`if` 문 다음에 `releases_behind`라는 변수를 만들고 `sorted_releases`에서 `installed`의 인덱스를 할당하세요.
