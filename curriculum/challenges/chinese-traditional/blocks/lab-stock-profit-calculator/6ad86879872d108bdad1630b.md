# --description--

在這個實驗中，你將找出單次股票交易能獲得的最大利潤。你會得到每一天的股票價格，你可以在某一天買入一股，並在之後的某一天賣出。你的目標是找出能獲得的最高利潤，也就是賣出價格減去買入價格。

例如，對於價格 `[7, 1, 5, 3, 6, 4]`，最佳交易是在第 `1` 天以價格 `1` 買入，並在第 `4` 天以價格 `6` 賣出，獲利為 `5`。你不能在價格為 `1` 時買入，然後在價格為 `7` 時賣出，因為價格 `7` 出現在價格 `1` 之前。

列表可能非常長，因此你的解法應該是高效的。比較每一對可能的買賣日會花費二次方時間，`O(n²)`。相反地，找出一種只需遍歷列表一次的方法，讓你的解法能以線性時間，`O(n)` 執行。

**目標：** 完成以下使用者故事並通過所有測試以完成實驗。

**使用者故事：**

1. 你應該有一個名為 `max_profit` 的函式，帶有一個參數，該參數代表一個正整數列表，每個元素是該天的股票價格。
1. `max_profit` 應該傳回在某一天買入並在之後某一天賣出所能獲得的最高利潤。
1. 如果沒有交易能獲利，或 `prices` 少於兩個元素，`max_profit` 應該傳回 `0`。
1. `max_profit` 不應修改 `prices`。
1. `max_profit` 應該以線性時間，`O(n)` 執行，其中 `n` 是 `prices` 的長度。

**注意：** 不要檢查每一對天數，而是嘗試在遍歷列表時，持續追蹤目前為止見過的最低價格，並計算當天賣出的利潤。

```py
def max_profit(prices):
    lowest_price = float("inf")
    best_profit = 0

    for price in prices:
        if price < lowest_price:
            lowest_price = price
        elif price - lowest_price > best_profit:
            best_profit = price - lowest_price

    return best_profit
```
