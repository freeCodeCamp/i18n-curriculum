## コードエディターまたはIDEのインストール

前のレッスンでは、ローカルデバイスにPythonをインストールする方法を学びました。このレッスンでは、Pythonコードをローカルで実行する方法を学びます。

ローカルでPythonスクリプトの作成を始める前に、コードエディターまたはIDEをインストールする必要があります。IDEとは統合開発環境のことで、コードエディター、テストツール、ターミナルなどの機能を組み合わせたものです。

多くの開発者に人気のあるコードエディターの1つがVS Codeです。`https://code.visualstudio.com/download` にアクセスして、macOS、Windows、Linuxに対応したVS Codeをダウンロードしてください。このレッスンではこのエディターを使用します。

Python開発でよく使われる他の選択肢には以下があります：

- PyCharm
- Spyder

## Pythonファイルの作成

VS Codeをインストールしたら開き、`File` を選択してから `Open Folder` を選んでください。プロジェクト用のフォルダーを選ぶか新しく作成します。レッスン外での練習用に `python-projects` という名前のフォルダーを作成しても良いでしょう。

VS Codeの左サイドバーにあるExplorerを開きます。紙にプラス記号が付いたような `New File` アイコンを選択してください。`main.py` という名前のファイルを作成し、<kbd>Enter</kbd> を押します。`.py` 拡張子はPythonファイルであることを示します。

`main.py`ファイルを開き、次のコードを入力してください：

```py
print("Hello, world!")
```

## Python拡張機能のインストール

Microsoftの公式Python拡張機能をインストールするには、以下の手順に従ってください。

### 方法A：アプリケーション内でのインストール

1. 左側のアクティビティバーにある四つのブロックのアイコンをクリックして拡張機能ビューを開きます。あるいは、<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>（Windows / Linux）または <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>（macOS）を押します。
1. 上部の検索バーに `Python` と入力します。
1. 一番上に表示されるPythonという名前の結果を探し、その下にMicrosoftと表示されていることを確認します。
1. 青い <kbd>Install</kbd> ボタンをクリックします。

### 方法B：ターミナル / コマンドラインからのインストール

ターミナルから拡張機能をインストールしたい場合は、まず `code` コマンドが使えることを確認してください。macOSではコマンドパレットを開き、`Shell Command: Install 'code' command in PATH` を実行してからターミナルを再起動します。

その後、以下のコマンドを実行してPython拡張機能をインストールします。

```bash
code --install-extension ms-python.python
```

## Pythonインタープリターの選択

拡張機能は橋渡しの役割をしますが、実際のPython言語ファイルは含まれていません。まだインストールしていない場合は、公式PythonウェブサイトからPythonインタープリターを別途インストールする必要があります。

PythonがOSにインストールされたら、エディターに紐付けます。

1. VS Codeで任意のフォルダーか `.py` で終わるファイルを開きます。
1. <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（Windows / Linux）または <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（macOS）でコマンドパレットを開きます。
1. `Python: Select Interpreter` と入力して選択します。
1. マシンにインストールされているPython 3のバージョンを選びます。これでワークスペースのステータスバーにネイティブ表示されます。

## Pythonスクリプトの実行

このコードを実行するにはいくつかの方法があります。最初の方法は、右上にある再生ボタンのような実行ボタンをクリックすることです。これでターミナルが開き、Pythonスクリプトが実行されます。`Hello, world!` というテキストが表示されるはずです。

もう一つの方法は、ターミナルを開いて手動で次のコマンドを使ってプログラムを実行することです：

```bash
python main.py
```

このコマンドは`main.py`が保存されているフォルダから実行する必要があります。例えば、`main.py`が`python-projects`というフォルダ内にある場合、まずターミナルで以下を使います。

```bash
cd python-projects
```

次に以下を実行します。

```bash
python main.py
```

## `python` の代わりに `python3` を使う

特にmacOSやLinuxの環境では、Python 2とPython 3の両方がインストールされている場合、`python`の代わりに`python3`を使う必要がある場合があります。これは`python`コマンドが存在しないか、古いバージョンのPythonを指している場合によくあります。

```bash
python3 main.py
```
