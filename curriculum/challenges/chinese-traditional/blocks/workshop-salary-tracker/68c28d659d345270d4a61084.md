# --description--

`__repr__` 方法是一個特殊的方法，應該傳回一個可以用來實例化該物件的字串表述。

例如，`Employee('Charlie', 'developer')` 的 `__repr__` 方法應該傳回字串 `Employee('Charlie', 'developer')`，這是用來創建該物件的相同字串。

如果你在每個值周圍加上引號，當值中包含引號時結果就會出錯。對於一個名為 `O'Reilly`、層級為 `junior` 的員工，你會得到 `Employee('O'Reilly', 'junior')`，這是不合法的，因為撇號會提早結束字串。

Python 內建的 `repr()` 函式會傳回一個值的字串表述。對於字串，它會加上引號並跳脫任何需要跳脫的字元：

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

在 f-string 裡，你可以在表達式後加上 `!r` 來套用 `repr()`：

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

為你的 `Employee` 類別添加一個帶有 `self` 參數的 `__repr__` 方法。讓它傳回一個可用來實例化該物件的字串，並對 `self.name` 和 `self.level` 使用 `!r`，以保留任何引號或反斜線。
