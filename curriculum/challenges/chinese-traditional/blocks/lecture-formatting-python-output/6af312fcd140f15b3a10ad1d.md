# --description--

在之前關於數字和數學運算的課程中，你使用過像 `.2f` 這樣的格式規範在 f-string 中控制數字顯示的小數位數。

格式規範也可以控制一個值佔用多少空間以及它的位置。當你想讓輸出整齊排列成欄時，這非常有用。

## 設定最小寬度和對齊方式

冒號後的數字設定欄位的最小寬度，也就是值應該佔用的字元數。如果值比這個寬度短，Python 會加空格直到達到該寬度。以下是範例：

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

在寬度前使用特定符號可以控制值在欄位中的位置。以下是這些特定符號：

- 小於符號（`<`）將值靠左對齊
- 大於符號（`>`）將值靠右對齊
- 脫字符號（`^`）將值置中。

以下是這三個符號的示範：

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

`'Tea'` 包含三個字元，所以 Python 加了五個空格來達到寬度 `8`。

- 使用 `<` 時，空格會加在值的後面
- 使用 `>` 時，空格會加在值的前面
- 使用 `^` 時，空格會分配在兩邊以置中文字。

如果空格無法平均分配，多出來的空格會放在右邊：

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

如果省略對齊符號，字串預設靠左對齊，而數字預設靠右對齊：

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## 使用填充字元

Python 預設用空格填充。若要使用其他字元填充，請將該字元放在對齊符號前面：

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

在 `*^9` 中，`*` 是填充字元，`^` 將值置中，`9` 是最小寬度。注意，填充字元只能和對齊符號一起使用。

## 結合寬度和精度

你可以將對齊、寬度和你在上一課學到的精度結合在同一個格式規範中：

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

上面範例中的格式規範表示：靠右對齊，最小寬度為 `7`，顯示兩位小數。Python 先將數字格式化為 `4.50`（長度為四個字元），然後在前面加三個空格以填滿寬度 `7`。

## 建立一列述語

你可以將標籤和金額放在同一行。如果每列都使用相同的格式規範，欄位就會對齊：

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

每個標籤在寬度為 `12` 的欄位中靠左對齊並用點號填充，而每個金額在寬度為 `8` 的欄位中靠右對齊，這樣小數點就會對齊。

## 寬度是最小值，不是最大值

寬度只會加上填充空格，絕不會截斷值。如果值比指定寬度長，會顯示整個值：

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

數字也是如此。以下範例中，格式化後的金額需要八個字元，因此會忽略指定的寬度 `7`：

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

在 `:7.2f` 中，`7` 是最小寬度，而不是限制金額長度的上限。Python 不會為了讓數字符合寬度而截斷位數。

這就是為什麼你應該選擇足夠大的寬度來符合預期的值，否則欄位不會對齊。

如果你想限制字串長度，可以在格式規範中加入精度。對字串來說，精度設定顯示的最大字元數：

```py
label = 'Long description'

print(f'|{label:.8}|') # |Long des|
print(f'|{label:<12.8}|') # |Long des    |
```

在 `<12.8` 中：

- `<` 將值靠左對齊
- `12` 是最小寬度
- `.8` 是最大字元數。

Python 會先將字串截斷為八個字元，然後再填充到寬度十二。

注意，精度對字串和數字的意義不同。對 `.2f`，`.2` 設定小數位數；對字串，`.8` 設定最大字元數。
