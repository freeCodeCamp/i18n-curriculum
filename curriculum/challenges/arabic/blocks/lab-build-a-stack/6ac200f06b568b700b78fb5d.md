# --description--

في هذا المختبر، ستنفذ هيكل بيانات المكدس باستخدام الدوال. المكدس هو هيكل بيانات من نوع آخر يدخل أولاً يخرج أخيراً (LIFO)، حيث تُضاف العناصر وتُزال من الأعلى.

سيكون مكدسك قاموسًا يحتوي على مفتاح `collection` يحمل قائمة من العناصر. قمة المكدس هي نهاية القائمة، لذا فإن آخر عنصر في القائمة هو الأحدث إضافة.

**الهدف:** إكمال قصص المستخدم أدناه واجتياز جميع الاختبارات لإتمام المختبر.

**قصص المستخدم:**

1. يجب أن تحتوي على دالة `init_stack` تُرجع قاموسًا بمفتاح `collection` مضبوط على قائمة فارغة.
1. يجب أن تحتوي على دالة `push` تأخذ مكدسًا وعنصرًا، وتضيف العنصر إلى قمة المكدس.
1. يجب أن تحتوي على دالة `pop` تأخذ مكدسًا، وتزيل وتُرجع عنصر القمة، أو تُرجع `None` إذا كان المكدس فارغًا.
1. يجب أن تحتوي على دالة `peek` تأخذ مكدسًا، وتُرجع عنصر القمة دون إزالته، أو تُرجع `None` إذا كان المكدس فارغًا.
1. يجب أن تحتوي على دالة `is_empty` تأخذ مكدسًا، وتُرجع `True` إذا لم يحتوي على عناصر، و`False` خلاف ذلك.
1. يجب أن تحتوي على دالة `clear` تأخذ مكدسًا، وتزيل كل عناصره.

**ملاحظة:** تعتمد معظم الاختبارات على دالتي `init_stack` و `push`. نفذهما أولًا، إذ تتطلب اختبارات `pop` و `peek` و `is_empty` و `clear` إضافة عناصر إلى المكدس.

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
