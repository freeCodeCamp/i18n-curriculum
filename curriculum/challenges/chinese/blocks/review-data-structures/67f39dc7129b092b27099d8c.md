## 算法和大 O 表示法

- **算法**：解决问题或完成任务的一组明确指令。算法必须在有限步骤内完成，每步必须精确且明确。

- **Big O 表示法**：描述算法资源使用随输入规模增加的渐近上界。Big O 衡量整体的增长趋势，独立于你是在看最好、平均还是最坏情况，同时忽略常数因子和较小项。

### 常见时间复杂度

- **O(1) - 常数时间**：算法所需时间与输入规模无关。

```python
def check_even_or_odd(number):
    if number % 2 == 0:
        return 'Even'
    else:
        return 'Odd'
```

- **O(log n) - 对数时间**：运行时间的上界最多以对数速度随输入规模增长。当上界紧确时，算法运行时间为对数时间。这通常发生在问题规模被反复按固定比例缩小时，比如二分查找。

- **O(n) - 线性时间**：运行时间的上界最多以线性速度随输入规模增长。当上界紧确时，运行时间与输入规模成正比。

```python
for grade in grades:
    print(grade)
```

- **O(n log n) - 对数线性时间**：高效的分治排序中常见。归并排序的最坏情况复杂度为 O(n log n)。快速排序的平均情况复杂度为 O(n log n)，但最坏情况复杂度为 O(n²)。

- **O(n²) - 平方时间**：运行时间的上界最多以输入规模的平方速度增长。当上界紧确时，运行时间与输入规模的平方成正比。这发生在嵌套循环中，每个循环执行 n 次迭代。

```python
for i in range(n):
    for j in range(n):
        print("Hello, World!")
```

- **O(2ⁿ) - 指数时间**：运行时间的指数上界。当上界紧确时，增长率与 2ⁿ 成正比，n 增加 1 时运行时间翻倍。

- **O(n!) - 阶乘时间**：运行时间的阶乘上界。当上界紧确时，增长率与 n! 成正比，即 n 个不同项的排列数。

### 空间复杂度

- **O(1) - 常量空间**：内存使用被一个与输入规模无关的常量限制。

- **O(n) - 线性空间**：内存使用最多以线性速度随输入规模增长。当上界紧确时，内存使用与输入规模成正比。

- **O(n²) - 平方空间**：内存使用最多以输入规模的平方速度增长。当上界紧确时，内存使用与输入规模的平方成正比。

- **O(2ⁿ) - 指数空间**：内存使用的指数上界。当上界紧确时，内存使用与 2ⁿ 成正比。

- **O(n!) - 阶乘空间**：内存使用的阶乘上界。当上界紧确时，内存使用与 n! 成正比。

## 解决问题的技巧

- **理解问题**：多次阅读问题描述。确定输入、预期输出以及如何将输入转换为输出。

- **算法和数据结构选择**：比较备选算法的时间和空间需求，选择适合问题的数据结构。

- **伪代码**：算法逻辑的高级描述，与语言无关，使用常见书面语言混合编程结构如 `IF`、`ELSE`、`FOR` 和 `WHILE`。

```md

```

- **实现**：根据伪代码计划编写简洁、可读且模块化的代码。使用适当的内置工具完成常见任务。

- **边界情况**：算法应处理的边界上的特定有效输入。始终考虑并测试边界情况。

- **测试和精化**：用提供的示例和边界情况测试代码。调试错误，检查结果，精化方案以提高清晰度或效率。

## 数组

- **静态数组**：创建时大小固定，元素存储在连续内存中。相邻布局支持快速、常数时间的索引访问（O(1)）。当最大项数严格已知时选择静态数组。

- **动态数组**：程序执行期间可自动增长或缩小。空间不足时，底层会分配更大内存块并拷贝现有元素来处理扩容。

**注意：** Python 没有传统的内置静态数组。Python 的列表是动态数组。

### Python 列表（动态数组）

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### 动态数组的时间复杂度

- **访问**：O(1)

- **末尾插入**：平均 O(1)，需要扩容时为 O(n)

- **中间插入**：O(n)

- **删除**：中间为 O(n)，末尾为 O(1)

## 栈

- **栈**：后进先出（LIFO）数据结构。元素仅从顶部添加和移除。

- **入栈操作**：将元素添加到栈顶。对于下面的 Python 列表实现，普通入栈耗时 O(1)，额外空间 O(1)。需要扩容的入栈耗时 O(n)，额外空间 O(n)。

- **出栈操作**：从栈顶移除元素。时间复杂度通常为 O(1)，额外空间通常为 O(1)。

```python
# Using Python list as stack
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operations
top_element = stack.pop()  # Returns 3
```

## 队列

- **队列**：先进先出（FIFO）数据结构，元素从尾部添加，从头部移除。

- **入队操作**：将元素添加到队列尾部。时间复杂度：O(1)，空间复杂度：O(1)。

- **出队操作**：从队列头部移除元素。时间复杂度：O(1)，空间复杂度：O(1)。

## 链表

- **链表**：线性数据结构，每个节点包含数据和指向下一个节点的引用。节点像链条一样连接。

### 单链表

- **结构**：每个节点包含数据和一个指向下一个节点的引用。

- **遍历**：只能从头到尾向前移动。

- **头节点**：列表中的第一个节点，通常是唯一可直接访问的节点。

- **尾节点**：列表中的最后一个节点，指向 `None`。

### 链表实现

- **节点类**：嵌套的 `Node` 类表示单个节点。每个节点包含数据和指向下一个节点的引用。

- **初始化**：`head` 引用初始为 `None`，因为链表没有节点。每个新节点的 `next` 引用初始为 `None`，因为它还没有后继节点。

- **长度跟踪**：一个长度变量记录链表中节点的数量。

- **`is_empty()`**：通过检查 `head` 是否为 `None` 来判断链表是否为空。

- **追加**：从头节点遍历直到最后一个节点，然后更新其 `next` 引用指向新节点。如果链表为空，新节点成为头节点。

```python
class LinkedList:
    class Node:
        def __init__(self, data):
            self.data = data
            self.next = None

    def __init__(self):
        self.head = None
        self.length = 0

    def is_empty(self):
        return self.head is None

    def append(self, data):
        new_node = self.Node(data)

        if self.is_empty():
            self.head = new_node
        else:
            current = self.head

            while current.next:
                current = current.next

            current.next = new_node

        self.length += 1
```

### 操作和时间复杂度

- **开头插入**：O(1)

- **末尾插入**：O(n) - 必须遍历到末尾

- **中间插入**：O(n) - 必须遍历到指定位置

- **开头删除**：O(1)

- **末尾删除**：O(n) - 必须遍历找到前一个节点

- **中间删除**：O(n) - 必须遍历找到目标节点

### 插入和删除

- **开头插入**：创建新节点，将其 `next` 引用指向当前头节点，然后更新头节点指向新节点。

- **末尾插入**：遍历到最后一个节点，更新其 `next` 引用指向新节点。

- **中间插入**：遍历到目标位置的前一个节点。更新新节点的 `next` 引用指向后继节点，再更新前一个节点的 `next` 引用指向新节点。

- **开头删除**：更新头节点指向第二个节点。

- **末尾删除**：遍历到倒数第二个节点，将其 `next` 引用更新为 `None`。

- **中间删除**：找到目标节点的前一个节点，更新其 `next` 引用跳过目标节点。

- **按值删除**：遍历时跟踪前一个节点。如果目标是头节点，直接更新头节点。如果未找到值，返回且不修改链表或长度。只有成功删除后才减少长度。

### 辅助空间复杂度

- **开头插入**：辅助空间 O(1)，不包括新节点的存储空间。

- **末尾插入**：辅助空间 O(1)，不包括新节点的存储空间。

- **中间插入**：辅助空间 O(1)，不包括新节点的存储空间。

- **开头删除**：辅助空间 O(1)。

- **末尾删除**：辅助空间 O(1)。

- **中间删除**：辅助空间 O(1)。

### 双链表

- **结构**：每个节点包含数据和两个引用：下一个节点和上一个节点。

- **遍历**：可以双向移动。

- **内存**：由于额外的引用，所需内存比单链表多。

- **尾部引用**：维护对最后一个节点的引用允许使用上一个引用进行反向遍历。

## 哈希映射和集合

### 映射和哈希映射

- **抽象数据类型（ADT）与实现**：ADT 定义*接口*——说明数据结构支持哪些操作及其逻辑行为。具体实现定义后台机制，展示这些操作如何在内存中构建和执行。

- **映射（ADT）**：定义唯一键映射到值的集合的抽象数据类型。它规定映射能做什么，但不限定其内部存储方式。

- **哈希映射**：映射 ADT 的具体实现，使用哈希函数计算底层数组中的存储位置以实现快速查找。

### Python 字典（哈希映射）

```python
# Creating dictionaries
my_dictionary = {
    "A": 1,
    "B": 2,
    "C": 3
}

# Alternative creation
my_dictionary = dict(A=1, B=2, C=3)

# Access and modify
value = my_dictionary["A"]  # 1
my_dictionary["A"] = 4      # Update value
del my_dictionary["A"]      # Remove key-value pair

# Check membership
"C" in my_dictionary

# Get keys, values, items
my_dictionary.keys()
my_dictionary.values()
my_dictionary.items()
```

### 哈希映射的时间复杂度

- **平均情况**：插入、获取、删除均为 O(1)

- **最坏情况**：当发生大量哈希冲突时为 O(n)

### 哈希映射的辅助空间复杂度

- **插入**：普通插入额外空间为 O(1)。扩容可能需要 O(n) 额外空间。

- **查找**：辅助空间 O(1)。

- **删除**：辅助空间 O(1)。

### 集合

- **集合**：无序且唯一元素的集合。不允许重复，不维护特定顺序。

- **集合元素**：集合可以包含数字、字串和只包含数字与字串的元组。列表、字典和其他集合不能作为集合元素。包含列表的元组不能作为集合元素，尽管元组本身是不可变的。

```python
# Creating sets
numbers = {1, 2, 3, 4}
empty_set = set()  # Must use set(), not {}

# Add and remove elements
numbers.add(5)
numbers.remove(4)      # Raises KeyError if not found
numbers.discard(4)     # No error if not found

# Remove and return an arbitrary element
numbers.pop()

# Remove all elements
numbers.clear()

# Get the number of elements
len(numbers)
```

### 集合操作

```python
set_a = {1, 2, 3, 4}
set_b = {2, 3, 4, 5, 6}

# Union, intersection, difference, symmetric difference
set_a.union(set_b)                  # or set_a | set_b
set_a.intersection(set_b)           # or set_a & set_b
set_a.difference(set_b)             # or set_a - set_b
set_a.symmetric_difference(set_b)   # or set_a ^ set_b

# Subset and superset checks
set_a.issubset(set_b)
set_a.issuperset(set_b)
set_a.isdisjoint(set_b)

# Membership testing
5 in numbers
```

### 集合的时间复杂度

- **平均情况**：添加、移除、成员测试均为 O(1)

- **最坏情况**：因哈希冲突为 O(n)

- **长度查询**：使用 `len()` 为 O(1)。

### 集合的辅助空间复杂度

- **插入**：普通插入额外空间为 O(1)。扩容可能需要 O(n) 额外空间。

- **查找**：辅助空间 O(1)。

- **删除**：辅助空间 O(1)。

- **长度查询**：辅助空间 O(1)。

## 哈希冲突

- **哈希冲突**：不同的键可能产生相同的哈希值。在哈希表中，当不同哈希值映射到相同数组索引时也会发生冲突。共享索引的条目必须通过冲突解决策略处理。

- **冲突解决策略**：

  - **链地址法**：每个数组索引指向一个链表，存储映射到该桶索引的所有条目。

  - **开放寻址法**：当发生冲突时，使用预定义序列搜索下一个可用数组索引。

## 何时使用各数据结构

- **列表**：当你需要有序、索引访问且事先不知道大小时使用。

- **栈**：用于后进先出（LIFO）操作（撤销功能、表达式求值、回溯）。

- **队列**：用于先进先出（FIFO）操作（任务调度、广度优先搜索）。

- **链表**：当频繁在开头插入/删除、大小未知且不需要随机访问时使用。

- **哈希映射**：用于快速键值查找、计数出现次数、缓存。

- **集合**：用于唯一性检查、数学集合操作、去重。
