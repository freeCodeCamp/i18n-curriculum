# --description--

此时，`rawData` 是深度嵌套的：`departments → programs → instructors`。要通过电子邮件查找讲师，你需要循环遍历每个部门，然后是每个项目，最后是每个讲师，直到找到匹配项。

虽然这种方法可行，但随着数据量的增长，它会变得缓慢且重复。

在后续的工作坊中，你将学习如何对数据进行规范化，这是一种更高效的方法。

但在接下来的几个步骤中，你将创建一个函数，该函数以电子邮件作为参数，使用循环在嵌套的 `rawData` 结构中查找，并在找到匹配的电子邮件地址时返回讲师的姓名。

首先删除上一步中的 `console.log()`。

然后，声明一个名为 `getInstructorByEmail` 的函数，参数名使用 `email`。函数中先返回 `null`。
