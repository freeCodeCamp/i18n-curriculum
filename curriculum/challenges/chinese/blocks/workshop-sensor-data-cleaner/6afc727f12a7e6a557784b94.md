# --description--

要为每个 difference 添加标签，你需要在 `for` 之前使用条件式，而不是在后面加 `if`：

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

从你的列表推导中移除尾随的 `if`。然后，将 `for` 前的表达式改为条件式，如果 `difference` 大于 `0`，则计算为 `f'+{difference} °C'`，否则计算为 `f'{difference} °C'`。负数已经带有 `-` 符号，所以只需要单位。
