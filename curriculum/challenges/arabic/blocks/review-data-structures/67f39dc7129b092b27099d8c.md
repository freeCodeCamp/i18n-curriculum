## الخوارزميات وترميز Big O

- **الخوارزميات**: مجموعة من التعليمات غير الغامضة لحل مشكلة أو تنفيذ مهمة. يجب أن تنتهي الخوارزميات بعدد محدود من الخطوات، ويجب أن تكون كل خطوة دقيقة وغير غامضة.

- **ترميز Big O**: يصف حدًا علويًا تقريبيًا لاستخدام الموارد في الخوارزمية مع زيادة حجم المُدخَل. يقيس Big O هذا الاتجاه العام للتوسع بشكل منفصل عن كونك تنظر إلى أفضل حالة أو متوسط حالة أو أسوأ حالة، مع تجاهل العوامل الثابتة والمصطلحات الأصغر.

### التعقيدات الزمنية الشائعة

- **O(1) - زمن ثابت**: تستغرق الخوارزمية نفس الوقت بغض النظر عن حجم الإدخال.

```python
def check_even_or_odd(number):
    if number % 2 == 0:
        return 'Even'
    else:
        return 'Odd'
```

- **O(log n) - زمن لوغاريتمي**: حد علوي لزمن التشغيل ينمو على الأكثر لوغاريتميًا مع حجم المُدخَل. عندما يكون الحد ضيقًا، تعمل الخوارزمية بزمن لوغاريتمي. يحدث هذا عادةً عندما يتم تقليل حجم المشكلة بشكل متكرر بنسبة ثابتة، كما في البحث الثنائي.

- **O(n) - زمن خطي**: حد علوي لزمن التشغيل ينمو على الأكثر خطيًا مع حجم المُدخَل. عندما يكون الحد ضيقًا، ينمو زمن التشغيل تناسبًا مع حجم المُدخَل.

```python
for grade in grades:
    print(grade)
```

- **O(n log n) - زمن لوغاريتمي خطي**: شائع في فرز التقسيم والتغلب الفعال. يحتوي فرز الدمج على تعقيد أسوأ حالة O(n log n). يحتوي فرز سريع على تعقيد متوسط حالة O(n log n)، لكن أسوأ حالة له هي O(n²).

- **O(n²) - زمن تربيعي**: حد علوي لزمن التشغيل ينمو على الأكثر تربيعيًا مع حجم المُدخَل. عندما يكون الحد ضيقًا، ينمو زمن التشغيل تناسبًا مع مربع حجم المُدخَل. يحدث هذا في الحلقات المتداخلة حيث تقوم كل حلقة بتنفيذ n تكرارًا.

```python
for i in range(n):
    for j in range(n):
        print("Hello, World!")
```

- **O(2ⁿ) - زمن أُسّي**: حد علوي أُسّي لزمن التشغيل. عندما يكون الحد ضيقًا، يكون معدل النمو تناسبيًا مع 2ⁿ، والذي يتضاعف كلما زاد n بواحد.

- **O(n!) - زمن مضروب**: حد علوي مضروب لزمن التشغيل. عندما يكون الحد ضيقًا، يكون معدل النمو تناسبيًا مع n!، عدد التباديل لعناصر n المميزة.

### التعقيد المكاني

- **O(1) - مساحة ثابتة**: استخدام الذاكرة محدود بثابت مستقل عن حجم المُدخَل.

- **O(n) - مساحة خطية**: استخدام الذاكرة ينمو على الأكثر خطيًا مع حجم المُدخَل. عندما يكون الحد ضيقًا، ينمو استخدام الذاكرة تناسبًا مع حجم المُدخَل.

- **O(n²) - مساحة تربيعية**: استخدام الذاكرة ينمو على الأكثر تربيعيًا مع حجم المُدخَل. عندما يكون الحد ضيقًا، ينمو استخدام الذاكرة تناسبًا مع مربع حجم المُدخَل.

- **O(2ⁿ) - مساحة أُسّية**: حد علوي أُسّي لاستخدام الذاكرة. عندما يكون الحد ضيقًا، ينمو استخدام الذاكرة تناسبًا مع 2ⁿ.

- **O(n!) - مساحة مضروبة**: حد علوي مضروب لاستخدام الذاكرة. عندما يكون الحد ضيقًا، ينمو استخدام الذاكرة تناسبًا مع n!.

## تقنيات حل المشكلات

- **فهم المشكلة**: اقرأ بيان المشكلة عدة مرات. حدد الإدخال، الناتج المتوقع، وكيفية تحويل الإدخال إلى الناتج.

- **اختيار الخوارزمية وهيكل البيانات**: قارن بين الخوارزميات البديلة حسب متطلبات الزمن والمساحة، واختر هياكل البيانات المناسبة للمشكلة.

- **الرمز الزائف**: وصف عالي المستوى لمنطق الخوارزمية مستقل عن اللغة، يستخدم لغة مكتوبة شائعة مختلطة مع تراكيب برمجية مثل `IF`، `ELSE`، `FOR`، و`WHILE`.

```md
GET original_string
SET reversed_string = ""

FOR EACH character IN original_string:
    ADD character TO THE BEGINNING OF reversed_string

DISPLAY reversed_string
```

- **التنفيذ**: اكتب كودًا نظيفًا، قابلًا للقراءة، ومجزأً بناءً على خطة الرمز الزائف. استخدم الأدوات المدمجة المناسبة للمهام الشائعة.

- **حالات الحافة**: إدخالات محددة وصحيحة تحدث عند حدود ما يجب أن تتعامل معه الخوارزمية. اعتبرها دائمًا واختبرها.

- **الاختبار والتنقيح**: اختبر الكود مقابل الأمثلة المقدمة وحالات الحافة. صحح الأخطاء، تحقق من النتائج، وحسّن الحل لتحسين الوضوح أو الكفاءة.

## المصفوفات

- **المصفوفات الثابتة**: لها حجم ثابت عند الإنشاء، مع تخزين العناصر في ذاكرة متجاورة. هذا الترتيب المجاور يمكّن من وصول فهرسي سريع بزمن ثابت (O(1)). اختر مصفوفة ثابتة عندما يكون الحد الأقصى لعدد العناصر معروفًا بدقة مسبقًا.

- **المصفوفات الديناميكية**: يمكن أن تنمو أو تنكمش تلقائيًا أثناء تنفيذ البرنامج. عندما تنفد المساحة، تتعامل مع إعادة التهيئة ضمنيًا عن طريق تخصيص كتلة ذاكرة أكبر ونسخ العناصر الموجودة إليها.

**ملاحظة:** لا تحتوي Python على مصفوفة ثابتة مدمجة تقليدية. قوائم Python هي مصفوفات ديناميكية.

### قوائم Python (مصفوفات ديناميكية)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### التعقيدات الزمنية للمصفوفات الديناميكية

- **الوصول**: O(1)

- **الإدراج في النهاية**: O(1) في المتوسط، O(n) عند الحاجة لإعادة التهيئة

- **الإدراج في الوسط**: O(n)

- **الحذف**: O(n) للوسط، O(1) للنهاية

## المكدسات

- **المكدسات**: هيكل بيانات يعتمد مبدأ آخر داخل، أول خارج (LIFO). تُضاف العناصر وتُزال من الأعلى فقط.

- **عملية الدفع (Push)**: إضافة عنصر إلى قمة المكدس. في تنفيذ قائمة Python أدناه، يستغرق الدفع العادي زمنًا O(1) ومساحة إضافية O(1). الدفع الذي يتطلب إعادة تهيئة قد يستغرق زمنًا O(n) ومساحة إضافية O(n).

- **عملية السحب (Pop)**: إزالة عنصر من قمة المكدس. تعقيد الزمن عادةً O(1)، والمساحة الإضافية المطلوبة عادةً O(1).

```python
# Using Python list as stack
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operations
top_element = stack.pop()  # Returns 3
```

## الطوابير

- **الطوابير**: هيكل بيانات من نوع أول داخل، أول خارج (FIFO) حيث تُضاف العناصر إلى الخلف وتُزال من الأمام.

- **عملية الإدخال في الطابور (Enqueue)**: إضافة عنصر إلى خلف الطابور. تعقيد الزمن: O(1)، تعقيد المساحة: O(1).

- **عملية الإخراج من الطابور (Dequeue)**: إزالة عنصر من أمام الطابور. تعقيد الزمن: O(1)، تعقيد المساحة: O(1).

## القوائم المرتبطة

- **القوائم المرتبطة**: هيكل بيانات خطي حيث تحتوي كل عقدة على بيانات ومرجع للعقدة التالية. العقد متصلة كسلسلة.

### القوائم المرتبطة المفردة

- **الهيكل**: تحتوي كل عقدة على بيانات ومرجع واحد للعقدة التالية.

- **التنقل**: يمكن التحرك فقط للأمام من الرأس إلى الذيل.

- **عقدة الرأس**: أول عقدة في القائمة، عادةً العقدة الوحيدة التي يمكن الوصول إليها مباشرة.

- **عقدة الذيل**: آخر عقدة في القائمة، تشير إلى `None`.

### تنفيذ القائمة المرتبطة

- **صنف العقدة**: صنف `Node` مسكن يمثل العقد الفردية. تحتوي كل عقدة على بيانات ومرجع للعقدة التالية.

- **التهيئة**: يبدأ المرجع `head` كـ `None` لأن القائمة لا تحتوي على عقد. يبدأ مرجع `next` لكل عقدة جديدة كـ `None` لأنها لا تملك خليفة بعد.

- **تتبع الطول**: متغير الطول يحتفظ بعدد العقد في القائمة.

- **`is_empty()`**: يتحقق مما إذا كانت القائمة فارغة بفحص ما إذا كان `head` هو `None`.

- **الإضافة في النهاية**: تنقل من الرأس حتى تصل إلى العقدة الأخيرة، ثم حدّث مرجع `next` الخاص بها ليشير إلى العقدة الجديدة. إذا كانت القائمة فارغة، تصبح العقدة الجديدة هي الرأس.

```python
class LinkedList:
    class Node:
        def __init__(self, data):
            self.data = data
            self.next = None

    def __init__(self):
        self.head = None
        self.length = 0

    def is_empty(self):
        return self.head is None

    def append(self, data):
        new_node = self.Node(data)

        if self.is_empty():
            self.head = new_node
        else:
            current = self.head

            while current.next:
                current = current.next

            current.next = new_node

        self.length += 1
```

### العمليات والتعقيدات الزمنية

- **الإدراج في البداية**: O(1)

- **الإدراج في النهاية**: O(n) - يجب التنقل إلى النهاية

- **الإدراج في الوسط**: O(n) - يجب التنقل إلى الموضع

- **الحذف من البداية**: O(1)

- **الحذف من النهاية**: O(n) - يجب التنقل لإيجاد العقدة السابقة

- **الحذف من الوسط**: O(n) - يجب التنقل لإيجاد العقدة

### الإدراج والحذف

- **الإدراج في البداية**: أنشئ عقدة جديدة، عيّن مرجع `next` الخاص بها إلى الرأس الحالي، وحدّث الرأس ليشير إلى العقدة الجديدة.

- **الإدراج في النهاية**: تنقل إلى العقدة الأخيرة وحدّث مرجع `next` الخاص بها ليشير إلى العقدة الجديدة.

- **الإدراج في الوسط**: تنقل إلى العقدة قبل الموضع المطلوب. حدّث مرجع `next` للعقدة الجديدة ليشير إلى العقدة التالية، ثم حدّث مرجع `next` للعقدة السابقة ليشير إلى العقدة الجديدة.

- **الحذف من البداية**: حدّث الرأس ليشير إلى العقدة الثانية.

- **الحذف من النهاية**: تنقل إلى العقدة قبل الأخيرة وحدّث مرجع `next` الخاص بها إلى `None`.

- **الحذف من الوسط**: ابحث عن العقدة قبل العقدة المستهدفة وحدّث مرجع `next` الخاص بها لتجاوز العقدة المستهدفة.

- **الإزالة بالقيمة**: تتبع العقدة السابقة أثناء التنقل. إذا كانت العقدة المستهدفة هي الرأس، حدّث الرأس مباشرة. إذا لم تُعثر على القيمة، ارجع دون تعديل القائمة أو طولها. قلل الطول فقط بعد إزالة ناجحة.

### تعقيدات المساحة المساعدة

- **الإدراج في البداية**: مساحة مساعدة O(1)، باستثناء التخزين المطلوب للعقدة الجديدة.

- **الإدراج في النهاية**: مساحة مساعدة O(1)، باستثناء التخزين المطلوب للعقدة الجديدة.

- **الإدراج في الوسط**: مساحة مساعدة O(1)، باستثناء التخزين المطلوب للعقدة الجديدة.

- **الحذف من البداية**: مساحة مساعدة O(1).

- **الحذف من النهاية**: مساحة مساعدة O(1).

- **الحذف من الوسط**: مساحة مساعدة O(1).

### القوائم المرتبطة المزدوجة

- **الهيكل**: تحتوي كل عقدة على بيانات ومرجعين: العقدة التالية والعقدة السابقة.

- **التنقل**: يمكن التحرك في كلا الاتجاهين.

- **الذاكرة**: يتطلب ذاكرة أكثر من القوائم المرتبطة المفردة بسبب المرجع الإضافي.

- **مرجع الذيل**: الحفاظ على مرجع للعقدة الأخيرة يسمح بالتنقل العكسي باستخدام المراجع السابقة.

## جداول التجزئة والمجموعات

### الخرائط وجداول التجزئة

- **نوع البيانات المجرد (ADT) مقابل التنفيذ**: يحدد ADT *الواجهة* — ما العمليات التي يدعمها هيكل البيانات وكيف يتصرف منطقيًا. يحدد التنفيذ الملموس الآلية الخلفية، موضحًا *كيف* تُبنى تلك العمليات وتُنفذ في الذاكرة.

- **الخريطة (ADT)**: نوع بيانات مجرد يحدد مجموعة من المفاتيح الفريدة المرتبطة بقيم. يحدد قواعد ما يمكن للخريطة فعله دون تحديد تخزينها الداخلي.

- **خريطة التجزئة**: تنفيذ ملموس لـ ADT الخريطة يستخدم دالة تجزئة لحساب مواقع التخزين في مصفوفة أساسية للوصول السريع.

### قواميس Python (جداول التجزئة)

```python
# Creating dictionaries
my_dictionary = {
    "A": 1,
    "B": 2,
    "C": 3
}

# Alternative creation
my_dictionary = dict(A=1, B=2, C=3)

# Access and modify
value = my_dictionary["A"]  # 1
my_dictionary["A"] = 4      # Update value
del my_dictionary["A"]      # Remove key-value pair

# Check membership
"C" in my_dictionary

# Get keys, values, items
my_dictionary.keys()
my_dictionary.values()
my_dictionary.items()
```

### التعقيدات الزمنية لجداول التجزئة

- **الحالة المتوسطة**: O(1) للإدراج، الاستعلام، والحذف

- **أسوأ حالة**: O(n) عند حدوث العديد من تصادمات التجزئة

### تعقيدات المساحة المساعدة لخريطة التجزئة

- **الإدراج**: مساحة إضافية O(1) للإدراج العادي. قد تتطلب إعادة التهيئة مساحة إضافية O(n).

- **الاستعلام**: مساحة مساعدة O(1).

- **الحذف**: مساحة مساعدة O(1).

### المجموعات

- **المجموعات**: مجموعات غير مرتبة من عناصر فريدة. لا يسمح بالتكرار، ولا يتم الحفاظ على ترتيب محدد.

- **عناصر المجموعات**: يمكن أن تحتوي المجموعات على أرقام، سلاسل نصية، وصفوف مرتبة تحتوي فقط على أرقام وسلاسل نصية. لا يمكن أن تكون القوائم، القواميس، والمجموعات الأخرى عناصر مجموعة. لا يمكن أن يكون الصف المرتب الذي يحتوي على قائمة عنصرًا في مجموعة، رغم أن الصف نفسه غير قابل للتغيير.

```python
# Creating sets
numbers = {1, 2, 3, 4}
empty_set = set()  # Must use set(), not {}

# Add and remove elements
numbers.add(5)
numbers.remove(4)      # Raises KeyError if not found
numbers.discard(4)     # No error if not found

# Remove and return an arbitrary element
numbers.pop()

# Remove all elements
numbers.clear()

# Get the number of elements
len(numbers)
```

### عمليات المجموعات

```python
set_a = {1, 2, 3, 4}
set_b = {2, 3, 4, 5, 6}

# Union, intersection, difference, symmetric difference
set_a.union(set_b)                  # or set_a | set_b
set_a.intersection(set_b)           # or set_a & set_b
set_a.difference(set_b)             # or set_a - set_b
set_a.symmetric_difference(set_b)   # or set_a ^ set_b

# Subset and superset checks
set_a.issubset(set_b)
set_a.issuperset(set_b)
set_a.isdisjoint(set_b)

# Membership testing
5 in numbers
```

### التعقيدات الزمنية للمجموعات

- **الحالة المتوسطة**: O(1) للإضافة، الإزالة، واختبار العضوية

- **أسوأ حالة**: O(n) بسبب تصادمات التجزئة

- **استعلام الطول**: O(1) باستخدام `len()`.

### تعقيدات المساحة المساعدة للمجموعات

- **الإدراج**: مساحة إضافية O(1) للإدراج العادي. قد تتطلب إعادة التهيئة مساحة إضافية O(n).

- **الاستعلام**: مساحة مساعدة O(1).

- **الحذف**: مساحة مساعدة O(1).

- **استعلام الطول**: مساحة مساعدة O(1).

## تصادمات التجزئة

- **تصادم التجزئة**: يمكن لمفاتيح مختلفة أن تنتج نفس قيمة التجزئة. في جدول التجزئة، تحدث التصادمات أيضًا عندما ترسم قيم تجزئة مختلفة إلى نفس فهرس المصفوفة. يجب التعامل مع المدخلات التي تشترك في فهرس بواسطة استراتيجية حل التصادم.

- **استراتيجيات حل التصادم**:

  - **التسلسل**: يشير كل فهرس في المصفوفة إلى قائمة مرتبطة تخزن كل المدخلات التي ترسم إلى نفس فهرس الدلو.

  - **العنوان المفتوح**: يبحث عن الفهرس التالي المتاح في المصفوفة باستخدام تسلسل محدد مسبقًا عند حدوث تصادم.

## متى تستخدم كل هيكل بيانات

- **القوائم**: عندما تحتاج إلى وصول مرتب ومفهرس ولا تعرف الحجم مسبقًا.

- **المكدسات**: لعمليات LIFO (وظيفة التراجع، تقييم التعبير، التراجع).

- **الطوابير**: لعمليات FIFO (جدولة المهام، البحث بالاتساع أولاً).

- **القوائم المرتبطة**: عند الحاجة إلى إدراج/حذف متكرر في البداية، حجم غير معروف، ولا حاجة للوصول العشوائي.

- **خرائط التجزئة**: للوصول السريع إلى القيم حسب المفتاح، عد التكرارات، التخزين المؤقت.

- **المجموعات**: لفحص التفرد، عمليات المجموعات الرياضية، إزالة التكرارات.
