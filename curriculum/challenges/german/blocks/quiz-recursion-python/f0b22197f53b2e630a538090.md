Eine Methode zum Sortieren von Listen.

---

---

### --question--

#### --text--

Welches der folgenden Beispiele ist ein Beispiel für Rekursion?

#### --distractors--

```py
def factorial(n):
    result = 1
    while n > 0:
        result *= n
        n -= 1
    return result
```

---

```py
def factorial(n):
    numbers = [number for number in range(1, n + 1)]
    result = 1
    for number in numbers:
        result *= number
    return result
```

---

```py
def factorial(n):
    result = 1
    for number in range(n, 0, -1):
        result *= number
    return result
```

#### --answer--

```py
def factorial(n):
    if n == 0 or n == 1:
        return 1
    return n * factorial(n - 1)
```

### --question--

#### --distractors--

---

Um die Anzahl der Funktionsaufrufe zu reduzieren.
