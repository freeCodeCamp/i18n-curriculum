# --description--

Регулярний вираз, або regex, — це шаблон, який використовується для співставлення послідовності символів у тексті.

Ви вже використовували оператор `in`, щоб перевірити, чи містить рядок точну підрядок. Але бувають випадки, коли ви не знаєте точний текст, який шукаєте, а лише його форму. Наприклад, ви можете захотіти перевірити, що рядок починається з кількох літер, за якими йдуть цифри, або що ім’я користувача складається лише з дозволених символів.

Регулярні вирази дозволяють описувати такі шаблони і перевіряти, чи відповідає їм рядок. Їх часто використовують для валідації вхідних даних, пошуку в тексті та вилучення інформації з рядків.

У Python, щоб використовувати регулярні вирази, потрібно імпортувати модуль `re`, який є частиною стандартної бібліотеки:

```python
import re
```

Найпростіший шаблон регулярного виразу — це буквальний шаблон: послідовність символів, які мають з’явитися саме в такому вигляді. Наприклад, шаблон `'cat'` співпадає з літерами `c`, `a` і `t`, які йдуть одна за одною.

Щоб шукати шаблон у рядку, можна використати функцію `search` з модуля `re`. Вона приймає шаблон як перший аргумент і рядок для пошуку як другий аргумент:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

Коли `re.search` знаходить шаблон у будь-якому місці рядка, вона повертає об’єкт співпадіння. Надрукований об’єкт співпадіння повідомляє вам дві речі:

- `match='cat'` — це текст, який співпав із шаблоном.

- `span=(4, 7)` — це позиція співпадіння в рядку. Співпадіння починається з індексу `4` і закінчується безпосередньо перед індексом `7`.

Ви також можете отримати цю інформацію з об’єкта співпадіння за допомогою його методів `group` і `span`:

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

Коли шаблон не знайдено, `re.search` повертає `None`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

За замовчуванням співставлення регулярних виразів чутливе до регістру. Це означає, що шаблон `'Cat'` не співпадає з текстом `cat`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

Щоб змінити спосіб співставлення шаблону, можна передати прапорець як третій аргумент у `re.search`. Прапорець `re.IGNORECASE` робить пошук нечутливим до регістру, тому великі та малі літери вважаються однаковими:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
