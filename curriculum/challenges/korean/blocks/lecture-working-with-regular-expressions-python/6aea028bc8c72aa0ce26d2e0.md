# --description--

정규 표현식은 역슬래시(`\`) 다음에 문자가 오는 특수 수열을 포함할 수 있습니다. 이 수열들은 특별한 의미를 가집니다. 여기 가장 흔한 것들이 있습니다:

- `\d`는 `0`부터 `9`까지 모든 10진수 숫자와 일치합니다.

- `\w`는 모든 단어 문자와 일치합니다: 문자, 숫자, 그리고 밑줄(`_`)입니다.

- `\s`는 공백 문자와 일치합니다. 예를 들어 공백, 탭, 또는 새 줄이 있습니다.

- `\D`, `\W`, 그리고 `\S`는 소문자 버전과 반대되는 것과 일치합니다. 예를 들어, `\D`는 숫자가 아닌 모든 문자와 일치합니다.

하지만 한 가지 주의할 점이 있습니다. Python 문자열도 역슬래시를 사용하여 `\n`(새 줄)이나 `\t`(탭) 같은 이스케이프 시퀀스를 작성합니다:

```python
print('Tab:\tdone') # Tab:    done
```

즉, 일반 Python 문자열 안의 역슬래시는 `re` 모듈이 보기 전에 Python이 먼저 해석할 수 있습니다. 뒤따르는 문자에 따라 패턴이 바뀌거나 Python이 경고를 표시할 수 있습니다.

이를 피하려면 raw 문자열을 사용할 수 있습니다. raw 문자열은 시작 따옴표 앞에 `r`(또는 `R`)를 붙여 만듭니다. raw 문자열은 역슬래시를 이스케이프 시퀀스가 아닌 문자 그대로 취급합니다:

```python
print(r'Tab:\tdone') # Tab:\tdone
```

이런 이유로 정규식 패턴은 항상 raw 문자열로 작성하는 것이 좋은 습관입니다:

```python
import re

room = 'Room 42B'
print(re.search(r'\d', room))
# <re.Match object; span=(5, 6), match='4'>
```

`re.search`가 찾은 첫 번째 일치를 반환한다는 점에 주목하세요. 여기서 `\d`는 한 자리 숫자와 일치하므로 일치는 `4`뿐입니다. 한 자리 이상과 일치시키려면 수량자를 사용해야 할 수 있습니다.

수량자는 앞선 문자나 수열이 몇 번 반복될 수 있는지 지정합니다. `+` 수량자는 앞선 문자가 한 번 이상 반복되는 것과 일치합니다.

그래서 `\d`가 한 자리 숫자와 일치하는 반면, `\d+`는 연속된 한 자리 이상의 숫자와 일치합니다:

```python
import re

room = 'Room 42B'
print(re.search(r'\d+', room))
# <re.Match object; span=(5, 7), match='42'>
```

다음은 다른 흔한 수량자들입니다:

- `*`는 앞선 문자가 0번 이상 반복되는 것과 일치합니다.

- `?`는 앞선 문자가 0번 또는 1번 나타나는 것과 일치하여 선택적입니다.

- `{n}`은 앞선 문자가 정확히 `n`번 반복되는 것과 일치합니다.

- `{n,m}`은 앞선 문자가 `n`번에서 `m`번 사이 반복되는 것과 일치합니다.

```python
import re

print(re.search(r'go*al', 'What a goooal!'))
# <re.Match object; span=(7, 13), match='goooal'>

print(re.search(r'colou?r', 'My favorite color is blue'))
# <re.Match object; span=(12, 17), match='color'>

print(re.search(r'\d{4}', 'Room 42, built in 1987'))
# <re.Match object; span=(18, 22), match='1987'>
```

문자 그대로 문자, 특수 수열, 수량자를 같은 패턴에 결합할 수 있습니다. 예를 들어, 패턴 `r'\d+ items'`는 한 자리 이상의 숫자 다음에 공백과 단어 `items`가 오는 것과 일치합니다. 또한 `re.IGNORECASE` 플래그와 결합하여 문자가 소문자 또는 대문자일 수 있게 할 수 있습니다:

```python
import re

cart = 'You have 3 ITEMS in your cart.'
print(re.search(r'\d+ items', cart, re.IGNORECASE))
# <re.Match object; span=(9, 16), match='3 ITEMS'>
```
