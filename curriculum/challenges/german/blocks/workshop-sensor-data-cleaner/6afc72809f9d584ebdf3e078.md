# --description--

Die Temperatur, die dem Durchschnitt entspricht, erhält die Bezeichnung `0.0 °C`, was nicht gut lesbar ist. Stattdessen sollte sie die Bezeichnung `average` erhalten.

Sie können bedingte Ausdrücke verketten, indem Sie nach `else` einen weiteren bedingten Ausdruck schreiben. Wenn die erste Bedingung falsch ist, wertet Python den nächsten bedingten Ausdruck aus:

```py
labels = [
    'large' if num > 100
    else 'medium' if num > 10
    else 'small'
    for num in numbers
]
```

Aktualisieren Sie Ihren bedingten Ausdruck so, dass er zu `f'+{difference} °C'` auswertet, wenn `difference` größer als `0` ist, zu `f'{difference} °C'`, wenn `difference` kleiner als `0` ist, und sonst zu dem String `average`.
