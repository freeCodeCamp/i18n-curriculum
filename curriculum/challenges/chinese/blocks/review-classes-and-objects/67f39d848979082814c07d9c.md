## Python 类和对象

- **类定义**：类是创建对象的蓝图。它通过属性和方法定义对象将具有的行为。以下是 Python 中类定义的基本示例：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **类名**：按照惯例，类名使用 PascalCase：每个单词首字母大写且不包含下划线，比如 `Dog` 或 `ShoppingCart`。

- **`__init__()` 方法**：每次你创建新对象时，Python 会自动调用 `__init__()`。它用于设置对象的初始属性。

- **`self` 参数**：`self` 指的是方法正在操作的具体对象。当你调用对象的方法时，Python 会自动传入它，所以调用时不需要写。`self` 是惯用名称，但它总是实例方法的第一个参数。

- **创建对象**：对象是类的实例。通过调用类并传入必要的参数来创建对象。

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **调用对象的方法**：你可以调用对象的方法来执行操作或获取信息。

```python
object_name1.method_name()
object_name2.method_name()
```

- **类和对象的区别**：类是可重用的模板，而对象是该类的具体实例，包含实际数据。

## 属性

- **实例属性**：通常在 `__init__()` 中使用 `self` 定义，并且每个对象都是唯一的。
- **类属性**：直接在类内部定义，所有实例共享。

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **动态处理属性**：有时属性名只有在运行时才知道，比如来自用户输入或循环时。这种情况下你不能写 `object.name`，所以你用接受名称字符串的函数：

  - `getattr(obj, name)` 返回属性的值。如果属性不存在，会引发 `AttributeError`，除非你传入第三个参数作为默认值。
  - `setattr(obj, name, value)` 创建或更新属性。
  - `hasattr(obj, name)` 如果属性存在返回 `True`，否则返回 `False`。
  - `delattr(obj, name)` 删除属性。

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **用 `dir()` 查看属性**：`dir()` 函数返回对象属性和方法名称的列表。结合 `callable()` 使用，可以区分方法和数据属性。

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## 方法

- **方法**：定义在类内部的函数，用于操作对象的属性。

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **访问方法**：使用点符号调用对象的方法。以下是对两个不同汽车对象调用 `describe` 方法的示例：

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## 双下划线（魔法）方法

- **定义**：以双下划线开头和结尾的特殊方法（例如 `__init__`、`__len__`、`__str__`、`__eq__`）。Python 内部使用它们来实现内置操作。

- **没有自定义特殊方法时的行为**：Python 不会推导内置操作如何使用自定义对象的属性。它会使用继承的默认行为（如果有），不支持的操作会引发 `TypeError`。

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **自定义方法改变的行为**：`__len__()` 让 `len()` 返回页数而不是报错。`__str__()` 用可读摘要替代默认表现。`__eq__()` 让 `==` 比较页数，而不是检查两个名字是否指向同一个对象。

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **间接调用双下划线方法**：你不需要直接调用双下划线方法。Python 会在特定操作发生时自动调用它们。这些操作包括：

  - **算术操作，如加法、减法、乘法、除法等**。加法调用 `__add__()`，减法调用 `__sub__()`，乘法调用 `__mul__()`，除法调用 `__truediv__()`。
        
  - **字符串操作，如串接、重复、格式化和转换为文本**。串接调用 `__add__()`，重复调用 `__mul__()`，格式化调用 `__format__()`，文本转换调用 `__str__()` 和 `__repr__()`，等等。
        
  - **比较操作，如相等、小于、大于等**。相等检查调用 `__eq__()`，小于调用 `__lt__()`，大于调用 `__gt__()`，等等。
        
  - **迭代操作，比如使对象可迭代并遍历各项**。调用 `__iter__()` 返回一个迭代器，调用 `__next__()` 获取下一项。

## 现实示例：购物车

- **带双下划线方法的购物车类**：允许添加、移除、迭代和检查内容，具有内置行为。

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## 对象协作

- **将对象作为参数传递**：对象可以像数字或字串一样传递给其他类的构造函数。

- **在属性中保存对象**：一个对象可以存储在另一个对象的属性中。然后你可以通过链式点符号调用该属性的方法，比如 `receiver.inbox.receive_email(email)`。

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## 处理日期和时间

- **获取当前日期和时间**：调用 `datetime.datetime.now()` 返回当前日期和时间的 `datetime` 对象。

- **在实例上保存时间戳**：在 `__init__()` 内调用 `datetime.datetime.now()` 并将结果赋值给属性，以记录对象创建时间。

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **用 `strftime()` 格式化**：`strftime()` 方法将 `datetime` 对象转换为字符串，使用格式代码：`%Y` 表示四位数年份，`%m` 表示月份，`%d` 表示日期，`%H` 表示小时（24 小时制），`%M` 表示分钟，`%S` 表示秒。其他字符如 `-`、`/`、`:` 或空格都作为字面分隔符保留。

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
