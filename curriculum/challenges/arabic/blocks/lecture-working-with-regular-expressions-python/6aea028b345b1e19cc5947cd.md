# --description--

التعبير النمطي، أو regex، هو نمط يُستخدم لمطابقة متتالية من الأحرف في النص.

لقد استخدمت بالفعل العامل `in` للتحقق مما إذا كانت السلسلة النصية تحتوي على جزء نصي محدد بالضبط. لكن هناك حالات لا تعرف فيها النص الدقيق الذي تبحث عنه، بل فقط شكله. على سبيل المثال، قد ترغب في التحقق من أن السلسلة تبدأ ببعض الحروف تليها أرقام، أو أن اسم المستخدم يتكون فقط من الأحرف المسموح بها.

تتيح لك التعبيرات النمطية وصف أنماط مثل هذه والتحقق مما إذا كانت السلسلة النصية تطابقها. تُستخدم عادةً للتحقق من صحة المُدخلات، والبحث في النصوص، واستخراج قطع من المعلومات من السلاسل النصية.

في Python، لاستخدام التعبيرات النمطية تحتاج إلى استيراد الوحدة `re`، التي هي جزء من مكتبة Python القياسية:

```python
import re
```

أبسط نمط تعبير نمطي هو النمط الحرفي: متتالية من الأحرف يجب أن تظهر تمامًا كما هي مكتوبة. على سبيل المثال، النمط `'cat'` يطابق الحروف `c` و `a` و `t`، واحدًا تلو الآخر.

للبحث عن نمط داخل سلسلة نصية، يمكنك استخدام الدالة `search` من الوحدة `re`. تأخذ النمط كمعلمتها الأولى والسلسلة النصية التي تبحث فيها كمعلمتها الثانية:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

عندما يجد `re.search` النمط في أي مكان داخل السلسلة، يرجع كائن مطابقة. يخبرك كائن المطابقة المطبوع بأمرين:

- `match='cat'` هو النص الذي طابق النمط.

- `span=(4, 7)` هو موقع المطابقة في السلسلة النصية. تبدأ المطابقة عند الفهرس `4` وتنتهي قبل الفهرس `7` مباشرة.

يمكنك أيضًا الحصول على هذه المعلومات من كائن المطابقة باستخدام طريقتيه `group` و `span`:

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

عندما لا يُعثر على النمط، يرجع `re.search` القيمة `None`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

افتراضيًا، تكون مطابقة التعبيرات النمطية حساسة لحالة الأحرف. هذا يعني أن النمط `'Cat'` لا يطابق النص `cat`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

لتغيير كيفية مطابقة النمط، يمكنك تمرير علم كمعلمة ثالثة إلى `re.search`. يجعل العلم `re.IGNORECASE` البحث غير حساس لحالة الأحرف، فيُعامل الحروف الكبيرة والصغيرة على أنها متساوية:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
