# --description--

Si la versión instalada no es la más reciente, tu función debe indicar qué tipo de actualización está disponible. Cuando los números principales son diferentes, es una actualización mayor. Eso significa que la versión más nueva contiene cambios importantes que podrían no funcionar con la versión anterior.

Puedes acceder al número principal de una versión con el índice `0`. Agrega una sentencia `if` que verifique si el número principal de `installed` es menor que el número principal de `latest`. Si es así, crea una variable llamada `update_type` y asígnale la cadena `major update`.
