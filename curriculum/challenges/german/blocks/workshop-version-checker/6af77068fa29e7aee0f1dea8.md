# --description--

Wenn die Major- und Minor-Nummern gleich sind, kann nur die Patch-Nummer unterschiedlich sein. Das bedeutet, dass die neuere Version nur kleine Korrekturen enthält, wie Bugfixes, und keine neuen Funktionen.

Fügen Sie eine `else`-Klausel hinzu, die den String `patch update` der Variable `update_type` zuweist.
