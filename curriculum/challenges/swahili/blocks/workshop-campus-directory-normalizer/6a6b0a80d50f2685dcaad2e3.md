# --description--

Katika warsha hii, utafanya kazi na saraka ya chuo mahiri na kuunda jedwali za kutafuta kutoka kwa data zilizopangwa ndani.
Utaitumia jedwali hizi za kutafuta kufanya utafutaji wa haraka na wenye ufanisi. `rawData` imetolewa kwako.

Chukua muda kuangalia muundo wake: kila ufunguo ni jina la idara, na thamani yake ina `Dept_code` pamoja na
safu ya data ya `programs`. Kila programu kisha ina safu yake ya `instructors`.

Kuanza, andika `rawData` kwenye konsoli ili uangalie muundo huu uliopangwa ndani kabla ya kuufanyia kazi.

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, "log");
const getLogs = () => globalThis.spy.calls.map(call => call?.[0]);
```

# --after-each--

```js
globalThis.spy.restore();
delete globalThis.spy;
```
