# --description--

正则表达式，或称 regex，是用于匹配文本中字符序列的模式。

你已经使用过 `in` 操作符来查看字符串是否包含某个精确的子串。但有些情况下你不知道确切的文本，只知道它的形式。例如，你可能想检查一个字符串是否以一些字母开头，后面跟着一些数字，或者用户名是否只由允许的字符组成。

正则表达式让你能够描述这样的模式，并检查字符串是否匹配它们。它们常用于验证输入、在文本中查找以及从字串中提取信息。

在 Python 中，要使用正则表达式，你需要导入 `re` 模块，它是标准函数库的一部分：

```python
import re
```

最简单的正则表达式模式是字面模式：一串必须完全按写法出现的字符。例如，模式 `'cat'` 匹配依次出现的字符 `c`、`a` 和 `t`。

要在字符串中查找模式，你可以使用 `re` 模块的 `search` 函数。它的第一个参数是模式，第二个参数是要查找的字符串：

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

当 `re.search` 在字符串中找到模式时，它返回一个匹配对象。打印的匹配对象告诉你两件事：

- `match='cat'` 是匹配到的文本。

- `span=(4, 7)` 是匹配在字符串中的位置。匹配从索引 `4` 开始，到索引 `7` 之前结束。

你也可以通过匹配对象的 `group` 和 `span` 方法获取这些信息：

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

当未找到模式时，`re.search` 返回 `None`：

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

默认情况下，正则表达式匹配是区分大小写的。这意味着模式 `'Cat'` 不匹配文本 `cat`：

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

要改变匹配方式，你可以将标记作为第三个参数传给 `re.search`。`re.IGNORECASE` 标记使搜索不区分大小写，因此大写和小写字母被视为相同：

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
