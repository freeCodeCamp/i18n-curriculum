# --description--

## なぜPythonをローカルにインストールするのか？

すべてのワークショップとラボでは、freeCodeCampのPythonエディターを使用します。しかし、ローカルマシンにPythonをセットアップする方法を学ぶことも重要です。

## Pythonのダウンロード

WindowsとMacにPythonをインストールする最も簡単な方法は、公式Pythonウェブサイトからインストーラーをダウンロードすることです。このレッスンの後半ではLinuxでPythonを実行する方法も説明します。

`https://www.python.org/`にアクセスして「Downloads」にカーソルを合わせてください。モーダルが表示され、あなたのOSに対応した現在のPythonバージョンが表示されます。

## macOSでのPythonのインストール

まずmacOSでPythonをインストールする方法を説明します：

- Pythonの現在のバージョンを示すボタン（前のモーダルから）をクリックすると、`.pkg`インストールファイルのダウンロードが自動的に始まります。
- `.pkg`インストーラーのダウンロードが完了したら開き、表示されるウィンドウで「続ける」をクリックしてください。
- 「続ける」ボタンをクリックし続けて「インストールの種類」セクションまで進み、そこで「インストール」ボタンをクリックします。
- 必要に応じてパスワードを入力し、インストールを開始してください。
- パッケージのインストールが完了すると、Pythonが正常にインストールされたというメッセージが表示されます。
- アプリケーションディレクトリに新しく作成されたPythonフォルダーを開いてください。
- `Install Certificates.command`ファイルをダブルクリックし、ターミナルの処理が完了するまで待ちます。
- ターミナルウィンドウに`Successfully installed certifi`と`update complete`が表示されていることを確認してください。
- ターミナルウィンドウを閉じ、インストーラーウィンドウで「閉じる」をクリックしてください。これでセットアップは完了です！

## インストールの確認

インストールを確認するには、ターミナルを開いて`python --version`または`python3 --version`を実行してください。

ターミナルで`python`または`python3`を実行してPythonインタープリターを開くこともできます。PythonインタープリターはPythonコードを読み取り、コンピューターが理解できる命令に変換し、その命令を実行するプログラムです。

## ターミナルとは何ですか？

<dfn>ターミナル</dfn>は、コマンドを入力してコンピューターとやり取りできるテキストベースのインターフェースです。各OSにはデフォルトのターミナルアプリがあります。macOSではTerminalアプリ、WindowsではCommand PromptやPowerShell、LinuxではGNOME TerminalやKonsoleなどのデスクトップ環境ごとのデフォルトターミナルがあります。

## `python` と `python3` の使い分け

古いmacOSやLinuxシステムでは、`python`がPython 2用に予約されていて、`python3`がPython 3専用の場合があります。`python --version`を実行して`Python 2.7.18`のようなPython 2のバージョンが表示されたら、OSが古いPythonで書かれたソフトウェアに依存している可能性があります。その場合は、今後Pythonコードを実行する際に`python3`を使うべきです。Python 2はサポート終了しており、新しい開発には使用しないでください。

## WindowsでのPythonのインストール

WindowsにPythonをインストールするには、以下の手順に従ってください：

- `https://www.python.org/`にアクセスし、「Downloads」にカーソルを合わせてください。「Download for Windows」と表示されたモーダルと、現在のPythonバージョンのダウンロードボタンが表示されます。
- バージョン番号をクリックすると、Pythonインストールマネージャー（`.msix`パッケージ）のダウンロードが自動的に始まります。
- Pythonインストールマネージャーのダウンロードが完了したら、それをダブルクリックして「インストール」を選択してください。
- インストール後、`python`、`py`、`pymanager`コマンドが利用可能になります。Pythonランタイムがインストールされていない場合、`python`を実行すると自動的にインストールされます。
- ランタイムを初めてインストールするときに、`PATH`に追加のエイリアス（例：`python3.14.exe`）用のディレクトリを追加するかどうかのオプションが表示されます。これらのエイリアスを使いたい場合は、このオプションを受け入れてください。


インストールを確認するには、PowerShellなどのコマンドラインシェルを開いて`python --version`を実行してください。Pythonインタープリターは`python`を実行して開けます。

## LinuxでのPythonのインストール

Linuxの主要なディストリビューション（Ubuntu、Debian、Fedoraなど）にはほとんどPythonがプリインストールされています。

ターミナルを開いて`python --version`または`python3 --version`を実行してください。

どちらのコマンドもPython 3のバージョンを表示しない場合は、`https://www.python.org`でLinuxディストリビューション用のインストールパッケージを探すか、オンラインで推奨されるPythonのインストール方法を検索してください。
