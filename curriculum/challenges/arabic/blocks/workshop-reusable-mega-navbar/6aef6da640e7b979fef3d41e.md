# --description--

لفتح وإغلاق الـ `sub-menu`، يحتاج مكوِّن `Navbar` إلى تذكر ما إذا كان الـ `sub-menu` مفتوحًا حاليًا. البيانات التي يتذكرها المكوِّن، والتي يمكن أن تتغير مع الوقت، تُسمى الحالة. كلما تغيرت الحالة، يُعيد React عرض المكوِّن ليُظهر الصفحة القيمة الجديدة.

ستتعلم المزيد عن الحالة في الدروس القادمة. الآن، يكفي أن تعرف أنه يمكنك إضافة حالة إلى مكوِّن دالي باستخدام الخطاف `useState`. الخطافات هي دوال خاصة تتيح لك استخدام ميزات React في مكوِّناتك. وبما أن React محمّل عبر عنصر `script` في هذه الورشة، يمكنك الوصول إلى الخطاف كـ `React.useState`:

```jsx
const [count, setCount] = React.useState(0);
```

تأخذ `React.useState` القيمة الابتدائية للحالة كمعلمتها وتُرجع مصفوفة تحتوي على عنصرين، يتم تفكيكهما هنا باستخدام التفكيك في المصفوفة:

- `count` هو متغير الحالة، الذي يحمل القيمة الحالية.
- `setCount` هو دالة التعيين، التي تستدعيها لتحديث الحالة.

داخل مكوِّن `Navbar`، استخدم `React.useState` لإنشاء متغير حالة اسمه `isOpen` ودالة تعيين اسمها `setIsOpen`. بما أن الـ `sub-menu` يجب أن يبدأ مغلقًا، أعطه القيمة الابتدائية `false`.
