# --description--

قبل العمل مع متغيرات Python، من المهم فهم أنواع البيانات. يصف نوع البيانات نوع القيمة التي يحملها المتغير، مثل رقم أو قطعة من النص. تستخدم لغات البرمجة أنواع البيانات لتعرف كيف تخزن وتتعامل مع أنواع مختلفة من المعلومات.

Python لغة ذات نوع ديناميكي. هذا يعني أنك لا تحدد نوع بيانات المتغير عند إنشائه. تحدد Python النوع بناءً على القيمة المُعيَّنة للمتغير.

إليك بعض الأمثلة:

```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```

يمكن تعيين قيمة من نوع مختلف للمتغير لاحقًا:

```python
age = 25
age = 'Twenty-five'
```

بعد التعيين الثاني، يحتوي `age` على سلسلة نصية بدلاً من عدد صحيح.

ركز الآن على أربعة أنواع بيانات ستستخدمها طوال هذه الوحدة:

- Integer: عدد صحيح بدون كسور عشرية، مثل `10` أو `-5`.

```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- Float: عدد يحتوي على فاصلة عشرية، مثل `4.41` أو `-0.4`.

```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- String: متتالية من الأحرف محاطة بعلامات اقتباس مفردة أو مزدوجة مثل `'Hello world!'`.

```python
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- Boolean: نوع بقيمة منطقية صحيحة أو خاطئة، مكتوبة كـ `True` أو `False`.

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

لدى Python أنواع بيانات أخرى. ستتعلم كل نوع منها عند حاجتك إليه لأول مرة.
