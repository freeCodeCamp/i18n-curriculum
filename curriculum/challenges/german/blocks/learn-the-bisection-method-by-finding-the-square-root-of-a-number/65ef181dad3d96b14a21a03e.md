# --description--

Die Bisektionsmethode, auch bekannt als binäre Suchmethode, verwendet eine binäre Suche, um die Nullstellen einer reellwertigen Funktion zu finden. Sie funktioniert, indem sie ein Intervall eingrenzt, in dem eine Nullstelle liegt, bis sie auf einen Wert innerhalb einer vorgegebenen Toleranz konvergiert.

In diesem Projekt verwenden Sie die Methode der Bisektion, um die ungefähre Quadratwurzel einer Zahl zu finden.

Beginnen Sie damit, eine Funktion namens `square_root_bisection` zu erstellen. Lassen Sie die Parameter vorerst leer.
