# --description--

트리가 준비되면, 모든 노드를 한 번씩 방문하는 순회가 가능합니다.

중위 순회는 깊이 우선 순회로, 한 가지 가지를 가능한 깊게 탐색한 후 다음 가지로 이동합니다. 각 노드에 대해 다음을 방문합니다:

1. 왼쪽 부분 트리.
1. 노드 자체.
1. 오른쪽 부분 트리.

`BinarySearchTree` 클래스 안에 `_inorder_traversal`이라는 이름의 메서드를 만들고, 세 개의 매개변수 `self`, `node`, `result`를 받으세요. `node`는 방문 중인 노드이고, `result`는 키를 모을 리스트입니다.

class TreeNode:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None


class BinarySearchTree:
    def __init__(self):
        self.root = None

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node

    def insert(self, key):
        self.root = self._insert(self.root, key)
