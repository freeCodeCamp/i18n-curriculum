# --description--

재귀 호출은 트리를 한 단계씩 내려가지만, 멈출 지점이 필요합니다. 두 가지 경우가 있습니다:

- `node.key`가 `key`와 같으면: 찾고자 하는 값을 가진 노드를 찾은 것입니다.
- `node`가 `None`이면: 탐색이 리프 노드를 지나쳤으므로 값이 트리에 없습니다.

`_search` 메서드 시작 부분에서 기존 `if` 문 전에 `node`가 `None`인지 또는 `node.key`가 `key`와 같은지 확인하는 `if` 문을 추가하고, 그 안에서 `node`를 반환하세요. 이렇게 하면 메서드는 값을 포함하는 노드를 반환하거나, 값이 트리에 없으면 `None`을 반환합니다.
