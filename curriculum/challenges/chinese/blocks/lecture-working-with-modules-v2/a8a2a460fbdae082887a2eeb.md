# --description--

在软件开发中，库就像开发者的工具箱。

库为你提供了预先编写且可重用的代码，如函数、类和数据结构，供你在项目中使用，而无需从头实现代码的每一个部分。

Python 标准函数库是随 Python 一起包含的模块和包的集合。第三方包是单独开发的，通常需要先安装才能使用。标准函数库为常见的编程任务提供了解决方案，例如：

* 与操作系统交互。

* 处理文件。

* 网络。

* 处理日期和时间。

* 执行数学操作。

* 使用正则表达式。

* 测试和调试你的代码。

* 还有更多！

一些标准函数库模块的例子有 `math`、`random`、`re`（“正则表达式”的缩写）和 `datetime`。

`math` 模块有用于执行更复杂数学操作的帮助函数。

`random` 模块对于生成随机数很有帮助。

`re` 模块用于处理正则表达式。

`datetime` 模块有助于在 Python 中处理日期和时间。

模块不仅可以提供函数和常量，还可以提供类。这里是 `datetime` 模块中一个类的示例。我们创建一个表示 1959 年 7 月 15 日的日期对象。然后，将该 `date` 对象赋值给一个变量，并使用点符号分别访问日、月和年：

```python
import datetime
birthday = datetime.date(1959, 7, 15)
print(birthday.day)    # 15
print(birthday.month)  # 7
print(birthday.year)   # 1959
```

要查找特定任务的模块，请浏览 [Python 标准函数库参考](https://docs.python.org/3/library/index.html)，模块按主题分组。每个模块的文档都会说明它提供了什么以及如何使用。例如，[`datetime` 文档](https://docs.python.org/3/library/datetime.html)描述了用于处理日期和时间的类和方法。

你也可以使用 `help()` 函数来显示模块或函数的文档。注意，`help()` 目前在 freeCodeCamp 编辑器中不可用。

例如，这段代码显示了关于 `math` 模块的信息：

```py
import math
help(math)
```

以下是输出的摘录：

```md

    math

DESCRIPTION
    This module provides access to the mathematical functions
    defined by the C standard.

FUNCTIONS
    acos(x, /)
        Return the arc cosine (measured in radians) of x.

...
...
...
```

你也可以获取特定函数的文档：

```py
import math
help(math.comb)
```

这是输出：

```md
Help on built-in function comb in module math:

comb(n, k, /)
    Number of ways to choose k items from n items without repetition and without order.
    
    Evaluates to n! / (k! * (n - k)!) when k <= n and evaluates
    to zero when k > n.
    
    Also called the binomial coefficient because it is equivalent
    to the coefficient of k-th term in polynomial expansion of the
    expression (1 + x)**n.
    
    Raises TypeError if either of the arguments are not integers.
    Raises ValueError if either of the arguments are negative.
```

要发现模块提供了哪些名称，可以使用 `dir()` 函数。它列出函数，比如用于向下取整的 `math.floor`，以及常量，比如欧拉数 `math.e` 和圆周率 `math.pi`。它还列出一些你将在课程后面学习的其他名称：

