# --description--

A última coisa a fazer é atualizar o estado `isOpen` quando o botão `Apps` for clicado.

No React, você responde a eventos passando uma função para um atributo de evento em um elemento. Esses atributos são escritos em camelcase, então um clique é tratado com `onClick`:

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

Perceba que `onClick` recebe uma função. O React chama essa função toda vez que o botão é clicado. Chamar a função setter com um novo valor atualiza o estado, e o React então re-renderiza o componente com esse novo valor.

Para alternar um estado booleano entre `true` e `false`, você pode passar o valor oposto do atual para a função setter usando o operador lógico NOT (`!`).

Adicione um atributo `onClick` ao elemento `button`. Dê a ele uma arrow function que chama `setIsOpen` com o valor oposto de `isOpen`.

Clique no botão `Apps` para abrir e fechar o `sub-menu`.

Com isso, seu componente `Navbar` está completo!

# --hints--

Clicar no botão `Apps` deve definir seu atributo `aria-expanded` para `"true"` e adicionar a classe `sub-menu--open` ao `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

Clicar no botão `Apps` pela segunda vez deve definir seu atributo `aria-expanded` de volta para `"false"` e remover a classe `sub-menu--open` do `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
