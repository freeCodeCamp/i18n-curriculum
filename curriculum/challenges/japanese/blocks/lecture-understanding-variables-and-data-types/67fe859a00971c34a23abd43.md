# --description--

Pythonの変数を扱う前に、データ型を理解することが重要です。データ型は変数が保持する値の種類を表し、例えば数値や文字列などがあります。プログラミング言語はデータ型を使って、さまざまな種類の情報をどのように保存し操作するかを判断します。

Pythonは動的型付け言語です。これは変数を作成するときにデータ型を指定しないことを意味します。Pythonは変数に代入された値から型を判断します。

いくつか例を示します：

```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```

変数には後から異なる型の値を代入することができます。

```python
age = 25
age = 'Twenty-five'
```

2回目の代入の後、`age`には整数ではなく文字列が代入されています。

ここでは、このモジュールを通して使う4つのデータ型にフォーカスしてください。

- 整数：小数点のない整数、例えば`10`や`-5`。

```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- 浮動小数点数：小数点を含む数値、例えば`4.41`や`-0.4`。

```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- 文字列：シングルクォーテーションまたはダブルクォーテーションで囲まれた文字のシーケンス、例えば`'Hello world!'`。

```python
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- ブール値：真または偽の型で、`True`や`False`と書きます。

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Pythonには他にもデータ型があります。必要になったときにそれぞれ学びます。
