# --description--

Як ви дізналися в попередньому уроці, модуль — це Python-файл, який групує пов’язаний код, щоб ви могли повторно його використовувати в інших Python-файлах.

Ви також можете писати власні модулі та імпортувати їх у свої скрипти. Створення власних модулів — це чудовий спосіб організувати свій код. Замість того, щоб мати один дуже довгий файл, ви можете розбити свій код на менші файли, де кожен групує пов’язаний код, а потім імпортувати їх туди, де вони потрібні.

Наприклад, припустімо, ви створили файл `temperature.py` з двома функціями для конвертації температур і викликом функції, щоб перевірити, що одна з них працює:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

Якщо ви запустите цей файл безпосередньо, отримаєте такий вихід:

```md
212.0
```

Тепер припустімо, ви створюєте інший файл під назвою `main.py` у тій самій папці, що й `temperature.py`. Щоб використовувати функції з вашого локального модуля, імпортуйте його, використовуючи ім’я модуля без розширення `.py`:

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

Якщо ви запустите файл `main.py`, отримаєте такий вихід:

```md
212.0
100.0
```

Коли імпортується `temperature`, Python виконує весь код у `temperature.py` зверху до низу. Саме тому виводиться `212.0`, хоча `main.py` викликає лише `fahrenheit_to_celsius()`. Код такого типу перевірки зазвичай хочеться запускати лише тоді, коли ви виконуєте файл безпосередньо, а не щоразу при імпорті.

Щоб контролювати це, ви можете використати загальний Python-ідiом:

```python
if __name__ == '__main__':
    # Code
```

`__name__` — це спеціальна вбудована змінна в Python.

Коли Python-файл виконується безпосередньо, Python призначає значення цієї змінної рядку `__main__`.

Але якщо Python-файл імпортується як модуль у інший Python-скрипт, значення змінної `__name__` встановлюється як назва цього модуля (зазвичай ім’я файлу без розширення `.py`).

Ось чому ви часто знайдете цю умову в Python-скриптах. Вона містить код, який ви хочете виконати **тільки якщо** Python-скрипт запускається як головна програма. Якщо скрипт імпортується як модуль, код у цьому блоці не виконується.

Це зручно, бо дозволяє Python-скриптам мати дві цілі. Вони можуть запускатися безпосередньо для виконання основної логіки або імпортуватися в інший модуль без виконання основної логіки.

Ось оновлений файл `temperature.py`, який використовує цей ідіом. Він також виводить значення `__name__`, щоб ви могли побачити, як воно змінюється:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

Якщо ви запустите цей файл безпосередньо, Python призначить `__name__` значення `'__main__'`, тому умова буде `True`, і код всередині блоку `if` виконається. Ось вихід:

```md
The value of __name__ is: __main__
212.0
```

Якщо ж ви запустите файл `main.py`, отримаєте такий вихід:

```md
The value of __name__ is: temperature
100.0
```

Виклик `print()` поза блоком `if` все одно виконується, коли імпортується `temperature`, і показує, що значення `__name__` тепер `temperature`, ім’я модуля.

Але оскільки `__name__` не дорівнює `'__main__'`, код всередині блоку `if` не виконується, тому `212.0` не виводиться. Єдиний інший вихід — це `100.0`, який походить із виклику функції в `main.py`.
