## HTML, CSS, 그리고 JavaScript 다루기

HTML과 CSS가 웹사이트의 구조를 제공하는 반면, JavaScript는 사용자 입력 처리, 요소 애니메이션, 심지어 완전한 웹 애플리케이션 구축과 같은 복잡한 기능을 가능하게 하여 웹사이트에 상호작용을 더합니다.

## JavaScript의 데이터 타입

데이터 타입은 프로그램이 숫자인지, 텍스트인지, 또는 다른 종류의 데이터인지 이해하는 데 도움을 줍니다.

- **Number**: 숫자는 정수와 부동소수점 값을 모두 나타냅니다. 정수 예시로는 7, 19, 90이 있습니다.
- **부동소수점**: 부동소수점 숫자는 소수점이 있는 숫자입니다. 예시로 3.14, 0.5, 0.0001이 있습니다.
- **문자열**: 문자열은 따옴표로 감싼 문자들의 수열 또는 텍스트입니다. `"I like coding"`와 `'JavaScript is fun'`는 문자열 예시입니다.
- **불리언**: 불리언은 두 가지 가능한 값 중 하나를 나타냅니다: `true` 또는 `false`. 불리언은 `isLoggedIn = true`와 같은 조건을 나타내는 데 사용할 수 있습니다.
- **Undefined와 Null**: `undefined` 값은 선언은 되었지만 값이 할당되지 않은 변수입니다. `null` 값은 빈 값이거나, 의도적으로 `null` 값을 할당한 변수입니다.
- **객체**: 객체는 키-값 쌍들의 모음입니다. 키는 속성 이름이고, 값은 속성 값입니다.

예를 들어, `{ name: "Fluffy", age: 3, type: "dog" }`는 세 개의 속성인 `name`, `age`, `type`을 가지고 있습니다.

- **Symbol**: Symbol 데이터 타입은 객체 속성의 식별자로 사용할 수 있는 고유하고 불변의 값입니다.

같은 설명으로 생성된 두 개의 심볼은 여전히 서로 다른 값입니다.

- **BigInt**: 숫자가 `Number` 데이터 타입으로 표현하기에 너무 클 때, 임의 길이의 정수를 나타내기 위해 BigInt 데이터 타입을 사용할 수 있습니다.

숫자 끝에 `n`를 추가하면 BigInt를 만들 수 있습니다.

## JavaScript의 변수

- 변수는 `let` 키워드를 사용해 선언할 수 있습니다.

- 변수에 값을 할당하려면 대입 연산자 `=`를 사용할 수 있습니다.

- `let`로 선언된 변수는 새 값을 다시 할당할 수 있습니다.

- `let` 외에도 `const`를 사용해 변수를 선언할 수 있습니다. 하지만 `const` 변수는 새 값을 다시 할당할 수 없습니다.

- `const`로 선언된 변수는 코드 전체에서 변경이 허용되지 않는 상수를 선언할 때 사용됩니다. 예를 들어 `PI`나 `MAX_SIZE` 같은 경우입니다.

## 변수 이름 관례

- 변수 이름은 설명적이고 의미 있어야 합니다.
- 변수 이름은 `cityName`, `isLoggedIn`, `veryBigNumber`처럼 카멜 케이스여야 합니다.
- 변수 이름은 숫자로 시작하면 안 됩니다. 반드시 문자, `_`, 또는 `$`로 시작해야 합니다.
- 변수 이름에는 공백이나 특수 문자가 포함되면 안 되며, `_`과 `$`는 예외입니다.
- 변수 이름은 예약된 키워드를 사용할 수 없습니다.
- 변수 이름은 대소문자를 구분합니다. `age`와 `Age`는 서로 다른 변수입니다.

## JavaScript에서 문자열과 문자열 불변성

- 문자열은 따옴표로 감싼 문자 수열입니다. 작은따옴표와 큰따옴표를 사용해 만들 수 있습니다.

- JavaScript에서 문자열은 불변입니다. 즉, 문자열이 한 번 생성되면 그 안의 문자를 변경할 수 없습니다. 하지만 문자열에 새 값을 다시 할당할 수는 있습니다.

## JavaScript에서 문자열 연결

- 연결은 여러 문자열을 합치거나 텍스트를 담고 있는 변수와 문자열을 결합하는 과정입니다. `+` 연산자는 문자열을 연결하는 가장 간단하고 자주 쓰이는 방법 중 하나입니다.

- 기존 문자열에 추가하거나 덧붙여야 할 때는 `+=` 연산자를 사용할 수 있습니다. 시간이 지나면서 문자열에 더 많은 텍스트를 덧붙여 나갈 때 유용합니다.

- 문자열을 연결하는 또 다른 방법은 `concat()` 메서드를 사용하는 것입니다. 이 메서드는 두 개 이상의 문자열을 함께 합칩니다.

## `console.log()`로 메시지 기록하기

- `console.log()` 메서드는 메시지를 콘솔에 기록하는 데 사용됩니다. 코드를 디버깅하고 테스트할 때 유용한 도구입니다.

## JavaScript에서 세미콜론

- 세미콜론은 주로 문장의 끝을 표시하는 데 사용됩니다. 이는 JavaScript 엔진이 개별 명령어의 구분을 이해하는 데 도움을 주며, 올바른 실행에 매우 중요합니다.

- 세미콜론은 코드 실행에서 모호함을 방지하고 문장이 올바르게 종료되도록 보장합니다.

## JavaScript의 주석

- 주석 처리된 코드 줄은 JavaScript 엔진에서 무시됩니다. 주석은 코드를 설명하거나 메모를 남기거나 코드를 일시적으로 비활성화할 때 사용합니다.
- 한 줄 주석은 `//`를 사용해 만듭니다.

- 여러 줄 주석은 `/*`로 시작하고 `*/`로 끝냅니다.

## 동적 타입 언어로서의 JavaScript

- JavaScript는 동적 타입 언어로, 변수를 선언할 때 데이터 타입을 명시할 필요가 없습니다. JavaScript 엔진이 변수에 할당된 값을 바탕으로 데이터 타입을 자동으로 결정합니다.

- C#과 같은 정적 타입 언어에서는 문자열을 정수 변수에 할당하면 오류가 발생합니다.

## `typeof` 연산자 사용하기

- `typeof` 연산자는 변수의 데이터 유형을 확인하는 데 사용합니다. 변수의 유형을 나타내는 문자열을 반환합니다.

- 하지만 JavaScript에서 `null`에 관해 잘 알려진 특이점이 있습니다. `typeof` 연산자는 `null` 값에 대해 `"object"`를 반환합니다.

## 문자열 기본

- **정의**: 문자열은 작은따옴표, 큰따옴표 또는 백틱으로 감싼 문자 수열입니다. 문자열은 원시 데이터 유형이며 변경할 수 없습니다. 변경 불가능하다는 것은 문자열이 한 번 생성되면 변경할 수 없다는 뜻입니다.  
- **문자열에서 문자 접근하기**: 문자열에서 문자를 접근하려면 대괄호 표기법을 사용하고 인덱스 번호를 전달하세요. 인덱스는 문자열 내 문자의 위치이며 0부터 시작합니다.

- **`\n` (줄바꿈 문자)**: 문자열에서 줄바꿈을 만들려면 `\n` 줄바꿈 문자를 사용하세요.

- **문자열 이스케이프**: 문자열에서 따옴표 앞에 역슬래시(`\`)를 넣어 문자를 이스케이프할 수 있습니다.

:::interactive_editor

```js
const statement = "She said, \"Hello!\"";
console.log(statement); // She said, "Hello!"
```

:::

## 템플릿 리터럴(템플릿 문자열)과 문자열 보간

- **정의**: 템플릿 리터럴은 백틱(`)으로 정의합니다. 문자열 안에 변수를 직접 임베드하는 문자열 보간이라는 기능을 포함해 문자열 조작을 더 쉽게 할 수 있습니다.

:::interactive_editor

```js
const name = "Jessica";
const greeting = `Hello, ${name}!`; 
console.log(greeting); // "Hello, Jessica!"
```

## ASCII, `charCodeAt()` 메서드와 `fromCharCode()` 메서드

- **ASCII**: ASCII(미국 표준 정보 교환 코드)는 기본 영어 문자를 숫자 값으로 나타내는 문자 인코딩 표준입니다. 이전 수업에서는 ASCII 예제를 사용해 `charCodeAt()`와 `fromCharCode()`를 소개했습니다.
- **유니코드**: JavaScript 문자열은 내부적으로 유니코드, 특히 UTF-16 인코딩을 사용합니다. 처음 128자(기본 라틴 문자, 숫자, 일반 기호)는 유니코드 값이 ASCII 코드와 일치합니다. 그래서 ASCII 기반 예제가 JavaScript에서 계속 작동합니다.
- **`charCodeAt()` 메서드**: 이 메서드는 지정한 인덱스의 문자에 해당하는 UTF-16 코드 단위를 반환합니다. 기본 라틴 문자에 대해서는 이 값이 ASCII 코드와 일치합니다.

- **`fromCharCode()` 메서드**: 이 메서드는 ASCII 코드를 해당하는 문자로 변환합니다.

## 기타 자주 사용하는 문자열 메서드

- **`indexOf` 메서드**: 이 메서드는 문자열 내에서 부분 문자열을 검색하는 데 사용됩니다. 부분 문자열이 발견되면 `indexOf`는 해당 부분 문자열이 처음 나타나는 인덱스(또는 위치)를 반환합니다. 부분 문자열이 발견되지 않으면 `indexOf`는 -1을 반환하는데, 이는 검색이 실패했음을 나타냅니다.

- **`includes()` 메서드**: 이 메서드는 문자열에 특정 부분 문자열이 포함되어 있는지 확인하는 데 사용됩니다. 부분 문자열이 문자열 내에 있으면 메서드는 true를 반환합니다. 그렇지 않으면 false를 반환합니다.

- **`slice()` 메서드**: 이 메서드는 문자열의 일부를 추출해 새 문자열로 반환하며 원본 문자열은 변경하지 않습니다. 시작 인덱스와 선택적 종료 인덱스 두 매개변수를 받습니다.

- **`toUpperCase()` 메서드**: 이 메서드는 모든 문자를 대문자로 변환하여 대문자로만 이루어진 새 문자열을 반환합니다.

- **`toLowerCase()` 메서드**: 이 메서드는 문자열 내 모든 문자를 소문자로 변환합니다.

- **`replace()` 메서드**: 이 메서드는 문자열에서 지정한 값(단어나 문자 등)을 찾아 다른 값으로 교체할 수 있게 해줍니다. 이 메서드는 교체된 새 문자열을 반환하며, JavaScript 문자열은 불변이기 때문에 원본 문자열은 변경되지 않습니다.

- **`replaceAll()` 메서드**: 이 메서드는 문자열 내 지정한 값(단어, 문자, 패턴)의 모든 발생을 찾아 다른 값으로 교체합니다. `replace()`와 비슷하지만 첫 번째 일치 후 멈추지 않고 문자열 내 모든 일치를 업데이트합니다.

- **`repeat()` 메서드**: 이 메서드는 문자열을 지정한 횟수만큼 반복하는 데 사용됩니다.

- **`trim()` 메서드**: 이 메서드는 문자열의 시작과 끝 양쪽에서 공백을 제거하는 데 사용됩니다.

- **`trimStart()` 메서드**: 이 메서드는 문자열의 시작 부분(또는 "앞쪽")에서 공백을 제거합니다.

- **`trimEnd()` 메서드**: 이 메서드는 문자열의 끝 부분에서 공백을 제거합니다.

- **`prompt()` 메서드**: `window`의 이 메서드는 대화 상자 형태로 사용자에게 정보를 입력받는 데 사용됩니다. 이 메서드는 두 개의 인수를 받습니다. 첫 번째 인수는 대화 상자 안에 표시될 메시지로, 보통 사용자에게 정보를 입력하라는 안내 문구입니다. 두 번째 인수는 선택 사항인 기본값으로, 입력 필드를 처음에 채우는 데 사용됩니다.

## 숫자 데이터 타입 다루기

- **정의**: JavaScript의 `Number` 타입은 정수, 부동소수점 숫자, `Infinity` 및 `NaN`를 포함합니다. 부동소수점 숫자는 소수점이 있는 숫자입니다. 양의 `Infinity`은 다른 어떤 숫자보다 큰 숫자이며 `-Infinity`는 다른 어떤 숫자보다 작은 숫자입니다. `NaN` (`Not a Number`)는 문자열 `"Jessica"`처럼 유효하지 않은 숫자 값을 나타냅니다.

## 일반적인 산술 연산

- **덧셈 연산자**: 이 연산자(`+`)는 두 개 이상의 숫자의 합을 계산하는 데 사용됩니다.
- **뺄셈 연산자**: 이 연산자(`-`)는 두 숫자의 차이를 계산하는 데 사용됩니다.
- **곱셈 연산자**: 이 연산자(`*`)는 두 개 이상의 숫자의 곱을 계산하는 데 사용됩니다.
- **나눗셈 연산자**: 이 연산자(`/`)는 두 숫자의 몫을 계산하는 데 사용됩니다.
- **0으로 나누기**: 0으로 나누려고 하면 JavaScript는 `Infinity`를 반환합니다.
- **나머지 연산자**: 이 연산자(`%`)는 나눗셈의 나머지를 반환합니다.
- **거듭제곱 연산자**: 이 연산자(`**`)는 한 숫자를 다른 숫자의 거듭제곱으로 올립니다.

## 숫자와 문자열 계산

- **설명**: 숫자와 문자열에 `+` 연산자를 사용하면 JavaScript가 숫자를 문자열로 강제 변환하여 두 값을 연결합니다. 반면, 문자열과 숫자에 `-`, `*`, `/` 연산자를 사용하면 JavaScript가 문자열을 숫자로 강제 변환하여 결과가 숫자가 됩니다. `null`과 `undefined`의 경우, 수학 연산에서 JavaScript는 `null`을 0으로, `undefined`를 `NaN`으로 처리합니다.

## 연산자 우선순위

- **정의**: 연산자 우선순위는 표현식에서 연산이 평가되는 순서를 결정합니다. 우선순위가 높은 연산자가 낮은 연산자보다 먼저 평가됩니다. 괄호 안의 값이 먼저 평가되고 곱셈/나눗셈이 덧셈/뺄셈보다 우선순위가 높습니다. 연산자 우선순위가 같으면 JavaScript는 결합법칙을 사용합니다.

- **정의**: 결합성은 동일한 유형의 연산자가 여러 개 있을 때 표현식이 평가되는 방향을 알려줍니다. 표현식을 왼쪽에서 오른쪽(`left-associative`)으로 평가할지, 오른쪽에서 왼쪽(`right-associative`)으로 평가할지를 정의합니다. 예를 들어, 지수 연산자는 오른쪽에서 왼쪽으로 결합합니다.

## 증가 연산자와 감소 연산자

- **증가 연산자**: 이 연산자는 값을 1만큼 증가시키는 데 사용합니다. 접두사 표기법 `++num`은 변수의 값을 먼저 증가시키고, 그 다음 새로운 값을 반환합니다. 접미사 표기법 `num++`은 변수의 현재 값을 먼저 반환한 후, 값을 증가시킵니다.

- **감소 연산자**: 이 연산자는 값을 1만큼 감소시키는 데 사용합니다. 접두사 표기법과 접미사 표기법은 증가 연산자와 마찬가지로 작동합니다.

## 복합 대입 연산자

- **덧셈 복합 대입 (`+=`) 연산자**: 이 연산자는 값들을 더한 후 결과를 변수에 할당합니다.
- **뺄셈 복합 대입 (`-=`) 연산자**: 이 연산자는 값들을 빼고 결과를 변수에 할당합니다.
- **곱셈 복합 대입 (`*=`) 연산자**: 이 연산자는 값들을 곱한 후 결과를 변수에 할당합니다.
- **나눗셈 복합 대입 (`/=`) 연산자**: 이 연산자는 값들을 나누고 결과를 변수에 할당합니다.
- **나머지 복합 대입 (`%=`) 연산자**: 이 연산자는 변수를 지정한 수로 나눈 후 나머지를 변수에 할당합니다.
- **거듭제곱 복합 대입 (`**=`) 연산자**: 이 연산자는 변수를 지정한 수의 거듭제곱으로 올리고 결과를 변수에 다시 할당합니다.

## 불리언과 동등성

- **불리언 정의**: 불리언은 두 가지 값만 가질 수 있는 데이터 타입입니다: `true` 또는 `false`.
- **동등 연산자 (`==`)**: 이 연산자는 값을 비교하기 전에 타입 강제 변환을 수행합니다.

- **엄격 동등 연산자 (`===`)**: 이 연산자는 타입 강제 변환을 수행하지 않으며, 타입과 값이 모두 같은지 확인합니다.

- **부등 연산자 (`!=`)**: 이 연산자는 값을 비교하기 전에 타입 강제 변환을 수행합니다.
- **엄격 부등 연산자 (`!==`)**: 이 연산자는 타입 강제 변환을 수행하지 않고 타입과 값이 모두 다른지 확인합니다.

## 비교 연산자

- **크다 (`>`) 연산자**: 이 연산자는 왼쪽 값이 오른쪽 값보다 큰지 확인합니다.  
- **크거나 같다 (`>=`) 연산자**: 이 연산자는 왼쪽 값이 오른쪽 값보다 크거나 같은지 확인합니다.  
- **작다 (`<`) 연산자**: 이 연산자는 왼쪽 값이 오른쪽 값보다 작은지 확인합니다.  
- **작거나 같다 (`<=`) 연산자**: 이 연산자는 왼쪽 값이 오른쪽 값보다 작거나 같은지 확인합니다.

## 단항 연산자

- **단항 더하기 연산자**: 이 연산자는 피연산자를 숫자로 변환합니다. 피연산자가 이미 숫자라면 변경되지 않습니다.

- **단항 부정 (`-`) 연산자**: 이 연산자는 피연산자를 부정합니다.

- **논리 NOT (`!`) 연산자**: 이 연산자는 피연산자의 불리언 값을 반전시킵니다. 따라서 피연산자가 `true`이면 `false`가 되고, `false`이면 `true`가 됩니다.

## 비트 연산자

- **비트 AND (`&`) 연산자**: 이 연산자는 두 피연산자의 해당 비트가 모두 1인 각 비트 위치에 1을 반환합니다.  
- **비트 AND 할당 (`&=`) 연산자**: 이 연산자는 지정된 숫자와 `bitwise AND` 연산을 수행하고 결과를 변수에 다시 할당합니다.  
- **비트 OR (`|`) 연산자**: 이 연산자는 두 피연산자 중 하나 또는 둘 다의 해당 비트가 1인 각 비트 위치에 1을 반환합니다.  
- **비트 OR 할당 (`|=`) 연산자**: 이 연산자는 지정된 숫자와 `bitwise OR` 연산을 수행하고 결과를 변수에 다시 할당합니다.  
- **비트 XOR (`^`) 연산자**: 이 연산자는 두 피연산자 중 하나만 1인 각 비트 위치에 1을 반환합니다.  
- **비트 NOT (`~`) 연산자**: 이 연산자는 숫자의 이진 표현을 반전시킵니다.  
- **왼쪽 시프트 (`<<`) 연산자**: 이 연산자는 모든 비트를 지정된 수만큼 왼쪽으로 이동시킵니다.  
- **오른쪽 시프트 (`>>`) 연산자**: 이 연산자는 모든 비트를 오른쪽으로 이동시킵니다.

## 조건문, 참 같은 값, 거짓 같은 값 그리고 삼항 연산자

- **`if/else if/else`**: `if` 문은 조건을 받아 그 조건이 `truthy`일 때 코드 블록을 실행합니다. 조건이 `false`이면 `else if` 블록으로 넘어갑니다. 그 어떤 조건도 `true`가 아니면 `else` 절을 실행합니다. `Truthy` 값은 `if` 문과 같은 불리언 문맥에서 평가할 때 `true`가 되는 모든 값입니다. `Falsy` 값은 불리언 문맥에서 `false`로 평가되는 값입니다.

:::interactive_editor

```js
const score = 87;

if (score >= 90) {
 console.log('You got an A'); 
} else if (score >= 80) {
 console.log('You got a B'); // You got a B
} else if (score >= 70) {
 console.log('You got a C');
} else {
 console.log('You failed! You need to study more!');
}
```

:::

- **삼항 연산자**: 이 연산자는 `if else` 문을 더 짧게 작성할 때 자주 사용합니다.

:::interactive_editor

```js
const temperature = 30;
const weather = temperature > 25 ? 'sunny' : 'cool';

console.log(`It's a ${weather} day!`); // It's a sunny day!
```

:::

## 이항 논리 연산자

- **논리 AND (`&&`) 연산자**: 이 연산자는 두 피연산자가 모두 `true`인지 확인합니다. 둘 다 `true`면 두 번째 값을 반환합니다. 어느 하나가 `falsy`면 `falsy` 값을 반환합니다. 둘 다 `falsy`면 첫 번째 `falsy` 값을 반환합니다.

- **논리 OR (`||`) 연산자**: 이 연산자는 피연산자 중 적어도 하나가 참 같은 값인지 확인합니다.
- **널 병합 (`??`) 연산자**: 이 연산자는 첫 번째 값이 `null` 또는 `undefined`일 때만 값을 반환합니다.

## `Math` 객체

- **`Math.random()` 메서드**: 이 메서드는 0(포함)과 1(배타적) 사이의 임의의 부동 소수점 숫자를 생성합니다. 즉, 출력값으로 0이 나올 수 있지만 1에 도달하지는 않습니다.
- **`Math.max()` 메서드**: 이 메서드는 숫자 집합을 받아 최대값을 반환합니다.
- **`Math.min()` 메서드**: 이 메서드는 숫자 집합을 받아 최솟값을 반환합니다.
- **`Math.ceil()` 메서드**: 이 메서드는 값을 가장 가까운 정수로 올림합니다.
- **`Math.floor()` 메서드**: 이 메서드는 값을 가장 가까운 정수로 내림합니다.
- **`Math.round()` 메서드**: 이 메서드는 값을 가장 가까운 정수로 반올림합니다.

- **`Math.trunc()` 메서드**: 이 메서드는 숫자의 소수 부분을 제거하고 정수 부분만 반환하며 반올림하지 않습니다.
- **`Math.sqrt()` 메서드**: 이 메서드는 숫자의 제곱근을 반환합니다.
- **`Math.cbrt()` 메서드**: 이 메서드는 숫자의 세제곱근을 반환합니다.
- **`Math.abs()` 메서드**: 이 메서드는 숫자의 절댓값을 반환합니다.
- **`Math.pow()` 메서드**: 이 메서드는 두 숫자를 받아 첫 번째 숫자를 두 번째 숫자만큼 거듭제곱합니다.

## 자주 쓰이는 숫자 메서드

- **`isNaN()`**: `NaN`는 "숫자가 아님(Not-a-Number)"을 뜻합니다. 이는 표현할 수 없거나 정의되지 않은 숫자 결과를 나타내는 특별한 값입니다. `isNaN()` 함수 속성은 값이 `NaN`인지 아닌지 판단하는 데 사용됩니다. `Number.isNaN()`은 특히 타입 강제 변환으로 인해 전역 `isNaN()` 함수가 예상치 못한 결과를 낼 수 있는 경우에 `NaN` 값을 더 신뢰성 있게 확인하는 방법을 제공합니다.

- **`parseFloat()` 메서드**: 이 메서드는 문자열 인수를 파싱하여 부동소수점 숫자를 반환합니다. 문자열에 숫자가 아닌 문자가 뒤에 있어도 문자열 시작 부분에서 숫자를 추출하도록 설계되었습니다.
- **`parseInt()` 메서드**: 이 메서드는 문자열 인수를 파싱하여 정수를 반환합니다. `parseInt()`는 처음 만나는 숫자가 아닌 문자에서 파싱을 멈춥니다. 부동소수점 숫자의 경우 정수 부분만 반환합니다. 문자열 시작 부분에서 유효한 정수를 찾지 못하면 `NaN`을 반환합니다.
- **`toFixed()` 메서드**: 이 메서드는 숫자에서 호출되며, 소수점 아래 표시할 자릿수를 나타내는 선택적 인수를 하나 받습니다. 지정한 소수점 자릿수만큼 숫자를 문자열로 반환합니다.

## 비교와 `null` 및 `undefined` 데이터 타입

- **비교와 `undefined`**: 변수가 선언되었지만 값이 할당되지 않은 상태일 때 `undefined`입니다. 초기화되지 않은 변수와 인수가 제공되지 않은 함수 매개변수의 기본값입니다. `undefined`는 숫자 문맥에서 `NaN`으로 변환되어, `undefined`와의 모든 숫자 비교가 `false`를 반환하게 만듭니다.

- **`null`과 비교**: `null` 타입은 의도적으로 값이 없음을 나타냅니다. `null`은 숫자 문맥에서 `0`으로 변환되어 숫자 비교에서 예상치 못한 동작을 일으킬 수 있습니다. 예를 들어, `null >= 0`은 `true`이지만, `null > 0`은 `false`입니다.

- 동등 연산자(`==`)를 사용할 때, `null`과 `undefined`는 서로와 자기 자신에만 동등합니다.

- 그러나 엄격한 동등 연산자(`===`)를 사용할 때는, 타입 강제 변환 없이 값과 타입을 모두 비교하므로 `null`과 `undefined`는 같지 않습니다.

## `switch` 문

- **정의**: `switch` 문은 표현식을 평가하고 그 값을 일련의 `case` 절과 비교합니다. 일치하는 절이 발견되면 해당 케이스에 연결된 코드 블록이 실행됩니다. 각 케이스 끝에는 실행을 종료하고 다음으로 넘어가기 위해 `break` 문이 있어야 합니다. `default` 케이스는 선택적이며 다른 케이스가 모두 일치하지 않을 때만 실행됩니다. `default` 케이스는 `switch` 문 끝에 위치합니다.

:::interactive_editor

```js
const dayOfWeek = 3; 

switch (dayOfWeek) {
  case 1:
    console.log("It's Monday! Time to start the week strong.");
    break;
  case 2:
    console.log("It's Tuesday! Keep the momentum going.");
    break;
  case 3:
    console.log("It's Wednesday! We're halfway there.");
    break;
  case 4:
    console.log("It's Thursday! Almost the weekend.");
    break;
  case 5:
    console.log("It's Friday! The weekend is near.");
    break;
  case 6:
    console.log("It's Saturday! Enjoy your weekend.");
    break;
  case 7:
    console.log("It's Sunday! Rest and recharge.");
    break;
  default:
    console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

:::

## JavaScript 함수

- 함수는 특정 작업을 수행하는 재사용 가능한 코드 블록입니다.
- 함수는 `function` 키워드 다음에 이름, 매개변수 목록, 작업을 수행하는 코드 블록을 작성하여 정의할 수 있습니다.

:::interactive_editor

```js
function addNumbers(x, y, z) {
  return x + y + z;
}

console.log(addNumbers(5, 3, 8)); // Output: 16
```

:::

- 인수는 함수가 호출될 때 전달되는 값입니다.
- 함수 호출은 함수 이름 뒤에 소괄호를 붙여 프로그램에서 함수를 실행하는 과정이며, 소괄호 안에 인수를 포함할 수도 있습니다.
- 함수가 실행을 마치면 항상 값을 반환합니다.
- 기본적으로 함수의 반환값은 `undefined`입니다.
- `return` 키워드는 함수에서 반환할 값을 지정하고 함수 실행을 종료하는 데 사용됩니다.
- 기본 매개변수는 함수가 호출될 때 인수가 제공되지 않으면 미리 정해진 값을 사용하도록 하여, 함수를 더 유연하게 만들고 특정 인수가 생략될 때 발생할 수 있는 오류를 방지합니다.

:::interactive_editor

```js
const calculateTotal = (amount, taxRate = 0.05) => {
  return amount + (amount * taxRate);
};

console.log(calculateTotal(100)); // Output: 105
```

:::

- 익명 함수는 이름이 없는 함수로, 변수에 할당할 수 있습니다. 변수에 할당하면 해당 변수가 접근 가능한 어디서든 재사용할 수 있습니다.

:::interactive_editor

```js
const multiplyNumbers = function(firstNumber, secondNumber) {
  return firstNumber * secondNumber;
};

console.log(multiplyNumbers(4, 5)); // Output: 20
```

:::

## 화살표 함수

- 화살표 함수는 JavaScript에서 함수를 더 간결하게 작성하는 방법입니다.

- 화살표 함수를 정의할 때 `function` 키워드는 필요하지 않습니다.
- 매개변수가 하나일 경우 매개변수 목록을 감싸는 소괄호를 생략할 수 있습니다.

- 함수 본문이 단일 표현식으로 이루어졌다면 중괄호와 `return` 키워드를 생략할 수 있습니다.

:::interactive_editor

```js
const square = number => number * number;

console.log(square(5)); // Output: 25
```

:::

## 프로그래밍에서의 범위

- **전역 범위**: JavaScript에서 가장 바깥쪽 범위입니다. 전역 범위에서 선언된 변수는 코드 어디에서나 접근할 수 있으며 전역 변수라고 합니다.
- **지역 범위**: 함수 내에서 선언된 변수를 가리킵니다. 이 변수들은 선언된 함수 내에서만 접근할 수 있으며 지역 변수라고 합니다.
- **블록 범위**: 블록은 중괄호 `{}`로 감싼 일련의 문장 집합으로, `if` 문장이나 반복문에서 사용됩니다.
- `let`와 `const`를 사용한 블록 범위는 변수 접근을 더욱 세밀하게 제어할 수 있어, 오류를 방지하고 코드를 더 예측 가능하게 만듭니다.

## JavaScript 배열 기초

- **정의**: JavaScript 배열은 숫자 인덱스로 식별되는 값들의 순서 있는 모음입니다. JavaScript 배열의 값들은 숫자, 문자열, 불리언, 객체, 심지어 다른 배열 등 다양한 데이터 유형일 수 있습니다. 배열은 메모리에서 연속적으로 저장되므로 모든 요소가 하나의 연속된 메모리 블록에 저장되어 인덱싱이 효율적이고 인덱스를 통한 요소 접근이 빠릅니다.

- **배열에서 요소 접근하기**: 배열에서 요소에 접근하려면 배열 이름 뒤에 대괄호 안에 인덱스 번호를 적어 참조해야 합니다. JavaScript 배열은 0부터 시작하는 인덱스를 사용하므로 첫 번째 요소는 인덱스 0, 두 번째 요소는 인덱스 1에 있습니다. 존재하지 않는 인덱스에 접근하면 JavaScript는 `undefined`를 반환합니다.

- **`length` 속성**: 이 속성은 배열에 있는 항목의 개수를 반환하는 데 사용됩니다.

- **배열 요소 업데이트하기**: 배열의 요소를 업데이트하려면 대입 연산자(`=`)를 사용해 특정 인덱스의 요소에 새 값을 할당하세요.

## 2차원 배열

- **정의**: 2차원 배열은 본질적으로 배열의 배열입니다. 체스판, 스프레드시트, 이미지의 픽셀처럼 자연스러운 격자 구조를 가진 데이터를 나타내는 데 사용합니다. 2차원 배열의 요소에 접근하려면 행과 열을 나타내는 두 개의 인덱스가 필요합니다.

## 배열 구조 분해

- **정의**: 배열 구조 분해는 JavaScript의 기능으로, 배열에서 값을 추출해 더 간결하고 읽기 쉬운 방식으로 변수에 할당할 수 있게 합니다. 배열 요소를 개별 변수로 풀어내는 편리한 구문을 제공합니다.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange"];

const [first, second, third] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(third); // "orange"
```

:::

- **나머지 구문**: 구조 분해되지 않은 배열의 나머지 요소들을 새로운 배열로 캡처할 수 있게 합니다.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange", "mango", "kiwi"];
const [first, second, ...rest] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(rest); // ["orange", "mango", "kiwi"]
```

:::

## 자주 사용하는 배열 메서드

- **`push()` 메서드**: 이 메서드는 배열 끝에 요소를 추가하는 데 사용하며, 새 배열 길이를 반환합니다.

- **`pop()` 메서드**: 이 메서드는 배열에서 마지막 요소를 제거하고 제거된 요소를 반환합니다. 배열이 비어 있으면 반환값은 `undefined`입니다.

- **`shift()` 메서드**: 이 메서드는 배열에서 첫 번째 요소를 제거하고 제거된 요소를 반환합니다. 배열이 비어 있으면 반환값은 `undefined`입니다.

- **`unshift()` 메서드**: 이 메서드는 배열의 시작 부분에 요소를 추가하며, 새 배열 길이를 반환합니다.

- **`indexOf()` 메서드**: 이 메서드는 배열 내 특정 요소의 첫 번째 인덱스를 찾는 데 유용합니다. 요소를 찾지 못하면 `-1`을 반환합니다.

- **`splice()` 메서드**: 이 메서드는 배열의 어느 위치에서든 요소를 추가하거나 제거하는 데 사용됩니다. `splice()` 메서드의 반환값은 배열에서 제거된 항목들의 배열입니다. 아무것도 제거하지 않으면 빈 배열이 반환됩니다. 이 메서드는 원본 배열을 직접 변경하여 새로운 배열을 만들지 않습니다. 첫 번째 인수는 배열을 수정할 시작 인덱스를 지정합니다. 두 번째 인수는 제거할 요소 수입니다. 그 다음 인수들은 추가할 요소들입니다.

- **`includes()` 메서드**: 이 메서드는 배열에 특정 값이 포함되어 있는지 확인하는 데 사용됩니다. 배열에 지정한 요소가 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환합니다.

- **`concat()` 메서드**: 이 메서드는 두 개 이상의 배열을 병합하여 새 배열을 만듭니다.

- **`slice()` 메서드**: 이 메서드는 원본 배열의 일부 구간을 시작과 끝 인덱스로 지정해 얕은 복사본을 포함하는 새 배열을 반환합니다. 새 배열은 원본 배열과 같은 요소를 참조합니다(복제본이 아님). 즉, 요소가 원시값(숫자나 문자열)일 경우 값이 복사되고, 객체나 배열일 경우 참조가 복사됩니다.

- **전개 구문**: 전개 구문은 배열의 얕은 복사를 만드는 데 사용됩니다.

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const shallowCopiedArray = [...originalArray];

shallowCopiedArray.push(4);

console.log(originalArray); // [1, 2, 3]
console.log(shallowCopiedArray); // [1, 2, 3, 4]
```

:::

- **`split()` 메서드**: 이 메서드는 문자열을 배열의 하위 문자열로 나누며, 주어진 구분자를 기준으로 분할 위치를 지정합니다. 구분자가 없으면 원본 문자열을 단일 요소로 포함하는 배열을 반환합니다.

- **`reverse()` 메서드**: 이 메서드는 배열을 제자리에서 뒤집습니다.

- **`join()` 메서드**: 이 메서드는 배열의 모든 요소를 지정한 구분자로 구분하여 하나의 문자열로 연결합니다. 구분자가 없거나 빈 문자열(`""`)이 사용되면 요소들이 구분자 없이 연결됩니다.

## 객체 기본

- **정의**: 객체는 속성들로 이루어진 자료 구조입니다. 속성은 키와 값으로 구성됩니다. 객체에서 데이터를 접근하려면 점 표기법이나 대괄호 표기법을 사용할 수 있습니다.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  city: "New York"
};

console.log(person.name);  // Alice
console.log(person["name"]); // Alice
```

:::

기존 객체의 속성을 설정하려면 점 표기법이나 대괄호 표기법과 대입 연산자를 함께 사용할 수 있습니다.

## 객체에서 속성 제거하기

- **`delete` 연산자**: 이 연산자는 객체에서 속성을 제거할 때 사용합니다.

## 객체에 속성이 있는지 확인하기

- **`hasOwnProperty()` 메서드**: 이 메서드는 객체가 지정한 속성을 자신의 속성으로 가지고 있는지 여부를 불리언으로 반환합니다.

- **`Object.hasOwn()` 메서드**: 이것은 객체가 자신의 속성(상속받은 것이 아닌)을 가지고 있는지 확인하는 현대적이고 권장되는 방법입니다. 구문은 `Object.hasOwn(object, propertyName)`입니다. 속성이 객체에 존재하면 `true`를 반환하고, 존재하지 않으면 속성 값과 상관없이 `false`를 반환합니다. 이로 인해 `hasOwnProperty()`보다 안전하고, 값이 `0`, `false`, `null`, `undefined`일 때 `if (obj.prop)`보다 더 신뢰할 수 있습니다.

`Object.hasOwn()`는 값이 `0`, `false`, 또는 `undefined`와 같이 falsy여도 객체 자신의 속성을 감지합니다.

- **`in` 연산자**: 이 연산자는 객체에 속성이 있으면 `true`을 반환합니다.

## 중첩 객체에서 프로프 접근하기

- **데이터 접근**: 중첩 객체에서 프로프에 접근할 때는 단순 객체에서 프로프에 접근하는 것처럼 점 표기법이나 대괄호 표기법을 사용합니다. 다만, 중첩 구조를 깊이 탐색하려면 이러한 접근자를 연쇄적으로 연결해야 합니다.

## 원시형과 비원시형 데이터 타입

- **원시형 데이터 타입**: 이 데이터 타입에는 숫자, 문자열, 불리언, `null`, `undefined`, 그리고 심볼이 포함됩니다. 이 타입들은 단일 값을 나타내고 객체가 아니기 때문에 "원시형"이라고 부릅니다. 원시형 값은 불변이며, 한 번 생성되면 그 값을 변경할 수 없습니다.  
- **비원시형 데이터 타입**: JavaScript에서 객체를 의미하며, 일반 객체, 배열, 함수가 포함됩니다. 원시형과 달리 비원시형 타입은 여러 값을 프로퍼티나 요소로 가질 수 있습니다.

## 객체 메서드

- **정의**: 객체 메서드는 객체와 연관된 함수입니다. 객체의 프로프로 정의되며, 객체의 데이터를 접근하고 조작할 수 있습니다. 메서드 내부의 `this` 키워드는 객체 자체를 가리켜 그 프로프에 접근할 수 있게 합니다.

## 객체 생성자

- **정의**: JavaScript에서 생성자는 객체를 만들고 초기화하는 데 사용되는 특별한 유형의 함수입니다. `new` 키워드로 호출되며 새로 생성된 객체에 프로퍼티와 메서드를 초기화할 수 있습니다. `Object()` 생성자는 새로운 빈 객체를 만듭니다.

## 선택적 체이닝 연산자 사용하기 (`?.`)

- **정의**: 이 연산자는 객체 프로프에 안전하게 접근하거나 메서드를 호출할 때, 해당 프로프나 메서드가 존재하는지 걱정하지 않아도 되게 해줍니다.

:::interactive_editor

```ts
const user = {
  name: "John",
  profile: {
    email: "john@example.com",
    address: {
      street: "123 Main St",
      city: "Somewhere"
    }
  }
};

console.log(user.profile?.address?.street); // "123 Main St"
console.log(user.profile?.phone?.number);   // undefined
```

:::

## 객체 구조 분해

- **정의**: 객체 구조 분해는 객체에서 값을 추출하여 변수에 더 간결하고 읽기 쉽게 할당할 수 있게 해줍니다.

:::interactive_editor

```js
const person = { name: "Alice", age: 30, city: "New York" };

const { name, age } = person;

console.log(name); // Alice
console.log(age);  // 30
```

:::

## JSON 다루기

- **정의**: JSON은 JavaScript Object Notation의 약자입니다. 서버와 웹 애플리케이션 간에 데이터를 주고받을 때 흔히 사용하는 가볍고 텍스트 기반의 데이터 형식입니다.

- **`JSON.stringify()`**: 이 메서드는 JavaScript 객체를 JSON 문자열로 변환하는 데 사용됩니다. 시스템 간에 쉽게 공유하거나 전송할 수 있는 형식으로 데이터를 저장하거나 전송할 때 유용합니다.

- **`JSON.parse()`**: 이 메서드는 JSON 문자열을 다시 JavaScript 객체로 변환합니다. 웹 서버나 localStorage에서 JSON 데이터를 가져와 애플리케이션에서 데이터를 조작해야 할 때 유용합니다.

## 반복문 다루기

- **`for` 반복문**: 이 반복문은 코드 블록을 정해진 횟수만큼 반복할 때 사용합니다. 이 반복문은 초기화 문장, 조건, 증감 문장 세 부분으로 나뉩니다. 초기화 문장은 반복문이 시작되기 전에 실행됩니다. 보통 카운터 변수를 초기화하는 데 사용합니다. 조건은 반복문이 한 번 실행될 때마다 평가됩니다. 한 번 실행되는 것을 한 번의 반복이라고 합니다. 조건이 `true`이면 반복문 내부의 코드 블록이 실행됩니다. 조건이 `false`이면 반복문이 정지하고 다음 코드 블록으로 넘어갑니다. 증감 문장은 반복문이 한 번 실행된 후 실행됩니다. 보통 카운터 변수를 증가시키거나 감소시키는 데 사용합니다.

:::interactive_editor

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

:::

- **`for...of` 반복문**: 이 반복문은 반복 가능한 값들을 순회할 때 사용합니다. 반복 가능한 예로는 배열과 문자열이 있습니다.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];

for (const num of numbers) {
  console.log(num);
}
```

:::

- **`for...in` 반복문**: 이 반복문은 객체의 프로프를 순회할 때 가장 적합합니다. 이 반복문은 상속된 프로프와 숫자가 아닌 프로프를 포함해 객체의 모든 열거 가능한 프로프를 순회합니다.

:::interactive_editor

```js
const fruit = {
  name: 'apple',
  color: 'red',
  price: 0.99
};

for (const prop in fruit) {
  console.log(fruit[prop]);
}
```

:::

- **`while` 반복문**: 이 반복문은 조건이 `true`인 동안 코드 블록을 실행합니다.

:::interactive_editor

```js
let i = 5;

while (i > 0) {
  console.log(i);
  i--;
}
```

:::

- **`do...while` 반복문**: 이 반복문은 조건을 확인하기 전에 코드 블록을 최소 한 번 실행합니다.

```js
let userInput;

do {
  userInput = prompt("Please enter a number between 1 and 10");
} while (Number(userInput) < 1 || Number(userInput) > 10);

alert("You entered a valid number!");
```

## `break`와 `continue` 문장

- **정의**: `break` 문장은 반복문을 조기에 종료할 때 사용하며, `continue` 문장은 현재 반복을 건너뛰고 다음 반복으로 넘어갈 때 사용합니다.

## 문자열 생성자와 `toString()` 메서드

- **정의**: 문자열 객체는 문자 수열을 나타내는 데 사용됩니다. 문자열 객체는 원시 값을 객체로 감싸는 `String` 생성자 함수로 생성합니다.

- **`toString()` 메서드**: 이 메서드는 값을 문자열 표현으로 변환합니다. 숫자, 불리언, 배열, 객체에 사용할 수 있는 메서드입니다.

이 메서드는 2에서 36 사이의 숫자인 선택적 기수를 받습니다. 이 기수는 2진수의 경우 2, 8진수의 경우 8과 같이 진법을 나타냅니다. 기수를 지정하지 않으면 기본값은 10진수인 10입니다.

## 숫자 생성자

- **정의**: `Number` 생성자는 숫자 객체를 만드는 데 사용됩니다. 숫자 객체는 `isNaN`과 `toFixed` 메서드 같은 몇 가지 유용한 프로프와 메서드를 포함합니다. 대부분의 경우, 다른 데이터 유형을 숫자 데이터 유형으로 변환할 때 `Number` 생성자를 사용하게 됩니다.

## 변수와 함수 이름 짓기 모범 사례

- **camelCasing**: 관례상 JavaScript 개발자들은 변수와 함수 이름을 지을 때 camel casing을 사용합니다. camel casing은 첫 단어는 모두 소문자로 쓰고, 그 다음 단어들은 첫 글자를 대문자로 시작하는 방식입니다. 예: `isLoading`.

- **불리언 변수 이름 짓기**: 불리언 변수에는 "is", "has", "can" 같은 접두사를 붙이는 것이 일반적인 관례입니다.

- **함수 이름 짓기**: 함수 이름은 함수가 하는 일을 명확히 나타내야 합니다. 불리언 값을 반환하는 함수(보통 술어 함수라고 함)에는 "is", "has", "can" 같은 접두사를 사용할 수 있습니다. 데이터를 가져오는 함수는 보통 "get"으로 시작하고, 데이터를 설정하는 함수는 보통 "set"으로 시작합니다. 이벤트 핸들러 함수에는 "handle"을 접두사로 붙이거나 "Handler"를 접미사로 붙이는 경우가 많습니다.

- **반복문 내부 변수 이름 짓기**: 반복문에서 반복자 변수 이름은 보통 `i`, `j`, `k` 같은 한 글자 이름을 사용합니다.

## 희소 배열 다루기

- **정의**: 빈 칸이 있는 배열을 가질 수 있습니다. 빈 칸은 아무것도 들어 있지 않은 칸으로 정의합니다. 이는 값이 `undefined`인 배열 칸과는 다릅니다. 이러한 유형의 배열을 희소 배열이라고 합니다.

## 린터와 포매터

- **린터**: 린터는 정적 코드 분석 도구로, 프로그래밍 오류, 버그, 스타일 오류, 의심스러운 구문을 표시합니다. 대표적인 린터 예로는 ESLint가 있습니다.  
- **포매터**: 포매터는 특정 스타일 가이드에 맞게 코드를 자동으로 포맷하는 도구입니다. 대표적인 포매터 예로는 Prettier가 있습니다.

## 메모리 관리

- **정의**: 메모리 관리는 메모리를 제어하고 필요할 때 할당하며 더 이상 필요하지 않을 때 해제하는 과정입니다. JavaScript는 자동 메모리 관리를 사용합니다. 즉, JavaScript(더 구체적으로는 웹 브라우저의 JavaScript 엔진)가 메모리 할당과 해제를 대신 처리합니다. 코드에서 명시적으로 메모리를 해제할 필요가 없습니다. 이 자동 과정은 흔히 "가비지 컬렉션"이라고 부릅니다.

## 클로저

- **정의**: 클로저는 외부(포함하는) 렉시컬 범위에 있는 변수에 외부 함수가 반환된 후에도 접근할 수 있는 함수입니다.

:::interactive_editor

```js
function outerFunction(x) {
  let y = 10;
  function innerFunction() {
    console.log(x + y);
  }
  return innerFunction;
}

let closure = outerFunction(5);
closure(); // 15
```

:::

## `var` 키워드와 호이스팅

- **정의**: `var`는 2015년 이전에 변수를 선언하는 원래 방법이었습니다. 하지만 `var`에는 범위, 재선언 등과 관련된 몇 가지 문제가 있었습니다. 그래서 현대 JavaScript 프로그래밍에서는 대신 `let`와 `const`를 사용합니다.
- **`var`로 변수 재선언하기**: `let`를 사용해 변수를 재선언하려 하면 `SyntaxError`가 발생합니다. 하지만 `var`를 사용하면 변수를 재선언할 수 있습니다.

- **`var`와 범위**: `var`로 블록(예: `if` 문이나 `for` 반복문) 내부에서 선언한 변수는 그 블록 밖에서도 접근할 수 있습니다.

- **호이스팅**: 코드를 실행하기 전에 컴파일 단계에서 선언을 해당 범위의 최상단으로 끌어올리는 JavaScript의 기본 동작입니다. `var` 키워드로 변수를 선언하면 JavaScript가 선언을 범위 최상단으로 호이스팅합니다.

함수 선언 구문으로 함수를 선언하면 함수 이름과 함수 본문 모두 호이스팅됩니다. 즉, 코드에서 함수를 선언하기 전에 호출할 수 있습니다.

`let` 또는 `const`로 선언한 변수는 호이스팅되지만 초기화되지 않으며, 실제 선언 전에 접근할 수 없습니다. 이 동작을 흔히 "일시적 사각지대(temporal dead zone)"라고 부릅니다.

## 가져오기, 내보내기 및 모듈 작업하기

- **모듈**: 관련된 함수, 클래스 또는 변수를 캡슐화하는 독립적인 코드 단위입니다. 모듈을 만들려면 JavaScript 코드를 별도의 파일에 작성하세요.
- **내보내기**: 애플리케이션의 다른 부분에서 사용하려는 변수, 함수 또는 클래스는 `export` 키워드를 사용해 명시적으로 내보내야 합니다. 내보내기에는 명명 내보내기와 기본 내보내기 두 가지 유형이 있습니다.
- **가져오기**: 내보낸 항목을 애플리케이션의 다른 부분에서 사용하려면 `import` 키워드를 사용해 가져와야 합니다. 가져오기 유형에는 명명 가져오기, 기본 가져오기, 네임스페이스 가져오기가 있습니다.

```js
// Within a file called math.js, we export the following functions:

// Named export
export function add(num1, num2) {
  return num1 + num2;
}

// Default export
export default function subtract(num1, num2) {
  return num1 - num2;
}

// Within another file, we can import the functions from math.js.

// Named import - This line imports the add function.
// The name of the function must exactly match the one exported from math.js.
import { add } from './math.js';

// Default import - This line imports the subtract function.
// The name of the function can be anything.
import subtractFunc from './math.js';

// Namespace import - This line imports everything from the file.
import * as Math from './math.js';

console.log(add(5, 3)); // 8
console.log(subtractFunc(5, 3)); // 2
console.log(Math.add(5, 3)); // 8
console.log(Math.subtract(5, 3)); // 2
```

## 콜백 함수와 `forEach` 메서드

- **정의**: JavaScript에서 콜백 함수는 다른 함수에 인수로 전달되어, 외부 함수가 특정 시점에 이를 호출할 수 있도록 하는 함수입니다.
- **`forEach()` 메서드**: 이 메서드는 배열의 각 요소를 순회하며 각 요소에 대해 작업을 수행하는 데 사용됩니다. `forEach`의 콜백 함수는 최대 세 개의 인수를 받을 수 있는데, 현재 요소, 현재 요소의 인덱스, 그리고 `forEach`가 호출된 배열입니다.

## 고차 함수

- **정의**: 고차 함수는 하나 이상의 함수를 인수로 받고, 함수나 값을 결과로 반환합니다.

- **`map()` 메서드**: 이 메서드는 주어진 함수를 원래 배열의 각 요소에 적용하여 새 배열을 만듭니다. 콜백 함수는 최대 세 개의 인수를 받을 수 있습니다: 현재 요소, 현재 요소의 인덱스, 그리고 `map`가 호출된 배열입니다.

- **`filter()` 메서드**: 이 메서드는 지정된 테스트를 통과하는 요소들로 새 배열을 만들어, 기준에 따라 항목을 선택적으로 추출할 때 유용합니다. `map` 메서드와 마찬가지로, `filter` 메서드의 콜백 함수도 처리 중인 현재 요소, 인덱스, 배열이라는 세 가지 인수를 받습니다.

- **`reduce()` 메서드**: 이 메서드는 배열을 처리하여 단일 값으로 압축합니다. 이 단일 값은 숫자, 문자열, 객체, 또는 또 다른 배열일 수 있습니다. `reduce()` 메서드는 배열의 각 요소에 순서대로 함수를 적용하며, 각 계산 결과를 다음 계산에 전달합니다. 이 함수는 종종 리듀서 함수라고 불립니다. 리듀서 함수는 두 가지 주요 매개변수를 받습니다: 누산기와 현재 값입니다. 누산기는 연산의 누적 결과를 저장하는 곳이고, 현재 값은 처리 중인 배열 요소입니다.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce(
  (accumulator, currentValue) => accumulator + currentValue,
  0
);

console.log(sum); // 15
```

:::

## 메서드 체이닝

- **정의**: 메서드 체이닝은 같은 객체에 대해 여러 메서드를 한 줄의 코드에서 연속으로 호출할 수 있게 하는 프로그래밍 기법입니다. 이 기법은 특히 같은 객체에 대해 일련의 작업을 수행할 때 코드를 더 읽기 쉽고 간결하게 만듭니다.

## `sort` 메서드 사용하기

- **정의**: `sort` 메서드는 배열의 요소를 정렬하고 정렬된 배열에 대한 참조를 반환하는 데 사용됩니다. 이 경우 요소들이 제자리에서 정렬되기 때문에 복사본이 만들어지지 않습니다.

숫자를 정렬해야 할 경우 비교 함수를 전달해야 합니다. `sort` 메서드는 요소를 문자열로 변환한 후 UTF-16 코드 단위 값의 순서를 비교합니다. UTF-16 코드 단위는 문자열의 문자를 나타내는 숫자 값입니다. 예를 들어, UTF-16 코드 단위 65, 66, 67은 각각 문자 "A", "B", "C"를 나타냅니다. 그래서 배열에서 숫자 200은 문자열 "200"이 "3"보다 UTF-16 코드 단위 비교 시 앞서기 때문에 숫자 3보다 앞에 나타납니다.

:::interactive_editor

```js
const numbers = [414, 200, 5, 10, 3];

numbers.sort((a, b) => a - b);

console.log(numbers); // [3, 5, 10, 200, 414]
```

:::

매개변수 `a`과 `b`는 비교되는 두 요소입니다. 비교 함수는 `a`이 `b`보다 앞서야 하면 음수를, `a`가 `b`보다 뒤에 와야 하면 양수를, `a`과 `b`이 같으면 0을 반환해야 합니다.

## `every`와 `some` 메서드 사용하기

- **`every()` 메서드**: 이 메서드는 배열의 모든 요소가 제공된 함수로 구현된 테스트를 통과하는지 검사합니다. `every()` 메서드는 배열의 모든 요소에 대해 제공된 함수가 `true`를 반환하면 `true`을 반환합니다. 만약 어떤 요소라도 테스트에 실패하면, 메서드는 즉시 `false`를 반환하고 나머지 요소에 대한 검사를 정지합니다.

- **`some()` 메서드**: 이 메서드는 적어도 하나의 요소가 테스트를 통과하는지 확인합니다. `some()` 메서드는 테스트를 통과하는 요소를 찾는 즉시 `true`를 반환합니다. 만약 어떤 요소도 테스트를 통과하지 못하면 `false`를 반환합니다.

## DOM과 웹 API 다루기

- **API**: API(애플리케이션 프로그래밍 인터페이스)는 소프트웨어 애플리케이션들이 서로 효율적으로 통신하고 데이터를 교환할 수 있게 하는 규칙과 프로토콜 집합입니다.
- **웹 API**: 웹 API는 웹 애플리케이션을 위해 특별히 설계된 API입니다. 이러한 API는 보통 브라우저 API와 서드파티 API 두 가지 주요 범주로 나뉩니다.
- **브라우저 API**: 이 API들은 브라우저에서 데이터를 노출합니다. 웹 개발자는 JavaScript를 사용해 이 데이터에 접근하고 조작할 수 있습니다.
- **서드파티 API**: 기본적으로 브라우저에 내장되어 있지 않습니다. 코드를 어떤 방식으로든 가져와야 합니다. 보통 서비스 사용법을 설명하는 자세한 문서가 제공됩니다. 예를 들어, Google Maps API는 웹사이트에 인터랙티브한 지도를 표시하는 데 사용할 수 있습니다.
- **DOM**: DOM은 문서 객체 모델(Document Object Model)의 약자입니다. HTML 문서와 상호작용할 수 있게 하는 프로그래밍 인터페이스입니다. DOM을 통해 웹페이지의 요소를 추가, 수정, 삭제할 수 있습니다. DOM 트리의 루트는 `html` 요소입니다. 이 요소는 HTML 문서의 모든 콘텐츠를 담는 최상위 컨테이너입니다. 다른 모든 노드는 이 루트 노드의 자손 요소입니다. 루트 노드 아래에는 계층 구조상 다른 노드들이 있습니다. 부모 노드는 다른 요소를 포함하는 요소이고, 자식 노드는 다른 요소 안에 포함된 요소입니다.
- **`navigator` 인터페이스**: 사용자 에이전트 문자열, 플랫폼, 브라우저 버전 등 브라우저 환경에 관한 정보를 제공합니다. 사용자 에이전트 문자열은 사용 중인 브라우저와 운영체제를 식별하는 텍스트 문자열입니다.
- **`window` 인터페이스**: DOM 문서를 포함하는 브라우저 창을 나타냅니다. 창 크기 조절, 새 창 열기, 다른 URL로 이동하기 등 브라우저 창과 상호작용하는 메서드와 프로프를 제공합니다.

## `querySelector()`, `querySelectorAll()` 그리고 `getElementById()` 메서드 사용하기

- **`getElementById()` 메서드**: 이 메서드는 지정한 `id`를 가진 HTML 요소를 나타내는 객체를 가져오는 데 사용합니다. id는 모든 HTML 문서에서 고유해야 하므로, 이 메서드는 하나의 Element 객체만 반환합니다.

- **`querySelector()` 메서드**: 이 메서드는 인수로 전달된 CSS 선택자와 일치하는 HTML 문서 내 첫 번째 요소를 가져오는 데 사용합니다.

- **`querySelectorAll()` 메서드**: 이 메서드를 사용하면 특정 CSS 선택자와 일치하는 모든 DOM 요소 목록을 가져올 수 있습니다.

## `innerText()`, `innerHTML()`, `createElement()` 그리고 `textContent()` 메서드 사용하기

- **`innerHTML` 속성**: HTML 마크업의 일부를 설정하거나 업데이트하는 데 사용되는 `Element`의 속성입니다.

- **`createElement` 메서드**: HTML 요소를 생성하는 데 사용합니다.

- **`innerText`**: HTML 요소와 그 자손 요소의 보이는 텍스트 내용을 나타냅니다.

- **`textContent`**: 요소와 그 자손 요소 내 모든 텍스트를 포함한 일반 텍스트 내용을 반환합니다.

## `appendChild()`와 `removeChild()` 메서드 사용하기

- **`appendChild()` 메서드**: 이 메서드는 지정한 부모 노드의 자식 목록 끝에 노드를 추가할 때 사용합니다.

- **`removeChild()` 메서드**: 이 메서드는 DOM에서 노드를 제거할 때 사용합니다.

## `setAttribute()` 메서드 사용하기

- **정의**: 이 메서드는 주어진 요소의 속성을 설정하는 데 사용됩니다. 속성이 이미 존재하면 값이 업데이트됩니다. 그렇지 않으면 값과 함께 새 속성이 추가됩니다.

## 이벤트 객체

- **정의**: `Event` 객체는 사용자가 웹 페이지와 어떤 방식으로 상호작용할 때 발생하는 페이로드입니다. 이러한 상호작용은 버튼 클릭, 입력 포커스, 모바일 기기 흔들기 등 다양할 수 있습니다. 모든 `Event` 객체는 `type` 속성을 가집니다. 이 속성은 keydown이나 click 같은 페이로드를 발생시킨 이벤트 유형을 나타냅니다. 이 값들은 `addEventListener()`에 전달할 수 있는 값과 일치하며, 여기서 `Event` 객체를 캡처하고 활용할 수 있습니다.

## `addEventListener()`와 `removeEventListener()` 메서드

- **`addEventListener` 메서드**: 이 메서드는 이벤트를 듣기 위해 사용합니다. 두 개의 인수를 받는데, 하나는 듣고자 하는 이벤트이고 다른 하나는 이벤트가 발생했을 때 호출될 함수입니다. 일반적인 이벤트 예로는 클릭 이벤트, 입력 이벤트, 변경 이벤트가 있습니다.

:::interactive_editor

```html
<button id="btn">Click Me</button>
<script src="./index.js"></script>
```

```js
const btn = document.getElementById("btn");

btn.addEventListener("click", () => alert("You clicked the button"));
```

:::

- **`removeEventListener()` 메서드**: 이 메서드는 이전에 `addEventListener()` 메서드를 사용해 요소에 추가한 이벤트 리스너를 제거하는 데 사용합니다. 특정 요소에서 특정 이벤트를 더 이상 듣고 싶지 않을 때 유용합니다.

- **인라인 이벤트 핸들러**: 인라인 이벤트 핸들러는 이벤트가 발생했을 때 JavaScript 코드를 실행하기 위해 HTML 요소에 특별히 지정하는 속성입니다. 현대 JavaScript에서는 인라인 이벤트 핸들러를 모범 사례로 여기지 않습니다. 대신 `addEventListener` 메서드를 사용하는 것이 권장됩니다.

## 변경 이벤트

- **정의**: 변경 이벤트는 사용자가 특정 입력 요소의 값을 수정할 때 발생하는 특별한 이벤트입니다. 예를 들어 체크박스나 라디오 버튼을 선택할 때, 또는 사용자가 날짜 선택기나 드롭다운 메뉴에서 선택할 때 발생합니다.

## 이벤트 버블링

- **정의**: 이벤트 버블링 또는 전파는 이벤트가 발생했을 때 부모 객체로 "거품처럼" 올라가는 방식을 말합니다.
- **`stopPropagation()` 메서드**: 이 메서드는 이벤트의 추가 전파를 막습니다.

## 이벤트 위임

- **정의**: 이벤트 위임은 이벤트가 발생한 요소에서 직접 처리하는 대신, 버블링되어 상위 요소에 도달한 이벤트를 감지하는 과정입니다.

## DOMContentLoaded

- **정의**: `DOMContentLoaded` 이벤트는 HTML 문서의 모든 내용이 로드되고 구문 분석이 완료되었을 때 발생합니다. 외부 스타일시트나 이미지가 있더라도 `DOMContentLoaded` 이벤트는 그것들이 로드될 때까지 기다리지 않습니다. HTML이 로드되는 것만 기다립니다.

## `style`와 `classList` 다루기

- **`Element.style` 속성**: 이 속성은 요소의 인라인 스타일을 나타내는 읽기 전용 속성입니다. 이 속성을 사용해 요소의 스타일을 가져오거나 설정할 수 있습니다.

- **`Element.classList` 속성**: 이 속성은 요소에 클래스를 추가, 제거 또는 토글하는 데 사용할 수 있는 읽기 전용 속성입니다.

## `setTimeout()`와 `setInterval()` 메서드 사용하기

- **`setTimeout()` 메서드**: 이 메서드는 지정한 시간 동안 동작을 지연시킬 수 있습니다.

- **`setInterval()` 메서드**: 이 메서드는 일정 간격으로 코드를 반복 실행합니다. `setInterval()`는 지정한 간격마다 함수를 계속 실행하므로, 중단하려면 `clearInterval()` 메서드를 사용해야 합니다.

## `requestAnimationFrame()` 메서드

- **정의**: 이 메서드는 다음 화면 새로 고침 전에 애니메이션의 다음 단계를 예약할 수 있게 하여 부드럽고 시각적으로 매력적인 경험을 제공합니다. 다음 화면 새로 고침은 브라우저가 웹 페이지의 시각적 표시를 새로 고침하는 순간을 의미합니다. 이는 대부분의 디스플레이에서 초당 약 60회(또는 60프레임) 정도 여러 번 발생합니다.

## 웹 애니메이션 API

- **정의**: 웹 애니메이션 API는 JavaScript 내에서 직접 애니메이션을 만들고 제어할 수 있게 해줍니다.

## 캔버스 API

- **정의**: 캔버스 API는 JavaScript 파일 안에서 그래픽을 직접 조작할 수 있게 해주는 강력한 도구입니다. 캔버스 API를 사용하려면 먼저 HTML에 `canvas` 요소를 제공해야 합니다. 이 요소는 캔버스 API의 인터페이스 인스턴스 메서드와 프로프를 사용해 조작할 수 있는 그리기 표면 역할을 합니다. 이 API에는 JavaScript 파일에서 그래픽을 만들 때 사용할 수 있는 메서드와 프로프를 포함하는 `HTMLCanvasElement`, `CanvasRenderingContext2D`, `CanvasGradient`, `CanvasPattern`, `TextMetrics` 같은 인터페이스가 있습니다.

## JavaScript로 대화상자와 모달 열기 및 닫기

- **모달과 대화상자 정의**: 대화상자는 사용자에게 중요한 정보나 작업을 보여줄 때 사용합니다. HTML 내장 dialog 요소를 사용하면 웹 애플리케이션에서 이러한 대화상자(모달과 비모달 모두)를 쉽게 만들 수 있습니다. 모달 대화상자는 사용자가 애플리케이션이나 웹페이지의 나머지 부분에 접근하기 전에 반드시 상호작용해야 하는 대화상자 유형입니다. 반면 비모달 대화상자는 대화상자가 열려 있어도 사용자가 페이지나 애플리케이션의 다른 부분과 계속 상호작용할 수 있게 하며, 나머지 콘텐츠에 대한 접근을 막지 않습니다.
- **`showModal()` 메서드**: 이 메서드는 모달을 열 때 사용합니다.

- **`close()` 메서드**: 이 메서드는 모달을 닫을 때 사용합니다.

## 일반적인 ARIA 접근성 속성

- **`aria-expanded` 속성**: 토글(또는 공개) 기능의 상태를 화면 읽기 프로그램 사용자에게 전달하는 데 사용합니다.

- **`aria-haspopup` 속성**: 이 상태는 상호작용 요소가 활성화될 때 팝업 요소를 트리거한다는 것을 나타내는 데 사용합니다. 팝업이 다음 역할 중 하나일 때만 `aria-haspopup` 속성을 사용할 수 있습니다: `menu`, `listbox`, `tree`, `grid`, 또는 `dialog`. `aria-haspopup`의 값은 이 역할 중 하나이거나 `true`이어야 하며, 이는 `menu`과 동일합니다.

- **`aria-checked` 속성**: 이 속성은 요소가 선택된 상태인지 여부를 나타내는 데 사용합니다. 주로 사용자 정의 체크박스, 라디오 버튼, 스위치, 리스트박스를 만들 때 사용합니다.

- **`aria-disabled` 속성**: 이 상태는 화면 읽기 프로그램과 같은 보조 기술을 사용하는 사람들에게만 요소가 비활성화되었음을 나타내는 데 사용합니다.

- **`aria-selected` 속성**: 이 상태는 요소가 선택되었음을 나타내는 데 사용합니다. 탭 인터페이스, 리스트박스, 그리드 같은 사용자 정의 컨트롤에 이 상태를 사용할 수 있습니다.

- **`aria-controls` 속성**: 요소를 제어하는 다른 요소와 연결하는 데 사용합니다. 이는 보조 기술 사용자가 요소 간의 관계를 이해하는 데 도움이 됩니다.

- **`hidden` 속성**: 비활성 패널을 시각적 사용자와 보조 기술 사용자 모두에게 숨깁니다.

## 라이브 영역과 동적 콘텐츠 작업

- **`aria-live` 속성**: 웹페이지의 일부를 라이브 영역으로 만들어 해당 영역 내의 업데이트가 화면 읽기 프로그램에 의해 알림되어 사용자가 중요한 변경 사항을 놓치지 않도록 합니다.
- **`polite` 값**: 대부분의 라이브 영역이 이 값을 사용합니다. 이 값은 업데이트가 긴급하지 않음을 의미하며, 화면 읽기 프로그램이 현재 알림을 마치거나 사용자가 현재 작업을 완료할 때까지 기다렸다가 업데이트를 알릴 수 있습니다.

다음은 JavaScript로 동적으로 업데이트되는 라이브 영역의 예입니다:

:::interactive_editor

```html
<div aria-live="polite" id="status"></div>

<button id="updateStatus">Update Status</button>

<script>
  const statusEl = document.getElementById("status");
  const btn = document.getElementById("updateStatus");

  btn.addEventListener("click", () => {
    statusEl.textContent = "Your file has been successfully uploaded.";
  });
</script>
```

:::

- **`contenteditable` 속성**: 요소를 라이브 편집기로 만들어 사용자가 텍스트 필드처럼 내용을 업데이트할 수 있게 합니다. contenteditable 영역에 눈에 띄는 레이블이나 제목이 없으면, 화면 읽기 프로그램 사용자가 편집 영역의 목적을 이해할 수 있도록 `aria-label` 속성으로 접근 가능한 이름을 추가하세요.

## `focus` 및 `blur` 이벤트

- **`blur` 이벤트**: 요소가 포커스를 잃을 때 발생합니다.

- **`focus` 이벤트**: 요소가 포커스를 받을 때 발생합니다.

## 일반적인 오류 메시지 유형

- **SyntaxError**: 코드에서 괄호나 대괄호를 빠뜨리는 등 잘못 작성했을 때 발생하는 오류입니다. 문장의 문법 오류와 비슷하게 생각하세요.

- **ReferenceError**: 여러 가지 유형이 있으며, 다양한 상황에서 발생합니다. 첫 번째 유형은 정의되지 않은 변수를 참조할 때입니다. 또 다른 예는 `let` 또는 `const`로 선언된 변수를 정의되기 전에 접근하려 할 때 발생하는 ReferenceError입니다.

- **TypeError**: 잘못된 타입에 대해 연산을 시도할 때 발생하는 오류입니다.

- **RangeError**: 코드가 JavaScript가 처리할 수 있는 범위를 벗어난 값을 사용하려 할 때 발생하는 오류입니다.

## `throw` 문장

- **정의**: JavaScript에서 `throw` 문장은 사용자 정의 예외를 발생시키는 데 사용합니다. 프로그래밍에서 예외란 예상치 못한 사건이 발생해 프로그램의 정상 흐름을 방해하는 경우를 말합니다.

## `try...catch...finally`

- **정의**: `try` 블록은 오류가 발생할 수 있는 코드를 감싸는 데 사용됩니다. 실패할 수 있는 작업을 시도하는 안전한 공간 역할을 합니다. `catch` 블록은 try 블록에서 발생한 오류를 포착하고 처리합니다. catch 내부의 error 객체를 사용해 무엇이 잘못되었는지 확인할 수 있습니다. `finally` 블록은 오류 발생 여부와 상관없이 try와 catch 블록 이후에 실행됩니다. 주로 파일 닫기나 자원 해제 같은 정리 작업에 사용됩니다.

:::interactive_editor

```js
function processInput(input) {
  if (typeof input !== "string") {
    throw new TypeError("Input must be a string.");
  }

  return input.toUpperCase();
}

try {
  console.log("Starting to process input...");
  const result1 = processInput("hello");
  console.log("Processed result:", result1);  // HELLO
  const result2 = processInput(9);  // throws TypeError
  console.log("Processed result:", result2);  // not executed
} catch (error) {
  console.error("Error occurred:", error.message);
} 
```

:::

## 디버깅 기법

- **`debugger` 문장**: 이 문장은 코드 실행을 특정 줄에서 멈추고 프로그램 상태를 조사할 수 있게 해줍니다.

- **중단점**: 중단점은 원하는 특정 줄에서 코드 실행을 멈추게 합니다. 멈춘 후에는 변수 값을 확인하고, 표현식을 평가하며, 호출 스택을 검사할 수 있습니다.
- **감시자**: 감시 표현식은 현재 범위를 벗어난 변수나 표현식의 값을 코드 실행 중에도 모니터링할 수 있게 해줍니다.
- **프로파일링**: 프로파일링은 CPU 사용량, 함수 호출, 실행 시간을 기록하고 스크린샷을 캡처하여 성능 병목 현상을 파악하는 데 도움을 줍니다.
- **`console.dir()`**: 이 메서드는 지정한 JavaScript 객체의 프로퍼티를 대화형 목록으로 표시하는 데 사용됩니다. 중첩된 모든 프로퍼티를 볼 수 있도록 계층적 목록을 확장할 수 있습니다.

- **`console.table()`**: 이 메서드는 콘솔에 표 형식으로 데이터를 표시합니다. 필수 인수로 배열이나 객체를 받고, 선택 인수로 표시할 프로퍼티(열)를 지정할 수 있습니다.

## 정규 표현식과 자주 쓰이는 메서드

- **정의**: 정규 표현식, 또는 정규식은 "패턴"을 만들 때 사용하며, 이 패턴을 이용해 문자열을 검사하거나 텍스트를 추출하는 등 다양한 작업을 할 수 있습니다.

- **`RegExp` 생성자**: 패턴이나 플래그가 변수에서 올 때, `RegExp` 생성자를 사용해 같은 종류의 정규식을 만들 수 있습니다. 이 생성자는 패턴 문자열과 선택적인 플래그 문자열을 받습니다.

예를 들어, `new RegExp(pattern, flags)`는 해당 문자열들로부터 정규 표현식을 생성합니다.

- **`test()` 메서드**: 이 메서드는 문자열을 인수로 받아 정규 표현식과 일치하는지 검사합니다. 문자열이 정규식과 일치하면 불리언 값을 반환합니다.

- **`match()` 메서드**: 이 메서드는 정규 표현식을 인수로 받으며, 문자열을 전달하면 정규 표현식으로 변환됩니다. `match` 메서드는 문자열에 대한 일치 배열을 반환합니다.

- **`replace()` 메서드**: 이 메서드는 두 개의 인수를 받습니다: 일치시킬 정규 표현식(또는 문자열)과 일치한 부분을 대체할 문자열(또는 각 일치에 대해 실행할 함수)입니다.

- **`replaceAll` 메서드**: 이 메서드는 지정한 패턴의 모든 발생을 새 문자열로 대체할 때 사용합니다. 글로벌 수정자가 없는 정규식을 전달하면 오류가 발생합니다.

- **`matchAll` 메서드**: 이 메서드는 문자열에서 주어진 정규식과 일치하는 모든 결과(캡처 그룹 포함)를 가져와 반복자로 반환합니다. 반복자는 항목 모음을 순회할 수 있는 객체입니다.

## 정규 표현식 수정자

- **정의**: 수정자, 흔히 "플래그"라고도 하며, 정규 표현식의 동작 방식을 변경합니다.  
- **`i` 플래그**: 이 플래그는 정규식이 대소문자를 구분하지 않도록 만듭니다.

- **`g` 플래그**: 이 플래그, 또는 글로벌 수정자는 정규 표현식이 패턴을 여러 번 일치시킬 수 있게 합니다.

- **앵커 정의**: 정규 표현식의 시작 부분에 있는 `^` 앵커는 "문자열의 시작과 일치"를 의미합니다. 정규 표현식의 끝 부분에 있는 `$` 앵커는 "문자열의 끝과 일치"를 의미합니다.

- **`m` 플래그**: 앵커는 전체 문자열의 시작과 끝을 찾습니다. 하지만 `m` 플래그, 즉 여러 줄 수정자를 사용하면 정규 표현식이 여러 줄을 처리하도록 만들 수 있습니다.

- **`d` 플래그**: 이 플래그는 매치 객체에 매치와 캡처 그룹의 시작 및 끝 인덱스를 추가합니다.

- **`u` 플래그**: 이 플래그는 정규 표현식의 기능을 확장하여 특수 유니코드 문자를 매치할 수 있게 합니다. `u` 플래그를 사용하면 대부분의 이모지를 매치하는 `Extended_Pictographic` 같은 특수 클래스를 사용할 수 있습니다. 또한 유니코드 매칭 기능을 더 확장하는 `v` 플래그도 있습니다.
- **`y` 플래그**: sticky 수정자는 global 수정자와 매우 비슷하게 동작하지만 몇 가지 예외가 있습니다. 가장 큰 차이는 global 정규식은 lastIndex부터 시작해 문자열의 나머지 전체를 검색하지만, sticky 정규식은 이전 lastIndex에서 즉시 매치가 없으면 null을 반환하고 lastIndex를 0으로 초기화한다는 점입니다.
- **`s` 플래그**: single-line 수정자는 정규식에서 `.`로 표현되는 와일드카드 문자가 줄 바꿈 문자도 매치할 수 있게 하여 문자열을 한 줄로 처리하는 효과를 줍니다.

## 문자 클래스

- **와일드카드 `.`**: 문자 클래스는 문자 집합이나 부분집합과 일치시키기 위해 사용할 수 있는 특별한 구문입니다. 가장 먼저 배워야 할 문자 클래스는 와일드카드 클래스입니다. 와일드카드는 마침표, 즉 점으로 나타내며 줄 바꿈을 제외한 모든 단일 문자와 일치합니다. 와일드카드 클래스가 줄 바꿈과도 일치하게 하려면 `s` 플래그를 사용해야 한다는 점을 기억하세요.

- **`\d`**: 이 클래스는 문자열 내 모든 숫자(`0-9`)와 일치합니다.

- **`\w`**: 문자열에서 모든 단어 문자를 매칭하는 데 사용됩니다(`a-zA-Z0-9_`). 단어 문자는 a부터 z 또는 A부터 Z까지의 문자, 0부터 9까지의 숫자, 또는 밑줄 문자로 정의됩니다.

- **`\s`**: 공백 문자 클래스 `\s`는 역슬래시 뒤에 `s`가 오는 형태로, 줄 바꿈, 공백, 탭, 특수 유니코드 공백 문자를 포함한 모든 공백 문자와 매치됩니다.
- **특수 문자 클래스 부정**: 이러한 문자 클래스 중 하나를 부정하려면, 역슬래시 뒤에 소문자 대신 대문자를 사용합니다. 예를 들어, `\D`는 숫자가 아닌 단일 문자와 매치됩니다.

- **사용자 정의 문자 클래스**: 매칭하려는 문자를 대괄호 안에 넣어 사용자 정의 문자 클래스를 만들 수 있습니다.

예를 들어, `/[abcdf]/`는 괄호 안의 문자 중 하나와 매치됩니다.

## 전방 탐색과 후방 탐색 어서션

- **정의**: 전방 탐색과 후방 탐색 어서션은 주변 패턴의 존재 여부에 따라 특정 패턴을 매칭할 수 있게 합니다.
- **긍정 전방 탐색 어서션**: 이 어서션은 특정 패턴 뒤에 다른 패턴이 올 때 매칭합니다. 긍정 전방 탐색을 만들려면, 먼저 매칭하려는 패턴을 작성하세요. 그런 다음, 조건으로 사용할 패턴을 소괄호로 감쌉니다. 소괄호 뒤에 `?=`를 사용해 해당 패턴을 긍정 전방 탐색으로 정의합니다.

예를 들어, `/free(?=code)/i`는 `code`가 뒤따를 때 `free`와 일치합니다.

- **부정 전방 탐색 어서션**: 정규 표현식에서 특정 패턴이 문자열 앞에 나타나지 않는지 확인하는 조건 유형입니다.

예를 들어, `/free(?!code)/i`는 `code`가 뒤따르지 않을 때 `free`와 일치합니다.

- **긍정 후방 탐색 어서션**: 이 어서션은 특정 패턴 앞에 다른 특정 패턴이 있을 때만 매칭하며, 앞선 패턴은 매칭 결과에 포함하지 않습니다.

예를 들어, `/(?<=free)code/i`는 `free`가 앞에 있을 때 `code`와 매치됩니다.

- **부정 후방 탐색 어서션**: 이 어서션은 특정 패턴 앞에 다른 특정 패턴이 없음을 보장합니다. 지정한 패턴이 바로 앞선 수열에 의해 선행되지 않을 때만 매칭하며, 앞선 수열은 매칭 결과에 포함하지 않습니다.

예를 들어, `/(?<!free)code/i`는 `free`가 앞에 없을 때 `code`와 매치됩니다.

## 정규식 수량자

- **정의**: 정규 표현식에서 수량자는 패턴(또는 패턴의 일부)이 몇 번 나타나야 하는지를 지정합니다. 이는 매치 내에서 문자나 그룹의 발생 횟수를 제어하는 데 도움을 줍니다.

예를 들어, `/^\d{4}$/`는 정확히 네 자리 숫자로 이루어진 문자열과 매치됩니다.

- **`*`** : 바로 앞 요소가 0번 이상 나타나는 경우와 일치합니다.
- **`+`**: 바로 앞 요소가 1번 이상 나타나는 경우와 일치합니다.
- **`?`**: 바로 앞 요소가 0번 또는 1번 나타나는 경우와 일치합니다.
- **`{n}`**: 바로 앞 요소가 정확히 n번 나타나는 경우와 일치합니다.
- **`{n,}`**: 바로 앞 요소가 n번 이상 나타나는 경우와 일치합니다.
- **`{n,m}`**: 바로 앞 요소가 n번에서 m번 사이에 나타나는 경우와 일치합니다.

## 캡처 그룹과 백참조

- **캡처 그룹**: 캡처 그룹은 일치한 문자열의 일부를 "캡처"하여 필요에 따라 사용할 수 있게 합니다. 캡처 그룹은 캡처할 패턴을 포함하는 소괄호로 정의하며, 전방 탐색 같은 선행 문자가 없습니다.

예를 들어, `/free(code)camp/i`는 `code`를 캡처합니다.

- **비캡처 그룹**: 비캡처 그룹은 캡처 그룹과 비슷하지만, 나중에 사용할 수 있도록 일치한 문자열을 저장하지 않습니다. 비캡처 그룹은 `(?:...)`로 정의합니다.

예를 들어, `/free(?:code)camp/i`는 `code`를 캡처하지 않고 그룹화합니다.

- **백참조**: 정규 표현식에서 백참조는 같은 표현식 내에서 이전에 일치한 패턴의 일부를 재사용하는 방법을 말합니다. 이는 소괄호 안에 있는 캡처 그룹을 번호로 참조할 수 있게 합니다. 예를 들어, `$1`는 첫 번째 캡처 그룹을 가리킵니다.

:::interactive_editor

```js
const regex = /free(co+de)camp/i;
console.log("freecoooooooodecamp".replace(regex, "paid$1world"));
```

:::

- 역참조는 정규식 내에서 백슬래시와 캡처 그룹 번호를 사용해 이전 그룹이 캡처한 동일한 텍스트와 일치시킬 수 있습니다. 예를 들어:

:::interactive_editor

```js
const regex = /(hello) \1/i;
console.log(regex.test("hello hello")); // true
console.log(regex.test("hello world")); // false
```

:::

## JavaScript로 폼 유효성 검사하기

- **제약 조건 유효성 검사 API**: `textarea`와 `input` 같은 특정 HTML 요소는 제약 조건 유효성 검사 API를 노출합니다. 이 API를 사용하면 사용자가 입력한 값이 최솟값 길이나 패턴 일치 같은 HTML 수준의 유효성 검사를 통과하는지 확인할 수 있습니다.
- **`checkValidity()` 메서드**: 이 메서드는 요소가 모든 HTML 유효성 검사(속성에 기반)를 통과하면 `true`를 반환하고, 실패하면 `false`를 반환합니다.

- **`reportValidity()` 메서드**: 이 메서드는 브라우저에 `input`가 유효하지 않다고 알립니다.

- **`validity` 속성**: 이 속성은 `<input>`, `<select>` 등과 같은 폼 컨트롤의 유효성 상태를 가져오는 데 사용되며, 사용자 입력이 해당 요소에 정의된 제약 조건(예: `required` 필드, 패턴 제약, 최대 길이 등)을 충족하는지에 대한 정보를 제공합니다.

- **`patternMismatch` 속성**: 값이 지정된 정규 표현식 패턴과 일치하지 않으면 `true`가 됩니다.

## `preventDefault()` 메서드

- **정의**: DOM에서 발생하는 모든 이벤트는 기본 동작을 가지고 있습니다. 체크박스의 클릭 이벤트는 기본적으로 해당 체크박스의 상태를 전환합니다. 포커스가 있는 버튼에서 <kbd>스페이스바</kbd>를 누르면 버튼이 활성화됩니다. 이러한 `Event` 객체의 `preventDefault()` 메서드는 이러한 기본 동작이 발생하지 않도록 막습니다.

## 폼 제출하기

- **정의**: 폼이 제출되는 방법은 세 가지가 있습니다. 첫 번째는 사용자가 `type` 속성이 `submit`으로 설정된 폼 내 버튼을 클릭할 때입니다. 두 번째는 사용자가 폼 내의 편집 가능한 `input` 필드에서 <kbd>엔터</kbd> 키를 누를 때입니다. 세 번째는 JavaScript에서 `form` 요소의 `requestSubmit()` 또는 `submit()` 메서드를 호출하는 경우입니다.
- **`action` 속성**: `action` 속성은 URL이거나 현재 도메인에 대한 상대 경로를 포함해야 합니다. 이 값은 폼이 데이터를 전송하려는 위치를 결정합니다. `action` 속성을 설정하지 않으면 폼은 현재 페이지의 URL로 데이터를 전송합니다.

- **`method` 속성**: 이 속성은 `HTTP` 메서드(예: `GET`, `POST`)를 받아서 action URL에 요청할 때 해당 메서드를 사용합니다. 메서드가 설정되지 않으면 폼은 기본적으로 `GET` 요청을 사용합니다. 폼의 데이터는 `name=value` 쌍으로 URL 인코딩되어 action URL에 쿼리 매개변수로 추가됩니다.

- **`enctype` 속성**: `form` 요소는 `enctype` 속성을 받아서 데이터를 인코딩하는 방식을 나타냅니다. 이 속성은 세 가지 값만 허용합니다: `application/x-www-form-urlencoded` (기본값으로, 데이터를 URL 인코딩된 폼 본문으로 전송), `text/plain` (데이터를 평문 형태로, `name=value` 쌍을 줄바꿈으로 구분하여 전송), 또는 `multipart/form-data` (파일 업로드가 포함된 폼을 처리할 때 사용).

## `date()` 객체와 자주 쓰이는 메서드

- **정의**: `date()` 객체는 JavaScript에서 날짜와 시간을 생성, 조작, 포맷하는 데 사용됩니다. 예를 들어, `const now = new Date();`는 `Date` 객체의 새 인스턴스를 생성하여 변수 `now`에 할당합니다. `now`의 값을 콘솔에 출력하면 실행 중인 컴퓨터의 시스템 시계 기준 현재 날짜와 시간이 표시됩니다.

- **`Date.now()` 메서드**: 이 메서드는 현재 날짜와 시간을 가져오는 데 사용됩니다. `Date.now()`는 1970년 1월 1일 00:00:00 UTC 이후 경과한 밀리초 수를 반환합니다. 이를 유닉스 에포크 시간이라고 합니다. 유닉스 에포크 시간은 정수로 쉽게 저장하고 조작할 수 있어 컴퓨터 시스템에서 날짜와 시간을 나타내는 일반적인 방식입니다. UTC는 세계가 시계와 시간을 조절하는 기본 시간 표준인 협정 세계시를 뜻합니다.
- **`getDate()` 메서드**: 이 메서드는 현재 날짜를 기준으로 월의 일을 가져오는 데 사용됩니다. `getDate()`는 월의 일에 따라 1부터 31 사이의 정수 값을 반환합니다. 날짜가 유효하지 않으면 `NaN` (숫자가 아님)을 반환합니다.

- **`getMonth()` 메서드**: 이 메서드는 월을 가져오는 데 사용됩니다. 월은 0부터 시작하므로 1월은 0, 2월은 1 등입니다. 예를 들어, 10월 날짜에 `getMonth()`를 호출하면 `9`가 반환됩니다. 월이 유효하지 않으면 `NaN`을 반환합니다.

- **`getFullYear()` 메서드**: 이 메서드는 연도를 가져오는 데 사용됩니다. 연도가 유효하지 않으면 `NaN`를 반환합니다.

## 날짜를 포맷하는 다양한 방법

- **`toISOString()` 메서드**: 이 메서드는 날짜를 확장된 `ISO` (ISO 8601) 형식으로 포맷하는 데 사용됩니다. ISO 8601은 날짜와 시간을 나타내는 국제 표준입니다. 형식은 `YYYY-MM-DDTHH:mm:ss.sssZ`입니다.

- **`toLocaleDateString()` 메서드**: 이 메서드는 사용자의 로케일에 따라 날짜를 포맷하는 데 사용됩니다.

`toLocaleDateString()` 메서드는 두 개의 선택적 매개변수인 locales와 options를 받습니다.

locales 매개변수는 사용할 로케일을 나타내는 문자열입니다. 예를 들어, 영어(미국)를 위해 `"en-US"`를, 프랑스어(프랑스)를 위해 `"fr-FR"`를 전달할 수 있습니다. locales 매개변수를 전달하지 않으면 기본 로케일이 사용됩니다. 두 번째 선택적 매개변수는 options 매개변수입니다. 이 매개변수는 날짜 문자열의 형식을 지정할 수 있는 객체입니다.

## `Audio` 생성자와 공통 메서드

- **정의**: `Audio` 생성자는 다른 생성자들처럼 `new` 키워드로 호출하는 특별한 함수입니다. 이 생성자는 `HTMLAudioElement`를 반환하며, 이를 사용해 사용자를 위해 오디오를 재생하거나 사용자가 직접 제어할 수 있도록 DOM에 추가할 수 있습니다. 생성자를 호출할 때 선택적으로 URL을 (유일한) 인수로 전달할 수 있습니다. 이 URL은 재생하려는 오디오 파일의 소스를 가리켜야 합니다. 또는 소스를 동적으로 변경해야 할 경우, 반환된 오디오 요소의 `src` 속성에 URL을 할당할 수 있습니다.
- **`play()` 메서드**: 이 메서드는 `audio` 또는 `video` 요소와 함께 미디어 재생을 시작하는 데 사용됩니다.

- **`pause()` 메서드**: 이 메서드는 `audio` 또는 `video` 요소와 함께 미디어 재생을 일시 중지하는 데 사용됩니다. 현재 위치를 유지하므로 `play()`이 호출되면 그 위치에서 재생이 시작됩니다.

- **`addTextTrack()` 메서드**: 이 메서드는 미디어 요소와 연결할 텍스트 트랙을 지정할 수 있게 해주며, 특히 비디오에 자막을 추가할 때 유용합니다.
- **`fastSeek()` 메서드**: 이 메서드는 미디어 내 특정 시간으로 재생 위치를 이동할 수 있게 해줍니다.

`Audio()` 생성자는 메서드뿐 아니라 속성도 가지고 있습니다. 그 속성들은 다음과 같습니다:

- `currentTime`: 오디오의 현재 재생 시간을 가져오는 속성
- `loop`: 끝에 도달하면 자동으로 다시 시작하여 오디오를 계속 재생하게 하는 속성
- `muted`: 볼륨 설정과 상관없이 미디어 요소의 오디오 출력을 음소거하는 속성

## 다양한 오디오 및 비디오 포맷

- **MIME 타입**: MIME 타입은 Multipurpose Internet Mail Extensions의 약자로, 프로그래밍적으로 파일 유형을 표준화해 나타내는 방식입니다. MIME 타입은 브라우저 같은 애플리케이션이 특정 파일을 어떻게 처리할지 알려줍니다. 오디오와 비디오의 경우 MIME 타입은 웹 페이지에 임베드할 수 있는 멀티미디어 형식임을 나타냅니다.
- **`source` 요소**: 이 요소는 파일 유형과 소스를 지정하는 데 사용되며, 여러 개의 소스 요소를 사용해 다양한 유형을 포함할 수 있습니다. 이렇게 하면 브라우저가 사용자의 현재 환경에 가장 적합한 포맷을 결정합니다.
- **MP3**: 음악, 오디오 또는 소리를 저장하는 데 사용되는 디지털 파일 형식입니다. 파일 크기를 줄여 저장과 공유를 쉽게 하는 압축된 사운드 녹음 버전입니다. MP3는 가장 넓은 브라우저 지원을 가지며 MIME 타입은 `audio/mpeg`입니다.
- **MP4**: 비디오와 오디오를 저장하는 디지털 파일 형식입니다. 비디오(이미지)와 사운드(음악 또는 음성)를 하나의 파일에 담는 컨테이너 역할을 합니다. MP4는 비디오 파일인지 오디오 전용인지에 따라 MIME 타입이 `audio/mp4` 또는 `video/mp4`일 수 있습니다.
- 그 밖의 포맷으로는 Windows Media Player 앱과 관련된 `WMV`, `OGG`, `MKV`, `AVI` 등이 있습니다.

## 코덱

- **정의**: codec은 "인코더/디코더"의 줄임말로, 아날로그와 디지털 형식 간에 오디오와 비디오를 변환할 수 있는 알고리즘이나 소프트웨어입니다. codec은 MIME 타입의 일부로 지정할 수 있습니다. codec을 정의하는 기본 구문은 미디어 타입 뒤에 세미콜론을 추가한 다음 `codecs=`와 codec을 붙이는 것입니다.

## HTMLMediaElement API

- **정의**: `HTMLMediaElement` API는 페이지의 오디오와 비디오 요소 동작을 제어하는 데 사용됩니다. 기본 `HTMLElement` 인터페이스를 확장하여 기본 속성과 메서드뿐 아니라 `waiting`, `ended`, `canplay`, `canplaythrough` 같은 유용한 이벤트도 사용할 수 있습니다. 메서드 예시로는 `play()`, `fastSeek()`, `pause()`, `canPlayType()`가 있으며, 브라우저가 오디오 파일을 재생할 수 있을지 확인하는 데 사용됩니다.

## 미디어 캡처 및 스트림 API

- **정의**: 미디어 캡처 및 스트림 API, 또는 MediaStream API는 기기에서 오디오와 비디오를 캡처하는 데 사용됩니다. 이 API를 사용하려면 `MediaStream` 객체를 생성해야 합니다. 생성자를 사용해 만들 수도 있지만, 그러면 사용자의 하드웨어와 연결되지 않습니다. 대신 `global` navigator 객체의 `mediaDevices` 속성에는 사용할 수 있는 `getUserMedia()` 메서드가 있습니다.

## 화면 캡처 API

- **정의**: 화면 캡처 API는 사용자의 화면을 녹화하는 데 사용됩니다. 이 API는 `mediaDevices` 객체의 `getDisplayMedia()` 메서드를 호출하고 반환된 미디어 스트림을 사용하여 노출됩니다.

## MediaStream 녹화 API

- **정의**: MediaStream 녹화 API는 MediaStreams API와 함께 작동하여 MediaStream(또는 `HTMLMediaElement` 자체)을 녹화할 수 있게 합니다.

## 미디어 소스 확장 API

- **주제**: Media Source Extensions API는 사용자의 웹캠 피드를 `srcObject` 속성을 통해 비디오 요소에 직접 전달할 수 있게 해줍니다.

## 웹 오디오 API

- **정의**: Web Audio API는 웹에서 들리는 모든 소리를 담당합니다. 이 API에는 오디오 데이터를 담은 버퍼를 나타내는 `AudioBuffer` 같은 중요한 객체와 오디오 처리 그래프를 나타내는 `AudioContext`가 포함되어 있습니다.

## JavaScript의 Set

- `Set`은 데이터 컬렉션을 관리하기 위한 내장 옵션입니다.
- Set은 각 값이 한 번만 나타나도록 보장하여 배열에서 중복을 제거하거나 고유 값 컬렉션을 처리하는 데 유용합니다.
- `Set()` 생성자를 사용해 `Set`을 만들 수 있습니다.

- Set은 다음 메서드로 조작할 수 있습니다:

  - `add()`: `Set`에 새 요소를 추가합니다.
  - `delete()`: `Set`에서 요소를 제거합니다.
  - `has()`: `Set`에 요소가 존재하는지 확인합니다.
  - `clear()`: `Set`의 모든 요소를 제거합니다.
  - `keys()`와 `values()`: 둘 다 `SetIterator`의 값을 포함하는 `Set`를 반환합니다. `keys()`가 `values()`의 별칭이기 때문에 동일합니다.
  - `forEach()`: `Set`의 값을 반복하는 데 사용합니다.

## JavaScript의 Weakset

- `WeakSet`는 약하게 참조된 객체를 저장할 수 있는 객체 모음입니다.

## Sets와 WeakSets의 차이점

- Sets와 달리 `WeakSet`는 숫자나 문자열 같은 원시값을 지원하지 않습니다.
- `WeakSet`는 객체만 저장하며, 그 객체에 대한 참조는 "약한" 참조입니다. 즉, 코드 내 다른 곳에서 해당 객체를 사용하지 않으면 메모리 확보를 위해 자동으로 제거됩니다.

## JavaScript의 맵

- `Map`은 키-값 쌍을 저장하는 내장 객체로, 일반 객체와 비슷하게 동작합니다.
- Map은 표준 JavaScript 객체와 달리, 키로 객체나 함수 등 어떤 타입도 사용할 수 있다는 점이 다릅니다.
- 키-값 쌍을 자주 추가하거나 삭제할 때는 일반 객체보다 `Map`이 더 나은 성능을 제공합니다.
- `Map()` 생성자를 사용해서 `Map`을 만들 수 있습니다.

- 맵은 다음 메서드로 조작할 수 있습니다:

  - `set()`: `Map`에 새 키-값 쌍을 추가합니다.
  - `get()`: `Map`에서 키의 값을 가져옵니다.
  - `delete()`: `Map`에서 키-값 쌍을 제거합니다.
  - `has()`: `Map`에 키가 존재하는지 확인합니다.
  - `clear()`: `Map`의 모든 키-값 쌍을 제거합니다.

맵과 세트 모두 고유한 요소 수를 반환하는 `size` 속성을 가지고 있다는 점에 유의하세요.

## JavaScript의 WeakMap

- `WeakMap`는 `Map`와 마찬가지로 키-값 쌍의 모음이지만, 키에 대한 약한 참조를 가집니다. 키는 반드시 객체여야 하며, 값은 원하는 어떤 것이든 될 수 있습니다.

## Maps와 WeakMaps 비교

- WeakMaps는 WeakSets와 비슷하게 오직 객체만 저장하며, 그 객체에 대한 참조가 "약한" 참조입니다.

## 영구 저장소

- **정의**: 영구 저장소는 전원이 꺼지거나 장치가 재시작된 후에도 데이터가 계속 유지되도록 저장하는 방식을 말합니다.

## 생성, 읽기, 수정, 삭제 (CRUD)

- **생성**: 새로운 데이터를 만드는 과정을 말합니다. 예를 들어, 웹 애플리케이션에서 사용자가 블로그에 새 게시물을 추가할 때가 이에 해당합니다.
- **읽기**: 데이터베이스에서 데이터를 가져오는 작업입니다. 예를 들어, 블로그 게시물을 방문하거나 웹사이트에서 프로필을 볼 때 데이터베이스에 저장된 데이터를 가져와 표시하는 작업입니다.
- **수정**: 데이터베이스에 있는 기존 데이터를 변경하는 작업입니다. 예를 들어, 블로그 게시물을 편집하거나 프로필 정보를 업데이트하는 경우입니다.
- **삭제**: 데이터베이스에서 데이터를 제거하는 작업입니다. 예를 들어, 블로그 게시물이나 계정을 삭제할 때 수행하는 작업입니다.

## HTTP 메서드

- **정의**: HTTP는 하이퍼텍스트 전송 프로토콜로, 웹에서 데이터 통신의 기반이 됩니다. HTTP 메서드는 웹상의 자원에 대해 수행할 수 있는 동작을 정의합니다. 일반적인 메서드는 GET, POST, PUT, PATCH, DELETE입니다.
- **`GET` 메서드**: 서버에서 데이터를 가져오는 데 사용됩니다.
- **`POST` 메서드**: 서버에 데이터를 제출하여 새 자원을 생성하는 데 사용됩니다.
- **`PUT` 메서드**: 자원을 완전히 교체하여 업데이트하는 데 사용됩니다.
- **`PATCH` 메서드**: 자원을 부분적으로 업데이트하는 데 사용됩니다.
- **`DELETE` 메서드**: 데이터베이스에서 레코드를 삭제하는 데 사용됩니다.

## `localStorage`와 `sessionStorage` 속성

- **웹 저장소 API**: 이 API는 브라우저 내에서 키-값 쌍을 저장할 수 있는 메커니즘을 제공하여, 개발자가 페이지 새로 고침이나 세션 간에 사용할 수 있는 정보를 저장할 수 있게 합니다. 웹 저장소 API의 두 가지 주요 컴포넌트는 `localStorage`와 `sessionStorage` 속성입니다.
- **`localStorage` 속성**: `localStorage`은 브라우저 창이 닫히거나 페이지가 새로 고침되어도 데이터가 유지되도록 하는 웹 저장소 API의 일부입니다. 이 데이터는 애플리케이션이나 사용자가 명시적으로 삭제할 때까지 계속 유지됩니다.
- **`localStorage.setItem()` 메서드**: 이 메서드는 `localStorage`에 키-값 쌍을 저장하는 데 사용됩니다.

- **`localStorage.getItem()` 메서드**: 이 메서드는 `localStorage`에서 주어진 키의 값을 가져오는 데 사용됩니다.

- **`localStorage.removeItem()` 메서드**: 이 메서드는 키를 사용하여 `localStorage`에서 특정 항목을 삭제하는 데 사용됩니다.

- **`localStorage.clear()` 메서드**: 이 메서드는 `localStorage`에 저장된 모든 데이터를 지우는 데 사용됩니다.

- **`sessionStorage` 속성**: 현재 세션 동안만 유지되며 브라우저 탭이나 창이 닫히면 지워지는 데이터를 저장합니다.
- **`sessionStorage.setItem()` 메서드**: 이 메서드는 `sessionStorage`에 키-값 쌍을 저장하는 데 사용됩니다.

- **`sessionStorage.getItem()` 메서드**: 이 메서드는 `sessionStorage`에서 주어진 키의 값을 가져오는 데 사용됩니다.

- **`sessionStorage.removeItem()` 메서드**: 이 메서드는 키를 사용하여 `sessionStorage`에서 특정 항목을 삭제하는 데 사용됩니다.

- **`sessionStorage.clear()` 메서드**: 이 메서드는 `sessionStorage`에 저장된 모든 데이터를 지우는 데 사용됩니다.

## 쿠키 다루기

- **정의**: 쿠키는 웹 쿠키 또는 브라우저 쿠키라고도 하며, 서버가 사용자의 웹 브라우저에 보내는 작은 데이터 조각입니다. 이 쿠키들은 사용자의 장치에 저장되고 이후 요청 시 서버로 다시 전송됩니다. 쿠키는 HTTP가 무상태 프로토콜인 상황에서 웹 애플리케이션이 상태를 유지하고 사용자 정보를 기억하는 데 필수적입니다.
- **세션 쿠키**: 이 쿠키는 사용자가 웹사이트에서 활동하는 세션 동안만 유지됩니다. 사용자가 브라우저나 탭을 닫으면 세션 쿠키는 삭제됩니다. 주로 방문 중 로그인 상태 유지 같은 작업에 사용됩니다.
- **보안 쿠키**: 이 쿠키는 HTTPS를 통해서만 전송되어 전송 중 공격자가 가로채지 못하도록 보장합니다.
- **HttpOnly 쿠키**: 이 쿠키는 브라우저에서 실행되는 JavaScript가 접근하거나 수정할 수 없어 교차 사이트 스크립팅(XSS) 공격에 더 안전합니다.
- **Set-Cookie 헤더**: 웹사이트를 방문할 때 서버가 HTTP 응답에 Set-Cookie 헤더를 보낼 수 있습니다. 이 헤더는 브라우저에 특정 정보를 가진 쿠키를 저장하도록 지시합니다. 예를 들어, 다음 방문 시 사용자를 인식하는 데 도움이 되는 고유 ID를 저장할 수 있습니다.
JavaScript에서 쿠키를 수동으로 설정하려면 `document.cookie`를 사용하세요:

```js
document.cookie = "organization=freeCodeCamp; expires=Fri, 31 Dec 2021 23:59:59 GMT; path=/";
```

쿠키를 삭제하려면 만료 날짜를 과거로 설정하면 됩니다.

## 캐시 API

- **정의**: 캐싱은 파일 복사본을 임시 저장소에 저장하여 더 빠르게 접근할 수 있도록 하는 과정입니다. 캐시 API는 네트워크 요청과 응답을 저장하여 웹 애플리케이션이 더 효율적으로 작동하고 오프라인에서도 기능할 수 있게 합니다. 이는 서비스 워커 API의 일부이며, 불안정하거나 느린 네트워크 환경에서 작동하는 프로그레시브 웹 앱(PWA)을 만드는 데 중요합니다.
캐시 API는 Request와 Response 객체를 저장하는 저장소 메커니즘입니다. 서버에 요청을 보낼 때 응답을 저장해 두었다가 나중에 새 네트워크 요청 대신 캐시에서 가져올 수 있습니다. 이를 통해 로드 시간이 줄고 대역폭이 절약되며 사용자 경험이 향상됩니다.
- **캐시 저장소**: HTTP 요청과 해당 응답의 키-값 쌍을 저장하는 데 사용됩니다. 이를 통해 이전에 요청한 자원을 효율적으로 다시 가져올 수 있어, 이후 방문 시 네트워크에서 다시 가져올 필요를 줄이고 성능을 개선합니다.
- **Cache-Control**: 개발자가 캐시된 자원을 얼마나 오래 보관할지, 재검증할지 아니면 캐시에서 바로 제공할지 정의할 수 있습니다.
- **오프라인 지원**: 캐시 API를 사용하면 오프라인 우선 웹 애플리케이션을 만들 수 있습니다. 예를 들어, PWA는 사용자가 네트워크에 연결되어 있지 않을 때 캐시된 자산을 제공할 수 있습니다.

## 부정적 패턴과 클라이언트 측 저장소

- **과도한 추적**: 명확한 동의나 정당한 필요 없이 클라이언트 측 저장소(쿠키, 로컬 저장소, 세션 저장소 등)에 과도한 사용자 데이터를 수집하고 저장하는 행위를 말합니다. 이는 여러 사이트나 세션에 걸쳐 사용자 행동, 선호도, 상호작용을 추적하여 사용자 프라이버시를 침해할 수 있습니다.
- **브라우저 지문 추적**: 쿠키나 전통적 추적 방법 대신 사용자의 장치와 브라우저 고유 특성을 기반으로 개별 사용자를 추적하고 식별하는 기법입니다. 쿠키가 사용자의 장치에 로컬로 저장되는 반면, 지문 추적은 사용자의 브라우저 세션을 구별하는 독특한 "지문"을 만들기 위해 다양한 정보를 수집합니다.
- **로컬 저장소에 비밀번호 저장**: 명백한 부정적 패턴으로 보일 수 있지만, 비밀번호 같은 민감한 데이터를 로컬 저장소에 저장하는 것은 보안 위험이 큽니다. 로컬 저장소는 암호화되지 않고 쉽게 접근할 수 있으므로 민감한 데이터를 절대 저장하지 말아야 합니다.

## IndexedDB

- **정의**: IndexedDB는 브라우저에서 구조화된 데이터를 저장하는 데 사용됩니다. 최신 웹 브라우저에 내장되어 있어 웹 애플리케이션이 JavaScript 객체를 효율적으로 저장하고 가져올 수 있게 합니다.

## 캐시/서비스 워커

- **정의**: 서비스 워커는 웹 페이지와 별도로 백그라운드에서 실행되는 스크립트입니다. 네트워크 요청을 가로채고 캐시에 접근하며 웹 앱이 오프라인에서도 작동하도록 만듭니다. 이는 프로그레시브 웹 앱의 핵심 컴포넌트입니다.

## 클래스 작업의 기본

- **정의**: JavaScript의 클래스는 객체를 생성하고 데이터를 캡슐화하는 청사진을 정의하는 데 사용됩니다. 클래스에는 생성자가 포함되어 있는데, 생성자는 클래스에서 새 객체가 만들어질 때 자동으로 호출되는 특별한 메서드입니다. 생성자는 객체의 프로퍼티를 초기화하는 데 사용됩니다. 여기서 `this` 키워드는 클래스의 현재 인스턴스를 가리키는 데 사용됩니다. 생성자 아래에는 메서드라고 하는 것들이 있을 수 있습니다. 메서드는 클래스 내부에 정의된 함수로, 클래스의 데이터나 상태에 대해 작업이나 동작을 수행합니다. 메서드는 클래스 인스턴스가 수행할 수 있는 동작을 정의하는 데 사용됩니다.

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);  // Gino
```

:::

클래스의 새 인스턴스를 만들려면 `new` 키워드 다음에 클래스 이름을 사용하세요.

클래스를 클래스 표현식으로 만들 수도 있습니다. 이 경우 클래스는 이름이 없고 변수에 할당됩니다.

## 클래스 상속

- **정의**: 프로그래밍에서 상속은 부모 클래스의 프로퍼티와 메서드를 물려받는 클래스를 정의할 수 있게 합니다. 이는 코드 재사용을 촉진하고 클래스 간 계층적 관계를 만듭니다. 부모 클래스는 다른 클래스의 청사진 역할을 하는 클래스로, 다른 클래스가 상속받는 프로퍼티와 메서드를 정의합니다. 자식 클래스는 다른 클래스의 프로퍼티와 메서드를 상속받는 클래스입니다. 자식 클래스는 새로운 프로퍼티와 메서드를 추가해 부모 클래스의 기능을 확장할 수도 있습니다. JavaScript에서는 `extends` 키워드를 사용해 상속을 구현합니다. 이 키워드는 한 클래스가 다른 클래스의 자식 클래스임을 나타냅니다.

`super` 키워드는 부모 클래스의 메서드, 생성자, 필드에 접근할 때 사용합니다.

:::interactive_editor

```js
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  constructor(brand, year, numDoors) {
    super(brand, year);
    this.numDoors = numDoors;
  }
}

const myCar = new Car("freeCodeCamp Motors", 2019, 4);
console.log(myCar.brand);  // freeCodeCamp Motors
console.log(myCar.year);  // 2019
console.log(myCar.numDoors);  // 4
```

:::

## 정적 메서드와 정적 속성 다루기

- **정적 메서드**: 이 메서드는 객체의 특정 상태에 접근할 필요가 없는 유틸리티 함수에 자주 사용됩니다. 관련 기능을 캡슐화하기 위해 클래스 내에 정의합니다.

`static` 키워드를 사용해 정적 메서드를 정의하고 클래스 자체에서 호출하세요.

정적 메서드는 "팩토리" 메서드를 구현할 때도 유용합니다. 팩토리 메서드는 생성자 외에 특정 기준에 따라 객체를 생성하기 위해 정의하는 메서드입니다.

- **정적 속성**: 이 속성은 클래스 자체와 관련된 값이나 속성을 정의하는 데 사용하며, 클래스 인스턴스와는 관련이 없습니다. 정적 속성은 클래스의 모든 인스턴스에서 공유되며, 클래스 인스턴스를 생성하지 않고도 접근할 수 있습니다.

예를 들어, `static numberOfWheels = 4;`는 클래스 내부에 정적 속성을 정의합니다.

- 재귀는 기본 사례에 도달할 때까지 함수를 반복해서 호출할 수 있게 하는 프로그래밍 개념입니다.

다음은 숫자의 팩토리얼을 계산하는 재귀 함수 예시입니다:

```js
function findFactorial(n) {
  if (n === 0) {
    return 1;
  }
  return n * findFactorial(n - 1);
}
```

위 예시에서 `findFactorial` 함수는 `n`이 `0`에 도달할 때까지 재귀적으로 호출됩니다. `n`이 `0`일 때 기본 사례에 도달하여 함수가 `1`를 반환합니다. 그 후 함수는 `n`과 `findFactorial(n - 1)`에 대한 재귀 호출 결과의 곱을 반환합니다.

- 재귀는 깊이가 알 수 없는 중첩 객체/배열이나 파일 트리 같은 구조를 처리할 때 유용합니다.
- 재귀 함수에서는 호출 스택이 함수 호출을 추적하는 데 사용됩니다. 함수가 호출될 때마다 호출 스택에 추가되고, 기본 사례에 도달하면 호출들이 스택에서 제거됩니다.
- 기본 사례를 신중하게 정의해야 합니다. 무한히 호출하면 재귀가 계속 쌓여 시스템 메모리가 부족해져 코드가 중단될 수 있습니다.
- 재귀는 팩토리얼과 피보나치 같은 수학 문제 해결, 트리와 그래프 탐색, 순열과 조합 생성 등 다양한 분야에서 활용됩니다.

## 알고리즘과 빅오 표기법

- **알고리즘**: 문제 해결이나 작업 수행을 위한 명확한 지침 집합입니다. 알고리즘은 유한한 단계 내에 끝나야 하며 각 단계는 정확하고 명확해야 합니다.

- **빅오 표기법**: 입력 크기가 커질 때 알고리즘의 최악 성능 또는 성장률을 나타냅니다. 상수 요소와 낮은 차수 항은 무시하고 입력 크기에 따른 자원 사용 증가에 집중합니다.

### 일반적인 시간 복잡도

- **O(1) - 상수 시간**: 입력 크기와 상관없이 일정한 시간이 걸립니다.

- **O(log n) - 로그 시간**: 입력이 커져도 시간이 천천히 증가합니다. 문제 크기를 반복해서 일정 비율로 줄이는 알고리즘(예: 이진 탐색)에 흔합니다.

- **O(n) - 선형 시간**: 실행 시간이 입력 크기에 비례해 증가합니다.

- **O(n log n) - 로그 선형 시간**: 병합 정렬, 퀵 정렬 같은 효율적인 정렬 알고리즘의 일반적인 시간 복잡도입니다.

- **O(n²) - 이차 시간**: 실행 시간이 제곱에 비례해 증가합니다. 중첩 반복문에서 자주 나타납니다.

### 공간 복잡도

- **O(1) - 상수 공간**: 입력 크기와 상관없이 일정한 메모리를 사용합니다.
- **O(n) - 선형 공간**: 메모리 사용량이 입력 크기에 비례해 증가합니다.
- **O(n²) - 이차 공간**: 메모리 사용량이 제곱에 비례해 증가합니다.

## 문제 해결 기법

- **문제 이해하기**: 문제 설명을 여러 번 읽고, 입력, 예상 출력, 입력을 출력으로 변환하는 방법을 파악하세요.

- **의사 코드**: 언어에 독립적인 알고리즘 논리의 고수준 설명입니다. `IF`, `ELSE`, `FOR`, `WHILE` 같은 프로그래밍 구성 요소와 일반 문자를 혼합해 사용합니다.

- **경계 사례**: 알고리즘이 처리해야 하는 경계에 위치한 특정 유효 입력입니다. 항상 경계 사례를 고려하고 테스트하세요.

## 배열

- **정적 배열**: 초기화 시 크기가 고정됩니다. 요소는 인접한 메모리 위치에 저장되며, 실행 중 크기를 변경할 수 없습니다.

- **동적 배열**: 실행 중 자동으로 크기가 커지거나 작아질 수 있습니다. 필요 시 더 큰 배열로 자동 복사해 크기를 조절합니다.

### JavaScript에서 동적 배열 구현

JavaScript 배열은 동적 배열입니다. 인덱스로 요소에 접근하고 업데이트할 수 있으며, `push()`로 요소를 추가하고 `pop()` 또는 `splice()`로 요소를 제거할 수 있습니다.

### 동적 배열의 시간 복잡도

- **접근**: O(1)
- **끝에 삽입**: 평균 O(1), 크기 조정 시 O(n)
- **중간에 삽입**: O(n)
- **삭제**: 중간 O(n), 끝 O(1)

## 스택

- **스택**: 후입선출(LIFO) 자료 구조입니다. 요소는 오직 맨 위에서 추가되고 제거됩니다.

- **푸시 연산**: 스택 맨 위에 요소를 추가합니다. 시간 복잡도: O(1).

- **팝 연산**: 스택 맨 위에서 요소를 제거합니다. 시간 복잡도: O(1).

JavaScript 배열은 `push()`로 요소를 추가하고 `pop()`으로 제거하여 스택으로 사용할 수 있습니다.

## 큐

- **큐**: 선입선출(FIFO) 자료 구조입니다. 요소는 뒤에서 추가되고 앞에서 제거됩니다.

- **인큐 연산**: 큐 뒤에 요소를 추가합니다. 시간 복잡도: O(1).

- **디큐 연산**: 큐 앞에서 요소를 제거합니다. 시간 복잡도: O(1).

배열은 `push()`로 요소를 큐에 넣고 `shift()`로 꺼내는 큐로 사용할 수 있습니다. 다만 `shift()`는 나머지 요소를 이동해야 하므로 O(n) 시간이 걸립니다.

## 연결 리스트

- **연결 리스트**: 각 노드가 데이터와 다음 노드에 대한 참조를 가지는 선형 자료 구조입니다. 노드들이 체인처럼 연결되어 있습니다.

### 단일 연결 리스트

- **구조**: 각 노드는 데이터와 다음 노드에 대한 하나의 참조를 가집니다.
- **순회**: 머리에서 꼬리 방향으로만 이동할 수 있습니다.
- **머리 노드**: 리스트의 첫 번째 노드로, 보통 직접 접근 가능한 유일한 노드입니다.
- **꼬리 노드**: 리스트의 마지막 노드로, `null`를 가리킵니다.

### 연산과 시간 복잡도

- **처음에 삽입**: O(1)
- **끝에 삽입**: O(n) - 끝까지 순회해야 함
- **중간에 삽입**: O(n) - 위치까지 순회해야 함
- **처음에서 삭제**: O(1)
- **끝에서 삭제**: O(n) - 이전 노드를 찾기 위해 순회해야 함
- **중간에서 삭제**: O(n) - 노드를 찾기 위해 순회해야 함

### 이중 연결 리스트

- **구조**: 각 노드는 데이터와 두 개의 참조(다음 노드, 이전 노드)를 가집니다.
- **순회**: 양방향으로 이동할 수 있습니다.
- **메모리**: 추가 참조 때문에 단일 연결 리스트보다 더 많은 메모리를 사용합니다.

## 각 자료 구조 사용 시기

- **배열(동적 배열)**: 순서가 있고 인덱스로 접근해야 하며 크기를 미리 모를 때
- **스택**: 후입선출 작업(실행 취소 기능, 표현식 평가, 백트래킹)에 적합
- **큐**: 선입선출 작업(작업 스케줄링, 너비 우선 탐색)에 적합
- **연결 리스트**: 처음에서 빈번한 삽입/삭제가 필요하고 크기를 모를 때, 임의 접근이 필요 없을 때

## 검색 알고리즘

검색 알고리즘은 특정 항목 목록 내에서 목표를 검색할 수 있게 합니다.

컴퓨터 과학에서 알아야 할 검색 알고리즘은 두 가지가 있습니다. 바로 **선형 검색**과 **이진 검색** 알고리즘입니다. 두 알고리즘의 차이점과 각각 언제 사용하는지 이해하는 것이 중요합니다.

### 선형 검색

- 선형 검색은 배열의 항목을 처음부터 끝까지 반복하며 목표 항목을 찾을 때까지 확인합니다.
- 목표 항목을 찾으면 배열 내 위치한 인덱스를 반환합니다.
- 목표를 찾지 못하면 `-1`를 반환하는데, 이는 JavaScript에서 **유효하지 않은 인덱스**를 의미합니다.
- 선형 검색은 목표를 찾을 때까지 모든 항목을 확인하기 때문에 큰 배열에서는 효율적이지 않습니다.
- 선형 검색의 시간 복잡도는 `O(n)`인데, 배열 크기에 따라 검색 시간이 선형적으로 증가하기 때문입니다.
- 선형 검색의 공간 복잡도는 `O(1)`인데, 배열을 검색하는 데 추가 공간이 필요하지 않기 때문입니다.

### 이진 검색

- 이진 검색은 배열을 반으로 나누고, 배열 중간에 목표 값이 있는지 확인하는 방식으로 작동합니다.
- 이진 검색이 작동하려면 배열의 항목이 오름차순 또는 내림차순으로 정렬되어 있어야 합니다.
- 이진 검색은 배열을 반으로 나누고 목표가 없는 절반은 무시하기 때문에 큰 배열을 검색할 때 더 효율적인 알고리즘입니다.
- 목표 항목이 배열 중간에 있으면 목표 항목의 인덱스를 반환합니다.
- 항목을 찾지 못하면 알고리즘은 목표 항목이 배열의 왼쪽 절반에 있는지 오른쪽 절반에 있는지 확인합니다.
- 목표 항목을 찾을 때까지 배열의 남은 부분을 계속 반으로 나눕니다.
- 배열에서 목표 항목을 찾지 못하면 `-1`를 반환합니다.
- 이진 검색의 시간 복잡도는 `O(log n)`인데, 배열 크기에 따라 검색 시간이 로그 함수적으로 증가하기 때문입니다.
- 이진 검색의 공간 복잡도는 `O(1)`인데, 배열을 검색하는 데 추가 공간이 필요하지 않기 때문입니다.

### 선형 검색과 이진 검색의 차이점

- 이진 검색은 선형 검색에 비해 큰 배열에 더 적합합니다.
- 선형 검색의 시간 복잡도는 `O(n)`인데, 배열 크기에 따라 검색 시간이 선형적으로 증가하기 때문입니다.
- 이진 검색의 시간 복잡도는 `O(log n)`인데, 배열 크기에 따라 검색 시간이 로그 함수적으로 증가하기 때문입니다.

## 정렬 알고리즘과 분할 정복

컴퓨터 과학에서 분할 정복은 문제를 더 작은 하위 문제로 나누어 해결하기 쉽게 만드는 기법입니다. 재귀는 분할 정복에서 자주 사용되는 기법이며, 분할 정복은 병합 정렬과 같은 효율적인 정렬 알고리즘을 구현하는 강력한 전략입니다.

### 병합 정렬

- 병합 정렬은 분할 정복 방식을 따르는 정렬 알고리즘입니다.
- 배열을 재귀적으로 더 작은 하위 배열로 나누어 각 하위 배열이 하나의 요소만 포함할 때까지 나눕니다.
- 그런 다음 하위 배열들을 정렬된 순서로 반복해서 병합합니다.
- 병합 정렬의 시간 복잡도는 `O(n log n)`인데, 배열을 계속 반으로 나누고 `(log n)` 그다음 병합하기 때문입니다 `(O(n))`.
- 병합 정렬의 공간 복잡도는 `O(n)`인데, 제자리 정렬 알고리즘이 아니기 때문입니다.

## 그래프 개요

그래프는 노드(정점) 집합과 간선(연결)으로 구성됩니다. 각 노드는 여러 다른 노드와 연결될 수 있어 네트워크를 형성합니다. 그래프 유형은 다음과 같습니다:

- **방향 그래프**: 간선이 한 노드에서 다른 노드로 향하는 방향을 가지며, 보통 직선과 화살표로 나타냅니다.
- **무방향 그래프**: 간선에 방향이 없으며, 단순한 선으로 표현됩니다.
- **노드 레이블**: 각 노드가 레이블이나 식별자와 연결되어 있습니다.
- **순환 그래프**: 시작 노드와 끝 노드가 같은 경로(사이클)를 포함합니다.
- **방향 비순환 그래프(DAG)**: 사이클이 없는 방향 그래프입니다.
- **간선 레이블**: 각 간선에 레이블이 붙어 있으며 보통 해당 간선 옆에 표시됩니다.
- **가중치 그래프**: 간선에 산술 연산에 사용할 수 있는 가중치(값)가 할당되어 있습니다.
- **비연결 그래프**: 두 개 이상의 노드 그룹(컴포넌트)이 간선으로 연결되어 있지 않습니다. 두 노드 사이에 직접 간선이 없어도 경로가 있을 수 있습니다.

그래프는 지도, 네트워크, 추천 시스템, 의존성 해결 등 다양한 애플리케이션에서 사용됩니다.

## 그래프 순회

그래프의 모든 노드를 방문하는 작업입니다. 주요 알고리즘 두 가지는:

- **너비 우선 탐색(BFS)**: 그래프에서 다음 레벨로 이동하기 전에 모든 인접 노드를 방문합니다.
  - **큐**: 큐(FIFO)를 사용합니다. 시작 노드를 방문 표시하고 큐에 추가합니다. 큐가 비어 있지 않은 동안 현재 노드를 큐에서 꺼내고, 방문하지 않은 이웃 노드를 방문 표시한 후 큐에 추가합니다.
  - **최단 경로**: 가중치 없는 그래프에서 최단 경로를 찾습니다.
  - **메모리**: 큐를 메모리에 저장해야 하므로, 특히 같은 레벨에 노드가 많을 때 공간 요구량이 클 수 있습니다.
  - **연결 컴포넌트**: 아직 방문하지 않은 각 노드에서 새 탐색을 시작하여 연결된 그래프 컴포넌트를 찾는 데도 사용할 수 있습니다.
  - **상태 공간 탐색**: 괄호 조합을 만들면서 다양한 상태를 추적하기 위해 큐를 사용합니다. 각 상태는 현재 생성 중인 문자열, 지금까지 사용한 여는 소괄호 수, 닫는 소괄호 수를 포함하는 배열로 나타냅니다. 여는 소괄호는 사용한 개수가 쌍의 개수보다 적을 때만 추가할 수 있습니다. 닫는 소괄호는 균형을 유지해야 하므로, 여는 소괄호가 닫는 소괄호보다 많을 때만 추가할 수 있습니다.

- **깊이 우선 탐색(DFS)**: 각 가지를 가능한 깊게 따라간 후 되돌아갑니다.
  - **스택**: 스택(LIFO)이나 재귀를 사용합니다. 시작 노드를 방문 표시하고 스택에 추가합니다. 스택이 비어 있지 않은 동안 현재 노드를 꺼내고, 방문하지 않은 이웃 노드를 방문 표시한 후 스택에 추가합니다.
  - **메모리**: 스택(또는 재귀 호출 스택)을 메모리에 저장해야 하므로, 매우 긴 경로가 있는 그래프에서는 공간 요구량이 커질 수 있습니다.
  - **사용 사례**: 사이클 탐지, 경로 찾기, 연결 컴포넌트 찾기에 유용합니다.
  - **제한점**: 가중치 없는 그래프에서 두 노드 사이의 최단 경로를 항상 찾는 것은 보장되지 않습니다.

## 그래프 표현

그래프는 두 가지 주요 방식으로 표현할 수 있습니다:

- **인접 리스트**: 각 노드는 이웃 노드 목록을 가집니다.
  - **구현 방법**: 배열로 구현할 수 있는데, 각 인덱스가 노드를 나타내고 그 인덱스에 저장된 배열이 이웃 노드를 포함합니다. 객체(또는 `Map`)로 구현할 수도 있는데, 각 키가 노드를 나타내고 그 키에 연결된 값(배열)이 이웃 노드를 포함합니다.
  - **공간**: 희소 그래프에 공간 효율적이며, 공간 복잡도는 `O(V + E)`입니다. 여기서 `V`는 정점(노드) 수, `E`는 간선 수입니다.
  - **이웃 노드**: 노드에 연결된 목록에 접근하기만 하면 되므로 이웃 노드를 순회하기 쉽습니다.
  - **간선 조회**: 두 노드 사이에 간선이 있는지 확인하는 데는 인접 행렬보다 덜 효율적입니다. 일반적으로 `O(deg(v))` 시간이 걸리는데, 여기서 `deg(v)`는 확인하는 노드의 이웃 수이며, 최악의 경우 `O(V)`가 될 수 있습니다.
  - **적합한 경우**: 희소 그래프가 더 흔한 실제 상황에서 보통 선호되는 선택입니다.

- **인접 행렬**: 행과 열이 노드를 나타내는 2차원 배열입니다.
  - **값**: 그래프가 가중치 없으면 `1`은 간선 존재, `0`은 간선 없음입니다. 가중치 그래프면 값이 간선의 가중치를 나타냅니다.
  - **자기 루프**: 대각선 값은 각 노드가 자기 자신과 연결된 간선(자기 루프)이 있는지 나타냅니다.
  - **공간**: 큰 그래프에 대해 공간을 많이 차지하며, 노드 수 `V`에 대해 `O(V²)` 공간 복잡도를 가집니다.
  - **간선 조회**: 두 노드 사이에 간선이 있는지 빠르게 확인할 수 있어 상수 시간 `O(1)`이 걸립니다.
  - **이웃 찾기**: 노드의 이웃을 찾으려면 전체 행이나 열을 순회해야 하므로 비효율적이며, 최악의 경우 `O(V)` 시간이 걸립니다.
  - **적합한 경우**: 간선이 많은 밀집 그래프에 유용하며, 간선이 적은 희소 그래프에는 비효율적입니다.

## 최단 경로 알고리즘

- **최단 경로 알고리즘**: 가중치 그래프에서 노드 간 최단 경로를 계산하고 거리와 경로를 모두 반환합니다.
  - **인접 행렬**: 각 값은 두 노드 간 간선의 가중치(거리)를 나타냅니다.
  - **간선 없음**: `INF`(`Infinity`) 값은 직접 연결된 간선이 없음을 의미합니다.
  - **거리 배열**: 시작 노드에서 다른 모든 노드까지 알려진 최단 거리를 추적하는 배열입니다. 처음에는 모든 노드가 무한대로 가정되고, 시작 노드에서 자기 자신까지 거리는 항상 `0`입니다.
  - **경로 리스트**: 각 항목은 각 노드에 도달하는 경로를 나타내는 노드 인덱스 배열입니다.
  - **방문 배열**: 이미 처리한 노드를 추적하여 중복 방문을 방지합니다.
  - **가장 가까운 미방문 노드**: 메인 루프는 그래프의 각 노드마다 한 번씩 실행되며, 매번 가장 가까운 미방문 노드를 선택합니다.
  - **간선 완화**: 아직 방문하지 않은 실제 간선이 있는 각 이웃에 대해 현재 노드를 통해 더 효율적으로 도달할 수 있는지 확인합니다. 새 거리가 기존 거리보다 좋으면 거리와 경로를 업데이트합니다.
  - **도달 불가능 노드**: 유효한 노드를 찾지 못하면 나머지 노드는 모두 도달 불가능하므로 루프를 조기 종료합니다.
  - **선택적 대상**: `targetNode` 매개변수는 선택 사항입니다. 제공하지 않으면 함수는 `startNode`에서 모든 다른 노드까지 최단 경로를 계산합니다.

## 트리

트리는 사이클이 없고 연결된 특수한 그래프입니다. 주요 속성은:

- **비순환**: 트리는 루프나 사이클(시작 노드와 끝 노드가 같은 경로)이 없습니다.
- **연결됨**: 모든 노드는 다른 모든 노드에서 도달할 수 있습니다.

### 트리 용어

- **루트 노드**: 트리의 가장 상단 노드로, 부모 노드가 없는 유일한 노드입니다.
- **부모 노드**: 바로 아래 노드들과 연결된 노드입니다.
- **자식 노드**: 바로 위 노드와 연결된 노드입니다.
- **잎 노드**: 자식 노드가 없는 노드입니다.
- **깊이**: 루트에서 해당 노드까지의 경로 길이입니다.
- **높이**: 해당 노드에서 잎 노드까지의 경로 길이입니다. 트리의 높이는 루트 노드의 높이입니다.
- **차수**: 각 노드가 가진 자식 노드 수입니다.
- **부분 트리**: 트리의 일부로서 자체가 트리인 섹션입니다.
- **균형 트리**: 어떤 노드의 왼쪽과 오른쪽 부분 트리 높이가 매우 비슷하여 연산이 효율적으로 유지되는 트리입니다.

### 일반적인 트리 유형

가장 일반적인 트리 유형은:

- **이진 트리**: 각 노드가 최대 두 개의 자식, 왼쪽과 오른쪽 자식을 가집니다.

- **이진 탐색 트리(BST)**: 각 노드에 대해 왼쪽 부분 트리의 모든 값은 노드 값보다 작고, 오른쪽 부분 트리의 모든 값은 노드 값보다 큰 이진 트리입니다. 왼쪽과 오른쪽 부분 트리도 각각 이진 탐색 트리여야 합니다.

- **자기 균형 트리**: 삽입이나 삭제로 균형이 깨질 때 내부 로직으로 트리를 재균형하는 트리입니다. 대표적인 예로 AVL 트리, 레드-블랙 트리, B-트리가 있습니다.

- **AVL 트리**: 어떤 노드의 왼쪽과 오른쪽 부분 트리 높이 차이가 최대 1인 자기 균형 이진 탐색 트리입니다.

- **레드-블랙 트리**: 각 노드가 빨간색 또는 검은색으로 색칠된 자기 균형 이진 탐색 트리입니다.

- **B-트리**: 각 노드가 여러 키와 두 개 이상의 자식 노드를 가질 수 있는 자기 균형 트리입니다.

## 트라이

- **트라이**: 접두사 트리라고도 하며, 각 노드가 문자를 나타내는 문자열 집합을 저장하는 데 사용됩니다.
- **루트 노드**: 특정 문자를 나타내지 않으며, 빈 문자열을 나타낸다고 생각할 수 있습니다.
- **접두사**: 루트에서 트라이를 따라 내려가면서 노드까지의 경로가 특정 접두사를 정의합니다.
- **단어 끝 표시**: 완전한 단어를 나타내는 노드에 단어 끝 표시가 할당됩니다.
- **공유 접두사**: 여러 문자열이 같은 접두사를 공유하면 경로가 겹쳐 접두사가 한 번만 저장되어, 자동 완성이나 맞춤법 검사에 효율적입니다.
- **삽입**: 트라이에 없는 문자에 대해서만 새 노드를 생성하면 됩니다.
- **시간 복잡도**: 검색과 삽입 연산은 문자열 길이 `L`에 대해 `O(L)` 시간이 걸립니다.
- **메모리**: 문자열 집합에 고유 문자가 많으면 각 문자를 개별 노드로 저장해야 하므로 비효율적일 수 있습니다.

## 우선순위 큐

- **우선순위 큐**: 각 요소가 우선순위를 가지는 추상 자료형입니다.
- **큐와 스택**: 큐와 스택은 삽입 순서만 고려하지만, 우선순위 큐는 요소의 우선순위를 고려합니다. 표준 큐는 FIFO(선입선출), 스택은 LIFO(후입선출)를 따릅니다.
- **제거 순서**: 보통 가장 높은 우선순위 요소가 먼저 제거되지만, 일부 구현은 가장 낮은 우선순위 요소를 먼저 제거할 수도 있습니다.
- **동점 처리**: 같은 우선순위 요소를 삽입 순서대로 제거하려면 고유 카운터를 포함해 동점을 깨뜨릴 수 있습니다.
- **애플리케이션**: 두 위치 간 최단 경로 찾기, 운영체제 작업 스케줄링, 교통 시뮬레이션, 데이터 압축, 네트워크 관리 등에 사용됩니다.

## 힙

힙은 힙 속성이라는 매우 특정한 속성을 가진 특수한 트리 기반 자료 구조입니다.

힙 속성은 부모 노드와 자식 노드 간의 관계를 결정합니다. 힙에는 두 가지 유형이 있습니다:

- **최대 힙**: 각 부모 노드 값이 자식 노드 값보다 크거나 같으며, 가장 큰 요소가 루트에 있습니다.

- **최소 힙**: 각 부모 노드 값이 자식 노드 값보다 작거나 같으며, 가장 작은 요소가 루트에 있습니다.

JavaScript에는 내장 힙 모듈이 없지만, 배열을 사용해 최소 힙을 구현할 수 있습니다.

- **배열 저장**: 힙은 보통 부모와 자식 노드에 효율적으로 접근하기 위해 배열로 구현됩니다. 힙이 완전 이진 트리 구조를 유지하면, 배열 인덱스를 기반으로 간단한 산술 연산만으로 요소 위치를 찾을 수 있습니다.
- **인덱스**: 인덱스 `i`에 있는 노드의 부모는 `Math.floor((i - 1) / 2)`에, 왼쪽 자식은 `2 * i + 1`에, 오른쪽 자식은 `2 * i + 2`에 있습니다.
- **Peek**: 힙 속성에 따라 최소값 또는 최대값을 제거하지 않고 얻습니다.
- **Push**: 힙 속성을 유지하기 위해 적절한 위치에 요소를 추가합니다. 새 요소는 배열 끝에 추가된 후 부모와 자리를 바꾸며 위로 올라갑니다(버블업).
- **Pop**: 가장 우선순위가 높은 요소(여기서는 가장 작은 값)를 제거합니다. 배열의 마지막 요소가 루트를 대체하고, 더 작은 자식과 자리를 바꾸며 아래로 내려갑니다(버블다운).
- **PushPop**: 두 연산을 하나로 합친 호출로, 특히 힙이 클 때 각각 호출하는 것보다 효율적이며 재정렬 작업을 한 번만 수행합니다.
- **Heapify**: 기존 배열을 힙으로 변환합니다.
- **비교 콜백**: JavaScript에서 배열은 자동으로 요소별 비교를 하지 않으므로, 우선순위를 먼저 비교하는 비교 함수를 힙에 전달합니다. 예: `[priority, element]`로 저장된 항목에 대해 `new MinHeap((a, b) => a[0] - b[0])`. 낮은 값이 더 높은 우선순위를 나타냅니다.
- **안정적 동점 처리**: 각 항목의 두 번째 요소로 증가하는 삽입 카운터를 포함합니다: `[priority, counter, element]`. 우선순위를 먼저 비교하고, 우선순위가 같으면 카운터를 비교합니다: `new MinHeap((a, b) => (a[0] - b[0]) || (a[1] - b[1]))`.
- **시간 복잡도**: 최소 또는 최대값 삽입과 추출은 `O(log n)`, peek는 `O(1)`, heapify는 `O(n)`, 임의 요소 검색 또는 삭제는 `O(n)`입니다.
- **공간 복잡도**: 힙에 포함된 요소 수 `n`에 대해 `O(n)`입니다.

## 동적 프로그래밍 소개

- **정의**: 복잡한 문제를 더 단순한 하위 문제로 나누고, 중복 계산을 피하기 위해 결과를 저장하는 알고리즘 기법입니다.
- **중복 하위 문제**: 큰 문제를 풀 때 같은 작은 문제가 여러 번 나타납니다. 이를 반복 계산하지 않고 결과를 저장합니다.
- **최적 부분 구조**: 문제의 최적 해가 하위 문제의 최적 해를 포함합니다. 즉, 작은 문제의 최적 해를 결합해 전체 최적 해를 만듭니다.

## 동적 프로그래밍 해법

- **메모이제이션(탑다운 방식)**: 비용이 큰 함수 호출 결과를 저장해 같은 입력이 다시 오면 저장된 결과를 반환합니다.

- **테이블화(바텀업 방식)**: 하위 문제부터 차례로 해결해 표에 결과를 채워가며 해를 만듭니다.

## 동적 프로그래밍을 활용한 실제 애플리케이션

- **라우트 최적화**: GPS 시스템은 동적 프로그래밍 알고리즘을 사용해 위치 간 최단 경로를 찾습니다.
- **텍스트 처리**: 맞춤법 검사기와 자동 완성 기능은 단어 간 편집 거리를 계산할 때 동적 프로그래밍에 의존하는 경우가 많습니다.
- **금융 모델링**: 투자 전략과 포트폴리오 최적화에 동적 프로그래밍 기법이 자주 활용됩니다.
- **자원 할당**: 배낭 문제와 그 변형은 일정 관리, 예산 편성, 자원 관리에 나타납니다.

## 동적 프로그래밍을 사용해야 할 때

다음과 같은 상황에서 동적 프로그래밍 사용을 고려하세요:

- 문제를 겹치는 하위 문제로 나눌 수 있을 때
- 문제에 최적 부분 구조가 있을 때
- 단순 재귀 해결법이 반복 계산을 포함할 때
- 공간 복잡도를 희생해서라도 시간 복잡도를 최적화해야 할 때

## 순수 함수와 비순수 함수

- 순수 함수는 같은 입력에 대해 항상 같은 출력을 내고 부작용이 없는 함수입니다. 출력은 오직 입력에만 의존하며 외부 상태를 변경하지 않습니다.
- 비순수 함수는 부작용이 있는데, 이는 함수 외부에서 관찰할 수 있는 프로그램 상태의 변화를 의미합니다.

## 함수형 프로그래밍

- 함수형 프로그래밍은 문제 해결을 위해 함수를 사용하는 소프트웨어 개발 접근법으로, 어떻게 할 것인가보다 무엇을 할 것인가에 집중합니다.
- 함수형 프로그래밍은 불변 자료 구조와 고차 함수 사용처럼 부작용을 피하는 기법을 장려합니다.
- 올바르게 사용하면 함수형 프로그래밍 원칙은 더 깔끔하고 유지보수하기 쉬운 코드를 만듭니다.

## 커링

- 커링은 여러 인수를 받는 함수를 각각 하나의 인수만 받는 함수들의 수열로 변환하는 함수형 프로그래밍 기법입니다.

예를 들어, 커링은 `average(a, b, c)` 호출을 `curriedAverage(a)(b)(c)`와 같은 연속 호출로 바꿉니다.

- 커링은 인수가 많은 함수와 작업할 때 특히 강력합니다.
- 커링은 코드를 더 유연하고 재사용하기 쉽게 만듭니다.
- 화살표 함수를 사용하면 커링 함수를 더 간결하게 만들 수 있습니다:

```js
const curriedAverage = a => b => c => (a + b + c) / 3;
```

- 커링은 코드를 더 유연하고 재사용 가능하게 만들지만, 과도하게 사용하면 코드를 읽기 어렵게 만들 수도 있습니다.

- **동기 JavaScript**는 순차적으로 실행되며 이전 작업이 끝날 때까지 다음 작업으로 넘어가지 않고 기다립니다.
- **비동기 JavaScript**는 메인 스레드를 막지 않고 여러 작업을 백그라운드에서 동시에 실행할 수 있게 합니다.
- **스레드**는 메인 프로그램 흐름과 독립적으로 실행할 수 있는 명령어 수열입니다.
- **콜백 함수**는 다른 함수에 인수로 전달되어 작업이 완료되거나 이벤트가 발생한 후 실행되는 함수입니다.

## JavaScript 엔진과 JavaScript 런타임

- **JavaScript 엔진**은 웹 브라우저에서 JavaScript 코드를 실행하는 프로그램입니다. 코드를 컴퓨터가 이해하고 처리할 수 있는 명령어로 변환하는 변환기 역할을 합니다.
- V8은 구글에서 개발한 JavaScript 엔진의 예입니다.
- **JavaScript 런타임**은 JavaScript 코드가 실행되는 환경으로, 코드를 처리하고 실행하는 JavaScript 엔진과 웹 브라우저 또는 Node.js 같은 추가 기능을 포함합니다.

## Fetch API

- Fetch API는 웹 앱이 네트워크 요청을 하도록 해주며, 주로 서버에서 데이터를 가져오거나 보내는 데 사용합니다. 이 요청을 만들 때 사용할 수 있는 `fetch()` 메서드를 제공합니다.
- Fetch API를 사용해 텍스트, 이미지, 오디오, JSON 및 기타 여러 유형의 데이터를 가져올 수 있습니다.

## Fetch API의 HTTP 메서드

Fetch API는 서버와 상호작용하기 위해 다양한 HTTP 메서드를 지원합니다. 가장 일반적인 메서드는 다음과 같습니다:

- **GET**: 서버에서 데이터를 가져올 때 사용합니다. 기본적으로 Fetch API는 데이터를 가져오기 위해 `GET` 메서드를 사용합니다.

가져온 데이터를 사용하려면 `.json()` 메서드를 사용해 JSON 형식으로 변환해야 합니다:

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
```

이 코드에서 `fetch()`는 프로미스를 반환하며, `.then()` 핸들러가 이행된 응답을 JSON 형식으로 변환합니다.

- **POST**: 서버에 데이터를 보낼 때 사용합니다. `POST` 메서드는 서버에 새 리소스를 생성할 때 사용합니다.

```js
fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Doe',
    email: 'john@example.com'
  })
})
```

이 예제에서는 새 사용자를 생성하기 위해 `POST` 요청을 보내고 있습니다. 메서드를 `POST`로 지정하고, 적절한 헤더를 설정했으며, 전송할 데이터를 포함한 본문을 추가했습니다. 본문은 문자열이어야 하므로, 객체를 JSON 문자열로 변환하기 위해 `JSON.stringify()`를 사용합니다.

- **PUT**: 서버의 데이터를 업데이트할 때 사용합니다. `PUT` 메서드는 서버의 기존 리소스를 업데이트할 때 사용합니다.

업데이트할 때는 `method: 'PUT'`을 지정하고 요청 본문에 업데이트할 데이터를 포함하세요. URL은 업데이트할 리소스를 식별합니다.

- **DELETE**: 서버의 데이터를 삭제할 때 사용합니다. `DELETE` 메서드는 서버의 리소스를 삭제할 때 사용합니다.

`method: 'DELETE'`를 지정하고 삭제할 리소스를 식별하는 URL을 사용하세요.

## 프로미스와 프로미스 체이닝

- **프로미스**는 비동기 작업의 최종 완료 또는 실패와 그 결과 값을 나타내는 객체입니다. 프로미스의 값은 비동기 작업이 완료되어야만 알 수 있습니다.
- 간단한 프로미스를 만드는 예는 다음과 같습니다:

```js
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```

- `.then()` 메서드는 프로미스가 이행되었을 때 실행할 작업을 지정하는 데 사용되고, `.catch()`는 발생한 오류를 처리하는 데 사용됩니다.

- **프로미스 체이닝**: 프로미스의 강력한 기능 중 하나는 여러 비동기 작업을 연속으로 연결할 수 있다는 점입니다. 각 `.then()`은 새 프로미스를 반환할 수 있어 비동기 작업을 순차적으로 수행할 수 있습니다.

`catch` 메서드는 이 과정에서 발생하는 모든 오류를 처리합니다. 따라서 각 단계마다 오류 처리를 추가할 필요가 없어 코드가 훨씬 간단해집니다.

## 프로미스를 처리하기 위해 `async/await` 사용하기

`async`/`await`는 프로미스를 기반으로 하여 비동기 코드를 더 쉽게 작성하고 읽을 수 있게 합니다.

- **async**: `async` 키워드는 비동기 함수를 정의할 때 사용합니다. `async` 함수는 프로미스를 반환하며, 이 프로미스는 `async` 함수에서 반환된 값으로 해결됩니다.
- **await**: `await` 키워드는 `async` 함수 내부에서만 사용할 수 있으며, 프로미스가 해결될 때까지 함수의 실행을 일시 중지합니다. 반드시 `async` 함수 안에서만 사용할 수 있습니다.

- `async/await`의 가장 큰 장점 중 하나는 `try/catch` 블록을 통한 오류 처리입니다. 예시는 다음과 같습니다:

```js
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

fetchData();
```

위 예시에서 `try` 블록은 오류를 발생시킬 수 있는 코드를 포함하고, `catch` 블록은 오류가 발생할 경우 이를 처리합니다. 이로 인해 오류 처리가 더 명확하고 읽기 쉬워집니다.

## `async` 속성

- `async` 속성은 브라우저가 HTML 문서 파싱을 계속하는 동안 스크립트 파일을 비동기적으로 다운로드하도록 지시합니다.
- 스크립트가 다운로드되면 HTML 파싱이 일시 중지되고 스크립트가 실행된 후 다시 HTML 파싱이 재개됩니다.
- 실행 순서가 중요하지 않은 독립적인 스크립트에는 `async`를 사용하세요.

## `defer` 속성

- `defer` 속성도 스크립트를 비동기적으로 다운로드하지만, HTML 문서가 완전히 파싱된 후에 스크립트 실행을 연기합니다.
- `defer` 스크립트는 HTML 문서에 나타난 순서대로 실행 순서를 유지합니다.

- `async`와 `defer` 속성은 인라인 스크립트에는 무시되고 외부 스크립트 파일에만 작동한다는 점이 중요합니다.

- `async`와 `defer` 속성이 모두 있을 때는 `async` 속성이 우선합니다.

## Geolocation API

- 위치 정보 API는 웹사이트가 사용자의 위치를 요청할 수 있는 방법을 제공합니다.

- 아래 예제는 사용자의 현재 위치를 얻기 위해 API의 `getCurrentPosition()` 메서드를 사용하는 방법을 보여줍니다.

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

이 코드에서는 `getCurrentPosition`을 호출하고, 위치가 성공적으로 얻어지면 호출될 함수를 전달합니다.

`position` 객체에는 다양한 정보가 포함되어 있지만 여기서는 `latitude`과 `longitude`만 선택했습니다.

`position`를 가져오는 데 문제가 있으면 오류가 콘솔에 기록됩니다.

- 사용자의 프라이버시를 존중하여 필요한 경우에만 위치를 요청하는 것이 중요합니다.
