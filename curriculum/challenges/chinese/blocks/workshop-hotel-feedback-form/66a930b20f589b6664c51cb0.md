# --description--

`type` 属性告诉浏览器 `input` 应该接受哪种类型的数据。`type` 属性的一些常见值有：

- `text`：单行文本字段
- `email`：检查用户输入是否为有效电子邮件地址的文本字段
- `number`：数字字段
- `radio` 和 `checkbox`：用户可以选择的选项

这是一个文本输入的示例：

```html
<input type="text">
```

为现有的 `input` 元素添加一个 `type` 属性，设置为 `"text"`。

还要为 `input` 元素添加一个 `id` 属性，值为 `"full-name"`。这与你的 `label` 元素上的 `for` 属性匹配，将两者连接起来。

当用户提供他们的全名时，`input` 将接受纯文本。

# --hints--


```js

assert.strictEqual(input?.getAttribute('type'), 'text');
```

你的 `input` 元素应该有一个 `id` 属性，值为 `"full-name"`。

```js

assert.strictEqual(input?.getAttribute('id'), 'full-name');
```
