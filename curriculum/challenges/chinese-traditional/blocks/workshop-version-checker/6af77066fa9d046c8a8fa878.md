# --description--

如果已安裝的版本不是最新的，你的函式應該說明可用的是哪一種更新。當主要版本號不同時，表示是重大更新。這代表新版包含了可能無法與舊版相容的大幅變更。

你可以用索引 `0` 來存取版本的主要版本號。新增一個 `if` 述語，檢查 `installed` 的主要版本號是否小於 `latest` 的主要版本號。如果是，創建一個名為 `update_type` 的變數，並將字串 `major update` 指定給它。

# --hints--

def check_for_update(installed, releases):
    sorted_releases = tuple(sorted(releases, reverse=True))
    latest = sorted_releases[0]

    if installed not in releases:
        return 'not a known release', latest

    if installed == latest:
        return 'up to date', latest
