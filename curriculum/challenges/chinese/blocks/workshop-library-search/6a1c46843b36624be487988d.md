# --description--

现在你需要处理潜在的问题。如果用户点击“查找”按钮时没有在输入字段中输入任何内容，会怎样？

目前，这个函数会接受那个空字串并返回`" is available to borrow!"`。这并没有什么帮助。

在这种情况下，你可以使用`throw`关键字来抛出一个`new Error()`，并停止函数执行。例如：

```js
throw new Error("Your error message goes here");
```

在成功的`return`语句之前，添加一个`if`语句，检查`title`参数是否严格相等于空字串（`""`）。

在`if`语句内部，使用`throw`关键字抛出一个`new Error()`。
将精确的字串`"Search field cannot be empty"`传入`Error`构造函数。

**注意：** 写完这段代码后，如果你点击查找按钮，屏幕上不会显示任何内容！这个错误会阻止点击处理程序继续执行，因为还没有任何地方捕获它。你将在接下来的几个步骤中修复它。不过你现在可以查看控制台确认代码是否有效。
