# --description--

现在将每个程序存储在 `programsById` 中，以其自身的 id 作为键。

存储的程序应保留其原有属性，并添加一个新的 `departmentId` 属性，将其与所属部门关联。对象展开语法（`...`）会将对象自身的可枚举属性复制到一个新对象中，你可以在其中添加额外的属性。

首先从你的代码中删除 `console.log(program)` 这一行。

然后，将一个展开了 `program` 并添加了 `departmentId` 的对象赋值给 `programsById[program.id]`。

最后，将 `programsById[program.id]` 记录到控制台，以检查存储的对象。
