# --description--

الآن بعد أن أصبح لديك فهم أساسي عن المصفوفات، دعنا نتحدث عن الحلقات. تُستخدم الحلقات لتنفيذ كتلة من الكود عدة مرات. واحدة من هذه الحلقات هي حلقة `while`. تنفذ حلقة `while` كتلة الكود طالما أن الشرط صحيح. صيغة حلقة `while` هي كما يلي:

```javascript
while (condition) {
  // code block to be executed
}
```

على سبيل المثال، يطبع مقتطف الكود التالي الأرقام من 1 إلى 5:

```javascript
let i = 1;
while (i <= 5) {
  console.log(i);
  i++;
}
```

يقوم مقتطف الكود أعلاه بتهيئة متغير `i` بالقيمة `1`. تنفذ حلقة `while` كتلة الكود طالما أن قيمة `i` أقل من أو تساوي `5`. تُزاد قيمة `i` بمقدار `1` في كل تكرار.
