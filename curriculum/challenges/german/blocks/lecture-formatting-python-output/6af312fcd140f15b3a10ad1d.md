# --description--

In einer vorherigen Lektion zu Zahlen und mathematischen Operationen haben Sie eine Formatangabe wie `.2f` in einem f-String verwendet, um zu steuern, wie viele Dezimalstellen eine Zahl anzeigt.

Formatangaben können auch steuern, wie viel Platz ein Wert einnimmt und wo er sitzt. Das ist nützlich, wenn Sie möchten, dass die Ausgabe in ordentlichen Spalten ausgerichtet ist.

## Festlegen einer Mindestbreite und Ausrichtung

Eine Zahl nach dem Doppelpunkt legt die Mindestbreite des Feldes fest, also die Anzahl der Zeichen, die der Wert einnehmen soll. Wenn der Wert kürzer ist, fügt Python Leerzeichen hinzu, bis die Breite erreicht ist. Hier ist ein Beispiel:

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

Bestimmte Symbole vor der Breite steuern, wo der Wert im Feld sitzt. Hier sind diese Symbole:

- Weniger als (`<`) richtet den Wert linksbündig aus
- Größer als (`>`) richtet den Wert rechtsbündig aus
- Caret (`^`) zentriert den Wert.

Hier sind diese drei Symbole in Aktion:

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

`'Tea'` enthält drei Zeichen, also fügt Python fünf Leerzeichen hinzu, um eine Breite von `8` zu erreichen.

- Bei `<` kommen die Leerzeichen nach dem Wert
- Bei `>` kommen die Leerzeichen vor den Wert
- Bei `^` werden die Leerzeichen auf beide Seiten verteilt, um den Text zu zentrieren.

Wenn der Platz nicht gleichmäßig aufgeteilt werden kann, kommt das zusätzliche Leerzeichen rechts:

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

Wenn Sie das Ausrichtungssymbol weglassen, sind Strings standardmäßig linksbündig ausgerichtet, während Zahlen rechtsbündig sind:

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## Verwendung eines Füllzeichens

Standardmäßig füllt Python mit Leerzeichen. Um ein anderes Zeichen für den Innenabstand zu verwenden, fügen Sie das Zeichen direkt vor das Ausrichtungssymbol ein:

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

In `*^9` ist `*` das Füllzeichen, `^` zentriert den Wert, und `9` ist die Mindestbreite. Beachten Sie, dass Sie ein Füllzeichen nur zusammen mit einem Ausrichtungssymbol verwenden können.

## Kombination von Breite und Genauigkeit

Sie können Ausrichtung und Breite mit der Genauigkeit kombinieren, die Sie in der vorherigen Lektion gelernt haben, alles in einer Formatangabe:

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

Die Formatangabe im obigen Beispiel bedeutet: rechtsbündig ausrichten, eine Mindestbreite von `7` verwenden und zwei Dezimalstellen anzeigen. Python formatiert die Zahl zuerst als `4.50`, was vier Zeichen lang ist, und fügt dann drei Leerzeichen davor hinzu, um die Breite von `7` zu füllen.

## Erstellen einer Zeile mit Bezeichnung und Betrag

Sie können eine Bezeichnung und einen Betrag zusammen in einer Zeile darstellen. Wenn Sie für jede Zeile dieselbe Formatangabe verwenden, richten sich die Spalten aus:

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

Jede Bezeichnung ist linksbündig in einem Feld von `12` Zeichen und mit Punkten gefüllt, während jeder Betrag rechtsbündig in einem Feld von `8` Zeichen ist, sodass die Dezimalpunkte ausgerichtet sind.

## Breite ist ein Minimum, kein Maximum

Die Breite fügt nur Innenabstand hinzu. Sie kürzt einen Wert niemals. Wenn der Wert länger als die angegebene Breite ist, wird der gesamte Wert angezeigt:

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

Das gilt auch für Zahlen. Im folgenden Beispiel benötigt der formatierte Betrag acht Zeichen, daher ignoriert er die angegebene Breite von `7`:

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

In `:7.2f` ist die `7` eine Mindestbreite, keine Begrenzung, wie lang der Betrag sein darf. Python schneidet niemals Ziffern ab, um eine Zahl passend zu machen.

Deshalb sollten Sie Breiten wählen, die groß genug für die erwarteten Werte sind, sonst richten sich die Spalten nicht aus.

Wenn Sie die Länge eines Strings begrenzen möchten, fügen Sie der Formatangabe eine Genauigkeit hinzu. Bei Strings legt die Genauigkeit die maximale Anzahl der anzuzeigenden Zeichen fest:

```py
label = 'Long description'

print(f'|{label:.8}|') # |Long des|
print(f'|{label:<12.8}|') # |Long des    |
```

In `<12.8`:

- `<` richtet den Wert linksbündig aus
- `12` ist die Mindestbreite
- `.8` ist die maximale Anzahl der Zeichen.

Python kürzt den String zuerst auf acht Zeichen und füllt ihn dann auf eine Breite von zwölf auf.

Beachten Sie, dass Genauigkeit bei Strings etwas anderes bedeutet als bei Zahlen. Bei `.2f` legt `.2` die Anzahl der Dezimalstellen fest. Bei einem String legt `.8` die maximale Anzahl der Zeichen fest.
