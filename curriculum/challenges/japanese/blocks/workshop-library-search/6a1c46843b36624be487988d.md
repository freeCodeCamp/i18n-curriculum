# --description--

次に、潜在的な問題に対処する必要があります。ユーザーが入力フィールドに何も入力せずに「Search」ボタンをクリックしたらどうしますか？

現在、その関数は空の文字列を受け取り、`" is available to borrow!"` を返しています。これはあまり役に立ちません。

このような場合、`throw` キーワードを使って `new Error()` をスローし、関数の実行を停止できます。例えば：

```js
throw new Error("Your error message goes here");
```

成功の `return` 文の前に、`title` パラメータが空の文字列（`""`）と厳密に等しいかどうかをチェックする `if` 文を追加してください。

`if`文の中で、`throw`キーワードを使って`new Error()`をスローしてください。
`Error`コンストラクタには正確に`"Search field cannot be empty"`という文字列を渡してください。

**注意：** これを書いた後に Search ボタンをクリックすると、画面には何も表示されません！エラーがクリックハンドラを停止させるためで、まだそれをキャッチする処理がないからです。これは数ステップ後に修正しますが、今はコンソールを確認してコードが動作していることを確かめてください。

# --hints--

`title` が空の文字列と厳密に等しいかどうかをチェックする `if` 文を作成し、その中で正確に `"Search field cannot be empty"` という文字列を持つ `new Error()` をスローしてください。

```js
assert.throws(() => findBook(""), Error, "Search field cannot be empty");
```

`findBook` 関数は、`"The Hobbit"` を渡して呼び出したときに `"The Hobbit is available to borrow!"` を返す必要があります。

```js
assert.strictEqual(findBook("The Hobbit"), "The Hobbit is available to borrow!");
```
