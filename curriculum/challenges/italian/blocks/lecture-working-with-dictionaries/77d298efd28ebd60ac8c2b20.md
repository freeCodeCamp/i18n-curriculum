# --description--

Hai imparato come creare dizionari e consultare e aggiornare i loro valori. Ora userai i metodi dei dizionari, copierai dizionari ed esplorerai come le funzioni possono modificarli.

Ogni esempio di metodo del dizionario qui sotto inizia con questo dizionario:

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## Metodi del dizionario

I dizionari hanno anche metodi utili per eseguire operazioni comuni.

Il metodo `.get()` recupera il valore associato a una chiave. È simile alla notazione a parentesi che hai imparato nella lezione precedente, ma il suo vantaggio è che puoi impostare un valore predefinito, così non otterrai un errore se la chiave non esiste:

```python
dictionary.get(key, default)
```

In questo esempio, se la chiave `toppings` non esiste, restituirà una lista vuota, che è il valore predefinito che stiamo passando qui come secondo argomento. Ma se `toppings` esiste, restituirà quel valore:

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

I metodi `.keys()` e `.values()` restituiscono un oggetto view con tutte le chiavi e i valori nel dizionario, rispettivamente:

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

Un oggetto view è solo un modo per vedere il contenuto di un dizionario senza creare una copia separata dei dati.

Il metodo `.items()` restituisce un oggetto view con tutte le coppie chiave-valore nel dizionario, includendo sia le chiavi sia i valori:

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

Il metodo `.clear()` rimuove tutte le coppie chiave-valore dal dizionario:

```python
pizza.clear()
```

Il metodo `.pop()` rimuove la coppia chiave-valore con la chiave che specifichi come primo argomento e restituisce il suo valore. Se la chiave non esiste, restituisce il valore predefinito che specifichi come secondo argomento. Se la chiave non esiste e non passi un valore predefinito, viene lanciata un’eccezione `KeyError`:

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

In Python 3.7 e nelle versioni più recenti, il metodo `.popitem()` rimuove l’ultimo elemento inserito:

```python
pizza.popitem()
```

Il metodo `.update()` aggiorna le coppie chiave-valore con le coppie chiave-valore di un altro dizionario. Se hanno chiavi in comune, i loro valori vengono sovrascritti.

In questo esempio, stiamo aggiornando il dizionario `pizza`. La chiave `price` esiste in entrambi, quindi il suo valore sarà sostituito con `15`.

Ma `total_time` è nuova, quindi verrà aggiunta al dizionario `pizza` come nuova coppia chiave-valore:

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

Questo è il nuovo dizionario con `price` aggiornato e la nuova `total_time`. Nota come il prezzo ora è `15` e `total_time` è una nuova coppia chiave-valore:

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### Assegnazione e copie superficiali

Come hai imparato con le liste, assegnare un dizionario a un'altra variabile crea un alias. Entrambi i nomi si riferiscono allo stesso oggetto:

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

Per creare un dizionario esterno separato, usa il metodo `.copy()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

Sostituire un elemento in `copied_settings` non sostituisce l'elemento corrispondente in `settings`. Tuttavia, `.copy()` crea una **copia superficiale**: crea un nuovo dizionario esterno i cui chiavi e valori si riferiscono agli stessi oggetti di quelli nel dizionario originale. Gli oggetti mutabili annidati sono ancora condivisi:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

I due dizionari sono oggetti diversi, ma i loro elementi `languages` si riferiscono alla stessa lista. Aggiungere elementi a quella lista è visibile attraverso entrambi i dizionari. Sostituire `copied_settings['languages']` con una nuova lista cambierebbe invece solo quell'elemento nella copia.

Puoi anche creare una copia superficiale passando un dizionario a `dict()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

Come `.copy()`, `dict(settings)` crea un nuovo dizionario esterno, ma la lista annidata è ancora condivisa. Sostituire un elemento in uno dei due dizionari influenza solo quel dizionario, mentre modificare la lista condivisa è visibile attraverso entrambi.

## Mutare un dizionario tramite un parametro di funzione

Le stesse regole di passaggio degli argomenti che hai imparato con le liste si applicano ai dizionari. Un parametro si riferisce inizialmente all'oggetto passato come argomento. Aggiornare un elemento tramite quel parametro muta il dizionario condiviso:

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

La funzione restituisce una stringa di stato, mentre `preferences` cambia tramite il riferimento condiviso. Restituire un valore e mutare un oggetto sono effetti separati. La funzione non deve restituire il dizionario affinché le modifiche siano visibili all'esterno. Riassegnare il parametro locale a un dizionario diverso non sostituirebbe il dizionario a cui fa riferimento `preferences`.

## Usare un dizionario come argomento predefinito

Ricorda che una lista predefinita viene creata quando la funzione è definita e riutilizzata nelle chiamate che omettono l'argomento. Un dizionario predefinito si comporta allo stesso modo:

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

La seconda chiamata riutilizza il dizionario modificato dalla prima chiamata. Questo significa che le impostazioni si accumulano attraverso chiamate indipendenti, anche se ogni chiamata ha il proprio nome di parametro locale.

Quando ogni chiamata dovrebbe iniziare con un dizionario nuovo, usa il pattern predefinito `None`:

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

Ogni chiamata che omette `settings` o passa `None` crea un dizionario nuovo. Passare un dizionario esistente permette comunque alla funzione di mutare quell'oggetto. Usa `settings is None` qui: `if not settings` corrisponderebbe anche a un dizionario vuoto passato come argomento e lo sostituirebbe con un nuovo dizionario locale.
