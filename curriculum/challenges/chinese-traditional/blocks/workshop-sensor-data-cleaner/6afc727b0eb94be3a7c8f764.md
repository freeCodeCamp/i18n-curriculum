# --description--

`map()` 函式會對可迭代物件的每個項目呼叫一個函式，並傳回結果的迭代器。就像使用 `filter()` 一樣，你可以傳入一個 lambda 函式：

```py
prices = [10, 20, 30]
discounted = list(map(
    lambda price: price * 0.9,
    prices
))
print(discounted) # [9.0, 18.0, 27.0]
```

現在你需要將有效讀數從十分之一度轉換成度。

創建一個名為 `temperatures` 的變數。將傳入 `map()` 的 lambda 函式和 `valid_readings` 的結果，並用 `list()` 包裹後指定給它。lambda 函式應該接受一個名為 `reading` 的參數，並傳回 `reading` 除以 `10` 的結果。

然後，列印 `temperatures`，而不是 `valid_readings`。
