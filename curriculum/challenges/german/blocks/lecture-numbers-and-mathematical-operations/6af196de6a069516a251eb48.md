# --description--

Manchmal ist eine Zahl für Ihre Berechnungen in Ordnung, sieht aber beim Ausgeben etwas unvollständig aus. Wenn Sie zum Beispiel einen Preis anzeigen, wirkt `12.50` natürlicher als `12.5`.

Ein F-String ermöglicht es Ihnen, zu steuern, wie eine Zahl angezeigt wird, ohne den ursprünglichen Wert zu ändern, sodass Sie sie weiterhin in Berechnungen verwenden können.

## Wie Formatangaben funktionieren

Der Ausdruck `f"{value:.2f}"` zeigt `value` mit genau zwei Stellen nach dem Dezimalpunkt an.

Innerhalb der geschweiften Klammern hat jedes Zeichen eine bestimmte Rolle:

- Der Doppelpunkt `:` leitet die Formatangabe ein
- `.2` wählt zwei Dezimalstellen aus
- `f` wählt die Festkommadarstellung, die die Zahl in Dezimalschreibweise anzeigt.

Das bedeutet, dass `print(f"{12.5:.2f}")` `12.50` ausgibt, während der ursprüngliche Wert unverändert bleibt:

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

Die Ausgabe zeigt `12.50`, weil die Formatangabe `.2f` immer zwei Dezimalstellen anzeigt, sodass Python das Ergebnis mit einer nachgestellten Null auffüllt. Der in `value` gespeicherte Wert ist weiterhin `12.5`.


Andererseits erzeugt die Formatierung eines Werts wie `12.3456` mit `.2f` `12.35`, weil die Zahl für die Anzeige gerundet werden muss:

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## Formatieren mit einem F-String erzeugt einen String

Ein F-String erzeugt einen String:

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

Das bedeutet, Sie können den resultierenden String separat speichern und trotzdem die ursprüngliche Zahl in Berechnungen verwenden.

## Wie sich `round()` von der F-String-Formatierung unterscheidet

Ein Ausdruck wie `round(value, 2)` liefert Ihnen ein numerisches Ergebnis, das Sie in weiteren Berechnungen verwenden können.

Die Ausgabe dieses Ergebnisses verwendet die übliche Zahlendarstellung von Python, sodass nachgestellte Nullen nicht garantiert sind:

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## Formatieren ändert den zugrundeliegenden Wert nicht

Wie Sie zuvor gesehen haben, können einige Dezimalzahlen wie `0.1` und `0.2` nur als Fließkommazahlen angenähert werden. Daher kann ihre Summe beim direkten Ausgeben etwas überraschend aussehen:

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

Wie Sie sehen, rundet der F-String die Summe nur für die Anzeige. Jede Berechnung, die `total` verwendet, nutzt weiterhin denselben Fließkommawert.
