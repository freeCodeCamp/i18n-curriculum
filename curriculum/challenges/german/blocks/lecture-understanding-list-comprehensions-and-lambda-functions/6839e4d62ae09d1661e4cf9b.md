# --description--

In den letzten Lektionen haben Sie sich mit Schleifen wie dieser vertraut gemacht:

```py
even_numbers = []

for num in range(21):
    if num % 2 == 0:
        even_numbers.append(num)

print(even_numbers)
```

Dieses Beispiel erstellt eine neue leere Liste namens `even_numbers` und durchläuft eine Folge von Zahlen zwischen `0` und `20`. Innerhalb der Schleife gibt es eine Bedingung, die überprüft, ob die aktuelle Zahl beim Teilen durch `0` einen Rest von `2` hat. Dies wird verwendet, um zu bestimmen, ob die Zahl gerade ist. Wenn die Bedingung `True` ist, wird die aktuelle `num` am Ende der `even_numbers` Liste angehängt. Schließlich geben wir die `even_numbers` Liste in der Konsole aus.

## Was ist List Comprehension?

Obwohl dieser Code funktioniert, gibt es eine prägnantere Möglichkeit, ihn mit List Comprehension zu schreiben. List Comprehension ermöglicht es Ihnen, eine neue Liste in einer einzigen Zeile zu erstellen, indem Sie eine Schleife direkt innerhalb von eckigen Klammern schreiben. Das macht den Code kürzer und oft leichter lesbar.

Die grundlegende Syntax einer List Comprehension sieht so aus:

```py
[expression for item in iterable]
```

Für jedes Element im iterierbaren Objekt wird der Ausdruck vor `for` ausgewertet, und das Ergebnis wird der neuen Liste hinzugefügt. Hier ist ein Beispiel, das eine Liste erstellt, in der jede Zahl von `0` bis `4` mit `2` multipliziert wird:

```py
doubled = [num * 2 for num in range(5)]
print(doubled) # [0, 2, 4, 6, 8]
```

## Filtern mit einem nachgestellten `if`

Optional können Sie am Ende einer List Comprehension eine `if`-Bedingung hinzufügen. Nur die Elemente, für die die Bedingung wahr ist, werden der neuen Liste hinzugefügt, während die anderen übersprungen werden.

Hier ist das Beispiel mit den geraden Zahlen von früher, das mit List Comprehension umgeschrieben wurde:

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

In diesem umgeschriebenen Beispiel wird die `even_numbers` Liste mit nur einer Codezeile erstellt. Die List Comprehension durchläuft Zahlen von `0` bis `20` und schließt nur diejenigen ein, die durch `2` teilbar sind. Dieser Ansatz ist kompakter und eliminiert die Notwendigkeit für eine separate Schleife und einen bedingten Block.

## Erstellen separater innerer Listen

Sie haben zuvor gelernt, dass `[[]] * 3` Referenzen auf eine innere Liste wiederholt. Eine Comprehension kann stattdessen bei jeder Iteration eine separate innere Liste erstellen:

```py
rows = [[] for _ in range(3)]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

Der Ausdruck `[]` wird bei jeder Iteration ausgewertet, sodass jede Position auf eine andere Liste verweist. Die Schleifenvariable wird im Ausdruck nicht verwendet; der Bereich steuert nur, wie viele Listen erstellt werden.

Wenn eine Schleifenvariable nicht benötigt wird, benennen Python-Entwickler sie konventionell `_`, um zu signalisieren, dass ihr Wert absichtlich ignoriert wird. `_` ist trotzdem ein gewöhnlicher Variablenname.

## Verwendung von bedingten Ausdrücken in List Comprehensions

Bisher haben Sie `if` und `else` verwendet, um bedingte Anweisungen zu schreiben. Python hat auch einen bedingten Ausdruck, der in einer einzigen Zeile geschrieben wird und einen Wert liefert. Hier ist seine Syntax:

```py
value_if_true if condition else value_if_false
```

Wenn die Bedingung wahr ist, wird der gesamte Ausdruck zu dem Wert vor `if` ausgewertet. Andernfalls wird er zu dem Wert nach `else` ausgewertet. Hier ist ein Beispiel:

```py
num = 7
label = 'Even' if num % 2 == 0 else 'Odd'
print(label) # Odd
```

Da `7` nicht durch `2` teilbar ist, ist die Bedingung `False`, und `'Odd'` wird der Bezeichnung `label` zugewiesen.

Sie können einen bedingten Ausdruck als Ausdruck vor `for` in einer List Comprehension verwenden. In diesem Fall wird für jedes Element im iterierbaren Objekt ein Wert gewählt, sodass die neue Liste genauso viele Elemente hat wie das Original. Das unterscheidet sich von einem nachgestellten `if`, das Elemente aus der neuen Liste ausschließen kann.

Schauen wir uns ein Beispiel an:

```py
numbers = [1, 2, 3, 4, 5]
result = [(num, 'Even') if num % 2 == 0 else (num, 'Odd') for num in numbers]
print(result)
```

In diesem Beispiel haben wir eine Liste von Zahlen und möchten eine neue Liste von Tuples erstellen, die angeben, welche Zahlen gerade oder ungerade sind. Im ersten Teil der List Comprehension verwenden wir einen `if`/`else`-Bedingungsausdruck, um zu prüfen, ob die Zahl durch `2` teilbar ist. Ist das der Fall, ist das Ergebnis ein Tuple aus dieser Zahl gefolgt vom Wort `Even`. Andernfalls ist das Ergebnis ein Tuple mit der Zahl gefolgt vom Wort `Odd`.

So sieht das Ergebnis aus, wenn es in der Konsole ausgegeben wird:

```py
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

## Listen filtern mit `filter()`

Eine weitere Möglichkeit, eine Liste aus einem bestehenden iterierbaren Objekt zu erstellen, ist die `filter()` Funktion. Hier ist ein Beispiel, wie man eine neue Liste nur mit Wörtern erstellt, die länger als vier Zeichen sind:

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

Die Funktion `filter()` wird verwendet, um Elemente aus einem iterierbaren Objekt auszuwählen, die eine bestimmte Bedingung erfüllen. Die Funktion `filter()` akzeptiert eine Funktion und ein iterierbares Objekt als Argumente. In diesem Beispiel übergeben wir der Funktion `filter()` eine Funktion namens `is_long_word`, um zu prüfen, ob die Anzahl der Zeichen im aktuellen Wort größer als `4` ist. `is_long_word` wird ohne Klammern geschrieben, weil Sie die Funktion selbst übergeben, nicht sie aufrufen. Die Funktion `filter()` ruft `is_long_word` für jedes Wort auf. Wie `zip()` gibt die Funktion `filter()` einen Iterator zurück, der nur die Wörter liefert, die die Bedingung erfüllen. Die Funktion `list()` sammelt diese Wörter in einer neuen Liste, die der Variablen `long_words` zugewiesen wird.

## Listen transformieren mit `map()`

Abgesehen von der `filter()` Funktion gibt es noch einige weitere Funktionen, die bei der Arbeit mit Listen hilfreich sind. Eine weitere Funktion, die Sie kennen sollten, ist die `map()` Funktion, die ein iterierbares Objekt nimmt und eine Funktion auf jedes seiner Elemente anwendet. Hier ist ein Beispiel für die Verwendung der `map()` Funktion, um eine Liste von Temperaturen von Celsius in Fahrenheit umzuwandeln:

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

Genau wie die Funktion `filter()` akzeptiert `map()` eine Funktion und ein iterierbares Objekt als Argumente. Die Funktion `to_fahrenheit` nimmt eine Temperatur und wandelt sie von Celsius in Fahrenheit um. Auch hier wird `to_fahrenheit` ohne Klammern übergeben, und `map()` ruft sie für jede Temperatur in der Liste `celsius` auf. Die Funktion `map()` gibt ebenfalls einen Iterator zurück, diesmal mit den umgerechneten Werten, sodass `list()` erneut verwendet wird, um sie in einer Liste zu sammeln.

## Werte aufsummieren mit `sum()`

Die letzte Funktion, die wir uns ansehen, ist die `sum()` Funktion. Diese Funktion wird verwendet, um die Summe aus einem iterierbaren Objekt wie einer Liste oder einem Tuple zu erhalten. Hier ist ein Beispiel für die Verwendung der `sum()` Funktion:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

Sie können auch ein optionales `start` Argument übergeben, das den Anfangswert für die Summierung festlegt. Hier ist ein aktualisiertes Beispiel, das das `start` Argument als Positionsargument verwendet:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

Sie können auch stattdessen das `start` Argument als Schlüsselwortargument verwenden:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

Beide Versionen liefern dasselbe Ergebnis, aber das Schlüsselwortargument ist etwas expliziter.

List Comprehension sowie andere Funktionen wie `map()`, `filter()` und `sum()` mögen anfangs etwas verwirrend erscheinen. Aber mit genügend Übung und Zeit werden Sie sich wohler fühlen, sie in Ihren Python-Programmen zu verwenden.
