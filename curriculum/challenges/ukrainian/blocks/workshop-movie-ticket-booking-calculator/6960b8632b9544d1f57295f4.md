# --description--

Користувачі, яким принаймні `18` років, але менше ніж `21`, можуть бронювати квитки, але лише коли `show_time` не дорівнює `Evening`.

Оператор нерівності (`!=`) перевіряє, чи два значення не рівні. Він повертає `True`, коли значення різні, і `False`, коли вони однакові:

```py
day = 'Monday'
print(day != 'Sunday') # True
print(day != 'Monday') # False
```

Коли в одному виразі використовуються `and` та `or`, `and` має вищий пріоритет, ніж `or`. Це означає, що умови, з’єднані через `and`, групуються разом, а результат цієї групи потім поєднується з умовою `or`:

```py
has_key = True
knows_code = False
is_daytime = False

print(has_key or knows_code and is_daytime) # True
```

У наведеному вище прикладі спочатку оцінюється `knows_code and is_daytime`, що дає результат `False`. Потім увесь вираз стає `has_key or False`, що дорівнює `True`.

Оновіть умову на лінії `if age >= 21:`. Використайте оператор `and` для створення виразу, який перевіряє, чи `age` більший або дорівнює `18`, і `show_time` не є `Evening`. Потім використайте оператор `or` для поєднання цього виразу з існуючою умовою. Не створюйте нових змінних.
