# --description--

各プログラムをそれぞれのidをキーにして`programsById`に保存してください。

保存されるプログラムは元のプロパティに加えて、その部署を示す新しい`departmentId`プロパティを持つ必要があります。オブジェクトのスプレッド構文（`...`）はオブジェクト自身の列挙可能なプロパティを新しいオブジェクトにコピーし、そこに追加のプロパティを加えられます。

まず、コードから`console.log(program)`の行を削除してください。

次に、`programsById[program.id]`に`program`をスプレッドし、`departmentId`を追加したオブジェクトを代入してください。

最後に、保存されたオブジェクトを確認するために`programsById[program.id]`をコンソールにログ出力してください。
