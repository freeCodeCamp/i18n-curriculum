# --description--

이제 `styles.css` 파일을 링크해서 스타일이 다시 적용되도록 하세요.

`link` 요소는 스타일시트나 사이트 아이콘 같은 외부 리소스에 링크할 수 있게 해줍니다. 외부 CSS를 링크하기 위해 `link` 요소를 사용하는 기본 구문은 다음과 같습니다:

```html
<link rel="stylesheet" href="styles.css" />
```

`rel` 속성은 링크된 리소스와 HTML 문서 간의 관계를 지정합니다. 이 경우, 이 링크된 리소스가 `stylesheet`임을 지정해야 합니다. `href` 속성은 외부 리소스의 위치를 지정합니다.

`head` 요소 안에 `link` 요소를 추가하세요. `rel` 속성에는 `"stylesheet"` 값을, `href` 속성에는 `"styles.css"` 값을 지정하세요.

**참고:** `link` 요소는 닫는 태그가 없는 void 요소입니다. void 요소는 `<element></element>`가 아니라 `<element>` 형태로 작성해야 합니다.

코드에 `link` 요소가 있어야 합니다.

```js
const link = document.querySelector('link');
assert.isNotNull(link);
```

`link` 요소는 void 요소이므로 닫는 태그 `</link>`가 없어야 합니다.

```js
assert.notMatch(code, /<\/link>/i);
```

기존 `head` 요소를 변경하지 마세요. 닫는 태그를 삭제하지 않았는지 확인하세요.

```js
const headElementCount = document.querySelectorAll('head')?.length;
assert.strictEqual(headElementCount, 1);
```

`link` 요소가 하나 있어야 합니다.

```js
const linkElementCount = document.querySelectorAll('link')?.length;
assert.strictEqual(linkElementCount, 1);
```

`link` 요소는 `head` 요소 안에 있어야 합니다.

```js
const link = document.querySelector('head > link');
assert.isNotNull(link);
```

`link` 요소는 값 `stylesheet`인 `rel` 속성을 가져야 합니다.

```js
const linkRelValue = document.querySelector('link')?.getAttribute('rel');
assert.strictEqual(linkRelValue, 'stylesheet');
```

`link` 요소에는 값이 `styles.css`인 `href` 속성이 있어야 합니다.

```js
const linkHrefValue = document.querySelector('link')?.dataset?.href;
assert.strictEqual(linkHrefValue, 'styles.css');

```
