# --description--

Тепер ви перетворите відмінності на текстові мітки, як-от `+3.6 °C`. Додатні числа виводяться без знака, тому потрібно додати `+` перед ними.

Щоб включити лише ті елементи, які відповідають умові, можна додати в кінці list comprehension умовний оператор `if`:

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

Створіть змінну з назвою `difference_labels`. Використайте list comprehension, щоб призначити їй список, що містить `f'+{difference} °C'` для кожного `difference` у `differences`, але лише якщо `difference` більше за `0`.

Потім виведіть `difference_labels` замість `differences`.

У терміналі ви побачите лише 3 мітки для 7 температур. Умовний оператор `if` у кінці виключає елементи, які не відповідають умові, тому неможливо визначити, якій температурі належить кожна мітка. Ви виправите це на наступному кроці.
