# --description--

Python에서 변수는 객체를 가리키는 이름입니다. 동일성 연산자는 두 피연산자가 같은 객체를 가리키는지 확인합니다. `is` 연산자는 같으면 `True`를, 그렇지 않으면 `False`를 반환합니다. `is not` 연산자는 반대 결과를 반환합니다.

동일성은 동등성과 다릅니다: `==`와 `!=`는 값을 비교하고, `is`와 `is not`은 객체 동일성을 비교합니다. 숫자나 문자열 값을 비교할 때는 동등 연산자를 사용하세요.

`None`은 값이 없음을 나타냅니다. `NoneType` 데이터 타입의 유일한 값입니다.

동일성 연산자로 확인할 수 있는 세 객체는 `None`, `True`, `False`입니다. 각각은 싱글턴으로, 각 객체가 정확히 하나씩 존재합니다.

## `None` 확인하기

값이 없음을 확인하려면 `is None`을, 값이 있음을 확인하려면 `is not None`을 사용하세요:

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None`은 거짓으로 평가되지만 `False`와는 다른 객체입니다. 예를 들어, 응답은 예를 나타내는 `True`, 아니오를 나타내는 `False`, 또는 답변이 없음을 나타내는 `None`일 수 있습니다:

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

`if not response`를 사용하면 `False`와 `None`을 동일하게 처리합니다. 동일성 검사는 부정 답변과 답변 없음의 차이를 구분합니다.

## `True`와 `False` 확인하기

동일성을 사용해 불리언 객체인지 구체적으로 확인할 수도 있습니다:

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

이 검사는 `response`가 정확히 `True`, `False`인지, 또는 `None`이 아닌 다른 객체인지 묻습니다. 단순히 참/거짓 여부를 테스트하는 것이 아닙니다.

일반 불리언 플래그에는 `if is_ready` 또는 `if not is_ready` 같은 직접적인 참 테스트를 사용하세요. `is True` 또는 `is False`는 응답이 `None`일 수도 있는 경우처럼 불리언 객체를 다른 값과 구분해야 할 때 사용하세요.
