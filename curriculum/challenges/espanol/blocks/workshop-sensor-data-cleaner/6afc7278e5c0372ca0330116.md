# --description--

En este taller, practicarás comprensiones de listas y funciones lambda limpiando las lecturas de un sensor de temperatura y comparándolas con el promedio habitual de temperatura de su ubicación.

El sensor reporta temperaturas en décimas de grado Celsius, así que una lectura de `215` significa `21.5` °C. Cuando no puede leer la temperatura, escribe el código de error `-999` en su lugar.

Crea una variable llamada `readings` y asígnale la lista `[215, 243, -999, 280, 316, 339, -999, 262, 305]`.

Luego, crea una variable llamada `average_temperature` y asígnale el número flotante `28.0`. Este es el promedio habitual de temperatura para la ubicación, ya en grados Celsius, y compararás las lecturas con él.
