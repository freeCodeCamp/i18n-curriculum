# --description--

Ein Aufzug braucht auch einen Notstopp. In dieser Simulation steht der String `stop` in der Liste der Anfragen dafür, dass jemand den Notstopp-Knopf gedrückt hat.

Die Anweisung `break` beendet eine Schleife sofort und überspringt alle verbleibenden Durchläufe.

Fügen Sie nach der Zuweisung von `target` und vor Ihrer anderen `if`-Anweisung eine `if`-Anweisung hinzu, die prüft, ob `target` gleich dem String `stop` ist. Wenn ja, geben Sie den String `Emergency stop!` aus und verwenden Sie `break`, um den Aufzug anzuhalten.

Diese Prüfung muss vor der verschachtelten `while`-Schleife erfolgen, da der Vergleich eines Integers mit einem String mittels `<` einen `TypeError` auslöst.
