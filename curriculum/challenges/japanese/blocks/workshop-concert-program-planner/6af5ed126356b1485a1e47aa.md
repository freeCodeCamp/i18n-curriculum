# --description--

リストを別の変数に代入してもリストのコピーは作成されません。両方の変数は同じリストを参照しているため、2つ目の変数はエイリアスと呼ばれます。どちらか一方を通じて行った変更はもう一方にも反映されます。

`printed_program` という変数を作成し、`pieces` を代入してください。次に、`append()` を使って文字列 `Humoresque No. 7` をアンコールとして `pieces` の末尾に追加し、`printed_program` を出力してください。

ターミナルでは、アンコールが `pieces` に追加されたにもかかわらず、`printed_program` にも表示されるのがわかります。

これでコンサートプログラムのプランナーが完成です。

pieces = ['Carnival Overture', 'Song to the Moon', 'Silent Woods']

pieces.append('Slavonic Dance No. 8')
pieces.insert(3, 'Slavonic Dance No. 1')
extra_pieces = ['Serenade for Strings', 'Cello Concerto in B Minor']
pieces.extend(extra_pieces)
pieces.remove('Song to the Moon')
removed_piece = pieces.pop()

pieces[1] = 'Romance for Violin'
print(pieces)


def find_piece(piece, program):
    if piece in program:
        return f'{piece} is piece number {program.index(piece) + 1}.'
    return f'{piece} is not in the program.'


half = len(pieces) // 2
before_intermission = pieces[:half]
after_intermission = pieces[half:]

opening, *middle, closing = pieces
print(opening)
print(middle)
print(closing)

printed_program = pieces
pieces.append('Humoresque No. 7')
