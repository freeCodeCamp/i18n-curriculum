# --description--

このラボでは、関数を使ってキューのデータ構造を実装します。キューは先入れ先出し（FIFO）のデータ構造で、要素はキューの後ろに追加され、前から取り出されます。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

**ユーザーストーリー：**

1. `initQueue` 関数を用意し、空の配列が設定された `collection` プロパティを持つオブジェクトを返すようにしてください。
1. `enqueue` 関数を用意し、要素をキューの後ろに追加できるようにしてください。
1. `dequeue` 関数を用意し、キューの先頭の要素を削除して返すようにしてください。要素がなければ `undefined` を返してください。
1. `front` 関数を用意し、キューの先頭の要素を削除せずに返すようにしてください。要素がなければ `undefined` を返してください。
1. `size` 関数を用意し、キュー内の要素数を返すようにしてください。
1. `isEmpty` 関数を用意し、キューが空なら `true`、そうでなければ `false` を返すようにしてください。

**注意:** `dequeue`、`front`、`size`、`isEmpty` のテストは `enqueue` 関数を使ってキューに要素を追加するため、まず `enqueue` を実装することをお勧めします。最後のテストではすべての関数が連携して動作するかを確認します。

# --hints--

`enqueue`関数が必要です。

```js
assert.isFunction(enqueue);
```

`enqueue` 関数は要素をキューの後ろに追加する必要があります。

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
assert.deepEqual(queue.collection, ['first', 'second']);
```

`dequeue`関数が必要です。

```js
assert.isFunction(dequeue);
```

`dequeue` 関数はキューの先頭の要素を削除して返す必要があります。

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
enqueue(queue, 'third');
assert.strictEqual(dequeue(queue), 'first');
assert.strictEqual(dequeue(queue), 'second');
assert.lengthOf(queue.collection, 1);
```

`dequeue`は空のキューに対して呼び出されたときに`undefined`を返す必要があります。

```js
const queue = initQueue();
assert.isUndefined(dequeue(queue));
```

`enqueue` は先頭から要素が削除された後も、引き続き要素をキューの後ろに追加し続ける必要があります。

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
queue.collection.shift();
enqueue(queue, 'third');
assert.deepEqual(queue.collection, ['second', 'third']);
```

異なるキューのインスタンスは状態を共有してはいけません。

```js
const queueOne = initQueue();
const queueTwo = initQueue();
enqueue(queueOne, 'first');
enqueue(queueTwo, 'second');
assert.deepEqual(queueOne.collection, ['first']);
assert.deepEqual(queueTwo.collection, ['second']);
```

```js
assert.isFunction(front);
```

`front` 関数はキューの先頭の要素を削除せずに返す必要があります。

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
assert.strictEqual(front(queue), 'first');
assert.strictEqual(front(queue), 'first');

```

`front` 関数は空のキューに対して呼び出された場合、`undefined` を返す必要があります。

```js
const queue = initQueue();
assert.isUndefined(front(queue));
```

`size`関数が必要です。

```js
assert.isFunction(size);
```

`size` 関数はキュー内の正しい要素数を返す必要があります。

```js
const queue = initQueue();
assert.strictEqual(size(queue), 0);
enqueue(queue, 'first');
assert.strictEqual(size(queue), 1);
enqueue(queue, 'second');
enqueue(queue, 'third');
assert.strictEqual(size(queue), 3);
queue.collection.shift();
assert.strictEqual(size(queue), 2);
```

`isEmpty` 関数を用意してください。

```js
assert.isFunction(isEmpty);
```

`isEmpty` 関数は空のキューに対して `true` を返す必要があります。

```js
const queue = initQueue();
assert.isTrue(isEmpty(queue));
```

`isEmpty` 関数は空でないキューに対して `false` を返す必要があります。

```js
const queue = initQueue();
enqueue(queue, 'element');
assert.isFalse(isEmpty(queue));
```

`isEmpty` 関数はキューのすべての要素が削除された後に `true` を返す必要があります。

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
queue.collection.shift();
queue.collection.shift();
assert.isTrue(isEmpty(queue));
```

すべてのキュー関数が連携して動作する必要があります。

```js
const queue = initQueue();
assert.isTrue(isEmpty(queue));
enqueue(queue, 'first');
enqueue(queue, 'second');
enqueue(queue, 'third');
assert.strictEqual(size(queue), 3);
assert.strictEqual(front(queue), 'first');
assert.strictEqual(dequeue(queue), 'first');
assert.strictEqual(size(queue), 2);
enqueue(queue, 'fourth');
assert.strictEqual(dequeue(queue), 'second');
assert.strictEqual(dequeue(queue), 'third');
assert.strictEqual(dequeue(queue), 'fourth');
assert.isTrue(isEmpty(queue));
```

# --solutions--

```js
function initQueue() {
  return {
    collection: []
  };
}

function print(queue) {
  console.log(queue.collection);
}

function enqueue(queue, element) {
  queue.collection.push(element);
}

function dequeue(queue) {
  return queue.collection.shift();
}

function front(queue) {
  return queue.collection[0];
}

function size(queue) {
  return queue.collection.length;
}

function isEmpty(queue) {
  return queue.collection.length === 0;
}
```
