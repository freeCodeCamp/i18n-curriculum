# --description--

`extra_charges` という変数を作成し、`0` を代入してください。これは夜の上映に適用される追加料金を表します。

等値演算子 (`==`) は2つの値が等しいかどうかをチェックし、`True` または `False` を返します。これは値を変数にストアする代入演算子 (`=`) とは異なります。

```py
color = 'red' # Assigns 'red' to color
print(color == 'red') # True
print(color == 'blue') # False
```
