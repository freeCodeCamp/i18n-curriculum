## Instalación de un editor de código o IDE

En la lección anterior, aprendiste cómo instalar Python en tu dispositivo local. En esta lección, aprenderás cómo ejecutar código Python localmente.

Antes de que puedas empezar a crear tus scripts de Python localmente, necesitarás instalar un editor de código o un IDE. IDE significa entorno de desarrollo integrado. Un IDE combina funcionalidades como un editor de código, herramientas de prueba y una terminal.

Un editor de código popular que muchos desarrolladores usan es VS Code. Visita `https://code.visualstudio.com/download` para descargar VS Code, que es compatible con macOS, Windows y Linux. Este es el editor que se usará en esta lección.

Otras opciones comunes para el desarrollo en Python incluyen las siguientes:

- PyCharm
- Spyder

## Creación de un archivo Python

Después de instalar VS Code, ábrelo y selecciona `File`, luego `Open Folder`. Elige o crea una carpeta para tu proyecto. Para practicar más fuera de la lección, podrías querer una carpeta llamada `python-projects`.

Abre el Explorador en la barra lateral izquierda de VS Code. Selecciona el ícono de `New File`, que parece una hoja de papel con un signo más. Crea un archivo llamado `main.py` y presiona <kbd>Enter</kbd>. La extensión `.py` lo identifica como un archivo de Python.

Abre tu archivo `main.py` y escribe el siguiente código:

```py
print("Hello, world!")
```

## Instalar la extensión de Python

Para instalar la extensión oficial de Python de Microsoft, sigue los pasos específicos a continuación:

### Método A: Dentro de la aplicación

1. Abre la vista de Extensiones haciendo clic en el ícono de cuatro bloques en la barra de actividades del lado izquierdo. Alternativamente, presiona <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (Windows / Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (macOS).
1. Escribe `Python` en la barra de búsqueda en la parte superior.
1. Busca el primer resultado llamado Python, asegurándote de que el editor listado debajo sea Microsoft.
1. Haz clic en el botón azul <kbd>Install</kbd>.

### Método B: Terminal / línea de comandos

Si prefieres instalar la extensión desde una terminal, primero asegúrate de que el comando `code` esté disponible. En macOS, abre la paleta de comandos, ejecuta `Shell Command: Install 'code' command in PATH` y reinicia tu terminal.

Luego instala la extensión de Python ejecutando:

```bash
code --install-extension ms-python.python
```

## Seleccionar un intérprete de Python

La extensión funciona como un puente, pero no contiene los archivos reales del lenguaje Python. Debes instalar un intérprete de Python por separado desde el sitio oficial de Python si aún no lo has hecho.

Una vez que Python esté instalado en tu sistema operativo, conéctalo a tu editor:

1. En VS Code, abre cualquier carpeta o un archivo que termine en `.py`.
1. Abre la paleta de comandos usando <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows / Linux) o <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS).
1. Escribe y selecciona `Python: Select Interpreter`.
1. Elige la versión instalada de Python 3 de la lista de tu máquina. Ahora aparecerá de forma nativa en la barra de estado de tu espacio de trabajo.

## Ejecutar tu script de Python

Para ejecutar este código, tienes varias opciones. La primera es hacer clic en el botón de ejecutar que parece un botón de reproducción ubicado en la esquina superior derecha. Eso abrirá una terminal y ejecutará tu script de Python allí. Deberías ver el texto `Hello, world!`

Otra opción es abrir una terminal y ejecutar el programa manualmente usando:

```bash
python main.py
```

Debes ejecutar este comando desde la carpeta donde está guardado `main.py`. Por ejemplo, si `main.py` está dentro de una carpeta llamada `python-projects`, primero usa lo siguiente en la terminal:

```bash
cd python-projects
```

Luego ejecuta:

```bash
python main.py
```

## Usar `python3` en lugar de `python`

En algunos entornos, especialmente en sistemas macOS y Linux donde están instalados Python 2 y Python 3, puede que necesites usar `python3` en lugar de `python`. Esto es común cuando el comando `python` no existe o apunta a una versión antigua de Python.

```bash
python3 main.py
```

A medida que avances en el curso, ejecuta localmente los ejemplos de cada lección y crea tus propios ejemplos para probar lo que aprendiste.
