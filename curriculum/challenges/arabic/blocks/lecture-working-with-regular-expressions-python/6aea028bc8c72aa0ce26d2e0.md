# --description--

يمكن أن تحتوي التعبيرات النمطية على متتاليات خاصة تتكون من شرطة مائلة عكسية (`\`) تليها حرف. لهذه المتتاليات معنى خاص. إليك بعضًا من أكثرها شيوعًا:

- `\d` تطابق أي رقم عشري، بما في ذلك من `0` إلى `9`.

- `\w` تطابق أي حرف كلمة: أحرف، أرقام، والشرطة السفلية (`_`).

- `\s` تطابق أي حرف فراغ، مثل المسافة، الجدولة، أو السطر الجديد.

- `\D`، `\W`، و`\S` تطابق عكس نسخها بأحرف صغيرة. على سبيل المثال، `\D` تطابق أي حرف ليس رقمًا.

لكن هناك مشكلة. سلاسل Python تستخدم أيضًا الشرطة المائلة العكسية لكتابة تخطى التسلسل مثل `\n` (سطر جديد) أو `\t` (جدولة):

```python
print('Tab:\tdone') # Tab:    done
```

هذا يعني أن الشرطة المائلة العكسية في سلسلة Python العادية قد تُفسر بواسطة Python قبل أن يرى وحدة `re` ذلك. اعتمادًا على الحرف الذي يليها، قد يغير ذلك نمطك أو يجعل Python يعرض تحذيرًا.

لتجنب ذلك، يمكنك استخدام سلسلة خام. تنشئ سلسلة خام بإضافة الحرف `r` (أو `R`) قبل علامة الاقتباس الافتتاحية. السلاسل الخام تعامل الشرطة المائلة العكسية كحروف حرفية بدلًا من تخطى التسلسل:

```python
print(r'Tab:\tdone') # Tab:\tdone
```

لهذا السبب، من الممارسات الجيدة دائمًا كتابة أنماط التعبير النمطي كسلاسل خام:

```python
import re

room = 'Room 42B'
print(re.search(r'\d', room))
# <re.Match object; span=(5, 6), match='4'>
```

لاحظ أن `re.search` تُرجع أول تطابق تجده. هنا، `\d` تطابق رقمًا واحدًا، لذا التطابق هو فقط `4`. إذا أردت مطابقة أكثر من رقم واحد، قد تحتاج إلى استخدام محدد كمي.

المحددات الكمية تحدد عدد مرات تكرار الحرف أو المتتالية السابقة. المحدد `+` يطابق الحرف السابق مرة واحدة أو أكثر.

لذا، بينما `\d` تطابق رقمًا واحدًا، `\d+` تطابق رقمًا واحدًا أو أكثر على التوالي:

```python
import re

room = 'Room 42B'
print(re.search(r'\d+', room))
# <re.Match object; span=(5, 7), match='42'>
```

إليك محددات كمية شائعة أخرى:

- `*` يطابق الحرف السابق صفر مرة أو أكثر.

- `?` يطابق الحرف السابق صفر مرة أو مرة واحدة، مما يجعله اختياريًا.

- `{n}` يطابق الحرف السابق بالضبط `n` مرات.

- `{n,m}` يطابق الحرف السابق من `n` إلى `m` مرات.

```python
import re

print(re.search(r'go*al', 'What a goooal!'))
# <re.Match object; span=(7, 13), match='goooal'>

print(re.search(r'colou?r', 'My favorite color is blue'))
# <re.Match object; span=(12, 17), match='color'>

print(re.search(r'\d{4}', 'Room 42, built in 1987'))
# <re.Match object; span=(18, 22), match='1987'>
```

يمكنك دمج الحروف الحرفية، المتتاليات الخاصة، والمحددات الكمية في نفس النمط. على سبيل المثال، النمط `r'\d+ items'` يطابق رقمًا واحدًا أو أكثر، يتبعه فراغ وكلمة `items`. يمكنك أيضًا دمجه مع العلم `re.IGNORECASE` ليكون الحروف إما أحرف صغيرة أو كبيرة:

```python
import re

cart = 'You have 3 ITEMS in your cart.'
print(re.search(r'\d+ items', cart, re.IGNORECASE))
# <re.Match object; span=(9, 16), match='3 ITEMS'>
```
