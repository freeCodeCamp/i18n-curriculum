# --description--

要開啟和關閉 `sub-menu`，你的 `Navbar` 組件需要記住 `sub-menu` 目前是否開啟。組件記住且會隨時間改變的資料稱為狀態。每當狀態改變時，React 會重新算繪組件，讓頁面顯示新的值。

你將在後續課程中學到更多關於狀態的內容。目前你只需要知道，可以用 `useState` 掛鉤為函式組件添加狀態。掛鉤是特殊函式，讓你在組件中使用 React 的功能。因為本工作坊中 React 是透過 `script` 元素載入，你可以用 `React.useState` 來存取這個掛鉤：

```jsx
const [count, setCount] = React.useState(0);
```

`React.useState` 以狀態的初始值作為引數，並傳回一個包含兩個項目的陣列，這裡用陣列解構來拆解它：

- `count` 是狀態變數，保存目前的值。
- `setCount` 是設值函式，你呼叫它來更新狀態。

在 `Navbar` 組件內，使用 `React.useState` 創建一個名為 `isOpen` 的狀態變數和一個名為 `setIsOpen` 的設值函式。因為 `sub-menu` 預設應該是關閉的，所以給它初始值 `false`。
