# --interactive--

`text-decoration` 屬性讓你可以為文字添加裝飾線。

它的初始值是 `none`，通常用來移除瀏覽器在聯結上預設加上的底線，當你需要自定這些聯結時特別有用。

```css
a {
  text-decoration: none;
}
```

雖然常用於聯結，`text-decoration` 也能裝飾其他文字。

## `text-decoration` 屬性的其他值

除了 `none`，`text-decoration` 屬性的其他值有：

- `underline`
- `overline`
- `line-through`

正如這些值的名稱所示，`underline` 會在文字下方加線，`overline` 會在文字上方加線，而 `line-through` 則會在文字中間加線，就像刪除線一樣。

## `text-decoration` 屬性還有更多功能

`text-decoration` 屬性其實是個縮寫屬性，結合了以下幾個屬性：

- `text-decoration-line`：`none`、`underline`、`overline` 和 `line-through`
- `text-decoration-color`：線條的顏色。
- `text-decoration-style`：`solid`、`double`、`dotted`、`dashed` 或 `wavy`。
- `text-decoration-thickness`：線條的粗細。

例如，這會為段落添加一條紅色波浪線：

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

這會為段落添加一條雙線綠色上劃線：

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

你也可以將多種線條類型組合起來：

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::

## --text--

當你對元素套用 `text-decoration: underline overline` 會發生什麼？

## --answers--

文字下方會有一條線，文字上方也會有一條線。

---

文字只有下方有一條線。
