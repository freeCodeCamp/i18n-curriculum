# --description--

In der vorherigen Lektion haben Sie gelernt, wie man mit dem Datentyp Tuple arbeitet. In dieser Lektion lernen Sie einige gängige Methoden kennen, die Sie beim Arbeiten mit Tuples verwenden.

## Die `count()`-Methode

Die erste Methode, die wir behandeln, ist `count()`. Diese Methode wird verwendet, um zu bestimmen, wie oft ein Element in einem Tuple vorkommt. Hier ist ein Beispiel, wie man überprüft, wie oft der String `Rust` in einem Tuple namens `programming_languages` vorkommt:

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.count('Rust') # 2
```

Da `Rust` zweimal im Tuple vorkommt, gibt die `count()`-Methode die Zahl `2` zurück. Wenn das angegebene Element in der `count()`-Methode überhaupt nicht im Tuple vorhanden ist, dann ist der Rückgabewert `0`:

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.count('JavaScript') # 0
```

Wenn keine Argumente an die `count()`-Methode übergeben werden, löst Python einen `TypeError` aus:

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.count()

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: tuple.count() takes exactly one argument (0 given)
"""
```

## Die `index()`-Methode

Die nächste Methode, die wir uns ansehen, ist die `index()`-Methode. Diese Methode wird verwendet, um den Index zu finden, an dem ein bestimmtes Element in einem Tuple vorhanden ist. Hier ist ein Beispiel für die Verwendung der `index()`-Methode, um den Index für den String `Java` zu finden:

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.index('Java') # 1
```

Wenn das angegebene Element nicht gefunden werden kann, löst Python einen `ValueError` aus:

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust')
programming_languages.index('JavaScript')

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
ValueError: tuple.index(x): x not in tuple
"""
```

Eine weitere Möglichkeit, die Sie mit der `index()`-Methode haben, ist das Übergeben optionaler Start- und Stopp-Index-Argumente. Hier ist ein Beispiel für das Übergeben eines optionalen Start-Index:

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python')
programming_languages.index('Python', 3) # 5
```

In diesem Beispiel geben wir an, wo die Suche nach dem String `Python` beginnen soll. Indem wir die Zahl `3` als zweiten Parameter an die `index()`-Methode übergeben, legen wir fest, dass die Suche bei Index `3` starten soll. Da `Python` zweimal im Tuple vorkommt, gibt die `index()`-Methode aufgrund des optionalen Startindex-Arguments den Index `5` zurück statt `2`.

Sie können auch einen optionalen Stopp-Index übergeben. Hier ist ein modifiziertes Beispiel, bei dem ein Start- und Stopp-Index angegeben wird:

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python', 'JavaScript', 'Python')
programming_languages.index('Python', 2, 5) # 2
```

Jetzt ist das Ergebnis der Index `2`, weil wir die Suche bei Index `2` starten und bis, aber nicht einschließlich, Index `5` suchen.

## Die `sorted()`-Funktion

Eine weitere Funktion, die häufig mit Tuples verwendet wird, ist die Funktion `sorted()`. In einer vorherigen Lektion haben Sie `sorted()` mit Listen verwendet und gesehen, dass sie im Gegensatz zur Methode `sort()` eine neue sortierte Liste zurückgibt, anstatt die ursprüngliche Liste zu verändern. Da `sorted()` mit jedem iterierbaren Objekt funktioniert, können Sie es auch mit Tuples verwenden. Tuples sind unveränderlich und haben keine `sort()`-Methode, daher ist `sorted()` der Weg, um ihre Werte in Ordnung zu bringen.

Hier ist ein Beispiel, wie Sie mit der Funktion `sorted()` eine neue Liste von Zahlen aus einem Tuple erstellen:

```py
numbers = (13, 2, 78, 3, 45, 67, 18, 7)
sorted(numbers) # [2, 3, 7, 13, 18, 45, 67, 78]
```

Beachten Sie, dass das Ergebnis eine Liste ist, kein Tuple. Die Funktion `sorted()` gibt immer eine neue Liste der sortierten Werte zurück, egal welchen Typ von iterierbarem Objekt Sie übergeben, und das ursprüngliche Tuple bleibt unverändert.

Wenn Sie das Sortierverhalten für ein iterierbares Objekt anpassen möchten, können Sie die optionalen Argumente `reverse` und `key` verwenden. Hier ist ein Beispiel, wie Sie das `key`-Argument nutzen, um Elemente in einem Tuple nach Länge zu sortieren:

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python')
sorted(programming_languages, key=len)

# Result
# ['C++', 'Rust', 'Java', 'Rust', 'Python', 'Python']
```

Beachten Sie, dass `len` ohne runde Klammern geschrieben ist. Anstatt `len` selbst aufzurufen, übergeben Sie die Funktion selbst an `sorted()`. Dann ruft `sorted()` `len` für jedes Element auf und verwendet die zurückgegebene Länge, um die Elemente zu vergleichen. Das Ergebnis enthält weiterhin die ursprünglichen Strings, nur nach ihrer Länge geordnet.

Wenn Sie eine neue Liste von Werten in absteigender Reihenfolge erstellen möchten, können Sie das Argument `reverse` wie folgt verwenden:

```py
programming_languages = ('Rust', 'Java', 'Python', 'C++', 'Rust', 'Python')

print(sorted(programming_languages, reverse=True))

# Result
# ['Rust', 'Rust', 'Python', 'Python', 'Java', 'C++']
```

## Fazit

Tuples sind ein gängiger Datentyp in Python. Zu verstehen, wie man mit ihnen arbeitet, zusammen mit einigen hilfreichen Methoden und Funktionen, wird Ihnen helfen, effizienteren Code zu schreiben.
