# --description--

Kabla ya kufanya kazi na vigezo vya Python, ni muhimu kuelewa aina za data. Aina ya data inaelezea aina ya thamani ambayo kigezo kinahifadhi, kwa mfano, nambari au kipande cha maandishi. Lugha za programu hutumia aina za data ili zijue jinsi ya kuhifadhi na kufanya kazi na aina tofauti za taarifa.

Python ni lugha yenye aina zinazobadilika kwa wakati wa utekelezaji. Hii ina maana huwezi kubainisha aina ya data ya kigezo unachotengeneza. Python huamua aina kutoka kwa thamani iliyowekwa kwa kigezo.

Hapa kuna mifano kadhaa:

```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```

Kigezo kinaweza baadaye kupewa thamani ya aina tofauti:

```python
age = 25
age = 'Twenty-five'
```

Baada ya mgawo wa pili wa thamani, `age` ina mfuatano wa herufi badala ya nambari kamili.

Kwa sasa, makini na aina nne za data ambazo utazitumia katika moduli hii yote:

- Integer: Nambari kamili isiyo na sehemu za desimali, kwa mfano, `10` au `-5`.

```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- Float: Nambari yenye sehemu ya desimali, kama `4.41` au `-0.4`.

```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- String: Mfuatano wa herufi uliowekwa ndani ya alama za nukuu moja au mbili kama `'Hello world!'`.

```python
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- Boolean: Thamani ya kweli au siyo kweli, imeandikwa kama `True` au `False`.

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python ina aina nyingine za data. Utajifunza kila moja unapoihitaji kwa mara ya kwanza.
