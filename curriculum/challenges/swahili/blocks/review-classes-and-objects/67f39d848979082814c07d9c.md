## Madarasa na vitu vya Python

- **Ufafanuzi wa darasa**: Darasa ni ramani ya kuunda vitu. Linafafanua tabia ambayo kitu kitakuwa nayo kupitia sifa na njia zake. Hapa kuna mfano wa msingi wa ufafanuzi wa darasa katika Python:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **Majina ya darasa la vitu**: Kwa mkataba, majina ya darasa la vitu hutumia PascalCase: kila neno huanza na herufi kubwa na hakuna alama za mstari chini, kama vile `Dog` au `ShoppingCart`.

- **Njia ya `__init__()`**: Python hufanya wito wa `__init__()` moja kwa moja kila unapotengeneza kipengele kipya. Inatumika kuweka sifa za awali za kipengele hicho.

- **Kigezo `self`**: `self` inarejelea kitu mahususi ambacho njia inafanya kazi juu yake. Python huipeleka moja kwa moja unapoita njia kwenye kitu, hivyo hauiandiki kwenye wito. `self` ndilo jina la kawaida, lakini daima ni kigezo cha kwanza cha njia ya mfano.

- **Kuunda vitu**: Vitu ni matukio ya darasa. Huundwa kwa kuita darasa na hoja zinazohitajika.

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **Kuita njia kwenye vitu**: Unaweza kuita njia kwenye vitu ili kufanya vitendo au kupata taarifa.

```python
object_name1.method_name()
object_name2.method_name()
```

- **Tofauti kati ya darasa na kitu**: Darasa ni kiolezo kinachoweza kutumika tena, wakati kitu ni tukio maalum la darasa hilo lenye data halisi.

## Sifa

- **Sifa za mfano**: Kwa kawaida huainishwa katika `__init__()` kwa kutumia `self`, na ni za kipekee kwa kila kitu.
- **Sifa za darasa la vitu**: Huainishwa moja kwa moja ndani ya darasa na hutumika kwa pamoja na mifano yote.

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **Kushughulikia sifa za kipengele kwa njia ya mabadiliko wakati wa utekelezaji**: Wakati mwingine jina la sifa ya kipengele linajulikana tu wakati wa utekelezaji, kwa mfano linapotoka kwenye ingizo la mtumizi au mzunguko. Katika hali hiyo huwezi kuandika `object.name`, kwa hivyo unatumia kazi zinazochukua jina kama mfuatano wa herufi:

  - `getattr(obj, name)` hurudisha thamani ya sifa ya kipengele. Hutoa `AttributeError` ikiwa sifa haipo, isipokuwa ukipitisha thamani ya chaguo kama hoja ya tatu.
  - `setattr(obj, name, value)` huunda au kusasisha sifa ya kipengele.
  - `hasattr(obj, name)` hurudisha `True` ikiwa sifa ipo, vinginevyo `False`.
  - `delattr(obj, name)` hufuta sifa ya kipengele.

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **Kukagua sifa za kipengele kwa kutumia `dir()`**: Kazi ya `dir()` hurudisha orodha yenye majina ya sifa na njia za kipengele. Unganisha na `callable()` kutofautisha njia na sifa za data.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## Njia

- **Njia**: Vitendakazi vilivyofafanuliwa ndani ya darasa vinavyofanya kazi kwenye sifa za kitu.

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **Kupata njia**: Ita njia kwenye vitu kwa kutumia uandishi wa nukta. Hapa kuna mfano wa kuitwa kwa njia ya `describe` kwenye magari mawili tofauti:

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## Njia za dunder (za kichawi)

- **Ufafanuzi**: Njia maalum zinazotangulia na kumalizika na alama mbili za mstari chini (mfano, `__init__`, `__len__`, `__str__`, `__eq__`). Python hutumia hizi ndani kwa ajili ya operesheni zilizojengwa ndani.

- **Tabia bila njia maalum za kawaida**: Python haifahamu jinsi shughuli zilizojengwa ndani zinavyotakiwa kutumia sifa za kipengele cha kawaida. Inatumia tabia ya msingi iliyorithiwa pale inapopatikana na hutoa `TypeError` kwa shughuli zisizoungwa mkono.

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **Mabadiliko yanayofanywa na njia maalum**: `__len__()` hufanya `len()` irudishe idadi ya kurasa badala ya kutoa kosa. `__str__()` hubadilisha uwakilishi wa kawaida na muhtasari unaoweza kusomeka. `__eq__()` hufanya `==` kulinganisha idadi ya kurasa badala ya kuangalia kama majina yote mawili yanahusu kipengele kimoja.

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **Kuita njia za dunder kwa njia isiyo ya moja kwa moja**: Huhitaji kuita njia za dunder moja kwa moja. Badala yake, Python huziita moja kwa moja wakati matendo fulani yanapotokea. Operesheni hizi ni pamoja na:

  - **operesheni za kihesabu kama kuongeza, kutoa, kuzidisha, kugawanya, na nyinginezo**. `__add__()` huitwa kwa kuongeza, `__sub__()` kwa kutoa, `__mul__()` kwa kuzidisha, na `__truediv__()` kwa kugawanya.
        
  - **operesheni za mfuatano wa herufi kama kuunganisha, kurudia, kuunda muundo, na kubadilisha kuwa maandishi**. `__add__()` huitwa kwa kuunganisha, `__mul__()` kwa kurudia, `__format__()` kwa kuunda muundo, `__str__()` na `__repr__()` kwa kubadilisha kuwa maandishi, na kadhalika.
        
  - **operesheni za kulinganisha kama usawa, chini kuliko, juu kuliko, na nyinginezo**. `__eq__()` huitwa kwa ukaguzi wa usawa, `__lt__()` kwa chini kuliko, `__gt__()` kwa juu kuliko, na kadhalika.
        
  - **operesheni za kurudiwa kama kufanya kitu kuwa inayoweza kurudiwa na kusonga mbele kupitia vitu**. `__iter__()` inaitwa kurudisha iterator na `__next__()` kuchukua kipengele kinachofuata.

## Mfano halisi wa dunia: Gari la ununuzi

- **Darasa la gari lenye njia za dunder**: Huruhusu kuongeza, kufuta, kurudia, na kuangalia yaliyomo kwa tabia zilizojengwa ndani.

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## Vitu vinavyofanya kazi pamoja

- **Kupitisha vitu kama hoja**: Vitu vinaweza kupitishwa kwa kijenzi za madarasa mengine, kama vile nambari au mfuatano wa herufi.

- **Kuhifadhi vitu katika sifa za kipengele**: Kipengele kinaweza kuhifadhiwa katika sifa ya kipengele kingine. Kisha unaweza kuita njia kupitia sifa hiyo kwa kutumia uunganishaji wa uandishi wa nukta, kama vile `receiver.inbox.receive_email(email)`.

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## Kufanya kazi na tarehe na nyakati

- **Kupata tarehe na wakati wa sasa**: Kufanya wito wa `datetime.datetime.now()` hurudisha tarehe na wakati wa sasa kama kipengele cha `datetime`.

- **Kuhifadhi alama ya wakati kwenye mfano**: Fanya wito wa `datetime.datetime.now()` ndani ya `__init__()` na weka matokeo kwenye sifa ya kipengele kurekodi wakati kipengele kilipotengenezwa.

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **Kupanga kwa kutumia `strftime()`**: Njia ya `strftime()` hubadilisha kipengele cha `datetime` kuwa mfuatano wa herufi, kwa kutumia misimbo ya muundo: `%Y` kwa mwaka wa nambari nne, `%m` kwa mwezi, `%d` kwa siku, `%H` kwa saa (saa 24), `%M` kwa dakika, na `%S` kwa sekunde. Herufi nyingine yoyote, kama `-`, `/`, `:`, au nafasi, zinahifadhiwa kama viunganishi halisi.

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
