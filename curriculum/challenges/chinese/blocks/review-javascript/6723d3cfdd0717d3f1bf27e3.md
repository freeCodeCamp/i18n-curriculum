## 使用 HTML、CSS 和 JavaScript

虽然 HTML 和 CSS 提供网站结构，但 JavaScript 通过实现复杂功能（如处理用户输入、动画元素，甚至构建完整的网页应用）为网站带来交互性。

## JavaScript 中的数据类型

数据类型帮助程序理解它正在处理的数据类型，无论是数字、文本还是其他类型。

- **数字**：数字表示整数和浮点数。整数的例子包括 7、19 和 90。
- **浮点数**：浮点数是带有小数点的数字。例子包括 3.14、0.5 和 0.0001。
- **字串**：字串是一系列字符或文本，包含在引号中。`"I like coding"` 和 `'JavaScript is fun'` 是字串的例子。
- **布尔**：布尔表示两种可能的值之一：`true` 或 `false`。你可以用布尔表示一个条件，比如 `isLoggedIn = true`。
- **Undefined 和 Null**：`undefined` 值是已声明但未赋值的变量。`null` 值是空值，或者是一个被故意赋值为 `null` 的变量。
- **对象**：对象是键值对的集合。键是属性名，值是属性值。

例如，`{ name: "Fluffy", age: 3, type: "dog" }` 有三个属性：`name`、`age` 和 `type`。

- **符号**：Symbol 数据类型是一个唯一且不可变的值，可用作对象属性的标识符。

两个具有相同描述的符号仍然是不同的值。

- **BigInt**：当数字对于 `Number` 数据类型来说太大时，你可以使用 BigInt 数据类型来表示任意长度的整数。

通过在数字末尾添加 `n`，你可以创建一个 BigInt。

## JavaScript 中的变量

- 变量可以使用 `let` 关键字声明。

- 要给变量赋值，可以使用赋值操作符 `=`。

- 使用 `let` 声明的变量可以重新赋值。

- 除了 `let`，你还可以使用 `const` 声明变量。但 `const` 变量不能重新赋值。

- 使用 `const` 声明的变量用于声明常量，这些常量在代码中不允许改变，比如 `PI` 或 `MAX_SIZE`。

## 变量命名规范

- 变量名应具有描述性和意义。
- 变量名应采用驼峰式大小写，如 `cityName`、`isLoggedIn` 和 `veryBigNumber`。
- 变量名不能以数字开头，必须以字母、`_` 或 `$` 开头。
- 变量名不能包含空格或特殊字符，除了 `_` 和 `$`。
- 变量名不能是保留关键字。
- 变量名区分大小写。`age` 和 `Age` 是不同的变量。

## JavaScript 中的字串及其不可变性

- 字串是包含在引号中的字符序列。可以使用单引号或双引号创建。

- JavaScript 中的字串是不可变的。这意味着一旦创建了字串，就不能更改其中的字符。但你仍然可以将字串重新赋值为新值。

## JavaScript 中的字串串接

- 串接是连接多个字串或将字串与包含文本的变量组合的过程。`+` 操作符是最简单且最常用的串接字串的方法之一。

- 如果你需要添加或追加到现有字串，可以使用 `+=` 操作符。当你想通过逐渐添加更多文本来构建字串时，这很有用。

- 另一种串接字串的方法是使用 `concat()` 方法。此方法将两个或多个字串连接在一起。

## 使用 `console.log()` 记录消息

- `console.log()` 方法用于将消息记录到控制台。这是调试和测试代码的有用工具。

## JavaScript 中的分号

- 分号主要用于标记语句的结束。这有助于 JavaScript 引擎理解各个指令的分隔，对于正确执行至关重要。

- 分号有助于防止代码执行中的歧义，确保语句正确终止。

## JavaScript 中的评论

- 任何被注释掉的代码行都会被 JavaScript 引擎忽略。评论用于解释代码、做笔记或临时禁用代码。
- 单行评论使用 `//` 创建。

- 多行评论使用 `/*` 开始，`*/` 结束。

## JavaScript 作为动态类型语言

- JavaScript 是动态类型语言，这意味着声明变量时不必指定数据类型。JavaScript 引擎会根据赋给变量的值自动确定数据类型。

- 在像 C# 这样的静态类型语言中，将字符串赋值给整数变量会导致错误。

## 使用 `typeof` 操作符

- `typeof` 操作符用于检查变量的数据类型。它返回一个字符串，指示变量的类型。

- 但是，JavaScript 在 `null` 方面有一个众所周知的怪癖。`typeof` 操作符对 `null` 值返回 `"object"`。

## 字串基础

- **定义**：字串是用单引号、双引号或反引号包裹的字符序列。字串是原语数据类型且不可变。不可变性意味着一旦创建字串，就不能更改它。
- **访问字串中的字符**：要访问字串中的字符，可以使用方括弧表示法并传入索引号。索引是字符在字串中的位置，且从零开始。

- **`\n`（换行字符）**：你可以使用 `\n` 换行字符在字串中创建换行。

- **转义字符串**：你可以通过在引号前放置反斜线（`\`）来转义字符串中的字符。

:::interactive_editor

```js
const statement = "She said, \"Hello!\"";
console.log(statement); // She said, "Hello!"
```

## 模板字面量（模板字串）和字串插值

- **定义**：模板字面量用反引号（`）定义。它们允许更方便地操作字串，包括直接在字串中嵌入变量，这称为字串插值。

:::interactive_editor

```js

const greeting = `Hello, ${name}!`; 
console.log(greeting); // "Hello, Jessica!"
```

## ASCII、`charCodeAt()` 方法和 `fromCharCode()` 方法

- **ASCII**：ASCII（美国信息交换标准代码）是一种字符编码标准，用于使用数字值表现基本的英文字符。之前的课程通过 ASCII 示例介绍了 `charCodeAt()` 和 `fromCharCode()`。
- **Unicode**：JavaScript 字串在内部使用 Unicode，具体为 UTF-16 编码。对于前 128 个字符（基本拉丁字母、数字和常用符号），Unicode 值与 ASCII 代码相匹配。这就是基于 ASCII 的示例在 JavaScript 中仍然有效的原因。
- **`charCodeAt()` 方法**：此方法返回指定索引处字符的 UTF-16 代码单元。对于基本拉丁字符，该值与 ASCII 码匹配。

- **`fromCharCode()` 方法**：此方法将 ASCII 码转换为对应的字符。

## 其他常用字串方法

- **`indexOf` 方法**：此方法用于在字串中查找子串。如果找到子串，`indexOf` 返回该子串首次出现的索引（位置）。如果未找到，`indexOf` 返回 -1，表示查找失败。

- **`includes()` 方法**：此方法用于检查字串是否包含特定子串。如果字串中包含该子串，方法返回 true，否则返回 false。

- **`slice()` 方法**：该方法提取字符串的一部分，并返回一个新的字符串，而不修改原始字符串。 它需要两个参数：开始索引和选填的结束索引。

- **`toUpperCase()` 方法**：此方法将所有字符转换为大写字母，并返回一个包含所有大写字符的新字串。

- **`toLowerCase()` 方法**：此方法将字串中的所有字符转换为小写。

- **`replace()` 方法**：此方法允许你在字串中查找指定值（如单词或字符）并替换为另一个值。该方法返回替换后的新字串，原字串保持不变，因为 JavaScript 字串是不可变的。

- **`replaceAll()` 方法**：此方法允许你查找字串中指定值（一个单词、字符或模式）的所有出现，并将它们替换为另一个值。它的工作方式类似于 `replace()`，但不是在找到第一个匹配后停止，而是更新字串中找到的每个匹配。

- **`repeat()` 方法**：此方法用于重复字串指定次数。

- **`trim()` 方法**：此方法用于移除字串开头和结尾的空白字符。

- **`trimStart()` 方法**：此方法移除字串开头（或“开始”）的空白字符。

- **`trimEnd()` 方法**：此方法移除字串结尾的空白字符。

- **`prompt()` 方法**：`window` 的此方法用于通过对话框形式从用户获取信息。此方法接受两个参数。第一个参数是显示在对话框中的消息，通常提示用户输入信息。第二个参数是可选的默认值，初始填充输入字段。

## 使用数字数据类型

- **定义**：JavaScript 的 `Number` 类型包括整数、浮点数、`Infinity` 和 `NaN`。浮点数是带小数点的数字。正 `Infinity` 是比任何其他数字都大的数字，而 `-Infinity` 是比任何其他数字都小的数字。`NaN`（`Not a Number`）表示无效的数字值，如字符串 `"Jessica"`。

## 常见算术操作

- **加法操作符**：此操作符（`+`）用于计算两个或多个数字的和。
- **减法操作符**：此操作符（`-`）用于计算两个数字的差。
- **乘法操作符**：此操作符（`*`）用于计算两个或多个数字的乘积。
- **除法操作符**：此操作符（`/`）用于计算两个数字的商。
- **除以零**：如果你尝试除以零，JavaScript 会返回 `Infinity`。
- **取余操作符**：此操作符（`%`）返回除法的余数。
- **指数操作符**：此操作符（`**`）将一个数字提升到另一个数字的幂。

## 数字和字串的计算

- **说明**：当你使用 `+` 操作符连接数字和字符串时，JavaScript 会将数字强制转换为字符串并连接两个值。当你使用 `-`、`*` 或 `/` 操作符连接字符串和数字时，JavaScript 会将字符串强制转换为数字，结果是一个数字。对于 `null` 和 `undefined`，JavaScript 在数学运算中将 `null` 视为 0，将 `undefined` 视为 `NaN`。

## 操作符优先级

- **定义**：运算符优先级决定了表达式中运算的求值顺序。 优先级较高的运算符先于优先级较低的运算符进行运算。 括号内的值将优先计算，乘法/除法的优先级高于加法/减法。 如果运算符具有相同的优先级，那么 JavaScript 将使用结合性。

- **定义**：结合性告诉我们当存在多个相同类型的操作符时，表达式的求值方向。它定义了表达式是应该从左到右求值（`left-associative`），还是从右到左求值（`right-associative`）。例如，指数操作符也是从右到左结合的。

## 自增和自减操作符

- **自增操作符**：此操作符用于将值增加 1。前缀表示法 `++num` 先增加变量值，然后返回新值。后缀表示法 `num++` 先返回变量当前值，然后增加它。

- **自减操作符**：此操作符用于将值减少 1。前缀和后缀表示法与自增操作符的工作方式相同。

## 复合赋值操作符

- **加法赋值（`+=`）操作符**：此操作符对值执行加法，并将结果赋给变量。
- **减法赋值（`-=`）操作符**：此操作符对值执行减法，并将结果赋给变量。
- **乘法赋值（`*=`）操作符**：此操作符对值执行乘法，并将结果赋给变量。
- **除法赋值（`/=`）操作符**：此操作符对值执行除法，并将结果赋给变量。
- **取余赋值（`%=`）操作符**：此操作符将变量除以指定数字，并将余数赋给变量。
- **指数赋值（`**=`）操作符**：此操作符将变量提升到指定数字的幂，并重新赋值给变量。

## 布尔值和相等性

- **布尔定义**：布尔是一种只能有两个值的数据类型：`true` 或 `false`。
- **相等（`==`）操作符**：此操作符在检查值是否相等之前使用类型强制转换。

- **严格相等（`===`）操作符**：此操作符不执行类型强制转换，检查类型和值是否都相等。

- **不等（`!=`）运算符**：该操作符在检查值是否不相等之前使用类型强制。
- **严格不等（`!==`）运算符**：该运算符不执行类型强制，并检查类型和值是否不相等。

## 比较操作符

- **大于（`>`）操作符**：此操作符检查左侧值是否大于右侧值。
- **大于等于（`>=`）操作符**：此操作符检查左侧值是否大于或等于右侧值。
- **小于（`<`）操作符**：此操作符检查左侧值是否小于右侧值。
- **小于等于（`<=`）操作符**：此操作符检查左侧值是否小于或等于右侧值。

## 一元操作符

- **一元加操作符**：此操作符将其操作对象转换为数字。如果操作对象已经是数字，则保持不变。

- **一元取反（`-`）操作符**：此操作符对操作对象取反。

- **逻辑非（`!`）操作符**：此操作符翻转操作对象的布尔值。如果操作对象是 `true`，则变为 `false`；如果是 `false`，则变为 `true`。

## 位操作符

- **按位与（`&`）操作符**：此操作符在两个操作数的对应位都为 1 时返回 1。
- **按位与赋值（`&=`）操作符**：此操作符对指定数字执行 `bitwise AND` 操作，并将结果重新赋值给变量。
- **按位或（`|`）操作符**：此操作符在两个操作数的对应位任一为 1 时返回 1。
- **按位或赋值（`|=`）操作符**：此操作符对指定数字执行 `bitwise OR` 操作，并将结果重新赋值给变量。
- **按位异或（`^`）操作符**：此操作符在两个操作数的对应位只有一个为 1 时返回 1。
- **按位非（`~`）操作符**：此操作符对数字的二进制表示取反。
- **左移（`<<`）操作符**：此操作符将所有位向左移动指定位置数。
- **右移（`>>`）操作符**：此操作符将所有位向右移动。

## 条件语句、真值、假值和三元操作符

- **`if/else if/else`**：`if` 语句接受一个条件，如果该条件为 `truthy`，则执行一段代码块。如果条件为 `false`，则执行 `else if` 块。如果这些条件都不为 `true`，则执行 `else` 子句。`Truthy` 值是在布尔上下文（如 `if` 语句）中计算结果为 `true` 的任何值。`Falsy` 值是在布尔上下文中计算结果为 `false` 的值。

:::interactive_editor

```js
const score = 87;

if (score >= 90) {
 console.log('You got an A'); 
} else if (score >= 80) {
 console.log('You got a B'); // You got a B
} else if (score >= 70) {
 console.log('You got a C');
} else {
 console.log('You failed! You need to study more!');
}
```

:::

- **三元操作符**：此操作符常用作编写 `if else` 语句的简写。

:::interactive_editor

```js
const temperature = 30;
const weather = temperature > 25 ? 'sunny' : 'cool';

console.log(`It's a ${weather} day!`); // It's a sunny day!
```

:::

## 二元逻辑操作符

- **逻辑与（`&&`）操作符**：该操作符检查两个操作对象是否都为 `true`。如果两者都为 `true`，则返回第二个值。如果任一操作对象为 `falsy`，则返回该 `falsy` 值。如果两个操作对象都是 `falsy`，则返回第一个 `falsy` 值。

- **逻辑或 (`||`) 操作符**：此操作符检查是否至少有一个操作对象为真值。
- **空值合并（`??`）运算符**：只有当第一个值为 `null` 或 `undefined` 时，该运算符才会返回一个值。

## `Math` 对象

- **`Math.random()` 方法**：此方法生成一个介于 0（含）和 1（不含）之间的随机浮点数。这意味着输出可能是 0，但永远不会达到 1。
- **`Math.max()` 方法**：此方法接受一组数字并返回最大值。
- **`Math.min()` 方法**：此方法接受一组数字并返回最小值。
- **`Math.ceil()` 方法**：此方法将值向上舍入到最接近的整数。
- **`Math.floor()` 方法**：此方法将值向下舍入到最接近的整数。
- **`Math.round()` 方法**：此方法将值舍入到最接近的整数。

- **`Math.trunc()` 方法**：此方法去除数字的小数部分，仅返回整数部分，不进行四舍五入。
- **`Math.sqrt()` 方法**：此方法返回数字的平方根。
- **`Math.cbrt()` 方法**：此方法返回数字的立方根。
- **`Math.abs()` 方法**：此方法返回数字的绝对值。
- **`Math.pow()` 方法**：此方法接受两个数字，将第一个数字提升到第二个数字的幂。

## 常用数字方法

- **`isNaN()`**：`NaN` 代表“非数字”（Not-a-Number）。它是一个特殊值，表示无法表示或未定义的数值结果。`isNaN()` 函数属性用于判断一个值是否是 `NaN`。`Number.isNaN()` 提供了一种更可靠的方式来检查 `NaN` 值，特别是在类型强制转换可能导致全局 `isNaN()` 函数出现意外结果的情况下。

- **`parseFloat()` 方法**：该方法解析字符串参数并返回一个浮点数。它设计用于从字符串开头提取数字，即使字符串后面包含非数字字符。
- **`parseInt()` 方法**：该方法解析字符串参数并返回一个整数。`parseInt()` 在遇到第一个非数字字符时停止解析。对于浮点数，它只返回整数部分。如果在字符串开头找不到有效整数，则返回 `NaN`。
- **`toFixed()` 方法**：该方法在数字上调用，接受一个可选参数，表示小数点后显示的位数。它返回指定小数位数的数字字符串表示。

## 比较与 `null` 和 `undefined` 数据类型

- **比较与 `undefined`**：当变量已声明但未赋值时，它是 `undefined`。这是未初始化变量和未传递参数的函数参数的默认值。`undefined` 在数值上下文中转换为 `NaN`，这使得所有与 `undefined` 的数值比较都返回 `false`。

- **与 `null` 的比较**：`null` 类型表示有意的无值。`null` 在数值上下文中转换为 `0`，这可能导致数值比较时出现意外行为。例如，`null >= 0` 是 `true`，但 `null > 0` 是 `false`。

- 使用相等操作符（`==`）时，`null` 和 `undefined` 只相等于彼此和自身。

- 但是，使用严格相等操作符（`===`）时，它会检查值和类型且不进行类型转换，`null` 和 `undefined` 不相等。

## `switch` 语句

- **定义**：`switch` 语句对表达式进行计算，并将其值与一系列 `case` 子句匹配。 找到匹配后，将执行与该 case 相关的代码块。 应在每个 case 的末尾添加 `break` 语句，以终止其执行，防止继续执行后面的 case。 `default` 是可选的，只有在其他 case 都不匹配时才会执行。 `default` 放在 `switch` 语句的末尾。

:::interactive_editor

```js
const dayOfWeek = 3; 

switch (dayOfWeek) {
  case 1:
    console.log("It's Monday! Time to start the week strong.");
    break;
  case 2:
    console.log("It's Tuesday! Keep the momentum going.");
    break;
  case 3:
    console.log("It's Wednesday! We're halfway there.");
    break;
  case 4:
    console.log("It's Thursday! Almost the weekend.");
    break;
  case 5:
    console.log("It's Friday! The weekend is near.");
    break;
  case 6:
    console.log("It's Saturday! Enjoy your weekend.");
    break;
  case 7:
    console.log("It's Sunday! Rest and recharge.");
    break;
  default:
    console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

:::

## JavaScript 函数

- 函数是可重复使用的代码片段，可执行特定任务。
- 可以使用 `function` 关键字定义函数，该关键字后跟一个名称、一个参数列表和一个执行任务的代码块。

:::interactive_editor

```js
function addNumbers(x, y, z) {
  return x + y + z;
}

console.log(addNumbers(5, 3, 8)); // Output: 16
```

:::

- 实参是调用函数时传递给函数的值。
- 函数调用是在程序中执行一个函数的过程，具体方法是在函数名称后加上括号，括号内可选择包含参数。
- 函数执行完毕后，总会返回一个值。
- 默认情况下，函数的返回值为 `undefined` 。
- `return` 关键字用于指定从函数返回的值，并结束函数的执行。
- 默认参数允许函数具有预定义值，如果调用函数时没有提供实参，就会使用这些值。 这使得函数更加灵活，并防止在省略某些实参时出现错误。

:::interactive_editor

```js
const calculateTotal = (amount, taxRate = 0.05) => {
  return amount + (amount * taxRate);
};

console.log(calculateTotal(100)); // Output: 105
```

:::

- 匿名函数是没有名称的函数，可以赋值给变量。通过将它们赋值给变量，你可以在变量可访问的任何地方重用它们。

:::interactive_editor

```js
const multiplyNumbers = function(firstNumber, secondNumber) {
  return firstNumber * secondNumber;
};

console.log(multiplyNumbers(4, 5)); // Output: 20
```

:::

- 定义箭头函数时，不需要使用 `function` 关键字。
- 如果只使用一个参数，可以省略参数列表中的括号。

- 如果函数体只有一个表达式，则可以省略大括号和 `return` 关键字。

## 编程中的作用域

- **局部作用域**：指在函数内部声明的变量。这些变量只能在声明它们的函数内部访问，称为局部变量。

## JavaScript 数组基础

- **定义**：JavaScript 数组是有序的值集合，每个值由数字索引标识。数组中的值可以是不同的数据类型，包括数字、字串、布尔值、对象，甚至其他数组。数组在内存中是连续存储的，这意味着所有元素存储在单个连续的内存块中，允许高效索引和快速通过索引访问元素。

- **访问数组元素**：访问数组元素需要引用数组名，后跟方括弧内的索引号。JavaScript 数组是零基索引，意味着第一个元素索引为 0，第二个元素索引为 1，依此类推。如果访问不存在的索引，JavaScript 会返回 `undefined`。

- **`length` 属性**：该属性用于返回数组中的项数。

- **更新数组元素**：更新数组元素时，使用赋值操作符（`=`）为特定索引的元素赋新值。

## 二维数组

- **定义**：二维数组本质上是数组的数组。它用于表示具有自然网格结构的数据，如棋盘、电子表格或图像中的像素。访问二维数组元素需要两个索引：一个表示行，一个表示列。

## 数组解构

- **定义**：数组解构是 JavaScript 的一项功能，允许你以更简洁易读的方式从数组中提取值并赋给变量。它提供了方便的语法，将数组元素拆包到不同变量中。

```js
console.log(first); // "apple"
console.log(second); // "banana"
console.log(third); // "orange"
```

:::

- **剩余语法**：允许你捕获未被解构的数组剩余元素，放入一个新数组。

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange", "mango", "kiwi"];
const [first, second, ...rest] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(rest); // ["orange", "mango", "kiwi"]
```

:::

## 常用数组方法

- **`push()` 方法**：该方法用于向数组末尾添加元素，并返回新长度。

- **`pop()` 方法**：该方法用于移除数组最后一个元素，并返回被移除的元素。如果数组为空，返回值为 `undefined`。

- **`shift()` 方法**：该方法用于移除数组第一个元素，并返回被移除的元素。如果数组为空，返回值为 `undefined`。

- **`unshift()` 方法**：该方法用于向数组开头添加元素，并返回新长度。

- **`indexOf()` 方法**：该方法用于查找数组中特定元素的第一个索引。如果找不到元素，返回 `-1`。

- **`splice()` 方法**：此方法用于从数组的任意位置添加或移除元素。`splice()` 方法的返回值将是一个包含从数组中移除项的数组。如果没有移除任何项，则返回一个空数组。此方法会修改原始数组，直接在原数组上进行更改，而不是创建新数组。第一个参数指定开始修改数组的索引。第二个参数是你希望移除的元素数量。后续参数是你希望添加的元素。

- **`includes()` 方法**：该方法用于检查数组是否包含特定值。如果包含指定元素，返回 `true`，否则返回 `false`。

- **`concat()` 方法**：该方法通过合并两个或多个数组创建新数组。

- **`slice()` 方法**：此方法返回一个包含原始数组部分浅拷贝的新数组，该部分由起始和结束索引指定。新数组包含对与原始数组相同元素的引用（而非副本）。这意味着如果元素是原语（如数字或字串），则值会被拷贝；但如果元素是对象或数组，则拷贝的是引用，而非对象本身。

- **扩展语法**：扩展语法用于创建数组的浅拷贝。

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const shallowCopiedArray = [...originalArray];

shallowCopiedArray.push(4);

console.log(originalArray); // [1, 2, 3]
console.log(shallowCopiedArray); // [1, 2, 3, 4]
```

:::

- **`split()` 方法**：该方法根据给定分隔符将字符串拆分成子字符串数组。如果未提供分隔符，返回包含原始字符串的单元素数组。

- **`reverse()` 方法**：该方法原地反转数组。

- **`join()` 方法**：该方法将数组所有元素连接成一个字符串，元素间用指定分隔符分隔。如果未提供分隔符或使用空字符串（`""`），则元素直接连接无分隔符。

## 检查对象是否拥有某属性

- **`hasOwnProperty()` 方法**：该方法返回布尔值，表示对象是否拥有指定属性（作为自身属性）。

- **`Object.hasOwn()` 方法**：这是检查对象是否拥有某个自身（非继承）属性的现代推荐方式。语法是 `Object.hasOwn(object, propertyName)`。如果属性存在于对象上，它返回 `true`，如果不存在则返回 `false`，无论属性值是什么。这使得它比 `hasOwnProperty()` 更安全，也比在属性值可能是 `0`、`false`、`null` 或 `undefined` 时使用 `if (obj.prop)` 更可靠。

`Object.hasOwn()` 即使属性值是 `0`、`false` 或 `undefined` 等假值，也能检测到对象自身的属性。

- **`in` 操作符**：如果属性存在于对象中，该操作符返回 `true`。

## 循环使用

- **`for` 循环**：这种循环用于重复执行代码块指定次数。循环分为三部分：初始化语句、条件和增减语句。初始化语句在循环开始前执行，通常用于初始化计数器变量。条件在每次循环迭代前计算。一次迭代是循环的一次执行。如果条件为 `true`，执行循环体内代码；如果为 `false`，循环停止，执行后续代码。增减语句在每次迭代后执行，通常用于计数器变量的增减。

```js
  console.log(i);
}
```

```js
  console.log(num);
}
```

:::interactive_editor

```js
const fruit = {

  color: 'red',

};

  console.log(fruit[prop]);
}
```

- **`while` 循环**：只要条件为 `true`，该循环就会执行代码块。

:::interactive_editor

```js
  console.log(i);

}
```

## `var` 关键字和提升

- **定义**：`var` 是 2015 年之前声明变量的原始方式。但 `var` 在作用域、重复声明等方面存在一些问题。因此现代 JavaScript 编程使用 `let` 和 `const` 代替。
- **使用 `var` 重复声明变量**：如果尝试用 `let` 重复声明变量，会出现 `SyntaxError`。但使用 `var` 可以重复声明变量。

- **`var` 和作用域**：用 `var` 在块内（如 `if` 语句或 `for` 循环）声明的变量，仍然可以在该块外访问。

- **提升**：这是 JavaScript 在编译阶段默认将声明提升到各自作用域顶部的行为。使用 `var` 关键字声明变量时，JavaScript 会将声明提升到作用域顶部。

使用函数声明语法声明函数时，函数名和函数体都会被提升。这意味着你可以在代码中声明函数之前调用它。

用 `let` 或 `const` 声明的变量会被提升，但不会初始化，且在代码中实际声明之前无法访问。这种行为通常称为“暂时性死区”。

## 使用导入、导出和模块

- **模块**：这是一个自包含的代码单元，封装了相关的函数、类或变量。要创建模块，你需要将 JavaScript 代码写在一个单独的文件中。
- **导出**：任何你想让应用其他部分使用的变量、函数或类，都需要使用 `export` 关键字显式导出。导出有两种类型：命名导出和默认导出。
- **导入**：要在应用的其他部分使用导出的内容，需要使用 `import` 关键字导入。导入类型包括命名导入、默认导入和命名空间导入。

```js
// Within a file called math.js, we export the following functions:

// Named export
export function add(num1, num2) {
  return num1 + num2;
}

// Default export
export default function subtract(num1, num2) {
  return num1 - num2;
}

// Within another file, we can import the functions from math.js.

// Named import - This line imports the add function.
// The name of the function must exactly match the one exported from math.js.
import { add } from './math.js';

// Default import - This line imports the subtract function.
// The name of the function can be anything.
import subtractFunc from './math.js';

// Namespace import - This line imports everything from the file.
import * as Math from './math.js';

console.log(add(5, 3)); // 8
console.log(subtractFunc(5, 3)); // 2
console.log(Math.add(5, 3)); // 8
console.log(Math.subtract(5, 3)); // 2
```

## 回调函数和 `forEach` 方法

- **定义**：在 JavaScript 中，回调函数是作为参数传递给另一个函数的函数，并在主函数执行完成后执行。
- **`forEach()` 方法**：该方法用于遍历数组中的每个元素，并对每个元素执行操作。`forEach` 中的回调函数最多可以接受三个参数：当前元素、当前元素的索引，以及调用 `forEach` 的数组。

## 高阶函数

- **定义**：高阶函数是指接受一个或多个函数作为参数，并返回一个函数或值的函数。

- **`map()` 方法**：该方法通过对原数组的每个元素应用给定函数来创建一个新数组。回调函数可以接受最多三个参数：当前元素、当前元素的索引，以及调用 `map` 的数组。

- **`filter()` 方法**：该方法用于创建一个新数组，包含通过指定测试的元素，适合根据条件选择性提取项。与 `map` 方法类似，`filter` 方法的回调函数接受相同的三个参数：正在处理的当前元素、索引和数组。

- **`reduce()` 方法**：该方法用于处理数组并将其压缩成单个值。这个单值可以是数字、字符串、对象，甚至是另一个数组。`reduce()` 方法通过依次对数组中的每个元素应用函数，并将每次计算的结果传递给下一次来工作。这个函数通常称为累加器函数。累加器函数接受两个主要参数：累加器和当前值。累加器用于存储操作的累计结果，当前值是正在处理的数组元素。

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce(
  (accumulator, currentValue) => accumulator + currentValue,
  0
);

console.log(sum); // 15
```

:::

## 方法链

- **定义**：方法链是一种编程技巧，允许你在一行代码中对同一个对象调用多个方法。这种技巧可以让你的代码更易读、更简洁，尤其是在对同一对象执行一系列操作时。

## 使用 `sort` 方法

- **定义**：`sort` 方法用于对数组元素进行排序，并返回排序后的数组引用。此方法不会创建副本，因为元素是在原地排序的。

如果你需要对数字进行排序，则需要传入一个比较函数。`sort` 方法会将元素转换为字符串，然后比较它们的 UTF-16 代码单元序列。UTF-16 代码单元是表示字符串中字符的数字值。例如，数字 65、66 和 67 分别代表字符 "A"、"B" 和 "C"。因此，在数组中数字 200 会排在数字 3 前面，因为字符串 "200" 在比较 UTF-16 代码单元时排在字符串 "3" 前面。

:::interactive_editor

```js
const numbers = [414, 200, 5, 10, 3];

numbers.sort((a, b) => a - b);

console.log(numbers); // [3, 5, 10, 200, 414]
```

:::

参数 `a` 和 `b` 是正在比较的两个元素。比较函数应返回负值，如果 `a` 应该排在 `b` 之前；返回正值，如果 `a` 应该排在 `b` 之后；如果 `a` 和 `b` 相等，则返回零。

## 使用 `every` 和 `some` 方法

- **`every()` 方法**：该方法测试数组中的所有元素是否都通过由提供的函数实现的测试。如果提供的函数对数组中所有元素都返回 `true`，则 `every()` 方法返回 `true`。如果有任何元素未通过测试，该方法会立即返回 `false` 并停止检查剩余元素。

- **`some()` 方法**：该方法检查是否至少有一个元素通过测试。`some()` 方法一旦找到通过测试的元素就返回 `true`。如果没有元素通过测试，则返回 `false`。

## 使用 DOM 和 Web API

- **API**：API（应用程序编程接口）是一组规则和协议，允许软件应用程序之间高效通信和数据交换。
- **Web API**：Web API 专门为 Web 应用设计。这类 API 通常分为两大类：浏览器 API 和第三方 API。
- **浏览器 API**：这些 API 暴露浏览器中的数据。作为 Web 开发者，你可以使用 JavaScript 访问和操作这些数据。
- **第三方 API**：这些 API 默认不内置于浏览器中。你需要以某种方式获取它们的代码。通常，它们会有详细文档说明如何使用其服务。比如 Google Maps API，可以用来在你的网站上显示交互式地图。
- **DOM**：DOM 代表文档对象模型。它是一个编程接口，允许你与 HTML 文档交互。通过 DOM，你可以添加、修改或删除网页上的元素。DOM 树的根节点是 `html` 元素。它是 HTML 文档所有内容的顶层容器。所有其他节点都是该根节点的后代。根节点下方是层次结构中的其他节点。父节点是包含其他元素的元素。子节点是被包含在另一个元素内的元素。
- **`navigator` 接口**：该接口提供有关浏览器环境的信息，如用户代理字符串、平台和浏览器版本。用户代理字符串是一个文本字符串，用于标识正在使用的浏览器和操作系统。
- **`window` 接口**：该接口表示包含 DOM 文档的浏览器窗口。它提供与浏览器窗口交互的方法和属性，如调整窗口大小、打开新窗口和导航到不同 URL。

## 使用 `querySelector()`、`querySelectorAll()` 和 `getElementById()` 方法

- **`getElementById()` 方法**：该方法用于获取表示具有指定 `id` 的 HTML 元素的对象。请记住，id 在每个 HTML 文档中必须唯一，因此该方法只会返回一个元素对象。

- **`querySelector()` 方法**：该方法用于获取 HTML 文档中第一个匹配传入的 CSS 选择器的元素。

- **`querySelectorAll()` 方法**：你可以使用该方法获取所有匹配特定 CSS 选择器的 DOM 元素列表。

## 使用 `innerText()`、`innerHTML()`、`createElement()` 和 `textContent()` 方法

- **`innerHTML` 属性**：这是 `Element` 的一个属性，用于设置或更新 HTML 标记的部分内容。

- **`createElement` 方法**：该方法用于创建 HTML 元素。

- **`innerText`**：表示 HTML 元素及其后代的可见文本内容。

- **`textContent`**：返回元素的纯文本内容，包括其所有后代中的文本。

## 使用 `appendChild()` 和 `removeChild()` 方法

- **`appendChild()` 方法**：该方法用于将节点添加到指定父节点的子节点列表末尾。

- **`removeChild()` 方法**：该方法用于从 DOM 中移除节点。

## 使用 `setAttribute()` 方法

- **定义**：该方法用于为给定元素设置属性。如果属性已存在，则更新其值。否则，添加一个带有值的新属性。

## 事件对象

- **定义**：`Event` 对象是当用户以某种方式与网页交互时触发的负载。这些交互可以是点击按钮、聚焦输入框，甚至摇动移动设备。所有 `Event` 对象都会有 `type` 属性。该属性显示触发负载的事件类型，如 keydown 或 click。这些值对应于你可能传递给 `addEventListener()` 的值，在那里你可以捕获并使用 `Event` 对象。

## `addEventListener()` 和 `removeEventListener()` 方法

- **`addEventListener` 方法**：该方法用于监听事件。它接受两个参数：你想监听的事件和事件发生时调用的函数。常见事件示例包括点击事件、输入事件和更改事件。

:::interactive_editor

```html
<button id="btn">Click Me</button>
<script src="./index.js"></script>
```

```js
const btn = document.getElementById("btn");

btn.addEventListener("click", () => alert("You clicked the button"));
```

:::

- **`removeEventListener()` 方法**：该方法用于移除之前使用 `addEventListener()` 方法添加到元素上的事件监听器。当你想停止监听某个元素的特定事件时，这非常有用。

- **内联事件处理程序**：内联事件处理程序是 HTML 元素上的特殊属性，用于在事件发生时执行 JavaScript 代码。在现代 JavaScript 中，内联事件处理程序不被视为最佳实践。更推荐使用 `addEventListener` 方法。

## Change 事件

- **定义**：change 事件是当用户修改某些输入元素的值时触发的特殊事件。例如，勾选复选框或单选按钮，或者用户从日期选择器或下拉菜单中做出选择。

## 事件冒泡

- **定义**：事件冒泡，或传播，指的是事件在被触发时如何“冒泡”到父对象。
- **`stopPropagation()` 方法**：此方法阻止事件的进一步传播。

## 事件委托

- **定义**：事件委托是监听冒泡到父元素的事件，而不是直接在触发事件的元素上处理事件的过程。

## DOMContentLoaded

- **定义**：`DOMContentLoaded` 事件在 HTML 文档的所有内容加载和解析完成时触发。如果你有外部样式表或图像，`DOMContentLoaded` 事件不会等待它们加载完成，只会等待 HTML 加载完成。

## 使用 `style` 和 `classList`

- **`Element.style` 属性**：这是一个只读属性，表示元素的内联样式。你可以使用该属性获取或设置元素的样式。

- **`Element.classList` 属性**：这是一个只读属性，可用于添加、移除或切换元素的类。

## 使用 `setTimeout()` 和 `setInterval()` 方法

- **`setTimeout()` 方法**：该方法允许你延迟指定时间后执行某个操作。

- **`setInterval()` 方法**：此方法会以设定的间隔重复运行一段代码。由于 `setInterval()` 会在指定的间隔持续执行提供的函数，你可能想要停止它。为此，你必须使用 `clearInterval()` 方法。

## `requestAnimationFrame()` 方法

- **定义**：该方法允许你在下一次屏幕重绘之前安排动画的下一步，从而实现流畅且视觉上吸引人的体验。下一次屏幕重绘指的是浏览器刷新网页视觉显示的时刻。大多数显示器每秒刷新约 60 次（即 60 帧每秒）。

## Web 动画 API

- **定义**：Web 动画 API 允许你直接在 JavaScript 中创建和控制动画。

## Canvas API

- **定义**：Canvas API 是一个强大的工具，允许你直接在 JavaScript 文件中操作图形。要使用 Canvas API，首先需要在 HTML 中提供一个 `canvas` 元素。该元素作为绘图表面，你可以通过 Canvas API 中接口的实例方法和属性来操作它。该 API 包含 `HTMLCanvasElement`、`CanvasRenderingContext2D`、`CanvasGradient`、`CanvasPattern` 和 `TextMetrics` 等接口，这些接口包含你可以用来在 JavaScript 文件中创建图形的方法和属性。

## 使用 JavaScript 打开和关闭对话框和模态框

- **模态框和对话框定义**：对话框允许你向用户显示重要信息或操作。借助 HTML 内置的 dialog 元素，你可以轻松在 Web 应用中创建这些对话框（包括模态和非模态对话框）。模态对话框是一种强制用户在访问应用或网页其他部分之前与其交互的对话框。相比之下，非模态对话框允许用户在对话框打开时继续与页面或应用的其他部分交互，不会阻止访问其余内容。
- **`showModal()` 方法**：该方法用于打开模态框。

- **`close()` 方法**：该方法用于关闭模态框。

## 常见的 ARIA 无障碍 属性

- **`aria-expanded` 属性**：用于向屏幕阅读器用户传达切换（或展开）特色的状态。

- **`aria-haspopup` 属性**：此状态用于指示交互元素激活时将触发弹出元素。只有当弹出元素具有以下角色之一时，才能使用 `aria-haspopup` 属性：`menu`、`listbox`、`tree`、`grid` 或 `dialog`。`aria-haspopup` 的值必须是这些角色之一或 `true`，true 等同于 `menu`。

- **`aria-checked` 属性**：此属性用于指示元素是否处于选中状态。它最常用于创建自定义复选框、单选按钮、开关和列表框时。

- **`aria-disabled` 属性**：此状态用于仅向使用辅助技术（例如屏幕阅读器）的人指示某个元素已被禁用。

- **`aria-selected` 属性**：此状态用于指示某个元素被选中。你可以在自定义控件中使用此状态，例如标签（页）接口、列表框或网格。

- **`aria-controls` 属性**：用于将一个元素与它控制的另一个元素关联起来。这有助于使用辅助技术的人理解这些元素之间的关系。

- **`hidden` 属性**：隐藏非活动窗格，既对视觉用户也对辅助技术用户不可见。

## 使用实时区域和动态内容

- **`aria-live` 属性**：使网页的一部分成为实时区域，意味着该区域内的任何更新都会被屏幕阅读器宣布，以便用户不会错过重要更改。
- **`polite` 值**：大多数实时区域使用此值。此值表示更新不是紧急的，因此屏幕阅读器可以等待完成当前的任何播报或用户完成当前操作后再播报更新。

下面是一个由 JavaScript 动态更新的实时区域示例：

:::interactive_editor

```html
<div aria-live="polite" id="status"></div>

<button id="updateStatus">Update Status</button>

<script>
  const statusEl = document.getElementById("status");
  const btn = document.getElementById("updateStatus");

  btn.addEventListener("click", () => {
    statusEl.textContent = "Your file has been successfully uploaded.";
  });
</script>
```

:::

- **`contenteditable` 属性**：将元素变成一个实时编辑器，允许用户像操作文本字段一样更新其内容。当 contenteditable 区域没有可见的标签或标题时，使用 `aria-label` 属性添加一个可访问名称，以帮助屏幕阅读器用户理解可编辑区域的用途。

- **`focus` 事件**：当元素获得焦点时触发。

## 常见错误信息类型

- **SyntaxError**：当你在代码中写错语法时发生的错误，比如缺少括号或方括弧。可以把它想象成句子中的语法错误。

- **ReferenceError**：有多种类型的引用错误，由不同情况触发。第一种引用错误是未定义的变量。另一个例子是尝试访问用 `let` 或 `const` 声明但尚未定义的变量。

- **TypeError**：当你尝试对错误类型执行操作时发生的错误。

- **RangeError**：当代码尝试使用超出 JavaScript 可处理范围的值时发生的错误。

## `throw` 语句

- **定义**：JavaScript 中的 `throw` 语句用于抛出用户定义的异常。编程中的异常是指当发生意外事件并中断程序的正常流程时。

## `try...catch...finally`

- **定义**：`try` 块用于包裹可能抛出错误的代码。它作为一个安全区，尝试可能失败的操作。`catch` 块捕获并处理 try 块中发生的错误。你可以在 catch 中使用错误对象检查错误原因。`finally` 块在 try 和 catch 块之后执行，无论是否发生错误。它通常用于清理任务，如关闭文件或释放资源。

:::interactive_editor

```js
function processInput(input) {
  if (typeof input !== "string") {
    throw new TypeError("Input must be a string.");
  }

  return input.toUpperCase();
}

try {
  console.log("Starting to process input...");
  const result1 = processInput("hello");
  console.log("Processed result:", result1);  // HELLO
  const result2 = processInput(9);  // throws TypeError
  console.log("Processed result:", result2);  // not executed
} catch (error) {
  console.error("Error occurred:", error.message);
} 
```

:::

## 正则表达式和常用方法

- **定义**：正则表达式（Regex）用于创建一个“模式”，你可以用它来检查字符串、提取文本等。

- **`RegExp` 构造函数**：当你的模式或标记来自变量时，你可以使用 `RegExp` 构造函数构建相同类型的正则表达式。它接受一个模式字串和一个可选的标记字串。

例如，`new RegExp(pattern, flags)` 从这些字符串构建一个正则表达式。

- **`test()` 方法**：该方法接受一个字符串，用于测试该字符串是否与正则表达式匹配。该方法返回一个布尔值，表示字符串是否匹配正则表达式。

- **`match()` 方法**：该方法接受一个正则表达式，也可以传入一个字符串，该字符串会被构造为正则表达式。`match` 方法返回字符串的匹配数组。

- **`replace()` 方法**：该方法接受两个参数：要匹配的正则表达式（或字符串），以及用于替换匹配项的字符串（或对每个匹配项运行的函数）。

- **`replaceAll` 方法**：该方法用于将指定模式的所有出现替换为新字符串。如果传入的正则表达式没有全局修饰符，则会抛出错误。

- **`matchAll` 方法**：该方法用于检索字符串中给定正则表达式的所有匹配项，包括捕获组，并以迭代器形式返回。迭代器是一个允许你遍历集合的对象。

## 正则表达式修饰符

- **定义**：修饰符，通常称为“标记”，用于修改正则表达式的行为。
- **`i` 标记**：该标记使正则表达式忽略大小写。

- **`g` 标记**：该标记，也称为全局修饰符，允许正则表达式多次匹配模式。

- **锚点定义**：正则表达式开头的 `^` 锚点表示“匹配字符串开头”。正则表达式结尾的 `$` 锚点表示“匹配字符串结尾”。

- **`m` 标记**：锚点用于查找整个字符串的开头和结尾。但你可以使用 `m` 标记（多行修饰符）让正则表达式处理多行。

- **`d` 标记**：此标记会将匹配项和捕获组的起始和结束索引添加到匹配对象中。

- **`u` 标记**：这个标记扩展了正则表达式的功能性，使其能够匹配特殊的 unicode 字符。`u` 标记让你可以访问像 `Extended_Pictographic` 这样的特殊类，以匹配大多数表情符号。还有一个 `v` 标记，进一步扩展了 unicode 匹配的功能性。
- **`y` 标记**：粘性修饰符的行为与全局修饰符非常相似，但有一些例外。最大区别是，全局正则表达式会从 lastIndex 开始，搜索字符串剩余部分的另一个匹配项，而粘性正则表达式如果在上一个 lastIndex 位置没有立即匹配，则会返回 null 并将 lastIndex 重置为 0。
- **`s` 标记**：单行修饰符允许通配符字符（在正则表达式中用 `.` 表示）匹配换行符——实际上将字符串视为单行文本。

## 字符类

- **通配符 `.`**：字符类是一种特殊语法，用于匹配字符的集合或子集。你应该学习的第一个字符类是通配符类。通配符用句点（点号）表示，匹配除换行符之外的任意单个字符。要让通配符匹配换行符，记得需要使用 `s` 标记。

- **`\d`**：这将匹配字符串中的所有数字（`0-9`）。

- **`\w`**：用于匹配字符串中的任何单词字符（`a-zA-Z0-9_`）。单词字符定义为任意字母（a 到 z 或 A 到 Z）、数字（0 到 9）或下划线字符。

- **`\s`**：空白字符类 `\s` 由反斜杠后跟一个 `s` 表示。此字符类匹配任何空白字符，包括换行、空格、制表符和特殊的 Unicode 空格字符。
- **否定特殊字符类**：要否定这些字符类之一，可以使用大写字母代替反斜杠后的小写字母。例如，`\D` 匹配任何非数字字符。

- **自定义字符类**：你可以通过将想匹配的字符放入一对方括弧中来创建自定义字符类。

例如，`/[abcdf]/` 匹配方括号中的任意一个字符。

## 前瞻和后顾断言

- **定义**：前瞻和后顾断言允许你根据周围模式的存在或缺失来匹配特定模式。
- **正向前瞻断言**：当某个模式后面跟着另一个模式时，该断言匹配该模式。构造正向前瞻时，先写要匹配的模式，然后用括号包裹你想用作条件的模式。在开括号后使用 `?=` 来定义该模式为正向前瞻。

例如，`/free(?=code)/i` 匹配后面跟着 `code` 的 `free`。

- **负向前瞻断言**：这是一种条件，用于检查字符串前方不出现某个特定模式。

例如，`/free(?!code)/i` 匹配后面不跟着 `code` 的 `free`。

- **正向后顾断言**：该断言仅在某模式前面有另一个特定模式时匹配，但不包括前面的模式。

例如，`/(?<=free)code/i` 匹配前面是 `free` 的 `code`。

- **负向后顾断言**：该断言确保某模式前面不紧跟另一个特定模式。仅当指定模式前面没有给定序列时匹配，且不包括前面的序列。

例如，`/(?<!free)code/i` 匹配前面不是 `free` 的 `code`。

## 正则表达式量词

- **定义**：正则表达式中的量词指定模式（或模式的一部分）应出现的次数。它们帮助控制字符或组在匹配中的出现次数。

例如，`/^\d{4}$/` 匹配恰好包含四个数字的字符串。

- **`*`** ：匹配前一个元素出现 0 次或多次。
- **`+`**：匹配前一个元素出现 1 次或多次。
- **`?`**：匹配前一个元素出现 0 次或 1 次。
- **`{n}`**：匹配前一个元素恰好出现 n 次。
- **`{n,}`**：匹配前一个元素出现 n 次或更多次。
- **`{n,m}`**：匹配前一个元素出现 n 到 m 次。

## 捕获组和反向引用

- **捕获组**：捕获组允许你“捕获”匹配字符串的一部分，以便你需要时使用。捕获组由包含要捕获模式的括号定义，不带前导字符如前瞻。

例如，`/free(code)camp/i` 捕获了 `code`。

- **非捕获组**：非捕获组类似于捕获组，但不会保存匹配的字串部分以供后续使用。非捕获组由 `(?:...)` 定义。

例如，`/free(?:code)camp/i` 对 `code` 进行了分组但不捕获它。

- **反向引用**：正则表达式中的反向引用是指在同一表达式中重用之前匹配的部分。它允许你通过编号引用捕获组（括号内的模式）。例如，`$1` 指代第一个捕获组。

:::interactive_editor

```js
const regex = /free(co+de)camp/i;
console.log("freecoooooooodecamp".replace(regex, "paid$1world"));
```

:::

- 你可以在正则表达式内部使用反向引用，通过斜线和捕捉组编号来匹配之前捕捉的相同文本。例如：

:::interactive_editor

```js
const regex = /(hello) \1/i;
console.log(regex.test("hello hello")); // true
console.log(regex.test("hello world")); // false
```

:::

## 使用 JavaScript 验证表单

- **约束验证 API**：某些 HTML 元素，如 `textarea` 和 `input` 元素，暴露了约束验证 API。该 API 允许你断言用户为该元素提供的值是否通过了你编写的任何 HTML 级别验证，如最小长度或模式匹配。
- **`checkValidity()` 方法**：如果元素通过所有基于其属性的 HTML 验证，该方法返回 `true`，否则返回 `false`。

- **`reportValidity()` 方法**：该方法告诉浏览器 `input` 是无效的。

- **`validity` 属性**：该属性用于获取表单控件（如 `<input>`、`<select>` 等）的有效性状态，并提供有关用户输入是否满足为该元素定义的约束（例如 `required` 字段、模式约束、最大长度等）的信息。

- **`patternMismatch` 属性**：如果值不匹配指定的正则表达式模式，该属性将为 `true`。

## `preventDefault()` 方法

- **定义**：DOM 中触发的每个事件都有某种默认行为。例如，复选框的点击事件默认会切换该复选框的状态。按下聚焦按钮上的 <kbd>Spacebar</kbd> 会激活该按钮。`Event` 对象上的 `preventDefault()` 方法可以阻止这些默认行为的发生。

## 提交表单

- **定义**：表单可以通过三种方式提交。第一种是用户点击表单中 `type` 属性设置为 `submit` 的按钮。第二种是用户在表单中任何可编辑的 `input` 字段上按下 <kbd>Enter</kbd> 键。第三种是通过 JavaScript 调用 `form` 元素的 `requestSubmit()` 或 `submit()` 方法。
- **`action` 属性**：`action` 属性应包含一个 URL 或当前域的相对路径。该值决定了表单尝试发送数据的位置——如果未设置 `action` 属性，表单将把数据发送到当前页面的 URL。

- **`method` 属性**：该属性接受标准的 `HTTP` 方法，如 `GET` 或 `POST`，并在向 action URL 发起请求时使用该方法。未设置方法时，表单默认使用 `GET` 请求。表单中的数据将作为 `name=value` 键值对进行 URL 编码，并附加到 action URL 作为查询参数。

- **`enctype` 属性**：`form` 元素接受一个 `enctype` 属性，该属性表现用于数据的编码类型。此属性仅接受三个值：`application/x-www-form-urlencoded`（这是默认值，将数据作为 URL 编码的形式体发送）、`text/plain`（以纯文本形式发送数据，使用换行符分隔的 `name=value` 点对），或 `multipart/form-data`，专门用于处理带有文件上传的形式。

## `date()` 对象和常用方法

- **定义**：`date()` 对象用于在 JavaScript 中创建、操作和格式化日期和时间。例如，`const now = new Date();` 创建了一个 `Date` 对象的新实例并赋值给变量 `now`。如果你将 `now` 的值打印到控制台，你会看到基于运行代码的计算机系统时钟的当前日期和时间。

- **`Date.now()` 方法**：此方法用于获取当前日期和时间。`Date.now()` 返回自 1970 年 1 月 1 日 00:00:00 UTC 以来的毫秒数。这被称为 Unix 纪元时间。Unix 纪元时间是在计算机系统中表现日期和时间的常用方式，因为它是一个可以轻松保存和操作的整数。UTC 代表协调世界时，是全球调节时钟和时间的主要时间标准。
- **`getDate()` 方法**：此方法用于根据当前日期获取一个月份中的某一天。`getDate()` 将返回一个介于 1 和 31 之间的整数值，具体取决于当月的日期。如果日期无效，它将返回 `NaN`（非数字）。

- **`getMonth()` 方法**：此方法用于获取月份。月份是从零开始的，所以一月是 0，二月是 1，依此类推。例如，在十月调用 `getMonth()` 返回 `9`。如果月份无效，则返回 `NaN`。

- **`getFullYear()` 方法**：该方法用于获取完整年份。如果年份无效，则返回 `NaN`。

## 不同的日期格式化方式

- **`toISOString()` 方法**：该方法用于以扩展的 `ISO`（ISO 8601）格式格式化日期。ISO 8601 是表示日期和时间的国际标准。格式为 `YYYY-MM-DDTHH:mm:ss.sssZ`。

- **`toLocaleDateString()` 方法**：该方法根据用户的区域设置格式化日期。

`toLocaleDateString()` 方法接受两个可选参数：locales 和 options。

locales 参数是表示要使用的区域设置的字符串。例如，你可以传入 `"en-US"` 表示英语（美国），或 `"fr-FR"` 表示法语（法国）。如果不传入 locales 参数，则使用默认区域设置。第二个可选参数是 options 参数。该参数是一个对象，允许你指定日期字符串的格式。

## `Audio` 构造函数和常用方法

- **定义**：`Audio` 构造函数，像其他构造函数一样，是一个使用 `new` 关键字调用的特殊函数。它返回一个 `HTMLAudioElement`，你可以用它为用户播放音频，或追加到 DOM 中让用户自行控制。当你调用构造函数时，可以可选地传入一个 URL 作为（唯一）参数。该 URL 应指向你想播放的音频文件的源。或者，如果你需要动态更改源，可以将 URL 赋值给返回的音频元素的 `src` 属性。
- **`play()` 方法**：此方法用于 `audio` 或 `video` 元素以开始媒体播放。

- **`pause()` 方法**：此方法用于 `audio` 或 `video` 元素以暂停媒体播放。它维护当前播放位置，因此如果调用 `play()`，会从该位置开始播放。

- **`addTextTrack()` 方法**：该方法允许你为媒体元素指定文本轨道，特别适合为视频添加字幕。
- **`fastSeek()` 方法**：该方法允许你将播放位置移动到媒体中的特定时间。

`Audio()` 构造函数既有方法，也有属性。这些属性包括：

- `currentTime`：获取音频当前的播放时间
- `loop`：使音频循环播放，播放结束时自动重新开始
- `muted`：无论音量设置如何，静音媒体元素的音频输出

## 不同的音频和视频格式

- **MIME 类型**：MIME 类型，全称多用途互联网邮件扩展，是一种以编程方式指示文件类型的标准化方式。MIME 类型可以告诉应用程序（例如浏览器）如何处理特定文件。对于音频和视频，MIME 类型表示它是可以嵌入网页的多媒体格式。
- **`source` 元素**：用于指定文件类型和源——可以通过使用多个 source 元素包含多种不同类型。当你这样做时，浏览器会根据用户当前环境确定最佳格式。
- **MP3**：一种用于存储音乐、音频或声音的数字文件格式。它是声音录音的压缩版本，使文件大小更小，更易于保存和分享。MP3 拥有最广泛的浏览器支持，MIME 类型为 `audio/mpeg`。
- **MP4**：一种用于存储视频和音频的数字文件格式。它作为一个容器，将视频（图像）和声音（音乐或语音）保存在一个文件中。MP4 的 MIME 类型可以是 `audio/mp4` 或 `video/mp4`，取决于是视频文件还是仅音频。
- 其他格式包括与 Windows Media Player 关联的 `WMV`，以及 `OGG`、`MKV`、`AVI` 等。

## 编解码器

- **定义**：编解码器（codec，编码器/解码器）是一种算法或软件，可以在模拟和数字格式之间转换音频和视频。编解码器可以作为 MIME 类型的一部分指定。定义编解码器的基本语法是在媒体类型后添加分号，然后是 `codecs=` 和编解码器名称。

## HTMLMediaElement API

- **定义**：`HTMLMediaElement` API 用于控制页面上的音频和视频元素的行为。它扩展了基础的 `HTMLElement` 接口，因此你可以访问基础属性、方法以及诸如 `waiting`、`ended`、`canplay`、`canplaythrough` 等有用事件。方法示例包括 `play()`、`fastSeek()`、`pause()`，以及用于检查浏览器是否可能播放某音频文件的 `canPlayType()`。

## 媒体捕获和流 API

- **定义**：媒体捕获和流 API（MediaStream API）用于从设备捕获音频和视频。要使用该 API，你需要创建 `MediaStream` 对象。你可以用构造函数创建，但它不会绑定到用户硬件。相反，`global` 导航器对象的 `mediaDevices` 属性有一个 `getUserMedia()` 方法供你使用。

## 屏幕捕获 API

- **定义**：屏幕捕获 API 用于录制用户屏幕。该 API 通过调用 `mediaDevices` 对象的 `getDisplayMedia()` 方法并使用返回的媒体流实现。

## MediaStream 录制 API

- **定义**：MediaStream 录制 API 与 MediaStreams API 配合使用，允许你录制 MediaStream（甚至直接录制 `HTMLMediaElement`）。

## 媒体源扩展 API

- **主题**：Media Source Extensions API 允许你通过 `srcObject` 属性将用户的摄像头视频直接传递给视频元素。

## Web 音频 API

- **定义**：Web Audio API 是驱动网页上所有可听内容的基础。该 API 包含重要的对象，如表示专门包含音频数据的缓冲区的 `AudioBuffer`，或用于表现音频处理图的 `AudioContext`。

## JavaScript 中的集合（Sets）

- `Set` 是管理数据集合的内置选项。
- Sets 确保其中的每个值只出现一次，这使其在消除数组重复项或处理不同值的集合时非常有用。
- 你可以使用 `Set()` 构造函数创建一个 `Set`。

- 集合可以通过以下方法操作：

  - `add()`：为 `Set` 添加一个新建元素。
  - `delete()`：从 `Set` 中移除一个元素。
  - `has()`：查看 `Set` 中是否存在某个元素。
  - `clear()`：从 `Set` 中移除所有元素。
  - `keys()` 和 `values()`：两者都返回包含 `Set` 值的 `SetIterator`。它们是相同的，因为 `keys()` 是 `values()` 的别名。
  - `forEach()`：用于遍历 `Set` 的值。

## JavaScript 中的弱集合（Weaksets）

- `WeakSet` 是一个对象集合，允许你存储弱引用的对象。

## 集合与弱集合的区别

- 与集合不同，`WeakSet` 不支持数字或字符串等原语。
- `WeakSet` 只存储对象，对这些对象的引用是“弱引用”，意味着如果对象在代码中未被其他地方使用，会自动移除以释放内存。

## JavaScript 中的映射（Maps）

- `Map` 是一个内置对象，持有键值对，就像对象一样。
- Maps 与标准 JavaScript 对象不同，它允许键为任何类型，包括对象和函数。
- 在频繁添加和删除键值对时，`Map` 提供比标准对象更好的性能。
- 你可以使用 `Map()` 构造函数创建一个 `Map`。

- 映射可以通过以下方法操作：

  - `set()`：向 `Map` 添加新的键值对。
  - `get()`：从 `Map` 获取键对应的值。
  - `delete()`：从 `Map` 移除键值对。
  - `has()`：检查键是否存在于 `Map`。
  - `clear()`：移除 `Map` 中的所有键值对。

请注意，Maps 和 Sets 都有 `size` 属性，该属性返回其中唯一元素的数量。

## JavaScript 中的弱映射（WeakMaps）

- `WeakMap` 是一个键值对集合，类似 `Map`，但对键使用弱引用。键必须是对象，值可以是任意类型。

## Maps 与 WeakMaps 的区别

- WeakMaps 类似于 WeakSets，它们只存储对象，并且对这些对象的引用是“弱引用”。

## 持久存储

- **定义**：持久存储指的是一种保存数据的方式，即使断电或设备重启后数据仍然可用。

## 创建、读取、更新、删除（CRUD）

- **创建**：这指的是创建新数据的过程。例如，在一个网页应用中，这可能是用户为博客添加新帖子的时候。
- **读取**：这是从数据库中检索数据的操作。例如，当你访问博客文章或查看你的网站评测时，你正在执行读取操作以获取并显示保存在数据库中的数据。
- **更新**：这涉及修改数据库中现有的数据。一个例子是编辑博客文章或更新你的评测信息。
- **删除**：这是从数据库中移除数据的操作。例如，当你删除一篇博客文章或账户时，你正在执行删除操作。

## HTTP 方法

- **定义**：HTTP 代表超文本传输协议，它是网络上数据通信的基础。存在 HTTP 方法，用于定义可以在网络资源上执行的操作。常见的方法有 GET、POST、PUT、PATCH、DELETE。
- **`GET` 方法**：这用于从服务器获取数据。
- **`POST` 方法**：这用于向服务器提交数据，从而创建一个新资源。
- **`PUT` 方法**：用于通过完全替换来更新资源。
- **`PATCH` 方法**：用于部分更新资源。
- **`DELETE` 方法**：用于从数据库中删除记录。

## `localStorage` 和 `sessionStorage` 属性

- **Web Storage API**：该 API 为浏览器提供了一种机制，可以在浏览器内直接保存键值对，允许开发者存储可跨不同页面重载和会话使用的信息。Web Storage API 的两个主要组件是 `localStorage` 和 `sessionStorage` 属性。
- **`localStorage` 属性**：`localStorage` 是 Web Storage API 的一部分，允许数据即使在浏览器窗口关闭或页面刷新后仍然保持持久。该数据将一直可用，直到被应用或用户显式移除。
- **`localStorage.setItem()` 方法**：此方法用于在 `localStorage` 中保存一个密钥-值对。

- **`localStorage.getItem()` 方法**：此方法用于从 `localStorage` 中检索给定密钥的值。

- **`localStorage.removeItem()` 方法**：此方法用于通过其密钥从 `localStorage` 中移除特定项。

- **`localStorage.clear()` 方法**：此方法用于清除 `localStorage` 中保存的所有数据。

- **`sessionStorage` 属性**：存储仅在当前会话中存在的数据，浏览器标签（页）或窗口关闭时会被清除。
- **`sessionStorage.setItem()` 方法**：此方法用于在 `sessionStorage` 中保存一个密钥-值点对。

- **`sessionStorage.getItem()` 方法**：此方法用于从 `sessionStorage` 中检索给定密钥的值。

- **`sessionStorage.removeItem()` 方法**：此方法用于通过其密钥从 `sessionStorage` 中移除特定项。

- **`sessionStorage.clear()` 方法**：此方法用于清除存储在 `sessionStorage` 中的所有数据。

## 使用 Cookie

- **定义**：Cookie，也称为网页 Cookie 或浏览器 Cookie，是服务器发送到用户网页浏览器的小块数据。这些 Cookie 存储在用户设备上，并在后续请求中发送回服务器。Cookie 对于帮助网页应用维护状态和记住用户信息至关重要，这一点尤其重要，因为 HTTP 是无状态协议。
- **会话 Cookies**：这些 Cookies 仅在用户在网站上的会话期间有效。一旦用户关闭浏览器或标签（页），会话 Cookie 就会被删除。这些 Cookies 通常用于保持用户在访问期间的登录状态等任务。
- **安全 Cookie**：这些 Cookie 仅通过 HTTPS 发送，确保它们在传输过程中不会被攻击者截获。
- **HttpOnly Cookies**：这些 Cookie 无法被浏览器中运行的 JavaScript 访问或修改，从而使它们在防范跨站脚本（XSS）攻击方面更安全。
- **Set-Cookie 头部**：当你访问一个网站时，服务器可以在 HTTP 响应中发送一个 Set-Cookie 头部。该头部告诉你的浏览器储存一个包含特定信息的 cookie。例如，它可能保存一个唯一 ID，帮助网站在你下次访问时识别你。  
你可以使用 `document.cookie` 在 JavaScript 中手动设置 cookie：

```js
document.cookie = "organization=freeCodeCamp; expires=Fri, 31 Dec 2021 23:59:59 GMT; path=/";
```

要删除 cookie，你可以将其过期时间设置为过去的某个时间。

## 缓存 API

- **定义**：缓存是将文件副本存储在临时存储位置的过程，以便可以更快速地访问它们。Cache API 用于保存网络请求和响应，使网页应用更高效，甚至可以离线运行。它是更广泛的 Service Worker API 的一部分，对于创建能够在不可靠或缓慢网络条件下工作的渐进式网页应用（PWA）至关重要。  
Cache API 是一种存储机制，用于存储 Request 和 Response 对象。当向服务器发出请求时，应用可以保存响应，并在以后从缓存中检索，而不是发出新的网络请求。这减少了装载时间，节省了带宽，并提升了整体用户体验。
- **缓存存储**：用于保存 HTTP 请求及其对应响应的键值点对。这使得能够高效地检索先前请求的资源，减少后续访问时从网络获取的需求，从而提升性能。
- **Cache-Control**：开发者可以定义缓存资源应保留多长时间，以及是否应重新验证或直接从缓存中提供。
- **离线支持**：通过使用 Cache API，你可以创建离线优先的网页应用。例如，当用户断开网络时，PWA 可以提供缓存的资源。

## 负面模式和客户端存储

- **过度跟踪**：指在没有明确、知情同意或合法需求的情况下，在客户端存储（例如 cookie、local storage 或 session storage）中收集和存储过多的用户数据的做法。这通常涉及跨多个站点或会话跟踪用户行为、偏好和交互，可能侵犯用户隐私。
- **浏览器指纹识别**：一种基于设备和浏览器的独特特征来跟踪和识别单个用户的技术，而不是依赖于 cookie 或其他传统的跟踪方法。与存储在用户设备上的 cookie 不同，指纹识别涉及收集一系列信息，这些信息可用于创建用户浏览器会话的独特“指纹”。
- **在 LocalStorage 中设置密码**：这看起来可能是一个更明显的负面模式，但在局部存储中设置任何敏感数据如密码都会带来安全性风险。局部存储未加密且可以轻松访问。因此，你绝不应该将任何类型的敏感数据保存其中。

## 索引数据库

- **定义**：IndexedDB 用于在浏览器中保存结构化数据。它内置于现代网页浏览器中，允许网页应用高效地保存和获取 JavaScript 对象。

## 缓存/服务工作者

- **定义**：Service Worker 是一个在后台运行的脚本，独立于你的网页。它可以拦截网络请求，访问缓存，并使网页应用离线工作。这是渐进式网页应用的关键组件。

## 类的基础知识

- **定义**：JavaScript 中的类用于定义创建对象的蓝图并封装数据。类包含构造函数，这是一个特殊方法，在从类创建新对象时自动调用，用于初始化对象的属性。这里使用 `this` 关键字引用当前类的实例。构造函数下方可以定义称为方法的函数。方法是在类内部定义的函数，用于对类的数据或状态执行操作，定义类实例可以执行的行为。

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);  // Gino
```

:::

要创建类的新实例，你将使用 `new` 关键字，后跟类名。

你也可以创建类表达式，即匿名类赋值给变量。

## 类继承

- **定义**：编程中，继承允许定义从父类继承属性和方法的类。这促进代码复用并建立类之间的层级关系。父类是作为其他类蓝图的类，定义被继承的属性和方法。子类继承另一个类的属性和方法，还可以通过添加新属性和方法扩展父类功能。在 JavaScript 中，使用 `extends` 关键字实现继承，表示一个类是另一个类的子类。

使用 `super` 关键字访问父类的方法、构造函数和字段。

:::interactive_editor

```js
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  constructor(brand, year, numDoors) {
    super(brand, year);
    this.numDoors = numDoors;
  }
}

const myCar = new Car("freeCodeCamp Motors", 2019, 4);
console.log(myCar.brand);  // freeCodeCamp Motors
console.log(myCar.year);  // 2019
console.log(myCar.numDoors);  // 4
```

## 使用静态方法和静态属性

- **静态方法**：这些方法通常用于不需要访问对象特定状态的工具函数。它们定义在类中，用于封装相关功能。

使用 `static` 关键字定义静态方法，并在类本身上调用它。

静态方法也有助于实现“工厂”方法。工厂方法是在构造函数之外定义的，用于根据特定条件创建对象的方法。

- **静态属性**：这些属性用于定义与类本身关联的值或属性，而不是类的实例。静态属性在所有实例间共享，可无需创建实例即可访问。

例如，`static numberOfWheels = 4;` 在类内部定义了一个静态属性。

- 递归是一种编程概念，允许你重复调用一个函数，直到达到基准分支。

下面是一个计算数字阶乘的递归函数示例：

```js
function findFactorial(n) {
  if (n === 0) {
    return 1;
  }
  return n * findFactorial(n - 1);
}
```

在上述示例中，`findFactorial` 函数被递归调用，直到 `n` 达到 `0`。当 `n` 为 `0` 时，达到基本情形，函数返回 `1`。然后函数返回 `n` 与递归调用 `findFactorial(n - 1)` 结果的乘积。

- 递归允许你处理具有未知深度的内容，例如深度嵌套的对象/数组，或文件树。
- 调用栈用于跟踪递归函数中的函数调用。每次调用函数时，都会将其添加到调用栈中。当达到基本情形时，函数调用会从栈中移除。
- 你应该仔细定义基本情形，因为无限调用它会导致你的代码崩溃。这是因为递归不断堆积越来越多的函数调用，直到系统内存耗尽。
- 递归在解决阶乘和斐波那契等数学问题、遍历树和图、生成排列组合等方面有广泛应用。

## 算法和大 O 表示法

- **算法**：解决问题或完成任务的一组明确指令。算法必须在有限步骤内完成，每步必须精确且明确。

- **大 O 表示法**：描述算法在输入规模增加时的最坏情况性能或增长率。关注资源使用随输入规模的增长，忽略常数和低阶项。

### 常见时间复杂度

- **O(1) - 常数时间**：算法所需时间与输入规模无关。

- **O(log n) - 对数时间**：时间随输入增长缓慢。常见于通过分割问题规模的算法（如二分查找）。

- **O(n) - 线性时间**：运行时间与输入规模成正比。

- **O(n log n) - 线性对数时间**：高效排序算法如归并排序和快速排序的常见时间复杂度。

- **O(n²) - 平方时间**：运行时间呈平方增长。常见于嵌套循环。

### 空间复杂度

- **O(1) - 常数空间**：算法使用的内存与输入规模无关。
- **O(n) - 线性空间**：内存使用随输入规模成正比增长。
- **O(n²) - 平方空间**：内存使用随输入规模呈平方增长。

## 解决问题的技巧

- **理解问题**：多次阅读问题描述。确定输入、预期输出以及如何将输入转换为输出。

- **伪代码**：算法逻辑的高级描述，与语言无关。使用常见书面语言混合编程结构，如 `IF`、`ELSE`、`FOR`、`WHILE`。

- **边界情况**：算法应处理的边界上的特定有效输入。始终考虑并测试边界情况。

## 数组

- **静态数组**：初始化时大小固定。元素存储在相邻内存位置。程序执行期间大小不可变。

- **动态数组**：程序执行期间可自动增长或缩小。通过自动复制到更大数组来处理调整大小。

### JavaScript 中的动态数组实现

JavaScript 数组是动态数组。你可以通过索引访问和更新元素，使用 `push()` 添加元素，使用 `pop()` 或 `splice()` 删除元素。

### 动态数组的时间复杂度

- **访问**：O(1)
- **末尾插入**：平均 O(1)，调整大小时 O(n)
- **中间插入**：O(n)
- **删除**：中间 O(n)，末尾 O(1)

## 栈

- **栈**：后进先出（LIFO）数据结构。元素仅从顶部添加和移除。

- **入栈操作**：向栈顶添加元素。时间复杂度：O(1)。

- **出栈操作**：从栈顶移除元素。时间复杂度：O(1)。

JavaScript 数组可以用作栈，使用 `push()` 添加元素，使用 `pop()` 删除元素。

## 队列

- **队列**：先进先出（FIFO）数据结构。元素从尾部添加，从头部移除。

- **入队操作**：向队尾添加元素。时间复杂度：O(1)。

- **出队操作**：从队头移除元素。时间复杂度：O(1)。

数组可以用作队列，使用 `push()` 入队，使用 `shift()` 出队。但 `shift()` 的时间复杂度是 O(n)，因为剩余元素需要移动。

## 链表

- **链表**：线性数据结构，每个节点包含数据和指向下一个节点的引用。节点像链条一样连接。

### 单链表

- **结构**：每个节点都有数据和一个指向下一个节点的引用。
- **遍历**：只能从头部向尾部转发。
- **头节点**：列表中的第一个节点，通常是唯一可直接访问的节点。
- **尾节点**：列表中的最后一个节点，指向 `null`。

### 操作和时间复杂度

- **开头插入**：O(1)
- **末尾插入**：O(n) - 需遍历到末尾
- **中间插入**：O(n) - 需遍历到指定位置
- **开头删除**：O(1)
- **末尾删除**：O(n) - 需遍历找到前一个节点
- **中间删除**：O(n) - 需遍历找到节点

### 双链表

- **结构**：每个节点有数据和两个引用：指向下一个节点和前一个节点。
- **遍历**：可双向移动。
- **内存**：由于额外引用，内存使用比单链表多。

## 何时使用各数据结构

- **数组（动态数组）**：当你需要有序、索引访问且事先不知道大小时
- **栈**：用于后进先出操作（撤销功能性、表达式求值、回溯）
- **队列**：用于 FIFO 操作（任务调度、广度优先查找）
- **链表**：当频繁在开头插入/删除、大小未知且不需要随机访问时

## 查找算法

查找算法让你在某个项列表中查找目标。

在计算机科学中，有两种你应该了解的查找算法。它们是**线性查找**和**binary search**算法。理解这两种算法的区别以及何时使用每一种非常重要。

### 线性查找

- 线性查找迭代一个数组中的项，从头开始查看每一项，直到找到目标项。
- 如果找到目标项，则返回该项在数组中的索引。
- 如果未找到 target，则返回 `-1`，这在 JavaScript 中表示**无效索引**。
- 因为线性查找会检查每一项直到找到目标，所以对于大量项的数组来说，它并不高效。
- 线性查找的时间复杂度是 `O(n)`，因为查找数组所需的时间随着数组大小线性增长。
- 线性查找的空间复杂度是 `O(1)`，因为它不需要任何额外空间来查找数组。

### 二分查找

- 二分查找通过将一个数组的项分成两半，并查看目标值是否在数组的中间来工作。
- 二分查找生效的条件是数组中的项必须按升序或降序排序。
- 二分查找是一种更高效的算法，用于在大型数组中查找项，因为它将数组分成两半，并忽略未找到目标的那一半。
- 如果在数组中间找到目标项，则返回目标项的索引。
- 如果未找到该项，算法会查看目标项是在数组的左半部分还是右半部分。
- 它继续将数组的剩余部分分成两半，直到找到目标项。
- 如果在数组中未找到目标项，则返回 `-1`，
- 二分查找的时间复杂度是 `O(log n)`，因为查找数组所需的时间随着数组大小呈对数增长。
- 二分查找的空间复杂度是 `O(1)`，因为它在查找数组时不需要任何额外空间。

### 线性查找与二分查找的区别

- 与线性查找相比，二分查找更适合用于大型数组的项。
- 线性查找的时间复杂度是 `O(n)`，因为查找整个数组所需的时间随着数组大小线性增长。
- 二分查找的时间复杂度是 `O(log n)`，因为查找数组所需的时间随着数组大小呈对数增长。

## 排序算法与分治法

在计算机科学中，分治是一种将问题拆分为更小子问题以便更容易解决的技术。递归是分治中常用的技术，分治是一种强大的策略，用于实现许多高效的排序算法，如归并排序。

### 归并排序

- 归并排序是一种遵循分治法的排序算法。
- 它通过递归地将一个数组划分为更小的子数组，直到每个子数组只包含一个元素。
- 然后它反复将子数组按排序顺序合并回去。
- 归并排序的时间复杂度是 `O(n log n)`，因为数组不断被对半分割 `(log n)`，然后再合并 `(O(n))`。
- 归并排序的空间复杂度是 `O(n)`，因为它不是原地排序算法。

## 图概述

图是一组由边（连接）连接的节点（顶点）。每个节点可以连接多个其他节点，形成网络。图的不同类型包括：

- **有向图**：边有方向（从一个节点指向另一个节点），通常用直线和箭头表示。
- **无向图**：边没有方向，用简单的线表示。
- **顶点带标签**：每个节点关联一个标签或标识符。
- **有环图**：包含环（路径的起点和终点是同一个节点）。
- **有向无环图（DAG）**：没有环的有向图。
- **边带标签**：每条边都有一个标签，通常绘制在对应边旁边。
- **带权图**：边带有权值（数值），可以用于算术操作。
- **非连通图**：包含两个或多个节点组（组件），这些组之间没有边连接。两个节点即使没有直接边，也可能存在路径相连。

图被广泛应用于地图、网络、推荐系统和依赖解析等领域。

## 图遍历

涉及访问图中所有节点。两种主要算法：

- **广度优先搜索（BFS）**：先访问所有邻近节点，再进入图的下一层。
  - **队列**：使用队列（先进先出）。起始节点标记为已访问并加入队列。队列非空时，出队当前节点，将其所有未访问邻居标记为已访问并加入队列。
  - **最短路径**：用于无权图中查找最短路径。
  - **内存**：需要在内存中保存队列，空间需求可能较大，尤其是同一层节点数量多时。
  - **连通组件**：也可用于查找连通图组件，从每个未访问节点开始新搜索。
  - **状态空间搜索**：使用队列跟踪构建括号组合的不同状态。每个状态用数组表示，包含当前构建的字符串、已使用的左括号数和右括号数。只有当已用左括号数小于总对数时，才能添加左括号。添加右括号时必须保持平衡，即已用左括号数多于右括号数。

- **深度优先搜索（DFS）**：沿每个分支尽可能深入后再回溯。
  - **栈**：使用栈（后进先出）或递归。起始节点标记为已访问并加入栈。栈非空时，弹出当前节点，将其所有未访问邻居标记为已访问并加入栈。
  - **内存**：需要在内存中保存栈（或递归调用栈），路径很长时空间需求会增加。
  - **应用场景**：适用于检测环、路径查找和查找连通组件。
  - **限制**：在无权图中不保证找到两节点间的最短路径。

## 图的表示

图主要有两种表示方式：

- **邻接列表**：每个节点有一个邻居列表。
  - **实现方式**：用数组实现时，每个索引代表一个节点，存储该节点邻居的数组作为值。用对象（或 `Map`）实现时，每个键代表一个节点，关联的值（数组）包含其邻居。
  - **空间**：对稀疏图空间高效，空间复杂度为 `O(V + E)`，其中 `V` 是顶点数，`E` 是边数。
  - **邻居访问**：遍历邻居简单，只需访问节点关联的列表。
  - **边查找**：判断两节点间是否有边不如邻接矩阵高效，通常需要 `O(deg(v))` 时间，其中 `deg(v)` 是被查节点的邻居数，最坏情况为 `O(V)`。
  - **适用场景**：通常是实际应用中更常用的选择，因为稀疏图更普遍。

- **邻接矩阵**：二维数组，行和列代表节点。
  - **数值**：无权图中，值为 `1` 表示节点间有边，`0` 表示无边。带权图中，值表示连接节点的边的权值。
  - **自环**：对角线上的值表示节点是否有自环，即连接自身的边。
  - **空间**：对大图空间消耗大，空间复杂度为 `O(V²)`，其中 `V` 是节点数。
  - **边查找**：判断两节点间是否有边速度快，常数时间 `O(1)`。
  - **邻居访问**：查找节点邻居效率低，因为需遍历整行或整列，最坏情况为 `O(V)`。
  - **适用场景**：适合边多的稠密图，对稀疏图效率低。

## 最短路径算法

- **最短路径算法**：计算带权图中节点间的最短路径，返回距离和路径。
  - **邻接矩阵**：每个值表示两节点间边的权值（距离）。
  - **缺失边**：值为 `INF`（`Infinity`）表示无直接边。
  - **距离**：数组记录从起始节点到每个节点的已知最短距离。初始时，所有节点距离设为无穷大，起始节点到自身距离为 `0`。
  - **路径**：列表中每项是一个节点索引数组，表示到达该节点的路径。
  - **已访问**：数组跟踪已处理的节点，避免重复访问。
  - **最近未访问节点**：主循环对图中每个节点运行一次，每次选择最近的未访问节点。
  - **边松弛**：对每个未访问且有边相连的邻居，检查通过当前节点是否能更高效到达。若新距离更优，更新距离和路径。
  - **不可达节点**：当找不到有效节点时，剩余节点均不可达，循环提前结束。
  - **可选目标**：`targetNode` 参数为可选，不提供时函数计算从 `startNode` 到所有其他节点的最短路径。

## 树

树是无环且连通的特殊图。关键属性包括：

- **无环**：树没有环或循环（起点和终点相同的路径）。
- **连通**：每个节点都能从其他任意节点到达。

### 树的术语

- **根节点**：树的最顶端节点，是唯一没有父节点的节点。
- **父节点**：直接连接到其下方其他节点的节点。
- **子节点**：直接连接到其上方节点的节点。
- **叶子节点**：没有子节点的节点。
- **深度**：从根节点到该节点路径的长度。
- **高度**：从该节点到叶子节点路径的长度。树的高度是其根节点的高度。
- **度数**：每个节点拥有的子节点数量。
- **子树**：树的一个部分，本身也是一棵树。
- **平衡树**：任意节点的左右子树高度相近，确保操作高效。

### 常见树类型

最常见的树类型：

- **二叉树**：每个节点最多有两个子节点，分别是左子节点和右子节点。

- **二叉搜索树（BST）**：一种二叉树，满足每个节点左子树的所有值都小于该节点值，右子树的所有值都大于该节点值。左右子树也必须是二叉搜索树。

- **自平衡树**：包含额外内部逻辑，当插入或删除导致不平衡时重新平衡树。常见例子有 AVL 树、红黑树和 B 树。

- **AVL 树**：一种自平衡二叉搜索树，任意节点的左右子树高度差最多为 1。

- **红黑树**：一种自平衡二叉搜索树，每个节点带有红色或黑色标记。

- **B 树**：一种自平衡树，每个节点可以有多个密钥和超过两个子节点。

## 字典树（Trie）

- **Trie 树**：也称前缀树，用于存储字符串集合，每个节点代表一个字符。
- **根节点**：根节点不代表任何特定字符，可以看作代表空字符串。
- **前缀**：从根节点向下遍历，路径定义了特定的前缀。
- **单词结束标记**：代表完整单词的节点被赋予单词结束标记。
- **共享前缀**：多个字符串共享相同前缀时，路径重叠，前缀只存储一次，使 Trie 在自动补全和拼写检查等任务中高效。
- **插入**：只需为 Trie 中不存在的字符创建新节点。
- **时间复杂度**：查找和插入操作时间为 `O(L)`，其中 `L` 是字符串长度。
- **内存**：如果字符串集合中有许多唯一字符，Trie 可能效率低，因为需要为每个唯一字符存储单独节点。

## 优先队列

- **优先队列**：一种抽象数据类型，每个元素有优先级。
- **队列和栈**：队列和栈只考虑插入顺序，优先队列考虑元素优先级。标准队列遵循先进先出（FIFO），栈遵循后进先出（LIFO）。
- **移除顺序**：通常优先级最高的元素先被移除，但有些实现也可能先移除优先级最低的元素。
- **平局处理**：如果需要相同优先级的元素按插入顺序移除，可以加入唯一计数器打破平局。
- **应用**：用于查找两地间最短路径、操作系统任务调度、交通模拟、数据压缩和网络管理。

## 堆

堆是一种特殊的基于树的数据结构，具有称为堆性质的特定属性。

堆属性决定父节点和子节点的关系。有两种堆：

- **最大堆**：每个父节点的值大于或等于其子节点的值，最大元素位于根节点。

- **最小堆**：每个父节点的值小于或等于其子节点的值，最小元素位于根节点。

JavaScript 没有内置的堆模块，但你可以使用数组实现一个最小堆。

- **数组存储**：堆通常用数组实现，以高效访问父节点和子节点。如果堆保持完全二叉树结构，数组实现只需基于索引进行简单数学运算即可定位元素。
- **索引**：索引为 `i` 的节点，其父节点索引为 `Math.floor((i - 1) / 2)`，左子节点索引为 `2 * i + 1`，右子节点索引为 `2 * i + 2`。
- **查看顶端**：获取最小或最大值（取决于堆类型），但不移除。
- **插入**：将元素添加到合适位置以保持堆性质。新元素添加到数组末尾，然后向上移动，与父节点交换位置，直到堆性质恢复（上浮）。
- **移除顶端**：移除优先级最高的元素（这里是最小值）。数组最后一个元素替换根节点，然后向下移动，与较小子节点交换位置，直到堆性质恢复（下沉）。
- **插入并移除**：将插入和移除操作合并为一次调用。比单独顺序调用更高效，尤其是堆较大时，因为只需一次重新排序操作。
- **堆化**：将现有数组转换为堆。
- **比较回调**：JavaScript 中数组不会自动逐元素比较排序，需要传入比较函数，优先比较优先级，如 `new MinHeap((a, b) => a[0] - b[0])`，其中元素存储为 `[priority, element]`。较小值表示较高优先级。
- **稳定的平局处理**：在每项中加入递增的插入计数器作为第二元素，如 `[priority, counter, element]`。优先比较优先级，优先级相同时比较计数器：`new MinHeap((a, b) => (a[0] - b[0]) || (a[1] - b[1]))`。
- **时间复杂度**：插入和提取最小或最大值为 `O(log n)`，查看顶端为 `O(1)`，堆化为 `O(n)`，查找或删除任意元素为 `O(n)`。
- **空间复杂度**：`O(n)`，其中 `n` 是堆中元素数量。

## 动态规划简介

- **定义**：动态规划是一种算法技术，通过将复杂问题拆分为更简单的子问题并存储结果，避免重复计算。
- **重叠子问题**：解决大问题时，多个子问题重复出现。通过存储解决方案避免重复计算。
- **最优子结构**：问题的最优解包含其子问题的最优解。意味着可以通过组合子问题的最优解构建整体最优解。

## 动态规划方案

- **备忘录法（自顶向下）**：存储昂贵函数调用的结果，当相同输入再次出现时返回缓存结果。

- **表格法（自底向上）**：从底层开始构建解决方案，填充子问题的解表。

## 使用动态规划的实际应用

- **路径优化**：GPS 系统使用动态规划算法来查找位置之间的最短路径。
- **文本处理**：拼写检查和自动完成功能通常依赖动态规划来计算单词之间的编辑距离。
- **金融建模**：投资策略和投资组合优化经常采用动态规划技术。
- **资源分配**：背包问题及其变体出现在调度、预算和资源管理中。

## 何时使用动态规划

你应该在以下情况下考虑使用动态规划：

- 问题可以分解为重叠的子问题。
- 问题具有最优子结构。
- 朴素的递归解法会涉及重复计算。
- 你需要以空间复杂度为代价来优化时间复杂度。

## 纯函数与非纯函数

- 纯函数是指对于相同输入总是产生相同输出且没有副作用的函数。其输出仅依赖输入，不修改任何外部状态。
- 非纯函数具有副作用，即对程序状态的可观察外部变化。

## 函数式编程

- 函数式编程是一种软件开发方法，强调使用函数来解决问题，关注需要做什么而不是如何做。
- 函数式编程鼓励使用有助于避免副作用的技术，例如使用不可变的数据结构和高阶函数。
- 当正确使用时，函数式编程原则会导致更简洁且更易维护的代码

## 柯里化

- 柯里化是一种函数式编程技术，将多参数函数转换为一系列单参数函数。

例如，柯里化将调用 `average(a, b, c)` 转换为连续调用 `curriedAverage(a)(b)(c)`。

- 柯里化在处理多参数函数时特别强大。
- 柯里化使代码更灵活、更易复用。
- 你可以用箭头函数更简洁地创建柯里化函数：

```js
const curriedAverage = a => b => c => (a + b + c) / 3;
```

- 虽然柯里化提高了代码灵活性和复用性，但过度使用可能导致代码难以阅读。

## Fetch API

- Fetch API 允许网页应用发起网络请求，通常用于从服务器获取或发送数据。它提供了 `fetch()` 方法用于发起请求。
- 你可以使用 Fetch API 获取文本、图像、音频、JSON 及其他类型的数据。

## Fetch API 的 HTTP 方法

Fetch API 支持多种 HTTP 方法与服务器交互。最常用的方法有：

- **GET**：用于从服务器获取数据。默认情况下，Fetch API 使用 `GET` 方法获取数据。

要使用获取的数据，必须用 `.json()` 方法将其转换为 JSON 格式：

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
```

在这段代码中，`fetch()` 返回一个 Promise，`.then()` 处理器将解析后的响应转换为 JSON 形式。

- **POST**：用于向服务器发送数据。`POST` 方法用于在服务器上创建新资源。

```js
fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Doe',
    email: 'john@example.com'
  })
})
```

在此示例中，我们发送 `POST` 请求以创建新用户。指定方法为 `POST`，设置适当的头部，并包含要发送的数据体。数据体需为字符串，因此使用 `JSON.stringify()` 将对象转换为 JSON 字符串。

- **PUT**：用于更新服务器上的数据。`PUT` 方法用于更新现有资源。

对于更新，指定 `method: 'PUT'` 并在请求体中包含更新的数据。URL 标识要更新的资源。

- **DELETE**：用于删除服务器上的数据。`DELETE` 方法用于删除资源。

设置 `method: 'DELETE'` 并使用标识要删除资源的 URL。

## Promise 与 Promise 链

- **Promises** 是表现异步操作最终完成或失败及其结果值的对象。Promise 的值只有在异步操作完成后才知道。
- 下面是创建一个简单 Promise 的示例：

```js
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```

- `.then()` 方法用于指定 Promise 成功时的处理操作，`.catch()` 用于处理发生的错误。

- **Promise 链**：Promise 的强大功能之一是可以将多个异步操作串联起来。每个 `.then()` 可以返回一个新的 Promise，使你能够依次执行一系列异步操作。

`catch` 方法会处理过程中发生的任何错误。这样你无需为每一步单独添加错误处理，大大简化代码。

## 使用 `async/await` 处理 Promise

`async`/`await` 使编写和读取异步的代码更容易，它是建立在 Promise 之上的。

- **async**：`async` 关键字用于定义一个异步函数。一个 `async` 函数会返回一个 Promise，该 Promise 会以 `async` 函数返回的值作为解析结果。
- **await**：`await` 关键字用于 `async` 函数内部，用来暂停函数的执行，直到 Promise 被解析。它只能在 `async` 函数内部使用。

- `async/await` 最大优势之一是通过 `try/catch` 块进行错误处理。示例如下：

```js
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

fetchData();
```

示例中，`try` 块包含可能抛出错误的代码，`catch` 块处理错误，使错误处理更直观易读。

## `async` 属性

- `async` 属性告诉浏览器在继续解析 HTML 文档的同时异步地下载脚本文件。
- 脚本下载完成后，HTML 解析暂停，脚本执行，然后 HTML 解析恢复。
- 你应该为执行顺序无关紧要的独立脚本使用 `async`。

## `defer` 属性

- `defer` 属性也会异步地下载脚本，但它会推迟脚本的执行，直到 HTML 文档完全解析之后。
- `defer` 脚本维护它们在 HTML 文档中出现的执行顺序。

- 需要注意的是，`async` 和 `defer` 属性对内联脚本无效，仅对外部脚本文件生效。

- 当同时存在 `async` 和 `defer` 属性时，`async` 属性优先。

## 地理位置 API

- 地理位置 API 提供网站请求用户位置的方式。

- 下面的示例演示了 API 的 `getCurrentPosition()` 方法，用于获取用户的当前位置。

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

在这段代码中，我们调用了 `getCurrentPosition` 并传入一个函数，该函数将在成功获取位置时被调用。

`position` 对象包含多种信息，这里只选择了 `latitude` 和 `longitude`。

如果获取 `position` 出现问题，则该误差将被记录到控制台日志中。

- 尊重用户的隐私非常重要，只有在必要时才请求他们的位置。
