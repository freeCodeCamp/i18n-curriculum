# --description--

Você atualizou a contagem local de ovos e a retornou de `make_fried_egg`. Agora, atribua o valor retornado à variável global para atualizar seu inventário.

Lembre-se de que os parâmetros da função são variáveis locais. Quando você passa a variável global `available_eggs` para `make_fried_egg`, seu parâmetro local inicialmente se refere ao mesmo inteiro. A atribuição `available_eggs = use_eggs(available_eggs, 1)` reatribui apenas esse parâmetro local para a contagem retornada. Ela não reatribui a variável global, que ainda se refere a `1`.

Para atualizar seu estoque real na cozinha, sobrescreva a variável global `available_eggs` com o novo número de ovos retornado pela sua função `make_fried_egg`.

No final do seu código, faça a chamada da função `make_fried_egg`, passando `available_eggs` como argumento, e atribua o resultado de volta à variável global `available_eggs`.

available_eggs = 1

def check_kitchen_stock():

    print(f'- {available_eggs} eggs')

check_kitchen_stock()

def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        print('The kitchen does not have enough eggs.')
        return available_eggs

    print(f'{eggs_to_use} egg(s) used out of {available_eggs} available.')
    return available_eggs - eggs_to_use

use_eggs(available_eggs, 1)
print(available_eggs)

def make_fried_egg(available_eggs):
    has_enough_eggs = available_eggs >= 1

    if has_enough_eggs:
        available_eggs = use_eggs(available_eggs, 1)
        print('Made a fried egg. Yummy!')
    else:
        print('Could not make a fried egg. Not enough eggs!')

    return available_eggs
