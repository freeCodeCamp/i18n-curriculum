# --description--

在終端機中，你會看到像 `-3.6999999999999993` 這樣的數值，而不是 `-3.7`。這是因為浮點數無法精確表述每個小數，所以在算術操作後可能會出現小誤差。

`round()` 函式會將數字四捨五入到你作為第二個引數傳入的小數位數：

```py
print(round(3.14159, 2)) # 3.14
```

將 `temperature - average` 包在 `round()` 呼叫中，將每個差異四捨五入到一位小數。
