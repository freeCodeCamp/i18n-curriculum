## Алгоритми та нотація Big O

- **Алгоритми**: Набір однозначних інструкцій для розв’язання задачі або виконання завдання. Алгоритми мають завершуватися за скінченну кількість кроків, і кожен крок має бути точним і однозначним.

- **Нотація Big O**: Описує асимптотичну верхню межу використання ресурсів алгоритму при збільшенні розміру вхідних даних. Big O вимірює загальну тенденцію масштабування окремо від того, чи розглядається найкращий, середній чи найгірший випадок, і ігнорує константні множники та менші доданки.

### Загальні часові складності

- **O(1) — константний час**: Алгоритм виконується за однаковий час незалежно від розміру вхідних даних.

```python
def check_even_or_odd(number):
    if number % 2 == 0:
        return 'Even'
    else:
        return 'Odd'
```

- **O(log n) - Логарифмічний час**: Верхня межа часу виконання, що зростає не більше ніж логарифмічно від розміру вхідних даних. Коли межа точна, алгоритм працює за логарифмічний час. Це часто трапляється, коли розмір задачі послідовно зменшується на сталу частку, як у бінарному пошуку.

- **O(n) - Лінійний час**: Верхня межа часу виконання, що зростає не більше ніж лінійно від розміру вхідних даних. Коли межа точна, час виконання пропорційний розміру вхідних даних.

```python
for grade in grades:
    print(grade)
```

- **O(n log n) - Лог-лінійний час**: Зустрічається у ефективних алгоритмах сортування методом розділяй і володарюй. Merge Sort має найгіршу складність O(n log n). Quick Sort має середню складність O(n log n), але найгірша складність — O(n²).

- **O(n²) - Квадратичний час**: Верхня межа часу виконання, що зростає не більше ніж квадратично від розміру вхідних даних. Коли межа точна, час виконання пропорційний квадрату розміру вхідних даних. Це трапляється у вкладених циклах, де кожен цикл виконує n ітерацій.

```python
for i in range(n):
    for j in range(n):
        print("Hello, World!")
```

- **O(2ⁿ) - Експоненційний час**: Експоненційна верхня межа часу виконання. Коли межа точна, швидкість зростання пропорційна 2ⁿ, що подвоюється при збільшенні n на одиницю.

- **O(n!) - Факторіальний час**: Факторіальна верхня межа часу виконання. Коли межа точна, швидкість зростання пропорційна n!, кількості перестановок n різних елементів.

### Просторова складність

- **O(1) - Константний простір**: Використання пам’яті обмежене константою, незалежно від розміру вхідних даних.

- **O(n) - Лінійний простір**: Використання пам’яті зростає не більше ніж лінійно від розміру вхідних даних. Коли межа точна, використання пам’яті пропорційне розміру вхідних даних.

- **O(n²) - Квадратичний простір**: Використання пам’яті зростає не більше ніж квадратично від розміру вхідних даних. Коли межа точна, використання пам’яті пропорційне квадрату розміру вхідних даних.

- **O(2ⁿ) - Експоненційний простір**: Експоненційна верхня межа використання пам’яті. Коли межа точна, використання пам’яті пропорційне 2ⁿ.

- **O(n!) - Факторіальний простір**: Факторіальна верхня межа використання пам’яті. Коли межа точна, використання пам’яті пропорційне n!.

## Масиви

- **Статичні масиви**: Мають фіксований розмір, встановлений під час створення, з елементами, що зберігаються в суміжній пам’яті. Такий суміжний макет забезпечує швидкий доступ за індексом за константний час (O(1)). Обирайте статичний масив, коли максимальна кількість елементів строго відома заздалегідь.

- **Динамічні масиви**: Можуть автоматично збільшуватися або зменшуватися під час виконання програми. Коли закінчується місце, вони під капотом змінюють розмір, виділяючи більший блок пам’яті та копіюючи існуючі елементи.

**Примітка:** У Python немає традиційного вбудованого статичного масиву. Списки Python — це динамічні масиви.

### Списки Python (динамічні масиви)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### Часові складності для динамічних масивів

- **Доступ**: O(1)

- **Вставка в кінець**: O(1) у середньому, O(n) при необхідності зміни розміру

- **Вставка посередині**: O(n)

- **Видалення**: O(n) для середини, O(1) для кінця

## Стек

- **Стек**: Структура даних типу LIFO (останній зайшов — перший вийшов). Елементи додаються і видаляються лише з вершини.

- **Операція push**: Додавання елемента на вершину стеку. Для реалізації на Python списку звичайний push займає O(1) часу і O(1) додаткового простору. Push, що вимагає зміни розміру, може займати O(n) часу і O(n) додаткового простору.

- **Операція pop**: Видалення елемента з вершини стеку. Часова складність зазвичай O(1), а додатковий простір зазвичай O(1).

```python
# Using Python list as stack
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operations
top_element = stack.pop()  # Returns 3
```

## Черги

- **Черги**: Структура даних типу FIFO (перший прийшов — перший вийшов), де елементи додаються в кінець і видаляються з початку.

- **Операція enqueue**: Додавання елемента в кінець черги. Часова складність: O(1), простір: O(1).

- **Операція dequeue**: Видалення елемента з початку черги. Часова складність: O(1), простір: O(1).

## Зв’язані списки

- **Зв’язані списки**: Лінійна структура даних, де кожен вузол містить дані і посилання на наступний вузол. Вузли з’єднані як ланцюг.

### Однозв’язні списки

- **Структура**: Кожен вузол містить дані та один референс на наступний вузол.

- **Обхід**: Можна рухатися лише вперед від голови до хвоста.

- **Головний вузол**: Перший вузол у списку, зазвичай єдиний безпосередньо доступний вузол.

- **Хвостовий вузол**: Останній вузол у списку, вказує на `None`.

### Реалізація зв’язаного списку

- **Клас Node**: Вкладений клас `Node` представляє окремі вузли. Кожен вузол містить дані та референс на наступний вузол.

- **Ініціалізація**: Референс `head` починається як `None`, бо список порожній. Референс `next` кожного нового вузла починається як `None`, бо він ще не має наступника.

- **Відстеження довжини**: Змінна довжини зберігає кількість вузлів у списку.

- **`is_empty()`**: Перевіряє, чи список порожній, перевіряючи, чи `head` дорівнює `None`.

- **Додавання в кінець**: Обходьте список від голови до останнього вузла, потім оновіть його референс `next`, щоб вказати на новий вузол. Якщо список порожній, новий вузол стає головою.

```python
class LinkedList:
    class Node:
        def __init__(self, data):
            self.data = data
            self.next = None

    def __init__(self):
        self.head = None
        self.length = 0

    def is_empty(self):
        return self.head is None

    def append(self, data):
        new_node = self.Node(data)

        if self.is_empty():
            self.head = new_node
        else:
            current = self.head

            while current.next:
                current = current.next

            current.next = new_node

        self.length += 1
```

### Операції та часові складності

- **Вставка на початок**: O(1)

- **Вставка в кінець**: O(n) — потрібно пройти до кінця

- **Вставка посередині**: O(n) — потрібно пройти до позиції

- **Видалення з початку**: O(1)

- **Видалення з кінця**: O(n) — потрібно пройти, щоб знайти попередній вузол

- **Видалення посередині**: O(n) — потрібно пройти, щоб знайти вузол

### Вставка та видалення

- **Вставка на початок**: Створіть новий вузол, встановіть його референс `next` на поточну голову, а голову оновіть, щоб вказувати на новий вузол.

- **Вставка в кінець**: Пройдіть до останнього вузла і оновіть його референс `next`, щоб вказати на новий вузол.

- **Вставка посередині**: Пройдіть до вузла перед потрібною позицією. Оновіть референс `next` нового вузла, щоб вказати на наступний вузол, потім оновіть референс `next` попереднього вузла, щоб вказати на новий вузол.

- **Видалення з початку**: Оновіть голову, щоб вказувати на другий вузол.

- **Видалення з кінця**: Пройдіть до передостаннього вузла і оновіть його референс `next` на `None`.

- **Видалення посередині**: Знайдіть вузол перед цільовим вузлом і оновіть його референс `next`, щоб пропустити цільовий вузол.

- **Видалення за значенням**: Відстежуйте попередній вузол під час обходу. Якщо ціль — голова, оновіть голову безпосередньо. Якщо значення не знайдено, поверніться без змін у списку чи довжині. Зменшуйте довжину лише після успішного видалення.

### Складність додаткового простору

- **Вставка на початок**: O(1) додаткового простору, не враховуючи пам’ять для нового вузла.

- **Вставка в кінець**: O(1) додаткового простору, не враховуючи пам’ять для нового вузла.

- **Вставка посередині**: O(1) додаткового простору, не враховуючи пам’ять для нового вузла.

- **Видалення з початку**: O(1) додаткового простору.

- **Видалення з кінця**: O(1) додаткового простору.

- **Видалення посередині**: O(1) додаткового простору.

### Двозв’язні списки

- **Структура**: Кожен вузол має дані та два референси: на наступний і попередній вузли.

- **Обхід**: Можна рухатися в обох напрямках.

- **Пам’ять**: Потребує більше пам’яті, ніж зв’язаний список з одним референсом, через додатковий референс.

- **Референс хвоста**: Підтримка референсу на останній вузол дозволяє рухатися назад, використовуючи попередні референси.

## Хеш-мапи та множини

### Мапи та хеш-мапи

- **Абстрактний тип даних (ADT) проти реалізації**: ADT визначає *інтерфейс* — які операції підтримує структура даних і як вона логічно поводиться. Конкретна реалізація визначає механізм на бекенді, показуючи, *як* ці операції фактично побудовані і виконуються в пам’яті.

- **Map (ADT)**: Абстрактний тип даних, що визначає колекцію унікальних ключів, зіставлених зі значеннями. Визначає правила, що може робити map, без вказівки внутрішнього зберігання.

- **Hash Map**: Конкретна реалізація Map ADT, що використовує хеш-функцію для обчислення місць зберігання в підлеглому масиві для швидких пошуків.

### Словники Python (хеш-мапи)

```python
# Creating dictionaries
my_dictionary = {
    "A": 1,
    "B": 2,
    "C": 3
}

# Alternative creation
my_dictionary = dict(A=1, B=2, C=3)

# Access and modify
value = my_dictionary["A"]  # 1
my_dictionary["A"] = 4      # Update value
del my_dictionary["A"]      # Remove key-value pair

# Check membership
"C" in my_dictionary

# Get keys, values, items
my_dictionary.keys()
my_dictionary.values()
my_dictionary.items()
```

### Часові складності для хеш-мап

- **Середній випадок**: O(1) для вставки, отримання, видалення

- **Найгірший випадок**: O(n) при великій кількості колізій хешів

### Складність додаткового простору для хеш-мап

- **Вставка**: O(1) додаткового простору для звичайної вставки. Зміна розміру може вимагати O(n) додаткового простору.

- **Пошук**: O(1) додаткового простору.

- **Видалення**: O(1) додаткового простору.

### Множини

- **Множини**: Неупорядковані колекції унікальних елементів. Дублікати не допускаються, порядок не зберігається.

- **Елементи множини**: Множини можуть містити числа, рядки та кортежі, що містять лише числа і рядки. Списки, словники та інші множини не можуть бути елементами множини. Кортеж, що містить список, не може бути елементом множини, хоча сам кортеж є незмінним.

```python
# Creating sets
numbers = {1, 2, 3, 4}
empty_set = set()  # Must use set(), not {}

# Add and remove elements
numbers.add(5)
numbers.remove(4)      # Raises KeyError if not found
numbers.discard(4)     # No error if not found

# Remove and return an arbitrary element
numbers.pop()

# Remove all elements
numbers.clear()

# Get the number of elements
len(numbers)
```

### Операції над множинами

```python
set_a = {1, 2, 3, 4}
set_b = {2, 3, 4, 5, 6}

# Union, intersection, difference, symmetric difference
set_a.union(set_b)                  # or set_a | set_b
set_a.intersection(set_b)           # or set_a & set_b
set_a.difference(set_b)             # or set_a - set_b
set_a.symmetric_difference(set_b)   # or set_a ^ set_b

# Subset and superset checks
set_a.issubset(set_b)
set_a.issuperset(set_b)
set_a.isdisjoint(set_b)

# Membership testing
5 in numbers
```

### Часові складності для множин

- **Середній випадок**: O(1) для додавання, видалення, перевірки членства

- **Найгірший випадок**: O(n) через колізії хешів

- **Пошук довжини**: O(1) за допомогою `len()`.

### Складність додаткового простору для множин

- **Вставка**: O(1) додаткового простору для звичайної вставки. Зміна розміру може вимагати O(n) додаткового простору.

- **Пошук**: O(1) додаткового простору.

- **Видалення**: O(1) додаткового простору.

- **Пошук довжини**: O(1) додаткового простору.

## Колізії хешів

- **Колізія хешів**: Різні ключі можуть давати однакове хеш-значення. У хеш-таблиці колізії також трапляються, коли різні хеш-значення відображаються на один індекс масиву. Записи, що ділять індекс, повинні оброблятися стратегією розв’язання колізій.

- **Стратегії розв’язання колізій**:

  - **Зв’язування (Chaining)**: Кожен індекс масиву вказує на зв’язаний список, що зберігає всі записи, які відображаються на цей індекс.

  - **Відкрите адресування (Open Addressing)**: Шукає наступний доступний індекс масиву за заздалегідь визначеною послідовністю, коли трапляється колізія.

## Коли використовувати кожну структуру даних

- **Списки**: Коли потрібен впорядкований, індексований доступ і розмір невідомий заздалегідь.

- **Стек**: Для операцій LIFO (функція скасування, оцінка виразів, повернення назад).

- **Черги**: Для операцій FIFO (планування завдань, пошук у ширину).

- **Зв’язані списки**: Коли потрібні часті вставки/видалення на початку, розмір невідомий, випадковий доступ не потрібен.

- **Хеш-мапи**: Для швидкого пошуку за ключем, підрахунку кількості, кешування.

- **Множини**: Для перевірки унікальності, математичних операцій над множинами, видалення дублікатів.
