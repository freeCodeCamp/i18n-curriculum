# --description--

現在你需要將 `styles.css` 檔案連結起來，這樣樣式才會再次套用。

`link` 元素讓你可以連結到外部資源，例如樣式表和網站圖示。以下是使用 `link` 元素連結外部 CSS 的基本語法：

```html
<link rel="stylesheet" href="styles.css" />
```

`rel` 屬性指定連結資源與 HTML 文件之間的關係。在這裡，你需要指定這個連結資源是 `stylesheet`。`href` 屬性則指定外部資源的位置。

在 `head` 元素內，新增一個 `link` 元素。給它一個 `rel` 屬性，值為 `"stylesheet"`，以及一個 `href` 屬性，值為 `"styles.css"`。

**注意：** `link` 元素是空元素，表示它沒有結束標籤。空元素應寫成 `<element>`，而不是 `<element></element>`。

# --hints--

你的程式碼應該有一個 `link` 元素。

```js
const link = document.querySelector('link');
assert.isNotNull(link);
```

`link` 元素是空元素，不應該有結束標籤 `</link>`。

```js
assert.notMatch(code, /<\/link>/i);
```

你不應該更改你現有的 `head` 元素。請確保你沒有刪除結束標籤。

```js
const headElementCount = document.querySelectorAll('head')?.length;
assert.strictEqual(headElementCount, 1);
```

你應該有一個 `link` 元素。

```js
const linkElementCount = document.querySelectorAll('link')?.length;
assert.strictEqual(linkElementCount, 1);
```

你的 `link` 元素應該位於你的 `head` 元素內。

```js
const link = document.querySelector('head > link');
assert.isNotNull(link);
```

你的 `link` 元素應該有一個 `rel` 屬性，其值為 `stylesheet`。

```js
const linkRelValue = document.querySelector('link')?.getAttribute('rel');
assert.strictEqual(linkRelValue, 'stylesheet');
```

你的 `link` 元素應該有一個 `href` 屬性，其值為 `styles.css`。

```js
const linkHrefValue = document.querySelector('link')?.dataset?.href;
assert.strictEqual(linkHrefValue, 'styles.css');

```
