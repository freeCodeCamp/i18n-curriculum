# --description--

Рекурсивні виклики спускаються деревом по одному рівню за раз, але їм потрібне місце, щоб зупинитися. Є два випадки:

- `node.key` дорівнює `key`: ви знайшли вузол із шуканим значенням.
- `node` дорівнює `None`: пошук пройшов за межі листка, отже значення немає в дереві.

На початку методу `_search`, перед вашою існуючою інструкцією `if`, додайте інструкцію `if`, яка перевіряє, чи `node` дорівнює `None` або чи `node.key` дорівнює `key`, і поверніть `node` з неї. Таким чином метод повертає вузол із значенням або `None`, якщо значення немає в дереві.
