# --description--

Has aprendido a crear diccionarios y a acceder y actualizar sus valores. Ahora usarás métodos de diccionarios, copiarás diccionarios y explorarás cómo las funciones pueden modificarlos.

Cada ejemplo de método de diccionario a continuación comienza con este diccionario:

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## Métodos de diccionario

Los diccionarios también tienen métodos útiles para realizar operaciones comunes.

El método `.get()` recupera el valor asociado a una clave. Es similar a la notación de corchetes que aprendiste en la lección anterior, pero su ventaja es que puedes establecer un valor predeterminado, para que no obtengas un error si la clave no existe:

```python
dictionary.get(key, default)
```

En este ejemplo, si la clave `toppings` no existe, devolverá una lista vacía, que es el valor predeterminado que estamos pasando aquí como segundo argumento. Pero si `toppings` sí existe, devolverá ese valor:

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

Los métodos `.keys()` y `.values()` devuelven un objeto vista con todas las claves y valores en el diccionario, respectivamente:

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

Un objeto view es solo una forma de ver el contenido de un diccionario sin crear una copia separada de los datos.

El método `.items()` devuelve un objeto vista con todos los pares clave-valor en el diccionario, incluyendo tanto las claves como los valores:

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

El método `.clear()` elimina todos los pares clave-valor del diccionario:

```python
pizza.clear()
```

El método `.pop()` elimina el par clave-valor con la clave que especificas como primer argumento y devuelve su valor. Si la clave no existe, devuelve el valor predeterminado que especificas como segundo argumento. Si la clave no existe y no pasas un valor predeterminado, se genera un `KeyError`:

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

En Python 3.7 y versiones más recientes, el método `.popitem()` elimina el último elemento insertado:

```python
pizza.popitem()
```

El método `.update()` actualiza los pares clave-valor con los pares clave-valor de otro diccionario. Si tienen claves en común, sus valores se sobrescriben.

En este ejemplo, estamos actualizando el diccionario `pizza`. La clave `price` existe en ambos, por lo que su valor será reemplazado por `15`.

Pero `total_time` es nuevo, así que se añadirá al diccionario `pizza` como un nuevo par clave-valor:

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

Este es el nuevo diccionario con el `price` actualizado y el nuevo `total_time`. Observa cómo el price ahora es `15` y `total_time` es un nuevo par clave-valor:

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### Asignación y copias superficiales

Como aprendiste con las listas, asignar un diccionario a otra variable crea un alias. Ambos nombres se refieren al mismo objeto:

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

Para crear un diccionario externo separado, usa el método `.copy()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

Reemplazar una entrada en `copied_settings` no reemplaza la entrada correspondiente en `settings`. Sin embargo, `.copy()` crea una **copia superficial**: crea un nuevo diccionario externo cuyas claves y valores se refieren a los mismos objetos que los del diccionario original. Los objetos mutables anidados siguen compartiéndose:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

Los dos diccionarios son objetos diferentes, pero sus entradas `languages` se refieren a la misma lista. Agregar elementos a esa lista es visible a través de ambos diccionarios. Reemplazar `copied_settings['languages']` con una lista nueva cambiaría solo esa entrada en la copia.

También puedes crear una copia superficial pasando un diccionario a `dict()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

Al igual que `.copy()`, `dict(settings)` crea un nuevo diccionario externo, pero la lista anidada sigue compartiéndose. Reemplazar una entrada en cualquiera de los diccionarios afecta solo a ese diccionario, mientras que cambiar la lista compartida es visible en ambos.

## Mutar un diccionario a través de un parámetro de función

Las mismas reglas de paso de argumentos que aprendiste con listas se aplican a los diccionarios. Un parámetro inicialmente se refiere al objeto pasado como argumento. Actualizar una entrada a través de ese parámetro muta el diccionario compartido:

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

La función devuelve una cadena de estado, mientras que `preferences` cambia a través de la referencia compartida. Devolver un valor y mutar un objeto son efectos separados. La función no necesita devolver el diccionario para que los cambios sean visibles fuera de la función. Reasignar el parámetro local a un diccionario diferente no reemplazaría el diccionario referenciado por `preferences`.

## Usar un diccionario como argumento predeterminado

Recuerda que una lista predeterminada se crea cuando se define la función y se reutiliza en llamadas que omiten el argumento. Un diccionario predeterminado se comporta igual:

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

La segunda llamada reutiliza el diccionario modificado por la primera llamada. Esto significa que las configuraciones se acumulan a través de llamadas independientes, aunque cada llamada tenga su propio nombre de parámetro local.

Cuando cada llamada debe comenzar con un diccionario nuevo, usa el patrón predeterminado `None`:

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

Cada llamada que omite `settings` o pasa `None` crea un diccionario nuevo. Pasar un diccionario existente aún permite que la función muta ese objeto. Usa `settings is None` aquí: `if not settings` también coincidiría con un diccionario vacío pasado como argumento y lo reemplazaría con un nuevo diccionario local.
