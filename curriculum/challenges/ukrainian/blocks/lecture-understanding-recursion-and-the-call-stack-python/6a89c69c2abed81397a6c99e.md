# --description--

Рекурсія — це техніка, у якій функція викликає сама себе. Кожен виклик працює з меншою версією початкової проблеми, доки не досягне умови, яка зупиняє рекурсію. Цю умову зупинки називають базовим випадком.

Рекурсивні функції можуть розв’язувати задачі з невідомою глибиною, наприклад, обходити дерево файлів. Вони також можуть виконувати простіші завдання, наприклад, відлік у зворотному напрямку від заданого числа.

Ось функція з назвою `recursive_countdown`, яка приймає число і виводить його:

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

Виклик функції виводить `5`, але відлік ще не починається. Перед тим як функція викличе сама себе, потрібно визначити її базовий випадок. Без досяжного базового випадку функція буде викликати сама себе без кінця. Зрештою Python припиняє виклики і викидає `RecursionError`.

Для цього відліку функція має зупинятися, коли `number` менше за `1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

Інструкція `if` — це базовий випадок. Коли `number` менше за `1`, `return` завершує цей виклик функції.

Функції ще потрібен рекурсивний випадок. Рекурсивний випадок викликає функцію знову з аргументом, який наближає її до базового випадку. Щоб відраховувати вниз, викличте `recursive_countdown` з `number - 1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

Це виводить числа `5`, `4`, `3`, `2` і `1`.

Позиція рекурсивного виклику змінює порядок виведення чисел. Якщо виклик `print()` йде після рекурсивного виклику, функція виводить числа у зростаючому порядку:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

Це виводить числа `1`, `2`, `3`, `4` і `5`. Щоб зрозуміти чому, потрібно розібратися з викликовим стеком.

Викликовий стек — це структура даних типу останній увійшов — перший вийшов, яку Python використовує для відстеження активних викликів функцій. Коли функцію викликають, Python додає кадр для цього виклику на вершину стеку. Кадр містить інформацію, наприклад аргументи функції та локальні змінні.

Розгляньте цю версію відліку:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

Вихідні дані такі:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

Виклик `recursive_countdown(3)` призупиняється, коли викликає `recursive_countdown(2)`. Виклик з `2` призупиняється, коли викликає функцію з `1`, а виклик з `1` призупиняється, коли викликає функцію з `0`.

Виклик з `0` досягає базового випадку і повертається. Python видаляє цей виклик з вершини стеку, тому виклик з `1` відновлюється після свого рекурсивного виклику. Решта викликів потім відновлюються і повертаються у зворотному порядку: `1`, `2` і `3`.

Кожна рекурсивна функція потребує базового випадку і рекурсивного випадку, який наближає до нього. Коли базовий випадок повертається, попередні виклики відновлюються у порядку останній увійшов — перший вийшов.
