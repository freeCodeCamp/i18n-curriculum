# --interactive--

Властивість `text-decoration` дозволяє додавати декоративні лінії до тексту.

Зі своїм ініціальним значенням `none` вона зазвичай використовується для видалення стандартного підкреслення, яке браузери додають до посилань, коли потрібно кастомізувати такі посилання.

```css
a {
  text-decoration: none;
}
```

Хоча її часто використовують для посилань, `text-decoration` також може прикрашати інший текст.

## Інші значення властивості `text-decoration`

Окрім `none`, іншими значеннями властивості `text-decoration` є:

- `underline`
- `overline`
- `line-through`

Як випливає з назв значень, `underline` додає лінію під текстом, `overline` додає лінію над текстом, а `line-through` додає лінію посередині тексту, ніби його зафарбовують.

## Властивість `text-decoration` має більше можливостей

Властивість `text-decoration` насправді є скороченою властивістю, яка об’єднує такі властивості:

- `text-decoration-line`: `none`, `underline`, `overline` та `line-through`
- `text-decoration-color`: колір лінії.
- `text-decoration-style`: `solid`, `double`, `dotted`, `dashed` або `wavy`.
- `text-decoration-thickness`: товщина лінії.

Наприклад, це додає червону хвилясту лінію до абзацу:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

А це додає подвійний зелений overline до абзацу:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

Ви також можете комбінувати типи ліній, якщо хочете:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
