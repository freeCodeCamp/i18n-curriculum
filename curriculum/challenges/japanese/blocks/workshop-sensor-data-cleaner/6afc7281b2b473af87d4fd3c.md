# --description--

各温度をそのラベルとペアにする必要があります。

`map()` 関数は複数のイテラブルを受け取ることができます。呼び出されるたびに、各イテラブルから1つずつアイテムを関数に渡すので、関数はイテラブルごとに1つのパラメータが必要です：

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

`report` という変数を作成してください。`map()` にラムダ関数、`temperatures`、`difference_labels` を渡し、その結果を `list()` で囲んだものを代入します。ラムダ関数は2つのパラメータ、`temperature` と `difference_label` を受け取り、`f'{temperature} °C ({difference_label})'` を返すようにしてください。

その後、`difference_labels` の代わりに `report` を出力してください。
