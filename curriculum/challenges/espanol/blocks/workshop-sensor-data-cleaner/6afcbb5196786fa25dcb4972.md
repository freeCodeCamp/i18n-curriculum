# --description--

En la terminal, deberías ver algo como `<filter object at 0x...>` en lugar de las lecturas. Esto sucede porque `filter()` devuelve un iterador, que te da los elementos uno a la vez en lugar de almacenarlos todos en una lista.

Para recopilar los elementos de un iterador en una lista, puedes pasarlo a la función `list()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

Envuelve la llamada a `filter()` asignada a `valid_readings` en una llamada a `list()`. En la terminal, deberías ver las lecturas sin los códigos de error `-999`.
