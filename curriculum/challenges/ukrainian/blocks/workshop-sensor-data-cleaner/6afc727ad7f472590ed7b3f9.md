# --description--

Перед тим як працювати з показниками, потрібно видалити коди помилок.

Як ви дізналися в попередніх уроках, функція `filter()` зберігає лише ті елементи ітерованого об’єкта, для яких функція повертає правдиве значення. Замість того, щоб визначати цю функцію за допомогою `def`, ви можете передати лямбда-функцію безпосередньо у `filter()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

Створіть змінну з назвою `valid_readings`. Призначте їй результат виклику `filter()` з лямбда-функцією та `readings`. Лямбда-функція має приймати параметр з назвою `reading` і перевіряти, чи `reading` не дорівнює `-999`.

Потім виведіть `valid_readings` замість `readings`.
