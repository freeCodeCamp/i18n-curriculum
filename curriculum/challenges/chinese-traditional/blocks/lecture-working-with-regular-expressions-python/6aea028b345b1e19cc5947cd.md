# --description--

正規表達式（regex）是一種用來匹配文字中一連串字元的樣式。

你已經使用過 `in` 運算子來檢查字串是否包含精確的子字串。但有些情況下，你不知道要找的確切文字，只知道它的形狀。舉例來說，你可能想檢查字串是否以一些字母開頭，接著是一些數字，或者使用者名稱是否只包含允許的字元。

正規表達式讓你描述這類樣式，並檢查字串是否符合它們。它們常用於驗證輸入、搜尋文字，以及從字串中擷取資訊。

在 Python 中，要使用正規表達式，你需要匯入 `re` 模組，它是標準程式庫的一部分：

```python
import re
```

最簡單的正規表達式樣式是字面樣式：一連串必須完全照寫出現的字元。舉例來說，樣式 `'cat'` 會匹配字母 `c`、`a` 和 `t`，依序出現。

要在字串中尋找樣式，你可以使用 `re` 模組的 `search` 函式。它的第一個引數是樣式，第二個引數是要搜尋的字串：

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

當 `re.search` 在字串中任何地方找到樣式時，它會傳回一個匹配物件。列印這個匹配物件會告訴你兩件事：

- `match='cat'` 是符合樣式的文字。

- `span=(4, 7)` 是匹配在字串中的位置。匹配從索引 `4` 開始，到索引 `7` 之前結束。

你也可以用匹配物件的 `group` 和 `span` 方法取得這些資訊：

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

當找不到樣式時，`re.search` 會傳回 `None`：

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

預設情況下，正規表達式匹配是區分大小寫的。這表示樣式 `'Cat'` 不會匹配文字 `cat`：

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

要改變樣式的匹配方式，你可以將旗標作為第三個引數傳給 `re.search`。`re.IGNORECASE` 旗標會讓搜尋不區分大小寫，因此大寫和小寫字母視為相同：

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
