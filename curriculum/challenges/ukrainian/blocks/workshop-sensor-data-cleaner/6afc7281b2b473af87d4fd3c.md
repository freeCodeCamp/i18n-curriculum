# --description--

Тепер потрібно поєднати кожну температуру з її міткою.

Функція `map()` може приймати більше ніж один ітерований об’єкт. При кожному виклику вона передає по одному елементу з кожного ітерованого об’єкта у функцію, тому функція потребує по одному параметру на кожен ітерований об’єкт:

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

Створіть змінну з назвою `report`. Призначте їй результат виклику `map()` з лямбда-функцією, `temperatures` та `difference_labels`, обгорнутих у виклик `list()`. Лямбда-функція має приймати два параметри — `temperature` і `difference_label` — і повертати `f'{temperature} °C ({difference_label})'`.

Потім виведіть `report` замість `difference_labels`.
