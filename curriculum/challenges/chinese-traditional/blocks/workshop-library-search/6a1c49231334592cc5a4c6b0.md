# --description--

太好了！不過，如果你的 `findBook` 函式丟出錯誤，事件監聽器中剩下的程式碼就不會執行，因為沒有任何東西可以捕捉它。

為了優雅地處理這些錯誤，你需要將可能失敗的程式碼包在 `try` 區塊中。

```js
try {
  // Code that might throw an error
}
```

看看檔案底部的 `searchBtn` 事件監聽器。將該回呼函式中現有的程式碼包在 `try` 區塊裡。

**注意：** 忽略大括號下方的紅色錯誤線。你會在下一步修正它。

const library = [

    throw new Error("Search field cannot be empty");
  }

  if (!library.includes(title)) {
    throw new Error(title + " not found!");
  }

  return title + " is available to borrow!";
};
