# --description--

生産性を上げるために使えるコマンドラインのショートカットについて学びましょう。

ターミナルやコマンドラインのショートカットは、作業の効率化や生産性の最大化に役立ちます。LinuxとmacOSはどちらもUnixにルーツがあるため、多くのショートカットは共通しています。しかしWindowsではいくつか違いがあります。

## <kbd>上矢印</kbd> と <kbd>下矢印</kbd> のショートカット

最初のショートカットは<kbd>Up Arrow</kbd>キーです。このキーを押すと、コマンド履歴を1つずつ遡ってサイクルできます。次に<kbd>Down Arrow</kbd>キーは、コマンド履歴を順に進めるために使えます。この2つのキーで、以前に実行したコマンドを素早く見つけて再実行できます。

## <kbd>Tab</kbd> キーによる自動補完

多くのシェルは、自動補完機能も提供しており、入力を始めた内容に基づいてコマンドを提案します。<kbd>Tab</kbd> キーを使うと提案の残りを補完でき、コマンドラインに完全な構文を素早く入力できます。提案される内容はシェル、入力中のコマンド、シェルの設定によって異なります。例えば、コマンド名を入力しているときは Bash や zsh が一致するコマンドを提案し、引数を入力しているときは通常、一致するファイルやディレクトリ名を提案します。PowerShell はコマンド、パラメータ名、変数、ファイルパスを補完できます。

## <kbd>Control</kbd> + <kbd>L</kbd> のショートカット

時にはコマンドの出力が大量になり、端末画面が見づらくなったり作業の妨げになることがあります。LinuxやmacOSの*nix系端末では、<kbd>Control</kbd> + <kbd>L</kbd>を押すと画面全体がクリアされ、きれいなプロンプトから再開できます。PowerShellでも<kbd>Control</kbd> + <kbd>L</kbd>で画面がクリアされ、同じ結果を得るには`cls`コマンドを実行できます。

## <kbd>Control</kbd> + <kbd>C</kbd> のショートカット

コマンドの実行を中断したい場合は、<kbd>Control</kbd> + <kbd>C</kbd> を押してください。これはフォアグラウンドで実行中のコマンドに割り込みリクエストを送り、通常はコマンドを停止して新しいプロンプトに戻り、他の作業を続けられるようにします。一部のプログラムはこのリクエストを自分で処理し、確認を求めたり実行を続けたりする場合があります。PowerShell ユーザーにとっては、<kbd>Control</kbd> + <kbd>C</kbd> はテキストのコピーにも使われ、コピーするテキストが選択されていない場合にのみコマンドの中断が機能します。

## *nix ベースのターミナルショートカット

次のいくつかのショートカットは*nix系ターミナルでのみ利用可能で、PowerShellには対応するものがありません。

作業を切り替えたいときに、コマンドを一時停止して別の作業をする場合があります。<kbd>Control</kbd> + <kbd>Z</kbd> を押すと、フォアグラウンドで実行中のコマンドが一時停止され、コマンドラインに戻って作業を続けられます。一時停止されたコマンドは停止状態であり、実行はしていません。バックグラウンドで実行を続けたい場合は `bg` コマンドを使い、フォアグラウンドに戻したい場合は `fg` コマンドを使ってください。

最後に、連続して同じコマンドを実行したい場合があります。<kbd>Up Arrow</kbd>キーで直前のコマンドに遡れますが、コマンドラインに感嘆符を2つ（`!!`）入力して<kbd>Enter</kbd>を押すと、最後に実行したコマンドが自動的に再実行されます。
