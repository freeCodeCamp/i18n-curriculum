# --description--

Функція `map()` виконує виклик функції для кожного елемента ітерованого об’єкта та повертає ітератор із результатами. Як і з `filter()`, ви можете передати їй лямбда-функцію:

```py
prices = [10, 20, 30]
discounted = list(map(
    lambda price: price * 0.9,
    prices
))
print(discounted) # [9.0, 18.0, 27.0]
```

Тепер потрібно конвертувати дійсні показники з десятих градуса у градуси.

Створіть змінну з назвою `temperatures`. Призначте їй результат виклику `map()` з лямбда-функцією та `valid_readings`, обгорнутим у виклик `list()`. Лямбда-функція має приймати параметр з назвою `reading` і повертати `reading`, поділене на `10`.

Потім виведіть `temperatures` замість `valid_readings`.
