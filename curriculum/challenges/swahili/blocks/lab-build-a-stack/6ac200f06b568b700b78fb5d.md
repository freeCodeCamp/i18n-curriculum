# --description--

Katika maabara hii, uta-tekeleza muundo wa data wa stack kwa kutumia vitendakazi. Stack ni muundo wa data wa Last-In-First-Out (LIFO) ambapo vipengele huongezwa na kuondolewa kutoka juu.

Stacki yako itakuwa kamusi ambayo ufunguo wake wa `collection` unashikilia orodha ya vipengele. Juu ya stacki ni mwisho wa orodha, kwa hivyo kipengele cha mwisho katika orodha ndicho kilichoongezwa hivi karibuni.

**Lengo:** Timiza hadithi za watumizi zilizo hapa chini na upite vipimo vyote ili kumaliza maabara.

**Hadithi za watumizi:**

1. Unapaswa kuwa na kitendakazi cha `init_stack` kinachorejesha kamusi yenye ufunguo wa `collection` uliowekwa kwa orodha tupu.
1. Unapaswa kuwa na kitendakazi cha `push` kinachochukua stacki na kipengele, na kuongeza kipengele hicho juu ya stacki.
1. Unapaswa kuwa na kitendakazi cha `pop` kinachochukua stacki, na kuondoa na kurudisha kipengele chake cha juu, au kurudisha `None` ikiwa stacki ni tupu.
1. Unapaswa kuwa na kitendakazi cha `peek` kinachochukua stacki, na kurudisha kipengele chake cha juu bila kuondoa, au kurudisha `None` ikiwa stacki ni tupu.
1. Unapaswa kuwa na kitendakazi cha `is_empty` kinachochukua stacki, na kurudisha `True` ikiwa haina vipengele, na `False` vinginevyo.
1. Unapaswa kuwa na kitendakazi cha `clear` kinachochukua stacki, na kuondoa vipengele vyote vyake.

**Kumbuka:** Vipimo vingi vinategemea vitendakazi vya `init_stack` na `push`. Tekeleza kwanza, kwani vipimo vya `pop`, `peek`, `is_empty`, na `clear` vinahitaji kuongeza vipengele kwenye stacki.

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
