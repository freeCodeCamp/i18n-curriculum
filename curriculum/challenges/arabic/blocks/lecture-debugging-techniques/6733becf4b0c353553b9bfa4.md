# --description--

جملة `debugger` هي أداة قوية في JavaScript تتيح لك إيقاف كودك عند سطر معين للتحقق مما يحدث في البرنامج. عند استخدامها بشكل صحيح، توفر جملة `debugger` الكثير من الوقت في محاولة معرفة سبب عدم عمل شيء كما ينبغي.

ينفذ JavaScript الكود من الأعلى إلى الأسفل. عندما يصل التنفيذ إلى جملة `debugger`، يتوقف فورًا عند ذلك السطر. هذا يمنحك فرصة لفحص المتغيرات، والتحقق من الدوال، وتتبع سير الكود بشكل عام.

بهذا يمكنك رؤية بالضبط ما يحدث بشكل صحيح أو خاطئ. لكن هذا يحدث فقط إذا كانت أدوات المطوِّر في المتصفح مفتوحة. وإلا، تُتجاهل جملة `debugger` ويستمر الكود في العمل كالمعتاد.

بالإضافة إلى ذلك، عند استخدام جملة `debugger`، توقف المتصفحات الحديثة تنفيذ الكود عند السطر المحدد. كما تسمح لك باستئناف التنفيذ بالنقر على زر التشغيل، لكن الصفحة نفسها لا تُعاد تحميلها تلقائيًا إلا إذا تم تفعيل ذلك يدويًا.

لاستخدام جملة `debugger`، ضعها في السطر الذي تريد أن يتوقف عنده تنفيذ الكود. إليك مثالًا:

```js
let firstNumber = 5;
let secondNumber = 10;
debugger; // Code execution pauses here
let sum = firstNumber + secondNumber;
console.log(sum);
```

في هذا المثال، إذا لم تكن وحدة التحكم مفتوحة قبل تشغيل الكود وفتحتها لاحقًا، سترى القيمة `15` هناك. بينما وحدة التحكم مفتوحة وتعيد تحميل الصفحة، يتوقف التنفيذ لتتمكن من فحص الكود.

إليك مثالًا أكثر تعقيدًا:

```js
function calculateTotalPrice(price, discountPercentage) {
 debugger
 let discountAmount = (price * discountPercentage) / 100
 let totalPrice = price - discountAmount

 console.log(`Original Price: ${price}`)
 console.log(`Discount Amount: ${discountAmount}`)
 console.log(`Total Price after Discount: ${totalPrice}`)

 return totalPrice
}

let price = 100
let discount = 15

let finalPrice = calculateTotalPrice(price, discount)
console.log(`Final Price: ${finalPrice}`);
```

في هذا المثال، وُضعت جملة `debugger` في بداية دالة `calculateTotalPrice`. عند استدعاء الدالة، يتوقف تنفيذها مؤقتًا.

إذا أعدت تحميل الصفحة مع فتح وحدة التحكم، سترى أن الصفحة تستمر في إعادة التحميل، مما يؤكد أن تنفيذ الكود متوقف مؤقتًا فقط وليس متوقفًا نهائيًا. إذا أردت استمرار التنفيذ، يمكنك النقر على زر التشغيل.

بينما تواصل بناء برامج JavaScript الخاصة بك، جرب استخدام جملة `debugger` في كودك لترى كيف تساعدك على فهم سير التنفيذ بشكل أفضل، وفحص المتغيرات في الوقت الحقيقي، وتحديد مكان الخطأ بسرعة.
