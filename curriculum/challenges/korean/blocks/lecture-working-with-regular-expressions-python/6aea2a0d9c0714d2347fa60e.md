# --description--

지금까지 `re.search`를 사용해 문자열 어디에서나 패턴을 찾았습니다. `re` 모듈에는 정규식 패턴과 함께 작동하는 다른 많은 함수가 있습니다. 이 수업에서는 가장 유용한 함수 몇 가지를 배워보세요.

## `match` 함수

`match` 함수는 `search`와 비슷하지만, 문자열의 시작 부분에서만 패턴을 찾습니다. 문자열 시작이 패턴과 일치하면 매치 객체를 반환하고, 그렇지 않으면 `None`을 반환합니다:

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

두 번째 예제에서 문자열에 숫자가 포함되어 있어 `re.search`는 이를 찾을 수 있습니다. 하지만 문자열이 숫자로 시작하지 않기 때문에 `re.match`는 `None`을 반환합니다.

## `fullmatch` 함수

패턴 `r'\d+:\d+'`는 하나 이상의 숫자 다음에 콜론과 다시 하나 이상의 숫자가 오는 형태를 의미합니다. 이는 `10:30` 같은 시간 형식입니다.

사용자 입력이 시간 형식이고 다른 문자가 포함되지 않았는지 확인하고 싶다고 상상해보세요. `re.search`를 사용하면 문제가 발생합니다:

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

`10:30pm`이 예상 형식을 따르지 않는데도 매치 객체를 반환합니다. 이는 `re.search`가 문자열 어디에서나 패턴을 찾고, 매치 주변의 추가 문자는 무시하기 때문입니다. `re.match`도 같은 문제를 겪는데, `10:30pm`이 유효한 시간으로 시작하기 때문입니다.

데이터를 검증할 때는 보통 전체 문자열이 패턴을 따라야 합니다. 이럴 때 `fullmatch` 함수를 사용하세요. 패턴이 전체 문자열과 일치할 때만 매치 객체를 반환하고, 그렇지 않으면 `None`을 반환합니다:

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## `findall` 함수

`search`, `match`, `fullmatch`는 최대 한 개의 매치만 제공합니다. 문자열 내 모든 매치를 찾고 싶을 때는 `findall` 함수를 사용하세요. 찾은 모든 매치를 문자열 리스트로 반환합니다:

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

매치가 없으면 `findall`은 빈 리스트를 반환합니다:

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## `sub` 함수

`sub` 함수는 패턴과 일치하는 모든 부분을 다른 문자열로 교체합니다. 패턴, 교체 문자열, 검색할 문자열을 받아 새 문자열을 반환합니다:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub`에는 두 개의 선택적 매개변수가 있습니다. 첫 번째는 `count`로, 교체할 매치 수를 제한합니다:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

두 번째는 `flags`입니다. 다른 함수들처럼 `sub`도 `re.IGNORECASE` 같은 플래그를 사용할 수 있습니다:

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

`count`와 `flags`는 항상 키워드 인수로 전달하세요. `re.IGNORECASE`를 네 번째 위치 인수로 전달하면 Python이 이를 `count` 값으로 처리합니다.
