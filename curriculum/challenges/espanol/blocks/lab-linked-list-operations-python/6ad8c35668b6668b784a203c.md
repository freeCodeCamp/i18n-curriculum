# --description--

En este laboratorio, implementarás operaciones adicionales para una estructura de datos de lista enlazada, basándote en la clase `LinkedList` que creaste en el taller anterior.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

**Historias de usuario:**

1. Tu clase `LinkedList` debe tener un método `contains` que tome un elemento como argumento. Debe devolver `True` si el elemento existe en la lista enlazada, y `False` en caso contrario.
1. Tu clase `LinkedList` debe tener un método `get_at` que tome un índice como argumento. Debe devolver el elemento en el índice dado en la lista enlazada. Si el índice está fuera de rango, debe devolver `None`.
1. Tu clase `LinkedList` debe tener un método `insert_at` que tome un índice y un elemento como argumentos. Debe insertar el elemento en la posición dada en la lista enlazada y actualizar el atributo `length`. Un índice igual a la longitud de la lista es válido y debe agregar el elemento al final. Si el índice está fuera de rango, no debe modificar la lista.
1. Tu clase `LinkedList` debe tener un método `remove_at` que tome un índice como argumento. Debe eliminar el nodo en el índice dado en la lista enlazada y actualizar el atributo `length`. Si el índice está fuera de rango, no debe modificar la lista.
1. Tu clase `LinkedList` debe tener un método `clear` que elimine todos los elementos de la lista enlazada, restableciéndola a un estado vacío con `head` establecido en `None` y `length` en `0`.

**Nota:** Algunas pruebas posteriores dependen de métodos anteriores. Por ejemplo, si `get_at` no está implementado correctamente, las pruebas para métodos como `insert_at` y `remove_at` pueden fallar incluso cuando esos métodos están casi correctos.

class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
