# --description--

لإنهاء الأمور، عيّن نص العنصر الأول `a` **في `sub-menu`** إلى `Calendar`، والثاني إلى `Chat`، والثالث إلى `Email`.

أخيرًا، اجعل زر `Apps` وقائمة `sub-menu` يتغيران ديناميكيًا. استخدم `React.useState` لإضافة حالة تتبع ما إذا كانت القائمة الفرعية مفتوحة، وأضف معالِج `onClick` إلى عنصر `button` لتبديلها. عيّن خاصية `aria-expanded` في عنصر `button` إلى `"true"` أو `"false"` (كسلسلة نصية) حسب الحالة. بالنسبة إلى عنصر `ul`، أضف الصنف `sub-menu--open` عندما تكون الحالة true (مع الإبقاء على صنف `sub-menu`).

بهذا، يصبح مكوِّن `Navbar` الخاص بك مكتملًا!

```js

```

يجب أن تدمج حالة React لتبديل الخاصية `aria-expanded` والصنف `sub-menu--open`.

```js
const button = document.querySelector('button');
const subMenu = document.querySelector('.sub-menu');
assert.equal(button?.getAttribute('aria-expanded'), 'false');
assert.isFalse(subMenu?.classList.contains('sub-menu--open'));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute('aria-expanded'), 'true');
assert.isTrue(subMenu?.classList.contains('sub-menu--open'));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute('aria-expanded'), 'false');
assert.isFalse(subMenu?.classList.contains('sub-menu--open'));
```

export const Navbar = () => {
  const [isOpen, setIsOpen] = React.useState(false);

  return (
    <nav className="navbar">
      <ul>
        <li className="nav-item">
          <a href="#">Dashboard</a>
        </li>
        <li className="nav-item">
          <a href="#">Widgets</a>
        </li>
        <li className="nav-item">
          <button
            aria-expanded={isOpen ? "true" : "false"}
            onClick={() => setIsOpen(!isOpen)}
          >
            Apps
          </button>
          <ul
            className={isOpen ? "sub-menu sub-menu--open" : "sub-menu"}
            aria-label="Apps"
          >
            <li><a href="#">Calendar</a></li>
            <li><a href="#">Chat</a></li>
            <li><a href="#">Email</a></li>
          </ul>
        </li>
      </ul>
    </nav>
  );
};
