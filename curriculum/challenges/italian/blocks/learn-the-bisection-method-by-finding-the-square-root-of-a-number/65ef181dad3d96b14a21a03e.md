# --description--

Il metodo della bisezione, noto anche come metodo di ricerca binaria, usa una ricerca binaria per trovare le radici di una funzione a valori reali. Funziona restringendo un intervallo in cui si trova una radice fino a convergere a un valore entro una tolleranza specificata.

In questo progetto userai il metodo della bisezione per trovare la radice quadrata approssimativa di un numero.

Inizia creando una funzione chiamata `square_root_bisection`. Lascia per ora i parametri vuoti.
