# --description--

في هذا المختبر، ستعالج طلبات التجارة الإلكترونية وتتولى التعامل مع الأخطاء التي تظهر أثناء العملية.

**الهدف:** إكمال قصص المستخدم أدناه واجتياز جميع الاختبارات لإتمام المختبر.

البيانات التي ستعمل معها لها نفس هيكل المتغيرات في الكود الابتدائي:

- الطلب هو قاموس يحتوي على:
  - `order_id`: عدد صحيح يحدد الطلب.
  - `products`: قائمة من القواميس، كل منها يحتوي على `product_id` و`quantity` المطلوبة.
  - `discount_code`: سلسلة نصية، أو `None` إذا لم يكن للطلب رمز خصم.
  - `status`: سلسلة نصية تصف حالة الطلب.
- سجل الطلبات هو قائمة من الطلبات.
- المخزون هو قاموس تكون مفاتيحه معرفات المنتجات وقيمه قواميس تحتوي على اسم `product`، وكمية `quantity` المخزون، وسعر `price` الوحدة الواحدة.
- رموز الخصم هي قاموس مفاتيحه هي الرموز وقيمه هي معدلات الخصم، مثل `0.1` لخصم 10%.

**قصص المستخدم:**

1. يجب أن تملك دالة باسم `find_order` بمعلمتين: معرف الطلب وتاريخ الطلبات، بهذا الترتيب.
1. يجب أن تقوم `find_order` بما يلي:
   - إرجاع الطلب من تاريخ الطلبات المعطى الذي يكون `order_id` الخاص به مساويًا لمعرف الطلب المعطى.
   - رفع استثناء `ValueError` مع الرسالة `Order ID {order_id} not found in order history.` إذا لم يتطابق أي طلب مع معرف الطلب المعطى.
1. يجب أن تملك دالة باسم `verify_availability` بمعلمتين: طلب ومخزون، بهذا الترتيب.
1. يجب أن تقوم `verify_availability` بما يلي:
   - رفع استثناء `ValueError` مع الرسالة `Product ID {product_id} is not in the inventory.` إذا كان منتج في الطلب مفقودًا من المخزون المعطى.
   - رفع استثناء `ValueError` مع الرسالة `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.` إذا كانت الكمية المطلوبة من منتج أكبر من الكمية المتوفرة في المخزون المعطى.
   - عدم رفع أي استثناء إذا كان كل منتج في الطلب متوفرًا بالكمية المطلوبة.
1. يجب أن تملك دالة باسم `get_discount_rate` بمعلمتين: طلب ورموز الخصم، بهذا الترتيب.
1. يجب أن تقوم `get_discount_rate` بما يلي:
   - إرجاع `0.0` إذا كان `discount_code` الخاص بالطلب هو `None`.
   - رفع استثناء `ValueError` مع الرسالة `Invalid discount code: {discount_code}.` إذا كان `discount_code` الخاص بالطلب غير موجود ضمن رموز الخصم المعطاة.
   - إرجاع معدل الخصم الخاص بـ `discount_code` الخاص بالطلب خلاف ذلك.
1. يجب أن تملك دالة باسم `process_order` بأربع معلمات: معرف الطلب المراد معالجته، تاريخ الطلبات، المخزون، ورموز الخصم، بهذا الترتيب.
1. يجب أن تستخدم `process_order` الدوال `find_order` و`verify_availability` و`get_discount_rate` لمعالجة الطلب، وأن تتعامل مع استثناء `ValueError` الذي ترفعونه بحيث لا يرفع `process_order` أي استثناء عند استدعائه.
1. عندما لا يطابق أي طلب في سجل الطلبات المعطى رقم الطلب المعطى، يجب أن تقوم الدالة `process_order` بـ:
   - طباعة `Error processing order {order_id}: {error message}`، حيث تكون `{error message}` هي رسالة الخطأ من نوع `ValueError` التي أرجعتها الدالة `find_order`، وعدم طباعة أي شيء آخر.
   - ترك المخزون ورموز الخصم المعطاة دون تغيير.
1. عندما يكون الطلب موجودًا لكنه لا يمكن تنفيذه، بسبب فقدان منتج من المخزون، أو عدم توفر الكمية المطلوبة، أو بسبب أن رمز الخصم غير صالح، يجب على `process_order`:
   - طباعة `Error processing order {order_id}: {error message}`، حيث تكون `{error message}` هي رسالة `ValueError` التي أرجعتها دالتي `verify_availability` أو `get_discount_rate`.
   - تعيين حالة الطلب `status` إلى `failed`.
   - ترك المخزون ورموز الخصم كما هما دون تغيير.
   - طباعة `Order {order_id} processing completed. Current status: failed`.
1. عندما يمكن تنفيذ الطلب، يجب أن تقوم الدالة `process_order` بـ:
   - طباعة `Order {order_id} total: ${total}` مع تطبيق الخصم وتقريب المجموع إلى منزلتين عشريتين.
   - تعيين قيمة `status` للطلب إلى `processed`.
   - طرح الكميات المطلوبة من المخزون المعطى.
   - إزالة رمز الخصم الذي استخدمه الطلب من رموز الخصم المعطاة، بحيث يمكن استخدام كل رمز مرة واحدة فقط.
   - طباعة `Order {order_id} processing completed. Current status: processed`.

**ملاحظة:** تم تزويدك بمخزون وتاريخ طلبات ورموز خصم يمكنك استخدامها لاختبار كودك. استدعِ دوالك لتجربتها، بما في ذلك الحالات التي ترفع أخطاء، لكن أضف تعليقًا على تلك الاستدعاءات قبل تشغيل الاختبارات، حتى لا تؤثر على نتائجها.

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id, order_history, inventory, discount_codes):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
