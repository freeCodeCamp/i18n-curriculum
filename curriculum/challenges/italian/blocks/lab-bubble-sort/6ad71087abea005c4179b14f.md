# --description--

Il bubble sort funziona passando ripetutamente attraverso una lista, confrontando elementi adiacenti e scambiandoli se sono fuori ordine. Dopo ogni passaggio, il valore più grande non ordinato "risale" fino alla fine della lista. L'algoritmo si ferma quando un passaggio completo termina senza alcuno scambio.

Il bubble sort ha una complessità temporale quadratica nei casi medi e peggiori, quindi è usato raramente nella pratica.

**Obiettivo:** Completa le storie utente qui sotto e fai passare tutti i test per completare il laboratorio.

**Storie utente:**

1. Dovresti definire una funzione chiamata `bubble_sort` con un parametro che rappresenta la lista di elementi.
1. La tua funzione `bubble_sort` dovrebbe ordinare la lista in loco dal più piccolo al più grande e restituirla.
1. La tua funzione `bubble_sort` dovrebbe seguire l'algoritmo bubble sort, confrontando elementi adiacenti e scambiandoli solo quando l'elemento a sinistra è maggiore di quello a destra.
1. La tua funzione `bubble_sort` dovrebbe fermarsi non appena un passaggio attraverso la lista si completa senza alcuno scambio.
1. La tua funzione `bubble_sort` non dovrebbe usare né il metodo integrato `sort()` né la funzione `sorted()`.

**Nota:** Non dovresti importare moduli nel tuo codice.

```js
({
  test: () =>
    runPython(`
from collections import UserList

class CustomList(UserList):
    def __init__(self, *args, **kwargs):
        self._record = []
        super().__init__(*args, **kwargs)

    def __setitem__(self, key, value):
        self._record.append((key, value))
        super().__setitem__(key, value)

def expected_swaps(items):
    items = list(items)
    swaps = []
    swapped = True
    while swapped:
        swapped = False
        for j in range(len(items) - 1):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swaps.append({(j, items[j]), (j + 1, items[j + 1])})
                swapped = True
    return swaps

for values in ([33, 1, 89, 2, 67, 245], [4, 4, 2, 2, 1, 4, 3]):
    list_to_sort = CustomList(values)
    bubble_sort(list_to_sort)
    record = list_to_sort._record
    expected = expected_swaps(values)
    assert len(record) == 2 * len(expected)
    actual = [set(record[i:i + 2]) for i in range(0, len(record), 2)]
    assert actual == expected
    `)
});
```

```py
def bubble_sort(items):
    n = len(items)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swapped = True
        if not swapped:
            break
    return items
```
