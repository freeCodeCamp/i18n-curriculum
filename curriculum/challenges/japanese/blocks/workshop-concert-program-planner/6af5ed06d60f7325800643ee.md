# --description--

特定の位置にアイテムを追加するには、`insert()` メソッドを使えます。これは新しいアイテムを入れたいインデックスと、その後にアイテム自体を受け取ります。そのインデックス以降のアイテムは右に1つずつずれます。

```py
fruits = ['apple', 'banana', 'cherry']
fruits.insert(1, 'blueberry')
print(fruits) # ['apple', 'blueberry', 'banana', 'cherry']
```
