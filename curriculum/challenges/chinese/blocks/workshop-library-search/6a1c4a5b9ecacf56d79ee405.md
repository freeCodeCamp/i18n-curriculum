# --description--

你已经成功处理了成功和误差状态。但如果你有一些代码想无论发生什么都要执行呢？这时就用到 `finally` 块了。

```js
try {
  // Code that might throw an error
} catch (err) {
  // Code to handle the error
} finally {
  // Code to run regardless of success or failure
}
```

在你的 `catch` 块正下方，添加一个 `finally` 块。在里面，将 `bookInput` 的 `value` 属性设置为空字串（`""`），以清空输入字段，让用户可以立即输入新的查找内容。
