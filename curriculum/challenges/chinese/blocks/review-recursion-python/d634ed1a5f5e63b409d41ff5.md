# --description--

- 递归是一种编程概念，允许你反复调用一个函数，直到达到基本情形。

下面是一个计算数字阶乘的递归函数示例：

```py
def find_factorial(n):
    if n == 0:
        return 1
    return n * find_factorial(n - 1)
```

在上面的例子中，`find_factorial` 函数递归调用，直到 `n` 达到 `0`。当 `n` 为 `0` 时，达到基本情形，函数返回 `1`。然后函数返回 `n` 与递归调用 `find_factorial(n - 1)` 结果的乘积。

- 递归允许你处理未知深度的结构，比如深度嵌套的字典和列表，或者文件树。
- 调用栈用于跟踪递归函数中的函数调用。每次调用函数时，它都会被添加到调用栈中。当达到基本情形时，函数调用会从栈中移除。
- 你应该仔细定义基本情形。否则，函数会不断调用自身，直到 Python 引起 `RecursionError`。
- 递归对于解决阶乘和斐波那契等数学问题、遍历树和图、生成排列组合非常有用。
