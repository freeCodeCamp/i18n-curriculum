# --description--

En Python, las variables son nombres que se refieren a objetos. Los operadores de identidad verifican si dos operandos se refieren al mismo objeto. El operador `is` devuelve `True` si es así, y `False` en caso contrario. El operador `is not` devuelve el resultado opuesto.

La identidad difiere de la igualdad: `==` y `!=` comparan valores, mientras que `is` y `is not` comparan la identidad del objeto. Usa operadores de igualdad al comparar valores numéricos o cadenas.

`None` representa la ausencia de un valor. Es el único valor del tipo de dato `NoneType`.

Tres objetos que puedes verificar con operadores de identidad son `None`, `True` y `False`. Cada uno es un singleton, lo que significa que existe exactamente un objeto para cada uno.

## Verificar `None`

Puedes usar `is None` para comprobar si falta un valor, o `is not None` para comprobar si está presente:

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None` es falso, pero no es el mismo objeto que `False`. Por ejemplo, una respuesta podría ser `True` para sí, `False` para no, o `None` si no se ha dado respuesta:

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

Usar `if not response` en su lugar trataría a `False` y `None` por igual. La verificación de identidad distingue una respuesta negativa de una respuesta ausente.

## Verificar `True` y `False`

También puedes usar la identidad para verificar específicamente los objetos booleanos:

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

Estas verificaciones preguntan si `response` es exactamente `True`, `False` o un objeto distinto de `None`. No solo prueban la veracidad.

Para banderas booleanas ordinarias, usa pruebas directas de verdad como `if is_ready` o `if not is_ready`. Usa `is True` o `is False` cuando necesites distinguir específicamente un objeto booleano de otros valores posibles, como con una respuesta que también puede ser `None`.
