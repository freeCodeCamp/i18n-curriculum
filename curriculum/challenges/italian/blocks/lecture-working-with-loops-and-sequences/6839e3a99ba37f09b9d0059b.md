## Che cos'è una tupla?

Una tupla è un tipo di dato Python usato per creare una sequenza ordinata di valori. Le tuple possono contenere un insieme misto di tipi di dati come questo:

```py
developer = ('Alice', 34, 'Rust Developer')
```

Le virgole creano la tupla, quindi le parentesi tonde sono opzionali in un'assegnazione come questa:

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

Per creare una tupla con un solo elemento, serve una virgola finale:

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

Una tupla vuota si scrive come `()`.

Le tuple sono simili alle liste, ma mentre le liste sono un tipo di dato mutabile, le tuple sono immutabili. Questo significa che gli elementi in una tupla non possono essere modificati una volta creata.

Se provi ad aggiornare uno degli elementi nella tupla, otterrai un `TypeError`:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## Consultare gli elementi di una tupla

Per consultare un elemento da una tupla, puoi usare la notazione a parentesi e il numero dell’indice:

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

Se hai bisogno di consultare elementi partendo dalla fine di una tupla, puoi usare l’indicizzazione negativa. Ecco un esempio di utilizzo di un indice negativo per consultare il penultimo elemento in una tupla:

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

Se provi a passare un numero di indice che supera o è uguale alla lunghezza della tupla, riceverai un `IndexError` come questo:

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## Usare il costruttore `tuple()`

Un altro modo per creare una tupla è usando il costruttore `tuple()` così:

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

Per il costruttore `tuple()`, puoi passare diversi iterabili come stringhe, liste e persino altre tuple.

## Verificare se un elemento è in una tupla

Per verificare se un elemento è in una tupla, puoi usare la parola chiave `in` così:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## Estrarre valori da una tupla

Puoi anche decomprimere elementi da una tupla proprio come hai fatto con le liste:

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

In questo esempio, `name` ha il valore `'Alice'`, `age` ha il valore `34` e `job` ha il valore `'Rust Developer'`.

Se hai bisogno di raccogliere gli elementi rimanenti da una tupla, puoi usare l’operatore asterisco (`*`) così:

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

Qui, `name` ha il valore `'Alice'` e `rest` è una lista composta dal numero `34` e dalla stringa `'Rust Developer'`.

## Usare le tuple nell'assegnazione simultanea

Puoi creare una tupla sul lato destro di un'assegnazione e decomprimerla nelle variabili sul lato sinistro:

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

Python valuta tutte le espressioni sul lato destro prima di assegnare i loro valori alle variabili sul lato sinistro. Questo ti permette di scambiare due valori senza una variabile temporanea:

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## Restituire una tupla da una funzione

Una funzione può restituire una tupla mettendo valori separati da virgole dopo `return`:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

I valori separati da virgole creano una tupla che la funzione restituisce. Qui, `return first, second` è equivalente a `return (first, second)`. Le parentesi tonde sono opzionali.

Puoi decomprimere la tupla restituita direttamente nelle variabili:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## Estrarre porzioni di tuple

Proprio come con una lista, puoi usare l’operatore slice su una tupla per estrarne una porzione. Ecco un esempio di estrazione degli elementi `'pie'` e `'cookies'` in una tupla separata:

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

Ricorda che il primo numero rappresenta l’indice di partenza per l’estrazione mentre il secondo numero rappresenta l’indice finale. Ma nota che l’elemento all’indice finale non è incluso nella tupla estratta.

## Confrontare le tuple

Python confronta le tuple lessicograficamente. Questo significa che confronta gli elementi corrispondenti da sinistra a destra. La prima coppia non uguale determina il risultato:

```py
print((1, 9) < (2, 0)) # True
```

Qui, `1` è minore di `2`, quindi la prima tupla è più piccola. Python non ha bisogno di confrontare `9` e `0`.

Se i primi elementi sono uguali, Python passa alla coppia successiva:

```py
print((1, 3) < (1, 5)) # True
```

Entrambe le tuple iniziano con `1`, quindi Python confronta `3` con `5` per determinare il risultato.

Se tutti gli elementi corrispondenti sono uguali, la tupla più corta è più piccola. Tuple con la stessa lunghezza e elementi corrispondenti uguali sono uguali:

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

I valori nella prima coppia non uguale devono supportare il confronto di ordine. Altrimenti, Python genera un `TypeError`:

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

Qui, i primi elementi sono uguali, ma Python non può ordinare l'intero `3` e la stringa `'five'`.

Gli elementi successivi non devono essere confrontabili se una coppia precedente ha già determinato il risultato:

```py
print((1, 3) < (2, 'five')) # True
```

## Rimuovere elementi da una tupla

Se hai bisogno di rimuovere un elemento da una tupla, non è possibile perché le tuple sono immutabili. Quindi questo esempio genererà un errore:

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## Scegliere tra tuple e liste

Quando potresti quindi usare una tupla invece di una lista?

Se ti serve una collezione dinamica di elementi in cui puoi aggiungere, rimuovere e aggiornare elementi, allora dovresti usare una lista. Se sai di lavorare con una collezione fissa e immutabile di dati, allora dovresti usare una tupla.

Nella prossima lezione, vedremo alcuni metodi comuni che userai quando lavori con le tuple.
