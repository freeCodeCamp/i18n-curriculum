## HTMLの基本

- **HTMLの役割**：HTML（Hypertext Markup Language）はウェブ構造の基盤であり、ウェブページの要素を定義します。
- **HTML要素**：ページ上のコンテンツを表すために使われます。ほとんどは開始タグと終了タグで構成されています（例：`<h1></h1>`、`<p></p>`）。
- **HTMLの構造**：HTMLは`head`と`body`で構成されており、メタデータ、スタイル、コンテンツが構造化されています。
- **一般的なHTML要素**：見出し（`<h1>` - `<h6>`）、段落（`<p>`）、およびdivコンテナ（`<div>`）。
- **`div`要素**：`div`要素は意味論的な意味を持たない汎用のHTML要素です。ほかのHTML要素を格納するための汎用コンテナとして使われます。
- **空要素**：終了タグを持ちません（例：`<img>`）。
- **属性**：要素にメタデータや動作を追加します。

## 識別子とグループ化

- **ID**：一意の要素識別子です。
- **クラス**：スタイルや動作のために要素をグループ化します。

## ボイラープレートとエンコーディング

- **HTMLボイラープレート**：ウェブページの基本構造で、`DOCTYPE`、`html`、`head`、`body`要素を含みます。HTMLドキュメントの出発点として使います。
- **UTF-8文字エンコーディング**：文字の普遍的な表示を保証します。

## セマンティックHTMLの重要性

- **見出し要素の構造的階層**：コンテンツの構造的階層を維持するために、正しい見出し要素を使うことが重要です。`h1`要素は最上位の見出しで、`h6`要素は最下位の見出しです。
- **セマンティックHTML要素**：これらの要素はコンテンツの構造に意味を与えます。例は以下の通りです：
  - `<header>`：導入部分のコンテンツを表します。
  - `<nav>`：ナビゲーションリンクを含みます。
  - `<article>`：独立したコンテンツを表します。
  - `<section>`：文書内の関連するコンテンツをグループ化します。
  - `<footer>`：セクションまたは文書のフッターを定義します。
  - `<blockquote>`：別のソースから引用した部分を表します。`cite`属性にソースを指定してください。
  - `<q>`：短いインライン引用を表します。

## HTMLフォーム要素と属性

### フォーム

- **`form`要素**：ユーザー入力のためのHTMLフォームを作成するために使います。
- **一般的な入力タイプ**：
  - `text`、`email`、`radio`、`checkbox`、`number`。
- **`action`属性**：フォームデータを送信するURLを指定します。
- **`method`属性**：フォームデータ送信時に使うHTTPメソッドを指定します。一般的なメソッドは`GET`と`POST`です。

```html
<form method="value-goes-here" action="url-goes-here">
  <!-- inputs go inside here -->
</form>
```

- **`input` 要素**：ユーザーの入力用の入力フィールドを作成するときに使います。
- **`type` 属性**：入力フィールドの種類を指定します。例：`text`、`email`、`number`、`radio`、`checkbox`。
- **`placeholder` 属性**：入力フィールドに何を入力すればよいか、ユーザーへのヒントを表示するために使います。
- **`value` 属性**：入力の値を指定します。`button` タイプの場合、`value` 属性でボタンのテキストを設定できます。
- **`name` 属性**：入力フィールドに名前を付けるために使います。これはフォームデータを送信するときのキーになります。ラジオボタンの場合、同じ `name` を付けることでグループ化され、グループ内で1つだけ選択できるようになります。
- **`size` 属性**：ユーザーが入力中に表示される文字数を指定します。
- **`min` 属性**：`number` などの入力タイプで、入力フィールドに許可される最小値を指定できます。
- **`max` 属性**：`number` などの入力タイプで、入力フィールドに許可される最大値を指定できます。
- **`required` 属性**：フォームを提出する前に入力フィールドが必ず入力されている必要があることを指定します。

:::interactive_editor

```html
<!-- Text input -->
<input 
  type="text"
  id="name"
  name="name"
  placeholder="e.g. Quincy Larson"
  size="20"
  required
/>

<!-- Number input -->
<input 
  type="number"
  id="quantity"
  name="quantity"
  min="2"
  max="10"
/>

<!-- Button -->
<input type="button" value="Show Alert" />
```

:::

- **`label`要素**：入力フィールドのラベルを作成します。
- **`for`属性**：ラベルがどの入力フィールドに対応しているかを指定します。

:::interactive_editor

```html
<form action="">
  <label for="email">Email Address: </label>
  <input type="email" id="email" />
</form>
```

:::

- **`button`要素**：クリック可能なボタンを作成します。ボタンには`type`属性もあり、ボタンが起動されたときの動作を制御します。

:::interactive_editor

```html
<button type="submit">Submit Form</button>
```

:::

- **`fieldset`要素**：関連する入力をグループ化します。
- **`legend`要素**：入力グループの説明キャプションを追加します。

:::interactive_editor

```html
<!-- Radio group -->
<fieldset>
  <legend>Was this your first time at our hotel?</legend>

  <input id="yes-option" type="radio" name="hotel-stay" value="yes" />
  <label for="yes-option">Yes</label>

  <input id="no-option" type="radio" name="hotel-stay" value="no" />
  <label for="no-option">No</label>
</fieldset>

<!-- Checkbox group -->
<fieldset>
  <legend>
    Why did you choose to stay at our hotel? (Check all that apply)
  </legend>

  <input type="checkbox" id="location" name="location" value="location" />
  <label for="location">Location</label>

  <input type="checkbox" id="price" name="price" value="price" />
  <label for="price">Price</label>
</fieldset>
```

:::

## HTMLテーブル要素と属性の操作

- **テーブル要素**：HTMLテーブルを作成します。
- **テーブルヘッド（`thead`）要素**：HTMLテーブルのヘッダーコンテンツをグループ化します。
- **テーブル行（`tr`）要素**：HTMLテーブルの行を作成します。
- **テーブルヘッダー（`th`）要素**：HTMLテーブルのヘッダーセルを作成します。
- **テーブルボディ（`tbody`）要素**：HTMLテーブルの本文コンテンツをグループ化します。
- **テーブルデータセル（`td`）要素**：HTMLテーブルのデータセルを作成します。
- **テーブルフット（`tfoot`）要素**：HTMLテーブルのフッターコンテンツをグループ化します。
- **`caption`要素**：HTMLテーブルのタイトルを追加します。
- **`colspan`属性**：テーブルセルがまたがる列数を指定します。

:::interactive_editor

```html
<table>
  <caption>Exam Grades</caption>

  <thead>
    <tr>
      <th>Last Name</th>
      <th>First Name</th>
      <th>Grade</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Davis</td>
      <td>Alex</td>
      <td>54</td>
    </tr>

    <tr>
      <td>Doe</td>
      <td>Samantha</td>
      <td>92</td>
    </tr>

    <tr>
      <td>Rodriguez</td>
      <td>Marcus</td>
      <td>88</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <td colspan="2">Average Grade</td>
      <td>78</td>
    </tr>
  </tfoot>
</table>
```

:::

## アクセシビリティ

- **Webコンテンツアクセシビリティガイドライン**：Webコンテンツアクセシビリティガイドライン（WCAG）は、障害のある人々がウェブコンテンツによりアクセスしやすくするための指針のセットです。WCAGの4つの原則はPOURで、Perceivable（知覚可能）、Operable（操作可能）、Understandable（理解可能）、Robust（堅牢）を表します。
- **適切な`alt`テキストの重要性**：画像には`alt`属性を使ってテキストの代替を提供してください。これにより支援技術が画像の内容を理解できます。
- **適切なリンクテキストの重要性**：ユーザーがリンクの目的を理解できるように、説明的なリンクテキストを使ってください。
