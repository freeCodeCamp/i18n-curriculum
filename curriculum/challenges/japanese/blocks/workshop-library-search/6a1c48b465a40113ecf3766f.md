# --description--

ユーザーが空のフィールドで検索しようとした場合、関数は実行を停止してエラーをスローします。

しかし、ユーザーが`library`配列にない本を検索したらどうしますか？その例外も処理する必要があります。

最初の`if`文の下に、2つ目の`if`文を作成してください。条件の中で論理NOT演算子（`!`）と`.includes()`メソッドを使い、`library`配列に関数に渡された`title`が含まれていないかをチェックしてください。

`if`文の中で、`throw`キーワードを使って`new Error()`をスローしてください。`Error`コンストラクタには式`title + " not found!"`を渡してください。

# --hints--
