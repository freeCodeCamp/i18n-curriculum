# --description--

根節點是樹的最頂端節點，其他所有節點都可以從它到達。

現在創建一個名為 `BinarySearchTree` 的類別來表述整棵樹。給它一個只帶有 `self` 的 `__init__` 方法。

一棵新的樹沒有節點，所以在 `__init__` 方法中將 `root` 屬性設為 `None`。
