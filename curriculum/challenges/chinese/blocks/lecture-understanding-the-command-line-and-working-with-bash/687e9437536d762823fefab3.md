# --description--

让我们了解你可以使用的命令行快捷，以加快生产力。

终端和命令行快捷可以帮助你简化工作流程并最大化你的生产力。对于 Linux 和 macOS，这两者都可以追溯到 Unix，许多这些快捷将是相同的。但对于 Windows，会有一些差异。

第一个快捷键是 <kbd>上箭头</kbd> 键。按下这个键可以让你一次向后浏览一条命令历史。然后，<kbd>下箭头</kbd> 键可以用来向前浏览命令历史。这两个键让你能够快速浏览之前运行过的命令，找到需要再次运行的命令。

许多 shell 还提供自动补全功能，根据你开始输入的内容推荐命令。你可以使用 <kbd>Tab</kbd> 键来补全建议，快速将完整的语法填充到命令行中。不同的 shell 生成建议的方式会有所不同。例如，在 zsh 中，这些建议基于你最近的命令历史；而在 PowerShell 中，建议基于可用的命令、变量和参数（对最近使用的权重较低）。

有时命令会在终端产生大量输出。这些额外的信息可能会干扰你的工作流程。在基于 *nix 的 Linux 和 macOS 终端中，你可以按 <kbd>Control</kbd> + <kbd>L</kbd> 清除整个屏幕，开始一个干净的提示符。在 PowerShell 中，<kbd>Control</kbd> + <kbd>L</kbd> 也默认清屏，你还可以运行 `cls` 命令达到同样效果。

如果你需要中止命令的执行，可以使用 <kbd>Control</kbd> + <kbd>C</kbd> 来终止进程。这会结束命令并创建一个新的提示符，让你继续处理其他任务。对于 PowerShell 用户，<kbd>Control</kbd> + <kbd>C</kbd> 也用于复制文本——只有在没有选中文本时才会终止进程。

接下来的几个快捷只在基于 *nix 的终端中可用，且没有 PowerShell 备选。

有时你需要多任务处理，让一个进程或命令在后台运行，同时处理其他工作。按下 <kbd>Control</kbd> + <kbd>Z</kbd> 会将当前进程放入后台任务，并返回命令行，方便你继续工作。当你需要重新关注后台任务时，可以使用 `fg` 命令将其还原。

最后，有些命令你可能需要连续运行两次。你可以按 <kbd>上箭头</kbd> 键向后浏览到之前运行的命令，也可以在命令行输入两个感叹号（`!!`）并按 <kbd>Enter</kbd> ——这会自动运行上一次执行的命令。
