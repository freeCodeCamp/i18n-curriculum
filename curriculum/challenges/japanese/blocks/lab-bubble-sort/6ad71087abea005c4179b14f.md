# --description--

バブルソートは、リストを繰り返し順に進みながら隣接する要素を比較し、順序が逆であれば入れ替えることで動作します。各パスの後、未ソートの中で最大の値がリストの末尾に「浮かび上がる」ように移動します。入れ替えが一度も起きないまま1回のパスが完了すると、アルゴリズムは停止します。

バブルソートは平均および最悪の場合で二次の時間計算量を持つため、実際にはほとんど使われません。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

**ユーザーストーリー：**

1. アイテムのリストを表す1つのパラメータを持つ `bubble_sort` という名前の関数を定義してください。
1. `bubble_sort` 関数はリストを最小から最大の順にその場でソートし、ソート済みのリストを返してください。
1. `bubble_sort` 関数はバブルソートのアルゴリズムに従い、隣接する要素を比較して左の要素が右の要素より大きい場合のみ入れ替えを行ってください。
1. `bubble_sort` 関数は入れ替えが一度も起きないパスが完了した時点で停止してください。
1. `bubble_sort` 関数は組み込みの `sort()` メソッドや `sorted()` 関数を使わないでください。

**注意:** コード内でモジュールをインポートしないでください。

`bubble_sort` 関数はバブルソートのアルゴリズムに従い、左の要素が右の要素より大きい場合にのみ隣接要素を入れ替えてください。

```js
({
  test: () =>
    runPython(`
from collections import UserList

class CustomList(UserList):
    def __init__(self, *args, **kwargs):
        self._record = []
        super().__init__(*args, **kwargs)

    def __setitem__(self, key, value):
        self._record.append((key, value))
        super().__setitem__(key, value)

def expected_swaps(items):
    items = list(items)
    swaps = []
    swapped = True
    while swapped:
        swapped = False
        for j in range(len(items) - 1):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swaps.append({(j, items[j]), (j + 1, items[j + 1])})
                swapped = True
    return swaps

for values in ([33, 1, 89, 2, 67, 245], [4, 4, 2, 2, 1, 4, 3]):
    list_to_sort = CustomList(values)
    bubble_sort(list_to_sort)
    record = list_to_sort._record
    expected = expected_swaps(values)
    assert len(record) == 2 * len(expected)
    actual = [set(record[i:i + 2]) for i in range(0, len(record), 2)]
    assert actual == expected
    `)
});
```

```py
def bubble_sort(items):
    n = len(items)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swapped = True
        if not swapped:
            break
    return items
```
