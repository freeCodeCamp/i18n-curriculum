## Pythonのクラスとオブジェクト

- **クラス定義**: クラスはオブジェクトを作成するための設計図です。属性やメソッドを通じてオブジェクトの振る舞いを定義します。以下はPythonでの基本的なクラス定義の例です。

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **クラス名**: 慣例として、クラス名はPascalCaseを使います。各単語の最初の文字が大文字で、アンダースコアは使いません。例として `Dog` や `ShoppingCart` があります。

- **`__init__()` メソッド**: Pythonは新しいオブジェクトを作成するたびに自動的に `__init__()` を呼び出します。これはオブジェクトの初期属性を設定するために使います。

- **`self` パラメータ**: `self` はメソッドが操作している特定のオブジェクトを指します。オブジェクトのメソッドを呼び出すときにPythonが自動的に渡すので、呼び出し時には書きません。`self` は慣例的な名前ですが、インスタンスメソッドの最初のパラメータであることが常です。

- **オブジェクトの作成**: オブジェクトはクラスのインスタンスです。必要な引数を渡してクラスを呼び出すことで作成されます。

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **オブジェクトのメソッド呼び出し**: オブジェクトのメソッドを呼び出して、動作を実行したり情報を取得したりできます。

```python
object_name1.method_name()
object_name2.method_name()
```

- **クラスとオブジェクトの違い**: クラスは再利用可能なテンプレートであり、オブジェクトはそのクラスから作られた具体的なデータを持つインスタンスです。

## 属性

- **インスタンス属性**: 通常は`__init__()`内で`self`を使って定義され、各オブジェクトごとに固有です。
- **クラス属性**: クラス内で直接定義され、すべてのインスタンスで共有されます。

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **属性を動的に扱う**: 属性名が実行時にしかわからない場合があります。例えばユーザーの入力やループから来る場合です。その場合は `object.name` と書けないので、名前を文字列として受け取る関数を使います。

  - `getattr(obj, name)` は属性の値を返します。属性が存在しない場合は `AttributeError` を発生させますが、3番目の引数にデフォルト値を渡すとそれを返します。
  - `setattr(obj, name, value)` は属性を作成または更新します。
  - `hasattr(obj, name)` は属性が存在すれば `True`、なければ `False` を返します。
  - `delattr(obj, name)` は属性を削除します。

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **`dir()` で属性を調べる**: `dir()` 関数はオブジェクトの属性とメソッドの名前のリストを返します。`callable()` と組み合わせて、メソッドとデータ属性を区別できます。

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## メソッド

- **メソッド**: クラス内で定義され、オブジェクトの属性に対して操作を行う関数です。

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **メソッドのアクセス**: ドット記法を使ってオブジェクトのメソッドを呼び出します。以下は2つの異なる車のオブジェクトで`describe`メソッドを呼び出す例です。

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## ダンダー（マジック）メソッド

- **定義**: ダブルアンダースコアで始まり終わる特別なメソッド（例：`__init__`、`__len__`、`__str__`、`__eq__`）。Pythonは組み込み操作のために内部でこれらを使用します。

- **カスタム特殊メソッドなしの動作**: Pythonは組み込み操作がカスタムオブジェクトの属性をどう使うかを推測しません。利用可能な場合は継承されたデフォルトの動作を使い、サポートされていない操作には `TypeError` を発生させます。

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **カスタムメソッドが変えること**: `__len__()` は `len()` がエラーを出す代わりにページ数を返します。`__str__()` はデフォルトの表現を読みやすい要約に置き換えます。`__eq__()` は `==` が両方の名前が同じオブジェクトかどうかを調べる代わりにページ数を比較します。

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **ダンダーメソッドの間接的な呼び出し**: ダンダーメソッドを直接呼び出す必要はありません。特定の操作が起こるとPythonが自動的に呼び出します。これらの操作には以下が含まれます：

  - **加算、減算、乗算、除算などの算術演算**。加算には`__add__()`、減算には`__sub__()`、乗算には`__mul__()`、除算には`__truediv__()`が呼ばれます。
        
  - **連結、繰り返し、フォーマット、文字列変換などの文字列操作**。連結には`__add__()`、繰り返しには`__mul__()`、フォーマットには`__format__()`、文字列変換には`__str__()`と`__repr__()`が呼ばれます。
        
  - **等価性、より小さい、より大きいなどの比較操作**。等価性には`__eq__()`、より小さいには`__lt__()`、より大きいには`__gt__()`が呼ばれます。
        
  - **オブジェクトをイテラブルにしてアイテムを順に進めるようなイテレーション操作**。`__iter__()` はイテレーターを返すために呼び出され、`__next__()` は次のアイテムを取得するために呼び出されます。

## 実例：ショッピングカート

- **ダンダーメソッドを持つカートクラス**: 追加、削除、イテレーション、内容の確認を組み込みの振る舞いで可能にします。

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## オブジェクトの連携

- **オブジェクトを引数として渡す**: オブジェクトは数値や文字列と同じように他のクラスのコンストラクタに渡せます。

- **属性にオブジェクトを格納する**: あるオブジェクトの属性に別のオブジェクトを格納できます。その属性を通じてメソッドを呼び出すときは、ドット記法のチェーンで `receiver.inbox.receive_email(email)` のように書けます。

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## 日付と時刻の操作

- **現在の日付と時刻を取得する**: `datetime.datetime.now()` を呼び出すと、現在の日付と時刻を表す `datetime` オブジェクトが返されます。

- **インスタンスにタイムスタンプを保存する**: `__init__()` 内で `datetime.datetime.now()` を呼び出し、その結果を属性に代入してオブジェクトが作成された時刻を記録します。

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **`strftime()` でフォーマットする**: `strftime()` メソッドは `datetime` オブジェクトを文字列に変換します。フォーマットコードは `%Y` が4桁の年、`%m` が月、`%d` が日、`%H` が24時間制の時、`%M` が分、`%S` が秒です。`-`、`/`、`:`、空白などの他の文字は区切り文字としてそのまま使われます。

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
