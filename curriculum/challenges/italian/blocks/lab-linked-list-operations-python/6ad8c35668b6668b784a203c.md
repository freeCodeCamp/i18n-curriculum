# --description--

In questo laboratorio implementerai operazioni aggiuntive per una struttura dati lista concatenata, basandoti sulla classe `LinkedList` che hai creato nel workshop precedente.

**Obiettivo:** Completa le storie utente qui sotto e fai passare tutti i test per completare il laboratorio.

**Storie utente:**

1. La tua classe `LinkedList` dovrebbe avere un metodo `contains` che prende un elemento come argomento. Dovrebbe restituire `True` se l'elemento esiste nella lista concatenata, e `False` altrimenti.
1. La tua classe `LinkedList` dovrebbe avere un metodo `get_at` che prende un indice come argomento. Dovrebbe restituire l'elemento all'indice dato nella lista concatenata. Se l'indice è fuori dai limiti, dovrebbe restituire `None`.
1. La tua classe `LinkedList` dovrebbe avere un metodo `insert_at` che prende un indice e un elemento come argomenti. Dovrebbe inserire l'elemento nella posizione indicata nella lista concatenata e aggiornare l'attributo `length`. Un indice uguale alla lunghezza della lista è valido e dovrebbe aggiungere l'elemento alla fine. Se l'indice è fuori dai limiti, non dovrebbe modificare la lista.
1. La tua classe `LinkedList` dovrebbe avere un metodo `remove_at` che prende un indice come argomento. Dovrebbe rimuovere il nodo all'indice indicato nella lista concatenata e aggiornare l'attributo `length`. Se l'indice è fuori dai limiti, non dovrebbe modificare la lista.
1. La tua classe `LinkedList` dovrebbe avere un metodo `clear` che rimuove tutti gli elementi dalla lista concatenata, riportandola a uno stato vuoto con `head` impostato a `None` e `length` impostato a `0`.

**Nota:** Alcuni test successivi dipendono da metodi precedenti. Per esempio, se `get_at` non è implementato correttamente, i test per metodi come `insert_at` e `remove_at` potrebbero fallire anche se quei metodi sono quasi corretti.

```py
            self.head = node
```

```py
class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
```
