# --description--

Speichern Sie nun jedes Programm in `programsById`, wobei der Schlüssel die jeweilige id ist.

Das gespeicherte Programm sollte seine ursprünglichen Eigenschaften plus eine neue `departmentId`-Eigenschaft haben, die es mit seiner Abteilung verknüpft. Die Spread-Syntax (`...`) kopiert die eigenen aufzählbaren Eigenschaften eines Objekts in ein neues Objekt, in das Sie zusätzliche Eigenschaften hinzufügen können.

Beginnen Sie damit, die Zeile `console.log(program)` aus Ihrem Code zu entfernen.

Weisen Sie dann `programsById[program.id]` ein Objekt zu, das `program` spreadet und `departmentId` hinzufügt.

Protokollieren Sie zuletzt `programsById[program.id]` in der Konsole, um das gespeicherte Objekt zu überprüfen.
