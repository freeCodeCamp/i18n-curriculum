# --description--

Jetzt müssen Sie jede Temperatur mit ihrer Bezeichnung paaren.

Die `map()`-Funktion kann mehr als eine iterierbare übergeben bekommen. Bei jedem Aufruf übergibt sie der Funktion jeweils ein Element aus jeder iterierbaren, daher benötigt die Funktion einen Parameter pro iterierbarer:

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

Erstellen Sie eine Variable namens `report`. Weisen Sie ihr das Ergebnis zu, das entsteht, wenn Sie `map()` eine Lambda-Funktion, `temperatures` und `difference_labels` übergeben, eingehüllt in einen `list()`-Aufruf. Die Lambda-Funktion soll zwei Parameter annehmen, `temperature` und `difference_label`, und `f'{temperature} °C ({difference_label})'` zurückgeben.

Geben Sie dann `report` aus, anstatt `difference_labels`.
