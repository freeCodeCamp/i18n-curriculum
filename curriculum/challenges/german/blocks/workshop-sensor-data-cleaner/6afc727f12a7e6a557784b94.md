# --description--

Um eine Bezeichnung für jede Differenz zu erhalten, benötigen Sie einen bedingten Ausdruck vor `for` anstelle eines nachgestellten `if`:

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

Entfernen Sie das nachgestellte `if` aus Ihrer List Comprehension. Ändern Sie dann den Ausdruck vor `for` in einen bedingten Ausdruck, der zu `f'+{difference} °C'` auswertet, wenn `difference` größer als `0` ist, und andernfalls zu `f'{difference} °C'`. Negative Zahlen haben bereits ein `-`-Zeichen, daher benötigen sie nur die Einheit.
