# --description--

Ahora convertirás las diferencias en etiquetas de texto como `+3.6 °C`. Los números positivos se imprimen sin signo, así que necesitarás agregar un `+` delante de ellos.

Para incluir solo los elementos que cumplen una condición, puedes agregar un `if` al final de una comprensión de listas:

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

Crea una variable llamada `difference_labels`. Usa una comprensión de listas para asignarle una lista que contenga `f'+{difference} °C'` para cada `difference` en `differences`, pero solo si `difference` es mayor que `0`.

Luego, imprime `difference_labels` en lugar de `differences`.

En la terminal, verás solo 3 etiquetas para 7 temperaturas. Un `if` al final excluye los elementos que no cumplen la condición, así que no hay forma de saber a qué temperatura pertenece cada etiqueta. Arreglarás esto en el siguiente paso.
