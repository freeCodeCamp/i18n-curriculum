# --description--

في هذا المختبر، ستنظف ملفات السجلات شبه المنظمة عن طريق استبدال الأحرف غير المسموح بها بـ `#` وتتبع عدد المدخلات التي تمت معالجتها.

**الهدف:** إكمال قصص المستخدم أدناه واجتياز جميع الاختبارات لإتمام المختبر.

**قصص المستخدم:**

1. يجب استخدام إعلان دالة لإنشاء دالة باسم `sanitizeLog` بمعلمتين: `entry`، وهي سلسلة نصية تمثل مدخلاً في السجل، و`disallowedCharacters`، وهي مصفوفة من سلاسل نصية مكونة من حرف واحد تمثل الأحرف التي يجب استبدالها.
1. يجب أن تُرجع الدالة سلسلة `entry` معدلة بحيث يُستبدل كل حرف غير مسموح به بـ `#`. يجب أن يكون التطابق حساسًا لحالة الأحرف. على سبيل المثال، إذا كانت الأحرف غير المسموح بها هي `["e", "E", "o", "r"]`، فإن `DEBUG: Server started on port 3000` تُرجع `D#BUG: S##v## sta#t#d #n p##t 3000`.
1. يجب إنشاء دالة باسم `cleanLogs` بمعلمتين: `logs`، وهي مصفوفة من السلاسل النصية تمثل مدخلات السجل، و`disallowedCharacters`، وهي مصفوفة من سلاسل نصية مكونة من حرف واحد تمثل الأحرف التي يجب استبدالها.
1. يجب أن تقوم `cleanLogs` بالتكرار على مصفوفة مدخلات السجل المعطاة بالترتيب.
1. عندما تصل `cleanLogs` إلى مدخل سجل يحتوي على العلامة القاتلة `$`، يجب أن تتوقف وتُرجع `Sanitizing stopped. Failure Reason: Fatal character occurred.`
1. مدخل السجل الذي يبدأ بالحرف `/` هو مدخل معلوماتي ولا يجب تنظيفه. يجب تتبع عدد المدخلات المعلوماتية.
1. يجب تنظيف جميع مدخلات السجل الأخرى باستخدام دالة `sanitizeLog`. يجب تتبع عدد المدخلات التي تم تنظيفها.
1. إذا أنهت `cleanLogs` العمل دون مواجهة علامة قاتلة، يجب أن تُرجع `Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.`، حيث `X` هو العدد الإجمالي للمدخلات، و`Y` هو عدد المدخلات التي تم تنظيفها، و`Z` هو عدد المدخلات المعلوماتية.

**تُستخدم مصفوفات السجلات التالية في الاختبارات:**

```js
let logs_1 = [
  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"
];

let logs_2 = [
  "FATAL: System overload detected, shutting down",
  "DEBUG: token=def456$ refreshed for session",
  "ERROR: Null pointer exception in module auth"
];

let logs_3 = [
  "ERROR: Failed to connect to db, retry=3",
  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
