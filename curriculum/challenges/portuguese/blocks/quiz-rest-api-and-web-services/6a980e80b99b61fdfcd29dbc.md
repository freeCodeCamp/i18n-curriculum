#### --distractors--

---

### --question--

#### --text--

Qual é uma vantagem chave dos microserviços em relação a um monólito?

#### --distractors--

Depuração mais simples e menos chamadas de rede entre serviços.

---

Uma única base de código compartilhada para todas as equipes.

---

Gerenciamento de infraestrutura mais fácil em todos os serviços.

#### --answer--

Desenvolvimento mais rápido, melhor isolamento de falhas e a capacidade de usar diferentes linguagens por serviço.

### --question--

#### --text--

#### --distractors--

Uma base de código única e compartilhada que facilita a coordenação de mudanças.

---

São necessárias menos chamadas de rede entre os componentes.

---

A depuração se torna mais simples já que todo o código roda em um único processo.

#### --answer--

A depuração se torna mais complexa e há mais overhead de rede entre os serviços.
