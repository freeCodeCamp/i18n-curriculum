# --description--

Se a versão instalada não for a mais recente, sua função deve informar que tipo de atualização está disponível. Quando os números major forem diferentes, é uma atualização major. Isso significa que a versão mais nova contém grandes mudanças que podem não funcionar com a versão antiga.

Você pode acessar o número major de uma versão pelo índice `0`. Adicione uma declaração `if` que verifique se o número major de `installed` é menor que o número major de `latest`. Se for, crie uma variável chamada `update_type` e atribua a ela a string `major update`.
