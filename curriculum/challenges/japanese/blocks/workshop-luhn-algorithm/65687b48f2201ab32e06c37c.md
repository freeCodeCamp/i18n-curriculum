# --description--

各`digit`は文字列です。`sum_of_odd_digits`に加算する前に、組み込みの`int`関数を使って整数に変換してください。

`for`ループ内で、`print(digit)`を`sum_of_odd_digits += int(digit)`に置き換えてください。その後、ループの後に`print(sum_of_odd_digits)`を追加して合計を出力してください。
