## 演算法與大 O 符號

- **演算法**：解決問題或執行任務的一組明確指令。演算法必須在有限步驟內完成，每一步都必須精確且明確。

- **Big O 符號**：描述演算法在輸入規模增加時資源使用的漸近上界。Big O 獨立於最佳、平均或最壞情況，衡量整體的擴展趨勢，同時忽略常數因子和較小項。

### 常見時間複雜度

- **O(1) - 常數時間**：演算法執行時間不受輸入大小影響。

```python
def check_even_or_odd(number):
    if number % 2 == 0:
        return 'Even'
    else:
        return 'Odd'
```

- **O(log n) - 對數時間**：執行時間的上界最多以對數速度隨輸入規模成長。當此上界緊密時，演算法以對數時間執行。這通常發生在問題規模反覆被固定比例縮減時，例如二分搜尋。

- **O(n) - 線性時間**：執行時間的上界最多以線性速度隨輸入規模成長。當此上界緊密時，執行時間與輸入規模成正比。

```python
for grade in grades:
    print(grade)
```

- **O(n log n) - 對數線性時間**：常見於高效的分治排序。合併排序在最壞情況下為 O(n log n)。快速排序平均情況為 O(n log n)，但最壞情況為 O(n²)。

- **O(n²) - 平方時間**：執行時間的上界最多以平方速度隨輸入規模成長。當此上界緊密時，執行時間與輸入規模的平方成正比。這發生在巢狀迴圈中，每個迴圈執行 n 次。

```python
for i in range(n):
    for j in range(n):
        print("Hello, World!")
```

- **O(2ⁿ) - 指數時間**：執行時間的指數上界。當此上界緊密時，成長率與 2ⁿ 成正比，n 增加 1 時執行時間會加倍。

- **O(n!) - 階乘時間**：執行時間的階乘上界。當此上界緊密時，成長率與 n! 成正比，即 n 個不同項目的排列數。

### 空間複雜度

- **O(1) - 常數空間**：記憶體使用量被一個與輸入大小無關的常數限制。

- **O(n) - 線性空間**：記憶體使用量最多以線性速度隨輸入規模成長。當此上界緊密時，記憶體使用量與輸入規模成正比。

- **O(n²) - 平方空間**：記憶體使用量最多以平方速度隨輸入規模成長。當此上界緊密時，記憶體使用量與輸入規模的平方成正比。

- **O(2ⁿ) - 指數空間**：記憶體使用量的指數上界。當此上界緊密時，記憶體使用量與 2ⁿ 成正比。

- **O(n!) - 階乘空間**：記憶體使用量的階乘上界。當此上界緊密時，記憶體使用量與 n! 成正比。

## 問題解決技巧

- **理解問題**：多次閱讀問題描述。辨識輸入、預期輸出，以及如何將輸入轉換為輸出。

- **演算法與資料結構選擇**：比較不同演算法的時間和空間需求，並選擇適合問題的資料結構。

- **偽程式碼**：以高階且與語言無關的方式描述演算法邏輯，使用一般書寫語言混合程式設計構件如 `IF`、`ELSE`、`FOR` 和 `WHILE`。

```md
GET original_string
SET reversed_string = ""

FOR EACH character IN original_string:
    ADD character TO THE BEGINNING OF reversed_string

DISPLAY reversed_string
```

- **實作**：根據偽程式碼計畫撰寫乾淨、易讀且模組化的程式碼。使用適當的內建工具來完成常見任務。

- **邊界案例**：在演算法應處理範圍邊界出現的特定有效輸入。務必考慮並測試邊界案例。

- **測試與精進**：針對提供的範例和邊界案例測試你的程式碼。偵錯錯誤，檢查結果，並優化解法以提升清晰度或效率。

## 陣列

- **靜態陣列**：創建時大小固定，元素存放於連續記憶體中。這種相鄰配置使得索引存取快速且為常數時間（O(1)）。當最大項目數事先明確時，選擇靜態陣列。

- **動態陣列**：可在程式執行期間自動擴增或縮減。當空間不足時，會在背後重新配置更大的記憶體區塊並複製現有元素。

**注意：** Python 沒有傳統的內建靜態陣列。Python 的列表是動態陣列。

### Python 列表（動態陣列）

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### 動態陣列的時間複雜度

- **存取**：O(1)

- **尾端插入**：平均 O(1)，需要重新配置時為 O(n)

- **中間插入**：O(n)

- **刪除**：中間為 O(n)，尾端為 O(1)

## 堆疊

- **堆疊**：後進先出（LIFO）資料結構。元素只能從頂端新增和移除。

- **推入操作**：將元素加入堆疊頂端。以下 Python 列表實作中，普通推入為 O(1) 時間和 O(1) 額外空間。需要重新配置的推入可能為 O(n) 時間和 O(n) 額外空間。

- **彈出操作**：從堆疊頂端移除元素。時間複雜度通常為 O(1)，額外空間通常為 O(1)。

```python
# Using Python list as stack
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operations
top_element = stack.pop()  # Returns 3
```

## 佇列

- **佇列**：先進先出（FIFO）資料結構，元素從尾端加入，從前端移除。

- **入列操作**：將元素加入佇列尾端。時間複雜度：O(1)，空間複雜度：O(1)。

- **出列操作**：從佇列前端移除元素。時間複雜度：O(1)，空間複雜度：O(1)。

## 鏈結串列

- **鏈結串列**：線性資料結構，每個節點包含資料和指向下一節點的參考。節點像串鏈般連接。

### 單向鏈結串列

- **結構**：每個節點包含資料和一個指向下一節點的引用。

- **巡訪**：只能從頭節點向尾節點前進。

- **頭節點**：列表中的第一個節點，通常是唯一可直接存取的節點。

- **尾節點**：列表中的最後一個節點，指向 `None`。

### 鏈結串列實作

- **節點類別**：一個巢狀的 `Node` 類別代表個別節點。每個節點包含資料和指向下一節點的引用。

- **初始化**：`head` 引用起始為 `None`，因為列表沒有節點。每個新節點的 `next` 引用起始為 `None`，因為尚無後繼節點。

- **長度追蹤**：使用一個長度變數來記錄列表中節點數量。

- **`is_empty()`**：透過檢查 `head` 是否為 `None` 來判斷列表是否為空。

- **附加**：從頭節點巡訪至最後一個節點，然後更新其 `next` 引用指向新節點。若列表為空，則新節點成為頭節點。

```python
class LinkedList:
    class Node:
        def __init__(self, data):
            self.data = data
            self.next = None

    def __init__(self):
        self.head = None
        self.length = 0

    def is_empty(self):
        return self.head is None

    def append(self, data):
        new_node = self.Node(data)

        if self.is_empty():
            self.head = new_node
        else:
            current = self.head

            while current.next:
                current = current.next

            current.next = new_node

        self.length += 1
```

### 操作與時間複雜度

- **開頭插入**：O(1)

- **尾端插入**：O(n) - 必須巡訪至尾端

- **中間插入**：O(n) - 必須巡訪至指定位置

- **開頭刪除**：O(1)

- **尾端刪除**：O(n) - 必須巡訪尋找前一節點

- **中間刪除**：O(n) - 必須巡訪尋找目標節點

### 插入與刪除

- **開頭插入**：建立新節點，將其 `next` 指向目前的頭節點，然後更新頭節點指向新節點。

- **尾端插入**：巡訪至最後一個節點，更新其 `next` 指向新節點。

- **中間插入**：巡訪至目標位置前一節點。更新新節點的 `next` 指向下一節點，再更新前一節點的 `next` 指向新節點。

- **開頭刪除**：更新頭節點指向第二個節點。

- **尾端刪除**：巡訪至倒數第二個節點，將其 `next` 設為 `None`。

- **中間刪除**：尋找目標節點的前一節點，更新其 `next` 跳過目標節點。

- **依值刪除**：巡訪時追蹤前一節點。若目標為頭節點，直接更新頭節點。若未找到值，則不修改列表或長度。成功刪除後才減少長度。

### 輔助空間複雜度

- **開頭插入**：O(1) 輔助空間，不含新節點的儲存空間。

- **尾端插入**：O(1) 輔助空間，不含新節點的儲存空間。

- **中間插入**：O(1) 輔助空間，不含新節點的儲存空間。

- **開頭刪除**：O(1) 輔助空間。

- **尾端刪除**：O(1) 輔助空間。

- **中間刪除**：O(1) 輔助空間。

### 雙向鏈結串列

- **結構**：每個節點包含資料和兩個引用：下一節點與前一節點。

- **巡訪**：可雙向移動。

- **記憶體**：因為多了額外引用，比單向鏈結串列需要更多記憶體。

- **尾節點引用**：維護尾節點引用可利用前一節點引用進行反向巡訪。

## 雜湊映射與集合

### 映射與雜湊映射

- **抽象資料型別（ADT）與實作**：ADT 定義*介面*——指定資料結構支援哪些操作及其邏輯行為。具體實作定義後端機制，展示這些操作如何在記憶體中實際建構和執行。

- **映射（ADT）**：一種抽象資料型別，定義一組唯一鍵對應到值的群集。它規範映射可執行的操作，卻不限定內部儲存方式。

- **雜湊映射**：映射 ADT 的具體實作，使用雜湊函式計算底層陣列的儲存位址以加速查找。

### Python 字典（雜湊映射）

```python
# Creating dictionaries
my_dictionary = {
    "A": 1,
    "B": 2,
    "C": 3
}

# Alternative creation
my_dictionary = dict(A=1, B=2, C=3)

# Access and modify
value = my_dictionary["A"]  # 1
my_dictionary["A"] = 4      # Update value
del my_dictionary["A"]      # Remove key-value pair

# Check membership
"C" in my_dictionary

# Get keys, values, items
my_dictionary.keys()
my_dictionary.values()
my_dictionary.items()
```

### 雜湊映射的時間複雜度

- **平均情況**：插入、取得、刪除皆為 O(1)

- **最壞情況**：大量雜湊碰撞時為 O(n)

### 雜湊映射的輔助空間複雜度

- **插入**：普通插入需 O(1) 額外空間。重新配置可能需 O(n) 額外空間。

- **查找**：O(1) 輔助空間。

- **刪除**：O(1) 輔助空間。

### 集合

- **集合**：無序且元素唯一的集合。不允許重複，且不維持特定順序。

- **集合元素**：集合可包含數字、字串，以及只含數字和字串的元組。列表、字典和其他集合不可作為集合元素。即使元組本身不可變，含有列表的元組也不能作為集合元素。

```python
# Creating sets
numbers = {1, 2, 3, 4}
empty_set = set()  # Must use set(), not {}

# Add and remove elements
numbers.add(5)
numbers.remove(4)      # Raises KeyError if not found
numbers.discard(4)     # No error if not found

# Remove and return an arbitrary element
numbers.pop()

# Remove all elements
numbers.clear()

# Get the number of elements
len(numbers)
```

### 集合操作

```python
set_a = {1, 2, 3, 4}
set_b = {2, 3, 4, 5, 6}

# Union, intersection, difference, symmetric difference
set_a.union(set_b)                  # or set_a | set_b
set_a.intersection(set_b)           # or set_a & set_b
set_a.difference(set_b)             # or set_a - set_b
set_a.symmetric_difference(set_b)   # or set_a ^ set_b

# Subset and superset checks
set_a.issubset(set_b)
set_a.issuperset(set_b)
set_a.isdisjoint(set_b)

# Membership testing
5 in numbers
```

### 集合的時間複雜度

- **平均情況**：新增、移除、成員測試皆為 O(1)

- **最壞情況**：因雜湊碰撞為 O(n)

- **長度查詢**：使用 `len()` 為 O(1)。

### 集合的輔助空間複雜度

- **插入**：普通插入需 O(1) 額外空間。重新配置可能需 O(n) 額外空間。

- **查找**：O(1) 輔助空間。

- **刪除**：O(1) 輔助空間。

- **長度查詢**：O(1) 輔助空間。

## 雜湊碰撞

- **雜湊碰撞**：不同鍵可能產生相同雜湊值。在雜湊表中，碰撞也發生於不同雜湊值映射到相同陣列索引。共享索引的項目必須透過碰撞解決策略處理。

- **碰撞解決策略**：

  - **串鏈法**：每個陣列索引指向一個鏈結串列，儲存所有映射到該桶索引的項目。

  - **開放定址法**：當碰撞發生時，依預定序列尋找下一個可用陣列索引。

## 何時使用各種資料結構

- **列表**：當你需要有序且可索引存取，且事先不知道大小時使用。

- **堆疊**：用於後進先出（LIFO）操作（復原功能、運算式求值、回溯）。

- **佇列**：用於先進先出（FIFO）操作（任務排程、廣度優先搜尋）。

- **鏈結串列**：當頻繁在開頭插入/刪除、大小未知且不需要隨機存取時使用。

- **雜湊映射**：用於快速鍵值查找、計數出現次數、快取。

- **集合**：用於唯一性檢查、數學集合運算、移除重複項目。
