## 動態規劃簡介

- **定義**：動態規劃是一種演算法技巧，透過將複雜問題拆解成較簡單的子問題，並儲存結果以避免重複計算來解決問題。
- **重疊子問題**：在解決較大問題時，會多次出現相同的較小問題。我們透過儲存解決方案避免重複計算。
- **最優子結構**：問題的最優解包含其子問題的最優解。這表示我們可以透過組合較小部分的最佳解來建立整體最佳解。

## 爬樓梯問題

動態規劃的一個經典範例是計算以正整數步數 `n` 的樓梯頂端為目標，有多少種不同方式可以到達，每次可以爬 1 或 2 步：

- **天真的遞迴**：因為到達第 `n` 階的方法數是到達第 `n - 1` 階和第 `n - 2` 階方法數的總和，直接的遞迴解法會重複計算相同的子問題。例如，計算第 `5` 階時會重複計算第 `3` 階兩次和第 `2` 階三次。這導致時間複雜度呈指數級 `O(2^n)`，呼叫堆疊空間為 `O(n)`。

## 動態規劃解法

動態規劃透過兩種主要方法消除重複計算：

- **備忘錄法（自頂向下方法）**：備忘錄法將函式呼叫的結果存入快取（例如字典），當遇到相同子問題時直接回傳快取結果：

```py
def climb_stairs_memo(n, memo={}):
    """Dynamic programming with memoization"""
    # Check if we've already calculated this value
    if n in memo:
        return memo[n]  # Return cached result - O(1) lookup!
    
    # Base cases
    if n <= 2:
        return n
    
    # Calculate once and store in memo for future use
    memo[n] = climb_stairs_memo(n-1, memo) + climb_stairs_memo(n-2, memo)
    return memo[n]
```

在初始快取為空的情況下，備忘錄法將時間複雜度降低為線性 `O(n)`，並需要 `O(n)` 空間來存放快取的子問題結果以及遞迴呼叫堆疊。

- **表格法（自底向上方法）**：表格法透過反覆迭代，從最小的子問題開始建置解答直到目標，並將中間結果存入列表中，避免遞迴：

```py
def climb_stairs_tabulation(n):
    """Dynamic programming with tabulation"""
    if n <= 2:
        return n
    
    # Create array to store results for all steps from 0 to n
    dp = [0] * (n + 1)
    dp[1] = 1  # 1 way to reach step 1
    dp[2] = 2  # 2 ways to reach step 2
    
    # Build up the solution iteratively
    for i in range(3, n + 1):
        # Ways to reach step i = ways to reach (i-1) + ways to reach (i-2)
        dp[i] = dp[i-1] + dp[i-2]
    
    return dp[n]
```

表格法的時間複雜度為 `O(n)`，使用 `O(n)` 空間來存放列表，主要優點是避免遞迴呼叫堆疊的成長。

- **常數空間表格法優化**：因為每個新步驟只依賴前兩個值，完整的表格可以用兩個變數取代，分別存放最近兩個計數：

```py
def climb_stairs_optimized(n):
    if n <= 2:
        return n
    
    prev2, prev1 = 1, 2  # Only store the last two values
    for i in range(3, n + 1):
        current = prev1 + prev2
        prev2, prev1 = prev1, current
    return prev1
```

將每個算術運算視為常數時間，每個存放的計數視為一單位空間，此優化保留 `O(n)` 時間複雜度，同時將輔助空間複雜度降低到 `O(1)`。

## 實作範例：找零問題

找零問題是一個經典的優化問題，要求用最少的硬幣數量湊出目標金額：

- **演算法**：此演算法使用自底向上的表格法，建立一個大小為 `amount + 1` 的陣列 `dp`，並以無限大（`float('inf')`）初始化，代表初始時無法達成的數值。基底條件為 `dp[0] = 0`，因為要湊出金額 `0` 不需要任何硬幣。對於每個金額 `i` 從 `1` 到 `amount`，演算法會在所有符合條件的硬幣面額（`coin <= i`）中，取 `dp[i - coin] + 1` 的最小值。如果 `dp[amount]` 仍為無限大，表示無法湊出該金額，則傳回 `-1`：

```py
def min_coins(amount, coins):
    """Find minimum number of coins needed to make the given amount"""
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0  # Base case: 0 coins needed for amount 0
    
    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)
    
    return dp[amount] if dp[amount] != float('inf') else -1
```

對於面額 `[1, 3, 4]` 和目標 `6`，演算法計算出 `dp[6] = min(dp[5] + 1, dp[3] + 1, dp[2] + 1) = 2`，產生兩枚硬幣（`3 + 3`）的最佳組合。

- **複雜度**：演算法對每個子金額檢查所有面額，時間複雜度為 `O(amount * number_of_coins)`，輔助空間複雜度為 `O(amount)` 用於 DP 陣列。

## 使用動態規劃的實際應用

- **路徑最佳化**：GPS 系統使用動態規劃演算法來尋找地點之間的最短路徑。
- **文字處理**：拼字檢查和自動完成功能經常依賴動態規劃來計算單字之間的編輯距離。
- **財務建模**：投資策略和投資組合最佳化常常運用動態規劃技術。
- **資源分配**：背包問題及其變體出現在排程、預算和資源管理中。

## 何時使用動態規劃

你應該在以下情況考慮使用動態規劃：

- 問題可以拆解成重疊的子問題。
- 問題具有最佳子結構。
- 簡單的遞迴解法會涉及重複計算。
- 你需要以空間複雜度為代價來優化時間複雜度。
