# --description--

`departmentEntries` の各エントリーは `[key, value]` という形の小さな配列です。これらにインデックス（`entry[0]`、`entry[1]`）でアクセスする代わりに、配列の分割代入を使って一行で名前付き変数に展開できます。

`departmentEntries[i]` を分割代入して、`departmentName` と `departmentData` にしてください。その後、2行の別々の
`console.log()` 文を使い、1つは `departmentName` を、もう1つは `departmentData` を出力してください。

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, 'log');
const getLogs = () => globalThis.spy.calls.map((call) => call?.[0]);
```

# --after-each--

```js
globalThis.spy.restore();
delete globalThis.spy;
```
