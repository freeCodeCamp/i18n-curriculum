# --description--

O bubble sort funciona passando repetidamente por uma lista, comparando elementos adjacentes e trocando-os se estiverem fora de ordem. Após cada passagem, o maior valor não ordenado "sobe" para o final da lista. O algoritmo para quando uma passagem completa é feita sem nenhuma troca.

O bubble sort tem complexidade de tempo quadrática nos casos médio e pior, por isso raramente é usado na prática.

**Objetivo:** Cumprir as user stories abaixo e fazer todos os testes passarem para completar o laboratório.

**Histórias de Usuário:**

1. Você deve definir uma função chamada `bubble_sort` com um parâmetro que representa a lista de itens.
1. Sua função `bubble_sort` deve ordenar a lista no lugar do menor para o maior e retorná-la.
1. Sua função `bubble_sort` deve seguir o algoritmo bubble sort, comparando elementos adjacentes e trocando-os somente quando o elemento da esquerda for maior que o da direita.
1. Sua função `bubble_sort` deve parar assim que uma passagem pela lista for concluída sem nenhuma troca.
1. Sua função `bubble_sort` não deve usar nem o método embutido `sort()` nem a função `sorted()`.

**Nota:** Você não deve importar nenhum módulo no seu código.

Sua função `bubble_sort` deve seguir o algoritmo bubble sort, trocando elementos adjacentes somente quando o elemento da esquerda for maior que o da direita.

```js
({
  test: () =>
    runPython(`
from collections import UserList

class CustomList(UserList):
    def __init__(self, *args, **kwargs):
        self._record = []
        super().__init__(*args, **kwargs)

    def __setitem__(self, key, value):
        self._record.append((key, value))
        super().__setitem__(key, value)

def expected_swaps(items):
    items = list(items)
    swaps = []
    swapped = True
    while swapped:
        swapped = False
        for j in range(len(items) - 1):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swaps.append({(j, items[j]), (j + 1, items[j + 1])})
                swapped = True
    return swaps

for values in ([33, 1, 89, 2, 67, 245], [4, 4, 2, 2, 1, 4, 3]):
    list_to_sort = CustomList(values)
    bubble_sort(list_to_sort)
    record = list_to_sort._record
    expected = expected_swaps(values)
    assert len(record) == 2 * len(expected)
    actual = [set(record[i:i + 2]) for i in range(0, len(record), 2)]
    assert actual == expected
    `)
});
```

```py
def bubble_sort(items):
    n = len(items)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swapped = True
        if not swapped:
            break
    return items
```
