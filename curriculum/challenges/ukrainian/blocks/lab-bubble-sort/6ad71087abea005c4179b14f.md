# --description--

Сортування бульбашкою працює шляхом багаторазового проходження списком, порівняння сусідніх елементів і обміну їх місцями, якщо вони розташовані не за порядком. Після кожного проходу найбільше не відсортоване значення «спливає» до кінця списку. Алгоритм зупиняється, коли повний прохід завершується без жодних обмінів.

Сортування бульбашкою має квадратичну часову складність у середньому та гіршому випадках, тому його рідко використовують на практиці.

**Мета:** Виконайте наведені нижче історії користувача та пройдіть усі тести, щоб завершити лабораторну роботу.

**Історія користувача:**

1. Ви повинні визначити функцію з назвою `bubble_sort` з одним параметром, який представляє список елементів.
1. Ваша функція `bubble_sort` повинна сортувати список на місці від найменшого до найбільшого і повертати його.
1. Ваша функція `bubble_sort` повинна слідувати алгоритму сортування бульбашкою, порівнюючи сусідні елементи і обмінюючи їх місцями лише тоді, коли лівий елемент більший за правий.
1. Ваша функція `bubble_sort` повинна зупинятися, як тільки прохід списком завершується без жодних обмінів.
1. Ваша функція `bubble_sort` не повинна використовувати вбудований метод `sort()` або функцію `sorted()`.

**Примітка:** Ви не повинні імпортувати жодних модулів у свій код.

```py
def bubble_sort(items):
    n = len(items)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swapped = True
        if not swapped:
            break
    return items
```
