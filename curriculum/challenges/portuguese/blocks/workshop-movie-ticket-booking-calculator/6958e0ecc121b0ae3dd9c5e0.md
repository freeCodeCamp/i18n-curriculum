# --description--

Você também deve lidar com o caso em que o usuário não se qualifica para um desconto de associação.

Adicione uma cláusula `else` à sua declaração `if` e imprima `User does not qualify for membership discount` dentro do corpo do `else`.

Você também quer mostrar o valor atualizado de `discount`. Como é uma quantia em dinheiro, deve ser exibido com duas casas decimais.

Como você aprendeu em uma lição anterior, pode fazer isso com a especificação de formato `.2f` dentro de uma f-string. Funciona com inteiros também, então um valor como `3` é exibido como `3.00`.

Abaixo da declaração `if...else`, use uma f-string para imprimir `Discount:` seguido de um espaço e `discount` formatado com duas casas decimais. Depois, verifique a saída no terminal.
