## 安装代码编辑器或集成开发环境

在上一课中，你学习了如何在本地设备上安装 Python。在本课中，你将学习如何在本地运行 Python 代码。

在你开始本地创建 Python 脚本之前，你需要安装一个代码编辑器或集成开发环境（IDE）。IDE 代表集成开发环境。IDE 集成了代码编辑器、测试工具和终端等特色。

许多开发者常用的一个流行代码编辑器是 VS Code。访问 `https://code.visualstudio.com/download` 下载支持 macOS、Windows 和 Linux 的 VS Code。这就是本课将使用的编辑器。

其他常见的 Python 开发选择包括：

- PyCharm
- Spyder

## 创建 Python 文件

安装 VS Code 后，打开它并选择 `File`，然后选择 `Open Folder`。选择或创建一个用于你的项目的文件夹。为了课外额外练习，你可以创建一个名为 `python-projects` 的文件夹。

在 VS Code 左侧边栏打开资源管理器。选择 `New File` 图标，它看起来像一张带加号的纸。创建一个名为 `main.py` 的文件，然后按 <kbd>Enter</kbd>。`.py` 扩展名表明这是一个 Python 文件。

打开你的 `main.py` 文件并输入以下代码：

```py
print("Hello, world!")
```

## 安装 Python 扩展（程序、功能）

要安装微软官方的 Python 扩展，请按照以下具体步骤操作：

### 方法 A：在应用内安装

1. 点击左侧活动栏上由四个积木组成的图标，打开扩展视图。或者，按 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>（Windows / Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>（macOS）。
1. 在顶部搜索栏输入 `Python`。
1. 找到名为 Python 的首个结果，确保其发布者是 Microsoft。
1. 点击蓝色的 <kbd>Install</kbd> 按钮。

### 方法 B：终端 / 命令行安装

如果你更喜欢通过终端安装扩展，首先确保 `code` 命令可用。在 macOS 上，打开命令面板，运行 `Shell Command: Install 'code' command in PATH`，然后重启终端。

然后运行以下命令安装 Python 扩展：

```bash
code --install-extension ms-python.python
```

## 选择 Python 解释器

该扩展作为桥梁，但不包含实际的 Python 语言文件。如果你还没有安装 Python 解释器，必须单独从官方 Python 网站安装。

Python 安装到你的操作系统后，将其绑定到你的编辑器：

1. 在 VS Code 中，打开任意文件夹或以 `.py` 结尾的文件。
1. 使用 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（Windows / Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（macOS）打开命令面板。
1. 输入并选择 `Python: Select Interpreter`。
1. 从你的机器列表中选择已安装的 Python 3 版本。它现在会原生显示在你的工作区状态栏中。

## 运行你的 Python 脚本

运行这段代码有几种选择。第一种是点击位于右上角的运行按钮，它看起来像一个播放按钮。这样会打开终端并在那里运行你的 Python 脚本。你应该能看到文本 `Hello, world!`

另一个选项是打开终端并手动运行程序，使用：

```bash
python main.py
```

你必须从保存 `main.py` 的文件夹中运行此命令。例如，如果 `main.py` 在名为 `python-projects` 的文件夹内，先在终端中使用以下命令：

```bash
cd python-projects
```

然后运行：

```bash
python main.py
```

## 使用 `python3` 替代 `python`

在某些环境中，尤其是在同时安装了 Python 2 和 Python 3 的 macOS 和 Linux 系统上，你可能需要使用 `python3` 代替 `python`。当 `python` 命令不存在或指向旧版本的 Python 时，这种情况很常见。

```bash
python3 main.py
```
