## Was ist ein Tuple?

Ein Tuple ist ein Python-Datentyp, der verwendet wird, um eine geordnete Folge von Werten zu erstellen. Tuples können eine gemischte Menge von Datentypen enthalten, wie hier:

```py
developer = ('Alice', 34, 'Rust Developer')
```

Die Kommas erzeugen das Tuple, daher sind runde Klammern bei einer Zuweisung wie dieser optional:

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

Um ein Tuple mit einem Element zu erstellen, benötigen Sie ein nachgestelltes Komma:

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

Ein leeres Tuple wird als `()` geschrieben.

Tuples sind Listen ähnlich, aber während Listen ein veränderbarer Datentyp sind, sind Tuples unveränderlich. Das bedeutet, dass die Elemente in einem Tuple nicht geändert werden können, sobald es erstellt wurde.

Wenn Sie versuchen, eines der Elemente im Tuple zu aktualisieren, erhalten Sie einen `TypeError`:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## Auf Tuple-Elemente zugreifen

Um auf ein Element eines Tuples zuzugreifen, können Sie die Klammernotation und die Indexnummer verwenden:

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

Wenn Sie Elemente vom Ende eines Tuples aus zugreifen müssen, können Sie negative Indizes verwenden. Hier ist ein Beispiel, wie Sie mit einem negativen Index auf das vorletzte Element eines Tuples zugreifen:

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

Wenn Sie versuchen, eine Indexnummer zu verwenden, die größer oder gleich der Länge des Tuples ist, erhalten Sie eine `IndexError` wie diese:

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## Verwendung des `tuple()` Konstruktors

Eine andere Möglichkeit, ein Tuple zu erstellen, ist die Verwendung des `tuple()`-Konstruktors, so:

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

Für den `tuple()` Konstruktor können Sie verschiedene iterierbare Objekte wie Strings, Listen und sogar andere Tuples übergeben.

## Überprüfen, ob ein Element in einem Tuple ist

Um zu überprüfen, ob ein Element in einem Tuple enthalten ist, können Sie das Schlüsselwort `in` verwenden, so:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## Werte aus einem Tuple entpacken

Sie können Elemente aus einem Tuple auch entpacken, genau wie Sie es bei Listen gemacht haben:

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

In diesem Beispiel hat `name` den Wert `'Alice'`, `age` hat den Wert `34` und `job` hat den Wert `'Rust Developer'`.

Wenn Sie alle verbleibenden Elemente aus einem Tuple sammeln müssen, können Sie den Stern-Operator (`*`) verwenden, so:

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

Hier hat `name` den Wert `'Alice'`, und `rest` ist eine Liste, die aus der Zahl `34` und dem String `'Rust Developer'` besteht.

## Verwendung von Tuples bei gleichzeitiger Zuweisung

Sie können ein Tuple auf der rechten Seite einer Zuweisung erstellen und es in die Variablen auf der linken Seite entpacken:

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

Python wertet alle Ausdrücke auf der rechten Seite aus, bevor es deren Werte den Variablen auf der linken Seite zuweist. So können Sie zwei Werte tauschen, ohne eine temporäre Variable zu verwenden:

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## Ein Tuple aus einer Funktion zurückgeben

Eine Funktion kann ein Tuple zurückgeben, indem sie durch Kommas getrennte Werte nach `return` angibt:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

Die durch Kommas getrennten Werte erzeugen ein Tuple, das die Funktion zurückgibt. Hier ist `return first, second` äquivalent zu `return (first, second)`. Die runden Klammern sind optional.

Sie können das zurückgegebene Tuple direkt in Variablen entpacken:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## Tuples ausschneiden

Genau wie bei einer Liste können Sie den Slice-Operator auf ein Tuple anwenden, um einen Teil davon zu extrahieren. Hier ist ein Beispiel, wie die Elemente `'pie'` und `'cookies'` in ein separates Tuple extrahiert werden:

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

Denken Sie daran, dass die erste Zahl den Startindex für die Extraktion darstellt, während die zweite Zahl den Endindex angibt. Beachten Sie aber, dass das Element am Endindex nicht im extrahierten Tuple enthalten ist.

## Tuples vergleichen

Python vergleicht Tuples lexikographisch. Das bedeutet, es vergleicht die entsprechenden Elemente von links nach rechts. Das erste ungleiche Paar bestimmt das Ergebnis:

```py
print((1, 9) < (2, 0)) # True
```

Hier ist `1` kleiner als `2`, daher ist das erste Tuple kleiner. Python muss `9` und `0` nicht vergleichen.

Wenn die ersten Elemente gleich sind, geht Python zum nächsten Paar über:

```py
print((1, 3) < (1, 5)) # True
```

Beide Tuples beginnen mit `1`, also vergleicht Python `3` mit `5`, um das Ergebnis zu bestimmen.

Wenn alle entsprechenden Elemente gleich sind, ist das kürzere Tuple kleiner. Tuples mit gleicher Länge und gleichen entsprechenden Elementen sind gleich:

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

Die Werte im ersten ungleichen Paar müssen die Ordnungsvergleiche unterstützen. Andernfalls wirft Python einen `TypeError`:

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

Hier sind die ersten Elemente gleich, aber Python kann die Ganzzahl `3` und den String `'five'` nicht ordnen.

Spätere Elemente müssen nicht vergleichbar sein, wenn ein früheres Paar bereits das Ergebnis bestimmt:

```py
print((1, 3) < (2, 'five')) # True
```

## Elemente aus einem Tuple entfernen

Wenn Sie ein Element aus einem Tuple entfernen müssen, ist das nicht möglich, da Tuples unveränderlich sind. Dieses Beispiel führt also zu einem Fehler:

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## Wahl zwischen Tuples und Listen

Wann sollten Sie also ein Tuple einer Liste vorziehen?

Wenn Sie eine dynamische Sammlung von Elementen benötigen, bei der Sie Elemente hinzufügen, entfernen und aktualisieren können, sollten Sie eine Liste verwenden. Wenn Sie wissen, dass Sie mit einer festen und unveränderlichen Datensammlung arbeiten, sollten Sie ein Tuple verwenden.
