# --description--

正規表現（regex）とは、テキスト内の文字のシーケンスにマッチさせるためのパターンです。

すでに`in`演算子を使って文字列に正確な部分文字列が含まれているかを確認したことがあります。しかし、探している正確なテキストはわからず、その形だけがわかっている場合もあります。例えば、文字列がいくつかの文字で始まり、その後に数字が続くかどうか、あるいはユーザー名が許可された文字だけで構成されているかを確認したい場合です。

正規表現を使うと、このようなパターンを記述して文字列がそれにマッチするかどうかをチェックできます。入力の検証、テキストの検索、文字列から情報の抽出に一般的に使われます。

Pythonで正規表現を使うには、標準ライブラリの一部である`re`モジュールをインポートする必要があります。

```python
import re
```

最も単純な正規表現パターンはリテラルパターンです。これは、書かれた通りに正確に現れる必要がある文字のシーケンスです。例えば、パターン`'cat'`は文字`c`、`a`、`t`が順に並んでいるものにマッチします。

文字列の中でパターンを探すには、`re`モジュールの`search`関数を使います。これは最初の引数にパターンを、2番目の引数に検索対象の文字列を取ります。

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

`re.search`が文字列のどこかでパターンを見つけると、マッチオブジェクトを返します。出力されたマッチオブジェクトは2つのことを教えてくれます。

- `match='cat'`はパターンにマッチしたテキストです。

- `span=(4, 7)`は文字列内のマッチの位置です。マッチはインデックス`4`から始まり、インデックス`7`の直前で終わります。

この情報はマッチオブジェクトの`group`メソッドと`span`メソッドからも取得できます。

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

パターンが見つからない場合、`re.search`は`None`を返します。

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

デフォルトでは、正規表現のマッチングは大文字小文字を区別します。つまり、パターン`'Cat'`は文字列`cat`にはマッチしません。

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

パターンのマッチ方法を変えたい場合、`re.search`の3番目の引数にフラグを渡せます。`re.IGNORECASE`フラグを使うと検索が大文字小文字を区別しなくなり、大文字と小文字が同じものとして扱われます。

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
