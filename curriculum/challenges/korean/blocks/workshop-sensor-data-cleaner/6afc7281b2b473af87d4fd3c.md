# --description--

이제 각 온도를 해당 레이블과 짝지어야 합니다.

`map()` 함수는 여러 개의 반복 가능한 객체를 받을 수 있습니다. 호출할 때마다 각 반복 가능한 객체에서 하나씩 항목을 함수에 전달하므로, 함수는 반복 가능한 객체마다 하나의 매개변수를 가져야 합니다:

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

`report`라는 변수를 만드세요. `map()`에 람다 함수, `temperatures`, `difference_labels`를 전달한 결과를 `list()`로 감싸서 할당하세요. 람다 함수는 두 개의 매개변수 `temperature`와 `difference_label`을 받고, `f'{temperature} °C ({difference_label})'`를 반환해야 합니다.

그런 다음 `difference_labels` 대신 `report`를 출력하세요.
