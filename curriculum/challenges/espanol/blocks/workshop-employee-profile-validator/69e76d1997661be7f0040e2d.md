# --description--

El método `.split(separator)` divide una cadena en una lista de subcadenas en cada aparición de `separator`. Por ejemplo:

```py
fruits = 'apple, banana, cherry'
parts = fruits.split(', ')
print(parts)  # Output: ['apple', 'banana', 'cherry']
```

Crea una variable `full_address` y asígnale la cadena `123 Main Street, Springfield, IL`. Luego crea `address_parts` dividiendo por una coma seguida de un espacio.

Luego imprime `address_parts` para que la salida sea `Address parts: ['123 Main Street', 'Springfield', 'IL']`.
