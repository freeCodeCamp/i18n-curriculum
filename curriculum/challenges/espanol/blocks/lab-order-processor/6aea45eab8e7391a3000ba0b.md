# --description--

En este laboratorio, procesarás pedidos de comercio electrónico y manejarás los errores que surjan en el camino.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

Los datos con los que trabajarás tienen la misma estructura que las variables en el código inicial:

- Un **pedido** es un diccionario con:
  - `order_id`: un entero que identifica el pedido.
  - `products`: una lista de diccionarios, cada uno con un `product_id` y la `quantity` solicitada.
  - `discount_code`: una cadena, o `None` si el pedido no tiene código de descuento.
  - `status`: una cadena que describe el estado del pedido.
- Un **historial de pedidos** es una lista de pedidos.
- Un **inventario** es un diccionario cuyas claves son IDs de productos y cuyos valores son diccionarios con el nombre del `product`, la `quantity` en stock y el `price` de una unidad.
- Los **códigos de descuento** son un diccionario cuyas claves son los códigos y cuyos valores son las tasas de descuento, por ejemplo `0.1` para un 10% de descuento.

**Historias de usuario:**

1. Debes tener una función llamada `find_order` con dos parámetros: un ID de pedido y un historial de pedidos, en ese orden.
1. `find_order` debe:
   - devolver el pedido del historial dado cuyo `order_id` sea igual al ID de pedido dado.
   - lanzar un `ValueError` con el mensaje `Order ID {order_id} not found in order history.` si ningún pedido coincide con el ID dado.
1. Debes tener una función llamada `verify_availability` con dos parámetros: un pedido y un inventario, en ese orden.
1. `verify_availability` debe:
   - lanzar un `ValueError` con el mensaje `Product ID {product_id} is not in the inventory.` si un producto del pedido no está en el inventario dado.
   - lanzar un `ValueError` con el mensaje `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.` si la cantidad solicitada de un producto es mayor que la cantidad disponible en el inventario dado.
   - no lanzar ningún error si todos los productos del pedido están disponibles en la cantidad solicitada.
1. Debes tener una función llamada `get_discount_rate` con dos parámetros: un pedido y los códigos de descuento, en ese orden.
1. `get_discount_rate` debe:
   - devolver `0.0` si el `discount_code` del pedido es `None`.
   - lanzar un `ValueError` con el mensaje `Invalid discount code: {discount_code}.` si el `discount_code` del pedido no está entre los códigos de descuento dados.
   - devolver la tasa del `discount_code` del pedido en caso contrario.
1. Debes tener una función llamada `process_order` con cuatro parámetros: el ID del pedido a procesar, un historial de pedidos, un inventario y los códigos de descuento, en ese orden.
1. `process_order` debe usar `find_order`, `verify_availability` y `get_discount_rate` para procesar el pedido, y manejar el `ValueError` que lancen para que llamar a `process_order` nunca lance un error.
1. Cuando ningún pedido en el historial dado coincida con el ID dado, `process_order` debe:
   - imprimir `Error processing order {order_id}: {error message}`, donde `{error message}` es el mensaje del `ValueError` lanzado por `find_order`, y no imprimir nada más.
   - dejar el inventario y los códigos de descuento dados sin cambios.
1. Cuando el pedido existe pero no puede cumplirse, porque falta un producto en el inventario, porque la cantidad solicitada no está disponible o porque el código de descuento es inválido, `process_order` debe:
   - imprimir `Error processing order {order_id}: {error message}`, donde `{error message}` es el mensaje del `ValueError` lanzado por `verify_availability` o `get_discount_rate`.
   - establecer el `status` del pedido a `failed`.
   - dejar el inventario y los códigos de descuento dados sin cambios.
   - imprimir `Order {order_id} processing completed. Current status: failed`.
1. Cuando el pedido puede cumplirse, `process_order` debe:
   - imprimir `Order {order_id} total: ${total}`, con el descuento aplicado y el total redondeado a dos decimales.
   - establecer el `status` del pedido a `processed`.
   - restar las cantidades pedidas del inventario dado.
   - eliminar el código de descuento que usó el pedido de los códigos dados, para que cada código solo pueda usarse una vez.
   - imprimir `Order {order_id} processing completed. Current status: processed`.

**Nota:** Se te ha proporcionado un inventario, un historial de pedidos y códigos de descuento que puedes usar para probar tu código. Llama a tus funciones para probarlas, incluyendo los casos que generan errores, pero comenta esas llamadas antes de ejecutar las pruebas, o podrían interferir con ellas.

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id, order_history, inventory, discount_codes):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
