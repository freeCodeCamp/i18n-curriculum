# --description--

O desempacotamento permite atribuir os itens de uma lista a várias variáveis em uma única linha. Você pode usar uma variável com asterisco para coletar os itens restantes em uma lista:

```py
fruits = ['apple', 'banana', 'cherry']
first, *rest = fruits
print(first) # apple
print(rest) # ['banana', 'cherry']
```

Desempacote `pieces` em três variáveis: `opening` para o primeiro item, `middle` para todos os itens do meio e `closing` para o último item. Depois, imprima `opening`, `middle` e `closing` em três chamadas separadas de `print()`.
