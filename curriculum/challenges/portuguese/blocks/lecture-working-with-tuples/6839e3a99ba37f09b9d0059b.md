# --description--

## O que é uma tupla?

Uma tupla é um tipo de dado Python usado para criar uma sequência ordenada de valores. Tuplas podem conter um conjunto misto de tipos de dados assim:

```py
developer = ('Alice', 34, 'Rust Developer')
```

As vírgulas criam a tupla, então os parênteses são opcionais em uma atribuição assim:

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

Para criar uma tupla com um elemento, você precisa de uma vírgula no final:

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

Uma tupla vazia é escrita como `()`.

Tuplas são semelhantes a listas, mas enquanto listas são um tipo de dado mutável, tuplas são imutáveis. Isso significa que, uma vez criada uma tupla, suas referências de elementos não podem ser substituídas, adicionadas ou removidas.

Se você tentar atualizar um dos itens na tupla, você receberá um `TypeError`:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## Objetos mutáveis dentro de tuplas

Uma tupla pode conter um objeto mutável, como uma lista. A imutabilidade da tupla não impede mudanças nesse objeto contido:

```py
def add_greeting(values):
    values[0].append('hi')

greetings = (['hello'],)
original_list = greetings[0]

add_greeting(greetings)
print(greetings) # (['hello', 'hi'],)
print(greetings[0] is original_list) # True
```

A função modifica a lista dentro da tupla. A tupla ainda mantém uma referência para a mesma lista. Atribuir uma lista diferente a `greetings[0]` geraria um `TypeError`, porque isso substituiria a referência do elemento da tupla.

## Acessando elementos de uma tupla

Para acessar um elemento de uma tupla, você pode usar a notação de colchetes e o número do índice:

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

Se você precisar acessar elementos começando do final de uma tupla, então você pode usar indexação negativa. Aqui está um exemplo de uso de um índice negativo para acessar o penúltimo elemento em uma tupla:

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

Se você tentar passar um número de índice que excede ou é igual ao comprimento da tupla, então você receberá um `IndexError` assim:

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## Usando o construtor `tuple()`

Outra forma de criar uma tupla é usando o construtor `tuple()` assim:

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

Para o construtor `tuple()`, você pode passar diferentes iteráveis como strings, listas e até outras tuplas.

## Verificando se um elemento está em uma tupla

Para verificar se um item está em uma tupla, você pode usar a palavra-chave `in` assim:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## Desempacotando valores de uma tupla

Você também pode desempacotar itens de uma tupla assim como fez com listas:

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

Neste exemplo, `name` tem o valor `'Alice'`, `age` tem o valor `34` e `job` tem o valor `'Rust Developer'`.

Se você precisar coletar quaisquer elementos restantes de uma tupla, pode usar o operador asterisco (`*`) assim:

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

Aqui, `name` tem o valor `'Alice'` e `rest` é uma lista composta pelo número `34` e a string `'Rust Developer'`.

## Usando tuplas em atribuição simultânea

Você pode criar uma tupla no lado direito de uma atribuição e desempacotá-la nas variáveis do lado esquerdo:

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

Python avalia todas as expressões do lado direito antes de atribuir seus valores às variáveis do lado esquerdo. Isso permite trocar dois valores sem uma variável temporária:

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## Retornando uma tupla de uma função

Uma função pode retornar uma tupla colocando valores separados por vírgulas após o `return`:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

Os valores separados por vírgulas criam uma tupla, que a função retorna. Aqui, `return first, second` é equivalente a `return (first, second)`. Os parênteses são opcionais.

Você pode desempacotar a tupla retornada diretamente em variáveis:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## Fatiando tuplas

Assim como em uma lista, você pode usar o operador slice em uma tupla para extrair uma parte dela. Aqui está um exemplo de extração dos itens `'pie'` e `'cookies'` para uma tupla separada:

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

Lembre-se de que o primeiro número representa o índice inicial para a extração enquanto o segundo número representa o índice final. Mas note que o item no índice final não está incluído na tupla extraída.

## Comparando tuplas

Python compara tuplas lexicograficamente. Isso significa que compara elementos correspondentes da esquerda para a direita. O primeiro par desigual determina o resultado:

```py
print((1, 9) < (2, 0)) # True
```

Aqui, `1` é menor que `2`, então a primeira tupla é menor. Python não precisa comparar `9` e `0`.

Se os primeiros elementos forem iguais, Python passa para o próximo par:

```py
print((1, 3) < (1, 5)) # True
```

Ambas as tuplas começam com `1`, então Python compara `3` com `5` para determinar o resultado.

Se todos os elementos correspondentes forem iguais, a tupla mais curta é menor. Tuplas com o mesmo comprimento e elementos correspondentes iguais são iguais:

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

Os valores no primeiro par desigual devem suportar a comparação de ordenação. Caso contrário, Python gera um `TypeError`:

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

Aqui, os primeiros elementos são iguais, mas Python não pode ordenar o inteiro `3` e a string `'five'`.

Elementos posteriores não precisam ser comparáveis se um par anterior já determinar o resultado:

```py
print((1, 3) < (2, 'five')) # True
```

## Removendo elementos de uma tupla

Se você precisar remover um item de uma tupla, isso não é possível porque tuplas são imutáveis. Então este exemplo vai gerar um erro:

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## Escolhendo entre tuplas e listas

Então, quando você pode usar uma tupla em vez de uma lista?

Se você precisa de uma coleção dinâmica de elementos onde pode adicionar, remover e atualizar elementos, deve usar uma lista. Se precisa de uma sequência cujas referências de elementos permaneçam fixas, pode usar uma tupla. Lembre-se que quaisquer objetos mutáveis que ela contenha ainda podem mudar.
