## O que é Express.js?

- **Express**: Um framework web minimalista e flexível construído sobre Node.js que facilita criar servidores web e APIs.
- **Instalar Express**: `npm install express`
- **O que você pode construir com Express**: apps web, APIs RESTful, backends para SPA, serviços com muito middleware e qualquer coisa server-side com HTTP.
- **Middleware**: Código que roda entre receber uma requisição e enviar uma resposta. Usado para tratamento de erros, validação de entrada, modificar dados da requisição ou resposta e mais. Várias funções middleware podem ser encadeadas.
- **Plugins**: Módulos npm externos que estendem o Express, geralmente implementados como middleware.

## Criando um app básico com Express

```javascript
const express = require("express");
const app = express();
const port = 3000;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

- `require("express")` — carrega a biblioteca Express.
- `express()` — função fábrica que cria e retorna uma nova instância de aplicação Express.
- `app` — o objeto principal do servidor com acesso a métodos como `.get()`, `.post()` e `.listen()`.
- `port` — o endpoint de rede onde o app escuta. A porta `3000` é comum para desenvolvimento local.
- `app.listen(port, callback)` — inicia o servidor e começa a escutar requisições HTTP.

## Roteamento no Express

- **Rota**: Uma regra que diz ao app como responder quando um cliente requisita uma URL específica com um método HTTP específico.
- **Métodos de rota**: `app.get()`, `app.post()`, `app.put()`, `app.delete()` — cada um trata requisições com o método HTTP correspondente.
- **Caminho de rota estático**: Uma URL fixa como `/home` ou `/menu/drinks`.
- **Caminho de rota dinâmico (parâmetro de rota)**: Um marcador de posição na URL que captura um valor, prefixado com `:`, por exemplo `/post/:postId`.
- **`req.params`**: Um objeto contendo os valores dinâmicos capturados da URL. Por exemplo, uma requisição para `/post/42` retorna `req.params.postId === "42"`.

### Manipuladores de rota

- Um **manipulador de rota** é a função de callback `(req, res) => { ... }` que roda quando uma requisição corresponde a uma rota.
- `req` — contém informações sobre a requisição recebida (params, query strings, cabeçalhos, corpo).
- `res` — usado para enviar uma resposta de volta ao cliente.

## Métodos de resposta

| Método | O que faz |
| --- | --- |
| `res.send()` | Envia uma resposta — texto simples, HTML, JSON ou dados binários. |
| `res.json()` | Envia uma resposta JSON; converte automaticamente um objeto JavaScript. |
| `res.status(code)` | Define o código de status HTTP; geralmente encadeado com `res.send()` ou `res.json()`. |
| `res.redirect(url)` | Redireciona o cliente para uma URL diferente. |
| `res.render(view, data)` | Renderiza uma view de template engine e envia o HTML resultante. |

## Manipuladores de rota encadeáveis com `app.route()`

- `app.route(path)` agrupa múltiplos manipuladores de métodos HTTP para o mesmo caminho para evitar repetições.

```javascript
app
  .route("/user")
  .get((req, res) => { res.send("Fetching user data"); })
  .post((req, res) => { res.send("Creating a user"); })
  .put((req, res) => { res.send("Updating the user"); })
  .delete((req, res) => { res.send("Deleting the user"); });
```

## Roteamento modular com `express.Router()`

- `express.Router()` cria um objeto roteador — como um mini app Express — onde você pode definir rotas e depois montar no app principal.
- Monte um roteador com `app.use(path, router)`. As rotas dentro do roteador são relativas ao caminho de montagem.
- **Benefícios**: separa responsabilidades, mantém o arquivo principal limpo e torna as rotas reutilizáveis e mais fáceis de escalar.

```javascript
// userRoutes.js
const express = require("express");
const router = express.Router();
router.get("/", (req, res) => { res.send("List of users"); });
router.get("/:id", (req, res) => { res.send(`User ${req.params.id}`); });
module.exports = router;

// app.js
app.use("/users", userRoutes); // mounts the router at /users
```

## Servindo arquivos estáticos

- **Arquivos estáticos**: Assets como imagens, CSS e JavaScript do lado cliente que são servidos diretamente sem processamento no servidor.
- `express.static(directory)` — middleware embutido que serve arquivos de uma pasta especificada.
- Se um arquivo solicitado não for encontrado, o Express responde automaticamente com 404.
- Não são necessárias definições de rota para arquivos estáticos individuais.

```javascript
app.use(express.static(path.join(__dirname, "public")));
```

- Você pode servir de múltiplos diretórios chamando `app.use()` várias vezes, opcionalmente com um caminho de montagem:

```javascript
app.use(express.static(path.join(__dirname, "public")));
app.use("/images", express.static(path.join(__dirname, "images")));
```
