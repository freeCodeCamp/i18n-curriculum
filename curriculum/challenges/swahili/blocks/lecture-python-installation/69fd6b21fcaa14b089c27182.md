## Kusakinisha Mhariri wa Msimbo au IDE

Katika funzo lililopita, ulijifunza jinsi ya kusakinisha Python kwenye kifaa chako cha karibu. Katika funzo hili, utajifunza jinsi ya kuendesha msimbo wa Python kwa karibu.

Kabla hujaanza kujenga misimbo yako ya Python kwa ndani, utahitaji kusakinisha mhariri wa msimbo au IDE. IDE inasimama kwa mazingira ya ukuzaji yaliyojumuishwa. IDE huunganisha vipengele kama mhariri wa msimbo, zana za majaribio, na terminali.

Mhariri maarufu wa msimbo ambao wasanidi programu wengi hutumia ni VS Code. Tembelea `https://code.visualstudio.com/download` kupakua VS Code, ambayo inaunga mkono macOS, Windows, na Linux. Huu ndio mhariri utakaotumika katika funzo hili.

Chaguzi nyingine za kawaida kwa ukuzaji wa Python ni pamoja na:

- PyCharm
- Spyder

## Kuunda Faili la Python

Baada ya kusakinisha VS Code, fungua na chagua `File`, kisha `Open Folder`. Chagua au tengeneza folda kwa ajili ya mradi wako. Kwa mazoezi ya ziada nje ya funzo, unaweza kutaka folda iitwayo `python-projects`.

Fungua Explorer kwenye upau wa kushoto wa VS Code. Chagua ikoni ya `New File`, inayofanana na kipande cha karatasi chenye alama ya kuongeza. Tengeneza faili iitwayo `main.py` na bonyeza <kbd>Enter</kbd>. Kiambatanisho `.py` kinaonyesha kuwa ni faili la Python.

Fungua faili yako ya `main.py` na andika msimbo ufuatao:

```py
print("Hello, world!")
```

## Sakinisha kiendelezi cha Python

Ili kusakinisha kiendelezi rasmi cha Python cha Microsoft, fuata hatua maalum zilizo hapa chini:

### Njia A: Ndani ya programu

1. Fungua mtazamo wa Extensions kwa kubofya ikoni ya vipande vinne vya jengo kwenye Upau wa Shughuli upande wa kushoto. Vinginevyo, bonyeza <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (Windows / Linux) au <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (macOS).
1. Andika `Python` kwenye upau wa utafutaji juu.
1. Tafuta matokeo ya juu yenye jina Python, ukihakikisha mchapishaji aliye chini ni Microsoft.
1. Bofya kitufe cha buluu cha <kbd>Install</kbd>.

### Njia B: Terminali / Mstari wa Amri

Ikiwa unapendelea kusakinisha kiendelezi kutoka terminali, hakikisha kwanza amri ya `code` inapatikana. Kwenye macOS, fungua Command Palette, endesha `Shell Command: Install 'code' command in PATH`, na anzisha upya terminali yako.

Kisha sakinisha kiendelezi cha Python kwa kuendesha:

```bash
code --install-extension ms-python.python
```

## Kuchagua tafsiri ya Python

Kiendelezi hufanya kazi kama daraja, lakini hakina faili halisi za lugha ya Python. Lazima usakinishe tafsiri ya Python tofauti kutoka Tovuti Rasmi ya Python ikiwa bado hujasakinisha.

Mara Python itakapokuwa imewekwa kwenye mfumo wako wa uendeshaji, iunganishe na mhariri wako:

1. Kwenye VS Code, fungua folda yoyote au faili inayomalizika na `.py`.
1. Fungua Command Palette kwa kutumia <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows / Linux) au <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS).
1. Andika na chagua `Python: Select Interpreter`.
1. Chagua toleo la Python 3 lililosakinishwa kutoka kwenye orodha ya mashine yako. Sasa litaonekana moja kwa moja kwenye upau wa hali ya kazi ya eneo lako la kazi.

## Kuendesha Msimbo Wako wa Python

Ili kuendesha msimbo huu, una chaguzi kadhaa. Chaguo la kwanza ni kubofya kitufe cha kuendesha kinachoonekana kama kitufe cha kucheza kilicho upande wa juu kulia. Hilo litafungua terminali na kuendesha msimbo wako wa Python hapo. Unapaswa kuona maandishi `Hello, world!`

Chaguo jingine ni kufungua terminali na kuendesha programu kwa mkono kwa kutumia:

```bash
python main.py
```

Lazima ukimbie amri hii kutoka kwenye folda ambapo `main.py` imehifadhiwa. Kwa mfano, kama `main.py` iko ndani ya folda inayoitwa `python-projects`, kwanza tumia ifuatayo kwenye terminali:

```bash
cd python-projects
```

Kisha kimbia:

```bash
python main.py
```

## Kutumia `python3` Badala ya `python`

Katika baadhi ya mazingira, hasa kwenye mifumo ya macOS na Linux ambapo Python 2 na Python 3 zote zimewekwa, unaweza kuhitaji kutumia `python3` badala ya `python`. Hii ni kawaida wakati amri ya `python` haipo au inaelekeza kwenye toleo la zamani la Python.

```bash
python3 main.py
```

Unapoendelea na kozi, endesha mifano ya kila funzo kwa ndani na tengeneza mifano yako mwenyewe kujaribu kile ulichojifunza.
