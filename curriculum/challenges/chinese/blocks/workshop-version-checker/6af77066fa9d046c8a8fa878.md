# --description--

如果已安装的版本不是最新的，你的函数应该说明可用的更新类型。当主版本号不同的时候，就是重大更新。这意味着新版本包含了可能与旧版本不兼容的大改动。

你可以通过索引 `0` 访问版本的主版本号。添加一个 `if` 语句，检查 `installed` 的主版本号是否小于 `latest` 的主版本号。如果是，创建一个名为 `update_type` 的变量，并赋值为字串 `major update`。

# --hints--

def check_for_update(installed, releases):
    sorted_releases = tuple(sorted(releases, reverse=True))
    latest = sorted_releases[0]

    if installed not in releases:
        return 'not a known release', latest

    if installed == latest:
        return 'up to date', latest
