# --description--

Expressões regulares podem conter sequências especiais que consistem em uma barra invertida (`\`) seguida por um caractere. Essas sequências têm um significado especial. Por exemplo, `\d` corresponde a um dígito decimal.

Em Python, prefixar um literal de string com `r` ou `R` cria uma *raw string*. Raw strings tratam barras invertidas como caracteres literais em vez de sequências de escape, tornando-as ideais para expressões regulares.

```py
import re

book = "Fahrenheit 451"
print(re.search(r'\d', book))
# <re.Match object; span=(11, 12), match='4'>
```

Após a letra `p`, o `patient_id` deve ter uma sequência de números. Então, modifique seu padrão regex para ser a raw string `r'p\d'`.
