# --description--

In diesem Labor verarbeiten Sie E-Commerce-Bestellungen und gehen mit den dabei auftretenden Fehlern um.

**Ziel:** Erfüllen Sie die untenstehenden User Stories und bestehen Sie alle Tests, um das Labor abzuschließen.

Die Daten, mit denen Sie arbeiten, haben die gleiche Struktur wie die Variablen im Startcode:

- Eine **Bestellung** ist ein Wörterbuch mit:
  - `order_id`: einer Ganzzahl, die die Bestellung identifiziert.
  - `products`: einer Liste von Wörterbüchern, jeweils mit einer `product_id` und der angeforderten `quantity`.
  - `discount_code`: einem String oder `None`, wenn die Bestellung keinen Rabattcode hat.
  - `status`: einem String, der den Zustand der Bestellung beschreibt.
- Eine **Bestellhistorie** ist eine Liste von Bestellungen.
- Ein **Inventar** ist ein Wörterbuch, dessen Schlüssel Produkt-IDs sind und dessen Werte Wörterbücher mit dem `product`-Namen, der `quantity` auf Lager und dem `price` einer einzelnen Einheit sind.
- Die **Rabattcodes** sind ein Wörterbuch, dessen Schlüssel die Codes sind und dessen Werte die Rabattwerte, zum Beispiel `0.1` für 10 % Rabatt.

**User Stories:**

1. Sie sollten eine Funktion namens `find_order` mit zwei Parametern haben: eine Bestell-ID und eine Bestellhistorie, in dieser Reihenfolge.
1. `find_order` sollte:
   - die Bestellung aus der gegebenen Bestellhistorie zurückgeben, deren `order_id` der angegebenen Bestell-ID entspricht.
   - einen `ValueError` mit der Nachricht `Order ID {order_id} not found in order history.` auslösen, wenn keine Bestellung der angegebenen Bestell-ID entspricht.
1. Sie sollten eine Funktion namens `verify_availability` mit zwei Parametern haben: eine Bestellung und ein Inventar, in dieser Reihenfolge.
1. `verify_availability` sollte:
   - einen `ValueError` mit der Nachricht `Product ID {product_id} is not in the inventory.` auslösen, wenn ein Produkt in der Bestellung im gegebenen Inventar fehlt.
   - einen `ValueError` mit der Nachricht `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.` auslösen, wenn die angeforderte Menge eines Produkts größer ist als die Menge im gegebenen Inventar.
   - nichts auslösen, wenn jedes Produkt in der Bestellung in der angeforderten Menge verfügbar ist.
1. Sie sollten eine Funktion namens `get_discount_rate` mit zwei Parametern haben: eine Bestellung und die Rabattcodes, in dieser Reihenfolge.
1. `get_discount_rate` sollte:
   - `0.0` zurückgeben, wenn der `discount_code` der Bestellung `None` ist.
   - einen `ValueError` mit der Nachricht `Invalid discount code: {discount_code}.` auslösen, wenn der `discount_code` der Bestellung nicht zu den gegebenen Rabattcodes gehört.
   - sonst den Wert des `discount_code` der Bestellung zurückgeben.
1. Sie sollten eine Funktion namens `process_order` mit vier Parametern haben: die ID der zu verarbeitenden Bestellung, eine Bestellhistorie, ein Inventar und die Rabattcodes, in dieser Reihenfolge.
1. `process_order` sollte `find_order`, `verify_availability` und `get_discount_rate` verwenden, um die Bestellung zu verarbeiten, und die von ihnen ausgelösten `ValueError` so behandeln, dass ein Aufruf von `process_order` niemals einen Fehler auslöst.
1. Wenn keine Bestellung in der gegebenen Bestellhistorie der angegebenen Bestell-ID entspricht, sollte `process_order`:
   - `Error processing order {order_id}: {error message}` ausgeben, wobei `{error message}` die Nachricht des von `find_order` ausgelösten `ValueError` ist, und sonst nichts ausgeben.
   - das gegebene Inventar und die Rabattcodes unverändert lassen.
1. Wenn die Bestellung existiert, aber nicht erfüllt werden kann, weil ein Produkt im Inventar fehlt, die angeforderte Menge nicht verfügbar ist oder der Rabattcode ungültig ist, sollte `process_order`:
   - `Error processing order {order_id}: {error message}` ausgeben, wobei `{error message}` die Nachricht des von `verify_availability` oder `get_discount_rate` ausgelösten `ValueError` ist.
   - den `status` der Bestellung auf `failed` setzen.
   - das gegebene Inventar und die Rabattcodes unverändert lassen.
   - `Order {order_id} processing completed. Current status: failed` ausgeben.
1. Wenn die Bestellung erfüllt werden kann, sollte `process_order`:
   - `Order {order_id} total: ${total}` ausgeben, mit angewendetem Rabatt und auf zwei Dezimalstellen gerundetem Gesamtbetrag.
   - den `status` der Bestellung auf `processed` setzen.
   - die bestellten Mengen vom gegebenen Inventar abziehen.
   - den von der Bestellung verwendeten Rabattcode aus den gegebenen Rabattcodes entfernen, sodass jeder Code nur einmal verwendet werden kann.
   - `Order {order_id} processing completed. Current status: processed` ausgeben.

**Hinweis:** Ihnen wurde ein Inventar, eine Bestellhistorie und Rabattcodes zur Verfügung gestellt, mit denen Sie Ihren Code testen können. Rufen Sie Ihre Funktionen auf, um sie auszuprobieren, auch die Fälle, die Fehler auslösen, aber kommentieren Sie diese Aufrufe vor dem Ausführen der Tests aus, da sie sonst die Tests stören könnten.

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id, order_history, inventory, discount_codes):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
