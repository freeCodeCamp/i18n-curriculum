# --description--

最後一個操作是刪除一個值。在 `BinarySearchTree` 類別中，創建一個名為 `_delete` 的方法，帶有三個參數：`self`、`node` 和 `key`。像 `_insert` 一樣，它會傳回變更後的子樹。

先從尋找要刪除的節點開始，方式和你在 `_insert` 中做的一樣。新增一個 `if` 述語，檢查 `key` 是否小於 `node.key`，並將呼叫 `self._delete` 並傳入 `node.left` 和 `key` 的結果指定給 `node.left`。接著，新增一個 `elif` 語句，當 `key` 大於 `node.key` 時，對右子樹做同樣的操作。

最後，在方法結尾傳回 `node`。

class BinarySearchTree:
    def __init__(self):
        self.root = None

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)

        self.root = self._insert(self.root, key)

        if node:
            self._inorder_traversal(node.left, result)
            result.append(node.key)
            self._inorder_traversal(node.right, result)

        self._inorder_traversal(self.root, result)
        return result

    def _search(self, node, key):
        if node is None or node.key == key:
            return node
        if key < node.key:
            return self._search(node.left, key)
        return self._search(node.right, key)

    def search(self, key):
        return self._search(self.root, key)
