# --description--

Kama ulivyojifunza katika funzo lililopita, moduli ni faili ya Python inayokusanya msimbo unaohusiana, ili uweze kuutumia tena katika mafaili mengine ya Python.

Pia unaweza kuandika moduli zako mwenyewe na kuzi import katika script zako. Kuunda moduli zako mwenyewe ni njia nzuri ya kupanga msimbo wako. Badala ya kuwa na faili moja refu sana, unaweza kugawanya msimbo wako katika mafaili madogo, ambapo kila moja hukusanya msimbo unaohusiana, kisha kuzi import mahali popote unapoihitaji.

Kwa mfano, fikiria umeunda faili la `temperature.py` lenye kitendakazi viwili kwa ajili ya kubadilisha joto, na wito wa kitendakazi kuangalia kuwa moja ya hizo zinafanya kazi:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

Ukikimbia faili hii moja kwa moja, huu ndio matokeo:

```md
212.0
```

Sasa, fikiria umeunda faili nyingine iitwayo `main.py` katika folda ile ile kama `temperature.py`. Ili kutumia kitendakazi kutoka moduli yako ya ndani, unai import kwa kutumia jina la moduli bila kiambatanisho cha `.py`:

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

Ukikimbia faili la `main.py`, huu ndio matokeo:

```md
212.0
100.0
```

Wakati `temperature` inapo importwa, Python inakimbia msimbo wote katika `temperature.py` kutoka juu hadi chini. Ndiyo maana `212.0` inachapishwa, ingawa `main.py` inawito tu `fahrenheit_to_celsius()`. Msimbo kama huu wa ukaguzi kawaida ni kitu unachotaka kukimbia tu wakati unatekeleza faili moja kwa moja, si kila mara inapo importwa.

Ili kudhibiti hili, unaweza kutumia msemo wa kawaida wa Python:

```python
if __name__ == '__main__':
    # Code
```

`__name__` ni kigezo maalum kilichojengwa ndani katika Python.

Wakati faili ya Python inapo tekelezwa moja kwa moja, Python huweka thamani ya mabadiliko huu kuwa mfuatano wa herufi `__main__`.

Lakini ikiwa faili ya Python inaletwa kama moduli ndani ya skiripti nyingine ya Python, thamani ya kigezo cha `__name__` huwekwa kuwa jina la moduli hiyo (kwa kawaida jina la faili bila nyongeza ya `.py`).

Hii ndiyo sababu mara nyingi utapata masharti haya katika script za Python. Yana msimbo unaotaka kukimbia **tu ikiwa** script ya Python inaendeshwa kama programu kuu. Ikiwa script ime importwa kama moduli, msimbo ndani ya block hiyo haukimbii.

Hii ni msaada kwa sababu inaruhusu skiripti za Python kuwa na madhumuni mawili. Zinaweza kuendeshwa moja kwa moja kutekeleza mantiki kuu, au kuletwa ndani ya moduli nyingine bila kutekeleza mantiki kuu.

Hapa kuna faili la `temperature.py` lililosahihishwa kutumia msemo huu. Pia linachapisha thamani ya `__name__`, ili uone jinsi inavyobadilika:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

Ukikimbia faili hii moja kwa moja, Python huweka `__name__` kuwa `'__main__'`, hivyo sharti ni `True` na msimbo ndani ya block ya `if` unakimbia. Huu ndio matokeo:

```md
The value of __name__ is: __main__
212.0
```

Ukikimbia faili la `main.py` badala yake, huu ndio matokeo:

```md
The value of __name__ is: temperature
100.0
```

Wito la `print()` nje ya block ya `if` bado unakimbia wakati `temperature` inapo importwa, na linaonyesha kuwa thamani ya `__name__` sasa ni `temperature`, jina la moduli.

Lakini kwa kuwa `__name__` si sawa na `'__main__'`, msimbo ndani ya block ya `if` haukimbii, hivyo `212.0` haichapishwi. Matokeo pekee ni `100.0`, ambayo hutoka kwenye wito wa kitendakazi katika `main.py`.
