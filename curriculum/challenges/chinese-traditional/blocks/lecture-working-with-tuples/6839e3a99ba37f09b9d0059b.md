## 什麼是 Tuple？

元組是 Python 的一種資料型別，用於創建有序的值序列。元組可以包含像這樣混合的資料型別：

```py
developer = ('Alice', 34, 'Rust Developer')
```

逗號用來創建 tuple，因此在這種指派中，小括號是選用的：

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

要創建只有一個元素的 tuple，必須在元素後面加上逗號：

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

空的 tuple 寫作 `()`。

tuple 類似列表，但列表是可變的資料型別，而 tuple 是不可變的。這表示一旦 tuple 被創建，其元素的引用就無法被替換、添加或刪除。

如果你嘗試更新元組中的其中一個項目，將會得到 `TypeError`：

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## tuple 中的可變物件

tuple 可以包含可變物件，例如列表。tuple 的不可變性不會阻止對該包含物件的更改：

```py
def add_greeting(values):
    values[0].append('hi')

greetings = (['hello'],)
original_list = greetings[0]

add_greeting(greetings)
print(greetings) # (['hello', 'hi'],)
print(greetings[0] is original_list) # True
```

該函式會變更 tuple 中的列表。tuple 仍然持有對同一列表的引用。若將不同的列表指派給 `greetings[0]`，會引發 `TypeError`，因為那會替換 tuple 的元素引用。

## 存取 Tuple 元素

要存取元組中的元素，你可以使用括號表示法和索引號碼：

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

如果你需要從元組的末端開始存取元素，則你可以使用負索引。以下是使用負索引存取元組中倒數第二個元素的範例：

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

如果你嘗試傳入一個大於或相等於 tuple 長度的索引數字，則你會收到像這樣的 `IndexError`：

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## 使用 `tuple()` 建構式

另一種建立 tuple 的方式是使用 `tuple()` 建構式，如下所示：

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

對於 `tuple()` 建構式，你可以傳入不同的可迭代物件，例如字串、列表，甚至其他元組。

## 檢查元素是否在 Tuple 中

要檢查一個項目是否在一個 tuple 中，你可以像這樣使用 `in` 關鍵字：

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## 從元組中解包值

你也可以像對列表一樣從元組中解包項目：

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

在這個範例中，`name` 的值是 `'Alice'`，`age` 的值是 `34`，而 `job` 的值是 `'Rust Developer'`。

如果你需要收集元組中任何剩餘的元素，你可以像這樣使用星號（`*`）運算子：

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

這裡，`name` 的值是 `'Alice'`，而 `rest` 是一個由數字 `34` 和字串 `'Rust Developer'` 組成的列表。

## 在同時指派中使用 tuple

你可以在指派的右側創建一個 tuple，並將其解包到左側的變數中：

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

Python 會先評估右側所有的運算式，再將它們的值指派給左側的變數。這讓你可以在不使用暫存變數的情況下交換兩個值：

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## 從函式傳回 tuple

函式可以透過在 `return` 後放置以逗號分隔的值來傳回 tuple：

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

這些以逗號分隔的值會創建一個 tuple，函式會傳回它。這裡，`return first, second` 等同於 `return (first, second)`。小括號是選用的。

你可以直接將傳回的 tuple 解包到變數中：

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## 切片 Tuple

就像對列表一樣，你可以對元組使用切片運算子來擷取其中的一部分。以下是一個將項目 `'pie'` 和 `'cookies'` 擷取到一個獨立元組的範例：

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

請記住，第一個數字表述擷取的起始索引，而第二個數字表述結束索引。但請注意，結束索引的項目不包含在擷取的元組中。

## 比較 tuple

Python 以字典序比較 tuple。這表示它從左到右比較對應的元素。第一組不相等的元素決定結果：

```py
print((1, 9) < (2, 0)) # True
```

這裡，`1` 小於 `2`，所以第一個 tuple 較小。Python 不需要比較 `9` 和 `0`。

如果第一個元素相等，Python 會繼續比較下一組：

```py
print((1, 3) < (1, 5)) # True
```

兩個 tuple 都以 `1` 開頭，所以 Python 比較 `3` 和 `5` 來決定結果。

如果所有對應元素都相等，較短的 tuple 較小。長度相同且對應元素相等的 tuple 是相等的：

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

第一組不相等的元素必須支援排序比較。否則，Python 會引發 `TypeError`：

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

這裡，第一個元素相等，但 Python 無法比較整數 `3` 和字串 `'five'` 的大小。

如果較早的元素組已決定結果，後面的元素不必可比較：

```py
print((1, 3) < (2, 'five')) # True
```

## 從元組中移除元素

如果你需要從元組中移除一個項目，這是不可能的，因為元組是不可變的。所以這個範例會產生錯誤：

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## 在元組和列表之間做選擇

那麼，什麼時候你會使用 tuple 而不是 列表？

如果你需要一個可以新增、刪除和更新元素的動態群集，應該使用列表。如果你需要一個元素引用保持固定的序列，可以使用 tuple。記得它包含的任何可變物件仍然可以改變。
