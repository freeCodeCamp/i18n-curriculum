## Express.js란?

- **Express**: Node.js 위에 구축된 최소한의 유연한 웹 프레임워크로, 웹 서버와 API를 쉽게 만들 수 있게 합니다.
- **Express 설치**: `npm install express`
- **Express로 만들 수 있는 것**: 웹 앱, RESTful API, SPA 백엔드, 미들웨어 중심 서비스, HTTP를 사용하는 모든 서버 측 애플리케이션.
- **미들웨어**: 요청을 받고 응답을 보내기 전 사이에 실행되는 코드입니다. 오류 처리, 입력 유효성 검사, 요청 또는 응답 데이터 수정 등에 사용합니다. 여러 미들웨어 함수를 연쇄적으로 연결할 수 있습니다.
- **플러그인**: Express를 확장하는 외부 npm 모듈로, 보통 미들웨어로 구현됩니다.

## 기본 Express 앱 만들기

```javascript
const express = require("express");
const app = express();
const port = 3000;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

- `require("express")` — Express 라이브러리를 불러옵니다.
- `express()` — 새 Express 애플리케이션 인스턴스를 생성하고 반환하는 팩토리 함수입니다.
- `app` — `.get()`, `.post()`, `.listen()` 같은 메서드에 접근할 수 있는 주요 서버 객체입니다.
- `port` — 앱이 수신 대기하는 네트워크 엔드포인트입니다. 로컬 개발에 `3000` 포트가 흔히 사용됩니다.
- `app.listen(port, callback)` — 서버를 시작하고 들어오는 HTTP 요청을 수신하기 시작합니다.

## Express에서 라우팅

- **라우트**: 클라이언트가 특정 URL에 특정 HTTP 메서드로 요청할 때 앱이 어떻게 응답할지 알려주는 규칙입니다.
- **라우트 메서드**: `app.get()`, `app.post()`, `app.put()`, `app.delete()` — 각각 일치하는 HTTP 메서드 요청을 처리합니다.
- **정적 라우트 경로**: `/home` 또는 `/menu/drinks` 같은 고정 URL입니다.
- **동적 라우트 경로(라우트 매개변수)**: URL에서 값을 캡처하는 자리 표시자로, `:`가 접두사입니다. 예: `/post/:postId`.
- **`req.params`**: URL에서 캡처한 동적 값을 담은 객체입니다. 예를 들어 `/post/42`에 대한 요청은 `req.params.postId === "42"`를 제공합니다.

### 라우트 핸들러

- **라우트 핸들러**는 요청이 라우트와 일치할 때 실행되는 콜백 함수 `(req, res) => { ... }`입니다.
- `req` — 들어오는 요청에 관한 정보(매개변수, 쿼리 문자열, 헤더, 본문)를 포함합니다.
- `res` — 클라이언트에 응답을 보내는 데 사용합니다.

## 응답 메서드

| 메서드 | 기능 |
| --- | --- |
| `res.send()` | 일반 텍스트, HTML, JSON, 바이너리 데이터를 포함한 응답을 보냅니다. |
| `res.json()` | JSON 응답을 보내며, JavaScript 객체를 자동으로 변환합니다. |
| `res.status(code)` | HTTP 상태 코드를 설정합니다; 보통 `res.send()` 또는 `res.json()`와 함께 체인으로 사용합니다. |
| `res.redirect(url)` | 클라이언트를 다른 URL로 리다이렉트합니다. |
| `res.render(view, data)` | 템플릿 엔진 뷰를 렌더링하고 결과 HTML을 보냅니다. |

## `app.route()`를 사용한 체인 가능한 라우트 핸들러

- `app.route(path)`는 같은 경로에 대해 여러 HTTP 메서드 핸들러를 그룹화해 경로 반복을 피합니다.

```javascript
app
  .route("/user")
  .get((req, res) => { res.send("Fetching user data"); })
  .post((req, res) => { res.send("Creating a user"); })
  .put((req, res) => { res.send("Updating the user"); })
  .delete((req, res) => { res.send("Deleting the user"); });
```

## `express.Router()`를 사용한 모듈식 라우팅

- `express.Router()`는 미니 Express 앱 같은 라우터 객체를 생성하며, 여기에 라우트를 정의하고 메인 앱에 마운트할 수 있습니다.
- `app.use(path, router)`로 라우터를 마운트합니다. 라우터 내부의 라우트는 마운트 경로에 상대적입니다.
- **장점**: 관심사 분리, 메인 파일 정리, 라우트 재사용과 확장 용이.

```javascript
// userRoutes.js
const express = require("express");
const router = express.Router();
router.get("/", (req, res) => { res.send("List of users"); });
router.get("/:id", (req, res) => { res.send(`User ${req.params.id}`); });
module.exports = router;

// app.js
app.use("/users", userRoutes); // mounts the router at /users
```

## 정적 파일 제공

- **정적 파일**: 이미지, CSS, 클라이언트 측 JavaScript 같은 서버 측 처리 없이 직접 제공되는 자산입니다.
- `express.static(directory)` — 지정한 폴더에서 파일을 제공하는 내장 미들웨어입니다.
- 요청한 파일이 없으면 Express가 자동으로 404 응답을 보냅니다.
- 개별 정적 파일에 대한 라우트 정의는 필요 없습니다.

```javascript
app.use(express.static(path.join(__dirname, "public")));
```

- `app.use()`를 여러 번 호출해 여러 디렉터리에서 제공할 수 있으며, 선택적으로 마운트 경로를 지정할 수 있습니다:

```javascript
app.use(express.static(path.join(__dirname, "public")));
app.use("/images", express.static(path.join(__dirname, "images")));
```
