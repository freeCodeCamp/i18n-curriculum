# --description--

Sasa utageuza tofauti hizo kuwa lebo za maandishi kama `+3.6 °C`. Nambari chanya huchapishwa bila alama, kwa hivyo utahitaji kuongeza `+` mbele yao.

Ili kujumuisha vitu vinavyokidhi sharti tu, unaweza kuongeza `if` mwishoni mwa list comprehension:

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

Tengeneza kigezo kinachoitwa `difference_labels`. Tumia list comprehension kuweka thamani yake kuwa orodha inayojumuisha `f'+{difference} °C'` kwa kila `difference` katika `differences`, lakini tu ikiwa `difference` ni kubwa kuliko `0`.

Kisha, chapisha `difference_labels` badala ya `differences`.

Katika terminal, utaona lebo 3 tu kwa joto 7. `if` inayofuata huondoa vitu ambavyo havilingani na sharti, kwa hivyo hakuna njia ya kusema joto gani kila lebo inahusiana nalo. Utarekebisha hili katika hatua inayofuata.
