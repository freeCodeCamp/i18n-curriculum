# --description--

También debes manejar el caso cuando el usuario no califique para un descuento de membresía.

Agrega una cláusula `else` a tu declaración `if` e imprime `User does not qualify for membership discount` dentro del cuerpo de `else`.

También quieres mostrar el valor actualizado de `discount`. Como es una cantidad de dinero, debe mostrarse con dos decimales.

Como aprendiste en una lección anterior, puedes hacer esto con la especificación de formato `.2f` dentro de una f-string. También funciona con enteros, así que un valor como `3` se muestra como `3.00`.

Debajo de la sentencia `if...else`, usa una f-string para imprimir `Discount:` seguido de un espacio y `discount` formateado con dos decimales. Luego, verifica la salida en la terminal.
