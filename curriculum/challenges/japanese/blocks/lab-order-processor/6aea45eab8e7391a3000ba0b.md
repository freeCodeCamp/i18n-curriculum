# --description--

このラボでは、eコマースの注文を処理し、その過程で発生するエラーを扱います。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

扱うデータは、開始コードの変数と同じ構造を持っています：

- **order** は辞書で、以下を含みます：
  - `order_id`：注文を識別する整数。
  - `products`：各要素が `product_id` と要求された `quantity` を持つ辞書のリスト。
  - `discount_code`：文字列、または割引コードがない場合は `None`。
  - `status`：注文の状態を表す文字列。
- **order history** は注文のリスト。
- **inventory** は、キーが商品IDで値が `product` 名、在庫数 `quantity`、単価 `price` の辞書の辞書。
- **discount codes** は、キーがコードで値が割引率の辞書。例えば10%割引なら `0.1`。

**ユーザーストーリー：**

1. `find_order` という名前の関数を用意してください。パラメータは2つで、順に注文IDと注文履歴です。
1. `find_order` は以下のことを行う必要があります。
   - 指定された注文IDと等しい `order_id` を持つ注文履歴から注文を返すこと。
   - 指定された注文IDに一致する注文がない場合、メッセージ `Order ID {order_id} not found in order history.` を持つ `ValueError` を発生させること。
1. `verify_availability` という名前の関数を用意してください。パラメータは2つで、順に注文と在庫です。
1. `verify_availability` は以下のことを行う必要があります。
   - 注文内の製品が指定された在庫に存在しない場合、メッセージ `Product ID {product_id} is not in the inventory.` を持つ `ValueError` を発生させること。
   - 注文された数量が指定された在庫の数量を超えている場合、メッセージ `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.` を持つ `ValueError` を発生させること。
   - 注文内のすべての製品が要求された数量で在庫に存在する場合は、何も発生させないこと。
1. `get_discount_rate` という名前の関数を用意してください。パラメータは2つで、順に注文と割引コードです。
1. `get_discount_rate` は以下のことを行う必要があります。
   - 注文の `discount_code` が `None` の場合は `0.0` を返すこと。
   - 注文の `discount_code` が指定された割引コードに含まれていない場合、メッセージ `Invalid discount code: {discount_code}.` を持つ `ValueError` を発生させること。
   - それ以外の場合は注文の `discount_code` に対応する割引率を返すこと。
1. `process_order` という名前の関数を用意してください。パラメータは4つで、順に処理する注文のID、注文履歴、在庫、割引コードです。
1. `process_order` は `find_order`、`verify_availability`、`get_discount_rate` を使って注文を処理し、これらが発生させる `ValueError` を処理して、`process_order` の呼び出しでエラーが発生しないようにしてください。
1. 指定された注文IDに一致する注文が注文履歴にない場合、`process_order` は以下を行う必要があります。
   - `find_order` が発生させた `ValueError` のメッセージを `{error message}` として、`Error processing order {order_id}: {error message}` を出力し、それ以外は何も出力しないこと。
   - 指定された在庫と割引コードは変更しないこと。
1. 注文は存在するが、在庫に製品がない、要求された数量が不足している、または割引コードが無効なために処理できない場合、`process_order` は以下を行う必要があります。
   - `verify_availability` または `get_discount_rate` が発生させた `ValueError` のメッセージを `{error message}` として、`Error processing order {order_id}: {error message}` を出力すること。
   - 注文の `status` を `failed` に設定すること。
   - 指定された在庫と割引コードは変更しないこと。
   - `Order {order_id} processing completed. Current status: failed` を出力すること。
1. 注文を処理できる場合、`process_order` は以下を行う必要があります。
   - 割引を適用し、合計金額を小数点以下2桁に丸めて、`Order {order_id} total: ${total}` を出力すること。
   - 注文の `status` を `processed` に設定すること。
   - 注文された数量を指定された在庫から差し引くこと。
   - 注文で使われた割引コードを指定された割引コードから削除し、各コードは一度だけ使えるようにすること。
   - `Order {order_id} processing completed. Current status: processed` を出力すること。

**注意:** 在庫、注文履歴、割引コードが提供されているので、コードをテストするために使えます。エラーを発生させるケースも含めて関数を呼び出して試してください。ただし、テストを実行する前にそれらの呼び出しはコメントアウトしてください。テストに影響を与える可能性があります。

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id, order_history, inventory, discount_codes):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
