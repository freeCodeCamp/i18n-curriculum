# --description--

Sasa tumeshazungumzia encapsulation, urithi, na polymorphism, hebu tujadili dhana kuu inayofuata katika programu za vitu – abstraction.

## Abstraction ni nini?

Abstraction ni mchakato wa kuficha maelezo magumu ya utekelezaji na kuonyesha tu vipengele muhimu vya kitu au mfumo. Fikiria kama makini na kile kitu kinachofanya badala ya jinsi kinavyokifanya.

Abstraction haijafungiwa kwa Python tu. Ni dhana ya programu inayoweza kutekelezwa katika lugha nyingi zinazounga mkono programu za vitu.

## Mfano halisi wa abstraction

Ili kuonyesha abstraction, fikiria unaendesha gari. Unapokuwa kwenye kiti cha dereva, unashirikiana na sehemu muhimu kama vile gurudumu la mwelekeo, shifter, na pedal za accelerator na breki. Huna haja ya kujua maelezo ya kina jinsi injini inavyofanya kazi, jinsi transmission inavyobadilisha gia, au fizikia nyuma ya mfumo wa breki, kwani yote hayo ni maelezo tata ya utekelezaji.

Hiyo ni abstraction ikifanya kazi! Inakupa kiolesura kilichorahisishwa cha kushirikiana na mfumo mgumu.

Katika mfano wa gari tena, kiolesura kilichorahisishwa ni usukani, breki, na accelerator, wakati mfumo mgumu ni gari lenyewe.

## Abstraction katika Python kwa kutumia moduli ya `abc`

Wakati vitendakazi na madarasa ya kawaida tayari vinatoa aina za abstraction katika Python, moduli ya `abc` hutoa njia maalum ya kutangaza na kulazimisha interfaces za madarasa ya abstraction.

Moduli hii hutoa darasa la `ABC` (linalomaanisha "darasa la msingi la abstraction") na dekoreta ya `@abstractmethod`.

`ABC` ni darasa la msaada linalokusudiwa kurithiwa ili kutangaza madarasa ya msingi ya abstraction. Wakati `ABC` yenyewe na madarasa madogo yasiyo na wanachama wa abstraction yanaweza kuanzishwa moja kwa moja, darasa la abstraction haliwezi kuanzishwa ikiwa lina njia au sifa za kipengele za abstraction ambazo hazijatekelezwa.

Kwa upande mwingine, njia ya abstraction ni njia inayotangazwa katika Darasa la Msingi la Abstraction (ABC) kwa kutumia dekoreta ya `@abstractmethod`. Inaweza kuwa haina utekelezaji au kuwa na utekelezaji wa msingi wa chaguo. Hata hivyo, ili kuchukuliwa kuwa halisi na kuanzishwa, darasa lazima lipe au lirithi utekelezaji halisi kwa kila njia ya abstraction, hata kama utekelezaji wa chaguo umetolewa.

## Sintaksia ya darasa la abstraction

Hapa kuna sintaksia ya msingi ya darasa la abstraction katika Python:

```py
from abc import ABC, abstractmethod

# Define an abstract base class
class AbstractClass(ABC):
    @abstractmethod
    def abstract_method(self):
        pass

# Concrete subclass that implements the abstract method
class ConcreteClassOne(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassOne')

# Another concrete subclass
class ConcreteClassTwo(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassTwo')
```

## Kutumia darasa la msingi la abstraction

Hapa kuna mfano wa msingi:

```py
from abc import ABC, abstractmethod

class Animal(ABC): # Inherits from abstract base class
   @abstractmethod # Abstract method decorator
   def make_sound(self):  # The method subclasses must override
       pass

# Concrete class that will override the abstract method
class Dog(Animal):
   def make_sound(self):
       print('Woof!')

# Another concrete class that will override the abstract method
class Cat(Animal):
   def make_sound(self):
       print('Meow!')

# Another concrete class that will override the abstract method
class Monkey(Animal):
   def make_sound(self):
       print('Ooh ooh aah aah!')

# Create instances of each concrete class
animals = [Dog(), Cat(), Monkey()]

# Loop through the instances to call the make_sound method
for animal in animals:
   animal.make_sound()

# Output:
# Woof!
# Meow!
# Ooh ooh aah aah!
```

Katika mfano huu:

- Tunaleta darasa la vitu la `ABC` na njia ya `abstractmethod` kutoka moduli ya `abc`.
- Kisha tunaunda darasa la vitu la `Animal` linalo mrithi `ABC`, na kuunda njia ya `make_sound` isiyo na utekelezaji ambayo madarasa ya vitu yanayomrithi lazima yatekeleze ili yaweze kuanzishwa.
- Tunaunda madarasa ya vitu halisi ya `Dog`, `Cat`, na `Monkey`, ambayo lazima yaghairi njia ya `make_sound` isiyo na utekelezaji.
- Tunaunda mifano ya madarasa ya vitu halisi na kuita njia yao ya `make_sound` kuonyesha jinsi kila moja inavyotekeleza njia ya `make_sound` isiyo na utekelezaji kwa njia yake mwenyewe.

## Madarasa ya abstraction hayawezi kuanzishwa kama vitu halisi

Kumbuka kuwa huwezi kuunda mfano wa darasa la `Animal`. Hapa ni kile kinachotokea ukijaribu kufanya hivyo:

```py
dog = Animal() 
# TypeError: Can't instantiate abstract class Animal 
# without an implementation for abstract method 'make_sound'
```

Sera ile ile inatumika kwa madarasa madogo ambayo hayatoi utekelezaji wa njia ya abstraction. Hata kama unatangaza darasa dogo la `Animal`, huwezi kulianzisha hadi litolee au lirithi utekelezaji halisi wa `make_sound`. Hapa kuna mfano unaoonyesha hilo:

```py
class Bird(Animal):
    pass

bird = Bird()
# TypeError: Can't instantiate abstract class Bird 
# without an implementation for abstract method 'make_sound'
```

## Madarasa ya abstraction yenye sifa za mfano

Hapa kuna mfano mwingine, wakati huu na sifa ya mfano inayozinduliwa kutoka kwa hoja inayotumwa wakati wa kuunda mifano ya madarasa halisi:

```py
from abc import ABC, abstractmethod

# The blueprint for any toy that can speak
class TalkingToy(ABC):
   def __init__(self, name):
       self.name = name
   @abstractmethod
   def speak(self):
       pass

class RobotToy(TalkingToy):
   def speak(self):
       print(f'{self.name} says beep boop! I am a robot!')

class TeddyBearToy(TalkingToy):
   def speak(self):
       print(f"{self.name} says hug me! I'm cuddly!")

class DinosaurToy(TalkingToy):
   def speak(self):
       print(f'{self.name} says ROOOOAR!')

# Create toys
rusty = RobotToy('Rusty')
fluffy = TeddyBearToy('Fluffy')
rex = DinosaurToy('Rex')

toys = [rusty, fluffy, rex]
for toy in toys:
   toy.speak()

# Output:
# Rusty says beep boop! I am a robot!
# Fluffy says hug me! I'm cuddly!
# Rex says ROOOOAR!
```

Katika mfano huu:

- Tuna darasa la msingi la abstract `TalkingToy` linalobainisha ramani kwa ajili ya toy yoyote inayoweza kuzungumza.
- Madarasa ya chini `RobotToy`, `TeddyBearToy`, na `DinosaurToy` yatekeleza njia ya `speak` kwa njia zao wenyewe.
- Tunapotengeneza vitu vya madarasa haya ya chini na kuita njia ya `speak`, kila toy huzungumza kwa njia yake ya kipekee.

## Jinsi abstraction inavyosaidia kuweka mifumo tata kuwa na mpangilio

Kwa kumalizia, abstraction katika Python hurahisisha mifumo ngumu kwa kuongeza matumizi tena.

Umeona jinsi unavyoweza kutumia tena njia moja kutoka darasa la abstract katika madarasa mengi ya chini huku ukilazimisha kila darasa la chini kutoa tabia yake maalum.

Njia hii inahakikisha msimbo wako uko na mpangilio, una ufanisi, na ni rahisi kudumishwa, hasa programu yako inapokua.
