## 查找算法

- **目的**：查找算法让你在一组项中查找目标。
- **查找算法类型**：两种常见的查找算法是线性查找和二分查找。理解它们的区别有助于确定何时使用哪种算法。

### 线性查找

- **线性查找算法**：遍历一组项，从头开始检查每一项，直到找到目标。
- **查找成功**：如果找到目标项，返回它在列表中的索引。
- **查找失败**：讲解中的实现返回 `-1` 表示未找到目标。在 Python 中，`-1` 也表示非空列表的最后一个元素索引，因此在将结果用作索引前要检查是否为 `-1`。否则，查找失败可能会错误地返回最后一个元素。
- **效率**：由于线性查找逐项顺序检查，对于大型列表可能效率较低。
- **时间复杂度**：`O(n)`，因为查找所需时间随列表大小线性增长。
- **空间复杂度**：`O(1)`，因为无论输入大小如何，使用的额外空间都是常量。

### 二分查找

- **二分查找算法**：一种高效的查找算法，通过反复将已排序的列表分成两半来查找目标值。
- **排序输入前提**：二分查找要求输入列表按升序排序。
- **查找范围初始化**：初始化 `low = 0` 作为第一个元素的索引，`high = len(arr) - 1` 作为最后一个元素的索引。这些变量定义了正在查找的包含边界的范围。
- **查找继续条件**：当 `low <= high` 时继续查找。如果 `low > high`，说明查找范围为空，目标未找到。
- **中点计算**：使用整数除法计算中间索引：`mid = (low + high) // 2`。
- **目标比较**：将目标值与 `arr[mid]` 比较。如果它们相等，说明在索引 `mid` 找到了目标。
- **下边界更新**：如果 `arr[mid] < target`，目标如果存在，必定在右半部分。更新 `low = mid + 1`，排除中点及其之前的所有元素。
- **上边界更新**：如果 `arr[mid] > target`，目标如果存在，必定在左半部分。更新 `high = mid - 1`，排除中点及其之后的所有元素。
- **讲解成功查找**：讲解中的实现当找到目标时返回目标的索引。
- **讲解失败查找**：讲解中的实现当查找范围为空时返回 `-1`。
- **练习路径追踪**：练习中的实现初始化一个空的 `path_to_target` 列表，并在查找过程中将每个访问的中点值追加进去。
- **练习成功查找**：当找到目标时，练习返回一个包含 `path_to_target` 和指示目标索引的消息的元组。
- **工作坊未成功查找**：当查找范围变为空时，工作坊返回一个空列表和一条 `"Value not found"` 消息。
- **时间复杂度**：`O(log n)`，因为每次比较后查找范围大约减半。
- **空间复杂度**：讲解实现使用 `O(1)` 辅助空间，存储如 `low`、`high` 和 `mid` 等变量。练习实现使用 `O(log n)` 辅助空间，因为 `path_to_target` 保存了查找过程中访问的中点值。

### 线性查找与二分查找的区别

- **前提条件**：线性查找不要求列表排序，而二分查找要求输入数据按升序排序。
- **可扩展性**：与线性查找相比，二分查找更适合大型列表。
- **时间复杂度比较**：线性查找的时间复杂度是 `O(n)`，而二分查找是 `O(log n)`。

## 排序算法与分治法

- **分治法**：一种将问题拆分成更小子问题以便更容易解决的技术。递归通常用于实现这种方法，它常见于高效排序算法，如归并排序。

### 归并排序

- **归并排序算法**：一种遵循分治法的排序算法。
- **基本情形**：长度为零或一的列表已经排序好，因此当 `len(array) <= 1` 时递归停止。
- **拆分列表**：将列表分成两个切片的半部分，递归地对每个半部分排序。
- **合并子列表**：比较两个已排序半部分中下一个未合并的元素，将较小的元素复制到下一个输出位置，并推进其索引。一旦一半用尽，复制另一半的所有剩余元素。
- **练习实现**：练习创建切片的半部分，并将合并后的值写回原列表，每写入一次推进 `sorted_index`。修改原列表并不使其成为原地排序算法，因为切片半部分需要额外存储。
- **时间复杂度**：`O(n log n)`，因为列表被反复分成两半（`log n` 层），每层合并元素需要 `O(n)` 时间。
- **空间复杂度**：`O(n)`，因为归并排序需要额外内存来合并子列表，且不是原地排序算法。
