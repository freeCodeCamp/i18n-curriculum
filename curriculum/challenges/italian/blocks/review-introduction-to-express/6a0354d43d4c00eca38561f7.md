## Cos’è Express.js?

- **Express**: un framework web minimale e flessibile costruito sopra Node.js che facilita la creazione di server web e API.
- **Installare Express**: `npm install express`
- **Cosa puoi costruire con Express**: app web, API RESTful, backend per SPA, servizi con middleware pesante e qualsiasi cosa server-side con HTTP.
- **Middleware**: codice che gira tra la ricezione di una richiesta e l’invio di una risposta. Usato per gestire errori, validare input, modificare dati di richiesta o risposta e altro. Più funzioni middleware possono essere concatenate.
- **Plugin**: moduli npm esterni che estendono Express, di solito implementati come middleware.

## Creare una app Express di base

```javascript
const express = require("express");
const app = express();
const port = 3000;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

- `require("express")` — carica la libreria Express.
- `express()` — funzione factory che crea e restituisce una nuova istanza di applicazione Express.
- `app` — l’oggetto server principale con accesso a metodi come `.get()`, `.post()` e `.listen()`.
- `port` — l’endpoint di rete su cui l’app ascolta. La porta `3000` è comune per lo sviluppo locale.
- `app.listen(port, callback)` — avvia il server e inizia ad ascoltare le richieste HTTP in arrivo.

## Routing in Express

- **Rotta**: una regola che dice all’app come rispondere quando un client richiede un URL specifico con un metodo HTTP specifico.
- **Metodi di rotta**: `app.get()`, `app.post()`, `app.put()`, `app.delete()` — ognuno gestisce richieste con il metodo HTTP corrispondente.
- **Percorso di rotta statico**: un URL fisso come `/home` o `/menu/drinks`.
- **Percorso di rotta dinamico (parametro di rotta)**: un segnaposto nell’URL che cattura un valore, preceduto da `:`, per esempio `/post/:postId`.
- **`req.params`**: un oggetto che contiene i valori dinamici catturati dall’URL. Per esempio, una richiesta a `/post/42` restituisce `req.params.postId === "42"`.

### Gestori di rotta

- Un **gestore di rotta** è la funzione di callback `(req, res) => { ... }` che viene eseguita quando una richiesta corrisponde a una rotta.
- `req` — contiene informazioni sulla richiesta in arrivo (parametri, query string, intestazioni, corpo).
- `res` — usato per inviare una risposta al client.

## Metodi di risposta

| Metodo | Cosa fa |
| --- | --- |
| `res.send()` | Invia una risposta — testo semplice, HTML, JSON o dati binari. |
| `res.json()` | Invia una risposta JSON; converte automaticamente un oggetto JavaScript. |
| `res.status(code)` | Imposta il codice di stato HTTP; di solito concatenato con `res.send()` o `res.json()`. |
| `res.redirect(url)` | Reindirizza il client a un URL diverso. |
| `res.render(view, data)` | Renderizza una vista con un motore di template e invia l’HTML risultante. |

## Gestori di rotta concatenabili con `app.route()`

- `app.route(path)` raggruppa più gestori di metodi HTTP per lo stesso percorso per evitare di ripeterlo.

```javascript
app
  .route("/user")
  .get((req, res) => { res.send("Fetching user data"); })
  .post((req, res) => { res.send("Creating a user"); })
  .put((req, res) => { res.send("Updating the user"); })
  .delete((req, res) => { res.send("Deleting the user"); });
```

## Routing modulare con `express.Router()`

- `express.Router()` crea un oggetto router — come una mini app Express — su cui puoi definire rotte e poi montare nell’app principale.
- Monta un router con `app.use(path, router)`. Le rotte dentro il router sono relative al percorso di montaggio.
- **Vantaggi**: separa le responsabilità, mantiene il file principale pulito e rende le rotte riutilizzabili e più facili da scalare.

```javascript
// userRoutes.js
const express = require("express");
const router = express.Router();
router.get("/", (req, res) => { res.send("List of users"); });
router.get("/:id", (req, res) => { res.send(`User ${req.params.id}`); });
module.exports = router;

// app.js
app.use("/users", userRoutes); // mounts the router at /users
```

## Servire file statici

- **File statici**: risorse come immagini, CSS e JavaScript client-side servite direttamente senza elaborazione server-side.
- `express.static(directory)` — middleware integrato che serve file da una cartella specificata.
- Se un file richiesto non viene trovato, Express risponde automaticamente con un 404.
- Non servono definizioni di rotta per singoli file statici.

```javascript
app.use(express.static(path.join(__dirname, "public")));
```

- Puoi servire da più directory chiamando `app.use()` più volte, opzionalmente con un percorso di montaggio:

```javascript
app.use(express.static(path.join(__dirname, "public")));
app.use("/images", express.static(path.join(__dirname, "images")));
```
