# --description--

في الدرس السابق، تعلمت كيف تُشغّل سكريبتات Python محليًا. أحيانًا قد ترغب في اختبار قطعة قصيرة من كود Python دون إنشاء برنامج كامل. يتيح لك الـ Python interactive shell فعل ذلك.

لكن أولًا، دعنا نراجع ما هو الطرفية.

الطرفية هي واجهة نصية تتيح لك التفاعل مع الكمبيوتر عبر كتابة الأوامر. كل نظام تشغيل يأتي مع تطبيق طرفية افتراضي. على macOS، يمكنك استخدام تطبيق Terminal. على Windows، يمكنك استخدام Command Prompt أو PowerShell. على Linux، لكل بيئة سطح مكتب تطبيق طرفية افتراضي خاص بها، مثل GNOME Terminal أو Konsole.

افتح تطبيق الطرفية، اكتب `python` أو `python3`، واضغط <kbd>Enter</kbd> لبدء الـ Python interactive shell. استخدم الأمر الذي أظهر إصدار Python 3 عندما تحققت من تثبيتك. الـ interactive shell هو برنامج يتيح لك كتابة الأوامر واحدة تلو الأخرى ورؤية النتائج.

عندما تبدأ جلسة جديدة، قد ترى هذا النوع من المخرجات في البداية:

```md
Python 3.12.2 (main, Mar 21 2024, 22:48:26) [Clang 14.0.3 (clang-1403.0.22.14.1)] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>> 
```

رمز `>>>` يعني أن Python ينتظر منك كتابة أمر. جرّب طباعة `"Hello, world!"` في الطرفية:

```py
print("Hello, world!")
```

يجب أن ترى النص يظهر هكذا:

```md
>>> print("Hello, world!")
Hello, world!
```

بعد طباعة النص، تعود Python إلى التالي:

```md
>>>
```

هذا يعني أنه يمكنك كتابة أمر آخر.

مُفسر Python يتبع حلقة قراءة-تقييم-طباعة (REPL). يقرأ مُدخَلك، يُقيّمه، يطبع النتيجة، ثم يعود إلى موجه `>>>`.

ماذا يحدث إذا حاولت كتابة أمر غير صالح مثل هذا؟

```md
>>> something random
```

حسنًا، مفسر Python سيظل يتبع نفس عملية REPL. في هذه الحالة، ستحصل على رسالة خطأ:

```md
>>> something random
  File "<stdin>", line 1
    something random
              ^^^^^^
SyntaxError: invalid syntax
```

لخروج من الـ interactive shell، اكتب `exit()`، اضغط <kbd>Ctrl</kbd> + <kbd>D</kbd> على macOS أو Linux، أو اضغط <kbd>Ctrl</kbd> + <kbd>Z</kbd> ثم <kbd>Enter</kbd> على Windows.

استخدام القشرة التفاعلية لـ Python ممتاز للتجارب الصغيرة مع الكود أو الاستكشاف الأساسي. أثناء تقدمك في الدروس المتبقية في الدورة، يمكنك كتابة بعض الطرق الجديدة التي تعلمتها داخل القشرة التفاعلية.

إذا كنت تخطط للعمل على برامج أطول أو عبر ملفات متعددة، استخدم محرر كود أو بيئة تطوير متكاملة (IDE).
