# --description--

到目前為止，你已經使用過 `re.search` 在字串中尋找任意位置的樣式。`re` 模組還有許多其他與正規表達式樣式搭配使用的函式（程式）。在本課中，你將學習一些最有用的函式（程式）。

## `match` 函式（程式）

`match` 函式（程式）和 `search` 類似，但它只會在字串開頭尋找樣式。如果字串開頭符合樣式，它會傳回一個比對物件，否則傳回 `None`：

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

在第二個範例中，字串包含數字，所以 `re.search` 會找到它們。但字串並非以數字開頭，因此 `re.match` 傳回 `None`。

## `fullmatch` 函式（程式）

樣式 `r'\d+:\d+'` 會比對一個或多個數字，接著是一個冒號，再接著一個或多個數字。這是像 `10:30` 這種時間的格式。

假設你想檢查某個使用者輸入是時間格式，且沒有其他多餘字元。如果你用 `re.search`，會遇到問題：

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

這會傳回一個比對物件，儘管 `10:30pm` 並不符合預期格式。這是因為 `re.search` 會在字串任意位置尋找樣式，並忽略比對周圍的額外字元。`re.match` 也會有同樣問題，因為 `10:30pm` 是以有效時間開頭。

當你在驗證資料時，通常希望整個字串都符合樣式。為此，你可以使用 `fullmatch` 函式（程式）。它只會在樣式完全符合整個字串時傳回比對物件，否則傳回 `None`：

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## `findall` 函式（程式）

`search`、`match` 和 `fullmatch` 最多只會給你一個比對結果。當你想取得字串中所有比對時，可以使用 `findall` 函式（程式）。它會傳回一個字串列表，包含所有找到的比對：

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

如果沒有任何比對，`findall` 會傳回空列表：

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## `sub` 函式（程式）

`sub` 函式（程式）會將樣式的每個比對替換成另一個字串。它接受樣式、替換字串和要搜尋的字串，並傳回一個新字串：

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub` 也有兩個選用參數。第一個是 `count`，用來限制替換的比對數量：

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

第二個是 `flags`。和其他函式（程式）一樣，`sub` 可以使用像 `re.IGNORECASE` 這樣的旗標：

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

務必將 `count` 和 `flags` 當作關鍵字引數傳入。如果你把 `re.IGNORECASE` 當作第四個位置引數傳入，Python 會把它當成 `count` 的值。
