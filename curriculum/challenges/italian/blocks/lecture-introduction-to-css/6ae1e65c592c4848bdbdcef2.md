# --interactive--

La proprietà `text-decoration` ti permette di aggiungere linee decorative al testo.

Con il suo valore iniziale `none`, è comunemente usata per rimuovere la sottolineatura predefinita che i browser aggiungono ai collegamenti quando è necessaria una personalizzazione di tali collegamenti.

```css
a {
  text-decoration: none;
}
```

Sebbene comunemente usata per i collegamenti, `text-decoration` può decorare anche altri testi.

## Altri valori della proprietà `text-decoration`

Oltre a `none`, altri valori della proprietà `text-decoration` sono:

- `underline`
- `overline`
- `line-through`

Come suggeriscono i nomi dei valori, `underline` aggiunge una linea sotto il testo, `overline` aggiunge una linea sopra il testo e `line-through` aggiunge una linea proprio in mezzo al testo, come per cancellarlo.

## C'è di più nella proprietà `text-decoration`

La proprietà `text-decoration` è in realtà una proprietà abbreviata che combina le seguenti proprietà:

- `text-decoration-line`: `none`, `underline`, `overline` e `line-through`
- `text-decoration-color`: il colore della linea.
- `text-decoration-style`: `solid`, `double`, `dotted`, `dashed` o `wavy`.
- `text-decoration-thickness`: lo spessore della linea.

Per esempio, questo aggiunge una linea ondulata rossa a un paragrafo:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

E questo aggiunge un overline verde doppio a un paragrafo:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

Puoi anche combinare i tipi di linea se vuoi:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
