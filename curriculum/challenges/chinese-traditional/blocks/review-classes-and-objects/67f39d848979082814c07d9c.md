## Python 類別與物件

- **類別定義**：類別是用來創建物件的藍圖。它透過屬性和方法定義物件的行為。以下是 Python 中類別定義的基本範例：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **類別名稱**：依慣例，類別名稱使用 PascalCase：每個字的首字母大寫且不使用底線，例如 `Dog` 或 `ShoppingCart`。

- **`__init__()` 方法**：每次你創建新物件時，Python 都會自動呼叫 `__init__()`。它用來設定物件的初始屬性。

- **`self` 參數**：`self` 指的是方法正在操作的特定物件。當你對物件呼叫方法時，Python 會自動傳入它，所以你不需要在呼叫時寫出來。`self` 是慣用名稱，但它永遠是實體方法的第一個參數。

- **創建物件**：物件是類別的實體。它們是透過呼叫類別並傳入必要的引數來創建的。

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **呼叫物件的方法**：你可以對物件呼叫方法來執行動作或取得資訊。

```python
object_name1.method_name()
object_name2.method_name()
```

- **類別與物件的差異**：類別是可重複使用的模板，而物件是該類別的具體實體，擁有實際的資料。

## 屬性

- **實體屬性**：通常在 `__init__()` 中使用 `self` 定義，且每個物件獨有。
- **類別屬性**：直接在類別內定義，並由所有實體共用。

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **動態處理屬性**：有時屬性名稱只有在執行期才知道，例如來自使用者輸入或迴圈。在這種情況下，你無法寫 `object.name`，所以你使用接受名稱字串的函式：

  - `getattr(obj, name)` 傳回該屬性的值。如果屬性不存在，會引發 `AttributeError`，除非你傳入第三個引數作為預設值。
  - `setattr(obj, name, value)` 創建或更新屬性。
  - `hasattr(obj, name)` 如果屬性存在，傳回 `True`，否則傳回 `False`。
  - `delattr(obj, name)` 刪除屬性。

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **用 `dir()` 檢視屬性**：`dir()` 函式會傳回物件屬性和方法名稱的列表。搭配 `callable()` 使用，可以區分方法和資料屬性。

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## 方法

- **方法**：定義在類別內的函式，操作物件的屬性。

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **存取方法**：使用點記法對物件呼叫方法。以下是對兩個不同車輛物件呼叫 `describe` 方法的範例：

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## 雙底線（魔術）方法

- **定義**：特殊方法，名稱前後各有兩個底線（例如 `__init__`、`__len__`、`__str__`、`__eq__`）。Python 內部使用它們來執行內建操作。

- **沒有自訂特殊方法時的行為**：Python 不會推斷內建操作應如何使用自訂物件的屬性。它會使用繼承的預設行為（如果有），並對不支援的操作引發 `TypeError`。

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **自訂方法改變的行為**：`__len__()` 讓 `len()` 傳回頁數而非引發錯誤。`__str__()` 用可讀摘要取代預設表述。`__eq__()` 讓 `==` 比較頁數，而非檢查兩個名稱是否指向同一物件。

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **間接呼叫雙底線方法**：你不需要直接呼叫雙底線方法。當特定操作發生時，Python 會自動呼叫它們。這些操作包括：

  - **算術運算如加法、減法、乘法、除法等**。加法會呼叫 `__add__()`，減法呼叫 `__sub__()`，乘法呼叫 `__mul__()`，除法呼叫 `__truediv__()`。
        
  - **字串運算如串接、重複、格式化和轉換為文字**。串接呼叫 `__add__()`，重複呼叫 `__mul__()`，格式化呼叫 `__format__()`，文字轉換呼叫 `__str__()` 和 `__repr__()`，等等。
        
  - **比較運算如相等、小於、大於等**。相等檢查呼叫 `__eq__()`，小於呼叫 `__lt__()`，大於呼叫 `__gt__()`，等等。
        
  - **迭代操作，例如讓物件可被迭代並前進到下一個項目**。`__iter__()` 被呼叫以傳回迭代器，`__next__()` 用來取得下一個項目。

## 實際範例：購物車

- **帶有雙底線方法的購物車類別**：允許新增、移除、迭代和檢查內容，具備內建行為。

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## 物件協同運作

- **將物件作為引數傳遞**：物件可以像數字或字串一樣傳給其他類別的建構式。

- **在屬性中儲存物件**：一個物件可以儲存在另一個物件的屬性中。你可以透過串鏈點記法呼叫該屬性的方法，例如 `receiver.inbox.receive_email(email)`。

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## 使用日期和時間

- **取得目前日期和時間**：呼叫 `datetime.datetime.now()` 會傳回目前日期和時間的 `datetime` 物件。

- **在實體上儲存時間戳記**：在 `__init__()` 中呼叫 `datetime.datetime.now()` 並將結果指定給屬性，以記錄物件建立的時間。

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **使用 `strftime()` 格式化**：`strftime()` 方法將 `datetime` 物件轉成字串，使用格式碼：`%Y` 表示四位數年份，`%m` 表示月份，`%d` 表示日期，`%H` 表示小時（24 小時制），`%M` 表示分鐘，`%S` 表示秒數。其他字元如 `-`、`/`、`:` 或空格會保留為字面分隔符。

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
