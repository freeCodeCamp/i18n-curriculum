# --description--

现在你需要将每个温度与其标签配对。

`map()` 函数可以接受多个可迭代对象。每次调用时，它会将每个可迭代对象中的一项传递给函数，因此函数需要为每个可迭代对象设置一个参数：

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

创建一个名为 `report` 的变量。将传入 `map()` 的结果赋值给它，传入的参数包括一个 lambda 函数、`temperatures` 和 `difference_labels`，并用 `list()` 包裹。lambda 函数应接受两个参数，`temperature` 和 `difference_label`，并返回 `f'{temperature} °C ({difference_label})'`。

然后，打印 `report`，而不是 `difference_labels`。
