# --description--

이 실습에서는 큐 클래스를 만드세요. 큐는 FIFO(선입선출) 원칙을 따릅니다: 요소는 큐의 뒤에 추가되고 앞에서 제거됩니다.

**목표:** 아래 사용자 스토리를 충족하고 모든 테스트를 통과하여 실습을 완료하세요.

**사용자 스토리:**

1. `Queue`라는 이름의 클래스를 정의하세요. `Queue`의 새 인스턴스는 비어 있어야 합니다.

1. `Queue` 클래스는 다음 메서드를 가져야 합니다:

   - `enqueue`: 요소를 받아 큐의 뒤에 추가합니다.
   - `dequeue`: 큐의 앞에 있는 요소를 제거하고 반환합니다. 큐가 비어 있으면 `None`을 반환해야 합니다.
   - `front`: 큐의 앞에 있는 요소를 제거하지 않고 반환합니다. 큐가 비어 있으면 `None`을 반환해야 합니다.
   - `size`: 큐에 있는 요소의 개수를 반환합니다.
   - `is_empty`: 큐에 요소가 없으면 `True`, 그렇지 않으면 `False`를 반환합니다.

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
