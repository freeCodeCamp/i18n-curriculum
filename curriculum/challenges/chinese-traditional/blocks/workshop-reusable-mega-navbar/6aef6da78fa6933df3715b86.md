# --description--

最後要做的是在點擊 `Apps` 按鈕時更新 `isOpen` 狀態。

在 React 中，你透過將函式傳給元素上的事件屬性來回應事件。這些屬性使用駝峰式命名，因此點擊事件是用 `onClick` 來處理：

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

注意 `onClick` 接收一個函式。React 每次按鈕被點擊時都會呼叫該函式。用新值呼叫設值函式會更新狀態，React 隨後會用該新值重新算繪組件。

要在 `true` 和 `false` 之間切換布林值狀態，你可以用邏輯非 (`!`) 運算子將目前值取反後傳給設值函式。

為 `button` 元素添加一個 `onClick` 屬性。給它一個箭頭函式，該函式呼叫 `setIsOpen` 並傳入 `isOpen` 的相反值。

點擊 `Apps` 按鈕以開啟和關閉 `sub-menu`。

這樣，你的 `Navbar` 組件就完成了！

# --hints--

點擊 `Apps` 按鈕時，應將其 `aria-expanded` 屬性設為 `"true"`，並將 `sub-menu--open` 類別加入 `sub-menu`。

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

再次點擊 `Apps` 按鈕時，應將其 `aria-expanded` 屬性設回 `"false"`，並從 `sub-menu` 移除 `sub-menu--open` 類別。

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
