# --description--

現在，也要在電子郵件列表中顯示時間戳記。更新 `__str__` 方法，在主旨後面加上 ` | Time: `，接著是格式為 `'%Y-%m-%d %H:%M'` 的時間戳記：

```md
[status] From: sender | Subject: subject | Time: time
```

為了讓 `Time` 行對齊，將主旨以寬度 `15` 左對齊。寬度只是最小值，所以較長的主旨仍會完整列印並將 `Time` 推開。為避免這種情況，先將主旨切片為前 `15` 個字元再格式化。

例如，主旨較短和較長的電子郵件會是：

```md
[Unread] From: Alice      | Subject: Hello           | Time: 2025-01-15 09:30
[Unread] From: Alice      | Subject: Quarterly budge | Time: 2025-01-15 09:30
```


主旨長度超過 `15` 個字元時，應截取前 `15` 個字元。

```js
({
    test: () => runPython(`
        import datetime
        _email = Email(User('Alice'), User('Bob'), 'Quarterly budget review', 'See you there.')
        _email.timestamp = datetime.datetime(2025, 1, 15, 9, 30)
        _email.read = True
        assert str(_email) == '[Read  ] From: Alice      | Subject: Quarterly budge | Time: 2025-01-15 09:30'
    `)
})
```

```py
import datetime

class Email:
    def __init__(self, sender, receiver, subject, body):
        self.sender = sender
        self.receiver = receiver
        self.subject = subject

        self.read = True

        print(f"{'Body:':<10}{self.body}")
        print(f"{'':-^29}\n")

    def __str__(self):
        status = 'Read' if self.read else 'Unread'

class User:

    def send_email(self, receiver, subject, body):

class Inbox:
    def __init__(self):
        self.emails = []

        self.emails.append(email)

    def list_emails(self):
        if not self.emails:
            print('Your inbox is empty.\n')
            return
        print('\nYour Emails:')
        for i, email in enumerate(self.emails, start=1):
            print(f'{i:>2}. {email}')

    def read_email(self, index):
        if not self.emails:
            print('Inbox is empty.\n')
            return

        if actual_index < 0 or actual_index >= len(self.emails):
            print('Invalid email number.\n')
            return
        self.emails[actual_index].display_full_email()

    def delete_email(self, index):
        if not self.emails:
            print('Inbox is empty.\n')
            return
        actual_index = index - 1
        if actual_index < 0 or actual_index >= len(self.emails):
            print('Invalid email number.\n')
            return
```
