# --description--

Im Moment springt der Aufzug direkt zu jedem Stockwerk. Ein echter Aufzug bewegt sich jeweils ein Stockwerk nach dem anderen, bis er sein Ziel erreicht.

Nachdem Sie `target` ausgegeben haben, erstellen Sie eine verschachtelte `while`-Schleife, die so lange läuft, wie `current_floor` nicht gleich `target` ist. Verwenden Sie darin eine `if`-Anweisung, um zu prüfen, ob `current_floor` kleiner als `target` ist. Falls ja, erhöhen Sie `current_floor` um `1`. Andernfalls verringern Sie `current_floor` um `1`.

Jede Iteration bringt den Aufzug ein Stockwerk näher an `target`, sodass `current_floor` schließlich gleich `target` wird und die verschachtelte Schleife stoppt.
