# --description--

التكرار هو تقنية تستدعي فيها الدالة نفسها. كل استدعاء يعمل على نسخة أصغر من المشكلة الأصلية حتى يصل إلى شرط يوقف التكرار. يُسمى هذا الشرط الذي يوقف التكرار بالحالة الأساسية.

يمكن للدوال المتكررة حل مشكلات ذات عمق غير معروف، مثل التنقل في شجرة الملفات. كما يمكنها أداء مهام أبسط، مثل العد التنازلي من رقم معين.

إليك دالة باسم `recursive_countdown` تقبل رقمًا وتطبعه:

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

استدعاء الدالة يطبع `5`، لكنه لا يبدأ العد التنازلي بعد. قبل أن تستدعي الدالة نفسها، يجب تعريف الحالة الأساسية. بدون حالة أساسية يمكن الوصول إليها، ستستمر الدالة في استدعاء نفسها. في النهاية، توقف Python الاستدعاءات وترجع خطأ `RecursionError`.

لهذا العد التنازلي، يجب أن تتوقف الدالة عندما يكون `number` أقل من `1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

عبارة `if` هي الحالة الأساسية. عندما يكون `number` أقل من `1`، ينهي `return` استدعاء الدالة ذلك.

لا تزال الدالة بحاجة إلى حالة متكررة. الحالة المتكررة تستدعي الدالة مرة أخرى بمعلمة تحركها نحو الحالة الأساسية. للعد التنازلي، استدعِ `recursive_countdown` مع `number - 1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

هذا يطبع الأرقام `5`، `4`، `3`، `2`، و`1`.

يتغير موضع الاستدعاء المتكرر عند طباعة الأرقام. إذا جاء استدعاء `print()` بعد الاستدعاء المتكرر، تطبع الدالة الأرقام بترتيب تصاعدي:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

هذا يطبع الأرقام `1`، `2`، `3`، `4`، و`5`. لفهم السبب، تحتاج إلى فهم مكدس الاستدعاءات.

مكدس الاستدعاءات هو هيكل بيانات من نوع آخر داخل أولاً، خارج أولاً تستخدمه Python لتتبع استدعاءات الدوال النشطة. عند استدعاء دالة، تضيف Python إطارًا لذلك الاستدعاء في أعلى المكدس. يحتوي الإطار على معلومات مثل معلمات الدالة والمتغيرات المحلية.

انظر هذا الإصدار من العد التنازلي:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

الناتج هو:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

يتوقف استدعاء `recursive_countdown(3)` مؤقتًا عندما يستدعي `recursive_countdown(2)`. يتوقف الاستدعاء مع `2` مؤقتًا عندما يستدعي الدالة مع `1`، ويتوقف الاستدعاء مع `1` مؤقتًا عندما يستدعي الدالة مع `0`.

يصل الاستدعاء مع `0` إلى الحالة الأساسية ويرجع. تزيل Python ذلك الاستدعاء من أعلى المكدس، فيستأنف الاستدعاء مع `1` بعد استدعائه المتكرر. ثم تستأنف الاستدعاءات المتبقية وتُرجع بترتيب عكسي: `1`، `2`، و`3`.

كل دالة متكررة تحتاج إلى حالة أساسية وحالة متكررة تتحرك نحوها. عندما ترجع الحالة الأساسية، تستأنف الاستدعاءات السابقة بترتيب آخر داخل أولاً، خارج أولاً.
