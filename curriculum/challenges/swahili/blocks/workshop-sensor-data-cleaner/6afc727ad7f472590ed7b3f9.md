# --description--

Kabla ya kufanya kazi na vipimo, unahitaji kuondoa misimbo ya makosa.

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

Tengeneza kigezo kinachoitwa `valid_readings`. Weka thamani yake kuwa matokeo ya kupitisha `filter()` kitendakazi cha lambda na `readings`. Kitendakazi cha lambda kinapaswa kuchukua kigezo kinachoitwa `reading` na kukagua kama `reading` si sawa na `-999`.

Kisha, chapisha `valid_readings` badala ya `readings`.
