# --description--

Come hai imparato nella lezione precedente, un modulo è un file Python che raggruppa codice correlato, così puoi riutilizzarlo in altri file Python.

Puoi anche scrivere i tuoi moduli e importarli nei tuoi script. Creare i propri moduli è un ottimo modo per organizzare il codice. Invece di avere un file molto lungo, puoi dividere il codice in file più piccoli, dove ognuno raggruppa codice correlato, e poi importarli dove ti servono.

Per esempio, supponi di aver creato un file `temperature.py` con due funzioni per convertire le temperature e una chiamata a funzione per verificare che una di esse funzioni:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

Se esegui questo file direttamente, questo è l'output:

```md
212.0
```

Ora, supponi di creare un altro file chiamato `main.py` nella stessa cartella di `temperature.py`. Per usare le funzioni dal tuo modulo locale, lo importi usando il nome del modulo senza l'estensione `.py`:

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

Se esegui il file `main.py`, questo è l'output:

```md
212.0
100.0
```

Quando `temperature` viene importato, Python esegue tutto il codice in `temperature.py` dall'inizio alla fine. Ecco perché viene stampato `212.0`, anche se `main.py` chiama solo `fahrenheit_to_celsius()`. Codice come questo di verifica è solitamente qualcosa che vuoi eseguire solo quando esegui il file direttamente, non ogni volta che viene importato.

Per controllare questo, puoi usare un modo comune in Python:

```python
if __name__ == '__main__':
    # Code
```

`__name__` è una variabile integrata speciale in Python.

Quando un file Python viene eseguito direttamente, Python imposta il valore di questa variabile sulla stringa `__main__`.

Ma se il file Python viene importato come modulo in un altro script Python, il valore della variabile `__name__` viene impostato sul nome di quel modulo (di solito il nome del file senza l'estensione `.py`).

Ecco perché spesso trovi questa condizione negli script Python. Contiene il codice che vuoi eseguire **solo se** lo script Python sta girando come programma principale. Se lo script viene importato come modulo, il codice dentro quel blocco non viene eseguito.

Questo è utile perché permette agli script Python di avere due scopi. Possono essere eseguiti direttamente per eseguire la loro logica principale, oppure possono essere importati in un altro modulo senza eseguire la loro logica principale.

Ecco il file `temperature.py` aggiornato per usare questo modo. Stampa anche il valore di `__name__`, così puoi vedere come cambia:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

Se esegui questo file direttamente, Python imposta `__name__` su `'__main__'`, quindi la condizione è `True` e il codice dentro il blocco `if` viene eseguito. Questo è l'output:

```md
The value of __name__ is: __main__
212.0
```

Se invece esegui il file `main.py`, questo è l'output:

```md
The value of __name__ is: temperature
100.0
```

La chiamata a `print()` fuori dal blocco `if` viene comunque eseguita quando `temperature` viene importato, e mostra che il valore di `__name__` ora è `temperature`, il nome del modulo.

Ma siccome `__name__` non è uguale a `'__main__'`, il codice dentro il blocco `if` non viene eseguito, quindi `212.0` non viene stampato. L'unico altro output è `100.0`, che viene dalla chiamata a funzione in `main.py`.
