# --description--

Has manejado con éxito tanto los estados de éxito como de error. Pero, ¿qué pasa si hay código que quieres ejecutar sin importar lo que ocurra? Ahí es donde entra el bloque `finally`.

```js
try {
  // Code that might throw an error
} catch (err) {
  // Code to handle the error
} finally {
  // Code to run regardless of success or failure
}
```

Justo debajo de tu bloque `catch`, agrega un bloque `finally`. Dentro de él, asigna la propiedad `value` de `bookInput` a una cadena vacía (`""`) para limpiar el campo de entrada y que el usuario pueda escribir inmediatamente una nueva búsqueda.
