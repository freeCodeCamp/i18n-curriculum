# --description--

エレベーターはリクエストが残っている限りサービスを続ける必要があります。`while`ループは条件が真である限り繰り返すので、これに最適です。構文の復習はこちらです：

```py
while condition:
    # code to repeat
    ...
```

空でないリストは真とみなされ、空のリストは偽とみなされるため、リストをループの条件として使い、リストが空になるまでループを実行できます。

`requests`が空でない限り実行される`while`ループを作成してください。ループ内では、`pop(0)`を使って`requests`の最初のリクエストを取り出し、`target`という変数に代入してください。その後、`target`を出力してください。

`pop(0)`は毎回リストを短くするので、最終的にリストは空になりループはストップします。これがなければ条件は決して偽にならず、ループは永遠に続いてしまいます。
