## 动态规划简介

- **定义**：动态规划是一种算法技术，通过将复杂问题分解为更简单的子问题并存储结果，避免重复计算。
- **重叠子问题**：在解决大问题时，多个子问题会重复出现。我们通过存储它们的解来避免重复计算。
- **最优子结构**：问题的最优解包含其子问题的最优解。这意味着我们可以通过组合较小部分的最优解来构建最佳解。

## 爬楼梯问题

动态规划的一个经典例子是计算以正整数步数 `n` 到达楼梯顶端的不同方法数，每次可以迈 1 步或 2 步：

- **朴素递归**：因为到达第 `n` 级台阶的方法数是到达第 `n - 1` 级和第 `n - 2` 级方法数之和，直接递归解法会重复计算相同的子问题。例如，计算第 `5` 级时会两次计算第 `3` 级，三次计算第 `2` 级。这导致时间复杂度呈指数级 `O(2^n)`，调用栈空间为 `O(n)`。

## 动态规划方案

动态规划通过两种主要方法消除冗余计算：

- **记忆化（自顶向下方法）**：记忆化将函数调用结果存储在缓存（如字典）中，当遇到相同子问题时返回缓存结果：

```py
def climb_stairs_memo(n, memo={}):
    """Dynamic programming with memoization"""
    # Check if we've already calculated this value
    if n in memo:
        return memo[n]  # Return cached result - O(1) lookup!
    
    # Base cases
    if n <= 2:
        return n
    
    # Calculate once and store in memo for future use
    memo[n] = climb_stairs_memo(n-1, memo) + climb_stairs_memo(n-2, memo)
    return memo[n]
```

在初始缓存为空的情况下，记忆化将时间复杂度降低到线性 `O(n)`，需要 `O(n)` 空间来保存缓存的子问题结果和递归调用栈。

- **表格法（自底向上方法）**：表格法通过迭代从最小的子问题开始构建解决方案，直到目标，过程中将中间结果存储在列表中：

```py
def climb_stairs_tabulation(n):
    """Dynamic programming with tabulation"""
    if n <= 2:
        return n
    
    # Create array to store results for all steps from 0 to n
    dp = [0] * (n + 1)
    dp[1] = 1  # 1 way to reach step 1
    dp[2] = 2  # 2 ways to reach step 2
    
    # Build up the solution iteratively
    for i in range(3, n + 1):
        # Ways to reach step i = ways to reach (i-1) + ways to reach (i-2)
        dp[i] = dp[i-1] + dp[i-2]
    
    return dp[n]
```

表格法运行时间为 `O(n)`，使用 `O(n)` 空间存储列表，关键优势是避免了递归调用栈的增长。

- **常量空间表格法优化**：因为每个新步骤只依赖前两个值，完整表格可以用两个变量替代，分别保存最近两个计数：

```py
def climb_stairs_optimized(n):
    if n <= 2:
        return n
    
    prev2, prev1 = 1, 2  # Only store the last two values
    for i in range(3, n + 1):
        current = prev1 + prev2
        prev2, prev1 = prev1, current
    return prev1
```

将每个算术操作视为常量时间，每个存储计数视为一个单位空间，这种优化保持了 `O(n)` 时间复杂度，同时将辅助空间复杂度降低到 `O(1)`。

## 实际示例：零钱兑换问题

找零问题是一个经典的优化问题，要求用最少的硬币数凑出目标金额：

- **算法**：该算法使用标签法，通过创建一个大小为 `amount + 1` 的数组 `dp`，并初始化为无穷大（`float('inf')`）来表示初始不可达的值。基本情形是 `dp[0] = 0`，因为凑成金额 `0` 不需要任何硬币。对于每个从 `1` 到 `amount` 的金额 `i`，算法在所有满足条件的硬币面额（`coin <= i`）中，取 `dp[i - coin] + 1` 的最小值。如果 `dp[amount]` 仍然是无穷大，说明无法凑出目标金额，则返回 `-1`：

```py
def min_coins(amount, coins):
    """Find minimum number of coins needed to make the given amount"""
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0  # Base case: 0 coins needed for amount 0
    
    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)
    
    return dp[amount] if dp[amount] != float('inf') else -1
```

对于面额 `[1, 3, 4]` 和目标 `6`，算法计算 `dp[6] = min(dp[5] + 1, dp[3] + 1, dp[2] + 1) = 2`，得出最优组合为两枚硬币（`3 + 3`）。

- **复杂度**：算法对每个子金额检查所有面额，时间复杂度为 `O(amount * number_of_coins)`，DP 数组的辅助空间复杂度为 `O(amount)`。

## 使用动态规划的实际应用

- **路径优化**：GPS 系统使用动态规划算法来查找位置之间的最短路径。
- **文本处理**：拼写检查和自动完成功能通常依赖动态规划来计算单词之间的编辑距离。
- **金融建模**：投资策略和投资组合优化经常采用动态规划技术。
- **资源分配**：背包问题及其变体出现在调度、预算和资源管理中。

## 何时使用动态规划

你应该在以下情况下考虑使用动态规划：

- 问题可以分解为重叠的子问题。
- 问题具有最优子结构。
- 朴素的递归解法会涉及重复计算。
- 你需要以空间复杂度为代价来优化时间复杂度。
