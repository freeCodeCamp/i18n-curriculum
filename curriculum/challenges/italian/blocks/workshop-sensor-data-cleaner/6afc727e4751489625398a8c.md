# --description--

Ora trasformerai le differenze in etichette di testo come `+3.6 °C`. I numeri positivi vengono stampati senza segno, quindi dovrai aggiungere un `+` davanti a loro.

Per includere solo gli elementi che soddisfano una condizione, puoi aggiungere un `if` finale alla fine di una list comprehension:

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

Crea una variabile chiamata `difference_labels`. Usa una list comprehension per assegnarle una lista contenente `f'+{difference} °C'` per ogni `difference` in `differences`, ma solo se `difference` è maggiore di `0`.

Poi, stampa `difference_labels` invece di `differences`.

Nel terminale vedrai solo 3 etichette per 7 temperature. Un `if` finale esclude gli elementi che non soddisfano la condizione, quindi non c'è modo di sapere a quale temperatura appartiene ogni etichetta. Lo sistemerai nel passaggio successivo.
