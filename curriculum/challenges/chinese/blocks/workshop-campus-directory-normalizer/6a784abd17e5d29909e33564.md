# --description--

目前，`program` 通过 `departmentId` 知道它属于哪个部门，但部门还不知道哪些程序属于它。
将每个 `program.id` 推入 `departmentsById[departmentId].programIds`。

这创建了一个双向关系：部门可以通过 `programIds` 查找它的程序，每个程序可以通过 `departmentId` 查找它的部门，而不需要任何一个对象保存另一个的完整数据。

在添加程序 ID 之前，删除上一步中的 `console.log(programsById[program.id])`。

在 `departmentData.programs` 循环结束后，在控制台记录 `departmentsById[departmentId]`。
