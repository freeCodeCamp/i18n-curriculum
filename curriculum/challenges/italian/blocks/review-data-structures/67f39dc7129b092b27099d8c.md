## Algoritmi e notazione Big O

- **Algoritmi**: Un insieme di istruzioni non ambigue per risolvere un problema o svolgere un’attività. Gli algoritmi devono terminare in un numero finito di passaggi e ogni passaggio deve essere preciso e non ambiguo.

- **Notazione Big O**: Descrive un limite superiore asintotico sull'utilizzo delle risorse di un algoritmo all'aumentare della dimensione dell'input. Big O misura questa tendenza generale di crescita separatamente dal fatto che si stia considerando il caso migliore, medio o peggiore, ignorando fattori costanti e termini minori.

### Complessità temporali comuni

- **O(1) - Tempo costante**: L’algoritmo impiega lo stesso tempo indipendentemente dalla dimensione dell’input.

```python
def check_even_or_odd(number):
    if number % 2 == 0:
        return 'Even'
    else:
        return 'Odd'
```

- **O(log n) - Tempo logaritmico**: Un limite superiore sul tempo di esecuzione che cresce al massimo in modo logaritmico con la dimensione dell'input. Quando il limite è stretto, l'algoritmo funziona in tempo logaritmico. Questo si verifica comunemente quando la dimensione del problema viene ripetutamente ridotta di una frazione costante, come nella ricerca binaria.

- **O(n) - Tempo lineare**: Un limite superiore sul tempo di esecuzione che cresce al massimo in modo lineare con la dimensione dell'input. Quando il limite è stretto, il tempo di esecuzione cresce proporzionalmente alla dimensione dell'input.

```python
for grade in grades:
    print(grade)
```

- **O(n log n) - Tempo log-lineare**: Comune negli ordinamenti efficienti divide-et-impera. Merge Sort ha complessità nel caso peggiore O(n log n). Quick Sort ha complessità media O(n log n), ma nel caso peggiore è O(n²).

- **O(n²) - Tempo quadratico**: Un limite superiore sul tempo di esecuzione che cresce al massimo in modo quadratico con la dimensione dell'input. Quando il limite è stretto, il tempo di esecuzione cresce proporzionalmente al quadrato della dimensione dell'input. Questo si verifica in loop annidati dove ogni loop esegue n iterazioni.

```python
for i in range(n):
    for j in range(n):
        print("Hello, World!")
```

- **O(2ⁿ) - Tempo esponenziale**: Un limite superiore esponenziale sul tempo di esecuzione. Quando il limite è stretto, il tasso di crescita è proporzionale a 2ⁿ, che raddoppia ogni volta che n aumenta di uno.

- **O(n!) - Tempo fattoriale**: Un limite superiore fattoriale sul tempo di esecuzione. Quando il limite è stretto, il tasso di crescita è proporzionale a n!, il numero di permutazioni di n elementi distinti.

### Complessità spaziale

- **O(1) - Spazio costante**: L'utilizzo di memoria è limitato da una costante indipendente dalla dimensione dell'input.

- **O(n) - Spazio lineare**: L'utilizzo di memoria cresce al massimo in modo lineare con la dimensione dell'input. Quando il limite è stretto, l'utilizzo di memoria cresce proporzionalmente alla dimensione dell'input.

- **O(n²) - Spazio quadratico**: L'utilizzo di memoria cresce al massimo in modo quadratico con la dimensione dell'input. Quando il limite è stretto, l'utilizzo di memoria cresce proporzionalmente al quadrato della dimensione dell'input.

- **O(2ⁿ) - Spazio esponenziale**: Un limite superiore esponenziale sull'utilizzo di memoria. Quando il limite è stretto, l'utilizzo di memoria cresce proporzionalmente a 2ⁿ.

- **O(n!) - Spazio fattoriale**: Un limite superiore fattoriale sull'utilizzo di memoria. Quando il limite è stretto, l'utilizzo di memoria cresce proporzionalmente a n!.

## Tecniche di risoluzione dei problemi

- **Comprendere il problema**: Leggi più volte l’enunciato del problema. Identifica l’input, l’output atteso e come trasformare l’input in output.

- **Selezione di algoritmo e struttura dati**: Confronta algoritmi alternativi in base ai loro requisiti di tempo e spazio, e scegli strutture dati adatte al problema.

- **Pseudocodice**: Descrizione ad alto livello della logica di un algoritmo indipendente dal linguaggio, che usa un linguaggio scritto comune mescolato a costrutti di programmazione come `IF`, `ELSE`, `FOR` e `WHILE`.

```md
GET original_string
SET reversed_string = ""

FOR EACH character IN original_string:
    ADD character TO THE BEGINNING OF reversed_string

DISPLAY reversed_string
```

- **Implementazione**: Scrivi codice pulito, leggibile e modulare basato sul tuo piano in pseudocodice. Usa strumenti integrati appropriati per attività comuni.

- **Casi limite**: Input specifici e validi che si trovano ai confini di ciò che un algoritmo dovrebbe gestire. Considera e testa sempre i casi limite.

- **Test e perfezionamento**: Testa il tuo codice con gli esempi forniti e i casi limite. Esegui il debug degli errori, verifica i risultati e perfeziona la soluzione per migliorarne chiarezza o efficienza.

## Array

- **Array statici**: Hanno una dimensione fissa impostata alla creazione, con elementi archiviati in memoria contigua. Questa disposizione adiacente consente un accesso indicizzato veloce e in tempo costante (O(1)). Scegli un array statico quando il numero massimo di elementi è noto a priori.

- **Array dinamici**: Possono crescere o ridursi automaticamente durante l'esecuzione del programma. Quando finiscono lo spazio, gestiscono il ridimensionamento allocando un blocco di memoria più grande e copiando gli elementi esistenti.

**Nota:** Python non ha un array statico integrato tradizionale. Le liste Python sono array dinamici.

### Liste Python (array dinamici)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### Complessità temporali per array dinamici

- **Consultare**: O(1)

- **Inserire alla fine**: O(1) in media, O(n) quando è necessario il ridimensionamento

- **Inserire in mezzo**: O(n)

- **Eliminare**: O(n) per il mezzo, O(1) per la fine

## Stack

- **Stack**: Struttura dati Last-In, First-Out (LIFO). Gli elementi si aggiungono e rimuovono solo dalla cima.

- **Operazione push**: Aggiungere un elemento in cima allo stack. Per l'implementazione con lista Python sotto, un push ordinario richiede tempo O(1) e spazio aggiuntivo O(1). Un push che richiede il ridimensionamento può richiedere tempo O(n) e spazio aggiuntivo O(n).

- **Operazione pop**: Rimuovere un elemento dalla cima dello stack. La complessità temporale è tipicamente O(1), e lo spazio aggiuntivo richiesto è solitamente O(1).

```python
# Using Python list as stack
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operations
top_element = stack.pop()  # Returns 3
```

## Code

- **Code**: Struttura dati First-In, First-Out (FIFO) dove gli elementi vengono aggiunti in coda e rimossi dalla testa.

- **Operazione enqueue**: Aggiungere un elemento in coda alla coda. Complessità temporale: O(1), complessità spaziale: O(1).

- **Operazione dequeue**: Rimuovere un elemento dalla testa della coda. Complessità temporale: O(1), complessità spaziale: O(1).

## Liste concatenate

- **Liste concatenate**: Struttura dati lineare in cui ogni nodo contiene dati e un riferimento al nodo successivo. I nodi sono collegati come una catena.

### Liste concatenate singole

- **Struttura**: Ogni nodo contiene dati e un riferimento al nodo successivo.

- **Attraversamento**: Si può muovere solo in avanti dalla testa alla coda.

- **Nodo testa**: Primo nodo della lista, solitamente l'unico nodo accessibile direttamente.

- **Nodo coda**: Ultimo nodo della lista, punta a `None`.

### Implementazione della lista concatenata

- **Classe nodo**: Una classe `Node` annidata rappresenta i singoli nodi. Ogni nodo contiene dati e un riferimento al nodo successivo.

- **Inizializzazione**: Il riferimento `head` inizia come `None` perché la lista non ha nodi. Il riferimento `next` di ogni nuovo nodo inizia come `None` perché non ha ancora un successore.

- **Tracciamento della lunghezza**: Una variabile tiene traccia del numero di nodi nella lista.

- **`is_empty()`**: Verifica se la lista è vuota controllando se `head` è `None`.

- **Aggiunta in coda**: Attraversa dalla testa fino all'ultimo nodo, poi aggiorna il suo riferimento `next` per puntare al nuovo nodo. Se la lista è vuota, il nuovo nodo diventa la testa.

```python
class LinkedList:
    class Node:
        def __init__(self, data):
            self.data = data
            self.next = None

    def __init__(self):
        self.head = None
        self.length = 0

    def is_empty(self):
        return self.head is None

    def append(self, data):
        new_node = self.Node(data)

        if self.is_empty():
            self.head = new_node
        else:
            current = self.head

            while current.next:
                current = current.next

            current.next = new_node

        self.length += 1
```

### Operazioni e complessità temporali

- **Inserimento all'inizio**: O(1)

- **Inserimento alla fine**: O(n) - bisogna attraversare fino alla fine

- **Inserimento in mezzo**: O(n) - bisogna attraversare fino alla posizione

- **Eliminazione dall'inizio**: O(1)

- **Eliminazione dalla fine**: O(n) - bisogna attraversare per trovare il nodo precedente

- **Eliminazione dal mezzo**: O(n) - bisogna attraversare per trovare il nodo

### Inserimento ed eliminazione

- **Inserimento all'inizio**: Crea un nuovo nodo, imposta il suo riferimento `next` alla testa corrente, e aggiorna la testa per puntare al nuovo nodo.

- **Inserimento alla fine**: Attraversa fino all'ultimo nodo e aggiorna il suo riferimento `next` per puntare al nuovo nodo.

- **Inserimento in mezzo**: Attraversa fino al nodo prima della posizione desiderata. Aggiorna il riferimento `next` del nuovo nodo per puntare al nodo successivo, poi aggiorna il riferimento `next` del nodo precedente per puntare al nuovo nodo.

- **Eliminazione dall'inizio**: Aggiorna la testa per puntare al secondo nodo.

- **Eliminazione dalla fine**: Attraversa fino al penultimo nodo e aggiorna il suo riferimento `next` a `None`.

- **Eliminazione dal mezzo**: Trova il nodo prima del nodo da eliminare e aggiorna il suo riferimento `next` per saltare il nodo da eliminare.

- **Rimozione per valore**: Tieni traccia del nodo precedente durante l'attraversamento. Se il nodo da rimuovere è la testa, aggiorna direttamente la testa. Se il valore non viene trovato, ritorna senza modificare la lista o la sua lunghezza. Decrementa la lunghezza solo dopo una rimozione riuscita.

### Complessità spaziale ausiliaria

- **Inserimento all'inizio**: Spazio ausiliario O(1), escluso lo spazio per il nuovo nodo.

- **Inserimento alla fine**: Spazio ausiliario O(1), escluso lo spazio per il nuovo nodo.

- **Inserimento in mezzo**: Spazio ausiliario O(1), escluso lo spazio per il nuovo nodo.

- **Eliminazione dall'inizio**: Spazio ausiliario O(1).

- **Eliminazione dalla fine**: Spazio ausiliario O(1).

- **Eliminazione dal mezzo**: Spazio ausiliario O(1).

### Liste concatenate doppie

- **Struttura**: Ogni nodo contiene dati e due riferimenti: al nodo successivo e al nodo precedente.

- **Attraversamento**: Si può muovere in entrambe le direzioni.

- **Memoria**: Richiede più memoria rispetto alle liste concatenate singole a causa del riferimento extra.

- **Riferimento alla coda**: Mantenere un riferimento all'ultimo nodo permette l'attraversamento inverso usando i riferimenti precedenti.

## Mappe hash e insiemi

### Mappe e mappe hash

- **Tipo astratto di dato (ADT) vs. implementazione**: Un ADT definisce l'*interfaccia*—specificando quali operazioni supporta una struttura dati e come si comporta logicamente. Un'implementazione concreta definisce il meccanismo sottostante, mostrando *come* quelle operazioni sono effettivamente costruite ed eseguite in memoria.

- **Mappa (ADT)**: Un tipo astratto di dato che definisce una collezione di chiavi uniche mappate a valori. Stabilisce le regole su cosa può fare una mappa senza dettare il suo archivio interno.

- **Hash map**: Un'implementazione concreta dell'ADT mappa che usa una funzione hash per calcolare le posizioni di archiviazione in un array sottostante per ricerche rapide.

### Dizionari Python (mappe hash)

```python
# Creating dictionaries
my_dictionary = {
    "A": 1,
    "B": 2,
    "C": 3
}

# Alternative creation
my_dictionary = dict(A=1, B=2, C=3)

# Access and modify
value = my_dictionary["A"]  # 1
my_dictionary["A"] = 4      # Update value
del my_dictionary["A"]      # Remove key-value pair

# Check membership
"C" in my_dictionary

# Get keys, values, items
my_dictionary.keys()
my_dictionary.values()
my_dictionary.items()
```

### Complessità temporali per mappe hash

- **Caso medio**: O(1) per inserimento, recupero, eliminazione

- **Caso peggiore**: O(n) quando si verificano molte collisioni hash

### Complessità spaziali ausiliarie per hash map

- **Inserimento**: Spazio aggiuntivo O(1) per inserimento ordinario. Il ridimensionamento può richiedere spazio aggiuntivo O(n).

- **Ricerca**: Spazio ausiliario O(1).

- **Eliminazione**: Spazio ausiliario O(1).

### Insiemi

- **Insiemi**: Collezioni non ordinate di elementi unici. Non sono ammessi duplicati, non si mantiene un ordine specifico.

- **Elementi di un set**: I set possono contenere numeri, stringhe e tuple contenenti solo numeri e stringhe. Liste, dizionari e altri set non possono essere elementi di un set. Una tupla contenente una lista non può essere elemento di un set, anche se la tupla stessa è immutabile.

```python
# Creating sets
numbers = {1, 2, 3, 4}
empty_set = set()  # Must use set(), not {}

# Add and remove elements
numbers.add(5)
numbers.remove(4)      # Raises KeyError if not found
numbers.discard(4)     # No error if not found

# Remove and return an arbitrary element
numbers.pop()

# Remove all elements
numbers.clear()

# Get the number of elements
len(numbers)
```

### Operazioni sui set

```python
set_a = {1, 2, 3, 4}
set_b = {2, 3, 4, 5, 6}

# Union, intersection, difference, symmetric difference
set_a.union(set_b)                  # or set_a | set_b
set_a.intersection(set_b)           # or set_a & set_b
set_a.difference(set_b)             # or set_a - set_b
set_a.symmetric_difference(set_b)   # or set_a ^ set_b

# Subset and superset checks
set_a.issubset(set_b)
set_a.issuperset(set_b)
set_a.isdisjoint(set_b)

# Membership testing
5 in numbers
```

### Complessità temporali per insiemi

- **Caso medio**: O(1) per aggiungere, rimuovere, testare appartenenza

- **Caso peggiore**: O(n) a causa di collisioni hash

- **Ricerca della lunghezza**: O(1) usando `len()`.

### Complessità spaziali ausiliarie per set

- **Inserimento**: Spazio aggiuntivo O(1) per inserimento ordinario. Il ridimensionamento può richiedere spazio aggiuntivo O(n).

- **Ricerca**: Spazio ausiliario O(1).

- **Eliminazione**: Spazio ausiliario O(1).

- **Ricerca della lunghezza**: Spazio ausiliario O(1).

## Collisioni hash

- **Collisione hash**: Chiavi diverse possono produrre lo stesso valore hash. In una tabella hash, le collisioni si verificano anche quando valori hash diversi mappano allo stesso indice dell'array. Gli elementi che condividono un indice devono essere gestiti con una strategia di risoluzione delle collisioni.

- **Strategie di risoluzione delle collisioni**:

  - **Concatenamento**: Ogni indice dell'array punta a una lista concatenata che archivia tutti gli elementi che mappano allo stesso bucket.

  - **Open addressing**: Cerca il prossimo indice disponibile nell'array usando una sequenza predefinita quando si verifica una collisione.

## Quando usare ogni struttura dati

- **Liste**: Quando hai bisogno di accesso ordinato e indicizzato e non conosci la dimensione in anticipo.

- **Stack**: Per operazioni LIFO (funzionalità annulla, valutazione di espressioni, backtracking).

- **Code**: Per operazioni FIFO (pianificazione attività, ricerca in ampiezza).

- **Liste concatenate**: Quando servono inserimenti/eliminazioni frequenti all'inizio, dimensione sconosciuta, nessun accesso casuale necessario.

- **Hash map**: Per ricerche rapide chiave-valore, conteggio occorrenze, caching.

- **Set**: Per verificare unicità, operazioni matematiche su insiemi, rimuovere duplicati.
