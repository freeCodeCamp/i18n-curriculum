# --description--

現在將每個程式存放在 `programsById` 中，並以其自身的 id 作為鍵。

儲存的程式應該保有原本的屬性，並新增一個 `departmentId` 屬性來連結到它的部門。物件展開語法（`...`）會將物件自身可列舉的屬性複製到一個新物件中，你可以在那裡添加額外的屬性。

先從你的程式碼中移除 `console.log(program)` 這一行。

接著，為 `programsById[program.id]` 指定一個物件，該物件展開 `program` 並加入 `departmentId`。

最後，將 `programsById[program.id]` 輸出到主控台，以檢查儲存的物件。
