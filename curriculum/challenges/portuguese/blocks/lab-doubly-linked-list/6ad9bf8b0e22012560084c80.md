# --description--

Neste laboratório, você vai construir uma lista ligada duplamente, onde cada nó mantém uma referência tanto para o próximo quanto para o nó anterior na lista.

**Objetivo:** Cumprir as user stories abaixo e fazer todos os testes passarem para completar o laboratório.

**Histórias de Usuário:**

1. Você deve ter uma classe chamada `DoublyLinkedList`.
1. `DoublyLinkedList` deve ter uma classe aninhada chamada `Node`, cujo método `__init__` deve:
   - receber um parâmetro `element` e um parâmetro opcional `previous` que tem `None` como padrão.
   - definir o atributo `element` com o valor do parâmetro `element`.
   - definir o atributo `previous` com o valor do parâmetro `previous`.
   - definir o atributo `next` como `None`.
1. O método `__init__` de `DoublyLinkedList` deve definir o atributo `length` como `0` e os atributos `head` e `tail` como `None`.
1. `DoublyLinkedList` deve ter um método `is_empty` que retorna `True` se a lista não tiver nós e `False` caso contrário.
1. `DoublyLinkedList` deve ter um método `add` que recebe um `element` e:
   - cria um novo `Node` contendo esse `element` e o adiciona ao final da lista.
   - define o atributo `previous` do novo nó para o nó que era o tail antes da adição, ou `None` se a lista estava vazia.
   - atualiza o `head` (quando a lista estava vazia), o `tail` e o `length` da lista.
   - não percorre a lista para encontrar seu final.
1. `DoublyLinkedList` deve ter um método `remove` que recebe um `element` e:
   - remove todos os nós cujo `element` seja igual ao `element` dado.
   - mantém as referências `next` e `previous` dos nós restantes corretamente ligadas.
   - atualiza o `head`, o `tail` e o `length` da lista quando necessário.
   - deixa a lista inalterada se nenhum nó corresponder ou se a lista estiver vazia.
1. `DoublyLinkedList` deve ter um método `reverse` que inverte a ordem dos nós no lugar.
1. `DoublyLinkedList` deve ter um método `to_list` que retorna uma lista dos elementos na lista ligada, do `head` ao `tail`.

class DoublyLinkedList:
    class Node:
        def __init__(self, element, previous=None):
            self.element = element
            self.previous = previous
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None
        self.tail = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element, self.tail)
        if self.is_empty():
            self.head = node
        else:
            self.tail.next = node
        self.tail = node
        self.length += 1

    def remove(self, element):
        current_node = self.head
        while current_node is not None:
            next_node = current_node.next
            if current_node.element == element:
                if current_node.previous is not None:
                    current_node.previous.next = current_node.next
                else:
                    self.head = current_node.next
                if current_node.next is not None:
                    current_node.next.previous = current_node.previous
                else:
                    self.tail = current_node.previous
                self.length -= 1
            current_node = next_node

    def reverse(self):
        current_node = self.head
        while current_node is not None:
            current_node.previous, current_node.next = current_node.next, current_node.previous
            current_node = current_node.previous
        self.head, self.tail = self.tail, self.head

    def to_list(self):
        elements = []
        current_node = self.head
        while current_node is not None:
            elements.append(current_node.element)
            current_node = current_node.next
        return elements
