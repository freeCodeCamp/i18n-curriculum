# --description--

Usuários que tenham pelo menos `18` anos mas menos de `21` podem reservar ingressos, mas somente quando o `show_time` não for `Evening`.

O operador de desigualdade (`!=`) verifica se dois valores não são iguais. Ele avalia para `True` quando os valores são diferentes e para `False` quando são iguais:

```py
day = 'Monday'
print(day != 'Sunday') # True
print(day != 'Monday') # False
```

Quando `and` e `or` são usados na mesma expressão, `and` tem precedência maior que `or`. Isso significa que as condições unidas por `and` são agrupadas, e o resultado desse grupo é então combinado com a condição `or`:

```py
has_key = True
knows_code = False
is_daytime = False

print(has_key or knows_code and is_daytime) # True
```

No exemplo acima, `knows_code and is_daytime` é avaliado primeiro, resultando em `False`. A expressão inteira então se torna `has_key or False`, que é `True`.

Atualize a condição da `if age >= 21:` linha. Use o operador `and` para construir uma expressão verificando se `age` é maior ou igual a `18` e `show_time` não é `Evening`. Depois use o operador `or` para combinar essa expressão com a condição existente. Não crie novas variáveis.
