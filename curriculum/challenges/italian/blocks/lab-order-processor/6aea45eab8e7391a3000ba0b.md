# --description--

In questo laboratorio, elaborerai ordini di e-commerce e gestirai gli errori che si presentano lungo il percorso.

**Obiettivo:** Completa le storie utente qui sotto e fai passare tutti i test per completare il laboratorio.

I dati con cui lavorerai hanno la stessa struttura delle variabili nel codice iniziale:

- Un **ordine** è un dizionario con:
  - `order_id`: un intero che identifica l'ordine.
  - `products`: una lista di dizionari, ciascuno con un `product_id` e la `quantity` richiesta.
  - `discount_code`: una stringa, o `None` se l'ordine non ha un codice sconto.
  - `status`: una stringa che descrive lo stato dell'ordine.
- Una **cronologia degli ordini** è una lista di ordini.
- Un **inventario** è un dizionario le cui chiavi sono gli ID dei prodotti e i cui valori sono dizionari con il nome del `product`, la `quantity` in stock e il `price` di una singola unità.
- I **codici sconto** sono un dizionario le cui chiavi sono i codici e i cui valori sono le percentuali di sconto, per esempio `0.1` per uno sconto del 10%.

**Storie utente:**

1. Dovresti avere una funzione chiamata `find_order` con due parametri: un ID ordine e una cronologia degli ordini, in questo ordine.
1. `find_order` dovrebbe:
   - restituire l'ordine dalla cronologia data il cui `order_id` è uguale all'ID ordine fornito.
   - sollevare un `ValueError` con il messaggio `Order ID {order_id} not found in order history.` se nessun ordine corrisponde all'ID ordine fornito.
1. Dovresti avere una funzione chiamata `verify_availability` con due parametri: un ordine e un inventario, in questo ordine.
1. `verify_availability` dovrebbe:
   - sollevare un `ValueError` con il messaggio `Product ID {product_id} is not in the inventory.` se un prodotto nell'ordine manca nell'inventario dato.
   - sollevare un `ValueError` con il messaggio `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.` se la quantità richiesta per un prodotto è maggiore della quantità disponibile nell'inventario dato.
   - non sollevare nulla se ogni prodotto nell'ordine è disponibile nella quantità richiesta.
1. Dovresti avere una funzione chiamata `get_discount_rate` con due parametri: un ordine e i codici sconto, in questo ordine.
1. `get_discount_rate` dovrebbe:
   - restituire `0.0` se il `discount_code` dell'ordine è `None`.
   - sollevare un `ValueError` con il messaggio `Invalid discount code: {discount_code}.` se il `discount_code` dell'ordine non è uno dei codici sconto dati.
   - restituire la percentuale del `discount_code` dell'ordine altrimenti.
1. Dovresti avere una funzione chiamata `process_order` con quattro parametri: l'ID dell'ordine da processare, una cronologia degli ordini, un inventario e i codici sconto, in questo ordine.
1. `process_order` dovrebbe usare `find_order`, `verify_availability` e `get_discount_rate` per processare l'ordine, e gestire il `ValueError` che sollevano in modo che chiamare `process_order` non sollevi mai un errore.
1. Quando nessun ordine nella cronologia data corrisponde all'ID ordine fornito, `process_order` dovrebbe:
   - stampare `Error processing order {order_id}: {error message}`, dove `{error message}` è il messaggio del `ValueError` sollevato da `find_order`, e non stampare altro.
   - lasciare invariati l'inventario e i codici sconto dati.
1. Quando l'ordine esiste ma non può essere evaso, perché un prodotto manca nell'inventario, perché la quantità richiesta non è disponibile o perché il codice sconto è invalido, `process_order` dovrebbe:
   - stampare `Error processing order {order_id}: {error message}`, dove `{error message}` è il messaggio del `ValueError` sollevato da `verify_availability` o `get_discount_rate`.
   - impostare lo `status` dell'ordine su `failed`.
   - lasciare invariati l'inventario e i codici sconto dati.
   - stampare `Order {order_id} processing completed. Current status: failed`.
1. Quando l'ordine può essere evaso, `process_order` dovrebbe:
   - stampare `Order {order_id} total: ${total}`, con lo sconto applicato e il totale arrotondato a due decimali.
   - impostare lo `status` dell'ordine su `processed`.
   - sottrarre le quantità ordinate dall'inventario dato.
   - rimuovere il codice sconto usato dall'ordine dai codici sconto dati, così che ogni codice possa essere usato solo una volta.
   - stampare `Order {order_id} processing completed. Current status: processed`.

**Nota:** Ti sono stati forniti un inventario, una cronologia degli ordini e codici sconto che puoi usare per testare il tuo codice. Chiama le tue funzioni per provarle, inclusi i casi che sollevano errori, ma commenta quelle chiamate prima di eseguire i test, altrimenti potrebbero interferire con i test.

    'SUMMER20': 0.20,

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id, order_history, inventory, discount_codes):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
