## 배열

- **정적 배열**: 초기화 시 크기가 고정됩니다. 요소들은 인접한 메모리 위치에 저장되어 접근이 매우 효율적입니다. 프로그램 실행 중에는 크기를 변경할 수 없습니다.

- **동적 배열**: 프로그램 실행 중 자동으로 크기가 커지거나 작아질 수 있습니다. 배열이 가득 차면 요소들이 더 큰 새 배열로 복사됩니다. 새 크기는 이러한 비용이 큰 복사가 덜 자주 일어나도록 선택됩니다.

- **Python의 정적 배열**: Python은 전통적인 정적 배열을 내장 자료 구조로 포함하지 않습니다. Java 같은 다른 언어들은 이를 지원합니다.

### Python 리스트(동적 배열)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### 동적 배열의 시간 복잡도

- **접근**: O(1)
- **끝에 삽입**: 공간이 있으면 O(1), 크기 조정이 필요하면 O(n)
- **중간에 삽입**: 뒤에 있는 요소들을 재배치해야 하므로 O(n)

### 정적 배열과 동적 배열 선택하기

- **정적 배열**: 요소 수를 미리 알고 자주 접근해야 할 때
- **동적 배열**: 요소 수가 불명확하거나 시간이 지나면서 변하거나 자주 삽입과 삭제가 일어날 때

## 스택

- **스택**: 후입선출(LIFO) 자료 구조입니다. 스택은 위와 아래 두 끝이 있으며, 요소는 위에서만 추가되고 제거됩니다.

- **푸시 연산**: 스택 위에 요소를 추가합니다. Python 리스트를 사용할 때 공간이 있으면 O(1), 크기 조정이 필요하면 O(n) 시간이 걸립니다.

- **팝 연산**: 스택 위에서 요소를 제거합니다. 시간 복잡도: O(1). 공간 복잡도: O(1).

```python
# Using a Python list as a stack, where the end of the list is the top
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operation
top_element = stack.pop()  # Returns 3
```

## 큐

- **큐**: 선입선출(FIFO) 자료 구조입니다. 큐는 앞과 뒤 두 끝이 있으며, 요소는 뒤에서 추가되고 앞에서 제거됩니다.

- **인큐 연산**: 큐 뒤에 요소를 추가합니다. Python 리스트를 사용할 때 공간이 있으면 O(1), 크기 조정이 필요하면 O(n) 시간이 걸립니다.

- **디큐 연산**: 큐 앞에서 요소를 제거합니다. 다음 요소가 새 앞이 됩니다. 시간 복잡도: O(1). 공간 복잡도: O(1).

```python
# Using a Python list as a queue, where the start of the list is the front
queue = []

# Enqueue operations
queue.append(1)
queue.append(2)
queue.append(3)

# Front element
front_element = queue[0]  # 1

# Dequeue operation
front_element = queue.pop(0)  # Returns 1
```

- **참고**: Python 리스트에서 `.pop(0)`으로 첫 요소를 제거하면 나머지 모든 요소가 재배치되어 O(n) 시간이 걸립니다.

## 연결 리스트

- **연결 리스트**: 각 노드가 데이터와 다음 노드에 대한 참조를 저장하는 선형 자료 구조입니다. 노드들이 사슬처럼 연결되어 있습니다. 연결 리스트는 크기가 고정되어 있지 않고 노드 간 연결을 업데이트하여 크기를 늘리거나 줄일 수 있습니다.

- **주요 용도**: 스택, 큐, 덱 같은 다른 자료 구조 구현과 깊이 우선 탐색, 너비 우선 탐색 같은 그래프 알고리즘에 사용됩니다.

### 단일 연결 리스트

- **구조**: 각 노드는 데이터와 다음 노드에 대한 하나의 참조를 저장합니다.
- **순회**: 머리에서 꼬리 방향으로만 이동할 수 있습니다.
- **머리 노드**: 리스트의 첫 노드로 보통 유일하게 직접 접근 가능한 노드입니다. 순회는 여기서 시작합니다.
- **꼬리 노드**: 리스트의 마지막 노드입니다. 다음 노드에 대한 참조가 `None`으로 리스트의 끝을 표시합니다.

#### 노드 삽입하기

- **처음에 삽입**: O(1) - 새 노드를 기존 머리와 연결하고 새 머리로 만듭니다
- **끝에 삽입**: O(n) - 끝까지 순회한 후 꼬리를 새 노드와 연결합니다
- **중간에 삽입**: O(n) - 위치까지 순회한 후 이전 노드를 새 노드와, 새 노드를 다음 노드와 연결합니다
- **공간 복잡도**: O(1) - 새 노드만 생성됩니다

#### 노드 제거하기

- **처음에서 제거**: O(1) - 다음 노드를 새 머리로 만듭니다
- **중간에서 제거**: O(n) - 노드까지 순회한 후 이전 노드를 다음 노드와 연결해 제거된 노드를 건너뜁니다
- **끝에서 제거**: O(n) - 끝까지 순회한 후 이전 노드의 연결을 끊어 새 꼬리로 만듭니다
- **공간 복잡도**: O(1) - 추가 메모리가 필요 없습니다

### 이중 연결 리스트

- **구조**: 각 노드는 데이터와 두 개의 참조를 저장합니다: 다음 노드와 이전 노드에 대한 참조입니다.
- **순회**: 양방향으로 이동할 수 있습니다.
- **꼬리 참조**: 리스트 자체에 꼬리 노드에 대한 참조를 보관하는 것이 일반적입니다. 이를 통해 리스트를 순회하지 않고도 O(1) 시간에 끝에 노드를 추가하고 끝에서부터 순회를 시작할 수 있습니다.
- **삽입과 삭제**: 단일 연결 리스트와 같은 방식으로 작동하지만 노드마다 두 개의 참조를 업데이트해야 합니다.
- **메모리**: 각 노드가 하나 대신 두 개의 참조를 저장하므로 단일 연결 리스트보다 더 많은 메모리가 필요합니다.

## 각 자료 구조 사용 시기

- **정적 배열**: 요소 수를 미리 알고 빠르고 자주 접근해야 할 때
- **동적 배열(리스트)**: 순서가 있고 인덱스로 접근해야 하며 크기를 미리 모를 때
- **스택**: 마지막에 추가된 요소가 가장 먼저 제거되어야 할 때(LIFO)
- **큐**: 요소가 추가된 순서대로 처리되어야 할 때(FIFO)
- **단일 연결 리스트**: 크기가 자주 변하고 주로 처음에서 삽입과 제거가 일어날 때
- **이중 연결 리스트**: 양방향 순회가 필요하거나 끝에 효율적으로 요소를 추가해야 하며 노드당 추가 메모리가 허용될 때
