# --description--

خلال الدروس السابقة، كنت تعرف الدوال باستخدام الكلمة المفتاحية `def` بهذا الشكل:

```py
def square(num):
    return num ** 2

print(square(4)) # 16
```

في الدرس السابق، مررت دوالًا مثل `is_long_word` و `to_fahrenheit` إلى `map()` و `filter()`. الدالة التي تقبل دالة أخرى كمعلمة تُسمى دالة رتبة عليا. تعريف دالة منفصلة باستخدام `def` في كل مرة تحتاج فيها لتمرير دالة قصيرة إلى دالة رتبة عليا قد يكون مفرطًا في الطول. بدلًا من ذلك، يمكنك كتابة دالة lambda، وهي دالة بلا اسم، مباشرة حيث تحتاجها.

صيغة دالة lambda تبدو هكذا:

```py
lambda parameters: expression
```

بعد كلمة `lambda`، تدرج معلمات الدالة. تفصل النقطتان المعلمات عن تعبير واحد، ويتم إرجاع نتيجة ذلك التعبير تلقائيًا، دون الحاجة إلى جملة `return`.

إليك كيف تبدو الدالة `square()` عند إعادة صياغتها كدالة lambda:

```py
lambda num: num ** 2
```

هنا، `num` هي المعلمة، و `num ** 2` هو التعبير الذي تُرجع نتيجته. كما ذُكر سابقًا، دوال lambda مجهولة الاسم، لذلك لم تعد هذه الدالة مرتبطة بالاسم `square`.

يمكن أن تحتوي دالة lambda أيضًا على أكثر من معلمة. تمامًا كما في الدوال المعرفة بـ `def`، تفصل المعلمات بفواصل:

```py
lambda a, b: a + b
```

تأخذ دالة lambda هذه معلمتين، `a` و `b`، وتُرجع مجموعهما.

دوال lambda رائعة عندما تحتاج إلى تمريرها إلى دوال رتبة عليا مثل هذه:

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

في هذا المثال، لدينا قائمة من الأرقام ونريد إنشاء قائمة جديدة تحتوي على الأرقام الزوجية. لذلك نمرر دالة lambda كواحدة من المعلمات إلى دالة `filter()`. تستدعي دالة `filter()` دالة lambda على كل رقم، وتحتفظ فقط بالأرقام التي تحقق الشرط `x % 2 == 0` وتكون نتيجته `True`. ثم تجمع دالة `list()` هذه الأرقام في قائمة جديدة تحتوي على الرقمين `2` و `4`.

عند العمل مع دوال lambda، من المهم أن تكون على دراية بأفضل الممارسات. على سبيل المثال، ليس من الجيد تعيين دالة lambda إلى متغير بهذه الطريقة:

```py
numbers = [1, 2, 3, 4, 5]

square = lambda x: x ** 2
squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

هذا يُفقد الهدف من استخدام الدوال المجهولة. في هذه الحالة، يجب استخدام دالة عادية، مثل هذه:

```py
numbers = [1, 2, 3, 4, 5]

def square(num):
    return num ** 2

squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

أيضًا، يجب تجنب إنشاء دوال lambda يصعب قراءتها أو معقدة بلا داعٍ، مثل هذه:

```py
result = (lambda x: (x**2 + 2*x - 1) if x > 0 else (x**3 - x + 4))(3)
print(result)  # 14
```

بينما تعمل هذه الدالة بشكل جيد وتنتج النتيجة الصحيحة `14`، إلا أنها ليست سهلة القراءة أو الفهم. في هذه الحالة، من الأفضل إنشاء دالة منفصلة تحتوي على جملة `if/else`، ثم استدعاء تلك الدالة:

```py
def calculate_expression(x):
    if x > 0:
        return x**2 + 2*x - 1
    else:
        return x**3 - x + 4

print(calculate_expression(3))  # 14
```

لكل من الدوال العادية ودوال lambda استخداماتها في برامج Python. إذا كنت تتعامل مع تعبير مضمَّن واحد فقط، فقد تفكر في استخدام دالة lambda. أما إذا لم يكن كذلك، فالأفضل استخدام دالة عادية.
