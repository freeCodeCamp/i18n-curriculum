# --description--

在這個工作坊中，你將使用智慧校園目錄並從巢狀資料中建立查詢表。
你將使用這些查詢表來執行快速且高效的搜尋。`rawData` 已經提供給你。

花點時間看看它的結構：每個鍵是系所名稱，其值包含一個 `Dept_code` 和一個 `programs` 陣列。
每個課程接著有自己的 `instructors` 陣列。

首先，將 `rawData` 記錄到主控台，這樣你就能在操作之前檢查這個巢狀結構。

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, "log");
const getLogs = () => globalThis.spy.calls.map(call => call?.[0]);
```

# --after-each--

```js
globalThis.spy.restore();
delete globalThis.spy;
```

# --hints--

你應該將 `rawData` 記錄到主控台。

```js
assert.include(getLogs(), rawData);
```
