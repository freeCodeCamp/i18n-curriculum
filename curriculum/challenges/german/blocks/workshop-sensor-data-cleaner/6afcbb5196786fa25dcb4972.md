# --description--

Im Terminal sollten Sie etwas sehen wie `<filter object at 0x...>` anstelle der Messwerte. Das passiert, weil `filter()` einen Iterator zurückgibt, der Ihnen die Elemente einzeln liefert, anstatt sie alle in einer Liste zu speichern.

Um die Elemente eines Iterators in einer Liste zu sammeln, können Sie ihn an die `list()`-Funktion übergeben:

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

Fassen Sie den `filter()`-Aufruf, der `valid_readings` zugewiesen ist, in einen `list()`-Aufruf ein. Im Terminal sollten Sie dann die Messwerte ohne die `-999`-Fehlercodes sehen.
