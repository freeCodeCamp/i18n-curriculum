# --description--

你已經學會如何創建字典並存取與更新它們的值。現在你將使用字典方法、複製字典，並探索函式如何改變它們。

以下每個字典方法範例都從這個字典開始：

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## 字典方法

字典也有有用的方法來執行常見的操作。

`.get()` 方法會取用與鍵相關聯的值。它類似你在上一課學到的中括號表示法，但它的優點是你可以設定預設值，因此如果鍵不存在就不會出錯：

```python
dictionary.get(key, default)
```

在此範例中，如果 `toppings` 鍵不存在，它將傳回一個空列表，這是我們作為第二個引數傳遞的預設值。但如果 `toppings` 存在，它將傳回該值：

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

`.keys()` 和 `.values()` 方法分別傳回包含字典中所有鍵和值的檢視物件：

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

檢視物件只是查看字典內容的一種方式，並不會建立資料的獨立複本。

`.items()` 方法會傳回一個檢視物件，包含字典中所有的鍵值配對，包括鍵和值：

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

`.clear()` 方法會從字典中移除所有的鍵值對組：

```python
pizza.clear()
```

`.pop()` 方法會移除你作為第一個引數指定的鍵所對應的鍵值配對，並傳回其值。如果該鍵不存在，則會傳回你作為第二個引數指定的預設值。如果該鍵不存在且你沒有傳入預設值，則會引發 `KeyError`：

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

在 Python 3.7 及更新版本中，`.popitem()` 方法會移除最後插入的項目：

```python
pizza.popitem()
```

`.update()` 方法會用另一個字典的鍵值對更新字典。如果它們有相同的鍵，則會覆寫其值。

在這個範例中，我們正在更新 `pizza` 字典。`price` 鍵在兩者中皆存在，所以它的值將被取代為 `15`。

但是 `total_time` 是新的，因此它將作為新的鍵值配對添加到 `pizza` 字典中：

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

這是包含更新後 `price` 和新的 `total_time` 的新字典。注意現在 price 是 `15`，而 `total_time` 是一個新的鍵值對：

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### 指派與淺層複製

如同你在列表中學到的，將字典指派給另一個變數會建立別名。兩個名稱都指向同一個物件：

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

要創建一個獨立的外層字典，請使用 `.copy()` 方法：

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

替換 `copied_settings` 中的條目不會替換 `settings` 中相對應的條目。然而，`.copy()` 會產生**淺層複製**：它創建一個新的外層字典，其鍵和值指向與原始字典相同的物件。巢狀的可變物件仍然是共享的：

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

這兩個字典是不同的物件，但它們的 `languages` 條目指向同一個列表。對該列表的附加操作會在兩個字典中都可見。若用新的列表替換 `copied_settings['languages']`，則只會改變複製字典中的該條目。

你也可以透過將字典傳給 `dict()` 來創建淺層複製：

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

像 `.copy()` 一樣，`dict(settings)` 創建一個新的外層字典，但巢狀列表仍然是共享的。替換任一字典中的條目只會影響該字典，而改變共享的列表則會在兩者中都可見。

## 透過函式參數變異字典

你在列表中學到的引數傳遞規則同樣適用於字典。參數最初指向作為引數傳入的物件。透過該參數更新條目會變異共享的字典：

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

函式傳回狀態字串，而 `preferences` 則透過共享引用改變。傳回值和變異物件是兩種不同的效果。函式不需要傳回字典，變更才能在函式外可見。將區域參數重新指派給不同的字典不會取代 `preferences` 指涉的字典。

## 將字典用作預設引數

回想預設列表是在函式定義時創建，並在省略引數的呼叫中重複使用。預設字典的行為也是如此：

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

第二次呼叫重複使用第一次呼叫改變過的字典。這表示設定會在獨立呼叫間累積，即使每次呼叫都有自己的區域參數名稱。

當每次呼叫都應從全新字典開始時，請使用 `None` 預設樣式：

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

每次省略 `settings` 或傳入 `None` 的呼叫都會創建一個全新字典。傳入現有字典仍允許函式變異該物件。這裡使用 `settings is None`：`if not settings` 也會匹配傳入的空字典並用新的區域字典取代它。
