# --description--

Los usuarios que tengan al menos `18` años pero menos de `21` pueden reservar entradas, pero solo cuando el `show_time` no sea `Evening`.

El operador de desigualdad (`!=`) verifica si dos valores no son iguales. Evalúa a `True` cuando los valores son diferentes y a `False` cuando son iguales:

```py
day = 'Monday'
print(day != 'Sunday') # True
print(day != 'Monday') # False
```

Cuando `and` y `or` se usan en la misma expresión, `and` tiene una precedencia mayor que `or`. Esto significa que las condiciones unidas con `and` se agrupan, y el resultado de ese grupo se combina luego con la condición `or`:

```py
has_key = True
knows_code = False
is_daytime = False

print(has_key or knows_code and is_daytime) # True
```

En el ejemplo anterior, primero se evalúa `knows_code and is_daytime`, dando como resultado `False`. La expresión completa entonces se convierte en `has_key or False`, que es `True`.

Actualiza la condición de la línea `if age >= 21:`. Usa el operador `and` para construir una expresión que verifique si `age` es mayor o igual a `18` y `show_time` no es `Evening`. Luego usa el operador `or` para combinar esa expresión con la condición existente. No crees nuevas variables.
