# --description--

- **التكرار (Recursion)**: تقنية تستدعي فيها الدالة نفسها. كل استدعاء يعمل على نسخة أصغر من المشكلة الأصلية حتى يصل إلى حالة قاعدة توقف الاستدعاءات التكرارية الإضافية.
- **حالة القاعدة (Base Case)**: الشرط الذي يوقف التكرار. يجب تعريف حالة القاعدة بعناية. وإلا، تستمر الدالة في استدعاء نفسها حتى يرفع Python استثناء `RecursionError`.
- **الحالة التكرارية (Recursive Case)**: الجزء من الدالة الذي يستدعي الدالة مرة أخرى بمعلمة تحركها نحو حالة القاعدة، مثل `number - 1` عند العد التنازلي.

```py
def recursive_countdown(number):
    if number < 1:  # Base case
        return
    print(number)
    recursive_countdown(number - 1)  # Recursive case

recursive_countdown(5)  # Prints 5, 4, 3, 2, 1
```

- **ترتيب التنفيذ**: يتغير موقع الاستدعاء التكراري عندما ينفذ الكود الآخر في الدالة. الكود الموضوع قبل الاستدعاء التكراري ينفذ أثناء تعمق الاستدعاءات، بينما الكود الموضوع بعده ينفذ أثناء عودة الاستدعاءات. نقل دالة `print()` بعد الاستدعاء التكراري يجعل الدالة تطبع الأرقام بترتيب تصاعدي:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)  # Prints 1, 2, 3, 4, 5
```

- **مكدس الاستدعاءات (Call Stack)**: هيكل بيانات من نوع آخر داخل أول خارج يستخدمه Python لتتبع استدعاءات الدوال النشطة. في كل مرة تُستدعى دالة، يضيف Python إطارًا لذلك الاستدعاء في أعلى المكدس. يحتوي الإطار على معلومات مثل معلمات الدالة والمتغيرات المحلية.
- **استئناف الاستدعاءات**: يتوقف الاستدعاء مؤقتًا عند إجراء استدعائه التكراري. عندما تعود حالة القاعدة، يزيل Python ذلك الاستدعاء من أعلى المكدس، وتستأنف الاستدعاءات السابقة بعد استدعائها التكراري وتعود بترتيب آخر داخل أول خارج:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

الناتج هو:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

- **بناء قائمة بشكل تكراري**: يستأنف كل استدعاء عندما يعود استدعاؤه التكراري، ثم يستخدم القيمة المعادة. الدالة `countup` أدناه تعيد قائمة فارغة في حالة القاعدة. كل استدعاء آخر يستلم القائمة من استدعائه التكراري، يضيف رقمه الخاص، ثم يعيد القائمة:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(5))  # [1, 2, 3, 4, 5]
```

الاستدعاء مع `1` يستلم `[]` ويعيد `[1]`، والاستدعاء مع `2` يستلم `[1]` ويعيد `[1, 2]`، وهكذا حتى الاستدعاء مع `5` يعيد `[1, 2, 3, 4, 5]`.

- **تطبيقات التكرار**: يمكن للتكرار التعامل مع مهام بسيطة مثل العد التنازلي، العد التصاعدي، وبناء قائمة. كما أنه مفيد للمشاكل ذات العمق غير المعروف، مثل استعراض شجرة الملفات.
