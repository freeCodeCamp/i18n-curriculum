# --description--

У цій лабораторній роботі ви оброблятимете замовлення електронної комерції та опрацьовуватимете помилки, які виникають у процесі.

**Мета:** Виконайте наведені нижче історії користувача та пройдіть усі тести, щоб завершити лабораторну роботу.

Дані, з якими ви працюватимете, мають таку ж структуру, як і змінні у початковому коді:

- **Замовлення** — це словник, який містить:
  - `order_id`: ціле число, що ідентифікує замовлення.
  - `products`: список словників, кожен із яких має `product_id` та запитувану `quantity`.
  - `discount_code`: рядок або `None`, якщо у замовленні немає коду знижки.
  - `status`: рядок, що описує стан замовлення.
- **Історія замовлень** — це список замовлень.
- **Інвентар** — це словник, ключами якого є ідентифікатори продуктів, а значеннями — словники з назвою `product`, кількістю на складі `quantity` та ціною одиниці `price`.
- **Коди знижок** — це словник, ключами якого є коди, а значеннями — ставки знижок, наприклад `0.1` для 10% знижки.

**Історія користувача:**

1. Ви повинні мати функцію з назвою `find_order` з двома параметрами: ідентифікатор замовлення та історія замовлень, у такому порядку.
1. `find_order` має:
   - повертати замовлення з наданої історії замовлень, у якого `order_id` дорівнює заданому ідентифікатору.
   - викликати `ValueError` з повідомленням `Order ID {order_id} not found in order history.`, якщо жодне замовлення не відповідає заданому ідентифікатору.
1. Ви повинні мати функцію з назвою `verify_availability` з двома параметрами: замовлення та інвентар, у такому порядку.
1. `verify_availability` має:
   - викликати `ValueError` з повідомленням `Product ID {product_id} is not in the inventory.`, якщо продукт із замовлення відсутній у наданому інвентарі.
   - викликати `ValueError` з повідомленням `Insufficient stock for product ID {product_id}: requested {quantity}, available {available}.`, якщо запитувана кількість продукту більша за наявну у наданому інвентарі.
   - не викликати помилок, якщо кожен продукт у замовленні доступний у запитуваній кількості.
1. Ви повинні мати функцію з назвою `get_discount_rate` з двома параметрами: замовлення та коди знижок, у такому порядку.
1. `get_discount_rate` має:
   - повертати `0.0`, якщо `discount_code` замовлення дорівнює `None`.
   - викликати `ValueError` з повідомленням `Invalid discount code: {discount_code}.`, якщо `discount_code` замовлення відсутній серед наданих кодів знижок.
   - повертати ставку знижки для `discount_code` замовлення в іншому випадку.
1. Ви повинні мати функцію з назвою `process_order` з чотирма параметрами: ідентифікатор замовлення для обробки, історія замовлень, інвентар та коди знижок, у такому порядку.
1. `process_order` має використовувати `find_order`, `verify_availability` та `get_discount_rate` для обробки замовлення, а також обробляти виклики `ValueError`, щоб виклик `process_order` ніколи не викликав помилку.
1. Якщо жодне замовлення в наданій історії не відповідає заданому ідентифікатору, `process_order` має:
   - вивести `Error processing order {order_id}: {error message}`, де `{error message}` — це повідомлення `ValueError`, викликаного `find_order`, і більше нічого не виводити.
   - залишити надані інвентар та коди знижок без змін.
1. Якщо замовлення існує, але його не можна виконати через відсутність продукту в інвентарі, недостатню кількість або недійсний код знижки, `process_order` має:
   - вивести `Error processing order {order_id}: {error message}`, де `{error message}` — це повідомлення `ValueError`, викликаного `verify_availability` або `get_discount_rate`.
   - встановити `status` замовлення в `failed`.
   - залишити надані інвентар та коди знижок без змін.
   - вивести `Order {order_id} processing completed. Current status: failed`.
1. Якщо замовлення можна виконати, `process_order` має:
   - вивести `Order {order_id} total: ${total}`, зі застосованою знижкою та загальною сумою, округленою до двох десяткових знаків.
   - встановити `status` замовлення в `processed`.
   - відняти замовлені кількості з наданого інвентарю.
   - видалити код знижки, який використало замовлення, з наданих кодів знижок, щоб кожен код можна було використати лише один раз.
   - вивести `Order {order_id} processing completed. Current status: processed`.

**Примітка:** Вам надано інвентар, історію замовлень і коди знижок, які можна використовувати для тестування коду. Викликайте свої функції, щоб перевірити їх, включно з випадками, що викликають помилки, але перед запуском тестів закоментуйте ці виклики, щоб вони не заважали тестам.

def find_order(order_id, order_history):
    for order in order_history:
        if order['order_id'] == order_id:
            return order
    raise ValueError(f'Order ID {order_id} not found in order history.')

def set_order_status(order, status):
    order['status'] = status

def get_discount_rate(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is None:
        return 0.0
    if discount_code not in discount_codes:
        raise ValueError(f'Invalid discount code: {discount_code}.')
    return discount_codes[discount_code]

def consume_discount_code(order, discount_codes):
    discount_code = order['discount_code']
    if discount_code is not None:
        del discount_codes[discount_code]

def verify_availability(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        quantity = product['quantity']
        if product_id not in inventory:
            raise ValueError(f'Product ID {product_id} is not in the inventory.')
        available = inventory[product_id]['quantity']
        if available < quantity:
            raise ValueError(
                f'Insufficient stock for product ID {product_id}: '
                f'requested {quantity}, available {available}.'
            )

def calculate_total(order, inventory):
    products = order['products']
    total = 0.0
    for product in products:
        product_id = product['product_id']
        price = inventory[product_id]['price']
        quantity = product['quantity']
        total += price * quantity
    return total

def reserve_stock(order, inventory):
    products = order['products']
    for product in products:
        product_id = product['product_id']
        inventory[product_id]['quantity'] -= product['quantity']

def process_order(order_id, order_history, inventory, discount_codes):
    try:
        order = find_order(order_id, order_history)
    except ValueError as e:
        print(f'Error processing order {order_id}: {e}')
        return

    try:
        verify_availability(order, inventory)
        discount_rate = get_discount_rate(order, discount_codes)
        total = calculate_total(order, inventory)
    except ValueError as e:
        set_order_status(order, 'failed')
        print(f'Error processing order {order_id}: {e}')
    else:
        reserve_stock(order, inventory)
        consume_discount_code(order, discount_codes)
        set_order_status(order, 'processed')
        print(f'Order {order_id} total: ${total * (1 - discount_rate):.2f}')

    print(f'Order {order_id} processing completed. Current status: {order["status"]}')
