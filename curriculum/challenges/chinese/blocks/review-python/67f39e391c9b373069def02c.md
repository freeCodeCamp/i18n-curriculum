## 什么是 Python？

- **介绍**：Python 是一种通用的编程语言，以其简洁和易用性著称。
- **常见用途**：Python 被用于数据科学、机器学习、网页开发、安全性、嵌入式系统和物联网、脚本编写、自动化，以及像 Raspberry Pi 和兼容 MicroPython 的微型计算机等领域。

## 变量

- **声明变量**：声明变量时，先写变量名，后跟赋值操作符（`=`），然后是值。这个值可以是数字、字串、布尔值等。

- **变量命名规范**：变量命名应遵循以下规则：

  - 变量名只能以字母或下划线（`_`）开头，不能以数字开头。
  - 变量名只能包含字母数字字符（`a-z`、`A-Z`、`0-9`）和下划线（`_`）。
  - 变量名区分大小写：`age`、`Age` 和 `AGE` 都被视为不同的变量。
  - 变量名不能是 Python 的保留关键字，如 `if`、`class` 或 `def`。
  - 多词变量名使用下划线连接，如 `snake_case`。
  - 变量名应描述其用途，如 `user_age`。
  - 当单个字母变量名无法传达意义时，应避免使用。

## 注释

- **单行评论**：这种评论用于代码中的简短注释。

- **多行评论**：你可以在每行开头使用 `#` 来创建跨多行的评论。

- **`print()` 函数**：要在终端打印数据，可以使用 `print()` 函数。

## Python 中常见的数据类型

- **介绍**：Python 是动态类型语言，意味着你不需要声明变量的数据类型。Python 会根据赋给变量的值来确定类型。
- **整数**：没有小数的整数。

- **浮点数**：带有小数的数字。

- **字串**：用引号包裹的一串字符序列。

- **布尔**：表示 `True` 或 `False` 的值。

Python 还有其他数据类型。你将在首次需要时学习每一种。

- **`type()` 函数**：要查看变量的类型，可以使用 `type()` 函数。

- **`isinstance()` 函数**：用于检查变量是否匹配特定的数据类型。

## 字串操作

- **定义**：字串是不可变的，意味着创建后不能更改。在 Python 中，你可以使用单引号或双引号。选择一种风格并保持一致使用。

- **访问字串中的字符**：可以用方括弧表示法访问字串中的字符，如下：

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **转义字串**：如果字串中包含引号，可以使用反斜线（`\`）转义，如下：

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **字串串接**：要串接字串，可以使用 `+` 操作符。

另一种串接字串的方法是使用 `+=` 操作符。这用于在同一步骤中执行串接和赋值。

- **`f-strings`**：即格式化字串字面值，允许你用简洁易读的语法进行插值和串接：

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

- **字串切片**：可以提取字串的一部分。语法是 `str[start:stop:step]`。

起始位置表示提取开始的索引。结束位置表示切片结束的索引，该位置不包含在内。步长表示切片时索引的增量间隔。

- **获取字串长度**：`len()` 函数用于返回字串中的字符数。

## 函数操作

- **定义**：函数是可重用的代码块，接受输入（参数）并返回输出。调用函数时，引用函数名后跟一对括号：

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

如果函数没有显式返回值，则默认返回值是 `None`。

你也可以为参数提供默认值，如下：

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```

如果调用函数时参数数量不正确，会得到 `TypeError`。

## 使用 `if`、`elif` 和 `else` 语句

- **`if` 语句**：用于判断条件是否为真。如果条件为 `True`，则执行该代码块。

- **`elif` 子句**：这些是跟在 `if` 语句之后的条件。只有当所有之前的条件计算结果为 `elif` 且自身条件计算结果为 `False` 时，`True` 块才会运行。

- **`else` 分支**：当没有其他条件为 `True` 时执行。

```py
age = 12

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')
else:
    print('You are a child')  # You are a child
```

你也可以在另一个条件块中嵌套 `if` 语句。

## 真值和假值

- **定义**：在 Python 中，每个值都有固有的布尔值，或者说在逻辑上下文中应被视为 `True` 或 `False`。许多值被认为是 truthy，即在逻辑上下文中评估为 `True`。其他值是 falsy，意味着它们评估为 `False`。

示例包括 `None`、`False`、`0`、`0.0` 和空字串 `''`。

其他值如非零数字和非空字串是真值。

## 使用 `bool()` 函数

- **定义**：如果你想检查一个值是 truthy 还是 falsy，可以使用内置的 `bool()` 函数。它会显式将值转换为布尔等价物，truthy 值返回 `True`，falsy 值返回 `False`。

## 布尔操作符与短路求值

- **定义**：这些特殊操作符允许你组合多个表达式，创建更复杂的决策逻辑。Python 中有三个布尔操作符：`and`、`or` 和 `not`。
- **`and` 操作符**：接受两个操作数，如果第一个是假值，则返回第一个，否则返回第二个。两个操作数都必须是真值，表达式才为真值。

你也可以在条件式中使用 `and` 操作符。

- **`or` 操作符**：如果第一个操作数是 truthy，则返回第一个操作数，否则返回第二个操作数。`or` 表达式只要有一个操作数为 truthy 就会返回 truthy。

就像 `and` 操作符一样，你也可以在条件式中使用 `or` 操作符。

- **短路**：`and` 和 `or` 操作符被称为短路操作符。短路意味着 Python 从左到右检查值，一旦确定最终结果就停止。
- **`not` 操作符**：该操作符接受一个操作数并反转其布尔值。它将 truthy 值转换为 `False`，falsy 值转换为 `True`。与之前的操作符不同，`not` 总是返回 `True` 或 `False`。

`not` 操作符也可以在条件式中使用。

## Python 列表

- **简介**：Python 中的列表数据类型是有序元素序列，可以包含字串、数字甚至其他列表。列表是可变的，且索引从零开始。

例如，`cities = ['Los Angeles', 'London', 'Tokyo']` 创建了一个字串列表。

- **访问列表元素**：要访问 `cities` 列表中的元素，引用其索引，例如 `cities[0]` 表示 `'Los Angeles'`。

- **使用负索引访问元素**：要访问列表的最后一个元素，可以使用索引 `-1`。

- 负索引用于从列表末尾访问元素，而非从索引 `0` 开始。

- **使用 `list()` 构造函数创建列表**：列表也可以使用 `list()` 构造函数创建。`list()` 构造函数用于将可迭代对象转换为列表。

- **获取列表长度**：你可以使用 `len()` 函数获取列表长度。

- **列表的可变性**：列表是可变的，意味着只要传入有效索引，你可以更新列表中的任何元素。要更新特定索引的列表元素，可以给该索引赋新值。

- **索引超出范围错误**：如果传入的索引（正数或负数）超出列表边界，会收到 `IndexError`。

- **从列表中移除元素**：可以使用 `del` 关键字从列表中移除元素。

- **检查元素是否存在于列表中**：可以使用 `in` 关键字检查元素是否存在于列表中。

- **嵌套列表**：列表可以嵌套在其他列表中。

- 在下面的示例中，嵌套列表位于索引 `2`，因为列表是从零开始索引的。

- 进一步访问嵌套列表中的第二个语言，需要使用索引 `1`：

```python
developer = ['Alice', 25, ['Python', 'Rust', 'C++']]
developer[2][1] # Rust
```

- **列表解包**：列表解包是将列表中的值赋给新变量的技术。下面示例将 `developer` 列表解包到名为 `name`、`age` 和 `job` 的新变量中：

```py
developer = ['Alice', 34, 'Rust Developer']
name, age, job = developer
```

- 如果赋值操作符左侧变量数量与列表项总数不匹配，会抛出 `ValueError`。

- **收集列表剩余元素**：使用星号（`*`）操作符收集列表中剩余元素，如下：

```py
developer = ['Alice', 34, 'Rust Developer']
name, *rest = developer
```

- **列表切片**：切片是通过切片操作符 `:` 访问列表部分的概念。例如，对于 `desserts = ['cake', 'pie', 'cookies', 'ice cream']`，`desserts[1:3]` 返回 `['pie', 'cookies']`。

- **步长间隔**：也可以指定步长间隔，决定索引之间的增量。例如，`[1, 2, 3, 4, 5, 6][1::2]` 产生 `[2, 4, 6]`。

## 列表方法

- **append()**：用于将项添加到列表末尾。例如，`numbers.append(6)` 将 `6` 添加到 `numbers` 末尾。

- **追加列表**：`append()` 方法也可用于将一个列表添加到另一个列表末尾：

```py
numbers = [1, 2, 3, 4, 5]
even_numbers = [6, 8, 10]

numbers.append(even_numbers)
print(numbers) # [1, 2, 3, 4, 5, [6, 8, 10]]
```

- **extend()**：用于向列表末尾添加多个项。下面示例向 `numbers` 列表末尾添加数字 `6`、`8` 和 `10`：

```py
numbers = [1, 2, 3, 4, 5]
even_numbers = [6, 8, 10]

numbers.extend(even_numbers)
print(numbers) # [1, 2, 3, 4, 5, 6, 8, 10]
```

- **insert()**：用于在列表的特定索引插入项。

- **remove()**：用于从列表中移除项。`remove()` 方法只移除列表中第一次出现的该项。

- **pop()**：用于移除列表中特定项并返回它。

- 如果不指定 `pop` 方法的元素，则移除最后一个元素。

- **clear()**：用于移除列表中的所有项。

- **sort()**：`sort()` 方法用于原地排序列表元素。例如，`numbers.sort()` 会对 `numbers` 进行原地排序。

- **sorted()**：内置函数，返回一个新的排序列表，而不修改原列表。

- **reverse()**：用于反转列表中元素的顺序。

- **index()**：用于查找列表中某元素首次出现的索引。

- 如果使用 `index()` 方法找不到元素，结果将是 `ValueError`。

## Python 元组

- **定义**：元组是 Python 数据类型，用于创建有序值序列。元组可以包含混合数据类型：

例如，`developer = ('Alice', 34, 'Rust Developer')`。

- 元组是不可变的，意味着创建后不能更改其中的元素。如果尝试更新元组中的项，会得到 `TypeError`。

- **访问元组元素**：使用方括弧和索引号访问元组中的元素。

- 可以使用负索引从元组末尾访问元素。

- 如果传入的索引号大于或等于元组长度，会收到 `IndexError`。

- 元组也可以用 `tuple()` 构造函数创建。构造函数中可以传入字符串、列表甚至其他元组等可迭代对象。

- **验证元组中的项**：可以使用 `in` 关键字检查项是否在元组中。

- **解包元组**：可以将元组中的项赋值给多个变量，例如 `name, age, job = developer`。

- 如果需要收集元组中剩余的元素，可以使用星号（`*`）操作符。

- **切片元组**：切片可以提取元组的一部分。例如，对于 `desserts = ('cake', 'pie', 'cookies', 'ice cream')`，`desserts[1:3]` 返回 `('pie', 'cookies')`。

- **从元组中移除项**：由于元组是不可变的，移除项会引发 `TypeError`。

- **何时使用元组而非列表？**：如果需要动态集合，可以添加、删除和更新元素，应使用列表。如果数据集合是固定且不可变的，应使用元组。

## 常用元组方法

- **`count()`**：用于确定项在元组中出现的次数。例如，对于 `programming_languages = ('Rust', 'Java', 'Python', 'Rust')`，`programming_languages.count('Rust')` 返回 `2`。

- 如果 `count()` 方法指定的项在元组中完全不存在，返回值为 `0`。

- 如果 `count()` 方法没有传入任何参数，Python 将返回一个 `TypeError`。

- **index()**：用于查找元组中特定项的索引。例如，`programming_languages.index('Java')` 查找 `'Java'` 的首次索引。

- 如果找不到指定的项，Python 会返回一个 `ValueError`。

- 你可以向 `index()` 方法传入可选的起始索引，指定从哪里开始搜索项。

- 你也可以向 `index()` 方法传入可选的结束索引，指定搜索项的终止位置。

- **`sorted()`**：用于对任何可迭代对象的元素进行排序，并返回一个新的排序列表。例如，`sorted(numbers)` 返回一个新的排序列表。

- **修改排序行为**：你可以使用可选的 `reverse` 和 `key` 参数自定义排序行为。例如，`sorted(programming_languages, key=len)` 按字符串长度排序。

- 你可以通过传入 `reverse=True` 给 `sorted()` 来创建一个逆序的新列表。

## Python 中的循环

- **定义**：循环用于重复执行一段代码块指定次数。

- **`for` 循环**：用于遍历序列（如列表、元组或字串），并对序列中的每个项执行一段代码。下面是使用 `for` 循环遍历列表并打印每种语言到控制台的示例：

```py
programming_languages = ['Rust', 'Java', 'Python', 'C++']

for language in programming_languages:
    print(language)

"""
Result

Rust
Java
Python
C++
"""
```

- `for` 循环可以遍历字串 `'code'` 并打印每个字符：`c`、`o`、`d` 和 `e`。

- `for` 循环可以嵌套，内层循环会在外层循环的每次迭代中执行。

- **`while` 循环**：重复执行代码块直到条件为 `False`。下面是使用 `while` 循环实现猜数字游戏的示例：

```py
secret_number = 3
guess = 0

while guess != secret_number:

    if guess != secret_number:
        print('Wrong! Try again.')

print('You got it!')

"""
Result

```

- **`break` 和 `continue` 语句**：用于在循环中修改循环的执行。

- `break` 语句用于在满足特定条件时立即退出循环。

- `continue` 语句用于跳过当前迭代，进入下一次循环迭代。

## 范围及其在循环中的使用

- **`range()` 函数**：用于生成整数序列，语法为 `range(start, stop, step)`。

- 必需的 `stop` 参数是一个整数（不包含该值），表示生成的数字序列的结束点。

- 如果未指定 `start` 参数，则默认值为 `0`。默认情况下，整数序列以 `1` 递增。你可以使用可选的 `step` 参数来更改默认的递增值。例如，`range(2, 11, 2)` 生成从 2 到不包括 11 的偶数（即包含 10）。

- 如果你不向 `range()` 函数传入任何参数，则会得到一个 `TypeError`。

- `range()` 函数只接受整数作为参数，不接受浮点数。使用浮点数也会导致 `TypeError`。

- 你可以使用负整数作为 `step` 参数来生成递减的整数序列。

- `range()` 函数也可以与 `list` 构造函数一起使用来创建整数列表。`list` 构造函数用于将可迭代对象转换为列表。例如，`list(range(2, 11, 2))` 生成 `[2, 4, 6, 8, 10]`。

## Python 中的 `enumerate()` 和 `zip()` 函数

- **`enumerate()`**：用于遍历序列并跟踪序列中每个项的索引。`enumerate()` 函数接受一个可迭代对象作为参数，返回一个 `enumerate` 对象，该对象包含可迭代对象中每个项的索引和值。

languages = ['Spanish', 'English', 'Russian', 'Chinese']

for index, language in enumerate(languages):

- **`zip()`**：用于并行遍历多个可迭代对象。下面是使用 `zip()` 函数遍历 `developers` 和 `ids` 的示例：

developers = ['Naomi', 'Dario', 'Jessica', 'Tom']

even_numbers = [num for num in range(21) if num % 2 == 0]

## 可迭代函数

- **`filter()`**：用于根据条件过滤可迭代对象中的元素。它返回一个迭代器，只包含满足条件的元素。例如，过滤条件可以选择长度超过四个字符的单词。

- **`map()`**：用于对可迭代对象中的每个项应用一个函数，并返回一个包含结果的新可迭代对象。例如，该函数可以将列表中的每个摄氏温度转换为华氏温度。

- **`sum()`**：用于计算列表或元组等可迭代对象的总和。

- 你还可以传入一个可选的 `start` 参数，设置求和的初始值。例如，`sum([5, 10, 15, 20], 10)` 返回 `60`。

- 你也可以使用关键字参数形式的 `start`，如 `sum([5, 10, 15, 20], start=10)`。

## Lambda 函数

- **定义**：Python 中的 lambda 函数是一种简洁的无名函数（匿名函数）创建方式。
- lambda 函数通常作为另一个函数的参数使用。下面是一个 lambda 函数的示例：

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

- 使用 lambda 函数的最佳实践包括不将其赋值给变量，保持简单易读，并用于简短的一次性函数。

## 字典

- **字典**：字典是内置的数据结构，用于存储键值对集合。键必须是不可变的数据类型。一般语法为 `dictionary = {key1: value1, key2: value2}`。

- **`dict()` 构造函数**：`dict()` 构造函数是构建字典的另一种方式。你可以将元组列表作为参数传递给 `dict()` 构造函数。这些元组的第一个元素是键，第二个元素是值。

- **方括弧表示法**：要访问键值对的值，可以使用称为方括弧表示法的语法。

## 常用字典方法

- **`get()` 方法**：`get()` 方法用于获取与键关联的值。它类似于方括号访问，但允许设置默认值，避免键不存在时引发错误。语法为 `dictionary.get(key, default)`。

- **`keys()` 和 `values()` 方法**：`keys()` 和 `values()` 方法分别返回包含字典所有键和值的视图对象。视图对象是一种查看字典内容而不创建数据副本的方式。

- **`items()` 方法**：`items()` 方法返回包含字典所有键值对的视图对象，包括键和值。

- **`clear()` 方法**：`clear()` 方法删除字典中的所有键值对。

- **`pop()` 方法**：`pop()` 方法删除指定键的键值对并返回其值。如果键不存在，则返回作为第二个参数指定的默认值。如果键不存在且未指定默认值，则会引发 `KeyError`。

- **`popitem()` 方法**：在 Python 3.7 及以上版本中，`popitem()` 方法删除最后插入的项。

- **`update()` 方法**：`update()` 方法使用另一个字典的键值对更新当前字典。如果有相同的键，其值会被覆盖。新键会作为新的键值对添加到字典中。

## 遍历字典

- **遍历值**：如果你需要遍历字典中的值，可以写一个 `for` 循环，使用 `values()` 获取字典的所有值。

```python
products = {
    'Laptop': 990,
    'Smartphone': 600,
    'Tablet': 250,
    'Headphones': 70,
}

for price in products.values():
    print(price)
```

- **遍历键**：如果你需要遍历上面 `products` 字典中的键，可以直接写 `products.keys()` 或 `products`。

- **遍历键值对**：如果你需要同时遍历键及其对应的值，可以遍历 `products.items()`。你会得到包含键及其对应值的元组。

要将键和值存储在不同的循环变量中，需要用逗号分隔。第一个变量存储键，第二个变量存储值。

```python
for product, price in products.items():
    print(product, price)
```

- **`enumerate()` 函数**：如果你需要在遍历字典时跟踪计数器，可以调用 `enumerate()` 函数。该函数返回一个 `enumerate` 对象，为每个项分配一个整数计数器。计数器可以从任意数字开始，默认从 0 开始。

将索引和值分别赋给不同的循环变量是使用 `enumerate()` 的常见方式。例如，`for index, (product, price) in enumerate(products.items()):` 解包计数器和每个键值对。

你可以向 `enumerate()` 传入第二个参数来自定义计数起始值。例如，`enumerate(products.items(), 1)` 从 1 开始计数。

## 集合

- **集合**：集合是 Python 内置的数据结构，不允许重复值。集合是可变且无序的，这意味着它们的元素没有特定顺序，因此不能使用索引或键访问它们。此外，集合只能包含不可变数据类型的值，如数字、字符串和元组。

- **定义集合**：要定义集合，需要将元素写在花括弧内，并用逗号分隔。

例如，`numbers = {1, 2, 3, 4}`。

- **定义空集合**：如果需要定义空集合，必须使用 `set()` 函数。仅写空花括弧会自动创建一个字典。

## 常用集合方法

- **`add()` 方法**：你可以使用 `add()` 方法向集合添加元素，传入新元素作为参数。

- **`remove()` 和 `discard()` 方法**：要从集合中移除元素，可以使用 `remove()` 方法或 `discard()` 方法，传入要移除的元素作为参数。`remove()` 方法在元素不存在时会引发 `KeyError`，而 `discard()` 方法不会。

- **`clear()` 方法**：`clear()` 方法移除集合中的所有元素。

## 数学集合操作

- **`issubset()` 和 `issuperset()` 方法**：`issubset()` 和 `issuperset()` 方法分别检查一个集合是否是另一个集合的子集或超集。

- **`isdisjoint()` 方法**：`isdisjoint()` 方法检查两个集合是否不相交，即没有共同元素。

- **并集操作符（`|`）**：并集操作符 `|` 返回一个包含两个集合所有元素的新集合。

- **交集操作符（`&`）**：交集操作符 `&` 返回一个只包含两个集合共有元素的新集合。

- **差集操作符（`-`）**：差集操作符 `-` 返回一个包含第一个集合中不在另一个集合中的元素的新集合。

- **对称差集操作符（`^`）**：对称差集操作符 `^` 返回一个包含只在第一个或第二个集合中出现但不同时出现的元素的新集合。

- **`in` 操作符**：你可以使用 `in` 操作符检查元素是否在集合中。

## 导入语句

- **导入语句**：要访问内置模块中定义的元素，使用导入语句。导入语句通常写在文件顶部。导入语句对函数、类、常量、变量以及模块中定义的其他元素的作用相同。

- **基本导入语句**：你可以使用 `import` 关键字后跟模块名来导入模块。

然后，如果你需要调用该模块中的函数，使用点表示法，模块名后跟函数名。

例如，在执行 `import math` 之后，`math.sqrt(36)` 返回 36 的平方根。

- **使用别名导入模块**：如果需要用不同名称（别名）导入模块，可以在导入语句末尾使用 `as` 关键字加上别名。这通常用于模块名较长或避免命名冲突。

例如，`import math as m` 将 `math` 模块赋予别名 `m`。

然后，你可以使用别名访问模块元素，如 `m.sqrt(36)`。

- **导入特定元素**：如果不需要模块中的所有内容，可以使用 `from` 导入特定元素。此时导入语句以 `from` 开头，后跟模块名，再用 `import` 关键字，最后是要导入的元素名。

例如，`from math import sqrt, sin, cos`。

然后，你可以在你的 Python 脚本中使用这些名称而无需模块前缀。

这很方便，但如果你已有同名函数或变量，可能会导致命名冲突。选择导入方式时请注意。

如果需要为这些名称指定别名，也可以使用 `as` 关键字加上别名。

例如，`from math import sqrt as square_root`。

- **带星号的导入语句（`*`）**：星号告诉 Python 导入模块中的所有内容，但导入后使用时不需要模块名前缀。

例如，使用 `from math import *` 后，你可以直接调用 `sqrt(36)`，无需 `math` 前缀。

不过，这通常不推荐，因为可能导致命名空间冲突，且难以判断名称来源。

## `if __name__ == '__main__'`

- **`__name__` 变量**：`__name__` 是 Python 中的一个特殊内置变量。当 Python 文件被直接执行时，Python 会将该变量的值设置为字符串 `"__main__"`。但如果该文件作为模块被导入到另一个 Python 脚本中，`__name__` 变量的值则被设置为该模块的名称。

这就是为什么你经常会在 Python 脚本中看到这个条件语句。它包含了你只想在 Python 脚本作为主程序运行时才执行的代码。

```python
if __name__ == '__main__':
    # Code
```

## Python 中的常见错误

- **SyntaxError**：当代码不符合语法规则时，Python 抛出的错误。例如，代码 `print("Hello there"` 会导致语法错误，错误信息为 `SyntaxError: '(' was never closed`，因为代码缺少闭合括号。
- **NameError**：当你尝试访问未定义的变量或函数时，Python 会抛出 `NameError`。例如，如果代码中有 `print(username)`，但未先定义 `username` 变量，则会出现名称错误，错误信息为 `NameError: name 'username' is not defined`。
- **TypeError**：当你对两个或多个不兼容的数据类型执行操作时，Python 会抛出此错误。例如，尝试将字符串与数字相加时，会出现错误 `TypeError: can only concatenate str (not "int") to str`。
- **IndexError**：如果访问列表或其他序列（如元组和字符串）中不存在的索引，会出现 `IndexError`。例如，在 `Hello world` 字符串中，最后一个字符的索引是 `10`。如果你这样访问字符 `greet = "hello world"; print(greet[11])`，会出现错误，错误信息为 `IndexError: string index out of range`。
- **AttributeError**：当你尝试在某种类型的对象上使用不存在的方法或属性时，Python 会抛出此错误。例如，在字符串 `"hello".append("!")` 上调用 `.append()` 会导致错误，错误信息为 `AttributeError: 'str' object has no attribute 'append'`。

## 异常处理

- **`try...except`**：用于执行可能引发异常的代码块。`try` 块包含可能出错的代码，`except` 块捕获指定异常并执行相应代码。

  你也可以链式使用多个 `except` 块，以处理更多类型的异常：

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

- **`else` 和 `finally`**：这两个块扩展了 `try...except`。如果没有异常发生，`else` 块会执行。`finally` 块无论是否发生错误都会执行。

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **异常对象**：允许你访问异常本身，以便更好地调试和打印直接的错误信息。要访问异常对象，需要使用 `as` 关键字。示例如下：

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **`raise` 语句**：允许你在满足某个条件时手动引发异常，例如 `raise ValueError("Invalid value")`。

## 异常信号

  `raise` 语句还可以抛出带有自定义消息的自定义异常。通过创建继承自 `Exception` 的类来定义自定义异常。

  使用命名该异常类的 `except` 块来处理自定义异常。

  - `raise` 语句也可以与 `from` 关键字一起使用，用于链式异常，显示不同错误之间的关系：

  ```py
  def parse_config(filename):
    try:
        with open(filename, 'r') as file:
            data = file.read()
            return int(data)
    except FileNotFoundError:
        raise ValueError('Configuration file is missing') from None
    except ValueError as e:
        raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```

## Python 类和对象

- **类定义**：类是创建对象的蓝图。它通过属性和方法定义对象将具有的行为。以下是 Python 中类定义的基本示例：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **创建对象**：对象是类的实例。通过调用类并传入必要的参数来创建对象。

- **调用对象的方法**：你可以调用对象的方法来执行操作或获取信息。

- **类和对象的区别**：类是可重用的模板，而对象是该类的具体实例，包含实际数据。

## 属性

- **实例属性**：在 `__init__()` 中使用 `self` 定义，每个对象独有。
- **类属性**：直接在类内部定义，所有实例共享。

## 方法

- **方法**：定义在类内部的函数，用于操作对象的属性。

- **调用方法**：使用点符号调用对象的方法。例如，对于 `dog = Dog('Jack', 3)`，`dog.bark()` 调用 `dog` 的 `bark` 方法。

## 双下划线（魔法）方法

- **定义**：以双下划线开头和结尾的特殊方法（例如 `__init__`、`__len__`、`__str__`、`__eq__`）。Python 内部使用它们来实现内置操作。

- **间接调用双下划线方法**：你不需要直接调用双下划线方法。Python 会在特定操作发生时自动调用它们。这些操作包括：

  - **算术操作，如加法、减法、乘法、除法等**。加法调用 `__add__()`，减法调用 `__sub__()`，乘法调用 `__mul__()`，除法调用 `__truediv__()`。

  - **字符串操作，如串接、重复、格式化和转换为文本**。串接调用 `__add__()`，重复调用 `__mul__()`，格式化调用 `__format__()`，文本转换调用 `__str__()` 和 `__repr__()`，等等。

  - **比较操作，如相等、小于、大于等**。相等检查调用 `__eq__()`，小于调用 `__lt__()`，大于调用 `__gt__()`，等等。

  - **迭代操作，比如使对象可迭代并遍历各项**。调用 `__iter__()` 返回一个迭代器，调用 `__next__()` 获取下一项。

## 什么是面向对象编程？

- **面向对象编程**：一种编程风格，开发者将代码中的所有内容视为现实世界中的对象。通常称为 OOP。帮助你有效组织和管理代码的四个关键原则是 **封装**、**继承**、**多态** 和 **抽象**。

## 什么是封装？

- **封装**：将对象的属性和方法打包成一个单元。它允许你通过一组简单的公共方法和属性隐藏对象的内部状态，这些公共接口就像门一样。门后是私有属性和方法，控制数据如何变化以及谁能访问它。
- **封装示例**：如果你想跟踪钱包余额，你会允许存款和取款，但不希望任何人篡改钱包余额本身。

- **单下划线和双下划线前缀属性的区别**：属性和方法前加单下划线表示仅供内部使用，这是约定，不强制禁止外部访问。前加双下划线则有效防止外部访问这些属性和方法。

## 什么是 Getter 和 Setter？

- **Getter 和 Setter**：允许你控制类属性的访问和修改。通过 getter 获取值，通过 setter 设置值。
- **属性**：连接 getter 和 setter，允许访问数据。当你获取、设置或删除值时，属性会在后台运行额外逻辑。
- **为什么用属性而不是方法**：属性比方法更易读、更简洁。它们允许你像访问普通属性一样使用点符号访问值，无需括号。
- **创建 Getter**：使用 `@property` 装饰器创建 getter。下面示例中的 `radius` getter 返回内部的 `_radius` 值。

- **创建 Setter**：定义同名方法并在其上方使用 `@<property_name>.setter` 装饰器来创建 setter：

```py
class Circle:
    def __init__(self, radius):
        self.radius = radius # Calling the setter

    @property
    def radius(self):  # A getter to get the radius
        return self._radius

    @radius.setter
    def radius(self, value):  # A setter to set the radius
        if value <= 0:
            raise ValueError('Radius must be positive')
        self._radius = value

my_circle = Circle(3)
print('Initial radius:', my_circle.radius) # Initial radius: 3

my_circle.radius = 8
print('After modifying the radius:', my_circle.radius) # After modifying the radius: 8
```

- **Python 如何处理 Getter 和 Setter**：定义 getter 和 setter 后，当你使用普通属性语法时，Python 会自动调用它们。读取 `my_circle.radius` 调用 getter；赋值 `my_circle.radius = 4` 调用 setter。

在 setter 内部，不应给属性名本身赋值，否则会导致 `RecursionError`。

- **删除器（Deleter）**：在设置和获取值后，你可以用 `deleter` 控制如何删除它。删除器在你对属性使用 `del` 语句时运行自定义逻辑。创建删除器时，使用 `@<property_name>.deleter` 装饰器。

## 什么是继承？它如何促进代码复用？

- **继承**：子类使用父类的属性和方法的过程。继承促进代码复用，提供清晰的层次结构，并允许定制行为而无需重写所有内容。实现继承时，子类接收父类名称：

例如，`class Child(Parent):` 开始定义一个子类。

- **单继承和多继承**：当子类继承自单个父类时，称为**单继承**。当子类继承自多个父类时，称为**多继承**。

例如，`class Child(Parent1, Parent2):` 继承自两个父类。

- **`super()` 函数**：允许你在类对某方法有不同实现或扩展时，调用父类的方法而不重复代码。

## 什么是多态？它如何促进代码复用？

- **多态**：面向对象编程原则，允许不同类使用相同的方法名，但每个类在调用时有不同的实现。

- **基于继承的多态**：父类定义方法，子类根据需要修改实现。

## 什么是名称重整？它如何工作？

- **名称重整**：Python 内部将以双下划线开头的属性重命名，添加一个下划线和类名作为前缀，将 `__attribute` 变为 `_ClassName__attribute`。
- **名称重整的目的**：主要目的是防止在使用继承时意外覆盖属性和方法。

## 什么是抽象？它如何帮助保持复杂系统的组织？

- **抽象**：编程概念，隐藏对象或系统的复杂实现细节，只显示必要特性。在 Python 和其他语言中，抽象通过提高复用性简化复杂系统。
- **抽象示例**：生活中汽车只让你使用方向盘、踏板和换挡杆，而不需要了解发动机或刹车的工作原理。
- **Python 如何实现抽象**：通过 `abc` 模块实现。该模块提供 `ABC` 类（抽象基类）和 `@abstractmethod` 装饰器。抽象基类定义子类必须实现的公共方法和属性，不能实例化。
- **抽象方法的定义**：用 `@abstractmethod` 定义抽象方法，子类必须重写它，即使有默认实现。抽象的基本语法如下：

```py
from abc import ABC, abstractmethod

# Define an abstract base class
class AbstractClass(ABC):
    @abstractmethod
    def abstract_method(self):
        pass

# Concrete subclass that implements the abstract method
class ConcreteClassOne(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassOne')

# Another concrete subclass
class ConcreteClassTwo(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassTwo')
```

## 算法和大 O 表示法

- **算法**：解决问题或完成任务的一组明确指令。算法必须在有限步骤内完成，每步必须精确且明确。

- **大 O 表示法**：描述算法在输入规模增加时的最坏情况性能或增长率。关注资源使用随输入规模的增长，忽略常数和低阶项。

### 常见时间复杂度

- **O(1) - 常数时间**：算法所需时间与输入规模无关。

- **O(log n) - 对数时间**：时间随输入增长缓慢。常见于通过分割问题规模的算法（如二分查找）。

- **O(n) - 线性时间**：运行时间与输入规模成正比。

- **O(n log n) - 线性对数时间**：高效排序算法如归并排序和快速排序的常见时间复杂度。

- **O(n²) - 平方时间**：运行时间呈平方增长。常见于嵌套循环。

### 空间复杂度

- **O(1) - 常数空间**：算法使用的内存与输入规模无关。
- **O(n) - 线性空间**：内存使用随输入规模成正比增长。
- **O(n²) - 平方空间**：内存使用随输入规模呈平方增长。

## 解决问题的技巧

- **理解问题**：多次阅读问题描述。确定输入、预期输出以及如何将输入转换为输出。

- **伪代码**：算法逻辑的高级描述，与语言无关。使用常见书面语言混合编程结构，如 `IF`、`ELSE`、`FOR`、`WHILE`。

- **边界情况**：算法应处理的边界上的特定有效输入。始终考虑并测试边界情况。

## 数组

- **静态数组**：初始化时大小固定。元素存储在相邻内存位置。程序执行期间大小不可变。

- **动态数组**：程序执行期间可自动增长或缩小。通过自动复制到更大数组来处理调整大小。

### Python 列表（动态数组）

Python 列表是动态数组。你可以通过索引访问和更新元素，使用 `append()` 或 `insert()` 添加元素，使用 `pop()` 或 `remove()` 删除元素。

### 动态数组的时间复杂度

- **访问**：O(1)
- **末尾插入**：平均 O(1)，调整大小时 O(n)
- **中间插入**：O(n)
- **删除**：中间 O(n)，末尾 O(1)

## 栈

- **栈**：后进先出（LIFO）数据结构。元素仅从顶部添加和移除。

- **入栈操作**：向栈顶添加元素。时间复杂度：O(1)。

- **出栈操作**：从栈顶移除元素。时间复杂度：O(1)。

Python 列表可以用作栈，使用 `append()` 压入元素，使用 `pop()` 弹出栈顶元素。

## 队列

- **队列**：先进先出（FIFO）数据结构。元素从尾部添加，从头部移除。

- **入队操作**：向队尾添加元素。时间复杂度：O(1)。

- **出队操作**：从队头移除元素。时间复杂度：O(1)。

`collections` 模块中的 `deque` 可以用作队列，使用 `append()` 入队，使用 `popleft()` 出队。

## 链表

- **链表**：线性数据结构，每个节点包含数据和指向下一个节点的引用。节点像链条一样连接。

### 单链表

- **结构**：每个节点有数据和一个指向下一个节点的引用。
- **遍历**：只能从头到尾向前移动。
- **头节点**：链表的第一个节点，通常是唯一可直接访问的节点。
- **尾节点**：链表的最后一个节点，指向 `None`。

### 操作和时间复杂度

- **开头插入**：O(1)
- **末尾插入**：O(n) - 需遍历到末尾
- **中间插入**：O(n) - 需遍历到指定位置
- **开头删除**：O(1)
- **末尾删除**：O(n) - 需遍历找到前一个节点
- **中间删除**：O(n) - 需遍历找到节点

### 双链表

- **结构**：每个节点有数据和两个引用：指向下一个节点和前一个节点。
- **遍历**：可双向移动。
- **内存**：由于额外引用，内存使用比单链表多。

## 哈希映射和集合

### 映射和哈希映射

- **映射（抽象数据类型）**：管理键值对集合。每个键必须唯一，但值可以重复。

- **哈希映射**：映射抽象数据类型的具体实现，使用哈希技术。通过哈希函数生成键的哈希值，决定在底层数组中的存储位置。

### Python 字典（哈希映射）

Python 字典实现了哈希映射。使用键访问、更新或删除值，使用 `in` 检查键是否存在。

### 哈希映射的时间复杂度

- **平均情况**：插入、获取、删除均为 O(1)
- **最坏情况**：大量哈希冲突时为 O(n)

### 集合

- **集合**：无序且唯一元素的集合。不允许重复，不维护特定顺序。

- **仅允许不可变元素**：集合只能包含不可变数据类型（数字、字串、元组），因为哈希值必须保持不变。

### 集合的时间复杂度

- **平均情况**：添加、移除、成员测试均为 O(1)
- **最坏情况**：哈希冲突导致为 O(n)

## 哈希冲突

- **哈希冲突**：不同键产生相同哈希值时发生。

- **冲突解决策略**：
  - **链式法**：每个数组索引指向一个链表，存储所有具有相同哈希值的元素。
  - **开放寻址法**：使用预定义序列寻找下一个可用索引。

## 何时使用各数据结构

- **列表**：需要有序、索引访问且大小未知时。
- **栈**：用于后进先出操作（撤销功能、表达式求值、回溯）。
- **队列**：用于先进先出操作（任务调度、广度优先搜索）。
- **链表**：频繁在开头插入/删除、大小未知且不需要随机访问时。
- **哈希映射**：快速键值查找、计数、缓存。
- **集合**：唯一性检查、数学集合操作、去重。

## 递归

- 递归是一种编程概念，允许你反复调用一个函数，直到达到基本情形。

下面是一个计算数字阶乘的递归函数示例：

```py
def find_factorial(n):
    if n == 0:
        return 1
    return n * find_factorial(n - 1)
```

在上面的例子中，`find_factorial` 函数递归调用，直到 `n` 达到 `0`。当 `n` 为 `0` 时，达到基本情形，函数返回 `1`。然后函数返回 `n` 与递归调用 `find_factorial(n - 1)` 结果的乘积。

- 递归允许你处理未知深度的结构，比如深度嵌套的字典和列表，或者文件树。
- 调用栈用于跟踪递归函数中的函数调用。每次调用函数时，它都会被添加到调用栈中。当达到基本情形时，函数调用会从栈中移除。
- 你应该仔细定义基本情形。否则，函数会不断调用自身，直到 Python 引起 `RecursionError`。
- 递归对于解决阶乘和斐波那契等数学问题、遍历树和图、生成排列组合非常有用。

## 查找算法

查找算法让你在某个项列表中查找目标。

在计算机科学中，有两种你应该了解的查找算法。它们是**线性查找**和**binary search**算法。理解这两种算法的区别以及何时使用每一种非常重要。

### 线性查找

- 线性查找迭代一个项列表，从头开始查看每一项，直到找到目标项。
- 如果找到目标项，则返回该项在列表中的索引。
- 如果未找到目标，它将返回 `-1`，这在大多数编程语言中表示**无效索引**。
- 因为线性查找会检查每一项直到找到目标，所以对于大量项的列表来说，它并不高效。
- 线性查找的时间复杂度是 `O(n)`，因为查找列表所需的时间随着列表大小线性增长。
- 线性查找的空间复杂度是 `O(1)`，因为它不需要任何额外空间来查找列表。

### 二分查找

- 二分查找通过将列表中的项分成两半，并查看目标值是否在列表中间来工作。
- 二分查找生效的条件是列表中的项必须按升序或降序排序。
- 二分查找是一种更高效的算法，用于在大型项列表中查找，因为它将项列表分成两半，并忽略任何未找到目标的那一半。
- 如果目标项位于列表中间，则返回目标项的索引。
- 如果未找到该项，算法会查看目标项是在列表的左半部分还是右半部分。
- 它继续将列表的剩余部分分成两半，直到找到目标项。
- 如果最终在列表中未找到目标项，则返回 `-1`
- 二分查找的时间复杂度是 `O(log n)`，因为查找列表所需的时间随着列表大小呈对数增长。
- 二分查找的空间复杂度是 `O(1)`，因为它在查找列表时不需要任何额外空间。

### 线性查找与二分查找的区别

- 与线性查找相比，二分查找更适合用于大型项列表。
- 线性查找的时间复杂度是 `O(n)`，因为查找列表所需的时间随着列表大小线性增长。
- 二分查找的时间复杂度是 `O(log n)`，因为查找列表所需的时间随着列表大小呈对数增长。

## 排序算法与分治法

在计算机科学中，分治是一种将问题拆分为更小子问题以便更容易解决的技术。递归是分治中常用的技术，分治是一种强大的策略，用于实现许多高效的排序算法，如归并排序。

### 归并排序

- 归并排序是一种遵循分治法的排序算法。
- 它通过递归地将一个列表划分为更小的子列表，直到每个子列表只包含一个元素。
- 然后它反复将子列表合并回去，按排序顺序。
- 归并排序的时间复杂度是 `O(n log n)`，因为列表不断被对半划分 `(log n)`，然后再合并 `(O(n))`。
- 归并排序的空间复杂度是 `O(n)`，因为它不是原地排序算法。

## 图概述

图是一组由边（连接）连接的节点（顶点）。每个节点可以连接多个其他节点，形成网络。图的不同类型包括：

- 有向图：边有方向（从一个节点到另一个节点），通常用直线和箭头表示。
- 无向图：边无方向，用简单线条表示。
- 顶点：每个节点关联一个标签或标识符。
- 有环图：包含环（起点和终点相同的路径）。
- 无环图（DAG）：不包含环。
- 边带标签：每条边有一个标签，通常绘制在对应边旁。
- 带权图：边带有权值（数值），可用于算术操作。
- 非连通图：包含两个或多个不通过边连接的节点。

图用于地图、网络、推荐系统、依赖解析等多种应用。

## 图遍历

涉及访问图中所有节点。两种主要算法：

- **广度优先搜索（BFS）**
  - 使用队列。
  - 按层级探索。
  - 在无权图中找到最短路径。

- **深度优先搜索（DFS）**
  - 使用栈（或递归）。
  - 先深入探索一个分支，再回溯。
  - 用于检测环和路径查找。

## 图的表示

图主要有两种表示方式：

- **邻接表**
  - 每个节点有一个邻居列表。
  - 对稀疏图空间高效。
  - 易于遍历邻居。

- **邻接矩阵**
  - 二维数组，行列代表节点。
  - 对大图空间消耗大。
  - 快速检查两节点间是否有边。

## 树

树是无环且连通的特殊图。关键属性包括：

- 无环（无起点和终点相同的路径）。
- 连通（每个节点都能从其他节点访问）。

### 常见树类型

最常见的树类型：

- 二叉树
  - 每个节点最多有两个子节点，左子节点和右子节点。

- 二叉搜索树（BST）
  - 每个左子节点小于父节点，每个右子节点大于父节点。

## 字典树（Trie）

也称前缀树，用于存储字符串集合，每个节点代表一个字符。

共享前缀只存储一次，适合自动补全和拼写检查。

查找和插入操作时间复杂度为 O(L)，L 是字符串长度。

## 优先队列

优先队列是一种抽象数据类型，每个元素有优先级。

队列和栈只考虑插入顺序，而优先队列考虑元素优先级。

标准队列遵循先进先出（FIFO），栈遵循后进先出（LIFO）。优先队列中，优先级高的元素先被处理，无视插入顺序。

## 堆

堆是一种特殊的基于树的数据结构，具有堆属性。

堆属性决定父节点和子节点的关系。有两种堆：

- 最大堆
  - 每个父节点的值大于或等于其子节点。
  - 最大元素位于根节点。

- 最小堆
  - 每个父节点的值小于或等于其子节点。
  - 最小元素位于根节点。

### Python `heapq` 模块

`heapq` 模块使用列表实现最小堆。使用 `heapq.heappush(heap, item)` 插入元素，`heapq.heappop(heap)` 移除最小元素，`heapq.heappushpop(heap, item)` 先插入再移除最小元素。`heapq.heapify(items)` 就地将列表转换为堆。

### 使用优先级

在堆中存储 `(priority, item)` 元组以按优先级排序。数字越小越先被移除，因此 `(1, "C")` 会先于 `(2, "B")` 被处理。

## 动态规划简介

- **定义**：动态规划是一种算法技术，通过将复杂问题分解为更简单的子问题并存储结果，避免重复计算。
- **重叠子问题**：在解决大问题时，多个子问题会重复出现。我们通过存储它们的解来避免重复计算。
- **最优子结构**：问题的最优解包含其子问题的最优解。这意味着我们可以通过组合较小部分的最优解来构建最佳解。

## 动态规划方案

- **备忘录法（自顶向下）**：存储昂贵函数调用的结果，当相同输入再次出现时返回缓存结果。

- **表格法（自底向上）**：从底层开始构建解决方案，填充子问题的解表。

## 使用动态规划的实际应用

- **路径优化**：GPS 系统使用动态规划算法来查找位置之间的最短路径。
- **文本处理**：拼写检查和自动完成功能通常依赖动态规划来计算单词之间的编辑距离。
- **金融建模**：投资策略和投资组合优化经常采用动态规划技术。
- **资源分配**：背包问题及其变体出现在调度、预算和资源管理中。

## 何时使用动态规划

你应该在以下情况下考虑使用动态规划：

- 问题可以分解为重叠的子问题。
- 问题具有最优子结构。
- 朴素的递归解法会涉及重复计算。
- 你需要以空间复杂度为代价来优化时间复杂度。
