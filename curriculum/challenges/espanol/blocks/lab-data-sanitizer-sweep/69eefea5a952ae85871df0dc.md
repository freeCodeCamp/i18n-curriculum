# --description--

En este laboratorio, limpiarás archivos de registro semi-estructurados reemplazando caracteres no permitidos con `#` y registrando cuántas entradas se procesaron.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

**Historias de usuario:**

1. Debes usar una declaración de función para crear una función llamada `sanitizeLog` con dos parámetros: `entry`, una cadena que representa una entrada de registro, y `disallowedCharacters`, un arreglo de cadenas de un solo carácter que representan los caracteres a reemplazar.
1. La función debe devolver una cadena `entry` modificada con cada carácter no permitido reemplazado por `#`. La coincidencia debe ser sensible a mayúsculas y minúsculas. Por ejemplo, si los caracteres no permitidos son `["e", "E", "o", "r"]`, entonces `DEBUG: Server started on port 3000` devuelve `D#BUG: S##v## sta#t#d #n p##t 3000`.
1. Debes crear una función llamada `cleanLogs` con dos parámetros: `logs`, un arreglo de cadenas que representan entradas de registro, y `disallowedCharacters`, un arreglo de cadenas de un solo carácter que representan los caracteres a reemplazar.
1. `cleanLogs` debe iterar sobre el arreglo dado de entradas de registro en orden.
1. Cuando `cleanLogs` llegue a una entrada de registro que contenga el marcador fatal `$`, debe detenerse y devolver `Sanitizing stopped. Failure Reason: Fatal character occurred.`
1. Una entrada de registro que comienza con el carácter `/` es una entrada informativa y no debe ser sanitizada. Debes llevar un conteo de las entradas informativas.
1. Todas las demás entradas de registro deben ser sanitizadas usando la función `sanitizeLog`. Debes llevar un conteo de las entradas sanitizadas.
1. Si `cleanLogs` termina sin encontrar un marcador fatal, debe devolver `Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.`, donde `X` es el número total de entradas, `Y` es el número de entradas sanitizadas y `Z` es el número de entradas informativas.

**Los siguientes arreglos de registros se usan en las pruebas:**

```js
let logs_1 = [
  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"
];

let logs_2 = [
  "FATAL: System overload detected, shutting down",
  "DEBUG: token=def456$ refreshed for session",
  "ERROR: Null pointer exception in module auth"
];

let logs_3 = [
  "ERROR: Failed to connect to db, retry=3",
  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
