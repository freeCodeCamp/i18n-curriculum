# --description--

在這個實驗中，你將為鏈結串列資料結構實作額外的操作，並以你在前一個工作坊中創建的 `LinkedList` 類別為基礎。

**目標：** 完成以下使用者故事並通過所有測試以完成實驗。

**使用者故事：**

1. 你的 `LinkedList` 類別應該有一個 `contains` 方法，該方法接受一個元素作為引數。如果該元素存在於鏈結串列中，則應傳回 `True`，否則傳回 `False`。
1. 你的 `LinkedList` 類別應該有一個 `get_at` 方法，該方法接受一個索引作為引數。它應該傳回鏈結串列中該索引位置的元素。如果索引超出範圍，則應傳回 `None`。
1. 你的 `LinkedList` 類別應該有一個 `insert_at` 方法，該方法接受一個索引和一個元素作為引數。它應該在鏈結串列中指定的位置插入該元素，並更新 `length` 屬性。索引等於列表長度是有效的，應該將元素添加到末尾。如果索引超出範圍，則不應修改列表。
1. 你的 `LinkedList` 類別應該有一個 `remove_at` 方法，該方法接受一個索引作為引數。它應該移除鏈結串列中該索引位置的節點，並更新 `length` 屬性。如果索引超出範圍，則不應修改列表。
1. 你的 `LinkedList` 類別應該有一個 `clear` 方法，該方法會移除鏈結串列中的所有元素，將其重設為空狀態，並將 `head` 設為 `None`，`length` 設為 `0`。

**注意：** 後續的一些測試依賴於先前的方法。例如，如果 `get_at` 沒有正確實作，即使 `insert_at` 和 `remove_at` 方法接近正確，相關測試也可能會失敗。

```py
class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
```
