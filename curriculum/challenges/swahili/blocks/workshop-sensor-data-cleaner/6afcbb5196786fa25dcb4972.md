# --description--

Katika terminali, unapaswa kuona kitu kama `<filter object at 0x...>` badala ya vipimo. Hii hutokea kwa sababu `filter()` inarudisha iterator, ambayo inakupa vitu moja kwa moja badala ya kuviweka vyote kwenye orodha.

Ili kukusanya vitu vya iterator katika orodha, unaweza kuipitisha kwa kitendakazi cha `list()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

Zungusha wito wa `filter()` ulipewa thamani `valid_readings` ndani ya wito wa `list()`. Katika terminali, unapaswa kuona vipimo bila misimbo ya makosa ya `-999`.
