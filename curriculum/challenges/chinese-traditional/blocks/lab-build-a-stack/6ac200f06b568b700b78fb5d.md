# --description--

在這個實驗中，你將使用函式實作一個堆疊資料結構。堆疊是一種後進先出（LIFO）的資料結構，元素會從頂端被加入和移除。

你的堆疊將是一個字典，其 `collection` 鍵包含一個元素列表。堆疊的頂端是列表的末端，因此列表中的最後一個元素是最近加入的。

**目標：** 完成以下使用者故事並通過所有測試以完成實驗。

**使用者故事：**

1. 你應該有一個 `init_stack` 函式，傳回一個字典，其 `collection` 鍵設為空列表。
1. 你應該有一個 `push` 函式，接受一個堆疊和一個元素，並將該元素添加到堆疊頂端。
1. 你應該有一個 `pop` 函式，接受一個堆疊，移除並傳回其頂端元素，若堆疊為空則傳回 `None`。
1. 你應該有一個 `peek` 函式，接受一個堆疊，傳回其頂端元素但不移除，若堆疊為空則傳回 `None`。
1. 你應該有一個 `is_empty` 函式，接受一個堆疊，若其不含任何元素則傳回 `True`，否則傳回 `False`。
1. 你應該有一個 `clear` 函式，接受一個堆疊，並移除其所有元素。

**注意：** 大多數測試依賴 `init_stack` 和 `push` 函式。請先實作它們，因為 `pop`、`peek`、`is_empty` 和 `clear` 的測試需要先向堆疊添加元素。

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
