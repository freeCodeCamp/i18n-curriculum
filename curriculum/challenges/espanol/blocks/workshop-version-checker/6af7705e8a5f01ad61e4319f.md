# --description--

En este taller, practicarás trabajar con tuplas construyendo un programa que verifica si una app necesita una actualización.

Cada versión de un software recibe un número de versión, para que las personas puedan distinguir las versiones y saber cuál es más reciente. Una convención común es usar tres números separados por puntos, en el formato `MAJOR.MINOR.PATCH`:

- El número `MAJOR` aumenta con cambios grandes que podrían impedir que código o archivos antiguos funcionen con la nueva versión.
- El número `MINOR` aumenta cuando se agregan nuevas funcionalidades de forma que sigue funcionando con lo anterior.
- El número `PATCH` aumenta para correcciones pequeñas, como arreglos de bugs, que no agregan nuevas funcionalidades.

Una versión como `2.1.0` puede almacenarse como una tupla de tres enteros: los números major, minor y patch.

Crea una variable llamada `releases` y asígnale una tupla que contenga las siguientes tuplas de versión, en este orden:

```py
(1, 9, 0), (2, 0, 0), (1, 9, 1), (2, 1, 0),
(2, 1, 1), (2, 2, 0), (1, 9, 2), (2, 2, 1)
```

Las versiones están listadas en el orden en que se publicaron, no de la versión más baja a la más alta. La antigua línea `1.9` siguió recibiendo correcciones incluso después de que salió la versión `2.0.0`.
