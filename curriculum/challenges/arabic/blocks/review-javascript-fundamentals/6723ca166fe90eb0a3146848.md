## دالة البناء للسلسلة النصية وطريقة `toString()`

- **التعريف**: كائن السلسلة النصية يُستخدم لتمثيل تسلسل من الأحرف. تُنشأ كائنات السلسلة النصية باستخدام دالة البناء `String`، التي تغلف القيمة الأولية داخل كائن.

:::interactive_editor

```js
const greetingObject = new String("Hello, world!");

console.log(typeof greetingObject); // "object"
```

:::

- **طريقة `toString()`**: تُحوّل هذه الطريقة القيمة إلى تمثيلها كسلسلة نصية. يمكن استخدامها للأعداد، القيم المنطقية، المصفوفات، والكائنات.

:::interactive_editor

```js
const num = 10;
console.log(num.toString()); // "10"

const arr = [1, 2, 3];
console.log(arr.toString()); // "1,2,3"
```

:::

تقبل هذه الطريقة معاملًا اختياريًا يسمى radix وهو رقم من 2 إلى 36. يمثل هذا الرقم أساس العد، مثل الأساس 2 للثنائي أو الأساس 8 للأوكتال. إذا لم يُحدد radix، فإنه يُفترض الأساس 10، وهو النظام العشري.


:::interactive_editor

```js
const num = 10;
console.log(num.toString(2)); // "1010"(binary)
```

:::

## دالة البناء للعدد

- **التعريف**: دالة البناء `Number` تُستخدم لإنشاء كائن عدد. يحتوي كائن العدد على بعض الخصائص والطرق المفيدة مثل `isNaN` و`toFixed`. في معظم الأحيان، ستستخدم دالة البناء `Number` لتحويل أنواع بيانات أخرى إلى نوع العدد.

:::interactive_editor

```js
const myNum = new Number("34");
console.log(typeof myNum); // "object"

const num = Number('100');
console.log(num); // 100

console.log(typeof num); // number
```

:::

## أفضل الممارسات لتسمية المتغيرات والدوال

- **camelCasing**: حسب الاصطلاح، يستخدم مطورو JavaScript تسمية المتغيرات والدوال بطريقة camel casing. حيث تكون الكلمة الأولى كلها أحرف صغيرة والكلمات التالية تبدأ بحرف كبير. مثال: `isLoading`.

- **تسمية القيم المنطقية**: للمتغيرات المنطقية، من الممارسات الشائعة استخدام بادئات مثل "is"، "has"، أو "can".

```js
let isLoading = true;
let hasPermission = false;
let canEdit = true;
```

- **تسمية الدوال**: يجب أن يوضح اسم الدالة بوضوح ما تقوم به. للدوال التي تُرجع قيمة منطقية (تُسمى غالبًا predicates)، يمكنك استخدام نفس البادئات "is"، "has"، أو "can". للدوال التي تسترجع بيانات، من الشائع البدء بكلمة "get". للدوال التي تعيّن بيانات، من الشائع البدء بكلمة "set". لدوال معالجي الأحداث، قد تستخدم بادئة "handle" أو لاحقة "Handler".

```js
function getUserData() { /* ... */ }

function isValidEmail(email) { /* ... */ }

function getProductDetails(productId) { /* ... */ }

function setUserPreferences(preferences) { /* ... */ }

function handleClick() { /* ... */ }
```

- **تسمية المتغيرات داخل الحلقات**: عند تسمية متغيرات التكرار في الحلقات، من الشائع استخدام أحرف مفردة مثل `i`، `j`، أو `k`.

```js
for (let i = 0; i < array.length; i++) { /* ... */ }
```

## العمل مع المصفوفات المتفرقة

- **التعريف**: من الممكن وجود مصفوفات تحتوي على خانات فارغة. تُعرف الخانات الفارغة بأنها خانات لا تحتوي على أي شيء بداخلها. هذا يختلف عن خانات المصفوفة التي تحتوي على القيمة `undefined`. تُعرف هذه الأنواع من المصفوفات بالمصفوفات المتفرقة.

:::interactive_editor

```js
const sparseArray = [1, , , 4];
console.log(sparseArray.length); // 4
```

:::

## أدوات التدقيق والتنسيق

- **أدوات التدقيق**: أداة تدقيق الكود هي أداة تحليل كود ثابت تُشير إلى أخطاء البرمجة، والأخطاء البرمجية، وأخطاء الأسلوب، والبُنى المشبوهة. مثال شائع لأداة تدقيق هو ESLint.
- **أدوات التنسيق**: أدوات التنسيق هي أدوات تُنسق كودك تلقائيًا ليتوافق مع دليل أسلوب محدد. مثال شائع لأداة تنسيق هو Prettier.

## إدارة الذاكرة

- **التعريف**: إدارة الذاكرة هي عملية التحكم في الذاكرة، تخصيصها عند الحاجة وتحريرها عند عدم الحاجة إليها. يستخدم JavaScript إدارة ذاكرة تلقائية. هذا يعني أن JavaScript (وبشكل أدق، محرك JavaScript في متصفح الويب) يتولى تخصيص الذاكرة وتحريرها نيابة عنك. لا تحتاج إلى تحرير الذاكرة صراحة في كودك. تُسمى هذه العملية التلقائية غالبًا "جمع القمامة".

## الإغلاقات (Closures)

- **التعريف**: الإغلاق هو دالة لديها وصول إلى المتغيرات في نطاقها الخارجي (النطاق الحرفي المحيط)، حتى بعد أن تنتهي الدالة الخارجية من التنفيذ.

:::interactive_editor

```js
function outerFunction(x) {
  let y = 10;
  function innerFunction() {
    console.log(x + y);
  }
  return innerFunction;
}

let closure = outerFunction(5);
closure(); // 15
```

:::

## الكلمة المفتاحية `var` والرفع (Hoisting)

- **التعريف**: كانت `var` هي الطريقة الأصلية لإعلان المتغيرات قبل 2015. لكن ظهرت بعض المشاكل مع `var` من حيث النطاق، إعادة الإعلان، وأكثر. لهذا السبب يستخدم برمجة JavaScript الحديثة `let` و`const` بدلاً منها.
- **إعادة إعلان المتغيرات باستخدام `var`**: إذا حاولت إعادة إعلان متغير باستخدام `let`، ستحصل على `SyntaxError`. لكن مع `var`، يُسمح بإعادة الإعلان.

```js
// Uncaught SyntaxError: Identifier 'num' has already been declared 
let num = 19;
let num = 18;

var myNum = 5;
var myNum = 10; // This is allowed and doesn't throw an error

console.log(myNum) // 10
```

- **`var` والنطاق**: المتغيرات المعلنة باستخدام `var` داخل كتلة (مثل جملة `if` أو حلقة `for`) تظل قابلة للوصول خارج تلك الكتلة.

:::interactive_editor

```js
if (true) {
  var num = 5;
}
console.log(num); // 5
```

:::

- **الرفع**: هذا هو السلوك الافتراضي في JavaScript الذي ينقل الإعلانات إلى أعلى نطاقاتها خلال مرحلة الترجمة قبل تنفيذ الكود. عند إعلان متغير باستخدام الكلمة المفتاحية `var`، يقوم JavaScript برفع الإعلان إلى أعلى نطاقه.

:::interactive_editor

```js
console.log(num); // undefined
var num = 5;
console.log(num); // 5
```

:::

عندما تعلن عن دالة باستخدام صيغة إعلان الدالة، يتم رفع اسم الدالة وجسم الدالة معًا. هذا يعني أنه يمكنك استدعاء دالة قبل إعلانها في كودك.

:::interactive_editor

```js
sayHello(); // "Hello, World!"

function sayHello() {
  console.log("Hello, World!");
}
```

:::

إعلانات المتغيرات التي تتم باستخدام `let` أو `const` تُرفع، لكنها لا تُهيأ، ولا يمكنك الوصول إليها قبل الإعلان الفعلي في كودك. يُشار إلى هذا السلوك غالبًا باسم "منطقة الموت الزمنية".

:::interactive_editor

```js
console.log(num); // Throws a ReferenceError
let num = 10;
```

:::

## العمل مع الاستيراد، التصدير والوحدات

- **الوحدة**: هي وحدة كود مستقلة تحتوي على دوال، أصناف، أو متغيرات ذات صلة. لإنشاء وحدة، اكتب كود JavaScript في ملف منفصل.
- **التصدير**: أي متغيرات، دوال، أو أصناف تريد إتاحتها لأجزاء أخرى من التطبيق يجب تصديرها صراحة باستخدام الكلمة المفتاحية `export`. هناك نوعان من التصدير: التصدير المسمي والتصدير الافتراضي.
- **الاستيراد**: لاستخدام العناصر المصدرة في جزء آخر من التطبيق، تحتاج إلى استيرادها باستخدام الكلمة المفتاحية `import`. أنواع الاستيراد تشمل الاستيراد المسمي، الاستيراد الافتراضي، واستيراد النطاق.

```js
// Within a file called math.js, we export the following functions:

// Named export
export function add(num1, num2) {
  return num1 + num2;
}

// Default export
export default function subtract(num1, num2) {
  return num1 - num2;
}

// Within another file, we can import the functions from math.js.

// Named import - This line imports the add function.
// The name of the function must exactly match the one exported from math.js.
import { add } from './math.js';

// Default import - This line imports the subtract function.
// The name of the function can be anything.
import subtractFunc from './math.js';

// Namespace import - This line imports everything from the file.
import * as Math from './math.js';

console.log(add(5, 3)); // 8
console.log(subtractFunc(5, 3)); // 2
console.log(Math.add(5, 3)); // 8
console.log(Math.subtract(5, 3)); // 2
```
