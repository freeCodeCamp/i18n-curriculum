# --description--

現在、`program` は自分がどの部署に属しているかを `departmentId` で知っていますが、部署はまだどのプログラムが属しているかを知りません。
各 `program.id` を `departmentsById[departmentId].programIds` に追加してください。

これにより双方向の関係が作られます。部署は `programIds` を通じて自分のプログラムを参照でき、各プログラムは `departmentId` を通じて自分の部署を参照できます。どちらのオブジェクトも相手の完全なデータを保持する必要はありません。

プログラムIDを追加する前に、前のステップで使った `console.log(programsById[program.id])` を削除してください。

`departmentData.programs` のループが終わった後に、`departmentsById[departmentId]` をコンソールにログしてください。
