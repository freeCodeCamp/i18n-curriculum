# --description--

<dfn>色彩模型</dfn> 是一種表述顏色的系統。主要有兩種色彩模型：用於電子裝置的 <dfn>加色</dfn> RGB 模型，以及用於印刷的 <dfn>減色</dfn> CMYK（青色、品紅、黃色、黑色）模型。

在這個專案中，你將使用 RGB 模型。RGB 代表紅色、綠色和藍色，這是光的三原色。這三種顏色以不同的色階組合，產生廣泛的色彩。使用 RGB 時，顏色從黑色開始，隨著不同層次的紅、綠、藍被加入而改變。

你可以用 CSS 的 `rgb` 函式來觀察這點，它讓你使用 RGB 色彩模型定義顏色。

創建一個新的 CSS 規則，標的為類別 `container`，並將其 `background-color` 設為黑色，使用 `rgb(0, 0, 0)`。
