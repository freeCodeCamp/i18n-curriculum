## Що таке кортеж?

Кортеж — це тип даних у Python, який використовується для створення впорядкованої послідовності значень. Кортежі можуть містити змішаний набір типів даних, як-от:

```py
developer = ('Alice', 34, 'Rust Developer')
```

Коми створюють кортеж, тому круглі дужки необов’язкові в присвоєнні такого виду:

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

Щоб створити кортеж з одним елементом, потрібна кома в кінці:

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

Порожній кортеж записується як `()`.

Кортежі схожі на списки, але поки списки є змінним типом даних, кортежі — незмінні. Це означає, що після створення кортежу його референси елементів не можна замінити, додати або видалити.

Якщо ви спробуєте оновити один із елементів кортежу, ви отримаєте `TypeError`:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## Змінні об’єкти всередині кортежів

Кортеж може містити змінний об’єкт, наприклад список. Незмінність кортежу не заважає змінювати цей вкладений об’єкт:

```py
def add_greeting(values):
    values[0].append('hi')

greetings = (['hello'],)
original_list = greetings[0]

add_greeting(greetings)
print(greetings) # (['hello', 'hi'],)
print(greetings[0] is original_list) # True
```

Функція змінює список всередині кортежу. Кортеж все ще містить референс на той самий список. Призначення іншого списку `greetings[0]` викличе `TypeError`, бо це замінило б референс елемента кортежу.

## Доступ до елементів кортежу

Щоб отримати доступ до елемента кортежу, ви можете використати дужкову нотацію та номер індексу:

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

Якщо потрібно отримати доступ до елементів, починаючи з кінця кортежу, можна використати від’ємну індексацію. Ось приклад використання від’ємного індексу для доступу до передостаннього елемента кортежу:

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

Якщо ви спробуєте передати номер індексу, який перевищує або дорівнює довжині кортежу, ви отримаєте `IndexError` такого вигляду:

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## Використання конструктора `tuple()`

Інший спосіб створити кортеж — використати конструктор `tuple()` ось так:

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

Для конструктора `tuple()` ви можете передавати різні ітеровані об’єкти, такі як рядки, списки та навіть інші кортежі.

## Перевірка, чи є елемент у кортежі

Щоб перевірити, чи є елемент у кортежі, можна використати ключове слово `in` ось так:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## Розпакування значень із кортежу

Ви також можете розпакувати елементи з кортежу так само, як і зі списків:

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

У цьому прикладі `name` має значення `'Alice'`, `age` має значення `34`, а `job` має значення `'Rust Developer'`.

Якщо потрібно зібрати всі залишкові елементи з кортежу, можна використати оператор зірочки (`*`) ось так:

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

Тут `name` має значення `'Alice'`, а `rest` — це список, що складається з числа `34` і рядка `'Rust Developer'`.

## Використання кортежів у одночасному присвоєнні

Ви можете створити кортеж справа від присвоєння і розпакувати його у змінні зліва:

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

Python оцінює всі вирази справа перед тим, як призначити їх значення змінним зліва. Це дозволяє поміняти місцями два значення без тимчасової змінної:

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## Повернення кортежу з функції

Функція може повернути кортеж, розмістивши через кому значення після `return`:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

Значення, розділені комами, створюють один кортеж, який повертає функція. Тут `return first, second` еквівалентне `return (first, second)`. Круглі дужки необов’язкові.

Ви можете розпакувати повернутий кортеж безпосередньо у змінні:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## Вирізання частини кортежу

Як і зі списком, ви можете використати оператор зрізу для кортежу, щоб витягти його частину. Ось приклад витягування елементів `'pie'` і `'cookies'` у окремий кортеж:

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

Пам’ятайте, що перше число позначає початковий індекс для витягування, а друге — кінцевий індекс. Але зверніть увагу, що елемент із кінцевим індексом не включається до витягнутого кортежу.

## Порівняння кортежів

Python порівнює кортежі лексикографічно. Це означає, що він порівнює відповідні елементи зліва направо. Перша нерівна пара визначає результат:

```py
print((1, 9) < (2, 0)) # True
```

Тут `1` менше за `2`, тому перший кортеж менший. Python не потрібно порівнювати `9` і `0`.

Якщо перші елементи рівні, Python переходить до наступної пари:

```py
print((1, 3) < (1, 5)) # True
```

Обидва кортежі починаються з `1`, тому Python порівнює `3` з `5`, щоб визначити результат.

Якщо всі відповідні елементи рівні, менший той кортеж, що коротший. Кортежі з однаковою довжиною і рівними відповідними елементами рівні:

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

Значення в першій нерівній парі мають підтримувати порівняння за порядком. Інакше Python викличе `TypeError`:

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

Тут перші елементи рівні, але Python не може впорядкувати ціле число `3` і рядок `'five'`.

Пізніші елементи не обов’язково мають бути порівнювані, якщо раніша пара вже визначила результат:

```py
print((1, 3) < (2, 'five')) # True
```

## Видалення елементів із кортежу

Якщо потрібно видалити елемент із кортежу, це неможливо, оскільки кортежі є незмінними. Тож цей приклад призведе до помилки:

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## Вибір між кортежами та списками

Отже, коли варто використовувати кортеж замість списку?

Якщо вам потрібна динамічна колекція елементів, де можна додавати, видаляти та оновлювати елементи, слід використовувати список. Якщо потрібна послідовність, у якій референси елементів залишаються фіксованими, можна використовувати кортеж. Пам’ятайте, що будь-які змінні об’єкти всередині нього все одно можуть змінюватися.
