# --description--

النطاق يحدد أين يمكنك استخدام متغير في كودك.

لدى Python قواعد نطاق إضافية. ركز الآن على النطاق المحلي والعام.

المتغير الذي يُنشأ خارج دالة له نطاق عام. يمكنك استخدامه داخل الدوال وخارجها.

المتغير الذي يُنشأ داخل دالة له نطاق محلي. يمكنك استخدامه فقط داخل تلك الدالة. معلمات الدالة هي أيضًا متغيرات محلية.

إليك مثال على النطاق المحلي والعام:

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

المتغير `tax_rate` عام لأنه يُنشأ خارج الدالة. يمكن للدالة `calculate_tax` قراءته، ويمكن لاستدعاء `print()` الثاني قراءته أيضًا.

المعلمة `price` والمتغير `tax` محليان للدالة `calculate_tax`. هما متاحان أثناء تشغيل تلك الدالة، لكن ليس خارجها. استدعاء `print()` الأخير يرفع خطأ `NameError` لأن `tax` غير معرف في النطاق العام.
