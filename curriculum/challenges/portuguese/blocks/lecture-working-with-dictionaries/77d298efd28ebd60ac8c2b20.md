# --description--

Você aprendeu a criar dicionários e acessar e atualizar seus valores. Agora você vai usar métodos de dicionário, copiar dicionários e explorar como funções podem modificá-los.

Cada exemplo de método de dicionário abaixo começa com este dicionário:

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## Métodos do dicionário

Dicionários também possuem métodos úteis para realizar operações comuns.

O método `.get()` recupera o valor associado a uma chave. É semelhante à notação por colchetes que você aprendeu na lição anterior, mas sua vantagem é que você pode definir um valor padrão, para não receber um erro se a chave não existir:

```python
dictionary.get(key, default)
```

Neste exemplo, se a chave `toppings` não existir, ela retornará uma lista vazia, que é o valor padrão que estamos passando aqui como o segundo argumento. Mas se `toppings` existir, ele retornará esse valor:

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

Os métodos `.keys()` e `.values()` retornam um objeto view com todas as chaves e valores no dicionário, respectivamente:

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

Um objeto view é apenas uma forma de ver o conteúdo de um dicionário sem criar uma cópia separada dos dados.

O método `.items()` retorna um objeto view com todos os pares chave-valor no dicionário, incluindo tanto as chaves e os valores:

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

O método `.clear()` remove todos os pares chave-valor do dicionário:

```python
pizza.clear()
```

O método `.pop()` remove o par chave-valor com a chave que você especifica como o primeiro argumento e retorna seu valor. Se a chave não existir, ela retorna o valor padrão que você especificar como o segundo argumento. Se a chave não existir e você não passar um valor padrão, um `KeyError` será gerado:

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

No Python 3.7 e versões mais recentes, o método `.popitem()` remove o último item inserido:

```python
pizza.popitem()
```

O método `.update()` atualiza os pares chave-valor com os pares chave-valor de outro dicionário. Se eles tiverem chaves em comum, seus valores são sobrescritos.

Neste exemplo, estamos atualizando o dicionário `pizza`. A chave `price` existe em ambos, então seu valor será substituído por `15`.

Mas `total_time` é novo, então será adicionado ao dicionário `pizza` como um novo par chave-valor:

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

Este é o novo dicionário com o `price` atualizado e o novo `total_time`. Observe como o preço agora é `15` e `total_time` é um novo par chave-valor:

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### Atribuição e cópias rasas

Como você aprendeu com listas, atribuir um dicionário a outra variável cria um alias. Ambos os nomes referem-se ao mesmo objeto:

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

Para criar um dicionário externo separado, use o método `.copy()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

Substituir uma entrada em `copied_settings` não substitui a entrada correspondente em `settings`. No entanto, `.copy()` faz uma **cópia rasa**: cria um novo dicionário externo cujas chaves e valores referem-se aos mesmos objetos do dicionário original. Objetos mutáveis aninhados ainda são compartilhados:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

Os dois dicionários são objetos diferentes, mas suas entradas `languages` referem-se à mesma lista. Acrescentar itens a essa lista é visível em ambos os dicionários. Substituir `copied_settings['languages']` por uma nova lista mudaria apenas essa entrada na cópia.

Você também pode criar uma cópia rasa passando um dicionário para `dict()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

Como `.copy()`, `dict(settings)` cria um novo dicionário externo, mas a lista aninhada ainda é compartilhada. Substituir uma entrada em qualquer dicionário afeta apenas aquele dicionário, enquanto mudar a lista compartilhada é visível em ambos.

## Mutando um dicionário através de um parâmetro de função

As mesmas regras de passagem de argumentos que você aprendeu com listas se aplicam a dicionários. Um parâmetro inicialmente refere-se ao objeto passado como argumento. Atualizar uma entrada por meio desse parâmetro modifica o dicionário compartilhado:

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

A função retorna uma string de status, enquanto `preferences` muda pela referência compartilhada. Retornar um valor e modificar um objeto são efeitos separados. A função não precisa retornar o dicionário para que as mudanças sejam visíveis fora dela. Reatribuir o parâmetro local para um dicionário diferente não substituiria o dicionário referenciado por `preferences`.

## Usando um dicionário como argumento padrão

Lembre-se que uma lista padrão é criada quando a função é definida e reutilizada em chamadas que omitem o argumento. Um dicionário padrão se comporta da mesma forma:

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

A segunda chamada reutiliza o dicionário alterado pela primeira chamada. Isso significa que as configurações se acumulam em chamadas independentes, mesmo que cada chamada tenha seu próprio nome local para o parâmetro.

Quando cada chamada deve começar com um dicionário novo, use o padrão `None` como valor padrão:

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

Cada chamada que omite `settings` ou passa `None` cria um dicionário novo. Passar um dicionário existente ainda permite que a função modifique esse objeto. Use `settings is None` aqui: `if not settings` também corresponderia a um dicionário vazio passado como argumento e o substituiria por um novo dicionário local.
