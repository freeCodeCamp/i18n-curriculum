# --description--

今のところ、エレベーターは各階に直接ジャンプしています。実際のエレベーターは目的の階に到達するまで、一度に1階ずつ移動します。

`target` を出力した後、`current_floor` が `target` と等しくない間実行されるネストされた `while` ループを作成してください。その中で、`if` 文を使って `current_floor` が `target` より小さいかどうかを確認します。もしそうなら、`current_floor` を `1` 増やしてください。そうでなければ、`current_floor` を `1` 減らしてください。

各イテレーションでエレベーターは `target` に1階ずつ近づくので、最終的に `current_floor` は `target` と等しくなり、ネストされたループはストップします。
