## الأخطاء الشائعة في Python

- **`SyntaxError`**: الخطأ الذي تُرجعه Python عندما لا يتبع كودك القواعد النحوية الخاصة بها. على سبيل المثال، الكود `print("Hello there"` سيؤدي إلى خطأ نحوي مع الرسالة `SyntaxError: '(' was never closed`، لأن الكود ينقصه قوس إغلاق.
- **`NameError`**: تُرجع Python خطأ `NameError` عندما تحاول الوصول إلى متغير أو دالة لم تقم بتعريفها. مثلًا، إذا كتبت السطر `print(username)` في كودك دون أن تعرّف متغير باسم `username` أولًا، ستحصل على خطأ باسم `NameError: name 'username' is not defined`.
- **`TypeError`**: هذا هو الخطأ الذي تُرجعه Python عندما تطبق عملية أو دالة على كائن من نوع غير مناسب. مثلًا، إذا حاولت جمع سلسلة نصية مع رقم، ستحصل على الخطأ `TypeError: can only concatenate str (not "int") to str`.
- **`IndexError`**: ستحصل على `IndexError` إذا حاولت الوصول إلى فهرس غير موجود في قائمة أو متتالية أخرى مثل الصفوف المرتبة أو السلاسل النصية. على سبيل المثال، في سلسلة نصية `Hello world`، فهرس آخر حرف هو `10`. إذا حاولت الوصول إلى حرف بهذا الشكل: `greet = "hello world"; print(greet[11])`، ستحصل على خطأ مع الرسالة `IndexError: string index out of range`.
- **`AttributeError`**: تُرجع Python هذا الخطأ عندما تحاول استخدام طريقة أو خاصية غير موجودة في كائن من هذا النوع. مثلًا، استدعاء `.append()` على سلسلة نصية مثل `"hello".append("!")` سيؤدي إلى خطأ مع الرسالة `AttributeError: 'str' object has no attribute 'append'`.

## تقنيات تصحيح الأخطاء الجيدة في Python

- **استخدام دالة `print`**: إدخال عبارات `print()` في نقاط مختلفة من كودك أثناء تصحيح الأخطاء يساعدك على رؤية قيم المتغيرات وكيف يتدفق الكود.
- **استخدام مصحح الأخطاء المدمج في Python (`pdb`)**: توفر Python وحدة `pdb` لتصحيح الأخطاء كجزء من مكتبة Python القياسية. استدعاء `pdb.set_trace()` يوقف التنفيذ ويفتح موجه تفاعلي. يمكنك إدخال `help` لعرض الأوامر، و`whatis` لفحص نوع تعبير، و`continue` (أو ألقابها `cont` و`c`) لاستئناف تنفيذ البرنامج.
- **الاستفادة من أدوات تصحيح الأخطاء في بيئات التطوير المتكاملة**: توفر بيئات التطوير المتكاملة (IDEs) ومحررات الكود مثل PyCharm وVS Code أدوات تصحيح مرئية. على سبيل المثال، يوفر VS Code ما يلي:
  - **نقاط التوقف**: انقر في مسافة الفراغ في المحرر لوضع نقطة توقف (تمثل بنقطة حمراء) حيث يجب أن يتوقف التنفيذ.
  - **فحص المتغيرات ووحدة تحكم التصحيح**: مرر فوق المتغيرات أو افحص لوحة المتغيرات لرؤية القيم الحالية، واستخدم وحدة تحكم التصحيح لتقييم التعبيرات تفاعليًا.
  - **عناصر التحكم في التنقل خطوة بخطوة**:
    - **استمرار (<kbd>F5</kbd>)**: يستأنف التنفيذ حتى نقطة التوقف التالية.
    - **تخطي (<kbd>F10</kbd>)**: ينفذ السطر الحالي وينتقل للسطر التالي دون الدخول في استدعاءات الدوال.
    - **الدخول (<kbd>F11</kbd>)**: يدخل داخل الدالة المستدعاة للتنقل عبر أسطرها.
    - **الخروج (<kbd>Shift</kbd> + <kbd>F11</kbd>)**: ينهي الدالة الحالية ويعود إلى المستدعي.

## معالجة الاستثناءات

- **`try...except`**: تُستخدم لتنفيذ كتلة كود قد ترفع استثناءً. كتلة `try` هي المكان الذي تتوقع فيه حدوث خطأ، بينما كتلة `except` تتعامل مع استثناء محدد وتنفذ إذا حدث ذلك الخطأ. إليك مثالًا:

  ```py
  try:
    print(22 / 0)
  except ZeroDivisionError:
    print('You can\'t divide by zero!')
    # You can't divide by zero!
  ```

  يمكنك أيضًا ربط عدة كتل `except` لتتعامل مع أنواع متعددة من الاستثناءات:

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

  يمكنك أيضًا التقاط أنواع متعددة من الاستثناءات في بند `except` واحد عن طريق تجميعها في صف مرتب:

  ```py
  try:
    number = int(input('Enter a number: '))
    result = 10 / number
  except (ValueError, ZeroDivisionError) as e:
    print(f'Error occurred: {e}')
  ```

- **`else` و `finally`**: هذه الكتل توسع `try...except`. إذا لم يحدث استثناء، تُنفذ كتلة `else`. كتلة `finally` تُنفذ دائمًا بغض النظر عن الأخطاء.

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **كائن الاستثناء**: يتيح لك الوصول إلى الاستثناء نفسه لتحسين تصحيح الأخطاء وطباعة رسالة الخطأ المباشرة. للوصول إلى كائن الاستثناء، تحتاج إلى استخدام الكلمة المفتاحية `as`. إليك مثالًا:

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **بيان `raise`**: يسمح لك برمي استثناء يدويًا. يمكنك استخدامه لرمي استثناء عند تحقق شرط معين:

  ```py
  def divide(a, b):
      if b == 0:
          raise ZeroDivisionError('You cannot divide by zero')
      return a / b
  ```

  استخدام `raise` بدون معطيات داخل كتلة `except` يعيد رمي الاستثناء الحالي الجاري التعامل معه. هذا يسمح لك بتسجيل الخطأ أو إجراء تنظيف مع استمرار رفع الاستثناء في سلسلة الاستدعاءات:

  ```py
  def process_data(data):
      try:
          result = int(data)
          return result * 2
      except ValueError:
          print('Logging: Invalid data received')
          raise
  ```

- **تعليمة `assert`**: تعليمة `assert` تتحقق من الافتراضات أثناء تصحيح الأخطاء، وترجع خطأ `AssertionError` إذا كان الشرط غير صحيح. بما أن Python تزيل تعليمات التحقق عند التشغيل في الوضع المحسن (`-O`)، لا يجب استخدام التحقق لأغراض التحقق الحرج من المُدخلات التي يجب تنفيذها دائمًا. استخدم شرطًا صريحًا مع `raise` للفحوصات الضرورية بدلًا من ذلك.

## الإشارة إلى الاستثناءات

- **الاستثناءات المخصصة**: بيان `raise` مفيد أيضًا عند إنشاء استثناءات مخصصة عن طريق توريث `Exception`. هذا يسمح برمي أخطاء بمنطق ورسائل خاصة بالمجال:

  ```py
  class InvalidCredentialsError(Exception):
      def __init__(self, message="Invalid username or password"):
          self.message = message
          super().__init__(self.message)

  def login(username, password):
      stored_username = "admin"
      stored_password = "password123"
      
      if username != stored_username or password != stored_password:
          raise InvalidCredentialsError()
      
      return f"Welcome, {username}!"
  ```

  إليك كيف تستخدم دالة `login` مع استثناء `InvalidCredentialsError`:

  ```py
  # failed login attempt
  try:
      message = login("user", "wrongpassword")
  except InvalidCredentialsError as e:
      print(f"Login failed: {e}")
  else:
      print(message)

  # successful login attempt
  try:
      message = login("admin", "password123")
  except InvalidCredentialsError as e:
      # This block is not executed because the login was successful
      print(f"Login failed: {e}")
  else:
      # The else block runs if the 'try' block completes without an exception
      print(message)
  ```

- **تسلسل الاستثناءات**: يمكن استخدام بيان `raise` مع الكلمة المفتاحية `from` لتسلسل الاستثناءات. استخدام `from None` يخفي سياق الاستثناء الأصلي من تتبع الأخطاء المعروض، بينما `from e` يسجل الاستثناء الأصلي كسبب صريح:

  ```py
  def parse_config(filename):
      try:
          with open(filename, 'r') as file:
              data = file.read()
              return int(data)
      except FileNotFoundError:
          raise ValueError('Configuration file is missing') from None
      except ValueError as e:
          raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```
