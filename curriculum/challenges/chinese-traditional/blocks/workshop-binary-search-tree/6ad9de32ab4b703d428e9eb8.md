# --description--

為你的 `if` 述語添加一個 `elif` 語句，檢查 `key` 是否大於 `node.key`。在裡面，使用 `node.right` 和 `key` 呼叫 `self._insert`，並將結果指定給 `node.right`。

如果 `key` 與 `node.key` 相等，兩個分支都不會執行，因此不會將重複的值加入樹中。
