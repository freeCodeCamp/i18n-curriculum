## 什麼是物件導向程式設計？

- **物件導向程式設計**：一種程式設計風格，開發者將程式碼中的所有東西視為真實世界的物件。它通常被稱為 OOP。幫助你有效組織和管理程式碼的四大關鍵原則是 **封裝**、**繼承**、**多型** 和 **抽象性**。
- **類別**：用來創建物件的藍圖。每個從類別創建的物件都有定義資料的屬性和決定物件行為的方法。

## 什麼是封裝？

- **封裝**：將物件的屬性和方法打包成單一單元。它讓你將物件的內部狀態隱藏在一組簡單的公開方法和屬性後面，這些公開介面就像門一樣。門後是私有的屬性和方法，控制資料如何變更以及誰能看到它。
- **封裝範例**：如果你想追蹤錢包餘額，你會允許存款和提款，但不希望任何人直接竄改錢包餘額：

```py
class Wallet:
   def __init__(self, balance):
       self.__balance = balance # Private attribute

   def deposit(self, amount):
       if amount > 0:
           self.__balance += amount # Add to the balance safely

   def withdraw(self, amount):
       if 0 < amount <= self.__balance:
           self.__balance -= amount # Remove from the balance safely

account = Wallet(500)
print(account.__balance) # AttributeError: 'Wallet' object has no attribute '__balance'
```

- **單底線與雙底線前綴屬性的差異**：以單底線作為屬性和方法的前綴表示它們是供內部使用的慣例，Python 並不限制類別外部存取它們。以雙底線作為前綴會觸發名稱改寫，將 `__balance` 重新命名為 `_Wallet__balance`。這有助於避免子類別中意外的名稱衝突，但並不代表外部無法存取：

```py
print(account._Wallet__balance) # 500
```

## 什麼是 Getter 和 Setter？

- **取值函式與設值函式**：讓你控制類別屬性如何被存取和修改的方法。你用取值函式取得值，用設值函式設定值。
- **屬性**：連結取值函式和設值函式，並允許存取資料。當你取得、設定或刪除值時，它們會在背後執行額外邏輯。
- **為什麼用屬性而非方法**：屬性用來取代方法以提升可讀性和程式碼整潔度。它們讓你像存取一般屬性一樣用點記法存取值，無需加小括號。
- **裝飾器**：裝飾器是一種函式，用來修改或包裝其他函式或類別，而不改變其原始程式碼。你透過將 `@decorator_name` 放在函式或類別定義上方來套用裝飾器。例如，在方法上方放置 `@property` 裝飾器會將該方法變成屬性，讓你像存取屬性一樣存取它，內部則呼叫被裝飾的方法。
- **建立取值函式**：要建立取值函式，使用 `@property` 裝飾器。以下是一個取得圓半徑的取值函式：

```py
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self): # A getter to get the radius
        return self._radius
  
    @property
    def area(self):  # A getter to calculate area
        return 3.14 * (self._radius ** 2)

my_circle = Circle(3)

print(my_circle.radius) # 3
print(my_circle.area) # 28.26
```

- **建立 Setter**：建立設定半徑的 setter，需要定義同名方法並在上方使用 `@<property_name>.setter`：

```py
class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def radius(self):  # A getter to get the radius
        return self._radius

    @radius.setter
    def radius(self, value):  # A setter to set the radius
        if value <= 0:
            raise ValueError('Radius must be positive')
        self._radius = value

my_circle = Circle(3)
print('Initial radius:', my_circle.radius) # Initial radius: 3

my_circle.radius = 8
print('After modifying the radius:', my_circle.radius) # After modifying the radius: 8
```

- **Python 如何處理 Getter 和 Setter**：定義 getter 和 setter 後，當你使用一般屬性語法時，Python 會自動在背後呼叫它們：

```py
my_circle.radius # This will call the getter
my_circle.radius = 4 # This will call the setter
```

在 setter 內不應該直接指定給屬性名稱本身，否則會造成 `RecursionError`。

- **刪除器（Deleter）**：在設定和取得值後，你可以用 `deleter` 控制如何刪除屬性。當你對屬性使用 `del` 陳述時，deleter 會執行自訂邏輯。建立 deleter 使用 `@<property_name>.deleter` 裝飾器。

```py
  # Deleter
    @radius.deleter
    def radius(self):
        print("Deleting radius...")
        del self._radius
```

## 什麼是繼承？它如何促進程式碼重用？

- **繼承**：子類別使用父類別的屬性和方法的過程。繼承促進程式碼重用，提供清晰的階層結構，並能自訂行為而無需重寫所有程式碼。實作繼承時，子類別會帶入父類別名稱：

```py
class Parent:
    # Parent attributes and methods

class Child(Parent):
    # Child inherits, extends, and/or overrides where necessary
```

- **單繼承與多繼承**：子類別從單一父類別繼承屬性和方法稱為 **單繼承**，從多個父類別繼承則稱為 **多繼承**。語法如下：

```py
class Parent:
    # Attributes and methods for Parent

class Child:
    # Attributes and methods for Child

class GrandChild(Parent, Child):
    # GrandChild inherits from both Parent and Child
    # GrandChild can combine or override behavior from each
```

- **`super()` 函式**：讓你在類別有不同實作或擴充方法時，呼叫父類別的方法，避免重複程式碼。

## 什麼是多型？它如何促進程式碼重用？

- **多型**：物件導向原則，允許不同類別使用相同的方法名稱，但每個類別在呼叫時有不同的實作。語法如下：

```py
class A:
   def action(self): ...

class B:
   def action(self): ...

class C:
   def action(self): ...

Class().method()  # Works for A, B, or C
```

- **基於繼承的多型**：父類別定義方法，子類別各自調整以符合需求。

## 什麼是名稱改寫？它如何運作？

- **名稱改寫**：Python 內部將以雙底線開頭的屬性重新命名，透過在前面加底線和類別名稱，將 `__attribute` 變成 `_ClassName__attribute`。
- **名稱改寫的目的**：名稱改寫的主要目的是避免在使用繼承時意外覆寫屬性和方法。以下程式碼範例能讓你更容易理解：

```py
class Parent:
    def __init__(self):
        self.__data = 'Parent data'

class Child(Parent):
    def __init__(self):
        super().__init__()
        self.__data = 'Child data'

c = Child()
print(c.__dict__) # {'_Parent__data': 'Parent data', '_Child__data': 'Child data'}
```

## 什麼是抽象性？它如何幫助維持複雜系統的組織？

- **抽象性**：一種程式設計概念，將物件或系統複雜的實作細節隱藏起來，只顯示必要的特性。在 Python 和其他程式語言中，抽象性透過提高重用性來簡化複雜系統。
- **抽象性的範例**：生活中抽象性的好例子是汽車，讓你只用方向盤、踏板和排檔桿，而不必知道引擎或煞車如何運作。
- **Python 如何實作抽象性**：你可以用普通函式和類別創建抽象體，透過簡單介面隱藏實作細節。對於更正式的介面，Python 的 `abc` 模組提供 `ABC` 輔助類別和 `@abstractmethod` 裝飾器。抽象基底類別定義具體子類別應該提供的共通方法和屬性。
- **抽象方法如何定義**：抽象方法用 `@abstractmethod` 定義。只有當類別提供或繼承所有抽象方法的具體實作時，該類別才能被具現化。若子類別未實作任何抽象方法，該子類別仍為抽象類別。抽象方法仍可有預設實作，子類別可用 `super()` 呼叫。單純繼承 `ABC` 不會阻止具現化：`ABC()` 和沒有抽象方法的子類別都能被具現化。抽象性的基本語法如下：

```py
from abc import ABC, abstractmethod

# Define an abstract base class
class AbstractClass(ABC):
    @abstractmethod
    def abstract_method(self):
        pass

# Concrete subclass that implements the abstract method
class ConcreteClassOne(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassOne')

# Another concrete subclass
class ConcreteClassTwo(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassTwo')

AbstractClass() # TypeError
ConcreteClassOne().abstract_method() # Implementation in ConcreteClassOne
```

## 物件表示法

- **`__repr__` 方法**：一個特殊方法，回傳物件的字串表示。理想情況下，該字串看起來像用來創建該物件的程式碼。例如，`Employee('Charlie', 'developer')` 應該被表示為 `Employee('Charlie', 'developer')`。
- **`repr()` 函式**：當你對物件呼叫 `repr()` 時，Python 會在背後呼叫該物件的 `__repr__` 方法。對字串而言，`repr()` 會加上引號並跳脫需要跳脫的字元：

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

- **`!r` 轉換**：在 f-string 中，表達式後加上 `!r` 會套用 `repr()`。在 `__repr__` 中使用 `!r` 能保持表示法有效，當值包含引號或反斜線時，比手動加引號更安全：

```py
class Employee:
    def __init__(self, name, level):
        self.name = name
        self.level = level

    def __repr__(self):
        return f'Employee({self.name!r}, {self.level!r})'

print(repr(Employee("O'Reilly", 'junior'))) # Employee("O'Reilly", 'junior')
```

## 文件字串與型別檢查

- **文件字串**：文件字串是放在類別或函式第一行的字串，用來做說明文件。文件字串通常用三個雙引號包住：

```py
class Movie:
    """Parent class representing a movie."""

def add(x, y):
    """A function that returns the sum of two numbers."""
    return x + y
```

- **`isinstance()` 與 `type()` 的差異**：`isinstance(obj, ClassName)` 若 `obj` 是 `ClassName` 或其任何子類別的實體，會回傳 `True`，因為它會考慮完整繼承鏈。若要檢查是否為精確的類別，則比較 `type(obj)`：

```py
class Movie:
    pass

class TVSeries(Movie):
    pass

series = TVSeries()
print(isinstance(series, Movie)) # True
print(type(series) == Movie) # False
print(type(series) == TVSeries) # True
```

## 帶有額外背景的自訂例外

- **在例外中儲存背景**：自訂例外可以接受除了訊息外的額外資料。呼叫 `super().__init__(message)` 讓內建的 `Exception` 類別儲存並顯示訊息，然後你可以將額外資料存成屬性。當你捕捉例外時，可以讀取該屬性來協助偵錯：

```py
class MediaError(Exception):
    """Custom exception for media-related errors."""

    def __init__(self, message, obj):
        super().__init__(message)
        self.obj = obj

try:
    raise MediaError('Only Movie or TVSeries instances can be added', 42)
except MediaError as e:
    print(f'Media Error: {e}') # Media Error: Only Movie or TVSeries instances can be added
    print(f'Unable to add {e.obj}: {type(e.obj)}') # Unable to add 42: <class 'int'>
```

## 型別提示

- **型別提示**：可選的註解，用來告訴其他開發者變數、參數或返回值預期的資料型別。Python 不會在執行期強制執行它們。
- **參數與返回型別提示**：你在參數名稱後加冒號來加參數型別提示，在參數列後加 `-> return_type` 來加返回型別提示。由於 `__init__` 是初始化函式，返回值必須是 `None`，所以它的返回型別提示是 `None`：

```py
class Product:
    def __init__(self, name: str, price: float) -> None:
        self.name = name
        self.price = price

    def is_affordable(self, budget: float) -> bool:
        return self.price <= budget
```

- **自訂類別與列表作為型別**：你可以使用自己的類別作為型別提示，`list[ClassName]` 指定一個包含該類別物件的列表：

```py
class DiscountStrategy:
    pass

class DiscountEngine:
    def __init__(self, strategies: list[DiscountStrategy]) -> None:
        self.strategies = strategies
```
