# --description--

最后要做的是在点击 `Apps` 按钮时更新 `isOpen` 状态。

在 React 中，你通过将一个函数传递给元素上的事件属性来响应事件。这些属性使用驼峰式大小写书写，所以点击事件用 `onClick` 处理：

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

注意 `onClick` 接收一个函数。每次按钮被点击时，React 都会调用该函数。调用设置函数并传入新值会更新状态，React 随后用该新值重新渲染组件。

要在布尔状态 `true` 和 `false` 之间切换，你可以使用逻辑非（`!`）操作符，将当前值的相反值传给设置函数。

为 `button` 元素添加一个 `onClick` 属性。给它一个箭头函数，调用 `setIsOpen` 并传入 `isOpen` 的相反值。

点击 `Apps` 按钮以打开和关闭 `sub-menu`。

这样，你的 `Navbar` 组件就完成了！

# --hints--

点击 `Apps` 按钮时，应将其 `aria-expanded` 属性设置为 `"true"`，并为 `sub-menu` 添加 `sub-menu--open` 类。

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

第二次点击 `Apps` 按钮时，应将其 `aria-expanded` 属性设置回 `"false"`，并从 `sub-menu` 中移除 `sub-menu--open` 类。

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
