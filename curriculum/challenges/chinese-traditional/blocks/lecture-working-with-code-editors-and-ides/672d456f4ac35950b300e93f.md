# --description--

你可能已經熟悉一些基本的快捷鍵，這些快捷鍵是從你的作業系統繼承而來。像是 <kbd>Ctrl</kbd> + <kbd>S</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>S</kbd>（macOS）用來存檔，<kbd>Ctrl</kbd> + <kbd>C</kbd> 或 <kbd>Cmd</kbd> + <kbd>C</kbd> 用來複製，還有 <kbd>Ctrl</kbd> + <kbd>V</kbd> 或 <kbd>Cmd</kbd> + <kbd>V</kbd> 用來貼上，這些在 VS Code 都適用。

但有一些是應用程式專屬的，仍然可以提升你的生產力。值得注意的是，這些快捷鍵在不同作業系統上可能會有所不同。

例如，<kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> 會對目前開啟的檔案執行你所組態的格式化工具（像是 JavaScript 專案中的 Prettier）。

使用 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>（macOS）可以搜尋工作區中所有檔案的文字內容。如果你想執行尋找並取代，則使用 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd>（macOS）。

如果你需要刪除一列，<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>（macOS）會幫你刪除該列。

需要更多空間來放你的程式碼嗎？<kbd>Ctrl</kbd> + <kbd>B</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>B</kbd>（macOS）會隱藏側邊欄，該側邊欄包含檔案列表和擴充套件選單。

還是你根本看不清楚程式碼？<kbd>Ctrl</kbd> + <kbd>Plus</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Plus</kbd>（macOS）會放大編輯器的縮放比例，而 <kbd>Ctrl</kbd> + <kbd>Minus</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Minus</kbd>（macOS）會縮小它。

VS Code 另一個有用的功能是多列編輯，讓你能一次修改多列。舉例來說，你可以用 <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> 和 <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd>（Windows）、<kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> 和 <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd>（Linux）、或 <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Down</kbd> 和 <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Up</kbd>（macOS）來將游標延伸到連續的列。你也可以按住 <kbd>Alt</kbd>（Windows/Linux）或 <kbd>Option</kbd>（macOS）並點擊，在你需要的不同列上新增游標。游標放好後，你輸入或刪除的任何內容都會同時套用到所有這些位置，這在處理重複程式碼時能節省很多時間。

最後，如果你忘記任何這些快捷鍵，你隨時可以按 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（Windows/Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（macOS），這會開啟命令調色盤，讓你選擇你需要的任何指令。
