# --description--

挿入ソートはリストの先頭にソート済みの部分を1つずつ要素を追加して作ります。最初の要素をソート済みとみなして始めます。次に次の要素を取り、それをソート済み部分に向かって後ろに移動させます。移動中はそれより大きい要素を右に1つずつずらすか入れ替えながら、その要素より小さいか等しい要素に出会うまで続けます。これを残りのすべての要素に対して繰り返し、リスト全体がソートされます。

挿入ソートは平均および最悪の場合で二次の時間計算量ですが、リストがすでにソートされている場合は線形時間で動作します。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

**ユーザーストーリー：**

1. `insertion_sort` という名前の関数を定義してください。この関数はリストのアイテムを表す1つのパラメータを持ちます。
1. `insertion_sort` 関数はリストを小さい順にその場でソートし、ソート済みのリストを返してください。
1. `insertion_sort` 関数は挿入ソートアルゴリズムに従い、左から右へ各要素をリストの先頭のソート済み部分の正しい位置に挿入してください。
1. `insertion_sort` 関数は要素を後ろに移動させるのを、その要素より小さいか等しい要素に到達した時点で止めてください。
1. `insertion_sort` 関数は組み込みの `sort()` メソッドや `sorted()` 関数を使わないでください。

**注意:** モジュールをインポートしたり、リストに要素を追加・削除するメソッドを使わないでください。

from collections import UserList

class CustomList(UserList):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self._states = [list(self.data)]

    def __setitem__(self, key, value):
        super().__setitem__(key, value)
        self._states.append(list(self.data))

def expected_states(items):
    return [
        sorted(items[:i]) + items[i:]
        for i in range(1, len(items) + 1)
    ]

for values in ([33, 1, 89, 2, 67, 245], [4, 4, 2, 2, 1, 4, 3], [5, 3, 8, 1, 9, 2]):

    insertion_sort(list_to_sort)
    states = iter(list_to_sort._states)
    state = next(states)
    for expected in expected_states(values):

            state = next(states)
    assert list_to_sort.data == sorted(values)
    `)
});

```py
def insertion_sort(items):
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j -= 1
        items[j + 1] = current
    return items
```
