# --description--

No terminal, você verá alguns valores como `-3.6999999999999993` em vez de `-3.7`. Isso acontece porque floats não conseguem representar exatamente todo número decimal, então pequenos erros podem aparecer após operações aritméticas.

A função `round()` arredonda um número para a quantidade de casas decimais que você passa como segundo argumento:

```py
print(round(3.14159, 2)) # 3.14
```

Envolva `temperature - average` em uma chamada `round()` para arredondar cada diferença para uma casa decimal.
