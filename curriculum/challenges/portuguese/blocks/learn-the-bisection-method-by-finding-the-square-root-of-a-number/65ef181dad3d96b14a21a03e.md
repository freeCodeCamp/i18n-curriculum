# --description--

O método da bissecção, também conhecido como método de busca binária, usa uma busca binária para buscar as raízes de uma função de valor real. Ele funciona estreitando um intervalo onde uma raiz está até convergir para um valor dentro de uma tolerância especificada.

Neste projeto, você vai usar o método da bissecção para buscar a raiz quadrada aproximada de um número.

Comece criando uma função chamada `square_root_bisection`. Deixe os parâmetros vazios por enquanto.
