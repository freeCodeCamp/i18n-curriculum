# --description--

Давайте дізнаємося, як мова системи та налаштування клавіатури можуть впливати на практичні заняття з Bash і PostgreSQL.

Багато інструментів програмування очікують, що команди використовуватимуть стандартні символи англійської клавіатури. У практичних заняттях з Bash і PostgreSQL це особливо важливо для символів, таких як крапка з комою (`;`), лапки, слеші та інші спеціальні символи.

Якщо ваша операційна система або макет клавіатури використовує налаштування неанглійською мовою, деякі символи можуть поводитися інакше, ніж очікується. Це може призвести до заплутаних помилок при введенні SQL-команд або команд у терміналі.

Для найкращого досвіду під час проходження цих практичних занять рекомендується тимчасово переключитися на англійський (США) макет клавіатури під час виконання курсу. Це особливо корисно, якщо команди в Bash або PostgreSQL видають несподівані символи або синтаксичні помилки при введенні таких символів, як `;` або `\`.

GitHub Codespaces використовує локальний макет клавіатури, тому зміна макета на вашому комп’ютері також вплине на введення в Codespaces.

У Windows:

1. Відкрийте **Параметри** > **Час і мова** > **Мова та регіон**
2. Додайте **English (United States)**, якщо він ще не встановлений
3. У розділі макетів клавіатури виберіть клавіатуру **US**
4. За потреби перемістіть макет клавіатури US на початок списку

У macOS:

1. Відкрийте **Системні налаштування** > **Клавіатура** > **Джерела введення**
2. Додайте макет клавіатури **English (US)**
3. Переконайтеся, що макет US вибрано як активний

У дистрибутивах Linux, таких як Ubuntu, Debian або Mint:

1. Відкрийте налаштування клавіатури системи
2. Додайте макет клавіатури **English (US)**
3. За можливості перемістіть його на початок списку макетів клавіатури

Деякі системи Linux також дозволяють перевіряти та змінювати макет клавіатури з терміналу. Спочатку перевірте свій поточний макет:

```bash
setxkbmap -query
```

Потім переключіться на макет US:

```bash
setxkbmap us
```

Після перемикання макетів протестуйте наступні символи у текстовому полі або терміналі:

```md
; : / \ | ' " $ { } [ ] ( )
```

Якщо символи відображаються правильно, ймовірно, ваш макет клавіатури налаштовано правильно.

Деякі неанглійські макети розглядають символи, як `'` і `"`, як мертві клавіші, тобто вони чекають наступного натискання замість негайного введення. Після перемикання на макет US ці символи мають вводитися одразу. Якщо символ досі не з’являється відразу, це ознака того, що макет не повністю переключився.

Якщо ви використовуєте фізичний макет клавіатури, відмінний від US, наприклад AZERTY, QWERTZ або регіональні варіанти QWERTY, клавіші зі символами можуть бути розташовані в інших фізичних позиціях. У такому разі використовуйте екранну клавіатуру або переглядач клавіатури вашої операційної системи, щоб знайти клавіші, такі як `;`, `/`, `\`, `|`, `'` і `"` після перемикання на макет US.

Використання англійського (US) макета клавіатури допомагає гарантувати, що команди Bash і PostgreSQL працюватимуть саме так, як очікується, протягом усього практичного заняття.

Після завершення практичних занять ви можете повернутися до свого початкового макета клавіатури.
