# --description--

El atributo `type` le indica al navegador qué tipo de datos debe aceptar un `input`. Algunos valores comunes para el atributo `type` son:

- `text`: un campo de texto de una sola línea
- `email`: un campo de texto que verifica que el usuario ingrese una dirección de correo electrónico válida
- `number`: un campo para números
- `radio` y `checkbox`: opciones que el usuario puede seleccionar

Aquí tienes un ejemplo de un input de texto:

```html
<input type="text">
```

Para el elemento `input` existente, agrega un atributo `type` con el valor `"text"`.

También dale al elemento `input` un atributo `id` con el valor `"full-name"`. Esto coincide con el atributo `for` en tu elemento `label`, que conecta ambos.

Cuando un usuario proporciona su nombre completo, el `input` aceptará texto sin formato.
