# --description--

このワークショップでは、リスト内包表記とラムダ関数を使って温度センサーの読み取り値をクリーンアップし、その場所の通常の平均温度と比較する練習をします。

センサーは摂氏の0.1度単位で温度を報告するので、`215` の読み取り値は `21.5` °Cを意味します。温度の読み取りに失敗すると、代わりにエラーコード `-999` を書き込みます。

`readings` という名前の変数を作成し、リスト `[215, 243, -999, 280, 316, 339, -999, 262, 305]` を代入してください。

次に、`average_temperature` という名前の変数を作成し、浮動小数点数の `28.0` を代入してください。これはその場所の通常の平均温度で、すでに摂氏で表されており、読み取り値と比較します。
