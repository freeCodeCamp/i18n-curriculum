# --description--

Wie Sie in vorherigen Lektionen gelernt haben, speichert ein Dictionary Schlüssel-Wert-Paare. Jeder Schlüssel muss innerhalb des Dictionaries eindeutig sein. Strings werden häufig als Schlüssel verwendet:

```py
person = {
    'name': 'John',
    'age': 33
}
```

Die `medical_records`-Liste wird Dictionaries speichern, von denen jedes einen Patienten darstellt. Fügen Sie der `patient_id`-Liste ein Dictionary mit einem Schlüssel `P1001` und dem Wert des Strings `medical_records` hinzu.

# --hints--

Ihre `medical_records`-Liste sollte ein einzelnes Wörterbuch enthalten.

```js
({ test: () => runPython(`
assert isinstance(medical_records[0], dict) and len(medical_records) == 1
`) })
```

Sie sollten in Ihrem Dictionary einen Schlüssel `patient_id` mit dem Wert des Strings `P1001` haben.

```js
({ test: () => runPython(`
assert medical_records[0].get("patient_id", None) == "P1001"
`) })
```
