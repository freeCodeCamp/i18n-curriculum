## 什么是 Express.js？

- **Express**：基于 Node.js 的极简且灵活的网络框架，使构建网络服务器和 API 更简单。
- **安装 Express**：`npm install express`
- **用 Express 可以构建**：网络应用、RESTful API、单页应用后端、重中间件服务以及任何基于 HTTP 的服务器端功能。
- **中间件**：在接收请求和发送响应之间运行的代码。用于错误处理、输入验证、修改请求或响应数据等。可以串联多个中间件函数。
- **插件**：扩展 Express 的外部 npm 模块，通常以中间件形式实现。

## 创建基础 Express 应用

```javascript
const express = require("express");
const app = express();
const port = 3000;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

- `require("express")` — 装载 Express 库。
- `express()` — 工厂函数，创建并返回新的 Express 应用实例。
- `app` — 主要服务器对象，拥有 `.get()`、`.post()` 和 `.listen()` 等方法。
- `port` — 应用监听的网络端点。端口 `3000` 是本地开发常用端口。
- `app.listen(port, callback)` — 启动服务器，开始监听传入的 HTTP 请求。

## Express 中的路由

- **路由**：告诉应用当客户端用特定 HTTP 方法请求特定 URL 时如何响应的规则。
- **路由方法**：`app.get()`、`app.post()`、`app.put()`、`app.delete()` — 分别处理对应 HTTP 方法的请求。
- **静态路由路径**：固定 URL，如 `/home` 或 `/menu/drinks`。
- **动态路由路径（路由参数）**：URL 中的占位符，用 `:` 前缀标识，例如 `/post/:postId`。
- **`req.params`**：包含从 URL 捕获的动态值的对象。例如，请求 `/post/42` 会得到 `req.params.postId === "42"`。

### 路由处理程序

- **路由处理程序** 是当请求匹配路由时运行的回调函数 `(req, res) => { ... }`。
- `req` — 包含关于传入请求的信息（参数、查询字符串、头部、体）。
- `res` — 用于向客户端发送响应。

## 响应方法

| 方法 | 功能 |
| --- | --- |
| `res.send()` | 发送响应——纯文本、HTML、JSON 或二进制数据。 |
| `res.json()` | 发送 JSON 响应；自动将 JavaScript 对象转换。 |
| `res.status(code)` | 设置 HTTP 状态码；通常与 `res.send()` 或 `res.json()` 链式调用。 |
| `res.redirect(url)` | 重定向客户端到不同 URL。 |
| `res.render(view, data)` | 渲染模板引擎视图并发送生成的 HTML。 |

## 使用 `app.route()` 链式路由处理程序

- `app.route(path)` 将同一路径的多个 HTTP 方法处理程序分组，避免重复路径。

```javascript
app
  .route("/user")
  .get((req, res) => { res.send("Fetching user data"); })
  .post((req, res) => { res.send("Creating a user"); })
  .put((req, res) => { res.send("Updating the user"); })
  .delete((req, res) => { res.send("Deleting the user"); });
```

## 使用 `express.Router()` 进行模块化路由

- `express.Router()` 创建路由器对象——类似迷你 Express 应用——你可以在上面定义路由，然后挂载到主应用。
- 使用 `app.use(path, router)` 挂载路由器。路由器内的路由相对于挂载路径。
- **优点**：分离关注点，保持主文件整洁，使路由可复用且更易扩展。

```javascript
// userRoutes.js
const express = require("express");
const router = express.Router();
router.get("/", (req, res) => { res.send("List of users"); });
router.get("/:id", (req, res) => { res.send(`User ${req.params.id}`); });
module.exports = router;

// app.js
app.use("/users", userRoutes); // mounts the router at /users
```

## 提供静态文件服务

- **静态文件**：图像、CSS 和客户端 JavaScript 等资产，直接提供，无需服务器端处理。
- `express.static(directory)` — 内置中间件，从指定文件夹提供文件。
- 如果请求的文件不存在，Express 会自动返回 404。
- 不需要为单个静态文件定义路由。

```javascript
app.use(express.static(path.join(__dirname, "public")));
```

- 你可以通过多次调用 `app.use()` 来从多个目录提供服务，可选带挂载路径：

```javascript
app.use(express.static(path.join(__dirname, "public")));
app.use("/images", express.static(path.join(__dirname, "images")));
```
