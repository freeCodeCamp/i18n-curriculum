# --description--

Es ist Zeit, die Informationen zum Absender und Empfänger anzuzeigen. Damit die Namen ordentlich untereinander ausgerichtet sind, geben Sie dem Text vor jedem Namen mit einem Formatbezeichner eine feste Breite.

Fügen Sie der `display_full_email`-Methode zwei ausgabe-Anweisungen hinzu:

- `'From:'` linksbündig mit einer Breite von `10`, gefolgt vom Namen des Absenders.
- `'To:'` linksbündig mit einer Breite von `10`, gefolgt vom Namen des Empfängers.

Zum Beispiel würden die beiden Zeilen mit `Alice` als Absender und `Bob` als Empfänger so aussehen:

```md
From:     Alice
To:       Bob
```
