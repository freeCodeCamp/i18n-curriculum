# --description--

Python에서 `bool`은 `int`의 하위클래스이며, `True`는 `1`처럼, `False`는 `0`처럼 동작합니다. 이는 `isinstance()`가 불리언 값을 정수로 취급한다는 뜻입니다:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True
```

이 때문에 현재 함수는 `True`와 `False`를 shift 값으로 받아들입니다.

`or` 연산자를 사용해 `if` 문에 두 번째 조건으로 `isinstance(shift, bool)`을 추가해 `shift`가 불리언인지 확인하세요. 이렇게 하면 `shift`가 `True`나 `False`일 때도 함수가 `Shift must be an integer value.`를 반환합니다.
