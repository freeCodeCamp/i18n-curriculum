# --description--

このワークショップでは、スマートキャンパスディレクトリを扱い、ネストされたデータからルックアップテーブルを作成します。
これらのルックアップテーブルを使って、高速かつ効率的な検索を行います。`rawData`はすでに用意されています。

その構造を少し見てみましょう：各キーは学部名で、その値には`Dept_code`と`programs`配列が含まれています。
各プログラムはさらに独自の`instructors`配列を持っています。

まずは、`rawData` をコンソールにログ出力して、このネストされた構造を確認してください。

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, "log");
const getLogs = () => globalThis.spy.calls.map(call => call?.[0]);
```

# --after-each--

```js
globalThis.spy.restore();
delete globalThis.spy;
```

# --hints--

`rawData` をコンソールにログ出力してください。

```js
assert.include(getLogs(), rawData);
```
