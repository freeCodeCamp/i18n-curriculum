# --description--

现在你需要链接 `styles.css` 文件，这样样式才能再次生效。

`link` 元素允许你链接到外部资源，比如样式表和网站图标。以下是使用 `link` 元素链接外部 CSS 的基本语法：

```html
<link rel="stylesheet" href="styles.css" />
```

`rel` 属性指定链接资源与 HTML 文档之间的关系。在这里，你需要指定该链接资源是一个 `stylesheet`。`href` 属性指定外部资源的位置。

在 `head` 元素内，添加一个 `link` 元素。给它一个 `rel` 属性，值为 `"stylesheet"`，以及一个 `href` 属性，值为 `"styles.css"`。

**注意：** `link` 元素是一个空元素，这意味着它没有闭合标签。空元素应该写成 `<element>`，而不是 `<element></element>`。
