# --description--

在终端中，你应该会看到类似 `<filter object at 0x...>` 的内容，而不是读取值。这是因为 `filter()` 返回一个迭代器，它一次给你一项，而不是将所有项存储在一个列表中。

要将迭代器的项收集到列表中，你可以将它传递给 `list()` 函数：

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

将赋值给 `valid_readings` 的 `filter()` 调用包裹在一个 `list()` 调用中。在终端中，你应该能看到没有 `-999` 误差代码的读取值。
