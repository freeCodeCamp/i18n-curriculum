# --description--

Сортування вставками формує відсортовану частину на початку списку, по одному елементу за раз. Воно починається з того, що перший елемент вважається відсортованим. Потім береться наступний елемент і переміщується назад у відсортовану частину, зсуваючи або міняючи місцями кожен більший елемент на одну позицію вправо, доки не досягне елемента, який менший або рівний йому. Це повторюється для кожного наступного елемента, доки весь список не буде відсортований.

Сортування вставками має квадратичну часову складність у середньому та гіршому випадках, але працює за лінійний час, коли список уже відсортований.

**Мета:** Виконайте наведені нижче історії користувача та пройдіть усі тести, щоб завершити лабораторну роботу.

**Історія користувача:**

1. Ви повинні визначити функцію з назвою `insertion_sort` з одним параметром, який представляє список елементів.
1. Ваша функція `insertion_sort` повинна сортувати список на місці від найменшого до найбільшого і повертати його.
1. Ваша функція `insertion_sort` повинна слідувати алгоритму сортування вставками, вставляючи кожен елемент зліва направо у його правильне місце у відсортованій частині на початку списку.
1. Ваша функція `insertion_sort` повинна припиняти переміщення елемента назад, щойно він досягне елемента, який менший або рівний йому.
1. Ваша функція `insertion_sort` не повинна використовувати вбудований метод `sort()` або функцію `sorted()`.

**Примітка:** Ви не повинні імпортувати жодних модулів або використовувати методи, які додають або видаляють елементи зі списку.

```py
def insertion_sort(items):
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j -= 1
        items[j + 1] = current
    return items
```
