# --description--

以下游戏是组合博弈论的经典示例：

两个玩家从一条由 $n$ 个白色方块组成的纸带开始，轮流进行操作。每轮，一个玩家选择两个相邻的白色方块并将它们涂成黑色。第一个无法进行操作的玩家输掉比赛。

- $n = 1$：没有有效移动，因此第一个玩家自动失败。
- $n = 2$：只有一个有效移动，之后第二个玩家输。
- $n = 3$：两个有效的移动，但两者都会导致第二个玩家输掉局面。
- $n = 4$：第一个玩家有三个有效的移动；他能够通过涂色中间的两个平方来赢得游戏。
- $n = 5$：第一个玩家有四个有效移动（如下图红色所示）；但无论玩家做什么，第二个玩家（蓝色）都会获胜。

<img alt="valid starting moves for strip with 5 squares" src="https://cdn.freecodecamp.org/curriculum/project-euler/paper-strip-game.gif" style="background-color: white; padding: 10px; display: block; margin-right: auto; margin-left: auto; margin-bottom: 1.2rem;">

所以，对于 $1 ≤ n ≤ 5$，有 3 个 $n$ 的值使得第一位玩家可以迫使获胜。

同样地，对于 $1 ≤ n ≤ 50$，有 40 个 $n$ 值使得第一位玩家可以迫使获胜。

对于 $1 ≤ n ≤ 1\,000\,000$，有多少个 $n$ 的值使得第一位玩家可以迫使获胜？
