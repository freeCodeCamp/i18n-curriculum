## Робота з HTML, CSS та JavaScript

HTML і CSS забезпечують структуру вебсайту, а JavaScript додає інтерактивності, що дозроляє складну функціональність (наприклад, обробку вхідних даних користувача, анімацію елементів і навіть створення повноцінних вебзастосунків).

## Типи даних у JavaScript

Типи даних допомагають програмі розуміти, з якими даними вона працює: будь то число, текст або щось інше.

- **Число**: число може представляти як цілі числа, так і числа з плаваючою комою. Прикладами цілих чисел є 7, 19 і 90.
- **Число з плаваючою комою**: число з плаваючою комою — це число з десятковою крапкою. Прикладами є 3.14, 0.5 та 0.0001.
- **Рядок**: рядок — це послідовність символів або текст в лапках. Наприклад, `"I like coding"` та `'JavaScript is fun'`.
- **Булеве значення**: булеве значення представляє одне з двох можливих: `true` або `false`. Ви можете використовувати його, щоб представити умову; наприклад `isLoggedIn = true`.
- **Значення undefined та null**: `undefined` — це змінна, яку оголосили, але не призначили значення. `null` — це порожнє значення або змінна, якій навмисно призначили значення `null`.
- **Об’єкт**: об’єкт — це колекція пар ключ-значення. Ключ — це назва властивості, а значення — це значення властивості.

Наприклад, `{ name: "Fluffy", age: 3, type: "dog" }` має три властивості: `name`, `age` та `type`.

- **Symbol**: тип даних Symbol — це унікальне та незмінне значення, яке можна використовувати як ідентифікатор для властивостей об’єкта.

Два символи, створені з однаковим описом, все одно є різними значеннями.

- **BigInt**: якщо число занадто велике для типу даних `Number`, ви можете використати тип BigInt для представлення цілих чисел довільної довжини.

Щоб створити BigInt, додайте `n` у кінець числа.

## Змінні в JavaScript

- Змінні можна оголосити за допомогою ключового слова `let`.

- Щоб призначити значення змінній, використайте оператор присвоєння `=`.

- Змінним, оголошеним за допомогою `let`, можна призначати нове значення.

- Окрім `let`, для оголошення змінної можна також використовувати `const`. Однак змінній `const` не можна призначати нове значення.

- Змінні, оголошені за допомогою `const`, використовують для оголошення констант, які не можна змінювати протягом усього коду (наприклад, `PI` або `MAX_SIZE`).

## Конвенції іменування змінних

- Назви змінних мають бути описовими та змістовними.
- Назви змінних мають бути у верблюдячому регістрі (наприклад, `cityName`, `isLoggedIn` і `veryBigNumber`).
- Назви змінних не можуть починатися з числа. Вони мають починатися з літери, `_` або `$`.
- Назви змінних не можуть містити пробілів або спеціальних символів, окрім `_` і `$`.
- Назви змінних не можуть бути зарезервованими ключовими словами.
- Назви змінних чутливі до регістру. `age` і `Age` — це різні змінні.

## Рядки та незмінність рядків у JavaScript

- Рядки — це послідовності символів, взяті в лапки. Їх можна створювати за допомогою одинарних або подвійних лапок.

- Рядки в JavaScript є незмінними. Це означає, що після створення рядка ви не можете змінити символи в ньому. Але ви можете призначити рядку нове значення.

## Конкатенація рядків у JavaScript

- Конкатенація — це процес об’єднання кількох рядків або поєднання рядків із змінними, які містять текст. Оператор `+` — один із найпростіших і найчастіших методів для конкатенації рядків.

- Якщо до існуючого рядка потрібно щось додати або приєднати, можна використати оператор `+=`. Це корисно, коли ви хочете поступово розширювати рядок, додаючи до нього більше тексту.

- Ще один спосіб конкатенації рядків — використати метод `concat()`. Цей метод об’єднує два або більше рядків разом.

## Виведення повідомлень за допомогою `console.log()`

- Метод `console.log()` використовують для виведення повідомлень на консолі. Це корисний інструмент для налагодження та тестування коду.

## Крапки з комою в JavaScript

- Крапки з комою в основному використовують для позначення кінця інструкції. Це допомагає JavaScript-рушію розуміти розділення окремих інструкцій, що важливо для правильного виконання.

- Крапки з комою допомагають уникнути неоднозначностей у виконанні коду та гарантують правильне завершення інструкцій.

## Коментарі в JavaScript

- Будь-який закоментований рядок коду ігнорується JavaScript-рушієм. Коментарі використовують, щоб пояснити код, написати нотатки або тимчасово вимкнути код.
- Однолінійні коментарі створюють за допомогою `//`.

- Багатолінійні коментарі створюють, починаючи з `/*` і закінчуючи `*/`.

## JavaScript як мова з динамічною типізацією

- JavaScript — це мова з динамічною типізацією, тобто вам не потрібно вказувати тип даних змінної під час її оголошення. JavaScript автоматично визначає тип даних на основі значення, призначеного змінній.

- У статично типізованих мовах, таких як C#, призначення рядка змінній цілого числа призводить до помилки.

## Використання оператора `typeof`

- Оператор `typeof` використовується для перевірки типу даних змінної. Він повертає рядок, що вказує тип змінної.

- Однак у JavaScript є відома особливість щодо `null`. Оператор `typeof` повертає `"object"` для значень `null`.

## Основи рядків

- **Визначення**: рядок — це послідовність символів в одинарних, подвійних або зворотних лапках. Рядки є примітивними типами даних і вони незмінні. Незмінність означає, що після створення рядка його не можна змінити.
- **Доступ до символів рядка**: щоб отримати доступ до символу рядка, можна використати дужкову нотацію та передати індекс числа. Індекс — це позиція символу в рядку, і він починається з нуля.

- **`\n` (символ нового рядка)**: ви можете створити новий рядок у рядку, використовуючи символ нового рядка `\n`.

- **Екранування рядків**: Ви можете екранувати символи в рядку, розміщуючи зворотні скісні риски (`\`) перед лапками.

:::interactive_editor

```js
const statement = "She said, \"Hello!\"";
console.log(statement); // She said, "Hello!"
```

:::

## Шаблонні літерали (шаблонні рядки) та інтерполяція рядків

- **Визначення**: шаблонні літерали визначаються за допомогою зворотних лапок (`). Вони дозволяють легше працювати з рядками, зокрема вставляти змінні безпосередньо всередину рядка — ця функція відома як інтерполяція рядків.

:::interactive_editor

```js
const name = "Jessica";
const greeting = `Hello, ${name}!`; 
console.log(greeting); // "Hello, Jessica!"
```

:::

## ASCII, метод `charCodeAt()` та метод `fromCharCode()`

- **ASCII**: ASCII (Американський стандартний код для обміну інформацією) — це стандарт кодування символів, який використовується для представлення базових англійських символів за допомогою числових значень. Раніші уроки знайомлять з `charCodeAt()` і `fromCharCode()` на прикладах ASCII.
- **Unicode**: Рядки JavaScript внутрішньо використовують Unicode, зокрема кодування UTF-16. Для перших 128 символів (базові латинські літери, цифри та загальні символи) значення Unicode співпадають з кодами ASCII. Саме тому приклади на основі ASCII продовжують працювати в JavaScript.
- **Метод `charCodeAt()`**: Цей метод повертає одиницю коду UTF-16 символу за вказаним індексом. Для базових латинських символів це значення співпадає з кодом ASCII.

- **Метод `fromCharCode()`**: цей метод перетворює ASCII-код у відповідний символ.

## Інші поширені методи рядків

- **Метод `indexOf`**: цей метод використовується для пошуку підрядка в рядку. Якщо підрядок знайдено, то `indexOf` повертає індекс (або позицію) першого входження цього підрядка. Якщо підрядок не знайдено, то `indexOf` повертає -1, що означає неуспішний пошук.

- **Метод `includes()`**: цей метод використовується для перевірки, чи містить рядок певний підрядок. Якщо підрядок знайдено в рядку, то метод повертає true. Інакше він повертає false.

- **Метод `slice()`**: Цей метод витягує частину рядка і повертає новий рядок, не змінюючи оригінал. Він приймає два параметри: початковий індекс і необов’язковий кінцевий індекс.

- **Метод `toUpperCase()`**: цей метод перетворює всі символи на великі літери і повертає новий рядок з усіма символами у верхньому регістрі.

- **Метод `toLowerCase()`**: цей метод перетворює всі символи рядка на нижній регістр.

- **Метод `replace()`**: цей метод дозволяє знайти в рядку певне значення (наприклад, слово або символ) і замінити його іншим значенням. Метод повертає новий рядок із заміною і залишає оригінал незмінним, оскільки рядки в JavaScript є незмінними.

- **Метод `replaceAll()`**: Цей метод дозволяє знайти всі входження певного значення (слова, символу або шаблону) в рядку і замінити їх іншим значенням. Він працює як `replace()`, але замість того, щоб зупинитися після першого збігу, оновлює кожен знайдений збіг у рядку.

- **Метод `repeat()`**: цей метод використовується для повторення рядка задану кількість разів.

- **Метод `trim()`**: цей метод використовується для видалення пробілів з початку і кінця рядка.

- **Метод `trimStart()`**: цей метод видаляє пробіли з початку (або «старту») рядка.

- **Метод `trimEnd()`**: цей метод видаляє пробіли з кінця рядка.

- **Метод `prompt()`**: цей `window`-метод використовується для отримання інформації від користувача через форму діалогового вікна. Цей метод приймає два аргументи. Перший аргумент — це повідомлення, яке з’явиться всередині діалогового вікна, зазвичай з проханням ввести інформацію. Другий — це значення за замовчуванням, яке є необов’язковим і спочатку заповнює поле введення.

## Робота з типом даних Number

- **Визначення**: `Number` у JavaScript включає цілі числа, числа з плаваючою комою, `Infinity` та `NaN`. Числа з плаваючою комою — це числа з десятковою крапкою. Додатне `Infinity` — це число, більше за будь-яке інше число, а `-Infinity` — число, менше за будь-яке інше число. `NaN` (`Not a Number`) представляє недійсне числове значення, (наприклад, рядок `"Jessica"`).

## Поширені арифметичні дії

- **Оператор додавання**: Цей оператор (`+`) використовується для обчислення суми двох або більше чисел.
- **Оператор віднімання**: Цей оператор (`-`) використовується для обчислення різниці між двома числами.
- **Оператор множення**: Цей оператор (`*`) використовується для обчислення добутку двох або більше чисел.
- **Оператор ділення**: Цей оператор (`/`) використовується для обчислення частки від ділення двох чисел.
- **Ділення на нуль**: Якщо ви спробуєте поділити на нуль, JavaScript поверне `Infinity`.
- **Оператор остачі**: Цей оператор (`%`) повертає остачу від ділення.
- **Оператор піднесення до степеня**: Цей оператор (`**`) підносить одне число до степеня іншого.

## Обчислення з числами та рядками

- **Пояснення**: Коли ви використовуєте оператор `+` з числом і рядком, JavaScript перетворює число на рядок і конкатенує обидва значення. Коли ви використовуєте оператори `-`, `*` або `/` з рядком і числом, JavaScript перетворює рядок на число, і результатом буде число. Для `null` і `undefined` JavaScript трактує `null` як 0, а `undefined` як `NaN` у математичних операціях.

## Пріоритет операторів

- **Визначення**: Пріоритет операторів визначає порядок, у якому операції оцінюються у виразі. Оператори з вищим пріоритетом оцінюються раніше за оператори з нижчим пріоритетом. Значення в дужках оцінюються першими, а множення/ділення мають вищий пріоритет, ніж додавання/віднімання. Якщо оператори мають однаковий пріоритет, тоді JavaScript використовує асоціативність.

- **Визначення**: Асоціативність вказує напрямок, у якому оцінюється вираз, коли існує кілька операторів одного типу. Вона визначає, чи слід оцінювати вираз зліва направо (`left-associative`), чи справа наліво (`right-associative`). Наприклад, оператор піднесення до степеня також є асоціативним справа наліво.

## Оператори інкременту та декременту

- **Оператор інкременту**: цей оператор використовується для збільшення значення на одиницю. Префіксний запис `++num` спочатку збільшує значення змінної, а потім повертає нове значення. Постфіксний запис `num++` спочатку повертає поточне значення змінної, а потім збільшує його.

- **Оператор декременту**: цей оператор використовується для зменшення значення на одиницю. Префіксний та постфіксний записи працюють так само, як і раніше з оператором інкременту.

## Оператори складеного присвоєння

- **Оператор додавання з присвоєнням (`+=`)**: цей оператор виконує додавання значень і призначає результат змінній.
- **Оператор віднімання з присвоєнням (`-=`)**: цей оператор виконує віднімання значень і призначає результат змінній.
- **Оператор множення з присвоєнням (`*=`)**: цей оператор виконує множення значень і призначає результат змінній.
- **Оператор ділення з присвоєнням (`/=`)**: цей оператор виконує ділення значень і призначає результат змінній.
- **Оператор присвоєння остачі (`%=`)**: цей оператор ділить змінну на вказане число і призначає остачу змінній.
- **Оператор піднесення до степеня з присвоєнням (`**=`)**: цей оператор підносить змінну до степеня вказаного числа і повторно призначає результат змінній.

## Булеві значення та рівність

- **Визначення булевого типу**: булевим називають тип даних, який може мати лише два значення: `true` або `false`.
- **Оператор рівності (`==`)**: цей оператор виконує перетворення типів перш ніж перевірити, чи значення рівні.

- **Оператор суворої рівності (`===`)**: цей оператор не виконує перетворення типів і перевіряє рівність як типів, так і значень.

- **Оператор нерівності (`!=`)**: Цей оператор використовує перетворення типів перед перевіркою, чи не рівні значення.
- **Оператор суворої нерівності (`!==`)**: Цей оператор не виконує перетворення типів і перевіряє, чи не рівні як типи, так і значення.

## Оператори порівняння

- **Оператор «більше ніж» (`>`)**: цей оператор перевіряє, чи значення зліва більше за значення справа.
- **Оператор «більше або дорівнює» (`>=`)**: цей оператор перевіряє, чи значення зліва більше або рівне значенню справа.
- **Оператор «менше ніж» (`<`)**: цей оператор перевіряє, чи значення зліва менше за значення справа.
- **Оператор «менше або дорівнює» (`<=`)**: цей оператор перевіряє, чи значення зліва менше або рівне значенню справа.

## Унарні оператори

- **Унарний оператор плюс**: цей оператор перетворює свій операнд у число. Якщо операнд уже є числом, то він залишається без змін.

- **Унарний оператор заперечення (`-`)**: цей оператор змінює знак операнда на протилежний.

- **Логічний оператор NOT (`!`)**: цей оператор інвертує булеве значення свого операнда. Тобто, якщо операнд дорівнює `true`, він стає `false`, а якщо `false`, то стає `true`.

## Побітові оператори

- **Побітовий оператор AND (`&`)**: цей оператор повертає 1 у кожній позиції біта, для якої відповідні біти обох операндів дорівнюють 1.  
- **Побітовий оператор присвоєння AND (`&=`)**: цей оператор виконує операцію `bitwise AND` з вказаним числом і повторно призначає результат змінній.  
- **Побітовий оператор OR (`|`)**: цей оператор повертає 1 у кожній позиції біта, для якої відповідні біти одного або обох операндів дорівнюють 1.  
- **Побітовий оператор присвоєння OR (`|=`)**: цей оператор виконує операцію `bitwise OR` з вказаним числом і повторно призначає результат змінній.  
- **Побітовий оператор XOR (`^`)**: цей оператор повертає 1 у кожній позиції біта, для якої відповідні біти одного, але не обох, операндів дорівнюють 1.  
- **Побітовий оператор NOT (`~`)**: цей оператор інвертує бінарне представлення числа.  
- **Побітовий оператор зсуву вліво (`<<`)**: цей оператор зсуває всі біти вліво на вказану кількість позицій.  
- **Побітовий оператор зсуву вправо (`>>`)**: цей оператор зсуває всі біти вправо.

## Умовні інструкції, правдиві значення, хибні значення та тернарний оператор

- **`if/else if/else`**: інструкція `if` приймає умову і запускає блок коду, якщо ця умова `truthy`. Якщо умова `false`, тоді виконується блок `else if`. Якщо жодна з цих умов не `true`, тоді виконується умова `else`. `Truthy` значення — це будь-які значення, які при оцінці в булевому контексті, наприклад в інструкції `if`, дають результат `true`. `Falsy` значення — це значення, які при оцінці в булевому контексті дають результат `false`.

:::interactive_editor

```js
const score = 87;

if (score >= 90) {
 console.log('You got an A'); 
} else if (score >= 80) {
 console.log('You got a B'); // You got a B
} else if (score >= 70) {
 console.log('You got a C');
} else {
 console.log('You failed! You need to study more!');
}
```

:::

- **Тернарний оператор**: цей оператор часто використовується як коротший спосіб запису інструкцій `if else`.

:::interactive_editor

```js
const temperature = 30;
const weather = temperature > 25 ? 'sunny' : 'cool';

console.log(`It's a ${weather} day!`); // It's a sunny day!
```

:::

## Бінарні логічні оператори

- **Логічний AND (`&&`)**: Цей оператор перевіряє, чи обидва операнди є `true`. Якщо обидва `true`, він повертає друге значення. Якщо будь-який операнд `falsy`, він повертає `falsy`. Якщо обидва операнди `falsy`, він повертає перше `falsy` значення.

- **Логічний OR (`||`)**: Цей оператор перевіряє, чи принаймні один з операндів є правдивим.
- **Оператор об’єднання з null (`??`)**: Цей оператор повертає значення, лише якщо перше є `null` або `undefined`.

## Об’єкт `Math`

- **Метод `Math.random()`**: цей метод генерує випадкове число з плаваючою комою між 0 (включно) та 1 (виключно). Це означає, що можливе вихідне значення може бути 0, але ніколи не досягне 1.
- **Метод `Math.max()`**: цей метод приймає множину чисел і повертає максимальне значення.
- **Метод `Math.min()`**: цей метод приймає множину чисел і повертає мінімальне значення.
- **Метод `Math.ceil()`**: цей метод округлює значення вгору до найближчого цілого числа.
- **Метод `Math.floor()`**: цей метод округлює значення вниз до найближчого цілого числа.
- **Метод `Math.round()`**: цей метод округлює значення до найближчого цілого числа.

- **Метод `Math.trunc()`**: цей метод видаляє десяткову частину числа, повертаючи лише цілу частину без округлення.
- **Метод `Math.sqrt()`**: цей метод повертає квадратний корінь числа.
- **Метод `Math.cbrt()`**: цей метод повертає кубічний корінь числа.
- **Метод `Math.abs()`**: цей метод повертає абсолютне значення числа.
- **Метод `Math.pow()`**: цей метод приймає два числа і підносить перше до степеня другого.

## Поширені методи для чисел

- **`isNaN()`**: `NaN` означає Not-a-Number (укр. «не число»). Це спеціальне значення, яке представляє неможливий або невизначений числовий результат. Властивість функції `isNaN()` використовується, щоб визначити, чи є значення `NaN` чи ні. `Number.isNaN()` надає більш надійний спосіб перевірки на `NaN`, особливо у випадках, коли перетворення типів може призвести до несподіваних результатів із глобальною функцією `isNaN()`.

- **Метод `parseFloat()`**: цей метод аналізує рядковий аргумент і повертає число з плаваючою комою. Він призначений для вилучення числа з початку рядка, навіть якщо пізніше в рядку є нечислові символи.
- **Метод `parseInt()`**: цей метод аналізує рядковий аргумент і повертає ціле число. `parseInt()` припиняє аналіз при першому нецифровому символі. Для чисел з плаваючою комою він повертає лише цілу частину. Якщо на початку рядка не вдається знайти дійсне ціле число, він повертає `NaN`.
- **Метод `toFixed()`**: цей метод викликається для числа і приймає один необов’язковий аргумент — кількість цифр після десяткової крапки. Він повертає рядкове представлення числа з вказаною кількістю десяткових знаків.

## Порівняння та типи даних `null` і `undefined`

- **Порівняння та `undefined`**: змінна є невизначеною (`undefined`), коли її оголосили, але не призначили значення. Це значення за замовчуванням для неініціалізованих змінних і параметрів функції, яким не передали аргумент. `undefined` перетворюється на `NaN` у числових контекстах, що призводить до того, що всі числові порівняння з `undefined` повертають `false`.

- **Порівняння та `null`**: Тип `null` представляє навмисну відсутність значення. `null` перетворюється на `0` у числових контекстах, що може призвести до несподіваної поведінки при числових порівняннях. Наприклад, `null >= 0` є `true`, але `null > 0` є `false`.

- При використанні оператора рівності (`==`), `null` і `undefined` рівні лише один одному та самим собі.

- Однак при використанні оператора строгої рівності (`===`), який перевіряє і значення, і тип без перетворення типів, `null` і `undefined` не є рівними.

## Інструкції `switch`

- **Визначення**: Інструкція `switch` оцінює вираз і порівнює його значення з низкою умов `case`. Коли знаходиться відповідність, виконується блок коду, пов’язаний із цим випадком. Інструкція `break` має бути розміщена в кінці кожного випадку, щоб завершити його виконання і перейти до наступного. `default` — це необов’язковий випадок, який виконується лише якщо жоден із інших випадків не співпадає. `default` розміщується в кінці інструкції `switch`.

:::interactive_editor

```js
const dayOfWeek = 3; 

switch (dayOfWeek) {
  case 1:
    console.log("It's Monday! Time to start the week strong.");
    break;
  case 2:
    console.log("It's Tuesday! Keep the momentum going.");
    break;
  case 3:
    console.log("It's Wednesday! We're halfway there.");
    break;
  case 4:
    console.log("It's Thursday! Almost the weekend.");
    break;
  case 5:
    console.log("It's Friday! The weekend is near.");
    break;
  case 6:
    console.log("It's Saturday! Enjoy your weekend.");
    break;
  case 7:
    console.log("It's Sunday! Rest and recharge.");
    break;
  default:
    console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

:::

## Функції JavaScript

- Функції — це багаторазові блоки коду, які виконують певне завдання.
- Функції можна оголосити за допомогою ключового слова `function`, за яким іде ім’я, список параметрів і блок коду, що виконує завдання.

:::interactive_editor

```js
function addNumbers(x, y, z) {
  return x + y + z;
}

console.log(addNumbers(5, 3, 8)); // Output: 16
```

:::

- Аргументи — це значення, які передаються функції під час її виклику.
- Виклик функції — це процес виконання функції в програмі шляхом вказання її імені з круглими дужками, у яких за потреби можуть бути аргументи.
- Коли функція завершує виконання, вона завжди повертає значення.
- За замовчуванням повернене значення функції — це `undefined`.
- Ключове слово `return` використовується, щоб вказати значення, яке має повернути функція, і завершує її виконання.
- Параметри за замовчуванням дозволяють функціям мати попередньо визначені значення, які використовуються, якщо аргумент не передано під час виклику функції. Це робить функції гнучкішими і запобігає помилкам у випадках, коли деякі аргументи можуть бути пропущені.

:::interactive_editor

```js
const calculateTotal = (amount, taxRate = 0.05) => {
  return amount + (amount * taxRate);
};

console.log(calculateTotal(100)); // Output: 105
```

:::

- Анонімні функції — це функції без імені, які можна призначити змінним. Призначивши їх змінним, ви можете повторно використовувати їх у будь-якому місці, де доступна ця змінна.

:::interactive_editor

```js
const multiplyNumbers = function(firstNumber, secondNumber) {
  return firstNumber * secondNumber;
};

console.log(multiplyNumbers(4, 5)); // Output: 20
```

:::

## Стрілкові функції

- Стрілкові функції — це більш лаконічний спосіб написання функцій у JavaScript.

- При оголошенні стрілкової функції ключове слово `function` не потрібне.
- Якщо використовується один параметр, можна опустити круглі дужки навколо списку параметрів.

- Якщо тіло функції складається з одного виразу, можна опустити фігурні дужки та ключове слово `return`.

:::interactive_editor

```js
const square = number => number * number;

console.log(square(5)); // Output: 25
```

:::

## Область видимості в програмуванні

- **Глобальна область видимості**: це зовнішня область видимості в JavaScript. Змінні, оголошені в глобальній області видимості, доступні з будь-якого місця в коді і називаються глобальними змінними.
- **Локальна область видимості**: це змінні, оголошені всередині функції. Ці змінні доступні лише в тій функції, де вони оголошені, і називаються локальними змінними.
- **Область видимості блоку**: блок — це множина інструкцій, укладених у фігурні дужки `{}` (наприклад, в `if`-інструкціях або циклах).
- Область видимості блоку з `let` та `const` дає ще більш точний контроль над доступом до змінних, допомагаючи уникнути помилок і зробити код більш передбачуваним.

## Масиви в JavaScript

- **Визначення**: масив у JavaScript — це впорядкована колекція значень, кожне з яких ідентифікується числовим індексом. Значення в масиві JavaScript можуть бути різних типів даних, включно з числами, рядками, булевими значеннями, об’єктами та навіть іншими масивами. Масиви розташовані безперервно в пам’яті, тобто всі елементи зберігаються в одному безперервному блоці пам’яті, що дозволяє ефективно індексувати та швидко отримувати доступ до елементів за їхнім індексом.

- **Доступ до елементів масивів**: щоб отримати доступ до елементів масиву, потрібно звернутися до масиву, вказавши індекс елемента в квадратних дужках. Масиви в JavaScript мають індексацію з нуля, тобто перший елемент має індекс 0, другий — індекс 1 і так далі. Якщо ви спробуєте звернутися до індексу, якого немає в масиві, то JavaScript поверне `undefined`.

- **Властивість `length`**: ця властивість використовується для повернення кількості елементів у масиві.

- **Оновлення елементів у масиві**: для оновлення елемента в масиві використовуйте оператор присвоєння (`=`), щоб призначити нове значення елементу за певним індексом.

## Двовимірні масиви

- **Визначення**: двовимірний масив — це по суті масив масивів. Його використовують, щоб представити дані, які мають природну сіткову структуру (наприклад, шахівницю, електронну таблицю або пікселі на зображенні). Щоб отримати доступ до елемента у двовимірному масиві, потрібні два індекси: один для рядка і один для стовпця.

## Деструктуризація масивів

- **Визначення**: деструктуризація масивів — це функція в JavaScript, яка дозволяє витягувати значення з масивів і призначати їх змінним у більш стислому та зрозумілому вигляді. Вона надає зручний синтаксис для розпакування елементів масиву в окремі змінні.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange"];

const [first, second, third] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(third); // "orange"
```

:::

- **Синтаксис rest**: це дозволяє захопити залишок елементів масиву, які не були деструктуризовані, у новий масив.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange", "mango", "kiwi"];
const [first, second, ...rest] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(rest); // ["orange", "mango", "kiwi"]
```

:::

## Поширені методи масивів

- **Метод `push()`**: цей метод використовується, щоб додати елементи в кінець масиву і повернути нову довжину.

- **Метод `pop()`**: цей метод використовується, щоб видалити останній елемент з масиву і повернути цей видалений елемент. Якщо масив порожній, то поверненим значенням буде `undefined`.

- **Метод `shift()`**: цей метод використовується, щоб видалити перший елемент з масиву і повернути цей видалений елемент. Якщо масив порожній, то поверненим значенням буде `undefined`.

- **Метод `unshift()`**: цей метод використовується, щоб додати елементи на початок масиву і повернути нову довжину.

- **Метод `indexOf()`**: Цей метод корисний для того, щоб знайти перший індекс конкретного елемента в масиві. Якщо елемент не знайдено, то він поверне `-1`.

- **Метод `splice()`**: Цей метод використовується, щоб додавати або видаляти елементи з будь-якої позиції в масиві. Поверненим значенням для методу `splice()` буде масив елементів, видалених з масиву. Якщо нічого не видаляється, то повертається порожній масив. Цей метод змінює оригінальний масив, модифікуючи його на місці, а не створюючи новий масив. Перший аргумент вказує індекс, з якого починається модифікація масиву. Другий аргумент — це кількість елементів, які ви хочете видалити. Наступні аргументи — це елементи, які ви хочете додати.

- **Метод `includes()`**: цей метод використовується, щоб перевірити, чи містить масив конкретне значення. Цей метод повертає `true`, якщо масив містить вказаний елемент, і `false` в іншому випадку.

- **Метод `concat()`**: цей метод створює новий масив, об’єднуючи два або більше масивів.

- **Метод `slice()`**: Цей метод повертає новий масив, що містить поверхневу копію частини оригінального масиву, визначеної початковим і кінцевим індексами. Новий масив містить референси на ті ж елементи, що й оригінальний масив (не дублікати). Це означає, що якщо елементи — примітиви (наприклад, числа або рядки), значення копіюються; але якщо елементи — об’єкти або масиви, копіюються референси, а не самі об’єкти.

- **Синтаксис розширення**: синтаксис розширення використовується для створення поверхневих копій масиву.

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const shallowCopiedArray = [...originalArray];

shallowCopiedArray.push(4);

console.log(originalArray); // [1, 2, 3]
console.log(shallowCopiedArray); // [1, 2, 3, 4]
```

:::

- **Метод `split()`**: цей метод розбиває рядок на масив підрядків і визначає, де має відбутися кожне розбиття на основі заданого роздільника. Якщо роздільник не вказано, то метод повертає масив, що містить оригінальний рядок як один елемент.

- **Метод `reverse()`**: цей метод змінює порядок елементів масиву на зворотний на місці.

- **Метод `join()`**: цей метод об’єднує всі елементи масиву в один рядок, розділяючи кожен елемент вказаним роздільником. Якщо роздільник не вказано або використано порожній рядок (`""`), елементи будуть об’єднані без роздільника.

## Основи об’єктів

- **Визначення**: об’єкт — це структура даних, яка складається з властивостей. Властивість містить ключ і значення. Щоб отримати доступ до даних об’єкта, можна використовувати або точкову нотацію, або дужкову нотацію.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  city: "New York"
};

console.log(person.name);  // Alice
console.log(person["name"]); // Alice
```

:::

Щоб призначити властивість існуючого об’єкта, можна використовувати або точкову нотацію, або дужкову нотацію разом з оператором присвоєння.

## Видалення властивостей з об’єкта

- **Оператор `delete`**: цей оператор використовується для видалення властивості з об’єкта.

## Перевірка, чи має об’єкт властивість

- **Метод `hasOwnProperty()`**: цей метод повертає булеве значення, яке вказує, чи має об’єкт вказану властивість як власну властивість.

- **`Object.hasOwn()` метод**: Це сучасний, рекомендований спосіб перевірити, чи має об’єкт власну (не успадковану) властивість. Синтаксис: `Object.hasOwn(object, propertyName)`. Він повертає `true`, якщо властивість існує в об’єкті, і `false`, якщо ні, незалежно від значення властивості. Це робить його безпечнішим за `hasOwnProperty()` і надійнішим за `if (obj.prop)`, коли значення можуть бути `0`, `false`, `null` або `undefined`.

`Object.hasOwn()` виявляє власну властивість навіть тоді, коли її значення є хибним, наприклад `0`, `false` або `undefined`.

- **Оператор `in`**: цей оператор поверне `true`, якщо властивість існує в об’єкті.

## Доступ до властивостей вкладених об’єктів

- **Доступ до даних**: доступ до властивостей вкладених об’єктів здійснюється за допомогою точкової або дужкової нотації, так само як і для простих об’єктів. Проте потрібно ланцюжком викликати ці доступи, щоб заглибитися у вкладену структуру.

## Примітивні та непримітивні типи даних

- **Примітивні типи даних**: ці типи даних включають числа, рядки, булеві значення, `null`, `undefined` та символи. Ці типи називають «примітивними», тому що вони представляють окремі значення і не є об’єктами. Примітивні значення є незмінними, тобто після створення їхнє значення не можна змінити.  
- **Непримітивні типи даних**: у JavaScript це об’єкти, які включають звичайні об’єкти, масиви та функції. На відміну від примітивів, непримітивні типи можуть містити кілька значень у вигляді властивостей або елементів.

## Методи об’єктів

- **Визначення**: методи об’єктів — це функції, які пов’язані з об’єктом. Вони визначаються як властивості об’єкта і можуть отримувати доступ до даних об’єкта та змінювати їх. Ключове слово `this` всередині методу посилається на сам об’єкт, що дає змогу отримувати доступ до його властивостей.

## Конструктор об’єкта

- **Визначення**: конструктор у JavaScript — це спеціальний тип функції, який використовується для створення та ініціалізації об’єктів. Його викликають за допомогою ключового слова `new` і він може ініціалізувати властивості та методи на новоствореному об’єкті. Конструктор `Object()` створює новий порожній об’єкт.

## Робота з оператором необов’язкового ланцюжка (`?.`)

- **Визначення**: цей оператор дозволяє безпечно отримувати доступ до властивості об’єкта або викликати методи, не турбуючись про те, чи вони існують.

:::interactive_editor

```ts
const user = {
  name: "John",
  profile: {
    email: "john@example.com",
    address: {
      street: "123 Main St",
      city: "Somewhere"
    }
  }
};

console.log(user.profile?.address?.street); // "123 Main St"
console.log(user.profile?.phone?.number);   // undefined
```

:::

## Деструктуризація об’єктів

- **Визначення**: деструктуризація об’єктів дозволяє витягувати значення з об’єктів і призначати їх до змінних більш лаконічним і зрозумілим способом.

:::interactive_editor

```js
const person = { name: "Alice", age: 30, city: "New York" };

const { name, age } = person;

console.log(name); // Alice
console.log(age);  // 30
```

:::

## Робота з JSON

- **Визначення**: JSON означає JavaScript Object Notation. Це легкий, текстовий формат даних, який часто використовується для обміну даними між сервером і вебзастосунком.

- **`JSON.stringify()`**: цей метод використовується для перетворення JavaScript-об’єкта в JSON-рядок. Це корисно, коли потрібно зберегти або передати дані у форматі, яким можна легко поділитись або передати між системами.

- **`JSON.parse()`**: цей метод перетворює JSON-рядок назад у JavaScript-об’єкт. Це корисно, коли ви отримуєте JSON-дані з вебсервера або localStorage і потрібно опрацювати ці дані у своєму застосунку.

## Робота з циклами

- **Цикл `for`**: цей тип циклу використовується для повторення блоку коду певну кількість разів. Цикл складається з трьох частин: інструкції ініціалізації, умови та інструкції збільшення/зменшення. Інструкція ініціалізації виконується перед початком циклу. Зазвичай її використовують для ініціалізації змінної-лічильника. Умова оцінюється перед кожною ітерацією циклу. Ітерація — це один прохід циклом. Якщо умова `true`, то виконується блок коду всередині циклу. Якщо умова `false`, то цикл зупиняється, і ви переходите до наступного блоку коду. Інструкція збільшення/зменшення виконується після кожної ітерації циклу. Зазвичай її використовують для збільшення або зменшення змінної-фішки.

:::interactive_editor

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

:::

- **Цикл `for...of`**: цей тип циклу використовується, коли потрібно ітерувати над значеннями ітерованого об’єкта. Прикладами ітерованих об’єктів є масиви та рядки.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];

for (const num of numbers) {
  console.log(num);
}
```

:::

- **Цикл `for...in`**: цей тип циклу найкраще підходить, коли потрібно ітерувати над властивостями об’єкта. Цикл ітеруватиме всі перелічувані властивості об’єкта, включно з успадкованими та непронумерованими.

:::interactive_editor

```js
const fruit = {
  name: 'apple',
  color: 'red',
  price: 0.99
};

for (const prop in fruit) {
  console.log(fruit[prop]);
}
```

:::

- **Цикл `while`**: цей тип циклу виконуватиме блок коду доти, доки умова `true`.

:::interactive_editor

```js
let i = 5;

while (i > 0) {
  console.log(i);
  i--;
}
```

:::

- **Цикл `do...while`**: цей тип циклу буде виконувати блок коду принаймні один раз перед перевіркою умови.

```js
let userInput;

do {
  userInput = prompt("Please enter a number between 1 and 10");
} while (Number(userInput) < 1 || Number(userInput) > 10);

alert("You entered a valid number!");
```

## Інструкції `break` та `continue`

- **Визначення**: інструкція `break` використовується для дострокового виходу з циклу, тоді як інструкція `continue` використовується, щоб пропустити поточну ітерацію циклу і перейти до наступної.

## Конструктор рядка та метод `toString()`

- **Визначення**: об’єкт рядка використовується для представлення послідовності символів. Об’єкти рядка створюються за допомогою конструктора `String`, який обгортає примітивне значення в об’єкт.

- **Метод `toString()`**: цей метод перетворює значення у його рядкове представлення. Це метод, який можна використовувати для чисел, булевих значень, масивів і об’єктів.

Цей метод приймає необов’язковий параметр radix — число від 2 до 36. Цей radix представляє основу (наприклад, основу 2 для бінарної системи або 8 для вісімкової). Якщо radix не вказано, за замовчуванням використовується основа 10, тобто десяткова система.

## Конструктор числа

- **Визначення**: конструктор `Number` використовується для створення об’єкта number. Об’єкт number містить кілька корисних властивостей і методів, таких як методи `isNaN` і `toFixed`. Здебільшого ви будете використовувати конструктор `Number` для перетворення інших типів даних у тип number.

## Найкращі практики іменування змінних і функцій

- **верблюдячийРегістр**: за правилами, розробники JavaScript використовують верблюдячий регістр для назв змінних і функцій. Тобто перше слово пишеться з малої літери, а наступні — з великої. Наприклад, `isLoading`.

- **Іменування булевих змінних**: для булевих змінних часто використовують префікси на кшталт «is», «has» або «can».

- **Іменування функцій**: назва функції має чітко вказувати, що вона робить. Для функцій, які повертають булеве значення (їх часто називають предикатами), можна використовувати ті ж префікси «is», «has» або «can». Назви функцій, які отримують дані, зазвичай починаються зі слова «get». Назви функцій, які встановлюють дані, зазвичай починаються зі слова «set». Для функцій, які обробляють події, можна додавати префікс «handle» або суфікс «Handler».

- **Іменування змінних у циклах**: для іменування змінних-ітераторів у циклах зазвичай використовують поодинокі літери, наприклад `i`, `j` або `k`.

## Робота з розрідженими масивами

- **Визначення**: бувають масиви з порожніми слотами. Порожні слоти — це слоти, у яких нічого немає. Вони відрізняються від слотів масиву зі значенням `undefined`. Такі типи масивів відомі як розріджені масиви.

## Лінтери та форматери

- **Лінтери**: лінтер — це інструмент статичного аналізу коду, який позначає помилки програмування, баги, стилістичні помилки та підозрілі конструкції. Прикладом поширеного лінтера є ESLint.
- **Форматери**: форматери — це інструменти, які автоматично форматують код відповідно до певного стилістичного довідника. Прикладом поширеного форматера є Prettier.

## Керування пам’яттю

- **Визначення**: керування пам’яттю — це процес контролю пам’яті, її виділення за потреби та звільнення, коли вона більше не потрібна. JavaScript використовує автоматичне керування пам’яттю. Це означає, що JavaScript (точніше, JavaScript-рушій у браузері) самостійно піклується про виділення та звільнення пам’яті. Вам не потрібно чистити пам’ять у своєму коді. Цей автоматичний процес часто називають «прибиранням сміття».

## Замикання

- **Визначення**: замикання — це функція, яка має доступ до змінних у своїй зовнішній лексичній області видимості, навіть після того, як зовнішня функція повернула результат.

:::interactive_editor

```js
function outerFunction(x) {
  let y = 10;
  function innerFunction() {
    console.log(x + y);
  }
  return innerFunction;
}

let closure = outerFunction(5);
closure(); // 15
```

:::

## Ключове слово `var` та підняття оголошень

- **Визначення**: `var` був початковим способом оголошення змінних до 2015 року. Але з `var` виникли деякі проблеми, пов’язані з областю видимості, повторним оголошенням та іншими аспектами. Тому сучасне програмування на JavaScript використовує `let` та `const` замість нього.
- **Повторне оголошення змінних з `var`**: якщо ви спробуєте повторно оголосити змінну за допомогою `let`, то отримаєте `SyntaxError`. Але з `var` повторне оголошення змінної дозволене.

- **`var` та область видимості**: змінні, оголошені з `var` всередині блоку (наприклад, в інструкції `if` або циклу `for`), залишаються доступними поза межами цього блоку.

- **Підняття оголошень**: це стандартна поведінка JavaScript, коли оголошення піднімаються на початок відповідних областей видимості під час фази компіляції перед виконанням коду. Коли ви оголошуєте змінну за допомогою ключового слова `var`, JavaScript піднімає це оголошення на початок області видимості.

Коли ви оголошуєте функцію за допомогою синтаксису оголошення функції, і назва функції, і її тіло піднімаються. Це означає, що ви можете викликати функцію до того, як оголосите її у своєму коді.

Оголошення змінних, зроблені за допомогою `let` або `const`, також піднімаються, але вони не ініціалізовані, і ви не можете отримати до них доступ до фактичного оголошення у коді. Цю поведінку часто називають «тимчасовою мертвою зоною».

## Робота з імпортами, експортами та модулями

- **Модуль**: це автономна одиниця коду, яка інкапсулює пов’язані функції, класи або змінні. Щоб створити модуль, напишіть JavaScript-код в окремому файлі.
- **Експорти**: будь-які змінні, функції або класи, які ви хочете зробити доступними для інших частин застосунку, потрібно явно експортувати за допомогою ключового слова `export`. Існує два типи експорту: іменований експорт і експорт за замовчуванням.
- **Імпорти**: щоб використовувати експортовані елементи в іншій частині застосунку, їх потрібно імпортувати за допомогою ключового слова `import`. Типами імпорту можуть бути: іменований імпорт, імпорт за замовчуванням і імпорт простору імен.

```js
// Within a file called math.js, we export the following functions:

// Named export
export function add(num1, num2) {
  return num1 + num2;
}

// Default export
export default function subtract(num1, num2) {
  return num1 - num2;
}

// Within another file, we can import the functions from math.js.

// Named import - This line imports the add function.
// The name of the function must exactly match the one exported from math.js.
import { add } from './math.js';

// Default import - This line imports the subtract function.
// The name of the function can be anything.
import subtractFunc from './math.js';

// Namespace import - This line imports everything from the file.
import * as Math from './math.js';

console.log(add(5, 3)); // 8
console.log(subtractFunc(5, 3)); // 2
console.log(Math.add(5, 3)); // 8
console.log(Math.subtract(5, 3)); // 2
```

## Функції зворотного виклику та метод `forEach`

- **Визначення**: У JavaScript функція зворотного виклику — це функція, яка передається як аргумент іншій функції, щоб зовнішня функція могла викликати її у певний момент.
- **Метод `forEach()`**: Цей метод використовується для ітерування над кожним елементом масиву та виконання операції над кожним елементом. Функція зворотного виклику в `forEach` може приймати до трьох аргументів: поточний елемент, індекс поточного елемента та масив, над яким викликано `forEach`.

## Функції вищого порядку

- **Визначення**: функція вищого порядку приймає одну або кілька функцій як аргументи і повертає функцію або значення як результат.

- **Метод `map()`**: цей метод використовується для створення нового масиву шляхом застосування заданої функції до кожного елемента початкового масиву. Функція зворотного виклику може приймати не більше трьох аргументів: поточний елемент, індекс поточного елемента та масив, до якого було застосовано `map`.

- **Метод `filter()`**: цей метод використовується для створення нового масиву з елементів, які проходять заданий тест, що робить його корисним для вибіркового вилучення елементів за певними критеріями. Так само, як і метод `map`, функція зворотного виклику для методу `filter` приймає ті ж три аргументи: поточний оброблюваний елемент, індекс і масив.

- **Метод `reduce()`**: цей метод використовується для обробки масиву та зведення його до одного значення. Це значення може бути числом, рядком, об’єктом або навіть іншим масивом. Метод `reduce()` працює шляхом застосування функції до кожного елемента масиву послідовно, передаючи результат кожного обчислення наступному. Цю функцію часто називають функцією-редуктором. Функція-редуктор приймає два основні параметри: акумулятор і поточне значення. Акумулятор — це місце, де ви зберігаєте поточний результат операцій, а поточне значення — це елемент масиву, який обробляється.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce(
  (accumulator, currentValue) => accumulator + currentValue,
  0
);

console.log(sum); // 15
```

:::

## Ланцюжок методів

- **Визначення**: ланцюжок методів — це техніка програмування, яка дозволяє викликати кілька методів на одному об’єкті в одному рядку коду. Ця техніка може зробити код більш читабельним і лаконічним, особливо коли ви виконуєте серію операцій над одним і тим самим об’єктом.

## Робота з методом `sort`

- **Визначення**: метод `sort` використовується для сортування елементів масиву та повертає референс на відсортований масив. Копія в цьому випадку не створюється, оскільки елементи сортуються на місці.

Якщо потрібно сортувати числа, необхідно передати функцію порівняння. Метод `sort` перетворює елементи на рядки, а потім порівнює їх послідовності кодових одиниць UTF-16. Кодові одиниці UTF-16 — це числові значення, які представляють символи в рядку. Прикладами кодових одиниць UTF-16 є числа 65, 66 і 67, які відповідають символам "A", "B" і "C" відповідно. Тому число 200 з’являється перед числом 3 у масиві, бо рядок "200" йде перед рядком "3" при порівнянні їх кодових одиниць UTF-16.

:::interactive_editor

```js
const numbers = [414, 200, 5, 10, 3];

numbers.sort((a, b) => a - b);

console.log(numbers); // [3, 5, 10, 200, 414]
```

:::

Параметри `a` і `b` — це два елементи, які порівнюються. Функція порівняння має повертати від’ємне значення, якщо `a` має йти перед `b`; додатне значення, якщо `a` має йти після `b`; і нуль, якщо `a` і `b` рівні.

## Робота з методами `every` та `some`

- **Метод `every()`**: цей метод перевіряє, чи всі елементи масиву проходять тест, реалізований наданою функцією. Метод `every()` повертає `true`, якщо надана функція повертає `true` для всіх елементів масиву. Якщо будь-який елемент не проходить тест, то метод одразу повертає `false` і припиняє перевірку решти елементів.

- **Метод `some()`**: цей метод перевіряє, чи принаймні один елемент проходить тест. Метод `some()` повертає `true` щойно знаходить елемент, який проходить тест. Якщо жоден елемент не проходить тест, то він повертає `false`.

## Робота з DOM і веб-API

- **API**: API (інтерфейс програмування застосунків) — це набір правил і протоколів, які дозволяють програмним застосункам ефективно взаємодіяти між собою та обмінюватися даними.
- **Веб-API**: веб-API спеціально розроблені для вебзастосунків. Ці типи API часто поділяють на дві основні категорії: API браузера та сторонні API.
- **API браузера**: ці API відкривають доступ до даних браузера. Як веброзробник, ви можете отримувати доступ до цих даних і маніпулювати ними за допомогою JavaScript.
- **Сторонні API**: вони не вбудовані в браузер за замовчуванням. Вам потрібно отримати їхній код якимось чином. Зазвичай вони мають детальну документацію, яка пояснює, як користуватися їхніми сервісами. Прикладом є Google Maps API, який можна використати для відображення інтерактивних карт на сайті.
- **DOM**: DOM означає Document Object Model (укр. модель об’єктів документа). Це інтерфейс програмування, який дозволяє взаємодіяти з HTML-документами. За допомогою DOM ви можете додавати, змінювати або видаляти елементи на вебсторінці. Коренем дерева DOM є елемент `html`. Це контейнер найвищого рівня для всього вмісту HTML-документа. Всі інші вузли є нащадками цього кореневого вузла. Далі, під кореневим вузлом, знаходяться інші вузли в ієрархії. Батьківський вузол — це елемент, який містить інші елементи. Дочірній вузол — це елемент, який міститься в іншому елементі.
- **Інтерфейс `navigator`**: він надає інформацію про середовище браузера, таку як рядок user agent, платформу та версію браузера. Рядок user agent — це текстовий рядок, який ідентифікує браузер і операційну систему, які використовуються.
- **Інтерфейс `window`**: він представляє вікно браузера, яке містить документ DOM. Він надає методи та властивості для взаємодії з вікном браузера (наприклад, зміни розміру вікна, відкриття нових вікон і навігації за різними посиланнями).

## Робота з методами `querySelector()`, `querySelectorAll()` та `getElementById()`

- **Метод `getElementById()`**: цей метод використовується, щоб отримати об’єкт, який представляє HTML-елемент із заданим `id`. Пам’ятайте, що ідентифікатори мають бути унікальними в кожному HTML-документі, тому цей метод поверне лише один об’єкт Element.

- **Метод `querySelector()`**: цей метод використовується, щоб отримати перший елемент у HTML-документі, який відповідає CSS-селектору, переданому як аргумент.

- **Метод `querySelectorAll()`**: ви можете використати цей метод, щоб отримати список усіх DOM-елементів, які відповідають певному CSS-селектору.

## Робота з методами `innerText()`, `innerHTML()`, `createElement()` та `textContent()`

- **Властивість `innerHTML`**: це властивість `Element`, яка використовується для встановлення або оновлення частин HTML-розмітки.

- **Метод `createElement`**: використовується для створення HTML-елемента.

- **`innerText`**: це представляє видимий текстовий вміст HTML-елемента та його нащадків.

- **`textContent`**: повертає простий текстовий вміст елемента, включно з усім текстом у його нащадках.

## Робота з методами `appendChild()` та `removeChild()`

- **Метод `appendChild()`**: цей метод використовується, щоб додати вузол у кінець списку дочірніх елементів вказаного батьківського вузла.

- **Метод `removeChild()`**: цей метод використовується, щоб видалити вузол з DOM.

## Робота з методом `setAttribute()`

- **Визначення**: цей метод використовується, щоб встановити атрибут для заданого елемента. Якщо атрибут уже існує, тоді його значення оновлюється. Інакше додається новий атрибут зі значенням.

## Об’єкт події

- **Визначення**: об’єкт `Event` — це корисне навантаження, яке спрацьовує, коли користувач взаємодіє з вебсторінкою певним чином. Ці взаємодії можуть бути будь-якими: від натискання на кнопку або фокусу на вхідних даних до трясіння мобільного пристрою. Усі об’єкти `Event` матимуть властивість `type`. Ця властивість показує тип події, яка спричинила корисне навантаження (наприклад, keydown або click). Ці значення відповідатимуть тим самим значенням, які ви можете передати до `addEventListener()`, де можна захопити й використати об’єкт `Event`.

## Методи `addEventListener()` і `removeEventListener()`

- **Метод `addEventListener`**: цей метод використовується для прослуховування подій. Він приймає два аргументи: подію, яку ви хочете відстежувати, і функцію, яка буде викликана, коли ця подія станеться. Поширеними прикладами подій є події натискання, введення та зміни.

:::interactive_editor

```html
<button id="btn">Click Me</button>
<script src="./index.js"></script>
```

```js
const btn = document.getElementById("btn");

btn.addEventListener("click", () => alert("You clicked the button"));
```

:::

- **Метод `removeEventListener()`**: цей метод використовується для видалення обробника події, який раніше було додано до елемента за допомогою методу `addEventListener()`. Це корисно, коли ви хочете припинити прослуховування певної події на елементі.

- **Рядкові обробники подій**: рядкові обробники подій — це спеціальні атрибути HTML-елемента, які використовуються для виконання JavaScript-коду при виникненні події. У сучасному JavaScript рядкові обробники подій не вважаються найкращою практикою. Натомість рекомендується використовувати метод `addEventListener`.

## Подія change

- **Визначення**: подія change — це спеціальна подія, яка спрацьовує, коли користувач змінює значення певних вхідних елементів. Прикладами можуть бути випадки, коли прапорець або радіокнопка позначаються. Або коли користувач робить вибір у такому елементі, як вибір дати чи випадаюче меню.

## Поширення подій (event bubbling)

- **Визначення**: Поширення подій, або пропагування, означає, як подія «піднімається» до батьківських об’єктів після спрацьовування.
- **Метод `stopPropagation()`**: Цей метод запобігає подальшому поширенню події.

## Делегування подій

- **Визначення**: делегування подій — це процес прослуховування подій, які піднялися до батьківського елемента, замість того, щоб обробляти їх безпосередньо на елементі, який їх викликав.

## Подія DOMContentLoaded

- **Визначення**: подія `DOMContentLoaded` спрацьовує, коли все в HTML-документі було завантажено та проаналізовано. Якщо у вас є зовнішні таблиці стилів або зображення, то подія `DOMContentLoaded` не чекатиме на їхнє завантаження. Вона чекатиме лише на завантаження HTML.

## Робота з `style` та `classList`

- **Властивість `Element.style`**: ця властивість є властивістю лише для читання, яка представляє рядковий стиль елемента. Ви можете використовувати цю властивість, щоб отримати або задати стиль елемента.

- **Властивість `Element.classList`**: ця властивість є властивістю лише для читання, яку можна використовувати для додавання, видалення або перемикання класів на елементі.

## Робота з методами `setTimeout()` та `setInterval()`

- **Метод `setTimeout()`**: цей метод дозволяє затримати виконання дії на вказаний час.

- **Метод `setInterval()`**: Цей метод запускає фрагмент коду повторно через встановлений інтервал. Оскільки `setInterval()` продовжує виконувати передану функцію з вказаним інтервалом, можливо, ви захочете його зупинити. Для цього потрібно використати метод `clearInterval()`.

## Метод `requestAnimationFrame()`

- **Визначення**: цей метод дозволяє запланувати наступний крок анімації перед наступним оновленням екрану, що забезпечує плавний і привабливий візуальний ефект. Наступне оновлення екрану — це момент, коли браузер оновлює візуальне відображення вебсторінки. Це відбувається кілька разів на секунду, зазвичай близько 60 разів (або 60 кадрів на секунду) на більшості дисплеїв.

Щоб працювати з Canvas API, спочатку потрібно додати елемент `canvas` у HTML. Цей елемент слугує поверхнею для малювання, якою ви можете керувати за допомогою методів і властивостей інтерфейсів в Canvas API. ## Відкриття та закриття діалогів і модальних вікон за допомогою JavaScript

- **Визначення модальних вікон і діалогів**: діалоги дозволяють відображати важливу інформацію або дії для користувачів. За допомогою вбудованого в HTML елемента dialog ви можете легко створювати ці діалоги (як модальні, так і немодальні) у вебзастосунках. Модальний діалог — це тип діалогу, який змушує користувача взаємодіяти з ним, перш ніж він зможе отримати доступ до решти застосунку або сторінки. На відміну від нього, немодальний діалог дозволяє користувачу продовжувати взаємодіяти з іншими частинами сторінки або застосунку навіть коли діалог відкритий. Він не блокує доступ до решти вмісту.
- **Метод `showModal()`**: цей метод використовується для відкриття модального вікна.

- **Метод `close()`**: цей метод використовується для закриття модального вікна.

## Загальні атрибути доступності ARIA

- **`aria-expanded` атрибут**: Використовується для передачі стану функції перемикання (або розкриття) користувачам читачів екрана.

- **атрибут `aria-haspopup`**: Цей стан використовується, щоб вказати, що інтерактивний елемент активує спливаючий елемент. Ви можете використовувати атрибут `aria-haspopup` лише тоді, коли спливаючий елемент має одну з таких ролей: `menu`, `listbox`, `tree`, `grid` або `dialog`. Значення `aria-haspopup` має бути або однією з цих ролей, або `true`, що еквівалентно `menu`.

- **атрибут `aria-checked`**: Цей атрибут використовується, щоб вказати, чи перебуває елемент у стані вибраності. Найчастіше його застосовують при створенні кастомних прапорців, радіокнопок, перемикачів і listbox.

- **атрибут `aria-disabled`**: Цей стан використовується, щоб вказати, що елемент вимкнений лише для користувачів допоміжних технологій, таких як читачі екрана.

- **атрибут `aria-selected`**: Цей стан використовується, щоб вказати, що елемент вибраний. Ви можете застосовувати цей стан до кастомних елементів керування, таких як вкладковий інтерфейс, listbox або сітка.

- **атрибут `aria-controls`**: Використовується для зв’язку елемента з іншим елементом, яким він керує. Це допомагає користувачам допоміжних технологій зрозуміти взаємозв’язок між елементами.

- **атрибут `hidden`**: Приховує неактивні панелі як від візуальних користувачів, так і від користувачів допоміжних технологій.

## Робота з живими регіонами та динамічним вмістом

- **`aria-live` атрибут**: Робить частину вебсторінки живим регіоном, тобто будь-які оновлення в цій області будуть оголошені читачем екрана, щоб користувачі не пропустили важливі зміни.
- **`polite` значення**: Більшість живих регіонів використовують це значення. Воно означає, що оновлення не є терміновим, тому читач екрана може почекати, поки завершить поточне оголошення або користувач завершить свою дію, перш ніж оголосити оновлення.

Ось приклад живого регіону, який динамічно оновлюється за допомогою JavaScript:

:::interactive_editor

```html
<div aria-live="polite" id="status"></div>

<button id="updateStatus">Update Status</button>

<script>
  const statusEl = document.getElementById("status");
  const btn = document.getElementById("updateStatus");

  btn.addEventListener("click", () => {
    statusEl.textContent = "Your file has been successfully uploaded.";
  });
</script>
```

:::

- **`contenteditable` атрибут**: Перетворює елемент на живий редактор, дозволяючи користувачам оновлювати його вміст, ніби це текстове поле. Якщо для області з contenteditable немає видимої мітки або заголовка, додайте доступну назву за допомогою атрибута `aria-label`, щоб допомогти користувачам читачів екрана зрозуміти призначення редагованої області.

- **`blur` подія**: Виникає, коли елемент втрачає фокус.

- **`focus` подія**: Виникає, коли елемент отримує фокус.

## Поширені типи повідомлень про помилку

- **SyntaxError**: ці помилки виникають, коли ви неправильно пишете щось у своєму коді (наприклад, пропускаєте круглу або квадратну дужку). Думайте про це як граматичну помилку в реченні.

- **ReferenceError**: існує кілька типів помилок ReferenceError, які виникають різними способами. Перший тип помилки посилання — це невизначені змінні. Ще один приклад ReferenceError — це спроба звернутися до змінної, оголошеної з `let` або `const`, до того, як вона була визначена.

- **TypeError**: ці помилки виникають, коли ви намагаєтеся виконати операцію з неправильним типом.

- **RangeError**: ці помилки трапляються, коли код намагається використати значення, що виходить за межі діапазону, який JavaScript може обробити.

## Інструкція `throw`

- **Визначення**: Інструкція `throw` у JavaScript використовується для викидання користувацького виключення. Виключення в програмуванні — це коли трапляється несподівана подія, яка порушує нормальний потік програми.

## `try...catch...finally`

- **Визначення**: блок `try` використовується для обгортання коду, який може викликати помилку. Він слугує безпечним простором, щоб спробувати щось, що може не вийти. Блок `catch` ловить і обробляє помилки, які виникають у блоці try. Ви можете використовувати об’єкт помилки всередині catch, щоб перевірити, що пішло не так. Блок `finally` виконується після блоків try і catch, незалежно від того, чи сталася помилка. Його зазвичай використовують для прибирання (наприклад, закриття файлів або звільнення ресурсів).

:::interactive_editor

```js
function processInput(input) {
  if (typeof input !== "string") {
    throw new TypeError("Input must be a string.");
  }

  return input.toUpperCase();
}

try {
  console.log("Starting to process input...");
  const result1 = processInput("hello");
  console.log("Processed result:", result1);  // HELLO
  const result2 = processInput(9);  // throws TypeError
  console.log("Processed result:", result2);  // not executed
} catch (error) {
  console.error("Error occurred:", error.message);
} 
```

:::

## Техніки налагодження

- **Інструкція `debugger`**: ця інструкція дозволяє призупинити виконання коду на певному рядку, щоб дослідити, що відбувається в програмі.

- **Точки зупинки**: точки зупинки дозволяють призупинити виконання коду на вибраному вами рядку. Після паузи ви можете перевірити змінні, оцінити вирази та дослідити стек викликів.
- **Спостерігачі**: спостерігачі за виразами дають змогу відстежувати значення змінних або виразів під час виконання коду, навіть якщо вони поза поточною областю видимості.
- **Профілювання**: профілювання допомагає виявити місця низької продуктивності, дозволяючи робити знімки екрана та записувати використання центрального процесора, виклики функцій і час виконання.
- **`console.dir()`**: цей метод використовується для відображення інтерактивного списку властивостей заданого JavaScript-об’єкта. Він виводить ієрархічний перелік, який можна розгорнути, щоб побачити всі вкладені властивості.

- **`console.table()`**: цей метод відображає табличні дані у вигляді таблиці в консолі. Він приймає один обов’язковий аргумент, який має бути масивом або об’єктом, і один необов’язковий аргумент для вказівки, які властивості (стовпці) відображати.

## Регулярні вирази та поширені методи

- **Визначення**: регулярні вирази, або regex, використовують для створення «шаблону», який потім можна застосувати для перевірки рядка, вилучення тексту та іншого.

- **Конструктор `RegExp`**: Коли ваш шаблон або прапорці беруться з змінних, ви можете створити той самий регулярний вираз за допомогою конструктора `RegExp`. Він приймає рядок шаблону та необов’язковий рядок прапорців.

Наприклад, `new RegExp(pattern, flags)` створює регулярний вираз із цих рядків.

- **Метод `test()`**: цей метод приймає рядок, який потрібно перевірити на відповідність регулярному виразу. Метод поверне булеве значення, якщо рядок відповідає регулярному виразу.

- **Метод `match()`**: цей метод приймає регулярний вираз, хоча можна також передати рядок, який буде перетворений на регулярний вираз. Метод `match` повертає масив збігів для рядка.

- **Метод `replace()`**: цей метод приймає два аргументи: регулярний вираз для пошуку (або рядок) і рядок для заміни збігу (або функцію, яку потрібно виконати для кожного збігу).

- **Метод `replaceAll`**: цей метод використовується для заміни всіх входжень заданого шаблону на новий рядок. Якщо передати регулярний вираз без глобального модифікатора, то метод викличе помилку.

- **Метод `matchAll`**: цей метод використовується для отримання всіх збігів заданого регулярного виразу в рядку, включно з групами захоплення, і повертає їх у вигляді ітератора. Ітератор — це об’єкт, який дозволяє пройтися (або «ітерувати над») колекцією елементів.

## Модифікатори регулярних виразів

- **Визначення**: модифікатори, які часто називають «прапорцями», змінюють поведінку регулярного виразу.  
- **Прапорець `i`**: цей прапорець змушує регулярний вираз ігнорувати регістр.

- **Прапорець `g`**: цей прапорець, або глобальний модифікатор, дозволяє регулярному виразу знаходити шаблон більше одного разу.

- **Визначення якоря**: якір `^` на початку регулярного виразу означає «збіг з початком рядка». Якір `$` в кінці регулярного виразу означає «збіг з кінцем рядка».

- **Прапорець `m`**: Якорі шукають початок і кінець усього рядка. Але ви можете змусити регулярний вираз обробляти кілька рядків за допомогою прапорця `m`, або багаторядкового модифікатора.

- **Прапорець `d`**: Цей прапорець додає початкові та кінцеві індекси збігів і груп захоплення до об’єкта збігу.

- **`u` прапорець**: розширює функціональність регулярного виразу, дозволяючи йому співпадати зі спеціальними символами Unicode. Прапорець `u` дає доступ до спеціальних класів, таких як `Extended_Pictographic`, для співпадіння з більшістю емодзі. Існує також прапорець `v`, який ще більше розширює можливості співпадіння Unicode.
- **`y` прапорець**: модифікатор sticky поводиться дуже схоже на глобальний модифікатор, але з кількома винятками. Найголовніший полягає в тому, що глобальний регулярний вираз починає пошук з lastIndex і шукає співпадіння в усьому залишку рядка, а sticky регулярний вираз повертає null і скидає lastIndex до 0, якщо одразу немає співпадіння на попередньому lastIndex.
- **`s` прапорець**: модифікатор single-line дозволяє символу підстановки, який у регулярних виразах позначається як `.`, співпадати з розривами рядків — фактично розглядаючи рядок як один єдиний рядок тексту.

## Класи символів

- **Універсальний символ `.`**: класи символів — це спеціальний синтаксис, який ви можете використовувати, щоб співпадати з множинами або підмножинами символів. Перший клас символів, який варто вивчити, — це універсальний символ. Універсальний символ позначається крапкою і співпадає з БУДЬ-ЯКИМ одним символом, ОКРІМ розривів рядків. Щоб дозволити універсальному символу співпадати з розривами рядків, пам’ятайте, що потрібно використовувати прапорець `s`.

- **`\d`**: це співпаде з усіма цифрами (`0-9`) у рядку.

- **`\w`**: Це використовується для пошуку будь-якого символу слова (`a-zA-Z0-9_`) у рядку. Символ слова визначається як будь-яка літера від a до z або від A до Z, або число від 0 до 9, або символ підкреслення.

- **`\s`**: Клас пробілів `\s` позначається зворотною скісною рискою, за якою йде `s`. Цей клас символів відповідає будь-якому пробілу, включно з новими рядками, пробілами, табуляціями та спеціальними пробілами Unicode.
- **Заперечення спеціальних класів символів**: Щоб заперечити один із цих класів символів, замість використання малої літери після зворотної скісної риски, можна використати відповідну велику літеру. Наприклад, `\D` відповідає будь-якому символу, який НЕ є цифрою.

- **Користувацькі класи символів**: Ви можете створювати користувацькі класи символів, розміщуючи символи, які хочете співставити, всередині квадратних дужок.

Наприклад, `/[abcdf]/` відповідає будь-якому одному з символів у дужках.

## Твердження випередження та відставання

- **Визначення**: твердження випередження та відставання дозволяють співставляти конкретні шаблони залежно від наявності або відсутності навколишніх шаблонів.
- **Позитивне твердження випередження**: це твердження співставить шаблон, якщо за ним слідує інший шаблон. Щоб створити позитивне твердження випередження, потрібно почати з шаблону, який ви хочете співставити. Потім використайте круглі дужки, щоб обгорнути шаблон, який ви хочете використати як умову. Після відкриваючої дужки використайте `?=`, щоб визначити цей шаблон як позитивне твердження випередження.

Наприклад, `/free(?=code)/i` відповідає `free`, коли за ним слідує `code`.

- **Негативне твердження випередження**: це тип умови, що використовується в регулярних виразах для перевірки, що певний шаблон не зустрічається попереду в рядку.

Наприклад, `/free(?!code)/i` відповідає `free`, коли за ним НЕ слідує `code`.

- **Позитивне твердження відставання**: це твердження співставить шаблон лише якщо перед ним стоїть інший конкретний шаблон, не включаючи цей попередній шаблон у співставлення.

Наприклад, `/(?<=free)code/i` відповідає `code`, коли перед ним стоїть `free`.

- **Негативне твердження відставання**: це твердження гарантує, що шаблон не передує іншому конкретному шаблону. Воно співставляє лише якщо вказаний шаблон не безпосередньо передує заданій послідовності, не включаючи цю послідовність у співставлення.

Наприклад, `/(?<!free)code/i` відповідає `code`, коли перед ним НЕ стоїть `free`.

## Квантори регулярних виразів

- **Визначення**: Квантори в регулярних виразах вказують, скільки разів шаблон (або його частина) має з’явитися. Вони допомагають контролювати кількість входжень символів або груп у збігу.

Наприклад, `/^\d{4}$/` відповідає рядку, що містить рівно чотири цифри.

- **`*`** : збігається з 0 або більше входженнями попереднього елемента.
- **`+`**: збігається з 1 або більше входженнями попереднього елемента.
- **`?`**: збігається з 0 або 1 входженням попереднього елемента.
- **`{n}`**: збігається рівно з n входженнями попереднього елемента.
- **`{n,}`**: збігається з n або більше входженнями попереднього елемента.
- **`{n,m}`**: збігається з кількістю входжень попереднього елемента від n до m.

## Групи захоплення та референси

- **Групи захоплення**: група захоплення дозволяє «захопити» частину знайденого рядка, щоб використовувати її так, як вам потрібно. Групи захоплення визначаються круглими дужками, які містять шаблон для захоплення, без провідних символів, як-от випередження.

Наприклад, `/free(code)camp/i` захоплює `code`.

- **Некатчинг-групи**: Некатчинг-група схожа на групу захоплення, але не зберігає знайдену частину рядка для подальшого використання. Некатчинг-групи визначаються `(?:...)`.

Наприклад, `/free(?:code)camp/i` групує `code` без його захоплення.

- **Референси**: референс у регулярних виразах — це спосіб повторно використати частину шаблону, яка була знайдена раніше в тому ж виразі. Він дозволяє посилатися на групу захоплення (частину шаблону в круглих дужках) за її номером. Наприклад, `$1` посилається на першу групу захоплення.

:::interactive_editor

```js
const regex = /free(co+de)camp/i;
console.log("freecoooooooodecamp".replace(regex, "paid$1world"));
```

:::

- Ви можете використовувати зворотні посилання всередині самого regex, щоб знайти той самий текст, захоплений попередньою групою, за допомогою зворотної скісної риски та номера групи. Наприклад:

:::interactive_editor

```js
const regex = /(hello) \1/i;
console.log(regex.test("hello hello")); // true
console.log(regex.test("hello world")); // false
```

:::

## Валідація форм за допомогою JavaScript

- **Constraint Validation API**: певні HTML-елементи, такі як `textarea` і `input`, відкривають доступ до constraint validation API. Цей API дозволяє переконатися, що значення, яке користувач ввів для цього елемента, проходить будь-яку валідацію на рівні HTML, яку ви задали (наприклад, мінімальну довжину або відповідність шаблону).
- **Метод `checkValidity()`**: цей метод повертає `true`, якщо елемент відповідає всім HTML-валідаціям (на основі його атрибутів), і `false`, якщо ні.

- **Метод `reportValidity()`**: цей метод повідомляє браузеру, що `input` є недійсним.

- **Властивість `validity`**: Ця властивість використовується для отримання стану валідності елементів керування формою (таких як `<input>`, `<select>` тощо) і надає інформацію про те, чи відповідають введені користувачем дані обмеженням, визначеним для цього елемента (наприклад, полям з `required`, обмеженням за шаблоном, максимальною довжиною тощо).

- **Властивість `patternMismatch`**: вона буде `true`, якщо значення не відповідає заданому регулярному виразу.

## `preventDefault()` метод

- **Визначення**: Кожна подія, що виникає в DOM, має певну поведінку за замовчуванням. Подія натискання на прапорець за замовчуванням змінює його стан. Натискання <kbd>Spacebar</kbd> на елементі кнопки з фокусом активує цю кнопку. Метод `preventDefault()` для цих об’єктів `Event` зупиняє цю поведінку.

## Відправлення форм

- **Визначення**: Існує три способи відправки форми. Перший — коли користувач натискає кнопку у формі, у якої атрибут `type` встановлений у `submit`. Другий — коли користувач натискає клавішу <kbd>Enter</kbd> у будь-якому редагованому полі `input` у формі. Третій — через виклик JavaScript методів `requestSubmit()` або `submit()` елемента `form`.
- **Атрибут `action`**: Атрибут `action` повинен містити або URL, або відносний шлях для поточного домену. Це значення визначає, куди форма намагається надіслати дані — якщо ви не встановите атрибут `action`, форма надішле дані на URL поточної сторінки.

- **Атрибут `method`**: цей атрибут приймає стандартний метод `HTTP`, наприклад `GET` або `POST`, і використовує цей метод при виконанні запиту до посилання дії. Якщо метод не встановлено, форма за замовчуванням виконає запит `GET`. Дані у формі будуть кодуватися у форматі `name=value` пар і додаватися до посилання дії як параметри запиту.

- **Атрибут `enctype`**: елемент `form` приймає атрибут `enctype`, який визначає тип кодування для даних. Цей атрибут приймає лише три значення: `application/x-www-form-urlencoded` (за замовчуванням, надсилає дані у вигляді URL-кодованого тіла форми), `text/plain` (надсилає дані у вигляді простого тексту, у парах `name=value`, розділених новими рядками) або `multipart/form-data`, який спеціально призначений для обробки форм із завантаженням файлів.

## Об’єкт `date()` і загальні методи

- **Визначення**: Об’єкт `date()` використовується для створення, маніпулювання та форматування дат і часу в JavaScript. Наприклад, `const now = new Date();` створює новий екземпляр об’єкта `Date` і призначає його змінній `now`. Якщо ви виведете значення `now` в консоль, побачите поточну дату і час за системним годинником комп’ютера, на якому виконується код.

- **Метод `Date.now()`**: Цей метод використовується для отримання поточної дати і часу. `Date.now()` повертає кількість мілісекунд, що минули з 1 січня 1970 року, 00:00:00 UTC. Це відоме як час Unix-епохи. Час Unix-епохи — це загальний спосіб представлення дат і часу в комп’ютерних системах, оскільки це ціле число, яке легко зберігати і обробляти. UTC означає Всесвітній координований час, який є основним стандартом часу, за яким світ регулює годинники і час.
- **Метод `getDate()`**: Цей метод використовується для отримання дня місяця на основі поточної дати. `getDate()` поверне ціле число від 1 до 31, залежно від дня місяця. Якщо дата недійсна, він поверне `NaN` (Not a Number).

- **Метод `getMonth()`**: Цей метод використовується для отримання місяця. Місяці нумеруються починаючи з нуля, тому січень — це 0, лютий — 1 і так далі. Наприклад, виклик `getMonth()` для дати в жовтні поверне `9`. Якщо місяць недійсний, метод поверне `NaN`.

- **Метод `getFullYear()`**: цей метод використовується для отримання повного року. Якщо рік недійсний, він поверне `NaN`.

## Різні способи форматування дат

- **Метод `toISOString()`**: цей метод використовується для форматування дати у розширеному форматі `ISO` (ISO 8601). ISO 8601 — це міжнародний стандарт для представлення дат і часу. Формат такий: `YYYY-MM-DDTHH:mm:ss.sssZ`.

- **Метод `toLocaleDateString()`**: цей метод використовується для форматування дати залежно від локалі користувача.

Метод `toLocaleDateString()` приймає два необов’язкові параметри: locales і options.

Параметр locales — це рядок, який представляє локаль для використання. Наприклад, ви можете передати `"en-US"` для англійської (США) або `"fr-FR"` для французької (Франція). Якщо ви не передасте параметр locales, то буде використана локаль за замовчуванням. Другий необов’язковий параметр — це параметр options. Цей параметр є об’єктом, який дозволяє вказати формат рядка дати.

Він повертає `HTMLAudioElement`, який ви можете використовувати для відтворення аудіо для користувача або додати до DOM, щоб користувач міг керувати ним самостійно. Конструктор `Audio()` має властивості так само, як і методи. До цих властивостей належать:

- `muted`: для вимкнення звуку медіаелемента незалежно від налаштувань гучності

## Різні аудіо- та відеоформати

- **MIME-тип**: MIME-тип, що означає Multipurpose Internet Mail Extensions, — це стандартизований спосіб програмно вказати тип файлу. MIME-тип може повідомити застосунку, наприклад вашому браузеру, як обробляти конкретний файл. У випадку аудіо та відео MIME-тип вказує, що це мультимедійний формат, який можна вставити у вебсторінку.
- **Елемент `source`**: використовується для вказання типу файлу та джерела — і може містити кілька різних типів за допомогою кількох елементів source. Коли ви це робите, браузер визначає найкращий формат для поточного середовища користувача.
- **MP3**: це тип цифрового формату файлу, який використовується для зберігання музики, аудіо або звуку. Це стисла версія звукового запису, що зменшує розмір файлу, тому його легше зберігати та передавати. MP3 має найширшу підтримку в браузерах і MIME-тип `audio/mpeg`.
- **MP4**: MP4 — це тип цифрового формату файлу, який використовується для зберігання відео та аудіо. Він слугує контейнером, що містить і відео (зображення), і звук (музику або мову) в одному файлі. MP4 може мати MIME-тип `audio/mp4` АБО `video/mp4`, залежно від того, чи це відеофайл, чи лише аудіо.
- Інші формати — це `WMV`, який асоціюється із застосунком Windows Media Player, `OGG`, `MKV`, `AVI` та інші.

## Сети в JavaScript

- `Set` — це вбудований варіант для керування колекцією даних.

## Weaksets в JavaScript

- `WeakSet` — це колекція об’єктів, яка дозволяє зберігати об’єкти з слабким посиланням.

## Сети та WeakSet

- На відміну від сету, `WeakSet` не підтримує примітиви, такі як числа або рядки.
- `WeakSet` зберігає лише об’єкти, а референси на ці об’єкти є «слабкими», тобто якщо об’єкт ніде більше не використовується у коді, він автоматично видаляється для звільнення пам’яті.

## Мапи в JavaScript

- `Map` — це вбудований об’єкт, який зберігає пари ключ-значення, подібно до об’єкта.
- Карти відрізняються від стандартних JavaScript-об’єктів тим, що дозволяють використовувати ключі будь-якого типу, включно з об’єктами та функціями.
- `Map` забезпечує кращу продуктивність порівняно зі стандартним об’єктом при частому додаванні та видаленні пар ключ-значення.
- Ви можете створити `Map`, використовуючи конструктор `Map()`.

- Мапами можна маніпулювати за допомогою таких методів:

  - `set()`: додає нову пару ключ-значення до `Map`.
  - `get()`: отримує значення ключа з `Map`.
  - `delete()`: видаляє пару ключ-значення з `Map`.
  - `has()`: перевіряє, чи ключ існує в `Map`.
  - `clear()`: видаляє всі пари ключ-значення з `Map`.

Зверніть увагу, що і карти, і множини мають властивість `size`, яка повертає кількість унікальних елементів у них.

- **Створення**: Це процес створення нових даних. Наприклад, у вебзастосунку це може бути, коли користувач додає новий допис у блог.

- **Оновлення**: Це зміна існуючих даних у базі даних. Приклад — редагування допису в блозі або оновлення інформації у вашому профілі.
- **Видалення**: Це операція, яка видаляє дані з бази даних. Наприклад, коли ви видаляєте допис у блозі або акаунт, ви виконуєте операцію видалення.

- **Метод `sessionStorage.getItem()`**: Цей метод використовується для отримання значення за заданим ключем із `sessionStorage`.

## Робота з cookie

- **Визначення**: Cookie, також відомі як веб-куки або браузерні куки, — це невеликі фрагменти даних, які сервер надсилає веббраузеру користувача. Ці куки зберігаються на пристрої користувача і надсилаються назад на сервер з наступними запитами. Куки є важливими для того, щоб вебзастосунки могли підтримувати стан і запам’ятовувати інформацію про користувача, що особливо важливо, оскільки HTTP — це протокол без стану.
- **Сесійні куки**: Ці куки існують лише під час сесії користувача на сайті. Після закриття браузера або вкладки сесійні куки видаляються. Зазвичай їх використовують для таких завдань, як підтримка користувача в системі під час відвідування.
- **Безпечні куки**: Ці куки надсилаються лише через HTTPS, що гарантує, що їх не зможе перехопити зловмисник під час передачі.
- **HttpOnly куки**: Ці куки не можуть бути доступні або змінені JavaScript у браузері, що робить їх більш захищеними від атак типу XSS.
- **Заголовок Set-Cookie**: Коли ви відвідуєте сайт, сервер може надіслати заголовок Set-Cookie у відповіді HTTP. Цей заголовок наказує браузеру зберегти куку з певною інформацією. Наприклад, він може зберігати унікальний ідентифікатор, який допомагає сайту впізнати вас при наступному відвідуванні.
Ви можете вручну встановити куку в JavaScript за допомогою `document.cookie`:

```js
document.cookie = "organization=freeCodeCamp; expires=Fri, 31 Dec 2021 23:59:59 GMT; path=/";
```

Щоб видалити куку, можна встановити її дату закінчення на час у минулому.

## Cache API

- **Визначення**: Кешування — це процес збереження копій файлів у тимчасовому сховищі, щоб отримувати до них доступ швидше. Cache API використовується для збереження мережевих запитів і відповідей, що робить вебзастосунки більш ефективними і навіть здатними працювати офлайн. Це частина ширшого Service Worker API і є ключовим для створення прогресивних вебзастосунків (PWA), які можуть працювати в умовах ненадійного або повільного інтернет-з’єднання.
Cache API — це механізм зберігання, який зберігає об’єкти Request і Response. Коли робиться запит до сервера, застосунок може зберегти відповідь і пізніше отримати її з кешу замість нового мережевого запиту. Це зменшує час завантаження, економить трафік і покращує загальний досвід користувача.
- **Сховище кешу**: Використовується для збереження пар ключ-значення HTTP-запитів і відповідних відповідей. Це дозволяє ефективно отримувати раніше запитані ресурси, зменшуючи потребу завантажувати їх з мережі при наступних відвідуваннях і покращуючи продуктивність.
- **Cache-Control**: Розробники можуть визначати, як довго зберігати кешований ресурс і чи потрібно його перевіряти або віддавати безпосередньо з кешу.
- **Підтримка офлайн**: Використовуючи Cache API, можна створювати вебзастосунки з пріоритетом офлайн. Наприклад, PWA може віддавати кешовані ресурси, коли користувач не має підключення до мережі.

## Від’ємні шаблони і клієнтське зберігання

- **Надмірне відстеження**: Це практика збору і зберігання надмірної кількості даних користувача в клієнтському сховищі (наприклад, куки, local storage або session storage) без чіткої, усвідомленої згоди або законної потреби. Часто це включає відстеження поведінки, вподобань і взаємодій користувача на різних сайтах або сесіях, що може порушувати приватність користувача.
- **Браузерний фингерпринтинг**: Техніка відстеження і ідентифікації окремих користувачів на основі унікальних характеристик їхнього пристрою і браузера, а не за допомогою куків чи інших традиційних методів відстеження. На відміну від куків, які зберігаються локально на пристрої користувача, фингерпринтинг збирає різноманітну інформацію, щоб створити унікальний «відбиток» сесії браузера користувача.
- **Зберігання паролів у LocalStorage**: Це очевидний від’ємний шаблон, але зберігання будь-яких чутливих даних, як-от паролі, у local storage становить ризик безпеки. Local Storage не шифрується і до нього легко отримати доступ. Тому ніколи не слід зберігати там чутливі дані.

## IndexedDB

- **Визначення**: IndexedDB використовується для зберігання структурованих даних у браузері. Це вбудовано в сучасні веббраузери, що дозволяє вебзастосункам ефективно зберігати і отримувати JavaScript-об’єкти.

## Кеш/Сервісні працівники

- **Визначення**: Service Worker — це скрипт, який працює у фоновому режимі, окремо від вашої вебсторінки. Він може перехоплювати мережеві запити, отримувати доступ до кешу і забезпечувати роботу вебзастосунку офлайн. Це ключовий компонент прогресивних вебзастосунків.

## Основи роботи з класами

- **Визначення**: класи в JavaScript використовуються, щоб визначити шаблони для створення об’єктів та інкапсуляції даних. Класи включають конструктор, який є спеціальним методом, що викликається автоматично, коли створюється новий об’єкт з класу. Він використовується для ініціалізації властивостей об’єкта. Ключове слово `this` тут використовується для посилання на поточний екземпляр класу. Нижче конструктора можуть бути так звані методи. Методи — це функції, визначені всередині класу, які виконують дії або операції над даними чи станом класу. Вони використовуються для визначення поведінки, яку можуть виконувати екземпляри класу.

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);  // Gino
```

:::

Щоб створити новий екземпляр класу, використовуйте ключове слово `new`, за яким слідує ім’я класу.

Ви також можете створювати класи як класові вирази. Це коли клас анонімний і призначений до змінної.

## Успадкування класів

- **Визначення**: успадкування в програмуванні дозволяє визначати класи, які успадковують властивості та методи від батьківських класів. Це сприяє повторному використанню коду та встановлює ієрархічні відносини між класами. Батьківський клас — це клас, який виступає як шаблон для інших класів. Він визначає властивості та методи, які успадковуються іншими класами. Дочірній клас — це клас, який успадковує властивості та методи іншого класу. Дочірні класи також можуть розширювати функціональність своїх батьківських класів, додаючи нові властивості та методи. У JavaScript ми використовуємо ключове слово `extends` для реалізації успадкування. Це ключове слово вказує, що клас є дочірнім класом іншого класу.

Ключове слово `super` використовується, щоб отримати доступ до методів, конструкторів і полів батьківського класу.

:::interactive_editor

```js
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  constructor(brand, year, numDoors) {
    super(brand, year);
    this.numDoors = numDoors;
  }
}

const myCar = new Car("freeCodeCamp Motors", 2019, 4);
console.log(myCar.brand);  // freeCodeCamp Motors
console.log(myCar.year);  // 2019
console.log(myCar.numDoors);  // 4
```

:::

## Робота зі статичними методами та статичними властивостями

- **Статичні методи**: ці методи часто використовуються для утилітних функцій, які не потребують доступу до конкретного стану об’єкта. Вони визначаються всередині класів для інкапсуляції пов’язаної функціональності.

Використовуйте ключове слово `static` для визначення статичного методу і викликайте його безпосередньо на класі.

Статичні методи також корисні для реалізації «фабричних» методів. Фабричний метод — це метод, визначений додатково до конструктора для створення об’єктів на основі певних критеріїв.

- **Статичні властивості**: ці властивості використовуються для визначення значень або атрибутів, які пов’язані з самим класом, а не з його екземплярами. Статичні властивості спільні для всіх екземплярів класу і до них можна отримати доступ без створення екземпляра класу.

Наприклад, `static numberOfWheels = 4;` визначає статичну властивість всередині класу.

- Рекурсія — це концепція програмування, яка дозволяє викликати функцію повторно, доки не буде досягнуто базового випадку.

Ось приклад рекурсивної функції, яка обчислює факторіал числа:

```js
function findFactorial(n) {
  if (n === 0) {
    return 1;
  }
  return n * findFactorial(n - 1);
}
```

У наведеному прикладі функція `findFactorial` викликається рекурсивно, доки `n` не досягне `0`. Коли `n` дорівнює `0`, досягається базовий випадок, і функція повертає `1`. Потім функція повертає добуток `n` та результату рекурсивного виклику `findFactorial(n - 1)`.

- Рекурсія дозволяє опрацьовувати структури з невідомою глибиною, наприклад, глибоко вкладені об’єкти/масиви або дерево файлів.
- Для відстеження викликів функцій у рекурсивній функції використовується стек викликів. Кожного разу, коли функція викликається, вона додається до стека викликів. Коли досягається базовий випадок, виклики функцій видаляються зі стека.
- Ви повинні ретельно визначити базовий випадок, оскільки безкінечний виклик може призвести до збою коду. Це відбувається тому, що рекурсія накопичує все більше викликів функцій, доки система не вичерпає пам’ять.
- Рекурсія застосовується для розв’язання математичних задач, таких як факторіал і послідовність Фібоначчі, обходу дерев і графів, генерації перестановок і комбінацій та багато іншого.

## Алгоритми та нотація Big O

- **Алгоритми**: Набір однозначних інструкцій для розв’язання задачі або виконання завдання. Алгоритми мають завершуватися за скінченну кількість кроків, і кожен крок має бути точним і однозначним.

- **Нотація Big O**: Описує найгірший випадок продуктивності або швидкість зростання алгоритму залежно від розміру вхідних даних. Вона фокусується на тому, як зростає використання ресурсів із збільшенням розміру вхідних даних, ігноруючи константні множники та члени нижчого порядку.

### Загальні часові складності

- **O(1) — константний час**: Алгоритм виконується за однаковий час незалежно від розміру вхідних даних.

- **O(log n) — логарифмічний час**: Час зростає повільно зі збільшенням вхідних даних. Зустрічається в алгоритмах, які багаторазово зменшують розмір задачі (наприклад, бінарний пошук).

- **O(n) — лінійний час**: Час виконання пропорційний розміру вхідних даних.

- **O(n log n) — лог-лінійний час**: Типова складність ефективних алгоритмів сортування, таких як merge sort і quick sort.

- **O(n²) — квадратичний час**: Час виконання зростає квадратично. Часто зустрічається у вкладених циклах.

### Просторова складність

- **O(1) — константний простір**: Алгоритм використовує однакову кількість пам’яті незалежно від розміру вхідних даних.
- **O(n) — лінійний простір**: Використання пам’яті зростає пропорційно розміру вхідних даних.
- **O(n²) — квадратичний простір**: Використання пам’яті зростає квадратично з розміром вхідних даних.

## Техніки розв’язання задач

- **Розуміння задачі**: Прочитайте умову задачі кілька разів. Визначте вхідні дані, очікуваний результат і як перетворити вхідні дані у вихідні.

- **Псевдокод**: Опис логіки алгоритму на високому рівні, незалежний від мови програмування. Використовує загальновживану мову, змішану з конструкціями програмування, такими як `IF`, `ELSE`, `FOR`, `WHILE`.

- **Крайні випадки**: Конкретні, дійсні вхідні дані, які трапляються на межах того, що алгоритм повинен обробляти. Завжди враховуйте і тестуйте крайні випадки.

## Масиви

- **Статичні масиви**: Мають фіксований розмір, визначений під час ініціалізації. Елементи зберігаються у суміжних ділянках пам’яті. Розмір не можна змінити під час виконання програми.

- **Динамічні масиви**: Можуть автоматично збільшуватися або зменшуватися під час виконання програми. Зміна розміру відбувається через автоматичне копіювання у більші масиви за потреби.

### Реалізація динамічних масивів у JavaScript

Масиви JavaScript є динамічними масивами. Ви можете отримувати доступ і оновлювати елементи за індексом, додавати елементи за допомогою `push()` і видаляти елементи за допомогою `pop()` або `splice()`.

### Часові складності для динамічних масивів

- **Доступ**: O(1)
- **Вставка в кінець**: O(1) у середньому, O(n) при зміні розміру
- **Вставка посередині**: O(n)
- **Видалення**: O(n) посередині, O(1) в кінці

## Стек

- **Стек**: Структура даних типу LIFO (останній зайшов — перший вийшов). Елементи додаються і видаляються лише з вершини.

- **Операція push**: Додавання елемента на вершину стеку. Часова складність: O(1).

- **Операція pop**: Видалення елемента з вершини стеку. Часова складність: O(1).

Масив JavaScript може слугувати стеком, використовуючи `push()` для додавання елементів і `pop()` для їх видалення.

## Черги

- **Черги**: Структура даних типу FIFO (перший зайшов — перший вийшов). Елементи додаються в кінець і видаляються з початку.

- **Операція enqueue**: Додавання елемента в кінець черги. Часова складність: O(1).

- **Операція dequeue**: Видалення елемента з початку черги. Часова складність: O(1).

Масив може демонструвати чергу, використовуючи `push()` для додавання в кінець і `shift()` для вилучення з початку. Однак `shift()` має складність O(n), оскільки решта елементів мусить зміститися.

## Зв’язані списки

- **Зв’язані списки**: Лінійна структура даних, де кожен вузол містить дані і посилання на наступний вузол. Вузли з’єднані як ланцюг.

### Однозв’язні списки

- **Структура**: Кожен вузол має дані і один референс на наступний вузол.
- **Перебір**: Можна рухатися лише вперед від голови до хвоста.
- **Головний вузол**: Перший вузол у списку, зазвичай єдиний, до якого є прямий доступ.
- **Хвостовий вузол**: Останній вузол у списку, вказує на `null`.

### Операції та часові складності

- **Вставка на початок**: O(1)
- **Вставка в кінець**: O(n) — потрібно пройти до кінця
- **Вставка посередині**: O(n) — потрібно пройти до позиції
- **Видалення з початку**: O(1)
- **Видалення з кінця**: O(n) — потрібно знайти попередній вузол
- **Видалення посередині**: O(n) — потрібно знайти вузол

### Двозв’язні списки

- **Структура**: Кожен вузол має дані і два посилання: на наступний і попередній вузол.
- **Перебір**: Можна рухатися в обох напрямках.
- **Пам’ять**: Потребує більше пам’яті, ніж однозв’язні списки через додаткове посилання.

## Коли використовувати кожну структуру даних

- **Масиви (динамічні масиви)**: Коли потрібен впорядкований, індексований доступ і розмір невідомий заздалегідь
- **Стек**: Для операцій LIFO (функціонал скасування, оцінка виразів, повернення назад)
- **Черги**: Для операцій FIFO (планування завдань, пошук у ширину)
- **Зв’язані списки**: Коли часто потрібно вставляти/видаляти на початку, розмір невідомий, випадковий доступ не потрібен

## Алгоритми пошуку

Алгоритми пошуку дозволяють знайти ціль у певному списку елементів.

У комп’ютерних науках існують два алгоритми пошуку, які ви повинні знати. Це алгоритми **лінійного пошуку** та **бінарного пошуку**. Важливо розуміти відмінності між цими двома алгоритмами та коли слід використовувати кожен із них.

### Лінійний пошук

- Лінійний пошук ітерує масив елементів, перевіряючи кожен елемент від початку, доки не знайде цільовий елемент.
- Якщо цільовий елемент знайдено, повертається індекс, на якому він розташований у масиві.
- Якщо ціль не знайдена, повертається `-1`, що означає **недійсний індекс** у JavaScript.
- Оскільки лінійний пошук перевіряє кожен елемент, доки не знайде ціль, він не є ефективним для великого масиву елементів.
- Часова складність лінійного пошуку — `O(n)`, бо час пошуку зростає лінійно зі збільшенням розміру масиву.
- Просторова складність лінійного пошуку — `O(1)`, бо він не потребує додаткового простору для пошуку в масиві.

### Бінарний пошук

- Бінарний пошук працює, ділячи масив елементів навпіл і перевіряючи, чи знаходиться цільове значення посередині масиву.
- Умова для роботи бінарного пошуку — елементи масиву мають бути відсортовані, або за зростанням, або за спаданням.
- Бінарний пошук є більш ефективним алгоритмом для пошуку в великому масиві, бо він ділить масив навпіл і ігнорує ту половину, де ціль не знайдена.
- Якщо цільовий елемент знайдено посередині масиву, повертається індекс цільового елемента.
- Якщо елемент не знайдено, алгоритм перевіряє, чи знаходиться ціль у лівій чи правій половині масиву.
- Він продовжує ділити залишкові частини масиву навпіл, доки не знайде цільовий елемент.
- Якщо цільовий елемент не знайдено в масиві, повертається `-1`.
- Часова складність бінарного пошуку — `O(log n)`, бо час пошуку зростає логарифмічно зі збільшенням розміру масиву.
- Просторова складність бінарного пошуку — `O(1)`, бо він не потребує додаткового простору для пошуку в масиві.

### Відмінності лінійного пошуку від бінарного

- Бінарний пошук краще підходить для великого масиву елементів у порівнянні з лінійним пошуком.
- Часова складність лінійного пошуку — `O(n)`, бо час пошуку зростає лінійно зі збільшенням розміру масиву.
- Часова складність бінарного пошуку — `O(log n)`, бо час пошуку зростає логарифмічно зі збільшенням розміру масиву.

## Алгоритми сортування та техніка розділяй і володарюй

У комп’ютерних науках техніка розділяй і володарюй використовується для розбиття задачі на менші підзадачі, щоб їх було легше розв’язати. Рекурсія часто застосовується у цій техніці, а розділяй і володарюй — це потужна стратегія, яка використовується для реалізації багатьох ефективних алгоритмів сортування, таких як сортування злиттям.

### Сортування злиттям

- Сортування злиттям — це алгоритм сортування, який слідує підходу розділяй і володарюй.
- Він працює, рекурсивно ділячи масив на менші підмасиви, доки кожен підмасив не містить лише один елемент.
- Потім він повторно об’єднує підмасиви у відсортованому порядку.
- Часова складність сортування злиттям — `O(n log n)`, бо масив безперервно ділиться навпіл `(log n)` і потім об’єднується `(O(n))`.
- Просторова складність сортування злиттям — `O(n)`, бо це не алгоритм сортування на місці.

## Огляд графів

Граф — це множина вузлів (вершин), з’єднаних ребрами (зв’язками). Кожен вузол може бути з’єднаний з кількома іншими вузлами, утворюючи мережу. Різновиди графів включають:

- **Орієнтований**: ребра мають напрямок (від одного вузла до іншого), часто зображуються прямими лініями зі стрілками.
- **Неорієнтований**: ребра не мають напрямку, зображуються простими лініями.
- **Вузол з міткою**: кожен вузол має мітку або ідентифікатор.
- **Циклічний**: містить цикли (шлях, що починається і закінчується в одному й тому ж вузлі).
- **Орієнтований ациклічний граф (DAG)**: орієнтований граф без циклів.
- **Ребро з міткою**: кожне ребро має мітку, зазвичай розташовану поруч із відповідним ребром.
- **Зважений**: ребра мають ваги (значення), які можна використовувати для арифметичних дій.
- **Роз’єднаний**: містить дві або більше груп вузлів (компонентів), які не з’єднані ребрами. Два вузли можуть не мати прямого ребра, але між ними може існувати шлях.

Графи використовують у різних застосунках, таких як карти, мережі, системи рекомендацій і розв’язання залежностей.

## Обхід графів

Це процес відвідування всіх вузлів графа. Основні алгоритми:

- **Пошук у ширину (BFS)**: відвідує всі сусідні вузли перед переходом до наступного рівня графа.
  - **Черга**: використовує чергу (FIFO). Початковий вузол позначається як відвіданий і додається до черги. Поки черга не порожня, поточний вузол вилучається, а кожен його невідвіданий сусід позначається як відвіданий і додається до черги.
  - **Найкоротший шлях**: знаходить найкоротший шлях у незважених графах.
  - **Пам’ять**: потребує зберігання черги в пам’яті, тому вимоги до простору можуть бути значними, особливо для графів із великою кількістю вузлів на одному рівні.
  - **З’єднані компоненти**: також можна використовувати для пошуку з’єднаних компонентів графа, починаючи новий пошук із кожного вузла, який ще не відвідували.
  - **Пошук у просторі станів**: використовує чергу для відстеження різних станів під час побудови комбінацій круглих дужок. Кожен стан представлений масивом, що містить поточний рядок, кількість використаних відкриваючих дужок і кількість використаних закриваючих дужок. Відкриваючу дужку можна додати лише якщо кількість використаних відкриваючих дужок менша за кількість пар. Закриваючу дужку можна додати лише якщо вона підтримує баланс, тобто кількість відкриваючих дужок має бути більшою за кількість закриваючих.

- **Пошук у глибину (DFS)**: проходить кожну гілку якомога глибше, перш ніж повернутися назад.
  - **Стек**: використовує стек (LIFO) або рекурсію. Початковий вузол позначається як відвіданий і додається до стеку. Поки стек не порожній, поточний вузол вилучається, а його невідвідані сусіди позначаються як відвідані і додаються до стеку.
  - **Пам’ять**: потребує зберігання стеку (або стеку викликів функцій при рекурсії) в пам’яті, тому вимоги до простору можуть зростати у графах із дуже довгими шляхами.
  - **Використання**: корисний для виявлення циклів, пошуку шляхів і знаходження з’єднаних компонентів.
  - **Обмеження**: не завжди гарантує знаходження найкоротшого шляху між двома вузлами в незваженому графі.

## Представлення графів

Графи можна представити двома основними способами:

- **Список суміжності**: кожен вузол має список своїх сусідів.
  - **Реалізації**: у вигляді масиву, де кожен індекс представляє вузол, а масив за цим індексом містить його сусідів. У вигляді об’єкта (або `Map`), де кожен ключ представляє вузол, а значення за цим ключем (масив) містить його сусідів.
  - **Простір**: ефективний за простором для розріджених графів, з просторовою складністю `O(V + E)`, де `V` — кількість вершин (вузлів), а `E` — кількість ребер.
  - **Сусіди**: легко ітерувати над сусідами, оскільки ця операція вимагає лише доступу до списку, пов’язаного з вузлом.
  - **Пошук ребра**: менш ефективний, ніж матриці суміжності, для визначення наявності ребра між двома вузлами. Зазвичай це займає `O(deg(v))` часу, де `deg(v)` — кількість сусідів вузла, який перевіряють, а в найгіршому випадку може бути `O(V)`.
  - **Найкраще для**: зазвичай переважний вибір для реальних сценаріїв, де розріджені графи зустрічаються частіше.

- **Матриця суміжності**: двовимірний масив, де рядки і стовпці представляють вузли.
  - **Значення**: якщо граф незважений, значення `1` означає наявність ребра між вузлами, а `0` — його відсутність. Якщо граф зважений, значення представляє вагу ребра, що з’єднує вузли.
  - **Петлі**: значення на діагоналі показують, чи має кожен вузол петлю — ребро, що з’єднує вузол із самим собою.
  - **Простір**: вимагає багато пам’яті для великих графів, з квадратичною складністю `O(V²)`, де `V` — кількість вузлів у графі.
  - **Пошук ребра**: швидкий для перевірки наявності ребра між двома вузлами, оскільки це займає сталий час `O(1)`.
  - **Сусіди**: неефективний для пошуку сусідів вузла, бо потрібно ітерувати весь рядок або стовпець. У найгіршому випадку це займає `O(V)` часу.
  - **Найкраще для**: корисний для густих графів із багатьма ребрами. Неефективний для розріджених графів, які мають мало ребер.

## Алгоритм найкоротшого шляху

- **Алгоритм найкоротшого шляху**: обчислює найкоротший шлях між вузлами у зваженому графі та повертає як відстані, так і пройдені шляхи.
  - **Матриця суміжності**: кожне значення представляє вагу (відстань) ребра між двома вузлами.
  - **Відсутні ребра**: значення `INF` (`Infinity`) означає відсутність прямого ребра.
  - **Відстані**: масив, що відстежує найкоротшу відому відстань від початкового вузла до кожного іншого вузла. Спочатку вважається, що всі вузли знаходяться на нескінченній відстані, а відстань від початкового вузла до себе завжди `0`.
  - **Шляхи**: список, де кожен запис — це масив індексів вузлів, що представляє маршрут до кожного вузла.
  - **Відвідані**: масив, що відстежує, які вузли вже оброблені, щоб не відвідувати їх повторно.
  - **Найближчий невідвіданий вузол**: головний цикл виконується по одному разу для кожного вузла в графі, кожного разу вибираючи найближчий невідвіданий вузол.
  - **Розслаблення ребра**: для кожного сусіда з наявним ребром, який ще не відвідували, перевіряють, чи можна дістатися до нього ефективніше через поточний вузол. Якщо нова відстань краща за збережену, оновлюють відстань і шлях.
  - **Недосяжні вузли**: коли не знаходиться жодного дійсного вузла, усі решта вузлів недосяжні, тому цикл завершується раніше.
  - **Опційна ціль**: параметр `targetNode` є необов’язковим. Якщо його не вказано, функція обчислює найкоротші шляхи від `startNode` до всіх інших вузлів графа.

## Дерева

Дерево — це особливий тип графа, який є ациклічним і зв’язаним. Основні властивості:

- **Ациклічний**: дерево не має петель або циклів (шляхів, де початковий і кінцевий вузли однакові).
- **З’єднане**: кожен вузол можна досягти з будь-якого іншого вузла.

### Терміни, пов’язані з деревом

- **Кореневий вузол**: найвищий вузол дерева. Це єдиний вузол у дереві без батьківського вузла.
- **Батьківський вузол**: вузол, який безпосередньо з’єднаний з іншими вузлами нижче.
- **Дочірній вузол**: вузол, який безпосередньо з’єднаний з вузлом вище.
- **Листок**: вузол, який не має дочірніх вузлів.
- **Глибина**: довжина шляху від кореня до цього вузла.
- **Висота**: довжина шляху від цього вузла до листка. Висота дерева — це висота його кореневого вузла.
- **Ступінь**: кількість дочірніх вузлів у кожного вузла.
- **Піддерево**: частина дерева, яка сама є деревом.
- **Збалансоване дерево**: дерево, у якому висоти лівого і правого піддерев будь-якого вузла дуже схожі, щоб операції залишалися ефективними.

### Загальні типи дерев

Найпоширеніші типи дерев:

- **Двійкові дерева**: кожен вузол має не більше двох дочірніх — лівого і правого.

- **Двійкові дерева пошуку (BST)**: двійкове дерево, у якому для кожного вузла всі значення в його лівому піддереві менші за значення вузла, а всі значення в правому піддереві більші. Ліве і праве піддерево також мають бути двійковими деревами пошуку.

- **Самозбалансовані дерева**: дерева, які містять додаткову внутрішню логіку для повторного балансування дерева, коли вставки або видалення створюють стан дисбалансу. Загальні приклади — AVL-дерева, червоно-чорні дерева та B-дерева.

- **AVL-дерева**: тип самозбалансованого двійкового дерева пошуку, у якому висоти лівого і правого піддерев будь-якого вузла відрізняються не більше ніж на один.

- **Червоно-чорні дерева**: тип самозбалансованого двійкового дерева пошуку, у якому кожен вузол має колір — червоний або чорний.

- **B-дерева**: тип самозбалансованого дерева, у якому кожен вузол може мати кілька ключів і більше двох дочірніх вузлів.

## Префіксні дерева (Trie)

- **Префіксні дерева (tries)**: також відомі як префіксні дерева, використовуються для зберігання множин рядків, де кожен вузол представляє символ.
- **Кореневий вузол**: кореневий вузол не представляє жодного конкретного символу, тому його можна вважати порожнім рядком.
- **Префікси**: під час проходження префіксного дерева від кореня шлях до вузла визначає конкретний префікс.
- **Маркування кінця слова**: вузли, що представляють повні слова, мають маркери кінця слова.
- **Спільні префікси**: коли кілька рядків мають однаковий префікс, їхні шляхи перекриваються, тому префікс зберігається лише один раз. Це робить префіксні дерева ефективними для автозаповнення та перевірки орфографії.
- **Вставка**: вимагає створення нових вузлів лише для символів, яких ще немає в префіксному дереві.
- **Часова складність**: операції пошуку та вставки займають `O(L)` часу, де `L` — довжина рядка.
- **Пам’ять**: префіксні дерева можуть бути неефективними, якщо множина рядків містить багато унікальних символів, оскільки це вимагає зберігання багатьох унікальних символів як окремих вузлів.

## Пріоритетні черги

- **Пріоритетна черга**: абстрактний тип даних, у якому кожен елемент має пріоритет.
- **Черги і стеки**: черги і стеки враховують лише порядок вставки, тоді як пріоритетні черги враховують пріоритет елементів. Стандартні черги працюють за принципом FIFO (перший прийшов — перший пішов), а стеки — за принципом LIFO (останній прийшов — перший пішов).
- **Порядок видалення**: зазвичай елемент з найвищим пріоритетом видаляється першим, але деякі реалізації можуть також видаляти елемент з найнижчим пріоритетом першим.
- **Рівні пріоритети**: якщо потрібно, щоб елементи з однаковим пріоритетом видалялися в порядку їх вставки, можна додати унікальний лічильник для розв’язання рівності.
- **Застосування**: пошук найкоротшого шляху між двома локаціями, планування завдань в операційних системах, моделювання трафіку, стиснення даних і керування мережами.

## Купи

Купа — це спеціалізована дерево-подібна структура даних із дуже специфічною властивістю, яка називається властивістю купи.

Властивість купи визначає відношення між батьківськими і дочірніми вузлами. Існують два типи куп:

- **Максимальна купа (Max-Heap)**: значення кожного батьківського вузла більше або дорівнює значенням його дочірніх вузлів, а найбільший елемент знаходиться в корені.

- **Мінімальна купа (Min-Heap)**: значення кожного батьківського вузла менше або дорівнює значенням його дочірніх вузлів, а найменший елемент знаходиться в корені.

JavaScript не має вбудованого модуля для куп, але ви можете реалізувати мін-купу, використовуючи масив.

- **Зберігання у масиві**: купи зазвичай реалізують як масиви для ефективного доступу до батьківських і дочірніх вузлів. Якщо купа підтримує структуру повного двійкового дерева, реалізація масиву вимагає лише простих математичних операцій на основі індексів для знаходження розташування елементів.
- **Індекси**: для вузла з індексом `i` батьківський вузол знаходиться за індексом `Math.floor((i - 1) / 2)`, лівий дочірній — за індексом `2 * i + 1`, а правий дочірній — за індексом `2 * i + 2`.
- **Перегляд (Peek)**: отримання мінімального або максимального значення (залежно від типу купи) без видалення.
- **Додавання (Push)**: додає елемент на правильне місце, щоб зберегти властивість купи. Новий елемент додається в кінець масиву, а потім піднімається вгору, міняючись місцями з батьком, поки властивість купи не буде відновлена (підйом).
- **Видалення (Pop)**: видаляє елемент з найвищим пріоритетом (у цьому випадку найменше значення). Останній елемент масиву заміщує корінь, а потім опускається вниз, міняючись місцями з меншим дочірнім вузлом, поки властивість купи не буде відновлена (спуск).
- **PushPop**: поєднує обидві операції в один виклик. Це ефективніше, ніж викликати їх окремо, особливо для великих куп, оскільки виконується лише одна операція перестановки.
- **Heapify**: перетворює існуючий масив у купу.
- **Функція порівняння**: масиви в JavaScript не порівнюються автоматично поелементно для впорядкування, тому ви передаєте функцію порівняння в купу, яка спочатку порівнює пріоритети, наприклад `new MinHeap((a, b) => a[0] - b[0])` для елементів, збережених як `[priority, element]`. Менші значення означають вищий пріоритет.
- **Стабільне розв’язання рівності**: включайте зростаючий лічильник вставки як другий елемент кожного елемента, наприклад `[priority, counter, element]`. Спочатку порівнюють пріоритети, а потім лічильники, якщо пріоритети рівні: `new MinHeap((a, b) => (a[0] - b[0]) || (a[1] - b[1]))`.
- **Часова складність**: вставка і вилучення мінімального або максимального значення — `O(log n)`, перегляд — `O(1)`, heapify — `O(n)`, пошук або видалення довільного елемента — `O(n)`.
- **Просторова складність**: `O(n)`, де `n` — кількість елементів у купі.

## Вступ до динамічного програмування

- **Визначення**: Динамічне програмування — це алгоритмічна техніка, яка розв’язує складні задачі, розбиваючи їх на простіші підзадачі і зберігаючи результати, щоб уникнути повторних обчислень.
- **Перекривні підзадачі**: Одні й ті ж менші задачі з’являються кілька разів при розв’язанні більшої задачі. Замість повторного обчислення ми зберігаємо їхні рішення.
- **Оптимальна підструктура**: Оптимальне рішення задачі містить оптимальні рішення її підзадач. Це означає, що можна побудувати найкраще рішення, комбінуючи найкращі рішення менших частин.

## Рішення динамічного програмування

- **Мемоізація (підхід зверху вниз)**: Мемоізація зберігає результати дорогих викликів функцій і повертає кешований результат, коли ті самі вхідні дані з’являються знову.

- **Табуляція (підхід знизу вгору)**: Табуляція будує рішення знизу вгору, заповнюючи таблицю рішеннями підзадач.

## Застосунки динамічного програмування у реальному світі

- **Оптимізація маршруту**: GPS-системи використовують алгоритми динамічного програмування, щоб знайти найкоротші шляхи між локаціями.
- **Обробка тексту**: Перевірка орфографії та функції автозаповнення часто покладаються на динамічне програмування для обчислення відстаней редагування між словами.
- **Фінансове моделювання**: Інвестиційні стратегії та оптимізація портфоліо часто застосовують техніки динамічного програмування.
- **Розподіл ресурсів**: Задача рюкзака та її варіанти зустрічаються у плануванні, бюджетуванні та управлінні ресурсами.

## Коли використовувати динамічне програмування

Варто розглянути використання динамічного програмування у таких випадках:

- Проблему можна розбити на перекривні підзадачі.
- Проблема має оптимальну підструктуру.
- Наївне рекурсивне рішення передбачає повторні обчислення.
- Потрібно оптимізувати часову складність за рахунок просторової складності.

## Чисті та нечисті функції

- Чиста функція — це така, що завжди повертає однакові вихідні дані для однакових вхідних даних і не має побічних ефектів. Її вихідні дані залежать лише від вхідних даних, і вона не змінює жоден зовнішній стан.
- Нечисті функції мають побічні ефекти, які є змінами стану програми, що спостерігаються поза межами функції.

## Функціональне програмування

- Функціональне програмування — це підхід до розробки програмного забезпечення, який наголошує на використанні функцій для розв’язання задач, зосереджуючись на тому, що потрібно зробити, а не як це зробити.
- Функціональне програмування заохочує використання технік, які допомагають уникати побічних ефектів, наприклад, використання незмінних структур даних і функцій вищого порядку.
- При правильному застосуванні принципи функціонального програмування ведуть до чистішого та легшого для підтримки коду.

## Каррінг

- Каррінг — це техніка функціонального програмування, яка перетворює функцію з кількома аргументами на послідовність функцій, кожна з яких приймає один аргумент.

Наприклад, каррінг змінює виклик `average(a, b, c)` на послідовні виклики `curriedAverage(a)(b)(c)`.

- Каррінг може бути особливо потужним при роботі з функціями, які приймають багато аргументів.
- Каррінг робить код гнучкішим і легшим для повторного використання.
- Ви можете використовувати стрілкові функції, щоб створювати каровані функції більш лаконічно:

```js
const curriedAverage = a => b => c => (a + b + c) / 3;
```

- Хоча каррінг може призвести до гнучкішого та повторно використовуваного коду, він також може ускладнити читання коду, якщо його надмірно використовувати.

- **Синхронний JavaScript** виконується послідовно і чекає на завершення попередньої операції перед переходом до наступної.
- **Асинхронний JavaScript** дозволяє виконувати кілька операцій у фоновому режимі, не блокуючи головний потік.
- **Потік** — це послідовність інструкцій, яку можна виконувати незалежно від основного потоку програми.
- **Функції зворотного виклику** — це функції, які передаються як аргументи іншим функціям і виконуються після завершення операції або в результаті події.

## JavaScript-рушій та середовище виконання JavaScript

- **JavaScript-рушій** — це програма, яка виконує JavaScript-код у веббраузері. Він працює як конвертер, який бере ваш код, перетворює його на інструкції, зрозумілі комп’ютеру, і виконує їх.
- V8 — приклад JavaScript-рушія, розробленого Google.
- **Середовище виконання JavaScript** — це середовище, у якому виконується JavaScript-код. Воно включає JavaScript-рушій, який обробляє та виконує код, а також додаткові функції, як-от веббраузер або Node.js.

## Fetch API

- Fetch API дозволяє вебзастосункам робити мережеві запити, зазвичай для отримання або відправлення даних на сервер. Він надає метод `fetch()`, який можна використовувати для виконання цих запитів.
- Ви можете отримувати текст, зображення, аудіо, JSON та інші типи даних за допомогою Fetch API.

## HTTP-методи для Fetch API

Fetch API підтримує різні HTTP-методи для взаємодії з сервером. Найпоширеніші методи:

- **GET**: використовується для отримання даних із сервера. За замовчуванням Fetch API використовує метод `GET` для отримання даних.

Щоб використовувати отримані дані, їх потрібно конвертувати у формат JSON за допомогою методу `.json()`:

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
```

У цьому коді `fetch()` повертає проміс, а обробник `.then()` конвертує розв’язану відповідь у формат JSON.

- **POST**: використовується для відправлення даних на сервер. Метод `POST` використовується для створення нових ресурсів на сервері.

```js
fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Doe',
    email: 'john@example.com'
  })
})
```

У цьому прикладі ми надсилаємо `POST`-запит для створення нового користувача. Ми вказали метод як `POST`, встановили відповідні заголовки та додали тіло з даними, які хочемо надіслати. Тіло має бути рядком, тому ми використовуємо `JSON.stringify()` для перетворення нашого об’єкта на JSON рядок.

- **PUT**: використовується для оновлення даних на сервері. Метод `PUT` використовується для оновлення існуючих ресурсів на сервері.

Для оновлення вкажіть `method: 'PUT'` і включіть оновлені дані в тіло запиту. URL ідентифікує ресурс для оновлення.

- **DELETE**: використовується для видалення даних на сервері. Метод `DELETE` використовується для видалення ресурсів на сервері.

Встановіть `method: 'DELETE'` і використовуйте URL, який ідентифікує ресурс для видалення.

## Проміс і ланцюжок промісів

- **Проміси** — це об’єкти, які представляють майбутнє завершення або невдачу асинхронної операції та її результативне значення. Значення промісу відоме лише після завершення асинхронної операції.
- Ось приклад створення простого промісу:

```js
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```

- Метод `.then()` використовується в промісі для вказівки дій після його виконання, а `.catch()` — для обробки помилок.

- **Ланцюжок промісів**: Одна з потужних можливостей промісів — це можливість ланцюжка кількох асинхронних операцій. Кожен `.then()` може повертати новий проміс, що дозволяє виконувати послідовність асинхронних операцій одну за одною.

Метод `catch` обробляє будь-які помилки, що виникають під час процесу. Це означає, що вам не потрібно додавати обробку помилок до кожного кроку, що значно спрощує код.

## Використання `async/await` для обробки промісів

`async`/`await` робить написання та читання асинхронного коду простішим, він побудований на основі промісів.

- **async**: Ключове слово `async` використовується для визначення асинхронної функції. `async` функція повертає проміс, який розв’язується зі значенням, поверненим цією `async` функцією.
- **await**: Ключове слово `await` використовується всередині `async` функції, щоб призупинити виконання функції до моменту розв’язання промісу. Його можна використовувати лише всередині `async` функції.

- Одна з найбільших переваг `async/await` — це обробка помилок за допомогою блоків `try/catch`. Ось приклад:

```js
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

fetchData();
```

У наведеному вище прикладі блок `try` містить код, який може викликати помилку, а блок `catch` обробляє помилку, якщо вона виникає. Це робить обробку помилок простою та зрозумілою.

## Атрибут `async`

- Атрибут `async` повідомляє браузеру скачати файл скрипта асинхронно, продовжуючи парсинг HTML-документа.
- Після того, як скрипт завантажено, парсинг HTML призупиняється, скрипт виконується, а потім парсинг HTML відновлюється.
- Використовуйте `async` для незалежних скриптів, де порядок виконання не має значення.

## Атрибут `defer`

- Атрибут `defer` також завантажує скрипт асинхронно, але відкладає виконання скрипта до повного парсингу HTML-документа.
- Скрипти `defer` зберігають порядок виконання відповідно до їх розташування в HTML-документі.

- Важливо зазначити, що обидва атрибути `async` та `defer` ігноруються для рядкових скриптів і працюють лише для зовнішніх скриптових файлів.

- Коли присутні обидва атрибути `async` та `defer`, то перевага надається атрибуту `async`.

## Geolocation API

- Geolocation API дозволяє зробити запит про місцезнаходження користувача.

- Наведений нижче приклад демонструє метод API `getCurrentPosition()`, який використовується для отримання поточного місцезнаходження користувача.

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

У цьому коді ми викликаємо `getCurrentPosition` і передаємо йому функцію, яка буде викликана, коли позиція буде успішно отримана.

Об’єкт `position` містить різноманітну інформацію, але тут ми вибрали лише `latitude` та `longitude`.

Якщо виникає проблема з отриманням `position`, помилка буде виведена в консоль.

- Важливо поважати приватність користувача і запитувати його місцезнаходження лише тоді, коли це необхідно.
