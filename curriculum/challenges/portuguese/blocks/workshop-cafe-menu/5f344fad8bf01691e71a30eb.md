# --description--

Até agora, você teve controle limitado sobre a apresentação e aparência do seu conteúdo. Para mudar isso, você vai usar CSS.

Uma forma de adicionar CSS a uma página é com o elemento `style`, geralmente colocado dentro da tag `head`. Qualquer regra CSS dentro da tag `style` se aplica a toda a página. Aqui está um exemplo:

```html
<style>
  p {
    color: green;
  }
</style>
```

Adicione um elemento `style` dentro do elemento `head`.

# --hints--

Seu código deve ter um elemento `style`.

```js
assert.exists(document.querySelector('style:not(.fcc-hide-header)'));
```

Seu código deve ter uma tag de fechamento `</style>`.

```js
assert.match(code, /<\/style\s*>/i);
```

O elemento `style` deve estar dentro do elemento `head`.

```js
assert.exists(document.querySelector('head > style:not(.fcc-hide-header)'));
```
