# --description--

A volte un numero va bene per i tuoi calcoli ma sembra un po' incompleto quando lo stampi. Se stai mostrando un prezzo, per esempio, `12.50` può sembrare più naturale di `12.5`.

Una f-string ti permette di controllare come appare un numero quando viene mostrato, senza cambiare il valore originale, così puoi continuare a usarlo nei calcoli.

## Come funzionano le specifiche di formato

L'espressione `f"{value:.2f}"` mostra `value` con esattamente due cifre dopo il punto decimale.

Dentro le parentesi graffe, ogni carattere ha un ruolo specifico:

- I due punti `:` introducono la specifica di formato
- `.2` seleziona due cifre decimali
- `f` seleziona la presentazione a punto fisso, che mostra il numero in notazione decimale.

Questo significa che `print(f"{12.5:.2f}")` produce `12.50`, lasciando però il valore iniziale invariato:

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

L'output mostra `12.50` perché la specifica di formato `.2f` mostra sempre due cifre decimali, quindi Python aggiunge uno zero finale. Il valore memorizzato in `value` è ancora `12.5`.


D'altra parte, formattare un valore come `12.3456` con `.2f` produce `12.35`, perché il numero deve essere arrotondato per la visualizzazione:

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## Formattare con una f-string produce una stringa

Una f-string produce una stringa:

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

Questo significa che puoi salvare la stringa risultante separatamente e continuare a usare il numero originale nei calcoli.

## Come `round()` differisce dalla formattazione con f-string

Un'espressione come `round(value, 2)` ti dà un risultato numerico che puoi usare in ulteriori calcoli.

Stampare quel risultato usa la visualizzazione numerica usuale di Python, quindi gli zeri finali non sono garantiti:

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## La formattazione non cambia il valore sottostante

Come hai visto prima, alcuni numeri decimali come `0.1` e `0.2` possono essere approssimati solo come float. Perciò, la loro somma può sembrare un po' sorprendente se stampata direttamente:

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

Come vedi, la f-string arrotonda la somma per la visualizzazione. Qualsiasi calcolo che usa `total` continua a usare lo stesso valore in virgola mobile.
