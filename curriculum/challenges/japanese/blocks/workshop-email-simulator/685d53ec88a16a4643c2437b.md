# --description--

メール一覧にもタイムスタンプを表示してください。`__str__` メソッドを更新して、件名の後に ` | Time: ` と続けて、`'%Y-%m-%d %H:%M'` 形式でフォーマットしたタイムスタンプを追加してください。

```md
[status] From: sender | Subject: subject | Time: time
```

`Time` 列を揃えるために、件名を幅 `15` で左寄せにしてください。幅はあくまで最小値なので、件名が長い場合は全文が表示されて `Time` がずれることがあります。これを防ぐために、フォーマットする前に件名を最初の `15` 文字に切り取ってください。

例えば、件名が短いメールと長いメールは次のようになります：

```md
[Unread] From: Alice      | Subject: Hello           | Time: 2025-01-15 09:30
[Unread] From: Alice      | Subject: Quarterly budge | Time: 2025-01-15 09:30
```

# --hints--

```js
({
    test: () => runPython(`
        import datetime

        _email = Email(User('Alice'), User('Bob'), 'Hello', 'How are you?')
        _email.timestamp = datetime.datetime(2025, 1, 15, 9, 30)
        assert str(_email) == '[Unread] From: Alice      | Subject: Hello           | Time: 2025-01-15 09:30'
    `)
})
```

件名が `15` 文字より長い場合は、最初の `15` 文字に切り取ってください。

```js
({
    test: () => runPython(`
        import datetime
        _email = Email(User('Alice'), User('Bob'), 'Quarterly budget review', 'See you there.')
        _email.timestamp = datetime.datetime(2025, 1, 15, 9, 30)
        _email.read = True
        assert str(_email) == '[Read  ] From: Alice      | Subject: Quarterly budge | Time: 2025-01-15 09:30'
    `)
})
```
