# --description--

L'attributo `type` indica al browser che tipo di dati un `input` dovrebbe accettare. Alcuni valori comuni per l'attributo `type` sono:

- `text`: un campo di testo a riga singola
- `email`: un campo di testo che verifica che l'utente inserisca un indirizzo email valido
- `number`: un campo per numeri
- `radio` e `checkbox`: opzioni che l'utente può selezionare

Ecco un esempio di un input di testo:

```html
<input type="text">
```

Per l'elemento `input` esistente, aggiungi un attributo `type` impostato su `"text"`.

Dai anche all'elemento `input` un attributo `id` con il valore `"full-name"`. Questo corrisponde all'attributo `for` del tuo elemento `label`, che collega i due insieme.

Quando un utente fornisce il proprio nome completo, l'`input` accetterà testo semplice.
