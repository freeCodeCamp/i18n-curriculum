# --description--

React — одна з найпопулярніших бібліотек JavaScript для створення інтерфейсів користувача та веб-застосунків. Спочатку розроблена у Facebook, тепер Meta, React здобула величезну популярність у веб-розробці завдяки своїй ефективності, гнучкості та функціям.

Основна концепція в React — створення багаторазових UI-компонентів. Ці компоненти, такі як кнопки, картки та аватари, можна легко повторно використовувати по всьому вашому застосунку. Ви можете вкладати ці компоненти один в одного, щоб створювати більш складні, динамічні інтерфейси.

Одна з ключових переваг React полягає в тому, що ці кастомні компоненти можуть оновлюватися та відтворюватися незалежно один від одного при зміні даних.

На відміну від традиційного JavaScript, який вимагає прямої маніпуляції DOM (Document Object Model), React використовує віртуальний DOM, що покращує продуктивність і ефективність. Ви дізнаєтеся більше про віртуальний DOM і як він працює в наступних уроках.

Окрім багаторазових компонентів, React також надає потужний спосіб керування станом вашого застосунку. Стан — це дані, які визначають, як компонент відтворюється і поводиться.

З React ви легко можете відстежувати та оновлювати стан компонентів, забезпечуючи, щоб UI відображав найактуальніші дані. Ви дізнаєтеся більше про роботу зі станом у майбутніх уроках.

Хоча в екосистемі JavaScript є багато бібліотек, freeCodeCamp переважно навчає React через його широке використання та попит у галузі.

У наступних кількох уроках ви глибше розглянете створення кастомних компонентів, керування станом і не тільки.
