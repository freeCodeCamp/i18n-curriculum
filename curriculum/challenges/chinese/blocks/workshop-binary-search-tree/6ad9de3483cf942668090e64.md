# --description--

递归调用沿着树每次向下一个层级，但它们需要一个停止的地方。

当向右方向的下一个节点不存在时，`_insert` 会以 `None` 作为 `node` 被调用。那就是新值应该放置的空位置。现在，你的方法会尝试访问 `None` 上的 `node.key` 并引起误差。

在 `_insert` 方法的开头，在你现有的 `if` 语句之前，添加基本情形：一个检查 `node is None` 的 `if` 语句，并返回一个带有给定 `key` 的新 `TreeNode`。之前的调用会将新节点赋值给其父节点的 `node.left` 或 `node.right`。
