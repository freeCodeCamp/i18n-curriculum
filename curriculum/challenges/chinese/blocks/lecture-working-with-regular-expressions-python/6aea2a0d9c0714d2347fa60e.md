# --description--

到目前为止，你已经使用过 `re.search` 在字串中查找任意位置的模式。`re` 模块还有许多其他与正则表达式模式配合使用的函数。在本课中，你将学习一些最有用的函数。

## `match` 函数

`match` 函数的工作方式类似于 `search`，但它只在字串的开头查找模式。如果字串开头匹配模式，它会返回一个匹配对象，否则返回 `None`：

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

在第二个例子中，字串包含数字，所以 `re.search` 会找到它们。但字串开头不是数字，因此 `re.match` 返回 `None`。

## `fullmatch` 函数

模式 `r'\d+:\d+'` 匹配一个或多个数字，后跟冒号，再后跟一个或多个数字。这是像 `10:30` 这样的时间格式。

假设你想检查某些用户输入是否是时间，且没有其他内容。如果你使用 `re.search`，你会发现问题：

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

这会返回一个匹配对象，尽管 `10:30pm` 并不符合预期格式。这是因为 `re.search` 会在字串中任意位置查找模式，并忽略匹配周围的额外字符。`re.match` 也会有同样的问题，因为 `10:30pm` 以有效时间开头。

当你验证数据时，通常希望整个字串都符合模式。为此，你可以使用 `fullmatch` 函数。只有当模式匹配整个字串时，它才返回匹配对象，否则返回 `None`：

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## `findall` 函数

`search`、`match` 和 `fullmatch` 最多只返回一个匹配。当你想要字串中的所有匹配时，可以使用 `findall` 函数。它返回一个包含所有匹配字串的列表：

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

如果没有匹配，`findall` 返回一个空列表：

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## `sub` 函数

`sub` 函数用另一个字串替换模式的每个匹配项。它接受模式、替换字串和要查找的字串，并返回一个新字串：

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

`sub` 还有两个可选参数。第一个是 `count`，用于限制替换的匹配数量：

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

第二个是 `flags`。像其他函数一样，`sub` 可以使用诸如 `re.IGNORECASE` 之类的标记：

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

始终将 `count` 和 `flags` 作为关键字参数传递。如果你将 `re.IGNORECASE` 作为第四个位置参数传递，Python 会将其视为 `count` 的值。
