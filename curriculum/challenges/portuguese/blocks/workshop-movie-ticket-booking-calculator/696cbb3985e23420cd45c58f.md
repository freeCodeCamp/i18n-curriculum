# --description--

A declaração `if...elif...else` é usada para verificar múltiplas condições em ordem.

```py
if condition1:
    # Code to execute if condition1 is True
elif condition2:
    # Code to execute if condition1 is False and condition2 is True
else:
    # Code to execute if all conditions are False
```

Ainda dentro do corpo da declaração externa `if`, adicione uma cláusula `elif` entre as linhas `if seat_type == 'Premium':` e `else:` e verifique se `seat_type` é igual a `Gold`. Dentro do corpo da cláusula `elif`, atualize o valor de `service_charges` para `3`.

Abaixo da declaração aninhada `if...elif...else`, use uma f-string para imprimir `Service charges:` seguido de um espaço e `service_charges` formatado com duas casas decimais. Depois, verifique a saída no terminal.
