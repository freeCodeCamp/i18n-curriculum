# --description--

이 실습에서는 모든 HTML과 CSS가 제공되었습니다. TypeScript를 사용해 오토바이 가게 페이지의 기능을 완성하세요.

**목표:** 아래 사용자 스토리를 충족하고 모든 테스트를 통과하여 실습을 완료하세요.

**사용자 스토리:**

1. 다음 가능한 값들로 구성된 `Category`라는 이름의 `type`을 만들어야 합니다: `'Sport'`, `'Cruiser'`, `'Touring'`, `'Dirt'`, `'Adventure'`, `'Naked'`, `'Electric'`.
2. 다음 속성을 가진 `Motorcycle`이라는 이름의 `interface`를 만들어야 합니다: `string` 타입의 `id`, `string` 타입의 `name`, `string` 타입의 `manufacturer`, `Category` 타입의 `category`, `number` 타입의 `price`, `string` 타입의 `image_url`, `Date` 타입의 `created_at` 속성, `string` 타입의 `description`, 그리고 `number` 타입의 `year`. 
3. `Motorcycle` 객체의 배열로 해결되는 `Promise`를 반환하는 `fetchMotorcycles`라는 이름의 함수를 만들어야 합니다.
4. `https://cdn.freecodecamp.org/curriculum/labs/data/motorcycle-shop/motorcycles.json` 엔드포인트에서 `Motorcycle` 데이터를 불러와야 합니다.
5. 하나의 `Motorcycle` 객체를 매개변수로 받아 오토바이 카드를 서식이 적용된 HTML 문자열로 반환하는 `renderMotorcycleCard`라는 이름의 함수를 만들어야 합니다.
   1. `renderMotorcycleCard` 함수는 `Motorcycle` 타입의 `motorcycle`이라는 매개변수를 받아야 합니다. 
   2. `renderMotorcycleCard` 함수는 motorcycle-card 컴포넌트를 이루는 HTML 요소들의 문자열을 반환해야 합니다. 함수의 반환 타입은 `string`이어야 합니다. 
   3. 각 motorcycle-card 컴포넌트에는 `motorcycle-card` 클래스를 가진 바깥쪽 컨테이너 요소가 있어야 합니다. 
   4. 각 motorcycle-card 컴포넌트에는 유효한 이미지를 가지고 `motorcycle-card-image` 클래스를 가진 `img` 요소가 있어야 합니다.
   5. 각 motorcycle-card 컴포넌트에는 `motorcycle-card-year-badge` 클래스를 가진, 연도를 일반 텍스트로 표시하는 요소가 있어야 합니다.
   6. 각 motorcycle-card 컴포넌트에는 `motorcycle-card-title` 클래스를 가진, 오토바이 이름을 일반 텍스트로 표시하는 요소가 있어야 합니다.
   7. 각 motorcycle-card 컴포넌트에는 `motorcycle-card-manufacturer` 클래스를 가진, 오토바이 제조사 이름을 일반 텍스트로 표시하는 요소가 있어야 합니다.
   8. 각 motorcycle-card 컴포넌트에는 `motorcycle-card-category` 클래스를 가진, 오토바이 카테고리를 일반 텍스트로 표시하는 요소가 있어야 합니다. 
   9. 각 motorcycle-card 컴포넌트에는 `motorcycle-card-description` 클래스를 가진, 오토바이 설명을 일반 텍스트로 표시하는 요소가 있어야 합니다. 
   10. 각 motorcycle-card 컴포넌트에는 `motorcycle-card-price` 클래스를 가진, 오토바이 가격을 일반 텍스트로 표시하는 요소가 있어야 합니다.
6. `MotorcycleGalleryApp`이라는 클래스가 있어야 합니다. 
   1. 이 클래스에는 `allMotorcycles`라는 `private` 멤버가 있어야 하며, `Motorcycle` 객체 배열 타입으로 정적 타입이 지정되고 빈 배열로 설정되어야 합니다.
   2. 이 클래스에는 `loadData`라는 이름의 `public` 함수가 있어야 합니다. 이 함수는 `async`로 정의되어야 하고, `fetchMotorcycles`를 호출해야 하며, 반환된 데이터를 `allMotorcycles` 클래스 속성에 저장해야 합니다.
   3. 이 클래스에는 이름에 `filterTerm`이 포함된 `allMotorcycles`의 오토바이 카드를 id가 `motorcycle-grid`인 요소 안에 렌더링하는 `renderMotorcycles`라는 이름의 public 함수가 있어야 합니다.
   4. 이 클래스에는 `private` 속성 `filterTerm`이 있어야 하며, 문자열로 정적 타입이 지정되어야 합니다.
7. 표시된 오토바이 카드의 개수가 id가 `results-number`인 요소에 표시되어야 합니다.
8. `input` 이벤트가 발생할 때 `filterTerm` 속성이 `#name-filter-input`의 값으로 업데이트되어야 합니다. 각 이벤트 후에는 표시되는 오토바이 카드와 `results-number`가 업데이트되어야 합니다.
9. `MotorcycleGalleryApp`의 인스턴스를 만들고, 그 `loadData` 메서드를 await한 다음, 불러온 오토바이 카드를 표시하고 `results-number`의 개수를 업데이트해야 합니다.

type Category = 
  | 'Sport'
  | 'Cruiser'
  | 'Touring'
  | 'Dirt'
  | 'Adventure'
  | 'Naked'
  | 'Electric';

interface Motorcycle {
  id: string;
  name: string;
  manufacturer: string;
  category: Category;
  price: number;
  image_url: string;
  description: string;
  year: number;
  created_at: Date;
}


async function fetchMotorcycles():  Promise<Motorcycle[]> {
    const res = await fetch(`https://cdn.freecodecamp.org/curriculum/labs/data/motorcycle-shop/motorcycles.json`);
    const motorcycles = await res.json();
    return [...motorcycles].map((m: Motorcycle) => ({ ...m, created_at: new Date(m.created_at) })).sort((a, b) => 
      b.created_at.getTime() - a.created_at.getTime()
    );
}

function renderMotorcycleCard(motorcycle: Motorcycle): string {
    return `
      <div class="motorcycle-card">
        <div class="motorcycle-card-image-container">
          <img
            src="${motorcycle.image_url}"
            alt="${motorcycle.name}"
            class="motorcycle-card-image"
          />
          <div class="motorcycle-card-year-badge">
            ${motorcycle.year}
          </div>
        </div>
        <div class="motorcycle-card-content">
          <div class="motorcycle-card-header">
            <div>
              <h3 class="motorcycle-card-title">${motorcycle.name}</h3>
              <p class="motorcycle-card-manufacturer">${motorcycle.manufacturer}</p>
            </div>
            <span class="motorcycle-card-category">
              ${motorcycle.category}
            </span>
          </div>
          <p class="motorcycle-card-description">${motorcycle.description}</p>
          <div class="motorcycle-card-footer">
            <div>
              <p class="motorcycle-card-price">
                $${motorcycle.price.toLocaleString()}
              </p>
           
            </div>
            <button class="motorcycle-card-button" data-motorcycle-id="${motorcycle.id}">
              View Details
            </button>
          </div>
        </div>
      </div>
    `;
  }

class MotorcycleGalleryApp {
  private allMotorcycles: Motorcycle[] = [];
  private filterTerm: string = '';
  constructor() {
    this.init();
  }

  async loadData(): Promise<void> {
    await this.loadMotorcycles();
  }

  private async init(): Promise<void> {
    this.setupEventListeners();
  }

  private async loadMotorcycles(): Promise<void> {
    this.showLoading(true);
    try {
      const data = await fetchMotorcycles();
      this.allMotorcycles = [...data];
    } catch (error) {
      console.error('Error loading motorcycles:', error);
    } finally {
      this.showLoading(false);
    }
  }

  private setupEventListeners(): void {
    const nameFilterInput = document.getElementById('name-filter-input') as HTMLInputElement;
    if (nameFilterInput) {
      nameFilterInput.addEventListener('input', (event: Event) => {
        const {value} = event.target as HTMLInputElement;
        this.filterTerm = value;
        this.render();
      });
    }
  }
 
  render(): void {
    this.renderResultsCount();
    this.renderMotorcycles();
  }

  private renderResultsCount(): void {
    const resultsNumber = document.getElementById('results-number');
    if (resultsNumber) {
      resultsNumber.textContent = this.allMotorcycles.filter((m: Motorcycle) => m.name.toLowerCase().includes(this.filterTerm.toLowerCase())).length.toString();
    }
  }

  renderMotorcycles(): void {
    const container = document.getElementById('motorcycle-grid');
    const noResults = document.getElementById('no-results');
    if (!container) return;

    if (noResults) {
      noResults.style.display = 'none';
    }

    const filteredResults = this.allMotorcycles.filter((m: Motorcycle) => m.name.toLowerCase().includes(this.filterTerm.toLowerCase()));

    if (filteredResults.length === 0 && noResults) {
      container.innerHTML = '';
      container.style.display = 'none';
      noResults.style.display = 'block';
      return;
    }

    container.style.display = 'grid';
    container.innerHTML = filteredResults
      .map(renderMotorcycleCard)
      .join('');
  }

  private showLoading(show: boolean): void {
    const loadingContainer = document.getElementById('loading-container');
    const motorcycleGrid = document.getElementById('motorcycle-grid');
    if (loadingContainer) {
      loadingContainer.style.display = show ? 'flex' : 'none';
    }
    if (motorcycleGrid) {
      motorcycleGrid.style.display = show ? 'none' : 'grid';
    }
  }
}

document.addEventListener('DOMContentLoaded',async () => {
   const gallery = new MotorcycleGalleryApp();
   await gallery.loadData();
   gallery.render();
});
