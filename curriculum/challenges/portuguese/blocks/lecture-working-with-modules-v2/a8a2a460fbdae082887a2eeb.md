# --description--

No desenvolvimento de software, uma biblioteca é como uma caixa de ferramentas para desenvolvedores.

Em vez de ter que implementar cada parte do código você mesmo do zero, uma biblioteca oferece código pré-escrito e reutilizável, como funções, classes e estruturas de dados que você pode usar em seus projetos.

A biblioteca padrão do Python é uma coleção de módulos e pacotes incluídos com o Python. Pacotes de terceiros são desenvolvidos separadamente e geralmente precisam ser instalados antes que você possa usá-los. A biblioteca padrão oferece soluções para tarefas comuns de programação, como:

* Interagindo com o sistema operacional.

* Trabalhando com arquivos.

* Rede.

* Trabalhando com data e hora.

* Realizando operações matemáticas.

* Usando expressões regulares.

* Testando e depurando seu código.

* E muito mais!

Alguns exemplos de módulos da biblioteca padrão são `math`, `random`, `re` (abreviação de "expressões regulares") e `datetime`.

O módulo `math` possui funções úteis para realizar operações matemáticas mais complexas.

O módulo `random` é útil para gerar números aleatórios.

O módulo `re` é usado para trabalhar com expressões regulares.

O módulo `datetime` é útil para trabalhar com datas e horários em Python.

Módulos podem fornecer classes, assim como funções e constantes. Aqui está um exemplo de uma classe do módulo `datetime`. Criamos um objeto date que representa 15 de julho de 1959. Depois, atribuímos esse objeto `date` a uma variável e acessamos o dia, mês e ano individualmente usando notação de ponto:

```python
import datetime
birthday = datetime.date(1959, 7, 15)
print(birthday.day)    # 15
print(birthday.month)  # 7
print(birthday.year)   # 1959
```

Para encontrar um módulo para uma tarefa específica, navegue pela [referência da biblioteca padrão do Python](https://docs.python.org/3/library/index.html), onde os módulos são agrupados por tópico. A documentação de cada módulo explica o que ele oferece e como usá-lo. Por exemplo, a [documentação do `datetime`](https://docs.python.org/3/library/datetime.html) descreve as classes e métodos disponíveis para trabalhar com datas e horários.

Você também pode usar a função `help()` para exibir a documentação de um módulo ou função. Note que `help()` não está disponível atualmente no editor do freeCodeCamp.

Por exemplo, este código exibe informações sobre o módulo `math`:

```py
import math
help(math)
```

Aqui está um trecho da saída:

Você também pode obter a documentação de uma função específica:

```py
import math
help(math.comb)
```

Este é o output:

```md
Help on built-in function comb in module math:

comb(n, k, /)
    Number of ways to choose k items from n items without repetition and without order.
    
    Evaluates to n! / (k! * (n - k)!) when k <= n and evaluates
    to zero when k > n.
    
    Also called the binomial coefficient because it is equivalent
    to the coefficient of k-th term in polynomial expansion of the
    expression (1 + x)**n.
    
    Raises TypeError if either of the arguments are not integers.
    Raises ValueError if either of the arguments are negative.
```

Para descobrir quais nomes um módulo fornece, você pode usar a função `dir()`. Ela lista funções, como `math.floor` para arredondar um número para baixo, e constantes, como `math.e` (número de Euler) e `math.pi`. Também lista alguns outros nomes que você aprenderá mais adiante no currículo:

```py
import math
print(dir(math))
```
