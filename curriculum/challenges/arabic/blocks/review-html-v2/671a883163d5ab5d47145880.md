## أساسيات HTML

- **دور HTML**: HTML (لغة ترميز النص الفائق) هي أساس هيكل الويب، تُعرّف عناصر صفحة الويب.
- **عناصر HTML**: تُستخدم لتمثيل المحتوى على الصفحة. معظمها يتكون من وسم افتتاحي ووسم إغلاق (مثلًا، `<h1></h1>`, `<p></p>`).
- **هيكل HTML**: يتكون HTML من `head` و`body`، حيث تُنظّم البيانات الوصفية، الأنماط، والمحتوى.
- **عناصر HTML الشائعة**: العناوين (`<h1>` - `<h6>`)، الفقرات (`<p>`)، وحاويات div (`<div>`).
- **عناصر `div`**: عنصر `div` هو عنصر HTML عام لا يحمل معنى دلالي. يُستخدم كحاوية عامة لاحتواء عناصر HTML أخرى.
- **العناصر الفارغة**: لا تحتوي على وسم إغلاق (مثلًا، `<img>`).
- **الخصائص**: إضافة بيانات وصفية وسلوك للعناصر.

## المعرفات والتجميع

- **المعرفات (IDs)**: معرفات فريدة للعناصر.
- **الأصناف (Classes)**: تجميع العناصر لأغراض التنسيق والسلوك.

## القالب الجاهز والترميز

- **قالب HTML الجاهز**: الهيكل الأساسي لصفحة الويب، الذي يشمل عناصر `DOCTYPE`، `html`، `head`، و`body`. يجب استخدامه كنقطة بداية لوثيقة HTML.
- **ترميز الأحرف UTF-8**: لضمان عرض الأحرف بشكل عالمي.

## أهمية HTML الدلالي

- **التسلسل الهيكلي لعناصر العنوان**: من المهم استخدام عنصر العنوان الصحيح للحفاظ على التسلسل الهيكلي للمحتوى. عنصر `h1` هو أعلى مستوى للعنوان و`h6` هو أدنى مستوى للعنوان.
- **عناصر HTML الدلالية**: توفر هذه العناصر معنى لبنية المحتوى. تشمل الأمثلة:
  - `<header>`: يمثل المحتوى التمهيدي.
  - `<nav>`: يحتوي على روابط التنقل.
  - `<article>`: يمثل محتوى مستقلًا بذاته.
  - `<section>`: يجمع المحتوى المرتبط داخل المستند.
  - `<footer>`: يحدد التذييل لقسم أو مستند.
  - `<blockquote>`: يستخدم لتمثيل قسم مقتبس من مصدر آخر. استخدم المصدر كقيمة لخاصية `cite`.
  - `<q>`: يستخدم لتمثيل اقتباس مضمّن قصير.

## عناصر وخصائص نماذج HTML

### النماذج

- **عنصر `form`**: يستخدم لإنشاء نموذج HTML لإدخال المستخدم.
- **أنواع الإدخال الشائعة**:
  - `text`، `email`، `radio`، `checkbox`، `number`.
- **خاصية `action`**: تستخدم لتحديد عنوان URL الذي يجب إرسال بيانات النموذج إليه.
- **خاصية `method`**: تستخدم لتحديد طريقة HTTP المستخدمة عند إرسال بيانات النموذج. أكثر الطرق شيوعًا هي `GET` و`POST`.

```html
<form method="value-goes-here" action="url-goes-here">
  <!-- inputs go inside here -->
</form>
```

- **عنصر `input`**: يُستخدم لإنشاء حقل الإدخال لمُدخَل المستخدم.
- **خاصية `type`**: تُستخدم لتحديد نوع حقل الإدخال، مثل `text`، `email`، `number`، `radio`، `checkbox`.
- **خاصية `placeholder`**: تُستخدم لإظهار تلميح للمستخدم يوضح ما يجب إدخاله في حقل الإدخال.
- **خاصية `value`**: تُستخدم لتحديد قيمة المُدخَل.
- **خاصية `name`**: تُستخدم لتعيين اسم لحقل الإدخال، ويعمل كالمفتاح عند إرسال بيانات النموذج. بالنسبة لأزرار الاختيار، تعيين نفس `name` يجمعها معًا بحيث يمكن اختيار خيار واحد فقط في المجموعة في كل مرة.
- **خاصية `size`**: تُستخدم لتحديد عدد الأحرف التي يجب أن تظهر أثناء كتابة المستخدم في المُدخَل.
- **خاصية `min`**: يمكن استخدامها مع أنواع المُدخَل مثل `number` لتحديد الحد الأدنى للقيمة المسموح بها في حقل الإدخال.
- **خاصية `max`**: يمكن استخدامها مع أنواع المُدخَل مثل `number` لتحديد الحد الأقصى للقيمة المسموح بها في حقل الإدخال.
- **خاصية `required`**: تُستخدم لتحديد أن حقل الإدخال يجب ملؤه قبل إرسال النموذج.

:::interactive_editor

```html
<!-- Text input -->
<input 
  type="text"
  id="name"
  name="name"
  placeholder="e.g. Quincy Larson"
  size="20"
  required
/>

<!-- Number input -->
<input 
  type="number"
  id="quantity"
  name="quantity"
  min="2"
  max="10"
/>
```

:::

- **عنصر `label`**: يستخدم لإنشاء مسمى لحقل الإدخال.
- **خاصية `for`**: تستخدم لتحديد حقل الإدخال الذي ينتمي إليه المسمى.

:::interactive_editor

```html
<form action="">
  <label for="email">Email Address: </label>
  <input type="email" id="email" />
</form>
```

:::

- **عنصر `button`**: يستخدم لإنشاء زر قابل للنقر. يمكن أيضًا أن يحتوي الزر على خاصية `type`، التي تتحكم في سلوك الزر عند تفعيله.

:::interactive_editor

```html
<button type="submit">Submit Form</button>
```

:::

- **عنصر `fieldset`**: يُستخدم لتجميع المدخلات المرتبطة معًا.
- **عنصر `legend`**: يُستخدم لإضافة تسمية توضيحية لوصف مجموعة المدخلات.

:::interactive_editor

```html
<!-- Radio group -->
<fieldset>
  <legend>Was this your first time at our hotel?</legend>

  <input id="yes-option" type="radio" name="hotel-stay" value="yes" />
  <label for="yes-option">Yes</label>

  <input id="no-option" type="radio" name="hotel-stay" value="no" />
  <label for="no-option">No</label>
</fieldset>

<!-- Checkbox group -->
<fieldset>
  <legend>
    Why did you choose to stay at our hotel? (Check all that apply)
  </legend>

  <input type="checkbox" id="location" name="location" value="location" />
  <label for="location">Location</label>

  <input type="checkbox" id="price" name="price" value="price" />
  <label for="price">Price</label>
</fieldset>
```

:::

## العمل مع عناصر وخصائص جدول HTML

- **عنصر الجدول**: يُستخدم لإنشاء جدول HTML.
- **عنصر رأس الجدول (`thead`)**: يُستخدم لتجميع محتوى الرأس في جدول HTML.
- **عنصر صف الجدول (`tr`)**: يُستخدم لإنشاء صف في جدول HTML.
- **عنصر رأس الخلية (`th`)**: يُستخدم لإنشاء خلية رأس في جدول HTML.
- **عنصر جسم الجدول (`tbody`)**: يُستخدم لتجميع محتوى الجسم في جدول HTML.
- **عنصر خلية البيانات (`td`)**: يُستخدم لإنشاء خلية بيانات في جدول HTML.
- **عنصر تذييل الجدول (`tfoot`)**: يُستخدم لتجميع محتوى التذييل في جدول HTML.
- **عنصر `caption`**: يُستخدم لإضافة عنوان لجدول HTML.
- **خاصية `colspan`**: تُستخدم لتحديد عدد الأعمدة التي يجب أن تمتد عليها خلية الجدول.

:::interactive_editor

```html
<table>
  <caption>Exam Grades</caption>

  <thead>
    <tr>
      <th>Last Name</th>
      <th>First Name</th>
      <th>Grade</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>Davis</td>
      <td>Alex</td>
      <td>54</td>
    </tr>

    <tr>
      <td>Doe</td>
      <td>Samantha</td>
      <td>92</td>
    </tr>

    <tr>
      <td>Rodriguez</td>
      <td>Marcus</td>
      <td>88</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <td colspan="2">Average Grade</td>
      <td>78</td>
    </tr>
  </tfoot>
</table>
```

:::

## إمكانية الوصول

- **إرشادات إمكانية الوصول لمحتوى الويب**: إرشادات إمكانية الوصول لمحتوى الويب (WCAG) هي مجموعة من الإرشادات لجعل محتوى الويب أكثر إمكانية الوصول للأشخاص ذوي الإعاقات. المبادئ الأربعة لـ WCAG هي POUR والتي تعني قابلية الإدراك، وقابلية التشغيل، وقابلية الفهم، والمتانة.
- **أهمية نص `alt` الجيد**: يجب استخدام خاصية `alt` لتوفير بديل نصي للصور. هذا يساعد تقنيات المساعدة على فهم محتوى الصورة.
- **أهمية نص الرابط الوصفي**: يجب استخدام نص رابط وصفي لمساعدة المستخدمين على فهم هدف الرابط.
