# --description--

Seja `n` o número de caracteres no número do cartão de entrada. Sua implementação tem complexidade de tempo **O(n)**. Traduzir e inverter a string levam tempo linear. Criar os recortes das posições ímpares e pares também leva tempo linear, e os dois loops juntos processam cada dígito uma vez. Somar essas operações lineares ainda resulta em O(n).

Complete seu validador retornando se `total` é divisível por `10`.

def is_valid_card_number(card_number):
    card_translation = str.maketrans({'-': '', ' ': ''})
    card_number = card_number.translate(card_translation)

    sum_of_odd_digits = 0
    card_number_reversed = card_number[::-1]
    odd_digits = card_number_reversed[::2]

    for digit in odd_digits:
        sum_of_odd_digits += int(digit)

    sum_of_even_digits = 0
    even_digits = card_number_reversed[1::2]
    for digit in even_digits:
        number = int(digit) * 2
        if number >= 10:
            number = (number // 10) + (number % 10)
        sum_of_even_digits += number
    total = sum_of_odd_digits + sum_of_even_digits
