# --description--

在 Python 中，`bool` 是 `int` 的子類別，其中 `True` 表現得像 `1`，`False` 表現得像 `0`。這表示 `isinstance()` 將布林值視為整數：

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True
```

因此，你的函式目前接受 `True` 和 `False` 作為位移值。

使用 `or` 運算子為你的 `if` 述語添加第二個條件，檢查 `shift` 是否為布林值，方法是使用 `isinstance(shift, bool)`。這樣，當 `shift` 是 `True` 或 `False` 時，你的函式也會傳回 `Shift must be an integer value.`。
