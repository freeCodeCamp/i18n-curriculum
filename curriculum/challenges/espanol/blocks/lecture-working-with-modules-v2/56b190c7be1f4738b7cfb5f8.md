# --description--

Como aprendiste en la lección anterior, un módulo es un archivo Python que agrupa código relacionado, para que puedas reutilizarlo en otros archivos Python.

También puedes escribir tus propios módulos e importarlos en tus scripts. Crear tus propios módulos es una excelente manera de organizar tu código. En lugar de tener un archivo muy largo, puedes dividir tu código en archivos más pequeños, donde cada uno agrupa código relacionado, y luego importarlos donde los necesites.

Por ejemplo, supongamos que creaste un archivo `temperature.py` con dos funciones para convertir temperaturas, y una llamada a función para verificar que una de ellas funciona:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

Si ejecutas este archivo directamente, esta es la salida:

```md
212.0
```

Ahora, supongamos que creas otro archivo llamado `main.py` en la misma carpeta que `temperature.py`. Para usar las funciones de tu módulo local, lo importas usando el nombre del módulo sin la extensión `.py`:

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

Si ejecutas el archivo `main.py`, esta es la salida:

```md
212.0
100.0
```

Cuando se importa `temperature`, Python ejecuta todo el código en `temperature.py` de arriba hacia abajo. Por eso se imprime `212.0`, aunque `main.py` solo llama a `fahrenheit_to_celsius()`. Código como esta verificación normalmente quieres que se ejecute solo cuando ejecutas el archivo directamente, no cada vez que se importa.

Para controlar esto, puedes usar un modismo común en Python:

```python
if __name__ == '__main__':
    # Code
```

`__name__` es una variable incorporada especial en Python.

Cuando un archivo Python se ejecuta directamente, Python asigna a esta variable el valor de la cadena `__main__`.

Pero si el archivo Python se importa como un módulo en otro script Python, el valor de la variable `__name__` se establece con el nombre de ese módulo (usualmente el nombre del archivo sin la extensión `.py`).

Por eso a menudo encontrarás esta condición en scripts Python. Contiene el código que quieres ejecutar **solo si** el script Python se está ejecutando como programa principal. Si el script se importa como módulo, el código dentro de ese bloque no se ejecuta.

Esto es útil porque permite que los scripts de Python tengan dos propósitos. Pueden ejecutarse directamente para llevar a cabo su lógica principal, o pueden importarse en otro módulo sin ejecutar su lógica principal.

Aquí está el archivo `temperature.py` actualizado para usar este modismo. También imprime el valor de `__name__`, para que puedas ver cómo cambia:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

Si ejecutas este archivo directamente, Python asigna a `__name__` el valor `'__main__'`, así que la condición es `True` y el código dentro del bloque `if` se ejecuta. Esta es la salida:

```md
The value of __name__ is: __main__
212.0
```

Si en cambio ejecutas el archivo `main.py`, esta es la salida:

```md
The value of __name__ is: temperature
100.0
```

La llamada a `print()` fuera del bloque `if` todavía se ejecuta cuando se importa `temperature`, y muestra que el valor de `__name__` ahora es `temperature`, el nombre del módulo.

Pero como `__name__` no es igual a `'__main__'`, el código dentro del bloque `if` no se ejecuta, así que no se imprime `212.0`. La única otra salida es `100.0`, que proviene de la llamada a función en `main.py`.
