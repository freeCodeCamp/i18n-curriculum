# --description--

`map()` 関数はイテラブルの各要素に関数を呼び出し、その結果のイテレーターを返します。`filter()` と同様に、ラムダ関数を渡すことができます。

```py
prices = [10, 20, 30]
discounted = list(map(
    lambda price: price * 0.9,
    prices
))
print(discounted) # [9.0, 18.0, 27.0]
```

有効な読み取り値を10分の1度から度に変換する必要があります。

`temperatures` という変数を作成してください。`map()` にラムダ関数と `valid_readings` を渡し、その結果を `list()` で囲んだものを代入してください。ラムダ関数は `reading` というパラメータを受け取り、`reading` を `10` で割った値を返すようにしてください。

その後、`valid_readings` の代わりに `temperatures` を出力してください。
