# --description--

이제 JSX에서 `isOpen` 상태를 사용할 수 있습니다. `button` 요소부터 시작하세요.

`aria-expanded` 속성은 화면 읽기 프로그램과 같은 보조 기술에 버튼이 제어하는 콘텐츠가 표시(`"true"`)되는지 숨겨져 있는지(`"false"`) 알려줍니다. 현재 값은 항상 `"false"`입니다.

중괄호가 JSX에서 JavaScript 표현식을 임베드할 수 있게 해준다는 점을 기억하세요. 이 방법은 속성 값에도 적용되므로, 조건에 따라 값을 선택하려면 삼항 연산자를 사용할 수 있습니다:

```jsx
<p title={isDarkMode ? "Dark theme" : "Light theme"}>Theme</p>
```

`button`의 `aria-expanded` 속성을 `isOpen`이 `true`일 때는 `"true"`로, `isOpen`이 `false`일 때는 `"false"`로 업데이트하세요.
