# --description--

你可能还需要查看字串的结尾。Python 提供了 `.endswith()` 方法来完成这个操作。如果字串以给定的后缀结尾，它会返回 `True`，否则返回 `False`。

这是一个示例：

```python
code = 'EMP-001'
print(code.endswith('EMP')) # False
print(code.endswith('001')) # True
```
