# --description--

`sub-menu`を開閉するには、`Navbar`コンポーネントが`sub-menu`が現在開いているかどうかを記憶しておく必要があります。コンポーネントが記憶し、時間とともに変化する可能性のあるデータを状態と呼びます。状態が変わるたびに、Reactはコンポーネントを再レンダリングしてページに新しい値を表示します。

状態については今後のレッスンでさらに詳しく学びます。今のところは、`useState`フックを使って関数コンポーネントに状態を追加できることだけ知っていれば十分です。フックはコンポーネント内でReactの機能を使える特別な関数です。このワークショップではReactが`script`要素で読み込まれているので、`React.useState`としてフックにアクセスできます。

```jsx
const [count, setCount] = React.useState(0);
```

`React.useState`は状態の初期値を引数に取り、2つの要素を持つ配列を返します。ここでは配列の分割代入で展開しています。

- `count`は現在の値を保持する状態変数です。
- `setCount`は状態を更新するために呼び出すセッター関数です。

`Navbar`コンポーネント内で`React.useState`を使い、`isOpen`という状態変数と`setIsOpen`というセッター関数を作成してください。`sub-menu`は最初は閉じている状態にしたいので、初期値は`false`にします。
