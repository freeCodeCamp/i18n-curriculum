# --description--

最后，对于蓝色标记的 `box-shadow` 属性，将命名颜色替换为 `hsla` 函数。

`hsla` 函数的工作方式与 `hsl` 函数完全相同，但增加了第四个值 alpha，用于控制颜色的不透明度。与 `rgba` 一样，alpha 值是从 `0` 到 `1.0` 的数字。基本语法如下：

```css
hsla(hue, saturation, lightness, alpha);
```

使用色调为 `223`，饱和度为 `59%`，亮度为 `31%`，alpha 通道为 `0.8` 的值。

至此，你的彩色标记集工作坊完成了！干得漂亮。

# --hints--

你的 `.blue` CSS 规则应该有一个 `box-shadow` 简写属性，其值为 `0 0 20px 0 hsla(223, 59%, 31%, 0.8)`。

```js
assert.strictEqual(new __helpers.CSSHelp(document).getStyle('.blue')?.boxShadow, 'rgba(32, 59, 126, 0.8) 0px 0px 20px 0px');
```
