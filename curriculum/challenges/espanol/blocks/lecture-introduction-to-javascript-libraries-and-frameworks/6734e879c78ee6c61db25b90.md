# --description--

Los componentes son los bloques de construcción de las aplicaciones React que permiten a los desarrolladores dividir interfaces de usuario complejas en piezas más pequeñas y manejables, facilitando el desarrollo y mantenimiento de aplicaciones a gran escala.

Los dos tipos de componentes en React son componentes funcionales y basados en clases. En React moderno, los desarrolladores usan componentes funcionales, y cada ejemplo en esta lección es un componente funcional.

A un nivel alto, puedes pensar en los componentes como funciones de JavaScript que devuelven elementos que describen la interfaz de usuario.

Esta interfaz de usuario se describe usando JSX, una extensión de sintaxis para JavaScript que se parece al HTML pero le permite escribir elementos de UI de una manera más declarativa.

Veamos un ejemplo de un componente React:

```jsx
function Greeting() {
  const name = "John";
  return (
    <h1 className="title">
      {/* The result will be Hello John */}
      Hello {name}
    </h1>
  );
}
```

En este ejemplo, hemos definido un componente llamado `Greeting`. Las llaves `{}` dentro de las etiquetas `h1` nos permiten insertar expresiones de JavaScript, lo que nos permite acceder a la variable `name` dentro del elemento `h1`.

También estamos aplicando una clase llamada `title` al elemento `h1` usando el atributo `className`.

¿Pero por qué estamos usando `className` en lugar de `class` como con los elementos HTML normales?

Esto se debe a que en JavaScript, `class` es una palabra clave reservada. Por eso, necesitamos usar `className` en su lugar.

También estamos usando un comentario dentro del JSX. Un comentario dentro del JSX debe estar envuelto en llaves. Fuera del JSX, en el cuerpo del componente, escribes un comentario normal de JavaScript:

```jsx
{/* Block Comments */}
```

Otra cosa que podrías haber notado es que estamos usando una letra mayúscula al principio del nombre del componente. Pero, ¿por qué no podemos usar solo letras minúsculas?

Esto se debe a que React trata a los componentes con una letra mayúscula como componentes personalizados, mientras que a los elementos con letras minúsculas los considera elementos HTML incorporados.

Cuando React encuentra una etiqueta en minúsculas, como `<div>` o `<span>`, asume que es un elemento HTML estándar. Sin embargo, si el nombre del componente comienza con una letra mayúscula, React lo tratará como un componente definido por el usuario y lo renderizará en consecuencia. Esta distinción ayuda a React a diferenciar entre etiquetas HTML nativas y los componentes que tú creas.

Para usar este componente `Greeting` en nuestra aplicación, escribiríamos algo así:

```jsx
<Greeting />
```

Esto representaría un elemento `h1` con el texto `Hello John` en la página. Pero observe más de cerca la sintaxis aquí. Cuando usamos el componente, termina con una barra diagonal y luego el símbolo mayor que.

Al trabajar con JSX, todas las etiquetas y usos de componentes deben cerrarse explícitamente. Así que si el componente o etiqueta no tiene hijos, necesitas cerrarlo explícitamente como se muestra aquí:

```jsx
<Greeting /> {/* /> is required */}
```

Hasta ahora solo hemos visto cómo renderizar un solo elemento `h1`. Pero en realidad puedes renderizar múltiples elementos.

Echemos un vistazo al siguiente código de ejemplo aquí:

```jsx
function Greeting() {
  const name = "John";
  // This will throw an error
  return (
    <h1>Hello {name}</h1>
    <p>Nice to meet you.</p>
  );
}
```

Estamos intentando agregar otra oración de `Nice to meet you` pero no se muestra correctamente en la página.

En cambio, parece que hay un mensaje de error. El mensaje de error dice `Adjacent JSX elements must be wrapped in an enclosing tag.`

La razón por la que recibes ese mensaje de error es porque múltiples elementos hermanos deben estar envueltos en un elemento padre. Aunque podrías envolver los elementos `h1` y `p` en un simple `div`, hay otra forma de cumplir con ese requisito.

Se utilizan fragmentos de React para agrupar elementos. Así es como se verá el ejemplo revisado:

```jsx
import { Fragment } from "react";

function Greeting() {
  const name = "John";
  return (
    <Fragment>
      <h1>Hello {name}</h1>
      <p>Nice to meet you.</p>
    </Fragment>
  );
}
```

También puede optar por usar etiquetas JSX vacías que pueden servir como taquigrafía para fragmentos:

```jsx
function Greeting() {
  const name = "John";
  return (
    <>
      <h1>Hello {name}</h1>
      <p>Nice to meet you.</p>
    </>
  );
}
```

En futuras lecciones, continuaremos aprendiendo más sobre cómo trabajar con componentes y JSX. Pero por ahora, has obtenido una introducción sólida para construir interfaces de usuario con componentes, estableciendo una base fuerte para lo que viene.
