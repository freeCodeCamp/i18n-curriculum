# --description--

Para abrir y cerrar el `sub-menu`, tu componente `Navbar` necesita recordar si el `sub-menu` está abierto actualmente. Los datos que un componente recuerda y que pueden cambiar con el tiempo se llaman estado. Cada vez que el estado cambia, React vuelve a renderizar el componente para que la página muestre el nuevo valor.

Aprenderás mucho más sobre el estado en las próximas lecciones. Por ahora, solo necesitas saber que puedes agregar estado a un componente funcional con el hook `useState`. Los hooks son funciones especiales que te permiten usar funcionalidades de React en tus componentes. Como React se carga con un elemento `script` en este taller, puedes acceder al hook como `React.useState`:

```jsx
const [count, setCount] = React.useState(0);
```

`React.useState` toma el valor inicial del estado como argumento y devuelve un arreglo con dos elementos, que aquí se desempaquetan con desestructuración de arreglos:

- `count` es la variable de estado, que contiene el valor actual.
- `setCount` es la función setter, que llamas para actualizar el estado.

Dentro del componente `Navbar`, usa `React.useState` para crear una variable de estado llamada `isOpen` y una función setter llamada `setIsOpen`. Como el `sub-menu` debe comenzar cerrado, dale un valor inicial de `false`.
