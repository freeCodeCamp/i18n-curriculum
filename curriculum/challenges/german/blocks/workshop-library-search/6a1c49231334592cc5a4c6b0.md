Super! Wenn Ihre `findBook`-Funktion jedoch einen Fehler wirft, wird der restliche Code in Ihrem Ereignis-Listener nicht ausgeführt, weil nichts vorhanden ist, um ihn abzufangen.

Um diese Fehler elegant zu behandeln, müssen Sie den Code, der fehlschlagen könnte, in einen `try`-Block einschließen.

```js
try {
  // Code that might throw an error
}
```

  }

  return title + " is available to borrow!";
};
