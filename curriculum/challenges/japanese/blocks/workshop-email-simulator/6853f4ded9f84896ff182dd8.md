# --description--

空の受信トレイのチェックの後に、メッセージ `\nYour Emails:` を出力してください。その後、`for` ループと列挙を使って受信トレイ内のすべてのメールを繰り返し処理してください。開始番号を指定した列挙の構文は `enumerate(iterable, start=start_number)` です。

列挙を使ってメールに `1` から番号を付けてください。反復変数として `i`（インデックス）と `email`（メールオブジェクト）を使います。

ループ内では、反復のインデックスを幅 `2` で右寄せし、その後に `.` とスペースを付けて、メールオブジェクトの文字列表現を次の形式で出力してください。

```md
 i. string_representation
```

`i` はインデックス、`string_representation` はメールオブジェクトの表現です。番号を右寄せにすることで、受信トレイに10件以上のメールがあってもリストの位置が揃います。
