# --description--

`map()` 函数对可迭代对象的每个项调用一个函数，并返回结果的迭代器。和 `filter()` 一样，你可以传递一个 lambda 函数：

```py
prices = [10, 20, 30]
discounted = list(map(
    lambda price: price * 0.9,
    prices
))
print(discounted) # [9.0, 18.0, 27.0]
```

现在你需要将有效读数从十分之一度转换为度。

创建一个名为 `temperatures` 的变量。将传递给 `map()` 的 lambda 函数和 `valid_readings` 的结果赋值给它，并用 `list()` 包裹。lambda 函数应接受一个名为 `reading` 的参数，并返回 `reading` 除以 `10` 的结果。

然后，打印 `temperatures`，而不是 `valid_readings`。
