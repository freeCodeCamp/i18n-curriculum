# --description--

Agrega una cláusula `elif` a tu sentencia `if` que verifique si `key` es mayor que `node.key`. Dentro de ella, llama a `self._insert` con `node.right` y `key`, y asigna el resultado a `node.right`.

Si `key` es igual a `node.key`, ninguna rama se ejecuta, por lo que no se agregan valores duplicados al árbol.
