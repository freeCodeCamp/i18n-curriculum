# --description--

재귀 호출은 트리를 한 단계씩 내려가지만, 멈출 지점이 필요합니다.

오른쪽 방향의 다음 노드가 없으면, `_insert`가 `node`로 `None`을 받아 호출됩니다. 그곳이 새 값이 들어갈 빈 자리입니다. 현재 메서드는 `None`에서 `node.key`에 접근하려고 하여 오류가 발생합니다.

`_insert` 메서드 시작 부분, 기존 `if` 문 앞에 기본 사례를 추가하세요: `node is None`인지 확인하는 `if` 문을 넣고 주어진 `key`로 새 `TreeNode`를 반환하세요. 이전 호출은 새 노드를 부모의 `node.left` 또는 `node.right`에 할당합니다.
