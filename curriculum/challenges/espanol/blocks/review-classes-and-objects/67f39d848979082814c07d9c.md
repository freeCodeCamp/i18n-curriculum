## Clases y objetos en Python

- **Definición de clase**: Una clase es un modelo para crear objetos. Define el comportamiento que tendrá un objeto a través de sus atributos y métodos. Aquí tienes un ejemplo básico de definición de clase en Python:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **Nombres de clase**: Por convención, los nombres de clase usan PascalCase: cada palabra comienza con una letra mayúscula y no hay guiones bajos, como en `Dog` o `ShoppingCart`.

- **El método `__init__()`**: Python llama automáticamente a `__init__()` cada vez que creas un nuevo objeto. Se usa para configurar los atributos iniciales del objeto.

- **El parámetro `self`**: `self` se refiere al objeto específico en el que trabaja el método. Python lo pasa automáticamente cuando llamas a un método en un objeto, por lo que no lo escribes en la llamada. `self` es el nombre convencional, pero siempre es el primer parámetro de un método de instancia.

- **Creación de objetos**: Los objetos son instancias de una clase. Se crean llamando a la clase con los argumentos necesarios.

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **Llamar métodos en objetos**: Puedes llamar métodos en objetos para realizar acciones o recuperar información.

```python
object_name1.method_name()
object_name2.method_name()
```

- **Diferencia entre clase y objeto**: Una clase es una plantilla reutilizable, mientras que un objeto es una instancia específica de esa clase con datos reales.

## Atributos

- **Atributos de instancia**: Usualmente definidos en `__init__()` usando `self`, y únicos para cada objeto.
- **Atributos de clase**: Definidos directamente dentro de la clase y compartidos por todas las instancias.

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **Manejo dinámico de atributos**: A veces el nombre del atributo solo se conoce en tiempo de ejecución, por ejemplo cuando proviene de la entrada del usuario o de un ciclo. En ese caso no puedes escribir `object.name`, así que usas funciones que toman el nombre como una cadena:

  - `getattr(obj, name)` devuelve el valor del atributo. Lanza un `AttributeError` si el atributo no existe, a menos que pases un valor predeterminado como tercer argumento.
  - `setattr(obj, name, value)` crea o actualiza un atributo.
  - `hasattr(obj, name)` devuelve `True` si el atributo existe, de lo contrario `False`.
  - `delattr(obj, name)` elimina un atributo.

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **Inspeccionar atributos con `dir()`**: La función `dir()` devuelve una lista con los nombres de los atributos y métodos de un objeto. Combínala con `callable()` para separar métodos de atributos de datos.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## Métodos

- **Métodos**: Funciones definidas dentro de una clase que operan sobre los atributos del objeto.

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **Acceso a métodos**: Llama métodos en objetos usando la notación de punto. Aquí tienes un ejemplo de llamar al método `describe` en dos objetos coche diferentes:

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## Métodos dunder (mágicos)

- **Definición**: Métodos especiales que comienzan y terminan con doble guion bajo (por ejemplo, `__init__`, `__len__`, `__str__`, `__eq__`). Python los usa internamente para operaciones integradas.

- **Comportamiento sin métodos especiales personalizados**: Python no infiere cómo las operaciones integradas deben usar los atributos de un objeto personalizado. Usa el comportamiento predeterminado heredado cuando está disponible y lanza un `TypeError` para operaciones no soportadas.

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **Qué cambian los métodos personalizados**: `__len__()` hace que `len()` devuelva el número de páginas en lugar de lanzar un error. `__str__()` reemplaza la representación predeterminada con un resumen legible. `__eq__()` hace que `==` compare el número de páginas en lugar de verificar si ambos nombres se refieren al mismo objeto.

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **Llamar métodos dunder indirectamente**: No necesitas llamar a métodos dunder directamente. En cambio, Python los llama automáticamente cuando ocurren ciertas acciones. Estas operaciones incluyen:

  - **operaciones aritméticas como suma, resta, multiplicación, división y otras**. `__add__()` se llama para suma, `__sub__()` para resta, `__mul__()` para multiplicación y `__truediv__()` para división.
        
  - **operaciones con cadenas como concatenación, repetición, formato y conversión a texto**. `__add__()` se llama para concatenación, `__mul__()` para repetición, `__format__()` para formato, `__str__()` y `__repr__()` para conversión a texto, y así sucesivamente.
        
  - **operaciones de comparación como igualdad, menor que, mayor que y otras**. `__eq__()` se llama para comprobaciones de igualdad, `__lt__()` para menor que, `__gt__()` para mayor que, y así sucesivamente.
        
  - **operaciones de iteración como hacer que un objeto sea iterable y avanzar a través de los elementos**. `__iter__()` se llama para devolver un iterador y `__next__()` para obtener el siguiente elemento.

## Ejemplo real: carrito de compras

- **Clase carrito con métodos dunder**: Permite agregar, eliminar, iterar y verificar contenido con comportamiento integrado.

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## Objetos trabajando juntos

- **Pasar objetos como argumentos**: Los objetos pueden pasarse a los constructores de otras clases, igual que números o cadenas.

- **Almacenar objetos en atributos**: Un objeto puede almacenarse en el atributo de otro objeto. Luego puedes llamar métodos a través de ese atributo encadenando la notación de punto, como en `receiver.inbox.receive_email(email)`.

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## Trabajando con fechas y horas

- **Obtener la fecha y hora actual**: Llamar a `datetime.datetime.now()` devuelve la fecha y hora actual como un objeto `datetime`.

- **Almacenar una marca de tiempo en una instancia**: Llama a `datetime.datetime.now()` dentro de `__init__()` y asigna el resultado a un atributo para registrar cuándo se creó el objeto.

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **Formatear con `strftime()`**: El método `strftime()` convierte un objeto `datetime` en una cadena, usando códigos de formato: `%Y` para el año de cuatro dígitos, `%m` para el mes, `%d` para el día, `%H` para la hora (reloj de 24 horas), `%M` para los minutos y `%S` para los segundos. Cualquier otro carácter, como `-`, `/`, `:` o espacios, se mantiene como separadores literales.

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
