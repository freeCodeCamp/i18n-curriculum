## Python의 일반적인 오류

- **SyntaxError**: 코드가 구문 규칙을 따르지 않을 때 Python이 발생시키는 오류입니다. 예를 들어, `print("Hello there"` 코드는 닫는 괄호가 없어서 `SyntaxError: '(' was never closed` 메시지와 함께 구문 오류가 발생합니다.
- **NameError**: Python이 정의되지 않은 변수나 함수에 접근하려고 할 때 `NameError`를 발생시킵니다. 예를 들어, `print(username)` 코드에서 `username` 변수가 정의되지 않았다면 `NameError: name 'username' is not defined` 메시지와 함께 이름 오류가 발생합니다.
- **TypeError**: 호환되지 않는 데이터 타입끼리 연산을 수행할 때 Python이 발생시키는 오류입니다. 예를 들어, 문자열과 숫자를 더하려 하면 `TypeError: can only concatenate str (not "int") to str` 오류가 발생합니다.
- **IndexError**: 리스트나 튜플, 문자열 같은 시퀀스에서 존재하지 않는 인덱스를 접근하면 `IndexError`가 발생합니다. 예를 들어, `Hello world` 문자열에서 마지막 문자의 인덱스는 `10`입니다. 이 인덱스를 벗어나 `greet = "hello world"; print(greet[11])`처럼 접근하면 `IndexError: string index out of range` 메시지와 함께 오류가 발생합니다.
- **AttributeError**: 객체에 없는 메서드나 속성을 사용하려 할 때 Python이 발생시키는 오류입니다. 예를 들어, `"hello".append("!")` 같은 문자열에 `.append()`를 호출하면 `AttributeError: 'str' object has no attribute 'append'` 메시지와 함께 오류가 발생합니다.

## Python에서 좋은 디버깅 기법

- **`print` 함수 사용**: 디버깅 중 코드 여러 지점에 `print()` 문을 삽입해 변수 값과 코드 흐름을 확인할 수 있습니다.
- **Python 내장 디버거 (`pdb`) 사용**: Python은 `pdb` 모듈을 제공합니다. 표준 라이브러리의 일부로 항상 사용할 수 있습니다. `pdb`를 사용하면 `set_trace()` 함수로 추적을 설정해 대화형으로 코드를 단계별 실행하며 변수 상태를 검사할 수 있습니다.
- **IDE 디버깅 도구 활용**: Pycharm, VS Code 같은 통합 개발 환경과 코드 편집기는 중단점, 단계 실행, 변수 검사 등 디버깅 기능을 제공합니다.

## 예외 처리

- **`try...except`**: 예외가 발생할 수 있는 코드 블록을 실행할 때 사용합니다. `try` 블록은 오류가 발생할 수 있는 코드를 포함하고, `except` 블록은 지정한 예외가 발생하면 실행됩니다. 예:

  ```py
  try:
    print(22 / 0)
  except ZeroDivisionError:
    print('You can\'t divide by zero!')
    # You can't divide by zero!
  ```

  여러 `except` 블록을 연결해 다양한 예외를 처리할 수도 있습니다:

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

- **`else` 와 `finally`**: 이 블록들은 `try...except`를 확장합니다. 예외가 없으면 `else` 블록이 실행되고, `finally` 블록은 오류 여부와 상관없이 항상 실행됩니다.

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **예외 객체**: 예외 자체에 접근해 디버깅과 직접적인 오류 메시지 출력을 할 수 있습니다. 예외 객체에 접근하려면 `as` 키워드를 사용합니다. 예:

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **`raise` 문**: 수동으로 예외를 발생시킬 때 사용합니다. 특정 조건이 충족되면 예외를 발생시키는 데 쓸 수 있습니다. 예:

  ```py
  def divide(a, b):
      if b == 0:
          raise ZeroDivisionError('You cannot divide by zero')
      return a / b
  ```
  
## 예외 신호 보내기
  
  `raise` 문은 사용자 정의 예외를 만들 때도 유용하며, 사용자 정의 메시지와 함께 예외를 발생시킬 수 있습니다. 예:

  ```py
  class InvalidCredentialsError(Exception):
      def __init__(self, message="Invalid username or password"):
          self.message = message
          super().__init__(self.message)

  def login(username, password):
      stored_username = "admin"
      stored_password = "password123"
      
      if username != stored_username or password != stored_password:
          raise InvalidCredentialsError()
      
      return f"Welcome, {username}!"
  ```  

  다음은 `login` 함수와 `InvalidCredentialsError` 예외를 사용하는 방법입니다:

  ```py
  # failed login attempt
  try:
      message = login("user", "wrongpassword")
  except InvalidCredentialsError as e:
      print(f"Login failed: {e}")
  else:
      print(message)

  # successful login attempt
  try:
      message = login("admin", "password123")
  except InvalidCredentialsError as e:
      # This block is not executed because the login was successful
      print(f"Login failed: {e}")
  else:
      # The else block runs if the 'try' block completes without an exception
      print(message)
  ```

  `raise` 문은 `from` 키워드와 함께 사용해 예외를 연결할 수 있으며, 서로 다른 오류 간의 관계를 보여줍니다:

  ```py
  def parse_config(filename):
    try:
        with open(filename, 'r') as file:
            data = file.read()
            return int(data)
    except FileNotFoundError:
        raise ValueError('Configuration file is missing') from None
    except ValueError as e:
        raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```
