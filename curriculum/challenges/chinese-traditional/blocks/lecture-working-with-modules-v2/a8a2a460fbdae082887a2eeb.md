# --description--

在軟體開發中，函式庫就像是開發者的工具箱。

函式庫提供你預先撰寫且可重複使用的程式碼，例如函式（程式）、類別和資料結構，讓你不必從頭實作程式碼的每一個零件，並能在你的專案中使用。

Python 標準程式庫是隨 Python 一起包含的模組和軟體包群集。第三方軟體包是獨立開發的，通常需要先安裝才能使用。標準程式庫提供常見程式設計任務的解決方案，例如：

* 與作業系統互動。

* 處理檔案。

* 網路。

* 處理日期和時間。

* 執行數學操作。

* 使用正規表達式。

* 測試和偵錯你的程式碼。

* 還有更多！

一些標準程式庫模組的例子有 `math`、`random`、`re`（「regular expressions」的縮寫）和 `datetime`。

`math` 模組具有用於執行更複雜數學操作的有用函式（程式）。

`random` 模組有助於產生隨機數。

`re` 模組用於處理正規表達式。

`datetime` 模組對於在 Python 中處理日期和時間非常有幫助。

模組可以提供類別，也可以提供函式和常數。這裡是一個來自 `datetime` 模組的類別範例。我們創建一個代表 1959 年 7 月 15 日的日期物件。接著，我們將該 `date` 物件指定給一個變數，並使用點記法個別存取日、月和年：

```python
import datetime
birthday = datetime.date(1959, 7, 15)
print(birthday.day)    # 15
print(birthday.month)  # 7
print(birthday.year)   # 1959
```

要尋找特定任務的模組，請瀏覽 [Python 標準程式庫參考](https://docs.python.org/3/library/index.html)，模組會依主題分組。每個模組的文件說明它提供什麼以及如何使用。例如，[`datetime` 文件](https://docs.python.org/3/library/datetime.html)描述了用於處理日期和時間的類別和方法。

你也可以使用 `help()` 函式來顯示模組或函式的文件。請注意，`help()` 目前在 freeCodeCamp 編輯器中無法使用。

例如，這段程式碼會顯示關於 `math` 模組的資訊：

```py
import math
help(math)
```

以下是輸出的一部分摘錄：

```md

    math

DESCRIPTION
    This module provides access to the mathematical functions
    defined by the C standard.

FUNCTIONS
    acos(x, /)
        Return the arc cosine (measured in radians) of x.

...
...
...
```

你也可以取得特定函式的文件：

```py
import math
help(math.comb)
```

這是輸出：

```md
Help on built-in function comb in module math:

comb(n, k, /)
    Number of ways to choose k items from n items without repetition and without order.
    
    Evaluates to n! / (k! * (n - k)!) when k <= n and evaluates
    to zero when k > n.
    
    Also called the binomial coefficient because it is equivalent
    to the coefficient of k-th term in polynomial expansion of the
    expression (1 + x)**n.
    
    Raises TypeError if either of the arguments are not integers.
    Raises ValueError if either of the arguments are negative.
```

要發現模組提供了哪些名稱，你可以使用 `dir()` 函式。它會列出函式，例如用來向下取整數的 `math.floor`，以及常數，例如 `math.e`（歐拉數）和 `math.pi`。它還會列出一些你稍後課程會學到的其他名稱：

```py

print(dir(math))
```
