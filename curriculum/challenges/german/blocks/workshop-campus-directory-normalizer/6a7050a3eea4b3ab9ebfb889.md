# --description--

Zu diesem Zeitpunkt ist `rawData` tief verschachtelt: `departments → programs → instructors`. Um einen Instructor per E-Mail zu finden, müssten Sie durch jede Abteilung, dann jedes Programm und schließlich jeden Instructor iterieren, bis Sie eine Übereinstimmung finden.

Dieser Ansatz funktioniert zwar, wird aber mit wachsendem Datenvolumen langsam und wiederholend.

Später im Workshop lernen Sie, wie Sie die Daten normalisieren, was ein effizienterer Ansatz ist.

Für die nächsten Schritte erstellen Sie jedoch eine Funktion, die eine E-Mail als Argument nimmt, Schleifen verwendet, um die verschachtelte `rawData`-Struktur zu durchsuchen, und den Namen des Instructors zurückgibt, wenn sie eine passende E-Mail-Adresse findet.

Beginnen Sie damit, das `console.log()` aus dem vorherigen Schritt zu löschen.

Deklarieren Sie dann eine Funktion namens `getInstructorByEmail` und verwenden Sie `email` als Parametername. Geben Sie anschließend `null` aus der Funktion zurück.
