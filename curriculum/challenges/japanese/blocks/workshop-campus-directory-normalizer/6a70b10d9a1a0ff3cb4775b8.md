# --description--

`departmentId` を取得したので、それを使って `departmentsById` の中に部署のデータを保存してください。

`departmentsById[departmentId]` に次の内容を含むオブジェクトを代入してください。

`id`: `departmentId` に設定、  
`code`: `departmentData.Dept_code` に設定、  
`name`: `departmentName` に設定、  
`programIds`: 空の配列（後のステップで埋めます）

最後に、`departmentsById[departmentId]` をコンソールにログ出力してください。

globalThis.spy = __helpers.spyOn(console, "log");
const getLogs = () => globalThis.spy.calls.map((call) => call?.[0]);

# --after-each--

assert.match(

そのオブジェクトには `id` プロパティがあり、`departmentId` に設定されている必要があります。

```js
assert.match(
  __helpers.removeJSComments(code),
  /id\s*:\s*departmentId/
);
```

そのオブジェクトには `code` プロパティがあり、`departmentData.Dept_code` に設定されている必要があります。

```js
assert.match(
  __helpers.removeJSComments(code),
  /code\s*:\s*departmentData\s*\.\s*Dept_code/
);
```

そのオブジェクトには `name` プロパティがあり、`departmentName` に設定されている必要があります。

```js
assert.match(
  __helpers.removeJSComments(code),
  /name\s*:\s*departmentName/
);
```

そのオブジェクトには `programIds` プロパティがあり、空の配列に設定されている必要があります。

```js
assert.match(
  __helpers.removeJSComments(code),
  /programIds\s*:\s*\[\s*\]/
);
```

`console.log()` を呼び出し、引数に `departmentsById[departmentId]` を渡してください。

```js
assert.match(
  __helpers.removeJSComments(code),
  /console\s*\.\s*log\s*\(\s*departmentsById\s*\[\s*departmentId\s*\]\s*\)/
);
```

ログに出力される各部署オブジェクトは、期待される `id`、`code`、`name`、および空の `programIds` の値を正しくマッピングしている必要があります。

```js
const expectedDepartments = Object.entries(rawData).map(
  ([departmentName, departmentData], index) => ({
    id: departmentData.Dept_code || `dept-${index + 1}`,
    code: departmentData.Dept_code,
    name: departmentName,
    programIds: [],
  }),
);

assert.deepEqual(getLogs(), expectedDepartments);
```
