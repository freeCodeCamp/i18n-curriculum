# --description--

Prima di lavorare con le letture, devi rimuovere i codici di errore.

Come hai imparato nelle lezioni precedenti, la funzione `filter()` mantiene solo gli elementi di un iterabile per i quali una funzione restituisce un valore truthy. Invece di definire quella funzione con `def`, puoi passare direttamente una funzione lambda a `filter()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

Crea una variabile chiamata `valid_readings`. Assegna a essa il risultato di passare a `filter()` una funzione lambda e `readings`. La funzione lambda deve prendere un parametro chiamato `reading` e verificare se `reading` non è uguale a `-999`.

Poi, stampa `valid_readings` invece di `readings`.
