# --description--

## ¿Por qué instalar Python localmente?

Para todos los talleres y laboratorios, usarás el editor de Python de freeCodeCamp. Pero es importante aprender a configurar Python en tu máquina local.

## Descargar Python

La forma más fácil de instalar Python en Windows y Mac es descargar el instalador desde el sitio oficial de Python. También veremos cómo ejecutar Python en Linux más adelante en esta lección.

Ve a `https://www.python.org/` y pasa el cursor sobre "Downloads". Aparecerá un modal que muestra la versión actual de Python para tu sistema operativo (SO).

## Instalar Python en macOS

Primero veremos cómo instalar Python en una computadora con macOS:

- Haz clic en el botón que muestra la versión actual de Python (del modal anterior) y comenzarás a descargar automáticamente un archivo de instalación `.pkg`.
- Cuando termine de descargarse el instalador `.pkg`, ábrelo y haz clic en "Continuar" en la ventana que se abre.
- Sigue haciendo clic en el botón "Continuar" hasta llegar a la sección "Tipo de instalación". Allí, haz clic en el botón "Instalar".
- Ingresa tu contraseña si es necesario y comienza la instalación.
- Cuando termine la instalación del paquete, deberías ver un mensaje que indica que Python se instaló correctamente.
- Abre la carpeta de Python recién creada en tu directorio de Aplicaciones.
- Haz doble clic en el archivo `Install Certificates.command` y permite que el proceso en la terminal termine.
- Verifica que aparezcan en la ventana de la terminal los mensajes `Successfully installed certifi` y `update complete`.
- Cierra la ventana de la terminal y haz clic en "Cerrar" en la ventana del instalador. ¡Tu configuración ya está completa!

## Verificar la instalación

Puedes verificar la instalación abriendo tu terminal y ejecutando `python --version` o `python3 --version`.

También puedes abrir el intérprete de Python ejecutando `python` o `python3` en la terminal. Un intérprete de Python es un programa que lee código Python, lo traduce en instrucciones que la computadora entiende y ejecuta esas instrucciones.

## ¿Qué es un terminal?

Un <dfn>terminal</dfn> es una interfaz basada en texto que te permite interactuar con tu computadora escribiendo comandos. Cada sistema operativo viene con una app de terminal predeterminada. En macOS, puedes usar la app Terminal. En Windows, puedes usar Command Prompt o PowerShell. En Linux, cada entorno de escritorio tiene su propia app de terminal predeterminada, como GNOME Terminal o Konsole.

## Usar `python` vs. `python3`

Ten en cuenta que, en algunos sistemas macOS y Linux antiguos, `python` puede estar reservado para Python 2, mientras que `python3` es para Python 3 específicamente. Si ejecutas `python --version` y ves una versión de Python 2 como `Python 2.7.18`, entonces es posible que tu SO dependa de algún software escrito en la versión antigua de Python. En ese caso, deberías usar `python3` para ejecutar tu código Python de ahora en adelante. Python 2 está en fin de vida y no debe usarse para ningún desarrollo nuevo.

## Instalar Python en Windows

Para instalar Python en Windows, sigue estos pasos:

- Ve a `https://www.python.org/` y pasa el cursor sobre "Downloads". Deberías ver un modal que dice "Download for Windows" y un botón de descarga con la versión actual de Python.
- Haz clic en el número de versión y comenzarás a descargar automáticamente el Administrador de instalación de Python (paquete `.msix`).
- Cuando termines de descargar el Administrador de instalación de Python, haz doble clic en él y selecciona "Instalar".
- Después de la instalación, los comandos `python`, `py` y `pymanager` deberían estar disponibles. Si no hay un runtime de Python instalado, ejecutar `python` instalará uno automáticamente.
- Cuando instales un runtime por primera vez, puede que te pidan agregar un directorio a tu `PATH` para alias adicionales, como `python3.14.exe`. Acepta este aviso opcional si quieres usar esos alias.


Puedes verificar la instalación abriendo una consola de comandos como PowerShell y ejecutando `python --version`. También puedes abrir el intérprete de Python ejecutando `python`.

## Instalar Python en Linux

Para Python en Linux, la mayoría de las distribuciones principales como Ubuntu, Debian y Fedora ya incluyen Python.

Solo abre una terminal y ejecuta `python --version` o `python3 --version`.

Si ninguno de los comandos muestra una versión de Python 3, puedes buscar un paquete de instalación para tu distribución de Linux en `https://www.python.org` o buscar en línea la forma recomendada de instalar Python para tu distro.
