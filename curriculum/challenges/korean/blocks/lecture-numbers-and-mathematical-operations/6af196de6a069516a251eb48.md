# --description--

때때로 숫자는 계산에는 문제가 없지만 출력할 때는 조금 미완성처럼 보일 수 있습니다. 예를 들어 가격을 표시할 때 `12.50`이 `12.5`보다 더 자연스럽게 느껴질 수 있습니다.

f-문자열은 원래 값을 변경하지 않고 숫자가 표시되는 방식을 제어할 수 있어서 계산에 계속 사용할 수 있게 해줍니다.

## 포맷 지정자가 작동하는 방식

표현식 `f"{value:.2f}"`는 `value`를 소수점 아래 정확히 두 자리까지 표시합니다.

중괄호 안의 각 문자는 특정 역할을 합니다:

- 콜론 `:`은 포맷 지정자를 시작합니다
- `.2`는 소수점 이하 두 자리를 선택합니다
- `f`는 고정 소수점 표기를 선택하여 숫자를 십진법으로 표시합니다.

즉, `print(f"{12.5:.2f}")`는 `12.50`을 출력하지만 원래 값은 변경하지 않습니다:

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

출력 결과가 `12.50`인 이유는 `.2f` 포맷 지정자가 항상 소수점 이하 두 자리를 표시해서 Python이 결과에 0을 덧붙이기 때문입니다. `value`에 저장된 값은 여전히 `12.5`입니다.


반면에 `12.3456` 같은 값을 `.2f`로 포맷하면 표시를 위해 숫자가 반올림되어 `12.35`가 됩니다:

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## F-문자열 포맷은 문자열을 생성합니다

f-문자열은 문자열을 생성합니다:

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

즉, 결과 문자열을 따로 저장할 수 있고 원래 숫자는 계산에 계속 사용할 수 있습니다.

## `round()`와 F-문자열 포맷의 차이점

`round(value, 2)` 같은 표현식은 추가 계산에 사용할 수 있는 숫자 결과를 제공합니다.

그 결과를 출력할 때는 Python의 일반적인 숫자 표시 방식을 사용하므로 끝에 0이 붙는 것이 보장되지 않습니다:

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## 포맷은 기본 값을 변경하지 않습니다

앞서 봤듯이 `0.1`과 `0.2` 같은 일부 십진수는 부동소수점으로 근사할 수밖에 없습니다. 그래서 이들의 합을 직접 출력하면 약간 놀라운 결과가 나올 수 있습니다:

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

보시다시피 f-문자열은 표시를 위해 합계를 반올림합니다. `total`을 사용하는 계산은 여전히 같은 부동소수점 값을 사용합니다.
