# --description--

In questo workshop, eserciterai a lavorare con le liste pianificando il programma di un concerto d'orchestra.

Come hai imparato nelle lezioni precedenti, una lista è una raccolta ordinata di elementi. Crei una lista inserendo elementi separati da virgole all'interno di parentesi quadre:

```py
fruits = ['apple', 'banana', 'cherry']
```

Crea una variabile chiamata `pieces` e assegnale una lista contenente le stringhe `Carnival Overture`, `Song to the Moon` e `Silent Woods`, in questo ordine.
