# --description--

Às vezes um número serve para seus cálculos mas parece um pouco incompleto quando você o imprime. Se você estiver mostrando um preço, por exemplo, `12.50` pode parecer mais natural do que `12.5`.

Uma f-string permite controlar como um número aparece quando exibido, sem alterar o valor original, para que você possa continuar usando ele nos cálculos.

## Como funcionam as especificações de formato

A expressão `f"{value:.2f}"` exibe `value` com exatamente dois dígitos após o ponto decimal.

Dentro das chaves, cada caractere tem um papel específico:

- O dois-pontos `:` introduz a especificação de formato
- `.2` seleciona duas casas decimais
- `f` seleciona a apresentação em ponto fixo, que exibe o número em notação decimal.

Isso significa que `print(f"{12.5:.2f}")` produz `12.50`, enquanto mantém o valor inicial inalterado:

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

A saída mostra `12.50` porque a especificação de formato `.2f` sempre exibe duas casas decimais, então o Python completa o resultado com um zero à direita. O valor armazenado em `value` ainda é `12.5`.


Por outro lado, formatar um valor como `12.3456` com `.2f` produz `12.35`, porque o número precisa ser arredondado para exibição:

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## Formatar com uma f-string produz uma string

Uma f-string produz uma string:

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

Isso significa que você pode salvar a string resultante separadamente e ainda usar o número original nos cálculos.

## Como `round()` difere da formatação com f-string

Uma expressão como `round(value, 2)` te dá um resultado numérico que você pode usar em cálculos posteriores.

Imprimir esse resultado usa a exibição usual de números do Python, então zeros à direita não são garantidos:

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## A formatação não altera o valor subjacente

Como você viu antes, alguns números decimais como `0.1` e `0.2` só podem ser aproximados como floats. Portanto, a soma deles pode parecer um pouco surpreendente quando impressa diretamente:

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

Como você pode ver, a f-string arredonda a soma para exibição. Qualquer cálculo que use `total` ainda usa o mesmo valor de ponto flutuante.
