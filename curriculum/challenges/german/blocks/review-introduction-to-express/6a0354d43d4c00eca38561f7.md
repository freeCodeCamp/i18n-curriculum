## Was ist Express.js?

- **Express**: Ein minimalistisches und flexibles Webframework, das auf Node.js aufbaut und das Erstellen von Webservern und APIs erleichtert.
- **Express installieren**: `npm install express`
- **Was Sie mit Express bauen können**: Webanwendungen, RESTful APIs, SPA-Backends, middleware-lastige Dienste und alles Serverseitige mit HTTP.
- **Middleware**: Code, der zwischen dem Empfang einer Anfrage und dem Senden einer Antwort ausgeführt wird. Wird für Fehlerbehandlung, Eingabevalidierung, Modifikation von Anfrage- oder Antwortdaten und mehr verwendet. Mehrere Middleware-Funktionen können hintereinander geschaltet werden.
- **Plugins**: Externe npm-Module, die Express erweitern, meist als Middleware implementiert.

## Erstellen einer einfachen Express-Anwendung

```javascript
const express = require("express");
const app = express();
const port = 3000;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Example app listening on port ${port}`);
});
```

- `require("express")` — lädt die Express-Bibliothek.
- `express()` — Fabrikfunktion, die eine neue Express-Anwendungsinstanz erstellt und zurückgibt.
- `app` — das Hauptserverobjekt mit Zugriff auf Methoden wie `.get()`, `.post()` und `.listen()`.
- `port` — der Netzwerkendpunkt, auf dem die Anwendung lauscht. Port `3000` ist üblich für lokale Entwicklung.
- `app.listen(port, callback)` — startet den Server und beginnt, eingehende HTTP-Anfragen zu empfangen.

## Routing in Express

- **Route**: Eine Regel, die der Anwendung sagt, wie sie reagieren soll, wenn ein Client eine bestimmte URL mit einer bestimmten HTTP-Methode anfragt.
- **Routenmethoden**: `app.get()`, `app.post()`, `app.put()`, `app.delete()` — jede behandelt Anfragen mit der passenden HTTP-Methode.
- **Statischer Routenpfad**: Eine feste URL wie `/home` oder `/menu/drinks`.
- **Dynamischer Routenpfad (Routenparameter)**: Ein Platzhalter in der URL, der einen Wert erfasst, mit `:` als Präfix, zum Beispiel `/post/:postId`.
- **`req.params`**: Ein Objekt, das die dynamischen Werte enthält, die aus der URL erfasst wurden. Zum Beispiel liefert eine Anfrage an `/post/42` `req.params.postId === "42"`.

### Routen-Handler

- Ein **Routen-Handler** ist die Callback-Funktion `(req, res) => { ... }`, die ausgeführt wird, wenn eine Anfrage zu einer Route passt.
- `req` — enthält Informationen über die eingehende Anfrage (Parameter, Abfragezeichenfolgen, Kopfzeilen, Body).
- `res` — wird verwendet, um eine Antwort an den Client zu senden.

## Antwortmethoden

| Methode | Was sie macht |
| --- | --- |
| `res.send()` | Sendet eine Antwort — Klartext, HTML, JSON oder Binärdaten. |
| `res.json()` | Sendet eine JSON-Antwort; wandelt automatisch ein JavaScript-Objekt um. |
| `res.status(code)` | Setzt den HTTP-Statuscode; wird meist mit `res.send()` oder `res.json()` verkettet. |
| `res.redirect(url)` | Leitet den Client zu einer anderen URL um. |
| `res.render(view, data)` | Rendert eine Template-Engine-Ansicht und sendet das resultierende HTML. |

## Verkettbare Routen-Handler mit `app.route()`

- `app.route(path)` gruppiert mehrere HTTP-Methoden-Handler für denselben Pfad, um Wiederholungen zu vermeiden.

```javascript
app
  .route("/user")
  .get((req, res) => { res.send("Fetching user data"); })
  .post((req, res) => { res.send("Creating a user"); })
  .put((req, res) => { res.send("Updating the user"); })
  .delete((req, res) => { res.send("Deleting the user"); });
```

## Modulares Routing mit `express.Router()`

- `express.Router()` erstellt ein Router-Objekt — wie eine Mini-Express-Anwendung — auf dem Sie Routen definieren und dann in der Hauptanwendung einbinden können.
- Einen Router binden Sie mit `app.use(path, router)` ein. Die Routen im Router sind relativ zum Einbindungspfad.
- **Vorteile**: Trennt Verantwortlichkeiten, hält die Hauptdatei sauber und macht Routen wiederverwendbar und leichter skalierbar.

```javascript
// userRoutes.js
const express = require("express");
const router = express.Router();
router.get("/", (req, res) => { res.send("List of users"); });
router.get("/:id", (req, res) => { res.send(`User ${req.params.id}`); });
module.exports = router;

// app.js
app.use("/users", userRoutes); // mounts the router at /users
```

## Statische Dateien bereitstellen

- **Statische Dateien**: Ressourcen wie Bilder, CSS und clientseitiges JavaScript, die direkt ohne serverseitige Verarbeitung ausgeliefert werden.
- `express.static(directory)` — eingebaute Middleware, die Dateien aus einem angegebenen Ordner bereitstellt.
- Wenn eine angeforderte Datei nicht gefunden wird, antwortet Express automatisch mit einem 404.
- Für einzelne statische Dateien sind keine Routen-Definitionen nötig.

```javascript
app.use(express.static(path.join(__dirname, "public")));
```

- Sie können aus mehreren Verzeichnissen bereitstellen, indem Sie `app.use()` mehrfach aufrufen, optional mit einem Einbindungspfad:

```javascript
app.use(express.static(path.join(__dirname, "public")));
app.use("/images", express.static(path.join(__dirname, "images")));
```
