# --description--

要捕捉并处理来自你的 `try` 块的误差，你需要添加一个 `catch` 块。你可以为这个块声明一个参数，以检查被抛出的实际误差对象。

```js
try {
  // Code that might throw an error
} catch (err) {
  // Code to handle the error
}
```

在你的 `try` 块正下方，添加一个带有名为 `err` 参数的 `catch` 块。在该块内，通过将 `statusDisplay` 的 `textContent` 设置为 `err.message` 来更新 DOM。
