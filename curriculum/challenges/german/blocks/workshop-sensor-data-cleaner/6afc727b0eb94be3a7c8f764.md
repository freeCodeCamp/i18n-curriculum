# --description--

Die `map()`-Funktion ruft eine Funktion für jedes Element eines iterierbaren Objekts auf und gibt einen Iterator mit den Ergebnissen zurück. Wie bei `filter()` können Sie ihr eine Lambda-Funktion übergeben:

```py
prices = [10, 20, 30]
discounted = list(map(
    lambda price: price * 0.9,
    prices
))
print(discounted) # [9.0, 18.0, 27.0]
```

Jetzt müssen Sie die gültigen Messwerte von Zehntelgraden in Grad umrechnen.

Erstellen Sie eine Variable namens `temperatures`. Weisen Sie ihr das Ergebnis zu, das entsteht, wenn Sie `map()` eine Lambda-Funktion und `valid_readings` übergeben, eingehüllt in einen `list()`-Aufruf. Die Lambda-Funktion soll einen Parameter namens `reading` haben und `reading` geteilt durch `10` zurückgeben.

Geben Sie dann `temperatures` statt `valid_readings` aus.
