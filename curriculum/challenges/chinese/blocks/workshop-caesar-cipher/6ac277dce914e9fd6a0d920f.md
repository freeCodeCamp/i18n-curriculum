# --description--

在 Python 中，`bool` 是 `int` 的子类，其中 `True` 表现得像 `1`，`False` 表现得像 `0`。这意味着 `isinstance()` 会将布尔值视为整数：

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True
```

因此，你的函数当前接受 `True` 和 `False` 作为 shift 值。

使用 `or` 操作符为你的 `if` 语句添加第二个条件，使用 `isinstance(shift, bool)` 检查 `shift` 是否为布尔值。这样，当 `shift` 是 `True` 或 `False` 时，你的函数也会返回 `Shift must be an integer value.`。
