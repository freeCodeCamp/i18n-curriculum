# --interactive--

`text-decoration` 속성은 텍스트에 장식선을 추가할 수 있게 해줍니다.

초기값이 `none`으로 설정되어 있어, 브라우저가 링크에 기본으로 추가하는 밑줄을 제거할 때 주로 사용됩니다.

```css
a {
  text-decoration: none;
}
```

주로 링크에 사용되지만, `text-decoration`은 다른 텍스트에도 장식을 추가할 수 있습니다.

## `text-decoration` 속성의 다른 값들

`none`을 제외한 `text-decoration` 속성의 다른 값들은 다음과 같습니다:

- `underline`
- `overline`
- `line-through`

값 이름이 의미하듯이, `underline`은 텍스트 아래에 선을 추가하고, `overline`은 텍스트 위에 선을 추가하며, `line-through`는 텍스트 중간에 선을 추가해 텍스트를 취소선처럼 만듭니다.

## `text-decoration` 속성에 대해 더 알아보기

`text-decoration` 속성은 실제로 다음 속성들을 결합한 단축 속성입니다:

- `text-decoration-line`: `none`, `underline`, `overline`, `line-through`
- `text-decoration-color`: 선의 색상
- `text-decoration-style`: `solid`, `double`, `dotted`, `dashed`, 또는 `wavy`
- `text-decoration-thickness`: 선의 두께

예를 들어, 이것은 단락에 빨간색 물결선 장식을 추가합니다:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>This is an error</p>
```

```css
p {
  text-decoration: underline wavy red 2px;
}
```

:::

이것은 단락에 초록색 이중 오버라인을 추가합니다:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<p>There's a double overline on this text</p>
```

```css
p {
  text-decoration: overline double green 2px;
}
```

:::

원한다면 선 유형을 조합할 수도 있습니다:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css" />

<h2>This subheading has both an underline and overline</h2>
```

```css
h2 {
  text-decoration: underline overline;
}
```

:::
