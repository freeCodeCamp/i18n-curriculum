## 数组

- **静态数组**：大小在初始化时确定。元素存储在相邻的内存位置，这使得访问非常高效。程序运行时大小不可更改。

- **动态数组**：程序运行时可以自动增长或缩小。当数组满时，其元素会被复制到一个新的、更大的数组中。新大小的选择使得这些昂贵的复制操作发生得更少。

- **Python 中的静态数组**：Python 不包含传统的静态数组作为内置数据结构。其他语言，如 Java，支持静态数组。

### Python 列表（动态数组）

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### 动态数组的时间复杂度

- **访问**：O(1)
- **末尾插入**：如果有空间，O(1)；需要调整大小时，O(n)
- **中间插入**：O(n)，因为后面的元素需要重新定位

### 静态数组与动态数组的选择

- **静态数组**：当你提前知道元素数量且需要频繁访问时。
- **动态数组**：当元素数量未知或随时间变化，或者你会频繁插入和删除元素时。

## 栈

- **栈**：后进先出（LIFO）数据结构。栈有两个端，顶部和底部。元素只能从顶部添加和移除。

- **入栈操作**：将元素添加到栈顶。使用 Python 列表时，如果有空间，耗时 O(1)；需要调整大小时，耗时 O(n)。

- **出栈操作**：从栈顶移除元素。时间复杂度：O(1)。空间复杂度：O(1)。

```python
# Using a Python list as a stack, where the end of the list is the top
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operation
top_element = stack.pop()  # Returns 3
```

## 队列

- **队列**：先进先出（FIFO）数据结构。队列有两个端，前端和后端。元素从后端添加，从前端移除。

- **入队操作**：将元素添加到队列后端。使用 Python 列表时，如果有空间，耗时 O(1)；需要调整大小时，耗时 O(n)。

- **出队操作**：从队列前端移除元素。下一元素成为新的前端。时间复杂度：O(1)。空间复杂度：O(1)。

```python
# Using a Python list as a queue, where the start of the list is the front
queue = []

# Enqueue operations
queue.append(1)
queue.append(2)
queue.append(3)

# Front element
front_element = queue[0]  # 1

# Dequeue operation
front_element = queue.pop(0)  # Returns 1
```

- **注意**：使用 `.pop(0)` 移除 Python 列表的第一个元素会重新定位所有剩余元素，因此耗时为 O(n)。

## 链表

- **链表**：线性数据结构，每个节点存储数据和指向下一个节点的引用。节点像链条一样连接。链表没有固定大小，可以通过更新节点之间的连接来增长或缩小。

- **常见用途**：实现其他数据结构，如栈、队列和双端队列，以及图算法，如深度优先搜索和广度优先搜索。

### 单链表

- **结构**：每个节点存储数据和一个指向下一个节点的引用。
- **遍历**：只能向前移动，从头到尾。
- **头节点**：列表中的第一个节点，通常是唯一可直接访问的节点。遍历从这里开始。
- **尾节点**：列表中的最后一个节点。它指向下一个节点的引用为 `None`，标志着列表的结束。

#### 插入节点

- **开头插入**：O(1) - 将新节点连接到旧头节点，并使其成为新头节点
- **末尾插入**：O(n) - 必须遍历到末尾，然后将尾节点连接到新节点
- **中间插入**：O(n) - 必须遍历到指定位置，然后将前一个节点连接到新节点，新节点连接到下一个节点
- **空间复杂度**：O(1) - 只创建新节点

#### 删除节点

- **开头删除**：O(1) - 使下一个节点成为新头节点
- **中间删除**：O(n) - 必须遍历到该节点，然后将前一个节点连接到下一个节点，形成跨越被删除节点的“桥梁”
- **末尾删除**：O(n) - 必须遍历到末尾，然后移除前一个节点的连接，使其成为新尾节点
- **空间复杂度**：O(1) - 不需要额外内存

### 双链表

- **结构**：每个节点存储数据和两个引用：一个指向下一个节点，一个指向上一个节点。
- **遍历**：可以双向移动。
- **尾部引用**：通常在链表中保留对尾节点的引用。这允许在 O(1) 时间内在末尾添加节点，无需遍历列表，并且可以从末尾开始遍历。
- **插入和删除**：与单链表相同，但每个节点需要更新两个引用。
- **内存**：比单链表需要更多内存，因为每个节点存储两个引用而不是一个。

## 何时使用各数据结构

- **静态数组**：当元素数量提前已知且需要快速、频繁访问时
- **动态数组（列表）**：当你需要有序、索引访问且大小未知时
- **栈**：当最后添加的元素应最先移除（LIFO）时
- **队列**：当元素应按添加顺序处理（FIFO）时
- **单链表**：当大小经常变化且主要在开头插入和删除时
- **双链表**：当你需要双向遍历或高效地在末尾添加元素，且每个节点额外内存可接受时
