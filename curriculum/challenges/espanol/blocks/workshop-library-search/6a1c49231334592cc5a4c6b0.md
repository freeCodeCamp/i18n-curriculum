# --description--

¡Genial! Sin embargo, si tu función `findBook` lanza un error, el resto del código en tu listener de evento no se ejecutará porque no hay nada que lo capture.

Para manejar estos errores de forma elegante, necesitas envolver el código que podría fallar dentro de un bloque `try`.

```js
try {
  // Code that might throw an error
}
```

Mira el listener de evento `searchBtn` al final del archivo. Envuelve el código existente en esa función callback dentro de un bloque `try`.

**Nota:** Ignora la línea roja de error debajo de las llaves. La corregirás en el siguiente paso.

  }

  return title + " is available to borrow!";
};
