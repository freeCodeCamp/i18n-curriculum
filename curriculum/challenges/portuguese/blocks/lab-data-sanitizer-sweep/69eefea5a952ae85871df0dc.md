# --description--

Neste laboratório, você vai limpar arquivos de log semi-estruturados substituindo caracteres não permitidos por `#` e acompanhando quantas entradas foram processadas.

**Objetivo:** Cumprir as user stories abaixo e fazer todos os testes passarem para completar o laboratório.

**Histórias de Usuário:**

1. Você deve usar uma declaração de função para criar uma função chamada `sanitizeLog` com dois parâmetros: `entry`, uma string que representa uma entrada de log, e `disallowedCharacters`, um array de strings de um único caractere que representam os caracteres a serem substituídos.
1. A função deve retornar uma string `entry` modificada com cada caractere não permitido substituído por `#`. A correspondência deve ser sensível a maiúsculas e minúsculas. Por exemplo, se os caracteres não permitidos forem `["e", "E", "o", "r"]`, então `DEBUG: Server started on port 3000` retorna `D#BUG: S##v## sta#t#d #n p##t 3000`.
1. Você deve criar uma função chamada `cleanLogs` com dois parâmetros: `logs`, um array de strings que representam entradas de log, e `disallowedCharacters`, um array de strings de um único caractere que representam os caracteres a serem substituídos.
1. `cleanLogs` deve iterar sobre o array dado de entradas de log na ordem.
1. Quando `cleanLogs` encontrar uma entrada de log que contenha o marcador fatal `$`, deve parar e retornar `Sanitizing stopped. Failure Reason: Fatal character occurred.`
1. Uma entrada de log que começa com o caractere `/` é uma entrada informativa e não deve ser sanitizada. Você deve manter a contagem das entradas informativas.
1. Todas as outras entradas de log devem ser sanitizadas usando a função `sanitizeLog`. Você deve manter a contagem das entradas sanitizadas.
1. Se `cleanLogs` terminar sem encontrar um marcador fatal, deve retornar `Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.`, onde `X` é o número total de entradas, `Y` é o número de entradas sanitizadas e `Z` é o número de entradas informativas.

**Os seguintes arrays de logs são usados nos testes:**

```js
let logs_1 = [
  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"
];

let logs_2 = [
  "FATAL: System overload detected, shutting down",
  "DEBUG: token=def456$ refreshed for session",
  "ERROR: Null pointer exception in module auth"
];

let logs_3 = [
  "ERROR: Failed to connect to db, retry=3",
  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
