## O que é Python?

- **Python**: Python é uma linguagem de programação de uso geral conhecida por sua simplicidade e facilidade de uso.
- **Casos de uso comuns**: Python é usado em ciência de dados, aprendizado de máquina, desenvolvimento web, cibersegurança, sistemas embarcados e IoT, scripts, automação e microcomputadores como Raspberry Pi e placas compatíveis com MicroPython.

## Variáveis

- **Declaring Variables**: Para declarar uma variável, comece com o nome da variável, seguido do operador de atribuição (`=`) e logo depois, do valor. Isto pode ser um número, string, boolean, etc. Aqui estão alguns exemplos:

```py
name = 'John Doe'
age = 25
```

- **Convenções de Nomenclatura para Variáveis**: Aqui estão as convenções de nomenclatura que você deve usar para variáveis:

  - Nomes de variáveis só podem começar com uma letra ou um underscore (`_`), não com um número.
  - Nomes de variáveis podem conter letras (`a-z`, `A-Z`), dígitos (`0-9`) e underscores (`_`).
  - Nomes de variáveis são sensíveis a maiúsculas e minúsculas: `age`, `Age` e `AGE` são considerados únicos.
  - Nomes de variáveis não podem ser palavras-chave reservadas do Python, como `if`, `class` ou `def`.
  - Nomes de variáveis com múltiplas palavras usam underscores, como em `snake_case`.
  - Nomes de variáveis devem descrever seu propósito, como em `user_age`.
  - Nomes de variáveis com uma única letra devem ser evitados quando não comunicam significado.

## Comments

- **Comentários de linha única**: Esse tipo de comentário deve ser usado para notas curtas no seu código.

```py
# This is a single line comment
```

- **Comentários multilinha**: Você pode usar um `#` no início de cada linha para criar comentários em várias linhas.

```py
# This is a multi-line comment.
# Here is some code commented out.
#
# name = 'John Doe'
# age = 25
```

## Imprimindo

- **Função `print()`**: Para imprimir dados no terminal, você pode usar a função `print()` assim:

```py
print('Hello world!') # Hello world!
```

Você pode passar múltiplos argumentos para `print()` separando-os por vírgulas. Por padrão, `print()` insere um espaço entre os valores exibidos:

```py
print('Hello', 'world!') # Hello world!
```

## Tipos Comuns de Dados em Python

- **Tipagem dinâmica**: Python é uma linguagem de tipagem dinâmica, o que significa que você não precisa declarar o tipo de dado de uma variável. Python determina o tipo a partir do valor atribuído à variável.

- **Inteiro**: Um número inteiro sem decimais:

```py
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- **Float**: Um número com decimais:

```py
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- **String**: Uma sequência de caracteres envolvida por aspas:

```py
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- **Booleano**: Um valor que representa `True` ou `False`:

```py
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python tem outros tipos de dados. Você aprenderá cada um quando precisar deles pela primeira vez.

- **Função `type()`**: Para ver o tipo de uma variável, você pode usar a função `type()` assim:

```py
greeting = 'Hello there!'
age = 21

print(type(greeting)) # <class 'str'>
print(type(age)) # <class 'int'>
```

- **Função `isinstance()`**: Isso é usado para verificar se uma variável corresponde a um tipo de dado específico:

```py
greeting = 'Hello world'
name = 'John Doe'

print(isinstance(greeting, str)) # True
print(isinstance(name, int)) # False
```

Para verificar contra mais de um tipo, coloque os tipos entre parênteses, separados por vírgulas, e passe-os como segundo argumento. O resultado é `True` se o valor for uma instância de qualquer tipo listado:

```py
account_balance = 12
print(isinstance(account_balance, (int, float))) # True
```

## Trabalhando com Strings

- **Strings**: Strings são sequências de caracteres. Em Python, você pode usar aspas simples ou aspas duplas. Escolha um estilo e use-o consistentemente:

```py
developer = 'Jessica'
city = "Los Angeles"
```

- **Strings multilinha**: Aspas simples triplas ou aspas duplas triplas permitem que uma string ocupe várias linhas:

```py
message = """Hello
world!"""
print(message)
# Hello
# world!
```

- **Aspas dentro de strings**: Você pode usar o tipo de aspas oposto ao redor de uma string para evitar escapar suas aspas:

```py
msg = "It's a sunny day"
quote = 'She said, "Hello!"'
```

- **Escapando Strings**: Você pode usar uma barra invertida (`\`) se sua string contiver aspas assim:

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **Sequências de escape**: Uma barra invertida combinada com outro caractere pode representar um caractere especial. Por exemplo, `\n` representa uma nova linha, `\t` representa uma tabulação e `\\` representa uma única barra invertida:

```py
print('Hello\nworld')
# Hello
# world

print('Name:\tAlice')  # Name:   Alice
print('C:\\Users\\Alice')  # C:\Users\Alice
```

- **Operador `in`**: Isso retorna um booleano que especifica se o caractere ou os caracteres existem na string ou não:

```py
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

- **Obtendo o comprimento de uma string**: A função `len()` retorna o número de caracteres em uma string:

```py
developer = 'Jessica'

print(len(developer)) # 7
```

- **Acessando Caracteres de Strings**: Você pode acessar caracteres de strings usando a notação de colchetes assim:

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **Reatribuição e imutabilidade**: Strings são imutáveis, o que significa que você não pode alterá-las depois de criadas. Reatribuir uma variável faz com que ela se refira a um valor diferente. Isso não modifica a string original:

```py
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello
```

Modificação direta de uma string não é permitida:

```py
greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```

Inteiros, floats e booleanos também são imutáveis.

- **Concatenação de Strings**: Para concatenar strings, você pode usar o operador `+` assim:

```py
developer = 'Jessica'
print('My name is ' + developer + '.') # My name is Jessica.
```

- **Repetição de strings**: O operador `*` repete uma string um número especificado de vezes:

```py
print('ha' * 3) # hahaha
```

- **Concatenar strings com números**: Concatenar uma string e um número gera um `TypeError`:

```py
'Age: ' + 26 # TypeError: can only concatenate str (not "int") to str
```

A função `str()` converte o número em uma string para que possa ser concatenado:

```py
print('Age: ' + str(26)) # Age: 26
```

Outra forma de concatenar strings é usando o operador `+=`. Isto é usado para realizar concatenação e atribuição na mesma etapa assim:

```py
greeting = 'My name is '
developer = 'Jessica.'

greeting += developer
print(greeting) # My name is Jessica.
```

O operador `*=` repete uma string e atribui o resultado de volta à variável:

```py
sound = 'ha'
sound *= 3
print(sound) # hahaha
```

Tanto `+=` quanto `*=` atribuem uma nova string à variável sem modificar a string original.

- **`f-strings`**: Isso é a abreviação de formatted string literals. Permite que você faça interpolação e também alguma concatenação com uma sintaxe compacta e legível:

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

Campos de substituição em f-strings podem conter expressões. O Python avalia a expressão e insere seu valor na string:

```py
num1 = 5
num2 = 10
print(f'The sum is {num1 + num2}') # The sum is 15
```

- **Fatiamento de String**: Isso é quando você pode extrair partes de uma string. Aqui está a sintaxe básica:

```py
str[start:stop:step]
```

O índice `start` especifica onde a extração começa. O índice `stop` é não inclusivo, então o caractere nesse índice não é incluído. O `step` especifica o intervalo entre os índices selecionados e é `1` por padrão. Com um `step` positivo, um `start` omitido assume o início da string, e um `stop` omitido assume o fim. `[:]` extrai a string inteira. `[::-1]` inverte a string andando para trás do último caractere até o primeiro. O slicing não modifica a string original.

```py
message = 'Python is fun!'

print(message[0:6])  # Python
print(message[:6])  # Python
print(message[7:])  # is fun!
print(message[::2])  # Pto sfn
print(message[:])  # Python is fun!
print(message[::-1])  # !nuf si nohtyP
```

## Métodos Comuns de String

- **Métodos**: Um método é uma função que você chama em um valor. Para chamar um método de string, escreva a string ou o nome da variável seguido de um ponto e a chamada do método.

- **`str.upper()`**: Isso retorna uma nova string com todos os caracteres convertidos para maiúsculas:

```py
developer = 'Jessica'

print(developer.upper()) # JESSICA
```

- **`str.lower()`**: Isso retorna uma nova string com todos os caracteres convertidos para minúsculas:

```py
developer = 'Jessica'

print(developer.lower()) # jessica
```

- **`str.strip()`**: Isso retorna uma cópia da string com os caracteres especificados no início e no fim removidos (se nenhum argumento for passado para o método, ele remove os espaços em branco no início e no fim).

```py
greeting = '  hello world  '

trimmed_my_str = greeting.strip()
print(trimmed_my_str)  # hello world
```

- **`replace()`**: Isso retorna uma nova string com todas as ocorrências da string antiga substituídas por uma nova.

```py
greeting = 'hello world'

replaced_my_str = greeting.replace('hello', 'hi')
print(replaced_my_str)  # hi world
```

- **`split()`**: É usado para dividir uma string em uma lista usando um separador especificado. Um separador é uma string que indica onde a divisão deve ocorrer. Se nenhum separador for especificado, `split()` divide nos espaços em branco.

```py
dashed_name = 'example-dashed-name'

split_words = dashed_name.split('-')
print(split_words)  # ['example', 'dashed', 'name']
```

- **`join()`**: Isso é usado para juntar uma coleção de strings em uma única string com um separador.

```py
example_list = ['example', 'dashed', 'name']

joined_str = ' '.join(example_list)
print(joined_str)  # example dashed name
```

- **`str.startswith(prefix)`**: Isso retorna um booleano indicando se uma string começa com o prefixo especificado:

```py
developer = 'Naomi'

result = developer.startswith('N')
print(result)  # True
```

- **`str.endswith(suffix)`**: Isso retorna um booleano indicando se uma string termina com o sufixo especificado:

```py
developer = 'Naomi'

result = developer.endswith('N')
print(result)  # False
```

- **`str.find()`**: Retorna o índice da primeira ocorrência de uma substring. Se não for encontrada, retorna `-1`:

```py
developer = 'Naomi'

result = developer.find('N')
print(result)  # 0

city = 'Los Angeles'
print(city.find('New')) # -1
```

- **`str.count(substring)`**: Conta quantas vezes uma substring aparece em uma string sem sobreposição. Uma vez que uma correspondência é encontrada, a busca continua após o fim dessa correspondência:

```py
city = 'Los Angeles'
print(city.count('e')) # 2

# Matches do not overlap, so this is 2, not 3
print('aaaa'.count('aa')) # 2
```

- **`str.capitalize()`**: Isso retorna uma nova string com o primeiro caractere em maiúscula e os outros caracteres em minúscula:

```py
dessert = 'chocolate cake'
print(dessert.capitalize()) # Chocolate cake
```

- **`str.isupper()`**: Retorna `True` se a string contiver pelo menos um caractere com caixa e todos os caracteres com caixa forem maiúsculas. Caso contrário, retorna `False`:

```py
dessert = 'chocolate cake'
print(dessert.isupper()) # False
```

- **`str.islower()`**: Retorna `True` se a string contiver pelo menos um caractere com caixa e todos os caracteres com caixa forem minúsculas. Caso contrário, retorna `False`:

```py
dessert = 'chocolate cake'
print(dessert.islower()) # True
```

- **`str.title()`**: Retorna uma nova string com a primeira letra de cada palavra em maiúscula e as demais letras em minúsculas:

```py
city = 'lOS aNGELES'
print(city.title()) # Los Angeles
```

employee_code = 'DEV-2026-JD-001'

## Operações comuns usadas com inteiros e floats

- **Operações matemáticas básicas**: Em Python, você pode fazer operações matemáticas básicas com inteiros e floats, incluindo adição, subtração, multiplicação e divisão:

```py
int_1 = 56
int_2 = 12
float_1 = 5.4
float_2 = 12.0

# Addition

print('Integer Addition:', int_1 + int_2) # Integer Addition: 68
print('Float Addition:', float_1 + float_2) # Float Addition: 17.4

# Subtraction

print('Int Subtraction:', int_1 - int_2) # Int Subtraction: 44
print('Float Subtraction:',  float_2 - float_1) # Float Subtraction: 6.6

# Multiplication

print('Int Multiplication:', int_1 * int_2) # Int Multiplication: 672
print('Float Multiplication:', float_2 * float_1) # Float Multiplication: 64.80000000000001

# Division

print('Division:', int_1 / int_2) # Division: 4.666666666666667
print('Float Division:', float_2 / float_1) # Float Division: 2.222222222222222
```

Quando você adiciona um float e um inteiro, o resultado será convertido para um float assim:

```py
int_1 = 56
float_1 = 5.4

print(int_1 + float_1) # 61.4
```

- **Operador Modulo (`%`)**: Isso retorna o resto quando um número é dividido por outro número:

```py
int_1 = 56
int_2 = 12

print(int_1 % int_2) # 8
```

- **Divisão Inteira (`//`)**: Este operador é usado para dividir dois números e arredondar para baixo o resultado para o número inteiro mais próximo:

```py
int_1 = 56
int_2 = 12

print(int_1 // int_2) # 4
```

- **Operador de Exponenciação (`**`)**: Este operador é usado para elevar um número à potência de outro:

```py
int_1 = 4
int_2 = 2

print(int_1 ** int_2) # 16
```

- **Aproximação de ponto flutuante**: Algumas frações decimais não podem ser representadas exatamente em binário, então são armazenadas como aproximações finitas. Isso pode causar pequenos erros de arredondamento, como o resultado `64.80000000000001` da multiplicação acima.

```py
print(0.1 + 0.2) # 0.30000000000000004
```

- **Função `float()`**: Você pode usar essa função para converter um inteiro ou uma string decimal válida em um float, ou para criar um valor especial de float que representa infinito positivo, que é maior que qualquer inteiro ou float finito:

```py
num = 4

print(float(num)) # 4.0
print(float('7.8')) # 7.8
print(float('inf')) # inf
```

- **Função `int()`**: Você pode usar essa função para converter um float em inteiro.

```py
num = 4.0

print(int(num)) # 4
```

- **Função `round()`**: Com um argumento, arredonda um número para o inteiro mais próximo. Passe um segundo argumento para especificar o número de casas decimais:

```py
num_1 = 3.4
num_2 = 7.7

print(round(num_1)) # 3
print(round(num_2)) # 8
print(round(3.14159, 2)) # 3.14
```

- **Função `abs()`**: Esta é usada para retornar o valor absoluto de um número:

```py
num = -13

print(abs(num)) # 13
```

- **Função `pow()`**: Eleva um número à potência de outro. Com argumentos inteiros, você pode passar um terceiro argumento não zero para calcular o resultado módulo desse valor:

```py
result = pow(2, 3)
print(result)  # 8
print(pow(2, 3, 5)) # 3
```

## Operadores de comparação

print(3 < 4) # True

print(3 <= 4) # True

## Trabalhando com declarações `if`, `elif` e `else`

- **Blocos de código e indentação**: Python usa indentação para agrupar declarações em um bloco, como o corpo de uma função ou condicional. Declarações no mesmo bloco devem usar o mesmo nível de indentação. A convenção é usar quatro espaços para cada nível.

- **Declaração `pass`**: `pass` não faz nada. Use como marcador de posição onde Python exige uma declaração, como em um corpo condicional vazio:

```py
age = 18
if age >= 18:
    pass
```

- **Declarações `if`**: Uma declaração `if` executa seu corpo quando Python trata sua condição como verdadeira.

```py
age = 18

if age >= 18:
    print('You are an adult') # You are an adult
```

- **Cláusula `else`**: Uma cláusula `else` executa seu corpo quando Python trata todas as condições anteriores na mesma cadeia `if...elif...else` como falsas.

```py
age = 12

if age >= 18:
    print('You are an adult')
else:
    print('You are not an adult yet') # You are not an adult yet
```

- **Cláusula `elif`**: Uma cláusula `elif` testa outra condição quando Python trata todas as condições anteriores na mesma cadeia como falsas. Executa seu corpo se Python tratar sua própria condição como verdadeira.

```py
age = 16

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')  # You are a teenager
```

Você também pode usar declarações `if` aninhadas assim:

```py
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

## Valores Truthy e Falsy

- **Verdadeiro e falso (truthiness)**: Em Python, todo valor tem um valor booleano inerente, ou um sentido embutido de se deve ser tratado como `True` ou `False` em um contexto lógico. Muitos valores são considerados truthy, ou seja, avaliam para `True` em um contexto lógico. Outros são falsy, significando que avaliam para `False`. Aqui estão alguns exemplos de valores falsy:

```md
False
None
Integer 0
Float 0.0
Empty strings ''
```

Outros valores como números diferentes de zero e strings não vazias são truthy.

## Trabalhando com a Função `bool()`

- **Função `bool()`**: Se você quiser verificar se um valor é truthy ou falsy, pode usar a função embutida `bool()`. Ela converte explicitamente um valor para seu equivalente booleano e retorna `True` para valores truthy e `False` para valores falsy. Aqui estão alguns exemplos:

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

## Operadores booleanos e avaliação curta

- **Operadores booleanos**: São operadores especiais que permitem combinar múltiplas expressões para criar lógica de decisão mais complexa no seu código. Existem três operadores booleanos em Python: `and`, `or` e `not`.
- **Operador `and`**: Esse operador recebe dois operandos e retorna o primeiro operando se ele for falsy; caso contrário, retorna o segundo operando. Ambos os operandos devem ser truthy para que a expressão resulte em um valor truthy.

```py
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

Você também pode usar o operador `and` em condicionais assim:

```py
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

- **Operador `or`**: Esse operador retorna o primeiro operando se ele for truthy; caso contrário, retorna o segundo operando. Uma expressão com `or` resulta em um valor truthy se pelo menos um dos operandos for truthy. Aqui está um exemplo:

```py
age = 19
is_employed = False

print(age or is_employed) # 19
```

Assim como com o operador `and`, você pode usar o operador `or` em condicionais assim:

```py
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

- **Curto-circuito**: Os operadores `and` e `or` são conhecidos como operadores de curto-circuito. Curto-circuito significa que o Python verifica os valores da esquerda para a direita e para assim que determina o resultado final.
- **Operador `not`**: Esse operador recebe um único operando e inverte seu valor booleano. Ele converte valores truthy em `False` e valores falsy em `True`. Diferente dos operadores anteriores que vimos, `not` sempre retorna `True` ou `False`. Aqui estão alguns exemplos:

```py
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

Aqui está um exemplo do operador `not` em uma condicional:

```py
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

## Operadores de identidade

- **Identidade e igualdade**: Variáveis referem-se a objetos. O operador `is` verifica se dois operandos referem-se ao mesmo objeto, enquanto `is not` verifica se referem a objetos diferentes. Os operadores `==` e `!=` comparam valores. Use operadores de igualdade ao comparar valores numéricos ou strings.
- **`None` e `NoneType`**: `None` representa a ausência de valor. É o único valor do tipo de dado `NoneType`.
- **Singletons**: `None`, `True` e `False` são singletons, ou seja, existe exatamente um objeto para cada um. Você pode verificar esses objetos com operadores de identidade.
- **Verificando `None`**: Use `is None` para verificar valor ausente e `is not None` para verificar valor presente. Tanto `None` quanto `False` são falsy, mas são objetos diferentes:

```py
response = False

print(response is None) # False
print(response is not None) # True
print(response is True) # False
print(response is False) # True
```

- **Identidade e truthiness**: Se `response` pode ser `True`, `False` ou `None`, `response is None` distingue uma resposta ausente de uma negativa. Usar `not response` trataria `False` e `None` da mesma forma. Para flags booleanas comuns, use `if is_ready` ou `if not is_ready`. Use `is True` ou `is False` quando precisar distinguir especificamente um objeto booleano de outros valores possíveis.

## Precedência dos operadores booleanos

- **Precedência de operadores e parênteses**: Quando `and` e `or` aparecem na mesma expressão, `and` tem precedência maior que `or`. Isso significa que `and` agrupa seus operandos primeiro, então `True or False and False` é agrupado como `True or (False and False)`:

```py
print(True or False and False) # True
```

O operando à esquerda do `or` é `True`, então o curto-circuito significa que `False and False` nunca é avaliado, e o resultado é `True`.

Você pode usar parênteses para mudar o agrupamento. Aqui, `True or False` é agrupado junto e avaliado como `True`, e então `True and False` é avaliado como `False`:

```py
print((True or False) and False) # False
```

name = input('What is your name?') # User types 'Kolade' and presses Enter

## Trabalhando com Funções

- **Funções**: Funções são pedaços reutilizáveis de código que executam quando você as chama. Para chamar uma função, você precisa referenciar o nome da função seguido de um conjunto de parênteses:

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

- **Parâmetros e argumentos**: Parâmetros são os nomes listados na definição de uma função, como `num_1` e `num_2` acima. Argumentos são os valores passados ao chamar a função, como `3` e `4`.

Se você chamar a função sem o número correto de argumentos, você receberá um `TypeError`:

```py
def calculate_sum(a, b):
    print(a + b)

calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

- **Argumentos posicionais**: Esses argumentos são associados aos parâmetros pela posição na chamada da função.

```py
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

- **Argumentos com palavra-chave**: Esses argumentos usam `name=value` para associar um parâmetro pelo nome. Eles podem aparecer em uma ordem diferente dos parâmetros:

```py
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

- **Combinando tipos de argumentos**: Argumentos posicionais devem vir antes dos nomeados. Cada parâmetro pode receber apenas um valor:

```py
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

- **Declaração `return`**: Uma declaração `return` termina a função e torna seu valor disponível onde a função foi chamada.

- **`None`**: `None` representa a ausência de valor. Se uma função não retorna explicitamente um valor, o valor de retorno padrão é `None`:

```py
def greet():
    print('hello')

result = greet() # hello
print(result) # None
```

## Escopo em Python

Python tem regras adicionais de escopo. Por enquanto, foque no escopo local e global.

- **Escopo global**: Uma variável criada fora de uma função pode ser usada tanto dentro quanto fora das funções.

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + (subtotal * tax)
    return total

print(get_total(100))  # 170.0
```

- **Escopo local**: Uma variável criada dentro de uma função só pode ser usada dentro dessa função. Parâmetros de função também são variáveis locais.

```py
def my_func():
    num = 10
    print(num)
```

- **Passagem de argumentos e reatribuição de parâmetros**: Python passa argumentos por atribuição. Um parâmetro é um nome local que inicialmente se refere ao objeto fornecido; o objeto não é copiado automaticamente. Reatribuir o parâmetro não reatribui a variável passada como argumento:

```py
def double_number(number):
    number = number * 2
    print(number) # 20

original = 10
double_number(original)
print(original) # 10
```

## Aplicando funções e escopo

- **Corpos de função vazios**: Você pode usar `pass` como marcador de posição em um corpo de função. Uma função contendo apenas `pass` retorna implicitamente `None`:

```py
def placeholder():
    pass

print(placeholder()) # None
```

- **Sombreamento de nomes**: Quando um parâmetro ou variável local tem o mesmo nome que uma variável global, a função usa o nome local. Reatribuir esse parâmetro local não altera a variável global:

```py
available_eggs = 5

def use_eggs(available_eggs, eggs_to_use):
    available_eggs -= eggs_to_use
    return available_eggs

print(use_eggs(available_eggs, 1)) # 4
print(available_eggs) # 5
```

- **Retornos antecipados**: Uma declaração `return` termina imediatamente a função e torna seu valor disponível onde a função foi chamada. Isso permite retornar cedo quando uma condição é atendida:

```py
def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        return available_eggs
    return available_eggs - eggs_to_use

print(use_eggs(2, 3)) # 2
print(use_eggs(2, 1)) # 1
```

- **Chamando funções de outras funções**: Uma função pode chamar outra função e usar ou retornar seu resultado:

```py
def use_eggs(available_eggs, eggs_to_use):
    return available_eggs - eggs_to_use

def make_fried_egg(available_eggs):
    return use_eggs(available_eggs, 1)

print(make_fried_egg(3)) # 2
```

- **Atribuindo valores retornados**: Retornar um novo valor não atualiza automaticamente a variável passada como argumento. Para atualizá-la, atribua o valor retornado de volta a essa variável:

```py
available_eggs = use_eggs(available_eggs, 1)
print(available_eggs) # 4
```

## Traduzindo strings

- **`str.maketrans()`**: A forma com duas strings de `str.maketrans()` recebe strings de comprimento igual e mapeia cada caractere da primeira string para o caractere correspondente na segunda. A tabela armazena caracteres como ordinais Unicode, números que os identificam unicamente. O método `translate()` aplica a tabela a uma string e retorna uma nova string. Caracteres não incluídos na tabela permanecem inalterados.

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc!'.translate(trans_table)
print(result)  # 123123!
```

## Validando argumentos inteiros

- **Booleanos e inteiros**: Python trata booleanos como um tipo especial de inteiro, então `isinstance(True, int)` e `isinstance(False, int)` retornam `True`. Ao validar um inteiro que não deve ser booleano, exclua explicitamente valores booleanos:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True

value = True
print(isinstance(value, int) and not isinstance(value, bool)) # False

value = 5
print(isinstance(value, int) and not isinstance(value, bool)) # True
```

## Valores padrão de parâmetros

- **Parâmetros padrão**: Você pode fornecer um valor padrão para um parâmetro. Se omitir seu argumento ao chamar a função, Python usa esse valor padrão:

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```
