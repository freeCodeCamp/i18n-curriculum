# --description--

要演示一个 HTML 模板，你首先需要一个 HTML 文件用于操作。

在你的计算机上创建一个新文件夹，并命名它为 `html-boilerplate`。 在该文件夹中创建一个新文件，命名为 `index.html`。

你可能已经熟悉了许多不同类型的文件，例如文档、pdf 和图像文件。

要让计算机知道你想要创建一个 HTML 文件，你需要在文件名添加后缀 `.html`，如你在创建 `index.html` 文件时所做的那样。

值得注意的是，你将你的 HTML 文件命名为 index。你应该始终将包含你网站主页的 HTML 文件命名为 `index.html`。这是因为网络服务器默认会在用户访问你的网站时查找 `index.html` 页面——如果没有这个文件，会导致严重问题。

## DOCTYPE

每个 HTML 页面都以一个 doctype 声明开始。doctype 的作用是告诉浏览器应该使用哪个版本的 HTML 来渲染文档。最新版本的 HTML 是 HTML5，该版本的 doctype 就是简单的 `<!DOCTYPE html>`。

旧版本的 HTML 文档类型比较复杂。 例如：HTML4 的文档类型声明是

```html
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd">
```

但是，你可能永远不会想使用旧版本的 HTML，因此你将始终使用 `<!DOCTYPE html>`。

在你的文本编辑器中打开之前创建的 `index.html` 文件，并在第一行添加 `<!DOCTYPE html>`。
