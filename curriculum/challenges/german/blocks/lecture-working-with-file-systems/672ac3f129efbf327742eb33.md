# --description--

Lernen wir, wie Sie Dateien und Ordner unter Windows und macOS suchen können.

Wir beginnen mit Windows. Sie können entweder über die Taskleiste oder den Datei-Explorer suchen.

Um über die Taskleiste zu suchen, geben Sie den Namen der Datei oder des Ordners ein, den Sie suchen. Sie können auch nach Schlüsselwörtern suchen. Sie sehen Ergebnisse von Ihrem gesamten PC und OneDrive.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-1.png" alt="Windows 11 taskbar with Start button, search bar, Task View, and Chrome icon">

Wenn Sie nur Dokumente sehen möchten, können Sie auf den Tab „Dokumente“ klicken. Es gibt auch Tabs für Apps und Web-Ergebnisse.

Eine weitere Möglichkeit ist die Suche im Datei-Explorer. Sie finden sie oben rechts im Explorer-Fenster, wo „Dokumente durchsuchen“ steht.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-2.png" alt="Windows File Explorer with the Search Documents box highlighted on the top right">

Sie haben drei Optionen, um den Gültigkeitsbereich der Suche festzulegen:

- Sie können von „Start“ aus suchen, um schnell Dateien von Ihrem PC und aus der Cloud zu finden.

- Sie können von einem Ordner aus suchen, um Dateien zu finden, die darin gespeichert sind.

- Sie können von „Dieser PC“ aus suchen, was eine langsame, aber gründliche Suche ist.

So können Sie Dateien und Ordner unter Windows suchen. Nun sehen wir, wie Sie das unter macOS machen können.

Zuerst können Sie Spotlight verwenden, ein Tool, das Ihnen hilft, Dateien auf Ihrem Mac zu finden. Um Spotlight zu öffnen, gehen Sie in Ihre Menüleiste oben rechts und suchen Sie das Lupensymbol.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-3.png" alt="macOS menu bar featuring system icons including the magnifying glass Spotlight icon">

Wenn Sie dieses Symbol in der Menüleiste nicht sehen, können Sie es in den Einstellungen des Control Centers hinzufügen.

Gehen Sie zu Ihren Einstellungen, filtern Sie nach „Control Center“, klicken Sie auf diese Option und scrollen Sie dann nach unten, bis Sie die Option „Spotlight“ finden.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-4.png" alt="macOS Control Center settings window showing Spotlight set to Show in Menu Bar">

Sie können auch eine Tastenkombination verwenden, um Spotlight zu öffnen: <kbd>Command</kbd> + <kbd>Spacebar</kbd>.

Wenn Sie Spotlight öffnen, sehen Sie die Spotlight-Suche, in der Sie nach jeder Datei oder jedem Ordner suchen können, indem Sie den Namen eingeben.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-5.png" alt="macOS Spotlight Search bar open on screen">

Wenn Sie zu tippen beginnen, sehen Sie die Ergebnisse nach Kategorien gruppiert, darunter Vorschläge, Ordner, Präsentationen, Fotos, Dokumente und verwandte Suchanfragen.

Sie können auch eine bestimmte Kategorie erweitern, indem Sie auf „Mehr anzeigen“ klicken.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-6.png" alt="macOS Spotlight Search displaying search results for freeCodeCamp">

Eine weitere Möglichkeit, nach Dateien zu suchen, die Sie kürzlich geöffnet haben, ist, den Finder zu öffnen, indem Sie auf das Finder-Symbol im Dock klicken.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-7.png" alt="macOS Dock featuring the blue Finder icon alongside Launchpad and Google Chrome icons">

Gehen Sie dann in der Finder-Seitenleiste zu „Zuletzt verwendet“.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-search-for-files-and-folders-on-your-computer-8.png" alt="macOS Finder sidebar with the Recents option highlighted under Favorites">

Dort finden Sie alle Dateien, die Sie kürzlich angesehen haben.

So können Sie Dateien und Ordner unter macOS suchen. Mit diesen Suchwerkzeugen können Sie Ihren Arbeitsablauf optimieren und die benötigten Dateien und Ordner sehr schnell finden.
