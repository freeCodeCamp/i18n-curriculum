# --description--

평균과 같은 온도는 `0.0 °C`라는 레이블이 붙는데, 이는 읽기에 좋지 않습니다. 대신 `average`라는 레이블이 붙어야 합니다.

`else` 뒤에 또 다른 조건 표현식을 작성하여 조건 표현식을 연결할 수 있습니다. 첫 번째 조건이 거짓이면 Python이 다음 조건 표현식을 평가합니다:

```py
labels = [
    'large' if num > 100
    else 'medium' if num > 10
    else 'small'
    for num in numbers
]
```

조건 표현식을 업데이트해서 `difference`가 `0`보다 크면 `f'+{difference} °C'`를 평가하고, `difference`가 `0`보다 작으면 `f'{difference} °C'`를 평가하며, 그렇지 않으면 문자열 `average`를 평가하도록 하세요.
