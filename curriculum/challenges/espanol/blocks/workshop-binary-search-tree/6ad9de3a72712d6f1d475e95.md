Finalmente, debajo de la llamada a `append`, llama a `self._inorder_traversal` con `node.right` y `result` para visitar el subárbol derecho.

En un árbol de búsqueda binaria, los valores en el subárbol izquierdo de un nodo son menores que el valor del nodo, y los valores en el subárbol derecho son mayores. Así que visitar el subárbol izquierdo, luego el nodo y después el subárbol derecho recoge las claves de menor a mayor.

class BinarySearchTree:

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node

    def insert(self, key):
