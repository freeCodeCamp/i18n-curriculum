# --description--

`type` 屬性告訴瀏覽器 `input` 應該接受哪種類型的資料。`type` 屬性的一些常見值有：

- `text`：單行文字欄位
- `email`：會檢查使用者輸入是否為有效電子郵件位址的文字欄位
- `number`：數字欄位
- `radio` 和 `checkbox`：使用者可以選擇的選項

以下是一個文字輸入欄位的範例：

```html
<input type="text">
```

為現有的 `input` 元素添加一個 `type` 屬性，並設定為 `"text"`。

同時給 `input` 元素添加一個 `id` 屬性，值為 `"full-name"`。這會與你的 `label` 元素上的 `for` 屬性相匹配，將兩者連結起來。

當使用者提供他們的全名時，`input` 將接受純文字。
