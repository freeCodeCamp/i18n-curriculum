# --description--

In diesem Workshop implementieren Sie zusätzliche Operationen für eine verkettete Liste als Datenstruktur, basierend auf der `LinkedList`-Klasse, die Sie im vorherigen Workshop erstellt haben.

**Ziel:** Erfüllen Sie die untenstehenden User Stories und bestehen Sie alle Tests, um das Labor abzuschließen.

**User Stories:**

1. Ihre `LinkedList`-Klasse sollte eine `contains`-Methode haben, die ein Element als Argument nimmt. Sie sollte `True` zurückgeben, wenn das Element in der verketteten Liste existiert, und sonst `False`.
1. Ihre `LinkedList`-Klasse sollte eine `get_at`-Methode haben, die einen Index als Argument nimmt. Sie sollte das Element an dem angegebenen Index in der verketteten Liste zurückgeben. Wenn der Index außerhalb des gültigen Bereichs liegt, sollte sie `None` zurückgeben.
1. Ihre `LinkedList`-Klasse sollte eine `insert_at`-Methode haben, die einen Index und ein Element als Argumente nimmt. Sie sollte das Element an der angegebenen Position in der verketteten Liste einfügen und das `length`-Attribut aktualisieren. Ein Index, der der Länge der Liste entspricht, ist gültig und sollte das Element am Ende hinzufügen. Wenn der Index ungültig ist, sollte die Liste nicht verändert werden.
1. Ihre `LinkedList`-Klasse sollte eine `remove_at`-Methode haben, die einen Index als Argument nimmt. Sie sollte den Knoten an dem angegebenen Index in der verketteten Liste entfernen und das `length`-Attribut aktualisieren. Wenn der Index ungültig ist, sollte die Liste nicht verändert werden.
1. Ihre `LinkedList`-Klasse sollte eine `clear`-Methode haben, die alle Elemente aus der verketteten Liste entfernt und sie in einen leeren Zustand zurücksetzt, wobei `head` auf `None` und `length` auf `0` gesetzt wird.

**Hinweis:** Einige spätere Tests bauen auf früheren Methoden auf. Wenn zum Beispiel `get_at` nicht korrekt implementiert ist, können Tests für Methoden wie `insert_at` und `remove_at` fehlschlagen, selbst wenn diese Methoden fast korrekt sind.

```py
class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
```
