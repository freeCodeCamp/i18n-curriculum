## CSSの基本

- **CSSとは？**: Cascading Style Sheets（CSS）は、HTML要素にスタイルを適用するためのスタイルシート言語です。CSSは色、背景画像、レイアウトなどに使われます。
- **CSSルールの基本構造**: CSSルールは主に2つの部分で構成されます：セレクターと宣言ブロックです。セレクターは特定のHTML要素を識別しスタイルを適用するためのパターンです。宣言ブロックは、指定されたセレクターに対して一連のスタイルを適用します。

## `width` と `height` プロパティの操作

- **`width` プロパティ**: このプロパティは要素の幅を指定します。幅を指定しない場合、デフォルトは`auto`に設定されます。これによりブラウザはコンテンツ、親要素、表示タイプに基づいて要素の幅を決定します。
- **`min-width` プロパティ**: このプロパティは要素の最小幅を指定します。
- **`max-width` プロパティ**: このプロパティは要素の最大幅を指定します。
- **`height` プロパティ**: このプロパティは要素の高さを指定します。同様に、高さはデフォルトで`auto`に設定されており、内部のコンテンツに合わせて調整されます。
- **`min-height` プロパティ**: このプロパティは要素の最小高さを指定します。
- **`max-height` プロパティ**: このプロパティは要素の最大高さを指定します。

## インライン、ブロック、インラインブロックレベル要素

- **インラインレベル要素**: インライン要素は必要な幅だけを占め、新しい行を開始しません。これらの要素はコンテンツ内に流れ、テキストや他のインライン要素と並んで表示されます。一般的なインライン要素には`span`、`a`、`img`があります。
- **ブロックレベル要素**: ブロックレベル要素はデフォルトで利用可能な幅全体を占め、コンテナの幅いっぱいに広がります。一般的なブロックレベル要素には`div`、`p`、`section`があります。
- **インラインブロックレベル要素**: `display`プロパティで`inline-block`を設定すると、インライン要素のように振る舞いながら、ブロックレベル要素のように`width`や`height`を設定できます。

## マージンとパディング

- **`margin` プロパティ**: このプロパティは要素の外側、要素のボーダーと周囲の要素との間にスペースを適用します。
- **`margin` の省略形**: 1～4つの値を指定してマージンの各辺を設定できます。1つの値は4辺すべてに適用され、2つの値は`top`と`bottom`、`right`と`left`に設定されます。3つの値は`top`、水平（`right`と`left`）、`bottom`に設定され、4つの値は`top`、`right`、`bottom`、`left`にそれぞれ設定されます。
- **`padding` プロパティ**: このプロパティは要素の内側、コンテンツとボーダーの間にスペースを適用します。
- **`padding` の省略形**: 1～4つの値を指定してパディングの各辺を設定できます。1つの値は4辺すべてに適用され、2つの値は`top`と`bottom`、`right`と`left`に設定されます。3つの値は`top`、水平（`right`と`left`）、`bottom`に設定され、4つの値は`top`、`right`、`bottom`、`left`にそれぞれ設定されます。

## 背景画像

- **`background-image` プロパティ**: このプロパティは要素の背景画像を設定するために使います。
- **`background-size` プロパティ**: このプロパティは背景画像のサイズを設定します。`contain` の値は画像を切り取ったり伸ばしたりせずにできるだけ大きく表示します。`cover` の値は画像のアスペクト比を保ちながら要素全体を覆うように拡大縮小し、画像の一部が切り取られる場合があります。
- **`background-repeat` プロパティ**: デフォルトでは背景画像は水平方向と垂直方向の両方に繰り返されて要素を埋めます。`no-repeat` は繰り返しを止め、`repeat-x` は水平方向に繰り返し、`repeat-y` は垂直方向に繰り返します。
- **`background-position` プロパティ**: このプロパティは背景画像が要素内のどこに表示されるかを設定します。`top`、`bottom`、`left`、`right`、`center` のようなキーワードやピクセルやパーセンテージの値を使えます。
- **`background-attachment` プロパティ**: このプロパティは背景画像がコンテンツと一緒にスクロールするか、固定されるかを決めます。デフォルト値は `scroll` で、`fixed` はページをスクロールしても画像が画面上の同じ位置に留まります。
- **`background` 省略形プロパティ**: このプロパティは `background-image`、`background-position`、`background-attachment` など複数の背景関連プロパティを一つの宣言にまとめられます。

## ボーダー

- **`border` プロパティ**: 幅、スタイル、色を一度に設定できる省略形プロパティです。一般的なボーダースタイルには `solid`、`dashed`、`dotted`、`double` があります。
- **個別のボーダー側**: `border-top`、`border-right`、`border-bottom`、`border-left` プロパティでボーダーの各辺を個別にスタイル設定できます。
- **`outline` プロパティ**: 要素の周りに線を作成します。`border` と似ていますが、`outline` は要素の寸法やレイアウトに影響しません。
- **`border-radius` プロパティ**: 要素のボーダーに丸みをつけるために使います。

## CSSの特異性

- **Inline CSS Specificity**: インラインCSSは要素に直接適用されるため、最も高い優先度を持ちます。内部CSSや外部CSSをオーバーライドします。インラインスタイルの特異性の値は(1, 0, 0, 0)です。
- **Internal CSS Specificity**: 内部CSSはHTMLドキュメントの`head`セクション内の`style`要素で定義されます。インラインスタイルよりも特異性は低いです。内部CSSと外部CSSは同じ特異性レベルを持ち、その優先度は場所ではなくセレクターによって決まります。
- **External CSS Specificity**: 外部CSSは`head`セクションの`link`要素を通じてリンクされ、別の`.css`ファイルに記述されます。内部CSSと同様に、特異性は使用されるセレクターによって決まります。特異性が同じルールが複数ある場合は、ドキュメント内で後に記述されたルールが優先されます。外部CSSは大規模なプロジェクトでの保守性に優れています。
- **Universal Selector (`*`)**: これはドキュメント内のすべての要素にマッチする特別なCSSセレクターです。ページ内のすべての要素にスタイルを適用するために使われることが多く、異なるブラウザ間でのスタイルのリセットや正規化に役立ちます。ユニバーサルセレクターはすべてのセレクターの中で最も低い特異性値を持ち、特異性のすべての部分に0を寄与します(0, 0, 0, 0)。
- **Type Selectors**: これらのセレクターはタグ名に基づいて要素をターゲットにします。型セレクターは他のセレクターに比べて比較的低い特異性を持ちます。型セレクターの特異性値は(0, 0, 0, 1)です。
- **Class Selectors**: これらのセレクターはピリオド(`.`)に続けてクラス名を指定します。クラスセレクターの特異性値は(0, 0, 1, 0)です。つまり、クラスセレクターは型セレクターをオーバーライドできますが、IDセレクターやインラインスタイルにはオーバーライドされます。
- **ID Selectors**: IDセレクターはハッシュ記号(`#`)に続けてID名を指定します。IDセレクターは非常に高い特異性を持ち、型セレクターやクラスセレクターよりも高いですが、インラインスタイルよりは低いです。IDセレクターの特異性値は(0, 1, 0, 0)です。
- **`!important` keyword**: スタイルルールに最高の優先度を与え、他のどんな宣言よりもそのプロパティをオーバーライドできるようにします。使用すると、他のセレクターの特異性に関係なくブラウザが指定されたスタイルを適用します。`!important`はCSSの保守やデバッグを難しくするため、使用には注意が必要です。

## 絶対単位

- **`px`（ピクセル）**: CSSの絶対単位で、寸法を正確に制御できます。1pxは常に1/96インチに相当します。
- **`in`（インチ）**: この絶対単位は96pxに相当します。
- **`cm`（センチメートル）**: この絶対単位は25.2/64インチに相当します。
- **`mm`（ミリメートル）**: この絶対単位は1/10センチメートルに相当します。
- **`q`（四分の一ミリメートル）**: この絶対単位は1/40センチメートルに相当します。
- **`pc`（パイカ）**: この絶対単位は1/6インチに相当します。
- **`pt`（ポイント）**: この絶対単位は1/72インチに相当します。

## 相対単位

- **パーセンテージ**: これらの相対単位は、親要素に対するサイズや寸法、その他のプロパティを割合で指定できます。例えば、要素に `width: 50%;` を設定すると、その要素は親コンテナの幅の半分を占めます。
- **`em` 単位**: これらの単位は要素のフォントサイズに対して相対的です。`font-size` プロパティに `ems` を使う場合、テキストのサイズは親要素のフォントサイズに対して相対的になります。
- **`rem` 単位**: これらの単位はルート要素である `html` 要素のフォントサイズに対して相対的です。
- **`vh` 単位**: `vh` は `"viewport height"` の略で、`1vh` はビューポートの高さの1%に相当します。
- **`vw` 単位**: `vw` は `"viewport width"` の略で、`1vw` はビューポートの幅の1%に相当します。

## `calc` 関数

- **`calc()` 関数**: `calc()`関数を使うと、スタイルシート内で直接計算を行い、プロパティ値を動的に決定できます。これにより、ビューポートサイズや他の要素に基づいて寸法を計算し、柔軟でレスポンシブなUIを作成できます。

## 疑似クラス

- **疑似クラスの定義**: これらは特定の状態や位置に基づいて要素を選択できる特別なCSSキーワードです。
- **`:active` 疑似クラス**: ボタンをクリックしたときのような要素のアクティブ状態を選択できます。
- **`:hover` 疑似クラス**: 要素にマウスカーソルが乗ったときの状態を定義します。
- **`:focus` 疑似クラス**: キーボード操作やフォーム入力時に要素がフォーカスを得たときにスタイルを適用します。
- **`:first-child` 疑似クラス**: 親要素やドキュメント内の最初の要素を選択します。
- **`:last-child` 疑似クラス**: 親要素やドキュメント内の最後の要素を選択します。
- **`:first-of-type` 疑似クラス**: 親内で特定の要素タイプの最初の出現を選択します。
- **`:last-of-type` 疑似クラス**: 親内で特定の要素タイプの最後の出現を選択します。
- **`:nth-of-type(n)` 疑似クラス**: 同じタイプの兄弟要素の中で特定の位置にある要素を選択できます。
- **`:visited` 疑似クラス**: ユーザーが訪問したリンクをターゲットにします。
- **`:enabled` 疑似クラス**: 現在有効なフォームボタンや他の要素をターゲットにします。
- **`:disabled` 疑似クラス**: 無効状態のインタラクティブな要素にスタイルを適用します。
- **`:checked` 疑似クラス**: チェックされていることをユーザーに示すために使います。

## 疑似要素

- **`::before` 疑似要素**: この疑似要素は`content`プロパティを使い、要素の直前にアイコンなどの装飾的なコンテンツを挿入します。
- **`::after` 疑似要素**: この疑似要素は`content`プロパティを使い、要素の直後に装飾的なコンテンツを挿入します。
- **`::first-letter` 疑似要素**: この疑似要素は要素の内容の最初の文字をターゲットにし、スタイルを適用できます。
- **`::marker` 疑似要素**: この疑似要素はリスト項目のマーカー（箇条書きや番号）を選択してスタイルを適用します。

## CSSでの色の扱い方

- **名前付きカラー**: これらはブラウザが認識する事前定義された色名です。例として `blue`、`darkred`、`lightgreen` があります。
- **`rgb()` 関数**: RGBは赤、緑、青の光の三原色を表します。これらの色を異なる強度で組み合わせて幅広い色を作ります。`rgb()` 関数はRGBカラーモデルを使って色を定義できます。
- **`rgba()` 関数**: この関数は4番目の値であるアルファ値を追加し、色の透明度を制御します。
- **`hsl()` 関数**: HSLは色相、彩度、明度の3つの主要な要素で色を定義します。
- **`hsla()` 関数**: この関数は4番目の値であるアルファ値を追加し、色の不透明度を制御します。
- **16進数**: 16進コード（hexコード）はRGBカラーモデルの色を表す6文字の文字列です。「hex」は16進数のことで、数字の0から9とAからFの文字を使います。

## `box-shadow` プロパティ

- **定義**: `box-shadow` プロパティは要素の周りに1つ以上の影を適用します。
- **オフセット値**: 水平方向（`offset-x`）と垂直方向（`offset-y`）の値を指定する必要があります。正の `offset-x` は影を右に、負の値は左に移動させます。正の `offset-y` は影を下に、負の値は上に移動させます。値が `0` の場合は単位を省略できます。
- **ぼかし半径**: これは影のぼかし具合を制御する任意の値です。指定しない場合は `0` で、シャープなエッジになります。値が大きいほど影は柔らかくなります。
- **広がり半径**: 影の広がりや縮小を制御する任意の値です。指定しない場合は `0` です。
- **影の色**: 名前付きカラー、16進値、`rgb()`、`rgba()`、`hsl()`、`hsla()` 関数で色を指定できます。

## グラデーション

- **線形グラデーション**: これらのグラデーションは直線に沿って色が徐々に混ざり合う効果を作ります。線の方向や使用する色を制御できます。

## CSSのトランスフォームプロパティ

- **定義**: このプロパティは要素に対して回転、拡大縮小、傾斜、平行移動（2Dまたは3D空間での移動）などの変形を適用できます。
- **`rotate()` 関数**: この関数は要素の中心を軸に回転させるために使います。

## ボックスモデル

- **定義**: CSSのボックスモデルでは、すべての要素はボックスに囲まれています。このボックスは4つの要素で構成されます：コンテンツエリア、`padding`、`border`、`margin`。
- **コンテンツエリア**: コンテンツエリアはボックスの最も内側の部分で、テキストや画像など要素の実際の内容が入るスペースです。
- **`padding`**: パディングはコンテンツエリアのすぐ外側のエリアで、コンテンツエリアと要素のボーダーの間のスペースです。
- **`border`**: ボーダーはCSSボックスモデルにおける要素の外枠や輪郭です。要素の視覚的な境界線です。
- **`margin`**: マージンは要素のボーダーの外側のスペースで、要素と周囲の他の要素との距離を決めます。

## `content-box` と `border-box` のプロパティ値

- **`box-sizing` プロパティ**: このプロパティはHTML要素の合計の `width` と `height` の計算方法を決定します。
- **`content-box` 値**: `content-box` モデルでは、設定した `width` と `height` はコンテンツエリアの寸法を決めますが、`padding` や `border` は含みません。
- **`border-box` 値**: `border-box` では、設定した `width` と `height` にコンテンツエリア、`padding`、`border` が含まれます。

## CSSフィルタープロパティ

- **定義**: このプロパティはぼかしなどのさまざまな効果を作るために使えます。
- **`blur()` 関数**: この関数は要素にぼかしを適用します。量はピクセル単位で指定し、ぼかしの半径を表します。

## CSS Flexboxとフレックスモデルの紹介

- **定義**: CSSフレックスボックスは1次元のレイアウトモデルで、コンテナ内の要素を行や列に並べることができます。
- **フレックスモデル**: このモデルはフレックスコンテナ内でフレックスアイテムがどのように配置されるかを定義します。すべてのフレックスコンテナには主軸と交差軸の2つの軸があります。

## `flex-direction` プロパティ

- **定義**: このプロパティは主軸の方向を設定します。`flex-direction` のデフォルト値は `row` で、すべてのフレックスアイテムをブラウザのデフォルト言語の方向（左から右または右から左）に同じ行に配置します。
- **`flex-direction: row-reverse;`**: 行内のアイテムの順序を逆にします。
- **`flex-direction: column;`**: フレックスアイテムを水平方向ではなく垂直方向に整列します。
- **`flex-direction: column-reverse;`**: フレックスアイテムの垂直方向の順序を逆にします。

## `flex-wrap` プロパティ

- **定義**: このプロパティはフレックスコンテナ内でフレックスアイテムが利用可能なスペースに収まるように折り返す方法を決定します。`flex-wrap`は`nowrap`、`wrap`、`wrap-reverse`の3つの値を取れます。
- **`flex-wrap: nowrap;`**: デフォルト値です。フレックスアイテムはコンテナの幅を超えても新しい行に折り返されません。
- **`flex-wrap: wrap;`**: アイテムがコンテナの幅を超えた場合に折り返します。
- **`flex-wrap: wrap-reverse;`**: フレックスアイテムを逆順で折り返します。
- **`flex-flow` プロパティ**: `flex-direction` と `flex-wrap` の省略形プロパティです。

## `justify-content` プロパティ

- **定義**: このプロパティはフレックスコンテナの主軸に沿って子要素を配置します。
- **`justify-content: flex-start;`**: フレックスアイテムを主軸の開始位置に揃えます。主軸は水平または垂直の場合があります。
- **`justify-content: flex-end;`**: フレックスアイテムを主軸の終了位置に揃えます。
- **`justify-content: center;`**: フレックスアイテムを主軸の中央に配置します。
- **`justify-content: space-between;`**: 主軸に沿って要素を均等に配置します。
- **`justify-content: space-around;`**: 主軸に沿って要素を均等に配置し、最初と最後の要素の前後にスペースを追加します。
- **`justify-content: space-evenly;`**: 主軸に沿って要素を均等に配置します。

## `align-items` プロパティ

- **定義**: このプロパティは交差軸に沿ってアイテムを分布させます。交差軸は主軸に垂直です。
- **`align-items: center;`**: アイテムを交差軸の中央に配置します。
- **`align-items: flex-start;`**: アイテムを交差軸の開始位置に整列させます。
- **`align-items: stretch;`**: フレックスアイテムを交差軸に沿って伸ばします。

## CSS `font-family` プロパティ

- **定義**: フォントファミリーは共通のデザインを共有するフォントのグループです。同じファミリーに属するフォントは同じ基本書体に基づきますが、スタイル、太さ、幅にバリエーションがあります。複数のフォントファミリーを優先順位順にカンマで区切って指定できます。代替フォントはフォールバックとして機能します。フォントファミリーリストの最後には必ず総称フォントファミリーを含めるべきです。
- **一般的なフォントファミリー**: CSSでよく使われるフォントファミリーには、serif、sans-serif、monospace、cursive、fantasyがあります。

## 属性セレクターとリンクの操作

- **定義**: `attribute` セレクターは、`href` や `title` のような属性に基づいてHTML要素をターゲットにできます。

## CSSコンビネーターの種類

- **子孫結合子（` `）※セレクター間に空白1つ**: 指定した親要素の子孫である要素をターゲットにします。
- **子結合子（`>`）**: 指定した親要素の直接の子要素を選択します。
- **隣接兄弟結合子（`+`）**: 指定した兄弟要素の直後に続く要素を選択します。
- **一般兄弟結合子（`~`）**: 指定した要素の後に続くすべての兄弟要素を選択します。

## 静的、相対、絶対位置指定

- **静的配置**: ドキュメントの通常の流れで、要素は上から下、左から右へ順に配置されます。
- **相対配置**: `top`、`left`、`right`、`bottom`プロパティを使って、通常のドキュメントフロー内で要素を位置調整できます。また、相対配置を使って要素を他の要素と重ねることも可能です。
- **絶対配置**: 要素を通常のドキュメントフローから外し、他の要素とは独立して振る舞うようにできます。

## 固定位置とスティッキー位置

- **固定配置**: `position: fixed`で配置された要素は通常のドキュメントフローから外れ、ビューポートに対して相対的に配置されます。ユーザーがスクロールしても同じ位置に留まります。ヘッダーやナビゲーションバーなど、常に表示しておきたい要素に使われます。
- **スティッキー配置**: 相対配置と固定配置のハイブリッドのように振る舞います。最初は相対配置としてドキュメントフロー内に留まりますが、ユーザーがスクロールして特定の位置を超えると、ビューポート（通常は上部）に「貼り付く」ように固定配置になります。スクロール時に固定されるナビゲーションバーなどに適しています。

## `z-index` プロパティの操作

- **定義**: CSSの`z-index`プロパティは、ページ上で重なり合う位置指定要素の垂直方向の重なり順序を制御します。

## メディアクエリ

- **定義**: 開発者がデバイスの特性、主にビューポートの幅に基づいて異なるスタイルを適用できるようにするものです。

## CSSカスタムプロパティ（CSS変数）

- **定義**: CSSカスタムプロパティ、別名CSS変数は、CSS作者が定義し、ドキュメント全体で再利用できる特定の値を含むエンティティです。これは、より効率的で保守しやすく柔軟なスタイルシートを作成できる強力な機能です。カスタムプロパティはテーマ対応デザインを作成する際に特に役立ちます。異なるテーマ用のプロパティセットを定義できます。

## CSSグリッドの基本

- **定義**: CSSグリッドはウェブページで複雑なレイアウトを作るための2次元レイアウトシステムです。グリッドは行と列があり、それらの間にギャップがあります。グリッドレイアウトを定義するには、`display` プロパティを `grid` に設定します。
- **`fr`（分数）単位**: この単位はグリッドコンテナ内の空間の分数を表します。`fr` 単位を使って柔軟なグリッドを作れます。
- **トラック間のギャップ作成**: CSSグリッドでトラック間のギャップを作る方法は3つあります。`column-gap` プロパティで列間のギャップを作れます。`row-gap` プロパティで行間のギャップを作れます。`gap` 省略形プロパティで行と列の両方のギャップを作れます。
- **`repeat()` 関数**: トラックの繰り返し部分を指定するために使います。`grid-template-columns: 1fr 1fr 1fr;` の代わりに `repeat()` 関数を使えます。
- **明示的グリッド**: `grid-template-columns` や `grid-template-rows` プロパティで行や列の数を指定できます。
- **暗黙的グリッド**: アイテムがグリッド外に配置されると、そのために行や列が自動的に作成されます。
- **`minmax()` 関数**: トラックの最小値と最大値のサイズを設定するために使います。
- **グリッド自動配置**: ブラウザは自動配置アルゴリズムを使ってアイテムを配置します。`grid-auto-flow` プロパティは配置方向や空きスペースの埋め戻しを制御し、`row`、`column`、`dense` の値を使えます。
- **ラインベースの配置**: すべてのグリッドにはラインがあります。アイテムの開始位置は `grid-column-start` と `grid-row-start` プロパティで指定し、終了位置は `grid-column-end` と `grid-row-end` で指定します。省略形の `grid-column` や `grid-row` を使うこともできます。
- **`grid-template-areas`**: グリッド上で配置するアイテムに名前を付けるために使います。
- **整列**: `justify-items` と `align-items` でグリッドエリア内のアイテムの整列を制御し、個別のグリッドアイテムには `justify-self` と `align-self` でコンテナの整列をオーバーライドできます。
