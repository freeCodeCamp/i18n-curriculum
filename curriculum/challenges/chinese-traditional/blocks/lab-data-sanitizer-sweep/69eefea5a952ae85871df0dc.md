# --description--

在這個實驗中，你將透過將不允許的字元替換為 `#`，並追蹤處理了多少筆條目，來清理半結構化的日誌檔案。

**目標：** 完成以下使用者故事並通過所有測試以完成實驗。

**使用者故事：**

1. 你應該使用函式宣告來創建一個名為 `sanitizeLog` 的函式，該函式有兩個參數：`entry`，一個代表日誌條目的字串，以及 `disallowedCharacters`，一個包含單一字元字串的陣列，代表要替換的字元。
1. 該函式應傳回修改後的 `entry` 字串，其中每個不允許的字元都被替換成 `#`。匹配應區分大小寫。例如，如果不允許的字元是 `["e", "E", "o", "r"]`，則 `DEBUG: Server started on port 3000` 應傳回 `D#BUG: S##v## sta#t#d #n p##t 3000`。
1. 你應該創建一個名為 `cleanLogs` 的函式，該函式有兩個參數：`logs`，一個包含日誌條目的字串陣列，以及 `disallowedCharacters`，一個包含單一字元字串的陣列，代表要替換的字元。
1. `cleanLogs` 應依序迭代給定的日誌條目陣列。
1. 當 `cleanLogs` 遇到包含致命標記 `$` 的日誌條目時，應停止並傳回 `Sanitizing stopped. Failure Reason: Fatal character occurred.`。
1. 以 `/` 字元開頭的日誌條目是資訊性條目，不應被清理。你應該統計資訊性條目的數量。
1. 其他所有日誌條目都應使用 `sanitizeLog` 函式進行清理。你應該統計已清理條目的數量。
1. 如果 `cleanLogs` 在未遇到致命標記的情況下完成，應傳回 `Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.`，其中 `X` 是條目總數，`Y` 是已清理條目數，`Z` 是資訊性條目數。

**以下日誌陣列用於測試：**

```js
let logs_1 = [
  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"
];

let logs_2 = [
  "FATAL: System overload detected, shutting down",
  "DEBUG: token=def456$ refreshed for session",
  "ERROR: Null pointer exception in module auth"
];

let logs_3 = [
  "ERROR: Failed to connect to db, retry=3",
  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
