# --interactive--

HTML 中的 `form` 元素用于收集用户信息，如姓名和电子邮件地址。 下面是一个 `form` 元素的示例：

```html
<form action="url-goes-here">
  <!-- input elements go here -->
</form>
```

`action` 属性指定表单数据提交后发送到的位置。要收集特定的信息，比如姓名和电子邮件地址，你需要使用 `input` 元素。下面是使用 `input` 元素的示例。

启用交互式编辑器，通过在字段中输入你的名字，与预览窗口中的 `input` 元素进行交互。

:::interactive_editor

```html
<form action="">
  <input type="text" />
</form>
```

:::

`input` 元素是空元素，没有闭合标签。`type` 属性定义了期望用户输入的数据类型。在这个例子中，数据类型是纯文本。要为输入添加标签，你可以使用 `label` 元素。下面是一个带有文本 `Full Name:` 的 `label` 元素示例。

点击预览窗口中的文本 `Full Name:`，你将看到输入获得焦点。要与示例交互，你需要启用交互式编辑器。

:::interactive_editor

```html
<form action="">
  <label>
    Full Name:
    <input type="text" />
  </label>
</form>
```

:::

通过将 `input` 嵌套在 `label` 元素内，你创建了 `label` 和 `input` 字段之间的隐式关联。“隐式”指的是无需显式声明或通过额外属性或元素定义就能理解或推断的关系。要显式关联 `label` 和 `input`，你可以使用 `for` 属性。下面是一个为电子邮件地址标签使用 `for` 属性的示例。

通过在预览窗口的 `input` 元素中输入一个假的电子邮件地址，如 `jane@example.com`，与其交互。要与示例交互，你需要启用交互式编辑器。

:::interactive_editor

```html
<form action="">
  <label for="email"> Email Address: </label>
  <input type="email" id="email" />
</form>
```

:::

使用显式关联时，`for` 属性和 `id` 的值必须相同。在这个例子中，两者都设置为 `email`。输入框中 `email` 类型提供了对格式正确的电子邮件地址的基本验证。如果你想向用户显示关于期望输入的额外提示，可以使用 `placeholder` 属性。下面是一个在电子邮件输入框中使用 `placeholder` 属性的示例。

启用交互式编辑器，点击电子邮件 input 并开始输入电子邮件，你将看到占位符文本消失。

:::interactive_editor

```html
<form action="">
  <label for="email"> Email Address: </label>
  <input type="email" id="email" placeholder="example@email.com" />
</form>
```

:::

对于占位符文本，你需要提供有帮助的简短文本，以显示你期望用户输入的数据的格式和类型。在这种情况下，占位符文本 `example@email.com` 向用户显示他们必须输入格式正确的电子邮件地址。
