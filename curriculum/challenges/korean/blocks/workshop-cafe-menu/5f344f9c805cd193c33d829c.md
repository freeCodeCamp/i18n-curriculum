# --description--

CSS 규칙은 두 가지 주요 부분으로 구성됩니다: 선택자와 선언 블록입니다.

기본 구문은 다음과 같습니다:

```css
selector {
  property: value;
}
```

선택자는 CSS에서 특정 HTML 요소를 식별하고 스타일을 적용하기 위해 사용하는 패턴입니다.

모든 문단 요소의 색상을 파란색으로 변경하는 예시입니다.

```css
p {
  color: blue;
}
```

`h1` 요소의 내용을 가운데 정렬하려면 `text-align` 속성을 `center` 값으로 설정하세요.

# --hints--

`style` 요소에 `h1` 선택자가 있어야 합니다.

```js
const hasSelector = new __helpers.CSSHelp(document).getStyle('h1');
assert.exists(hasSelector);
```

`text-align` 속성은 `center` 값을 가져야 합니다.

```js
const hasTextAlign = new __helpers.CSSHelp(document).getCSSRules().some(x => x.style['text-align'] === 'center');
assert.isTrue(hasTextAlign);
```

`h1` 선택자는 `text-align` 속성을 `center`로 설정해야 합니다.

```js
const h1TextAlign = new __helpers.CSSHelp(document).getStyle('h1')?.getPropertyValue('text-align');
assert.equal(h1TextAlign, 'center');
```
