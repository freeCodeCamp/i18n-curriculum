# --description--

Ви дізналися, що присвоєння створює псевдонім, а метод `.copy()` словника створює поверхневу копію. Поверхнева копія має окремий зовнішній словник, але вкладені об’єкти все ще спільні. Тепер, коли ви знаєте, як імпортувати модулі, ви можете також використовувати вбудований модуль `copy` стандартної бібліотеки для копіювання вкладених колекцій.

## Створення глибокої копії

Функція `copy.deepcopy()` рекурсивно копіює вкладені колекції. Для словника, що містить список, вона створює новий зовнішній словник і окремий вкладений список:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
deep_copy = copy.deepcopy(original)

print(deep_copy == original) # True
print(deep_copy is original) # False
print(deep_copy['items'] is original['items']) # False

deep_copy['items'].append('fruit')
print(original['items']) # ['bread', 'cheese']
print(deep_copy['items']) # ['bread', 'cheese', 'fruit']
```

Спочатку словники мають однаковий вміст, але ні зовнішній словник, ні вкладений список не є спільними між ними. Додавання до скопійованого списку не змінює оригінальний список.

## Порівняння присвоєння, поверхневого та глибокого копіювання

Давайте створимо усі три варіанти з одного й того самого словника:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
alias = original
shallow_copy = original.copy()
deep_copy = copy.deepcopy(original)

print(alias is original) # True
print(shallow_copy is original) # False
print(deep_copy is original) # False

print(alias['items'] is original['items']) # True
print(shallow_copy['items'] is original['items']) # True
print(deep_copy['items'] is original['items']) # False
```

Продовжуючи з цими об’єктами, змініть верхній рівень запису через кожне ім’я:

```python
alias['name'] = 'Picnic'
shallow_copy['name'] = 'Snack'
deep_copy['name'] = 'Dinner'

print(original['name']) # Picnic
print(alias['name']) # Picnic
print(shallow_copy['name']) # Snack
print(deep_copy['name']) # Dinner
```

Псевдонім посилається на оригінальний словник, тому присвоєння через `alias` змінює цей словник. Кожна копія має свій власний зовнішній словник, тому заміна запису `name` впливає лише на цю копію.

Далі змініть вкладені списки:

```python
alias['items'].append('water')
shallow_copy['items'].append('fruit')
deep_copy['items'].append('soup')

print(original['items']) # ['bread', 'cheese', 'water', 'fruit']
print(alias['items']) # ['bread', 'cheese', 'water', 'fruit']
print(shallow_copy['items']) # ['bread', 'cheese', 'water', 'fruit']
print(deep_copy['items']) # ['bread', 'cheese', 'soup']
```

Оригінальний словник, його псевдонім і поверхнева копія всі посилаються на один і той самий список. Зміни через будь-який із цих референсів видно через інші. Глибока копія має свій власний список, тому її зміни залишаються окремими.

Це також працює зі словниками, вкладеними всередині списків:

```python
import copy

original = {'meals': [{'name': 'Lunch', 'items': ['bread']}]}
deep_copy = copy.deepcopy(original)
deep_copy['meals'][0]['items'].append('fruit')

print(original['meals'][0]['items']) # ['bread']
print(deep_copy['meals'][0]['items']) # ['bread', 'fruit']
```

Тут `deepcopy()` копіює зовнішній словник, список `meals`, словник всередині цього списку та його список `items`. У прикладі використовуються вбудовані словники та списки; глибоке копіювання не означає, що кожен можливий об’єкт Python дублюється.
