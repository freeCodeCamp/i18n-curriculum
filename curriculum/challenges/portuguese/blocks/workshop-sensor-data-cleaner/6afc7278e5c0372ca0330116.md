# --description--

Nesta oficina, você vai praticar compreensões de listas e funções lambda limpando as leituras de um sensor de temperatura e comparando-as com a média usual de temperatura do local.

O sensor informa temperaturas em décimos de grau Celsius, então uma leitura de `215` significa `21.5` °C. Quando ele não consegue ler a temperatura, escreve o código de erro `-999` em vez disso.

Crie uma variável chamada `readings` e atribua a ela a lista `[215, 243, -999, 280, 316, 339, -999, 262, 305]`.

Depois, crie uma variável chamada `average_temperature` e atribua a ela o float `28.0`. Essa é a média usual de temperatura para o local, já em graus Celsius, e você vai comparar as leituras com ela.
