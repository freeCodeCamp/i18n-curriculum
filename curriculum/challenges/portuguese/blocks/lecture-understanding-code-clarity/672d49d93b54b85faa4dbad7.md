# --description--

Assim como um ponto final (`.`) pode marcar o fim de uma frase em inglês, um ponto e vírgula (`;`) pode ser usado para marcar o fim de uma declaração em JavaScript. No entanto, declarações não são necessariamente a mesma coisa que linhas de código fonte. Uma declaração pode abranger várias linhas e uma única linha pode conter mais de uma declaração.

Por exemplo:

```js
let variableOne = 5;
let variableTwo = 10;
```

Neste código, os pontos e vírgulas tornam explícito o fim de cada declaração. O JavaScript também possui a Inserção Automática de Ponto e Vírgula (ASI), que permite que essas declarações permaneçam válidas sem pontos e vírgulas explícitos:

```js
let variableOne = 5
let variableTwo = 10
```

Neste exemplo, a ASI permite que o JavaScript trate cada declaração como uma declaração separada mesmo sem pontos e vírgulas. No entanto, a ASI não insere simplesmente um ponto e vírgula após toda quebra de linha.

Por exemplo, uma quebra de linha após uma declaração `return` pode causar um comportamento inesperado:

```js
function getValue() {
  return
  {
    value: 42
  };
}
```

Aqui, a ASI insere um ponto e vírgula após o `return`, então a função retorna `undefined` em vez do objeto. Escrever o objeto na mesma linha evita esse comportamento:

```js
function getValue() {
  return {
    value: 42
  };
}
```

Isso mostra por que quebras de linha e limites de declaração nem sempre são a mesma coisa.

Pontos e vírgulas também podem ser úteis quando uma quebra de linha poderia permitir que dois trechos de código fossem interpretados como uma única expressão. Uma expressão de função imediatamente invocada (IIFE) é uma função que executa assim que é definida. Uma forma de criar uma IIFE é envolver uma função anônima, que é uma função sem nome, em parênteses e adicionar `()` no final para chamá-la. Uma IIFE pode causar um problema quando a declaração anterior não termina com um ponto e vírgula:

```js
const message = "Hello"

(function () {
  console.log(message);
})()
```

Aqui, o JavaScript não insere um ponto e vírgula após a declaração da string porque o `(` seguinte pode continuar a expressão inicializadora. O JavaScript analisa a inicialização como uma chamada para a string `"Hello"`, com a expressão da função como argumento. Isso lança um `TypeError` antes que a IIFE possa executar. Adicionar um ponto e vírgula termina a declaração antes da IIFE:

```js
const message = "Hello";

(function () {
  console.log(message);
})()
```

O ponto e vírgula explícito mantém a declaração da variável e a IIFE como declarações separadas.

Pontos e vírgulas são usados em muitas linguagens de programação, incluindo C, C++ e Java. Suas regras exatas variam entre as linguagens, mas geralmente ajudam a indicar onde as declarações terminam.

Um compilador traduz código fonte para outra forma, como código de máquina, bytecode ou uma representação intermediária, dependendo da linguagem e do compilador. A compilação não necessariamente produz um arquivo executável independente.

Usar pontos e vírgulas consistentemente pode tornar os limites das declarações mais claros e facilitar a leitura e manutenção do código.
