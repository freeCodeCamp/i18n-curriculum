# --description--

Ein Minor-Release erhöht die Minor-Nummer um `1` und setzt die Patch-Nummer auf `0` zurück, während ein Patch-Release nur die Patch-Nummer um `1` erhöht.

Fügen Sie eine `elif`-Klausel hinzu, die überprüft, ob `release_type` gleich dem String `minor` ist. Wenn ja, weisen Sie `new_version` ein Tuple zu, das `major`, `minor + 1` und `0` enthält.

Fügen Sie dann eine weitere `elif`-Klausel hinzu, die überprüft, ob `release_type` gleich dem String `patch` ist. Wenn ja, weisen Sie `new_version` ein Tuple zu, das `major`, `minor` und `patch + 1` enthält.
