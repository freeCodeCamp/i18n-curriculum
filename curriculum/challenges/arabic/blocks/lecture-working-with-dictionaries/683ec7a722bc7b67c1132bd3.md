# --description--

في Python، القواميس هي هياكل بيانات مدمجة تخزن مجموعات من أزواج المفتاح-القيمة. تعمل بطريقة مشابهة جدًا للقواميس الحقيقية، حيث تبحث عن كلمة لتجد معناها المقابل.

مع قواميس Python، تستخدم مفتاحًا لتجد القيمة المقابلة له. يجب استخدام القواميس عندما تحتاج إلى ربط قيم بمفاتيح فريدة. هذا مفيد عندما تحتاج إلى إيجاد قيمة بسرعة بناءً على المفتاح، وعندما تحتاج إلى تمثيل بيانات منظمة.

## صيغة القاموس

هذه هي الصيغة النحوية العامة لقاموس في Python:

```python
dictionary = {
    key1: value1,
    key2: value2
}
```

أولًا، نجد المتغير الذي يحتوي على القاموس. لا تحتاج بالضرورة إلى تعيين القاموس إلى متغير، لكن من الشائع جدًا فعل ذلك للاحتفاظ به في الذاكرة واستخدامه لاحقًا في الكود.

بعد ذلك تأتي الأقواس المتعرجة، التي تُسمى أحيانًا أقواس متعرجة. وداخل هذه الأقواس توجد أزواج المفتاح-القيمة.

يرتبط كل مفتاح بقيمة، لذا يمكنك استخدام المفتاح للوصول إلى تلك القيمة. بعد كل قيمة، ما عدا الأخيرة، يوجد فاصلة لفصل أزواج المفتاح-القيمة المختلفة. يجب أن يكون كل مفتاح فريدًا داخل القاموس. تُستخدم السلاسل النصية عادةً كمفاتيح. تشمل أمثلة المفاتيح الصالحة الأخرى الأرقام وصفوف مرتبة من السلاسل النصية والأرقام. مع ذلك، يمكن تكرار القيم، ويمكن أن تكون من أي نوع بيانات.

## إنشاء قاموس

هنا لدينا مثال على قاموس يخزن معلومات عن وصفة بيتزا مارغريتا:

```python
pizza = {
    'name': 'Margherita Pizza',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

تم تعيين القاموس إلى المتغير `pizza`. يحتوي على أربعة أزواج مفتاح-قيمة: `name`، و`price`، و`calories_per_slice`، و`toppings`.

بديل آخر هو استخدام دالة البناء `dict()`، التي تبني القاموس من متتالية من أزواج المفتاح-القيمة.

هذه هي الصيغة النحوية المكافئة لمثال البيتزا لدينا. نمرر قائمة من الصفوف المرتبة كمعلمة إلى دالة البناء `dict()`. تحتوي هذه الصفوف على المفتاح كالعنصر الأول والقيمة كالعنصر الثاني.

```python
pizza = dict([('name', 'Margherita Pizza'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

## الوصول إلى قيم القاموس

للوصول إلى قيمة زوج مفتاح-قيمة، يمكنك استخدام هذه الصيغة المعروفة بترميز الأقواس. هي اسم المتغير الذي يحمل القاموس، متبوعًا بأقواس مربعة، والمفتاح الذي تريد الوصول إليه داخل الأقواس المربعة:

```python
dictionary[key]
```

في مثال البيتزا لدينا، إذا أردت الوصول إلى قيمة `name`، تكتب اسم المتغير `pizza`، متبوعًا بأقواس مربعة، والمفتاح `name` بين علامات اقتباس:

```python
pizza['name']
```

هذا سيُقيَّم إلى:

```python
'Margherita Pizza'
```

## تحديث قيم القاموس

لتحديث قيمة، تحتاج فقط إلى إضافة معامل التعيين، متبوعًا بالقيمة الجديدة.

إذا لم يكن المفتاح موجودًا في القاموس، سيتم إنشاء زوج مفتاح-قيمة جديد. في الإصدارات الحديثة من Python، تحافظ القواميس على ترتيب الإدخال. هذا مفيد عندما تحتاج إلى التكرار على القاموس:

```python
pizza['name'] = 'Margherita'
```

الآن قيمة المفتاح `name` هي `'Margherita'`:

```python
print(pizza['name']) # 'Margherita'
```
