# --description--

Finora hai avuto un controllo limitato sulla presentazione e l'aspetto del tuo contenuto. Per cambiare questo, userai CSS.

Un modo per aggiungere CSS a una pagina è con l'elemento `style`, solitamente posizionato all'interno del tag `head`. Qualsiasi regola CSS dentro il tag `style` si applica all'intera pagina. Ecco un esempio:

```html
<style>
  p {
    color: green;
  }
</style>
```

Aggiungi un elemento `style` all'interno dell'elemento `head`.

# --hints--

Il tuo codice dovrebbe avere un elemento `style`.

```js
assert.exists(document.querySelector('style:not(.fcc-hide-header)'));
```

Il tuo codice dovrebbe avere un tag di chiusura `</style>`.

```js
assert.match(code, /<\/style\s*>/i);
```

Il tuo elemento `style` dovrebbe essere annidato nel tuo elemento `head`.

```js
assert.exists(document.querySelector('head > style:not(.fcc-hide-header)'));
```
