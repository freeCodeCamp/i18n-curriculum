## 安裝程式碼編輯器或整合開發環境

在上一課中，你學會了如何在你的區域裝置上安裝 Python。在本課中，你將學習如何在本地執行 Python 程式碼。

在你開始在區域建立 Python 腳本之前，你需要先安裝一個程式碼編輯器或整合開發環境（IDE）。IDE 代表整合開發環境。IDE 結合了程式碼編輯器、測試工具和終端機等功能。

一個許多開發者常用的熱門程式碼編輯器是 VS Code。前往 `https://code.visualstudio.com/download` 下載 VS Code，它支援 macOS、Windows 和 Linux。這是本課程將使用的編輯器。

其他常見的 Python 開發選擇包括：

- PyCharm
- Spyder

## 建立 Python 檔案

安裝 VS Code 後，打開它並選擇 `File`，然後選擇 `Open Folder`。選擇或創建一個資料夾作為你的專案。若想在課程外多加練習，你可以準備一個名為 `python-projects` 的資料夾。

在 VS Code 左側邊欄打開 Explorer。選擇 `New File` 圖示，看起來像一張帶加號的紙張。建立一個名為 `main.py` 的檔案，然後按 <kbd>Enter</kbd>。`.py` 副檔名表示這是 Python 檔案。

打開你的 `main.py` 檔案，輸入以下程式碼：

```py
print("Hello, world!")
```

## 安裝 Python 擴充套件

要安裝微軟官方的 Python 擴充套件，請依照以下具體步驟操作：

### 方法 A：在應用程式內安裝

1. 點擊左側活動列上由四個積木組成的圖示，打開擴充套件檢視。或者，按 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>（Windows / Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>（macOS）。
1. 在頂部搜尋欄輸入 `Python`。
1. 找到名稱為 Python 的第一個結果，確認發行者是 Microsoft。
1. 點擊藍色的 <kbd>Install</kbd> 按鈕。

### 方法 B：終端機 / 命令列安裝

如果你偏好從終端機安裝擴充套件，請先確定 `code` 指令可用。在 macOS 上，打開命令面板，執行 `Shell Command: Install 'code' command in PATH`，然後重新啟動終端機。

接著執行以下指令安裝 Python 擴充套件：

```bash
code --install-extension ms-python.python
```

## 選擇 Python 直譯器

擴充套件本身是橋樑，但不包含實際的 Python 語言檔案。如果你還沒安裝 Python 直譯器，必須從官方 Python 網站另行安裝。

Python 安裝在你的作業系統後，將它與編輯器綁定：

1. 在 VS Code 中，打開任何資料夾或以 `.py` 結尾的檔案。
1. 使用 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（Windows / Linux）或 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（macOS）打開命令面板。
1. 輸入並選擇 `Python: Select Interpreter`。
1. 從你的機器列表中選擇已安裝的 Python 3 版本。它將會原生顯示在你的工作區狀態列中。

## 執行你的 Python 腳本

要執行這段程式碼，你有幾個選項。第一個選項是點擊位於右上角看起來像播放按鈕的執行按鈕。這會開啟終端機並在那裡執行你的 Python 腳本。你應該會看到文字 `Hello, world!`

另一種選擇是打開終端機，手動使用以下指令執行程式：

```bash
python main.py
```

你必須在 `main.py` 所在的資料夾執行此指令。例如，如果 `main.py` 位於名為 `python-projects` 的資料夾中，先在終端機輸入：

```bash
cd python-projects
```

接著執行：

```bash
python main.py
```

## 使用 `python3` 取代 `python`

在某些環境中，特別是在 macOS 和 Linux 系統上同時安裝了 Python 2 和 Python 3 時，你可能需要使用 `python3` 來取代 `python`。這種情況常見於 `python` 指令不存在或指向較舊版本的 Python。

```bash
python3 main.py
```
