# --description--

Hai imparato che l'assegnazione crea un alias e che il metodo `.copy()` di un dizionario crea una copia superficiale. Una copia superficiale ha un dizionario esterno separato, ma gli oggetti annidati sono ancora condivisi. Ora che sai come importare i moduli, puoi usare il modulo `copy` della libreria standard per copiare anche le collezioni annidate.

## Creare una copia profonda

La funzione `copy.deepcopy()` copia ricorsivamente le collezioni annidate. Per un dizionario che contiene una lista, crea un nuovo dizionario esterno e una lista annidata separata:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
deep_copy = copy.deepcopy(original)

print(deep_copy == original) # True
print(deep_copy is original) # False
print(deep_copy['items'] is original['items']) # False

deep_copy['items'].append('fruit')
print(original['items']) # ['bread', 'cheese']
print(deep_copy['items']) # ['bread', 'cheese', 'fruit']
```

I dizionari inizialmente hanno contenuti uguali, ma né il dizionario esterno né la lista annidata sono condivisi tra loro. Aggiungere elementi alla lista copiata lascia invariata la lista originale.

## Confronto tra assegnazione, copia superficiale e copia profonda

Creiamo tutte e tre le forme a partire dallo stesso dizionario:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
alias = original
shallow_copy = original.copy()
deep_copy = copy.deepcopy(original)

print(alias is original) # True
print(shallow_copy is original) # False
print(deep_copy is original) # False

print(alias['items'] is original['items']) # True
print(shallow_copy['items'] is original['items']) # True
print(deep_copy['items'] is original['items']) # False
```

Continuando con questi oggetti, modifica una voce di primo livello tramite ciascun nome:

```python
alias['name'] = 'Picnic'
shallow_copy['name'] = 'Snack'
deep_copy['name'] = 'Dinner'

print(original['name']) # Picnic
print(alias['name']) # Picnic
print(shallow_copy['name']) # Snack
print(deep_copy['name']) # Dinner
```

L'alias si riferisce al dizionario originale, quindi assegnare tramite `alias` modifica quel dizionario. Ogni copia ha il proprio dizionario esterno, quindi sostituire la voce `name` influisce solo su quella copia.

Ora, modifica le liste annidate:

```python
alias['items'].append('water')
shallow_copy['items'].append('fruit')
deep_copy['items'].append('soup')

print(original['items']) # ['bread', 'cheese', 'water', 'fruit']
print(alias['items']) # ['bread', 'cheese', 'water', 'fruit']
print(shallow_copy['items']) # ['bread', 'cheese', 'water', 'fruit']
print(deep_copy['items']) # ['bread', 'cheese', 'soup']
```

Il dizionario originale, il suo alias e la copia superficiale si riferiscono tutti alla stessa lista. Le modifiche tramite uno di questi riferimenti sono visibili anche agli altri. La copia profonda ha la sua lista, quindi le sue modifiche rimangono separate.

Questo funziona anche con dizionari annidati dentro liste:

```python
import copy

original = {'meals': [{'name': 'Lunch', 'items': ['bread']}]}
deep_copy = copy.deepcopy(original)
deep_copy['meals'][0]['items'].append('fruit')

print(original['meals'][0]['items']) # ['bread']
print(deep_copy['meals'][0]['items']) # ['bread', 'fruit']
```

Qui, `deepcopy()` copia il dizionario esterno, la lista `meals`, il dizionario dentro quella lista e la sua lista `items`. L'esempio usa dizionari e liste integrati; la copia profonda non significa che ogni possibile oggetto Python venga duplicato.

Usa l'assegnazione quando vuoi un altro nome per lo stesso oggetto. Usa una copia superficiale quando basta una collezione esterna separata e condividere gli oggetti annidati è accettabile. Usa una copia profonda quando le modifiche a queste collezioni annidate devono lasciare inalterate le collezioni originali.
