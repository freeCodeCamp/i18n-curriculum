# --description--

In diesem Labor erstellen Sie eine doppelt verkettete Liste, bei der jeder Knoten eine Referenz sowohl auf den nächsten als auch auf den vorherigen Knoten in der Liste hält.

**Ziel:** Erfüllen Sie die untenstehenden User Stories und bestehen Sie alle Tests, um das Labor abzuschließen.

**User Stories:**

1. Sie sollten eine Klasse namens `DoublyLinkedList` haben.
1. `DoublyLinkedList` sollte eine verschachtelte Klasse namens `Node` haben, deren `__init__`-Methode:
   - einen `element`-Parameter und einen optionalen `previous`-Parameter, der standardmäßig auf `None` gesetzt ist, entgegennimmt.
   - das `element`-Attribut auf den Wert des `element`-Parameters setzt.
   - das `previous`-Attribut auf den Wert des `previous`-Parameters setzt.
   - das `next`-Attribut auf `None` setzt.
1. Die `__init__`-Methode von `DoublyLinkedList` sollte das `length`-Attribut auf `0` setzen und die `head`- und `tail`-Attribute auf `None`.
1. `DoublyLinkedList` sollte eine `is_empty`-Methode haben, die `True` zurückgibt, wenn die Liste keine Knoten hat, und sonst `False`.
1. `DoublyLinkedList` sollte eine `add`-Methode haben, die ein `element` entgegennimmt und:
   - einen neuen `Node` erstellt, der dieses `element` hält, und ihn ans Ende der Liste anhängt.
   - das `previous`-Attribut des neuen Knotens auf den Knoten setzt, der vor der Hinzufügung der Tail war, oder auf `None`, wenn die Liste leer war.
   - den `head` (wenn die Liste leer war), den `tail` und die `length` der Liste aktualisiert.
   - nicht durch die Liste iteriert, um ihr Ende zu finden.
1. `DoublyLinkedList` sollte eine `remove`-Methode haben, die ein `element` entgegennimmt und:
   - jeden Knoten entfernt, dessen `element` dem angegebenen `element` entspricht.
   - die `next`- und `previous`-Referenzen der verbleibenden Knoten korrekt verknüpft hält.
   - den `head`, den `tail` und die `length` der Liste bei Bedarf aktualisiert.
   - die Liste unverändert lässt, wenn kein Knoten übereinstimmt oder die Liste leer ist.
1. `DoublyLinkedList` sollte eine `reverse`-Methode haben, die die Reihenfolge der Knoten vor Ort umkehrt.
1. `DoublyLinkedList` sollte eine `to_list`-Methode haben, die eine Liste der Elemente in der verketteten Liste von `head` bis `tail` zurückgibt.

class DoublyLinkedList:
    class Node:
        def __init__(self, element, previous=None):
            self.element = element
            self.previous = previous
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None
        self.tail = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element, self.tail)
        if self.is_empty():
            self.head = node
        else:
            self.tail.next = node
        self.tail = node
        self.length += 1

    def remove(self, element):
        current_node = self.head
        while current_node is not None:
            next_node = current_node.next
            if current_node.element == element:
                if current_node.previous is not None:
                    current_node.previous.next = current_node.next
                else:
                    self.head = current_node.next
                if current_node.next is not None:
                    current_node.next.previous = current_node.previous
                else:
                    self.tail = current_node.previous
                self.length -= 1
            current_node = next_node

    def reverse(self):
        current_node = self.head
        while current_node is not None:
            current_node.previous, current_node.next = current_node.next, current_node.previous
            current_node = current_node.previous
        self.head, self.tail = self.tail, self.head

    def to_list(self):
        elements = []
        current_node = self.head
        while current_node is not None:
            elements.append(current_node.element)
            current_node = current_node.next
        return elements
