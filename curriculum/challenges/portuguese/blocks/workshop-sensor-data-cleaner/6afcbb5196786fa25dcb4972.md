# --description--

No terminal, você deve ver algo como `<filter object at 0x...>` em vez das leituras. Isso acontece porque `filter()` retorna um iterador, que fornece os itens um de cada vez em vez de armazená-los todos em uma lista.

Para coletar os itens de um iterador em uma lista, você pode passá-lo para a função `list()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

Envolva a chamada `filter()` atribuída a `valid_readings` em uma chamada `list()`. No terminal, você deve ver as leituras sem os códigos de erro `-999`.
