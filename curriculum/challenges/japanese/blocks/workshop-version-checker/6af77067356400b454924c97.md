# --description--

メジャー番号が同じ場合は、マイナー番号を比較する必要があります。マイナー番号が異なる場合はマイナーアップデートであり、新しいリリースは古いバージョンでも動作する新しい機能を追加しています。

タプルをスライスすると新しいタプルが得られ、タプルの比較は最初に異なる要素のペアで止まります。例えば、`(2, 1) < (2, 2)` は `True` です。これは最初の要素が等しく、`1` が `2` より小さいためです。

`installed` の最初の2つの要素を含むスライスが `latest` の同じスライスより小さいかどうかをチェックする `elif` 節を追加してください。もしそうなら、文字列 `minor update` を `update_type` に代入してください。
