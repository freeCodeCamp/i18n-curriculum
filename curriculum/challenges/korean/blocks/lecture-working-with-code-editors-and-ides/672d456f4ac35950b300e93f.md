# --description--

운영체제에서 물려받은 기본 단축키 몇 가지는 이미 익숙할 거예요. 예를 들어, 저장할 때는 <kbd>Ctrl</kbd> + <kbd>S</kbd> (Windows/Linux) 또는 <kbd>Cmd</kbd> + <kbd>S</kbd> (macOS), 복사할 때는 <kbd>Ctrl</kbd> + <kbd>C</kbd> 또는 <kbd>Cmd</kbd> + <kbd>C</kbd>, 붙여넣을 때는 <kbd>Ctrl</kbd> + <kbd>V</kbd> 또는 <kbd>Cmd</kbd> + <kbd>V</kbd>가 VS Code에서 모두 작동합니다.

하지만 애플리케이션별로 특정된 몇 가지 단축키가 있어 생산성을 크게 높일 수 있습니다. 운영체제에 따라 일부 단축키가 다를 수 있다는 점도 기억하세요.

예를 들어, <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd>는 현재 열린 파일에 대해 설정된 포매터(예: JavaScript 프로젝트의 Prettier)를 실행합니다.

작업 공간 내 모든 파일의 텍스트 내용을 검색하려면 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (Windows/Linux) 또는 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> (macOS)를 사용하세요. 그리고 찾기 및 바꾸기를 실행하려면 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (Windows/Linux) 또는 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (macOS)를 사용하세요.

한 줄을 삭제해야 한다면 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (Windows/Linux) 또는 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd> (macOS)를 누르세요.

코드를 위한 공간이 더 필요하다면 <kbd>Ctrl</kbd> + <kbd>B</kbd> (Windows/Linux) 또는 <kbd>Cmd</kbd> + <kbd>B</kbd> (macOS)를 눌러 파일 목록과 확장 메뉴가 있는 사이드바를 숨기세요.

코드가 잘 안 보인다면 <kbd>Ctrl</kbd> + <kbd>Plus</kbd> (Windows/Linux) 또는 <kbd>Cmd</kbd> + <kbd>Plus</kbd> (macOS)로 편집기 확대를 키우고, <kbd>Ctrl</kbd> + <kbd>Minus</kbd> (Windows/Linux) 또는 <kbd>Cmd</kbd> + <kbd>Minus</kbd> (macOS)로 축소하세요.

VS Code의 또 다른 유용한 기능은 여러 줄을 동시에 편집할 수 있는 멀티라인 편집입니다. 예를 들어, <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> 및 <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Windows), <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> 및 <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd> (Linux), 또는 <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Down</kbd> 및 <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Up</kbd> (macOS)을 사용해 연속된 줄에 여러 커서를 배치할 수 있습니다. 또한 <kbd>Alt</kbd> (Windows/Linux) 또는 <kbd>Option</kbd> (macOS)를 누른 상태에서 클릭해 필요한 줄마다 커서를 추가할 수도 있습니다. 커서가 배치되면 입력하거나 삭제하는 모든 작업이 동시에 적용되어 반복적인 코드를 다룰 때 많은 시간을 절약할 수 있습니다.

마지막으로, 단축키를 잊어버렸을 때는 언제든 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows/Linux) 또는 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS)를 눌러 명령 팔레트를 열고 필요한 명령을 선택하세요.
