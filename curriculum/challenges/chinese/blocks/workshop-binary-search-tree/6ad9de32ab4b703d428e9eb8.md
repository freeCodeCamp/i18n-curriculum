# --description--

为你的 `if` 语句添加一个 `elif` 分支，检查 `key` 是否大于 `node.key`。在该分支内，调用 `self._insert`，传入 `node.right` 和 `key`，并将结果赋值给 `node.right`。

如果 `key` 与 `node.key` 相等，则两个分支都不会执行，因此不会将重复值添加到树中。
