# --description--

엘리베이터는 남아 있는 요청이 있는 한 계속 요청을 처리해야 합니다. `while` 루프는 조건이 참인 동안 반복하기 때문에 이 작업에 완벽합니다. 구문을 다시 한 번 확인하세요:

```py
while condition:
    # code to repeat
    ...
```

비어 있지 않은 리스트는 참으로 간주되고 빈 리스트는 거짓으로 간주되므로, 리스트를 루프 조건으로 사용해 리스트가 비어질 때까지 실행할 수 있습니다.

`requests`가 비어 있지 않은 동안 실행되는 `while` 루프를 만드세요. 루프 안에서 `pop(0)`을 사용해 `requests`에서 첫 번째 요청을 제거하고 `target`이라는 변수에 할당하세요. 그런 다음 `target`을 출력하세요.

`pop(0)`이 매 반복마다 리스트를 짧게 만들기 때문에 리스트는 결국 비어지고 루프는 정지합니다. 그렇지 않으면 조건이 절대 거짓이 되지 않아 루프가 무한히 실행됩니다.
