# --description--

할당이 별칭을 만든다는 것과 딕셔너리의 `.copy()` 메서드가 얕은 복사를 만든다는 것을 배웠습니다. 얕은 복사는 별도의 외부 딕셔너리를 가지지만, 중첩된 객체는 여전히 공유됩니다. 이제 모듈을 가져오는 방법을 알게 되었으니, 표준 라이브러리의 `copy` 모듈을 사용해 중첩된 컬렉션도 복사할 수 있습니다.

## 깊은 복사 만들기

`copy.deepcopy()` 함수는 중첩된 컬렉션을 재귀적으로 복사합니다. 리스트를 포함하는 딕셔너리의 경우, 새로운 외부 딕셔너리와 별도의 중첩 리스트를 생성합니다:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
deep_copy = copy.deepcopy(original)

print(deep_copy == original) # True
print(deep_copy is original) # False
print(deep_copy['items'] is original['items']) # False

deep_copy['items'].append('fruit')
print(original['items']) # ['bread', 'cheese']
print(deep_copy['items']) # ['bread', 'cheese', 'fruit']
```

딕셔너리들은 처음에는 내용이 같지만, 외부 딕셔너리도 중첩 리스트도 서로 공유되지 않습니다. 복사된 리스트에 항목을 추가해도 원본 리스트는 변경되지 않습니다.

## 할당, 얕은 복사, 깊은 복사 비교하기

같은 딕셔너리에서 세 가지 형태를 모두 만들어 봅시다:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
alias = original
shallow_copy = original.copy()
deep_copy = copy.deepcopy(original)

print(alias is original) # True
print(shallow_copy is original) # False
print(deep_copy is original) # False

print(alias['items'] is original['items']) # True
print(shallow_copy['items'] is original['items']) # True
print(deep_copy['items'] is original['items']) # False
```

이 객체들을 계속 사용하며, 각 이름을 통해 최상위 항목을 변경해 봅시다:

```python
alias['name'] = 'Picnic'
shallow_copy['name'] = 'Snack'
deep_copy['name'] = 'Dinner'

print(original['name']) # Picnic
print(alias['name']) # Picnic
print(shallow_copy['name']) # Snack
print(deep_copy['name']) # Dinner
```

별칭은 원본 딕셔너리를 참조하므로 `alias`를 통해 할당하면 그 딕셔너리가 변경됩니다. 각 복사본은 자체 외부 딕셔너리를 가지므로 `name` 항목을 바꾸면 그 복사본에만 영향을 줍니다.

다음으로 중첩된 리스트를 변경해 봅시다:

```python
alias['items'].append('water')
shallow_copy['items'].append('fruit')
deep_copy['items'].append('soup')

print(original['items']) # ['bread', 'cheese', 'water', 'fruit']
print(alias['items']) # ['bread', 'cheese', 'water', 'fruit']
print(shallow_copy['items']) # ['bread', 'cheese', 'water', 'fruit']
print(deep_copy['items']) # ['bread', 'cheese', 'soup']
```

원본 딕셔너리, 별칭, 얕은 복사는 모두 같은 리스트를 참조합니다. 이 참조들 중 어느 하나를 통해 변경하면 모두에게 보입니다. 깊은 복사는 자체 리스트를 가지므로 변경 사항이 분리되어 있습니다.

이것은 리스트 안에 중첩된 딕셔너리에도 적용됩니다:

```python
import copy

original = {'meals': [{'name': 'Lunch', 'items': ['bread']}]}
deep_copy = copy.deepcopy(original)
deep_copy['meals'][0]['items'].append('fruit')

print(original['meals'][0]['items']) # ['bread']
print(deep_copy['meals'][0]['items']) # ['bread', 'fruit']
```

여기서 `deepcopy()`는 외부 딕셔너리, `meals` 리스트, 그 리스트 안의 딕셔너리, 그리고 그 딕셔너리의 `items` 리스트를 복사합니다. 예제는 내장 딕셔너리와 리스트를 사용하며, 깊은 복사가 모든 파이썬 객체를 복제한다는 뜻은 아닙니다.

같은 객체에 대해 다른 이름이 필요할 때는 할당을 사용하세요. 별도의 외부 컬렉션만 필요하고 중첩 객체 공유가 괜찮을 때는 얕은 복사를 사용하세요. 중첩된 컬렉션에 대한 변경이 원본 컬렉션에 영향을 주지 않아야 할 때는 깊은 복사를 사용하세요.
