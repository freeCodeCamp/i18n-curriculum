# --description--

El ámbito determina dónde puedes usar una variable en tu código.

Python tiene reglas adicionales de ámbito. Por ahora, enfócate en el ámbito local y global.

Una variable creada afuera de una función tiene ámbito global. Puedes usarla tanto dentro como fuera de funciones.

Una variable creada dentro de una función tiene ámbito local. Solo puedes usarla dentro de esa función. Los parámetros de función también son variables locales.

Aquí tienes un ejemplo de ámbito local y global:

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

La variable `tax_rate` es global porque se crea afuera de la función. La función `calculate_tax` puede leerla, y la segunda llamada a `print()` también puede leerla.

El parámetro `price` y la variable `tax` son locales a `calculate_tax`. Están disponibles mientras esa función se ejecuta, pero no afuera. La última llamada a `print()` genera un `NameError` porque `tax` no está definida en el ámbito global.
