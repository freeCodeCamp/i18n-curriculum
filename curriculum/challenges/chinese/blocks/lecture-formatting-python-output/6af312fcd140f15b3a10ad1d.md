# --description--

在之前关于数字和数学运算的课程中，你使用过像 `.2f` 这样的格式说明符来控制数字显示的小数位数。

格式说明符还可以控制一个值占用多少空间以及它的位置。这在你想让输出整齐排列成列时非常有用。

## 设置最小宽度和对齐方式

冒号后面的数字设置字段的最小宽度，也就是值应该占用的字符数。如果值比这个宽度短，Python 会添加空格直到达到该宽度。下面是一个例子：

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

在宽度前使用特定符号可以控制值在字段中的位置。以下是这些特定符号：

- 小于号（`<`）将值左对齐
- 大于号（`>`）将值右对齐
- 脱字符号（`^`）将值居中。

下面是这三个符号的示例：

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

`'Tea'` 包含三个字符，所以 Python 添加了五个空格以达到宽度 `8`。

- 使用 `<`，空格加在值后面
- 使用 `>`，空格加在值前面
- 使用 `^`，空格分布在两边以居中文本。

如果空格不能均分，多余的空格会加在右边：

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

如果省略对齐符号，字符串默认左对齐，而数字默认右对齐：

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## 使用填充字符

默认情况下，Python 用空格填充。要使用其他字符填充，请将该字符放在对齐符号之前：

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

在 `*^9` 中，`*` 是填充字符，`^` 使值居中，`9` 是最小宽度。注意，填充字符只能和对齐符号一起使用。

## 结合宽度和查准率

你可以将对齐、宽度和之前课程中学到的查准率结合在一个格式说明符中：

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

上面例子中的格式说明符表示：右对齐，最小宽度为 `7`，显示两位小数。Python 先将数字格式化为 `4.50`，长度为四个字符，然后在前面添加三个空格以填满宽度 `7`。

## 创建语句行

你可以将标签和金额放在同一行。如果每行使用相同的格式说明符，列就会对齐：

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

每个标签在一个宽度为 `12` 字符的字段中左对齐，并用点填充，而每个金额在一个宽度为 `8` 字符的字段中右对齐，因此小数点对齐。

## 宽度是最小值，不是最大值

宽度只会添加填充，不会截断值。如果值比指定宽度长，整个值都会显示：

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

数字也是如此。下面的例子中，格式化后的金额需要八个字符，所以它忽略了指定的宽度 `7`：

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

在 `:7.2f` 中，`7` 是最小宽度，而不是金额长度的限制。Python 从不截断数字以适应宽度。

这就是为什么你应该选择足够大的宽度来适应预期的值，否则列就不会对齐。

如果你想限制字符串的长度，可以在格式说明符中添加查准率。对于字符串，查准率设置显示的最大字符数：

```py
label = 'Long description'

print(f'|{label:.8}|') # |Long des|
print(f'|{label:<12.8}|') # |Long des    |
```

在 `<12.8` 中：

- `<` 将值左对齐
- `12` 是最小宽度
- `.8` 是最大字符数。

Python 先将字符串截断为八个字符，然后填充到宽度十二。

注意，查准率对字符串和数字的含义不同。对于 `.2f`，`.2` 设置小数位数。对于字符串，`.8` 设置最大字符数。
