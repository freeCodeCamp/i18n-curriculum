# --description--

Die `__repr__`-Methode ist eine spezielle Methode, die eine String-Darstellung des Objekts zurückgeben soll, mit der es instanziiert werden kann.

Zum Beispiel sollte die `__repr__`-Methode von `Employee('Charlie', 'developer')` den String `Employee('Charlie', 'developer')` zurückgeben, der derselbe String ist, mit dem das Objekt erstellt wurde.

Wenn Sie Anführungszeichen um jeden Wert haben, funktioniert das Ergebnis nicht mehr, wenn ein Wert ein Anführungszeichen enthält. Für einen Mitarbeiter namens `O'Reilly` mit dem Level `junior` würden Sie `Employee('O'Reilly', 'junior')` erhalten, was ungültig ist, weil der Apostroph die Zeichenkette vorzeitig schließt.

Pythons eingebaute `repr()`-Funktion gibt eine String-Darstellung eines Werts zurück. Für Strings fügt sie die Anführungszeichen hinzu und maskiert alle Zeichen, die es benötigen:

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

Innerhalb eines f-Strings können Sie `!r` nach einem Ausdruck hinzufügen, um `repr()` darauf anzuwenden:

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

Geben Sie Ihrer `Employee`-Klasse eine `__repr__`-Methode mit einem `self`-Parameter. Lassen Sie sie einen String zurückgeben, der verwendet werden kann, um das Objekt zu instanziieren, und verwenden Sie `!r` bei `self.name` und `self.level`, damit alle Anführungszeichen oder Backslashes erhalten bleiben.
