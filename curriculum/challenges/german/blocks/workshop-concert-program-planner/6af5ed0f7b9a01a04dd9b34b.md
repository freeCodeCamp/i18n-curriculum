# --description--

Unpacking ermöglicht es Ihnen, die Elemente einer Liste in einer einzigen Zeile mehreren Variablen zuzuweisen. Sie können eine mit * markierte Variable verwenden, um alle verbleibenden Elemente in einer Liste zu sammeln:

```py
fruits = ['apple', 'banana', 'cherry']
first, *rest = fruits
print(first) # apple
print(rest) # ['banana', 'cherry']
```

Packen Sie `pieces` in drei Variablen aus: `opening` für das erste Element, `middle` für alle Elemente dazwischen und `closing` für das letzte Element. Geben Sie dann `opening`, `middle` und `closing` in drei separaten `print()`-Aufrufen aus.
