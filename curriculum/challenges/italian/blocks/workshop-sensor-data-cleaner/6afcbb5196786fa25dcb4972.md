# --description--

Nel terminale dovresti vedere qualcosa come `<filter object at 0x...>` invece delle letture. Questo succede perché `filter()` restituisce un iteratore, che ti dà gli elementi uno alla volta invece di memorizzarli tutti in una lista.

Per raccogliere gli elementi di un iteratore in una lista, puoi passarli alla funzione `list()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

Avvolgi la chiamata a `filter()` assegnata a `valid_readings` in una chiamata a `list()`. Nel terminale dovresti vedere le letture senza i codici di errore `-999`.
