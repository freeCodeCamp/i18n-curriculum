# --description--

Agora você precisa linkar o arquivo `styles.css`, para que os estilos sejam aplicados novamente.

O elemento `link` permite que você faça link para recursos externos como folhas de estilo e ícones do site. Aqui está a sintaxe básica para usar o elemento `link` para linkar um CSS externo:

```html
<link rel="stylesheet" href="styles.css" />
```

O atributo `rel` especifica a relação entre o recurso linkado e o documento HTML. Neste caso, você precisa especificar que esse recurso linkado é uma `stylesheet`. O atributo `href` especifica a localização do recurso externo.

Dentro do elemento `head`, adicione um elemento `link`. Dê a ele um atributo `rel` com o valor `"stylesheet"` e um atributo `href` com o valor `"styles.css"`.

**Nota:** O elemento `link` é um elemento void, o que significa que ele não tem tag de fechamento. Elementos void devem ser escritos como `<element>` em vez de `<element></element>`.
