# --description--

- **Ricorsione**: una tecnica in cui una funzione chiama se stessa. Ogni chiamata lavora su una versione più piccola del problema originale fino a raggiungere un caso base che ferma ulteriori chiamate ricorsive.
- **Caso base**: la condizione che ferma la ricorsione. Devi definire con attenzione il caso base. Altrimenti, la funzione può continuare a chiamare se stessa finché Python non genera un `RecursionError`.
- **Caso ricorsivo**: la parte della funzione che chiama di nuovo la funzione con un argomento che la avvicina al caso base, come `number - 1` quando si conta a ritroso.

```py
def recursive_countdown(number):
    if number < 1:  # Base case
        return
    print(number)
    recursive_countdown(number - 1)  # Recursive case

recursive_countdown(5)  # Prints 5, 4, 3, 2, 1
```

- **Ordine di esecuzione**: la posizione della chiamata ricorsiva cambia quando viene eseguito il resto del codice della funzione. Il codice posizionato prima della chiamata ricorsiva viene eseguito mentre le chiamate si approfondiscono, mentre il codice posizionato dopo viene eseguito mentre le chiamate ritornano. Spostare `print()` dopo la chiamata ricorsiva fa sì che la funzione stampi i numeri in ordine crescente:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)  # Prints 1, 2, 3, 4, 5
```

- **Call stack**: una struttura dati last-in, first-out che Python usa per tenere traccia delle chiamate di funzione attive. Ogni volta che una funzione viene chiamata, Python aggiunge un frame per quella chiamata in cima allo stack. Il frame contiene informazioni come gli argomenti della funzione e le variabili locali.
- **Ripresa delle chiamate**: una chiamata si mette in pausa quando effettua la sua chiamata ricorsiva. Quando il caso base ritorna, Python rimuove quella chiamata dalla cima dello stack e le chiamate precedenti riprendono dopo la loro chiamata ricorsiva e ritornano in ordine last-in, first-out:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

L'output è:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

- **Costruire una lista ricorsivamente**: ogni chiamata riprende quando la sua chiamata ricorsiva ritorna, poi usa il valore restituito. La funzione `countup` qui sotto restituisce una lista vuota nel caso base. Ogni altra chiamata riceve la lista dalla sua chiamata ricorsiva, aggiunge il proprio numero e restituisce la lista:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(5))  # [1, 2, 3, 4, 5]
```

La chiamata con `1` riceve `[]` e restituisce `[1]`, la chiamata con `2` riceve `[1]` e restituisce `[1, 2]`, e così via fino a che la chiamata con `5` restituisce `[1, 2, 3, 4, 5]`.

- **Applicazioni della ricorsione**: la ricorsione può gestire attività semplici come contare a ritroso, contare in avanti e costruire una lista. È anche utile per problemi con una profondità sconosciuta, come attraversare un albero dei file.
