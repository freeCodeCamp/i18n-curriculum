## Was sind Funktionen?

Funktionen sind wiederverwendbare Codeabschnitte, die ausgeführt werden, wenn Sie sie aufrufen. Python stellt eingebaute Funktionen bereit, darunter `print()`, die Sie in vorherigen Lektionen verwendet haben.

Eine weitere hilfreiche eingebaute Funktion ist `input()`, mit der Sie den Benutzer zur Eingabe auffordern können:

```python
name = input('What is your name?') # User types "Kolade" and presses Enter  
print('Hello', name) # Output: Hello Kolade
```

Andererseits wandelt `int()` eine Zahl, einen Boolean oder einen String, der eine ganze Zahl darstellt, in eine ganze Zahl um:

```python
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0 
```

## Funktionen definieren und aufrufen

Sie können auch eigene benutzerdefinierte Funktionen schreiben. Dazu verwenden Sie das Schlüsselwort `def`, gefolgt vom Namen, den Sie Ihrer Funktion geben möchten, einem Paar runder Klammern und einem Doppelpunkt. Dann schreiben Sie in einer neuen Zeile den Code, den Ihre Funktion ausführen soll. Der Code, den die Funktion ausführt, wird auch als Funktionskörper bezeichnet.

Hier ist ein Beispiel für eine benutzerdefinierte Funktion namens `hello`, die den String `Hello World` im Terminal ausgibt:

```python
def hello():
    print('Hello World')
```

Um die Funktion auszuführen, müssen Sie sie mit ihrem Namen gefolgt von einem Paar runder Klammern aufrufen:

```python
hello() # Hello World
```

Beachten Sie die Einrückung vor `print('Hello World')`. Wie Sie sich aus vorherigen Lektionen erinnern, verwendet Python Einrückungen, um zu bestimmen, welche Anweisungsgruppen zusammengehören. Diese Anweisungsgruppen nennt man Codeblöcke.

## Parameter und Argumente verwenden

Hier ist eine weitere einfache Funktion, die die Summe von zwei Zahlen im Terminal ausgibt:

```python
def calculate_sum(a, b):
    print(a + b)
```

Sie sehen, dass unsere Funktion `calculate_sum` `a` und `b` in ihren Klammern hat, getrennt durch ein Komma. Diese nennt man Parameter. Denken Sie an Parameter als Platzhaltervariablen, die als „Slots“ für die Werte dienen, die Sie beim Aufrufen der Funktion übergeben.

Um die Parameter zu verwenden, müssen Sie „Argumente“ übergeben. Argumente sind die Werte, die Sie einer Funktion beim Aufrufen übergeben.

So rufen Sie die Funktion `calculate_sum` auf, um die Zahlen `3` und `1` zusammenzuzählen:

```python
calculate_sum(3, 1) # 4
```

Wenn Sie die Funktion ohne die richtige Anzahl von Argumenten aufrufen, erhalten Sie einen `TypeError`:

```python
calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

## Positions- und Schlüsselwortargumente

Die Argumente in `calculate_sum(3, 1)` sind Positionsargumente. Python ordnet sie den Parametern nach ihrer Position zu: `3` wird `a` zugewiesen, und `1` wird `b` zugewiesen.

Hier ist eine Funktion, bei der die Reihenfolge der Argumente wichtig ist:

```python
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

Wenn Sie die Positionsargumente vertauschen, erhält `name` den Wert `25` und `age` erhält `'Alice'`:

```python
introduce(25, 'Alice')
# My name is 25 and I am Alice years old.
```

Sie können auch Schlüsselwortargumente übergeben, indem Sie den Parameternamen gefolgt von `=` und einem Wert schreiben. Python ordnet diese Argumente nach Namen zu, sodass Sie sie in einer anderen Reihenfolge schreiben können:

```python
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

Hier übergibt `name='Alice'` den Wert `'Alice'` an den Parameter `name`. Es wird keine Variable namens `name` außerhalb der Funktion zugewiesen.

Sie können Positions- und Schlüsselwortargumente kombinieren, aber die Positionsargumente müssen zuerst kommen:

```python
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

Ein Positionsargument nach einem Schlüsselwortargument führt zu einem `SyntaxError`:

```python
introduce(name='Alice', 25)
# SyntaxError: positional argument follows keyword argument
```

Sie können auch nicht mehr als einen Wert für denselben Parameter angeben:

```python
introduce('Alice', name='Bob', age=25)
# TypeError: introduce() got multiple values for argument 'name'
```

In diesem Aufruf liefert das Positionsargument `'Alice'` bereits den Wert für `name`. Das Übergeben von `name='Bob'` liefert einen zweiten Wert für denselben Parameter.

## Werte aus Funktionen zurückgeben

Funktionen verwenden auch ein spezielles Schlüsselwort `return`, um die Funktion zu verlassen und einen Wert zurückzugeben. Wenn Sie `return` nicht explizit verwenden, gibt Python standardmäßig `None` zurück.

Wie Sie in der Lektion zu Identitätsoperatoren gelernt haben, steht `None` für das Fehlen eines Werts. Hier zeigt es an, dass die Funktion kein explizites Ergebnis zurückgegeben hat.

Hier ist ein Beispiel:

```python
def calculate_sum(a, b):
    print(a + b)

my_sum = calculate_sum(3, 1) # 4
print(my_sum) # None
```

Sie sehen, dass die Funktion `calculate_sum` die Summe von `a` und `b` ausgibt, aber nichts explizit zurückgibt. Wenn wir also ihr Ergebnis `my_sum` zuweisen, ist der Wert tatsächlich `None`. Um das zu beheben, können Sie das Schlüsselwort `return` verwenden, um das Ergebnis zurückzugeben:

```python
def calculate_sum(a, b):
    return a + b

my_sum = calculate_sum(3, 1)
print(my_sum) # 4
```

Jetzt gibt `calculate_sum` die Summe von `a` und `b` zurück, die in `my_sum` gespeichert wird.
