# --description--

In der Softwareentwicklung ist eine Bibliothek wie ein Werkzeugkasten für Entwickler.

Anstatt jeden einzelnen Teil des Codes selbst von Grund auf neu zu implementieren, stellt Ihnen eine Bibliothek vorgefertigten und wiederverwendbaren Code zur Verfügung, wie Funktionen, Klassen und Datenstrukturen, die Sie in Ihren Projekten verwenden können.

Die Python-Standardbibliothek ist eine Sammlung von Modulen und Paketen, die mit Python geliefert werden. Drittanbieter-Pakete werden separat entwickelt und müssen normalerweise installiert werden, bevor Sie sie verwenden können. Die Standardbibliothek bietet Lösungen für häufige Programmieraufgaben, wie zum Beispiel:

* Interaktion mit dem Betriebssystem.

* Arbeiten mit Dateien.

* Netzwerken.

* Arbeiten mit Datum und Uhrzeit.

* Ausführen mathematischer Operationen.

* Verwendung von regulären Ausdrücken.

* Testen und Debuggen Ihres Codes.

* Und vieles mehr!

Einige Beispiele für Standardbibliotheksmodule sind `math`, `random`, `re` (Kurzform für „regulärer Ausdruck“) und `datetime`.

Das `math`-Modul enthält hilfreiche Funktionen für komplexere mathematische Operationen.

Das `random`-Modul ist nützlich, um Zufallszahlen zu erzeugen.

Das `re`-Modul wird für die Arbeit mit regulären Ausdrücken verwendet.

Das `datetime`-Modul ist hilfreich für die Arbeit mit Daten und Zeiten in Python.

Module können Klassen sowie Funktionen und Konstanten bereitstellen. Hier ist ein Beispiel für eine Klasse aus dem `datetime`-Modul. Wir erstellen ein Datumsobjekt, das den 15. Juli 1959 darstellt. Dann weisen wir dieses `date`-Objekt einer Variablen zu und greifen mit Punktnotation einzeln auf Tag, Monat und Jahr zu:

```python
import datetime
birthday = datetime.date(1959, 7, 15)
print(birthday.day)    # 15
print(birthday.month)  # 7
print(birthday.year)   # 1959
```

Um ein Modul für eine bestimmte Aufgabe zu finden, durchsuchen Sie die [Python-Standardbibliotheksreferenz](https://docs.python.org/3/library/index.html), in der Module nach Themen gruppiert sind. Die Dokumentation jedes Moduls erklärt, was es bietet und wie man es verwendet. Zum Beispiel beschreibt die [`datetime`-Dokumentation](https://docs.python.org/3/library/datetime.html) die Klassen und Methoden, die für die Arbeit mit Daten und Zeiten verfügbar sind.

Sie können auch die `help()`-Funktion verwenden, um die Dokumentation eines Moduls oder einer Funktion anzuzeigen. Beachten Sie, dass `help()` derzeit im freeCodeCamp-Editor nicht verfügbar ist.

Zum Beispiel zeigt dieser Code Informationen über das `math`-Modul an:

```py
import math
help(math)
```

Hier ist ein Auszug aus der Ausgabe:

```md
Help on built-in module math:

NAME
    math

DESCRIPTION
    This module provides access to the mathematical functions
    defined by the C standard.

FUNCTIONS
    acos(x, /)
        Return the arc cosine (measured in radians) of x.

...
...
...
```

Sie können auch die Dokumentation einer bestimmten Funktion abrufen:

```py
import math
help(math.comb)
```

Dies ist die Ausgabe:

```md
Help on built-in function comb in module math:

comb(n, k, /)
    Number of ways to choose k items from n items without repetition and without order.
    
    Evaluates to n! / (k! * (n - k)!) when k <= n and evaluates
    to zero when k > n.
    
    Also called the binomial coefficient because it is equivalent
    to the coefficient of k-th term in polynomial expansion of the
    expression (1 + x)**n.
    
    Raises TypeError if either of the arguments are not integers.
    Raises ValueError if either of the arguments are negative.
```

Um herauszufinden, welche Namen ein Modul bereitstellt, können Sie die `dir()`-Funktion verwenden. Sie listet Funktionen auf, wie `math.floor`, um eine Zahl abzurunden, und Konstanten, wie `math.e` (Eulersche Zahl) und `math.pi`. Außerdem listet sie einige andere Namen auf, die Sie später im Curriculum kennenlernen werden:

```py

print(dir(math))
```

## --text--

Nach dem Import des `math`-Moduls, welcher Ausdruck zeigt speziell die Dokumentation für die Funktion `math.comb` an?

## --answers--

`help(math)`

### --feedback--

Dies zeigt die Dokumentation für das gesamte `math`-Modul an, nicht nur für die `comb`-Funktion.

---

`dir(math.comb)`

### --feedback--

Die `dir()`-Funktion gibt die auf einem Objekt verfügbaren Namen zurück, nicht dessen Dokumentation.

---

`help(math.comb)`

---

`math.comb.help()`

### --feedback--

Die `help()`-Funktion ist ein eingebautes Python-Feature, keine Methode von `math.comb`.
