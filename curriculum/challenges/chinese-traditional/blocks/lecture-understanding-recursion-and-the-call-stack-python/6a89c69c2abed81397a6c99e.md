# --description--

遞迴是一種函式呼叫自身的技巧。每次呼叫都處理原始問題的較小版本，直到達到停止遞迴的條件。這個停止條件稱為基底案例。

遞迴函式可以解決深度未知的問題，例如遍歷檔案樹。它們也能執行較簡單的任務，例如從指定數字倒數。

這裡有一個名為 `recursive_countdown` 的函式，它接受一個數字並列印出來：

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

呼叫該函式會列印 `5`，但尚未開始倒數。在讓函式呼叫自身之前，你需要定義它的基底案例。若沒有可達的基底案例，函式會持續呼叫自身。Python 最終會停止呼叫並引發 `RecursionError`。

對於這個倒數，函式應該在 `number` 小於 `1` 時停止：

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

`if` 述語是基底案例。當 `number` 小於 `1` 時，`return` 結束該次函式呼叫。

函式仍需要一個遞迴案例。遞迴案例會再次呼叫函式，並帶入一個使它朝向基底案例前進的引數。要倒數，呼叫 `recursive_countdown` 並傳入 `number - 1`：

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

這會列印數字 `5`、`4`、`3`、`2` 和 `1`。

遞迴呼叫的位置會影響數字列印的順序。如果 `print()` 呼叫在遞迴呼叫之後，函式會以遞增順序列印數字：

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

這會列印數字 `1`、`2`、`3`、`4` 和 `5`。要理解原因，你需要了解呼叫堆疊。

呼叫堆疊是 Python 用來追蹤作用中函式呼叫的後進先出資料結構。當函式被呼叫時，Python 會在堆疊頂端加入該呼叫的訊框。訊框包含函式的引數和區域變數等資訊。

考慮這個版本的倒數：

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

輸出是：

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

呼叫 `recursive_countdown(3)` 時，當它呼叫 `recursive_countdown(2)` 就會暫停。帶入 `2` 的呼叫在呼叫帶入 `1` 的函式時暫停，而帶入 `1` 的呼叫在呼叫帶入 `0` 的函式時暫停。

帶入 `0` 的呼叫達到基底案例並返回。Python 從堆疊頂端移除該呼叫，因此帶入 `1` 的呼叫在其遞迴呼叫後恢復。剩下的呼叫依序恢復並以相反順序返回：`1`、`2` 和 `3`。

每個遞迴函式都需要一個基底案例和一個朝向基底案例前進的遞迴案例。當基底案例返回時，先前的呼叫會以後進先出順序恢復。
