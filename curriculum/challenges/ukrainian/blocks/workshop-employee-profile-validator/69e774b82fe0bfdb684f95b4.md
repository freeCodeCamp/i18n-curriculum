# --description--

Іноді потрібно перевірити, з чого починається рядок. Для цього Python надає метод `.startswith()`. Він повертає `True`, якщо рядок починається з заданого префікса; інакше повертає `False`.

Ось приклад:

```python
code = 'EMP-001'
print(code.startswith('EMP')) # True
print(code.startswith('001')) # False
```
