# --description--

أحيانًا يكون الرقم مناسبًا لحساباتك لكنه يبدو غير مكتمل قليلًا عند طباعته. إذا كنت تعرض سعرًا، على سبيل المثال، قد يبدو `12.50` أكثر طبيعية من `12.5`.

تسمح لك سلسلة f بالتحكم في شكل الرقم عند عرضه، دون تغيير القيمة الأصلية، حتى تستمر في استخدامه في الحسابات.

## كيف تعمل مواصفات التنسيق

التعبير `f"{value:.2f}"` يعرض `value` بدقة رقمين بعد الفاصلة العشرية.

داخل الأقواس، لكل حرف دور محدد:

- النقطتان `:` تقدمان مواصفة التنسيق
- `.2` يحدد رقمين عشريين
- `f` يحدد العرض بنظام النقطة الثابتة، الذي يعرض الرقم بصيغة عشرية.

هذا يعني أن `print(f"{12.5:.2f}")` ينتج `12.50`، مع بقاء القيمة الأصلية دون تغيير:

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

الناتج يظهر `12.50` لأن مواصفة التنسيق `.2f` تعرض دائمًا رقمين عشريين، لذا تضيف Python صفرًا في النهاية. القيمة المخزنة في `value` لا تزال `12.5`.


من ناحية أخرى، تنسيق قيمة مثل `12.3456` باستخدام `.2f` ينتج `12.35`، لأن الرقم يجب أن يُقرب للعرض:

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## التنسيق باستخدام سلسلة F ينتج سلسلة نصية

سلسلة f تنتج سلسلة نصية:

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

هذا يعني أنه يمكنك حفظ السلسلة الناتجة بشكل منفصل ولا تزال تستخدم الرقم الأصلي في الحسابات.

## كيف يختلف `round()` عن تنسيق سلسلة F

تعبير مثل `round(value, 2)` يعطيك نتيجة رقمية يمكنك استخدامها في حسابات لاحقة.

طباعة تلك النتيجة تستخدم عرض الأرقام المعتاد في Python، لذا لا تضمن وجود أصفار في النهاية:

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## التنسيق لا يغير القيمة الأساسية

كما رأيت سابقًا، بعض الأعداد العشرية مثل `0.1` و `0.2` لا يمكن تمثيلها إلا تقريبًا كأعداد عائمة. لذلك، مجموعها قد يبدو مفاجئًا قليلًا عند طباعته مباشرة:

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

كما ترى، سلسلة f تقرب المجموع للعرض فقط. أي حساب يستخدم `total` لا يزال يستخدم نفس القيمة العائمة.
