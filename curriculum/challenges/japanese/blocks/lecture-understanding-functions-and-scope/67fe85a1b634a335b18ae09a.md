# --description--

スコープはコード内で変数を使える範囲を決めます。

Pythonには追加のスコープルールがあります。ここではローカルスコープとグローバルスコープにフォーカスしてください。

関数の外で作成された変数はグローバルスコープを持ちます。関数の内外どちらでも使えます。

関数の中で作成された変数はローカルスコープを持ちます。その関数の中でしか使えません。関数のパラメータもローカル変数です。

ローカルスコープとグローバルスコープの例を示します：

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

`tax_rate` 変数は関数の外で作成されているのでグローバルです。`calculate_tax` 関数はこれを読み取れますし、2回目の `print()` 呼び出しも読み取れます。

`price` パラメータと `tax` 変数は `calculate_tax` にローカルです。その関数が実行されている間だけ使えますが、外では使えません。最後の `print()` 呼び出しは `tax` がグローバルスコープに定義されていないため `NameError` を発生させます。
