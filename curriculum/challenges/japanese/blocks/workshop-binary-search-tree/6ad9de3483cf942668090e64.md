# --description--

再帰呼び出しはツリーを一段ずつ下っていきますが、停止する場所が必要です。

右方向の次のノードが存在しない場合、`_insert` は `node` に `None` を渡して呼び出されます。そこが新しい値が入る空き場所です。現在のメソッドは `None` に対して `node.key` にアクセスしようとしてエラーになります。

`_insert` メソッドの最初に、既存の `if` 文の前に基本ケースを追加してください：`node is None` をチェックする `if` 文を追加し、与えられた `key` で新しい `TreeNode` を返します。前の呼び出しはその新しいノードを親の `node.left` または `node.right` に代入します。
