# --description--

O método `__repr__` é um método especial que deve retornar uma representação em string do objeto que pode ser usada para instanciá-lo.

Por exemplo, o método `__repr__` de `Employee('Charlie', 'developer')` deve retornar a string `Employee('Charlie', 'developer')`, que é a mesma string usada para criar o objeto.

Se você colocar aspas ao redor de cada valor, o resultado quebra quando um valor contém uma aspa. Para um funcionário chamado `O'Reilly` com nível `junior`, você teria `Employee('O'Reilly', 'junior')`, que não é válido porque o apóstrofo fecha a string cedo demais.

A função embutida `repr()` do Python retorna uma representação em string de um valor. Para strings, ela adiciona as aspas e faz escape de quaisquer caracteres que precisem:

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

Dentro de uma f-string, você pode adicionar `!r` após uma expressão para aplicar `repr()` nela:

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

Dê à sua classe `Employee` um método `__repr__` com um parâmetro `self`. Faça-o retornar uma string que possa ser usada para instanciar o objeto, usando `!r` em `self.name` e `self.level` para que quaisquer aspas ou barras invertidas sejam preservadas.
