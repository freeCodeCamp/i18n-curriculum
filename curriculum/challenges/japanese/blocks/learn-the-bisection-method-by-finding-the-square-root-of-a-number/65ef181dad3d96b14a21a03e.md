# --description--

二分法は、二分探索法とも呼ばれ、実数値関数の根を見つけるために二分探索を使います。根が存在する区間を絞り込んでいき、指定された許容誤差内の値に収束するまで続けます。

このプロジェクトでは、二分法を使って数の近似平方根を求めます。

まず、`square_root_bisection` という名前の関数を作成してください。パラメータはまだ空のままにしておきます。
