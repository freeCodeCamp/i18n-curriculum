# --description--

في الطرفية، يجب أن ترى شيئًا مثل `<filter object at 0x...>` بدلًا من القراءات. يحدث هذا لأن `filter()` تُرجع مُكرّرًا، يعطيك العناصر واحدة تلو الأخرى بدلًا من تخزينها كلها في قائمة.

لجمع عناصر المُكرّر في قائمة، يمكنك تمريرها إلى الدالة `list()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

غلف استدعاء `filter()` المُعيّن إلى `valid_readings` باستدعاء `list()`. في الطرفية، سترى القراءات بدون رموز الخطأ `-999`.
