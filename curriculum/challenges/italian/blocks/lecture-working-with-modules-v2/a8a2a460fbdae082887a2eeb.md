# --description--

Nello sviluppo software, una libreria è come una cassetta degli attrezzi per gli sviluppatori.

Invece di dover implementare ogni singola parte del codice da zero, una libreria ti offre codice già scritto e riutilizzabile, come funzioni, classi e strutture dati che puoi usare nei tuoi progetti.

La libreria standard di Python è una raccolta di moduli e pacchetti inclusi con Python. I pacchetti di terze parti sono sviluppati separatamente e di solito devono essere installati prima di poterli usare. La libreria standard offre soluzioni per attività di programmazione comuni, come:

* Interagire con il sistema operativo.

* Lavorare con i file.

* Reti.

* Gestire date e orari.

* Eseguire operazioni matematiche.

* Usare espressioni regolari.

* Testare ed eseguire il debug del tuo codice.

* E molto altro!

Alcuni esempi di moduli della libreria standard sono `math`, `random`, `re` (abbreviazione di "espressioni regolari") e `datetime`.

Il modulo `math` ha funzioni utili per eseguire operazioni matematiche più complesse.

Il modulo `random` è utile per generare numeri casuali.

Il modulo `re` serve per lavorare con le espressioni regolari.

Il modulo `datetime` è utile per lavorare con date e orari in Python.

I moduli possono fornire classi oltre a funzioni e costanti. Ecco un esempio di una classe del modulo `datetime`. Creiamo un oggetto date che rappresenta il 15 luglio 1959. Poi assegniamo quell'oggetto `date` a una variabile e consultiamo giorno, mese e anno singolarmente usando la notazione a punto:

```python
import datetime
birthday = datetime.date(1959, 7, 15)
print(birthday.day)    # 15
print(birthday.month)  # 7
print(birthday.year)   # 1959
```

Per trovare un modulo per un'attività specifica, consulta il [riferimento della libreria standard di Python](https://docs.python.org/3/library/index.html), dove i moduli sono raggruppati per argomento. La documentazione di ogni modulo spiega cosa offre e come usarlo. Per esempio, la [documentazione di `datetime`](https://docs.python.org/3/library/datetime.html) descrive le classi e i metodi disponibili per lavorare con date e orari.

Puoi anche usare la funzione `help()` per mostrare la documentazione di un modulo o di una funzione. Nota che `help()` non è attualmente disponibile nell'editor di freeCodeCamp.

Per esempio, questo codice mostra informazioni sul modulo `math`:

```py
import math
help(math)
```

Ecco un estratto dell'output:

```md

```

Puoi anche ottenere la documentazione di una funzione specifica:

```py
import math
help(math.comb)
```

Questo è l’output:

```md
Help on built-in function comb in module math:

comb(n, k, /)
    Number of ways to choose k items from n items without repetition and without order.
    
    Evaluates to n! / (k! * (n - k)!) when k <= n and evaluates
    to zero when k > n.
    
    Also called the binomial coefficient because it is equivalent
    to the coefficient of k-th term in polynomial expansion of the
    expression (1 + x)**n.
    
    Raises TypeError if either of the arguments are not integers.
    Raises ValueError if either of the arguments are negative.
```

Per scoprire quali nomi un modulo fornisce, puoi usare la funzione `dir()`. Elenca funzioni, come `math.floor` per arrotondare un numero per difetto, e costanti, come `math.e` (numero di Eulero) e `math.pi`. Elenca anche altri nomi che imparerai più avanti nel curriculum:

```py

print(dir(math))
```
