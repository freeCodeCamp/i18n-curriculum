# --description--

根节点是树的最顶层节点，所有其他节点都可以从它访问到。

现在创建一个名为 `BinarySearchTree` 的类来表现这棵树本身。给它一个只接受 `self` 的 `__init__` 方法。

一棵新树没有任何节点，所以在 `__init__` 方法中将 `root` 属性设置为 `None`。
