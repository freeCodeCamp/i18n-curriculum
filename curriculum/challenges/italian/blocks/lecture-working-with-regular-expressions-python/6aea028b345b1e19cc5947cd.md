# --description--

Un'espressione regolare, o regex, è un pattern usato per trovare una sequenza di caratteri in un testo.

Hai già usato l'operatore `in` per verificare se una stringa contiene una sottostringa esatta. Ma ci sono casi in cui non conosci il testo esatto che stai cercando, solo la sua forma. Per esempio, potresti voler controllare che una stringa inizi con alcune lettere seguite da alcune cifre, o che un nome utente sia composto solo da caratteri consentiti.

Le espressioni regolari ti permettono di descrivere pattern come questi e verificare se una stringa li rispetta. Sono comunemente usate per convalidare input, cercare nel testo ed estrarre informazioni dalle stringhe.

In Python, per usare le espressioni regolari devi importare il modulo `re`, che fa parte della libreria standard:

```python
import re
```

Il pattern regex più semplice è un pattern letterale: una sequenza di caratteri che deve apparire esattamente come scritta. Per esempio, il pattern `'cat'` corrisponde alle lettere `c`, `a` e `t`, una dopo l'altra.

Per cercare un pattern all'interno di una stringa, puoi usare la funzione `search` del modulo `re`. Prende il pattern come primo argomento e la stringa da cercare come secondo argomento:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

Quando `re.search` trova il pattern in qualsiasi punto della stringa, restituisce un oggetto match. L'oggetto match stampato ti dice due cose:

- `match='cat'` è il testo che ha corrisposto al pattern.

- `span=(4, 7)` è la posizione della corrispondenza nella stringa. La corrispondenza inizia all'indice `4` e termina subito prima dell'indice `7`.

Puoi anche ottenere queste informazioni dall'oggetto match con i suoi metodi `group` e `span`:

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

Quando il pattern non viene trovato, `re.search` restituisce `None`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

Per impostazione predefinita, la corrispondenza delle regex è case sensitive. Questo significa che il pattern `'Cat'` non corrisponde al testo `cat`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

Per cambiare come viene effettuata la corrispondenza, puoi passare una flag come terzo argomento a `re.search`. La flag `re.IGNORECASE` rende la ricerca case insensitive, quindi lettere maiuscole e minuscole sono trattate allo stesso modo:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
