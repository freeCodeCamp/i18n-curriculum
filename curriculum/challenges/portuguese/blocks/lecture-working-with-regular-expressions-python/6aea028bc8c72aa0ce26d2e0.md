# --description--

Expressões regulares podem conter sequências especiais feitas de uma barra invertida (`\`) seguida por um caractere. Essas sequências têm um significado especial. Aqui estão algumas das mais comuns:

- `\d` corresponde a qualquer dígito decimal, incluindo `0` a `9`.

- `\w` corresponde a qualquer caractere de palavra: letras, dígitos e o sublinhado (`_`).

- `\s` corresponde a qualquer caractere de espaço em branco, como um espaço, uma tabulação ou uma nova linha.

- `\D`, `\W` e `\S` correspondem ao oposto das suas versões em minúsculas. Por exemplo, `\D` corresponde a qualquer caractere que não seja um dígito.

Mas há um detalhe. Strings em Python também usam barras invertidas para escrever sequências de escape como `\n` (uma nova linha) ou `\t` (uma tabulação):

```python
print('Tab:\tdone') # Tab:    done
```

Isso significa que uma barra invertida em uma string comum do Python pode ser interpretada pelo Python antes mesmo do módulo `re` vê-la. Dependendo do caractere que vem depois, isso pode alterar seu padrão ou fazer o Python exibir um aviso.

Para evitar isso, você pode usar uma raw string. Você cria uma raw string adicionando a letra `r` (ou `R`) antes da aspa de abertura. Raw strings tratam barras invertidas como caracteres literais em vez de sequências de escape:

```python
print(r'Tab:\tdone') # Tab:\tdone
```

Por isso, é uma boa prática sempre escrever padrões regex como raw strings:

```python
import re

room = 'Room 42B'
print(re.search(r'\d', room))
# <re.Match object; span=(5, 6), match='4'>
```

Note que `re.search` retorna a primeira correspondência que encontra. Aqui, `\d` corresponde a um único dígito, então a correspondência é apenas `4`. Para corresponder a mais de um dígito, você pode querer usar um quantificador.

Quantificadores especificam quantas vezes o caractere ou sequência anterior pode ser repetido. O quantificador `+` corresponde ao caractere anterior uma ou mais vezes.

Então, enquanto `\d` corresponde a um único dígito, `\d+` corresponde a um ou mais dígitos seguidos:

```python
import re

room = 'Room 42B'
print(re.search(r'\d+', room))
# <re.Match object; span=(5, 7), match='42'>
```

Aqui estão outros quantificadores comuns:

- `*` corresponde ao caractere anterior zero ou mais vezes.

- `?` corresponde ao caractere anterior zero ou uma vez, tornando-o opcional.

- `{n}` corresponde ao caractere anterior exatamente `n` vezes.

- `{n,m}` corresponde ao caractere anterior de `n` a `m` vezes.

```python
import re

print(re.search(r'go*al', 'What a goooal!'))
# <re.Match object; span=(7, 13), match='goooal'>

print(re.search(r'colou?r', 'My favorite color is blue'))
# <re.Match object; span=(12, 17), match='color'>

print(re.search(r'\d{4}', 'Room 42, built in 1987'))
# <re.Match object; span=(18, 22), match='1987'>
```

Você pode combinar caracteres literais, sequências especiais e quantificadores no mesmo padrão. Por exemplo, o padrão `r'\d+ items'` corresponde a um ou mais dígitos, seguido por um espaço e a palavra `items`. Você também pode combiná-lo com a flag `re.IGNORECASE` para que as letras possam ser minúsculas ou maiúsculas:

```python
import re

cart = 'You have 3 ITEMS in your cart.'
print(re.search(r'\d+ items', cart, re.IGNORECASE))
# <re.Match object; span=(9, 16), match='3 ITEMS'>
```
