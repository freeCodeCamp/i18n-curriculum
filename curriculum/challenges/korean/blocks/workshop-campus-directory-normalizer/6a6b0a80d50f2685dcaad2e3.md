# --description--

이 워크숍에서는 스마트 캠퍼스 디렉터리를 다루고 중첩된 데이터에서 조회 표를 만드실 거예요.
이 조회 표를 사용해 빠르고 효율적인 검색을 수행할 수 있습니다. `rawData`가 제공되어 있습니다.

잠시 시간을 내어 구조를 살펴보세요: 각 키는 학과 이름이고, 그 값은 `Dept_code`와 함께
`programs` 배열을 포함합니다. 각 프로그램은 다시 자체 `instructors` 배열을 가지고 있습니다.

먼저, `rawData`를 콘솔에 출력하여 이 중첩된 구조를 작업 전에 살펴보세요.

globalThis.spy = __helpers.spyOn(console, "log");

```js
globalThis.spy.restore();
delete globalThis.spy;
```
