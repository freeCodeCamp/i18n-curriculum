# --description--

在本实验中，你将为链表数据结构实现额外的操作，基于你在上一个工作坊中创建的 `LinkedList` 类。

**目标：**实现以下用户需求并通过所有测试以完成实验。

**用户故事：**

1. 你的 `LinkedList` 类应有一个 `contains` 方法，接受一个元素作为参数。如果该元素存在于链表中，应返回 `True`，否则返回 `False`。
1. 你的 `LinkedList` 类应有一个 `get_at` 方法，接受一个索引作为参数。它应返回链表中该索引位置的元素。如果索引超出边界，应返回 `None`。
1. 你的 `LinkedList` 类应有一个 `insert_at` 方法，接受一个索引和一个元素作为参数。它应在链表的指定位置插入该元素，并更新 `length` 属性。索引等于列表长度是有效的，应将元素添加到末尾。如果索引超出边界，不应修改列表。
1. 你的 `LinkedList` 类应有一个 `remove_at` 方法，接受一个索引作为参数。它应移除链表中该索引位置的节点，并更新 `length` 属性。如果索引超出边界，不应修改列表。
1. 你的 `LinkedList` 类应有一个 `clear` 方法，移除链表中的所有元素，将其重置为空状态，`head` 设为 `None`，`length` 设为 `0`。

**注意：** 后续的一些测试依赖于之前的方法。例如，如果 `get_at` 没有正确实现，像 `insert_at` 和 `remove_at` 这样的方法的测试即使接近正确也可能失败。

class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
