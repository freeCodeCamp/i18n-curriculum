# --description--

Bubble Sort funktioniert, indem er wiederholt eine Liste durchläuft, benachbarte Elemente vergleicht und sie vertauscht, wenn sie in der falschen Reihenfolge sind. Nach jedem Durchgang "steigt" der größte unsortierte Wert bis ans Ende der Liste. Der Algorithmus stoppt, wenn ein kompletter Durchgang ohne Vertauschungen abgeschlossen wird.

Bubble Sort hat im Durchschnitt und im schlimmsten Fall eine quadratische Zeitkomplexität, weshalb er in der Praxis selten verwendet wird.

**Ziel:** Erfüllen Sie die untenstehenden User Stories und bestehen Sie alle Tests, um das Labor abzuschließen.

**User Stories:**

1. Sie sollten eine Funktion namens `bubble_sort` definieren, die einen Parameter hat, der die Liste der Elemente darstellt.
1. Ihre `bubble_sort`-Funktion sollte die Liste an Ort und Stelle von klein nach groß sortieren und zurückgeben.
1. Ihre `bubble_sort`-Funktion sollte dem Bubble-Sort-Algorithmus folgen, benachbarte Elemente vergleichen und sie nur vertauschen, wenn das linke Element größer als das rechte ist.
1. Ihre `bubble_sort`-Funktion sollte stoppen, sobald ein Durchgang durch die Liste ohne Vertauschungen abgeschlossen ist.
1. Ihre `bubble_sort`-Funktion sollte weder die eingebaute `sort()`-Methode noch die `sorted()`-Funktion verwenden.

**Hinweis:** Sie sollten in Ihrem Code keine Module importieren.

Ihre `bubble_sort`-Funktion sollte dem Bubble-Sort-Algorithmus folgen und benachbarte Elemente nur vertauschen, wenn das linke Element größer als das rechte ist.

```js
({
  test: () =>
    runPython(`
from collections import UserList

class CustomList(UserList):
    def __init__(self, *args, **kwargs):
        self._record = []
        super().__init__(*args, **kwargs)

    def __setitem__(self, key, value):
        self._record.append((key, value))
        super().__setitem__(key, value)

def expected_swaps(items):
    items = list(items)
    swaps = []
    swapped = True
    while swapped:
        swapped = False
        for j in range(len(items) - 1):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swaps.append({(j, items[j]), (j + 1, items[j + 1])})
                swapped = True
    return swaps

for values in ([33, 1, 89, 2, 67, 245], [4, 4, 2, 2, 1, 4, 3]):
    list_to_sort = CustomList(values)
    bubble_sort(list_to_sort)
    record = list_to_sort._record
    expected = expected_swaps(values)
    assert len(record) == 2 * len(expected)
    actual = [set(record[i:i + 2]) for i in range(0, len(record), 2)]
    assert actual == expected
    `)
});
```

```py
def bubble_sort(items):
    n = len(items)
    for i in range(n):
        swapped = False
        for j in range(n - 1 - i):
            if items[j] > items[j + 1]:
                items[j], items[j + 1] = items[j + 1], items[j]
                swapped = True
        if not swapped:
            break
    return items
```
