## Makosa ya kawaida katika Python

- **`SyntaxError`**: Hitilafu ambayo Python hutupa wakati msimbo wako haufuati sheria zake za sintaksia. Kwa mfano, msimbo `print("Hello there"` utasababisha kosa la sintaksia lenye ujumbe, `SyntaxError: '(' was never closed`, kwa sababu msimbo unakosa mabano ya kufunga.
- **`NameError`**: Python hutupa `NameError` unapojaribu kupata upatikanaji wa kigezo au kitendakazi ambacho hujafafanua. Kwa mfano, ikiwa una mstari `print(username)` katika msimbo wako bila kuwa na kigezo `username` kilichofafanuliwa awali, utapata kosa la jina lenye ujumbe `NameError: name 'username' is not defined`.
- **`TypeError`**: Hii ni hitilafu ambayo Python hutupa wakati operesheni au kitendakazi kinatumika kwa kitu cha aina isiyofaa. Kwa mfano, ukijaribu kuongeza mfuatano wa herufi kwenye nambari, utapata kosa `TypeError: can only concatenate str (not "int") to str`.
- **`IndexError`**: Utapata `IndexError` ikiwa utapata kielezo ambacho hakipo katika orodha au mfululizo mwingine kama tuple na mfuatano wa herufi. Kwa mfano, katika mfuatano wa herufi `Hello world`, kielezo cha herufi ya mwisho ni `10`. Ikiwa utaendelea na kupata herufi kwa njia hii, `greet = "hello world"; print(greet[11])`, utapata kosa lenye ujumbe `IndexError: string index out of range`.
- **`AttributeError`**: Python hutupa hitilafu hii unapojaribu kutumia njia au sifa ambayo haipo katika kitu cha aina hiyo. Kwa mfano, kuitisha `.append()` kwenye mfuatano wa herufi kama `"hello".append("!")` kutaongoza kwa kosa lenye ujumbe `AttributeError: 'str' object has no attribute 'append'`.

## Mbinu nzuri za kurekebisha makosa katika Python

- **Kutumia kitendakazi cha `print`**: Kuingiza taarifa za `print()` sehemu mbalimbali za msimbo wako wakati wa kurekebisha makosa husaidia kuona thamani za vigezo na jinsi msimbo unavyotiririka.
- **Kutumia Kirekebishaji cha Makosa kilichojengwa ndani cha Python (`pdb`)**: Python hutoa moduli ya `pdb` kwa ajili ya kurekebisha makosa kama sehemu ya maktaba yake ya kawaida. Kuitisha `pdb.set_trace()` kunasimamisha utekelezaji na kufungua kiolesura cha maingiliano. Unaweza kuingiza `help` kuorodhesha amri, `whatis` kuchunguza aina ya usemi wa kihesabu, na `continue` (au majina yake mbadala `cont` na `c`) kuendelea na utekelezaji wa programu.
- **Kujitahidi kutumia zana za kurekebisha makosa za IDE**: Mazingira ya ukuzaji yaliyojumuishwa (IDEs) na wahariri wa msimbo kama PyCharm na VS Code hutoa zana za kuona kurekebisha makosa. Kwa mfano, VS Code hutoa yafuatayo:
  - **Mabreakpoint**: Bofya katika nafasi kati ya safu ya mhariri kuweka breakpoint (inayowakilishwa na doa jekundu) ambapo utekelezaji unapaswa kusimama.
  - **Ukaguzi wa vigezo na konsoli ya kurekebisha makosa**: Elea juu ya vigezo au angalia paneli ya Vigezo kuona thamani za sasa, na tumia Konsoli ya Kurekebisha Makosa kutathmini usemi wa kihesabu kwa maingiliano.
  - **Udhibiti wa hatua**:
    - **Endelea (<kbd>F5</kbd>)**: Huuza utekelezaji hadi breakpoint inayofuata.
    - **Ruka hatua (<kbd>F10</kbd>)**: Hutekeleza mstari wa sasa na kuhamia mstari unaofuata bila kuingia ndani ya wito wa kitendakazi.
    - **Ingiza hatua (<kbd>F11</kbd>)**: Inaingia ndani ya kitendakazi kilichoitwa ili kupita kupitia mistari yake.
    - **Toka hatua (<kbd>Shift</kbd> + <kbd>F11</kbd>)**: Inamaliza kitendakazi cha sasa na kurudi kwa mtumaji.

## Kushughulikia makosa

- **`try...except`**: Hii hutumika kutekeleza kifungu cha msimbo ambacho kinaweza kusababisha hitilafu. Kifungu cha `try` ndicho unachotarajia hitilafu itatokea, wakati kifungu cha `except` kinachukua hitilafu maalum na kinatekelezwa ikiwa hitilafu hiyo itatokea. Hapa kuna mfano:

  ```py
  try:
    print(22 / 0)
  except ZeroDivisionError:
    print('You can\'t divide by zero!')
    # You can't divide by zero!
  ```

  Unaweza pia kuunganisha vifungu vingi vya `except` ili kushughulikia aina zaidi za makosa:

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

  Unaweza pia kushika aina nyingi za hitilafu katika kifungu kimoja cha `except` kwa kuzichanganya katika tuple:

  ```py
  try:
    number = int(input('Enter a number: '))
    result = 10 / number
  except (ValueError, ZeroDivisionError) as e:
    print(f'Error occurred: {e}')
  ```

- **`else` na `finally`**: Vifungu hivi vinaongeza `try...except`. Ikiwa hakuna hitilafu itatokea, kifungu cha `else` hutekelezwa. Kifungu cha `finally` hutekelezwa kila wakati bila kujali kama hitilafu ilitokea au la.

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **Kipengele cha hitilafu**: Hiki kinakuruhusu kupata hitilafu yenyewe kwa ajili ya kurekebisha makosa bora na kuchapisha ujumbe wa kosa moja kwa moja. Ili kupata kipengele cha hitilafu, unahitaji kutumia neno kuu `as`. Hapa kuna mfano:

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **Kauli ya `raise`**: Hii inakuwezesha kutupa hitilafu kwa hiari. Unaweza kuitumia kutupa hitilafu wakati hali fulani inatimizwa:

  ```py
  def divide(a, b):
      if b == 0:
          raise ZeroDivisionError('You cannot divide by zero')
      return a / b
  ```

  Kutumia `raise` bila hoja ndani ya kifungu cha `except` hutupa tena hitilafu inayoshughulikiwa kwa sasa. Hii inakuwezesha kurekodi hitilafu au kufanya usafi huku hitilafu ikienea juu katika mfululizo wa wito:

  ```py
  def process_data(data):
      try:
          result = int(data)
          return result * 2
      except ValueError:
          print('Logging: Invalid data received')
          raise
  ```

- **Kauli ya `assert`**: Kauli ya `assert` huangalia dhana wakati wa kurekebisha makosa na huibua `AssertionError` wakati hali si kweli. Kwa sababu Python huondoa uthibitisho wakati inapoendesha katika hali ya uboreshaji (`-O`), uthibitisho haupaswi kutumika kwa uthibitisho muhimu wa ingizo ambao lazima uendelee kila wakati. Badala yake tumia hali wazi na `raise` kwa ukaguzi unaohitajika.

## Kuashiria hitilafu

- **Hitilafu Maalum**: Kauli ya `raise` pia ni muhimu unapounda hitilafu zako maalum kwa kurithi `Exception`. Hii inakuwezesha kutupa makosa yenye mantiki na ujumbe maalum wa eneo fulani:

  ```py
  class InvalidCredentialsError(Exception):
      def __init__(self, message="Invalid username or password"):
          self.message = message
          super().__init__(self.message)

  def login(username, password):
      stored_username = "admin"
      stored_password = "password123"
      
      if username != stored_username or password != stored_password:
          raise InvalidCredentialsError()
      
      return f"Welcome, {username}!"
  ```

  Hapa ni jinsi unavyoweza kutumia kitendakazi cha `login` na hitilafu ya `InvalidCredentialsError`:

  ```py
  # failed login attempt
  try:
      message = login("user", "wrongpassword")
  except InvalidCredentialsError as e:
      print(f"Login failed: {e}")
  else:
      print(message)

  # successful login attempt
  try:
      message = login("admin", "password123")
  except InvalidCredentialsError as e:
      # This block is not executed because the login was successful
      print(f"Login failed: {e}")
  else:
      # The else block runs if the 'try' block completes without an exception
      print(message)
  ```

- **Uunganishaji wa Hitilafu**: Kauli ya `raise` inaweza kutumika pamoja na neno `from` kuunganisha hitilafu. Kutumia `from None` huficha muktadha wa hitilafu ya awali kutoka kwenye taarifa ya makosa, wakati `from e` huandika wazi hitilafu ya awali kama sababu:

  ```py
  def parse_config(filename):
      try:
          with open(filename, 'r') as file:
              data = file.read()
              return int(data)
      except FileNotFoundError:
          raise ValueError('Configuration file is missing') from None
      except ValueError as e:
          raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```
