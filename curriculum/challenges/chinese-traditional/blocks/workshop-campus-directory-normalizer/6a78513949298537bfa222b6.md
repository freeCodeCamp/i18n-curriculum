# --description--

在這個步驟中，你將把每個 `instructor` 存入 `instructorsById`，並以它自己的 id 作為鍵。
就像你對 `programs` 所做的那樣，將一個物件指定給 `instructorsById[instructor.id]`，
該物件展開 `instructor` 並新增 `programId`（設為 `program.id`）和 `departmentId`。

在指定物件之前，刪除前一步驟中的 `console.log(instructor)`。

將 `instructorsById[instructor.id]` 記錄到主控台，以檢查儲存的物件。
