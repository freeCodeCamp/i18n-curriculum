# --description--

각 프로그램을 자신의 id를 키로 하여 `programsById`에 저장하세요.

저장된 프로그램은 원래 속성에 더해 해당 부서와 연결하는 새로운 `departmentId` 속성을 가져야 합니다. 객체 전개 구문(`...`)은 객체의 고유 열거 가능한 속성을 새 객체로 복사하며, 여기서 추가 속성을 더할 수 있습니다.

먼저 코드에서 `console.log(program)` 줄을 삭제하세요.

그다음 `programsById[program.id]`에 `program`을 전개하고 `departmentId`를 추가한 객체를 할당하세요.

마지막으로 저장된 객체를 확인하기 위해 `programsById[program.id]`를 콘솔에 출력하세요.
