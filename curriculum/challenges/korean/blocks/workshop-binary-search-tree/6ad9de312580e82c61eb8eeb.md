# --description--

값을 삽입하려면 루트에서 시작해 값이 노드의 값보다 작으면 왼쪽으로, 크면 오른쪽으로 이동해 빈 자리를 찾으세요. 각 부분 트리도 이진 탐색 트리이므로 재귀로 이 작업을 할 수 있습니다.

`BinarySearchTree` 클래스 안에 `_insert`라는 이름의 메서드를 만들고 세 개의 매개변수 `self`, `node`, `key`를 받게 하세요. 앞에 붙은 밑줄은 내부용 헬퍼임을 표시합니다.

그 안에 `key`가 `node.key`보다 작은지 확인하는 `if` 문을 추가하세요. `if` 문 안에서 `self._insert`를 `node.left`와 `key`를 인자로 호출하고, 그 결과를 `node.left`에 할당하세요. 이렇게 하면 값을 왼쪽 부분 트리에 삽입하고, 업데이트된 부분 트리를 현재 노드에 연결 상태로 유지합니다.
