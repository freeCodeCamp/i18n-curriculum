# --description--

Функція може викликати іншу функцію та використовувати її повернене значення. Наприклад:

```py
def calculate_sum(a, b):
    return a + b

def show_total(a, b):
    total = calculate_sum(a, b)
    print(total)

show_total(3, 4) # 7
```

Тут `show_total` виконує виклик `calculate_sum`, призначає її повернене значення локальній змінній `total` і виводить його.

Далі ви створите функцію, яка перевіряє, чи є яйце в наявності, і викликає `use_eggs`, щоб його використати. Під інструкцією `print(available_eggs)` визначте порожню функцію з назвою `make_fried_egg`, яка приймає `available_eggs` як єдиний параметр.

Поки що використайте ключове слово `pass` всередині тіла функції.

def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        print('The kitchen does not have enough eggs.')
        return available_eggs

    print(f'{eggs_to_use} egg(s) used out of {available_eggs} available.')
    return available_eggs - eggs_to_use
