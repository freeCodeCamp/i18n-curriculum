# --description--

在过去的几节课中，你已经开始熟悉像这样的循环操作：

```py
even_numbers = []

for num in range(21):
    if num % 2 == 0:
        even_numbers.append(num)

print(even_numbers)
```

这个示例创建了一个名为 `even_numbers` 的新空列表，并循环遍历 `0` 到 `20` 之间的数字序列。在循环内部，有一个条件查看当前数字除以 `2` 后的余数是否为 `0`。这用于判断数字是否为偶数。如果条件为 `True`，则将当前的 `num` 追加到 `even_numbers` 列表的末尾。最后，我们将 `even_numbers` 列表打印到控制台。

## 什么是列表推导式？

虽然这段代码可以运行，但有一种更简洁的写法是使用列表推导式。列表推导式允许你通过在方括弧内直接写循环，在一行内创建一个新列表。这使代码更短且通常更易读。

列表推导式的基本语法如下所示：

```py
[expression for item in iterable]
```

对于可迭代对象中的每一项，`for` 前的表达式会被计算，结果被添加到新列表中。下面是一个示例，创建一个列表，其中包含从 `0` 到 `4` 的每个数字乘以 `2` 的结果：

```py
doubled = [num * 2 for num in range(5)]
print(doubled) # [0, 2, 4, 6, 8]
```

## 使用尾随的 `if` 进行过滤

你可以选择在列表推导式的末尾添加一个 `if` 条件。只有满足条件为真值的项会被添加到新列表中，其他项会被跳过。

下面是之前的偶数示例，使用列表推导式重构后的代码：

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

在这个重构的示例中，`even_numbers` 列表是使用一行代码创建的。列表推导式循环遍历从 `0` 到 `20` 的数字，并且只包含能被 `2` 整除的数字。这种方法更简洁，且无需单独的循环和条件块。

## 创建独立的内层列表

之前你学过 `[[]] * 3` 会重复引用同一个内层列表。列表推导式可以在每次迭代时创建独立的内层列表：

```py
rows = [[] for _ in range(3)]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

表达式 `[]` 在每次迭代时都会被计算，因此每个位置引用的是不同的列表。循环变量未被用于表达式中；范围仅控制创建多少个列表。

当循环变量不需要时，Python 开发者通常将其命名为 `_`，以表示该值被有意忽略。`_` 仍然是一个普通的变量名。

## 在列表推导式中使用条件式表达式

到目前为止，你已经使用过 `if` 和 `else` 来编写条件语句。Python 还有一种条件表达式，它写在一行内并产生一个值。其语法如下：

```py
value_if_true if condition else value_if_false
```

如果条件为真值，整个表达式的值为 `if` 前的值。否则，表达式的值为 `else` 后的值。下面是一个示例：

```py
num = 7
label = 'Even' if num % 2 == 0 else 'Odd'
print(label) # Odd
```

由于 `7` 不能被 `2` 整除，条件为 `False`，因此 `'Odd'` 被赋值给 `label`。

你可以在列表推导式中将条件表达式用作 `for` 前的表达式。在这种情况下，它会为可迭代对象中的每一项选择一个值，因此新列表的项数与原列表相同。这与尾随的 `if` 不同，后者可以排除某些项不加入新列表。

让我们来看一个例子：

```py
numbers = [1, 2, 3, 4, 5]
result = [(num, 'Even') if num % 2 == 0 else (num, 'Odd') for num in numbers]
print(result)
```

在这个例子中，我们有一个数字列表，想要创建一个新的元组列表，表示哪些数字是偶数或奇数。在列表推导式的第一部分，我们使用 `if`/`else` 条件式来检查数字是否能被 `2` 整除。如果是，那么结果是一个元组，包含该数字和单词 `Even`。否则，结果是一个元组，包含该数字和单词 `Odd`。

以下是在控制台中打印的结果示例：

```py
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

## 使用 `filter()` 过滤列表

另一种从现有可迭代对象创建列表的方法是使用 `filter()` 函数。下面是一个只创建长度超过四个字符单词的新列表的示例：

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

`filter()` 函数用于从可迭代对象中选择满足特定条件的元素。`filter()` 函数接受一个函数和一个可迭代对象作为参数。在这个示例中，我们将 `is_long_word` 函数传入 `filter()`，用来检查当前单词的字符数是否大于 `4`。`is_long_word` 没有加括号，因为你传递的是函数本身，而不是调用它。`filter()` 会对每个单词调用 `is_long_word`。和 `zip()` 类似，`filter()` 返回一个迭代器，只包含满足条件的单词。`list()` 函数将这些单词收集到一个新列表中，并赋值给变量 `long_words`。

## 使用 `map()` 转换列表

除了 `filter()` 函数外，还有一些在处理列表时非常有用的函数。另一个需要注意的函数是 `map()` 函数，它接受一个可迭代对象并对其每个元素应用一个函数。下面是使用 `map()` 函数将摄氏温度列表转换为华氏温度的示例：

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

和 `filter()` 函数一样，`map()` 接受一个函数和一个可迭代对象作为参数。`to_fahrenheit` 函数接受一个温度值，将其从摄氏度转换为华氏度。同样，`to_fahrenheit` 传入时不带括号，`map()` 会对 `celsius` 列表中的每个温度调用它。`map()` 也返回一个迭代器，这次是转换后的值，因此再次使用 `list()` 将它们收集成列表。

## 使用 `sum()` 计算总和

我们将要看的最后一个函数是 `sum()` 函数。这个函数用于从可迭代对象（如列表或元组）中获取总和。以下是使用 `sum()` 函数的示例：

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

你也可以传入一个可选的 `start` 参数，用于设置求和的初始值。下面是一个使用 `start` 参数作为位置参数的更新示例：

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

你也可以选择将 `start` 参数作为关键字参数这样使用：

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

两个版本都会产生相同的结果，但关键字参数更为显式。

列表推导式以及其他函数如 `map()`、`filter()` 和 `sum()` 起初可能会让人感到有些困惑。但经过足够的练习和时间，你会开始在你的 Python 程序中更自如地使用它们。
