# --description--

El término `automate` significa hacer que un proceso funcione por sí solo sin necesidad de que una persona lo ayude. En programación, puede implicar usar software para escribir código, probar aplicaciones o encontrar y corregir errores. Por ejemplo, una cafetera que se enciende sola por la mañana para preparar café está `automated`.

La palabra `certain` se usa para hablar de cosas o personas específicas, pero no de todas. Por ejemplo, si dices que `certain books are on sale`, significa que solo algunos libros están en oferta, no todos.
