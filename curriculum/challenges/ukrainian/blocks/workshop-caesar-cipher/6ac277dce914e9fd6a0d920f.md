# --description--

У Python `bool` є підкласом `int`, де `True` поводиться як `1`, а `False` — як `0`. Це означає, що `isinstance()` розглядає булеві значення як цілі числа:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True
```

Через це ваша функція наразі приймає `True` і `False` як значення зсуву.

Використайте оператор `or`, щоб додати другу умову до вашої інструкції `if`, яка перевіряє, чи є `shift` булевим за допомогою `isinstance(shift, bool)`. Таким чином ваша функція також повертатиме `Shift must be an integer value.`, коли `shift` дорівнює `True` або `False`.
