## Що таке функції?

Функції — це багаторазові частини коду, які запускаються, коли ви їх викликаєте. Python надає вбудовані функції, зокрема `print()`, яку ви використовували в попередніх уроках.

Ще одна корисна вбудована функція — `input()`, яка дозволяє запитати користувача про вхідні дані:

```python
name = input('What is your name?') # User types "Kolade" and presses Enter  
print('Hello', name) # Output: Hello Kolade
```

З іншого боку, `int()` перетворює число, булевий тип або рядок, що представляє ціле число, у ціле число:

```python
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0 
```

## Визначення та виклик функцій

Ви також можете написати власні кастомні функції. Для цього використовуйте ключове слово `def`, за яким іде ім’я функції, пара круглих дужок і двокрапка. Потім на новому рядку напишіть код, який має виконувати функція. Код, що виконує функція, також називають тілом функції.

Ось приклад кастомної функції з ім’ям `hello`, яка виводить рядок `Hello World` у термінал:

```python
def hello():
    print('Hello World')
```

Щоб запустити функцію, потрібно викликати її за ім’ям із парою круглих дужок:

```python
hello() # Hello World
```

Зверніть увагу на відступ перед `print('Hello World')`. Як ви пам’ятаєте з попередніх уроків, Python покладається на відступи, щоб визначити, які групи інструкцій належать разом. Ці групи інструкцій називають блоками коду.

## Використання параметрів і аргументів

Ось ще одна проста функція, яка виводить суму двох чисел у термінал:

```python
def calculate_sum(a, b):
    print(a + b)
```

Ви бачите, що наша функція `calculate_sum` має `a` і `b` у круглих дужках, розділені комою. Це називаються параметрами. Уявіть параметри як змінні-заповнювачі, які виступають «слотами» для значень, які ви передаєте у функцію під час виклику.

Щоб використати параметри, потрібно передати «аргументи». Аргументи — це значення, які ви передаєте функції під час її виклику.

Ось як викликати функцію `calculate_sum`, щоб підсумувати числа `3` і `1`:

```python
calculate_sum(3, 1) # 4
```

Якщо викликати функцію без правильної кількості аргументів, ви отримаєте `TypeError`:

```python
calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

## Позиційні та ключові аргументи

Аргументи в `calculate_sum(3, 1)` — це позиційні аргументи. Python зіставляє їх із параметрами за позицією: `3` призначається `a`, а `1` — `b`.

Ось функція, де порядок аргументів має значення:

```python
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

Якщо поміняти позиційні аргументи місцями, `name` отримає `25`, а `age` — `'Alice'`:

```python
introduce(25, 'Alice')
# My name is 25 and I am Alice years old.
```

Ви також можете передавати ключові аргументи, написавши ім’я параметра, за яким слідує `=` і значення. Python зіставляє ці аргументи за іменем, тому ви можете писати їх у будь-якому порядку:

```python
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

Тут `name='Alice'` передає `'Alice'` параметру `name`. Це не призначає змінну з ім’ям `name` поза межами функції.

Ви можете комбінувати позиційні та ключові аргументи, але позиційні аргументи мають іти першими:

```python
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

Розміщення позиційного аргумента після ключового викликає `SyntaxError`:

```python
introduce(name='Alice', 25)
# SyntaxError: positional argument follows keyword argument
```

Ви також не можете надати значення для одного й того самого параметра більше одного разу:

```python
introduce('Alice', name='Bob', age=25)
# TypeError: introduce() got multiple values for argument 'name'
```

У цьому виклику позиційний аргумент `'Alice'` уже задає значення для `name`. Передача `name='Bob'` задає друге значення для того самого параметра.

## Повернення значень із функцій

Функції також використовують спеціальне ключове слово `return`, щоб вийти з функції і повернути значення. Якщо ви явно не використовуєте `return`, Python за замовчуванням поверне `None`.

Як ви дізналися в уроці про оператори ідентичності, `None` означає відсутність значення. Тут це вказує на те, що функція не повернула явного результату.

Ось приклад:

```python
def calculate_sum(a, b):
    print(a + b)

my_sum = calculate_sum(3, 1) # 4
print(my_sum) # None
```

Ви бачите, що функція `calculate_sum` виводить суму `a` і `b`, але нічого явно не повертає. Тож коли ми присвоюємо її результат `my_sum`, значення фактично є `None`. Щоб це виправити, можна використати ключове слово `return`, щоб повернути результат:

```python
def calculate_sum(a, b):
    return a + b

my_sum = calculate_sum(3, 1)
print(my_sum) # 4
```

Тепер `calculate_sum` повертає суму `a` і `b`, яка зберігається в `my_sum`.
