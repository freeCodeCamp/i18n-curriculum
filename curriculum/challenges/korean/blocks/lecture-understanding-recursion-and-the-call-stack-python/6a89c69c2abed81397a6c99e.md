# --description--

재귀는 함수가 자기 자신을 호출하는 기법입니다. 각 호출은 원래 문제의 더 작은 버전에서 작동하며, 재귀를 멈추는 조건에 도달할 때까지 계속됩니다. 그 멈추는 조건을 기본 사례라고 합니다.

재귀 함수는 파일 트리 탐색과 같이 깊이를 알 수 없는 문제를 해결할 수 있습니다. 또한 주어진 숫자에서 카운트다운하는 것과 같은 더 간단한 작업도 수행할 수 있습니다.

숫자를 받아 출력하는 `recursive_countdown`이라는 함수가 있습니다:

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

함수를 호출하면 `5`가 출력되지만 아직 카운트다운하지는 않습니다. 함수가 자기 자신을 호출하기 전에 기본 사례를 정의해야 합니다. 도달할 수 있는 기본 사례가 없으면 함수는 계속 자기 자신을 호출합니다. Python은 결국 호출을 멈추고 `RecursionError`를 발생시킵니다.

이 카운트다운에서는 `number`가 `1`보다 작을 때 함수가 멈춰야 합니다:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

`if` 문이 기본 사례입니다. `number`가 `1`보다 작으면 `return`이 해당 함수 호출을 종료합니다.

함수에는 여전히 재귀 사례가 필요합니다. 재귀 사례는 기본 사례로 나아가도록 인수를 바꿔 함수 자신을 다시 호출합니다. 카운트다운하려면 `number - 1`을 인수로 하여 `recursive_countdown`을 호출하세요:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

이것은 숫자 `5`, `4`, `3`, `2`, `1`을 출력합니다.

숫자가 출력되는 위치에 따라 재귀 호출 위치가 달라집니다. `print()` 호출이 재귀 호출 뒤에 오면 함수는 숫자를 오름차순으로 출력합니다:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

이것은 숫자 `1`, `2`, `3`, `4`, `5`를 출력합니다. 이유를 이해하려면 호출 스택을 이해해야 합니다.

호출 스택은 Python이 활성 함수 호출을 추적하는 데 사용하는 후입선출 자료 구조입니다. 함수가 호출되면 Python은 해당 호출에 대한 프레임을 스택 맨 위에 추가합니다. 프레임에는 함수의 인수와 지역 변수가 포함됩니다.

이 카운트다운 버전을 살펴보세요:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

출력은 다음과 같습니다:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

`recursive_countdown(3)` 호출은 `recursive_countdown(2)`를 호출할 때 일시 중지됩니다. `2` 호출은 `1` 함수를 호출할 때 일시 중지되고, `1` 호출은 `0` 함수를 호출할 때 일시 중지됩니다.

`0` 호출이 기본 사례에 도달하여 반환합니다. Python은 스택 맨 위에서 해당 호출을 제거하므로 `1` 호출이 재귀 호출 후에 다시 시작됩니다. 나머지 호출도 역순으로 다시 시작되고 반환됩니다: `1`, `2`, `3`.

모든 재귀 함수는 기본 사례와 그쪽으로 나아가는 재귀 사례가 필요합니다. 기본 사례가 반환되면 이전 호출들이 후입선출 순서로 다시 시작됩니다.
