# --description--

讓我們來了解你可以使用的命令列捷徑，以加快生產力。

終端機和命令列捷徑可以幫助你簡化工作流程並最大化你的生產力。對於 Linux 和 macOS，兩者皆可追溯至 Unix，許多這些捷徑將會相同。但對於 Windows，則會有一些差異。

## <kbd>上方向鍵</kbd> 和 <kbd>下方向鍵</kbd> 快捷鍵

第一個捷徑是 <kbd>上箭頭</kbd> 鍵。按下這個鍵可以讓你逐一往後瀏覽你的指令歷史。接著，<kbd>下箭頭</kbd> 鍵則可以用來往前瀏覽指令歷史。這兩個鍵讓你能快速瀏覽之前執行過的指令，找到你需要再次執行的指令。

## 使用 <kbd>Tab</kbd> 鍵自動完成

許多 shell 也會提供自動完成的功能，根據你開始輸入的內容建議命令。你可以使用 <kbd>Tab</kbd> 鍵來填入建議的剩餘部分，快速將完整語法填入命令列。建議內容取決於 shell、你正在輸入的命令，以及你的 shell 組態。舉例來說，當你輸入命令名稱時，Bash 和 zsh 會建議符合的命令；當你輸入引數時，它們通常會建議符合的檔案和目錄名稱。PowerShell 則可以完成命令、參數名稱、變數和檔案路徑。

## <kbd>Control</kbd> + <kbd>L</kbd> 快捷鍵

有時候指令會在終端機上產生大量輸出。這些額外的資訊可能會干擾或破壞你的工作流程。在 Linux 和 macOS 裝置上的 *nix 終端機中，你可以按 <kbd>Control</kbd> + <kbd>L</kbd> 來清除整個螢幕，並開始一個全新的乾淨提示字元。在 PowerShell 中，<kbd>Control</kbd> + <kbd>L</kbd> 也會預設清除螢幕，你也可以執行 `cls` 指令達到相同效果。

## <kbd>Control</kbd> + <kbd>C</kbd> 快捷鍵

如果你需要中斷命令以停止其執行，可以按 <kbd>Control</kbd> + <kbd>C</kbd>。這會向前景中正在執行的命令發送中斷請求，通常會停止該命令並返回新的提示符，讓你繼續處理其他工作。有些程式會自行處理此請求，因此可能會要求你確認或繼續執行。對 PowerShell 使用者來說，<kbd>Control</kbd> + <kbd>C</kbd> 也用於複製文字，且只有在沒有選取文字可複製時才會中斷命令。

## *nix 系統終端機快捷鍵

接下來的幾個快速鍵僅在 *nix 基於終端機中可用，且沒有 PowerShell 替代方案。

有時你可能需要多工處理，暫停一個命令以執行另一個。按下 <kbd>Control</kbd> + <kbd>Z</kbd> 會暫停前景中正在執行的命令，並返回命令列，讓你繼續工作。被暫停的命令是暫停狀態，並未執行。如果你想讓它繼續在背景執行，請使用 `bg` 命令；當你需要將它帶回前景時，使用 `fg` 命令。

最後，有些指令你可能需要連續執行兩次。你可以按 <kbd>上箭頭</kbd> 鍵往回瀏覽到先前執行的指令，也可以在命令列輸入兩個驚嘆號（`!!`）並按 <kbd>Enter</kbd> — 這會自動執行最後一次執行的指令。
