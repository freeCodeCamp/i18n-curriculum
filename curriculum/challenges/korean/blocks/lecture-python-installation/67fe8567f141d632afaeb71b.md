# --description--

## 왜 로컬에 Python을 설치해야 할까요?

모든 워크숍과 실습에서 freeCodeCamp의 Python 편집기를 사용하게 됩니다. 하지만 로컬 컴퓨터에 Python을 설정하는 방법을 배우는 것이 중요합니다.

## Python 다운로드하기

Windows와 Mac에서 Python을 설치하는 가장 쉬운 방법은 공식 Python 웹사이트에서 설치 프로그램을 다운로드하는 것입니다. 이 수업 후반부에서는 Linux에서 Python을 실행하는 방법도 다룹니다.

`https://www.python.org/`에 접속해 "Downloads" 위에 마우스를 올려보세요. 운영 체제(OS)에 맞는 현재 Python 버전을 보여주는 모달이 나타납니다.

## macOS에 Python 설치하기

먼저 macOS에서 Python을 설치하는 방법을 살펴보겠습니다:

- 이전 모달에서 보여준 현재 Python 버전 버튼을 클릭하면 `.pkg` 설치 파일이 자동으로 다운로드됩니다.
- `.pkg` 설치 파일 다운로드가 완료되면 열고, 열리는 창에서 "계속"을 클릭하세요.
- "설치 유형" 섹션에 도달할 때까지 "계속" 버튼을 계속 클릭하세요. 그곳에서 "설치" 버튼을 클릭하세요.
- 필요하면 비밀번호를 입력한 후 설치를 시작하세요.
- 패키지 설치가 완료되면 Python이 성공적으로 설치되었다는 메시지가 표시됩니다.
- 애플리케이션 디렉터리에서 새로 생성된 Python 폴더를 여세요.
- `Install Certificates.command` 파일을 더블클릭하고 터미널 프로세스가 완료될 때까지 기다리세요.
- 터미널 창에 `Successfully installed certifi`와 `update complete`가 나타나는지 확인하세요.
- 터미널 창을 닫고 설치 프로그램 창에서 "닫기"를 클릭하세요. 이제 설정이 완료되었습니다!

## 설치 확인하기

터미널을 열고 `python --version` 또는 `python3 --version`를 실행해 설치를 확인할 수 있습니다.

터미널에서 `python` 또는 `python3`을 실행해 Python 인터프리터를 열 수도 있습니다. Python 인터프리터는 Python 코드를 읽고, 컴퓨터가 이해하는 명령어로 번역한 뒤 그 명령어를 실행하는 프로그램입니다.

## 터미널이란 무엇인가요?

<dfn>터미널</dfn>은 명령어를 입력해 컴퓨터와 상호작용할 수 있는 텍스트 기반 인터페이스입니다. 각 운영 체제는 기본 터미널 앱을 제공합니다. macOS에서는 Terminal 앱을, Windows에서는 Command Prompt나 PowerShell을, Linux에서는 GNOME Terminal이나 Konsole 같은 데스크톱 환경별 기본 터미널 앱을 사용할 수 있습니다.

## `python`과 `python3` 사용하기

일부 구형 macOS와 Linux 시스템에서는 `python`가 Python 2용으로 예약되어 있고 `python3`가 Python 3용입니다. `python --version`를 실행했을 때 `Python 2.7.18` 같은 Python 2 버전이 나타난다면, 운영 체제가 구버전 Python으로 작성된 소프트웨어에 의존할 수 있습니다. 이 경우 앞으로 Python 코드를 실행할 때 `python3`를 사용하세요. Python 2는 지원 종료되어 새로운 개발에 사용하지 않아야 합니다.

## Windows에 Python 설치하기

Windows에서 Python을 설치하려면 다음 단계를 따르세요:

- `https://www.python.org/`에 접속해 "Downloads" 위에 마우스를 올리세요. "Download for Windows"라는 모달과 현재 Python 버전이 표시된 다운로드 버튼이 보일 것입니다.
- 버전 번호를 클릭하면 Python 설치 관리자(`.msix` 패키지)가 자동으로 다운로드됩니다.
- Python 설치 관리자 다운로드가 완료되면 더블클릭하고 "설치"를 선택하세요.
- 설치가 완료되면 `python`, `py`, `pymanager` 명령어를 사용할 수 있습니다. Python 런타임이 설치되어 있지 않으면 `python`을 실행할 때 자동으로 설치됩니다.
- 런타임을 처음 설치할 때, `python3.14.exe` 같은 추가 별칭을 위해 `PATH`에 디렉터리를 추가하라는 선택적 프롬프트가 나타날 수 있습니다. 이 별칭들을 사용하려면 이 선택적 프롬프트를 수락하세요.


PowerShell 같은 명령줄 셸을 열고 `python --version`를 실행해 설치를 확인할 수 있습니다. 또한 `python`를 실행해 Python 인터프리터를 열 수 있습니다.

## Linux에 Python 설치하기

Linux에서는 Ubuntu, Debian, Fedora 같은 주요 배포판에 Python이 기본으로 포함되어 있습니다.

터미널을 열고 `python --version` 또는 `python3 --version`을 실행하세요.

두 명령어 모두 Python 3 버전을 표시하지 않으면, `https://www.python.org`에서 사용하는 리눅스 배포판에 맞는 설치 패키지를 검색하거나, 배포판에 맞는 Python 설치 권장 방법을 온라인에서 찾아보세요.
