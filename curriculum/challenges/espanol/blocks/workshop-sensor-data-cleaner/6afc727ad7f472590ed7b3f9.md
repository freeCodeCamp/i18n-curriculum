Antes de trabajar con las lecturas, necesitas eliminar los códigos de error.

Como aprendiste en las lecciones anteriores, la función `filter()` conserva solo los elementos de un iterable para los cuales una función devuelve un valor truthy. En lugar de definir esa función con `def`, puedes pasar una función lambda directamente a `filter()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

Luego, imprime `valid_readings` en lugar de `readings`.
