# --description--

现在你将把差值转换成类似 `+3.6 °C` 的文本标签。正数打印时没有符号，所以你需要在它们前面添加一个 `+`。

要只包含满足条件的项，你可以在列表推导式的末尾添加一个尾随的 `if`：

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

创建一个名为 `difference_labels` 的变量。使用列表推导式为它赋值一个列表，列表中包含每个 `differences` 中 `difference` 对应的 `f'+{difference} °C'`，但仅当 `difference` 大于 `0` 时才包含。

然后，打印 `difference_labels`，而不是 `differences`。

在终端中，你会看到 7 个温度中只有 3 个标签。尾随的 `if` 会排除不符合条件的项，因此无法判断每个标签对应哪个温度。你将在下一步修复这个问题。
