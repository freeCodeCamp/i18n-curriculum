# --description--

要将部门名称和值作为数组条目处理，请使用 `Object.entries(rawData)`。它会返回一个包含对象自身可枚举字符串键属性的 `[key, value]` 点对数组。

```js
const person = {
  name: "Alice",
  age: 30
};

console.log(Object.entries(person));
/*
Output: 
[ ["name", "Alice"], ["age", 30] ]
*/
```

声明一个名为 `departmentEntries` 的变量，并将其设置为 `Object.entries(rawData)`。
然后将 `departmentEntries` 记录到控制台，以查看它生成的 `[key, value]` 点对。
