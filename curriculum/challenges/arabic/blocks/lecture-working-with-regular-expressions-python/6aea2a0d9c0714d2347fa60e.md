# --description--

حتى الآن، استخدمت `re.search` للبحث عن نمط في أي مكان داخل سلسلة نصية. تحتوي وحدة `re` على العديد من الدوال الأخرى التي تعمل مع التعبيرات النمطية. في هذا الدرس، ستتعلم عن بعض من أكثرها فائدة.

## دالة `match`

تعمل دالة `match` مثل `search`، لكنها تبحث عن النمط فقط في بداية السلسلة النصية. تُرجع كائن تطابق إذا كان بداية السلسلة تطابق النمط، و`None` خلاف ذلك:

```python
import re

print(re.match(r'\d+', '42 apples'))
# <re.Match object; span=(0, 2), match='42'>

print(re.match(r'\d+', 'apples: 42')) # None
```

في المثال الثاني، تحتوي السلسلة على أرقام، لذا `re.search` ستجدها. لكن السلسلة لا تبدأ بأرقام، لذلك تُرجع `re.match` قيمة `None`.

## دالة `fullmatch`

النمط `r'\d+:\d+'` يطابق رقمًا أو أكثر، متبوعًا بنقطتين ثم رقمًا أو أكثر. هذا هو شكل الوقت مثل `10:30`.

تخيل أنك تريد التحقق من أن مُدخَل المستخدم هو وقت فقط، ولا شيء آخر. إذا استخدمت `re.search`، ستواجه مشكلة:

```python
import re

user_input = '10:30pm'
print(re.search(r'\d+:\d+', user_input))
# <re.Match object; span=(0, 5), match='10:30'>
```

هذا يُرجع كائن تطابق، رغم أن `10:30pm` لا يتبع التنسيق المتوقع. ذلك لأن `re.search` يبحث عن النمط في أي مكان داخل السلسلة، ويتجاهل أي حروف إضافية حول التطابق. سيكون لدى `re.match` نفس المشكلة، لأن `10:30pm` يبدأ بوقت صالح.

عند التحقق من صحة البيانات، عادةً تريد أن تتبع السلسلة النصية بأكملها النمط. لهذا، يمكنك استخدام دالة `fullmatch`. تُرجع كائن تطابق فقط عندما يطابق النمط السلسلة بأكملها، و`None` خلاف ذلك:

```python
import re

print(re.fullmatch(r'\d+:\d+', '10:30pm')) # None

print(re.fullmatch(r'\d+:\d+', '10:30'))
# <re.Match object; span=(0, 5), match='10:30'>
```

## دالة `findall`

`search` و`match` و`fullmatch` تعطيك تطابقًا واحدًا على الأكثر. عندما تريد كل التطابقات في سلسلة نصية، يمكنك استخدام دالة `findall`. تُرجع قائمة من السلاسل النصية بكل التطابقات التي تجدها:

```python
import re

menu = 'Coffee costs 3 dollars, tea costs 2, and cake costs 5.'
print(re.findall(r'\d+', menu)) # ['3', '2', '5']
```

إذا لم توجد تطابقات، تُرجع `findall` قائمة فارغة:

```python
import re

print(re.findall(r'\d+', 'No numbers here')) # []
```

## دالة `sub`

تستبدل دالة `sub` كل تطابق لنمط معين بسلسلة نصية أخرى. تأخذ النمط، وسلسلة الاستبدال، والسلسلة التي تبحث فيها، وتُرجع سلسلة جديدة:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message))
# My phone number is *** ****
```

لدى `sub` أيضًا معلمتان اختياريتان. الأولى هي `count`، التي تحدد عدد التطابقات التي تُستبدل:

```python
import re

message = 'My phone number is 555 0123'
print(re.sub(r'\d', '*', message, count=3))
# My phone number is *** 0123
```

الثانية هي `flags`. مثل الدوال الأخرى، يمكن لـ `sub` استخدام علامات مثل `re.IGNORECASE`:

```python
import re

sentence = 'Cat and cat'
print(re.sub('cat', 'dog', sentence, flags=re.IGNORECASE))
# dog and dog
```

مرر دائمًا `count` و`flags` كمعلمات مسماة. إذا مررت بـ `re.IGNORECASE` كالمعامل الرابع الموضع، سيعتبرها Python قيمة `count` بدلًا من ذلك.
