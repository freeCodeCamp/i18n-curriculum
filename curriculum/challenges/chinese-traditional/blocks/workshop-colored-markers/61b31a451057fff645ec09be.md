# --description--

為綠色標記的 `box-shadow` 屬性，將命名顏色取代為十六進位色碼。

要為十六進位色碼添加 alpha 通道，你需要在末尾加上第四組字元。和其他組一樣，它的範圍從 `00`（完全透通）到 `FF`（完全不透明）。例如，`#FF000080` 是約 50% 不透明度的純紅色。

紅色使用值 `3B`，綠色使用 `7E`，藍色使用 `20`，alpha 通道使用 `CC`。

# --hints--

你的 `.green` CSS 規則應該有一個 `box-shadow` 簡寫屬性，且值為 `0 0 20px 0 #3B7E20CC`。

```js
assert.strictEqual(new __helpers.CSSHelp(document).getStyle('.green')?.boxShadow, 'rgba(59, 126, 32, 0.8) 0px 0px 20px 0px');
```
