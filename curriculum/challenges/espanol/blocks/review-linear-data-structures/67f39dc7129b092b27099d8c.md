## Arreglos

- **Arreglos estáticos**: Tienen un tamaño fijo determinado en la inicialización. Los elementos se almacenan en ubicaciones de memoria adyacentes, lo que hace que el acceso sea muy eficiente. Su tamaño no puede cambiar mientras el programa se ejecuta.

- **Arreglos dinámicos**: Pueden crecer o reducirse automáticamente mientras el programa se ejecuta. Cuando el arreglo está lleno, sus elementos se copian en un nuevo arreglo más grande. El nuevo tamaño se elige para que estas copias costosas ocurran con menos frecuencia.

- **Arreglos estáticos en Python**: Python no incluye arreglos estáticos tradicionales como estructuras de datos integradas. Otros lenguajes, como Java, sí los soportan.

### Listas en Python (arreglos dinámicos)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### Complejidades de tiempo para arreglos dinámicos

- **Acceso**: O(1)
- **Insertar al final**: O(1) si hay espacio disponible, O(n) cuando se necesita redimensionar
- **Insertar en medio**: O(n) porque los elementos posteriores deben ser reubicados

### Elegir entre arreglos estáticos y dinámicos

- **Arreglos estáticos**: Cuando sabes el número de elementos de antemano y necesitas acceder a ellos con frecuencia.
- **Arreglos dinámicos**: Cuando el número de elementos es desconocido o cambia con el tiempo, o cuando insertar y eliminar elementos será frecuente.

## Pilas

- **Pilas**: Estructura de datos LIFO (último en entrar, primero en salir). Las pilas tienen dos extremos, arriba y abajo. Los elementos se agregan y eliminan solo desde arriba.

- **Operación push**: Agregar un elemento a la cima de la pila. Al usar una lista de Python, esto toma tiempo O(1) si hay espacio disponible, o O(n) cuando se necesita redimensionar.

- **Operación pop**: Eliminar un elemento de la cima de la pila. Complejidad de tiempo: O(1). Complejidad de espacio: O(1).

```python
# Using a Python list as a stack, where the end of the list is the top
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operation
top_element = stack.pop()  # Returns 3
```

## Colas

- **Colas**: Estructura de datos FIFO (primero en entrar, primero en salir). Las colas tienen dos extremos, frente y atrás. Los elementos se agregan al final y se eliminan del frente.

- **Operación enqueue**: Agregar un elemento al final de la cola. Al usar una lista de Python, esto toma tiempo O(1) si hay espacio disponible, o O(n) cuando se necesita redimensionar.

- **Operación dequeue**: Eliminar un elemento del frente de la cola. El siguiente elemento en la fila se convierte en el nuevo frente. Complejidad de tiempo: O(1). Complejidad de espacio: O(1).

```python
# Using a Python list as a queue, where the start of the list is the front
queue = []

# Enqueue operations
queue.append(1)
queue.append(2)
queue.append(3)

# Front element
front_element = queue[0]  # 1

# Dequeue operation
front_element = queue.pop(0)  # Returns 1
```

- **Nota**: Eliminar el primer elemento de una lista de Python con `.pop(0)` reubica todos los elementos restantes, por lo que toma tiempo O(n).

## Listas enlazadas

- **Listas enlazadas**: Estructura de datos lineal donde cada nodo almacena datos y una referencia al siguiente nodo. Los nodos están conectados como una cadena. Las listas enlazadas no tienen un tamaño fijo y pueden crecer o reducirse actualizando las conexiones entre los nodos.

- **Usos comunes**: Implementar otras estructuras de datos, como pilas, colas y deques, y algoritmos de grafos como búsqueda en profundidad y búsqueda en anchura.

### Listas enlazadas simples

- **Estructura**: Cada nodo almacena datos y una referencia al siguiente nodo.
- **Recorrido**: Solo puede avanzar, de la cabeza a la cola.
- **Nodo cabeza**: Primer nodo de la lista, usualmente el único nodo accesible directamente. El recorrido comienza aquí.
- **Nodo cola**: Último nodo de la lista. Su referencia al siguiente nodo es `None`, lo que marca el final de la lista.

#### Insertar nodos

- **Insertar al inicio**: O(1) - conecta el nuevo nodo con la antigua cabeza y lo convierte en la nueva cabeza
- **Insertar al final**: O(n) - se debe recorrer hasta el final, luego conectar la cola con el nuevo nodo
- **Insertar en medio**: O(n) - se debe recorrer hasta la posición, luego conectar el nodo anterior con el nuevo nodo y el nuevo nodo con el siguiente
- **Complejidad de espacio**: O(1) - solo se crea el nuevo nodo

#### Eliminar nodos

- **Eliminar al inicio**: O(1) - convierte el siguiente nodo en la nueva cabeza
- **Eliminar en medio**: O(n) - se debe recorrer hasta el nodo, luego conectar el nodo anterior con el siguiente, formando un "puente" sobre el nodo eliminado
- **Eliminar al final**: O(n) - se debe recorrer hasta el final, luego eliminar la conexión del nodo anterior, convirtiéndolo en la nueva cola
- **Complejidad de espacio**: O(1) - no se requiere memoria adicional

### Listas doblemente enlazadas

- **Estructura**: Cada nodo almacena datos y dos referencias: una al siguiente nodo y otra al nodo anterior.
- **Recorrido**: Puede moverse en ambas direcciones.
- **Referencia a la cola**: Es común mantener una referencia al nodo cola en la lista misma. Esto permite agregar nodos al final en tiempo O(1), sin recorrer la lista, y comenzar un recorrido desde el final.
- **Inserción y eliminación**: Funcionan igual que en listas enlazadas simples, pero se deben actualizar dos referencias por nodo.
- **Memoria**: Requiere más memoria que las listas enlazadas simples porque cada nodo almacena dos referencias en lugar de una.

## Cuándo usar cada estructura de datos

- **Arreglos estáticos**: Cuando se conoce el número de elementos de antemano y se necesita acceso rápido y frecuente
- **Arreglos dinámicos (listas)**: Cuando necesitas acceso ordenado e indexado y no conoces el tamaño de antemano
- **Pilas**: Cuando el último elemento agregado debe ser el primero en eliminarse (LIFO)
- **Colas**: Cuando los elementos deben procesarse en el orden en que se agregaron (FIFO)
- **Listas enlazadas simples**: Cuando el tamaño cambia con frecuencia y principalmente insertas y eliminas al inicio
- **Listas enlazadas dobles**: Cuando necesitas recorrer en ambas direcciones o agregar elementos al final eficientemente, y la memoria extra por nodo es aceptable
