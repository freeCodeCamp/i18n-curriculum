# --description--

Wie Sie in der vorherigen Lektion gelernt haben, ist ein Modul eine Python-Datei, die zusammengehörigen Code gruppiert, sodass Sie ihn in anderen Python-Dateien wiederverwenden können.

Sie können auch eigene Module schreiben und sie in Ihre Skripte importieren. Eigene Module zu erstellen ist eine großartige Möglichkeit, Ihren Code zu organisieren. Anstatt eine sehr lange Datei zu haben, können Sie Ihren Code in kleinere Dateien aufteilen, wobei jede zusammengehörigen Code gruppiert, und diese dann überall dort importieren, wo Sie sie brauchen.

Zum Beispiel nehmen wir an, Sie haben eine `temperature.py`-Datei mit zwei Funktionen zum Umrechnen von Temperaturen erstellt und einen Funktionsaufruf, um zu überprüfen, ob eine davon funktioniert:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

Wenn Sie diese Datei direkt ausführen, ist dies die Ausgabe:

```md
212.0
```

Nehmen wir nun an, Sie erstellen eine weitere Datei namens `main.py` im selben Ordner wie `temperature.py`. Um die Funktionen aus Ihrem lokalen Modul zu verwenden, importieren Sie es mit dem Namen des Moduls ohne die `.py`-Erweiterung:

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

Wenn Sie die Datei `main.py` ausführen, ist dies die Ausgabe:

```md
212.0
100.0
```

Wenn `temperature` importiert wird, führt Python den gesamten Code in `temperature.py` von oben bis unten aus. Deshalb wird `212.0` ausgegeben, obwohl `main.py` nur `fahrenheit_to_celsius()` aufruft. Solcher Code wie diese Überprüfung soll normalerweise nur ausgeführt werden, wenn Sie die Datei direkt ausführen, nicht jedes Mal, wenn sie importiert wird.

Um dies zu steuern, können Sie eine gängige Python-Redewendung verwenden:

```python
if __name__ == '__main__':
    # Code
```

`__name__` ist eine spezielle eingebaute Variable in Python.

Wenn eine Python-Datei direkt ausgeführt wird, setzt Python den Wert dieser Variablen auf den String `__main__`.

Wenn die Python-Datei jedoch als Modul in ein anderes Python-Skript importiert wird, wird der Wert der `__name__`-Variablen auf den Namen dieses Moduls gesetzt (normalerweise der Dateiname ohne die `.py`-Erweiterung).

Deshalb finden Sie diese Bedingung oft in Python-Skripten. Sie enthält den Code, den Sie **nur ausführen möchten, wenn** das Python-Skript als Hauptprogramm läuft. Wenn das Skript als Modul importiert wird, läuft der Code in diesem Block nicht.

Das ist hilfreich, weil es Python-Skripten erlaubt, zwei Zwecke zu erfüllen. Sie können direkt ausgeführt werden, um ihre Hauptlogik auszuführen, oder sie können in ein anderes Modul importiert werden, ohne ihre Hauptlogik auszuführen.

Hier ist die `temperature.py`-Datei, aktualisiert mit dieser Redewendung. Sie gibt auch den Wert von `__name__` aus, damit Sie sehen können, wie er sich ändert:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

Wenn Sie diese Datei direkt ausführen, setzt Python `__name__` auf `'__main__'`, sodass die Bedingung `True` ist und der Code im `if`-Block ausgeführt wird. Dies ist die Ausgabe:

```md
The value of __name__ is: __main__
212.0
```

Wenn Sie stattdessen die Datei `main.py` ausführen, ist dies die Ausgabe:

```md
The value of __name__ is: temperature
100.0
```

Der `print()`-Aufruf außerhalb des `if`-Blocks läuft weiterhin, wenn `temperature` importiert wird, und zeigt, dass der Wert von `__name__` jetzt `temperature` ist, der Name des Moduls.

Da `__name__` aber nicht gleich `'__main__'` ist, läuft der Code im `if`-Block nicht, sodass `212.0` nicht ausgegeben wird. Die einzige andere Ausgabe ist `100.0`, die vom Funktionsaufruf in `main.py` stammt.
