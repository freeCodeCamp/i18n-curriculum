# --description--

複合代入は、変数に対して演算を行い、その結果を同じ変数に一度のステップでストアします。

加算代入の基本的な構文は次のようになります：

```python
variable <operator>= value
```

数値変数の場合、これは次の代入を短く書く方法です。

```python
variable = variable <operator> value
```

例えば、加算代入演算子を使って既存の変数に `5` を加えることができます。

```python
my_var = 10
my_var += 5

print(my_var) # 15
```

同じことを加算代入を使わずに書くとこうなります：

```python
my_var = 10
my_var = my_var + 5

print(my_var) # 15
```

加算代入の利点は、変数名を繰り返さずに変数の値を簡潔かつ読みやすく更新できることです。これにより冗長さが減り、タイプミスなどによるエラーの可能性も減ります。

算術演算子とビット演算子には加算代入の形があります。加算代入演算子（`+=`）を見てきたので、他のものも見てみましょう。

- 減算代入演算子（`-=`）は、左の変数から右の値を引き、その差を左の変数に代入します：

```python
count = 14
count -= 3

print(count) # 11
```

- 乗算代入演算子（`*=`）は、左の変数に右の値を掛け、その積を左の変数に代入します：
    

```python
product = 65
product *= 7

print(product) # 455
```

- 除算代入演算子（`/=`）は、左の変数を右の値で割り、その結果を左の変数に代入します：
    

```python
price = 100
price /= 4

print(price) # 25.0
```

- フロア除算代入演算子（`//=`）は左の変数を右の値でフロア除算し、その結果を左の変数にストアします。
    

```python
total_pages = 23
total_pages //= 5

print(total_pages) # 4
```

- モジュラス代入演算子（`%=`）は、左の変数を右の値で割った余りを計算し、それを左の変数に代入します：
    

```python
bits = 35
bits %= 2

print(bits) # 1
```

- べき乗代入演算子（`**=`）は、左の変数を右の値のべき乗にし、その結果を左の変数に代入します：
    

```python
power = 2
power **= 3

print(power) # 8
```

文字列に対しても一部の加算代入演算子が使えます。例えば、加算代入演算子は文字列の連結を簡単にします：

```python
greet = 'Hello'
greet += ' World'

print(greet) # Hello World
```

また、乗算代入演算子は文字列の繰り返しに使えます：

```python
greet = 'Hello'
greet *= 3

print(greet) # HelloHelloHello
```

減算代入演算子と除算代入演算子は、文字列に使うと `TypeError` を発生させます。

```python
greet = 'Hello'
greet -= ' World' # TypeError: unsupported operand type(s) for -=: 'str' and 'str'
```

```python
greet = 'Hello'
greet /= 'World' # TypeError: unsupported operand type(s) for /=: 'str' and 'str'
```
