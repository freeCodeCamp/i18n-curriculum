Der Operator `==` prüft, ob zwei Tuples gleiche Elemente in der gleichen Reihenfolge haben.

Fügen Sie nach der ersten `if`-Anweisung eine weitere `if`-Anweisung hinzu, die überprüft, ob `installed` gleich `latest` ist. Wenn ja, geben Sie ein Tuple zurück, das den String `up to date` und `latest` enthält.

Ändern Sie dann das Argument `(3, 0, 0)` Ihres `check_for_update`-Aufrufs in `(2, 2, 1)`, um den neuen Status im Terminal zu sehen.
