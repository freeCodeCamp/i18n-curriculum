# --description--

递归是一种技术，其中函数调用自身。每次调用都处理原始问题的一个更小版本，直到达到停止递归的条件。这个停止条件称为基本情形。

递归函数可以解决深度未知的问题，例如遍历文件树。它们也可以执行更简单的任务，比如从给定数字倒数。

这里有一个名为 `recursive_countdown` 的函数，它接受一个数字并打印它：

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

调用该函数会打印 `5`，但还没有开始倒数。在让函数调用自身之前，你需要定义它的基本情形。如果没有可达的基本情形，函数会不断调用自身。Python 最终会停止调用并引发 `RecursionError`。

对于这个倒数，函数应该在 `number` 小于 `1` 时停止：

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

`if` 语句是基本情形。当 `number` 小于 `1` 时，`return` 结束该函数调用。

函数仍然需要一个递归情形。递归情形再次调用函数，传入一个使其向基本情形靠近的参数。要倒数，调用 `recursive_countdown` 并传入 `number - 1`：

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

这会打印数字 `5`、`4`、`3`、`2` 和 `1`。

递归调用的位置改变了数字的打印顺序。如果 `print()` 调用在递归调用之后，函数会按升序打印数字：

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

这会打印数字 `1`、`2`、`3`、`4` 和 `5`。要理解原因，你需要了解调用栈。

调用栈是一个后进先出（LIFO）数据结构，Python 用它来跟踪活动的函数调用。当函数被调用时，Python 会为该调用在栈顶添加一个帧。该帧包含函数的参数和局部变量等信息。

考虑这个版本的倒数：

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

输出是：

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

调用 `recursive_countdown(3)` 时，当它调用 `recursive_countdown(2)`，该调用会暂停。传入 `2` 的调用在调用传入 `1` 的函数时暂停，传入 `1` 的调用在调用传入 `0` 的函数时暂停。

传入 `0` 的调用达到基本情形并返回。Python 会从栈顶移除该调用，因此传入 `1` 的调用在其递归调用后恢复。剩下的调用随后按相反顺序恢复并返回：`1`、`2` 和 `3`。

每个递归函数都需要一个基本情形和一个向其靠近的递归情形。当基本情形返回时，之前的调用会按后进先出顺序恢复。
