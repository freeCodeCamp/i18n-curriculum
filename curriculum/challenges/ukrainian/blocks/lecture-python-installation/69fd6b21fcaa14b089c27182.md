## Встановлення редактора коду або IDE

У попередньому уроці ви дізналися, як встановити Python на свій локальний пристрій. У цьому уроці ви навчитеся запускати код Python локально.

Перш ніж почати створювати свої Python-скрипти локально, вам потрібно встановити редактор коду або IDE. IDE означає інтегроване середовище розробки. IDE поєднує такі функції, як редактор коду, інструменти для тестування та термінал.

Одним із популярних редакторів коду, який використовують багато розробників, є VS Code. Відвідайте `https://code.visualstudio.com/download`, щоб скачати VS Code, який підтримує macOS, Windows і Linux. Саме цей редактор буде використаний у цьому уроці.

Інші загальні варіанти для розробки на Python включають:

- PyCharm
- Spyder

## Створення Python-файлу

Після встановлення VS Code відкрийте його та виберіть `File`, потім `Open Folder`. Оберіть або створіть папку для свого проєкту. Для додаткової практики поза межами уроку ви можете створити папку з назвою `python-projects`.

Відкрийте Explorer у лівій бічній панелі VS Code. Виберіть іконку `New File`, яка виглядає як аркуш паперу з плюсом. Створіть файл з назвою `main.py` і натисніть <kbd>Enter</kbd>. Розширення `.py` ідентифікує його як Python-файл.

Відкрийте свій файл `main.py` і введіть наступний код:

```py
print("Hello, world!")
```

## Встановлення розширення Python

Щоб встановити офіційне розширення Python від Microsoft, виконайте наведені нижче кроки:

### Метод A: всередині застосунку

1. Відкрийте перегляд розширень, натиснувши на іконку з чотирьох блоків у лівій панелі активності. Або натисніть <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (Windows / Linux) або <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (macOS).
1. Введіть `Python` у рядок пошуку зверху.
1. Знайдіть перший результат з назвою Python, переконайтеся, що під ним вказаний видавець Microsoft.
1. Натисніть синю кнопку <kbd>Install</kbd>.

### Метод B: термінал / командний рядок

Якщо ви віддаєте перевагу встановленню розширення через термінал, спочатку переконайтеся, що команда `code` доступна. На macOS відкрийте Command Palette, виконайте `Shell Command: Install 'code' command in PATH` і перезапустіть термінал.

Потім встановіть розширення Python, виконавши команду:

```bash
code --install-extension ms-python.python
```

## Вибір інтерпретатора Python

Розширення виступає як міст, але не містить самі файли мови Python. Якщо ви ще не встановили інтерпретатор Python, зробіть це окремо з офіційного сайту Python.

Після встановлення Python на вашу операційну систему зв’яжіть його з редактором:

1. У VS Code відкрийте будь-яку папку або файл з розширенням `.py`.
1. Відкрийте Command Palette, натиснувши <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows / Linux) або <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS).
1. Введіть і виберіть `Python: Select Interpreter`.
1. Оберіть встановлену версію Python 3 зі списку вашої машини. Вона тепер відображатиметься у рядку стану робочого простору.

## Запуск вашого Python-скрипта

Щоб запустити цей код, у вас є кілька варіантів. Перший — натиснути кнопку запуску, яка виглядає як кнопка відтворення і розташована у верхньому правому куті. Це відкриє термінал і запустить ваш Python-скрипт там. Ви побачите текст `Hello, world!`

Інший варіант — відкрити термінал і вручну запустити програму за допомогою:

```bash
python main.py
```

Цю команду потрібно запускати з папки, де збережено `main.py`. Наприклад, якщо `main.py` знаходиться у папці `python-projects`, спочатку використайте у терміналі:

```bash
cd python-projects
```

Потім запустіть:

```bash
python main.py
```

## Використання `python3` замість `python`

У деяких середовищах, особливо на macOS і Linux, де встановлені і Python 2, і Python 3, можливо, доведеться використовувати `python3` замість `python`. Це поширено, коли команда `python` або не існує, або вказує на старішу версію Python.

```bash
python3 main.py
```
