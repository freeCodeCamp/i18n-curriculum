# --description--

آخر شيء يجب فعله هو تحديث حالة `isOpen` عند نقر زر `Apps`.

في React، تستجيب للأحداث بتمرير دالة إلى خاصية حدث على عنصر. تُكتب هذه الخصائص بتنسيق سنام الجمل، لذا يُتعامل مع النقر باستخدام `onClick`:

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

لاحظ أن `onClick` تستقبل دالة. تستدعي React هذه الدالة في كل مرة يُنقر فيها الزر. استدعاء دالة التعيين بقيمة جديدة يحدث الحالة، ثم تعيد React عرض المكوِّن بهذه القيمة الجديدة.

لتبديل حالة منطقية بين `true` و `false`، يمكنك تمرير القيمة العكسية للحالة الحالية إلى دالة التعيين باستخدام عامل النفي المنطقي (`!`).

أضف خاصية `onClick` إلى عنصر `button`. اجعلها دالة سهمية تستدعي `setIsOpen` بالقيمة العكسية لـ `isOpen`.

انقر زر `Apps` لفتح وإغلاق `sub-menu`.

بهذا، يصبح مكوِّن `Navbar` الخاص بك مكتملًا!

# --hints--

يجب أن يؤدي نقر زر `Apps` إلى تعيين خاصية `aria-expanded` إلى `"true"` وإضافة الصنف `sub-menu--open` إلى `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

يجب أن يؤدي نقر زر `Apps` مرة ثانية إلى إعادة خاصية `aria-expanded` إلى `"false"` وإزالة الصنف `sub-menu--open` من `sub-menu`.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
