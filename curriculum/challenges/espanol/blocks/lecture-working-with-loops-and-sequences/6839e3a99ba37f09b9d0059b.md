## ¿Qué es una tupla?

Una tupla es un tipo de dato de Python usado para crear una secuencia ordenada de valores. Las tuplas pueden contener un conjunto mixto de tipos de datos como este:

```py
developer = ('Alice', 34, 'Rust Developer')
```

Las comas crean la tupla, por lo que los paréntesis son opcionales en una asignación como esta:

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

Para crear una tupla con un elemento, necesitas una coma al final:

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

Una tupla vacía se escribe como `()`.

Las tuplas son similares a las listas, pero mientras las listas son un tipo de dato mutable, las tuplas son inmutables. Esto significa que los elementos en una tupla no pueden cambiarse una vez que se ha creado.

Si intenta actualizar uno de los elementos en la tupla, obtendrá un `TypeError`:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## Acceder a elementos de una tupla

Para acceder a un elemento de una tupla, puedes usar la notación con corchetes y el número de índice:

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

Si necesitas acceder a elementos comenzando desde el final de una tupla, entonces puedes usar indexación negativa. Aquí tienes un ejemplo de cómo usar un índice negativo para acceder al penúltimo elemento en una tupla:

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

Si intentas pasar un número de índice que excede o es igual a la longitud de la tupla, recibirás un `IndexError` como este:

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## Usar el constructor `tuple()`

Otra forma de crear una tupla es usando el constructor `tuple()` así:

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

Para el constructor `tuple()`, puedes pasar diferentes iterables como cadenas, listas e incluso otras tuplas.

## Comprobar si un elemento está en una tupla

Para verificar si un elemento está en una tupla, puedes usar la palabra clave `in` así:

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## Desempaquetar valores de una tupla

También puedes desempaquetar elementos de una tupla tal como lo hiciste con las listas:

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

En este ejemplo, `name` tiene el valor `'Alice'`, `age` tiene el valor `34` y `job` tiene el valor `'Rust Developer'`.

Si necesita recoger cualquier elemento restante de una tupla, puede usar el operador asterisco (`*`) de esta manera:

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

Aquí, `name` tiene el valor `'Alice'`, y `rest` es una lista compuesta por el número `34` y la cadena `'Rust Developer'`.

## Usar tuplas en asignación simultánea

Puedes crear una tupla en el lado derecho de una asignación y desempaquetarla en las variables del lado izquierdo:

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

Python evalúa todas las expresiones del lado derecho antes de asignar sus valores a las variables del lado izquierdo. Esto te permite intercambiar dos valores sin una variable temporal:

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## Devolver una tupla desde una función

Una función puede devolver una tupla colocando valores separados por comas después de `return`:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

Los valores separados por comas crean una tupla que la función devuelve. Aquí, `return first, second` es equivalente a `return (first, second)`. Los paréntesis son opcionales.

Puedes desempaquetar la tupla devuelta directamente en variables:

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## Cortar tuplas

Al igual que con una lista, puedes usar el operador de corte en una tupla para extraer una porción de ella. Aquí tienes un ejemplo de cómo extraer los elementos `'pie'` y `'cookies'` en una tupla separada:

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

Recuerda que el primer número representa el índice inicial para la extracción mientras que el segundo número representa el índice final. Pero ten en cuenta que el elemento en el índice final no está incluido en la tupla extraída.

## Comparar tuplas

Python compara tuplas lexicográficamente. Esto significa que compara los elementos correspondientes de izquierda a derecha. El primer par desigual determina el resultado:

```py
print((1, 9) < (2, 0)) # True
```

Aquí, `1` es menor que `2`, por lo que la primera tupla es más pequeña. Python no necesita comparar `9` y `0`.

Si los primeros elementos son iguales, Python pasa al siguiente par:

```py
print((1, 3) < (1, 5)) # True
```

Ambas tuplas comienzan con `1`, así que Python compara `3` con `5` para determinar el resultado.

Si todos los elementos correspondientes son iguales, la tupla más corta es la más pequeña. Las tuplas con la misma longitud y elementos correspondientes iguales son iguales:

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

Los valores en el primer par desigual deben soportar la comparación de orden. De lo contrario, Python genera un `TypeError`:

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

Aquí, los primeros elementos son iguales, pero Python no puede ordenar el entero `3` y la cadena `'five'`.

Los elementos posteriores no necesitan ser comparables si un par anterior ya determina el resultado:

```py
print((1, 3) < (2, 'five')) # True
```

## Eliminar elementos de una tupla

Si necesitas eliminar un elemento de una tupla, eso no es posible porque las tuplas son inmutables. Así que este ejemplo producirá un error:

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## Elegir entre tuplas y listas

Entonces, ¿cuándo podrías usar una tupla en lugar de una lista?

Si necesitas una colección dinámica de elementos donde puedas agregar, eliminar y actualizar elementos, entonces debes usar una lista. Si sabes que estás trabajando con una colección fija e inmutable de datos, entonces debes usar una tupla.

En la próxima lección, veremos algunos métodos comunes que usarás al trabajar con tuplas.
