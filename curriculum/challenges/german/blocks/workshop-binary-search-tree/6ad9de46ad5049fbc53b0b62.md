# --description--

Wenn der Knoten zwei Kinder hat, müssen Sie seinen Wert durch einen anderen ersetzen und dabei den Baum geordnet halten. Die richtige Wahl ist sein inorder-Nachfolger: der Wert, der direkt nach ihm bei einer inorder-Durchquerung kommt.

Der inorder-Nachfolger ist der kleinste Wert im rechten Teilbaum des Knotens, und Sie finden ihn, indem Sie vom rechten Kind aus so weit wie möglich nach links gehen.

Erstellen Sie innerhalb der `BinarySearchTree`-Klasse eine Methode namens `_min_value` mit zwei Parametern, `self` und `node`. Verwenden Sie darin eine `while`-Schleife, um `node.left` so lange `node` zuzuweisen, wie `node.left` nicht `None` ist. Nach der Schleife geben Sie `node.key` zurück.
