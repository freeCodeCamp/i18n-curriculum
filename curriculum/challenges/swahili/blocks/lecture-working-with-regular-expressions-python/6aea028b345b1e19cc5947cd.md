# --description--

Usemi wa kawaida, au regex, ni muundo unaotumika kulinganisha mfululizo wa herufi katika maandishi.

Umeweza tayari kutumia `in` operator kuangalia kama mfuatano wa herufi una sehemu ndogo halisi. Lakini kuna hali ambapo hujui maandishi halisi unayotafuta, bali tu muundo wake. Kwa mfano, unaweza kutaka kuangalia kama mfuatano wa herufi unaanza na herufi fulani ikifuatiwa na nambari fulani, au jina la mtumiaji limeundwa tu na herufi zinazoruhusiwa.

Usemi wa kawaida hukuruhusu kuelezea mifumo kama hii na kuangalia kama mfuatano wa herufi unalingana nayo. Hutumika sana kwa kuthibitisha ingizo, kutafuta ndani ya maandishi, na kutoa vipande vya taarifa kutoka kwa mfuatano wa herufi.

Katika Python, ili kutumia usemi wa kawaida unahitaji ku import moduli ya `re`, ambayo ni sehemu ya maktaba ya kawaida:

```python
import re
```

Mfumo rahisi zaidi wa regex ni mfumo halisi: mfululizo wa herufi ambao lazima uonekane kama ulivyoandikwa. Kwa mfano, mfumo `'cat'` unalingana na herufi `c`, `a`, na `t`, moja baada ya nyingine.

Ili kutafuta mfumo ndani ya mfuatano wa herufi, unaweza kutumia kitendakazi `search` kutoka moduli ya `re`. Huchukua mfumo kama hoja yake ya kwanza na mfuatano wa herufi wa kutafuta kama hoja yake ya pili:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('cat', sentence))
# <re.Match object; span=(4, 7), match='cat'>
```

Wakati `re.search` inapopata mfumo mahali popote ndani ya mfuatano wa herufi, hurudisha kitu cha mechi. Kitu cha mechi kilicho chapishwa hukueleza mambo mawili:

- `match='cat'` ni maandishi yaliyo lingana na mfumo.

- `span=(4, 7)` ni mahali pa mechi ndani ya mfuatano wa herufi. Mechi inaanza kwenye kielezo `4` na inamalizika kabla ya kielezo `7`.

Unaweza pia kupata taarifa hii kutoka kwa kitu cha mechi kwa njia zake za `group` na `span`:

```python
import re

sentence = 'The cat sat on the mat.'
result = re.search('cat', sentence)

print(result.group()) # cat
print(result.span())  # (4, 7)
```

Wakati mfumo haupatikani, `re.search` hurudisha `None`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('dog', sentence)) # None
```

Kwa chaguo-msingi, kulinganisha regex ni nyeti kwa herufi kubwa na ndogo. Hii ina maana mfumo `'Cat'` haulingani na maandishi `cat`:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence)) # None
```

Ili kubadilisha jinsi mfumo unavyolinganishwa, unaweza kupitisha bendera kama hoja ya tatu kwa `re.search`. Bendera `re.IGNORECASE` hufanya utafutaji usiwe nyeti kwa herufi kubwa na ndogo, hivyo herufi kubwa na ndogo hutazamwa sawa:

```python
import re

sentence = 'The cat sat on the mat.'
print(re.search('Cat', sentence, re.IGNORECASE))
# <re.Match object; span=(4, 7), match='cat'>
```
