# --description--

L'operatore `or` serve a verificare se almeno una delle due condizioni è vera. Ecco come puoi usarlo con un confronto in un'istruzione `if`:

```py
day = 'Sunday'
is_raining = False

if day == 'Sunday' or is_raining:
    print('Stay at home')
```

Nell'esempio sopra, viene stampato `Stay at home` perché la prima condizione è vera, anche se `is_raining` è `False`.

Le spese extra dovrebbero applicarsi anche nei fine settimana. Aggiorna la condizione della riga `if show_time == 'Evening':` usando l'operatore `or` per combinare la condizione esistente con una seconda condizione che verifica se `is_weekend` è vera.
