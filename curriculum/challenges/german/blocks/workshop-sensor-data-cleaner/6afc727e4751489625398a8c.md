# --description--

Jetzt wandeln Sie die Differenzen in Textbezeichnungen wie `+3.6 °C` um. Positive Zahlen werden ohne Vorzeichen ausgegeben, daher müssen Sie ein `+` davor setzen.

Um nur die Elemente einzuschließen, die eine Bedingung erfüllen, können Sie am Ende einer List Comprehension ein nachgestelltes `if` hinzufügen:

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

Erstellen Sie eine Variable namens `difference_labels`. Verwenden Sie eine List Comprehension, um ihr eine Liste zuzuweisen, die `f'+{difference} °C'` für jede `difference` in `differences` enthält, aber nur, wenn `difference` größer als `0` ist.

Geben Sie dann `difference_labels` statt `differences` aus.

Im Terminal sehen Sie nur 3 Bezeichnungen für 7 Temperaturen. Ein nachgestelltes `if` schließt die Elemente aus, die die Bedingung nicht erfüllen, sodass nicht erkennbar ist, zu welcher Temperatur jede Bezeichnung gehört. Das beheben Sie im nächsten Schritt.
