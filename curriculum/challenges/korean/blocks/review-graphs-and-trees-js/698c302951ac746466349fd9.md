## 그래프 개요

그래프는 노드(정점) 집합과 간선(연결)으로 구성됩니다. 각 노드는 여러 다른 노드와 연결될 수 있어 네트워크를 형성합니다. 그래프 유형은 다음과 같습니다:

- **방향 그래프**: 간선이 한 노드에서 다른 노드로 향하는 방향을 가지며, 보통 직선과 화살표로 나타냅니다.
- **무방향 그래프**: 간선에 방향이 없으며, 단순한 선으로 표현됩니다.
- **노드 레이블**: 각 노드가 레이블이나 식별자와 연결되어 있습니다.
- **순환 그래프**: 시작 노드와 끝 노드가 같은 경로(사이클)를 포함합니다.
- **방향 비순환 그래프(DAG)**: 사이클이 없는 방향 그래프입니다.
- **간선 레이블**: 각 간선에 레이블이 붙어 있으며 보통 해당 간선 옆에 표시됩니다.
- **가중치 그래프**: 간선에 산술 연산에 사용할 수 있는 가중치(값)가 할당되어 있습니다.
- **비연결 그래프**: 두 개 이상의 노드 그룹(컴포넌트)이 간선으로 연결되어 있지 않습니다. 두 노드 사이에 직접 간선이 없어도 경로가 있을 수 있습니다.

그래프는 지도, 네트워크, 추천 시스템, 의존성 해결 등 다양한 애플리케이션에서 사용됩니다.

## 그래프 순회

그래프의 모든 노드를 방문하는 작업입니다. 주요 알고리즘 두 가지는:

- **너비 우선 탐색(BFS)**: 그래프에서 다음 레벨로 이동하기 전에 모든 인접 노드를 방문합니다.
  - **큐**: 큐(FIFO)를 사용합니다. 시작 노드를 방문 표시하고 큐에 추가합니다. 큐가 비어 있지 않은 동안 현재 노드를 큐에서 꺼내고, 방문하지 않은 이웃 노드를 방문 표시한 후 큐에 추가합니다.
  - **최단 경로**: 가중치 없는 그래프에서 최단 경로를 찾습니다.
  - **메모리**: 큐를 메모리에 저장해야 하므로, 특히 같은 레벨에 노드가 많을 때 공간 요구량이 클 수 있습니다.
  - **연결 컴포넌트**: 아직 방문하지 않은 각 노드에서 새 탐색을 시작하여 연결된 그래프 컴포넌트를 찾는 데도 사용할 수 있습니다.
  - **상태 공간 탐색**: 괄호 조합을 만들면서 다양한 상태를 추적하기 위해 큐를 사용합니다. 각 상태는 현재 생성 중인 문자열, 지금까지 사용한 여는 소괄호 수, 닫는 소괄호 수를 포함하는 배열로 나타냅니다. 여는 소괄호는 사용한 개수가 쌍의 개수보다 적을 때만 추가할 수 있습니다. 닫는 소괄호는 균형을 유지해야 하므로, 여는 소괄호가 닫는 소괄호보다 많을 때만 추가할 수 있습니다.

- **깊이 우선 탐색(DFS)**: 각 가지를 가능한 깊게 따라간 후 되돌아갑니다.
  - **스택**: 스택(LIFO)이나 재귀를 사용합니다. 시작 노드를 방문 표시하고 스택에 추가합니다. 스택이 비어 있지 않은 동안 현재 노드를 꺼내고, 방문하지 않은 이웃 노드를 방문 표시한 후 스택에 추가합니다.
  - **메모리**: 스택(또는 재귀 호출 스택)을 메모리에 저장해야 하므로, 매우 긴 경로가 있는 그래프에서는 공간 요구량이 커질 수 있습니다.
  - **사용 사례**: 사이클 탐지, 경로 찾기, 연결 컴포넌트 찾기에 유용합니다.
  - **제한점**: 가중치 없는 그래프에서 두 노드 사이의 최단 경로를 항상 찾는 것은 보장되지 않습니다.

## 그래프 표현

그래프는 두 가지 주요 방식으로 표현할 수 있습니다:

- **인접 리스트**: 각 노드는 이웃 노드 목록을 가집니다.
  - **구현 방법**: 배열로 구현할 수 있는데, 각 인덱스가 노드를 나타내고 그 인덱스에 저장된 배열이 이웃 노드를 포함합니다. 객체(또는 `Map`)로 구현할 수도 있는데, 각 키가 노드를 나타내고 그 키에 연결된 값(배열)이 이웃 노드를 포함합니다.
  - **공간**: 희소 그래프에 공간 효율적이며, 공간 복잡도는 `O(V + E)`입니다. 여기서 `V`는 정점(노드) 수, `E`는 간선 수입니다.
  - **이웃 노드**: 노드에 연결된 목록에 접근하기만 하면 되므로 이웃 노드를 순회하기 쉽습니다.
  - **간선 조회**: 두 노드 사이에 간선이 있는지 확인하는 데는 인접 행렬보다 덜 효율적입니다. 일반적으로 `O(deg(v))` 시간이 걸리는데, 여기서 `deg(v)`는 확인하는 노드의 이웃 수이며, 최악의 경우 `O(V)`가 될 수 있습니다.
  - **적합한 경우**: 희소 그래프가 더 흔한 실제 상황에서 보통 선호되는 선택입니다.

- **인접 행렬**: 행과 열이 노드를 나타내는 2차원 배열입니다.
  - **값**: 그래프가 가중치 없으면 `1`은 간선 존재, `0`은 간선 없음입니다. 가중치 그래프면 값이 간선의 가중치를 나타냅니다.
  - **자기 루프**: 대각선 값은 각 노드가 자기 자신과 연결된 간선(자기 루프)이 있는지 나타냅니다.
  - **공간**: 큰 그래프에 대해 공간을 많이 차지하며, 노드 수 `V`에 대해 `O(V²)` 공간 복잡도를 가집니다.
  - **간선 조회**: 두 노드 사이에 간선이 있는지 빠르게 확인할 수 있어 상수 시간 `O(1)`이 걸립니다.
  - **이웃 찾기**: 노드의 이웃을 찾으려면 전체 행이나 열을 순회해야 하므로 비효율적이며, 최악의 경우 `O(V)` 시간이 걸립니다.
  - **적합한 경우**: 간선이 많은 밀집 그래프에 유용하며, 간선이 적은 희소 그래프에는 비효율적입니다.

## 최단 경로 알고리즘

- **최단 경로 알고리즘**: 가중치 그래프에서 노드 간 최단 경로를 계산하고 거리와 경로를 모두 반환합니다.
  - **인접 행렬**: 각 값은 두 노드 간 간선의 가중치(거리)를 나타냅니다.
  - **간선 없음**: `INF`(`Infinity`) 값은 직접 연결된 간선이 없음을 의미합니다.
  - **거리 배열**: 시작 노드에서 다른 모든 노드까지 알려진 최단 거리를 추적하는 배열입니다. 처음에는 모든 노드가 무한대로 가정되고, 시작 노드에서 자기 자신까지 거리는 항상 `0`입니다.
  - **경로 리스트**: 각 항목은 각 노드에 도달하는 경로를 나타내는 노드 인덱스 배열입니다.
  - **방문 배열**: 이미 처리한 노드를 추적하여 중복 방문을 방지합니다.
  - **가장 가까운 미방문 노드**: 메인 루프는 그래프의 각 노드마다 한 번씩 실행되며, 매번 가장 가까운 미방문 노드를 선택합니다.
  - **간선 완화**: 아직 방문하지 않은 실제 간선이 있는 각 이웃에 대해 현재 노드를 통해 더 효율적으로 도달할 수 있는지 확인합니다. 새 거리가 기존 거리보다 좋으면 거리와 경로를 업데이트합니다.
  - **도달 불가능 노드**: 유효한 노드를 찾지 못하면 나머지 노드는 모두 도달 불가능하므로 루프를 조기 종료합니다.
  - **선택적 대상**: `targetNode` 매개변수는 선택 사항입니다. 제공하지 않으면 함수는 `startNode`에서 모든 다른 노드까지 최단 경로를 계산합니다.

## 트리

트리는 사이클이 없고 연결된 특수한 그래프입니다. 주요 속성은:

- **비순환**: 트리는 루프나 사이클(시작 노드와 끝 노드가 같은 경로)이 없습니다.
- **연결됨**: 모든 노드는 다른 모든 노드에서 도달할 수 있습니다.

### 트리 용어

- **루트 노드**: 트리의 가장 상단 노드로, 부모 노드가 없는 유일한 노드입니다.
- **부모 노드**: 바로 아래 노드들과 연결된 노드입니다.
- **자식 노드**: 바로 위 노드와 연결된 노드입니다.
- **잎 노드**: 자식 노드가 없는 노드입니다.
- **깊이**: 루트에서 해당 노드까지의 경로 길이입니다.
- **높이**: 해당 노드에서 잎 노드까지의 경로 길이입니다. 트리의 높이는 루트 노드의 높이입니다.
- **차수**: 각 노드가 가진 자식 노드 수입니다.
- **부분 트리**: 트리의 일부로서 자체가 트리인 섹션입니다.
- **균형 트리**: 어떤 노드의 왼쪽과 오른쪽 부분 트리 높이가 매우 비슷하여 연산이 효율적으로 유지되는 트리입니다.

### 일반적인 트리 유형

가장 일반적인 트리 유형은:

- **이진 트리**: 각 노드가 최대 두 개의 자식, 왼쪽과 오른쪽 자식을 가집니다.

- **이진 탐색 트리(BST)**: 각 노드에 대해 왼쪽 부분 트리의 모든 값은 노드 값보다 작고, 오른쪽 부분 트리의 모든 값은 노드 값보다 큰 이진 트리입니다. 왼쪽과 오른쪽 부분 트리도 각각 이진 탐색 트리여야 합니다.

- **자기 균형 트리**: 삽입이나 삭제로 균형이 깨질 때 내부 로직으로 트리를 재균형하는 트리입니다. 대표적인 예로 AVL 트리, 레드-블랙 트리, B-트리가 있습니다.

- **AVL 트리**: 어떤 노드의 왼쪽과 오른쪽 부분 트리 높이 차이가 최대 1인 자기 균형 이진 탐색 트리입니다.

- **레드-블랙 트리**: 각 노드가 빨간색 또는 검은색으로 색칠된 자기 균형 이진 탐색 트리입니다.

- **B-트리**: 각 노드가 여러 키와 두 개 이상의 자식 노드를 가질 수 있는 자기 균형 트리입니다.

## 트라이

- **트라이**: 접두사 트리라고도 하며, 각 노드가 문자를 나타내는 문자열 집합을 저장하는 데 사용됩니다.
- **루트 노드**: 특정 문자를 나타내지 않으며, 빈 문자열을 나타낸다고 생각할 수 있습니다.
- **접두사**: 루트에서 트라이를 따라 내려가면서 노드까지의 경로가 특정 접두사를 정의합니다.
- **단어 끝 표시**: 완전한 단어를 나타내는 노드에 단어 끝 표시가 할당됩니다.
- **공유 접두사**: 여러 문자열이 같은 접두사를 공유하면 경로가 겹쳐 접두사가 한 번만 저장되어, 자동 완성이나 맞춤법 검사에 효율적입니다.
- **삽입**: 트라이에 없는 문자에 대해서만 새 노드를 생성하면 됩니다.
- **시간 복잡도**: 검색과 삽입 연산은 문자열 길이 `L`에 대해 `O(L)` 시간이 걸립니다.
- **메모리**: 문자열 집합에 고유 문자가 많으면 각 문자를 개별 노드로 저장해야 하므로 비효율적일 수 있습니다.

## 우선순위 큐

- **우선순위 큐**: 각 요소가 우선순위를 가지는 추상 자료형입니다.
- **큐와 스택**: 큐와 스택은 삽입 순서만 고려하지만, 우선순위 큐는 요소의 우선순위를 고려합니다. 표준 큐는 FIFO(선입선출), 스택은 LIFO(후입선출)를 따릅니다.
- **제거 순서**: 보통 가장 높은 우선순위 요소가 먼저 제거되지만, 일부 구현은 가장 낮은 우선순위 요소를 먼저 제거할 수도 있습니다.
- **동점 처리**: 같은 우선순위 요소를 삽입 순서대로 제거하려면 고유 카운터를 포함해 동점을 깨뜨릴 수 있습니다.
- **애플리케이션**: 두 위치 간 최단 경로 찾기, 운영체제 작업 스케줄링, 교통 시뮬레이션, 데이터 압축, 네트워크 관리 등에 사용됩니다.

## 힙

힙은 힙 속성이라는 매우 특정한 속성을 가진 특수한 트리 기반 자료 구조입니다.

힙 속성은 부모 노드와 자식 노드 간의 관계를 결정합니다. 힙에는 두 가지 유형이 있습니다:

- **최대 힙**: 각 부모 노드 값이 자식 노드 값보다 크거나 같으며, 가장 큰 요소가 루트에 있습니다.

- **최소 힙**: 각 부모 노드 값이 자식 노드 값보다 작거나 같으며, 가장 작은 요소가 루트에 있습니다.


JavaScript에는 내장 힙 모듈이 없지만, 배열을 사용해 최소 힙을 구현할 수 있습니다.

- **배열 저장**: 힙은 보통 부모와 자식 노드에 효율적으로 접근하기 위해 배열로 구현됩니다. 힙이 완전 이진 트리 구조를 유지하면, 배열 인덱스를 기반으로 간단한 산술 연산만으로 요소 위치를 찾을 수 있습니다.
- **인덱스**: 인덱스 `i`에 있는 노드의 부모는 `Math.floor((i - 1) / 2)`에, 왼쪽 자식은 `2 * i + 1`에, 오른쪽 자식은 `2 * i + 2`에 있습니다.
- **Peek**: 힙 속성에 따라 최소값 또는 최대값을 제거하지 않고 얻습니다.
- **Push**: 힙 속성을 유지하기 위해 적절한 위치에 요소를 추가합니다. 새 요소는 배열 끝에 추가된 후 부모와 자리를 바꾸며 위로 올라갑니다(버블업).
- **Pop**: 가장 우선순위가 높은 요소(여기서는 가장 작은 값)를 제거합니다. 배열의 마지막 요소가 루트를 대체하고, 더 작은 자식과 자리를 바꾸며 아래로 내려갑니다(버블다운).
- **PushPop**: 두 연산을 하나로 합친 호출로, 특히 힙이 클 때 각각 호출하는 것보다 효율적이며 재정렬 작업을 한 번만 수행합니다.
- **Heapify**: 기존 배열을 힙으로 변환합니다.
- **비교 콜백**: JavaScript에서 배열은 자동으로 요소별 비교를 하지 않으므로, 우선순위를 먼저 비교하는 비교 함수를 힙에 전달합니다. 예: `[priority, element]`로 저장된 항목에 대해 `new MinHeap((a, b) => a[0] - b[0])`. 낮은 값이 더 높은 우선순위를 나타냅니다.
- **안정적 동점 처리**: 각 항목의 두 번째 요소로 증가하는 삽입 카운터를 포함합니다: `[priority, counter, element]`. 우선순위를 먼저 비교하고, 우선순위가 같으면 카운터를 비교합니다: `new MinHeap((a, b) => (a[0] - b[0]) || (a[1] - b[1]))`.
- **시간 복잡도**: 최소 또는 최대값 삽입과 추출은 `O(log n)`, peek는 `O(1)`, heapify는 `O(n)`, 임의 요소 검색 또는 삭제는 `O(n)`입니다.
- **공간 복잡도**: 힙에 포함된 요소 수 `n`에 대해 `O(n)`입니다.
