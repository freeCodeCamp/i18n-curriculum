# --description--

En una lección anterior sobre números y operaciones matemáticas, usaste una especificación de formato como `.2f` en una f-string para controlar cuántos lugares decimales muestra un número.

Las especificaciones de formato también pueden controlar cuánto espacio ocupa un valor y dónde se sitúa. Esto es útil cuando quieres que la salida se alinee en columnas ordenadas.

## Establecer un ancho mínimo y alineación

Un número después de los dos puntos establece el ancho mínimo del campo, que es la cantidad de caracteres que debe ocupar el valor. Si el valor es más corto, Python agrega espacios hasta alcanzar ese ancho. Aquí tienes un ejemplo:

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

Usar símbolos específicos antes del ancho controla dónde se sitúa el valor dentro del campo. Estos son esos símbolos específicos:

- Menor que (`<`) alinea el valor a la izquierda
- Mayor que (`>`) alinea el valor a la derecha
- Circunflejo (`^`) centra el valor.

Aquí están esos tres símbolos en acción:

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

`'Tea'` contiene tres caracteres, así que Python agrega cinco espacios para alcanzar un ancho de `8`.

- Con `<`, los espacios van después del valor
- Con `>`, los espacios van antes
- Con `^`, los espacios se dividen entre ambos lados para centrar el texto.

Si el espacio no se puede dividir de manera uniforme, el espacio extra va a la derecha:

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

Si omites el símbolo de alineación, las cadenas se alinean a la izquierda por defecto, mientras que los números se alinean a la derecha:

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## Usar un carácter de relleno

Por defecto, Python rellena con espacios. Para usar un carácter diferente para el relleno, inserta el carácter justo antes del símbolo de alineación:

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

En `*^9`, el `*` es el carácter de relleno, `^` centra el valor y `9` es el ancho mínimo. Ten en cuenta que solo puedes usar un carácter de relleno junto con un símbolo de alineación.

## Combinar ancho y precisión

Puedes combinar alineación y ancho con la precisión que aprendiste en la lección anterior, todo en una sola especificación de formato:

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

La especificación de formato en el ejemplo anterior significa: alinear a la derecha, usar un ancho mínimo de `7` y mostrar dos decimales. Python formatea primero el número como `4.50`, que tiene cuatro caracteres, y luego agrega tres espacios delante para llenar el ancho de `7`.

## Construir una fila de sentencias

Puedes poner una etiqueta y una cantidad juntas en una línea. Si usas la misma especificación de formato para cada fila, las columnas se alinean:

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

Cada etiqueta se alinea a la izquierda en un campo de `12` caracteres y se rellena con puntos, mientras que cada cantidad se alinea a la derecha en un campo de `8` caracteres, para que los puntos decimales se alineen.

## El ancho es un mínimo, no un máximo

El ancho solo agrega relleno. Nunca corta un valor. Si el valor es más largo que el ancho especificado, se muestra completo:

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

Lo mismo aplica para números. En el ejemplo a continuación, la cantidad formateada necesita ocho caracteres, así que ignora el ancho especificado de `7`:

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

En `:7.2f`, el `7` es un ancho mínimo, no un límite para la longitud de la cantidad. Python nunca corta dígitos para hacer que un número quepa.

Por eso debes elegir anchos lo suficientemente grandes para los valores que esperas, o las columnas no se alinearán.

Si quieres limitar la longitud de una cadena, agrega una precisión a la especificación de formato. Para cadenas, la precisión establece el número máximo de caracteres a mostrar:

```py
label = 'Long description'

print(f'|{label:.8}|') # |Long des|
print(f'|{label:<12.8}|') # |Long des    |
```

En `<12.8`:

- `<` alinea el valor a la izquierda
- `12` es el ancho mínimo
- `.8` es el número máximo de caracteres.

Python recorta la cadena a ocho caracteres primero, luego la rellena hasta un ancho de doce.

Ten en cuenta que la precisión significa algo diferente para cadenas que para números. Con `.2f`, el `.2` establece el número de decimales. Con una cadena, `.8` establece el número máximo de caracteres.
