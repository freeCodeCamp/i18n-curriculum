# --description--

Beachten Sie, dass `each_pays` als `62.1` statt `62.10` ausgegeben wurde. Das liegt daran, dass `round()` einen float zurückgibt und Python für floats keine nachgestellten Nullen ausgibt.

Hier hilft die Zahlenformatierung. `round()` liefert Ihnen eine Zahl, mit der Sie weiterrechnen können, und der Formatbezeichner `:.2f` steuert, wie diese Zahl angezeigt wird.

running_total = 0
