# --description--

正規表現には、バックスラッシュ（`\`）に続く文字で構成される特殊シーケンスが含まれることがあります。これらのシーケンスには特別な意味があります。ここにいくつかの一般的なものを紹介します：

- `\d` は `0` から `9` までの10進数の桁にマッチします。

- `\w` は文字、数字、アンダースコア（`_`）を含む任意の単語文字にマッチします。

- `\s` はスペース、タブ、改行などの任意の空白文字にマッチします。

- `\D`、`\W`、および `\S` はそれぞれの小文字バージョンの逆にマッチします。例えば、`\D` は数字以外の任意の文字にマッチします。

ただし注意点があります。Pythonの文字列もバックスラッシュを使って、`\n`（改行）や `\t`（タブ）などのエスケープシーケンスを書きます：

```python
print('Tab:\tdone') # Tab:    done
```

つまり、通常のPython文字列内のバックスラッシュは、`re` モジュールが見る前にPythonによって解釈される場合があります。続く文字によっては、パターンが変わったりPythonが警告を表示したりすることがあります。

これを避けるために、raw文字列を使うことができます。raw文字列は、開きの引用符の前に `r`（または `R`）を付けて作成します。raw文字列はバックスラッシュをエスケープシーケンスではなく文字通りの文字として扱います：

```python
print(r'Tab:\tdone') # Tab:\tdone
```

このため、正規表現のパターンは常にraw文字列で書くことが良い習慣です：

```python
import re

room = 'Room 42B'
print(re.search(r'\d', room))
# <re.Match object; span=(5, 6), match='4'>
```

`re.search` は最初に見つけたマッチを返すことに注意してください。ここでは `\d` が1つの数字にマッチするので、マッチは `4` のみです。1つ以上の数字にマッチさせたい場合は量指定子を使うと良いです。

量指定子は、直前の文字やシーケンスが何回繰り返されるかを指定します。`+` 量指定子は直前の文字を1回以上繰り返すものにマッチします。

つまり、`\d` は1つの数字にマッチしますが、`\d+` は連続する1つ以上の数字にマッチします：

```python
import re

room = 'Room 42B'
print(re.search(r'\d+', room))
# <re.Match object; span=(5, 7), match='42'>
```

他の一般的な量指定子は次の通りです：

- `*` は直前の文字を0回以上繰り返すものにマッチします。

- `?` は直前の文字を0回か1回繰り返すものにマッチし、オプションにします。

- `{n}` は直前の文字をちょうど `n` 回繰り返すものにマッチします。

- `{n,m}` は直前の文字を `n` 回から `m` 回繰り返すものにマッチします。

```python
import re

print(re.search(r'go*al', 'What a goooal!'))
# <re.Match object; span=(7, 13), match='goooal'>

print(re.search(r'colou?r', 'My favorite color is blue'))
# <re.Match object; span=(12, 17), match='color'>

print(re.search(r'\d{4}', 'Room 42, built in 1987'))
# <re.Match object; span=(18, 22), match='1987'>
```

リテラル文字、特殊シーケンス、量指定子を同じパターンで組み合わせることができます。例えば、パターン `r'\d+ items'` は1つ以上の数字に続いてスペースと単語 `items` にマッチします。また、`re.IGNORECASE` フラグを使えば文字が小文字でも大文字でもマッチします：

```python
import re

cart = 'You have 3 ITEMS in your cart.'
print(re.search(r'\d+ items', cart, re.IGNORECASE))
# <re.Match object; span=(9, 16), match='3 ITEMS'>
```
