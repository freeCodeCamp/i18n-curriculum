# --description--

アルゴリズムの流れをこの初期段階で理解するために、動作をテストする必要があります。

ループはまだ `low` や `high` を更新していません。中央の値がターゲットと一致しない場合、同じ値を無限にチェックし続けます。それを避けるために、一度チェックしたらループを停止する必要があります。

`if` 文の直後に `break` キーワードを使って `while` ループから抜けてください。そして、`while` ループの後に、値が見つからなかったことを示すために空のリストを返してください。

def binary_search(search_list, value):
    path_to_target = []
    low = 0
    high = len(search_list) - 1
    
    while low <= high:
        mid = (low + high) // 2
        value_at_middle = search_list[mid]
        path_to_target.append(value_at_middle)
        
        if value == value_at_middle:
            return path_to_target
