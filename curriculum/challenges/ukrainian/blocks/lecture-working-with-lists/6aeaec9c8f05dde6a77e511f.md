# --description--

Ви дізналися, що імена посилаються на об’єкти, а списки є змінними. Давайте подивимося, що відбувається, коли більше одного імені посилаються на один і той самий список.

## Порівняння рівних списків і псевдонімів

Два списки можуть містити однакові значення, не будучи одним і тим самим об’єктом. Нагадаємо, що `==` перевіряє рівність, а `is` — ідентичність:

```py
items = ['milk']
equal_items = ['milk']
alias = items

print(items == equal_items) # True
print(items is equal_items) # False
print(items is alias) # True
```

Кожен вираз `['milk']` створює окремий список. Однак `alias = items` не створює копію. Він призначає інше ім’я для існуючого списку. Це інше ім’я ми називаємо псевдонімом.

Зміна списку через будь-яке з імен буде видна через інше:

```py
items = ['milk']
equal_items = ['milk']
alias = items

alias.append('eggs')
print(items) # ['milk', 'eggs']
print(alias) # ['milk', 'eggs']
print(equal_items) # ['milk']
```

Окремий список `equal_items` залишається незмінним.

## Мутація списку через параметр функції

Аргументи передаються через присвоєння. Параметр — це локальне ім’я, спочатку пов’язане з об’єктом, який передав викликач. Python не копіює цей об’єкт автоматично.

Тут параметр `items` і змінна викликача `groceries` посилаються на один і той самий список:

```py
def add_item(items):
    items.append('eggs')

groceries = ['milk']
add_item(groceries)
print(groceries) # ['milk', 'eggs']
```

Виклик `append()` мутує спільний список. Функція не має інструкції `return`, тому повертає `None`, але зміни в списку все одно видно викликачу.

Перепризначення локального параметра має інший ефект:

```py
def replace_items(items):
    items = ['bread']

groceries = ['milk']
replace_items(groceries)
print(groceries) # ['milk']
```

Присвоєння змінює локальне ім’я `items`, щоб воно посилалося на новий список. Воно не змінює оригінальний список і не перепризначає змінну викликача `groceries`.

## Повернення нового списку

Функція може створити і повернути новий список замість мутації переданого. Оператор `+` конкатенує списки, створюючи новий зовнішній список, що містить їхні елементи:

```py
def with_extra_item(items):
    return items + ['eggs']

groceries = ['milk']
alias = groceries

groceries = with_extra_item(groceries)
print(groceries) # ['milk', 'eggs']
print(alias) # ['milk']
print(groceries is alias) # False
```

Викликач призначає повернений список змінній `groceries`. Ім’я `alias` все ще посилається на оригінальний список. Виклик функції без присвоєння або іншого використання поверненого значення залишить `groceries` посилатися на той самий оригінальний список.

Конкатенація створює новий зовнішній список, але не копіює вкладені об’єкти. Якщо елемент сам є списком, новий зовнішній список містить референс на той самий внутрішній список.

## Порівняння `+` і `+=` для списків

Для вбудованих списків `items = items + [...]` створює новий список і перепризначає `items`. Натомість `items += [...]` розширює існуючий список на місці:

```py
def add_with_plus(items):
    items = items + ['eggs']

def add_with_plus_equals(items):
    items += ['eggs']

groceries = ['milk']
alias = groceries

add_with_plus(groceries)
print(groceries) # ['milk']
print(alias) # ['milk']

add_with_plus_equals(groceries)
print(groceries) # ['milk', 'eggs']
print(alias) # ['milk', 'eggs']
```

У першій функції лише локальне ім’я посилається на новий список. У другій — спільний список мутує, і локальне ім’я все ще посилається на нього. Ось чому `+=` для списків не є взаємозамінним з додаванням із наступним присвоєнням, коли існують інші референси на список.

## Використання списку як аргументу за замовчуванням

Аргумент за замовчуванням надає значення, коли викликач пропускає цей аргумент. Якщо ви використовуєте порожній список за замовчуванням, Python створює цей список один раз, коли функція визначається. Виклики, які пропускають аргумент, повторно використовують той самий список:

```py
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item('milk')) # ['milk']
print(add_item('eggs')) # ['milk', 'eggs']
```

Другий виклик отримує список, змінений першим викликом. Хоча кожен виклик має своє локальне ім’я параметра, це ім’я посилається на той самий об’єкт за замовчуванням. Список не стає порожнім знову між викликами.

Якщо кожен виклик має починатися з нового списку, коли список не передається, використовуйте `None` як значення за замовчуванням і створюйте список всередині функції:

```py
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item('milk')) # ['milk']
print(add_item('eggs')) # ['eggs']
```

Тут `items = []` виконується щоразу, коли аргумент пропущено або явно передано як `None`, створюючи новий список для цього виклику.

Ви все ще можете передати існуючий список для мутації:

```py
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

groceries = []
add_item('milk', groceries)
add_item('eggs', groceries)
print(groceries) # ['milk', 'eggs']
```

Перевірка `items is None` відрізняє відсутній список від порожнього, переданого викликачем. Використання `if not items` також співпадало б із порожнім списком і замінювало його новим, тому порожній список викликача не отримав би доданий елемент.

## Повторення референсів на вкладені списки

Ви бачили, як повторення списку може створити список на кшталт `[0] * 3`. Повторення створює новий зовнішній список, але повторює референси на його елементи, а не копіює ці елементи.

Це важливо, коли елемент є змінним:

```py
rows = [[]] * 3
print(rows) # [[], [], []]
print(rows[0] is rows[1]) # True

rows[0].append('hello')
print(rows) # [['hello'], ['hello'], ['hello']]
```

Вираз `[[]]` створює один внутрішній список. Повторення розміщує референси на той самий внутрішній список у всіх трьох позиціях. Мутація через `rows[0]` видна в кожній позиції.

З `numbers = [0] * 3` присвоєння `numbers[0] = 1` замінює один референс елемента; воно не мутує незмінне ціле число `0`. Ось чому інші позиції залишаються `0`.

Якщо потрібні окремі внутрішні списки, створюйте кожен окремо:

```py
rows = [[], [], []]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

Пізніше в цьому модулі ви дізнаєтеся, як генератори списків можуть створювати потрібну кількість окремих внутрішніх списків.
