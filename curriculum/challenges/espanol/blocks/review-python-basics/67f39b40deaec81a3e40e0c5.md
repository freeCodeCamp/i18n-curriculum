## ¿Qué es Python?

- **Python**: Python es un lenguaje de programación de propósito general conocido por su simplicidad y facilidad de uso.
- **Casos de uso comunes**: Python se usa en ciencia de datos, aprendizaje automático, desarrollo web, ciberseguridad, sistemas embebidos e IoT, scripting, automatización y microcomputadoras como Raspberry Pi y placas compatibles con MicroPython.

## Variables

- **Declarar variables**: Para declarar una variable, comienzas con el nombre de la variable seguido del operador de asignación (`=`) y luego el valor. Esto puede ser un número, cadena, booleano, etc. Aquí algunos ejemplos:

```py
name = 'John Doe'
age = 25
```

- **Convenciones para nombrar variables**: Estas son las convenciones que debes usar para nombrar variables:

  - Los nombres de variables solo pueden comenzar con una letra o un guion bajo (`_`), no con un número.
  - Los nombres de variables pueden contener letras (`a-z`, `A-Z`), dígitos (`0-9`) y guiones bajos (`_`).
  - Los nombres de variables distinguen mayúsculas y minúsculas: `age`, `Age` y `AGE` se consideran únicos.
  - Los nombres de variables no pueden ser palabras clave reservadas de Python como `if`, `class` o `def`.
  - Los nombres de variables con varias palabras usan guiones bajos, como en `snake_case`.
  - Los nombres de variables deben describir su propósito, como en `user_age`.
  - Se deben evitar nombres de variables de una sola letra cuando no comunican significado.

## Comentarios

- **Comentarios de una línea**: Este tipo de comentario se debe usar para notas cortas en tu código.

```py
# This is a single line comment
```

- **Comentarios multilínea**: Puedes usar un `#` al principio de cada línea para crear comentarios que abarquen varias líneas.

```py
# This is a multi-line comment.
# Here is some code commented out.
#
# name = 'John Doe'
# age = 25
```

## Imprimir

- **Función `print()`**: Para imprimir datos en el terminal, puedes usar la función `print()` así:

```py
print('Hello world!') # Hello world!
```

Puedes pasar múltiples argumentos a `print()` separándolos con comas. Por defecto, `print()` inserta un espacio entre los valores mostrados:

```py
print('Hello', 'world!') # Hello world!
```

## Tipos de datos comunes en Python

- **Tipado dinámico**: Python es un lenguaje con tipado dinámico, lo que significa que no necesitas declarar el tipo de dato de una variable. Python determina el tipo a partir del valor asignado a la variable.

- **Entero**: Un número entero sin decimales:

```py
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- **Float**: Un número con decimales:

```py
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- **Cadena**: Una secuencia de caracteres entre comillas:

```py
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- **Booleano**: Un valor que representa `True` o `False`:

```py
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python tiene otros tipos de datos. Aprenderás cada uno cuando los necesites por primera vez.

- **Función `type()`**: Para ver el tipo de una variable, puedes usar la función `type()` así:

```py
greeting = 'Hello there!'
age = 21

print(type(greeting)) # <class 'str'>
print(type(age)) # <class 'int'>
```

- **Función `isinstance()`**: Se usa para verificar si una variable coincide con un tipo de dato específico:

```py
greeting = 'Hello world'
name = 'John Doe'

print(isinstance(greeting, str)) # True
print(isinstance(name, int)) # False
```

Para verificar contra más de un tipo, pon los tipos entre paréntesis, separados por comas, y pásalos como segundo argumento. El resultado es `True` si el valor es una instancia de cualquiera de los tipos listados:

```py
account_balance = 12
print(isinstance(account_balance, (int, float))) # True
```

## Trabajar con cadenas

- **Cadenas**: Las cadenas son secuencias de caracteres. En Python, puedes usar comillas simples o dobles. Elige un estilo y úsalo de forma consistente:

```py
developer = 'Jessica'
city = "Los Angeles"
```

- **Cadenas multilínea**: Las comillas triples simples o triples dobles permiten que una cadena abarque varias líneas:

```py
message = """Hello
world!"""
print(message)
# Hello
# world!
```

- **Comillas dentro de cadenas**: Puedes usar el tipo de comilla opuesto alrededor de una cadena para evitar escapar sus marcas de comillas:

```py
msg = "It's a sunny day"
quote = 'She said, "Hello!"'
```

- **Escapar cadenas**: Puedes usar una barra invertida (`\`) si tu cadena contiene comillas así:

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **Secuencias de escape**: Una barra invertida combinada con otro carácter puede representar un carácter especial. Por ejemplo, `\n` representa un salto de línea, `\t` representa una tabulación y `\\` representa una sola barra invertida:

```py
print('Hello\nworld')
# Hello
# world

print('Name:\tAlice')  # Name:   Alice
print('C:\\Users\\Alice')  # C:\Users\Alice
```

- **Operador `in`**: Devuelve un booleano que especifica si el carácter o caracteres existen en la cadena o no:

```py
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

- **Obtener la longitud de una cadena**: La función `len()` devuelve el número de caracteres en una cadena:

```py
developer = 'Jessica'

print(len(developer)) # 7
```

- **Acceder a caracteres en cadenas**: Puedes acceder a caracteres de cadenas usando notación de corchetes así:

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **Reasignación e inmutabilidad**: Las cadenas son inmutables, lo que significa que no puedes cambiarlas después de haberlas creado. Reasignar una variable hace que se refiera a un valor diferente. No modifica la cadena original:

```py
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello
```

No está permitido modificar directamente una cadena:

```py
greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```

Los enteros, floats y booleanos también son inmutables.

- **Concatenación de cadenas**: Para concatenar cadenas, puedes usar el operador `+` así:

```py
developer = 'Jessica'
print('My name is ' + developer + '.') # My name is Jessica.
```

- **Repetición de cadenas**: El operador `*` repite una cadena un número especificado de veces:

```py
print('ha' * 3) # hahaha
```

- **Concatenar cadenas con números**: Concatenar una cadena y un número genera un `TypeError`:

```py
'Age: ' + 26 # TypeError: can only concatenate str (not "int") to str
```

La función `str()` convierte el número en una cadena para que pueda ser concatenada:

```py
print('Age: ' + str(26)) # Age: 26
```

Otra forma de concatenar cadenas es usando el operador `+=`. Este se usa para realizar concatenación y asignación en un solo paso así:

```py
greeting = 'My name is '
developer = 'Jessica.'

greeting += developer
print(greeting) # My name is Jessica.
```

El operador `*=` repite una cadena y asigna el resultado de nuevo a la variable:

```py
sound = 'ha'
sound *= 3
print(sound) # hahaha
```

Tanto `+=` como `*=` asignan una nueva cadena a la variable sin modificar la cadena original.

- **`f-strings`**: Esto es la abreviatura de literales de cadena formateada. Permite manejar interpolación y también hacer concatenación con una sintaxis compacta y legible:

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

Los campos de reemplazo en f-strings pueden contener expresiones. Python evalúa la expresión e inserta su valor en la cadena:

```py
num1 = 5
num2 = 10
print(f'The sum is {num1 + num2}') # The sum is 15
```

- **Rebanado de cadenas**: Esto es cuando puedes extraer porciones de una cadena. Aquí está la sintaxis básica:

```py
str[start:stop:step]
```

El índice `start` especifica dónde comienza la extracción. El índice `stop` no es inclusivo, por lo que el carácter en ese índice no se incluye. El `step` especifica el intervalo entre índices seleccionados y por defecto es `1`. Con un `step` positivo, un `start` omitido comienza al inicio de la cadena y un `stop` omitido termina al final. `[:]` extrae toda la cadena. `[::-1]` invierte la cadena avanzando hacia atrás desde el último carácter hasta el primero. El slicing no modifica la cadena original.

```py
message = 'Python is fun!'

print(message[0:6])  # Python
print(message[:6])  # Python
print(message[7:])  # is fun!
print(message[::2])  # Pto sfn
print(message[:])  # Python is fun!
print(message[::-1])  # !nuf si nohtyP
```

## Métodos comunes de cadenas

- **Métodos**: Un método es una función que llamas sobre un valor. Para llamar a un método de cadena, escribe la cadena o su nombre de variable seguido de un punto y la llamada al método.

- **`str.upper()`**: Esto devuelve una nueva cadena con todos los caracteres convertidos a mayúsculas:

```py
developer = 'Jessica'

print(developer.upper()) # JESSICA
```

- **`str.lower()`**: Esto devuelve una nueva cadena con todos los caracteres convertidos a minúsculas:

```py
developer = 'Jessica'

print(developer.lower()) # jessica
```

- **`str.strip()`**: Esto devuelve una copia de la cadena con los caracteres especificados al inicio y al final eliminados (si no se pasa un argumento al método, elimina los espacios en blanco al inicio y al final).

```py
greeting = '  hello world  '

trimmed_my_str = greeting.strip()
print(trimmed_my_str)  # hello world
```

- **`replace()`**: Devuelve una nueva cadena con todas las ocurrencias de la cadena antigua reemplazadas por una nueva.

```py
greeting = 'hello world'

replaced_my_str = greeting.replace('hello', 'hi')
print(replaced_my_str)  # hi world
```

- **`split()`**: Se usa para dividir una cadena en una lista usando un separador especificado. Un separador es una cadena que indica dónde debe ocurrir la división. Si no se especifica separador, `split()` divide en espacios en blanco.

```py
dashed_name = 'example-dashed-name'

split_words = dashed_name.split('-')
print(split_words)  # ['example', 'dashed', 'name']
```

- **`join()`**: Se usa para unir una colección de cadenas en una sola cadena con un separador.

```py
example_list = ['example', 'dashed', 'name']

joined_str = ' '.join(example_list)
print(joined_str)  # example dashed name
```

- **`str.startswith(prefix)`**: Esto devuelve un booleano que indica si una cadena comienza con el prefijo especificado:

```py
developer = 'Naomi'

result = developer.startswith('N')
print(result)  # True
```

- **`str.endswith(suffix)`**: Esto devuelve un booleano que indica si una cadena termina con el sufijo especificado:

```py
developer = 'Naomi'

result = developer.endswith('N')
print(result)  # False
```

- **`str.find()`**: Devuelve el índice de la primera aparición de una subcadena. Si no se encuentra, devuelve `-1`:

```py
developer = 'Naomi'

result = developer.find('N')
print(result)  # 0

city = 'Los Angeles'
print(city.find('New')) # -1
```

- **`str.count(substring)`**: Esto cuenta cuántas veces aparece una subcadena en una cadena sin solapamientos. Una vez que se encuentra una coincidencia, la búsqueda continúa después del final de esa coincidencia:

```py
city = 'Los Angeles'
print(city.count('e')) # 2

# Matches do not overlap, so this is 2, not 3
print('aaaa'.count('aa')) # 2
```

- **`str.capitalize()`**: Esto devuelve una nueva cadena con el primer carácter en mayúscula y los demás en minúsculas:

```py
dessert = 'chocolate cake'
print(dessert.capitalize()) # Chocolate cake
```

- **`str.isupper()`**: Devuelve `True` si la cadena contiene al menos un carácter con distinción de mayúsculas y todas las letras con distinción están en mayúsculas. De lo contrario, devuelve `False`:

```py
dessert = 'chocolate cake'
print(dessert.isupper()) # False
```

- **`str.islower()`**: Devuelve `True` si la cadena contiene al menos un carácter con distinción de mayúsculas y todas las letras con distinción están en minúsculas. De lo contrario, devuelve `False`:

```py
dessert = 'chocolate cake'
print(dessert.islower()) # True
```

- **`str.title()`**: Esto devuelve una nueva cadena con la primera letra de cada palabra en mayúscula y las letras restantes en minúscula:

```py
city = 'lOS aNGELES'
print(city.title()) # Los Angeles
```

## Más operaciones con cadenas

```py
employee_code = 'DEV-2026-JD-001'
print(employee_code[-3:]) # 001
```

```py
print(name.strip().title()) # Jane Doe
```

## Operaciones comunes usadas con enteros y floats

- **Operaciones matemáticas básicas**: En Python, puedes hacer operaciones matemáticas básicas con enteros y floats, incluyendo suma, resta, multiplicación y división:

```py
int_1 = 56
int_2 = 12
float_1 = 5.4
float_2 = 12.0

# Addition

print('Integer Addition:', int_1 + int_2) # Integer Addition: 68
print('Float Addition:', float_1 + float_2) # Float Addition: 17.4

# Subtraction

print('Int Subtraction:', int_1 - int_2) # Int Subtraction: 44
print('Float Subtraction:',  float_2 - float_1) # Float Subtraction: 6.6

# Multiplication

print('Int Multiplication:', int_1 * int_2) # Int Multiplication: 672
print('Float Multiplication:', float_2 * float_1) # Float Multiplication: 64.80000000000001

# Division

print('Division:', int_1 / int_2) # Division: 4.666666666666667
print('Float Division:', float_2 / float_1) # Float Division: 2.222222222222222
```

Cuando sumas un float y un entero, el resultado se convierte en float así:

```py
int_1 = 56
float_1 = 5.4

print(int_1 + float_1) # 61.4
```

- **Operador módulo (`%`)**: Devuelve el resto cuando un número se divide por otro:

```py
int_1 = 56
int_2 = 12

print(int_1 % int_2) # 8
```

- **División entera (`//`)**: Este operador se usa para dividir dos números y redondear hacia abajo al entero más cercano:

```py
int_1 = 56
int_2 = 12

print(int_1 // int_2) # 4
```

- **Operador de exponenciación (`**`)**: Este operador se usa para elevar un número a la potencia de otro:

```py
int_1 = 4
int_2 = 2

print(int_1 ** int_2) # 16
```

- **Aproximación de punto flotante**: Algunas fracciones decimales no pueden representarse exactamente en binario, por lo que se almacenan como aproximaciones finitas. Esto puede causar pequeños errores de redondeo, como el resultado de multiplicación `64.80000000000001` mostrado arriba.

```py
print(0.1 + 0.2) # 0.30000000000000004
```

- **Función `float()`**: Puedes usar esta función para convertir un entero o una cadena decimal válida a un float, o para crear un valor float especial que representa infinito positivo, que es mayor que cualquier entero o float finito:

```py
num = 4

print(float(num)) # 4.0
print(float('7.8')) # 7.8
print(float('inf')) # inf
```

- **Función `int()`**: Puedes usar esta función para convertir un float a entero.

```py
num = 4.0

print(int(num)) # 4
```

- **Función `round()`**: Con un argumento, redondea un número al entero más cercano. Pasa un segundo argumento para especificar el número de decimales:

```py
num_1 = 3.4
num_2 = 7.7

print(round(num_1)) # 3
print(round(num_2)) # 8
print(round(3.14159, 2)) # 3.14
```

- **Función `abs()`**: Se usa para devolver el valor absoluto de un número:

```py
num = -13

print(abs(num)) # 13
```

- **Función `pow()`**: Eleva un número a la potencia de otro. Con argumentos enteros, puedes pasar un tercer argumento distinto de cero para calcular el resultado módulo ese valor:

```py
result = pow(2, 3)
print(result)  # 8
print(pow(2, 3, 5)) # 3
```

## Trabajar con sentencias `if`, `elif` y `else`

- **Bloques de código e indentación**: Python usa la indentación para agrupar sentencias en un bloque, como el cuerpo de una función o condicional. Las sentencias en el mismo bloque deben usar el mismo nivel de indentación. La convención es usar cuatro espacios por nivel.

- **Sentencia `pass`**: `pass` no hace nada. Úsalo como marcador de posición donde Python requiere una sentencia, como en un cuerpo condicional vacío:

```py
age = 18
if age >= 18:
    pass
```

- **Sentencias `if`**: Una sentencia `if` ejecuta su cuerpo cuando Python considera que su condición es verdadera.

```py
age = 18

if age >= 18:
    print('You are an adult') # You are an adult
```

- **Cláusula `else`**: Una cláusula `else` ejecuta su cuerpo cuando Python considera que todas las condiciones anteriores en la misma cadena `if...elif...else` son falsas.

```py
age = 12

if age >= 18:
    print('You are an adult')
else:
    print('You are not an adult yet') # You are not an adult yet
```

- **Cláusula `elif`**: Una cláusula `elif` prueba otra condición cuando Python considera que todas las condiciones anteriores en la misma cadena son falsas. Ejecuta su cuerpo si Python considera que su propia condición es verdadera.

```py
age = 16

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')  # You are a teenager
```

También puedes usar sentencias `if` anidadas así:

```py
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

## Valores truthy y falsy

- **Verdad lógica**: En Python, cada valor tiene un valor booleano inherente, o un sentido integrado de si debe tratarse como `True` o `False` en un contexto lógico. Muchos valores se consideran truthy, es decir, evalúan a `True` en un contexto lógico. Otros son falsy, lo que significa que evalúan a `False`. Aquí hay algunos ejemplos de valores falsy:

```md
False
None
Integer 0
Float 0.0
Empty strings ''
```

Otros valores como números distintos de cero y cadenas no vacías son truthy.

## Trabajar con la función `bool()`

- **Función `bool()`**: Si quieres verificar si un valor es truthy o falsy, puedes usar la función integrada `bool()`. Convierte explícitamente un valor a su equivalente booleano y devuelve `True` para valores truthy y `False` para valores falsy. Aquí algunos ejemplos:

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

## Operadores booleanos y evaluación corta

- **Operadores booleanos**: Son operadores especiales que te permiten combinar múltiples expresiones para crear lógica de decisión más compleja en tu código. Hay tres operadores booleanos en Python: `and`, `or` y `not`.
- **Operador `and`**: Este operador toma dos operandos y devuelve el primero si es falsy; de lo contrario, devuelve el segundo. Ambos operandos deben ser truthy para que la expresión resulte en un valor truthy.

```py
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

También puedes usar el operador `and` en condicionales así:

```py
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

- **Operador `or`**: Este operador devuelve el primer operando si es un valor truthy; de lo contrario, devuelve el segundo operando. Una expresión con `or` resulta en un valor truthy si al menos un operando es truthy. Aquí tienes un ejemplo:

```py
age = 19
is_employed = False

print(age or is_employed) # 19
```

Al igual que con el operador `and`, puedes usar el operador `or` en condicionales así:

```py
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

- **Cortocircuito**: Los operadores `and` y `or` se conocen como operadores de cortocircuito. Cortocircuito significa que Python evalúa los valores de izquierda a derecha y se detiene tan pronto como determina el resultado final.
- **Operador `not`**: Este operador toma un solo operando e invierte su valor booleano. Convierte valores truthy en `False` y valores falsy en `True`. A diferencia de los operadores anteriores, `not` siempre devuelve `True` o `False`. Aquí algunos ejemplos:

```py
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

Aquí un ejemplo del operador `not` en un condicional:

```py
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

## Operadores de identidad

- **Identidad e igualdad**: Las variables se refieren a objetos. El operador `is` verifica si dos operandos se refieren al mismo objeto, mientras que `is not` verifica si se refieren a objetos diferentes. Los operadores `==` y `!=` comparan valores en su lugar. Usa operadores de igualdad cuando compares valores numéricos o cadenas.
- **`None` y `NoneType`**: `None` representa la ausencia de un valor. Es el único valor del tipo de dato `NoneType`.
- **Singletons**: `None`, `True` y `False` son cada uno singletons, lo que significa que hay exactamente un objeto para cada uno. Puedes verificar estos objetos con operadores de identidad.
- **Verificar `None`**: Usa `is None` para verificar un valor ausente y `is not None` para verificar un valor presente. Tanto `None` como `False` son falsy, pero son objetos diferentes:

```py
response = False

print(response is None) # False
print(response is not None) # True
print(response is True) # False
print(response is False) # True
```

- **Identidad y verdad lógica**: Si `response` puede ser `True`, `False` o `None`, `response is None` distingue una respuesta ausente de una negativa. Usar `not response` trataría igual a `False` y `None`. Para banderas booleanas ordinarias, usa `if is_ready` o `if not is_ready`. Usa `is True` o `is False` cuando necesites distinguir específicamente un objeto booleano de otros posibles valores.

## Precedencia de operadores booleanos

- **Precedencia de operadores y paréntesis**: Cuando `and` y `or` aparecen en la misma expresión, `and` tiene mayor precedencia que `or`. Esto significa que `and` agrupa primero sus operandos, así que `True or False and False` se agrupa como `True or (False and False)`:

```py
print(True or False and False) # True
```

El operando izquierdo de `or` es `True`, por lo que el cortocircuito significa que `False and False` nunca se evalúa, y el resultado es `True`.

Puedes usar paréntesis para cambiar la agrupación. Aquí, `True or False` se agrupa y evalúa como `True`, y luego `True and False` se evalúa como `False`:

```py
print((True or False) and False) # False
```

## Funciones integradas comunes

- **Función `input()`**: Se usa para solicitar al usuario una entrada:

```py
name = input('What is your name?') # User types 'Kolade' and presses Enter
print('Hello', name) # Hello Kolade
```

- **Función `int()`**: Se usa para convertir un número, booleano o una cadena que representa un entero a un entero:

```py
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0

# A string representing a decimal number cannot be converted directly
# int('3.14') raises a ValueError
```

## Trabajar con funciones

- **Funciones**: Las funciones son fragmentos reutilizables de código que se ejecutan cuando las llamas. Para llamar a una función, necesitas referenciar el nombre de la función seguido de un conjunto de paréntesis:

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

- **Parámetros y argumentos**: Los parámetros son los nombres listados en la definición de una función, como `num_1` y `num_2` arriba. Los argumentos son los valores pasados al llamar a la función, como `3` y `4`.

Si llamas a la función sin el número correcto de argumentos, obtendrás un `TypeError`:

```py
def calculate_sum(a, b):
    print(a + b)

calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

- **Argumentos posicionales**: Estos argumentos se asignan a los parámetros según su posición en la llamada a la función.

```py
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

- **Argumentos con palabra clave**: Estos argumentos usan `name=value` para asignar un parámetro por nombre. Pueden aparecer en un orden diferente al de los parámetros:

```py
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

- **Combinación de tipos de argumentos**: Los argumentos posicionales deben ir antes que los argumentos con palabra clave. Cada parámetro solo puede recibir un valor:

```py
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

- **Sentencia `return`**: Una sentencia `return` termina la función y hace que su valor esté disponible donde se llamó la función.

- **`None`**: `None` representa la ausencia de un valor. Si una función no devuelve explícitamente un valor, el valor de retorno predeterminado es `None`:

```py
def greet():
    print('hello')

result = greet() # hello
print(result) # None
```

## Ámbito en Python

Python tiene reglas adicionales de ámbito. Por ahora, enfócate en el ámbito local y global.

- **Ámbito global**: Una variable creada fuera de una función puede usarse tanto dentro como fuera de las funciones.

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + (subtotal * tax)
    return total

print(get_total(100))  # 170.0
```

- **Ámbito local**: Una variable creada dentro de una función solo puede usarse dentro de esa función. Los parámetros de función también son variables locales.

```py
def my_func():
    num = 10
    print(num)
```

- **Paso de argumentos y reasignación de parámetros**: Python pasa argumentos por asignación. Un parámetro es un nombre local que inicialmente se refiere al objeto suministrado; el objeto no se copia automáticamente. Reasignar el parámetro no reasigna la variable pasada como argumento:

```py
def double_number(number):
    number = number * 2
    print(number) # 20

original = 10
double_number(original)
print(original) # 10
```

## Aplicar funciones y ámbito

- **Cuerpos de función vacíos**: Puedes usar `pass` como marcador de posición en el cuerpo de una función. Una función que contiene solo `pass` devuelve implícitamente `None`:

```py
def placeholder():
    pass

print(placeholder()) # None
```

- **Sombreado de nombres**: Cuando un parámetro o variable local tiene el mismo nombre que una variable global, la función usa el nombre local. Reasignar ese parámetro local no cambia la variable global:

```py
available_eggs = 5

def use_eggs(available_eggs, eggs_to_use):
    available_eggs -= eggs_to_use
    return available_eggs

print(use_eggs(available_eggs, 1)) # 4
print(available_eggs) # 5
```

- **Retornos anticipados**: Una sentencia `return` termina inmediatamente la función y hace que su valor esté disponible donde se llamó la función. Esto te permite retornar temprano cuando se cumple una condición:

```py
def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        return available_eggs
    return available_eggs - eggs_to_use

print(use_eggs(2, 3)) # 2
print(use_eggs(2, 1)) # 1
```

- **Llamar funciones desde otras funciones**: Una función puede llamar a otra función y usar o devolver su resultado:

```py
def use_eggs(available_eggs, eggs_to_use):
    return available_eggs - eggs_to_use

def make_fried_egg(available_eggs):
    return use_eggs(available_eggs, 1)

print(make_fried_egg(3)) # 2
```

- **Asignar valores retornados**: Devolver un nuevo valor no actualiza automáticamente la variable pasada como argumento. Para actualizarla, asigna el valor retornado de nuevo a esa variable:

```py
available_eggs = use_eggs(available_eggs, 1)
print(available_eggs) # 4
```

## Traducir cadenas

- **`str.maketrans()`**: La forma de dos cadenas de `str.maketrans()` toma cadenas de igual longitud y asigna cada carácter en la primera cadena al carácter correspondiente en la segunda. La tabla almacena caracteres como ordinales Unicode, números que los identifican de forma única. El método `translate()` aplica la tabla a una cadena y devuelve una nueva cadena. Los caracteres no incluidos en la tabla permanecen sin cambios.

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc!'.translate(trans_table)
print(result)  # 123123!
```

## Validar argumentos enteros

- **Booleanos y enteros**: Python trata los booleanos como un tipo especial de entero, por lo que `isinstance(True, int)` y `isinstance(False, int)` devuelven ambos `True`. Al validar un entero que no debe ser booleano, excluye explícitamente los valores booleanos:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True

value = True
print(isinstance(value, int) and not isinstance(value, bool)) # False

value = 5
print(isinstance(value, int) and not isinstance(value, bool)) # True
```

## Valores predeterminados de parámetros

- **Parámetros predeterminados**: Puedes suministrar un valor predeterminado a un parámetro. Si omites su argumento al llamar a la función, Python usa ese valor predeterminado:

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```
