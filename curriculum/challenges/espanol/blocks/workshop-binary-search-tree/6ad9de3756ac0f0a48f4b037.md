# --description--

Con el árbol en su lugar, puedes recorrerlo, lo que significa visitar cada nodo una vez.

El recorrido inorder es un recorrido en profundidad: avanza lo más profundo posible por una rama antes de pasar a la siguiente. Para cada nodo, visita:

1. El subárbol izquierdo.
1. El nodo mismo.
1. El subárbol derecho.

Dentro de la clase `BinarySearchTree`, crea un método llamado `_inorder_traversal` con tres parámetros: `self`, `node` y `result`. `node` es el nodo que se está visitando, y `result` es la lista donde recogerás las claves.

class TreeNode:
    def __init__(self, key):
        self.key = key
        self.left = None

class BinarySearchTree:
    def __init__(self):
        self.root = None

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node

    def insert(self, key):
        self.root = self._insert(self.root, key)
