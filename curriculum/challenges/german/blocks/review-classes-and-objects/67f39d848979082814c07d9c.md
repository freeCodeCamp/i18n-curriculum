## Python-Klassen und Objekte

- **Klassendefinition**: Eine Klasse ist eine Vorlage zur Erstellung von Objekten. Sie definiert das Verhalten, das ein Objekt durch seine Attribute und Methoden haben wird. Hier ist ein einfaches Beispiel für eine Klassendefinition in Python:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f'{self.name.upper()} says woof woof!')
```

- **Klassenamen**: Nach Konvention verwenden Klassennamen PascalCase: Jedes Wort beginnt mit einem Großbuchstaben und es gibt keine Unterstriche, wie bei `Dog` oder `ShoppingCart`.

- **Die `__init__()`-Methode**: Python ruft `__init__()` automatisch jedes Mal auf, wenn Sie ein neues Objekt erstellen. Sie wird verwendet, um die anfänglichen Attribute des Objekts einzurichten.

- **Der `self`-Parameter**: `self` bezieht sich auf das spezifische Objekt, an dem die Methode arbeitet. Python übergibt es automatisch, wenn Sie eine Methode an einem Objekt aufrufen, sodass Sie es im Aufruf nicht schreiben müssen. `self` ist der konventionelle Name, aber es ist immer der erste Parameter einer Instanzmethode.

- **Objekte erstellen**: Objekte sind Instanzen einer Klasse. Sie werden erstellt, indem die Klasse mit den notwendigen Argumenten aufgerufen wird.

```python
dog1 = Dog('Jack', 3)
dog2 = Dog('Thatcher', 5)

dog1.bark()  # JACK says woof woof!
dog2.bark()  # THATCHER says woof woof!
```

- **Methoden auf Objekten aufrufen**: Sie können Methoden auf Objekten aufrufen, um Aktionen auszuführen oder Informationen abzurufen.

```python
object_name1.method_name()
object_name2.method_name()
```

- **Unterschied zwischen Klasse und Objekt**: Eine Klasse ist eine wiederverwendbare Vorlage, während ein Objekt eine spezifische Instanz dieser Klasse mit tatsächlichen Daten ist.

## Attribute

- **Instanzattribute**: Üblicherweise in `__init__()` mit `self` definiert und für jedes Objekt einzigartig.
- **Klassenattribute**: Direkt innerhalb der Klasse definiert und von allen Instanzen geteilt.

```python
class Dog:
    species = 'French Bulldog'  # Class attribute

    def __init__(self, name):
        self.name = name  # Instance attribute

print(Dog.species) # French Bulldog

jack = Dog('Jack')
print(jack.name)     # Jack
print(jack.species)  # French Bulldog
```

- **Attribute dynamisch handhaben**: Manchmal ist der Name eines Attributs erst zur Laufzeit bekannt, zum Beispiel wenn er von Benutzereingaben oder einer Schleife stammt. In diesem Fall können Sie nicht `object.name` schreiben, sondern verwenden Funktionen, die den Namen als String annehmen:

  - `getattr(obj, name)` gibt den Wert des Attributs zurück. Es löst einen `AttributeError` aus, wenn das Attribut nicht existiert, es sei denn, Sie übergeben als dritten Parameter einen Standardwert.
  - `setattr(obj, name, value)` erstellt oder aktualisiert ein Attribut.
  - `hasattr(obj, name)` gibt `True` zurück, wenn das Attribut existiert, sonst `False`.
  - `delattr(obj, name)` löscht ein Attribut.

```python
class Dog:
    def __init__(self, name):
        self.name = name

dog = Dog('Jack')

print(getattr(dog, 'name'))            # Jack
print(getattr(dog, 'age', 'unknown'))  # unknown
getattr(dog, 'age')                    # AttributeError

setattr(dog, 'age', 3)
print(hasattr(dog, 'age'))  # True

delattr(dog, 'age')
print(hasattr(dog, 'age'))  # False
```

- **Attribute mit `dir()` inspizieren**: Die Funktion `dir()` gibt eine Liste mit den Namen der Attribute und Methoden eines Objekts zurück. Kombinieren Sie sie mit `callable()`, um Methoden von Datenattributen zu unterscheiden.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print('woof')

dog = Dog('Jack')
names = [n for n in dir(dog) if not n.startswith('__')]

print([n for n in names if callable(getattr(dog, n))])      # ['bark']
print([n for n in names if not callable(getattr(dog, n))])  # ['name']
```

## Methoden

- **Methoden**: Funktionen, die innerhalb einer Klasse definiert sind und auf die Attribute des Objekts zugreifen.

```python
class Car:
    def __init__(self, color, model):
        self.color = color
        self.model = model

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
print(my_car_1.describe())  # This car is a red Tesla Model S
```

- **Methoden aufrufen**: Rufen Sie Methoden auf Objekten mit der Punktnotation auf. Hier ist ein Beispiel, wie die `describe`-Methode bei zwei verschiedenen Autoobjekten aufgerufen wird:

```python
class Car:
    def __init__(self, color, model):
        self.color = color  
        self.model = model  

    def describe(self):
        return f'This car is a {self.color} {self.model}'

my_car_1 = Car('red', 'Tesla Model S')
my_car_2 = Car('green', 'Lamborghini Revuelto')

print(my_car_1.describe()) # Calling method using the dot notation

print(my_car_2.describe()) # Calling method using the dot notation
```

## Dunder- (Magic-) Methoden

- **Definition**: Spezielle Methoden, die mit einem doppelten Unterstrich beginnen und enden (z. B. `__init__`, `__len__`, `__str__`, `__eq__`). Python verwendet sie intern für eingebaute Operationen.

- **Verhalten ohne benutzerdefinierte spezielle Methoden**: Python leitet nicht ab, wie eingebaute Operationen die Attribute eines benutzerdefinierten Objekts verwenden sollen. Es nutzt die geerbten Standardverhalten, wo verfügbar, und löst einen `TypeError` für nicht unterstützte Operationen aus.

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book1 = Book('Built Wealth Like a Boss', 420)
book2 = Book('Another Book', 420)

print(book1)           # <__main__.Book object at 0x...>
print(book1 == book2)  # False
len(book1)             # TypeError: object of type 'Book' has no len()
```

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

    def __len__(self):
        return self.pages

    def __str__(self):
        return f"'{self.title}' has {self.pages} pages"

    def __eq__(self, other):
        return self.pages == other.pages

book1 = Book('Built Wealth Like a Boss', 420)
print(len(book1))        # 420
print(str(book1))        # 'Built Wealth Like a Boss' has 420 pages
```

- **Was die benutzerdefinierten Methoden ändern**: `__len__()` sorgt dafür, dass `len()` die Seitenanzahl zurückgibt, statt einen Fehler auszulösen. `__str__()` ersetzt die Standarddarstellung durch eine lesbare Zusammenfassung. `__eq__()` bewirkt, dass `==` die Seitenzahlen vergleicht, statt zu prüfen, ob beide Namen auf dasselbe Objekt verweisen.

```python
book2 = Book('Another Book', 420)

print(book1 == book2)  # True
```

- **Dunder-Methoden indirekt aufrufen**: Sie müssen Dunder-Methoden nicht direkt aufrufen. Python ruft sie automatisch auf, wenn bestimmte Aktionen stattfinden. Diese Operationen umfassen:

  - **arithmetische Operationen wie Addition, Subtraktion, Multiplikation, Division und andere**. `__add__()` wird für Addition aufgerufen, `__sub__()` für Subtraktion, `__mul__()` für Multiplikation und `__truediv__()` für Division.
        
  - **String-Operationen wie Verkettung, Wiederholung, Formatierung und Umwandlung in Text**. `__add__()` wird für Verkettung aufgerufen, `__mul__()` für Wiederholung, `__format__()` für Formatierung, `__str__()` und `__repr__()` für Textumwandlung und so weiter.
        
  - **Vergleichsoperationen wie Gleichheit, Kleiner-als, Größer-als und andere**. `__eq__()` wird für Gleichheitsprüfungen aufgerufen, `__lt__()` für Kleiner-als, `__gt__()` für Größer-als und so weiter.
        
  - **Iteration Operationen wie das Machen eines Objekts iterierbar und das Voranschreiten durch Elemente**. `__iter__()` wird aufgerufen, um einen Iterator zurückzugeben, und `__next__()` um das nächste Element abzurufen.

## Praxisbeispiel: Einkaufswagen

- **Warenkorb-Klasse mit Dunder-Methoden**: Ermöglicht das Hinzufügen, Entfernen, Iterieren und Überprüfen von Inhalten mit eingebautem Verhalten.

```python
class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def remove(self, item):
        if item in self.items:
            self.items.remove(item)
        else:
            print(f'{item} is not in cart')

    def list_items(self):
        return self.items

    def __len__(self):
        return len(self.items)

    def __getitem__(self, index):
        return self.items[index]

    def __contains__(self, item):
        return item in self.items

    def __iter__(self):
        return iter(self.items)

cart = Cart()
cart.add('Laptop')
print(len(cart))        # 1
print('Laptop' in cart) # True
```

## Zusammenarbeit von Objekten

- **Objekte als Argumente übergeben**: Objekte können an die Konstruktoren anderer Klassen übergeben werden, genau wie Zahlen oder Strings.

- **Objekte in Attributen speichern**: Ein Objekt kann im Attribut eines anderen Objekts gespeichert werden. Sie können dann Methoden über dieses Attribut aufrufen, indem Sie die Punktnotation verketten, wie in `receiver.inbox.receive_email(email)`.

```python
class Email:
    def __init__(self, sender, receiver, body):
        self.sender = sender      # A User object
        self.receiver = receiver  # A User object
        self.body = body

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

class User:
    def __init__(self, name):
        self.name = name
        self.inbox = Inbox()  # Each User gets its own Inbox object

sender = User('Ada')
receiver = User('Grace')

email = Email(sender, receiver, 'Hello!')
receiver.inbox.receive_email(email)

print(receiver.inbox.emails[0].body)         # Hello!
print(receiver.inbox.emails[0].sender.name)  # Ada
```

## Arbeiten mit Datum und Uhrzeit

- **Aktuelles Datum und Uhrzeit abrufen**: Der Aufruf von `datetime.datetime.now()` gibt das aktuelle Datum und die aktuelle Uhrzeit als `datetime`-Objekt zurück.

- **Zeitstempel in einer Instanz speichern**: Rufen Sie `datetime.datetime.now()` innerhalb von `__init__()` auf und weisen Sie das Ergebnis einem Attribut zu, um zu protokollieren, wann das Objekt erstellt wurde.

```python
import datetime

class Email:
    def __init__(self, body):
        self.body = body
        self.timestamp = datetime.datetime.now()
```

- **Formatieren mit `strftime()`**: Die Methode `strftime()` wandelt ein `datetime`-Objekt in einen String um, wobei Formatcodes verwendet werden: `%Y` für das vierstellige Jahr, `%m` für den Monat, `%d` für den Tag, `%H` für die Stunde (24-Stunden-Format), `%M` für die Minuten und `%S` für die Sekunden. Alle anderen Zeichen wie `-`, `/`, `:` oder Leerzeichen bleiben als literale Trennzeichen erhalten.

```python
email = Email('Hello!')

print(email.timestamp.strftime('%Y-%m-%d %H:%M:%S'))  # 2026-11-02 14:30:05
print(email.timestamp.strftime('%d/%m/%Y'))           # 02/11/2026
```
