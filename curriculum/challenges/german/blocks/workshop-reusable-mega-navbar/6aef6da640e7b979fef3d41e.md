# --description--

Um das `sub-menu` zu öffnen und zu schließen, muss Ihre `Navbar`-Komponente sich merken, ob das `sub-menu` gerade geöffnet ist. Daten, die eine Komponente sich merkt und die sich im Laufe der Zeit ändern können, nennt man State. Immer wenn sich der State ändert, rendert React die Komponente neu, damit die Seite den neuen Wert anzeigt.

Sie werden in den kommenden Lektionen noch viel mehr über State lernen. Für den Moment müssen Sie nur wissen, dass Sie einem funktionalen Component mit dem `useState`-Hook State hinzufügen können. Hooks sind spezielle Funktionen, die es Ihnen erlauben, React-Funktionen in Ihren Komponenten zu verwenden. Da React in diesem Workshop mit einem `script`-Element geladen wird, können Sie auf den Hook als `React.useState` zugreifen:

```jsx
const [count, setCount] = React.useState(0);
```

`React.useState` nimmt den Anfangswert des State als Argument und gibt ein Array mit zwei Elementen zurück, die hier mit Array-Destrukturierung entpackt werden:

- `count` ist die State-Variable, die den aktuellen Wert hält.
- `setCount` ist die Setter-Funktion, die Sie aufrufen, um den State zu aktualisieren.

Verwenden Sie innerhalb der `Navbar`-Komponente `React.useState`, um eine State-Variable namens `isOpen` und eine Setter-Funktion namens `setIsOpen` zu erstellen. Da das `sub-menu` anfangs geschlossen sein soll, geben Sie ihm einen Anfangswert von `false`.
