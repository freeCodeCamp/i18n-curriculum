# --description--

지난 수업들에서 다음과 같은 반복문을 다루는 데 익숙해졌을 것입니다:

```py
even_numbers = []

for num in range(21):
    if num % 2 == 0:
        even_numbers.append(num)

print(even_numbers)
```

이 예제는 `even_numbers`라는 새 빈 리스트를 만들고 `0`부터 `20` 사이의 숫자 수열을 반복합니다. 반복문 안에는 현재 숫자를 `0`로 나누었을 때 나머지가 `2`인지 확인하는 조건문이 있습니다. 이 조건은 숫자가 짝수인지 판단하는 데 사용됩니다. 조건이 `True`일 경우 현재 `num`가 `even_numbers` 리스트 끝에 추가됩니다. 마지막으로 `even_numbers` 리스트를 콘솔에 출력합니다.

## 리스트 내포란 무엇인가요?

이 코드는 작동하지만, 대신 리스트 내포를 사용해 더 간결하게 작성할 수 있습니다. 리스트 내포는 대괄호 안에 직접 반복문을 작성해 한 줄로 새 리스트를 만들 수 있게 해줍니다. 이렇게 하면 코드가 더 짧아지고 읽기 쉬워집니다.

리스트 내포의 기본 구문은 다음과 같습니다:

```py
[expression for item in iterable]
```

반복 가능한 객체의 각 항목에 대해 `for` 앞의 표현식이 평가되고, 그 결과가 새 리스트에 추가됩니다. 다음은 `0`부터 `4`까지 각 숫자에 `2`를 곱한 리스트를 만드는 예입니다:

```py
doubled = [num * 2 for num in range(5)]
print(doubled) # [0, 2, 4, 6, 8]
```

## 끝에 오는 `if`로 필터링하기

선택적으로 리스트 내포 끝에 `if` 조건을 추가할 수 있습니다. 조건이 참인 항목만 새 리스트에 추가되고, 나머지는 건너뜁니다.

앞서 나온 짝수 예제를 리스트 내포로 다시 작성한 예는 다음과 같습니다:

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

이 리팩터링된 예제에서는 `even_numbers` 리스트가 한 줄의 코드로 생성됩니다. 리스트 내포는 `0`부터 `20`까지 숫자를 반복하며 `2`로 나누어 떨어지는 숫자만 포함합니다. 이 방법은 더 간결하며 별도의 반복문과 조건문 블록이 필요 없습니다.

## 별도의 내부 리스트 만들기

앞서 `[[]] * 3`이 하나의 내부 리스트 참조를 반복한다는 것을 배웠습니다. 내포는 각 반복마다 별도의 내부 리스트를 만들 수 있습니다:

```py
rows = [[] for _ in range(3)]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

표현식 `[]`는 각 반복마다 평가되므로, 각 위치는 서로 다른 리스트를 참조합니다. 반복 변수는 표현식에서 사용되지 않고, 범위는 생성할 리스트 수만 제어합니다.

반복 변수가 필요 없을 때, 파이썬 개발자들은 그 값을 의도적으로 무시한다는 신호로 관례적으로 `_`라는 이름을 붙입니다. `_`는 여전히 일반 변수 이름입니다.

## 리스트 내포에서 조건 표현식 사용하기

지금까지 `if`와 `else`로 조건문을 작성했지만, 파이썬에는 한 줄로 작성하며 값을 생성하는 조건 표현식도 있습니다. 구문은 다음과 같습니다:

```py
value_if_true if condition else value_if_false
```

조건이 참이면 전체 표현식은 `if` 앞의 값을 평가하고, 그렇지 않으면 `else` 뒤의 값을 평가합니다. 예시는 다음과 같습니다:

```py
num = 7
label = 'Even' if num % 2 == 0 else 'Odd'
print(label) # Odd
```

`7`은 `2`로 나누어 떨어지지 않으므로 조건이 `False`이고, `'Odd'`가 `label`에 할당됩니다.

조건 표현식을 리스트 내포에서 `for` 앞의 표현식으로 사용할 수 있습니다. 이 경우 반복 가능한 각 항목에 대해 값을 선택하므로 새 리스트는 원본과 같은 개수의 항목을 가집니다. 이는 새 리스트에서 항목을 제외할 수 있는 끝에 오는 `if`와 다릅니다.

예제를 살펴보겠습니다:

```py
numbers = [1, 2, 3, 4, 5]
result = [(num, 'Even') if num % 2 == 0 else (num, 'Odd') for num in numbers]
print(result)
```

이 예제에서는 숫자 리스트가 있고, 어떤 숫자가 짝수인지 홀수인지 나타내는 튜플의 새 리스트를 만들고자 합니다. 리스트 내포의 첫 부분에서 `if`/`else` 조건 표현식을 사용해 숫자가 `2`로 나누어 떨어지는지 확인합니다. 그렇다면 결과는 그 숫자와 `Even`이라는 단어가 들어간 튜플이 됩니다. 그렇지 않으면 숫자와 `Odd`라는 단어가 들어간 튜플이 결과가 됩니다.

콘솔에 출력된 결과는 다음과 같습니다:

```py
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

## `filter()`로 리스트 필터링하기

기존 반복 가능한 객체에서 새 리스트를 만드는 또 다른 방법은 `filter()` 함수입니다. 다음은 네 글자 이상인 단어만 포함하는 새 리스트를 만드는 예제입니다:

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

`filter()` 함수는 특정 조건을 만족하는 반복 가능한 객체의 요소를 선택하는 데 사용됩니다. `filter()` 함수는 함수와 반복 가능한 객체를 인수로 받습니다. 이 예에서는 현재 단어의 글자 수가 `4`보다 큰지 확인하는 `is_long_word` 함수를 `filter()`에 전달합니다. `is_long_word`는 함수 자체를 전달하는 것이므로 괄호 없이 작성합니다. `filter()`는 각 단어에 대해 `is_long_word`를 호출합니다. `zip()`과 마찬가지로 `filter()`는 조건을 만족하는 단어만 제공하는 반복자를 반환합니다. `list()` 함수가 이 단어들을 새 리스트로 모아 `long_words` 변수에 할당합니다.

## `map()`으로 리스트 변환하기

`filter()` 함수 외에도 리스트 작업에 유용한 몇 가지 함수가 더 있습니다. 또 알아둘 함수는 `map()` 함수로, 반복 가능한 객체의 각 요소에 함수를 적용합니다. 다음은 `map()` 함수를 사용해 섭씨 온도를 화씨로 변환하는 예제입니다:

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

`filter()` 함수와 마찬가지로 `map()`도 함수와 반복 가능한 객체를 인수로 받습니다. `to_fahrenheit` 함수는 온도를 섭씨에서 화씨로 변환합니다. 다시 `to_fahrenheit`는 괄호 없이 전달되고, `map()`은 `celsius` 리스트의 각 온도에 대해 호출합니다. `map()` 함수도 변환된 값을 담은 반복자를 반환하므로, `list()`를 사용해 다시 리스트로 모읍니다.

## `sum()`으로 값 더하기

마지막으로 살펴볼 함수는 `sum()` 함수입니다. 이 함수는 리스트나 튜플 같은 반복 가능한 객체의 합계를 구하는 데 사용됩니다. 다음은 `sum()` 함수를 사용하는 예제입니다:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

선택적으로 `start` 인수를 전달해 합계의 초기값을 설정할 수도 있습니다. 다음은 위치 인수로 `start` 인수를 사용하는 업데이트된 예제입니다:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

또는 다음과 같이 키워드 인수로 `start` 인수를 사용할 수도 있습니다:

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

두 버전 모두 같은 결과를 내지만, 키워드 인수가 좀 더 명확합니다.

리스트 내포뿐 아니라 `map()`, `filter()`, `sum()` 같은 다른 함수들도 처음에는 다소 혼란스러울 수 있습니다. 하지만 충분한 연습과 시간이 지나면 Python 프로그램에서 이들을 더 편하게 사용할 수 있게 될 것입니다.
