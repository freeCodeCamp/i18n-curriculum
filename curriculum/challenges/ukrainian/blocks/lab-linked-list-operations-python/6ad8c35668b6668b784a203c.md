# --description--

У цій лабораторній роботі ви реалізуєте додаткові операції для структури даних зв’язаний список, базуючись на класі `LinkedList`, який ви створили на попередньому практичному занятті.

**Мета:** Виконайте наведені нижче історії користувача та пройдіть усі тести, щоб завершити лабораторну роботу.

**Історія користувача:**

1. Ваш клас `LinkedList` має мати метод `contains`, який приймає елемент як аргумент. Він повинен повертати `True`, якщо елемент існує у зв’язаному списку, і `False` в іншому випадку.
1. Ваш клас `LinkedList` має мати метод `get_at`, який приймає індекс як аргумент. Він повинен повертати елемент за заданим індексом у зв’язаному списку. Якщо індекс виходить за межі, він повинен повертати `None`.
1. Ваш клас `LinkedList` має мати метод `insert_at`, який приймає індекс і елемент як аргументи. Він повинен вставити елемент на задану позицію у зв’язаному списку та оновити атрибут `length`. Індекс, рівний довжині списку, є дійсним і повинен додати елемент у кінець. Якщо індекс виходить за межі, список не повинен змінюватися.
1. Ваш клас `LinkedList` має мати метод `remove_at`, який приймає індекс як аргумент. Він повинен видалити вузол за заданим індексом у зв’язаному списку та оновити атрибут `length`. Якщо індекс виходить за межі, список не повинен змінюватися.
1. Ваш клас `LinkedList` має мати метод `clear`, який видаляє всі елементи зі зв’язаного списку, скидаючи його до порожнього стану з `head`, встановленим у `None`, і `length`, встановленим у `0`.

**Примітка:** Деякі пізніші тести залежать від ранніх методів. Наприклад, якщо `get_at` реалізований неправильно, тести для методів, як-от `insert_at` і `remove_at`, можуть не пройти, навіть якщо ці методи майже правильні.

class LinkedList:
    class Node:
        def __init__(self, element):
            self.element = element
            self.next = None

    def __init__(self):
        self.length = 0
        self.head = None

    def is_empty(self):
        return self.length == 0

    def add(self, element):
        node = self.Node(element)
        if self.is_empty():
            self.head = node
        else:
            current_node = self.head
            while current_node.next is not None:
                current_node = current_node.next
            current_node.next = node
        self.length += 1

    def remove(self, element):
        previous_node = None
        current_node = self.head
        while current_node is not None and current_node.element != element:
            previous_node = current_node
            current_node = current_node.next
        if current_node is None:
            return
        elif previous_node is not None:
            previous_node.next = current_node.next
        else:
            self.head = current_node.next
        self.length -= 1

    def contains(self, element):
        current_node = self.head
        while current_node is not None:
            if current_node.element == element:
                return True
            current_node = current_node.next
        return False

    def get_at(self, index):
        if index < 0 or index >= self.length:
            return None
        current_node = self.head
        for _ in range(index):
            current_node = current_node.next
        return current_node.element

    def insert_at(self, index, element):
        if index < 0 or index > self.length:
            return
        node = self.Node(element)
        if index == 0:
            node.next = self.head
            self.head = node
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            node.next = previous_node.next
            previous_node.next = node
        self.length += 1

    def remove_at(self, index):
        if index < 0 or index >= self.length:
            return
        if index == 0:
            self.head = self.head.next
        else:
            previous_node = self.head
            for _ in range(index - 1):
                previous_node = previous_node.next
            previous_node.next = previous_node.next.next
        self.length -= 1

    def clear(self):
        self.head = None
        self.length = 0
