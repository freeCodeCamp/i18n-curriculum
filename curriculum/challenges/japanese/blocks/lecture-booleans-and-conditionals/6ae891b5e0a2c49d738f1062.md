# --description--

Pythonでは、変数はオブジェクトを指す名前です。識別演算子は、2つのオペランドが同じオブジェクトを指しているかどうかを確認します。`is`演算子は同じオブジェクトを指していれば`True`を返し、そうでなければ`False`を返します。`is not`演算子はその逆の結果を返します。

識別は等値とは異なります：`==`と`!=`は値を比較し、`is`と`is not`はオブジェクトの識別を比較します。数値や文字列の値を比較するときは等値演算子を使ってください。

`None`は値の不在を表します。`NoneType`データ型の唯一の値です。

識別演算子でチェックできる3つのオブジェクトは`None`、`True`、`False`です。それぞれがシングルトンであり、各オブジェクトは1つだけ存在します。

## `None`のチェック

値が欠けているかどうかを確認するには`is None`を使い、値が存在するかどうかを確認するには`is not None`を使えます：

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None`は偽とみなされますが、`False`とは異なるオブジェクトです。例えば、レスポンスは「はい」の場合は`True`、「いいえ」の場合は`False`、回答がない場合は`None`になることがあります：

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

`if not response`を使うと`False`と`None`の両方を同じように扱います。識別チェックは否定の回答と回答がないことを区別します。

## `True`と`False`のチェック

識別を使ってブール値オブジェクトかどうかを特にチェックすることもできます：

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

これらのチェックは`response`が正確に`True`、`False`、または`None`以外のオブジェクトかどうかを尋ねています。単に真偽値をテストしているわけではありません。

通常のブールフラグには`if is_ready`や`if not is_ready`のような直接的な真偽テストを使ってください。`is True`や`is False`は、`None`もあり得るレスポンスのように、ブール値オブジェクトを他の可能な値から区別する必要がある場合に使います。
