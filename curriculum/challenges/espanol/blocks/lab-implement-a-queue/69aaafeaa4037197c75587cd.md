# --description--

En este laboratorio, implementarás una estructura de datos de cola usando funciones. Una cola es una estructura de datos First-In-First-Out (FIFO) donde los elementos se agregan al final de la cola y se eliminan desde el frente.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

**Historias de usuario:**

1. Debes tener una función `initQueue` que devuelva un objeto con una propiedad `collection` establecida en un arreglo vacío.
1. Debes tener una función `enqueue` que agregue un elemento al final de la cola.
1. Debes tener una función `dequeue` que elimine y devuelva el elemento del frente de la cola, o `undefined` si no hay ninguno.
1. Debes tener una función `front` que devuelva el elemento del frente de la cola sin eliminarlo, o `undefined` si no hay ninguno.
1. Debes tener una función `size` que devuelva el número de elementos en la cola.
1. Debes tener una función `isEmpty` que devuelva `true` si la cola está vacía y `false` en caso contrario.

**Nota:** Las pruebas para `dequeue`, `front`, `size` y `isEmpty` usan la función `enqueue` para agregar elementos a la cola, por lo que es mejor implementar `enqueue` primero. La prueba final verifica que todas tus funciones trabajen juntas.

Debes tener una función `enqueue`.

```js
assert.isFunction(enqueue);
```

La función `enqueue` debe agregar un elemento al final de la cola.

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
assert.deepEqual(queue.collection, ['first', 'second']);
```

Debes tener una función `dequeue`.

```js
assert.isFunction(dequeue);
```

La función `dequeue` debe eliminar y devolver el elemento del frente de la cola.

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
enqueue(queue, 'third');
assert.strictEqual(dequeue(queue), 'first');
assert.strictEqual(dequeue(queue), 'second');
assert.lengthOf(queue.collection, 1);
```

`dequeue` debe devolver `undefined` cuando se llama en una cola vacía.

```js
const queue = initQueue();
assert.isUndefined(dequeue(queue));
```

`enqueue` debe continuar agregando elementos al final de la cola después de que se eliminen elementos del frente.

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
queue.collection.shift();
enqueue(queue, 'third');
assert.deepEqual(queue.collection, ['second', 'third']);
```

Diferentes instancias de cola no deben compartir estado.

```js
const queueOne = initQueue();
const queueTwo = initQueue();
enqueue(queueOne, 'first');
enqueue(queueTwo, 'second');

assert.deepEqual(queueTwo.collection, ['second']);
```

const queue = initQueue();

assert.strictEqual(front(queue), 'first');

La función `front` debe devolver `undefined` cuando se llame en una cola vacía.

Debes tener una función `size`.

```js
const queue = initQueue();
assert.strictEqual(size(queue), 0);
enqueue(queue, 'first');
assert.strictEqual(size(queue), 1);
enqueue(queue, 'second');
enqueue(queue, 'third');
assert.strictEqual(size(queue), 3);

assert.strictEqual(size(queue), 2);
```

Debes tener una función `isEmpty`.

```js
assert.isFunction(isEmpty);
```

La función `isEmpty` debe devolver `true` para una cola vacía.

```js
const queue = initQueue();
assert.isTrue(isEmpty(queue));
```

La función `isEmpty` debe devolver `false` para una cola que no está vacía.

```js
const queue = initQueue();
enqueue(queue, 'element');
assert.isFalse(isEmpty(queue));
```

La función `isEmpty` debe devolver `true` después de que se eliminen todos los elementos de la cola.

```js
const queue = initQueue();
enqueue(queue, 'first');
enqueue(queue, 'second');
queue.collection.shift();
queue.collection.shift();
assert.isTrue(isEmpty(queue));
```

Todas tus funciones de la cola deben trabajar juntas.

```js
const queue = initQueue();
assert.isTrue(isEmpty(queue));
enqueue(queue, 'first');
enqueue(queue, 'second');
enqueue(queue, 'third');
assert.strictEqual(size(queue), 3);
assert.strictEqual(front(queue), 'first');
assert.strictEqual(dequeue(queue), 'first');
assert.strictEqual(size(queue), 2);
enqueue(queue, 'fourth');
assert.strictEqual(dequeue(queue), 'second');
assert.strictEqual(dequeue(queue), 'third');
assert.strictEqual(dequeue(queue), 'fourth');
assert.isTrue(isEmpty(queue));
```

# --solutions--

```js
function initQueue() {
  return {
    collection: []
  };
}

function print(queue) {
  console.log(queue.collection);
}

function enqueue(queue, element) {
  queue.collection.push(element);
}

function dequeue(queue) {
  return queue.collection.shift();
}

function front(queue) {
  return queue.collection[0];
}

function size(queue) {
  return queue.collection.length;
}

function isEmpty(queue) {
  return queue.collection.length === 0;
}
```
