# --description--

Siyo kila idara inahakikishiwa kuwa na `Dept_code`. Unahitaji njia mbadala wakati haipo, ili idara bado ipate kitambulisho kinachoweza kutumika.

Kipengele cha `||` hurudisha thamani ya upande wa kushoto ikiwa thamani hiyo ni `truthy`, vinginevyo hurudisha thamani ya upande wa kulia.

Kwa mfano: `a || b` hutathmini kuwa `a` wakati `a` ni `truthy`, na hutumia njia mbadala ya `b` wakati `a` ni `falsy` (kama `undefined`, `null`, au `""`).

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

Sahihisha mgawo wa `departmentId` ili utumie operator `||`. Tumia `departmentData.Dept_code` kama operand ya kushoto na template literal `` `dept-${i + 1}` `` kama operand ya kulia. Hii hutumia njia mbadala kila `departmentData.Dept_code` inapokuwa falsy, ikiwa ni pamoja na pale inapokuwa `undefined`.
