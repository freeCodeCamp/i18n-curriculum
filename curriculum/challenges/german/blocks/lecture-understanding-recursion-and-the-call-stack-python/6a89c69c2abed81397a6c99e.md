# --description--

Rekursion ist eine Technik, bei der eine Funktion sich selbst aufruft. Jeder Aufruf arbeitet an einer kleineren Version des ursprünglichen Problems, bis eine Bedingung erreicht wird, die die Rekursion stoppt. Diese Stoppbedingung nennt man Basisfall.

Rekursive Funktionen können Probleme mit unbekannter Tiefe lösen, wie zum Beispiel das Durchlaufen eines Dateibaums. Sie können auch einfachere Aufgaben ausführen, wie das Herunterzählen von einer gegebenen Zahl.

Hier ist eine Funktion namens `recursive_countdown`, die eine Zahl entgegennimmt und sie ausgibt:

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

Das Aufrufen der Funktion gibt `5` aus, zählt aber noch nicht herunter. Bevor die Funktion sich selbst aufruft, müssen Sie ihren Basisfall definieren. Ohne einen erreichbaren Basisfall ruft die Funktion sich immer wieder selbst auf. Python stoppt die Aufrufe schließlich und wirft einen `RecursionError`.

Für dieses Herunterzählen sollte die Funktion stoppen, wenn `number` kleiner als `1` ist:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

Die `if`-Anweisung ist der Basisfall. Wenn `number` kleiner als `1` ist, beendet `return` diesen Funktionsaufruf.

Die Funktion braucht noch einen rekursiven Fall. Der rekursive Fall ruft die Funktion erneut mit einem Argument auf, das sie dem Basisfall näherbringt. Um herunterzuzählen, rufen Sie `recursive_countdown` mit `number - 1` auf:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

Dies gibt die Zahlen `5`, `4`, `3`, `2` und `1` aus.

Die Position des rekursiven Aufrufs ändert sich, wenn die Zahlen ausgegeben werden. Wenn der `print()`-Aufruf nach dem rekursiven Aufruf kommt, gibt die Funktion die Zahlen in aufsteigender Reihenfolge aus:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

Dies gibt die Zahlen `1`, `2`, `3`, `4` und `5` aus. Um zu verstehen, warum, müssen Sie den Aufrufstapel verstehen.

Der Aufrufstapel ist eine Last-in-first-out-Datenstruktur, die Python verwendet, um aktive Funktionsaufrufe zu verfolgen. Wenn eine Funktion aufgerufen wird, fügt Python einen Rahmen für diesen Aufruf oben auf den Stapel hinzu. Der Rahmen enthält Informationen wie die Argumente und lokalen Variablen der Funktion.

Betrachten Sie diese Version des Herunterzählens:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

Die Ausgabe ist:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

Der Aufruf von `recursive_countdown(3)` pausiert, wenn er `recursive_countdown(2)` aufruft. Der Aufruf mit `2` pausiert, wenn er die Funktion mit `1` aufruft, und der Aufruf mit `1` pausiert, wenn er die Funktion mit `0` aufruft.

Der Aufruf mit `0` erreicht den Basisfall und gibt zurück. Python entfernt diesen Aufruf vom oberen Ende des Stapels, sodass der Aufruf mit `1` nach seinem rekursiven Aufruf fortgesetzt wird. Die übrigen Aufrufe werden dann in umgekehrter Reihenfolge fortgesetzt und geben zurück: `1`, `2` und `3`.

Jede rekursive Funktion braucht einen Basisfall und einen rekursiven Fall, der darauf zusteuert. Wenn der Basisfall zurückgibt, werden die vorherigen Aufrufe in Last-in-first-out-Reihenfolge fortgesetzt.
