# --description--

在本实验中，你将使用函数实现一个栈数据结构。栈是一种后进先出（LIFO）的数据结构，元素从顶部添加和移除。

你的栈将是一个字典，其 `collection` 密钥保存一个元素列表。栈顶是列表的末尾，因此列表中的最后一个元素是最近添加的那个。

**目标：**实现以下用户需求并通过所有测试以完成实验。

**用户故事：**

1. 你应该有一个 `init_stack` 函数，它返回一个字典，字典的 `collection` 密钥设置为空列表。
1. 你应该有一个 `push` 函数，它接受一个栈和一个元素，并将该元素添加到栈顶。
1. 你应该有一个 `pop` 函数，它接受一个栈，移除并返回栈顶元素，如果栈为空则返回 `None`。
1. 你应该有一个 `peek` 函数，它接受一个栈，返回栈顶元素但不移除它，如果栈为空则返回 `None`。
1. 你应该有一个 `is_empty` 函数，它接受一个栈，如果栈不包含任何元素则返回 `True`，否则返回 `False`。
1. 你应该有一个 `clear` 函数，它接受一个栈，并移除其所有元素。

**注意：** 大多数测试依赖于 `init_stack` 和 `push` 函数。先实现它们，因为 `pop`、`peek`、`is_empty` 和 `clear` 的测试需要先向栈中添加元素。

# --solutions--

```py
def init_stack():
    return {"collection": []}

def print_stack(stack):
    print(stack["collection"])

def push(stack, element):
    stack["collection"].append(element)

def pop(stack):
    if is_empty(stack):
        return None
    return stack["collection"].pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack["collection"][-1]

def is_empty(stack):
    return not stack["collection"]

def clear(stack):
    stack["collection"].clear()
```
