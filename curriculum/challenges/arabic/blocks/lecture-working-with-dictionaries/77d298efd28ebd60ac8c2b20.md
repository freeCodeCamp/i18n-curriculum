# --description--

لقد تعلمت كيفية إنشاء القواميس والوصول إلى قيمها وتحديثها. الآن ستستخدم طرق القواميس، وتنسخ القواميس، وتستكشف كيف يمكن للدوال تغييرها.

يبدأ كل مثال لطريقة من طرق القاموس أدناه بهذا القاموس:

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## طرق القاموس

للقواميس أيضًا طرق مفيدة لأداء العمليات الشائعة.

تسترجع الطريقة `.get()` القيمة المرتبطة بمفتاح. هي مشابهة لترميز الأقواس الذي تعلمته في الدرس السابق، لكن ميزتها أنك تستطيع تعيين قيمة افتراضية، فلا تحصل على خطأ إذا لم يكن المفتاح موجودًا:

```python
dictionary.get(key, default)
```

في هذا المثال، إذا لم يكن المفتاح `toppings` موجودًا، سترجع قائمة فارغة، وهي القيمة الافتراضية التي نمررها هنا كالمعلمة الثانية. لكن إذا كان `toppings` موجودًا، سترجع تلك القيمة:

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

طرقا `.keys()` و`.values()` تعيدان كائن عرض يحتوي على كل المفاتيح والقيم في القاموس، على التوالي:

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

كائن العرض هو مجرد طريقة لرؤية محتوى القاموس دون إنشاء نسخة منفصلة من البيانات.

طريقة `.items()` تعيد كائن عرض يحتوي على كل أزواج المفتاح-القيمة في القاموس، بما في ذلك المفاتيح والقيم:

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

طريقة `.clear()` تزيل كل أزواج المفتاح-القيمة من القاموس:

```python
pizza.clear()
```

طريقة `.pop()` تزيل زوج المفتاح-القيمة الذي تحدده كالمعلمة الأولى وتُرجع قيمته. إذا لم يكن المفتاح موجودًا، تُرجع القيمة الافتراضية التي تحددها كالمعلمة الثانية. إذا لم يكن المفتاح موجودًا ولم تمرر قيمة افتراضية، يُثار الخطأ `KeyError`:

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

في Python 3.7 والإصدارات الأحدث، طريقة `.popitem()` تزيل آخر عنصر تم إدخاله:

```python
pizza.popitem()
```

تُحدّث الطريقة `.update()` أزواج المفتاح-القيمة بأزواج المفتاح-القيمة من قاموس آخر. إذا كان لهما مفاتيح مشتركة، تُستبدل قيمها.

في هذا المثال، نحن نحدث قاموس `pizza`. مفتاح `price` موجود في كلاهما، لذا ستُستبدل قيمته بـ `15`.

لكن `total_time` جديد، لذا سيُضاف إلى قاموس `pizza` كزوج مفتاح-قيمة جديد:

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

هذا هو القاموس الجديد مع تحديث `price` و`total_time` الجديد. لاحظ كيف أن السعر الآن `15` و`total_time` زوج مفتاح-قيمة جديد:

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### التعيين والنسخ السطحي

كما تعلمت مع القوائم، تعيين قاموس إلى متغير آخر ينشئ اسمًا بديلًا. كلا الاسمين يشيران إلى نفس الكائن:

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

لإنشاء قاموس خارجي منفصل، استخدم الطريقة `.copy()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

استبدال مدخل في `copied_settings` لا يستبدل المدخل المقابل في `settings`. مع ذلك، `.copy()` تنشئ **نسخة سطحية**: تنشئ قاموسًا خارجيًا جديدًا مفاتيحه وقيمه تشير إلى نفس الكائنات في القاموس الأصلي. الكائنات القابلة للتحوُّل المتداخلة لا تزال مشتركة:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

القاموسان كائنان مختلفان، لكن مدخلات `languages` تشير إلى نفس القائمة. الإضافة إلى تلك القائمة تظهر في كلا القاموسين. استبدال `copied_settings['languages']` بقائمة جديدة يغير فقط ذلك المدخل في النسخة.

يمكنك أيضًا إنشاء نسخة سطحية بتمرير قاموس إلى `dict()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

مثل `.copy()`، ينشئ `dict(settings)` قاموسًا خارجيًا جديدًا، لكن القائمة المتداخلة لا تزال مشتركة. استبدال مدخل في أي من القاموسين يؤثر فقط على ذلك القاموس، بينما تغيير القائمة المشتركة يظهر في كلاهما.

## تحوُّل قاموس عبر معلمة دالة

تنطبق قواعد تمرير المعلمات التي تعلمتها مع القوائم على القواميس. المعلمة تشير في البداية إلى الكائن الممرر كمعلمة. تحديث مدخل عبر تلك المعلمة يحوِّل القاموس المشترك:

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

ترجع الدالة سلسلة حالة، بينما يتغير `preferences` عبر المرجع المشترك. إرجاع قيمة وتحويل كائن هما تأثيران منفصلان. لا تحتاج الدالة إلى إرجاع القاموس لتكون التغييرات مرئية خارج الدالة. إعادة تعيين المعلمة المحلية إلى قاموس مختلف لا يستبدل القاموس المشار إليه بـ `preferences`.

## استخدام قاموس كمعلمة افتراضية

تذكر أن القائمة الافتراضية تُنشأ عند تعريف الدالة وتُعاد استخدامها عبر الاستدعاءات التي تحذف المعلمة. القاموس الافتراضي يتصرف بنفس الطريقة:

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

تُعاد استخدام القاموس الذي تغيّر في الاستدعاء الأول في الاستدعاء الثاني. هذا يعني أن الإعدادات تتراكم عبر استدعاءات مستقلة، رغم أن لكل استدعاء اسمه المحلي الخاص للمعلمة.

عندما يجب أن يبدأ كل استدعاء بقاموس جديد، استخدم نمط الافتراضي `None`:

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

كل استدعاء يحذف `settings` أو يمرر `None` ينشئ قاموسًا جديدًا. تمرير قاموس موجود لا يزال يسمح للدالة بتحويل ذلك الكائن. استخدم `settings is None` هنا: `if not settings` سيطابق أيضًا قاموسًا فارغًا ممررًا كمعلمة ويستبدله بقاموس محلي جديد.
