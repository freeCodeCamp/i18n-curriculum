# --description--

El desempaquetado te permite asignar los elementos de una lista a varias variables en una sola línea. Puedes usar una variable con asterisco para recoger los elementos restantes en una lista:

```py
fruits = ['apple', 'banana', 'cherry']
first, *rest = fruits
print(first) # apple
print(rest) # ['banana', 'cherry']
```

Desempaqueta `pieces` en tres variables: `opening` para el primer elemento, `middle` para todos los elementos intermedios y `closing` para el último elemento. Luego, imprime `opening`, `middle` y `closing` en tres llamadas separadas a `print()`.
