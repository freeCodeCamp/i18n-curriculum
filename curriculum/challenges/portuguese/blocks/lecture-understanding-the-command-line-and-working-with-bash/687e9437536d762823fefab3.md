# --description--

Vamos aprender sobre atalhos de linha de comando que você pode usar para acelerar a produtividade.

Atalhos de terminal e linha de comando podem ajudar você a otimizar seus fluxos de trabalho e maximizar sua produtividade. Para Linux e macOS, que ambos podem traçar suas raízes ao Unix, muitos desses atalhos serão os mesmos. Mas para Windows, haverá algumas diferenças.

## Os atalhos <kbd>seta para cima</kbd> e <kbd>seta para baixo</kbd>

O primeiro atalho é a tecla <kbd>Seta para cima</kbd>. Pressioná-la permite navegar para trás pelo histórico de comandos, um comando por vez. A tecla <kbd>Seta para baixo</kbd> pode ser usada para navegar para frente pelo histórico de comandos. Essas duas teclas permitem que você percorra rapidamente os comandos que executou anteriormente para encontrar um que precise executar novamente.

## Autocompletar com a tecla <kbd>Tab</kbd>

Muitos shells também oferecem um recurso de autocompletar, sugerindo comandos com base no que você começou a digitar. A tecla <kbd>Tab</kbd> pode ser usada para preencher o restante da sugestão, preenchendo rapidamente sua linha de comando com a sintaxe completa. O que é sugerido depende do shell, do comando que você está digitando e de como seu shell está configurado. Por exemplo, quando você digita o nome de um comando, Bash e zsh sugerem comandos correspondentes, e quando você digita um argumento, geralmente sugerem nomes de arquivos e diretórios correspondentes. O PowerShell pode completar comandos, nomes de parâmetros, variáveis e caminhos de arquivos.

## O atalho <kbd>Control</kbd> + <kbd>L</kbd>

Às vezes, um comando pode gerar muita saída no terminal. Esse ruído extra pode atrapalhar ou se tornar disruptivo para seu fluxo de trabalho. Em terminais baseados em *nix encontrados em dispositivos Linux e macOS, você pode pressionar <kbd>Control</kbd> + <kbd>L</kbd> para limpar toda a tela e começar com um prompt limpo. No PowerShell, <kbd>Control</kbd> + <kbd>L</kbd> também limpa a tela por padrão, e você pode executar o comando `cls` para o mesmo resultado.

## O atalho <kbd>Control</kbd> + <kbd>C</kbd>

Se precisar interromper um comando para parar sua execução, você pode pressionar <kbd>Control</kbd> + <kbd>C</kbd>. Isso envia uma requisição de interrupção para o comando em execução no primeiro plano, que geralmente o para e retorna um novo prompt, permitindo que você continue com o que precisar fazer. Alguns programas lidam com essa requisição por conta própria, então podem pedir para você confirmar ou continuar executando. Para usuários do PowerShell, <kbd>Control</kbd> + <kbd>C</kbd> também é usado para copiar texto — e só funciona para interromper um comando quando o contexto não está ambíguo (como quando não há texto selecionado para copiar).

## Atalhos para terminais baseados em *nix

Os próximos atalhos estão disponíveis apenas em terminais baseados em *nix e não possuem uma alternativa no PowerShell.

Pode haver momentos em que você precise fazer multitarefa, pausando um comando enquanto trabalha em outro. Pressionar <kbd>Control</kbd> + <kbd>Z</kbd> suspende o comando em execução no primeiro plano e retorna para a linha de comando, onde você pode continuar seu trabalho. Um comando suspenso está pausado, não em execução. Se quiser que ele continue rodando em segundo plano, use o comando `bg`. Quando precisar trazê-lo de volta para o primeiro plano, use o comando `fg`.

E finalmente, pode haver comandos que você precise executar duas vezes seguidas. Você pode pressionar a tecla <kbd>Seta para cima</kbd> para navegar para trás até o comando executado anteriormente, mas também pode digitar dois pontos de exclamação (`!!`) na linha de comando e pressionar <kbd>Enter</kbd> — isso executará automaticamente o último comando executado.
