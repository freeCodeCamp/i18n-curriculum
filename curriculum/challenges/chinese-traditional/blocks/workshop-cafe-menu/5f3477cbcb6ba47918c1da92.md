# --description--

為了讓頁面的樣式在行動裝置上看起來與桌面或筆記型電腦相似，你需要添加一個帶有特殊 `content` 屬性的 `meta` 元素。

viewport 的 `meta` 元素會給瀏覽器指示，告訴它如何在不同裝置上控制頁面的尺寸和縮放，特別是在手機和平板上。以下是一個範例：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

`width=device-width` 這部分告訴瀏覽器將頁面寬度設定為與裝置螢幕寬度相符。`initial-scale=1.0` 則設定頁面初次載入時的縮放層級。值為 `1.0` 表示頁面以 `100%` 縮放顯示，沒有縮放比例。

如果沒有這個元素，行動瀏覽器通常會以桌面螢幕寬度來呈現頁面，然後再縮小，這會導致文字變得非常小且難以閱讀。

# --hints--

你的程式碼應該有兩個 `meta` 元素。

```js
assert.lengthOf(document.querySelectorAll('meta'), 2);
```

你的 `meta` 元素應該有一個 `name` 屬性，且其值為 `viewport`。

```js
assert.exists(document.querySelector('meta[name="viewport"]'));
```

你的 `meta` 元素應該有一個 `content` 屬性，其值為 `width=device-width, initial-scale=1.0`。

```js
assert.equal(document.querySelector('meta[name="viewport"]')?.getAttribute('content'), 'width=device-width, initial-scale=1.0');
```
