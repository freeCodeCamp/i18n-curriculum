# --description--

Метод `.split(separator)` розбиває рядок на список підрядків у кожному місці появи `separator`. Наприклад:

```py
fruits = 'apple, banana, cherry'
parts = fruits.split(', ')
print(parts)  # Output: ['apple', 'banana', 'cherry']
```

Створіть змінну `full_address` і призначте їй рядок `123 Main Street, Springfield, IL`. Потім створіть `address_parts`, розбивши рядок за комою з одним пробілом.

Потім виведіть `address_parts`, щоб вихідні дані виглядали так: `Address parts: ['123 Main Street', 'Springfield', 'IL']`.
