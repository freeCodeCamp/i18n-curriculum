# --description--

## 関数とは何ですか？

関数は呼び出すと実行される再利用可能なコードの断片です。Pythonには組み込み関数があり、前のレッスンで使った`print()`もその一つです。

もう一つ便利な組み込み関数が`input()`で、ユーザーに入力を促すことができます。

```python
name = input('What is your name?') # User types "Kolade" and presses Enter  
print('Hello', name) # Output: Hello Kolade
```

一方で、`int()` は数値、ブール値、または整数を表す文字列を整数に変換します。

```python
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0 
```

## 関数の定義と呼び出し

また、自分でカスタム関数を書くこともできます。そのためには、`def`キーワードの後に関数名、丸括弧、コロンを続けて書きます。次の行に関数が実行するコードを書きます。関数が実行するコードは関数の本体とも呼ばれます。

以下は、`hello`という名前のカスタム関数の例で、文字列`Hello World`をターミナルに出力します。

```python
def hello():
    print('Hello World')
```

関数を実行するには、関数名の後に丸括弧を付けて呼び出します。

```python
hello() # Hello World
```

`print('Hello World')`の前のインデントに注目してください。これまでのレッスンで学んだように、Pythonはどの文のグループが一緒に属するかをインデントで判断します。これらの文のグループはコードブロックと呼ばれます。

## パラメータと引数の使い方

次は、2つの数の合計をターミナルに出力するシンプルな関数です。

```python
def calculate_sum(a, b):
    print(a + b)
```

関数`calculate_sum`の丸括弧内に`a`と`b`がカンマで区切られているのがわかります。これらはパラメータと呼ばれます。パラメータは、関数を呼び出すときに渡す値の「スロット」として機能するプレースホルダー変数のようなものです。

パラメータを使うには、呼び出し時に「引数」を渡す必要があります。引数は関数に渡す値のことです。

`calculate_sum`関数を呼び出して、`3`と`1`の数を合計する方法は以下の通りです。

```python
calculate_sum(3, 1) # 4
```

正しい数の引数を渡さずに関数を呼び出すと、`TypeError`が発生します。

```python
calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

## 位置引数とキーワード引数

`calculate_sum(3, 1)` の引数は位置引数です。Pythonはこれらを位置でパラメータに対応させます：`3` は `a` に、`1` は `b` に割り当てられます。

引数の順序が重要な関数の例を示します：

```python
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

位置引数を入れ替えると、`name` に `25` が、`age` に `'Alice'` が割り当てられます：

```python
introduce(25, 'Alice')
# My name is 25 and I am Alice years old.
```

パラメータ名の後に `=` と値を書くことでキーワード引数を渡すこともできます。Pythonは名前でこれらの引数を対応させるので、異なる順序で書くことができます：

```python
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

ここで、`name='Alice'` は `'Alice'` を `name` パラメータに渡します。関数外で `name` という変数を代入するわけではありません。

位置引数とキーワード引数を組み合わせることができますが、位置引数は必ず先に来なければなりません：

```python
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

キーワード引数の後に位置引数を置くと `SyntaxError` が発生します：

```python
introduce(name='Alice', 25)
# SyntaxError: positional argument follows keyword argument
```

同じパラメータに対して複数回値を渡すこともできません：

```python
introduce('Alice', name='Bob', age=25)
# TypeError: introduce() got multiple values for argument 'name'
```

この呼び出しでは、位置引数 `'Alice'` がすでに `name` の値を渡しています。`name='Bob'` を渡すと同じパラメータに2つ目の値を渡すことになります。

## 関数からの値の返却

関数は特別な`return`キーワードを使って関数を終了し、値を返すこともできます。明示的に`return`を使わない場合、Pythonはデフォルトで`None`を返します。

識別演算子のレッスンで学んだように、`None` は値が存在しないことを表します。ここでは、関数が明示的な結果を返していないことを示しています。

例を示します。

```python
def calculate_sum(a, b):
    print(a + b)

my_sum = calculate_sum(3, 1) # 4
print(my_sum) # None
```

`calculate_sum`関数は`a`と`b`の合計を出力しますが、明示的に何も返していません。そのため、結果を`my_sum`に代入すると、実際には`None`になります。これを修正するには、結果を返すために`return`キーワードを使います。

```python
def calculate_sum(a, b):
    return a + b

my_sum = calculate_sum(3, 1)
print(my_sum) # 4
```

これで`calculate_sum`は`a`と`b`の合計を返し、その値が`my_sum`にストアされます。
