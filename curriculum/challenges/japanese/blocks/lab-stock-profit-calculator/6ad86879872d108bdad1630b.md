# --description--

このラボでは、単一の株取引で得られる最大の利益を見つけます。各日の株価が与えられ、ある日に1株を購入し、後の日に売ることができます。目標は、売値から買値を引いた最大の利益を見つけることです。

例えば、価格が `[7, 1, 5, 3, 6, 4]` の場合、最良の取引は `1` 日目に価格 `1` で買い、`4` 日目に価格 `6` で売ることで、利益は `5` です。価格 `7` は価格 `1` より前の日にあるため、`1` で買って `7` で売ることはできません。

リストが非常に長くなる場合があるので、効率的な解決策が必要です。すべての買い日と売り日の組み合わせを比較すると二次時間、`O(n²)`がかかります。代わりにリストを一度だけ通過する方法を見つけて、線形時間、`O(n)`で動作するようにしてください。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

**ユーザーストーリー：**

1. `max_profit`という名前の関数を用意し、パラメータは各要素がその日の株価である正の整数のリストを表します。
1. `max_profit`は、ある日に買って後の日に売ることで得られる最大の利益を返す必要があります。
1. 利益が出る取引がない場合、または`prices`の要素数が2未満の場合、`max_profit`は`0`を返す必要があります。
1. `max_profit`は`prices`を変更してはいけません。
1. `max_profit`は、`prices`の長さを`n`としたとき、線形時間、`O(n)`で動作する必要があります。

**注意:** すべてのペアの日をチェックする代わりに、リストを通過しながらこれまでに見た最安値を記録し、現在の日に売った場合の利益を計算してください。

```py
def max_profit(prices):
    lowest_price = float("inf")
    best_profit = 0

    for price in prices:
        if price < lowest_price:
            lowest_price = price
        elif price - lowest_price > best_profit:
            best_profit = price - lowest_price

    return best_profit
```
