## Python in Ihrer lokalen Umgebung installieren

- **Installation**: Der einfachste Weg, Python unter Windows und macOS zu installieren, ist der Download des Installers von der offiziellen Python-Website (`https://www.python.org/`). Unter Linux beinhalten die meisten großen Distributionen wie Ubuntu, Debian und Fedora Python bereits, daher prüfen Sie zuerst die installierte Version und installieren nur ein distributionsspezifisches Paket, wenn Python 3 fehlt.
- **Einrichtung unter macOS**: Laden Sie den `.pkg`-Installer herunter und öffnen Sie ihn, folgen Sie den Anweisungen. Wenn die Installation abgeschlossen ist, doppelklicken Sie auf die Datei `Install Certificates.command` und lassen Sie den Terminalprozess abschließen, um die Einrichtung zu beenden.
- **Einrichtung unter Windows**: Laden Sie den `.msix` Python Install Manager herunter und führen Sie ihn aus. Danach sind die Befehle `python`, `py` und `pymanager` verfügbar. Wenn Sie `python` ohne installierte Laufzeit ausführen, wird diese automatisch installiert. Sie können die optionale Aufforderung akzeptieren, ein Alias-Verzeichnis (für Befehle wie `python3.14.exe`) zu Ihrem `PATH` hinzuzufügen.
- **Einrichtung unter Linux**: Öffnen Sie ein Terminal und führen Sie `python --version` oder `python3 --version` aus. Wenn keiner der Befehle eine Python 3 Version meldet, suchen Sie nach einem Installationspaket auf `https://www.python.org/` oder recherchieren Sie online, wie Sie Python für Ihre Distribution am besten installieren.

## Die Installation überprüfen

- **Version prüfen**: Bestätigen Sie die Installation, indem Sie `python --version` oder `python3 --version` in einem Terminal ausführen.
- **`python` vs. `python3`**: Auf einigen älteren macOS- und Linux-Systemen kann `python` auf Python 2 verweisen. Wenn `python --version` eine Python 2 Version meldet, verwenden Sie ab dann `python3` für Ihren Code. Python 2 ist veraltet und sollte für neue Entwicklungen nicht mehr verwendet werden.

## Terminal

- **Definition**: Ein Terminal ist eine textbasierte Schnittstelle, mit der Sie durch Eingabe von Befehlen mit Ihrem Computer interagieren können. Jedes Betriebssystem hat eine Standard-Terminal-App. Unter macOS können Sie die Terminal-App verwenden. Unter Windows stehen die Eingabeaufforderung oder PowerShell zur Verfügung. Unter Linux hat jede Desktop-Umgebung ihre eigene Standard-Terminal-App, wie GNOME Terminal oder Konsole.

## Code-Editoren und IDEs

- **IDE**: IDE steht für Integrated Development Environment (integrierte Entwicklungsumgebung) und bietet Funktionen wie einen Code-Editor, Testwerkzeuge, ein Terminal und mehr.
- **Beliebte Code-Editoren und IDEs für Python**: VS Code, PyCharm und Spyder.

## Python-Skripte ausführen

- **Editor einrichten**: Öffnen Sie Ihren Projektordner in VS Code und erstellen Sie eine `.py`-Datei. Installieren Sie die Python-Erweiterung von Microsoft über die Erweiterungsansicht oder indem Sie `code --install-extension ms-python.python` ausführen (unter macOS muss der `code`-Befehl zuerst zu Ihrem `PATH` hinzugefügt werden). Die Erweiterung fügt dem Editor Python-Unterstützung hinzu, installiert aber Python nicht selbst.
- **Interpreter auswählen**: Führen Sie `Python: Select Interpreter` aus der Befehlspalette aus, um den Editor auf einen zuvor installierten Python 3 Interpreter zu verweisen.
- **Code ausführen**: Klicken Sie auf die Ausführen-Schaltfläche (das Play-Symbol oben rechts in VS Code), um die aktuelle Datei in einem Terminal auszuführen. Sie können ein Skript auch manuell im Terminal ausführen. Wenn Ihr Projektordner beispielsweise `python-projects` heißt und Ihr Skript `main.py`, öffnen Sie ein Terminal im Ordner, der `python-projects` enthält, wechseln Sie in den Projektordner und führen Sie das Skript aus:

```bash
cd python-projects
python main.py
```

Verwenden Sie stattdessen `python3 main.py`, wenn `python3` der Befehl ist, der auf Ihrem System Python 3 meldet.

## Verwendung der Python-Interactive-Shell

- **Shell starten**: Öffnen Sie ein Terminal und führen Sie `python` oder `python3` aus (verwenden Sie den Befehl, der eine Python 3 Version meldet). Die Eingabeaufforderung `>>>` bedeutet, dass Python auf einen Befehl wartet. Versuchen Sie, `"Hello, world!"` auszugeben:

```python
print("Hello, world!")
```

- **Read, Evaluate, Print, Loop-Zyklus (REPL)**: Der Interpreter liest Ihre Eingabe, wertet sie aus, gibt das Ergebnis aus und kehrt zur `>>>`-Eingabeaufforderung zurück, damit Sie einen weiteren Befehl eingeben können.
- **Ungültige Eingabe**: Wenn Sie etwas eingeben, das kein gültiger Python-Code ist, wie `something random`, erscheint die Meldung `SyntaxError: invalid syntax` und die Shell kehrt zur Eingabeaufforderung zurück.
- **Shell beenden**: Geben Sie `exit()` ein, drücken Sie <kbd>Ctrl</kbd> + <kbd>D</kbd> unter macOS oder Linux oder <kbd>Ctrl</kbd> + <kbd>Z</kbd> gefolgt von <kbd>Enter</kbd> unter Windows.
- **Wann verwenden**: Die interaktive Shell eignet sich am besten für kleine Experimente und schnelle Erkundungen. Für längere Programme oder Arbeiten über mehrere Dateien hinweg verwenden Sie einen Code-Editor oder eine IDE.
