## 알고리즘과 빅오 표기법

- **알고리즘**: 문제 해결이나 작업 수행을 위한 명확한 지침 집합입니다. 알고리즘은 유한한 단계 내에 끝나야 하며 각 단계는 정확하고 명확해야 합니다.

- **Big O 표기법**: 입력 크기가 증가함에 따라 알고리즘의 자원 사용량에 대한 점근적 상한을 설명합니다. Big O는 최선, 평균, 최악의 경우를 따로 구분하지 않고 전체적인 확장 추세를 측정하며, 상수 요소와 작은 항들은 무시합니다.

### 일반적인 시간 복잡도

- **O(1) - 상수 시간**: 입력 크기와 상관없이 일정한 시간이 걸립니다.

```python
def check_even_or_odd(number):
    if number % 2 == 0:
        return 'Even'
    else:
        return 'Odd'
```

- **O(log n) - 로그 시간**: 입력 크기에 대해 최대 로그 함수만큼 증가하는 실행 시간의 상한입니다. 이 상한이 정확할 때 알고리즘은 로그 시간에 실행됩니다. 이는 문제 크기를 일정 비율로 반복해서 줄이는 경우, 예를 들어 이진 탐색에서 흔히 발생합니다.

- **O(n) - 선형 시간**: 입력 크기에 대해 최대 선형적으로 증가하는 실행 시간의 상한입니다. 이 상한이 정확할 때 실행 시간은 입력 크기에 비례해 증가합니다.

```python
for grade in grades:
    print(grade)
```

- **O(n log n) - 로그 선형 시간**: 효율적인 분할 정복 정렬에서 흔히 나타납니다. 병합 정렬은 최악의 경우 O(n log n) 복잡도를 가지며, 퀵 정렬은 평균적으로 O(n log n)이지만 최악의 경우 O(n²)입니다.

- **O(n²) - 이차 시간**: 입력 크기에 대해 최대 이차 함수만큼 증가하는 실행 시간의 상한입니다. 이 상한이 정확할 때 실행 시간은 입력 크기의 제곱에 비례해 증가합니다. 이는 각 루프가 n번 반복되는 중첩 루프에서 발생합니다.

```python
for i in range(n):
    for j in range(n):
        print("Hello, World!")
```

- **O(2ⁿ) - 지수 시간**: 실행 시간에 대한 지수 상한입니다. 이 상한이 정확할 때 성장률은 2ⁿ에 비례하며, n이 1 증가할 때마다 두 배로 증가합니다.

- **O(n!) - 팩토리얼 시간**: 실행 시간에 대한 팩토리얼 상한입니다. 이 상한이 정확할 때 성장률은 n개의 서로 다른 항목의 순열 수인 n!에 비례합니다.

### 공간 복잡도

- **O(1) - 상수 공간**: 메모리 사용량이 입력 크기와 무관한 상수로 제한됩니다.

- **O(n) - 선형 공간**: 메모리 사용량이 입력 크기에 대해 최대 선형적으로 증가합니다. 이 상한이 정확할 때 메모리 사용량은 입력 크기에 비례해 증가합니다.

- **O(n²) - 이차 공간**: 메모리 사용량이 입력 크기에 대해 최대 이차 함수만큼 증가합니다. 이 상한이 정확할 때 메모리 사용량은 입력 크기의 제곱에 비례해 증가합니다.

- **O(2ⁿ) - 지수 공간**: 메모리 사용량에 대한 지수 상한입니다. 이 상한이 정확할 때 메모리 사용량은 2ⁿ에 비례해 증가합니다.

- **O(n!) - 팩토리얼 공간**: 메모리 사용량에 대한 팩토리얼 상한입니다. 이 상한이 정확할 때 메모리 사용량은 n!에 비례해 증가합니다.

## 문제 해결 기법

- **의사 코드**: `IF`, `ELSE`, `FOR`, `WHILE` 같은 프로그래밍 구문과 일반 언어를 혼합해 언어에 독립적인 알고리즘 논리를 고수준으로 설명합니다.

```md
GET original_string
SET reversed_string = ""

FOR EACH character IN original_string:
    ADD character TO THE BEGINNING OF reversed_string

DISPLAY reversed_string
```

- **구현**: 의사 코드 계획을 바탕으로 깔끔하고 읽기 쉬우며 모듈화된 코드를 작성하세요. 일반적인 작업에는 적절한 내장 도구를 사용하세요.

- **경계 사례**: 알고리즘이 처리해야 하는 경계에 위치한 특정 유효 입력입니다. 항상 경계 사례를 고려하고 테스트하세요.

- **테스트와 개선**: 제공된 예제와 경계 사례로 코드를 테스트하세요. 버그를 디버그하고 결과를 확인하며 명확성이나 효율성을 높이도록 해결책을 다듬으세요.

## 배열

- **정적 배열**: 생성 시 고정 크기를 가지며 요소가 연속된 메모리에 저장됩니다. 이 인접한 배치는 빠르고 상수 시간인 인덱스 접근(O(1))을 가능하게 합니다. 최대 항목 수가 엄격히 알려진 경우 정적 배열을 선택하세요.

- **동적 배열**: 프로그램 실행 중 자동으로 크기가 커지거나 작아질 수 있습니다. 공간이 부족하면 더 큰 메모리 블록을 할당하고 기존 요소를 복사하여 크기 조정을 처리합니다.

**참고:** Python에는 전통적인 내장 정적 배열이 없습니다. Python 리스트는 동적 배열입니다.

### Python 리스트(동적 배열)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### 동적 배열의 시간 복잡도

- **접근**: O(1)

- **끝에 삽입**: 평균 O(1), 크기 조정 필요 시 O(n)

- **중간에 삽입**: O(n)

- **삭제**: 중간은 O(n), 끝은 O(1)

## 스택

- **스택**: 후입선출(LIFO) 자료 구조입니다. 요소는 오직 맨 위에서 추가되고 제거됩니다.

- **푸시 연산**: 스택 상단에 요소를 추가합니다. 아래 Python 리스트 구현에서 일반 푸시는 O(1) 시간과 O(1) 추가 공간이 필요합니다. 크기 조정이 필요한 푸시는 O(n) 시간과 O(n) 추가 공간이 필요할 수 있습니다.

- **팝 연산**: 스택 상단에서 요소를 제거합니다. 시간 복잡도는 일반적으로 O(1)이며, 추가 공간도 보통 O(1)입니다.

```python
# Using Python list as stack
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operations
top_element = stack.pop()  # Returns 3
```

## 큐

- **큐**: 먼저 들어온 요소가 먼저 나가는(FIFO) 자료 구조로, 요소는 뒤에서 추가되고 앞에서 제거됩니다.

- **인큐 연산**: 큐 뒤에 요소를 추가합니다. 시간 복잡도: O(1), 공간 복잡도: O(1).

- **디큐 연산**: 큐 앞에서 요소를 제거합니다. 시간 복잡도: O(1), 공간 복잡도: O(1).

## 연결 리스트

- **연결 리스트**: 각 노드가 데이터와 다음 노드에 대한 참조를 가지는 선형 자료 구조입니다. 노드들이 체인처럼 연결되어 있습니다.

### 단일 연결 리스트

- **구조**: 각 노드는 데이터와 다음 노드에 대한 참조 하나를 가집니다.

- **순회**: 머리에서 꼬리 방향으로만 이동할 수 있습니다.

- **머리 노드**: 리스트의 첫 번째 노드로, 보통 유일하게 직접 접근 가능한 노드입니다.

- **꼬리 노드**: 리스트의 마지막 노드로, `None`을 가리킵니다.

### 연결 리스트 구현

- **노드 클래스**: 중첩된 `Node` 클래스가 개별 노드를 나타냅니다. 각 노드는 데이터와 다음 노드에 대한 참조를 포함합니다.

- **초기화**: 리스트에 노드가 없으므로 `head` 참조는 `None`으로 시작합니다. 새 노드의 `next` 참조도 후속 노드가 없으므로 `None`으로 시작합니다.

- **길이 추적**: 리스트 내 노드 수를 추적하는 길이 변수가 있습니다.

- **`is_empty()`**: `head`가 `None`인지 확인해 리스트가 비었는지 검사합니다.

- **추가**: 머리부터 순회해 마지막 노드에 도달한 후, 그 노드의 `next` 참조를 새 노드로 업데이트합니다. 리스트가 비었으면 새 노드가 머리가 됩니다.

```python
class LinkedList:
    class Node:
        def __init__(self, data):
            self.data = data
            self.next = None

    def __init__(self):
        self.head = None
        self.length = 0

    def is_empty(self):
        return self.head is None

    def append(self, data):
        new_node = self.Node(data)

        if self.is_empty():
            self.head = new_node
        else:
            current = self.head

            while current.next:
                current = current.next

            current.next = new_node

        self.length += 1
```

### 연산과 시간 복잡도

- **처음에 삽입**: O(1)

- **끝에 삽입**: O(n) - 끝까지 순회해야 함

- **중간에 삽입**: O(n) - 위치까지 순회해야 함

- **처음에서 삭제**: O(1)

- **끝에서 삭제**: O(n) - 이전 노드를 찾기 위해 순회해야 함

- **중간에서 삭제**: O(n) - 노드를 찾기 위해 순회해야 함

### 삽입과 삭제

- **처음에 삽입**: 새 노드를 만들고 그 `next` 참조를 현재 머리로 설정한 후, 머리를 새 노드로 업데이트합니다.

- **끝에 삽입**: 마지막 노드까지 순회한 후 그 노드의 `next` 참조를 새 노드로 업데이트합니다.

- **중간에 삽입**: 원하는 위치 바로 전 노드까지 순회합니다. 새 노드의 `next` 참조를 다음 노드로 설정하고, 이전 노드의 `next` 참조를 새 노드로 업데이트합니다.

- **처음에서 삭제**: 머리를 두 번째 노드로 업데이트합니다.

- **끝에서 삭제**: 끝에서 두 번째 노드까지 순회한 후 그 노드의 `next` 참조를 `None`으로 업데이트합니다.

- **중간에서 삭제**: 대상 노드 바로 전 노드를 찾아 그 노드의 `next` 참조를 대상 노드 다음 노드로 업데이트합니다.

- **값으로 제거**: 순회하면서 이전 노드를 추적합니다. 대상이 머리면 머리를 직접 업데이트합니다. 값을 찾지 못하면 리스트나 길이를 변경하지 않고 반환합니다. 성공적으로 제거한 후에만 길이를 감소시킵니다.

### 보조 공간 복잡도

- **처음에 삽입**: 새 노드 저장 공간 제외하고 O(1) 보조 공간.

- **끝에 삽입**: 새 노드 저장 공간 제외하고 O(1) 보조 공간.

- **중간에 삽입**: 새 노드 저장 공간 제외하고 O(1) 보조 공간.

- **처음에서 삭제**: O(1) 보조 공간.

- **끝에서 삭제**: O(1) 보조 공간.

- **중간에서 삭제**: O(1) 보조 공간.

### 이중 연결 리스트

- **구조**: 각 노드는 데이터와 두 개의 참조를 가집니다: 다음 노드와 이전 노드.

- **순회**: 양방향으로 이동할 수 있습니다.

- **메모리**: 추가 참조 때문에 단일 연결 리스트보다 더 많은 메모리가 필요합니다.

- **꼬리 참조**: 마지막 노드에 대한 참조를 유지하면 이전 참조를 사용해 역방향 순회가 가능합니다.

## 해시 맵과 세트

### 맵과 해시 맵

- **추상 자료형(ADT) 대 구현**: ADT는 자료 구조가 지원하는 연산과 논리적 동작을 명시하는 *인터페이스*를 정의합니다. 구체적 구현은 메모리에서 실제로 그 연산들이 어떻게 만들어지고 실행되는지 보여줍니다.

- **맵(ADT)**: 고유한 키를 값에 매핑하는 컬렉션을 정의하는 추상 자료형입니다. 내부 저장 방식을 규정하지 않고 맵이 할 수 있는 작업의 규칙을 설정합니다.

- **해시 맵**: 해시 함수를 사용해 기본 배열 내 저장 위치를 계산하여 빠른 조회를 제공하는 맵 ADT의 구체적 구현입니다.

### Python 딕셔너리(해시 맵)

```python
# Creating dictionaries
my_dictionary = {
    "A": 1,
    "B": 2,
    "C": 3
}

# Alternative creation
my_dictionary = dict(A=1, B=2, C=3)

# Access and modify
value = my_dictionary["A"]  # 1
my_dictionary["A"] = 4      # Update value
del my_dictionary["A"]      # Remove key-value pair

# Check membership
"C" in my_dictionary

# Get keys, values, items
my_dictionary.keys()
my_dictionary.values()
my_dictionary.items()
```

### 해시 맵의 시간 복잡도

- **평균 경우**: 삽입, 조회, 삭제 모두 O(1)

- **최악 경우**: 해시 충돌이 많을 때 O(n)

### 해시 맵의 보조 공간 복잡도

- **삽입**: 일반 삽입 시 O(1) 추가 공간. 크기 조정 시 O(n) 추가 공간 필요할 수 있음.

- **조회**: O(1) 보조 공간.

- **삭제**: O(1) 보조 공간.

### 세트

- **세트**: 중복 없는 고유 요소의 무순서 집합입니다. 중복 허용하지 않고 특정 순서도 유지하지 않습니다.

- **셋 요소**: 셋은 숫자, 문자열, 숫자와 문자열만 포함하는 튜플을 가질 수 있습니다. 리스트, 딕셔너리, 다른 셋은 셋 요소가 될 수 없습니다. 리스트를 포함하는 튜플은 튜플 자체가 불변이어도 셋 요소가 될 수 없습니다.

```python
# Creating sets
numbers = {1, 2, 3, 4}
empty_set = set()  # Must use set(), not {}

# Add and remove elements
numbers.add(5)
numbers.remove(4)      # Raises KeyError if not found
numbers.discard(4)     # No error if not found

# Remove and return an arbitrary element
numbers.pop()

# Remove all elements
numbers.clear()

# Get the number of elements
len(numbers)
```

### 세트 연산

```python
set_a = {1, 2, 3, 4}
set_b = {2, 3, 4, 5, 6}

# Union, intersection, difference, symmetric difference
set_a.union(set_b)                  # or set_a | set_b
set_a.intersection(set_b)           # or set_a & set_b
set_a.difference(set_b)             # or set_a - set_b
set_a.symmetric_difference(set_b)   # or set_a ^ set_b

# Subset and superset checks
set_a.issubset(set_b)
set_a.issuperset(set_b)
set_a.isdisjoint(set_b)

# Membership testing
5 in numbers
```

### 세트의 시간 복잡도

- **평균 경우**: 추가, 제거, 멤버십 테스트 모두 O(1)

- **최악 경우**: 해시 충돌로 인해 O(n)

- **길이 조회**: `len()`을 사용해 O(1).

### 셋의 보조 공간 복잡도

- **삽입**: 일반 삽입 시 O(1) 추가 공간. 크기 조정 시 O(n) 추가 공간 필요할 수 있음.

- **조회**: O(1) 보조 공간.

- **삭제**: O(1) 보조 공간.

- **길이 조회**: O(1) 보조 공간.

## 해시 충돌

- **해시 충돌**: 서로 다른 키가 같은 해시 값을 생성할 수 있습니다. 해시 테이블에서는 서로 다른 해시 값이 같은 배열 인덱스에 매핑될 때도 충돌이 발생합니다. 같은 인덱스를 공유하는 항목들은 충돌 해결 전략으로 처리해야 합니다.

- **충돌 해결 전략**:

  - **체이닝**: 각 배열 인덱스가 해당 버킷 인덱스에 매핑된 모든 항목을 저장하는 연결 리스트를 가리킵니다.

  - **오픈 어드레싱**: 충돌이 발생하면 미리 정의된 순서를 따라 다음 사용 가능한 배열 인덱스를 찾습니다.

## 각 자료 구조 사용 시기

- **리스트**: 순서가 있고 인덱스 접근이 필요하며 크기를 미리 모를 때 사용하세요.

- **스택**: LIFO 연산(실행 취소 기능, 표현식 평가, 백트래킹)에 사용하세요.

- **큐**: FIFO 연산(작업 스케줄링, 너비 우선 탐색)에 사용하세요.

- **연결 리스트**: 처음에 자주 삽입/삭제하고 크기가 불명확하며 임의 접근이 필요 없을 때 사용하세요.

- **해시 맵**: 빠른 키-값 조회, 발생 횟수 세기, 캐싱에 사용하세요.

- **셋**: 고유성 검사, 수학적 집합 연산, 중복 제거에 사용하세요.
