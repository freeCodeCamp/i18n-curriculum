# --description--

이 워크숍에서는 앱이 업데이트가 필요한지 확인하는 프로그램을 만들어 튜플을 다루는 연습을 하세요.

소프트웨어의 각 릴리스에는 버전 번호가 붙어 릴리스를 구분하고 어느 것이 최신인지 알 수 있습니다. 일반적인 관례는 점으로 구분된 세 개의 숫자를 사용하는 것으로, 형식은 `MAJOR.MINOR.PATCH`입니다:

- `MAJOR` 숫자는 이전 코드나 파일이 새 버전과 호환되지 않을 수 있는 큰 변경이 있을 때 올라갑니다.
- `MINOR` 숫자는 이전 버전과 호환되면서 새로운 기능이 추가될 때 올라갑니다.
- `PATCH` 숫자는 새로운 기능을 추가하지 않는 버그 수정과 같은 작은 수정이 있을 때 올라갑니다.

`2.1.0` 같은 버전은 세 개의 정수인 메이저, 마이너, 패치 숫자를 담은 튜플로 저장할 수 있습니다.

`releases`라는 변수를 만들고 다음 버전 튜플들을 이 순서대로 포함하는 튜플을 할당하세요:

```py
(1, 9, 0), (2, 0, 0), (1, 9, 1), (2, 1, 0),
(2, 1, 1), (2, 2, 0), (1, 9, 2), (2, 2, 1)
```

릴리스는 게시된 순서대로 나열되어 있으며, 가장 낮은 버전부터 높은 버전 순이 아닙니다. 오래된 `1.9` 버전은 `2.0.0` 버전이 나온 후에도 계속 수정되었습니다.
