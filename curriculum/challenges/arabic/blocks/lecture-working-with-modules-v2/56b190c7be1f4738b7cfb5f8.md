# --description--

كما تعلمت في الدرس السابق، الوحدة هي ملف Python يجمع كودًا ذا صلة، بحيث يمكنك إعادة استخدامه في ملفات Python أخرى.

يمكنك أيضًا كتابة وحداتك الخاصة واستيرادها في سكريبتاتك. إنشاء وحداتك الخاصة طريقة رائعة لتنظيم الكود. بدلًا من وجود ملف طويل جدًا، يمكنك تقسيم الكود إلى ملفات أصغر، يجمع كل منها كودًا ذا صلة، ثم تستوردها حيثما تحتاج.

على سبيل المثال، افترض أنك أنشأت ملف `temperature.py` يحتوي على دالتين لتحويل درجات الحرارة، واستدعاء دالة للتحقق من أن إحداها تعمل:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

إذا شغلت هذا الملف مباشرة، سيكون الناتج:

```md
212.0
```

الآن، افترض أنك أنشأت ملفًا آخر اسمه `main.py` في نفس المجلد مع `temperature.py`. لاستخدام الدوال من وحدتك المحلية، تستوردها باستخدام اسم الوحدة بدون امتداد `.py`:

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

إذا شغلت ملف `main.py`، سيكون الناتج:

```md
212.0
100.0
```

عند استيراد `temperature`، ينفذ Python كل الكود في `temperature.py` من الأعلى إلى الأسفل. لهذا السبب يُطبع `212.0`، رغم أن `main.py` يستدعي فقط `fahrenheit_to_celsius()`. عادةً ما يكون هذا النوع من التحقق كودًا تريد تشغيله فقط عند تنفيذ الملف مباشرة، وليس في كل مرة يُستورد فيها.

للتحكم في ذلك، يمكنك استخدام تعبير شائع في Python:

```python
if __name__ == '__main__':
    # Code
```

`__name__` هو متغير مدمج خاص في Python.

عندما يُنفذ ملف Python مباشرة، يعيّن Python قيمة هذه المتغير إلى السلسلة النصية `__main__`.

لكن إذا تم استيراد ملف Python كوحدة في سكريبت Python آخر، تُعيّن قيمة المتغير `__name__` إلى اسم تلك الوحدة (عادة اسم الملف بدون امتداد `.py`).

لهذا السبب تجد غالبًا هذا الشرط في سكريبتات Python. يحتوي على الكود الذي تريد تشغيله **فقط إذا** كان سكريبت Python يعمل كبرنامج رئيسي. إذا استُورد السكريبت كوحدة، لا يُنفذ الكود داخل هذا البلوك.

هذا مفيد لأنه يسمح لسكريبتات Python بأن يكون لها غرضان. يمكن تشغيلها مباشرة لتنفيذ المنطق الرئيسي، أو يمكن استيرادها في وحدة أخرى بدون تنفيذ المنطق الرئيسي.

إليك ملف `temperature.py` محدثًا لاستخدام هذا التعبير. كما يطبع قيمة `__name__`، لتشاهد كيف تتغير:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

إذا شغلت هذا الملف مباشرة، يعيّن Python `__name__` إلى `'__main__'`، فيكون الشرط `True` وينفذ الكود داخل بلوك `if`. هذا هو الناتج:

```md
The value of __name__ is: __main__
212.0
```

إذا شغلت ملف `main.py` بدلًا من ذلك، سيكون الناتج:

```md
The value of __name__ is: temperature
100.0
```

استدعاء `print()` خارج بلوك `if` لا يزال يُنفذ عند استيراد `temperature`، ويُظهر أن قيمة `__name__` الآن هي `temperature`، اسم الوحدة.

لكن بما أن `__name__` لا يساوي `'__main__'`، لا يُنفذ الكود داخل بلوك `if`، لذا لا يُطبع `212.0`. الناتج الوحيد الآخر هو `100.0`، الذي يأتي من استدعاء الدالة في `main.py`.
