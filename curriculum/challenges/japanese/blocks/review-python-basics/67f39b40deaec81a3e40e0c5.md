## Pythonとは何ですか？

- **Python**: Pythonは、そのシンプルさと使いやすさで知られる汎用プログラミング言語です。
- **主な利用例**: Pythonはデータサイエンス、機械学習、ウェブ開発、サイバーセキュリティ、組み込みシステムやIoT、スクリプト作成、自動化、そしてRaspberry PiやMicroPython対応ボードなどのマイクロコンピュータで使われています。

## 変数

- **変数の宣言**: 変数を宣言するには、変数名の後に代入演算子(`=`)を置き、その後に値を代入します。値は数値、文字列、ブール値などが使えます。例をいくつか示します。

```py
name = 'John Doe'
age = 25
```

- **変数名の命名規則**: 変数名には以下の規則があります。

  - 変数名は文字またはアンダースコア（`_`）で始まる必要があり、数字で始めることはできません。
  - 変数名には文字（`a-z`、`A-Z`）、数字（`0-9`）、およびアンダースコア（`_`）を含めることができます。
  - 変数名は大文字と小文字を区別します：`age`、`Age`、`AGE`はすべて異なるものとして扱われます。
  - 変数名はPythonの予約キーワード（`if`、`class`、`def`など）を使うことはできません。
  - 複数単語の変数名はアンダースコアを使い、`snake_case`のようにします。
  - 変数名は目的を説明するものにしてください。例：`user_age`。
  - 意味を伝えない単一文字の変数名は避けることをお勧めします。

## コメント

- **一行コメント**: このタイプのコメントはコード内の短いメモに使います。

```py
# This is a single line comment
```

- **複数行コメント**: 各行の先頭に`#`を使うことで、複数行にわたるコメントを作成できます。

```py
# This is a multi-line comment.
# Here is some code commented out.
#
# name = 'John Doe'
# age = 25
```

## 出力

- **`print()` 関数**: ターミナルにデータを出力するには、`print()` 関数を次のように使います。

```py
print('Hello world!') # Hello world!
```

`print()` に複数の引数を渡す場合は、カンマで区切ってください。デフォルトでは、`print()` は表示される値の間にスペースを挿入します。

```py
print('Hello', 'world!') # Hello world!
```

## Pythonの一般的なデータ型

- **動的型付け**: Pythonは動的型付け言語であり、変数のデータ型を宣言する必要はありません。Pythonは変数に代入された値から型を判断します。

- **整数**: 小数点を含まない整数の数値です：

```py
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- **浮動小数点数**: 小数点を含む数値です。

```py
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- **文字列**: 引用符で囲まれた文字の並びです。

```py
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- **ブール値**: `True`または`False`を表す値です。

```py
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Pythonには他にもデータ型があります。必要になったときにそれぞれ学びます。

- **`type()` 関数**: 変数の型を確認するには、`type()` 関数を次のように使います。

```py
greeting = 'Hello there!'
age = 21

print(type(greeting)) # <class 'str'>
print(type(age)) # <class 'int'>
```

- **`isinstance()`関数**: 変数が特定のデータ型かどうかをチェックするのに使います。

```py
greeting = 'Hello world'
name = 'John Doe'

print(isinstance(greeting, str)) # True
print(isinstance(name, int)) # False
```

複数の型をチェックする場合は、型を丸括弧で囲み、カンマで区切って2番目の引数として渡します。値がリスト内のいずれかの型のインスタンスであれば結果は`True`になります：

```py
account_balance = 12
print(isinstance(account_balance, (int, float))) # True
```

## 文字列の操作

- **文字列**: 文字列は文字のシーケンスです。Pythonではシングルクォートかダブルクォートのどちらかを使えます。どちらか一方のスタイルを選び、一貫して使ってください：

```py
developer = 'Jessica'
city = "Los Angeles"
```

- **複数行文字列**: トリプルシングルクオートまたはトリプルダブルクオートを使うと、文字列を複数行にまたがって記述できます。

```py
message = """Hello
world!"""
print(message)
# Hello
# world!
```

- **文字列内の引用符**: 文字列の引用符をエスケープしたくない場合は、文字列の周りに反対の種類の引用符を使うことができます。

```py
msg = "It's a sunny day"
quote = 'She said, "Hello!"'
```

- **文字列のエスケープ**: 文字列に引用符が含まれる場合はバックスラッシュ(`\`)を使います。

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **エスケープシーケンス**: バックスラッシュと他の文字を組み合わせて特殊文字を表現できます。例えば、`\n`は改行、`\t`はタブ、`\\`はバックスラッシュ1つを表します：

```py
print('Hello\nworld')
# Hello
# world

print('Name:\tAlice')  # Name:   Alice
print('C:\\Users\\Alice')  # C:\Users\Alice
```

- **`in`演算子**: 文字列に指定した文字が存在するかどうかを示すブール値を返します。

```py
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

- **文字列の長さを取得する**: `len()` 関数は文字列の文字数を返します。

```py
developer = 'Jessica'

print(len(developer)) # 7
```

- **文字列の文字にアクセスする**: ブラケット記法を使って文字列の文字にアクセスできます。

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **再代入と不変性**: 文字列は不変であり、一度作成された後は変更できません。変数に再代入すると別の値を参照するようになりますが、元の文字列は変更されません：

```py
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello
```

文字列を直接変更することはできません。

```py
greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```

整数、浮動小数点数、ブール値も不変です。

- **文字列の連結**: 文字列を連結するには`+`演算子を使います。

```py
developer = 'Jessica'
print('My name is ' + developer + '.') # My name is Jessica.
```

- **文字列の繰り返し**: `*` 演算子は文字列を指定した回数だけ繰り返します。

```py
print('ha' * 3) # hahaha
```

- **文字列と数値の連結**: 文字列と数値を連結すると `TypeError` が発生します。

```py
'Age: ' + 26 # TypeError: can only concatenate str (not "int") to str
```

`str()` 関数は数値を文字列に変換して連結できるようにします。

```py
print('Age: ' + str(26)) # Age: 26
```

もう1つの連結方法は`+=`演算子を使うことです。これは連結と代入を同時に行います。

```py
greeting = 'My name is '
developer = 'Jessica.'

greeting += developer
print(greeting) # My name is Jessica.
```

`*=`演算子は文字列を指定回数繰り返し、その結果を変数に代入します：

```py
sound = 'ha'
sound *= 3
print(sound) # hahaha
```

`+=`と`*=`の両方は元の文字列を変更せず、新しい文字列を変数に代入します。

- **`f-strings`**: これはフォーマット済み文字列リテラルの略称で、補間や連結を簡潔で読みやすい構文で行えます。

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

f-strings の置換フィールドには式を含めることができます。Python はその式を評価し、その値を文字列に挿入します。

```py
num1 = 5
num2 = 10
print(f'The sum is {num1 + num2}') # The sum is 15
```

- **文字列のスライス**: 文字列の一部を抽出することです。基本構文は以下の通りです。

```py
str[start:stop:step]
```

`start` インデックスは抽出を開始する位置を指定します。`stop` インデックスは含まれないため、その位置の文字は含まれません。`step` は選択するインデックス間の間隔を指定し、デフォルトは `1` です。正の `step` の場合、`start` を省略すると文字列の先頭が、`stop` を省略すると文字列の末尾がデフォルトになります。`[:]` は文字列全体を抽出し、`[::-1]` は最後の文字から最初の文字へ逆方向にステップして文字列を反転します。スライスは元の文字列を変更しません。

```py
message = 'Python is fun!'

print(message[0:6])  # Python
print(message[:6])  # Python
print(message[7:])  # is fun!
print(message[::2])  # Pto sfn
print(message[:])  # Python is fun!
print(message[::-1])  # !nuf si nohtyP
```

## よく使う文字列メソッド

- **メソッド**: メソッドとは、値に対して呼び出す関数のことです。文字列のメソッドを呼び出すには、文字列またはその変数名の後にドットを付けてメソッドを呼び出します。

- **`str.upper()`**: すべての文字を大文字に変換した新しい文字列を返します：

```py
developer = 'Jessica'

print(developer.upper()) # JESSICA
```

- **`str.lower()`**: すべての文字を小文字に変換した新しい文字列を返します：

```py
developer = 'Jessica'

print(developer.lower()) # jessica
```

- **`str.strip()`**: 指定した先頭と末尾の文字を削除した文字列のコピーを返します（引数なしの場合は空白文字を削除）。

```py
greeting = '  hello world  '

trimmed_my_str = greeting.strip()
print(trimmed_my_str)  # hello world
```

- **`replace()`**: 古い文字列を新しい文字列にすべて置き換えた新しい文字列を返します。

```py
greeting = 'hello world'

replaced_my_str = greeting.replace('hello', 'hi')
print(replaced_my_str)  # hi world
```

- **`split()`**: 指定した区切り文字で文字列をリストに分割するために使います。区切り文字は分割する位置を指定する文字列です。区切り文字を指定しない場合、`split()` は空白で分割します。

```py
dashed_name = 'example-dashed-name'

split_words = dashed_name.split('-')
print(split_words)  # ['example', 'dashed', 'name']
```

- **`join()`**: これは文字列の集合を区切り文字でつなげて一つの文字列にするために使います。

```py
example_list = ['example', 'dashed', 'name']

joined_str = ' '.join(example_list)
print(joined_str)  # example dashed name
```

- **`str.startswith(prefix)`**: 指定した接頭辞で文字列が始まるかどうかを示すブール値を返します：

```py
developer = 'Naomi'

result = developer.startswith('N')
print(result)  # True
```

- **`str.endswith(suffix)`**: 指定した接尾辞で文字列が終わるかどうかを示すブール値を返します：

```py
developer = 'Naomi'

result = developer.endswith('N')
print(result)  # False
```

- **`str.find()`**: 部分文字列が最初に現れるインデックスを返します。見つからなければ `-1` を返します。

```py
developer = 'Naomi'

result = developer.find('N')
print(result)  # 0

city = 'Los Angeles'
print(city.find('New')) # -1
```

- **`str.count(substring)`**: これは、文字列内に部分文字列が重ならずに何回現れるかを数えます。マッチが見つかると、そのマッチの終わりの後から検索を続けます。

```py
city = 'Los Angeles'
print(city.count('e')) # 2

# Matches do not overlap, so this is 2, not 3
print('aaaa'.count('aa')) # 2
```

- **`str.capitalize()`**: 最初の文字を大文字にし、他の文字を小文字にした新しい文字列を返します：

```py
dessert = 'chocolate cake'
print(dessert.capitalize()) # Chocolate cake
```

- **`str.isupper()`**: 文字列に少なくとも1つの大文字が含まれ、すべての大文字が大文字の場合に `True` を返します。そうでなければ `False` を返します。

```py
dessert = 'chocolate cake'
print(dessert.isupper()) # False
```

- **`str.islower()`**: 文字列に少なくとも1つの小文字が含まれ、すべての小文字が小文字の場合に `True` を返します。そうでなければ `False` を返します。

```py
dessert = 'chocolate cake'
print(dessert.islower()) # True
```

- **`str.title()`**: 各単語の最初の文字を大文字にし、残りの文字を小文字にした新しい文字列を返します：

```py
city = 'lOS aNGELES'
print(city.title()) # Los Angeles
```

## さらに文字列操作

- **負のスライス境界**: スライスの境界は文字列の末尾から逆方向に数えることができます。例えば、`[-3:]`は末尾の3文字を抽出します：

```py
employee_code = 'DEV-2026-JD-001'
print(employee_code[-3:]) # 001
```

- **メソッドチェーン**: 複数の文字列メソッドを1つの式で連続して呼び出せます。各メソッドは前の呼び出しの結果に対して動作します：

```py
name = '  jANE dOE  '
print(name.strip().title()) # Jane Doe
```

## 整数と浮動小数点数で使う一般的な操作

- **基本的な数学演算**: Pythonでは、整数と浮動小数点数を使って加算、減算、乗算、除算などの基本的な数学演算ができます。

```py
int_1 = 56
int_2 = 12
float_1 = 5.4
float_2 = 12.0

# Addition

print('Integer Addition:', int_1 + int_2) # Integer Addition: 68
print('Float Addition:', float_1 + float_2) # Float Addition: 17.4

# Subtraction

print('Int Subtraction:', int_1 - int_2) # Int Subtraction: 44
print('Float Subtraction:',  float_2 - float_1) # Float Subtraction: 6.6

# Multiplication

print('Int Multiplication:', int_1 * int_2) # Int Multiplication: 672
print('Float Multiplication:', float_2 * float_1) # Float Multiplication: 64.80000000000001

# Division

print('Division:', int_1 / int_2) # Division: 4.666666666666667
print('Float Division:', float_2 / float_1) # Float Division: 2.222222222222222
```

浮動小数点数と整数を加算すると結果は浮動小数点数になります。

```py
int_1 = 56
float_1 = 5.4

print(int_1 + float_1) # 61.4
```

- **剰余演算子（`%`）**: ある数を別の数で割った余りを返します。

```py
int_1 = 56
int_2 = 12

print(int_1 % int_2) # 8
```

- **切り捨て除算（`//`）**: 2つの数を割り、結果を小数点以下切り捨てで整数にします。

```py
int_1 = 56
int_2 = 12

print(int_1 // int_2) # 4
```

- **べき乗演算子（`**`）**: 数値を別の数のべき乗にします。

```py
int_1 = 4
int_2 = 2

print(int_1 ** int_2) # 16
```

- **浮動小数点の近似**: 一部の10進分数は2進数で正確に表現できないため、有限の近似値として保存されます。これにより、上記の`64.80000000000001`のような小さな丸め誤差が生じることがあります。

```py
print(0.1 + 0.2) # 0.30000000000000004
```

- **`float()`関数**: 整数や有効な10進文字列を浮動小数点数に変換したり、有限の整数や浮動小数点数より大きい正の無限大を表す特別な浮動小数点値を作成したりできます：

```py
num = 4

print(float(num)) # 4.0
print(float('7.8')) # 7.8
print(float('inf')) # inf
```

- **`int()`関数**: 浮動小数点数を整数に変換します。

```py
num = 4.0

print(int(num)) # 4
```

- **`round()`関数**: 引数が1つの場合は数値を最も近い整数に丸めます。2つ目の引数を渡すと小数点以下の桁数を指定できます：

```py
num_1 = 3.4
num_2 = 7.7

print(round(num_1)) # 3
print(round(num_2)) # 8
print(round(3.14159, 2)) # 3.14
```

- **`abs()`関数**: 数値の絶対値を返します。

```py
num = -13

print(abs(num)) # 13
```

- **`pow()`関数**: 数値を別の数値のべき乗にします。整数引数の場合、3つ目の非ゼロ引数を渡すと結果をその値で割った余りを計算します：

```py
result = pow(2, 3)
print(result)  # 8
print(pow(2, 3, 5)) # 3
```

## 複合代入

- **複合代入**: 複合代入は変数に対して演算を行い、その結果を同じ変数に一度に代入します。

```py
# Addition assignment
my_var = 10
my_var += 5

print(my_var) # 15

# Subtraction assignment
count = 14
count -= 3

print(count) # 11

# Multiplication assignment
product = 65
product *= 7

print(product) # 455

# Division assignment
price = 100
price /= 4

print(price) # 25.0

# Floor Division assignment
total_pages = 23
total_pages //= 5

print(total_pages) # 4

# Modulo assignment
bits = 35
bits %= 2

print(bits) # 1

# Exponentiation assignment
power = 2
power **= 3

print(power) # 8
```

## 比較演算子

- **等しい（`==`）**: 2つの値が等しいかチェックします。

```py
print(3 == 4) # False
```

- **等しくない（`!=`）**: 2つの値が等しくないかチェックします。

```py
print(3 != 4) # True
```

- **より大きい（`>`）**: 1つの値がもう1つより大きいかチェックします。

```py
print(3 > 4) # False
```

- **より小さい（`<`）**: 1つの値がもう1つより小さいかチェックします。

```py
print(3 < 4) # True
```

- **以上（`>=`）**: ある値が別の値以上かどうかをチェックします。

```py
print(3 >= 4) # False
```

- **以下（`<=`）**: ある値が別の値以下かどうかをチェックします。

```py
print(3 <= 4) # True
```

## `if`、`elif`、および `else` 文の使い方

- **コードブロックとインデント**: Pythonはインデントで文をブロックにまとめます。関数や条件文の本体などが該当します。同じブロック内の文は同じインデントレベルを使う必要があります。慣例として1レベルにつき4つのスペースを使います。

- **`pass`文**: `pass`は何もしません。Pythonが文を必要とする場所で、例えば空の条件文の本体などにプレースホルダーとして使います：

```py
age = 18
if age >= 18:
    pass
```

- **`if`文**: `if`文は条件が真と評価された場合にその本体を実行します。

```py
age = 18

if age >= 18:
    print('You are an adult') # You are an adult
```

- **`else`節**: `else`節は同じ`if...elif...else`チェーン内のすべての前の条件が偽と評価された場合に本体を実行します。

```py
age = 12

if age >= 18:
    print('You are an adult')
else:
    print('You are not an adult yet') # You are not an adult yet
```

- **`elif`節**: `elif`節は同じチェーン内の前の条件がすべて偽と評価された場合に別の条件をテストします。自身の条件が真と評価された場合に本体を実行します。

```py
age = 16

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')  # You are a teenager
```

ネストされた`if`文も使えます。

```py
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

## 真値と偽値

- **真偽値**: Pythonではすべての値に固有のブール値があり、論理的な文脈で`True`または`False`として扱われます。多くの値は真値（論理的に`True`と評価される）であり、他は偽値（`False`と評価される）です。以下は偽値の例です：

```md
False
None
Integer 0
Float 0.0
Empty strings ''
```

非ゼロの数値や空でない文字列は真値です。

## `bool()`関数の使い方

- **`bool()`関数**: 値が真値か偽値かを調べたい場合、組み込みの`bool()`関数を使えます。値を明示的にブール値に変換し、真値なら`True`、偽値なら`False`を返します。いくつかの例を示します：

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

## ブール演算子とショートサーキット

- **ブール演算子**: これらは複数の式を組み合わせてより複雑な意思決定ロジックを作るための特別な演算子です。Pythonには3つのブール演算子があります：`and`、`or`、`not`。
- **`and`演算子**: 2つのオペランドを取り、最初のオペランドが偽値ならそれを返し、そうでなければ2番目のオペランドを返します。式が真値になるには両方のオペランドが真値である必要があります。

```py
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

条件文で`and`演算子も使えます。

```py
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

- **`or` 演算子**: この演算子は最初のオペランドが真値の場合はそれを返し、そうでなければ2番目のオペランドを返します。`or` 式は少なくとも1つのオペランドが真値であれば真値になります。以下は例です。

```py
age = 19
is_employed = False

print(age or is_employed) # 19
```

`and`演算子と同様に、条件文で`or`演算子も使えます。

```py
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

- **ショートサーキット**: `and`と`or`演算子はショートサーキット演算子と呼ばれます。左から右に値をチェックし、結果が確定した時点で評価を停止します。
- **`not`演算子**: 1つのオペランドを取り、そのブール値を反転します。真値を`False`に、偽値を`True`に変換します。前述の演算子とは異なり、`not`は常に`True`か`False`を返します。例を示します。

```py
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

条件文での`not`演算子の例です。

```py
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

## 同一性演算子

- **同一性と等価性**: 変数はオブジェクトを参照します。`is`演算子は2つのオペランドが同じオブジェクトを参照しているかをチェックし、`is not`は異なるオブジェクトを参照しているかをチェックします。`==`と`!=`は値を比較します。数値や文字列の比較には等値演算子を使ってください。
- **`None`と`NoneType`**: `None`は値の不在を表し、`NoneType`型の唯一の値です。
- **シングルトン**: `None`、`True`、`False`はそれぞれシングルトンであり、各々に対して正確に1つのオブジェクトがあります。同一性演算子でこれらのオブジェクトをチェックできます。
- **`None`のチェック**: 値が存在しないかを調べるには`is None`を使い、存在するかを調べるには`is not None`を使います。`None`と`False`はどちらも偽値ですが、異なるオブジェクトです：

```py
response = False

print(response is None) # False
print(response is not None) # True
print(response is True) # False
print(response is False) # True
```

- **同一性と真偽値**: `response`が`True`、`False`、または`None`のいずれかの場合、`response is None`は回答が欠けていることを否定的な回答と区別します。`not response`は`False`と`None`の両方を同じように扱います。通常のブールフラグには`if is_ready`や`if not is_ready`を使い、ブールオブジェクトを他の値と区別したい場合は`is True`や`is False`を使ってください。

## ブール演算子の優先順位

- **演算子の優先順位と丸括弧**: `and` と `or` が同じ式に現れる場合、`and` の方が `or` より優先順位が高いです。つまり、`and` が先にオペランドをまとめるため、`True or False and False` は `True or (False and False)` としてグループ化されます。

```py
print(True or False and False) # True
```

`or` の左オペランドは `True` なので、ショートサーキットにより `False and False` は評価されず、結果は `True` になります。

丸括弧を使ってグループ化を変えることができます。ここでは `True or False` が一緒にグループ化されて `True` と評価され、その後 `True and False` が評価されて `False` になります。

```py
print((True or False) and False) # False
```

## よく使う組み込み関数

- **`input()`関数**: ユーザーからの入力を促すのに使います。

```py
name = input('What is your name?') # User types 'Kolade' and presses Enter
print('Hello', name) # Hello Kolade
```

- **`int()` 関数**: これは、数値、ブール値、または整数を表す文字列を整数に変換するために使います。

```py
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0

# A string representing a decimal number cannot be converted directly
# int('3.14') raises a ValueError
```

## 関数の使い方

- **関数**: 関数は呼び出すと実行される再利用可能なコードの塊です。関数を呼び出すには、関数名の後に丸括弧を付けて参照します：

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

- **パラメータと引数**: パラメータは関数定義に記載された名前で、上記の例では`num_1`や`num_2`です。引数は関数呼び出し時に渡される値で、例では`3`や`4`です。

引数の数が正しくない場合、`TypeError`が発生します。

```py
def calculate_sum(a, b):
    print(a + b)

calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

- **位置引数**: これらの引数は関数呼び出しでの位置によってパラメータに対応します。

```py
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

- **キーワード引数**: これらの引数は`name=value`の形式でパラメータ名に対応し、パラメータの順序と異なる順序で渡すことができます：

```py
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

- **引数の組み合わせ**: 位置引数はキーワード引数の前に来る必要があります。各パラメータは1つの値しか受け取れません：

```py
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

- **`return`文**: `return`文は関数を終了させ、呼び出し元に値を返します。

- **`None`**: `None`は値の不在を表します。関数が明示的に値を返さない場合、戻り値はデフォルトで`None`になります：

```py
def greet():
    print('hello')

result = greet() # hello
print(result) # None
```

## Pythonのスコープ

Pythonには追加のスコープルールがあります。ここではローカルスコープとグローバルスコープにフォーカスしてください。

- **グローバルスコープ**: 関数の外で作成された変数は関数の内外で使えます。

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + (subtotal * tax)
    return total

print(get_total(100))  # 170.0
```

- **ローカルスコープ**: 関数内で作成された変数はその関数内でのみ使えます。関数のパラメータもローカル変数です。

```py
def my_func():
    num = 10
    print(num)
```

- **引数の渡し方とパラメータの再代入**: Pythonは代入によって引数を渡します。パラメータは最初に渡されたオブジェクトを参照するローカル名であり、オブジェクトは自動的にコピーされません。パラメータを再代入しても、渡された引数の変数は再代入されません：

```py
def double_number(number):
    number = number * 2
    print(number) # 20

original = 10
double_number(original)
print(original) # 10
```

## 関数とスコープの適用

- **空の関数本体**: 関数本体に`pass`をプレースホルダーとして使えます。`pass`だけの関数は暗黙的に`None`を返します：

```py
def placeholder():
    pass

print(placeholder()) # None
```

- **名前のシャドウイング**: ローカルのパラメータや変数がグローバル変数と同じ名前の場合、関数はローカル名を使います。そのローカルパラメータを再代入してもグローバル変数は変わりません：

```py
available_eggs = 5

def use_eggs(available_eggs, eggs_to_use):
    available_eggs -= eggs_to_use
    return available_eggs

print(use_eggs(available_eggs, 1)) # 4
print(available_eggs) # 5
```

- **早期リターン**: `return`文は関数を即座に終了させ、呼び出し元に値を返します。条件が満たされたときに早く戻るために使えます：

```py
def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        return available_eggs
    return available_eggs - eggs_to_use

print(use_eggs(2, 3)) # 2
print(use_eggs(2, 1)) # 1
```

- **関数から他の関数を呼び出す**: 関数は別の関数を呼び出し、その結果を使ったり返したりできます：

```py
def use_eggs(available_eggs, eggs_to_use):
    return available_eggs - eggs_to_use

def make_fried_egg(available_eggs):
    return use_eggs(available_eggs, 1)

print(make_fried_egg(3)) # 2
```

- **戻り値の代入**: 新しい値を返しても引数として渡された変数は自動的に更新されません。更新するには戻り値をその変数に代入してください：

```py
available_eggs = use_eggs(available_eggs, 1)
print(available_eggs) # 4
```

## 文字列の変換

- **`str.maketrans()`**: `str.maketrans()`の2つの文字列形式は、同じ長さの文字列を取り、最初の文字列の各文字を2番目の文字列の対応する文字にマッピングします。テーブルは文字をUnicodeの序数（ユニークな番号）として保存します。`translate()`メソッドはテーブルを文字列に適用し、新しい文字列を返します。テーブルに含まれない文字は変更されません。

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc!'.translate(trans_table)
print(result)  # 123123!
```

## 整数引数の検証

- **ブール値と整数**: Pythonはブール値を特別な整数として扱うため、`isinstance(True, int)`と`isinstance(False, int)`はどちらも`True`を返します。ブール値であってはならない整数を検証する場合は、明示的にブール値を除外してください：

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True

value = True
print(isinstance(value, int) and not isinstance(value, bool)) # False

value = 5
print(isinstance(value, int) and not isinstance(value, bool)) # True
```

## デフォルトパラメータ値

- **デフォルトパラメータ**: パラメータにデフォルト値を指定できます。関数呼び出し時に引数を省略すると、そのデフォルト値が使われます：

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```
