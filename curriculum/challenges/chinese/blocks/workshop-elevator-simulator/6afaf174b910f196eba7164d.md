# --description--

只要还有请求，电梯就应该继续服务。`while` 循环非常适合这个场景，因为只要条件为真，它就会重复执行。这里是语法的提醒：

```py
while condition:
    # code to repeat
    ...
```

非空列表为真，空列表为假，所以你可以用列表作为循环的条件，让它运行直到列表为空。

创建一个 `while` 循环，只要 `requests` 不为空就运行。在循环内部，使用 `pop(0)` 从 `requests` 中移除第一个请求，并赋值给名为 `target` 的变量。然后，打印 `target`。

由于每次迭代 `pop(0)` 都会使列表变短，列表最终会变为空，循环也会停止。否则，条件永远不会变为假，循环将永远运行。
