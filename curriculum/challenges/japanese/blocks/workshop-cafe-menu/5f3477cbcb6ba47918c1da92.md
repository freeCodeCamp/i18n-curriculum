# --description--

ページのスタイルをモバイルでもデスクトップやノートパソコンと似た見た目にするには、特別な`content`属性を持つ`meta`要素を追加する必要があります。

ビューポートの`meta`要素は、特に携帯電話やタブレットなどの異なるデバイスでページの寸法や拡大縮小をどのように制御するかについてブラウザーに指示を与えます。以下はその例です：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

`width=device-width`の部分は、ページの幅をデバイスの画面幅に合わせるようブラウザーに指示します。`initial-scale=1.0`はページが最初に読み込まれたときの初期ズームレベルを設定します。値が`1.0`の場合、ページは`100%`のズームで表示され、拡大縮小はされません。

この要素がないと、モバイルブラウザーは通常、デスクトップの画面幅でページをレンダリングし、それを縮小するため、文字が非常に小さく読みづらくなることがあります。

# --hints--

コードには`meta`要素が2つあるはずです。

```js
assert.lengthOf(document.querySelectorAll('meta'), 2);
```

`meta`要素には、値が`viewport`の`name`属性が必要です。

```js
assert.exists(document.querySelector('meta[name="viewport"]'));
```

`meta`要素には、値が`width=device-width, initial-scale=1.0`の`content`属性が必要です。

```js
assert.equal(document.querySelector('meta[name="viewport"]')?.getAttribute('content'), 'width=device-width, initial-scale=1.0');
```
