# --description--

`key` が `node.key` より小さくも大きくもない場合、削除するノードが見つかったことになります。削除方法はその子ノードによって異なります。

ノードに左の子がいなければ、右の子がその位置を引き継げます。これは子がいないノードにも当てはまります。その場合、`node.right` も `None` なので、ノードは `None` に置き換えられます。

2つ目の `if` 文に `else` 節を追加してください。その中に、`node.left` が `None` かどうかをチェックする `if` 文を追加し、そこから `node.right` を返してください。
