# --description--

并非每个讲师都有 `email` 属性。对于没有此属性的讲师，赋值给 `instructorsByEmail[instructor.email]` 会创建一个键为字符串 `"undefined"` 的条目。

在添加 `if` 块之前，删除上一步中的 `console.log(instructorsById[instructor.id])`。

添加一个 `if (instructor.email)` 块。在其中，将 `instructor.id` 赋值给 `instructorsByEmail[instructor.email]`。这个表格让你可以通过电子邮件查找讲师的 ID，然后检索该讲师的记录。
