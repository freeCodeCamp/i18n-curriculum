## Array

- **Array statici**: hanno una dimensione fissa determinata all'inizializzazione. Gli elementi sono archiviati in posizioni di memoria adiacenti, il che rende molto efficiente consultarli. La loro dimensione non può essere modificata mentre il programma è in esecuzione.

- **Array dinamici**: possono crescere o ridursi automaticamente mentre il programma è in esecuzione. Quando l'array è pieno, i suoi elementi vengono copiati in un nuovo array più grande. La nuova dimensione è scelta in modo che queste costose copie avvengano meno frequentemente.

- **Array statici in Python**: Python non include array statici tradizionali come strutture dati integrate. Altri linguaggi, come Java, li supportano.

### Liste Python (array dinamici)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### Complessità temporali per array dinamici

- **Consultare**: O(1)
- **Inserire alla fine**: O(1) se c'è spazio disponibile, O(n) quando è necessario ridimensionare
- **Inserire in mezzo**: O(n) perché gli elementi successivi devono essere spostati

### Scegliere tra array statici e dinamici

- **Array statici**: quando conosci il numero di elementi in anticipo e devi consultarli frequentemente.
- **Array dinamici**: quando il numero di elementi è sconosciuto o cambia nel tempo, o quando inserirai e rimuoverai elementi frequentemente.

## Stack

- **Stack**: struttura dati Last-In, First-Out (LIFO). Gli stack hanno due estremità, cima e fondo. Gli elementi vengono aggiunti e rimossi solo dalla cima.

- **Operazione push**: aggiungere un elemento in cima allo stack. Usando una lista Python, questo richiede tempo O(1) se c'è spazio disponibile, o O(n) quando è necessario ridimensionare.

- **Operazione pop**: rimuovere un elemento dalla cima dello stack. Complessità temporale: O(1). Complessità spaziale: O(1).

```python
# Using a Python list as a stack, where the end of the list is the top
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operation
top_element = stack.pop()  # Returns 3
```

## Code

- **Code**: struttura dati First-In, First-Out (FIFO). Le code hanno due estremità, fronte e retro. Gli elementi vengono aggiunti al retro e rimossi dal fronte.

- **Operazione enqueue**: aggiungere un elemento al retro della coda. Usando una lista Python, questo richiede tempo O(1) se c'è spazio disponibile, o O(n) quando è necessario ridimensionare.

- **Operazione dequeue**: rimuovere un elemento dal fronte della coda. L'elemento successivo diventa il nuovo fronte. Complessità temporale: O(1). Complessità spaziale: O(1).

```python
# Using a Python list as a queue, where the start of the list is the front
queue = []

# Enqueue operations
queue.append(1)
queue.append(2)
queue.append(3)

# Front element
front_element = queue[0]  # 1

# Dequeue operation
front_element = queue.pop(0)  # Returns 1
```

- **Nota**: rimuovere il primo elemento di una lista Python con `.pop(0)` sposta tutti gli elementi rimanenti, quindi richiede tempo O(n).

## Liste concatenate

- **Liste concatenate**: struttura dati lineare in cui ogni nodo archivia dati e un riferimento al nodo successivo. I nodi sono collegati come una catena. Le liste concatenate non hanno dimensione fissa e possono crescere o ridursi aggiornando i collegamenti tra i nodi.

- **Usi comuni**: implementare altre strutture dati, come stack, code e deque, e algoritmi su grafi come la ricerca in profondità e la ricerca in ampiezza.

### Liste concatenate singole

- **Struttura**: ogni nodo archivia dati e un riferimento al nodo successivo.
- **Attraversamento**: si può muovere solo in avanti, dalla testa alla coda.
- **Nodo testa**: primo nodo della lista, solitamente l'unico nodo accessibile direttamente. L'attraversamento inizia qui.
- **Nodo coda**: ultimo nodo della lista. Il suo riferimento al nodo successivo è `None`, che segna la fine della lista.

#### Inserimento di nodi

- **Inserire all'inizio**: O(1) - collega il nuovo nodo alla vecchia testa e rendilo la nuova testa
- **Inserire alla fine**: O(n) - devi attraversare fino alla fine, poi collegare la coda al nuovo nodo
- **Inserire in mezzo**: O(n) - devi attraversare fino alla posizione, poi collegare il nodo precedente al nuovo nodo e il nuovo nodo a quello successivo
- **Complesso spaziale**: O(1) - viene creato solo il nuovo nodo

#### Rimozione di nodi

- **Rimuovere dall'inizio**: O(1) - rendi il nodo successivo la nuova testa
- **Rimuovere in mezzo**: O(n) - devi attraversare fino al nodo, poi collegare il nodo precedente a quello successivo, formando un "ponte" sopra il nodo rimosso
- **Rimuovere dalla fine**: O(n) - devi attraversare fino alla fine, poi rimuovere il collegamento del nodo precedente, rendendolo la nuova coda
- **Complesso spaziale**: O(1) - non è richiesta memoria aggiuntiva

### Liste concatenate doppie

- **Struttura**: ogni nodo archivia dati e due riferimenti: uno al nodo successivo e uno al nodo precedente.
- **Attraversamento**: si può muovere in entrambe le direzioni.
- **Riferimento alla coda**: è comune mantenere un riferimento al nodo coda nella lista stessa. Questo permette di aggiungere nodi alla fine in tempo O(1), senza attraversare la lista, e di iniziare un attraversamento dalla fine.
- **Inserimento e rimozione**: funzionano come nelle liste concatenate singole, ma devono essere aggiornati due riferimenti per nodo.
- **Memoria**: richiede più memoria rispetto alle liste concatenate singole perché ogni nodo archivia due riferimenti invece di uno.

## Quando usare ogni struttura dati

- **Array statici**: quando il numero di elementi è noto in anticipo e serve un accesso veloce e frequente
- **Array dinamici (liste)**: quando serve un accesso ordinato e indicizzato e non si conosce la dimensione in anticipo
- **Stack**: quando l'ultimo elemento aggiunto deve essere il primo rimosso (LIFO)
- **Code**: quando gli elementi devono essere processati nell'ordine in cui sono stati aggiunti (FIFO)
- **Liste concatenate singole**: quando la dimensione cambia spesso e si inserisce o rimuove principalmente all'inizio
- **Liste concatenate doppie**: quando serve attraversare in entrambe le direzioni o aggiungere elementi alla fine in modo efficiente, e la memoria extra per nodo è accettabile
