## Lavorare con HTML, CSS e JavaScript

Mentre HTML e CSS forniscono la struttura del sito web, JavaScript aggiunge interattività ai siti permettendo funzionalità complesse, come gestire l’input dell’utente, animare elementi e persino costruire applicazioni web complete.

## Tipi di dati in JavaScript

I tipi di dati aiutano il programma a capire che tipo di dati sta gestendo, che sia un numero, un testo o altro.

- **Number**: Un numero rappresenta sia numeri interi sia valori a virgola mobile. Esempi di numeri interi sono 7, 19 e 90.  
- **Virgola mobile**: Un numero a virgola mobile è un numero con un punto decimale. Esempi sono 3.14, 0.5 e 0.0001.  
- **Stringa**: Una stringa è una sequenza di caratteri, o testo, racchiusa tra virgolette. `"I like coding"` e `'JavaScript is fun'` sono esempi di stringhe.  
- **Booleano**: Un booleano rappresenta uno dei due valori possibili: `true` o `false`. Puoi usare un booleano per rappresentare una condizione, come `isLoggedIn = true`.  
- **Undefined e Null**: Un valore `undefined` è una variabile dichiarata ma non assegnata a un valore. Un valore `null` è un valore vuoto, o una variabile a cui è stato intenzionalmente assegnato il valore `null`.  
- **Oggetto**: Un oggetto è una raccolta di coppie chiave-valore. La chiave è il nome della proprietà, e il valore è il valore della proprietà.

Ad esempio, `{ name: "Fluffy", age: 3, type: "dog" }` ha tre proprietà: `name`, `age` e `type`.

- **Symbol**: Il tipo di dato Symbol è un valore unico e immutabile che può essere usato come identificatore per le proprietà degli oggetti.

Due simboli creati con la stessa descrizione sono comunque valori distinti.

- **BigInt**: Quando un numero è troppo grande per il tipo di dato `Number`, puoi usare il tipo di dato BigInt per rappresentare numeri interi di lunghezza arbitraria.

Aggiungendo un `n` alla fine del numero, puoi creare un BigInt.

## Variabili in JavaScript

- Le variabili possono essere dichiarate usando la parola chiave `let`.

- Per assegnare un valore a una variabile, puoi usare l'operatore di assegnazione `=`.

- Le variabili dichiarate usando `let` possono essere riassegnate con un nuovo valore.

- Oltre a `let`, puoi anche usare `const` per dichiarare una variabile. Tuttavia, una variabile `const` non può essere riassegnata con un nuovo valore.

- Le variabili dichiarate usando `const` sono usate per dichiarare costanti, che non possono cambiare durante tutto il codice, come `PI` o `MAX_SIZE`.

## Convenzioni per la denominazione delle variabili

- I nomi delle variabili dovrebbero essere descrittivi e significativi.
- I nomi delle variabili dovrebbero essere in camelCase come `cityName`, `isLoggedIn` e `veryBigNumber`.
- I nomi delle variabili non dovrebbero iniziare con un numero. Devono cominciare con una lettera, `_` o `$`.
- I nomi delle variabili non dovrebbero contenere spazi o caratteri speciali, tranne `_` e `$`.
- I nomi delle variabili non devono essere parole chiave riservate.
- I nomi delle variabili fanno distinzione tra maiuscole e minuscole. `age` e `Age` sono variabili diverse.

## Stringhe e immutabilità delle stringhe in JavaScript

- Le stringhe sono sequenze di caratteri racchiuse tra virgolette. Possono essere create usando virgolette singole o virgolette doppie.

- Le stringhe sono immutabili in JavaScript. Questo significa che una volta creata una stringa, non puoi modificare i caratteri all’interno della stringa. Tuttavia, puoi comunque riassegnare una stringa a un nuovo valore.

## Concatenazione di stringhe in JavaScript

- La concatenazione è il processo di unire più stringhe o combinare stringhe con variabili che contengono testo. L'operatore `+` è uno dei metodi più semplici e usati frequentemente per concatenare stringhe.

- Se hai bisogno di aggiungere o concatenare a una stringa esistente, puoi usare l'operatore `+=`. Questo è utile quando vuoi costruire una stringa aggiungendo altro testo nel tempo.

- Un altro modo per concatenare stringhe è usare il metodo `concat()`. Questo metodo unisce due o più stringhe insieme.

## Registrare messaggi con `console.log()`

- Il metodo `console.log()` viene usato per registrare messaggi nella console. È uno strumento utile per eseguire il debug e testare il tuo codice.

## Punto e virgola in JavaScript

- Il punto e virgola viene usato principalmente per segnare la fine di un’istruzione. Questo aiuta il motore JavaScript a capire la separazione tra le singole istruzioni, fondamentale per un’esecuzione corretta.

- Il punto e virgola aiuta a evitare ambiguità nell’esecuzione del codice e garantisce che le istruzioni siano terminate correttamente.

## Commenti in JavaScript

- Qualsiasi riga di codice commentata viene ignorata dal motore JavaScript. I commenti servono a spiegare il codice, prendere appunti o disabilitare temporaneamente il codice.
- I commenti su singola riga si creano usando `//`.

- I commenti su più righe si creano usando `/*` per iniziare il commento e `*/` per terminarlo.

## JavaScript come linguaggio a tipizzazione dinamica

- JavaScript è un linguaggio a tipizzazione dinamica, il che significa che non devi specificare il tipo di dato di una variabile quando la dichiari. Il motore JavaScript determina automaticamente il tipo di dato in base al valore assegnato alla variabile.

- In linguaggi a tipizzazione statica come C#, assegnare una stringa a una variabile intera genera un errore.

## Usare l'operatore `typeof`

- L'operatore `typeof` serve a verificare il tipo di dato di una variabile. Restituisce una stringa che indica il tipo della variabile.

- Tuttavia, c'è una nota stranezza in JavaScript riguardo a `null`. L'operatore `typeof` restituisce `"object"` per valori `null`.

## ASCII, il metodo `charCodeAt()` e il metodo `fromCharCode()`

- **ASCII**: ASCII (American Standard Code for Information Interchange) è uno standard di codifica dei caratteri usato per rappresentare i caratteri base inglesi tramite valori numerici. Le lezioni precedenti introducono `charCodeAt()` e `fromCharCode()` usando esempi ASCII.
- **Unicode**: Le stringhe JavaScript usano internamente Unicode, specificamente la codifica UTF-16. Per i primi 128 caratteri (lettere latine base, cifre e simboli comuni), i valori Unicode corrispondono ai codici ASCII. Per questo motivo gli esempi basati su ASCII continuano a funzionare in JavaScript.
- **Il metodo `charCodeAt()`**: Questo metodo restituisce l'unità di codice UTF-16 del carattere a un indice specificato. Per i caratteri latini base, questo valore corrisponde al codice ASCII.

- **Il metodo `fromCharCode()`**: Questo metodo converte un codice ASCII nel carattere corrispondente.

## Altri metodi comuni per le stringhe

- **Il metodo `indexOf`**: questo metodo serve a cercare una sottostringa all'interno di una stringa. Se la sottostringa viene trovata, `indexOf` restituisce l'indice (o la posizione) della prima occorrenza di quella sottostringa. Se la sottostringa non viene trovata, `indexOf` restituisce -1, che indica che la ricerca non ha avuto successo.

- **Il metodo `includes()`**: questo metodo serve a verificare se una stringa contiene una specifica sottostringa. Se la sottostringa è presente nella stringa, il metodo restituisce true. Altrimenti restituisce false.

- **Il metodo `slice()`**: Questo metodo estrae una porzione di stringa e restituisce una nuova stringa, senza modificare quella originale. Prende due parametri: l'indice di partenza e l'indice di fine opzionale.

- **Il metodo `toUpperCase()`**: questo metodo converte tutti i caratteri in lettere maiuscole e restituisce una nuova stringa con tutti i caratteri maiuscoli.

- **Il metodo `toLowerCase()`**: questo metodo converte tutti i caratteri di una stringa in minuscolo.

- **Il metodo `replace()`**: questo metodo permette di trovare un valore specificato (come una parola o un carattere) in una stringa e sostituirlo con un altro valore. Il metodo restituisce una nuova stringa con la sostituzione e lascia invariata quella originale perché le stringhe in JavaScript sono immutabili.

- **Il metodo `replaceAll()`**: Questo metodo permette di trovare tutte le occorrenze di un valore specificato (una parola, un carattere o un pattern) in una stringa e sostituirle con un altro valore. Funziona come `replace()`, ma invece di fermarsi alla prima corrispondenza aggiorna tutte le corrispondenze trovate nella stringa.

- **Il metodo `repeat()`**: questo metodo serve a ripetere una stringa un numero specificato di volte.

- **Il metodo `trim()`**: questo metodo serve a rimuovere gli spazi bianchi sia dall'inizio sia dalla fine di una stringa.

- **Il metodo `trimStart()`**: questo metodo rimuove gli spazi bianchi dall'inizio (o "start") della stringa.

- **Il metodo `trimEnd()`**: questo metodo rimuove gli spazi bianchi dalla fine della stringa.

- **Il metodo `prompt()`**: questo metodo di `window` serve a ottenere informazioni da un utente tramite una finestra di dialogo. Questo metodo prende due argomenti. Il primo argomento è il messaggio che apparirà all'interno della finestra di dialogo, solitamente per invitare l'utente a inserire informazioni. Il secondo è un valore predefinito opzionale che riempirà inizialmente il campo di input.

## Lavorare con il tipo di dato number

- **Definizione**: Il tipo `Number` di JavaScript include numeri interi, numeri a virgola mobile, `Infinity` e `NaN`. I numeri a virgola mobile sono numeri con un punto decimale. `Infinity` positivo è un numero maggiore di qualsiasi altro numero mentre `-Infinity` è un numero minore di qualsiasi altro numero. `NaN` (`Not a Number`) rappresenta un valore numerico non valido come la stringa `"Jessica"`.

## Operazioni aritmetiche comuni

- **Operatore di addizione**: Questo operatore (`+`) viene usato per calcolare la somma di due o più numeri.
- **Operatore di sottrazione**: Questo operatore (`-`) viene usato per calcolare la differenza tra due numeri.
- **Operatore di moltiplicazione**: Questo operatore (`*`) viene usato per calcolare il prodotto di due o più numeri.
- **Operatore di divisione**: Questo operatore (`/`) viene usato per calcolare il quoziente tra due numeri.
- **Divisione per zero**: Se provi a dividere per zero, JavaScript restituirà `Infinity`.
- **Operatore resto**: Questo operatore (`%`) restituisce il resto di una divisione.
- **Operatore di esponenziazione**: Questo operatore (`**`) eleva un numero alla potenza di un altro.

## Calcoli con numeri e stringhe

- **Spiegazione**: Quando usi l'operatore `+` con un numero e una stringa, JavaScript converte il numero in stringa e concatena i due valori. Quando usi gli operatori `-`, `*` o `/` con una stringa e un numero, JavaScript converte la stringa in numero e il risultato sarà un numero. Per `null` e `undefined`, JavaScript tratta `null` come 0 e `undefined` come `NaN` nelle operazioni matematiche.

## Precedenza degli operatori

- **Definizione**: La precedenza degli operatori determina l'ordine in cui le operazioni vengono valutate in un'espressione. Gli operatori con precedenza più alta vengono valutati prima di quelli con precedenza più bassa. I valori dentro le parentesi vengono valutati per primi e moltiplicazione/divisione hanno precedenza più alta di addizione/sottrazione. Se gli operatori hanno la stessa precedenza, allora JavaScript usa l'associatività.

- **Definizione**: L'associatività indica la direzione in cui un'espressione viene valutata quando esistono più operatori dello stesso tipo. Definisce se l'espressione deve essere valutata da sinistra a destra (`left-associative`) o da destra a sinistra (`right-associative`). Ad esempio, l'operatore di esponente è associativo da destra a sinistra.

## Operatori di incremento e decremento

- **Operatore di incremento**: questo operatore serve ad aumentare il valore di uno. La notazione prefisso `++num` aumenta prima il valore della variabile, poi restituisce un nuovo valore. La notazione postfisso `num++` restituisce prima il valore attuale della variabile, poi lo aumenta.

- **Operatore di decremento**: questo operatore serve a diminuire il valore di uno. La notazione prefisso e la notazione postfisso funzionano allo stesso modo di prima con l'operatore di incremento.

## Operatori di assegnazione composta

- **Operatore di assegnazione composta per l'addizione (`+=`)**: questo operatore esegue l'addizione sui valori e assegna il risultato alla variabile.
- **Operatore di assegnazione composta per la sottrazione (`-=`)**: questo operatore esegue la sottrazione sui valori e assegna il risultato alla variabile.
- **Operatore di assegnazione composta per la moltiplicazione (`*=`)**: questo operatore esegue la moltiplicazione sui valori e assegna il risultato alla variabile.
- **Operatore di assegnazione composta per la divisione (`/=`)**: questo operatore esegue la divisione sui valori e assegna il risultato alla variabile.
- **Operatore di assegnazione composta per il resto (`%=`)**: questo operatore divide una variabile per il numero specificato e assegna il resto alla variabile.
- **Operatore di assegnazione composta per l'esponenziazione (`**=`)**: questo operatore eleva una variabile alla potenza del numero specificato e riassegna il risultato alla variabile.

## Booleani e uguaglianza

- **Definizione di booleano**: Un booleano è un tipo di dato che può avere solo due valori: `true` o `false`.
- **Operatore di uguaglianza (`==`)**: Questo operatore usa la conversione implicita prima di verificare se i valori sono uguali.

- **Operatore di uguaglianza stretta (`===`)**: Questo operatore non esegue la conversione implicita e verifica se sia i tipi sia i valori sono uguali.

- **Operatore di disuguaglianza (`!=`)**: Questo operatore usa la conversione implicita prima di verificare se i valori non sono uguali.
- **Operatore di disuguaglianza stretta (`!==`)**: Questo operatore non esegue conversione implicita e verifica se sia i tipi sia i valori non sono uguali.

## Operatori di confronto

- **Operatore maggiore di (`>`)**: questo operatore verifica se il valore a sinistra è maggiore di quello a destra.  
- **Operatore maggiore di o uguale a (`>=`)**: questo operatore verifica se il valore a sinistra è maggiore o uguale a quello a destra.  
- **Operatore minore di (`<`)**: questo operatore verifica se il valore a sinistra è minore di quello a destra.  
- **Operatore minore di o uguale a (`<=`)**: questo operatore verifica se il valore a sinistra è minore o uguale a quello a destra.

## Operatori unari

- **Operatore unario più**: questo operatore converte il suo operando in un numero. Se l'operando è già un numero, rimane invariato.

- **Operatore unario meno (`-`)**: questo operatore nega l'operando.

- **Operatore logico NOT (`!`)**: questo operatore inverte il valore booleano del suo operando. Quindi, se l'operando è `true`, diventa `false`, e se è `false`, diventa `true`.

## Operatori bit a bit

- **Operatore bit a bit AND (`&`)**: Questo operatore restituisce 1 in ogni posizione di bit per cui i bit corrispondenti di entrambi gli operandi sono 1.  
- **Operatore di assegnazione bit a bit AND (`&=`)**: Questo operatore esegue un'operazione `bitwise AND` con il numero specificato e riassegna il risultato alla variabile.  
- **Operatore bit a bit OR (`|`)**: Questo operatore restituisce 1 in ogni posizione di bit per cui i bit corrispondenti di uno o entrambi gli operandi sono 1.  
- **Operatore di assegnazione bit a bit OR (`|=`)**: Questo operatore esegue un'operazione `bitwise OR` con il numero specificato e riassegna il risultato alla variabile.  
- **Operatore bit a bit XOR (`^`)**: Questo operatore restituisce 1 in ogni posizione di bit per cui i bit corrispondenti di uno solo degli operandi sono 1, ma non entrambi.  
- **Operatore bit a bit NOT (`~`)**: Questo operatore inverte la rappresentazione binaria di un numero.  
- **Operatore di shift a sinistra (`<<`)**: Questo operatore sposta tutti i bit verso sinistra di un numero specificato di posizioni.  
- **Operatore di shift a destra (`>>`)**: Questo operatore sposta tutti i bit verso destra.

## Istruzioni condizionali, valori truthy, valori falsy e operatore ternario

- **`if/else if/else`**: Un'istruzione `if` prende una condizione ed esegue un blocco di codice se quella condizione è `truthy`. Se la condizione è `false`, allora passa al blocco `else if`. Se nessuna di queste condizioni è `true`, allora eseguirà la clausola `else`. I valori `Truthy` sono tutti quei valori che risultano in `true` quando valutati in un contesto booleano come un'istruzione `if`. I valori `Falsy` sono valori che valutano a `false` in un contesto booleano.

:::interactive_editor

```js
const score = 87;

if (score >= 90) {
 console.log('You got an A'); 
} else if (score >= 80) {
 console.log('You got a B'); // You got a B
} else if (score >= 70) {
 console.log('You got a C');
} else {
 console.log('You failed! You need to study more!');
}
```

:::

- **Operatore ternario**: Questo operatore viene spesso usato come modo più breve per scrivere istruzioni `if else`.

:::interactive_editor

```js
const temperature = 30;
const weather = temperature > 25 ? 'sunny' : 'cool';

console.log(`It's a ${weather} day!`); // It's a sunny day!
```

:::

## Operatori logici binari

- **Operatore logico AND (`&&`)**: Questo operatore verifica se entrambi gli operandi sono `true`. Se entrambi sono `true`, allora restituirà il secondo valore. Se uno degli operandi è `falsy`, allora restituirà il valore `falsy`. Se entrambi gli operandi sono `falsy`, restituirà il primo valore `falsy`.

- **Operatore logico OR (`||`)**: Questo operatore verifica se almeno uno degli operandi è truthy. 
- **Operatore di coalescenza nullish (`??`)**: Questo operatore restituirà un valore solo se il primo è `null` o `undefined`.

## L'oggetto `Math`

- **Il metodo `Math.random()`**: questo metodo genera un numero a virgola mobile casuale tra 0 (incluso) e 1 (escluso). Questo significa che l'output possibile può essere 0, ma non raggiungerà mai effettivamente 1.

- **Il metodo `Math.round()`**: questo metodo arrotonda un valore all'intero più vicino.

- **Il metodo `Math.sqrt()`**: questo metodo restituisce la radice quadrata di un numero.

## Metodi comuni per i numeri

- **`isNaN()`**: `NaN` indica "Not-a-Number". È un valore speciale che rappresenta un risultato numerico non rappresentabile o indefinito. La proprietà della funzione `isNaN()` serve a determinare se un valore è `NaN` o meno. `Number.isNaN()` offre un modo più affidabile per verificare valori `NaN`, soprattutto nei casi in cui la conversione implicita possa portare a risultati inattesi con la funzione globale `isNaN()`.

- **Il metodo `parseFloat()`**: questo metodo analizza un argomento stringa e restituisce un numero in virgola mobile. È progettato per estrarre un numero dall'inizio di una stringa, anche se la stringa contiene caratteri non numerici in seguito.
- **Il metodo `parseInt()`**: questo metodo analizza un argomento stringa e restituisce un intero. `parseInt()` interrompe l'analisi al primo carattere non numerico incontrato. Per i numeri in virgola mobile, restituisce solo la parte intera. Se non riesce a trovare un intero valido all'inizio della stringa, restituisce `NaN`.
- **Il metodo `toFixed()`**: questo metodo viene chiamato su un numero e accetta un argomento opzionale, che indica il numero di cifre da mostrare dopo il punto decimale. Restituisce una rappresentazione in stringa del numero con il numero specificato di cifre decimali.

## Confronti e i tipi di dati `null` e `undefined`

- **Confronti e `undefined`**: Una variabile è `undefined` quando è stata dichiarata ma non le è stato assegnato un valore. È il valore predefinito delle variabili non inizializzate e dei parametri di funzione a cui non è stato passato un argomento. `undefined` si converte in `NaN` nei contesti numerici, il che fa sì che tutti i confronti numerici con `undefined` restituiscano `false`.

- **Confronti e `null`**: Il tipo `null` rappresenta l'assenza intenzionale di un valore. `null` viene convertito in `0` nei contesti numerici, il che può causare comportamenti inattesi nei confronti numerici. Ad esempio, `null >= 0` è `true`, ma `null > 0` è `false`.

- Quando si usa l'operatore di uguaglianza (`==`), `null` e `undefined` sono uguali solo tra loro e a se stessi.

- Tuttavia, usando l'operatore di uguaglianza stretta (`===`), che verifica sia il valore sia il tipo senza conversione implicita, `null` e `undefined` non sono uguali.

## Istruzioni `switch`

- **Definizione**: Un'istruzione `switch` valuta un'espressione e confronta il suo valore con una serie di clausole `case`. Quando viene trovata una corrispondenza, viene eseguito il blocco di codice associato a quel caso. Un'istruzione `break` dovrebbe essere posta alla fine di ogni caso, per terminare la sua esecuzione e passare al successivo. Il caso `default` è un caso opzionale e viene eseguito solo se nessuno degli altri casi corrisponde. Il caso `default` è posto alla fine di un'istruzione `switch`.

:::interactive_editor

```js
const dayOfWeek = 3; 

switch (dayOfWeek) {
  case 1:
    console.log("It's Monday! Time to start the week strong.");
    break;
  case 2:
    console.log("It's Tuesday! Keep the momentum going.");
    break;
  case 3:
    console.log("It's Wednesday! We're halfway there.");
    break;
  case 4:
    console.log("It's Thursday! Almost the weekend.");
    break;
  case 5:
    console.log("It's Friday! The weekend is near.");
    break;
  case 6:
    console.log("It's Saturday! Enjoy your weekend.");
    break;
  case 7:
    console.log("It's Sunday! Rest and recharge.");
    break;
  default:
    console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

:::

## Funzioni JavaScript

- Le funzioni sono blocchi di codice riutilizzabili che eseguono un'attività specifica.
- Le funzioni possono essere definite usando la parola chiave `function` seguita da un nome, una lista di parametri e un blocco di codice che esegue l'attività.

:::interactive_editor

```js
function addNumbers(x, y, z) {
  return x + y + z;
}

console.log(addNumbers(5, 3, 8)); // Output: 16
```

:::

- Gli argomenti sono valori passati a una funzione quando viene chiamata.
- Una chiamata di funzione è il processo di eseguire una funzione in un programma specificando il nome della funzione seguito da parentesi tonde, includendo opzionalmente argomenti all'interno delle parentesi.
- Quando una funzione termina la sua esecuzione, restituisce sempre un valore.
- Per impostazione predefinita, il valore di ritorno di una funzione è `undefined`.
- La parola chiave `return` viene usata per specificare il valore da restituire dalla funzione e termina l'esecuzione della funzione.
- I parametri predefiniti permettono alle funzioni di avere valori già impostati che verranno usati se un argomento non viene fornito quando la funzione viene chiamata. Questo rende le funzioni più flessibili e previene errori nei casi in cui certi argomenti potrebbero essere omessi.

:::interactive_editor

```js
const calculateTotal = (amount, taxRate = 0.05) => {
  return amount + (amount * taxRate);
};

console.log(calculateTotal(100)); // Output: 105
```

:::

- Le funzioni anonime sono funzioni senza nome che possono essere assegnate a variabili. Assegnandole a variabili, puoi riutilizzarle ovunque la variabile sia accessibile.

:::interactive_editor

```js
const multiplyNumbers = function(firstNumber, secondNumber) {
  return firstNumber * secondNumber;
};

console.log(multiplyNumbers(4, 5)); // Output: 20
```

:::

## Funzioni freccia

- Le funzioni freccia sono un modo più conciso per scrivere funzioni in JavaScript.

- Quando definisci una funzione freccia, non serve la parola chiave `function`.
- Se usi un solo parametro, puoi omettere le parentesi tonde intorno alla lista dei parametri.

- Se il corpo della funzione consiste in una singola espressione, puoi omettere le parentesi graffe e la parola chiave `return`.

:::interactive_editor


## Ambito nella programmazione

- **Ambito globale**: è l’ambito più esterno in JavaScript. Le variabili dichiarate nell’ambito globale sono consultabili da qualsiasi punto del codice e si chiamano variabili globali.  
- **Ambito locale**: indica le variabili dichiarate all’interno di una funzione. Queste variabili sono consultabili solo all’interno della funzione in cui sono dichiarate e si chiamano variabili locali.  
- **Ambito di blocco**: un blocco è un insieme di istruzioni racchiuse tra parentesi graffe `{}` come nelle istruzioni `if` o nei loop.  
- L’ambito di blocco con `let` e `const` offre un controllo ancora più preciso sulla consultazione delle variabili, aiutando a prevenire errori e a rendere il codice più prevedibile.

## Nozioni di base sugli array in JavaScript

- **Definizione**: Un array in JavaScript è una collezione ordinata di valori, ognuno identificato da un indice numerico. I valori in un array JavaScript possono essere di tipi di dati diversi, inclusi numeri, stringhe, booleani, oggetti e persino altri array. Gli array sono contigui in memoria, il che significa che tutti gli elementi sono archiviati in un unico blocco continuo di posizioni di memoria, permettendo un indicizzazione efficiente e un accesso rapido agli elementi tramite il loro indice.

- **Consultare gli elementi di un array**: Per consultare gli elementi di un array, devi fare riferimento all'array seguito dal suo numero di indice racchiuso tra parentesi quadre. Gli array JavaScript hanno indice basato su zero, il che significa che il primo elemento si trova all'indice 0, il secondo all'indice 1, e così via. Se provi a consultare un indice che non esiste nell'array, JavaScript restituirà `undefined`.

- **Proprietà `length`**: Questa proprietà viene usata per restituire il numero di elementi in un array.

- **Aggiornare gli elementi in un array**: Per aggiornare un elemento in un array, usa l'operatore di assegnazione (`=`) per assegnare un nuovo valore all'elemento a un indice specifico.

## Array bidimensionali

- **Definizione**: Un array bidimensionale è essenzialmente un array di array. Viene usato per rappresentare dati che hanno una struttura naturale a griglia, come una scacchiera, un foglio di calcolo o i pixel in un'immagine. Per consultare un elemento in un array bidimensionale, servono due indici: uno per la riga e uno per la colonna.

## Destrutturazione degli array

- **Definizione**: La destrutturazione degli array è una funzionalità di JavaScript che ti permette di estrarre valori dagli array e assegnarli a variabili in modo più conciso e leggibile. Offre una sintassi comoda per decomprimere gli elementi di un array in variabili distinte.


:::

:::interactive_editor


## Metodi comuni degli array

- **Metodo `push()`**: Questo metodo serve per aggiungere elementi alla fine dell'array e restituisce la nuova lunghezza.

- **Metodo `pop()`**: Questo metodo serve per rimuovere l'ultimo elemento da un array e restituisce l'elemento rimosso. Se l'array è vuoto, il valore di ritorno sarà `undefined`.

- **Metodo `shift()`**: Questo metodo serve per rimuovere il primo elemento da un array e restituisce l'elemento rimosso. Se l'array è vuoto, il valore di ritorno sarà `undefined`.

- **Metodo `unshift()`**: Questo metodo serve per aggiungere elementi all'inizio dell'array e restituisce la nuova lunghezza.

- **Metodo `indexOf()`**: Questo metodo è utile per trovare il primo indice di un elemento specifico all'interno di un array. Se l'elemento non viene trovato, restituisce `-1`.

- **Metodo `splice()`**: Questo metodo serve per aggiungere o rimuovere elementi da qualsiasi posizione in un array. Il valore di ritorno del metodo `splice()` sarà un array degli elementi rimossi dall'array. Se non viene rimosso nulla, viene restituito un array vuoto. Questo metodo modifica l'array originale, cambiandolo direttamente invece di crearne uno nuovo. Il primo argomento specifica l'indice da cui iniziare a modificare l'array. Il secondo argomento è il numero di elementi che vuoi rimuovere. Gli argomenti successivi sono gli elementi che vuoi aggiungere.

- **Metodo `includes()`**: Questo metodo serve per verificare se un array contiene un valore specifico. Restituisce `true` se l'array contiene l'elemento specificato, e `false` altrimenti.

- **Metodo `concat()`**: Questo metodo crea un nuovo array unendo due o più array.

- **Metodo `slice()`**: Questo metodo restituisce un nuovo array contenente una copia superficiale di una porzione dell'array originale, specificata dagli indici di inizio e fine. Il nuovo array contiene riferimenti agli stessi elementi dell'array originale (non duplicati). Questo significa che se gli elementi sono primitivi (come numeri o stringhe), i valori vengono copiati; ma se gli elementi sono oggetti o array, vengono copiati i riferimenti, non gli oggetti stessi.

- **Sintassi di espansione**: La sintassi di espansione serve per creare copie superficiali di un array.

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const shallowCopiedArray = [...originalArray];

shallowCopiedArray.push(4);

console.log(originalArray); // [1, 2, 3]
console.log(shallowCopiedArray); // [1, 2, 3, 4]
```

:::

- **Metodo `split()`**: Questo metodo divide una stringa in un array di sottostringhe e specifica dove deve avvenire ogni divisione in base a un separatore dato. Se non viene fornito alcun separatore, il metodo restituisce un array contenente la stringa originale come unico elemento.

- **Metodo `reverse()`**: Questo metodo inverte un array sul posto.

- **Metodo `join()`**: Questo metodo concatena tutti gli elementi di un array in una singola stringa, separando ogni elemento con un separatore specificato. Se non viene fornito alcun separatore, o viene usata una stringa vuota (`""`), gli elementi saranno uniti senza alcun separatore.

## Verificare se un oggetto ha una proprietà

- **Metodo `hasOwnProperty()`**: Questo metodo restituisce un booleano che indica se l'oggetto possiede la proprietà specificata come propria proprietà.

- **Metodo `Object.hasOwn()`**: Questo è il modo moderno e consigliato per verificare se un oggetto possiede una proprietà come propria (non ereditata). La sintassi è `Object.hasOwn(object, propertyName)`. Restituisce `true` se la proprietà esiste nell'oggetto e `false` se non esiste, indipendentemente dal valore della proprietà. Questo lo rende più sicuro di `hasOwnProperty()` e più affidabile di `if (obj.prop)` quando i valori possono essere `0`, `false`, `null` o `undefined`.

`Object.hasOwn()` rileva una proprietà propria anche quando il suo valore è falsy, come `0`, `false` o `undefined`.

## Lavorare con i loop

- **`for` Loop**: Questo tipo di loop si usa per ripetere un blocco di codice un certo numero di volte. Questo loop è suddiviso in tre parti: l’istruzione di inizializzazione, la condizione e l’istruzione di incremento/decremento. L’istruzione di inizializzazione viene eseguita prima che il loop inizi. Di solito serve per inizializzare una variabile contatore. La condizione viene valutata prima di ogni iterazione del loop. Un’iterazione è un singolo passaggio attraverso il loop. Se la condizione è `true`, il blocco di codice all’interno del loop viene eseguito. Se la condizione è `false`, il loop si ferma e si passa al blocco di codice successivo. L’istruzione di incremento/decremento viene eseguita dopo ogni iterazione del loop. Di solito serve per incrementare o decrementare la variabile contatore.

```js
  console.log(i);
}
```

:::

```js
}
```

## `var` parola chiave e hoisting

- **Definizione**: `var` era il modo originale per dichiarare variabili prima del 2015. Ma c’erano alcuni problemi legati a `var` in termini di ambito, ridefinizione e altro. Per questo motivo la programmazione moderna in JavaScript usa invece `let` e `const`.
- **Ridefinire variabili con `var`**: Se provi a ridefinire una variabile usando `let`, otterresti un `SyntaxError`. Ma con `var` è permesso ridefinire una variabile.

- **`var` e ambito**: Le variabili dichiarate con `var` dentro un blocco (come un’istruzione `if` o un loop `for`) sono comunque accessibili all’esterno di quel blocco.

- **Hoisting**: Questo è il comportamento predefinito di JavaScript che sposta le dichiarazioni in cima ai rispettivi ambiti durante la fase di compilazione prima che il codice venga eseguito. Quando dichiari una variabile usando la parola chiave `var`, JavaScript sposta la dichiarazione in cima al suo ambito.

Quando dichiari una funzione usando la sintassi di dichiarazione della funzione, sia il nome della funzione sia il corpo della funzione vengono spostati in cima. Questo significa che puoi chiamare una funzione prima di averla dichiarata nel codice.

Le dichiarazioni di variabili fatte con `let` o `const` vengono spostate in cima, ma non sono inizializzate e non puoi consultarle prima della dichiarazione effettiva nel codice. Questo comportamento è spesso chiamato "zona morta temporale".

## Lavorare con importazioni, esportazioni e moduli

- **Modulo**: è un'unità autonoma di codice che racchiude funzioni, classi o variabili correlate. Per creare un modulo, scrivi il tuo codice JavaScript in un file separato.
- **Esportazioni**: tutte le variabili, funzioni o classi che vuoi rendere disponibili ad altre parti della tua applicazione devono essere esportate esplicitamente usando la parola chiave `export`. Esistono due tipi di esportazione: esportazione nominata ed esportazione predefinita.
- **Importazioni**: per usare gli elementi esportati in un'altra parte della tua applicazione, devi importarli usando la parola chiave `import`. I tipi possono essere importazione nominata, importazione predefinita e importazione di namespace.

```js
// Within a file called math.js, we export the following functions:

// Named export
export function add(num1, num2) {
  return num1 + num2;
}

// Default export
export default function subtract(num1, num2) {
  return num1 - num2;
}

// Within another file, we can import the functions from math.js.

// Named import - This line imports the add function.
// The name of the function must exactly match the one exported from math.js.
import { add } from './math.js';

// Default import - This line imports the subtract function.
// The name of the function can be anything.
import subtractFunc from './math.js';

// Namespace import - This line imports everything from the file.
import * as Math from './math.js';

console.log(add(5, 3)); // 8
console.log(subtractFunc(5, 3)); // 2
console.log(Math.add(5, 3)); // 8
console.log(Math.subtract(5, 3)); // 2
```

## Funzioni di callback e il metodo `forEach`

- **Definizione**: In JavaScript, una funzione di callback è una funzione che viene passata come argomento a un'altra funzione, in modo che la funzione esterna possa invocarla in un momento specifico.
- **Metodo `forEach()`**: Questo metodo viene usato per iterare su ogni elemento di un array ed eseguire un'operazione su ciascun elemento. La funzione di callback in `forEach` può accettare fino a tre argomenti: l'elemento corrente, l'indice dell'elemento corrente e l'array su cui è stato chiamato `forEach`.

## Funzioni di ordine superiore

- **Definizione**: Una funzione di ordine superiore prende una o più funzioni come argomenti e restituisce una funzione o un valore come risultato.

- **Metodo `map()`**: Questo metodo viene usato per creare un nuovo array applicando una funzione data a ogni elemento dell'array originale. La funzione di callback può accettare fino a tre argomenti: l'elemento corrente, l'indice dell'elemento corrente e l'array su cui `map` è stato chiamato.

- **Metodo `filter()`**: Questo metodo viene usato per creare un nuovo array con gli elementi che superano un test specificato, risultando utile per estrarre selettivamente elementi in base a criteri. Proprio come il metodo `map`, la funzione di callback per il metodo `filter` accetta gli stessi tre argomenti: l'elemento corrente in elaborazione, l'indice e l'array.

- **Metodo `reduce()`**: Questo metodo viene usato per elaborare un array e condensarlo in un singolo valore. Questo valore singolo può essere un numero, una stringa, un oggetto o anche un altro array. Il metodo `reduce()` funziona applicando una funzione a ogni elemento dell'array, in ordine, passando il risultato di ogni calcolo al successivo. Questa funzione è spesso chiamata funzione reducer. La funzione reducer prende due parametri principali: un accumulatore e il valore corrente. L'accumulatore è dove archivi il risultato progressivo delle tue operazioni, e il valore corrente è l'elemento dell'array in elaborazione.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce(
  (accumulator, currentValue) => accumulator + currentValue,
  0
);

console.log(sum); // 15
```

:::

## Lavorare con il metodo `sort`

- **Definizione**: Il metodo `sort` serve per ordinare gli elementi di un array e restituire un riferimento all'array ordinato. In questo caso non viene fatta alcuna copia perché gli elementi vengono ordinati direttamente sul posto.

Se devi ordinare numeri, allora devi passare una funzione di confronto. Il metodo `sort` converte gli elementi in stringhe e poi confronta le loro sequenze di valori unità di codice UTF-16. Le unità di codice UTF-16 sono i valori numerici che rappresentano i caratteri nella stringa. Esempi di unità di codice UTF-16 sono i numeri 65, 66 e 67 che rappresentano rispettivamente i caratteri "A", "B" e "C". Quindi il numero 200 appare prima del numero 3 in un array, perché la stringa "200" viene prima della stringa "3" quando si confrontano le loro unità di codice UTF-16.

:::interactive_editor

```js
const numbers = [414, 200, 5, 10, 3];

numbers.sort((a, b) => a - b);

console.log(numbers); // [3, 5, 10, 200, 414]
```

:::

I parametri `a` e `b` sono i due elementi che vengono confrontati. La funzione di confronto dovrebbe restituire un valore negativo se `a` deve venire prima di `b`, un valore positivo se `a` deve venire dopo `b`, e zero se `a` e `b` sono uguali.

## Lavorare con i metodi `every` e `some`

- **Metodo `every()`**: questo metodo verifica se tutti gli elementi in un array superano un test implementato da una funzione fornita. Il metodo `every()` restituisce `true` se la funzione fornita restituisce `true` per tutti gli elementi dell'array. Se un elemento non supera il test, il metodo restituisce immediatamente `false` e smette di controllare gli elementi rimanenti.

- **Metodo `some()`**: questo metodo verifica se almeno un elemento supera il test. Il metodo `some()` restituisce `true` non appena trova un elemento che supera il test. Se nessun elemento supera il test, restituisce `false`.

## Lavorare con il DOM e le API web

- **API**: Un'API (Application Programming Interface) è un insieme di regole e protocolli che permettono alle applicazioni software di comunicare tra loro e scambiare dati in modo efficiente.
- **API web**: Le API web sono progettate specificamente per le applicazioni web. Questi tipi di API sono spesso divisi in due categorie principali: API del browser e API di terze parti.
- **API del browser**: Queste API espongono dati dal browser. Come sviluppatore web, puoi consultare e manipolare questi dati usando JavaScript.
- **API di terze parti**: Queste non sono integrate nel browser per impostazione predefinita. Devi recuperare il loro codice in qualche modo. Di solito, hanno una documentazione dettagliata che spiega come usare i loro servizi. Un esempio è l'API di Google Maps, che puoi usare per mostrare mappe interattive sul tuo sito web.

Con il DOM puoi aggiungere, modificare o eliminare elementi su una pagina web. La radice dell'albero DOM è l'elemento `html`. È il contenitore di livello superiore per tutto il contenuto di un documento HTML. Tutti gli altri nodi sono discendenti di questo nodo radice. Poi, sotto il nodo radice, troviamo altri nodi nella gerarchia. Un nodo genitore è un elemento che contiene altri elementi. Un nodo figlio è un elemento contenuto all'interno di un altro elemento.
- **Interfaccia `navigator`**: Questa fornisce informazioni sull'ambiente del browser, come la stringa user agent, la piattaforma e la versione del browser. Una stringa user agent è una stringa di testo che identifica il browser e il sistema operativo in uso.
- **Interfaccia `window`**: Questa rappresenta la finestra del browser che contiene il documento DOM. Fornisce metodi e proprietà per interagire con la finestra del browser, come ridimensionare la finestra, aprire nuove finestre e navigare verso URL diversi.

## L'istruzione `throw`

- **Definizione**: L'istruzione `throw` in JavaScript serve a lanciare un'eccezione definita dall'utente. Un'eccezione in programmazione è quando succede un evento imprevisto che interrompe il normale flusso del programma.

## `try...catch...finally`

- **Definizione**: Il blocco `try` serve a racchiudere codice che potrebbe lanciare un errore. Funziona come uno spazio sicuro per provare qualcosa che potrebbe fallire. Il blocco `catch` cattura e gestisce gli errori che si verificano nel blocco try. Puoi usare l'oggetto error all'interno di catch per esaminare cosa è andato storto. Il blocco `finally` viene eseguito dopo i blocchi try e catch, indipendentemente dal fatto che si sia verificato un errore. Viene comunemente usato per attività di pulizia, come chiudere file o liberare risorse.

:::interactive_editor

```js
function processInput(input) {
  if (typeof input !== "string") {
    throw new TypeError("Input must be a string.");
  }

  return input.toUpperCase();
}

try {
  console.log("Starting to process input...");
  const result1 = processInput("hello");
  console.log("Processed result:", result1);  // HELLO
  const result2 = processInput(9);  // throws TypeError
  console.log("Processed result:", result2);  // not executed
} catch (error) {
  console.error("Error occurred:", error.message);
} 
```

:::

## Espressioni regolari e metodi comuni

- **Definizione**: Le espressioni regolari, o regex, si usano per creare un "pattern", che puoi poi usare per verificare una stringa, estrarre testo e altro.

- **Costruttore `RegExp`**: Quando il tuo pattern o i flag provengono da variabili, puoi costruire lo stesso tipo di espressione regolare con il costruttore `RegExp`. Accetta una stringa di pattern e una stringa di flag opzionale.

Ad esempio, `new RegExp(pattern, flags)` costruisce un'espressione regolare da quelle stringhe.

- **Metodo `test()`**: Questo metodo accetta una stringa, che è la stringa da testare per verificare se corrisponde all'espressione regolare. Restituisce un booleano se la stringa corrisponde alla regex.

- **Metodo `match()`**: Questo metodo accetta un'espressione regolare, anche se puoi passare una stringa che verrà trasformata in un'espressione regolare. Il metodo `match` restituisce l'array delle corrispondenze per la stringa.

- **Metodo `replace()`**: Questo metodo accetta due argomenti: l'espressione regolare da cercare (o una stringa) e la stringa con cui sostituire la corrispondenza (o una funzione da eseguire su ogni corrispondenza).

- **Metodo `replaceAll`**: Questo metodo serve a sostituire tutte le occorrenze di un pattern specificato con una nuova stringa. Lancia un errore se gli passi un'espressione regolare senza il modificatore globale.

- **Metodo `matchAll`**: Questo metodo serve a recuperare tutte le corrispondenze di una data espressione regolare in una stringa, inclusi i gruppi di cattura, e le restituisce come un iteratore. Un iteratore è un oggetto che ti permette di scorrere (o "iterare su") una collezione di elementi.

## Modificatori delle espressioni regolari

- **Definizione**: I modificatori, spesso chiamati "flag", modificano il comportamento di un'espressione regolare.  
- **Flag `i`**: Questo flag fa sì che una regex ignori le differenze tra maiuscole e minuscole.

- **Flag `g`**: Questo flag, o modificatore globale, permette alla tua espressione regolare di trovare più di una corrispondenza per un pattern.

- **Definizione di àncora**: L'àncora `^` all'inizio dell'espressione regolare indica "corrispondi all'inizio della stringa". L'àncora `$` alla fine dell'espressione regolare indica "corrispondi alla fine della stringa".

- **Flag `m`**: Le ancore cercano l'inizio e la fine dell'intera stringa. Ma puoi fare in modo che una regex gestisca più righe con il flag `m`, o il modificatore multilinea.

- **Flag `d`**: Questo flag aggiunge gli indici di inizio e fine delle corrispondenze e dei gruppi di cattura all'oggetto corrispondenza.

- **Flag `u`**: Questo flag amplia la funzionalità di un'espressione regolare permettendole di corrispondere a caratteri unicode speciali. Il flag `u` ti dà accesso a classi speciali come `Extended_Pictographic` per corrispondere alla maggior parte delle emoji. Esiste anche un flag `v`, che espande ulteriormente la funzionalità del matching unicode.
- **Flag `y`**: Il modificatore sticky si comporta in modo molto simile al modificatore globale, ma con alcune eccezioni. La più importante è che un'espressione regolare globale partirà da lastIndex e cercherà un'altra corrispondenza nell'intero resto della stringa, mentre un'espressione regolare sticky restituirà null e resetterà lastIndex a 0 se non c'è una corrispondenza immediata all'indice lastIndex precedente.
- **Flag `s`**: Il modificatore single-line permette a un carattere jolly, rappresentato da un `.` nelle espressioni regolari, di corrispondere anche alle interruzioni di riga, trattando di fatto la stringa come una singola riga di testo.

## Classi di caratteri

- **Wildcard `.`**: Le classi di caratteri sono una sintassi speciale che puoi usare per far corrispondere insiemi o sottoinsiemi di caratteri. La prima classe di caratteri che dovresti imparare è la classe wildcard. La wildcard è rappresentata da un punto e corrisponde a QUALSIASI singolo carattere TRANNE le interruzioni di riga. Per permettere alla classe wildcard di corrispondere anche alle interruzioni di riga, ricorda che dovresti usare la flag `s`.

- **`\d`**: Questo corrisponderà a tutte le cifre (`0-9`) in una stringa.

- **`\w`**: Questo serve per trovare qualsiasi carattere di parola (`a-zA-Z0-9_`) in una stringa. Un carattere di parola è definito come qualsiasi lettera, da a a z o da A a Z, oppure un numero da 0 a 9, o il carattere underscore.

- **`\s`**: La classe di caratteri per gli spazi bianchi `\s` è rappresentata da una barra rovesciata seguita da una `s`. Questa classe corrisponde a qualsiasi spazio bianco, inclusi ritorni a capo, spazi, tabulazioni e caratteri di spazio unicode speciali.
- **Negazione delle classi di caratteri speciali**: Per negare una di queste classi di caratteri, invece di usare una lettera minuscola dopo la barra rovesciata, puoi usare la corrispondente maiuscola. Ad esempio, `\D` corrisponde a qualsiasi singolo carattere che NON sia numerico.

- **Classi di caratteri personalizzate**: Puoi creare classi di caratteri personalizzate mettendo i caratteri che vuoi far corrispondere all'interno di un insieme di parentesi quadre.

Ad esempio, `/[abcdf]/` corrisponde a uno qualsiasi dei caratteri tra parentesi.

## Asserzioni lookahead e lookbehind

- **Definizione**: Le asserzioni lookahead e lookbehind ti permettono di far corrispondere pattern specifici basandoti sulla presenza o assenza di pattern circostanti.
- **Asserzione lookahead positiva**: Questa asserzione fa corrispondere un pattern quando è seguito da un altro pattern. Per costruire un lookahead positivo, devi partire dal pattern che vuoi far corrispondere. Poi, usa le parentesi tonde per racchiudere il pattern che vuoi usare come condizione. Dopo la parentesi di apertura, usa `?=` per definire quel pattern come lookahead positivo.

Ad esempio, `/free(?=code)/i` corrisponde a `free` quando è seguito da `code`.

- **Asserzione lookahead negativa**: Questo è un tipo di condizione usata nelle espressioni regolari per verificare che un certo pattern non si presenti più avanti nella stringa.

Ad esempio, `/free(?!code)/i` corrisponde a `free` quando non è seguito da `code`.

- **Asserzione lookbehind positiva**: Questa asserzione fa corrispondere un pattern solo se è preceduto da un altro pattern specifico, senza includere il pattern precedente nella corrispondenza.

Ad esempio, `/(?<=free)code/i` corrisponde a `code` quando è preceduto da `free`.

- **Asserzione lookbehind negativa**: Questa asserzione garantisce che un pattern non sia preceduto da un altro pattern specifico. Fa corrispondere solo se il pattern specificato non è immediatamente preceduto dalla sequenza data, senza includere la sequenza precedente nella corrispondenza.

Ad esempio, `/(?<!free)code/i` corrisponde a `code` quando non è preceduto da `free`.

## Quantificatori nelle regex

- **Definizione**: I quantificatori nelle espressioni regolari specificano quante volte un pattern (o parte di esso) deve apparire. Aiutano a controllare il numero di occorrenze di caratteri o gruppi in una corrispondenza.

Ad esempio, `/^\d{4}$/` corrisponde a una stringa contenente esattamente quattro cifre.

- **`*`** : Corrisponde a 0 o più occorrenze dell'elemento precedente.
- **`+`**: Corrisponde a 1 o più occorrenze dell'elemento precedente.
- **`?`**: Corrisponde a 0 o 1 occorrenza dell'elemento precedente.
- **`{n}`**: Corrisponde esattamente a n occorrenze dell'elemento precedente.
- **`{n,}`**: Corrisponde a n o più occorrenze dell'elemento precedente.
- **`{n,m}`**: Corrisponde a un numero di occorrenze dell'elemento precedente compreso tra n e m.

## Gruppi di cattura e riferimenti indietro

- **Gruppi di cattura**: Un gruppo di cattura ti permette di "catturare" una porzione della stringa corrispondente per usarla come preferisci. I gruppi di cattura si definiscono con parentesi tonde che contengono il pattern da catturare, senza caratteri iniziali come un lookahead.

Ad esempio, `/free(code)camp/i` cattura `code`.

- **Gruppi non di cattura**: Un gruppo non di cattura è simile a un gruppo di cattura ma non memorizza la porzione corrispondente della stringa per un uso successivo. I gruppi non di cattura sono definiti da `(?:...)`.

Ad esempio, `/free(?:code)camp/i` raggruppa `code` senza catturarlo.

- **Riferimenti indietro**: Un riferimento indietro nelle espressioni regolari indica un modo per riutilizzare una parte del pattern che è stata corrisposta in precedenza nella stessa espressione. Ti permette di fare riferimento a un gruppo catturato (una parte del pattern tra parentesi tonde) tramite il suo numero. Per esempio, `$1` fa riferimento al primo gruppo catturato.

:::interactive_editor

```js
const regex = /free(co+de)camp/i;
console.log("freecoooooooodecamp".replace(regex, "paid$1world"));
```

:::

- Puoi usare le backreference all'interno della regex stessa per corrispondere allo stesso testo catturato da un gruppo precedente con una barra rovesciata e il numero del gruppo di cattura. Per esempio:

:::interactive_editor

```js
const regex = /(hello) \1/i;
console.log(regex.test("hello hello")); // true
console.log(regex.test("hello world")); // false
```

:::

## Validare i moduli con JavaScript

- **Constraint Validation API**: Alcuni elementi HTML, come gli elementi `textarea` e `input`, espongono un'API di validazione dei vincoli. Questa API ti permette di verificare che il valore fornito dall'utente per quell'elemento superi qualsiasi validazione a livello HTML che hai scritto, come la lunghezza minima o la corrispondenza con un pattern.
- **Metodo `checkValidity()`**: Questo metodo restituisce `true` se l'elemento rispetta tutte le validazioni HTML (basate sui suoi attributi), e `false` se non le rispetta.

- **Metodo `reportValidity()`**: Questo metodo comunica al browser che il `input` non è valido.

- **Proprietà `validity`**: Questa proprietà serve per ottenere lo stato di validità dei controlli del modulo (come `<input>`, `<select>`, ecc.) e fornisce informazioni sul fatto che l'input dell'utente soddisfi i vincoli definiti per quell'elemento (ad esempio, campi `required`, vincoli di pattern, lunghezza massima, ecc.).

- **Proprietà `patternMismatch`**: Sarà `true` se il valore non corrisponde al pattern di espressione regolare specificato.

## Metodo `preventDefault()`

- **Definizione**: Ogni evento che si attiva nel DOM ha un comportamento predefinito. L'evento click su una casella di spunta cambia lo stato di quella casella, per impostazione predefinita. Premere <kbd>Barra spaziatrice</kbd> su un pulsante con focus attiva il pulsante. Il metodo `preventDefault()` su questi oggetti `Event` impedisce che quel comportamento avvenga.

## Invio dei moduli

- **Definizione**: Ci sono tre modi in cui un modulo può essere inviato. Il primo è quando l'utente clicca un pulsante nel modulo che ha l'attributo `type` impostato su `submit`. Il secondo è quando l'utente preme il tasto <kbd>Invio</kbd> su un qualsiasi campo `input` modificabile nel modulo. Il terzo è tramite una chiamata JavaScript ai metodi `requestSubmit()` o `submit()` dell'elemento `form`.
- **Attributo `action`**: L'attributo `action` dovrebbe contenere un URL o un percorso relativo per il dominio corrente. Questo valore determina dove il modulo tenta di inviare i dati: se non imposti un attributo `action`, il modulo invierà i dati all'URL della pagina corrente.

- **Attributo `method`**: Questo attributo accetta un metodo `HTTP` standard, come `GET` o `POST`, e usa quel metodo per effettuare la richiesta all’URL di azione. Quando un metodo non è impostato, il modulo userà per default una richiesta `GET`. I dati nel modulo saranno codificati URL come coppie `name=value` e aggiunti in coda all’URL di azione come parametri di query.

- **Attributo `enctype`**: L’elemento `form` accetta un attributo `enctype`, che rappresenta il tipo di codifica da usare per i dati. Questo attributo accetta solo tre valori: `application/x-www-form-urlencoded` (che è il predefinito, inviando i dati come corpo del modulo codificato URL), `text/plain` (che invia i dati in forma di testo semplice, in coppie `name=value` separate da nuove righe), o `multipart/form-data`, specifico per gestire moduli con caricamento di file.

## L'oggetto `date()` e i metodi comuni

- **Definizione**: L'oggetto `date()` è usato per creare, manipolare e formattare date e orari in JavaScript. Ad esempio, `const now = new Date();` crea una nuova istanza dell'oggetto `Date` e la assegna alla variabile `now`. Se registrassi il valore di `now` nella console, vedresti la data e l'ora correnti basate sull'orologio di sistema del computer che esegue il codice.

- **Metodo `Date.now()`**: Questo metodo serve per ottenere la data e l'ora correnti. `Date.now()` restituisce il numero di millisecondi trascorsi dal 1° gennaio 1970, 00:00:00 UTC. Questo è noto come tempo epoch Unix. Il tempo epoch Unix è un modo comune per rappresentare date e orari nei sistemi informatici perché è un intero che può essere facilmente archiviato e manipolato. UTC sta per Universal Time Coordinated, che è lo standard temporale principale con cui il mondo regola orologi e tempo.
- **Metodo `getDate()`**: Questo metodo serve per ottenere il giorno del mese basato sulla data corrente. `getDate()` restituirà un valore intero tra 1 e 31, a seconda del giorno del mese. Se la data non è valida, restituirà `NaN` (Not a Number).

- **Metodo `getMonth()`**: Questo metodo serve per ottenere il mese. Il mese è a base zero, quindi gennaio è 0, febbraio è 1, e così via. Ad esempio, chiamare `getMonth()` su una data di ottobre restituisce `9`. Se il mese non è valido, restituisce `NaN`.

- **Metodo `getFullYear()`**: Questo metodo serve per ottenere l'anno completo. Se l'anno non è valido, restituirà `NaN`.

## Modi diversi per formattare le date

- **Metodo `toISOString()`**: questo metodo serve a formattare la data in un formato esteso `ISO` (ISO 8601). ISO 8601 è uno standard internazionale per rappresentare date e orari. Il formato è `YYYY-MM-DDTHH:mm:ss.sssZ`.

- **Metodo `toLocaleDateString()`**: questo metodo serve a formattare la data in base alla localizzazione dell'utente.

Il metodo `toLocaleDateString()` accetta due parametri opzionali: locales e options.

Il parametro locales è una stringa che rappresenta la localizzazione da usare. Per esempio, puoi passare `"en-US"` per l'inglese (Stati Uniti) o `"fr-FR"` per il francese (Francia). Se non passi un parametro locales, viene usata la localizzazione predefinita. Il secondo parametro opzionale è options. Questo parametro è un oggetto che ti permette di specificare il formato della stringa della data.

## `Audio` costruttore e metodi comuni

- **Definizione**: Il costruttore `Audio`, come altri costruttori, è una funzione speciale chiamata con la parola chiave `new`. Restituisce un `HTMLAudioElement`, che puoi poi usare per riprodurre audio per l’utente o aggiungere al DOM affinché l’utente possa controllarlo da solo. Quando chiami il costruttore, puoi opzionalmente passare un URL come (unico) argomento. Questo URL dovrebbe puntare alla sorgente del file audio che vuoi riprodurre. Oppure, se hai bisogno di cambiare la sorgente dinamicamente, puoi assegnare l’URL alla proprietà `src` dell’elemento audio restituito.
- **Metodo `play()`**: Questo metodo si usa con gli elementi `audio` o `video` per iniziare la riproduzione del media.

- **Metodo `pause()`**: Questo metodo si usa con gli elementi `audio` o `video` per mettere in pausa la riproduzione del media. Mantiene la posizione corrente, quindi se chiami `play()`, la riproduzione riparte da quella posizione.

- **Metodo `addTextTrack()`**: Questo metodo ti permette di specificare una traccia testuale da associare all’elemento media — particolarmente utile per aggiungere sottotitoli a un video.
- **Metodo `fastSeek()`**: Questo metodo ti permette di spostare la posizione di riproduzione a un momento specifico all’interno del media.

Il costruttore `Audio()` ha proprietà proprio come ha metodi. Tra queste proprietà ci sono:

- `currentTime`: per ottenere il tempo corrente di riproduzione di un audio
- `loop`: per far riprodurre l’audio in modo continuo riavviandolo automaticamente quando arriva alla fine
- `muted`: per silenziare l’output audio di un elemento media indipendentemente dal volume impostato

## Formati audio e video diversi

- **Tipo MIME**: Un tipo MIME, che sta per Multipurpose Internet Mail Extensions, è un modo standardizzato per indicare programmaticamente un tipo di file. Il tipo MIME può dire a un’applicazione, come il tuo browser, come gestire un file specifico. Nel caso di audio e video, il tipo MIME indica che si tratta di un formato multimediale che può essere incorporato nella pagina web.
- **Elemento `source`**: Questo si usa per specificare un tipo di file e una sorgente — e può includere più tipi diversi usando più elementi source. Quando fai così, il browser determina il formato migliore da usare per l’ambiente attuale dell’utente.
- **MP3**: È un tipo di formato digitale usato per archiviare musica, audio o suoni. È una versione compressa di una registrazione sonora che rende il file più piccolo, quindi più facile da archiviare e condividere. MP3 ha il supporto più ampio nei browser e il tipo MIME `audio/mpeg`.
- **MP4**: Un MP4 è un tipo di formato digitale usato per archiviare video e audio. Funziona come un contenitore che contiene sia il video (immagini) sia il suono (musica o voce) in un unico file. Un MP4 può avere il tipo MIME `audio/mp4` O `video/mp4`, a seconda che sia un file video o solo audio.
- Altri formati sono `WMV` associato all’app Windows Media Player, `OGG`, `MKV`, `AVI` e altri.

## codec

- **Definizione**: Un codec, abbreviazione di "encoder/decoder", è un algoritmo o un software che può convertire audio e video tra formati analogici e digitali. I codec possono essere specificati come parte del tipo MIME. La sintassi base per definire un codec è aggiungere un punto e virgola dopo il tipo di media, poi `codecs=` e il codec.

## Insiemi in JavaScript

- Un `Set` è un'opzione integrata per gestire collezioni di dati.
- I set assicurano che ogni valore appaia una sola volta, rendendoli utili per eliminare duplicati da un array o gestire collezioni di valori distinti.
- Puoi creare un `Set` usando il costruttore `Set()`.

- Gli insiemi possono essere manipolati usando questi metodi:

  - `delete()`: rimuove un elemento dal `Set`.
  - `has()`: verifica se un elemento esiste nel `Set`.
  - `clear()`: rimuove tutti gli elementi dal `Set`.
  - `keys()` e `values()`: entrambi restituiscono un `SetIterator` che contiene i valori del `Set`. Sono uguali perché `keys()` è un alias di `values()`.
  - `forEach()`: per iterare sui valori del `Set`.

## Weakset in JavaScript

- `WeakSet` è una collezione di oggetti che ti permette di archiviare oggetti mantenuti in modo debole.

## Insiemi vs WeakSet

- A differenza degli insiemi, un `WeakSet` non supporta tipi primitivi come numeri o stringhe.
- Un `WeakSet` archivia solo oggetti, e i riferimenti a quegli oggetti sono "deboli", cioè se l'oggetto non viene usato da nessun'altra parte nel tuo codice, viene rimosso automaticamente per liberare memoria.

## Map in JavaScript

- Una `Map` è un oggetto integrato che contiene coppie chiave-valore proprio come un oggetto.
- Le mappe differiscono dagli oggetti JavaScript standard per la capacità di permettere chiavi di qualsiasi tipo, inclusi oggetti e funzioni.
- Una `Map` offre migliori prestazioni rispetto all'oggetto standard quando si tratta di aggiunte e rimozioni frequenti di coppie chiave-valore.
- Puoi creare una `Map` usando il costruttore `Map()`.

- Le mappe possono essere manipolate usando questi metodi:

  - `set()`: aggiunge una nuova coppia chiave-valore alla `Map`.
  - `get()`: recupera il valore di una chiave dalla `Map`.
  - `delete()`: rimuove una coppia chiave-valore dalla `Map`.
  - `has()`: verifica se una chiave esiste nella `Map`.
  - `clear()`: rimuove tutte le coppie chiave-valore dalla `Map`.

Nota che sia le map che i set hanno la proprietà `size` che restituisce il numero di elementi unici al loro interno.

## WeakMap in JavaScript

- Una `WeakMap` è una collezione di coppie chiave-valore proprio come `Map`, ma con riferimenti deboli alle chiavi. Le chiavi devono essere un oggetto e i valori possono essere qualsiasi cosa tu voglia.

## Mappe vs WeakMappe

## Archiviazione persistente

## Creare, leggere, aggiornare, eliminare (CRUD)

- **Creare**: Si riferisce al processo di creare nuovi dati. Per esempio, in un'app web, questo può essere quando un utente aggiunge un nuovo post a un blog.
- **Leggere**: Questa è l'operazione in cui i dati vengono recuperati da un database. Per esempio, quando visiti un post del blog o visualizzi il tuo profilo su un sito web, stai eseguendo un'operazione di lettura per recuperare e mostrare i dati memorizzati nel database.
- **Aggiornare**: Questo comporta la modifica di dati esistenti nel database. Un esempio è modificare un post del blog o aggiornare le informazioni del profilo.
- **Eliminare**: Questa è l'operazione che rimuove dati da un database. Per esempio, quando elimini un post del blog o un account, stai eseguendo un'operazione di eliminazione.

## Metodi HTTP

- **Definizione**: HTTP sta per Hypertext Transfer Protocol ed è la base per la comunicazione dei dati sul web. Esistono metodi HTTP che definiscono le azioni che possono essere eseguite sulle risorse tramite il web. I metodi comuni sono GET, POST, PUT, PATCH, DELETE.
- **Metodo `GET`**: Serve per recuperare dati da un server.
- **Metodo `POST`**: Serve per inviare dati a un server che crea una nuova risorsa.
- **Metodo `PUT`**: Serve per aggiornare una risorsa sostituendola completamente.
- **Metodo `PATCH`**: Serve per aggiornare parzialmente una risorsa.
- **Metodo `DELETE`**: Serve per rimuovere record da un database.

I due componenti principali della Web Storage API sono le proprietà `localStorage` e `sessionStorage`.

- **Metodo `sessionStorage.getItem()`**: Questo metodo serve per recuperare il valore di una chiave data da `sessionStorage`.

## Lavorare con i cookie

- **Definizione**: I cookie, noti anche come cookie web o cookie del browser, sono piccoli pezzi di dati che un server invia al browser web di un utente. Questi cookie vengono memorizzati sul dispositivo dell'utente e inviati nuovamente al server con le richieste successive. I cookie sono essenziali per aiutare le applicazioni web a mantenere lo stato e ricordare le informazioni dell'utente, cosa particolarmente importante dato che HTTP è un protocollo senza stato.
- **Cookie di sessione**: Questi cookie durano solo per la durata della sessione dell'utente sul sito web. Una volta che l'utente chiude il browser o la scheda, il cookie di sessione viene eliminato. Questi cookie sono tipicamente usati per attività come mantenere un utente connesso durante la visita.
- **Cookie sicuri**: Questi cookie vengono inviati solo tramite HTTPS, garantendo che non possano essere intercettati da un attaccante durante il trasferimento.
- **Cookie HttpOnly**: Questi cookie non possono essere consultati o modificati da JavaScript in esecuzione nel browser, rendendoli più sicuri contro attacchi di cross-site scripting (XSS).
- **Intestazione Set-Cookie**: Quando visiti un sito web, il server può inviare un'intestazione Set-Cookie nella risposta HTTP. Questa intestazione dice al browser di salvare un cookie con informazioni specifiche. Per esempio, potrebbe memorizzare un ID univoco che aiuta il sito a riconoscerti la prossima volta che visiti.
Puoi impostare manualmente un cookie in JavaScript usando `document.cookie`:

```js
document.cookie = "organization=freeCodeCamp; expires=Fri, 31 Dec 2021 23:59:59 GMT; path=/";
```

Per eliminare un cookie, puoi impostare la sua data di scadenza a un momento nel passato.

## Cache API

- **Definizione**: La cache è il processo di memorizzare copie di file in una posizione di archiviazione temporanea, così da poterli consultare più rapidamente. La Cache API serve per memorizzare richieste e risposte di rete, rendendo le applicazioni web più efficienti e capaci di funzionare anche offline. Fa parte della più ampia Service Worker API ed è fondamentale per creare Progressive Web App (PWA) che funzionano anche in condizioni di rete lente o inaffidabili.
La Cache API è un meccanismo di archiviazione che conserva oggetti Request e Response. Quando viene fatta una richiesta a un server, l'applicazione può memorizzare la risposta e poi recuperarla dalla cache invece di fare una nuova richiesta di rete. Questo riduce i tempi di caricamento, risparmia banda e migliora l'esperienza utente complessiva.
- **Archivio cache**: Serve per memorizzare coppie chiave-valore di richieste HTTP e delle loro risposte corrispondenti. Questo permette un recupero efficiente delle risorse già richieste, riducendo la necessità di scaricarle nuovamente dalla rete nelle visite successive e migliorando le prestazioni.
- **Cache-Control**: Gli sviluppatori possono definire per quanto tempo una risorsa in cache deve essere mantenuta e se deve essere riconsultata o servita direttamente dalla cache.
- **Supporto offline**: Usando la Cache API, puoi creare applicazioni web che funzionano prima offline. Per esempio, una PWA può servire risorse memorizzate in cache quando l'utente è disconnesso dalla rete.

## Pattern negativi e archiviazione lato client

- **Tracciamento eccessivo**: Si riferisce alla pratica di raccogliere e memorizzare una quantità eccessiva di dati utente nell'archiviazione lato client (come cookie, local storage o session storage) senza un consenso chiaro, informato o una necessità legittima. Spesso comporta il tracciamento del comportamento, delle preferenze e delle interazioni dell'utente su più siti o sessioni, il che può violare la privacy dell'utente.
- **Fingerprinting del browser**: Tecnica usata per tracciare e identificare utenti individuali basandosi su caratteristiche uniche del loro dispositivo e browser, invece di affidarsi a cookie o altri metodi tradizionali di tracciamento. A differenza dei cookie, che sono memorizzati localmente sul dispositivo dell'utente, il fingerprinting raccoglie una serie di informazioni che possono essere usate per creare un "impronta" distintiva della sessione del browser dell'utente.
- **Memorizzare password in LocalStorage**: Questo può sembrare un pattern negativo ovvio, ma memorizzare dati sensibili come password nel local storage rappresenta un rischio per la sicurezza. Il local storage non è criptato e può essere facilmente consultato. Quindi non dovresti mai memorizzare dati sensibili di alcun tipo lì.

## IndexedDB

- **Definizione**: IndexedDB serve per memorizzare dati strutturati nel browser. È integrato nei browser moderni, permettendo alle app web di archiviare e recuperare oggetti JavaScript in modo efficiente.

## Cache/Service Worker

- **Definizione**: Un Service Worker è uno script che gira in background separatamente dalla tua pagina web. Può intercettare richieste di rete, consultare la cache e far funzionare l'app web offline. È un componente chiave delle Progressive Web App.

## Nozioni di base sul lavoro con le classi

- **Definizione**: Le classi in JavaScript servono a definire modelli per creare oggetti e incapsulare dati. Le classi includono un costruttore, un metodo speciale che viene chiamato automaticamente quando si crea un nuovo oggetto dalla classe. Serve per inizializzare le proprietà dell'oggetto. La parola chiave `this` viene usata qui per riferirsi all'istanza corrente della classe. Sotto il costruttore, puoi avere quelli che si chiamano metodi. I metodi sono funzioni definite all'interno di una classe che eseguono azioni o operazioni sui dati o sullo stato della classe. Servono a definire i comportamenti che le istanze della classe possono eseguire.

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);  // Gino
```

:::

Per creare una nuova istanza della classe, usa la parola chiave `new` seguita dal nome della classe.

Puoi anche creare classi come espressioni di classe. In questo caso la classe è anonima e assegnata a una variabile.

## Ereditarietà delle classi

- **Definizione**: nella programmazione, l'ereditarietà ti permette di definire classi che ereditano proprietà e metodi da classi genitrici. Questo favorisce il riutilizzo del codice e stabilisce una relazione gerarchica tra le classi. Una classe genitrice è una classe che funge da modello per altre classi. Definisce proprietà e metodi che vengono ereditati da altre classi. Una classe figlia è una classe che eredita le proprietà e i metodi di un'altra classe. Le classi figlie possono anche estendere la funzionalità delle loro classi genitrici aggiungendo nuove proprietà e metodi. In JavaScript, usiamo la parola chiave `extends` per implementare l'ereditarietà. Questa parola chiave indica che una classe è la classe figlia di un'altra classe.

La parola chiave `super` viene usata per consultare i metodi, i costruttori e i campi della classe genitrice.

:::interactive_editor

```js
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  constructor(brand, year, numDoors) {
    super(brand, year);
    this.numDoors = numDoors;
  }
}

const myCar = new Car("freeCodeCamp Motors", 2019, 4);
console.log(myCar.brand);  // freeCodeCamp Motors
console.log(myCar.year);  // 2019
console.log(myCar.numDoors);  // 4
```

## Lavorare con metodi statici e proprietà statiche

- **Metodi statici**: Questi metodi sono spesso usati per funzioni di utilità che non richiedono di consultare lo stato specifico di un oggetto. Vengono definiti all'interno delle classi per racchiudere funzionalità correlate.

Usa la parola chiave `static` per definire un metodo statico e chiamalo direttamente sulla classe.

I metodi statici sono utili anche per implementare metodi "factory". Un metodo factory è un metodo che definisci oltre al costruttore per creare oggetti basati su criteri specifici.

- **Proprietà statiche**: Queste proprietà servono a definire valori o attributi associati alla classe stessa, non alle istanze della classe. Le proprietà statiche sono condivise da tutte le istanze della classe e possono essere consultate senza creare un'istanza della classe.

Ad esempio, `static numberOfWheels = 4;` definisce una proprietà statica all'interno di una classe.

- La ricorsione è un concetto di programmazione che ti permette di chiamare una funzione ripetutamente fino a raggiungere un caso base.

Ecco un esempio di funzione ricorsiva che calcola il fattoriale di un numero:

```js
function findFactorial(n) {
  if (n === 0) {
    return 1;
  }
  return n * findFactorial(n - 1);
}
```

Nell'esempio sopra, la funzione `findFactorial` viene chiamata ricorsivamente fino a quando `n` raggiunge `0`. Quando `n` è `0`, si raggiunge il caso base e la funzione restituisce `1`. La funzione poi restituisce il prodotto di `n` e il risultato della chiamata ricorsiva a `findFactorial(n - 1)`.

- La ricorsione ti permette di gestire qualcosa con una profondità sconosciuta, come oggetti/array profondamente annidati o un albero dei file.
- Uno stack di chiamate viene usato per tenere traccia delle chiamate di funzione in una funzione ricorsiva. Ogni volta che una funzione viene chiamata, viene aggiunta allo stack di chiamate. Quando si raggiunge il caso base, le chiamate di funzione vengono rimosse dallo stack.
- Devi definire con attenzione il caso base perché chiamarlo indefinitamente può far crashare il tuo codice. Questo succede perché la ricorsione continua ad accumulare sempre più chiamate di funzione finché il sistema esaurisce la memoria.
- Le ricorsioni trovano impiego nella risoluzione di problemi matematici come il fattoriale e Fibonacci, nell'attraversamento di alberi e grafi, nella generazione di permutazioni e combinazioni e molto altro.

## Algoritmi e notazione Big O

- **Algoritmi**: Un insieme di istruzioni non ambigue per risolvere un problema o svolgere un’attività. Gli algoritmi devono terminare in un numero finito di passaggi e ogni passaggio deve essere preciso e non ambiguo.

- **Notazione Big O**: Descrive la performance nel caso peggiore, o il tasso di crescita, di un algoritmo all’aumentare della dimensione dell’input. Si concentra su come l’uso delle risorse cresce con la dimensione dell’input, ignorando fattori costanti e termini di ordine inferiore.

### Complessità temporali comuni

- **O(1) - Tempo costante**: L’algoritmo impiega lo stesso tempo indipendentemente dalla dimensione dell’input.

- **O(log n) - Tempo logaritmico**: Il tempo aumenta lentamente all’aumentare dell’input. Comune in algoritmi che riducono ripetutamente la dimensione del problema di una frazione (come la ricerca binaria).

- **O(n) - Tempo lineare**: Il tempo di esecuzione cresce proporzionalmente alla dimensione dell’input.

- **O(n log n) - Tempo log-lineare**: Complessità temporale comune di algoritmi di ordinamento efficienti come merge sort e quick sort.

- **O(n²) - Tempo quadratico**: Il tempo di esecuzione cresce quadraticamente. Spesso visto in loop annidati.

### Complessità spaziale

- **O(1) - Spazio costante**: L’algoritmo usa la stessa quantità di memoria indipendentemente dalla dimensione dell’input.
- **O(n) - Spazio lineare**: L’uso di memoria cresce proporzionalmente alla dimensione dell’input.
- **O(n²) - Spazio quadratico**: L’uso di memoria cresce quadraticamente con la dimensione dell’input.

## Tecniche di risoluzione dei problemi

- **Comprendere il problema**: Leggi più volte l’enunciato del problema. Identifica l’input, l’output atteso e come trasformare l’input in output.

- **Pseudocodice**: Descrizione ad alto livello della logica dell’algoritmo indipendente dal linguaggio. Usa linguaggio scritto comune mescolato a costrutti di programmazione come `IF`, `ELSE`, `FOR`, `WHILE`.

- **Casi limite**: Input specifici e validi che si trovano ai confini di ciò che un algoritmo dovrebbe gestire. Considera e testa sempre i casi limite.

## Array

- **Array statici**: Hanno una dimensione fissa determinata all’inizializzazione. Gli elementi sono archiviati in posizioni di memoria adiacenti. La dimensione non può essere cambiata durante l’esecuzione del programma.

- **Array dinamici**: Possono crescere o ridursi automaticamente durante l’esecuzione del programma. Gestiscono il ridimensionamento tramite copia automatica in array più grandi quando necessario.

### Implementazione degli array dinamici in JavaScript

Gli array JavaScript sono array dinamici. Puoi consultare e aggiornare gli elementi tramite indice, aggiungere elementi con `push()` e rimuoverli con `pop()` o `splice()`.

### Complessità temporali per array dinamici

- **Consultare**: O(1)
- **Inserire alla fine**: O(1) in media, O(n) quando serve ridimensionare
- **Inserire in mezzo**: O(n)
- **Eliminare**: O(n) per mezzo, O(1) per fine

## Stack

- **Stack**: Struttura dati Last-In, First-Out (LIFO). Gli elementi si aggiungono e rimuovono solo dalla cima.

- **Operazione push**: Aggiungere un elemento in cima allo stack. Complessità temporale: O(1).

- **Operazione pop**: Rimuovere un elemento dalla cima dello stack. Complessità temporale: O(1).

Un array JavaScript può funzionare come uno stack usando `push()` per aggiungere elementi e `pop()` per rimuoverli.

## Code

- **Code**: Struttura dati First-In, First-Out (FIFO). Gli elementi si aggiungono in coda e si rimuovono dalla testa.

- **Operazione enqueue**: Aggiungere un elemento in coda alla coda. Complessità temporale: O(1).

- **Operazione dequeue**: Rimuovere un elemento dalla testa della coda. Complessità temporale: O(1).

Un array può funzionare come una coda usando `push()` per inserire e `shift()` per rimuovere. Tuttavia, `shift()` richiede tempo O(n) perché gli elementi rimanenti devono essere spostati.

## Liste concatenate

- **Liste concatenate**: Struttura dati lineare in cui ogni nodo contiene dati e un riferimento al nodo successivo. I nodi sono collegati come una catena.

### Liste concatenate singole

- **Struttura**: Ogni nodo ha dati e un riferimento al nodo successivo.
- **Attraversamento**: Si può muovere solo in avanti dalla testa alla coda.
- **Nodo testa**: Primo nodo della lista, solitamente l'unico nodo accessibile direttamente.
- **Nodo coda**: Ultimo nodo della lista, punta a `null`.

### Operazioni e complessità temporali

- **Inserire all’inizio**: O(1)
- **Inserire alla fine**: O(n) - bisogna attraversare fino alla fine
- **Inserire in mezzo**: O(n) - bisogna attraversare fino alla posizione
- **Eliminare dall’inizio**: O(1)
- **Eliminare dalla fine**: O(n) - bisogna attraversare per trovare il nodo precedente
- **Eliminare da mezzo**: O(n) - bisogna attraversare per trovare il nodo

### Liste concatenate doppie

- **Struttura**: Ogni nodo ha dati e due riferimenti: al nodo successivo e al nodo precedente.
- **Attraversamento**: Puoi muoverti in entrambe le direzioni.
- **Memoria**: Richiede più memoria rispetto alle liste concatenate singole a causa del riferimento extra.

## Quando usare ogni struttura dati

- **Array (array dinamici)**: Quando serve un accesso ordinato e indicizzato e non si conosce la dimensione in anticipo
- **Stack**: Per operazioni LIFO (funzionalità annulla, valutazione di espressioni, backtracking)
- **Code**: Per operazioni FIFO (pianificazione attività, ricerca in ampiezza)
- **Liste concatenate**: Quando servono inserimenti/eliminazioni frequenti all'inizio, dimensione sconosciuta, nessun accesso casuale necessario

## Algoritmi di ricerca

Gli algoritmi di ricerca ti permettono di cercare un obiettivo all'interno di una certa lista di elementi.

In informatica, ci sono due algoritmi di ricerca che dovresti conoscere. Sono gli algoritmi di **ricerca lineare** e **ricerca binaria**. È importante capire le differenze tra i due algoritmi e quando usare ciascuno.

### Ricerca lineare

- La ricerca lineare itera attraverso un array di elementi, controllando ogni elemento dall'inizio finché non trova l'elemento obiettivo.
- Se l'elemento obiettivo viene trovato, viene restituito l'indice in cui si trova nell'array.
- Se l'obiettivo non viene trovato, restituisce `-1`, che in JavaScript significa **indice non valido**.
- Poiché la ricerca lineare controlla ogni elemento finché non trova l'obiettivo, non è efficiente per un array di grandi dimensioni.
- La complessità temporale della ricerca lineare è `O(n)` perché il tempo necessario per cercare nell'array cresce linearmente con la dimensione dell'array.
- La complessità spaziale della ricerca lineare è `O(1)` perché non richiede spazio aggiuntivo per cercare nell'array.

### Ricerca binaria

- La ricerca binaria funziona dividendo a metà un array di elementi e controllando se il valore obiettivo si trova nel mezzo dell'array.
- La condizione perché la ricerca binaria funzioni è che gli elementi nell'array devono essere ordinati, sia in ordine crescente sia decrescente.
- La ricerca binaria è un algoritmo più efficiente per cercare in un array di grandi dimensioni perché divide l'array a metà e ignora qualsiasi metà in cui l'obiettivo non si trova.
- Se l'elemento obiettivo viene trovato nel mezzo dell'array, viene restituito l'indice dell'elemento obiettivo.
- Se l'elemento non viene trovato, l'algoritmo controlla se l'obiettivo si trova nella metà sinistra o destra dell'array.
- Continua a dividere le parti rimanenti dell'array in metà finché non trova l'elemento obiettivo.
- Se l'elemento obiettivo non viene trovato nell'array, restituisce `-1`.
- La complessità temporale della ricerca binaria è `O(log n)` perché il tempo necessario per cercare nell'array cresce in modo logaritmico con la dimensione dell'array.
- La complessità spaziale della ricerca binaria è `O(1)` perché non richiede spazio aggiuntivo per cercare nell'array.

### Come la ricerca lineare differisce dalla ricerca binaria

- La ricerca binaria è più adatta per un array di grandi dimensioni rispetto alla ricerca lineare.
- La complessità temporale della ricerca lineare è `O(n)` perché il tempo necessario per cercare nell'array cresce linearmente con la dimensione dell'array.
- La complessità temporale della ricerca binaria è `O(log n)` perché il tempo necessario per cercare nell'array cresce in modo logaritmico con la dimensione dell'array.

## Algoritmi di ordinamento e divide-et-impera

In informatica, divide-et-impera è una tecnica usata per suddividere un problema in sotto-problemi più piccoli così da renderli più facili da risolvere. La ricorsione è la tecnica spesso impiegata nel divide-et-impera, e questa è una strategia potente usata per implementare molti algoritmi di ordinamento efficienti come il merge sort.

### Merge sort

- Merge sort è un algoritmo di ordinamento che segue l'approccio divide-et-impera.
- Funziona dividendo ricorsivamente un array in sotto-array più piccoli finché ogni sotto-array contiene un solo elemento.
- Poi unisce ripetutamente i sotto-array insieme in ordine ordinato.
- La complessità temporale del merge sort è `O(n log n)` perché l'array viene continuamente diviso a metà `(log n)` e poi unito `(O(n))`.
- La complessità spaziale del merge sort è `O(n)` perché non è un algoritmo di ordinamento in-place.

## Panoramica sui grafi

Un grafo è un insieme di nodi (vertici) collegati da archi (connessioni). Ogni nodo può collegarsi a più altri nodi, formando una rete. I diversi tipi di grafi includono:

- **Orientato**: Gli archi hanno una direzione (da un nodo a un altro), spesso rappresentati con linee rette e frecce.
- **Non orientato**: Gli archi non hanno direzione, rappresentati con linee semplici.
- **Nodo etichettato**: Ogni nodo è associato a un'etichetta o identificatore.
- **Ciclico**: Contiene cicli (un percorso che inizia e termina nello stesso nodo).
- **Grafo orientato aciclico (DAG)**: Un grafo orientato senza cicli.
- **Arco etichettato**: Ogni arco ha un'etichetta solitamente disegnata accanto all'arco corrispondente.
- **Pesato**: Gli archi hanno pesi (valori) associati che possono essere usati per eseguire operazioni aritmetiche.
- **Disconnesso**: Contiene due o più gruppi di nodi (componenti) che non sono collegati da alcun arco. Due nodi possono non avere un arco diretto ma comunque avere un percorso tra loro.

I grafi sono usati in varie applicazioni come mappe, reti, sistemi di raccomandazione e risoluzione delle dipendenze.

## Attraversamenti di grafi

Consiste nel visitare tutti i nodi di un grafo. I due algoritmi principali sono:

- **Ricerca in ampiezza (BFS)**: Visita tutti i nodi vicini prima di passare al livello successivo nel grafo.
  - **Coda**: Usa una coda (FIFO). Il nodo di partenza viene marcato come visitato e aggiunto alla coda. Finché la coda non è vuota, il nodo corrente viene estratto e ciascuno dei suoi vicini non visitati viene marcato come visitato e aggiunto alla coda.
  - **Percorso più breve**: Trova il percorso più breve nei grafi non pesati.
  - **Memoria**: Richiede di conservare una coda in memoria, quindi lo spazio richiesto può essere considerevole, specialmente per grafi con molti nodi allo stesso livello.
  - **Componenti connesse**: Può essere usata anche per trovare componenti connesse del grafo, iniziando una nuova ricerca da ogni nodo non ancora visitato.
  - **Ricerca nello spazio degli stati**: Usa una coda per tracciare diversi stati mentre costruisce le combinazioni di parentesi. Ogni stato è rappresentato come un array contenente la stringa corrente in costruzione, il numero di parentesi aperte usate finora e il numero di parentesi chiuse usate finora. Una parentesi aperta può essere aggiunta solo se il numero di parentesi aperte usate è inferiore al numero di coppie. Una parentesi chiusa può essere aggiunta solo se mantiene l'equilibrio, cioè ci devono essere più parentesi aperte usate che chiuse.

- **Ricerca in profondità (DFS)**: Segue ogni ramo il più a fondo possibile prima di tornare indietro.
  - **Stack**: Usa uno stack (LIFO) o la ricorsione. Il nodo di partenza viene marcato come visitato e aggiunto allo stack. Finché lo stack non è vuoto, il nodo corrente viene estratto e i suoi vicini non visitati vengono marcati come visitati e aggiunti allo stack.
  - **Memoria**: Richiede di conservare uno stack (o lo stack delle chiamate di funzione, quando si usa la ricorsione) in memoria, quindi lo spazio richiesto può crescere in grafi con percorsi molto lunghi.
  - **Casi d'uso**: Utile per rilevare cicli, trovare percorsi e trovare componenti connesse.
  - **Limitazione**: Non garantisce sempre di trovare il percorso più breve tra due nodi in un grafo non pesato.

## Rappresentazioni dei grafi

I grafi possono essere rappresentati in due modi principali:

- **Lista di adiacenza**: Ogni nodo ha una lista dei suoi vicini.
  - **Implementazioni**: Come array, dove ogni indice rappresenta un nodo e l'array memorizzato a quell'indice contiene i suoi vicini. Come oggetto (o `Map`), dove ogni chiave rappresenta un nodo e il valore associato a quella chiave (un array) contiene i suoi vicini.
  - **Spazio**: Efficiente in termini di spazio per grafi sparsi, con complessità spaziale `O(V + E)`, dove `V` è il numero di vertici (nodi) e `E` è il numero di archi.
  - **Vicini**: Facile iterare sui vicini, poiché questa operazione richiede solo di consultare la lista associata al nodo.
  - **Ricerca arco**: Meno efficiente delle matrici di adiacenza per determinare se esiste un arco tra due nodi. Tipicamente richiede tempo `O(deg(v))`, dove `deg(v)` è il numero di vicini del nodo che stai controllando, e nel peggior caso può essere `O(V)`.
  - **Ideale per**: Solitamente la scelta preferita per scenari reali, dove i grafi sparsi sono più comuni.

- **Matrice di adiacenza**: Un array 2D dove righe e colonne rappresentano i nodi.
  - **Valori**: Se il grafo non è pesato, un valore di `1` indica che c'è un arco che collega questi nodi, mentre un valore di `0` indica che non c'è alcun arco tra loro. Se il grafo è pesato, il valore rappresenta il peso dell'arco che collega i nodi.
  - **Anelli su se stessi**: I valori sulla diagonale rappresentano se ogni nodo ha un anello su se stesso, un arco che collega il nodo a sé stesso.
  - **Spazio**: Richiede molto spazio per grafi grandi, con un requisito quadratico `O(V²)`, dove `V` è il numero di nodi nel grafo.
  - **Ricerca arco**: Veloce per verificare se esiste un arco tra due nodi, poiché richiede tempo costante `O(1)`.
  - **Vicini**: Inefficiente per trovare i vicini di un nodo, perché il programma deve iterare su tutta la riga o colonna. Nel peggior caso, questo richiede tempo `O(V)`.
  - **Ideale per**: Utile per grafi densi con molti archi. Inefficiente per grafi sparsi, che hanno pochi archi.

## Algoritmo del percorso più breve

- **Algoritmo del percorso più breve**: Calcola il percorso più breve tra nodi in un grafo pesato e restituisce sia le distanze sia i percorsi seguiti.
  - **Matrice di adiacenza**: Ogni valore rappresenta il peso (distanza) dell'arco tra due nodi.
  - **Archi mancanti**: Un valore di `INF` (`Infinity`) indica che non esiste un arco diretto.
  - **Distanze**: Un array che tiene traccia della distanza più breve conosciuta dal nodo di partenza a ogni altro nodo. All'inizio, ogni nodo è considerato infinitamente lontano, e la distanza dal nodo di partenza a sé stesso è sempre `0`.
  - **Percorsi**: Una lista dove ogni voce è un array di indici dei nodi che rappresentano la rotta seguita per raggiungere ogni nodo.
  - **Visitati**: Un array che traccia quali nodi sono già stati processati per evitare di visitarli di nuovo.
  - **Nodo non visitato più vicino**: Il ciclo principale viene eseguito una volta per ogni nodo nel grafo, selezionando ogni volta il nodo non visitato più vicino.
  - **Rilassamento degli archi**: Per ogni vicino con un arco reale non ancora visitato, verifica se puoi raggiungerlo in modo più efficiente passando per il nodo corrente. Se la nuova distanza è migliore di quella già memorizzata, aggiorna la distanza e il percorso.
  - **Nodi irraggiungibili**: Quando non si trova alcun nodo valido, tutti i nodi rimanenti sono irraggiungibili, quindi il ciclo si interrompe anticipatamente.
  - **Obiettivo opzionale**: Il parametro `targetNode` è opzionale. Se non fornito, la funzione calcola i percorsi più brevi da `startNode` a tutti gli altri nodi nel grafo.

## Alberi

Un albero è un tipo speciale di grafo che è aciclico e connesso. Le proprietà chiave includono:

- **Acilico**: Un albero non ha loop o cicli (percorsi in cui i nodi di partenza e arrivo sono gli stessi).
- **Connesso**: Ogni nodo può essere raggiunto da ogni altro nodo.

### Terminologia degli alberi

- **Nodo radice**: La cima di un albero. È l'unico nodo nell'albero senza un nodo genitore.
- **Nodo genitore**: Un nodo immediatamente collegato ad altri nodi sottostanti.
- **Nodo figlio**: Un nodo immediatamente collegato a un nodo sopra di esso.
- **Foglia**: Un nodo che non ha nodi figli.
- **Profondità**: La lunghezza del percorso dalla radice a quel nodo.
- **Altezza**: La lunghezza del percorso da quel nodo fino a una foglia. L'altezza di un albero è l'altezza del suo nodo radice.
- **Grado**: Il numero di nodi figli che ogni nodo ha.
- **Sottoalbero**: Una sezione di un albero che è essa stessa un albero.
- **Albero bilanciato**: Un albero in cui le altezze dei sottoalberi sinistro e destro di ogni nodo sono molto simili per garantire che le operazioni rimangano efficienti.

### Tipi comuni di alberi

I tipi più comuni di alberi sono:

- **Alberi binari**: Ogni nodo ha al massimo due figli, un figlio sinistro e un figlio destro.

- **Alberi binari di ricerca (BST)**: Un albero binario in cui, per ogni nodo, tutti i valori nel suo sottoalbero sinistro sono minori del valore del nodo, e tutti i valori nel suo sottoalbero destro sono maggiori del valore del nodo. I sottoalberi sinistro e destro devono essere anch'essi alberi binari di ricerca.

- **Alberi auto-bilancianti**: Alberi che contengono una logica interna aggiuntiva che riequilibra l'albero quando inserimenti o cancellazioni creano uno stato di squilibrio. Esempi comuni includono alberi AVL, alberi rosso-neri e alberi B.

- **Alberi AVL**: Un tipo di albero binario di ricerca auto-bilanciante in cui le altezze dei sottoalberi sinistro e destro di ogni nodo differiscono al massimo di uno.

- **Alberi rosso-neri**: Un tipo di albero binario di ricerca auto-bilanciante in cui ogni nodo è colorato di rosso o nero.

- **Alberi B**: Un tipo di albero auto-bilanciante in cui ogni nodo può avere più chiavi e più di due nodi figli.

## Trie

- **Trie**: Conosciuti anche come alberi dei prefissi, sono usati per archiviare insiemi di stringhe, dove ogni nodo rappresenta un carattere.
- **Nodo radice**: Il nodo radice non rappresenta alcun carattere particolare, quindi puoi pensarlo come rappresentante una stringa vuota.
- **Prefissi**: Scorrendo il trie dalla radice, il percorso verso un nodo definisce un prefisso specifico.
- **Marcatori di fine parola**: I nodi che rappresentano parole complete hanno marcatori di fine parola.
- **Prefissi condivisi**: Quando più stringhe condividono lo stesso prefisso, i loro percorsi si sovrappongono, quindi il prefisso stesso è memorizzato una sola volta. Questo rende i trie efficienti per attività come l'autocompletamento e il controllo ortografico.
- **Inserimento**: Richiede solo di creare nuovi nodi per i caratteri che non esistono ancora nel trie.
- **Complessità temporale**: Le operazioni di ricerca e inserimento richiedono tempo `O(L)`, dove `L` è la lunghezza della stringa.
- **Memoria**: I trie possono essere inefficienti se l'insieme di stringhe ha molti caratteri unici, perché questo richiede di memorizzare molti caratteri unici come nodi individuali.

## Code di priorità

- **Coda di priorità**: Un tipo astratto di struttura dati in cui ogni elemento ha una priorità.
- **Code e stack**: Code e stack considerano solo l'ordine di inserimento, mentre le code di priorità considerano la priorità degli elementi. Le code standard seguono FIFO (First In First Out) e gli stack seguono LIFO (Last In First Out).
- **Ordine di rimozione**: Di solito, l'elemento con la priorità più alta viene rimosso per primo, ma alcune implementazioni possono scegliere di rimuovere per prime anche le priorità più basse.
- **Pari merito**: Se hai bisogno che gli elementi con la stessa priorità vengano rimossi nell'ordine in cui sono stati inseriti, puoi includere un contatore unico per risolvere il pareggio.
- **Applicazioni**: Trovare il percorso più breve tra due località, pianificare attività nei sistemi operativi, simulare il traffico, comprimere dati e gestire reti.

## Heap

Un heap è una struttura dati specializzata basata su un albero con una proprietà molto specifica chiamata proprietà di heap.

La proprietà di heap determina la relazione tra nodi genitori e figli. Ci sono due tipi di heap:

- **Max-Heap**: Il valore di ogni nodo genitore è maggiore o uguale ai valori dei suoi figli, e l'elemento più grande si trova nella radice.

- **Min-Heap**: Il valore di ogni nodo genitore è minore o uguale ai valori dei suoi figli, e l'elemento più piccolo si trova nella radice.

JavaScript non ha un modulo heap integrato, ma puoi implementare un min-heap usando un array.

- **Archiviazione in array**: Gli heap sono tipicamente implementati come array per consultare efficientemente i nodi genitore e figlio. Se l'heap mantiene la struttura di un albero binario completo, l'implementazione tramite array richiede solo semplici operazioni matematiche basate sugli indici per trovare dove si trovano gli elementi.
- **Indici**: Per il nodo all'indice `i`, il genitore si trova all'indice `Math.floor((i - 1) / 2)`, il figlio sinistro all'indice `2 * i + 1` e il figlio destro all'indice `2 * i + 2`.
- **Peek**: Ottenere il valore minimo o massimo (a seconda del tipo di heap) senza rimuoverlo.
- **Push**: Aggiunge un elemento nella posizione corretta per preservare la proprietà di heap. Il nuovo elemento viene aggiunto alla fine dell'array e poi spostato verso l'alto, scambiando posto con il genitore, finché la proprietà di heap è preservata (bubble-up).
- **Pop**: Rimuove l'elemento con la priorità più alta (in questo caso, il valore più piccolo). L'ultimo elemento dell'array sostituisce la radice e viene poi spostato verso il basso, scambiando posto con il figlio più piccolo, finché la proprietà di heap è preservata (bubble-down).
- **PushPop**: Combina entrambe le operazioni in una sola chiamata. È più efficiente che chiamarle separatamente in sequenza, specialmente quando l'heap è grande, perché esegue solo un'operazione di riordinamento.
- **Heapify**: Trasforma un array esistente in un heap.
- **Callback di confronto**: Gli array non vengono confrontati automaticamente elemento per elemento per l'ordinamento in JavaScript, quindi si passa una funzione di confronto all'heap che confronta prima le priorità, come `new MinHeap((a, b) => a[0] - b[0])` per elementi archiviati come `[priority, element]`. Valori più bassi rappresentano priorità più alte.
- **Risoluzione stabile dei pareggi**: Includi un contatore di inserimento crescente come secondo elemento di ogni elemento, così: `[priority, counter, element]`. Confronta prima le priorità e poi i contatori quando le priorità sono uguali: `new MinHeap((a, b) => (a[0] - b[0]) || (a[1] - b[1]))`.
- **Complessità temporale**: Inserire ed estrarre il valore minimo o massimo è `O(log n)`, peek è `O(1)`, heapify è `O(n)`, e cercare o eliminare un elemento arbitrario è `O(n)`.
- **Complessità spaziale**: `O(n)`, dove `n` è il numero di elementi contenuti nell'heap.

## Introduzione alla programmazione dinamica

- **Definizione**: La programmazione dinamica è una tecnica algoritmica che risolve problemi complessi suddividendoli in sotto-problemi più semplici e memorizzando i risultati per evitare calcoli ridondanti.
- **Sovrapposizione di sotto-problemi**: Gli stessi sotto-problemi più piccoli appaiono più volte quando si risolve il problema più grande. Invece di ricalcolare questi sotto-problemi ripetutamente, memorizziamo le loro soluzioni.
- **Sottostruttura ottimale**: La soluzione ottimale al problema contiene soluzioni ottimali ai suoi sotto-problemi. Questo significa che possiamo costruire la soluzione migliore combinando le soluzioni migliori alle parti più piccole.

## Soluzioni di programmazione dinamica

- **Memoizzazione (approccio top-down)**: La memoizzazione memorizza i risultati di chiamate di funzione costose e restituisce il risultato memorizzato quando gli stessi input si ripresentano.

- **Tabulazione (approccio bottom-up)**: La tabulazione costruisce la soluzione dal basso verso l’alto, riempiendo una tabella con le soluzioni ai sotto-problemi.

## Applicazioni reali che usano la programmazione dinamica

- **Ottimizzazione delle rotte**: i sistemi GPS usano algoritmi di programmazione dinamica per trovare i percorsi più brevi tra le località.
- **Elaborazione del testo**: i correttori ortografici e le funzionalità di completamento automatico spesso si basano sulla programmazione dinamica per calcolare le distanze di modifica tra le parole.
- **Modellazione finanziaria**: le strategie di investimento e l'ottimizzazione del portfolio impiegano frequentemente tecniche di programmazione dinamica.
- **Assegnazione delle risorse**: il problema dello zaino e le sue varianti compaiono nella pianificazione, nel budgeting e nella gestione delle risorse.

## Quando usare la programmazione dinamica

Dovresti considerare di usare la programmazione dinamica nei seguenti casi:

- Il problema può essere suddiviso in sotto-problemi sovrapposti.
- Il problema presenta una struttura ottimale dei sotto-problemi.
- Una soluzione ricorsiva ingenua comporterebbe calcoli ripetuti.
- Hai bisogno di ottimizzare la complessità temporale a scapito della complessità spaziale.

## Funzioni pure vs impure

- Una funzione pura è quella che produce sempre lo stesso output per lo stesso input e non ha effetti collaterali. Il suo output dipende solo dal suo input e non modifica alcuno stato esterno.
- Le funzioni impure hanno effetti collaterali, cioè modifiche allo stato del programma che sono osservabili all’esterno della funzione.

## Programmazione funzionale

- La programmazione funzionale è un approccio allo sviluppo software che enfatizza l’uso delle funzioni per risolvere problemi, concentrandosi su cosa deve essere fatto piuttosto che su come farlo.
- La programmazione funzionale incoraggia l’uso di tecniche che aiutano a evitare effetti collaterali, come l’uso di strutture dati immutabili e funzioni di ordine superiore.
- Se usati correttamente, i principi della programmazione funzionale portano a codice più pulito e più facile da mantenere.

## Currying

- Il currying è una tecnica di programmazione funzionale che trasforma una funzione con più argomenti in una sequenza di funzioni, ognuna delle quali prende un singolo argomento.

Ad esempio, il currying trasforma una chiamata come `average(a, b, c)` in chiamate successive come `curriedAverage(a)(b)(c)`.

- Il currying può essere particolarmente potente quando si lavora con funzioni che accettano molti argomenti.
- Il currying rende il tuo codice più flessibile e più facile da riutilizzare.
- Puoi usare le funzioni freccia per creare funzioni curried in modo più conciso:

```js
const curriedAverage = a => b => c => (a + b + c) / 3;
```

- Anche se il currying può portare a un codice più flessibile e riutilizzabile, può anche rendere il codice più difficile da leggere se usato eccessivamente.

- Il **JavaScript sincrono** viene eseguito in sequenza e aspetta che l'operazione precedente finisca prima di passare a quella successiva.
- Il **JavaScript asincrono** permette di eseguire più operazioni in background senza bloccare il thread principale.
- Un **thread** è una sequenza di istruzioni che può essere eseguita indipendentemente dal flusso principale del programma.
- Le **funzioni di callback** sono funzioni passate come argomenti ad altre funzioni e vengono eseguite dopo il completamento dell’operazione o in seguito a un evento.

## Il motore JavaScript e l'ambiente di esecuzione JavaScript

- Il **motore JavaScript** è un programma che esegue codice JavaScript in un browser web. Funziona come un convertitore che prende il tuo codice, lo trasforma in istruzioni che il computer può capire ed eseguire di conseguenza.
- V8 è un esempio di motore JavaScript sviluppato da Google.
- Il **runtime JavaScript** è l’ambiente in cui il codice JavaScript viene eseguito. Include il motore JavaScript che elabora ed esegue il codice, e funzionalità aggiuntive come un browser web o Node.js.

## L'API Fetch

- L'API Fetch permette alle app web di fare richieste di rete, solitamente per recuperare o inviare dati al server. Fornisce un metodo `fetch()` che puoi usare per effettuare queste richieste.
- Puoi recuperare testo, immagini, audio, JSON e altri tipi di dati usando l'API Fetch.

## Metodi HTTP per Fetch API

La Fetch API supporta vari metodi HTTP per interagire con il server. I metodi più comuni sono:

- **GET**: usato per recuperare dati dal server. Per impostazione predefinita, la Fetch API usa il metodo `GET` per recuperare i dati.

Per usare i dati recuperati, devono essere convertiti in formato JSON usando il metodo `.json()`:

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
```

In questo codice, `fetch()` restituisce una Promise, e il gestore `.then()` converte la risposta risolta in formato JSON.

- **POST**: usato per inviare dati al server. Il metodo `POST` viene usato per creare nuove risorse sul server.

```js
fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Doe',
    email: 'john@example.com'
  })
})
```

In questo esempio, stiamo inviando una richiesta `POST` per creare un nuovo utente. Abbiamo specificato il metodo come `POST`, impostato le intestazioni appropriate e incluso un corpo con i dati che vogliamo inviare. Il corpo deve essere una stringa, quindi usiamo `JSON.stringify()` per convertire il nostro oggetto in una stringa JSON.

- **PUT**: usato per aggiornare dati sul server. Il metodo `PUT` viene usato per aggiornare risorse esistenti sul server.

Per un aggiornamento, specifica `method: 'PUT'` e includi i dati aggiornati nel corpo della richiesta. L'URL identifica la risorsa da aggiornare.

- **DELETE**: usato per eliminare dati sul server. Il metodo `DELETE` viene usato per eliminare risorse sul server.

Imposta `method: 'DELETE'` e usa un URL che identifica la risorsa da rimuovere.

## Promise e concatenamento di promise

- Le **promise** sono oggetti che rappresentano il completamento eventuale o il fallimento di un’operazione asincrona e il suo valore risultante. Il valore della promise è noto solo quando l’operazione asincrona è completata.
- Ecco un esempio per creare una promise semplice:

```js
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```

- Il metodo `.then()` è usato in una Promise per specificare cosa succede quando la Promise è risolta, mentre `.catch()` gestisce eventuali errori che si verificano.

- **Concatenamento di promise**: Una delle potenti funzionalità delle Promise è la possibilità di concatenare più operazioni asincrone. Ogni `.then()` può restituire una nuova Promise, permettendo di eseguire una sequenza di operazioni asincrone una dopo l'altra.

Il metodo `catch` gestirebbe eventuali errori che si verificano durante il processo. Questo significa che non devi aggiungere la gestione degli errori a ogni passaggio, il che può semplificare molto il tuo codice.

## Usare `async/await` per gestire le promise

`async`/`await` rende più facile scrivere e leggere codice asincrono ed è costruito sopra le Promise.

- **async**: La parola chiave `async` è usata per definire una funzione asincrona. Una funzione `async` restituisce una Promise, che si risolve con il valore restituito dalla funzione `async`.
- **await**: La parola chiave `await` è usata all'interno di una funzione `async` per mettere in pausa l'esecuzione della funzione finché la Promise non viene risolta. Può essere usata solo dentro una funzione `async`.

- Uno dei vantaggi principali di `async/await` è la gestione degli errori tramite i blocchi `try/catch`. Ecco un esempio:

```js
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

fetchData();
```

Nell’esempio sopra, il blocco `try` contiene il codice che potrebbe lanciare un errore, e il blocco `catch` gestisce l’errore se si verifica. Questo rende la gestione degli errori più semplice e leggibile.

## L’attributo `async`

- L’attributo `async` dice al browser di scaricare il file script in modo asincrono mentre continua a parsare il documento HTML.
- Una volta scaricato lo script, il parsing HTML viene messo in pausa, lo script viene eseguito, e poi il parsing HTML riprende.
- Dovresti usare `async` per script indipendenti dove l’ordine di esecuzione non è importante.

## L’attributo `defer`

- L’attributo `defer` scarica anch’esso lo script in modo asincrono, ma differisce l’esecuzione dello script fino a dopo che il documento HTML è stato completamente parsato.
- Gli script `defer` mantengono l’ordine di esecuzione come appaiono nel documento HTML.

- È importante notare che entrambi gli attributi `async` e `defer` vengono ignorati per gli script in linea e funzionano solo per i file di script esterni.

- Quando sono presenti entrambi gli attributi `async` e `defer`, ha la precedenza l'attributo `async`.

## API Geolocation

- L'API di geolocalizzazione offre un modo per i siti web di richiedere la posizione dell'utente.

- L'esempio qui sotto dimostra il metodo `getCurrentPosition()` dell'API, che serve per ottenere la posizione attuale dell'utente.

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

In questo codice, stiamo chiamando `getCurrentPosition` e passando una funzione, che verrà eseguita quando la posizione sarà ottenuta con successo.

L'oggetto `position` contiene varie informazioni, ma qui abbiamo selezionato solo `latitude` e `longitude`.

Se c’è un problema nel recuperare la `position`, l’errore verrà stampato nella console.

- È importante rispettare la privacy dell’utente e richiedere la sua posizione solo quando necessario.
