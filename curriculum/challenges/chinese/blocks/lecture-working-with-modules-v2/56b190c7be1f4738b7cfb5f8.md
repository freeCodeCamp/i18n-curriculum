# --description--

正如你在上一课中学到的，模块是一个 Python 文件，它将相关的代码分组，这样你就可以在其他 Python 文件中重用它。

你也可以编写自己的模块并将它们导入到你的脚本中。创建自己的模块是组织代码的好方法。你不必只有一个很长的文件，而是可以将代码拆分成更小的文件，每个文件分组相关代码，然后在需要的地方导入它们。

例如，假设你创建了一个 `temperature.py` 文件，里面有两个用于转换温度的函数，还有一个函数调用用来检查其中一个函数是否有效：

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

如果你直接运行这个文件，输出如下：

```md
212.0
```

现在，假设你在与 `temperature.py` 相同的文件夹中创建另一个名为 `main.py` 的文件。要使用你本地模块中的函数，你可以用模块名（不带 `.py` 扩展名）导入它：

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

如果你运行 `main.py` 文件，输出如下：

```md
212.0
100.0
```

当导入 `temperature` 时，Python 会从上到下运行 `temperature.py` 中的所有代码。这就是为什么即使 `main.py` 只调用了 `fahrenheit_to_celsius()`，也会打印出 `212.0`。像这样的检查代码通常只想在直接执行文件时运行，而不是每次导入时都运行。

为控制这一点，你可以使用一个常见的 Python 习惯用法：

```python
if __name__ == '__main__':
    # Code
```

`__name__` 是 Python 中一个特殊的内置变量。

当 Python 文件被直接执行时，Python 会将这个变量的值设置为字符串 `__main__`。

但是如果 Python 文件作为模块被导入到另一个 Python 脚本中，`__name__` 变量的值将被设置为该模块的名称（通常是没有 `.py` 扩展名的文件名）。

这就是为什么你经常会在 Python 脚本中看到这个条件式。它包含了你只想在 Python 脚本作为主程序运行时执行的代码。如果脚本被作为模块导入，那个块内的代码就不会运行。

这很有帮助，因为它允许 Python 脚本有两个用途。它们可以直接运行以执行其主要逻辑，或者可以被导入到另一个模块中而不执行其主要逻辑。

这是更新后的 `temperature.py` 文件，使用了这个习惯用法。它还打印了 `__name__` 的值，这样你可以看到它是如何变化的：

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

如果你直接运行这个文件，Python 会将 `__name__` 设置为 `'__main__'`，所以条件为 `True`，`if` 块内的代码会执行。输出如下：

```md
The value of __name__ is: __main__
212.0
```

如果你改为运行 `main.py` 文件，输出如下：

```md
The value of __name__ is: temperature
100.0
```

`if` 块外的 `print()` 调用在导入 `temperature` 时仍然会运行，并显示 `__name__` 的值现在是模块名 `temperature`。

但由于 `__name__` 不等于 `'__main__'`，`if` 块内的代码不会运行，因此不会打印 `212.0`。唯一的其他输出是 `100.0`，它来自 `main.py` 中的函数调用。
