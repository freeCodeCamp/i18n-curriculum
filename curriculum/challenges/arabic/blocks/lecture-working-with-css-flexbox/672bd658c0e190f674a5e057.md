# --interactive--

تتحكم خصائص flex في كيفية تصرف العناصر داخل تخطيط مرن، من توزيع على مستوى الحاوية إلى محاذاة ذاتية على مستوى العنصر. سنغطي بعضًا من أكثرها استخدامًا في هذا الدرس: `flex-wrap`، `flex-flow`، `justify-content`، `align-items`، و`align-self`.

لنبدأ بـ `flex-wrap`. تحدد هذه الخاصية كيفية لف العناصر المرنة داخل الحاوية المرنة لتناسب المساحة المتاحة. يمكن أن تأخذ `flex-wrap` ثلاث قيم ممكنة: `nowrap`، `wrap`، و`wrap-reverse`. القيمة الافتراضية هي `nowrap`: لن تُلف العناصر المرنة إلى سطر جديد حتى لو تجاوز عرضها عرض الحاوية.

في الشفرة أدناه، لدينا ثلاثة عناصر `div`. لنركز على `width`. الحاوية `main` المحددة بحدود لها `width` مقدارها `200px`، بينما يبلغ مجموع `width` لعناصر `div` الثلاثة الفرعية `240px` (`80px` لكل منها):

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  display: flex;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

عرض عناصر `div` يتجاوز عرض الحاوية، لكن افتراضيًا سيتم تقليصها لتناسب المساحة المتاحة. إذا أردت لفها عند تجاوز عرضها عرض الحاوية، يمكنك تعيين `flex-wrap: wrap` على الحاوية المرنة:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  display: flex;
  flex-wrap: wrap;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

سيتم إعادة ترتيب عناصر `div` في صفوف عند تجاوز عرض الحاوية. يمكنك لف العناصر المرنة بترتيب عكسي باستخدام `flex-wrap: wrap-reverse`. خاصية `flex-flow` هي خاصية مختصرة لـ `flex-direction` و`flex-wrap`. في هذا المثال، عيّنا `flex-direction` إلى `column` و`flex-wrap` إلى `wrap-reverse`:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  width: 200px;
  height: 120px;
  display: flex;
  flex-flow: column wrap-reverse;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

رائع. الآن لنتحدث عن `justify-content`. تقوم `justify-content` بمحاذاة العناصر الفرعية على طول المحور الرئيسي للحاوية المرنة. إذا عيّنت القيمة `flex-start` لـ `justify-content`، ستُحاذى العناصر المرنة إلى بداية المحور الرئيسي. قد يكون هذا أفقيًا أو عموديًا:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: flex-start;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

مع `justify-content: flex-end`، تُحاذى العناصر المرنة إلى نهاية المحور الرئيسي، أفقيًا أو عموديًا.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>

  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
}

}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

لتمركز العناصر المرنة على طول المحور الرئيسي، يمكنك استخدام `justify-content: center`.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: center;
  border: 2px solid #444;

#third-div {
  background-color: #4da3b2;
```

:::

لتوزيع العناصر على المحور الرئيسي بدون فراغات عند الحواف، يمكنك استخدام `justify-content: space-between`. يجلس العنصر الأول عند بداية المحور الرئيسي، والآخر عند نهايته، ويتم توزيع أي مساحة متبقية بين العناصر المجاورة.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: space-between;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

`justify-content: space-around` يوزع العناصر المرنة بالتساوي على المحور الرئيسي، مضيفًا فراغًا قبل العنصر الأول وبعد العنصر الأخير. هذه المساحة الإضافية تساوي نصف المسافة بين كل زوج من العناصر المجاورة. إذا كان هناك عنصر واحد فقط للتوزيع، فسيتم تمركزه.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  justify-content: space-around;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

وأخيرًا، لدينا `justify-content: space-evenly`، التي توزع العناصر بالتساوي على المحور الرئيسي. المسافة بين العناصر والمسافة قبل وبعد العنصرين الأول والأخير متساوية تمامًا:

:::interactive_editor

```html

<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css

  display: flex;
  justify-content: space-evenly;
  border: 2px solid #444;

  width: 80px;
  height: 50px;

  background-color: #5c4db2;

```

:::

رائع. الآن تعرف كيف توزع العناصر المرنة على طول المحور الرئيسي. لكن قد ترغب أيضًا في توزيعها على طول المحور المتقاطع. تذكر أن المحور المتقاطع عمودي على المحور الرئيسي. يمكنك فعل ذلك باستخدام خاصية `align-items`. لتمركز العناصر على طول المحور المتقاطع، فقط أضف `align-items: center` إلى الحاوية المرنة:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: center;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

في هذا المثال، تمركزت العناصر المرنة على طول المحور المتقاطع، الذي يكون عموديًا افتراضيًا. إذا كان المحور المتقاطع أفقيًا، فسيتم تمركزها أفقيًا بدلًا من ذلك. بالمقابل، `align-items: flex-start` تحاذي العناصر إلى بداية المحور المتقاطع:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: flex-start;
  border: 2px solid #444;
}

  width: 80px;
  height: 50px;
}

  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

العكس هو `align-items: flex-end`. ستُحاذى العناصر المرنة إلى نهاية المحور المتقاطع، عموديًا أو أفقيًا.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: flex-end;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
}
```

:::

لتمديد العناصر المرنة على المحور المتقاطع، يمكنك استخدام `align-items: stretch`. يؤثر هذا فقط على العناصر التي يكون حجمها على المحور المتقاطع `auto`؛ العناصر التي لها حجم محدد صراحةً على المحور المتقاطع (مثل `height` محدد في حاوية صف) لن تتمدد. العناصر المتأثرة ستملأ الحاوية في اتجاه المحور المتقاطع.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<main>
  <div id="first-div"></div>
  <div id="second-div"></div>
  <div id="third-div"></div>
</main>
```

```css
main {
  display: flex;
  height: 300px;
  align-items: stretch;
  border: 2px solid #444;
}

div {
  width: 80px;
  height: 50px;
}

#first-div {
  background-color: #4d70b2;
}

#second-div {
  background-color: #5c4db2;
}

#third-div {
  background-color: #4da3b2;
  height: auto;
}
```

:::
