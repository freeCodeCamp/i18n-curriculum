# --description--

Como você aprendeu na lição anterior, um módulo é um arquivo Python que agrupa código relacionado, para que você possa reutilizá-lo em outros arquivos Python.

Você também pode escrever seus próprios módulos e importá-los em seus scripts. Criar seus próprios módulos é uma ótima forma de organizar seu código. Em vez de ter um arquivo muito longo, você pode dividir seu código em arquivos menores, onde cada um agrupa código relacionado, e então importá-los onde precisar.

Por exemplo, suponha que você criou um arquivo `temperature.py` com duas funções para converter temperaturas e uma chamada de função para verificar se uma delas funciona:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(celsius_to_fahrenheit(100))
```

Se você executar esse arquivo diretamente, esta será a saída:

```md
212.0
```

Agora, suponha que você crie outro arquivo chamado `main.py` na mesma pasta que `temperature.py`. Para usar as funções do seu módulo local, você o importa usando o nome do módulo sem a extensão `.py`:

```python
# main.py
import temperature

print(temperature.fahrenheit_to_celsius(212))
```

Se você executar o arquivo `main.py`, esta será a saída:

```md
212.0
100.0
```

Quando `temperature` é importado, o Python executa todo o código em `temperature.py` de cima para baixo. Por isso `212.0` é impresso, mesmo que `main.py` chame apenas `fahrenheit_to_celsius()`. Código como essa verificação geralmente é algo que você quer executar apenas quando o arquivo é executado diretamente, não toda vez que é importado.

Para controlar isso, você pode usar um idiom comum em Python:

```python
if __name__ == '__main__':
    # Code
```

`__name__` é uma variável interna especial em Python.

Quando um arquivo Python é executado diretamente, o Python define o valor dessa variável como a string `__main__`.

Mas se o arquivo Python for importado como um módulo em outro script Python, o valor da variável `__name__` é definido como o nome desse módulo (geralmente o nome do arquivo sem a extensão `.py`).

É por isso que você frequentemente encontra essa condicional em scripts Python. Ela contém o código que você quer executar **somente se** o script Python estiver rodando como programa principal. Se o script for importado como módulo, o código dentro desse bloco não é executado.

Isso é útil porque permite que scripts Python tenham dois propósitos. Eles podem ser executados diretamente para rodar sua lógica principal ou podem ser importados para outro módulo sem executar sua lógica principal.

Aqui está o arquivo `temperature.py` atualizado para usar esse idiom. Ele também imprime o valor de `__name__`, para que você veja como ele muda:

```python
# temperature.py
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

def fahrenheit_to_celsius(fahrenheit):
    return (fahrenheit - 32) * 5 / 9

print(f'The value of __name__ is: {__name__}')

if __name__ == '__main__':
    print(celsius_to_fahrenheit(100))
```

Se você executar esse arquivo diretamente, o Python define `__name__` como `'__main__'`, então a condição é `True` e o código dentro do bloco `if` é executado. Esta é a saída:

```md
The value of __name__ is: __main__
212.0
```

Se você executar o arquivo `main.py` em vez disso, esta será a saída:

```md
The value of __name__ is: temperature
100.0
```

A chamada `print()` fora do bloco `if` ainda é executada quando `temperature` é importado, e mostra que o valor de `__name__` agora é `temperature`, o nome do módulo.

Mas como `__name__` não é igual a `'__main__'`, o código dentro do bloco `if` não é executado, então `212.0` não é impresso. A única outra saída é `100.0`, que vem da chamada de função em `main.py`.
