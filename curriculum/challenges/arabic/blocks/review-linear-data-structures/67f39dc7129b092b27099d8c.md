## المصفوفات

- **المصفوفات الثابتة**: لها حجم ثابت يُحدد عند التهيئة. تُخزن العناصر في مواقع ذاكرة متجاورة، مما يجعل الوصول إليها فعالًا جدًا. لا يمكن تغيير حجمها أثناء تشغيل البرنامج.

- **المصفوفات الديناميكية**: يمكن أن تنمو أو تتقلص تلقائيًا أثناء تشغيل البرنامج. عندما تمتلئ المصفوفة، تُنسخ عناصرها إلى مصفوفة جديدة أكبر. يُختار الحجم الجديد بحيث تحدث هذه النسخ المكلفة بشكل أقل تكرارًا.

- **المصفوفات الثابتة في Python**: لا تتضمن Python المصفوفات الثابتة التقليدية كـ هياكل بيانات مدمجة. تدعم لغات أخرى مثل Java هذه المصفوفات.

### قوائم Python (مصفوفات ديناميكية)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### التعقيدات الزمنية للمصفوفات الديناميكية

- **الوصول**: O(1)
- **الإدراج في النهاية**: O(1) إذا كان هناك مساحة متاحة، O(n) عند الحاجة لإعادة التهيئة
- **الإدراج في الوسط**: O(n) لأن العناصر التي تليها تحتاج إلى إعادة تموضع

### الاختيار بين المصفوفات الثابتة والديناميكية

- **المصفوفات الثابتة**: عندما تعرف عدد العناصر مسبقًا وتحتاج إلى الوصول إليها بشكل متكرر.
- **المصفوفات الديناميكية**: عندما يكون عدد العناصر غير معروف أو يتغير مع الوقت، أو عندما تقوم بإدراج وحذف العناصر بشكل متكرر.

## المكدسات

- **المكدسات**: هيكل بيانات يعتمد مبدأ آخر داخل، أول خارج (LIFO). للمكدسات طرفان، الأعلى والأسفل. تُضاف وتُزال العناصر من الأعلى فقط.

- **عملية الدفع (Push)**: إضافة عنصر إلى أعلى المكدس. عند استخدام قائمة Python، تستغرق هذه العملية وقت O(1) إذا كانت هناك مساحة متاحة، أو O(n) عند الحاجة لإعادة التهيئة.

- **عملية السحب (Pop)**: إزالة عنصر من أعلى المكدس. تعقيد الوقت: O(1). تعقيد المساحة: O(1).

```python
# Using a Python list as a stack, where the end of the list is the top
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operation
top_element = stack.pop()  # Returns 3
```

## الطوابير

- **الطوابير**: هيكل بيانات يعتمد مبدأ أول داخل، أول خارج (FIFO). للطوابير طرفان، الأمام والخلف. تُضاف العناصر إلى الخلف وتُزال من الأمام.

- **عملية الإدخال في الطابور (Enqueue)**: إضافة عنصر إلى خلف الطابور. عند استخدام قائمة Python، تستغرق هذه العملية وقت O(1) إذا كانت هناك مساحة متاحة، أو O(n) عند الحاجة لإعادة التهيئة.

- **عملية الإخراج من الطابور (Dequeue)**: إزالة عنصر من أمام الطابور. يصبح العنصر التالي في الصف هو الأمام الجديد. تعقيد الوقت: O(1). تعقيد المساحة: O(1).

```python
# Using a Python list as a queue, where the start of the list is the front
queue = []

# Enqueue operations
queue.append(1)
queue.append(2)
queue.append(3)

# Front element
front_element = queue[0]  # 1

# Dequeue operation
front_element = queue.pop(0)  # Returns 1
```

- **ملاحظة**: إزالة العنصر الأول من قائمة Python باستخدام `.pop(0)` يعيد تموضع جميع العناصر المتبقية، لذا تستغرق وقت O(n).

## القوائم المرتبطة

- **القوائم المرتبطة**: هيكل بيانات خطي حيث تخزن كل عقدة بيانات ومرجعًا إلى العقدة التالية. العقد متصلة كسلسلة. القوائم المرتبطة ليس لها حجم ثابت ويمكن أن تنمو أو تتقلص بتحديث الروابط بين العقد.

- **الاستخدامات الشائعة**: تنفيذ هياكل بيانات أخرى مثل المكدسات والطوابير والـ deques، وخوارزميات الرسم البياني مثل البحث بالعمق أولاً والبحث بالاتساع أولاً.

### القوائم المرتبطة المفردة

- **الهيكل**: تخزن كل عقدة بيانات ومرجعًا واحدًا إلى العقدة التالية.
- **التنقل**: يمكن التحرك فقط للأمام، من الرأس إلى الذيل.
- **عقدة الرأس**: أول عقدة في القائمة، وعادةً العقدة الوحيدة التي يمكن الوصول إليها مباشرة. يبدأ التنقل منها.
- **عقدة الذيل**: آخر عقدة في القائمة. مرجعها إلى العقدة التالية هو `None`، مما يشير إلى نهاية القائمة.

#### إدخال العقد

- **الإدخال في البداية**: O(1) - ربط العقدة الجديدة بالرأس القديم وجعلها الرأس الجديد
- **الإدخال في النهاية**: O(n) - يجب التنقل إلى النهاية، ثم ربط الذيل بالعقدة الجديدة
- **الإدخال في الوسط**: O(n) - يجب التنقل إلى الموضع، ثم ربط العقدة السابقة بالعقدة الجديدة والعقدة الجديدة بالعقدة التالية
- **تعقيد المساحة**: O(1) - تُنشأ العقدة الجديدة فقط

#### إزالة العقد

- **الإزالة من البداية**: O(1) - جعل العقدة التالية هي الرأس الجديد
- **الإزالة من الوسط**: O(n) - يجب التنقل إلى العقدة، ثم ربط العقدة السابقة بالعقدة التالية، مكونًا "جسرًا" فوق العقدة المحذوفة
- **الإزالة من النهاية**: O(n) - يجب التنقل إلى النهاية، ثم إزالة ارتباط العقدة السابقة، مما يجعلها الذيل الجديد
- **تعقيد المساحة**: O(1) - لا حاجة لذاكرة إضافية

### القوائم المرتبطة المزدوجة

- **الهيكل**: تخزن كل عقدة بيانات ومرجعين: واحد للعقدة التالية وواحد للعقدة السابقة.
- **التنقل**: يمكن التحرك في كلا الاتجاهين.
- **مرجع الذيل**: من الشائع الاحتفاظ بمرجع لعقدة الذيل داخل القائمة نفسها. هذا يسمح بإضافة العقد في النهاية في وقت O(1)، دون التنقل في القائمة، وبدء التنقل من النهاية.
- **الإدخال والحذف**: يعملان بنفس طريقة القوائم المرتبطة المفردة، لكن يجب تحديث مرجعين لكل عقدة.
- **الذاكرة**: يتطلب ذاكرة أكثر من القوائم المرتبطة المفردة لأن كل عقدة تخزن مرجعين بدلًا من واحد.

## متى تستخدم كل هيكل بيانات

- **المصفوفات الثابتة**: عندما يكون عدد العناصر معروفًا مسبقًا وتحتاج إلى وصول سريع ومتكرر
- **المصفوفات الديناميكية (القوائم)**: عندما تحتاج إلى وصول مرتب ومفهرس ولا تعرف الحجم مسبقًا
- **المكدسات**: عندما يجب أن يكون آخر عنصر أُضيف هو أول عنصر يُزال (LIFO)
- **الطوابير**: عندما يجب معالجة العناصر حسب ترتيب إضافتها (FIFO)
- **القوائم المرتبطة المفردة**: عندما يتغير الحجم كثيرًا وتُدخل وتُزيل العناصر غالبًا من البداية
- **القوائم المرتبطة المزدوجة**: عندما تحتاج إلى التنقل في كلا الاتجاهين أو إضافة عناصر في النهاية بكفاءة، ويكون استهلاك الذاكرة الإضافي لكل عقدة مقبولًا
