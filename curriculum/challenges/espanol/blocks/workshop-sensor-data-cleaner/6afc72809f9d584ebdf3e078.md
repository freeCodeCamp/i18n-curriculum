# --description--

La temperatura igual al promedio recibe la etiqueta `0.0 °C`, que no se lee bien. Debería recibir la etiqueta `average` en lugar de eso.

Puedes encadenar expresiones condicionales escribiendo otra expresión condicional después de `else`. Si la primera condición es falsa, Python evalúa la siguiente expresión condicional:

```py
labels = [
    'large' if num > 100
    else 'medium' if num > 10
    else 'small'
    for num in numbers
]
```

Actualiza tu expresión condicional para que evalúe a `f'+{difference} °C'` si `difference` es mayor que `0`, a `f'{difference} °C'` si `difference` es menor que `0`, y a la cadena `average` en caso contrario.
