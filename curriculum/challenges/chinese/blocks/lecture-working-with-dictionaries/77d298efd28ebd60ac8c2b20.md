# --description--

你已经学会了如何创建字典以及访问和更新它们的值。现在你将使用字典方法，拷贝字典，并探索函数如何改变它们。

下面每个字典方法示例都以这个字典开始：

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## 字典方法

字典也有有助于执行常见操作的帮助方法。

`.get()` 方法检索与某个键关联的值。它类似于你在上一课中学到的方括弧表示法，但它的优势是你可以设置一个默认值，这样如果键不存在就不会报错：

```python
dictionary.get(key, default)
```

在此示例中，如果 `toppings` 密钥不存在，它将返回一个空列表，这是我们作为第二个参数传递的默认值。但如果 `toppings` 存在，它将返回该值：

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

`.keys()` 和 `.values()` 方法分别返回包含字典中所有密钥和值的视图对象：

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

视图对象只是查看字典内容的一种方式，而不会创建数据的单独拷贝。

`.items()` 方法返回一个包含字典中所有键值点对的视图对象，包括键和值：

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

`.clear()` 方法会从字典中移除所有的键值对：

```python
pizza.clear()
```

`.pop()` 方法移除你作为第一个参数指定的密钥对应的点对，并返回其值。如果密钥不存在，则返回你作为第二个参数指定的默认值。如果密钥不存在且你未传入默认值，则引起 `KeyError`：

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

在 Python 3.7 及更高版本中，`.popitem()` 方法会移除最后插入的项：

```python
pizza.popitem()
```

`.update()` 方法用另一个字典的键值对更新字典。如果它们有相同的键，则对应的值会被覆盖。

在此示例中，我们正在更新 `pizza` 字典。`price` 密钥在它们两个中都存在，因此其值将被替换为 `15`。

但是 `total_time` 是新建的，所以它将作为一个新的键值点对添加到 `pizza` 字典中：

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

这是带有更新的 `price` 和新建的 `total_time` 的新字典。注意现在 price 是 `15`，而 `total_time` 是一个新的密钥-值点对：

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### 赋值和浅拷贝

正如你在列表中学到的，将字典赋值给另一个变量会创建一个别名。两个名字都指向同一个对象：

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

要创建一个独立的外层字典，使用 `.copy()` 方法：

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

替换 `copied_settings` 中的条目不会替换 `settings` 中对应的条目。然而，`.copy()` 创建的是**浅拷贝**：它创建一个新的外层字典，其键和值引用原字典中的相同对象。嵌套的可变对象仍然是共享的：

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

这两个字典是不同的对象，但它们的 `languages` 条目引用同一个列表。对该列表追加内容可以通过两个字典看到。用新列表替换 `copied_settings['languages']` 会只改变拷贝中的该条目。

你也可以通过将字典传给 `dict()` 来创建浅拷贝：

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

和 `.copy()` 一样，`dict(settings)` 创建一个新的外层字典，但嵌套的列表仍然共享。替换任一字典中的条目只影响该字典，而修改共享列表则能通过两个字典看到。

## 通过函数参数变异字典

你在列表中学到的参数传递规则同样适用于字典。参数最初引用传入的对象。通过该参数更新条目会变异共享的字典：

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

函数返回一个状态字符串，而 `preferences` 通过共享引用发生变化。返回值和变异对象是两个独立的效果。函数不需要返回字典，外部也能看到变化。将局部参数重新赋值为另一个字典不会替换 `preferences` 引用的字典。

## 使用字典作为默认参数

回想一下，默认列表是在函数定义时创建的，并在省略参数的调用间复用。默认字典的行为也是如此：

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

第二次调用复用了第一次调用修改过的字典。这意味着设置会在独立调用间累积，尽管每次调用都有自己的局部参数名。

当每次调用都应从一个新的字典开始时，使用 `None` 作为默认值模式：

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

每次省略 `settings` 或传入 `None` 都会创建一个新的字典。传入已有字典仍允许函数变异该对象。这里用 `settings is None`：`if not settings` 也会匹配传入的空字典并用新局部字典替换它。
