# --description--

Com a árvore pronta, você pode percorrê-la, o que significa visitar cada nó uma vez.

A travessia inorder é uma travessia em profundidade: ela vai o mais fundo possível ao longo de um ramo antes de passar para o próximo. Para cada nó, ela visita:

1. A subárvore esquerda.
1. O próprio nó.
1. A subárvore direita.

Dentro da classe `BinarySearchTree`, crie um método chamado `_inorder_traversal` com três parâmetros: `self`, `node` e `result`. `node` é o nó que está sendo visitado, e `result` é a lista onde você vai coletar as chaves.

class TreeNode:
    def __init__(self, key):
        self.key = key

class BinarySearchTree:
    def __init__(self):
        self.root = None

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node

    def insert(self, key):
        self.root = self._insert(self.root, key)
