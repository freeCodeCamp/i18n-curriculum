## 로컬 환경에 Python 설치하기

- **설치**: Windows와 macOS에서 Python을 설치하는 가장 쉬운 방법은 공식 Python 웹사이트(`https://www.python.org/`)에서 설치 프로그램을 다운로드하는 것입니다. Linux에서는 Ubuntu, Debian, Fedora 같은 주요 배포판에 이미 Python이 포함되어 있으므로 먼저 설치된 버전을 확인하고 Python 3이 없으면 배포판별 패키지를 설치하세요.
- **macOS에서 설정하기**: `.pkg` 설치 프로그램을 다운로드하여 열고 안내에 따라 진행하세요. 완료되면 `Install Certificates.command` 파일을 더블클릭하고 터미널 프로세스가 끝날 때까지 기다려 설정을 마치세요.
- **Windows에서 설정하기**: `.msix` Python 설치 관리자를 다운로드하여 실행하세요. 이후 `python`, `py`, `pymanager` 명령어를 사용할 수 있으며, 런타임이 설치되어 있지 않은 상태에서 `python`을 실행하면 자동으로 설치됩니다. 또한 `python3.14.exe` 같은 명령어를 위한 별칭 디렉터리를 `PATH`에 추가하는 선택적 프롬프트를 수락할 수 있습니다.
- **Linux에서 설정하기**: 터미널을 열고 `python --version` 또는 `python3 --version`을 실행하세요. 둘 다 Python 3 버전을 표시하지 않으면 `https://www.python.org/`에서 설치 패키지를 찾거나 배포판에 맞는 설치 방법을 온라인에서 검색하세요.

## 설치 확인하기

- **버전 확인하기**: 터미널에서 `python --version` 또는 `python3 --version`을 실행하여 설치를 확인하세요.
- **`python`과 `python3`의 차이**: 일부 오래된 macOS와 Linux 시스템에서는 `python`이 Python 2를 가리킬 수 있습니다. `python --version`이 Python 2 버전을 표시하면 이후부터는 `python3`을 사용하세요. Python 2는 지원이 종료되어 새 개발에 사용하지 않아야 합니다.

## 터미널

- **정의**: 터미널은 명령어를 입력해 컴퓨터와 상호작용할 수 있는 텍스트 기반 인터페이스입니다. 각 운영체제는 기본 터미널 앱을 제공합니다. macOS에서는 Terminal 앱을, Windows에서는 명령 프롬프트나 PowerShell을, Linux에서는 GNOME Terminal이나 Konsole 같은 데스크톱 환경별 기본 터미널 앱을 사용할 수 있습니다.

## 코드 편집기와 IDE

- **IDE**: IDE는 통합 개발 환경(Integrated Development Environment)의 약자로, 코드 편집기, 테스트 도구, 터미널 등 다양한 기능을 포함합니다.
- **Python용 인기 코드 편집기와 IDE**: VS Code, PyCharm, Spyder가 있습니다.

## Python 스크립트 실행하기

- **편집기 설정하기**: VS Code에서 프로젝트 폴더를 열고 `.py` 파일을 만드세요. 확장 뷰에서 Microsoft의 Python 확장 기능을 설치하거나 `code --install-extension ms-python.python` 명령어로 설치하세요(맥에서는 먼저 `code` 명령어를 `PATH`에 추가해야 합니다). 이 확장은 편집기에 Python 지원을 추가하지만 Python 자체를 설치하지는 않습니다.
- **인터프리터 선택하기**: 명령 팔레트에서 `Python: Select Interpreter`를 실행해 이전에 설치한 Python 3 인터프리터를 편집기에 지정하세요.
- **코드 실행하기**: VS Code 오른쪽 상단의 실행 버튼(재생 아이콘)을 클릭해 현재 파일을 터미널에서 실행하세요. 터미널에서 직접 스크립트를 실행할 수도 있습니다. 예를 들어 프로젝트 폴더가 `python-projects`이고 스크립트가 `main.py`라면, `python-projects`가 있는 폴더에서 터미널을 열고 프로젝트 폴더로 이동한 뒤 스크립트를 실행하세요:

```bash
cd python-projects
python main.py
```

시스템에서 Python 3 버전을 보고하는 명령어가 `python3`라면 대신 `python3 main.py`를 사용하세요.

## 파이썬 대화형 셸 사용하기

- **셸 시작하기**: 터미널을 열고 `python` 또는 `python3`를 실행하세요(Python 3 버전을 보고한 쪽을 사용). `>>>` 프롬프트는 Python이 명령을 기다리고 있음을 의미합니다. `"Hello, world!"`를 출력해 보세요:

```python
print("Hello, world!")
```

- **읽기, 평가, 출력, 반복(REPL) 주기**: 인터프리터가 입력을 읽고, 평가하며, 결과를 출력하고, 다시 `>>>` 프롬프트로 돌아가 다음 명령을 입력할 수 있게 합니다.
- **잘못된 입력**: `something random` 같은 유효하지 않은 Python 코드를 입력하면 `SyntaxError: invalid syntax` 메시지가 나오고 셸이 프롬프트로 돌아갑니다.
- **셸 종료하기**: `exit()`를 입력하거나 macOS/Linux에서는 <kbd>Ctrl</kbd> + <kbd>D</kbd>를, Windows에서는 <kbd>Ctrl</kbd> + <kbd>Z</kbd>를 누른 뒤 <kbd>Enter</kbd>를 누르세요.
- **언제 사용하나요**: 인터랙티브 셸은 작은 실험이나 빠른 탐색에 가장 적합합니다. 여러 파일에 걸친 긴 프로그램 작업에는 코드 편집기나 IDE를 사용하세요.
