# --description--

再帰呼び出しはツリーを1レベルずつ下っていきますが、停止する場所が必要です。場合は2つあります。

- `node.key` が `key` と等しい：探している値を持つノードが見つかりました。
- `node` が `None`：探索が葉を超えたため、値はツリーに存在しません。

`_search` メソッドの最初に、既存の `if` 文の前に、`node` が `None` か `node.key` が `key` と等しいかをチェックする `if` 文を追加し、そこから `node` を返してください。こうすることで、メソッドは値を含むノードか、値がツリーにない場合は `None` を返します。
