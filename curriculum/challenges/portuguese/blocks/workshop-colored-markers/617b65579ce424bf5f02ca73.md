# --description--

Um <dfn>modelo de cor</dfn> é um sistema para representar cores. Existem dois modelos principais de cor: o modelo RGB <dfn>aditivo</dfn>, usado em dispositivos eletrônicos, e o modelo CMYK <dfn>subtrativo</dfn> (ciano, magenta, amarelo, preto), usado em impressão.

Neste projeto, você vai trabalhar com o modelo RGB. RGB significa vermelho, verde e azul, as cores primárias da luz. Essas três cores são combinadas em diferentes tons para criar uma ampla variedade de cores. Com RGB, as cores começam como preto e mudam conforme diferentes níveis de vermelho, verde e azul são adicionados.

Uma forma de ver isso é com a função CSS `rgb`, que permite definir cores usando o modelo de cor RGB.

Crie uma nova regra do CSS vinculada à classe `container` e defina sua propriedade `background-color` para `rgb(0, 0, 0)`.
