# --description--

Nesta oficina, você vai praticar trabalhar com tuplas construindo um programa que verifica se um app precisa de uma atualização.

Cada lançamento de um software recebe um número de versão, para que as pessoas possam diferenciar os lançamentos e saber qual é o mais recente. Uma convenção comum é usar três números separados por pontos, no formato `MAJOR.MINOR.PATCH`:

- O número `MAJOR` aumenta para grandes mudanças que podem impedir que códigos ou arquivos antigos funcionem com a nova versão.
- O número `MINOR` aumenta quando novos recursos são adicionados de forma que ainda funcionam com o que veio antes.
- O número `PATCH` aumenta para pequenas correções, como correções de bug, que não adicionam novos recursos.

Uma versão como `2.1.0` pode ser armazenada como uma tupla de três inteiros: os números major, minor e patch.

Crie uma variável chamada `releases` e atribua a ela uma tupla contendo as seguintes tuplas de versão, nesta ordem:

```py
(1, 9, 0), (2, 0, 0), (1, 9, 1), (2, 1, 0),
(2, 1, 1), (2, 2, 0), (1, 9, 2), (2, 2, 1)
```

Os lançamentos estão listados na ordem em que foram publicados, não do menor para o maior número de versão. A linha antiga `1.9` continuou recebendo correções mesmo depois que a versão `2.0.0` foi lançada.
