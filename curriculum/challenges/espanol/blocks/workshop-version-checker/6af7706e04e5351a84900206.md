# --description--

Una versión menor aumenta el número menor en `1` y reinicia el número de parche a `0`, mientras que una versión de parche solo aumenta el número de parche en `1`.

Agrega una cláusula `elif` que verifique si `release_type` es igual a la cadena `minor`. Si es así, asigna a `new_version` una tupla que contenga `major`, `minor + 1` y `0`.

Luego, agrega otra cláusula `elif` que verifique si `release_type` es igual a la cadena `patch`. Si es así, asigna a `new_version` una tupla que contenga `major`, `minor` y `patch + 1`.
