# --description--

Insertion Sort baut einen sortierten Abschnitt am Anfang der Liste auf, und zwar ein Element nach dem anderen. Er beginnt damit, das erste Element als sortiert zu betrachten. Dann nimmt er das nächste Element und verschiebt es rückwärts in den sortierten Abschnitt, indem er jedes größere Element eine Position nach rechts verschiebt oder tauscht, bis er auf ein Element trifft, das kleiner oder gleich ist. Dies wiederholt sich für jedes verbleibende Element, bis die gesamte Liste sortiert ist.

Insertion Sort hat im Durchschnitt und im schlimmsten Fall eine quadratische Zeitkomplexität, läuft aber in linearer Zeit, wenn die Liste bereits sortiert ist.

**Ziel:** Erfüllen Sie die untenstehenden User Stories und bestehen Sie alle Tests, um das Labor abzuschließen.

**User Stories:**

1. Sie sollten eine Funktion namens `insertion_sort` definieren, die einen Parameter hat, der die Liste der Elemente darstellt.
1. Ihre `insertion_sort`-Funktion sollte die Liste an Ort und Stelle von klein nach groß sortieren und zurückgeben.
1. Ihre `insertion_sort`-Funktion sollte dem Insertion-Sort-Algorithmus folgen und jedes Element von links nach rechts an seine korrekte Position im sortierten Abschnitt am Anfang der Liste einfügen.
1. Ihre `insertion_sort`-Funktion sollte das Rückwärtsverschieben eines Elements stoppen, sobald es auf ein Element trifft, das kleiner oder gleich ist.
1. Ihre `insertion_sort`-Funktion sollte weder die eingebaute `sort()`-Methode noch die `sorted()`-Funktion verwenden.

**Hinweis:** Sie sollten keine Module importieren oder Methoden verwenden, die Elemente zur Liste hinzufügen oder daraus entfernen.

from collections import UserList

class CustomList(UserList):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self._states = [list(self.data)]

    def __setitem__(self, key, value):
        super().__setitem__(key, value)
        self._states.append(list(self.data))

def expected_states(items):
    return [
        sorted(items[:i]) + items[i:]
        for i in range(1, len(items) + 1)
    ]

for values in ([33, 1, 89, 2, 67, 245], [4, 4, 2, 2, 1, 4, 3], [5, 3, 8, 1, 9, 2]):
    list_to_sort = CustomList(values)
    insertion_sort(list_to_sort)
    states = iter(list_to_sort._states)
    state = next(states)
    for expected in expected_states(values):
        while state != expected:
            state = next(states)
    assert list_to_sort.data == sorted(values)
    `)
});

```py
def insertion_sort(items):
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j -= 1
        items[j + 1] = current
    return items
```
