# --description--

Jeder Eintrag in `departmentEntries` ist selbst ein kleines Array in der Form `[key, value]`. Anstatt darauf über den Index zuzugreifen (`entry[0]`, `entry[1]`), können Sie Array-Destrukturierung verwenden, um sie in einer Zeile in benannte Variablen zu entpacken.

Zerlegen Sie `departmentEntries[i]` in `departmentName` und `departmentData`. Verwenden Sie dann zwei separate
`console.log()`-Anweisungen: eine, um `departmentName` auszugeben, und eine andere, um `departmentData` auszugeben.
