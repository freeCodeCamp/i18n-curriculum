# --description--

Neste laboratório, você vai construir uma classe de fila. Uma fila segue o princípio FIFO (first-in, first-out): os elementos são adicionados ao final da fila e removidos do início.

**Objetivo:** Cumprir as user stories abaixo e fazer todos os testes passarem para completar o laboratório.

**Histórias de Usuário:**

1. Você deve definir uma classe chamada `Queue`. Uma nova instância de `Queue` deve começar vazia.

1. A classe `Queue` deve ter os seguintes métodos:

   - `enqueue`: recebe um elemento e o adiciona ao final da fila.
   - `dequeue`: remove o elemento do início da fila e o retorna. Se a fila estiver vazia, deve retornar `None`.
   - `front`: retorna o elemento do início da fila sem removê-lo. Se a fila estiver vazia, deve retornar `None`.
   - `size`: retorna o número de elementos na fila.
   - `is_empty`: retorna `True` se a fila não tiver elementos e `False` caso contrário.

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
