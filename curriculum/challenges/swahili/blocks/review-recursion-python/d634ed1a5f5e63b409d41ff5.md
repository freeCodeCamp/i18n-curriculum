# --description--

- **Recursion**: Mbinu ambayo kitendakazi hujita. Kila wito hufanya kazi kwenye toleo dogo la tatizo la awali hadi lifikie kesi ya msingi inayosimamisha wito zaidi wa kurudia.
- **Kesi ya msingi**: Hali inayosimamisha recursion. Unapaswa kufafanua kesi ya msingi kwa uangalifu. Vinginevyo, kitendakazi kinaweza kuendelea kujita hadi Python itoe `RecursionError`.
- **Kesi ya kurudia**: Sehemu ya kitendakazi inayojita tena kwa hoja inayosogeza kuelekea kesi ya msingi, kama vile `number - 1` wakati wa kuhesabu chini.

```py
def recursive_countdown(number):
    if number < 1:  # Base case
        return
    print(number)
    recursive_countdown(number - 1)  # Recursive case

recursive_countdown(5)  # Prints 5, 4, 3, 2, 1
```

- **Mpangilio wa utekelezaji**: Nafasi ya wito wa kurudia hubadilika wakati msimbo mwingine wa kitendakazi unapoendeshwa. Msimbo uliowekwa kabla ya wito wa kurudia huendeshwa wakati wito zinapoingia ndani zaidi, wakati msimbo uliowekwa baada ya wito huendeshwa wakati wito zinaporudi. Kuhamisha `print()` baada ya wito wa kurudia hufanya kitendakazi kuchapisha nambari kwa mpangilio wa kuongezeka:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)  # Prints 1, 2, 3, 4, 5
```

- **Call stack**: Muundo wa data wa last-in, first-out unaotumika na Python kufuatilia wito hai wa vitendakazi. Kila wakati kitendakazi kinapoitwa, Python huongeza fremu kwa wito huo juu ya stack. Fremu hiyo ina taarifa kama hoja za kitendakazi na vigezo vya ndani.
- **Kuanza tena wito**: Wito huacha muda mfupi linapofanya wito wake wa kurudia. Kesi ya msingi inaporudi, Python huondoa wito huo kutoka juu ya stack, na wito wa awali huendelea baada ya wito wao wa kurudia na kurudi kwa mpangilio wa last-in, first-out:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

Matokeo ni:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

- **Kujenga orodha kwa kurudia**: Kila wito huendelea wakati wito wake wa kurudia unaporudi, kisha hutumia thamani iliyorejeshwa. Kitendakazi `countup` kilicho hapa chini hurudisha orodha tupu katika kesi ya msingi. Kila wito mwingine hupokea orodha kutoka kwa wito wake wa kurudia, huongeza nambari yake mwenyewe, na hurudisha orodha hiyo:

```py
def countup(number):
    if number < 1:
        return []
    count_list = countup(number - 1)
    count_list.append(number)
    return count_list

print(countup(5))  # [1, 2, 3, 4, 5]
```

Wito wenye `1` hupokea `[]` na hurudisha `[1]`, wito wenye `2` hupokea `[1]` na hurudisha `[1, 2]`, na kadhalika hadi wito wenye `5` hurudisha `[1, 2, 3, 4, 5]`.

- **Matumizi ya recursion**: Recursion inaweza kushughulikia kazi rahisi kama kuhesabu chini, kuhesabu juu, na kujenga orodha. Pia ni muhimu kwa matatizo yenye kina kisichojulikana, kama vile kupita kwenye mpangilio wa faili.
