# --description--

Kitendakazi cha `map()` hufanya wito kwa kitendakazi kwa kila kipengee cha kitu kinachoweza kurudiwa, na hurudisha kizunguzungu cha matokeo. Kama ilivyo kwa `filter()`, unaweza kukipatia kitendakazi cha lambda:

```py
prices = [10, 20, 30]
discounted = list(map(
    lambda price: price * 0.9,
    prices
))
print(discounted) # [9.0, 18.0, 27.0]
```

Sasa unahitaji kubadilisha vipimo halali kutoka sehemu kumi za digrii hadi digrii.

Tengeneza kigezo kinachoitwa `temperatures`. Weka thamani yake kuwa matokeo ya kupitisha `map()` kitendakazi cha lambda na `valid_readings`, vikiwa vimefungwa katika wito wa `list()`. Kitendakazi cha lambda kinapaswa kuchukua kigezo kinachoitwa `reading` na kurudisha `reading` iliyogawanywa kwa `10`.

Kisha, chapisha `temperatures` badala ya `valid_readings`.
