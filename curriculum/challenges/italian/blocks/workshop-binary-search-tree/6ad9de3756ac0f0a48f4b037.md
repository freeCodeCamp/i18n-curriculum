# --description--

Con l'albero pronto, puoi attraversarlo, cioè visitare ogni nodo una volta sola.

La visita inorder è una visita in profondità: scende il più possibile lungo un ramo prima di passare a quello successivo. Per ogni nodo, visita:

1. Il sottoalbero sinistro.
1. Il nodo stesso.
1. Il sottoalbero destro.

All'interno della classe `BinarySearchTree`, crea un metodo chiamato `_inorder_traversal` con tre parametri: `self`, `node` e `result`. `node` è il nodo che viene visitato, e `result` è la lista dove raccoglierai le chiavi.

class BinarySearchTree:
    def __init__(self):
        self.root = None

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node

    def insert(self, key):
        self.root = self._insert(self.root, key)
