## Usare Esplora file su Windows

Per creare un file su Windows usando Explorer, puoi cliccare sull'opzione "Nuovo" in alto a sinistra. Questo ti mostrerà una lista dei diversi tipi di file che puoi creare.

![Esplora file di Windows con il pulsante Nuovo evidenziato da un riquadro e una freccia arancione in alto a sinistra, e un nuovo documento di testo selezionato nella cartella freeCodeCamp Files.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-1.png)

Puoi anche creare file nelle loro applicazioni corrispondenti.

![Esplora file di Windows che mostra la cartella freeCodeCamp Files all'interno di Documenti, con un nuovo documento di testo selezionato.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-2.png)

Creiamo un file di testo per mostrarti il processo.

Quando clicchi su "Nuovo" e selezioni il tipo di file, vedrai un nuovo file di testo nella cartella corrente con un nome predefinito. Puoi rinominarlo se vuoi.

![Icona di un documento di testo con il nome file demo.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-3.png)

Il processo per creare cartelle è esattamente lo stesso. Clicca sul pulsante "Nuovo" in alto a sinistra e poi seleziona l'opzione "Cartella" oppure fai clic con il tasto destro su uno spazio vuoto e vai su "Nuovo". Poi, seleziona l'opzione "Cartella". Vedrai una nuova cartella vuota nella posizione corrente.

![Esplora file di Windows che mostra una nuova cartella chiamata Nuova cartella nella cartella freeCodeCamp Files.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-4.png)

### Rinominare file e cartelle

![Barra degli strumenti di Esplora file di Windows con il pulsante Rinomina, mostrato come una lettera A accanto a un cursore di testo, evidenziato da un riquadro verde.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-5.png)

Puoi rinominare file e cartelle selezionandoli e cliccando sull'opzione "Rinomina" in alto. Quando il nome attuale del file è evidenziato, puoi iniziare a scrivere il nuovo nome del file. Premi <kbd>Enter</kbd> per confermare le modifiche.

In alternativa, puoi cliccare con il tasto destro sul file o sulla cartella e selezionare l'opzione "Rinomina" oppure usare la scorciatoia da tastiera <kbd>F2</kbd>. Scrivi il nuovo nome e premi <kbd>Enter</kbd> per confermare le modifiche.

### Spostare file e cartelle

Puoi spostare un file o una cartella in un'altra cartella trascinandolo e rilasciandolo nella cartella di destinazione, se l'hai aperta come scheda.

Puoi anche selezionare il file o la cartella e scegliere l'opzione "Taglia" in alto.

![Barra degli strumenti di Esplora file di Windows con il pulsante Taglia, mostrato come forbici, evidenziato da un riquadro verde.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-6.png)

Poi, vai nella cartella di destinazione e incollalo cliccando sul pulsante "Incolla" in alto. Se hai copiato o tagliato il file in precedenza, questo pulsante sarà abilitato.

![Barra degli strumenti di Esplora file di Windows con il pulsante Incolla, mostrato come un blocco appunti, evidenziato da un riquadro verde.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-7.png)

Puoi farlo anche facendo clic con il tasto destro su uno spazio vuoto e poi cliccando sull'icona incolla. Questo rimuoverà il file o la cartella dalla sua posizione originale.

### Eliminare file e cartelle

Per eliminare un file o una cartella, cliccaci sopra e poi clicca sull'icona del Cestino in alto.

![Barra degli strumenti di Esplora file di Windows con il pulsante Elimina, mostrato come un cestino, evidenziato da un riquadro verde.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-8.png)

Troverai anche un'opzione "Elimina" se ci clicchi con il tasto destro.

## Usare Finder su macOS

Ottimo. Ora vediamo come fare questo su macOS usando Finder.

Finder è il gestore di file predefinito su macOS.

### Creare file

Per creare un file su macOS, devi aprire un'applicazione che ti permetta di creare il tipo di documento che ti serve. Attualmente, non esiste un modo integrato per creare un file direttamente su Finder.

Per esempio, per creare un semplice file di testo, puoi aprire TextEdit e salvare il file. Il processo funziona esattamente allo stesso modo per qualsiasi tipo di file.

Ci sono molti modi per aprire TextEdit. Uno di questi è andare su Launchpad.

![Icona di Launchpad su macOS, un quadrato arrotondato contenente una griglia di riquadri colorati delle app.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-9.png)

Poi, cerca un'app dove puoi creare il tipo di file che ti interessa. In questo caso, sarebbe "TextEdit." Clicca sull'icona per aprire l'app.

![Il campo di ricerca di Launchpad contenente il testo TextEdit, con l'icona dell'app TextEdit sotto.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-10.png)

Una volta dentro l'app, dovresti vedere un'opzione per salvare il file nel menu File. Questo menu si trova in alto a sinistra, accanto all'icona del menu Apple.

![TextEdit aperto con un documento vuoto. Una freccia verde punta verso la barra dei menu di macOS, che elenca TextEdit, File, Modifica, Formato, Vista, Finestra e Aiuto.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-11.png)

In una delle opzioni del menu dell'app, dovresti vedere un comando per salvare il file. Di solito si trova sotto il menu File.

![Primo piano della barra dei menu di macOS che mostra il logo Apple, poi TextEdit, File, Modifica, Formato, Vista, Finestra e Aiuto.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-12.png)

Accanto, vedrai la scorciatoia da tastiera per salvare il file. Di solito è <kbd>Command</kbd> + <kbd>S</kbd> su macOS.

![Menu File di TextEdit aperto, con Salva evidenziato e la sua scorciatoia Command + S mostrata a destra.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-13.png)

Quando salvi il file per la prima volta, vedrai una finestra di dialogo dove puoi scrivere il nome del file e scegliere una posizione.

Di solito, l'estensione del file viene aggiunta automaticamente dall'applicazione ma puoi cambiarla prima di salvare il file.

![La finestra di salvataggio di TextEdit con Untitled.txt nel campo Salva come, un browser di cartelle e i pulsanti Annulla e Salva in basso.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-14.png)

Dopo aver salvato il file, puoi aprire Finder cliccando sull'icona di Finder nel Dock.

![L'icona di Finder nel Dock di macOS, un volto sorridente blu e bianco.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-15.png)

Dovresti vedere il tuo nuovo file nella cartella dove l'hai salvato.

![Una finestra di Finder che mostra la cartella freeCodeCamp Files contenente un file, demo.txt.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-16.png)

### Creare cartelle

Per creare una nuova cartella, devi andare nella posizione dove vuoi creare quella nuova cartella e fare clic con il tasto destro su uno spazio vuoto. Vedrai una lista di opzioni. La prima opzione è "Nuova cartella".

![Menu contestuale di Finder aperto su un'area vuota, con Nuova cartella evidenziata in cima alla lista.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-17.png)

Se ci clicchi sopra, puoi assegnare un nome alla tua nuova cartella. Scrivi il nome e premi <kbd>Enter</kbd> per confermare.

![Una nuova cartella di Finder chiamata cartella senza nome, con il nome evidenziato per la modifica.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-18.png)

![La stessa cartella rinominata in freeCodeCamp.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-19.png)

### Spostare file e cartelle

Ci sono diversi modi per spostare file e cartelle in Finder. Se devi spostarli in una cartella elencata nella sezione "Preferiti" di Finder, puoi semplicemente trascinarli e rilasciarli.

![Una finestra di Finder con demo.txt trascinato su Documenti nella barra laterale Preferiti, mostrato da frecce verdi.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-20.png)

Se devi spostarli in una cartella diversa, hai due opzioni.

Puoi aprire la cartella di destinazione come scheda e trascinare il file o la cartella dentro la scheda.

Oppure puoi usare le scorciatoie da tastiera. Prima copia il file con <kbd>Command</kbd> + <kbd>C</kbd>, vai nella nuova cartella e poi usa <kbd>Command</kbd> + <kbd>Option</kbd> + <kbd>V</kbd> per incollare il file o la cartella in quella posizione. Questo lo rimuoverà anche dalla cartella originale.

### Eliminare file e cartelle

Per eliminare un file o una cartella, puoi fare clic con il tasto destro su di esso e selezionare "Sposta nel cestino".

![Menu contestuale di Finder per demo.txt con Sposta nel cestino evidenziato.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-21.png)

![Menu contestuale di Finder per la cartella freeCodeCamp con Sposta nel cestino evidenziato.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-22.png)

Puoi anche trascinarli e rilasciarli sull'icona del cestino nel Dock. È equivalente.

![L'icona del Cestino nel Dock di macOS, un contenitore pieno di carta accartocciata.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-23.png)

Quando il file o la cartella è nel cestino, puoi fare clic con il tasto destro su di esso per eliminarlo immediatamente oppure puoi svuotare il cestino per rimuovere definitivamente tutti i file e le cartelle eliminati.

![La finestra del Cestino di Finder con il menu contestuale per demo.txt aperto, elencando Apri, Apri con, Ripristina, Elimina immediatamente e Svuota cestino.](https://cdn.freecodecamp.org/curriculum/lecture-transcripts/how-to-create-move-and-delete-files-and-folders-using-explorer-finder-24.png)
