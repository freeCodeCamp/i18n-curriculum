# --description--

Para buscar a versão mais recente, você precisa das versões em ordem. Tuplas são comparadas elemento por elemento, da esquerda para a direita, então ordenar uma coleção de tuplas de versões as coloca na ordem correta de versões.

Então, imprima `sorted_releases`.
