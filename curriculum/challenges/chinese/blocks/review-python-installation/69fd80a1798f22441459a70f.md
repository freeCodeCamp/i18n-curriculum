## 在你的本地环境中安装 Python

- **安装**：在 Windows 和 macOS 上安装 Python 最简单的方法是从官方 Python 网站（`https://www.python.org/`）下载安装程序。在 Linux 上，大多数主流发行（版本）如 Ubuntu、Debian 和 Fedora 已经包含 Python，因此你可以先查看已安装的版本，只有在缺少 Python 3 时才安装特定发行（版本）的包。
- **在 macOS 上设置**：下载并打开 `.pkg` 安装程序，按照提示操作。完成后，双击 `Install Certificates.command` 文件，让终端完成处理以完成设置。
- **在 Windows 上设置**：下载并运行 `.msix` Python 安装管理器。之后，`python`、`py` 和 `pymanager` 命令可用，运行没有安装运行期的 `python` 会自动安装一个，你也可以接受可选提示，将别名目录（用于类似 `python3.14.exe` 的命令）添加到你的 `PATH`。
- **在 Linux 上设置**：打开终端，运行 `python --version` 或 `python3 --version`。如果两者都没有报告 Python 3 版本，请访问 `https://www.python.org/` 查找安装包，或在线搜索适合你发行（版本）的推荐安装方法。

## 验证安装

- **查看版本**：通过在终端运行 `python --version` 或 `python3 --version` 来确认安装。
- **`python` 与 `python3`**：在一些较旧的 macOS 和 Linux 系统上，`python` 可能指向 Python 2。如果 `python --version` 报告的是 Python 2 版本，从此以后请使用 `python3` 来运行你的代码。Python 2 已经停止维护，不应再用于新开发。

## 终端

- **定义**：终端是一个基于文本的接口，允许你通过输入命令与计算机交互。每个操作系统都自带一个默认的终端应用程序。在 macOS 上，你可以使用 Terminal 应用。在 Windows 上，可以使用命令提示符或 PowerShell。在 Linux 上，每个桌面环境都有自己的默认终端应用，比如 GNOME Terminal 或 Konsole。

## 代码编辑器和集成开发环境

- **IDE**：IDE 代表集成开发环境，具备代码编辑器、测试工具、终端等多种特色功能。
- **Python 常用的代码编辑器和 IDE**：VS Code、PyCharm 和 Spyder。

## 运行 Python 脚本

- **设置你的编辑器**：在 VS Code 中打开你的项目文件夹并创建一个 `.py` 文件。从扩展视图安装微软的 Python 扩展，或运行 `code --install-extension ms-python.python`（在 macOS 上，需先将 `code` 命令添加到你的 `PATH`）。该扩展为编辑器添加 Python 支持，但不安装 Python 本身。
- **选择解释器**：从命令面板运行 `Python: Select Interpreter`，指向你之前安装的 Python 3 解释器。
- **运行你的代码**：点击运行按钮（VS Code 右上角的播放图标）在终端中运行当前文件。你也可以在终端手动运行脚本。例如，如果你的项目文件夹是 `python-projects`，脚本是 `main.py`，在包含 `python-projects` 的文件夹打开终端，进入项目文件夹并运行脚本：

```bash
cd python-projects
python main.py
```

如果你的系统中 `python3` 命令报告的是 Python 3，改用 `python3 main.py`。

## 使用 Python 交互式 Shell

- **启动交互式 Shell**：打开终端，运行 `python` 或 `python3`（使用报告 Python 3 版本的那个）。`>>>` 提示符表示 Python 正在等待命令。试着打印 `"Hello, world!"`：

```python
print("Hello, world!")
```

- **读、评估、打印、循环周期（REPL）**：解释器读取你的输入，评估它，打印结果，然后循环回到 `>>>` 提示符，等待你输入下一个命令。
- **无效输入**：输入无效的 Python 代码，比如 `something random`，会产生 `SyntaxError: invalid syntax` 消息，Shell 返回提示符。
- **退出 Shell**：输入 `exit()`，在 macOS 或 Linux 上按 <kbd>Ctrl</kbd> + <kbd>D</kbd>，或在 Windows 上按 <kbd>Ctrl</kbd> + <kbd>Z</kbd> 然后回车。
- **何时使用**：交互式 Shell 最适合小实验和快速探索。对于较长程序或跨多个文件的工作，使用代码编辑器或 IDE。
