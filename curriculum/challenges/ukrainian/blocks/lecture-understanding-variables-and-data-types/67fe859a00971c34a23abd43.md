# --description--

Перед тим як працювати з змінними в Python, важливо розуміти типи даних. Тип даних описує, яке саме значення містить змінна, наприклад, число або текст. Мови програмування використовують типи даних, щоб знати, як зберігати та обробляти різні види інформації.

Python — це мова з динамічною типізацією. Це означає, що ви не вказуєте тип даних змінної під час її створення. Python визначає тип за значенням, призначеним змінній.

Ось кілька прикладів:

```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```

Пізніше змінній можна призначити значення іншого типу:

```python
age = 25
age = 'Twenty-five'
```

Після другого присвоєння `age` містить рядок замість цілого числа.

Наразі зосередьтеся на чотирьох типах даних, які ви будете використовувати протягом цього модуля:

- Ціле число: ціле число без десяткових знаків, наприклад, `10` або `-5`.

```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- Подвійний (float): число з десятковою крапкою, як `4.41` або `-0.4`.

```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- Рядок: послідовність символів, укладена в одинарні або подвійні лапки, як `'Hello world!'`.

```python
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- Булевий: тип, що приймає значення істина або хиба, записується як `True` або `False`.

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

У Python є й інші типи даних. Ви вивчите кожен з них, коли він вам знадобиться вперше.
