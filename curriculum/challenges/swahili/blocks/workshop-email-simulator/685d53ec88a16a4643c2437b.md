# --description--

Sasa, onyesha pia alama za wakati katika orodha ya barua pepe. Sasisha njia ya `__str__` kuongeza ` | Time: ` ikifuatiwa na alama ya wakati, iliyopangwa kwa muundo wa `'%Y-%m-%d %H:%M'`, baada ya kichwa cha habari:

```md
[status] From: sender | Subject: subject | Time: time
```

Ili kuweka safu ya `Time` iwe sawa, weka kichwa cha habari upande wa kushoto katika upana wa `15`. Upana huu ni kiwango cha chini tu, hivyo kichwa cha habari kirefu bado kitachapishwa kikamilifu na kusukuma `Time` nje ya mstari. Kata kichwa cha habari kwa herufi zake `15` za kwanza kabla ya kuipanga ili kuzuia hilo.

Kwa mfano, barua pepe yenye kichwa cha habari kifupi na ile yenye kichwa cha habari kirefu itakuwa:

```md
[Unread] From: Alice      | Subject: Hello           | Time: 2025-01-15 09:30
[Unread] From: Alice      | Subject: Quarterly budge | Time: 2025-01-15 09:30
```

import datetime

class Email:

        self.receiver = receiver
        self.subject = subject

        self.read = True

    def display_full_email(self):
        self.mark_as_read()

        print(f"{'Body:':<10}{self.body}")
        print(f"{'':-^29}\n")

    def __str__(self):
        status = 'Read' if self.read else 'Unread'

        return f'[{status:<6}] From: {self.sender.name:<10} | Subject: {self.subject}'

class User:

    def send_email(self, receiver, subject, body):

class Inbox:
    def __init__(self):
        self.emails = []

    def receive_email(self, email):
        self.emails.append(email)

    def list_emails(self):
        if not self.emails:
            print('Your inbox is empty.\n')
            return
        print('\nYour Emails:')
        for i, email in enumerate(self.emails, start=1):
            print(f'{i:>2}. {email}')

        if not self.emails:
            print('Inbox is empty.\n')
            return
        actual_index = index - 1
        if actual_index < 0 or actual_index >= len(self.emails):
            print('Invalid email number.\n')
            return
        self.emails[actual_index].display_full_email()

    def delete_email(self, index):
        if not self.emails:
            print('Inbox is empty.\n')
            return
        actual_index = index - 1
        if actual_index < 0 or actual_index >= len(self.emails):
            print('Invalid email number.\n')
            return
        del self.emails[actual_index]
