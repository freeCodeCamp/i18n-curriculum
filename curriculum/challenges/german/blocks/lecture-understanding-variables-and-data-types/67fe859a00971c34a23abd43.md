# --description--

Bevor Sie mit Python-Variablen arbeiten, ist es wichtig, Datentypen zu verstehen. Ein Datentyp beschreibt die Art des Werts, den eine Variable enthält, zum Beispiel eine Zahl oder einen Textabschnitt. Programmiersprachen verwenden Datentypen, damit sie wissen, wie sie verschiedene Arten von Informationen speichern und verarbeiten.

Python ist eine dynamisch typisierte Sprache. Das bedeutet, dass Sie den Datentyp einer Variable nicht angeben, wenn Sie sie erstellen. Python bestimmt den Typ anhand des der Variable zugewiesenen Werts.

Hier sind einige Beispiele:

```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```

Einer Variable kann später ein Wert eines anderen Typs zugewiesen werden:

```python
age = 25
age = 'Twenty-five'
```

Nach der zweiten Zuweisung enthält `age` einen String statt einer Ganzzahl.

Konzentrieren Sie sich vorerst auf vier Datentypen, die Sie im gesamten Modul verwenden werden:

- Integer: Eine ganze Zahl ohne Dezimalstellen, zum Beispiel `10` oder `-5`.

```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- Float: Eine Zahl mit Dezimalpunkt, wie `4.41` oder `-0.4`.

```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- String: Eine Folge von Zeichen, eingeschlossen in einfache oder doppelte Anführungszeichen wie `'Hello world!'`.

```python
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- Boolean: Ein Wahrheitswert, geschrieben als `True` oder `False`.

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python hat weitere Datentypen. Sie lernen jeden einzelnen, wenn Sie ihn zum ersten Mal benötigen.
