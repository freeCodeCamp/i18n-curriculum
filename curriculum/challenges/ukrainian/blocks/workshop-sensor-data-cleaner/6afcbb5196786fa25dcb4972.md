# --description--

У терміналі ви повинні побачити щось на кшталт `<filter object at 0x...>` замість показників. Це відбувається тому, що `filter()` повертає ітератор, який дає вам елементи по одному, замість того щоб зберігати їх усі у списку.

Щоб зібрати елементи ітератора у список, ви можете передати його у функцію `list()`:

```py
numbers = [1, 2, 3, 4]
even_numbers = list(filter(
    lambda num: num % 2 == 0,
    numbers
))
print(even_numbers) # [2, 4]
```

Обгорніть виклик `filter()`, призначений `valid_readings`, у виклик `list()`. У терміналі ви побачите показники без кодів помилок `-999`.
