Agora você precisa lidar com problemas potenciais. E se o usuário clicar no botão "Search" sem digitar nada no campo de entrada?

No momento, a função pega essa string vazia e retorna `" is available to borrow!"`. Isso não é muito útil.

Em situações como essa, você pode usar a palavra-chave `throw` para lançar um `new Error()` e interromper a execução da função. Por exemplo:

```js
throw new Error("Your error message goes here");
```

Passe a string exata `"Search field cannot be empty"` para o construtor do `Error`.

**Nota:** Se você clicar no botão Search depois de escrever isso, nada aparecerá na tela! O erro interrompe o manipulador de clique porque nada está capturando ele ainda. Você vai corrigir isso em alguns passos. No entanto, você pode verificar o console por enquanto para confirmar que seu código funciona.
