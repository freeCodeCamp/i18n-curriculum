## Масиви

- **Статичні масиви**: мають фіксований розмір, визначений під час ініціалізації. Елементи зберігаються у суміжних ділянках пам’яті, що робить доступ дуже ефективним. Їхній розмір не можна змінити під час виконання програми.

- **Динамічні масиви**: можуть автоматично збільшуватися або зменшуватися під час виконання програми. Коли масив заповнений, його елементи копіюють у новий, більший масив. Новий розмір обирають так, щоб ці дорогі копіювання траплялися рідше.

- **Статичні масиви в Python**: Python не включає традиційні статичні масиви як вбудовані структури даних. Інші мови, як-от Java, підтримують їх.

### Списки Python (динамічні масиви)

```python
numbers = [3, 4, 5, 6]

# Access elements
numbers[0]  # 3

# Update elements
numbers[2] = 16

# Add elements
numbers.append(7)
numbers.insert(3, 15)  # Insert at specific index

# Remove elements
numbers.pop(2)  # Remove at specific index
numbers.pop()   # Remove last element
```

### Часові складності для динамічних масивів

- **Доступ**: O(1)
- **Вставка в кінець**: O(1), якщо є вільне місце, O(n), коли потрібне змінення розміру
- **Вставка посередині**: O(n), бо елементи після неї потрібно перемістити

### Вибір між статичними та динамічними масивами

- **Статичні масиви**: коли ви знаєте кількість елементів наперед і часто до них звертаєтеся.
- **Динамічні масиви**: коли кількість елементів невідома або змінюється з часом, або коли ви часто вставляєте та видаляєте елементи.

## Стек

- **Стек**: структура даних типу останній прийшов — перший вийшов (LIFO). Стек має два кінці: верх і низ. Елементи додають і видаляють лише з верху.

- **Операція push**: додавання елемента на вершину стеку. При використанні списку Python це займає O(1), якщо є вільне місце, або O(n), коли потрібне змінення розміру.

- **Операція pop**: видалення елемента з вершини стеку. Часова складність: O(1). Просторова складність: O(1).

```python
# Using a Python list as a stack, where the end of the list is the top
stack = []

# Push operations
stack.append(1)
stack.append(2)
stack.append(3)

# Pop operation
top_element = stack.pop()  # Returns 3
```

## Черги

- **Черги**: структура даних типу перший прийшов — перший вийшов (FIFO). Черги мають два кінці: перед і зад. Елементи додають у задню частину і видаляють із передньої.

- **Операція enqueue**: додавання елемента в кінець черги. При використанні списку Python це займає O(1), якщо є вільне місце, або O(n), коли потрібне змінення розміру.

- **Операція dequeue**: видалення елемента з початку черги. Наступний елемент стає новим передом. Часова складність: O(1). Просторова складність: O(1).

```python
# Using a Python list as a queue, where the start of the list is the front
queue = []

# Enqueue operations
queue.append(1)
queue.append(2)
queue.append(3)

# Front element
front_element = queue[0]  # 1

# Dequeue operation
front_element = queue.pop(0)  # Returns 1
```

- **Примітка**: видалення першого елемента списку Python за допомогою `.pop(0)` переміщує всі решту елементів, тому це займає O(n) часу.

## Зв’язані списки

- **Зв’язані списки**: лінійна структура даних, де кожен вузол зберігає дані та референс на наступний вузол. Вузли з’єднані як ланцюг. Зв’язані списки не мають фіксованого розміру і можуть збільшуватися або зменшуватися шляхом оновлення зв’язків між вузлами.

- **Загальне використання**: реалізація інших структур даних, таких як стеки, черги та дека, а також алгоритми на графах, як-от пошук у глибину та пошук у ширину.

### Однозв’язні списки

- **Структура**: кожен вузол зберігає дані та один референс на наступний вузол.
- **Перебір**: можна рухатися лише вперед, від голови до хвоста.
- **Головний вузол**: перший вузол у списку, зазвичай єдиний, до якого є прямий доступ. Перебір починається звідси.
- **Хвостовий вузол**: останній вузол у списку. Його референс на наступний вузол — `None`, що позначає кінець списку.

#### Вставка вузлів

- **Вставка на початок**: O(1) — під’єднати новий вузол до старої голови і зробити його новою головою
- **Вставка в кінець**: O(n) — потрібно пройти до кінця, потім під’єднати хвіст до нового вузла
- **Вставка посередині**: O(n) — потрібно пройти до позиції, потім під’єднати попередній вузол до нового, а новий — до наступного
- **Просторова складність**: O(1) — створюється лише новий вузол

#### Видалення вузлів

- **Видалення з початку**: O(1) — зробити наступний вузол новою головою
- **Видалення посередині**: O(n) — потрібно пройти до вузла, потім під’єднати попередній вузол до наступного, утворюючи «міст» над видаленим вузлом
- **Видалення з кінця**: O(n) — потрібно пройти до кінця, потім видалити зв’язок попереднього вузла, зробивши його новим хвостом
- **Просторова складність**: O(1) — додаткова пам’ять не потрібна

### Двозв’язні списки

- **Структура**: кожен вузол зберігає дані та два референси: один на наступний вузол і один на попередній.
- **Перебір**: можна рухатися в обох напрямках.
- **Референс на хвіст**: зазвичай у списку зберігають референс на хвостовий вузол. Це дозволяє додавати вузли в кінець за O(1), не проходячи весь список, і починати перебір з кінця.
- **Вставка та видалення**: працюють так само, як у зв’язаних списках з одним референсом, але потрібно оновлювати два референси на вузол.
- **Пам’ять**: потребує більше пам’яті, ніж зв’язані списки з одним референсом, бо кожен вузол зберігає два референси замість одного.

## Коли використовувати кожну структуру даних

- **Статичні масиви**: коли кількість елементів відома наперед і потрібен швидкий, частий доступ
- **Динамічні масиви (списки)**: коли потрібен впорядкований, індексований доступ і розмір невідомий наперед
- **Стек**: коли останній доданий елемент має бути першим, що видаляють (LIFO)
- **Черга**: коли елементи мають оброблятися в порядку додавання (FIFO)
- **Однозв’язні списки**: коли розмір часто змінюється і ви переважно вставляєте та видаляєте на початку
- **Двозв’язні списки**: коли потрібно рухатися в обох напрямках або ефективно додавати елементи в кінець, і додаткова пам’ять на вузол прийнятна
