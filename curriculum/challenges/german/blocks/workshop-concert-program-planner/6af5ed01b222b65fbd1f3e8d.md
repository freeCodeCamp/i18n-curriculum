# --description--

In diesem Workshop üben Sie den Umgang mit Listen, indem Sie das Programm eines Orchesterkonzerts planen.

Wie Sie in den vorherigen Lektionen gelernt haben, ist eine Liste eine geordnete Sammlung von Elementen. Sie erstellen eine Liste, indem Sie durch Kommas getrennte Elemente in eckige Klammern setzen:

```py
fruits = ['apple', 'banana', 'cherry']
```

Erstellen Sie eine Variable namens `pieces` und weisen Sie ihr eine Liste zu, die die Strings `Carnival Overture`, `Song to the Moon` und `Silent Woods` in dieser Reihenfolge enthält.
