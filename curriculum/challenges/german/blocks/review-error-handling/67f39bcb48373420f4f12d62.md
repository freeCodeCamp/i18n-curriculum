## Häufige Fehler in Python

- **`SyntaxError`**: Der Fehler, den Python auslöst, wenn Ihr Code nicht den Syntaxregeln entspricht. Zum Beispiel führt der Code `print("Hello there"` zu einem Syntaxfehler mit der Meldung `SyntaxError: '(' was never closed`, weil die schließende Klammer fehlt.
- **`NameError`**: Python löst einen `NameError` aus, wenn Sie versuchen, auf eine Variable oder Funktion zuzugreifen, die Sie nicht definiert haben. Wenn Sie zum Beispiel die Zeile `print(username)` in Ihrem Code haben, ohne vorher eine Variable `username` definiert zu haben, erhalten Sie einen Namensfehler mit der Meldung `NameError: name 'username' is not defined`.
- **`TypeError`**: Dies ist der Fehler, den Python auslöst, wenn eine Operation oder Funktion auf ein Objekt eines ungeeigneten Typs angewendet wird. Wenn Sie zum Beispiel versuchen, einen String mit einer Zahl zu addieren, erhalten Sie den Fehler `TypeError: can only concatenate str (not "int") to str`.
- **`IndexError`**: Sie erhalten einen `IndexError`, wenn Sie auf einen Index zugreifen, der in einer Liste oder anderen Folgen wie Tuples und Strings nicht existiert. Zum Beispiel hat der String `Hello world` den Index des letzten Zeichens `10`. Wenn Sie versuchen, ein Zeichen so zuzugreifen: `greet = "hello world"; print(greet[11])`, erhalten Sie einen Fehler mit der Meldung `IndexError: string index out of range`.
- **`AttributeError`**: Python löst diesen Fehler aus, wenn Sie versuchen, eine Methode oder Eigenschaft zu verwenden, die in einem Objekt dieses Typs nicht existiert. Zum Beispiel führt der Aufruf von `.append()` bei einem String wie `"hello".append("!")` zu einem Fehler mit der Meldung `AttributeError: 'str' object has no attribute 'append'`.

## Gute Debugging-Techniken in Python

- **Verwendung der `print`-Funktion**: Das Einfügen von `print()`-Anweisungen an verschiedenen Stellen im Code während des Debuggings hilft Ihnen, die Werte von Variablen zu sehen und den Ablauf Ihres Codes nachzuvollziehen.
- **Verwendung des eingebauten Python-Debuggers (`pdb`)**: Python stellt das `pdb`-Modul als Teil der Standardbibliothek zum Debuggen bereit. Der Aufruf von `pdb.set_trace()` pausiert die Ausführung und öffnet eine interaktive Eingabeaufforderung. Sie können `help` eingeben, um Befehle aufzulisten, `whatis`, um den Typ eines Ausdrucks zu prüfen, und `continue` (oder die Aliase `cont` und `c`), um die Programmausführung fortzusetzen.
- **Nutzung von Debugging-Tools in IDEs**: Integrierte Entwicklungsumgebungen (IDEs) und Code-Editoren wie PyCharm und VS Code bieten visuelle Debugging-Werkzeuge. Zum Beispiel bietet VS Code Folgendes:
  - **Haltepunkte**: Klicken Sie im Spaltenabstand des Editors, um einen Haltepunkt (dargestellt durch einen roten Punkt) zu setzen, an dem die Ausführung pausieren soll.
  - **Variableninspektion & Debug-Konsole**: Fahren Sie mit der Maus über Variablen oder sehen Sie sich das Variablenfenster an, um aktuelle Werte zu sehen, und verwenden Sie die Debug-Konsole, um Ausdrücke interaktiv auszuwerten.
  - **Schrittsteuerung**:
    - **Fortsetzen (<kbd>F5</kbd>)**: Setzt die Ausführung bis zum nächsten Haltepunkt fort.
    - **Übergehen (<kbd>F10</kbd>)**: Führt die aktuelle Zeile aus und geht zur nächsten Zeile, ohne in Funktionsaufrufe hineinzugehen.
    - **Hineingehen (<kbd>F11</kbd>)**: Geht in die aufgerufene Funktion hinein, um deren Zeilen Schritt für Schritt auszuführen.
    - **Herausgehen (<kbd>Shift</kbd> + <kbd>F11</kbd>)**: Beendet die aktuelle Funktion und kehrt zum Aufrufer zurück.

## Ausnahmebehandlung

- **`try...except`**: Damit führen Sie einen Codeblock aus, der eine Ausnahme auslösen könnte. Der `try`-Block ist der Bereich, in dem Sie einen Fehler erwarten, während der `except`-Block eine bestimmte Ausnahme abfängt und ausgeführt wird, wenn dieser Fehler auftritt. Hier ist ein Beispiel:

  ```py
  try:
    print(22 / 0)
  except ZeroDivisionError:
    print('You can\'t divide by zero!')
    # You can't divide by zero!
  ```

  Sie können auch mehrere `except`-Blöcke verketten, um verschiedene Arten von Ausnahmen zu behandeln:

  ```py
  try:
    number = int(input('Enter a number: '))
    print(22 / number)
  except ZeroDivisionError:
    print('You cannot divide by zero!')
    # You cannot divide by zero! prints when you enter 0
  except ValueError:
    print('Please enter a valid number!')
    # Please enter a valid number! prints when you don't enter an integer
  ```

  Sie können auch mehrere Ausnahmetypen in einer einzigen `except`-Klausel abfangen, indem Sie sie in einem Tuple gruppieren:

  ```py
  try:
    number = int(input('Enter a number: '))
    result = 10 / number
  except (ValueError, ZeroDivisionError) as e:
    print(f'Error occurred: {e}')
  ```

- **`else`- und `finally`-Blöcke**: Diese Blöcke erweitern `try...except`. Wenn keine Ausnahme auftritt, wird der `else`-Block ausgeführt. Der `finally`-Block wird immer ausgeführt, unabhängig von Fehlern.

  ```py
  try:
    result = 100 / 4
  except ZeroDivisionError:
    print('You cannot divide by zero!') # This will not run
  else:
    print(f'Result is {result}') # Result is 25.0
  finally:
    print('Execution complete!') # Execution complete!
  ```

- **Ausnahmeobjekt**: Damit können Sie auf die Ausnahme selbst zugreifen, um besser zu debuggen und die direkte Fehlermeldung auszugeben. Um auf das Ausnahmeobjekt zuzugreifen, verwenden Sie das Schlüsselwort `as`. Hier ist ein Beispiel:

  ```py
  try:
      value = int('This will raise an error')
  except ValueError as e:
      print(f'Caught an error: {e}')
      # Caught an error: invalid literal for int() with base 10: 'This will raise an error'
  ```

- **Die `raise`-Anweisung**: Damit können Sie manuell eine Ausnahme auslösen. Sie können sie verwenden, um eine Ausnahme zu werfen, wenn eine bestimmte Bedingung erfüllt ist:

  ```py
  def divide(a, b):
      if b == 0:
          raise ZeroDivisionError('You cannot divide by zero')
      return a / b
  ```

  Die Verwendung von `raise` ohne Argumente innerhalb eines `except`-Blocks löst die aktuell behandelte Ausnahme erneut aus. So können Sie den Fehler protokollieren oder Aufräumarbeiten durchführen und gleichzeitig die Ausnahme weiter nach oben in den Aufrufstapel geben:

  ```py
  def process_data(data):
      try:
          result = int(data)
          return result * 2
      except ValueError:
          print('Logging: Invalid data received')
          raise
  ```

- **Die `assert`-Anweisung**: Die `assert`-Anweisung überprüft Annahmen während des Debuggings und löst eine `AssertionError` aus, wenn die Bedingung falsch ist. Da Python Assertions im optimierten Modus (`-O`) entfernt, sollten Assertions nicht für kritische Eingabevalidierungen verwendet werden, die immer ausgeführt werden müssen. Verwenden Sie stattdessen eine explizite Bedingung und `raise` für erforderliche Prüfungen.

## Ausnahme-Signalisierung

- **Benutzerdefinierte Ausnahmen**: Die `raise`-Anweisung ist auch nützlich, wenn Sie eigene benutzerdefinierte Ausnahmen erstellen, indem Sie von `Exception` erben. So können Sie Fehler mit domänenspezifischer Logik und Meldungen werfen:

  ```py
  class InvalidCredentialsError(Exception):
      def __init__(self, message="Invalid username or password"):
          self.message = message
          super().__init__(self.message)

  def login(username, password):
      stored_username = "admin"
      stored_password = "password123"
      
      if username != stored_username or password != stored_password:
          raise InvalidCredentialsError()
      
      return f"Welcome, {username}!"
  ```

  So können Sie die `login`-Funktion mit der Ausnahme `InvalidCredentialsError` verwenden:

  ```py
  # failed login attempt
  try:
      message = login("user", "wrongpassword")
  except InvalidCredentialsError as e:
      print(f"Login failed: {e}")
  else:
      print(message)

  # successful login attempt
  try:
      message = login("admin", "password123")
  except InvalidCredentialsError as e:
      # This block is not executed because the login was successful
      print(f"Login failed: {e}")
  else:
      # The else block runs if the 'try' block completes without an exception
      print(message)
  ```

- **Ausnahmeverkettung**: Die `raise`-Anweisung kann mit dem Schlüsselwort `from` verwendet werden, um Ausnahmen zu verketten. Die Verwendung von `from None` unterdrückt den ursprünglichen Ausnahme-Kontext im angezeigten Traceback, während `from e` die ursprüngliche Ausnahme explizit als Ursache festhält:

  ```py
  def parse_config(filename):
      try:
          with open(filename, 'r') as file:
              data = file.read()
              return int(data)
      except FileNotFoundError:
          raise ValueError('Configuration file is missing') from None
      except ValueError as e:
          raise ValueError('Invalid configuration format') from e

  config = parse_config('config.txt')
  ```
