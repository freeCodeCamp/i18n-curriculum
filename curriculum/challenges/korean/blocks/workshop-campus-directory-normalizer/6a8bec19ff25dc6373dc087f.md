# --description--

모든 학과에 `Dept_code`가 있다고 보장할 수는 없습니다. 값이 없을 때를 대비한 대체값이 필요하며, 그래야 해당 학과도 사용할 수 있는 ID를 갖게 됩니다.

`||` 연산자는 왼쪽 값이 `truthy`일 경우 그 값을 반환하고, 그렇지 않으면 오른쪽 값을 반환합니다.

예를 들어: `a || b`는 `a`가 `truthy`일 때 `a`로 평가되고, `a`가 `falsy`일 때(예: `undefined`, `null`, 또는 `""`) `b`로 대체됩니다.

```js
const code = undefined;
const fallback = code || "default-code";
console.log(fallback); // "default-code"
```

`departmentId` 할당을 `||` 연산자를 사용하도록 업데이트하세요. 왼쪽 피연산자로 `departmentData.Dept_code`를, 오른쪽 피연산자로 템플릿 리터럴 `` `dept-${i + 1}` ``를 사용하세요. 이렇게 하면 `departmentData.Dept_code`가 `undefined`를 포함해 falsy일 때 대체 수단이 사용됩니다.
