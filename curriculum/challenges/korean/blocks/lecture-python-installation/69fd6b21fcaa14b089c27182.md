## 코드 편집기 또는 IDE 설치하기

이전 수업에서는 로컬 장치에 Python을 설치하는 방법을 배웠습니다. 이번 수업에서는 Python 코드를 로컬에서 실행하는 방법을 배우세요.

로컬에서 Python 스크립트를 작성하기 전에 코드 편집기나 IDE를 설치해야 합니다. IDE는 통합 개발 환경을 의미합니다. IDE는 코드 편집기, 테스트 도구, 터미널 같은 기능을 결합합니다.

많은 개발자가 사용하는 인기 있는 코드 편집기 중 하나는 VS Code입니다. `https://code.visualstudio.com/download`에서 macOS, Windows, Linux를 지원하는 VS Code를 다운로드하세요. 이 수업에서는 이 편집기를 사용할 것입니다.

Python 개발에 흔히 사용되는 다른 선택지는 다음과 같습니다:

- PyCharm
- Spyder

## 파이썬 파일 만들기

VS Code를 설치한 후 열고 `File`을 선택한 다음 `Open Folder`를 선택하세요. 프로젝트용 폴더를 선택하거나 새로 만드세요. 수업 외에 추가 연습을 위해 `python-projects`라는 폴더를 만들어도 좋습니다.

VS Code 왼쪽 사이드바에서 Explorer를 열고, 종이에 더하기 기호가 있는 `New File` 아이콘을 선택하세요. `main.py`라는 파일을 만들고 <kbd>Enter</kbd>를 누르세요. `.py` 확장자는 이 파일이 Python 파일임을 나타냅니다.

`main.py` 파일을 열고 다음 코드를 입력하세요:

```py
print("Hello, world!")
```

## Python 확장 설치하기

Microsoft의 공식 Python 확장을 설치하려면 아래 단계를 따라 하세요:

### 방법 A: 애플리케이션 내에서

1. 왼쪽 활동 표시줄에 있는 네 개의 블록 아이콘을 클릭해 확장 보기로 들어가세요. 또는 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (Windows / Linux) 또는 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (macOS)를 누르세요.
1. 상단 검색창에 `Python`을 입력하세요.
1. Microsoft가 게시한 Python이라는 최상위 결과를 찾으세요.
1. 파란색 <kbd>Install</kbd> 버튼을 클릭하세요.

### 방법 B: 터미널 / 명령줄에서

터미널에서 확장을 설치하려면 먼저 `code` 명령어가 사용 가능한지 확인하세요. macOS에서는 명령 팔레트를 열고 `Shell Command: Install 'code' command in PATH`를 실행한 후 터미널을 재시작하세요.

그런 다음 다음 명령어로 Python 확장을 설치하세요:

```bash
code --install-extension ms-python.python
```

## Python 인터프리터 선택하기

확장은 다리 역할을 하지만 실제 Python 언어 파일을 포함하지 않습니다. 아직 설치하지 않았다면 공식 Python 웹사이트에서 Python 인터프리터를 별도로 설치해야 합니다.

운영체제에 Python이 설치되면 편집기와 연결하세요:

1. VS Code에서 폴더나 `.py`로 끝나는 파일을 열세요.
1. <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows / Linux) 또는 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS)를 눌러 명령 팔레트를 여세요.
1. `Python: Select Interpreter`를 입력하고 선택하세요.
1. 기기에 설치된 Python 3 버전을 선택하세요. 이제 작업 공간 상태 표시줄에 기본으로 표시됩니다.

## 파이썬 스크립트 실행하기

이 코드를 실행하려면 몇 가지 방법이 있습니다. 첫 번째는 오른쪽 상단에 있는 재생 버튼 모양의 실행 버튼을 클릭하는 것입니다. 그러면 터미널이 열리고 Python 스크립트가 실행됩니다. `Hello, world!`라는 텍스트가 보여야 합니다.

또 다른 방법은 터미널을 열고 다음 명령어로 수동으로 프로그램을 실행하는 것입니다:

```bash
python main.py
```

이 명령은 `main.py`가 저장된 폴더에서 실행해야 합니다. 예를 들어 `main.py`가 `python-projects`라는 폴더 안에 있다면, 먼저 터미널에서 다음을 입력하세요:

```bash
cd python-projects
```

그런 다음 다음을 실행하세요:

```bash
python main.py
```

## `python` 대신 `python3` 사용하기

특히 macOS와 Linux 시스템에서 Python 2와 Python 3가 모두 설치된 환경에서는 `python` 대신 `python3`을 사용해야 할 수 있습니다. 이는 `python` 명령어가 없거나 이전 버전 Python을 가리키는 경우에 흔합니다.

```bash
python3 main.py
```

과정을 진행하면서 각 수업의 예제를 로컬에서 실행하고 자신만의 예제를 만들어 배운 내용을 테스트하세요.
