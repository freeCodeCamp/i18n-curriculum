# --description--

الآن ستحول الفروقات إلى مسميات نصية مثل `+3.6 °C`. الأعداد الموجبة تُطبع بدون إشارة، لذا تحتاج إلى إضافة `+` أمامها.

لإدراج العناصر التي تحقق شرطًا فقط، يمكنك إضافة `if` في نهاية تعبير القائمة:

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

أنشئ متغيرًا باسم `difference_labels`. استخدم تعبير قائمة لتعيين قائمة تحتوي على `f'+{difference} °C'` لكل `difference` في `differences`، ولكن فقط إذا كان `difference` أكبر من `0`.

ثم، اطبع `difference_labels` بدلًا من `differences`.

في الطرفية، سترى 3 مسميات فقط مقابل 7 درجات حرارة. الـ `if` في النهاية تستبعد العناصر التي لا تحقق الشرط، لذا لا يمكن معرفة أي درجة حرارة ينتمي إليها كل مسمى. ستصلح هذا في الخطوة التالية.
