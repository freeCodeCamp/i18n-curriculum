# --description--

在這最後一步，你將使用前面步驟計算出的數值來計算電影票的最終價格。

最終票價是透過將額外費用和服務費加到基本價格上，然後再扣除折扣來計算的。

要從一個數字中減去另一個數字，你可以使用減法運算子 `-`。你也可以在同一個表達式中將它與 `+` 運算子結合使用：

```py
total_cost = 50
shipping = 5
coupon = 10

amount_due = total_cost + shipping - coupon
print(amount_due)  # 45
```

在最後一個 `if` 述語的區塊內，位於列印服務費的那一行下面，計算電影票的最終價格並將其存入名為 `final_price` 的變數中。

最後，使用 f-string 列印 `Final price of ticket:`，後面接一個空格和格式化為兩位小數的 `final_price`。

# --solutions--

```py
base_price = 15
age = 21
seat_type = 'Gold'
show_time = 'Evening'

if age > 17:
    print('User is eligible to book a ticket')

if age >= 21:
    print('User is eligible for Evening shows')
else:
    print('User is not eligible for Evening shows')

is_member = False
is_weekend = False

discount = 0
if is_member and age >= 21:
    discount = 3
    print('User qualifies for membership discount')
else:
    print('User does not qualify for membership discount')
print(f'Discount: {discount:.2f}')

extra_charges = 0
if show_time == 'Evening' or is_weekend:
    extra_charges = 2
    print('Extra charges will be applied')
else:
    print('No extra charges will be applied')
print(f'Extra charges: {extra_charges:.2f}')

if age >= 21 or age >= 18 and (show_time != 'Evening' or is_member):
    print('Ticket booking condition satisfied')

    service_charges = 0
    if seat_type == 'Premium':
        service_charges = 5
    elif seat_type == 'Gold':
        service_charges = 3
    else:
        service_charges = 1
    print(f'Service charges: {service_charges:.2f}')

    final_price = base_price + extra_charges + service_charges - discount
    print(f'Final price of ticket: {final_price:.2f}')
else:
    print('Ticket booking failed due to restrictions')
```
