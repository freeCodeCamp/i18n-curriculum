# --description--

ターミナルでは、`-3.7` の代わりに `-3.6999999999999993` のような値が表示されることがあります。これは、浮動小数点数がすべての小数を正確に表せないため、算術演算の後に小さな誤差が生じることがあるからです。

`round()` 関数は、2番目の引数で指定した小数点以下の桁数に数値を丸めます。

```py
print(round(3.14159, 2)) # 3.14
```

`temperature - average` を `round()` で囲んで、それぞれの差を小数点以下1桁に丸めてください。
