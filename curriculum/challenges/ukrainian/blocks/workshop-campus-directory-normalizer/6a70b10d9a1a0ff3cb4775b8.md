# --description--

Тепер, коли у вас є `departmentId`, використайте його, щоб зберегти дані відділу всередині `departmentsById`.

Призначте `departmentsById[departmentId]` об’єкт, що містить:

`id`: призначте `departmentId`,  
`code`: призначте `departmentData.Dept_code`,  
`name`: призначте `departmentName`  
`programIds`: порожній масив (ви заповните його на наступних кроках)

Насамкінець, виведіть у консоль `departmentsById[departmentId]`.
