# --description--

У попередньому уроці про числа та математичні операції ви використовували специфікацію формату, як-от `.2f` у f-рядку, щоб контролювати, скільки десяткових знаків показує число.

Специфікації формату також можуть контролювати, скільки місця займає значення і де воно розташоване. Це корисно, коли ви хочете, щоб вихідні дані вирівнювалися у акуратні колонки.

## Встановлення мінімальної довжини та вирівнювання

Число після двокрапки встановлює мінімальну довжину поля, тобто кількість символів, які має займати значення. Якщо значення коротше, Python додає пробіли, доки не досягне цієї довжини. Ось приклад:

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

Використання певних символів перед довжиною контролює, де значення розташовується всередині поля. Ось ці символи:

- Менше ніж (`<`) вирівнює значення ліворуч
- Більше ніж (`>`) вирівнює значення праворуч
- Карет (`^`) центрує значення.

Ось як ці три символи працюють на практиці:

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

`'Tea'` містить три символи, тому Python додає п’ять пробілів, щоб досягти довжини `8`.

- З `<` пробіли йдуть після значення
- З `>` пробіли йдуть перед значенням
- З `^` пробіли розподіляються з обох боків, щоб центрирувати текст.

Якщо пробіли не можна розділити порівну, зайвий пробіл додається справа:

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

Якщо пропустити символ вирівнювання, рядки за замовчуванням вирівнюються ліворуч, а числа — праворуч:

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## Використання символу заповнення

За замовчуванням Python додає відступи пробілами. Щоб використати інший символ для відступів, вставте його безпосередньо перед символом вирівнювання:

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

У `*^9` `*` — це символ заповнення, `^` центрує значення, а `9` — мінімальна довжина. Зверніть увагу, що символ заповнення можна використовувати лише разом із символом вирівнювання.

## Поєднання довжини та точності

Ви можете поєднати вирівнювання та довжину з точністю, яку вивчили в попередньому уроці, все в одній специфікації формату:

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

Специфікація формату в наведеному прикладі означає: вирівняти праворуч, використати мінімальну довжину `7` і показати два десяткові знаки. Спочатку Python форматує число як `4.50`, що має чотири символи, а потім додає три пробіли спереду, щоб заповнити довжину `7`.

## Створення рядка інструкції

Ви можете розмістити мітку та суму в одному рядку. Якщо використовувати однакову специфікацію формату для кожного рядка, колонки вирівнюються:

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

Кожна мітка вирівнюється ліворуч у полі шириною `12` символів і доповнюється крапками, а кожна сума вирівнюється праворуч у полі шириною `8` символів, щоб десяткові крапки збігалися.

## Довжина — це мінімум, а не максимум

Довжина додає лише відступи. Вона ніколи не обрізає значення. Якщо значення довше за вказану довжину, відображається повне значення:

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

Те саме стосується чисел. У наведеному нижче прикладі відформатована сума потребує вісім символів, тому вона ігнорує вказану довжину `7`:

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

У `:7.2f` `7` — це мінімальна довжина, а не обмеження на довжину суми. Python ніколи не обрізає цифри, щоб число помістилося.

Ось чому слід вибирати довжини достатньо великими для очікуваних значень, інакше колонки не вирівняються.

Якщо хочете обмежити довжину рядка, додайте точність до специфікації формату. Для рядків точність встановлює максимальну кількість символів для відображення:

```py
label = 'Long description'

print(f'|{label:.8}|') # |Long des|
print(f'|{label:<12.8}|') # |Long des    |
```

У `<12.8`:

- `<` вирівнює значення ліворуч
- `12` — мінімальна довжина
- `.8` — максимальна кількість символів.

Python спочатку обрізає рядок до восьми символів, а потім доповнює його до довжини дванадцять.

Зверніть увагу, що точність означає різне для рядків і чисел. З `.2f` `.2` задає кількість десяткових знаків. Для рядка `.8` задає максимальну кількість символів.
