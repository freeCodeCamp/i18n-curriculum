# --description--

在本次研讨会中，你将使用智能校园目录并从嵌套数据中创建查找表。
你将使用这些查找表来执行快速且高效的查找。`rawData` 已为你提供。

花点时间观察它的结构：每个键是一个系的名称，其值包含一个 `Dept_code` 和一个 `programs` 数组。
每个项目又包含它自己的 `instructors` 数组。

首先，将 `rawData` 记录到控制台，这样你就可以在操作之前检查这个嵌套结构。

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, "log");

```

# --after-each--

```js
globalThis.spy.restore();
delete globalThis.spy;
```
