# --description--

У Python змінні — це імена, які посилаються на об’єкти. Оператори ідентичності перевіряють, чи посилаються два операнди на один і той самий об’єкт. Оператор `is` повертає `True`, якщо це так, і `False` інакше. Оператор `is not` повертає протилежний результат.

Ідентичність відрізняється від рівності: `==` і `!=` порівнюють значення, тоді як `is` і `is not` порівнюють ідентичність об’єктів. Використовуйте оператори рівності, коли порівнюєте числові або рядкові значення.

`None` представляє відсутність значення. Це єдине значення типу даних `NoneType`.

Три об’єкти, які можна перевірити за допомогою операторів ідентичності, — це `None`, `True` і `False`. Кожен із них є сінглтоном, тобто існує рівно один об’єкт для кожного.

## Перевірка на `None`

Ви можете використовувати `is None`, щоб перевірити, чи відсутнє значення, або `is not None`, щоб перевірити, чи воно присутнє:

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None` є хибним значенням, але це не той самий об’єкт, що й `False`. Наприклад, відповідь може бути `True` для так, `False` для ні або `None`, якщо відповідь не надана:

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

Використання `if not response` замість цього трактувало б `False` і `None` однаково. Перевірка ідентичності відрізняє від’ємну відповідь від відсутньої.

## Перевірка на `True` і `False`

Ви також можете використовувати ідентичність, щоб перевірити конкретно булеві об’єкти:

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

Ці перевірки питають, чи є `response` саме `True`, `False` або об’єктом, відмінним від `None`. Вони не просто перевіряють істинність.

Для звичайних булевих прапорців використовуйте прямі перевірки істинності, такі як `if is_ready` або `if not is_ready`. Використовуйте `is True` або `is False`, коли вам потрібно саме відрізнити булевий об’єкт від інших можливих значень, як у випадку з відповіддю, яка також може бути `None`.
