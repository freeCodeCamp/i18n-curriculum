# --description--

計算には数字で問題なくても、出力すると少し中途半端に見えることがあります。例えば価格を表示する場合、`12.50`の方が`12.5`より自然に感じるかもしれません。

f-stringを使うと、元の値を変えずに数字の見た目を表示時にコントロールできるので、計算にはそのまま使い続けられます。

## フォーマット指定子の仕組み

式 `f"{value:.2f}"` は、小数点以下ちょうど2桁で`value`を表示します。

波括弧の中の各文字にはそれぞれ役割があります：

- コロン `:` はフォーマット指定子の開始を示します
- `.2` は小数点以下2桁を指定します
- `f` は固定小数点表記を選び、数字を10進数表記で表示します。

つまり、`print(f"{12.5:.2f}")` は `12.50` を出力しますが、元の値は変わりません：

```py
value = 12.5

print(f"{value:.2f}") # 12.50
print(value) # 12.5
```

出力が `12.50` になるのは、`.2f` のフォーマット指定子が常に小数点以下2桁を表示し、Pythonが結果に末尾のゼロを補っているからです。`value`に保存されている値はまだ `12.5` のままです。


一方、`12.3456` のような値を `.2f` でフォーマットすると、表示用に四捨五入されて `12.35` になります：

```py
value = 12.3456

print(f"{value:.2f}") # 12.35
print(value) # 12.3456
```

## F-Stringでのフォーマットは文字列を生成する

f-stringは文字列を生成します：

```py
value = 12.3456
display = f"{value:.2f}"

print(display) # 12.35
print(value) # 12.3456

print(type(display)) # <class 'str'>
print(type(value)) # <class 'float'>
```

つまり、結果の文字列を別に保存しておき、元の数字は計算に使い続けられます。

## `round()` とF-Stringフォーマットの違い

`round(value, 2)` のような式は、さらに計算に使える数値を返します。

その結果を出力するときはPythonの通常の数字表示が使われるため、末尾のゼロは保証されません：

```py
value = 12.5

rounded_value = round(value, 2)
formatted_value = f"{value:.2f}"

print(rounded_value) # 12.5
print(formatted_value) # 12.50
```

## フォーマットは元の値を変えない

先ほど見たように、`0.1` や `0.2` のような小数は浮動小数点数として近似されるだけです。そのため、合計を直接出力すると少し驚くような表示になることがあります：

```py
total = 0.1 + 0.2

print(total) # 0.30000000000000004
print(f"{total:.2f}") # 0.30
```

ご覧の通り、f-stringは表示用に合計を丸めています。`total` を使った計算は依然として同じ浮動小数点の値を使います。
