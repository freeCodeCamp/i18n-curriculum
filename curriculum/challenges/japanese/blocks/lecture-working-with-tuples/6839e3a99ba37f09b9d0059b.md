# --description--

## タプルとは何ですか？

タプルは、Pythonのデータ型で、順序付けられた値のシーケンスを作成するために使われます。タプルはこのように異なるデータ型を混在させることができます。

```py
developer = ('Alice', 34, 'Rust Developer')
```

カンマがタプルを作成するので、このような代入では丸括弧は省略可能です。

```py
developer = 'Alice', 34, 'Rust Developer'
print(developer) # ('Alice', 34, 'Rust Developer')
```

要素が1つのタプルを作成するには、末尾にカンマが必要です。

```py
single_value = (5,)
print(single_value) # (5,)

not_a_tuple = (5)
print(not_a_tuple) # 5
```

空のタプルは `()` と書きます。

タプルはリストに似ていますが、リストは変更可能なデータ型であるのに対し、タプルは変更不可能です。つまり、一度タプルが作成されると、その要素の参照は置き換えたり、追加したり、削除したりできません。

もしタプルの中のアイテムを更新しようとすると、`TypeError`が発生します。

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')
programming_languages[0] = 'JavaScript'

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: 'tuple' object does not support item assignment
"""
```

## タプル内の変更可能なオブジェクト

タプルはリストのような変更可能なオブジェクトを含むことができます。タプルの変更不可能性は、その中に含まれるオブジェクトの変更を妨げません。

```py
def add_greeting(values):
    values[0].append('hi')

greetings = (['hello'],)
original_list = greetings[0]

add_greeting(greetings)
print(greetings) # (['hello', 'hi'],)
print(greetings[0] is original_list) # True
```

関数はタプル内のリストを変更しています。タプルは同じリストへの参照を保持し続けます。`greetings[0]` に別のリストを代入すると、タプルの要素参照が置き換えられるため `TypeError` が発生します。

## タプルの要素にアクセスする

タプルの要素にアクセスするには、ブラケット記法とインデックス番号を使います。

```py
developer = ('Alice', 34, 'Rust Developer')
developer[1] # 34
```

タプルの末尾から要素にアクセスする必要がある場合は、負のインデックスを使うことができます。以下は、タプルの後ろから2番目の要素にアクセスする例です。

```py
numbers = (1, 2, 3, 4, 5)
numbers[-2] # 4
```

もしタプルの長さを超えるか等しいインデックス番号を渡そうとすると、次のような`IndexError`が発生します。

```py
numbers = (1, 2, 3, 4, 5)
numbers[7]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
IndexError: tuple index out of range
"""
```

## `tuple()` コンストラクタの使い方

タプルを作成するもう一つの方法は、`tuple()`コンストラクタを使うことです。

```py
developer = 'Jessica'
tuple(developer) # ('J', 'e', 's', 's', 'i', 'c', 'a')
```

`tuple()` コンストラクタには、文字列、リスト、さらには他のタプルなど、さまざまなイテラブルを渡すことができます。

## タプルに要素が含まれているか確認する

タプルにアイテムが含まれているかどうかを確認するには、`in`キーワードを使います。

```py
programming_languages = ('Python', 'Java', 'C++', 'Rust')

'Rust' in programming_languages # True
'JavaScript' in programming_languages # False
```

## タプルから値をアンパックする

リストと同様に、タプルからアイテムをアンパックすることもできます。

```py
developer = ('Alice', 34, 'Rust Developer')
name, age, job = developer

print(name) # 'Alice'
print(age) # 34
print(job) # 'Rust Developer'
```

この例では、`name`は`'Alice'`の値を持ち、`age`は`34`の値を持ち、`job`は`'Rust Developer'`の値を持ちます。

タプルから残りの要素をまとめて取得したい場合は、アスタリスク（`*`）演算子を使うことができます。

```py
developer = ('Alice', 34, 'Rust Developer')
name, *rest = developer

print(name) # 'Alice'
print(rest) # [34, 'Rust Developer']
```

ここで、`name`は`'Alice'`の値を持ち、`rest`は数値`34`と文字列`'Rust Developer'`からなるリストです。

## 同時代入でのタプルの使用

代入の右側にタプルを作成し、左側の変数に展開できます。

```py
first, second = 10, 20
print(first) # 10
print(second) # 20
```

Pythonは代入の右側のすべての式を評価してから、左側の変数に値を代入します。これにより、一時変数なしで2つの値を入れ替えられます。

```py
first, second = 10, 20
first, second = second, first

print(first) # 20
print(second) # 10
```

## 関数からのタプルの返却

関数は `return` の後にカンマ区切りの値を置くことでタプルを返せます。

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

coordinates = get_coordinates()
print(coordinates) # (10, 20)
```

カンマ区切りの値は1つのタプルを作成し、関数はそれを返します。ここで `return first, second` は `return (first, second)` と同じで、丸括弧は省略可能です。

返されたタプルを直接変数に展開できます。

```py
def get_coordinates():
    first = 10
    second = 20
    return first, second

x, y = get_coordinates()
print(x) # 10
print(y) # 20
```

## タプルのスライス

リストと同様に、スライス演算子を使ってタプルの一部を抽出することができます。以下は、`'pie'`と`'cookies'`のアイテムを別のタプルに抽出する例です。

```py
desserts = ('cake', 'pie', 'cookies', 'ice cream')
desserts[1:3] # ('pie', 'cookies')
```

最初の数字は抽出の開始インデックスを表し、2番目の数字は終了インデックスを表します。ただし、終了インデックスのアイテムは抽出されたタプルに含まれません。

## タプルの比較

Pythonはタプルを辞書式順序で比較します。つまり、左から右へ対応する要素を比較し、最初に異なるペアで結果が決まります。

```py
print((1, 9) < (2, 0)) # True
```

ここでは `1` が `2` より小さいので、最初のタプルの方が小さいです。Pythonは `9` と `0` を比較する必要はありません。

最初の要素が等しい場合、Pythonは次のペアに進みます。

```py
print((1, 3) < (1, 5)) # True
```

両方のタプルは `1` で始まるので、Pythonは `3` と `5` を比較して結果を決めます。

すべての対応する要素が等しい場合、短い方のタプルが小さいです。同じ長さで対応する要素が等しいタプルは等しいです。

```py
print((1, 2) < (1, 2, 3)) # True
print((1, 2) == (1, 2)) # True
```

最初に異なるペアの値は順序比較をサポートしている必要があります。そうでなければ、Pythonは `TypeError` を発生させます。

```py
print((1, 3) < (1, 'five'))
# TypeError: '<' not supported between instances of 'int' and 'str'
```

ここでは最初の要素は等しいですが、Pythonは整数の `3` と文字列の `'five'` を順序付けできません。

前のペアで結果が決まれば、後の要素は比較可能である必要はありません。

```py
print((1, 3) < (2, 'five')) # True
```

## タプルから要素を削除する

タプルからアイテムを削除する必要がある場合、それは不可能です。なぜならタプルはイミュータブルだからです。この例はエラーになります：

```py
developer = ('Jane Doe', 23, 'Python Developer')
del developer[1]

"""
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
TypeError: "tuple" object doesn't support item deletion
"""
```

## タプルとリストの使い分け

では、リストではなくタプルを使うのはどんな場合でしょうか？

要素を追加、削除、更新できる動的なコレクションが必要ならリストを使うべきです。要素の参照が固定されたシーケンスが必要ならタプルを使えます。含まれる変更可能なオブジェクトは変わる場合があることを覚えておいてください。
