# --description--

おそらく、基本的なショートカットのいくつかにはすでに慣れているでしょう。これらはお使いのオペレーティングシステムから引き継がれています。例えば、保存には <kbd>Ctrl</kbd> + <kbd>S</kbd>（Windows/Linux）や <kbd>Cmd</kbd> + <kbd>S</kbd>（macOS）、コピーには <kbd>Ctrl</kbd> + <kbd>C</kbd> または <kbd>Cmd</kbd> + <kbd>C</kbd>、貼り付けには <kbd>Ctrl</kbd> + <kbd>V</kbd> または <kbd>Cmd</kbd> + <kbd>V</kbd> が VS Code で使えます。

しかし、アプリケーション固有のショートカットもいくつかあり、生産性をさらに向上させることができます。これらのショートカットはオペレーティングシステムによって異なる場合があることに注意してください。

例えば、<kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> は、現在開いているファイルに対して設定されたフォーマッター（JavaScript プロジェクトなら Prettier など）を実行します。

ワークスペース内のすべてのファイルのテキスト内容を検索するには、<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>（Windows/Linux）または <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>（macOS）を使います。さらに、検索と置換を実行したい場合は、<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd>（Windows/Linux）または <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd>（macOS）を使ってください。

行を削除したい場合は、<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>（Windows/Linux）または <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>K</kbd>（macOS）で削除できます。

コードのスペースをもっと確保したいですか？<kbd>Ctrl</kbd> + <kbd>B</kbd>（Windows/Linux）または <kbd>Cmd</kbd> + <kbd>B</kbd>（macOS）で、ファイルリストや拡張機能メニューがあるサイドバーを非表示にできます。

コードが見づらい場合は、<kbd>Ctrl</kbd> + <kbd>Plus</kbd>（Windows/Linux）または <kbd>Cmd</kbd> + <kbd>Plus</kbd>（macOS）でエディターの拡大率を上げ、<kbd>Ctrl</kbd> + <kbd>Minus</kbd>（Windows/Linux）または <kbd>Cmd</kbd> + <kbd>Minus</kbd>（macOS）で縮小できます。

VS Code のもう一つ便利な機能は複数行編集で、複数の行にまたがって同時に変更できます。例えば、複数のカーソルを配置するには、<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> と <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd>（Windows）、<kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Down</kbd> と <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>Up</kbd>（Linux）、または <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Down</kbd> と <kbd>Option</kbd> + <kbd>Cmd</kbd> + <kbd>Up</kbd>（macOS）を使って連続した行にカーソルを拡張できます。また、<kbd>Alt</kbd>（Windows/Linux）または <kbd>Option</kbd>（macOS）を押しながらクリックすると、必要な場所の別々の行にカーソルを追加できます。カーソルが配置されると、入力や削除した内容がすべてのカーソル位置に同時に反映されるため、繰り返しのコード作業で大幅に時間を節約できます。

最後に、これらのショートカットを忘れてしまった場合でも、<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（Windows/Linux）または <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（macOS）でコマンドパレットを開き、必要なコマンドを選択できます。
