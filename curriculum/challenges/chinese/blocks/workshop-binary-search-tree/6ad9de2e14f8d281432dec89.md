# --description--

在之前的课程中，你学习了树。二叉树是一种每个节点最多有两个子节点的树，这两个子节点分别称为左子节点和右子节点。

二叉搜索树（BST）是一种保持其值有序的二叉树：对于每个节点，它左子树中的所有值都比该节点的值小，右子树中的所有值都比该节点的值大。

<img alt="a binary search tree" src="https://cdn.freecodecamp.org/curriculum/python/bst-example.png" style="background-color: white; height:500px; width:500px; padding: 10px; display: block; margin-right: auto; margin-left: auto; margin-bottom: 1.2rem;">

在本次练习中，你将构建一个二叉搜索树并学习如何遍历它。

首先创建一个名为 `TreeNode` 的类来表现树的单个节点。给它一个带有两个参数 `self` 和 `key` 的 `__init__` 方法，并将 `key` 赋值给 `self.key`。
