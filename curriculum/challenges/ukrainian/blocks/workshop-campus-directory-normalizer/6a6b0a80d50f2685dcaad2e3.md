# --description--

У цьому практичному занятті ви працюватимете з розумним довідником кампусу та створите таблиці пошуку з вкладених даних.
Ви використовуватимете ці таблиці пошуку для швидких і ефективних пошуків. `rawData` вже надано для вас.

Зверніть увагу на його форму: кожен ключ — це назва відділу, а його значення містить `Dept_code` разом із масивом `programs`.
Кожна програма містить власний масив `instructors`.

Для початку виведіть `rawData` у консоль, щоб ви могли оглянути цю вкладену структуру перед тим, як працювати з нею.

```js
globalThis.spy = __helpers.spyOn(console, "log");
```

# --after-each--

```js
globalThis.spy.restore();

```
