# --description--

이 실습에서는 허용되지 않은 문자를 `#`로 교체하고 처리된 항목 수를 추적하여 반구조화된 로그 파일을 정리할 것입니다.

**목표:** 아래 사용자 스토리를 충족하고 모든 테스트를 통과하여 실습을 완료하세요.

**사용자 스토리:**

1. 함수 선언을 사용해 `sanitizeLog`라는 이름의 함수를 만들고, 두 개의 매개변수 `entry`(로그 항목을 나타내는 문자열)와 `disallowedCharacters`(교체할 단일 문자 문자열 배열)를 받도록 하세요.
1. 이 함수는 각 허용되지 않은 문자가 `#`로 교체된 수정된 `entry` 문자열을 반환해야 합니다. 대소문자를 구분하여 일치시켜야 합니다. 예를 들어, 허용되지 않은 문자가 `["e", "E", "o", "r"]`라면 `DEBUG: Server started on port 3000`은 `D#BUG: S##v## sta#t#d #n p##t 3000`을 반환해야 합니다.
1. `cleanLogs`라는 이름의 함수를 만들고, 두 개의 매개변수 `logs`(로그 항목 문자열 배열)와 `disallowedCharacters`(교체할 단일 문자 문자열 배열)를 받도록 하세요.
1. `cleanLogs`는 주어진 로그 항목 배열을 순서대로 순회해야 합니다.
1. `cleanLogs`가 치명적 표시 `$`가 포함된 로그 항목에 도달하면 중지하고 `Sanitizing stopped. Failure Reason: Fatal character occurred.`를 반환해야 합니다.
1. `/` 문자로 시작하는 로그 항목은 정보성 항목이며 세니타이징하지 않아야 합니다. 정보성 항목 수를 세야 합니다.
1. 그 외 모든 로그 항목은 `sanitizeLog` 함수를 사용해 세니타이징해야 하며, 세니타이징된 항목 수를 세야 합니다.
1. `cleanLogs`가 치명적 표시를 만나지 않고 끝나면 `Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.`를 반환해야 하며, 여기서 `X`는 전체 항목 수, `Y`는 세니타이징된 항목 수, `Z`는 정보성 항목 수입니다.

**테스트에 사용되는 다음 로그 배열들이 있습니다:**

```js
let logs_1 = [
  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"
];

let logs_2 = [
  "FATAL: System overload detected, shutting down",
  "DEBUG: token=def456$ refreshed for session",
  "ERROR: Null pointer exception in module auth"
];

let logs_3 = [
  "ERROR: Failed to connect to db, retry=3",
  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
