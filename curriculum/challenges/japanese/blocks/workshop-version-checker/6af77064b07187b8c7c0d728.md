# --description--

関数がタプルを返すようになったので、それを複数の変数にアンパックできます。

`check_for_update` の呼び出しを、その結果を `status` と `latest_version` の2つの変数にアンパックする代入に変えてください。

次に、文字列 `Status:` と空白、その後に `status` の値を出力してください。また、文字列 `Latest version:` と空白、その後に `latest_version` の値も出力してください。
