# --description--

ここ数レッスンで、次のようなループの使い方に慣れてきました。

```py
even_numbers = []

for num in range(21):
    if num % 2 == 0:
        even_numbers.append(num)

print(even_numbers)
```

この例では、`even_numbers` という新しい空のリストを作成し、`0` から `20` までの数値のシーケンスをループしています。ループ内では、現在の数値を `0` で割ったときの余りが `2` かどうかを条件でチェックしています。これは数値が偶数かどうかを判定するためです。条件が `True` の場合、現在の `num` が `even_numbers` リストの末尾に追加されます。最後に、`even_numbers` リストをコンソールに出力しています。

## リスト内包表記とは何ですか？

このコードは動作しますが、リスト内包表記を使うともっと簡潔に書けます。リスト内包表記では、丸括弧の中に直接ループを書いて一行で新しいリストを作成できます。これによりコードが短くなり、読みやすくなることが多いです。

リスト内包表記の基本的な構文は次のようになります：

```py
[expression for item in iterable]
```

イテラブルの各アイテムに対して、`for`の前の式が評価され、その結果が新しいリストに追加されます。例えば、`0`から`4`までの各数字に`2`を掛けたリストを作る例は次の通りです：

```py
doubled = [num * 2 for num in range(5)]
print(doubled) # [0, 2, 4, 6, 8]
```

## 後置の`if`によるフィルタリング

リスト内包表記の最後に`if`条件を追加することができます。条件が真となるアイテムだけが新しいリストに追加され、それ以外はスキップされます。

先ほどの偶数の例をリスト内包表記で書き直したものがこちらです：

```py
even_numbers = [num for num in range(21) if num % 2 == 0]
print(even_numbers)
```

この書き換え例では、`even_numbers` リストが1行のコードで作成されています。リスト内包表記は `0` から `20` までの数値をループし、`2` で割り切れる数だけを含めています。この方法はよりコンパクトで、別のループや条件ブロックが不要になります。

## 個別の内側リストを作成する

以前、`[[]] * 3`は1つの内側リストの参照を3回繰り返すことを学びました。内包表記を使うと、各イテレーションで別々の内側リストを作成できます：

```py
rows = [[] for _ in range(3)]
print(rows[0] is rows[1]) # False

rows[0].append('hello')
print(rows) # [['hello'], [], []]
```

式`[]`は各イテレーションで評価されるため、それぞれの位置は異なるリストを指します。ループ変数は式内で使われず、rangeは作成するリストの数だけを制御します。

ループ変数が不要な場合、Pythonの開発者は慣例としてその変数名を`_`にします。これは値が意図的に無視されていることを示しますが、`_`は普通の変数名です。

## リスト内包表記で条件式を使う

これまで`if`と`else`を使って条件文を書いてきました。Pythonには1行で書けて値を返す条件式もあります。構文は次の通りです：

```py
value_if_true if condition else value_if_false
```

条件が真なら、式全体は`if`の前の値に評価されます。そうでなければ、`else`の後の値に評価されます。例を示します：

```py
num = 7
label = 'Even' if num % 2 == 0 else 'Odd'
print(label) # Odd
```

`7`は`2`で割り切れないので条件は`False`となり、`label`には`'Odd'`が代入されます。

リスト内包表記の `for` の前の式として条件式を使うことができます。その場合、イテラブルの各アイテムに対して値を選ぶので、新しいリストは元のリストと同じ数のアイテムを持ちます。これは、末尾の `if` とは異なり、新しいリストからアイテムを除外することができます。

例を見てみましょう。

```py
numbers = [1, 2, 3, 4, 5]
result = [(num, 'Even') if num % 2 == 0 else (num, 'Odd') for num in numbers]
print(result)
```

この例では、数字のリストがあり、どの数字が偶数か奇数かを示すタプルの新しいリストを作成したいです。リスト内包表記の最初の部分では、`if`/`else` 条件式を使って数字が `2` で割り切れるかどうかを確認します。割り切れる場合は、その数字に続いて `Even` という単語が入ったタプルが結果になります。そうでなければ、その数字に続いて `Odd` という単語が入ったタプルが結果になります。

コンソールに出力した結果は次のようになります。

```py
[(1, 'Odd'), (2, 'Even'), (3, 'Odd'), (4, 'Even'), (5, 'Odd')]
```

## `filter()` でリストをフィルタリングする

既存のイテラブルからリストを作成する別の方法は `filter()` 関数です。こちらは4文字より長い単語だけを集めた新しいリストを作る例です。

```py
words = ['tree', 'sky', 'mountain', 'river', 'cloud', 'sun']

def is_long_word(word):
    return len(word) > 4

long_words = list(filter(is_long_word, words))
print(long_words) # ['mountain', 'river', 'cloud']
```

`filter()`関数は、特定の条件を満たすイテラブルの要素を選択するために使います。`filter()`は関数とイテラブルを引数に取ります。この例では、現在の単語の文字数が`4`より大きいかをチェックする`is_long_word`関数を`filter()`に渡しています。`is_long_word`は関数自体を渡すため、丸括弧なしで書きます。`filter()`は各単語に対して`is_long_word`を呼び出します。`zip()`と同様に、`filter()`は条件を満たす単語だけを返すイテレータを返します。`list()`関数がそれらの単語を新しいリストにまとめ、`long_words`変数に代入します。

## `map()` でリストを変換する

`filter()` 関数以外にも、リスト操作に便利な関数がいくつかあります。もう一つ知っておきたいのは `map()` 関数で、これはイテラブルの各要素に関数を適用します。こちらは `map()` 関数を使って摂氏の温度リストを華氏に変換する例です。

```py
celsius = [0, 10, 20, 30, 40]

def to_fahrenheit(temp):
    return (temp * 9/5) + 32

fahrenheit = list(map(to_fahrenheit, celsius))
print(fahrenheit) # [32.0, 50.0, 68.0, 86.0, 104.0]
```

`filter()`関数と同様に、`map()`も関数とイテラブルを引数に取ります。`to_fahrenheit`関数は温度を摂氏から華氏に変換します。`to_fahrenheit`も丸括弧なしで渡し、`map()`が`celsius`リストの各温度に対して呼び出します。`map()`も変換後の値のイテレータを返すため、`list()`でリストにまとめます。

## `sum()` で値を合計する

最後に紹介するのは `sum()` 関数です。この関数はリストやタプルのようなイテラブルの合計を取得するために使います。こちらは `sum()` 関数の使用例です。

```py
numbers = [5, 10, 15, 20]
total = sum(numbers)
print(total) # Result: 50
```

オプションの `start` 引数を渡すこともでき、これは合計の初期値を設定します。こちらは `start` 引数を位置引数として使った更新例です。

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, 10) # positional argument
print(total) # 60
```

また、`start` 引数をキーワード引数として使うこともできます。

```py
numbers = [5, 10, 15, 20]
total = sum(numbers, start=10) # keyword argument
print(total) # 60
```

どちらの方法でも同じ結果になりますが、キーワード引数のほうが少し明示的です。

リスト内包表記や `map()`、`filter()`、`sum()` のような関数は最初は少し混乱するかもしれません。でも練習と時間をかければ、Pythonプログラムで使いこなせるようになります。
