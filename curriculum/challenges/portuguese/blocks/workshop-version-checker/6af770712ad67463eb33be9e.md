# --description--

Tuplas são imutáveis, então você não pode adicionar um elemento a `releases`. Em vez disso, você pode usar o operador `+` para criar uma nova tupla que une os elementos de duas tuplas:

```py
numbers = (1, 2)
print(numbers + (3, 4)) # (1, 2, 3, 4)
```

`new_version` é uma tupla por si só, então `releases + new_version` adicionaria seus três números como elementos separados. Para adicioná-la como um único elemento, envolva-a em uma tupla com um elemento. Lembre-se de que uma tupla com um elemento precisa de uma vírgula no final.

No final da sua função, retorne o resultado da união de `releases` com uma tupla contendo apenas `new_version`.

    sorted_releases = tuple(sorted(releases, reverse=True))

        return 'not a known release', latest

    elif installed[:2] < latest[:2]:
        update_type = 'minor update'
    else:

def release_version(releases, release_type, base_version=None):
    if base_version is None:
        base_version = sorted(releases, reverse=True)[0]
    elif base_version not in releases:
        print(f'{base_version} is not a known release')
        return releases

    elif release_type == 'minor':

    elif release_type == 'patch':
        new_version = (major, minor, patch + 1)
    else:
        print(f'{release_type} is not a valid release type')
        return releases

    if new_version in releases:
        print(f'{new_version} has already been released')
        return releases
