Em uma árvore binária de busca, os valores na subárvore esquerda de um nó são menores que o valor do nó, e os valores na subárvore direita são maiores. Então visitar a subárvore esquerda, depois o nó, depois a subárvore direita coleta as chaves do menor para o maior.

class BinarySearchTree:

    def _insert(self, node, key):

        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node
