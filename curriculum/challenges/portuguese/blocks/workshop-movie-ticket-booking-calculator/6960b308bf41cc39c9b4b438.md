# --description--

O operador `or` é usado para verificar se pelo menos uma de duas condições é verdadeira. Veja como você pode usá-lo com uma comparação em uma declaração `if`:

```py
day = 'Sunday'
is_raining = False

if day == 'Sunday' or is_raining:
    print('Stay at home')
```

No exemplo acima, `Stay at home` é impresso porque a primeira condição é verdadeira, mesmo que `is_raining` seja `False`.

Cobranças extras também devem ser aplicadas nos fins de semana. Atualize a condição da linha `if show_time == 'Evening':` usando o operador `or` para combinar a condição existente com uma segunda condição que verifica se `is_weekend` é verdadeiro.
