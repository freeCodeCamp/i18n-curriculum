# --description--

値を挿入するには、ルートから始めて、値がノードの値より小さければ左へ、大きければ右へ進み、空いている場所にたどり着くまで続けます。各サブツリーも二分探索木なので、これを再帰で行うことができます。

`BinarySearchTree` クラスの中に、`self`、`node`、`key` の3つのパラメータを持つ `_insert` という名前のメソッドを作成してください。先頭のアンダースコアは内部用のヘルパーであることを示します。

その中に、`key` が `node.key` より小さいかどうかをチェックする `if` 文を追加してください。`if` の中で、`self._insert` を `node.left` と `key` を使って呼び出し、その結果を `node.left` に代入してください。これにより、左のサブツリーに値が挿入され、更新されたサブツリーが現在のノードに接続されたままになります。
