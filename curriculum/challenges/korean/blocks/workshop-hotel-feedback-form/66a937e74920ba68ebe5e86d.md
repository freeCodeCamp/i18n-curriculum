# --description--

`placeholder` 속성은 `input` 안에 힌트 텍스트를 보여줍니다. 사용자가 입력을 시작하면 힌트 텍스트는 사라집니다.

`required` 속성은 사용자가 폼을 제출하기 전에 `input`을 반드시 채우도록 합니다. 이 속성은 불리언 속성이어서 값이 필요하지 않습니다.

다음은 두 속성을 모두 사용하는 `input` 예시입니다:

```html
<input type="email" placeholder="e.g., jane@example.com" required>
```

기존 `input` 요소에 `placeholder` 속성을 값 `"e.g., John Doe"`로 추가하세요.

또한 `input` 요소에 `required` 속성을 추가하세요.

# --hints--

기존 `input` 요소는 제거하지 마세요.

```js
assert.isNotNull(document.querySelector('fieldset input'));
```

`input`에는 값이 `"e.g., John Doe"`인 `placeholder` 속성이 있어야 합니다.

```js
assert.strictEqual(document.querySelector('fieldset input')?.getAttribute('placeholder'), 'e.g., John Doe');
```

`input`에는 `required` 속성이 있어야 합니다.

```js
assert.isNotNull(document.querySelector('fieldset input[required]'));
```
