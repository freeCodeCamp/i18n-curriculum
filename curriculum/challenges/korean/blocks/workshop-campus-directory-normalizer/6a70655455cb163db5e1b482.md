# --description--

부서 이름과 값을 배열 항목으로 처리하려면 `Object.entries(rawData)`를 사용하세요. 이 메서드는 객체의 고유한 열거 가능한 문자열 키 프로퍼티에 대해 `[key, value]` 쌍의 배열을 반환합니다.

```js
const person = {
  name: "Alice",
  age: 30
};

console.log(Object.entries(person));
/*
Output: 
[ ["name", "Alice"], ["age", 30] ]
*/
```

`departmentEntries`라는 변수를 선언하고 `Object.entries(rawData)`로 설정하세요.
그런 다음 `departmentEntries`를 콘솔에 출력하여 생성된 `[key, value]` 쌍을 확인하세요.
