# --interactive--

**ПРИМІТКА**: Деякі інтерактивні приклади можуть використовувати CSS, який ви ще не вивчали. Не хвилюйтеся, якщо не розумієте весь код. Мета прикладів — показати вам попередній перегляд цих концепцій дизайну, щоб ви краще зрозуміли, як все працює. Щоб побачити попередній перегляд, потрібно увімкнути інтерактивний редактор.

Коли йдеться про вебдизайн, існує багато типів навігаційних допоміжних засобів, які ви можете використовувати. Прикладами є верхні навігаційні панелі, бічні панелі та нижні колонтитули. Але якщо ваш сайт досить складний і має глибші рівні навігації, варто розглянути використання breadcrumbs.

Breadcrumbs — це навігаційний помічник, який показує користувачу, де він знаходиться в ієрархії сайту. Ось приклад того, як виглядають breadcrumbs для макету сайту електроніки:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="breadcrumbs">
  Home / Electronics / Phones / Smartphone XYZ
</div>
```

```css
.breadcrumbs {
  font-size: 0.9rem;
  color: #555;
  margin: 1rem 0;
}
```

:::

На більшості сайтів хлібні крихти відображаються у верхній частині сторінки, показуючи, де поточна сторінка розташована у структурі сайту. У цьому прикладі продукт `Smartphone XYZ` знаходиться в категорії `Phones`, яка, у свою чергу, входить до категорії `Electronics`, що пов’язана зі сторінкою `Home`. Хлібні крихти показують цей самий шлях незалежно від того, як користувач потрапив на сторінку. Той, хто перейшов за посиланнями з головної сторінки, і той, хто потрапив на продукт безпосередньо з результатів пошуку, побачать однаковий шлях `Home / Electronics / Phones / Smartphone XYZ`. Ви, мабуть, вже стикалися з хлібними крихтами на сайтах під час пошуку продукту або конкретної інформації.

Використання хлібних крихт корисне, бо допомагає користувачам зрозуміти, де вони знаходяться у ієрархії сайту, і як піднятися до ширших сторінок вище за поточну. Це особливо важливо, коли користувач прийшов із результатів пошуку або зовнішнього посилання і потребує розуміння контексту сторінки, на якій він перебуває.

Деякі сайти використовують інший тип хлібних крихт, які відстежують сторінки, які користувач фактично відвідував, подібно до історії браузера. Цей урок зосереджений на ієрархічних хлібних крихтах, які є найпоширенішим типом.

## Вибір роздільника

При проєктуванні breadcrumbs варто врахувати кілька моментів. Перший — визначити, який буде роздільник. Роздільник — це символ, який відокремлює різні рівні ієрархії. Загальними роздільниками є знак більше (`>`), праві лапки (`»`) і коса риска (`/`).

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="breadcrumbs">
  Home &gt; Electronics &gt; Phones &gt; Smartphone XYZ
</div>
```

```css
.breadcrumbs {
  font-size: 0.9rem;
  color: #555;
  margin: 1rem 0;
}
```

:::

## Розміщення

Другий момент — розміщення breadcrumbs. Зазвичай їх розміщують у верхній частині сторінки, або над, або під головною навігаційною панеллю. Користувачам не повинно бути складно знайти breadcrumbs, тому переконайтеся, що вони видимі та легко доступні.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<nav class="main-nav">
  <a href="#">Home</a>
  <a href="#">Electronics</a>
  <a href="#">Phones</a>
</nav>
<div class="breadcrumbs">
  Home &gt; Electronics &gt; Phones &gt; Smartphone XYZ
</div>
```

```css
.main-nav {
  background-color: #333;
  padding: 1rem;
}

.main-nav a {
  color: white;
  margin-right: 1rem;
  text-decoration: none;
}

.breadcrumbs {
  font-size: 0.9rem;
  color: #555;
  margin: 1rem 0;
}
```

:::

У цьому прикладі головна навігація містить посилання на `Phones`, хоча `Phones` — це категорія всередині `Electronics`. Це нормально, бо посилання в головній навігації часто є скороченнями до популярних сторінок і не обов’язково мають бути категоріями верхнього рівня. Хлібні крихти все одно показують повну ієрархію, тож користувачі бачать, що `Phones` знаходиться під `Electronics`.

## Розмір

Ще одним аспектом є розмір хлібних крихт. Потрібно переконатися, що хлібні крихти достатньо великі, щоб їх легко читати, але не настільки, щоб вони займали забагато місця на сторінці. Пам’ятайте, що хлібні крихти не призначені для основної навігації, а скоріше як допоміжний навігаційний елемент. На сайтах із великою кількістю інформації на сторінці користувачі можуть легко бачити, де вони знаходяться в ієрархії, і переходити до батьківських сторінок за допомогою хлібних крихт.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="breadcrumbs">
  Home &gt; Electronics &gt; Phones &gt; Smartphone XYZ
</div>
<p>
  Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.
</p>
```

```css
.breadcrumbs {
  font-size: 1rem;
  color: #555;
  margin: 1rem 0;
}   

p {
  font-size: 1.2rem;
  line-height: 1.6;
}
```

:::

## Коли використовувати breadcrumbs

Отже, коли варто використовувати breadcrumbs на вашому сайті? Якщо ваш сайт простий і має неглибоку ієрархію, breadcrumbs можуть бути не потрібні. Неглибока ієрархія означає, що сайт має лише кілька рівнів навігації, тому breadcrumbs можуть не додати значної користі. Зазвичай breadcrumbs використовують на сайтах електронної комерції, новинних сайтах та інших сайтах із глибокою ієрархією, наприклад, на сайтах технічної документації.
