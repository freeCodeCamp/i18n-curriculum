# --description--

Proprio come un punto (`.`) può segnare la fine di una frase in inglese, un punto e virgola (`;`) può essere usato per segnare la fine di un'istruzione in JavaScript. Tuttavia, le istruzioni non sono necessariamente la stessa cosa delle righe di codice sorgente. Un'istruzione può estendersi su più righe e una singola riga può contenere più di un'istruzione.

Per esempio:

```js
let variableOne = 5;
let variableTwo = 10;
```

In questo codice, i punti e virgola rendono esplicita la fine di ogni istruzione. JavaScript ha anche l'inserimento automatico del punto e virgola (ASI), che permette a queste dichiarazioni di rimanere valide senza punti e virgola espliciti:

```js
let variableOne = 5
let variableTwo = 10
```

In questo esempio, ASI permette a JavaScript di trattare ogni dichiarazione come un'istruzione separata anche se non ci sono punti e virgola. Tuttavia, ASI non inserisce semplicemente un punto e virgola dopo ogni interruzione di riga.

Per esempio, un'interruzione di riga dopo un'istruzione `return` può causare comportamenti inattesi:

```js
function getValue() {
  return
  {
    value: 42
  };
}
```

Qui, ASI inserisce un punto e virgola dopo `return`, quindi la funzione restituisce `undefined` invece dell'oggetto. Scrivere l'oggetto sulla stessa riga evita questo comportamento:

```js
function getValue() {
  return {
    value: 42
  };
}
```

Questo mostra perché le interruzioni di riga e i confini delle istruzioni non sono sempre la stessa cosa.

I punti e virgola possono essere utili anche quando un'interruzione di riga potrebbe altrimenti permettere a due pezzi di codice di essere interpretati come un'unica espressione. Un'espressione di funzione immediatamente invocata (IIFE) è una funzione che viene eseguita appena viene definita. Un modo per creare un'IIFE è racchiudere una funzione anonima, cioè una funzione senza nome, tra parentesi tonde e aggiungere `()` alla fine per chiamarla. Un'IIFE può causare un problema quando l'istruzione precedente non termina con un punto e virgola:

```js
const message = "Hello"

(function () {
  console.log(message);
})()
```

Qui, JavaScript non inserisce un punto e virgola dopo la dichiarazione della stringa perché la successiva `(` può continuare l'espressione di inizializzazione. JavaScript analizza l'inizializzatore come una chiamata alla stringa `"Hello"`, con l'espressione della funzione come argomento. Questo lancia un `TypeError` prima che l'IIFE possa essere eseguita. Aggiungere un punto e virgola termina la dichiarazione prima dell'IIFE:

```js
const message = "Hello";

(function () {
  console.log(message);
})()
```

Il punto e virgola esplicito mantiene la dichiarazione della variabile e l'IIFE come istruzioni separate.

I punti e virgola sono usati in molti linguaggi di programmazione, inclusi C, C++ e Java. Le loro regole esatte variano tra i linguaggi, ma comunemente aiutano a indicare dove finiscono le istruzioni.

Un compilatore traduce il codice sorgente in un'altra forma, come codice macchina, bytecode o una rappresentazione intermedia, a seconda del linguaggio e del compilatore. La compilazione non produce necessariamente un file eseguibile autonomo.

Usare i punti e virgola in modo coerente può rendere più chiari i confini delle istruzioni e facilitare la lettura e la manutenzione del codice.
