# --description--

`or` 運算子用來檢查兩個條件中是否至少有一個為真。以下示範如何在 `if` 述語中搭配比較運算使用它：

```py
day = 'Sunday'
is_raining = False

if day == 'Sunday' or is_raining:
    print('Stay at home')
```

在上面的範例中，因為第一個條件為真，即使 `is_raining` 是 `False`，仍會列印 `Stay at home`。

額外費用也應該在週末適用。請更新 `if show_time == 'Evening':` 這行的條件，使用 `or` 運算子將現有條件與第二個檢查 `is_weekend` 是否為真值的條件結合。
