Оператор рівності (`==`) перевіряє, чи два значення рівні, і повертає `True` або `False`. Він відрізняється від оператора присвоєння (`=`), який зберігає значення у змінній:

```py

print(color == 'red') # True
print(color == 'blue') # False
```
