# --description--

## لماذا تثبت Python محليًا؟

في جميع ورش العمل والمختبرات، ستستخدم محرر Python الخاص بـ freeCodeCamp. لكن من المهم أن تتعلم كيفية إعداد Python على جهازك المحلي.

## تنزيل Python

أسهل طريقة لتثبيت Python على ويندوز وماك هي تنزيل المثبت من الموقع الرسمي لـ Python. سنشرح أيضًا كيفية تشغيل Python على لينكس لاحقًا في هذا الدرس.

اذهب إلى `https://www.python.org/` وحرك المؤشر فوق "التنزيلات". ستظهر نافذة منبثقة تعرض الإصدار الحالي من Python لنظام التشغيل الخاص بك.

## تثبيت Python على macOS

سنبدأ بشرح كيفية تثبيت Python على جهاز يعمل بنظام macOS أولاً:

- انقر على الزر الذي يعرض الإصدار الحالي من Python (من النافذة السابقة)، وسيبدأ تنزيل ملف تثبيت `.pkg` تلقائيًا.
- بعد انتهاء تنزيل مثبت `.pkg`، افتحه ثم انقر على "Continue" في النافذة التي تظهر.
- استمر في النقر على زر "Continue" حتى تصل إلى قسم "Installation Type". هناك، انقر على زر "Install".
- أدخل كلمة المرور إذا لزم الأمر، ثم ابدأ التثبيت.
- عند انتهاء تثبيت الحزمة، يجب أن ترى رسالة تفيد بأن Python تم تثبيته بنجاح.
- افتح مجلد Python الجديد في دليل التطبيقات.
- انقر نقرًا مزدوجًا على ملف `Install Certificates.command` ودع عملية الطرفية تكتمل.
- تحقق من ظهور `Successfully installed certifi` و`update complete` في نافذة الطرفية.
- أغلق نافذة الطرفية وانقر على "Close" في نافذة المثبت. أصبح الإعداد الآن مكتملًا!

## التحقق من التثبيت

يمكنك التحقق من التثبيت بفتح الطرفية وتشغيل الأمر `python --version` أو `python3 --version`.

يمكنك أيضًا فتح مفسر Python بتشغيل `python` أو `python3` في الطرفية. مفسر Python هو برنامج يقرأ كود Python، يترجمه إلى تعليمات يفهمها الكمبيوتر، وينفذ تلك التعليمات.

## ما هو الطرفية؟

<dfn>الطرفية</dfn> هي واجهة نصية تتيح لك التفاعل مع جهاز الكمبيوتر بكتابة الأوامر. كل نظام تشغيل يأتي مع تطبيق طرفية افتراضي. على macOS، يمكنك استخدام تطبيق Terminal. على ويندوز، يمكنك استخدام Command Prompt أو PowerShell. على لينكس، لكل بيئة سطح مكتب تطبيق طرفية افتراضي خاص بها، مثل GNOME Terminal أو Konsole.

## استخدام `python` مقابل `python3`

لاحظ أنه في بعض أنظمة macOS وLinux القديمة، قد يكون `python` مخصصًا لـ Python 2، بينما `python3` مخصص لـ Python 3 تحديدًا. إذا شغلت `python --version` ورأيت إصدار Python 2 مثل `Python 2.7.18`، فمن المحتمل أن نظام التشغيل يعتمد على بعض البرامج المكتوبة بالإصدار القديم من Python. في هذه الحالة، يجب استخدام `python3` لتشغيل كود Python الخاص بك من الآن فصاعدًا. Python 2 انتهى عمره الافتراضي ولا يجب استخدامه لأي تطوير جديد.

## تثبيت Python على Windows

لتثبيت Python على ويندوز، اتبع الخطوات التالية:

- اذهب إلى `https://www.python.org/`، وحوم فوق "Downloads". سترى نافذة تقول "Download for Windows" وزر تنزيل مع الإصدار الحالي من Python.
- انقر على رقم الإصدار، وسيبدأ تنزيل مدير تثبيت Python (`.msix` package) تلقائيًا.
- بعد الانتهاء من تنزيل مدير التثبيت، انقر نقرًا مزدوجًا عليه واختر "Install".
- بعد التثبيت، يجب أن تتوفر أوامر `python` و`py` و`pymanager`. إذا لم يكن هناك وقت تشغيل Python مثبت، فإن تشغيل `python` سيقوم بتثبيته تلقائيًا.
- عند تثبيت وقت تشغيل لأول مرة، قد يُطلب منك إضافة دليل إلى متغير `PATH` لتمكين الأسماء المستعارة الإضافية، مثل `python3.14.exe`. اقبل هذا الطلب الاختياري إذا أردت استخدام تلك الأسماء المستعارة.


يمكنك التحقق من التثبيت بفتح واجهة سطر الأوامر مثل PowerShell وتشغيل `python --version`. يمكنك أيضًا فتح مفسر Python بتشغيل `python`.

## تثبيت Python على Linux

بالنسبة لـ Python على لينكس، معظم التوزيعات الرئيسية مثل أوبونتو، ديبيان، وفيدورا تأتي مع Python مثبتة.

افتح الطرفية وشغّل `python --version` أو `python3 --version`.

إذا لم يعرض أي من الأمرين إصدار Python 3، يمكنك البحث عن حزمة تثبيت لتوزيعتك من Linux على `https://www.python.org`، أو ابحث عبر الإنترنت عن الطريقة الموصى بها لتثبيت Python لتوزيعتك.
