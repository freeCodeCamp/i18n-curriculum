## Datentypen in JavaScript

Datentypen helfen dem Programm zu verstehen, mit welcher Art von Daten es arbeitet, ob es sich um eine Zahl, Text oder etwas anderes handelt.

- **Number**: Eine Zahl repräsentiert sowohl ganze Zahlen als auch Gleitkommazahlen. Beispiele für ganze Zahlen sind 7, 19 und 90. 
- **Gleitkommazahl**: Eine Gleitkommazahl ist eine Zahl mit einem Dezimalpunkt. Beispiele sind 3,14, 0,5 und 0,0001.
- **String**: Ein String ist eine Folge von Zeichen oder Text, der in Anführungszeichen eingeschlossen ist. `"I like coding"` und `'JavaScript is fun'` sind Beispiele für Strings.
- **Boolean**: Ein Boolean repräsentiert einen von zwei möglichen Werten: `true` oder `false`. Sie können einen Boolean verwenden, um eine Bedingung auszudrücken, wie zum Beispiel `isLoggedIn = true`.
- **Undefined und Null**: Ein `undefined`-Wert ist eine Variable, die deklariert, aber nicht mit einem Wert zugewiesen wurde. Ein `null`-Wert ist ein leerer Wert oder eine Variable, der absichtlich der Wert `null` zugewiesen wurde.
- **Object**: Ein Objekt ist eine Sammlung von Schlüssel-Wert-Paaren. Der Schlüssel ist der Name der Eigenschaft, und der Wert ist der Wert der Eigenschaft.

Zum Beispiel hat `{ name: "Fluffy", age: 3, type: "dog" }` drei Eigenschaften: `name`, `age` und `type`.

- **Symbol**: Der Datentyp Symbol ist ein einzigartiger und unveränderlicher Wert, der als Bezeichner für Objekteigenschaften verwendet werden kann.

Zwei Symbole, die mit derselben Beschreibung erstellt wurden, sind dennoch unterschiedliche Werte.

- **BigInt**: Wenn die Zahl zu groß für den `Number`-Datentyp ist, können Sie den BigInt-Datentyp verwenden, um ganze Zahlen beliebiger Länge darzustellen.

Indem Sie ein `n` an das Ende der Zahl anhängen, können Sie einen BigInt erstellen.

## Variablen in JavaScript

- Variablen können mit dem Schlüsselwort `let` deklariert werden.

- Um einer Variable einen Wert zuzuweisen, können Sie den Zuweisungsoperator `=` verwenden.

- Variablen, die mit `let` deklariert wurden, können einen neuen Wert zugewiesen bekommen.

- Neben `let` können Sie auch `const` verwenden, um eine Variable zu deklarieren. Allerdings kann einer `const`-Variablen kein neuer Wert zugewiesen werden.

- Variablen, die mit `const` deklariert wurden, werden verwendet, um Konstanten zu deklarieren, die im gesamten Code nicht geändert werden dürfen, wie `PI` oder `MAX_SIZE`.

## Konventionen zur Benennung von Variablen

- Variablennamen sollten beschreibend und aussagekräftig sein.
- Variablennamen sollten CamelCase sein, wie `cityName`, `isLoggedIn` und `veryBigNumber`.
- Variablennamen dürfen nicht mit einer Zahl beginnen. Sie müssen mit einem Buchstaben, `_` oder `$` beginnen.
- Variablennamen dürfen keine Leerzeichen oder Sonderzeichen enthalten, außer `_` und `$`.
- Variablennamen dürfen keine reservierten Schlüsselwörter sein.
- Variablennamen sind case-sensitiv. `age` und `Age` sind unterschiedliche Variablen.

## Strings und die Unveränderlichkeit von Strings in JavaScript

- Strings sind Zeichenfolgen, die in Anführungszeichen eingeschlossen sind. Sie können mit einfachen oder doppelten Anführungszeichen erstellt werden.

- Strings sind in JavaScript unveränderlich. Das bedeutet, dass Sie, sobald ein String erstellt wurde, die Zeichen im String nicht ändern können. Sie können jedoch Strings einem neuen Wert zuweisen.

## String-Verkettung in JavaScript

- Verkettung ist der Prozess, mehrere Strings zu verbinden oder Strings mit Variablen zu kombinieren, die Text enthalten. Der `+`-Operator ist eine der einfachsten und am häufigsten verwendeten Methoden, um Strings zu verketten.

- Wenn Sie einen bestehenden String erweitern oder anhängen möchten, können Sie den `+=`-Operator verwenden. Dies ist hilfreich, wenn Sie einen String im Laufe der Zeit durch Hinzufügen von mehr Text erweitern möchten.

- Eine weitere Möglichkeit, Strings zu verketten, ist die Verwendung der `concat()`-Methode. Diese Methode verbindet zwei oder mehr Strings miteinander.

## Nachrichten mit `console.log()` protokollieren

- Die `console.log()`-Methode wird verwendet, um Nachrichten in der Konsole zu protokollieren. Sie ist ein hilfreiches Werkzeug zum Debuggen und Testen Ihres Codes.

## Semikolons in JavaScript

- Semikolons werden hauptsächlich verwendet, um das Ende einer Anweisung zu markieren. Dies hilft der JavaScript-Engine, die Trennung einzelner Anweisungen zu verstehen, was für die korrekte Ausführung entscheidend ist.

- Semikolons helfen, Mehrdeutigkeiten bei der Codeausführung zu vermeiden und stellen sicher, dass Anweisungen korrekt beendet werden.

## Kommentare in JavaScript

- Jede auskommentierte Codezeile wird von der JavaScript-Engine ignoriert. Kommentare werden verwendet, um Code zu erklären, Notizen zu machen oder Code vorübergehend zu deaktivieren.
- Einzeilige Kommentare werden mit `//` erstellt.

- Mehrzeilige Kommentare werden mit `/*` begonnen und mit `*/` beendet.

## JavaScript als dynamisch typisierte Sprache

- JavaScript ist eine dynamisch typisierte Sprache, was bedeutet, dass Sie den Datentyp einer Variablen bei der Deklaration nicht angeben müssen. Die JavaScript-Engine bestimmt den Datentyp automatisch basierend auf dem Wert, der der Variablen zugewiesen wird.

- In statisch typisierten Sprachen wie C# führt das Zuweisen eines Strings an eine Ganzzahlvariable zu einem Fehler.

## Verwendung des `typeof`-Operators

- Der `typeof`-Operator wird verwendet, um den Datentyp einer Variablen zu überprüfen. Er gibt einen String zurück, der den Typ der Variablen angibt.

- Es gibt jedoch eine bekannte Eigenheit in JavaScript bei `null`. Der `typeof`-Operator gibt für `"object"` bei `null`-Werten zurück.

## ASCII, die `charCodeAt()`-Methode und die `fromCharCode()`-Methode

- **ASCII**: ASCII (American Standard Code for Information Interchange) ist ein Zeichencodierungsstandard, der verwendet wird, um grundlegende englische Zeichen mit numerischen Werten darzustellen. Frühere Lektionen führen `charCodeAt()` und `fromCharCode()` anhand von ASCII-Beispielen ein.
- **Unicode**: JavaScript-Strings verwenden intern Unicode, speziell die UTF-16-Codierung. Für die ersten 128 Zeichen (Grundlateinische Buchstaben, Ziffern und gängige Symbole) stimmen die Unicode-Werte mit den ASCII-Codes überein. Deshalb funktionieren ASCII-basierte Beispiele weiterhin in JavaScript.
- **Die `charCodeAt()`-Methode**: Diese Methode gibt die UTF-16-Code-Einheit des Zeichens an einem bestimmten Index zurück. Für grundlegende lateinische Zeichen entspricht dieser Wert dem ASCII-Code.

- **Die `fromCharCode()`-Methode**: Diese Methode wandelt einen ASCII-Code in das entsprechende Zeichen um.

## Weitere häufige String-Methoden

- **Die `indexOf`-Methode**: Diese Methode wird verwendet, um nach einem Teilstring innerhalb eines Strings zu suchen. Wenn der Teilstring gefunden wird, gibt `indexOf` den Index (oder die Position) des ersten Vorkommens dieses Teilstrings zurück. Wenn der Teilstring nicht gefunden wird, gibt `indexOf` -1 zurück, was anzeigt, dass die Suche erfolglos war.

- **Die `includes()`-Methode**: Diese Methode wird verwendet, um zu überprüfen, ob ein String einen bestimmten Teilstring enthält. Wenn der Teilstring im String gefunden wird, gibt die Methode true zurück. Andernfalls gibt sie false zurück.

- **Die `slice()`-Methode**: Diese Methode extrahiert einen Teil eines Strings und gibt einen neuen String zurück, ohne den ursprünglichen String zu verändern. Sie nimmt zwei Parameter: den Startindex und den optionalen Endindex.

- **Die `toUpperCase()`-Methode**: Diese Methode wandelt alle Zeichen in Großbuchstaben um und gibt einen neuen String mit allen Großbuchstaben zurück.

- **Die `toLowerCase()`-Methode**: Diese Methode wandelt alle Zeichen in einem String in Kleinbuchstaben um.

- **Die `replace()`-Methode**: Diese Methode ermöglicht es Ihnen, einen angegebenen Wert (wie ein Wort oder Zeichen) in einem String zu finden und durch einen anderen Wert zu ersetzen. Die Methode gibt einen neuen String mit der Ersetzung zurück und lässt den ursprünglichen String unverändert, da JavaScript-Strings unveränderlich sind.

- **Die `replaceAll()`-Methode**: Diese Methode ermöglicht es Ihnen, alle Vorkommen eines bestimmten Werts (eines Wortes, Zeichens oder Musters) in einem String zu finden und durch einen anderen Wert zu ersetzen. Sie funktioniert wie `replace()`, aber anstatt nach dem ersten Treffer zu stoppen, aktualisiert sie jeden gefundenen Treffer im String.

- **Die `repeat()`-Methode**: Diese Methode wird verwendet, um einen String eine bestimmte Anzahl von Malen zu wiederholen.

- **Die `trim()`-Methode**: Diese Methode wird verwendet, um Leerzeichen sowohl am Anfang als auch am Ende eines Strings zu entfernen.

- **Die `trimStart()`-Methode**: Diese Methode entfernt Leerzeichen vom Anfang (oder „Start“) des Strings.

- **Die `trimEnd()`-Methode**: Diese Methode entfernt Leerzeichen vom Ende des Strings.

- **Die `prompt()`-Methode**: Diese Methode des `window` wird verwendet, um Informationen von einem Benutzer über ein Dialogfeld zu erhalten. Diese Methode nimmt zwei Argumente entgegen. Das erste Argument ist die Nachricht, die im Dialogfeld angezeigt wird und typischerweise den Benutzer auffordert, Informationen einzugeben. Das zweite Argument ist ein Standardwert, der optional ist und das Eingabefeld initial ausfüllt.

## Arbeiten mit dem Datentyp Number

- **Definition**: Der `Number`-Typ in JavaScript umfasst ganze Zahlen, Gleitkommazahlen, `Infinity` und `NaN`. Gleitkommazahlen sind Zahlen mit Dezimalpunkt. Positives `Infinity` ist eine Zahl, die größer ist als jede andere Zahl, während `-Infinity` eine Zahl ist, die kleiner ist als jede andere Zahl. `NaN` (`Not a Number`) repräsentiert einen ungültigen numerischen Wert wie den String `"Jessica"`.

## Häufige arithmetische Operationen

- **Additionsoperator**: Dieser Operator (`+`) wird verwendet, um die Summe von zwei oder mehr Zahlen zu berechnen. 
- **Subtraktionsoperator**: Dieser Operator (`-`) wird verwendet, um die Differenz zwischen zwei Zahlen zu berechnen.
- **Multiplikationsoperator**: Dieser Operator (`*`) wird verwendet, um das Produkt von zwei oder mehr Zahlen zu berechnen. 
- **Divisionsoperator**: Dieser Operator (`/`) wird verwendet, um den Quotienten zwischen zwei Zahlen zu berechnen.
- **Division durch Null**: Wenn Sie versuchen, durch Null zu dividieren, gibt JavaScript `Infinity` zurück.
- **Restoperator**: Dieser Operator (`%`) gibt den Rest einer Division zurück. 
- **Exponentiationsoperator**: Dieser Operator (`**`) potenziert eine Zahl mit einer anderen.

## Berechnungen mit Zahlen und Strings

- **Erklärung**: Wenn Sie den `+` Operator mit einer Zahl und einem String verwenden, wandelt JavaScript die Zahl in einen String um und verknüpft die beiden Werte. Wenn Sie die Operatoren `-`, `*` oder `/` mit einem String und einer Zahl verwenden, wandelt JavaScript den String in eine Zahl um, und das Ergebnis ist eine Zahl. Für `null` und `undefined` behandelt JavaScript `null` als 0 und `undefined` als `NaN` bei mathematischen Operationen.

## Operatorpriorität

- **Definition**: Die Operatorpriorität bestimmt die Reihenfolge, in der Operationen in einem Ausdruck ausgewertet werden. Operatoren mit höherer Priorität werden vor denen mit niedrigerer Priorität ausgewertet. Werte in Klammern werden zuerst ausgewertet, und Multiplikation/Division hat eine höhere Priorität als Addition/Subtraktion. Haben die Operatoren die gleiche Priorität, verwendet JavaScript die Assoziativität.

- **Definition**: Die Assoziativität gibt an, in welcher Richtung ein Ausdruck ausgewertet wird, wenn mehrere Operatoren desselben Typs vorhanden sind. Sie definiert, ob der Ausdruck von links nach rechts (`left-associative`) oder von rechts nach links (`right-associative`) ausgewertet werden soll. Zum Beispiel ist der Exponentenoperator ebenfalls rechts-assoziativ.

## Inkrement- und Dekrementoperatoren

- **Inkrementoperator**: Dieser Operator wird verwendet, um den Wert um eins zu erhöhen. Die Präfixnotation `++num` erhöht zuerst den Wert der Variablen und gibt dann den neuen Wert zurück. Die Postfixnotation `num++` gibt zuerst den aktuellen Wert der Variablen zurück und erhöht ihn dann.

- **Dekrementoperator**: Dieser Operator wird verwendet, um den Wert um eins zu verringern. Die Präfix- und Postfixnotation funktionieren genauso wie beim Inkrementoperator.

## Zusammengesetzte Zuweisungsoperatoren

- **Additionszuweisungsoperator (`+=`)**: Dieser Operator führt eine Addition der Werte durch und weist das Ergebnis der Variablen zu.
- **Subtraktionszuweisungsoperator (`-=`)**: Dieser Operator führt eine Subtraktion der Werte durch und weist das Ergebnis der Variablen zu.
- **Multiplikationszuweisungsoperator (`*=`)**: Dieser Operator führt eine Multiplikation der Werte durch und weist das Ergebnis der Variablen zu.
- **Divisionszuweisungsoperator (`/=`)**: Dieser Operator führt eine Division der Werte durch und weist das Ergebnis der Variablen zu.
- **Restzuweisungsoperator (`%=`)**: Dieser Operator dividiert eine Variable durch die angegebene Zahl und weist den Rest der Variablen zu.
- **Exponentationszuweisungsoperator (`**=`)**: Dieser Operator hebt eine Variable auf die Potenz der angegebenen Zahl und weist das Ergebnis der Variablen erneut zu.

## Booleans und Gleichheit

- **Boolean-Definition**: Ein Boolean ist ein Datentyp, der nur zwei Werte haben kann: `true` oder `false`.
- **Gleichheitsoperator (`==`)**: Dieser Operator verwendet Typumwandlung, bevor geprüft wird, ob die Werte gleich sind.

- **Strenger Gleichheitsoperator (`===`)**: Dieser Operator führt keine Typumwandlung durch und prüft, ob sowohl die Typen als auch die Werte gleich sind.

- **Ungleichheitsoperator (`!=`)**: Dieser Operator verwendet Typumwandlung, bevor geprüft wird, ob die Werte ungleich sind.
- **Strikter Ungleichheitsoperator (`!==`)**: Dieser Operator führt keine Typumwandlung durch und prüft, ob sowohl Typ als auch Wert ungleich sind.

## Vergleichsoperatoren

- **Größer-als-Operator (`>`)**: Dieser Operator prüft, ob der Wert links größer ist als der Wert rechts.
- **Größer-als-oder-gleich-Operator (`>=`)**: Dieser Operator prüft, ob der Wert links größer oder gleich dem Wert rechts ist.
- **Kleiner-als-Operator (`<`)**: Dieser Operator prüft, ob der Wert links kleiner ist als der Wert rechts.
- **Kleiner-als-oder-gleich-Operator (`<=`)**: Dieser Operator prüft, ob der Wert links kleiner oder gleich dem Wert rechts ist.

## Unäre Operatoren

- **Unärer Plus-Operator**: Dieser Operator wandelt seinen Operanden in eine Zahl um. Wenn der Operand bereits eine Zahl ist, bleibt er unverändert.

- **Unärer Negationsoperator (`-`)**: Dieser Operator negiert den Operanden.

- **Logischer NICHT-Operator (`!`)**: Dieser Operator kehrt den Boolean-Wert seines Operanden um. Wenn der Operand `true` ist, wird er zu `false`, und wenn er `false` ist, wird er zu `true`.

## Bitweise Operatoren

- **Bitweises UND (`&`)**: Dieser Operator gibt an jeder Bitposition eine 1 zurück, für die die entsprechenden Bits beider Operanden 1 sind.
- **Bitweises UND-Zuweisungsoperator (`&=`)**: Dieser Operator führt eine `bitwise AND`-Operation mit der angegebenen Zahl aus und weist das Ergebnis der Variablen zu.
- **Bitweises ODER (`|`)**: Dieser Operator gibt an jeder Bitposition eine 1 zurück, für die die entsprechenden Bits eines oder beider Operanden 1 sind.
- **Bitweises ODER-Zuweisungsoperator (`|=`)**: Dieser Operator führt eine `bitwise OR`-Operation mit der angegebenen Zahl aus und weist das Ergebnis der Variablen zu.
- **Bitweises XOR (`^`)**: Dieser Operator gibt an jeder Bitposition eine 1 zurück, für die die entsprechenden Bits entweder des einen oder des anderen, aber nicht beider Operanden 1 sind.
- **Bitweises NICHT (`~`)**: Dieser Operator invertiert die binäre Darstellung einer Zahl.
- **Linksverschiebungsoperator (`<<`)**: Dieser Operator verschiebt alle Bits um eine angegebene Anzahl von Positionen nach links.
- **Rechtsverschiebungsoperator (`>>`)**: Dieser Operator verschiebt alle Bits nach rechts.

## Bedingte Anweisungen, truthy-Werte, falsy-Werte und der ternäre Operator

- **`if/else if/else`**: Eine `if`-Anweisung nimmt eine Bedingung und führt einen Codeblock aus, wenn diese Bedingung `truthy` ist. Wenn die Bedingung `false` ist, wird der `else if`-Block ausgeführt. Wenn keine dieser Bedingungen `true` ist, wird die `else`-Klausel ausgeführt. `Truthy`-Werte sind alle Werte, die in einem Boolean-Kontext wie einer `true`-Anweisung zu `if` ausgewertet werden. `Falsy`-Werte sind Werte, die in einem Boolean-Kontext zu `false` ausgewertet werden.

:::interactive_editor

```js
const score = 87;

if (score >= 90) {
 console.log('You got an A'); 
} else if (score >= 80) {
 console.log('You got a B'); // You got a B
} else if (score >= 70) {
 console.log('You got a C');
} else {
 console.log('You failed! You need to study more!');
}
```

:::

- **Ternärer Operator**: Dieser Operator wird oft als kürzere Schreibweise für `if else`-Anweisungen verwendet.

:::interactive_editor

```js
const temperature = 30;
const weather = temperature > 25 ? 'sunny' : 'cool';

console.log(`It's a ${weather} day!`); // It's a sunny day!
```

:::

## Binäre logische Operatoren

- **Logisches UND (`&&`)**: Dieser Operator prüft, ob beide Operanden `true` sind. Sind beide `true`, gibt er den zweiten Wert zurück. Ist einer der Operanden `falsy`, gibt er den `falsy`-Wert zurück. Sind beide Operanden `falsy`, gibt er den ersten `falsy`-Wert zurück.

- **Logisches ODER (`||`)**: Dieser Operator prüft, ob mindestens einer der Operanden truthy ist.
- **Nullish Coalescing (`??`)**: Dieser Operator gibt einen Wert nur zurück, wenn der erste `null` oder `undefined` ist.

## Häufige Methoden für Zahlen

- **`isNaN()`**: `NaN` steht für "Not-a-Number". Es ist ein spezieller Wert, der ein nicht darstellbares oder undefiniertes numerisches Ergebnis repräsentiert. Die Eigenschaft `isNaN()` einer Funktion wird verwendet, um zu bestimmen, ob ein Wert `NaN` ist oder nicht. `Number.isNaN()` bietet eine zuverlässigere Möglichkeit, auf `NaN`-Werte zu prüfen, insbesondere in Fällen, in denen Typumwandlungen zu unerwarteten Ergebnissen mit der globalen `isNaN()`-Funktion führen können.

- **Die `parseFloat()`-Methode**: Diese Methode parst ein String-Argument und gibt eine Fließkommazahl zurück. Sie ist dafür ausgelegt, eine Zahl vom Anfang eines Strings zu extrahieren, selbst wenn der String später nicht-numerische Zeichen enthält.
- **Die `parseInt()`-Methode**: Diese Methode parst ein String-Argument und gibt eine Ganzzahl zurück. `parseInt()` stoppt das Parsen beim ersten nicht-ziffern Zeichen. Bei Fließkommazahlen gibt sie nur den ganzzahligen Teil zurück. Wenn am Anfang des Strings keine gültige Ganzzahl gefunden wird, gibt sie `NaN` zurück.
- **Die `toFixed()`-Methode**: Diese Methode wird auf eine Zahl aufgerufen und nimmt ein optionales Argument entgegen, das die Anzahl der Nachkommastellen angibt. Sie gibt eine String-Darstellung der Zahl mit der angegebenen Anzahl Dezimalstellen zurück.

## Vergleiche und die Datentypen `null` und `undefined`

- **Vergleiche und `undefined`**: Eine Variable ist `undefined`, wenn sie deklariert wurde, aber noch kein Wert zugewiesen wurde. Es ist der Standardwert für nicht initialisierte Variablen und Funktionsparameter, denen kein Argument übergeben wurde. `undefined` wird in numerischen Kontexten zu `NaN`, was dazu führt, dass alle numerischen Vergleiche mit `undefined` `false` zurückgeben.

- **Vergleiche und `null`**: Der Typ `null` steht für das absichtliche Fehlen eines Werts. `null` wird in numerischen Kontexten zu `0` konvertiert, was zu unerwartetem Verhalten bei numerischen Vergleichen führen kann. Zum Beispiel ist `null >= 0` `true`, aber `null > 0` ist `false`.

- Beim Verwenden des Gleichheitsoperators (`==`) sind `null` und `undefined` nur gleich sich selbst und einander.

- Beim Verwenden des strikten Gleichheitsoperators (`===`), der sowohl Wert als auch Typ ohne Typumwandlung prüft, sind `null` und `undefined` nicht gleich.

## `switch`-Anweisungen

- **Definition**: Eine `switch` Anweisung wertet einen Ausdruck aus und vergleicht dessen Wert mit einer Reihe von `case` Klauseln. Wenn eine Übereinstimmung gefunden wird, wird der mit diesem Fall verknüpfte Codeblock ausgeführt. Eine `break` Anweisung sollte am Ende jedes Falls stehen, um dessen Ausführung zu beenden und mit dem nächsten fortzufahren. Der `default` Fall ist ein optionaler Fall und wird nur ausgeführt, wenn keiner der anderen Fälle zutrifft. Der `default` Fall steht am Ende einer `switch` Anweisung.

:::interactive_editor

```js
const dayOfWeek = 3; 

switch (dayOfWeek) {
  case 1:
    console.log("It's Monday! Time to start the week strong.");
    break;
  case 2:
    console.log("It's Tuesday! Keep the momentum going.");
    break;
  case 3:
    console.log("It's Wednesday! We're halfway there.");
    break;
  case 4:
    console.log("It's Thursday! Almost the weekend.");
    break;
  case 5:
    console.log("It's Friday! The weekend is near.");
    break;
  case 6:
    console.log("It's Saturday! Enjoy your weekend.");
    break;
  case 7:
    console.log("It's Sunday! Rest and recharge.");
    break;
  default:
    console.log("Invalid day! Please enter a number between 1 and 7.");
}
```

:::

## JavaScript-Funktionen

- Funktionen sind wiederverwendbare Codeblöcke, die eine bestimmte Aufgabe ausführen.
- Funktionen können mit dem `function`-Schlüsselwort definiert werden, gefolgt von einem Namen, einer Liste von Parametern und einem Codeblock, der die Aufgabe ausführt.

:::interactive_editor

```js
function addNumbers(x, y, z) {
  return x + y + z;
}

console.log(addNumbers(5, 3, 8)); // Output: 16
```

:::

- Argumente sind Werte, die an eine Funktion übergeben werden, wenn sie aufgerufen wird.
- Ein Funktionsaufruf ist der Vorgang, eine Funktion in einem Programm auszuführen, indem der Name der Funktion gefolgt von runden Klammern angegeben wird, optional mit Argumenten innerhalb der Klammern.
- Wenn eine Funktion ihre Ausführung beendet, gibt sie immer einen Wert zurück.
- Standardmäßig ist der Rückgabewert einer Funktion `undefined`.
- Das `return`-Schlüsselwort wird verwendet, um den Wert anzugeben, der von der Funktion zurückgegeben wird, und beendet die Ausführung der Funktion.
- Standardparameter ermöglichen es Funktionen, vordefinierte Werte zu haben, die verwendet werden, wenn beim Aufruf der Funktion kein Argument übergeben wird. Das macht Funktionen flexibler und verhindert Fehler in Fällen, in denen bestimmte Argumente weggelassen werden könnten.

:::interactive_editor

```js
const calculateTotal = (amount, taxRate = 0.05) => {
  return amount + (amount * taxRate);
};

console.log(calculateTotal(100)); // Output: 105
```

:::

- Anonyme Funktionen sind Funktionen ohne Namen, die Variablen zugewiesen werden können. Durch die Zuweisung an Variablen können Sie sie überall dort wiederverwenden, wo die Variable zugänglich ist.

:::interactive_editor

```js
const multiplyNumbers = function(firstNumber, secondNumber) {
  return firstNumber * secondNumber;
};

console.log(multiplyNumbers(4, 5)); // Output: 20
```

:::

## Pfeilfunktionen

- Pfeilfunktionen sind eine prägnantere Art, Funktionen in JavaScript zu schreiben.

- Beim Definieren einer Pfeilfunktion benötigen Sie nicht das `function`-Schlüsselwort.
- Wenn Sie nur einen Parameter verwenden, können Sie die runden Klammern um die Parameterliste weglassen.

- Wenn der Funktionskörper aus einem einzigen Ausdruck besteht, können Sie die geschweiften Klammern und das `return`-Schlüsselwort weglassen.

:::interactive_editor

```js
const square = number => number * number;

console.log(square(5)); // Output: 25
```

:::

## Gültigkeitsbereich (Scope) in der Programmierung

- **Globaler Gültigkeitsbereich**: Dies ist der äußerste Gültigkeitsbereich in JavaScript. Variablen, die im globalen Gültigkeitsbereich deklariert sind, sind von überall im Code zugänglich und werden globale Variablen genannt.
- **Lokaler Gültigkeitsbereich**: Dies bezieht sich auf Variablen, die innerhalb einer Funktion deklariert sind. Diese Variablen sind nur innerhalb der Funktion zugänglich, in der sie deklariert wurden, und werden lokale Variablen genannt.
- **Block-Gültigkeitsbereich**: Ein Block ist eine Gruppe von Anweisungen, die in geschweifte Klammern `{}` eingeschlossen sind, wie zum Beispiel in `if`-Anweisungen oder Schleifen.
- Die Block-Gültigkeitsbereiche mit `let` und `const` bieten noch feinere Kontrolle über die Zugänglichkeit von Variablen, helfen Fehler zu vermeiden und machen Ihren Code vorhersehbarer.

## Grundlagen zu JavaScript-Arrays

- **Definition**: Ein JavaScript-Array ist eine geordnete Sammlung von Werten, die jeweils durch einen numerischen Index identifiziert werden. Die Werte in einem JavaScript-Array können unterschiedliche Datentypen haben, darunter Zahlen, Strings, Booleans, Objekte und sogar andere Arrays. Arrays sind im Speicher zusammenhängend, was bedeutet, dass alle Elemente in einem einzigen, kontinuierlichen Speicherblock gespeichert sind. Das ermöglicht effizientes Indizieren und schnellen Zugriff auf Elemente anhand ihres Index.

- **Zugriff auf Elemente in Arrays**: Um auf Elemente eines Arrays zuzugreifen, müssen Sie das Array gefolgt von seiner Indexnummer in eckigen Klammern angeben. JavaScript-Arrays sind nullbasiert indiziert, das heißt, das erste Element hat den Index 0, das zweite den Index 1 usw. Wenn Sie versuchen, auf einen Index zuzugreifen, der im Array nicht existiert, gibt JavaScript `undefined` zurück.

- **`length`-Eigenschaft**: Diese Eigenschaft wird verwendet, um die Anzahl der Elemente in einem Array zurückzugeben.

- **Elemente in einem Array aktualisieren**: Um ein Element in einem Array zu aktualisieren, verwenden Sie den Zuweisungsoperator (`=`), um dem Element an einem bestimmten Index einen neuen Wert zuzuweisen.

## Zweidimensionale Arrays

- **Definition**: Ein zweidimensionales Array ist im Grunde ein Array von Arrays. Es wird verwendet, um Daten darzustellen, die eine natürliche rasterartige Struktur haben, wie ein Schachbrett, eine Tabelle oder Pixel in einem Bild. Um auf ein Element in einem zweidimensionalen Array zuzugreifen, benötigen Sie zwei Indizes: einen für die Zeile und einen für die Spalte.

## Array-Destrukturierung

- **Definition**: Die Array-Destrukturierung ist eine Funktion in JavaScript, mit der Sie Werte aus Arrays extrahieren und auf eine prägnantere und lesbarere Weise Variablen zuweisen können. Sie bietet eine bequeme Syntax, um Array-Elemente in einzelne Variablen zu entpacken.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange"];

const [first, second, third] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(third); // "orange"
```

:::

- **Rest-Syntax**: Diese ermöglicht es Ihnen, die verbleibenden Elemente eines Arrays, die nicht destrukturiert wurden, in einem neuen Array zu erfassen.

:::interactive_editor

```js
const fruits = ["apple", "banana", "orange", "mango", "kiwi"];
const [first, second, ...rest] = fruits;

console.log(first); // "apple"
console.log(second); // "banana"
console.log(rest); // ["orange", "mango", "kiwi"]
```

:::

## Häufige Array-Methoden

- **`push()`-Methode**: Diese Methode wird verwendet, um Elemente am Ende des Arrays hinzuzufügen und gibt die neue Länge zurück.

- **`pop()`-Methode**: Diese Methode wird verwendet, um das letzte Element aus einem Array zu entfernen und gibt dieses entfernte Element zurück. Wenn das Array leer ist, ist der Rückgabewert `undefined`.

- **`shift()`-Methode**: Diese Methode wird verwendet, um das erste Element aus einem Array zu entfernen und gibt dieses entfernte Element zurück. Wenn das Array leer ist, ist der Rückgabewert `undefined`.

- **`unshift()`-Methode**: Diese Methode wird verwendet, um Elemente am Anfang des Arrays hinzuzufügen und gibt die neue Länge zurück.

- **`indexOf()`-Methode**: Diese Methode ist nützlich, um den ersten Index eines bestimmten Elements innerhalb eines Arrays zu finden. Wenn das Element nicht gefunden wird, gibt sie `-1` zurück.

- **`splice()`-Methode**: Diese Methode wird verwendet, um Elemente an beliebiger Stelle in einem Array hinzuzufügen oder zu entfernen. Der Rückgabewert der `splice()`-Methode ist ein Array der aus dem Array entfernten Elemente. Wenn nichts entfernt wird, wird ein leeres Array zurückgegeben. Diese Methode verändert das ursprüngliche Array, indem sie es an Ort und Stelle modifiziert, anstatt ein neues Array zu erstellen. Das erste Argument gibt den Index an, an dem die Modifikation beginnt. Das zweite Argument ist die Anzahl der Elemente, die entfernt werden sollen. Die folgenden Argumente sind die Elemente, die hinzugefügt werden sollen.

- **`includes()`-Methode**: Diese Methode wird verwendet, um zu prüfen, ob ein Array einen bestimmten Wert enthält. Diese Methode gibt `true` zurück, wenn das Array das angegebene Element enthält, und `false` sonst.

- **`concat()`-Methode**: Diese Methode erstellt ein neues Array, indem zwei oder mehr Arrays zusammengeführt werden.

- **`slice()`-Methode**: Diese Methode gibt ein neues Array zurück, das eine flache Kopie eines Abschnitts des ursprünglichen Arrays enthält, definiert durch Start- und Endindizes. Das neue Array enthält Referenzen auf dieselben Elemente wie das ursprüngliche Array (keine Duplikate). Das bedeutet, wenn die Elemente primitive Werte (wie Zahlen oder Strings) sind, werden die Werte kopiert; wenn die Elemente Objekte oder Arrays sind, werden die Referenzen kopiert, nicht die Objekte selbst.

- **Spread-Syntax**: Die Spread-Syntax wird verwendet, um flache Kopien eines Arrays zu erstellen.

:::interactive_editor

```js
const originalArray = [1, 2, 3];
const shallowCopiedArray = [...originalArray];

shallowCopiedArray.push(4);

console.log(originalArray); // [1, 2, 3]
console.log(shallowCopiedArray); // [1, 2, 3, 4]
```

:::

- **`split()`-Methode**: Diese Methode teilt einen String in ein Array von Teilstrings auf und gibt an, wo jede Teilung basierend auf einem angegebenen Trennzeichen erfolgen soll. Wenn kein Trennzeichen angegeben ist, gibt die Methode ein Array zurück, das den ursprünglichen String als einzelnes Element enthält.

- **`reverse()`-Methode**: Diese Methode kehrt ein Array an Ort und Stelle um.

- **`join()`-Methode**: Diese Methode verbindet alle Elemente eines Arrays zu einem einzigen String, wobei jedes Element durch ein angegebenes Trennzeichen getrennt wird. Wenn kein Trennzeichen angegeben ist oder ein leerer String (`""`) verwendet wird, werden die Elemente ohne Trennzeichen verbunden.

## Grundlagen zu Objekten

- **Definition**: Ein Objekt ist eine Datenstruktur, die aus Eigenschaften besteht. Eine Eigenschaft besteht aus einem Schlüssel und einem Wert. Um Daten aus einem Objekt zuzugreifen, können Sie entweder die Punktnotation oder die Klammernotation verwenden.

:::interactive_editor

```js
const person = {
  name: "Alice",
  age: 30,
  city: "New York"
};

console.log(person.name);  // Alice
console.log(person["name"]); // Alice
```

:::

Um eine Eigenschaft eines bestehenden Objekts zu setzen, können Sie entweder die Punktnotation oder die Klammernotation zusammen mit dem Zuweisungsoperator verwenden.

## Entfernen von Eigenschaften aus einem Objekt

- **`delete`-Operator**: Dieser Operator wird verwendet, um eine Eigenschaft aus einem Objekt zu entfernen.

## Prüfen, ob ein Objekt eine Eigenschaft hat

- **`hasOwnProperty()`-Methode**: Diese Methode gibt einen Boolean zurück, der angibt, ob das Objekt die angegebene Eigenschaft als eigene Eigenschaft besitzt.

- **`Object.hasOwn()`-Methode**: Dies ist die moderne, empfohlene Methode, um zu prüfen, ob ein Objekt eine Eigenschaft als eigene (nicht geerbte) besitzt. Die Syntax lautet `Object.hasOwn(object, propertyName)`. Sie gibt `true` zurück, wenn die Eigenschaft im Objekt existiert, und `false`, wenn nicht, unabhängig vom Wert der Eigenschaft. Dadurch ist sie sicherer als `hasOwnProperty()` und zuverlässiger als `if (obj.prop)`, wenn Werte `0`, `false`, `null` oder `undefined` sein können.

`Object.hasOwn()` erkennt eine eigene Eigenschaft auch dann, wenn ihr Wert falsch ist, wie `0`, `false` oder `undefined`.

- **`in`-Operator**: Dieser Operator gibt `true` zurück, wenn die Eigenschaft im Objekt existiert.

## Zugriff auf Eigenschaften aus verschachtelten Objekten

- **Datenzugriff**: Der Zugriff auf Eigenschaften aus verschachtelten Objekten erfolgt ähnlich wie bei einfachen Objekten mit Punkt- oder Klammernotation. Allerdings müssen Sie diese Zugriffe verketten, um in die verschachtelte Struktur hineinzudringen.

## Primitive und nicht primitive Datentypen

- **Primitive Datentypen**: Diese Datentypen umfassen Zahlen, Strings, Booleans, `null`, `undefined` und Symbole. Diese Typen werden "primitiv" genannt, weil sie einzelne Werte repräsentieren und keine Objekte sind. Primitive Werte sind unveränderlich, das heißt, sobald sie erstellt sind, kann ihr Wert nicht geändert werden.
- **Nicht primitive Datentypen**: In JavaScript sind dies Objekte, zu denen reguläre Objekte, Arrays und Funktionen gehören. Im Gegensatz zu Primitiven können nicht primitive Typen mehrere Werte als Eigenschaften oder Elemente enthalten.

## Methoden von Objekten

- **Definition**: Objektmethoden sind Funktionen, die mit einem Objekt verknüpft sind. Sie werden als Eigenschaften eines Objekts definiert und können auf die Daten des Objekts zugreifen und diese manipulieren. Das Schlüsselwort `this` innerhalb der Methode bezieht sich auf das Objekt selbst und ermöglicht den Zugriff auf dessen Eigenschaften.

## Objekt-Konstruktor

- **Definition**: In JavaScript ist ein Konstruktor eine spezielle Art von Funktion, die verwendet wird, um Objekte zu erstellen und zu initialisieren. Er wird mit dem Schlüsselwort `new` aufgerufen und kann Eigenschaften und Methoden auf dem neu erstellten Objekt initialisieren. Der `Object()`-Konstruktor erstellt ein neues leeres Objekt.

## Arbeiten mit dem optionalen Verkettungsoperator (`?.`)

- **Definition**: Dieser Operator ermöglicht es Ihnen, sicher auf Objekteigenschaften zuzugreifen oder Methoden aufzurufen, ohne sich Sorgen machen zu müssen, ob sie existieren.

:::interactive_editor

```ts
const user = {
  name: "John",
  profile: {
    email: "john@example.com",
    address: {
      street: "123 Main St",
      city: "Somewhere"
    }
  }
};

console.log(user.profile?.address?.street); // "123 Main St"
console.log(user.profile?.phone?.number);   // undefined
```

:::

## Objekt-Destrukturierung

- **Definition**: Die Objekt-Destrukturierung ermöglicht es Ihnen, Werte aus Objekten zu extrahieren und auf eine prägnantere und lesbarere Weise Variablen zuzuweisen.

:::interactive_editor

```js
const person = { name: "Alice", age: 30, city: "New York" };

const { name, age } = person;

console.log(name); // Alice
console.log(age);  // 30
```

:::

## Arbeiten mit JSON

- **Definition**: JSON steht für JavaScript Object Notation. Es ist ein leichtgewichtiges, textbasiertes Datenformat, das häufig zum Austausch von Daten zwischen einem Server und einer Webanwendung verwendet wird.

- **`JSON.stringify()`**: Diese Methode wird verwendet, um ein JavaScript-Objekt in einen JSON-String zu konvertieren. Das ist nützlich, wenn Sie Daten in einem Format speichern oder übertragen möchten, das leicht zwischen Systemen geteilt oder übertragen werden kann.

- **`JSON.parse()`**: Diese Methode konvertiert einen JSON-String zurück in ein JavaScript-Objekt. Das ist nützlich, wenn Sie JSON-Daten von einem Webserver oder localStorage abrufen und die Daten in Ihrer Anwendung verarbeiten müssen.

## Arbeiten mit Schleifen

- **`for`-Schleife**: Diese Art von Schleife wird verwendet, um einen Codeblock eine bestimmte Anzahl von Malen zu wiederholen. Diese Schleife ist in drei Teile unterteilt: die Initialisierungsanweisung, die Bedingung und die Inkrement-/Dekrement-Anweisung. Die Initialisierungsanweisung wird vor Beginn der Schleife ausgeführt. Sie wird typischerweise verwendet, um eine Zählervariable zu initialisieren. Die Bedingung wird vor jeder Iteration der Schleife ausgewertet. Eine Iteration ist ein einzelner Durchlauf durch die Schleife. Wenn die Bedingung `true` ist, wird der Codeblock innerhalb der Schleife ausgeführt. Wenn die Bedingung `false` ist, stoppt die Schleife und Sie fahren mit dem nächsten Codeblock fort. Die Inkrement-/Dekrement-Anweisung wird nach jeder Iteration ausgeführt. Sie wird typischerweise verwendet, um die Zählervariable zu erhöhen oder zu verringern.

:::interactive_editor

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

:::

- **`for...of`-Schleife**: Diese Art von Schleife wird verwendet, wenn Sie über Werte aus einem iterierbaren Objekt iterieren müssen. Beispiele für Iterierbare sind Arrays und Strings.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];

for (const num of numbers) {
  console.log(num);
}
```

:::

- **`for...in`-Schleife**: Diese Art von Schleife eignet sich am besten, wenn Sie über die Eigenschaften eines Objekts iterieren müssen. Diese Schleife durchläuft alle aufzählbaren Eigenschaften eines Objekts, einschließlich geerbter Eigenschaften und nicht-numerischer Eigenschaften.

:::interactive_editor

```js
const fruit = {
  name: 'apple',
  color: 'red',
  price: 0.99
};

for (const prop in fruit) {
  console.log(fruit[prop]);
}
```

:::

- **`while`-Schleife**: Diese Art von Schleife führt einen Codeblock aus, solange die Bedingung `true` ist.

:::interactive_editor

```js
let i = 5;

while (i > 0) {
  console.log(i);
  i--;
}
```

:::

- **`do...while`-Schleife**: Diese Art von Schleife führt den Codeblock mindestens einmal aus, bevor die Bedingung geprüft wird.

```js
let userInput;

do {
  userInput = prompt("Please enter a number between 1 and 10");
} while (Number(userInput) < 1 || Number(userInput) > 10);

alert("You entered a valid number!");
```

## `break`- und `continue`-Anweisungen

- **Definition**: Eine `break`-Anweisung wird verwendet, um eine Schleife vorzeitig zu verlassen, während eine `continue`-Anweisung verwendet wird, um die aktuelle Iteration einer Schleife zu überspringen und mit der nächsten fortzufahren.

## String-Konstruktor und `toString()`-Methode

- **Definition**: Ein String-Objekt wird verwendet, um eine Folge von Zeichen darzustellen. String-Objekte werden mit der `String`-Konstrukturfunktion erstellt, die den primitiven Wert in einem Objekt kapselt.

- **`toString()`-Methode**: Diese Methode konvertiert einen Wert in seine String-Darstellung. Sie ist eine Methode, die Sie für Zahlen, Booleans, Arrays und Objekte verwenden können.

Diese Methode akzeptiert eine optionale Basis (radix), die eine Zahl von 2 bis 36 ist. Diese Basis repräsentiert das Zahlensystem, zum Beispiel Basis 2 für Binär oder Basis 8 für Oktal. Wenn die Basis nicht angegeben wird, ist standardmäßig Basis 10, also Dezimal, eingestellt.

## Number-Konstruktor

- **Definition**: Der `Number`-Konstruktor wird verwendet, um ein Number-Objekt zu erstellen. Das Number-Objekt enthält einige hilfreiche Eigenschaften und Methoden wie die `isNaN`- und `toFixed`-Methode. Meistens verwenden Sie den `Number`-Konstruktor, um andere Datentypen in den Number-Datentyp zu konvertieren.

## Bewährte Vorgehensweisen für die Benennung von Variablen und Funktionen

- **camelCasing**: Nach Konvention verwenden JavaScript-Entwickler camel casing für die Benennung von Variablen und Funktionen. Camel casing bedeutet, dass das erste Wort komplett in Kleinbuchstaben geschrieben wird und die folgenden Wörter mit einem Großbuchstaben beginnen. Zum Beispiel `isLoading`.

- **Benennung von Booleans**: Für Boolean-Variablen ist es üblich, Präfixe wie „is“, „has“ oder „can“ zu verwenden.

- **Benennung von Funktionen**: Der Name einer Funktion sollte klar angeben, was die Funktion tut. Für Funktionen, die einen Boolean zurückgeben (oft Prädikate genannt), können Sie dieselben Präfixe „is“, „has“ oder „can“ verwenden. Wenn Sie Funktionen haben, die Daten abrufen, ist es üblich, mit „get“ zu beginnen. Wenn Sie Funktionen haben, die Daten setzen, ist es üblich, mit „set“ zu beginnen. Für Event-Handler-Funktionen können Sie mit „handle“ voranstellen oder mit „Handler“ enden.

- **Benennung von Variablen in Schleifen**: Bei der Benennung von Iterator-Variablen in Schleifen ist es üblich, einzelne Buchstaben wie `i`, `j` oder `k` zu verwenden.

## Arbeiten mit lückenhaften Arrays

- **Definition**: Es ist möglich, Arrays mit leeren Slots zu haben. Leere Slots sind Slots, in denen nichts enthalten ist. Das unterscheidet sich von Array-Slots mit dem Wert `undefined`. Diese Arten von Arrays werden als lückenhafte Arrays bezeichnet.

## Linters und Formatierer

- **Linters**: Ein Linter ist ein statisches Code-Analyse-Tool, das Programmierfehler, Bugs, stilistische Fehler und verdächtige Konstrukte markiert. Ein Beispiel für einen gängigen Linter ist ESLint.
- **Formatierer**: Formatierer sind Werkzeuge, die Ihren Code automatisch formatieren, um einem bestimmten Styleguide zu entsprechen. Ein Beispiel für einen gängigen Formatierer ist Prettier.

## Speicherverwaltung

- **Definition**: Speicherverwaltung ist der Prozess der Kontrolle des Speichers, der Zuweisung bei Bedarf und der Freigabe, wenn er nicht mehr benötigt wird. JavaScript verwendet automatische Speicherverwaltung. Das bedeutet, dass JavaScript (genauer gesagt die JavaScript-Engine in Ihrem Webbrowser) die Speicherzuweisung und -freigabe für Sie übernimmt. Sie müssen den Speicher in Ihrem Code nicht explizit freigeben. Dieser automatische Prozess wird oft als „Garbage Collection“ bezeichnet.

## Closures

- **Definition**: Ein Closure ist eine Funktion, die Zugriff auf Variablen in ihrem äußeren (einschließenden) lexikalischen Gültigkeitsbereich hat, selbst nachdem die äußere Funktion zurückgegeben wurde.

:::interactive_editor

```js
function outerFunction(x) {
  let y = 10;
  function innerFunction() {
    console.log(x + y);
  }
  return innerFunction;
}

let closure = outerFunction(5);
closure(); // 15
```

:::

## `var`-Schlüsselwort und Hoisting

- **Definition**: `var` war die ursprüngliche Art, Variablen vor 2015 zu deklarieren. Aber es gab einige Probleme mit `var` bezüglich Gültigkeitsbereich, Neudeklaration und mehr. Deshalb verwendet die moderne JavaScript-Programmierung stattdessen `let` und `const`.
- **Neudeklaration von Variablen mit `var`**: Wenn Sie versuchen, eine Variable mit `let` neu zu deklarieren, erhalten Sie einen `SyntaxError`. Mit `var` ist die Neudeklaration einer Variable erlaubt.

- **`var` und Gültigkeitsbereich**: Variablen, die mit `var` innerhalb eines Blocks (wie einer `if`-Anweisung oder einer `for`-Schleife) deklariert werden, sind außerhalb dieses Blocks weiterhin zugänglich.

- **Hoisting**: Dies ist das Standardverhalten von JavaScript, Deklarationen während der Kompilierungsphase vor der Ausführung des Codes an den Anfang ihres jeweiligen Gültigkeitsbereichs zu verschieben. Wenn Sie eine Variable mit dem Schlüsselwort `var` deklarieren, hebt JavaScript die Deklaration an den Anfang ihres Gültigkeitsbereichs an.

Wenn Sie eine Funktion mit der Funktionsdeklarationssyntax deklarieren, werden sowohl der Funktionsname als auch der Funktionskörper gehoben. Das bedeutet, Sie können eine Funktion aufrufen, bevor Sie sie im Code deklariert haben.

Variablendeklarationen mit `let` oder `const` werden gehoben, aber sie sind nicht initialisiert, und Sie können nicht auf sie zugreifen, bevor die eigentliche Deklaration im Code steht. Dieses Verhalten wird oft als „temporale Dead Zone“ bezeichnet.

## Arbeiten mit Imports, Exports und Modulen

- **Modul**: Dies ist eine eigenständige Codeeinheit, die zusammengehörige Funktionen, Klassen oder Variablen kapselt. Um ein Modul zu erstellen, schreiben Sie Ihren JavaScript-Code in eine separate Datei.
- **Exports**: Alle Variablen, Funktionen oder Klassen, die Sie anderen Teilen Ihrer Anwendung verfügbar machen möchten, müssen explizit mit dem `export` Schlüsselwort exportiert werden. Es gibt zwei Arten von Exporten: benannter Export und Standardexport.
- **Imports**: Um die exportierten Elemente in einem anderen Teil Ihrer Anwendung zu verwenden, müssen Sie sie mit dem `import` Schlüsselwort importieren. Die Typen können benannter Import, Standardimport und Namespace-Import sein.

```js
// Within a file called math.js, we export the following functions:

// Named export
export function add(num1, num2) {
  return num1 + num2;
}

// Default export
export default function subtract(num1, num2) {
  return num1 - num2;
}

// Within another file, we can import the functions from math.js.

// Named import - This line imports the add function.
// The name of the function must exactly match the one exported from math.js.
import { add } from './math.js';

// Default import - This line imports the subtract function.
// The name of the function can be anything.
import subtractFunc from './math.js';

// Namespace import - This line imports everything from the file.
import * as Math from './math.js';

console.log(add(5, 3)); // 8
console.log(subtractFunc(5, 3)); // 2
console.log(Math.add(5, 3)); // 8
console.log(Math.subtract(5, 3)); // 2
```

## Callback-Funktionen und die `forEach` Methode

- **Definition**: In JavaScript ist eine Callback-Funktion eine Funktion, die als Argument an eine andere Funktion übergeben wird und nach Abschluss der Hauptfunktion ausgeführt wird.
- **`forEach()` Methode**: Diese Methode wird verwendet, um über jedes Element in einem Array zu iterieren und eine Operation auf jedem Element auszuführen. Die Callback-Funktion in `forEach` kann bis zu drei Argumente annehmen: das aktuelle Element, den Index des aktuellen Elements und das Array, auf dem `forEach` aufgerufen wurde.

## Higher-Order-Funktionen

- **Definition**: Eine Higher-Order-Funktion nimmt eine oder mehrere Funktionen als Argumente und gibt eine Funktion oder einen Wert als Ergebnis zurück.

- **`map()` Methode**: Diese Methode wird verwendet, um ein neues Array zu erstellen, indem eine gegebene Funktion auf jedes Element des ursprünglichen Arrays angewendet wird. Die Callback-Funktion kann bis zu drei Argumente annehmen: das aktuelle Element, den Index des aktuellen Elements und das Array, auf dem `map` aufgerufen wurde.

- **`filter()` Methode**: Diese Methode wird verwendet, um ein neues Array mit Elementen zu erstellen, die einen bestimmten Test bestehen, was sie nützlich macht, um Elemente selektiv basierend auf Kriterien zu extrahieren. Genau wie die `map` Methode akzeptiert die Callback-Funktion für die `filter` Methode dieselben drei Argumente: das aktuell verarbeitete Element, den Index und das Array.

- **`reduce()` Methode**: Diese Methode wird verwendet, um ein Array zu verarbeiten und es zu einem einzelnen Wert zu verdichten. Dieser einzelne Wert kann eine Zahl, ein String, ein Objekt oder sogar ein weiteres Array sein. Die `reduce()` Methode arbeitet, indem sie eine Funktion auf jedes Element im Array der Reihe nach anwendet und das Ergebnis jeder Berechnung an die nächste weitergibt. Diese Funktion wird oft als Reduzierfunktion bezeichnet. Die Reduzierfunktion nimmt zwei Hauptparameter: einen Akkumulator und den aktuellen Wert. Der Akkumulator speichert das laufende Ergebnis Ihrer Operationen, und der aktuelle Wert ist das gerade verarbeitete Array-Element.

:::interactive_editor

```js
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce(
  (accumulator, currentValue) => accumulator + currentValue,
  0
);

console.log(sum); // 15
```

:::

## Methodenverkettung

- **Definition**: Method Chaining ist eine Programmiertechnik, die es Ihnen erlaubt, mehrere Methoden auf demselben Objekt in einer einzigen Codezeile aufzurufen. Diese Technik kann Ihren Code lesbarer und prägnanter machen, besonders wenn Sie eine Reihe von Operationen auf demselben Objekt ausführen.

## Arbeiten mit der `sort` Methode

- **Definition**: Die `sort` Methode wird verwendet, um die Elemente eines Arrays zu sortieren und eine Referenz auf das sortierte Array zurückzugeben. Es wird keine Kopie erstellt, da die Elemente an Ort und Stelle sortiert werden.

Wenn Sie Zahlen sortieren müssen, müssen Sie eine Vergleichsfunktion übergeben. Die `sort`-Methode wandelt die Elemente in Strings um und vergleicht dann deren Folgen von UTF-16-Codeeinheiten. UTF-16-Codeeinheiten sind die numerischen Werte, die die Zeichen im String darstellen. Beispiele für UTF-16-Codeeinheiten sind die Zahlen 65, 66 und 67, die die Zeichen „A“, „B“ und „C“ darstellen. Daher erscheint die Zahl 200 vor der Zahl 3 in einem Array, weil der String „200“ vor dem String „3“ kommt, wenn ihre UTF-16-Codeeinheiten verglichen werden.

:::interactive_editor

```js
const numbers = [414, 200, 5, 10, 3];

numbers.sort((a, b) => a - b);

console.log(numbers); // [3, 5, 10, 200, 414]
```

:::

Die Parameter `a` und `b` sind die zwei zu vergleichenden Elemente. Die Vergleichsfunktion sollte einen negativen Wert zurückgeben, wenn `a` vor `b` stehen soll, einen positiven Wert, wenn `a` nach `b` stehen soll, und null, wenn `a` und `b` gleich sind.

## Arbeiten mit den `every` und `some` Methoden

- **`every()` Methode**: Diese Methode prüft, ob alle Elemente in einem Array einen Test bestehen, der durch eine bereitgestellte Funktion implementiert ist. Die `every()` Methode gibt `true` zurück, wenn die bereitgestellte Funktion für alle Elemente im Array `true` zurückgibt. Wenn ein Element den Test nicht besteht, gibt die Methode sofort `false` zurück und hört auf, die restlichen Elemente zu prüfen.

- **`some()` Methode**: Diese Methode prüft, ob mindestens ein Element den Test besteht. Die `some()` Methode gibt `true` zurück, sobald sie ein Element findet, das den Test besteht. Wenn kein Element den Test besteht, gibt sie `false` zurück.

## Arbeiten mit dem DOM und Web-APIs

- **API**: Eine API (Application Programming Interface) ist eine Sammlung von Regeln und Protokollen, die es Softwareanwendungen ermöglichen, miteinander zu kommunizieren und Daten effizient auszutauschen.
- **Web-API**: Web-APIs sind speziell für Webanwendungen konzipiert. Diese Arten von APIs werden oft in zwei Hauptkategorien unterteilt: Browser-APIs und Drittanbieter-APIs.
- **Browser-APIs**: Diese APIs machen Daten aus dem Browser verfügbar. Als Webentwickler können Sie mit JavaScript auf diese Daten zugreifen und sie manipulieren.
- **Drittanbieter-APIs**: Diese sind nicht standardmäßig im Browser eingebaut. Sie müssen deren Code auf irgendeine Weise abrufen. Normalerweise verfügen sie über eine ausführliche Dokumentation, die erklärt, wie Sie deren Dienste nutzen können. Ein Beispiel ist die Google Maps API, mit der Sie interaktive Karten auf Ihrer Webseite anzeigen können.
- **DOM**: Das DOM steht für Document Object Model. Es ist eine Programmierschnittstelle, die Ihnen erlaubt, mit HTML-Dokumenten zu interagieren. Mit dem DOM können Sie Elemente auf einer Webseite hinzufügen, ändern oder löschen. Die Wurzel des DOM-Baums ist das `html` Element. Es ist der oberste Container für den gesamten Inhalt eines HTML-Dokuments. Alle anderen Knoten sind Nachfahren dieses Wurzelknotens. Unterhalb des Wurzelknotens finden wir weitere Knoten in der Hierarchie. Ein Elternknoten ist ein Element, das andere Elemente enthält. Ein Kindknoten ist ein Element, das innerhalb eines anderen Elements enthalten ist.
- **`navigator` Schnittstelle**: Diese stellt Informationen über die Browserumgebung bereit, wie den User-Agent-String, die Plattform und die Version des Browsers. Ein User-Agent-String ist ein Textstring, der den verwendeten Browser und das Betriebssystem identifiziert.
- **`window` Schnittstelle**: Diese repräsentiert das Browserfenster, das das DOM-Dokument enthält. Sie bietet Methoden und Eigenschaften zur Interaktion mit dem Browserfenster, wie das Ändern der Fenstergröße, das Öffnen neuer Fenster und das Navigieren zu verschiedenen URLs.

## Arbeiten mit den `querySelector()`, `querySelectorAll()` und `getElementById()` Methoden

- **`getElementById()` Methode**: Diese Methode wird verwendet, um ein Objekt zu erhalten, das das HTML-Element mit der angegebenen `id` repräsentiert. Denken Sie daran, dass IDs in jedem HTML-Dokument eindeutig sein müssen, daher gibt diese Methode nur ein Element-Objekt zurück.

- **`querySelector()` Methode**: Diese Methode wird verwendet, um das erste Element im HTML-Dokument zu erhalten, das dem als Argument übergebenen CSS-Selektor entspricht.

- **`querySelectorAll()` Methode**: Mit dieser Methode können Sie eine Liste aller DOM-Elemente erhalten, die einem bestimmten CSS-Selektor entsprechen.

## Arbeiten mit den `innerText()`, `innerHTML()`, `createElement()` und `textContent()` Methoden

- **`innerHTML` Eigenschaft**: Dies ist eine Eigenschaft des `Element`, die verwendet wird, um Teile der HTML-Auszeichnung zu setzen oder zu aktualisieren.

- **`createElement` Methode**: Diese wird verwendet, um ein HTML-Element zu erstellen.

- **`innerText`**: Dies repräsentiert den sichtbaren Textinhalt des HTML-Elements und seiner Nachfahren.

- **`textContent`**: Dies gibt den reinen Textinhalt eines Elements zurück, einschließlich aller Texte innerhalb seiner Nachfahren.

## Arbeiten mit den `appendChild()` und `removeChild()` Methoden

- **`appendChild()` Methode**: Diese Methode wird verwendet, um einen Knoten am Ende der Liste der Kinder eines angegebenen Elternknotens hinzuzufügen.

- **`removeChild()` Methode**: Diese Methode wird verwendet, um einen Knoten aus dem DOM zu entfernen.

## Arbeiten mit der `setAttribute()` Methode

- **Definition**: Diese Methode wird verwendet, um ein Attribut für ein gegebenes Element zu setzen. Wenn das Attribut bereits existiert, wird der Wert aktualisiert. Andernfalls wird ein neues Attribut mit einem Wert hinzugefügt.

## Ereignisobjekt

- **Definition**: Das `Event` Objekt ist eine Nutzlast, die ausgelöst wird, wenn ein Benutzer auf irgendeine Weise mit Ihrer Webseite interagiert. Diese Interaktionen können alles sein, vom Klicken auf einen Button oder dem Fokussieren einer Eingabe bis hin zum Schütteln des mobilen Geräts. Alle `Event` Objekte haben die `type` Eigenschaft. Diese Eigenschaft zeigt den Typ des Ereignisses an, das die Nutzlast ausgelöst hat, wie keydown oder click. Diese Werte entsprechen den gleichen Werten, die Sie an `addEventListener()` übergeben könnten, wo Sie das `Event` Objekt erfassen und nutzen können.

## `addEventListener()` und `removeEventListener()` Methoden

- **`addEventListener` Methode**: Diese Methode wird verwendet, um auf Ereignisse zu hören. Sie nimmt zwei Argumente: das Ereignis, auf das Sie hören möchten, und eine Funktion, die aufgerufen wird, wenn das Ereignis eintritt. Einige häufige Beispiele für Ereignisse sind Klick-Ereignisse, Eingabe-Ereignisse und Änderungs-Ereignisse.

:::interactive_editor

```html
<button id="btn">Click Me</button>
<script src="./index.js"></script>
```

```js
const btn = document.getElementById("btn");

btn.addEventListener("click", () => alert("You clicked the button"));
```

:::

- **`removeEventListener()` Methode**: Diese Methode wird verwendet, um einen zuvor mit der `addEventListener()` Methode hinzugefügten Ereignis-Listener zu entfernen. Dies ist nützlich, wenn Sie aufhören möchten, auf ein bestimmtes Ereignis an einem Element zu hören.

- **Inline-Ereignis-Handler**: Inline-Ereignis-Handler sind spezielle Attribute an einem HTML-Element, die verwendet werden, um JavaScript-Code auszuführen, wenn ein Ereignis eintritt. In modernem JavaScript gelten Inline-Ereignis-Handler nicht als bewährte Vorgehensweise. Es wird bevorzugt, stattdessen die `addEventListener` Methode zu verwenden.

## Das Change-Ereignis

- **Definition**: Das Change-Ereignis ist ein spezielles Ereignis, das ausgelöst wird, wenn der Benutzer den Wert bestimmter Eingabeelemente ändert. Beispiele sind, wenn ein Kontrollkästchen oder eine Optionsschaltfläche aktiviert wird oder wenn der Benutzer eine Auswahl aus einem Datumsauswahlfeld oder Dropdown-Menü trifft.

## Ereignis-Bubbling

- **Definition**: Ereignis-Bubbling oder -Propagation beschreibt, wie ein Ereignis „nach oben“ zu übergeordneten Objekten weitergegeben wird, wenn es ausgelöst wird.
- **`stopPropagation()`-Methode**: Diese Methode verhindert die weitere Weitergabe eines Ereignisses.

## Ereignis-Delegation

- **Definition**: Event Delegation ist der Prozess, auf Ereignisse zu hören, die zu einem Elternteil hochgebubbelt sind, anstatt sie direkt am Element zu behandeln, das sie ausgelöst hat.

## DOMContentLoaded

- **Definition**: Das `DOMContentLoaded` Ereignis wird ausgelöst, wenn alles im HTML-Dokument geladen und geparst wurde. Wenn Sie externe Stylesheets oder Bilder haben, wartet das `DOMContentLoaded` Ereignis nicht darauf, dass diese geladen sind. Es wartet nur darauf, dass das HTML geladen ist.

## Arbeiten mit `style` und `classList`

- **`Element.style` Eigenschaft**: Diese Eigenschaft ist eine schreibgeschützte Eigenschaft, die den inline-Stil eines Elements repräsentiert. Sie können diese Eigenschaft verwenden, um den Stil eines Elements zu erhalten oder zu setzen.

- **`Element.classList` Eigenschaft**: Diese Eigenschaft ist eine schreibgeschützte Eigenschaft, mit der Sie Klassen an einem Element hinzufügen, entfernen oder umschalten können.

## Arbeiten mit den `setTimeout()` und `setInterval()` Methoden

- **`setTimeout()` Methode**: Diese Methode ermöglicht es Ihnen, eine Aktion für eine bestimmte Zeit zu verzögern.

- **`setInterval()`-Methode**: Diese Methode führt ein Stück Code wiederholt in einem festgelegten Intervall aus. Da `setInterval()` die bereitgestellte Funktion im angegebenen Intervall immer wieder ausführt, möchten Sie sie möglicherweise stoppen. Dafür müssen Sie die `clearInterval()`-Methode verwenden.

## Die `requestAnimationFrame()` Methode

- **Definition**: Diese Methode ermöglicht es Ihnen, den nächsten Schritt Ihrer Animation vor dem nächsten Bildschirm-Neuzeichnen zu planen, was zu einer flüssigen und optisch ansprechenden Erfahrung führt. Das nächste Bildschirm-Neuzeichnen bezeichnet den Moment, in dem der Browser die visuelle Darstellung der Webseite aktualisiert. Dies geschieht mehrmals pro Sekunde, typischerweise etwa 60 Mal (oder 60 Frames pro Sekunde) auf den meisten Bildschirmen.

## Web Animations API

- **Definition**: Die Web Animations API ermöglicht es Ihnen, Animationen direkt in JavaScript zu erstellen und zu steuern.

## Die Canvas API

- **Definition**: Die Canvas API ist ein leistungsstarkes Werkzeug, mit dem Sie Grafiken direkt in Ihrer JavaScript-Datei manipulieren können. Um mit der Canvas API zu arbeiten, müssen Sie zuerst ein `canvas` Element in HTML bereitstellen. Dieses Element fungiert als Zeichenfläche, die Sie mit den Instanzmethoden und Eigenschaften der Schnittstellen in der Canvas API manipulieren können. Diese API enthält Schnittstellen wie `HTMLCanvasElement`, `CanvasRenderingContext2D`, `CanvasGradient`, `CanvasPattern` und `TextMetrics`, die Methoden und Eigenschaften enthalten, mit denen Sie Grafiken in Ihrer JavaScript-Datei erstellen können.

## Öffnen und Schließen von Dialogen und Modals mit JavaScript

- **Definitionen von Modal und Dialog**: Dialoge ermöglichen es Ihnen, wichtige Informationen oder Aktionen für Benutzer anzuzeigen. Mit dem eingebauten HTML-Dialogelement können Sie diese Dialoge (sowohl modale als auch nicht-modale Dialoge) in Ihren Webanwendungen einfach erstellen. Ein modaler Dialog ist eine Art Dialog, der den Benutzer zwingt, mit ihm zu interagieren, bevor er auf den Rest der Anwendung oder Webseite zugreifen kann. Im Gegensatz dazu erlaubt ein nicht-modaler Dialog dem Benutzer, weiterhin mit anderen Teilen der Seite oder Anwendung zu interagieren, auch wenn der Dialog geöffnet ist. Er verhindert nicht den Zugriff auf den restlichen Inhalt.
- **`showModal()` Methode**: Diese Methode wird verwendet, um ein Modal zu öffnen.

- **`close()` Methode**: Diese Methode wird verwendet, um das Modal zu schließen.

## Häufige ARIA-Barrierefreiheitsattribute

- **`aria-expanded` Attribut**: Wird verwendet, um den Zustand einer Umschalt- (oder Offenlegungs-) Funktion für Screenreader-Nutzende zu übermitteln.

- **`aria-haspopup` Attribut**: Dieser Zustand zeigt an, dass ein interaktives Element beim Aktivieren ein Pop-up-Element auslöst. Das `aria-haspopup` Attribut darf nur verwendet werden, wenn das Pop-up eine der folgenden Rollen hat: `menu`, `listbox`, `tree`, `grid` oder `dialog`. Der Wert von `aria-haspopup` muss entweder eine dieser Rollen oder `true` sein, was dasselbe ist wie `menu`.

- **`aria-checked` Attribut**: Dieses Attribut zeigt an, ob ein Element sich im aktivierten Zustand befindet. Es wird am häufigsten bei der Erstellung benutzerdefinierter Kontrollkästchen, Optionsschaltflächen, Schalter und Listboxen verwendet.

- **`aria-disabled` Attribut**: Dieser Zustand zeigt an, dass ein Element nur für Personen mit Hilfstechnologien wie Screenreadern deaktiviert ist.

- **`aria-selected` Attribut**: Dieser Zustand zeigt an, dass ein Element ausgewählt ist. Sie können diesen Zustand bei benutzerdefinierten Steuerelementen wie einem Registerkarten-Interface, einer Listbox oder einem Raster verwenden.

- **`aria-controls` Attribut**: Wird verwendet, um ein Element mit einem anderen Element zu verknüpfen, das es steuert. Dies hilft Menschen mit Hilfstechnologien, die Beziehung zwischen den Elementen zu verstehen.

- **`hidden` Attribut**: Verbirgt inaktive Bereiche sowohl vor visuellen Nutzenden als auch vor Nutzenden von Hilfstechnologien.

## Arbeiten mit Live-Regionen und dynamischen Inhalten

- **`aria-live` Attribut**: Macht einen Teil einer Webseite zu einer Live-Region, was bedeutet, dass alle Aktualisierungen in diesem Bereich von einem Screenreader angesagt werden, damit Nutzende keine wichtigen Änderungen verpassen.
- **`polite` Wert**: Die meisten Live-Regionen verwenden diesen Wert. Er bedeutet, dass die Aktualisierung nicht dringend ist, sodass der Screenreader warten kann, bis er eine laufende Ansage beendet oder die Nutzenden ihre aktuelle Aktion abgeschlossen haben, bevor die Aktualisierung angesagt wird.

Hier ist ein Beispiel für eine Live-Region, die dynamisch mit JavaScript aktualisiert wird:

:::interactive_editor

```html
<div aria-live="polite" id="status"></div>

<button id="updateStatus">Update Status</button>

<script>
  const statusEl = document.getElementById("status");
  const btn = document.getElementById("updateStatus");

  btn.addEventListener("click", () => {
    statusEl.textContent = "Your file has been successfully uploaded.";
  });
</script>
```

:::

- **`contenteditable` Attribut**: Verwandelt das Element in einen Live-Editor, der es Nutzenden erlaubt, seinen Inhalt zu aktualisieren, als wäre es ein Textfeld. Wenn es keine sichtbare Bezeichnung oder Überschrift für einen contenteditable-Bereich gibt, fügen Sie mit dem `aria-label` Attribut einen zugänglichen Namen hinzu, um Screenreader-Nutzenden den Zweck des bearbeitbaren Bereichs zu verdeutlichen.

## `focus` und `blur` Ereignisse

- **`blur` Ereignis**: Wird ausgelöst, wenn ein Element den Fokus verliert.

- **`focus` Ereignis**: Wird ausgelöst, wenn ein Element den Fokus erhält.

## Häufige Arten von Fehlermeldungen

- **SyntaxError**: Diese Fehler treten auf, wenn Sie etwas in Ihrem Code falsch schreiben, wie eine fehlende Klammer oder ein fehlendes Zeichen. Man kann es sich wie einen Grammatikfehler in einem Satz vorstellen.

- **ReferenceError**: Es gibt verschiedene Arten von Reference Errors, die auf unterschiedliche Weise ausgelöst werden. Die erste Art von Reference Error ist eine nicht definierte Variable. Ein weiteres Beispiel für einen ReferenceError ist der Versuch, auf eine mit `let` oder `const` deklarierte Variable zuzugreifen, bevor sie definiert wurde.

- **TypeError**: Diese Fehler treten auf, wenn Sie versuchen, eine Operation auf einem falschen Typ auszuführen.

- **RangeError**: Diese Fehler treten auf, wenn Ihr Code versucht, einen Wert zu verwenden, der außerhalb des Bereichs liegt, den JavaScript verarbeiten kann.

## Die `throw` Anweisung

- **Definition**: Die `throw`-Anweisung in JavaScript wird verwendet, um eine benutzerdefinierte Ausnahme zu werfen. Eine Ausnahme in der Programmierung ist ein unerwartetes Ereignis, das den normalen Ablauf des Programms unterbricht.

## `try...catch...finally`

- **Definition**: Der `try` Block wird verwendet, um Code einzuschließen, der einen Fehler werfen könnte. Er dient als sicherer Bereich, um etwas zu versuchen, das fehlschlagen könnte. Der `catch` Block fängt Fehler ab und behandelt sie, die im try-Block auftreten. Sie können das Fehlerobjekt innerhalb von catch verwenden, um zu untersuchen, was schiefgelaufen ist. Der `finally` Block wird nach den try- und catch-Blöcken ausgeführt, unabhängig davon, ob ein Fehler aufgetreten ist. Er wird häufig für Aufräumarbeiten verwendet, wie das Schließen von Dateien oder das Freigeben von Ressourcen.

:::interactive_editor

```js
function processInput(input) {
  if (typeof input !== "string") {
    throw new TypeError("Input must be a string.");
  }

  return input.toUpperCase();
}

try {
  console.log("Starting to process input...");
  const result1 = processInput("hello");
  console.log("Processed result:", result1);  // HELLO
  const result2 = processInput(9);  // throws TypeError
  console.log("Processed result:", result2);  // not executed
} catch (error) {
  console.error("Error occurred:", error.message);
} 
```

:::

## Debugging-Techniken

- **`debugger` Anweisung**: Diese Anweisung ermöglicht es Ihnen, Ihren Code an einer bestimmten Zeile anzuhalten, um zu untersuchen, was im Programm vor sich geht.

- **Breakpoints**: Breakpoints ermöglichen es Ihnen, die Ausführung Ihres Codes an einer bestimmten Zeile Ihrer Wahl anzuhalten. Nach dem Anhalten können Sie Variablen inspizieren, Ausdrücke auswerten und den Aufrufstapel untersuchen.
- **Watchers**: Watch-Ausdrücke ermöglichen es Ihnen, die Werte von Variablen oder Ausdrücken während der Codeausführung zu überwachen, auch wenn sie außerhalb des aktuellen Gültigkeitsbereichs liegen.
- **Profiling**: Profiling hilft Ihnen, Leistungsengpässe zu identifizieren, indem Sie Screenshots aufnehmen und CPU-Auslastung, Funktionsaufrufe und Ausführungszeit aufzeichnen.
- **`console.dir()`**: Diese Methode wird verwendet, um eine interaktive Liste der Eigenschaften eines angegebenen JavaScript-Objekts anzuzeigen. Sie gibt eine hierarchische Auflistung aus, die erweitert werden kann, um alle verschachtelten Eigenschaften zu sehen.

- **`console.table()`**: Diese Methode zeigt tabellarische Daten als Tabelle in der Konsole an. Sie nimmt ein obligatorisches Argument, das ein Array oder ein Objekt sein muss, und ein optionales Argument, um anzugeben, welche Eigenschaften (Spalten) angezeigt werden sollen.

## Reguläre Ausdrücke und gängige Methoden

- **Definition**: Reguläre Ausdrücke, oder Regex, werden verwendet, um ein „Muster“ zu erstellen, mit dem Sie dann einen String überprüfen, Text extrahieren und mehr können.

- **`RegExp` Konstruktor**: Wenn Ihr Muster oder Ihre Flags aus Variablen stammen, können Sie mit dem `RegExp` Konstruktor denselben Typ von Regex erstellen. Er akzeptiert einen Muster-String und einen optionalen Flags-String.

Zum Beispiel erstellt `new RegExp(pattern, flags)` einen regulären Ausdruck aus diesen Strings.

- **`test()` Methode**: Diese Methode akzeptiert einen String, der auf Übereinstimmungen mit dem regulären Ausdruck getestet wird. Diese Methode gibt einen Boolean zurück, wenn der String dem Regex entspricht.

- **`match()` Methode**: Diese Methode akzeptiert einen regulären Ausdruck, obwohl Sie auch einen String übergeben können, der in einen regulären Ausdruck umgewandelt wird. Die `match` Methode gibt das Übereinstimmungs-Array für den String zurück.

- **`replace()` Methode**: Diese Methode akzeptiert zwei Argumente: den regulären Ausdruck, der übereinstimmen soll (oder einen String), und den String, mit dem die Übereinstimmung ersetzt werden soll (oder eine Funktion, die für jede Übereinstimmung ausgeführt wird).

- **`replaceAll` Methode**: Diese Methode wird verwendet, um alle Vorkommen eines bestimmten Musters durch einen neuen String zu ersetzen. Diese Methode wirft einen Fehler, wenn Sie ihr einen regulären Ausdruck ohne den globalen Modifikator übergeben.

- **`matchAll` Methode**: Diese Methode wird verwendet, um alle Übereinstimmungen eines gegebenen regulären Ausdrucks in einem String abzurufen, einschließlich der Capturing-Gruppen, und gibt sie als Iterator zurück. Ein Iterator ist ein Objekt, das es Ihnen ermöglicht, eine Sammlung von Elementen durchzugehen (oder „zu iterieren“).

## Modifikatoren für reguläre Ausdrücke

- **Definition**: Modifikatoren, oft „Flags“ genannt, verändern das Verhalten eines regulären Ausdrucks.
- **`i` Flag**: Dieses Flag lässt einen Regex die Groß- und Kleinschreibung ignorieren.

- **`g` Flag**: Dieses Flag, oder globaler Modifikator, erlaubt Ihrem regulären Ausdruck, ein Muster mehr als einmal zu finden.

- **Definition Anker**: Der `^` Anker am Anfang des regulären Ausdrucks bedeutet „beginne am Anfang des Strings“. Der `$` Anker am Ende des regulären Ausdrucks bedeutet „ende am Ende des Strings“.

- **`m` Flag**: Anker suchen den Anfang und das Ende des gesamten Strings. Aber Sie können einen Regex mit dem `m` Flag, dem Mehrzeilen-Modifikator, so einstellen, dass er mehrere Zeilen behandelt.

- **`d`-Flag**: Dieses Flag fügt dem Match-Objekt Start- und Endindizes von Treffern und Erfassungsgruppen hinzu.

- **`u`-Flag**: Diese erweitert die Funktionalität eines regulären Ausdrucks, sodass er spezielle Unicode-Zeichen erkennen kann. Die `u`-Flag gibt Ihnen Zugriff auf spezielle Klassen wie die `Extended_Pictographic`, um die meisten Emojis zu erkennen. Es gibt auch eine `v`-Flag, die die Funktionalität der Unicode-Erkennung weiter ausbaut.
- **`y`-Flag**: Der sticky-Modifikator verhält sich sehr ähnlich wie der globale Modifikator, jedoch mit einigen Ausnahmen. Die wichtigste ist, dass ein globaler regulärer Ausdruck ab lastIndex startet und den gesamten Rest des Strings nach einem weiteren Treffer durchsucht, während ein sticky regulärer Ausdruck null zurückgibt und lastIndex auf 0 zurücksetzt, wenn nicht sofort ein Treffer an der vorherigen lastIndex-Stelle vorliegt.
- **`s`-Flag**: Der Single-Line-Modifikator erlaubt es einem Wildcard-Zeichen, dargestellt durch einen `.` im Regex, Zeilenumbrüche zu erkennen – wodurch der String effektiv als eine einzige Textzeile behandelt wird.

## Zeichenklassen

- **Wildcard `.`**: Zeichenklassen sind eine spezielle Syntax, mit der Sie Mengen oder Teilmengen von Zeichen erkennen können. Die erste Zeichenklasse, die Sie lernen sollten, ist die Wildcard-Klasse. Die Wildcard wird durch einen Punkt dargestellt und erkennt JEDES einzelne Zeichen AUSSER Zeilenumbrüchen. Um die Wildcard-Klasse Zeilenumbrüche erkennen zu lassen, müssen Sie das `s` Flag verwenden.

- **`\d`**: Dies erkennt alle Ziffern (`0-9`) in einem String.

- **`\w`**: Dies wird verwendet, um jedes Wortzeichen (`a-zA-Z0-9_`) in einem String zu finden. Ein Wortzeichen ist definiert als jeder Buchstabe von a bis z oder A bis Z, eine Zahl von 0 bis 9 oder das Unterstrichzeichen.

- **`\s`**: Die Weißraumklasse `\s` wird durch einen Backslash gefolgt von einem `s` dargestellt. Diese Zeichenklasse trifft auf jeden Weißraum, einschließlich Zeilenumbrüchen, Leerzeichen, Tabs und speziellen Unicode-Leerzeichen zu.
- **Negieren von Sonderzeichenklassen**: Um eine dieser Zeichenklassen zu negieren, verwenden Sie statt eines Kleinbuchstabens nach dem Backslash den entsprechenden Großbuchstaben. Zum Beispiel trifft `\D` auf jedes einzelne Zeichen zu, das KEIN numerisches Zeichen ist.

- **Benutzerdefinierte Zeichenklassen**: Sie können benutzerdefinierte Zeichenklassen erstellen, indem Sie die Zeichen, die Sie treffen möchten, in eckige Klammern setzen.

Zum Beispiel trifft `/[abcdf]/` auf eines der Zeichen in den Klammern zu.

## Lookahead- und Lookbehind-Zusicherungen

- **Definition**: Lookahead- und Lookbehind-Zusicherungen erlauben es Ihnen, bestimmte Muster basierend auf dem Vorhandensein oder Fehlen umliegender Muster zu erkennen.
- **Positive Lookahead-Zusicherung**: Diese Zusicherung erkennt ein Muster, wenn es von einem anderen Muster gefolgt wird. Um ein positives Lookahead zu erstellen, beginnen Sie mit dem Muster, das Sie erkennen möchten. Dann verwenden Sie runde Klammern, um das Muster einzuschließen, das Sie als Bedingung verwenden möchten. Nach der öffnenden Klammer verwenden Sie `?=`, um dieses Muster als positives Lookahead zu definieren.

Zum Beispiel trifft `/free(?=code)/i` auf `free` zu, wenn es von `code` gefolgt wird.

- **Negative Lookahead-Zusicherung**: Dies ist eine Art Bedingung in regulären Ausdrücken, um zu prüfen, dass ein bestimmtes Muster nicht vor dem aktuellen Punkt im String vorkommt.

Zum Beispiel trifft `/free(?!code)/i` auf `free` zu, wenn es nicht von `code` gefolgt wird.

- **Positive Lookbehind-Zusicherung**: Diese Zusicherung erkennt ein Muster nur, wenn es von einem anderen bestimmten Muster vorausgeht, ohne das vorausgehende Muster in die Übereinstimmung einzubeziehen.

Zum Beispiel trifft `/(?<=free)code/i` auf `code` zu, wenn es von `free` vorausgegangen wird.

- **Negative Lookbehind-Zusicherung**: Diese Zusicherung stellt sicher, dass ein Muster nicht von einem anderen bestimmten Muster vorausgegangen wird. Sie erkennt nur, wenn das angegebene Muster nicht unmittelbar von der gegebenen Sequenz vorausgegangen wird, ohne die vorausgehende Sequenz in die Übereinstimmung einzubeziehen.

Zum Beispiel trifft `/(?<!free)code/i` auf `code` zu, wenn es nicht von `free` vorausgegangen wird.

## Regex-Quantifizierer

- **Definition**: Quantifizierer in regulären Ausdrücken geben an, wie oft ein Muster (oder ein Teil eines Musters) erscheinen soll. Sie steuern die Anzahl der Vorkommen von Zeichen oder Gruppen in einem Treffer.

Zum Beispiel trifft `/^\d{4}$/` auf einen String zu, der genau vier Ziffern enthält.

- **`*`**: Erkennt 0 oder mehr Vorkommen des vorhergehenden Elements.
- **`+`**: Erkennt 1 oder mehr Vorkommen des vorhergehenden Elements.
- **`?`**: Erkennt 0 oder 1 Vorkommen des vorhergehenden Elements.
- **`{n}`**: Erkennt genau n Vorkommen des vorhergehenden Elements.
- **`{n,}`**: Erkennt n oder mehr Vorkommen des vorhergehenden Elements.
- **`{n,m}`**: Erkennt zwischen n und m Vorkommen des vorhergehenden Elements.

## Capturing-Gruppen und Backreferences

- **Capturing-Gruppen**: Eine Capturing-Gruppe erlaubt es Ihnen, einen Teil des erkannten Strings „einzufangen“, um ihn nach Bedarf zu verwenden. Capturing-Gruppen werden durch runde Klammern definiert, die das zu erfassende Muster enthalten, ohne führende Zeichen wie ein Lookahead.

Zum Beispiel erfasst `/free(code)camp/i` `code`.

- **Nicht-erfassende Gruppen**: Eine nicht-erfassende Gruppe ist ähnlich wie eine erfassende Gruppe, speichert aber den erkannten Teil des Strings nicht für die spätere Verwendung. Nicht-erfassende Gruppen werden durch `(?:...)` definiert.

Zum Beispiel gruppiert `/free(?:code)camp/i` `code`, ohne es zu erfassen.

- **Backreferences**: Eine Backreference in regulären Ausdrücken bezieht sich auf eine Möglichkeit, einen Teil des Musters, der zuvor in derselben Expression erkannt wurde, wiederzuverwenden. Sie erlaubt es, auf eine erfasste Gruppe (einen Teil des Musters in Klammern) durch ihre Nummer zu verweisen. Zum Beispiel bezieht sich `$1` auf die erste erfasste Gruppe.

:::interactive_editor

```js
const regex = /free(co+de)camp/i;
console.log("freecoooooooodecamp".replace(regex, "paid$1world"));
```

:::

- Sie können Rückverweise innerhalb des Regex selbst verwenden, um denselben Text zu erkennen, der von einer vorherigen Gruppe mit einem Backslash und der Nummer der Erfassungsgruppe erfasst wurde. Zum Beispiel:

:::interactive_editor

```js
const regex = /(hello) \1/i;
console.log(regex.test("hello hello")); // true
console.log(regex.test("hello world")); // false
```

:::

## Validierung von Formularen mit JavaScript

- **Constraint Validation API**: Bestimmte HTML-Elemente, wie die `textarea` und `input` Elemente, stellen eine Constraint Validation API bereit. Diese API erlaubt es Ihnen zu prüfen, ob der vom Benutzer eingegebene Wert für dieses Element alle HTML-Validierungen erfüllt, die Sie definiert haben, wie Mindestlänge oder Mustererkennung.
- **`checkValidity()` Methode**: Diese Methode gibt `true` zurück, wenn das Element alle HTML-Validierungen (basierend auf seinen Attributen) besteht, und `false`, wenn es fehlschlägt.

- **`reportValidity()` Methode**: Diese Methode teilt dem Browser mit, dass das `input` ungültig ist.

- **`validity` Eigenschaft**: Diese Eigenschaft wird verwendet, um den Gültigkeitsstatus von Formularsteuerelementen (wie `<input>`, `<select>`, etc.) zu erhalten und liefert Informationen darüber, ob die Benutzereingabe die für dieses Element definierten Einschränkungen erfüllt (z. B. `required` Felder, Musterbeschränkungen, maximale Länge usw.).

- **`patternMismatch` Eigenschaft**: Diese ist `true`, wenn der Wert nicht dem angegebenen regulären Ausdrucksmuster entspricht.

## `preventDefault()` Methode

- **Definition**: Jedes Ereignis, das im DOM ausgelöst wird, hat eine Art Standardverhalten. Das Klick-Ereignis auf ein Kontrollkästchen ändert standardmäßig den Zustand dieses Kontrollkästchens. Das Drücken der <kbd>Leertaste</kbd> auf einem fokussierten Button aktiviert den Button. Die Methode `preventDefault()` bei diesen `Event`-Objekten verhindert, dass dieses Verhalten eintritt.

## Absenden von Formularen

- **Definition**: Ein Formular kann auf drei Arten abgesendet werden. Die erste ist, wenn der Benutzer auf einen Button im Formular klickt, dessen `type`-Attribut auf `submit` gesetzt ist. Die zweite ist, wenn der Benutzer die <kbd>Enter</kbd>-Taste in einem bearbeitbaren `input`-Feld im Formular drückt. Die dritte ist ein JavaScript-Aufruf der Methoden `requestSubmit()` oder `submit()` des `form`-Elements.
- **`action`-Attribut**: Das `action`-Attribut sollte entweder eine URL oder einen relativen Pfad für die aktuelle Domain enthalten. Dieser Wert bestimmt, wohin das Formular versucht, die Daten zu senden – wenn Sie kein `action`-Attribut setzen, sendet das Formular die Daten an die URL der aktuellen Seite.

- **`method` Attribut**: Dieses Attribut akzeptiert eine Standard-`HTTP` Methode, wie `GET` oder `POST`, und verwendet diese Methode, wenn die Anfrage an die Aktions-URL gesendet wird. Wenn keine Methode gesetzt ist, verwendet das Formular standardmäßig eine `GET` Anfrage. Die Daten im Formular werden als URL-kodierte `name=value` Paare kodiert und als Abfrageparameter an die Aktions-URL angehängt.

- **`enctype` Attribut**: Das `form` Element akzeptiert ein `enctype` Attribut, das den zu verwendenden Kodierungstyp für die Daten angibt. Dieses Attribut akzeptiert nur drei Werte: `application/x-www-form-urlencoded` (Standard, sendet die Daten als URL-kodierten Formular-Body), `text/plain` (sendet die Daten im Klartext, als `name=value` Paare, getrennt durch Zeilenumbrüche) oder `multipart/form-data`, das speziell für Formulare mit Datei-Uploads gedacht ist.

## Das `date()`-Objekt und gängige Methoden

- **Definition**: Das `date()`-Objekt wird verwendet, um Daten und Zeiten in JavaScript zu erstellen, zu manipulieren und zu formatieren. Zum Beispiel erstellt `const now = new Date();` eine neue Instanz des `Date`-Objekts und weist sie der Variablen `now` zu. Wenn Sie den Wert von `now` in der Konsole ausgeben, sehen Sie das aktuelle Datum und die aktuelle Uhrzeit basierend auf der Systemuhr des Computers, auf dem der Code ausgeführt wird.

- **`Date.now()`-Methode**: Diese Methode wird verwendet, um das aktuelle Datum und die aktuelle Uhrzeit zu erhalten. `Date.now()` gibt die Anzahl der Millisekunden seit dem 1. Januar 1970, 00:00:00 UTC zurück. Dies ist als Unix-Epoch-Zeit bekannt. Die Unix-Epoch-Zeit ist eine gängige Methode, um Daten und Zeiten in Computersystemen darzustellen, da sie eine Ganzzahl ist, die leicht gespeichert und bearbeitet werden kann. UTC steht für Coordinated Universal Time, den primären Zeitstandard, nach dem die Welt Uhren und Zeit reguliert.
- **`getDate()`-Methode**: Diese Methode wird verwendet, um den Tag des Monats basierend auf dem aktuellen Datum zu erhalten. `getDate()` gibt einen ganzzahligen Wert zwischen 1 und 31 zurück, abhängig vom Tag des Monats. Wenn das Datum ungültig ist, wird `NaN` (Not a Number) zurückgegeben.

- **`getMonth()`-Methode**: Diese Methode wird verwendet, um den Monat zu erhalten. Der Monat ist nullbasiert, also ist Januar 0, Februar 1 und so weiter. Zum Beispiel gibt `getMonth()` bei einem Datum im Oktober `9` zurück. Wenn der Monat ungültig ist, wird `NaN` zurückgegeben.

- **`getFullYear()` Methode**: Diese Methode wird verwendet, um das volle Jahr zu erhalten. Wenn das Jahr ungültig ist, gibt es `NaN` zurück.

## Verschiedene Möglichkeiten, Daten zu formatieren

- **`toISOString()` Methode**: Diese Methode wird verwendet, um das Datum im erweiterten `ISO` (ISO 8601) Format zu formatieren. ISO 8601 ist ein internationaler Standard zur Darstellung von Daten und Zeiten. Das Format ist `YYYY-MM-DDTHH:mm:ss.sssZ`.

- **`toLocaleDateString()` Methode**: Diese Methode wird verwendet, um das Datum basierend auf der Spracheinstellung des Benutzers zu formatieren.

Die `toLocaleDateString()` Methode akzeptiert zwei optionale Parameter: locales und options.

Der Parameter locales ist ein String, der die zu verwendende Spracheinstellung repräsentiert. Zum Beispiel können Sie `"en-US"` für Englisch (Vereinigte Staaten) oder `"fr-FR"` für Französisch (Frankreich) übergeben. Wenn Sie keinen locales-Parameter übergeben, wird die Standardspracheinstellung verwendet. Der zweite optionale Parameter ist der options-Parameter. Dieser Parameter ist ein Objekt, mit dem Sie das Format des Datumsstrings angeben können.

## `Audio` Konstruktor und gängige Methoden

- **Definition**: Der `Audio`-Konstruktor ist wie andere Konstruktoren eine spezielle Funktion, die mit dem Schlüsselwort `new` aufgerufen wird. Er gibt ein `HTMLAudioElement` zurück, das Sie dann verwenden können, um Audio für den Benutzer abzuspielen oder es dem DOM hinzuzufügen, damit der Benutzer es selbst steuern kann. Wenn Sie den Konstruktor aufrufen, können Sie optional eine URL als (einziges) Argument übergeben. Diese URL sollte auf die Quelle der Audiodatei zeigen, die Sie abspielen möchten. Oder, wenn Sie die Quelle dynamisch ändern müssen, können Sie die URL der `src`-Eigenschaft des zurückgegebenen Audioelements zuweisen.
- **`play()`-Methode**: Diese Methode wird mit den Elementen `audio` oder `video` verwendet, um die Wiedergabe der Medien zu starten.

- **`pause()`-Methode**: Diese Methode wird mit den Elementen `audio` oder `video` verwendet, um die Wiedergabe der Medien zu pausieren. Sie behält die aktuelle Position bei, sodass bei erneutem Aufruf von `play()` die Wiedergabe an dieser Stelle fortgesetzt wird.

- **`addTextTrack()` Methode**: Diese Methode erlaubt es Ihnen, eine Textspur mit dem Medienelement zu verknüpfen – was besonders hilfreich ist, um Untertitel zu einem Video hinzuzufügen.
- **`fastSeek()` Methode**: Diese Methode erlaubt es Ihnen, die Wiedergabeposition auf eine bestimmte Zeit innerhalb der Medien zu verschieben.

Der `Audio()`-Konstruktor hat ebenso Eigenschaften wie Methoden. Zu diesen Eigenschaften gehören:

- `currentTime`: um die aktuelle Wiedergabezeit eines Audios zu erhalten
- `loop`: um das Audio kontinuierlich abzuspielen, indem es automatisch neu startet, wenn es das Ende erreicht
- `muted`: um die Audioausgabe eines Medienelements stummzuschalten, unabhängig von der Lautstärkeeinstellung

## Verschiedene Audio- und Videoformate

- **MIME-Typ**: Ein MIME-Typ, kurz für Multipurpose Internet Mail Extensions, ist eine standardisierte Möglichkeit, programmgesteuert einen Dateityp anzugeben. Der MIME-Typ kann einer Anwendung, wie Ihrem Browser, mitteilen, wie eine bestimmte Datei behandelt werden soll. Im Fall von Audio und Video zeigt der MIME-Typ an, dass es sich um ein Multimediaformat handelt, das in die Webseite eingebettet werden kann.
- **`source`-Element**: Dieses wird verwendet, um einen Dateityp und eine Quelle anzugeben – und kann mehrere verschiedene Typen enthalten, indem mehrere Source-Elemente verwendet werden. Wenn Sie dies tun, bestimmt der Browser das beste Format für die aktuelle Umgebung des Benutzers.
- **MP3**: Dies ist ein digitaler Dateityp, der verwendet wird, um Musik, Audio oder Ton zu speichern. Es handelt sich um eine komprimierte Version einer Tonaufnahme, die die Dateigröße verkleinert, sodass sie leichter gespeichert und geteilt werden kann. MP3 hat die breiteste Browserunterstützung und den MIME-Typ `audio/mpeg`.
- **MP4**: Ein MP4 ist ein digitaler Dateityp, der verwendet wird, um Video und Audio zu speichern. Er dient als Container, der sowohl das Video (Bilder) als auch den Ton (Musik oder Sprache) in einer Datei enthält. Ein MP4 kann den MIME-Typ `audio/mp4` ODER `video/mp4` haben, je nachdem, ob es sich um eine Videodatei oder nur Audio handelt.
- Weitere Formate sind `WMV`, das mit der Windows Media Player-Anwendung verbunden ist, `OGG`, `MKV`, `AVI` und mehr.

## Codecs

- **Definition**: Ein Codec, kurz für „Encoder/Decoder“, ist ein Algorithmus oder eine Software, die Audio und Video zwischen analogen und digitalen Formaten konvertieren kann. Codecs können als Teil des MIME-Typs angegeben werden. Die grundlegende Syntax zur Definition eines Codecs besteht darin, nach dem Medientyp ein Semikolon zu setzen, dann `codecs=` und den Codec.

Beispiele für Methoden sind `play()`, `fastSeek()`, `pause()` und `canPlayType()`, mit denen Sie überprüfen können, ob ein Browser wahrscheinlich eine Audiodatei abspielen kann.

## Sets in JavaScript

- Ein `Set` ist eine eingebaute Option zur Verwaltung von Datensammlungen.
- Sets stellen sicher, dass jeder Wert nur einmal vorkommt, was nützlich ist, um Duplikate aus einem Array zu entfernen oder Sammlungen von eindeutigen Werten zu verwalten.
- Sie können ein `Set` mit dem Konstruktor `Set()` erstellen.

- Sets können mit diesen Methoden bearbeitet werden:

  - `add()`: Fügt dem `Set` ein neues Element hinzu.
  - `delete()`: Entfernt ein Element aus dem `Set`.
  - `has()`: Prüft, ob ein Element im `Set` vorhanden ist.
  - `clear()`: Entfernt alle Elemente aus dem `Set`.
  - `keys()` und `values()`: Beide geben ein `SetIterator` zurück, das die Werte des `Set` enthält. Sie sind identisch, da `keys()` ein Alias für `values()` ist.
  - `forEach()`: Zum Durchlaufen der Werte des `Set`.

## Weaksets in JavaScript

- `WeakSet` ist eine Sammlung von Objekten, die es Ihnen erlaubt, schwach gehaltene Objekte zu speichern.

## Sets vs. WeakSets

- Im Gegensatz zu Sets unterstützt ein `WeakSet` keine Primitiven wie Zahlen oder Strings.
- Ein `WeakSet` speichert nur Objekte, und die Referenzen auf diese Objekte sind „schwach“, was bedeutet, dass das Objekt automatisch entfernt wird, wenn es im Code sonst nicht verwendet wird, um Speicher freizugeben.

## Maps in JavaScript

- Eine `Map` ist ein eingebautes Objekt, das Schlüssel-Wert-Paare ähnlich wie ein Objekt enthält.
- Maps unterscheiden sich von Standard-JavaScript-Objekten durch ihre Fähigkeit, Schlüssel beliebigen Typs zuzulassen, einschließlich Objekten und Funktionen.
- Eine `Map` bietet bessere Leistung als das Standardobjekt bei häufigem Hinzufügen und Entfernen von Schlüssel-Wert-Paaren.
- Sie können eine `Map` mit dem Konstruktor `Map()` erstellen.

- Maps können mit diesen Methoden bearbeitet werden:

  - `set()`: Fügt ein neues Schlüssel-Wert-Paar zum `Map` hinzu.
  - `get()`: Ruft den Wert eines Schlüssels aus dem `Map` ab.
  - `delete()`: Entfernt ein Schlüssel-Wert-Paar aus dem `Map`.
  - `has()`: Prüft, ob ein Schlüssel im `Map` vorhanden ist.
  - `clear()`: Entfernt alle Schlüssel-Wert-Paare aus dem `Map`.

Beachten Sie, dass sowohl Maps als auch Sets die `size`-Eigenschaft besitzen, die die Anzahl der eindeutigen Elemente darin zurückgibt.

## WeakMaps in JavaScript

- Ein `WeakMap` ist eine Sammlung von Schlüssel-Wert-Paaren wie `Map`, aber mit schwachen Referenzen auf die Schlüssel. Die Schlüssel müssen Objekte sein, und die Werte können beliebig sein.

## Maps vs WeakMaps

- WeakMaps ähneln WeakSets darin, dass sie nur Objekte speichern und die Referenzen auf diese Objekte „schwach“ sind.

## Persistenter Speicher

- **Definition**: Persistenter Speicher bezeichnet eine Möglichkeit, Daten so zu speichern, dass sie auch nach dem Ausschalten des Geräts oder einem Neustart weiterhin verfügbar bleiben.

## Erstellen, Lesen, Aktualisieren, Löschen (CRUD)

- **Erstellen**: Dies bezeichnet den Prozess, neue Daten anzulegen. Zum Beispiel kann ein Nutzer in einer Webanwendung einen neuen Beitrag in einem Blog hinzufügen.
- **Lesen**: Dies ist die Operation, bei der Daten aus einer Datenbank abgerufen werden. Wenn Sie beispielsweise einen Blogbeitrag besuchen oder Ihr Profil auf einer Webseite ansehen, führen Sie eine Leseoperation aus, um die gespeicherten Daten abzurufen und anzuzeigen.
- **Aktualisieren**: Dies umfasst das Ändern vorhandener Daten in der Datenbank. Ein Beispiel wäre das Bearbeiten eines Blogbeitrags oder das Aktualisieren Ihrer Profilinformationen.
- **Löschen**: Dies ist die Operation, die Daten aus einer Datenbank entfernt. Wenn Sie beispielsweise einen Blogbeitrag oder ein Konto löschen, führen Sie eine Löschoperation aus.

## HTTP-Methoden

- **Definition**: HTTP steht für Hypertext Transfer Protocol und ist die Grundlage für die Datenkommunikation im Web. Es gibt HTTP-Methoden, die definieren, welche Aktionen auf Ressourcen im Web ausgeführt werden können. Die gängigen Methoden sind GET, POST, PUT, PATCH, DELETE.
- **`GET` Methode**: Diese wird verwendet, um Daten von einem Server abzurufen.
- **`POST` Methode**: Diese wird verwendet, um Daten an einen Server zu senden, der dadurch eine neue Ressource erstellt.
- **`PUT` Methode**: Diese wird verwendet, um eine Ressource vollständig zu ersetzen und zu aktualisieren.
- **`PATCH` Methode**: Diese wird verwendet, um eine Ressource teilweise zu aktualisieren.
- **`DELETE` Methode**: Diese wird verwendet, um Datensätze aus einer Datenbank zu entfernen.

- **`sessionStorage.clear()` Methode**: Diese Methode wird verwendet, um alle gespeicherten Daten in `sessionStorage` zu löschen.

## Arbeiten mit Cookies

- **Definition**: Cookies, auch Web-Cookies oder Browser-Cookies genannt, sind kleine Datenstücke, die ein Server an den Webbrowser eines Nutzers sendet. Diese Cookies werden auf dem Gerät des Nutzers gespeichert und bei nachfolgenden Anfragen an den Server zurückgesendet. Cookies sind wichtig, damit Webanwendungen den Zustand aufrechterhalten und Nutzerinformationen speichern können, was besonders wichtig ist, da HTTP ein zustandsloses Protokoll ist.
- **Session-Cookies**: Diese Cookies gelten nur für die Dauer der Sitzung des Nutzers auf der Webseite. Sobald der Nutzer den Browser oder Tab schließt, wird das Session-Cookie gelöscht. Diese Cookies werden typischerweise verwendet, um einen Nutzer während seines Besuchs eingeloggt zu halten.
- **Sichere Cookies**: Diese Cookies werden nur über HTTPS gesendet, wodurch sichergestellt wird, dass sie unterwegs nicht von Angreifern abgefangen werden können.
- **HttpOnly-Cookies**: Diese Cookies können von JavaScript im Browser nicht aufgerufen oder verändert werden, was sie sicherer gegen Cross-Site-Scripting-(XSS-)Angriffe macht.
- **Set-Cookie-Kopfzeile**: Wenn Sie eine Webseite besuchen, kann der Server in der HTTP-Antwort eine Set-Cookie-Kopfzeile senden. Diese weist Ihren Browser an, ein Cookie mit bestimmten Informationen zu speichern. Zum Beispiel könnte eine eindeutige ID gespeichert werden, die der Seite hilft, Sie beim nächsten Besuch wiederzuerkennen.
Sie können ein Cookie manuell in JavaScript mit `document.cookie` setzen:

```js
document.cookie = "organization=freeCodeCamp; expires=Fri, 31 Dec 2021 23:59:59 GMT; path=/";
```

Um ein Cookie zu löschen, können Sie sein Ablaufdatum auf eine Zeit in der Vergangenheit setzen.

## Cache API

- **Definition**: Caching ist der Prozess, Kopien von Dateien an einem temporären Speicherort abzulegen, damit sie schneller abgerufen werden können. Die Cache API wird verwendet, um Netzwerk-Anfragen und -Antworten zu speichern, wodurch Webanwendungen effizienter arbeiten und sogar offline funktionieren können. Sie ist Teil der umfassenderen Service Worker API und entscheidend für die Erstellung von Progressive Web Apps (PWAs), die auch bei unzuverlässigen oder langsamen Netzwerkverbindungen funktionieren.
Die Cache API ist ein Speichersystem, das Request- und Response-Objekte speichert. Wenn eine Anfrage an einen Server gesendet wird, kann die Anwendung die Antwort speichern und später aus dem Cache abrufen, anstatt eine neue Netzwerk-Anfrage zu stellen. Das reduziert Ladezeiten, spart Bandbreite und verbessert die Nutzererfahrung.
- **Cache-Speicher**: Dieser wird verwendet, um Schlüssel-Wert-Paare von HTTP-Anfragen und deren zugehörigen Antworten zu speichern. Dadurch können zuvor angeforderte Ressourcen effizient abgerufen werden, ohne sie bei späteren Besuchen erneut aus dem Netzwerk laden zu müssen, was die Leistung verbessert.
- **Cache-Control**: Entwickler können definieren, wie lange eine zwischengespeicherte Ressource aufbewahrt werden soll und ob sie neu validiert oder direkt aus dem Cache ausgeliefert wird.
- **Offline-Unterstützung**: Durch die Verwendung der Cache API können Sie Offline-First-Webanwendungen erstellen. Zum Beispiel kann eine PWA zwischengespeicherte Ressourcen bereitstellen, wenn der Nutzer keine Netzwerkverbindung hat.

## Negative Muster und clientseitiger Speicher

- **Übermäßiges Tracking**: Dies bezeichnet die Praxis, eine übermäßige Menge an Nutzerdaten im clientseitigen Speicher (wie Cookies, Local Storage oder Session Storage) ohne klare, informierte Zustimmung oder legitimen Bedarf zu sammeln und zu speichern. Dabei wird oft das Verhalten, die Vorlieben und Interaktionen der Nutzer über mehrere Seiten oder Sitzungen hinweg verfolgt, was die Privatsphäre der Nutzer beeinträchtigen kann.
- **Browser-Fingerprinting**: Eine Technik, mit der einzelne Nutzer anhand einzigartiger Merkmale ihres Geräts und Browsers identifiziert und verfolgt werden, ohne auf Cookies oder andere traditionelle Tracking-Methoden zurückzugreifen. Im Gegensatz zu Cookies, die lokal auf dem Gerät gespeichert werden, sammelt Fingerprinting eine Vielzahl von Informationen, um einen unverwechselbaren „Fingerabdruck“ der Browsersitzung zu erstellen.
- **Passwörter im LocalStorage speichern**: Dies mag wie ein offensichtliches negatives Muster erscheinen, aber das Speichern sensibler Daten wie Passwörter im Local Storage stellt ein Sicherheitsrisiko dar. Local Storage ist nicht verschlüsselt und kann leicht ausgelesen werden. Daher sollten Sie niemals sensible Daten dort speichern.

## IndexedDB

- **Definition**: IndexedDB wird verwendet, um strukturierte Daten im Browser zu speichern. Es ist in modernen Webbrowsern integriert und ermöglicht Webanwendungen, JavaScript-Objekte effizient zu speichern und abzurufen.

## Cache-/Service Worker

- **Definition**: Ein Service Worker ist ein Skript, das im Hintergrund läuft und von Ihrer Webseite getrennt ist. Er kann Netzwerk-Anfragen abfangen, auf den Cache zugreifen und die Webanwendung offline funktionsfähig machen. Dies ist eine Schlüsselkomponente von Progressive Web Apps.

## Grundlagen der Arbeit mit Klassen

- **Definition**: Klassen in JavaScript werden verwendet, um Baupläne für die Erstellung von Objekten und die Kapselung von Daten zu definieren. Klassen enthalten einen Konstruktor, eine spezielle Methode, die automatisch aufgerufen wird, wenn ein neues Objekt aus der Klasse erstellt wird. Sie dient dazu, die Eigenschaften des Objekts zu initialisieren. Das `this` Schlüsselwort wird hier verwendet, um auf die aktuelle Instanz der Klasse zu verweisen. Unterhalb des Konstruktors können Methoden definiert werden. Methoden sind Funktionen, die innerhalb einer Klasse definiert sind und Aktionen oder Operationen auf den Daten oder dem Zustand der Klasse ausführen. Sie definieren das Verhalten, das Instanzen der Klasse ausführen können.

:::interactive_editor

```js
class Dog {
  constructor(name) {
    this.name = name;
  }

  bark() {
    console.log(`${this.name} says woof!`);
  }
}

const dog = new Dog("Gino");
console.log(dog.name);  // Gino
```

:::

Um eine neue Instanz der Klasse zu erstellen, verwenden Sie das Schlüsselwort `new` gefolgt vom Klassennamen.

Sie können Klassen auch als Klassen-Ausdrücke erstellen. Dabei ist die Klasse anonym und wird einer Variablen zugewiesen.

## Klassenvererbung

- **Definition**: In der Programmierung ermöglicht Vererbung, Klassen zu definieren, die Eigenschaften und Methoden von Elternklassen übernehmen. Dies fördert die Wiederverwendung von Code und stellt eine hierarchische Beziehung zwischen Klassen her. Eine Elternklasse ist eine Klasse, die als Vorlage für andere Klassen dient. Sie definiert Eigenschaften und Methoden, die von anderen Klassen geerbt werden. Eine Kindklasse ist eine Klasse, die die Eigenschaften und Methoden einer anderen Klasse erbt. Kindklassen können die Funktionalität ihrer Elternklassen erweitern, indem sie neue Eigenschaften und Methoden hinzufügen. In JavaScript verwenden wir das `extends` Schlüsselwort, um Vererbung zu implementieren. Dieses Schlüsselwort zeigt an, dass eine Klasse die Kindklasse einer anderen Klasse ist.

Das `super` Schlüsselwort wird verwendet, um auf die Methoden, Konstruktoren und Felder der Elternklasse zuzugreifen.

:::interactive_editor

```js
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  constructor(brand, year, numDoors) {
    super(brand, year);
    this.numDoors = numDoors;
  }
}

const myCar = new Car("freeCodeCamp Motors", 2019, 4);
console.log(myCar.brand);  // freeCodeCamp Motors
console.log(myCar.year);  // 2019
console.log(myCar.numDoors);  // 4
```

:::

## Arbeiten mit statischen Methoden und statischen Eigenschaften

- **Statische Methoden**: Diese Methoden werden oft für Hilfsfunktionen verwendet, die keinen Zugriff auf den spezifischen Zustand eines Objekts benötigen. Sie werden innerhalb von Klassen definiert, um zusammengehörige Funktionalität zu kapseln.

Verwenden Sie das Schlüsselwort `static`, um eine statische Methode zu definieren und rufen Sie sie auf der Klasse selbst auf.

Statische Methoden sind auch hilfreich, um „Factory“-Methoden zu implementieren. Eine Factory-Methode ist eine Methode, die zusätzlich zum Konstruktor definiert wird, um Objekte basierend auf bestimmten Kriterien zu erstellen.

- **Statische Eigenschaften**: Diese Eigenschaften definieren Werte oder Attribute, die mit der Klasse selbst verbunden sind und nicht mit Instanzen der Klasse. Statische Eigenschaften werden von allen Instanzen der Klasse geteilt und können ohne Erstellung einer Instanz der Klasse aufgerufen werden.

Zum Beispiel definiert `static numberOfWheels = 4;` eine statische Eigenschaft innerhalb einer Klasse.

- Rekursion ist ein Programmierkonzept, das es Ihnen ermöglicht, eine Funktion wiederholt aufzurufen, bis ein Basisfall erreicht ist.

Hier ist ein Beispiel für eine rekursive Funktion, die die Fakultät einer Zahl berechnet:

```js
function findFactorial(n) {
  if (n === 0) {
    return 1;
  }
  return n * findFactorial(n - 1);
}
```

Im obigen Beispiel wird die `findFactorial`-Funktion rekursiv aufgerufen, bis `n` `0` erreicht. Wenn `n` `0` ist, wird der Basisfall erreicht und die Funktion gibt `1` zurück. Die Funktion gibt dann das Produkt von `n` und dem Ergebnis des rekursiven Aufrufs von `findFactorial(n - 1)` zurück.

- Rekursion ermöglicht es Ihnen, etwas mit unbekannter Tiefe zu verarbeiten, wie zum Beispiel tief verschachtelte Objekte/Arrays oder einen Dateibaum.
- Ein Aufrufstapel wird verwendet, um die Funktionsaufrufe in einer rekursiven Funktion zu verfolgen. Jedes Mal, wenn eine Funktion aufgerufen wird, wird sie dem Aufrufstapel hinzugefügt. Wenn der Basisfall erreicht ist, werden die Funktionsaufrufe aus dem Stapel entfernt.
- Sie sollten den Basisfall sorgfältig definieren, da ein unendliches Aufrufen dazu führen kann, dass Ihr Code abstürzt. Das liegt daran, dass die Rekursion immer mehr Funktionsaufrufe anhäuft, bis das System keinen Speicher mehr hat.
- Rekursionen werden verwendet, um mathematische Probleme wie Fakultät und Fibonacci zu lösen, Bäume und Graphen zu durchlaufen, Permutationen und Kombinationen zu erzeugen und vieles mehr.

## Algorithmen und Big-O-Notation

- **Algorithmen**: Eine Reihe eindeutiger Anweisungen zur Lösung eines Problems oder zur Durchführung einer Aufgabe. Algorithmen müssen in einer endlichen Anzahl von Schritten abgeschlossen sein, und jeder Schritt muss präzise und eindeutig sein.

- **Big-O-Notation**: Beschreibt die Worst-Case-Leistung oder das Wachstum eines Algorithmus, wenn die Eingabegröße zunimmt. Sie konzentriert sich darauf, wie der Ressourcenverbrauch mit der Eingabegröße wächst, und ignoriert konstante Faktoren und niedrigere Ordnungstermen.

### Häufige Zeitkomplexitäten

- **O(1) – konstante Zeit**: Der Algorithmus benötigt unabhängig von der Eingabegröße immer die gleiche Zeit.

- **O(log n) – logarithmische Zeit**: Die Zeit wächst langsam mit der Eingabegröße. Häufig bei Algorithmen, die die Problemgröße wiederholt um einen Bruchteil reduzieren (wie binäre Suche).

- **O(n) – lineare Zeit**: Die Laufzeit wächst proportional zur Eingabegröße.

- **O(n log n) – log-lineare Zeit**: Häufige Zeitkomplexität effizienter Sortieralgorithmen wie Merge Sort und Quick Sort.

- **O(n²) – quadratische Zeit**: Die Laufzeit wächst quadratisch. Oft bei verschachtelten Schleifen.

### Speicherkomplexität

- **O(1) – konstanter Speicher**: Der Algorithmus verwendet unabhängig von der Eingabegröße immer denselben Speicher.
- **O(n) – linearer Speicher**: Der Speicherverbrauch wächst proportional zur Eingabegröße.
- **O(n²) – quadratischer Speicher**: Der Speicherverbrauch wächst quadratisch mit der Eingabegröße.

## Problemlösungstechniken

- **Problem verstehen**: Lesen Sie die Problemstellung mehrmals. Identifizieren Sie die Eingabe, die erwartete Ausgabe und wie die Eingabe in die Ausgabe umgewandelt wird.

- **Pseudocode**: Eine sprachunabhängige, hochrangige Beschreibung der Algorithmuslogik. Verwendet eine Mischung aus gebräuchlicher Schriftsprache und Programmierkonstrukten wie `IF`, `ELSE`, `FOR`, `WHILE`.

- **Randfälle**: Spezifische, gültige Eingaben, die an den Grenzen dessen auftreten, was ein Algorithmus verarbeiten soll. Berücksichtigen und testen Sie immer Randfälle.

## Arrays

- **Statische Arrays**: Haben eine feste Größe, die bei der Initialisierung bestimmt wird. Elemente werden an benachbarten Speicherstellen gespeichert. Die Größe kann während der Programmausführung nicht geändert werden.

- **Dynamische Arrays**: Können während der Programmausführung automatisch wachsen oder schrumpfen. Die Größenänderung erfolgt durch automatisches Kopieren in größere Arrays, wenn nötig.

### Implementierung dynamischer Arrays in JavaScript

JavaScript-Arrays sind dynamische Arrays. Sie können Elemente über den Index zugreifen und aktualisieren, Elemente mit `push()` hinzufügen und mit `pop()` oder `splice()` entfernen.

### Zeitkomplexitäten für dynamische Arrays

- **Zugriff**: O(1)
- **Einfügen am Ende**: O(1) im Durchschnitt, O(n) bei Größenänderung
- **Einfügen in der Mitte**: O(n)
- **Löschen**: O(n) in der Mitte, O(1) am Ende

## Stacks

- **Stacks**: Last-In, First-Out (LIFO) Datenstruktur. Elemente werden nur oben hinzugefügt und entfernt.

- **Push-Operation**: Ein Element oben auf den Stack legen. Zeitkomplexität: O(1).

- **Pop-Operation**: Ein Element oben vom Stack entfernen. Zeitkomplexität: O(1).

Ein JavaScript-Array kann als Stack dienen, indem Sie `push()` zum Hinzufügen und `pop()` zum Entfernen von Elementen verwenden.

## Queues

- **Queues**: First-In, First-Out (FIFO) Datenstruktur. Elemente werden hinten hinzugefügt und vorne entfernt.

- **Enqueue-Operation**: Ein Element hinten in die Queue einfügen. Zeitkomplexität: O(1).

- **Dequeue-Operation**: Ein Element vorne aus der Queue entfernen. Zeitkomplexität: O(1).

Ein Array kann eine Queue demonstrieren, indem Sie `push()` zum Einreihen und `shift()` zum Ausreihen verwenden. Allerdings benötigt `shift()` O(n)-Zeit, da die verbleibenden Elemente verschoben werden müssen.

## Verkettete Listen

- **Verkettete Listen**: Lineare Datenstruktur, bei der jeder Knoten Daten und eine Referenz auf den nächsten Knoten enthält. Knoten sind wie eine Kette verbunden.

### Einfach verkettete Listen

- **Struktur**: Jeder Knoten hat Daten und eine Referenz auf den nächsten Knoten.
- **Durchlaufen**: Kann nur vorwärts vom Kopf bis zum Ende gehen.
- **Kopf-Knoten**: Erster Knoten in der Liste, normalerweise der einzige direkt zugängliche Knoten.
- **End-Knoten**: Letzter Knoten in der Liste, zeigt auf `null`.

### Operationen und Zeitkomplexitäten

- **Einfügen am Anfang**: O(1)
- **Einfügen am Ende**: O(n) – muss bis zum Ende durchlaufen
- **Einfügen in der Mitte**: O(n) – muss bis zur Position durchlaufen
- **Löschen am Anfang**: O(1)
- **Löschen am Ende**: O(n) – muss vorherigen Knoten finden
- **Löschen in der Mitte**: O(n) – muss Knoten finden

### Doppelt verkettete Listen

- **Struktur**: Jeder Knoten hat Daten und zwei Referenzen: auf den nächsten und den vorherigen Knoten.
- **Durchlaufen**: Kann in beide Richtungen gehen.
- **Speicher**: Benötigt mehr Speicher als einfach verkettete Listen wegen der zusätzlichen Referenz.

## Wann welche Datenstruktur verwenden

- **Arrays (dynamische Arrays)**: Wenn Sie geordneten, indizierten Zugriff benötigen und die Größe nicht im Voraus kennen
- **Stacks**: Für LIFO-Operationen (Rückgängig-Funktion, Ausdrucksauswertung, Backtracking)
- **Queues**: Für FIFO-Operationen (Aufgabenplanung, Breitensuche)
- **Verkettete Listen**: Wenn häufiges Einfügen/Löschen am Anfang, unbekannte Größe, kein direkter Zugriff benötigt wird

## Suchalgorithmen

Suchalgorithmen ermöglichen es Ihnen, in einer bestimmten Liste von Elementen nach einem Ziel zu suchen.

In der Informatik gibt es zwei Suchalgorithmen, die Sie kennen sollten. Das sind die **lineare Suche** und die **binäre Suche**. Es ist wichtig, die Unterschiede zwischen diesen beiden Algorithmen zu verstehen und zu wissen, wann welcher Algorithmus verwendet wird.

### Lineare Suche

- Die lineare Suche iteriert durch ein Array von Elementen und prüft jedes Element von Anfang an, bis das Ziel gefunden wird.
- Wenn das Ziel gefunden wird, wird der Index zurückgegeben, an dem es sich im Array befindet.
- Wenn das Ziel nicht gefunden wird, gibt sie `-1` zurück, was in JavaScript **ungültiger Index** bedeutet.
- Da die lineare Suche jedes Element überprüft, bis das Ziel gefunden wird, ist sie bei großen Arrays nicht effizient.
- Die Zeitkomplexität der linearen Suche ist `O(n)`, weil die Zeit, die zum Durchsuchen des Arrays benötigt wird, linear mit der Größe des Arrays wächst.
- Die Speicherkomplexität der linearen Suche ist `O(1)`, weil kein zusätzlicher Speicher zum Durchsuchen des Arrays benötigt wird.

### Binäre Suche

- Die binäre Suche funktioniert, indem sie ein Array von Elementen halbiert und prüft, ob sich der Zielwert in der Mitte des Arrays befindet.
- Die Voraussetzung für die binäre Suche ist, dass die Elemente im Array sortiert sein müssen, entweder aufsteigend oder absteigend.
- Die binäre Suche ist ein effizienterer Algorithmus für die Suche in großen Arrays, weil sie das Array halbiert und jede Hälfte ignoriert, in der das Ziel nicht gefunden wird.
- Wenn das Ziel in der Mitte des Arrays gefunden wird, wird der Index des Ziel-Elements zurückgegeben.
- Wenn das Element nicht gefunden wird, prüft der Algorithmus, ob sich das Ziel im linken oder rechten Teil des Arrays befindet.
- Er teilt die verbleibenden Teile des Arrays weiterhin in Hälften, bis das Ziel gefunden wird.
- Wenn das Ziel nicht im Array gefunden wird, gibt er `-1` zurück.
- Die Zeitkomplexität der binären Suche ist `O(log n)`, weil die Zeit, die zum Durchsuchen des Arrays benötigt wird, logarithmisch mit der Größe des Arrays wächst.
- Die Speicherkomplexität der binären Suche ist `O(1)`, weil kein zusätzlicher Speicher zum Durchsuchen des Arrays benötigt wird.

### Wie sich die lineare Suche von der binären Suche unterscheidet

- Die binäre Suche ist für große Arrays besser geeignet als die lineare Suche.
- Die Zeitkomplexität der linearen Suche ist `O(n)`, weil die Zeit, die zum Durchsuchen des Arrays benötigt wird, linear mit der Größe des Arrays wächst.
- Die Zeitkomplexität der binären Suche ist `O(log n)`, weil die Zeit, die zum Durchsuchen des Arrays benötigt wird, logarithmisch mit der Größe des Arrays wächst.

## Sortieralgorithmen und Divide-and-Conquer

In der Informatik ist Divide-and-Conquer eine Technik, mit der ein Problem in kleinere Teilprobleme zerlegt wird, damit diese leichter zu lösen sind. Rekursion ist die Technik, die oft bei Divide-and-Conquer eingesetzt wird, und Divide-and-Conquer ist eine mächtige Strategie, die verwendet wird, um viele effiziente Sortieralgorithmen wie Merge Sort zu implementieren.

### Merge Sort

- Merge Sort ist ein Sortieralgorithmus, der dem Divide-and-Conquer-Ansatz folgt.
- Er funktioniert, indem er ein Array rekursiv in kleinere Teilarrays aufteilt, bis jedes Teilarray nur noch ein Element enthält.
- Dann werden die Teilarrays wiederholt in sortierter Reihenfolge zusammengeführt.
- Die Zeitkomplexität von Merge Sort ist `O(n log n)`, weil das Array kontinuierlich halbiert `(log n)` und dann wieder zusammengeführt `(O(n))` wird.
- Die Speicherkomplexität von Merge Sort ist `O(n)`, weil es kein In-Place-Sortieralgorithmus ist.

## Überblick über Graphen

Ein Graph ist eine Menge von Knoten (Vertices), die durch Kanten (Verbindungen) verbunden sind. Jeder Knoten kann mit mehreren anderen Knoten verbunden sein und bildet so ein Netzwerk. Die verschiedenen Arten von Graphen umfassen:

- **Gerichtet**: Kanten haben eine Richtung (von einem Knoten zu einem anderen), oft dargestellt mit geraden Linien und Pfeilen.
- **Ungerichtet**: Kanten haben keine Richtung, dargestellt mit einfachen Linien.
- **Knoten mit Bezeichnung**: Jeder Knoten ist mit einer Bezeichnung oder einem Identifikator verbunden.
- **Zyklisch**: Enthält Zyklen (ein Pfad, der am selben Knoten beginnt und endet).
- **Gerichteter azyklischer Graph (DAG)**: Ein gerichteter Graph ohne Zyklen.
- **Kanten mit Bezeichnung**: Jede Kante hat eine Bezeichnung, die normalerweise neben der entsprechenden Kante gezeichnet wird.
- **Gewichtet**: Kanten haben Gewichte (Werte), die für arithmetische Operationen verwendet werden können.
- **Getrennt**: Enthält zwei oder mehr Gruppen von Knoten (Komponenten), die durch keine Kanten verbunden sind. Zwei Knoten können keine direkte Kante haben und dennoch einen Pfad zwischen ihnen besitzen.

Graphen werden in verschiedenen Anwendungen verwendet, wie Karten, Netzwerken, Empfehlungssystemen und der Auflösung von Abhängigkeiten.

## Graphdurchläufe

Dabei werden alle Knoten eines Graphen besucht. Die zwei Hauptalgorithmen sind:

- **Breitensuche (BFS)**: Besucht alle benachbarten Knoten, bevor es zur nächsten Ebene im Graphen übergeht.
  - **Warteschlange**: Verwendet eine Warteschlange (FIFO). Der Startknoten wird als besucht markiert und zur Warteschlange hinzugefügt. Solange die Warteschlange nicht leer ist, wird der aktuelle Knoten aus der Warteschlange entfernt, und jeder seiner unbesuchten Nachbarn wird als besucht markiert und zur Warteschlange hinzugefügt.
  - **Kürzester Pfad**: Findet den kürzesten Pfad in ungewichteten Graphen.
  - **Speicher**: Erfordert das Speichern einer Warteschlange im Speicher, daher können die Speicheranforderungen beträchtlich sein, besonders bei Graphen mit vielen Knoten auf derselben Ebene.
  - **Zusammenhängende Komponenten**: Kann auch verwendet werden, um zusammenhängende Graphkomponenten zu finden, indem eine neue Suche von jedem Knoten gestartet wird, der noch nicht besucht wurde.
  - **Zustandsraumsuche**: Verwendet eine Warteschlange, um verschiedene Zustände zu verfolgen, während die Kombinationen von runden Klammern aufgebaut werden. Jeder Zustand wird als Array dargestellt, das den aktuellen aufgebauten String, die Anzahl der bisher verwendeten öffnenden runden Klammern und die Anzahl der bisher verwendeten schließenden runden Klammern enthält. Eine öffnende runde Klammer kann nur hinzugefügt werden, wenn die Anzahl der verwendeten öffnenden Klammern kleiner ist als die Anzahl der Paare. Eine schließende runde Klammer kann nur hinzugefügt werden, wenn das Gleichgewicht erhalten bleibt, das heißt, es müssen mehr öffnende als schließende Klammern verwendet worden sein.

- **Tiefensuche (DFS)**: Verfolgt jeden Zweig so tief wie möglich, bevor es zurückkehrt.
  - **Stapel**: Verwendet einen Stapel (LIFO) oder Rekursion. Der Startknoten wird als besucht markiert und zum Stapel hinzugefügt. Solange der Stapel nicht leer ist, wird der aktuelle Knoten vom Stapel entfernt, und seine unbesuchten Nachbarn werden als besucht markiert und zum Stapel hinzugefügt.
  - **Speicher**: Erfordert das Speichern eines Stapels (oder des Funktionsaufrufstapels bei Verwendung von Rekursion) im Speicher, daher können die Speicheranforderungen bei Graphen mit sehr langen Pfaden wachsen.
  - **Anwendungsfälle**: Nützlich für Zykluserkennung, Pfadsuche und das Finden zusammenhängender Komponenten.
  - **Einschränkung**: Es ist nicht immer garantiert, den kürzesten Pfad zwischen zwei Knoten in einem ungewichteten Graphen zu finden.

## Graphdarstellungen

Graphen können auf zwei Hauptarten dargestellt werden:

- **Adjazenzliste**: Jeder Knoten hat eine Liste seiner Nachbarn.
  - **Implementierungen**: Als Array, wobei jeder Index einen Knoten darstellt und das an diesem Index gespeicherte Array seine Nachbarn enthält. Als Objekt (oder `Map`), wobei jeder Schlüssel einen Knoten darstellt und der zugehörige Wert (ein Array) seine Nachbarn enthält.
  - **Speicher**: Speicherplatzsparend für dünn besetzte Graphen mit einer Raumkomplexität von `O(V + E)`, wobei `V` die Anzahl der Knoten und `E` die Anzahl der Kanten ist.
  - **Nachbarn**: Einfaches Durchlaufen der Nachbarn, da diese Operation nur den Zugriff auf die Liste des Knotens erfordert.
  - **Kantenabfrage**: Weniger effizient als Adjazenzmatrizen, um zu bestimmen, ob eine Kante zwischen zwei Knoten existiert. Normalerweise benötigt es `O(deg(v))` Zeit, wobei `deg(v)` die Anzahl der Nachbarn des überprüften Knotens ist, und im schlimmsten Fall kann es `O(V)` sein.
  - **Am besten geeignet für**: Üblicherweise die bevorzugte Wahl für reale Szenarien, in denen dünn besetzte Graphen häufiger vorkommen.

- **Adjazenzmatrix**: Ein 2D-Array, bei dem Zeilen und Spalten Knoten darstellen.
  - **Werte**: Wenn der Graph ungewichtet ist, bedeutet ein Wert von `1`, dass eine Kante diese Knoten verbindet, während ein Wert von `0` bedeutet, dass keine Kante zwischen ihnen besteht. Wenn der Graph gewichtet ist, repräsentiert der Wert das Gewicht der Kante, die die Knoten verbindet.
  - **Selbstschleifen**: Die Werte auf der Diagonale zeigen an, ob jeder Knoten eine Selbstschleife hat, also eine Kante, die den Knoten mit sich selbst verbindet.
  - **Speicher**: Speicherintensiv für große Graphen mit einem großen quadratischen Speicherbedarf von `O(V²)`, wobei `V` die Anzahl der Knoten im Graphen ist.
  - **Kantenabfrage**: Schnell, um zu prüfen, ob eine Kante zwischen zwei Knoten existiert, da dies konstante Zeit `O(1)` benötigt.
  - **Nachbarn**: Ineffizient, um die Nachbarn eines Knotens zu finden, da das Programm die gesamte Zeile oder Spalte durchlaufen muss. Im schlimmsten Fall dauert dies `O(V)`.
  - **Am besten geeignet für**: Hilfreich für dichte Graphen mit vielen Kanten. Es ist ineffizient für dünn besetzte Graphen, die nur wenige Kanten haben.

## Algorithmus für den kürzesten Pfad

- **Algorithmus für den kürzesten Pfad**: Berechnet den kürzesten Pfad zwischen Knoten in einem gewichteten Graphen und gibt sowohl die Distanzen als auch die zurückgelegten Routen zurück.
  - **Adjazenzmatrix**: Jeder Wert repräsentiert das Gewicht (die Distanz) der Kante zwischen zwei Knoten.
  - **Fehlende Kanten**: Ein Wert von `INF` (`Infinity`) bedeutet, dass keine direkte Kante existiert.
  - **Distanzen**: Ein Array, das die kürzeste bekannte Distanz vom Startknoten zu jedem anderen Knoten verfolgt. Zu Beginn wird angenommen, dass jeder Knoten unendlich weit entfernt ist, und die Distanz vom Startknoten zu sich selbst ist immer `0`.
  - **Routen**: Eine Liste, bei der jeder Eintrag ein Array von Knotenindizes ist, das die Route darstellt, die zum Erreichen jedes Knotens genommen wurde.
  - **Besucht**: Ein Array, das verfolgt, welche Knoten bereits verarbeitet wurden, damit Sie sie nicht erneut besuchen.
  - **Nächster unbesuchter Knoten**: Die Hauptschleife läuft einmal für jeden Knoten im Graphen und wählt jedes Mal den nächstgelegenen unbesuchten Knoten aus.
  - **Kanten-Relaxation**: Für jeden Nachbarn mit einer tatsächlichen Kante, der noch nicht besucht wurde, prüfen Sie, ob Sie ihn effizienter über den aktuellen Knoten erreichen können. Wenn die neue Distanz besser ist als die bereits gespeicherte, aktualisieren Sie die Distanz und die Route.
  - **Unerreichbare Knoten**: Wenn kein gültiger Knoten gefunden wird, sind alle verbleibenden Knoten unerreichbar, sodass die Schleife frühzeitig stoppt.
  - **Optionales Ziel**: Der Parameter `targetNode` ist optional. Wenn er nicht angegeben wird, berechnet die Funktion die kürzesten Pfade vom `startNode` zu allen anderen Knoten im Graphen.

## Bäume

Ein Baum ist eine spezielle Art von Graph, der azyklisch und zusammenhängend ist. Wichtige Eigenschaften sind:

- **Azyklisch**: Ein Baum hat keine Schleifen oder Zyklen (Pfade, bei denen Start- und Endknoten gleich sind).
- **Zusammenhängend**: Jeder Knoten ist von jedem anderen Knoten aus erreichbar.

### Baum-Terminologie

- **Wurzelknoten**: Die oberste Ebene eines Baums. Es ist der einzige Knoten im Baum ohne Elternknoten.
- **Elternknoten**: Ein Knoten, der unmittelbar mit anderen Knoten darunter verbunden ist.
- **Kindknoten**: Ein Knoten, der unmittelbar mit einem Knoten darüber verbunden ist.
- **Blatt**: Ein Knoten ohne Kindknoten.
- **Tiefe**: Die Länge des Pfads von der Wurzel zu diesem Knoten.
- **Höhe**: Die Länge des Pfads von diesem Knoten bis zu einem Blatt. Die Höhe eines Baums ist die Höhe seines Wurzelknotens.
- **Grad**: Die Anzahl der Kindknoten, die jeder Knoten hat.
- **Teilbaum**: Ein Abschnitt eines Baums, der selbst ein Baum ist.
- **Ausgeglichener Baum**: Ein Baum, bei dem die Höhen der linken und rechten Teilbäume jedes Knotens sehr ähnlich sind, um sicherzustellen, dass Operationen effizient bleiben.

### Häufige Baumtypen

Die häufigsten Baumtypen sind:

- **Binäre Bäume**: Jeder Knoten hat höchstens zwei Kinder, ein linkes und ein rechtes Kind.

- **Binäre Suchbäume (BST)**: Ein binärer Baum, bei dem für jeden Knoten alle Werte im linken Teilbaum kleiner sind als der Wert des Knotens und alle Werte im rechten Teilbaum größer sind als der Wert des Knotens. Die linken und rechten Teilbäume müssen ebenfalls binäre Suchbäume sein.

- **Selbstbalancierende Bäume**: Bäume, die zusätzliche interne Logik enthalten, die den Baum neu ausbalanciert, wenn Einfügungen oder Löschungen einen Zustand der Unausgeglichenheit erzeugen. Häufige Beispiele sind AVL-Bäume, Rot-Schwarz-Bäume und B-Bäume.

- **AVL-Bäume**: Ein Typ selbstbalancierender binärer Suchbäume, bei dem die Höhen der linken und rechten Teilbäume jedes Knotens höchstens um eins differieren.

- **Rot-Schwarz-Bäume**: Ein Typ selbstbalancierender binärer Suchbäume, bei dem jeder Knoten rot oder schwarz gefärbt ist.

- **B-Bäume**: Ein Typ selbstbalancierender Bäume, bei dem jeder Knoten mehrere Schlüssel und mehr als zwei Kindknoten haben kann.

## Tries

- **Tries**: Auch Präfixbäume genannt, werden verwendet, um Mengen von Strings zu speichern, wobei jeder Knoten ein Zeichen darstellt.
- **Wurzelknoten**: Der Wurzelknoten stellt kein bestimmtes Zeichen dar, man kann ihn als leeren String betrachten.
- **Präfixe**: Wenn Sie den Trie vom Wurzelknoten aus durchlaufen, definiert der Pfad zu einem Knoten ein bestimmtes Präfix.
- **Ende-Wort-Markierungen**: Knoten, die vollständige Wörter darstellen, erhalten Ende-Wort-Markierungen.
- **Geteilte Präfixe**: Wenn mehrere Strings dasselbe Präfix teilen, überlappen sich ihre Pfade, sodass das Präfix nur einmal gespeichert wird. Das macht Tries effizient für Aufgaben wie Autovervollständigung und Rechtschreibprüfung.
- **Einfügen**: Erfordert nur das Erstellen neuer Knoten für die Zeichen, die im Trie noch nicht existieren.
- **Zeitkomplexität**: Such- und Einfügeoperationen benötigen `O(L)` Zeit, wobei `L` die Länge des Strings ist.
- **Speicher**: Tries können ineffizient sein, wenn die Menge der Strings viele einzigartige Zeichen enthält, da dies das Speichern vieler einzigartiger Zeichen als einzelne Knoten erfordert.

## Prioritätswarteschlangen

- **Prioritätswarteschlange**: Ein abstrakter Datentyp, bei dem jedes Element eine Priorität hat.
- **Warteschlangen und Stapel**: Warteschlangen und Stapel berücksichtigen nur die Einfügereihenfolge, während Prioritätswarteschlangen die Priorität der Elemente berücksichtigen. Standardwarteschlangen folgen FIFO (First In First Out) und Stapel folgen LIFO (Last In First Out).
- **Entfernungsreihenfolge**: Üblicherweise wird das Element mit der höchsten Priorität zuerst entfernt, aber einige Implementierungen können auch das Element mit der niedrigsten Priorität zuerst entfernen.
- **Gleichstände**: Wenn Elemente mit derselben Priorität in der Reihenfolge entfernt werden sollen, in der sie eingefügt wurden, können Sie einen eindeutigen Zähler hinzufügen, um Gleichstände zu brechen.
- **Anwendungen**: Finden des kürzesten Pfads zwischen zwei Orten, Planung von Aufgaben in Betriebssystemen, Simulation von Verkehr, Datenkompression und Netzwerkverwaltung.

## Heaps

Ein Heap ist eine spezialisierte baumbasierte Datenstruktur mit einer sehr spezifischen Eigenschaft, der Heap-Eigenschaft.

Die Heap-Eigenschaft bestimmt die Beziehung zwischen Eltern- und Kindknoten. Es gibt zwei Arten von Heaps:

- **Max-Heap**: Der Wert jedes Elternknotens ist größer oder gleich den Werten seiner Kinder, und das größte Element befindet sich an der Wurzel.

- **Min-Heap**: Der Wert jedes Elternknotens ist kleiner oder gleich den Werten seiner Kinder, und das kleinste Element befindet sich an der Wurzel.

JavaScript hat kein eingebautes Heap-Modul, aber Sie können einen Min-Heap mit einem Array implementieren.

- **Array-Speicherung**: Heaps werden typischerweise als Arrays implementiert, um effizient auf Eltern- und Kindknoten zuzugreifen. Wenn der Heap die Struktur eines vollständigen binären Baums beibehält, erfordert die Array-Implementierung nur einfache mathematische Operationen basierend auf den Indizes, um zu bestimmen, wo sich die Elemente befinden.
- **Indizes**: Für den Knoten am Index `i` befindet sich der Elternknoten am Index `Math.floor((i - 1) / 2)`, das linke Kind am Index `2 * i + 1` und das rechte Kind am Index `2 * i + 2`.
- **Peek**: Das Abrufen des Minimums oder Maximums (je nach Heap-Typ), ohne es zu entfernen.
- **Push**: Fügt ein Element an der richtigen Stelle hinzu, um die Heap-Eigenschaft zu bewahren. Das neue Element wird am Ende des Arrays hinzugefügt und dann nach oben bewegt, indem es mit seinem Elternknoten getauscht wird, bis die Heap-Eigenschaft wiederhergestellt ist (Bubble-up).
- **Pop**: Entfernt das Element mit der höchsten Priorität (in diesem Fall den kleinsten Wert). Das letzte Element des Arrays ersetzt die Wurzel und wird dann nach unten bewegt, indem es mit seinem kleineren Kind getauscht wird, bis die Heap-Eigenschaft wiederhergestellt ist (Bubble-down).
- **PushPop**: Kombiniert beide Operationen in einem Aufruf. Dies ist effizienter als sie nacheinander aufzurufen, besonders wenn der Heap groß ist, da nur eine Umordnung durchgeführt wird.
- **Heapify**: Wandelt ein bestehendes Array in einen Heap um.
- **Vergleichs-Callback**: Arrays werden in JavaScript nicht automatisch elementweise für die Ordnung verglichen, daher übergeben Sie dem Heap eine Vergleichsfunktion, die zuerst die Prioritäten vergleicht, z. B. `new MinHeap((a, b) => a[0] - b[0])` für Elemente, die als `[priority, element]` gespeichert sind. Niedrigere Werte bedeuten höhere Prioritäten.
- **Stabile Gleichstandauflösung**: Fügen Sie einen zunehmenden Einfügezähler als zweites Element jedes Eintrags hinzu, z. B. `[priority, counter, element]`. Vergleichen Sie zuerst die Prioritäten und dann die Zähler, wenn die Prioritäten gleich sind: `new MinHeap((a, b) => (a[0] - b[0]) || (a[1] - b[1]))`.
- **Zeitkomplexität**: Einfügen und Extrahieren des Minimums oder Maximums ist `O(log n)`, Peek ist `O(1)`, Heapify ist `O(n)`, und das Suchen oder Löschen eines beliebigen Elements ist `O(n)`.
- **Speicherkomplexität**: `O(n)`, wobei `n` die Anzahl der Elemente im Heap ist.

## Einführung in dynamische Programmierung

- **Definition**: Dynamische Programmierung ist eine algorithmische Technik, die komplexe Probleme löst, indem sie in einfachere Teilprobleme zerlegt werden und die Ergebnisse gespeichert werden, um redundante Berechnungen zu vermeiden.
- **Überlappende Teilprobleme**: Dieselben kleineren Probleme treten mehrfach auf, wenn das größere Problem gelöst wird. Statt diese Teilprobleme wiederholt zu berechnen, speichern wir ihre Lösungen.
- **Optimale Teilstruktur**: Die optimale Lösung des Problems enthält optimale Lösungen seiner Teilprobleme. Das bedeutet, wir können die beste Lösung aufbauen, indem wir die besten Lösungen für kleinere Teile kombinieren.

## Lösungen mit dynamischer Programmierung

- **Memoisierung (Top-Down-Ansatz)**: Memoisierung speichert die Ergebnisse teurer Funktionsaufrufe und gibt das zwischengespeicherte Ergebnis zurück, wenn dieselben Eingaben erneut auftreten.

- **Tabellierung (Bottom-Up-Ansatz)**: Tabellierung baut die Lösung von unten nach oben auf und füllt eine Tabelle mit Lösungen für Teilprobleme.

## Anwendungen aus der Praxis mit dynamischer Programmierung

- **Routenoptimierung**: GPS-Systeme verwenden dynamische Programmieralgorithmen, um die kürzesten Wege zwischen Orten zu finden.
- **Textverarbeitung**: Rechtschreibprüfungen und Autovervollständigungsfunktionen basieren oft auf dynamischer Programmierung, um Editierabstände zwischen Wörtern zu berechnen.
- **Finanzmodellierung**: Anlagestrategien und Portfoliooptimierung nutzen häufig Techniken der dynamischen Programmierung.
- **Ressourcenzuweisung**: Das Rucksackproblem und seine Varianten treten bei der Terminplanung, Budgetierung und Ressourcenverwaltung auf.

## Wann dynamische Programmierung verwenden

Sie sollten dynamische Programmierung in den folgenden Fällen in Betracht ziehen:

- Das Problem lässt sich in sich überschneidende Teilprobleme zerlegen.
- Das Problem zeigt eine optimale Teilstruktur.
- Eine naive rekursive Lösung würde wiederholte Berechnungen erfordern.
- Sie müssen die Zeitkomplexität auf Kosten der Speicherkomplexität optimieren.

## Reine vs unreine Funktionen

- Eine reine Funktion ist eine Funktion, die immer dasselbe Ergebnis für dieselbe Eingabe liefert und keine Nebeneffekte hat. Ihr Ergebnis hängt nur von der Eingabe ab, und sie verändert keinen externen Zustand.
- Unreine Funktionen haben Nebeneffekte, das sind Änderungen am Programmzustand, die außerhalb der Funktion beobachtbar sind.

## Funktionale Programmierung

- Funktionale Programmierung ist ein Ansatz zur Softwareentwicklung, der die Verwendung von Funktionen zur Problemlösung betont und sich darauf konzentriert, was getan werden muss, statt wie es getan wird.
- Funktionale Programmierung fördert Techniken, die helfen, Nebeneffekte zu vermeiden, wie die Verwendung unveränderlicher Datenstrukturen und höherwertiger Funktionen.
- Wenn funktionale Programmiergrundsätze richtig angewendet werden, führt das zu saubererem und besser wartbarem Code.

## Currying

- Currying ist eine Technik der funktionalen Programmierung, die eine Funktion mit mehreren Argumenten in eine Folge von Funktionen umwandelt, die jeweils ein einzelnes Argument annehmen.

Zum Beispiel ändert Currying einen Aufruf wie `average(a, b, c)` in aufeinanderfolgende Aufrufe wie `curriedAverage(a)(b)(c)`.

- Currying kann besonders mächtig sein, wenn Sie mit Funktionen arbeiten, die viele Argumente annehmen.
- Currying macht Ihren Code flexibler und leichter wiederverwendbar.
- Sie können Pfeilfunktionen verwenden, um curried Funktionen kürzer zu schreiben:

```js
const curriedAverage = a => b => c => (a + b + c) / 3;
```

- Obwohl Currying zu flexiblerem und wiederverwendbarem Code führt, kann es den Code schwerer lesbar machen, wenn es übermäßig verwendet wird.

- **Synchrones JavaScript** wird sequenziell ausgeführt und wartet, bis die vorherige Operation abgeschlossen ist, bevor es mit der nächsten fortfährt.
- **Asynchrones JavaScript** erlaubt es, mehrere Operationen im Hintergrund auszuführen, ohne den Haupt-Thread zu blockieren.
- **Thread** ist eine Folge von Anweisungen, die unabhängig vom Hauptprogrammfluss ausgeführt werden kann.
- **Callback-Funktionen** sind Funktionen, die als Argumente an andere Funktionen übergeben werden und nach Abschluss der Operation oder als Ergebnis eines Ereignisses ausgeführt werden.

## Die JavaScript-Engine und das JavaScript-Laufzeitsystem

- Die **JavaScript-Engine** ist ein Programm, das JavaScript-Code in einem Webbrowser ausführt. Sie funktioniert wie ein Konverter, der Ihren Code nimmt, ihn in Anweisungen umwandelt, die der Computer verstehen kann, und entsprechend arbeitet.
- V8 ist ein Beispiel für eine von Google entwickelte JavaScript-Engine.
- Die **JavaScript-Laufzeitumgebung** ist die Umgebung, in der JavaScript-Code ausgeführt wird. Sie umfasst die JavaScript-Engine, die den Code verarbeitet und ausführt, sowie zusätzliche Funktionen wie einen Webbrowser oder Node.js.

## Die Fetch API

- Die Fetch API ermöglicht es Webanwendungen, Netzwerk-Anfragen zu stellen, typischerweise um Daten vom Server abzurufen oder an ihn zu senden. Sie stellt eine `fetch()` Methode bereit, mit der Sie diese Anfragen durchführen können.
- Sie können Text, Bilder, Audio, JSON und andere Datentypen mit der Fetch API abrufen.

## HTTP-Methoden für die Fetch API

Die Fetch API unterstützt verschiedene HTTP-Methoden zur Interaktion mit dem Server. Die gebräuchlichsten Methoden sind:

- **GET**: Wird verwendet, um Daten vom Server abzurufen. Standardmäßig verwendet die Fetch API die `GET` Methode, um Daten abzurufen.

Um die abgerufenen Daten zu verwenden, müssen sie mit der `.json()` Methode in das JSON-Format konvertiert werden:

```js
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data))
```

In diesem Code gibt `fetch()` ein Promise zurück, und der `.then()`-Handler konvertiert die aufgelöste Antwort in ein JSON-Format.

- **POST**: Wird verwendet, um Daten an den Server zu senden. Die `POST` Methode wird verwendet, um neue Ressourcen auf dem Server zu erstellen.

```js
fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    name: 'John Doe',
    email: 'john@example.com'
  })
})
```

In diesem Beispiel senden wir eine `POST` Anfrage, um einen neuen Nutzer zu erstellen. Wir haben die Methode als `POST` angegeben, die passenden Header gesetzt und einen Body mit den zu sendenden Daten hinzugefügt. Der Body muss ein String sein, daher verwenden wir `JSON.stringify()`, um unser Objekt in einen JSON-String umzuwandeln.

- **PUT**: Wird verwendet, um Daten auf dem Server zu aktualisieren. Die `PUT` Methode wird verwendet, um bestehende Ressourcen auf dem Server zu aktualisieren.

Für ein Update geben Sie `method: 'PUT'` an und fügen die aktualisierten Daten im Anfrage-Body hinzu. Die URL identifiziert die zu aktualisierende Ressource.

- **DELETE**: Wird verwendet, um Daten auf dem Server zu löschen. Die `DELETE` Methode wird verwendet, um Ressourcen auf dem Server zu löschen.

Setzen Sie `method: 'DELETE'` und verwenden Sie eine URL, die die zu entfernende Ressource identifiziert.

## Promise und Promise-Verkettung

- **Promises** sind Objekte, die den endgültigen Abschluss oder das Scheitern einer asynchronen Operation und deren Ergebniswert darstellen. Der Wert des Promise ist erst bekannt, wenn die asynchrone Operation abgeschlossen ist.
- Hier ist ein Beispiel, um ein einfaches Promise zu erstellen:

```js
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Data received successfully');
  }, 2000);
});
```

- Die `.then()`-Methode wird in einem Promise verwendet, um anzugeben, was passieren soll, wenn das Promise erfüllt wird, während `.catch()` verwendet wird, um Fehler zu behandeln, die auftreten können.

- **Promise-Verkettung**: Eine der leistungsstarken Funktionen von Promises ist, dass wir mehrere asynchrone Operationen hintereinander verketten können. Jede `.then()`-Methode kann ein neues Promise zurückgeben, sodass Sie eine Folge von asynchronen Operationen nacheinander ausführen können.

Die `catch` Methode würde alle während des Prozesses auftretenden Fehler behandeln. Das bedeutet, dass Sie nicht für jeden Schritt eine Fehlerbehandlung hinzufügen müssen, was Ihren Code erheblich vereinfacht.

## Verwendung von `async/await` zur Behandlung von Promises

`async`/`await` macht das Schreiben und Lesen von asynchronem Code einfacher und basiert auf Promises.

- **async**: Das Schlüsselwort `async` wird verwendet, um eine asynchrone Funktion zu definieren. Eine `async`-Funktion gibt ein Promise zurück, das mit dem Wert aufgelöst wird, den die `async`-Funktion zurückgibt.
- **await**: Das Schlüsselwort `await` wird innerhalb einer `async`-Funktion verwendet, um die Ausführung der Funktion anzuhalten, bis das Promise aufgelöst ist. Es kann nur innerhalb einer `async`-Funktion verwendet werden.

- Einer der größten Vorteile von `async/await` ist die Fehlerbehandlung über `try/catch` Blöcke. Hier ist ein Beispiel:

```js
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

fetchData();
```

Im obigen Beispiel enthält der `try` Block den Code, der einen Fehler auslösen könnte, und der `catch` Block behandelt den Fehler, falls er auftritt. Dies macht die Fehlerbehandlung einfacher und lesbarer.

## Das `async` Attribut

- Das `async`-Attribut weist den Browser an, die Skriptdatei asynchron herunterzuladen, während das HTML-Dokument weiterhin geparst wird.
- Sobald das Skript heruntergeladen ist, wird das HTML-Parsen pausiert, das Skript ausgeführt und dann das HTML-Parsen fortgesetzt.
- Sie sollten `async` für unabhängige Skripte verwenden, bei denen die Ausführungsreihenfolge keine Rolle spielt.

## Das `defer` Attribut

- Das `defer`-Attribut lädt das Skript ebenfalls asynchron herunter, verschiebt aber die Ausführung des Skripts, bis das HTML-Dokument vollständig geparst wurde.
- Die `defer`-Skripte behalten die Ausführungsreihenfolge bei, wie sie im HTML-Dokument erscheinen.

- Es ist wichtig zu beachten, dass sowohl `async` als auch `defer` Attribute bei Inline-Skripten ignoriert werden und nur für externe Skriptdateien funktionieren.

- Wenn sowohl `async` als auch `defer` Attribute vorhanden sind, hat das `async` Attribut Vorrang.

## Geolocation-API

- Die Geolocation API bietet Webseiten die Möglichkeit, den Standort des Nutzers anzufragen.

- Das folgende Beispiel zeigt die `getCurrentPosition()`-Methode der API, mit der der aktuelle Standort des Benutzers ermittelt wird.

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

In diesem Code rufen wir `getCurrentPosition` auf und übergeben eine Funktion, die aufgerufen wird, wenn die Position erfolgreich ermittelt wurde.

Das `position` Objekt enthält verschiedene Informationen, hier haben wir nur `latitude` und `longitude` ausgewählt.

Wenn es ein Problem bei der Ermittlung der `position` gibt, wird der Fehler in der Konsole protokolliert.

- Es ist wichtig, die Privatsphäre des Benutzers zu respektieren und den Standort nur dann anzufragen, wenn es notwendig ist.
