# --description--

A lo largo de las lecciones anteriores, has estado definiendo funciones usando la palabra clave `def` así:

```py
def square(num):
    return num ** 2

print(square(4)) # 16
```

En la lección anterior, pasaste funciones como `is_long_word` y `to_fahrenheit` a `map()` y `filter()`. Una función que acepta otra función como argumento se llama función de orden superior. Definir una función separada con `def` cada vez que necesitas pasar una función corta a una función de orden superior puede ser un poco verboso. En lugar de eso, puedes escribir una función lambda, que es una función sin nombre, directamente donde la necesitas.

La sintaxis de una función lambda se ve así:

```py
lambda parameters: expression
```

Después de la palabra clave `lambda`, enumeras los parámetros de la función. Los dos puntos separan los parámetros de una sola expresión, y el resultado de esa expresión se devuelve automáticamente, sin necesidad de una sentencia `return`.

Así es como se ve la función `square()` cuando se refactoriza en una función lambda:

```py
lambda num: num ** 2
```

Aquí, `num` es el parámetro, y `num ** 2` es la expresión cuyo resultado se devuelve. Como se mencionó antes, las funciones lambda son anónimas, por lo que esta función ya no tiene el nombre `square` asociado.

Una función lambda también puede tener más de un parámetro. Al igual que con las funciones definidas con `def`, separas los parámetros con comas:

```py
lambda a, b: a + b
```

Esta función lambda toma dos parámetros, `a` y `b`, y devuelve su suma.

Las funciones lambda son ideales cuando necesitas pasarlas a funciones de orden superior como esta:

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

En este ejemplo, tenemos una lista de números y queremos crear una nueva lista con los números pares. Así que pasamos una función lambda como uno de los argumentos a la función `filter()`. La función `filter()` llama a la función lambda para cada número y conserva solo los números para los cuales `x % 2 == 0` es `True`. Luego, `list()` los recopila en una nueva lista que contiene los números `2` y `4`.

Al trabajar con funciones lambda, es importante estar al tanto de las mejores prácticas. Por ejemplo, no es buena práctica asignar una función lambda a una variable de esta manera:

```py
numbers = [1, 2, 3, 4, 5]

square = lambda x: x ** 2
squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Esto va en contra del propósito de usar funciones anónimas. En este caso, deberías usar una función regular, así:

```py
numbers = [1, 2, 3, 4, 5]

def square(num):
    return num ** 2

squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Además, debes evitar crear funciones lambda que sean difíciles de leer o innecesariamente complicadas, como esta:

```py
result = (lambda x: (x**2 + 2*x - 1) if x > 0 else (x**3 - x + 4))(3)
print(result)  # 14
```

Aunque esta función se ejecuta bien y produce el resultado correcto de `14`, no es fácil de leer ni de entender. En este caso, sería mejor crear una función separada con una estructura `if/else`, y luego llamar a esa función:

```py
def calculate_expression(x):
    if x > 0:
        return x**2 + 2*x - 1
    else:
        return x**3 - x + 4

print(calculate_expression(3))  # 14
```

Tanto las funciones regulares como las funciones lambda tienen sus casos de uso en programas Python. Si estás trabajando con una sola expresión en línea, podrías considerar usar una función lambda. De lo contrario, usar una función regular sería lo más adecuado.
