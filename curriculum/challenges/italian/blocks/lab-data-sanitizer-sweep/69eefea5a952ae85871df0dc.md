# --description--

In questo laboratorio, pulirai file di log semi-strutturati sostituendo i caratteri non consentiti con `#` e tenendo traccia di quante voci sono state elaborate.

**Obiettivo:** Completa le storie utente qui sotto e fai passare tutti i test per completare il laboratorio.

**Storie utente:**

1. Dovresti usare una dichiarazione di funzione per creare una funzione chiamata `sanitizeLog` con due parametri: `entry`, una stringa che rappresenta una voce di log, e `disallowedCharacters`, un array di stringhe di un solo carattere che rappresentano i caratteri da sostituire.
1. La funzione dovrebbe restituire una stringa `entry` modificata con ogni carattere non consentito sostituito da `#`. Il confronto deve essere case-sensitive. Per esempio, se i caratteri non consentiti sono `["e", "E", "o", "r"]`, allora `DEBUG: Server started on port 3000` restituisce `D#BUG: S##v## sta#t#d #n p##t 3000`.
1. Dovresti creare una funzione chiamata `cleanLogs` con due parametri: `logs`, un array di stringhe che rappresentano le voci di log, e `disallowedCharacters`, un array di stringhe di un solo carattere che rappresentano i caratteri da sostituire.
1. `cleanLogs` dovrebbe iterare sull'array di voci di log nell'ordine dato.
1. Quando `cleanLogs` incontra una voce di log che contiene il marcatore fatale `$`, dovrebbe fermarsi e restituire `Sanitizing stopped. Failure Reason: Fatal character occurred.`
1. Una voce di log che inizia con il carattere `/` è una voce informativa e non dovrebbe essere sanificata. Dovresti tenere il conto delle voci informative.
1. Tutte le altre voci di log dovrebbero essere sanificate usando la funzione `sanitizeLog`. Dovresti tenere il conto delle voci sanificate.
1. Se `cleanLogs` termina senza incontrare un marcatore fatale, dovrebbe restituire `Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.`, dove `X` è il numero totale di voci, `Y` è il numero di voci sanificate e `Z` è il numero di voci informative.

**I seguenti array di log sono usati nei test:**

```js
let logs_1 = [
  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"
];

let logs_2 = [
  "FATAL: System overload detected, shutting down",
  "DEBUG: token=def456$ refreshed for session",
  "ERROR: Null pointer exception in module auth"
];

let logs_3 = [
  "ERROR: Failed to connect to db, retry=3",
  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
