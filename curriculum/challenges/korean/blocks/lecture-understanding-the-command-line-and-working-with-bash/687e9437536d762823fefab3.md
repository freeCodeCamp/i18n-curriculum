# --description--

생산성을 높이기 위해 사용할 수 있는 명령줄 단축키에 대해 배워보세요.

터미널과 명령줄 단축키는 작업 흐름을 간소화하고 생산성을 극대화하는 데 도움이 됩니다. Linux와 macOS는 모두 Unix에서 유래했기 때문에 많은 단축키가 동일합니다. 하지만 Windows에서는 약간의 차이가 있을 수 있습니다.

## <kbd>위쪽 화살표</kbd>와 <kbd>아래쪽 화살표</kbd> 단축키

첫 번째 단축키는 <kbd>위쪽 화살표</kbd> 키입니다. 이 키를 누르면 명령 기록을 한 번에 한 명령씩 거꾸로 순환할 수 있습니다. 그리고 <kbd>아래쪽 화살표</kbd> 키는 명령 기록을 앞으로 순환하는 데 사용됩니다. 이 두 키를 사용하면 이전에 실행한 명령을 빠르게 찾아 다시 실행할 수 있습니다.

## <kbd>Tab</kbd> 키를 이용한 자동완성

많은 셸은 입력을 시작한 내용을 바탕으로 명령어를 제안하는 자동완성 기능도 제공합니다. <kbd>Tab</kbd> 키를 눌러 제안된 나머지 부분을 채워 명령줄에 전체 구문을 빠르게 입력할 수 있습니다. 제안 내용은 사용하는 셸, 입력 중인 명령어, 그리고 셸 설정에 따라 달라집니다. 예를 들어, 명령어 이름을 입력할 때 Bash와 zsh는 일치하는 명령어를 제안하고, 인수를 입력할 때는 보통 일치하는 파일과 디렉터리 이름을 제안합니다. PowerShell은 명령어, 매개변수 이름, 변수, 파일 경로를 완성할 수 있습니다.

## <kbd>Control</kbd> + <kbd>L</kbd> 단축키

때때로 명령이 터미널에 많은 출력을 생성할 수 있습니다. 이 추가 출력은 작업 흐름에 방해가 되거나 혼란을 줄 수 있습니다. Linux와 macOS 장치에서 사용하는 *nix 기반 터미널에서는 <kbd>Control</kbd> + <kbd>L</kbd> 키를 눌러 전체 화면을 지우고 새롭고 깨끗한 프롬프트로 시작할 수 있습니다. PowerShell에서도 <kbd>Control</kbd> + <kbd>L</kbd> 키가 기본적으로 화면을 지우며, 같은 결과를 위해 `cls` 명령을 실행할 수 있습니다.

## <kbd>Control</kbd> + <kbd>C</kbd> 단축키

명령어 실행을 중단해야 할 때 <kbd>Control</kbd> + <kbd>C</kbd>를 누르세요. 이 키 조합은 현재 포그라운드에서 실행 중인 명령어에 인터럽트 요청을 보내 보통 실행을 멈추고 새 프롬프트로 돌아가 작업을 계속할 수 있게 합니다. 일부 프로그램은 이 요청을 자체적으로 처리해 확인을 요구하거나 계속 실행할 수도 있습니다. PowerShell 사용자는 <kbd>Control</kbd> + <kbd>C</kbd>가 텍스트 복사에도 사용되며, 복사할 텍스트가 선택되지 않은 경우에만 명령어 중단에 작동합니다.

## *nix 기반 터미널 단축키

다음 몇 가지 단축키는 *nix 기반 터미널에서만 사용할 수 있으며 PowerShell에는 대응하는 단축키가 없습니다.

때로는 멀티태스킹을 위해 한 명령어를 일시 중지하고 다른 작업을 해야 할 때가 있습니다. <kbd>Control</kbd> + <kbd>Z</kbd>를 누르면 현재 포그라운드에서 실행 중인 명령어가 일시 중지되고 명령줄로 돌아가 작업을 계속할 수 있습니다. 일시 중지된 명령어는 실행이 멈춘 상태이며, 백그라운드에서 계속 실행하려면 `bg` 명령어를 사용하세요. 다시 포그라운드로 가져오려면 `fg` 명령어를 사용합니다.

마지막으로, 연속해서 두 번 실행해야 하는 명령이 있을 수 있습니다. 이전에 실행한 명령으로 거꾸로 순환하려면 <kbd>위쪽 화살표</kbd> 키를 누를 수 있지만, 명령줄에 느낌표 두 개(`!!`)를 입력하고 <kbd>Enter</kbd>를 누르면 마지막으로 실행한 명령이 자동으로 실행됩니다.
