## 什么是面向对象编程？

- **面向对象编程**：一种编程风格，开发者将代码中的所有内容都视为现实世界中的对象。它通常被称为 OOP。帮助你有效组织和管理代码的四个关键原则是**封装**、**继承**、**多态**和**抽象**。
- **类**：创建对象的蓝图。每个由类创建的对象都有定义数据的属性和决定对象行为的方法。

## 什么是封装？

- **封装**：将对象的属性和方法打包成一个单元。它让你通过一组简单的公共方法和属性（像门一样）隐藏对象的内部状态。门后是私有属性和方法，控制数据如何变化以及谁可以访问它。
- **封装示例**：如果你想跟踪钱包余额，你会允许存款和取款，但不希望任何人篡改钱包余额本身：

```py
class Wallet:
   def __init__(self, balance):
       self.__balance = balance # Private attribute

   def deposit(self, amount):
       if amount > 0:
           self.__balance += amount # Add to the balance safely

   def withdraw(self, amount):
       if 0 < amount <= self.__balance:
           self.__balance -= amount # Remove from the balance safely

account = Wallet(500)
print(account.__balance) # AttributeError: 'Wallet' object has no attribute '__balance'
```

- **单下划线和双下划线前缀属性的区别**：用单下划线前缀属性和方法表示它们是供内部使用的。这只是一个约定，Python 不限制类外部访问它们。用双下划线前缀属性和方法会触发名称改写，将 `__balance` 重命名为 `_Wallet__balance`。这有助于避免子类中意外的名称冲突，但并不意味着外部访问不可能：

```py
print(account._Wallet__balance) # 500
```

## 什么是 Getter 和 Setter？

- **Getter 和 Setter**：允许你控制类属性如何被访问和修改的方法。你用 getter 获取值，用 setter 设置值。
- **属性**：它们连接 getter 和 setter，允许访问数据。当你获取、设置或删除值时，它们会在后台运行额外逻辑。
- **为什么用属性而不是方法**：属性比方法更易读，代码更简洁。它们让你像访问普通属性一样用点符号访问值，无需括号。
- **装饰器**：装饰器是修改或包装其他函数或类的函数，而不改变它们的原始代码。你通过将 `@decorator_name` 放在函数或类定义上方来应用装饰器。例如，在方法上方放置 `@property` 装饰器会将其变成属性，这样访问时像访问属性一样，内部调用被装饰的方法。
- **创建 Getter**：要创建 getter，使用 `@property` 装饰器。下面是一个获取圆半径的 getter：

```py
class Circle:
    def __init__(self, radius):
        self._radius = radius

    @property
    def radius(self): # A getter to get the radius
        return self._radius
  
    @property
    def area(self):  # A getter to calculate area
        return 3.14 * (self._radius ** 2)

my_circle = Circle(3)

print(my_circle.radius) # 3
print(my_circle.area) # 28.26
```

- **创建 Setter**：定义同名方法并在其上方使用 `@<property_name>.setter` 装饰器来创建 setter：

```py
class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def radius(self):  # A getter to get the radius
        return self._radius

    @radius.setter
    def radius(self, value):  # A setter to set the radius
        if value <= 0:
            raise ValueError('Radius must be positive')
        self._radius = value

my_circle = Circle(3)
print('Initial radius:', my_circle.radius) # Initial radius: 3

my_circle.radius = 8
print('After modifying the radius:', my_circle.radius) # After modifying the radius: 8
```

- **Python 如何处理 Getter 和 Setter**：定义 getter 和 setter 后，Python 会在你用普通属性语法访问时自动调用它们：

```py
my_circle.radius # This will call the getter
my_circle.radius = 4 # This will call the setter
```

在 setter 内部，不应给属性名本身赋值，否则会导致 `RecursionError`。

- **删除器（Deleter）**：在设置和获取值后，你可以用 `deleter` 控制如何删除它。删除器在你对属性使用 `del` 语句时运行自定义逻辑。创建删除器时，使用 `@<property_name>.deleter` 装饰器。

```py
  # Deleter
    @radius.deleter
    def radius(self):
        print("Deleting radius...")
        del self._radius
```

## 什么是继承？它如何促进代码复用？

- **继承**：子类使用父类的属性和方法的过程。继承促进代码复用，提供清晰的层次结构，并允许定制行为而无需重写所有内容。实现继承时，子类接收父类名称：

```py
class Parent:
    # Parent attributes and methods

class Child(Parent):
    # Child inherits, extends, and/or overrides where necessary
```

- **单继承和多继承**：子类从单个父类继承属性和方法称为 **单继承**，从多个父类继承称为 **多继承**。语法如下：

```py
class Parent:
    # Attributes and methods for Parent

class Child:
    # Attributes and methods for Child

class GrandChild(Parent, Child):
    # GrandChild inherits from both Parent and Child
    # GrandChild can combine or override behavior from each
```

- **`super()` 函数**：允许你在类对某方法有不同实现或扩展时，调用父类的方法而不重复代码。

## 什么是多态？它如何促进代码复用？

- **多态**：面向对象编程原则，允许不同类使用相同的方法名，但每个类在调用时有不同实现。语法如下：

```py
class A:
   def action(self): ...

class B:
   def action(self): ...

class C:
   def action(self): ...

Class().method()  # Works for A, B, or C
```

- **基于继承的多态**：父类定义方法，子类根据需要修改实现。

## 什么是名称改写，它是如何工作的？

- **名称改写**：Python 内部将双下划线前缀的属性重命名，添加下划线和类名作为前缀，将 `__attribute` 变成 `_ClassName__attribute`。
- **名称改写的目的**：名称改写的主要目的是防止在使用继承时意外覆盖属性和方法。下面的代码示例能帮助你更好理解：

```py
class Parent:
    def __init__(self):
        self.__data = 'Parent data'

class Child(Parent):
    def __init__(self):
        super().__init__()
        self.__data = 'Child data'

c = Child()
print(c.__dict__) # {'_Parent__data': 'Parent data', '_Child__data': 'Child data'}
```

## 什么是抽象？它如何帮助保持复杂系统的组织？

- **抽象**：一种编程概念，将对象或系统的复杂实现细节隐藏，只显示必要的特性。在 Python 和其他编程语言中，抽象通过提高可重用性简化复杂系统。
- **抽象的例子**：生活中抽象的一个好例子是汽车，你只用方向盘、踏板和换挡杆，而不需要知道发动机或刹车是如何工作的。
- **Python 如何实现抽象**：你可以用普通函数和类通过简单接口隐藏实现细节来创建抽象。对于更正式的接口，Python 的 `abc` 模块提供了 `ABC` 辅助类和 `@abstractmethod` 装饰器。抽象基类定义了具体子类应提供的公共方法和属性。
- **抽象方法如何定义**：抽象方法用 `@abstractmethod` 定义。只有当类提供或继承了所有抽象方法的具体实现时，才能实例化该类。未实现任何抽象方法的子类仍然是抽象的。抽象方法仍可有默认实现，子类可以用 `super()` 调用。仅继承 `ABC` 不会阻止实例化：`ABC()` 和没有抽象方法的子类都可以实例化。抽象的基本语法如下：

```py
from abc import ABC, abstractmethod

# Define an abstract base class
class AbstractClass(ABC):
    @abstractmethod
    def abstract_method(self):
        pass

# Concrete subclass that implements the abstract method
class ConcreteClassOne(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassOne')

# Another concrete subclass
class ConcreteClassTwo(AbstractClass):
    def abstract_method(self):
        print('Implementation in ConcreteClassTwo')

AbstractClass() # TypeError
ConcreteClassOne().abstract_method() # Implementation in ConcreteClassOne
```

## 对象表示

- **`__repr__` 方法**：一个特殊方法，返回对象的字符串表示。理想情况下，该字符串看起来像创建对象的代码。例如，`Employee('Charlie', 'developer')` 应该表示为 `Employee('Charlie', 'developer')`。
- **`repr()` 函数**：调用对象的 `repr()` 时，Python 会在后台调用该对象的 `__repr__` 方法。对于字符串，`repr()` 会添加引号并转义需要的字符：

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

- **`!r` 转换**：在 f-string 中，在表达式后加 `!r` 会应用 `repr()`。在 `__repr__` 中使用 `!r` 可以保持表示的有效性，尤其当值包含引号或反斜线时，这比手动加引号更安全：

```py
class Employee:
    def __init__(self, name, level):
        self.name = name
        self.level = level

    def __repr__(self):
        return f'Employee({self.name!r}, {self.level!r})'

print(repr(Employee("O'Reilly", 'junior'))) # Employee("O'Reilly", 'junior')
```

## 文档字符串和类型检查

- **文档字符串**：文档字符串是放在类或函数的第一条语句中的字符串，用于记录它们。文档字符串通常用三重双引号括起来：

```py
class Movie:
    """Parent class representing a movie."""

def add(x, y):
    """A function that returns the sum of two numbers."""
    return x + y
```

- **`isinstance()` 与 `type()`**：`isinstance(obj, ClassName)` 如果 `obj` 是 `ClassName` 或其任何子类的实例，则返回 `True`，因为它考虑了完整的继承链。要检查确切的类，请比较 `type(obj)`：

```py
class Movie:
    pass

class TVSeries(Movie):
    pass

series = TVSeries()
print(isinstance(series, Movie)) # True
print(type(series) == Movie) # False
print(type(series) == TVSeries) # True
```

## 带额外上下文的自定义异常

- **在异常中存储上下文**：自定义异常可以接受除消息外的额外数据。调用 `super().__init__(message)` 让内置的 `Exception` 类存储和显示消息，然后你可以将额外数据存储为属性。捕获异常时，可以读取该属性以帮助调试：

```py
class MediaError(Exception):
    """Custom exception for media-related errors."""

    def __init__(self, message, obj):
        super().__init__(message)
        self.obj = obj

try:
    raise MediaError('Only Movie or TVSeries instances can be added', 42)
except MediaError as e:
    print(f'Media Error: {e}') # Media Error: Only Movie or TVSeries instances can be added
    print(f'Unable to add {e.obj}: {type(e.obj)}') # Unable to add 42: <class 'int'>
```

## 类型提示

- **类型提示**：可选注解，向其他开发者表明变量、参数或返回值预期的数据类型。Python 在运行期不强制执行它们。
- **参数和返回类型提示**：你在参数名后加冒号添加参数类型提示，在参数列表后用 `-> return_type` 添加返回类型提示。由于 `__init__` 是初始化函数，返回值必须是 `None`，所以它的返回类型提示是 `None`：

```py
class Product:
    def __init__(self, name: str, price: float) -> None:
        self.name = name
        self.price = price

    def is_affordable(self, budget: float) -> bool:
        return self.price <= budget
```

- **自定义类和列表作为类型**：你可以用自己的类作为类型提示，`list[ClassName]` 指定包含该类对象的列表：

```py
class DiscountStrategy:
    pass

class DiscountEngine:
    def __init__(self, strategies: list[DiscountStrategy]) -> None:
        self.strategies = strategies
```
