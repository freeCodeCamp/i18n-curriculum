# --description--

O elevador deve continuar atendendo às requisições enquanto houver alguma. Um `while` loop é perfeito para isso, porque ele se repete enquanto sua condição for verdadeira. Aqui está um lembrete da sintaxe:

```py
while condition:
    # code to repeat
    ...
```

Uma lista não vazia é verdadeira e uma lista vazia é falsa, então você pode usar uma lista como condição do loop para fazê-lo rodar até a lista ficar vazia.

Crie um `while` loop que rode enquanto `requests` não estiver vazia. Dentro do loop, use `pop(0)` para remover a primeira requisição de `requests` e atribuí-la a uma variável chamada `target`. Depois, imprima `target`.

Como `pop(0)` deixa a lista menor a cada iteração, a lista eventualmente fica vazia e o loop para. Sem isso, a condição nunca se tornaria falsa e o loop rodaria para sempre.
