# --description--

El método `__repr__` es un método especial que se supone debe devolver una representación en cadena del objeto que pueda usarse para instanciarlo.

Por ejemplo, el método `__repr__` de `Employee('Charlie', 'developer')` debería devolver la cadena `Employee('Charlie', 'developer')`, que es la misma cadena usada para crear el objeto.

Si tienes comillas alrededor de cada valor, el resultado falla cuando un valor contiene una comilla. Para un empleado llamado `O'Reilly` con un nivel `junior`, obtendrías `Employee('O'Reilly', 'junior')`, lo cual no es válido porque el apóstrofe cierra la cadena antes de tiempo.

La función integrada `repr()` de Python devuelve una representación en cadena de un valor. Para cadenas, agrega las comillas y hace escape de cualquier carácter que lo necesite:

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

Dentro de una f-string, puedes agregar `!r` después de una expresión para aplicar `repr()` a esa expresión:

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

Dale a tu clase `Employee` un método `__repr__` con un parámetro `self`. Haz que devuelva una cadena que pueda usarse para instanciar el objeto, usando `!r` en `self.name` y `self.level` para que cualquier comilla o barra invertida se preserve.
