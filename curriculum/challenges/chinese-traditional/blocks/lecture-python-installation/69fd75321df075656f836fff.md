# --description--

在上一課中，你學會了如何在區域執行 Python 腳本。有時你可能想測試一小段 Python 程式碼，而不需要建立完整的程式。Python 互動式 shell 就能讓你做到這點。

但首先，我們來複習一下什麼是終端機。

終端機是一種以文字為基礎的介面，讓你透過輸入指令與你的電腦互動。每個作業系統都附帶一個預設的終端機應用程式。在 macOS 上，你可以使用 Terminal 應用程式。在 Windows 上，你可以使用命令提示字元或 PowerShell。在 Linux 上，每個桌面環境都有自己的預設終端機應用程式，例如 GNOME Terminal 或 Konsole。

打開終端機應用程式，輸入 `python` 或 `python3`，然後按 <kbd>Enter</kbd> 開啟 Python 互動式 shell。請使用你檢查安裝時顯示 Python 3 版本的指令。互動式 shell 是一個讓你一次輸入一個指令並看到結果的程式。

當你開始一個新的工作階段時，最初可能會看到這樣的輸出：

```md
Python 3.12.2 (main, Mar 21 2024, 22:48:26) [Clang 14.0.3 (clang-1403.0.22.14.1)] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>> 
```

`>>>` 符號表示 Python 正在等待你輸入指令。試著在終端機輸入 `"Hello, world!"`：

```py
print("Hello, world!")
```

你應該會看到文字如下顯示：

```md
>>> print("Hello, world!")
Hello, world!
```

文字列印完後，Python 會回到以下狀態：

```md
>>>
```

這表示你可以繼續輸入下一個指令。

Python 直譯器遵循讀取-求值-列印迴圈（REPL）。它會讀取你的輸入，評估它，列印結果，然後返回到 `>>>` 提示符號。

如果你嘗試輸入像這樣的無效指令會發生什麼事？

```md
>>> something random
```

Python 直譯器仍會遵循相同的 REPL 流程。在這種情況下，你會收到錯誤訊息：

```md
>>> something random
  File "<stdin>", line 1
    something random
              ^^^^^^
SyntaxError: invalid syntax
```

要離開互動式 shell，請輸入 `exit()`，在 macOS 或 Linux 上按 <kbd>Ctrl</kbd> + <kbd>D</kbd>，或在 Windows 上按 <kbd>Ctrl</kbd> + <kbd>Z</kbd>，接著按 <kbd>Enter</kbd>。

使用 Python 的互動式 shell 非常適合做小型程式實驗或基本探索。在你完成課程剩餘的課程時，可以在互動式 shell 中輸入你學到的一些新方法。

如果你打算處理較長的程式或跨多個檔案工作，請使用程式碼編輯器或整合開發環境（IDE）。
