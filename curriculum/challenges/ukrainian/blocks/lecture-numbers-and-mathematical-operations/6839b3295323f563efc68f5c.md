# --description--

Ви вже використовували розширене присвоєння з рядками. Тепер давайте подивимося, як це працює з числами. Розширене присвоєння застосовує операцію і зберігає результат у тій самій змінній, все в одному кроці.

Основний синтаксис розширеного присвоєння виглядає так:

```python
variable <operator>= value
```

Для числових змінних це коротший спосіб записати таке присвоєння:

```python
variable = variable <operator> value
```

Наприклад, ви можете використати оператор розширеного присвоєння, щоб додати `5` до існуючої змінної:

```python
my_var = 10
my_var += 5

print(my_var) # 15
```

А ось те саме, але без розширеного присвоєння:

```python
my_var = 10
my_var = my_var + 5

print(my_var) # 15
```

Перевага розширеного присвоєння в тому, що воно забезпечує стислий і зрозумілий спосіб оновити значення змінної без повторення її імені. Це, у свою чергу, зменшує надмірність і потенційні помилки, які можуть виникнути через опечатку чи щось подібне.

Арифметичні та побітові оператори мають форми розширеного присвоєння. Ми вже розглянули оператор додавання з присвоєнням (`+=`), тож давайте подивимось на інші.

- Оператор віднімання з присвоєнням (`-=`) віднімає правий операнд від лівої змінної і зберігає різницю у лівій змінній:

```python
count = 14
count -= 3

print(count) # 11
```

- Оператор множення з присвоєнням (`*=`) множить ліву змінну на правий операнд і зберігає добуток назад у ліву змінну:
    

```python
product = 65
product *= 7

print(product) # 455
```

- Оператор ділення з присвоєнням (`/=`) ділить ліву змінну на правий операнд і зберігає результат назад у ліву змінну:
    

```python
price = 100
price /= 4

print(price) # 25.0
```

- Оператор присвоєння цілочисельного ділення (`//=`) виконує цілочисельне ділення лівої змінної на правий операнд і зберігає результат у лівій змінній:
    

```python
total_pages = 23
total_pages //= 5

print(total_pages) # 4
```

- Оператор за модулем з присвоєнням (`%=`) обчислює остачу від ділення лівої змінної на правий операнд і зберігає її назад у ліву змінну:
    

```python
bits = 35
bits %= 2

print(bits) # 1
```

- Оператор піднесення до степеня з присвоєнням (`**=`) підносить ліву змінну до степеня правого операнда і зберігає результат назад у ліву змінну:
    

```python
power = 2
power **= 3

print(power) # 8
```
