# --description--

Ahora necesitas emparejar cada temperatura con su etiqueta.

La función `map()` puede tomar más de un iterable. En cada llamada, pasa un elemento de cada iterable a la función, por lo que la función necesita un parámetro por cada iterable:

```py
first = [1, 2, 3]
second = [10, 20, 30]
totals = list(map(
    lambda a, b: a + b,
    first,
    second
))
print(totals) # [11, 22, 33]
```

Crea una variable llamada `report`. Asígnale el resultado de pasar a `map()` una función lambda, `temperatures` y `difference_labels`, envuelto en una llamada a `list()`. La función lambda debe tomar dos parámetros, `temperature` y `difference_label`, y devolver `f'{temperature} °C ({difference_label})'`.

Luego, imprime `report` en lugar de `difference_labels`.
