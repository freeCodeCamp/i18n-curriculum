# --description--

Il metodo `__repr__` è un metodo speciale che dovrebbe restituire una rappresentazione in stringa dell’oggetto che può essere usata per istanziarlo.

Per esempio, il metodo `__repr__` di `Employee('Charlie', 'developer')` dovrebbe restituire la stringa `Employee('Charlie', 'developer')`, che è la stessa stringa usata per creare l’oggetto.

Se hai delle citazioni intorno a ogni valore, il risultato si rompe quando un valore contiene una citazione. Per un dipendente chiamato `O'Reilly` con un livello `junior`, otterresti `Employee('O'Reilly', 'junior')`, che non è valido perché l'apostrofo chiude prematuramente la stringa.

La funzione integrata di Python `repr()` restituisce una rappresentazione stringa di un valore. Per le stringhe, aggiunge le citazioni e fa l'escape di tutti i caratteri che ne hanno bisogno:

```py
print(repr('Charlie')) # 'Charlie'
print(repr("O'Reilly")) # "O'Reilly"
print('C:\\new', repr('C:\\new')) # C:\new 'C:\\new'
```

All'interno di una f-string, puoi aggiungere `!r` dopo un'espressione per applicare `repr()` a essa:

```py
name = "O'Reilly"
print(f'Name: {name!r}')  # Name: "O'Reilly"
```

Dai alla tua classe `Employee` un metodo `__repr__` con un parametro `self`. Fallo restituire una stringa che può essere usata per istanziare l'oggetto, usando `!r` su `self.name` e `self.level` in modo che eventuali citazioni o barre rovesciate vengano preservate.
