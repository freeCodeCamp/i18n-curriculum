# --description--

Nella lezione precedente, hai imparato a usare gli operatori di confronto e le istruzioni condizionali per controllare il flusso dei tuoi programmi.

Anche se questi sono molto potenti, ti capiterà spesso di dover confrontare più valori contemporaneamente. Questo può portare a istruzioni condizionali annidate, per esempio:

```python
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

L'esempio sopra controllerà prima se `is_citizen` è `True`. Se sì, passerà all'istruzione `if` annidata e verificherà se `age` è maggiore o uguale a `18`. Poiché `age` è maggiore o uguale a `18`, il messaggio stampato sul terminale sarà `You are eligible to vote`. Se `is_citizen` fosse stato `False`, allora il messaggio stampato sul terminale sarebbe stato `You are not eligible to vote`.

Se lavori con istruzioni condizionali più complesse, puoi usare gli operatori `and`, `or` e `not` di Python.

Ma prima di addentrarci in questi operatori, diamo un'occhiata a cosa sono i valori truthy e falsy.

In Python, ogni valore ha un valore booleano intrinseco, cioè un senso integrato di se debba essere trattato come `True` o `False` in un contesto logico. Molti valori sono considerati **truthy**, cioè valutano a `True` in un contesto logico. Altri sono **falsy**, cioè valutano a `False`.

Ecco alcuni valori falsy:

- `False`
- Intero `0`
- Float `0.0`
- Stringhe vuote `""`

Altri valori come numeri diversi da zero e stringhe non vuote sono truthy.

Se vuoi verificare se un valore è truthy o falsy, puoi usare la funzione integrata `bool()`. Essa converte esplicitamente un valore nel suo equivalente booleano e restituisce `True` per i valori truthy e `False` per i valori falsy. Ecco alcuni esempi:

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

Ora che hai capito cosa sono i valori truthy e falsy, possiamo dare un'occhiata agli operatori booleani, noti anche come operatori logici. Questi sono operatori speciali che ti permettono di combinare più espressioni per creare una logica decisionale più complessa nel tuo codice.

In Python ci sono tre operatori booleani: `and`, `or` e `not`.

Iniziamo con l'operatore `and`.

L'operatore `and` prende due operandi e restituisce il primo operando se è falsy, altrimenti restituisce il secondo operando. Entrambi gli operandi devono essere truthy affinché un'espressione risulti truthy.

Ecco un esempio:

```python
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

Nell'esempio sopra, il numero 25 viene stampato sul terminale perché l'operatore `and` valuterà il secondo operando se il primo operando è `True`. L'operatore `and` è noto come operatore di short-circuit. Lo short-circuiting significa che Python controlla i valori da sinistra a destra e si ferma non appena determina il risultato finale.

Spesso userai `and` all'interno di istruzioni `if` per verificare se più condizioni sono soddisfatte. Ecco come puoi rifattorizzare l'esempio precedente usando l'operatore `and` invece di istruzioni `if` annidate:

```python
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

Nell'esempio sopra, `is_citizen` è `True` e `age >= 18` valuta a `True`. Poiché entrambi gli operandi dell'operatore `and` sono truthy, la condizione `is_citizen and age >= 18` valuta a `True` e la chiamata `print` nel blocco `if` viene eseguita.

Ora diamo un'occhiata all'operatore `or`. Questo operatore restituisce il primo operando se è truthy, altrimenti restituisce il secondo operando. Un'espressione `or` risulta truthy se almeno un operando è truthy. L'operatore `or` è anch'esso noto come operatore di short-circuit. Ecco un esempio:

```python
age = 19
is_employed = False

print(age or is_employed) # 19
```

Il codice seguente stamperà il numero 19 perché il primo operando `age` è truthy.

Se devi verificare se una o più espressioni sono `True`, puoi usare l'operatore `or` in una condizione come questa:

```python
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

In questo caso, `age < 18` è `False`, ma `is_student` è `True`. Poiché almeno una condizione è vera, l'intera espressione `or` valuta a `True` e il messaggio di sconto nel blocco `if` viene stampato.

L'ultimo operatore che vedremo è l'operatore `not` che prende un solo operando e ne inverte il valore booleano. Converte i valori truthy in `False` e i valori falsy in `True`. A differenza degli operatori precedenti, `not` restituisce sempre `True` o `False`.

Ecco alcuni esempi:

```python
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

È comune usare l'operatore `not` nelle condizioni per verificare se qualcosa non è `True` o `False`, come in questo esempio:

```python
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

Poiché `is_admin` è `False`, allora `not is_admin` sta dicendo non `False` che è `True`. Quindi verrà stampato il messaggio `Access denied for non-administrators.`.

Ora che hai capito cosa sono i valori truthy e falsy, come funzionano gli operatori `and`, `or` e `not` e come funziona lo short-circuiting, puoi scrivere una logica condizionale più flessibile e leggibile.
