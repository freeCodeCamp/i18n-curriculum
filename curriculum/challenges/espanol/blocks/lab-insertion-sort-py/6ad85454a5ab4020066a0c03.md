# --description--

La ordenación por inserción construye una porción ordenada al principio de la lista, un elemento a la vez. Comienza tratando el primer elemento como ordenado. Luego toma el siguiente elemento y lo mueve hacia atrás dentro de la porción ordenada, desplazando o intercambiando cada elemento mayor una posición a la derecha, hasta que alcanza un elemento que es menor o igual que él. Esto se repite para cada elemento restante hasta que toda la lista está ordenada.

La ordenación por inserción tiene una complejidad temporal cuadrática en los casos promedio y peor, pero se ejecuta en tiempo lineal cuando la lista ya está ordenada.

**Objetivo:** Cumplir con las historias de usuario a continuación y pasar todas las pruebas para completar el laboratorio.

**Historias de usuario:**

1. Debes definir una función llamada `insertion_sort` con un parámetro que represente la lista de elementos.
1. Tu función `insertion_sort` debe ordenar la lista en el lugar de menor a mayor y devolverla.
1. Tu función `insertion_sort` debe seguir el algoritmo de ordenación por inserción, insertando cada elemento, de izquierda a derecha, en su posición correcta dentro de la porción ordenada al principio de la lista.
1. Tu función `insertion_sort` debe dejar de mover un elemento hacia atrás tan pronto como alcance un elemento que sea menor o igual que él.
1. Tu función `insertion_sort` no debe usar ni el método integrado `sort()` ni la función `sorted()`.

**Nota:** No debes importar ningún módulo ni usar métodos que agreguen o eliminen elementos de la lista.

```py
def insertion_sort(items):
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j -= 1
        items[j + 1] = current
    return items
```
