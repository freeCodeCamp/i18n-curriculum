# --description--

In der vorherigen Lektion haben wir gelernt, wie man mit `localStorage` arbeitet, und wurden kurz in `sessionStorage` eingeführt.

Erinnern Sie sich, dass bei `sessionStorage` die Daten gelöscht werden, sobald der Benutzer den Tab oder das Fenster schließt, in dem die Webanwendung läuft. Es ist ideal für Situationen, in denen Daten nur für die Dauer einer einzelnen Sitzung erhalten bleiben müssen, wie zum Beispiel das Beibehalten von Formulardaten während der Navigation oder das Speichern temporärer Zustandsinformationen während eines Bestellvorgangs.

Ähnlich wie `localStorage` verwendet `sessionStorage` Schlüssel-Wert-Paare, um Daten zu speichern und abzurufen. Die Methoden, die mit `sessionStorage` verwendet werden, sind auch dieselben wie bei `localStorage`, wobei der einzige wirkliche Unterschied darin besteht, wie lange die Daten gespeichert werden.

Hier sind einige Beispiele für die Arbeit mit den verschiedenen Methoden:

- `sessionStorage.setItem()`: Speichert ein Schlüssel-Wert-Paar in `sessionStorage`.

```js
sessionStorage.setItem('cart', '3 items');
```

- `sessionStorage.getItem()`: Ruft den Wert eines bestimmten Schlüssels aus `sessionStorage` ab.

```js
let cart = sessionStorage.getItem('cart');
console.log(cart); // Outputs: '3 items'
```

- `sessionStorage.removeItem()`: Entfernt einen bestimmten Eintrag aus `sessionStorage` anhand seines Schlüssels.

```js
sessionStorage.removeItem('cart');
```

- `sessionStorage.clear()`: Löscht alle in `sessionStorage` gespeicherten Daten.

```js
sessionStorage.clear();
```

Schauen wir uns ein Beispiel an, bei dem wir Daten in `sessionStorage` speichern, die nur so lange bestehen bleiben, wie der Browser-Tab oder das Fenster geöffnet ist:

```js
// Store data in sessionStorage
sessionStorage.setItem('currentUser', 'JohnDoe');

// Retrieve the stored data
const user = sessionStorage.getItem('currentUser');
console.log(user); // 'JohnDoe'

// Remove a specific key from sessionStorage
sessionStorage.removeItem('currentUser');

// Clear all sessionStorage data
sessionStorage.clear();
```

In diesem Beispiel:

1. Speichern Sie den Namen des aktuellen Benutzers (`JohnDoe`) in `sessionStorage`.

2. Rufen ihn ab und zeigen ihn an.

3. Entfernen den Eintrag mit dem Schlüssel `currentUser`.

4. Löschen alle `sessionStorage`-Daten.

Der entscheidende Unterschied zu `localStorage` ist, dass alle gespeicherten Sitzungsdaten verloren gehen, sobald der Benutzer den Tab schließt.

`sessionStorage` ist besonders nützlich in Szenarien wie:

- Temporäres Speichern von Daten wie Formulareinträgen während eines mehrseitigen Formularprozesses.

- Temporäre Auswahlen oder Einstellungen speichern, die nicht über Sitzungen hinweg erhalten bleiben müssen.

- Den Zustand einer Single-Page-Anwendung beibehalten, der nicht gespeichert werden muss, sobald der Tab geschlossen wird.

`sessionStorage` stellt sicher, dass die Sitzungsdaten gelöscht werden, sobald der Benutzer die Seite verlässt, was ideal für Szenarien ist, in denen Sie keine Informationen über die aktuelle Sitzung hinaus behalten möchten.
