# --description--

在這個工作坊中，你將透過規劃管弦樂團音樂會的節目來練習操作列表。

如你在前面的課程中所學，列表是一個有序的項目群集。你可以將以逗號分隔的項目放在方括號內來建立列表：

```py
fruits = ['apple', 'banana', 'cherry']
```

創建一個名為 `pieces` 的變數，並為它指定一個列表，該列表依序包含字串 `Carnival Overture`、`Song to the Moon` 和 `Silent Woods`。
