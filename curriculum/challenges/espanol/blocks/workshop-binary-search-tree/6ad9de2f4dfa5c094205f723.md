# --description--

Cada nodo puede tener hasta dos hijos.

Dentro del método `__init__`, crea un atributo `left` y un atributo `right`, y asigna a ambos el valor `None` para representar un nodo nuevo que comienza sin hijos.

Un nodo sin hijos se llama nodo hoja.
