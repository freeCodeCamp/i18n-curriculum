# --description--

في Python، المتغيرات هي أسماء تشير إلى كائنات. معاملات الهوية تتحقق مما إذا كان العاملان يشيران إلى نفس الكائن. معامل `is` يرجع `True` إذا كانا كذلك، و`False` خلاف ذلك. معامل `is not` يرجع النتيجة المعاكسة.

الهوية تختلف عن المساواة: `==` و`!=` تقارن القيم، بينما `is` و`is not` تقارن هوية الكائن. استخدم معاملات المساواة عند مقارنة قيم الأعداد أو السلاسل النصية.

`None` تمثل غياب القيمة. هي القيمة الوحيدة لنوع البيانات `NoneType`.

ثلاثة كائنات يمكنك التحقق منها باستخدام معاملات الهوية هي `None`، و`True`، و`False`. كل منها كائن مفرد، أي يوجد كائن واحد فقط لكل منها.

## التحقق من `None`

يمكنك استخدام `is None` للتحقق مما إذا كانت القيمة مفقودة، أو `is not None` للتحقق مما إذا كانت موجودة:

```python
response = None

print(response is None) # True
print(response is not None) # False
```

`None` تعتبر قيمة خاطئة، لكنها ليست نفس كائن `False`. على سبيل المثال، قد تكون الاستجابة `True` للنعم، أو `False` للرفض، أو `None` إذا لم يُعطَ جواب:

```python
response = False

if response is None:
    print('No answer yet')
else:
    print('An answer was given') # An answer was given
```

استخدام `if not response` يعامل كل من `False` و`None` بنفس الطريقة. تحقق الهوية يميز بين جواب سلبي وجواب مفقود.

## التحقق من `True` و`False`

يمكنك أيضًا استخدام الهوية للتحقق تحديدًا من كائنات القيم المنطقية:

```python
response = False

print(response is True) # False
print(response is False) # True
print(response is not None) # True
```

هذه الفحوصات تسأل ما إذا كانت `response` هي بالضبط `True` أو `False` أو كائن غير `None`. لا تختبر فقط صحة القيمة.

للعلامات المنطقية العادية، استخدم اختبارات الحقيقة المباشرة مثل `if is_ready` أو `if not is_ready`. استخدم `is True` أو `is False` عندما تحتاج تحديدًا لتمييز كائن القيمة المنطقية عن القيم الأخرى المحتملة، كما في استجابة قد تكون أيضًا `None`.
