# --description--

Agora você vai transformar as diferenças em rótulos de texto como `+3.6 °C`. Números positivos são impressos sem sinal, então você precisará adicionar um `+` na frente deles.

Para incluir apenas os itens que atendem a uma condição, você pode adicionar um `if` no final de uma compreensão de lista:

```py
numbers = [1, 2, 3, 4]
even_numbers = [num for num in numbers if num % 2 == 0]
print(even_numbers) # [2, 4]
```

Crie uma variável chamada `difference_labels`. Use uma compreensão de lista para atribuir a ela uma lista contendo `f'+{difference} °C'` para cada `difference` em `differences`, mas somente se `difference` for maior que `0`.

Depois, imprima `difference_labels` em vez de `differences`.

No terminal, você verá apenas 3 rótulos para 7 temperaturas. Um `if` no final exclui os itens que não correspondem à condição, então não há como saber a qual temperatura cada rótulo pertence. Você vai corrigir isso no próximo passo.
