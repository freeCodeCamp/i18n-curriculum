# --description--

빈 받은편지함 확인 후, 메시지 `\nYour Emails:`을 출력하세요. 그다음, `for` 루프와 열거를 사용해 받은편지함의 모든 이메일을 순차적으로 반복하세요. 시작 번호가 있는 열거 구문은 다음과 같습니다: `enumerate(iterable, start=start_number)`.

열거를 사용해 이메일에 `1`부터 번호를 매기세요. 반복 변수로 `i` (인덱스)와 `email` (이메일 객체)를 사용하세요.

루프 안에서, 반복 인덱스를 너비 `2`로 오른쪽 정렬한 f-문자열을 출력하고, 그 뒤에 `.`과 공백, 그리고 이메일 객체의 문자열 표현을 다음 형식으로 출력하세요:

```md
 i. string_representation
```

`i`는 인덱스이고 `string_representation`은 이메일 객체의 표현입니다. 숫자를 오른쪽 정렬하면 받은편지함에 이메일이 10개 이상 있어도 목록이 정렬된 상태로 유지됩니다.
