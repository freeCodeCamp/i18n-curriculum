# --description--

이제 잠재적인 문제를 처리해야 합니다. 사용자가 입력 필드에 아무것도 입력하지 않고 "Search" 버튼을 클릭하면 어떻게 될까요?

현재 함수는 빈 문자열을 받아서 `" is available to borrow!"`를 반환합니다. 이는 별로 도움이 되지 않습니다.

이런 상황에서는 `throw` 키워드를 사용해 `new Error()`를 발생시키고 함수 실행을 정지할 수 있습니다. 예를 들어:

```js
throw new Error("Your error message goes here");
```

성공적인 `return` 문 앞에 `title` 매개변수가 빈 문자열(`""`)과 엄격히 같은지 확인하는 `if` 문을 추가하세요.

`if` 문 안에서 `throw` 키워드를 사용해 `new Error()`를 발생시키세요.
`Error` 생성자에 정확히 `"Search field cannot be empty"` 문자열을 전달하세요.

**참고:** 이 코드를 작성한 후 Search 버튼을 클릭하면 화면에 아무것도 나타나지 않습니다! 오류가 클릭 핸들러를 멈추게 하는데 아직 이를 처리하는 부분이 없기 때문입니다. 몇 단계 후에 이 문제를 고칠 것입니다. 지금은 콘솔을 확인해 코드가 작동하는지 확인하세요.

# --hints--

`title`이 빈 문자열과 엄격히 같은지 확인하는 `if` 문을 만들고, 그 안에서 정확히 `"Search field cannot be empty"` 문자열을 가진 `new Error()`를 발생시켜야 합니다.

```js
assert.throws(() => findBook(""), Error, "Search field cannot be empty");
```

`findBook` 함수는 `"The Hobbit"`을 인자로 호출했을 때 `"The Hobbit is available to borrow!"`를 반환해야 합니다.

```js
assert.strictEqual(findBook("The Hobbit"), "The Hobbit is available to borrow!");
```
