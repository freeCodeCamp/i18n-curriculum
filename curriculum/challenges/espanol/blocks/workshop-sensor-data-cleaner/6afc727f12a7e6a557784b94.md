# --description--

Para obtener una etiqueta para cada diferencia, necesitas una expresión condicional antes de `for` en lugar de un `if` al final:

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

Elimina el `if` al final de tu comprensión de listas. Luego, cambia la expresión antes de `for` a una expresión condicional que evalúe a `f'+{difference} °C'` si `difference` es mayor que `0`, y a `f'{difference} °C'` en caso contrario. Los números negativos ya tienen un signo `-`, así que solo necesitan la unidad.
