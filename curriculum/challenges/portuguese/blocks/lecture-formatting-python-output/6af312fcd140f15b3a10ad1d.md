# --description--

Em uma lição anterior sobre números e operações matemáticas, você usou uma especificação de formato como `.2f` em uma f-string para controlar quantas casas decimais um número mostra.

Especificações de formato também podem controlar quanto espaço um valor ocupa e onde ele fica. Isso é útil quando você quer que a saída fique alinhada em colunas organizadas.

## Definindo uma largura mínima e alinhamento

Um número após os dois pontos define a largura mínima do campo, que é o número de caracteres que o valor deve ocupar. Se o valor for menor que isso, o Python adiciona espaços até alcançar essa largura. Aqui está um exemplo:

```py
print(f'|{"Tea":8}|') # |Tea     |
print(f'|{"Coffee":8}|') # |Coffee  |

print(len(f'{"Tea":8}')) # 8
print(len(f'{"Coffee":8}')) # 8
```

Usar símbolos específicos antes da largura controla onde o valor fica dentro do campo. Aqui estão esses símbolos específicos:

- Menor que (`<`) alinha o valor à esquerda
- Maior que (`>`) alinha o valor à direita
- Cursor (`^`) centraliza o valor.

Aqui estão esses três símbolos em ação:

```py
label = 'Tea'

print(f'|{label:<8}|') # |Tea     |
print(f'|{label:>8}|') # |     Tea|
print(f'|{label:^8}|') # |  Tea   |
```

`'Tea'` contém três caracteres, então o Python adiciona cinco espaços para alcançar uma largura de `8`.

- Com `<`, os espaços vão depois do valor
- Com `>`, os espaços vão antes dele
- Com `^`, os espaços são divididos entre os dois lados para centralizar o texto.

Se o espaço não puder ser dividido igualmente, o espaço extra vai para a direita:

```py
label = 'Tea'

print(f'|{label:^9}|') # |   Tea   |
print(f'|{label:^8}|') # |  Tea   |
```

Se você deixar de fora o símbolo de alinhamento, strings são alinhadas à esquerda por padrão, enquanto números são alinhados à direita:

```py
label = 'Tea'
amount = 4.5

print(f'|{label:8}|')     # |Tea     |
print(f'|{amount:7.2f}|') # |   4.50|
```

## Usando um caractere de preenchimento

Por padrão, o Python adiciona preenchimento com espaços. Para usar um caractere diferente para o preenchimento, insira o caractere logo antes do símbolo de alinhamento:

```py
label = 'Tea'

print(f'{label:*^9}') # ***Tea***
print(f'{label:-<8}') # Tea-----
```

Em `*^9`, o `*` é o caractere de preenchimento, `^` centraliza o valor, e `9` é a largura mínima. Note que você só pode usar um caractere de preenchimento junto com um símbolo de alinhamento.

## Combinando largura e precisão

Você pode combinar alinhamento e largura com a precisão que aprendeu na lição anterior, tudo em uma única especificação de formato:

```py
amount = 4.5

print(f'|{amount:>7.2f}|') # |   4.50|
```

A especificação de formato no exemplo acima significa: alinhar à direita, usar uma largura mínima de `7` e mostrar duas casas decimais. O Python formata o número como `4.50` primeiro, que tem quatro caracteres, e então adiciona três espaços na frente para preencher a largura de `7`.

## Construindo uma linha de declaração

Você pode colocar um rótulo e um valor juntos em uma linha. Se usar a mesma especificação de formato para cada linha, as colunas ficam alinhadas:

```py
print(f'{"Tea":.<12}{4.5:>8.2f}')
print(f'{"Sandwich":.<12}{12.75:>8.2f}')
print(f'{"Cookie":.<12}{2:>8.2f}')

# Output:
# Tea.........    4.50
# Sandwich....   12.75
# Cookie......    2.00
```

Cada rótulo é alinhado à esquerda em um campo de `12` caracteres e preenchido com pontos, enquanto cada valor é alinhado à direita em um campo de `8` caracteres, para que os pontos decimais fiquem alinhados.

## A largura é um mínimo, não um máximo

A largura só adiciona preenchimento. Ela nunca corta um valor. Se o valor for maior que a largura especificada, o valor inteiro é exibido:

```py
label = 'Long description'

print(f'|{label:<8}|') # |Long description|
```

O mesmo vale para números. No exemplo abaixo, o valor formatado precisa de oito caracteres, então ignora a largura especificada de `7`:

```py
amount = 12345.67

print(f'|{amount:7.2f}|') # |12345.67|
```

Em `:7.2f`, o `7` é uma largura mínima, não um limite para o comprimento do valor. O Python nunca corta dígitos para fazer um número caber.

Por isso você deve escolher larguras grandes o suficiente para os valores que espera, ou as colunas não ficarão alinhadas.

Se quiser limitar o comprimento de uma string, adicione uma precisão à especificação de formato. Para strings, a precisão define o número máximo de caracteres a exibir:

```py
label = 'Long description'

print(f'|{label:.8}|') # |Long des|
print(f'|{label:<12.8}|') # |Long des    |
```

Em `<12.8`:

- `<` alinha o valor à esquerda
- `12` é a largura mínima
- `.8` é o número máximo de caracteres.

O Python corta a string para oito caracteres primeiro, depois adiciona preenchimento até a largura de doze.

Note que precisão significa algo diferente para strings do que para números. Com `.2f`, o `.2` define o número de casas decimais. Com uma string, `.8` define o número máximo de caracteres.
