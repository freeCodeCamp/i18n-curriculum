# --description--

In diesem letzten Schritt berechnen Sie den Endpreis für das Kinoticket anhand der in den vorherigen Schritten berechneten Werte.

Der endgültige Ticketpreis wird berechnet, indem die Zusatzgebühren und Servicegebühren zum Grundpreis addiert und anschließend der Rabatt abgezogen wird.

Um eine Zahl von einer anderen zu subtrahieren, können Sie den Subtraktionsoperator `-` verwenden. Sie können ihn auch mit dem Operator `+` in demselben Ausdruck kombinieren:

```py
total_cost = 50
shipping = 5
coupon = 10

amount_due = total_cost + shipping - coupon
print(amount_due)  # 45
```

Berechnen Sie im Rumpf der letzten `if`-Anweisung unterhalb der Zeile, die die Servicegebühren ausgibt, den Endpreis des Tickets und speichern Sie ihn in einer Variablen namens `final_price`.

Verwenden Sie abschließend eine f-String-Ausgabe, um `Final price of ticket:` gefolgt von einem Leerzeichen und `final_price` formatiert auf zwei Dezimalstellen auszugeben.
