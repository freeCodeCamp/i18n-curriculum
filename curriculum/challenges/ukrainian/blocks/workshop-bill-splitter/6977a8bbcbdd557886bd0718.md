# --description--

Тепер, коли чайові включено, у вас є фінальна сума для всієї групи. Ви маєте визначити, скільки кожна людина повинна заплатити, поділивши загальний рахунок на кількість друзів.

У Python для виконання ділення використовується коса риска `/`. Наприклад:

```py
half = 10 / 2
```

Створіть змінну з ім’ям `final_bill` і призначте їй результат ділення `running_total` на `num_of_friends`.

Нарешті, використайте f-рядок, щоб вивести `Bill per person:` з пробілом і `final_bill`, відформатований до двох десяткових знаків.
