# --description--

Las expresiones regulares pueden contener secuencias especiales formadas por una barra invertida (`\`) seguida de un carácter. Estas secuencias tienen un significado especial. Aquí están algunas de las más comunes:

- `\d` coincide con cualquier dígito decimal, incluyendo del `0` al `9`.

- `\w` coincide con cualquier carácter de palabra: letras, dígitos y el guion bajo (`_`).

- `\s` coincide con cualquier carácter de espacio en blanco, como un espacio, una tabulación o una nueva línea.

- `\D`, `\W` y `\S` coinciden con lo opuesto a sus versiones en minúsculas. Por ejemplo, `\D` coincide con cualquier carácter que no sea un dígito.

Sin embargo, hay un detalle. Las cadenas en Python también usan barras invertidas para escribir secuencias de escape como `\n` (una nueva línea) o `\t` (una tabulación):

```python
print('Tab:\tdone') # Tab:    done
```

Esto significa que una barra invertida en una cadena normal de Python podría ser interpretada por Python antes de que el módulo `re` la vea. Dependiendo del carácter que siga, eso puede cambiar tu patrón o hacer que Python muestre una advertencia.

Para evitar esto, puedes usar una cadena raw. Creas una cadena raw agregando la letra `r` (o `R`) antes de la comilla de apertura. Las cadenas raw tratan las barras invertidas como caracteres literales en lugar de secuencias de escape:

```python
print(r'Tab:\tdone') # Tab:\tdone
```

Por esta razón, es buena práctica siempre escribir los patrones regex como cadenas raw:

```python
import re

room = 'Room 42B'
print(re.search(r'\d', room))
# <re.Match object; span=(5, 6), match='4'>
```

Fíjate que `re.search` devuelve la primera coincidencia que encuentra. Aquí, `\d` coincide con un solo dígito, así que la coincidencia es solo `4`. Para coincidir con más de un dígito, puedes usar un cuantificador.

Los cuantificadores especifican cuántas veces se puede repetir el carácter o la secuencia anterior. El cuantificador `+` coincide con el carácter anterior una o más veces.

Entonces, mientras que `\d` coincide con un solo dígito, `\d+` coincide con uno o más dígitos seguidos:

```python
import re

room = 'Room 42B'
print(re.search(r'\d+', room))
# <re.Match object; span=(5, 7), match='42'>
```

Aquí hay otros cuantificadores comunes:

- `*` coincide con el carácter anterior cero o más veces.

- `?` coincide con el carácter anterior cero o una vez, haciéndolo opcional.

- `{n}` coincide con el carácter anterior exactamente `n` veces.

- `{n,m}` coincide con el carácter anterior de `n` a `m` veces.

```python
import re

print(re.search(r'go*al', 'What a goooal!'))
# <re.Match object; span=(7, 13), match='goooal'>

print(re.search(r'colou?r', 'My favorite color is blue'))
# <re.Match object; span=(12, 17), match='color'>

print(re.search(r'\d{4}', 'Room 42, built in 1987'))
# <re.Match object; span=(18, 22), match='1987'>
```

Puedes combinar caracteres literales, secuencias especiales y cuantificadores en el mismo patrón. Por ejemplo, el patrón `r'\d+ items'` coincide con uno o más dígitos, seguido de un espacio y la palabra `items`. También puedes combinarlo con la bandera `re.IGNORECASE` para que las letras puedan estar en minúsculas o mayúsculas:

```python
import re

cart = 'You have 3 ITEMS in your cart.'
print(re.search(r'\d+ items', cart, re.IGNORECASE))
# <re.Match object; span=(9, 16), match='3 ITEMS'>
```
