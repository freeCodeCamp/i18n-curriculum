# --description--

Im Terminal sehen Sie einige Werte wie `-3.6999999999999993` statt `-3.7`. Das passiert, weil Fließkommazahlen nicht jede Dezimalzahl exakt darstellen können, sodass nach arithmetischen Operationen kleine Fehler auftreten können.

Die `round()`-Funktion rundet eine Zahl auf die Anzahl der Dezimalstellen, die Sie als zweiten Argument übergeben:

```py
print(round(3.14159, 2)) # 3.14
```

Fassen Sie `temperature - average` in einen `round()`-Aufruf, um jede Differenz auf eine Dezimalstelle zu runden.
