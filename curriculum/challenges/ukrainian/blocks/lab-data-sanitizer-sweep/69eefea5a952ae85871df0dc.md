# --description--

У цій лабораторній роботі ви очистите напівструктуровані журнали, замінюючи заборонені символи на `#` та відстежуючи, скільки записів було оброблено.

**Мета:** Виконайте наведені нижче історії користувача та пройдіть усі тести, щоб завершити лабораторну роботу.

**Історія користувача:**

1. Ви повинні використати оголошення функції, щоб створити функцію з назвою `sanitizeLog` з двома параметрами: `entry`, рядок, що представляє запис журналу, та `disallowedCharacters`, масив рядків з одним символом, які потрібно замінити.
1. Функція має повертати змінений рядок `entry`, у якому кожен заборонений символ замінений на `#`. Порівняння має бути чутливим до регістру. Наприклад, якщо заборонені символи — `["e", "E", "o", "r"]`, тоді `DEBUG: Server started on port 3000` повертає `D#BUG: S##v## sta#t#d #n p##t 3000`.
1. Ви повинні створити функцію з назвою `cleanLogs` з двома параметрами: `logs`, масив рядків, що представляють записи журналу, та `disallowedCharacters`, масив рядків з одним символом, які потрібно замінити.
1. `cleanLogs` має ітерувати над заданим масивом записів журналу послідовно.
1. Коли `cleanLogs` досягає запису журналу, що містить фатальний маркер `$`, вона має зупинитися і повернути `Sanitizing stopped. Failure Reason: Fatal character occurred.`
1. Запис журналу, що починається з символу `/`, є інформаційним і не повинен очищатися. Ви маєте вести підрахунок інформаційних записів.
1. Всі інші записи журналу мають очищатися за допомогою функції `sanitizeLog`. Ви маєте вести підрахунок очищених записів.
1. Якщо `cleanLogs` завершується без зустрічі фатального маркера, вона має повернути `Total Entry Count: X. Sanitized Entry Count: Y. Informational Entry Count: Z. Finished sanitizing logs.`, де `X` — загальна кількість записів, `Y` — кількість очищених записів, а `Z` — кількість інформаційних записів.

**Наступні масиви журналів використовуються в тестах:**

```js
let logs_1 = [
  "INFO: Server started on port 3000",
  "DEBUG: user=admin token=abc123 connected",
  "WARN: High memory usage detected at 87%"
];

let logs_2 = [
  "FATAL: System overload detected, shutting down",
  "DEBUG: token=def456$ refreshed for session",
  "ERROR: Null pointer exception in module auth"
];

let logs_3 = [
  "ERROR: Failed to connect to db, retry=3",
  "DEBUG: api_key=XYZ789 used in request",
  "/INFO: Cache cleared successfully",
  "WARN: Disk usage at 92%, threshold=90%",
  "/INFO: Disk usage stabilized"
];
```

# --solutions--

```js
function sanitizeLog(entry, disallowedCharacters) {
  return entry.split('').map(char => {
    return disallowedCharacters.includes(char) ? '#' : char;
  }).join('');
}

function cleanLogs(logs, disallowedCharacters) {
  let sanitizedLogCount = 0;
  let infoLogCount = 0;
  for(let i=0; i<logs.length; i++) {
    if (logs[i].includes('$')) {
      return 'Sanitizing stopped. Failure Reason: Fatal character occurred.';
    }

    if (logs[i].startsWith('/')) {
      infoLogCount++;
      continue;
    }

    sanitizeLog(logs[i], disallowedCharacters);
    sanitizedLogCount++;
  }

  return `Total Entry Count: ${logs.length}. Sanitized Entry Count: ${sanitizedLogCount}. Informational Entry Count: ${infoLogCount}. Finished sanitizing logs.`;
}
```
