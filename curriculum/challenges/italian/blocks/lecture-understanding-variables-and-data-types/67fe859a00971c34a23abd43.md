# --description--

Prima di lavorare con le variabili in Python, è importante capire i tipi di dati. Un tipo di dato descrive il tipo di valore che una variabile contiene, per esempio un numero o un pezzo di testo. I linguaggi di programmazione usano i tipi di dati per sapere come archiviare e lavorare con diversi tipi di informazioni.

Python è un linguaggio a tipizzazione dinamica. Questo significa che non specifichi il tipo di dato di una variabile quando la crei. Python determina il tipo dal valore assegnato alla variabile.

Ecco alcuni esempi:

```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```

A una variabile può essere assegnato in seguito un valore di tipo diverso:

```python
age = 25
age = 'Twenty-five'
```

Dopo la seconda assegnazione, `age` contiene una stringa invece di un intero.

Per ora, concentrati su quattro tipi di dati che userai in tutto questo modulo:

- Integer: un numero intero senza decimali, per esempio, `10` o `-5`.

```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- Float: un numero con la virgola decimale, come `4.41` o `-0.4`.

```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- String: una sequenza di caratteri racchiusa tra virgolette singole o doppie come `'Hello world!'`.

```python
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- Boolean: un tipo vero o falso, scritto come `True` o `False`.

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python ha altri tipi di dati. Imparerai ciascuno di essi quando ne avrai bisogno per la prima volta.
