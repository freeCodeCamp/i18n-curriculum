# --description--

La recursión es una técnica en la que una función se llama a sí misma. Cada llamada trabaja sobre una versión más pequeña del problema original hasta que alcanza una condición que detiene la recursión. Esa condición de parada se llama caso base.

Las funciones recursivas pueden resolver problemas con una profundidad desconocida, como recorrer un árbol de archivos. También pueden realizar tareas más simples, como contar hacia atrás desde un número dado.

Aquí hay una función llamada `recursive_countdown` que acepta un número y lo imprime:

```py
def recursive_countdown(number):
    print(number)

recursive_countdown(5)
```

Llamar a la función imprime `5`, pero aún no cuenta hacia atrás. Antes de que la función se llame a sí misma, necesitas definir su caso base. Sin un caso base alcanzable, la función seguirá llamándose a sí misma. Python eventualmente detiene las llamadas y lanza un `RecursionError`.

Para esta cuenta regresiva, la función debe detenerse cuando `number` sea menor que `1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)

recursive_countdown(5)
```

La sentencia `if` es el caso base. Cuando `number` es menor que `1`, `return` termina esa llamada a la función.

La función aún necesita un caso recursivo. El caso recursivo llama a la función nuevamente con un argumento que la acerca al caso base. Para contar hacia atrás, llama a `recursive_countdown` con `number - 1`:

```py
def recursive_countdown(number):
    if number < 1:
        return
    print(number)
    recursive_countdown(number - 1)

recursive_countdown(5)
```

Esto imprime los números `5`, `4`, `3`, `2` y `1`.

La posición de la llamada recursiva cambia cómo se imprimen los números. Si la llamada a `print()` viene después de la llamada recursiva, la función imprime los números en orden ascendente:

```py
def recursive_countdown(number):
    if number < 1:
        return
    recursive_countdown(number - 1)
    print(number)

recursive_countdown(5)
```

Esto imprime los números `1`, `2`, `3`, `4` y `5`. Para entender por qué, necesitas comprender el call stack.

El call stack es una estructura de datos de último en entrar, primero en salir que Python usa para llevar el control de las llamadas activas a funciones. Cuando se llama a una función, Python agrega un marco para esa llamada en la parte superior del stack. El marco contiene información como los argumentos y variables locales de la función.

Considera esta versión de la cuenta regresiva:

```py
def recursive_countdown(number):
    print(f'Function call started for number: {number}')
    if number < 1:
        print('Base case reached')
        return
    print(f'Calling recursive_countdown with number: {number - 1}')
    recursive_countdown(number - 1)
    print(f'Function call completed for number: {number}')

recursive_countdown(3)
```

La salida es:

```md
Function call started for number: 3
Calling recursive_countdown with number: 2
Function call started for number: 2
Calling recursive_countdown with number: 1
Function call started for number: 1
Calling recursive_countdown with number: 0
Function call started for number: 0
Base case reached
Function call completed for number: 1
Function call completed for number: 2
Function call completed for number: 3
```

La llamada a `recursive_countdown(3)` se pausa cuando llama a `recursive_countdown(2)`. La llamada con `2` se pausa cuando llama a la función con `1`, y la llamada con `1` se pausa cuando llama a la función con `0`.

La llamada con `0` alcanza el caso base y retorna. Python elimina esa llamada de la parte superior del stack, así que la llamada con `1` continúa después de su llamada recursiva. Las llamadas restantes luego continúan y retornan en orden inverso: `1`, `2` y `3`.

Cada función recursiva necesita un caso base y un caso recursivo que se acerque a él. Cuando el caso base retorna, las llamadas anteriores continúan en orden de último en entrar, primero en salir.
