# --description--

Атрибут `type` повідомляє браузеру, який тип даних має приймати `input`. Деякі загальні значення атрибута `type` такі:

- `text`: однорядкове текстове поле
- `email`: текстове поле, яке перевіряє, чи ввів користувач дійсну адресу е-пошти
- `number`: поле для чисел
- `radio` та `checkbox`: варіанти, які користувач може вибрати

Ось приклад текстового поля вводу:

```html
<input type="text">
```

Для існуючого елемента `input` додайте атрибут `type` зі значенням `"text"`.

Також додайте елементу `input` атрибут `id` зі значенням `"full-name"`. Це відповідає атрибуту `for` у вашому елементі `label`, що зв’язує їх разом.

Коли користувач вводить своє повне ім'я, `input` прийматиме звичайний текст.
