## Instalación de Python en tu entorno local

- **Instalación**: La forma más fácil de instalar Python en Windows y macOS es descargar el instalador desde el sitio web oficial de Python (`https://www.python.org/`). En Linux, la mayoría de las distribuciones principales como Ubuntu, Debian y Fedora ya incluyen Python, así que primero verifica la versión instalada y solo instala un paquete específico de la distribución si falta Python 3.
- **Configuración en macOS**: Descarga y abre el instalador `.pkg` y sigue las indicaciones. Cuando termine, haz doble clic en el archivo `Install Certificates.command` y deja que el proceso en la terminal se complete para finalizar la configuración.
- **Configuración en Windows**: Descarga y ejecuta el Administrador de instalación de Python `.msix`. Después, los comandos `python`, `py` y `pymanager` estarán disponibles, ejecutar `python` sin un entorno de ejecución instalado instalará uno automáticamente, y puedes aceptar la opción para agregar un directorio de alias (para comandos como `python3.14.exe`) a tu `PATH`.
- **Configuración en Linux**: Abre una terminal y ejecuta `python --version` o `python3 --version`. Si ninguno muestra una versión de Python 3, busca un paquete de instalación en `https://www.python.org/` o busca en línea la forma recomendada de instalar Python para tu distribución.

## Verificar la instalación

- **Verificar la versión**: Confirma la instalación ejecutando `python --version` o `python3 --version` en una terminal.
- **`python` vs. `python3`**: En algunos sistemas macOS y Linux antiguos, `python` puede referirse a Python 2. Si `python --version` muestra una versión de Python 2, usa `python3` para tu código a partir de entonces. Python 2 está en fin de vida y no debe usarse para desarrollo nuevo.

## Terminal

- **Definición**: Un terminal es una interfaz basada en texto que te permite interactuar con tu computadora escribiendo comandos. Cada sistema operativo viene con una app de terminal predeterminada. En macOS, puedes usar la app Terminal. En Windows, puedes usar Command Prompt o PowerShell. En Linux, cada entorno de escritorio tiene su propia app de terminal predeterminada, como GNOME Terminal o Konsole.

## Editores de código e IDEs

- **IDE**: IDE significa entorno de desarrollo integrado, y tiene funcionalidades que incluyen un editor de código, herramientas de prueba, un terminal y más.
- **Editores de código e IDEs populares para Python**: VS Code, PyCharm y Spyder.

## Ejecutar scripts de Python

- **Configurar tu editor**: Abre la carpeta de tu proyecto en VS Code y crea un archivo `.py`. Instala la extensión de Python de Microsoft desde la vista de Extensiones o ejecutando `code --install-extension ms-python.python` (en macOS, primero debes agregar el comando `code` a tu `PATH`). La extensión agrega soporte para Python al editor pero no instala Python en sí.
- **Elegir un intérprete**: Ejecuta `Python: Select Interpreter` desde la paleta de comandos para apuntar el editor a un intérprete de Python 3 que hayas instalado antes.
- **Ejecutar tu código**: Haz clic en el botón de ejecutar (el ícono de play en la esquina superior derecha de VS Code) para ejecutar el archivo actual en una terminal. También puedes ejecutar un script manualmente desde una terminal. Por ejemplo, si tu carpeta de proyecto es `python-projects` y tu script es `main.py`, abre una terminal en la carpeta que contiene `python-projects`, luego entra en la carpeta del proyecto y ejecuta el script:

```bash
cd python-projects
python main.py
```

Usa `python3 main.py` en su lugar si `python3` es el comando que muestra Python 3 en tu sistema.

## Usar el intérprete interactivo de Python

- **Iniciar el shell**: Abre una terminal y ejecuta `python` o `python3` (usa el que haya mostrado una versión de Python 3). El prompt `>>>` significa que Python está esperando un comando. Prueba imprimir `"Hello, world!"`:

```python
print("Hello, world!")
```

- **Ciclo leer, evaluar, imprimir, repetir (REPL)**: El intérprete lee tu entrada, la evalúa, imprime el resultado y vuelve al prompt `>>>` para que puedas escribir otro comando.
- **Entrada inválida**: Ingresar algo que no sea Python válido, como `something random`, produce un mensaje `SyntaxError: invalid syntax` y el shell vuelve al prompt.
- **Salir del shell**: Escribe `exit()`, presiona <kbd>Ctrl</kbd> + <kbd>D</kbd> en macOS o Linux, o presiona <kbd>Ctrl</kbd> + <kbd>Z</kbd> seguido de <kbd>Enter</kbd> en Windows.
- **Cuándo usarlo**: El shell interactivo es ideal para experimentos pequeños y exploración rápida. Para programas más largos o trabajo en varios archivos, usa un editor de código o IDE.
