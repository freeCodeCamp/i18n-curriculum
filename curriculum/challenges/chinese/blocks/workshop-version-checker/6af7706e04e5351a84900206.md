# --description--

次版本发布会将次版本号增加 `1` 并将补丁号重置为 `0`，而补丁版本发布只会将补丁号增加 `1`。

添加一个 `elif` 分支，检查 `release_type` 是否相等于字串 `minor`。如果是，则为 `new_version` 赋值一个包含 `major`、`minor + 1` 和 `0` 的元组。

然后，添加另一个 `elif` 分支，检查 `release_type` 是否相等于字串 `patch`。如果是，则为 `new_version` 赋值一个包含 `major`、`minor` 和 `patch + 1` 的元组。
