# --description--

`try` 블록에서 발생한 오류를 포착하고 처리하려면 `catch` 블록을 추가해야 합니다. 이 블록에 매개변수를 선언하여 발생한 실제 오류 객체를 검사할 수 있습니다.

```js
try {
  // Code that might throw an error
} catch (err) {
  // Code to handle the error
}
```

`try` 블록 바로 아래에 `err`라는 매개변수를 가진 `catch` 블록을 추가하세요. 블록 안에서는 `statusDisplay`의 `textContent`를 `err.message`로 설정하여 DOM을 업데이트하세요.
