# --description--

In questo workshop, praticherai le list comprehension e le funzioni lambda pulendo le letture di un sensore di temperatura e confrontandole con la media abituale della temperatura del suo luogo.

Il sensore riporta le temperature in decimi di grado Celsius, quindi una lettura di `215` significa `21.5` °C. Quando non riesce a leggere la temperatura, scrive invece il codice di errore `-999`.

Crea una variabile chiamata `readings` e assegnale la lista `[215, 243, -999, 280, 316, 339, -999, 262, 305]`.

Poi, crea una variabile chiamata `average_temperature` e assegnale il float `28.0`. Questa è la media abituale della temperatura per il luogo, già in gradi Celsius, e confronterai le letture con essa.
