# --description--

各プログラムにはそれぞれ独自の`instructors`配列があります。プログラムのループ内にネストされた3つ目の`for`ループを追加し、`k = 0`から`program.instructors.length`まで`program.instructors`を繰り返してください。

インストラクターループを追加する前に、前のステップであった`console.log(departmentsById[departmentId])`を削除してください。

このループ内で、`instructor`という変数を`program.instructors[k]`に設定して宣言し、`instructor`をコンソールにログしてください。

# --before-each--

```js
globalThis.consoleSpy = __helpers.spyOn(console, "log");
```

# --after-each--

```js
globalThis.consoleSpy.restore();
delete globalThis.consoleSpy;
```
