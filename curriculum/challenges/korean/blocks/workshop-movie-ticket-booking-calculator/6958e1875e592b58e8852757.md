# --description--

`extra_charges`라는 변수를 만들고 값을 `0`으로 설정하세요. 이 변수는 저녁 상영 영화 티켓에 적용할 추가 요금을 나타냅니다.

동등 연산자(`==`)는 두 값이 같은지 확인하고 `True` 또는 `False`로 평가합니다. 이는 값을 변수에 저장하는 대입 연산자(`=`)와 다릅니다:

```py
color = 'red' # Assigns 'red' to color
print(color == 'red') # True
print(color == 'blue') # False
```

그다음, `if` 문을 만들어 `show_time`이 문자열 `Evening`과 같은지 확인하세요. `if` 문 내부에서는 `extra_charges` 값을 `2`로 업데이트하고 터미널에 `Extra charges will be applied`를 출력하세요.
