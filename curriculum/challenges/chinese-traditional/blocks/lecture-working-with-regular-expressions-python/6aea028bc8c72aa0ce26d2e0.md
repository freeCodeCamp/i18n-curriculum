# --description--

正則表達式可以包含由反斜線（`\`）後接一個字元組成的特殊序列。這些序列具有特殊意義。以下是一些最常見的：

- `\d` 匹配任何十進位數字，包括 `0` 到 `9`。

- `\w` 匹配任何字元：字母、數字和底線（`_`）。

- `\s` 匹配任何空白字元，例如空格、製表符或換行符。

- `\D`、`\W` 和 `\S` 匹配其小寫版本的相反字元。舉例來說，`\D` 匹配任何非數字字元。

不過有個陷阱。Python 字串也使用反斜線來寫轉義序列，例如 `\n`（換行）或 `\t`（製表符）：

```python
print('Tab:\tdone') # Tab:    done
```

這表示在一般 Python 字串中，反斜線可能會在 `re` 模組看到之前就被 Python 解讀。根據後面接的字元，這可能會改變你的樣式或讓 Python 顯示警告。

為避免這種情況，你可以使用未經處理的字串。你只要在開頭引號前加上字母 `r`（或 `R`）即可。未經處理的字串會將反斜線視為字面字元，而非轉義序列：

```python
print(r'Tab:\tdone') # Tab:\tdone
```

因此，養成習慣總是將正則表達式樣式寫成未經處理的字串是個好做法：

```python
import re

room = 'Room 42B'
print(re.search(r'\d', room))
# <re.Match object; span=(5, 6), match='4'>
```

注意 `re.search` 會傳回它找到的第一個符合項目。這裡，`\d` 匹配單一數字，所以匹配結果只有 `4`。如果你想匹配多於一個數字，可能會想用量詞。

量詞用來指定前一個字元或序列可以重複出現的次數。`+` 量詞匹配前一個字元出現一次或多次。

所以，雖然 `\d` 匹配單一數字，`\d+` 則匹配連續出現的一個或多個數字：

```python
import re

room = 'Room 42B'
print(re.search(r'\d+', room))
# <re.Match object; span=(5, 7), match='42'>
```

以下是其他常見的量詞：

- `*` 匹配前一個字元出現零次或多次。

- `?` 匹配前一個字元出現零次或一次，使其成為選用。

- `{n}` 精確匹配前一個字元出現 `n` 次。

- `{n,m}` 匹配前一個字元出現從 `n` 到 `m` 次。

```python
import re

print(re.search(r'go*al', 'What a goooal!'))
# <re.Match object; span=(7, 13), match='goooal'>

print(re.search(r'colou?r', 'My favorite color is blue'))
# <re.Match object; span=(12, 17), match='color'>

print(re.search(r'\d{4}', 'Room 42, built in 1987'))
# <re.Match object; span=(18, 22), match='1987'>
```

你可以在同一個樣式中結合字面字元、特殊序列和量詞。舉例來說，樣式 `r'\d+ items'` 匹配一個或多個數字，後面接一個空格和字串 `items`。你也可以搭配 `re.IGNORECASE` 旗標，使字母可為小寫或大寫：

```python
import re

cart = 'You have 3 ITEMS in your cart.'
print(re.search(r'\d+ items', cart, re.IGNORECASE))
# <re.Match object; span=(9, 16), match='3 ITEMS'>
```
