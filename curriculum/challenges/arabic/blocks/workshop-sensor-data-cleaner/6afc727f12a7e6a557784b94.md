# --description--

للحصول على مسمى لكل فرق، تحتاج إلى تعبير شرطي قبل `for` بدلاً من وجود `if` في النهاية:

```py
numbers = [1, 2, 3, 4]
labels = [
    'Even' if num % 2 == 0 else 'Odd'
    for num in numbers
]
print(labels) # ['Odd', 'Even', 'Odd', 'Even']
```

احذف الـ `if` اللاحق من تعبير القائمة الخاص بك. ثم، غيّر التعبير قبل `for` إلى تعبير شرطي يُقيّم إلى `f'+{difference} °C'` إذا كان `difference` أكبر من `0`، وإلى `f'{difference} °C'` خلاف ذلك. الأعداد السالبة تحتوي بالفعل على علامة `-`، لذا فهي تحتاج فقط إلى الوحدة.
