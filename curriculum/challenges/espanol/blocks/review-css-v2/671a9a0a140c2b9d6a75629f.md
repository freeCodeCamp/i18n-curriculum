## Conceptos básicos de CSS

- **¿Qué es CSS?**: Las hojas de estilo en cascada (CSS) son un lenguaje de hojas de estilo usado para aplicar estilos a elementos HTML. CSS se usa para colores, imágenes de fondo, diseños y más.
- **Anatomía básica de una regla CSS**: Una regla CSS está compuesta por dos partes principales: un selector y un bloque de declaraciones. Un selector es un patrón usado en CSS para identificar y seleccionar elementos HTML específicos para aplicar estilos. Un bloque de declaraciones aplica un conjunto de estilos para un selector o selectores dados.

## Trabajando con las propiedades `width` y `height`

- **Propiedad `width`**: Esta propiedad especifica el ancho de un elemento. Si no especificas un ancho, el valor predeterminado es `auto`. Esto permite que el navegador determine el ancho del elemento según su contenido, padre y tipo de visualización.
- **Propiedad `min-width`**: Esta propiedad especifica el ancho mínimo para un elemento.
- **Propiedad `max-width`**: Esta propiedad especifica el ancho máximo para un elemento.
- **Propiedad `height`**: Esta propiedad especifica la altura de un elemento. De manera similar, la altura es `auto` por defecto, lo que significa que se ajustará al contenido interno.
- **Propiedad `min-height`**: Esta propiedad especifica la altura mínima para un elemento.
- **Propiedad `max-height`**: Esta propiedad especifica la altura máxima para un elemento.

## Elementos en línea, de bloque y de nivel en línea/bloque

- **Elementos en línea**: Los elementos en línea solo ocupan el ancho que necesitan y no comienzan en una nueva línea. Estos elementos fluyen dentro del contenido, permitiendo que el texto y otros elementos en línea aparezcan junto a ellos. Los elementos en línea comunes son `span`, `a` y `img`.
- **Elementos de nivel bloque**: Los elementos de nivel bloque ocupan todo el ancho disponible por defecto, extendiéndose a lo largo del ancho de su contenedor. Algunos elementos comunes de nivel bloque son `div`, `p` y `section`.
- **Elementos de nivel inline-block**: Puedes establecer un elemento como `inline-block` usando la propiedad `display`. Estos elementos se comportan como elementos en línea pero pueden tener un `width` y `height` establecidos como los elementos de nivel bloque.

## Margen y Relleno

- **Propiedad `margin`**: Esta propiedad se usa para aplicar espacio fuera del elemento, entre el borde del elemento y los elementos circundantes.
- **Propiedad abreviada `margin`**: Puedes especificar de 1 a 4 valores para establecer los márgenes. Un valor se aplica a los cuatro lados; dos valores establecen `top` y `bottom`, luego `right` y `left`; tres valores establecen `top`, horizontal (`right` y `left`), luego `bottom`; cuatro valores establecen `top`, `right`, `bottom`, `left`.
- **Propiedad `padding`**: Esta propiedad se usa para aplicar espacio dentro del elemento, entre el contenido y su borde.
- **Propiedad abreviada `padding`**: Puedes especificar de 1 a 4 valores para establecer los rellenos. Un valor se aplica a los cuatro lados; dos valores establecen `top` y `bottom`, luego `right` y `left`; tres valores establecen `top`, horizontal (`right` y `left`), luego `bottom`; cuatro valores establecen `top`, `right`, `bottom`, `left`.

## Imágenes de fondo

- **Propiedad `background-image`**: Esta propiedad se usa para establecer una imagen de fondo para un elemento.
- **Propiedad `background-size`**: Esta propiedad define el tamaño de la imagen de fondo. El valor `contain` escala la imagen lo más grande posible sin recortarla ni estirarla. El valor `cover` escala la imagen para cubrir todo el elemento manteniendo su proporción, lo que puede recortar parte de la imagen.
- **Propiedad `background-repeat`**: Por defecto, las imágenes de fondo se repiten horizontal y verticalmente para llenar el elemento. El valor `no-repeat` evita que la imagen se repita, `repeat-x` la repite horizontalmente y `repeat-y` la repite verticalmente.
- **Propiedad `background-position`**: Esta propiedad define dónde aparece la imagen de fondo dentro del elemento. Puedes usar palabras clave como `top`, `bottom`, `left`, `right` y `center`, o valores en píxeles y porcentajes.
- **Propiedad `background-attachment`**: Esta propiedad determina si la imagen de fondo se desplaza con el contenido o permanece fija. El valor predeterminado es `scroll`, mientras que `fixed` mantiene la imagen en la misma posición en la pantalla cuando se desplaza la página.
- **Propiedad abreviada `background`**: Esta propiedad permite combinar varias propiedades de fondo, como `background-image`, `background-position` y `background-attachment`, en una sola declaración.

## Bordes

- **Propiedad `border`**: Esta es una propiedad abreviada usada para establecer el ancho, estilo y color de un borde de una sola vez. Los estilos de borde comunes incluyen `solid`, `dashed`, `dotted` y `double`.
- **Lados individuales del borde**: Las propiedades `border-top`, `border-right`, `border-bottom` y `border-left` permiten estilizar cada lado del borde por separado.
- **Propiedad `outline`**: Esta propiedad crea una línea alrededor de un elemento, similar a un borde. A diferencia del `border`, el `outline` no afecta las dimensiones ni el diseño del elemento.
- **Propiedad `border-radius`**: Esta propiedad se usa para crear esquinas redondeadas en el borde de un elemento.

## Especificidad de CSS

- **Especificidad de CSS en línea**: El CSS en línea tiene la especificidad más alta porque se aplica directamente al elemento. Sobrescribe cualquier CSS interno o externo. El valor de especificidad para estilos en línea es (1, 0, 0, 0).
- **Especificidad de CSS interno**: El CSS interno se define dentro de un elemento `style` en la sección `head` del documento HTML. Tiene menor especificidad que los estilos en línea. Tanto el CSS interno como el externo comparten el mismo nivel de especificidad, que se determina por sus selectores, no por su ubicación.
- **Especificidad de CSS externo**: El CSS externo se enlaza mediante un elemento `link` en la sección `head` y se escribe en archivos `.css` separados. Al igual que el CSS interno, su especificidad se determina por los selectores usados. Cuando dos reglas tienen igual especificidad, el orden en el código determina el ganador: la regla que aparece más tarde en el documento tiene prioridad. El CSS externo ofrece la mejor mantenibilidad para proyectos grandes.
- **Selector universal (`*`)**: Es un tipo especial de selector CSS que coincide con cualquier elemento en el documento. Se usa a menudo para aplicar un estilo a todos los elementos de la página, lo que puede ser útil para reiniciar o normalizar estilos entre navegadores. El selector universal tiene el valor de especificidad más bajo de cualquier selector. Contribuye con 0 a todas las partes del valor de especificidad (0, 0, 0, 0).
- **Selectores de tipo**: Estos selectores apuntan a elementos basados en su nombre de etiqueta. Los selectores de tipo tienen una especificidad relativamente baja comparada con otros selectores. El valor de especificidad para un selector de tipo es (0, 0, 0, 1).
- **Selectores de clase**: Estos selectores se definen con un punto (`.`) seguido del nombre de la clase. El valor de especificidad para un selector de clase es (0, 0, 1, 0). Esto significa que los selectores de clase pueden sobrescribir selectores de tipo, pero pueden ser sobrescritos por selectores de ID y estilos en línea.
- **Selectores de ID**: Los selectores de ID se definen con un símbolo de almohadilla (`#`) seguido del nombre del ID. Los selectores de ID tienen una especificidad muy alta, mayor que los selectores de tipo y clase, pero menor que los estilos en línea. El valor de especificidad para un selector de ID es (0, 1, 0, 0).
- **Palabra clave `!important`**: se usa para dar a una regla de estilo la máxima prioridad, permitiendo que sobrescriba cualquier otra declaración para una propiedad. Cuando se usa, fuerza al navegador a aplicar el estilo especificado, sin importar la especificidad de otros selectores. Debes tener cuidado al usar `!important` porque puede hacer que tu CSS sea más difícil de mantener y depurar.

## Unidades absolutas

- **`px` (píxeles)**: Esta unidad absoluta es una unidad de tamaño fijo en CSS, que proporciona control preciso sobre las dimensiones. Esto significa que 1px siempre equivale a 1/96 de pulgada.
- **`in` (pulgada)**: Esta unidad absoluta equivale a 96px.
- **`cm` (centímetros)**: Esta unidad absoluta equivale a 25.2/64 de pulgada.
- **`mm` (milímetros)**: Esta unidad absoluta equivale a 1/10 de centímetro.
- **`q` (cuarto de milímetro)**: Esta unidad absoluta equivale a 1/40 de centímetro.
- **`pc` (picas)**: Esta unidad absoluta equivale a 1/6 de pulgada.
- **`pt` (puntos)**: Esta unidad absoluta equivale a 1/72 de pulgada.

## Unidades Relativas

- **Porcentajes**: Estas unidades relativas te permiten definir tamaños, dimensiones y otras propiedades como una proporción del elemento padre. Por ejemplo, si estableces `width: 50%;` en un elemento, ocupará la mitad del ancho de su contenedor padre.
- **Unidad `em`**: Estas unidades son relativas al tamaño de la fuente del elemento. Si usas `ems` para la propiedad `font-size`, el tamaño del texto será relativo al tamaño de la fuente del elemento padre.
- **Unidad `rem`**: Estas unidades son relativas al tamaño de la fuente del elemento raíz, que es el elemento `html`.
- **Unidad `vh`**: `vh` significa `"viewport height"` y `1vh` equivale al 1% de la altura del viewport.
- **Unidad `vw`**: `vw` significa `"viewport width"` y `1vw` equivale al 1% del ancho del viewport.

## Función `calc`

- **`calc()` Función**: Con la función `calc()`, puedes realizar cálculos directamente dentro de tus hojas de estilo para determinar valores de propiedades dinámicamente. Esto significa que puedes crear interfaces de usuario flexibles y receptivas calculando dimensiones basadas en el tamaño del viewport u otros elementos.

## Pseudoclases

- **Definición de pseudoclases**: Son palabras clave especiales de CSS que te permiten seleccionar un elemento basado en su estado o posición específica.
- **Pseudoclase `:active`**: Esta pseudoclase te permite seleccionar el estado activo de un elemento, como cuando haces clic en un botón.
- **Pseudoclase `:hover`**: Esta pseudoclase define el estado hover (pasar el cursor) de un elemento.
- **Pseudoclase `:focus`**: Esta pseudoclase aplica estilos cuando un elemento recibe enfoque, típicamente mediante navegación con teclado o cuando un usuario hace clic en una entrada de formulario.
- **Pseudoclase `:first-child`**: Esta pseudoclase selecciona el primer elemento dentro de un elemento padre o del documento.
- **Pseudoclase `:last-child`**: Esta pseudoclase selecciona el último elemento dentro de un elemento padre o del documento.
- **Pseudoclase `:first-of-type`**: Esta pseudoclase selecciona la primera ocurrencia de un tipo específico de elemento dentro de su padre.
- **Pseudoclase `:last-of-type`**: Esta pseudoclase selecciona la última ocurrencia de un tipo específico de elemento dentro de su padre.
- **Pseudoclase `:nth-of-type(n)`**: Esta pseudoclase te permite seleccionar un elemento específico dentro de su padre basado en su posición entre hermanos del mismo tipo.
- **Pseudoclase `:visited`**: Esta pseudoclase apunta a un enlace que el usuario ha visitado.
- **Pseudoclase `:enabled`**: Esta pseudoclase se usa para seleccionar botones de formulario u otros elementos que están habilitados.
- **Pseudoclase `:disabled`**: Esta pseudoclase te permite estilizar un elemento interactivo en modo deshabilitado.
- **Pseudoclase `:checked`**: Esta pseudoclase se usa para indicar al usuario que un elemento está marcado.

## Pseudo-elementos

- **`::before` Pseudo-elemento**: Este pseudo-elemento usa la propiedad `content` para insertar contenido cosmético, como íconos justo antes del elemento.
- **`::after` Pseudo-elemento**: Este pseudo-elemento usa la propiedad `content` para insertar contenido cosmético, como íconos justo después del elemento.
- **`::first-letter` Pseudo-elemento**: Este pseudo-elemento apunta a la primera letra del contenido de un elemento, lo que te permite estilizarla.
- **`::marker` Pseudo-elemento**: Este pseudo-elemento te permite seleccionar el marcador (viñeta o numeración) de elementos de lista para estilizado.

## Diferentes Formas de Trabajar con Colores en CSS

- **Colores nombrados**: Estos colores son nombres predefinidos reconocidos por los navegadores. Ejemplos incluyen `blue`, `darkred`, `lightgreen`.
- **Función `rgb()`**: RGB significa rojo, verde y azul, los colores primarios de la luz. Estos tres colores se combinan en diferentes intensidades para crear una amplia gama de colores. La función `rgb()` te permite definir colores usando el modelo de color RGB.
- **Función `rgba()`**: Esta función añade un cuarto valor, alfa, que controla la transparencia del color.
- **Función `hsl()`**: HSL significa tono, saturación y luminosidad, tres componentes clave que definen un color.
- **Función `hsla()`**: Esta función añade un cuarto valor, alfa, que controla la opacidad del color.
- **Hexadecimal**: Un código hex (abreviatura de código hexadecimal) es una cadena de seis caracteres usada para representar colores en el modelo RGB. "Hex" se refiere al sistema de numeración base 16, que usa dígitos del 0 al 9 y letras de la A a la F.

## Propiedad `box-shadow`

- **Definición**: La propiedad `box-shadow` aplica una o más sombras alrededor de un elemento.
- **Valores de desplazamiento**: Debes especificar valores horizontales (`offset-x`) y verticales (`offset-y`). Un `offset-x` positivo mueve la sombra a la derecha, mientras que valores negativos la mueven a la izquierda. Un `offset-y` positivo mueve la sombra hacia abajo, mientras que valores negativos la mueven hacia arriba. Si un valor es `0`, no necesitas incluir una unidad.
- **Radio de desenfoque**: Este valor opcional controla qué tan borrosa aparece la sombra. Si no se incluye, el valor predeterminado es `0`, lo que crea bordes nítidos. A mayor valor, más suave es la sombra.
- **Radio de expansión**: Este valor opcional controla cuánto se expande o contrae la sombra. Si no se incluye, el valor predeterminado es `0`.
- **Color de la sombra**: Puedes especificar el color usando colores nombrados, valores hexadecimales, funciones `rgb()`, `rgba()`, `hsl()` o `hsla()`.

## Gradientes

- **Degradados lineales**: Estos degradados crean una mezcla gradual entre colores a lo largo de una línea recta. Puedes controlar la dirección de esta línea y los colores usados.

## Propiedad de Transformación de CSS

- **Definición**: Esta propiedad te permite aplicar varias transformaciones a los elementos, como rotar, escalar, sesgar o trasladar (mover) en espacio 2D o 3D.
- **Función `rotate()`**: Esta función se usa para rotar un elemento alrededor de su centro.

## El Modelo de Caja

- **Definición**: En el modelo de caja CSS, cada elemento está rodeado por una caja. Esta caja consiste en cuatro componentes: el área de contenido, `padding`, `border`, `margin`.
- **Área de Contenido**: El área de contenido es la parte más interna de la caja. Es el espacio que contiene el contenido real de un elemento, como texto o imágenes.
- **`padding`**: El padding es el área inmediatamente después del área de contenido. Es el espacio entre el área de contenido y el borde de un elemento.
- **`border`**: El borde es el borde o contorno exterior de un elemento en el modelo de caja CSS. Es el límite visual del elemento.
- **`margin`**: El margen es el espacio fuera del borde de un elemento. Determina la distancia entre un elemento y otros elementos alrededor de él.

## Los Valores de las Propiedades `content-box` y `border-box`

- **Propiedad `box-sizing`**: Esta propiedad se usa para determinar cómo se calculan el `width` y `height` totales de un elemento HTML.
- **Valor `content-box`**: En el modelo `content-box`, el `width` y `height` que estableces para un elemento determinan las dimensiones del área de contenido, pero no incluyen el `padding` ni el `border`.
- **Valor `border-box`**: Con `border-box`, el `width` y `height` que estableces para un elemento incluyen el área de contenido, el `padding` y el `border`.

## Propiedad de Filtro CSS

- **Definición**: Esta propiedad puede usarse para crear varios efectos, como desenfoque.
- **Función `blur()`**: Esta función aplica un desenfoque al elemento. La cantidad se define en píxeles y representa el radio del desenfoque.

## Introducción a CSS Flexbox y el Modelo Flex

- **Definición**: CSS flexbox es un modelo de diseño unidimensional que te permite organizar elementos en filas y columnas dentro de un contenedor.
- **Modelo flex**: Este modelo define cómo se organizan los elementos flexibles dentro de un contenedor flex. Cada contenedor flex tiene dos ejes: el eje principal y el eje transversal.

## La Propiedad `flex-direction`

- **Definición**: Esta propiedad establece la dirección del eje principal. El valor predeterminado de `flex-direction` es `row`, que coloca todos los elementos flexibles en la misma fila, en la dirección del idioma predeterminado de tu navegador (de izquierda a derecha o de derecha a izquierda).
- **`flex-direction: row-reverse;`**: Esto invierte el orden de los elementos en la fila.
- **`flex-direction: column;`**: Esto alinea los elementos flexibles verticalmente en lugar de horizontalmente.
- **`flex-direction: column-reverse;`**: Esto invierte el orden de los elementos flexibles verticalmente.

## La Propiedad `flex-wrap`

- **Definición**: Esta propiedad determina cómo se envuelven los elementos flexibles dentro de un contenedor flex para ajustarse al espacio disponible. `flex-wrap` puede tomar tres valores posibles: `nowrap`, `wrap` y `wrap-reverse`.
- **`flex-wrap: nowrap;`**: Este es el valor predeterminado. Los elementos flexibles no se envolverán en una nueva línea, incluso si su ancho excede el del contenedor.
- **`flex-wrap: wrap;`**: Esta propiedad envolverá los elementos cuando excedan el ancho de su contenedor.
- **`flex-wrap: wrap-reverse;`**: Esta propiedad envolverá los elementos flexibles en orden inverso.
- **Propiedad `flex-flow`**: Esta propiedad es una abreviatura para `flex-direction` y `flex-wrap`.

## La Propiedad `justify-content`

- **Definición**: Esta propiedad alinea los elementos hijos a lo largo del eje principal del contenedor flex.
- **`justify-content: flex-start;`**: En este caso, los elementos flexibles se alinearán al inicio del eje principal. Esto podría ser horizontal o vertical.
- **`justify-content: flex-end;`**: En este caso, los elementos flexibles están alineados al final del eje principal, ya sea horizontal o verticalmente.
- **`justify-content: center;`**: Esto centra los elementos flexibles a lo largo del eje principal.
- **`justify-content: space-between;`**: Esto distribuirá los elementos uniformemente a lo largo del eje principal.
- **`justify-content: space-around;`**: Esto distribuirá los elementos flexibles uniformemente dentro del eje principal, agregando un espacio antes del primer elemento y después del último elemento.
- **`justify-content: space-evenly;`**: Esto distribuye los elementos de manera uniforme a lo largo del eje principal.

## La Propiedad `align-items`

- **Definición**: Esta propiedad se utiliza para distribuir elementos a lo largo del eje cruzado. Recuerda que el eje transversal es perpendicular al eje principal.
- **`align-items: center;`**: Se utiliza para centrar los elementos a lo largo del eje cruzado.
- **`align-items: flex-start;`**: Esto alinea los elementos al inicio del eje cruzado.
- **`align-items: stretch;`**: Se utiliza para estirar los elementos flexibles a lo largo del eje cruzado.

## Propiedad CSS `font-family`

- **Definición**: Una familia de fuentes es un grupo de fuentes que comparten un diseño común. Todas las fuentes que pertenecen a la misma familia están basadas en la misma tipografía principal pero también tienen variaciones en su estilo, peso y ancho. Puedes especificar múltiples familias de fuentes en orden de prioridad, de mayor a menor, separándolas con comas. Estas fuentes alternativas actuarán como opciones de respaldo. Siempre debe incluir una familia de fuentes genérica al final de la lista de la propiedad font-family.
- **Familias de fuentes comunes**: Aquí están algunas de las familias de fuentes comunes utilizadas en CSS: serif, sans-serif, monospace, cursive, fantasy.

## Trabajando con diferentes selectores de atributos y enlaces

- **Definición**: El selector de `attribute` te permite seleccionar elementos HTML basándote en sus atributos como los atributos `href` o `title`.

## Diferentes tipos de combinadores CSS

- **Combinador descendiente (` `) *un espacio simple entre selectores**: Este combinador se usa para seleccionar elementos que son descendientes de un elemento padre especificado.
- **Combinador hijo (`>`)**: Este combinador se usa para seleccionar elementos que son hijos directos de un elemento padre especificado.
- **Combinador hermano siguiente (`+`)**: Este combinador selecciona un elemento que sigue inmediatamente a un elemento hermano especificado.
- **Combinador hermano posterior (`~`)**: Este combinador selecciona todos los hermanos de un elemento especificado que vienen después de él.

## Posicionamiento Estático, Relativo y Absoluto

- **Posicionamiento Estático**: Este es el flujo normal del documento. Los elementos están posicionados de arriba a abajo, y de izquierda a derecha uno tras otro.
- **Posicionamiento Relativo**: Esto te permite usar las propiedades `top`, `left`, `right` y `bottom` para posicionar el elemento dentro del flujo normal del documento. También puedes usar el posicionamiento relativo para hacer que los elementos se superpongan con otros elementos en la página.
- **Posicionamiento Absoluto**: Esto te permite extraer un elemento del flujo normal del documento, haciéndolo comportar de manera independiente de otros elementos.

## Posicionamiento Fijo y Adhesivo

- **Posicionamiento fijo**: Cuando un elemento está posicionado con `position: fixed`, se elimina del flujo normal del documento y se coloca relativo al viewport, lo que significa que permanece en la misma posición incluso cuando el usuario hace scroll. Esto se usa a menudo para elementos como encabezados o barras de navegación que deben permanecer visibles en todo momento.
- **Posicionamiento sticky**: Este tipo de posicionamiento actúa como un híbrido entre el posicionamiento relativo y fijo. Inicialmente, el elemento se comporta como si estuviera posicionado relativamente, permaneciendo dentro del flujo del documento. Sin embargo, una vez que el usuario desplaza el elemento más allá de cierto punto, este "se pega" al viewport (usualmente en la parte superior) y se comporta como si estuviera fijo. Esto es ideal para crear elementos como barras de navegación sticky, que solo se fijan cuando el usuario hace scroll hasta cierta posición.

## Trabajando con la Propiedad `z-index`

- **Definición**: La propiedad `z-index` en CSS se utiliza para controlar el orden de apilamiento vertical de elementos posicionados que se superponen en la página.

## Consultas de Medios

- **Definición**: Esto permite a los desarrolladores aplicar diferentes estilos basándose en las características del dispositivo, principalmente el ancho del viewport.

## Propiedades Personalizadas CSS (Variables CSS)

- **Definición**: Las propiedades personalizadas de CSS, también conocidas como variables CSS, son entidades definidas por los autores de CSS que contienen valores específicos para ser reutilizados a lo largo de un documento. Son una característica poderosa que permite hojas de estilo más eficaces, mantenibles y flexibles. Las propiedades personalizadas son particularmente útiles para crear diseños tematizables. Puedes definir un conjunto de propiedades para diferentes temas.

## Conceptos básicos de CSS Grid

- **Definición**: CSS Grid es un sistema de diseño bidimensional usado para crear diseños complejos en páginas web. Las rejillas tienen filas y columnas con espacios entre ellas. Para definir un diseño de rejilla, se establece la propiedad `display` en `grid`.
- **Unidad `fr` (fraccional)**: Esta unidad representa una fracción del espacio dentro del contenedor de rejilla. Puedes usar la unidad `fr` para crear rejillas flexibles.
- **Crear espacios entre pistas**: Hay tres formas de crear espacios entre pistas en CSS grid. Puedes usar la propiedad `column-gap` para crear espacios entre columnas. Puedes usar la propiedad `row-gap` para crear espacios entre filas. O puedes usar la propiedad abreviada `gap` para crear espacios entre filas y columnas.
- **Función `repeat()`**: Esta función se usa para repetir secciones en la lista de pistas. En lugar de escribir `grid-template-columns: 1fr 1fr 1fr;` puedes usar la función `repeat()`.
- **Rejilla explícita**: Puedes especificar el número de líneas o pistas usando las propiedades `grid-template-columns` o `grid-template-rows`.
- **Rejilla implícita**: Cuando los elementos se colocan fuera de la rejilla, se crean automáticamente filas y columnas para esos elementos externos.
- **Función `minmax()`**: Esta función se usa para establecer los tamaños mínimo y máximo para una pista.
- **Colocación automática en rejilla**: El navegador coloca automáticamente los elementos usando el algoritmo de colocación automática. La propiedad `grid-auto-flow` controla este comportamiento, usando valores como `row`, `column` o `dense` para influir en la dirección de colocación y si se rellenan huecos vacíos.
- **Colocación basada en líneas**: Todas las rejillas tienen líneas. Para especificar dónde comienza un elemento en una línea, puedes usar las propiedades `grid-column-start` y `grid-row-start`. Para especificar dónde termina el elemento en la línea, puedes usar las propiedades `grid-column-end` y `grid-row-end`. También puedes usar las propiedades abreviadas `grid-column` o `grid-row`.
- **`grid-template-areas`**: Esta propiedad se usa para asignar un nombre a los elementos que vas a posicionar en la rejilla.
- **Alineación:** Usa `justify-items` y `align-items` para controlar cómo se alinean los elementos dentro de sus áreas de rejilla. Usa `justify-self` y `align-self` en elementos individuales para sobrescribir la alineación establecida en el contenedor.
