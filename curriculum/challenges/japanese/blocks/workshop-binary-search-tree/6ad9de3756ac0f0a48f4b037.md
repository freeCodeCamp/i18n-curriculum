# --description--

ツリーができたら、それを走査できます。走査とは、すべてのノードを一度ずつ訪問することです。

Inorder traversalは深さ優先走査の一種で、枝をできるだけ深く進んでから次の枝に移ります。各ノードでは次の順に訪問します：

1. 左のサブツリー。
1. ノード自身。
1. 右のサブツリー。

`BinarySearchTree`クラスの中に、`_inorder_traversal`という名前のメソッドを作成してください。パラメータは3つで、`self`、`node`、`result`です。`node`は訪問中のノードで、`result`はキーを集めるリストです。

class TreeNode:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None


class BinarySearchTree:
    def __init__(self):
        self.root = None

    def _insert(self, node, key):
        if node is None:
            return TreeNode(key)
        if key < node.key:
            node.left = self._insert(node.left, key)
        elif key > node.key:
            node.right = self._insert(node.right, key)
        return node

    def insert(self, key):
        self.root = self._insert(self.root, key)
