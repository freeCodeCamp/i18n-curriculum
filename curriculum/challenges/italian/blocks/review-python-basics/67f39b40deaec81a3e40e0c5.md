## Cos'è Python?

- **Python**: Python è un linguaggio di programmazione general-purpose noto per la sua semplicità e facilità d'uso.
- **Casi d'uso comuni**: Python è usato in data science, machine learning, sviluppo web, cybersecurity, sistemi embedded e IoT, scripting, automazione e microcomputer come Raspberry Pi e schede compatibili con MicroPython.

## Variabili

- **Dichiarare variabili**: Per dichiarare una variabile, inizi con il nome della variabile seguito dall’operatore di assegnazione (`=`) e poi il valore. Questo può essere un numero, una stringa, un booleano, ecc. Ecco alcuni esempi:

```py
name = 'John Doe'
age = 25
```

- **Convenzioni per i nomi delle variabili**: Ecco le convenzioni che dovresti usare per i nomi delle variabili:

  - I nomi delle variabili possono iniziare solo con una lettera o un underscore (`_`), non con un numero.
  - I nomi delle variabili possono contenere lettere (`a-z`, `A-Z`), cifre (`0-9`) e underscore (`_`).
  - I nomi delle variabili sono case-sensitive: `age`, `Age` e `AGE` sono considerati tutti unici.
  - I nomi delle variabili non possono essere parole chiave riservate di Python come `if`, `class` o `def`.
  - I nomi delle variabili composti da più parole usano gli underscore, come in `snake_case`.
  - I nomi delle variabili dovrebbero descrivere il loro scopo, come in `user_age`.
  - I nomi di variabili di una sola lettera dovrebbero essere evitati quando non comunicano un significato.

## Commenti

- **Commenti su singola riga**: Questo tipo di commento va usato per brevi note nel tuo codice.

```py
# This is a single line comment
```

- **Commenti multilinea**: Puoi usare un `#` all'inizio di ogni riga per creare commenti su più righe.

```py
# This is a multi-line comment.
# Here is some code commented out.
#
# name = 'John Doe'
# age = 25
```

## Stampare

- **Funzione `print()`**: Per stampare dati nel terminale, puoi usare la funzione `print()` in questo modo:

```py
print('Hello world!') # Hello world!
```

Puoi passare multipli argomenti a `print()` separandoli con delle virgole. Per impostazione predefinita, `print()` inserisce uno spazio tra i valori mostrati:

```py
print('Hello', 'world!') # Hello world!
```

## Tipi di dati comuni in Python

- **Tipizzazione dinamica**: Python è un linguaggio a tipizzazione dinamica, il che significa che non devi dichiarare il tipo di dato di una variabile. Python determina il tipo dal valore assegnato alla variabile.

- **Numero intero**: Un numero intero senza decimali:

```py
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- **Float**: Un numero con decimali:

```py
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- **Stringa**: Una sequenza di caratteri racchiusa tra virgolette:

```py
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- **Booleano**: Un valore che rappresenta `True` o `False`:

```py
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python ha altri tipi di dati. Imparerai ciascuno di essi quando ne avrai bisogno per la prima volta.

- **Funzione `type()`**: Per vedere il tipo di una variabile, puoi usare la funzione `type()` in questo modo:

```py
greeting = 'Hello there!'
age = 21

print(type(greeting)) # <class 'str'>
print(type(age)) # <class 'int'>
```

- **Funzione `isinstance()`**: Serve a verificare se una variabile corrisponde a un tipo di dato specifico:

```py
greeting = 'Hello world'
name = 'John Doe'

print(isinstance(greeting, str)) # True
print(isinstance(name, int)) # False
```

Per verificare più tipi, metti i tipi tra parentesi, separati da virgole, e passali come secondo argomento. Il risultato è `True` se il valore è un'istanza di uno qualsiasi dei tipi elencati:

```py
account_balance = 12
print(isinstance(account_balance, (int, float))) # True
```

## Lavorare con le stringhe

- **Stringhe**: Le stringhe sono sequenze di caratteri. In Python puoi usare sia virgolette singole sia virgolette doppie. Scegli uno stile e usalo in modo coerente:

```py
developer = 'Jessica'
city = "Los Angeles"
```

- **Stringhe multilinea**: Le triple virgolette singole o triple virgolette doppie permettono a una stringa di estendersi su più righe:

```py
message = """Hello
world!"""
print(message)
# Hello
# world!
```

- **Virgolette all'interno delle stringhe**: Puoi usare il tipo di virgolette opposto intorno a una stringa per evitare di dover scappare i suoi segni di citazione:

```py
msg = "It's a sunny day"
quote = 'She said, "Hello!"'
```

- **Escape delle stringhe**: Puoi usare una barra rovesciata (`\`) se la tua stringa contiene virgolette così:

```py
msg = 'It\'s a sunny day'
quote = "She said, \"Hello!\""
```

- **Sequenze di escape**: Una barra rovesciata combinata con un altro carattere può rappresentare un carattere speciale. Per esempio, `\n` rappresenta una nuova riga, `\t` rappresenta una tabulazione e `\\` rappresenta una singola barra rovesciata:

```py
print('Hello\nworld')
# Hello
# world

print('Name:\tAlice')  # Name:   Alice
print('C:\\Users\\Alice')  # C:\Users\Alice
```

- **Operatore `in`**: Restituisce un booleano che specifica se il carattere o i caratteri esistono nella stringa oppure no:

```py
my_str = 'Hello world'

print('Hello' in my_str)  # True
print('hey' in my_str)    # False
print('hi' in my_str)    # False
print('e' in my_str)  # True
print('f' in my_str)  # False
```

- **Ottenere la lunghezza di una stringa**: La funzione `len()` restituisce il numero di caratteri in una stringa:

```py
developer = 'Jessica'

print(len(developer)) # 7
```

- **Consultare caratteri nelle stringhe**: Puoi consultare i caratteri nelle stringhe usando la notazione a parentesi così:

```py
my_str = 'Hello world'

print(my_str[0])  # H
print(my_str[6])  # w

print(my_str[-1])  # d
print(my_str[-2]) # l
```

- **Riassegnazione e immutabilità**: Le stringhe sono immutabili, il che significa che non puoi modificarle dopo che sono state create. Riassegnare una variabile la fa riferire a un valore diverso. Non modifica la stringa originale:

```py
greeting = 'hi'
greeting = 'hello'
print(greeting) # hello
```

La modifica diretta di una stringa non è permessa:

```py
greeting = 'hi'
greeting[0] = 'H' # TypeError: 'str' object does not support item assignment
```

Anche numeri interi, float e booleani sono immutabili.

- **Concatenazione di stringhe**: Per concatenare stringhe puoi usare l’operatore `+` così:

```py
developer = 'Jessica'
print('My name is ' + developer + '.') # My name is Jessica.
```

- **Ripetizione di stringhe**: L'operatore `*` ripete una stringa un numero specificato di volte:

```py
print('ha' * 3) # hahaha
```

- **Concatenare stringhe con numeri**: Concatenare una stringa e un numero genera un `TypeError`:

```py
'Age: ' + 26 # TypeError: can only concatenate str (not "int") to str
```

La funzione `str()` converte il numero in una stringa così può essere concatenata:

```py
print('Age: ' + str(26)) # Age: 26
```

Un altro modo per concatenare stringhe è usare l’operatore `+=`. Serve a fare concatenazione e assegnazione nello stesso passaggio così:

```py
greeting = 'My name is '
developer = 'Jessica.'

greeting += developer
print(greeting) # My name is Jessica.
```

L'operatore `*=` ripete una stringa e assegna il risultato di nuovo alla variabile:

```py
sound = 'ha'
sound *= 3
print(sound) # hahaha
```

Sia `+=` che `*=` assegnano una nuova stringa alla variabile senza modificare la stringa originale.

- **`f-strings`**: È l’abbreviazione di formatted string literals. Ti permette di gestire l’interpolazione e anche di fare un po’ di concatenazione con una sintassi compatta e leggibile:

```py
developer = 'Jessica'
greeting = f'My name is {developer}.'
print(greeting) # My name is Jessica.
```

I campi di sostituzione nelle f-string possono contenere espressioni. Python valuta l'espressione e inserisce il suo valore nella stringa:

```py
num1 = 5
num2 = 10
print(f'The sum is {num1 + num2}') # The sum is 15
```

- **Slicing delle stringhe**: È quando puoi estrarre porzioni di una stringa. Ecco la sintassi base:

```py
str[start:stop:step]
```

L'indice `start` specifica dove inizia l'estrazione. L'indice `stop` non è incluso, quindi il carattere a quell'indice non è incluso. Il `step` specifica l'intervallo tra gli indici selezionati e per impostazione predefinita è `1`. Con un `step` positivo, un `start` omesso corrisponde all'inizio della stringa e un `stop` omesso corrisponde alla fine. `[:]` estrae l'intera stringa. `[::-1]` inverte la stringa facendo un passo indietro dall'ultimo carattere al primo. Lo slicing non modifica la stringa originale.

```py
message = 'Python is fun!'

print(message[0:6])  # Python
print(message[:6])  # Python
print(message[7:])  # is fun!
print(message[::2])  # Pto sfn
print(message[:])  # Python is fun!
print(message[::-1])  # !nuf si nohtyP
```

## Metodi comuni per le stringhe

- **Metodi**: Un metodo è una funzione che chiami su un valore. Per chiamare un metodo di una stringa, scrivi la stringa o il nome della sua variabile seguito da un punto e dalla chiamata al metodo.

- **`str.upper()`**: Restituisce una nuova stringa con tutti i caratteri convertiti in maiuscolo:

```py
developer = 'Jessica'

print(developer.upper()) # JESSICA
```

- **`str.lower()`**: Restituisce una nuova stringa con tutti i caratteri convertiti in minuscolo:

```py
developer = 'Jessica'

print(developer.lower()) # jessica
```

- **`str.strip()`**: Restituisce una copia della stringa con i caratteri iniziali e finali specificati rimossi (se non viene passato alcun argomento al metodo, rimuove gli spazi bianchi iniziali e finali).

```py
greeting = '  hello world  '

trimmed_my_str = greeting.strip()
print(trimmed_my_str)  # hello world
```

- **`replace()`**: Restituisce una nuova stringa con tutte le occorrenze della vecchia stringa sostituite da una nuova.

```py
greeting = 'hello world'

replaced_my_str = greeting.replace('hello', 'hi')
print(replaced_my_str)  # hi world
```

- **`split()`**: Serve a dividere una stringa in una lista usando un separatore specificato. Un separatore è una stringa che indica dove deve avvenire la divisione. Se non viene specificato alcun separatore, `split()` divide sugli spazi bianchi.

```py
dashed_name = 'example-dashed-name'

split_words = dashed_name.split('-')
print(split_words)  # ['example', 'dashed', 'name']
```

- **`join()`**: Serve per unire una collezione di stringhe in un'unica stringa usando un separatore.

```py
example_list = ['example', 'dashed', 'name']

joined_str = ' '.join(example_list)
print(joined_str)  # example dashed name
```

- **`str.startswith(prefix)`**: Restituisce un booleano che indica se una stringa inizia con il prefisso specificato:

```py
developer = 'Naomi'

result = developer.startswith('N')
print(result)  # True
```

- **`str.endswith(suffix)`**: Restituisce un booleano che indica se una stringa termina con il suffisso specificato:

```py
developer = 'Naomi'

result = developer.endswith('N')
print(result)  # False
```

- **`str.find()`**: Restituisce l'indice della prima occorrenza di una sottostringa. Se non viene trovata, restituisce `-1`:

```py
developer = 'Naomi'

result = developer.find('N')
print(result)  # 0

city = 'Los Angeles'
print(city.find('New')) # -1
```

- **`str.count(substring)`**: Conta quante volte una sottostringa appare in una stringa senza sovrapposizioni. Una volta trovata una corrispondenza, la ricerca continua dopo la fine di quella corrispondenza:

```py
city = 'Los Angeles'
print(city.count('e')) # 2

# Matches do not overlap, so this is 2, not 3
print('aaaa'.count('aa')) # 2
```

- **`str.capitalize()`**: Restituisce una nuova stringa con il primo carattere maiuscolo e gli altri caratteri minuscoli:

```py
dessert = 'chocolate cake'
print(dessert.capitalize()) # Chocolate cake
```

- **`str.isupper()`**: Restituisce `True` se la stringa contiene almeno un carattere con distinzione di maiuscole/minuscole e tutti i caratteri con distinzione sono maiuscoli. Altrimenti, restituisce `False`:

```py
dessert = 'chocolate cake'
print(dessert.isupper()) # False
```

- **`str.islower()`**: Restituisce `True` se la stringa contiene almeno un carattere con distinzione di maiuscole/minuscole e tutti i caratteri con distinzione sono minuscoli. Altrimenti, restituisce `False`:

```py
dessert = 'chocolate cake'
print(dessert.islower()) # True
```

- **`str.title()`**: Restituisce una nuova stringa con la prima lettera di ogni parola maiuscola e le altre lettere minuscole:

```py
city = 'lOS aNGELES'
print(city.title()) # Los Angeles
```

## Altre operazioni sulle stringhe

- **Limiti negativi dello slicing**: I limiti dello slicing possono contare all'indietro dalla fine di una stringa. Per esempio, `[-3:]` estrae gli ultimi tre caratteri:

```py
employee_code = 'DEV-2026-JD-001'
print(employee_code[-3:]) # 001
```

- **Concatenamento di metodi**: Puoi chiamare più metodi di stringa in un'unica espressione. Ogni metodo opera sul risultato della chiamata precedente:

```py
name = '  jANE dOE  '
print(name.strip().title()) # Jane Doe
```

## Operazioni comuni usate con numeri interi e float

- **Operazioni matematiche di base**: In Python puoi fare operazioni matematiche di base con numeri interi e float, inclusi addizione, sottrazione, moltiplicazione e divisione:

```py
int_1 = 56
int_2 = 12
float_1 = 5.4
float_2 = 12.0

# Addition

print('Integer Addition:', int_1 + int_2) # Integer Addition: 68
print('Float Addition:', float_1 + float_2) # Float Addition: 17.4

# Subtraction

print('Int Subtraction:', int_1 - int_2) # Int Subtraction: 44
print('Float Subtraction:',  float_2 - float_1) # Float Subtraction: 6.6

# Multiplication

print('Int Multiplication:', int_1 * int_2) # Int Multiplication: 672
print('Float Multiplication:', float_2 * float_1) # Float Multiplication: 64.80000000000001

# Division

print('Division:', int_1 / int_2) # Division: 4.666666666666667
print('Float Division:', float_2 / float_1) # Float Division: 2.222222222222222
```

Quando sommi un float e un intero, il risultato viene convertito in float così:

```py
int_1 = 56
float_1 = 5.4

print(int_1 + float_1) # 61.4
```

- **Operatore modulo (`%`)**: Restituisce il resto della divisione tra due numeri:

```py
int_1 = 56
int_2 = 12

print(int_1 % int_2) # 8
```

- **Divisione intera (`//`)**: Questo operatore divide due numeri e arrotonda per difetto al numero intero più vicino:

```py
int_1 = 56
int_2 = 12

print(int_1 // int_2) # 4
```

- **Operatore di esponenziazione (`**`)**: Serve ad elevare un numero alla potenza di un altro:

```py
int_1 = 4
int_2 = 2

print(int_1 ** int_2) # 16
```

- **Approssimazione in virgola mobile**: Alcune frazioni decimali non possono essere rappresentate esattamente in binario, quindi sono archiviate come approssimazioni finite. Questo può causare piccoli errori di arrotondamento, come il risultato `64.80000000000001` della moltiplicazione mostrata sopra.

```py
print(0.1 + 0.2) # 0.30000000000000004
```

- **Funzione `float()`**: Puoi usare questa funzione per convertire un numero intero o una stringa decimale valida in un float, oppure per creare un valore float speciale che rappresenta l'infinito positivo, che è maggiore di qualsiasi numero intero o float finito:

```py
num = 4

print(float(num)) # 4.0
print(float('7.8')) # 7.8
print(float('inf')) # inf
```

- **Funzione `int()`**: Puoi usare questa funzione per convertire un float in intero.

```py
num = 4.0

print(int(num)) # 4
```

- **Funzione `round()`**: Con un argomento arrotonda un numero all'intero più vicino. Passa un secondo argomento per specificare il numero di cifre decimali:

```py
num_1 = 3.4
num_2 = 7.7

print(round(num_1)) # 3
print(round(num_2)) # 8
print(round(3.14159, 2)) # 3.14
```

- **Funzione `abs()`**: Serve a restituire il valore assoluto di un numero:

```py
num = -13

print(abs(num)) # 13
```

- **Funzione `pow()`**: Eleva un numero alla potenza di un altro. Con argomenti interi, puoi passare un terzo argomento diverso da zero per calcolare il risultato modulo quel valore:

```py
result = pow(2, 3)
print(result)  # 8
print(pow(2, 3, 5)) # 3
```

- **Assegnazione aumentata**: L'assegnazione aumentata applica un'operazione a una variabile e archivia il risultato nella stessa variabile, tutto in un solo passaggio.


```py
print(3 < 4) # True
```

```py
print(3 <= 4) # True
```

## Lavorare con le istruzioni `if`, `elif` e `else`

- **Blocchi di codice e indentazione**: Python usa l'indentazione per raggruppare le istruzioni in un blocco, come il corpo di una funzione o di un condizionale. Le istruzioni nello stesso blocco devono usare lo stesso livello di indentazione. La convenzione è usare quattro spazi per ogni livello.

- **Istruzione `pass`**: `pass` non fa nulla. Usala come segnaposto dove Python richiede un'istruzione, come in un corpo condizionale vuoto:

```py
age = 18
if age >= 18:
    pass
```

- **Istruzioni `if`**: Un'istruzione `if` esegue il suo corpo quando Python considera vera la sua condizione.

```py
age = 18

if age >= 18:
    print('You are an adult') # You are an adult
```

- **Clausola `else`**: Una clausola `else` esegue il suo corpo quando Python considera false tutte le condizioni precedenti nella stessa catena `if...elif...else`.

```py
age = 12

if age >= 18:
    print('You are an adult')
else:
    print('You are not an adult yet') # You are not an adult yet
```

- **Clausola `elif`**: Una clausola `elif` testa un'altra condizione quando Python considera false tutte le condizioni precedenti nella stessa catena. Esegue il suo corpo se Python considera vera la sua condizione.

```py
age = 16

if age >= 18:
    print('You are an adult')
elif age >= 13:
    print('You are a teenager')  # You are a teenager
```

Puoi anche usare istruzioni `if` annidate così:

```py
is_citizen = True
age = 25

if is_citizen:
    if age >= 18:
        print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

## Valori truthy e falsy

- **Veridicità**: In Python, ogni valore ha un valore booleano intrinseco, o un senso integrato di se debba essere trattato come `True` o `False` in un contesto logico. Molti valori sono considerati truthy, cioè valutano a `True` in un contesto logico. Altri sono falsy, cioè valutano a `False`. Ecco alcuni esempi di valori falsy:

```md
False
None
Integer 0
Float 0.0
Empty strings ''
```

Altri valori come numeri diversi da zero e stringhe non vuote sono truthy.

## Lavorare con la funzione `bool()`

- **Funzione `bool()`**: Se vuoi verificare se un valore è truthy o falsy, puoi usare la funzione integrata `bool()`. Converte esplicitamente un valore nel suo equivalente booleano e restituisce `True` per i valori truthy e `False` per i valori falsy. Ecco alcuni esempi:

```py
print(bool(False)) # False
print(bool(0))  # False
print(bool('')) # False

print(bool(True)) # True
print(bool(1)) # True
print(bool('Hello')) # True
```

## Operatori booleani e short-circuiting

- **Operatori booleani**: Sono operatori speciali che ti permettono di combinare più espressioni per creare logiche decisionali più complesse nel tuo codice. In Python ci sono tre operatori booleani: `and`, `or` e `not`.
- **Operatore `and`**: Questo operatore prende due operandi e restituisce il primo se è falsy; altrimenti restituisce il secondo. Entrambi gli operandi devono essere truthy perché l'espressione risulti truthy.

```py
is_citizen = True
age = 25

print(is_citizen and age) # 25
```

Puoi anche usare l’operatore `and` nelle condizioni così:

```py
is_citizen = True
age = 25

if is_citizen and age >= 18:
    print('You are eligible to vote') # You are eligible to vote
else:
    print('You are not eligible to vote')
```

- **Operatore `or`**: Questo operatore restituisce il primo operando se è truthy; altrimenti, restituisce il secondo operando. Un'espressione `or` risulta in un valore truthy se almeno un operando è truthy. Ecco un esempio:

```py
age = 19
is_employed = False

print(age or is_employed) # 19
```

Come per l’operatore `and`, puoi usare l’operatore `or` nelle condizioni così:

```py
age = 19
is_student = True

if age < 18 or is_student:
    print('You are eligible for a student discount') # You are eligible for a student discount
else:
    print('You are not eligible for a student discount')
```

- **Short-circuiting**: Gli operatori `and` e `or` sono chiamati operatori short-circuit. Lo short-circuiting significa che Python controlla i valori da sinistra a destra e si ferma appena determina il risultato finale.
- **Operatore `not`**: Questo operatore prende un solo operando e inverte il suo valore booleano. Converte valori truthy in `False` e valori falsy in `True`. A differenza degli operatori precedenti, `not` restituisce sempre `True` o `False`. Ecco alcuni esempi:

```py
print(not '') # True, because empty string is falsy
print(not 'Hello') # False, because non-empty string is truthy
print(not 0) # True, because 0 is falsy
print(not 1) # False, because 1 is truthy
print(not False) # True, because False is falsy
print(not True) # False, because True is truthy
```

Ecco un esempio dell’operatore `not` in una condizione:

```py
is_admin = False

if not is_admin:
    print('Access denied for non-administrators.') # Access denied for non-administrators.
else:
    print('Welcome, Administrator!')
```

## Operatori di identità

- **Identità e uguaglianza**: Le variabili si riferiscono a oggetti. L'operatore `is` verifica se due operandi si riferiscono allo stesso oggetto, mentre `is not` verifica se si riferiscono a oggetti diversi. Gli operatori `==` e `!=` confrontano invece i valori. Usa gli operatori di uguaglianza quando confronti valori numerici o stringhe.
- **`None` e `NoneType`**: `None` rappresenta l'assenza di un valore. È l'unico valore del tipo di dato `NoneType`.
- **Singleton**: `None`, `True` e `False` sono ciascuno singleton, cioè esiste esattamente un oggetto per ciascuno. Puoi verificarli con gli operatori di identità.
- **Verifica di `None`**: Usa `is None` per verificare un valore mancante e `is not None` per verificare un valore presente. Sia `None` che `False` sono falsy, ma sono oggetti diversi:

```py
response = False

print(response is None) # False
print(response is not None) # True
print(response is True) # False
print(response is False) # True
```

- **Identità e veridicità**: Se `response` può essere `True`, `False` o `None`, `response is None` distingue una risposta mancante da una negativa. Usare `not response` tratterebbe allo stesso modo sia `False` che `None`. Per flag booleani ordinari, usa `if is_ready` o `if not is_ready`. Usa `is True` o `is False` quando devi distinguere specificamente un oggetto booleano da altri valori possibili.

## Precedenza degli operatori booleani

- **Precedenza degli operatori e parentesi tonde**: Quando `and` e `or` appaiono nella stessa espressione, `and` ha una precedenza più alta di `or`. Questo significa che `and` raggruppa prima i suoi operandi, quindi `True or False and False` è raggruppato come `True or (False and False)`:

```py
print(True or False and False) # True
```

L'operando a sinistra di `or` è `True`, quindi lo short-circuiting significa che `False and False` non viene mai valutato e il risultato è `True`.

Puoi usare le parentesi tonde per cambiare il raggruppamento. Qui, `True or False` è raggruppato insieme e valuta a `True`, e poi `True and False` valuta a `False`:

```py
print((True or False) and False) # False
```

## Lavorare con le funzioni

- **Funzioni**: Le funzioni sono pezzi di codice riutilizzabili che vengono eseguiti quando le chiami. Per chiamare una funzione, devi fare riferimento al nome della funzione seguito da un paio di parentesi tonde:

```py
# Defining a function

def get_sum(num_1, num_2):
    return num_1 + num_2

result = get_sum(3, 4) # function call
print(result) # 7
```

- **Parametri e argomenti**: I parametri sono i nomi elencati nella definizione di una funzione, come `num_1` e `num_2` sopra. Gli argomenti sono i valori passati quando chiami la funzione, come `3` e `4`.

Se chiami la funzione senza il numero corretto di argomenti, otterrai un `TypeError`:

```py
def calculate_sum(a, b):
    print(a + b)

calculate_sum()

# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'
```

- **Argomenti posizionali**: Questi argomenti sono associati ai parametri in base alla loro posizione nella chiamata della funzione.

```py
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')

introduce('Alice', 25)
# My name is Alice and I am 25 years old.
```

- **Argomenti con parola chiave**: Questi argomenti usano `name=value` per associare un parametro per nome. Possono apparire in un ordine diverso rispetto ai parametri:

```py
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
```

- **Combinare tipi di argomenti**: Gli argomenti posizionali devono precedere quelli con parola chiave. Ogni parametro può ricevere solo un valore:

```py
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
```

- **Istruzione `return`**: Un'istruzione `return` termina la funzione e rende disponibile il suo valore nel punto in cui la funzione è stata chiamata.

- **`None`**: `None` rappresenta l'assenza di un valore. Se una funzione non restituisce esplicitamente un valore, il valore di ritorno predefinito è `None`:

```py
def greet():
    print('hello')

result = greet() # hello
print(result) # None
```

## Ambito in Python

Python ha regole aggiuntive sull'ambito. Per ora, concentrati sull'ambito locale e globale.

- **Ambito globale**: Una variabile creata all'esterno di una funzione può essere usata sia dentro che fuori dalle funzioni.

```py
tax = 0.70

def get_total(subtotal):
    total = subtotal + (subtotal * tax)
    return total

print(get_total(100))  # 170.0
```

- **Ambito locale**: Una variabile creata all'interno di una funzione può essere usata solo all'interno di quella funzione. Anche i parametri delle funzioni sono variabili locali.

```py
def my_func():
    num = 10
    print(num)
```

- **Passaggio degli argomenti e riassegnazione dei parametri**: Python passa gli argomenti per assegnazione. Un parametro è un nome locale che inizialmente si riferisce all'oggetto fornito; l'oggetto non viene copiato automaticamente. Riassegnare il parametro non riassegna la variabile passata come argomento:

```py
def double_number(number):
    number = number * 2
    print(number) # 20

original = 10
double_number(original)
print(original) # 10
```

## Applicare funzioni e ambito

- **Corpi di funzione vuoti**: Puoi usare `pass` come segnaposto nel corpo di una funzione. Una funzione che contiene solo `pass` restituisce implicitamente `None`:

```py
def placeholder():
    pass

print(placeholder()) # None
```

- **Ombreggiatura del nome**: Quando un parametro o una variabile locale ha lo stesso nome di una variabile globale, la funzione usa il nome locale. Riassegnare quel parametro locale non cambia la variabile globale:

```py
available_eggs = 5

def use_eggs(available_eggs, eggs_to_use):
    available_eggs -= eggs_to_use
    return available_eggs

print(use_eggs(available_eggs, 1)) # 4
print(available_eggs) # 5
```

- **Ritorni anticipati**: Un'istruzione `return` termina immediatamente la funzione e rende disponibile il suo valore nel punto in cui la funzione è stata chiamata. Questo ti permette di uscire prima quando una condizione è soddisfatta:

```py
def use_eggs(available_eggs, eggs_to_use):
    if eggs_to_use > available_eggs:
        return available_eggs
    return available_eggs - eggs_to_use

print(use_eggs(2, 3)) # 2
print(use_eggs(2, 1)) # 1
```

- **Chiamare funzioni da altre funzioni**: Una funzione può chiamare un'altra funzione e usare o restituire il suo risultato:

```py
def use_eggs(available_eggs, eggs_to_use):
    return available_eggs - eggs_to_use

def make_fried_egg(available_eggs):
    return use_eggs(available_eggs, 1)

print(make_fried_egg(3)) # 2
```

- **Assegnare valori restituiti**: Restituire un nuovo valore non aggiorna automaticamente la variabile passata come argomento. Per aggiornarla, assegna il valore restituito di nuovo a quella variabile:

```py
available_eggs = use_eggs(available_eggs, 1)
print(available_eggs) # 4
```

## Tradurre stringhe

- **`str.maketrans()`**: La forma a due stringhe di `str.maketrans()` prende stringhe di lunghezza uguale e mappa ogni carattere della prima stringa al carattere corrispondente nella seconda. La tabella archivia i caratteri come ordinali Unicode, numeri che li identificano univocamente. Il metodo `translate()` applica la tabella a una stringa e restituisce una nuova stringa. I caratteri non inclusi nella tabella rimangono invariati.

```py
trans_table = str.maketrans('abc', '123')
print(trans_table) # {97: 49, 98: 50, 99: 51}

result = 'abcabc!'.translate(trans_table)
print(result)  # 123123!
```

## Validare argomenti interi

- **Booleani e numeri interi**: Python tratta i booleani come un tipo speciale di numero intero, quindi `isinstance(True, int)` e `isinstance(False, int)` restituiscono entrambi `True`. Quando validi un numero intero che non deve essere un booleano, escludi esplicitamente i valori booleani:

```py
print(isinstance(True, int)) # True
print(isinstance(False, int)) # True

value = True
print(isinstance(value, int) and not isinstance(value, bool)) # False

value = 5
print(isinstance(value, int) and not isinstance(value, bool)) # True
```

## Valori predefiniti dei parametri

- **Parametri predefiniti**: Puoi fornire un valore predefinito a un parametro. Se ometti il suo argomento quando chiami la funzione, Python usa quel valore predefinito:

```py
def get_sum(num_1, num_2=2):
    return num_1 + num_2

result = get_sum(3)
print(result) # 5
```
