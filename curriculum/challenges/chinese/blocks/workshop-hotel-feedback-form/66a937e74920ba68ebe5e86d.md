# --description--

`placeholder` 属性会在 `input` 内显示提示文本。一旦用户开始在输入框中输入，提示文本就会消失。

`required` 属性确保用户在提交形式之前填写了 `input`。它是一个布尔属性，意味着不需要赋值。

下面是一个同时使用这两个属性的 `input` 示例：

```html
<input type="email" placeholder="e.g., jane@example.com" required>
```

为你现有的 `input` 元素添加一个值为 `"e.g., John Doe"` 的 `placeholder` 属性。

也在 `input` 元素中添加 `required` 属性。

# --hints--

你不应删除现有的 `input` 元素。

```js
assert.isNotNull(document.querySelector('fieldset input'));
```

你的 `input` 应该有一个 `placeholder` 属性，值为 `"e.g., John Doe"`。

```js
assert.strictEqual(document.querySelector('fieldset input')?.getAttribute('placeholder'), 'e.g., John Doe');
```

你的 `input` 应该具有 `required` 属性。

```js
assert.isNotNull(document.querySelector('fieldset input[required]'));
```
