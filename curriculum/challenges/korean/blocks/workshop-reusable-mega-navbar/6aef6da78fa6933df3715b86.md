# --description--

`Apps` 버튼을 클릭할 때 `isOpen` 상태를 업데이트하는 것이 마지막 작업입니다.

React에서는 이벤트에 반응할 때 요소의 이벤트 속성에 함수를 전달합니다. 이 속성들은 카멜 케이스로 작성되므로 클릭은 `onClick`으로 처리합니다:

```jsx
<button onClick={() => setCount(count + 1)}>Add one</button>
```

`onClick`이 함수를 받는다는 점을 주목하세요. React는 버튼이 클릭될 때마다 그 함수를 호출합니다. 새 값으로 설정자 함수를 호출하면 상태가 업데이트되고 React는 그 새 값으로 컴포넌트를 다시 렌더링합니다.

불리언 상태를 `true`와 `false` 사이에서 전환하려면 논리 NOT(`!`) 연산자를 사용해 현재 값의 반대를 설정자 함수에 전달할 수 있습니다.

`button` 요소에 `onClick` 속성을 추가하세요. `isOpen`의 반대 값을 `setIsOpen`에 호출하는 화살표 함수를 할당하세요.

`Apps` 버튼을 클릭해 `sub-menu`를 열고 닫으세요.

이렇게 하면 `Navbar` 컴포넌트가 완성됩니다!

# --hints--

`Apps` 버튼을 클릭하면 `aria-expanded` 속성이 `"true"`로 설정되고 `sub-menu`에 `sub-menu--open` 클래스가 추가되어야 합니다.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
try {
  assert.equal(button.getAttribute("aria-expanded"), "true");
  assert.isTrue(subMenu.classList.contains("sub-menu--open"));
} finally {
  button.click();
  await new Promise(resolve => setTimeout(resolve, 0));
}
```

`Apps` 버튼을 두 번째로 클릭하면 `aria-expanded` 속성이 다시 `"false"`로 설정되고 `sub-menu`에서 `sub-menu--open` 클래스가 제거되어야 합니다.

```js
const button = document.querySelector("button");
const subMenu = document.querySelector(".sub-menu");

button.click();
await new Promise(resolve => setTimeout(resolve, 0));
button.click();
await new Promise(resolve => setTimeout(resolve, 0));
assert.equal(button?.getAttribute("aria-expanded"), "false");
assert.isFalse(subMenu?.classList.contains("sub-menu--open"));
```
