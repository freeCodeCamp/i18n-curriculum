# --description--

このラボでは、キューのクラスを作成します。キューはFIFO（先入れ先出し）原則に従います：要素はキューの後ろに追加され、前から取り出されます。

**目的：** 以下のユーザーストーリーを満たし、すべてのテストに合格してラボを完了してください。

**ユーザーストーリー：**

1. `Queue` という名前のクラスを定義してください。`Queue` の新しいインスタンスは空で始まる必要があります。

1. `Queue` クラスは次のメソッドを持つ必要があります：

   - `enqueue`: 要素を受け取り、キューの後ろに追加します。
   - `dequeue`: キューの前から要素を取り除き、それを返します。キューが空の場合は `None` を返す必要があります。
   - `front`: キューの前の要素を取り除かずに返します。キューが空の場合は `None` を返す必要があります。
   - `size`: キュー内の要素数を返します。
   - `is_empty`: キューに要素がなければ `True` を、そうでなければ `False` を返します。

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
