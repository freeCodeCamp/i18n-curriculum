# --description--

在处理读取数据之前，你需要先移除误差代码。

正如你在之前的课程中学到的，`filter()` 函数只保留可迭代对象中函数返回真值的项。你可以不用用 `def` 定义该函数，而是直接将一个 lambda 函数传递给 `filter()`：

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

创建一个名为 `valid_readings` 的变量。将调用 `filter()` 并传入一个 lambda 函数和 `readings` 的结果赋值给它。这个 lambda 函数应接受一个名为 `reading` 的参数，并检查 `reading` 是否不等于 `-999`。

然后，打印 `valid_readings`，而不是 `readings`。
