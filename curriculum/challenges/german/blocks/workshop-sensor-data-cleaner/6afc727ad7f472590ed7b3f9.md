# --description--

Bevor Sie mit den Messwerten arbeiten, müssen Sie die Fehlercodes entfernen.

Wie Sie in den vorherigen Lektionen gelernt haben, behält die `filter()`-Funktion nur die Elemente eines iterierbaren Objekts, für die eine Funktion einen truthy-Wert zurückgibt. Anstatt diese Funktion mit `def` zu definieren, können Sie eine Lambda-Funktion direkt an `filter()` übergeben:

```py
numbers = [1, 2, 3, 4]
even_numbers = filter(
    lambda num: num % 2 == 0,
    numbers
)
```

Erstellen Sie eine Variable namens `valid_readings`. Weisen Sie ihr das Ergebnis zu, das entsteht, wenn Sie `filter()` eine Lambda-Funktion und `readings` übergeben. Die Lambda-Funktion soll einen Parameter namens `reading` haben und prüfen, ob `reading` nicht gleich `-999` ist.

Geben Sie dann `valid_readings` anstelle von `readings` aus.
