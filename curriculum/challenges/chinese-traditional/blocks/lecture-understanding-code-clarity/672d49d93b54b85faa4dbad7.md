# --description--

就像句號（`.`）可以標示英文句子的結尾，分號（`;`）也可以用來標示 JavaScript 中述語的結尾。然而，述語不一定等同於原始碼的行數。述語可以跨越多行，而一行中也可以包含多個述語。

例如：

```js
let variableOne = 5;
let variableTwo = 10;
```

在這段程式碼中，分號明確指出每個述語的結尾。JavaScript 也有自動分號插入（ASI），允許這些宣告在沒有明確分號的情況下仍然有效：

```js
let variableOne = 5
let variableTwo = 10
```

在這個範例中，ASI 讓 JavaScript 將每個宣告視為獨立的述語，即使沒有分號。然而，ASI 並不是在每個換行處都插入分號。

例如，`return` 述語後的換行可能會導致意外行為：

```js
function getValue() {
  return
  {
    value: 42
  };
}
```

這裡，ASI 在 `return` 後插入了分號，因此函式傳回 `undefined` 而不是物件。將物件寫在同一行可以避免這種行為：

```js
function getValue() {
  return {
    value: 42
  };
}
```

這說明了為什麼換行和述語邊界不一定相同。

當換行可能讓兩段程式碼被解讀為一個運算式時，分號也很有用。立即呼叫函式運算式（IIFE）是一種函式，定義後立即執行。創建 IIFE 的一種方法是將匿名函式（沒有名稱的函式）包在小括號中，並在結尾加上 `()` 來呼叫它。當前述述語沒有以分號結尾時，IIFE 可能會造成問題：

```js
const message = "Hello"

(function () {
  console.log(message);
})()
```

這裡，JavaScript 沒有在字串宣告後插入分號，因為後面的 `(` 可以繼續初始化運算式。JavaScript 將初始化運算式解析為對字串 `"Hello"` 的呼叫，並將函式運算式當作引數。這在 IIFE 執行前就丟出 `TypeError`。加上分號則在 IIFE 前結束宣告：

```js
const message = "Hello";

(function () {
  console.log(message);
})()
```

明確的分號讓變數宣告和 IIFE 成為獨立的述語。

分號在許多程式語言中都有使用，包括 C、C++ 和 Java。它們的具體規則因語言而異，但通常用來指出述語的結尾。

編譯器會將原始碼轉換成另一種形式，例如機器碼、位元組碼或中介表示法，這取決於語言和編譯器。編譯不一定會產生獨立的可執行檔。

一致使用分號可以讓述語邊界更清楚，並使程式碼更容易閱讀和維護。
