# --description--

In diesem Workshop arbeiten Sie mit einem intelligenten Campus-Verzeichnis und erstellen Nachschlagetabellen aus verschachtelten Daten.
Sie verwenden diese Nachschlagetabellen, um schnelle und effiziente Suchvorgänge durchzuführen. Die `rawData` wurde Ihnen bereitgestellt.

Schauen Sie sich kurz die Struktur an: Jeder Schlüssel ist ein Fachbereichsname, und sein Wert enthält einen `Dept_code` sowie
ein `programs`-Array. Jedes Programm enthält dann wiederum ein eigenes Array von `instructors`.

Beginnen Sie damit, `rawData` in der Konsole auszugeben, damit Sie diese verschachtelte Struktur vor der Arbeit damit inspizieren können.

# --before-each--

```js
globalThis.spy = __helpers.spyOn(console, "log");

```

# --after-each--

```js
globalThis.spy.restore();
delete globalThis.spy;
```
