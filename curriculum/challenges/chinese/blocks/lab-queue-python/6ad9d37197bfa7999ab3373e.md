# --description--

在本实验中，你将构建一个队列类。队列遵循 FIFO（先进先出）原则：元素被添加到队列的末尾，并从队列的前端移除。

**目标：**实现以下用户需求并通过所有测试以完成实验。

**用户故事：**

1. 你应该定义一个名为 `Queue` 的类。`Queue` 的新实例应从空开始。

1. `Queue` 类应具有以下方法：

   - `enqueue`：接收一个元素并将其添加到队列的末尾。
   - `dequeue`：移除并返回队列前端的元素。如果队列为空，应返回 `None`。
   - `front`：返回队列前端的元素但不移除它。如果队列为空，应返回 `None`。
   - `size`：返回队列中元素的数量。
   - `is_empty`：如果队列没有元素，返回 `True`，否则返回 `False`。

```py
class Queue:
    def __init__(self):
        self.collection = []

    def enqueue(self, item):
        self.collection.append(item)

    def dequeue(self):
        if self.is_empty():
            return None
        return self.collection.pop(0)

    def front(self):
        if self.is_empty():
            return None
        return self.collection[0]

    def size(self):
        return len(self.collection)

    def is_empty(self):
        return len(self.collection) == 0
```
