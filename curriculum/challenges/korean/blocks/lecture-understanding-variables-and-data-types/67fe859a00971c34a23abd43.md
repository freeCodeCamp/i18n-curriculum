# --description--

Python 변수로 작업하기 전에 데이터 타입을 이해하는 것이 중요합니다. 데이터 타입은 변수에 저장된 값의 종류를 설명하며, 예를 들어 숫자나 텍스트 조각이 될 수 있습니다. 프로그래밍 언어는 다양한 종류의 정보를 어떻게 저장하고 다룰지 알기 위해 데이터 타입을 사용합니다.

Python은 동적 타입 언어입니다. 이는 변수를 만들 때 데이터 타입을 지정하지 않는다는 뜻입니다. Python은 변수에 할당된 값으로부터 타입을 결정합니다.

다음은 몇 가지 예시입니다:

```python
name = 'John Doe' # Python knows this is a string
age = 25 # Python knows this is an integer
```

변수에 나중에 다른 타입의 값을 할당할 수 있습니다:

```python
age = 25
age = 'Twenty-five'
```

두 번째 할당 후에는 `age`가 정수가 아닌 문자열을 포함합니다.

지금은 이 모듈 전체에서 사용할 네 가지 데이터 타입에 집중하세요:

- 정수: 소수점 없는 전체 숫자, 예를 들어 `10` 또는 `-5`.

```python
my_integer_var = 10
print('Integer:', my_integer_var) # Integer: 10
```

- 부동소수점: 소수점이 있는 숫자, 예를 들어 `4.41` 또는 `-0.4`.

```python
my_float_var = 4.50
print('Float:', my_float_var) # Float: 4.5
```

- 문자열: 작은따옴표나 큰따옴표로 감싼 문자 수열, 예를 들어 `'Hello world!'`.

```python
my_string_var = 'hello'
print('String:', my_string_var) # String: hello
```

- 불리언: 참 또는 거짓 타입, `True` 또는 `False`로 표현.

```python
my_boolean_var = True
print('Boolean:', my_boolean_var) # Boolean: True
```

Python에는 다른 데이터 타입도 있습니다. 필요할 때마다 하나씩 배우게 됩니다.
