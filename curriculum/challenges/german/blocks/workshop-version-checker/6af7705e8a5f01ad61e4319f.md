# --description--

In diesem Workshop üben Sie den Umgang mit Tuples, indem Sie ein Programm erstellen, das überprüft, ob eine App ein Update benötigt.

Jede Veröffentlichung einer Software erhält eine Versionsnummer, damit man die Versionen unterscheiden und erkennen kann, welche neuer ist. Eine gängige Konvention ist die Verwendung von drei durch Punkte getrennten Zahlen im Format `MAJOR.MINOR.PATCH`:

- Die `MAJOR`-Nummer steigt bei großen Änderungen, die dazu führen können, dass älterer Code oder Dateien mit der neuen Version nicht mehr funktionieren.
- Die `MINOR`-Nummer steigt, wenn neue Funktionen hinzugefügt werden, die weiterhin mit dem Vorherigen kompatibel sind.
- Die `PATCH`-Nummer steigt bei kleinen Korrekturen, wie Bugfixes, die keine neuen Funktionen hinzufügen.

Eine Version wie `2.1.0` kann als Tuple aus drei ganzen Zahlen gespeichert werden: die Major-, Minor- und Patch-Nummern.

Erstellen Sie eine Variable namens `releases` und weisen Sie ihr ein Tuple zu, das die folgenden Version-Tuples in dieser Reihenfolge enthält:

```py
(1, 9, 0), (2, 0, 0), (1, 9, 1), (2, 1, 0),
(2, 1, 1), (2, 2, 0), (1, 9, 2), (2, 2, 1)
```

Die Versionen sind in der Reihenfolge aufgelistet, in der sie veröffentlicht wurden, nicht von der niedrigsten bis zur höchsten Version. Die alte `1.9`-Linie wurde weiterhin mit Korrekturen versorgt, auch nachdem die Version `2.0.0` erschienen war.
