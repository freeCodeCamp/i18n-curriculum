# --description--

当节点有两个子节点时，你需要用另一个值替换它的值，同时保持树的有序。正确的选择是它的中序后继：在中序遍历中紧跟它之后的值。

中序后继是该节点右子树中最小的值，你可以通过从右子节点开始尽可能向左移动来找到它。

在 `BinarySearchTree` 类中，创建一个名为 `_min_value` 的方法，带有两个参数 `self` 和 `node`。在方法内部，使用 `while` 循环，只要 `node.left` 不是 `None`，就将 `node.left` 赋值给 `node`。循环结束后，返回 `node.key`。
