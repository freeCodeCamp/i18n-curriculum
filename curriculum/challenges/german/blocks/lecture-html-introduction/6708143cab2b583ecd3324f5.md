# --interactive--

## Was ist ein Attribut?

Ein Attribut ist ein Wert, der im öffnenden Tag eines HTML-Elements platziert wird. Attribute liefern zusätzliche Informationen über das Element oder geben an, wie sich das Element verhalten soll. Hier ist die grundlegende Syntax für ein Attribut:

```html
<element attribute="value"></element>
```

Dem Attributnamen folgt ein Gleichheitszeichen (`=`) und ein Wert in Anführungszeichen. Der Wert kann ein String oder eine Zahl sein, je nach Attribut.

## Die `href`- und `target`-Attribute

Dieses erste Beispiel verwendet die `href`- und `target`-Attribute. Das `href`-Attribut gibt die URL eines Links an und das `target`-Attribut bestimmt, wo der Link geöffnet wird.

**Hinweis:** Das `a`-Element, auch als Ankerelement bekannt, wird verwendet, um Hyperlinks zu erstellen. Der Text zwischen dem öffnenden und schließenden `a`-Tag ist der anklickbare Teil, den Benutzer auswählen, um zu navigieren.

Aktivieren Sie den interaktiven Editor und ändern Sie das `href="https://www.freecodecamp.org/news/"` in `href="https://www.freecodecamp.org"`. Wenn Sie jetzt auf den Link im interaktiven Editor klicken, sehen Sie die freeCodeCamp-Startseite in einem neuen Browser-Tab.

:::interactive_editor

```html
<a href="https://www.freecodecamp.org/news/" target="_blank">Visit freeCodeCamp</a>
```

:::

Ohne das `href`-Attribut würde der Link nicht funktionieren, da keine Ziel-URL vorhanden wäre. Daher müssen Sie dieses `href`-Attribut einschließen, damit der Link funktioniert. Das `target="_blank"`-Attribut ermöglicht es, den Link in einem neuen Browser-Tab zu öffnen. Mehr über das `target`-Attribut lernen Sie in zukünftigen Lektionen.

## Die `src`- und `alt`-Attribute

Weitere gebräuchliche Attribute sind die `src`- und `alt`-Attribute, die verwendet werden, um die Quelle eines Bildes anzugeben bzw. alternativen beschreibenden Text für das Bild bereitzustellen.

Aktivieren Sie den interaktiven Editor und ändern Sie das `src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/cats.jpg"` in `src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/running-cats.jpg"`. Ändern Sie dann das `alt="Two tabby kittens sleeping together on a couch."` in `alt="Two cats running in the dirt."`.

:::interactive_editor

```html
<img src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/cats.jpg" alt="Two tabby kittens sleeping together on a couch." />
```

:::

Ähnlich wie beim `href`-Attribut ist das `src`-Attribut erforderlich, da es die anzuzeigende Bilddatei angibt. Das `alt`-Attribut ist nicht erforderlich, wird aber aus Gründen der Barrierefreiheit empfohlen. Barrierefreiheit bedeutet, sicherzustellen, dass alle Menschen, einschließlich Menschen mit Behinderungen, Dinge wie Websites, Apps und physische Räume nutzen und verstehen können. Mehr über Barrierefreiheit lernen Sie in den kommenden Lektionen.

## Das `checked`-Attribut

Einige Attribute sind mit ihrer Syntax etwas einzigartig, wie das `checked`-Attribut.

Aktivieren Sie den interaktiven Editor und versuchen Sie, im Vorschaufenster auf das Kontrollkästchen zu klicken, um zu sehen, wie es zwischen einem aktivierten und deaktivierten Zustand wechselt.

:::interactive_editor

```html
<input type="checkbox" checked />
```

:::

Im folgenden Beispiel haben wir ein `input`-Element mit dem `type`-Attribut, das auf `checkbox` gesetzt ist. Eingaben werden verwendet, um Daten von Benutzern zu sammeln, und das `type`-Attribut gibt den Typ der Eingabe an. In diesem Fall ist diese Eingabe ein Kontrollkästchen. Mehr darüber, wie Eingaben funktionieren, lernen Sie in den kommenden Lektionen.

Das `checked`-Attribut wird verwendet, um anzugeben, dass das Kontrollkästchen standardmäßig aktiviert sein soll. Das `checked`-Attribut benötigt keinen Wert. Wenn es vorhanden ist, ist das Kontrollkästchen standardmäßig aktiviert. Wenn das Attribut nicht vorhanden ist, ist das Kontrollkästchen deaktiviert. Dies ist als Boolean-Attribut bekannt. Mehr über Booleans im Allgemeinen lernen Sie im JavaScript-Abschnitt.

Aktivieren Sie den interaktiven Editor und versuchen Sie, das `checked`-Attribut vom `input` zu entfernen. Sie werden sehen, dass das Kontrollkästchen nicht mehr standardmäßig aktiviert ist.

:::interactive_editor

```html
<input type="checkbox" checked />
```

:::

## Weitere Boolean-Attribute

Es gibt mehrere häufige Boolean-Attribute, denen Sie in HTML begegnen werden, wie `disabled`, `readonly` und `required`. Diese Attribute werden verwendet, um den Zustand eines Elements anzugeben, beispielsweise ob es deaktiviert, schreibgeschützt oder erforderlich ist.

Hier ist ein Beispiel für ein Text-`input`-Element, das standardmäßig deaktiviert ist. Aktivieren Sie den interaktiven Editor und versuchen Sie, im Vorschaufenster auf das `input`-Element zu klicken. Entfernen Sie nun das `disabled`-Attribut vom `input`-Element, und Sie werden sehen, dass das `input` nicht mehr standardmäßig deaktiviert ist. Sie sollten jetzt darauf klicken und im Feld tippen können.

:::interactive_editor

```html
<input type="text" disabled>
```

:::

HTML hat viele Attribute, die verwendet werden können, um das Verhalten und Aussehen von Elementen auf einer Webseite anzupassen. Zu verstehen, wie man Attribute verwendet, ist entscheidend, um interaktive und barrierefreie Webinhalte zu erstellen. In den nächsten Lektionen lernen Sie weitere HTML-Attribute kennen und wie Sie diese effektiv in Ihren Webentwicklungsprojekten einsetzen.
