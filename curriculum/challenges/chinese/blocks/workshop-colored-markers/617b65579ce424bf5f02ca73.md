# --description--

<dfn>颜色模型</dfn>是表现颜色的系统。主要有两种颜色模型：用于电子设备的<dfn>加色</dfn>RGB模型，以及用于印刷的<dfn>减色</dfn>CMYK（青色、品红、黄色、黑色）模型。

在这个项目中，你将使用 RGB 模型。RGB 代表红色、绿色和蓝色，是光的三原色。这三种颜色以不同的色调组合，创造出广泛的颜色范围。使用 RGB 时，颜色从黑色开始，随着不同程度的红、绿、蓝被添加而变化。

你可以通过 CSS 的 `rgb` 函数看到这一点，它允许你使用 RGB 颜色模型定义颜色。

创建一个定位 `container` 类的新 CSS 规则，并使用 `rgb(0, 0, 0)` 将其 `background-color` 设置为黑色。
