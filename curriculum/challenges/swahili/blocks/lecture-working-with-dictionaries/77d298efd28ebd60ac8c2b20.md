# --description--

Umejifunza jinsi ya kuunda jedwali na kupata na kusahihisha thamani zake. Sasa utatumia njia za jedwali, kunakili jedwali, na kuchunguza jinsi vitendakazi vinaweza kubadilisha.

Kila mfano wa njia ya jedwali hapa chini huanza na jedwali hili:

```python
pizza = {
    'name': 'Margherita',
    'price': 8.9,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil']
}
```

## Njia za Kamusi

Kamusi pia zina njia za msaada kufanya shughuli za kawaida.

Njia ya `.get()` hupata thamani inayohusiana na ufunguo. Ni sawa na uandishi wa mabano uliojifunza katika funzo lililopita, lakini faida yake ni kwamba unaweza kuweka thamani ya msingi, hivyo hutapokea kosa ikiwa ufunguo haupo:

```python
dictionary.get(key, default)
```

Katika mfano huu, ikiwa ufunguo `toppings` haupo, itarudisha orodha tupu, ambayo ni thamani ya msingi tunayopitisha hapa kama hoja ya pili. Lakini ikiwa `toppings` ipo, itarudisha thamani hiyo:

```python
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

Njia za `.keys()` na `.values()` hurudisha kitu cha mtazamo chenye funguo zote na thamani zote katika kamusi, mtawalia:

```python
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice', 'toppings'])

pizza.values()
# dict_values(['Margherita', 8.9, 250, ['mozzarella', 'basil']])
```

Kitu cha mtazamo ni njia tu ya kuona yaliyomo katika kamusi bila kuunda nakala tofauti ya data.

Njia ya `.items()` hurudisha kitu cha mtazamo chenye jozi zote za ufunguo-thamani katika kamusi, ikiwa ni pamoja na funguo na thamani:

```python
pizza.items()
# dict_items([('name', 'Margherita'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

Njia ya `.clear()` huondoa jozi zote za ufunguo-thamani kutoka kamusi:

```python
pizza.clear()
```

Njia ya `.pop()` huondoa jozi ya ufunguo-thamani yenye ufunguo unaobainishwa kama hoja ya kwanza na hurudisha thamani yake. Ikiwa ufunguo haupo, hurudisha thamani ya msingi unayoainisha kama hoja ya pili. Ikiwa ufunguo haupo na haupitishi thamani ya msingi, `KeyError` hutupwa:

```python
pizza.pop('price', 10)
pizza.pop('total_price') # KeyError
```

Katika Python 3.7 na matoleo ya hivi karibuni, njia ya `.popitem()` huondoa kipengele cha mwisho kilichowekwa:

```python
pizza.popitem()
```

Njia ya `.update()` husahihisha jozi za ufunguo-thamani kwa jozi za ufunguo-thamani za jedwali jingine. Ikiwa zinafunguo sawa, thamani zao hubadilishwa.

Katika mfano huu, tunasasisha kamusi ya `pizza`. Ufunguo `price` upo katika zote mbili, hivyo thamani yake itabadilishwa kuwa `15`.

Lakini `total_time` ni mpya, hivyo itaongezwa kwenye kamusi ya `pizza` kama jozi mpya ya ufunguo-thamani:

```python
pizza.update({ 'price': 15, 'total_time': 25 })
```

Hii ni kamusi mpya yenye `price` iliyosasishwa na `total_time` mpya. Angalia jinsi bei sasa ni `15` na `total_time` ni jozi mpya ya ufunguo-thamani:

```python
{
    'name': 'Margherita',
    'price': 15,
    'calories_per_slice': 250,
    'toppings': ['mozzarella', 'basil'],
    'total_time': 25
}
```

### Mgawo wa thamani na nakala zisizo za kina

Kama ulivyojifunza kwa orodha, kuweka jedwali kwenye kigezo kingine huunda jina lingine. Majina yote mawili yanarejea kitu kimoja:

```python
settings = {'theme': 'light', 'languages': ['English']}
alias = settings
alias['theme'] = 'dark'

print(settings['theme']) # dark
print(alias is settings) # True
```

Ili kuunda jedwali la nje tofauti, tumia njia ya `.copy()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()
copied_settings['theme'] = 'dark'

print(settings['theme']) # light
print(copied_settings['theme']) # dark
print(copied_settings is settings) # False
```

Kubadilisha maingizo katika `copied_settings` hakubadilishi maingizo yanayolingana katika `settings`. Hata hivyo, `.copy()` hufanya **nakala isiyo ya kina**: huunda jedwali jipya la nje ambalo funguo na thamani zake zinarejea vitu vile vile kama katika jedwali la awali. Vitu vilivyopangwa ndani vinashirikiwa bado:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = settings.copy()

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True

copied_settings['languages'].append('Spanish')
print(settings['languages']) # ['English', 'Spanish']
print(copied_settings['languages']) # ['English', 'Spanish']
```

Jedwali mbili ni vitu tofauti, lakini maingizo yao ya `languages` yanarejea orodha ile ile. Kuongeza kwenye orodha hiyo kunaonekana kupitia jedwali zote mbili. Kubadilisha `copied_settings['languages']` kwa orodha mpya kutabadilisha maingizo hayo tu katika nakala.

Unaweza pia kuunda nakala isiyo ya kina kwa kupitisha jedwali kwa `dict()`:

```python
settings = {'theme': 'light', 'languages': ['English']}
copied_settings = dict(settings)

print(copied_settings is settings) # False
print(copied_settings['languages'] is settings['languages']) # True
```

Kama `.copy()`, `dict(settings)` huunda jedwali jipya la nje, lakini orodha iliyopangwa ndani bado inashirikiwa. Kubadilisha maingizo katika jedwali lolote huathiri jedwali hilo tu, wakati kubadilisha orodha iliyoshirikiwa kunaonekana kupitia zote mbili.

## Kubadilisha jedwali kupitia kigezo cha kitendakazi

Sheria zile zile za kupitisha hoja ulizojifunza kwa orodha zinatumika kwa jedwali. Kigezo awali kinarejea kitu kilichopitishwa kama hoja. Kusahihisha maingizo kupitia kigezo hicho hubadilisha jedwali lililoshirikiwa:

```python
def set_theme(settings, theme):
    settings['theme'] = theme
    return 'Theme updated'

preferences = {'theme': 'light'}
status = set_theme(preferences, 'dark')

print(status) # Theme updated
print(preferences) # {'theme': 'dark'}
```

Kitendakazi hurudisha mfuatano wa hali, wakati `preferences` hubadilika kupitia rejea lililoshirikiwa. Kurudisha thamani na kubadilisha kitu ni matokeo tofauti. Kitendakazi hakihitaji kurudisha jedwali ili mabadiliko yaonekane nje ya kitendakazi. Kuweka upya kigezo cha ndani kwa jedwali tofauti hakutabadilisha jedwali linalorejea `preferences`.

## Kutumia jedwali kama hoja ya msingi

Kumbuka kwamba orodha ya msingi huundwa wakati kitendakazi kinapozinduliwa na hutumika tena kwa wito zinazokosa hoja. Jedwali la msingi hufanya vivyo hivyo:

```python
def add_setting(key, value, settings={}):
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'theme': 'dark', 'language': 'English'}
```

Wito wa pili hutumia tena jedwali lililobadilishwa na wito la kwanza. Hii ina maana mipangilio hukusanyika kwa wito huru, ingawa kila wito lina jina la kigezo la ndani.

Wakati kila wito unapaswa kuanza na jedwali safi, tumia mfano wa msingi wa `None`:

```python
def add_setting(key, value, settings=None):
    if settings is None:
        settings = {}
    settings[key] = value
    return settings

print(add_setting('theme', 'dark')) # {'theme': 'dark'}
print(add_setting('language', 'English')) # {'language': 'English'}

preferences = {}
add_setting('theme', 'dark', preferences)
print(preferences) # {'theme': 'dark'}
```

Kila wito linalokosa `settings`, au linalopitisha `None`, huunda jedwali safi. Kupitisha jedwali lililopo bado huruhusu kitendakazi kubadilisha kitu hicho. Tumia `settings is None` hapa: `if not settings` pia italingana na jedwali tupu lililopitishwa kama hoja na kulibadilisha na jedwali jipya la ndani.
