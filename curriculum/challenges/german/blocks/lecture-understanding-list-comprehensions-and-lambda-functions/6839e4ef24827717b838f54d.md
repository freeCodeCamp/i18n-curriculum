# --description--

In den vorherigen Lektionen haben Sie Funktionen mit dem Schlüsselwort `def` wie folgt definiert:

```py
def square(num):
    return num ** 2

print(square(4)) # 16
```

In der vorherigen Lektion haben Sie Funktionen wie `is_long_word` und `to_fahrenheit` an `map()` und `filter()` übergeben. Eine Funktion, die eine andere Funktion als Argument akzeptiert, nennt man eine Funktion höherer Ordnung. Jedes Mal eine separate Funktion mit `def` zu definieren, wenn Sie eine kurze Funktion an eine Funktion höherer Ordnung übergeben müssen, kann etwas umständlich sein. Stattdessen können Sie eine Lambda-Funktion schreiben, also eine Funktion ohne Namen, direkt dort, wo Sie sie brauchen.

Die Syntax einer Lambda-Funktion sieht so aus:

```py
lambda parameters: expression
```

Nach dem Schlüsselwort `lambda` listen Sie die Parameter der Funktion auf. Der Doppelpunkt trennt die Parameter von einem einzelnen Ausdruck, und das Ergebnis dieses Ausdrucks wird automatisch zurückgegeben, ohne dass eine `return`-Anweisung nötig ist.

So sieht die `square()`-Funktion aus, wenn sie in eine Lambda-Funktion umgeschrieben wird:

```py
lambda num: num ** 2
```

Hier ist `num` der Parameter, und `num ** 2` ist der Ausdruck, dessen Ergebnis zurückgegeben wird. Wie bereits erwähnt, sind Lambda-Funktionen anonym, daher ist dieser Funktion der Name `square` nicht mehr zugeordnet.

Eine Lambda-Funktion kann auch mehr als einen Parameter haben. Genau wie bei mit `def` definierten Funktionen trennen Sie die Parameter mit Kommas:

```py
lambda a, b: a + b
```

Diese Lambda-Funktion nimmt zwei Parameter, `a` und `b`, und gibt deren Summe zurück.

Lambda-Funktionen sind ideal, wenn Sie sie an Funktionen höherer Ordnung wie diese übergeben müssen:

```py
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4]
```

In diesem Beispiel haben wir eine Liste von Zahlen und wollen eine neue Liste mit geraden Zahlen erstellen. Also übergeben wir eine Lambda-Funktion als eines der Argumente an die `filter()`-Funktion. Die `filter()`-Funktion ruft die Lambda-Funktion für jede Zahl auf und behält nur die Zahlen, für die `x % 2 == 0` `True` ist. Dann sammelt `list()` sie in einer neuen Liste, die die Zahlen `2` und `4` enthält.

Beim Arbeiten mit Lambda-Funktionen ist es wichtig, bewährte Vorgehensweisen zu beachten. Zum Beispiel ist es keine gute Praxis, eine Lambda-Funktion einer Variablen wie folgt zuzuweisen:

```py
numbers = [1, 2, 3, 4, 5]

square = lambda x: x ** 2
squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Das widerspricht dem Zweck, anonyme Funktionen zu verwenden. In diesem Fall sollten Sie eine reguläre Funktion verwenden, so wie hier:

```py
numbers = [1, 2, 3, 4, 5]

def square(num):
    return num ** 2

squared_numbers = list(map(square, numbers))
print(squared_numbers) # [1, 4, 9, 16, 25]
```

Außerdem sollten Sie vermeiden, Lambda-Funktionen zu erstellen, die schwer zu lesen oder unnötig kompliziert sind, wie diese:

```py
result = (lambda x: (x**2 + 2*x - 1) if x > 0 else (x**3 - x + 4))(3)
print(result)  # 14
```

Obwohl diese Funktion einwandfrei läuft und das korrekte Ergebnis `14` liefert, ist sie nicht leicht zu lesen oder anzuschauen. In diesem Fall wäre es besser, eine separate Funktion mit einer `if/else`-Anweisung zu erstellen und dann diese Funktion aufzurufen:

```py
def calculate_expression(x):
    if x > 0:
        return x**2 + 2*x - 1
    else:
        return x**3 - x + 4

print(calculate_expression(3))  # 14
```

Sowohl reguläre Funktionen als auch Lambda-Funktionen haben ihre Anwendungsfälle in Python-Programmen. Wenn Sie mit einem einzelnen inline-Ausdruck arbeiten, sollten Sie eine Lambda-Funktion in Betracht ziehen. Andernfalls ist die Verwendung einer regulären Funktion der richtige Weg.
