# --description--

Le espressioni regolari possono contenere sequenze speciali composte da una barra rovesciata (`\`) seguita da un carattere. Queste sequenze hanno un significato speciale. Ecco alcune delle più comuni:

- `\d` corrisponde a qualsiasi cifra decimale, inclusi i numeri da `0` a `9`.

- `\w` corrisponde a qualsiasi carattere di parola: lettere, cifre e il carattere di underscore (`_`).

- `\s` corrisponde a qualsiasi carattere di spazio bianco, come uno spazio, una tabulazione o una nuova riga.

- `\D`, `\W` e `\S` corrispondono all'opposto delle loro versioni minuscole. Per esempio, `\D` corrisponde a qualsiasi carattere che non sia una cifra.

C'è però un problema. Le stringhe in Python usano anch'esse le barre rovesciate per scrivere sequenze di escape come `\n` (una nuova riga) o `\t` (una tabulazione):

```python
print('Tab:\tdone') # Tab:    done
```

Questo significa che una barra rovesciata in una stringa Python normale potrebbe essere interpretata da Python prima che il modulo `re` la veda. A seconda del carattere che segue, questo può modificare il tuo pattern o far comparire un avviso da parte di Python.

Per evitare questo, puoi usare una stringa raw. Crei una stringa raw aggiungendo la lettera `r` (o `R`) prima della virgoletta di apertura. Le stringhe raw trattano le barre rovesciate come caratteri letterali anziché come sequenze di escape:

```python
print(r'Tab:\tdone') # Tab:\tdone
```

Per questo motivo, è buona pratica scrivere sempre i pattern delle espressioni regolari come stringhe raw:

```python
import re

room = 'Room 42B'
print(re.search(r'\d', room))
# <re.Match object; span=(5, 6), match='4'>
```

Nota che `re.search` restituisce la prima corrispondenza che trova. Qui, `\d` corrisponde a una singola cifra, quindi la corrispondenza è solo `4`. Per corrispondere a più di una cifra, potresti voler usare un quantificatore.

I quantificatori specificano quante volte il carattere o la sequenza precedente può essere ripetuta. Il quantificatore `+` corrisponde al carattere precedente una o più volte.

Quindi, mentre `\d` corrisponde a una singola cifra, `\d+` corrisponde a una o più cifre consecutive:

```python
import re

room = 'Room 42B'
print(re.search(r'\d+', room))
# <re.Match object; span=(5, 7), match='42'>
```

Ecco altri quantificatori comuni:

- `*` corrisponde al carattere precedente zero o più volte.

- `?` corrisponde al carattere precedente zero o una volta, rendendolo opzionale.

- `{n}` corrisponde al carattere precedente esattamente `n` volte.

- `{n,m}` corrisponde al carattere precedente da `n` a `m` volte.

```python
import re

print(re.search(r'go*al', 'What a goooal!'))
# <re.Match object; span=(7, 13), match='goooal'>

print(re.search(r'colou?r', 'My favorite color is blue'))
# <re.Match object; span=(12, 17), match='color'>

print(re.search(r'\d{4}', 'Room 42, built in 1987'))
# <re.Match object; span=(18, 22), match='1987'>
```

Puoi combinare caratteri letterali, sequenze speciali e quantificatori nello stesso pattern. Per esempio, il pattern `r'\d+ items'` corrisponde a una o più cifre, seguite da uno spazio e dalla parola `items`. Puoi anche combinarlo con il flag `re.IGNORECASE` in modo che le lettere possano essere minuscole o maiuscole:

```python
import re

cart = 'You have 3 ITEMS in your cart.'
print(re.search(r'\d+ items', cart, re.IGNORECASE))
# <re.Match object; span=(9, 16), match='3 ITEMS'>
```
