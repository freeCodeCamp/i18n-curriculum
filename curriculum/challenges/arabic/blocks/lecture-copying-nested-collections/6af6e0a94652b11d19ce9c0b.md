# --description--

لقد تعلمت أن التعيين ينشئ اسمًا مستعارًا وأن طريقة `.copy()` للقاموس تنشئ نسخة سطحية. النسخة السطحية لها قاموس خارجي منفصل، لكن الكائنات المسكنة لا تزال مشتركة. الآن بعد أن عرفت كيفية استيراد الوحدات، يمكنك استخدام وحدة `copy` المدمجة في مكتبة Python القياسية لنسخ المجموعات المسكنة أيضًا.

## إنشاء نسخة عميقة

تنسخ الدالة `copy.deepcopy()` المجموعات المسكنة بشكل متكرر. بالنسبة لقاموس يحتوي على قائمة، تنشئ قاموسًا خارجيًا جديدًا وقائمة مسكنة منفصلة:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
deep_copy = copy.deepcopy(original)

print(deep_copy == original) # True
print(deep_copy is original) # False
print(deep_copy['items'] is original['items']) # False

deep_copy['items'].append('fruit')
print(original['items']) # ['bread', 'cheese']
print(deep_copy['items']) # ['bread', 'cheese', 'fruit']
```

تحتوي القواميس في البداية على محتويات متساوية، لكن لا يتم مشاركة القاموس الخارجي ولا القائمة المسكنة بينهما. إضافة عناصر إلى القائمة المنسوخة لا تغير القائمة الأصلية.

## مقارنة التعيين والنسخ السطحي والنسخ العميق

لننشئ الأشكال الثلاثة كلها من نفس القاموس:

```python
import copy

original = {'name': 'Lunch', 'items': ['bread', 'cheese']}
alias = original
shallow_copy = original.copy()
deep_copy = copy.deepcopy(original)

print(alias is original) # True
print(shallow_copy is original) # False
print(deep_copy is original) # False

print(alias['items'] is original['items']) # True
print(shallow_copy['items'] is original['items']) # True
print(deep_copy['items'] is original['items']) # False
```

استمر مع هذه الكائنات، وغيّر إدخالًا على المستوى الأعلى من خلال كل اسم:

```python
alias['name'] = 'Picnic'
shallow_copy['name'] = 'Snack'
deep_copy['name'] = 'Dinner'

print(original['name']) # Picnic
print(alias['name']) # Picnic
print(shallow_copy['name']) # Snack
print(deep_copy['name']) # Dinner
```

الاسم المستعار يشير إلى القاموس الأصلي، لذا فإن التعيين عبر `alias` يغير ذلك القاموس. كل نسخة لها قاموس خارجي خاص بها، لذا فإن استبدال إدخال `name` يؤثر فقط على تلك النسخة.

بعد ذلك، عدّل القوائم المسكنة:

```python
alias['items'].append('water')
shallow_copy['items'].append('fruit')
deep_copy['items'].append('soup')

print(original['items']) # ['bread', 'cheese', 'water', 'fruit']
print(alias['items']) # ['bread', 'cheese', 'water', 'fruit']
print(shallow_copy['items']) # ['bread', 'cheese', 'water', 'fruit']
print(deep_copy['items']) # ['bread', 'cheese', 'soup']
```

القاموس الأصلي واسم المستعار والنسخة السطحية كلها تشير إلى نفس القائمة. التغييرات عبر أي من هذه المراجع تظهر في البقية. النسخة العميقة لها قائمتها الخاصة، لذا تبقى تغييراتها منفصلة.

هذا يعمل أيضًا مع القواميس المسكنة داخل القوائم:

```python
import copy

original = {'meals': [{'name': 'Lunch', 'items': ['bread']}]}
deep_copy = copy.deepcopy(original)
deep_copy['meals'][0]['items'].append('fruit')

print(original['meals'][0]['items']) # ['bread']
print(deep_copy['meals'][0]['items']) # ['bread', 'fruit']
```

هنا، تنسخ `deepcopy()` القاموس الخارجي، وقائمة `meals`، والقاموس داخل تلك القائمة، وقائمة `items` الخاصة به. المثال يستخدم القواميس والقوائم المدمجة؛ النسخ العميق لا يعني أن كل كائن Python ممكن يُكرر.

استخدم التعيين عندما تريد اسمًا آخر لنفس الكائن. استخدم النسخ السطحي عندما يكون وجود مجموعة خارجية منفصلة كافيًا ويُقبل مشاركة الكائنات المسكنة. استخدم النسخ العميق عندما يجب أن تبقى التغييرات على هذه المجموعات المسكنة منفصلة عن المجموعات الأصلية.
