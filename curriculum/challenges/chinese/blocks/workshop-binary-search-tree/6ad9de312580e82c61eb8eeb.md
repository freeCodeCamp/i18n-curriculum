# --description--

要插入一个值，你从根节点开始，如果该值小于节点的值就向左走，反之向右走，直到找到一个空位置。由于每个子树也是二叉搜索树，你可以用递归来实现这一过程。

在 `BinarySearchTree` 类中，创建一个名为 `_insert` 的方法，带有三个参数：`self`、`node` 和 `key`。前导下划线表示这是一个供内部使用的辅助函数。

在方法内部，添加一个 `if` 语句，检查 `key` 是否小于 `node.key`。在 `if` 语句内，调用 `self._insert`，传入 `node.left` 和 `key`，并将结果赋值给 `node.left`。这样就把值插入到左子树，并保持更新后的子树连接到当前节点。
