# --description--

L'ambito determina dove puoi usare una variabile nel tuo codice.

Python ha regole aggiuntive sull'ambito. Per ora, concentrati sull'ambito locale e globale.

Una variabile creata esternamente a una funzione ha ambito globale. Puoi usarla sia dentro che fuori dalle funzioni.

Una variabile creata all'interno di una funzione ha ambito locale. Puoi usarla solo dentro quella funzione. Anche i parametri della funzione sono variabili locali.

Ecco un esempio di ambito locale e globale:

```python
tax_rate = 0.1

def calculate_tax(price):
    tax = price * tax_rate
    return tax

print(calculate_tax(50)) # 5.0
print(tax_rate) # 0.1
print(tax) # NameError: name 'tax' is not defined
```

La variabile `tax_rate` è globale perché è creata esternamente alla funzione. La funzione `calculate_tax` può leggerla, e anche la seconda chiamata a `print()` può leggerla.

Il parametro `price` e la variabile `tax` sono locali a `calculate_tax`. Sono disponibili mentre quella funzione è in esecuzione, ma non al di fuori di essa. L'ultima chiamata a `print()` genera un `NameError` perché `tax` non è definita nell'ambito globale.
