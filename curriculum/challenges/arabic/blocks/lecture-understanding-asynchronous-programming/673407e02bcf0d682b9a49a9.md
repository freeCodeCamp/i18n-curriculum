# --description--

يمتلك محرك JavaScript القدرة على قراءة كودك وفهمه وتنفيذه. يعمل كمحول يأخذ كودك ويحوّله إلى تعليمات يمكن للكمبيوتر فهمها وتنفيذها.

أحد أشهر محركات JavaScript هو V8، الذي طورته Google، ويُستخدم في Chrome وNode.js. يعمل محرك JavaScript بعدة خطوات. أولاً، يُحلل كودك، يقرأه سطرًا بسطر للتأكد من عدم وجود أخطاء في كود JavaScript. ثم يحول هذا الكود إلى bytecode، وهو نسخة أبسط ومتوسطة من كودك تسهل على الكمبيوتر فهمها وتنفيذها. وأخيرًا، يشغّل هذا الـ bytecode لتنفيذ تعليمات برنامجك. إليك مثالًا على كود JavaScript:

```js
const greeting = "Hello, World!";
console.log(greeting);
```

عندما تشغّل هذا الكود، يبدأ محرك JavaScript بتحليله أولًا للتحقق من وجود أي أخطاء نحوية. التحليل يعني أن المحرك يقرأ الكود ويفككه إلى بنية يمكنه فهمها، مع التحقق من الأخطاء أثناء العملية.

بعد ذلك، يُجمّع الكود إلى صيغة وسيطة (غالبًا bytecode أو كود آلة، حسب المحرك). التجميع هو عملية تحويل الكود المقروء للبشر إلى صيغة أكثر كفاءة يمكن للكمبيوتر تنفيذها بسرعة أكبر.

أخيرًا، ينفذ المحرك الكود، ويطبع `Hello, World!` في وحدة التحكم.

الآن، لنتحدث عن وقت تشغيل JavaScript. وقت تشغيل JavaScript هو بيئة العمل التي يُنفذ فيها كود JavaScript الخاص بك. يشمل محرك JavaScript (مثل V8 في Chrome أو SpiderMonkey في Firefox)، الذي يعالج وينفذ الكود، بالإضافة إلى ميزات إضافية توفرها بيئة العمل (مثل متصفح الويب أو Node.js، والتي ستتعلم عنها أكثر في الدروس القادمة).

بينما تتعامل لغة JavaScript الأساسية مع أشياء مثل المتغيرات والحلقات والدوال، توفر بيئة التشغيل أدوات إضافية تسمح لـ JavaScript بالتفاعل مع أشياء خارج اللغة نفسها، مثل DOM (لصفحات الويب) أو Fetch API (لإجراء طلبات الشبكة).

باختصار، بيئة التشغيل هي التي تسمح لـ JavaScript بأداء أكثر من مجرد مهام برمجية أساسية – مثل التفاعل مع صفحات الويب أو التعامل مع الإجراءات الزمنية – من خلال توفير هذه الميزات الإضافية خارج اللغة نفسها.

بينما لا تحتاج إلى معرفة كل تفاصيل المحركات وبيئات التشغيل لكتابة JavaScript، فإن فهمًا أساسيًا يمكن أن يساعدك على كتابة كود أكثر كفاءة ومعالجة الأخطاء بشكل أفضل.
