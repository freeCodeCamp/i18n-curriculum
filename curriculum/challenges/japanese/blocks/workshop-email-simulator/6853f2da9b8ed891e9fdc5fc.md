# --description--

送信者と受信者の情報を表示する時間です。名前がきれいに縦に揃うように、それぞれの名前の前のテキストにフォーマット指定子で固定幅を与えてください。

`display_full_email` メソッドに2つの出力文を追加してください。

- `'From:'` を幅 `10` で左寄せし、その後に送信者の名前を続けます。
- `'To:'` を幅 `10` で左寄せし、その後に受信者の名前を続けます。

例えば、送信者が `Alice` で受信者が `Bob` の場合、2行は次のようになります。

```md
From:     Alice
To:       Bob
```
