# --description--

平均と等しい温度にはラベルが `0.0 °C` と付けられていますが、これは読みづらいです。代わりにラベルは `average` にするべきです。

`else` の後に別の条件式を書くことで条件式を連結できます。最初の条件が偽の場合、Python は次の条件式を評価します。

```py
labels = [
    'large' if num > 100
    else 'medium' if num > 10
    else 'small'
    for num in numbers
]
```

条件式を更新して、`difference` が `0` より大きい場合は `f'+{difference} °C'`、`difference` が `0` より小さい場合は `f'{difference} °C'`、それ以外の場合は文字列の `average` を評価するようにしてください。
