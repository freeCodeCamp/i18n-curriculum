# --description--

Das `type`-Attribut sagt dem Browser, welche Art von Daten ein `input` akzeptieren soll. Einige gängige Werte für das `type`-Attribut sind:

- `text`: ein einzeiliges Textfeld
- `email`: ein Textfeld, das überprüft, ob der Benutzer eine gültige E-Mail-Adresse eingibt
- `number`: ein Feld für Zahlen
- `radio` und `checkbox`: Optionen, die der Benutzer auswählen kann

Hier ist ein Beispiel für eine Texteingabe:

```html
<input type="text">
```

Fügen Sie dem vorhandenen `input`-Element ein `type`-Attribut mit dem Wert `"text"` hinzu.

Geben Sie dem `input`-Element außerdem ein `id`-Attribut mit dem Wert `"full-name"`. Dieses entspricht dem `for`-Attribut Ihres `label`-Elements, das die beiden miteinander verbindet.

Wenn ein Benutzer seinen vollständigen Namen angibt, akzeptiert das `input` einfachen Text.
